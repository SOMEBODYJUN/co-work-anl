# 两设施异构允许集：六顶点、每对至多两共有客户的 2 下界

2026-09-30。本定理独立于任何全局 φ 上界、异构 2 上界或候选菜单完备性。**本文只证明下界 2，不声称已经证明一般异构模型上界 2。**

## 1. 定理

**定理。** 对每个 `1≤α<2`，存在只有六名正有理加权客户、两家设施各有两个允许位置的实例，使：

1. 每个合法设施位置对至多有两名共有客户；
2. 每个客户子博弈的独立混合 NE 唯一，且为纯均衡；事实上 CE 和 CCE 也唯一；
3. 不存在 α 近似纯设施位置 SPE，甚至允许任意客户 CE／CCE continuation 也不能挽救；
4. 实例可表示为六顶点无向图上的闭邻域可达模型，全部顶点权重严格为正，两允许集不交且各有两个位置。
5. 所有结论保持于任意客户特定严格递增成本 `E[f_i(L)]`，只要求同一客户在两设施使用相同的 `f_i`。

因此，已知每对至多一名共有客户的 ρ≈1.80194 紧界，**一旦放宽到至多两名共有客户，就不能保留任何小于 2 的统一上界**。

## 2. 二部表述与六个客户

取任意有理 `0<ε<1/4`。位置为 A、B、C、D；设施 1 仅可选择 `{A,B}`，设施 2 仅可选择 `{C,D}`。六名客户如下：

| 客户 | 权重 | 可达允许位置 |
|---|---:|---|
| x | `1` | A、B、C |
| y | `ε` | A、B、D |
| z | `1+8ε` | A、C、D |
| t | `1+2ε` | B、C、D |
| b | `10ε` | B |
| c | `6ε` | C |

对应四个位置的客户集合为

`C_A={x,y,z}`,

`C_B={x,y,t,b}`,

`C_C={x,z,t,c}`,

`C_D={y,z,t}`。

四个合法交集恰为

| 合法布局 | 共有客户 |
|---|---|
| AC | x、z |
| AD | y、z |
| BC | x、t |
| BD | y、t |

所以 κ=2；既没有遗漏其他合法布局，也没有使用不合法共址布局。

## 3. 四个子博弈的全部混合 NE、CE、CCE 均唯一

以下严格比较直接对其他客户的每个可能纯实现成立，因而对任何独立混合或相关分布也成立。先有严格占优客户，再在其必然行动下确定另一客户，排除了额外混合均衡及额外 CE／CCE。

### AC

独占客户负载为 A 端 `ε`、C 端 `1+8ε`；共享客户为 `x=1`、`z=1+8ε`。

客户 z 去 A 与去 C 的成本差（自身重量消去）为

`−(1+7ε) ± 1`。

无论 x 选哪边都严格小于零，所以 z 严格选择 A。给定这一点，x 选择 A 的实现负载为 `2+9ε`，选择 C 的实现负载为 `2+8ε`，所以 x 严格选择 C。

唯一负载为

`AC : (1+9ε, 2+8ε)`。

### AD

独占负载为 A 端 `1`、D 端 `1+2ε`；共享客户为 `y=ε`、`z=1+8ε`。

z 去 A 与去 D 的成本差为 `−2ε±ε<0`，故 z 严格选择 A。给定 z 去 A，y 去 A 的成本为 `2+9ε`，去 D 的成本为 `1+3ε`，故 y 严格选择 D。

唯一负载为

`AD : (2+8ε, 1+3ε)`。

### BC

独占负载为 B 端 `11ε`、C 端 `1+14ε`；共享客户为 `x=1`、`t=1+2ε`。

x 去 B 与去 C 的成本差为 `−(1+3ε)±(1+2ε)`，最大值为 `−ε<0`；t 去 B 与去 C 的成本差为 `−(1+3ε)±1`，最大值为 `−3ε<0`。所以二者均严格选择 B。

唯一负载为

`BC : (2+13ε, 1+14ε)`。

### BD

独占负载为 B 端 `1+10ε`、D 端 `1+8ε`；共享客户为 `y=ε`、`t=1+2ε`。

t 去 B 与去 D 的成本差为 `2ε±ε>0`，故 t 严格选择 D。给定这一点，y 去 B 的成本为 `1+11ε`，去 D 的成本为 `2+11ε`，故 y 严格选择 B。

唯一负载为

`BD : (1+11ε, 2+10ε)`。

### 为什么 CCE 也唯一

对任何严格占优客户，若联合分布对其劣行动赋正概率，无条件偏离到占优行动会严格降低期望成本；因此任何 CCE 都以概率 1 使用其占优行动。在此已固定行动下，第二名共有客户的严格偏好同样把其行动固定。独占客户无选择。故每个布局的联合分布本身唯一，而非仅 NE 唯一。

这一步没有一般性地把“唯一 NE”误读成“唯一 CCE”。

### 任意严格递增客户成本的稳健性

上文先行客户的比较对另一客户的每个纯行动均严格同向，后行客户则面对确定负载。将客户 i 的实现负载成本改为任意严格递增 `f_i(L)`，每个这样的逐实现严格比较保持。故所有严格占优消元、NE／CE／CCE 唯一性及设施收益表都不变。这里无需二次函数战略等价性，也没有将 `E[f_i(L)]` 换成 `f_i(E[L])`。

## 4. 四步严格改善环及精确最优因子

唯一客户 continuation 给出的收益表为

| 设施 1／设施 2 | C | D |
|---|---|---|
| A | `(1+9ε, 2+8ε)` | `(2+8ε, 1+3ε)` |
| B | `(2+13ε, 1+14ε)` | `(1+11ε, 2+10ε)` |

考虑改善环

`AC → BC → BD → AD → AC`。

各步偏离者收益比分别为

`r₁=(2+13ε)/(1+9ε)`，

`r₂=(2+10ε)/(1+14ε)`，

`r₃=(2+8ε)/(1+11ε)`，

`r₄=(2+8ε)/(1+3ε)`。

对于 `0<ε<1/4`，这四数均大于 1，各布局的另外一个偏离则严格降低收益。且 `r₂` 是四者中的最小值：

`(2+13ε)(1+14ε)−(2+10ε)(1+9ε)=13ε+92ε²>0`，

`(2+8ε)(1+14ε)−(2+10ε)(1+11ε)=4ε+2ε²>0`，

`(2+8ε)(1+14ε)−(2+10ε)(1+3ε)=20ε+82ε²>0`。

所以本实例的**精确最优近似因子**是

`α*(ε)=r₂=(2+10ε)/(1+14ε)=2−18ε/(1+14ε)`。

给定 `1≤α<2`，任选正有理

`ε < min{1/4, (2−α)/(14α−10)}`。

分母 `14α−10>0`。于是 `r₂>α`，每个合法布局都存在因子严格大于 α 的偏离。由于客户 continuation 唯一，没有其他后续均衡可以改变结论。证毕。

## 5. 六顶点正权无向图实现

将客户 `x,y,z,t,b,c` 分别置于六个图顶点 `A,B,C,D,E,F`。取无向边

`AB, AC, BD, CD, BE, CF`。

客户可达自己与所有相邻顶点；允许位置仍为设施 1 的 `{A,B}`、设施 2 的 `{C,D}`。顶点权重依次为

`(1, ε, 1+8ε, 1+2ε, 10ε, 6ε)`。

这是四环 `A−B−D−C−A`，加 B 端叶子 E 与 C 端叶子 F。E、F 不是允许位置。它们的自可达以及 B→E、C→F 不影响任何合法布局，但每个图顶点都具有正权客户和自可达性。四个允许位置的闭邻域客户集合恰等于第 2 节的四集合。

因此本例同时适用于要求位置也是客户顶点的原图模型；不需要零权占位顶点、方向性、客户相关随机化或未计入的站点客户。

## 6. 精确整数例

取 `ε=1/1000`，整体乘 1000 得顶点权重

`(A,B,C,D,E,F)=(1000,1,1008,1002,10,6)`。

收益表变为

| 设施 1／设施 2 | C | D |
|---|---|---|
| A | `(1009,2008)` | `(2008,1003)` |
| B | `(2013,1014)` | `(1011,2010)` |

四改善比分别为

`2013/1009`, `2010/1014=335/169`, `2008/1011`, `2008/1003`。

最优近似因子精确为

`335/169 ≈ 1.982248520710059`。

这已经严格大于 ρ。例如 `335/169>19/10`，而 `ρ<19/10` 因为 `q(19/10)=q(z)=z³−z²−2z+1` 在该点为 `449/1000>0` 且 q 在 `[φ,∞)` 严格递增。

更一般地取整数 `M>4`，令权重

`(M,1,M+8,M+2,10,6)`，

则精确最优因子为 `(2M+10)/(M+14)`，随 M→∞ 从下方趋于 2。

输入生成器为 `tight_two_family.py`。例如：

```bash
python tight_two_family.py --M 1000 --output tight_two_M1000.json
python bounded_overlap.py tight_two_M1000.json --output tight_two_M1000.certificate.json
```

## 7. 范围与后续目标

本定理把两设施异构允许集的一般下界从 ρ 提高到 2，并且只需每个交叉位置对两名共有客户、六个无向图顶点、两种目录各两位置。它不构成任何共同允许集模型的反例，因为此处不允许双方互换目录，也不允许四个共址布局。

若一般异构 2 上界能被证明，则此六顶点参数族立即给出紧性；在上界证明尚未闭合前，应将结论表述为“通用最优常数至少 2”，不能称一般问题已经解决。
