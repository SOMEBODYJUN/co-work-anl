# 加权拥塞：从局部费用到全局稳定

这篇讲义先回答一个问题，再解释构造：给定一个有限的加权拥塞博弈，能否找到一个纯状态，使每个玩家的任何单人偏离至多把自己的成本降低一个固定倍率？当资源费用是高次多项式、玩家的重量不可再分时，这个倍率的最坏情形是多少？

前两篇研究的是“设施先选位置、客户再选设施”的两阶段博弈。那里要挑选每个位置的客户均衡，才能控制设施偏离；这里把两阶段外壳去掉，直接研究玩家选择资源集合的拥塞博弈。两篇工作的共同问题是“局部偏离比较怎样变成全局稳定状态”，但第三篇的技术障碍换成了：同一个玩家在多个资源上的局部比较，能不能用同一个尺度拼起来；如果只在一小块结构化状态上安排偏离，怎样保证游戏里的其他状态也不稳定。

## 1. 问题先说清楚

设 `d` 是资源费用的次数上界。我们问两件不同的事。

**存在性问题。** 是否有一个只依赖 `d` 的倍率 `α`，使每一个这样的博弈都有一个 `α`-稳定的纯状态？

**反例问题。** 能否造出一个合法博弈，使每一个纯状态都有一个严格的改善偏离，从而排除某个更小的倍率？

把所有次数至多 `d` 的博弈放在一起，记它们的最坏存在性阈值为

`a*(d) = inf{ α≥1 : 每个次数至多 d 的博弈都有 α-PNE }`。

已知的存在性上界是 `d`。第三篇的反例把下界推到

`d − 1200⌈log₂ d⌉²`（`d ≥ 2²⁰`），所以最坏倍率的增长阶是线性的；这不等于已经求出每个有限 `d` 的精确阈值。

先看最小的原子效应。一个重量为 `1` 的玩家若把自己放进负载为 `y` 的资源，偏离后的负载是 `y+1`，而不是把一单位连续流平滑地摊开。若费用是 `c(x)=xᵈ`，这一步的成本是 `(y+1)ᵈ`。因此“资源现在看起来空”并不足以判断偏离便宜；必须把偏离者自己的整份重量放进新负载。

## 2. 模型和量词

玩家集合 `I`、资源集合 `E` 都有限。玩家 `i` 有正重量 `wᵢ>0`，策略族 `Sᵢ` 是 `2ᴱ` 的非空有限子集；一个策略 `sᵢ` 是玩家选择的资源子集。纯状态为 `s=(sᵢ)ᵢ∈I`。

资源 `e` 在状态 `s` 的总负载是

`xₑ(s) = Σᵢ:e∈sᵢ wᵢ`。

每个资源的费用是非负系数多项式

`cₑ(x) = Σₖ₌₀ᵈ aₑ,ₖ xᵏ`, 其中 `aₑ,ₖ ≥ 0`。

玩家 `i` 的成本是它所选资源费用之和：

`Cᵢ(s) = Σₑ∈sᵢ cₑ(xₑ(s))`。

注意这里的成本约定不再额外乘 `wᵢ`；重量已经通过资源负载进入费用。若玩家改用另一策略 `tᵢ`，必须重新计算所有被删去和加入的资源负载，得到 `Cᵢ(tᵢ,s₋ᵢ)`。

当 `α≥1` 时，状态 `s` 称为 `α`-PNE，如果对每个玩家和每个合法偏离都有

`Cᵢ(s) ≤ α Cᵢ(tᵢ,s₋ᵢ)`。

上界问题的量词是 `对每个博弈 G，存在一个状态 s`；反例问题的量词相反，是 `对每个状态 s，存在一个玩家和偏离 tᵢ`。零成本时仍使用这个不等式，不把它改写成除法。

社会成本是另一个对象：

`W(s) = Σᵢ wᵢ Cᵢ(s) = Σₑ xₑ(s)cₑ(xₑ(s))`。

以后谈社会最优时，`OPT` 指在**全体纯状态**上的最小 `W`，不能只在一个前沿子集上取最小值。

### 一个可以手算的偏离

有两个玩家，重量分别为 `1` 和 `1/2`；两个资源都收取 `c(x)=x²`，每个玩家都可以选其中一个。若两人都在资源 `e` 上，负载是 `3/2`，每人的当前资源费用是 `9/4`。重量为 `1` 的玩家改去空资源 `f` 后，`f` 的新负载是 `1`，所以偏离费用是 `1`；比较的是 `9/4` 与 `1`，而不是把一单位“流量”从 `e` 平滑地挪走。这个自重进入新负载的事实，是后面所有端点和门计算的起点。

## 3. 第一个缺口：局部边际怎样拼成一个势

假设我们给每个资源安排一个集合函数 `Hₑ`，并把所有资源相加成 `Φ(s) = Σₑ Hₑ(s)`。玩家插入资源 `e` 后的势增量记为 `ΔᵢHₑ`。要让一次多资源偏离的增量可以相加，必须存在同一个玩家尺度 `qᵢ`，在它能切换的每个资源上都满足

`qᵢ cₑ(Y) ≤ ΔᵢHₑ ≤ βqᵢ cₑ(Y)`，

其中 `Y` 是插入玩家后的资源负载，`β` 是想要的近似倍率。

删去资源使用左边界，加入资源使用右边界，求和得到

`Φ(t) − Φ(s) ≤ qᵢ[βCᵢ(tᵢ,s₋ᵢ) − Cᵢ(s)]`。

于是一次严格的 `β`-改善会严格降低有限状态空间上的 `Φ`，改进路径终止，势的全局最小点就是 `β`-PNE。

这一步交付的不是一个已经存在的势，而是一个明确的接口：**每个资源的局部边际必须用同一个玩家尺度连接起来。** 如果不同资源给同一玩家不同的尺度，删去项和加入项就不能合成上面的一条全局不等式。

## 4. 本质一：端点费用和面积费用不是同一种量

高次费用放大的来源可以先用一个没有博弈符号的计算看清。对 `f(t)=tᵈ`，区间 `[0,1]` 的端点值是 `1`，而面积是

`∫₀¹ tᵈ dt = 1/(d+1)`。

所以端点相对于面积的比例是 `d+1`。若用很多很小的原子去采样这个区间，右端点和会逼近面积；若只有一个大原子，右端点效应就会保留下来。

一般地，令 `0 = x₀ < ⋯ < xₙ = Q`，最大原子间隔为 `h`，背景负载为 `b`，`T=b+Q`。对任意非减函数 `f`，右端点和满足

`∫ᵦᵀ f(t)dt ≤ Σⱼ (xⱼ−xⱼ₋₁)f(b+xⱼ)`，

`Σⱼ (xⱼ−xⱼ₋₁)f(b+xⱼ) ≤ ∫ᵦᵀ f(t)dt + h[f(T)−f(b)]`。

误差由 `h` 控制，而不是由窗口总质量 `Q` 单独控制。于是有两个独立旋钮：窗口有多大，以及每个原子有多粗。

在反例里，重玩家提供端点，许多轻玩家提供近似面积。令重权为 `1`，轻权为 `1/R`，窗口总轻质量为 `m=K/R`，写

`P = (1+m)ᵈ`, `X = Σⱼ₌₁ᴷ (1+j/R)ᵈ`, `Y = Σⱼ₌₁ᴷ (j/R)ᵈ`。

目标倍率 `α` 传播一次时，局部合同是

`Γ = (αX − Y)/(R(P − α))`。

选择参数使 `P>α` 且 `Γ<1`，就得到一个严格的局部传播余量。把网格变细后，有限阈值逼近

`α_area(d,m) = ((d+1)(1+m)ᵈ + mᵈ⁺¹)/(d + (1+m)ᵈ⁺¹)`。

这个阈值只说明**一次局部传播**可以成功；它没有排除整个游戏中的稳定状态。后面还需要把传播接成环，并处理所有没有落在传播前沿上的状态。

## 5. 本质二：共同尺度和权重类型图

现在回到“怎样拼成势”。一个资源上若有重权 `a` 和轻权 `b` 两种可动玩家，可以把同一资源的用户按两种顺序写成右端点和。重玩家最后插入时的边际是 `a c(Y)`；轻玩家最后插入时的边际也是 `b c(Y)`，但换一种顺序会出现最多 `d` 倍的上界。

把两种顺序按比例混合，可以为重类型和轻类型分别得到局部尺度。若记两类尺度的比值为 `r = t_b/t_a`，要用同一个倍率 `β` 包住两类边际，必须满足

`r ≤ β`，

`1+(d−1)/r ≤ β`。

在一棵类型森林里，可以沿每条边取同一个最优比值

`a(d) = (1+√(4d−3))/2`，

从而得到约 `√d` 的存在性保证。

如果类型图有环，沿环相乘后必须回到原尺度。于是出现两类乘积不等式，例如对一次环行的重到轻步数 `p` 和轻到重步数 `q`，需要

`βᑫ(β−1)ᵖ ≥ (d−1)ᵖ`，

`βᵖ(β−1)ᑫ ≥ (d−1)ᑫ`。

环不满足这些条件，只能说明**这套共同尺度证书**无法闭合；它不说明原博弈没有 `β`-PNE。独立的空策略或其他势仍可能给出均衡，这个边界必须保留。

当资源上有很多权重类型时，第三种办法是按严格递减的潜在共用关系给玩家排层。若最长递减路径有 `h` 个玩家，定义 `A = A(d,h)` 为方程

`A = Σⱼ₌₀ʰ⁻¹ ((d−1)/A)ʲ`

的正根。按层混合有序右端点和，可以得到 `A`-PNE。反过来，没有 `α`-PNE 的游戏必须有足够长的递减深度；当 `α` 接近 `d` 时，所需深度也接近线性。深度是必要条件，不是失稳的充分条件。

## 6. 本质三：前沿上的证明还不是全状态证明

局部传播通常只看一类有序二元状态。以三位串为例，至多一次变化的前沿是

`000, 001, 011, 111, 110, 100`，

而 `010`、`101` 是非法的交替串。即使已经证明前沿上的每一个状态都有改善偏离，非法串仍可能是稳定点，所以还不能得到全状态反例。

解决办法是加入真实的拥塞资源作为“锚定门”。对同一权重类的锚点、位置 `j`、位置 `k`，门只由这三个玩家的动作决定；当动作出现 `010` 或 `101` 时，三人同用一侧，费用为 `v`；在前沿上只形成二人组和单人，移动者至多支付 `u`。令 `B` 是基体游戏中该类玩家的最大成本，`L` 是它参与的门数。若

`v > α(B + Lu)`，

则离开前沿会立刻触发大费用，非法状态有严格的纠正偏离；从前沿跳出去的偏离也不会成为 `α`-改善。

门必须被写成真正的资源、真正的非负多项式费用和不改变的玩家动作，不能直接把任意状态成本表叫作拥塞实现。并且近似稳定在前沿内部会留下一个加性容差：门在两个前沿端点上都有共同的二人组成本 `u`，所以基体偏离必须超过这项容差才算真正被排除。

## 7. 四个接口怎样合成一个全状态反例

反例的四个接口各自承担不同义务：

| 接口 | 反映的本质 | 交付的义务 | 删除它会怎样 |
| --- | --- | --- | --- |
| 同权二元时钟 | 一个权重类的状态顺序 | 把状态排成有前沿的位串 | 失去可追踪的相位 |
| 相邻权层短窗 | 端点和面积的差异 | 把一次改善从一层传到下一层 | 传播余量断掉 |
| 回返窗口（return） | 局部余量的闭合 | 处理相邻测试没有覆盖的相位 | 环上留下未处理状态 |
| 锚定门 | 非法状态的强制纠正 | 把前沿证明扩展到全体纯状态 | 可能留下前沿外的均衡 |

先在乘积前沿 `F` 上覆盖所有相位。相邻测试把第 `a` 类的位串和第 `a+1` 类的位串接到一对真实资源上：如果两条前沿的切换位置相差超过短窗，重玩家的端点成本与轻玩家的面积成本给出严格改善；如果每个相邻差都落在短窗内，就把这些短差沿环相加。剩下的两种奇偶相位由 回返资源分别封口，最后一类轻玩家得到严格改善。这个“相邻测试 + 回返”步骤交付的是前沿上每一个状态都有出口，而不是只找到一个改善环。

再用锚定门排除 `F` 外的状态。这样才得到“对每个纯状态都有严格偏离”的全状态结论。

参数化家族的结论是：对每个 `d≥2²⁰`，取 `ℓ=⌈log₂d⌉` 和 `n=⌈d/(1200ℓ²)⌉`，可以把所有资源费用取为正有理的纯 `d` 次幂，并构造一个合法有限博弈，使每个状态都有严格的 `(d−1200ℓ²)`-改善。这个结论的量词是“每个状态都有一个真实单人偏离”；它不是“发现一个改善环”，也不是“有限枚举没找到均衡”。

还要分清两个参数制度：若先固定 `c∈(0,1)`，可以先选一个固定的 `n>1/(1−c)`，再取充分大的 `d`，得到没有 `cd`-PNE 的族；这不能把 `c` 改成随 `d` 趋近 `1` 的函数后仍沿用同一个固定 `n`。

## 8. 同一组工具何时改善存在性

反例和正向结果使用同一分析，但假设方向相反。

**小原子份额。** 若在每个相关状态中，玩家 i 选择资源 e 且它是可选用户时，都满足 `wᵢ/xₑ(s)≤η≤1`，积分势给出

`K_d(η) = [1 − (1−η)ᵈ⁺¹]/[(d+1)η]`，

并存在 `K_d(η)^{-1}`-PNE。当 `dη` 很小时，这个倍率趋近 `1`。条件必须在所有相关状态检查；只检查一个状态不够。

**类型森林或有限深度。** 森林中的共同尺度给出约 `√d` 的保证；有限递减深度给出 `A(d,h)` 的保证。它们是有结构的子类结论，不是把全类的线性下界推翻。

**社会成本。** 个体稳定只需要势的局部最小；要同时比较社会成本，必须再加入 `W` 的边际界、前沿上的共同门成本恒移，以及把基体最优转移到完整游戏的外部性条件。门的一个典型外部性预算是 `3v−2u−z>(p+1)B`：触发门被消除的社会收益必须超过基体费用增加。前沿上的最优值未经这一步不能代替全游戏的 `OPT`。

## 9. 边界和读者应带走的四句话

1. 端点—面积差异说明高次费用的放大从哪里来，但它只是局部传播接口。
2. 共同玩家尺度说明多个局部比较何时能拼成一个全局势；尺度证书失败不等于博弈没有均衡。
3. 锚定门说明前沿上的结构化证明怎样扩成全状态证明；门的余量必须写进近似稳定不等式。
4. 四个接口合在一起才给出近线性全状态反例；同一工具在小份额、森林或有限深度条件下又给出较好的存在性保证。

文献中的 `d`-近似存在性上界和较早的 `√d/log d` 下界是外部结果；这里的端点、共同尺度、门实现、全状态反例和正向条件按各自的假设使用。有限算例可以帮助检查转录，但不能替代对所有参数和所有状态的证明。
