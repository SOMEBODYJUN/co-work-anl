# 加权拥塞：从局部费用到全局稳定

这篇讲义先回答一个问题，再解释构造：给定一个有限的加权拥塞博弈，能否找到一个纯状态，使每个玩家的任何单人偏离至多把自己的成本降低一个固定倍率？当资源费用是高次多项式、玩家的重量不可再分时，这个倍率的最坏情形是多少？

前两篇研究的是“设施先选位置、客户再选设施”的两阶段博弈。那里要挑选每个位置的客户均衡，才能控制设施偏离；这里把两阶段外壳去掉，直接研究玩家选择资源集合的拥塞博弈。两篇工作的共同问题是“局部偏离比较怎样变成全局稳定状态”，但第三篇的技术障碍换成了：同一个玩家在多个资源上的局部比较，能不能用同一个尺度拼起来；如果只在一小块结构化状态上安排偏离，怎样保证游戏里的其他状态也不稳定。

## 1. 问题先说清楚

设 `d` 是资源费用的次数上界。我们问两件不同的事。

**存在性问题。** 是否有一个只依赖 `d` 的倍率 `α`，使每一个这样的博弈都有一个 `α`-稳定的纯状态？

**反例问题。** 能否造出一个合法博弈，使每一个纯状态都有一个严格的改善偏离，从而排除某个更小的倍率？

把一个具体博弈记为 `G`，把 `PNE` 读作“纯纳什均衡”。若 `𝒢(d)` 表示所有费用次数至多 `d` 的合法博弈，记它们的最坏存在性阈值为

`α⋆(d) = inf{ α≥1 : 对每个 G∈𝒢(d)，存在 α-PNE }`。

已知的存在性上界是 `d`。第三篇的反例把下界推到

`d − 1200⌈log₂ d⌉²`（`d ≥ 2²⁰`），所以最坏倍率的增长阶是线性的；这不等于已经求出每个有限 `d` 的精确阈值。

先看最小的原子效应。一个重量为 `1` 的玩家若把自己放进负载为 `y` 的资源，偏离后的负载是 `y+1`，而不是把一单位连续流平滑地摊开。若费用是 `c(x)=xᵈ`，这一步的成本是 `(y+1)ᵈ`。因此“资源现在看起来空”并不足以判断偏离便宜；必须把偏离者自己的整份重量放进新负载。

## 2. 模型和量词

玩家集合 `I`、资源集合 `E` 都有限。玩家 `i` 有正重量 `wᵢ>0`，策略族 `Sᵢ` 是 `2ᴱ` 的非空有限子集；一个策略 `sᵢ` 是玩家选择的资源子集。纯状态为 `s=(sᵢ)ᵢ∈I`。

资源 `e` 在状态 `s` 的总负载是

`xₑ(s) = Σᵢ:e∈sᵢ wᵢ`。

每个资源的费用是非负系数多项式

`cₑ(x) = Σₖ₌₀ᵈ aₑ,ₖ xᵏ`, 其中 `aₑ,ₖ ≥ 0`。

玩家 `i` 的成本是它所选资源费用之和：

`Cᵢ(s) = Σₑ∈sᵢ cₑ(xₑ(s))`。

注意这里的成本约定不再额外乘 `wᵢ`；重量已经通过资源负载进入费用。若玩家改用另一策略 `tᵢ`，必须重新计算所有被删去和加入的资源负载，得到 `Cᵢ(tᵢ,s₋ᵢ)`；这里 `s₋ᵢ` 表示除玩家 `i` 外其他玩家的策略保持原样，`(tᵢ,s₋ᵢ)` 是偏离后的完整状态。

当 `α≥1` 时，状态 `s` 称为 `α`-PNE，如果对每个玩家和每个合法偏离都有

`Cᵢ(s) ≤ α Cᵢ(tᵢ,s₋ᵢ)`。

上界问题的量词是 `对每个博弈 G，存在一个状态 s`；反例问题的量词相反，是 `对每个状态 s，存在一个玩家和偏离 tᵢ`。零成本时仍使用这个不等式，不把它改写成除法。

社会成本是另一个对象：

`W(s) = Σᵢ wᵢ Cᵢ(s) = Σₑ xₑ(s)cₑ(xₑ(s))`。

以后谈社会最优时，定义

`OPT(G) = min{ W(s) : s∈∏ᵢSᵢ }`。

这个最小值是在**全体纯状态**上取的，不能只在一个前沿子集上取最小值。

### 一个可以手算的偏离

有两个玩家，重量分别为 `1` 和 `1/2`；两个资源都收取 `c(x)=x²`，每个玩家都可以选其中一个。若两人都在资源 `e` 上，负载是 `3/2`，每人的当前资源费用是 `9/4`。重量为 `1` 的玩家改去空资源 `f` 后，`f` 的新负载是 `1`，所以偏离费用是 `1`；比较的是 `9/4` 与 `1`，而不是把一单位“流量”从 `e` 平滑地挪走。这个自重进入新负载的事实，是后面所有端点和门计算的起点。若 `α<9/4`，这里的状态就满足 `9/4>α·1`，因此重量为 `1` 的玩家的偏离已经严格改善；这个小例同时展示了 `α`-PNE 不等式的方向。

## 3. 第一个缺口：局部边际怎样拼成一个势

假设我们给每个资源安排一个定义在其可选用户集合上的集合函数 `Hₑ`，并把所有资源相加成 `Φ(s) = Σₑ Hₑ(s)`。把玩家 `i` 插入资源 `e` 的增量记为 `Δᵢ⁺Hₑ`，把它从资源 `e` 删除所减少的势记为 `Δᵢ⁻Hₑ`。对加入资源记 `Yₑ⁺=xₑ(t)`（偏离后的目标负载），对删除资源记 `Yₑ⁻=xₑ(s)`（偏离前仍含有玩家的当前负载）。于是同一条边际合同写成

`qᵢcₑ(Yₑ^±)≤Δᵢ^±Hₑ≤βqᵢcₑ(Yₑ^±)`。

这里的 `±` 只是把两种负载分别记号化，并不是把删除也当成使用目标负载。若 `t=(tᵢ,s₋ᵢ)`，要让一次多资源偏离的增量可以相加，必须在这条逐资源夹逼接口中使用同一个玩家尺度 `qᵢ`，并取 `β≥1`；`qᵢ` 已把玩家重量吸收到尺度里，例如可写成 `qᵢ=wᵢtᵢ`。这里的 `tᵢ` 只是玩家的尺度，不是后面玩家降权图中的层秩。

令 `A=sᵢ∖tᵢ` 是删去的资源，`B=tᵢ∖sᵢ` 是加入的资源，`R=sᵢ∩tᵢ` 是保留的资源。保留资源的势增量为零，所以

`Φ(t)−Φ(s) = Σ_{e∈B}Δᵢ⁺Hₑ − Σ_{e∈A}Δᵢ⁻Hₑ`。

对加入项用上界、对删去项用下界，得到 `qᵢ[βΣ_{e∈B}cₑ(xₑ(t))−Σ_{e∈A}cₑ(xₑ(s))]`。再把保留资源的非负项 `qᵢ(β−1)Σ_{e∈R}cₑ(xₑ(s))` 加回右边，便得到

`Φ(t) − Φ(s) ≤ qᵢ[βCᵢ(tᵢ,s₋ᵢ) − Cᵢ(s)]`。

于是一次严格的 `β`-改善会严格降低有限状态空间上的 `Φ`，改进路径终止，势的全局最小点就是 `β`-PNE。

这一步交付的不是一个已经存在的势，而是一个明确的接口：**每个资源的局部边际必须用同一个玩家尺度连接起来。** 如果不同资源给同一玩家不同的尺度，删去项和加入项就不能合成上面的一条全局不等式。

## 4. 本质一：端点费用和面积费用不是同一种量

高次费用放大的来源可以先用一个没有博弈符号的计算看清。对 `f(t)=tᵈ`，区间 `[0,1]` 的端点值是 `1`，而面积是

`∫₀¹ tᵈ dt = 1/(d+1)`。

所以端点相对于面积的比例是 `d+1`。若用很多很小的原子去采样这个区间，右端点和会逼近面积；若只有一个大原子，右端点效应就会保留下来。

一般地，令 `0 = x₀ < ⋯ < xₙ = Q`，最大原子间隔为 `h`，背景负载为 `b`，`T=b+Q`。对任意非减函数 `f`，右端点和满足

`∫ᵦᵀ f(t)dt ≤ Σⱼ (xⱼ−xⱼ₋₁)f(b+xⱼ)`，

`Σⱼ (xⱼ−xⱼ₋₁)f(b+xⱼ) ≤ ∫ᵦᵀ f(t)dt + h[f(T)−f(b)]`。

误差由 `h` 控制，而不是由窗口总质量 `Q` 单独控制。于是有两个独立旋钮：窗口有多大，以及每个原子有多粗。

在反例里，重玩家提供端点，许多轻玩家提供近似面积。令 `K,R∈ℕ` 且 `K≥1,R≥1`，重权为 `1`，轻权为 `1/R`，窗口总轻质量为 `m=K/R`，写

`P = (1+m)ᵈ`, `X = Σⱼ₌₁ᴷ (1+j/R)ᵈ`, `Y = Σⱼ₌₁ᴷ (j/R)ᵈ`。

目标倍率 `α` 传播一次时，局部合同是

`Γ = (αX − Y)/(R(P − α))`。

这里必须先有 `P>α`。并且

`1−Γ = [R(P−α)−αX+Y]/[R(P−α)]`。

因此 `Γ<1` 等价于分子严格为正，这个正数就是一次传播留下的余量。有限网格的临界值是 `(P+Y/R)/(1+X/R)`；把 `R` 增大、保持 `m=K/R`，它逼近

`α_area(d,m) = ((d+1)(1+m)ᵈ + mᵈ⁺¹)/(d + (1+m)ᵈ⁺¹)`。

这个阈值只说明**一次局部传播**可以成功；它没有排除整个游戏中的稳定状态。后面还需要把传播接成环，并处理所有没有落在传播前沿上的状态。

## 5. 本质二：共同尺度和权重类型图

现在回到“怎样拼成势”。先限定这一小节的适用域：每个资源至多有两种可选玩家权重。把不同的权重值叫作**类型**；若某个资源允许两种类型共同出现，就在类型图中连一条边，并从较重类型 `a` 指向较轻类型 `b`。

一个资源上若有重权 `a` 和轻权 `b`，可以把同一资源的用户按两种顺序写成右端点和。重玩家最后插入时的边际是 `a c(Y)`；轻玩家最后插入时的边际也是 `b c(Y)`，但换一种顺序会出现最多 `d` 倍的上界。

把两种顺序按比例混合，可以为重类型和轻类型分别得到局部尺度。`t_a,t_b>0` 是类型尺度，`r=t_b/t_a` 且在重到轻的方向上取 `r≥1`。例如取一个资源上各有一名重玩家和轻玩家、费用 `c(x)=x²`：重先的右端点和为 `D=17`，轻先的右端点和为 `U=19`；插入重量 `2` 的玩家时，两个边际分别是 `48` 和 `50=2·c(5)`，插入重量 `1` 的玩家时，两个边际分别是 `16=1·c(4)` 和 `18`。这就是“同一资源、两种顺序、两类边际区间”的具体来源。

把两种顺序按比例混合，可以为重类型和轻类型分别得到局部尺度。要用同一个倍率 `β` 包住两类边际，必须满足

`r ≤ β`，

`1+(d−1)/r ≤ β`。

右边两项分别来自重类型的下界 `1/r` 和轻类型的上界 `1+(d−1)/r`；所以要同时满足它们，最小化的是 `max{r,1+(d−1)/r}`。令两项相等得到

`A_d = (1+√(4d−3))/2`,  且 `A_d(A_d−1)=d−1`。

在一棵类型森林里，沿每条边取 `r=A_d`，唯一路径保证尺度不会绕回冲突，从而得到约 `√d` 的存在性保证。

如果类型图有环，沿环相乘后必须回到原尺度。设沿一次闭合走法经过的重到轻边数为 `p`、轻到重边数为 `q`；每一步都把尺度比值相乘，最后必须回到起点，所以需要

`βᑫ(β−1)ᵖ ≥ (d−1)ᵖ`，

`βᵖ(β−1)ᑫ ≥ (d−1)ᑫ`。

环不满足这些条件，只能说明**这套共同尺度证书**无法闭合；它不说明原博弈没有 `β`-PNE。独立的空策略或其他势仍可能给出均衡，这个边界必须保留。

当资源上有很多权重类型时，第三种办法是换一张图：顶点是实际玩家；若较重的玩家和较轻的玩家在某个策略组合中可能共同使用同一资源，就画一条从重到轻的边。设这张玩家图的最长严格降权路径含 `h` 个顶点。这里的 `h` 与前面的类型图不同，不能把类型合并后再偷偷当作玩家路径。定义 `A = A(d,h)` 为方程

`A = Σⱼ₌₀ʰ⁻¹ ((d−1)/A)ʲ`

的唯一正根；它位于 `1≤A<d`。按层混合有序右端点和，可以得到 `A`-PNE。更精确地，若 `1≤α<d` 且游戏没有 `α`-PNE，则必须有

`h > H(d,α) = log(d−α)/log((d−1)/α)`（当 `α=d−1` 时取 `H(d,α)=d−1`）。

固定比例 `α=cd`（`c<1`）时，这个必要深度是 `Θ(log d)`；只有在 `α=d−b` 且 `b` 固定时才会逼近线性。深度是必要条件，不是失稳的充分条件。

## 6. 本质三：前沿上的证明还不是全状态证明

局部传播通常只看一类有序二元状态。对含 `n` 位的同权类，定义前沿

`Fₙ` 是所有“前缀全为 `0`、后缀全为 `1`”的位串，加上它们的 `0↔1` 反向串；例如 `F₃={000,001,011,111,110,100}`。它就是从全零到全一、再从全一退回全零的所有至多一次变化位串。多类时使用乘积前沿 `F=∏ₐFₙₐ`。以三位串为例，至多一次变化的前沿是

`000, 001, 011, 111, 110, 100`，

而 `010`、`101` 是非法的交替串。即使已经证明前沿上的每一个状态都有改善偏离，非法串仍可能是稳定点，所以还不能得到全状态反例。

解决办法是加入真实的拥塞资源作为“锚定门”。在一类中取锚点 `0` 和两个位置 `j<k`，每人只有动作 `0,1`；加入两条新资源 `g⁰,g¹`，玩家 `r∈{0,j,k}` 在动作 `b_r` 下使用 `g⁰` 当且仅当 `b_r xor (0,1,0)_r=0`，否则使用 `g¹`。于是动作 `010` 的三人都在 `g⁰`，动作 `101` 的三人都在 `g¹`；前沿动作只形成“一人+二人”的分裂。两条资源使用同一个延迟 `c(x)`，并记

`z=c(w)`, `u=c(2w)`, `v=c(3w)`。

三位动作与门负载的关系可以直接列成表：

| 动作 `(b₀,bⱼ,bₖ)` | `g⁰` 上的人 | `g¹` 上的人 | 每个门用户的费用 |
| --- | --- | --- | --- |
| `010` | `0,j,k` | 空 | `v` |
| `101` | 空 | `0,j,k` | `v` |
| 其他前沿动作 | 两人 | 一人 | 二人支付 `u`，单人支付 `z` |

令 `B` 是基体游戏中该类任一玩家在任一状态的成本上界，`L` 是一个玩家参与的门数上界（可取 `L=(n−1)(n−2)/2`）。若

`v > α(B + Lu)`，

则对每个权重类、每个门和每个可能状态，离开前沿都会触发大费用。若 `s∈F` 而 `t∉F`，直接用 `Cᵢ⁺(s)≤B+Lu` 与 `Cᵢ⁺(t)≥v`，得到 `Cᵢ⁺(s)−αCᵢ⁺(t)≤B+Lu−αv<0`；这条不等式负责阻止从前沿跳出去。

前沿内部的核心偏离另有容差，而且只在 `s,t∈F`、每个相关门的两端都保持“一人+二人”非触发模式时成立：若玩家参与了 `r_i` 个门，则

`Cᵢ⁺(s)−αCᵢ⁺(t)=Cᵢᴮ(s)−αCᵢᴮ(t)−(α−1)r_i u`。

因此前沿出口必须满足 `Cᵢᴮ(s)−αCᵢᴮ(t)>(α−1)r_i u`，而不是只在基体里有一点正余量。

门必须被写成真正的资源、真正的非负多项式费用和不改变的玩家动作，不能直接把任意状态成本表叫作拥塞实现。并且近似稳定在前沿内部会留下一个加性容差：门在两个前沿端点上都有共同的二人组成本 `u`，所以基体偏离必须超过这项容差才算真正被排除。

## 7. 四个接口怎样合成一个全状态反例

反例的四个接口各自承担不同义务：

| 接口 | 反映的本质 | 交付的义务 | 删除它会怎样 |
| --- | --- | --- | --- |
| 同权二元时钟 | 一个权重类的状态顺序 | 把状态排成有前沿的位串 | 失去可追踪的相位 |
| 相邻权层短窗 | 端点和面积的差异 | 把一次改善从一层传到下一层 | 传播余量断掉 |
| 回返窗口（return） | 局部余量的闭合 | 处理相邻测试没有覆盖的相位 | 环上留下未处理状态 |
| 锚定门 | 非法状态的强制纠正 | 把前沿证明扩展到全体纯状态 | 可能留下前沿外的均衡 |

为了让这段相位记账有完整参数域，先固定一个 `c<1` 的近似比例，取固定 `n>1/(1−c)`，并令 `δ=1/n`、`α=(1−δ)d`、`θ=δ/8`、`κ=1+θ`、`K=d⁴`、`R=8nd⁴`、`b=1−δ/2`。取

`g=min{r∈ℕ:r≥2 且 bʳ≤(192d²)⁻¹}`。

于是 `R` 被 `d` 整除；令 `N=Rᵍ/d`、`ε=R⁻ᵍ`，就有 `N∈ℕ` 且 `Nε=1/d`。这里 `g` 是相邻权类边数，因而有 `g+1` 个权类，每类有 `N` 个同权 clone。沿用短窗中的 `X,Y`，再定义 `T=(1+θ)ᵈ`、`H=T−α`、`S=κ(αX−Y)/H`，供相邻资源振幅使用。

在参数化家族中，前沿用相位 `xₐ∈ℤ/(2N)ℤ` 编码，前进 `xₐ→xₐ+1` 或后退 `xₐ→xₐ−1` 都只翻一个真实玩家。对原始相对相位 `rₐ=xₐ₊₁−xₐ (mod 2N)`，若 `rₐ` 不在两个短区间 `[0,K]` 与 `[N,N+K]` 内，就按对应方向选择重类端点，端点—面积估计给出至少 `η` 的严格改善；只有在 `rₐ∈[0,K]∪[N,N+K]` 时，才写成

`rₐ=kₐN+tₐ`, 其中 `kₐ∈{0,1}` 且 `0≤tₐ≤K`。

若全部相邻差都短，令 `k` 为 `Σₐkₐ` 的奇偶，`t=Σₐtₐ`；参数条件保证 `0≤t≤gK<N`。末类的回返资源使用

`W=(1+1/d)ᵈ`, `U=Σ_{r=1}ᴺ(1+rε)ᵈ`, `V=Σ_{r=1}ᴺ(rε)ᵈ`, `Z=U−αV`。

奇偶 `k=0` 时选回返前进，`k=1` 时选回返后退；真实旧、新成本向量分别至多偏离 `(U,V)` 或 `(V,U)` 共 `t+1` 个坐标，每个坐标误差至多 `W`。因此回返模块的余量至少为

`Z−(α+1)(t+1)W>0`。

完整的末类出口还要扣除 进入末类的相邻测试的成本。令相邻资源振幅为 `Aₐ=Sᵃ`，回返振幅为 `A_R=H/(4αW)`，并把 `X` 取为 进入末类的相邻测试的统一新成本上界；参数选择满足

`(3/4)A_RZ−αA_{g−1}X≥η`。

于是回返与进入末类的相邻测试合在一起仍留下统一的前沿余量 `η`。这条链把“相邻测试 + 回返”变成了可重算的全称覆盖：每个前沿相位要么有一个短区间外的重端点出口，要么由累计奇偶确定一个回返出口，而不是只找到一个改善环。

再用锚定门排除 `F` 外的状态。这样才得到“对每个纯状态都有严格偏离”的全状态结论。

近次数族的结论是：对每个 `d≥2²⁰`，取 `ℓ=⌈log₂d⌉` 和 `n(d)=⌈d/(1200ℓ²)⌉`，每个资源延迟都是 `aₑxᵈ`，其中 `aₑ>0` 为有理数；于是可以构造一个合法有限博弈，使每个状态都有严格的 `(d−1200ℓ²)`-改善。为了让锚定门仍保持次数 `d`，还要选门系数使泄漏满足

`(2/3)ᵈ ≤ η/(4α²B⋆L_c)`。

这里 `B⋆=maxₐBₐ`，`L_c=maxₐLₐ`，并令 `M=2αB⋆` 为锚定门的触发幅度；`η` 是上面相邻—回返覆盖对所有前沿状态给出的统一基体改善余量。选择门次数 `d` 使

`αL_cM(2/3)ᵈ≤η/2`，等价于足够强的 `((2/3)ᵈ≤η/(4α²B⋆L_c))`，就能保证门的非触发泄漏最多吃掉一半余量；于是完整出口仍至少留下 `η/2`，且新增门没有偷偷提高次数。这个结论的量词是“每个状态都有一个真实单人偏离”；它不是“发现一个改善环”，也不是“有限枚举没找到均衡”。

还要分清两个参数制度：若先固定 `c∈(0,1)`，可以先选一个固定的 `n>1/(1−c)`，再取充分大的 `d`，得到没有 `cd`-PNE 的族；这不能把 `c` 改成随 `d` 趋近 `1` 的函数后仍沿用同一个固定 `n`。

## 8. 同一组工具何时改善存在性

反例和正向结果使用同一分析，但假设方向相反。

**小原子份额。** 只在玩家 `i` 实际占用资源 `e` 的状态检查 `wᵢ/xₑ(s)≤η≤1`；此时 `xₑ(s)≥wᵢ>0`，所以没有零分母。积分势给出

`K(d,η) = [1 − (1−η)ᵈ⁺¹]/[(d+1)η]`,  并约定 `K(d,0)=1`。

于是存在 `1/K(d,η)`-PNE；当 `dη→0` 时，`(1−η)ᵈ⁺¹→1`，所以 `K(d,η)→1`，倍率趋近 `1`。条件必须在所有相关状态检查；只检查一个状态不够。

**类型森林或有限深度。** 第 5 节的类型图为森林时，共同尺度给出约 `√d` 的保证；玩家降权图的有限递减深度给出 `A(d,h)` 的保证。它们是有结构的子类结论，不是把全类的线性下界推翻。

**社会成本。** 个体稳定只需要势的局部最小；要同时比较社会成本，必须再加入 `W` 的边际界、前沿上的共同门成本恒移，以及把基体最优转移到完整游戏的外部性条件。若基体费用次数至多为 `p`，且同一类的门参数为 `z_a=c_a(w_a)`, `u_a=c_a(2w_a)`, `v_a=c_a(3w_a)`，典型外部性预算写成

`3vₐ−2uₐ−zₐ>(p+1)Bₐ`。

它表示触发门被消除的社会收益必须超过基体费用增加。前沿上的最优值未经这一步不能代替全游戏的 `OPT`。

## 9. 边界和读者应带走的四句话

1. 端点—面积差异说明高次费用的放大从哪里来，但它只是局部传播接口。
2. 共同玩家尺度说明多个局部比较何时能拼成一个全局势；尺度证书失败不等于博弈没有均衡。
3. 锚定门说明前沿上的结构化证明怎样扩成全状态证明；门的余量必须写进近似稳定不等式。
4. 四个接口合在一起才给出近线性全状态反例；同一工具在小份额、森林或有限深度条件下又给出较好的存在性保证。

文献中的 `d`-近似存在性上界和较早的 `√d/log d` 下界是外部结果；这里的端点、共同尺度、门实现、全状态反例和正向条件按各自的假设使用。有限算例可以帮助检查转录，但不能替代对所有参数和所有状态的证明。
