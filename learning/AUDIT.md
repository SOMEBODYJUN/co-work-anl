## 独立审读如何进行

三名审读者先分组读取实际讲义，不接收主编的问题清单或此前审读结论，从正文重构证明并寻找反例。范围分别为前置与证明技术、双设施及多设施主线与结构下界、复杂度及后半部推广。修订后，再阅读实际改稿，核验问题是否消除、正确证明是否受损。原始意见、判断和复读范围保存在[审读记录](reviews/20261010.json)。

| 范围 | 本轮修订及复查重点 |
| --- | --- |
| 00、01、01A、01B | 补齐收敛子列与最值证明；区分受保护修复和一般最大重量修复；将双锚每笔重量落实到客户集合及完整假设；展开三名同时混合的算例；统一局部符号和默认种子。 |
| 02、03、A02 | 补全两设施一般纯修复的步数证明；给出外部纳什化定理的准确版本；让所有未用同址布局也兑现独立对半规则。原有上界长证明及各终局保留。 |
| 04、A14、A15 | 增加四地点全局无 FPTAS 与固定重支持的近带精确补全。分别检查全部带标签布局、任意实概率支持、四个补全分支、边界与总位复杂度。全局 EPTAS 保持候选。 |

两轮审读提出的具体问题已修回实际正文，复读在覆盖范围内未留下结论错误或证明缺口。这一结论描述此次审读结果，不是对所有未来读者理解程度或所有外部论文的认证。

## 精确计算与导出核验

算例使用 Python 有理分数从条件成本独立复算。复核包括纯修复与保和交换、三态支持谱、下界全布局、近带边界、盒改善与归位，以及倍率完整证书。有限核算只检验列出的输入；全称定理依据正文证明。

导出器记录每份 Markdown 的 SHA-256、字节数和公式数量。结构检查逐份核对源摘要与 TeX 公式、多重公式计数、全部内链目标、唯一锚点、资源内嵌、渲染错误与标题跳转。对应数据在导出的 `.audit.json` 中。

本轮从最终 HTML 抽取分析前置、双锚与强弦技术、两种纯修复、新盒构造以及 A14、A15，另经 WeasyPrint 渲染复核可见排版。该检查针对实际公式与代表页面，不声称完成浏览器交互或全书 PDF 逐页审阅。此前 `PAGE_REVIEW.json` 对应 2026-10-07 的旧 PDF，保留为历史记录，不充当本轮更新文件的分页认证。本轮视觉记录与源版本关联保存；视觉检查不替代数学审读。

## 定稿的数学范围

共同目录双设施的尖锐黄金比例界与任意设施数的因子 2 存在性保持原范围。一般异构因子 2 保持内部候选。完整贪心盒 NE 现在具有一般有限构造，仍未得到一般输入的位多项式总时间；等权可移动客户的流算法有自己的输入条件。四地点无 FPTAS 不排除 PTAS 或 EPTAS。近带工具不等于完整全局 EPTAS。

读者可从导读连续进入前置、模型、技术分析与两条主证明，再按各章指引阅读长附录。掌握的检验仍是能重述对象和量词、逐步重构证明、逐人检查精确 NE，并说明每个推广的假设与开放义务。
