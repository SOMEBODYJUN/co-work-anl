# 第三篇教学页重写审查记录（2026-10-31）

## 失败稿判定

上一版不作为教学成果保留。失败不是少几个定义，而是结构和审查对象错了：

- 学生正文混入研究地图、仓库检索、来源哈希、审计状态和投稿工程信息；
- 没有先固定问题、模型、`α`-PNE 定义和正向/反向量词；
- 把局部传播阈值、共同尺度证书、前沿改善环和有限计算检查并列成“结果”，没有说明各自回答哪个障碍；
- 没有证明前沿外状态被真实拥塞资源排除；
- 历史导出页使用裸 MathML，长公式没有稳定的外层滚动盒，公式计数被误当作可读性检查；
- 页面没有把前两篇的两阶段设施模型与第三篇的单层拥塞模型的关系说清楚。

因此本轮没有在旧 HTML 上修补，而是重新写了一条教学主线。

## 独立审查范围

三路审查在重写前分别读取真实仓库文件和历史失败页，互不以主代理的结论作为依据：

1. **教学结构审查**：要求从“问题→定义→手算例→障碍→本质→组合→用途→边界”重排，列出学生页不得出现的工程内容。
2. **数学重构审查**：逐项检查端点—面积、共同尺度与环冲突、前沿与锚定门、相邻测试与 return 覆盖、同次数门预算、固定 `c` 的量词和社会外部性条件。
3. **公式审查**：攻击历史页的裸 MathML 和长公式溢出机制，要求每个公式独立可见、符号先定义、长式可横向查看，且不依赖网络脚本或字体。

## 本轮交付的阅读路线

`learning/13_weighted_congestion.md` 与对应 HTML 只保留学生所需数学内容：

1. 研究问题与 `a*(d)`；
2. 玩家、资源、策略、负载、费用、成本、`α`-PNE、社会成本；
3. 一个两玩家手算偏离；
4. 共同玩家尺度的势接口；
5. 端点—面积局部传播；
6. 类型森林、环乘积约束和权重深度；
7. 前沿、锚定门和近似容差；
8. 相邻短窗、return 和门如何共同给出全状态反例；
9. 小份额、有限深度和社会成本的正向用途；
10. 量词与适用边界。

公式全部改为页面内可见的独立公式框，避免把编译责任交给浏览器的 MathML 实现；页面无外部脚本、字体、图片或链接。

## 仍然不声称的事项

这份教学页不是第三篇论文全文，也不把教学重排升级为新的数学命题、外部评审或新颖性认证。局部公式和有限算例用于解释机制；一般结论仍以研究目录中的自足证明为准。

## 第二轮修复

第二轮独立审查指出共同尺度、前沿门、相邻—回返量词和社会预算仍有定义跳步。本轮已补入两权重两排序的手算例、类型图与玩家降权图的区别、前沿 `F_n` 与乘积前沿、三人两资源锚定门表、前沿门的加性容差、相邻相位的三层示意、同次数泄漏预算、固定 `c` 与 `n(d)` 的量词分离，以及 `p,z_a,u_a,v_a,B_a,L_c` 的定义。公式输出改为离线 KaTeX 0.16.11 的静态 HTML+MathML 双树，28 个块公式逐式渲染，字体以 data URL 内嵌；没有外部脚本或资源，构建检查中 `katex-error=0`、annotation 与块公式一一对应。

## 最终定向修正

随后两轮定向攻击发现并修正了两个量词错误：删除边际使用偏离前的 `Y⁻=x_e(s)`，加入边际使用偏离后的 `Y⁺=x_e(t)`；锚定门的加性容差等式限定为前沿到前沿且两端均为非触发二人组，前沿跳出单独使用 `B+Lu−αv<0`。前沿覆盖段又补入参数化家族的实际相位记账：`x_a∈Z/(2N)Z`、`x_{a+1}−x_a=k_aN+t_a`、`t<N`，以及回返量 `Z−(α+1)(t+1)W>0`。

最终公式审查为 PASS：28 个块公式各有 KaTeX 可见树和 MathML annotation，外层公式框支持横向滚动，20 个数学字体文件以内嵌 data URL，`katex-error=0`，无外部脚本、链接、图片或残留 TeX。数学二审的剩余边界是：该页是经过定义审查的教学摘要，不是八份正文的逐引理全文。
