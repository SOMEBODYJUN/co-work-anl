# 阅读入口与全书路线

本书从有限集合和概率开始，研究一个明确的两阶段问题：设施先选地点，原子客户再选择设施；我们能否同时安排设施位置和所有客户续局，使任何设施单独搬迁都得不到过大的收益？这里的客户均衡要求精确，允许放宽的是设施稳定的收益倍率。

首次阅读从[导读](00_guide.md)开始，再顺读下表。不要先通读研究账本。账本用于核对结论的范围与状态；讲义负责把定义、实际推导和证明用途连续讲出来。

| 顺序 | 章节 | 本章解决的问题 |
| --- | --- | --- |
| 00 | [数学语言与博弈基础](00_prerequisites.md) | 什么是独立随机选择、单方改善、存在性和算法时间？ |
| 01 | [两阶段模型](01_model.md) | 客户实际承担什么成本？什么叫布局加完整续局？ |

## 数学状态与学习完成标准

共同目录双设施黄金比例与任意设施数因子 2 存在性依据仓库完整内部证明；一般异构双设施因子 2 保持内部候选状态；任意设施数的一般位多项式构造仍开放。非线性讲义是从本轮上传材料重构的教学论证，其现行仓库登记与程序可用性另外说明。讲义改写不升级证明审查状态。

掌握一节，应能独立完成四件事：把命题的对象、假设和结论连成一句准确的话；重做关键成本或收益计算；指出交换后的状态为何合法；解释结论在哪里被下一节使用。练习附有解答，先独立推导再核对。若只能记住结论或技术名称，就回到具体计算。
