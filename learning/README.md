# 人类团队学习入口

这套材料为准备两周研讨会、随后参与研究的团队编写。起点允许没有博弈论或复杂度理论训练，但需要愿意做代数和证明练习。**先读本目录，不按提交时间通读仓库。** 现行证明仍以 `research/current/` 为准；讲义是学习桥梁，不替代原证明，也不升级审查状态。

截至 2026-10-05，当前最具体的目标是：对任意设施数的共同目录模型，按联合输入的二进制位长，在多项式时间内构造完整因子 2 的近似 SPE。因子 2 的存在性已有完整内部证明；一般高效构造仍开放。最佳统一常数、外部审稿和文献优先权核查是另外的工作。

## 三层阅读，不让细节吞掉主线

**全员必会：**模型、完整续局的量词、两设施客户 NE 式、主要定理的适用域、任意设施数因子 2 的证明骨架、位复杂度，以及第 06 讲的少数障碍。可以随时查表，不能靠模糊记忆变更假设。

**报告组逐式掌握：**φ 的完整分支、ρ 的全长证明、五地点困难性归约、任意设施数主定理的全部预算和离轨情形。各组必须能接受其他组的定义级追问。两周完成的是团队覆盖；每个人随后都可按完整路线补读，不承诺两周内人人独立重做所有长证明。

**按需查阅：**每一种树形/类型压缩/权种 DP 子类、每个历史反例参数、全部实现细节和提交日志。主线需要其中一种工具时再打开。它们保留在原位置，不删除数学资产。

若第 3 天仍算不清条件期望成本，先补预备课；若第 10 天不能讲清源站消失时的预算，延长主定理研讨。过关靠解释和推导，不靠读完文件。
