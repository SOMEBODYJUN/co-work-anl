# 正权 Boolean 向量核的交互秩暴露面：独立重构与闭包审查

本文是 E1 的最终数学审查，不修改规范正文与共享登记。审查者先仅依据 exact statement 独立重构有限锥秩面，未阅读作者候选正文或既有 selector 证明；随后核查作者发来的顶 context 定量公式，并参与闭包强化；最后读取冻结正文逐项攻击。闭包部分据此属于参与构建后的复核，不能将其全部标为独立盲审。有限审查代码与普遍证明分开。审查对象仅为三个 PK ID，下面的全 context 比较是附加推导，不另立主张。

## 1. 精确对象与可证结论

固定整数 n≥1、实权 w_i>0。对非空 S⊆[n]、整数 k≥0，令

K_{S,k,i}(s)=1_{i∈S}s_i (Σ_{j∈S}w_js_j)^k，s∈{0,1}^n。

仅在 s_i=1 时计算幂，k=0 时其值规定为 1，故无 0^0 歧义。每个核均非零。K_fin 是这些完整向量核的有限非负线性组合；表示中系数为零的项不计入支撑。

在向量空间 V={C:C_i(s)=0 whenever s_i=0} 中，取 active 表 f_i(A)=C_i(1_i,1_A)，A⊆N\{i}。以下 r 为非负整数；如果 r 是实数，应统一换为 floor(r)。交互秩≤r 指每个 f_i 的唯一 multilinear 多项式次数≤r。记

G_r=cone{K_{S,k}:min(k,|S|−1)≤r}。

最强可证结果为：

1. K_fin 中交互秩≤r 的元素恰为 G_r；其每个有限非负表示中所有正系数项均满足 min(k,|S|−1)≤r。
2. G_r 是 K_fin 的暴露面。全 context 之和和只取顶 context 的线性泛函均可暴露此面。
3. 在固定 n,w 下，两种泛函对禁止核的适当归一化都有严格统一正 gap；因此闭包中的低秩截面恰为 closure(G_r)。
4. 闭包可精确写出：加入有限个 unanimity 向量 U_S，即得到 closure(K_fin)。低秩闭包只需加入 |S|≤r+1 的 U_S。
5. 原锥在 n≥2 时非闭。低秩子锥在 r=0 时闭，在 n≥2、r≥1 时非闭。

这里“暴露面”允许退化情形等于整个锥，暴露泛函为零；若约定暴露面必须真包含，则应对 r≥n−1 单独称为整个锥。

## 2. 单核的差分、秩与无消去

对 i∉T、R⊆N\(T∪{i}) 定义

Δ_T f_i(R)=Σ_{A⊆T}(−1)^{|T|−|A|} f_i(R∪A)。

对 K_{S,k}，若 i∉S 或 T⊄S\{i}，该差分为零。否则写 t=|T|≥1、a=w_i+Σ_{j∈R∩S}w_j>0，差分为

Σ_{A⊆T}(−1)^{t−|A|}(a+Σ_{j∈A}w_j)^k。

由展开式，或者 t 次连续积分恒等式，此值非负，且严格为正当且仅当 k≥t。积分形式为

∫_[0,w_{j_1}]⋯∫_[0,w_{j_t}] (d^t/dx^t)x^k |_(x=a+u_1+⋯+u_t) du_1⋯du_t。

当 k<t 导数恒零；当 k≥t 时所有权区间长度正且被积函数严格正。因此每个核恰有交互秩 min(k,|S|−1)。相同结论也可由在 R=∅ 的 Möbius 系数直接得到：所有非零系数为正，每个可用阶数都出现。

取 q=r+1≤n−1。定义全 context 泛函

L_all,q(C)=Σ_i Σ_{T⊆N\{i},|T|=q} Σ_{R⊆N\(T∪{i})} Δ_T f_i(R)，

以及顶 context 泛函

L_top,q(C)=Σ_i Σ_{T⊆N\{i},|T|=q} Δ_T f_i(N\(T∪{i}))。

两者对所有核非负；对单核严格为正当且仅当 |S|≥q+1 且 k≥q。故对任意非负有限表示 C=Σa_{S,k}K_{S,k}，L(C)=0 当且仅当每个正系数项均为允许核。这一结论对每个表示分别成立，因而自动给出“每个表示”的量词。

次数≤r 总能推出 L(C)=0，不要求 C 在锥中；反方向需要 C 在锥中。于是 K_fin∩{rank≤r}=K_fin∩ker L=G_r。线性泛函非负且其零集是子锥，给出暴露面。

## 3. 顶 context 的 sharp gap

采用作者发来的归一化

b(K_{S,k})=Σ_i K_{S,k,i}(1)=m W^k，m=|S|，W=Σ_{j∈S}w_j。

这里 b 是全激活状态上响应之和；若另取所有状态的总和，两者不能混用 sharp 常数。

固定 i∈S、T⊆S\{i}、|T|=q。在顶 context，将差分除以 W^k，所得恰是 k 次独立抽样中每个 T 颜色至少出现一次的概率，其中颜色 j 的概率为 w_j/W，剩余颜色合并为一个类别。这可由 inclusion-exclusion 逐项核验。

此事件对增加抽样次数单调。k=q 时概率恰为 q!∏_{j∈T}w_j/W^q。对 i,T 求和，每个 q-set T 被计数 m−q 次，故所有禁止核满足

L_top,q(K)/b(K) ≥ γ_S := q!(m−q)e_q(w_S)/(mW^q)，

且对该 S，在 k=q 时取等。定义

γ=min_{S⊆N,|S|≥q+1} γ_S >0。

集合有限且权严格正，γ 严格正；某个最小集合的 k=q 核达到 γ。因此此 γ 是针对 b 归一化的全体禁止单核的 sharp gap。它也适用于禁止核的任意非负组合。

若任意表示 C=ΣaK 中删去禁止项，所得 C_low∈G_r 满足逐坐标

0≤C−C_low≤Σ_bad a b(K)≤L_top,q(C)/γ。

第一处上界表示每个坐标均不超过该标量；原因单核每个坐标介于 0 和 W^k≤b(K) 之间。这个投影依赖表示，不声称唯一或线性。

作为附加比较，可取所有状态的总和

N(K)=Σ_iΣ_{s∈{0,1}^n}K_i(s)≤2^{n−1}b(K)。

又因为全 context 包含顶 context，L_all,q(K)≥L_top,q(K)。故禁止核满足

L_all,q(K)/N(K)≥γ/2^{n−1}>0。

此比较也给出该额外归一化的统一 gap；不声称右侧是所有状态总和归一化下的 sharp 常数。

## 4. 精确闭包与极限核

令 U_{S,i}(s)=1_{i∈S}∏_{j∈S}s_j。固定 S，因权严格正，每个真子集 A⊊S 都有 W_A<W_S，所以

K_{S,k}/W_S^k → U_S，k→∞。

在 b=1 截面，归一化核 K_{S,k}/b(K_{S,k}) 的全部聚点仅为 U_S/|S|。S 的选择有限，因此归一化生成集的闭包 A 是紧集，而且 b≡1。

有限维空间中 conv(A) 紧。cone(A) 也闭：若 t_j x_j 收敛，x_j∈conv(A)，则 t_j=b(t_jx_j) 收敛且有界，取紧子列即可。由原生成集稠密于 A，得到

closure(K_fin)=cone({K_{S,k}:S≠∅,k≥0} ∪ {U_S:S≠∅})。

这里 cone 仍指有限非负组合；这已经是闭锥。对允许核的归一化集合用同样证明，只有 |S|≤r+1 的 S 能令 k 沿允许核趋向无穷，故

closure(G_r)=cone({允许 K_{S,k}} ∪ {U_S:1≤|S|≤r+1})。

同时，对 |S|=m，直接计数给出

L_top,q(U_S)/b(U_S)=C(m−1,q)，

L_all,q(U_S)/N(U_S)=C(m−1,q)，

其中 q>m−1 时二项式为零。因此新增极限核仍被同一暴露超平面精确区分，得到

closure(K_fin)∩ker L = closure(K_fin)∩{rank≤r} = closure(G_r)。

这一结论也可不显式刻画闭包而由第 3 节的 gap 与删项估计证明：C_j→C、L(C)=0 蕴含删项残差趋零。

因 U_S 的禁止情形下 L_top/b≥1≥γ，同一删项误差估计可直接推广到闭锥：每个 C∈closure(K_fin) 均存在 D∈closure(G_r)，使 0≤C−D≤L_top(C)/γ 逐坐标成立。

## 5. 到任意低秩目标的定量距离

设 H 为任意 rank≤r 的 active 表，未要求 H 在锥中，且 ||C−H||_∞≤ε。L_top(H)=0，故

0≤L_top(C)≤||L_top||_1 ε。

作者给出的系数范数上界实际上是精确值：

||L_top||_1=n C(n−1,q)2^q。

证明：固定 i、A⊆N\{i}，设其缺席集合 B=(N\{i})\A 有大小 b≤q，则 f_i(A) 的系数为

(−1)^b C(n−1−b,q−b)。

同一坐标所有贡献同号，故总绝对系数和为 nΣ_{b=0}^q C(n−1,b)C(n−1−b,q−b)=nC(n−1,q)2^q。

因此上节给出的某个低秩 D 还满足 ||C−D||_∞≤nC(n−1,q)2^q ε/γ。此论断对 C∈K_fin 取 D∈G_r，对 C∈closure(K_fin) 取 D∈closure(G_r)。

## 6. 必须保留的边界和反例

- r≥n−1：所有核允许，相关 q-set 为空，L=0，闭包结论为恒等式；无禁止核，γ 不定义也无需定义。n=1 完全属于此情形。
- 零系数：不得把一个系数为零的禁止核算作违反“每个表示”；正权下没有非零系数的零核，零向量只能由全零系数组成。
- 非闭性：n≥2、|S|≥2 的 U_S 不在 K_fin。任何对某 i 有正输出的有限非负核表示，在该 i 单独激活时也严格正；U_S 在此状态为零。这也证明 r≥1 的 G_r 非闭，取 |S|=2 即可。r=0 时允许核仅给出 nonnegative constant active 表，等于由 n 个 singleton 核生成的正交象限，故闭。
- 只取底 context 的 q 阶差分可判定有限锥的秩，但一般不能处理闭包。当 |S|≥q+2 时，U_S 的每个底 context q 阶差分均为零，而其秩 |S|−1>q−1。因此该泛函没有统一 gap，闭包零面含更高秩元素。该反例要求 n≥q+2。
- 允许负系数会有消去。n=2,w=(1,1),S={1,2} 时 K_{S,2}−3K_{S,1}+3K_{S,0}=K_{S,0}，右侧 rank=0，左侧有高秩项。非负系数是必要假设。
- 权仅非负不够：n=3,w=(1,0,0),S=N,k=2 的 active 表为 (1,x_1,x_1)，rank=1，低于 min(k,|S|−1)=2。全零权还产生 k≥1 的零核。
- 负权使差分非负性失效：n=2,w=(1,−1),S=N,k=1 的 active 表为 (1−x_2,−1+x_1)，rank=1 而 L_top,1=0；k=2 时 L_top,1=−2。
- γ 的正性是对固定权向量。q≥2 时不能跨所有严格正权取统一正下界：q=2,n=3,w=(1,ε,ε) 的唯一禁止 support 给出 γ=2(2ε+ε²)/(3(1+2ε)²)→0。q=1 是例外：γ_S=(m−1)/m，n≥2 时 γ=1/2，与权无关。
