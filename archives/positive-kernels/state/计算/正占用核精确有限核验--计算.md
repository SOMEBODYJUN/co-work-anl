# 正占用核精确有限核验

两个原实现逐份全文读过：作者程序从完整Boolean响应表计算Möbius系数、所有一二阶背景差分、顶背景量与删项；独立程序另写表结构、差分、秩和全背景枚举，没有导入作者实现。本轮按原输入复跑两个实现，所有数学输出与冻结输出逐字段相同。

## 复跑

在仓库根运行：

```sh
python3 archives/positive-kernels/tools/rank-faces/verify_rank_faces.py
python3 archives/positive-kernels/tools/rank-faces/independent_rank_face.py
```

两者仅标准库、确定性、无随机种子，以Fraction精确计算。作者读[实际输入](../../tools/rank-faces/rank_face_inputs.json)；独立实现的完整参数内嵌源码并在输出metadata给出canonical JSON hash。源码仅适配ROOT/输入路径与显示命令，数学循环、公式、断言不变；[provenance](../../evidence/rank-faces/provenance.json)绑定9源版本的18处实际冻结内容hash及适配前后源码hash。

| 核验 | 作者实现 | 原独立实现 |
| --- | ---: | ---: |
| 完整核表/精确秩 | 656 / 656 | 1539 / 1539 |
| Möbius系数或泛函检查 | 29064系数 | 6561泛函 |
| 所有一二阶背景差分 | 88496 | 含于完整泛函扫描 |
| gap比较 | 618 | 1611 |
| k=q达到 | 95 | 216 |
| 相邻k单调 | 未单列 | 1395 |
| unanimity泛函 | 极限诊断 | 729 |
| 精确系数范数 | 16 | 10 |

作者输入8组质量（含小有理权），次数0,1,2,3,4,5,8,13；独立实现在n=1,…,5的三类质量（全1、递增整数、倒数）上遍历全部非空支持及k=0,…,8。作者另测k=2,4,8,16,32,64的归一化极限与底背景失败。两者均精确检查质量(1,2,3)的复用：gamma=11/54、L2=11/50、bad mass=27/25；作者还给实际坐标误差9/25。两程序输出PASS/pass且独立failures=[]。

## 证据与限制

[作者重放](../../evidence/rank-faces/replay/author.json)、[独立重放](../../evidence/rank-faces/replay/independent.json)、[原冻结作者日志](../../evidence/rank-faces/original/rank_faces_author.json)、[原冻结独立日志](../../evidence/rank-faces/original/rank_faces_independent.json)均保留。当前Python版本和当前源码hash以重放日志为准，历史Python 3.12.14只属于原记录。原输入字节不变，原作者源码hashf9eecca…和独立源码hashc2f5bf…与冻结日志一致。原规范正文hash1d1d0327…与审查最终冻结hash相同，已逐字节核对。

有限网格核验不能证明任意正实质量、所有整数次数、拓扑闭包、均衡存在或全球新颖性。这些普遍结论由三篇自足定理证明承担。本轮复跑复用了两个原实现，不能再称第三份独立实现。[审查正文](../审查/正占用核重构与冻结攻击--审查.md)保留独立重构、共同构建闭包后复核与四项冻结修复的区分。
