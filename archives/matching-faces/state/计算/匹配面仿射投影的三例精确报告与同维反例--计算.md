# 匹配面仿射投影的三例精确报告与同维反例

## 实际模型和报告字段

对$n\ge1$，允许边$E\subseteq[n]\times[n]$，左/右端各$n$个点。$P_E$为支持在$E$上的全部$n\times n$置换矩阵的凸包，坐标只列$E$。本报告还要求每条允许边属于某个完美匹配，因而平均全部顶点在允许边上严格正，确实定义所称支持面。

取唯一$p=\arg\min_{x\in\operatorname{aff}P_E}\|x\|_2^2$。这里“centered”为$p\in P_E$，等价$p$非负；是对**仿射包**的投影。不是平均顶点（平均始终非负），不是解带非负约束的QP，也不要求$p$在相对内部：坐标零仍centered。

2943B报告全文给method、三个examples及limits。每例完整字段为n、按字典序edges、全部permutations、face_dimension、projection（同edge顺序的Fraction字符串）、minimum、centered、squared_norm。方法写为Fraction affine projection from all permutation vertices；未写seed、Python版本、代码SHA或外部评审，本批不补称原报告自带这些字段。

## 三例的全部输入与坐标

以下均用报告**零基**索引。置换列表$(p_0,\ldots,p_{n-1})$意为每左点$i$匹配右点$p_i$。

singleton：$n=1,E=((0,0))$，唯一置换$(0)$；维数零，投影$(1)$，minimum一，centered=true，平方范数一。

star4：$n=4$，

$$E=((0,0),(0,1),(0,2),(0,3),(1,0),(1,1),(2,0),(2,2),(3,0),(3,3)).$$

全部置换依次为$(0,1,2,3),(1,0,2,3),(2,1,0,3),(3,1,2,0)$。投影

$$p=(0,1/3,1/3,1/3,1/3,2/3,1/3,2/3,1/3,2/3).$$

face_dimension=3，minimum=0，centered=true，squared_norm=2。

odd_subdivision：$n=5$，

$$E=((0,0),(0,2),(0,3),(0,4),(1,0),(1,1),(2,0),(2,2),(3,0),(3,3),(4,1),(4,4)).$$

全部置换为$(0,1,2,3,4),(2,1,0,3,4),(3,1,2,0,4),(4,0,2,3,1)$。投影

$$p=\tfrac1{28}(-1,9,9,11,11,17,9,19,9,19,11,17).$$

face_dimension=3，minimum=$-1/28$，centered=false，squared_norm=$71/28$。负坐标是允许边$(0,0)$，不是被省略的非边或数值容差。

## 为什么这些向量就是仿射最近点

令$V_0$为第一置换，$D_i=V_i-V_0$为其余三个方向。原程序以Fraction选线性独立方向、解Gram系统
$G\alpha=-D^TV_0$，再取$p=V_0+D\alpha$。若$p\cdot D_i=0$，则对任意方向$d$有$\|p+d\|^2=\|p\|^2+\|d\|^2$，故是唯一仿射最小点；不依赖QP求解器。

star4的Gram矩阵对角四、非对角一，右端$(2,2,2)$，解$\alpha=(1/3,1/3,1/3)$。三个方向独立，故维数三；$p=(V_1+V_2+V_3)/3$确在面内，但在$p_{00}=0$边界，平方范数$4-2=2$。

odd_subdivision的Gram与右端为

$$G=\begin{pmatrix}4&1&1\\1&4&1\\1&1&6\end{pmatrix},\qquad
-D^TV_0=(2,2,3)^T.$$

解$\alpha=(9,9,11)/28$，所以四个仿射系数为$(-1,9,9,11)/28$。Gram非奇异（正定）给维数三，正规方程给上述投影；$\|p\|^2=5-(2\cdot9+2\cdot9+3\cdot11)/28=71/28$。其$(0,0)$分量负，不在非负匹配面内。

这两个明确三维面因此反驳“是否centered只由仿射维数决定”的推广；给完整有限反例，不给所有图的必要充分分类或新颖性。odd_subdivision的**约束**最小范数点必在面中，但本报告没有计算它，不能把负仿射投影当不存在任何合法面点。
