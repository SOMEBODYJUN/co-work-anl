# 隐式配置定价与梯度背景的算法合同

配置笔记112行完整实读，前半的隐式模型、梯度和文献边界不因后半有简单舍入而删除。[整数覆盖等价](../等价/下闭配置指派与最大值覆盖的整数等价--等价.md)与[给定支持算法](../算法/给定稀疏配置的确定性预算舍入--算法.md)回答不同任务；新[等成本纠错](../反例/等启用成本的自然预算LP与整数截断缺口--反例.md)另定位原文缺口。

## 指数地集必须交付的五个接口

$E=\{(l,S):S\in\mathcal I_l\}$可能指数。对显式$E$时间$\operatorname{poly}(|E|)$不等对原紧输入多项式。必须分别交付：局部族的访问模型（membership不等optimization）；非负模权pricing $\max_{S\in\mathcal I_l}\sum_{i\in S}w_i$；分数点及其多项式支持的构造；multilinear值/梯度及误差；预算/局部约束的实际舍入。近似pricing的$\alpha$损失、猜大元素的枚举规模亦不能省。

原2026-10-20笔记报告CGST2011 *Maximizing a Monotone Submodular Function Subject to a Matroid Constraint* Theorem1.3/§4.2已有SAP配置覆盖归约；Theorem4.1用每bin $\alpha$-approximate modular pricing给$1-e^{-\alpha}-o(1)$。这些是历史具体来源定位，本批未外部重新读该论文或核当前最佳界，也不将其statement扩为非均匀opening预算、任意matroid激活或不确定需求的联合模型。

## 梯度是模权和，不代表所有候选共享同一背景

标准独立extension，$M_i(Q)=\max(\{v_{ki}:(k,T)\in Q,i\in T\}\cup\{0\})$。对$e=(l,S)$，

$$\partial_eG(z)=\sum_{i\in S}
\mathbb E[(v_{li}-M_i(R_{z,-e}))_+].$$

公式本身正确，但背景排除了$e$，当$z_e>0$时会依赖候选。不能无条件用同一组item weights作一次pricing就算同bin所有现有正坐标导数。

具体例：单bin配置$e=\{p\},f=\{p,q\}$，$v_p=1,v_q=0$，$z_e=1/5,z_f=4/5$。$G=1-(1-z_e)(1-z_f)$，故$\partial_eG=1/5,\partial_fG=4/5$。两配置的有效正利润item同为$p$，统一模权却不能同时给这两个值。若新配置坐标为零，排除它不改当前背景，可得到针对该类新方向的一致模权；bin-exclusive extension、structured sparse process也可能处理，但须给完整算法、梯度合同和可实现性，不能据一个公式宣布已完成。

原笔记称CGST的structured sparse process已有合法实现；这里保其历史归属而不假装本批逐行重构该外部算法。稀疏支持上直接精确算$G$的舍入，不依赖“一次pricing算全梯度”这个缺省步骤。

## consecutive-ones局部oracle的准确条件

条件引理：一个bin的显式资源-物品矩阵$A$仅有$0/1$，每列一段连续的一，选择变量$z_i\in\{0,1\}$、非负有理利润，容量$u_t\ge0$有理，则局部最大模权选择可精确位多项式求解。因整数选择的每行消耗为整数，可先把$u_t$取floor。

自足理由：对任意选出的行集按顺序交替赋$\pm1$，每个连续列与这些行相交仍为所选行序的连续段，符号和为$-1,0,1$。Ghouila-Houri判据给$A$全幺模；加入上下界单位矩阵保全幺模，所以$\{0\le z\le1,Az\le\lfloor u\rfloor\}$的顶点整数。有理LP求最优顶点即得整数最优。矩阵、容量和利润是显式多项式描述，floor不展开容量数值，故位多项式。全零列可全选（利润非负）；若用区间端点压缩行，必须保持全部容量约束和闭开端点约定。

这只证明该明确条件模型；原P03的完整输入与网络尚未在本批取得核查，不能认证其全场景满足。nonunit demands、重复占用或非interval supports可能失去TU，不继承此oracle。

## 历史去重、LP值与整数值不可混用

原笔记另报告Ganz Rozenman–Kulik–Schwartz–Singh2026 arXiv2605.03071 Theorem1.5：plain SAP在局部$\alpha$ pricing耗时$p(n,\alpha)$时有$(1-\varepsilon)(1-e^{-\alpha})$，时间$\widetilde O((n/\varepsilon+p(n,\alpha))m)$。这是其2026-10-20文献记录，不是本批最新检索；plain SAP不自动包含额外knapsack/matroid/随机需求。

Sarpatwar–Schieber–Shachnai *Constrained Submodular Maximization via Greedy Local Search*，1705.06319v3(2018)，原笔记报告matroid+knapsack的$(1-e^{-2})/2$及引言提及$1-1/e-\varepsilon$通用方法但大枚举指数。其显式支持上的比较对象为整数最优，不经额外gap论证不能声称相对配置LP的$L(x)$达到约$.432$；本次floor反例进一步说明两者不可偷换。

原第一轮提出的“非均匀成本给定支持always feasible常数基线”已由第二轮$(1-1/e)/2$构造具体回答，因此不能继续仅以从$1/8$到某普通常数立新题。但Algorithm1先采样/密度截断/best-copy的$1/8$紧例、相对通用方法的速度/访问模型、局部近似损失究竟为$\alpha(1-1/e)$还是$1-e^{-\alpha}$，均需各自证明。这里没有交付Algorithm1、所有外部论文全文、一般GBAP新比值或新颖性认证。原件、纠错与实际读取界见[证据](../../../../tools/evidence/retired-config-certificates/README.md)。
