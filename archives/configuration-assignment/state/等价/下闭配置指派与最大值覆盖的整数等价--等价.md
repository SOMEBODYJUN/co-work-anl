# 下闭配置指派与最大值覆盖的整数等价

有限物品集$P$、bins $L$。每bin $l$有下闭$\mathcal I_l\subseteq2^P$：$S\in\mathcal I_l,T\subseteq S$则$T\in\mathcal I_l$。利润$v_{li}\ge0$。一个指派取两两不交$S_l\in\mathcal I_l$，利润$\sum_l\sum_{i\in S_l}v_{li}$；可启用的bins受成本$c_l\ge0$、预算$B\ge0$或另给的matroid约束。无价值空bin可不打开。

令配置地集$E=\{(l,S):S\in\mathcal I_l\}$，选$A\subseteq E$时每bin至多一配置，启用成本$\sum_{(l,S)\in A}c_l\le B$。定义

$$g(A)=\sum_{i\in P}\max\bigl(\{v_{li}:(l,S)\in A,\ i\in S\}\cup\{0\}\bigr).$$

**定理。** 配置最大化与原整数指派的最优值精确相等，且$g$归一、非负、单调、子模。

证明：固定$i$，已有最高利润$M_i(A)$随$A$增大而增；加入配置$e=(l,S)$的边际为$\mathbf1_{i\in S}(v_{li}-M_i(A))_+$，只会减小，故每项子模。求和即得$g$性质。指派映到自身各bin配置，物品不冲突，值不变。反向对每个在多个配置中的$i$，只保留到利润最大的一个bin，平局任定；其它bin中删去$i$。下闭性保证仍局部可行，利润恰为$g(A)$，启用数和成本均不增。两向均保持可行和价值，最优相等。若局部族不下闭，删除未必可行，此证明不能移用。

每bin配置为同一个partition块；每块至多一个是partition matroid。共同正成本$c$时，整数预算恰为$|A|\le k=\lfloor B/c\rfloor$，所以是该matroid的截断；$c=0$时预算无影响。若开bin集合本身受matroid $M$，将其每个bin替换为该bin配置的平行副本，独立集条件恰为每bin至多一且对应bin集在$M$中，仍是matroid。

上述都是**整数**等价。一般自然分数预算$\sum_ecx_e\le B$只给$\sum_ex_e\le B/c$，未必给$\sum_ex_e\le\lfloor B/c\rfloor$，不能直接宣称$x$在截断matroid多面体。[本次纠错反例](../反例/等启用成本的自然预算LP与整数截断缺口--反例.md)精确展示差别。

配置数可能为$|L|2^{|P|}$。整数等价并没有给原紧输入的多项式求解器、pricing、稀疏分数点或一般GBAP新比值。[给定稀疏支持](../算法/给定稀疏配置的确定性预算舍入--算法.md)和[隐式oracle合同](../审查/隐式配置定价与梯度背景的算法合同--审查.md)分别处理这些接口。
