# 近似模权定价下的确定性离散连续贪心

使用[近似模权定价恢复的固定点方向](近似模权定价恢复短支持真梯度方向--定理.md)、[给定支持的预算舍入](../算法/给定稀疏配置的确定性预算舍入--算法.md)和[紧输入的精确配置 LP](精确模权定价下的紧输入配置LP与硬预算指派--定理.md)。采用非空下闭局部族、非负有理配置利润、有限物品和 bin，以及返回实际配置的确定性非负模权定价，保证至少已知有理 \(0<\alpha\le1\) 倍。删去成本大于硬预算的 bin。令 `P_cfg` 为每 bin、每 item 和自然预算行的配置多面体。共同正成本的强界和较短步数使用整数截断行。记 \(m\) 为 bin 数、\(n\) 为物品数、\(\mathrm{OPT}\) 为原硬预算整数指派最优值，\(g\) 为最大利润覆盖，\(G\) 为独立采样的多线性延拓。

**结论。** 对有理 \(0<\epsilon<1\)，确定性时间多项式于输入位长和 \(1/\epsilon\) 可构造可行有理点 \(x\in P_{\rm cfg}\)，满足 \(G(x)\ge(1-e^{-\alpha}-\epsilon)\mathrm{OPT}\)，且 \(|\operatorname{supp}(x)|\le T(m+n+1)\)，其中 \(T=\lceil 2/\epsilon\rceil\)。同时可从该点显式取回原预算可行指派，非均匀成本值至少 \(G(x)/2\)，共同正成本整数截断或共同零成本时值至少 \(G(x)\)。这是可实现多线性轨迹和可接任意更强舍入的短支持输入。精确定价是 α=1 的特例，原线性 LP 路线在该特例已有相应整数比值，且没有 \(\epsilon\) 损失。

## 单步可执行性和分母界

空物品集、空 bin 集或零最优值都允许返回零点或执行同一算法。以 \(x_0=0\)，\(\delta=1/T\)，每步用稀疏点近似方向定理求真实可行的基本解
\[
y_t\in P_{\rm cfg},\qquad \nabla G(x_t)\cdot y_t\ge\alpha\max_{y\in P_{\rm cfg}}\nabla G(x_t)\cdot y,
\qquad
x_{t+1}=x_t+\delta y_t.
\]
该解在恢复出的列子系统上是显式短支持基本最优解，补零后仍是原始可行域顶点。因 \(x_t\) 是 \(t\) 个方向和零点的凸组合，\(x_t\in P_{\rm cfg}\)，全路径留在单位立方体，\(\|y_t\|_1\le m\)。每步最多增加 \(d=m+n+1\) 个坐标，允许重复配置并合并。方向是**同一个**有理可行多面体的顶点，其有理数位长不依赖梯度值。具体地，对所有约束行用输入成本与预算的公共分母作统一整数化，任意基本可行解由至多 \(d\) 个这样的列与松弛列决定。克拉默法则对其分子、分母给统一输入多项式位长。将至多 \(Td\) 个短方向坐标按 \(\delta\) 相加，共同分母乘积位长至多这批分母位长和再加 \(\log T\)。因而各 \(x_t\) 输入及其梯度分母也有统一多项式界，不会因调用 \(T\) 次而递归膨胀。每步梯度和返回切面按当前支持精确有理计算，最终多线性值可按利润阈值排序用有限乘积精确求出。

## 误差和目标值

设 \(S^*\) 是原模型最优指派的配置集，\(\mathbf1_{S^*}\in P_{\rm cfg}\)。由最大覆盖的单调性与子模性，\(G\) 的异坐标二阶偏导非正，逐坐标把 \(S^*\) 坐标提至一得到
\[
\nabla G(x_t)\cdot y_t
\ge\alpha\nabla G(x_t)\cdot\mathbf1_{S^*}
\ge\alpha\bigl(G(x_t\vee\mathbf1_{S^*})-G(x_t)\bigr)
\ge\alpha\bigl(\mathrm{OPT}-G(x_t)\bigr).
\]
其中第二步逐坐标的实际增量只长 \(1-x_{t,e}\le1\)，且后续导数不增。

保留的 item 行还给一个与配置数、bin 数和物品数均无关的相对曲率界。固定物品 \(i\)。若不同坐标 \(e,f\) 均含它，固定其余采样的最高利润 \(M\)，两坐标的离散二阶差是
\[
-\min\{(v_{ei}-M)_+,(v_{fi}-M)_+\}.
\]
若任一配置不含该物品则差为零。对其余采样取期望，再沿任意可行非负方向 \(y\in P_{\rm cfg}\) 求二阶导，纯二阶项为零，且
\[
0\le-D_y^2G(z)
\le\sum_i\sum_{e\ni i}y_ev_{ei}\sum_{f\ni i}y_f
\le L(y).
\]
中间的两重和可以加回本来为零的对角，因为上界项非负。最后一步用每物品边际至多一。这里 \(L(y)\) 是方向的线性配置利润，已有给定支持舍入证明 \((1-1/e)L(y)/2\le\mathrm{OPT}\)，因而 \(L(y)\le4\mathrm{OPT}\)。仅用其存在性界即可，无需在循环中舍入方向或知道 \(\mathrm{OPT}\)。共同正成本截断或共同零成本时还可用 \(L(y)\le2\mathrm{OPT}\)。

由积分余项，
\[
G(x_t+\delta y_t)\ge G(x_t)+\delta\nabla G(x_t)\cdot y_t
-2\delta^2\mathrm{OPT}.
\]
递推 \(T\) 次。误差几何权至多一，故累计损失至多 \(2T\delta^2\mathrm{OPT}\)。得到
\[
G(x_T)\ge
\bigl(1-(1-\alpha/T)^T-2/T\bigr)\mathrm{OPT}
\ge(1-e^{-\alpha}-\epsilon)\mathrm{OPT}.
\]
该误差界对全部有理利润相对原整数最优值，不依赖利润尺度、配置数或物品数。选择 \(T=\lceil 1/\epsilon\rceil\) 对共同成本截断或共同零成本也已足够。

## 保值舍入及未支付范围

在已给定支持舍入正文中，item 边际只用于先比较 \(G\) 与线性值 \(L\)。本结论直接保有 \(G(x_T)\)，因此从同 bin 交换开始。同 bin 交换及正成本保持交换各自选 \(G\) 不降的端点。剩至多一个正成本分数配置，比较可负担 singleton 和整数其余集至少得 \(G(x_T)/2\)；共同正成本下整数截断容许将其升至一，共同零成本则全升一。最后用下闭性逐物品去重。舍入本身沿用正文的确切位复杂度。

固定点方向定理所需的近似 oracle 接受任意显式非负有理模权并返回实际配置。在扣除固定 bin 和预算价之后，单次查询的乘法误差障碍仍在。这里靠扣物品价格、统一对偶缩放及真实列重放恢复可行方向。将同一近似方向算法用在线性配置利润上，可得 \(\alpha(1-1/e)\mathrm{OPT}/2\) 的另一预算路线，共同正成本截断或共同零成本可去掉半损失。该线性路线不调用梯度。更强一般成本舍入以及额外 matroid/随机模型各留作独立问题。
