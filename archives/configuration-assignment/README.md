# 下闭局部族的配置利润指派

有限物品和bins，各bin有下闭局部可行集族、非负bin-dependent利润，可有非负启用成本及共同预算。目标最大总利润；这与BMKP的中央max-min目标、UM的makespan目标分别建模。本档只保存本批实际全文读过的一份配置归约/舍入来源和其中具体接口，不声称完成所有SAP、GBAP或被链论文。

- [整数覆盖等价](state/等价/下闭配置指派与最大值覆盖的整数等价--等价.md)：冲突去重、下闭性、等成本与matroid激活的精确合同。
- [给定支持预算舍入](state/算法/给定稀疏配置的确定性预算舍入--算法.md)：一般成本的(1−1/e)/2基线、位复杂度及修复后的等成本强界。
- [自然预算LP的截断缺口](state/反例/等启用成本的自然预算LP与整数截断缺口--反例.md)：原等cost给定x说法漏floor条件，明确原比较L不能自动保留。
- [隐式定价/梯度合同](state/审查/隐式配置定价与梯度背景的算法合同--审查.md)：指数地集、局部oracle、候选梯度依赖和历史文献定位。

来源为10224B配置笔记的完整实质清洗；一般成本基线可重构，等成本原范围须按本次反例纠正，完整隐式算法/新颖性未认证。[证据与逐源记录](../../tools/evidence/retired-config-certificates/README.md)。根总树由Boss串行接回，关系留阶段三。
