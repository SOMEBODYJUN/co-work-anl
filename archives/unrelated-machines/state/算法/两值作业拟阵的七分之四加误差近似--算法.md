# 两值拟阵双向桥及其实际作业调度保证

## 1. 两值 job-matroid 的具体算法保证

令 `E` 为非空有限机器集，`J` 为有限作业集。每项作业有公共有限非负有理尺寸 `p_j`，正尺寸至多取两个值；每项有归一化、单调、整数值次模秩 `f_j:2^E -> Z_{>=0}`，按值 oracle 给出。合法输出为每项的一个整数 polymatroid 基

`x_j >= 0, x_j(S)<=f_j(S) (S subset E), x_j(E)=f_j(E)`，

机器 `i` 的负载为 `sum_j p_j x_j(i)`，目标是最小化这些负载的最大值。允许原模型中的整数重数；尺寸不依机器改变。零尺寸项可任取原基并单独保存，零秩项的基为零。

**算法保证。** 对每个固定 `epsilon>0`，存在多项式时间算法，对上述任意输入输出原作业的整数基，使峰值至多 `(7/4+epsilon) OPT`。多项式时间沿用原论文的整数 polymatroid 值 oracle 与数值访问合同，常数及次数可以依赖固定 `epsilon`。本保证不另行强化为任意二进制巨大重数输入上的位复杂度定理，不声称精度也是输入时的统一多项式界，不要求显式枚举全部基，也不推广到机器依赖尺寸、machine-matroid 或普通 unrelated 模型。

该保证使用正式身份 `M-57aea6b6d55243269c09c9ba8f026e87`，就是冻结 BLMRS 2023 v1 作者稿的 Corollary 5（印刷页 3），不是单独的参数算术。其证明的联合输入为当前对象 `M-a3feff9f6a574834925528d0f9d9d658` 的**两值** `(4+eta)` 算法及 `M-e7c107d268344ca592782a71e1925647` 的双向归约。

## 2. 双向桥的完整方向审读

本节核对上述桥的模型及承重推导，不把整类算法的等价与 assignment-LP 舍入的逐见证等价混为一谈。固定 `alpha>=2`，写 `beta=2-1/alpha`。

### 2.1 同值项聚合与回译

对同值原项的秩求和 `f_h(S)=sum_{j:p_j=h} f_j(S)`，得到同值项聚合后的 polymatroid。原基相加是聚合基；反过来，每个聚合整数基可以用两整数 polymatroid 的交分解为原项的整数基，逐坐标之和保持。于是每机负载、每人收益均精确保留，至多两种正值可化为两个聚合项。这是 Proposition 9 及 Appendix A 的双向合同，不是把每项改成秩一。

### 2.2 从 Santa 算法得到 job 算法：Lemma 15

先把猜测 makespan `T>0` 归一化为一。对两个正尺寸项 `p_1,p_2`，若某项正秩而 `p_j>1`，该猜测不可能可行。去掉零尺寸和零秩项；只有一个正尺寸时，封顶后是否仍有原总秩可由 oracle 判断，并可直接构造一个基。以下为两个正项的情形。

取 `k_j=floor(1/p_j)`，以坐标上界 `k_j` 封顶原 polymatroid 为 `P'_j`。若原实例有峰值至多一的调度，它的每项基都在 `P'_j` 中，因此封顶后总秩仍等于原总秩。若总秩下降，该猜测可拒绝。令 `bar P_j` 为 `P'_j` 对 `k_j 1_E` 的对偶，资源价值仍为 `p_j`，并设

`C=k_1 p_1+k_2 p_2, t=C-1`。

原可行调度 `x_j` 的补向量 `k_j 1_E-x_j` 是对偶资源基，逐人收益 `C-load_i>=t`。正尺寸且不超过一时 `1/2<k_jp_j<=1`，故 `0<t<=1`。给定 Santa 的 `alpha` 近似输出 `bar y_j`，逐人收益至少 `OPT_SC/alpha>=t/alpha`。再取补向量回到 `P'_j`；因封顶前后总秩相同，它也是原 `P_j` 的基。每机峰值至多

`C-t/alpha = 1+(1-1/alpha)t <= 2-1/alpha`。

对偶是显式 oracle 变换：若原封顶秩为 `f'_j`，对偶秩为 `g_j(S)=k_j|S|+f'_j(E\S)-f'_j(E)`。双取补还原原封顶基；此处 makespan 端没有随意补基。恢复 `T`，再按下述阈值框架搜索，给原作业的 `beta` 近似。

为明确阈值调用次数，取正有理公共分母 `D`，使每个 `D p_j` 为整数。所有原调度负载、特别是 `OPT`，都在网格 `(1/D) Z_{>=0}` 上；任意原基给上界 `B<=sum_j p_j f_j(E)`。给猜测 `T` 时，只有验证到原基输出且峰值 `<=beta T` 才算成功；若 `OPT<=T`，Lemma 15 保证成功，故失败意味着 `T<OPT`。二分保持一个失败下界和一个成功上界，直到相邻网格点。失败下界严格小于网格上的 `OPT`，所以最终成功上界 `<=OPT`，输出峰值 `<=beta OPT`。成功集合本身无需另加单调性。调用次数为 `O(log(1+D sum_j p_j f_j(E)))`；这是此标量搜索的编码界，不扩大源局部搜索及其 oracle 的整体数值合同。全零实例直接处理，不启动正阈值搜索。

### 2.3 从 job 算法得到 Santa 算法：Lemma 16

给 Santa 猜测值 `V>0`，假设 `OPT_SC>=V`，聚合后两值为 `u<=w`。零值项不影响收益。完整归约有三个分支，均保留原项基的回译。

若 `u>=V/alpha`，给每人至少一个正值单位已足够。是否能做到由两个 polymatroid 的单位覆盖/拟阵并判定；原正阈值可行解保证覆盖存在。非负值使独立向量补为原基无损。

若 `w<V/alpha`，原可行解保证每人值至少 `V` 的 assignment-LP 分数基见证存在；按原秩 oracle 的次模分离/有理 LP 合同求出该见证，再用减最大项舍入，整数值至少

`V-w > V(1-1/alpha) >= V/alpha`。

这里恰用 `alpha>=2`。该舍入步骤由当前对象 `M-737cbc9ea3b54c03b847026018cf5b19` 及严格替代槽证明支付；冻结 v1 两相邻索引图的错误分数见证不作为证明。

剩下 `u<V/alpha<=w`。令 `b=ceil(V/u)`，将大项封顶为每坐标一单位、作为值一的 matroid，将小项保留为单位价值 `1/b` 的 polymatroid。原达到 `V` 的解中，每人或者有大项，或者小项重数至少 `b`；把两坐标分别封顶为一和 `b` 后，补到封顶后的基，仍使规范实例每人值至少一。对这两个封顶秩分别用上界 `1_E,b 1_E` 对偶，给一个尺寸 `1,1/b` 的 job 实例。原规范解逐机的补负载至多一，因此其最优峰值至多一。给 `beta` 近似得到负载至多 `beta`；补回后规范收益至少 `2-beta=1/alpha`。将规范独立/基向量补为原资源基：有一单位大项者的原值至少 `w>=V/alpha`；其余者小项重数至少 `b/alpha`，原值至少 `ub/alpha>=V/alpha`。原资源端的非负性使补基安全。若两正值相等，归入单值覆盖/小最大值分支即可。

这给 Lemma 16 的完整解码。Lemma 22 的无穷值/单位值表述和 Appendix D 的有限 `1,1/b` 表述承担相同覆盖子问题；不能把无穷值直接送入有限最大值舍入。结合两方向、聚合/分解和阈值框架，得到完整的两值 `alpha <-> 2-1/alpha` 整类算法等价。

## 3. 由两值局部搜索迁移到实际 job 保证

给任意固定目标 `epsilon>0`，取源 Santa 算法精度 `eta=min(1,16epsilon)`，于是 `alpha=4+eta>=2`。联合 Theorem 3 的 **Santa 算法到 job 算法方向**，得到对全部两值 restricted job-matroid 输入的多项式算法，其比率为

`2-1/(4+eta) = 7/4+eta/(16+4eta) < 7/4+eta/16 <= 7/4+epsilon`。

若精度限定为有理参数，可取任一固定正有理 `eta<=min(1,16epsilon)`；函数 `2-1/(4+eta)` 单调递增，仍有同一目标保证。这个选择对任意大的 `epsilon` 也始终使用 `eta<=1`，而得到的实际比率始终小于二。全零尺寸实例任取原基即可。所得输出是聚合前每个原作业的合法整数基，非仅聚合负载证书。源端只用两值的 `4+eta`，没有把一般值 `8+eta` 送入两值桥。迁移的联合前提不能拆成“只有源算法”或“只有归约桥”各自足够的两条边。
