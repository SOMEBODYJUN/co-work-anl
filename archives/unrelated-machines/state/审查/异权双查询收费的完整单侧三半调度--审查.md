# 一个共同的实际三半分配

对每个左顶点u任选一个统一λ(u)。每边e=(u,v)选aₑ=λ(u)。完整调度如下：sₑ去Rₑλ；所选左查询实际去Hₑᵤλ，所选右查询**留Rₑλ**；未选state两查询都留自身R。收到左查询的guard去Aᵤλ，其他guards留H。

每左顶点只打开λ：其w去B、全部D枚f分别到原Cᵤᵣ；其余左标签w留A/f留B。每右标签w留A、全部f留B。所有原任务恰执行一次，逐机：

| 原机器 | 实际负载 |
|---|---|
| 所选root | unit s+一件半长右查询=3/2 |
| 未选root | 两件半长查询=1 |
| 接左查询H / 其他H | 1 / β |
| 左Aᵤλ | incident guards之Σaᵤλₑ≤1 |
| 其他左A、全部右A | 只有unit w=1 |
| 每台B | 所选左标签只有w，其余D件f，总均1 |
| 每台左C / 右C | 唯一所选标签的一unit / 0 |

所以Cmax≤3/2，不依赖源满足性、分数证书、未知OPT或β远离1。非单射投影不冲突：所选右查询没有实际去潜在H，未选查询也留各自root；实际左H按edge incidence分隔。同一左顶点所有所选左查询真实输出，**不是**每边左右两个查询都输出。

有边时这份构造峰恰3/2，未声称实际OPT也恰3/2。非空无边可全w留A/f留B得峰1；孤立左点可随意开一标签或不开，完全空图峰0。构造仅扫描展开矩阵及有理预算，多项式总位长；源生成可取D=max(2,max degree)保持多项式展开，巨大二进制D若另给只承诺展开输入多项式，非poly(log D)输出。

# 仍可保的strict接口

真实OPT≤1当且仅当源singleton全满足。YES：给满足λ，每边选λ(u)，两查询都外送；对应guards到一致A，每标签完整incident预算≤1，每顶点只打开一个标签、其全部f到原pool，其他任务留原端，峰≤1。

反向对任意完整实际峰≤1调度，s所在root已有unit，两个半长查询必外送。β>0迫对应guard离H，a>0迫对应w去B，δ>0迫该标签全部f到原C。C≤1使同顶点至多一个标签激活，否则每个编号C都撞两unit。所选根给左标签和投影右标签，同顶点一致，得到满足赋值；未用非规范任务只加非负负载。孤立点任选，空图按前述处理。

E非空时所有实际a的最小值a_min>0，设κ=min(1/2,β,1/D,a_min)。对于任意完整峰C<1+κ调度，root+半长、H+β、A+a、B+δ的严格排斥逐步仍成立，C<2阻止pool两unit，故同样反解。κ可能随输入变小，不能当统一near-two decoder；等号C=1+κ不被此strict论证排除。正权维持strict反解，但不阻止上面的单侧三半逃逸。
