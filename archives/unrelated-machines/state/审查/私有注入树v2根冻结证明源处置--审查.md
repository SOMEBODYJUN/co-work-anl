# 模型与承重条件

模型是有限非空 root 集合；每个 root 有非空状态菜单。每个状态是高度 (h\ge1)、分支数 (d\ge1) 的完全私有树。selector 根处理时间为 1；每个内部节点有一件 incoming unit job 和 (d) 件 outgoing job，父机处理时间为 (1/d)，子机处理时间为 1；叶 outgoing job 只能在指定外部机器上处理时间 1。不同状态、不同 root 的内部机器均私有；叶映射可以先允许重数，但五三存在性部分要求所选状态的叶映射单射。配置 LP 要求每机配置权重和为 1、每个原 job 恰覆盖一次。

这些条件不能删除：共享内部机器、多单位叶端、其它 processing time、预载和一般 unrelated-machines 实例都不在本源结论中。空 root 集合也单独约定，不被非空证明偷换。

# 证明链的逐项核对

## 配置边际的精确局部系统

在 (1\le T<2) 时令
\[
s=\lfloor d(T-1)\rfloor,\qquad a=d-s.
\]
对 incoming unit 边际 (q_v) 和每条 outgoing job 的下端 unit 边际 (t_e)，源稿给出
\[
\sum_e(q_v-t_e)_+\le s q_v,
\]
等价于
\[
\sum_e\min(q_v,t_e)\ge a q_v.
\]
必要性来自 Fréchet 下界：incoming 与对应 small job 同时出现的概率至少为 ((q_v-t_e)_+)，而含 incoming 的配置最多放 (s) 件 small。充分性使用长度 ((q_v-t_e)_+) 的区间在长度 (q_v) 的圆周上串接并模投影，使每点至多覆盖 (s) 段；无 incoming 的剩余区间承载其余边际。端点 (q=0,1) 与 (s=0) 直接退化。外部机在 (T<2) 时只需 singleton/empty 配置。

源稿还给出 (z_e\ge q_v-t_e)、
\(\sum z_e\le s q_v\) 的有理线性表达。它说明配置阈值可由精确 LP 判定，但不等于已经有总位多项式长度的整数调度构造。

## (T=1) 的共同 λ 系统

当 (s=0) 时，每条 outgoing 的 unit 边际至少为父 incoming 边际。沿树向下传，状态根边际 λ 逐层下界所有叶边际，因此每个外部资源 (z) 必须满足
\[
\sum_{u,s}|f_{us}^{-1}(z)|\lambda_{us}\le1,
\qquad \sum_s\lambda_{us}=1.
\]
反向构造在每个状态内部以权 λ 放 incoming singleton、以权 (1-λ) 放全部父端 small，并在外机用 unit singleton/empty 补足。该等价按叶重数计数，单射只在后面的资源阻断中使用。

## 从配置证书抽取共同受容量约束的 a-叉树

对每个 root 先按根边际选择同一个真实状态。若某节点激活质量为 (b\le q)，由局部系统有
\[
\sum_e\min(b,t_e)\ge (b/q)\sum_e\min(q,t_e)\ge ab.
\]
从每个容量 μₑ=min(b,tₑ) 中有理地取出总量 (ab)，令子节点激活质量为取出的 (b_e)。向量 (b_e/b\in[0,1]^d) 且坐标和为 (a)，可分解为恰选 (a) 个 child 的有限分布。递归得到每个 root 的局部满 (a)-叉高 (h) 树分布；每个叶激活概率不超过原配置的 (t_e)，所以外部资源的总期望请求仍受容量 1 约束。

这是每个 root 的局部存在性证书，支持可能指数大，也没有把不同 root 的资源冲突提前假装消失。不同 root 之间的互斥留给下一步的超图匹配。

## 阻断数与 Haxell 条件

满 (a)-叉高 (h) 树中，命中所有满 (r)-叉高 (h) 子树至少需要
\[
B_h=(a-r+1)^h
\]
个叶；归纳在根层至少阻断 (a-r+1) 个 child。单射叶映射把这些叶变成不同外部资源。对每个正权 a-树候选及其每个 r-子树建立超边；超边含一个 root 标签和 (R=r^h) 个资源，大小为 (R+1)。对任意 root 子集 (I)，用同一份 root 局部分布按资源容量加权，得到资源侧 transversal 下界
\[
\tau(H_I)\ge B_h|I|.
\]

源稿引用已核对的 Annamalai/AFS 版本 Haxell 条件：若边大小为 (k)，要求 τ 超过 ((2k-3)(|I|-1))。这里 (k=R+1)，阈值是 (2R-1)；当 (B_h\ge2R-1) 时存在覆盖全部 root 的匹配。源稿没有声称重建 Haxell 1995 原证明，也没有把匹配存在性写成已经实现的多项式算法。(R=1) 退化为 Hall。

取
\[
r=\lfloor(a+2)/3\rfloor=\lceil a/3\rceil,
\]
有 (a-r+1\ge2r-1)，并且 ((2r-1)^h\ge2r^h-1)，故上述条件自动满足。

## 回填完整原 jobs 与五三界

匹配选择每个 root 的一个真实状态及一个 r-子树。激活节点处理 incoming unit 和剩余 (d-r) 件父端 small，负载为
\[
2-r/d.
\]
未激活节点、未选分枝和所有未选状态的原 jobs 全部父置，负载为 1；每个外部机至多接收一个匹配叶 unit。辅助 a-树只是从原 d-树中抽取的见证，不是新增机器或任务。

令 (x=a/d)，源稿的数值链为
\[
2-x/3\le(5/3)(2-x),
\]
而 (T_0=1+s/d=2-x\le T)，故
\[
OPT\le(5/3)T.
\]
当 (T\ge2) 时全父置负载 2 补齐同一上界。该常数是此结构类的存在性上界，不是锐性声明。

## 非单射过滤的 promise 范围

若某实际调度的峰值 (C\le1)，selector 选中的状态会强迫整棵树的 small job 逐层下送，所有叶 unit 必须落在外部机；因此选中状态叶映射必须单射，且不同 root 的选中叶像互不相交。于是过滤非单射状态后解共同 λ LP：无候选或 LP 不可行只保证原实例 (OPT>1)。若 LP 可行，前述五三存在性作用于保留状态；被过滤状态不取 selector，全部原 jobs 父置回填，得到完整原实例 (OPT\le5/3)。

因此判定器只区分 promise YES `OPT≤1` 与 NO `OPT>5/3`，中间带可任答；它不输出 Haxell 匹配，不证明任意非单射原实例的配置间隙有 (5/3) 上界，也不升级为一般 UM 算法。
