# 裸菜单与逐坐标配额的分域审查

两份审查引用同一个11689字节组合文件，SHA256均为50d41b240871e19d82c6cdb82165f13cdfb9087097e7c0162fef3cb45075592a，但认证的数学身份不同：一份只负责§1–5的[裸菜单反向放大](../反例/裸笛卡尔菜单乘积的精确反向放大--反例.md)，另一份只负责§6–7的[逐坐标整数配额](../定理/逐坐标一致菜单的整数资源配额--定理.md)。读过组合文件全文不等于认证全部身份；§8程序也不是逐坐标配额的软件实现。

本对象保全两个原审查记录，并把各自数学义务、先验、实际执行者和未实现接口分别说明。本轮全文读两记录，先比较逐坐标Exact-only重构，后将其与对应Exact及作者Proof三原件分别完整清洗；没有重跑历史审计、生成新有限实验或把数学算法升级为已交付程序。

## 2. 裸菜单审查的实质数学核对

审查并非只确认一个数值表。它核对以下完整主链：

1. 每个状态支持本身为纯Cartesian积，组仍可以按整个g选择\(\ell_i(g)=g_{i+1}\)。跨坐标的是选择函数，不是把原状态支持改成非积集合。
2. 任意补组 \(h=g+\mathbf1\) 的任意两个完整所选状态恰交一枚真实资源，因此任意部分分配的最小整数基数至多D−1。
3. 循环标签并排除a=1后，公共资源给\(\delta_{i+1}=a_i\delta_i\)，由一个零坐标沿环迫全部δ=0。合法bundle达D−1，且组间真实不交。
4. 上界回填全部未选状态的实际任务；下界针对任意完整调度，明确分开C≥2和C<2两支。不能把部分资源领取直接冒作完整调度。
5. t=0不在域，t=1有效；资源跨组度为D增长。若后接保持实际OPT的正规形，只能保持已经下降的值，不能自动修复NO。

本次正文中的两份不同矩阵比较也服从这一范围：裸菜单t=2是32机68任务144边、OPT5/4；完整矩阵Kronecker平方另有mixed任务和机器，不能混为本对象。两种证明各有自己的完整任务义务。

## 4. 逐坐标审查的两个可复用数学接口

### 同一个全局资源平移，不是逐组换资源

本轮追读来源2a16a3d506c1e180f6cf的完整Exact-only重构，确认“全局平移”有明确形式。记\(u_i=f_i(0)\)、\(v_i=f_i(1)\)，对每一枚真实资源同时作
\[
a_i'=a_i+u_i+v_i,\qquad b_i'=b_i+u_i.
\]
这是整个资源宇宙的双射，不依赖g。若g_i=0，原条件b_i=u_i等价于b_i'=0；若g_i=1，原条件b_i+a_i=v_i等价于b_i'+a_i'=0。因此全部组的所选状态同时变为零标签状态。

它保持组身份、所选支持的每条邻边、每项1/D及资源不交性；故任意固定f的完整可行配额集合与canonical f=0相同，不仅最优值恰好相同。对canonical单坐标，两组支持分别为{C,E0}与{C,E1}，其中C=(0,0)、E0=(1,0)、E1=(1,1)，第四项(0,1)未用。这个全局一致双射不能替换成每组分别重命名资源，否则会错误消除真实共享。

### 容量流与槽展开的等价性

三符号并集3^t只给上界。原独立证明还用每资源按共同坐标数h向全部2^h邻组各给2^-h，得到每组分数总量ρ=(3/2)^t，故对每个组集合A都有
\[
|N(A)|\ge\rho|A|\ge k|A|,\qquad k=\lfloor\rho\rfloor.
\]
这涵盖任意A，不仅全体组或子立方体形的A；整数floor来自最终不可拆物品。

已有正文采用每组k个槽的Hall匹配。原独立稿同时给更省的整数网络：源到每组容量k，组到每个邻资源容量1，每资源到汇容量1。槽匹配逐条合并为单位流给出满流Dk；整数满流则把每组的k条单位流边分别配给它的k个槽，恢复槽匹配。每条资源→汇边独立受容量1约束，因此资源最多给一组，直接恢复实际bundles。它与槽展开给同一可行性与精确值。

网络有D组、3^t个使用资源、D²条组—资源边，总边数D²+D+3^t；槽展开则可能到D³条邻边。所有容量和标签位长O(t)，k用整数除法求出，确定性增广路按固定顺序即可，总增广量Dk≤3^t。时间按完整展开输入计为多项式，匹配后用逆平移返回原f资源标签。两种都是数学构造，原审查明确没有软件实现或有限配额实验。

## 5. 事后修复限制需要两条数学前提

逐坐标审查特别指出，统一正常数保值修复的否定不能只用受限配额公式。还必须使用无约束裸菜单的达界值：
\[
V_{\mathrm{free}}=1-2^{-t},\qquad
V_{\mathrm{obl}}=\frac{\lfloor(3/2)^t\rfloor}{2^t}.
\]
原general的Exact-only记录也单独重证了无约束值，未把一个未核的高值前提免费带入。作用于无约束最优分配时，任何同一菜单上的统一保值比例都不能超过
\[
\frac{\lfloor(3/2)^t\rfloor}{2^t-1}\to0.
\]

这只限制保留同一菜单/资源/选择语义的事后修复合同。原普通矩阵没有自动施加全组的局部函数一致性，不能据受限配额把原调度实例宣布为更强NO；更没有已经实现的物理gadget。t=1、任意固定f以及优化f的量词都包含在证明中。显式位多项式不等于用t和2t个函数位作紧凑输入还能poly(t)显式输出指数多个bundle。

**精确陈述的两层量词。** 先定义允许共同选择任意函数族f的优化问题，再声明每个固定f的最优值均相同；两句相容，而且固定任意f（例如全零）就足以构造达到总体最优的分配，无需遍历全部 \(4^t\) 个函数族。领取子集不受Cartesian形状限制，资源可以不领，最终仍为不可分资源。显式bit-polynomial只按完整展开的组、资源、菜单输入计，程序和普通调度物理约束都没有随Exact一起交付。

**作者证明的实际内容。** 作者直接在原坐标标签上辨认两线的唯一交点与各自独占项，以三符号并集给上界、资源均分给全部组子集Hall条件，再证明任意槽子集也满足普通Hall。它没有借用独立稿的全局平移。其 \(D^3\) 槽邻边上界对应原全部菜单的 \(D^3\) 个带状态索引incidence；独立稿的 \(D^2\) 则只计固定f后的所选状态图，两者无计数冲突。

**独立重构的实际增量。** 全局平移给出完整可行配额谱同构；较省容量流可逆回原资源标签；每容量和标签只有O(t)位。均分证据也给连续图配额精确等于 \(\rho\)，但作者与独立稿都另外用整数匹配落实 \(\lfloor\rho\rfloor\)，没有把连续值当作实际bundle。独立稿§6完整证明无约束bare值，而短作者Proof只给受限值。受限证明无需引用bare值；两值对照和统一比例修复限制才同时依赖它们。此分工已接入[配额定理](../定理/逐坐标一致菜单的整数资源配额--定理.md)。

**原始流程措辞与真实先验。** Exact文件开头说reviewer先据“本Exact”重构，是作者对流程的概括；独立记录明确实际输入是消息中的精确陈述，冻结前未读作者Exact文件或Proof。后续作者读后b328149b8fc58c944be1实际核对文件与消息合同相同，不能倒写成最初就读了作者文件。本轮为核对这一差别全文读了该读后及a242b2de9edf2bd78f08的最终范围记录；这两份目前仍只作比较来源，未在本批自动完成清洗。

三原件没有数学更正冲突；应保留的是证明分工、消息先验、连续与整数语义、完整菜单与所选图的计数，以及显式输出规模。这里没有重做历史独立盲审，也没有实现或运行配额匹配程序。
