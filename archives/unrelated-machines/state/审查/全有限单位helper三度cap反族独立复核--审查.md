# 独立补核：同一 cap 反族可完全有限化

本页是 root 在原任务比较中提出的同族推论的独立评估，不是当前 C 的 statement，也不是新增对象、任务或覆盖资产。原任务的两条整结果边和 receipt 不引用本页，不需要刷新 H/C 版本才能交付。所有 clone 操作仍只读；未跑求解器或枚举。

## 精确构造与结论

对每个整数 n≥4，仍令 v=(n−1)/n、a=(2n−1)/n²。取当前 C 的同一个源 I_n、同一个 n−1 条专属副本路径，只将 K_n 的每条新增 helper∞端改为有限值1，得到 L_n。也就是说，每条共享路径有 n 份副本，原玩家 i 仅在自己的副本保值 v；每名 helper 仅在相邻两副本值1。private 值 a、其余端零不变。

则原始值域包含于 {0,a,v,1}，全部原∞度为零；玩家数 N=n²−n+1、物品数 n²、正端数 3n²−4n+2、物品总正度≤3 均与 K_n 相同。这个有限化输入的 raw 整数 OPT 和 raw ConfigOPT 均为 a；其 λ=1 cap M-LP 全正参数集仍恰为 (0,a]∪(v,1]。所以最高 cap/raw 比仍 n²/(2n−1)=Θ(√N)，n=4 仍给13玩家16物品34正端、比16/7，cap(1)可行但 raw CONFIG(1/2)不可行。

## raw 精确值的独立证明

因为 a<1，每位旧玩家取自己的 private、每条链留一份副本并将其余 n−1 份按路径匹配给 n−1 位 helper，即让所有旧玩家达 a、helpers 达1。因此整数和 raw CONFIG 在 a 均可行。

反之给任何有限正 s>a。旧玩家若要达 s，每个合法配置都必须含至少一份其自己的 shared-copy，因为没有这类副本时唯一正值资源就是 private a。每个 helper 的有效配置必须包含它相邻副本至少一件，因为 s>0、其他端全零。对一条链，n−1 个 helper 归一的配置质量因此消耗至少 n−1 的总副本边际，而 n 列总容量为 n，所以供全部旧玩家的正值副本边际至多1。n−1 条链合计最多 n−1；然而 n 个旧玩家的归一有效配置至少需要 n 的这种边际，矛盾。这是纯配置边际论证，不用任何配置的联合实现；对整数分配，分别以 helper 至少占一件及 n 个旧玩家各需 shared-copy 得同一矛盾。因此 raw 两种正阈值集恰为 (0,a]。在 s>1 时 helper 可能需两件，只会增强上界，没有遗漏。

## cap 全参数集的独立证明

首先在 0<M≤1、λ=1 时，每条新增 helper1端被封顶后都是 big M；完全复用 H 的正向公式，保旧 z、按副本重命名旧正 x，并用 z_h=0 和 hole/prefix 两端 x 填副本容量。所以源 I_n 在这些参数可行必推出 L_n 可行。

其次反向对全部 M>0 都成立。若 M≤1，helper big，(6) 迫 z_h=0，(5) 迫相邻两端总 x≥1。若 M>1，则 helper 的两个正端均 small、系数1；没有 big 端，(5) 迫 z_h≥1，(6) 迫左右总 x≥Mz_h≥M>1。因此两种情形每名 helper 至少消耗一单位副本容量，每条链旧 owner 总边际≤1；投影回源物品、保旧 z 恢复源全部约束。这是 finite-H 的全参数反向直接证明。

源 I_n 已逐四区间证明精确正参数集 S_n=(0,a]∪(v,1]，特别 S_n⊆(0,1]。因此对 M∈S_n 用低区间正向得到 L_n 可行；对 M∉S_n 用全 M 反向和源不可行排除新解，含所有 M>1。故 L_n 的集合同样精确为 S_n。这里没有把有限 helper 的 raw s>1 上界套给 M-LP，也没有声称有限 helper 对任意输入都全阈值正向保持；只因本源全部可行 M 已在1以下，有限1足够覆盖本族。

M=1 的显式证书无需更改 C 的新证书：旧玩家每份专属 shared-copy x=1/n、private x=1、z=1；helper 左右 x=(n−k)/n、k/n，z=0。只有 helper1端是 big，旧 a、v 端都 small，所以此点还满足规范化物品 big 度≤2。低目标上有限旧端可能也变 big，不能声称所有目标的 big 度≤2；原∞度零则始终是原值矩阵上的事实。
