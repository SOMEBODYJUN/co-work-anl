# 1. 一般v1 Exact究竟冻结什么

机器数 \(m\ge1\)、任务数 \(n\ge0\)，同一显式ordinary UM矩阵 \(P\) 的有限时间为非负二进制有理数，其余为不可用端 \(\infty\)，每任务至少一有限端。输入有理 \(T\ge0\) 和同一 \(P\) 的两份完整实际分配 \(\sigma_0,\sigma_1\)，各机负载均至多 \(T\)。没有unit/home、唯一小端、度数或查询源分散假设。记
\[
D_{\rm ch}=\{j:\sigma_0(j)\ne\sigma_1(j)\},\quad
\varnothing\ne Q\subseteq D_{\rm ch},\quad
\delta_q=\max_i\sum_{r\in Q\setminus\{q\}:\sigma_0(r)=i}p_{ir}\in[0,T].
\]
v1要求确定性总位多项式构造**同一族**两两不交、与权无关的 \(A_q\subseteq D_{\rm ch}\setminus Q\)。\(\tau_q\) 恰把 \(\{q\}\cup A_q\) 放至各自 \(\sigma_1\) 原端，其余全部留 \(\sigma_0\) 原端，全部原任务恰一次，查询中恰 \(q\) 改owner，并同时有
\[
C_{\max}(\tau_q)\le\max\{3T/2,T+\delta_q\}.
\tag{1}
\]
任意非负有理权只给非query差异任务，\(W=\sum_{D_{\rm ch}\setminus Q}w_j\)。本族 \(\operatorname{fee}(\tau_q)=\sum_{A_q}w_j\)，总费用至多 \(W\)，至少一费至多 \(W/|Q|\)。若每机全部query的旧端总负载至多 \(\eta T\)、\(0\le\eta\le1/2\)，全部singleton峰至多 \(3T/2\)；若**每个**该阈值合法单查询都必付指定费 \(F>0\)，则 \(W\ge|Q|F\)。这不是只限制单件query大小的条件。

非query非unit→unit的指定权可实例化新增unit费；query、既有unit背景费、其它收费及退款须另计。\(T=0\)时两见证所用端均为零，输出应为零负载；非空 \(Q\) 排除空差异集。支持总量至多 \(|D_{\rm ch}\setminus Q|\)，支持加给定 \(q\) 的完整分配生成器是简洁输出，不要求列指数多调度。所有有理计算按总位长，不按精度倒数。

v1明确只含陈述，要求先给审查者Exact，再读作者Proof。其数学身份在v2保持不变；v2新增的是 \(3/2\) 的锐性族。v1通过不自动认证新增锐性，也未承诺用支持并集实现任意query子集。其完整作者/替代证明已在前述对象，冻结Exact的独有角色是审查输入边界和版本身份。

该记录另核作者六机例，区别于它自己先给的五机例。作者机器为 \(H_1,H_2,A_1,A_2,R,S\)，任务有限端恰为
\[
q_i:H_i:a\to A_i:1,\quad x_i:A_i:1\to R:1/2\ (i=1,2),\quad
f:R:1-\gamma\to S:1,
\]
取有理 \(0<a\le\eta\le1/2\)、\(0<\gamma<\min(1/2,3/2-B)\)、\(1\le B<3/2\)。两见证旧端全选的负载为 \((a,a,1,1,1-\gamma,0)\)，新端全选为 \((0,0,1,1,1,1)\)。这些向量同时核了全部机器和查询初态每机聚合至多 \(\eta\)。

指定恰 \(q_i\) 改端，若 \(x_i\) 留旧端则 \(A_i\) 负载2；故 \(x_i\) 必回 \(R\)，若 \(f\) 留则 \(R\ge3/2-\gamma>B\)，所以所有合格singleton均强迫同一 \(f\)。只迁 \(\{q_i,x_i,f\}\) 的峰恰1，排除了不可行空真的必要性。\(f\) 是正非unit→unit，而 \(x_i\) 是unit→nonunit；权 \(w_f=1\)、其余0时 \(W=1\)，两singleton各费1。查询不在费用对象中，已有背景费不得抹去。

对有理 \(B\in[1,3/2)\)，可取 \(\gamma=(3/2-B)/2\)、\(a=\eta\)，参数有理且 \(\gamma\le1/4\)，位长多项式；对固定实 \(B\) 只用区间有理稠密性，不把实数当二进制输入。两strict见证已给 \(\mathrm{OPT}\le1\)，所以不是OPT gap或困难性。general独立五机例中blocker旧/新均 \(1/2\)，不能与作者旧1新 \(1/2\) 混成同一矩阵。源结论为作者证明通过；唯一措辞建议是显式写有理参数及区分实常数/有理输入。

# 4. 最终组合新增核清的全原任务与域内外义务

直接机器图将 \(d\in D\) 画为 \(h(d)\to\sigma_1(d)\)，\(u\in U\) 画为 \(\sigma_0(u)\to\sigma_1(u)\)。目标都为 \(\sigma_1\) 的unit任务，故总入度至多1。删去query弧后，\(r_q=\sigma_1(q)\) 是互异零入度根；前向域 \(R_q\) 两两不交且不能进入有向圈。全图的无根圈/自环仍可存在，不能声称全图无环。定义 \(R(S)=\bigcup_{q\in S}R_q\)、\(A(S)=\bigcup_{q\in S}A_q\)。

| 原任务部分 | 完整输出的唯一安排 |
| --- | --- |
| \(S\) | 用各自 \(\sigma_1\) 原unit端 |
| \(A(S)\) | 用各自 \(\sigma_1\) 原unit端 |
| \(Z\) | 用各自 \(\sigma_1\) 原零端 |
| \(J\setminus(S\cup A(S)\cup Z)\) | 回唯一home；特别 \(Q\setminus S\) 全回home |
| \(u\in U\) | 若 \(\sigma_0(u)\in R(S)\) 用 \(\sigma_1(u)\)，否则用 \(\sigma_0(u)\) |

四块 \(J\) 两两不交且穷尽全部 \(J\)，每枚 \(U\) 也恰二选一，没有新增、删除、复制任务。原Exact对unit端和 \(U\) 的重排写得较概括；最终正文显式限制为这些原端，由该构造原样满足，并非无证加强。

域内非根点有唯一前驱提供所选非query或 \(U\) unit，根由所选query提供，故每机恰接一枚unit；其目标互异且留在 \(R(S)\)。旧 \(U\) 若位于域内必重排。若某 \(U\) 是原端相同的自环，它不可能被外部根触达，否则该点将有两条入边。因此没有保留的旧unit与新unit在域内碰撞。

域外没有任何所选 \(J/U\) 的新unit进入，未动 \(U\) 仍用 \(\sigma_0\) 原端，剩余正home任务只是 \(\sigma_0\) 的子集，\(Z\) 即使移到别机也贡献零。**应将这两类同时和同一 \(\sigma_0\) 比较**，而非把各自至多1错误相加：strict初态下unit和任何严格正home任务本来不能同住。故域外全负载至多1。

域内每机在 \(\sigma_1\) 有unit，所有以此为home的正任务都必须属于 \(D\cup Z\)。\(Z\) 归零、非query \(D\) 被闭包全导出、\(S\) 亦导出，剩余恰为 \(Q\setminus S\)，从而精确有
\[
L_i(\tau_S)=1+\sum_{q\in Q\setminus S:h(q)=i}a_q\le1+\delta(S)
\quad(i\in R(S)).
\tag{2}
\]
samehome多query、query home落在别根域、所选query的home位于未激活域，都由域外减负和(2)统一覆盖。\(S=Q\)余量零，\(S=\varnothing\)没有所选unit、\(U\)用初态、\(J\setminus Z\)回home，二者实际均strict1。

不交支持给本构造族 \(c_q=\sum_{A_q}w_j\)、\(\operatorname{fee}(\tau_S)=\sum_{q\in S}c_q\)、\(\sum_qc_q\le W\)，不是最优费用函数模加。若每home全部query小质量至多 \(\eta\)，且每个 \(1+\eta\) 阈值合法singleton都必费 \(F\)，则每个 \(c_q\ge F\)、\(W\ge|Q|F\)。该费用必要条件仍严格依赖normal form及指定费。

源提出的唯一明确化建议是把“完整分配”展开成开始时刻：每机零时间任务置0，有unit先排unit，余下home任务按固定输入序串行；全部原任务的有理开始时刻是输入部分和，位复杂度多项式。这是可写清的实现输出格式，不是fatal或加强Claim。
