# 输入与模型

冻结源 `examples/unrelated_machines/configuration_finite_cover_seed.json` 的 SHA-256 为
`6f36b009b87e67528a883ea161f0d413346615a630d2914b6ef9b7570b15d782`，两个来源提交内容一致。输入有四台机器 `A,B,a,b` 和七个作业
[
 c, A_0,A_1,A_2, B_0,B_1,B_2.
]
目标配置阈值为 (T=4/3)。处理时间矩阵按机器行给出：

* `A` 对 (c,A_0,A_1,A_2) 的时间分别为 (1,1/3,1/3,1/3)，对三个 `B_i` 不可用；
* `B` 对 (c,B_0,B_1,B_2) 的时间分别为 (1,1/3,1/3,1/3)，对三个 `A_i` 不可用；
* `a` 只对 `A_0,A_1,A_2` 有限，均为 (1)；
* `b` 只对 `B_0,B_1,B_2` 有限，均为 (1)。

因此每个 `A_i`、`B_i` 有两个可用机器，而公共作业 (c) 只有 `A,B` 两个端点。输入本身是一个有限配置证书种子，没有写入“这是全局最优”或一般算法的字段。

# 配置证书的逐项核验

对 `A`，配置分布为
[
\frac12\{A_0,A_1,A_2\}
+\frac16\{c,A_0\}
+\frac16\{c,A_1\}
+\frac16\{c,A_2\};
]
对 `B` 完全对称地替换 (A_i) 为 (B_i)。对 `a`，三个 singleton 配置 ({A_i}) 各权 (1/3)；对 `b`，三个 singleton 配置 ({B_i}) 各权 (1/3)。

本轮重算的精确结果如下：

| 机器 | 配置权重和 | 加权负载 | 单个配置的最大负载 |
|---|---:|---:|---:|
| `A` | (1) | (7/6) | (4/3) |
| `B` | (1) | (7/6) | (4/3) |
| `a` | (1) | (1) | (1) |
| `b` | (1) | (1) | (1) |

七个作业的跨机器配置覆盖都恰为 (1)。特别地，包含 (c) 和一个 (A_i)（或 (B_i)）的配置负载为 (1+1/3=4/3)，达到但不超过阈值；其余配置负载为 (1) 或更低。故这是一个完整的有限 `CONFIG(4/3)` 可行证书。

证书的加权负载 (7/6) 不是整数调度峰值，也不是 LP 目标值的自动下界；它只是该配置分布下的行平均。把“每个配置列不超过 (4/3)”与“某个整数赋值达到 (4/3)”混为一谈会丢失配置松弛与整数调度的区别。

# 全部整数赋值的精确重放

每个 `A_i`、`B_i` 任选两个端点，公共作业 (c) 任选 `A` 或 `B`，所以共有
[
2^7=128
]
个完整整数赋值。本轮使用 `replay_configuration_finite_cover_seed.py`，以 `Fraction` 逐赋值计算四台机器负载，得到：

* 精确整数最优值 (operatorname{OPT}=5/3)；
* 达到该值的赋值数为 24；
* 一个见证是把 (c,A_0,A_1) 放在 `A`、把 (A_2) 放在 `a`、把所有 (B_i) 放在 `B`，其负载为 `(5/3,1,1,0)`（按 `A,B,a,b` 顺序）。

这部分是对**该 seed 的完整枚举**，不是一般配置优化器。现有 `configuration_finite_cover_audit.json` 和 `configuration_finite_cover_independent.json` 使用相同输入哈希，并把它接到 q=6 finite-cover 提升：基调度 128 个、基准峰值 (5/3)、目标配置阈值 (4/3)，独立版本还检查了所有基调度 lift 和 570 个高围长部分置换词。那些 q=6/高围长结果属于相关审查的有限范围；本页只把当前 source JSON 的四机七作业证书与本轮重放登记清楚。

# 结论等级、用途与缺口

**完整有限结论：** 给定上述四机七作业输入，所列配置分布满足每行权重和、每项任务覆盖和及 (T=4/3) 的容量条件；同一输入的 128 个整数赋值中最小峰值为 (5/3)。

**不能推出的结论：** 不能由这个 seed 推出所有配置覆盖实例都有 (4/3) 证书，不能把 (5/3) 写成某个参数族的普遍整数最优值，不能推出 q=6 高围长覆盖的一般存在性，也不能推出任何 NP-hardness、近似下界或通用舍入器。相关审查明确把 finite-cover 源标记为有限可行性/回归证据，没有 generic LP solver。

本对象可用于第三阶段作为一个精确有限节点：配置证书提供“分数/配置可行”一侧，整数全枚举提供“实际离散峰值”一侧，两者的差值 (5/3) 对 (4/3) 反映该 seed 的松弛间隙。若继续推广，必须说明共同配置分布、参数族和全量整数/LP 量词，不能只复制这七个作业的数值。
