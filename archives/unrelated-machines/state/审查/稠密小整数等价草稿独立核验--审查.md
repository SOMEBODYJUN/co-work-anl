# 实读结论

本源是 UM-DENSE-SMALL-INTEGER-EQUIVALENCE-v1 的完整草稿，6706 字节，SHA-256 为 `ba90a721306b3b86dbfdfe6144788db125ff08882b3888184e94e4dcac7df7f2`。它给出一般非负有理/无穷处理时间模型存在固定常数小于 2 的确定性位多项式算法，当且仅当完全有限、严格正、每项属于 `{1,...,n^2}` 的子类存在相应算法；固定 `2-1/k` backend 可回译为一般输入的 `2-1/(2k)` 算法。源文件主动声明“不证明任一侧存在或不存在”，并把有限审计与一般证明分开。

# 逐步核对与独有内容

草稿的回译先处理 n=0、零处理时间边和 n<8k 的有限精确枚举；正 OPT 时取逐任务最小端形成 L、U 网格，并在每个 T 上构造 `q_ij=max(1,ceil(4kn p_ij/T))` 的完全有限正整数实例。原来不可用或超过 T 的端统一变成 n² 哨兵并保留禁止恢复标记。首个 T≥OPT 的候选满足 `T≤(1+1/(4k))OPT`，backend 输出峰值严格小于 n²，故不使用哨兵；逐边回译得到 `2-1/(2k)` 上界。草稿明确指出若只使用粗的 `(4k+1)n` 估计而不保留第一项，会丢掉所需精确比率。

独有的逻辑边界是：任意固定实 ε>0 都包含某个固定倒整数 1/k，不需要 ε 可计算或从算法代码提取；固定 k 允许小 n 分支的 `m^(8k-1)` 次数和算法常数依赖 k，但不提供统一可变 k、FPTAS 或有效寻找最佳 ε。逐实例严格小于 2、配置 LP gap 或有限反例集合都不能替代对全部算法的困难性论证。
