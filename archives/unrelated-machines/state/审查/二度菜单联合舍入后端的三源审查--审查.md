# 二度菜单联合舍入后端的三源审查

## 来源和冻结身份

本批三源研究同一个受限 `UM-DEGREE-TWO-BOUNDED-MENU-JOINT-ROUNDING-v2` 对象。先读独立重构/后端审查（源 ID `8937d43a1e470ace7aa1`，SHA-256 `0cfe217d33058809872de5862c5f40a1fa45a418cc67f1db59e3b675328012f9`），其中实际核读了 Verschae--Wiese 2010 v1 的 §5.1、Lemma 11、Theorem 12 及 PDF 页 10--11；再读实际代码审查（`7a479340d3503830410a`，SHA-256 `4a301c7905d438dc5f24aac46a096b02a6557110c5a9ca3b37bd300c96ea1769`），最后通读 canonical v2 read-after（`dc9f56bcbf195d72a6a3`，SHA-256 `e9f6d03b9eb555827fb842b41d91e46457f4567a601d0267d02492d8e4cf89be`）。canonical 所审冻结主稿 SHA-256 为 `41ceb9e9bdbe2fe81705d2c4f8b64c23983beba2f9767ec97ad36db4eba97e18`；独立重构引用的 Exact SHA-256 为 `7435885c698e741f0dc762cd1fc79be270ad7de164859477645b37affbd9a298`。三源路径在 `legacy-cleanup`（`68fad804ec5946cb296f77dc5b336308a66abf12`）和 `main`（`aefc58eac3fc6eb5d7a47d087dd2c62b5aa9974c`）均相同。

本对象与既有《二度菜单联合取整有限审计--审查》互补：既有对象保存 5 个 weighted-menu fixture、7 个 raw backend case、非法输入和 root 原始矩阵枚举；本对象保存三源对主数学、生产代码和独立后端的语义核对，不把有限运行提升为全量词证明。

## 完整输入域和归一化身份

输入是显式非空 group 集，每组有非空 indexed state menu；每 state 有独有 private machine，列出无重复资源 incidence，私有时间非负且总和 (W_{gs}\le1)。每个资源在全部 states 中最多接触两个不同组（即使相应私有权为零也计入 degree）；每个 incidence 只有本 state private 端和单位 resource 端两个有限资格。selector 只在本组所有 state 机上耗时 1，未选 states 的 jobs 仍是完整实例；空 state、重复 indexed state 身份、零权 jobs 均保留。资源/组/state/incidence 标签必须显式且互不重复，空 group 集不在该 Exact 域。

为每个 (W_{gs}<1) 的 state 加一枚独有 bonus job 与 bonus resource，private 时间 (1-W_{gs})，resource 端时间 1，使每个 state 的 private mass 正好为 1。每个原 schedule 可把**所有** states 的 bonus jobs 各自外送到独有资源而不超过原峰（原峰至少为 1，由 selector 保证）；删除 bonuses 只降负载，所以 normalized 与原实例的实际 OPT 相等。归一化不是把原 jobs 替换成 bonus，也不按分母数值复制对象。

## (OPT=2-V) 与共同取整桥

给每组只选一个 state 的正支持 clause (f_{gs})，令 (V) 是资源不重复约束下各组可获得的最小选中质量的最大值。归一化后所有 private jobs 留 home 给峰值 2；对于 (C<2) 的完整调度，资源外端因单位时间至多接一枚 job，选中 state 必须外送至少 (2-C) 的 private mass，得到跨组不相交 (B_g)，故 (V\ge2-C)。反向给任意不相交 (B_g)，每组选择在 (B_g) 上获得最大质量的真实 state，只外送该 state 分给该组的 jobs，得到峰值 (2-f_g(B_g))。从而

\[
OPT=2-V.
\]

这个反向/正向身份在 (C<2) 的资源独占处使用，(OPT=2) 时由 (V=0) 单独处理；不能把资源独占假设扩到任意峰值。

把每组的 (K_g) 个 state clauses 平均成一个 additive agent 的 value (v_g(B))。由 (f_g(B)/K\le f_g(B)/K_g\le v_g(B)\le f_g(B))，共同资源最多连接两个 agents，故可应用已读的 VW2010 §5.1 degree-two additive 后端。其输出满足所有 groups 的 value 至少 (A/2)，其中 (A\ge V/K) 是 additive optimum；再扫描每组真实菜单选最大 clause，得到 selected mass 至少 (V/(2K))，因而 normalized schedule

\[
C\le2-\frac{V}{2K}=2-\frac{2-OPT}{2K}.
\]

利用 (OPT\ge1) 可写成相对比值 ((2-1/(2K))OPT)，但这不是对任意输入的绝对 makespan (2-1/(2K)) 上界。代码和 canonical 都明确保留这一量词。

## 生产后端的算法义务和代码审查

后端以 exact Fraction 读取私有时间，拒绝 float、bool、decimal/exponent shorthand、负值、重复资源/组/state/incidence、未知资源、row sum>1、空 group/menu、资源跨三组（即使全零）等输入。归一化、group averaging、共同整数分母缩放、threshold oracle、菜单选择、bonus 删除和完整原任务恢复均在 core 内；core 不导入 audit，不调用 brute-force、LP、外部 solver 或递归 DFS。

threshold oracle 的 active item 每一 occurrence 有 1 或 2 个正端。`force-largest` 在“可用值减去该 agent 最大项后小于阈值”时固定该项，并从两个端点的可用列表扣除，重新入队受影响 agents，确保闭包；剩余 occurrence 图由 same-item edges 和 agent 内相邻 pair edges 构成偶环，迭代 BFS 二染色而非递归 DFS，每 item 由唯一颜色获得，返回每 agent 至少阈值一半。二分只把 success 作为得到 (T/2) 解，failure 才给 additive optimum (<T) 证书；整数缩放后 (high=low+1) 时 (low\ge OPT)，未假设 success 谓词单调。A=0 或无正 items 使用合法 fallback。

完整输出逐原 job 恢复：只选一个 state 的 selector，未选 states 全部 jobs 留各自 private；仅被 allocation 选中的原 incidence 外送，其余留 private；每个 job 的实际 processing time、资格、start/finish、正区间不重叠和峰值由 verify 复核。bonus 只在 normalized 内部出现并可安全删除，重复 indexed states 按独立标签保留。

## 有限证据（不替代一般证明）

代码审查独立运行了以下有限检查：

- 4681 个穷尽小 backend 输入、20,522 次整数 threshold 调用，逐一核对 success 给至少 (T/2)、failure 推出 (OPT<T)、最终 (low\ge OPT) 且 (high>OPT)；其中 225 次 (T>OPT) 仍 success，显示未把 success 当精确可行。
- 1800-agent 反向 force-closure、1800-agent/3600-occurrence 长 pair 环，验证重新入队、两端扣除和迭代 BFS 不受递归深度限制。
- 140 个结构实例（不等 menu、私有权、零项、空 state、bonus），独立从 JSON 构造原资格，枚举 26,265 个完整 assignments，核相对/加性界和完整真实输出。
- 2600 个 empty states 的大显式 menu；5,002 位分母回归（成功，峰值 1，16,613 次二分）；零 job/重复 identity 保留；16 类非法输入拒绝。
- 提供 audit 重跑成功，生成的 `audit_results.json` SHA-256=`75ee844b64ecc2ef672d4d03a6c3276377f10bebbabb590a30ad2c6dd0ba4bca`，`fixture_outputs.json` SHA-256=`90491d0227782c056b0992e94054d8dfbfbb66a95810ad945dfd34b6d39560d1`。另有既有三文件有限审计对象保存 root 原始矩阵重放，不在本对象重复计数。

这些数字是有限实现/测试证据，不能推出一般 UM 算法正确、一般 degree-three 支持或全局近似比。

## 适用范围、缺口和处置

已核数学和代码在以下合同内成立：显式 degree-two resource incidence、(W\le1)、单位外端、独有 private machines、无其它 jobs/constraints、真实完整原任务输出。资源跨三组、任意外端处理时间、degree-three cube、隐式指数菜单、一般 unrelated-machines、全局新颖性和生产安全性均未认证。VW2010 的 published additive interface 只是被逐条件调用的外部结果，不被重写成新定理。

处置：三源均 `integrated` 到本审查对象；canonical 语义、独立实现和代码审查的独有边界均保留。后续使用需先验证输入属于上述受限域，再引用《二度菜单联合取整有限审计--审查》的有限 fixture/root 证据；不能将其 finite audit 当作全量证明，也不能把 degree-two 结论移植到五源 degree-three cube。
