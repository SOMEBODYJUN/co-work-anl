本批三源都审查候选 `UM-Q-PRIVATE-INJECTIVE-TREE-FRACTIONAL-FLOOR-v1` 的独立证明链，但不重复领取/改写 Exact v1 原件（`4b9189efa90c412a130c` 已由 Boss3 认领）。独立 cover、independent literal 与作者 Proof 都明确引用同一个 Exact v1 SHA `aa3ed3a09e04d291b1266468af5814ffd8bd649cac4746514f60a79e791ecf54`；它们的独有内容是从该陈述独立重构树 blocker、共同 lambda 计数、Haxell 参数对齐和完整 ordinary schedule 回填。

与现有 v2 定理《私有注入树配置五三界与非注入承诺判定》相比，本增量只补 v1 的独立/作者读后来源与外部定理证据等级。它不建立第二个五三定理，也不把 v1 存在性静默升级为生产调度器或一般 unrelated-machines 结果。

# 共同模型和精确结论

令 d,h>=1，U 为非空 roots，每 root u 有非空状态集 S_u。每个 (u,s) 是完全私有的满 d-叉高 h 树；每个叶 job 的外部映射 f_us 对该状态的 d^h 个叶单射。共同非负 lambda_us 满足每个 root 的状态和为 1，并且每个外部资源 z 的加权全 root incidence 不超过 1：sum_(u,s) lambda_us * indicator[z in f_us([d]^h)] <= 1。

固定 1<=r<=d，写 k=r^h、b=(d-r+1)^h。若 b>=2k-1，则存在每 root 一条带真实状态见证的满 r-叉子树，所有 roots 的选中叶资源两两不交；回填原树所有 selector、internal edge、leaf jobs 后得到完整 ordinary schedule，峰值 Cmax<=2-r/d。取 r=floor((d+2)/3)=ceil(d/3) 时 b>=2r^h-1，故 r/d>=1/3，给出 Cmax<=5/3。该结果是存在性结论。

# 三源逐项交叉核验

## 1. 单树 blocker 和单射承重

Independent cover 与 literal 两份重构都从同一归纳开始：要击中满 d-叉高 h 树中的每一棵满 r-叉高 h 根子树，最少要删除 b=(d-r+1)^h 枚原叶。高度 t 时，至少 d-r+1 个根孩子必须各自被阻断；反向任选这些孩子并递归放最小 blocker 即达到下界。

叶到外机的状态内单射把叶的 cardinality 精确转成外部资源集合的 cardinality。若映射不注入，一个外机可同时命中多枚叶，b 下界就不能推到资源 transversal；这一前提必须和 v2 的非注入过滤器分开。

## 2. 共同 lambda 的资源命中下界

构造二部均匀超图：左侧 root u，右侧外机 z；每条边含一个 root 和某一真实状态满 r-叉子树叶像的 k=r^h 个不同资源，因此总边大小 k+1。任意非空 I subset U 的资源 hitting set X 对每个状态命中全部子树，故每个状态在 X 中至少有 b 个叶像。用**同一**共同 lambda 加权并交换求和：

`b |I| <= sum_(u in I,s) lambda_us |X intersect B_us| <= |X|`。

最后一步是每个资源 z 的共同容量上界；不能让 X 或 z 重新选择 lambda，也不能把 root 顶点本身算作 resource-side hitting vertex。因而 transversal number tau_I>=b|I|>= (2k-1)|I| > (2k-1)(|I|-1)。Haxell 条件的系数与总边大小 k+1 对齐为 2(k+1)-3=2k-1，严格差对 |I|=1 和边界 b=2k-1 仍成立。两份独立记录分别从 Annamalai Theorem 1.1 和 AFS Theorem 2/3 核对这一外部条件；它们未把 Haxell 1995 原文误报为已阅读全文。

## 3. 完整实际 schedule 回填

匹配为每 root 返回一条真实 (state, subtree) witness。选中根放一个 selector unit；每个 active internal 节点向下发送 r 个 unit outgoing jobs，其余 d-r 个任务留在父端，得到 `1+(d-r)/d=2-r/d`。未激活节点没有 incoming unit，全部 d 个 small jobs 留父端，负载 1；未选状态和 lambda=0 状态的 jobs 也全部保留。选中叶 unit 发送到匹配保证的全局不同资源，外机负载至多 1。

Proof 明确在 C<2 逆向/回填中保留所有 original jobs、zero private times、duplicate states 和 unused resources；它不只算叶资源，也不在负载恰等于 2 时套用 unit 排斥。若 supplied target 的峰已达到 2，则全 private schedule 提供 load-at-most-two fallback，端点闭合。

## 4. 五三算术与退化

取 r=floor((d+2)/3)，有 d-r+1>=2r-1。由 `(2r-1)^h+1>=2r^h` 得 b>=2k-1；r>=d/3 给 C<=5/3。d=1 时 r=k=b=1，超图退化为 Hall，完整链负载 1；r=1 是路径候选；h=1、lambda=0、跨状态资源重复均已覆盖。U、菜单、d、h 非空/正是模型域；非注入、共享内部机、额外 preload/job、非均匀父时间不在结论内。

# 外部证据等级与未解决范围

Independent cover 的 Annamalai 读取确认有限均匀超图定义、Theorem 1.1 严格 transversal 条件及固定 rank/slack 算法限制；independent literal 与 author Proof 进一步核对 AFS/Haxell 参数转换。三源共同承认候选超边数可随 d,h 指数增长，Haxell 是存在性工具；没有给变参数 deterministic bit-polynomial 匹配或实际调度生成器。共同 lambda 和完整状态单射是可检验前提，不由 CONFIG、Latin 或逐资源分布自动产生。

这批来源不提供一般 UM 五三算法、近二 hardness、source decoder、客户 SPE 结论或全球新颖性。后续若要使用 v2 的非注入过滤判定、CONFIG(T) 桥或有界 multiplicity 扩展，必须分别验证对象的状态内单射、完整任务回填和共同 lambda 量词，不能把 v1 的存在性当作统一输出算法。
