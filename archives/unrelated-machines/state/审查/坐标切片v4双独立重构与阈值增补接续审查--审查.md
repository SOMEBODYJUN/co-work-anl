# 2. 共同对象和 v4 量词

三源都围绕稳定身份 `UM-Q-COORDINATE-SLICE-PARTIAL-MINREP-COUNTEREXAMPLE-v4`：simple balanced (D)-regular bipartite projection source，双方各 (D) 个顶点，字母表 (Sigma) 大小 (Q)，每条边有完整双射 (pi_{ij})，并固定 (pi_{ij}(0)=p_i)。每个左玩家为每个状态建一棵深 (Q) 的 (D)-叉私有树；叶资源为 ((b_j,x)in[D]^Sigma)，叶固定 (x_eta=i)；selector 时间 1，树弧父端 (1/D)、子端 1，未列有限端为 (infty)。

source 列表成本是两侧列表大小之和，边由一对兼容标签覆盖。每个 seed 的坐标表、任务身份、资源块和完整 P 都是显式有限对象。该模型与一般 unrelated-machines 的所有矩阵不同，也不含 CAG 的顺序提供者或覆盖均分。

# 3. 两份独立 H 重构：同时廉价列表的概率存在

## 3.1 第一份重构的计数路线

第一份来源设

\[
K=gN=2gD,\qquad M=D^2,\qquad T=2DQ,
\]

并要求 (D\ge16g/\rho)、(D\le17g/\rho)、(Q\ge(100g^2/\rho)^4)。给定总成本至多 (K) 的列表族，固定 (pi_{ij}(0)=p_i) 的特殊标签覆盖边数至多 (K)。一个普通覆盖边由非零标签造成；条件双射使其概率至多

\[
p=K^2/(Q-1).
\]

边间独立只来自不同 (pi_{ij}) 的独立抽样，不需要同一边内部不同标签事件独立。若覆盖至少 (
ho M) 条边，普通边至少 (
ho M-K\ge7K\ge4K)。选出 (4K) 条边后，固定列表族成为坏列表的概率至多

\[
\binom{M}{4K}\left(\frac{K^2}{Q-1}\right)^{4K}
\le \left(\frac{e gD^3}{Q}\right)^{4K}.
\]

所有列表族是 (T) 个 token 的子集。以 (z=K/T=g/Q) 的生成函数估计

\[
\sum_{k\le K}\binom{T}{k}\le(eT/K)^K=(eQ/g)^K.
\]

总坏概率不超过

\[
\left[\frac{e^5g^3D^{12}}{Q^3}\right]^K
\le \left(\frac{e^5 17^{12}}{10^{24}g^9}\right)^K<10^{-5}<1/2.
\]

所以至少半数 seed 同时使**所有**成本不超过 (gN) 的列表覆盖严格少于 (
ho M)；该结论不依赖有限实验或外部困难性。它没有把互不相交 copy 的同一 soundness 自动推出，也没有声称确定性 seed 检测器。

## 3.2 第二份重构的独立尾界路线

第二份来源使用相同 v4 Exact 参数，但把 H 写成另一种更细的严格尾界。固定列表边的特殊标签 0 覆盖至多 (2gD\le\rho D^2/8)。非零覆盖概率仍为

\[
\le(gD)^2/(Q-1),
\]

并用 (D\le20g/\rho)、(Q\ge(100g^2/\rho)^4) 得到 (<Q^{-1/2})。列表数用

\[
\sum_{k\le2gD}\binom{2DQ}{k}
\le e^{2D}Q^{2gD}.
\]

若 (Y) 是非零覆盖边数，则均值不超过 (D^2Q^{-1/2})。取 (t=3
ho D^2/4)，标准 upper-tail/指数 Markov 给出

\[
\Pr[Y\ge t]
\le Q^{-3\rho D^2/16}.
\]

合并列表数得到

\[
e^{2D}Q^{2gD-3\rho D^2/16}
\le e^{2D}Q^{-gD}<1/2,
\]

其中最后一步使用 (D\ge16g/\rho)、(Q\ge2D+1) 的严格常数余量。特殊边占比后，覆盖至少 (
ho D^2) 必然触发该尾事件，因此得到同一“所有廉价列表同时严格少覆盖”的 good seed 存在性。

这份路线独有的是：对边内事件不作独立假设、用 Bernoulli 和的上尾替代选 (4K) 条边、显式处理实数阈值和列表可在看到 seed 后自适应选择。两份 H 证明可互相作为独立计数重构，但均是内部数学笔记，不是新的 source-hardness 定理。

# 4. 两份 I/J/K 重构的共同核心

## 4.1 I：每个 seed 的真实近满分叉调度

所有玩家选状态 0。每个测试保留 (D-1) 个孩子；对其他投影坐标 (p_t)（(t\ne i)）删值 (t)，其余自由坐标删任意固定值，形成深 (Q)、每层 (D-1) 叉的完整子树。任意两个玩家 (i,i') 在同测试中不能共用叶资源：玩家 (i') 要求 (x_{p_{i'}}=i')，而玩家 (i) 已排除该值。不同测试资源块天然不交。

selector 放状态 0 根，选中子树 port 全下传，其余状态/分支 port 全留父端。活跃内部机器负载 (1+1/D)，非活跃内部机器负载 1，资源机至多一枚单位 port。该实际分配对每个 seed 成立，不依赖 H 的 good 事件，也不依赖 source value。

## 4.2 J：CONFIG1 有理证书

每个内部机器使用两个配置：incoming unit singleton，权 (1/Q)；全部 (D) 枚 outgoing small 端，权 (1-1/Q)。selector 在其 (Q) 个状态根合计覆盖 1；每条内部 port 由父端 (1-1/Q) 与子端 (1/Q) 合计覆盖 1。每个资源机 ((b_j,x)) 恰有 (Q) 枚 eligible 叶 port（由每位玩家的双射遍历所有 (eta) 计数），分别列 singleton 权 (1/Q)。所有非空配置负载恰 1，所有任务边际覆盖恰 1。

由于任何 selector 的有限处理时间为 1，(T<1) 的配置 LP 不可能覆盖 selector，故 (T_{CONFIG}\ge1)；上述证书给 (T_{CONFIG}\le1)，所以恰为 1。两份重构都强调：CONFIG 证书不是一份真实同时执行的整数调度，也不自动给出整数 OPT。

## 4.3 K：good-NO 的精确整数值

good seed 的 H 性质排除源完美单标签赋值：若存在该赋值，singleton 列表总成本 (N\le gN) 会覆盖全部 (M\ge\rho M)，矛盾。已有 strict threshold 等价给出：完整 P 存在实际 makespan (le1) 当且仅当源有满足赋值；因此 good seed 的实际 OPT (>1)。所有有限处理时间是 (1/D) 的整数倍，非空有限调度集合使 OPT 取得，故

\[
\operatorname{OPT}\ge1+1/D.
\]

I 给相反上界，故

\[
\operatorname{OPT}=1+1/D,
\qquad
\operatorname{OPT}/T_{CONFIG}=1+1/D.
\]

该 gap 随 (D) 增长趋近 1，不能写成 near-two hardness。两份来源都强调完整 P 可能含 (D^Q) 树展开，证书多项式性只相对于已显式展开的 P 编码，不承诺 binary (D,Q) 的统一 source compiler。

# 5. v2 Exact-threshold addendum 的独有增补

`9becde5d515007ec32fc` 是 `UM-Q-COORDINATE-SLICE-PARTIAL-MINREP-COUNTEREXAMPLE-v2` 的陈述增补，继承 v1 Exact A–D，不覆写 v1。它把严格阈值写成任意 simple balanced (D)-regular 全投影输入的两向 iff：

\[
\text{完整实际 }P\text{ 存在 }C\le1
\iff
\text{原投影游戏存在满足全部边的单标签赋值}.
\]

对具体 (K_{D,D})、(Sigma=\{0,\ell_j,p_i\})、(pi_{ij}(0)=p_i) 的条件双射 NO 家，在 (D>\max(2,2g/\rho)) 时，实际整数最优恰为 (1+1/D)。它还纠正复杂度措辞：固定满足条件的 (D) 时，随 (t) 变化的显式展开是多项式；“固定 D”不能被误读为 binary (D) 变化时的统一多项式 source compiler。

该增补为主对象提供更一般的 strict-threshold iff 和复杂度边界，但文件本身没有证明；主对象的证明与有限物理核验继续承担具体数学支持。它不增加 PCP/UGC、NP-hardness、一般 UM 或近二结论。
