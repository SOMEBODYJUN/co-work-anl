# 精确输入与全部任务的构造

给同一合法显式UM的两份实际完整分配 $\sigma_0,\sigma_1$，有限时间属于 $\{1,1/k\}$，二进制整数 $k\ge2$，两份峰值均≤$T=1+1/k<2$。两不同原机器v/w在前一见证均unit-vacant、后一见证均unit-present；unit指实际处理时间恰1，而非某件指定job身份。任务可有任意多合法端、可在两见证small↔unit切换，不要求DAG或small行预算。对四个指定位向量可输出全部原任务一次合法执行，使

\[
C_{\max}\le B(k)=1+\lceil(k+2)/2\rceil/k.
\]

每份见证中的“原job—机器”unit边是一份matching，因为一任务一个目的地且T<2。保留公共边，差分分量是交替路径或偶环，job/machine顶点在分量间互斥。四类解释不能省略：

| 分量 | 两方向对原任务的实际含义 |
| --- | --- |
| machine–machine路径 | 内部job都unit，两个机器端点presence相反；恰一端是0→1新增端。 |
| job–job路径 | 两端job各只有一个见证用unit，另一端是真实small；任一方向恰一端small。用一个virtual变量编码选择哪端small，最终恢复整条路径全部原jobs；同机small选项也合法。 |
| job–machine路径 | active同时匹配job端和机器端；inactive让该端点job去已知small端。改active只删一枚small、增加端点unit，内部unit不变。 |
| 偶环/公共边、并图外job | 前者始终unit；并图外job两见证都small，可在其两原small端选择。 |

两测量机均是N1新增的机器端点，同一分量不能含两台这样的端点。因此改变一个测量分量不动另一测量位。00/11直接返回两原见证。对mixed令v要vacant、w要present：

若v为job–machine端，从完整$\sigma_1$翻此一分量为inactive，只新增一个已知small端点job，所有机器峰≤$T+1/k=1+2/k\le B(k)$，w不受影响。若v为machine–machine端，固定其方向0，w所在另一分量方向1或active，其余machine–machine/环固定方向，**全部**job–machine分量active。此时需要共同分配的只有真实small–small jobs与每条job–job路径的一个virtual变量。

各变量在两选项各放一半，同机合并。记机器均值任务数$\mu_i$，两原见证small任务数$s_i^0,s_i^1$，则$\mu_i\le(s_i^0+s_i^1)/2$：全部active只删掉原均值中的非负half small。变量到两原small机的分数满流已存在，机器整数容量$\lceil\mu_i\rceil$由流整数性给共同整数解，再按virtual选项解码原路径。virtual不是新增执行任务，最终原jobs各一个原合法端。

逐机同时控制：两见证均unit-present时small数各≤1，最终unit+small≤T；均vacant时small数各≤k+1、最终不会新增unit，仍≤T；presence不同则small均值≤$(k+2)/2$，最终至多一unit加$\lceil(k+2)/2\rceil$枚small，峰≤B(k)。这覆盖全部机器，不只两个测量端。

# 参数、显式锐族与复杂度

k2/3均有B2，不能说所有k绝对次二。偶k为$3/2+1/k$，奇k为$3/2+3/(2k)$；k≥4时B≤9/5（k5达到），趋于3/2，且所有k有B≤3T/2、奇k等号。空任务不能满足两台新增unit测量位的附加输入，非反例。

四机P/Q/M/N，unit-only任务x可P/M、y可Q/N；两组各k+2枚small-only任务分别可M/Q及P/N。00见证令x在P、y在Q，并给每small组在无unit机k+1枚、有unit机1枚；11反向，全部机恰T。mixed10强制x在M/y在Q，第一small组的两个端都已有unit，鸽笼迫某机至少$\lceil(k+2)/2\rceil$枚small，C≥B；两组尽量平分达到B。mixed01对称。无边界约束的真实OPT为T：一致模式每个small二机组总工作2T，mixed亦≥T，两给定见证达到。因此是逐k锐胶合，不是原P近二gap。k3给严格模式4/3而mixed2，比值3/2。

一般胶合只扫描两份实际见证、至多2n条unit边，small流变量/边数多项式，容量可截到变量数、分母仅2，不按k数值造槽。四机锐族自身有2k+6 jobs，逐k输出O(k)，不承诺按bit(k)写k件任务。
