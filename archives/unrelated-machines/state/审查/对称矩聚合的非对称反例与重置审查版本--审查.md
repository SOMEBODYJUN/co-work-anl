# 对称真列足够合成新真/补列，不能删对称性

各job选择集互斥，P为非空有界有理one-hot多面体。源$x\in P$、$Y=Y^T$、diagY=x、每真列$Y_{:e}\in x_eP$。由真列本任务块非负且和x_e，得同任务异选择Y=0；由覆盖及对称性得每job共同整列恒等式$\sum_{e\in E(j)}Y_{:e}=x$。

R仅在同一保留job内合并旧选择，整job删除为零列。若每保留旧选择都有$RY_{:e}\in x_eP'$，则新选择f、原像$A_f\subseteq E(j)$满足

\[
x'=Rx,\quad Y'=RYR^T,\quad Y'_{ff}=x'_f,
\quad Y'_{:f}=\sum_{e\in A_f}RY_{:e},\quad
x'-Y'_{:f}=\sum_{e\in E(j)\setminus A_f}RY_{:e}.
\]

凸锥求和给新真/假齐次列；任一保留job全旧列求和给$x'\in P'$。没有保留job时不能从空真前提推出任意零维P'可行，须另查。边际0/1不除法。此证明**没有用旧补列**，但用了能推出共同整列恒等式的对称性；不主张全对称性在所有推广中逻辑最弱，不得无替代假设直接删掉。

## 五literal反例：旧真/假列及目标真列全合法，新补列仍负

取job A三选择a1/a2/a3、job B两选择b1/b2，P为两单纯形积。令

\[
x=(1/3,1/3,1/3,1/2,1/2),\quad
Y=\begin{pmatrix}
1/3&0&0&1/6&1/6\\
0&1/3&0&1/6&1/6\\
0&0&1/3&1/6&1/6\\
1/3&1/3&1/3&1/2&0\\
0&0&0&0&1/2
\end{pmatrix}.
\]

Y非对称、diag=x。任a_s列两job块和均1/3、补列均2/3且非负；b_s列两块和均1/2、补列同样合法。R合并a1/a2成a0，其余不改，整个P映入P'，所以全部旧真列的目标齐次前提成立。但$x'_{b1}=1/2$，$Y'_{b1,a0}=2/3$，新补列该坐标$-1/6$。源A整列在b1行和1≠x_b1，正是对称性缺失的破口；即便目标允许非对称，补列也已负，不只是形式上目标不对称。

# 固定fallback的2q、同边际q及随机q+2不能合并

取q≥2、m2q/n2q²、时间1/q、原分布均匀平衡每机q jobs。吸收标签包大小c、删机，不条件化原分布。固定逐job fallback的组大小f_k，r=n−c，均值$(r+f_k)/m$。c<2q时必某f_k≥q，取其新真literal双原像，条件计数

\[
L=1+\frac{(2q-1)(r+f_k-2)}{2(n-1)},\quad
L-q=\frac{(2q-1)(f_k-c)+n-2q}{2(n-1)}
\ge\frac{q-1}{2(n-1)}>0.
\]

量化到所有标签包/固定fallback。q≤c<2q残余真实峰1本来可行，故是指定旧矩推前失败，不是残余不可行；q1阈值1另分支。

c2q且全部f_k≤q，真条件按原像大小t及受查行k/l分五类（f=f_k）：

| 类 | L |
| --- | --- |
| t2,k=l | $1+(2q-1)(r+f-2)/(2(n-1))$ |
| t2,k≠l | $[q(r-1)+(q-1/2)f]/(n-1)$ |
| t1,k=l | $1+[(q-1)(r-1)+qf]/(n-1)$ |
| t1,k≠l且job fallback=k | $q(r+f-2)/(n-1)$ |
| t1,k≠l且fallback≠k | $q(r+f-1)/(n-1)$ |

全≤q，第三类q2可等号，不能改为严格。假条件须另证：$(m\mu_k-tL)/(m-t)\le q$等价$t(q-L)\le c-f$；t1由c−f≥q/L≥0，t2用L≥f/2，首/次类分别化为$r(2q+1-f)/(2(n-1))\ge0$和$[2q(r-1)-fr]/(2(n-1))\ge0$。分母m−t>0。删更多整任务只删条件非负项，阈值扩到更大c。旧分布真实推前继承one-hot/对角/对称，但个别态可超容量。

c=q、fallback各组q时，指定Rx边际$(1+\mathbf1[\phi(a)=k])/m$逐列和1/逐行q。旧条件超额$q(q-1)/(2q²-1)>0$，却可把此同一边际填q单位槽、乘m成m-正则二分多重图，反复Hall匹配m次得m份真实残余峰1调度，精确保边际且全部真/假行计数q。故新$\widehat Y\ne RYR^T$，并不意味着Rx不可实现。显式n2q²、矩/匹配输出总位多项式，无一般非均匀重耦合oracle。

后来另立独立uniform后备kernel，逐旧删机保留job独立抽K2q−1。新same/other条件概率$\alpha=1/K-(q-1)/(q(n-1))$、$\beta=1/K+1/(2q(n-1))$，同任务categorical块须修正。A1+(r−1)α、B(r−1)β满足$A-B=1-(r-1)K/[2q(n-1)]>0$，假行是B或A/B凸组合，全部容量等价A≤q。q+1过载与q+2余量的分子分别$(q-2)q(2q+1)+2$、$q²+4q-3$，同正分母qK(n−1)；单调性给全称q+2，空残余/q1单列。该第三Claim不改前两个合同。

随机矩通过不保每态：旧两机各q保留jobs、删机全部抽到另一机的正概率事件给负载2。m=2q承重，review另有q2/m8 c4计数283/140>2、c5为27/14<2，吸收5/2大于2；不当一般m定理。
