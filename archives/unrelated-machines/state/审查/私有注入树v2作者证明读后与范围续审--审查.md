## 2. 局部 CONFIG 行：正部构造确实充分

在 `1 <= T < 2` 下令 `s=floor(d(T-1))`、`a=d-s`。若 incoming 边际为 q、每个 outgoing job 的 unit 边际为 t_e，则 small 边际 A_e=1-t_e。Frechet 下界给 incoming 与 small 同时出现的概率至少 `c_e=(q-t_e)_+`，含 incoming 的配置最多容纳 s 枚 small，故 `sum c_e <= s q` 是必要条件。

作者 v2 的充分性不是只写一个边际等式：当 q>0，把每个长度 c_e<=q 的区间串接到长度 `L=sum c_e<=s q` 的圆周并模 q 投影。各原区间长度不超过 q，所以同一 small 不会在 incoming 部分重复；任一点覆盖次数至多 `ceil(L/q)<=s`。非 incoming 区间长度 `1-q`，剩余边际 A_e-c_e 非负且不超过 1-q，因而可在该段初始区间内实现；无 incoming 时全部 d small 的总负载恰为 1。q=0、q=1、s=0 分支分别删去零长段或强迫 `c_e=0`，没有除零。

该构造保证每个 small 边际精确为 1-t_e、incoming 边际精确为 q。外机 T<2 的配置仅允许 empty 或 unit singleton；资源行 `sum t_e<=1` 正好充分。每内部 job 的父边际 `1-t_e` 与子端边际 t_e 合成 1，selector 根边际也合成 1。它构造的是一个配置分布，不声称不同机器行来自同一个整数调度。

作者另给辅助变量 `z_e >= 0`、`z_e >= q-t_e`、`sum z_e <= s q` 的线性系统，并说明它与正部行等价、显式规模和整数系数位长多项式。有限 processing times 只有 1 和 1/d，配置负载在整数/d 网格上；nonempty selector 给阈值下界 1，全父置给上界 2，故可在 `j=0,...,d` 的 `T=1+j/d` 网格上做配置阈值二分。该二分只求 configuration threshold，不输出整数 schedule。配置族向下封闭，逐项拆分/删除 excess job 的权重可把“至少覆盖”规范为“恰覆盖”，不增负载。

## 3. 共同 b 子树流和单状态一致性

由局部行条件得到

`sum_e min(q_v,t_e) >= a q_v`.

对任意 `0<b<=q`，逐项有 `min(b,t) >= (b/q) min(q,t)`，分别在 t<=b、b<t<=q 和 t>=q 核对。因此可选有理 b_e<=min(b,t_e) 且总和 ab；逐项贪心填容量合法。比例 b_e/b 位于 uniform-matroid base polytope `{x in [0,1]^d: sum x=a}`，可分解为恰 a 个 distinct children 的子集分布。

根质量 b=y_us，先按 root y 选一个真实 state；每活跃节点继续按固定子集分布，节点有唯一私有 parent，递归的无条件活跃质量保持给定 b_e。每 child 质量不超过 t_e=q_child，每 leaf 实际活跃概率不超过原 LP unit 边际。作者允许先在可行有理配置 LP 中无损选有理点，再做有理递归；不把任意原分布默认成有理。

这是每个 root 的局部树分布，不是全局整数调度耦合；不同 roots 的资源冲突仍交给 Haxell。每 root 从头到尾选择同一真实 state，而非沿路径改 label。菜单可能指数大，但这里只作存在性辅助 state。

## 4. Blocker、Haxell 和 rank 量词

作者 v1/v2 的 blocker 归纳分别使用 d-tree 与 a-tree，数量为 `(d-r+1)^h` 与 `(a-r+1)^h`；height zero 只作辅助归纳，h=1、r=1 均正常。state 内 leafmap 注入保证同一 auxiliary a-tree 的 leaf resources 互异，所以 blocker 数可换算为资源数。

v2 只用正权 a-trees 并对每棵树全部 r-subtrees 建 hyperedges，已经足够：任何 hitting set 要命中每个正权辅助 tree 内全部 r-subtrees；按同一 root 分布加权得 `tau(H_I) >= B_h |I|`。不需要把零权或未生成 a-tree 加入超图。每条 hyperedge 含一个 root 和 R=r^h 个 distinct resources，总 rank 是 R+1；独立亲读的 Annamalai arXiv:1509.07007v2 Theorem 1.1 使用该总 rank，所需常数为 `2(R+1)-3=2R-1`。B_h>=2R-1 时严格超过 Haxell 阈值，I 为空时右侧为负，R=1 退化 Hall。重复 edges 可去重并保留 witness。

记录明确区分外部证据：本次依据已亲读的 Annamalai 论文复述，没有冒称亲读 AFS2008 Theorem 2 或 Haxell 1995 原 proof 全文。Annamalai 的算法还要求固定 rank/固定正 slack；本对象辅助 rank、tree height 与 hyperedge family 可能随输入变化，不能把存在性匹配直接写成一般确定性位多项式 schedule algorithm。

## 5. 全部原 jobs 的真实回填

作者 v1/v2 的完整回填保持普通 UM 原矩阵所有 jobs：selector 放 matching 选出的原 state root；选中真实 r-subtree 的 jobs 下送；其余 jobs 全父置。

* 活跃根有 selector unit，活跃非根有唯一父 job unit，另留 d-r small jobs，负载 `2-r/d`；
* 非活跃内部节点、同一 state 未选 d-branches、其他未选/零权 states 没有 incoming unit，全部 d small jobs 父置，负载 1；
* 每个外机至多接一枚 matching leaf unit。

辅助 a-tree 不变成额外物理任务或机器；作者明确回填完整原 d-tree。因此证明没有通过删除辅助树外 jobs 人为降低峰值。不同 states 的 private machines 在这一步是真正私有的。

默认 `r=ceil(a/3)` 的 blocker 数值条件和比值链给 `2-x/3 <= (5/3)(2-x)`（x=a/d，x<=1）；T>=2 由直接全父置调度覆盖。d=1,a=1,r=1,h=1、zero lambda、阈值等号均无例外。

## 6. C 过滤和承诺判定边界

在严格 actual C<=1 下 selector 迫使选中 state 的全部正 small ports 逐层下送，最终全叶 unit 外置；注入 leafmap 与 root 间 resource disjointness 因而是必要的。过滤后共同 lambda 至少包含该 0/1 证书；空菜单或 LP 不可行确实排除原 OPT<=1。

若过滤后的共同 lambda 可行，对保留部分应用五三存在性；被过滤 states 的全部原 jobs 全父置，内部负载 1，不用外机，故可无冲突回填原完整 P。原 selector 的保留资格仍合法。

该判定器的准确承诺是：可行返回给出原 OPT<=5/3 的存在性，不可行返回保证原 OPT>1。它不是对所有 NO 输入都证明 OPT>5/3，也不是一般 approximation algorithm；Haxell 只提供存在性 schedule，不输出 sigma。v2 也没有推出非注入原 P 的 CONFIG gap<=5/3，只有过滤后 LP 可行才进入该结论。
