# 森林边界审查源 e279 补录

## 来源身份与整合关系

`e2795e4107346f02a15e` 是 `research/reviews/unrelated_machines/forest_boundary_contraction_review.md` 的 32,295 字节冻结审查版本。本轮通过 `clean show` 全文实读。现有 `archives/unrelated-machines/state/审查/森林边界与双端菜单有限审计--审查.md` 已保存同一系列的有限审计汇总；本补录把该版本的完整合同、证明链、失败边界和审计计数与现有对象明确接上，不把历史 review 当作一般 UM 新定理。

## 承接的数学合同

单边界版本要求：根边界机不受局部容量约束，内部支撑为以根为边界的森林，每个 gadget 任务有一或两台可用机，内部无外部任务。局部 floor DP 传递真实父端负载 `m_v`；在 `T>0` 时以 `δ_v=ηT/q_v` 向下取整、对父包做精确 0/1 背包，得到内部负载不超过 `(1+η)T`，并对任意精确 `T` 可行分配保持根端负载支配。`T=0`、空任务、零成本、巨大有理分母、平行任务、无根分量和深链都逐项保留；FAIL 只保证精确不可行时可靠，成功允许精确 `T` 不可行。

双边界菜单版本要求两个边界 `a,b` 的同一实际菜单项同时满足一端精确支配、另一端至多乘 `(1+η)`，并且所有内部机与 b 端受 `(1+η)T` 约束。通过从最小正 b 端时间起的几何预算、零预算分支和局部父包 floor，源中证明 `(1+η/3)^2≤1+η`；共同选择不能拆成两个独立最小值。多次恢复误差按 `max` 组合而不按深度相加，但必须每次真正删除活跃机器并保存 task-disjoint 展开见证。

## 有限证据与边界

源中完整列出 458 个强域有限实例、1211 份参考调度、541 个独立菜单见证、2595 次预算查询、7351 个局部背包状态更新，以及 1500 边深链、257 位分母、非森林三角形拒绝和共享 b 挂件。另有 500 例规范 two-boundary 审计与 600 例 one-boundary crosscheck 的冻结 JSON。它们是 Fraction/整数有限证据，不能替代全称归纳证明，也不能证明一般图结构选择、普通任务压缩、core selection、统一小于 2 近似或新颖性。

来源还逐字区分规范 `forest_boundary_downward.py` 与独立 local-floor 原型：前者保存 backpointer，后者复制 tuple；二者的输入合同、根/孤立分量处理、外部任务隔离和 `None=REJECT_TARGET` 语义不能由稀疏局部字典自动推断。Jansen–Maack–Solis-Oba 的一般结构参数 FPTAS 只作为已知边界定位，不从本源导入一般结论。
