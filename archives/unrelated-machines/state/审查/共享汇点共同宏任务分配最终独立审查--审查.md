# 2. 结构合同和先行义务

模型有 private homes、一个共享 sink、宏任务 B 和不交私有任务组 S_h。宏任务只在 homes 可用；每个私有任务可在自身 home 和 sink 的显式非空子集上处理，时间为二进制非负有理数。阈值 T>=0、eta>0，严格要求每条有限宏边大于 T/2。私有任务不要求 tiny 尺寸。

先行独立重构识别六项承重义务：

1. 宏任务边必须严格大于 T/2，等号不能自动纳入，否则同一 home 可放两枚宏任务；
2. 空 home 也有私有任务撤离成本，不能只覆盖宏任务；
3. 每个局部模式必须有同一个实际子集见证，机器之间任务组不交才可共同实现；
4. T=0、无私有任务、空 home 集、零成本、不可用端和强制任务必须分别处理；
5. sink 误差只能使用一个全局 budget，不能让各 home 独立花 eta T 后求和；
6. 位复杂度包含所有模式、猜测、DP 状态、匹配增广和有理位长。

独立路线使用全局 scale s=eta T/N，按真实 sink 成本 floor；每 home 的 DP 计算各整数 sink budget 下最小精确 home load，统一查询宏任务和空模式，再用 integer residual matching。这个路线未调用规范 cover-DP/Hungarian，作为交叉证明义务审查。

# 3. 规范构造、覆盖 DP 和全局预算

规范正向先收集零价物品；随后猜最优正价集合最大成本，保留不超过猜测的物品；真实覆盖量由 DP 计算，避免舍入丢失。每次使用新层/不可变 bitmask，整数成本为零的物品也不复用。每个 home 以一个模式覆盖宏任务和 private subset，匹配成本是同一 sink 上真实所选子集成本。

与一个真正 T 调度比较时，所有局部乘性误差的总和只有一个 (1+eta)，不是 h eta。强制 sink 成本保留原值，方向为 C<= (1+eta)T。空模式、零价任务和未选任务都保留全原 jobs 语义。

拒绝条件包括：

- 单 home 至多一个宏任务；
- 宏边大于 T 的剪枝；
- 强制 home 超载；
- 强制 sink 超过 T；
- 全局匹配不可行；
- 近似匹配实际 sink 成本超过增广预算。

这些拒绝在 OPT<=T 时是健全的；成功可以发生在 OPT>T 的实例，这是接口允许的资源增广，不是错误分类。

# 4. Integer Hungarian、总位复杂度和输入修正

规范模式成本清除全部原有理数分母；禁边罚值取 h*maximum+1，严格超过任何全有限完美匹配成本上界，输出后仍检查禁边。这样不会把罚边分配误当可行解。

模式数至多 h(b+1)，每个局部猜测至多 O(q^3/eta) 状态更新、至多 q 个猜测；Hungarian 使用 O(h^3) 次整数操作。真实 cost/cover 是原数据子集和，清分母后的整数位长多项式。指数 oracle 只用于有限审计，不进入算法合同。

发现并修复的接口问题：

- 初始实现拒绝时间浮点不完整，仍可能通过 Fraction(eta) 接受 float；
- Python bool 作为 int 可能被误接受；
- 最终代码统一拒绝 float/bool 的时间、target、eta、home 编号和 home 数，新增非法输入检查；
- 独立复核 14 次非法 API 调用均为 ValueError。

这属于输入接口校正，不是数学反例。严格阈值仍不能省掉：一个 home、两枚各 T/2 宏任务可以 T 可行但不符合单宏匹配表示；多 sink 时标量匹配成本不能自动维护每个预算。

# 5. Hall、price-cover 与有限审计的关系

与 Hall 联合组流对象的共同思想是把私有任务撤离资格写成统一接收池，再用一次全局整数流或共同宏匹配；但 Hall 版本允许多个 sink、共同资格集和接收槽，shared-sink 版本只有一个 sink、每任务可用 home/sink 非空子集，先精确生成 local pattern 最小 sink cost，再统一匹配。两者不能因都叫 shared sink 合并量词。

与 private group exit pool 对象的关系是共同退出/有界 profile 和完整调度回填；shared-sink joint 的宏任务、空home、私有成本和 Hungarian budget 合同不同。与 price-cover/共同占位对象以及 higher-order NC 负相关对象也不同；本合同不承诺 pairwise/higher-order law 或多 sink联合选择。

# 6. 尚未扩展的边界

以下仍未解决：

- 一个任务有多个 home，或不同机器上具有不同 identity/大小；
- 多个共享 sink 同时守预算；
- 一般结构的 extraction 与统一 epsilon 常数；
- 更广的宏任务模式、拓扑和全局 joint matching；
- 一般 unrelated-machines 近似算法、UM-TARGET-v1 或外部新颖性。

本审查确认的是一个限域共同宏任务/共享汇点合同及其 finite audit，不构成一般 shared-sink theorem。处置为 integrated：原 review 已复制到 evidence；正文保留独立重构义务、规范构造、接口修正、Hall/price-cover 去重和两份有限审计的准确范围。
