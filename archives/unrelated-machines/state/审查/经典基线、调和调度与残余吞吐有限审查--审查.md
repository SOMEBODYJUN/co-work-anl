# 审查范围与分类

本稿逐字段读取七份冻结 JSON，并回读各自引用的数学稿、测试程序和已有 unrelated-machines 审查。对象都使用精确有理数或整数；它们分别涉及经典 VW 型树族的有限 gap、有限调和调色板的 gcd/lcm 障碍、同总工作量下的坐标下降恒等式、残余容量的晶格与吞吐函数、资源畸变独立重放、严格小于二的批阈值，以及独立均匀后备选择的条件矩运输。每个结论都按“正文中的符号论证”“有限精确核验”“模型障碍/反例”和“未覆盖量词”区分。任何有限 JSON 都没有被当作通用近似定理或新颖性证明。

## 1. 经典 VW 基线：对称树族的显式 gap 端点

`classical_baseline_audit.json` 使用 `fractions.Fraction`，没有浮点 LP 求解器。它记录 3,375 个矩阵案例、13,824 个 oracle assignments、150 个 rational cases 和 6 个非法输入。教学 toy 例只核对了 `OPT=3`、指定坏分配 makespan `5`、比值 `5/3` 和 2,187 个 assignments；JSON 明确说这不是某本教材实例的重现。

正文相关的对称 VW 树族给出以下小规模端点。`k=2` 的展开实例有 4 台机器、5 个作业、32 个分配，`OPT=3/2`、配置证书上界 `3/2`；`k=3` 有 4 台机器、7 个作业、128 个分配，`OPT=5/3`、配置上界 `4/3`；`k=4` 有 74 台机器、169 个作业、树高 3，`OPT=7/4`、配置上界 `5/4`。压缩 DP 另外保留 `k=5,8,16,32` 的端点，整数容量分别出现 `5/9`、`8/15`、`16/31`、`32/63` 的二层计数；这些是显式对称树的递推输出，较大 k 的完整图没有物化。

可作为条件结论的部分是：在该明确 VW 对称树族、给定根参数和 DP 状态的条件下，整数调度值、可行配置证书和枚举最优值彼此一致。它把 `gap_lower_bound` 记录成有限实例的整数下界，而不是声称对所有 unrelated-machines 输入成立。源 JSON 的四条限制必须随结论保留：没有通用 LP solver；rounding 假定输入了可行的 `x`；压缩 DP 只适用于给定对称树；大 k 没有完整图与通用高效求解器。

## 2. 有限调和调色板与 gcd/lcm 障碍

`finite_palette_gcd_barrier.json` 的 claim 是 `UM-FINITE-PALETTE-GCD-BARRIER-v1`。它在 10 个小矩阵上精确枚举，检查零边、无穷边、公共分母、gcd/lcm 网格和端点算术；scope 明确排除 LST LP 和普遍证明。代表性行如下：

| 实例 | 机器/作业 | `B` | `g` | `g/B` | `OPT` | `rho` | 完整有限分配 |
|---|---:|---:|---:|---:|---:|---:|---:|
| zero edges and infinity | 3/5 | 4 | `1/2` | `1/8` | 1 | `15/8` | 72 |
| fixed palette | 3/6 | `5/2` | `1/2` | `1/5` | 2 | `9/5` | 216 |
| coprime rationals | 2/6 | `19/17` | `1/1236789689135` | `1/1382294358445` | `332/221` | `2764588716889/1382294358445` | 16 |
| large denominator | 2/5 | `7/N`（333 位分母） | `1/N` | `1/7` | `8/N` | `13/7` | 8 |

另有五个 deterministic random rows，3 台机器、7 个作业，公共分母位数 9–11，完整有限 assignment 从 216 到 1,458。所有行都通过指定的 4 或 6 项 arithmetic inequalities 与 grid target checks。这里可保留的数学信息是“当输入真的落在该有限调色板并且负载被同一 gcd 网格量化时，端点算术和有限 enumeration 一致”；它不能把 `g/B` 的有限表格变成任意精度实例的 rounding bound。大分母行特别说明，精确有理数并不会自动带来统一数值余量。

## 3. 同工作量恒等式：配置来源的局部下降核验

`identical_work_invariant_audit.json` 是无随机、Fraction 精确的七行回归。对 `m=2,n=4` 穷举 16 个 assignments，初始 makespan `4/3` 的等工作量分配中有 3 个，单次移动后的 makespan 是 1，`OPT=1`。`m=3,n=9` 穷举 19,683 个 assignments，初始 `3/2`、单步 `5/4`，其中 560 个保持坐标非增且总工作量相同。`m=4..8` 只保留公式化输入，给出初始值 `8/5,5/3,12/7,7/4,16/9` 和单步值 `7/5,3/2,11/7,13/8,5/3`，因为全 assignment 数已经不再运行。

因此，正文中“同机器工作量分配的某个坐标下降或重排保留总工作量”的一般 m 恒等式可以作为数学稿中的证明使用；JSON 只核对了 m=2,3 的完整小例与 m=4..8 的公式值。它没有把配置-derived initialization 外推到另一个 one-destination fork obstruction，也没有证明任何调度算法总能找到下降步。与 VW gap 结合时，必须保持对象身份：这里是在固定总工作量层面核对 invariant，尚未给出从任意配置 LP 点到该层的构造。

## 4. 残余吞吐晶格与共同身份控制

`residual_throughput_lattice_release.json` 的 scope 只有七个 tiny lattice cases、四个 occupancy masks、两个近完备 one-job LP、一个 2x2 joint-identity negative control、四个原始 schedules 和四个 exact residual LP；没有随机或大规模 scheduling enumeration。

七个晶格案例覆盖空任务、无轻端点、严格机器重叠、任意端点时间、不完整 eligibility、零时长/零容量和大分母 `1/1000003`。每行都记录 `c,d,c\vee d,c\wedge d`、`lattice_slack` 和 primal/dual vertices。例如 strict machine overlap 的 slack 为 1，mixed dual costs 的 meet/join 都是 1；incomplete eligibility 的 slack 为 `1/36`，而 zero-time/zero-capacity 行保留 `c=1,d=2`。四个 occupancy masks 得到 `(D,F)=(0,2),(0,2),(1/12,23/12),(3/4,5/4)`。吞吐公式的三行只说明在一个未服务任务的构造中，服务比可为 `1/2`,`3/4` 或 `1000000/1000001`。

2x2 negative control 特别重要：矩阵 `[[1,1/2],[1/2,1]]`、目标 `T=1` 的四个 assignment 中，原始 optimum 为 `1/2`；如果按一个共同身份矩阵把两个 residual states 绑定，残余证书只在逐 mask 计算时成立。它说明“先为每个 mask 求 residual LP 再把独立身份拼成一个共同全局分布”需要额外一致性条件。该文件可作为候选定义/障碍和有限证据，不能被写成全局 residual theorem。

## 5. 资源畸变独立重放与容量边界

`resource_distortion_independent_audit.json` 的 scope 是 1,296 个完整 2-group/2-state/2-resource half-integer matrices 加五个 boundary，独立运行共计 1,301 instances、1,328,275 个 original schedules 和 20,798 个 Santa allocations。所有 exact finite checks passed；最差观察比值在解码的 `41/10` 与 `7` 两类中都是 `3/2`，原始 OPT 值覆盖 `1,2,3/2,7/6`，最大记录的 `kappa=2147483647/100003`。它没有调用外部 restricted Santa Claus backend，也没有任何 backend runtime 或普遍 approximation guarantee。

因此可安全接续的内容是：有限资源畸变解码与原始 schedule enumeration 可作为回归、反例搜索和容量边界探针。`3/2` 是在此固定 half-integer 家族和实现合同中的最大观察比值，不是该模型的全局上界。此对象与 palette gcd 审查共享“精确网格不能代替量词”的边界，但保持资源畸变与调度 LP 的模型身份。

## 6. 严格小于二的批阈值

`strict_sub2_batch_barrier_audit.json` 只运行 `k=2,3,7,100`，输出为 `PASS ... OPT=1 witness; strict-sub-2 batch threshold k+1`。这支持一项明确的有限必要条件：在该批构造中，若要求一个批量严格低于 2 的容量上界，则至少需要 `k+1` 个位置/参与者才能容纳该 witness。它是 batch threshold 的条件障碍；JSON 只有四个 k 点，没有任意 k 的机器矩阵、LP 或 schedule enumeration。一般断言只能来自对应数学稿中的符号证明，不能由 `k=100` 的运行输出单独推出。

## 7. 独立均匀后备的条件矩运输

`uniform_random_moment_reset_audit.json` 不是调度 approximation，而是明确输入合同 `m=2q,n=2q^2,p=1/q` 下的条件矩运输。主程序对 `q=2..128` 做了 8,636 个 scalar cases；独立程序还检查直接矩阵与容量行。主表的 `q=2,c=3` 有 15 个 violations，`q=2,c=4` 为 0；`q=3,c=4` 有 70 个，`q=3,c=5` 为 0；`q=4,c=5` 有 189 个，`q=4,c=6` 为 0。零 violations 行不能被解释为全部 family 的成立，因为同一 q 邻近 c 行已经有显式失败。

保留的候选结论是：对该随机 transition matrix，吸收 `q+2` 个任务是某些条件矩行通过的最小门槛候选；这在主表六个 explicit matrices 和 8,636 个 scalar tests 中被核对。独立重放还显示 q=1 的 c=0 行、q=2 的 c=0/1 行存在容量失败，随机分支会产生 `load 2T` 或超过阈值的 literal row。来源明确限制为 uniform family、矩构造而非 schedule approximation、可能需要更高 absorbed load、不是固定的 `R Y R^T` 合同，也没有一般 approximation guarantee。

## 与既有对象的关系

- 经典 VW gap 与《最小星收缩与配置耦合有限审查》《最优凸包长链与闭环逃逸有限审查》都出现 `2-1/k` 或树状递推，但本稿的 `classical_baseline` 只支持显式对称树族的 DP/配置证书；它不补上 pairwise coupling 到全局联合分布的缺口。
- 同工作量 invariant 可以与配置/凸包对象对接，前提是先给出配置点到同工作量层的映射；有限 `m=2,3` assignment 不足以替代该映射。
- 残余吞吐和 uniform moment reset 都涉及“保留/吸收任务”后的容量，但前者是确定性 residual LP，后者是独立均匀矩运输；两者不能互换为共同随机调度模型。
- 资源畸变的 `3/2` 观察比值和严格 sub-2 threshold 是不同的障碍：前者来自半整数资源枚举，后者来自批容量 witness，均需保留原模型量词。

## 处置与接续

七源全部按 `integrated` 处置。已整合的独有内容是：VW 对称树的有限 gap 表、gcd/lcm 调色板端点、同工作量下降核验、joint-identity negative control、残余晶格和吞吐数值、资源畸变独立计数、`k+1` 批阈值与 `q+2` 条件矩门槛。仍属开放或未实现的部分包括一般配置 LP/rounding、跨 mask 的共同身份耦合、外部资源 backend、任意 k 的批阈值证明和一般随机矩近似保证。后续工作应先固定这些对象的输入合同和量词，再尝试把有限障碍升级为符号证明；不能用已列 assignments、matrix cases 或 scalar cases 代替全称论证。
