# 2. Upper-column / 模式基的单侧加性舍入

## 2.1 输入合同

给定二分图 `G=(B,H;E)`，有一个覆盖 `B` 的匹配；每个 home `h` 有显式模式集合 `Q_h`，不允许同一 home 多选，且非空模式的 home 集 `H_Q` 仍能匹配全部 `B`。模式扩张后的横截拟阵基大小为 `|B|`。

给定非负有理矩阵 `A=(a_{zq})`、资源预算 `c_z`、常数列预算 `b≥0`，每列总量至多 `b`，以及可核查的分数基 `x` 满足 `Ax≤c`。舍入目标是确定性总位多项式地输出整数基 `I` 和覆盖 `B` 的宏匹配，并保证

\[
\sum_{q\in I}a_{zq}\le c_z+b
\]

对每个资源行成立。该合同提供统一加性 `+b` 上界，不保证任意成本、严格最优负载或双侧误差。

## 2.2 紧集链和永久固定

算法对 `x` 做逐坐标精确 lex LP，取得投影顶点，而不是任意扩展流顶点。固定若干变量为 0、收缩为 1 后，剩余基多面体的极大紧集链给出最小面维数 `d≥Σ_e(1−x_e)`。若有 `k` 条尚未删除的资源行，交切顶点的维数约束给 `d≤k`，所以剩余分数缺额总和不超过 `k`。列预算推出未来总增量至多 `bk`，至少有一行的未来上增包络不超过 `b`；删除该行并永久保留当前预算，迭代直到得到整数基。最后使用整数匹配恢复真实宏身份。

这条链只允许永久固定 0/1；临时 LP 顶点、释放临时分数和 lex 等式不能被当作已选实际任务。直接邻接复制会允许同 home 多选，从而破坏 home 容量与联合匹配。

边界包括 `b=0`、rank 零、空资源行和显式模式。来源记录的小菜单例说明在一般接口中统一误差 `cb`（`c<1`）不能保证；`+b` 是该合同自然边界。该证明是上界型拟阵计数重构，不声称新颖性或外部论文认证。

# 3. 任意汇点 private-group price/MW 舍入

## 3.1 限定输入与输出界

输入含不交 home 集 `H`、sink 集 `Z`、宏任务 `B` 和不交私有任务组 `J_h`。每个私有任务在唯一 home 有 `a_j≥0`，可在合法 sink 子集 `E_j` 运行；宏任务只在 home 上。合同参数为 `T>0`、`rho≥1`、`delta≥0`、`tau∈[1/2,1)`、`eta∈(0,1]`，满足

\[
b_0=\rho(1-\tau+\delta)\le1.
\]

每个 home 总私有量 `W_h≤T`，单件 `a_j≤delta T`，合法 sink 时间 `p_{zj}≤rho a_j`；宏有限边大于 `T/2`，宏边大于 `T` 先剪掉。允许任意 home/sink 数和有理分母，逐件资格可不同。

算法返回 FAIL 或完整实际分配。成功时

\[
L_h\le(1+\tau)T,
\qquad
L_z\le[1+\eta+b_0]T.
\]

若 `OPT≤T`，必成功；因此 FAIL 是 `OPT>T` 的 sound 一侧证书，成功不代表精确 `T` 可行。固定 `rho,delta,eta` 且 `rho*delta+eta<1` 时取

\[
\tau=\frac{\rho(1+\delta)+\eta}{1+\rho}
\]

得到

\[
\alpha=2-\frac{1-\rho\delta-\eta}{1+\rho}<2.
\]

该比例属于限定接口，不是一般 unrelated-machines 的近二算法。

## 3.2 Price cover、共同模式与 MW

给定 price 向量 `pi`（非负且和为 1），每个 home 以

\[
D_h=(W_h-\tau T)_+
\]

为覆盖需求，只允许有 sink 端的私有任务参加。对每个 home 取 inclusion-minimal cover，保留实际覆盖量；总私有量严格小于 `D_h+delta T`。选定每件任务的合法 sink 后，模式的 sink 向量总量至多 `b_0T`。

所有 home 使用同一 price oracle，之后以二分匹配共同选择宏占位 home；不能逐 home 独立选完再修补，因为宏身份和 sink 负载耦合。单次价格查询使用覆盖 FPTAS（`epsilon=eta/4`）、真实处理时间回溯和最小成本宏匹配；若所得 sink 向量价格成本大于 `(1+epsilon)T`，则返回 FAIL。若 `OPT≤T`，最优调度删冗余后给出共同 home/macro 见证，故不会触发该 FAIL。

接着用 multiplicative weights，轮数

\[
N=\left\lceil\frac{16RK}{\eta^2}\right\rceil,
\qquad R\le\max(1,|H|),
\]

重复价格查询，保留全部真实整数方案并按频率平均，得到模式扩张基的显式分数点；再调用单侧基舍入，把每个 sink 增量限制在 `b_0T`。所有模式和 MW 输出都从真实任务回溯产生，没有把指数 Pareto 菜单或精确 LP oracle 当作免费输入。

复杂度关于总输入位长和 `1/eta` 多项式；不声称关于 `log(1/eta)` 多项式。`T=0`、无 sink、空组、零时间、大分母等均需单列分支。

# 4. Unknown-OPT promise 版本

未知 OPT 版本用整数 makespan 网格和二分搜索调用同一阈值程序。它额外要求以真实 OPT 为尺度满足 `W_h≤OPT`、`a_j≤delta OPT`、宏有限边大于 `OPT/2`。在该 promise 内，FAIL 说明当前阈值低于 OPT，成功阈值给出 `alpha OPT` 上界；所有有限时间分母乘积给出多项式位长网格，二分查询次数多项式。

该版本取消固定 sink 数、同组共同资格和统一接收时间的包络，但保留唯一 home、私有分组、统一 `rho,delta` 和可计算宏占位结构。算法不能一般性验证 promise，也不能从任意 unrelated-machines 矩阵自动生成这些角色。知道最优调度后删边得到结构，不等于存在多项式结构提取器。因此它是条件算法，不是 `UM-TARGET-v1` 的一般近二结论。

# 7. 结论

`98694007d7ea5f775a14` 的稳健结论是：在修复空模式满秩漏洞并要求非空模式类覆盖全部 `B` 后，任意 sink private-group 接口具有可证明的单侧 `+b` upper-column 舍入；在唯一 home、私有分组、宏占位、逐件 sink 资格和 `b_0≤1` 条件下，price cover + common macro matching + MW + 单侧基舍入给出 `L_h≤(1+tau)T`、`L_z≤[1+eta+b_0]T`，并提供 `OPT≤T` 时不误拒绝的 one-sided FAIL 逻辑。

这些结果都依赖显式结构 promise、真实任务回溯和共同匹配；成功不等于精确阈值可行，关于 `eta` 的复杂度按 `1/eta` 而非其二进制长度声明。有限审计支持实现回归，不替代一般 LP backend、结构提取、近二 hardness 或 `UM-TARGET-v1`。
