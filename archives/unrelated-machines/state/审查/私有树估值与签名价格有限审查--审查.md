# 1. 对象身份与读取边界

本审查实际读取两个冻结 JSON 的完整字段，并回读其对应正文、审查稿和相关 unrelated-machines 证明。第一源 `cc688171bbc058292c05` 是分叉树 `q` 估值、XOS 包络、单状态 minorant LP 的有限实现审计；第二源 `19d6dbe5fca0f2c533e4` 是私有 sink 边际模型的完整 assignment 与概率分布审计。两个来源都在 legacy-cleanup commit `68fad804ec5946cb296f77dc5b336308a66abf12` 和 main commit `aefc58eac3fc6eb5d7a47d087dd2c62b5aa9974c` 具有同路径版本。

本批不是把两个对象合成一个新定理：树审计检查显式树估值器和支持多面体数据；sink 审计检查另一族私有可用机器、最优值、行/汇点计数和负相关概率。已有《分叉树估值与单状态支持多面体》承担一般定义及证明；已有《长链联合投影与最优凸包边际障碍有限审查》承担固定最优凸包点的普遍行/计数障碍。本文件只保存有限运行的覆盖、反例标签和边界。

真值等级为“有限精确实现和边际边界证据”，不升级为 generic LP 求解器、通用 rounding、全局调度算法或复杂度结论。

* `UM-TREE-Q-XOS-ENVELOPE-v1`；

这些计数的数学用途是验证实现中的值、需求、单状态分离和约束数据相互一致。它们不能替代正文中的树递推、补树对偶、minorant 投影证明，也不能把 `8` 个 compact LP certificate 写成已经运行 generic LP optimizer。

## 2.1 签名价格证书

JSON 保留四个 shared-state signed-price 实例。价格向量分别包括：全零价格；六个 `2` 加一个 `-1/3`；

\[
(-2/3,\,1/3,\,0,\,4/3,\,-1/3,\,1,\,-2/3);
\]

以及六个极小正价与一个相反符号的极小负价，分母为脚本给出的超大整数。它们覆盖了三类容易误读的情况：全零基线、负资源信用、混合正负价格和近零的符号边界。

来源的 `actual_subset_and_blocker_certificates` 还标记：

* `unary-deep-negative-unused-resource`：深 unary 树上存在负价但未使用资源的边界；负价资源必须进入需求集合的目标计算，却不自动成为所选子树叶。
* `non-XOS-three-ary-height-two`：一个三叉、深度二的 exact non-XOS certificate。它只说明该具体 `q` 不应被未经定义的单一 additive vector 误代，不能推出所有树估值都非 XOS，亦不能删除正文中“XOS-envelope”作为逐点包络的限定。
* `compact-LP-data-and-feasible-uniform-support`：给定支持上的紧凑约束与一个可行 uniform support；source 同时写明 `generic_LP_optimization_implemented=false`、`solver_used=null`，故不能写成已完成通用 LP 最优化。

这些证书的独有信息是“实现确实处理了 signed prices、负资源和 non-XOS 标签”。现有定理正文保留一般 `q/f` 次可加、demand、包络和单状态强分离的证明；本文件不重复证明，也不把有限证书提升为新的结构定理。

## 2.2 可安全衔接的实现结论

在显式树、逐状态叶资源单射、有限有理价格的既定合同下，有限运行支持以下工程判断：

1. 负价格先计入目标、再对候选子树的有效价格作截断的实现，在列出的 shared-state 输入上通过全 ground subset 对照。
2. 对候选分叉子树做 minimum-cost 查询与 full-subset OPT 对照的 170/52 组没有报告误差。
3. 非法实例和非法 query 的 reject 分支确实被触发，分别为 9 和 11；这保留了输入域而非只测试合法 happy path。

上述是有限实现证据；它不证明资源重复、隐式指数树、跨状态联合 minorant 或 generic LP 优化均已解决。

# 3. 私有 sink 边际：完整 assignment 与概率核对

`19d6dbe5fca0f2c533e4` 的目标是 finite exact audit，使用 `Fraction` 加独立 scaled-integer enumeration。它重构 8 组 `(k,r)`：

\[
(1,1),(1,3),(2,2),(2,4),(3,3),(3,4),(4,4),(4,16).
\]

所有列出的完整 assignment oracle 都得到 `OPT=1`。有代表性的 count/cap 结果如下：

| `k,r` | assignments | best ceil-count caps | best row-discrepancy caps | 备注 |
|---|---:|---:|---:|---|
| 2,2 | 32 | `3/2` | `1` | sink integer cap 2 |
| 2,4 | 1,024 | `3/2` | `3/2` | sink integer cap 1 |
| 3,3 | 1,536 | `5/3` | `4/3` | sink integer cap 2 |
| 3,4 | 16,384 | `5/3` | `5/3` | sink integer cap 1 |
| 4,4 | 262,144 | `7/4` | `3/2` | sink integer cap 2 |

同一 JSON 还保留 `(1,1)` 的 2 assignments、`(1,3)` 的 24 assignments，以及两个 `(2,3)` 的不同 `(a,b)` 行参数（各 192 assignments）。这些小边界不能被删掉，因为它们显示 sink cap 与 row discrepancy cap 并不总是同一合同。

## 3.1 独立分布与 sharp-NC 边界

在 independent law 检查中，所有 job 与 B marginals 都精确，且同 sink pair negative correlation 为真。典型 expected makespan 与 universal NC lower 为：

| `k,r` | independent expected | universal NC lower | total expected sink pairs |
|---|---:|---:|---:|
| 2,2 | `3/2` | `5/4` | `1/2` |
| 2,4 | `7/4` | `11/8` | `1/4` |
| 3,3 | `5/3` | `4/3` | `1` |
| 3,4 | `7/4` | `17/12` | `3/4` |

sharp-NC laws 则给出若干恰达到 lower 的有限实例：`(2,2)` 为 `5/4`，`(2,4)` 为 `11/8`，`(3,3)` 为 `4/3`，`(3,9)` 为 `14/9`，`(4,6)` collision size 2 为 `3/2`。`(4,6)` collision size 3 的 expected 为 `19/12`，lower 仍是 `3/2`，说明 higher-order collision 的分布可以严格高于 universal pairwise lower；这不是负相关条件失效，而是 higher-order law 没有被 pair budget 唯一确定。

这些概率值来自完整有限 atom enumeration：例如 sharp `(3,9)` 有 7,452 个正原子、`(4,6)` collision size 2/3 分别有 5,760/15,840 个正原子。它们是对具体私有 sink law 的精确核对，不是对任意 k、r 分布的极限定理。

## 3.2 符号族检查与边界解释

来源还检查了 `(k,r)=(2,4),(3,9),(4,16),(8,64),(16,256),(32,1024),(64,4096),(128,16384)` 的公式逆向。`row_cap_lower` 依次包含 `3/2,5/3,7/4,15/8,31/16,63/32,127/64,255/128`；“quarter improvement requires sink jobs” 从 1 增至 32。该段是 symbolic parameter check，不是对每个大参数做完整 assignment 枚举。

因此可写出的接续是：sink job 数量、row discrepancy 和 pair budget 各自控制不同的有限边界；要把它们合成 rounding theorem，仍须给出任意 `(k,r)` 的联合耦合和全局可行性证明。

# 4. 与既有正文及其他来源的比较

## 4.1 与分叉树一般定理

《分叉树估值与单状态支持多面体--定理》已经给出显式满树 `q_T` 的次可加、有限状态最大值、signed-demand 算法、单状态 XOS envelope 和 `O(k|V|)` 扩展 LP。树审计应被引用来证明实现覆盖了负价、reject 分支和非 XOS 边界；不能反向用 901 个树证书替代一般证明，或把单状态 minorant LP 延伸为多状态 `max_a q_a` 的 generic LP。

## 4.2 与长链/最优凸包边际审查

《长链联合投影与最优凸包边际障碍有限审查》处理固定真实最优调度凸包点的逐行/计数合同和长链配置间隙；本 sink audit 的 `(k,r)` 完整 assignment 与 independent/sharp-NC laws 是另一族私有 sink 概率对象。二者都显示“局部边际或 pairwise law 通过”不足以自动给出全局调度，但不共享相同的机器图、任务端点或 ratio，不能合并表格里的 makespan。

## 4.3 与私有 graft/复制审计

私有 graft 的 exact `min` 恒等式和完整池整数化只关乎需求 DAG 组合、三维匹配复制；树估值的资源价格和 sink law 不应被导入为同一对象。它们可以在第三阶段作为不同证据：graft/复制阻止某些放大路线，树审计检查 signed-price 实现，sink 审计保留边际合同的有限障碍。
