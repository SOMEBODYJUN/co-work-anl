# 2. 对称条件矩聚合与固定推前阈值

## 2.1 对象和对称列合同

稳定身份为 `UM-SYMMETRIC-JOB-AGGREGATION-v1` 与 `UM-SINGLE-MACHINE-MOMENT-RESET-THRESHOLD-v1`。每个任务 `j` 有非空选择集 `E(j)`，选择互不相交。给定非空有界有理多面体 `P`，对一阶 `x` 和对称二阶 `Y` 要求
\[
x\in P,\quad Y_{ee}=x_e,\quad Y_{:e}\in x_eP,\quad x-Y_{:e}\in(1-x_e)P.
\]
这是同一个矩阵锥的对称列合同；边际 0 或 1 用齐次式处理，不能偷偷除以零。删去任务/选择后用确定矩阵 `R` 聚合到 `x'=Rx,Y'=RYR^T`。若每个保留任务的每个旧选择都满足 `RY_:e in x_e P'`，则聚合后的真列和补列满足新合同；关键恒等式是每个任务的全列和 `sum_{e in E(j)}Y_:e=x`。这给出了检查一个给定 `R,x,Y,P'` 的多项式条件，却没有寻找 R 的算法。

准确的重置义务是：旧列在新坐标下仍落入残余容量多面体。旧 `N(P)` 可行不能推出这些条件；非对称 `N_0` 也不能默用全列和恒等式。该边界应在第三阶段标为“对称列合同的充分条件/固定映射检查”，不写成一般 LS 或配置算法。

## 2.2 对称均匀实例和固定推前的尖锐 2T 门槛

取 `q>=2`，`m=2q` 台机器、`n=2q^2` 项任务，每个有限端时间 `1/q`、`T=OPT=1`。真实分布 `D` 在所有每台机器恰有 q 件任务的最优调度上均匀。删去机器 i 并吸收任务包 C（大小 `c`），其余任务若旧选择 i 则按预先给定的后备 `phi(a)` 改送，否则保持旧端。指定矩推前检查所有真/假容量及前缀约束。

当 `c<2q`，存在后备机器拥有至少 q 件被映射任务；取该机上的新真 literal，条件计数超过 q，严格违反容量。因 `q<=c<2q` 时残余本来仍有 makespan 1 调度，所以失败是 `RYR^T` 规则的运输障碍，不是残余不可行。到 `c=2q`，对每种原像/机器关系逐式核查真列和假列条件，`f_k<=q` 保证全部通过；因此固定推前的最小吸收包准确为 `2q`（`q=1` 退化阈值为 1）。

在 `c=q`，旧推前仍违反条件，但保持同一新一阶边际可以重新构造真实矩：将每台残余机器分成 q 个单位槽，把 `x'` 乘以 m 变成正则二分多重图，反复用 Hall/增广路分解成 m 份完美匹配。均匀取这些调度得到 `Yhat`，满足新列合同和所有条件容量，而 `Yhat != RYR^T`。结论是“固定联合矩推前的阈值”，不是“给定边际无法实现”或“重置后调度变差”。

## 2.3 随机均匀运输的另一个锐阈值

正文另立 `UM-INDEPENDENT-UNIFORM-MOMENT-RESET-v1`：每个保留任务若旧在删机 i，则独立均匀送往其余 `K=2q-1` 台，旧非 i 选择保持。新边际为 `1/K`；不同任务同机/异机二阶由显式 `beta,gamma` 公式给出，同任务对角必须加入 `diag(R_j x_j)-R_j diag(x_j)R_j^T` 修正，不能把整个矩简单写成 `RYR^T`。

令剩余任务数 `r=n-c`。真列/假列的最大条件计数由 `A=1+(r-1)beta` 控制；逐式得到 `c=q+1` 仍失败，`c=q+2` 及以后通过，且该阈值对整数 `q>=2` 精确。这里随机变量只定义矩，不能当作实际调度算法：某些随机 realization 仍会使一台机器负载 2。`q=1` 是单独的退化端。该正面运输说明固定后备的 `2q` 门槛不能泛化到所有可计算运输，但仍没有一般输入的余量或舍入算法。

## 2.4 证据层级和开放义务

主程序与独立程序均使用 `Fraction`、整数匹配和确定性枚举；审计覆盖 `q=2..64` 的参数公式、`q=2` 的 2520 个平衡调度、代表性矩阵真/假容量、`q=2,3` 的同边际重耦合，以及随机运输的条件矩。有限输出只回归这些显式公式和实现边界；一般阈值来自计数推导，不能把审计规模当作任意 q 的证明。

保留的反例和限制包括：没有证明 `Rx` 不在残余多面体，当前族反而展示 `c=q` 的可修复边际；没有证明迭代重置、非均匀 UM 输入、通用 SDP/LS 层级或近二算法的失败。后续真正义务是一般输入中的可计算联合迁移，既满足所有真/假条件容量，又给统一的低于 2 输出；源本身没有提供它。

# 3. 双见证查询分离、费用平均和 3/2 锐界

## 3.1 v2 的一般域和不交染色

稳定身份为 `UM-TWO-WITNESS-QUERY-SEPARATION-v2`。输入是任意显式合法 UM 矩阵、同一矩阵的两份完整分配 `sigma_0,sigma_1`（峰值均不超过 T）、差异任务集 D 和非空查询集 `Q subset D`。任务时间可以是任意非负二进制有理数或无穷；不要求 unit、home、度数或图结构。查询 `q` 的其他查询初态聚合负荷为
\[
\delta_q=\max_i\sum_{r\in Q\setminus\{q\}:\sigma_0(r)=i}p_{i,r}.
\]

确定性阈值染色把每个差异任务画成 `sigma_0(j)->sigma_1(j)` 弧，查询弧先固定自身颜色。若某机器尚未触发且某颜色的目标端流入严格大于 `T/2`，就把该机器标为该颜色，并把从它出发的全部非查询弧染成该颜色；一台机器至多触发一次，各非查询弧至多着一种颜色。设 `A_q` 为 q 色非查询弧，输出 `tau_q` 恰把 `{q} union A_q` 切到 sigma1 端，其他任务留 sigma0 端，则
\[
C_{max}(tau_q)\le\max\{3T/2,T+\delta_q\}.
\]
给 D\Q 任意非负权 `w`，所有支持不交，故总改派费不超过 `W=sum w`，至少一查询费不超过 `W/|Q|`。T=0、零时间任务和无穷不可用边均有明确处理；输出规模和有理运算是总位多项式。

证明分两类机器：未标该颜色的机器流入不超过 T/2，加原 σ0 负载至多 3T/2；被标机器的非查询迁出全部随颜色移动，sigma1 负载至多 T，再加同机其他查询的旧负荷至多 delta_q，得到 T+delta_q。费用只是相对 sigma0 的指定改派费，不等于扣退款后的净费用或任意物理收费。

## 3.2 锐例和费用边界

六机五任务例在 `T=1` 下有两个查询各从小端移到 unit 端，共享一个中间资源任务和一个最终 unit 任务。任一单查询若要求峰值严格低于任意 `B<3/2`，都必须改派同一个非查询任务，故可取该任务权为 1，使两个查询的支持都收费 1。两份输入见证峰值严格不超过 1，查询初态质量可任意小；因此 3/2 是全域上界的 sharp supremum。该例 `OPT<=1`，不是近二 gap 或 NP 困难性。

## 3.3 v3 计数、共享任务收费和限制

正文在同一染色族上另立 `UM-TWO-WITNESS-QUERY-COUNT-FEE-v3`：给定 `beta in [3/2,2)`，设 `c=beta-1`、`R_beta` 为查询初态总负荷严格大于 cT 的机器数，则至少 `d-R_beta` 个查询实际峰值不超过 beta T；其中一个费用至多 `W/(d-R_beta)`。若每 query 的初态端时间小于 `eta T` 且 `eta<c`，可得到严格比例和至少一半的合格查询界，`s=floor(c/eta)+1` 时有 `d-floor(d/s)` 的整数下界。v3 特别保留了 eta=0 只能给全部 d 个合格 query 的修正，不能写成严格超过 d。

多见证源另立 `UM-MULTIWITNESS-SHARED-JOB-FEE-CAPACITY-v2`，给每个 query 各自 actual 但没有共同全开 actual。原任务 q_r、x_r、f 的共享资源 R 结构给出对任意非空 K 的精确式：若 `B_K=sum_{r in K} b_r`，则 `OPT_K=min{2,max{1,B_K}}`；给定峰值 `beta<2` 的最小改派费为 0/1/不可行，分别由 `c+B_K<=beta`、`B_K<=beta<c+B_K`、`B_K>beta` 决定。K=empty 单独给 1 峰和 0 费，修复旧 v1 的空集严格不等式错误。全部 `b_r=c=1` 时，单查询 strict1 可行但所有峰值 <2 的模式都必须移动同一 f，故 p 个查询的费用不能由一个非查询费用池无重复支付；而峰值达到 2 时全部模式可 fee0。

这些 v3/多见证结果只适用于同一固定 P、指定 query owner 和明确费用对象。没有共同 strict actual 时，不能套用 v2 的两见证输入；也没有源 decoder、未知 YES 见证寻找、全局近二结论。

# 4. 两源比较、先有对象和第三阶段用途

- 对称重置源研究的是共同矩的运输，失败可由固定 `RYR^T` 造成，且同一边际允许 Hall 重耦合；双见证源从两份真实调度直接构造实际 query 分离，输出的是支持不交的 actual。一个是矩合同边界，一个是实际见证下的收费/峰值定理。
- 与《强配置矩与对称重置阈值有限审查》相比，本页把当前 `afd52` canonical 的随机运输、`c=q` 重耦合和对角修正写清，并区分旧固定阶强矩对象；不把两个 source ID 的有限证据重复计数。
- 与《匿名令牌非扩展与双见证查询分离三源审查》相比，当前 `11cd` 增加 v3 的 query 计数、近单位读数条件和多见证共享任务容量；其 v2 阈值染色与既有三 case 审计相同，当前版本新增的量词/空集修复保留在本页。
- 与《共居查询SAT与单home级联查询分离双源审查》相比，v2 不要求唯一正小端、单 parent 或 home 结构，允许任意端时间；单 home 的更强同一组子集构造不能替代一般染色。反向地，v2 的费用平均不能修复共居 SAT 桥丢失 occurrence 身份的问题。

第三阶段可记录三条带前提的边：

1. `对称共同矩 -> 固定推前残余容量检查 -> 小包失败/2T阈值`，并有 `同一边际重新耦合 -> T级修复` 的旁路；
2. `两份实际见证 -> 阈值染色 -> 不交查询支持与费用平均`；
3. `多见证共享任务 -> B_K容量公式 -> 峰值2收费阈值`。

边的标签必须写出“固定运输/实际见证/是否共同全开 actual/费用定义”，不能从旧图摘要导入成一般近二关系。
