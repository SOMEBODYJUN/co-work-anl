# 读取范围和数学身份

本审查逐字读取两份 `research/current/unrelated_machines` 正文及其关联审计/审查链接，并比较冻结版本的量词和增量边界。稳定 ID 为 `35a2d39e7186f10d2c1d`，文件 SHA `ff8d35a5c019fa6c5faaa26fa9848727490ade77141fcff4275273877f1064a1`；以及 `8ce8667e13d3c4d60937`，文件 SHA `a9c99e79cc528a0a278a812708d410852c5c022a170bfe3ba5f5a5941c5a29d7`。两份均有 legacy-cleanup/main 绑定，视为同一冻结路径版本。

两源承担不同数学对象。第一源是配置 LP 与有限 permutation cover 的精确等价及其对反向困难性路线的坍缩障碍；第二源构造只保持任务等式/保护负载的零空间枢轴死锁，并进一步构造双副本双符号和单环 circuit 的完整 CONFIG 双坏端点。二者都写明 `UM-TARGET-v1` 仍开放，不能合并为“调度不可近似”或“所有方向算法失败”。

## 1. 有限置换 cover 与配置阈值的精确关系

对任意合法一般不相关机实例 (P)，固定 (q\ge1)。每条有限 incidence 边 (i\!\leftrightarrow j) 由置换 (pi_{ij}:[q]\to[q]) 接到机器 copy ((i,b)) 与任务 copy ((j,a))。在不增加其它边或资源的合同内，正文证明：

1. 任意 q-cover 的 makespan-(T) 调度去标签并按 q 平均，给出原实例的 (T)-配置可行解；
2. 任意 cover 的配置阈值 (T_{CONF}(Q)) 等于 (T_{CONF}(P))；
3. 原实例真实调度可逐 copy 提升到每个 cover，且每台 machine copy 负载保持原机负载；
4. 原实例的有理配置证书（共同分母 q）可按每个 machine type 的配置计数，给出某个 q-cover 的真实 makespan-(T) 调度；
5. 因而 (min_Q OPT(Q)=T_{CONF}(P))，但这个 min 不是位多项式算法。

证明 4 的关键是：配置覆盖等式保证每个 job-copy 被恰好 q 个 machine-copy 位置覆盖；在每条 incidence 上把这些位置编号成任务标签，再把 partial bijection 补成置换。配置 LP 的基本可行解分母可由 0/1 基矩阵的 Cramer/Hadamard 界控制，(log q) 可能多项式，但显式 cover 的机器/任务数与 q 成正比，不能把它称为多项式规模归约。

正文还给出高围长 cover 的自足群作用构造：有限基图每条边配不同生成元，取长度不超过 g 的 reduced words 构造部分置换并补全，再以有限生成置换群右作用形成 cover，消除长度不超过 g 的简单环。这个结论是“存在高围长 cover”，不是随机 cover 或可高效生成的概率陈述。它说明纯 cover 选择不能自动保持整数 soundness；相同 seed 和相同 q 的恒等 cover 与适当置换 cover 可以有不同真实 OPT，后者可恰降到配置阈值。

对反向困难性路线的准确含义是：不能从局部配置 gap、纯复制、或高围长本身推出所有 cover 的近二真实 gap。仍可研究选定接线族，但必须单独证明低负载调度解码到源问题、YES/NO 接线选择及总位复杂度。源文同时保留 q=6 的显式 seed：同一 seed 的某 cover 有 (OPT=T_{CONF}=4/3)，恒等 cover 仍为 (5/3)，故“任意接线都保留 gap”和“任意接线都实现配置 LP”都错误。

## 2. 永久消元的零缺陷死锁

第二源固定 (epsilon\in(0,1))、(m>1/epsilon)、(T=1)、(q=1-1/m)、(eta=(1-epsilon)/4)，构造 (2m) 台机器与 (2m+1) 个任务：锚任务 (B)，每组 (A_i,F_i)，其中 (B) 在 (H_i) 上用时 1，(A_i) 在 (H_i/Z_i) 上用时 (q/\beta)，(F_i) 在 (H_i/Z_i) 上用时 (1/m/\beta)。显式平均 (m) 个 makespan-1 最优调度得到 (OPT=1) 的真实最优凸包点。

按 excess 规则先永久删除所有 (Z_i) 行；每次处理一组的合法最大零空间方向为
\[
d_{H_i,A_i}=1, d_{Z_i,A_i}=-1, d_{H_i,F_i}=-(m-1), d_{Z_i,F_i}=m-1,
\]
步长恰为 (1/m)，把 (A_i) 固定到 (H_i)、(F_i) 固定到 (Z_i)，并保持全部 core 保护行。处理 (t) 组后，活变量、任务、保护行数为 (N_t=m+4a)、(J_t=2a+1)、(P_t=m)（(a=m-t)），零空间维数为 (2a-1)；当 (a=0) 时 core 行对锚变量组成单位矩阵，确实 full rank、没有非零方向，而不是仅靠计数猜测。所有补全的 makespan 恰 (2-1/m>2-epsilon)，且总亏缺 (D=0)。

这个反例只攻击“保持任务等式和保护负载、按 excess 永久删行、任意合法零空间方向走到边界”的合同。它不攻击全过程保持 big-count/CONFIG 不等式的增强规则：初态在 (x_{H_i,B}+x_{H_i,A_i}\le1) 上取等，所选方向会立即违反；因此完整 CONFIG 条件确实可以阻断这条历史，是否足够仍开放。

## 3. 双副本双符号与单环 circuit

同一源进一步取两个互不相交副本，分别沿相反方向变化参数 (lambda_A=1/2+	heta,lambda_B=1/2-	heta)。整条 (	heta\in[-1/2,1/2]) 线保持完整 CONFIG(1) 和保护负载，两个最大符号端点都达到 `max{1,OPT(P+)}`；若 (OPT(P+)>2-epsilon)，两端同时失去次二补全。该方向是直和方向，不是 support-minimal circuit，故只否定“任意方向试两符号”的充分合同。

更强的单环构造取奇数 (D\ge3)、(L=D+2)、(N=DL)，使用两个复制标签、selector rails、port tasks、(H_t/E_t) blocker 和停车端，建立 (4N) 个列/行组成的简单交替环。初态由 N 个旋转原子均匀平均，真实 (OPT=1)；环方向是支撑极小 circuit，最大箱段为 ([-gamma,gamma])，其中 (gamma=(L-1)/(2L))。整条箱段保持完整 CONFIG(1) 证书，所有机器行 excess 均大于 (1-epsilon)（取奇 (D>1/epsilon)），但两个端点的完整正支撑实例最优值都精确为 (2-1/D>2-epsilon)。

该结论把障碍精确化为：即使方向支撑极小且 CONFIG 沿整条路径保持，两个最大符号端点也可能同时坏；因此候选算法必须控制方向、保留共同真实原子或允许恢复已删端。构造本身有显式最优原子，属于结构反例而非新的难实例族，也不否定所有 circuit、所有方向规则或任何特定恢复策略。

## 与既有对象的比较和接续

1. **配置/cover 与后续选择器：** 第一源说明局部 LP gap 与复制接线不保持整数 soundness；三主机/weighted-fanout 选择器则说明给定两份 YES witness 仍有有限逃逸上界。二者共同要求后续反向归约写清接线族和完整解码。
2. **零缺陷与 upper-column/matroid 舍入：** 第二源的死锁依赖永久删除和不维护 CONFIG 行；upper-column (+B) 证书的非负列总量与 parallel-copy 约束是另一合同，不能互相替代。
3. **冻结与增量：** 单环、双副本和高围长 cover 的数量/位复杂度边界均保留；旧图或摘要不作为完成依据，审查只把两份当前正文的明确公式、证明与审计入口接入存档。

**保留的完整/条件结论：** 有限 cover 与配置阈值的等价关系、适当 cover 可坍缩整数 OPT、零空间 excess 历史的 full-rank 零缺陷终点、双副本双坏符号端点和单环 circuit 双坏端点。

**未解项：** 选定接线族的全局 soundness、任意方向以外的算法规则、配置/大计数不等式的多项式维护、恢复删端策略、源相关解码、一般 UM hardness/算法不存在性、外审和新颖性仍未完成。不能把这两源写成 `UM-TARGET-v1` 已解决。
