# 两个合同的完整数学区别

共同ordinary输入：有限主点U，每u有非空显式labels，所有state支持$C_{u,a}$有相同D≥1个不同资源；每state独立parent及D枚port，private时间1/D、相应资源时间1。**每u一枚selector**可选其全部parents。mandatory unit aux只在资源机有非空资格，全部未选state ports保留，无其它jobs。结构已给出，不提供任意UM的识别器。

给资源matroid M，真实保留值β*是每u选一个label、取不交$S_u\subseteq C_{u,a}$且union独立时的最大minimum $|S_u|/D$。先建variants p=(u,a)，$f(X)=r_M(\bigcup_{p\in X}C_p)$为整数单调次模函数。整数counts满足全部$x(X)\le f(X)$当且仅当可找真实不交、union M-independent的$I_p$且$|I_p|=x_p$：Rado复制的任意partial copies子集不比所触完整players的不等式更强；eligible-pairs parallel extension与player partition matroid intersection恢复实际资源，不只返回rank值。

用价值1的polymatroid资源P_f，加每u恰$|L_u|-1$个价值D的rank1大资源，得到restricted two-value resource-polymatroid Santa Claus。其真实值恰Dβ*：正向其余variants各给一个大资源；反向大资源比variants少一个，至少一variant没大资源，需用cheap满足SC最低值，从每u取这样的variant、丢其它cheap，独立性保持。即使多个大资源给同一variant，也仍有至少一个没拿到。价值只依resource为1与D两值，不依player；不是直接把global item matroid当另一源模型。

源review记录实际读BLMRS v1 Definition7/Theorem4后，导入固定η>0的(4+η)算法，得β_alg≥β*/(4+η)。这里是外定理的准确应用，不重新认证该外部local-search全文或全球新颖性。

aux可在峰1匹配时，vacancy matroid为transversal N的对偶，$S\in N^*$恰为aux可全匹配到R\S；rank由matching计算。全部原jobs双向给$\mathrm{OPT}=2-\beta^*$：选择保留集合导出ports、aux在余资源停车，selected parent负载$2-|S_u|/D$、未选为1、外机≤1；反向C<2时unit aux/ports不能同机，selector所在label的真实外送集合自动vacancy-independent。β0由全private基线及反向含2端点。故输出峰≤$2-\beta^*/(4+\eta)$，比值随β从0到1递增，最大$2-1/(4+\eta)$。不从β_LP=1保证常数保留。

aux自身最优unit瓶颈B≥2时用b-matching精确求B，全部ports留parent给峰max(B,2)=B=OPT。U空仅调度aux；全空峰0/dummy。D1、单label组（无大资源）均合法。D/labels/ports显式、rank≤资源数、固定η、后处理总位多项式；不同D_u若按player归一化cheap value便失去restricted两值前提，不能免费套用。

# m=D+1配置间隙及完整调度

对D≥3取m=D+1，各state$C_{u,a}=\{g_{u,a,j}:j\in[D]\}$，aux $L_{u,a,j}$仅可去自己的g、私有$A_{u,a}$或全局$B_j$。N为该mandatory邻接的transversal matroid，M=N*。删单C可把其D个L送不同B（代码可混一个A），其余停自己的g，因此每完整C独立。固定j同时删所有$g_{u,a,j}$，对应L各去不同A；均匀混D份独立集给真实边际$y_g=1/D$，不是总rank估计。

任意每u选一state并各保≥2项时，受影响aux至少2m件，只能去m个所选A与D个B，邻域≤m+D=2D+1<2D+2=2m，Hall矛盾。每u保一g、其L去A可达，故β*=1/D。配置LP每parent给单selector配置1/D、全D ports配置1−1/D；每g给单port1/D、单L1−1/D；每A的D种单L各1/D；每B空配置1。全部行和/覆盖恰1，Tconf1；unit selector又排T<1。

实际把selector放固定label、外送一port、其L去A，其余所有ports留各parent、L停g，峰$2-1/D$。任何更低C迫每个selected parent至少外送2ports，相应unit L不能再停这些g，又触发同一2m>m+D矛盾，故真实OPT恰$2-1/D$。这是解析全称下界，不是有限枚举所得。本族没有β*=1的integer YES，因此不反驳相对真实OPT算法；将所有三元aux资格强归同一纯右列block会改变完备性，不能偷接hardness。
