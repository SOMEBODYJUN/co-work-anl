# 实读和复跑

四项 source 均 clean show 导出并逐行读取。vector_moment_greedy_independent 用其显式 Fraction 输入完成正交基、Gram projection 和严格 winner；weighted_excess_zero_defect_trap 输出 8 个 epsilon/m cases 的全 Fraction checks；weighted_fanout_profile_independent 内联 helper 并完成 400 random weighted instances、32975 full assignments、6722 local K-budget checks、8376 actual constructions、140 weighted-star equalities 和 192 simplified-tree instances。upper_column_budget_base_audit 依赖 occupation_vertex_audit_core.py，当前 batch 未带 helper，未伪造输出。

# 各对象边界

upper-column 程序枚举 lambda vertices、integer choices、rank-set tight chains、copy-face matching 和 final row loads，验证空零占用、occupied copies、sum(1-x) 预算与 actual C+B 上界；这是指数 audit，不是 production polynomial LP backend。

vector-moment 程序直接在真实有限调度样本函数空间做 Fraction Gram-Schmidt，逐任务乘 literal、正交投影并按固定顺序选严格最大分数。它只证明 supplied finite distribution/order 的碰撞贪心，不能推出一般上界。

weighted-excess 程序构造 compact true-optimal-hull pivot trap，逐项验证 OPT=1 witness、protected loads、terminal makespan 2-1/m 和 maximal pivots；它保留 legal history 反例机制，不涉及 CONFIG/big-count inequalities。

weighted-fanout 程序把 weighted profile construction、all-blocked-mask oracle、q-color/two-color tests 和简化 root tree checks 分开。exact outputs 保留 400 random、32975 assignments、6722 budget checks、8376 constructions、140 equalities 和 192 tree instances；它明确不求 unknown YES witness、不做 global hardness 或 novelty certification。

# 处置

四源均处置为 integrated。代码与本轮 JSON 保存到 batch10 evidence，upper-column 的 helper 缺失如实记录。所有结果限于容量/矩/扇出合同，不升级为一般 unrelated-machines approximation、NP-hardness、外部新颖性或 customer-attraction/SPE 结论。
