# 阅读范围与对象身份

本页是 Boss8 对五份冻结来源的逐份 `clean show` 全文阅读记录。它不把历史作者 Proof、canonical review 或有限程序的旧阅读时序改写成新的盲审；每份来源的独有内容与去向均列在末表。数学对象是：整数处理时间矩阵在容量 K 下的共享负载直方图弱递推 \(\widehat H_j\)，以及它与逐机 CONFIG1 负载投影 \(P_j\) 的集合恒等式。各机只保留行直方图和跨机 job-cover 等式，不保留一份共同的完整调度 law。

# Exact-first 的完整合同

独立 Exact-first 记录先把一层递推消去为 selected-mass 合同。给上一层行直方图 \(y_{r,s}\)，选入当前 job 的质量 \(x_r(s)\) 满足
\[
0\le x_r(s)\le y_{r,s},\qquad x_r(s)=0\text{ 若端不可用或 }s+a_{rj}>K,
\qquad\sum_{r,s}x_r(s)=1.
\]
更新为 \(y'_{r,s}=y_{r,s}-x_r(s)+x_r(s-a_{rj})\)（不可用行不平移）。从该合同可逐行构造各分支 \(z^i\)：own 行取 \(x_r\)，其余行按残余质量分摊；当 \(x_r\) 的行总量为 1 时逐坐标必有 \(x_r=y_r\)，其它分支质量为零，故没有除零。反向从任一 CONFIG witness 删除当前 job 得旧 witness，再按当前 job 的 inclusion/非 inclusion 分解得到 \(x\)。这保留所有旧 jobs 的覆盖量词，处理空前缀、无资格端、零时间、\(\infty\)、\(K=0\) 与 \(theta=0,1\)。

由每机层状 subset-sum DAG 的带标签路径分解，弱递推与 CONFIG 投影逐前缀相等：\(\widehat H_j=P_j\)。selected/skip 在零时间时仍是两条不同弧，不能合并；跨机 add 流和为一只是 side equality，故 LP 不是可由网络 TU 推出整数共同调度的纯流多面体。\(K\) 二进制给出时节点数按数值 \(K+1\) 展开，只有伪多项式规模。下舍入只给可靠方向：真实 \(C_{\max}\le T\) 调度产生 CONFIG，因而 LP 不可行蕴含 \(\operatorname{OPT}>T\)；LP 可行不解码真实容量 K 的共同 schedule。

# v1 作者 Proof、勘误与四机反例

作者 v1 read-after 逐项核对了 CONFIG→weak 的 \(v^+,v^-\) 构造、\(x_r=1\) 的分段、不可用端与零时间标签。它同时确认原稿把 aggregate 写成真共同 hull 的字面有实质错误：四机六 job 例中前四 job 的真实 \(H_4\) 只有两个匹配状态 \(D=(b,b,a,a)\) 与 \(O=(a,a,b,b)\) 的凸包。加入辅助 job A 后，真实 \(H_5\) 的机器 3、4 仍恒为 b；辅助 job B 在真实 \(H_5\) 的两个 own face 均为空，但 CONFIG_6 仍可行。因此递推必须写 aggregate\(\in\widehat H_{j-1}\)，不能写成每层都在真实 H。

取 \(a=2/3,b=1,d=1/3\)，四机矩阵的六件原 job（含 A、B）有 CONFIG 阈值 1，而任一真实完整调度的峰至少 \(4/3\)，取 D 并把 A 放机 1、B 放机 3 达到负载 \((4/3,1,1,2/3)\)。弱递推先经 A 产生机 3、4 的混合直方图，再经 B 到达各行 load-1 Dirac；该 Dirac 只代表行边际，不能称为共同实际调度。乘 3 后是整数容量 \(K=3\)、端时间 1、2、3、实际 OPT=4 的同一例，不能把分数 load 直接当整数坐标。

v1 的计算合同另有两个必须保留的边界：若显式输出末层 \(y_{r,s}\)，j=0 仍需 \(m(K+1)\) 坐标，安全界为 \(O(m(j+1)(K+1)+|E_{[j]}|(K+1))\)；任意有理目标的编码长度应计入输入。v2 专用 Proof 已修正这两点并继续明确 K=0、n=0、T=0 与 \(\delta\) 依赖。v1 勘误明确这不是排版差异，而是旧 full Proof 的过强字面被撤回。
