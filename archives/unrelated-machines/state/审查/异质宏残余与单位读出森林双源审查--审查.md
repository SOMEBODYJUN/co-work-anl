# 2. 异质宏/tiny：在明确承诺域内的 3/2+delta 候选

## 2.1 精确域和算法

给定互不相交 home 集合 H、sink 集合 Z、宏任务 B 和 tiny 任务 S，`|B|=|H|`。宏任务只在 H 上可用，处理时间满足 `T/2 < p_hb <= T`；tiny 端任意但不超过 `delta T`，其中固定 `0<=delta<1/2`。给定有理 T，且真实 `OPT<=T`。

算法先在宏二分图中找覆盖全部宏任务的任意匹配 M；再对 tiny 任务解 LST 可行性 LP，home 容量设为 `T/2`、sink 容量为 `T`，保留全部 tiny 有限边；LP 可行后做有序单位槽舍入，并将 M 的宏任务放回 home。若承诺成立，输出完整 schedule 且
\[
C_{max}\le(3/2+\delta)T.
\]

证明的关键量词来自一份真实 `OPT<=T` 调度 `sigma*`：每个 home 至多承载一个大于 T/2 的宏，且 `|B|=|H|` 强迫宏给出完美匹配；home 的 tiny 残余小于 T/2，sink tiny 残余不超过 T，故 LP 有整数可行点。ST 舍入只增加至多 `delta T`，home 加回宏后至多 `T+(T/2+delta T)`，sink 至多 `(1+delta)T`。

这是一条结构域内一般证明，若宏数少于 home 数、宏可去 sink、或存在大 tiny 边，home `T/2` 容量不再由 `OPT<=T` 保证；这些情况不能被程序“自动覆盖”。

## 2.2 未知 OPT 的承诺搜索和强 NP 完全边界

若在真实 `OPT>0` 处承诺所有宏边大于 `OPT/2`、tiny 边不超过 `delta OPT`，定义 `F(t)` 为宏边保留 `p<=t` 后有完美匹配且 tiny LP 在 home `t/2`、sink `t` 容量可行。测试阶段不检查 `p>t/2`，也不删除 `p>delta t` 的 tiny 边；这些只在 `t=OPT` 使用。`F` 单调，按有限处理时间分母构造有理网格后可二分最小接受点。接受点可能低于真实整数 OPT，因此只能推出 `C<=3t*/2+delta OPT`，不能把 `t*` 称为 OPT。

候选的必要性边界是异质 tiny 成本：以强 3-PARTITION 构造 home 被宏完全占满、sink 需填 `T-B` 的实例，tiny LP 可把 item 分数均匀分给 sink，但 makespan-T 整数调度等价于三元组分箱。因此不能把 LP 可行当成精确整数 `T` 可行；ST 的加性余量是候选的真实保证。候选状态仍为“声明范围证明完成、一般分层和共同容量未闭合”。

# 3. 单位读出双树：精确必选森林合同

## 3.1 定义域与 iff

稳定身份 `UM-UNIT-READOUT-PRUNED-FOREST-IDENTITY-v1`。每变量有两棵私有完整 k 叉深 h 树；selector 只能在两根之一耗时 1；内部边任务在父端 `1/k`、子端 1；末层 port 在父端 `1/k`，或在其 clause 的任意 unit slot 上耗时 1。每个 clause 有整数容量 A_c，仅接自己的 ports；变量间内部机器不共享。给 `C in [1,2)`，令
\[
r=\lceil k(2-C)\rceil.
\]

“必选 r 配额森林”对每个变量恰选一个符号根，沿选中树的每个 active 节点恰选 r 个孩子，末层选 r 个 leaf ports，并给所有选中 ports 一个每 clause 不超过 A_c 的注入。正文证明：存在完整实际调度峰值不超过 C，当且仅当存在该森林及注入。

从调度到森林：C<2 时 active 节点已有 unit incoming，父端最多留下 `floor(k(C-1))` 个 `1/k` 小边，至少下传 r 个；只保留已实际下传的 r 条边，其他分支全部正规化回父端。active 负载恰为 `1+(k-r)/k<=C`，inactive 机器负载为 1，保留的原 slot 注入仍是合法不交集合。反向给森林时，非森林分支回父端，active 节点按 r 条下传，得到完整 schedule，所有原 jobs 恰一次。

这条 iff 的关键是所有变量 selector mandatory、所有树私有、slot 无其他 preload；不能改成“只取某一全局根可达分量”或用配置 LP 代替真实注入。k=1、h=1、C=1、A_c=0、空变量和二进制容量均在正文边界中处理。

## 3.2 半密度 universal 3/2 与叶命中门槛

若每个 clause 的实际 port arity `d_c<=2A_c`，同一模型对任意深度、任意 wiring 都有确定性完整调度，内部机器负载至多
\[
1+\lfloor k/2\rfloor/k\le3/2,
\]
unit slot 至多 1。每个原 job 先分成两个 half-slots：selector 两根、内部边父子、port 父端与一个合法 unit；clause ports 两两配对，每对占一个 unit slot。Hall 匹配一次同时覆盖所有 half-jobs，得到共同实际调度。该证明依赖“每 job 两端、每槽至多两半片”的全局 matching，而非逐机分别选最优槽。

`k=2,h=1` 的四 clause split 例给出绝对三半锐性；它只说明该结构类的 `C=3/2` 下界，不是近似比普适锐。更一般的 pruned-tree 叶命中引理：对完整 k 叉深 h 树、每节点选 r 子树，命中任意 rooted r-pruned subtree 的最小叶数为 `(k-r+1)^h`，不含任何该子树的最大叶数为 `k^h-(k-r+1)^h`。严格少于该门槛的真实叶需靠虚拟端口补齐，但虚拟叶的共同 clause 容量仍是额外条件；叶数达到门槛也不保证具体位置命中。

在 `k=4,h=3,r=2` 的开放叶模块中，容量与祖先兼容性可共同造成 `OPT=7/4`；这反驳“只按叶容量匹配即可恢复”而不反驳半密度下的 half-slot Hall 证明。平衡 source（每变量正负出现数相等）若 `arity>2A`，任意赋值的总 occurrence 数超过容量，严格 YES 为空；因此不能只改密度就声称得到有 YES 的近二归约。

# 4. 双源比较、既有结果与开放义务

异质宏候选与单位森林都把“局部可行”与“完整实际调度”分开：前者由宏匹配、tiny LP、ST 槽舍入给出有加性残差的实际 schedule；后者由一次全局 half-job Hall matching 给出所有树和 clause 的共同 schedule。二者的证明不能交叉替换：异质 tiny 的 3-PARTITION 障碍不属于 unit forest；unit forest 的 r-pruned 祖先兼容也不属于宏/tiny LP。

与同质宏 `1+delta` 候选相比，异质宏只能统一给 `3/2+delta`，差异来自宏身份与 home 残余不再可交换。与 rooted DAG degree-token、BCG M-pyramid 文稿相比，unit forest 本页承认 mandatory all-sources、unit slot 机制的既有来源；新增记录是固定 C 下的精确 r 配额 iff、半密度任意 wiring 的三半边界及叶命中门槛，不能声称这些是无条件新颖性。

第三阶段关系图可保留三条条件边：

- `宏边>T/2 + tiny<=delta T + |B|=|H| + OPT<=T` → `残余 LP + ST` → `3/2+delta 实际调度`；
- `unit private trees + mandatory selectors + d_c<=2A_c` → `half-slot Hall` → `3/2` universal bound；
- `r-pruned leaf blocker <实际叶/容量共同可容纳>` → `森林可达性`，否则只能得到 structural obstruction。

未闭义务：一般 UM 中如何识别宏/tiny 分层和匹配承诺；异质 tiny 的共同整数容量；半密度之外仍有 YES 且能排除全部低负载必选森林的源归约；虚拟叶补齐的外部容量；以及任何低于 2 的一般近似/UM-TARGET 结论。两源有限证据和内部审计只核验声明结构，不能扩大量词。
