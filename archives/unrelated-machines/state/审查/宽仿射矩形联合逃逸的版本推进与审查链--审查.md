# 完整输入与不能混淆的参数

素数 $R\ge2$ 是域大小，所有线坐标在 $\mathbb F_R$ 运算。有限变量集X可含unused变量；非空G中各组有非空distinct-variable集合 $X_g$ 及非空显式indexed-state菜单 $S_g$。记

\[
q=\max_g|X_g|,\quad d_x=|\{g:x\in X_g\}|,\quad
D=\max_xd_x,\quad M_g=\sum_{x\in X_g}(d_x-1),\quad M=\max_gM_g.
\]

这里q是最大arity，**不是域大小**；$D\ge1$、$D\le R$、$0\le M\le q(D-1)$。每个变量的各incident组给固定、互异的截距 $j_x(g)$，算法不能重编号。不同x的完整资源平面 $U_x=\{x\}\times\mathbb F_R^2$ 带tag隔离。状态s在每个x上给一条完整线，支持

\[
T_{g,s}=\bigsqcup_{x\in X_g}\{(x,z,a_{g,s}(x)z+j_x(g)):z\in\mathbb F_R\}.
\]

每个state-resource incidence给非负二进制有理权p，逐state和恰1。零权点仍是实际incidence，权可以依赖整个indexed state、截距与全部输入。重复label vector的states可以有不同权与marks，不能合并。

输入还给各 $(g,x)$ 非空显式 $A_{g,x}\subseteq\mathbb F_R$，要求完整rectangle $\prod_x A_{g,x}$ 的每个vector至少在菜单出现一次。菜单可更大，state index可重复vector；令 $L=\min|A_{g,x}|$。该rectangle自由度是承重条件，不能由均匀边际、pairwise independence或字母表很大自动推出。

# v1到v2：哪些是新结论，哪些只是同一推论

| 版本 | 精确新增或保留的合同 |
| --- | --- |
| v1 Exact | 每条state-variable line至多b个正点（b≥1）且 $L>b(D-1)$ 时，存在共同选态/分配质量1、完整实际OPT1；不加稀疏条件但D>1且 $L>2q(D-1)^2$ 时，质量至少1/2、完整实际峰至多3/2。D1另单列全领取。 |
| v2 Exact | 给二进制整数b≥0、非负有理β、逐真实state-variable的marked子集E，大小≤b且本state的所有unmarked点权≤β。在同一严格 $L>b(D-1)$ 下，选一个共同整数解保留全部selected marks及所有selected独占点，每组质量至少 $v=\max(0,1-M\beta)$，完整实际峰至多 $2-v$。 |

# 同一整数见证的证明：选state后才读其marks

作者Proof与v2独立重构的主链一致，已有正文第2.2–2.3节吸收。以下保留决定任意state-dependent权也成立的具体顺序。

1. 按任意固定group顺序处理。当前g在变量x上至多面对 $b(d_x-1)$ 个旧selected marks。旧点 $(x,z,y)$ 若z≠0，恰可能禁止一个新slope $(y-j_x(g))/z$；若z=0，它的y等于旧截距，与新截距不同，所以禁止零个。不能对z0求逆，也不能更换截距。
2. $b(d_x-1)\le b(D-1)<L$，每个显式A里还有合法slope。逐坐标选好一个完整rectangle vector后，才查菜单固定一个同vector的**真实state index**，再读取该index的p/E。无需预知将来所选state的marks；重复vector的另一state不可代换。
3. 新完整线避开所有旧marks，故全部selected marks两两不交。但新mark仍可撞旧unmarked点，完整supports不必不交；这一方向性不能省略。
4. 选完states后，记 $E_g$ 为本组marks并，$Q_g=T_g\setminus\bigcup_{h\ne g}T_h$ 为所有独占点，直接取 $B_g=E_g\cup Q_g$。这些实际子集同时不交。marked/unmarked共点归marked owner，全unmarked共点可全不领，不是两份各自分配的免费叠加。

本组没领到的点一定是自己的unmarked共享点。不同截距的同变量两条线若同slope则平行不交，否则恰交一点；跨变量tag分离，故本组的真实共享点至多 $M_g$。同一点遇多个对手可多计，只使上界更松。因此

\[
p_g(B_g)\ge1-M_g\beta\ge1-M\beta,
\quad p_g(B_g)\ge0,
\]

得到v，且为**同一组states和同一整数分配对所有g同时成立**，不是期望、局部CONFIG/FSLP或任意预先固定states的结论。新marks抢走旧unmarked的损失已包含在Mβ中。

## 完整任务与端点

普通P每indexed state一private、每真实资源一resource、每组一件selector（在本组所有private时间1），每incidence原job仅在自身private用p或资源用1，其余无穷。只外送selected B的jobs，其余全部留自己的private，包括所有未选states和零私时jobs。资源负载至多1、unselected private为1、selected private精确为

\[
1+\sum_{u\in T_g\setminus B_g}p_{g,s(g),u}
=2-p_g(B_g)\le2-v.
\]

因 $v\in[0,1]$，同一峰值上界覆盖所有机器。导出零私时job也按真实resource时间1收费，或可留private，均不漏任务。v0时仍合法峰≤2；v1时selector给OPT≥1，所以输出峰和OPT均恰1。一般 $2-v$ 是上界，不宣称处处精确最优。

半值推论标记严格p>1/K：state总权1使这些点数严格小于K，逐line≤b=K足够；只扫描真实点，不创建K个物品。$M\beta\le1/2$，因此同解质量≥1/2。稀疏推论β0保全所有正质量，zero marks在预算内也可保留。

M0在非空域等价于D1：若某出现变量degree≥2，任何使用它的组M_g≥1；反过来D1使不同组的tagged资源块分离，任取states即可全领取，不需除以D−1/M/β。unused degree0从不出现在X_g的和中。b0使marks全空仍合法，β0不求倒数；b=β=0与非空norm1输入不兼容，是空前件而非反例。R2、q1、单组和可能为空的应用参数域均已在作者和独立稿逐项处理。

# 独立稿增加的严格等号边界

原独立稿第9节给出一个解析边界，后被最终canonical第4节吸收；它不是有限实验。取R2、一变量x、两组各一个state，截距0/1、slope0/1。两条线在 $u_*=(x,1,0)$ 相交，每组只给该点权1并marked，其余完整line点权0；各A为对应singleton。于是

\[
L=1=b(D-1),\quad b=1,D=2,M=1,\beta=0.
\]

两组不能同时取得同一真实marked点，V=0。全部jobs留private给峰2；若完整峰<2，两个selector只能在各自唯一private，正incidence都必须外送，同一资源收到两件unit，矛盾，所以实际OPT=2。零私时原jobs也始终执行。

这只说明不能对所有输入把主条件的严格大于改成大于等于，不反驳严格合同，也不证明所有参数门槛都全局sharp，更不提供困难性。

# 查表、位复杂度与可复用关系

Rectangle核验只数显式菜单中落在product内的**distinct vectors**，与二进制整数 $\prod_x|A_{g,x}|$ 比较。所数对象本是product子集，等数当且仅当containment；product位长受各 $\log|A|$ 之和控制，不枚举可能比菜单还大的product。重复vector仅在此计数去重，真实state的index/p/E仍分开保留。

禁slope只扫描实际旧marks，找label只扫显式A，查state只查真实菜单，最后扫描selected supports计出现次数生成Q/B。giant binary b、极小β或大分母只影响精确binary运算，不迭代b/1/β/分母数值；z0另处置，只对非零场元素求逆。完整planes、line权表等已经显式给出或实际展开，不能偷换成compact CSP加权oracle的poly(logR)承诺。

记 $n=\sum_g|S_g|,m=R\sum_g|S_g||X_g|,u=|X|R^2,h=|G|$，则P有n+u机器、m+h任务、2m+n有限端（包括p0的private端），dense大小 $(n+u)(m+h)$。全assignment输出m+h项，全部精确有理运算及输出按显式总位长多项式。本六源和当前canonical均无软件/有限实验交付，本批未为字段新增程序或扫描；证据是解析证明、真实全读/比较和原字节校验。

关系判断：v2统一主合同通过两组具体标记法恢复v1推论；禁旧marks、rectangle查index、同解E并独占点、Mβ损失和全jobs回填是联合推导，任一步的条件不可拆走。独立边界例反驳把严格条件无条件弱化；作者读后/scope只提供内部复核证据，不是数学前提。与先前均匀权任意关系或完整sum关系任意权的半保留相比，这里依赖的是显式宽矩形自由度，不能因都用仿射线就互换其菜单假设。与同页前缀原子oracle仅共同输出调度，输入承诺完全不同。
