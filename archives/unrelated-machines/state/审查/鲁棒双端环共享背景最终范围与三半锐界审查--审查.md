# 1. Robust cycle 的输入合同和二相位分类

取正有理 `T`、`T≤B<2T`。每个 core 含 `n≥2` 台互异物理机器和 `n` 件互异原作业；作业 `j_i` 恰有两个 finite 端：home `M_i` 上时间 `a_i∈[0,T]`，successor `M_{i+1}` 上时间 `b_i∈[0,T]`。不同 core 的机器集和任务集彼此不交。context 可跨 core 关联这些已有机器及额外机器，但不能给 core 作业添加第三端。

给定完整 ordinary UM 调度 `sigma`：所有原 jobs 执行一次、所有机器同时负载≤T。对于每个 core，用 `x_i=0` 表示 `j_i` 留 home，`x_i=1` 表示去 successor。机器 `M_i` 同时收到两件 core jobs 的充要条件是 `(x_{i-1},x_i)=(1,0)`，碰撞负载为 `a_i+b_{i-1}`；其余状态至多一件，负载≤T≤B。

因此核心恒等式是

\[
\text{core 在 }B\text{ 下鲁棒}
\iff
 a_i+b_{i-1}>B\quad(\forall i).
\]

若存在碰撞和≤B，只翻转该碰撞前驱作业即可得到一个完整的非恒定 B-feasible phase；若所有碰撞和>B，Boolean 循环中不能出现 `10` 转折，非恒定循环也必同时出现 `01` 与 `10`，故只剩全 0 和全 1 两个 constant phases。等号必须放在非鲁棒端，`B=2T` 不能鲁棒。

鲁棒时 `a_i,b_{i-1}>B−T` 且每项≤T，故两个 phase 在 `M_i` 的 core 负载差严格小于

\[
T-(B-T)=2T-B.
\]

# 2. 给定完整 strict 调度后的共同 context 切换

去掉 `sigma` 的 context jobs 后，每个 core 的限制调度峰值仍≤T≤B，因此由上节确定为某一个 constant phase。对一台 core machine `M_i`，记原 phase core 负载为 `x_i`，目标 phase core 负载为 `y_i`，所有 context jobs 在该物理机上的实际总负载为 `c_i`。原调度给

\[
c_i+x_i\le T,
\]

而鲁棒差界给 `y_i−x_i<2T−B`。于是切换所有 core phase、逐件保持每个 context job 的原端点，得到

\[
c_i+y_i< T+(2T-B)=3T-B.
\]

这一个逐机不等式同时处理 context 跨多个 core、共享额外机器、phase 相同/不同、负载下降或无变化。额外机器没有 core jobs，context 端点保持不变，负载仍≤T<3T−B。不同 core 机器集不交确保每台物理机只计一份 core old/new load；没有复制、丢弃、拆分、第三端或隐藏预载。

因此对任意显式 phase 向量 `theta`，都有完整实际调度 `tau_theta` 满足

\[
C_{\max}(\tau_\theta)<3T-B.
\]

若 `B≥3T/2`，则 `3T−B≤B`，所有 phase 切换弱 B 可行；在边界 `B=3T/2` 实际界仍严格小于 B。该结果是假定给定 strict witness 的相位切换，不是未知 `sigma` 的搜索器或 source assignment decoder。

# 3. 三半阈值和 3T−B−e 锐界

## 3.1 三半阈值最小解析例

对任意 `T≤B<3T/2`，取两台机器 `M1,M2`、两件 core jobs：

| job | M1 | M2 |
|---|---:|---:|
| `j1` | `T/2` home | `T` successor |
| `j2` | `T` successor | `T/2` home |

再加一件只有 `M1:T/2` 有限端的 context job `k`。core 的两种 collision sums 为 `3T/2` 和 `2T`，均>B，因此 core 在 B 下鲁棒。第一 phase 加 `k` 的负载为 `(T,T)`，给出 strict T 调度；反向 phase 使 M1 负载 `3T/2>B`，context 无法逃逸，故没有 weak B 扩展。该族覆盖 `T=B`，并在 `B` 达到 `3T/2` 时恰失去鲁棒性。

这证明三半阈值是锐的，但不声称每个 B 都有有限实例恰达到 `3T−B`。

## 3.2 上确界族

最终 canonical 另给出任意有理 `0<e<2T−B` 的包络锐族。令

\[
d=B-T+e\in(0,T).
\]

两机 core 的一件 job 在两机均耗 T，另一件 job 在两机均耗 d；固定 context 只在 M1 耗 `T−d`。碰撞和 `T+d=B+e>B`，所以 core B-鲁棒。选定 phase 得到负载 `(T,T)`；反向 phase 的峰值为

\[
2T-d=3T-B-e.
\]

当 `e→0+`，指定 phase 的实际最小扩展值趋近 `3T−B`；每个有限实例都严格低于包络。应写“上确界锐”，不能写“有限实例达到包络”。

# 4. 域外共享 core machine 反例

若删除不同 core machine-disjoint 条件，定理不成立。取 `T=1`、`B=6/5`，两个两机 core 共用机器 `M`，各自另一台机器为 `N1,N2`；每个 core 的两个作业端点分别为 `(M:3/10,N_l:9/10)` 与 `(N_l:9/10,M:19/20)`。各 core 单独两 collision sums 为 `5/4` 和 `9/5`，所以单独 B-鲁棒。

加入只有 M 端耗 `2/5` 的 context job。两 core 都 phase0 时 M 负载 `2*(3/10)+2/5=1`、N_l=9/10，存在 strict 调度；两 core 都切 phase1 时 M 负载

\[
2(19/20)+2/5=23/10>3T-B=9/5.
\]

该反例保留所有 core jobs 两端和 context 单端，说明机器 disjoint 是完整包络的真正必要域条件，不可被“允许共享机器”模糊措辞覆盖。

# 5. 位复杂度、有限审计与实际重放

验证 `sigma` 只需按显式 finite endpoints 检查每件 job、逐机有理求和；读取每 core 一件作业目的地即可确定 candidate phase，再全量核验。`theta` 作为一次显式输入，不枚举所有 `2^(core数)` 相位向量。切换只写原机器编号，context 任务原端点不变；分母位长按输入分母位长之和多项式增长，不对 `2T−B` 求倒数循环。

最终代码实际覆盖：7 个 local cases、11 jobs/6 machines 的 shared-context 例全部 32 orientations 与 4 targets、6 个三半锐例、8 个包络例、碰撞等号和域外 overlap 反例。退出码 0，`all_assertions_passed=true`；算术为 Fraction/整数、无随机抽样。该有限程序是审查重放，不是一般 UM solver 或任意 context 生成 `sigma` 的算法。

# 7. 结论

`6d89d94065382070b081` 在明确域内确认：给定各 core machine/task disjoint、每个 core job 恰两端、完整 strict `T` witness 和任意 context 原端点固定时，鲁棒双端环的任意 phase 切换均满足严格 `Cmax<3T−B`；`B≥3T/2` 时因此弱 B 可行。三半阈值由两机两任务加单端 context 的锐例给出，`3T−B−e` 家族给出上确界锐性。

删除 machine-disjoint 条件会出现实际域外失败，且不应被模糊措辞掩盖。有限 Fraction 审计和最终代码重放支持列明案例，不替代未知 strict witness 生成、一般 UM 算法、near-two hardness 或外部新颖性结论。
