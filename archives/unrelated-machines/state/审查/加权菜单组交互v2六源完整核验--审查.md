# 2. 承重模型与量词

输入是有限非空组集 (G)。每组有显式、带索引的非空 state 菜单 (A_g)；state (s) 列出有限资源集合 (S_gs)，其中资源标识在同一 state 内必须互异，集合可为空。每个 incidence 的 private 时间 p_gsu >= 0 为二进制有理数，且

W_gs := Σ_{u in S_gs} p_gsu <= 1。

每个 indexed state 有一台私有机，每个资源有一台资源机；selector 在本组所有私有机上耗时 1；incidence job 在所属私有机耗时 p_gsu，在其资源机耗时 1，未列时间为无穷。所有 state、原 job、零时间项、空 state 和重复 indexed state 都保留，没有预载、拒绝、侧约束或私有机/资源机合并。
令 Delta >= 1 是完整菜单并集上任一资源出现于多少个不同组的有效上界，令 M >= 0 是组交互图最大度：两组的完整资源并集相交即相邻。参数可二进制编码，只能按显式输入的 incidences 检查，不能按其数值复制节点。令

beta = 1/(M + 2 Delta - 1)，R = 2 - beta。

全称结论是：每个满足上述显式域的输入，都有确定性位多项式算法输出所有原 jobs 的完整合法调度，峰值不超过 R * OPT(P)。算法不输入 (OPT)、YES witness、最优 state、配置解或隐藏分布。严格单位 promise 只在实际输出负载上判别 (OPT <= 1) 与 (OPT > R)，并非宣称每个输入都有绝对负载 (R) 的输出。

# 3. 归一化与精确 optimum 保持

对每个 W_gs < 1 的 indexed state 加一个该 state 独有的 bonus resource 和 bonus job，private 时间为 1-W_gs，资源时间为 1。对所有 deficient state 加 bonus，包括最终未选 state；不删除任何原 job。删除所有 bonus 是从归一化调度到原实例的投影，不增峰值。反向地，任意原调度的峰值 C >= 1（由 selector 强制）可把每个 state 的所有 bonus 都放到各自 dedicated resource，峰值仍为 C。故
OPT(N(P)) = OPT(P)。

新资源只属于一个组，(M, Delta) 上界不变。b089 read-after 明确了 heavy/slot 图中的“resource”指包含 bonus 的当前归一化实例；若误读成只能用原资源，空 state 的证明会失效。此句是措辞澄清，不是模型修改。

# 4. heavy 失败分支

在归一化实例中，若某组有 state 的全部 private 时间不超过 beta，按固定输入顺序选一个，称这些组为 L；其余组为 H。对 H 的每个 state 至少有一个 p_gsu > beta。建二分图 H--资源：若某 state 的 incidence 在资源 u 上有 p_gsu > beta，连边并保存 witness state。


若存在峰值 C < 1 + beta 的实际调度，任一 g in H 的 selector 选出的真实 state 都有一个 heavy incidence；若该 job 留在私有机，selector 加它的负载 1+p > 1+beta，所以必须送到资源机。又因 C < 1+beta <= 2，一个资源机至多接一个 external unit job。逐组选出的 heavy jobs 给出覆盖 H 的 matching。因此无 covering matching 时 OPT >= 1+beta。此时全 private 调度峰值至多 2，且
2/(1+beta) <= 2-beta。
# 5. heavy 成功、单一 slot matching 与尾项精确计数

若 heavy 图有覆盖 matching，每个 H 组选其 witness state，只 export 匹配的一个 heavy incidence，保留其余所有 incidence（含未选 state）在私有机，并 reserve 匹配资源。对 g in L 的 selected diffuse state，去掉 reserve 资源。完整菜单交互图保证，含正 private 权的被删资源至多来自 M 个邻组；每项权至多 beta，故剩余质量
W_prime_g >= 1 - M beta。

对每个 g in L，把剩余权重降序记为 w_1 >= ... >= w_n >= 0，令 m=floor(n/Delta)。前 m Delta 项按连续完整 Delta-块建立 slots；每个 slot 连接该块的 Delta 个不同原资源，末尾不完整块不建 slot。

实际块匹配的导出质量至少为 Σ_{t=1}^m w_{t Delta}。把前 Delta-1 项单独估为 (Delta-1) beta，其余位置按区间 [t Delta, min(n,(t+1) Delta-1)] 归入样本 w_{t Delta}，得到 Delta * Σ_{t=1}^m w_{t Delta} >= W_prime_g - (Delta-1) beta。

一个资源在同一组的选定 state 中只出现一次，并在完整菜单至多属于 Delta 个组，因此 slot 图中资源度至多 Delta。边计数给 Delta |A| <= Delta |N(A)|，Hall 一次覆盖所有组的全部 full slots；匹配同时避开已 reserve 的 heavy 资源。于是

导出质量 >= (W_prime_g - (Delta-1) beta)/Delta >= (1 - (M+Delta-1) beta)/Delta = beta。

成功调度把每个 selector 放在所选 private state；H 组只 export 匹配的一个 heavy incidence，L 组 export slot matching 指定的 incidences；其余所有原 incidence（包括未选 state）留在自身 private 机。资源机至多一个 external unit job，selected private root 峰值至多 2-beta，未选 root 至多 1。

H 组导出质量严格大于  beta，L 组至少  beta；selected private root 峰值至多 (2 - beta)，资源至多一个 external job，所有其余原 jobs 都有归属。由于 (OPT >= 1)，成功分支的绝对上界也是相对上界。
Exact-only 审查给出关键域外反例：单组单 state 含两件不同 incidence job 却都指向同一资源，各 private 时间 1/2，看似 Delta=1,M=0，但真实 OPT=3/2，因此 distinct-resource 条件不能省略。该例不否定形式域定理，也不能推出非单射域一定无精确算法；它只证明当前 Hall/端点证明不能越界。
# 6. 复杂度、边界与独立审查结论
在 tagged grouped cube 特例中，若每组完整变量并集至多 q，每变量跨组至多 d，且 incidence index injective，则可取 M <= q(d-1)、Delta <= min(d,Q)。这是完整菜单并集上的度数界；若只对单个 state 计数，不足以应用该定理。固定 M,Delta 给受限类统一次二界，但 M 或 Delta 增长时保证可趋近 2；不构成一般 unrelated-machines 算法、NP-hardness、因子锐性或严格单位 NO 解码。
排序、两张显式二分图的确定性 matching、精确有理比较、bonus 计算和逐个原 job 回填都按显式 incidences 与分母位长多项式。大二进制 (Delta,M) 只用于比较、整除、阈值和分块索引；不循环到参数数值，也不复制 Delta 个虚节点。稠密矩阵若需审计，bonus 至多每 state 增一行一列，矩阵大小仍按显式 state/job 数多项式；算法实际输出的是每个原 job 的机器标识。

六源最终处置为 `integrated`：Exact 提供正式量词与版本身份，Proof 给出承重推导，Exact-only 与 Proof/canonical read-after 提供独立复核及空尾、零权、binary 参数、稠密输出和 bonus 资源边界。它们合一到本审查对象，不把同一 v2 候选重复计为六个算法成果。与既有 `加权菜单组交互匹配双源续审查--审查` 的关系是“六源扩展核验”；与 v1 记录的关系是“同一模型版本修正”，v2 的 (Delta-1) 尾项常数取代 v1 的较弱分母 (M+2Delta)。第三阶段应为这些对象建立版本修正、受限算法和域边界关系；不把旧图或未建立的 embedding 直接当完成。
