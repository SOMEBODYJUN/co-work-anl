# 精确输入、历史身份和当前能使用的合同

主源是hardness_decoder仅据literature_bridge发来的Exact/算法合同、在未读作者完整Proof前冻结的71行独立重构。其结论的“三二质量”是**总任务权至少2/3**，不是执行全部任务。源尚把近优CONFIG的实际primal恢复列为义务A；没有本源后置作者读后或canonical认证可免费继承。本页完整保其条件证明，不将历史待核义务悄悄补成无条件实现。

普通UM显式给m≥1、有限任务J、非负二进制有理/不可用∞矩阵P，每件有有限端；允许零时间、任意资格及m,n增长。给非负有理任务权wⱼ，W=Σwⱼ，阈值T≥0，承诺真实OPT(P)≤T。部分调度每件任务至多执行一次，可不覆盖一些任务；每机实际负载目标≤3T/2，覆盖权目标≥2W/3。权不等于处理量或任务件数。

以下**条件接口A**是需要的算法依赖：对原任务集及之后真正未覆盖的任务集，能按总位长多项式返回显式多项式支撑的T-configuration packing可行解，原容量精确≤T、每机配置总权≤1、每任务覆盖≤1，目标值至少(1−η)倍该子集总权，η=1/100000。承诺OPT≤T保证两次packing optimum均等于对应总权：真实调度给全覆盖可行解，任务覆盖上界给反向界。这不等于已经计算到该解。以下组合推导先取W>0、T>0，零边界在后段单列。

# 分数big匹配或两阶段小包

记第一解对j的big(pᵢⱼ>T/2)覆盖bⱼ、small(pᵢⱼ≤T/2)覆盖sⱼ，bⱼ+sⱼ≤1，Σwⱼ(bⱼ+sⱼ)≥(1−η)W。每个T配置至多一件big，故big边际是任务—机器二部图的分数匹配。最大**任务权**整数匹配M满足w(M)≥Σwⱼbⱼ，逐机至多一件p≤T任务；不要求覆盖所有有big资格的任务。

若w(M)≥2W/3即输出M。否则Σwⱼsⱼ≥(1/3−η)W。对任一配置的small子集，总工作≤T、单件≤T/2，可以next-fit拆成最多三个T/2包，补空包到三个。证明：若出现四包，第一包加第二包首件>H=T/2，第三包加第四包首件>H，两组任务互不相交，迫总工作>T，矛盾；等于H及零时间照常。

每机独立按第一解抽配置，再均匀选三个包之一。j在机i被选概率为其small边际的1/3；只需**跨机器**独立，不假设同机各任务独立。因此
\[
\Pr(j\text{被覆盖})\ge1-e^{-s_j/3}
\ge(1-e^{-1/3})s_j\ge c s_j,
\quad c=283/1000.
\]
中间一步是s∈[0,1]上的凹函数弦下界。每件重复选中的任务只保最小编号机器，删除不增负载。条件期望确定化得到实际S₀，各机≤T/2，w(S₀)≥c(1/3−η)W。

固定这份**实际S₀**后，在真正剩余任务上第二次调用A。不能把第一解未用分数残量当成满覆盖配置解。原最优T调度删除dom(S₀)仍可行，故第二packing optimum=W−w(S₀)。每机独立抽一个完整配置、去重并条件期望确定化，利用覆盖概率≥(1−e⁻¹)qⱼ≥a qⱼ，a=79/125，得到S₁：
\[
w(S_1)\ge a(1-\eta)(W-w(S_0)),\qquad
\operatorname{load}_i(S_1)\le T.
\]
两实际任务域不交，所以**同一份**S₀∪S₁在全部机器负载≤3T/2，不是两份各自可行但相互冲突的菜单。

令x=w(S₀)/W，联合权下界x+a(1−η)(1−x)随x递增，故
\[
\frac{w(S_0\cup S_1)}W\ge
a(1-\eta)+(1-a(1-\eta))c(1/3-\eta)
=\frac{2500154630232929}{3750000000000000}
=\frac23+\frac{154630232929}{3750000000000000}>\frac23.
\]
取M与S₀∪S₁中实际权较大者，覆盖保证成立。它没有执行剩余至多1/3权任务的全局延伸合同。

# 不用浮点指数的确定化与位复杂度

第一阶段每机状态是显式支撑配置×三个包号，第二阶段是显式支撑配置；剩余概率补empty。已固定机器覆盖的任务收益为常数，对尚未覆盖j，剩余收益概率精确为
\[
1-\prod_{i\text{未固定}}(1-q_{ij}).
\]
逐机枚举有限状态、按该式计算有理条件期望，选最大者，不枚举机器联合状态，也不计算e或exp。若A输出支撑及有理权位长多项式，每乘积至多m因子，分子分母位长受总输入/输出位长和控制；所有条件和、排序/匹配及去重均多项式。

常数可用纯有理正Taylor项认证：Σ_(h=0)^6 1/h!=1957/720>1/(1−a)，Σ_(h=0)^4 (1/3)^h/h!=2713/1944>1/(1−c)，从而a<1−e⁻¹、c<1−e^(−1/3)。指数只在证明中，不进入算法。W=0或无任务可返回空调度；T=0且OPT≤0时每件有零端，逐件选零端甚至覆盖全部，不需除T或此pipeline。

# 义务A的弱分离路线及尚缺内容

配置packing变量λᵢC≥0，约束Σ_CλᵢC≤1、Σ_(i,C∋j)λᵢC≤1；目标Σ_(i,C)λᵢCΣ_(j∈C)wⱼ。其对偶是
\[
\min\sum_i\alpha_i+\sum_j\beta_j,
\quad\alpha_i+\sum_{j\in C}\beta_j\ge\sum_{j\in C}w_j,
\quad\alpha,\beta\ge0.
\]
给β时每机分离是以max(wⱼ−βⱼ,0)为收益、容量T的0/1 knapsack。若δ-近似knapsack返回的**真实配置**收益>αᵢ，它确为有效违反列；若所有行返回≤αᵢ，则完整最优收益≤αᵢ/(1−δ)，所以(α/(1−δ),β)完整对偶可行，总代价≤原代价/(1−δ)。这只是multiplicative弱分离，不是精确分离。

在本承诺域已知packing optimum=W，可取0<δ<η、测试预算K=(1−η)W：伪接受点缩放后代价≤K/(1−δ)<W不可能，因此该预算区域必须能给真违反列。源把它作为有希望的路线，**仍未写出**有理ellipsoid的阈值/边界体积、有限列恢复，以及在原容量与覆盖约束上精确可行、值≥(1−η)W的多项式支撑primal。数值LP、近可行对偶或一句“椭球自动可得”不完成A。
