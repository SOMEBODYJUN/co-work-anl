# 2. 双轨来源：归一化、拆分容量、单例外和完整立方体四个合同

## 2.1 归一化双轨和通用三二上界

变量 v 有两台私有轨机器 U(v,+), U(v,-)，一枚 selector 只能在两轨上用时 1。每个 clause c 有唯一外机，整数容量参数 A_c>=1，真实 occurrence 数 m_c<=2A_c-1。每个 occurrence port 属于一条符号轨；若该轨出现 K(v,s)>0 次，则 port 在轨上用时 1/K(v,s)，或在其 clause 外机上用时 1/A_c。重复 occurrence 被视为不同 job；K=0 不产生 port；没有预载和隐含任务，空实例可加一台 dummy。

`UM-NORMALIZED-DUAL-RAIL-UNIVERSAL-THREE-HALVES-v1` 的结论是：对全部显式实例，不需要源赋值、YES 假设或最优值，即可在总输入位长多项式时间输出每枚 selector/port 的原合法目的地，所有机器负载不超过 3/2。selector 在非空实例中给 OPT>=1；空变量实例单独输出空调度。证明把每件原任务在两个端点放半片，将每轨 selector 半片放首并把 port 半片两两成单位槽，clause 端亦成槽；Hall 保证覆盖全部任务的整数匹配。含 selector 的轨最多保留 floor(K/2) 个 port，负载为 1+floor(K/2)/K<=3/2；未选轨负载至多 1，clause 外机因 ceil(m_c/2)<=A_c 而至多 1。

来源另给共同整数流实现：候选轨容量 floor(K/2)，clause 共享容量按 3A_c/2 计数，K=1 的变量以一个单位供给在两 occurrence 间分半。该流必须一次性共享 clause 容量，不能把每条轨独立拼接。half-slot 证明和整数流证明是同一 scoped contract 的两种构造，不应互称一般 ST 或一般 UM 算法。

严格阈值 C<=1 时，selector 所在轨不能再容纳正时间 port，故所有真 port 必须外放；每个 clause 外送不超过 A_c，因而可解码严格源解。C>1 时可只外送真轨的一部分 port，弱端不能由此自动解码。这个失败机制是双轨近二归约的关键边界。

## 2.2 三二锐例和拆分 unit 外机

四个 clause、三变量 x,y,z、每个 A_c=2，occurrence 模式为 (x+,x+,y+)、(x-,x-,y+)、(y-,z+,z+)、(y-,z-,z-)。每条轨 K=2，port 时间均为 1/2，selector 为 1。严格源无解：前两 clause 迫使 y 同时为真和假，后两在 y 假时迫使 z 同时为真和假。所有处理时间在 {1/2,1}，任何 C<3/2 不能满足该严格无解编码；把 selectors 放正轨、正 ports 外放、负 ports 内放可达到 C=3/2。原始模型为 10 台机器、15 件任务，允许重复 occurrence；独立枚举直方图只有 3/2 和 2 两档，故这是该模板的真实锐例，而非一般 UM 锐界。

`UM-SPLIT-CAPACITY-DUAL-RAIL-THREE-HALVES-v1` 把 clause 外机替换为 L_c=min(A_c,m_c) 台私有 unit 机器，port 在 unit 外机上用时 1，容量语义不再与 scalar clause 混合。网络 source->variable 容量 floor((K_++K_-)/2)，variable->occurrence 容量 1，occurrence->clause 容量 1，clause->sink 容量 A_c；半流先证可行，再用整数满流挑出某符号至少 ceil(K_s/2) 个 ports。选中轨只外送被流选中的 ports，其负载至多 3/2；unit 外机各接至多一个 port，负载至多 1。相同四-clause 输入在拆分模型中是 14 台机器、15 件任务，OPT 仍恰为 3/2。

这里的 source-based 编码失败只说明这两种外部容量合同不足以提供近二 soundness。它不否定引入跨层状态、共同核心或另一容量语义后的归约；拆分模型的 modes 计数也不是对所有原始物理 assignment 的穷举。

## 2.3 单例外地板和完整立方体精确前沿

`UM-DUAL-RAIL-ONE-EXCEPTION-FLOOR-v1` 允许每个 port 在选定轨上的内部时间为任意非负有理数，总轨负载 W<=1，外部 clause 机器统一使用 1/A，arity<=2A。若每个变量指定一个 exception e，且 W-w_e<=rho-1，则将该 port 外送、其余留轨即可得到 C<=rho，同时 clause 负载<=1。若例外可自由选，精确条件是 max_e w_e>=W+1-rho；在 W=1 时变为 max_e w_e>=2-rho。该合同不提供任意非均匀端点的通用选择算法。

完整立方体族取 A>=1，d=2A-1，变量数 d，包含全部 2^d 符号模式的 d 元 clause，每个符号每轨出现 k=2^(d-1) 次。A>=2 时任何赋值都有一个 d 个文字全真的 clause，因此即使阈值降到 d-1=2A-2，源仍无解；A=1 不属于该 NO 族的同一断言。对 B∈[A,d] 定义

`R_B = sum_{s=0}^d (s-B)_+ * binom(d,s)`,
`r_B = ceil(R_B/d)`,
`F_B = max{B/A, 1+r_B/k}`.

来源证明该显式实例的整数最优 makespan 精确为 `OPT_A=min_{B=A,...,d} F_B`。下界先取 B=floor(AC)（或 B=d 的大 C 情形），用符号置换同构把 selectors 归一到负轨，再把正 ports 留内；每个负轨最多 floor((C-1)k) 个负 ports，大小 s>B 的 clause 至少有 s-B 枚负 port 留内，累计得到 d*h>=R_B，从而 C>=F_B。上界用 clause->variable 网络：每大小 s>B 的 clause 供给 s-B，每 incidence 容量 1，每变量入容量 r_B；对称均匀分流给出有理满流，整数容量最大流给出实际选择。外机负 port 数至多 B，轨内负 port 数至多 r_B，故达到 F_B。复杂度按显式 2^d clauses 和 d*2^d ports 的展开输入长度计，不声称按 log A 多项式。

A=3,d=5,k=16 的完全证书有 42 台机器、165 枚 jobs。大小 4 的负文字 clause 各内收一个指定 port，大小 5 的 clause 内收两个，五条负轨内收数 [2,2,1,1,1]，故 C=9/8；若 C<9/8，每轨至多一枚负 port而五个大小4 clause和一个大小5 clause至少要求总共七枚内收，矛盾。该实例的实际 OPT 恰为 9/8。

来源还给出 A>=2 的三二逃逸：每变量只外送 k/2 个负 ports，选在负文字数不超过 A 的 clauses 中，负轨负载为 3/2，clause 负载不超过 1；进一步 B=A 的公式给 `OPT_A<=1+ceil(R_A/d)/k`，由二项绝对偏差估计趋于 1。固定任意 1<rho<2 时，大 A 使源弱阈值仍无解但实际 C<rho，说明该平衡双轨模板不具备近二 soundness。

# 3. 逐行均匀相关读出来源

## 3.1 精确对象与 v1/v2 版本边界

输入是有限二部简单图 G=(U,V,E)，左点 u 有显式非空标签集 A_u，右点 v 有 q_v=deg(v) 个互异单位资源 R_v，不同右点资源互异，孤立右点没有资源。每条边 e=(u,v) 的映射 f_e:A_u->R_v 全定义并逐行均匀：每个 r∈R_v 的原像大小为 |A_u|/q_v。一个左标签决定该左点所有 incident tests 的请求，不允许按边单独选标签；合法读出 F 是请求资源全局互异的边子集。

`UM-ROW-UNIFORM-CORRELATED-GUARD-HALF-RETENTION-v2` 对全部有限显式输入输出同一个全左标签和合法 F，满足每个左点保留至少 ceil(d_u/2) 条边。d_u=0 配额为 0，d_u=1 的唯一请求全保。待审 scratch v1 只写 floor(d_u/2)（单边另全保），不能把 v1 与 v2 混称；正式正文采用 v2，并把 v1 作为版本边界保留。

## 3.2 整数碰撞势和一次全局匹配

给定全左标签，资源 r 的请求数为 c_r，定义碰撞势 `Phi=sum_r binom(c_r,2)`。固定其余标签并替换 u，因简单关联和不同右点资源分区，u 自身不同测试不会落到同一资源，所以势差恰等于其新旧碰撞成本。对 u 的标签均匀平均，逐行均匀性给出

`average_a C_u(a | a_-u) = sum_{v in N(u)} (q_v-1)/q_v < d_u`.

逐次扫描每个左点和显式标签，只在严格下降时换标；每次势至少下降 1，初势至多 binom(|E|,2)。停止时所有非孤立左点同时满足 `C_u<=d_u-1`。

在最终标签下给每个真实请求资源权 1/c_r。整数不等式 `1/c >= 1-(c-1)/2` 使每个 u 的权和至少 `(d_u+1)/2`。复制 ceil(d_u/2) 个配额节点并做一次全局二部增广匹配，或直接用 Hall 计算，可同时覆盖全部配额。Hall 版本对左点集 S 令 k_r 为请求数，利用 `sum_r k_r(k_r-1)<=sum_{u in S} C_u<=D_S-|S|` 和 `k(k-1)>=2(k-1)`，得到 `|N(S)| >= sum_{u in S} ceil(d_u/2)`。因此 F 是同一组标签下的真实共同读出，不能逐左拼接局部选择。

该算法总位长多项式：势下降次数由 |E|^2 控制，标签表和映射表显式访问，配额匹配节点总数不超过 |E|。实现使用 Fraction/整数回算，有限审计不能代替上述证明。

## 3.3 平层 unrelated-machines 编译和承重反例

对每个 (u,a) 建 parent 机器 M_{u,a}，对每个资源建单位外机；每个 u 有一枚 selector，可在任意 parent 上用时 1；每个状态 a 与 incident edge e 有一枚 port，在 M_{u,a} 上用时 1/d_u，在外机 f_e(a) 上用时 1，未列资格为无穷。将第 3.2 节的标签和 F 编译为：selector 放选中 parent，选中状态的 F ports 放真实外机，其余所有状态和 ports 留各自 parent。未选 parent 负载 1，选中 parent 为 `1+(d_u-|F∩δ(u)|)/d_u<=3/2`，外机至多接一个 port；空图、孤立左点和无机情况分开处理。`UM-ROW-UNIFORM-FLAT-STATE-THREE-HALVES-v1` 因 selector 给 OPT>=1，得到该显式平层子类的 3/2 近似和绝对负载界。

承重假设删除后有两个精确反例。其一，一个左点四条平行边到同一右点、四标签和四资源、identity 映射；任一标签把四请求压到同一资源，只能保留一条，平层编译 OPT=7/4。其二，两个左点各一标签、一个度2右测试，纯列映射各自看似完美但复合请求均落在资源0；平层编译精确 OPT=2。由此必须保留简单图、资源分区和逐行均匀性；仅有共享源标签或纯列完美不够。

# 4. 证据、程序和与全仓结果的比较

双轨源的实际证据包括：归一化锐例的 2^15 个 assignment states；split-unit 锐例的 2^15 selector/capacity modes（不是物理 assignment 全枚举）；full-cube cuts 只枚举删除网络的变量侧 cuts 与物理负载 breakpoints；one-exception 审计使用 Fraction/integer flow 和边界案例。已有审查记录 748 个 exhaustive actual optima、12,565 个 template constructions、2,000 个随机不平衡 clause constructions、68,288 个 test-only assignment states、12 个非法域拒绝和空/零度/A=1/大整数边界。所有计数属于冻结实现证据，不能替代一般证明或外部新颖性认证。

row-uniform 的冻结证据来自 `row_uniform_correlated_guard.py` 及其 JSON：361 个明确输入，1646 个标签 profile，943 个稳定 profile 的全部左子集 Hall 核验，6068 枚原任务回算，151 次严格势下降，12 个非法输入拒绝。有限 frustrated-triangle 枚举给 OPT=3/2，odd-degree 例给构造输出 4/3 而 OPT=1，说明构造不是精确最优算法；这些结果与第 3 节一般证明分开登记。

与现有全局基数/row-uniform 审查相比，本批新增并独立核对 dual-rail 的四合同、完整立方体精确公式、A=3 的 9/8 证书、三二逃逸趋近 1 和自查询/纯列反例。与重边匹配、全层配额、三维匹配和共享汇点审查相比，双轨仍是固定外容量的源编码，row-uniform 仍是正面平层子类；不能把它们组合成一般近似算法。与六人 SPE 当前对象相比，两源都没有客户目录、六提供者完整历史、任意平局或覆盖均分量词，继续保持 unrelated-machines 身份；它们只为第三阶段提供“简单逐行均匀结构足以保半边”和“双轨弱端会逃逸”的关系证据。

# 5. 成熟度、处置与接续
