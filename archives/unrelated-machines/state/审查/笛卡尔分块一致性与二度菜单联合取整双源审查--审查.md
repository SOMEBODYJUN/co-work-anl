# 阅读范围与对象分离

本批完整读取两个当前正文，并与仓库内的裸笛卡尔菜单、逐坐标配额、分组超立方 Hall 保留、配置联合匹配和 degree-two 有限审计逐项比较。两个来源都属于显式菜单模型，但承担的数学任务不同。

第一个来源给出一族有限域笛卡尔菜单的精确资源配额、仿射矩阵秩公式、分块一致性下界和任意重选的并发缺项界。它研究的是“加入何种标签一致性后，原来高值的裸菜单还能保留多少资源”的组合边界；其普通 UM 桥只把菜单值还原为完整任务调度，不能把额外的选择语义当成普通矩阵的资格约束。

第二个来源给出一类每个资源至多连接两个 group 的显式菜单的联合取整算法。它先把每组所有 indexed state 的资源权平均成一个辅助加性玩家，调用带二度资源的 MaxMin-balancing 2-近似，再选择每组一个 state，并把所有原 jobs 完整回填；对非归一化 state 通过独占 bonus resource 保持真实 OPT。它是限定结构类的条件近似定理，不是一般 unrelated-machines 的算法。

本审查保留两份正文的稳定 ID、来源版本、量词和限制；有限审计只作为证据，不替代正文推导；主目标 `UM-TARGET-v1` 与六人 SPE 仍未由此解决。

# 一、笛卡尔菜单的精确值与一致性边界

## 1. 普通矩阵桥和选择域

给 prime power (q\ge2)、整数 (t\ge1)，令 (N=q^t)。组和 indexed state 均由 (g,\ell\in\mathbb F_q^t) 标记；真实资源为 ((a,b)\in\mathbb F_q^t\times\mathbb F_q^t)。

状态支持为
\[
S_{g,\ell}=\{(a,b): b_i+g_i a_i=\ell_i\ \text{for all }i\},
\]
恰有 (N) 枚资源；每个 private incidence 的时间为 (1/N)，总量为 1。每组有一个 selector，只能在本组 state machine 上取时间 1；每个原 incidence 是独立任务，只能在自身 private machine 取 (1/N)，或在其唯一真实 resource machine 取 1；其余端均不可用。未选 state 的任务仍全部存在且必须执行。

对固定选择函数 (ell(g))，令 (k(ell)) 是每组都能领取且跨组不交的最大整数资源数，令 (V(ell)=k(ell)/N)。对任意非空选择域 \(\mathcal L\)，正文证明受限实际最优为
\[
 C_{\mathcal L}=2-V_{\mathcal L},
\quad V_{\mathcal L}=\max_{\ell\in\mathcal L}V(\ell).
\tag{1}
\]
正向把每组选中 state 的 (B_g\) 项 incidence 导到真实资源，其余原任务留在 private；逆向从任意 (C<2) 的完整调度提取 selector 实际选中的 state 及其 exports。每台资源在峰值严格小于2时至多接一件unit，因此所得$B_g$跨组不交。若所选state有$d_g$件未导出incidences留在private，其精确负载为$1+d_g/N$，只有$d_g=N$时才等于2；故$C<2$给出$|B_g|\ge N(2-C)$。(C\ge2) 时由全 private 基线覆盖。这个恒等式包含全部原任务，不能只对 selected subset 计数。

式 (1) 的域是选择函数的额外语义。若 (mathcal L) 是外部逻辑条件，式 (1) 只给该逻辑域的受限实际值；它没有证明普通 UM 可以免费检查或强制该条件。

## 2. q-ary affine、循环和逐坐标选择

正文的稳定身份为 `UM-QARY-AFFINE-MENU-RECOUPLING-CONSISTENCY-v1`。选择域包含：

- cyclic：(ell_i(g)=g_{i+1})，下标循环；
- affine：(ell(g)=Ag+c)，其中 (A\in\mathbb F_q^{t\times t})、(c\in\mathbb F_q^t)；
- coordinatewise：(ell_i(g)=f_i(g_i))，每个 (f_i:\mathbb F_q\to\mathbb F_q) 可非线性但不能读取其它坐标。

正文给出的精确值为
\[
V_{\rm cyc}=V_{\rm aff}=1-\frac{\lceil(q-1)^t/q\rceil}{q^t},
\qquad
V_{\rm sep}=\frac{\lfloor(q-1+1/q)^t\rfloor}{q^t}.
\tag{2}
\]
对应的实际峰值仍按式 (1) 为 (2-V)。固定 (q) 时 cyclic/affine 的值趋于 1，coordinatewise 的值趋于 0；因此不能把裸菜单的高值 allocation 事后强制成逐坐标选择，并同时保留统一正常数比例。这个结论不依赖修复算法是否有效，只依赖同一菜单内受限值的全称上界。

范围要点是：(q>2) 时正文没有声称所有固定非线性 (f_i) 都给同一值；式 (2) 的 coordinatewise 值是优化选择函数族的结果。affine 上界不扩展到任意非线性全域，(q=2) 的无约束精确值由相关裸菜单正文另行处理。

## 3. 固定 affine 选择的秩公式

给定 (ell(g)=Ag+c)，对每个 (a\in\mathbb F_q^t) 定义
\[
\nu_a=\dim\ker(A-\operatorname{diag}(a)),
\qquad
\Lambda(A)=\sum_{a\in\mathbb F_q^t}q^{-\nu_a}.
\]
正文证明
\[
k(\ell)=\lfloor\Lambda(A)\rfloor.
\tag{3}
\]
在固定 (a) 层，资源端是线性映射 ((A-\operatorname{diag}(a))g+c) 的 image；其并集大小为 (Nq^{-\nu_a})。任意组子集 (F) 的像至少为 (|F|q^{-\nu_a})，所以各层合计满足 Hall 配额 (Lambda(A)|F|)，给每组 (lfloor\Lambda(A)\rfloor) 枚资源。全体组的 union 又给整数上界，故等式成立。这里的 (A-\operatorname{diag}(a)) 符号是定义的一部分，不能未经换元改写为加号。

所有 affine 的缺项上界来自非零、每变量次数至多一的 determinant polynomial：至少 ((q-1)^r) 个点非零。应用于 (\det(A-\operatorname{diag}(a)))，至少 ((q-1)^{t-1}) 个前缀出现唯一使 determinant 为零的末坐标，得到
\[
N-\Lambda(A)\ge \frac{(q-1)^t}{q}.
\tag{4}
\]
cyclic 的核递推为 (\delta_{i+1}=a_i\delta_i)，恰在 (prod_i a_i=1) 时有一维 kernel；它达到式 (4)，故循环值达到 affine 上界。奇异层不能全部丢弃，必须在左度 (L=(q-1)^{t-1})、右度 (q) 的图中完成共同 matching。

## 4. 二元 block coherence 与无环链

正文身份 `UM-BINARY-CARTESIAN-BLOCK-FIBER-QUOTA-v1`。取 (q=2)，把坐标分成非空 blocks (I_1,\ldots,I_s)，(b_j=|I_j|)。附加选择语义要求 (ell(g)|_{I_j}=F_j(g|_{I_j}))，同一 (F_j) 不能随其它 block 改变；partial bundles 仍可自由选择。

置
\[
H=\prod_j(2^{b_j}-1/2).
\]
优化全部这类 block functions 和不交 partial bundles 的值恰为
\[
Q=\frac{\lfloor H\rfloor}{2^t},
\qquad
\left|\bigcup_gS_{g,\ell(g)}\right|\le 2^tH.
\tag{5}
\]
若所有 (b_j\le L)，则
\[
Q\le(1-2^{-L-1})^{\lceil t/L\rceil},
\qquad
0\le H/2^t-Q<2^{-t}.
\tag{6}
\]
证明把一个 block 的 (2^b) groups 配成补组对；每对任意非线性标签的两个支持恰交一枚资源，故该 block 的 union 至多 (2^{2b}-2^{b-1})。独立 blocks 给乘积上界。循环 shift 在每个 block 达到上界，奇异层与非奇异层联合 Hall matching 给 floor 配额；不能先逐 block 取整再相乘。

固定无环链标签 (ell_1=0,ell_i(g)=g_{i-1}) 仍有精确值 (1/2)，union 为 (N(N+1)/2)。该依赖图无环但跨越固定 blocks，所以“无环”或“每个输出最多依赖一个其它坐标”本身不能推出 block 衰减；需要真正的 block-local coherence 语义。

## 5. 任意非线性 selector 的 concurrent deficit

同一来源还给出 `UM-QARY-AFFINE-MENU-NEAR-FULL-DEFICIT-v2` 的必要条件。设每组领取的 bundle 至少 (N-d) 项。对公共资源 (x)，令 (F_x) 是包含它的 groups，(k_x=|F_x|)。对 (F\subseteq F_x)，令 (pi_JF) 是 group labels 在坐标子集 (J) 上的投影。正文的并集恒等式为
\[
\left|\bigcup_{g\in F}S_{g,\ell(g)}\right|
=\sum_{J\subseteq[t]}(q-1)^{|J|}|\pi_JF|.
\tag{7}
\]
每个 group 至多遗漏 (d) 项，故
\[
kd\ge \sum_{J\subseteq[t]}(q-1)^{|J|}(k-|\pi_JF|).
\tag{8}
\]
置
\[
h(k)=(k-1)+\sum_{j=1}^t\binom tj(q-1)^j\max\{k-q^j,0\},
\quad
K(d)=\max\{1\le k\le N:h(k)\le kd\}.
\]
则每个非空 concurrent fiber 满足 (k_x\le K(d))，且全部分配都要满足
\[
dK(d)\ge(q-1)^t.
\tag{9}
\]
(h(k)/k) 单调不减，(K(d)) 可用精确整数比较求出；这是必要条件，不是一般最优选择算法。若 (2d<q)，严格近满引理给 (d\ge(q-1)^t/q)，等号边界不能被含入。全局计数使用两组逐坐标完全不同的 group 对：每对无论如何选标签都恰共享一枚resource，给出pair计数下界；配合每resource的领取容量和总遗漏预算推出式(9)；没有错误地假设只有这些 pairs 相交。

精确端点包括：(q=3,t=2) 时 (d_*=2)、(V_*=7/9)、实际最优 (11/9)；(q=3,t=3) 时，(d\le2) 不能达到全称必要条件，而 cyclic 给 (d_*=3)、(V_*=8/9)、实际最优 (10/9)。这些是普通 UM 桥下的真实端点，不是求解器输出，也不把 selected subset 当作全部任务。

## 6. 二进制分块与普通 UM 的边界

上面的 block、affine 和 concurrent 结果都依赖显式有限域标签、状态支持、partial bundle 和全局不交领取语义。普通 UM 矩阵没有自动的“同一 block 使用同一个 (F_j)”资格约束；若未来要把一致性作为源约束，必须把它编译成真实任务和资格图，并同时保留 YES 调度。

对二元 block 模型，普通桥的真实 (P_t) 仍允许全局 cyclic，原普通最优为 (1+2^{-t})。因此式 (5) 的低 Q 值不能直接写成原矩阵的 OPT 下界。固定二元 base 也没有 full-support YES；若换成其它字母表，block 函数定义域和值域必须一并改写，不能从二元 claim 免费推广。

仓库已有的裸菜单审查已经关闭了“通过保值降度恢复旧 NO 间隙”的误读：选择树和资源路径 reduction 可保真实 OPT，但只保留已经下降的菜单值；逐坐标配额审查则给出同一裸菜单中事后一致化的比例必趋零。当前来源新增的是 q-ary affine/block 的定量标尺、任意非线性 near-full deficit 和无环链反例，不替代这些既有结论。

# 二、degree-two group menu 的联合取整定理

## 7. 输入契约和稳定身份

稳定身份为 `UM-DEGREE-TWO-BOUNDED-MENU-JOINT-ROUNDING-v2`。输入有有限非空 groups (G)，每组显式列出的 indexed states (A_g)，以及 state resource sets (S_{g,s})。同一 resource 可以在一个 group 的多个 states 出现，但跨所有 states 至多属于两个不同 groups。每个 incidence 有非负二进制有理权 (p_{gsu})，state 总 private mass
\[
W_{gs}=\sum_{u\in S_{gs}}p_{gsu}\le1.
\]

完整原 UM 矩阵只包含：每组一个 selector (J_g)，在本组 state machine 上时间 1；每个 incidence 一个独立任务 (I_{gsu})，在对应 private machine 取 (p_{gsu})，或在 resource machine 取 1；其它端均为 infinity。所有机器、状态、资源、incidence、时间都显式给出；没有隐藏预载、拒绝端、共享 private machine 或额外 side constraint。结构标签是输入契约的一部分，不能把一般 P 自动分解成该形式。

## 8. 归一化菜单的真实 UM/XOS 恒等式

先设每个 (W_{gs}=1)。定义
\[
a_{gs}(B)=\sum_{u\in B\cap S_{gs}}p_{gsu},
\quad f_g(B)=\max_{s\in A_g}a_{gs}(B),
\]
以及
\[
V=\max_{B_g\text{ pairwise disjoint}}\min_g f_g(B_g).
\]
这里 XOS 只是显式非负 additive clauses 的最大值。正文证明完整原 UM 的真实最优峰值恰为
\[
\operatorname{OPT}(P)=2-V.
\tag{10}
\]
正向给不交 (B_g)，每组选择达到 (f_g(B_g)) 的 state；只把选中 state 的 (B_g) incidence 导出，其它所有 incidence 留在自己的 private machine，得到峰值至多 (2-min_g f_g(B_g))。反向从任意 (C<2) 调度取每组 selector 的实际 state；未选 state 可全部收回 private，选中 state 若有导出集合 (B_g)，则 (2-a_{gs}(B_g)\le C)。resource unit capacity 使 (B_g) 跨组不交。若 OPT=2，则 (V=0)，否则 (V>0) 会给出小于 2 的调度。这一转换把全部原 jobs 保留，不能只把 chosen states 当作实例。

## 9. 辅助平均、二度 MaxMin 和实际保证

令每组一个辅助加性玩家
\[
v_g(u)=\frac1{K_g}\sum_{s\in A_g:u\in S_{gs}}p_{gsu},
\quad K_g=|A_g|,
\quad K=\max_gK_g.
\]
对任意 (B)，有
\[
\frac{f_g(B)}K\le\frac{f_g(B)}{K_g}\le v_g(B)\le f_g(B).
\tag{11}
\]
因此辅助 MaxMin 最优值 (A\) 至少为 (V/K)。每个 resource 的正值最多给两个辅助 groups，所以可调用 Verschae–Wiese 的“每 item 至多两个玩家” MaxMin-balancing 2-近似，得到不交 (C_g) 满足 (v_g(C_g)\ge V/(2K))。每组再选择令 (a_{gs}(C_g)) 最大的 state，并按式 (10) 的完整回填构造调度。

于是对所有该结构类输入有确定性位多项式算法
\[
C_{\max}(\sigma)\le2-\frac{2-\operatorname{OPT}(P)}{2K}
\le\left(2-\frac1{2K}\right)\operatorname{OPT}(P).
\tag{12}
\]
算法不输入 OPT、最优调度、YES witness 或 state 分布。K 可增长，仍按显式输入位长多项式；只有 K 固定时才得到统一的常数改善。G 非空的 selector 保证 OPT≥1；空 G 若扩展接口需单独输出空调度，不能把它混进式 (12) 的 min over groups。

外部依赖只是一条明确的 Paper Fact：Verschae–Wiese arXiv:1011.4957v1 §5.1 Theorem 12 的非负加性 MaxMin-balancing 2-approx，条件是每个 item 至多两个可用玩家、二进制输入位长多项式。它不是本来源新造的 makespan theorem，也没有被误写为 CONFIG-gap 结果。

## 10. W<1 的精确保 OPT 归一化

对任意 (W_{gs}<1) 的 state 增加一个独占新 resource (z_{gs}) 和一枚 bonus incidence：private 端为 (1-W_{gs})，resource 端为 1。每个 state 的 private mass 变为 1，新增 resource 只连接一个 group。

任意增广实例调度删掉 bonus 任务和其独占机器即可得到原实例调度，所以 (OPT(P)\le OPT(N(P)))。反过来，若原实例调度峰值 (C\ge1)，对每个 state（包括未选 state）都把 bonus 导出其独占 resource，新机器负载为1，不改变旧机器，得到峰值不增的增广调度。因此
\[
OPT(N(P))=OPT(P).
\tag{13}
\]
运行归一化算法后删除 bonus，完整保留原 jobs，仍满足式 (12) 第一项。令 (O=OPT(P)\ge1)、(R=2-1/(2K))，有
\[
RO-\left[2-\frac{2-O}{2K}\right]=(2-1/K)(O-1)\ge0,
\]
得到相对保证。空 state、零 private jobs、重复 state 和大有理分母均由同一 bonus 规则处理；没有把数值展开成一元个体数。

## 11. 范围、边界和已有有限审计

算法依赖跨 group resource degree 至多 2、resource 端时间恰为 1、显式有限 K 和完整 state/private 结构。degree 3 或更高、(W>1)、未知角色混合、共享 private machine、medium 共居、任意深树均不在此证明内。K 增长时改善 (1/(2K)) 可趋于零；该来源不声称因子锐，也不覆盖一般 UM 的 unknown state/role 选择。

已有《二度菜单联合取整有限审计》保存了 5 个 weighted menu、7 个 raw backend、6 类非法输入和 root 独立枚举的 832 个原始 assignments。典型案例包含 `joint_bad_heavy_yes` 的 OPT=1、`near_two_single_state_no` 的 OPT=33/17、空/重复/零工作 state 的 normalized makespan=1，以及 auxiliary optimum 为零时的峰值 2 fallback。它们验证有限 fixture 的实际资格和精确有理负载，不能替代式 (10)–(13) 的全称证明，也不能把 degree-two backend 升级为任意输入算法。

与分组超立方 Hall 定理的联系只是共同使用显式资源流和完整任务回填；后者的 (d,Q) 乘积切片和 3/2 上界有不同资源共享量词，不能直接替换 degree-two 的 (K)-平均和 MaxMin 证明。与裸菜单/逐坐标配额的联系是同一“额外选择语义必须编译进真实矩阵”的纪律；degree-two 定理的输入结构已经把 state identity、resource degree 和 private weights 写进原矩阵，所以它不是对裸菜单缺失一致性的事后修复。

# 三、跨源关系、独有内容与后续义务

1. 第一个来源的 affine/block/concurrent 结果回答“在额外一致性语义下，裸笛卡尔菜单最多能保留多少”。第二个来源回答“当 group-resource degree 已被限制为 2 且 state/private 结构显式给出时，如何联合取整并保真实 OPT”。一个来源的 q-ary 配额不能替代另一个来源的 MaxMin 后端。
2. 第一个来源的 (C_{\mathcal L}=2-V_{\mathcal L}) 与第二个来源的 (OPT=2-V) 形式相似，但前者的选择域可能是外部逻辑条件，后者把每组 state、resource degree 和 private weights 直接作为普通 UM 输入合同；不能因为公式相似就宣称两个模型等价。
3. affine 的 determinant/核秩界、binary block 的 floor、near-full deficit (dK(d)\ge(q-1)^t) 和 (q=3,t=2,3) 端点是本批的独有精确内容；它们不能被已有逐坐标配额或分组 Hall 的摘要替代。
4. degree-two 的 group averaging、式 (10) 的完整原 jobs 转换、bonus normalization 保 OPT 和相对式 (12) 是本批第二源的独有正面结论。外部 2-近似只承担明确的辅助 MaxMin 步骤；不把它归为新 Santa Claus 算法。
5. 若第三阶段要把一致性接入普通 UM，必须给出真实任务、资格边和全部原 jobs 的低峰值解码，并保留 YES；只在 selector 语义上限定 affine/block/coordinatewise 不足以形成源约束。若要扩大 degree-two 算法，必须首先证明 degree、private machine、resource time 和 state identity 的新量词，不能靠增加有限 fixture 数量外推。
6. 主目标仍 OPEN。两源提供的是一个负面一致性标尺和一个限定类联合取整接口，未给一般 (2-\varepsilon) 算法、近二 hardness 或六人 SPE 的覆盖半数定理。
