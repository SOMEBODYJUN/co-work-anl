# 已核v1的精确对象

这里从[已有完整真单环正文](真单环双坏端点的三种实际基态与全支撑证明--审查.md)取**奇D≥3、L=D+2、N=DL**，不可把探索短稿未重写的D域扩大。t循环mod N，a(t)=t mod L；gcd(D,L)=1。机器K_(c,a)有2L台、G_(c,t)有2N台、Q_a有L台、Z_t有N台，c∈{0,1}。全部原任务/有限端如下，未列为∞：

| 任务 | 全部有限端及时间 |
|---|---|
| U_c | 所有K_(c,a)，时间1 |
| F_(c,t) | K_(c,a(t))上1/D；G_(c,t)上1 |
| H_t | G_(0,t)、G_(1,t)、Q_(a(t))，各1 |
| E_t | G_(1,t)、G_(0,t+1)、Z_t，各1 |

规模m=3N+3L、n=4N+2、有限端10N+2L。ρ=(L−1)/L、γ=ρ/2。基点x⁰为U各rail1/L，F home/outer为ρ/1/L，H/E两个G端各γ、停车1/L。

这不是仅行内CONFIG的假原子：写t=hL+r，0≤h<D、0≤r≤D+1，U₀放rail D、U₁放rail D+1，选中rail的D件F外送，其余F home；H/E逐件如下。

| offset r | H_t | E_t |
|---|---|---|
| r<h | G_(1,t) | G_(0,t+1) |
| r=h | Q_h | G_(1,t) |
| h<r<D | G_(0,t) | G_(1,t) |
| r=D | G_(1,t) | Z_t |
| r=D+1 | G_(0,t) | G_(0,t+1) |

每K恰1；G₁由H/E/F互补填一unit，G₀由前E/H/F互补填一unit，r=0接前block末E，包括全环t=0回绕；Q_h各一H、Z各至多自己的E。因此是完整峰1原子。同步旋转所有索引t→t+s及rail a→a+s mod L，U身份不变，s∈Z_N，取N等权原子。U/F边际如上；每block H的G₀/G₁计数D−h、h+1，E反向，求和均D(D+1)/2，停车D次，得到x⁰。unit U迫真实OPT=1，所有有限端边际严格正。

# 全段CONFIG和给定点拒绝

只沿H的G₀/G₁取+1/−1、E的G₁/G₀next取+1/−1，余坐标0。x(θ)相应权γ±θ，箱段[−γ,γ]。完整CONFIG(1)行证书为：K用singleton U权1/L及全部home F权ρ；G₀用F/H/前E三个singleton权1/L、γ+θ、γ−θ；G₁用F/H/E权1/L、γ−θ、γ+θ；Q用本rail的每个H singleton权1/L及empty权2/L；Z用E权1/L、empty权ρ。每行权1、容量1，任务边际守恒。

令x⁺=x(γ)，其H在G₁的边际全零。对**任意实际峰≤1调度**，U₀所在rail a已占unit，迫该rail D件F₀全部在各自G₀。对应D件H不能同G₀，只能到各自G₁或同一个Q_a；Q_a至多接一unit。因此真实T=1调度凸包满足全局有效式
\[
\sum_t x_{G_{1,t},H_t}\ge D-1.
\]
U₁对称给G₀方向有效式。这不是仅对所列基态成立，而是对全部实际调度成立。

取δ=1/D²，x^δ=(1−δ)x⁺+δx⁰。CONFIG凸性给完整CONFIG(1)；δx⁰给所有原有限端严格正，支撑就是原实例，真实OPT仍1。但
\[
\sum_t x^\delta_{G_{1,t},H_t}
=\delta N\gamma=\frac{D+1}{2D}<D-1.
\]
故这个**给定点**没有真实T原子分解。sound拒绝其分解不等于实例/当前支撑OPT>T；否则会错误拒绝一个明有完整峰1原子的实例。该cut可在本族指定箱端前截断，但未提供任意输入cut生成器或CONFIG强化oracle。

# 未来v2：低停车负载而不倒改v1

源另保rounding_new提出的未审扩域：D≥2、L≥D+2、gcd(D,L)=1、N=DL。同一任务表及上述作者基态在0≤r≤D+1不变；对额外r>D+1，增规则H→G₁,t、E→G₀,t+1。r=D+1及额外尾段的E连续填后续G₀；回绕到下一block r=0时，H在G₁或Q，故不撞。原先r≤D+1的G互补也不变，仍给完整峰1原子。

同步旋转的H之G₀/G₁概率及E之G₁/G₀next概率分别为
\[
p=\frac{D+1}{2L},\qquad q=\frac{2L-D-3}{2L},
\]
停车仍1/L。计数是H在G₀共D(D+1)/2次，G₁共D(2L−D−3)/2次，E反向；p+q=ρ。对应方向箱段变成[−p,q]，不能继续用对称γ。Q上D个H各1/L，分数负载D/L；Z负载1/L。取L=D²+1满足互素及L≥D+2，D/L→0；单位big-count仍≤1。

行CONFIG证书同上，把相应G权改成p+θ、q−θ，Q empty改成1−D/L≥0。两端H分别只剩G₀/Q或G₁/Q，E只剩另一G/Z。其正支撑真实OPT仍2−1/D：若低于该值，hard复制的U所在rail至少两F外送，迫至少两对应H撞同Q；上界可取两U都rail0，每复制仅一F_(c,0)外送，其余D−1 home，正端H₀→Q₀/E₀→Z₀，负端H₀→Q₀/E_(N−1)→Z_(N−1)，其余按对应G，全部任务合法峰2−1/D。

这些局部代数和回绕重构保留候选内容；**不是**把v2登记为已审canonical。源明说进入current前须另立v2、复核全原子计数及后置独立审查；不能把v1的odd D、L=D+2、对称γ认证扩称任意互素参数。扩大L可减停车分数负载，不自动修复方向/点再生或产生算法困难性。
