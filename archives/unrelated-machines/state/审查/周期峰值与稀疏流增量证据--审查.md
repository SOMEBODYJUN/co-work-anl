# 周期峰值与稀疏流增量证据

本页只整理本批四个已实读 JSON。它们属于 unrelated-machines 的异构机器/稀疏响应工具线，和共同目录客户吸引模型、设施菜单模型保持独立。字段中的有限赋值、循环、到达量和 Fraction 都按原始字节核对；没有把“在给定搜索域中通过”写成任意规模的定理。

## 1. 两作业循环的瞬时峰值

`089130e3487588be2f65` 的输入是 `examples/unrelated_machines/transient_peak_two_job_cycle.json`，目标赋值为 `[1,1,2,2,0,0]`，给出的静态最优值为
\(\operatorname{OPT}=1\)，而整条直接路径的峰值 \(U=9/4\)。路径从
`[0,0,1,1,2,2]` 开始，三个机器负载均为 \(7/4\)。依次移动作业 0、2、4、1、3、5 后，负载依次出现

\[
(7/8,9/4,7/4),\quad(7/8,11/8,9/4),\quad(11/8,11/8,11/8),
\quad(1/2,15/8,11/8),\quad(1/2,1,15/8),\quad(1,1,1).
\]

因此这是“最终配置最优但指定移动顺序经过临时峰值”的真实路径证据。源字段 `proof_reference` 指向 `pruned_first_move_and_transient_peak.md#4`；本页保留这个引用，而不是重新声称已证明一个更广的动态下界。用途是提醒后续任何局部修复/循环坍缩证明必须同时控制中间状态；静态 \(\operatorname{OPT}\) 不能代替路径峰值。该来源的独有内容已与原证明引用合并，不另造反例对象。

## 2. 加权组联合槽位的完整配置证书

`d2b9fdf6beb4c7e38afb` 审计的是给定 token rounding API 返回的**实际完整赋值**，不是抽象松弛。八个 witness 中，前两类有独立全枚举范围：

`private_assignment` 的深层数组在导出中以省略号标记，这是导出器的结构化缩写；本批没有据此恢复缺失任务，而只使用完整输出中未省略的负载、demand、slot_count 与 makespan 字段。该来源可接续到“联合槽位/私有负载的边界条件”审查，不能单独推出调度最优性、近似比或任意分母的统一构造。

## 3. 稀疏长环的有限有理表

`444fd6ed8f39f526fef1` 使用闭式有理权重 \(r=7/4\)，对 \(n\in\{1,2,3,10,30,100\}\) 枚举布局。客户数为 \(2n+4\)，布局数为 \((n+1)^2\)，最小/最大 reach 始终记录为 \(79/100\) 与 \(9/5\)。报告给出的最佳 factor 依次为

\[
\frac{237}{133},\ \frac{395}{223},\ \frac{553}{313},\ \frac{1659}{943},\ \frac{4819}{2743},\ \frac{15879}{9043},
\]

对应的显式环长度为 \(4,6,8,22,62,202\)（较大 \(n\) 未在 JSON 中保存完整 cycle 列表）。这批数值支持既有稀疏长环的算术核验；报告自身明确指出，任意 \(n\) 与所有 \(r<\rho\) 的结论依赖原文的符号不等式和有理稠密性证明，有限表不能独立承载这些量词。接续时应把这份 JSON 当作回归表和边界样例，原证明仍是主证据。

## 4. 高可达性探针与 tie negative control

`97bfcda419e2251dbdfa` 在 \(n=2,3,4,5\)、\(r\in\{1,3/2,9/5,2\}\) 上做 400 次 Fraction 探针。随机计数为 `pure_bad=2`、`mixed_bad=0`、`balanced=25`、`ties=272`、`zero_reach=31`。继承的 sharp lower 例保存 reach
`[144504187,80193772,144504186,180193774]`、固定环 `[0,2,1,3]`，静态 optimum \(80193772/44504187\)；把中间 tie 改成负控制后 optimum 变成 1。另一个六环样例 reach `[42,40,38,41,39,37]`，pure/rho 均稳定，optimum \(40/39\)，且 balanced。

这三个字段分开说明两件事：固定纯规则的稳定性可能被 tie 改写，而完整混合均衡的最优值是另一对象；有限随机攻击没有证明 `SPARSE-HIGH-ACYCLIC` 或 `SPARSE-RHO-ALL` 的全称界。该来源的独有用途是给出负控制和量词分离，保留原审查中的“不能把固定纯规则失败写成全局均衡失败”。

## 5. 处置、证据与接续

四个 raw JSON 原字节已冻结到 `archives/unrelated-machines/tools/evidence/extra-cycle-flow/`，其清点和 SHA-256 见同目录 `manifest.json`；本轮还用 Python `json` 解析全部字段并用 `fractions.Fraction` 解析所有分数样式值。证据等级分别是：089 为实际路径的显式有限峰值；d2 为实际完整赋值的有限配置证书；444 为闭式族的有限回归表；97 为有限随机攻击与 tie 对照。没有一项替代已有一般证明，也没有一项给出 unrelated-machines 的通用优化器。

与先有对象的关系是：089 合并进已有“首次移动/瞬时峰值”证明引用；444 与 97 作为稀疏长环/可达性边界的增量审查；d2 作为加权联合槽位边界的独立证书。暂不建立跨模型边：它们没有共同的客户目录、SPE 或设施菜单量词。后续若建立图边，应以“有限证据支持/量词障碍”语义连接到相应 unrelated-machines 定理或障碍对象，而不是迁移到 CAG。
