# 实读和复跑边界

三项 source 均 clean show 导出并逐行读取。shared_ud 程序本地 exact audit 状态 passed，记录 26674 个 feasible original resource ownerships、160 heterogeneous lambda cases 和 160 changed-helper same-outer cases；signed_one_job 程序本地 exact audit 因缺少 examples/unrelated_machines/signed_one_job_port_sharp_profiles.json 依赖而未完成注册 fixture，但源码中的随机/边界审计逻辑已逐段核对。seven_state_star 程序的 d=4/8 小例和 d=1000 参数循环会枚举 degree-6 masks；本轮尝试全量运行未在窗口内生成输出，故不伪造计数。

# 共享 UD 最优交换

shared_ud_optimal_exchange_small_network_audit.py 直接枚举原始 resource ownership、leaf matchability 和 weighted profile exchange。它不调用 matroid exchange、potential formula 或 proof coupling；每个 ownership 通过 leaves_fit 检查实际 leaves，optimal_vectors 枚举可行 assignment，比较 old profile 与 helper change 后的向量。审计以 240 个随机小网络为主体，另检查 extreme weights、同 outer helper 改变和所有可行 ownership。该程序只验证小网络中 exchange vector 的有限关系，不给 19/10 近似或一般 scheduling solver。

# 有符号单 job 端口

signed_one_job_port_downset.py 的对象是每个 port 只有一个内部 endpoint 和一个 global bit。它显式构造两个 uniform internal assignments，允许翻转单一 port 的 incoming bit，并验证 downward projection 的 loads、witness profile、strict bound 与 mixed result。程序强调 external capacity 被排除，multi-job encoding、shared external capacities 和求 uniform assignments 都不在范围。缺失的 signed_one_job_port_sharp_profiles.json 只影响 registered example 回放，不改变代码对边界条件、Fraction arithmetic 和 invalid input 的语义。

# 七态星 global quadratic

seven_state_star_global_quadratic_audit.py 生成 private star 的 raw/global quadratic signed slack。固定偶数 d 与 s，检查 row first/pair law、对称 signed slack 的 PSD、full M3 与 global quadratic signed slack，并枚举小 d 的 assignment states 和 degree<=6 moments；实际 OPT=1 的原任务总在其 unique home。主循环还要求 d=1000、s=500 等参数并生成 masks，规模随 d 迅速增长，因此本轮只做源码阅读和运行边界记录。该审计不证明 deep internal-child budget、growing-depth law、general gap 或一般算法。

# 处置

三源均处置为 integrated。shared_ud 的 exact JSON、signed_one_job 源码和 seven_state 源码保存在 batch6 evidence；seven_state 的未完成大规模运行与 signed_one_job fixture 缺失如实记录。所有结论限于各自星/端口/共享资源合同，不升级为一般 unrelated-machines approximation、NP-hardness、外部新颖性或 customer-attraction/SPE 结论。
