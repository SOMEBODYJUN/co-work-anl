# 2. Exact限定的是完整模板与局部证书

有限CNF每clause k_c≥2，每真实occurrence身份唯一且只属一clause，重复文字/变量允许。变量环显式padding到至少3索引；只保出现变量，dummy不属clause。q_i原外端恰两个ring端[0,T]，真实b_i唯一polarity pin[0,T]；dummy b仅原D_i:T，不能进ring。每H_c/A_c私有互不共享，辅助只能自身内部，全部原demand/guard必须列A_c且始终执行。内部任意非负异权/∞、zero及未用finite>T均允许，无其它任务/预载/资格。

每索引λ_ci仅实际覆盖A_c+q_i+(R_c减b_i)的H_c内部模式且全H_c≤T，不是全局strict源调度或SAT赋值。显式提供全部λ才有算法；仅存在它们只给条件性OPT≤3T/2存在性。source bit-polynomial还要求环/内部网络/证书本来由源显式多项式生成；额外padding或压缩未展开网络不能免费计规模。

计算输出覆盖原全部2N+a任务，原机器N+H+d，ring每机恰一原q或真实b、H_c≤3T/2、dummy D_i:T，在同一τ内全部同时受控。空公式独立一idle机/零任务/OPT0；空或unit clause不属域。T>0与零内部/外部时间是不同条件，不能用T正排除zero端。

这与局部私有outside Claim的对象不同：主原P没有那些测试O或分析标签，最终ring容量必须另证。其“任意SAT/UNSAT”只量化满足完整模板和全部局部可选前提的输入，不是一般UM三半算法或所有source compiler不可能。

两图分数均为分析matching质量，不是UM处理时间或拆分执行。q在pin扣θ由同号b或B补回，每原M列恰一；K/V或C列及所有行恰一。对**任意左子集**流求和得Hall，而非只核整图总数。一次共同整数匹配同时协调所有clause返回pin与其它q，避免逐clause选pin后竞争冲突。
