# A：分数 benchmark 重匹配引理

所有 statement 版本的 A 段具有相同对象：有限物品集 (U)，恰含 (n) 个不同物品的 (H)，残余 (B=U\setminus H)，有限有理配置族 (y)，正 benchmark

\[
\mathcal B(y)=\exp\!\left(n^{-1}\sum_{i,S}y_{i,S}\ln v_i(S)\right),
\]

以及对**所有**可行残余分数配置族的预算

\[
\sum_{i\in A,T\subseteq B}z_{i,T}v_i(T)/V_i\le cn.
\]

目标是选 (H) 上双射 (pi)，使

\[
\left(\prod_i(V_i+v_i(\{\pi(i)\}))\right)^{1/n}\ge \mathcal B(y)/(c+1).
\]

`rank v1` 独立重建了：把配置质量按真实物品身份投影到 (H)，用残余分数预算与 (H)-出现次数预算控制总比值，再以 Jensen 和双随机矩阵分解抽出置换；零 singleton、(V_i=0)、(A=\varnothing)、(B=\varnothing) 均需分支。它同时给出有限位最大乘积匹配：两个不同有理乘积之间有显式指数分离，用有理对数近似即可确定性求真最大积。

`rank v3` 再次核对 A 的量词，明确不能用一个整数分配福利界替换“所有残余分数族”。`author v5` 的 §2 逐项给出配置标签、运输补缺口、正性和 Birkhoff/Hall 分解；其 §1.1–§1.2 给出有理对数级数和精度界。三者互相一致，因此 A 可作为完整证明对象接入正式存档。A 的输入前提仍是语义承诺；算法不负责验证任意 value-oracle 的次可加性或 A2。

# 版本差异与 backend 结论

## statement v1 与 rank v1

v1 只提出 A 及条件 backend 接口 E1–E3：E1 需产生 (V_i) 和全分数残余界，E2 需对每个比较匹配给出统一后续 rematching 保证，E3 需位复杂度与成功概率。v1 的 `rho=10^{12}` 只是 backend 验证后才可使用的候选安全常数。rank v1 只认证 A、unit-FSLP 的正支持 benchmark 和低质量组计数的代数结构，不把 DLRV 的实际 OPT 近似定理升格为 log-CONFIG 分数定理。

## statement v2 与 rank v2

v2 保留 A 的全部文字，修正下游常数，并增加内部逐坐标 floor：

\[
\widetilde p_{i,s,j}=\frac1{4|U|}\lfloor4|U|p_{i,s,j}\rfloor,
\]

使每个原 clause 总量至少 (3/4)，同时保持 (widetilde v\le v)。rank v2 逐集合核对这一 floor、(3/4) benchmark 与 (\rho=2^{24}) 的安全放宽，但仍明确 E1–E3 未被执行或独立证明；它不把 floor 的内部权重当成原物理处理时间。

## statement v3 与 rank v3

v3 在 B 中保守保留 factor-three，加入 shared singleton REPAIR 和完整 flat-UM 计数接口。rank v3 找到旧一般次可加 tail 链的两类边界：旧 (mu) 代回漏了因子 3；对移位 (f=v+\nu) 直接套 Theorem 20 的 singleton 前提不成立。因此不能照搬 (60000)、(1{,}125{,}000) 等旧数字；C 的 unit 证书/LP/floor 代数、D 的 shared-singleton 组合论、E 的全 job 物理转换只在各自前提下成立。

## 作者 Proof v5 的修正范围

作者稿不再依赖上述一般次可加 tail 链，而在显式有限 XOS 菜单上给出固定 lift 的有理迭代、支持 clause 的确定性 CDF welfare rounding、逐候选分裂、candidate-local (Q=210|B|) floor、移位 Bernoulli inverse-moment、有限 mask DP，以及对任意 comparison bijection 的最终最大乘积重匹配。它还保留原始 indexed state、全部 incidence job 和共享 repair state 的 flat-UM 调度。

其 §7.3 给出 (1/(60000d^2)) 的比较因子；与 A 的 (c=2)、(d=5/2) 合并，benchmark 因子为 (1/1{,}125{,}000)，另留固定二倍安全余量为 (1/2{,}250{,}000)。归一化 unit-FSLP 分支再给严格 (1/3{,}000{,}000>2^{-24})，故只有在 v5 的 backend 前件成立时才可采用 (\rho=2^{24})。这些数字不能回填 v1–v3 的旧一般次可加合同；本次没有执行审计或独立复核所有实现细节。

# C、D、E 与适用边界

C 的 unit-FSLP 证书把每个正 clause support 当作值一的分数配置，故 item-inequality log-CONFIG optimum 为零；低质量组排除只以原始菜单组数 (n) 为分母。D 的 shared singleton REPAIR 只处理同一 (n) 组、同一组每个 repair state 使用独立共享资源的承诺 gap，YES/NO 分离依赖 C 的条件 backend 和正 slack (gamma-a)。E 保留每个 indexed state、resource、selector 和显式 incidence job，用原始系数安排完整 flat-UM 调度；内部 floor、mask 标签、LP 变量不是物理作业或机器。不能由 C–E 推出所有组有统一正质量、一般 UM solver、source hardness、P=NP 结果或六人 Q-CAG-HALF。
