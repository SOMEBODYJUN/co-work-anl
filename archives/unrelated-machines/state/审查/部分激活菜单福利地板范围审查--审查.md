# 部分激活菜单福利地板范围审查

本文只核主源 e7736babc411473bec2a 的 F2 身份及其关联审查 a0ffc0bf14eee80c5fce，不把同页 A–E 的分数 NSW、matching、LP 或普通 flat-UM 结论自动并入本对象。当前 clean show 主源副本为48118字节、SHA256 9ef11b3f69d786c4a89f3e575f0cce60cc5d611c2fbad61cdabd3d642aaea33c；审查副本为9313字节、SHA256 310ac795bc0c8dde547d32b51709acf792126f7e7e258dec5cc0c95aa07833bb。历史记录曾给出 F2 章节 hash 8972edd52e7bb4f61fe8ae5665f51118d23765ae7645fecf0e2cef94e2f19755；本轮证据 JSON 另记录当前 clean show 的字节范围和 hash。

## 1. Exact-first 顺序与对象域

关联审查记录了先只读精确陈述、独立重构独立抽态和最高出价福利，随后才读作者 F2；第二阶段补入 row mass≤1、总质量q的部分激活扩展，并发现必须对 \(W-\delta A\) 同时计费，不能把实际激活数擅自当作q。最终读后另核作者状态、F2范围及规范脚本接口。

实际 F2 域为显式归一化菜单：每个 state 的全资源权恰为1，允许零项、重复 indexed states、整行零激活和 unused resources。给定有理 \(\lambda\) 满足每组 row mass \(a_g\le1\)、总 mass \(\sum_g a_g=q\) 和正支撑列容量至多1。列约束不按权值加权，零系数不占容量；q>0才进入严格 \(H>2q/5\) 结论。

## 2. 福利下界和激活罚项

独立抽态后，资源总 welfare 为
\[
W=\sum_u\max_g\mathrm{bid}_{gu},
\]
active 组数为 \(A\)。对每个资源的阈值事件，正支撑列约束给 \(\sum_g r_g(t)\le1\)，故
\[
\mathbb E W\ge(1-1/e)q,\qquad \mathbb E A=q.
\]
固定候选 state/inactive 时用有限 CDF 精确计算条件期望；目标
\[
\Phi=W-\delta A
\]
的父期望是子期望概率平均，逐组选最大子期望即可确定性去随机化，且最终 \(\Phi\ge(1-1/e-\delta)q\)。

审查特别确认实际 active 数可能大于q；罚项是必要的，不可只最大化W再把A写成q。每个正出价资源交给最高 bidder，随后重新遍历原菜单取真正 attaining state；这一步避免把抽中的 indexed state错误当作实际最优 state。

## 3. 高组计数和严格边界

若 \(H_\delta\) 组质量至少 \(\delta\)，低于 \(\delta\) 的 active 组对 \(\Phi\) 贡献非正，其余每组贡献至多 \(1-\delta\)，故
\[
\Phi\le(1-\delta)H_\delta.
\]
于是
\[
H_\delta\ge\frac{1-1/e-\delta}{1-\delta}\,q.
\]
取 \(\delta=3/8\)，由 \(e>65/24>8/3\) 得 \(H_{3/8}>2q/5\)。严格号来自 \(q>0\)，不要求 q 或 \(2q/5\) 整除；q=0必须单独处理。

给定见证的 promise 筛选也保持准确量词：若 YES 有至少q个质量1组，则从其 attaining norm1 state 取 \(\lambda=q/r\) 构造式 (1) 的 LP 见证；若 NO 中每个 allocation 的质量至少3/8组数严格小于 \(\beta q\)，且 \(\beta\le3/8\)，LP 可行将产生 \(H>2q/5\ge\beta q\) 矛盾。LP 不可行只排除该显式源的 YES，不是一般 UM 的 FAIL 证书。

## 4. 位复杂度和软件边界

条件期望只使用有限出价层、输入概率的有理和与乘积；不计算e、不做微小事件的反复Bayes除法、不按 \(1/q\)、\(1/\lambda\) 或原分母数值展开。审查历史记录报告其本人读取规范脚本并进行15次定向运行，同时另有1440、27648和极小q的inline辅助枚举；本轮把这些作为冻结历史证据，不计作新的运行，也没有读取或复制冻结JSON。

规范脚本的历史 hash 为 ee41f5fd20993dff6ecdf7103d5930793654201557b83c293f9b929e3d971e53。完整枚举审计、软件源实现和外部Feige/DLRV证明都不属于本对象的本轮新核验。

## 5. 与旧F范围及private-tree对象的纠错

源审查保留了旧F高组/低组比例混淆的实质纠错：robust NO 的高质量组上限与 C–D 的低质量组下限必须取互补，不能把同一个 \(\gamma\) 直接交换。F2 的 \(\beta\) 是禁止的高质量组比例，不能误写为旧F使用的低质量比例。该纠错只修正集合互补和适用范围，不扩大为一般 UM 的正反面证明。

[三坐标零权切片的精确菜单嵌入](../定理/三坐标零权切片的精确菜单嵌入--定理.md)、[完整菜单的资源度三路径归约](../定理/完整菜单的资源度三路径归约--定理.md)和[归一化菜单的三态资源度三正规形](../定理/归一化菜单的三态资源度三正规形--定理.md)分别处理表示、资源度和三态；它们不提供本页的部分激活 LP 见证或激活罚项。已有[资源失真平菜单的有限矩阵审计边界](../计算/资源失真平菜单的有限矩阵审计边界--计算.md)是另一 source 的945-case有限记录，不能代替本页全称证明。

## 6. 保留范围和未解义务

当前清洗接受：给定显式 norm1 菜单、正支撑 LP 见证和 \(q>0\)，F2 的福利地板、确定性有理去随机化、3/8严格号、promise筛选和位复杂度边界均在限定范围内成立。

未升级的事项包括：A–E 分数 NSW 结论、全组 max-min、一般 XOS/subadditive 或 oracle-only 输入、普通 UM 全矩阵近二调度、F2 规范脚本完整枚举、外审/全球新颖性、以及一般 UM-TARGET-v1 的正反面。
