# 1. v3保持的合同与真正新增项

一般ordinary UM矩阵显式给出，机器有限非空、任务有限，有限时间为非负二进制有理，其余为 \(\infty\)，每任务至少一有限端。输入同一 \(P\) 的两份完整实际分配 \(\sigma_0,\sigma_1\)，各机负载至多有理 \(T>0\)。令
\[
D=\{j:\sigma_0(j)\ne\sigma_1(j)\},\quad
\varnothing\ne Q\subseteq D,\ d=|Q|,\quad
\beta\in[3/2,2)\cap\mathbb Q,\ c=\beta-1.
\]
使用作者分离v2同一固定 \(I_i(q)>T/2\) 染色。\(A_q\subseteq D\setminus Q\) 两两不交且不依赖 \(\beta\)/权，\(\tau_q\) 恰改派 \(\{q\}\cup A_q\) 至原 \(\sigma_1\) 端，全部其它原任务保留 \(\sigma_0\)。所有原任务各一次，查询身份和目标不替换；不输出任意子集cube，不调用未知可行调度搜索。

给 \(D\setminus Q\) 非负有理改派权，\(W=\sum w_j\)、\(f_q=\sum_{A_q}w_j\)，则 \(\sum_q f_q\le W\)。两实际见证、一般端时间和零端始终保留；没有后加unit/home/typed、查询单件小或heavy作为分离v2的前提。分离v2本身还允许 \(T=0\)，计数单列 \(T>0\)以使用质量比，不能反向缩窄前文一般定理。

定义重源机数及实际good集
\[
L_i^Q=\sum_{q:\sigma_0(q)=i}p_{iq},\quad
R_\beta=\#\{i:L_i^Q>cT\},\quad
G=\{q:C_{\max}(\tau_q)\le\beta T\}.
\]
作者Proof取**全部实际good**，用原矩阵逐机精确回算即可识别；坏query的最小编号超载机必须标其色且严格重，唯一机色给单射，故 \(|G|\ge d-R_\beta\)。\(R_\beta<d\)时在同一非空G内平均，至少同一个query同时满足实际负载界和 \(f_q\le W/(d-R_\beta)\)。这不是分别找一枚可行query和另一枚低费query，也不需为筛选重染或找一份新全局调度。

v3真正新增的无统一 \(\eta\) 项为
\[
H=\#\{q:p_{\sigma_0(q),q}>cT\},\quad S=d-H,
\quad |G|\ge\lceil S/2\rceil.
\tag{1}
\]
这里 \(R_\beta\)数机器聚合重，\(H\)数单件heavy，不能混成同一计数。含heavy重机可选一枚heavy作见证，源组不交，至多H台；不含heavy重机单件均 \(\le cT\)，严格聚合 \(>cT\)至少两枚nonheavy，至多 \(\lfloor S/2\rfloor\)台。含heavy机器额外消耗nonheavy只会放松此上界。于是 \(R_\beta\le H+\lfloor S/2\rfloor\)，结合旧计数得到(1)。general独立审查特别指出第一类计数本身不需额外用 \(c\ge1/2\)，但整个结论仍保留原 \(\beta\) 域，不能据一个局部观察扩域。

# 2. “故收费”承接前句，不能脱离条件

v3 Exact新增段有 \(|G|\ge\lceil S/2\rceil\)后“故 \(W\ge\lceil S/2\rceil F\)”的简写，作者Proof新增段也沿用前文费用条件。两独立read-after/final均明确按以下前提阅读：**每个**符合指定单query模式、峰至多 \(\beta T\) 的合法实际分配，都在同一非query改派费合同下至少费 \(F>0\)。此时每个构造good也须收费，故
\[
W\ge\sum_{q\in G} f_q\ge |G|F\ge\lceil S/2\rceil F.
\tag{2}
\]
无此普遍F假设，零权即可使W为0，不能仅从计数获得正费下界。被引用的F必须仍是同一指定非负改派费；若实例化新增unit费，只对旧非unit、新unit的非query改派计正权，旧unit背景费和退款不能冲抵W。

若另给有理 \(\kappa\ge0\)、\(W\le\kappa F\)，(2)给整数 \(\lceil S/2\rceil\le\kappa\)，所以
\[
\lceil S/2\rceil\le\lfloor\kappa\rfloor,
\qquad S\le2\lfloor\kappa\rfloor,
\qquad \boxed{H\ge d-2\lfloor\kappa\rfloor.}
\tag{3}
\]
取整后的必要界比可推出的较弱实界 \(H\ge d-2\kappa\)强，不能把非整数κ当整数。\(W\le F\)时至少d−2枚初态query严格大于cT；写 \(\beta=2-\varepsilon\)须保 \(0<\varepsilon\le1/2\)，heavy准确是旧时间严格 \(>(1-\varepsilon)T\)。它是给定两actual与收费合同下的必要形状，不是充分性、gadget存在性、OPT gap或一般UM反证。

本轮从现canonical恢复的同SHA历史快照第5节，明确在式(9)和heavy段内再次写“若每单query……必付F”，实际字节支持上述前句作用域解释，不需改动原v3 Exact字节来伪造局部完整陈述。

# 3. 零端点、严格边界与平凡结论

| 端点/参数 | 准确结论及原因 |
| --- | --- |
| 单件旧时间恰 \(cT\) | 属nonheavy；一枚单件至多cT不能形成严格重机，因此至少两枚的分组仍对。旧零端同属nonheavy。 |
| \(S=0\) | (1)只保证零枚good、(2)仅 \(W\ge0\)。不能凭空保证某singleton可行。 |
| \(\kappa=0\)或 \(0<\kappa<1\) | 在F条件及W上界下，\(\lfloor\kappa\rfloor=0\)，必要S=0、H=d；不声称这类形状可实现或所有singleton可行。 |
| \(\kappa\in[1,2)\) | (3)要求S≤2，κ=1.9不能放宽成S≤3；核心是 \(\lceil S/2\rceil\)为整数。 |
| \(W=0,F>0\) | 非负费总和≤0，而每good必须≥F，故实际G为空；再由(1)迫S=0。没有负费、也没有可行性承诺。 |
| \(W\le F,d\le2\) | H≥d−2可为平凡下界；右侧为负的必要界不构成错误，更不能当存在性证明。 |
| 某query没有峰≤βT合法singleton | 对该模式的普遍F下界可以空真；只能对实际G中已构造的good应用(2)，不能据空真补造actual。 |
| \(\beta=3/2\) | 未标本色机负载≤3T/2恰为闭阈值，严格超载仍只能来自标本色机，单射无等号漏洞。 |
| \(\beta\uparrow2\) | 允许任意小正ε，但2不在域内；不能取ε=0声称端点结论。 |
| \(T=0\) | 分离v2输出全零合法；计数v3正T质量比不使用这分支，两身份不冲突。 |

v3保留v2已有的零/正η分支：若每query旧量≤ηT、0≤η<c，η=0时全部d合格及某费≤W/d；heavy给的至少ceil(d/2)只是同时成立的较弱界，不能替换全d。正η严格good数 \(>(1-\eta/c)d\)，整数至少 \(\lfloor(1-\eta/c)d\rfloor+1\)；另有 \(s=\lfloor c/\eta\rfloor+1\) 分组界 \(|G|\ge d-\lfloor d/s\rfloor\)。c/η恰为整数仍加1；W=0保非严格费用。实际源总量0但采用正η上界也覆盖；不存在因新增heavy而撤销旧零端修复的版本变化。相关完整反例及分支证明保留在前述零边界页。
