# 1. 逐行均匀相关读出：整数势、共同匹配与 flat-state 编译

对简单二部图、每条左行逐行均匀的单位资源映射，固定其它左标签后，左点改标签的碰撞势差正好等于该行新旧碰撞成本差；同一左点不同测试不自碰撞。逐行均匀平均使稳定终态的整数碰撞成本 `C_u` 满足 `C_u≤d_u−1`。整数不等式
`1/c >= 1-(c-1)/2` 给出请求资源权重总和至少 `(d_u+1)/2`，全局增广匹配同时支付 `ceil(d_u/2)`，从而得到真实共同读出 `F`。这一步不能改成逐左局部可支付的拼接。

实读保留了三个容易误用的边界：孤立左点先删零配额再做 Hall 计数；四条平行 identity 请求和纯列完美匹配反例说明简单图/互异测试资源是承重假设；实现的 361 输入、343 个完整 2×3 图、1646 个 profile 和 32768 个三角调度只验证列明有限域。flat-state 编译把 selector、port 和单位外机接起来，得到显式子类 `3/2` 负载上界，但不识别任意 UM 矩阵，也不宣称精确最优。

# 2. 强配置共同匹配矩：局部可检验与真实 law 分离

固定 `r>=2`、奇数 `N>=4r−1` 的 `K_{2,2}` 块族可取 Boolean slice `t=N/2` 的 harmonic Gram 泛函，满足固定阶 PSD、one-hot、短 mixed-cylinder 正性和 row CONFIG 相容。若真实完整匹配 law 保留指定一阶与跨块二阶，则每块状态 `B_s` 的和具有均值 `N/2` 且方差 0；奇数 `N` 使整数值和不可能恒为半整数。只保一阶、允许改二阶时，精确最小最大 pair 误差为
`Delta=1/[4N(N−1)]`，说明强矩接口的失败是全局整数支持障碍，而不是 `OPT=1` 实例的调度 gap。

读后还复核了 `N=5,7,11` 的 Schur/PSD fixture、短柱面和 variance 证据：`N=5` 不满足全部短事件正性，后两组满足记录的强化域；这些数字不替代 harmonic 一般证明。有限程序和 Potechin 背景只作范围内比较，不能写成一般算法、NP-hardness 或六人 SPE 负面结论。

# 3. 两源不能静默合并

逐行均匀源的缺口是“同一标签在多测试中的共同选择和全局资源匹配”；强矩源的缺口是“局部 PSD/CONFIG 矩看似相容却没有真实整数支持”。前者的正面结果依简单图、逐行均匀、互异资源和一次整数匹配；后者的负面结果依固定阶、奇数块、跨机器二阶保持。逐行 source 的 flat-state `3/2` 编译不能修复强矩的整数 law 障碍，强矩的 `Delta` 修复半径也不提供逐行资源读出算法。两者均不推出一般 UM near-two 算法/困难性，不进入当前六人 SPE 目录目标。
