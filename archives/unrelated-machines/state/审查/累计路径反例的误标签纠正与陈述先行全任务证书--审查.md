# 反例的完整对象：不是只画一条逻辑路径

源SC为3名agents和2枚不可拆items $u_1,u_2$，各人对每件原value都是3/5，行总6/5。允许不分物品，每件至多一个owner。任意分配至少一人无item，非负性给真实max-min OPT0。单人的unit路径却合法：cap在1的累计credits是先3/5、再2/5；第二item的原value仍是3/5，没有改成2/5，也没有舍入或DAG merging。

被攻击的**新增规则**是：一步take credit $c\in(0,1)$ 用质量1的additive state $\{\text{原item}:c,\text{下一own}:1-c\}$；下一节点有own singleton/off，末节点有fresh accept singleton。这在full threshold1时看似迫item和continuation同取，但positive partial可只取continuation。对每个 $a=1,2,3$，全部真实菜单如下，$x_a,y_a,z_a$ 彼此及跨a互异，而 $u_1,u_2$ 全局共享：

| group | indexed state | 资源及private权 |
| --- | --- | --- |
| $r_a$ | take1 | $u_1:3/5,\ x_a:2/5$ |
| $m_a$ | off | $x_a:1$ |
| $m_a$ | take2 | $u_2:2/5,\ y_a:3/5$ |
| $l_a$ | off | $y_a:1$ |
| $l_a$ | accept | $z_a:1$ |

每state各有不同private机，每不同resource恰一resource机；每group恰一件selector，时间1，仅该组全部state private有资格。每state-resource incidence是不同原job，只在自己的private用表内权，或在对应resource机用1；余端∞。无额外job、预载、免费逻辑或删除的off任务。同名 $x_a$ 的r/take1 incidence与m/off incidence是不同jobs，后者可留自己private，不能因共享外端就合并原jobs。

每a是3groups、5states、7incidences；全体9selectors、15private、11resource、21incidences，共26机器30任务。selector有限端15，incidences各两端42，共57有限资格。所有state质量恰1，全部未选states的jobs必须执行。

这是常数规模的完整显式P，有限时间只有1、3/5、2/5；没有隐藏展开、阈值倒数循环或求解器假设。其解析反例足以否定所列全输入decoder合同，但常数矩阵本身不提供一般算法或复杂性困难性。

# 完整证明及30行实际证书

令V为每group选一个state并领其任意真实资源子集，跨group不交时，最大化最小private质量。选择take1/take2/accept，分别领 $x_a,y_a,z_a$，九束全局不交，质量分别2/5、3/5、1，故V≥2/5。若某分配全组minimum>2/5，每个r的唯一state都必须领取u1，三个r不能同时领取同一不可拆资源，矛盾；不限制m/l选态或其它束形状，故V=2/5。

# 为什么不反驳已有selector-tree正规形

原source声明读过的接口wholeSHA为 `5e3f12dff54e770ff4afeae4201ef7f5c21536f0243858708fc24e3449439b41`，对应本批实际全文读取的[组合主源744a](../../tools/evidence/cumulative-path-review-correction/comparisons/degree_three_weighted_menu_cube_embedding.md)第8–9节及现[三态资源度三正规形](../定理/归一化菜单的三态资源度三正规形--定理.md)。该定理的输入本来就是显式normalized flat菜单，tree的每个leaf是**已有完整原state**，其全部原incidences及private/resource有限端真实保留。root的正值singleton迫沿child-own继续，最终只提取一个真实原state的原partial子集；没有承诺把路径上多个原items组合成新的AND。off-path可额外激活，逆向仍保全部原jobs；K1直接原位。

E candidate把本应同取的items分散为沿路additive states，再把终leaf换成fresh accept singleton。这是新增且被本反例否掉的接口，不是对正规形假设内“完整原state leaf”的反例。原SC每行总6/5也不是免费获得的norm1原state。本批全读组合源不等于给其中其它cube/path命题追加新认证或done；这里只用实际§8–9来核该范围区别。其它AND/guard或完整leaf合同须各自分析。
