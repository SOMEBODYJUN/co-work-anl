# 1. 处置范围和对象身份

本批三个冻结来源属于 unrelated-machines 存档，但分成两个数学对象处理。第一源是长链替换后配置解的有限联合投影审计，承重的是正文中的一般森林耦合、长链整数下界和围长参数化证明。后两源是私有汇点族的独立有限核验：一个核验逐行负载/计数合同，另一个核验保留固定最优凸包边际且只施加同汇点任务两两负相关时的精确概率边界。它们没有合并成一个“更强算法”或共同 gap 定理。

主模型仍是每个任务可在其有限可用机器上运行的 unrelated parallel-machine makespan。所有本批结论都把 OPT=0、空任务、零处理时间和任意平局保留为模型边界；涉及比值的陈述只在 OPT>0 上取上确界。有限脚本使用 `Fraction` 或整数缩放，不调用浮点容差、LP/SDP 求解器或随机种子。

完整读过的相关正文和程序包括：`long_path_coalition_gap.md`、其独立 `long_path_coalition_gap.py` 与 `independent_coalition_gluing.py`；`optimal_hull_marginal_rounding_barrier.md`、`optimal_hull_marginal_review.md`、`private_sink_marginal_barrier.py`、`independent_marginal_row_oracle.py`、`independent_marginal_pairwise_oracle.py`。后者是必要的跨文件比较：两个边际审计 JSON 本身没有把模型定义和一般证明重复写全，必须回到规范正文检查量词和缺口。

# 2. 长链联合投影：一般证明与精确范围

## 2.1 CC_r 的定义和森林耦合

对每台机器 i 的负载至多 T 配置集合 `C_i(T)`，配置解 y 给每个任务恰好一次的包含边际。`CC_r(T)` 要求对每个机器集 U、`|U|<=r`，存在 U 内互不相交配置的联合分布，且每台机器的**完整配置**边际仍等于 y_i；不同 U 不要求在多机交集上相容。因而它强于只检查 `x_ij` 的局部投影，却弱于完整的 Sherali–Adams 或全交叠一致性层级。由完整整数调度的点质量可知

`T_CONF <= T_CC,r <= OPT`。

若机器多重图简单且诱导子图 G[U] 是森林，可把每个树分量定根。先按 y 抽根配置；对子 v 与父 u 共享任务 e，在给定父状态下只在 `1_{e in S_v}=1-1_{e in S_u}` 的条件事件中按 y_v 条件抽样。任务守恒给两个条件事件的总概率恰为该父触发概率，因此子节点完整配置边际保持 y_v。森林中每个节点只有一个父约束，不会发生条件冲突；边界任务不能造成 U 内重复，内部任务恰选一次。这个递归是一般证明，不是脚本字段检查。

于是 girth 大于 r 时所有 `|U|<=r` 诱导图都是森林，原配置解自动满足 `CC_r`。证明只保留单机分布，不声称不同 U 的联合见证可以拼成一个全局分布。

## 2.2 长链替换和整数最优值

原经典两树族固定 k>=4，`c_k=2-1/k` 为整数最优值，`T_k=1+1/k` 有配置证书，终端父点 v 与终端点 t 之间有 k 条平行任务。把每条平行任务替成长度 `ell>=2` 的独立 v--t 路径：首边在 v 的时间为 1/k，在第一个内部点为 1；其余边两端时间为 1。不同路径的内部机器互不相同。

若新实例存在 makespan `<c_k<2` 的调度，则一条路径若首边给第一个内部点，该点已有单位负载，第二边只能向右；归纳后末边必须给 t，故整条路径可收缩为原任务给 t。若首边给 v，则收缩为原任务给 v。收缩不会增加原机器负载，矛盾于原族的精确 `c_k`。反向地，从原最优调度沿路径向左或向右延伸，每个内部机器只接一个单位任务，得到新实例值恰 `2-1/k`。

配置证书也可沿同样路径延伸：v 的首边替代旧终端任务，t 的末边替代旧任务；每个内部机器以概率 1/k 选左边、以概率 1-1/k 选右边。边际覆盖仍为 1，阈值仍为 `1+1/k`。图是简单图，终端 gadget 的任意环长恰 `2ell`，树宽为 2；这说明围长可以任意增大，但不提供一般求解器。

因此正文的两个一般身份成立：

- `UM-LONG-PATH-GAP-v1`：每任务恰两台可用机器、简单图、围长至少任意给定 g>=3 的合法输入中，配置 LP 整数间隙上确界仍为 2。
- `UM-COALITION-PROJECTION-GAP-v1`：同一输入类、任意固定 r，`CC_r` 阈值的整数间隙上确界仍为 2。

取 `2ell>=g` 且 `2ell>r`，森林耦合使长链证书满足 CC_r，给出下界 `(2-1/k)/(1+1/k)=2-3/(k+1)`；k 趋于无穷逼近 2。上界 `OPT<=2T_CC,r` 只使用配置边际和已知的 ST 型舍入界。结论只排除“相对 CC_r 阈值统一达到 2-epsilon”的合同，不排除全交叠一致性、树宽动态规划、全局组合下界或相对 OPT 的算法。

正文还给出一个正面边界：若所有至多三机器的联合分布在所有交集上的完整配置边际都一致，则树宽 2 族可沿 separator 条件耦合成全局分布并得到真实调度。这是对本批负结果的量词限制，不能被省略。

## 2.3 有限审计实际覆盖

冻结审计对 `(k,ell)=(2,2),(2,3),(3,2),(3,3),(4,2),(4,4),(5,2)` 建造证书，机器图围长均为 `2ell`，并在边数不超过 20 时独立枚举全部取向。记录的完整枚举包括 `(2,2),(2,3),(3,2),(3,3)`；例如 k=3、ell=2 的 8192 个取向最优值为 5/3，k=3、ell=3 的 524288 个取向最优值为 5/3。k=4、ell=2 与 k=4、ell=4 的显式调度值均为 7/4，k=5、ell=2 为 9/5；这些值与一般收缩证明一致。

独立 coalition gluing 程序另外在 k=2,3、ell=2,3 上枚举路径取向与森林联合状态：最大 coalition 大小分别取 `min(3,2ell-1)`，并核对完整配置边际与内部任务恰选一次。脚本明确在含环 coalition 上拒绝 forest 前提；这个拒绝只检查程序先决条件，**不**证明环上的联合分布不存在。有限输出支持上述定理的实现边界，不替代一般森林耦合证明，也没有 high-order overlap hierarchy。

# 3. 固定最优凸包点的逐行/计数障碍

## 3.1 构造和量词

取 k>=2、r>=k。机器为 homes `H_1,...,H_r` 和私有 sinks `Z_1,...,Z_r`。大任务 B 只能在任一 H_i 上以时间 1 处理；第 i 组有 k 个小任务，每个只能在 H_i、Z_i 上以时间 1/k 处理。对每个 h，调度 S_h 把 B 放 H_h、整组 h 放 Z_h、其余小任务留在各自 home；所以 OPT=1，且

`x=(1/r) sum_h 1_{S_h}`

是**真实最优整数调度凸包**中的点。其逐行量为

`ell_H=1, M_H=1, N_H=k-(k-1)/r;`
`ell_Z=1/r, M_Z=1/k, N_Z=k/r`。

这点区别于经典 Shmoys–Tardos 紧性例：那里给定点把小任务固定在相同机器上，未必属于真实 OPT 调度凸包；本族的平均点有显式最优分解。SV 的单任务例只给出可抢占值的加性差，也没有本族的相对近 2 合同。

## 3.2 逐行负载合同的精确下界

任意完整合法调度把 B 放在某个 H_h，令 q_h 为 h 组小任务中送到 Z_h 的个数。因为该组小任务没有第三个端点，

`L_{H_h}=2-q_h/k,  L_{Z_h}=q_h/k`。

若对所有机器要求 `L_i <= a ell_i+b M_i`，则

`q_h <= floor(a k/r+b)`。

令 `q=min(k,floor(a k/r+b))`。当 a,b>=1 时合同域非空，且受合同限制的最优 makespan**恰**为 `2-q/k`：下界来自 B 所在 home，上界由把 q 个 h 组小任务送入 Z_h、其余小任务留 home 的显式调度达到。取 r=k² 后 q/k 趋于 0，所以任意固定 epsilon>0 都能得到大于 `2-epsilon` 的合同内最优值。结合一般 ST 型上界，固定真实最优凸包点的常数逐行偏差合同的 supremum 精确为 2。

若允许更宽 a,b>=0，正文仅保留“不相容”推论；当 a+b<2 时合同可能连大任务所在 home 都无法容纳。不能把这个可空宽版写成 a,b>=0 的统一非空 supremum。

## 3.3 计数合同和集中迁移

若只要求 `c_i<=a N_i+b`，同一 q 上界原样成立。特别在 `r>=k` 时 `ceil(N_H)=k`、`ceil(N_Z)=1`；对每机合同 `c_i<=ceil(N_i)+b_0`，精确受限值为 `2-min(k,1+b_0)/k`，故任意固定额外槽数的上确界仍为 2。

若某调度达到 `C_max<=2-epsilon`，B 所在 home 的私有 sink 至少接收 `ceil(epsilon k)` 个小任务，因此该 sink 负载至少 epsilon，而原 x 在该 sink 的分数负载只有 1/r、最大支撑时间只有 1/k。令 r=k²，所需接收负载相对于 `ell_Z+M_Z` 的倍率至少 `epsilon k²/(k+1)`，无界。这明确指出逃生方向：必须允许集中迁移、重选 x，或放弃固定逐行/槽包络。

本族本身显式可解：取任一 S_h 即得 OPT=1。因此该障碍不是 UM-TARGET 的计算困难性，也不否定允许重选分数点或从完整凸包分解直接恢复好调度的算法。

# 4. 固定边际和两两负相关的随机边界

## 4.1 一般证明

允许输出为任意合法调度的随机变量 Sigma，只保留 x 的全部边际；对同一 sink 的不同小任务仅要求

`Pr[j_it,j_iu both go to Z_i] <= 1/r²`。

令 `D_i` 为第 i 组送 sink 的小任务数，`D_max=max_i D_i`，`Q=sum_i binom(D_i,2)`。若 B 落在 H_h，则每态

`C_max=2-D_h/k >= 2-D_max/k`。

又有整数不等式 `D_max<=1+Q`，且负相关假设给 `E Q<=binom(k,2)/r`。因此

`E C_max >= 2-1/k-(k-1)/(2r)`。

若 `C_max<=2-epsilon`，令 `q=ceil(epsilon k)>=2`，则 `D_h>=q`、`Q>=binom(q,2)`，Markov 得

`Pr[C_max<=2-epsilon] <= min(1, k(k-1)/(r q(q-1)))`。

这不假设 B 与小任务独立，也不限制不同 sink 的高阶相关性。令 r=k²，固定边际/两两负相关合同的期望值趋近 2，尾部成功概率对固定 epsilon 趋于 0；但这是特定随机输出合同的障碍，不是一般随机算法下界。

## 4.2 尖锐达到分布

当 `r>=max(k,binom(k,2))` 时，先均匀选 B 的 home h。以概率 `c=binom(k,2)/r` 在 h 组送两个小任务到 Z_h，并在其他 k-2 个组各送一个；以概率 1-c 在 k 个不同组各送一个。其余小任务留 home。由组和任务的对称性，每个小任务 sink 边际恰为 1/r、B 的 home 边际恰为 1/r；同 sink pair 联合概率恰为 1/r²。两类状态分别给 `D_h=2` 与 `D_h=1`，从而期望恰达到上式。对 `2<=q<=k`，把碰撞类改成 q 个任务并以 `binom(k,2)/(r binom(q,2))` 的概率发生，得到尾界的非截断值恰达。两个 sharpness 结论不要求同一个分布同时使任意 q 的期望和尾界都达到。

# 6. 与全仓成果的比较、保留和接续

1. 与《固定过载固定 sink 与凸局部最小有限审计》《经典基线固定工作与调色板 GCD 有限审查》：它们研究固定工作或具体占用面；本批的 long-path 结果研究配置阈值和局部联合分布，不能合并 OPT 数值。交叉处只保留“有限审计不等于通用 oracle”的共同量词。
2. 与《森林边界与双端菜单有限审计》：森林耦合机制相邻，但本批给出的是配置分布到 `CC_r` 的一般递归和长链 gap；forest-boundary 的菜单/端点证据不重复计作本批来源。接续时应比较完整 separator 相容性，而不是把两个有限算法混成一个定理。
3. 与《近平坦 HS 矩提取与负接口有限审计》《前缀原子有限精度与相对 Gram 审计》：都使用 exact Fraction 和拒绝边界，但本批没有 PSD、Gram 或 HS 提取；各自保留独立文件和身份。
4. 与《固定槽/最优凸包边际障碍》祖先：标准 ST 上界、固定相同机器 tightness、Shmoys–Tardos 及 SV 例只作来源线索。本族新增的数学内容是“真实最优凸包平均点 + 私有 sink + 固定 row/count 或 pair-NC 合同”的精确量词与集中迁移边界，不把祖先的固定槽反例重新归属给本批。
5. 与当前六人 CAG/SPE 目标：机器配置、任务取向和负载证书与客户目录覆盖、终局均分和 SPE 偏差不同，保持 unrelated-machines 子存档隔离。
