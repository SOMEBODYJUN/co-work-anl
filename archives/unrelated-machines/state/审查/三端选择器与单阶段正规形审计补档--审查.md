三项 source 均 clean show 导出并逐行读取。ternary_unit_selector_normal_form.py 本地 exact audit 状态 pass，输出完整 finite cases；three_host_and_santa_majority_independent.py 的构造、exhaustive 2-agent/2-ordinary cases、3000 random SC cases、2500 random actual cases 和 fixed huge-rational boundaries 均已阅读，本轮长运行未保存 stdout；three_host_selector_optimum_independent.py 依赖同目录 normative three_host_majority_selector.py，当前 batch 未带该 helper，未伪造 JSON。

# Ternary selector normal form

程序把每个 old job 替换成 private full binary selector tree，所有有限 processing times 属于 [0,b]。它验证实际 transformed instance、forward schedule、actual decoder 和 strict threshold 2b 以下的 one-stage normal form；不提供 approximation algorithm 或 hardness theorem。审计 JSON 保留 complete finite cases、large binary parameter 和 negative controls，强调 bounded arity/explicit input 合同。

# Three-host majority

独立程序实现 two supplied YES allocations 下的 monotone majority_bad_allocation。它处理 arbitrary ordinary/special utility degrees、zero/unused goods、coincident special owners、same-outer helper changes、exact exhaustive 2-agent/2-ordinary profiles、3000 random SC cases、2500 random actual contexts、huge rational scales、nonconsecutive host IDs 和 zero/empty boundaries。程序逻辑把三 special items 的 A-only/B-C-only 分支传播到实际 integral allocation；但有限检查不等于一般 UM hardness。长输出未生成证据文件，故本批不宣称新计数。

# Selector optimum independent

该源通过 all_actual_schedules 枚举原始 eligible assignment，计算四种 profile（a,bc,b,c）的 exact OPT 和 YES witnesses，再调用 normative selector constructor 对实际 sigma 做独立检查。它明确把 three-host IDs、fixed T preloads、original matrix loads 和 finite oracle 分离。由于缺少 normative helper，本轮只保存源码和依赖边界，不伪造 optimum JSON。
