# `ROADMAP.md`（`aa6573daa34846cf9f41`）

ROADMAP 以四项承重义务概述旧 UM-TARGET 路线：

1. 共同相关性与真实容量：已有单边/单机/有限投影仍可出现 gap 2，需要共同多机条件容量或绕开当前松弛。
2. 联合舍入与可终止修复：固定槽、固定包络、冻结宏任务有准确障碍，需要同时重选、接收机增载和总位多项式进展。
3. 可恢复结构分解：星消元、配置保持、一/双边界森林菜单有精确合同，但一般共同菜单选择、嵌套或有环核心仍缺。
4. 新表示的可计算桥梁：给定矩推前、重新耦合、给定支撑共同流和未知 \(W\) 的算法义务必须最终落回真实任务分配及总编码复杂度。

路线表之外，ROADMAP 还将加权拥塞旧题、顺序客户吸引、设施 EPTAS、三设施常数和立方费用列为独立保留线，不把它们作为当前 UM-TARGET 的默认入口。它强调每条路线必须先明确额外信息、输入/输出、已知 gap、零值边界、统一 \(\varepsilon\) 和位复杂度，不以特殊结构、估值、困难接口或实验表代替主目标。
