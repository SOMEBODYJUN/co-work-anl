## 1. 有限正支撑模型与福利舍入

设 (G) 是非空有限组集，(n=|G|)，(U) 是有限资源集。每个 (g) 有有限、显式且带索引的 state 集 (A_g)。state ((g,s)) 的资源系数 (p_{gsu}) 是非负二进制有理数，列出的系数和为 1；允许显式零系数、零 incidence、重复 indexed states 和未使用资源。对 bundle (Bsubseteq U)，

\[
v_g(B)=\max_{s\in A_g}\sum_{u\in B\cap U_{gs}}p_{gsu}.
\]

只允许两两不交的真实资源 bundles，未分配资源不产生收益。正支撑 (P_{gs}={u:p_{gsu}>0}) 上的 FSLP 是

\[
\lambda_{gs}\ge0,\qquad \sum_s\lambda_{gs}=1,
\qquad \sum_{g,s:u\in P_{gs}}\lambda_{gs}\le1\quad(u\in U).
\]

令每组独立按 \(\lambda_g\) 抽 state，固定资源 (u) 的随机系数为 (Y_{gu}=p_{g,s_g,u})。对每个 (t>0)，

\[
Q_u(t)=\sum_g\Pr(Y_{gu}\ge t)\le1,
\]

因为事件 (Y_{gu}>0) 的概率不超过正支撑容量。组间独立给出

\[
\Pr[\max_gY_{gu}\ge t]
 =1-\prod_g(1-q_{gu}(t))
 \ge1-e^{-Q_u(t)}
 \ge(1-e^{-1})Q_u(t).
\]

有限 levels 的 tail sum/integral 得

\[
\mathbb E\!\left[\sum_u\max_gY_{gu}\right]
 \ge (1-e^{-1})\,n.
\]

逐资源把资源交给最大系数的组（固定索引破平局）即得真实不交 bundles。精确条件期望算法按组逐次固定 state：在当前 prefix 下，对每个资源的 distinct positive level (0=a_0<a_1<\cdots<a_k) 使用

\[
E_u=\sum_{i=1}^{k}(a_i-a_{i-1})\left(1-\prod_gF_{gu}(a_i)\right),
\]

其中 (F_{gu}(a_i)=\Pr(Y_{gu}<a_i))，已固定组为 0/1，未固定组为原 (lambda) 子集和。当前期望是候选 state 期望按 (lambda_{gs}) 加权的平均，选取最大正概率候选不降低期望。所有 levels 总数至多显式 incidence 数，分母是输入有理分母的多项式次乘积；不以最小正系数、概率倒数或指数级 state 子集作为循环界。

由于 (e>1+1+1/2+1/6=8/3)，所以 (1-1/e>5/8)。最终选 state 的真实效用 (r_g=v_g(B_g)) 满足

\[
\sum_g r_g>\frac58 n.
\]

对 (0\le\delta<5/8)，令 (h_{\ge}(\delta)=|\{g:r_g\ge\delta\}|)，同样由上界 (sum_g r_g\le h+(n-h)\delta) 得

\[
h_{\ge}(\delta)>\frac{5/8-\delta}{1-\delta}n.
\]

把“(gedelta)”换成“(>delta)”时必须重新说明互补低端的严格性；不能把两种源定义静默互换。

## 2. 完整 `P_gate` 的精确值

在上述菜单上构造完整 ordinary-UM 矩阵：一台 root (R)；每组一台 gate (X_g)；每个 indexed state 一台 private (M_{gs})；每个资源一台 (Q_u)。任务身份全部显式保留：root pin (J_0)（只在 (R) 为 1）、connector (C_g)（在 (R) 为 (1/n)，在 (X_g) 为 1）、selector (T_g)（在 (X_g) 与本组每个 (M_{gs}) 为 1），以及每个列出的 incidence job (I_{gsu})（在 (M_{gs}) 为 (p_{gsu})，在 (Q_u) 为 1）。未选 state、零 incidence 和 unused 机器都保留；不生成隐式“拒绝任务”。

定义 balanced value

\[
\beta^*=\max\!\left(\{0\}\cup\left\{\min\left(\frac{|H|}{n},\min_{g\in H}v_g(B_g)\right):\varnothing\ne H\subseteq G,\ B_g\text{ 两两不交}\right\}\right).
\]

任给一个 (\beta>0) 的见证，connector 送入对应 gates、selector 送入见证 state 的 private、见证正 incidence 送入资源机，其余所有 jobs 留原 private/root 端，峰值至多 (2-\beta)。

反向取任意完整调度峰值 \(C<2\)。令 (H) 是 connector 在 (X_g) 执行的组；root 负载精确为 (2-|H|/n)，故 (|H|/n\ge2-C)。这些组的 selector 不能与自身 gate connector 同处 (X_g)，只能在某个本组 (M_{gs})；该 state 的正 incidence 若未导出就留 private，导出集合 (B_g) 的质量至少 (2-C)。由于每个资源机只给每个 incidence 一个单位资格，且 \(C<2\)，不同 (B_g) 必须全局不交。于是 (\beta^*\ge2-C)。

因此

\[
\operatorname{OPT}(P_{\mathrm{gate}})=2-\beta^*.
\]


(\beta^*=0) 时有峰值 2 的完整基线；root pin 保证 (operatorname{OPT}\ge1)。这一值桥依赖完整 P_gate、单位 connector/selector、所有未选 jobs 仍被执行和 \(C<2\) 下的资源独占，不能推广到原 flat menu 或一般 unrelated-machines。

## 3. 13/8 调度及其适用域

FSLP 可行时，上述福利舍入在 \(\delta=3/8\) 产生多于 (2n/5) 个 (r_g>3/8)（或按对应语义 (\ge3/8)）的组。选这些组作为 (H)，得到 (\beta>3/8)，从而构造峰值 (<13/8) 的完整调度。v2 的一般 LP 版本还允许质量变量 (z_{gs}) 和 claims (x_{gsu})，目标

\[
L=\sum_{g,s,u}p_{gsu}x_{gsu},\quad 0\le x_{gsu}\le z_{gs},\quad\sum_s z_{gs}=1,\quad\sum_{g,s}x_{gsu}\le1.
\]

取 state 的条件 claims \(x/z\) 后，初始每资源正 claim 概率和仍不超过 1；条件固定后不再错误地复用该初始不等式，而使用同一有理 level 公式。作者 Proof 与两个独立攻击都确认这一点。对 balanced value 的二次估计与 v2 证明相合，给出 scoped 的 (13/8) 近似比例；此处不把它扩成原 flat menu、一般 R\|\|Cmax、Santa Claus 或未知菜单识别算法。

## 4. robust 参数的互补纠错

旧 NSW 页中的 \(\gamma_{bad}\) 是“低质量组比例”的下界，而门控源中的 \(\gamma_{hi}\) 是“高质量组数量上限”的阈值。对 (h=|\{g:r_g\ge\delta\}|)，正确关系是

\[
h<\gamma_{hi}n\quad\Longleftrightarrow\quad
|\{g:r_g<\delta\}|>(1-\gamma_{hi})n.
\]

右侧不是“至少 \(\gamma_{hi}n\) 个低质量组”。若高端使用 (>delta)，互补端变成 \(\le\delta\)；strict/weak 边界必须逐案保存。旧页关于 C–D 不等式本身和 F.1 的内容不因该纠错自动失效，失效的是把两个不同参数语义直接相等并据此声称“未覆盖”。

在完整显式 normalized 输入、all-allocation NO 量词、FSLP-feasible YES 和给定有理阈值的范围内，LP 可行性给出 promise 判别：YES 的质量一 allocation 诱导 FSLP；FSLP 可行则福利舍入产生高质量组数，和 NO 高端上限冲突。对近完美 YES/NO，正文只保留实际写出的不等式边界；没有声称已经构造归约或解决任何一般 NP-hardness 问题。

## 5. 八源的相互审查结论

* `9a15…` 的 Exact 对象、`3e856…` 的作者证明和 `32384…` 的独立重构在 FSLP、正支撑概率、四层 P_gate 负载与严格计数上相互吻合。

* `c883…` 实际渲染并读取 DNS 作者稿 §3.2 的关键页，确认 (1-1/e) 福利机制已有文献归属；因此本文不主张该舍入技术或常数为原创。它也记录 v1 Proof 的未运行/未读部分不能转移为证据。
* `b7a…` 对最终规范和旧 NSW C–F 的范围做了全段审查，明确旧 review 中已证伪的“不同 gamma 导致未覆盖”段落须撤回；未读取的 audit JSON、生产 LP 实现与 novelty 仍是缺口。
* `ae4…` 与 `854…` 对 v2 的 \(z/x\) 质量等式、条件 claims 和未知 OPT 比例逐节复核；v2 与独立重构一致，但没有把 v1 的通过状态静默移植，也没有把作者报告的有限运行当作本次独立重跑。

因此本批可集成为一个“明示模型内的完整证明与参数纠错”对象。其结果是真值/适用范围分离的条件结论：有限有理输入、正支撑 FSLP 或明示 (z,x) LP、完整 P_gate 和 all-allocation 量词必须同时满足；一般 UM、旧 flat 菜单、六人 SPE 覆盖模型和新颖性均保持开放。
