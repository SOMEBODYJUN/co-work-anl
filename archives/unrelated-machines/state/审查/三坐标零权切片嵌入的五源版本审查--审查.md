## 经核对的数学合同

源域是有限、非空的显式 flat weighted-menu ordinary unrelated-machines 实例。每组 (g) 有非空 indexed state 菜单 (A_g)，每个 state 的资源集合 (S_{gs}) 可为空或含重复 indexed states；每个列出的 incidence 有非负二进制有理私有时间 (p_{gsu})，总和 (W_{gs}le1)。每个 state 有自己的 private machine，资源 (u) 有单位外端机器，组有只在自己全部 state 机上耗时 1 的 selector；原 incidence 的全部有限资格恰为 private 端和对应资源端，未选 state 的 jobs 也属于完整实例。一个资源在全部 states 的并集中最多属于三组，零权 incidence 仍计入这一 membership，组交互图按完整并集定义，最大度 (M) 不受菜单大小限制。

目标为每个变量带独立 tag 的完整 ([3]^3) 资源 cube。变量至多属于三组，并给这些组互异坐标 index (j_x(g)in[3])。每组每个 indexed state 为每个变量放一个 9-cell slice (z_{j_x(g)}=j_x(g))，允许零 cell 权、状态依赖的成本表和相同 label vector 的不同 state。源状态身份由独立 private machine、selector 选项与 job 表保留；这项许可是构造的承重条件。

对每个原资源 (u) 建 (x_u)，固定 active 格 (a^*=(1,2,3))，令接触 (u) 的组在该变量上使用互异 index。所有这些组的所有 state slices 都含同一 active 格。原 incidence (I_{gsu}) 映为该 state/variable 的 active-cell job，保留原私有时间和两端资格；若 state 不含 (u)，active-cell 和其余切片格补为 private time 0 的辅助 job。空并集组用只属于该组的 dummy variable。源 private machines、selectors、indexed states、原资源 machine 全部有显式 identity map，unused 原 resource 也保留其 active machine image。

## 双向映射及其后果

任意完整源 schedule 均可扩展到目标：原 job 按 identity map 保持端点，所有 auxiliary zero-private jobs（包括选中和未选 states）留在各自 private machine，峰值逐机不变。反向从任意完整目标 schedule 删除辅助 jobs 与辅助 machines，不能按“private time=0”误删原 zero-job；要依赖构造时保存的原 job identity。每个原 job 只有原 private 端和 active resource 端，因此逆映合法，删除只降低负载。两向不要求最优、(C<2) 或所有 job 外送，故

\[
OPT(C(P))=OPT(P)
\]

对所有实际 makespan 阈值（含 (OPT=2)、严格/非严格阈值）成立。该等式传递已有源域的 promise，但不制造 hardness、allocation gap、额外费用或任务数约束。

## 结构、unit 支持和退化情况

完整组交互图精确保持：共享原资源 (u) 的两组共享 active cell；不共享的组只用不相交变量 tags 或独占 dummy。目标每个 cell 所属组数至多三，故资源组度仍至多三；但一个组可以使用任意多个变量，所以固定 (d=Q=3) 不给交互最大度 (M) 上界。

在峰值至多 1 时，selector 已占所选 private 机的一个单位，选中 state 的正私有 jobs 必须外送，且外端单位容量使不同组选态的正 supports 两两不交；反向把正 jobs 外送、零 jobs（及未选 states 全部 jobs）留 private 即得完整 unit 调度。因此嵌入保持的是正 support，而不是所有几何 slice。不同组 slices 在零权 cell 的交集不产生一致性约束。若把零 cell 作正扰动，可能引入新的强制外送和 unit 冲突；不能顺手升级为 all-positive 结果。

允许 (q_g=0)、(U=arnothing)、unused 原 resource、零私有权和重复 indexed states。若 (e) 组的完整并集为空，目标资源机为 (27(|U|+e))，incidence job 数为 (9\sum_g K_g\max(1,q_g))，仍是显式输入大小的多项式；dense 矩阵同样多项式，处理时间只复制原有理数或写 0/1/∞，不按数值分母复制对象。

## 五源独有审查内容与版本纠错

- Exact 给出完整源/目标定义、active 格构造、双向调度、精确 OPT、组交互 M 与复杂度；明确结果是 embedding 而非新算法或 hardness。
- Exact-only 独立审查逐项核对所有原 jobs 的单射、missing-incidence 与原 zero-job 的区分、任意目标 schedule（可外送辅助零 jobs、峰值不受限）的投影、unused 资源与空并集 dummy，未发现 fatal。
- 作者 Proof 与其 read-after 重新核对 slice (a_i=i)、active 格存在、原 job 两端、任意 schedule 扩展/投影、正 support 与 interaction，确认与独立重构一致；未把 selector 错称为“两端”。
- canonical read-after 首次发现并纠正一句措辞：此前“每个原 job 身份及其两个有限端时间”会误涵 selector；最终 canonical 改为“全部原有限资格（incidence 恰两端）”。该修订是表述纠错，不改变构造或公式；其余全文、公式及冻结 Exact/Proof 字节不变。

## 适用范围、未完成项和接续

本对象可与已有 bounded-interaction v2 正定理组合：目标资源组度 (Delta=3)，给定该正定理及同一 (M) 时，参数代入为 (2-1/(M+5))。本批未重新证明或重新审查该外部定理，故只记录条件接续。任意 (M)、固定菜单 (K\ge3) 的 source gap、一般 UM 算法、all-positive cube、label-vector 唯一决定成本、或由 Santa Claus/其他 allocation hardness 自动得到当前 scheduling promise，均未由五源解决。

处置：五源均 `integrated` 到本审查对象并链接已有主定理；无独立程序或有限实验需复制。后续若使用该嵌入，必须显式检查目标域是否允许零 cell 权、state-dependent cost tables、重复 indexed states 和完整 original-job accounting；否则不得套用本结果。
