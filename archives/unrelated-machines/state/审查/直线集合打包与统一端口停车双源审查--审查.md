## 一、直线集合打包与累计路径的两种接口

### 1. 发表事实和均匀菜单编译

LST 的 paper fact 是：在固定 (k\ge4) 和足够大的 prime (R) 下，完整 (k)-set packing 实例的最大匹配值来自 CSP 约束满足值；在 `NP` 不包含于 `BPP` 假设下，YES 值近1、NO 值约为 (k(1+\epsilon)/((k-3)R))。这是完整集合匹配的来源事实，未给 partial-set 保留的 soundness。

来源自足构造 `UM-LST2025-AFFINE-LINE-SOURCE-UNIFORM-COMPILATION-OBSTRUCTION-v1`：每 indexed constraint (g) 选一个 allowed state (s\)，用不同变量标签的仿射直线
\[
E_{x,g,a}=\{(x,z,az+j_x(g)):z\in\mathbb F_R\}
\]
组成 state bundle (S_{g,s})，每束含 (D=kR) 个资源。每个 group 有 selector，state-resource incidence 可在 private parent 用 (1/D) 或唯一资源机用1。对任意 local state 选择和任意 group 子族 (F)，每变量的不同 indexed constraints 直线至多一次相交，故
\[
|N(F)|\ge\sum_x \frac{R+1}{2}|F\cap G(x)|\ge \left\lceil\frac{kR}{2}\right\rceil|F|.
\]
Hall 给每组至少 (b=\lceil kR/2\rceil) 个不交资源。选中 state 的 parent 负载为 (2-b/(kR)\)，未选 parent 与资源机负载至多1，于是完整显式 UM 调度峰值至多 (3/2)。这是一条不依赖 source witness 的 scoped 正面合同，但依赖非空 relation、度数至多 (R)、intercept 注入、变量 tag、均匀权和完整矩阵展开；不声称按 succinct (log R) 输入多项式。

若另有真实全满足 assignment，则同 slope 的直线只因不同 intercept 相交为空，全部选束不交，OPT=1；但近完美 CSP YES 不自动提供此更强证书。把每个 tuple 单独分组或加入 dummy 会改变 (r_x\le R) 与直线重叠不变量，必须另证。

### 2. take/continue 的明确反例

`UM-PARTIAL-SUM-TAKE-CONTINUE-FLAT-MENU-ACTUAL-ESCAPE-v1` 给出三 agent、两件不可拆共享 item，各 agent 对每件价值 (3/5)，并用 (u_1,u_2) 及每 agent 私有 (x_a,y_a,z_a) 编排 take/off/accept states。每个 state 使用独立 private、资源机和 incidence job；所有未选 off jobs 仍保留，完整实例为26台机器、30件 jobs。

此对象的精确值为
\[
\operatorname{OPT}_{SC}=0,\qquad V=2/5,\qquad \operatorname{OPT}_{UM}=8/5.
\]
源只有两件不可拆 item，三人中必有人无 item，故源最优为0；领取 (x_a,y_a,z_a) 给出 (V=2/5)。若完整 UM 调度低于 (8/5)，三枚 root take1 selector 的对应 (u_1) incidence 都必须外送到同一资源机，产生负载3，矛盾。于是任何把正 partial state 统一解码成每位 agent 正效用的固定常数合同都失败，即使允许重新安排全部原 items。

这个反例只否定该明示的累计路径 take/continue 规则和其 flat menu，不否定其它 selector-tree、完整 leaf、跨层 activation 或非局部编译。它也不是一般 hardness；证书和有限 Fraction 回算只核对该常数实例的达界。

## 二、统一端口停车：配置间隙与实际近似的分离

### 1. 精确对象和整数 polymatroid

`UM-UNIFORM-PORT-PARKING-PAPER-APPROX-v1` 的输入为有限主点 (U)，每个 (u) 有标签集 (L_u)，每状态有统一 (D\ge1) 个不同 cheap resources (C_{u,a})。每个标签有 private parent；selector 时间1；每个 resource 有 port，在 parent 用 (1/D)、在资源机用1；另有显式 mandatory unit auxiliary jobs。资源全体承载一个 matroid rank oracle，目标选一标签并在其束中取互不交、并集独立的资源，最大化
\[
\beta=\min_u |S_u|/D.
\]

对每个 variant (p=(u,a)) 定义
\[
f(X)=r_M\left(\bigcup_{p\in X}C_p\right).
\]
这是整数、单调、次模的 polymatroid rank。向量 (x) 可由互不交的独立资源集合实现，当且仅当所有 (X) 满足 (x(X)\le f(X))，充分性来自 Rado 独立代表；实际可用 eligible-pair 的 matroid intersection 构造。该计数层把配置/边际证书和真实资源停车区分开。

### 2. 两值 Santa Claus 归约和实际普通 UM

把每个 variant 的其它选择用 (D)-价值大资源补齐，得到 Definition 7 的 two-value resource-matroid Santa Claus；其真实最优值为 \(\beta^*D\)。BLMRS Theorem 4 的现有算法给固定 \(\eta>0\) 的确定性 ((4+\eta))-近似，因此实际可构造
\[
\beta_{alg}\ge\beta^*/(4+\eta).
\]

在 mandatory unit jobs 的 vacancy matroid 是显式 transversal matroid 的对偶时，普通 matching 计算 rank 和保留后的 parking matching。选择标签、外送 (I_u)、其余 ports 留 private parent，严格得到
\[
\operatorname{OPT}_{UM}=2-\beta^*.
\]
故统一 (D) 的显式结构类有确定性
\[
2-\frac{\beta^*}{4+\eta}\le \left(2-\frac1{4+\eta}\right)(2-\beta^*)
]
形式的绝对峰值与相对真实 OPT 上界 (2-1/(4+\eta))（比值随 \(\beta^*\) 增大，在 \(\beta^*=1\) 处最坏）。若 auxiliary unit jobs 自身最优值 (B\ge2)，则全部 ports 留轨并精确得到 (B=\operatorname{OPT})。这是真实实际近似的 paper-based 正面结论，不依赖 CONFIG 分数解。

### 3. 每个配置都独立仍不足以保留共同资源

来源的显式 `UM-COTRANSVERSAL-UNIFORM-CONFIG-SHARP-GAP-v1` 族取 (D\ge3)、(m=D+1) 个主点，每人 (D) 个状态，构造 transversal vacancy matroid 的对偶。每个单状态配置均 (M)-independent；所有单状态边际混合给出一个看似完美的配置点。但选每人一个状态并要求共同保留集互不交且并集独立时，Hall 计数给出某人至多保留一项，故
\[
\beta^*=1/D,qquad T_{conf}=1,qquad \operatorname{OPT}_{UM}=2-1/D.
\]
该族证明“每个完整配置独立”不能推出统一实际保留；它只攻击 fractional/configuration-to-uniform 的局部合同，不具备 integer perfect completeness，也不否定上面的相对真实 OPT 算法。有限 D3/D4 证书核验不承担一般复杂度结论。

### 4. 量词、复杂度与未闭合边界

统一 (D) 端口模型按显式 resources、ports 和 rank/matching oracle 计复杂度；不能把 (D) 的展开输入误称为按 \(\log D\) 多项式。BLMRS 算法本身未集成到仓库软件，数学可构造性和可执行实现须分开表述。若各主点的 cheap 规模 (D_u) 不统一，或者把 cheap value 归一为 player-dependent，two-value theorem 的条件会失效；多尺度模型需要新的证明。

以上精确 polymatroid 与 cotransversal 族不构成一般 `UM-TARGET-v1` 的算法或 hardness。它们为第三阶段提供两个相反方向的关系证据：一方面，统一端口、全局 vacancy matroid 与 two-value resource 模型可以把真实 OPT 接到已知近似；另一方面，单配置独立和分数边际无法保共同容量，必须保留全局 matching/matroid 身份。两源没有客户目录、六提供者完整历史或均分语义，六人 SPE 目标保持独立开放。
