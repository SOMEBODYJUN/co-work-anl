# 结论和对象身份

这五个冻结源版本都研究同一受限对象 `UM-DEGREE-TWO-BOUNDED-MENU-JOINT-ROUNDING`。它的输入是有限非空 group 集合 (G)，每个 group 有显式、非空、带索引的 state 菜单 (A_g)，每个 state 的显式资源集合 (S_{g,s})，以及非负二进制有理 private 时间 (p_{gsu})。每个 state 的 private 总量 (W_{gs}=sum_{uin S_{gs}}p_{gsu}le 1)。一个资源在全部 state 中至多属于两个不同 group；它在同一 group 的多个 state 中重复出现是允许的。

原始 UM 矩阵只有以下任务和机器：每个 state 一个只属于该 state 的 private machine；每个资源一个 resource machine；每个 group 一个只可在本 group state machines 上取处理时间 1 的 selector；每个 incidence 一个任务，在其 state private machine 上取 (p_{gsu})，在对应 resource machine 上取 1；其它边为不可用。所有原 jobs、未选 state、零时间 incidence、重复 indexed state 都保留。不存在隐藏预载、共享 private machine、拒绝任务或额外资格约束。

v1 exact 源是 statement-first 候选：只写 strict-unit promise 的 (2-1/(2K)) 门槛，并允许返回 `FAIL`；它明确不声称 novelty 或一般 UM。v2 exact、独立 exact-first review、作者 proof 与作者 read-after 将结论提升为有条件的完整相对保证，并对 normalization、端点和复杂度给出补足。v1 的失败语义和较窄 promise 仍作为历史版本保留，不能倒写成 v2 的最终算法合同。

# v2 的自足数学内容

设先有 (W_{gs}=1)。对 bundle (Bsubseteq U) 定义
\[
 a_{gs}(B)=\sum_{u\in B\cap S_{gs}}p_{gsu},\qquad
 f_g(B)=\max_{s\in A_g}a_{gs}(B),
\]
以及
\[
 V=\max_{(B_g)\text{ pairwise disjoint}}\min_g f_g(B_g).
\]
从任意不交 (B_g) 选择达到 (f_g(B_g)) 的一个 state，把该 state 的 selector 放到自己的 private machine，把选中 state 中属于 (B_g) 的 incidence 导出到资源机，其余全部原 jobs 留在各自 private machine。资源机最多收到一件 unit job，未选 state 的 private load 为 1，选中 state 的 load 为
\[
 1+(1-f_g(B_g))=2-f_g(B_g).
\]
因此得到完整实际调度，且峰值不超过 (2-min_g f_g(B_g))。

反向取 (C<2) 的完整调度。每个资源机至多有一件 unit incidence；把所有没有 selector 的 state 的全部 incidence 拉回各自 private machine，不增加峰值。令 (B_g) 为 group (g) 的 selector state 中真正导出到资源机的资源，资源容量给出 (B_g) 两两不交，且 selector state 的负载给出导出质量至少 (2-C)。所以 (V\ge2-C)。selector 的全 private 基准给 (1\le\mathrm{OPT}\le2)，allocation-to-schedule 和 schedule-to-allocation 合并为
\[
 \mathrm{OPT}(P)=2-V.
\]
严格 (C<2) 才使用资源机独占；若 (mathrm{OPT}=2)，正 (V) 会由前向构造得到小于 2 的调度，故必须 (V=0)，等号端点同样成立。

把每个 group 的全部 state clauses 平均成一个辅助 additive agent：
\[
 v_g(u)=\frac1{K_g}\sum_{s\in A_g:u\in S_{gs}}p_{gsu},\qquad K=\max_gK_g.
\]
非负性给出对任意 (B)
\[
 \frac{f_g(B)}K\le\frac{f_g(B)}{K_g}\le v_g(B)\le f_g(B).
\]
把达到 (V) 的原 bundle 分配用于 (v_g)，得到辅助 additive max-min 最优值 (A\ge V/K)。一个资源的正值辅助 agents 正好是包含它的 groups 的子集，因此最多两个；同一 group 内多个 state 的重复只改变该一个 agent 的加总值。调用 Verschae--Wiese, arXiv:1011.4957v1, §5.1, Theorem 12 的确定性 degree-two additive MaxMin 2-近似，得到不交的 (C_g) 满足
\[
 \min_g v_g(C_g)\ge A/2\ge V/(2K).
\]
每个 group 再扫描真实菜单，取最大 (a_{gs}(C_g)) 的一个 state，按前述完整原 jobs 回填，得到
\[
 C_{\max}\le 2-\frac{V}{2K}
 =2-\frac{2-\mathrm{OPT}(P)}{2K}
 \le\left(2-\frac1{2K}\right)\mathrm{OPT}(P).
\]
最后不等式来自
\[
 (2-\tfrac1{2K})x-[2-\tfrac{2-x}{2K}]=(2-\tfrac1K)(x-1)\ge0,
\]
其中 (x=\mathrm{OPT}(P)\in[1,2])。算法不接收 OPT、最优 allocation 或 YES witness；(K) 可以随显式输入增长，运行时间仍按二进制输入长度多项式，而改善量 (1/(2K)) 不再是统一常数。

# (W_{gs}<1) 的 bonus normalization

对每个 (W_{gs}<1) 的 indexed state 增加独有 resource (z_{gs}) 和一枚 bonus incidence；其 private 时间为 (1-W_{gs})，resource 端时间为 1。每个 state 的 private 总量变成 1，新增资源只有一个 group，degree 合同不变。

从增广实例删除 bonus jobs 及其独有 machines 得到原实例调度，故 \(\mathrm{OPT}(P)\le\mathrm{OPT}(N(P))\)。反过来，原实例的任意完整调度峰值 (C\ge1)（至少有 selector）可把所有 bonus jobs，包括未选 state 的 bonus，导出到各自独有 resource；每个新机负载为 1，不改变旧机，故 \(\mathrm{OPT}(N(P))\le\mathrm{OPT}(P))。所以 normalization 精确保留真实 OPT；运行归一化算法后删除 bonus jobs 即得原 jobs 的完整调度。

# 适用边界和后续用途

该对象只覆盖显式 finite menus、跨 group resource degree 至多 2、resource 端 processing time 恰为 1、每 state private mass 不超过 1、独有 private machines、完整原 jobs 和无额外约束。degree 3、任意外端时间、(W>1)、共享 private machine、隐式指数菜单、一般 unrelated-machines、旧笛卡尔一致性逻辑和六人 Q-CAG-HALF 均未被解决。K 增大时改善可趋零；v1/v2 均不证明 sharpness、新颖性、生产实现或一般近二下界。

现有有限审计对象（5 weighted cases、7 raw backend cases、6 类非法输入、root 独立枚举 832 assignments）只能作为合同内回归证据，不能替代上述全称推导，也不能把 degree-two 后端外推到 degree-three。第三阶段如建立关系，应把 VW paper fact、完整原 jobs 解码和 bonus 保值分别作为独立前提，避免把外部定理或旧摘要误当本对象的普遍结论。
