# 2. 冻结合同中的全部实际量词

k≥2，显式正有理a_i总和≤1；原2k机H、k−1个P、k个E互异，原2k件q/b，无aux或预载。q_i只H:a_i/E_i:1，b_i只任意P_r:1/E_i:1，其余∞。真实E_i同住q_i与b_i时要计双unit，不私有化；H可多small query共居。

S是q实际进H集合，T是b实际到E集合，ρ为其它b实际pool目的地。S/T任意，包括空集/多query/多return/partial；ρ任意，池上共居是普通UM安排，不是先有容量1约束。pattern OPT对ρ优化，不把某个ρ固定再称模式最优。

独立稿的独有精确接口是全原机负载：H为Σ_(i∈S)a_i，E_i为1_(i不在S)+1_(i在T)，P_r为实际ρ选择该池的b件数。它给每份完整assignment和C，而非只最优值。所有b time1使C≥1，H≤1、P/E整数，因此C是正整数，可3乃至k；源只声称pattern最优值1/2，不排坏ρ更大。

下列三句话不能混为一个量词：

1. 对每个good pattern，**存在**按索引注入不同P的峰1最优ρ。
2. 对每个bad pattern，**每个**ρ峰≥2，且**存在**一个至多一池双件的峰2ρ。
3. 对给定任意完整actual，**先假设其C<2**，才可断言这同一份σ本来峰1且非空T⊆S，不先重排ρ。

独立稿用k=3、S=T={1}、b₂/b₃同P₁给显式反例：pattern OPT1，但这份ρ峰2。原作者Proof与读后均明确保留此区别，没有勘误。完整恒等式/双向构造/全部任务执行已在定理页，不以review摘要替证明。
