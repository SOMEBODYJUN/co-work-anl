## 1. 跨层全层配额障碍

来源 85d567cbb07542eff2ca 的核心是闭式容量。令 c=K-s，层值在 t>s 时为 min(q,floor(c/(t-s)))，在 t≤s 时为 q；当 q≥ceil(cK/s) 得到全层瓶颈 b*=s/K。桥梁矩阵固定根任务负载 1，外送全部 a_i,b_i 后每个 e_i 留下 c 个 1/K 任务，峰值下界为 2-s/K；K,s=(2,1),(3,2),(4,3) 枚举分别为 3/2,4/3,5/4。它只确认核心—私有资源树的 stated-scope obstruction，不能推出 NP-hardness 或多项式归约。已有跨层障碍对象保存闭式与 Fraction 审计；本源处置为 duplicate/integrated。

## 2. 资源跨组三的加权菜单立方嵌入

来源 45f94446de4975f04696 审查 UM-DEGREE-THREE-WEIGHTED-MENU-CUBE-EMBEDDING-v1。每个原资源复制为 tagged [3]^3 单元，原 incidence 映射到 active cell，其他 cell 用 private-zero 辅助任务占位；跨组 index 互异、每资源至多三组，selector、空组 dummy、zero membership 和同 label vector 异成本均保留。两向 schedule 映射保持峰值和 OPT，稠密编码多项式但不声称对原 incidence 线性。审查只认证命名有限交互定理的适用，不认证实现、外审、新颖性、一般 degree-three 算法或 hardness。已有 degree-three 立方嵌入审查链已吸收；处置 duplicate。

## 3. 二度加权菜单联合舍入

## 5. 稀释共享终端 raw-K2

来源 b4e687a38275e5c87e17 在精确定义 raw K2 合同下给 OPT=2-floor(sqrt(k))/k；指定共同 moment law、完整 first/pair CONFIG 与 affine localizers 在 T0=1+1/k 有证书，gap 趋二。raw 合同明确缺少 joint Boolean CONFIG links、export<=activation 和 active-tail 计数，不能把结论升级到更强 joint-CONFIG-M2。有限软件只复核 k=2 的状态范围，空任务和 OPT=0 不在 gap 声明中。已有 raw-K2 构造和双源审查已吸收，处置 duplicate。
