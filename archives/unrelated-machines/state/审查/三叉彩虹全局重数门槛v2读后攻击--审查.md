# 1. 重数 2 的 q 子可加性

全局每色至多两次时，把每个颜色的两次叶出现放入 A/B 两桶，桶内各自单射。对 raw `q` 做高度归纳：若 `Q=q(A∪B)>q(A)+q(B)=a+b`，支持 Q 的三个 child 中，`q(A)>a` 的 child 至多 a 个，`q(B)>b` 的至多 b 个；因 Q>a+b，余下 child 的两值均不超上界，与子树归纳矛盾。根的三 child 给 `q(全叶)=3`，故一个桶 `q≥2`，得到 rainbow binary witness。`a,b=0` 和任意高度均被覆盖；没有固定高度枚举或把颜色种类数误当 q。

# 2. 重数 3 低重数构件的实际检查

root proof 的 `Dead_H` 只在 `H≥1` 使用：每个最底 internal parent 的三个叶共享一个 parent-private fresh 色，其他 parents 不复用。任一满二叉见证在该 parent 取两叶，故 dead；每色全局恰三次。`R_H(S)` 的 H=1 三叶为 `(a,b,a)`，H≥2 只接两份 palette children 与一个 Dead，Dead 被排除后任何 witness 恰取 A+B、色集恰 S。protected 色放在 b 位并沿唯一子树传递，保持全局单次；其余 palette 色至多两次。H0 不调用 Dead；所有辅助 Dead 色与 palette/逻辑构件全局 fresh。

这与独立稿的 `Must_H(g)` 不是同构记法：独立稿用 `Must_{H−1}(g),Fresh,Dead` 强制 guard，root proof 用 protected palette 保持完整色集；两者都消除了旧 v1 `(A,B,A-copy)` 的重数随高度增长问题。

# 3. Atom、AND、OR、SAT 语义与全局计数

`Atom(c)=R_1({c,p})` 中 protected 原色 c 单次、私有 p 两次。每个 literal occurrence 色在 variable false branch 与 clause option 两个 atom 各出现一次，故全局恰两次；短 clause 补位置仍使用不同 occurrence IDs。neutral 色一次，OR guard 在两份 protected palette 各一次、总二次，其他 palette/filler 色一或二次，Dead 色三次；构件与模块之间均 fresh。逻辑表达式按树使用，每个子式只嵌入一次，没有共享 DAG 或未计费 alias。

AND 的第三 child 是 Dead，迫使同时取两个输入；Pad 只用 fresh palette 提高较矮树。OR 给两 option 各接一个共 guard `g` 的 protected palette，第三 child 是 fresh filler；两个 option 不能同时取而单份必含 `g`，因此实现 OR。按变量 false branch 与 clause true literal 的颜色冲突，SAT iff rainbow binary subtree；空 CNF/空 clause 用显式高 1 YES/NO 常量，避免 Dead0。

高度为 Atom 1、AND `max+1`、OR `max+2`，balanced bundle/top AND 给 `h=O(log(s+2))`，所有 R/Dead 显式展开，节点与颜色 ID 为输入规模固定多项式。给定 witness 的 root、深度、active children 和叶色单射可位多项式核验，因此受限判定仍在 NP。

# 4. 私有 unrelated-machines 回算与边界

继承实例每个 internal 一台私有机，root pin 单端 time1；树边 job 父端 time `1/3`、唯一 internal child 或叶色 resource 端 time1，其余 `∞`。每个非 pin job 恰两端，重数≤3 使每个颜色 resource 至多三枚 eligible leaf jobs。Rainbow witness 下送选中 edge jobs，active load `4/3`、inactive load1、resource≤1，故 YES actual≤4/3。若完整调度 `C<5/3`，每 active internal 至少下送两 outgoing jobs，递归选出 binary subtree；资源机不能接两 unit，故叶色单射。无 witness 时根到叶路径给完整 `C=5/3`，NO actualOPT=5/3，只有 5/4 比值锚点。

这不提供 near-two 放大、一般 UM hardness、任意 `<2` 近似排除、软件实现、外审或新颖性认证。read-after 无 standing fatal 只对限定树源和该私有转换有效。
