# 对象与阅读范围

四份来源围绕同一个失败接口：把一组 k 个不可区分原任务的匿名 head 占用 \(X_i\) 用不放回下降阶乘公式提升成带原标签变量 \(x_{a,i}\)。在真实联合 law 中，这个随机注入是合法的；对只给 aggregate moments 的 degree-4 伪期望，它不自动保持 M2。本文补齐来源链并把可安全复用的结论与未完成义务分开。源 Exact 与作者 Proof 是 statement/proof 版本；affine-context 稿把必要条件推广到任意全局 affine contexts；audit.py 是固定有理反例的精确检查代码，本轮已全文阅读代码但没有把历史运行转记为新 run。

# 形式提升与 M1 结论

每组有 \(k\ge1\) 个原标签、活跃量 A、\(r\) 个导出 head、\(h=k-r\) 个 home。共同次数至多四的 functional L 满足 Boolean ideal、\(X_wA=X_w\)、\(\sum_wX_w=rA\) 和共同 M2 PSD。对含 t 个不同 head 标签、s 个 home 标签的合法请求，下降阶乘替换为
\[
\frac{(h)_s}{(k)_{s+t}}\prod_w X_w,
\]
纯 home 请求为 \(1-(1-(h)_s/(k)_s)A\)，冲突请求取零；k=1 单独用线性替换。类别计数 \(n_0=k-rA,n_w=X_w\) 满足 \(\sum_cn_c=k\)。标签平均与 contrasts 分解后，每组 contrast 平方等于
\[
\frac1{k(k-1)}\sum_{a,c<e}(d_{a,c}-d_{a,e})^2L(n_cn_e)\ge0,
\]
因 head-head 与 home-head 交叉矩为非负。这证明形式提升在常数、恢复后原单变量及未动 affine context 的 M1 上 PSD，涵盖 r=0、r=k、k=1；它不证明 M2 或完全正的随机 kernel。

# 有理 M2 反例与审计能力

固定 \(k=4\)、十个 head、\(\sum_iX_i=4\)，取 210 个四子集的均匀 law \(\nu\)。另取有符号权 \(\beta\)：完全落在两半的四集各权 1/8，前后各二的四集各权 -1/400，其它为零；令 \(\delta=1/100\)，\(L(Yf)=\delta E_\beta f\)。这满足至四阶 Boolean/cardinality ideal；扩大 Gram 的三类特征值和 Schur 余谱均严格正，aggregate 67 维 M2 的历史精确检查 rank=55。

下降阶乘形式核作用于 \(Q=Y\sum_i s_i(x_{1,i}-x_{2,i})\)（前半 \(s_i=1\)、后半 -1）给
\[
L'(Q^2)=-1/150.
\]
更强地，任何保留该 aggregate 全部四阶矩、原任务 one-hot、每 head 完整 row CONFIG 与共同 M2 的原身份扩展，都必须满足完整必要块
\[
K_{(i,\ell),(j,t)}=k\mathbf1_{i=j}L(X_i z_\ell z_t)-L(X_iX_j z_\ell z_t)\succeq0.
\]
取 \(z\) 方向为 \(s_iY\) 得 \(c^TKc=-1/25\)，故该给定 aggregate point 无原身份 M2 extension。这个量词是 given-point nonextension，不是所有 aggregate points、所有深度或所有 native scheduling instances 的不可能性。

# 全语境 SOS 与普通实例边界

affine-context 来源给出不依赖标签对称、也不要求 \(X_i\) Boolean 的 SOS：对任意 affine basis \(z_0=1,z_1,\ldots,z_s\)，令 \(t_i=\sum_lc_{i,l}z_l\)、\(B=\sum_iX_it_i\)、\(q_a=\sum_ix_{a,i}t_i-B/k\)，则
\[
c^TKc=k\sum_aL(q_a^2)\ge0.
\]
K 必须作为完整 head×context 矩阵看；不同 context 的单独 cross-block 不能各自声称 PSD。该块在保留完整原 M2 时是冗余的 SOS 证书，但对匿名投影是额外必须约束；它不构成充分的全标签 lift 判据，完整 label-partition/Young blocks 尚未闭合。

作者 Proof 与 audit 还构造了一个 13 台机器、6 job、48 finite endpoints 的 ordinary witness：固定 root job g 在 r，四个同菜单 f 各占不同 z，另一个 y 去 y0，峰值与下界均为 1。坏 aggregate point 只说明标签矩合同不能扩展，不是该普通实例的 makespan gap 或不可行证明；不能据此推出一般 UM near-two hardness、generic SDP solver 或 SH3 source reduction。
