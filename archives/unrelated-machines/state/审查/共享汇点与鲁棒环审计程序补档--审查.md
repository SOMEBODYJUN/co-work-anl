三份 source 均 clean show 导出并逐行读取，代码与 JSON 输出保存在 evidence/agent-um-20261101/batch3。共享汇点规范程序和独立重构程序都使用 Fraction；鲁棒环程序只枚举显式小实例，明示不是一般 UM solver 或 hardness reduction。

# 共享汇点和宏任务共同匹配

规范程序的输入合同为 H 个 home 加一个共享 sink；宏任务只能使用 home，所有有限宏边严格大于 T/2；tiny 任务带唯一 home、home 时间和可选 sink 时间；所有时间必须是非负精确有理数，eta 在 (0,1]。算法先在每个 home/macro 模式上运行 covering FPTAS，再以一次精确整数 Hungarian 匹配同时决定宏任务去 home、空 home 和 sink 退出。返回 SCHEDULE 时 home 负载不超过 T，sink 不超过 (1+eta)T；返回 REJECT_TARGET 时，对声明的合同有 OPT>T 的单侧保证。成功不承诺精确 T 可行，T=0、空 home、zero-cost、强制 sink 和 dummy 贡献均显式处理。

covering_fptas 保持覆盖约束精确，只将成本按全局最大项和 eta 做有理 floor；minimum_assignment 先清除所有分母后运行整数 Hungarian。规范程序的有限审计使用独立 subset/permutation/完整 assignment oracle，而不是用自身 DP 或 Hungarian 证明自身。

独立程序先读候选源的字节 hash，再以同一全局 delta=eta*T/N 对 sink 时间 floor，按 home 建立字典 DP，最后用独立 residual-flow matcher。它不调用候选的 cover、matching、normalization 或枚举 oracle。其 39200 systematic 与 2000 random 结果支持接口回归；candidate success_without_T_feasibility 和 independent_success_without_T_feasibility 分别为 1972 与 383，说明成功输出可存在于 OPT>T 的合同外实例，故不能把 success 计数写成可行性判定。

与既有 private-group-exit-pool 审查的关系是：本批补齐了无 profile 的单一共享 sink 规范代码和独立 DP 对照；宏任务退出、完整 pool profile 和 rho(1+eta)+beta 上界仍由 private-group 对象承担。共享 sink 的单侧拒绝、精确 bit 处理和 empty-home dummy 逻辑可以复用，但不能替换任意资格、多 sink 或无 profile 情形。

# 鲁棒环共享上下文相位

robust-cycle 程序要求每个 core 至少两台 machine，任务只在 home/successor 两个端点，端时间位于 [0,T]；不同 core 的 machine 集必须互不相交。给定一份严格 Cmax<=T 的实际调度和固定在原端的 context jobs，程序枚举每个 core 的全 home 或全 successor 两种 coherent phase。对所有局部小例，混合 phase 的可行性恰等价于某个循环 collision b_(i-1)+a_i 不超过 B；若所有 collision 都大于 B，则只剩两种 coherent phase。

共享上下文取向共 32 个；程序确认固定 context 不变、额外机器负载不变、每个目标峰值严格小于 3T-B，并核验 B=3T/2 的阈值等号。6 个 two-machine family 例和 8 个 strict-envelope 例展示三半包络及其尖锐性。域外例把两个 core 复用 machine M，在 T=1、B=6/5 时原峰值 1、切换峰值 23/10，超过 3T-B=9/5；该例明确不属于 theorem domain，不能当作域内反例。

# 证据层级、比较和处置

三源均处置为 integrated。共享汇点程序独有的是可执行的 cover/Hungarian 合同和 dummy/zero 边界；独立程序独有的是 floor-budget 与 residual-flow 的不同实现及合同外成功计数；robust-cycle 程序独有的是域内 coherent phase 的有限枚举、三半锐族和 machine-overlap 域外控制。

有限通过只支持所列输入和程序断言。共享 sink 不提供一般 unrelated-machines 矩阵的结构提取、任意资格容量恢复、多 sink decoder、统一小于 2 算法或 hardness。robust-cycle 不提供一般相位 decoder、近二困难性或 approximation algorithm。三源与 customer-attraction/SPE、weighted-congestion 和 facility-games 保持模型隔离。
