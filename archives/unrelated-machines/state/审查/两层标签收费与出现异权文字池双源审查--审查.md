# 阅读范围与对象分离

本批完整读取两个当前正文，并与直接共居 SAT、仿射线、查询级联和标签收费审查比较。两源都把源问题的标签/文字选择编译成显式 unrelated-machines 任务，随后构造一个不需要源解或 OPT 的完整实际调度；共同结论是完整的资格预算会留下至多 (3/2) 的绝对上界。第一源研究两层投影图、每边状态和标签次数的精确 (mathrm{OPT}) 恒等式；第二源研究 CNF occurrence 位置异权、每变量每极性总预算至多 1 的直接文字池。两者的机器、任务和共享关系不同，不能把一个的锐性转给另一个。

稳定身份为 `UM-TWO-LEVEL-LABEL-FEE-ESCAPE-v1` 与 `UM-OCCURRENCE-WEIGHTED-DIRECT-LITERAL-POOL-BUDGET-ESCAPE-v1`。二者都不是一般 `UM-TARGET-v1` 的反例或证明，也没有给一般 NP-hardness；它们准确关闭的是具体 compiler 合同。

# 一、两层共享标签收费逃逸

## 1. 定义域和实际矩阵

给显式二部投影多重图 (G=(U,V,E))，每点有非空有限标签集，边 (e=(u,v)) 有全定义投影 (pi_e)，允许平行边、孤立点、异字母表和非单射投影。度数不超过 (D\ge2)，记 (delta=1/D)、(eta=3/4)。每边状态 (a_e) 选一个左标签；任务/机器包括根状态 (s_e)、半长查询 (x^u,x^v)、(H) 端、端口 (A)、标签 (w)、辅助 (f)、以及按顶点分隔的 (B,C) pool。未列边均不可用，全部任务不可拆。

构造使用完整原任务：状态任务在 (R_{e,a_e}) 上为 1，选中状态的半长查询到相应 (H)，其余查询留根；被查询的 (H) 把 (z) 任务送 (A)，标签 (w) 和 (f) 再按标签次数决定是否送 (B) 或固定编号 (C_{v,r})。同一顶点不同标签共享 (A_{v,b})、(B_{v,b})，但不同顶点的 (C) 分开；没有隐藏重编号或虚拟 pool。

## 2. 全部边状态的三半上界与精确值

对每个顶点标签 (b)，令 (c_{v,b}(a)) 为所选边端点落在该标签的次数。因为总次数不超过 (D)，至多一个标签有 (c_{v,b}\ge\lfloor D/2\rfloor+1)。把重标签的 (w) 送 (B)，其 (D) 件 (f) 分别送固定 (C_{v,r})；非重标签的 (w) 留 (A)，其 (f) 留 (B)。根和 (H) 端按状态构造安排，故同一份完整调度满足
\[
C_{\max}\le1+\frac{\lfloor D/2\rfloor}{D}\le\frac32.
\]
这不需要源满足性、正则性或投影单射性，也不求最优边状态。

正文还给出给定状态选择的精确值。设 (c_{v,(2)}(a)) 是每个顶点标签次数中的第二大值（不足两个标签补 0），
\[
\mu=\min_a\max_v c_{v,(2)}(a).
\]
非空图上
\[
\operatorname{OPT}=1+\mu/D.
\]
上界打开每个顶点出现最多的一个标签，其余标签保留在 (A/B)；下界假设峰值小于 (1+mu/D)，由 (A) 的 guard、(B) 的 unit 标签和 (C<2) 的单位容量强制两个高次标签同时导出，导致超过 (D) 件 (f) 任务挤入同顶点的 (D) 台 (C) 机器，矛盾。该恒等式不提供计算 (mu) 的多项式优化器；三半算法只任取状态。

若源有 singleton 满足赋值，则取其边状态，所有顶点只打开一个标签，得到峰值 1；反向若完整调度峰值严格小于 (1+1/D)，状态根、半长查询、guard、(w) 和 (f) 的端点被逐层强制，恢复每条边的投影一致标签。因此在该合同中，峰值不超过 1 当且仅当源存在满足赋值；低于 (1+1/D) 的调度也能解码。空图单独给 OPT=0。

## 3. 强列表 NO 与实际值趋一

奇数 (q\ge3) 的两点图有 (q) 条平行边 (pi_t(a)=a+t\pmod q)。任意左右列表 (L_u,L_v) 覆盖的边标签至多来自差集 (L_v-L_u)，所以覆盖边数至多 (|L_u||L_v|\le(|L_u|+|L_v|)^2/4)。固定总列表 cost (\le2g) 并取 (q>g^2/\rho)，得到覆盖率小于 (ho) 的强列表 NO。

但同一矩阵取边状态 (a_t=t) 时，每个顶点标签恰遍历一次；把所有 (w) 留在 (A)、所有 (f) 留 (B)，每台 (A) 负载 (1+1/q)，其余机器不超过 1。严格低调度的反解给
\[
\operatorname{OPT}(I_q)=1+1/q,
\]
并且规模、有限边数按 (q) 显式多项式增长。因此强列表 NO 不会自动转成该实际矩阵的近二 NO；它只说明列表收费和真实负载之间缺少保持源目标的机制。

# 二、出现位置异权的直接文字池

## 4. 完整资格预算和槽构造

输入为显式 CNF，每个子句至少两个 occurrence；每个 occurrence (e) 有非负二进制有理时间 (b_e)，并要求每个变量每个 polarity 的全部 eligible occurrence 时间总和至多 1。任务包括变量 (f_v)（正负 pool 各为 1）、每个 occurrence query (j_e)（自身 root 为 1、对应文字 pool 为 (b_e)）、每个 clause selector (s_c)（到其 occurrence roots 为 1）。所有其它端点不可用，重复变量和重复文字仍保持不同 occurrence 身份。

每个变量的正负 occurrence 列表按 (b_e) 降序。两侧首项共享一个容量一的槽；每侧剩余项按相邻二项配槽，奇数剩项单独成槽。每个 clause 把 (1/k_c) 质量送到包含其 occurrence 的槽；槽最多含两项且每项不超过 (1/2)，因此 slot 列和至多 1。二部匹配整数性给出同时覆盖所有 clause 的整数槽匹配，保留真实 occurrence witness；虚拟槽不进入实际矩阵。

## 5. 同一实际调度的负载界

匹配选出的 occurrence 在其原文字 pool 执行，同一 clause selector 放到对应 root；其它 query 留私有 root。每个变量至多有一侧首项被选，因此把 (f_v) 放到未选首项侧。该侧选中 query 的负载是偶数项之和，满足
\[
w_2+w_4+w_6+\cdots
\le\frac{w_1+w_2+w_3+\cdots}{2}\le\frac12.
\]
另一侧的选中 query 是全部 eligible 子集，负载至多 1；所有 root 至多 1。故同一份完整任务分配的峰值至多 (3/2)，不要求 SAT、strict 见证、配置 oracle 或源赋值。零时间、未使用变量、空公式和重复 occurrence 都在合同范围内；unit/empty clause 不在其承重域。

这是完整资格预算的关键：槽只证明每个变量的一侧首项与其余 occurrence 的配对，不改变原任务端点，也没有按 (1/b_e) 或分母数值展开。它关闭的是本页 private-root/full-sign-budget compiler；删掉预算、加入 shared guards、跨子句端或更大 pool 资格后需重新证明。

# 三、关系、证据和开放义务

1. 两层源的 (1+mu/D) 精确值把源一致性与真实负载分开：严格低于 (1+1/D) 才能逐层恢复 singleton 赋值，而强列表 NO 仍可对应 (1+1/q) 的真实调度。出现异权源则直接用槽匹配把所有 clause 同时接入，弱端绝对峰值不超过 (3/2)。
2. 两源都说明“源列表/逻辑难度”不能仅靠共享标签收费搬进 unrelated-machines：必须同时阻止任意低峰值实际调度，且保留所有原任务的合法端点和共同容量。
3. 第一源的精确 (mu) 恒等式、投影一致性反解、奇数平行边列表 NO 与实际值趋一是独有内容；第二源的完整 occurrence budget、首项共享槽、偶数项负载界和重复 occurrence 回填是独有内容。二者不互相替代。
4. 有限审计只核对所列展开输入、负载和列表计数；一般边状态优化、源 assignment 搜索、去预算后的矩阵、复杂度 hardness、外部新颖性和 `UM-TARGET-v1` 均开放。第三阶段若要扩展，必须明确新的资格结构、预算量词、低峰值解码和输出规模。

两源均已完整阅读并归档为“具体 compiler 的正面逃逸与方法边界”，没有因不在主线而丢弃，也没有把至多 (3/2) 的构造误写成一般算法或把强列表 NO 误写成实际近二下界。
