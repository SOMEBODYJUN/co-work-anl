# 实读与运行边界

两项 source 均 clean show 导出并逐行读取。token-label 程序自包含，本地输出 independent_exact_first=true、source proof 未读声明、固定十点四子集权重的 Gram/moment 检查；top-two 程序需要读取 research/current/unrelated_machines/top_two_pair_witness_boundary.md 作为 provenance，当前结果树没有该 canonical path，故未伪造 JSON。

# Token-label nonextension

程序在 10 个位置中选 4 子集，构造均匀 nu、带 Y-bit 的 delta*beta moment，并用 Fraction 精确计算一阶/二阶矩和 Gram PSD。它直接检查 source token lift 的 first/second moment identity、非扩展事件和矩秩；不导入 repository implementation 或 author proof。该审计只针对固定构造点，不能升级为一般 token-label hardness、调度算法或 full source compiler。

# Top-two pair witness

程序以每个 occurrence 两个 machine ports 构造 s/f/unit jobs，变量 occurrence 形成 cycles，assignment 的奇偶位解码为变量值；top_two_score 使用每台机器最大的两件作业总量。它枚举 clauses、assignments、validity、decode 和 B2 objective，独立核对 occurrence-cycle construction 的实际 assignment。由于 canonical proof 文件缺失，运行停止在 provenance 检查，未把源码的有限枚举当成完成证明。

# 处置

两源均处置为 integrated。源码和 token exact 输出保存在 batch9 evidence；top-two provenance 缺失如实记录。结论限于 token/moment 或 occurrence-cycle 二件见证合同，不升级为一般 unrelated-machines approximation、NP-hardness、外部新颖性或 customer-attraction/SPE 结论。
