# 逐资源正权畸变与固定κ边界审查

本文逐段核对主源 e485500ab42843f24524 与关联审查 ca8a79d256ec0619a338 的实际范围。主源当前 clean show 副本为10835字节、SHA256 为 983480e2db1676add57db68cbfd0f7eed4521cddc9c3152ef1de9fe6a283615b；审查副本为20415字节、SHA256 为 7859b1ee8f0fd880dbd78ef88d47aabdd58e1b588abe02601263286c078fe9a2。

## 1. 域和量词没有被压缩

输入是非空有限组集，每组有非空显式 indexed states；每个 state 的资源集合不重复、private 总质量 \(W_x\le1\)，所有资源机器与 state private 机器独立。selector 只在本组 state 机上耗时1，每个 incidence 只有 private 端 \(p_{xu}\) 和对应资源端 unit 两种资格。未选 state 的 jobs、零权 jobs、空 incidence state、重复 indexed state 和 unused/all-zero resource 都是实际域的一部分。

\(\kappa\) 只取每个资源上正 private 权的最大/最小比，外加常数1；零权不参与，all-zero 不制造 \(0/0\)。算法对每个固定 \(\alpha>4\) 给出总位多项式实际分配，但不把 \(\alpha\) 当输入、不需要 OPT、配置证书或 \(\kappa\) 上界。

## 2. Baseline \(V\) 和 actual OPT

审查确认 \(W<1\) 时必须把 \(b_x=1-W_x\) 作为 state baseline：
\[
f_g(B_g)=\max_{x\in S_g}
\left(b_x+\sum_{u\in B_g\cap S_x}p_{xu}\right),\quad
V=\max_{B_g\text{ disjoint}}\min_g f_g(B_g).
\]
它不是旧的无 baseline 菜单值；全零 state 的 \(V\) 可以为1而旧无 baseline 值为0。

正向用达到 \(f_g\) 的 state，导出 \(B_g\) 中的原 incidences，其余全部原 jobs 留 private，得到峰 \(2-V\) 上界。反向仅对 \(C<2\) 调度读取资源 unit 独占；每个 selector 的实际导出资源形成不交 \(B_g\)，selected private 负载给 \(f_g\ge2-C\)。全private峰至多2，故
\[
\mathrm{OPT}=2-V
\]
连同 \(V=0\)、\(\mathrm{OPT}=2\) 端点成立。审查特别排除了在峰恰2时误用资源独占的常见错误。

## 3. Restricted-Santa 转换逐项成立

中间 Santa 实例每个 state 一个 player；每资源只有一件 real item，值为该资源上的最小正 private 权；每个 \(b_x>0\) 建一个只属于该 state 的 baseline item；每组再建 \(|S_g|-1\) 件只属于本组的 unit dummy。资源不能按 incidence 克隆。

审查确认两侧值界
\[
V/\kappa\le V_-\le V.
\]
左侧由源 \(B_g\) 见证和 \(p\le\kappa q\) 得到；baseline 因 \(\kappa\ge1\) 可一并比较。右侧从任意 Santa allocation 为每组挑一个没有本组 dummy 的 player，保留其不交 real items，利用 \(b_x+\sum p_{xu}\le1\) 得到原 \(V\) 不小于 Santa 最小值。零权、\(b_x=0\)、全零资源与 \(V=0\) 不需额外正性假设。

## 4. 外部后端和原任务解码边界

固定有理 \(a\in(4,\alpha)\)，主源导入 Cheng–Mao restricted Santa Theorem 1 的完整 \(a\)-近似合同，得到 \(t\ge V_-/a\)。审查接受这个已发表后端，不把其 Build/Collapse、配置搜索或未知目标处理重新声称为仓库实现。

从后端 allocation 中为每组选择一个 dummy-free player，把 selector 放回对应原 private 机；只把该 player 收到且有正价值的 real items 对应 incidences 外送，其余原 jobs 全部留 private。审查逐项确认：

- real item 不交，故资源机至多一件 unit；
- 即使所选 player 没收到自己的 baseline，仍有 \(t\le b_x+\sum q_u\le b_x+\sum p_{xu}\)，故 selected private 负载不超过 \(2-t\)；
- 未选 states、zero jobs 和没有对应 real item 的 incidences 不删除，private 负载至多1；
- 输出是完整原矩阵的具体调度，而不是只有 Santa allocation 或估值证书。

于是 \(C\le2-(2-\mathrm{OPT})/(\alpha\kappa)\)，再由 \(O=\mathrm{OPT}\in[1,2]\) 和
\[
(2-c)O-\left[2-c(2-O)\right]=2(1-c)(O-1)\ge0
\]
得到第二段近似式。

## 5. 固定κ反面源筛选的严格边界

若所有归约输出满足 \(\kappa\le\kappa_0\)，YES 有 \(\mathrm{OPT}\le1\)，NO 有 \(\mathrm{OPT}\ge2-\varepsilon\)，且
\[
\varepsilon<1/(\alpha\kappa_0),
\]
则可选固定有理 separator
\[
2-1/(\alpha\kappa_0)<\theta<2-\varepsilon.
\]
YES 的算法输出峰严格小于 \(\theta\)，NO 的任何调度峰严格大于 \(\theta\)。这只筛掉固定κ完整flat像类中的严格间隔 promise；κ 随输入或精度增长时不推出统一常数，也不推出一般 UM 容易或困难。审查保留严格小于号，未把等号边界误写成可判别间隔。
