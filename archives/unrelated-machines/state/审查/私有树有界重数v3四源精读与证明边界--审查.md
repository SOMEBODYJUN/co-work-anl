# 对象与冻结边界

本批四源围绕候选 `UM-Q-PRIVATE-TREE-BOUNDED-MULTIPLICITY-CONFIGURATION-FLOOR-v3`。模型是有限非空 root 集 U；每个 `(u,s)` 是完全私有的满 d 叉高 h 树，内部 edge job 父端时间 1/d、子端时间 1，leaf job 父端时间 1/d、外机端时间 1；selector 选择一个状态根。状态内叶映射 `f_us:[d]^h→Z` 允许重复，但每个完整状态对每个实际资源的叶重数至多 μ。不同 root、不同状态的外机可共享；μ 是输入上界，不自动成为固定常数。

完整配置 LP 的资源行按叶 job 的实际重数求和，不能把相同外机的多枚叶去重。v3 的新桥是：先把叶位置按 occurrence index 分成至多 μ 个各自 rainbow 的类，再用 raw 叶 blocker 把资源命中条件转成**逆像叶数**下界，最后用同一共同 λ 的 multiplicity 容量与 Haxell 条件衔接。该对象仍远小于一般 unrelated-machines；没有把它升级为一般 UM 算法、近二 hardness 或六人 SPE 结论。

# 四源逐项阅读与一致性

## 1. Exact-only 陈述（`f02042e957b3e9be7426`）

Exact 给出三个层次。局部 L 声称：在满 a 叉高 h 树中每资源出现至多 μ 次，存在满 `ceil(a/μ)` 叉高 h 的 rainbow 子树；若资源集合 X 命中所有 rainbow 满 r 叉子树且 `μ(r−1)<a`，则 `|f^{-1}(X)|≥[a−μ(r−1)]^h`。A 要求每 root 的同一共同有理 λ 满足 `Σ_s λ_us=1` 与 `Σ_{u,s} λ_us |f_us^{-1}(z)|≤1`；在 `B=[d−μ(r−1)]^h≥2r^h−1` 时，Haxell 给每 root 一个真实状态及 rainbow r 子树，资源彼此不交，并回填完整 P 得到 `Cmax≤2−r/d`。B 将该桥用于 CONFIG(T)：`s=floor(d(T−1))`、`a=d−s`，选择 `r=ceil(a/(μ+2))`，得到 `α_μ=2−1/(μ+2)` 与 `OPT≤α_μ T`；μ=1 为 5/3、μ=2 为 7/4 的候选界。Exact 明确声明这是存在性，不声称变参数位多项式输出 σ。

## 2. 独立重构（`3bcfe2dc0fd9d849e80b`）

重构从 raw 叶集估值 q 的子可加性开始，并逐高度核对了发生次数分组。对每个资源的第 j 次出现组成第 j 个 occurrence class，每类全局 rainbow；`q(full)=a` 与 `q(∪A_i)≤Σq(A_i)` 给出 L1。删除 `f^{-1}(X)` 后剩余叶集没有 rainbow r 子树，因此每 occurrence class 的 q≤r−1，总 q≤μ(r−1)。把剩余 q 压到 t=μ(r−1) 意味着删除集命中所有 raw `(t+1)`-叉高 h 子树；raw blocker 的精确最小叶数为 `(a−t)^h`，即 L2。这里计数对象是叶逆像，不是 `|X|`，也没有先除以 μ。

在 A 层，候选边只取 rainbow r 子树，边的资源侧大小恰为 `R=r^h`，加 root 标记后的总均匀度是 `R+1`。若资源集合 X 命中 I 个 root 的全部候选，L2 对每个状态给出逆像至少 `B`；共同 λ 加权并交换有限求和，得到 `B|I|≤|X|`。当 `B≥2R−1` 时满足总边大小 `R+1` 的 Haxell 严格 transversal 条件 `2(R+1)−3=2R−1`。独立稿还明确：外部 Annamalai/AFS 仅按前阶段已核对的 primary 复述使用，未冒称重读 Haxell 1995 原文。

CONFIG(T) 桥把每 root 的状态 selector 边际递归成一个满 a 叉辅助树分布。内部行 `Σ_e min(q,t_e)≥a q` 允许逐节点拆成 a 个 child；叶 activation marginal 不超过配置 LP 中对应 leaf job 边际。辅助分布的资源行仍是期望叶数，因此保持 `Σ λ |f^{-1}(z)|≤1`，重复外机不被去重。Haxell 最终只返回每 root 一条原状态中的见证树，私有内部机器不冲突；其余原 jobs、未选状态和零权状态全部父置，故不丢任务。

## 3. 作者冻结证明（`55b4525e0a5dd85493e7`）

作者证明与独立重构在关键处完全对齐：q 的多集合归纳、occurrence classes、raw blocker `(a−μ(r−1))^h`、共同 λ 的实际 multiplicity 求和、候选边 rank `r^h+1`、Haxell 严格差、CONFIG 的 a-tree 支配桥、原 P 全部 jobs 回填，以及 `r=ceil(a/(μ+2))` 的算术。作者也明确将辅助树视为有限存在性构造，不把指数候选族或 Haxell 匹配搜索包装成一般变参数位多项式算法。

关键算术是 `a−μ(r−1)≥2r−1`，从而 `(a−μ(r−1))^h≥(2r−1)^h≥2r^h−1`；令 `β=1/(μ+2)`、`x=a/d`，则 `r≥βa` 且 `2−βx≤(2−β)(2−x)`，给出 `OPT≤α_μ T`。T≥2 时全父置调度提供 C≤2 的端点。

## 4. 作者读后审查（`a6745267b75dbc4a731a`）

读后审查将 Exact-only 重构与冻结证明逐节比较，未发现 L/A/B 的 standing fatal objection。它确认 multiplicity 容量必须按 `|f^{-1}(z)|` 计；把它写成资源 image 的去重大小会破坏 (3)/(5)。它也确认 Haxell rank 是 rainbow 资源数 `r^h` 加 root，而非 μ 倍或 raw 叶 multiset 长度。CONFIG 辅助分布可以指数支持但不改变有限存在性结论。

唯一应保留的措辞修正是作者证明 §7 的“d=1 的实际调度为 1”缺少 A/B 可行前提。若无共同 λ/CONFIG(T<2) 条件，两个 root 的唯一叶可以映到同一外机，此时两个 leaf 同时外送使外机负载 2，而父置也使各内部机器负载 2，OPT=2；因此无条件 d=1 只能说 C≤2。该反例不触及正式 A/B，因为在 T<2 时共同容量本身已不可行。

# 数学判断与可接续关系

- **已证明/内部一致**：在完整 private tree、状态内每资源重数≤μ、共同 multiplicity λ、Haxell 适用的有限存在性前提下，L 的 rainbow/blocker 桥、A 的不相交 rainbow 选择、B 的 `α_μ=2−1/(μ+2)` 配置间隙上界和原 P 回填链在四源间一致。
- **条件结论**：μ 固定时才得到输入无关的离二常数；μ 随输入增大时 α_μ 仍逐实例小于 2，但不产生统一 ε。`T≥2` 仅给直接 C≤2，不提供小于 2。
- **有限实验/程序**：本批没有程序或有限枚举；证据只保存四份原文、哈希 manifest 与字节校验脚本。
- **障碍与未决**：Haxell 候选族可能指数大，尚无一般变参数 bit-polynomial σ 构造；μ 上界、共同 λ 和完全私有内部机器是不可省的合同。若要把该层接到 v2 的判定/实现，必须另证如何显式产生见证，而不能把 CONFIG 分数点当作整数联合调度。
- **原模型反例**：无条件 d=1 退化措辞的两-root同外机例子已记录；它只修正边界说明，不否定正式结论。
