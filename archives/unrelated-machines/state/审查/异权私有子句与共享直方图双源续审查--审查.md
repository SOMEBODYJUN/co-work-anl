# 2. 异权私有子句网络：给定见证的实际三半交换

## 2.1 单子句异权交换

稳定身份 `UM-GENERAL-WEIGHTED-QUERY-RETURN-THREE-HALVES-EXCHANGE-v1`。内部机器 H、固定辅助任务 A、两族边界任务 `Q={q_1,...,q_k}`、`R={b_1,...,b_k}`，每个边界任务另有独占 private outside 机耗时 T；内部端可任意非负有理/不可用，允许异权、零和大于 T。给同一 P 中两个不同索引的完整 actual aligned 调度 `sigma_i,sigma_j`，都峰值≤T。

从两个见证删除 query 后构造分析实例，调用已有双见证 query separation 得到两个≤3T/2 的 single-query 分配。非 query `b_j` 只可能被一份支持移出，故至少一份保留所需内部边；A 和其余边界任务按支持不交地回填，测试 outside 只在分析中存在。最后将原 P 中所有未分析的边界任务放回各自 private outside，保证每个原任务恰执行一次、外部负载≤T，于是输出 inactive 或指定 cross 模式且 `Cmax≤3T/2`。

该证明只依赖给定 actual 见证，存在量词与可计算量词分开；没有给定见证时不能隐藏一般调度求解器。H 空、A 空、zero/∞ 端点均按显式矩阵处理；共享 outside、辅助外送、多 query/return bundle 都不在结论内。

## 2.2 全 CNF 私有子句模板

稳定身份 `UM-PRIVATE-CLAUSE-QUERY-RETURN-UNIVERSAL-THREE-HALVES-v1`。每 clause 有 `k_c>=2` 个 occurrences，真实 q/b 任务接变量环两端或 clause 内部 H_c，b 的外端是 literal pin；dummy q 只有 ring 两端，dummy b 只有 private T 端。给每个真实 occurrence 一份局部 aligned actual 证书，只覆盖该 clause 内部，不预设全局 SAT assignment。

每个 clause 先枚举局部模式：若一次交换返回 inactive，就保存 baseline；否则保存全部 cross(j,i) 和输入 diagonal。然后构造真实 ring 共同 matching：q/b 任务和每个 active clause 的分析 label 作为左侧，ring 机、分析 K/V label 作为右侧。active occurrence 的质量 `theta_i=1/k_c` 从 b 的 pin 扣到 V，label w_c 补足 K；行列和为一，Hall 整数性给一个**共同** perfect matching。每个 active clause 恰一 query 和 return，baseline clause 使用 inactive，回填后所有真实 q/b 和辅助 A_c 恰执行一次，ring 每机至多一任务，内部峰≤3T/2。

因此只要完整局部证书作为输入，任意 SAT/UNSAT 都有实际全公式 `Cmax≤3T/2`；没有这些输入证书只保存在性，不能声称算法会寻找未知 strict 调度。于是该准确模板不可能作为 `OPT>T(2-delta)`、`delta<1/2` 的近二 NO 归约。

## 2.3 共享 outside 的真实边界

四任务共享外端模块中，两个 aligned 调度都有 OPT=1，但 inactive/cross 模式在严格阈值下分别为 `2-epsilon` 或 2；共享 outside 使局部私有交换不能直接回填。它只反驳“把每个 outside 自动私有化”的步骤，不提供 source decoder。小查询池进一步给精确关系：q_i 仅能在 H 或同编号 E_i，b_i 仅能在池 P 或 E_i；对任意模式 S,T，`OPT=1` 当且仅当 `T` 非空且 `T subseteq S`，否则 `OPT=2`。这说明多个 query 可以共居 H，但它没有变量一致性或困难性含义；将 E 合并进环或共享容量需另证。

# 3. 共享负载直方图：弱递推等于 CONFIG 投影

## 3.1 定义域和精确等式

稳定身份 `UM-SHARED-LOAD-HISTOGRAM-CONFIG-PROJECTION-v1`。机器数 m、标签任务 J、整数时间 `a_ij in {0,...,K}`，不可用端为 ∞；零时间任务保留标签，任务可无有限端。前缀 `[j]` 的 CONFIG(K) 允许每机从容量合法配置中抽取一个随机子集，所有任务总覆盖恰一，但不同机器之间不要求共同 coupling。只记录每机总负载直方图 `y_(r,s)`，令 P_j 是完整 CONFIG 的直方图投影。

弱递推从空负载开始。处理任务 l 时，在有资格机器上取权 `theta_i` 和按机器/负载的质量 `z^i`，aggregate `sum_i z^i` 只须属于前一层弱集合；选中机器一行负载平移 `s -> s+a_il`，其他行保持。递推**不要求**每个分支 `z^i` 属于 `theta_i` 倍的真实共同调度凸包。

正文证明对所有输入和前缀
\[
\widehat H_j=P_j.
\]
前向方向按每行 add/stay 单位流做路径分解，得到完整 CONFIG；反向方向从任意 CONFIG 取当前任务包含/不包含概率，在每个 branch 定义 `z^i`，用条件概率归一化处理 `x_(r,l)=1` 的不除零情形，给出全部弱递推。等式是负载直方图的精确投影身份，而非真实 schedule convex hull 身份。

## 3.2 LP 与可靠拒绝

节点是每机层/负载状态，弧是 skip 或有限端 selected 平移；每任务跨机器 selected 弧总流量为一。LP 规模
\[
O(m(j+1)(K+1)+|E_[j]|(K+1))
\]
，系数为 `0,+/-1`，对整数时间和固定有理输入总位长多项式；但若 K 以数值给出，属于伪多项式。LP 可行点和 Farkas 证书可计算，不能用纯网络 TU 声称整体整数，因为跨机器任务覆盖 side constraints 会破坏该简化。

对一般有理 P 和阈值 T，可按固定 delta 把时间下取整到 `q=delta T/n`，容量 `K=floor(n/delta)`。真实 `T` 调度给出该 LP 的可行点，因此 LP 不可行可靠推出 `OPT>T`；LP 可行只提供弱 CONFIG/直方图证书，不能输出实际调度。`T=0`、空任务、删空资格均独立处理；若 delta 是输入，复杂度依赖数值 `1/delta`。

## 3.3 共同相关性反例

四机六任务整数例（容量 K=3）前四任务有两个真实 perfect matchings，CONFIG 行各半可覆盖；弱递推在加入 A 时拆分非负坐标，产生机 1/2 恒负载 3、机 3/4 各半负载 2/3 的直方图点，但真实前缀 H_5 中 A 只能从 O 端进入，机3/4 应恒负载 3。再加入 B，弱递推可回到每行负载 3 的 Dirac，然而真实整数 OPT=4（缩放后 OPT=4/3）。这给出“直方图投影可行但真实共同状态不可行”的精确反例；末层全为 Dirac 也不能恢复丢失的祖先相关性。

若要保住共同容量，应要求每个分支 `z^i` 位于真实前缀共同调度凸包 `H_(j-1)` 的相应缩放中，而不是仅属于 aggregate 弱集合。该强系统的生成、查询和解码复杂度仍未给出；本源没有把局部直方图 LP 误写成一般低于二舍入。

# 4. 双源关系、既有工作与开放义务

第一源的三半结论依赖实际 local certificates 和 private outside；第二源的等式只描述 CONFIG projection。两者都展示逐对象局部信息无法自动提供全球共同容量，但第一源给出真实实际 schedule，第二源明确展示即使每一步 histogram 都合法也会丢失任务身份/祖先相关性。不能用第二源反例否定第一源的给定见证算法，也不能用第一源三半回填修复弱 histogram 递推。

与双见证 query separation 的关系：第一源是其异权/全公式直接结构推论，新增是完整 CNF ring 的共同 matching 与 shared outside 的精确反例；与 unit readout、宏/tiny 和弱 H2 的关系只在“共同容量”层面，模型和量词仍独立。第三阶段可记录：

- `private clause + two actual aligned witnesses` → `local 3/2 exchange` → `global ring matching` → `full actual 3/2 schedule`；
- `aggregate load histogram recursion` = `CONFIG load projection` → `weak LP sound rejection only`；`no branch coupling` → `not a real schedule hull`。

未闭义务：在一般 UM 中生成局部见证、处理真实 shared outside/多 bundle、构造近二 NO 的全局 decoder，以及给共同前缀凸包一个可分离/可舍入表示。两源都不证明 `UM-TARGET-v1`、NP-hardness 或一般近似下界。有限/精确例只核对结构边界，不扩大量词。
