两项实际修正如下。

1. v1 第 4 项声称既有两套编译器的整个输出族“含合法常量分支”都满足末层两色。但旧 v1 常量仅为“固定 YES/NO”，未规定颜色。高一三叶 `(A,B,C)`（三色互异）是合法二叉虹彩 YES，却不满足末层两色。故合法 YES 本身不蕴含此前提。需要固定 `(A,B,A)` 与 `(A,A,A)`，或把结论限定到实际满足前提的输出。
2. 普通树矩阵的一般树 U 须有高度 H≥1。若允许 H=0，根不是内部节点，其 private machine 和 root pin 均未定义。不能把这一点隐藏在公式中。

现有 v2 对象第 3 节把 t 称为“真正下送”的件数后写成 `1+t/d`，其后仍得到正确下界；该处变量释义与负载式不符。下文明确以 t 表示下送数，负载为 `1+(d−t)/d`，不复用这项排印。以上不否定末层条件下的定理，也不构成一般 UM 算法或所有张量的障碍。

# 【论文版本】

## 1. 对象与普通树矩阵

令 U 为显式完整 d 叉树，d≥2，所有叶在共同深度 H≥1，叶色可重复。令 q(U) 为含根、全部叶仍在深 H、每个活跃内部节点恰选 r 个孩子且叶色互异的满 r 叉子树所允许的最大 r。路径给 q(U)≥1。

矩阵 P(U) 为每个内部节点设置一台私有机器、每种叶色设置一台资源机器。根 pin 仅可在根以时间 1 执行；每条原树边是一枚不同作业，父端时间 1/d，内部孩子端或叶色资源端时间 1，其余端不可用。全部边作业及 pin 都必须执行。

有精确等式
\[
\operatorname{OPT}(P(U))=2-\frac{q(U)}d.
\]
给定满 r 叉虹彩子树，把见证边作业下送，其余作业父置。活跃机器负载为 `1+(d−r)/d`，非活跃机器为 1，叶色资源至多一枚 unit 作业，因此给出完整调度上界。

反之，对任意峰值 C<2 的完整调度，根被 pin 激活。若活跃节点有 t 枚边作业下送，其负载为 `1+(d−t)/d`，故 t≥d(2−C)。逐层选取 `ceil(d(2−C))` 枚真实下送边；资源不能承载两枚 unit 作业，所获叶色互异。因此 q(U)≥d(2−C)，给出下界。C≥2 时该下界自动成立。该等式不提供寻找最优 q 的多项式算法。

## 2. 对齐张量与比值上包络

令 T 为完整三叉树，高 h≥1，每个末层父节点的三叶至多两色。对整数 k≥1，T^[k] 的同深节点为有序 k 元组，孩子逐坐标继承，叶色仅按有序颜色 tuple 的完全相等识别；其分叉度为 d=3^k，高度仍 h。

每个张量末层父节点最多有 2^k 种孩子颜色，故 q(T^[k])≤2^k。若 q(T)≥2，将一个原二叉虹彩见证逐坐标相乘，得到满 2^k 叉虹彩见证，因而
\[
q(T^{[k]})=2^k,\qquad
\operatorname{OPT}(P(T^{[k]}))=2-(2/3)^k.
\]
有序 tuple 的单射性至关重要，不允许使用可能碰撞的编码或重着色来替代。

任意同域 NO 树也有路径调度，峰值至多 2−3^(−k)。因此对任何实际 YES/NO 实例对，其比值上界为
\[
G_k=\frac{2-3^{-k}}{2-(2/3)^k}.
\]
这不要求原 NO 谓词在张量后保持。置 x=3^(−k)、y=(2/3)^k，交乘比较 G_k 与 G_(k+1) 的分子差为
\[
(2-x)(2-2y/3)-(2-x/3)(2-y)
=\frac{x}{3}(2\cdot2^k-4+2^kx)>0.
\]
所有分母正，故 G_k 严格递减，G_1=5/4，极限为 1。若 YES 家族为空，只作逐实例对的真空陈述，不定义空集合的最大比值。

## 3. 纯收缩与编译器范围

若 k≥2 且 k|h，纯 k 层收缩保留原叶色，以原 k 步后代为宏孩子。末层每宏父下有 3^(k−1) 个原三叶星，总颜色数至多 2·3^(k−1)。因此宏树
\[
q\le2\cdot3^{k-1}<3^k-1=d-1.
\]
原 YES 也受此限制。k=1、非整除高度、重着色、跨副本约束及 padding 不在该结论内。

既有非退化 Rigid 在高一时为 `(A,B,A)`，Dead 的末层同色；Atom 以正高度构件实现，AND/OR/Pad 只在正高度子树上方拼接，保持末层两色。当前 v2 固定常量 YES `(A,B,A)`、NO `(A,A,A)`。旧 v1 未指定的常量不能倒签为已经符合该规范。

## 4. 显式规模与接续

若原树有 N 个节点，张量第 ell 层有 3^(k·ell) 个节点，总规模至多 N^k，颜色 tuple 还须计编码位长。固定 k 时为多项式；不按 binary k 承诺多项式展开。纯收缩规模不超过原显式树。允许更大展开不会改变精确比值 G_k。

本页与 v2 是“历史异议及定义域修正”关系，与三叉 SAT 构造是“条件来源”关系；不是独立 hardness 放大证明。它保留 v1 未成熟部分和真实修正，后续可直接判断某个新编译器是否满足末层条件。改变颜色、端点或乘积操作后须重新核验，不能沿用本页宣布一概失败。
