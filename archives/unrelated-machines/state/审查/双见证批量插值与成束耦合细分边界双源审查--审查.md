# 一、批量双见证插值（`5610bbdbcc1156bc2668`）

## 1. v3 的完整域、输入量词和结论

稳定身份为 `UM-UNRELATED-AUX-HEAVY-READOUT-BULK-OR-COMMIT-SPLIT-v3`。输入是显式完整 ring backbone：每个变量块有 $2k$ 个环位置、正负 $k$-block、$M_{a,i}$、$C_{a,i}$ 和两个 pool $A_{a,0},A_{a,1}$；参数满足 $r≥2$、偶数 $k≥2$、$1/2<ρ<1$。`q` 在自身 $M$ 取 $ρ$、后继 $M$ 取 1、所属 block pool 取 $1/k$；正/负 `b` 分别有对应的 $M/C$ 端；selector `f_a` 只有两个 unit pool 端。额外辅助任务 $J$ 可以去任意内部机器 $I$，或去正 readout $C$ 且其有限时间在 $(1/2,1]$；它们必须保留真实任务身份、异权端、零时间端和跨 branch 资格。backbone 不接 $I$，$J$ 不接负 $C$、$M$ 或 pool。

给定不同变量 $(u,v)$ 的两份完整实际 strict $\le1$ 调度 $\sigma^u,\sigma^v$：第一份只让 $f_u$ 在负 pool，第二份只让 $f_v$ 在负 pool，其他 selectors 在正 pool。两份都覆盖所有原任务一次；同一矩阵的 OPT 由 strict 见证给出上界 1，而任一 selector 的全部有限端都是 unit 给出下界 1，故原模型 OPT 恰为 1。结论不是寻找这两份见证：一旦它们作为输入已给出，即可确定性总位多项式构造同一矩阵的完整 all-false 调度，所有 selectors 都放到各自的正 pool，最大实际负载至多 $3/2$。更细的 v3 负载界为：所有 $M,C\le1$，内部 $I\le3/2$，所有 pool $\le3/2$。

## 2. strict 计数和共同流的实际证明

在 strict 模式中，因 $ρ>1/2$，每台 $M$ 至多含一枚 `q/b`；正 $C$ 上的每个 $J$ 也大于 $1/2$，因此每台正 $C$ 至多含一枚 $J$，且与 unit `b` 不能共居。正 pool 为假 branch 时已被 unit selector 占满，环回填迫使除至多一个可导出的 `q` 外的正 `q` 只能留在正 $M$；因此该 branch 每个正 $C$ 的 $J$ 计数至多 1。令 $c_a^t$ 为见证 $σ^t$ 中正 block $a$ 接收的全部 $J$ 数，$K_a=⌈(c_a^u+c_a^v)/2⌉$。特殊 $(u,v)$ 的 $K_a≤⌈(k+1)/2⌉=k/2+1$，其余 $K_a≤1$。此计数包含 guards、aux 和跨 branch 共居，不能按 branch 独立忽略。

先固定两份见证中目的地相同的 $J$。对每个未固定 $J$，保留它在两份见证的两个带标号出现项，各送 $1/2$ 流。内部机器 $h$ 把其出现项按时间非增排序，邻项成容量 1 slot，奇数末项单独成 slot；每个正 $C$ 是单容量节点，再连接所属 branch gate，gate 容量为 $K_a-d_a$，其中 $d_a$ 是固定 $J$ 数。源到每个未固定 $J$ 容量 1，$J$ 连到它两个见证端所在 slot 或 $C$，slot/C 到汇容量如上。半流给出覆盖所有 $J$ 的分数流；网络整数容量使同值整数满流存在，按任意固定的增广顺序可确定性解码，每枚 $J$ 只执行一次，永不把 slot 当成物理机器。

若 $w_1\ge w_2\ge\cdots$ 是某 $I$ 的出现项时间，slot 选中的负载至多 $w_1+w_3+\cdots\le(\sum_j w_j+w_1)/2$。固定负载 $F_h\le1$，两见证给 $\sum_j w_j\le2(1-F_h)$、$w_1\le1-F_h$，故

\[
F_h+w_1+w_3+\cdots\le F_h+\frac{2(1-F_h)+(1-F_h)}2
=\frac32-\frac{F_h}{2}\le\frac32.
\]

正 $C$ 每台最多再接一枚 $J$，branch 总数至多 $K_a$。将最终被 $J$ 占用的正 $C$ 集合记作 $F$，把其中的 `b` 回送到对应 $M$，其余 `b` 留在 $C$，并按最大索引 $p=\max F$ 安排正/负 `q` 的 pool 导出和后继 $M$ 填充。所有 $M,C$ 的负载回到至多 1；正 pool 负载为 $1+(|F|-1)/k\le3/2$，负 pool 至多 $1/k$。这一步与同一次 $J$ 流合并，故没有逐机挑色后再发生隐藏冲突。

## 3. v4 的一般化和边界

v4 的稳定身份为 `UM-TWO-ACTUAL-INTERPOLATION-BULK-FALSE-ESCAPE-v4`，把上述 slot/flow 证明抽象为任意显式普通 unrelated 矩阵 $P$。给定两份完整 assignment $σ^0,σ^1$（每台负载至多二进制有理阈值 $T$）、一个固定任务集合 $F$ 及其合法指定目的地 $ν$，其余任务必须从自己的两个见证目的地二选一。对机器 $i$，设


\[
t_i=\sum_{z\in F:\nu(z)=i}p_{iz},\quad
L_i^b=\sum_{z\notin F:\sigma^b(z)=i}p_{iz},
\]

令 $N_i$ 是两份见证在 $i$ 上的出现项数（同一任务两次落在同机仍计两次），$d_i$ 是非 $F$ 出现项的最大实际时间，空最大值取 0。一次整数流给出完整 assignment $τ$，满足


\[
\#\{z\notin F:\tau(z)=i\}\le\left\lceil N_i/2\right\rceil,
\qquad
\sum_{z\notin F:\tau(z)=i}p_{iz}
\le\frac{L_i^0+L_i^1+d_i}{2},
\]

从而

\[
\operatorname{load}_i(\tau)\le t_i+\frac{L_i^0+L_i^1+d_i}{2}.
\]

当 $t_i=0$ 时得到 $3T/2$。若固定任务本身在一份旧见证已占满 $T$，则该见证的非固定负载为零；两份都在 $i$ 占满时 $d_i=0$，界退化为固定负载。这里 $ν$ 不必属于旧 support，也不必预先可行于阈值 $T$，只须是原矩阵的合法有限端。证明只使用出现项配对和一次整数最大流，不引入新物理机器、拆分执行或 CONFIG oracle。

bulk 特化允许 $J$ 接所有非 pool 的 $M,C,I$，包括 tiny 正 $C$、负 $C$ 和环机器；把全部 selector 固定到正 pool 后，非 pool 得到 $\le3/2$，pool 仍由 $1/k$ 的 `q` 控制得到 $\le3/2$。若进一步允许 $J$ 接 pool，定义指定特殊正 pool 上两见证实际使用的非-selector 最大时间 $d\le1$，则完整 all-false 只保证

\[
C_{\max}\le\frac32+\frac d2.
\]

对 $β=2-δ$（$0<δ<1/2$），要排除 all-false 的 $C_{max}<β$ 必须 $d≥1-2δ$，要排除 $C_{max}≤β$ 必须 $d>1-2δ$。若 $1/k<1-2δ$，这个 near-unit 时间不能来自 pool 上的 `q`，必须来自某枚真实执行于特殊正 pool 的 $J$；由于另一份见证同池已被 unit selector 占满，同一枚 $J$ 的目的地必然改变。该命题是必要条件，不是充分条件，也不构成源赋值解码。v4 因而扩大了 v3 的辅助资格域，却同时明确指出了接近 2 时必须面对的真实任务身份义务。

## 4. 第一个源的保留内容与不应升级之处

应完整保留：两份完整 strict 见证、所有真实 $J$ 的一次共同流、出现项而非匿名颜色、零时间/未用大端的处理、v3 backbone 回填、v4 的 $d_i$ 和 pool $d/2$ 界、确定性位复杂度说明。它关闭的是“在这两份已给见证下，凭任意异权内部或重读口辅助任务局部阻挡 all-false”的接口逃逸。

不应升级为：给定模型自动寻找两份 strict 见证；没有见证时的多项式近似算法；任意源 NO 矩阵都有两份指定模式；跨多个子句的全局解码；或 `UM-TARGET-v1` 的 near-2 hardness。`J` 接 pool 的 near-unit 必要身份只是一条进一步构造义务，尚未证明该义务可实现或可用于解码。

# 二、成束二阶约束、计数闭包与细分障碍（`662f60ef16911ee431c3`）

## 5. 二阶 pair-moment：一个具体两树族的精确切除

稳定身份 `UM-BUNDLE-MOMENT-v1` 只量化经典两树族、每个末层父机 $u$ 与终端机 $v$ 间的 $k\ge4$ 条束任务 $B$。父端处理时间为 $1/k$，终端端为 1；父端另有耗时 1 的 incoming 任务。对配置 $S$，写 $N_i(S)=|S\cap B|$。所有整数分配满足 $N_v=k-N_u$，因此在配置边际上加入

\[
\mathbb E_{y_u}\binom{k-N_u}{2}
=\mathbb E_{y_v}\binom{N_v}{2}.
\tag{1}
\]

逐任务的等价形式是，对不同 $j,\ell\in B$ 写 $q_{i,j\ell}=\Pr_{y_i}[j,\ell\in S]$，加入

\[
q_{v,j\ell}=1-x_{u,j}-x_{u,\ell}+q_{u,j\ell}.
\tag{2}
\]

当 $0\le T<\theta_k=2-1/k$ 时，终端每个可行配置至多带一条束任务，式 (1) 右端为 0；父端正质量配置因而至少带 $k-1$ 条束任务，不能再与 incoming 1 共存。自底向上，孩子 incoming 覆盖为 0 会迫使父点的 $k$ 条 outgoing 小任务边际全为 1；每个正质量配置已耗时 1，不能再接自身 incoming 1（$T<2$），最终根间大任务两端都被迫为 0，和恰覆盖矛盾。因此强化后的配置阈值对这个族恰为 $\theta_k$：在 $T=\theta_k$ 使用经典整数路径调度的 Dirac 配置满足全部约束。

旧配置证书被切掉的原因也明确：父端以质量 $1/(k-1)$ 选择 incoming 加一条 small，其余选择全 small；父端同时遗漏两条不同 small 的概率为 $(k-2)/(k(k-1))$，终端对应二阶概率为 0，聚合残差为 $(k-2)/2$。这只是该族的强化身份，不是一般多机器配置 hierarchy 的 gap theorem，也没有给出该指数列 LP 的多项式求解器。

## 6. 不调用配置 oracle 的计数删边闭包

稳定身份 `UM-CARDINALITY-CLOSURE-v1` 对任意合法 $P,T\ge0$ 初始化每个任务的候选域 $D(j)=\{i:p_{ij}\le T\}$，空域即拒绝。对候选边 $j→i$，先记单域强制负载

\[
F_i^{\neg j}=\sum_{h\ne j:D(h)=\{i\}}p_{ih},
\qquad R_v=T-F_v,
\]

并对每个 $v≠i$ 的二域束 $B_{iv}^{¬j}=\{h≠j:D(h)=\{i,v\}\}$ 和 $q=0,\ldots,|B_{iv}^{¬j}|$ 定义

$v$ 至多容纳 $q$ 个此集合任务；令 $b_{ivq}$ 是这些任务在 $i$ 端时间的总和减去其中最多 $q$ 个最大 $i$ 端时间，$r_{iv}^{¬j}=\max_q b_{ivq}$。若


\[
p_{ij}+F_i^{\neg j}+\sum_{v\ne i}r_{iv}^{\neg j}>T,
\tag{3}
\]

就安全删除 $j→i$。不同 $v$ 的束互不相交，且每一轮同步计算全部删除，保持每个 $T$-可行调度的所有真实边。域收缩使 $R_v$ 变小、强制负载变大，算子单调；等号 $p_{vh}=R_v/(q+1)$ 不列入 $K$，因为恰好装满是允许的。严格按输入有理数做排序、交叉相乘和有限求和，保守总位复杂度为多项式（文中给出 $O(m^3n^4log(n+1))$ 的轮次上界）。

在经典两树族，该闭包拒绝所有 $T<θ_k$：底层束在 $1≤T<θ_k$ 时 $q=1$ 强制大量父端负载，逐层删除 incoming，最后根间大任务无域；而 $T=θ_k$ 的已知整数调度因安全性被保留。闭包因此提供可计算的精确族下界/过滤器，但接受不保证存在 $T$-调度，也不输出近似调度。其明确的首次删除失败机制是：初始非空二域、无平行任务时，所有二域束至多一项，$r_{iv}=0$，没有任何第一条边可删；因此不能把它误写成一般域传播完备性。

## 7. Pair coupling 的真实增量与全局缺口

对每个机器对 $(u,v)$ 引入联合配置分布 $z_{uv}(S,R)$，要求边际分别为 $y_u,y_v$，且对恰连接 $(u,v)$ 的任务 $j$ 满足

\[
\mathbf1_{j\in S}+\mathbf1_{j\in R}=1.
\]

此 `T_PAIR` LP 包含 (1)/(2)，但只对每个机器对做局部联合，不要求不同机器对的耦合来自同一个全局联合分布。若机器对至多共享一枚任务，普通配置边际本身足以构造耦合：令 $a=x_{u,j}$，对兼容块按

\[
z(S,R)=
\begin{cases}
y_u(S)y_v(R)/a,&j\in S,\ j\notin R,\ a>0,\\
y_u(S)y_v(R)/(1-a),&j\notin S,\ j\in R,\ a<1,\\
0,&\text{其他情形},
\end{cases}
\tag{4}
\]

边际恢复；$a=0,1$ 的零分母块直接置 0。故简单机器图上 pair coupling 与普通配置 LP 等价，不能由逐对耦合推出三台以上机器的全局分布。

## 8. 任务细分如何恢复上确界间隙 2

稳定身份 `UM-PAIR-SUBDIVISION-GAP-v1`：原任务 $e=(u,v)$ 以新机 $w_e$ 和两子任务 $e_u,e_v$ 替换，旧端保留各自时间，新机两端均耗 $H>0$。对任意原实例 $P$，有安全界

\[
\min\{\operatorname{OPT}(P),2H\}\le \operatorname{OPT}(P')
\le\max\{\operatorname{OPT}(P),H\}.
\tag{5}
\]

上界把未分配的子任务放到 $w_e$，每个新机负载至多 $H$；若新调度低于 $2H$，每个 $w_e$ 至多容纳一个子任务，任选另一外端恢复原任务且不增旧机负载，得下界。等式只在 $\operatorname{OPT}(P)\in[H,2H]$ 保证；当 OPT 小于 $H$ 时不成立，例如单任务原端时间 0、$H=1$ 时新 OPT 为 1。

给定原 $T\ge H$ 的显式配置证书，把每个旧配置中的任务替换为相应子任务；新机用旧端边际 $x_{v,e}$ 或 $x_{u,e}$ 混合接收另一子任务，负载为 $H\le T$，每个子任务端点覆盖恰为 1。因此细分后的机器图简单二部，且完整 pair coupling 证书可以由原证书提升。

对经典两树族取 $H=1$，$\theta_k=2-1/k$，旧配置证书阈值 $T_k=1+1/k$ 得

\[
\frac{\operatorname{OPT}(P'_k)}{T_{\mathrm{PAIR}}(P'_k)}
\ge \frac{2-1/k}{1+1/k}=2-\frac3{k+1}\longrightarrow2.
\]

任意这类证书投影为普通配置证书，再用已有的 `UM-ST-ROUND-v1` 给上界 2，所以这里只能确认上确界趋近 2；没有声称 $T_{PAIR}=T_k$，也没有由此获得统一 $2-ε$ 算法的否定性复杂度结论。计数闭包在细分族的 $T_k$ 初态也不删任何边（每项仍为二域、无首次删边），所以“先闭包再 pair LP”仍保留同一方法间隙。

## 9. 第二个源的保留内容与不应升级之处

应保留三条互相独立但可串联的事实：二阶 moment 在经典两树族的确切强化阈值；计数闭包的安全性、单调性、位复杂度和接受不完备；以及局部 pair coupling 被任务细分以容量一中间机隔离的间隙趋近 2。还应保留二域无平行任务时的 `r=0` 首删失败和式 (5) 的 OPT<H 反例，因为它们直接限定后续推广。

不应把“消除旧两树证书”写成一般 LP 算法；不应把逐对耦合写成全局联合分布或多机器一致性；不应把细分后的 gap 写成一般 hardness；不应把脚本审计的有限穷举当成定理证明。源中提到的独立审计、冻结 JSON 和长链/固定大小 coalition 相关材料是证据与后续接口，不能覆盖这里没有证明的全局量词。

# 三、两源的关系、独有内容和接续

两源共同说明“局部结构增强不能自动得到全局 near-2 结论”，但作用方向相反。批量插值源在**已有两份完整实际见证**下用一次整数流把两个见证压成一个低峰值实际调度，给出全任务身份可追溯的上界和 pool near-unit 义务；成束耦合源试图用局部二阶统计和域闭包排除配置假证书，却展示了局部 pair 信息可被任务细分隔开、间隙重新趋近 2。前者的半项配对不是配置 LP 变量，后者的 pair coupling 也不能替代全局联合分布；两者不可互相升级为对方缺失的算法或复杂度结论。
