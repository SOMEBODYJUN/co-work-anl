# 所有给定allocation/schedule的双向转换

给不交原B_g，扫描每组取attaining state，把B_g给其SC agent，其余K−1 agents各一不同own dummy，SC min≥min_g f_g(B_g)。反向任意SC分配中，每组K agents却只有K−1个own dummy，至少一名没有own dummy，foreign dummy值0；它的real bundle值≥实际SC最低值且≤1。每组选该一个state/agent，不拼多个state bundles，跨组real资源仍不交，故V≥SC min。K1自动dummy-free，V0亦涵盖。

给原bundle/所选state，selector放其root，只导出它实际领的positive资源incidence，其余全部原jobs留各自private，零job可留零端。资源≤一unit、未选root≤1，选root=2−f_g(B_g)，得到完整真实峰≤2−minquality。所有原任务各一次，资格与时间不变。

反向给峰C<2的任意完整调度，取每selector真实所在state；该state实际外送资源B_g跨组不交，因为unit资源不能接两件。选root负载2−a_gs(B_g)≤C，故quality≥2−C，按第一步给SC。无需先规范化未选state，它们占的资源可以忽略。C≥2不使用独占，目标max(0,2−C)=0由非负SC任意分配满足。全private给峰≤2，有限选择保证最优达到，故两等式含UMOPT2端点。
