# 2. 主族的定义域、量词和准确结论

## 2.1 冻结宏、tiny 全开重优化

对任意整数 (r\ge1)，令 (k=r(r+1))。母族有 (2r) 台机器、r 个 unit 宏任务和 (rk) 个带身份 tiny 任务；每个 tiny 只在其私有 home 与共同 Z 端集合上有源中列出的有限边，宏任务的有限边和 sigma 的 home 位置也按母族定义保留，不能擅自缩成“宏只能在指定 H”。构造给出 (r^2) 个真实 OPT=1 调度，取其均匀平均 (x)，再由一个真实 ST 槽输出得到坏的 `sigma`。冻结全部 macro 后，允许 tiny 在其所有合法端自由重开，精确最优值仍为

\[
  C_{\mathrm{tiny\ reopt}}=\frac{2r}{r+1}=2-\frac{2}{r+1}.
\]

宏在冻结态的值为 (C=2-1/r)。因而对任意固定 \(\delta,\varepsilon\in(0,1)\)，可先取 (r(r+1)\ge1/\delta)，再增大 (r) 使 (2/(r+1)<\varepsilon)，得到 tiny 的单件处理时间不超过 \(\delta)，而冻结宏后值大于 (2-\varepsilon)。这里是存在量词顺序：先固定阈值，再选构造深度；不能反写成一个算法对输入的任意实数参数。

承重论证是容量计数而非槽图局部论证。所有工作只能进入 (r) 个 H 与 Z；平均总工作量给出 (2r/(r+1)) 下界，而每个组把 (2r) 个 tiny 外送到 Z 可达到该值。宏的具体槽号和逐行负载只负责证明坏 ST 输出及任务身份合法，重开下界不依赖逐行包络或负相关假设。r=1 的零 home-tiny 边在正文和两个 oracle 中单独处理。

## 2.2 宏迁移格点前沿

允许最终至多 (d) 个宏与原 sigma 的 home 不同，tiny 仍完全自由，且 (0\le d\le r-1)。记 (s=r-d) 为仍被原 home 宏阻塞的组数，则最终精确 makespan 为

\[
 M_s=\frac{\left\lceil 2sk/(s+1)\right\rceil}{k}.
\]

下界把每个未迁移宏 home 至少挤出的 (2k-M) 件 tiny 与 Z 的至多 (M) 容量相连；上界由把 d 个宏移入不同 Q、逐个给 blocked home 外送对应 tiny 数量的显式终态达到。该计数已涵盖 H 间交换、临时中间态和跨组协调；只看迁移路径长度会漏掉最终容量约束。(C\ge2) 的候选终态被显式达到态支配，不能并入 (C<2) 的 frontier。

对实数 \(\alpha\in[1,2))，令整数 (M=\lfloor k\alpha\rfloor)。达到 makespan 至多 \(\alpha\) 所需的最少宏改动为

\[
 d_{\min}(\alpha)=\max\!\left(0,\,r-\left\lfloor\frac{M}{2k-M}\right\rfloor\right).
\]

这是格点公式；连续的 \(\lfloor\alpha/(2-\alpha)\rfloor\) 只能作必要条件，不能替换 (M\) 的整除/取整边界。端点 (\alpha=1) 给出 (r-1)，r=1、d=0 与主式一致。证明中的“实 alpha”是数学恒等量词，不表示算法可以把任意未编码实数作为输入。

## 2.3 几何字母对象的地位

`geometric_alphabet_equivalence.json` 只核验编码/变换的有限恒等式：n=16..4096 的 4081 点、940974 probes；大 n 只有每点 7 个 grid-only probes；small-h transformation checks 计 7871 个矩阵；ratio identity 取 k=2..1000 样本；另有一个 n=32768 的 actual large branch fixture。它支持把该变换当作后续配置压缩的候选工具，不支持“所有 n 的普适等价”“最佳比率证明”或未知 sub-2 backend。`unverified` 字段必须保留。
