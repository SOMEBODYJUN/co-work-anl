# 2. Exact的完整物理合同与准确数值域

显式H、固定必做A、互异Q/R各k≥2，N=|A|+2k≥4，T>0二进制有理。每内部机h上的每个原job只可finite同一s_h≥0或∞，跨机任意资格和时间，无预载；允许s_h0、s_h>T、无资格行、任意aux和H空。模式X只指A∪X在H全部各一次且全负载≤T，边界补集仍必须外部执行。

Inactive X_∅=R，aligned X_i=(R减b_i)+q_i，指定mismatch(j,i)=(R减b_i)+q_j，均读真实job目的地。给两份T可行aligned actual，可确定性总位多项式输出inactive或指定mismatch(j,i)，每A保留。Inactive在T不可行时必得该错配，交换i/j得另一方向，全部aligned给全部k(k−1)错配。不给两见证时可在这个**精确容量域**先matching判定/构造，失败报告aligned不可行，不声称任意weighted UM或隐藏源解可求。

Weak B只要求任意有理B≥T：禁B内inactive⇒禁T内inactive，输出本来≤T≤B。无需B<2T，B不参与cap计算；仅B可行aligned不是T见证，不能压任意B调度至T。“至少一项”也不保证恰一模式可行。

每边界可加不同私有O_z:T，A无outside；输出内部模式后其余边界各去O_z，全部N原jobs恰一次，outside同时≤T。Slots只是分析容量不是真实新增任务/机器。真实外端若共享变量环/锁定机，换模式会变外部job集合与负载，本结论只保内部替换；模式相关A、同机异权、预载、bundle/多尺度及内外不可分容量都在域外，并未证明这些额外机制充分产生hardness。

# 3. 两种截断与两条证明，不删原任务

每h原负载是整数件数n_h乘原s_h，n_h≤N，所以s_h>0时c_h=min(N,⌊T/s_h⌋)，s_h0时N，对任意任务子集精确等价；大于T容量0。物理容量截N避免未截断T/s_h巨大展开，零机无除零。Slot总≤|H|N，资格展开≤原finite数×N，dense全部项计成本；可先比较Ns_h≤T直接取N，其余有理floor位长多项式。

独立证明在job侧transversal matroid收缩共同C=A+(R减b_i,b_j)，两aligned给{q_i,b_j}、{q_j,b_i}独立，b_i/b_j均非loop。Inactive不可行使它们依赖、秩1平行、closure相同，遂{q_j,b_j}、{q_i,b_i}独立，给两错配。原matroid收缩后秩可大于2，没有满载、两见证同slot或任意大集合是base的假设。可选rank2截断只保小集合独立性；作者“先收缩A再截到边界rank k”也是证明语言，与每机**cap截N**不同，不物理删机/任务/资格。

作者实际构造从aligned i删原q_i，M大小L−1、L=|A|+k，保全部A及R减b_i；只看U=A+R+q_j，另一aligned j有L条边，所以一次增广存在，起点只能b_i或q_j。前者给inactive，后者指定错配。翻转保全部原matched jobs，成功一次到L即停，终点是空slot而非整台原机空闲。

独立构造同一M先从q_j搜；成功即指定错配，失败则M不变，另一较大匹配确保增广且仅b_i还能起始，第二搜索必给inactive。未matched q_j不成为第二路径中间job，不偷入inactive。两方法可移动任意多aux但不漏A，投影原h恢复真实同时负载≤T。它们同构但实际搜索顺序/独立信息来源不同，均完整保在新证明页，不以“作者更晚”吞掉独立rank或把两者称新软件运行。

# 5. canonical才明确的封装前件精度

最终canonical 806238bb6efd4db5b901为8046字节，SHA **b930c8d0e8f2607495eb4addb94c071c60a2edfa85669c36847d5f77599feb5a**。734570…实际全文读并正式认证完整§1–5的v2数学/构造，范围包括明确的guard：任一aligned可行即每A实际已有内部finite端，边界都另有O_z且2k≥4保证机集非空，所以在这些算法/交换前件下封装是合法ordinary UM。

若A某job根本没有内部finite端，也无outside端，局部predicate仍可可靠判所有aligned不可行，但带这个无资格job的封装不是合法ordinary UM目标。即使已有2k台outside机，也不能救A的无端；H空并非仅机器数量的问题。早期Exact/独立/作者读后中的笼统封装措辞依此理解，旧原字节不改。这是普通输入合法性精度补清，不改变始终以两份可行actual为前提的matching交换和输出。

Guard的逻辑是“aligned可行**足以保证**A有端”，不是“有某aligned可行**才可能**是合法UM”。每A已有finite端的封装可以合法，而某aligned仍因容量不足不可行；不能把充分条件倒成必要条件。新证明明确这个区别，没有额外收窄主结果。

Canonical也重申模式只是指定/投影、private O未物理强制查询，inactive=R不等于所有boundary outside=∅；外接共享端需新全机负载证明。v2允许H空/零容量/零时间与任意无资格aux的**局部**判断，不因此把非法原job当完整目标。最终无standing fatal；不把后续清晰措辞倒填为过去每条记录都有相同guard。
