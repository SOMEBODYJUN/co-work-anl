## 1. 匿名 token 的 M1 保持与 M2 非扩展

`token_label_nonextension_independent_audit.json` 是 statement-first 的独立 Fraction 重建，明确 `author_proof_or_code_read=false`。它在 10 个 token label 上取全部 4-subsets，共 210 个 signed subsets；定义 beta 权重总和 1，并用 aggregate variables 的一阶/二阶矩构造 67×67 的 M2 Gram 矩阵。精确 Schur 消元给出 aggregate M2 rank 55；标记 M1 的 46×46 版本 rank 38。还核对了 232 个 (X=4) 的 Boolean monomial cardinality identity、45 维 pure-X pair basis，以及 45×45 的 (A^{-1}A=I)。

审计中的 signed beta 取：在 10 个 labels 分成两半时，取 0 或 4 个来自第一半的 4-subset 权 (1/8)，取恰有 2 个的权 (-1/400)，其余为 0。对 constant、half-sign、within-half 三个 Schur 对称方向，精确数据为

- (D=(8/5,2,1/20))；
- (E=(4932/125,15,453/1000))；
- (D-delta E=(3767/3125,37/20,4547/100000)>0)，其中 (delta=1/100)。

因此 aggregate M2 的 PSD 与全局 cardinality 约束仍可同时成立；然而形式 lift 的 (Q^2=-1/150)，必要 half-sign block 的特征值为 (-1/250)，quadratic 为 (-1/25)。这提供了明确的非扩展方向：保持全部 aggregate degree-4 矩并不能保证存在满足原 token/head 联合结构的 M2 lift。负方向来自联合 head 与 context 的原始二阶/四阶关系，不能被“aggregate M2 PSD”掩盖。

数学量词要保留：该独立文件验证一个固定的 210-subset 构造和指定二次矩空间；它没有给出 generic SDP、所有 group 的分离、增长深度 gap 或 all-input solver。必要 block 的负性也未被声称为充分条件，不能替代完整 token-label theorem。

## 3. 双见证查询分离：一般阈值染色与费用平均

`two_witness_query_separation_v2.json` 对应 claim `UM-TWO-WITNESS-QUERY-SEPARATION-v2`。输入是任意显式合法 unrelated-machines 矩阵、同一矩阵的两份完整分配 (sigma_0,sigma_1)（峰值均不超过 (T)）、差异任务集 (D) 和非空查询集 (Q\subseteq D)，不要求 unit/home、度数或图结构。对每个 q 定义其他查询在 (sigma_0) 上的聚合 (delta_q)。当前正文的精确构造给两两不交支持 (A_q\subseteq D\setminus Q)，使仅把 (q\cup A_q) 切换到 (sigma_1) 端、其余任务留在 (sigma_0) 端，并满足
\[
C_{\max}(\tau_q)\le\max\{3T/2,T+\delta_q\}.
\]
若在 (D\setminus Q) 上给任意非负权 (w_j)，则
\[
\sum_{q\in Q}\operatorname{fee}(\tau_q)\le\sum_{j\in D\setminus Q}w_j,
\]
所以至少一查询的改派费不超过总权的 (1/|Q|)。这是给定两份见证之间的确定性实际构造，不是一般近似算法或 hardness 结论。

证明把每个差异任务画成带标签的机器弧 (sigma_0(j)\to\sigma_1(j))，以目标 σ₁ 端的时间 b_j 为染色流入权（旧端时间 a_j 仅用于初态/残余查询负载）；查询弧各自保留颜色，未着色非查询弧在某颜色流入严格超过 (T/2) 时一次性随源机染色。每台机器至多触发一次，终止时未标颜色的流入不超过 (T/2)，标颜色的机器由 (sigma_1) 完整负载控制，并额外加上其他查询旧负载 (delta_q)。所有非查询弧最多着一种颜色，故支持不交且费用可求和。

### 锐例和实际 JSON 检查

首个 `sharp_six_machine_five_job` 是 (T=1,eta=gamma=1/8) 的 6 机 5 任务例：q1/q2 由小端分别进入 A/Bm，x1/x2 从 A/Bm 转到共同 R，f 从 R 转到 S。每份输入见证峰值为 1；针对 q1 或 q2 的指定输出峰值为 11/8，改变的非查询支持分别含 x1 或 x2，且完整 32 状态枚举核对了费用/峰值阈值。对于 cap 4/3，两种单查询均强制改派 f，最低费用为 1；到 cap 11/8，最低费用降为 0。这说明 (3/2) 的阈值是全域上界的 sharp supremum 机制，不能改述成近二 gap。

第二个 case 是 T=0 的两个 query 零端点，闭包无触发，输出峰值和费用都为 0。第三个 case 使用 T=2、共享 query source、任意有理端时间、五步 cascade 和额外 unused endpoints；JSON 核对每台机器最多触发一次、最终阈值不变量、各查询的 (A_q) 两两不交、fee equality 和 load bound。三例合计 `case_count=3`，`all_checks_passed=true`，算术为精确 Fraction，脚本 SHA `cc50d2e612de59b225d8bdf009d38cfa7e22c8ae67b10900086e6b7786238759`，输入 SHA `cee13089d6cc2e8d78aaae6fe80b60da442ff3fabced16bb7ff70f44406e147c`。

有限枚举仅是这三个显式 case；JSON 自己声明不证明一般定理。正文的一般性来自阈值染色证明，有限输出承担回归和锐例检查。费用是相对于 (sigma_0) 的指定改派权；若物理模型还计入背景 unit 费、退款或其它收费，不能直接把这条费用不等式当作净成本。

## 与已有存档的关系和接续

1. **与匿名 token lift 审查：** 本批独立审计补充已有 token-label review 的固定矩阵、Schur 谱和字节复现；它强化“aggregate M1/M2 条件不足以构造真实联合 lift”的方法障碍，但不提供 generic SDP 或全深度反例族。
2. **与 two-witness query separation 正文：** 本批 JSON 是同一 v2 证明的实际三 case 回归和 sharp threshold 记录；不把 3/2 写成 UM 近似因子，也不把费用平均写成源问题解码。
3. **与单 home cascade / shared job fee 对象：** 一般分离允许任意差异弧和共享 source；单 home 或固定 unit 费用的 stronger contracts 需各自保留，不能以本批三 case 覆盖。

**完整或条件数学结论：** token 非扩展的固定矩阵负方向、以及双见证查询分离的阈值染色定理，在各自明确的定义域和见证输入下成立。

**有限实验与复现证据：** 210-subset Schur/PSD 数值、三 case exact output、32-state sharp enumeration、T=0 和 cascade boundary，适合回放和回归。

**障碍与未解项：** 仍缺所有 group/任意深度的 token-label 非扩展、真实全输入 M2 solver、源相关全局 decoder、未知 YES 见证的寻找以及将查询费用强迫嵌入一般 UM gap 的完整归约。外审和新颖性未认证；`UM-TARGET-v1` 的正反面状态不因本批改变。
