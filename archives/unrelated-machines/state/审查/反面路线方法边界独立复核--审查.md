# 2. 单层配额超图：逐层值恒等与 soundness 义务

根需求为 `q`，每个选择点 `x` 需求 1，每个中间点 `e_x` 需求 `K`，而 `e_x` 连接的资源邻域为 `A_x`；单父条件使不同选择点使用的资源子集不相交。令 `nu_t(A)` 为最多可选择、且每个选点取得恰 `t` 个两两不交资源的点数，令 `nu_0=|X|`。源给出的桥值是

\[
b^* = \max_{0\le t\le K}\min\{1,\nu_t/q,t/K\},
\]

对应桥梁调度值 `OPT=2-b*`。上界把任意评分 `b>0` 的根树截到 `t=ceil(Kb)` 个中间点和至少 `ceil(qb)` 个选择点，得到 `nu_t/q` 与 `t/K` 两个约束；反向用达到 `nu_t` 的不交 `t`-资源子集族直接构造树，三类正需求比例恰为 `nu_t/q`、1、`t/K`。`b=0`、空邻域、`q=1`、`K=1` 及 `|X|>q` 的截断边界均保留。

这条恒等式的归约含义是逐层的：完整 YES (`b^*=1`) 需要 `nu_K=q`，而 NO 若要产生近二差距，必须同时压低每个 `t=1,...,K` 的 `min(nu_t/q,t/K)`。只控制完整 `K` 层无法排除部分配额树；给邻域添加私有资源会同时抬高多个层，不能作为只修复 YES 的黑盒补丁。源保留的有限证据为宇宙大小 3、`q<=3`、`K<=4`、`|X|<=3` 的 4788 个枚举实例和 100 个固定种子边界实例，均以 `Fraction` 比较且不调用一般优化器。该运行支撑实现和边界，不替代上述自足证明，也不提供一般计算复杂度或 `UM-TARGET-v1` gap。

# 3. 仿射互补：等基数恒等与计数解码反例

在源最大最小分配的处理时间编码

\[
p_{ij}=B-\lambda u_{ij}
\]

下，只有在每台机器恰取 `q` 件时才有

\[
L_i=qB-\lambda\sum_{j\in A_i}u_{ij}.
\]

若任务数不受等基数约束，基线实际是 `|A_i|B`，因此 makespan 乘性近似本身不能恢复等基数。源对任意 `1<rho<2` 取 `q\ge 1/(rho-1)` 的全同效用实例：均匀分配的最优值为 `q p_0`，而把某两台机器改为 `q+1` 与 `q-1` 件仍只有 `(q+1)p_0\le rho q p_0`，所以计数不平衡仍可落入同一乘性比率。该推导只否定“仿射互补+dummies+近似后按数量裁剪”这条接口；它不否定带独立过载惩罚、槽选择器或其他非仿射 gadget 的归约。

具体矩阵为

\[
U=\begin{pmatrix}1&1&1&1\\1&1&0&0\end{pmatrix},\qquad B=1,\quad\lambda=2/5.
\]

在平衡分配下 `OPT=6/5`；把三件资源放到第一台、剩一件给第二台，负载为 `9/5` 与 `1`，比率 `3/2<1.9`。再按数量截成两件时，第二台只能保留零效用资源，源最小效用从 2 降至 0。这一具体证书与冻结 Fraction 程序一致；程序只核给定矩阵、三个 rho 见证和 uniform count inequality，不遍历一般 OPT 或执行通用 decoder。
