# D个全局共享singleton REPAIR与完整调度

向每个相同原group增加同一D个新资源上的D个unit singleton alternatives，保留旧state/resource，组数仍n。增强utility为max{原quality,是否得到某repair}。原有至少n−D个unit groups时，把余下≤D组各给不同repair可全unit；任意增强allocation去repair后仍为原allocation，至多D组收到repair，故原全称低组下界γ_lo n最多减D。

固定0≤a_rep<γ_lo≤1，D≤a_rep n，0<η<γ_lo−a_rep，0≤δ_q≤c_η。在YES原可有≥n−D个unit groups、NO每原allocation都有≥γ_lo n组quality≤δ_q的promise下，以增强unit-FSLP可行为YES可分离：YES不交完整正supports给λ整数见证；NO若LP可行，输出低组<ηn，却必须≥γ_lo n−D>(ηn)，矛盾。D≤a_rep n使nD新增states显式多项式。只有另给到此准确promise的Karp reduction才有条件P=NP推论；此处没有构造困难源。

# 高低gamma混用的撤回与准确互补

旧§F把源的高质量组上限γ_hi与上述低质量组下限γ_lo当成同一比例，遂声称“不覆盖典型γ_hi≤δ_q”。该结论撤回，不能沿用主源前半尚未更正的旧段。UM-NORMALIZED-ROBUST-HIGH-LOW-COMPLEMENT-v1的准确论证只用集合互补和前述同一allocation：
\[
\#\{r_g\ge\delta_q\}<\gamma_{hi}n
\quad\Longleftrightarrow\quad
\#\{r_g<\delta_q\}>(1-\gamma_{hi})n.
\]
当0<δ_q≤q_η、0≤γ_hi≤1−η时，输出low<δ_q的组数≤low<q_η的组数<ηn，不能同时>(1−γ_hi)n≥ηn。因此全称robust NO不可能。双等号δ_q=q_η、γ_hi=1−η也矛盾。等价地输出#{r_g≥δ_q}>(1−η)n≥γ_hi n。

高端若用>δ_q，互补必须用≤δ_q。仅靠原第一计数式时，δ_q<q_η才有包含；等号若另用C.2的严格NSW可以再证，须明确指出：若≥ηn组≤q_η，product≤q_η^k≤ρ^(−n)，仍与NSW>ρ^(−1)矛盾。不得直接无理由交换严格符号。
