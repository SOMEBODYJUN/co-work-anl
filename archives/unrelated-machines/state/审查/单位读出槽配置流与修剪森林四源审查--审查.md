本审查逐项读取四个冻结 JSON、各自 `research/current` 数学正文、已有 review、规范/独立审计代码和相关例子。库存稳定 ID 与 JSON SHA 为：`7e674e0d4743cd8b4a8c` / `19d135ce5e24d2304b1e851191ed76c9361d447ea75f5177cde6f44e5b3703fc`；`47edad5a71c5699925ecf` / `b6e7c9731527844cc9840aad70bbddbedf87826c30227c12022135a82b33b51d`；`f9731a3cc1e7c2b591a2` / `bc130211137d081776f3c96d8e792cb64006f40969e8f59528fe7104abac7ae0`；`dc2c5ab5495d455beeb5` / `f251a09d98feae045ee04e694046d26ecb2f64d87b3b2f964ad397082a67c085`。legacy-cleanup 与 main 绑定的相同路径视为同一冻结版本。

四份 JSON 都把有限运行与一般证明分开。它们不能互相代签软件，也不能把给定见证的充分条件写成任意输入的必要条件。以下把可复用的数学合同、有限回归、反例和未解项分开保存。

## 1. 校准计数槽与有界密度

`unit_readout_calibrated_cardinality_slots_audit.json` 承载 `UM-UNIT-READOUT-CALIBRATED-SLOT-v1` 与 `UM-UNIT-READOUT-BOUNDED-DENSITY-SUBTWO-v1`。规范、独立和 root 原始矩阵回算均退出 0；代码 SHA 分别为 `039ac7db...f175c4`（规范）、`b87e5c...608b1e`（独立），输入反例 SHA `56bd2e...47f4e6`。根实际输出包含 1464 份完整 sigma、85094 原 jobs 的大回归（既有 review 记录），独立程序记录 522 位分母边界和 giant denominator；两者都明确没有集成通用 LP，也没有把有限 D 变成一般 UM。

数学合同是共同的分数槽/配置证书：selector 的 incoming 质量为 1，内部小边总质量受整数槽 (L=k-r+1) 控制，active 轨在同一次 Hall matching 中覆盖全部原 jobs；含 incoming 的机器负载至多 (1+(k-r)/k)，未含 incoming 的机器至多 1，外部 unit 每槽至多一个时间 1 的 port。总列质量恰 1，任何切片都按真实原资格保留。

读后攻击保留两个反例：(k=4,h=1,r=2) 的 weak-LP 条件能成立但强实际 makespan 达 (7/4)，所以弱的 (sum t\ge ry) 不能推出 (3/2)；(k=2,h=1) 的强 LP 不可行而实际 OPT=1，说明 LP 不可行并非一般阈值必要条件。固定 D 证明依赖统一密度 (d_c\le D A_c)、私有 incoming 和给定完整 YES；在 (k\ge D) 的证书中 (r=1+\lfloor(k-1)/(2D)\rfloor) 给 (C<2-1/(4D))，(k<D) 走实际容量匹配/正规形。该条件不覆盖一般 UM。

## 2. 配置正部、严格单位 gap 与闭合树回归

`unit_readout_configuration_threshold_audit.json` 为 `status=passed`，scope 直接写明 finite checks only、没有 global exact LP。`literal_gap` 的精确回归有 4337 个 complete schedules、59121 个 original jobs、214 个 literal unary matching、4168 个 exhaustive wiring/weight cases、4121 个 active calibrated cases、160 个 random feasible witnesses、3 个 global-density-failure-but-feasible cases、15 个非法输入拒绝；makespan histogram 含 0、1、3/2、5/3、8/5。单行配置分解另检查 1278 grid points，其中 894 个 exact feasible hull supports、384 个 exact infeasible vertex separators、9 个 boundary cases；SciPy 只找候选，最终正/负证书用 Fraction 核实。

相关一般正文的合同边界是：正部多面体/CONFIG 等价、严格单位阈值与闭合两树参数回算。关键量词必须保留：同一组边际 (t) 被所有局部配置共同使用；active 轨可用多数校准，但未选轨可全 parent，不能把强 LP 行强加到未选轨；k=1 走独立容量流；空实例先旁路。闭合参数样例给出 (T_{config},OPT) 和精确 gap，包含 k=1、2、3、4、5、8、12；这些只是有限重算，解析阈值来自当前正文证明。

严格单位 gap 的有限回归支持给定 witness 下的实际输出，不支持“任意 OPT 的五三必要性”。zero capacity、巨分母和 binary 边界均保留；Python 读取超 4300 位十进制需要解除默认上限，这属于复现环境事实，不是数学修正。

## 3. 全局叶流与 selector mixing

`unit_readout_global_leaf_flow_and_selector_mixing_audit.json` 载有 `UM-UNIT-READOUT-FIXED-HEIGHT-APPROX-v1` 与 `UM-UNIT-READOUT-SELECTOR-MIXING-v1`。canonical leaf-flow 只审 7 个关键 actual schedules，未做 physical sigma 或 forest-oracle exhaustive；selector mixing 审 7 actual complete schedules、361 jobs，4 calibrated active-only、2 sharp profile、1 empty，并拒绝多种非法输入。独立 sharp profile 检查 480 个 actual job assignments、300 machine loads、1166 finite edges、3002 matrix cells；root literal recalculation 检查 26 complete schedules、1359 actual assignments、603 load records、13 given YES 和 5 maximality cuts。

正文承载的完整合同是：给定 p 份同一 (P) 的完整 YES（峰值 ≤1）和指定 selector profile，所有任务在一次共同 flow/matching 中保留；指定轨下传比例给出的 root/leaf 流与固定高度比值 (1+2^{-1/h})，selector mixing 的多见证条件给出 (d^*\le pA) 和整体重组。未指定轨必须全 parent，不能把它们硬塞入强 LP。锐 profile 的 (2-1/(2p-1)) 只属于显式合同，不是一般近二比。

finite JSON 不包含通用 LP/OPT solver，构造不调用 oracle；独立程序不是全栈独立，因为复用了已审 builder/load core。h 无界时余量趋 0，(N<p)、k=1、空变量、C<2 的正规形和给定完整 YES 前提都必须按正文分别处理。NO 实例没有完整 YES 时，不能直接使用该重组反驳任意归约。

## 4. 修剪森林、半密度和 leaf-hitting

`unit_readout_pruned_forest_boundary_audit.json` 载有 `UM-UNIT-READOUT-PRUNED-FOREST-IDENTITY-v1`、`UM-UNIT-READOUT-HALF-DENSITY-THREE-HALVES-v1` 和 `UM-PRUNED-TREE-LEAF-HITTING-v1`。root 实际原始矩阵证书包含 6 份显式 certificate，半密度程序用 Fraction/half-incidence matching，leaf-hitting 程序独立实现命中递推；所有 process exit codes 为 0。代码 SHA 包括 `6bb5272d...ded9c8f`、`050e0534...b2b3fb`、`203e7920...5db987`、独立 `0527cce3...a04165`；实际输入例 SHA `b44ee0f...febefd`。

三项数学合同必须拆开：

1. **Forest identity：** 在 mandatory all-variable、实际 (C\in[1,2)) 和无 private pins 的 forest 域，令 (r=\lceil k(2-C)\rceil)，实际调度存在与逐变量 mandatory r-forest packing 等价的正规形。根、非根和所有原 jobs 都必须同时计入；C=1 给 r=k，k=1/h=1 和空输入旁路，不能除零。
2. **Half-density：** 额外 (d_c\le2A_c) 时，所有深度/wiring 都有 (C\le1+\lfloor k/2\rfloor/k)，unit ≤1。共同 matching 先覆盖所有 jobs，再读出实际 sigma；14-machine split example 的 (3/2) 是绝对上界锐例，不是一般近似比证明。
3. **Leaf-hitting：** 令 (q=k-r+1)，叶命中最小值为 (q^h)，最大 r-free 集大小为 (k^h-q^h)。该递推给每层 q 个 bad children/ r 个 good children 的精确阈值；补充 dummy 叶只能在外部容量也可容纳时使用。数量达到 (q^h) 本身不能忽略位置结构。

private host pins 属于不同合同；64-open bad module 的 (OPT=7/4) 与 nopins forest identity 不可混用。超半密度的全变量平衡推导只排除特定 balanced source 域，不给一般 NP-hardness。有限证书记录所有 jobs、loads 和 explicit paths，但一般 forest solver、任意 C 的构造器和外部 Paper Fact 仍分别受限。
