# 审查范围

这四份冻结 JSON 都研究 unrelated-machines 的有限二选一结构：先有一个完整的最优调度凸包点或闭环状态，再从真实 slot/optimal-hull 证书中选一个局部修复。它们提供精确有限运行和局部阈值，不能替代一般最优凸包算法、全局配置 LP 或任何普遍近二结论。

## 长链：最优凸包 slot 初始化的局部修复

`optimal_hull_long_chain_audit` 的主系列覆盖 `k=3..8`、`d=1..4`。每个实例的原始坏状态为

\[
 B_k=2-\frac1k,
\]

而从真实最优凸包点做最小 slot-cost 匹配后，有限证书得到

\[
 R_k=2-\frac2k,
 \qquad B_k-R_k=\frac1k.
\]

例如 `k=3` 的坏/修复值为 `5/3` 与 `4/3`，`k=4` 为 `7/4` 与 `3/2`，`k=8` 为 `15/8` 与 `7/4`。`d` 从 1 增至 4 时，改变的任务数为 `d+1`，参与机器数为 `d+2`，slot cost 仍被精确最小化；每个列出的案例只有一个最小 slot-owner assignment。边界探针 `k=3,d=20`、`k=16,d=1`、`k=32,d=2` 保留了同一修复模式，但其 `mincost_optimized=false`，因此不能把边界行当成已完成的最优化证书。

独立重放覆盖三组较小实例，全部 270,336 个分配被枚举；`k=3,d=1` 的 8,192 个分配中有 76 个严格 lex 改善，`k=3,d=2` 有 144 个，`k=4,d=1` 有 378 个。独立 reviewer 重算了初始 makespan、最小变动任务/机器数、slot cost 与唯一最小 owner/matching，结果与主输出一致。这些是实现和有限实例证据；它们没有证明任意 `k,d` 都有同一 slot 结构，也没有证明从任意真实最优凸包点都能高效找到该修复。

## 闭环：弱 local gap 与单任务逃逸阈值

`optimal_hull_closed_cycle_audit` 同时检查 `UM-OPT-HULL-CLOSED-CYCLE-WEAK-LOCAL-GAP-v1` 与 `UM-CLOSED-CYCLE-SINGLE-JOB-ESCAPE-THRESHOLD-v1`。规范枚举包含：

| `k,d` | 全部合法分配 | `OPT` | 坏状态 `B` | 最小首步峰值 | 超过 `B` |
|---|---:|---:|---:|---:|---:|
| 3,1 | 1,024 | 1 | `7/6` | `23/18` | `1/9` |
| 3,2 | 16,384 | 1 | `7/6` | `23/18` | `1/9` |
| 4,1 | 8,192 | 1 | `43/32` | `45/32` | `1/16` |

独立 integer-owner enumeration 还核对了 `k=4,d=2`（262,144 个分配）和 `k=5,d=1`（65,536 个分配），并在 `k=3,d=1`、`k=4,d=1` 遍历所有等尺寸根 tie order。subset-DP 与 independent minimax path 分别得到 98/269/171 等有限状态数和 4/6 步显式逃逸路径；这证明列出的状态中单个任务改动的最小峰值确实高于坏状态，不证明所有闭环或任意平局都有同一阈值。

`optimal_hull_closed_cycle_audit.json` 明确使用精确整数/Fraction、无浮点容差，且有限程序只核对已列构造、任务分配、slot matching 与 path oracle。源文件的 `limitation` 直接排除一般近似、硬度和由有限输出推出的普遍结论。闭环与长链的坏值、slot 代价和路径阈值相近，但它们是不同的局部对象，不能互相替代。

## 与已有正文的比较

- 《长链联合投影与最优凸包边际障碍有限审查》已经给出一般森林耦合、长链收缩和固定真实最优凸包逐行/计数障碍。本对象新增的是另一组最优 slot 初始化与闭环单任务逃逸输出，不能把有限 `R_k` 修复写成一般 rounding theorem。
- 《固定阶向量贪心与 q13 线性缺口增量审计》与本批都含局部 slot/凸包数值，但其对象是固定阶向量贪心；此处保持 optimal-hull/closed-cycle 身份，不合并数值比。
- 《配置剥离与联合匹配有限审计》中的全局配置/匹配结论不能吸收本批局部路径成本；本批也没有补上通用配置求解器。

## 处置与接续

四源全部 `integrated` 到本审查。独有内容是：长链 `B_k`→`R_k` 的有限修复表、最小 slot-owner 唯一性、闭环全状态枚举、最小首步峰值和 tie-order 检查。后续若要升级，需要先给出一般输入域上的最优凸包点来源、slot cost 优化算法及全局可行性证明，并明确任意平局、闭环和长链的量词；不能把本批 270,336 或 91,136 个有限状态当作全称证据。
