# 2. 精确命题与承重条件

给定合法 unrelated-machines 实例 `P`。任务 `j` 的有限可用端集合 `E_j`，所有有限边组成 `E`，边变量为 `x_e`。令 `I` 由以下 assignment ideal 恒等式生成：

- `x_e^2=x_e`；
- 同一任务的不同端 `e,f` 满足 `x_e x_f=0`；
- 每个任务满足 `Σ_{e∈E_j} x_e=1`。

固定有理 `T≥0`。要求存在定义在次数至多 `2n+1` 商空间上的同一个有理线性泛函 `L`，满足：

1. `L(1)=1`，且对每个次数至多 `n` 的 `q`，有 `L(q^2)≥0`；
2. 对每台机器 `i`，令 `K_i=T−Σ_{e=(i,j)}p_e x_e`，并对每个次数至多 `n` 的 `q` 有 `L(K_i q^2)≥0`；
3. `L` 尊重 `I` 中的所有恒等式。

量词是任意合法 `P`、任意 `T` 和任意满足这些条件的 `L`。结论是 `OPT(P)≤T`：至少存在一个真实、不可拆分、每机负载不超过 `T` 的整数分配。这里是给定证书的逻辑充分桥，不是寻找 `L`、验证所有指数对象或从输入构造 `L` 的算法。

# 3. 原子权筛选证明

对每个合法完整分配 `σ`，令 `e_j(σ)` 为任务 `j` 在 `σ` 中所选端，并定义完整原子

\[
m_σ=\prod_{j=1}^{n}x_{e_j(σ)}.
\]

其次数是 `n`。由 Boolean/one-hot 理想，`m_σ^2=m_σ`，并有商环恒等式

\[
\sum_{σ\text{ 合法}}m_σ
=\prod_{j=1}^{n}\left(\sum_{e\in E_j}x_e\right)=1. \tag{1}
\]

定义 `w_σ=L(m_σ)`。平方正性和幂等性给出 `w_σ=L(m_σ^2)≥0`；对 (1) 施加 `L` 得 `Σ_σ w_σ=1`，所以至少有一个正权原子。

固定机器 `i`。在商环中，同任务冲突恒等式把 `x_e m_σ` 消成零或 `m_σ`，因此

\[
K_i m_σ^2=(T-L_i(σ))m_σ,
\]

其中 `L_i(σ)` 是 `σ` 在机器 `i` 上的真实负载。由于 `deg(m_σ)=n`，可以把 `q=m_σ` 代入逐机局部化器：

\[
0\le L(K_i m_σ^2)=(T-L_i(σ))w_σ.
\]

任何 `w_σ>0` 的原子都满足所有 `L_i(σ)≤T`；结合权重和为一，得到真实 `T`-可行整数调度。这也说明了承重阶数：局部化器本身只测试 `K_i q^2`，要把完整原子放进去必须同时拥有 `q` 的次数 `n` 和泛函的最高次数 `2n+1`。

边界处理是同一证明的一部分：`n=0` 时唯一原子是 `1`，直接输出空分配；`T=0` 时任何正负载原子被逐机局部化器强制为零；`p_e=0` 不产生除法。不可用端不进入 `E_j`，因而不会被虚构为可行端。

# 4. 精确失败机制与不能推出的命题

以下削弱会使上述桥失效或改变其含义：

1. **次数不足。** 只有次数 `2r` 的共同矩至多允许把 `q` 取到次数 `r`。若 `r<n`，完整 `m_σ` 不能代入 `(T-L_i(σ))w_σ≥0`，所以固定阶四阶矩没有自动的原子筛选能力。
2. **不相容见证拼接。** 每台机器或每个前缀若分别选择自己的边际/矩，而非同一个全局 `L`，则 `Σ_σ w_σ=1` 与逐机负载不等式不再作用于同一批原子；不能由局部 CONFIG 边际拼出全局分布。
3. **局部化器被截断。** 只验证常数、低阶或有限抽样的 `K_i q^2`，不能声称所有完整原子均被筛掉。所谓“看过的原子”也不能替代对完整原子族的全称条件。
4. **把存在当生成。** 任意真实 `T`-可行分配的 Dirac 分布都能产生一个满足条件的 `L`，但该分布或完整原子表可能有 `m^n` 规模。证书存在、证书可验证、证书可位多项式表示/解码是三个不同问题。
5. **把有限审计当普遍定理。** 有限 Fraction 案例只能核对实现和边界，不能证明任意 `P,T` 的证书生成器，也不能推出 `OPT>T` 的可靠拒绝。

因此，本对象不能升级为一般 `UM-TARGET-v1`、统一 `(2−ε)` 算法、NP-hardness 结论或“所有低阶矩都存在统一 gap”的定理。它只钉死共同矩路线的全局原子承重义务。

# 5. 相关对象与层级比较

## 5.1 四阶共同矩、近平坦提取和 HS 反例

`UM-GLOBAL-ASSIGNMENT-C2-MOMENT-MODEL-v1`（正文 `43aee4f76d83e01522ad`）把剪枝边 `p_e≤T` 上的显式四阶 `C2-load(T)`、全局 `M_2⪰0` 和逐机一阶负载局部化器形式化；它只保留次数四信息。`UM-GLOBAL-MOMENT-NEARFLAT-EXTRACTION-v1` 在额外可验证的迹缺陷承诺

\[
\delta=\sum_e\operatorname{tr}(A_e-A_e^2)
\le\min\{1/(64ndR),\eta/16\}
\]

下，才从给定四阶矩运行 HS 贪心，输出真实调度并保证（已剪枝时）`L_i≤(1+3δ)T≤(1+η)T`。它是输入已给证书时的条件提取器；没有从普通 `P,T` 生成该矩的算法。`UM-GLOBAL-MOMENT-HS-GREEDY-GAP-v1` 的精确三机例（一个长度 1 任务、八个长度 `1/4` 任务、`T=OPT=1`，210 个真实最优分配的均匀四阶矩，`rank M_1=17`，全空间缺陷 `δ=66`）使指定 big-first 全 HS 规则输出负载 `(1,2,0)`，比率恰为二。该反例只否定无近平坦承诺的指定规则，不否定全阶桥、近平坦定理或所有矩算法。

这条层级关系应保持为：全阶 `2n+1` 证书给出直接正原子；四阶近平坦证书依赖额外小缺陷控制近幂等和选择损失；大缺陷四阶矩可失败。不能把四阶 HS 规则当作全阶原子证明的替代品。

## 5.2 C2/弱 H2 的近二间隙

`UM-C2-LOAD-UNIT-GAP-v1` 的单位同机多色 slice 对每个 `m≥3` 给出四阶 `C2-load` 证书，阈值 `T=(m+1)/m` 而整数 `OPT=2`，比率 `2m/(m+1)` 趋二；`UM-WEAK-H2-CONFIG-MOMENT-GAP-v1` 更进一步要求共享一阶点落在完整 `CONFIG(T)`，仍保留正值间隙上确界二。它们说明固定阶、低阶和仅一阶配置接口不能直接支付完整原子容量；这不是对所有低阶体系的统一 gap 定理，也不反驳全阶桥。

## 5.3 前缀原子解码

`UM-PREFIX-ATOMIC-DECODING-v1` 把完整原子族压缩成可查询前缀 law：同一个非负、one-hot 守恒的 `π(S)`，并要求每个完整叶原子满足逐机容量局部化。给定该 law，可按任务顺序正延伸，至多 `O(|E|)` 次查询得到正权完整调度；其存在性与 `OPT≤T` 等价。前缀审查明确指出，law 的生成、可靠 `FAIL⇒OPT>T`、full-degree localizer 和精度/秩条件仍开放。故前缀接口是“表示/解码”增量，不是从普通实例免费生成全阶证书的办法。
