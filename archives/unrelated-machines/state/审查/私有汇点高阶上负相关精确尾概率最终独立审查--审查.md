# 2. 固定边际 higher-order NC 合同

对象 UM-OPT-HULL-HIGHER-NC-SUCCESS-v1 只在明示合同下成立：k>=2、r>=k、1<=d,q<=k，同一个固定 x，所有组具有固定边际；B 大任务在 homes 上的边际为 1/r，每组 k 个 small 在 home/sink 两端时间 1/k。合同只要求同 sink 的全正 upper-NC：

Pr[所有 j 属于 S 都送到同一 sink] <= r^{-|S|}

对每个 2<=|S|<=d；不要求补事件 NC、跨组相关性限制、保持任务数或某类 dependent rounding。成功事件是 Cmax<=2−q/k。

若 B 在 home h，令 D_i 为第 i 组送 sink 的 small 数，则每态精确有 Cmax=2−D_h/k。对任意 2<=s<=min(d,q)，成功迫使

sum_i binom(D_i,s) >= binom(q,s)。

上界由 NC 求和给出

E sum_i binom(D_i,s)
<= binom(k,s) / r^{s−1}。

故成功概率至多

A_s = binom(k,s)/(r^{s−1} binom(q,s))。

相邻阶比是

A_(s+1)/A_s = (k−s)/(r(q−s)) <= 1，

使用 r>=k 和 s<q。令 t=min(d,q)，最强可用阶是 t，最终上界是 min(1,A_t)；t=1 时没有二阶以上计数界，精确最大值为 1，不能把形式上的 k/q 当作 exact probability。

# 3. 达到 law 与边界情况

作者达到 law 与独立重构一致：B 均匀选 home h；q-type 以概率 p 让 h 中 q 件、其它 q? 选取不同组各一件送 sink；1-type 让 h 中 1 件、其它 k−1 个不同组各一件送 sink；其余 small 留 home。每态总 sink 件数为 k，组与组内任务置换对称给每件 small 边际 1/r。

固定组内 s-subset 同时去 sink 的概率为

(p/r) * binom(q,s)/binom(k,s)（s<=q），s>q 时为 0。p<=所有 A_s 时同一 law 同时达到全部合同阶数，并保持全部边际。q=1、d=1、p=1 截断分支必须单列；纯 1-type 或纯 q-type 分别给出精确成功，不存在形式比值漏洞。权重是有限有理数，有限样本空间最大值达到。

该结论是固定 x 的随机舍入合同：可以重选 x、采后重新改派、改变边际或直接构造好调度时不受该尾界限制。实例本身可直接取 OPT=1 调度，因此高阶 NC 尾界不是困难性证明。

# 4. 补事件、期望和 adaptive 量词

不能默加补事件 NC。独立 audit/来源给出 k=r=3,d=3,q=2,p=1 时，同组三件 small 全留 home 的概率可为 1/3，高于 (1−1/r)^3=8/27，同时满足所有同 sink upper-NC。故达到 law 不能冒充全正/全负 NC 或特定 dependent-rounding 实现。

既有 pair-NC 期望达到 law 只含 1-type/2-type，三阶以上全正 cylinder 可为 0；在 r>=max(k,binom(k,2)) 时，既有期望值仍是另一个对象，不能被本高阶成功尾界替代。两者必须按目标事件和量词分开。

Adaptive best-of-B 采样的乘积界需要每个实际轮在给定全部正概率历史后仍保持同一 x 和 upper-NC 合同。此时条件成功概率<=p*，无成功概率逐轮乘下去，至多 B 轮成功率

1−(1−p*)^B <= Bp*。

不要求独立，允许 early stop；失败历史可以虚拟后续成功概率为 0。若只有每轮无条件 law，则只能直接使用 union bound Bp*，不能默加条件乘积。

# 5. 位复杂度与增长阶数

取 r=k²,d=k,q=ceil(epsilon k)，在充分大 k 时 q>=2，精确非截断概率为

binom(k,q) / k^(2q−2)
<= 2^k / k^(2 epsilon k−2)。

完整 P 和 x 仅需 polynomial(k) 位；任何固定输入位长多项式次数 B(L) 的 best-of-B 成功概率至多 Bp*，趋于 0。没有将数值指数小误称为证书位数指数。

对一般 d(k)→∞，取 s=min(d,floor(q/2))，则 s→∞ 且最终 s>=2。逐因子可得

A_s <= k² [2/(epsilon k²)]^s，

因此任意固定 polynomial budget 的成功率最终为超多项式小。固定 d 时只得到有限阶概率边界，不能据此排除所有固定多项式采样预算。
