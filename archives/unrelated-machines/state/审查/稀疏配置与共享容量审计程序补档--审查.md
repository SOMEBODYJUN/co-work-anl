# 来源读取与运行边界

六个 source 均已 clean show 导出并逐行读取，代码副本和本轮输出保存在 evidence/agent_um-20261101/batch2。代码大小分别为 7739、12078、10625、6789、9205、21738 字节。当前 blob、SHA-256 和 clean ID 已列在 frontmatter。已有稀疏、raw SH3 和 row-uniform 审查承担 canonical 数学叙述；本页补足当前测试程序的字节保全和复现边界，不重复命名同一数学对象。

本轮 raw K2 成功运行：c=3/4，T=7/4，18 台机器、17 项作业、34 个有限端点；7 维全局 M2 Gram 的正定 pivot 为 1、21/100、63/320、7/40、7/256、7/288、7/384；18 个 raw affine localizer 全部精确正定；72 个局部 squarefree moments 和 72 个完整 membership patterns；canonical state entry 为 -1/160，quality lift 为 -3/640；实际完整调度峰值为 1。程序明确没有枚举全部 assignments，也没有声称 global M3。

raw SH3 成功生成 120 个二项式公式案例，其中 85 个严格反向切为真；小完整矩阵 m=6,q=2 有 45 台机器、106 项作业、750 个有限端点，峰值 11/6。它把一般 SDP、全大矩阵、全 assignment 和未知 decoder 列为未运行义务。

稀疏主程序直接依赖 examples/unrelated_machines/sparse_conditioned_configuration_input.json 与 evidence/certificates/unrelated_machines/sparse_conditioned_configuration_witness.json。两份冻结输入不在当前结果树对应路径，直接运行得到 FileNotFoundError，因此不伪造输出。稀疏独立程序与 row-uniform 长审计在本轮运行窗口内未完成；沿用既有冻结 JSON 的计数并明确其不是本轮重跑。

# 稀疏条件配置程序

主程序构造两棵 k 叉深树、根桥、底层终端、相邻占位任务和共享 z。参数为 r=(k-1)/k，s0=min{s: k r^s <=1}，M=(k-1)k^(s0-2)，H>=s0 且 2^(H-2)>=M，gamma=2^(-(H-2))，T=1+1/k。每条有限边分别构造一个配置点，使指定边际为 1；不同边没有共同 base 或联合分布。整数调度仍由二叉扩散和 z 负载阻挡，既有 canonical 结论为 OPT=2-1/k、OPT/T=2-3/(k+1) 趋近 2。

独立程序用另一数据结构重建 k=3 域实例，增加 bag tree、separator、逐查询 forced edge 和上界调度检查，并将递推参数扫到 k=3..40。既有冻结审查给出 k=3,H=5 完整展开 1051 jobs、729 machines、2426 finite edges，以及 bag tree 565 bags、564 edges、最大 bag 4、separator 3；这些数字来自冻结 JSON，本轮不重新生成。

该源只支持 UM-SPARSE-CONDITIONED-CONFIG-GAP-v1 与 contracted/star-transfer 的明确条件合同。不提供通用 configuration LP oracle、共同 query law、SA/SDP 固定层级下界、一般近二 hardness 或 UM-TARGET-v1 结论。缺失 examples/evidence 依赖是复现边界，不是数学反例。

# raw K2、raw SH3 与吞吐晶格

raw K2 程序在 18 台机器和 17 项作业上令局部 full-law、degree-two、全部 affine localizer 通过，但 canonical claim 的 state entry 为 -1/160，加入 epsilon 后为 -3/640；同时存在峰值 1 的真实调度。因此它反驳“同一 raw full-local-law 自动给 canonical pullback 非负”，不反驳 actual OPT=1，也不推出一般 SDP hardness。

raw SH3 程序的 120 个大计数案例只验证二项式恒等式和尾界；m=6,q=2 小矩阵验证 690 个配置支持、106 个作业覆盖和 750 个端点边际，路径峰值 11/6。它支持指定集合切边界，不提供大族 decoder 或一般调度算法。

吞吐晶格程序的 primal/dual 顶点枚举验证容量函数 lattice 次模关系、occupancy 次模和 2×2 joint-identity 负控制。价格 LP 量不等于真实 assignment，不能把该有限对象当实际调度器。

# 行均匀相关读出

row-uniform 程序的输入是显式简单二部图：每个左点有共同标签，右点资源数等于度数，每条边映射对资源满射且均匀。算法以整数碰撞势严格下降得到稳定标签，再复制 ceil(d/2) 个配额节点并做一次全局增广匹配，最后把 selector/port 编译成显式平层 unrelated-machines 输入，适用子类的 makespan 上界为 3/2。该合同不覆盖非均匀行、重复自查询或一般 UM 矩阵。既有冻结审查记录 361 个输入、1646 个 profile、943 个稳定 profile 的全部小子集 Hall 检查、6068 个原任务回算和 151 次严格势下降；本轮保留代码但未把长审计重新计入这些数字。

# 比较与处置

稀疏两程序与既有 sparse canonical/review 是同一数学对象的代码层；本批独有的是当前 source ID 的程序字节、依赖缺失记录和未完成重跑声明。raw K2 的独有内容是局部矩全过而 canonical quality 为负的精确 pullback 反例。raw SH3 的独有内容是 120 个计数案例和 m=6,q=2 小矩阵。吞吐晶格独有的是容量函数与真实 assignment 的身份负控制。row-uniform 独有的是整数势、全局 Hall 匹配和 3/2 平层编译。
