# 2. DAG 需求桥：完整合同、精确恒等与可迁移边界

输入是显式有限简单 DAG `D=(V,E)`、指定入度为零的根 `r`、二进制非负需求 `k_v`。`k_v=0` 的顶点必须是出度零终端；正需求死端、不可达点、`k_v` 大于出度均保留。根树 `H` 是从 `r` 出发的外向子图，每个非根选中点入度恰为一，且所有选中正需求顶点（包括输出叶）都收费。定义

`b(H)=min({1} ∪ {deg_H^+(v)/k_v : v∈H, k_v>0})`，`b*=max_H b(H)`。

正文给出 `UM-DAG-DEGREE-TOKEN-IDENTITY-v1` 的显式构造：每个顶点一台机器；根任务 `g` 只在 `r` 运行且耗时 1；对正需求 `v` 设 `q_v=min(k_v,deg_D^+(v))`，建 `q_v` 个在 `v` 以 `1/k_v`、在每个显式孩子以 1 运行的子任务；若 `q_v<k_v`，再建一个只在 `v` 以 `1-q_v/k_v` 运行的填充任务。终端不建子任务/填充。子任务数至多 `|E|`，填充至多 `|V|`，不按二进制需求值作伪多项式展开；每件任务至少有一个有限端，全部处理时间非负且不超过 1。

两向证明的精确层次如下：

- 从任意 `C_max=C<2` 的完整实际调度，根任务使 `C≥1`；每个外送子任务在目标机器贡献 1，因此每台机器至多接一个外来 unit。以外送子任务 `v→w` 为边，根可达部分是实际根树 `H`。若选中正需求点 `v` 外送 `s_v` 件，精确负载为 `2-s_v/k_v`，故 `deg_H^+(v)/k_v≥2-C`，并得到 `b(H)≥2-C`。死端正需求若被选中会负载 2，不能充当免费终端。
- 反向给定根树 `H`，逐层删去超出 `k_v` 的子树，给每个保留孩子分配不同子任务，其余子任务留 home、填充留唯一端、根任务留根；选中正需求机负载至多 `2-b(H)`，非树机器至多 1。
- 由此得到该子族的精确恒等 `OPT(P(D,k))=2-b*`。`b*=0`、根终端、正需求死端与不可达图的边界都在正文中显式处理，避免 0/0。
- 阈值归约只做条件结论：列出 `Γ={1}∪{h/k_v:1≤h≤min(k_v,d_v)}`，对每个 `τ∈Γ` 把需求替换为 `ceil(τ k_v)`，调用假设的统一 `UM-TARGET-v1` 算法，只有返回 `C<2` 才解码并以原需求评分；在 `τ=b*` 时得到 `b(H)≥ε b*`。它不构造一般 UM 近二算法，也没有把 MMDA/Santa Claus 关联文献中的必要方向冒充为本源新定理。

因此可稳定写入正文的结论是：这是一个自足、可复算的特殊输入接口和精确恒等；“一般不相关机算法/硬度”仍是缺口。

# 3. 任意环境有向环：去环恒等与新增桥梁范围

扩展正文先区分“反馈环本身”和“由外部 unit 任务触发的树”。给完整调度 `σ`，`J` 任务都有 home `h(j)`、home 时间 `a_j∈[0,1]`，非 home 有限端耗时为 1；`U` 任务所有有限端耗时为 1。把外送 `J` 任务画成带原任务标签的弧 `h(j)→σ(j)`。逐次取一条简单有向环，将环上任务同时退回 home；环点负载变化严格为 `a_j-1≤0`，不增任何机器负载，至多 `|J|` 轮清除全部环。这是完整已知调度之间的正规化算法，不是从输入直接寻找好调度。

在 `C_max<2` 时，单位入度约束给出每个点“转移入弧数 + 执行 U 原任务数”至多 1。因而原环互不相交；在此附加域可一次清除全部环，剩余转移图是朝外有根树森林，但根不必来自 U。由 U 实际目的地向前可达的区域 `R` 若满足正文的 root-forest 合同，则保留 `R` 内 home 任务、把外部 home 任务退回 home，得到精确负载式：`R` 内等于原调度，`R` 外等于 `b_i=Σ_{h(j)=i}a_j`。正文特别强调：没有 `b_i` 预算，不能声称逐机不增；给出两机/多任务反例；`C<2` 的严格性也用三机环例展示。

随后扩展为允许环境有向环、根可有输入边的 `UM-DIRECTED-DEGREE-TOKEN-IDENTITY-v1`。根任务 `g` 的实际位置作为根；子任务外送图由实际 unit 阻塞自动成为真实根树，环境原图是否有环与根是否有入边均不改变解码。对任意根树 `H`，仍可通过削减每点子树构造完整实际调度；因此桥梁精确恒等在正文承诺的任意环境图域内保持。这个扩展修复了旧 DAG 输入合同的环境限制，却没有解决“从一般 UM 输入找到共同根位置/好森林”的主搜索义务。

该源还附加 `UM-ANONYMOUS-TOKEN-M1-LIFT-M2-NONEXTENSION-v1`：在共同次数至多四的 Boolean functional、匿名 head、home/context 约束下，形式抽样替换给一般 M1 Gram PSD；一个 `k=4` 的有符号 beta 例子证明给定聚合 functional 不能无条件提升到带原身份的 M2。正文将这一定义级非扩展严格限定为“该 functional 无原身份扩展”，不等同于原调度实例不可行，也不等同于一般近二、硬度或算法结果。必须保留所有 head×context 的完整 PSD 矩阵；不能只检查逐行 M2。该附加部分的结论与任务桥独立，不应把 signed functional 反例当成 CAG/SPE 结论。

# 4. 共同拥塞流：完整/条件/有限层次

`rooted_dag_congestion_flow.md` 接续 DAG 桥，输入仍是显式非空 DAG、根入度零、二进制需求。其核心新合同要求给定含根支撑 `W` 和非负有理流 `f`，在支撑上满足源/汇守恒、边容量与每点需求约束；从一次整数流提取根树，内部点负载由拥塞 `K` 控制，得到精确比例族（正文给出固定 `K` 的 `1/(2K−1)` 锐界及相应证书）。固定支撑的最小 `K` 可由最大流/最小割式搜索得到；这是真实证明与实际构造，不是枚举所有调度。

正文另立 `k≥2K` 合同，允许把需求至少 `2K` 的守恒点免费补入，再只对非单位分叉点作参数化枚举；指数因子落在 `h=#{v:k_v≥2}` 或非单位分叉支撑，因而没有变成一般多项式算法。`k≥K` 与 `k≥2K` 两个合同必须分开，不能把扩区后的指数支撑搜索写成“已解决一般支撑”。固定 `W,K` 的流提取、分叉点枚举、免费守恒点补入和终端补入是条件/参数化构造；一般输入的共同支撑选择、可避免枚举的结构，以及从一般处理时间矩阵提取该需求树对象均未解决。

正文还明确给出激活边际 LP 的失败机制：单位汇流走廊可在逐点边际上看似可行，但联合激活会产生共享瓶颈，单独的 edge/vertex marginal 不能替代一个共同整数流证书。因此“有流证书”的实例和“逐点边际通过”的实例必须在正文中分层。有限程序/独立实现只验证列出的固定支撑、拓扑和参数，不认证全局拥塞定理的新颖性。

# 5. 与既有成果的关系、保留与缺口

* 这三个源共同依赖“unit 阻塞 ⇒ 根树/森林”的结构，但 DAG 桥、任意环境去环扩展、共同拥塞流的合同和量词不同；不应一源多写为一般 UM theorem。
* 原文已把 MMDA/Santa Claus 的已知关联、SA 文献线索、固定流工具与本地自足证明分开。这里保留这种层次：精确桥梁是完整证明；流证书与半比例/参数化段是条件或参数化；有限审计只支撑实现和边界；`UM-TARGET-v1`、共同根/支撑搜索、一般近二和硬度仍 OPEN。
* 目标 CAG 六人有限单位客户模型与这三个 unrelated-machines 对象没有同一效用/均分语义；不能把 `b(H)`、`K` 或 signed M2 nonextension 转移到六人 SPE 覆盖目标。
