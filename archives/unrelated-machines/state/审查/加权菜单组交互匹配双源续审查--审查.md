# 加权菜单组交互匹配双源续审查

## 1. 对象与精确合同

每组 g 有非空 indexed states；state 的显式资源集合内标识互异，同资源可出现在多组和多个 state。每个 incidence job 在 private state 机上用时 p_gsu、在资源机上用时1，selector 在本组所有 private 机上用时1；state 私有权总和 W_gs≤1，允许零项和空集合。令 Δ 为全部 states 并集上某资源的跨组度，M 为组交互图中单组相邻组的最大数，并给出有效整数上界。来源 `UM-BOUNDED-GROUP-INTERACTION-WEIGHTED-MENU-v2` 取

β = 1/(M+2Δ−1),  R = 2−β。

对每个非空显式输入，确定性位多项式算法输出所有原 jobs 的具体合法调度，峰值至多 R·OPT。算法不输入 OPT、源 witness、最优 state 或配置分布；失败分支只保证实际 OPT≥1+β 并给峰值2，成功分支给峰值R。G 非空且 selector 给 OPT≥1；空 G 是另一个接口。

## 2. 归一化和失败分支

对每个 W_gs<1 的 state 加一枚只在该 private 机或独占新资源可执行的 bonus job，使 state 总私有负载归一为1。投影删除 bonus 不增负载，反向把每个 state 的 bonus 独立放新机，故增广实例和原实例 OPT 相同；这一步保留未选 state 的所有真实 jobs、零项和空 state。

称 state 为分散态若所有 private 时间≤β。若某组没有分散态，则每个 state 有某个 p>β 的 incidence。对这些组 H 与资源建立二分图：某组和资源相连当且仅当某个 state 含 p>β 的该资源。若无覆盖 H 的匹配，则假设有峰值小于1+β的调度；每个 H 组 selector 选一 state 后必须外送一枚 p>β job，否则 private 负载超过1+β；资源在 C<2 时至多接一枚 unit job，导出覆盖匹配，矛盾。于是 OPT≥1+β。失败时所有 selector 和 incidence 留 private，峰值2，且 2/(1+β)≤2−β，得到合同比。

## 3. 成功分支的双层匹配

若重资源图有覆盖匹配，为每 H 组选对应 state 并预留这枚互异资源。对分散组 L 选择固定 state，删除预留资源；完整菜单交互度 M 使每组至多被删除 M 项，每项权≤β，故剩余 private 质量 W'_g≥1−Mβ。

将每个轻组 state 的未预留正权排序。把前 floor(n/Δ)·Δ 项按连续完整 Δ 块建立 slot；每 slot 连接 Δ 个互异原资源。由于同资源跨组度≤Δ，所有轻组 slot 图满足 Hall，能一次匹配所有完整块。计账时前至多 Δ−1 项损失，每项≤β；其余尾项按块首权下界，得到导出质量

Σ_{u∈B_g} p_gsu ≥ [W'_g−(Δ−1)β]/Δ ≥ [1−(M+Δ−1)β]/Δ = β。

H 组导出质量>β，L 组至少β；所有资源互不重用。selector 放选中 private，未选 state 的 incidence 仍留原 private，每台资源最多一枚 unit job，峰值≤2−β。归一化投影后仍是原 jobs 的合法调度。整个证明只用输入给出的 M、Δ 结构；不把 CONFIG LP 的分数间隙当作算法后端。

## 4. 边界、复杂度与反面用途

distinct resource set 是承重条件；若同 state 两枚不同 jobs 指向同一资源，Δ=1、M=0 也可能出现真实 OPT=3/2，不能沿用 β=1 的端点。Δ、M 只参与比较、阈值和显式关联分块，不按二进制数值展开；归一化最多增加每 state 一枚 bonus。排序、增广路、完整 Δ 块匹配和有理负载回算按显式 incidence 数及输入位长多项式。

固定 M、Δ 给结构类规模无关的次二界；若变量标签菜单的完整并集度可估为每组最多 q、每变量跨组至多 d，则可取 M≤q(d−1)、Δ≤min(d,Q)。这为源反面提供必要边界：不能同时保持 M、Δ 常数而要求任意接近2的实际 hardness。允许 M 或 Δ 增长不自动给 NO 解码，固定 cube 维度也不自动控制完整菜单交互。

这是限定结构的真实调度算法和失败下界，未声称因子锐性、一般 UM 算法、NP-hardness 或 SPE 覆盖。有限排序核验只作辅助证据。第三阶段 mapper 应检查度数是否按全部 states 并集计算、bonus 是否覆盖未选 state、资源标识是否真的互异，并保留失败分支的 OPT≥1+β 语义。六人 SPE 目录、完整历史、均分和任意平局不在本源内，`UM-TARGET-v1` 仍开放。
