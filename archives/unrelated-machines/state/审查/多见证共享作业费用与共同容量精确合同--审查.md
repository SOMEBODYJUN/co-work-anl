# 1. 处置结论与对象身份

本批两份冻结 JSON 实际读取并合入同一个数学对象：固定的两目的地 unrelated-machines 家族，其中每个查询任务各有自己的 unit 目的地，所有查询候选在一个共享机器 `R` 上发生竞争；唯一收费任务 `f` 可以从 `R` 改派到 `S`。对象的稳定身份是
`UM-MULTIWITNESS-SHARED-JOB-FEE-CAPACITY-v2`。

这不是任意 unrelated-machines 输入的近似定理，也不是把多个独立的单查询见证拼成一个共同全开见证。它给出一个可完全写出、可位复杂度求值的参数族：无约束原实例的最优峰恒为 1；固定查询子集 `K` 后，峰值和闭阈值收费有精确公式。这个精确族的独有信息是“同一收费任务被多份互斥 singleton 见证重复使用”的门槛，而不是一个 makespan gap。

主审计 `2c928df5bca106c074f2` 的原始输出和代码独立于公式计算实际峰值，JSON 报告 `113` 个参数实例、`287104` 个完整原分配、`3004` 个 pattern、`19832` 次闭阈值收费检查，并重现 v1 空集缺口。独立审计 `4aaf9c59448e45021bdc` 另行保存 exact-first 实现：`359` 个参数实例、`135712` 个完整原分配、`4660` 个 pattern 最优值比较和 `23908` 次闭阈值比较；其声明明确是有限检查，不替代一般证明。两端都使用精确有理数，没有浮点容差。

v1 的第 7 项把空集误纳入严格和式，导致 `0 < B_empty=0`；v2 只把该项限制到非空 `K`，保留原 v1 字节和反例。该修复改变量词，不改变前六项。作者 Proof、Exact-first 独立重构以及最终 canonical 段的关联审查均已实际全文读取；它们没有发现修复后的合同有新的 standing fatal，但外部新颖性、源 NO 解码、跨实例预算和一般 hardness 均未认证。

# 2. 完整矩阵、量词和费用定义

取整数 `p>=1`，正有理数
`0<a_r<=1`、`0<b_r<=1`（`r=1,...,p`）、`0<c<=1`，并满足
\[
 c+\sum_{r=1}^{p} b_r\ge 1 .
\]
机器是互异的
`H_1,...,H_p,A_1,...,A_p,R,S`，共 `2p+2` 台；任务是互异的
`q_1,...,q_p,x_1,...,x_p,f`，共 `2p+1` 件。全部且仅有下表有限资格，未列边为无穷：

| 任务 | 初始端及时间 | 另一有限端及时间 |
|---|---|---|
| `q_r` | `H_r:a_r` | `A_r:1` |
| `x_r` | `A_r:1` | `R:b_r` |
| `f` | `R:c` | `S:1` |

每个任务必须恰执行一次，没有预载、额外任务、状态依赖资格或匿名容量。初态 `sigma_0` 选所有初始端。只给 `f` 计 owner 改派费用：`w_f=1`，所有 `x_r` 权为 0；因此费用是 `f` 是否真的从 `R` 改到 `S`，不是负载总量，也不是把一次改派的处理时间误称为新增 unit。

给 `K subseteq [p]`，pattern `K` 只规定：`q_r` 在 `A_r` 当且仅当 `r in K`，否则在自己的 `H_r`；所有 `x_r` 和 `f` 仍可在各自两条有限边中选择。写
\[
 B_K=\sum_{r\in K}b_r .
\]
`OPT_K` 是满足该 pattern 的所有完整实际调度的最小峰值。给有理闭阈值 `1<=beta<2`，`F_beta(K)` 是峰值不超过 `beta` 的完整调度的最小费用；不存在时记为无穷。这里“完整”始终包括未选的 `x_r` 与 `f`，不能删除背景任务或把 `R` 当作匿名共享容量。

# 3. 受限族的精确数学结论

## 3.1 原实例的精确值和单查询见证

`sigma_0` 的负载是
\[
H_r:a_r,\qquad A_r:1,\qquad R:c,\qquad S:0,
\]
故峰至多 1。反之若某完整调度峰值小于 1，则每个 `x_r` 不能在其 `A_r`（处理时间为 1），只能在 `R`；`f` 也不能在 `S`，只能在 `R`。于是 `R` 负载至少
`c+sum_r b_r>=1`，矛盾。因此
\[
\operatorname{OPT}(P)=1.
\]

对每个 `r`，另有完整调度 `sigma_r`：把 `q_r` 从 `H_r` 改到 `A_r`，把 `x_r` 从 `A_r` 改到 `R`，把 `f` 从 `R` 改到 `S`，其余任务保留初态。`A_r` 只剩 `q_r` 的 unit，`R` 只剩 `x_r` 的 `b_r`，`S` 为 `f` 的 unit，其余机器不变，所以峰至多 1；相对于初态，query owner 改变集合恰为 `{q_r}`。这些 singleton 见证各自存在，但不自动组成所有查询同时切换的共同见证。

## 3.2 任意 pattern 的最优峰值

对任意 `K`，有两份完整上界构造。

* 构造 I：`q_K` 按 pattern 放到 `A_r`，`x_r`（`r in K`）放 `R`，其余 `x_r` 留在 `A_r`，`f` 放 `S`。每个 `A_r` 恰有一枚 unit（或没有 `q_r` 时由 `x_r` 占一枚），`R` 负载为 `B_K`，`S` 为 1，故峰为 `max(1,B_K)`。
* 构造 II：`q_K` 放 `A_r`，其余 `q` 放 `H`；全部 `x_r` 留在 `A_r`，`f` 留在 `R`。`r in K` 的 `A_r` 有两枚 unit，其他 `A_r` 只有一枚，`R` 负载 `c<=1`，故峰至多 2；`K=empty` 时初态给出峰 1。

因此 `OPT_K<=min{2,max{1,B_K}}`。对下界，原实例下界给 `OPT_K>=1`。若某 pattern 调度峰值 `<2`，则每个 `r in K` 的 `q_r` 已在 `A_r` 占用 1，`x_r` 不能仍在 `A_r`，必须在 `R`，从而 `R` 负载至少 `B_K`。所以不可能存在峰值小于 `min{2,max{1,B_K}}` 的调度。若 `B_K>=2`，构造 II 达到 2；若 `B_K<2`，构造 I 达到 `max{1,B_K}`。故准确公式为
\[
\boxed{\operatorname{OPT}_K=\min\{2,\max\{1,B_K\}\}.}
\]

特别地，pattern 严格可行于峰值 1 当且仅当 `B_K<=1`；`B_K=1` 和 `B_K=2` 是闭等号，不应被有限程序的严格比较误读。

## 3.3 闭阈值的最小费用

当 `1<=beta<2` 时，任何峰值不超过 `beta` 的调度都落在 `<2` 的正规化区域，因此必须把所有 `x_r`（`r in K`）送到 `R`。

* 若 `B_K>beta`，`R` 的必要负载已经超过阈值，故 `F_beta(K)=infinity`。
* 若 `B_K<=beta` 且 `c+B_K<=beta`，让 `f` 留在 `R`，其余安排取构造 I 的非收费版本，峰值不超过 `beta`，故费用为 0。
* 若 `B_K<=beta<c+B_K`，`f` 留在 `R` 会使 `R` 超阈值，所以任何可行实际调度都必须把 `f` 改到 `S`，费用至少 1；构造 I 将它送到 `S`，峰至多 `max(1,B_K)<=beta`，故费用恰为 1。

因此
\[
\boxed{F_\beta(K)=
\begin{cases}
\infty,&B_K>\beta,\\
0,&c+B_K\le\beta,\\
1,&B_K\le\beta<c+B_K.
\end{cases}}
\]
等号 `B_K=beta` 属于可行分支，等号 `c+B_K=beta` 属于 fee 0 分支。`beta=2` 不可套用 `<2` 的强制论证：构造 II 在所有 `K` 上给 `f` 留在 `R` 的 fee 0 调度；`beta<1` 时则由原实例 `OPT(P)=1` 知所有 pattern 都不可行。

## 3.4 多 singleton 的共享收费边界

令 `b_r=c=1` 且 `p>=2`。每个 singleton `K={r}` 有 `B_K=1`，所以 `OPT_K=1`；但任何峰值 `<2` 的 singleton 调度都把 `x_r` 送到 `R`。若 `f` 仍在 `R`，两枚 unit 叠加成负载 2，故 `f` 必须去 `S`，每个 singleton 的费用都是 1。所有非 query 权重只有 `f`，所以总预算宇宙为 `W=1`，多份 singleton 见证重复触发同一收费任务。

然而 `|K|>=2` 时 `B_K>=2`，公式给 `OPT_K=2`，不存在把多个 query 同时切换到指定新端的共同 strict-1 actual。故“每个 query 各有一份 strict singleton”不能替代旧双见证分离论证所要求的同一完整 `sigma_1`。这里没有反驳旧定理；合同的量词和见证身份不同。到闭阈值 2，构造 II 使所有 pattern 都 fee 0，收费门槛正好落在 2。

对任意固定有理 `1<=beta<2`，可取 `b_r=1`、`beta-1<c<1`。singleton 仍有 `B=1<=beta<c+1`，故仍必收费 1；此时 `f` 的初端确为非 unit `c`、改派端为 unit 1。`a_r` 可任意取正且极小，不改变这个机制；该选择不是把 tiny query 时间冒充收费。

## 3.5 均匀容量和一般非空和式

令整数 `1<=s<=p`，取 `b_r=1/s`。则 `B_K=|K|/s`，严格峰 1 的条件变成 `|K|<=s`，闭阈值费用为
\[
F_\beta(K)=
\begin{cases}
\infty,& |K|>s\beta,\\
0,& |K|\le s(\beta-c),\\
1,& s(\beta-c)<|K|\le s\beta.
\end{cases}
\]
这是实阈值与整数基数的精确比较，不能偷偷取整。`s>=2` 且 `beta>=3/2` 时 singleton 满足 `c+1/s<=3/2`，所以有 fee-0 actual；只有 `s=1,c=1` 的 unit 共享在阈值 2 前保持收费。

更一般地，设 `K` **非空**、`B_K<=1`，并假定其中每个 singleton 在同一 `beta<2` 闭阈值上都必收费。逐个 singleton 的费用分支给 `c+b_r>beta`，相加得到
\[
\boxed{|K|(\beta-c)<B_K\le1.}
\]
空集不允许使用该严格相加：其前件真空成立而左项为 0，正是 v1 的 `0<0` 缺口。若 `beta>=3/2`、`c<=1`，则 `beta-c>=1/2`，故非空 `K` 必有 `|K|<2`，最多一项。这个结论只约束本共享汇流构件，不是一般网络的必要条件。

# 4. 证明等级、有限证据和失败机制

作者 Proof 对上述参数族给出完整的有限机器资格证明：原实例下界、两份 pattern 上界、`C<2` 时的 `x_K` 强制、闭阈值三分支、容量 `s` 特例和非空严格和式均逐项解释。Exact-first 审查先不读作者证明，从矩阵本身独立重构同一公式，并先找到 v1 空集反例；随后 v2/Proof 与 canonical §6 全文读后未发现新的 standing fatal。故“完整证明”只指这个显式参数族的数学合同，不指一般 unrelated-machines。

两份 JSON 是有限实现证据而非证明替代：

| 来源 | 实际读取的 exact 范围 | 独有去向 | 数学边界 |
|---|---|---|---|
| `2c928df5bca106c074f2` | 113 cases；287104 complete assignments；3004 patterns；19832 closed fee checks；直接由原 assignment mask/Fraction 求实际峰值 | 主规范回归、完整原分配 oracle、v1 空集反例重放 | 仅 raw two-destination family；不做 source decoder、通用 LP 或 hardness |
| `4aaf9c59448e45021bdc` | 359 cases；135712 assignments；4660 pattern optimum；23908 closed fee checks；exact Fraction；items 1–6 及 item 7（非空 K） | 独立实现的 exact-first 交叉核对 | finite checks only；不把独立代码的 PASS 变成一般证明 |

主程序先用原任务两个有限端直接枚举全部 `2^(2p+1)` 个完整 mask，再把实际最小峰与公式比较；它没有调用公式来生成主 oracle。阈值集合保留 `B=beta`、`c+B=beta`、`beta=2` 等边界，并显式记录 `v1_empty_set_counterexample_reproduced=true`。独立源保留旧 v1 exact 的 SHA 与独立审计代码 SHA；两者不应被合并成一次“同一程序重复运行”。

失败/障碍要单独保留：

1. v1 第 7 项的空集严格不等式是已发现并修复的真实量词错误；旧字节不能倒改，v2 只能限制非空 `K`。
2. 多 singleton 互相兼容于各自 pattern，却没有共同全开 strict 见证；不能用 `sigma_r` 的列表替换一个 `sigma_1`。
3. `OPT(P)=1`、`OPT_K` 精确可算并不提供 OPT gap；有限程序没有给出标签复制、跨源测试复用、外接容量、费用不重复预算或 source-NO 解码。
4. `s>=2` 的容量和 `beta>=3/2` 的 fee-0 singleton 说明“把更多 query 同时激活”会吞掉近 2 的收费门槛；这是真实边界，不是程序失效。

# 5. 与既有材料的关系和接续

* 与《共同容量修复的判定与实现边界》及其有序槽/共同尺寸分支相邻处在“完整任务、真实容量和精确有理比较”，但本对象的 `R` 竞争来自固定二目的地资格和 pattern，而不是可重开的共同尺寸流；不能把本公式当作一般 flow 或配置算法。
* 与《重型匹配凸化与逃逸残余审计》《双轨阈值与整除中性修复联合选择有限审计》一样保留有限 exact 证据和明确量词；它们的配置、half-unit、split/merged 机器语义与此矩阵不同，不能合并 ratio 或 hardness。
* 与《近平坦 HS 矩提取与负接口有限审计》同样有精确 Fraction 的有限实现，但 HS 源接收 moments/distribution 并只作条件提取；本对象直接枚举 ordinary unrelated-machines 原任务。相同的“有限 PASS 不等于一般定理”边界需保持。
* 与旧多输出预载星的合同不同：旧星在不同矩阵状态读独立的 zero/full 预载并要求两份全端模式；本对象在同一固定 `P` 中改变 `q_r` owner，`R` 同时承接互斥的 `x_r`，并只有一枚 `f` 计费。不能将两个接口的 pattern 直接互换。
* 与当前六人 Q-CAG-HALF-6 无模型身份关系：这里没有客户目录、SPE 或均分客户价值；对象继续留在 `archives/unrelated-machines`。

可复用接续是：若后续研究需要共享任务的多查询收费，先检查是否存在共同全开 strict actual，再应用 `B_K` 的汇流下界；若需要把多个 tests 接成通用 reduction，必须另行证明标签/任务复制、源 decoder 和跨实例费用预算，而不能从本族的 `p+1` 个实际见证直接推出。当前 generic LP、通用调度算法、NP-hardness 或主 UM 目标均未实现。
