# 2. 单任务端口向下闭集：独有核验与锐边界

## 2.1 量词和向下闭性

冻结 review 先在未读候选稿的阶段独立重构了入向位 y_j=1[x_j=s_j]。每个内部端口只有一个内部端点；给定辅助任务的一份真实内部分配后，任意端口从入向改到外部只删除非负负载。因此关系 R_T 的入向支持是布尔格向下闭集。这个论证只涉及内部容量；外部联合容量、外部既有任务和端口的另一端不进入投影。

若两份一致见证的入向支持分别含 a 个 0 端口和 b 个 1 端口，两个主理想的并集大小为 2^a+2^b-1。有 z 个零时间端口时，零坐标可任意自由加入，得到 2^z(2^a+2^b-1)。固定非零端口总数后，平衡两组给最小值 2^{floor(k/2)}+2^{ceil(k/2)}-1。这一步需要两份见证可以使用不同辅助分配；不要求把两个见证耦合成同一分配。

## 2.2 混合严格见证和锐例

当 k>=2 时，任意全态见证至少有一个入向端口。保持该见证的辅助分配，仅把一枚真实任务移到外部，得到恰翻一位的混合态；没有声称能在未知见证时多项式寻找这份分配，也没有把状态枚举误报为算法。

T>0 时，两台内部机器各放一枚时长 T 的辅助任务，按两组把端口时间分摊为 T/a、T/b，给出上述下界的达到例。a=0、b=0、k∈{0,1} 和 T=0 分别处理：零阈值时正时间端口不能入向，关系可因零坐标退化为整个立方体。单端口两个接口都计内部容量的情形在阈值 rho<2 下仍可保持等值；把共同外部容量重新计入则会产生第三态，不能从该对象外推联合网络。

## 2.3 受限文献代入和有限证据

review 独立打开 ECCC TR16-183，代入 d=2A-1，S={0,...,A}，T={0,...,B}，其中 A>=2，A<=B<=2A-2。在 A>1/(2-rho) 时，B=floor(rho A) 同时满足所需不等式，文献给出的三个可解条件均不成立。这个代入只说明该受限 downset 结构没有直接落入那三个充分可解条件；它不是本仓库新的困难性归约，也没有重证该文献的全部定理。

独立 Fraction 程序的有限回归覆盖 450 个随机内部实例、66 个符号组锐计数例、165 个零权强化例、边界与负控制、250 个等时间容量匹配实例、780 个有限重量集合代入和 32 个有理 rho 代入。另对冻结 7 状态输入逐机构造完整外接分配，并实际核验规范程序允许任意非空辅助端点数。有限运行只支撑列出的回归；向下闭性、主理想计数和锐例来自一般论证。

# 3. 单层平方根配额 review：离散地板与已归档重复

源 e6f9a7fab71e2f0aeaa3 完整读取单层配额 review。固定最大不交 t-束大小 s=nu_t，并集大小为 st。未选变量若在并集外有 t 个资源就能扩充，故至少 K-t+1 个邻域资源落在并集内。资源总关联度 Delta 给出
(q-s)(K-t+1) <= Delta st，
s/q >= (K-t+1)/(K-t+1+t Delta)。
与 t/K 取最小，再对 t 取最大，得到
b >= max_{1<=t<=K} min{t/K,(K-t+1)/(K-t+1+t Delta)}。
在 K>=sqrt(Delta)+1 时取 t=floor(K/(sqrt(Delta)+1))，保留整数误差 t/K>=1/(sqrt(Delta)+1)-1/K。分组族的极限必须写作 max{floor(sqrt(Delta))/Delta, 1/ceil(sqrt(Delta))}，不能写成连续值 1/(sqrt(Delta)+1) 的精确有限公式。

该 review 的结论和分组族、资源总量上界、多标签适用条件已完整包含在 单层平方根配额与单外层选择器双源审查--审查.md。其处置为 duplicate（保留 SHA 和全文处置链，但不再创建第二个平方根对象）。它仍明确：这是组合引理与有限审计，不是 NP-hardness，也不能未经固定完整标签把多标签邻域并集替代原需求图。

# 4. 单外层选择器 review：两个算法合同与 source boundary

## 4.1 两个输入量词不能合并

源 16116e77188b69b13ed9 记录两种明确合同。给定完整 typed primitive-SA1 有理点时，单外层独立 helper-home 结构给最低质量 epsilon^2/4，完整回填满足 Cmax<=2-epsilon^2/4。只输入 typed Q 时，11 次普通有理 LP 阈值查询和 CDF-max 后端给 13/8 比例。二者都只在一个 outer、各 home 互异、每个 home 有 own-singleton helper、fallback 与 homes 分离的显式域内成立；不识别任意 ordinary matrix，也不迁移到 multi-outer、无 home 的辅助组或隐式深层菜单。

对 typed Q，完整 ordinary 值满足 1 <= OPT(P(Q))=2-V <=2，其中 V 是不交 bundles 的最大最小 welfare。资源机器的 unit cap、selector/private jobs、未选 state jobs、zero jobs、重复 indexed states 和 unused machines 全部保留。反向只在 C<2 时由 unit resource 独占读出 bundle；C>=2 用平凡端点。

## 4.2 13/8 的数值合同和硬度源边界

Q-only 后端以 CDF-max 得到 W>(5/8) epsilon^2，并使用 a=13/8、b=10/8、d=1/256 的质量线和 11 次正二分。FAIL 只表示对应 plain LP 不可行，不能混作数值超时；可行下端点不必小于真实 V。完整回填将 selector、所有 incidence、未选 state、zero jobs 和重复索引逐一放回 private/resource 机器。

因此，对固定 0<delta<3/8，若某语言能以总位多项式归约到这个 typed 域，并且真实 YES 为 OPT=1、真实 NO 为 OPT>=2-delta>13/8，则运行该算法并计算实际 makespan 将区分两类；在 P!=NP 下，该特定 typed 结构不能承载这一真实近二 gap source。这里没有推出一般 unrelated-machines 的困难性，也没有把 primitive-SA1 relaxation 的局部不可行写成真实 NO。

源后半另记 raw K2 local-law canonical pullback obstruction 与 raw S3 充分提取桥。前者说明各机器 local degree<=4 law 与 global M2 仍可能在三因子上给出负项，不能自动得到 canonical SA1；后者仅在给定 raw degree<=4 moment table 同时满足 boxes、load slack、unit-resource cap 和长度至多三的 literal lifts 时可构造 canonical M1/M2 点。两者都不改变 13/8 typed 算法，也不是一般 hardness。

# 5. 关系、限制与第三阶段接续

本三源只能给出条件性的跨对象联系：

1. 单任务端口的向下闭集说明一个内部端点的签名接口会产生大量混合状态；平方根配额的 t-层计数说明高重数是压低所有部分配额的必要资源；两者都属于“局部资源合同不足以自动得到全局近二 gap”的障碍线索。
