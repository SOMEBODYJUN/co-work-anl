# 1. 一个 physical 模型，三种证明实现

本批五主源在实际认领确认后逐份全文读完，原件按冻结SHA保留；另三份已Boss2整合的独立/读后/最终稿只比较、不重done。[原件证据](../../tools/evidence/weighted-literal-pool-v2-history/README.md)列完整SHA和路由。主数学已有[bounded compiler障碍](../障碍/occurrence加权literal-pool三二上界--障碍.md)与[双源审查](两层标签收费与出现异权文字池双源审查--审查.md)；本批补尚未处置的作者/typed/root来源、typed连续槽完整加权论证和真实先验，不再另登记一个三半定理。

模型为显式CNF，每clause至少两个不同**occurrence identities**，重复变量/文字仍有不同query/root。每occurrence非负二进制有理b_e，每变量每极性的**全部eligible** b总和分别≤1。原finite表恰是：f_v在正负A池各时间一；j_e在自身R_e时间一、在自身literal A池时间b_e；s_c在本clause各R_e时间一。无其他端、guard、preload或供给见证。机器2N+L、jobsN+L+M、finite entries2N+3L；N=L=0另加idle机、零jobs，合法clause域迫M=0。

全部构造都输出一份共同actual：每clause选一原occurrence，s_c去其root，恰该原query导出自己的pool，其他query留自己的root；f去自己的一个pool。root≤1，f所在pool的query-only≤1/2、总≤3/2，另一pool≤1。没有SAT或OPT输入，没有删零jobs。零导出在pool以0执行，未选零query仍在root以1执行。算法槽不进入这个physical矩阵。

这个模型与[直接共居异权合同](../证明/直接共居的严格身份与异权三半共同调度--证明.md)不同：没有q/b/u环、Ci内真query与clause job共居，亦无其证明中的虚拟机。旧模型的strict-SAT、锐性、时间域或认证均不可转移。先前uniform special case只作为typed已知背景；本批不声称逐字读过其原稿或给未列旧对象补Proof。

# 2. 作者的离散 clause-only 构造

对每变量每极性按b非增排序全部真实occurrences，ties按原identity。两侧首项（各最多一枚）共享一个容量一的special slot；单侧为空就只含另一首项，双空不建。每侧余下项分别配成 `(2,3),(4,5),…`，末尾可为singleton；不同变量或其它项不合并。

clause节点连到包含自己真实occurrence的slots。给c的每个occurrence沿对应边质量1/k_c；clause行和一，slot最多两枚真实occurrences、每项≤1/2，列和≤1。同clause两项落同slot时质量相加，边保存一个实际occurrence witness。Hall整数matching覆盖全部clauses，匹配边固定选择其一个真实witness；每slot只用一次且每occurrence只属一个clause，无query重复。

同变量至多一侧首项被选。把f放到首项未选的一侧；空侧也适合，两侧首项均未选就固定任选。该侧剩余每配对槽至多选一项，query load≤`w_2+w_4+…≤(Σw)/2≤1/2`；另一侧的选中项是完整eligible子集，≤1。把selector和同一个chosen query按第1节恢复，原root恰一枚unit job，所有pool界同时成立。unused变量直接执行f；空formula仅f；全空idle峰零。

此图只match clauses，至多L条distinct clause-slot边，边含真实witness；分数1/k只是可行性证书，实际固定顺序整数matching不必存这些质量。排序/输入验证可用精确有理比较和求和；公共分母的位长是输入分母位长之和，不按数值扩点。这是作者3330B Proof的完整实现机制。

# 3. typed 先行连续槽：不同的真正加权证明

typed只读新Exact后冻结10209B重构，使用左侧clauses和全部原f。每occurrence在原pool给clause长度x_e=1/k_c≤1/2、排序权b_e；每f在两pool各给长度1/2、排序权一。因为b_e≤1，f在weight-one ties之前，始终先占 `[0,1/2]`。全部项按权铺成连续区间，再切单位槽，只有正长度重叠才有边。边权为重叠长度，clause边保原occurrence witness，同一分数图的左右质量给覆盖全部clauses和f的整数matching。

若f占某pool首槽，matched clause只能在ell≥2。该pool排序第j枚query右端为 `1/2+Q_j`，`Q_j=Σ_(r≤j)x_r≤j/2`；正重叠迫 `1/2+Q_j>ell−1`，故j≥2ell−2。每later slot的真实chosen query权≤w_(2ell−2)，求和给even-rank和≤全部预算一半。这项排名/严格端点与fractional endpoint位长证明已自足展开于[连续槽证明](../证明/异权文字池的连续槽排名与共同调度--证明.md)，不能用“标准matching”四字跳过异权付款。

该proof由一个global matching同时决定f和clause选择；不是各变量先独立选择f目的地，再拼互不相容的方案。它与作者离散图达同一完整actual保证，但图的边、slots与可能输出不要求逐项相同。不声称连续槽每个matching都能按未证明的双射变成离散图同一matching；“不同而等价”在来源中的用途是同一合同可被两套构造证明。

# 4. 另一独立审者的 all-original-job 图与精确消去

已完成的9,125B Exact-first（c759…）在未读作者Proof、typed记录或canonical前，从同一Exact独立构造：左侧是**全部原jobs**。每pool的首槽含 `{f_v,q_1}`，空表则仅f；后槽依次为 `{q_2,q_3},{q_4,q_5},…`，偶数d时末尾q_d单独。另为每个原R_e给一root slot。

f邻两pool首槽，query邻自己的root slot与唯一pool slot，selector邻自己clause的各root slots。存在质量证书：f两边各半、query两边各半、selector每occurrence边1/k_c。每左job和一；pool首槽≤1/2+1/2、其他pool槽至多两query各半、root槽为1/2+1/k_c≤1。Hall给覆盖所有原jobs的整数matching，固定identity的BFS实现不需计算分数证书。

先把匹配槽解释成原root/pool。若selector选中R_e，则j_e不能占该root，只能在pool。对每个**未选root**的query，即使matching先将它送pool，也全部移回自己的空root；只有该occurrence所属clause的selector才有资格去这个root，而它已经选了别处，所以回根合法且不会撞其他job。回根只减少pool query load。于是最终恰每clause一query导出，所有其他queries回根，所有jobs仍执行一次。

含f的pool首槽不容q1；后槽最大query权为even-rank和，≤1/2。其他pool负载≤完整预算一。全部图的左侧N+L+M、pool slots≤2N+L/2、root slotsL、边恰2N+3L，最多N+L+M次整数增广；排序、回根和位成本均显式多项式。

这里与作者clause-only离散图可明确消去：两个pool首槽总容量二，f占一个，故两侧q1至多有一个能export，消去f目的地后正是共享special slot；selector选root等于同identity query export，其他query可回根，消去这些原job节点后留下clause的occurrence-slot选择。反过来，作者图选好clause后，f用未占首项一侧，chosen queries占相应pool slots，其余query回root、selector占chosen root，就扩成一个覆盖全部原jobs的离散matching。两侧q1都未选时f可任选，不意味着唯一匹配或输出相同。

这个明确的离散消去关系不替代typed的连续重叠排名证明。三份来源不是同一个算法换名，也不是三次程序实验。
