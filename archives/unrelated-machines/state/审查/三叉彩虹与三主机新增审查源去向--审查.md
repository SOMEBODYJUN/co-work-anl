# 2. 三叉彩虹源的独有补充与去向

源对象是显式完整等深三叉树，叶色允许重复；二叉 rainbow witness 要求根连通、每个活动内部节点选两个原 child、深度不变且见证叶色单射。源重申了原 v1 的 3SAT 编译链：`Rigid/Dead/AND/OR/Pad` 及 fresh guard/color 分配，变量 false occurrence 与 clause selected literal 的唯一颜色碰撞，平衡 AND 把高度控制在 `O(log s)`，显式展开规模保持多项式。它还细化了原 private-tree 调度矩阵：root pin、内部 edge 的 `1/3` 对 `1`、叶 edge 的 color resource 端，YES ≤ `4/3`、无 rainbow 时 OPT = `5/3`，故该窄合同只有 `5/4` 比值。

当前源相对于既有《三叉彩虹二叉子树三源精读与原 P 边界》的新增承重信息是：

* v1 读后核对 `pin` 为单端；“每 job 两资格”的旧措辞必须改为“至多两资格”，不改变证明；`Dead` 只在高度至少一的调用合法；`Pad` 只提升到共同高度，不造成递归不终止。
* v2 低重数构造分别给出全树颜色重数 ≤2 的可行性与 ≤3 的 NP-complete 归约。所有原色和辅助色均计数；`Dead` 的三叶、`protected` guard、`OR` 的共享 guard 以及一次性逻辑子式使用不能被省略。结论是精确门槛 2/3，仍只导出 `4/3` 对 `5/3` 的窄调度比值，不是一般 UM near-two hardness。
* palette tensor v2 的障碍只适用于末层每个父节点至多两种颜色、tuple-equality 和保叶色对齐 Cartesian 张量。它保留 `OPT=2-(2/3)^k`、`G_k≤5/4` 且随 `k` 严格下降的受限结论；不能外推到改色、非对齐、跨副本一致性或所有 padding。

因此本源内容并入上述三份既有审查正文：v1 证明边界回到原 P 审查；重数门槛回到《三叉彩虹困难与树 Markov 联合审查》；palette tensor 版本和边界回到《三叉palette张量v2三源精读与放大障碍边界》。本页保存新源的版本差异和出处，不新造同义定理节点。

# 3. 三主机选择器源的承重结论与精确范围

三主机合同为：两份完整 YES 分配分别支持开放 `{a}` 与 `{b,c}`，关闭外接机有不可迁移预载 `T`，基础任务有限端不随状态改变。源重核了源权闭包：取两份调度按第一份源机处理时间的矩阵 `w_uv`，把固定 `b,c` 置为二色，其他节点只从零翻一；阈值闭包保证每个节点同色内部行权至少为其第一份基础行和的一半。包含 `a` 的色类 `W` 内，任务分成第二份进入子集和保留的跨出行权，得到每台机器 ≤ `T+T/2`；`W` 外保持第一份基础任务并加入相应预载。由此至少一侧 `{b}` 或 `{c}` 有完整合法分配，makespan ≤ `3T/2`。`T=0`、空任务、零处理时间、单端资格、多于两条有限边和非默认 host 编号均在量词内；两项任务 `a:T/2,b:T` 与 `a:T/2,c:T` 给 `3T/2` 锐例。

源另给出 Santa Claus 半值的直接行列证明和四-copy/K4 配置重构：删去零值或闲置特殊物品，普通物品正值来源只取两份 YES 中的正 recipient；三枚特殊物品用三组 perfect matching 使支持度 ≤2，再用 degree-two 配置舍入得到某一单侧全员 ≥1/2。该段是一个自足的有限非负加性合同，不能被当作调度矩阵的同一权方向；源明确没有在三-host 程序中运行 Santa 实例，也没有把 CCK 机制的近似 pricing 前提带入。

源还记录了有限证据边界：规范三-host 审计使用精确 `Fraction`，7000 个随机双 YES 实例和 1,391,178 个完整分配；另一独立原矩阵审计枚举 45,760 个矩阵、534,595 个分配、22,952 个双 YES 和 798 个锐例。Santa 段另有 23,248 个单正度穷举与随机样例，但这仍是有限回归，不替代闭包证明或 Santa 一般算法。

这些内容并入《三维匹配需求地板与三主机选择器双源审查》：三主机部分只补充独立 K4/Santa 角色划分、矩阵方向和审计计数；不把 Santa 半值或有限代码升级为一般 `UM-TARGET-v1` 结论。三维匹配需求地板对象本批未重新认领，保持其独立身份。
