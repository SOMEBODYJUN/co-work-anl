# 2. 原机器、原 jobs 和全部变量

Q 有非空有限 groups，每组有非空有限 indexed states。每个列出 incidence `e=(g,s,u)` 的系数 `p_e≥0` 为二进制有理数，每 state 的全部列出系数和恰一。所有零 incidence、重复 indexed states、未选 states、unused resources 都保留；不同索引不因向量相同而合并。

P(Q) 对每 state s 建一台独立 private root，对每原 resource u 建资源机器，二者以及各 roots 均物理不同。每 group **一枚** unit selector 可以去该组全部 roots。每 incidence **一枚**原 job，只能去本 state private（时间 p_e）或原 resource u（时间一）；其他端为无穷。零 private 时间仍是有限端，零 job 仍必须执行一次。没有先加 inactive-home、exports≤activation、逻辑 guard 或隐藏资格。

原 finite-endpoint 变量总数为 N。记 selector 去 s 的端为 `a_s`，incidence 的 private/resource 端为 `D_e,E_e`。两者都是原变量，不先删除 D_e。原 job identity 是 `D_e+E_e−1=0`，原 group selector identity 是 `H_g=Σ_(s∈g)a_s−1=0`。记 `epsilon=2−T∈(0,1]`。

# 3. S3 的全部付款和 canonical 目标

L 是全部 total-degree≤4 原变量多项式上的同一线性 functional，完整有限有理表作为输入，`L(1)=1`。它满足所有原变量 x 的 Boolean identities

`L((x²−x)m)=0`，`deg m≤2`，

以及每原 job 的 cover identity 乘 `deg m≤3` 的全部 monomials 后等于零。由线性性，可用预算内任意有符号多项式作等式乘子。

Raw literal 是 x 或 1−x。以下每条原 affine row h，乘任意长度≤3 的 raw literal product B（包括空乘积、重复和互补 literals）均要求 `L(hB)≥0`：

| 原行 | 具体内容 |
|---|---|
| boxes | 每原变量 `x≥0,1−x≥0` |
| physical | 每实际机器 `T−Σ_(j finite at i)p_(i,j)x_(j,i)≥0` |
| unit cap | 每原 resource `1−Σ_(e:u(e)=u)E_e≥0`，包含所有零 private 系数 job 的 heads |

这就是本桥使用的 S3；它不要求 PSD、CONFIG lists、配置权重矩或全局真实 law。`1−ΣE` 与同机的物理 `T−ΣE` 是两条不同的行，不能只拿后者充当前者。

置 canonical primitives

`A_s=a_s`，`Z_e=a_(s(e))E_e`，

并对每 canonical degree≤2 f 定义 `F(f)=L(f(a,aE))`。最高原次数四，故全表已给。所谓同点是保原 L 的所有被用 entries，**并非**把 `F(Z_e)` 认作 `L(E_e)`。

完整目标 plain common primitive-SA1 要求：`F1=1`；每 primitive V 的 `F(V²−V)=0`；每组 `Σ_sA_s−1=0` 及其乘任意 primitive/补的等式成立。下列每行均乘 `W∈{1,V,1−V}`，V 可为任意 group/state 的任意 primitive，F 值非负：

`A_s,1−A_s,Z_e,1−Z_e,A_s−Z_e`；

`1−Σ_(e:u(e)=u)Z_e`；

`Σ_(e∈s)p_eZ_e−epsilon A_s`。

零系数 claims 仍有 boxes、gate 与 resource 行，只在 quality 中系数为零。目标不含 M1 PSD，除非另加第7节的同点假设。

# 4. 四次正性工具、Boolean 和组等式

任意长度≤4 raw cylinder 的 L 非负：非空时取一个 literal 作其原 box row，剩余≤3 literals 作该 row 的乘子；空乘积用 L1。这里没有从 quartic PSD 猜测 literal 正性。

canonical W 的 pullback 是正系数 cylinders 之和，每项≤2 literals：

| W | pullback |
|---|---|
| 1 | 1 |
| A_t 或 1−A_t | a_t 或 1−a_t |
| Z_f | a_(s(f))E_f |
| 1−Z_f | `(1−a_(s(f)))+a_(s(f))(1−E_f)` |

所以 boxes、`1−Z_e` 和 gate `a_s(1−E_e)` 乘任意 W，每项至多四 literals，全部非负。包括重复或共享变量，均沿用同一 Boolean 表。

A 的 Boolean 性直接来自原 identity。Z 的 Boolean 性由普通多项式恒等式

`(aE)²−aE=(a²−a)E²+a(E²−E)`

给出；Boolean multipliers 次数分别为二、一，合法。组等式乘 W 的 pullback degree≤2，由原 selector cover 的 degree≤3 预算给零。若另显式列同组不同 A pair 为零，可用 H_g 乘 A_t、Boolean 性和各 pair cylinder 非负，逐项推出；不必给原 LP 加新假设。

# 5. Resource 与 quality 的全部共同 lifts

对每原资源 u，令 `r_u=1−ΣE_e`，其中求和遍历该资源全部原 incidences。精确恒等式为

`1−Σ a_(s(e))E_e = r_u + Σ(1−a_(s(e)))E_e`。

乘 W 后，r_u 项使用 cap1 原行及 W 的≤2 literal 正展开；补项是两个额外 literals 乘 W，至多四 literals。故每 resource 的空、primitive、补乘子均通过。unused resource 的空和也通过。这里若只用 `T−ΣE`，会多出无法凭本式删除的 T−1；cap1 是明确付款，不是由分数物理 slack 免费取整。

固定 state s，原 private slack 是

`h_s=T−a_s−Σ_(e∈s)p_eD_e`。

令 `q_s=Σp_ea_sE_e−epsilon a_s`。利用 `Σp_e=1` 和 `T+epsilon=2`，可写出**精确**多项式恒等式

`q_s−a_sh_s=(a_s²−a_s)+Σp_ea_s(D_e+E_e−1)`。

这解释作者 Proof 的模 identities 同余式，而不是把 incidence exports 偷设成 selected。乘 W 后，右侧 Boolean 项的乘子 degree≤2；cover 项的 `a_sW` degree≤3，均由原等式付清。因此

`F((Σp_eZ_e−epsilon A_s)W)=L(h_sa_s phi(W))≥0`。

最后一步将 W 作正展开，`a_s phi(W)` 每项至多三个 raw literals，恰由原 physical h_s 的 S3 lifts 支付。特别地 W=Z_f 需要 `h_sa_sa_(s(f))E_f`；W=1−Z_f 分成 `h_sa_s(1−a_(s(f)))` 与 `h_sa_sa_(s(f))(1−E_f)`。最高总次数四；没有第五次未知条目。所有不同 groups 的条件使用同一个 L，不能拼接各自可行的条件点。

| 证明义务 | 最大实际预算 |
|---|---|
| canonical degree2 entries | raw degree4 |
| cylinder boxes/gates | 4 literals = box+3 |
| resource 原 cap1 项 | 原行+2 literals |
| resource 补项 | 4 literals |
| quality 非负 | physical 原行+3 literals |
| quality cover replacement | 原等式乘 degree3 |
| quality Boolean defect | 原等式乘 degree2 |

零 p_e、L(a_s)=0、T=1、inactive exports、重复索引均在同式内；从未除 p_e、epsilon 或 marginal，也未丢原 jobs。故上述步骤确实覆盖目标完整二阶表和所有指定 rows，而非只一阶可行性。

# 6. 实际必要性、固定 LP 和位长

任何完整实际 schedule 若 makespan≤T，其原 finite assignments 为 Boolean、job cover 精确，所有 physical slack 与 boxes 非负。resource 上 eligible jobs 都耗一，T<2 强迫最多一 job，因此 cap1 也逐点非负，即使其 private 时间为零。每 literal product 在真实 assignment 上是0或1；该 assignment 的 Dirac degree-four 表满足全部 S3。故**精确 LP 不可行**是实际 threshold-T 不可行的 sound FAIL。它不是数值超时或未找到整数 schedule；也不声称 S3 可行即实际可行。

全部 moments 可用 `binom(N+4,4)=O((N+1)^4)` 个变量；Boolean/cover multipliers 的数量固定多项式。原不等式行数 `R=2N+#machines+#resources`，每行有 `O((N+1)^3)` 个 literal multipliers。至多三个 literals 展开最多八项，原行是输入长度内的线性式；系数来自输入 p、T 和多项式大小整数运算，位长多项式。

完整表的重复幂可由 Boolean identities 全消去：任何总 degree≤4 的 x²m 使用 `deg m≤2`，反复约化即可。对 square-free monomial M、degree≤4，box lifts 给 `0≤L(M)≤1`：非负取一个变量作 box；上界由 `(1−x)M'` 得 `L(xM')≤L(M')`，逐次归到 L1。约化 feasible polytope 因而有界；非空时可取 vertex。选线性独立活跃行、逐行清分母后，维数与整数系数 bitlength 均多项式，Cramer/Hadamard 给 vertex 分子分母多项式位长。因此普通 rational LP 算法能求有理点或判不可行。这是数学算法规格，两主源没有交付实现。

给定完整有理 L，canonical primitives 数 O(N)，一/二阶输出 O(N²) entries，每项直接查指定 raw degree≤4 monomial（重复幂按一致表示），或作固定次数展开。输出总位长和计算时间对显式 Q 与该给定点总位长多项式；没有按概率倒数、epsilon倒数或隐式状态数循环。

# 7. 可选 PSD、强弱合同和不能推出的事

若**同一个**原 L 另满足 M2，即对所有 raw degree≤2 p 有 `L(p²)≥0`，则每 canonical affine q 的 pullback degree≤2，所以

`F(q²)=L(q(a,aE)²)≥0`。

这给同点 canonical M1。plain R 的证明不靠该 PSD；S3 自身不自动 PSD，可选假设也不自动付清 S3 literal rows。有限有理证书保持不等于 exact SDP finder，更不等于“任意实 PSD feasible 都有有理 witness”。

raw K2、S3 不应被误写成未经限定的包含关系：本 S3 不要求 K2 的 M2/CONFIG；K2 的 raw affine localizers、逐机完整 CONFIG law 也不给全部 global literal lifts。要在一个现有 K2 点上应用本桥，必须对**该同一点**额外核完整 S3。第14节的 source-S3 亦可独立作 LP，不必先持有 K2。

实际 threshold-T schedule 确实给一个 S3 Dirac 点（第6节）；但知道某实例有实际 schedule，不能据此声称手上另一份给定 K2 functional 已满足 S3。这里存在点与指定点不可互换。18机17job参数族或14机13job前身的程序都不成为本桥的运行；本桥不证明层数最小/每条 source row 必要、不输出真实共同 law、不舍入一般全组菜单、不解决一般 UM 的常数近似、actual-gap 或 hardness。全球新颖性未认证。
