# 完整对象与精确结论

取整数 $t\ge1,n=2^t$。组 $g$ 和每组全部indexed states $\ell$ 遍历 $\mathbb F_2^t$；真实资源为 $(a,b)\in\mathbb F_2^t\times\mathbb F_2^t$，每个原状态

\[
S_{g,\ell}=\{(a,b):b_i+g_i a_i=\ell_i\ \forall i\}
\]

恰含n枚不同资源，各private权为普通有理数 $1/n$。坐标可用 $(a_i,b_i)\leftrightarrow2a_i+b_i$ 编为四符号，但相同资源不能因多个incidences而变成多个私有物品。

固定非空blocks partition $I_1,\ldots,I_s$，$b_j=|I_j|\ge1$、$\sum b_j=t$。逻辑admissibility要求存在**全family共同**的任意函数

\[
F_j:\mathbb F_2^{b_j}\to\mathbb F_2^{b_j},\qquad
\ell(g)|_{I_j}=F_j(g|_{I_j}).
\]

F可非线性、常数、非单射和有重复输出，唯一禁止的是读取block外坐标；同一个F也不能随外部坐标重选。组遍历完整tuple，领取的 $B_g\subseteq S_{g,\ell(g)}$ 可为任意形状、资源可闲置，但跨组不交。优化全部这些函数及partial subsets所得值为Q。置

\[
H=\prod_{j=1}^s(2^{b_j}-1/2),\qquad m=\lfloor H\rfloor.
\]

原六源共同证明

\[
Q=\frac m n,\qquad
\left|\bigcup_g S_{g,\ell(g)}\right|\le nH,
\tag{1}
\]

union上界可达到，且一个共同整数分配给每组恰m枚原资源。不能把分数H当不可分资源数，也不能先在各block取floor后再乘。

| 边界或参数条件 | 准确结论 |
| --- | --- |
| 一个block | $Q=1-2^{-t}$，恢复无约束二元菜单值。 |
| 全singleton blocks | $Q=\lfloor(3/2)^t\rfloor/2^t$，恢复逐坐标域。 |
| 所有 $b_j\le L$，整数 $L\ge1$ | $Q\le(1-2^{-L-1})^{\lceil t/L\rceil}$；固定L时该逻辑域的值指数衰减。 |
| 任意partition | $0\le H/n-Q<2^{-t}$。 |
| t=1 | 唯一partition给Q=1/2；t=0不在域。 |

# 两份证明的相同主干与独有论证

## 任意非线性F的单block上界

在大小b的block记 $h=2^b$，把h个组按互补对 $x,x+\mathbf1$ 配成 $h/2$ 对。任意F下两支持各h项、恰交一点：相减方程唯一给 $a=F(x)+F(x+\mathbf1)$，然后b坐标唯一。这完全不依赖F线性或可逆。

作者Proof第2节用multiplicity charge：资源u的owner数记M(u)，同时占它的互补对数c(u)因配对是matching而不超过 $\lfloor M(u)/2\rfloor\le M(u)-1$（对已用资源）。每对恰交一点，故 $\sum c(u)=h/2$；重复incidence损失至少h/2，得union至多 $h^2-h/2$。

rainbow独立稿第2节给更直接的同一上界：每对的union恰 $2h-1$，全union至多这些pair-unions之和，即 $(h/2)(2h-1)=h^2-h/2$。跨pair交点只会缩小它。两种证明的内容都保留；数学一致不等于可以删掉其中独有的计数方式。

全局union精确factor为各block的selected union之积，因为所有block-group witnesses可拼成同一个全组，且F不依赖block外输入。这才得到式(1)的 $nH$，不是要求最终partial bundles为product。总资源数 $nm\le nH$ 只给整数上界，达界另需全部Hall子集。

## 同时整数化而非逐block取整

每个block选择循环shift（singleton是identity）。固定a，两个组资源碰撞的差满足沿block循环的 $\delta_{\operatorname{next}(i)}=a_i\delta_i$。若block的a不全1，存在零坐标沿环迫全部差为0；全1时恰两个常差向量。因此全局资源的非空fiber大小为 $2^{z(a)}$，其中z是a全1的blocks数。

每枚使用资源均分给所有owners；每资源容量恰1，每组质量

\[
\sum_a2^{-z(a)}=\prod_j[(2^{b_j}-1)+1/2]=H.
\]

总分数质量又等于union大小，所以该cyclic-block family达到union上界 $nH$。对任意组集合A，分数证书给 $|N(A)|\ge H|A|\ge m|A|$，故复制m槽后所有槽子集满足Hall；等价地，源到组容量m、组到资源容量1、资源到汇容量1的**一个共同整数流**实现每组m项。分数只是证明证书，不是最终执行；一般 lemma也覆盖m=0的空分配。主应用不需要枚举任何非线性F。

有界block衰减来自归一化因子 $1-2^{-b_j-1}\le c=1-2^{-L-1}\in(0,1)$ 和 $s\ge\lceil t/L\rceil$，所以 $Q\le H/n\le c^s\le c^{\lceil t/L\rceil}$；floor误差直接由 $0\le H-m<1$ 给出。两处不等号方向均有实质条件。

# 固定无环链：两种分数证据与准确反例域

另固定 $\ell_1(g)=0,\ell_i(g)=g_{i-1}$（$i\ge2$），只优化partial领取，记值 $Q_{\rm chain}$。它不是在全部无环函数中优化。

对固定a，所选线性映射矩阵为下双对角矩阵：对角a、次对角全1。t≥2时取第2至t行、第1至t−1列的minor，矩阵上三角且对角全1，rank至少t−1；全det为 $\prod_i a_i$。所以a全1时rank t，其余rank t−1。t=1直接给rank1或0，结论一致。好层有n个资源、各一owner，其余n−1层各n/2个资源、各二owners，故

\[
\left|\bigcup_gS_{g,\ell(g)}\right|=\frac{n(n+1)}2,
\quad \min_g|B_g|\le\left\lfloor\frac{n+1}2\right\rfloor=\frac n2.
\]

达到的两个证明证书不同：

| 原证明 | 分数边量与整数化 |
| --- | --- |
| 作者Proof第5节 | 每资源均分给其一或二owners，每组质量 $1+(n-1)/2=(n+1)/2$，取floor后整数Hall给n/2项。 |
| rainbow独立稿第6节 | 每条selected incidence都给1/2，每组恰n/2，因资源至多二owners而容量不超过1，直接整数流给n/2项。独占资源留有分数余量无妨。 |

所以 $Q_{\rm chain}=1/2$。不同分数行和不是数学冲突；两证书都落实同一不可分整数配额。

依赖图仅 $1\to2\to\cdots\to t$，无自依赖、无环，每输出至多读取一个其它输入。因此只要求无环或单输入依赖的更大选择域至少允许值1/2，不能推出其最优值趋0。本Claim没有证明全部acyclic函数最优恰1/2。链若跨partition边界就不符合block-fiber；固定小blocks的衰减与链逃逸没有矛盾。

# 全部普通任务与两处不同的范围修订

完整P有每state一private、每真实资源一resource、每组一件selector1；每个incidence独立原job仅能在自己的private用1/n或资源用1，其余无穷，全部未选状态jobs均保留。给定任意不交B，只导出所选状态中B的jobs，其余全部留private，selected负载 $2-|B_g|/n$、unselected 1、resource至多1。任意完整峰C<2的调度按selector真实目的地提取实际exports，仍不交，未选状态额外exports只占资源；因此非空选态域的受限实际值为 $2-V_{\mathcal L}$。

原P没有物理block守卫，仍允许全局循环，使普通

\[
\operatorname{OPT}(P_t)=1+2^{-t},
\]

不能把逻辑限制的 $2-Q$ 当其无约束OPT。原证明也自足给普通下界：任意补组的所选支持恰交一点，峰C<2时那两件distinct incidence不能同时外送，至少一件与selector留private而负载至少 $1+1/n$；C≥2分支平凡。chain配额给的3/2是该固定family的合法完整调度，不取代更好的全局cycle。

本历史链有两种范围澄清，必须分开：

1. **非二元YES lifting的typing。** Exact第5节及Proof第6节说“任意其它base菜单”的逐坐标full-support YES见证能提升。对具有对应二元group/state字母表的base，这一机械提升正确：逐坐标选态属于每个partition，两个tuple在某坐标base组不同，其该坐标full supports不交，积支持遂不交。对任意非二元base，写定的 $F_j:\mathbb F_2^{b_j}\to\mathbb F_2^{b_j}$ 无法直接表达它，必须**另改函数定义域和值域为相应字母表的幂**。rainbow先行稿第8节指出此非fatal旁注，作者读后明确尚未读未来canonical修订，首次canonical scope才实际确认第6节已加这一typing并明示固定二元base本身没有full-support YES。该修复不扩大主二元配额定理，也不提供源归约、保degree或NO decoder。原Exact/Proof字节不改。
2. **共同值桥的非空选择域。** 初次scope所读canonical为16914字节、SHA `b859a872faf453265f3a4d0b99439df104ae7fac4af1dca92ca969e39f6e8b30`，其typing已修。之后第1节通用句“对任意选择域”另加“非空”，最终为16920字节、SHA `11dbb5c50317fada96a89d8cedd7ca1cdeeb13b8e5acc5f51c158902bf129e4f`。这是最大值及受限最优有定义的必要前提；具体block域本来非空（例如常零函数），故Q和chain数值不变。本批对同一已全文读取最终源复核唯一新短语及逆替换hash，见[核对记录](../../tools/evidence/binary-block-fiber-history/canonical-nonempty-replacement-check.json)。不把逆替换生成字节冒称另取的旧canonical原件。

这两项不是同一次修订：非二元typing在b859 scope已消解，非空域在11db final note另确认。不能把final非空字样倒填为旧句原有，也不能把旧作者旁注误作新的非二元定理或主配额fatal。

# 规模、证据与关系判断

完整P有n组、$n^2$ private、$n^2$ resources、$n^3$ incidences及n selectors；有限资格 $2n^3+n^2$，dense $2n^2(n^3+n)$。每资源在每组全部菜单中恰出现一次（标签唯一由 $\ell=b+g\odot a$ 决定），所以跨组degree是n，并非degree3。所选图只有 $n^2$ 邻边；可用整数容量流或至多 $n^2$ 槽、$n^3$ 槽邻边。精确

\[
H=\frac{\prod_j(2^{b_j+1}-1)}{2^s}
\]

的分子/分母位长 $O(t+s)$，m≤n，全部标签及1/n位长O(t)。复杂度按完整显式输入计，不是poly(t)输出 $n^3$ 原任务，也不需枚举全部非线性F或按更大隐藏分母复制。

本六源不附软件实现、有限运行日志或外部审稿；独立证明没有用有限枚举代替一般论证，本批也未新增数学扫描。验证仅原字节/size/SHA、最终非空短语修订范围、Markdown及receipt形状。主结论由补组计数、线性fiber和所有Hall子集承担。

六源均按 `integrated` 接回已有数学正文，新页保留独有证明与两个范围修订；没有将六源计成六个新定理。关系判断是：单block是裸二元族特化，singleton blocks是逐坐标配额特化，固定chain是对更弱依赖约束的反例；上界、分数证据和共同整数化联合给式(1)，来源/读后/scope另作内部证据支持。qary affine和near-full虽共用矩阵，函数域与证明义务不同，不能合并认证。本次未改第三阶段图或其他已交付正文。

未完成义务仍是实际普通矩阵中的coherence机制、YES保留与对任意partial exports的源NO decoder；这里没有它们，也没有一般UM算法、near2困难性、所有tensor失败或六人共同目录纯SPE结论。
