# 对象与精确槽收费

同源48行探索桌面的common_capacity部分，考虑普通UM中**同一个已选**big分配H，各机器big实际负载hᵢ，剩余tiny任务的一个共同分数指派x，每任务列和1、每坐标0≤xᵢⱼ≤1。big与tiny任务身份不重叠，tiny有正分数的原端有限；通常tiny上界来自外部接口，本公式本身只需非负时间。

每行按p₁≥…≥p_q≥0固定排序，Xⱼ=Σ_(ℓ≤j)x_ℓ、X₀=0，从位置0铺标准单位槽，只有**正交长**才连任务槽边。完整行包络E是每槽最大相邻加工时间之和，空行E=0。前j件的区间正好覆盖[0,Xⱼ)，所以它们接触的槽恰前ceil Xⱼ个，整数前缀不会额外连零长槽。按非负大小差分收费得
\[
E(x)=\sum_{j=1}^q p_j(\lceil X_j\rceil-\lceil X_{j-1}\rceil)
=p_q\lceil X_q\rceil+\sum_{j<q}(p_j-p_{j+1})\lceil X_j\rceil.
\]
排序平局的大小差为零，零质量/零时间也适用；这里必须用ceil而非floor。该包络是一个充分行上界，不宣称等于这个给定全局槽图的最佳覆盖匹配实际负载。

# 整数前缀共同证书

若能共同选出H、上述共同x和每行整数zⱼ≥Xⱼ，满足所有机器
\[
h_i+p_qz_q+\sum_{j<q}(p_j-p_{j+1})z_j\le(2-\varepsilon)T,
\]
则整数性给zⱼ≥ceil Xⱼ，故hᵢ+E(xᵢ)不超过预算。全部tiny列和1与槽容量1给一个共同分数匹配；Hall保证一次全局覆盖匹配。每槽所配任务大小不超过该槽最大值，所以**同一个**完整tiny安排在全部机器上同时满足实际负载≤E，再加原H给目标界。不能每机各选一个局部安排后拼接。

真实T-YES调度提供证书存在性：取其中big原分配H，tiny取0/1边际，z取真实前缀任务数，则E就是实际tiny负载，总预算≤T。若目标(2−ε)T≥T，该真实安排满足目标预算；这不是寻找H/x/z的算法，也不要求单侧稳定。给定一般有理证书，排序、精确前缀/ceil、槽图和覆盖匹配按显式总位长多项式。

# 为什么实数松弛没有保住槽损失

所有差分系数非负。若把z改成实数并只留zⱼ≥Xⱼ，最小预算取z=X而成为
\[
p_qX_q+\sum_{j<q}(p_j-p_{j+1})X_j=\sum_jp_jx_j.
\]
这恰抹掉整数前缀槽损失。故整数profile选择、与big状态相容的tiny共同流及共同purification不能写成一个未经证明的普通flow/TU。profile精确种类可指数多，尚无统一误差下的多项式压缩/提取定理；“固定profile能做流”不交付profile搜索。
