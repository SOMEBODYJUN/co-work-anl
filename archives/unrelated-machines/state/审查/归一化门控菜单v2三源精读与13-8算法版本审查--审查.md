# 2. v2 Exact 的完整普通 gated 矩阵合同

## 2.1 输入域与 P_gate

`exact_v2.md` 定义非空有限组集 (G)、有限资源集 (U)、(n=|G|)、(m=|U|)。每组有非空显式 indexed states；state (s) 的资源系数 (p_{gsu}in\mathbb Q_{ge0}) 二进制显式且总和为 1。允许零 incidence、重复 indexed states、unused resources 和任意菜单大小；未列系数作零，所有原 jobs 仍保留。

组在 allocation 中取得不交资源 bundle (B_g)，组价值为

\[
v_g(B)=\max_s\sum_{u\in B\cap U_{gs}}p_{gsu}.
\]

(W^*) 是所有真实不交 allocation 的最大福利；(eta^*) 是有限 witness 中“组比例与最小组价值”的最大平衡值。算法和输入都不提供 OPT、(eta^*)、最佳 bundle 或 source YES。

P_gate 有根 (R)、每组 gate (X_g)、每 state private (M_{gs})、每资源 (Q_u) 四类互异机器。jobs 恰为：root pin (J_0)（仅 (R)，时间 1）；connector (C_g)（(R) 时间 (1/n)、(X_g) 时间 1）；selector (T_g)（(X_g) 与该组全部 (M_{gs}) 时间 1）；incidence (I_{gsu})（(M_{gs}) 时间 (p_{gsu})、(Q_u) 时间 1）。全部未选 state、零 incidence、unused 资源和原 job 身份保留。

## 2.2 Exact GATE-IDENTITY

Exact 声称

\[
\operatorname{OPT}(P_{gate})=2-\beta^*\in[1,2].
\]

正向：给 (eta^*) witness，选中组的 connector 放 gate、selector 放 attaining private state，所领正 incidence 导出资源机，未选 states 和全部其他 jobs 留 private，得到峰值至多 (2-eta^*)。

反向：给任意 (C<2) 的完整实际调度，读取真正到 gate 的组 (H)；根负载给 (|H|/n\ge2-C)，selector 不能与 gate connector 同机，因此选中 state 的导出真实 bundle 质量至少 (2-C)。资源机在 (C<2) 时至多接一枚 unit incidence，导出 bundles 全局不交。(C\ge2) 时由 (eta^*\ge0) 给平凡端点。P_gate 完整任务身份和 (J_0) 是该双向等式的必要前提，不能删掉未选 state jobs 或把隐式配置当实际调度。

# 3. 福利 LP、条件期望和未知 OPT 算法

## 3.1 显式有理 LP

对每 state 设 (z_{gs}\ge0)，对正 incidence 设 (x_{gsu}\ge0)，约束

\[
\sum_s z_{gs}=1,
\qquad 0\le x_{gsu}\le z_{gs},
\qquad \sum_{g,s}x_{gsu}\le1,
\]

最大化

\[
L=\sum_{g,s,u}p_{gsu}x_{gsu}.
\]

LP 变量 (S+I_+)、等式 (n)、链接约束 (I_+)、资源容量 (m)，全部位长多项式；(W^*\le L\le n)。

## 3.2 两阶段完全有理去随机化

概念分布先按 (z_{gs}) 独立选每组 state，再以 (x_{gsu}/z_{gs}) 独立提议正 incidence 资源；每个资源只给提议者中原系数最大的组，平局固定组号。对每个资源的 tail level (t)，组 (g) 的提议概率为

\[
q_{gu}(t)=\sum_{s:p_{gsu}\ge t}x_{gsu},
\]

资源容量给 (sum_gq_{gu}(t)\le1)。独立性只跨组使用，故

\[
\mathbb E[\max_gX_{gu}]
\ge (1-1/e)\sum_gq_{gu}(t)
\]

并经有限 tail 求和得到期望福利 (A\ge(1-1/e)L>(5/8)L)（在 (L>0) 时）。

确定性化两阶段都只比较有理数：

1. 逐组固定 state，候选 state 的条件期望按 (z) 加权平均恢复当前期望；取最大者不降。不同资源共享同一 state 的相关性不破坏“总目标是资源贡献之和、每个资源乘积只跨组”的公式。
2. 固定 states 后，逐项固定选中 state 的 incidence coin。若 coin 概率为 (	heta)，当前期望是 ((1-	heta)E_0+	heta E_1)，取较大分支不降；(	heta=0,1) 不做 0/0。未选 states 的物理 incidence jobs 仍在最终执行阶段保留。

全部原 (p)、LP 分数和有限 levels 的分母可取一个多项式位长公共分母；每次条件期望直接从原表重算，避免重复平方递推。算法不比较无理 (e)，也不调用通用 exact SDP 或未知 OPT oracle。

## 3.3 平衡化与 13/8

取最终原 allocation 的质量 (r_g)，排序 (r_{(1)}\ge\cdots\ge r_{(n)})，扫描

\[
\widehat\beta=\max_{1\le k\le n}\min(k/n,r_{(k)}).
\]

取前 (k) 个组及其原 bundles；分析上有

\[
W\le n(2\widehat\beta-\widehat\beta^2),
\qquad W^*\ge n(\beta^*)^2.
\]

由福利下界得到

\[
C\le1+\sqrt{1-\frac58(\beta^*)^2}.
\]

Exact/Proof 用

\[
D=\frac{13}{8}(2-\beta)-1=\frac{18-13\beta}{8}
\]

和

\[
D^2-\left(1-\frac58\beta^2\right)
=\frac{209\beta^2-468\beta+260}{64}\ge\frac1{64}>0
\]

（(eta\in[0,1]) 上导数 (418eta-468\le-50)，最小值在 (eta=1)），推出

\[
C\le\frac{13}{8}\operatorname{OPT}(P_{gate}).
\]

本批 `check_ratio.py` 以 Fraction 检查 (eta=0,10/13,1) 的 margin 分别为 (65/16,125/338,1/64)，证明常数代入无算术错误；这不是端到端 scheduler 或 LP solver 运行。

# 4. 独立重构与 Exact 的量词差异

`independent_reconstruction.md` 在尚未读取正式 v2 Exact/Proof 时独立提出几乎同一 LP/福利/平衡化路线，独有价值是先验的自足推导和 13/8 解析比较。它使用

\[
\sum_s\lambda_{gs}\le1
\]

并显式允许 null state；正式 v2 Exact 使用每组等式 (sum_sz_{gs}=1)，不把 null 作为额外 state。因当前 norm1、非空 state 域可选实际 state，独立重构的松 LP 不能直接代替 Exact 的输入合同；其福利推导应作为方法独立复核，不能把两种约束量词混写。

独立稿的 (B=\beta^*) 嵌入 LP、条件 tail、逐组/逐 coin 去随机化和 (W\ge(5/8)nB^2) 逻辑与正式 Proof 相容；它没有证明 `OPT=2−β*` 的全部 jobs 双向回填，也没有读 v2 的 zero incidence、重复 state 或 exact source scope。该来源处置为“独立重构 + 量词差异已登记”，不新建第二个算法对象。

# 5. Author Proof v2 的独有补强与边界

`author_proof_v2.md` 在 Exact 后冻结，完整写出：

- P_gate 四类机器、所有 ordinary jobs、(W^*\le L\le n) 的有理 LP；
- resource claim 概率是 (x)，不是 (z) 或 (p x)；
- 两阶段精确条件期望，特别说明条件化后单资源提议概率可超过 1，不能错误重用初始 tail 下界；
- balanced sorting 的 (b) 与 (h\le nb) 证明；
- OPT=2−β* 双向作业映射；
- 13/8 二次式严格余量及 (L=0)、(eta=0/1)、(n=1)、zero/unused jobs 边界。

作者 Proof 还纠正旧 robust-source 参数：高质量组数 (h_{\ge\delta}<\gamma_{hi}n) 的互补是低质量组数 (>(1-\gamma_{hi})n)，不能把 (gamma_{bad})、(gamma_{hi}) 和低组下界混成一个符号。该纠错只约束 robust-source 归约参数，不给出可靠 YES/NO 编译器或一般 hardness。

Proof 引用了 DNS/Feige 的 XOS 配置舍入背景，但明确不把这些外部机制、常数、条件当作本页新证明；本页自足覆盖 finite explicit menu 的 LP、条件期望和门控回填。已有有限 audit 记录 36 FSLP、72 arbitrary weighted、3 nonbasic coin、12 brute-force 等样例，但本批没有重新运行 canonical implementation，也不把这些计数当作普遍算法认证。
