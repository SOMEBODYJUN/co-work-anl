# 2. Exact v1实际数学与“推广”的限定含义

域为有限H、固定必做A、互异Q/R各k≥2，T/B正有理、T≤B<2T，所有有限内部p_hj∈(B/2,T]、其余∞。不要求同机p相同、树/环或对称，A任意资格数，不含外加预载。指定模式X要全部A∪X在H各一次，其余原边界仍须外部执行；inactive是R，不是所有边界outside的空X。

任何≤B内部调度每机至多一件，真实单件p≤T，所以同一资格matching可strict≤T。两T-aligned且T内inactive不可行，便有双向指定错配；全部aligned给全部k(k−1)错配。给两份actual不承诺inactive也能bitpoly输出inactive或指定mismatch(j,i)，输出全部A；不给actual先matching找它们或报告某aligned不可行。输入k就是实际列出的边界任务数，不能按二进制k隐式生成指数任务。

Exact称推广旧 `UM-PROTECTED-CYCLE-CIRCUIT-CLAUSE-OR-FAILURE-v2` 的索引接口：旧Ci+Rc是某具体矩阵/全公式strict可行，此处是任意单容量辅助内部网络的关系交换，**并未从“推广”推出任意外接公式可行**。它也不同于匿名presence两见证胶合，承重对象是原q_j/b_i具体身份与所有可选索引；没有全局YES/NO源或hardness。

其外封装给每边界一个互异独占O_z:T，A无outside，完成内部模式后边界补集各去O，全部原jobs恰一次。若真实外端共享变量/锁机器，外部负载需另证。中小任务共居、bundles/多尺度、模式相关A或内部外部不可分容量不在该单容量合同，亦未证明这些改变充分产生困难性。
