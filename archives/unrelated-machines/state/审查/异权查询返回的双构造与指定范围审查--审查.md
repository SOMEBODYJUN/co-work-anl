# 2. 精确依赖与局部合同各自承担什么

一般原P为有限内部H、固定辅助A、互异边界Q/R、k≥2、T>0，任意非负有理/∞内部端；每A至少一有限内部端且只能内部，每边界z有互异独占原 \(O_z:T\)，无其它outside/任务/预载。两份完整aligned actual≤T由输入给。输出是同一原P全部N=|A|+2k任务的inactive或**指定**mismatch(j,i)，峰≤3T/2，A始终内部，输出H端只选两输入实际用过端。异权/zero/额外未用大端>T都允许，不对∞算术。

正式依赖读取版本是SHA **fa93beb7acbe8cbc96ce8da05c30e69584bd6c5828bb6e1ab164497150b45b1c** 的 `two_witness_query_separation.md`。这份[同SHA字节](../../tools/evidence/query-count-v3-history/two_witness_query_separation_count_v3_canonical.md)已由前批从当前源恢复，本批再次核字节并全文读取比较。原review正式使用其§1–2的完整实际single-query/不交nonquery支持/zero域及§4位多项式保证；**不用费用、sharpness或§5计数加强**。因此本局部交换是旧定理直接结构推论，不是新分离算法或计数推论。

两query是b_i、q_j，分析初态零端使δ均0；保护对象b_j是单个nonquery，由不交支持至多一份移出。只取“平均费用小”或只知每机器某份低负载，不包含这套任务身份/共同actual合同。所有H及原outside负载必须在**同一份完整assignment**中成立。
