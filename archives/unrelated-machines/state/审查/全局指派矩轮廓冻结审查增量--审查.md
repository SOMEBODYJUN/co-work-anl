# 证明承重与可行域边界

1. **全局同一性。** `X_e`/`A_e` 全部来自同一 `M₂(y)`（或 full-degree `L`）的商 Hilbert 空间；不同 machine、prefix 或 pair 的局部矩不能拼接成一个分配 law。零常数 state 缺陷为零不代表整个 `V₁` 缺陷小。
2. **近平坦常数。** `D_e=A_e-A_e²=B_e^*B_e`、`‖[A_e,A_f]‖≤2√(δ_eδ_f)`；前缀乘积近幂等的误差为 `≤nδ`，最大 HS 分支保持范数，selected loss 给 `≤3δ_e`，再由同一 `ρ=KK^*/‖K‖²_HS` 同时控制所有机器负载。`ρ` 是分析用密度，不是调度分布。
3. **剪枝/强界。** 只有剪枝 `p_e≤T` 才能直接写 `(1+3δ)T`；未剪枝输入要保留 `T/(1-3δ)` 型弱界。`δ=0` 需单独处理，不能用 `2a>a` 覆盖 `a=0`。
4. **实现边界。** 精确 Fraction、Schur/LDL、迹和有理逆足够；没有谱分解、随机实验或未实现 oracle。零任务/`T=0` 由外层边界约定处理；`T=0` 非零大缺陷矩不能被描述为无条件自动通过。
5. **全 HS 失败的逻辑范围。** 真实分布确保反例矩可行；失败来自固定全空间 HS 初始化/次序/平局，不能推出所有 moment rounding、所有 order、rank-one、其他联合矩或一般 `<2` 算法失败。
