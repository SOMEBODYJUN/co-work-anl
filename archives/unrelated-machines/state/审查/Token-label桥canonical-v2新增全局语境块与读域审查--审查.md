# 2. §7.3：aggregate M2 的 Schur 正性与真实标签 M1 非扩展

## 2.1 signed beta 与 aggregate 空间

§7.3 的 `β` 是 signed weights，不是概率或真实 conditional law。两个 full-row laws 只表示 anonymous cardinality-four 行和 Boolean `Y` 行；它们不是一个完整 true joint law，也不是完整原作业 CONFIG+M2。扩大 210 点函数空间后的 Schur 余谱为

对应的三个对称方向数据与既有双 Schur 记录一致；aggregate 67 维 Gram 的 rank 为 55。该正性只说明指定 aggregate functional 的 M2 可同时满足相应 cardinality 约束，不能推出原 token/head 身份已经存在联合 lift。

## 2.2 46 维 labelled M1 rank 的独立检查

§7.3 还给出 46 维原 M1 的 rank 38 解释，本次读域内独立核对如下：40 个 head variables 的真 uniform labelled injection M1 连同常数共 41 维；四条 token-row one-hot 关系使 rank 降为 37。`β` 与 `ν` 的 singleton 都为 `2/5`，所以 `Y` 与各原 head 的 covariance 为零；`Y−δ` 的范数 `δ(1−δ)>0` 再增加一维，最终 rank 为 38。

这解释区分了 aggregate M2 的 67/55 与原 labelled M1 的 46/38：两者指标空间不同，Schur 余谱不能混用。该 rank 计算不替代完整 token-label theorem，也不声称对任意 group 或任意深度的 M1/M2 都成立。

# 3. §7.4–§7.5：Q² 边界与 13 机 ordinary witness

§7.4 的 `Q²=−1/150` 与“保持全部 aggregate≤4 矩的任意 extension 不存在”保留两种证明。它们都只针对所给 signed aggregate point 和指定原身份/共同 M2 合同，不把一个 necessary block 负性升级成完整 SDP 不可行判定或 generic solver。

§7.5 列出一个 13 机、6 job、48 finite ends 的 ordinary unrelated-machines 实例。其完整峰值 1 witness 是：`g` 留在唯一 `r` 端；四个 `f` 分别送到不同 `z`；`y` 送到 `y0`。`g` 强迫 OPT≥1，因此 actual OPT=1。该 ordinary instance 本身有 strong Dirac 点；坏 aggregate point 是矩/标签 lift 的非扩展证据，不是原 native cycle 的 actual gap，也不是 strong-C2 NO。

该区分是 token-label/SH3 true-hardness 语义的关键：聚合矩的不可延拓和原任务调度值是不同对象。不能从 `Q²<0` 直接声称 ordinary matrix 的 near-two hardness；也不能用该 13 机实例替换 SH3 的 source-to-UM reduction。

# 4. §7.6：完整全局 affine-context 容量块 K

## 4.1 变量与完整指标

任一原 token `a` 的 head 类别 `x_{a,i}` 可以是一个原 endpoint，或一组互不交原 endpoints 的和；不可用类别取零，类别不必覆盖 home 或其它端。原 Boolean/one-hot ideal 在 degree four 内使每类幂等、同 token 异类乘积为零。

固定全局 affine context 列表

\[
z_0=1,z_1,\ldots,z_s,
\]

允许 context 含本组某个原 label。任意系数方向令

\[
t_i=\sum_l c_{i,l}z_l,
\qquad S_a=\sum_i x_{a,i}t_i,
\qquad B=\sum_i X_i t_i=\sum_a S_a,
\]

其中 `X_i=Σ_a x_{a,i}` 不要求 Boolean；`S_a`、`B`、`q_a=S_a−B/k` 至多二次。整体矩阵指标必须是 `(i,l)×(j,t)`，而不是任意两个不同 contexts 的单独交叉块。

## 4.2 SOS 恒等与 PSD

原 ideal 给出

\[
\sum_a L(S_a^2)=\sum_i L(X_i t_i^2).
\]

因此定义完整 global context block

\[
K_{(i,l),(j,t)}
=k\,\mathbf 1_{i=j}L(X_i z_lz_t)-L(X_iX_jz_lz_t),
\]

对任意系数方向有

\[
c^\top Kc
=k\sum_aL(S_a^2)-L(B^2)
=k\sum_aL(q_a^2)\ge0.
\]

整个 K 是必要 PSD block；证明只使用 degree four 的原方程和共同原 M2 对 degree-two `q_a` 的真实平方非负性。它不需要第六阶矩、不需要未知 conditional law、不需要 `X_i` Boolean，也不需要 label 对称化。`k=1` 时 `q_1` 恒零，K 由原 ideal 恒为零。

若 contexts 不含个别原 label且置换不变，K 可再按 standard-label 表示块命名；若 contexts 含个别 label，K 仍是正确整体对象，不能把某个异-context cross-block 单独称 PSD。对所给 counterexample，context 基含 `1,Y`、取 `t_i=s_iY`，有

\[
c^\top Kc=-1/25,
\]

四个 `q_a` 的平方期望和为 `−1/100`，乘 `k=4` 对齐该负值。它是给定 aggregate point 的不延拓证书，不是完整 anonymous functional 的充分扩展判据。
