## 一、多小端密度的容量流障碍

处理时间只取 1 或 1/k。对每个任务 j，small 端集合为 S_j，大小 d_j；Q 是没有 small 端的 unit 任务，R 是其余任务。每台机器 i 的 small incidence 数为 t_i，柔性数 b_i 是其中 d_j 至少2的个数。假设 t_i <= k，并逐机满足 b_i >= gamma t_i。若 Q 能被容量1二分匹配完整覆盖，给每个 R 任务每个 small 端分数 1/d_j，机器 i 的分数负载为 rho_i。

容量取 ceil(rho_i) 的二分流具有整数满流，故每个 R 任务选一个实际 small 端。由于 d_j=1 的贡献为1，d_j>=2 的贡献至多1/2，

rho_i <= t_i - b_i/2 <= (1-gamma/2)k。

与 Q 的容量1匹配叠加，输出完整调度峰值不超过

1 + max_i ceil(rho_i)/k <= 2 - floor(gamma k/2)/k。

若 Q 没有容量1匹配，任何峰值严格小于2的调度都只能在每台机器放至多一个 Q 任务，反推出完整 Q 匹配，矛盾，故 OPT >=2。Q 为空时去掉前导1，但不自动给相对 OPT 比率。

这个结论要求柔性密度逐机成立；全局平均密度不足以推出它。d_j=1 只说明 small 端没有跨机器选择，任务仍可能有 unit 端。D 端推广为 d_j>=D 时，rho_i <= [1-gamma(1-1/D)]k，得到更强的固定密度上界；例如三端小任务满密度时绝对峰值约4/3。

因此若某近二归约的 YES 峰值至多1、NO 要求超过固定 rho<2，而所有输出属于该单尺度和固定 gamma 结构，先做 Q 匹配，成功时容量流给出低于 rho 的调度，失败时直接判 NO；该类编译不能支撑任意接近2的 soundness。逃逸路线需要 gamma 趋零、多尺度处理时间或把一致性放进联合 unit/medium 容量。这是结构性排除，不是一般复杂度下界。

## 二、单位读出校准槽与固定密度次二算法

### 1. 分数任务数证书和给定证书舍入

单位读出双树中每变量有两棵私有树，内部 edge 和 leaf port 的小端时间为1/k，另一端在对应 unit 机器上为1。固定整数 r，令 L=k-r+1，C_r=2-r/k。给定每条小任务下传质量 t_e、selector 根质量 y，要求每内部机器的分数任务数满足

sum outgoing t_e >= r-1+y，

每个 clause 的叶下传总量不超过 A_c。第一式保证每行分数任务数不超过 L，第二式是真实 unit 外机容量。

按父端输入质量和小任务质量切长度为1的有序槽；每个小任务至多跨两个相邻槽，不能误用每槽度至多2的半质量论证。clause 端把下传质量切成 unit 槽，并映射到不同真实 unit 机器。所有 job 质量总和恰为1，Hall 匹配一次覆盖全部原 jobs。若 incoming 占用一行首槽，该行至多再收 k-r 个小任务，负载不超过 1+(k-r)/k=C_r；未占 incoming 的行负载至多1，unit 外机至多1。

这是给定有理证书的确定性位多项式算法。证书只给充分条件，通常不是必要条件；弱化第一式会接受实际 OPT 为7/4而目标3/2的反例，强化式也有 OPT=1但证书不可行的反例。

### 2. 深度校准和固定 D 的统一界

令 x_0=1/2，x_l=(r-1+x_(l-1))/k。k>1 时 x_h=a+(1/2-a)/k^h，其中 a=(r-1)/(k-1)。若每个 clause 的实际叶数 d_c 满足 d_c x_h <= A_c，则给出完整实际 C_r 调度。这是显式有理证书，位长随树深和 k 的编码多项式。

固定密度上界 D，若 d_c <= D A_c，对 k>=D 取 r=1+floor((k-1)/(2D))，可得 x_h <=1/D，因此 C <= 2-r/k 且 r/k >1/(4D)。非空实例有 selector，所以 OPT>=1，得到

Cmax <= (2-1/(4D)) OPT。

若 k<D，改做变量到 clause 的容量匹配；成功时沿选中叶路径给出 2-1/k 调度，失败时任何 C<2 调度都会提取同一容量匹配，故 OPT>=2，直接输出峰值2。空变量、k=1、零任务等分支单独处理。

这个固定 D 类算法是统一严格次二结果，但 D 必须固定；D 随目标误差增长时不能直接当作统一算法。它只使用单位读出树结构、唯一 incoming、统一 small 时间和共同 clause unit 资格，不证明一般矩阵能产生该证书，也不关闭已有趋二族。

## 比较、证据和第三阶段接续

第一源独有的是多小端柔性逐机密度、容量流整数化、Q 匹配失败时 OPT>=2 以及 D 端推广；第二源独有的是分数任务数证书、校准槽的完整 Hall 舍入、深度递推和固定 clause density D 的次二算法。两源共同说明：近二归约若把小任务大量放在多端或固定密度单位树上，会被实际整数流或槽匹配直接恢复。

有限审计、Fraction 匹配和固定实例反例只作证据；一般证明承担公式和量词。后续 mapper 应核对柔性密度是否逐机成立、clause 外机容量是否真实共同、证书是否显式给出、D 是否固定，以及是否把给定证书算法误写成通用 LP/SDP 求解。两源没有客户目录、六提供者历史或均分语义，UM-TARGET-v1 和六人 SPE 覆盖目标仍开放。

两源均按 integrated 处置。
