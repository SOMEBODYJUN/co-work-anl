# 2. 数学对象与承重结论

现有正式对象《单强制根树精确配置间隙--定理.md》承重五源的共同数学内容：

- 机器域只有一棵完整均匀 d 叉树、每个内部节点一台机器、每种叶色一台共享资源机；根有
  单端时间 1 的 pin，树边在父端时间 1/d、子端或颜色资源端时间 1，全部原 jobs 必须安排。
- q 是从根开始、同深同分叉的最大 rainbow 子树。给定 q 见证，把见证边下送、其余边留
  在父端，得到 OPT<=2-q/d；任意 C<2 的真实调度沿 root 递归保留至少 ceil(d(2-C)) 条
  下送边，且 C<2 时每资源机至多承载一个 unit leaf job，故反向给出 q>=ceil(d(2-C))，
  从而 OPT=2-q/d。
- 将每种颜色按整棵树的 occurrence 序号分到实际非空 bucket。每桶内颜色互异；raw-q 的
  并集次可加性给出某桶 q>=ceil(d/mu)，并可用固定桶上的底向上 H-index DP 回溯见证。这是
  对显式输入大小的位多项式构造，不是求一般 rainbow q 的算法，也不按二进制 mu 制造空桶。
- 对 mu>=2、mu|d 的底层 block 族，每个颜色恰出现 mu 次，q=d/mu，所有原 jobs 的
  OPT=2-1/mu；若 mu((d-1)/d)^h<=1，则逐内部节点的 incoming-unit/single-small 与
  all-small 配置分布、颜色资源 singleton/empty 配置给出 Tconf<=1+1/d。T<1+1/d 时 pin
  递归迫每个叶 unit 在颜色资源端边际为1，而重复颜色资源不能在负载小于2的配置中覆盖
  mu>=2 个 unit，故 Tconf=1+1/d。令 d 沿 mu 倍数增长得到 ratio 趋近 2-1/mu；声明是
  supremum，不把有限族写成必然取到。
- mu=1 时全树颜色唯一，q=d，实际调度和 pin 下界共同给 OPT=Tconf=1。

上述内容已按证明、条件结论和范围边界写入定理对象；五源没有互相矛盾的不同量词。作者
附注的 d=1 只作为历史边界保留，不回写正式域。
