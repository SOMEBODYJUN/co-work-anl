# 对象身份与输入域

四源处理一个 working candidate，不倒改冻结 v4 或其审查：有 k 个 outer，每 outer 只有一个 normalized indexed state，正权 homes 全局互异；每个 home 有一个 unit-own helper，helper 其它 states 是 B 上任意显式 normalized fallback；可有额外 leaf groups，但其正支持只在 B。每个 state 的系数和为一，所有 selector、未选 payload、zero incidence、duplicate indexed state 和 unused resource 都保留在完整 ordinary matrix。

k=1 无 home-weight 上界；k>=2 要求最大 home weight nu<=1/(1024k)。固定 epsilon=15/16，leaf 通过 E_l 与 b_l<epsilon 的 threshold-unit-demand 测试。结构呈现随输入给出，不需从任意矩阵识别；候选声称 deterministic total-bit polynomial 19/10 algorithm，仅在该 typed domain 内。

本批 Exact 明确是后续 working 对象，无正式 canonical Claim ID；作者 Proof 未独立审查，read-after 属知情后核验。故本文把数学链分层记录为 restricted candidate，未把“Proof PASS”改写为生产实现、外审或全球新颖性。

# 值桥、叶匹配和 baseline

完整菜单的福利 V 与 ordinary optimum 满足 OPT=2−V：bundle 选择导出 selected positive incidences；反向 C<2 时 resource unit 独占推出 disjoint bundles。若 leaf graph 无完整 matching，实际 V<epsilon，baseline 全部 jobs 留 private、峰 C<=2，因 2<=(19/10)OPT（epsilon=15/16 给 32/17<19/10）即可停止。无 fallback、B 为空、rank zero 和 empty leaf 均属该 baseline 分支。

若 matching 存在，当前 profile 每 helper 选一个 fallback state 或 empty，并在 B 上做完整 leaf matching。将同资源 candidates 视为 matroid parallel copies，固定权重 lambda 的最大 profile payoff 可由普通 matching 精确求取；分析中允许多 options 的 union 仅用于次模性证明，算法枚举的每个 helper 只替换一个原 fallback option。

actual V>=epsilon 时，从真实 allocation 保留每 outer 的 home 质量与叶 E_l 资源，得到一个仅证明存在的共同 profile O。对任意 lambda 有 `f_lambda(O)>=epsilon^2 sum lambda`。该 O 不作为输入，也不要求算法枚举 joint profile。

# reciprocal-gradient 候选算法链

k>=2 时，先在当前固定 profile 的 ownership/leaf-flow network 上以 rational LP 测是否所有 outer welfare W_i>=a=1/4；成功则直接进入整数 leaf circulation 和完整 jobs 恢复。LP 不可行时，作者使用 `phi(x)=x`（x<=a）及 `a+log(1+K(x-a))/K`（x>a），K=32k，势 Phi=sum phi(W_i)，gradient lambda_i=1 或倒数梯度。该 profile LP 分支是 soundness 所需：单靠“某一 profile LP fail”不能推出 actual V<epsilon。

对单 helper option replacement，weighted matroid exchange 给 owner/other outer 的变化：最大坐标 `|lambda_i Delta W_i|<=lambda_owner w_j`，L1 总变化至多 `2 lambda_owner w_j`。nu<=1/(1024k) 与 K=32k 使整段相对曲率步长小于 1/32；积分 Taylor 估计支付二阶项，累计曲率至多 `(1/8) sum lambda_i`。共同 profile O、submodular exchange 与 LP-infeasible inequality 给某个 option 使势增量至少常数 `rho/H`。

算法不调用实数 log：固定 rational Frank–Wolfe 近似 profile Phi，使用有理 gradient 与 finite matching；再以 `log_L` 的正有理截断给 `P−xi <= E <= P`。若无候选使 E 增至少 `tau=1/(64H)`，则 actual V<epsilon；否则接受最大候选。势范围与每轮最小增量给绝对多项式轮数。k=1 单独用标准 submodular greedy，不套 nu 或 reciprocal curvature。

# 19/10 输出与完整 jobs

成功 LP 分支从 fractional leaf-flow 通过整数 circulation 得完整 leaf matching；由 `W_i>19/100` 取 Good helpers 的 home mass，保留原 fallback states，其他 helpers 回 own homes，outer 取 Good homes，leaf 选 attaining state 中提供 epsilon incidence 的原 state。完整回填只导出 selected positive incidences，其他原 jobs 全留 private，故每 job 恰一次，Cmax<=2−1/10=19/10。baseline 也输出所有原 jobs。

read-after 对候选的逐式攻击确认 same-outer helper losses、cross-segment reciprocal curvature、停止条件和 all-jobs restore；终点坏坐标有 h_i=h_max>=64k，给出停止矛盾；k=1 单独满足。它还核了 rational bit accounting、无需 inverse-small-weight loop、无 joint-profile oracle。实际只运行了常数/不等式 Fraction 检查：source hash、182 行稿、D0、最小余量、baseline 等式和 Good-mass 等式；没有运行 NSW greedy/matching/profile search/full scheduler backend。

## 四源角色增量：独立 Exact-first（58de49571a4172661609）

第四源在未读取作者 Proof 前独立重构同一 typed single-state candidate，并给出实际 incidence-set 的 NSW 路线：先用叶匹配定义 dual matroid，再以每个 helper 至多一个 fallback state 的独立集维护真实 bundles；对候选 state 做 weighted matroid greedy，得到 same-outer 损失也计入的 L∞/L1 变化界。其新的分段倒数势在 cap `q=19/100` 两侧连续，沿允许步长给出相对二次余项，停止时把 `nu≤1/(1024k)` 付款到 `19/10`。它同时单独处理 k=1、失败基线 `V≤18/19`、全原 job 回填和有理位复杂度。

这份独立稿与作者 reciprocal-gradient Proof 的 mechanism 不同，不能合并成四次独立证明；69b20 的 informed read-after 又专门攻击独立稿的 same-outer losses、cap crossing、停止和 all-job recovery。四源共同支持的是 working candidate 的 typed 范围与互补的数学核对；没有端到端实现、软件运行或一般 UM 外推。
