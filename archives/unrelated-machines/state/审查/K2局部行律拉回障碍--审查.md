# K2 局部行律与规范拉回障碍

## 输入对象

主证书固定一个 K=2 的局部行律模型，参数为

\[
c=\frac34,\qquad T=\frac74,\qquad \varepsilon=\frac14,
\]

并含 18 台机器、17 个作业、34 条有限端点。它不是一般 unrelated-machines 输入的随机样本，而是为检验“局部行律通过后，把 canonical law 直接拉回全局 M2”这一特定模板构造的有限证书。

证书的全局二阶信息为：canonical pullback basis size 为 7，原始 degree-two square-free monomial 数为 596，7 个全局 M2 正 pivot 为

\[
1,\;\frac{21}{100},\;\frac{63}{320},\;\frac7{40},\;\frac7{256},\;\frac7{288},\;\frac7{384}.
\]

18 个 raw affine localizer 在该 c 上都被记录为 exact positive definite；两个 outer private localizer 还列出各自 4 个正 pivot。最大 row bit dependency 为 2；全部 72 个 local square-free moments 和全部 72 个 local full-membership patterns 均被检查。

## 规范拉回失败与真实调度

尽管局部矩与 M2 pivot 都为正，规范 canonical pullback 的两个记录量为

\[
\text{negative canonical claim-state entry}=-\frac1{160},
\qquad
\text{negative canonical quality-state lift}=-\frac3{640}.
\]

这说明该 canonical pullback 规则在此有限输入上产生负质量/负状态项；它不能作为一个保持非负性的全局构造。这里失败的是**模板**，不是原调度问题：主证书同时列出了 17 个作业的完整 assignment，并给出

\[
C_{\max}=1.
\]

因此该输入实际可行，`actual_schedule_peak=1` 也表明负 canonical entry 不是 OPT>1 的反例。主 JSON 明确写出 `full_matrix_all_assignments_enumerated=false` 和 `global_M3_or_global_literal_nonnegativity_claimed=false`；所以不能把有限 localizer 结果提升为全局 M3 证明，也不能把未穷尽的矩阵当作所有 assignment 的结论。

## 参数回归

参数 JSON 对同一 18 台机器、17 个作业在三个 c 值上保存了统一字段：

| (c) | (T=1+c) | local square-free/full membership 检查 | canonical claim entry | quality-state lift | 实际峰值 |
|---:|---:|---:|---:|---:|---:|
| (1/1000) | (1001/1000) | 72 / 72 | (-1/160) | (-1/160000) | (1) |
| (1/2) | (3/2) | 72 / 72 | (-1/160) | (-1/320) | (1) |
| (999/1000) | (1999/1000) | 72 / 72 | (-1/160) | (-999/160000) | (1) |

这三个点支持源中可见的缩放关系 `quality_state_lift=-c/160`，但它们不是对所有实数 c 的新证明；除非另有符号推导，否则应继续把它记录为三点精确回归/参数证据。所有点均保留同一“局部正、canonical 负、真实峰值 1”的分离。

## 重放和来源比较

root replay-scope 记录了独立代码 SHA `7c2dd68a019f712a9494860b3d3870bc6e6675f7792163d34910cfae0bfe6146`、默认输出 SHA `d1fe9ee0c3841372189a7743443eebf53ba0d3080fc664200d818b4471c02f73`，并说明默认输出与完整 CLI 输出逐字节一致；额外比较只确认摘要字段等于完整输出的投影，摘要 JSON 不能替代完整记录。重放实际读了完整 standalone code、符号证明和独立数学审查，但没有枚举全部 assignment 或全部原始四次恒等式。

这三份来源是一组互补材料：主审计提供 18 行 local law、正 pivot 和真实 assignment；参数 JSON 提供三个 c 的比较；root replay 证明运行和摘要的字节身份。它们不能被当作三份独立的全局证明。

## 真实边界、用途和接续

本对象的准确用途是给后续 CONFIG/M2 研究一个小而精确的模板障碍：局部 row law、若干 M2 正性证书和有限 membership 检查，仍不足以保证特定 canonical pullback 的逐项非负性。它可用于审查新的拉回规则是否错误地假定局部 PSD 自动传到全局；也可与已有 k=2 affine frame、C2/PSD 和配置证书比较，但变量和量词必须逐项对齐。

它不提供一般 M2 反例、一般调度不可行性、近似下界或复杂度结论。后续若要把障碍扩展为数学定理，需要写出对全体 c 或明确参数族的符号推导，并给出 canonical 规则的完整定义；若要证明全局方法仍可行，则需改造拉回或加入额外耦合条件。当前六人 SPE 目标与此对象无直接定义域交集。
