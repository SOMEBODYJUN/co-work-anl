# 反例含义与精确前沿

相关《单层配额超图与两状态行列池有限审查》说明，旧稿的
[
b^*=\min(1/2,s/K)
]
在可裁剪资源的两状态池中错误；(s=K=4) 的本输入选一行和四列的部分资源，15 枚资源各用一次，根比例 (5/8)、标签比例 (3/4)，实际评分 (5/8>1/2)。因此本源是一个明确的有限反例，否定“整束冲突”推导，而不是一个通用调度算法或复杂度反例。

同一相关审查给出修正族
[
h_k=\min\{s,\lfloor s^2/k\rfloor\},\qquad
b^*=\max_{1\le k\le 2s}\min\{k/(2s),h_k/K\},
]
并指出旧式断言在该族中需 (K\ge2s-2) 才成立。这个闭式前沿属于相关正文的构造与上界证明；当前 raw example 只提供 (s=K=4) 的实际树和资源选择。
