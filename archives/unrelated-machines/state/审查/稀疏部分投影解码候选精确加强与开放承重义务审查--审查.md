# 2. 精确加强与锐性

在非负权和为 1、共同 vertex 概率、`ξ` 投影支持及两边逐点 domination 的合同下，令右端在共同支撑 `S_v` 上均匀。若左端投影落入该支撑的概率至少 `τ_e`，先在左端取 argmax，再在右端取最佳响应，得到
\[
\sum_v w_v\,\tau_v/|S_v|\ge \beta/L.
\]
这比未经耦合的 `β²/L` 更强，且算法是明确的两阶段确定过程，不需要新枚举或通用 LP。

边界包括 `τ_0/β_0`、非空支撑和共同 vertex 合同。`q`-shift 的真实单标签最优值为 `1/R`；subset-shift 取 `τ=L/R`、`β/L=1/R`。锐性只对整数 `R≥L≥1`、`β=L/R` 的参数族声明，不能外推到任意实参数组合。

若源 NO 非空，必须有
\[
\gamma\ge1/R,
\qquad \beta/L>\gamma;
\]
不能只说“把 γ 取小”而固定 `R,L,β`。

# 3. 仍开放的调度承重义务

证明无需新枚举、通用 LP 或外部 hardness 定理；标准概率/支撑解码工具也没有被认证为原创，独立加强只改变给定证书的 decoder，不产生调度 gadget。

真正阻止升级的是：从同一真实 UM 输入的任意 `C≤(2−δ)T` 调度，在位多项式时间内产生统一 `μ`、正确 partial projection `ξ`、足够稀疏 `L` 和覆盖 `β`，满足 `β/L>γ`，同时保持源 YES 的完整实际 T 调度。只保 token 总数、逐边各挑分布或直接取 `L=alphabet` 都没有闭合该义务。来源没有声称 ordinary UM hardness、近二结果、generic solver 或 `UM-TARGET-v1` 已完成。

# 4. 处置

处置为 **retained**：保留 `β/L` 精确加强、锐性族和严格阈值作为开放候选的数学内核，明确其与已完成树边界对象的范围分离；不把候选解码器写成已完成调度归约、source NO 编译器、外部同行评审或新颖性认证。
