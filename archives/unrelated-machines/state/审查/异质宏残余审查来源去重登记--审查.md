# 2. 实际数学内容

## 2.1 异质宏/tiny 结构定理

机器分成 home 集合 `H` 与 sink 集合 `Z`，宏任务集 `B`、tiny 任务集 `S`，承重假设为 `|B|=|H|`；宏只在 home 上可用，每条有限宏边满足

\[
T/2 < p_{hb}\le T,
\]

每条有限 tiny 边满足 `p_{ij}≤δT`，其中固定 `0≤δ<1/2`，tiny 资格和端点成本可完全任意。给定承诺 `OPT≤T`，先在宏二分图中找覆盖全部宏的任意完美匹配，再对 tiny 任务求 LST 容量 LP：每个 home 容量统一取 `T/2`，每个 sink 容量取 `T`，保留全部有限 tiny 边；LP 可行后做有序单位槽舍入并把宏放回其匹配 home。

完备性只依赖一个真实 `OPT≤T` 调度 `σ*`。每台 home 至多承载一条严格大于 `T/2` 的宏；因为宏数等于 home 数，`σ*` 强迫宏对 home 是完美匹配。于是 `σ*` 在每个 home 的 tiny 负载严格小于 `T/2`，在 sink 的 tiny 负载不超过 `T`，所以该 tiny 分配本身就是统一容量 LP 的整数见证，而且与算法另选的宏完美匹配无关。ST 后 tiny 负载增加至多支撑边最大值 `δT`；加回任意宏后 home 至多 `(3/2+δ)T`，sink 至多 `(1+δ)T`。这里得到的是结构承诺下的实际调度保证，未得到一般 `R||Cmax` 算法或主目标结论。

## 2.2 未知 OPT 版本及量词边界

若真实 `OPT>0` 时承诺宏边均大于 `OPT/2`、tiny 边均不超过 `δOPT`，审查保留一个分离的单调谓词 `F(t)`：在宏图中保留 `p_{hb}≤t` 的边后有完美匹配，并且 tiny LP 在 home `t/2`、sink `t` 容量下可行。测试时**不**检查 `p_{hb}>t/2`，也**不**删除 `p_{ij}>δt` 的 tiny 边；这些条件只在 `t=OPT` 处由 promise 提供。宏边集合和 LP 容量随 `t` 单调，因此在有限处理时间分母网格上可二分最小接受点 `t*≤OPT`，并用 `O(log(QU+1))` 次测试得到

\[
C_{\max}\le \frac32t^*+\bar\delta\,OPT
      \le (\tfrac32+\bar\delta)OPT.
\]

有限分母乘积 `Q` 与任取合法分配的总时长上界 `U` 只用于说明网格位长多项式；不应枚举大数值分母或把 `t*` 冒充整数最优值。`T=0`、空任务、全零边需要外层精确分支。审查特别指出：统一 half-capacity 的完备性在 `|B|<|H|` 时失效，且宏可去 sink、大 tiny 边、一般宏/tiny 分层和共同容量仍未闭合。

## 2.3 异质 tiny 的整数/分数边界

审查保留强 `3-PARTITION` 型边界：宏完全占满 home，多个 sink 需要填充，item 任务在 home 和 sink 端成本可异质但都不超过 `δT`。精确 makespan `T` 的整数调度等价于把 item 分成规定和的三元组，而均匀 Fraction 残余 LP 仍可行。该障碍说明 tiny 资格与成本异质时不能把 LP 可行性偷换成整数 `T` 可行性；ST 的加性 `δT` 是真实输出误差，不能省略或改写成精确流。它没有认证从任意 `3-PARTITION` 输入到一般调度问题的完整复杂度归约，也没有声称 NP-hardness。
