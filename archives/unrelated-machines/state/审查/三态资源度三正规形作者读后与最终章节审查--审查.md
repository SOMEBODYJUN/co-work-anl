# 1. 审查精确覆盖的合同

输入为显式 normalized-flat 普通 UM：每组非空有限 indexed 菜单，每 state 的 distinct 资源非负有理 private 权和恰 1；每组一件 unit selector，每 incidence 是一件真实任务，在本 state private 端耗时 p，在原资源端耗时 1。允许零项、重复 state、unused 资源，全部未选 state 的任务仍须执行。

每个旧组的 K 个 indexed states 变为满二叉选择树。每顶点是一组、一件 selector；非 root 有独立 own-resource。root 选两个 child-own singleton，非 root internal 可选 own/左/右三个 singleton，非 root leaf 可选 own singleton 或完整旧 state。K=1 时 root 即唯一旧 leaf，没有 own-resource 或 root singleton。

先树后资源 port-path 降度，最终每组至多 3 states、每资源跨全部菜单至多 3 groups。合同是正 partial 阈值双向、任意完整 C<2 实际调度双向，继而精确保 V、OPT 及 V=0、OPT=2 端点。它不保持原组数、原 selector 资格或组交互度 M，不将一般 UM/未归一化 SC 行免费转入此域。

# 2. 作者读后实际补强：保全部旧 incidence 目的地

先行独立证明允许把未选 state 的旧 jobs 合法重排；作者 Proof 给出更强的实际映射：全部旧 incidence 的 private/原资源目的地都不改变，包括未选 states 的 exports 及 p=0 jobs。

给源 C<2 调度，读取旧 selector 所在 leaf，沿 root-to-leaf 路径配置新 selectors。旧 selector 移至 root singleton；终 leaf 的新 selector 以同一 unit 负载替代原 selector。其余旧 private 没有新增 selector。所选新 singleton incidence 外送，未选者留 private；每 own-resource 只被路径 parent 或 off-path 自己之一使用，新机负载至多 1≤C，旧资源负载完全保持。这逐件排出全部旧/新 jobs，不只是给一个 partial bundle。

逆向给任意目标 C<2 调度。selected singleton 若留 private，与 selector 两 unit 成负载 2，故必须实际外送。root 占 child-own 后，child 若也选 own 则再外送一 unit 造成同资源负载 2，故实际选择必继续下降至某个旧 state leaf。将旧 root-selector 移回该 leaf，恰替代将被删除的新 selector；全部旧 incidence 目的地保留。其它旧 private 仅删新增 selector，旧资源也不增负载。

这不预设“只有一条活路径”：off-path leaves 可以额外选择旧 state、未选 singleton 可以额外 export，均只增加真实占用，不能取消 root 迫出的链。每个旧组只取一个 root-chain leaf，不把多 state bundles 合并。

对 positive partial witness 也用同一阻塞链：正值 singleton 必领到 own-resource，后继不能再用 own，故递归到真实原 state；不同旧组提取的原 bundles 仍不交。v=0 时不能直接使用正值阻塞，而由有限达到性及所有正阈值等价推出 V=0 保持。

# 4. 规模及组合的精确校核

令旧组数 n、state 总数 S、incidence 数 I。满二叉树对每 K 贡献 2K−1 顶点；逐菜单计数得

| 中间对象 | 数量 |
|---|---:|
| 组及 selector | 2S−n |
| states/private 机 | 5S−4n |
| own-resources | 2S−2n |
| 新 singleton incidences | 4S−4n |
| 全部 incidences | I+4S−4n |
| 全部 jobs | I+6S−5n |

K=1 给 1 组、1 state、0 新资源和 0 新 incidence，与特判一致。资源降度在全部中间 memberships 上做，包含 own-resource 和零项；先拆 leaf 可能增加旧资源跨组度，所以必须最后降度。path helper 至多两态，不破坏三态上界。

所有新处理时间为 1 或复制原有理数，对象数及 dense 输入规模为总位多项式；不按分母、1/v 或 1/(2−C) 展开。基线全 private 负载≤2，所有 selector 给下界 1；任一侧 OPT=2、另一侧<2 会被反向映射矛盾排除。这是端点证明，不在 C=2 错用资源 unit 独占。
