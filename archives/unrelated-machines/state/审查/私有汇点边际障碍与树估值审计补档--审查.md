# 数学对象和边界

private_sink_marginal_barrier.py 构造真实 OPT=1 的均匀私有汇点族，并在完整 assignments 上重建凸包边际 x。每组 k 个 small 任务在 H_i 或 Z_i 上耗时 1/k；程序以 Fraction 计算 machine load、同 sink pair event 和 expected makespan。它只保留固定边际/同 sink 正事件合同的有限反例与 sharp law；可重选 x、直接输出最优调度或采后重排均不被排除。

private_tree_branching_valuation.py 定义显式 k-ary full tree 的 exact value、demand、minimum-cost subtree、full envelope、minorant separation 和 compact LP data。输入强制完整树、叶地址、injective leaf-resource map 和 exact rational prices。审计还包含 21 个 minimum-cost queries、8 个 compact LP auxiliary certificates、170 个 cost-vs-subtree enumeration、52 个 separation-vs-full-subset OPT 对照和 24 个 signed-price vectors。这是树 XOS/次模估值合同，不是 UM schedule 或 LP solver。

projected_vector_greedy.py 读取显式有限调度分布，选 literal columns，求有理 Gram inverse，再按固定 job order 逐层选择严格最大分数。当前输入为 5 machines、5 jobs、14 atoms、12 维基，最终 assignment [0,1,2,3,1]、loads [1,2,1,1,0]、makespan 2。程序只承诺 supplied finite distribution/fixed order。

pruned_tree_leaf_hitting.py 做显式 full-tree bottom-up extraction，枚举小树全部 pruned masks 和 leaf colorings，核对 recursive predicate、minimum hitting/max free counts、二色 universal monochromatic 条件，并在 64-leaf construction 中保留 bad half matching。独立版本使用另一套 families、supersets table 和 recursive_has，复核 24 parameter cases、569 个 r-subtree leafsets、264328 个 leaf subsets。两份程序都没有实际 UM scheduling 或 hardness。

route_composition_review.py 组合 menu、unit-demand flow、bounded demand 和真矩 affine recovery，枚举 n<=4 的 topological DAG 与 moment/cube candidates，计算为整数/Fraction。它依赖两个未随当前测试源冻结的 helper，故本轮只登记依赖缺口；既有对象中的 exact audit/JSON 是后续复现入口。
