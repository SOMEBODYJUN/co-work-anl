# 2. 宽标签仿射线矩形：共同逃逸与实际峰值

## 2.1 定义域和准确量词

稳定身份为 `UM-TAGGED-AFFINE-LINE-WIDE-RECTANGLE-JOINT-ESCAPE-v2`。取素数 `R>=2`，显式非空 group 集 `G`、每组非空变量集 `X_g`、有限 indexed-state 菜单。每个变量 `x` 有带 tag 的完整资源块 `U_x={x}×F_R^2`；同一变量在各 incidence group 的固定截距 `j_x(g)` 互异。不同变量资源块不相交。

状态 `s` 在每个 `x in X_g` 上给一条完整仿射线
\[
T_{g,s,x}=\{(x,z,a_{g,s}(x)z+j_x(g)):z\in F_R\},
\]
其全状态资源集为各线的不交并，权 `p_(g,s,u)` 非负且总和为 1，包含零权 cells。菜单可有相同 label vector 的多个真实 states；权和 marks 绑定实际 indexed state，不能用另一份同 label 状态替代。

输入还给每个组每变量的非空 label 集 `A_(g,x)`，其 Cartesian 矩形全部出现在菜单中；令 `L=min |A_(g,x)|`、`q=max |X_g|`、`d_x` 为使用变量的 group 数、`D=max d_x`。每条 state-variable line 给显式 marked 子集 `E_(g,s,x)`，大小不超过二进制整数 `b`；每个未标记点权不超过 `beta`。定义
\[
M_g=\sum_{x\in X_g}(d_x-1),\qquad M=\max_g M_g\le q(D-1).
\]

**定理（v2）。** 对每个满足 `L>b(D-1)` 的完整输入，存在确定性按显式输入位长多项式的共同选择：为每组选择一个真实 indexed state `s(g)` 和互不相交的资源子集 `B_g`，包含该 state 的全部 selected marks 以及 selected state 的独占点，并有
\[
p_g(B_g)\ge v:=\max\{0,1-M\beta\}.
\]
在同一完整普通 UM 矩阵上，把 selected `B_g` 的 incidence jobs 导出到对应 resource，其他 jobs 留在 private，所有 selector 执行一次，可得完整不可拆分调度
\[
C_{\max}\le2-v.
\]
这一定理只针对宽 Cartesian 矩形、固定截距和显式 marks/weights 的结构域；不要求 CONFIG、未知 actual YES 或概率分布，也不宣称所有 LST/Chan hard image 都有矩形自由度。

## 2.2 避开旧 marks 的逐组构造

按固定 group 顺序处理。若此前 group 在同一变量 `x` 上留下 marked 点 `(x,z,y)`，新线 `y'=a z+j_x(g)` 至多被禁止一个 slope：`z!=0` 时唯一 slope 为 `(y-j_x(g))/z`；`z=0` 时旧截距与新截距不同，禁止零个。此前 group 数为 `d_x-1`，所以最多禁止 `b(d_x-1)<L` 个 slopes；从 `A_(g,x)` 选一条合法 slope。Cartesian containment 使所得完整 label vector 对应真实 indexed state，之后才读取该实际 state 的权和 marks。

这一步得到新 line 不含旧 marks，因而每组 selected marks 集 `E_g` 两两不交。它没有保证新 marks 不落在旧 unmarked 点上；该冲突按同一 allocation 计入损失。选完 states 后令
\[
Q_g=T_g\setminus\bigcup_{h\ne g}T_h,\qquad B_g=E_g\cup Q_g.
\]
`E_g` 两两不交，`Q_g` 只包含本组独占点，因此 `B_g` 互不相交。固定本组在变量 `x` 上的线与每个其它同变量组的线至多交一点（同斜率平行，异斜率在域上至多一交点）；不同变量的 tags 隔离，所以共享点数至多 `M_g`。每个被本组放弃的共享点只可能是本组 unmarked 点，损失至多 `beta`，故 `p_g(B_g)>=1-M_g beta`。

这解释了为什么不能先分别找“重资源”与“细资源”两套 allocation 再相加：marks 和线交点必须在一个共同整数选择内处理；对同一个 indexed state 的完整 weight/marks 也不能被同 label 的其它 state 偷换。

## 2.3 编译为实际 UM 调度和边界

每个 indexed state 有一台 private machine；每个 tagged resource 有一台 resource machine；每组一个 selector，在该组任意 state private 上耗时 1；每个 state-resource incidence job 只能在自身 private 上耗 `p`，或在相应 resource 上耗时 1，其余端不可用。所有 selectors、未选 states 的 jobs、零权 jobs 都必须执行。

把 selector 放在 selected private；selected state 的 `B_g` incidence 导出到 resource；其余 incidence 留 private。每个 resource 至多接一个 unit job；未选 private 负载恰为 1；selected private 负载为 `2-p_g(B_g)<=2-v`。因此峰值 `2-v`，v=0 时也覆盖最宽松端点，v=1 时峰值/OPT 均为 1。复杂度按显式展开规模计：矩形 containment 先数 distinct label vectors，不能把 `R^2` 个资源压缩成只按 `log R` 收费；禁 slope、真实 state 查表、Q/B 构造和完整 assignment 输出均按输入总位长多项式。

两个可复用推论需保留边界：若每条 line 的正点都标记（`b` 足够、`beta=0`），在同一严格矩形条件下可得每组质量 1、峰值 1；若 `D>1` 且 `L>2q(D-1)^2`，标记所有 `p>1/(2q(D-1))` 的点可得质量至少 1/2、峰值至多 3/2。`M=0`（每个变量只在一个 group 出现）时资源块完全分离，任意状态均可取，OPT=1，不应除以 `D-1`。

严格不等式不能无条件改成非严格不等式。`R=2` 的两 singleton-state groups、截距 0/1 和 slopes 0/1 的边界例在 `L=b(D-1)` 时只有一个共同 marked 点，无法同时领取，实际峰值为 2。该例只证明门槛的必要边界；不声称全参数锐。

# 3. 前缀原子证书：查询式确定性解码

## 3.1 精确桥和等价量词

稳定身份为 `UM-PREFIX-ATOMIC-DECODING-v1`。给定合法 UM 实例和有理阈值 `T>=0`，每个任务 `j` 的有限端集合为 `E_j`。对每个相容部分分配前缀 `S`，定义 `m_S=prod_(e in S)x_e`，假设有理查询器 `Eval(S)=pi(S)` 满足：`pi(empty)=1`；所有前缀值非负；若任务 j 尚未出现在 S，则
\[
\pi(S)=\sum_{e\in E_j}\pi(S\cup\{e\});
\]
且每个完整合法分配 `sigma` 满足对每台机器
\[
(T-load_i(sigma))\pi(sigma)\ge0.
\]
查询运行时间与输出位长按输入总位长和前缀长度多项式有界。

**解码定理。** 从空前缀按固定任务顺序处理 j；查询全部孩子 `w_e=pi(S union {e})`，由守恒且 `pi(S)>0` 至少有一个正值，选任意正端并加入 S。至多查询 `|E|` 个前缀，最终得到 `pi(sigma)>0`；局部化不等式给出所有机器负载不超过 T。因此在该接口内，存在前缀证书当且仅当 `OPT(P)<=T`：正向取任一 T-可行调度的 Dirac law，反向由贪心解码。

平方正性不是解码本身所需；它只在 `pi(S)` 来自全阶矩时提供概率语义。前缀值甚至允许带符号，只要每步总和仍使一个正子项可选且最终原子局部化成立；正文的正式合同仍取非负值。

## 3.2 与全阶矩、复杂度和有限核验的关系

若有 degree `2n+1` 的全阶泛函 `L`，令 `pi(S)=L(m_S)`，Boolean/one-hot ideal 给守恒，平方正性给非负，degree-n 机器局部化器在完整原子处给出负载约束。该桥相对“全阶矩存在”新增的是可查询的压缩访问接口和 O(|E|) 解码；它不提供从 `(P,T)` 生成该接口的算法。若生成器在所有 `OPT<=T` 输入上返回查询器，在其余输入上给可靠 `FAIL => OPT>T`，才可把它变成阈值可行性判定；现有单位半选择 NP 完全族说明该生成义务不能免费假设。

冻结 Fraction 审计核验了两机两任务 Dirac/均匀可行 law、T=0 零端、两机三件单位任务 T=1 的 8 个完整原子全部被局部化排除，以及 5 个异质 Dirac 例。有限运行只核验公式和边界，不验证任意实例的 succinct oracle，也不建立 `UM-TARGET-v1`。

## 3.3 有限精度扩展及误差边界

同一 source 另立 `UM-PREFIX-ATOMIC-FINITE-PRECISION-v1`。固定任务顺序，令每项有限端数为 `d_j`，`D_k=prod_(j<=k)d_j`，`N=D_n` 为全部完整分配数。查询返回 `hat pi_a(S)`，误差绝对值不超过有理 `a`，查询时间和输出位长按 `log(1/a)` 计费。逐层选择近似最大 child 后，输出叶质量满足锐界
\[
\pi(\sigma)\ge b(a,N)=\max\{0,(1-2a(N-1))/N\}.
\]
若各层精度为 `a_k`，则更细的界为
\[
N\pi(\sigma)\ge1-2\sum_k a_k(D_k-D_{k-1}).
\]
该界由每步“其它孩子至多比所选真质量大 2a”并乘以 `D_k` 望远镜得到；给定平局规则存在达到它的叶质量分布，故截断界是最坏情形锐的。

若完整原子只满足绝对局部化残差
\[
(T-L_i(\sigma))\pi(\sigma)\ge-\tau_i,
\]
正叶只能保证
\[
L_i(\sigma)\le T+N\tau_i/(1-2a(N-1)).
\]
`N` 因子不能一般删去；均匀 law 可把每个原子质量稀释到 `1/N`，而所有原子都在同一机器超载。相对残差 `>=-Delta_i pi(sigma)` 则直接给 `L_i<=T+Delta_i`，但这是假设加强，不是从绝对残差免费获得。

令 `Q` 为全部有限处理时间和 T 的约分分母乘积，`Q(L_i-T)` 为整数。取 `a=1/(4N)`、`tau_i<=1/(4QN)`，由网格性可把小于 `1/Q` 的正超载排除，恢复精确 T 调度。这里 `N` 和 `Q` 可能数值指数，却只需多项式二进制位；算法不能按 `N` 或 `1/a` 数值循环，必须按其编码长度计时。低阶 Gram 矩只有在函数评价矩阵满行秩时才等价于逐原子容量；缺少满行秩不能推出原子界。

## 3.4 范围和开放义务

前缀桥是条件表示/解码接口，不是统一 `(2-epsilon)` 算法。若阈值换为 B，只能解码 B-可行调度；仍需生成器和失败语义。`infinity` 端不进 `E_j`，空任务、零端、T=0 和大分母都由同一守恒/局部化公式处理。有限精度扩展改善的是访问和位复杂度说明，不提供一般查询器、验证器或低阶矩压缩。

# 4. 两源关系、第三阶段边和逐源处置

仿射源和前缀源都最终输出实际调度，但承诺完全不同：仿射源直接读取显式矩形/截距/marks/权，靠有限域线交计数构造共同不交资源；前缀源只在已有共同前缀 law 查询器上贪心。可记录以下两条有条件关系：

1. `宽 Cartesian 标签矩形 -> 逐组避旧 marks -> 共享点损失 M beta -> 实际峰值 2-v`；
2. `可查询非负前缀 law + one-hot 守恒 + 原子局部化 -> 正叶贪心 -> T-可行调度`。

两者的开放义务不能互换：矩形输入没有给前缀概率 law，前缀 oracle 也没有给矩形状态自由度。二者都没有一般 OPT oracle、统一近二算法、NP-hardness 或六人 SPE 结论；当前 `UM-TARGET-v1` 仍 OPEN。

**一般/条件结论：** 仿射 v2 在 `L>b(D-1)` 的结构域内给出完整共同构造和峰值 `2-v`；前缀桥在明确查询合同内给出确定性 O(|E|) 解码，有限精度扩展给出精确质量/残差/网格界。

**有限证据：** 前缀审计的 Dirac、均匀、T=0、全原子排除和异质例，以及有限精度独立检查；仿射源没有当前软件/有限实验认证，历史 notes 只支持作者读后和 scope 过程。
