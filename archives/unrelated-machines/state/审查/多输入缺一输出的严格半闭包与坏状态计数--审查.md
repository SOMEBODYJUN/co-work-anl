# 精确状态与原有结论的区别

源暂定ID为 `UM-MULTIINPUT-MISSING-ONE-COUNT-CANDIDATE-v1`，仍是未进入current的候选。固定同一个普通UM基础矩阵：有限机器、不可拆分基础任务，非负二进制有理时间及不可用端∞；每个基础任务有有限端。输入机器集合A、输出集合B互不相交，r=|A|≥2、D=|B|≥2，内部机器和额外资格任意。阈值为有理T≥0。**关闭**机器是在该机器添加一件唯一端、耗时T的实际任务；不删除基础资格。不同状态拥有不同的关闭任务，基础任务完全不变。

输入必须已经给出两份逐任务完整实际见证：Sₒ在A全开/B全关时峰≤T，S𝚌在A全关/B全开时峰≤T。对每个bᵢ，目标状态关闭全部A和恰好bᵢ，其余输出开放，真实整数最优值记νᵢ。待保留结论是
\[
|\{i:\nu_i>3T/2\}|\le r.
\]
并能从两见证确定性输出至少max(0,D−r)个不同目标状态及其各自完整实际≤3T/2分配，不输入νᵢ。D≤r时不保证某状态≤3T/2；每个状态总可沿S𝚌再关闭bᵢ做到≤2T。

旧[单输入加权扇出](零缺陷与加权扇出边界双源审查--审查.md)及其完整原文有r=1的至多一个坏状态/两两预算νᵤ+νᵥ≤3T。此多输入稿扩展坏状态**计数**，不据此声称任意两输出仍满足那个单输入预算；也没有新认领单输入结果。

# 目标端权、零任务与最小闭包

T=0时沿S𝚌保留所有基础任务，加零关闭任务即可给每个目标完整零峰值，无需除法。以下T>0，除以T归一为1，记μ=S𝚌、λ=Sₒ的基础任务分配。

令J₀={j:μ(j)∈A}。μ的A已有unit关闭任务，故J₀在各自所选μ端的真实时间为零。始终逐件保留这些任务在μ；它们在其他资格上可能为正，不能全局删除。其余J*=J\J₀的μ原点在H=M\A。置
\[
w_{uv}=\sum_{j\in J^*:\mu(j)=u,\lambda(j)=v}p_{vj}
\qquad(u\in H,v\in M).
\]
这是**接收端**时间，不能换成μ端时间。每列和≤λ在该机的基础负载≤1；B在λ中已有unit关闭任务，故B列总和为零。即使某些J₀在λ上为正，省去其分析权只减少列和，实际任务仍保留。

分别从每个种子Qᵢ={bᵢ}增长**最小**闭包：当v∈H尚未入集且w(Qᵢ,v)>1/2，才将v加入，A从不加入。每轮只用此前集合，最终对H\Qᵢ有w(Qᵢ,v)≤1/2。

所有Qᵢ两两不交。若在同步轮次首次相交，交点不能是其他输出种子，因为B列为零。若同一非种子点先后在两闭包加入，其两份加入前驱都包含于首次相交前一轮各自集合；这两个集合不交，各贡献严格大于1/2，合计超过列预算1，矛盾。故不同加入时刻也不漏掉。正自环不会使尚未加入的点自发增长；结论不适用于任意人为加点的closed集合。

严格 `>1/2` 承重：两个种子各向同一新点送恰半量时，若改成 `≥1/2`，两个闭包会吸入同一点。目标“坏”也准确用νᵢ严格大于3T/2，而非大于等于。

# 输入列计数与同一份完整回填

令cₐᵢ=w(Qᵢ,a)。闭包不交给Σᵢcₐᵢ≤1，每个a至多使一个索引cₐᵢ>1/2。故至多r个索引对某个输入超半。对其余好索引i定义同一个完整分配：J₀留μ，J*中μ原点在Qᵢ的全部改到各自λ端，其余留μ；再加入目标的r+1件关闭任务。逐机如下：

| 机器类 | 同一分配的完整负载 |
|---|---|
| Qᵢ内非种子 | 只接λ在该机任务的子集，≤1 |
| 种子bᵢ | λ在B的基础负载0，再加unit，恰1 |
| H\Qᵢ | 原μ基础负载≤1，新增实际λ工作w(Qᵢ,v)≤1/2，无目标关闭任务 |
| a∈A | J₀的μ工作0，新增cₐᵢ≤1/2，再加unit，≤3/2 |

每件原任务恰在μ或λ的一条原有限端执行一次。这里是最终静态调度，不承诺逐件搬迁过程中峰值不增。构造排除集合只是“不获此构造保证”的索引，未必都是真正νᵢ>3/2；真正坏状态包含于这个至多r的集合，所以计数成立。

闭包每点至多吸入一次，D次闭包、稀疏权累计、每个输出逐任务回填均按显式两见证总位长多项式。只需A、B及两见证用过的活跃机器，未用机器负载零；没有按巨大空机器编号、分母数值、未知OPT或配置oracle枚举。除以正T、精确半比较及有理子和位长均为输入总位长多项式。

# 两项不同的锐性

T>0，t=min(r,D)。给t件wire任务，jᵢ仅在aᵢ、bᵢ两端耗T；两strict见证分别全在A、全在B。i≤t时目标的两个wire端都已关闭，νᵢ=2T；i>t时沿全B见证避开无工作bᵢ，νᵢ=T。因此恰min(r,D)个状态坏，r计数可达到；D≤r确可全部坏。

D>r时，取有D叶的任意满二叉树，根为一个输入，叶为输出，其余树点为内部机器。每条父子边任务在父耗T/2、在子耗T。全父与全子是两strict见证。缺一叶时从全子只将该叶入边退回父，峰3T/2；若严格小于3T/2，已关闭根不能收任何T/2，迫所有边向下，沿树把unit推到已关闭叶而达2T，矛盾。添加r−1个无基础工作的输入只加各自关闭T，故全部目标恰3T/2，保证系数不能统一降低。这复用旧单输入树例，不是新树定理。
