# 2. 完整普通原矩与真实 OPT

参数为正偶数 `d,s`，`2≤s≤d/2`，令 `eta=s/d`、`h=s/2`。机器是 `u,v,z_1,…,z_d`，共 `d+2` 台；原 job `R` 在 `u,v` 两端均为 1，每枚 `j` 在 `v` 为 `1/d`、在自己的 `z_j` 为 1。记 `C` 为 `R` 在 `v` 的指示，`Y_j` 为 job `j` 留在 `v` 的指示，`H=sum_j Y_j`。负载为

\[
load_u=1-C,\quad load_v=C+H/d,\quad load_{z_j}=1-Y_j.
\]

所有 jobs 留在 home 即给完整峰值 1 的调度，所以实际 `OPT=1`。这点必须与后面的伪矩/row-CONFIG 障碍分开：来源没有构造 actual near-two instance。

# 3. 同一真实七态 law 与逐行 CONFIG law 的分层

来源给出真实 assignment law：七个 `(C,H)` 类别的概率为

\[
p=\eta^3/1000,\quad 1/20,\quad1/20,\quad1/20,\quad1/20,\quad u_0=4p(1-\eta),\quad e=1-1/5-p-u_0,
\]

分别对应 `(1,d),(1,0),(1,h),(0,0),(0,h),(0,d/2),(0,d)`，每个给定 `H` 的 home 集均匀选择。`e>0.79`，因此 law 合法且所有 assignments 都完整。

为匹配 `v` 行的 first/pair，来源另给一个合法 row CONFIG law：把 bad `(1,d)` 质量 `p` 重新分配为 active `H=s` 的 `p/eta`、active `H=0` 的 `1/20+p-p/eta`，并把 inactive `H=d/2` 的 `u_0` 拆到 `H=0` 与 `H=d` 各 `u_0/2`。active/inactive 两行的 `H` 范围仍合法；二阶损失 `p d(d-s)` 与 half-home 转为 0/d 的增量 `u_0d^2/4` 相等。均匀子集于是保证原 `Y_j`、`Y_jY_k`、`CY_j` 的 first/pair 全部相同。

该分层是本源关键：真实全局 assignment law 与逐行 CONFIG law 共享必要矩，却不是把各行配置拼成另一份全局 law。`u` 和各 `z_j` 只有一个可见原 job，可直接取真实边际。由此得到一个真实共同 M3、完整 Boolean/one-hot 和 row first/pair 合同，同时真实 law 含概率 `p>0` 的 v 负载二坏样本；这只说明局部化接口允许该伪点，不能说明实际调度峰值大于 1。

# 4. 所有 global quadratic localizers 的对称化与插值

任意原 endpoint 都是 `C,Y` 的仿射式，故 global degree≤2 多项式 `q` 是这些坐标的二次式。对 home-job 标签置换平均，记对称化为 `bar q`。每个正状态的 `v` slack 为正常常数，Jensen 给 `E(q²|C,H)≥bar q(C,H)²`；坏 `(1,d)` 状态的 `Y` 全一，对称化不改变 `q` 值。因此只需处理

\[
\bar q(C,H)=P(H)+C(a+bH),\qquad \deg P\le2.
\]

令 `lambda=d/h=2/eta`、`q_a(x)=bar q(1,x)`、`q_i(x)=bar q(0,x)`。来源给出精确五点插值恒等式

\[
q_a(d)=\lambda q_a(h)+(1-\lambda)q_a(0)+q_i(d)-\lambda q_i(h)-(1-\lambda)q_i(0).
\]

五个正点系数平方和为 `4lambda²−4lambda+3≤16/eta²`。每个对应正状态质量乘 slack 至少 `eta/40`，而坏项上界

\[
p(1-\eta)16/\eta^2\le 16\eta/1000<\eta/40.
\]

故对所有 global degree≤2 `q`，`E[(T-load_v)q²]≥0`；其他行 slack 逐点非负。该证明是固定单行的 dimension-free coercivity：它不依赖 `d` 的多项式枚举，也不改变原矩的实际 assignment 合法性。

# 5. 可接线合同、固定次数方向与真实缺口

来源进一步写出一个可接线但受限的合同：固定外部背景、一个 incoming job `R` 的上游/v 开关和 `v` 上各自不同的 unit 导出位置，且这些 positions 未被背景占用，全部 assignment indicators 对 `C,Y` 仿射；此时上述对称化和全局 quadratic localizer 可逐背景成立，再对背景积分。

该合同不能直接用于 growing-depth：把 jobs 导到内部孩子会在孩子上新增 unit arrivals，incoming `R` 回原 home 也会收费父行。来源只给 fixed degree `D` 的插值方向：使用至多 `D` 个 active home-count nodes，使 active-minus-inactive 成为次数≤`D−1` 的 `H` 多项式，Lagrange 系数为 `O_D(eta^{-D+1})`，负质量可取 `c_D eta^{2D-1}`。节点分离、全部常数和跨深度预算未给出完整证明，必须标为未成熟方向。

来源还说明均匀 H-subset 的固定阶矩是 `(H)_t/(d)_t`，因此固定次数共同矩可用有理算术多项式时间计算；短参数描述不等于指数支持枚举或未知优化 oracle。已有 finite code/消息级核对不能替代 growing-depth 的跨行收费证明。

# 6. 与已有七态对象的去重与用途

与《七态星全局二次审计与 root 重放边界》相比，本源独有的是解析的五点插值 coercivity、同一真实 law 与 row-CONFIG first/pair 的构造及固定次数扩展方向；有限 audit 只覆盖列明参数的 Fraction PSD/秩/assignment 字段，不认证任意 `d,s` 或深层接线。与 affine owner boundary 和 faithful-AND localizer 审查相邻但不同：它们分别研究仿射 owner 分类与高次数 AND 负 localizer，本源研究单行 slack 的正性和 CONFIG trade。

可接续内容是：在任何多层构造中逐行检查 incoming job、child unit arrivals、不同物理机器和完整 original jobs；只有满足上述“固定背景+未占用 unit positions+仿射 assignment”合同时，才可引用该 coercivity。不能把 `OPT=1` 的原星、真实坏质量 `p` 或有限 PSD 通过改写为近二 gap、一般 UM hardness、全局 schedule algorithm 或六人 SPE 结论。
