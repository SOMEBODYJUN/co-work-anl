# 2. A：任意状态选择的乘积并集与 Hall 保留

输入是整数 (d,Q\ge1)、有限变量集 (X)、非空组集 (G)。每组 (g) 有非空 distinct-variable 集 (X_g) 和非空显式 indexed states (A_g)；每变量至多参加 (d) 组，且 incidence index (j_x:G(x)\hookrightarrow[d]) 为单射。变量资源带 tag，(U_x=\{x\}\times[d]^{[Q]}) 互不合并；state 只取每个变量的一个坐标切片。

固定任意 state 选择 (s(g)) 和任意子族 (F\subseteq G)。在单个变量 gadget 中，令 (r_x=|F\cap G(x)|\le d)，每个 label 的计数为 (t_i)，(sum_i t_i=r_x)。单射 index 保证同一坐标的禁值互异，故补集大小精确为

\[
\prod_{i=1}^Q(d-t_i),
\]

并集为 (d^Q(1-\prod_i(1-t_i/d)))。Bernoulli 与几何前缀平均给出

\[
\frac{d(1-z^{r_x})}{r_x}\ge1-z^d,
\qquad z=1-1/d,
\]

因此

\[
\left|\bigcup_{g\in F}S_{g,s(g)}\right|
\ge c_d\sum_{g\in F}k_g,
\qquad c_d=1-(1-1/d)^d,quad k_g=|X_g|d^{Q-1}.
\]

全变量 tag 使并集可相加；这是所有 state 选择和所有子族的统一 Hall 界，不需要 CSP YES 或状态标签跨组一致。

将每组需求取 (b_g=\lfloor c_dk_g\rfloor)，A 的子族不等式给 capacitated Hall；clone 后普通 Hall 或整数 max-flow 输出两两不交 (B_g\subseteq S_{g,s(g)})，(|B_g|=b_g)。(d=1) 与 (Q=1) 分别由 incidence 限制和 index 互异直接得到完全不交；空组排除以保持 (k_g>0)。

# 3. B/C：19/25、19/15 与完整 ordinary-UM 桥

## 3.1 d=5,Q=2

单变量中若两标签行列计数为 (a,b)，总 incidence (r=a+b\le5)，并集为 (5r-ab)。平衡 (a,b) 最大化 (ab\) 得

\[
\frac{5r-\lfloor r^2/4\rfloor}{5r}\ge19/25,
\]

且 (r=5,(a,b)=(2,3)) 取等。三变量组 (k_g=15) 因而可对任意固定 state 选择同时保留 (\lfloor19\cdot15/25\rfloor=11) 个资源；C2 给实际负载 (2-11/15=19/15)。这只是固定 state 选择的通用保留量，不声称优化菜单后一定需要11。

## 3.2 普通 UM 构造与任务身份

每个 indexed state 有独立机器 (M_{g,s})，每个 tagged resource 有机器 (R_u)。每组 selector 在本组每个 state 根上时间1；每个 incidence job 在自己的 (M_{g,s}) 上时间 (1/k_{g,s})，在 (R_u) 上时间1，其他端为 (infty)。所有未选 state、零 incidence 和 unused resources 保留。

若选定 states 的完整 sets 两两不交，将所有选中 state incidence 外送，未选 state incidence 留自己的 state machine，得到 OPT=1。给任意不交子集 (B_g\subseteq S_{g,s(g)})，只外送 (B_g) 中 jobs，其余保留，得到

\[
C_{\max}\le\max\left\{1,\max_g\left(2-\frac{|B_g|}{k_{g,s(g)}}\right)\right\}.
\]

A 的半分配强化保证 (c_d\ge(d+1)/(2d))；当 (Q\ge2) 时 (k_g) 是 (d) 的正整数倍，故 (c_dk_g\ge\lceil k_g/2\rceil)。通过 max-flow 取半量，得到所有显式输入的 (C_{\max}\le3/2)，(d=1) 或 (Q=1) 时 OPT=1。

## 3.3 3/2 精确锐例

取 (d=2,Q=2)、一个变量 (x)、两组各一个状态，两个切片分别是 ({a_1=1})、({a_2=2})，并集只有3个资源。两个 selector 各占根负载1；若 (C<3/2)，根不能留半单位 incidence，四个 unit incidence 必须外送到三个可用 resource machines，而 (C<2) 时每台至多一枚 unit，矛盾。导出一个不同 resource、另一个留根则达到 (3/2)。因此 3/2 是该**归一化构造类**的全局绝对上界且可达，但不是 NP-hard threshold、CONFIG gap 或一般 UM 近似下界。

independent review 还核对了 explicit bit complexity：资源、states、incidences 显式展开时，整数 max-flow 网络和 (1/k_g) 有理时间均位多项式；若仅以 binary (d,Q) 简洁编码而不展开 (d^Q) cube，则不作统一 succinct-input 多项式声明。

# 5. 与 DGR 原论文和其它对象的差异

来源读后对 Davies–Guruswami–Ren *Scheduling Problems with Constrained Rejections*（arXiv:2511.00184v1）做了范围核对：原论文 Theorem 4 是无分组 set-selection 的固定常数困难性，使用 degree-five 3SAT、二元标签、每 clause 七个 sets、每 set 15 个元素及 (\epsilon<1/30)。本对象另加“每 clause 一个 group、七个 local states、selector/incidence ordinary-UM 桥”的定义；19/15 与3/2来自本对象的乘积计数、Hall 和负载回算，不归属于 DGR 原定理。

保留15个元素且 (\epsilon<1/30) 已强迫保留全部15，不形成任意小 fraction 的 near-2 hardness。该 grouped hypercube theorem 反而排除了这类 concrete bridge 的 near-two 企图：所有输入都有3/2上界，DGR specialization 还有19/15上界。它不排除改变资源命名、重复 incidence index、非乘积切片、多尺度时间、非 selector 任务等域外机制；这些只是 escape hypotheses，不是新的 hard source。

与坐标切片 v4 深树反例的共同点是乘积坐标切片，区别是本对象不建立深 (D^Q) 私有树，而直接使用 Hall 取资源和 selector/incidence 平星桥。两者均不提供一般 UM near-two hardness，也不涉及 CAG 六名顺序提供者 SPE 覆盖。
