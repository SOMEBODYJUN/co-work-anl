# 2. 单任务局部极小与一次最终支持下界

二次势Φ=ΣL²的三个单任务动作：unit从0到leaf，tiny从leaf到0，tiny在两leaf间。Φ增量分别2/m、2/m、2/m²，均严格正；前两动作把最大值2升2+1/m，第三保首项2却将第二项d升1+2/m，排序lex也严格更差。所有分配W相同，所以局部停滞不是偏好小总工作量造成。

对任意0<ε<1，若某最终assignment峰≤2−ε，两unit必须分开，至少一unit离开初始0到leaf；该leaf原m+1 tiny，目标unit余量最多floor(m(1−ε))=m−ceil(εm)枚，所以至少1+ceil(εm) tiny离开，连unit最终Hamming支持≥2+ceil(εm)。这是**从初态一次到目标**的必要支持，不是每轮动作大小下界；ε目标是绝对峰2−ε，和初始比值2m/(m+2)各自保原量纲。
