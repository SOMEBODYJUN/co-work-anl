# 配置剥离与联合匹配有限审计

这十二份来源属于 unrelated-machines 的配置/资源/匹配线。它们处理 job--machine 的有限矩阵、资源槽位、priced covering、bundle peeling、Cartesian subdivision 或 prefix parity；不使用 CAG 的共同目录、SPE 或客户均分语义。已有[逐坐标一致菜单的整数资源配额](../定理/逐坐标一致菜单的整数资源配额--定理.md)、[有界重数克隆接线](../定理/有界重数克隆接线与共同循环坍缩--定理.md)和[配置证书批次审查](配置证书批次与量词边界--审查.md)是相邻对象，本页补充冻结运行中的数值、边界和失败机制。

## 1. 计数、重数与价格接口

### Affine complement 与 anchor deficiency

`c4f03674003e646df675` 的 `UM-AFFINE-COMPLEMENT-CARDINALITY-BOUNDARY-v1` 运行通过，精确见证 \(\rho=3/2\) 和 uniform count bound；状态明确是“exact finite witness and count inequality passed; method boundary only”。因此它只能支撑该 affine complement 计数不等式在给定构造中的成立，不能替代方法边界之外的通用配置证明。

`acb3c1e4d763176a59f2` 用 Fraction 检查三个 rounding fixtures：一类 deficiency 1、threshold \(1/2\)、loads \((3/2,1/2,3/2,1/2)\)、bound \(13/8\)；一类 deficiency 0、threshold 1、loads \((1,1)\)、bound \(13/10\)；一类删除资源 1 后使用极大有理分母，仍保持精确阈值。sharp cutoffs 为 \(d=0\mapsto1\)、\(d=1\mapsto1/2\)、\(d=4\mapsto1/5\)。没有通用 LP solver，零/空边界单独保存。

### Heavy-light price covering / MW

`eb69b21ac2fc7ee61e94` 使用 Fraction 重放 min-priced endpoint、cost-scaled covering、actual-volume inclusion、macro injection matching 和 product-potential MW。静态原始案例 112 个，其中 T-feasible 64 个、oracle price calls 371；总 oracle calls 1876、local cover checks 4016、actual schedules 104,920。最大值包括 cover approximation ratio \(97/96\)、mode \(\ell_1/B=549755813888/549755813889\)、priced load/T=2；一次 priced rejection 记录为 `PRICED_FAIL`。完整 MW 样例中 single-sink average budget 3/2、two-sink sub2 为 5/4；cycling 例不可行，small-eta 只跑 strict prefix。报告明确没有 generic rational LP、matroid-rounding backend、任意实例结构提取或通用近似比。

`aab22aac4dec0c04d05d` 的 batch support 独立审计覆盖所有 legal assignments：fanout \(k=1,\ldots,5\) 的整数 Gray 扫描（最大 4,194,304 assignments），k=1--3 另用 Fraction 交叉核对；压缩大 k 为 7、31、127、503，均记录唯一 optimum 1、min lex distance \(k+1\)、min makespan distance \(k+3\) 和 min max-out=k。rings \(q=2,3,4,5\) 也逐项给出唯一 optimum 1。大 k 的 assignment 数是压缩报告中的组合计数，不是实际逐项枚举；因此用途是支持 fanout/环模式的结构回归，不是一个通用运行时间结论。

## 2. 标签地板和显式配置包络

`9e050980899db202ae93` 的 bounded-collision label-floor 审计有 35,795 个 exhaustive families、107,385 次 coloring runs、1,971 个 independent-optimum families、328,231 个独立 oracle states，6 个非法输入拒绝。它用整数/Fraction、q=1,3、资源宇宙 1,4 和 forward/reverse/rotation owner orders 检查低重数标签地板；尖锐 singleton multiplicity 族给出 \(b^*=1/\Delta\)（例如 \(\Delta=1,2,3,4,5\) 对应 1、1/2、1/3、1/4、1/5），identical-pair 族也逐 k 检查。独立审计另有 421,839 个实际 resource-parent assignments、489,061 个 approximation assignments、240 个 full-menu DAG、500 个随机 full-menu DAG。它支持“局部 label/资源缺口导致地板”的有限和原定义检查；一般证明仍在独立 coloring/local-envelope 论证，不从计数外推新 hardness。

`b48773496547fdf35c6b` 的 bounded-configuration-cardinality 只保存低 K 的完整示例。K=2 时 central envelope/actual matching load 都为 \(3/2\)，K=3 为 \(11/6\)，K=4 为 \(47/24\)；每例 coverage=1、matching verified=true，配置权重和中心选择均显式列出。它的限制字段明确没有 generic LP、只覆盖 explicit low-K full instances，所以归为有限配置证书。

`dba30f87cb19b0cd4962` 是其 independent zero-T/covering-matching 重放：空 T=0、K=1 时删除零边 job 后 remaining jobs=0，coverage 前后相同；K1 ties、一个零边但别处正边、极大有理 T 等边界均逐个枚举 covering matchings，最大 matching makespan 与 exact coverage 相等。它核验“除零边再匹配”实现，不给一般配置算法。

## 3. Tensor、bundle peeling 与 subdivision

`d453e4528bb16b8f5756` 构造实际整数 source-product witness：base q=2、matching number 1、tensor power 4，使用 \(B^2=I+B\)、\(B(I+B)=I\)（\(\mathbf F_2\)）的矩阵身份。报告核对 16 条 selected tensor edges、6 个 base pair intersections、12 个单轴 prefix families、322 个 bounded level joint families、54 个 pair-only resource families，并分配 912 个 distinct resource clones。它明确只审计 L=2 的显式 B；higher-order countertest 的三个坐标自然容量为 2，却观测到三层 guard 失败。因此这是一个“局部容量 guard 不足”的障碍/证书，不能冒充一般 tensor coherence 证明。

`5481f824a943bdf04975` 的 bundle-peeling path audit 通过 27 个 three-vertex branch cases、48 个 generated cases、6 个 degenerate cases、12 个 invalid cases。sharp C/T 样例包括 \((C/T,U,\mathrm{OPT})=(1,2,1),(5/4,2,1),(3/2,2,1),(7/4,9/4,1),(2,5/2,1)\)，并保留极大有理 scale。报告范围是 finite prefix replay 与小 minimax/OPT oracle，不是 target solver 或 approximation algorithm。

`5af5d7b2abbe05cff336` 的 independent profile-peeling 运行通过 800 production-random、104,976 profile-exhaustive、1,200 profile-random、286 nonempty-core、999 peeling、21,845 LPT integer cases。96-vertex/384-arc deep-peeling 轨迹的 peak 为 \(7/4\)，bound 为 2；sharp cases 覆盖 \(C/T=1,5/4,3/2,7/4,2\) 及多组有理 T。它支持剥离实现和峰值上界的有限回归，不能单独证明任意输入的 instance-optimality。

`528f36466ffc7a22d79e` 是 bundle subdivision 的多文件汇总：pair-coupling 第一组在 k=2 得 target=3/2、proved/exhaustive optimum=3/2；k=3 target=4/3 但 optimum=5/3、certified ratio=5/4；k=4 target=5/4、proved optimum=7/4、ratio=7/5。cardinality-final 子审计检查 7,689 matrices、53,823 matrix targets、115,799 feasible schedules、7,232 deletions 和 53,823 monotonic checks；independent-final 解出 260 subdivision instances、113 equality instances。k=4 OPT 依赖显式数学族证明，k>4 未物化，有限检查不替代一般 soundness/complexity 证明。该结果保留了一个清楚的障碍：朴素 pair subdivision 会把 k=3/4 的目标拉高，不能直接保值。

## 4. C2 prefix parity

`e0dc61a356b4c548d797` 枚举 32 个 five-bit parity states，结果为 supports 16+16、degree≤4 moments 相等、\(q_F=1/16\)、conditional \(b_5=0/1\)、heavy pair \(T=2\)。状态明确是 finite exact audit；它只支撑 heavy-T=2 与 fixed-C interpretation 下的 prefix conditioning degree，不是任意 prefix 的通用结论。

## 5. 处置、证据和后续用途

十二个 raw JSON 已冻结至 `archives/unrelated-machines/tools/evidence/configuration-peeling-joint/`，manifest 记录各 source ref、SHA-256、字节数和 JSON 解析状态。处置如下：

* c4f、acb、eb69、aab、9e05、b487、dba 集成到配置计数、标签地板、价格覆盖和匹配计算对象；保留 exact finite 与 boundary 说明。
* d453 集成到 tensor joint-capacity 障碍，保留 higher-order guard 失败，不扩展为 general tensor theorem。
* 548、5af 集成到 bundle peeling 路径/峰值审计；528 保留为 subdivision 的目标膨胀障碍；e0dc 集成到 C2 prefix parity 的有限审计。

所有结论都区分了“精确有限证书”“独立一般证明所依赖的实现检查”“局部 guard 失败”。没有一项给 unrelated-machines 的通用 LP solver、统一近似比或新 hardness 结果，也没有与 CAG 建模型迁移边。
