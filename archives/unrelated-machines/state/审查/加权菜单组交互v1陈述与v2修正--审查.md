## 2. v1 的完整模型合同

输入是有限非空组集 (G)。每组有非空、显式、带索引的 state menu (A_g)；每个 state 有显式的互异资源集合 (S_{gs})，可为空；每个 state-resource incidence 有非负二进制有理 private time (p_{gsu})，并满足

\[
W_{gs}=\sum_{u\in S_{gs}}p_{gsu}\le1.
\]

普通 UM 实例包含：每个 indexed state 一台 distinct private machine，每个 resource 一台 resource machine，每组一枚只可去本组 state machine 且处理时间为 1 的 selector，以及每个 incidence 一件在其 state machine 上用时 (p_{gsu})、在 resource machine 上用时 1 的原任务。未列端均不可用；没有预载、侧约束、被拒任务或私有机/资源机合并。零 private time、空 state、重复 indexed state 都是输入合同的一部分，所有未选 state 的任务仍实际存在。

设 (S_g=\bigcup_sS_{gs})。整数 (Delta\ge1) 是完整菜单并集上每个资源跨组出现数的有效上界；(M\ge0) 是组交互图（两组的并集共享资源即相邻）的最大度上界。参数可二进制编码并从显式输入检查。v1 定义

\[
\beta_1=\frac1{M+2\Delta},\qquad R_1=2-\beta_1.
\]

量词是：每个满足该显式合同的输入都有确定性位多项式算法，输出原任务的完整合法分配，峰值至多 (R_1\operatorname{OPT}(P))。算法不输入 OPT、YES witness、state 分布、配置解或未知可行分配。另有严格单位 promise：用实际输出负载与 (2-\beta_1) 比较，区分 (OPT\le1) 和 (OPT>2-\beta_1)；这不是无条件输出绝对负载 (2-\beta_1)。

## 3. 归一化与 heavy/diffuse 两分支

对任意 (W_{gs}<1) 的 state，v1 加一枚该 state 独有的辅助 resource 和一件在 private 端耗时 (1-W_{gs})、辅助 resource 端耗时 1 的 bonus job。所有 state（包括未选 state）的 bonus 都被保留；投影删除 bonus 不增负载，原调度把每个 bonus 放到自己的 dedicated resource 可在不增加峰值的情况下扩展。故归一化实例与原实例 OPT 相同，且 (M,Delta\ge1) 的上界不被 bonus 增加。

以下先假设所有 state 的 (W_{gs}=1)。称 state 为 diffuse 若其所有 private time 不超过 (\beta_1)。有 diffuse state 的组记作 (L)，按固定输入顺序选一个；其余组记作 (H)，每个 state 都含某个 (p_{gsu}>\beta_1) 的 heavy incidence。

在 (H) 与资源间建立边：若 (g) 的某个 state 在 resource (u) 上有 (p_{gsu}>\beta_1)，便连边并存一个 witnessing indexed state。

### 失败分支

若该二分图没有覆盖全部 (H) 的 matching，v1 声称

\[
\operatorname{OPT}(P)\ge1+\beta_1.
\]

理由是：若存在峰值小于 (1+\beta_1) 的调度，每个 (H) 组 selector 选定某个 state 后必须外送至少一个 (p>\beta_1) 的 incidence，否则 selected private machine 的 selector 加该 private job 已超过阈值；在 (C<2) 时每个 resource 至多接一个 unit incidence，于是这些被外送的 heavy incidences 形成覆盖 (H) 的 matching，矛盾。失败时输出全-private 调度，所有 selector 放任意本组 state，所有 incidence 留 private，峰值至多 2；故

\[
\frac{2}{1+\beta_1}\le2-\beta_1.
\]

### 成功分支

若存在覆盖 (H) 的 matching，给每个 (H) 组选存储的 witnessing state，并只 export matched heavy incidence，其他 incidence 留原 private；这些 matched resources 被 reserve。

每个 (L) 组选择 diffuse state，删去所有 reserved heavy resources。因为组交互度最多 M，最多有 M 个 heavy groups 能在该 selected state 上占用带正 private 权的资源，每项权至多 (\beta_1)，所以剩余 private mass

\[
W'_g\ge1-M\beta_1.
\]

把剩余资源按 private time 非增排序，切成连续的完整 (Delta)-资源块，丢弃末尾少于 (Delta) 项的 incomplete tail。每个完整块产生一个 unit-demand slot，与其 (Delta) 个真实资源相连。每个 slot 的邻居数是 (Delta)，每个资源至多出现在 (Delta) 个 slot 中，因此 Hall matching 可覆盖所有完整 slots；必须一次匹配全部轻组 slots，不能替换成任意 fractional rounding。

v1 的账法写成

\[
\sum_{u\in B_g}p_{gs(g)u}
\ \ge\ \frac{W'_g}{\Delta}-\beta_1
\ \ge\ \beta_1.
\]

这里末尾 tail 的损失按至多一个 (\beta_1) 记账，第一项除以 (Delta) 后再减 (\beta_1)。于是每个 (H) 组 export 私有质量严格大于 (\beta_1)，每个 (L) 组至少 (\beta_1)。资源互不重用，所有 selected private roots 的负载至多 (2-\beta_1)，未选根负载至多 1，资源至多接一个 unit incidence，得到实际峰值至多 (2-\beta_1)。因 selector 迫使 OPT 至少 1，v1 将同一绝对上界写成比率上界 (R_1)。

## 4. v1 到 v2 的常数修正

现有 v2 续审查保持相同的 heavy matching、reserved resource、diffuse state、完整 (Delta)-块 Hall matching 和原任务回填，但重新核对了尾项的整数计数：完整块之前最多丢弃 (Delta-1) 项，每项至多 (\beta)，而不是把尾项统一估成一个额外 (Delta\beta) 量。v2 因此写出

\[
\sum_{u\in B_g}p_{gs(g)u}
\ge \frac{W'_g-(\Delta-1)\beta}{\Delta}
\ge \frac{1-(M+\Delta-1)\beta}{\Delta}.
\]

要求右端至少 (\beta) 时只需

\[
1-(M+\Delta-1)\beta\ge \Delta\beta
\quad\Longleftrightarrow\quad
\beta\le\frac1{M+2\Delta-1}.
\]

这解释了 v2 的

\[
\beta_2=\frac1{M+2\Delta-1},qquad R_2=2-\beta_2,
\]

而不是 v1 的较弱 (R_1)。两版本的模型、状态量词、bonus 归一化、失败分支和 Hall matching 不变；变化是尾项精确计数造成的常数改进。不能把 v1 的 (\beta_1) 报成最终最强界，也不能因 v2 改善就删除 v1 的历史陈述和其 statement-first 先验。

## 5. 复杂度和边界的共同范围

两个版本都按显式 state-resource incidences 计输入大小。组交互和资源跨组度是在全部 state 并集上统计，不是按算法选中的 state 事后估计。排序、精确有理比较、heavy graph matching、完整 (Delta)-块匹配和逐件原任务回填均按显式图大小及输入分母位长计确定性多项式；不按二进制 (Delta) 复制 dummy resources，也不把 (Delta^Q) 等隐式对象展开。

在 tagged grouped coordinate-slice specialization 中，若每组至多使用 (q) 个变量、每变量至多出现于 (d) 组且 incidence index injective，则

\[
M\le q(d-1),qquad \Delta\le\min(d,Q).

\]

因此固定 (q,d,Q) 的该结构类有一个统一低于二的保证；但固定 cube 维度不等于固定完整菜单交互度，(M) 增长时改善可以消失。若要求全正权、label 唯一决定 state identity、不同 source group 的额外一致性，需另立对象。两个版本都没有一般 MC 后端、生产实现、有限运行或 source hardness reduction。

## 6. 与全仓对象的关系和处置

`三坐标零权切片的精确菜单嵌入` 使用的是 v2 当前源，只证明零权三坐标表示精确保留 OPT、state quality 和完整组交互图；其第 6 节把有效资源度取为 (Delta=3)，得到 (2-1/(M+5))。这不是 v1 的新三坐标定理，也不把 v1 的更弱分母误接到该对象。

`完整菜单的资源度三路径归约` 和 `归一化菜单的三态资源度三正规形` 是后续不同表示接口，不能由本 v1/v2 的 group-interaction algorithm 自动承接；它们各自改变组数、selector 资格或 helper 任务，需保留对应量词。

本源的 v1 source 是同一受限加权菜单算法的早期精确陈述，但其常数、尾项账和陈述先行身份在 v2 中被修正或细化，具有独立版本 provenance 和数学边界信息。因此处置为 `integrated`：将 v1 的模型、较弱保证、失败/成功分支和 v2 的精确常数修正纳入本审查页；不另建一般 UM 定理，也不把 v1/v2 计为两个互相独立的算法成果。

后续第三阶段应把本页与 v2 续审查连为“版本修正/受限算法”边，并将 v1 的 source-only 记录与 v2 的最终承重证明分开标记。所有硬度或近二用途仍需额外的 source-related wiring、YES 保留和对每个低负载实际调度的可靠解码；M、(Delta) 有界本身不完成这些义务。
