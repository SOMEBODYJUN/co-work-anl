# 2. strict双向合同与算法上界是不同输入义务

完整B只含每i的M_i/C_i、q_i/b_i和每clause的u_c；q三个原端M_i:ρ、M_i⁺:1、C_i:x_i，b两个原端pin:ρ/C_i:1，u仅本clause真实C_i:y_i。ρ∈(1/2,1)，真实x/y正且x+y≤1，dummy x=1；每clause≥2个物理occurrences、变量环padding≥3。正负文字分别pin到本位/后继，重复文字仍是不同任务，且每occurrence只属一clause。没有h/D、预载、真实公共R或原输入未列的外端。

SAT给满足赋值后可选每clause一真occurrence，令q+u共居其C，b按同方向替换q的环槽，其余原任务全部在原端执行。任意strict≤1的实际调度则不输入SAT解：作者从E⊆R和N−|E|+|R|≤N得到E=R；typed从2N个q/b填满2N个至多一件槽得到同一逐编号身份。正y排除u读unit b，环方程(1−z_i)+z_(i⁻)=1迫同变量整环方向一致，直接解码满足赋值。两种证明均包含dummy及额外真实exports/returns，而非把身份作为免费关系。

全公式三半上界的算法又不输入未知strict调度、源解或局部兼容见证。每baseline clause选y≤1/2的真实索引，active全部y>1/2故其x<1/2。作者保留全部q/b、所有M/C，只有baseline u暂不入图；typed先固定baseline/dummy的b-C强制对并删这些成对分析节点，但**全部q仍保留**。这给2N+h与N+L₁+h两图的精确对应，不是修改原任务集。

Active i∈c的θ_i=1/k_c≤1/2：q两环端先各1/2，在pin扣θ并向分析V_c加θ；b在pin/C给θ/(1−θ)，active u向C给θ。所有行和及M/C/V列和均1，非负证书推出同一全局整数perfect matching。Active每clause恰一个query出口及一个b返回，编号允许不同；baseline/dummy C唯一邻居b不能被借用。Virtual R_c/V_c只是这同一分析节点的不同记号，不是旧稿真实公共clause机。

实际输出消去V，把同一原q放其自身C且用原x，b/u保原时间，并逐件加回所有baseline u。M一原job≤1；baseline C负载1+可选y≤3/2且无query；dummy C仅unit b；active留b的C可能加q为1+x<3/2；active返回b的C含u及可选q，总≤x+y≤1。不同u不会叠同C，因为物理occurrence独属一clause。每件2N+m原job恰一次，无分析目的地、分数执行或丢失原任务。

两种图在active空时仍有效，之后恢复全部baseline u；空公式另列一idle机、零任务、OPT0。任意显式长dummy表按实际N计，最少padding N≤L+2v；finite5N+L，dense2N(2N+m)。精确有理比较、θ位长O(logL)、一次显式matching与实际负载回算均为总位多项式，不按参数倒数/分母数值迭代。没有软件或有限扫描承担这些一般量词。
