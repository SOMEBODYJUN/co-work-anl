# 两层标签费用逃逸与真实最优值增量审计

## 1. 对象、来源与量词

本页整理两个冻结运行输出及其全仓相关材料。对象是一个显式展开的二部投影约束多重图编译器。两侧顶点集 (U,V) 不交；每个顶点 (v) 有非空有限标签集 (Sigma_v)，每条边 (e=(u,v)) 有全定义投影 (pi_e:Sigma_u	oSigma_v)。允许平行边、孤立点、不同字母表和非单射投影。给定整数 (Dge2)，要求每个顶点的度数不超过 (D)。所有机器和任务都按表实际展开，未列端不可用，全部原任务必须安排。

编译器的关键局部结构是：

* 每条边状态 (a) 有一个 unit selector (s_e) 在 (R_{e,a})，两个 (1/2) query 可留在同一 (R_{e,a}) 或送到左、右端口 (H)。
* 每个端口标签有一个 (3/4) guard，可留在 (H) 或以 (1/D) 送到共享 (A_{v,b})。
* 每个标签有 unit 任务 (w_{v,b}) 可在 (A_{v,b}) 或 (B_{v,b})，以及 (D) 个 (1/D) 的 (f_{v,b,r}) 可在 (B_{v,b}) 或固定编号的本顶点 (C_{v,r})。不同顶点的 (C) 不共享，不能重编号。

因此需要分别记录三个层次。

1. **显式域内的解析结论。** 给定任意边状态向量，正文给出完整调度和峰值上界；独立审查从真实任务重新推导相同上界和第二大重数恒等式。这里的“定理”只对上述编译器、任务资格和完整展开输入量化。
2. **冻结代码的有限核验。** 主审计运行五个奇数循环移位实例、三种状态模式和六个 tiny source；独立程序对列出的有限小矩阵做真实端 DFS 或完整状态构造。有限报告不能替代解析量词，也没有搜索一般输入的 optimum。
3. **障碍和列表反例。** 奇数循环移位族有强列表 NO 的差集计数，但其实际 UM 最优值趋近 1；这反驳把列表费用直接变成近二 actual gap 的企图，不反驳所有其它编译器或一般 UM 算法。

## 2. canonical 编译器的解析结论

### 2.1 任意边状态都有三半调度

选定每条边的状态 (a_e)。对应的两个 selected queries 送到各自 (H)，未选状态的两个 query 均留在自己的 (R)，所以每个 (R) 的负载是 1 或 (1/2+1/2=1)。selected (H) 有一件 unit query，其余 (H) 只留 (3/4) guards。

在顶点 (v)，令 (c_{v,b}) 是所选边端点标签 (b) 的次数，(sum_b c_{v,b}=deg(v)le D)。至多一个标签满足 (c_{v,b}>lfloor D/2
floor)。对非重标签，把 (w) 留在 (A)、全部 (f) 留在 (B)，得到 (A) 负载 (1+c_{v,b}/Dle1+lfloor D/2
floor/D)。若有唯一重标签，把它的 (w) 送到 (B)，全部 (f) 送到同编号的 (C_{v,r})；每台 (C) 至多收到一件 unit (f)。这安排逐件包含未选状态、未选标签和所有 guards，故

[
C_{\max}\le1+\frac{\lfloor D/2\rfloor}{D}\le\frac32.
]

该构造不需要源满足赋值、分数证书、未知 OPT、单射投影或 regularity。它只需要输入已经显式展开，或者按显式源标签/边表生成 (D) 个 (f) 任务；若 (D) 只以二进制给出而未展开，输出规模声明不能改写成 (operatorname{poly}(log D))。完全空顶点集没有原任务，单列 idle machine 和 OPT=0；有孤立顶点但 (E=arnothing) 时仍有 (w,f)，OPT=1。

### 2.2 第二大重数的真实最优值恒等式

对边状态 (a)，在每个顶点把多重集 ({c_{v,b}}_b) 的第二大值记作 (c_{v,(2)}(a))，不足两个标签时补零，令

[
\mu=\min_a\max_v c_{v,(2)}(a).
]

非空全顶点集满足

[
\operatorname{OPT}=1+\frac{\mu}{D},
\qquad 0\le\mu\le\left\lfloor\frac D2\right\rfloor.
	ag{I}
]

上界对给定 (a) 在每个顶点打开最大次数标签、把其全部 (f) 放入同编号 (C)，其它标签保持 (w) 在 (A)、(f) 在 (B)，得到 (1+max_vc_{v,(2)}(a)/D)，再对 (a) 取最小。

下界必须保留完整实际调度的非规范可能性。若 (C<1+mu/Dle3/2)，每个 selector 所在 (R) 不可能再留任一 (1/2) query；对应 (H) 不可能再留 (3/4) guard，因此实际读出的状态计数确实在 (A) 上产生至少 (c_{v,b}/D) 的负载。令 (k=\lfloor D(C-1)\rfloor<mu)，某个顶点有两个标签次数至少 (k+1)。这两个 (w) 都不能留在各自 (A)，于是各自在 (B)；每个 (B) 至多留 (k) 件 (f)，两标签合计至少导出 (2(D-k)>D) 件 unit (f) 到同一顶点的 (D) 台 (C)。因 (C<3/2<2)，每台 (C) 至多接一件，矛盾。额外未选任务的任意移动只增加非负负载。

(I) 是显式编译器的值恒等式，不是求 (mu) 的多项式算法；代码只按给定状态构造 schedule，没有实现 (mu)-优化后端。偶数 (D) 的等号 (C=3/2) 允许两个标签各外送互补半数 (f)，所以所有“至多一个打开标签”的说法都必须保持严格 (C<3/2)。

### 2.3 严格 singleton 解码

在非空全顶点集上，源存在满足全部边的 singleton 赋值，当且仅当实际最优值 (le1)。更强地，任何完整调度若

[
C<1+1/D
]

都能从每条 selector 的实际 (R) 标签读出边状态；两个 query 被迫到对应 (H)，guard 被迫到对应 (A)，被激活标签的 (w) 被迫到 (B)，其 (D) 个 (f) 被迫占用本顶点的 (C) 池。每顶点若激活两个标签，就有超过 (D) 个 unit (f) 需要进入 (D) 台 (C)，故所有边端点标签在同一顶点一致，读出的边状态给出 singleton 满足赋值。

完全空顶点集需要单列：源无任务且 OPT=0；因此正式命题应写“OPT (le1) 当且仅当源满足”，在非空域再把 YES 值写成恰为 1。严格阈值的等号不解码：D=2、无满足源的两平行边可以达到 (C=3/2)，所以不能把 (C<1+1/D) 改成非严格不等式。

## 3. 奇数循环移位：强列表 NO 与便宜实际调度

取奇数 (qge3)，两顶点 (u,v) 的标签均为 (mathbb Z_q)，有 (q) 条平行边 (t)，投影为

[
\pi_t(a)=a+t\pmod q,
\qquad D=q.
]

任意 singleton 标签对至多满足一条边。若两侧列表分别为 (L_u,L_v)，被覆盖的边移位属于差集 (L_v-L_u)，所以覆盖边数至多 (|L_u||L_v|)。在总列表成本 (|L_u|+|L_v|le2g) 下，覆盖率至多 (g^2/q)。固定 (g) 和目标覆盖率 (
ho)，取奇数 (q>g^2/
ho) 就得到强列表 NO；这只是一个两顶点显式族，不是 PCP hard image、NP 困难性或一般列表问题归约。

同一实例的实际 UM 最优值却很低。取边状态 (a_t=t)，右端标签 (2t) 在奇数 (q) 下遍历 (mathbb Z_q)，所有 (w) 留在 (A)、所有 (f) 留在 (B)，所有 (A) 负载为 (1+1/q)，其它机器至多 1。严格 decoder 排除更低峰值，所以

[
\operatorname{OPT}(I_q)=1+\frac1q.
]

这使列表 soundness 与真实 UM gap 明确脱钩：强列表 NO 可以和实际最优值趋近 1 同时成立。输出还检查了 (q=3,5,7,11,25)，其 jobs 数分别为 63、165、315、759、3825，构造峰值分别为 (4/3,6/5,8/7,12/11,26/25)。
