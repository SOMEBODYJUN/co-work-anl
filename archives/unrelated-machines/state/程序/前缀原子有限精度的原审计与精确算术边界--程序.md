# 一、固定顺序前缀、真实求和与近似选择

叶 `atom=(a_1,...,a_n)` 为任务端点标签，`law[atom]` 是精确有理权重；
`prefix_mass` 直接遍历字典，把匹配前缀的权重相加。
每层孩子标签默认 `0,...,d_j-1`，边界fixture可另给 `choices_by_job[j]`。
`noisy_max` 从空前缀、真父质量1开始，算出**每个孩子的真实质量**，再加噪声选估计最大者。
默认噪声为全局种子7711803产生的 `{-alpha,0,alpha}`；自定义 `offsets` 用于等号例。
Python `max` 平局保留列表最前端，所以这些构造的全零路径是确定的。

若选中真质量为q、父质量为p、孩子数d，则其它孩子至多q+2alpha，因此

\[
 q\ge[p-2\alpha(d-1)]/d.
\]

乘前k层端数积 `Q_k` 并望远镜，得到

\[
 Q_kq_k\ge1-2\alpha(Q_k-1).
\]

函数逐层断言孩子真质量和恰等前一真质量、上述单步式和累计式；返回叶、其真实权重和 `(q_k,Q_k)` trace。
这些断言只检查访问路径。函数没有验证所有字典权重非负、根总和1、所有前缀守恒，
也不验证自定义噪声绝对值是否≤alpha；`choices`只断言长度等d，没有检查标签互异。
所以不能将此函数当作任意输入law/误差的完整验证器。
正式正性、归一和噪声预算是输入承诺，本程序内部生成的例子满足相应条件。

更关键的是，真实前缀质量来自完整小字典求和，`random_law`先展开 `product(range(d_j))`。
这里并没有实现一般隐式 `Eval`；小例中的操作次数不等于承诺解码器 `O(sum d_j)` 的整体算法。
[前缀law的生成义务](../审查/前缀原子law解码的生成义务与精度后续--审查.md)
仍需另解，不能由枚举小law消除。

# 二、三类质量检查的准确域

`max_mass_audit` 的500次随机树：`1≤n≤6`，各 `d_j∈{1,2,3}`，
每个笛卡尔积叶抽整数权0到9，再除总和；全零抽样只把首叶置1。
最大729叶，允许零质量原子。设 `N=prod d_j`、`alpha=1/(4N)`，
每次断言输出权≥`1/(2N)`。这不是随机搜索调度或检验所有大树。

第二类k=1到8的二叉树：全零叶权0，其余叶各 `1/(2^k-1)`，
精度 `alpha=1/[2(2^k-1)]`。沿零前缀给目标孩子加alpha、首次离开零路径孩子减alpha；
断言最终选择全零叶、权0且恰达到未截断下界。
这展示临界精度可合法选零叶，并不说每个近似器都会如此。

第三类是六个显式度向量
`[2]`, `[2,2,2]`, `[3,2]`, `[1,3,1,2]`, `[2,3,2,1]`, `[3,3,3]`，
每个取五种精度：0、临界/16、临界/2、`1/(4N)`、临界。
给目标叶权

\[
 u=[1-2\alpha(N-1)]/N,
 \qquad v=(1+2\alpha)/N
\]

而其它叶各权v；全部权非负且和1。沿目标路径，目标孩子与每个兄弟的真实差恰2alpha，
加减噪声后平局，所以每层 `q_k=[1-2alpha(Q_k-1)]/Q_k` 取等。
源码断言这30个有限实例的每层等号。度1的中间任务保留，源不把它删掉。
一般任意度、`N=1`和超过临界后的截断锐性由既有数学证明承担；本30例不遍历那些全部情形。

# 三、绝对残差、网格和精度位数

`dilution_audit` 对k=0到12只算三项有理恒等式：`N=2^k`、均匀叶权 `1/N`、
负载 `3/4+3/4=3/2` 在阈值1处残差 `-1/(2N)=-tau`，并断言 `load=1+N*tau`。
它没有在此函数构造任务矩阵或遍历这些分配；
桥正文用两枚A上的强制3/4任务和k枚B/C的零时任务实现该算式。
因而残差小来自拆分质量，实际过载仍为1/2，不是网格恢复定理的反例。

`common_denominator` 取阈值和**所有非None处理时间的约分分母之积D**，
重复分母也相乘，不求最小公倍数。它检查乘积位长≤各分母位长和。
`grid_audit` 只构造三组2机2任务实例：

| 阈值B | 第二机首任务 `bad_p` | 首机两任务 | 第二机次任务 |
|---|---|---|---|
| 0 | `1/(10^83+53)` | B,0 | 0 |
| 7/11 | `7/11+1/(10^83+53)` | B,0 | 0 |
| 1 | 3/2 | B,0 | 0 |

此处 `N=4`、`tau=1/(4DN)`，令坏原子单叶权 `tau/[2(bad_p-B)]`，
两个首任务放第二机的坏叶各取该权，其余两好叶各取 `1/2-坏叶权`。
所有叶所有机都逐一检查 `D(load-B)` 为整数及 `(B-load)*w≥-tau`。
每组40次带噪选择精度 `1/(4N)`，检查叶权≥`1/(2N)`、
负载≤`B+2N*tau`以及负载≤B。后一个断言使用具体构造和精确Fraction，
不是把浮点数向下取整。

可复用的一般理由是：若选中权至少 `1/(2N)`，真实残差界给
`load-B≤2N*tau=1/(2D)<1/D`；正的过载又必须至少1/D，所以不存在正过载。
这里要求**同一真law的全部叶残差**和有理网格。
近似测到残差、近似守恒或近似根归一都不能替代这些承诺。

另有一个不枚举叶的位数检查：n=1000、N=`2^1000`、D=`3^1000`，
只构造整数/Fraction并比较分母位长。原输出N位数1001、alpha分母1003、tau分母2587，
不表示程序对该大树生成了law、调用了1000层查询或验证所有原子容量。
数值指数小与编码位数指数大是不同命题；依赖按 `1/tau` 耗时的求解器仍可能指数慢。

# 四、二阶Gram与四个调度边界

`relative_gram_audit` 对k=1,5,20,100设 `r=2^-k`，

\[
 M=\operatorname{diag}(1-r,r),\quad
 K=\operatorname{diag}(0,-r),\quad C=\begin{pmatrix}1&2\\3&7\end{pmatrix}.
\]

`psd2`只处理2×2对称矩阵，逐一检查两对角非负及行列式非负。
源码断言 `K+rI` PSD、`K+M` PSD、`K+(1/2)M`非PSD；
然后对 `C^TMC,C^TKC` 再检查相对系数1通过、1/2失败。
C行列式1，因而这是明确的非正交可逆合同变换有限核验。
它没有实现所有维度PSD判定，也没有在本函数计算512次满行秩等价或秩遗漏反例。
那两项属于另外独立程序的
[714B原报告](../../tools/evidence/prefix-atomic-finite-precision-original-primary/source-root/evidence/runs/unrelated_machines/prefix_atomic_relative_gram_independent_audit.json)，
不能挪成本源码的运行内容。

`boundary_audit` 的四个law都是显式Dirac承诺：

1. 一台机器、空任务、空叶权1，degrees空积1；
2. 一机一零任务，阈值0；
3. 一任务只许在首机运行1/17，另一端None；
4. 两任务分别只许第二机2/19和第一机0，阈值2/19。

每例检查输出正权且在law中、选中端非None、逐机峰值≤阈值以及共同分母格点。
端点标签可为1，因此显式choices不会把唯一可用端误写成0。
这些fixture均至少一台机器、每任务至少一条可用端，
没有覆盖零机器、空资格任务、负处理时间或任意无效law的拒绝合同。
