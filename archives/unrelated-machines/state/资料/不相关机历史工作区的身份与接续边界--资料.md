## 一般容量桥的精确交接边界

下一门槛是：从一般输入矩阵 P 产生可计算、可验证的共同容量，并输出所有机器上的完整整数调度；不能将最优分配、分组、真实来源或精确 oracle 免费输入。完整任务身份、所有机器同时负载、统一余量、可靠失败与总位复杂度由[任务级共同容量的算法义务](../问题/任务级共同容量的算法义务--问题.md)继续承担。本 README 记录义务，没有提供一般生成器。

原件逐项提醒了以下边界，不能因它们只是交接语句而删去。

1. **共同 CONFIG 的信息合同。** 只共享同一一阶点 x，与全局矩及同机 CONFIG 共享二阶或更高阶条目，是不同系统。[弱 H₂ 与强行矩审查](../审查/弱H2强行矩与加权扇出边界双源审查--审查.md)保留同一稀释星族的弱合同趋二、共享行二阶后该族阈值等于真实 OPT 的区别；该族校准不证明一般强系统改善。
2. **两树的真实阈值。** [双树配置证书](../障碍/双树配置证书的趋二整数间隙--障碍.md)给真实 OPT 恰为 `2−1/k<2`。真实最优调度在该阈值给 Dirac 共同证书，所以“所有 T<2 都不存在共同证书”必错。必须写明阈值 T、共享条目和矩阶；切掉旧配置证书阈值不等于全类 gap 改善。
3. **pricing 的计算责任。** 共享行二阶时，标准对偶行 pricing 已出现二次目标，不能免费继续用线性背包 oracle。此提醒保留自原件和旧路线矩阵的“清点复核：恢复成本、信息层级与下一可判别义务”段。它不在此构成 pricing 的 NP 困难性证明，也不从 pricing 困难性推出整个强化系统的求解困难性。
4. **无界 sink 与一般结构生成分开。** [共同资格组的加权出口联合槽](../算法/共同资格组的加权出口联合槽--算法.md)不要求 sink 数固定，但仍用显式唯一 home、共同资格和等端重量；因此无界 sink 不能继续充作该受限类尚未解决的缺口。一般逐件资格、跨 home 和混合端成本仍不由该接口处理。[单 token 资格与端点成本](../障碍/单token共同资格与端点成本--障碍.md)给逐件异资格和异端费用的实际恢复反例，反驳的是压缩接口而非一般调度算法。

这些边界解释了 README 的“共同资产纠错与一般容量桥”身份：保留已修复的限域成果，同时准确交接一般结构生成义务。UM 主目标仍 OPEN；历史研究方向、内部审查与该工作区的存在均不改变这一状态。

### 槽匹配与配置间隙各自承担什么

已实读的[有序槽定理](../定理/有序单位槽的支撑最大件舍入--定理.md)把地基正面结论写成：给同一非负有理 T 剪枝分数解 x，每任务质量 1、每机分数负载 ℓ_i≤T，按时间非增切单位质量槽，以 Hall 得到一个覆盖所有原任务的共同匹配。第 r≥2 槽的整数费用可收给前一个完整槽，首槽至多为正支撑最大件 r_i，故**全部机器同时**有 L_i≤ℓ_i+r_i≤2T。零、空任务、跨槽、平局和大分母都在合同内。软件是给定 x 后的精确 BFS 恢复器；一般 LP 求解和目标搜索没有因恢复器存在而自动交付，已知数学 2 近似与完整软件必须分开。

反面地基由[双树配置证书](../障碍/双树配置证书的趋二整数间隙--障碍.md)承担：k≥4 时，完整原任务矩阵的整数 OPT=2−1/k，而阈值 T_k=1+1/k 有完整、非负、精确任务覆盖的配置证书。递推最后只按比例删除两根配置中的同一根间任务，使每根覆盖 1/2，不删除其他任务或整配置。因此 T_CONF≤T_k，而不是 T_CONF=T_k；有

\[
\frac{\mathrm{OPT}}{T_{\rm CONF}}
\ge\frac{2-1/k}{1+1/k}=2-\frac3{k+1}\to2.
\]

结合槽上界才得配置间隙上确界 2；某个有限实例不必取到 2。它否定的是对全部配置可行证书阈值 T 承诺 `(2−ε)T` 输出的合同，不否定相对真实 OPT 的一般 `(2−ε)` 算法，也不是 NP 近二归约。旧文献树高度索引有一层偏差的判断限定为原审查实际核的 arXiv v1，不能追认期刊版也有相同问题。

### “真实矩可行”与固定提取规则的精确分界

在[固定阶与事件链向量贪心审查](../审查/固定阶与事件链向量贪心双源审查--审查.md)的事件链部分，输入不是任意形式 PSD 矩，而是一个有限有理真实完整调度分布 μ；每个支撑调度都满足同一阈值 T。固定空间 `V=span{1,x_ij}`，对边指示 e 令 `A_e=Π M_e|_V`，状态由常数 1 开始，按一个预设任务顺序逐次选择使 `||A_e ψ||²` 最大的端并左乘更新。它不在每步重新条件化、更新分布或查询真实过去容量。

对每个 k≥2，已有事件链证明构造三机、全部处理时间正且有理、真实 OPT=T=1 的有限实例和一个固定顺序，全部选择严格，输出峰值大于 k−1/2。证明使用

\[
\|A\psi\|^2-\|(I-A)\psi\|^2
=\langle\psi,(2A-I)\psi\rangle;
\]

严格差经同事件 r 次复制仍至少为 `4^(−r)` 倍原差。支持子空间一维时，重复把状态逼近事件指示的正倍数；每次转移必须同时保持下一事件的严格多数与正内积，不能从平方质量为正推断有符号均值非零。所有基本事件先已有任务，后加副本不扩张 V；收敛只保证找到**有限**副本数，不把极限当实际任务。固定 k 和有限辅助数 B 后，取 N=k+B、d=1/(2kN)、a=1−Bd；每支撑机 1 负载≤a+Bd=1、机 2≤Nd=1/(2k)，另有单位固定任务给 OPT 下界 1，规则输出机 1 负载 `ka+Bd=k−(k−1)Bd>k−1/2`。一般 k 的副本数没有多项式上界承诺。

源 README 的“真实条件矩可行并不自动给固定 max-norm 左乘守容”应精确理解为以上特定接口的存在性坏源／坏顺序；它没有说所有最优分布都坏，更没有否定所有矩算法。已实读的独立原审查还记录一个可回收正面边界：若全部压缩算子两两交换，则由 `(A_e²−A_e)1=0` 传播到全部生成元，A_e 成为投影，V 对指示乘法封闭，更新等于真实交事件；最大评分保持非零交事件，最终实际调度仍在真实源支撑并守 T。这解释障碍来自遗忘共同支撑，而非真实分布不存在。

### R-3ca5：同质宏接口的真实假设与历史候选身份

### 给定sigma/tau的静态cover充分桥

已全文比较[共同激活复制审查](../审查/两份复制多数地板与共同激活复制障碍双源审查--审查.md)、[原始来源记录](../审查/多件共同激活复制原始来源记录--审查.md)及[私有需求/复制障碍](../障碍/私有需求组合与共享三维匹配复制--障碍.md)。在一般UM中给定两份完整实际调度sigma、tau，峰分别≤C、≤T且T≤C≤2T。对改变任务j记源s_j、目标t_j、两端时间a_j、b_j，f_i是不变任务负载，并置

\[
S_i=f_i+\sum_{s_j=i}a_j,\quad Q_i=\sum_{t_j=i}b_j,
\quad U=\max\{2T,C+T/2\},\quad h_i=(S_i+Q_i-U)_+.
\]

若改变任务集合R满足每源机cover及每目标机packing

\[
\sum_{s_j=i,j\in R}a_j\ge h_i,
\qquad \sum_{t_j=i,j\in R}b_j\le U-S_i,
\]

则先迁R、再迁其余改变任务，每阶段内任意顺序均保持全部机器负载≤U。承重恒等式是迁移W后负载S_i−D_i(W)+P_i(W)：第一阶段不超过S_i+P_i(R)≤U；迁完R后，不论后续次序都有S_i−D_i(R)+Q_i≤U。这里只给静态充分证书；找不到R不推出OPT>T，tau未知时也不能免费把它输入。

同一源机的a_j全相等、同一目标机的b_j全相等时，源下界ceil(h_i/q_i)和目标容量floor((U−S_i)/r_i)可放进带上下界整数circulation，给可计算特殊分支；一般异端时间不能擅自用件数替代真实负载。HOLD-EDGE只是在同一静态集合内把保留任务后移，没有扩大cover存在性。两机三任务的已知反例取T=3/4、C=5/4、U=13/8；tau实际可行，但每个必须迁移的首步把峰推到7/4或2，故“有目标即有安全首步”错误。

另一个方向也必须分开：三机六任务每源两件时间1，目标边依次A→B、A→C各3/5，B→A、C→A各3/10，B→C、C→B各1/5。T1、C2、U5/2，h=(1/10,3/10,3/10)，初始目标余量每机1/2。没有静态R同时满足cover/packing，但动态顺序B→A、A→B、B→C、C→A、A→C、C→B的峰仅23/10。因此“静态证书失败”既不能推出OPT>T，也不能推出没有U内动态路径。两机例是否定无条件路径存在，三机例是否定静态证书必要性，不能混作同一反例。

复制也不给该全输入桥：不交块满足OPT(disjoint union)=max各块OPT；共享同机将每任务复制k份，若F为assignment-LP最优值、O_k为复制后整数最优，S=max_iΣ_{j:p_ij有限}p_ij，则kF≤O_k≤kF+S，O_k/k趋F。前者不放大gap，后者会整数化分数解；binary k可能使显式nk输出超出输入位长多项式。私有需求串接的精确min、固定根门的max/min及parity共享复制反例是相关但不同操作，不将它们统称所有复制都失败。

### KDM完整层不足与直接robust源的后续排除

[高维配额审查](../审查/三维匹配与高维配额部分障碍双源审查--审查.md)把普通完整KDM matching与所有部分层明确分开。K-均匀超图有q条边，nu_t为最多可同时选择的边数，每条所选边只领t个资源、全局资源不交。在根需求q、边点需求K、资源终端的给定需求树合同中，

\[
b^*=\max_{1\le t\le K}\min\{\nu_t/q,t/K\}.
\]
