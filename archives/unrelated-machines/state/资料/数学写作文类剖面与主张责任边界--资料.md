## Research article

研究文章的依赖顺序是：精确问题 → 相关缺口 → 贡献 → 假设与方法 → 结果 → 含义与边界。每项贡献要连到先前工作中的具体未解问题或限制；历史、技术、比较或实证主张应把引用放在支撑它的语句旁；假设应靠近使用它的结果或方法；结论解释机制、边界、可检验含义或开放问题。作者第一人称只有在说明 agency 时使用具体动词（derive、characterize、establish、construct、compare）。

这与第二阶段的“准确结论、推导/失败机制、用途和如何接续”相配，提醒正文不能只有结果标题而缺少对象、缺口和承重条件。

## Theorem-proof exposition

定理证明文的依赖顺序是：数学需要 → 定义/假设 → 结果 → 证明依赖 → 推论或反例。定理陈述必须原子化，包含对象、假设、量词和结论；证明先给关键构造、恒等式或归约，方程旁说明依据，精确引用此前定义/引理/定理；结果成立后即结束，remark 只有在改变解释、范围或后续用途时才保留。反例和 failed converse 是数学结果，不应作为可删的风格附注。

这条 profile 为当前六人 SPE 清洗提供直接检查点：正式页已经分别保留定义域、量词、条件结论、有限实验、障碍和原模型反例；任何把反例删成“写作 caveat”的改动都违反该边界。

## Textbook/lecture explanation

教材/讲义顺序是：具体问题或障碍 → 定义 → 最小例子 → 结果 → 解释或练习。术语在读者需要时引入；一个可复用例子可以贯穿多个定义和结果；难的转换要解释，例行代数可压缩；练习只有在完成证明、测试定义、建立依赖或扩展结果时保留。

该规则只约束解释层，不改变数学对象的真值，也不能把一个最小例子的行为外推成全类定理。

## Statistical 与 computational/empirical profiles

统计理论/方法/结果的顺序是：问题与总体 → 设计、模型和 estimand → estimator/procedure → 假设与不确定性 → 结果 → 解释与范围。必须分开 descriptive、associational、predictive、causal 和 decision claims，各自保有自己的支持和范围。

计算/实证分析的顺序是：目标量 → 数据或模拟设计 → estimator/algorithm → uncertainty/error → evidence → 局部结论。需要报告参数、样本量、seed policy、时间网格、容差和 benchmark；区分 Monte Carlo uncertainty、离散化误差、模型误差和测量误差；并说明限制方向和后果。

在本次六人 SPE 清洗中，有限 Fraction/整数重放和代码复现只能按这些规则标为 computational evidence；它们不能替代 theorem-proof 的全量词证明或真实调度解码。

## Visual companion 与 authorial voice

视觉伴随的顺序是：概念问题 → 最小正式陈述 → 视觉/数值构造 → 简洁解释。主课程源决定符号和范围；一幅图只承担一个主要解释任务；caption 描述编码，解释段说明分析含义；读者应能读出 encoding、pattern 和数学联系。

作者声音应是稳定作出数学判断的方式，而不是堆叠高贵短语。直接句子、精确动词、自然的段落长短差异和一个技术对象一个名称，有助于复核推导、建模选择和解释。
