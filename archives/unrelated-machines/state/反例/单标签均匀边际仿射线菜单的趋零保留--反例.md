# 对象分离与来源

这是**单标签边际均匀**的显式反例族，主值是 $1/(R-1)$。它不同于多primary的pairwise-independent simplex族。本批最初比较时，既有[仿射线单primary与单边际趋二双源审查](../审查/仿射线单primary与单边际趋二双源审查--审查.md)虽在前言和末尾列本ID，却在第3节实际展开另一个 `UM-TAGGED-AFFINE-LINE-PI-SIMPLEX-TINY-VALUE-v1`（其R⁴ states与 $2/(R+1)$ 公式）。pairwise均匀当然蕴含单标签边际均匀，所以旧PI反例在逻辑上也能说明更弱的单边际约束不足；但它不能代表185这份R-states/helper构造、精确V=1/(R−1)与其独有证明已经逐项吸收。这里未指出旧PI数学错误，缺口在来源身份和完整去向。该节不能作为本ID的完整正文去向。本页补齐本对象自己的完整构造、任意选态/partial的上下界、全部原任务和padding证明，不把两个反例合并。

# 定义域、完整几何与状态权

对每个素数 $R\ge3$，场为 $\mathbb F_R$。取互异变量tags $u_a,v_a$，$a\in\mathbb F_R$；每变量x有完整资源平面 $\{x\}\times\mathbb F_R^2$。线

\[
L_x(\ell,j)=\{(x,z,\ell z+j):z\in\mathbb F_R\}.
\]

组为一个main M及helpers $H_{a,j}$，其中 $a\in\mathbb F_R,j\ne0$。所有组均有**恰R个indexed states**；每个state支持是其参加变量的整条线之不交并，所有零权incidences也保留。每state非负有理权和恰1。每组选一个state、领取其任意子集，跨组真实资源不交，允许闲置；最大最小所领质量记V。

**Main。** M参加全部R个 $u_a$，截距皆0，state $t\in\mathbb F_R$ 在每个变量上slope均为t。记

\[
B_a=\{(u_a,z,az):z\ne0\},\qquad P_a=(v_a,1,0).
\]

state t只在 $B_t$ 的R−1点各给权 $1/(R-1)$，其它完整线点权0。B_t确在u_t的slope t、截距0线；不同a的B_a带不同tag。

**Helper。** $H_{a,j}$ 参加 $u_a,v_a$，两变量截距皆j。state $\ell\in\mathbb F_R$ 的两个slopes为 $\ell$ 和 $\ell-a-j$。它只有一枚权1点：

\[
\begin{cases}
(u_a,j/(a-\ell),aj/(a-\ell)),&\ell\ne a,\\
P_a,&\ell=a.
\end{cases}
\]

其它全部完整line点权0。第一分支分母非零、z非零，且 $\ell z+j=az$，所以点同时在helper原line与B_a。第二分支的v_a slope为−j，所以P_a也在原line。没有对0求逆，也没有只用正支持替代完整线几何。

u_a的incident groups为M（截距0）和R−1个helpers（截距j≠0），degree R；v_a只有后者，degree R−1。截距均注入，变量degree≤R。

每组给R个states的均匀分布。Main在各incidence的标签为t；helper标签为 $\ell$ 和 $\ell-a-j$，都是state index的置换，故每个incidence每个slope概率恰1/R。这是显式局部分布，不依赖未知YES witness。

# 任意选态和partial分配的精确值

对固定helper $H_{a,j}$，当 $\ell\ne a$ 遍历时，$z=j/(a-\ell)$ 遍历全部非零元素。因此它可选择的唯一正点恰为B_a的任一点或P_a；helper未被预绑某一B点。

对任意最小质量μ>0的合法分配，每个helper必须领取其所选state的唯一权1点。Main可任选state t；block t的R−1个helpers须从 $B_t\cup\{P_t\}$ 的R点中取R−1个不同点，最多一个fallback P_t，因而至少占掉R−2个B_t点。Main正权全在B_t，最多领一枚，得 $\mu\le1/(R-1)$。μ0也满足此上界。该论证覆盖全部helper选态、全部其它blocks及任意形状partial子集。

达到取任意t（例如0）：

| 组 | 所选state | 所领取的真实正点 |
| --- | --- | --- |
| Main M | t | $(u_t,1,t)$。 |
| $H_{t,1}$ | $\ell=t$ | $P_t=(v_t,1,0)$。 |
| 其余所有 $H_{a,j}$ | $\ell=a-1$ | $(u_a,j,aj)$。 |

非main block的helpers正好匹配整个B_a；main block避开z1给main，剩余helper用不同v_t tag的fallback。不同a的tags隔离，全部helpers同时取得质量1，main取得 $1/(R-1)$，没有遗漏非main块的正质量要求。因此

\[
\boxed{V=1/(R-1).}
\tag{1}
\]

R3时所述剩余j依然合法，值1/2；R2不在正式域，不自行扩大它。

# 完整普通UM的所有原任务

每indexed state一台private，每真实资源一台resource；每group一件selector只在本组各private上时间1。每个完整state-resource incidence是一件不同原job，只能在自身private时间p或对应resource时间1，其余无穷。所有未选states和零私时jobs均存在，无额外guard/预载/模式。

上界将selectors放上述所选states，仅外送所领正点对应原jobs，其余全部留自身private。Selected main负载为

\[
1+(R-2)/(R-1)=2-1/(R-1),
\]

selected helpers为1、unselected private为1、resources至多一unit。全部原任务恰一次，零私时jobs停private不增负载。

下界取任意完整调度峰C。C≥2已满足所需界；C<2时每selected helper的权1正incidence不能与selector1同处private，必须外送，且每resource最多一件unit。Main实际state记t，block t的helpers遂在 $B_t\cup\{P_t\}$ 占R−1个不同正点，至少占B_t中R−2点；main至多外送一件positive job，其余正质量与selector保留在selected private，峰至少 $2-1/(R-1)$。任意未选状态额外exports只多占资源，零job外送不减少main正工作量。因此

\[
\boxed{\operatorname{OPT}(P)=2-1/(R-1).}
\tag{2}
\]

这是同一完整普通实例的精确值，不是只执行所选子实例或删除零任务的值。随R趋大，V趋0、实际OPT趋2，但该可显式求值族不提供计算困难性。

# 共同arity/R-partite的零权padding及双向保值

parts以 $c\in\mathbb F_R$ 编号：u_a置part a，v_a置part a+1（两者不同）。对每helper与其它R−2个parts c，增加只属于它的fresh变量 $w_{a,j,c}$，截距0，state ℓ的slope为ℓ，整条R点线权全0。

每helper此时arity R、每part恰一个变量；main原已有此性质。Fresh degree1，均匀选ℓ仍使新incidence标签均匀，state总权不变。原allocation不领新点可扩展；任意padded allocation删除新零质量点不改质量且保持原资源互斥，故V双向相同。原schedule把所有新增零jobs留原private即可同峰扩展；任意padded schedule删新增jobs/资源机后旧资格不变、负载不增，故OPT也双向相同。新增任务在上界真实执行，不是从输入静默删除。

设 $n=1+R(R-1),S=Rn$。精确计数为：

| 对象 | 基础族 | Padding后 |
| --- | --- | --- |
| Groups / indexed states | n / S | 同左。 |
| 变量数 | 2R | $v'=2R+R(R-1)(R-2)$。 |
| 真实resources | $2R^3$ | $v'R^2$。 |
| 完整incidences | $I=R^3(2R-1)$ | $I'=R^3n$。 |
| Machines / jobs | $S+2R^3$ / $n+I$ | $S+v'R^2$ / $n+I'$。 |
| Finite entries | $S+2I$ | $S+2I'$。 |

Dense矩阵是相应machines与jobs乘积。有限时间仅0、$1/(R-1)$、1，位长O(logR)；支持生成、场运算、达界状态/资源和全部job assignment按显式poly(R)规模构造，不声称仅binary R输入的poly(logR)输出，也不需OPT oracle。

# 单边际、pairwise与其它仿射线结果的边界

Main两个旧变量labels恒相等；helper两个旧labels恒相差常数，联合支持仅R对，pairwise-independent uniform应有R²对。Padding新labels仍完全由ℓ决定，不能修复这一失败。因此该反例只否定“真tagged LINE+均匀单标签边际+任意state norm1权足以保统一正常数partial值”。它不反驳要求primary与auxiliary**pairwise**均匀的单primary正面定理，也不认证或排除Chan/LST pairwise-independent code-coset困难像。

同样，它不属于宽矩形半保留的自动应用：main及helper标签关系是一维确定性关系，完整Cartesian子矩形若一个坐标有两种值、其它固定，就违反关系，故各A都只能singleton；不能从每个坐标的均匀边际反推出大L。资源几何相同并不使菜单自由度相同。

旧双源页第3节PI-simplex的R⁴ states、多个primary、$2/(R+1)$ 值与本页每组Rstates、单边际相关标签、$1/(R-1)$ 是不同对象。这里只指出目录正文的身份区别，没有用本五源代替simplex的独立证明或把其CSP值移到本例。本例没有声明源CSP最大满足比例、CONFIG新值/gap、NP-hardness或源YES/NO承诺。
