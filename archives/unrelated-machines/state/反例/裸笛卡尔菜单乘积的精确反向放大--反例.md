# 裸笛卡尔菜单乘积的精确反向放大

对下面定义的每个整数 \(t\ge1\)，令 \(D=2^t\)。任意选原菜单状态、领取任意部分资源且组间不交时，其最优最小保留比例为
\[
\boxed{V_t=1-\frac1D}.
\]
把全部菜单编成下述普通 unrelated-machine 矩阵 \(P_t\)，保留所有已选和未选状态的实际任务，则
\[
\boxed{\operatorname{OPT}(P_t)=1+\frac1D=2-V_t}.
\]

量词覆盖这一个显式族的所有 t，不是任意 UM 输入。每个状态支持本身仍是纯 Cartesian 积；自由度是组 g 可以根据整个 g 选择状态标签 \(\ell(g)\)，并从该状态领取任意子集。既不要求标签逐坐标独立，也不要求领取的子集本身为 Cartesian 积。源资源保持真实共享，没有在乘积时私有化。

这个例子使基例 \(V_1=1/2\)、实际 OPT=3/2 的 NO 在裸乘积后趋近单位可行，而不是自动得到 \(V_1^t\)。它只否定指定的无附加一致性约束的通用放大合同，不排其它产品、受限困难图像或新的实际一致性构造，也没有给出 NP 困难源。

## 1. 完整对象与值的定义

所有向量属于 \(\mathbb F_2^t\)，加法均模 2。组由 \(g\in\mathbb F_2^t\) 编号，每组有全部 \(\ell\in\mathbb F_2^t\) 个 indexed states。真实资源为
\[
u=(a,b)\in\mathbb F_2^t\times\mathbb F_2^t.
\]
状态支持定义为
\[
S_{g,\ell}=\{(a,b): b_i+g_i a_i=\ell_i,\ 1\le i\le t\}.
\]
每个 a 给唯一 b，所以一个状态含 D 个不同资源，每项 private 权为 \(1/D\)，总质量 1。

基例 t=1 中把资源写为 \(u=2a+b\)，两组的菜单是
\[
g=0:\{0,2\},\{1,3\};\qquad
g=1:\{0,3\},\{1,2\}.
\]
一般 t 的支持就是这些坐标支持的 Cartesian 积。固定 \((g,\ell)\) 后，每坐标条件只涉及本坐标；这不限制跨不同组选择标签的函数 \(\ell(g)\)。

V_t 是以下有限优化问题的值：每组选择一个状态 \(\ell(g)\)，再选任意子集 \(B_g\subseteq S_{g,\ell(g)}\)，要求不同组的 \(B_g\) 不交，允许资源不用，最大化
\[
\min_g\frac{|B_g|}{D}.
\]

### 普通调度矩阵 \(P_t\)

每个资源有一台机器 \(R_{a,b}\)，每个 indexed state 有一台 private 机器 \(M_{g,\ell}\)。

- 每组一件不可拆 selector 任务 \(J_g\)，只可在该组所有 \(M_{g,\ell}\) 上运行，时间为 1。
- 对每个 \((g,\ell,u)\) 且 \(u\in S_{g,\ell}\)，都有一件不同的实际 incidence 任务 \(I_{g,\ell,u}\)。它只有两个有限端：在 \(M_{g,\ell}\) 耗时 \(1/D\)，在 \(R_u\) 耗时 1。
- 其余端不可用，没有预载或附加任务。所有未选状态的全部 incidence 也实际存在，必须安排。

任务是不同的不可拆对象：不同组或状态可以有对应同一资源的任务，它们不会因资源名相同而合并。实际调度的下界必须管全部任务，不能只检查一个部分资源分配。

## 2. 任意状态选择的共同资源上界

任取 g，令补组 \(h=g+\mathbf1\)。由于 \(t\ge1\)，两组不同。无论选择何种 \(\ell(g),\ell(h)\)，一个共同资源须满足
\[
b_i+g_i a_i=\ell_i(g),\qquad
b_i+(g_i+1)a_i=\ell_i(h).
\]
相加得到唯一解
\[
a_i=\ell_i(g)+\ell_i(h),\qquad
b_i=\ell_i(g)+g_i a_i.
\]
所以这两个完整支持总是恰交一枚真实资源。

若两个领取子集都达到 D，它们就各等于其完整支持，会在该资源相交。因此至少一组最多领取 \(D-1\) 项，对任意状态选择和任意部分分配都有
\[
V_t\le1-\frac1D.
\]
这里用的是任意状态的补组交点；仅对某组固定状态求全局并集大小不能替代这一上界。

## 3. 跨坐标循环选择与精确达界

把坐标按环编号，约定 \(g_{t+1}=g_1\)。选择
\[
\ell_i(g)=g_{i+1},
\]
并领取
\[
B_g=\{(a,b):a\ne\mathbf1,\quad b_i=g_{i+1}+g_i a_i\text{ 对每个 }i\}.
\]
这个标签确在原菜单中，每个 a≠1 给一个合法资源，每组恰 \(D-1\) 项。

证明这些子集不交。若同一 \((a,b)\) 同时属于 g、h，令 \(\delta=g+h\)，两组等式相加给
\[
\delta_{i+1}=a_i\delta_i.
\]
因为 a≠1，至少一个坐标 r 有 \(a_r=0\)，于是 \(\delta_{r+1}=0\)。沿整个坐标环依次推出所有 \(\delta_i=0\)，故 g=h。这是对全部组的真实资源不交证明，不是各组分别可行。

因此
\[
V_t\ge(D-1)/D,
\]
与上界合并得到精确值。t=1 时环就是自身，唯一保留 a=0，仍可推出 \(\delta=0\)，没有退化漏洞；t=0 不属于对象。

该方案的每个状态仍是原纯积状态，且领取的 B_g 允许为一般子集。不能以“每个状态是 Cartesian”推断 \(\ell_i(g)\) 必须只依赖 \(g_i\)。后者是另一个实质限制，见[逐坐标一致菜单的整数资源配额](../定理/逐坐标一致菜单的整数资源配额--定理.md)。

## 4. 全部实际任务的达界调度与下界

上界调度把 \(J_g\) 放在 \(M_{g,\ell(g)}\)，仅把该已选状态中对应 \(B_g\) 的 \(D-1\) 件 incidence 放到各自资源机。其余所有 incidence 都留其原 private 机，包括全部未选状态的 D 件任务。

于是每台已选 private 机器有一个单位 selector 和一件 \(1/D\) 的 incidence，负载恰 \(1+1/D\)；每台未选 private 机器负载恰 1；每台资源机器至多接一件 unit。所有 \(D^3+D\) 件不同原任务恰执行一次，得到
\[
OPT(P_t)\le1+1/D.
\]

再取任意完整实际调度，峰记为 C。若 C≥2，则下界平凡。若 C<2，每个资源机至多执行一件 unit incidence。选任意补组 g、h，由它们 selector 的实际目的地读取实际状态 \(\ell(g),\ell(h)\)。两状态共同资源对应的是两件不同实际任务，不能都送到同一资源机。因此至少一件仍在自己的已选 private 机器上，与该组 selector 共处，负载至少 \(1+1/D\)。

任意未选状态任务若也外送，只会额外占用资源，不能消除上述两件任务的冲突。由此对所有完整实际调度得到相反下界，证明精确 OPT。部分分配和完整调度分别给了证明，没有把“已选状态存在不交子集”直接当作所有任务已经执行。

## 5. 显式规模、位长与参数

| 对象 | 数量 |
|---|---:|
| 组 | D |
| indexed states / private 机器 | \(D^2\) |
| 资源机器 | \(D^2\) |
| incidence 任务 | \(D^3\) |
| selector 任务 | D |
| 全部机器 | \(2D^2\) |
| 全部任务 | \(D^3+D\) |
| 有限处理时间条目 | \(2D^3+D^2\) |
| 若要求完整 dense 矩阵的条目 | \(2D^2(D^3+D)\) |

selector 共提供 \(D\cdot D=D^2\) 个端，incidence 每件两个端。向量标签及 \(1/D\) 的二进制位长为 O(t)。逐项生成矩阵、状态选择、资源领取和全部实际调度，对完整显式编码长度是多项式时间；不声称输出 \(\Theta(8^t)\) 件任务能在 poly(t) 时间完成。

每资源 (a,b) 在每组 g 的菜单并集中恰出现一次，因为对应标签被唯一确定为 \(\ell=b+g\odot a\)。因此其跨组度为 D，会随 t 增长，不是固定度三族。若后来调用精确保实际 OPT 的正规形转换，转换只能保留这里已经下降的值；不能仅从改变表示或降低度数推出 NO gap 恢复。本定理无需以该转换作为证明前提。

## 6. 与完整矩阵平方的对象关系

t=1 时把 \(J_g\) 重命名为 \(A_g\)、\(M_{g,\ell}\) 为 \(S_{g\ell}\)、\(I_{g,\ell,(a,b)}\) 为 \(B_{g\ell a}\)（\(b=\ell+ga\)），完整 \(P_1\) 就是[完整矩阵Kronecker反例](完整矩阵Kronecker偶次幂坍缩--反例.md)的八机十任务基例。但本页先对菜单支持作积、再按 selector/incidence 编译；完整矩阵 Kronecker 积保留全部任务和机器元组。二者在 t=2 已是不同矩阵：

| 对象 | 机器 | 任务 | 有限边 | 实际OPT |
|---|---:|---:|---:|---:|
| 本页 \(P_2\) | 32 | 68 | 144 | \(5/4\) |
| \(P_1^{[2]}\)，完整处理时间矩阵平方 | 64 | 100 | 400 | 1 |

本页只有4件 selector、64件 incidence，以及16台private、16台resource机器。完整平方另有 selector×incidence 和 incidence×selector 的32件真实任务及32台混合机器，incidence×incidence 也保留混合机器端。它们不能被删去后仍声称是完整矩阵平方。本页5/4与另一对象的1都有各自完整证明，不能互作同一矩阵的界。

本页反驳“基例 \(V\le\eta\) 自动推出同一裸菜单 product 的 \(V\le\eta^t\)”：取 \(\eta=1/2\)，实际 \(V_t=1-2^{-t}\) 趋1。该失败来自组可跨坐标重新选择原状态并领取一般子集，区别于某些其它产品损失 YES 完备性的机制，也不否定所有张量放大方法。
