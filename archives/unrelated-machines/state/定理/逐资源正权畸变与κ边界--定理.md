# 逐资源正权畸变与κ边界

本文整理一个有明确输入域和外部算法接口的实际近二界。它处理完整显式 flat 菜单，允许任意菜单数、任意资源跨组度和 \(W_x\le1\)，但近似因子依赖同一资源上出现的正 private 权畸变
\[
\kappa(P)=\max\!\left(\{1\}\cup
 \left\{\frac{\max P_u}{\min P_u}:P_u\ne\varnothing\right\}\right),
\]
其中 \(P_u\) 是资源 \(u\) 上所有正 private 权组成的多重集。零权不进入比值，unused 或全零资源不会产生 \(0/0\)。\(\kappa\) 只用于分析，不由算法按数值循环。

对每个固定实常数 \(\alpha>4\)，在下述域内存在确定性总位多项式解码器；它不接收 \(\mathrm{OPT}\)、最优调度、配置证书或 \(\kappa\) 上界作为输入，输出全部原 jobs 的具体合法分配 \(\sigma\)，满足
\[
 C_{\max}(\sigma)\le
 2-\frac{2-\mathrm{OPT}(P)}{\alpha\kappa(P)}
 \le\left(2-\frac1{\alpha\kappa(P)}\right)\mathrm{OPT}(P).
\tag{1}
\]
固定 \(\alpha\) 的内部常数和运行次数可以依赖 \(\alpha\)；本文不声称把 \(\alpha\) 作为输入时的统一多项式次数。

## 1. 完整输入域和量词

输入是有限非空组集 \(G\)。每组 \(g\) 有非空显式 indexed state 集 (S_g)；把一个 state 写成 (x=(g,s))，其资源集合 \(S_x\) 内部不重复，private 权 \(p_{xu}\ge0\) 是二进制有理数，并满足
\[
W_x=\sum_{u\in S_x}p_{xu}\le1,\qquad b_x=1-W_x.
\]
允许零项、空 incidence 集、重复 indexed states 和显式 unused resources。

机器与任务是完整 ordinary flat UM 合同：

- 每个 state 有独立 private 机器 \(M_x\)，每个资源 \(u\) 有资源机器 \(R_u\)，两类机器彼此不同；
- 每组恰有一件 selector，只能在本组各 \(M_x\) 上运行，处理时间为1；
- 每个显式 incidence \((x,u)\) 是独立的一件原 job，只能在 \(M_x\) 上用时 \(p_{xu}\)，或在 \(R_u\) 上用时1；
- 没有其它任务、资格、预载或隐藏约束，所有未选 states 的原 jobs 也实际存在。

定理对这个域中的每一个输入成立。非空 \(G\) 使 selector 给出 \(\mathrm{OPT}\ge1\)。空组集不属于式 (1) 的中间不等式链；若单独需要，可直接输出空任务分配。

## 2. W≤1 域的 baseline 实际值

对每组 \(g\) 选择一个两两不交的资源子集 \(B_g\)。定义
\[
 f_g(B_g)=
 \max_{x\in S_g}
 \left(b_x+\sum_{u\in B_g\cap S_x}p_{xu}\right),
 \qquad
 V=\max_{B_g\ {\rm pairwise\ disjoint}}\min_g f_g(B_g).
\tag{2}
\]
这是带 baseline 的值；当 \(W_x<1\) 时不能把它偷换成只计原资源的旧菜单值。由 \(b_x+W_x=1\) 和有限显式域，
\[
0\le V\le1.
\]

### 2.1 从 \(V\) 到完整调度

给出达到式 (2) 的 \(B_g\)。每组取一个达到 \(f_g\) 的 state \(x\)，将 selector 放在 \(M_x\)，并把该 state 中 \(B_g\) 的 incidence 导出到对应资源机器；其余原 incidence（包括零权与未选 state 的 jobs）留在自己的 private 机器。

所选 private 机器负载为
\[
1+\sum_{u\in S_x}p_{xu}
-\sum_{u\in B_g\cap S_x}p_{xu}
=2-\left(b_x+\sum_{u\in B_g\cap S_x}p_{xu}\right)
\le2-V.
\]
未选 private 机器负载至多1，资源机器至多承载一件 unit job，因而得到完整实际调度
\[
\mathrm{OPT}(P)\le2-V.
\tag{3}
\]

### 2.2 从任意低峰完整调度回到 \(V\)

反向只在 \(C<2\) 时使用资源机器的 unit 独占。读取每个 selector 实际所在 state \(x\)，令 \(B_g\) 为该 state 实际导出到资源机器的资源集合。每个资源最多承载一件 unit job，所以这些 \(B_g\) 两两不交。所选 private 机器负载不超过 \(C\) 给出
\[
b_x+\sum_{u\in B_g\cap S_x}p_{xu}\ge2-C.
\]
因此 \(V\ge2-C\)。若 \(\mathrm{OPT}=2\) 而 \(V>0\)，式 (3) 会产生峰小于2的调度，矛盾。全 private 调度始终给峰至多2，于是
\[
\boxed{\mathrm{OPT}(P)=2-V.}
\tag{4}
\]
这也包含 \(V=0\) 和 \(\mathrm{OPT}=2\) 的端点；恰在峰2时不把两件 unit 强行判为冲突。

## 3. Restricted Santa 中间实例及两侧值界

为每个 state \(x\) 建一个 Santa player。对每个存在正 private 权的资源 \(u\)，只建一件 real item，固有值
\[
q_u=\min\{p_{xu}:p_{xu}>0\},
\]
并让它只对在该资源上具有正权的 players 有价值。对 \(b_x>0\) 建一件只属于 player \(x\) 的 baseline item，固有值 \(b_x\)。每组 \(g\) 再建 \(|S_g|-1\) 件互异 dummy，固有值1，只对本组 players 有价值。资源不能按 incidence 复制成多件 real item。

令 \(V_-\) 是这个 restricted additive Santa 实例的最优最小 player value。则
\[
\boxed{\frac{V}{\kappa}\le V_-\le V\le1.}
\tag{5}
\]

左侧：由式 (2) 的两两不交 \(B_g\) 见证，给达到 \(f_g\) 的 player 分配其收到的 real items 与 baseline，其余本组 players 各取一件 dummy。由于
\[
q_u\le p_{xu}\le\kappa q_u,\qquad
b_x+\sum q_u\ge
\frac{b_x+\sum p_{xu}}{\kappa},
\]
得到最小 value 至少 \(V/\kappa\)。

右侧：任意 Santa 分配中，每组至少有一个 player 没有本组 dummy。按组取一个这样的 player；其 real items 彼此不交，且
\[
\text{该player的value}
\le b_x+\sum_{u\in S_x}q_u
\le b_x+\sum_{u\in S_x}p_{xu}
\le1.
\]
把它收到的资源集合视作 \(B_g\)，即可得到原式 (2) 的值不小于 Santa allocation 的最小 value，再对最优 allocation 取值即得 \(V_-\le V\)。当 \(V=0\)、\(b_x=0\) 或资源全零时仍按同一不等式处理；没有假设每个 baseline 必须被分配。

## 4. 外部 restricted-Santa 算法与全部原 jobs 解码

固定一个有理数 \(a\) 满足 \(4<a<\alpha\)。来源合同调用 Cheng–Mao 的 restricted Santa Claus Theorem 1（固定 \(4+\delta=a\)），得到确定性实际物品分配，其最小 player value \(t\) 满足
\[
t\ge\frac{V_-}{a}\ge\frac{V}{\alpha\kappa}.
\tag{6}
\]
本文接受该已发表算法的完整固定参数合同，不重证其局部搜索、Build/Collapse 或未知目标处理，也不把配置 LP 当成已实现的免费 oracle。

对每组选择一个没有本组 dummy 的 player \(x\)，把原 selector 放到 \(M_x\)。该 player 收到且具有正价值的 real items 对应的原 incidence 导出到其原资源机器；其余所有原 jobs（包括未选 states、零权 jobs 和没有对应 real item 的 incidences）留在自己的 private 机器。

解码合法性逐项如下：

- real items 的 restricted 分配不交，所以每个资源机器至多得到一件 unit job；
- 即使所选 player 没有收到自己的 baseline，也有
  \[
  t\le b_x+\sum_{\text{received }u}q_u
  \le b_x+\sum_{\text{exported }u}p_{xu},
  \]
  从而其 private 负载不超过 \(2-t\)；
- 其它 private 机器的原 state 总质量至多1，故不超过 \(2-t\)；
- 新增 Santa item 不会替代或删除任何原 job，输出是完整原矩阵上的具体调度。

结合式 (4) 和式 (6)，得到第一段
\[
C_{\max}(\sigma)\le
2-\frac{2-\mathrm{OPT}(P)}{\alpha\kappa}.
\]
令 \(O=\mathrm{OPT}(P)\in[1,2]\)、\(c=1/(\alpha\kappa)\in(0,1)\)，则
\[
(2-c)O-\left[2-c(2-O)\right]
=2(1-c)(O-1)\ge0,
\]
得到式 (1) 的第二段。

## 5. 复杂度、位长与接口边界

设显式 state 数为 \(S\)、原 incidence 数为 \(I\)、资源数为 \(U\)。Santa 中间实例至多有 \(S\) 个 players、\(U+2S\) 件 items；dummy 资格表和 baseline/real 值均由输入显式表扫描产生。输入有理数只做求和、比较和固定有理倍，分母位长按输入总位长支付，不按数值大小复制物品。算法不按 \(\kappa\) 的数值迭代。

固定 \(\alpha\) 时选择一个固定有理 \(a\in(4,\alpha)\) 即可；若把 \(\alpha\) 作为输入，则本文没有承诺统一次数或精确实数比较。若自行改用几何目标网格，必须先取内部常数 \(a_0<a\) 并支付网格比；式 (6) 的无额外损失读法依赖直接导入完整的 \(a\)-近似算法合同。

来源审查还给出一种不损失因子的整数目标搜索：清分母后 Santa 最优值为整数，以 \(lo=0\)、\(hi=U_{\rm value}+1\) 维护 \(hi\) 严格高于真实最优值，固定参数时钟验证实际输出；成功提高 \(lo\)，失败降低 \(hi\)，结束时保存的 \(lo\) 达到真实最优。该说明仍只是接口补足，不等于本仓库提供了 Cheng–Mao 后端实现。

## 6. κ 统一有界时的反面源筛选

固定 \(\kappa_0\ge1\)。若某确定性多项式归约的所有输出都在本定理域内并满足 \(\kappa(P)\le\kappa_0\)，其 YES 输出有实际 \(\mathrm{OPT}\le1\)，NO 输出有实际 \(\mathrm{OPT}\ge2-\varepsilon\)，且
\[
\varepsilon<\frac1{\alpha\kappa_0},
\]
则可选固定有理 separator
\[
2-\frac1{\alpha\kappa_0}<\theta<2-\varepsilon.
\]
运行本算法并检查实际峰是否不超过 \(\theta\)，即可区分两种 promise。YES 的输出峰严格小于 \(\theta\)，NO 的任何实际调度峰严格大于 \(\theta\)。因此在 \(P\ne NP\) 假设下，该完整 flat 像类不能承载这种严格间隔的 NP-hard promise。

这是必要条件而非充分条件：令 \(\kappa\) 随输入或目标精度增长不会自动产生 NO gap；共同非单位容量、全部低载实际解码和物理一致性仍需另证。本文不推出一般 UM 的统一近似算法，也不把 κ 无界视为反例。

## 7. 与现有 private-tree 对象及有限证据的衔接

[三坐标零权切片的精确菜单嵌入](三坐标零权切片的精确菜单嵌入--定理.md)可把资源跨组度至多三的 flat 菜单精确保 \(\mathrm{OPT}\) 地表示到带零格的 \([3]^3\) 域，但它允许零格和 indexed 异成本；本定理的 \(\kappa\) 只比较正 private 权，不能把零格自动当成正项。[完整菜单的资源度三路径归约](完整菜单的资源度三路径归约--定理.md)保留 \(W\le1\) 与低峰全任务映射，但会增加 helper 组、port 和真实任务，也没有固定 \(\kappa\) 的承诺。[归一化菜单的三态资源度三正规形](归一化菜单的三态资源度三正规形--定理.md)可把 \(W=1\) 菜单压到三态并降资源度，却不限制同资源正权比，故不会单独产生固定 \(\varepsilon\)。

已有[资源失真平菜单的有限矩阵审计边界](../计算/资源失真平菜单的有限矩阵审计边界--计算.md)只保存945个普通矩阵案例、七个固定参数和精确分数运行记录；它与本定理的全域量词严格分开。本轮没有把 passed 或源程序哈希升级为一般证明，也没有重复执行该审计。
