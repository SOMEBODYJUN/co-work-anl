# 1. 模型与构造

给定普通 unrelated-machines 实例 (P)。任务 (j) 的有限端集合记为
(E_j)，端 ((i,j)) 的处理时间为 (p_{ij})。假设每个有限端满足
(0\le p_{ij}\le b)，其中 (b>0) 为共同有理数上界；任务至少有一个有限端。
该定理只处理这一显式矩阵模型，不把无穷端当成可选端。

对每个任务 (j)，令 (d_j=|E_j|)。取一棵有 (d_j) 个叶的满二叉树；
(d_j=1) 时树退化成一个叶。每个树节点 (v) 对应一台私有辅助机
(a_v)，这些机器与所有原机副本互异。加入以下新任务：

* 一个 root 任务，只能在根机上处理 (b)；
* 每个内部节点 (v) 一个 selector 任务，只能在 (a_v) 或两个孩子机上处理 (b)；
* 每个叶 (v) 一个 terminal 任务。若叶代表原端 ((i,j))，它在原机副本 (i) 上处理 (p_{ij})，在叶机 (a_v) 上处理 (b)，其它端为无穷。

因此每个新任务至多三端，所有辅助端均为 unit 端；原端的 small 数值被逐字复制。树共有 (2d_j-1) 个节点，新增任务数为
(1+(d_j-1)+d_j=2d_j)，辅助机数为 (2d_j-1)。全体构造大小对显式输入 (|P|) 线性（按端数计），不按数值 (b) 展开。

若要限定为 (\{b/k,b\}) 两值域，则原 small 端本来必须属于该集合；构造不会产生其它 small 值，也不会增加原机的 small 资格。辅助机不获得 small 端。

# 2. 从原调度到新调度

给定原实例的任意完整调度 (\sigma)，对每个 (j) 取被 \(\sigma) 使用的端对应叶 (v^*)。把该 terminal 分到原机副本 (i=\sigma(j))，其负载贡献正是
(p_{ij})；其余 terminals 分到自己的叶机，贡献 (b)。root 任务分到根机。

沿根到 (v^*) 的路径，每个 selector 分到下一孩子机；路径外的 selector 分到其自身节点机。于是每台辅助机恰有一个 (b)-任务，辅助负载为 (b)，而原机副本的负载等于原调度负载。因此

\[
 C(\tau)\le \max\{b,C(\sigma)\}.
\]

这里没有假定 (C(\sigma)\ge b)，所以该结论是上界而非逐值 OPT 恒等式。

# 3. 严格阈值下的收缩

反过来给定新实例的完整调度 (\tau)，并假设
(C(\tau)<2b)。所有辅助端的可用任务处理时间均为 (b)，故每台辅助机至多承载一个任务。

在每个 gadget 中，root 任务占据根机。若当前内部节点的 selector 不在当前节点机上，它只能在一个孩子机上；沿其实际去向继续走，最终到达某个叶。到达的叶机已被一个 (b)-任务占据，因此该叶 terminal 不能留在叶机，只能被分到其对应原机副本。把这一 terminal 所代表的原端选为 (\sigma(j))。

这给出每个原任务恰一个端：不同 terminal 是不同新任务，且每个 gadget 的根到叶选择只产生一个外送 terminal。对原机副本 (i)，被解码任务是新调度在该副本上承载的 terminal 的子集；由于处理时间非负，

\[
 \sum_{j:\,\sigma(j)=i}p_{ij}
 \le \operatorname{load}_\tau(i).
\]

所以 (\sigma) 是原实例的真实完整调度，且
(C(\sigma)\le C(\tau)<2b)。该论证使用严格不等式；若允许 (C=2b)，辅助机可能承载两个 unit 任务，路径解码不再由容量强制。

# 4. 由正规形近似器转移到原模型

设存在一个对上述三端 normal class 的确定性位多项式算法 (F)，其近似因子至多
(2-\varepsilon)，其中固定 (\varepsilon>0)。任选固定有理
(0<\eta<\min\{\varepsilon,1\})，令
(\alpha=2-\eta)（同一 (F) 也满足因子不超过 (\alpha)），并取
(g=1+\eta/4)。

先处理退化：空实例直接返回空调度；若每个任务都有 zero 端，则全体 OPT 为 0，逐任务选任一 zero 端。对一般情形，删去所有 (p_{ij}>b_t) 的端后若某任务失去全部端，则该阈值不可能覆盖原最优调度，跳过。令
(a_j) 为任务 (j) 的最短有限端，(L_0=\max_j a_j)，
(U=\sum_j a_j)。在存在至少一个无 zero 任务时，(0<L_0\le OPT(P)\le U\le nL_0)。

枚举网格 (b_t=L_0g^t) 直到首次 (b_t\ge U)。调用次数为
(O(\log(n+1)))，每个阈值有多项式位长。对每个阈值构造 (N_{b_t}(P_{b_t}))，运行 (F)，精确回算新调度负载；仅当回算值严格小于 (2b_t) 时应用第3节解码，并在所有成功解码的原调度中取实际峰值最小者。

取网格中首次满足 (b_t\ge OPT(P)) 的阈值。原最优调度的每个使用端均不超过 (b_t)，故保留在 (P_{b_t}) 中；第2节给出
(OPT(N_{b_t})\le b_t)。于是

\[
 C(\sigma_t)\le \alpha b_t
 < (2-\eta)(1+\eta/4)OPT(P)
 = (2-\eta/2-\eta^2/4)OPT(P)
 \le (2-\eta/2)OPT(P).
\]

若 (F) 在较低阈值偶然输出严格小于 (2b_t)，第3节仍只产生原实例真实调度，择优不会损害保证。所有构造、网格、回算和解码均按显式端数及输入有理数位长运行，不按 (b) 的数值大小循环。

# 5. 适用范围与未决项

该对象证明的是一个严格阈值下的可行性转移和一个条件算法转移。它不证明 normal class 存在 (2-\varepsilon) 算法，也不证明一般 UM 的近二正面或反面；不把新实例 OPT 与原实例 OPT 逐值相等。若某端 (p_{ij}>b)、允许辅助机获得 small 端、取消严格阈值或改变 terminal 的原端语义，均需另行证明。有限投影审计只支持已列有限样本，不提升为本定理的证明。
