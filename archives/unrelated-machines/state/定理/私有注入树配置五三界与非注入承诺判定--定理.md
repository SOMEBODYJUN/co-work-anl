# 私有注入树配置五三界与非注入承诺判定

## 模型和结论范围

有限非空 root 集合为 (U)。每个 (u) 有非空显式菜单 (S_u)。状态 ((u,s)) 是高度 (h\ge1)、分支数 (d\ge1) 的完全树；内部机器只在本状态内使用，状态之间以及不同 root 之间的内部机器均私有。root selector 在所选状态根上处理时间 1。每个内部节点有一件 incoming unit job 和 (d) 件 outgoing job，后者在父机处理时间 (1/d)，在各自 child 机处理时间 1；叶 outgoing job 只能在由显式映射 (f_{us}:[d]^h\to Z) 指定的一个外部机器上以时间 1 处理。没有其它端、预载或共享内部机器。

完整配置 LP `CONFIG(T)` 对每台机器取负载不超过 (T) 的配置，配置权非负且每台权重和为 1，每个原 job 的总覆盖恰为 1。配置采用向下封闭，因而“至少覆盖”与“恰覆盖”可相互稀释。非空 (U) 时 (OPT,T_{conf}\ge1)；空 (U) 单独约定 (OPT=T_{conf}=0)。

本条只覆盖上述完全私有、unit selector、父端 (1/d)、叶端 unit 的结构。它不覆盖共享内部机器、其它 processing times、叶多单位端、一般 unrelated-machines 实例，也不把结论升级为 UM-TARGET-v1 的一般算法或反例。

**定理（配置五三界）。** 若每个 (f_{us}) 单射，且 `CONFIG(T)` 可行，则：

1. 当 (1\le T<2)，令 (s=\lfloor d(T-1)\rfloor)、(a=d-s)。对任意整数 (1\le r\le a) 满足
   \[
   (a-r+1)^h\ge 2r^h-1,
   \]
   原完整实例存在纯调度，峰值至多 (2-r/d)。
2. 取 (r=\lfloor(a+2)/3\rfloor=\lceil a/3\rceil)，则条件自动成立，且
   \[
   OPT\le 2-\frac r d\le \frac53\Bigl(1+\frac{s}{d}\Bigr)\le \frac53T.
   \]
   (T\ge2) 时全父置给出峰值至多 2，因此同一上界仍成立。
3. 固定有理 (T<2) 的配置可行性有显式规模的精确有理线性系统；这说明配置阈值可判定，但不提供任意 (d,h) 下输出上述纯调度的多项式长度算法。

若 (f_{us}) 不单射，删除每个非单射状态作为 selector 候选，在剩余单射状态上解同一共同 (lambda) 线性系统：可行时承诺 `OPT≤5/3`，不可行或某 root 无候选时承诺 `OPT>1`。因此这是确定性总位多项式的 promise 判定器，区分 YES `OPT≤1` 与 NO `OPT>5/3`；中间带 (1<OPT\le5/3) 可任答。该判定器不输出调度，也不声称非单射原实例的配置间隙有 (5/3) 上界。

## 1. 配置边际的精确系统

对 (1\le T<2)，每个含 incoming unit 的内部机器最多再容纳

\[
s=\lfloor d(T-1)\rfloor
\]

件 (1/d) 的 outgoing small jobs。设该机器的 incoming unit 边际为 (q)，从它发出的第 (e) 个 job 在 child/外部端的 unit 边际为 (t_e)。在真实配置中，incoming 与 outgoing 同时出现的概率至少 ((q-t_e)_+)，故必要且充分的行条件是

\[
\sum_{e\text{ out of }v}(q_v-t_e)_+\le s q_v,
\qquad\text{等价于}\qquad
\sum_e\min(q_v,t_e)\ge a q_v. \tag{1}
\]

根边际 (y_{us}) 满足 (sum_s y_{us}=1)，内部 child 的 incoming 边际等于父 job 的 (t_e)，每个外部机器 (z) 满足

\[
\sum_{e:\,f(e)=z}t_e\le1. \tag{2}
\]

行式可写成有理 LP：引入 (z_{ve}\ge0)、(z_{ve}\ge q_v-t_e)、(sum_ez_{ve}\le s q_v)，并保留 (0\le q_v,t_e\le1)、根等式和外机容量行。规模与显式原 jobs、machines、树端点线性，(lfloor d(T-1)\rfloor) 可由精确整数运算得到。

充分性不是松弛：令 (c_e=(q-t_e)_+)。在 incoming 出现的质量 (q) 上，把长度 (c_e) 的区间段按模 (q) 串接；每点至多落入 (s) 段，因而每个配置至多放 (s) 件 small。没有 incoming 的质量 (1-q) 上放剩余边际。端点 (q=0,1) 直接退化。外机用叶 unit job 的 singleton 配置和 empty 补足 (2)。所得每个 job 两端覆盖恰为 1，所以 (1)-(2) 与 `CONFIG(T)` 等价。

## 2. (T=1) 的共同 \lambda 等价

当 (T=1) 时 (s=0)，(1) 强迫每个 outgoing job 的 unit 边际 (t_e\ge q_v)。沿状态树逐层下传，状态 ((u,s)) 的每个叶 unit 边际至少为根 selector 边际 (lambda_{us}:=y_{us})。故共同资源行必须满足

\[
\lambda_{us}\ge0,\quad \sum_{s\in S_u}\lambda_{us}=1,\quad
\sum_{u,s}|f_{us}^{-1}(z)|\,\lambda_{us}\le1\quad(z\in Z). \tag{3}
\]

反向给定 (3)，每个状态内部机以权 (lambda_{us}) 放 incoming unit singleton，以权 (1-lambda_{us}) 放全部 (d) 个父端 small；外机对每个真实 leaf job 放权 (lambda_{us}) 的 unit singleton，剩余放 empty。这样 selector、每个内部/叶 job 与每个外机都恰覆盖，故 `CONFIG(1)` 等价于 (3)。这一步按叶出现次数计数，即使 (f) 非单射也成立；单射只在后面的资源阻断数中使用。

## 3. 从配置证书抽取共同资源受限的 (a)-树分布

给定 `CONFIG(T)` witness。每个内部节点 (v) 的 incoming 边际为 (q_v)，每个 outgoing unit 边际为 (t_e)。对每个 root 先按 (y_{us}) 选一个真实状态。递归维护节点激活质量 (b_v\le q_v)，根处等号成立。由 (1) 及 (0<b_v\le q_v) 得

\[
\sum_e\min(b_v,t_e)\ge\frac{b_v}{q_v}\sum_e\min(q_v,t_e)\ge a b_v. \tag{4}
\]

从容量 (min(b_v,t_e)) 中装出总量 (a b_v)，记装出量为 (b_e\le\min(b_v,t_e))。向量 (b_e/b_v\in[0,1]^d) 且坐标和为 (a)，是 uniform-matroid base polytope 中点，可分解成“恰选 (a) 个 child”的有限分布。条件于节点激活按此分布选 child，令其激活质量为 (b_e)；于是 (b_e\le t_e=q_{\mathrm{child}}) 归纳成立，(b_v=0) 分支跳过。

这给每个 root 一份可能指数支持的有限随机满 (a)-叉高 (h) 子树分布；每个叶激活概率不超过原配置的 (t_e)，所以每个外部资源的总期望请求仍不超过 (2)。这是局部随机证书，不是多个 root 已经互不冲突的整数调度，也没有声称可在总位多项式时间列举其支持。

## 4. 阻断数、Haxell 匹配与真实负载

满 (a)-叉高 (h) 树中，命中每个满 (r)-叉高 (h) 子树的最小叶数为

\[
B_h=(a-r+1)^h. \tag{5}
\]

归纳理由是至少 (a-r+1) 个 child 必须被阻断，每个 child 的阻断数递推相乘。若 (f_{us}) 单射，则这些叶对应不同外部资源。把每个正权 (a)-树候选中的满 (r)-子树作为资源超边；每条超边含一个 root 和 (R=r^h) 个资源，故总边大小为 (R+1)。对任意非空 root 子集 (I)，资源侧任一 transversal 必须击中每个候选 (a)-树的所有 (r)-子树；用同一份配置导出的共同资源容量加权，得到

\[
\tau(H_I)\ge B_h |I|. \tag{6}
\]

所引用的 Santa-Claus 超图匹配定理（Asadpour--Feige--Saberi 作者稿 Theorem 2 及 Annamalai 版本 Theorem 1.1）要求资源侧 rank 至多 (k-1) 且 \(\tau(H_I)>(2k-3)(|I|-1)\)。取 (k=R+1)，阈值是 (2R-1)。若 (B_h\ge2R-1)，(6) 给出严格不等式，故存在覆盖全部 root 的匹配；(R=1) 退化为 Hall。

匹配选出每个 root 的一个真实状态和一个 (r)-子树，所有选中叶资源互异。对应原完整 jobs：激活内部机收 incoming unit、将恰 (r) 个 outgoing 向 child/外机、其余 (d-r) 个 small 留父，负载 (2-r/d)；未激活分枝及未选状态的所有 small 全留父，负载 1；外部机至多收一枚 unit。所有原 jobs 仍各覆盖一次，未生成新机器。

取 (r=\lfloor(a+2)/3\rfloor)。有 (a-r+1\ge2r-1)，且 ((2r-1)^h\ge2r^h-1)，所以 (5) 满足 Haxell 条件。又 (3r\ge a=d-s)，从而

\[
2-\frac rd\le\frac53+\frac{s}{3d}\le\frac53\left(1+\frac sd\right)\le\frac53T.
\]

这是存在性界；不等价于一个可输出纯策略的多项式算法。内部状态完全私有是回填所有未选分枝、保持原 jobs 的关键。

## 5. 非单射状态的严格 promise 判定

对每个 root 删除 (f_{us}) 非单射的状态作为 selector 候选，但不删除其机器或 jobs。若某 root 无剩余状态，输出 `NO`。

若原实例有实际峰值 \(\le1\)，所选 root unit 迫使其整棵状态树所有 leaf unit 外送；每个外部机最多容一枚 unit，故所选状态必须单射，并且各 root 选中的完整叶集合互异。其状态选择给过滤后的共同 \lambda 系统 (3) 一个积分可行点。因此过滤 LP 不可行只会输出 `NO`，不会拒绝任何 `OPT≤1` 输入。

若过滤 LP 可行，保留状态满足单射条件，前四节给出保留部分峰值 \(\le5/3\)。被过滤状态的 selector 从未取端；其全部原 small/edge jobs 留在各自私有父机，负载为 1，不占外机。这样得到原完整实例的峰值 \(\le5/3\)，不是删任务后的新实例。

单射检查、共同 \lambda 行和精确有理 LP 均为总位多项式。因此该程序区分 promise YES `OPT≤1` 与 NO `OPT>5/3`。LP 不可行只保证 `OPT>1`，LP 可行只保证 `OPT≤5/3`；中间带可任意回答。它既不输出 Haxell 匹配，也不证明一般非单射实例的 configuration gap 有 (5/3) 界。

## 6. 证据等级、版本和后续用途

- Exact 源（SHA-256 `ad33f6b2c42c184b943651e61437ece2d1372ee1445443017e62534d83487900`）是候选陈述，不含证明。
- root frozen proof（SHA-256 `e524ac4cf8df7310729477dc12f91c14842a90dff58953e66d3952397574a05a`）逐步给出配置行分解、(a)-树抽取、阻断数、Haxell 严格差、回填和过滤判定。
- independent cover/literal/shared 三份审查重构同一链条；其中明确检查了 ​(summin(q,t)) 而非错误的总和条件、零概率/端点、共同资源容量和非单射回填。它们未发现 standing fatal objection，但不是外部新颖性认证。
- Haxell 依赖仅按上述 primary 论文中的准确陈述使用；未声称重构 Haxell 1995 原证明，也未运行该 v2 的实现或有限实例。
- 仍需第三阶段判断它与已有“配置/资源度三正规形”对象的关系。已知联系是：本条的 private-tree、unit selector 和注入叶条件比一般菜单正规形更窄；不能把 (5/3) 界迁移到一般 UM。

**可接续事项。** 后续 Solver 可在不改变本条量词的前提下：(i) 给有限 (d,h) 生成 Haxell 匹配的显式构造或证明其参数复杂度；(ii) 检查非单射过滤器在其它配置模型中的必要性；(iii) 与 `unrelated-machines/normalized-flat-menu-three-state-degree-three-normal-form` 比较是否存在保持 selector 资格的归约。任何这些工作都不能把候选或有限审计改写成一般性定理。
