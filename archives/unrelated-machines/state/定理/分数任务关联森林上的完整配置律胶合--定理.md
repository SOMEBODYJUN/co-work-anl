# 分数任务关联森林上的完整配置律胶合

固定有限显式不相关机实例、一个非负有理阈值 \(T\)，以及每台机器 \(i\) 在其实际合法配置上的一份有理概率律 \(y_i\)。配置保原任务标签，负载不超过 \(T\)。令
\[
x_{ij}=\Pr_{C_i\sim y_i}(j\in C_i),\qquad \sum_i x_{ij}=1\quad\text{对每个原任务 }j.
\]
只取 \(0<x_{ij}<1\) 的机—任务二部边，得到分数关联图 \(F\)。每个任务的资格数任意，机器可有任意度数。

**结论。** 若 \(F\) 是森林，则给定的全部完整行配置律有同一个有理联合实现，其支持中的每个元组都是一份原阈值 \(T\) 的完整整数调度。可在显式输入及给定配置支撑总位长的多项式时间内构造有限有理分解，且分解支撑数不超过所有局部律的正支撑总数。反向，由保持给定完整行律的全调度分布求单机边际，直接得到原给定配置点。

## 固定整边与局部规律

\(x_{ij}=1\) 时该任务在 \(y_i\) 的每个正质量配置中都存在，别的行对此任务均为零。将这些任务固定给其原机器。所有 \(x_{ij}=0\) 的边也在相应局部规律中固定为零。剩余每个任务节点 \(j\) 的局部规律是其分数入边上的 one-hot 向量，按概率 \(x_{ij}\) 选唯一机器端。每个机器节点保原配置律在其分数边上的投影。加回该行固定任务唯一恢复原配置，故投影没有丢失行律。每条分数边的两端在同一布尔状态上的质量精确相同。

在 \(F\) 的一个分量任选根节点。先取根的一份正质量局部状态。树上一条父子边的布尔值由父状态确定。由于该值在父端有正质量，它在子端也有正质量，所以可以选任一与该值相容的正质量子状态，向下直到所有节点都选定。孤立节点按其局部律取值。合并全部分量后，每条分数边在两端相同。每个任务节点只有一个1，故选出的各机局部配置加回固定任务后，构成一份原任务恰执行一次的实际阈值调度。

## 精确有理分解

每次从当前局部非负质量中按上述方法找一份实际全局调度。令 \(\varepsilon>0\) 为所选各局部状态的最小剩余质量。给该调度权 \(\varepsilon\)，在所有节点减去相应所选状态的质量 \(\varepsilon\)。所有节点的剩余总质量仍相同。每条分数边在其被选状态上的两端总质量同减 \(\varepsilon\)，另一状态的质量未动，故保留全部边际一致性。每次至少耗尽一个原局部支撑项，从而有限步完成，权重总和恰一。节点无分数边时仍保其确定配置。

选兼容状态、减质量和恢复原配置均按显式正支撑进行。所有权可统一放在原输入有理分母的最小公倍数格点内，格点位长由输入分母位长总和控制。这给准确的位多项式过程，不要求高维隐式 CONFIG 列的枚举能力。

若配置 LP 输入只给每任务覆盖质量至少一，且原正支撑二部图本身为森林，可先从原配置中逐任务删除多出的覆盖质量直到等号。移去任务保持行合法，保其他任务边际；每个任务按顺序移动整份配置质量，最后至多拆一份，故显式支撑至多增加任务数。删除不会添加正资格边，仍可用上面的分解。此预处理给实际阈值可行性；保持原完整行律的结论使用原来的等号假设。

## 单环只给存在与固定行律的区别

有两台机器 \(A,B\)、两件任务 \(1,2\)，阈值 \(T=2\)。在 \(A\) 的两个处理值都是1，在 \(B\) 都是2。令
\[
 y_A(\varnothing)=y_A(\{1,2\})=1/2,\qquad
 y_B(\{1\})=y_B(\{2\})=1/2.
\]
每件任务在两台机器的期望覆盖质量之和为一。分数二部图是一条四环，亦即二资格机器多重图的一对平行边。任取 \(A\) 的空配置，\(B\) 的支持只能覆盖一个任务；任取 \(A\) 的双任务配置，\(B\) 的支持必重复一个任务。因此给定完整行律没有任何全调度联合实现。原阈值却可行，例如把两件任务都交给 \(A\)。这说明单环阈值存在性与逐一保持指定配置律是不同保证。

本论证采用树上同一布尔边际的精确拼接。它允许任务节点的任意度数，因而不同于只沿一件两资格任务对邻机状态取互补的专门形式。一般含环分数支撑上的完整相容性仍是独立义务。
