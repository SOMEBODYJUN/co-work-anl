# 1. 完整原矩阵与任意实际模式

整数k≥2，显式二进制正有理a₁,…,a_k满足Σa_i≤1。原机器为内部H、P₁,…,P_(k−1)和真实外部E₁,…,E_k，2k台互异；原任务恰2k件互异q_i、b_i，无辅助、预载、其它任务或资格。

| 原任务 | 全部内部有限端 | 唯一外部有限端 |
| --- | --- | --- |
| q_i | H:a_i | E_i:1 |
| b_i | 每个P_r:1（1≤r≤k−1） | E_i:1 |

未列端∞。每原job整件恰一次；E_i真正由q_i与b_i共用，负载全部计入峰，不能拆成两个private outside。H允许真实多query共居，例如a_i=1/k时全k件共H恰1。a_i正值是正式域，本页不悄悄扩到零端。

对完整合法assignment σ定义S={i:q_i在H}、T={i:b_i在E_i}。这里T是**返回索引集合**，不是其它定理的时间阈值；本页阈值记B。给任意S,T⊆[k]，q的目的地与outside b已确定，剩余b_i（i不在T）的pool选择为任意函数
\[
\rho:[k]\setminus T\to[k-1].
\]
pattern最优值 \(\operatorname{OPT}(S,T)\)对所有这些ρ求最小完整实际峰。普通UM允许pool共居，**不先假定**一P一件或matching；任何S,T都有有限完整调度，因为k−1≥1。

# 2. 每份实际分配的全机负载恒等式

任意S、T、ρ唯一编码完整合法分配，全部原机负载为
\[
L_H=\sum_{i\in S}a_i\le1,\quad
L_{E_i}=\mathbf1_{i\notin S}+\mathbf1_{i\in T},\quad
L_{P_r}=|\{i\notin T:\rho(i)=r\}|.
\tag{1}
\]
式(1)覆盖任意multiquery/multireturn/空集及pool碰撞，没有删未选原任务。所有b的有限时间均1，且b任务非空，故任意完整峰C≥1。H负载≤1，E/P负载为整数，C因而是至少1的整数；不只是1或2，差ρ可给3乃至k。这不影响下面**pattern最优值**只有1/2。

# 3. 全pattern精确最优值

对全部合法输入和任意S,T，
\[
\boxed{\operatorname{OPT}(S,T)=
\begin{cases}
1,&\varnothing\ne T\subseteq S,\\
2,&T=\varnothing\ \text{或}\ T\not\subseteq S.
\end{cases}}
\tag{2}
\]

**Good pattern的完整峰1构造。** 设非空T⊆S。将q_S放H，其它q_i各放E_i；b_T各放E_i。T⊆S使每E至多一件unit。剩余m=k−|T|≤k−1枚b按输入索引递增，一一注入P₁,…,P_m，各time1。H≤1，全部P/E≤1，所有2k件原任务恰一次；b-unit下界使峰恰1。

**所有bad pattern的统一下界。** T为空时k件unit b必须进k−1台pool，鸽巢迫某P至少两件、负载≥2，S任意不改变池机数。若T不含于S，取i∈T减S，q_i和b_i都在同一原E_i，真负载2，与ρ无关。这两个条件的并恰为所有bad模式，包括零/多query或return；不是只证明singleton cross。

**所有pattern都有峰≤2的完整上界。** 按pattern放所有q和outside b；每E至多两unit、H≤1。m=k−|T|≤k件pool b：若m≤k−1，放不同P；若m=k，前k−1件各放一P，最后一件再放P₁。k≥2保证P₁存在。全部原任务合法恰一次，各P最多两件。与bad下界合得精确2，不能把“容量1匹配失败”误报为pattern无合法分配。

# 4. 给定实际C小于2时，无需改动ρ的原样解码

现在先取**任意完整实际**σ，假设C(σ)<2，而非先假设其pattern good。P上全unit b，所以每P最多一件，k−|T|≤k−1迫T非空。若i∈T减S，E_i有两unit又与C<2矛盾，故T⊆S。

对**这同一份σ**，全部P/E至多一unit、H本来≤1，所以C(σ)≤1，结合b下界得C(σ)=1。没有先重排ρ或归一化再宣称原解本来峰1。任意1≤B<2的实际弱输出都已strict1，且能按原q/b目的地直接读出非空containment。

必须区分两层量词：

| 给定信息 | 可断言什么 |
| --- | --- |
| pattern满足非空T⊆S | 存在确定性构造的峰1最优ρ；不保证每份ρ都弱。 |
| 给定σ已经C<2 | 其真实T非空且含于S，而且这份原σ本身峰1。 |
| pattern bad | 每ρ峰≥2，同时存在某ρ峰恰2。 |

源独立稿给的明确例：k=3、S=T={1}是good，若b₂、b₃同放P₁，则该合法完整σ峰2，虽然同pattern最优值1。更大k差ρ可更高；不能把(2)写成“每个good assignment峰1”。这里H可多small query共居，一机一件只是在P/E由C<2推出，不是H的约束。

该接口只保证至少一件具体b返回，且每个返回b_i保证同索引q_i在H。允许S严格包含T，允许多query/多return；不保证S=T、singleton或每件内部q都有return。

# 5. 空集、singleton、闭阈值与k端点

| 模式/边界 | 准确结论 |
| --- | --- |
| S=T={i} | aligned_i，最优1，构造仍执行其它所有q的outside和b的pool负载。 |
| S=T=空 | inactive，k个unit b挤k−1池，最优2。 |
| S={j},T={i},i≠j | singleton cross，在E_i真实双unit，最优2。 |
| S空、T非空 | 不满足containment，最优2。 |
| T空、S任意 | 鸽巢下界不变，最优2。 |
| S=T=[k] | 全query共H、全部b各自E，峰1；孤立普通P恒OPT1，无source NO。 |
| B<1 | b-unit下界排除全部完整分配。 |
| 1≤B<2 | 实际可接受分配只有峰1；可行pattern恰非空T⊆S。 |
| B=2 | 每S,T至少有一个完整≤2 witness，全部bad pattern恢复可行；不代表每ρ都被接纳，k≥3可把三枚b同P给峰>2。 |
| k=1 | 正式排除；没有P机，T空强制b₁内部却无合法目的地，(2)的“所有pattern有限且bad值2”不再成立。 |

给任意有理δ∈(0,1)，B=2−δ即可排全部bad pattern，其最小峰2比B高δ；无需改矩阵、a_i或对象数，更不按δ倒数复制。这只是固定孤立接口的模式阈值，不是任意UM近2 gap。

# 6. 显式算法与总位长

给good S,T，按索引扫描构造第3节注入；给bad S,T，扫描构造至多一P双件的峰2 witness。输出每件原job的具体原机，不需要未知源assignment、最优witness或matching求解器。给实际σ，逐任务核恰一次/合法端、读取S/T/ρ，再按(1)回算所有2k台原机；不把pattern优化替成原样解码。

原机2k、原job2k，q有限资格2k、每b有k−1个P加一个E共k项，故finite总k²+2k，dense4k²项。k由显式对象给出，输入长度至少Ω(k)；资格矩阵quadratic计入原输入。单模式构造/解码只扫描原任务与显式数据，不枚举2^(2k)个patterns。

a_i、Σa_i及负载用二进制有理精确算术，分母部分和位长受输入分子/分母位长总和加多项式log项控制，不按1/a_i、分母值、1/δ或隐式指数展开。普通UM每机串行可给全部原任务开始时刻；源数学不等于已有软件实现，本轮未执行构造或枚举。

# 7. 相邻模型、可复用接口与未闭义务

[四任务共享外端环](../构造/共享外端四任务环的完整负载谱--构造.md)在strict弱阈值下各机至多一件，完整资格环只两aligned；本池允许H真实多small queries，关系是非空containment而非单一对齐。两者都计真实共享E，不能私有化；也都不反驳只保证内部替换的[uniform交换](逐机统一容量的查询返回严格交换--定理.md)。内部cross可能可行，完整E冲突才排它。

本池q仅有单outside E_i，不满足[全公式私有子句模板](../证明/私有子句的正外端染色与压缩共同匹配--证明.md)的双ring外端资格；不能把所有“共享outside”互套。给q_i第二个outside端后，b_i在E_i并不再直接迫q_i到H，故不得免费继承T⊆S；E同一化、额外H/guard任务、变量环接线或其它真实jobs也改变完整矩阵，需重新证明所有原jobs YES与全部低峰NO decoder。来源不声称这些修改充分产生hardness。

孤立模块全q可共同H、全部b可E，OPT恒1，未强制多个源occurrences共truth/label；不提供费用共享、任意clause读取或外接formula一致性。标准unit池/共享端技术与全部q停车本身不冒称新matching理论、NP-hard源、一般UM算法或near2 hardness。外审、全球新颖性与UM-TARGET-v1正反面未完成；历史4328辅助检查只属有限来源证据，不能承担本页任意k证明。
