# 真实最优来源的条件矩阶逐深度锐性

采用 `UM-C2-PREFIX-CONDITIONING-DEGREE-v1` 的真实 one-hot 矩模型。任意整数前缀深度 t≥0，机器为 A、B、C。独立强制一项 C-only 时间2，其他任务只在 A/B 有有限端。以下各例的每个支持调度峰均为2，强制任务给原OPT=2。

对任意真实来源和正概率的 t-literal 前缀，条件乘积期望为 E[∏_{e∈S}x_e | F]=y_{F∪S}/y_F。完整机器负载是原端 literal 的线性和，故其条件标量只需 t+1 阶。degree-one 负载局部化器由至多两个索引 literal 乘一个线性负载，故只需 t+3 阶。M₂ 的每条目是两个最高二次乘积，故只需 t+4 阶。重复 literal 幂约为一次，互斥项为零。

令 z∈{0,1}^n，用偶校验和奇校验上均匀概率作为两份真实来源。每个 bit 由一项 A/B 二择任务实现，A/B 两端的 one-hot literal 是 z_i 与1−z_i。任何至多 n−1 个 literal 的乘积若有冲突为零，否则只钉少于 n 个 bits，两校验类有同样补全数，故对应所有原矩完全相同。前缀 F 把头 t 个 bit 都钉为1，两个来源都给正概率2^(−t)。

- **标量完整负载。** n=t+1，前t任务两个端时间0，最后一项两个端时间1，并令 z_n=1 对应 B。条件下余位由校验唯一确定，L_B 分别为0、1。故 t 阶不够，原恒等式需至多 t+1 阶，且该上界逐 t 锐。
- **degree-one 局部化器。** n=t+3，前t+2项两个端时间0，最后一项两个端时间1，同样令 z_n=1 对应 B。比较条件局部化器的两个 degree-one 坐标 z_{t+1},z_{t+2} 的条目。条件差来自 −E[z_{t+1} z_{t+2} z_n | F]，在两源之间相差1/4，常数2的二次条目相同。所有原≤t+2阶矩相同，故一般最高 t+3 阶锐。
- **完整条件 M2。** n=t+4，所有 A/B 项两个端时间0。取 degree-two 行列 z_{t+1}z_{t+2}、z_{t+3}z_{t+4}，条件条目在两源间相差1/8。全部原≤t+3阶相同，故 M2 的 t+4 阶锐。

三条分别给对应最高阶必要性的实际见证。每条按自己的原矩阶合同取一对来源。它们排除用较低阶矩识别指定原来源的条件量，允许重新选择来源的舍入算法仍须单独判断。两个零时长任务端均为真实有限端，不能删成不可用。

如要求所有有限端严格正，仍可逐深度实现同样差值。把每例的零时长 A/B 任务两端改为同一有理 ε=1/(n+1)。A/B 总处理量始终小于2，C 的强制任务仍使每份支持调度最优。标量例在 F 上全部这些小任务位于 A。局部化器例在索引乘积非零时，前缀和两个索引把所有小任务都钉在 A，故它们对 B 的负载项为零。M₂ 本身只读真实 assignment 矩，与这项正时长改写无关。于是三个所需阶数及数值差都保留。
