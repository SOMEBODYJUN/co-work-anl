# 归一化菜单的三态资源度三正规形

每个下述显式归一化flat普通UM输入P，都可确定性地在总位多项式时间内变成同域P*，满足
\[
K_{\max}(P^*)\le3,\qquad
\Delta_{\mathrm{resource}}(P^*)\le3,
\]
以及
\[
OPT(P^*)=OPT(P),\qquad V(P^*)=V(P).
\]
两条等式分别有全部实际调度和全部正partial阈值的证明，包含OPT=2、V=0端点。归约不输入OPT、最优选态或源YES证书。

这里至多三态指每个新增组的完整indexed菜单大小；资源度在全部states并集上按组计数，包括零权membership。允许增加真实组、selector与singleton任务，原selector的资格会改变；不保原组数、组交互度M或某种固定角色模式。该正规形不制造源gap，也不把任意一般UM或未归一化Santa Claus行免费转入本域。

## 1. 完整输入与partial值

G为有限非空组集，每组菜单A_g非空且显式，\(K_g=|A_g|\)。state s具有互异资源组成的S_gs与非负二进制有理权p_gsu，严格要求
\[
\sum_{u\in S_{gs}}p_{gsu}=1.
\]
允许零项、重复indexed states和显式unused资源；这里归一化不是可省略的前提。

每state有独立private机M_gs，每资源有R_u；每组恰一件selector J_g，只能在本组state机耗时1；每(g,s,u)有独立incidence任务，只能在M_gs耗时p_gsu或在R_u耗时1；其余端不可用，无其它任务或预载。所有未选states的incidence也存在。

V是在每组选一个state并领取该state任意资源子集、组间领取不交时，最大化最小private质量。允许未领资源和零权项，资源不可拆，不把同资源的多个incidence当作多份独立容量。设原组数n、state总数 \(S=\sum_gK_g\)、incidence总数I。

## 2. 第一阶段：每顶点一selector的真实选择树

为每个旧组g建一棵叶恰为其K_g个indexed states的显式满二叉树。K_g=1时直接是一片root叶。每顶点v建立一个新组Q_v，**每组恰一件selector，不是每state一件**。每个非root顶点有fresh own-resource a_v，全部own标签与旧资源及其它树互不相交。

菜单如下，所有singleton private权为1，资源端也为1：

| 顶点 | 完整state菜单 |
|---|---|
| internal root | 左child own singleton、右child own singleton |
| 非root internal | 自己own singleton，以及左右child own singletons，共3态 |
| 非root leaf，对应旧state s | 自己own singleton，以及完整原state s，共2态 |
| root即单叶 | 只有完整原state s，不造own state或own-resource |

每state具有独立private机和全部incidence任务。原state机器M_gs及其全部原incidence沿用身份、时间与private／真实资源两端；旧selector J_g作为root selector，其资格改到root states。每非root新组另增一件unit selector。所有新singleton incidences是真实不可拆任务，不把树边当作免费OR逻辑。

每state总private质量仍为1。目标internal可能有三个重量1 singleton，leaf是own-heavy与任意原state二选一；不能把它擅自归入one-heavy/two-diffuse等更窄模式。

## 3. 任意正partial阈值的两向转换

固定 \(0<v\le1\)。

给源分配，每旧组选择state s并领取质量至少v的子集。沿选择树从root走到s对应leaf：root与路径internal选择下一child singleton并领取它；终leaf选择原state并领取原子集；其它顶点选择自己的own singleton并领取它。

每own-resource恰由路径上的parent领取或由off-path顶点自身领取，二者不会同时发生。所有新组质量1≥v，原资源子集仍跨旧组不交，故完整中间分配达到v。K_g=1直接保原state和子集。

反向给任意达到v的中间分配。root选择的singleton若不领取则质量0，所以必领取child的own-resource。该child无法再靠自己的own singleton获得正值，必须选择child分支，或在leaf选择原state。沿实际选择逐层到某个实际选择原state的leaf，从中取出同一原state的原partial子集，质量至少v。

目标off-path分支可以额外激活，甚至选择其它原state；逆向不要求它们规范化，也不合并多个state。每个旧组只提取root迫出的一个leaf，原资源不交性继承自全部目标分配。K_g=1的root本来就是原state。

因此全部正阈值两向等价；两侧非负且有限最大值达到，若一侧V=0、另一侧正值则逆向矛盾，故V=0也保持。

## 4. 源C<2完整调度的逐任务扩展

给源完整调度σ，峰C<2。所有selector为unit，故C≥1。对每组读取J_g实际所在state s，选择到它的树路径。

若K_g=1，全部旧任务原位不动，root无singleton，以下移动只用于K_g>1：

1. 将原J_g移到树root的相应singleton private机。
2. 路径非root internal的selector选择下一child state；终leaf的selector选择原M_gs；off-path顶点selector选择自己的own state。
3. 所有被选singleton incidences外送own-resource，未选singleton incidences留自己的private。
4. **所有原incidence保留σ的实际private或外送目的地**，包括每个未选原state的任务。

新own-resource由路径parent或off-path自己恰好占用，所有新增机器负载至多1≤C。原M_gs上的新leaf selector替代移走的原J_g，单位负载相同；其它原private没有新增selector，其原incidence总质量至多1；原资源负载不变。因此全部原及新增任务各一次，峰不增。

这不是仅把一个partial分配当作已经执行了完整实例。原state的所有incidence始终实际存在，扩展保持了原调度的全部incidence决定。

## 5. 任意目标C<2完整调度的逆向链

给任意选择树目标的完整调度，峰C<2。若selector实际选中singleton state，该state的incidence不能留private，否则两unit负载2；因此必须外送。

root占用某child的own-resource后，该child若选择自己的own state，它也必须外送一件unit到同一资源，负载2，矛盾。所以沿实际selector选择走向下一child，最终到达实际选择原state的leaf。

把旧root-selector J_g移回这个leaf的原M_gs，替代即将删除的新leaf selector。保留全部旧incidence的实际端，删除其余新增selector、所有singleton任务及own-resource：

- 被提取leaf的原private单位负载完全替换。
- 其它原private只可能失去新增selector，负载不增加。
- 旧资源的原incidence目的地不动。
- 所有源原任务仍恰一次，端与时间合法。

不能声称旧selector资格在构造中保持：它在目标选择root states，逆向后才恢复在原菜单上的合法目的地。目标也不必只有一条激活路径，off-path原state可以被选择或外送；逆向只提取root迫出的链，其余原incidence仍全部保留。K_g=1无需移动或删除原selector。

## 6. 第二阶段、顺序与端点

在三态中间实例的**全部资源**上应用[真实资源度三路径归约](完整菜单的资源度三路径归约--定理.md)，旧资源、own-resource和零权membership均纳入。必须先做选择树、后降度：把原states分成leaf组，在一般输入中可能提高同一旧资源接触的组数。

路径helpers只有两态，所以最终每组仍至多3态，资源跨组度至多3。路径归约的任意C<2实际调度双向映射与正partial阈值双向映射接在前一步之后，得到两条完整合同。

每阶段每state质量1，故源与最终目标都有全private峰≤2基线，selector使OPT≥1。若源OPT<2，正向后再对目标最优解逆向给相等；若源OPT=2而目标低于2，逆向矛盾。故实际OPT=2端点也保持。给定C≥2调度时可输出另一侧全private基线，但不再声称保留该调度的外送决定。

正partial阈值两向等价与有限最大值同理给V=0端点。整个实际OPT证明逐原任务经过真实中间矩阵，不依赖先宣布 \(OPT=2-V\) 来跳过全任务义务。

## 7. 精确第一阶段规模与总位复杂度

对每棵K_g叶满二叉树，顶点数2K_g−1。菜单和singleton逐项计数，得到：

| 第一阶段对象 | 精确数量 |
|---|---:|
| 组／selector | \(2S-n\) |
| indexed states／private机 | \(5S-4n\) |
| fresh own-resource | \(2S-2n\) |
| 原incidence | I，全部保留 |
| 新singleton incidence | \(4S-4n\) |
| 全部incidence | \(I+4S-4n\) |
| 全部任务 | \(I+6S-5n\) |

K_g=1时单组贡献1个组、1个state、0个own-resource和0个新incidence，以上公式仍成立。这也是实际正向算法必须为K=1单列的原因。

路径阶段helper数不超过第一阶段incidence数，每helper仅增加常数个机器、任务与有限端，所以总机器／任务及dense乘积仍多项式。新增处理时间为1，原有理数逐项复制；构造不按处理时间值、分母或阈值倒数展开。树路径与全任务映射可以按显式输入遍历，构造本身不寻找最优state。

## 8. 组成后的源义务与不保留量

任意显式normalized flat实际源若另已证明近二gap，可先变成三态／资源度三，再接[三坐标零权切片表示](三坐标零权切片的精确菜单嵌入--定理.md)。这样保实际OPT和归一化，目标允许零格与indexed异成本。原菜单数或资源度很大不再单独构成本域的归约缺口；但归一化、显式小表示，以及全部选态／任意partial导出的源NO仍承重。

本构造增加组与helpers，不保组交互度M。三态与资源度三也没有强迫M为常数，不能直接导出固定M算法的统一改善；更不能把角色自动缩成某种单重态／双分散态模板。

同样，不能从一般加性Santa Claus玩家的未归一化行免费取得这里的归一化显式菜单。本轮全文比较来源737121825175bccceb42：它的同资源宇宙、非负norm1、全部subset阈值接口有显式菜单规模障碍。例如固定η∈(0,1)，在2t资源上同时要求全部t子集取值1、所有至多⌊ηt⌋子集取值≤η，会迫使归一化显式菜单在大t时达到指数规模；这只排除该同宇宙逐玩家接口，不排除辅助资源、全局耦合或其它归约。本正规形没有放宽那份源域要求。

对[裸Cartesian菜单族](../反例/裸笛卡尔菜单乘积的精确反向放大--反例.md)，本合同实际保留 \(V=1-2^{-t}\)、\(OPT=1+2^{-t}\)，因此降度和压态不能恢复已经消失的NO间隙。该后果及旧palette的不同失真方向另见[关联接口审查](../审查/裸菜单读后与保值降度及调色板障碍--审查.md)。
