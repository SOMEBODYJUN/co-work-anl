# 固定多个受限边界的森林菜单

采用 `UM-FOREST-BOUNDARY-AUGMENT-v1` 的普通显式不相关机模型。每项原任务最多两个有限处理端，删除平行后的机器支撑为森林。固定一个无帽边界 a、q 个其它边界 b_j，内部阈值 T≥0。比较调度 ρ 对每个内部机器及每个 b_j 的原负载均≤T。q 可任意有限，只有固定 q 给位多项式菜单。

取 ε=η/3，0<η≤1。对每个 b_j，预算候选包含0、从最小正有限 b_j 处理时间 δ_j 起的公比1+ε网格，截在T并加入T。若没有正处理端，只用0。任何正比较负载≤T有同一预算向量 C，其每个正 C_j 介于 L_bj(ρ) 和 (1+ε)L_bj(ρ)，零坐标选0。每个网格有 O(1+L/ε) 项，L 为显式输入位长。

对每个向量，C_j=0 时删 b_j 的正端，C_j>0 时把 b_j 的所有有限端时间乘 T/C_j。把全部 b_j 当内部机器，只保 a 无帽。删除或缩放不增加支撑边，仍为单边界森林。无合法端的向量跳过。T=0 只有零向量并可直接删所有内部正端。匹配 ρ 的向量下，ρ 是内部阈值 T 的可行比较，单边界 oracle 输出同一个原任务分配 τ，a 负载不增。恢复原时间后每个 b_j 同时满足

    L_bj(τ) ≤ (1+ε) C_j ≤ (1+ε)^2 L_bj(ρ) ≤ (1+η)L_bj(ρ).

零预算仍零，原内部负载≤(1+η)T。任何返回项有 C_j≤T，因此每个 b_j 也≤(1+η)T。菜单大小与调用次数至多 O(1+L/ε)^q。保真实任务身份和相同 τ 的联合坐标；这不提供 q 变参统一多项式或有环支撑的算法。与外部核心拼接时，各边界实际总负载必须由核心约束同一菜单项的坐标。
