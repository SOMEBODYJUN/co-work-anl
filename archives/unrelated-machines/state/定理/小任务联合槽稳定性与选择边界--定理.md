## 定义域与主合同

输入是[有限不相关机器实例与合法 CONFIG 点](../定义/不相关机器与两个调度松弛--定义.md)、目标阈值 $T\ge0$、显式有理证书 $y$、非负小任务阈值 $\delta$ 和二进制编码的整数 $K\ge1$。CONFIG 的正确覆盖量词是

\[
y_{iC}\ge0,\qquad \sum_Cy_{iC}=1\quad(\forall i),\qquad
\sum_i\sum_{C\ni j}y_{iC}=1\quad(\forall j).
\]

每个配置 $C$ 是不重复的原任务子集，只含该机的有限端，且完整负载 $\sum_{j\in C}p_{ij}\le T$。每个任务的覆盖是在所有机器和配置间合计为一，不要求单个正权配置包含每个任务。

先把**任意位置具有零时间有限端**的每个原任务实际安置到某个零端，并从所有配置删除这些任务；相同残余配置可合并权重。该操作保持每机配置质量、其余任务的覆盖不变，负载不增。零端安置作为最终实际输出的一部分保留，不能只删任务而不回填。下述 $r_i,s_i,b_i$ 及 $K$ 的基数承诺均按删除后的残余证书计算；不把删除前的稳定性数值直接沿用。

对剩余边按 $p_{ij}\le\delta T$ 与 $p_{ij}>\delta T$ 分为 tiny/big，同一原任务在不同机器可有不同角色。对每个正权残余配置，要求其中的 **big 任务数至多 $K$**，tiny 任务数不受这个基数限制。定义

\[
\tau_i(C)=\sum_{j\in C:\,p_{ij}\le\delta T}p_{ij},\qquad
r_i=\min_{C:y_{iC}>0}\tau_i(C),\qquad
s_i=\sum_Cy_{iC}\tau_i(C).
\]

令 $b_i$ 为该机正边际 tiny 支撑上的最大单件时间，空支撑取零。对给定非负 $\omega$，稳定性要求为 $s_i-r_i\le\omega T$，并有 $b_i\le\delta T$。完整配置容量给的是其 **big 部分** 的界

\[
\sum_{j\in C:\,p_{ij}>\delta T}p_{ij}
\le T-\tau_i(C)\le T-r_i,
\]

而不是把完整配置负载再错误限制为 $T-\tau_i(C)$。若 $T-r_i=0$，严格正的 big 边际为空，不作除零。

对每台机器、每一类，把边际质量按处理时间非增排列并切成单位槽；一个作业的质量段与槽的**严格正长交集**为图边权。所有机器的两类槽放进同一张二部图，每个剩余原任务只保一个任务节点，而不是先分别舍入再拼接。

## 联合 Hall 舍入与负载界

每个作业的槽交集权总和为一，每个槽的总交集权不超过一，所以任意作业集合的邻槽容量至少等于其基数。Hall 匹配一次性覆盖全部作业，每作业只被匹配到一个真实有限端，故输出是完整合法调度。该构造不需要知道 OPT、生成 CONFIG 或枚举 (K)，并保留跨机器切换 tiny/big 的同一作业身份。

在机器 (i) 上，tiny 槽从第二槽起的最大件尺寸之和不超过 (s_i)，首槽最大件不超过 (b_i)，因而

\[
L_i^{\rm tiny}\le s_i+b_i. \tag{1}
\]

令 (U_i=T-r_i>0)，把 big 尺寸除以 (U_i)。若实际非空槽数为 (hle K)，槽最大尺寸为 (a_1ge\cdots\ge a_h)，则第 (\ell) 槽的正长交集给出严格前缀计数

\[
\mathbb E_yN_\ell(C)>\ell-1. \tag{2}
\]

对阈值区间计数向量构造只用于证明的整数多面体 (Q)。Abel 求和得任意非零 (z\in Q) 有 (\sum z_\ell<1)。顶点的有效约束矩阵是整数矩阵，每行 (\ell_1\) 范数至多 (K)，Hadamard 与 Cramer 给顶点和

\[
\sum_{\ell=2}^h a_\ell\le 1-K^{-(K-1)}.
\]

结合 (a_1\le1)，定义 \(\alpha_K=2-K^{-(K-1)}\)（按实际 (h) 可得到更强界），得到

\[
L_i^{\rm big}\le \alpha_KU_i,
\qquad
L_i\le \alpha_K(T-r_i)+s_i+b_i
\le (\alpha_K+\omega+\delta)T. \tag{3}
\]

这是给定显式 CONFIG 点、相对于给定 $T$ 的条件结论。若 $T=0$，合法覆盖使每个任务具有零端；若预处理后无任务，也直接输出已记录的零端分配。更一般地，真实 $\mathrm{OPT}=0$ 当且仅当每个任务具有某个零端，因此本页包含上述**全局零端预处理**的算法在 $\mathrm{OPT}=0$ 时一定输出零负载，即使输入给定的 $T>0$、零端未被原 $y$ 支持。

若省略预处理、仅沿给定 $y$ 的正支撑舍入，相对 OPT 的零界才可能失败。最小例是两机一任务，时间为 $(0,1)$、$T=1$、$K=1$、$\delta=\omega=0$；第一机以权一取空配置，第二机以权一取该任务。该点是合法 CONFIG(1)，支撑槽匹配会把任务送第二机、负载一，而真实 OPT 为零。此例不反驳给定 $T$ 的槽上界；它说明不能省掉全局零端安置。执行当前预处理后，任务在第一机实际安置、两机残余配置均为空，输出为零。

## 固定源族的三值选择器

另一独立对象使用显式三值 selector/root/leaf 矩阵，唯一有限 selector 端时间为一，(\ell\ge2)。在完整实际调度峰值 (C) 下：

* (C<1+1/\ell) 时，选中的 root 不能留任何 leaf，解码出所选三元组在三坐标上互不相交，即 perfect 3DM；
* (C<1+2/\ell\le2) 时，每个选中 root 至少外送一枚 B/C 叶，解码为覆盖全部 X 的二部匹配；
* 始终有 (C\ge1)。

源中 (\nu) 是 3DM 最大匹配数，\(\mu\) 是相应二部投影图的最大匹配。完整上界分别为

\[
\mathrm{OPT}\le 1,\quad 1+1/\ell,\quad 1+2/\ell
\]

（分别在 \(\nu=q\)、\(\mu=q\)、无前提时），因为未选 root 的全部 leaf 仍留在各自 home，所有原作业均被支付。该三值审查覆盖有限矩阵实例和精确任务身份，不把三值审计扩大成一般 selector 识别器。

## 选择复杂度与边界

审查同时保留 `UM-TINY-WORK-STABILITY-SELECTION-NP-v1`：在其固定源族和给定证书语义下，选择稳定 CONFIG/舍入证书是 NP 完全；这不是一般不相关机器调度的 NP 困难性，也不是从审计运行推出的结论。稳定性、联合舍入和选择器三部分必须分别标注其输入量词。

全机合同不包含生成 CONFIG 的算法、未知 OPT 的 oracle、一般 (R\|C_{\max}) 近似或六人 SPE 结论。有限证据只覆盖源中列明的联合槽、奇偶与三值实例；大整数 CLI 的解析修复属于复现边界，不能替代位复杂度证明。后续可将 (3) 作为显式 CONFIG 后端的条件接口，并将三值阈值作为解码障碍，而不得删除未选状态或把局部证书写成全局必要条件。
