# 1. 完整v1域和逐原任务模式

给有限显式H、固定辅助原A、互不相交且族内互异的Q={q₁,…,q_k}、R={b₁,…,b_k}，k≥2，原任务N=|A|+2k。给正二进制有理T、B，
\[
T\le B<2T,\qquad B/2<p_{hj}\le T
\]
对每条有限原内部资格成立，其余∞。不要求同机所有p相同；A可空、任意资格/强制单端、无树/环对称前提，无预载。每A在每模式均必须执行。局部系统允许无资格原job，使包含它的模式不可行；不能凭条件命题为空真就称带无端job的封装为合法普通UM。

对任意X⊆Q∪R，模式指定A∪X各一次整件在原H，其余边界在外。Inactive X_∅=R，aligned X_i=(R减b_i)+q_i，指定mismatch(j,i)=(R减b_i)+q_j。它们读真实原q/b身份及目的地，不是匿名机器presence；inactive不是所有边界outside的X=∅。

# 2. 对所有X而非仅列出模式的三等价

给同一原资格图任意X：

- 若有内部峰≤B完整分配，每h不能放两件，因为任意两原finite时间之和严格>B。因此它的原目的地已是覆盖A∪X的资格matching。
- 任何这样的matching每h最多一原job，该原端p≤T，所以**同一原目的地**已给strict峰≤T，不需要将p替成别的实际时间。
- strict≤T自然也≤B。

故对每个X，weakB可行 iff strictT可行 iff原资格matching覆盖A∪X。这只涉及内部H，不给共享真实外部任何负载界。B=T也有效；下端p>B/2必须开，等号会允许两件恰B共居；p≤T必须闭地保证任意资格单件能在T执行。源没有扩到B=2T、零内部时间或仅凭资格存在就处理任意异权。

A无端时所有含它的模式不可行；H空且k≥2时aligned包含k边界所以不可行，条件关系仍成立，算法可报告。无除法/巨大比值/slot展开；v1每内部机就是一个原匹配位置，不需假定总机数等于任务数或满载。

# 3. 原rank证明：收缩共同任务后平行返回元

固定i≠j，置C=A+(R减b_i,b_j)，x=q_i、y=q_j、u=b_i、v=b_j。在原资格图的job侧transversal matroid M中，独立集是可由matching覆盖的原job集。

两aligned strict见证让C+x+v、C+y+u独立，所以C独立，可收缩；在M/C中，{x,v}、{y,u}独立，u/v均非loop。若inactive不可行，{u,v}依赖、秩1，故u/v平行、closure相同。若{y,v}依赖，则y∈cl(v)=cl(u)，与{y,u}独立矛盾；同理{x,u}独立。还原到原资格图，C+y+v是指定mismatch(j,i)，C+x+u是另一方向。由三等价，它们都有原处理时间strict≤T调度。

此论证不假定H恰满载、两见证用同一机集、全图最大matching恰|A|+k或M/C原秩=2。可选把M/C截成rank2，仅保当前大小≤2的独立性；或先收缩A再把边界rank截k，保所有当前k元模式。均为证明语言，不删除原机器、资格或A；不使用v2物理容量截N。

若所有k个aligned可行且inactive不可行，对每有序i≠j应用便得全部k(k−1)错配。得到的反面只针对固定内部A、每h弱端单容量的原身份合同，不是一般medium/tiny共居或所有identity复制器不可能。

# 4. 无inactive承诺的实际算法与非查询辅助覆盖

给任意两份合法strict aligned实际分配，它们本身就是matching。由第一份删去原q_i=x的一边，保M覆盖C+v。先从未matched y=q_j做标准交替搜索，若到空闲原机则翻转得C+v+y，即指定错配；全部C及v仍各matched一次。

若y无增广路，M未变。只看左侧C+v+y+u，当前M有|C|+1条边，第二见证有|C|+2条边，所以M非最大、增广必存在。仅y/u未matched，y已穷尽无路，故从u=b_i必可增广。翻转得C+v+u，即inactive；未matched y不成为路径中间matched job，也未进入该实际输出。

至多两搜索、一次成功翻转，仅沿原finite资格重排原jobs，所有A保留、不匿名化/拆分/删除；原机最多一job，真实原p≤T，所有内部机**同时**受控。无需原机满载或两见证用同机集。成功得到大小|A|+k的模式即停，不继续增广另一个起点改变输出集合。“至少一项”允许两模式本来都可行，不保证恰一可行。

在inactive不可能承诺下，第二分支合法输出会矛盾，所以第一分支必给指定错配；交换i/j另运行得反向。不给见证可先对两个aligned原job集各做matching判定，失败可靠报告该aligned不可行；两者成功才作上述算法。不能要求某aligned失败也仍输出错配，亦不调用一般UM/未知source赋值oracle。

# 5. 封装全部原jobs、原时间与合法性

每边界原z添一台与H及其它O互异的私有原机O_z，仅z有timeT资格；A无outside。给内部模式X输出后，边界补集各到自身O，全部N原jobs恰一次。内部matching每端用原p≤T，outside每机唯一job时间T，所以同一完整actual全机峰≤T。反向符合模式X的完整封装actual限制H即内部模式。

在给定aligned前件下，每A已实际用有限内部端，故原矩阵合法，边界都有O且机数≥2k>0。若A无任何H端又无outside，封装仍有无资格job，不能仅因有2k outside机称其合法；这不影响局部报告全部aligned不可行。每A已有finite端即可保证ordinary UM资格合法，未必有某aligned在T可行；不要把足够guard倒成必要条件。此精度在后续v2 canonical明确，旧v1原文笼统封装话仍保字节，当前逻辑不反写为早期已经写明。

模式只是外部指定的目的地投影，O本身不强制must-query。由一份aligned保留A在H、让所有边界去O，也已给X=∅完整strict调度；这与inactive R不同。若把O改接共享变量/锁机器，外部任务集合及负载改变，当前单容量matching不能证明全局回填或任意fullformula可行。

# 6. 与v2只作模式化约，位域和状态

分析地将v1所有原finite时间统一为T，保同一资格图，得到v2的每机统一单slot系统。其strict可行模式与v1完全相同。对该分析系统用v2算法求matching，再投影到同一原job/原h并恢复各自真实p≤T，才是v1原矩阵实际输出。不能把统一T当成对物理原输入的静默修改，不能声称v1同机异权矩阵逐项属于v2。v2另允许zero和多tiny slots，两个原数值域不同。

所有任务/机器/finite资格与有理分子分母显式，dense全部项计入。匹配判定、最多两搜索、原目的地输出及outside O(k)补全均总位多项式；没有按T、B、p或分母数值展开，k为实际列出的边界任务数而非二进制隐式生成指数任务承诺。
