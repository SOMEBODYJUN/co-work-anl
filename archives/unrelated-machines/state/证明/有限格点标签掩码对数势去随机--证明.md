## 复杂度与物理不交边界

DP 表长为 (Q+1)，所以复杂度按 (Q) 的**数值**收费；二进制编码的巨大 (Q) 只有伪多项式保证。应用标注的 (Q=4m) 且 (mge1) 时，Q 的数值与显式 item 数同阶，才可转为总输入位多项式。文档没有代码、运行日志或数值回归。

若额外假设所有同一目标标签 (t) 的 (S_i) 两两不交，则 (T_i={jin S_i:r_j=t_i}) 跨全部 agent 两两不交：不同目标标签因一个 item 只有一个全局标签而不交，同目标标签由该额外假设而不交。没有这项条件，势不等式不推出物理 allocation 的全局不交，也不能为不同 agent 复制或独立重抽标签。
