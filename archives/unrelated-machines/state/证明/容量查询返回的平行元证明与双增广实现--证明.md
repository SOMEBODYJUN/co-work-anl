# 1. 所需原对象与精确容量

内部H有限显式，固定必做原A，互异边界Q={q₁,…,q_k}、R={b₁,…,b_k}，k≥2，三类不交，总原任务N=|A|+2k≥4。T>0为二进制有理；每h上所有finite原端同一非负有理s_h或∞，跨h任意，资格任意，无预载。固定模式X要求A∪X各一次在H执行、全机≤T，其余边界外部执行。定义inactive X_∅=R，aligned X_i=(R减b_i)+q_i，指定错配X_(j,i)=(R减b_i)+q_j，i≠j。Inactive不是所有边界outside的X=∅。

每h容量c_h为s_h>0时min(N,⌊T/s_h⌋)，s_h=0时N。给任意原任务子集及实际目的地，每h负载恰n_h s_h且n_h≤N，所以原实际≤T iff该目的地件数≤c_h。s_h>T给0，零机不除零，H空只使aligned前件失败。若展开同邻接slots，每h恰c_h个、总≤|H|N；原job不复制。实际→slots时按固定顺序注入不同slot，slots→原机时逐原job投影回所属h，真实负载仍≤T。此为任意子集的精确等价，不是时间近似。

计算先比较Ns_h≤T可直接取N，否则正有理floor；无须按巨大T/s_h数值扩图。二进制整数/有理位长、dense全部矩阵项均计成本，资格展开≤原finite数×N。这里的**容量截N**由原宇宙最多N件而来，与下面只作证明语言的rank截断不同。

# 2. 独立rank路线：共同C收缩，返回元被迫平行

在上述slots资格图取job侧transversal matroid M：独立集恰是可由原资格匹配覆盖的job集。只使用标准二部匹配的该拟阵性质，不新增物理限制。

设aligned i、j在T可行，置
\[
 C=A\cup(R\setminus\{b_i,b_j\}),\quad x=q_i,\ y=q_j,\ u=b_i,\ v=b_j.
\]
两见证给C∪{x,v}、C∪{y,u}独立，故C本身独立。在收缩M/C中，这等价于{ x,v }及{ y,u }独立；u、v各非loop。若inactive在T不可行，C∪{u,v}不独立，即收缩后非loop的u/v组成秩1依赖对，所以它们平行、closure相同。

{y,u}独立而u/v平行，若{y,v}不独立，则y∈cl(v)=cl(u)，与{y,u}独立矛盾。同理由{x,v}独立得到{x,u}独立。还原收缩并投影回原H，
\[
 C\cup\{y,v\}=A\cup X_{j,i},\qquad
 C\cup\{x,u\}=A\cup X_{i,j}
\]
均有原任务完整strict≤T实际调度，全部A在收缩还原时保留。逐有序i≠j即得全部k(k−1)错配。

没有假定全图最大matching恰|A|+k、两见证占同一机器/slots、原H满载、总容量恰某数或收缩后原秩=2。M/C的秩可以更大；只需四元中两元素独立性。可选将M/C作rank2截断，因为这保所有大小≤2独立性；或先收缩A、边界rank截到k，同样只保当前k元模式的独立性。两种rank操作都不是删真实机器、任务、资格或改变s_h。无需rank截断也已完成上述证明。

# 3. 作者路线：双起点的一次成功增广

这个实际算法不需要inactive不可行承诺。给两份任意已核aligned内部actual，先按容量等价转matching。记L=|A|+k，从aligned i匹配删除**原q_i**的一条边，得到覆盖A∪(R减b_i)的L−1件原jobs的M。仅考虑左侧原任务
\[
 U=A\cup R\cup\{q_j\}.
\]
其中恰b_i、q_j尚未匹配。第二份aligned j匹配也完全在这个U图内，大小L，所以M不是最大；普通二部图增广性给从b_i或q_j出发、到一个空余slot的路，可用确定性固定顺序多源BFS寻找。

翻转路保持每枚原已matched job仍恰matched一次，仅新增起点：b_i起点得A∪R，恰inactive；q_j起点得A∪(R减b_i)+q_j，恰指定mismatch(j,i)。**成功一次后大小到L即停**，不继续把U的L+1个任务都尝试匹配而改变所需模式。所有A、b_j和其它原已匹配任务都在翻转中保留，可移动但不删除、拆分、匿名替代。

终点只需某h还有空余slot，原h可已经执行其它jobs；不要求整台机器空闲。两份actual可用不同机器或slot，增广路可经过任意多aux，仍每步沿原有限资格。投影h给同一原P内部全机真实≤T。

# 4. 独立路线：先搜索q_j，失败再搜索b_i

独立稿使用同一初始M，但固定优先从y=q_j单源搜索：

1. 若能到空slot，翻转，覆盖C∪{v,y}，直接给mismatch(j,i)。全部C及v仍各恰matched一次。
2. 若q_j搜索失败，M尚未改变。在U=C∪{v,y,u}中，M有|C|+1条边，而第二见证M_j有|C|+2条。增广必存在，未matched左侧只有y/u；y已穷尽无路，所以u=b_i起点必能到空slot。翻转后覆盖C∪{v,u}，恰inactive。

失败搜索不把未matched q_j偷偷放入第二分支；未matched左任务也不会成为交替路中间的matched job。第二步只重排C∪{v}，新增u。故两次搜索、一次成功翻转，保同一原A，输出全部模式内原jobs。作者多源任选成功起点与独立“先q_j后b_i”是不同确定顺序、同一实际增广结构，不是两份无关定理，也不是软件执行记录。

若inactive在T不可行，任何b_i成功输出都会与承诺矛盾，因而必是指定错配；交换i/j重做得另一方向。不承诺inactive时仍至少一项输出，允许两模式本来都可行，不能把“至少一项”改“恰一项”。

不给见证时本**精确容量域**可先对两aligned原任务集分别作容量matching判定，失败即可靠报告该aligned不可行；两者成功再作上述算法。不要求某aligned失败时也输出错配/inactive，不调用一般weighted UM或未知源assignment oracle。

# 5. 全原任务封装与合法性guard

给每边界原z互异私有原机O_z，仅z可在该机耗时T，且与H不交；A无outside端。内部输出A∪X后，边界补集各去自身O_z，N件原jobs每件恰一次；内部≤T，outside每机最多自身一件T，slots不出现在实际输出。反向满足指定模式X的完整封装调度限制H便是内部模式。

局部网络允许某A根本没有finite内部端，此时每个含全部A的aligned都不可行，算法应报告而非给假见证。若任一aligned前件成立，它已让每A实际用过finite内部端，所有边界又有O_z，且2k≥4保证原机非空，于是封装是合法普通UM。

这只是**足以保证合法**的条件，不是说aligned可行是ordinary UM合法的必要条件；只要每A已有有限端，封装可合法而特定aligned因容量不足仍不可行。真正非法的反例是A无任何内部资格且无outside，边界O_z不能救这个原job。Canonical终读最后把这个guard说清，早期笼统措辞保原字节而不倒填。

模式仅是原job目的地投影，outside机本身不物理强制must-query。给一份aligned，保其中A在H，所有边界都放各自O_z，也已给同一封装全原jobs≤T的X=∅调度；inactive X=R被禁不等于它被禁。因此孤立封装本身不是源NO gap。若换成真实共享变量/锁机器，外部job集合改变可能增负，以上私有恢复不再适用，不能免费推任意fullformula。

# 6. Weak域、旧v1和不能外推的端点

v2只需任意有理B≥T且inactive在B内被禁，单调推出T内被禁，错配输出本就≤T≤B。不需要B<2T；B不参与c_h计算。仅有B可行aligned不能代T前件，也没有任意B调度压至T的算法。

旧v1 finite p_hz∈(B/2,T]、T≤B<2T，允许同机异权。任何weak≤B内部模式每机至多一job；反向任意资格matching每端≤T，给strict≤T。故可先分析地把全部finite改T，使用v2单slot证明，再把matching逐job恢复原p≤T。它是strict模式matching化约，不是v1异权矩阵逐项属于v2逐机统一域，也不保任意更高阈值的所有调度。

标准cap matching/增广/拟阵收缩截断交换都已扣除新颖性。任意同机异权、模式相关A、预载、bundle/多尺度或内部外部不可分容量需新证明；不声称它们充分制造困难性。输出和负载回算、两模式判定、至多两搜索/一次成功翻转全按显式任务/资格/有理位长多项式，无未截断比值或分母数值展开。没有新软件/有限run、一般UM算法、全局NO decoder、外审/全球原创性或UM-TARGET closure。
