这是既有直接共居异权Claim（历史称B）的完整证明整理，不重记新matching技术或一般UM算法。旧[共居SAT与单home审查](../审查/共居查询SAT与单home级联查询分离双源审查--审查.md)已有结果摘要；本页展开两种严格身份计数、作者完整图与typed先固定强制对的较小图，以及全任务异权负载恢复。原件/实际审查先验/两canonical范围见[历史与跨稿范围](../审查/直接共居异权合同的独立证据与跨稿范围--审查.md)与[证据包](../../tools/evidence/weighted-direct-cohabiting-history/README.md)。固定半权锐界C不是本页主对象。

# 1. 修改后的完整原矩阵

输入显式有限CNF，每clause c有k_c≥2个实际occurrences，重复文字/变量/clauses允许，但每occurrence是不同物理索引且只属一clause。只保出现变量；各变量真实occurrences任意排序成环，不足3补dummy，dummy不属clause、polarity任取。总索引N、真实L=Σk_c、clauses m；最少padding N≤L+2v，更长dummy表必须显式并按N收费。空公式m=L=N=0单列一idle原机、零任务、OPT0。

非空时每i有不同原机M_i、C_i和不同原任务q_i、b_i，每clause另有一原u_c。环后继i⁺，正文字s_i=0、负s_i=1，dummy s任取，pin(i)=M_i当s_i=0、pin(i)=M_i⁺当s_i=1。给二进制有理 \(1/2<\rho<1\)，真实i给正有理x_i,y_i且x_i+y_i≤1；dummy固定x_i=1、没有y_i。原端**恰**为

| 原任务 | 全部有限原端 |
| --- | --- |
| q_i | M_i:ρ，M_i⁺:1，C_i:x_i |
| b_i（含dummy） | pin(i):ρ，C_i:1 |
| u_c | 本clause每个真实i的C_i:y_i |

其它∞，无预载、免费状态、h/D任务/机器或真实公共clause机R。原机2N、原job2N+m、finite5N+L、dense2N(2N+m)。全部任务整件恰一次。Dummy在此模型的b仍有pin/C两端，不能混成另一私有子句模板的dummy D_i:T。

任意occurrence的x/y可不同，不取单一公共e；所有有限时间≤1。若另外希望保护某弱阈值 \(B_{\rm weak}\in[1,2)\)，可选ρ>B_weak/2，但下面全公式三半算法不需要B_weak。当前对象没有旧pair-sensor的h_i/D_i，也没有旧保护环§9真实公共R_c；这是改了物理矩阵，非旧输入上的静默加强。

# 2. SAT满足赋值给全部原任务strict调度

给满足赋值，每变量令z_v=0表示true、1表示false。每clause选一枚真实真文字i，其s_i=z_v；不同clause的所选物理索引不同。对被选i放q_i于C_i、b_i于pin(i)、u_c于C_i；其它所有i（含dummy）放q_i于M_i或M_i⁺的z_v方向，b_i留C_i。

每索引恰有一枚有效环任务：选中时b_i替换原q_i，未选时q_i。返回b_i与被替换q本来都沿z_v方向，故每变量整环每M恰一件，真实时间ρ或1。选中C_i有两原任务q_i+u_c，真实和x_i+y_i≤1；其它C仅unit b。全部2N+m原任务恰一次，所有原机同时≤1。构造仅扫描给定满足赋值，不求解SAT。

# 3. 任意strict调度的同编号身份：两种完整计数

给同一原P任意完整actual σ，峰≤1。每M只可q/b且时间ρ或1都>1/2，所以每M最多一件；每C_i不能同时q_i、b_i，因为x_i>0（dummy1）与unit b相加>1。

**作者E/R计数。** 定义E={i:q_i在C_i}、R={i:b_i在pin(i)}。q_i导出到C使b_i必须返回，逐索引E⊆R。M上的原任务数恰N−|E|+|R|，N台M每机≤1给|R|≤|E|。有限集合包含和等势迫E=R，每M恰一件，故同编号q_i在C iff b_i返回，不是仅匿名总数平衡。

**typed先行全槽计数。** 原q/b恰2N件，N台M和N台C每台至多一件这类任务，所以所有2N个q/b槽均恰占一件；u并未被当成独立unit槽，它可以真实与q共居。每C_i恰q_i或b_i，直接给相同逐索引身份，再得每M一件。它与作者包含/基数证明相合，不是另一输入域。

每u_c实际在某真实C_i且y_i>0，不能与unit b_i共居，所以该C必有同编号q_i，i∈E=R。Dummy无u资格，不能冒充clause见证。

每索引选有效环边任务：i不在E取q_i的实际M端；i在E取返回b_i的固定pin，方向z_i=s_i。每i恰一枚有效任务、每M恰一件；M_i收到件数为
\[
(1-z_i)+z_{i^-}=1,
\]
所以z_i=z_{i^-}，整变量环同向。置变量true iff z_v=0。每clause的实际u选到真实i且s_i=z_v，该文字为真，得到满足赋值。额外exports/returns及dummy全部在原计数中，没有免费同编号假设或未知source witness。

于是strict≤1当且仅当SAT，两个方向均总位多项式。一般异权B只给这个可行性合同，**不据此声称非空SAT的真实OPT一定等于1**；固定半权C的非空下界需另证，不能借可选unit端直接推出。

# 4. 全公式baseline/active分类，不输入源解或strict见证

定义C₀={c:某真实i∈c有y_i≤1/2}，固定一个此类t(c)；C₁为其它active clauses，h=|C₁|，I₁为全部active真实索引，L₁=|I₁|。Active全部y_i>1/2，所以x_i≤1−y_i<1/2。分支是按每occurrence原有理y比较，没有从异权中抽一个公共参数。

所有baseline/dummy b将在构造中固定自身C，baseline/dummy q必须仍参加共同环选择；baseline u只是暂不放分析图，最后逐原任务恢复，不删实际输入。Active j(c)可与return r(c)不同，这正是弱端允许的错配，不是另加身份约束。

# 5. 作者2N+h图的全局共同匹配

左侧为全部原q_i、b_i及仅active原u_c；右侧为全部原M_i、C_i及每active分析标签V_c，两边2N+h。边仅为q到两个M（active q再到V_c）、b到pin/C、active u到本clause各C。**没有q→C图边**。V不是实际机器，图边是组合选择，未把真实ρ/x/y换为unit执行。

Active i∈c置θ_i=1/k_c≤1/2，其余0，给同一全图fractional perfect matching：

- q的两个M端先各1/2，从pin端扣θ_i，active时向V_c加θ_i。
- b向pin给θ_i、向C_i给1−θ_i。
- active u_c向每个本clause C_i给θ_i。

每q/b/u行和1；每M的相邻q基量和1，扣掉的各pin θ由同号b逐项补回；active C的b+u为1，baseline/dummy C的b为1；每V收Σθ=1。所有值非负，k_c≥2是实质条件。对任意左子集求质量给Hall，标准确定性整数matching取一共同perfect matching，不将分数质量作为实际输出。

Baseline/dummy C只有自身b邻居，迫其b留C、q走M；不能借它们的返回资格给active。每active V选一q_j；每active u占一C_r，迫该b_r返回pin，其它C只由b覆盖，所以active恰一query、恰一return。每M恰一原q/b，所有返回pin与其它q的环目的地在同一匹配中无冲突，非各clause分别拼局部见证。

# 6. typed先固定强制对的较小图

独立稿先把baseline/dummy b固定C，删除这些左b/右C强制对，只保：左全部N个q、L₁个active b及h个active u；右全部N个M、L₁个active C及h个virtual R_c，两边N+L₁+h。其原记号R_c是**分析virtual**，不是旧物理公共R_c；为与作者对照可改名V_c，原件不改。

边和θ与作者图在剩余节点完全相同：q两M/active V，active b pin/C，active u各C。仍有q/b/u行和1和M/C/V列和1，因此同Hall和整数匹配证明。反向给较小图匹配，加回每个被删baseline/dummy b_i—C_i强制对即得作者图匹配；从作者图删这些对则得独立图。差别是分析表示，不是删原q/b任务。

Active空时L₁=h=0，较小图仍含全部q到全部M的环图，half/half证书和perfect matching有效；之后全部u是baseline恢复。作者全图仍含强制b/C，与之等价。空公式则另走idle分支，不套非空图计数。

# 7. 消去标签、恢复全部原任务与实际异权负载

同一整数匹配按以下原资格回填：q若匹配M则保该原端及ρ/1，若匹配V/R标签则把**同一原q_i**改放自身C_i、时间原x_i；b保原C/pin及1/ρ，active u保原C及原y；所有暂未入图baseline u逐件加回C_(t(c))。

| 原机器类别 | 完整τ实际负载 |
| --- | --- |
| 每M_i | 匹配恰一原q/b，真实时间≤1 |
| baseline C_i | 固定b_i=1，无q导出；若i=t(c)再有该原u_c，和≤1+y_i≤3/2 |
| dummy C_i | 仅原b_i=1；dummy q始终在环 |
| active C_i匹配留b_i | 无u，可能加同号导出q_i，至多1+x_i<3/2 |
| active C_i匹配无b_i | 恰有本clause原u，可能再加同号导出q_i，和≤y_i+x_i≤1 |

若j=r，返回C_j真实q+u≤1；若j≠r，query C_j有q+b<3/2，return C_r仅u≤1。每occurrence只属一clause，不会两u叠同C，重复文字/变量仍是不同索引。所有q/b/u恰一次，baseline的原u均恢复，没有virtual实际目的地、实际新任务、分数执行或任务副本。

这一个共同τ对所有原M/C同时峰≤3/2，任意SAT/UNSAT、所有合法逐occurrence异权、任意环序/dummy polarity皆如此。算法不输入源解或未知strict调度，所以严格SAT双向性不能修复已被全公式三半上界破坏的弱decoder：在近2且≥3/2的弱阈值内，UNSAT也有完整actual。它只否定这套具体矩阵的near2 soundness，不是一般medium/所有identity compiler反面。

# 8. 总位复杂度、旧对象与固定半权分界

Baseline分类用精确有理比较；图规模O(N+L+h)，θ=1/k_c位长O(logL)，matching是显式组合算法。原2N机、2N+m任务、5N+L有限资格和dense2N(2N+m)全部计入输入/输出。最少padding N≤L+2v，更长显式dummy按实际N收费。合法性、负载和输出开始时刻为输入有理部分和，位长多项式，不按1/x、1/y、1/ρ或分母数值展开；普通UM按机串行给实际完整时间表。

Exact明确旧pair-sensor有q/b/h与M/C/D，q_C=e、h_C=1−e、h_D=1、u_D=1；该旧pair-sensor已给具体全公式≤1+e；旧保护环§9另有真实公共R_c与unit clause出口，给全公式strict matching。本对象无h/D/真实R，u直接与q在C共居，故不是旧对象同输入上的加强；这些旧结果按本次Exact所载作为版本比较，这里不重新认证未重读的旧Proof，也不把本矩阵并入machine-uniform query/return v2。标准保护环和Hall技巧已从新颖性扣除。
