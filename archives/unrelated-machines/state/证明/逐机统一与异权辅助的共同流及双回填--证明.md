# 1. 两个过程版本的完整原矩阵

后继成熟v3/v4主数学已在[双见证批量插值与成束耦合细分边界双源审查](../审查/双见证批量插值与成束耦合细分边界双源审查--审查.md)吸收。本页保存前置v1/v2的完整不同证书、输入量词和双回填证明资源；两份statement原文均未预登记成熟资产，不额外给它们发明legacy Claim ID。五主源和三比较原件见[证据](../../tools/evidence/auxiliary-load-gluing-history/README.md)。

| 原任务 | 有限端与真实时间 |
| --- | --- |
| qₐᵢ | 自身Mᵢ:ρ，后继Mᵢ₊₁:1，所属正/负block的Aₐₛ:1/k |

# 2. strict False的两种完整计数证明

False时f的unit占满正pool，所有正q的1/k出口都不能用。每正C最多一J，J占C迫同编号正b返回自身M。因ρ>1/2，strict每M至多一q/b。

作者的**集合容量证明**：若返回正b有t枚，k枚正q加t枚正b中，只有q_k可能越出正block去Mₖ₊₁，其余至少k+t−1件须各占k台正M，故t≤1。其它负q/b入流只会减少余量，不破坏计数。于是False branch正C接全部J至多1，True branch平凡至多k。

独立v1稿的**后继传播证明**：若被J占的两个正C索引h<h′，b_h/b_h′均返回。q_h不能自身M（2ρ>1）、不能满正pool，只能到M_h₊₁且耗1。沿正block逐项迫q后继，最后q_h′₋₁落入已有b_h′的M_h′，矛盾。这在正block内闭合，不假设全环统一方向。

两证明计全部J，不只命名guards。令cₐⱼ为v1第j份实际见证在a正block的J数，v2则cₐᵘ/cₐᵛ。定义各自平均向上整Kₐ，得到

\[
\begin{aligned}
\text{v1: }&K_a=\left\lceil r^{-1}\sum_jc_{a,j}\right\rceil
\le1+\left\lceil\frac{k-1}{r}\right\rceil,\\
\text{v2: }&K_a=\left\lceil(c_a^u+c_a^v)/2\right\rceil,
\quad K_u,K_v\le k/2+1,\quad K_a\le1\ (a\notin\{u,v\}).
\end{aligned}
\tag{1}
\]

所有K≥0且≤k另由每见证正C至多k得出。这些是实际见证统计，不是添入UM的物理容量。

# 3. v1：全J共同整数件数流及数据界

置N=|J|，内部机器的整数容量

\[
u_h=\begin{cases}N,&c_h=0,\\
\min\{N,\lfloor1/c_h\rfloor\},&c_h>0.
\end{cases}
\tag{2}
\]

同机统一时间使每实际strict的J件数≤uₕ；反向满足件数便有真实负荷≤1。零行不除零，cₕ>1给容量0，截N避免任何按1/c数值展开。

网络：源→每原J(cap1)；J→每原有限I/正C端(cap1)；I→汇(cap uₕ)；每正C→所属branch gate(cap1)；gate→汇(cap Kₐ)。把r份J actual原去向各取1/r得值N分数流，各job总1、每I/C/gate均满足容量。所有J共享**同一个**流，跨branch/内部共同资源完整计入。

整数容量给整数满流：从0按固定顺序取残量增广路，若未到N就停止，残量可达集给容量<N割，与已显示的分数值N矛盾。每正增广整数≥1，最多N次。每原job唯一源单位挑一个原有限目的地，I实际≤1、每正C≤一J、每branch正C上的J数≤Kₐ。算法不需保存分数流，也不需展开uₕ个slot。

按§5或§6完整回填，只有正pool可能超过1，得

\[
B_{\rm data}=1+\frac1k\max_a\max(0,K_a-1),
\quad C_{\max}\le B_{\rm data}
\le1+\frac{\lceil(k-1)/r\rceil}{k}\le3/2.
\tag{3}
\]

最后因r≥2、k偶，ceil((k−1)/r)≤k/2。r2时这个统一表达式恰3/2，不说每实例达到它，亦不说B_data为条件真OPT。N0时直接空流/K0和无出口backbone，整机峰1。

# 4. v2：作者固定同端与独立重复出现项两条真实舍入

同机异权不能用(2)件数容量。以下两路线各使用同一份全J联合网络而非逐机挑色，均把每件J限制在其两个实际见证原端。

## 4.1 作者：先固定相同目的地

先固定σᵘ(z)=σᵛ(z)的全部J。内部h固定负荷Fₕ≤1；固定正C已被unit占满，移除该C。若branch固定C数dₐ，则两c均含dₐ，剩gate容量Kₐ−dₐ≥0。移去固定C不会失去其它剩余job的见证端，因为任何strict见证该C不可能再有一J。

每未固定J恰两个不同原机器选项，各送1/2。对内部h，把所有剩余见证出现项的真实成本非增排w₁≥w₂≥⋯，邻项成容量1的分析slot，奇尾单列。建源→未固定J(cap1)，J→其两出现项所在I slot或正C(cap1)，slot→汇(cap1)，C→gate(cap1)，gate→汇(cap Kₐ−dₐ)。half实际路由给完整分数流，整数化给各原J一个端；补回固定jobs。

在h，两输入中每出现项都与同一固定集合共居，故

\[
\sum_iw_i\le2(1-F_h),\qquad w_i\le1-F_h.
\]

每slot至多选一项，选中成本≤O=w₁+w₃+⋯≤(Σw+w₁)/2，因为排序交错差≤w₁。于是

\[
\operatorname{load}_h\le F_h+O
\le3/2-F_h/2\le3/2.
\tag{4}
\]

空表O0；Fₕ1时剩出现项可全0，仍合法，不删除这些原任务。每正C≤一J、branch总数≤dₐ+(Kₐ−dₐ)=Kₐ，固定C没有免费或双计。

## 4.2 独立v2旁读原稿：不固定，同机两次出现均保留

完整比较原稿ef54保留每J的两个有标号出现项(z,u)/(z,v)，即使同一job两见证在同一h，也保两项。内部全部出现项按真实成本排p₁≥p₂≥⋯，邻项配slot；总和≤2、最大≤1。同样源→每J cap1，J→其出现项slot或C cap1，slot→汇 cap1，C→branch cap1，branch→汇 capKₐ。重合边可合为一条，两个half合计1。

每slot至多两出现项，half可行；每C两actual各至多一J故half≤1，gate为平均≤Kₐ。整数流每job源容量1，重复出现不重复物理任务。若同job两项在不同slot也只能挑一个，选slot后执行其原h；真实时间等相应出现项成本，不超过slot最大值。因此

\[
\operatorname{load}_h\le p_1+p_3+\cdots
\le(\sum_ip_i+p_1)/2\le3/2.
\tag{5}
\]

该稿没有分离Fₕ，不必给作者更细3/2−Fₕ/2或同一assignment。奇数/空/全零列表均按同式处理。两种编码及其不同细界保留，不能把它们压成“固定同端后相同证明”。ef54本批只作全文比较，不另计主源done。

# 5. 作者的max集合回填：负末q导出

下面两种回填适用于任意最终正C被J占的集合S⊆[k]，c=|S|≤Kₐ，不要求连续、前缀、相同guard或与旧某份输入相同。暂略变量a。

两路线都把f放正poolA₀，i∈S的正b返回原Mᵢ，其余正b和所有负b留原Cᵢ；每C于是恰一unit J或b，真实负荷1。S空则每q放自身M，pool仅f且负pool空。

S非空令p=maxS。作者v1/v2安排：

| 原q索引 | 原目的地 |
| --- | --- |
| 正i∈S去掉p | 正poolA₀ |
| 正i<p且i∉S | 自身Mᵢ |
| 正p≤i≤k | 后继Mᵢ₊₁ |
| 负k+1≤i<2k | 后继Mᵢ₊₁ |
| 负末i=2k | 负poolA₁ |

这些互斥列表覆盖全部原q一次。p前的M由返回b或自身q各一，M_p有b_p，M_p₊₁至M₂ₖ各有前驱q；负末q已导出，不从环尾撞M₁。因此全部M恰一原q/b、成本ρ或1，≤1。正pool恰f加c−1枚q，负pool恰一q，负荷分别1+(c−1)/k与1/k。

# 6. 独立的区间回填：负首q导出

v1独立主源及v2独立比较原稿分别给另一完整assignment。设S={h₁<⋯<h_c}、c≥1。b/f同§5，q按：

| 原q索引 | 原目的地 |
| --- | --- |
| 1≤i<h₁ | 自身Mᵢ |
| 对j<c，hⱼ≤i≤hⱼ₊₁−2 | 后继Mᵢ₊₁ |
| 对j<c，i=hⱼ₊₁−1 | 正poolA₀ |
| h_c≤i≤k | 后继Mᵢ₊₁ |
| i=k+1 | 负poolA₁ |
| k+2≤i≤2k | 自身Mᵢ |

空区间略过，相邻返回点也合法：此时前一索引q正是下一返回点前需导出的那枚。列表仍覆盖每q一次。M₁至M_h₁₋₁为自身q，每M_hⱼ为返回b，中间空隙及最后返回点后到Mₖ₊₁为前驱q，Mₖ₊₂至M₂ₖ为自身q；全部互斥且覆盖2k台M。q_k的后继确为原Mₖ₊₁，导出的q_k₊₁确属负block，不用额外资格或环尾填充。

这里恰c−1枚正q和一枚负q导出，pool负荷与作者相同，但原q身份/目的地不同，不该删去。c0仍用无出口自身q方案。

# 7. 全部原机器共同闭合、算法与存在量词

先J的全局流，再按每变量两种之一回填，不是分别给branch花一份内部资源。不同变量ring/pool物理不交，J不接M/pool/负C且backbone不接I；共享J内部和正C已由**同一次**联合流定好。因此同一实际assignment全部原q/b/f/J各一次、资格合法，所有C1、所有M≤1、负pool≤1/k、正pool≤1+max(0,Kₐ−1)/k。

v1加内部≤1得(3)。v2加内部≤3/2、(1)两模式K界得整机≤3/2；即使pool很低，也不能把v2全机界降为v1的B_data。v2无需其它r−2模式；v1此合同确给r份，不能悄悄删该输入义务。

先验证每actual原job恰一次/有限原端/selector模式及全部有理负荷。v1流图O(N+|I|+rk+r)点、O(E_J+N+|I|+rk+r)边，内部容量计算c=p/q时floor(q/p)并截N，零先判；最多N增广。v2每J最多两出现项、O(N)slot及显式C/gate，排序精确有理值及原编号平局，最多N增广。所有原有理数比较/部分和、r或两份显式witness列表、原n任务解码及dense矩阵编码均收费，总位多项式。无时间倒数、分母值、ρ精度倒数或隐式padding循环。

空I/J、零内部、静止重复见证端及unused有限>1保留。v2输出只用已用端，故unused>1不入候选；v1原全资格网络可含容量0的>1内部端。没有对∞负荷算术。slot/gate为算法节点，绝非物理新机器或新增任务。原五源没有软件/有限枚举，本页没有用新实验替代证明。

若只知相应完整strict模式存在，数学上任选后得全False存在；没有求未知witness算法。原不固定selector的OPT=1：一份给定strict给≤1，所有f仅unit端给≥1。全False是指定实际读出条件下的构造，不是源NO或原OPT gap；也不声称B_data/3/2 sharp。

# 8. 后继范围与不能合并的数学身份

v1同机统一时间给更强内部≤1及r平均数据界；v2任意异权内部给较弱内部≤3/2、只需两个actual且保实际端。它们是不同合同，原字节不覆盖。后继current的成熟v3把正C端从unit扩大到(1/2,1]，C只保证≤1、负C恰1；不能倒改本页v1/v2的C=1。current v4又允许J接非poolM/C/I或pool，完整插值可不保M/C≤1，并引入实际pool d/2界，不能将其更广假设和较弱输出回填旧statement。

本结果只限制上述backbone、有给定完整模式及规定J资格的OR committer。跨多子句若没有两份全局strict模式，J去pool/ring/负C、非unit正C、模式相关任务或源decoder均需新合同；此处不证明这些变化可行或不可能。内部共同流不是CONFIG oracle或一般UM近似算法；没有新source hardness、外审/全球新颖性或六人SPE结论。先验/版本证据详见[范围记录](../审查/单位与异权辅助分摊的见证和版本边界--审查.md)。
