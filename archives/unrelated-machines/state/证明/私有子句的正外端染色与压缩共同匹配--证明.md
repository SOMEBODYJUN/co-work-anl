# 1. 全部实际对象与两种量词

给正二进制有理T、显式有限CNF Φ，每clause c有k_c≥2个真实occurrences，重复变量/文字允许，但每occurrence身份不同且只属一clause。空公式允许；空clause与unit clause在域外。每个实际出现变量的occurrences任意排环，补dummy至环长至少3；dummy不属clause。总索引N、真实L=Σk_c、dummy d=N−L，最少padding N≤L+2v；更长padding必须显式列出并按N收费。每索引i有互异原ring机M_i，后继i⁺；真实return pin(i)按正文字为M_i、负文字为M_i⁺，是q_i的两个ring端之一。

每clause有私有内部原机H_c和私有原辅助任务A_c。各H_c互不交且避开ring及dummy私有机；各A_c互异，只能在自身H_c执行。每索引有两件不同原任务q_i,b_i。真实i∈c的q/b仅有自身H_c的任意非负有理/∞内部条目，允许零、同机异权、任意资格及未用有限时间>T。q_i外部恰M_i、M_i⁺两有限端，时间各在[0,T]；真实b_i唯一外端pin(i)，时间在[0,T]。Dummy q只有两ring端[0,T]，dummy b只有其互异原机D_i:T，不回ring。所有其它资格不可用，无预载/其它原任务；真实demand/guard若存在必须作为A_c显式列出并始终执行，不能在证明中删去。

非空原P机器数N+H+d、任务数2N+a，其中H=Σ|H_c|、a=Σ|A_c|。每原任务整件恰一次，不新增或复制物理对象。令R_c={b_i:i∈c}，这里是**任务集**，不是另设机器。

计算输入给每(c,i)一份完整局部actual证书λ_ci，恰在原H_c覆盖
\[
A_c\cup\{q_i\}\cup(R_c\setminus\{b_i\}),
\quad\max_{h\in H_c}L_h(\lambda_{ci})\le T.
\tag{1}
\]
证书不是整个源P的strict调度，也不预设共同SAT赋值。验证逐任务身份/有限端/恰一次及全H_c有理负载；非法输入可报告合同外。A_c有限资格由合法证书保证。H_c空时(1)的q_i没有内部目的地，前件不成立。

结论：给全体λ时确定性总位多项式输出原P全部任务的共同实际τ，Cmax≤3T/2。若仅知有限多λ存在，可数学上各选一份，仍得OPT(P)≤3T/2存在性，不承诺找未知strict局部见证。空Φ独立输出一台idle原机、零任务、OPT0；不硬套非空计数产生非法零机UM。

# 2. 正测试外端T的独立局部染色：全局δ不是零

固定clause及i≠j，在**分析中**给每原边界q/b互异测试机O_z:T，把λ_ci、λ_cj缺席的边界任务放自身测试O，得到同一完整wrapper的两份actual σ0=aligned i、σ1=aligned j，峰均≤T。所有真实内部端/时间不改，A无外端；测试O不属于最终原P。

取两query z₁=q_j、z₂=b_i。它们从σ0的不同O_z:T进入σ1的H_c，因此全局旧query质量δ_z确为T，不能误写δ=0并直接由 \(\max(3T/2,T+\delta_z)\)得到三半；该公式只给2T。独立原稿从[旧分离染色机制](../审查/双见证查询分离的染色证明与冻结审查边界--审查.md)的更细位置不变量另证：

- query弧自持颜色。未触发机器若某色新端流入严格>T/2，标该色并给全部非query旧出弧该色。每非query仅由唯一旧源赋色；全色新入量≤σ1负载≤T，故一机不需第二色，两支持不交，算法有限终止。
- 两query旧outside O_qj、O_bi在σ1没有任务，且其它任务无资格去它们，故无新流入、永不触发。所有H_c机器则没有任何query旧端负荷。
- 对单一颜色，H_c未标该色机按初态≤T加新入≤T/2，得≤3T/2；H_c标该色机所有nonquery旧出任务迁走，又没有旧query残留，固定加选入是同一σ1子集，至多T。
- 每测试O只允许自身原任务，无论hybrid内外选择如何，outside全机负载同时≤T。因此两single-query输出各自都是完整wrapper actual≤3T/2。

bj（即b_j）是从H_c到O_bj的nonquery，支持不交迫至少一份不移它。确定性选该份，并将q_i放自己的O_qi（若已外送则不变），只减内部非负负载。其它q都outside、其它b在H_c、所有A始终H_c，故选z₁得到指定cross(j,i)，选z₂得到inactive：
\[
A_c+q_j+(R_c\setminus\{b_i\})
\quad\text{或}\quad A_c+R_c.
\tag{2}
\]
内部端只来自两证书实际已用端。q_i仍执行，没有删、复制或拒绝任何原任务。该局部核心是从旧染色机制独立证明，而不是把当时尚未读作者Proof的local新Exact免费当已证黑箱。

作者另用分析零端δ0和缩减P星得到同一局部结论；其完整原任务恢复见[私有查询返回两分析实例](私有查询返回的两种三半分析实例--证明.md)。正T路线与零端路线都合法，不能把作者新分析零端追记为原独立稿已读，也不能把正T稿的δ改成0。

# 3. 模式库是实际构造分类，不是可行性oracle

每clause按固定顺序对全部有序i≠j运行局部二选一。

- 一次实际输出inactive，即保存该H_c完整内部assignment，标baseline并可停止此clause；内部恰A_c+R_c。
- 若全部调用都未输出inactive，标active（独立稿称flexible）。每有序query j/return r、j≠r已有一份cross内部actual≤3T/2；对角j=r用输入λ≤T。因此模式库覆盖**所有**(j,r)。

k_c≥2保证不同对非空。active不表示inactive真的不可行：即使它可行但这些调用未找到，已保存全cross库仍足够。没有一般异权模式判定oracle或隐藏strict finder。库中每条在同一H_c上同时控制所有机器、覆盖全部A_c及准确边界清单；还不能据测试outside宣称真实ring负载可行。

# 4. N+h压缩图给所有clause共同选择

令F为active集，h=|F|。分析二部图左侧为全部原q_i及每c∈F一个符号B_c；右侧为全部真实M_i及每active一个符号C_c，两边N+h。

q_i连自身两个真实ring端，若i属active c再连C_c。B_c连本clause每真实occurrence的pin(i)。若多个occurrences同pin，可合并同目的边，但保其可选原occurrence标签列表；反向恢复return身份时从该列表固定选一r。Baseline与dummy q没有C边。B/C都是证书选择标签，不是新实际任务/机器。

对active真实i∈c取α_i=1/k_c≤1/2，其余α_i=0。赋一份**共同**fractional perfect matching：
\[
\begin{array}{c|c}
\text{边}&\text{质量}\hline
q_i\to C_c&\alpha_i\ (i\in c\in F)\\
q_i\to\operatorname{pin}(i)&1/2-\alpha_i\ (i\in c\in F)\\
q_i\to\text{另一个ring端}&1/2\ (i\in c\in F)\\
B_c\to\operatorname{pin}(i)&\alpha_i\text{，同目的边质量相加}\\
q_i\to\text{两个ring端}&\text{各 }1/2\ (\text{baseline或dummy})
\end{array}
\tag{3}
\]
非负性用k_c≥2；每q行和1，每B_c行Σα=1，每C_c列Σα=1。每索引把q_i及其B_c贡献相加，给q_i的两个ring端仍各恰1/2；每M_i收到q_i与前驱q的各半，故每ring列恰1。重复变量/文字不合并物理occurrence，重复pin流按原M列共同汇总，不会忽略竞争。

对任意左子集Y，总行流|Y|进入邻域N(Y)，右列容量1给|N(Y)|≥|Y|。Hall及标准确定性二部matching给一个整数perfect matching，不枚举所有子集，不求SAT，不把分数质量当原处理时间或可分任务。环长≥3保证两个q端及相邻任务是原来不同的对象。

在此同一整数匹配中，C_c选一q_j作为内部query，B_c选一pin(r)作为return原b_r；q的其它匹配都在原ring。选的(j,r)必在已建库中：对角用λ，非对角用cross。不同clause返回pin与其它q目的地已经共同协调，不能按clause各自选看似空闲pin再拼接。

# 5. 作者2N+h图及原q/b身份保留

作者图左侧为全部原q_i、b_i及每active w_c，右侧为全部原M_i、每索引K_i及每active V_c，两边2N+h。q连原两ring端，active真实q另连V_c，**无q→K**；真实b连pin与K，dummy b只连K；w_c只连本clause所有K_i。

取同样θ_i=1/k_c≤1/2，baseline/dummy θ=0。每q两个ring端先各1/2，active在pin端扣θ加到V；真实b向pin给θ、向K给1−θ，dummy b向K给1；w_c向本clause各K给θ。每左行1，ring列被同号b补回所扣θ仍1，active K为1−θ+θ=1，其余K为1，V收Σθ=1。故全Hall条件成立，并可用同一个整数perfect matching。

整数结构强制baseline/dummy的K只由自身b覆盖，故其b留K、q用ring。每active V吸一q_j；w占一K_r，迫b_r返回pin。若另一b也不占K，需要同clause第二个w覆盖其K，矛盾。因此每active恰一query和一return，而不是至多或某个匿名数量。每原M恰匹配一原q或真实b，dummy b不回ring。K/V/w只选择模式，最终不执行。

# 6. 两图是匹配保持展开，不是物理删任务

原two-Proof read-after逐项给出双向对应：

1. 从作者整数匹配删baseline/dummy的强制b_i—K_i对。
2. 对active，{b_i,K_i,w_c}子结构恰选择一occurrence r返回pin，其余b留K。以一个B_c连各pin表示该选择；把V_c改名C_c，保全部q/M。
3. 得左q+B、右M+C的N+h图。减少的是分析标签，不是从实际P删除b任务。
4. 反向：压缩图若B_c匹配某pin，从保留标签选一合法occurrence r，扩为b_r→pin、w_c→K_r，其余b_i→K_i；加回baseline/dummy强制对，得到作者图整数匹配。

合并重复pin边时同一压缩边可有多个合法r，必须保标签供模式库及展开；不声称合并后无标签图与作者图有逐匹配一一对应。存在/构造可双向保存。两个图规模不同不构成勘误，先行独立稿不因作者后读路线而被覆盖。

# 7. 回填全部原任务与真实ring/dummy负载

Baseline c在原H_c用保存inactive，全部q按匹配原ring端。Active c按(j,r)模式在H_c执行恰A_c+q_j+(R_c减b_r)，b_r在选中原pin，其它q按原ring端。Dummy q按原ring端，dummy b去原D_i:T。

逐原任务身份：每A_c只在自身H_c；每真实q恰内部或ring之一；每真实b恰H_c或pin之一；dummy两任务各一次，原总数2N+a。没有遗漏未选择边界、需求或辅助，没有测试O、分析Z、B/C、w/K/V留在执行清单。

同一τ的全部机器同时受控：各H_c使用一份已保存实际内部≤3T/2，H_c互不交所以不相加；每真实M由共同匹配恰执行一件原q或真实b，原端时间≤T，即使0也仍保任务身份；每D_i只有自身dummy b，负载T。因此
\[
C_{\max}(\tau)\le3T/2.
\tag{4}
\]
真实ring界来自另外证明的共同matching，不来自局部wrapper的“私有、单件”假设。q/b原外端不必等于T或有正下界，任意[0,T]已足够。

普通UM中可将每机零时长任务置0，其余按固定原任务序串行，开始时刻为有理部分和，得到实际完整时间表；不只是负载投影或一个分数点。

# 8. 精确规模、算法与只存在的不同承诺

原有限条目为q的两ring端2N、真实b的单pin及dummy b的单D合N，再加E_int内部，故总3N+E_int；原dense为(N+H+d)(2N+a)。分析O/Z/标签都不算原机器或任务。每份λ输入长按其指定A_c+1query+(k_c−1)return任务的真实目的地计。

局部构造至多Σk_c(k_c−1)≤L²次，每次有限有理染色或已证local调用均总位多项式；模式库多项式，可存所有证书或在选择pair后重算。压缩图两侧N+h、边至多2N+2L≤4N；展开图两侧2N+h、O(N+L)边。分数证书只用1/2与1/k_c，其位长O(log k_c)，matching不按分母复制原任务。原值/负载/开始时刻的分母部分和位长受完整输入总位长控制，不按T倒数、T/p、small time或padding数值展开。

若λ仅存在，有限多任选后上界仍成立；不能宣称从原P求未知strict证书。只有源本来以多项式显式规模生成环、内部网络和全部证书，才进一步是source bit-polynomial，不替压缩未展开模板免费收费。

# 9. 障碍结论与未覆盖域

该完整模板满足所有local indexed strict可选时，任意Φ（SAT/UNSAT）均条件性OPT≤3T/2。即使另证源YES全局OPT≤T，也不能在NO要求OPT>(2−δ)T、δ<1/2；这是构造所有原任务actual上界，不依赖P≠NP或假设源NO有全局strict调度。它不提供某个具体异权模板的strict SAT decoder，外端near-unit也不自动给身份。

A外送、不同clauses共享实际H/jobs、非全索引strict可选、多query/return bundles或不同外端资格改变承重前提，需另证。单纯新增资格保留旧actual；新guard若纳入A_c且全前提不变仍受上界，但不宣称任一退出模板修改足够产生hardness。一般UM、所有identity/block-coherence或任意near2 source未被排除。

原源无软件/有限枚举前提，本轮亦无数学run或新blind。新颖性扣除旧分离/Hall/匹配技术；保全的增量是任意私有异权子句网络与真实变量环的完整共同任务合同及两种可复用证明。外审、全球新颖性与UM-TARGET-v1正反面未完成。
