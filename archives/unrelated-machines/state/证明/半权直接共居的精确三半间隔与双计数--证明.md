# 1. 完整原矩阵、域与所证精确值

输入任意显式有限CNF，每clause至少两枚实际文字occurrences，允许重复文字/变量及重复clauses。每occurrence是不同物理索引，只属其自身clause。只保实际出现的变量，各变量occurrences任意排序成环并显式补dummy至环长至少3；dummy不属clause、polarity任取。总索引N、真实索引L=Σk_c、clauses m、出现变量v。非空m>0；空公式另定一idle原机器、零原jobs、OPT0，不能输出零台机器。

每索引有互异原机M_i、C_i及不同原任务q_i、b_i，每clause另有不同原u_c。环后继i⁺，前驱i⁻；正文字s_i=0、负s_i=1，pin(i)=M_i当s_i=0，pin(i)=M_i⁺当s_i=1。参数为输入二进制有理 **3/4<ρ<1**；真实x_i=y_i=1/2，dummy x_i=1且无y/u资格。

| 原任务 | 恰有的全部有限原端 |
| --- | --- |
| q_i | M_i:ρ，M_i⁺:1，C_i:x_i |
| b_i（真实及dummy） | pin(i):ρ，C_i:1 |
| u_c | 每个本clause真实i的C_i:1/2 |

其它∞。非空P共2N原机、2N+m原任务、5N+L有限资格，dense2N(2N+m)。没有预载、虚拟执行端、免费关系、h/D或真实公共R。任务整件恰一次，原资格由实际任务身份给出。

所证为：每个非空域内SAT公式真实OPT=1，UNSAT公式真实OPT=3/2；从**任意给定完整actual峰C<3/2的原调度**可确定性总位多项式解码SAT。这里不是只解码预先规范化的调度，不禁止额外合法q导出、b返回或dummy导出；空公式另有OPT0。相对B改变了权重域和精确最优结论，保独立ID，不能写成任意异权都sharp。

# 2. 不输入源赋值的全公式完整三半调度

任意SAT/UNSAT公式直接放每q_i于M_i、每b_i于C_i，每clause选其任意一枚真实i，放u_c于C_i。全部q/b/u原jobs恰一次，dummy也照原资格执行。

每M恰一q、负载ρ<1；每C有unit b，至多另加其唯一所属clause的一u，因为不同clauses的物理occurrences不同。故C负载1或3/2，dummy C仅b。非空至少一u，所输出这份baseline的峰恰3/2。空公式直接返回idle空调度。

这个构造无需求SAT、未知strict见证、异权B的baseline/active分类或任何matching oracle。它给所有输入实际OPT≤3/2，不能因SAT可能另有更优调度而把这份baseline误叫每个实例的最优解。

# 3. 任意峰低于三半的身份：作者包含计数

取任意非空原P完整actual σ，承诺C_max(σ)<3/2。原M只接受q/b且每内部finite≥ρ>3/4，两件总≥2ρ>3/2，所以每M至多一q/b。每C_i只允许同编号q_i、b_i及本clause的一u；q+b在真实C至少1/2+1=3/2、dummy C为2，都不能同时出现。

作者置E={i:q_i在C_i}、R={i:b_i在pin(i)}。q在C必迫同编号b返回，故逐索引E⊆R。M上的q/b原件总数精确N−|E|+|R|，N台M每台至多一件给|R|≤|E|。因此E=R、每M恰一件，每索引的q在C iff同编号b返回；不允许用别的索引返回抵换身份。

每原u_c在真实C_i耗时1/2，不能与unit b_i共居（和3/2已等于被排阈值），所以该i∈E=R，同编号q_i确在C_i。Dummy没有u资格，不能作为clause见证。

# 4. 独立全槽证明：额外合法去向也全覆盖

general先行稿不用作者E/R链：全部原q/b恰2N件，只能在N台M、N台C执行；由上一节的实际容量，每台至多一件这类q/b。因此全部2N槽恰饱和，每M和每C恰一q或b。

这里没有把u算成独立unit槽，它可真实与q共居。每C_i的q/b候选只同编号两件，故q_i在C iff b_i不在C iff b_i返回pin，得到相同E=R。原u所在真实C排斥unit b，故必须是同编号q+u。这完整覆盖任意未规范化的额外exports/returns、dummy及重复文字；不先改σ、不给身份关系作为输入。

作者包含/件数与独立全槽/饱和都是完整原P上的证明，结论相同但承重计数不同，二者均保留。

# 5. 共同环方向与逐clause实际解码

每索引恰一枚有效环任务e_i：未导出q_i时取该q在M的实际端，导出时取返回b_i的pin。其实际目的地只可能M_i或M_i⁺；定义h_i=0或1分别表示两端。若e_i=b_i，则h_i=s_i。

每M恰一有效任务，M_i入件数为
\[
(1-h_i)+h_{i^-}=1.
\]
故h_i=h_(i⁻)，沿每个变量显式环同一方向z_v。置z_v=0变量True、z_v=1变量False。每clause实际u目的地是其真实索引i，前两节已迫其q导出且b返回，因而s_i=h_i=z_v，该文字在共同赋值下为真。逐clause均有actual u见证，得到整个CNF满足赋值。

不同变量M环隔离，重复occurrences仍有不同job/machine标识；dummy可合法返回并约束同一环方向，却不冒充clause见证。解码只扫描给定完整assignment、原资格和显式环，读实际方向并输出每变量一位，不求解未知SAT、不依赖规范化、匹配搜索或删除任务。

于是UNSAT不存在任何完整C<3/2调度，配全公式上界得到非空UNSAT真实OPT=3/2。等号UNSAT完整witness确实存在，所以解码承诺不能改成C≤3/2。

# 6. SAT的全部原jobs单位构造

给满足赋值，令每变量z_v为True→0、False→1。每clause选一真实真文字i；它有s_i=z_v，且不同clause的选择是不同物理索引。

选中时q_i放自身C_i、b_i放相符pin、u_c放同C_i；未选的全部真实/dummy q沿z_v方向放M_i或M_i⁺，其b留C。每环每索引恰一个有效任务沿同方向，故每M恰一件，耗时ρ或1。选中C有**两枚原任务q_i+u_c**，真实和1/2+1/2=1，b在M；其它C仅unit b。全部2N+m任务恰一次，所有原机峰≤1。

此处共居的是q与u，不能误写q+b：后者真实和3/2，正是低于三半时被排除的组合。无须更改旧源字节来获得正确构造；本页始终明确原任务身份。

# 7. 非空OPT至少1：两种另外完整证明

不能由“某job有可选unit端”推出OPT≥1，因为它可以使用另一个更小端。下界须对任意完整调度证明，并把空公式排除。

**作者原证明。** 反设完整C<1。每b不能在自身C用unit执行，所以R为全部N索引。M仍至多一q/b，件数N−|E|+N≤N迫|E|=N。故全部q在自身C。至少一clause的u在真实C_i，与同编号q实际共居1/2+1/2=1，矛盾；若还有dummy q在C耗时1，更直接违C<1。

**独立稿证明。** C<1也低于3/2，故全槽饱和计数迫每C恰一q/b。任取一clause的实际u所在真实C：若该槽是b，负载至少3/2；若是q，q+u负载1。二者均不可能低于1。因此所有非空实例真实OPT≥1。

配SAT的单位上界得到非空SAT真实OPT=1；UNSAT前节已为3/2；空公式OPT0。不把独立非空下界误写成作者完全相同推导，也不漏作者“R全体→E全体”的独有路径。
