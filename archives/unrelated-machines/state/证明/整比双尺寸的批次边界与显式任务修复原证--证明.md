# 2. 阶段A：负荷可中性，组成严格下降

若有uₛ−uᵥ=d≥2，按固定编号选机器对，源必有macro。记D=ℓₛ−ℓᵥ。

若D≥Q，只移一macro s→v，负荷变(ℓₛ−Q,ℓᵥ+Q)，都在原[ℓᵥ,ℓₛ]区间且和相等。两坐标更加均衡或恰交换，所以整体majorization非增；D=Q时是精确交换，不能要求纯负荷势严格降。

若D<Q，令q=Q−D。整数tick使q正整数，且

\[
q=t_v-(u_s-u_v-1)Q-t_s\le t_v.
\tag{2}
\]

所以原目标v上有足够**实际**tiny可反迁。原子同时将一macro s→v和q枚tiny v→s，新负荷

\[
\ell'_s=\ell_s-Q+q=\ell_v,
\quad \ell'_v=\ell_v+Q-q=\ell_s.
\tag{3}
\]

即精确交换，对每个对称纯负荷势中性。D可为负，macro较多的机器未必较重；q甚至可大于Q，但(2)仍保证q≤tᵥ≤N。全资格/完全同机/共同tiny尺寸承重，不借新资格/拆任务。

两分支均使组成势Ψ=Σuᵢ²变化

\[
\Delta\Psi=(u_s-1)^2+(u_v+1)^2-u_s^2-u_v^2=-2(d-1)\le-2.
\tag{4}
\]

初值Ψ≤k²、始终非负，所以≤floor(k²/2)批，不会因中性负荷交换循环。结束时所有uᵢ只差至多1，**最大值**ceil(k/m)，各值通常为floor/ceil而非都ceil；k0时均0。

# 3. 阶段B：不用未知OPT，tiny精确削平

计算(1)的M。此时每机macro base Quᵢ≤Qceil(k/m)≤M。若ℓₛ>M，源必有tiny；由W≤mM必有某v满足ℓᵥ<M。移一tiny s→v，整数tick给ℓₛ≥M+1、ℓᵥ≤M−1，新两坐标在旧区间内且排序多重集改变，是严格majorization改善。

超额E=Σ(ℓᵢ−M)₊每次恰减1，因接收端更新后不超过M；初始每机超额≤本机tiny数，故E≤N。接收机器不会再成超M源，因此每tiny该阶段至多搬一次，tiny步≤N。结束全部机≤M。

任何调度都有macro件数鸽巢下界Qceil(k/m)，及整数平均负荷下界ceil(W/m)，所以M同时是下界，可达即精确OPT。不是只写两个必要界而未证可达。

也可用G=Σℓᵢ²+Σuᵢ²：阶段A纯负荷平方和非增/组成严格降，阶段B平方和严格降/组成不变，所以每步G严格降。**位复杂度不用G数值范围**，而用前述组合步数；Q binary很大时不按潜在巨大G循环。

# 4. 全部原任务、输入位长和退化

每机器维护macro/tiny原编号列表，固定取最小编号原任务，批次同时更新。每反迁q≤N，全部逐件更新O(k²N+k²+N)次，加原机器对选择/整数计算仍显式多项式。整数负荷≤kQ+N，位长O(log(k+N+1)+log Q)，δ仅正缩放，δM有理位长多项式。没有按Q/1δ/分母值造任务或迭代。

若原矩阵逐机显式给，扫描m按该编码计费。若同机子类仅紧凑给binary m/Q/δ和**逐任务**初始目的地，只维护≤k+N台非空机器及最小未用编号；m>k+N时用空机代表，m≤k+N时扫描已多项式。不能再把k/N也只给binary压缩计数、却要求显式输出全任务去向，然后凭k²+N声称压缩输入位多项式。

m1无迁移且M=kQ+N；k0只tiny削平，N0只macro均衡，空任务M0；Q1允许两类时间相同但原身份仍保。整数Q承重：若Q3/2、m2/k1/N1、δ1，两件分机真OPT3/2，而原整数ceil公式给2，反迁q还可非整数。一般异端时间、非全资格、不同tiny尺寸或受限固定包支持均非本合同。

# 5. strict启动族：中性一步后可严格进展

此特化须m≥2。root两件unit，余每机Q+r枚tiny各1/Q，0≤r≤Q−2。初负荷(2,1+r/Q,…)，向一叶搬unit并反迁r tiny，共r+1件，精确交换两机负荷。高叶此时一unit加Q tiny；再把一tiny送原root，得到(2−1/Q,1+(r+1)/Q)，因Q−r≥2严格majorization改善，随后阶段B到M。

总tick 2Q+(m−1)(Q+r)给此族

\[
M=Q+r+\lceil(Q-r)/m\rceil.
\tag{5}
\]

Q=m²、0<r<m时M=Q+m+r，所以OPT=1+(m+r)/m²，中性批后从高点2Q削到M，共tiny尾步Q−m−r。Q=m/r1/m≥3时M=m+2，尾步m−2。没有直接strict≤r+1件改善与一次r+1件中性再单tiny严格改善相容；不能把前者升级成同预算中性迭代障碍。

与[fixed-work已修正单任务局部极小](../审查/固定工作局部极小与真实凸包固定槽双源审查--审查.md)一致：它已撤回最终大Hamming支持推出多轮固定批次失败的外推。本算法允许包大小随实际tiny数增长，不否定[严格次二三机隔离](../障碍/严格次二中间态的三机批量隔离--障碍.md)的异端时间/资格/固定支持和全程<2合同，也不保证包内逐件临时峰。
