# 1. 原陈述的全部合同

这是一份已有主数学的**完整证明资源**。[近单位PCSP与单位presence胶合双源审查](../审查/近单位PCSP与单位presence胶合双源审查--审查.md)第3.3节已经吸收该结果；[tiny配对槽独立证明与重中端胶合的分域审查](../审查/tiny配对槽独立证明与重中端胶合的分域审查--审查.md)保留了后续review的概览。本页补齐本批作者Proof与Exact-first原稿的每个构造步骤，不再授予一条新定理。五份冻结原件及SHA见[证据说明](../../tools/evidence/heavy-medium-proof-history/README.md)。

有限显式合法UM矩阵P有m≥1台原机器、n≥0枚原任务，时间为非负有理数或∞，每任务至少一个有限端。给正有理T、参数

\[
0\le\epsilon<1/2,\qquad 0\le a<1-\epsilon,
\]

以及同一P的两份**完整实际**调度σ₀、σ₁，均峰≤T。每任务在这两份见证实际使用的端必须属于medium区间[0,aT]或heavy区间[(1−ε)T,T]；未用有限端任意，不要求整个P只有这两档。任务可跨heavy/medium角色、两medium成本可不同、可为零，可静止，可任意arity。两见证是输入，非未知存在量词或分数点。

输出只用各任务两个原见证端。令Hᵢ表示机器i实际接到至少一枚heavy原任务；不是潜在资格或某指定任务身份。给不同v、w，其H在σ₀同为0、σ₁同为1。对每个两位向量都能确定性总位多项式输出全部原任务各执行一次的完整调度τ，并有

\[
C_{\max}(\tau)\le B T,
\quad B=\frac32+\frac{\epsilon+a}{2}
=2-\frac{(1-\epsilon)-a}{2}<2.
\tag{1}
\]

00/11直接返回σ₀/σ₁。以下证明v0、w1，交换名称即得另一mixed。n=0或只有一台机不可能满足完整测量前件，故没有遗漏合法调用。T=0在本ID域外。

# 2. 两重匹配与四类分量

设h=(1−ε)T>T/2。取见证t中全部heavy执行边构成原job—原machine二部图的匹配Nₜ：每任务只有一条执行边，每机两heavy总时间≥2h>T，故至多一条。把共同边固定；该边两端在其它颜色也没有另外的heavy边，确为隔离固定部分。剩余图最大度2，边颜色0/1交替，所以只有路径和交替偶环。

| 分量端点 | 方向选择及原任务账 | 原machine的heavy-presence |
| --- | --- | --- |
| machine—machine | 整条取颜色0或1；内部jobs两色均heavy且全部匹配 | 两端分别只在0/1色occupied，内部机器恒1 |
| job—machine | 两端边色相同，该色为active；active时端点job走heavy；inactive时该job走另一见证的medium端 | 唯一端机active为1/inactive为0，内部机器恒1 |
| job—job | 两端边色相反；每方向恰一枚端点job走heavy，另一枚用其已知medium端；内部jobs走heavy | 全部内部机器恒1 |
| 偶环或共同边 | 选完整一色或固定共同边；全部原jobs各一次 | 相关机器恒1 |

无heavy边的原job在两见证都medium，稍后单独安排。不能因任务有heavy端就把它当成在两见证均heavy的原任务。

v、w仅颜色1有heavy，故只能是颜色1的machine端点，绝非内部机器。二者分量不同：machine—machine路的两端边色相反，不能同时颜色1；job—machine路仅一个machine端点。于是可以在同一份完整选择中同时固定v0、w1。

# 3. v在job—machine路：允许两项增量叠加

从完整σ₁出发，只把v所在active颜色1路径翻成另一方向。端机v失去heavy；w在别的分量，仍为1。内部机器仍恰一枚heavy，但新旧heavy原任务的真实时间可能不同，不能沿用精确unit时“内部负荷不变”。每机heavy最多增加

\[
T-(1-\epsilon)T=\epsilon T.
\]

路径唯一端点job从heavy改为其σ₀原medium端，新增负荷≤aT。该medium目的机可能正是heavy换重的内部机器，两项必须同时收费。所有其它原jobs不变，故全部机器同时满足

\[
C_{\max}\le(1+\epsilon+a)T<BT,
\qquad B-(1+\epsilon+a)=\frac{1-\epsilon-a}{2}>0.
\tag{2}
\]

整条匹配方向及唯一端点任务的medium恢复已经说明每枚原任务恰一次，不是只改读出位而忽略其他任务。

# 4. v在machine—machine路：先定heavy端点，再选真实medium

将v分量选颜色0。w若在另一machine—machine路选颜色1，若在job—machine路选active。其它machine—machine及偶环按固定规则任选；**所有**job—machine路一律active，使这些端点job全部heavy，不产生额外固定medium负荷。共同边不动。余下选择有两类items：

1. 两见证均medium的原job：两选项为其σ₀/σ₁原端及各自真实成本。
2. 每条job—job路：一个virtual item的两个选项分别为两方向留下的两个不同端点原job的medium原端及成本。选项决定整路heavy方向，恰把所指端点job放medium、另一端点job和内部jobs放heavy。

每个选项成本≤aT；即使目的机相同，virtual两选项对应不同原job，成本仍可不同。virtual只是有限方向编码，没有增加物理任务或把原任务分片执行。job—job方向不改变任何机器有无heavy，故后面的medium选择不会破坏v/w已定的presence；它可能换掉某台内部机heavy的**具体任务和时间**，全机界仍需按heavy≤T算。

两选项各取1/2，记机器i所得真实medium成本为μᵢ，原见证的medium负荷为Mᵢ⁰、Mᵢ¹。真实双medium原job和job—job两端的half贡献等于原平均中的对应部分；全部job—machine active只删去原inactive见证的一半非负medium成本。因此

\[
\mu_i\le(M_i^0+M_i^1)/2.
\tag{3}
\]

# 5. 不等成本半积分选择的完整共同舍入

下面引理仅要求每项两个非负成本均≤aT，与heavy身份无关。单选项先固定；同一机器的两选项选较便宜者，其实际负荷不超过两项half均值，按该选择解码相应方向。剩余item的两个incidences位于不同机器。

逐机器把剩余incidences按真实成本非增排序，相邻两两配成machine对，至多一枚未配。每item的两incidences另组成job对。以incidence为顶点，两类对各是匹配，每顶点恰有一条job边、至多一条machine边。并图分量为路径或边类型交替的偶环，可确定性二着色使每对一红一蓝。选择全部红incidences，每item恰选一个真实端。

某机排序为c₁≥c₂≥⋯≥cₛ≥0。每machine对恰选一项，奇数尾项最坏选中，故相对half均值的增加至多

\[
\frac12(c_1-c_2+c_3-c_4+\cdots)
\le c_1/2\le aT/2.
\tag{4}
\]

奇数尾项按正号。中间界来自c₂≥c₃、c₄≥c₅等；偶数最后负项只减小上界。预先固定的同机/单选项不增加原half均值，所以恢复后每机medium实际总负荷≤μᵢ+aT/2。这是**一个共同整数选择**同时控制全部机器，不是每机另选不同方向，也不是随机期望界。

按每virtual所选项恢复整条job—job匹配方向，按每真实item选择放双medium job，再加已固定heavy分量与job—machine active端点。所有原jobs恰一次、仅用σ₀/σ₁原合法端。无需隐藏执行虚拟item。

# 6. 全部原机器的负荷闭合

原见证有heavy的机器medium负荷≤T−h=εT，无heavy者medium≤T。由(3)(4)，逐机的完整账为：

| 两原见证presence | medium平均上界 | 最终heavy上界 | 完整负荷/T | 与B的余量 |
| --- | --- | --- | --- | --- |
| 11 | εT | T | 1+ε+a/2 | (1−ε)/2>0 |
| 01或10 | (1+ε)T/2 | T | 3/2+(ε+a)/2 | 0 |
| 00 | T | 0 | 1+a/2 | (1+ε)/2>0 |

00类在两重匹配都无边，最终不会新接heavy；不能给它凭空加一枚heavy再以medium界冒充全界。其它机最终至多一枚heavy、真实时间≤T。表覆盖所有非测量机和测量机，并和同一份原任务输出相容。配合单路翻转即证(1)。

# 8. 读口反面用途及不能替换的接口

若同一原P的裸heavy-presence复制器有两份上述strict actual，并要求每个峰≤βT的完整调度在v/w只允许同值，当β≥B时，两个mixed实际输出直接否定该合同。gap≥κ>0才给统一阈值≤(2−κ/2)T；只有每实例gap>0时，余量可任意小，不能无κ声称一个固定δ。

本构造不锁产生presence的某枚具体job、不锁其它外部任务位置/边界，不产生源标签decoder；它只要求**见证用过端**有gap。任意未用端可以处于gap、超过T或为零。指定job身份、共同外锁、无两strict输入或gap外见证必须另证，不能从本页推出其可实现或不可实现。
