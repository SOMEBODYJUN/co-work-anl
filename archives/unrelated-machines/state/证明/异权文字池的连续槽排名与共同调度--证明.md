# 1. 对象与用途

此页补全同一 bounded compiler 的一种来源证明，不另登记新的三半定理。[既有三二上界障碍](../障碍/occurrence加权literal-pool三二上界--障碍.md)已有另一独立 all-job matching 及作者离散配对证明；本页保存 typed 的**连续分数长度槽与排名引理**，不能用既有离散图摘要替代这一独有论证。具体原件和SHA见[证据说明](../../tools/evidence/weighted-literal-pool-v2-history/README.md)。

输入是显式 CNF，N个变量、M个clauses、L个occurrence identities，每clause c有 `k_c≥2` 个occurrences。同变量/同文字重复出现仍为不同identity、不同原query和private root。每occurrence e有非负二进制有理 `b_e`，且对每变量v与极性σ分别有

`Σ_(e:v(e)=v,sign(e)=σ)b_e≤1`。

预算计**全部原eligible occurrences**，不是仅最终被选子集；同变量同极性的不同occurrence可有异权，零允许。原矩阵只有下列有限端：

| 原 job | 全部原有限端及时间 |
|---|---|
| 每变量 f_v | A_(v,+):1，A_(v,−):1 |
| 每occurrence j_e | 自己的 R_e:1，自己的 A_(v(e),sign(e)):b_e |
| 每clause s_c | 该clause的每个原 R_e:1 |

不同名字是不同物理机，未列端皆无穷。机器 `2N+L`、jobs `N+L+M`、finite entries `2N+3L`。若N=L=0，合法引用与clause大小条件迫M=0，另给一idle机、零jobs，峰值0。没有其它guards、端点、preload、状态约束或给定SAT/schedule witness。

要输出同一原矩阵的完整actual：每clause恰选一原occurrence，selector去它的root，恰该原query去自身pool，其他query全留原root；每f去自己的一个pool。同时所有root≤1，含f的pool其query-only≤1/2、总负载≤3/2，另一pool≤1。下文对每个该域输入直接构造，不以SAT或实际OPT为前提。

# 2. 包含全部 f 选择的同一个分数图

算法图左侧是每clause一个节点及每原f_v一个节点。每occurrence e∈c在其**原literal pool**给clause一项，分数长度

`x_e=1/k_c∈(0,1/2]`，

项的排序权是实际原处理时间b_e。每f_v在两个原pools各给长度1/2、排序权一的项。每左节点全部分数长度恰一。这只是算法证书，不把原任务拆开执行。

在每pool按权非增排序全部项。由完整预算和非负性，每b_e≤1；故把f的项放在权一的ties之前，能确保f项永远首先，占区间 `[0,1/2]`。query项按实际occurrence identity固定打破ties，依次铺成连续区间。

将总区间按整数边界切成长度一的槽，允许末槽不足一。**正长度重叠**才创建左节点—槽边，边权为所有对应项与该槽的重叠长度总和。clause-slot边保存一个真实occurrence witness；合并多重边时加总其质量并保固定identity witness。f_v只邻它两个原pool的首槽。

每左节点的边权和一，每槽接收质量≤1，因此构成一个共同fractional matching。特别是同clause多个occurrences落同槽时质量相加，仍由槽长度控制，不把它们当多份独立容量。对任意左节点集S，求和得 `|S|≤|N(S)|`；有限Hall/单位容量流整数性给覆盖所有clauses和所有f的一个整数matching。按原索引固定扫描的增广路即可确定性找到，不需要SAT或原调度见证。

每clause选择其匹配边保存的原occurrence e(c)。每f_v匹配其两个首槽之一，因此它的physical pool目的地与所有clause选择由**同一个matching**确定，不是逐变量先各选一份互不相容的条件方案。槽是计算节点，绝不加入原机器集。

# 3. later-slot 的精确排名引理

固定一个matching将原f放入的pool。其首槽已被f占用，任何在这个pool的matched clause必须使用槽序号 `ell≥2`。把该pool全部eligible query按前述顺序记为

`w_1≥w_2≥…≥w_n≥0`，分数长度为 `x_1,…,x_n≤1/2`。

这里x取决于原clause大小，不是w，不假设各x相同。令 `Q_j=Σ_(r≤j)x_r≤j/2`。第j项query区间的右端点是 `1/2+Q_j`。

若第j项和第ell槽有正长度重叠，则右端点必须**严格大于**ell−1。因此

`1/2+Q_j>ell−1`，

`j/2≥Q_j>ell−3/2`，

`j>2ell−3`，故整数j满足 `j≥2ell−2`。

仅在一个端点碰到槽边界时不能建边；否则严格不等式消失，排名界便未经证明。一个匹配边即使有多个witness，每个真实witness都具有正重叠，故任选保存的那个仍满足排名界。对于确有邻接的later-slot，所需排名项必然存在。

第ell槽选中query的真实处理时间因此≤`w_(2ell−2)`。每槽至多匹配一个clause，每occurrence只属于一个clause，同一原query不会被两个clause重复选出。把实际chosen queries按匹配槽求和，得

`queryload≤w_2+w_4+w_6+…`。

由排序、非负性和完整eligible预算，逐对比较给

`2Σ_t w_(2t) ≤ Σ_t(w_(2t−1)+w_(2t)) ≤ Σ_(j=1)^n w_j ≤1`。

故这个**含f的pool**的全部actual query load≤1/2，加原time-one f得到≤3/2。一个尾部奇数项只增加右边；空表给零，n=1时query不能占f首槽所以没有query贡献。另一pool没有f，全部被选queries是其原eligible子集，非负完整预算直接给≤1。

这不是由旧uniform variable-capacity count flow自动推广异权；加权证明真正使用排序与上述even-rank估计。任意小正权和零权都在同一排序内，没有除以w。

# 4. 回到全部原 jobs 的共同 actual

对每clause c，把其原selector s_c放在所选occurrence e(c)的原R_e，把**同一枚原j_e**送到它的原literal pool。每个其他query留自己的原root。每原f_v去其匹配首槽所属的原pool。

原occurrence只属于一个clause，故不同clause选择的roots不同，即使文字或变量重复。选中root只有其time-one selector，未选root只有自己的time-one query；每root负载恰一（若无root，此陈述为空）。所有原f、queries、selectors各执行一次，目的地都是原finite端。selected zero query仍在原pool以零执行；unselected zero query在原root以一执行，不删除job或root。

第3节所有pool界和本节root界属于这**同一张完整actual**，所以Cmax≤3/2。unused variable只有f，任选一pool峰一；空formula但N>0同样只执行全部f；N=L=0使用第1节idle分支峰零。算法不声称该上界锐、不保证最优值恰3/2，也不因零权上界成立而给strict-SAT等价。

# 5. 编码规模和确定性总位成本

每pool一个长度1/2的f项及d个长度≤1/2的query项，槽数至多 `1+floor(d/2)`，全pool总数≤`2N+L/2`。每query区间长度≤1/2，正重叠至多两个槽；全部occurrences最多给2L条witness边，加每f的两个首槽边。图顶点O(N+L+M)、边O(N+L)，多重边可保留或合并。左侧不包含原query节点，后者由chosen occurrence精确恢复，不是丢任务。

排序用b的精确二进制有理比较，cross multiplication的位长受输入分子分母位长之和控制。分数端点是1/2与若干1/k_c之和；公共分母可取其分母乘积，其二进制长度是各分母编码长度之和，按显式occurrences计多项式。只对有理端点做加法、比较与整数除法定位相邻槽，不按这个分母的数值复制节点，也不沿所有分母刻度循环。

正重叠边和固定identity witness可用这些有理比较构造。匹配只处理有限图索引，最多N+M次增广，每次图规模内多项式；实际输出按原job列表线性恢复。预算如需验证，可用精确有理求和，公共分母乘积的位长同样由输入总位长控制。假设承诺输入时无需先算这些和来决定matching。

因此从完整显式CNF、b编码及其原矩阵得到完整actual的总位时间/输出位长多项式；没有按 `1/b_e`、最小正权、分母数值或隐式状态数展开。无CONFIG/SDP/unknown strict oracle。两份对应主源没有软件实现或有限实验；本轮也没有运行该数学算法。

# 6. 与另两种构造的关系和限制

[来源与终审审查](../审查/异权文字池的三种匹配来源与终审先验--审查.md)另完整保存作者的离散clause-only图，以及新独立审者的全部原job图和回根清理。三者都在**同一个physical矩阵域**达到同样的实际保证；连续分数槽的图结构与离散配对图不同，不声称它们逐边相同、输出matching相同或所有合法输出集合双射。可明确消去f/root-query选择的关系是离散all-job图与作者离散clause图之间，不能无证推广成连续图的全输出等同。

本证明只排每sign完整预算≤1、独立private roots、恰列有限端的这一个compiler作为near-two NO源。额外cross-clause端、shared guards、更大预算或不同约束均需重证；旧直接共居B/C模型的sharpness/SAT/审查不转移过来。标准匹配工具没有新颖性声明；一般UM近似、实际gap或hardness主目标仍开放。
