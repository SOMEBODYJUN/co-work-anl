# 条件叶：每行可分解和同一联合分布不同

设核心c在状态s的边际为λ_cs。每个条件叶流y_cs的行和为λ_cs、局部资源列与本状态占用z_cs合计至多λ_cs。MC进一步要求∑_s y_cs,ℓu=y0_ℓu，所有核心平均后具有相同global叶边际。

这些约束提供每个(c,s)的一份matching mixture，不提供一份同时抽取所有核心状态和同一个叶匹配的联合概率μ。后者还须保证：μ的核心状态边际是λ，每个条件叶边际确为y_cs，且每个样本下全部已选核心资源和叶匹配共同不超容量。逐行分解没有包含最后这个全体状态约束。

[MC独立重构](../审查/条件叶Hallv3新MC独立重构--审查.md)给出完整正面机制：对每条旧资源的端口，令b_i=∑_s z_cisu，选π_i≥b_i、∑π=1；用hole表
\[
q_{s,j}=θ_s1_{j=i}+\frac{λ_s-θ_s}{1-β}(π_j-β1_{j=i}),
\quad θ_s=z_cisu,\ β=\sum_sθ_s<1
\]
构造共同边际。β=1另取q_si=λ_s，避免除0；d=0/1、零λ保留。用各path的有理区间分割合并可多项式构造每个条件行的完整matching mixture。这证明指定LP投影接口，并不自动构造all-core law；Q_t全参数真实福利值仍按原证明来源的具体等级处理，不能从t=2检查数外推。

一个仅说明概率兼容性的抽象警告：三个0/1变量都边际1/2，每一对可取互斥联合分布；若要求三对同时互斥，则每样本总和至多1，却期望总和3/2，矛盾。它不是从原UM矩阵恢复的反例，只表明相同一阶边际和各局部耦合不足以蕴含共同联合分布。

# 私有汇点：同sink事件控制实际集中迁移

[私有汇点精确合同](../审查/最优凸包长链与私有汇点边界两源精读--审查.md)的r个homes各有k件small（home/sink时间1/k）及一件只能选home的unit大任务，真实OPT=1。固定最优凸包边际使每件small进其sink的概率1/r。要达到Cmax≤2−ε，大任务所在home的至少q=ceil(εk)件small必须一起进同sink。

若再强制同一sink两不同small的联合概率≤1/r²，记N_i为进入该sink的small数，则
\[
\Pr(C_{max}\le2-ε)\le\sum_i\Pr(N_i\ge q)
\le\frac{r\binom k2/r^2}{\binom q2}
=\frac{k(k-1)}{r q(q-1)}\quad(q\ge2).
\]
这针对固定边际及同sink二阶事件，容许正相关的最优混合不受排除。不能把一份共享sink的存在型assignment替换成这些概率事件。

# 共享汇点与其它对象的适用前提

[共享宏任务与占位基](../资源/共享汇点宏任务与占位基的联合选择--资源.md)已有自足算法：同组共同sink资格下的Hall组流、单sink实际覆盖子集成本+宏dummy匹配、完整profile池恢复，以及固定K的occupation base和3/2保证。每项各有自己的promise、真实物品资格及时间域；它们不被上述局部边际缺口否定。有限输入页中的zero target、empty homes/sinks、dummy cost、巨大分母和REJECT_TARGET分别保留，拒绝promise不是一般无调度反例。

树估值的单状态minorant LP、signed demand和投影向量固定次序贪心只提供各自集合估值/给定分布接口。它们不会自动给叶条件流或同sink事件的共同调度law。当前待补的具体义务是同一原模型中的全体状态/资源联合可行性和实际解码；不能以有限匹配片数、单机边际或某个路径峰代替。
