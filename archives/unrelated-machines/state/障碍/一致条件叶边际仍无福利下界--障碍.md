## 2. 完整 flat 菜单和实际 UM 矩阵

输入有有限资源集 U、非空组集 G、每组非空显式 indexed state 集合 S_g。state 系数 p_gsu 是非负二进制有理数，每 state 总和为 1；允许零系数、重复 indexed states、unused resources 和显式 zero incidences。对资源束 B 定义

`v_g(B) = max_s sum_{u in B} p_gsu`,

并定义不相交 bundles 的福利

`V(Q) = max_(B_g pairwise disjoint) min_g v_g(B_g)`.

完整 ordinary flat processing matrix P(Q) 保留每个 indexed state 的 private root、每个 resource machine、每组 unit selector，以及每件 `(g,s,u)` 的独立 original job。该 job 在 M_gs 上用时 p_gsu、在 R_u 上用时 1，所有其他端均不可用；包括 zero incidence 和未选 state 的 jobs 都必须存在并执行一次。v3 使用严格关系

`OPT(P(Q)) = 2 - V(Q)`.

这一步的实际任务身份与此前 `归一化菜单福利与配置证书双源审查` 相同；不能把 state 选择后删除 jobs，也不能把 V(Q) 当作算法输入。

## 3. threshold-unit-demand 预处理和旧 R1-R2

给定二进制有理 epsilon in (0,1]，令 `T=2-epsilon`，定义

`H_g(epsilon) = {u : max_s p_gsu >= epsilon}`,

`b_g(epsilon) = max_s sum_{u notin H_g} p_gsu`.

令 L 为满足 `b_g(epsilon) < epsilon` 的 groups，C=G\L。对每个 ell in L，`v_ell(B) >= epsilon` 当且仅当 B intersects H_ell；singleton unit-demand groups 也在此合同中。v3 特意说明，Q_t 的反例不是依赖把 threshold-unit-demand group 错误留在 C。

对每个 core c in C 和 state s，引入 lambda_cs >=0（每组 lambda 和为 1）与 `0 <= z_csu <= lambda_cs`，support 外 z=0。约束 R1 是

`sum_u p_csu z_csu >= epsilon lambda_cs`.

引入 global leaf flow `y0_ell,u`，以及每个 core-state 的 conditional leaf flow `y_cs_ell,u`，均只支持 H_ell(epsilon) 的 leaf edges。R2 要求：

* 每个 leaf ell 的 global row sum 为 1；每个 resource 的 `sum_cs z_csu + sum_ell y0_ell,u <= 1`；
* 对每个 core-state `(c,s)` 和 leaf ell，conditional row sum 为 lambda_cs；
* 对每个 core-state 和 resource，`z_csu + sum_ell y_cs_ell,u <= lambda_cs`。

每个 conditional column 只含该 state 的 z，不含其他 cores 的 usage；不要求 complete leaf matchings 或 states 之间的 joint distribution。zero lambda perspectives 的 z 和 flows 全为零；empty C、empty L、d=0/1/2、unused resource neighborhoods、zero coefficients 都按字面保留。

来源 v1/v2 的 necessary-relaxation claim 是：若 `V(Q) >= epsilon`（等价 `OPT(P(Q)) <= 2-epsilon`），则 R1-R2 可行；该 LP 的变量/约束数量按显式 state incidences 多项式。它只是必要测试，不能把可行性当实际整数调度。

## 4. v3 的 degree-three path family Q_t

固定整数 `t >= 2`，令 `D=t^2`。旧资源为

* `g_(a,j)` for a,j in [D]；
* `A_(a,h)` for a in [D], h in [t].

有一个 core group M 和每个 `(a,j)` 一个 core group H_(a,j)。M 有 D 个 states；state a 在每个 `g_(a,j)` 上权 `1/D`。每个 H_(a,j) 有 home state（在 `g_(a,j)` 上权 1）和 parking state（在所有 `A_(a,h)` 上权 `1/t`）。所有 state 总和为 1，包含 unit coefficients；parking 是完整 normalized state，而非小扰动。epsilon=1 时，且固定 epsilon 后 t>1/epsilon 时，这些 core groups 不进入自动 threshold-unit-demand 集合。

对每个旧 resource，按固定顺序列出 positive core neighbors。把一个 d-neighbor resource 换成 d 个 distinct ports，并将每个 core 的该 resource 系数转移到自己的 port；新增 d-1 个 path-leaf groups，每个 leaf group 有两个 singleton states，分别在相邻 ports 上系数 1。该 operation 是已有 BCG adjacent-dummy/path-copy 机制的应用，不声称是新构造或一般 normalization。所有 ports、原 states、叶 states 和 original jobs 都保留；在该 family 中每个 resource 至多属于三组且至多三个 indexed states，新增 leaves 正好构成 epsilon=1 的 threshold-unit-demand groups。

## 5. 旧 R1-R2 的 feasible sharp family claim

v3 声称对每个 t>=2，Q_t 的 complete R1-R2 在 epsilon=1 可行（因此 T=1）。给出的 rational point 为

`lambda_(M,a)=1/D`,

`lambda_(H_(a,j),home)=1-1/D`,

`lambda_(H_(a,j),parking)=1/D`,

且每个 positive core-state incidence 取 `z=lambda`。global leaf flow 每行恰为 1，并与 core z 的 global resource columns 同时相容；每个 core-state 的 conditional leaf flow 可以取为 lambda_cs 乘以一个覆盖全部 path leaves 的 integral matching。来源强调：旧反例不依赖遗漏 leaf、fractional conditional matching defect 或 perspective capacity 的误读。原 positive-support FSLP(1) 也可行。

但同一 explicit input 的实际值声称为

`V(Q_t)=1/t`,

`OPT(P(Q_t))=2-1/t`.

上值由显式 pairwise-disjoint bundles 和完整合法 schedule 达到，下界量化所有 state choices、partial bundles 和 complete ordinary schedules。zero incidences、unused resources、duplicate states 可追加而不改变该族值。固定 epsilon>0 时取 t>1/epsilon，就得到 relaxation 在自身 threshold 下可行而 `V(Q_t) < epsilon`、`OPT(P(Q_t)) > 2-epsilon`。来源没有声称该族在所有反例中参数最小；t=2 的具体规模是 17 cores、40 leaves、64 resources、116 indexed states、144 positive incidences、180 machines 和 201 jobs，精确值 `V=1/2`、`OPT=3/2`。

这部分是一个很强的候选障碍：即便 R1-R2 的每个 conditional state 有完整 matching，relaxation 也可能没有任何正的 uniform welfare floor。然而源文件本身没有给出 flow formula 或 combinatorial proof，故本页不将 `GAP` 标为已证明。

## 6. 一般 path projection claim

对任意 finite explicit normalized menu Q，先指定 nonempty core set C、epsilon 和 basic polytope B：只含 lambda/z normalization、bounds、R1 与旧 resource columns `sum_cs z_csu <= 1`。对每个 old resource u 的 d>=1 distinct positive core neighbors，建立每邻居 group 一个 shared port，转移该 group 在 u 上的系数，新增 d-1 adjacent path leaves；d=0 保留 unused resource，zero incidence 仍保留并指定合法 port/unused endpoint。

v3 的 Exact projection theorem 声称：full R1-R2 on Q^path 投影到原 lambda/core-z 变量后正好等于 B，适用于任意 rational epsilon、fractional z、zero lambda、d=0/1、zero/unused data；每个 basic point 有 polynomial-bit rational extension，且 path operation 保持 `V(Q^path)=V(Q)`、`OPT(P(Q^path))=OPT(P(Q))` 和 positive-support FSLP(1)。该 theorem 的共同前提是 C 由设计指定且新增 leaves 才属于 L；若把所有 threshold-unit-demand groups 自动加入 L，而原 groups 也满足阈值条件，则才可按其表述应用。无此前提时，额外原 groups 进入 L，projection equality 可能失效。

该 projection claim 与现有三坐标零权切片、资源度三路径和三态正规形对象相邻，但它保留的是一个特定 LP 的 lambda/z projection 和 welfare value，不是任意 UM 的 normalization 或 approximation-preserving reduction。

## 7. v3 新增 R_cons 一致边际约束

v3 第 9 节在同一指定 partition C/L 和同一 path operation 上增加：对每个 core c 与每个 leaf edge `(ell,u)`，加入

`sum_s y_cs_(ell,u) = y0_(ell,u)`.  (MC)

这要求每个 core menu 的 conditional flows 平均后具有同一 global leaf-edge marginals，但仍不要求 complete matching 的共同 joint distribution 或 all-core state coupling。来源声称：任何 genuine epsilon allocation 的 deterministic witness 满足 MC，因此 R_cons 仍是 necessary relaxation；新增约束数量至多 `|C| * E_L`，LP 仍有 deterministic total-bit polynomial construction/feasibility。

**New exact projection assertion.** 对任意 old normalized menu Q 和 section 8 的任意 basic feasible point `(lambda,z)`，存在 R_cons extension on `D_+(Q)`，保持原点、具有 polynomial rational bit length，并可确定性位多项式构造；反向 projection 仍给 basic point。extension 可能需要每个 conditional flow 是完整 integral leaf matchings 的 rational convex mixture；v3 特意不把 section 6 的“每 state 单一 integral matching”错误转移到 R_cons。

**New sharp-family assertion.** 同一个 Q_t 在 epsilon=1 下，R_cons 对同一 lambda/z 仍可行，实际 `V(Q_t)=1/t`、`OPT=2-1/t` 不变。固定 epsilon>0 且 t>1/epsilon 时，自动 threshold partition 仍为指定 C/L；因此即使加入一致全局叶边际，仍无正的 constant welfare floor，也不能从该 unit relaxation threshold 得到 uniform below-two guarantee。

## 8. 与现有有限证据和相关对象的比较

现有 `条件叶Hall与共享汇点联合审查` 的三个 conditional-leaf/flow 证据提供有限但重要的邻接事实：

* `conditional_leaf_consistent_marginals_independent.json`（source ID `409bcd01bd377010b36d`）保存 17 cores/40 leaves/64 resources/36 states 的 `global_leaf_flow`、conditional flows、matching mixtures、holes 和 loads；主族有 1,440 条 conditional rows、2,304 columns、1,360 MC rows、176 integral matching pieces，并保留 partial-z、zero-lambda、d=0/1/2、epsilon=2/5 与 beta=1 fixtures。
* `conditional_leaf_hall_path_projection_independent.json`（source ID `e7c981ac171cf2eb2260`）保存 t=2,D=4 的 path family：17 cores、40 leaves、64 resources、116 states、144 incidences、180 machines、201 jobs、404 finite entries，actual peak 3/2；同时有一个 partial-z/zero-lambda/zero-job toy。
* `conditional_leaf_hall_root_replay_scope.json`（source ID `a36b4eba229032d2fb63`）只登记 root replay scope，明确未测试 larger instances、general LP backend、joint-core/PSD constraints 和 hardness。

这些有限 JSON 与 v3 的 Q_2 尺寸和 marginal-consistency 语义相容，但它们不是 v3 的一般 projection proof，也不能认证任意 t、R_cons sharp family 或 `V=1/t` 全参数公式。现有审查已经明确“同边际不等于一个对所有 core states 同时适用的统一 joint matching oracle”；v3 的 MC 行只加强 edge marginals，仍不加入该 joint law。

与 `归一化菜单福利与配置证书双源审查` 的关系是接口级：FSLP/CONFIG(1) 的正-support 双向桥说明分数证书可以由完整 flat matrix 表示，但配置可行不自动给 integer perfect completeness。v3 的 Q_t 把这个分离推进到 R_cons，但仍然没有给出一般 algorithm 或 source hardness。
