# 对象身份与主边界

本源是 UM-FIXED-ARITY-WITNESS-FILTER-v1 与 UM-FIXED-ARITY-OVERLOAD-HARDNESS-BARRIER-v1 的作者草稿，完整读取 14325 字节，SHA-256 为 `fae679e37387eb91c3227bcc630dcbcc68e74f55de2ca897ec2ececd9e0d8fd0`。它研究固定正整数 r 下“每台机器最大至多 r 件任务之和”这一局部目标，明确不声称普通总 makespan 的近二算法或一般困难性。本文按 proof-read candidate 保存；有限程序若只验证给定证书，不替代一般行引理或 LP 位复杂度证明。

定义 `B_r(σ)` 为调度 σ 中每台机器最大至多 r 件任务处理时间之和的最大值。固定常数 `c_1=1`、`c_2=1/2`、`c_r=6^{-(r-1)!/2}`（r≥3；等价递推为 `c_r=c_{r-1}^{r-1}`）的候选过滤器声称：给定二进制有理阈值 T，确定性位多项式程序要么可靠 FAIL 并保证普通 OPT>T，要么输出完整保留端调度 σ 且 `B_r(σ)≤(2-c_r)T`。成功只约束 B_r，不约束普通总负载；不相对 `min B_r` 宣称近似。

若固定 `rho≥2-c_r`，YES 为 OPT≤T、NO 为所有完整保留端调度均有 `B_r>rho T`，则运行该过滤器即可判别此 promise；因此除非 P=NP，不能有从 NP-hard 源到该精确固定-r promise 的确定性多项式编译。这个推论只针对全称 NO 和固定 r，不是一般 makespan hardness。

# r=3 容量流与 11/6 包络

三槽网络对每台机器建立首槽（端处理时间 ≤T）、次槽（≤T/2）和 light 池（≤T/3，容量 n）。每任务连到所有合格机器槽，整数最大流若不能覆盖全部任务则 FAIL。任何普通 T-调度按每机非增顺序分配：第1件进首槽、第2件进次槽、其余进 light，故 OPT≤T 时流可行。成功流每机至多一件首槽、至多一件次槽，其余不超过 T/3，得到 `B_3≤T+T/2+T/3=11T/6`。r=2 退化为首槽加 ≤T/2 light，r=1 为任意 ≤T 端。

三件时间 1、1/2、1/3 的中心机加各自私有时间 1 的替代端给出该流输出包络 11/6 的锐性；它不证明任何最优 B_3 算法的近似界锐，也不构成 11/6 hardness。

# 固定前缀的配置行余量

对任何一台机器的真实局部配置概率分布（每份配置总负载 ≤T），按任务大小非增切单位槽，令第 s 槽相邻任务的最大时间为 a_s。候选行引理给出对固定 r：

`sum_{s=1}^r a_s ≤ (2-c_r)T`。

a1≤T；严格正交长给第 s 槽阈值 `a_s≤T/s`，先得到 r=2、3 的 3/2、11/6 初值。对 r≥4 令 `D=1/c_{r-1}`，若 `a_r≤T/(D+1)`，直接用归纳式；否则删除小于 `a_r` 的任务，按阈值分成 d=r−1 类。每个实际配置的整数类型向量 c 满足 `||c||_1≤D`、`c·b≤1`，而槽正交给所有前缀计数 `E(sum_{v≤t}c_v)>t`。类型多面体的活约束行是整数范数至多 D 的类型行、排序行和非负行；其顶点目标严格小于 1，Cramer 行列式上界 `D^d` 强迫 `sum b_t≤1-D^{-d}`，即递推余量。该论证只控制固定前缀 r，允许原配置含任意多 tiny 任务。

# 显式 big-only LP 实现接口

固定 r≥4，取 `delta=c_{r-1}/(2r)`、`K=ceil(1/delta)`。每台机器枚举大小至少 `delta T` 且总和 ≤T 的 big 配置（空配置包含）；变量 x 覆盖全部保留端，y 在每机 big 配置上取和为一，并约束 big 边的 x 等于对应 y 的配置边际。普通 T-调度给出 LP 可行点，因此 LP 不可行时可靠 FAIL。对任意有理解用标准非增槽匹配获得完整真实分配。

若该行 big 质量的向上取整 q_i≥r，前 r 槽受行引理控制；若 1≤q_i<r，后续槽的最大任务至多 delta T，由较短前缀的更大余量支付；若 q_i=0，r 个 tiny 槽总和至多 r delta T。于是同一实际输出满足 `B_r≤(2-c_r)T`。每行配置数至多 `sum_{ell≤K}n^ell`，r 固定时 LP、槽匹配和有理位复杂度均为输入位长多项式。该构造没有实现一般 CONFIG(T) oracle，只枚举固定阈值以上 big 配置。

# 严格次二局部障碍

作者同时给出固定三机实例：取 `k≥2`、`alpha=1-1/(8k)`、两件大任务、各叶 2k 件小任务、每机私有 padding `1-alpha`。坏态峰值 `2-1/(8k)<2`，全局最优为 1；若中间每步至多改变 k 件任务且所有中间态严格小于 2，则保持峰值 `<2` 时首次安全出口必须同步移动一件大任务和对应叶的 k 件小任务，共 k+1 件。参数化地，任意固定支持预算 r 可选 k>max(r,1/(8epsilon))，使坏态仍大于 `2-epsilon` 而首出口需 k+1>r 件。

这是局部状态图的严格 `<2` 批量障碍，不排除无界批量、允许穿越 2、全局重求解或其它全局证书；不能把有限脚本的 k=2,3,7,100 输出升级为所有 k 的独立软件证明。后续若使用该障碍，必须保留“固定 r vs 随 epsilon 增长”的量词。

# 与仓库对象和未闭缺口

本障碍与已有固定配置基数/单位槽舍入对象共享严格槽和 Cramer 工具，但它固定输出前缀件数 r，允许源配置含任意多 tiny；不能写成普通总 makespan 的约束。与资源畸变、周期菜单和双树 CONFIG 对象分别保持局部目标、状态图和配置证书身份。
