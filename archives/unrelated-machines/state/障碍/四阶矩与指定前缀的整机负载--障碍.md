# 四阶矩与指定前缀的整机负载

这是指定来源分布的条件信息非识别，不是一般C₂松弛gap，也不限制算法改变耦合、重求证书或选择另一真实来源。旧见证只检查一个literal，完整B负载却抵消为常数；本页保留修复后的原存在性合同。

## 矩阶数与真实条件量

每个任务的合法端literal为one-hot布尔变量x_e。真实有限分布μ给y_S=E_μ[∏_{e∈S}x_e]。若相容前缀F有y_F>0，机器i的**完整**真实条件平均负载为

\[
L_i(\mu\mid F)=\frac{\sum_{e\in E_i}p_e y_{F\cup\{e\}}}{y_F}.
\]

深度t的标量负载一般需t+1阶，degree-one负载localizer需t+3阶，普通C₂矩加该localizer整体最高需t+4阶。四阶数据直接可算t≤3的标量条件负载，不能据此自动得到深度四的真实续局容量。y_F=0时条件式不定义，必须裁剪分支或另给条件证书，不能除零后声称容量。

## 同一矩阵、两份真实最优来源

取机器A、B、C，T=2，七件任务：任务1–4在A/B两端均0；任务5在A/B两端均1；任务6在A/B两端均0；任务7只在C用2。未列端不可用。

对前四任务，bit z_r=1代表A、0代表B；对任务5，z₅=0代表A、1代表B。两个来源都固定任务6→A、7→C，分别在五bit偶、奇Hamming重上均匀分布，各16个调度。每份A/B负载是(1,0)或(0,1)，C为2。任务7给OPT≥2，所有支持调度达到2，所以都是同一矩阵的真实最优来源。

任意至多四个合法端literal的乘积，若同任务互斥则为零；否则仅固定至多四个非平凡bit。任务6/7的literal为常量或零，不增加所见bit数。五bit奇偶类对任何未固定的bit有相同补全计数，故**全部≤4阶实际one-hot矩**相等，包括由同一矩阵定义的M₂和负载localizer。

取F={前四任务均去A}，即z₁=…=z₄=1。两来源均y_F=1/16。偶来源强制z₅=0，完整条件负载(A,B,C)=(1,0,2)；奇来源强制z₅=1，负载(0,1,2)。五阶y_{F∪{x_{B,5}}}分别0与1/16。这里完整B负载只有任务5贡献，未把literal概率偷换成整机负载。

## 旧见证为何失败、修复保留了什么

旧见证含任务5和6互补地在A/B耗时3/2，无论所查literal如何，完整B总负载恒3/2。旧程序检查指定literal的0/1，不足以认证原文所称整机负载差异。替代见证改变实际Objects及审计，保留原存在性陈述的同一矩阵、真实OPT2、四阶相同、条件B为0/1的量词；不能倒称旧证明已经正确。

既有[C2前缀有限审计](../审查/C2前缀满载与单位多切片有限审计--审查.md)已保原报告；本页补自足矩阵、两个分布和补全计数。独立原程序不导入规范审计，穷举全部64个原矩阵合法调度、13个实际端literal的1093个≤4阶子集（706相容、387互斥零项），检查2142个one-hot乘子守恒。M₂维86、精确PSD秩16；三个degree-one localizer维14、秩6、6、0。这些秩是该有限矩阵的确切核验，不冒充任意C₂系统定理。

本轮实际重新运行该独立原程序，完整JSON与冻结报告一致；未运行未取得的规范修复审计。原字节和stdout见[核验资源](../计算/重配置比较依赖与恢复纠错的精确核验--计算.md)。深度任意t的编码及高阶oracle仍另需复杂度证明；本例不能推出所有下一步选择相反、一般舍入不存在、C₂+CONFIG的任何新gap或UM困难性。阶段三可登记旧literal误测→整机修复、相同四阶→指定来源负载非识别及重新耦合不受限的边界。
