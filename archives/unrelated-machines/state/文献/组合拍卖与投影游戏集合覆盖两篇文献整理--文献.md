## 1. Dobzinski–Nisan–Schapira：Approximation Algorithms for Combinatorial Auctions with Complement-Free Bidders

### 模型与查询

有 `m` 件异质不可分物品、`n` 个 bidder，估值 `v_i(S)` 对 bundle `S` 单调、归一化；目标是最大化社会福利 `Σ_i v_i(S_i)`。complement-free（CF）即 subadditive：`v(S∪T)≤v(S)+v(T)`；XOS 是更窄的“加性 clause 的最大值”类。作者把估值当黑箱，区分 value query、demand query 和 general query；算法/下界的成立模型必须连同 oracle 假设读取。

### 主要算法与界

1. **CF demand-oracle 算法（Theorem 1.1/Section 3.1）**：从 configuration LP 的最优分数解随机舍入成 pre-allocation，使每件物品最多出现在 `k=O(log m/log log m)` 个 bundle，且总福利仍保持常数比例。把每个 bundle 按物品出现次数分成 `k` 层 `S_i^r`，固定层内物品不重叠；由 subadditivity，至少有一层保留 `1/k` 的总价值。原稿更早写成 `O(log m)`，Feige 的校正把实际界写成 `O(log m/log log m)`，并给出相应下界示例。
2. **XOS**：用 demand query 先生成 pre-allocation，再用每个 bundle 的 maximizing XOS clause；Theorem 1.2 给出 `(e/(e−1))` 近似，另有确定性、组合式、快速的 2-approximation（Theorem 3.3）。2-approx 的价格过程单调：每阶段对 demand bundle 取 clause price，最终价格和下界住算法福利，而任意最优分配的福利至多为最终价格和的两倍。
3. **Truthful/value-query 方向**：Theorem 1.5 给出只用 value queries 的 truthful `O(√m)` 近似；Theorem 1.6 证明只用 value queries 时，即便 XOS 也不能以少于指数查询达到 `m^{1/2−ε}` 级更好近似。truthfulness、oracle 次数和 approximation factor 是不同维度，不能用 demand-oracle 结果替换 value-oracle 结果。
4. **下界**：CF 估值在 general-query/communication 模型下，优于 `2−ε` 需要指数通信（Theorem 1.3）；XOS 在给定 bidding language 下，优于 `e/(e−1)` 是 NP-hard，在 oracle 模型下也需指数通信（Theorem 1.4）。正文还记录后续工作对 CF 上界、机制和 submodular 查询模型的改进，当前整理只把原文结论与后续边界分层保留。

### 证明义务与限制

- 随机舍入的 item-load tail、Chebyshev/union bound 和 subadditivity 共同给出常数比例；没有 subadditivity，按层分割不能保持总价值。
- XOS clause oracle 在一般 XOS 下不等同于 demand oracle；正文明确指出 submodular 情况可用 demand/value oracle 得到 clause，而一般 XOS 不能自动模拟。
- 这些是福利最大化和机制设计模型，不是 MaxMin/makespan、vector capacity 或当前五/六人 SPE。归档用途是提供配置 LP、oracle 分层、随机舍入和有限福利算法的文献接口，不把 `e/(e−1)`、2 或 `O(√m)` 当成当前对象的结论。

## 2. Moshkovitz：The Projection Games Conjecture and the NP-Hardness of ln n-Approximating Set-Cover

### Label Cover 与 list-agreement

Label Cover 输入二部图、两侧字母表和边投影 `π_e`；目标最大化满足边比例。Projection Games Conjecture（PGC）要求在近线性规模和 `poly(1/ε)` 字母表下，把 SAT 变成几乎完美完整性、soundness `ε` 的 projection Label Cover。作者还定义 list-agreement soundness：A 侧每点可给 `ℓ` 个标签，B 点若没有两邻居在投影后相同则“total disagreement”。Lemma 4.7 说明 ordinary agreement soundness `ε₀` 可通过随机从每个列表取一项转成 list-agreement soundness `(ℓ,ε₀ℓ²)`。

### Set Cover 归约

- Dinur–Steurer 的平行重复结果（Theorem 2.3）把 almost-linear PCP 转成大小 `N^k`、字母表指数依赖 `1/ε,k`、soundness `(2ε)^{k/2}` 的 projection game；Corollary 4.8 进一步得到多对数列表长度、常数 B-degree 和 list-agreement soundness。
- Naor–Schulman–Srinivasan partition system（Lemma 4.9）给出 `D`-划分：若每个 partition 至多取一集，覆盖 universe 至少需要约 `D ln|U|(1−α)` 个集合。对每个 B 点复制 universe、对每个 A-label 建 set，若 Label Cover 完整则每个 B-universe 用一个一致 partition 覆盖；若 set cover 太小，则有足够多 B 点违反 total disagreement，反推出 list-agreement 违背。
- Claim 4.10 给出 completeness 与 soundness：完整情形 set cover 大小为 `|A|`；list-agreement soundness 情形下任何 cover 超过约 `|A|ln|U|(1−2α)`。令 `N=|B||U|` 后，Theorem 1.2 得到：对任意 `0<α<1`，SAT 可在多项式时间归约到大小 `N=n^{O(1/α)}` 的 Set Cover，使 `(1−α)ln N` 近似在相应假设下 NP-hard；指数时间假设下该规模膨胀量级近乎最优。

### 其他应用与开放条件

Theorem 5.1 把低 soundness Label Cover 归约到 Closest Vector Problem 的多项式因子硬度；Theorem 5.2 在 linear PGC 下把线性 Label Cover 归约到 MAX-3LIN 的 `1/2+N^{-c}` 窗口硬度。作者明确把 PGC、linear PGC、Shortest Vector 和更广 CSP 阈值列为开放问题；Set Cover 结论依赖 PGC/平行重复参数链，不能拆成无条件的任意 set-system 结论。
