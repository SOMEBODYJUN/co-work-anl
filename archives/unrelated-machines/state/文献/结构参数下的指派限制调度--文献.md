# 模型和三种限制图

有有限任务集 (J)、机器集 (M)，任务 (j) 在机器 (i) 上的加工时间 (p_{ij}) 可为正有限数或 (infty)。合法调度是把每个任务完整分配到一台允许机器，
\[
 C_{\max}(\sigma)=\max_{i\in M}\sum_{j:\sigma(j)=i}p_{ij},
\]
并最小化该值，记作 (R||C_{\max})。当同一任务的所有有限端时间相同，即 (p_{ij}\in\{p_j,\infty\})，得到 restricted assignment (P|M(j)|C_{\max})。文章在 Section 2 约定通常考虑每个任务至少有一个有限端；空任务实例的最优值为 0。

限制通过三张图编码：

* **primal graph** 的顶点是任务；若某台机器可以同时处理两任务，则这两个任务相邻。
* **dual graph** 的顶点是机器；若某任务可在两台机器上处理，则这两台机器相邻。
* **incidence graph** 是任务与机器的二部图，边正是允许的任务–机器端。

任务和机器集合的记号为 (J(i)=\{j:i\in M(j)\}) 与 (M(j)=\{i:p_{ij}<\infty\})。图宽只描述资格结构，不能把 (p_{ij}) 数值或资格集合当作免费 oracle；算法仍须读取实际输入。

# 基础参数关系和无结构基线

作者先给出两个简单树宽关系：

\[
\operatorname{tw}_{p}\ge \max_i|J(i)|,
\qquad
\operatorname{tw}_{d}\ge \max_j|M(j)|,
\]
因为每个 (J(i)) 在 primal 中是团、每个 (M(j)) 在 dual 中是团。若 incidence treewidth 为 (\operatorname{tw}_i)，则
\[
\operatorname{tw}_i\le \operatorname{tw}_p+1,\qquad
\operatorname{tw}_i\le \operatorname{tw}_d+1,
\]
以及
\[
\operatorname{tw}_p\le(\operatorname{tw}_i+1)\max_i|J(i)|-1,\qquad
\operatorname{tw}_d\le(\operatorname{tw}_i+1)\max_j|M(j)|-1.
\]
这些是约束满足文献中的结构关系在此模型上的应用，不是新的调度近似界。

无结构动态规划有两个作用。按机器逐台处理任务子集可在 (2^{O(n)}O(m)) 时间求精确最优；按任务逐个更新机器负载向量，若每台机器可能出现的不同负载值数至多 (L)，则在 (L^{O(m)}O(n)) 时间求精确最优。因此 (R||C_{\max}) 对参数 (n) FPT，对 ((m,k))（(k\in\{\mathrm{OPT},\max_i|J(i)|\})）FPT。固定机器数的 FPTAS 由 (B\le2\mathrm{OPT}) 的上界、把加工时间按 \(\delta B/n) 向上取整和上述负载向量 DP 获得；这只是无结构基线。

# Treewidth 动态规划

给三张图之一的宽度 (k) 树分解，作者把每个分解标准化为二叉树：叶袋为空，内部节点有左右孩子，另加 dummy 节点不增宽。对节点 (t)，任务和机器按“当前袋中活跃、曾在子树中活跃而现在离开、从 (t) 到父节点才离开（nearly inactive）”分组：

\[
(J_t,\check J_t,\widetilde J_t),\quad (M_t,\check M_t,\widetilde M_t).
\]
核心条件是：

\[
M(\check J_t\cup\widetilde J_t)\subseteq M_t\cup\check M_t,\qquad
J(\check M_t\cup\widetilde M_t)\subseteq J_t\cup\check J_t,
\]
且左右子树的 inactive/nearly-inactive 集合作不交并。节点 DP 做三步：合并孩子状态；枚举 nearly inactive 任务/机器在活跃或 inactive 侧的去向；合并负载/最大负载信息。三类图只是“哪一侧存任务子集、哪一侧存负载向量”的不同实现。

## Primal treewidth

Primal 袋中的任务就是 (J_t)。定义 \(\check M_t=M(\check J_t))，(M_t=M(J_t)\setminus\check M_t)，以及 \(\widetilde M_t=M(\widetilde J_t)\setminus\check M_t)。Lemma 9 证明上述分组条件，并特别得到
\[
J(\widetilde M_t)\subseteq J_t,
\qquad M(J_t\cup\widetilde J_t)=\widetilde M_t\cup\check M_t.
\]
对 (J\subseteq J_t) 记录 (S(t,J))：把 inactive 任务与 (J) 调度到 inactive 机器；对 (J'\subseteq J_t\setminus\widetilde J_t) 记录 \(\widetilde S(t,J')\)：把 nearly inactive 任务和 (J') 调度到 nearly/inactive 机器。节点合并的两个关键递推是：

\[
\operatorname{OPT}(S(t,J))
=\min_{(J_\ell,J_r)}\max_{s\in\{\ell,r\}}
  \operatorname{OPT}(\widetilde S(s(t),J_s)),
\]
其中 (J=J_\ell\dot\cup J_r)，以及
\[
\operatorname{OPT}(\widetilde S(t,J'))
=\min_{(A,X)}\max\{\operatorname{OPT}(S(t,X)),\operatorname{OPT}(I[A,\widetilde M_t])\}.
\]
第二个递推的 (A) 是送到 nearly inactive 机器的任务，(X) 送到 inactive 机器。子问题 (I[A,\widetilde M_t]) 用 Section 2 的按机器子集 DP 求值。状态数由袋大小 (k+1) 的任务子集控制，整体运行时间为 (2^{O(k)}O(nm))。

## Dual treewidth

Dual 袋中的机器就是 (M_t)。定义 \(\check J_t=J(\check M_t))，(J_t=J(M_t)\setminus\check J_t)，(\widetilde J_t=J(\widetilde M_t)\setminus\check J_t)。此时状态须保存活跃机器上的负载向量。对 (S(t)\) 与 \(\widetilde S(t)\) 按负载向量 \(\lambda\) 分类，孩子合并把两边向量通过投影映射 \(\tau_{M,M'}\) 相加；Lemma 13 给出
\[
\operatorname{OPT}(S(t,\lambda))
=\min_{(\lambda_\ell,\lambda_r)}\max_s
  \operatorname{OPT}(\widetilde S(s(t),\lambda_s)).
\]
nearly inactive 任务只能落在活跃机器（Lemma 12 的式(7)），因此 Lemma 14 把 \(\widetilde S(t,\lambda')\) 拆成 nearly 任务负载 \(\alpha\) 与 inactive 任务负载 \(\xi\)：
\[
\operatorname{OPT}(\widetilde S(t,\lambda'))
=\min_{\alpha+\xi=\lambda'}
\max\bigl(\operatorname{OPT}(S(t,\xi)),\max_{i\in M_t}\lambda'_i\bigr).
\]
若每台机器的可达负载值数至多 (L)，则状态数为 (L^{O(k)})，运行时间 (L^{O(k)}O(nm))。取 (L\le\mathrm{OPT}) 或 (L\le2\max_i|J(i)|) 得到 Theorem 2 的 FPT：参数为 dual treewidth 或 incidence treewidth，再加 OPT 或最大资格度。

## Incidence treewidth

Incidence 分解同时使用 primal 的任务分组和 dual 的机器分组。状态既记录送往 inactive 机器的任务子集，又记录活跃机器上的负载向量；Lemma 15、16 是前两类递推的联合形式。关键差别是 nearly inactive 任务既可能去 inactive 机器也可能去 nearly inactive 机器，活跃机器还可能同时收到两类负载，所以状态拆分为三个负载向量 \((\alpha,\beta,\xi)\)。若每机可达负载值数至多 (L)，整体同样为 (L^{O(k)}O(nm))。

由这些 DP，论文给出：

**Theorem 1.** (R||C_{\max}) 对 primal treewidth 参数 FPT。

**Theorem 2.** (R||C_{\max}) 对参数对 ((k_1,k_2)) FPT，其中 (k_1\in\{\operatorname{tw}_d,\operatorname{tw}_i\})，(k_2\in\{\mathrm{OPT},\max_i|J(i)|\})。

这里的 FPT 是输入中处理时间按通常二进制编码、目标值和资格结构均满足参数约束的精确算法；若只给出图宽而不限制第二个参数，负载向量可能有指数多种值，不能把 Theorem 2 写成仅由 dual/incidence treewidth 参数的 FPT。

**Theorem 3.** 当 dual 或 incidence treewidth 为常数时，(R||C_{\max}) 弱 NP-hard，但存在 FPTAS。弱 NP-hard 性来自两台相同机器的 (P2||C_{\max})；FPTAS 通过把加工时间按 (\delta B/n) 取整，压缩每机负载值数，再运行前述 DP。该结论仍是调度领域结果，不是一般输入的强多项式算法。

# Rankwidth 结果（仅 restricted assignment）

作者指出 primal/dual rankwidth 不能直接给出有意义的 PTAS：给任意 (P|M(j)|C_{\max}) 实例 (I) 添加一个大小为 \(\mathrm{OPT}(I)\) 且可在所有机器处理的任务，再添加一台只处理该新任务的机器，得到 (I')。最优值不变，而 primal 和 dual 图都变成完全图，rankwidth 为 1；因此这两个图的 rankwidth 可被人为压低，不能作为有效结构参数。

有意义的结果是 incidence rankwidth (k) 有界，并且先假定不同任务尺寸数 (d) 为常数。Lemma 17（Rounding Lemma）把常数尺寸假设去掉：给 (B\le2\mathrm{OPT})、\(\delta=\min\{1/3,\epsilon/7\})，把大任务 (p_j>\delta B) 向上取整到 (\delta^2B/n) 网格，把小任务复制为若干个大小 \(\delta B/n\) 的克隆。得到至多 (1/\delta+1) 种尺寸，且新实例最优值至多 \((1+3\delta)\mathrm{OPT})。在新实例上得到 \((1+\delta)\) 解后，将小任务的克隆分配看成分数 (x_{ij})，满足
\[
\sum_{i\in M(j)}x_{ij}=1,
\qquad
\sum_jp_jx_{ij}\le t_i.
\]
用 LST 有序槽舍入后，每台机器额外增加至多一个小任务，即至多 \(\delta B\)，总误差满足
\[
C_{\max}(\sigma)\le((1+\delta)(1+3\delta)+2\delta)\mathrm{OPT}\le(1+\epsilon)\mathrm{OPT}.
\]
该舍入依赖 restricted assignment 的同机任务尺寸 (p_j)；不能迁移到一般 (p_{ij}) 而保留同一证明。

## Rankwidth DP 的状态压缩

给 incidence 图的宽度 (k) branch decomposition。边 (e=\{a,b\}) 将任务、机器分成两侧 (J_{e,a},J_{e,b}) 与 (M_{e,a},M_{e,b})。跨切连接类型由邻居集合决定；GF(2) cut-rank ≤(k) 蕴含一侧任务相对另一侧机器的连接类型数至多 (2^k)（Remark 18）。

一份跨边的调度只需记录“从一侧送到另一侧”的任务多重集合。两个任务若有相同跨边连接类型且尺寸相同，则在 DP 中等价。设有 (d) 种尺寸、\(\kappa(e,b)\le2^k) 种连接类型；每类用计数向量 \(\iota\le\varphi_{e,b}\) 表示，状态数至多 (n^{\kappa(e,b)d}\le n^{2^kd})（Remark 20）。通过 translation function \(\tau_{f,g}\) 将同一批任务在分解树相邻边上的类型计数转换，内部节点按式(14)将上行/下行向量分拆并相加。Lemma 21 的递推为
\[
\operatorname{OPT}(e,\hat\iota,\check\iota)
=\min_{(\hat\lambda,\check\lambda,\hat\rho,\check\rho)}
\max\{\operatorname{OPT}(e_\ell,\hat\lambda,\check\lambda),
\operatorname{OPT}(e_r,\hat\rho,\check\rho)\},
\]
其中四个子向量满足翻译后的守恒关系。叶边直接检查单任务或单机器可行性。整个算法运行时间在论文中写为
\[
O\bigl(m\,2^k\,n^{O(d2^k)}\bigr)
\]
（文中公式排版为 (O(m2^k n^{O(d2^k)}))），对固定 (k,d) 为多项式；结合 Rounding Lemma 得到：

**Theorem 4.** restricted assignment 实例若 incidence graph rankwidth 有界常数，则存在 PTAS。

论文进一步说明 path-hierarchical、tree-hierarchical 和 nested restrictions 的 incidence 图都是 bi-cograph。bi-cograph 的 rankwidth 至多 4，且可在线性时间得到类似 cotree 的 branch decomposition；这些限制因此统一落在 Theorem 4 的 PTAS 类内。Lemma 23 的证明依次对树层级和嵌套资格做 bi-complement 操作，逐轮隔离机器或最大资格任务。

# 边界、可复用内容和非主张

1. treewidth/rankwidth 只约束资格图。处理时间的位长、零值/空任务和实际可用端仍属于输入；“宽度常数”不能抹掉二进制算术复杂度。作者在 treewidth 结论中保留弱 NP-hard 与 FPTAS 的区别。
2. Theorem 1 的 primal treewidth FPT 与 Theorem 2 的 dual/incidence FPT 有不同状态：前者用任务子集，后者还要枚举负载向量。不能删掉 (\mathrm{OPT}) 或最大资格度参数。
3. Theorem 3 的 FPTAS 只在 dual/incidence treewidth 常数下成立，通过整数化负载值；不是 general (R||C_{\max}) 的统一近二改善，也不是“固定机器/固定图”以外的强多项式算法。
4. Theorem 4 专门针对 (P|M(j)|C_{\max})。Rounding Lemma 用同机共同尺寸与克隆任务；换成一般 unrelated (p_{ij}) 时，rankwidth 状态和舍入都需要重做。
5. 文章没有讨论六提供者、有序完整历史、离轨策略、客户终局价值均分或 SPE；本对象不能作为 Q-CAG-HALF-6 的证明、反例或近似后端。它只提供“资格图有界结构 ⇒ 调度子问题可算法化”的独立资源。
6. PTAS/FPTAS 和 FPT 运行时间来自论文的 DP/舍入声明；本批没有把它们实现成仓库程序，也没有独立审查引用论文的复杂度优先权。后续 2019 版本 `jansen_rohwedder_2019_quasi_polynomial_v2.pdf` 是另一冻结源，应由其专门记录比较，不能把它的内容混入本对象。
