# 字母表只依实际任务数n

对n≥16，h=bitlength(n)=⌈log₂(n+1)⌉，b=1+1/h，R_n是最小非负整数r使b^r≥hn。定义

\[\mathcal A_n=\{\lceil b^r\rceil:0\le r\le R_n\}\cup\{n^2\}.\]

D_geo是显式m×n、m≥1、每项取A_n的全有限正整数矩阵。字母表不依原时间、分母、阈值、OPT或改善常数。b^h≥2给R≤h⌈log₂(hn)⌉，去重后|A_n|=O(log²n)。h≥5时n≥2^(h−1)>2(h+2)，最小R给b^R<(h+1)n，所有普通值<n²哨兵。幂用整数指数和确切有理乘法/ceil生成，位长O(log²n loglog n)，不用浮点或实指数优化。

# 条件backend如何回到全部原模型

先固定整数k≥2，假设D_geo上有α=2−1/k的确定性位多项式实际调度backend B。由此构造全模型2−1/(2k)算法：空任务直接返回；若每任务有零端给OPT0精确调度。其余令L=max_j min_i p_ij>0，U=Σ_j min_i p_ij≤nL，在合法每任务有有限端的域中L≤OPT≤U。保原m,n；零端任务仍可留在列表，取整误差按全部n收费。

若h<8k，直接枚举原合法分配；n<2^(8k)，次数m^(2^(8k))只依固定k，是理论固定次数多项式，不声称实用效率。它也处理n<16。

h≥8k时生成T=L b^t至首个≥U。对原p_ij≤T的端，令z=hn p_ij/T，取最小非负整数r使b^r≥max(1,z)，q_ij=ceil(b^r)；原∞或p>T端改n²。所有B调用都在同一A_n、保持m,n。z≤hn保证r≤R，所有z≥0满足

\[z\le q(z)\le bz+1.\]

z0、z1、p=T的边界都保留。验证B分配全部任务后，若用了按 **原p** 判断的哨兵/超T端则舍该候选，其余按原P精确回算并取最好。任何候选舍弃不是OPT>T证书。

# 对所有合格输出成立的解码

首个T≥O=OPT有T≤bO。原最优分配每机最多n个加一取整误差，给强式

\[OPT(Q)\le b(hn/T)O+n\le(h+2)n.\]

任一α合格实际输出峰值<2(h+2)n<n²，不可能使用哨兵，故至少这个候选必保留；并非只存在一份有利的YES调度。对保留端p≤Tq/(hn)，回译 **同一强式** 得

\[C_P(B(Q))\le\alpha[bO+T/h]\le\alpha b^2O.\]

h≥8k，于是

\[\alpha b^2\le(2-1/k)(1+1/(8k))^2
=2-1/(2k)-7/(32k^2)-1/(64k^3)<2-1/(2k).\]

若只用粗界(h+2)n回译，不能得到这一比率，故强式不可省。逆向限制原模型到D_geo直接成立。任何未知正实改善都支配某个固定1/k，不需要编码或比较实ε，因此得到统一改善存在性等价，而非交付未知B。
