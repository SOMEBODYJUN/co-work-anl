# 主地板的自足证明

变量集合Y，每变量在a=0,1两状态各有一个残余束R_x^a、原正需求K_x^a；同一状态内这些残余束两两不交。根需求q_root>0，变量需求1，标签需求K，资源需求0。给δ≥0，定义
\[
 G_a(\delta)=\{x\in Y:|R_x^a|/K_x^a\ge\delta\},\quad
 G=G_0\cup G_1.
\]
若G非空，至少一状态有≥|G|/2个好变量。选此状态的全部好变量，各取该真实标签及其残余束，资源无重复，得到真实树值
\[
 b(H)\ge\min\{|G|/(2q_{root}),\delta\}.
\]
G空时返回0；δ0与空束只产生零地板，不宣称正分树。根需求若为|Y|且每变量至少一状态好，则≥min(1/2,δ)。这种按状态多数构造允许删变量和删叶，但**需求K仍是原值**；删叶后好集合须重新算，不能把全束结果无条件移到所有残余。

`majority_floor`正按上述方式算好集合，tie取状态0，选中资源展开后assert不重复，返回根比例及所选标签比例的最小值与两个好集合。它不搜索混合状态标签、不裁剪束来优化，也不输入真实OPT；这是一个见证算法而非最优值求解器。

# 34389的真实枚举域

`families(q,r,K)`在有标号宇宙{0,…,r−1}上递归枚举q个**有序**、两两不交、大小均K的束。它可以为空（qK>r），空域不产生案例。若qK≤r，其族数
\[
 F(q,r,K)=\frac{r!}{(K!)^q(r-qK)!}.
\]
默认q=1..3、r=1..5、K=1..r，遍历每个完整状态对(A,B)，再遍历非空变量子集Y，故计数正是
\[
 \sum_{q=1}^3\sum_{r=1}^5\sum_{K=1}^r
 F(q,r,K)^2(2^q-1)=34389
\]
（不满足qK≤r的项取0）。各例两个状态都使用**完整束**，δ=1，所有需求都为同一个K，根需求重置为|Y|，断言所构造树值≥1/2。事实上这34389例的两个好集合都恰为Y，tie固定选择状态0，返回值恒为1；所以它们不测试非平局多数分支。它没有在这34389例中枚举任意删叶、异K、任意δ或固定较大根需求。一般这些情况由上面的证明覆盖，不由计数扩大。

# sharp_example的真实部分资源见证

默认s=4,d=s,K=8，q=2s=8。资源先有s²网格：状态0的前s变量各持一行，状态1的后s变量各持一列；再用互异私有资源补全各状态所有原束到K，并删除私有叶和坏状态全部叶。保留后前半只在状态0有s格、后半只在状态1有s格，状态内不交、跨侧可交。取δ=s/K=1/2，主函数给选4变量、每标签4/8，根4/8，见证值1/2及两个好集合。

源代码已明确：这是**一个多数状态见证**，不是求过所有混合部分束后的pool OPT。仅K≥2s时，单标签上界s/K与该见证共同证锐；默认K8恰在此域。`d`的注释提泛化，实际函数assert d==s，没有实现任意d；K的完整束补齐也只在所述K≥s的构造域解释，不当任意参数公共API。

允许跨两侧混取部分束时，同族精确值是
\[
 b^*=\max_{1\le k\le2s}\min\{k/(2s),\min(s,\lfloor s^2/k\rfloor)/K\}.
\]
s=K=4有5/8而非1/2；它只推翻旧“完整束相撞所以不能混侧”的附属锐性，不推翻多数地板。该公式与修复证明由[行列残余池资源](行列残余池的匹配与三路独立核验--资源.md)保存，本次不重新运行那两旧程序。默认sharp K8仍确为1/2；不能将其返回Fraction泛称所有K的最优性证书。
