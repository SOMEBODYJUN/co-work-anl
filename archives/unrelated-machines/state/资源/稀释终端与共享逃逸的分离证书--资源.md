# 一个安全过滤器为何仍会全通过

给T≥0，当前域D_j⊆{i:p_ij≤T}。测试边j→i，取其他在i可用且全部外部备选都严格大于T/2的任务F_i(j)。没有外部备选也按空真纳入。把F与外机连成二分图，每任务权为p_iℓ，令W_i(j)是最大权部分匹配，则真实T调度若把j给i，移出F的任务必须去互异外机。因此i的真实负载至少

\[B_i(j)=p_{ij}+\sum_{\ell\in F_i(j)}p_{i\ell}-W_i(j).\]

只有B_i(j)>T才安全删边；批量迭代仍保持所有真实T调度。严格p>T/2不能变成≥，有理最大权匹配/同步删域的总位复杂度对显式输入多项式。这个一般安全性不保证接受即可调度。

# 无global z的终端稀释族

k≥4，q=k/(k−1)，α_r=q^(r−1)/(k−1)，取最小h使α_h≥1/2，N=k(k−1)，T=1+1/k。两棵k叉树的边任务在父端1/k、子端1；两根由unit bridge连接。底层父有k个普通出边任务，各有自己的终端unit端，所在组共N个终端；另有N−1枚阻塞任务，每枚可去该组全部终端，时间1。

若真实峰值C<2−1/k，bridge使一根接unit。该活跃父若下传至多一件，留负载至少1+(k−1)/k，故须至少下传两件，沿树传到终端；每组N−1个阻塞占N−1个unit槽，只能允许至多一件普通任务外放，底层父又至少2−1/k，矛盾。单路径调度达到该值，所以真实OPT=2−1/k。

在T有配置证书：树上小端边际从底层1/(k−1)逐层递推，根bridge两端各1/2；终端普通任务总边际只占一个unit槽，其余N−1个槽供阻塞。每条有限边又各有一份普通剪枝LST点，令被探边质量1：先把普通任务放大端、扣实际占用、再按剩余总容量比例把每枚可交换阻塞任务分散填入。强制普通小端仅给父增1/k；强制阻塞终端时先把该处普通任务回父，再按残余填其余阻塞。每条查询使用不同点，不构成条件配置的共同分布。

重备选星也全通过：树任务有不同孩子/终端作备选，终端的阻塞可单射到其他终端。最大匹配收益恰全F权重，所以测试仅剩p_ij≤T，首轮无删，后续也无第一步。这说明独立配置、每边普通LST点与最大撤离匹配未共同保留整数终端槽；不是给一般算法的复杂度下界。h随k增长，展开树的规模不声称对log k多项式，所有证书复杂度按真实展开输入计算。

## 大任务基数探针确实修复这个底座

在每个候选目标C的同一条件LP里加入Σ_(j:p_ij>C/2)x_ij≤1，再对边强制x_ij=1迭代。其约束是任何真实C调度的必要条件，C是二进制有理输入。若1≤C<2−1/k，终端的单位任务都计为大任务，汇总N个槽扣N−1阻塞后普通总质量≤1。强制底层incoming unit便迫k−1件small在父，负载>C，逐层删除直到bridge两端无域。C<1先剪bridge；C≥OPT时真实调度的0/1点保其使用边不被删除。因此该加强 **恰判此底座阈值**，但它是多轮有理LP算法的证明，原有限代码没有实现通用LP求解器。

# 共享逃逸阶段：所有组共用唯一一台z

追加的是 **整个实例唯一一台global z**，所有组的每枚阻塞任务在z有时间1/2，其他任务无z端。它不是每组各一台z。k≥4时h≥3；若峰值B<2−1/k，每个活跃内部父至少产生两个活跃孩子，因此至少2^(h−1)≥4个不同活跃底组。每组至少两普通unit占终端，迫至少一枚阻塞去共同z；它们是不同任务，故z负载≥4/2=2>B。旧路径上界不使用z，OPT仍恰2−1/k。

新配置在z取空配置；旧逐边LST点的z质量0。强制新增阻塞边到z时，该处负载1/2，其组少一枚待填阻塞，其他组按原残余比例填。因此所有普通边/新边仍有独立条件点。

现行GHMR每次只强制一条大边，覆盖桥这个被迫大任务及当前机器的U_i，并取最大撤离收益；不是强制后嵌套完整过滤/条件LP。每个核心父的k个出边可匹配到不同孩子/终端；桥必要时放另一空根。终端U_i为空，z无大边查询；在z查询的可选阻塞也可全单射到各组不同终端。于是同一精确GHMR合同仍首轮零删。若改变为嵌套、条件配置、条件基数或其他共同预算，则是另一个尚待证明的系统，原第9节识别底座不自动迁到新族。
