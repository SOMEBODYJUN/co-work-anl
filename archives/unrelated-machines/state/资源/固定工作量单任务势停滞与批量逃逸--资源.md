# 精确构造及 OPT

取 m≥3 台相同机器，两枚 unit 任务，m²−1 枚大小1/m的 tiny。初态 σ 把两枚 unit 都放机器0，tiny 平均每台其他机器 m+1 枚，负载为

\[(2,d,\ldots,d),\qquad d=1+1/m.\]

总工作量恒定为 W=m+2−1/m，分配改变不了它。真实 OPT 恰为1+2/m：在 unit 所在的两台各配两枚 tiny，其他每台配 m+2 枚，tiny 总数4+(m−2)(m+2)=m²，需从一台减一件，得到所需 m²−1 枚且峰值1+2/m。下界若峰值严格更小，两 unit 不能同机；每个 unit 机最多1件 tiny，其他机最多m+1件，合计≤2+(m−2)(m+1)=m²−m<m²−1。故初态/OPT 比值2m/(m+2)趋2。

# 单任务严格势停滞

令 Φ=Σ_iL_i²。任务大小 p 从源负载 A 移到目的负载 B，势差为2p(B−A+p)。从初态移一枚 unit 到叶机，势差2/m；从叶机移一枚 tiny 到0，势差2/m；叶间移 tiny，势差2/m²。因此所有合法单任务改变都严格增加平方势。按负载递减排序的字典序也严格变坏：unit 移动后的新峰值 d+1>2；tiny 进0抬峰；叶间迁移在峰值2不动后抬高最大叶负载。这证明该初态是 **单任务** 局部极小。

若要求一次改成峰值≤2−ε（ε>0），两枚 unit 中必须有一枚离开0；其接收叶原有 d，加入 unit 后2+1/m，要降到2−ε至少移走1+⌈εm⌉枚原 tiny。因此相对初态一次输出的 Hamming 距离至少2+⌈εm⌉。这个计数只限制从原初态到一次大幅改进，不限制许多小改进的串联。

# 已撤回外推与真实逃逸

三件同步改变足以先启动严格下降：一枚 unit 从0去叶机，同时该叶两枚 tiny 回到0。两台新负载为1+2/m、2−1/m，平方势差

\[\Delta\Phi=-2(m-2)/m^2<0.\]

随后从刚接unit的叶机逐件送tiny给m−3台不同的其他叶机：该源原剩m−1枚tiny，最后剩2枚；每个接收叶从m+1枚升到m+2枚，尚留一台叶为m+1枚。源接收前与目的负载差至少2/m，故每次平方势严格下降，最终达到上述OPT。m=3时不需后续迁移。这保留了真实“单步小邻域可卡住”的反例，并明确否定“任何固定大小批次、任意多轮严格下降都卡住”的旧外推。README 的“批量支持下界”应读作一次支持下界，不应重新补回已撤回的多轮量词。

源中的 PARTITION 提醒也只约束免费 oracle：两机相同任务总量W时，分配载荷S,W−S的平方势为W²/2+2(S−W/2)²，能否达到W²/2等价于等分。不能在算法中不计成本地调用全局精确势最小化；这不是新的近二调度困难性。
