# 成束局部相容性：切掉旧证书仍可有 gap

经典两树实例中，每个末层父机 u 到终端 v 有 k≥4 枚束任务B（u端1/k、v端1），u另有incoming 1。配置中 N_i=|S∩B|。任何整数调度的两端任务身份给 N_v=k−N_u，因而可加二阶一致性

\[\mathbb E_{y_u}{k-N_u\choose2}=\mathbb E_{y_v}{N_v\choose2}.\]

当 T<θ_k=2−1/k，终端配置最多一枚，右侧0，父端每个正质量配置至少k−1枚small，不能与incoming共存。逐层向根推，最终根间任务两端都无覆盖，矛盾；T=θ_k的真实路径调度则给Dirac配置。因此该强化在 **这个族** 阈值恰θ_k。旧证书父端“同时遗漏两枚small”的正概率、终端0概率不一致，二阶约束确实切掉它。没有给一般配置列 LP 的多项式 oracle。

计数闭包是另一个、可直接计算的安全过滤器。初始化 D(j)={i:p_ij≤T}，空域拒绝；检测 j→i 时，扣除其他单域任务的强制负载，并对每个剩余机器v及二域束{h≠j:D(h)={i,v}}算保守i端必留负载：若某子束的每个v端时间严格大于R_v/(q+1)，则v至多收q枚；从该子束i端总时间减去最多q个最大i端时间得到下界，取各q最大值 r_iv。若

\[p_{ij}+F_i^{\neg j}+\sum_{v\ne i}r_{iv}^{\neg j}>T,\]

同步删边安全，因为各v子束互不相交。等号边不能进入“严格大于”的子束。有限域收缩、精确有理比较和排序给总位多项式；源保守计数 O(m³n⁴log(n+1))。在两树上它恰拒绝T<θ_k，但接受不输出可行调度。初始无单域、每个机器对最多一枚二域任务时 r_iv=0，没有首次删除，因此并不完备。

这里的 pair 合同对全部资格端恰为{u,v}的二域任务要求两配置中恰出现一次，本细分族全部任务都是二域。完整 pair coupling 要每个机器对的联合配置分布 z_uv 边际为 y_u,y_v。若机器对仅共享该二域任务j，a=x_uj，则兼容块可取 y_u(S)y_v(R)/a（j在S不在R）和除以1−a（反向）；a=0,1只保非零块。因此简单机器图上 pair coupling 与配置边际等强，多个对的分布未必共同胶合。

用新机w_e和两子任务细分旧任务e=(u,v)，旧端时间保留，新机端均为H>0。真实值满足

\[\min\{OPT(P),2H\}\le OPT(P')\le\max\{OPT(P),H\}.\]

上界由原调度把另一子任务放w_e；若新峰值<2H，每个w_e至多收一个，可恢复一个旧外端。只有OPT(P)∈[H,2H]才保证恒等；OPT(P)<H时不能冒等号。原显式配置证书阈值T≥H可提升到新机（每次只接一子任务），细分后机器图简单二部，故亦有pair证书。两树取H=1、证书T_k=1+1/k、OPT=2−1/k，得到

\[OPT(P'_k)/T_{PAIR}(P'_k)\ge2-3/(k+1)\to2.\]

这里 **T_PAIR≤T_k**；没有证明等号。普通配置/ST上界给上确界2。无平行二域细分族也卡住计数闭包首步。这是松弛接口 gap，不是一般 near-two hardness，也不是对统一近似算法的否定。

# 极小超载星：已成立的精确单任务压缩

在阈值T剪枝后的实例，机器v的 **全部** 可用任务F非空，S=Σ_(a∈F)p_va>T且S−p_va≤T对每个a成立。删v及F，加一枚普通任务e，在每个外机i设p'_ie=min_(a∈F)p_ia，空min为∞并保存argmin。

原T可行⇒至少一枚a∈F在外机i，把该a改成e只减外机负载，其他F删除。反向任意约化实际分配把e在i展开为argmin任务a，其余F放回v；v负载S−p_va≤T，外机负载不变。故T可行性双向保持，任意约化峰值B恢复≤max(B,T)。连续收缩逆序展开仍为一次max，须保存原任务身份和argmin，不能累计T或复制任务。全集邻域/每个删除条件都不可省略。

但配置点正向转换另需外部配置含F的总质量 Q_F(y)≥1（每个外机配置至多含一枚F是充分条件）。抽取质量1替成e可转；逆向按argmin无条件。若还要强制指定外机/边，必须优先抽其质量。整数可行性保持本身不推出配置点双向保持。

同时外放q≥2枚不能各机独立取q个min：原任务可能重复或不匹配。既有q+1任务/q+1外机的两类余量profile反例说明，若q个普通替代任务保持所有profile，其可用集合须两两不交且各至少两外机，需2q>q+1；带身份的matching或更强接口不在反例范围内。

容量一星族进一步表明，即使有完整配置点和所有两机器联合配置证书，极小星/域闭包也可全部无第一步，整数OPT≥2−1/k趋2。它更新了旧“检验预处理”的状态，但不排一般全局结构选择。现有极小星对象还含静态拟阵外包计数下界，其假设是保全部原重量可行集、逐原任务拟阵交及所有共同独立集安全；原README的q-profile义务不能借这一更受限接口扩大为全部匹配或拟阵算法的否定。辅助容量、选择性profile和非局部投影另有量词。
