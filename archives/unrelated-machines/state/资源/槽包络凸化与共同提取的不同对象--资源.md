# 单行定义及可提取性

给d个非负有限时间p₁≥…≥p_d≥0，p_(d+1)=0，x∈[0,1]^d，前缀X_t=Σ_(j≤t)x_j。标准有序单位槽按x区间的正交长连任务，其单行槽包络E_p(x)是各非空槽最大相邻p之和，准确为

\[E_p(x)=\sum_{t=1}^d(p_t-p_{t+1})\lceil X_t\rceil.\]

处理p平局只影响无权差的前缀，零x不接边，整数前缀的端点零交长不造新槽。逐层layer-cake计数每个前缀触及的槽数ceil X_t得公式，并有

\[E_p(x)-p\cdot x=\sum_t(p_t-p_{t+1})(\lceil X_t\rceil-X_t)\ge0.\]

对完整矩阵的分数assignment X(P)（任务列和1、不可用端0），全局ST覆盖匹配的每行实际负载至多E_(p_i)(x_i)，不是只逐行各选一个彼此冲突的配置。反向任意整数assignment的指示x有E_i=L_i，故

\[\min_{x\in X(P)}\max_iE_{p_i}(x_i)=OPT(P).\]

这是精确非凸重参数化，未给如何求全局最小值的多项式程序；称“包络值精确”不能把原优化问题藏进免费oracle。

# 固定阈值子水平凸化为何恰为CONFIG

固定B≥0，S_p(B)={x∈[0,1]^d:E_p(x)≤B}。对u∈[0,1)，设

\[y_t(u)=\lfloor X_t+u\rfloor-\lfloor X_{t-1}+u\rfloor.\]

因x_t≤1，每个y_t为0/1；均匀u使E_u y_t=x_t。任一u的前缀Σ_(j≤t)y_j=floor(X_t+u)≤ceil X_t，从而p·y(u)≤E_p(x)≤B。只在有限前缀分数断点改变，至多d+1个原子，权重可精确有理表示。因此每个x∈S是容量B的真实0/1配置凸组合；另一方面容量B整数配置本身属于S，得

\[\operatorname{conv}S_p(B)=\operatorname{conv}\{1_C:p(C)\le B\}.\]

每行做这个固定B凸化、再拼全局列和1，正好是等式覆盖CONFIG(B)的边际投影。补空配置、利用向下闭合可与至少覆盖1形式互换，但未使各行配置共同耦合为全任务assignment。既有CONFIG趋二gap仍适用。

# 先凸化整个上图又是另一个合同

E_p(x)≥p·x，故线性p·x是其凸下界；所有0/1顶点v满足E_p(v)=p·v，每个x可写顶点凸组合，于是完整上图凸化的下包络恰p·x。跨阈值先混合会忘掉固定容量B的信息，拼全局守恒只剩普通LST负载LP。它不能被称为固定阈值CONFIG，更不能反过来把CONFIG说成只含一阶线性负载。

区别可直接用于算法接口检查：保持非凸包络并求最优等价求原OPT；在同一B内逐行凸化保完整knapsack配置但失全局相关性；在B也可混合的上图凸化只剩平均工作量。任何pricing、容差和联合提取算法必须说明究竟选择哪一个域。原README的“共同信息可计算表示/实际提取仍缺”恰是这个未闭处，不是三种形式已有一般改善。

# 复杂度和证据边界

给定x的排序、前缀、ceil、断点和d+1原子可按输入有理位长多项式实现；给定非凸最优点后的ST匹配也可。它不计算未知最优点、不是指数CONFIG列pricing的通用免费oracle。空行/零p/零任务按公式给0，∞端先去掉，不能把∞放入差分求和。旧精确有限审计支持列明小例，普遍身份由上述两方向证明承担；本批0新run、无新颖性或外审认证，也没有一般UM正反面结论。
