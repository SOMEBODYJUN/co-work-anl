# 一般CONFIG转移合同与证明

在当前T剪枝实例中，v的**全部**邻任务F满足S=Σ_F p_vj>T，且每删一个j均有S−p_vj≤T。删v/F并加e，外机i的p'_ie=min_(j∈F) p_ij，记录argmin。整数T可行双向、逆恢复峰≤max(B,T)由一个外放任务替回和把其余F留v给出；这不无条件保持任意超T调度的OPT。

对显式配置点y，定义外部**碰到F的列质量**
\[
 Q_F(y)=\sum_{i\ne v}\sum_{C:C\cap F\ne\varnothing}y_{iC}.
\]
v配置都为F真子集，所以外任务质量q=|F|−E|C_v|≥1，但Q≤q；同一外列含多项F时不能拿q充Q。充分证书是Q≥1。实例级充分条件`p_ia+p_ib>T`使外列至多一F，故Q=q；源码固定稀疏族更强地要求每外机只邻一项F，条件更强但非一般必要。

从碰F列中按确定次序取总mass1，选中部分改(C\F)∪{e}，其他部分删F；新时间≤该列任一F任务时间，负载不增。非F覆盖、行归一保持，e覆盖1，删v。只有越过mass1的最后一列可拆，所以每步全局最多一次split，支持≤S_old−S_v+1。列相同必须**累加权重**，不能dict覆盖。原程序真正执行的路径使用defaultdict合并；一个未调用的`normalized`辅助函数不因此被称为经过所有API测试。

新e→i若须质量1，沿argmin选原F任务a→i的强制证书，该机全部mass1碰F。必须优先从i取这1份质量；普通外机顺序可先分给另一机。它只保留存活机器上的普通边/替代边查询，不承诺被删v上的旧query仍有同一含义。整链先反向沿argmin追到原source edge，再正向逐步跟踪。

逆向对每含e外列，把e换成该机argmin a，并给恢复v放F\{a}、相同权重。e总覆盖1使v归一；每a的外质量与v补集质量合1，v负载≤T。这个方向不需Q≥1，却不保原每条边的强制质量。链上每步只加减/min，权留在初始分母乘积格；支持不每步翻倍。复杂度相对于显式矩阵及给定配置点总编码长度，不存在免费一般CONFIG oracle。

# 共享稀疏输入及M的计数单位

生成器是两棵完整k叉树、根桥、底簇k终端、相邻终端block任务及共享z。树/星父端时间1/k、子端1，block两个终端时间1、z时间γ，每任务至多三端。令r=(k−1)/k，s0最小使k r^s0≤1，M=(k−1)k^(s0−2)，取H≥s0且2^(H−2)≥M、γ=2^(2−H)。本次固定k3，生成器parameters取s0=3、M=6、H5、γ1/8、T4/3。

给一个有限边单独强制质量1，生成器选择另一树承根桥，并沿查询后代传播大端边际α→rα；不换成所有query共同点。底簇terminal的星大端边际β≤1/k时，终端用真实路径singleton配置；若β>1/k，把该簇k−1个block同送z配置。

**M界的是外送block任务数，不是按M个簇再各乘k−1。** 距强制单位入口s条传播边的terminal若坏，1≤s<s0；对应底簇数至多k^(s−1)，外送任务至多(k−1)k^(s−1)≤M。强制某star大端只有一个坏簇、某block去z只有指定单件，亦受此界。故同z配置负载≤γM≤1。两现审查有“受影响簇最多M个”后的预算省略，新精确澄清proposal只把该句单位改成外送任务总数≤M（簇≤k^(s0−2)），不改原源、一般定理或程序。

整数下界则是另一计数：若峰B<2−1/k，每活跃核心必须下传至少两条小边，底层至少2^(H−1)个活跃簇，各至少一block去z，z负载≥γ2^(H−1)=2矛盾。沿一条路径给峰2−1/k上界，故原族OPT=2−1/k；不是由有限调度枚举求最优。

# 三个模型内反例的原数值

1. **Q不足。** 两根u1,u2、叶v1,v2，桥c在两根1；a_l,b_l在根1/2、对应叶1。各根以半概率选桥/两小，叶各半选a/b，是完整CONFIG1。收v1时外任务期望数量1但Q=1/2；e只在u1耗1/2，迫桥全去u2、a2,b2全去v2，超容量。独立代码核旧点/计数，新的不可行性由此forcing链证明，不是调用一般LP。
2. **逆不保probe。** T1，v接a,b各1；u上a1、b2/5、c3/5，c仅u。外行a+b>1确有配置互斥，但原a→u因c必u而不可能；约化e2/5与c3/5同u，全部约化边可强制。这里“互斥”指容量pair条件，**不是**每外机只邻一F的更强结构条件，不能把输出`structural_mutual_exclusion`误读为后者。
3. **优先控制。** F两任务完全外放u1/u2，Q2；普通顺序把e全给u1，目标u2 mass0；优先u2后mass1。两点都容量合法，失败只在指定probe。
