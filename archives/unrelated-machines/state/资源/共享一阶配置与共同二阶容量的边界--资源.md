# 先写清弱合同

有限端e=(i,j)有Boolean变量x_e，相同任务异端乘积0。次数≤4共同泛函L要求L1=1、到次数3的任务one-hot守恒；M₂[S,U]=L(x_Sx_U)（|S|,|U|≤2）PSD；各机器的(T−Σp_ex_e)次数1负载localizer PSD。再要求同一个一阶点x_e=L(x_e)有完整CONFIG(T)行分布，覆盖任务恰1。配置行 **不与L共享同机二阶**。p_e>T端先剪去。

不能把这个条件读成行CONFIG的完整矩也进入全局泛函，更不是一个真实全任务分布。弱H2投影到剪枝LST，标准槽舍入给OPT≤2T；下述显式族使比值趋2，给该精确弱合同的gap上确界2，没有一般UM困难性。

# 稀释星族及真实整数值

k≥3，b=k²，r=b+1，N=b+k，T=t=N/r=1+(k−1)/(k²+1)。机器有k个中心V_a、k−1全局G_g、每块r个R_(a,ℓ)。X_a在自己中心/全部G均unit；每块b件Y仅在该块全部R均unit；每块k件Z在中心1/k、该块全部R为unit。机器k³+3k−1，任务k³+k²+k，有限端O(k⁵)。

若C<2，k枚X在k−1台G放不下，至少一X去中心；该块b枚Y占b台R，剩余唯一R最多接一Z，所以中心至少X+(k−1)Z，负载2−1/k。相同分配可以达到，因此真实OPT=2−1/k。所给弱证书阈值T仅为显式可行值，不声称它是弱H2最小可行阈值；但OPT/T→2已经够给上确界。

# 全局PSD与同一一阶CONFIG为何能同时成立

通用fractional multislice取整数m≥3,N≥m+1、t=N/m，N任务各m端；相容单项式S含q≤4个不同任务，各机器计数c_a(S)，定义

\[\mu_S=\prod_a(t)_{c_a(S)}/(N)_q.\]

下降阶乘递推给任务one-hot，并给μ((Q_a−t)x_S)=0（degree S≤3）。因此(Q_a−t)乘一次函数是二次双线性型的radical，先证明守恒不预设PSD。

二次空间模这些radical拆成常数、零行列和一次函数、对称task-harmonic×对称零行和机器核、反对称对应块，彼此正交。一次块Gram为t/(N−1)的Frobenius内积。对称机器核B的平方Gram正倍于

\[\|B\|_F^2-\frac{m\|\operatorname{diag}B\|^2}{N-2}
+\frac{(\operatorname{tr}B)^2}{(N-1)(N-2)}.\]

零行和逐行Cauchy给m||diagB||²≤(m−1)||B||²，N−2≥m−1故非负；反对称块是t²/((N−1)(N−2))倍Frobenius内积。张成、正交和各块非负给完整M₂ PSD，允许负三阶矩。

全局证书先均匀选唯一激活块A。该块X去中心、其他X真实双射G；非激活块Y真实注入R、Z全home；激活块N枚Y/Z在r台R上用上述伪矩。各组件独立张量再平均：M₂为PSD张量积主子矩；one-hot由组件守恒；激活R的负载localizer由Q=t恒等为0，其他机器的非负slack加权真实Gram再与别的组件PSD张量给localizer PSD。

同一一阶边际是X→各资格端1/k，Z→中心(k−1)/k、每R为1/(kr)，Y→每R为1/r。另给每行合法CONFIG(1)：中心{X}权1/k、全k枚Z权(k−1)/k；G对各X单任务权1/k；R各Y singleton权1/r、各Z singleton权1/(kr)，总权(b+1)/r=1。所有正配置负载1，当然也T可行。这不是另外一份一阶点，却故意留下 **同机二阶不相容**。

# 强合同：把零同机pair传到真实条件容量

R上任意两不同Y的L同机pair=(1/k)t(t−1)/(N)₂>0，而singleton配置的pair0；三个Y的同机矩因1<t<2为负。故共享同机二阶或另加三阶单项式非负都切掉这份弱证书。

若要求每行同一配置分布的二阶与L相等，对全部unit的R/G行（T<2），不同端e,h有L(x_ex_h)=0。M₂ PSD使二次向量x_ex_h零范数，因而与每个二次向量正交，特别L(x_fx_ex_h)=0。于是

\[0\le L([x_f(1-Q_i)]^2)=L(x_f)-\sum_{e\in E_i}L(x_fx_e),\]

给任意全局原端f的条件容量 **1**，不能放松成T。中心含tiny，不用singleton行论证；其共享二阶只给另一计数界。

对1≤T<θ_k=2−1/k，q=⌊k(T−1)⌋≤k−2。固定中心X端f、α=L(x_f)≥0。含X的中心配置最多q枚home Z，所以Σ_jL(x_fx_(V,Zj))≤qα。Y/Z one-hot迫本块R的条件总量至少(b+k−q)α；r台R的上述条件容量最多(b+1)α。因此(k−q−1)α≤0，迫α0。所有X中心边际0后，全局G只能装k−1枚X，却要覆盖k，矛盾。T<1先剪X全部端；T=θ_k真实最优调度的Dirac矩/配置达到。故 **此同族强H2阈值恰OPT**，不是只排某个弱点。
