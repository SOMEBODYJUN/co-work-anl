# 完整局部优化器为何确实可计算

显式菜单的线图以项为点，e→f iff v_e=u_f且c_e≤r_f−λ。λ>0的闭走步每个转向严格；λ=0还须有至少一个严格转向。SCC里含严格转向且有回程即存在改善闭走步，普通“有环”不足。

重复源机器时不能执行同一任务两次。设两次入出配对α→a、β→b，若r_a>r_b则c_β≤r_b−λ<r_a−λ，可剪出较短闭段；反向取另一段；相等时两段都可，λ=0保含原严格转向段。接缝严格性在对应大小情况下保留，反复剪接得不同源机器的可执行循环。搜索、比较、剪接对显式菜单多项式。

不能免费列全部子集。取h=ηT/(2n)，整数收益z_j=⌊p_uj/h⌋，总收益≤Q=⌊4n/η⌋。每有向机器对用0/1背包在每个 **精确收益** q保最小实际到达成本代表；零收益非负成本任务可不选，两层更新/backpointer不重复物品。任意真实S的q>0代表满足

\[c(S_q)\le c(S),\qquad r(S_q)\ge r(S)-\eta T/2.\]

若真实循环每点余量ηT，其每弧r≥ηT保证q>0；替换后仍有ηT/2余量。因此菜单没有λ=ηT/2循环，便可靠地证明当前没有真实ηT循环。它不是全局OPT>T证书。

执行找到的循环后每台负载不增，至少一台净降λ，总工作量初值≤2mT，所以成功轮数≤⌊4m/η⌋，再一次失败查询停止。负载始终是原数的有限和，位长不随轮数指数增长；背包O(m²n²/η)算术、线图和恢复均按输入位长及1/η多项式。空任务/T0/m1直接分支，不能把T0返回误作“没有零余量循环”。终态只无此鲁棒循环，没有统一makespan改善保证。

# 批量预算与目的地是独立限制

三机A,B,E，A两unit分别可去B/E；B/E各2k枚tiny，本机1/k、A端1/(4k)。初态负载(2,2,2)，把两unit分走、全部tiny回A得OPT1。若unit离A到B，B必须至少撤k件tiny以守峰值2；若两unit都不离开，任何tiny回A都会超载。因此任意严格lex改善至少k+1件变化且某机撤k件，取一unit+k件反迁达到。k增长排固定任务预算/固定单机撤离预算，不是复杂度hardness，也不证明该坏态来自LP舍入。

另一个三机六任务fork核取θ∈(0,1)、a=1−θ/2、C=2−θ。A上X,Y时间a，第二端分别B上θ/4、E上θ/2；B上b时间a可回A时间1；E上c时间a可去B时间θ/4；B/E各一私有a。坏态各机C，唯一非平凡且Cmax≤C的改配是b→A、X/c→B、Y→E，达到1。若b不走则B满阻挡X/c，进而E挡Y；b走后A需同时撤X/Y，强迫多目的地。这个裸核的T1 LP唯一是最优整数点，不能冒坏态支撑反例。

补N=8k台H、各一私有a，四可移任务均有H端1，取θ=1/k。H私有使任何任务进H后负载1+a>C，故坏态后的C不增修复仍需上述分流。显式正支撑点：X/Y在A质量t=(a+1)/(4a)，b在B、c在E各β=θ/(4a)，余量均分H，私有质量1。A/B/E分数负载1−θ/4；令余量总和F=4−2t−2β<4，则每台H负载a+F/N≤a+4/(8k)=1。因此是合法LST点。标准槽正交长有覆盖匹配诱导坏态；每个可移任务在当前端a是正支撑内唯一最便宜机器，任意最小成本槽匹配都诱导同一坏的机器分配（槽匹配本身无需唯一）。

这准确排除“任意可行LST点+最小成本槽初始化+每机单目的地Cmax不增修复”合同。给定x未称basic，且A上两big质量2t>1违反CONFIG(1)基数，故不排配置投影初始化、别的x、槽外分流或非单调算法。

# 接续状态
