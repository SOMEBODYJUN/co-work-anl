# 商代数、通用矩与精确 PSD

一个有限端写为 `(job,machine)`。`canonical` 合并同任务同端的重复因子（Boolean），若同任务出现不同机器端则返回零单项式。`monomials(domains,d)` 枚举常数及最多 d 个不同任务、每任务一个端的全部相容坐标。它保留 one-hot 商代数身份，而非把所有端当独立 Boolean。

对 N 个任务、m 台单位机，令 t=N/m。`multislice` 定义相容矩
\[
 \mu(S)=\frac{\prod_{a=1}^m(t)_{c_a(S)}}{(N)_{|S|}},
 \qquad (t)_q=\prod_{j=0}^{q-1}(t-j).
\]
不同任务可同机；同机三阶可为负，因此它不是一般概率分布。`generic_check` 以次数至多二的全部相容单项式索引完整 M2，条目为 `mu(s+u)`；再对次数至多三的测试单项式逐任务查 one-hot、逐机器查行计数 `Σ_j μ(s x_ja)=t μ(s)`。它不是只看若干主子式。

`psd_rank` 先取所有有理分母的 lcm，以正整数放大矩阵。每轮在剩余对角选正 pivot 并同步换行换列；对 Schur 余块作精确 Bareiss 更新 `(pivot*a_ij−a_ik*a_kj)/previous`，逐项 `divmod` 断言整除。负对角直接拒绝；若无正对角，要求整个余块为零，以避免“零对角即跳过非零交叉项”的错误。正 pivot 的合同是精确合同变换，故保惯性；最终正 pivot 数即秩。运行中未用浮点容差，未关闭 Python `assert`。这解释有限矩 PSD 如何被检查，不代替任意 N,m 的 harmonic 分解证明。

默认通用输出为：

| N,m | M2 维数 | 秩 | degree≤3 one-hot 测试 | degree≤3 行恒等测试 |
|---|---:|---:|---:|---:|
| 4,3 | 67 | 16 | 700 | 525 |
| 5,3 | 106 | 30 | 1880 | 1128 |

维数为 `1+Nm+binom(N,2)m²`；测试数分别为 `N Σ_(q=0)^3 binom(N,q)m^q` 与 `m Σ_(q=0)^3 binom(N,q)m^q`。次数四矩来自二次坐标乘积，不是额外的全局 M4 检验。

# 小稀释星：同一 L 的哪些部分实际检查了

`mixed_fixture(2,2)` 取 r=b+1=3、N=b+k=4、T=N/r=4/3；共 10 任务、9 机器、32 有限端。每块有 X（中心 V 或全局 G，时间 1）、b 个 Y（本块 R 上时间 1）、k 个 Z（中心时间 1/k、本块 R 时间 1）。它先均匀选一个激活块：激活 X 留中心、其他 X 双射到 G；非激活 Y 真注入 R、Z 留中心；激活 Y/Z 用上述多切片伪矩。给定激活块时独立组件相乘，再对块平均。`conditional` 精确检查禁端、注入重复、X 双射资格；`lru_cache` 只记忆已查询矩，不改变分布合同。

实际形成的全局 M1 用常数及全部 32 个端索引，秩 18。程序对次数≤2的全部相容测试逐任务检查 one-hot，共 4910 次。每台机负载 localizer 的坐标也是相同 33 个常数/端，条目为
\[
 T L(su)-\sum_{e\text{ 在该机}}p_e L(su x_e).
\]
九个 localizer 均精确 PSD：两个 V 与一个 G 的秩各 18，六个 R 的秩各 11。这里是真实含权时间的完整行 localizer，并非只检查期望负载。

同一个一阶端边际由配置行实现：V 以 `1/k` 选 `{X}`、以 `(k−1)/k` 选全部 Z；G 对每 X 以 `1/k` 选 singleton；R 对每 Y 以 `1/r`、每 Z 以 `1/(kr)` 选 singleton。逐行权和 1、权非负、配置负载≤1≤T，全 32 个有限端都与同一个 `moment` 一阶相等。程序还查同 R 的两个 Y 与 Y,Y,Z：
\[
 L(Y_1Y_2)=1/54>0,\qquad L(Y_1Y_2Z)=-1/162<0.
\]
因此弱合同中 CONFIG 只共享一阶；同 R singleton 配置的二阶为零，与共同 L 正 pair 不同。负 triple 也阻止把该点升级为全部三阶单项式非负。脚本不会把正 pair 当失败，它正是强合同反对意见的见证。

**未数值检查混合全局 M2。** 输出明确 `mixed_global_M2_numerically_checked=false`。一般全局 M2 的 PSD 依靠通用分解、组件张量的主子矩、确定变量线性拉回和非负混合；默认小 fixture 没有穷举全局 degree≤3 one-hot。不得将通用两个小 M2 的精确通过与混合 M1 的通过拼成“一般全局 M2 已数值核过”。

# 一般结果与本程序的适用边界

原 canonical 的参数族 k≥3、b=k²、r=b+1 有 `OPT=2−1/k` 和弱 H2 可行目标 `T=(b+k)/(b+1)`，比值趋二。整数下界来自 k 件 X 仅有 k−1 台 G，某中心接 X 后，本块 b 件 Y 占 b 台 R，剩一 R 最多外送一 Z。PSD、配置一阶及整个族的证明属于既有正文；本次固定 k=2,b=2 的有限运行没有重新证明任意 k、没有证明给定 T 是弱 H2 最小阈值，也不是 near-two hardness。

同机二阶共享后的校准必须保留**单位行**条件：在 R/G 行、`1≤T<2` 时配置至多 singleton，因此不同端 pair 为零；M2 的零范数正交性给对任意全局端 f 的条件容量 `Σ_(e∈E_i)L(x_f x_e)≤L(x_f)`。中心有时间 1/k 的 Z，不能把全部中心 pair 也设零；中心应逐配置计数 `Σ_j L(x_VX x_VZ_j)≤floor(k(T−1))L(x_VX)`。与本块 R 条件容量合并才推出低于 `2−1/k` 不可行。k=3 在 T=5/3 的真实最优 Dirac 调度可在一中心同时放 X、Z1、Z2，所以该中心 pair=1 是合法的。相邻旧审查的“每行单位”一句需限定到 R/G，最小建议另包，原源不动。
