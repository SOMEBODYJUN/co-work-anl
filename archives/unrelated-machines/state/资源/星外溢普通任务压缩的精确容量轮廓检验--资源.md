# 原星与容量 profile

对 q=2..8，原星有 q+1 个任务。中心容量1、每项时间1；外机i执行自身任务i时间1/q，其他任务时间2。这里“时间2”是显式有限边，在下述容量≤1的profile上会被单端剪枝，不把它混写成一般不可用。

A-profile：任意 q 台外机各容量1/q，其余0；q项各去其本机、剩一项去中心，故可行。B-profile：任意 h≤q−1 台外机各容量1，其余0；外机仍只能做自身一项，中心至多一项，合计不足 q+1，故不可行。

| q | A 可行 profile | B 不可行 profile | 全部逐端剪枝分配 |

|2|3|4|19|
|3|4|11|65|
|4|5|26|211|
|5|6|57|665|
|6|7|120|2059|
|7|8|247|6305|
|8|9|502|19171|

A数为q+1，B数为 `Σ_(h=0)^(q−1) binom(q+1,h)=2^(q+1)−q−2`。A每个有2^q个剪枝选择，B活跃h时2^h个，所以最后一列为 `(q+1)2^q+Σ_(h<q)binom(q+1,h)2^h`，与新输出逐项一致。它只枚举原星的这些指定容量profile，不枚举替代处理矩阵。

# 任意替代矩阵的普遍障碍

与[极小星容量审查](../审查/极小星收缩与配置耦合有限审查--审查.md)及原主稿§5比较后，承重命题须独立保存：对**每个**整数 q≥2，不存在仅使用上述 q+1 台外机的 q 个普通替代任务（任意非负有理/∞时间，无额外身份/匹配约束），同时保持全部 A/B 残余容量profile的可行性。原中心已消去，替代任务不再使用它；外部容量可用各机私有预载任务实现。

设有替代矩阵。对任务r令 `A_r={i:p'_ir≤1/q}`。任一A-profile中的可行替代分配必须在 q 台不同机器各放一个正时间任务：若只用了≤q−1台正负载机，把这些机容量升为1、其余降为0，所有零时间任务仍可留在原机，就会使某B可行，矛盾。因而去掉任一外机后的A-profile都有覆盖所有q任务的小边匹配，特别每个 |A_r|≥2（空集不可能，singleton可删除其唯一机）。

若两个 A_r,A_s 交于i，把这两个任务都给i，其余各任务任选自己的小边机。共用机数≤q−1，每机至多q项、各时间≤1/q，总负载≤1；可能的零处理时间同样合法。于是在某B-profile可行，矛盾。故 q 个 A_r 两两不交，至少需2q台外机，却只有q+1<2q。此证明处理零和∞，且不要求枚举替代矩阵。程序只查不等式 q+1<2q及原星profile；一般不可能性来自这个论证。

该障碍只针对固定 q 普通任务、相同外机、精确保全部残余容量的局部表示。允许保原任务身份的 matching/matroid 接口、增加机器/任务、非局部选择或近似消元时，前提改变；它不排除这些路线，也不否定一般 UM 次二算法。

# 两个具体 envelope 反例的原数值

第一例原矩阵为中心 `[1,1,1]`、一外机 `[0,2,2]`、容量 `[1,1]`。后两项只能去中心，总负载2，故不可行。把它换成两项都取逐行最小值0的矩阵 `[[0,0]]`、容量1则可行。这显示反复取 minima 会把同一便宜原任务身份重复使用，**不保从约化可行向原可行的 lift**。

第二例原矩阵为中心 `[1,1,1]`、外机 `[0,2,2]`、另一外机 `[2,0,2]`，各容量1；前两项各去对应零边外机、第三项去中心，可行。某个 rank-envelope替代为两外机都 `[0,2]`、各容量1时第二替代项无合法端，不可行。这一**具体**包络丢失正向可行性；脚本未据此穷尽所有 rank/matroid 接口。

两例与上面的A/B普遍构造不是同一矩阵或参数族。`specific_envelope_counterexamples=2` 不能误称 q2..8 的每项额外两个独立全矩阵反例，也不能从这两例单独推出任意替代矩阵不可能。

# 接续用途与限制

原最小超载星“至少外放一项”能用argmin压成一任务，并逆序恢复峰值≤max(B,T)；多项外溢需保任务身份，不能把单项argmin规则机械重复。共享单位资源的匹配可保身份，但一般多尺寸容量怎样可分离、怎样给统一负载保证仍开放。其他配对/星收缩审计的数据不在本源码默认入口内；没有新run它们，也未把同报告链接扩成全部源码阅读或done。新运行和现全文审查的七条计数一致；本批不声称读了全部旧综合JSON或重现外部文献。有限证据、一般局部障碍和一般UM开放目标分别保留。
