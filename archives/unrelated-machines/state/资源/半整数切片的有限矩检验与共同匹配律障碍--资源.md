# 矩阵到底如何核验

对N奇、t=N/2，`mu(N,k)=(t)_k/(N)_k`。次数≤r的全部Boolean单项式用N位bitmask记录，`basis`枚举所有大小0..r子集；乘积以bitwise union合并重复变量。因此实际矩阵
\[
 M_r[A,B]=\mu_{|A\cup B|}
\]
维数是`Σ_(k=0)^r binom(N,k)`，不是任取小主块。`psd_rank`使用**Fraction精确Schur消元**，不同于整数Bareiss：正pivot对剩余对称块作Schur更新；零pivot要求该剩余行全部为零，负pivot拒绝；正pivot数给秩。此前消去的列可保旧数值，因为后续只使用未消去的主块。没有浮点特征值或容差。

默认只运行(N,r)=(5,2),(7,2),(11,3)，并断言秩为binom(N,r)。每例另逐次数a=0..2r−1查
\[
 a\mu_a+(N-a)\mu_{a+1}=t\mu_a,
\]
逐k=0..r查二项反演的Gram系数
\[
 \sum_{j=0}^k(-1)^{k-j}\binom{k}{j}\mu_{2k-j}
 =\frac{(t)_k(N-t)_k}{(N)_{2k}}>0.
\]
它也对全部整数a,b≥0、a+b≤2r逐项检查短混合柱面的包含排除式
\[
 \sum_{j=0}^b(-1)^j\binom bj\mu_{a+j}
 =\frac{(t)_a(N-t)_b}{(N)_{a+b}}.
\]
这利用对称性按文字数核算，不枚举每个带标签的柱面。只在N≥4r−1时断言全部这些值严格正；一般高阶PSD证明仍需harmonic分解，不能从三例代替任意N/r。

# 共同匹配律为何不存在，何种小修复足够

在N个K₂,₂单位块中，每个块任取两个完美匹配之一都给真实OPT1。把块状态写为Boolean B_s，目标矩的一阶、跨块二阶为
\[
 E B_s=1/2,\qquad E(B_sB_t)=\frac{N-2}{4(N-1)}\ (s\ne t).
\]
若有保持它们的真实完整匹配分布，Q=ΣB_s满足EQ=N/2及EQ²=N²/4，故VarQ=0。N奇使Q的整数值不可能恒为半整数。程序对所有s=0..N验证`(2s−N)²≥1`，这是按总数值检查的离散障碍，不是枚举全部2^N调度；方差公式给共同law矛盾。

保持一阶、允许每个跨块pair改动绝对值≤δ时，VarQ至多比目标增N(N−1)δ，而整数半均值要求VarQ≥1/4，所以
\[
 \delta\ge\frac1{4N(N-1)}.
\]
以各半概率均匀选大小(N−1)/2与(N+1)/2子集，保持EB_s=1/2，pair为(N−1)/(4N)，与原pair差恰上述半径，达到下界。程序以两层下降阶乘公式核这个差，未采样或显式枚举这两个分布。

因此失败的是**保给定一阶及跨块二阶的共同匹配律**；只保一阶可重耦合，或直接选一个完美匹配就有好调度。既有一般结论对固定r≥2、任意奇N≥4r−1给高阶PSD/短柱面和行CONFIG相容，大小N^{O(r)}只对固定r是多项式。代码不证关于变元r的一致多项式，不给调度近似下界、强层级gap、hardness或六人SPE反例。
