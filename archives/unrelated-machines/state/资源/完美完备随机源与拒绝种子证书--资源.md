# 硬时间的全种子合同

固定确定性R(Φ,r)每条路径都有输入长的硬多项式时间/输出长界，种子r多项式长，输出FAIL或合法显式source实例。D是总的确定性多项式判别程序，source YES答1、NO答0、promise外可任意但停机。定义复合结果D̂：R返回FAIL时直接答 **1**，否则运行D。要求

\[\Phi\in SAT\Rightarrow\forall r:\widehat D(\Phi,r)=1,\qquad
\Phi\in UNSAT\Rightarrow\exists r:\widehat D(\Phi,r)=0.\]

则拒绝seed是UNSAT的NP证书：猜r、重跑R，若FAIL **拒绝该证书**，否则当且仅当D输出0时接受证书。SAT全称完备排所有假证书，UNSAT存在拒seed保证至少一个真证书，故UNSAT∈NP，推出NP=coNP。不需找到seed，不主张所有输入共用一条seed，也不需识别“source好事件”或验证NO承诺；D在promise外拒绝仍不能造成SAT假证书，因为全SAT seeds已约束复合器接受。

把FAIL视为复合判别器YES，并不意味着把它视为不可满足证书接受。显式SAT公式R对全部seed都返回FAIL完全满足YES完备；若证书接受FAIL，就能伪证其不可满足，立即失soundness。这正是旧整理页错句需要改而非术语选择的原因。

# 有概率下界才得到单侧随机复杂度后果

若另有均匀公平位、最坏多项式sampler，对每个UNSAT输入的拒绝概率≥1/q(|Φ|)，q为同一个固定多项式，则独立运行q次、全部复合答1才接受SAT。SAT永不误拒，UNSAT误受≤(1−1/q)^q≤e^−1<1/2，SAT∈coRP。结合RP⊆NP、coRP⊆coNP及取补得

\[NP=RP=coRP=coNP.\]

不是P=NP；只有存在一个好seed可能概率指数小，不足给该升级。expected-polynomial构造不能未经转换套硬界lemma；若有统一期望界和逆多项式拒绝界，可用适当多项式cutoff再重核概率，转换本身是独立义务。随机advice或仅高概率YES完备不在此合同。

原v2/v3/v5的全seed YES/FAIL语义与好NO无条件概率在原review按source合同比较：v2删边保singleton labeling、空边也YES，≥0.9好NO；v3/v5 nonFAIL保perfect labeling、capped采样FAIL，≥0.8好NO。它们本身是已有随机源的条件应用，本批未重验外部PCP定理、全部概率分析或将其写成确定性P≠NP归约。固定g,ρ,G等参数后才用相应多项式界，不把随输入增长的所有参数免费统一。

# 条件UM推论不能省compiler或全输出decoder

对每个先固定整数k≥2，假设R_k每个非FAIL输出H还可由确定性总位多项式compiler生成合法P_H、正有理T_H，β_k=2−1/k；另需证明：SAT的全部nonFAIL seeds有真实OPT≤T_H；每个UNSAT至少一个好nonFAIL seed，使其每个完整实际分配σ若Cmax(σ)<β_kT_H都能解码出违反source NO的见证，故真实OPT≥β_kT_H。

若一般实际调度算法A保证2−ε，取固定k满足 **1/k<ε**，用

\[D_A(H)=1\iff C_{\max}(A(P_H))<\beta_kT_H.\]

YES负载≤(2−ε)T_H<β_kT_H，NO合法输出≥β_kT_H，满足前述seed合同，给NP=coNP。拒绝证书对应 **≥β_kT_H**，不能改成严格>而丢NO等号。算法只编码整数k/有理阈值，无需输入未知实ε；坏seed也必须输出合法实例、使A停机。空任务/零OPT负载0，正T保严格YES分离；∞不参加负载求和。

只有满足该 **编译后NO且全输出decoder** 合同的nonFAIL seeds有统一逆多项式概率时，才得到coRP升级。更大的source-NO事件概率不能免费替换它。实际固定费实现、同一源标签一致性、全部低负载调度decoder、source-to-UM连接仍没有给出；一份有利调度或LP证书不够。没有由此证明一般near-two hardness或主目标反面。
