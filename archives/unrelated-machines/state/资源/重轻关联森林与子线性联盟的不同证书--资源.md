# 重轻森林：纯saddle不提供整数性

固定T=1、m≥2、β∈[1/2,1)。中心任务z在每机器时间β；每台i的私有u_i只能在i，时间a=1−β/m。按严格p>βT为heavy，z为light，私有边若a>β则forced heavy，否则也light。因此 admissible heavy placement H唯一（可能为空）。中心分数均分1/m，私有任务固定，每台负载

\[a+\beta/m=1.\]

均匀价格λ_i=1/m时，固定H的残余对偶同为1，H又是唯一可用placement，所以确为 **纯saddle**；不是∀λ∃H被误换成∃H∀λ。

实际调度必须把z完整放一台，正好可得且必有

\[OPT=a+\beta=1+\beta-\beta/m.\]

令m→∞且β→1给趋二。若要H非空，取m≥4、β=(m−2)/m，此时a>β、所有私有任务forced heavy，而

\[OPT=2-3/m+2/m^2\longrightarrow2.\]

任务—机器 **关联图** 是中心任务连接m台机器、每台再接一个私有任务的树；2m+1个顶点、2m条边。m>2时中心任务有m个端点，不能把它画成“每任务两端的机器图森林”并套用普通图包算法。该例精确反驳“残余关联森林+纯saddle+R(H)≤T⇒整数T补全”。关联反馈边/叶消元可以正确判定这个T不可行，与LP没有整数性相容；没有否定配置/联合容量或其他实际算法。

# 子线性CC_r：换成了配置联合证书的模型

CC_r(T)给每个至多r台机器的集合U一份联合配置分布，配置均T可行，满足其投影覆盖条件；不同U之间不要求完整交集元组的共同一致性。该量词弱于全局联合分布，也弱于具有完整separator一致性的bag-tree合同，不能因每个U都可行就随机抽出同一全局调度。

从已归档的长链两树族：固定k，终端束分别换成长ℓ路径，机器数M_(k,ℓ)=A_k+B_kℓ，A_k,B_k仅依赖k；机器图围长2ℓ，真实OPT=2−1/k。有显式原配置证书阈值T_k=1+1/k；证书只说明配置/CC阈值 **≤T_k**。任何小于2ℓ的机器集合诱导森林，每条共享任务的两个端点出现事件互补，按树耦合各机器配置可得该U的联合分布。它不需要不同U的分布来自同一个全局样本。相关first-to-v概率和长链两个端事件的互补已在现行准确长链正文与前批资源保全，不重用曾经错误的端点概率。

给任意函数r(M)=o(M)，不要求可计算或单调。先固定k，ℓ→∞时M/ℓ→B_k且r(M)/M→0，所以r(M_(k,ℓ))/ℓ→0，最终r(M)<2ℓ，所有所需U均可耦合。因此

\[OPT/T_{CC_{r(M)}}\ge(2-1/k)/(1+1/k)=2-3/(k+1).\]

先给ε>0选k使3/(k+1)<ε，再取足够大ℓ，得比值>2−ε。该对角化以 **机器数M** 为参数；路径编号和时间表示占输入位长，不能直接换成任意子线性输入位长版本。有限脚本的机器计数回归只支持列明例子，既非一般复杂度归约，也不证明求CC证书容易。

# 比较用途和当前缺口

两结果共同提醒局部/分数证书不等于实际调度，但原因不同：森林族已有共同H仍有普通assignment分数—整数gap；CC族有每个小U的联合配置却无跨U完整一致性。森林族不依赖价格混合，CC族也不靠宏任务独立选择。将它们揉成一个“共同证书不可能”会丢掉各自真正量词。
