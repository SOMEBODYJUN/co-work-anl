# 逐坐标不增：真实最优凸包也不够

在相同机器p_ij=p_j上，全调度的Σ_iL_i固定。若重分配每台L_i都不增，则每台必恰不变，与步数/支持无关。[固定槽真OPT凸包族](真实最优凸包固定槽与最小工作量面的接续--资源.md)每机槽数m，全部槽匹配峰值2m/(m+1)趋2；其所有任务在所有端同成本，所以全部同时也是mincost输出。鲁棒循环工具要求参与点净降λ>0，求和变0≤−ℓλ，根本不存在，成功0轮。这个派生接口精确排除逐坐标非增修复，允许低负载机上升并降低整体峰值则可移big机tiny到其他机器直达OPT1。

# 开链：严格lex的最小任务/机器支持

k≥3,d≥1，δ=1/k，a=1−1/(2k)，D=d+2k−1。root有macro b（root1）和k枚tiny t_i（rootδ）；每枚g另可去自己的链首时间1。tiny链各d台home，macro链D台home，每台home自有e（home a，下一台1），末端另有空sink。链之间只共享root。m=kd+k+D+2，n=m−1，所有有限时间为δ,a,1。

S0留b在root、全tiny链激活；S1全tiny留root、只激活macro链；激活g指g去首、整链e逐个下传到sink。每个调度峰值1，b所有端1强迫OPT≥1，所以真OPT1。x=δS0+(1−δ)S1显式来自两个最优分量，自动有完整逐机CONFIG，不只是LST点。

root上b质量δ后tiny各1−δ，只有k槽却有k+1个root任务。b与平局排序首tiny只触槽0，其余tiny可各占后槽；每home总质量恰1，仅一槽。root任务g离开则占链首唯一槽，逼整链下传。令全home纯成本W0；tiny激活增

\[c_t=1-\delta+d(1-a)=(d+2k-2)/(2k)>0,\]

macro增c_b=D(1−a)=c_t+1/(2k)。单独后缀移动也增成本1−a>0。显式匹配仅激活首tiny达到W0+c_t，所以任意mincost槽匹配只激活恰这条tiny链，其实际机器分配σ唯一，槽级匹配不必唯一；任意tiny平局只改标签。峰值B=2−δ。

任意实际重分配τ若Cmax≤B，由1+a>B得：每条链的下传位只能是后缀，若g离root则全链下传。若没有新root任务离开，旧active tiny不能回root（否则负载2），其链不回迁；其他inactive链的非空后缀把正数个a换成1、0个数不变，严格让降序向量更坏。故 **严格lex改善必须激活一条新的原inactive链**，至少变d+1枚任务、其新旧端点至少root+d homes+sink=d+2台机器。再激活另一tiny链恰达到两个下界，峰值B−δ=2−2/k>1，各源只移一件。

参与机数统计变化任务全部新旧端点，不只净负载变的点；允许离开x/槽支撑仍受该原矩阵二端限制。这个证明不是只展示一条很长的修复路径，而是对所有严格lex改善给支持下界。

## 弱最大负载路径却很容易

在一条inactive tiny链，从tail向head逆序逐件下传，最后把root tiny送首。前d步新负载≤1且root保持B，lex可变坏；最后降δ。依次激活剩余k−1条tiny链，(k−1)(d+1)个单任务步骤到S0，Cmax从不增加。因此开链不排weak-Cmax中性预处理、一般重配置或全局算法。给出的最优分量还可直接输出，不能把已给凸包证书改称未知最优调度搜索器。

# 后续闭环是更强但不同的局部合同

循环原稿§11将tail回到满root，另立闭环身份。参数b=a=1−1/k、δ=(k−1)/k²、c=1/k²、β=1/k，macro链D=d+k−1。k条tiny中g0 root时间δ+c/4，其余δ；macro root b；各g去首1，home e时间a、下传1，tail回root c（g0环c/2）。两个真实OPT1分量为全tiny激活/只macro激活，x=βS0+(1−β)S1。

root k+1槽与各home一槽迫每个槽匹配整环开/闭；g0激活成本严格最便宜，所有mincost输出仅激活g0，B_k=2−3/k+3/(2k²)趋2。对任意实际τ的弱Cmax≤B，由1+a>B强迫环位z0≤…≤zh。没有新g离root时，g0回root或其他环tail后缀回root都严格抬root；所以任何非平凡弱max动作至少整个新tiny环d+1任务/d+1机器，再激活一条即达到。它甚至阻挡中性有界支持首步，区别于开链。

但所有单任务逃逸路径的最小峰值恰B+c：inactive tail先回root加c，再从后到前放空位、最后g出root，整环完成降δ−c；反复到S0。任一合法首步要么tail加c、要么home共居1+a>B+c、要么g0回root加δ+c/4>c，给下界。临时slack c=1/k²随趋二消失。该闭环与小块cactus精确算法相容，不是hardness；给定OPT分解照样可直接避开σ。
