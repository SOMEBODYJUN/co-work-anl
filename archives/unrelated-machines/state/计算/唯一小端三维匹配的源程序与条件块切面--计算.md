# N为空的原三分之一归约

给显式3DM坐标大小q≥0、s个triples。机器为s个S_a、3q个元素E_(d,e)及共同R；q+3个激活任务各在R时间1/3、每S_a时间1；每triple的三关联任务各在S_a时间1/3、其对应E时间1。m=s+3q+1，n=q+3+3s，所有job恰一个small端，所以必选大任务集N为空（不表示输出H为空）。q0,s0仍有R上的三个真实任务，峰1，不是helper另一构造的空调度。

接口(Aδ)给匹配H和剩余small共同分数容量；small端唯一使剩余质量全1，故其本身就是一个完整整数调度。δ<1/3时负载以1/3格点计、≤1+δ<4/3，等价≤1。R最多留三个激活任务，至少q个须去不同S_a；每激活S_a已有unit，三个关联任务均须占不同元素机，元素机总共3q台，故激活数r满足q≤r≤q。于是恰q个不交triples，给完美3DM。反向选q匹配triples、激活它们、三个多余selector留R、对应关联任务外送、其它留S，即得到峰1和合法H/x。

因此旧三分之一构造证明δ∈[0,1/3)的接口选择困难；归约数字常数位、输出显式多项式。δ=1/3端点不可加：q1、无triples的NO源，四selector全R峰4/3，H空且x整数，已可满足接口。本程序在块审计中真调用`round_interface(...,delta=1/3)`核此点；另3/2+1/3=11/6与3/2+1/2=2仅有理算术，不能说默认跑了所有δ的调度。

给定合法H/x后，helper以ST槽匹配仅舍入剩余small，负载≤(1+δ)T−h_i+T/2，加回H得≤(3/2+δ)T。这是已给共同见证的条件舍入，不寻找H。本程序194个YES调用均由实际调度制造0/1x，没有重跑helper主入口的四份真正分数/零/大分母案例。
