## 1. 一般双见证 v2 的完整合同与证明

令有限非空机器集为 M，有限任务集为 J；显式处理时间为非负二进制有理数或无穷，每个任务须有合法端。给同一 P 的完整合法分配 σ₀、σ₁ 和有理 T≥0，逐机负载均≤T。令 D={j:σ₀(j)≠σ₁(j)}，给非空 Q⊆D；查询的身份及指定新端固定。对每个差异任务定义旧端时间 a_j=p_{σ₀(j),j}、新端时间 b_j=p_{σ₁(j),j}；固定任务的逐机负载为 f_i。两见证给

\[
f_i+\sum_{j\in D:\sigma_0(j)=i}a_j\le T,
\qquad f_i+\sum_{j\in D:\sigma_1(j)=i}b_j\le T.
\]

定义

\[
\delta_q=\max_i\sum_{r\in Q\setminus\{q\}:\sigma_0(r)=i}a_r.
\]

`UM-TWO-WITNESS-QUERY-SEPARATION-v2` 构造两两不交 A_q⊆D\Q，令 τ_q 恰将 {q}∪A_q 移到 σ₁ 端、其余任务保持 σ₀ 端，则

\[
C_{\max}(\tau_q)\le\max\{3T/2,T+\delta_q\}.
\]

给 D\Q 任意非负有理权 w_j，令 W=Σw_j；构造不依赖权，实际改派费是 c_q=Σ_{j∈A_q}w_j，总和≤W，故至少一查询费≤W/|Q|。费用相对于 σ₀ 的指定非查询 owner 改变；背景费用、退款和不按改派计的物理费用需要另定合同。

证明和原实现都把任务 j 视为 σ₀(j)→σ₁(j) 的带标签弧。查询 q 起初染唯一颜色 q，非查询弧无色。**某色在机器 i 的流入必须用新端时间 b_j 求和**：

\[
I_i(q)=\sum_{j\in D:\sigma_1(j)=i,\,\operatorname{color}(j)=q} b_j.
\]

未触发机器若有 I_i(q)>T/2，按固定机器顺序、查询顺序选择首个，把它标 q，并将从该机出发的全部非查询弧染 q。非查询弧只有一个源，所以此前尚未染色；查询弧始终保留自己的颜色。由 σ₁ 负载，所有颜色总流入加 f_i≤T。一台机器触发 q 后，I_i(q)>T/2 单调保持，其余任一色再也不能超过 T/2，因此每机至多触发一次。终止时，未标 q 的机器满足 I_i(q)≤T/2。

令 A_q 为最终 q 色非查询弧。未标 q 机器的实际 τ_q 负载≤原 σ₀ 负载加 I_i(q)≤3T/2。标 q 机器的非查询旧出弧全部迁走，固定负载与 q 色新入任务由 σ₁ 控制≤T，额外仅剩其他查询的旧负载≤δ_q。两类覆盖全部机器，给所述界。不交性来自每弧唯一颜色，非负权求和给费用界。T=0 时已用端全部零，无严格触发，所有 A_q 空；构造仍合法。∞ 从未被实际见证使用。

染色至多 |M| 次触发、|D| 次赋色；显式 |M|×|Q| 有理表和重复固定序扫描是确定性总位多项式。输出 |Q| 份完整分配规模为 |J||Q|；有理求和/比较位长受输入编码控制。不要求 unit、唯一 home、度数或图形态，也不负责寻找未知 σ₀、σ₁。

现有[匿名令牌与查询分离审查](../审查/匿名令牌非扩展与双见证查询分离三源审查--审查.md)曾将弧流入误述为旧端权；应按本节改为 b_j。新保存见证检查发现10个已染流入单元的 a/b 和不同，例如锐例 A 上 q1 流入正确为1、错误旧权仅1/8；共享源例 C 上 qa 正确5/4、错误旧权7/4。原程序始终使用 b_j，错误在整理摘要。

## 2. 原实现和全部三个输入

`TwoWitnessColoring` 用 Fraction；有理输入只接受字符串或非 bool 整数，拒绝负时间/权、重复任务/机器、非法端和不完整分配、非空性/包含关系不符的 Q 以及超过 T 的给定见证。未列端表示不可用；输入可列两见证以外的合法端，但构造只使用这两个已核端。JSON 内给定 `expected` 支持、触发顺序、未染集合、峰/δ/界/费会逐项断言。

程序独立重算最终流入，检查 σ₁ 总流入上界、每机唯一触发、全部非查询出弧随色迁走、查询颜色不变、支持不交、费用相等和全部原任务/原机器负载。`requested_queries` 可仅输出指定子族，默认全部；染色与全族费用检查仍针对全部 Q。输入 `enumeration` 才枚举两端混合状态，硬上限64，且明确与多项式构造分开。只有输入要求并核实每任务所有有限端恰是两见证端，才可称穷尽全部有限端分配。

CLI 必须显式 `--input` 和 `--output`，输出文件必须尚不存在，以独占模式创建；查询程序不自动建父目录。输出含实际调用、Python版本、输入/脚本 SHA、每份完整 σ 和逐机负载、触发轨迹。它不是 v3 查询计数程序、通用调度优化器或任意 pattern 生成器。

| 全部输入 case | 实际规模与非查询支持 | 全部请求的单查询输出 |
| --- | --- | --- |
| `sharp_six_machine_five_job` | T=1；6机5任务；A_q1={x1}，A_q2={x2}，f未染；W=1 | 两份均峰11/8、δ=1/8、界3/2、费0 |
| `zero_threshold_two_queries` | T=0；4机2任务；两 query 在互异零端间迁移；无触发和非查询 | 两份均峰/δ/界/费0 |
| `arbitrary_times_shared_query_source` | T=2；8机9任务；A_qa={xa,y,z,v}，A_qb={xb}；W=39 | qa峰21/10、δ3/5、界3、费28；qb峰9/4、δ2/5、界3、费11 |

第三例两个查询旧端同为 H，含静止 s、w、额外未用资格 qa→F、xa→X，以及 A、B、C、D、H 五步触发。各实际时间不同，直接覆盖 a/b 不可混用的实现边界；这不是对所有任意时间矩阵的穷举。

锐例全部有限端如下，未列端∞：q1:H1(1/8)/A(1)，q2:H2(1/8)/Bm(1)，x1:A(1)/R(1/2)，x2:Bm(1)/R(1/2)，f:R(7/8)/S(1)。σ₀均取前端、σ₁均取后端，峰均1。仅 f 权1，其他非查询权0。程序枚举2⁵=32份完整分配；在指定恰一个 query 迁移时，cap4/3 的最低费1且 f 必迁，cap11/8 的最低费0；费≤0的最小峰11/8、费≤1的最小峰1。这是该固定例全部合法分配，不能把32扩充成所有一般输入。

一般3/2锐性的解析族将 q 旧端取任意正 η≤1/2、f旧端改成1−γ，其中0<γ<min{1/2,3/2−B}，其余端不变。对任何1≤B<3/2，指定单 q 进入 unit 端后，x 必离开，否则原 A/B 负载2；若 f不动，R负载≥3/2−γ>B，所以两个单查询都必须迁同一个 f。它们各可用 {q,x,f} 达峰1，非真空不可行。两 strict 见证仍在，查询初态任意小，故3/2是合同的全域锐上确界。固定γ=1/8实例的免费单查询阈值为11/8，并非恰3/2；原 P 有峰1调度，不是原 P 的 OPT gap。

## 3. 第一个固定矩阵：take/continue 的完整达界证书

第二原程序 `audit_query_return_source_fixed_certificates.py` 与前一程序没有共同输入 API。其 `take_check` 从以下固定菜单常数重建原矩阵，不调用证书生成器。对 a=1,2,3，每位源 agent 是**三个 groups、五个 states**：

| group | state | 资源及 private 时间 |
| --- | --- | --- |
| r_a | take1 | u1:3/5，x_a:2/5 |
| m_a | off | x_a:1 |
| m_a | take2 | u2:2/5，y_a:3/5 |
| l_a | off | y_a:1 |
| l_a | accept | z_a:1 |

每 state 一台独立 private、每资源一台 R；每 group 一件 unit selector，仅本 group 的 states 有资格；每 state-resource 一件不同 incidence，在自身 private 用表内时间或对应 R 用1，其他端∞。所有未选 states 的 jobs 仍执行。原矩阵26机、30任务=9 selector+21 incidence、57 finite entries。

保存证书选择 take1/take2/accept，各领取 x_a/y_a/z_a，bundles 全局不交，逐组质量2/5、3/5、1，最小2/5。把9 selector放所选 private，9件领取资源的 incidence 导出，其余12件（含全部未选 off）留 private。每 agent 的五台 private 负载依次8/5、1、7/5、1、1；九台私有资源机负载1，R_u1、R_u2为0。`take_check` 检查重建 state/job 表、全部57资格、完整 assignment 和全部26负载、所选状态、bundles、质量，得到达界峰8/5。

**这里没有运行优化枚举。** 精确最优值的下界来自[编译障碍的解析证明](../../tools/evidence/query-witness-originals/comparisons/line_set_packing_and_take_continue_compilation_obstructions.md)：若任何完整调度 C<8/5，每个 r_a 的 selector 只能在其唯一 take1 private，因此其 u1 incidence 必离开，否则叠成8/5；三件不同 u1 incidence 都被迫到 R_u1，总负载3，矛盾。达界给 OPT_UM=8/5。另一方面，任何 min partial质量>2/5 都迫三个 roots 同时领取 u1，不交性不可能，故 V=2/5。源只有两件不可拆 items、三 agents，各 item价值3/5，必有人无物，OPT_SC=0。于是这条具体 additive take/continue 编译无任何正常数的统一正值 decoder；证书核验不承担该全调度解析下界，更不否定全部其它编译。

## 4. 第二个固定矩阵：一个 UNSAT 例全部5184份合法分配

`sharp_check` 另重建8机10任务矩阵。i=0,1,2,3 下标模4：q_i 有 M_i 时间4/5、M_(i+1)时间1、C_i时间1/2；b_i 有 C_i时间1，另一端是 M_i（i<2）或 M_(i+1)（i≥2）时间4/5；u+可到 C0/C1、u−可到 C2/C3，时间均1/2。未列端∞。对应源公式 (x∨x)∧(¬x∨¬x)，无 padding，24 finite entries。

原程序按乘积3⁴·2⁶=5184枚举**全部合法端的完整分配**，以十分之一整数单位求所有机器负载。它核对 root 证书、独立证书（q0↔q_1等显式重命名）同一矩阵、两份各自最优 witness，以及独立 baseline 完整负载。实际峰直方图为：

| 峰值（十分之一单位） | 15 | 16 | 18 | 20 | 24 | 26 | 34 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 完整分配数 | 247 | 601 | 1485 | 1331 | 264 | 1112 | 144 |

数目和5184、最低15，因此这个固定 P 的 OPT=3/2。独立 baseline 把 q_i放M_i、b_i放C_i、u+放C0、u−放C2，M各4/5，C负载3/2、1、3/2、1，达到下界。原源的全公式定理还需[共居 SAT 的解析环计数](../../tools/evidence/query-witness-originals/comparisons/direct_cohabiting_query_return_strict_sat_and_sharp_escape.md)，不能由该单例枚举推出。

这份 P 本身无峰≤1分配。它与26机 take/continue 矩阵互异，与6机查询锐例也互异；把“两个证书审计”理解为同一 P 的两个 strict 见证，既违反实例身份，也与本例 OPT=3/2冲突。

## 5. 实际运行、独立性和证据归属

恢复的首次原入口运行使用 Python3.12.14，两个命令均 exit0、stderr空；完整命令、stdout、stderr及输出原样留存于 `runs/original-replay-001/`。原 `replay.py` 不 import 原程序，用子进程调用两个入口各一次；其保存的独立回算记录核对三 case 共44份完整调度（6输入见证+6单查询+32混合）、224任务归属、264逐机负载、7次严格触发和全32状态唯一性/阈值最小费。固定审计的5184枚举只属于该8机 P，take/continue仍为一份达界证书。

因已有两个入口成功记录，本轮未再执行它们。针对整理中旧端权误述，新增不 import 原程序、不调用旧 `replay.py` 的 `inspect_saved_witnesses.py`，直接从输入端表回算保存的44份查询调度，重建26机全矩阵并回算其证书，再核8机的两份最优证书和baseline。一次执行 exit0、stderr空，合计48份完整分配记录、284任务归属、314逐机负载；10个不同 a/b 流入单元见完整报告。它未重枚举5184，也未新生成32混合；48是保存记录数，不保证互异调度数。其输入/源码指纹与首次运行副本完全一致。

该新增检查是读后独立算术实现，不冒称先陈述盲审；第一次运行的 provenance、原作者/旧审查顺序和本轮检查分开。两个原入口与新检查均无失败记录；不据成功状态掩盖未实现功能。下界、全输入量词和位复杂度依靠上述证明，有限成功断言只提供列明输入的计算证据。

## 6. 全仓比较与接续关系

[对称重置与双见证审查](../审查/对称重置与双见证查询双源审查--审查.md)已保 v3 合格查询计数、nearunit初态读数和多替代见证共享任务容量；本原程序只实现 v2 单查询。一般染色不能宣称用同一 A_q 的并支持全部子集：不同小于半量的新流入合并可能另超载。单 home 级联则在“唯一正小端、σ₀全部留home、unit匹配”更强输入下给全部子集，其量词不能由本次三 case 覆盖。v3保留原条件 T>0、p_{σ₀(q),q}≤ηT（允许η=0），平均费 W/(d−Rβ) 只在 Rβ<d 时适用。

[向量贪心/累计路径冻结审计](../审查/向量贪心填充叉与累计路径冻结审计--审查.md)和[直线集合打包/端口停车审查](../审查/直线集合打包与统一端口停车双源审查--审查.md)已经保两固定证书及解析障碍；本批新增是原入口的完整可执行保全、精确命令和给定输入/输出核对，不重复认领这些 JSON 或解析定理。

关系判断可复用三条，保持标签和前提：两份同 P 实际≤T见证→目标时间阈值染色→不交单查询支持及费用平均（实现/有限检查）；固定take菜单常数+全部原任务证书→达界8/5（证书检查，最优下界另依解析强迫）；固定UNSAT原矩阵+全部合法端枚举→该 P 最优3/2（有限穷举，不是全公式推导）。没有三者联合推出一般算法或困难性的边。阶段三仍按实际对象建立图，本页已给可解释接续而不导入旧图。

继续时须区分给定两份 actual 的构造与寻找未知 YES，区分最小费优化与构造费用平均，并明确任何新物理收费、源边界和共同容量。不提供通用 LP/SDP、v3筛选生产实现、全 pattern 调度器、源 decoder或一般 UM 近二结论；UM-TARGET-v1仍开放。
