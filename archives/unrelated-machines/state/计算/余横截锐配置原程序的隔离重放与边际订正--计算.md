# 完整同族数学，不以有限表代全称证明

固定j删$I_j=\{g_{u,a,j}:u,a\}$，对应L各去自己的不同A，其余留g，故I_j独立。**D个原子各权1/D**，每g恰出现一原子，故$y_g=1/D$、$y_A=y_B=0$；此处m=D+1，不是1/m。任意每u选label并保≥2项，至少2m受影响L只邻m个所选A和D个B，m+D<2m，Hall矛盾；每u保一g并使其L去A可达，真实最大共同保留比例精确1/D。

普通P每label一个parent和D枚ports（private1/D、g端1），**每u一个**unit selector可选D parents，全部未选ports及所有L保留。T1配置证书：parent的单selector1/D及全ports1−1/D；g的单port1/D及单L1−1/D；每A的D个单L各1/D；每B空配置1。机器行和/job覆盖恰1，所有配置负荷≤1，selector又排T<1。实际选a0、只外送j0 port及其L去A，其余ports留parent/L留g，峰$2-1/D$。若任意实际C更小，每selector parent至少送2ports，其unit L不能再停这些g，触发同一2m>m+D的Hall矛盾，故真实OPT$2-1/D$。此一般下界来自解析全任务论证，不是程序穷举。
