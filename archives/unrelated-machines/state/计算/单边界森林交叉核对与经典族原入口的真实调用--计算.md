# 1. 相同原输入的两个不同圆整模型

crosscheck原码2276B SHA `e81faeea5df317f2cfa937eca2dee9f4ef85c3db0cc77d7f825cb75e3bef0fee`完整读。本轮一次原CLI，seed671244生成600个原任务字典：每真实parent边一/两件平行job，另随机singleton，精确Fraction T及η∈{1,1/2,1/5}。缺失真实边以空parent边接0供down表示所有顶点；这些空边不新增任务或资格，up只读真实支撑，允许不连通森林。

用up.brute全分配枚举内部T容量下的最小真实根负载；分别调用[local floor和global ceil](单边界森林双向格点程序的真实负载与恢复--计算.md)。None必须无精确可行分配；若返回，重新按原字典算load_vector，核根b确为真实负载、内部≤(1+η)T，有精确参考时b≤该参考。不同模型不要求互相相等。

实际600例精确可行382，down返回387、up返回414，返回状态分歧27、两者都返回时根值分歧20，不连通真实支撑323。额外返回并非错误可行性宣称；合同是资源放大的一侧支配。输出全结构与历史5a826一致，没有有限统计推出两个模型完全等价。

# 4. 固定B的等端私有汇点族

设r=k²，2r台机器为homes i与各自sink r+i，B固定只在home0时间1。每home有k个small任务，home与其sink的时间**均1/k**，其余端∞。这个显式固定B修复问题的simple支撑是平行包组成的森林，不是昂贵叶族（那里的叶端为1），也不是任意输入都可免费固定B的定理。

实际k2/3/5/10分别8机9job、18机28job、50机126job、200机1001job；T1、η1/10，根b和全峰均1，B-home的全部k件small都移到其私有sink。代码逐job核真实分配，B限制仅据该对称族解释，不转成一般结构生成方法。
