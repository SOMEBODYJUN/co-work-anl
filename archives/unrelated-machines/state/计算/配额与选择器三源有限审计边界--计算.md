# 处置对象

本对象把三个相邻但不相同的有限审计放在同一计算页，明确每个来源的定义域、量词、实际枚举、可推广证明和缺口。审计程序的 `PASS` 或 `ok` 字段只表示所列运行通过；对应的数学引理仍以主源正文为准。

## 1. 三值 selector 的完整 ordinary-UM 六例

`selector_tiny_root_three_values_audit.json` 覆盖三种三元组来源，每种 ℓ=2,3 两例。程序把时间缩放为 1/ℓ 的整数，保留全部 selector 与 leaf jobs，直接枚举完整 assignment，随后以 Fraction 报告 makespan。六例为：

| 来源 | q, ν, μ | ℓ=2 OPT | ℓ=3 OPT | 枚举规模（ℓ=2,ℓ=3） |
| --- | --- | ---: | ---: | ---: |
| perfect | q=2, ν=2, μ=2 | 1 | 1 | 16, 64 |
| parity_middle | q=2, ν=1, μ=2 | 3/2 | 4/3 | 1,024, 16,384 |
| nonisolated_h_deficiency | q=4, ν=2, μ=3 | 2 | 5/3 | 12,288, 786,432 |

当前重跑 JSON 与冻结记录完全一致，程序 hash 为 `4ca44b73a8b7b0abee8a047aad657ce2d943293d1e555b29d8f54fc07ca0df11`。这六例支持“分类值等于实际完整 assignment optimum”的有限断言；它们没有把三值分类扩展成任意 q、任意多标签 ordinary-UM 的算法，也没有删除任何原 jobs 后再报告 OPT。

## 2. 单层配额平方根重数地板

相关正文 `single_layer_quota_sqrt_multiplicity_floor.md` 给定有限变量集合 X、邻域 `|A_x|≥K` 和资源关联度 `deg(u)≤Δ`，定义 `ν_t` 为最多能各取 t 个互不相交资源的变量数，`b=max_t min{t/K,ν_t/q}`。固定 t 的最大 t-束并集大小为 `s t`；未选变量若在并集外还有 t 个资源即可扩充，因此至少有 `K−t+1` 个资源落在并集内。对资源重数计数后得到

`(q−s)(K−t+1) ≤ Δ s t`，

从而

`ν_t/q ≥ (K−t+1)/(K−t+1+tΔ)`。

对 t 取最大给出平方根量级地板；当 `K≥√Δ+1` 时，取 `t=floor(K/(√Δ+1))` 得到 `b≥1/(√Δ+1)−1/K`。同一正文还给出资源总量的上界 `b≤√(N/(qK))`，以及分组族的离散公式。关联审查已修正分组族的连续极限写法，不把有限离散值误写成连续平衡点。

当前重跑精确复现 `ok: 23192 exhaustive systems; group formulas checked`，程序 hash 为 `4025fb7add84be0e3706c26e9f43597fcd090673018224e2fec447aed6e470b5`。这是自足计数引理加有限核验；多标签必须先固定一个完整标签，不能把同一变量的标签并集当成原需求树中的邻域。它不推出一般困难性、近二 gap 或任意异质菜单算法。

## 3. 两状态固定方向 Hall 支付

`two_state_quota_hall_cut_decomposition.md` 处理已经固定的变量子集、每个变量的 rail 方向和标签支付需求。给标签集合 L 与需求 `t_ℓ`，存在不交资源支付当且仅当对所有标签子集 U 有

`Σ_{ℓ∈U} t_ℓ ≤ |N(U)|`。

资源度至多二时，邻域可按单标签资源、内部共享资源和边界共享资源分成 `p(U)+e(U)+∂(U)`，正 Hall 缺口即固定方向的可验证 FAIL。标准二部匹配或下界流给出精确等价；完整支付退化为 2-SAT，部分支付需要保留高阶 Hall 切。当前重跑精确复现 1,296 个关联模式与 279,936 个固定方向实例。

该等价只量化已选 L 和已固定方向；一个方向失败不能推出原调度阈值下的全输入 FAIL，因为另一方向可能可行。它也不选择变量子集、根树比例或统一算法。原 JSON 没有新的数学证明，正文/审查中的 Hall 证明承担全称结论，JSON 只承担有限程序核验。

## 4. 比较、证据和接续

三源共同使用 exact arithmetic，但对象层级不同：selector 六例是完整 ordinary-UM assignment；平方根是单层超图计数；Hall 是固定方向的离散支付。它们不能合并成“资源碰撞必然给硬度”或“固定方向可行即一般可解”。
