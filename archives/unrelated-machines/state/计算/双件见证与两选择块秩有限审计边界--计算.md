# 处置对象

本对象把两条有限审计链分开登记。它们都涉及少数大件或块配置，但量词、目标函数和程序合同不同；不能把它们的 `all checks passed` 合成一般 unrelated-machines 近二结论。

## 1. Top-two 三半审计

`top_two_pair_witness_boundary.md` 定义完整分配中的每机第二大件值，记所有机器最大值为 outer max、第二大件值为 inner top-two；其上界算法保证 `B₂ ≤ 3 O₂ / 2`，而 `O₂` 与普通总 makespan OPT 是不同目标。正文还给出固定 `1 ≤ ρ < 3/2` 的出现位置环 3SAT 编译：YES 的完整分配有 OPT=O₂=1，NO 的任何完整分配都有 unit+half 同机对，因此 O₂=3/2。它明确说这不是趋二 gap，也不等于普通 makespan 的一般算法。

本轮完整读取冻结 JSON（3,006 字节）、审计脚本（11,685 字节）、boundary 正文（25,250 字节）和范围审查（6,087 字节）。脚本直接枚举完整 assignment，不删除原 jobs；当前重跑与冻结 JSON 的核心字段完全一致：

| 矩阵族 | 总矩阵 | 有限可行 | OPT=0 | 三半精确比率案例 |
| --- | ---: | ---: | ---: | ---: |
| 2 机、4 job、值 ∞/0/1/2 | 65,536 | 50,625 | 2,401 | 5,296 |
| 3 机、3 job、值 ∞/1/2 | 19,683 | 17,576 | 0 | 5,697 |

SAT/锐度部分枚举 256 个公式模板，其中 95 个 satisfiable、161 个 unsatisfiable；穷举 50,625 个 unit placement，其中 46,456 个 UNSAT placement 有不可避免 unit+half pair。空 jobs、零机器非空 jobs、无有限端、零 OPT 和 100 位分母都通过。运行环境差异只在 base commit、platform 和 scratch source path，数学字段不变。

## 2. Two-choice block-rank 与 cactus 交叉

`two_choice_block_rank_audit.json` 明确 scope 是 finite exact oracle/witness evidence。脚本调用 `two_choice_block_rank_exact.py` 的块秩 solver，检查：

- seed=20261017 的 1,000 个随机实例、1,000 次 exact optimum search、5,000 次 threshold comparison，全部 witnesses checked；
- 4,096 个 two-triangle cut-vertex 实例、16,384 次阈值比较；
- 空 jobs、全零、单有限机、显式 ∞、巨大稀疏标签、521-bit 分母/602-bit 分子、4,000-edge 深树迭代遍历和 7 个并行 labelled jobs 等边界；
- 11 个非法案例拒绝；
- k=2,3,4 的 girth=3,4,7 cactus 交叉，实际 OPT 分别达到 3/2、5/3、7/4，且阈值判定与全部 witness 检查一致。

当前重跑的这些字段与冻结 JSON 完全一致。块秩程序的有限证据支持精确 oracle/witness 实现和给定 cactus 输入的数值，不声称 gap target 是一般配置阈值，也不声称 near-two hardness 或统一近似定理。程序依赖的 solver、cactus fixture 和 audit 全部保存于 evidence/source。

## 3. 比较、失败机制与接续

两条链共同保留几个关键边界：

1. `B₂` 的上界只能约束每机前两件；普通总负载可以由第三件或更多件主导，因而 `B₂` 上界不能替代普通 makespan 近似。
2. top-two 的固定小于 3/2 困难性依赖出现位置环、完整 decoder 和资格度界；不能由 256 个小公式的有限核验推出一般 NP-hard reduction。
3. block-rank 的 threshold witness 只对其显式矩阵和给定 T 有效；`FAIL`、cactus gap 和 finite oracle 不能自动转成一般实例的全称 NO 证书。
4. 两源都不改变六人单位客户共同目录 SPE 的目标和终局均分定义；不得将 unit/half pair、块秩或 cactus girth 直接导入六人模型。

本轮新建 evidence 目录 `archives/unrelated-machines/tools/evidence/pair-witness-audits/` 保存所有冻结输入、源程序、相关正文、重跑输出和 manifest。可推广的匹配/decoder 证明仍留在 boundary 正文；本计算对象只登记有限实现、自检和准确未检范围。
