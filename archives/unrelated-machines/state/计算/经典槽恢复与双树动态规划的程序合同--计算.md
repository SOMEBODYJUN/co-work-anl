# 经典槽恢复与双树动态规划的程序合同

[原程序](../../tools/evidence/model-classical/original/tests/audits/unrelated_machines/rounding_and_gap.py)是标准库Fraction有限审计及恢复器，来源ID`e57947bc795251d373c3`，完整hash为`5ba0dc52ddbb90ffece75e5accd2e801957c1172e337b9bdf033e22a64cbd75a`。完整源文件保存其全部输入生成和实现；本页解释各部分能被怎样调用。它不是通用LP软件，亦不靠运行次数证明一般结果。

## 输入、输出和确定性恢复

矩阵按machine-major排列，`None`表示不可用；规范使用整数/有理串，也可传已构造的Fraction。`rational`显式拒绝float和bool。`matrix`要求至少一台机器、每行长度相同、所有有限时间非负、每任务有有限端；`[[]]`可表示空任务，空机器列表被拒。`loads`逐任务验证assignment长度、机器标签必须严格为int、范围合法且端有限，再用Fraction重算所有机器负载。

`round_slots(p,x,target)`接收已经给定的有理证书：目标非负、x与p同维、x非负、每列和1；正x不得用None或p>T端，每行分数负载≤T。T0只允许零时间正支撑，空任务也被处理。没有在函数内部求LP或估计OPT。

通过验证后，每行按`(-p_ij,j)`排序正支撑，依累计质量的整数部分创建单位槽，只记录正交长邻接。每任务按原标签依次用BFS寻找空槽，保slot→job和交替路父关系，再沿旧job→slot逆匹配增广；没有递归深度假设。最终返回`(assignment, actual_loads)`，后者由`loads`重新求和。程序还检查每机实际负载≤分数行负载+该行正支撑最大件≤2T。

一般正确性由[有序槽完整定理](../定理/有序单位槽的支撑最大件舍入--定理.md)的Hall/前槽收费证明承担，图规模和有理位长均按实际证书计。源码没有最小费用匹配，不宣称保成本；也没有通用LP后端和目标搜索。恢复器完整实现与“接一个精确LP后数学上可得2近似”是两个可复用接口。

## 展开树的配置接口

`height(k)`只接受严格int且k≥2，从α=1/(k−1)乘k/(k−1)至首个α≥1/2。`gap_instance`另限制2≤k≤4，避免大图展开；返回实际p、每机器全部`(weight,job_tuple)`配置及T=1+1/k。

每树底父节点连一终端，k条平行任务是不同标签；其余内部节点有k个独立子树。`subtree`返回incoming边际a，机器先以1−a选择全small，再各以a/k选择incoming与一件small。根配置再分成保留big及只删big两份，以1/(2a)把每根big边际降到1/2；过滤零权，不删其他任务。程序逐机器核权重和1、权非负、配置内标签无重复、只用有限端、配置负载≤T，最后逐任务核覆盖恰1及每任务恰两有限端。

一般[双树配置证明](../障碍/双树配置证书的趋二整数间隙--障碍.md)以k≥4和明确高度重索引承担所有量词；程序k2/3的额外有限域不改那份证明的域。展开k2/3另外枚举32/128真实分配核OPT；k4实际74机169件只核显式配置和专用DP，不冒称全分配枚举。

## 专用树DP的状态和全部递推

`compressed_gap(k)`不创建矩阵或配置。以1/k为整数单位，b∈{0,1}表示本子树根是否承受incoming大端。令D_t(b)为高度t对称子树的最小峰单位，r表示k件outgoing中留在父机的件数。

底层k条平行边共用一个终端：父负载kb+r、终端负载k(k−r)，故

\[
D_1(b)=\min_{0\le r\le k}\max\{kb+r,\ k(k-r)\}.
\]

上一层留父的r件使其r个孩子处于incoming0，其余k−r个孩子处于incoming1。子树互不共享任务或机器，可独立取最优；因此

\[
D_{t+1}(b)=\min_{0\le r\le k}
\max\bigl(\{kb+r\}\cup
\{D_t(0):r>0\}\cup\{D_t(1):r<k\}\bigr).
\]

两树之间只共享一件big，恰一根incoming1，另一根incoming0，所以整族真实OPT是max(D_h(0),D_h(1))/k。源码的`max(dp.values())`正是这个最大值，不是用LP证书猜OPT。底式直接得D₁(0)=k、D₁(1)=2k−1：b0取r=k达k，更小r要给终端至少k；b1取r=k−1达2k−1，r≤k−2使终端≥2k，r=k使父2k。归纳中b0取r=k达k，r<k含旧D_t(1)；b1的r=k给2k，而r<k含2k−1且r0可达该值。因此各高度都保这两状态。该递推依赖完全对称树与独立子树，不能移作一般调度精确算法。

主程序只计算k5/8/16/32的压缩记录，高度5/11/33/88，OPT9/5、15/8、31/16、63/32；输出还保完整root α及证书阈值/下界比值。`certified_lp_upper`是配置证书的T，`gap_lower_bound=OPT/T`是gap下界；两者不同本来正常，未求精确T_CONF。
