# 三态单位选择器正规形的有限投影审计

## 记录内容

冻结 JSON 以 `status=pass` 保存一组精确有限检查。它记录 29 个实际投影、116 个新调度和13个原调度，全部用精确字符串/整数保存。输入控制包括空任务、重复和有序菜单、(p>b)、负 (p)、非正 (b)、实际 (C=2b)，并包含一个 (k) 为 20001 bits、6021 位十进制的二进制参数 round-trip。

九组枚举记录同时保存 original/new machine 数、调度计数、投影到 (<2b) 的数量和 original/transformed optimum。一个例子中 original optimum 为3、transformed optimum 为2；这正是不能把“正规形”有限实现误写成无条件保持 OPT 的证据。另一个完整前向例保存两组 ports、root pin、选中 port jobs、原/新载荷和投影选择器，足以对照一次实际构造，但不替代任意输入证明。

## 数学处置

本源可以支持“在列明的有限输入和精确枚举域内，程序完成投影、调度计数与超大参数 round-trip”的计算关系。它不支持一般 UM 到三态单位选择器的免费归约，不支持所有菜单或所有资源度的 OPT 保持，也不支持六人半覆盖结论。记录未提供可独立重编译的源程序正文；因此本页保存 JSON 并严格沿用其 `scope: finite exact audit, not general proof`。
