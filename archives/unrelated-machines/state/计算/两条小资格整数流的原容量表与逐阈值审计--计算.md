# 完整容量表及自足不等式

T<b时删small>T，只余至多两个资格；两件之和≤T给行容量2，否则容量1，unit禁用。这与C≤T调度精确等价。T≥b写T=ℓb+a、0≤a<b，令u为选中unit数，s_x/s_y为两small是否选中：

| 行情形 | 容量合同 |
|---|---|
| 无small | u≤ℓ |
| 仅p≤a | u≤ℓ，p独立容量1 |
| 仅p>a | u+s_x≤ℓ |
| p+q≤a | u≤ℓ，两small各独立容量1 |
| q≤a<p+q | u≤ℓ且u+s_x+s_y≤ℓ+1 |
| p≤a<q，或a<p且p+q≤b+a | u+s_y≤ℓ，p独立容量1 |
| a<p且p+q>b+a | u+s_x+s_y≤ℓ |

逐行真实负载≤T一定满足表；这是**完备性方向**，不是“所有过T状态都拒绝”。反向表允许轻微超载，但保证C≤T+b/2。除倒数第二行外，直接用数量和p,q<b可得C≤T。例如q≤a且两small均选时u≤ℓ−1，负载≤(ℓ−1)b+2a≤T。倒数第二行若q被选，u≤ℓ−1且p+q≤b+a，仍≤T；若q不选，唯一额外量为max(0,p−a)，由p≤q、p+q≤b+a得p−a≤(b−a)/2≤b/2。p≤a分支更为零。整数满流的一个覆盖匹配同时满足所有行表，故有共同真实σ及上述加性界；失败可排C≤T，但成功不保证OPT≤T。
