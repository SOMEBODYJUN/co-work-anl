# 共同原模型，两个不相同的API

两primary为8504B `normalized_dual_rail_half_slot_independent.py` 和21830B `normalized_dual_rail_three_halves.py`，均完整读、核SHA、原CLI各一次exit0，互不import。前者输入整数n和带0/1符号的显式clauses；后者输入显式不同int/string变量标签和`+/-`符号，有JSON接口。实际数学模型相同：每变量两台互异rail及一selector（两端时间1）；每真实occurrence一port，在自己的rail时间1/K（K为该符号实际出现总数），在自己clause的单台scalar机时间1/A_c。A_c≥1、实际arity≤2A_c−1；重复文字是不同job，K0无port，不除零。机器组互异，无预载/背景；空变量/clauses可有一个空dummy。

# 独立half-slot：每clause负载≤1

每job在两个原端各放一half-piece。每rail先排selector，再排ports，两连续half成一槽；clause也两half成一槽。每job恰邻两个不同槽，每槽至多邻两个job；对任意job集S数2|S|个半片，给|N(S)|≥|S|。迭代交错路匹配覆盖所有原job，槽所属机器就是同一实际σ。

若rail接selector，首槽已占，余ports数≤floor(K/2)，负载≤1+floor(K/2)/K≤3/2。未接selector的rail即使保留全部ports也≤1。clause接至多ceil(m_c/2)≤A_c ports，故负载≤1。这是ST半质量特殊情形，不把一般LP二倍界改成三半，也不需要源真假赋值、未知OPT或SAToracle。

独立程序250个seed558437随机输入，n0..6、至多9clauses、含A=2^257+5；另空输入、未用变量、K0/K1混合和一个非法arity拒绝。它只用`isinstance`等局部校验，不能继承规范API的12类非法拒绝，不能声称bool等全部拒绝。保完整实际job/两端、slots、job_to_slot、σ和逐机重算；随机250行摘要不含全部输入矩阵，不伪称已dump它们。

# 规范quarter-flow：只承诺全局≤3/2

对某变量有空rail，selector停空轨，ports全内留。两rail均非空且某K≥2，选一条这样的rail，每port作为单位供给，可进该rail容量floor(K/2)，或该clause容量floor(3A_c/2)。1/4留rail、3/4送clause的分数点可行，因为K/4≤floor(K/2)。若两rail恰K1/K1，给该变量一单位供给，向两occurrence的clauses各1/2；整数流选定哪条外送后才把selector放其rail。两类必须在**同一网络共享全部clause容量**。

每clause分数流量≤3m_c/4≤floor(3A_c/2)，故有全供给整数流。读出每port不拆分；选轨内留≤floor(K/2)，负载≤3/2，另一rail≤1，clause外送数≤floor(3A_c/2)给scalar负载≤3/2。这个API没有更强的clause≤1合同；本次锐例恰好clause都低于1不把测试值推广为API保证。容量A可巨大，但单位供给总数≤实际ports，增广次数按显式输入规模，不按A数值展开。

规范程序固定seed110723，实际12565个完整小模板+2000随机，748个小矩阵真OPT，另锐例全32768份实际σ；两部分oracle合计68288份真实分配。5个空/巨A/零degree边界、12类非法JSON拒绝；变量分类计数 empty_rail5470、heavy_rail16111、one_one5076。它显式拒bool/float变量及A，接受十进制整数字符串A；这些软件域差别不改变数学整数模板。

# 同一个10机15job锐例的两个真实输出

A均2，四clauses为(x+,x+,y+)、(x−,x−,y+)、(y−,z+,z+)、(y−,z−,z−)，每railK2。y真迫x同时真假，y假迫z同时真假，严格源无解。C≤1时selector真轨不能留正port，真ports全外送，必解码严格源；所以无C≤1。时间全为1或1/2，OPT≥3/2。两构造输出达到3/2：

| 构造 | 六rail负载 | 四scalar clause负载 |
|---|---|---|
| quarter-flow | (3/2,1,3/2,1,3/2,1) | (1/2,1/2,1/2,0) |
| half-slot | (3/2,1,3/2,1,3/2,1) | (1,0,1/2,0) |

独立half-slot原入口枚举全部2^15=32768实际σ，直方图13824份峰3/2、18944份峰2，并核全部8个源赋值均违约。规范另保正selectors/正ports全外送的真实σ：六rail全1、clauses(3/2,1/2,1,0)，也达3/2。这是绝对三半阈值锐；该例算法本身最优，不是近似比3/2锐性证明。
