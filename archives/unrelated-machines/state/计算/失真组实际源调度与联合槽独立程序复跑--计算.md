# 2. 从真实源调度构造共同LP见证

对非空给定源调度列表取均匀混合。d_h=(W_h−rT)_+。宏位置给a_bh；占宏home若d0走私有home零成本dummy槽；若d>0，把源调度实际出口的home体积e_hz按总e_h归一化y_hz。宏>T/2迫e_h>W_h−T/2≥d_h>0，故没有0/0。代码核同一a/y的home守恒及逐sink Σ b_hz d_h y_hz≤κT。

按每sink的**实际成本**c_hz=b_hz d_h降序排y区间，只把正交长连到单位槽；dummy为(None,h)，各home私有。与规范生产实现不同，独立代码用递归穷举给每宏选择一个正a home和一个正交槽，同时保证home/槽均不重复。它是有限审计的**指数packing oracle**，不把它的复杂度叫成算法定理中的整数流多项式。

占宏home按原任务编号送前缀到选sink，直至余量≤(r+δ)T。最后一件≤δT给总出口≤d；按上包络其真实sink成本≤token c_hz。代码逐sink核实际成本≤token，token≤原分数费用+一个最大c≤[κ+Bbar(1−r)]T。每home总量≤(1+r+δ)T。最后重新逐件累加全部宏和全部私有任务，验证输出负载不是只算虚拟量。
