# 2. 合同、槽与一般数学的边界

给机器行P（字典缺项为禁止端）、T≥0和每机配置分布y：每行权和一、非负、每配置不重复job、均为finite资格且实际负载≤T；每原job在全机配置的总覆盖质量恰一。先将**任何地方有零finite端**的job分配该零端并全局删除；从每个配置删除这些jobs，合并相同残余配置，保覆盖一。K约束用于删除后的正权配置，而不是要求原含零配置也≤K。

边际x从余下配置取出；每行按实际p非增、ID破平局，将x连续铺成区间，槽为单位区间。严格`max(lefts)<min(rights)`才邻接，微小正交长也保留，触端点不算边。正权配置≤K使总边际质量≤K，槽数≤K。E_i是每槽最大邻接时间的总和，任意覆盖任务的槽matching实际行负载≤E_i。

一般数学给K1的E≤T；K≥2的`E≤(2−K^(−(K−1)))T`，并对K2/3有锐界3T/2、11T/6。其证明用严格阈值前缀、整数类型多面体和行列式统一余量，见[既有严格槽定理](../定理/有界配置基数的严格槽余量与承诺搜索--定理.md)。两个程序只有有限fixture，不求一般y、不运行有理CONFIG LP，也不执行未知OPT承诺算法。

# 4. 独立重建与实际9例全覆盖枚举

独立`verify`先核原完整配置，再全局删除零job，合并残余配置并重算x。它重新生成每个真实interval、slot_count、包络，递归枚举每个剩余job到某个相邻**未用槽**的全部选择，检查每个完整覆盖matching的原机负载≤包络及一般ratio。没有枚举全部普通原调度（许多非槽调度不在这个图中），也不是多项式matching求解器。
