# 原代码、真实输入与执行次数

两primary为24350B规范 `normalized_gated_menu_welfare.py`（SHA31aeb2…）与10202B独立 `normalized_gated_menu_welfare_independent.py`（SHA523141…），逐份完整读后各启动一次原CLI并exit0。规范从seed20261018生成输入并向新payload排他写；独立程序实际读取其ROOT下**旧冻结192113B规范数据**，已按原SHA2b40…部署到保存原件树。它重放的是旧命名输入，不把它伪称本轮新规范输出；本次新规范payload恰与旧文件逐字节同，也另保留实际执行记录。

独立程序compile/exec同SHA规范源码为函数命名空间（`__name__`非main），替换期望函数并调用原舍入；不运行规范main或SciPy LP生成。它还在末尾用同一既存DATA路径启动一次规范CLI，实际exit2、stderr拒覆盖、原文件SHA不变。这是**第六次源CLI调用、仅走参数guard，无数学审计体**：本批5个主审计进程/5个审计体，另1拒覆盖进程，补充数学审计0。原独立程序未保存子进程独立stdout/stderr/秒数，本包不伪造这些文件，保存实际assert观察和源中argv。

独立payload的`code_sha256`指被测规范31aeb2，不是独立脚本自己的523141；后者由源manifest与执行记录绑定。全部源main/顶层行为据全文分清，不能把compile/exec函数定义算成规范主审计再次运行。

# 完整norm1菜单与四层真实原任务

组g=1,…,n非空、资源集非空；每组有限非空indexed states，每state非负有理p_gsu总和恰1。允许显式零、未用资源和重复state。原bundle彼此不交，v_g(B)=max_s Σ_{u∈B}p_gsu。平衡值β*为可选组H的min(|H|/n,min_g∈H v_g(B_g))的最大值，允许0。

机器是互异的根R、gate X_g、state私有M_gs和资源Q_u。原任务：pin仅R时间1；每组connector在R时间1/n、X_g时间1；selector在X_g及其全部M_gs时间1；每个**显式incidence**在M_gs时间p、Q_u时间1，包括零任务和全部未选states。两程序的菜单是长度m数组，全部条目都作为显式incidence，故实际I=S*m；canonical允许稀疏未列项但不据此造新任务，不能把密集数组的任务计数冒充所有稀疏编码。若S=state总数、I=incidence列数，机器/任务/边分别1+n+S+m、1+2n+I、1+3n+S+2I。

给平衡见证β，选中组connector→gate、selector→attaining state，选中state的实际bundle正incidence送唯一资源，其余所有incidence原地，未选组connector→R、selector→gate。根负载2−|H|/n，选中私有负载2−value，其它private和gate≤1，resource≤1，故峰≤2−β。反向任意C<2调度，根迫active组数≥n(2−C)；active gate已有connector unit，selector须进state，其实际外送质量≥2−C；resource unit在C<2时不能双占，得到真实不交bundle。因此
\[
OPT(P_{gate})=2-\beta^*.
\]
β0用全部connector在根的峰2基线，pin给OPT≥1。这一完整原矩阵不保原flat问题：两组单unit state共资源时flat OPT2而gated OPT3/2。不能把门控当保最优值的normal form。

# 有理LP与福利条件期望

显式LP是Σ_s z_gs=1、0≤x_gsu≤z_gs、Σ_gs x_gsu≤1/资源，零p的x0，最大化L=Σp x；W*≤L≤n。规范只用SciPy/HiGHS提供float primal/dual提案，再以`Fraction(...).limit_denominator(10^8)`逐式核primal非负/精确行、ub dual≤0、reduced costs≥0和原初/对偶目标相等。成功例有精确最优性证书；没有对任意合法输入的rationalization成功保证或fallback，不能称生产有理LP后端。

各组独立按z选state，再以x/z提出各资源，资源给最高正p组。只在z>0时除，state相关性在同组内保留。对资源u和高度t，q_g(t)=Σ_{s:p≥t}x_gsu且Σ_gq≤1，故1−∏(1−q_g)≥(1−1/e)Σq_g；有限高度积分给期望福利≥(1−1/e)L>5L/8（L>0）。逐组测试正z states、再逐已选state的coin，精确期望是候选加权平均，取最大不降；**条件化后Σq可能>1，之后只用精确期望公式，不重用初始容量不等式**。最终赢家bundle不交，再取各bundle attaining state只会增值。

均衡提取取top-k的最大min(k/n,r_(k))=βhat。由福利W/n≤2βhat−βhat²与W*≥n(β*)²，得到输出C≤1+sqrt(1−5(β*)²/8)。对β∈[0,1]，
\[
[(18-13\beta)/8]^2-[1-5\beta^2/8]=(209\beta^2-468\beta+260)/64\ge1/64,
\]
因为导数418β−468<0且β1取1/64。因此C≤(13/8)(2−β*)=(13/8)OPT。sqrt只作分析，算法有理。一般13/8证明依赖显式norm1和原任务桥；本程序1025点grid只是有限算术，不替代导数证明。
