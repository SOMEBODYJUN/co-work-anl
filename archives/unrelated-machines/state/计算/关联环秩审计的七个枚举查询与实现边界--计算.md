# 五个阈值回归输入

原精确枚举器逐个选择每件任务的机器，以 Fraction 累加原处理时间，遇到第一份峰值不超过 T 的完整分配即返回。下面五个矩阵保留了多端任务、零端、空任务和不可行端点；有限端以“机器:时间”表示，未列端不可用。

| 输入 | 机器数与各任务菜单 | 阈值及结果 |
| --- | --- | --- |
| 森林 | 4；{0:1,1:2,2:1}、{1:1,3:3}、{2:1} | T=2、1均可行 |
| 原拓扑四环 | 2；{0:1,1:2}、{0:2,1:1} | T=1可行，见证(0,1)；T=0不可行 |
| 空任务 | 1；无任务 | T=0，空分配 |
| 零端 | 2；{0:0,1:3}、{1:0} | T=0可行 |
| 同机超载 | 2；{0:2}、{0:2} | T=2不可行 |

这是七个矩阵/阈值查询。四环例在T=1剪去超过T的端后只剩两条对角边，因而没有测试残余单环。

[一般关联反馈算法](../算法/有限反馈边与安全叶消元的精确调度--算法.md)已证明反馈边分支、安全叶消元及单环恢复；此枚举器不计算反馈秩、不实现这些步骤。它可为后续实现提供小输入oracle，不能据其通过宣称生产算法已实现。原程序和完整输出见[证据](../../tools/evidence/incidence-rank-primary/source-manifest.json)。
