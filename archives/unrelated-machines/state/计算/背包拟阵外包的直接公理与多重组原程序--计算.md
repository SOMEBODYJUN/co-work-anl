# 一般分类、命中集与锐值

相关26982B canonical全篇及10785B两段review已完整读。§7给全k,p≥1的解析结论；旧review增补虽然记录whole825245…，明确**只审§7**，不是对后来§8配置转移或§9指数外包的全审。本次whole canonical bbbf…全文阅读也不倒填旧审查覆盖。

每个合格拟阵的small全集K独立且h非loop。若整个E独立则free；否则任何回路都含h。若有两个不同回路，回路消去会在K内产生回路，矛盾；也可由augmentation将C1去一元素f扩成E\{f}，它却含C2，得到相同矛盾。因此唯一回路为{h}∪A，所有独立集恰为不包含整个回路的集合。反向任意非空A由该回路上的U_(|A|,|A|+1)与其余free直和实现，分类完整。

忽略free拟阵，对其A1,…,Ap'令最小命中集大小τ（全free时τ=0）。含h的共同独立集{h}∪S要求K\S命中每个A，故最大含h重量2−τ/k；不含h最大1，而τ≤k，所以给定组最坏重量也是2−τ/k。任选每个A一点得τ≤min(p,k)。取min(p,k)个不同二元回路{h,s_i}、其余free，恰强迫舍这些不同small，达到
\[
\min_{M_1,\ldots,M_p:I1\subseteq\cap I(M_a)}\max_{S\in\cap I(M_a)}w(S)
=\max\{1,2-p/k\}.
\]

这个一般证明不把最小命中集当免费多项式oracle。锐值可由partition/可线性表示拟阵达到，但下界不要求拟阵种类。p≥k时存在精确表示I1，少于k不行；并非任意p≥k组都精确。固定0<ε<1时存在最坏负载≤2−ε的这种外包当且仅当p≥ceil(εk)。
