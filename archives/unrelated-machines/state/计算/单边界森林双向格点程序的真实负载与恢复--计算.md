# 1. 输入和返回合同

6949B downward SHA `e3854ca048d40fe3b8a4eb8e3bd1e74b1f1ae5b212b154d185055fa27bf761c3`、11820B upward SHA `95d52e10267c1c6b98e86276f5b30f3c3d63c5e947c2b0fb527de95d6fbe355c`均全文读、未改，本轮各一次原CLI。任务为显式字典{机器:非负有理时间}，每件一/两端，平行任务身份保留；合并平行包后的简单机器图为森林。根r目标无容量限制，内部机器目标T≥0，0<η≤1为证明合同。

若有内部负载≤T的原分配ρ，输出的同一个实际τ须满足内部≤(1+η)T、根真实负载b≤L_r(ρ)。None只保证不存在精确内部T可行分配；**成功可以发生在原T不可行时**，且根b可以>T。两程序不能用作双向T可行性判定。

downward接收显式parent森林、根固定0，检查双端属于parent关系；它不是完整的非法输入验证器，正确父关系、全活跃顶点及隔离为调用者前提。upward的API压缩活跃机器索引，DSU拒绝简单环、合并平行bundle、处理不连通分量；同样不核“外部任务不可用内部机器”，因为它只收到局部jobs。不能把稀疏局部字典自动当已完成外部隔离证明。

# 2. Local floor：保留父端真实消息

自底向上，内部v已有真实fixed=私人任务量+孩子真实消息。fixed>T拒绝。父包q件时δ_v=ηT/q、cap=floor((T−fixed)/δ_v)，每件child端重量floor(p_vj/δ_v)。逐项分层0/1 DP在容量内选child子集，最小化送parent的**真实**p_uj之和，回溯每件端身份；零重量也只用一次。原源码每状态复制decisions tuple，没有把它伪称另一backpointer实现版本。

若ρ内部T可行，归纳孩子消息不大于ρ的对应父机贡献，故fixed≤T，ρ选child的子集在floor容量内；DP最优给向父消息不增。实际child负载≤fixed+δ_v·cap+qδ_v≤(1+η)T。后代消息已经是真实量，不按深度叠加圆整误差。

无父包直接传0；T0时parent包凡child时间0留child，其余送parent，固定正内部负载照常拒绝，根只算真实负载。`eliminate_all`另逐个消叶，将局部实际分配封装成parent上的fixed singleton，保全部原任务展开字典。恢复只替换同一根负载，多个同T/η消元误差按max组合；不把双边界相关菜单当这种普通singleton。

# 3. Global ceil：内部整数目标和根Fraction目标分开

upward令δ=ηT/n，K=floor(n(1+1/η))=floor(n/η)+n；逐端q_ij=ceil(p_ij/δ)。含r的分量以r为根，其余分量另起根。父包DP给child容量，最小化父负担：父不是r时用该父的整数q，父是r时用原Fraction p，不能先求内部真实最优再ceil总和。保存层backpointer恢复全部原jobs。

原内部T分配逐项ceil总量≤K，故一定属于格点可行域；DP精确最小根真实目标给b≤b*(T)。任返回内部真实负载≤δK≤(1+η)T。其它分量的内部根也必须过K容量检查。T0时优先非根零端，否则有根端便给根；仅根有正时间任务可合法返回正b，不应拒绝。

活跃索引压缩只保根及实际端点，避免按巨大标签分配数组。本轮2^1000机器数/两活跃标签的测试是**稀疏API索引测试**，不是物化该大小显式矩阵。整数容量及运算数依赖数值1/η，不声称对η二进制位长统一多项式。一般归纳/消元合同已有[正式审查](../审查/单边界森林与极小超载星双源审查--审查.md)，本页不重登记新定理。
