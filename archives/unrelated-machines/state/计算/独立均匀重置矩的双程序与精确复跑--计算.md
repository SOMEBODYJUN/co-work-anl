# 完整原程序与输入

主源 `26b8c482db554dac0b69`（3884B）及独立源 `ab1d41cdad23123c64a7`（7356B）均全文实读。原件和旧冻结结果见[manifest](../../tools/evidence/uniform-presence-reset/manifest.json)。两程序只用标准库，无外部输入文件、无随机seed、浮点或容差，默认循环本身就是真实输入；不是接受任意实例的CLI/API。没有修改原代码，两个原入口分别在新空cwd执行**各一次**，stdout/stderr及真实命令、源码hash、Python和返回码完整保存。

共同模型：整数q≥2，m=2q、n=2q²，每job在每机时间1/q，原真实最优分布均匀遍历每机恰q任务的平衡分配，OPT=T1。吸收任意标签包C大小c，不条件化旧分布，删一机和C；剩余任务旧非删机选择不动，旧在删机者各自独立均匀抽K=2q−1个后备机。输出是此随机kernel的确定精确一二阶矩，不是抽一个近似调度。

# 公式、全部真/假条件与已证阈值

主程序由旧二点式出发：同任务同端1/m、异端0；不同任务同机$(q-1)/(m(n-1))$、异机$q/(m(n-1))$，用概率转移矩逐对运输。独立程序先由后验推导：给定新a在l，旧a在l概率K/m、旧a在删机概率1/m，重构不同任务条件概率

\[
\alpha=\frac1K-\frac{q-1}{q(n-1)},\qquad
\beta=\frac1K+\frac1{2q(n-1)},\qquad \alpha+(K-1)\beta=1.
\]

这里独立代码alpha/beta对应主代码及canonical的beta/gamma，不能只按变量名比数。新边际1/K，不同任务同机/异机joint为alpha/K、beta/K。同任务必须categorical：对角1/K、异选择0。主程序明确对同任务块修正；仅算无修正RYRᵀ会错。不同任务的后备coins独立，不允许给同一任务多个literal另抽独立coin。

令r=n−c≥1，基本均值μ=r/K、真同机$A=1+(r-1)\alpha$、真异机$B=(r-1)\beta$；假同机为B，假异机$[A+(K-2)B]/(K-1)$。有

\[
A-B=1-\frac{(r-1)K}{2q(n-1)}>0,
\]

因此基本与全部真/假容量（任务数≤q，等价本均匀族前缀）同时成立当且仅当A≤q。D=qK(n−1)时

\[
A(q+1)-q=\frac{(q-2)q(2q+1)+2}{D}>0,\quad
q-A(q+2)=\frac{q^2+4q-3}{D}>0.
\]

alpha>0使A随c严格递减，所以全称整数阈值为q+2；c=n无残余literal，零维通过。q1/K1另分支阈值1，假literal概率0，不套K−1分母。完整一般证明在[current第9节](../../tools/evidence/uniform-presence-reset/comparisons/symmetric_moment_reset_and_single_machine_threshold.md)，[后续review第9节](../../tools/evidence/uniform-presence-reset/comparisons/symmetric_moment_reset_review.md)实际核最终wholeSHA `73f4e8ac7b1a01b85b854b639eee4b553ee6f50fc40bc72f0f06445fec90e739`，并强调A−B中的K因子不能漏。

已有《经典基线、调和调度与残余吞吐有限审查》第7节仅凭JSON把q+2记作候选；不能把那种有限证据措辞覆盖后来current的全称代数证明。[对称重置与双见证查询双源审查](../审查/对称重置与双见证查询双源审查--审查.md)已按已证限定阈值整理。此处区分证明与程序，不改旧共享正文或把有限成功当普遍证明。

# 运输规则与调度目标的边界

即使c=q+2矩容量通过，也有真实正概率坏态负载2：把吸收包放在旧删机i及另一机k之外（$(m-2)q-(q+2)=(2q+1)(q-2)\ge0$），令旧i/k各保q jobs，再让i的q jobs都抽到k，概率K^(−q)>0。矩通过没有给每态负载1的schedule。固定后备RYRᵀ的2q门槛、独立均匀q+2、仅保边际允许重耦合的q，是三种不同合同。

也不能去掉m=2q：[比较review](../../tools/evidence/uniform-presence-reset/comparisons/symmetric_moment_reset_review.md)另以q2/m8给同机条件概率13/140，c4条件计数283/140>2、c5为27/14<2，最小吸收负载5/2；这是范围攻击，不是本双程序覆盖的一般m定理。没有通用矩层级间隙、一般重置/迭代算法或UM近二保证。

两个代码源均integrated：全代码/参数/依赖/原输出和一次新运行保存，符号阈值、有限检查与实际调度分别说明。关系为既有q+2对象的两路实现与有限回归；对角修正和后验推导共同支持同一kernel，不能据文件名把本轮知情复跑称盲审。阶段二关系判断留此，未重建阶段三图；没有六人SPE关系。
