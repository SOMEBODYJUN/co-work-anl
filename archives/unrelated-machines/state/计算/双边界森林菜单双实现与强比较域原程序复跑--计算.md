# 1. 两端必须由同一真实分配产生

规范13445B代码SHA `8346c844235046a2f0b82fba3ca9de2dbd956615934fcea3a786226f19b37d28`，独立16466B代码SHA `b17140437411d4bd332dea2a4736785b55fca7323fd6905d53c71bd1774a2aa0`，均全文读且未改。输入jobs逐件含一/两非负有理端点、不同边界a/b、T≥0、证明合同0<η≤1；合并平行包后simple支撑须森林。内部机器是所有活跃端中除a/b者；稀疏API不核外部任务隔离，隔离须由调用者另证。

比较域为所有真实ρ，其内部负载≤T、L_b(ρ)≤T，**a完全无容量限制**。菜单每项τ存原任务assignment及真实(α,β)=(L_a,L_b)。对每个比较ρ，须有**同一项**满足α≤L_a(ρ)、β≤(1+η)L_b(ρ)，且内部≤(1+η)T。L_b(ρ)=0时β必须恰0。菜单空可证明比较域空，非空可仅是放大后可行；不能拆成分别最小的两端数或把菜单当普通两端任务。

# 2. 规范ceil与独立local-floor的完整机制

两者先生成预算0和正预算C：p_min为b端最小正时间，若p_min≤T，从它起每次乘1+ε，直到首次≥T；ε=η/3（规范API对更大的η取min(η/3,1/3)）。若比较ρ的b负载x>0，首个C≥x满足C≤(1+ε)x；x0走0预算。最终b输出≤(1+ε)C≤(1+ε)²x≤(1+η)x。

规范实现以δ_internal=εT/n、K=n+floor(n/ε)，逐内部端ceil(p/δ)，b正预算用δ_b=εC/n的不同尺度；a始终原Fraction、无限容。b预算0时正端权1/零端0、容量0。对每个预算，逐树包分层0/1 DP最小化父端负担：父为a时真实p，否则该父自身整数q，不跨机混单位；按backpointer还原全部任务。每台非a容量检查含孤立分量根。`verify=True`额外全分配穷举该格点模型，仅供有限审计，生产复杂度不能含这个指数步骤。

独立实现不调用规范核心：每非a节点先汇总私人任务和孩子**真实**消息fixed；本节点cap为T或b的C，超cap即拒绝。当前父包q件取step=ε cap/q、容量floor((cap−fixed)/step)，用floor本节点时间的逐项背包最大化留child所节省的真实parent时间，保存chosen原job IDs。只对当前父包付ε cap，不把后代消息再次圆整；cap0只保本节点零时间项。按归纳得到父端一侧支配，内部≤(1+ε)T、b≤(1+ε)C。两实现可有不同菜单，但必须各自满足同一强比较域。

T0/空任务直接或按零容量处理，正a私人任务可合法保留，如a负载7、b0；不能因a>T拒绝。DSU/独立遍历拒simple环，平行任务逐件保留。预算数受输入位长和数值1/η控制，巨大标签只压缩活跃端，不能说物化2^1000机器矩阵。
