# 菱形矩阵的实际任务证书

[压缩双向任务桥](../定理/有向需求与调度的压缩双向任务桥--定理.md)对任意合法需求DAG证明OPT=2−b*。以下固定输入保留机器和原任务身份：根0，边(0,1),(0,2),(1,3),(2,3)，需求(2,1,1,0)。四机器为root/a/b/shared terminal；五任务依次是根unit、home0两枚token、home1与home2各一枚token。

\[
P=\begin{pmatrix}
1&1/2&1/2&\infty&\infty\\
\infty&1&1&1&\infty\\
\infty&1&1&\infty&1\\
\infty&\infty&\infty&1&1
\end{pmatrix}.
\]

根同时保留两个孩子时，两正需求孩子不能共享唯一终端，至少一个正需求叶使评分0。只保留一条根到终端的路径，根出度/需求=1/2，故b*=1/2。树(0,2),(2,3)达到它；完整assignment=[0,2,0,1,3]，负载=[3/2,1,1,1]，由桥得到真实OPT=3/2。实际输入和证书见[原件](../../tools/evidence/rooted-token-next/source-manifest.json)。

# 两种有限oracle

规范oracle枚举环境边子集，用独立的树评分过滤，保最佳树；只对最佳树做一次树到调度恢复，再枚举全部实际任务分配、逐一解码峰<2者。它记录有限Γ，并在τ=b*一处核缩放阈值。

独立oracle为每个非根选None或一个父指针，要求被选点的父亲也被选。DAG中父链必止于唯一root，故枚举恰为根树。它对每棵树独立裁枝并重算负载，另对每个τ∈Γ检查b*_(ceil(τk))=1当且仅当τ≤b*，以及旧评分≥τ乘新评分。两者均不调用假设中的一般UM算法。

规范固定族有1807输入、54936实际分配及3675个峰<2解码；独立族是75个自然序小DAG、需求取{1,d,d+1,2^127+17}的6807输入、374250实际分配及18645阈值比较。它们是不同输入域。规范构造只造min(k,outdegree)枚token及至多一件filler，大需求按二进制分母处理；不按k展开。

接口允许任意合法根编号，有限阈值生成必须传入同一root；根2的边界Γ为[1/2,1]。Python接口的edges需可哈希二元组，JSON数组对须先转tuple。生成的jobs、D/k及调度必须来自同一构造，不是任意外来jobs的模型关联验证器。完整代码、有限输出和输入证书均在上述证据包，普遍恢复和位长由任务桥定理承担。
