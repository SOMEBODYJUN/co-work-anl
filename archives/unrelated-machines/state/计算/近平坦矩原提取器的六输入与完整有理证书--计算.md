# 条件提取机制与准确保证

由M1选有理单项式独立基和Gram G，构造 A_e=G^−1H_e、D_e=A_e−A_e²，核G自伴/positive contraction、每任务ΣA=I、每机ΣpA≤TI。令 R=rankM1、n任务数、d端数、δ=ΣtrD_e，0<η≤1。非空输入的充分条件为
\[
\delta\le\min\{1/(64ndR),\eta/16\}.
\]

通过时K初I，逐任务按原端索引取最大精确G-HS平方 ‖A_eK‖²，平局最小端索引，左乘更新K。每前缀实际用PSD检查 ‖K²−K‖≤nδ、正分数与HS²≥1/4；最终ρ=KK†/h同一迹一密度，核selected loss≤3δ_e和所有真实原负载≤(1+η)T。完整证明的承重点是共同矩给交换子界、近幂等排除塌缩，再把每端线性loss与同一ρ代回所有机器容量；不是把ρ当实际调度分布。完整主稿及review已在BN按同SHA全读，本批核字节准确复用，见[资源](../../tools/evidence/um-normalized-rails-and-gates-primary/README.md)。

剪枝p≤T合同还给更强(1+3δ)T；本API可接未剪枝合法矩，其一般(1+η)T证明不能偷偷使用p≤T。六个测试本身均在剪枝范围。NF不通过只拒绝证书，不推出OPT>T。n=0在核心直接返回空分配，但默认六fixture没有新测空任务；T=0核心仍先核NF，可拒绝大δ零矩。原模型外层逐任务选零端的数学预处理不是这个核心已实现的绕过分支。
