## 1. 输入模型与使用的整数性定理

令玩家集合为非空有限集 `P`，资源集合为有限集 `R`。每个资源 `j` 有有限非负有理公共价值 `v_j`，以及归一化、单调、整数值次模秩函数 `f_j:2^P -> Z_{>=0}`，以 value oracle 给出。写

`Q_j = {a in R_{>=0}^P : a(S) <= f_j(S) for every S subset P}`，

`B_j = {a in Q_j : a(P)=f_j(P)}`。

论文的整数基是 `B_j` 中的整数向量；assignment LP 使用其凸包，即上述实数基多面体。输入是有理分数基 `x_j in B_j`，并有每人 `U_i := sum_j v_j x_j(i) >= T`。输出仍是原资源的整数基向量，允许原 polymatroid 的整数重数；没有擅自把它改成每资源只给一人的模型。

使用的标准整数性定理为：对同一有限底集 `E` 上两个归一化、单调、整数值次模函数 `F,G`，多面体

`{z in R_{>=0}^E : z(S)<=F(S), z(S)<=G(S) for all S subset E}`

是整数多面体；其最大总重数可由 polymatroid intersection 算法在秩 oracle 与数值编码的多项式时间内求出。这里不对一般三个 polymatroid 的交声称整数性。以下逐项证明本构造的 `F,G` 确实满足这一定理的前提，且给出饱和目标的分数见证。整数性不是由“槽已排序”推出。

## 2. Theorem 21 的严格证明

### 2.1 有序质量槽和分数见证

将资源按 `v_1 >= ... >= v_n >= 0` 排序。对每位玩家 `i` 定义

`a_{i,0}=0, a_{i,j}=sum_{h<=j} x_h(i), X_i=a_{i,n}, q_i=floor(X_i)`。

把资源 `j` 的分数质量视为区间 `[a_{i,j-1},a_{i,j})`。只保留完整单位槽 `I_{i,k}=[k-1,k)`，`1<=k<=q_i`。对每个正交长建立边 `e=(j,i,k)`，并令

`t_e = length([a_{i,j-1},a_{i,j}) intersect I_{i,k}) > 0`。

完整槽均满足 `sum_{e incident (i,k)} t_e=1`。对每项资源、玩家，`sum_k t_{j,i,k}<=x_j(i)`；舍去的只是该玩家最后不足一单位的质量，可能涉及多个资源，不能假称它总是最后一个资源的一段。

### 2.2 左右两个秩函数都为整数次模函数

对边集 `S`，令 `pi_j(S)={i : exists k, (j,i,k) in S}`。定义

`F(S)=sum_j f_j(pi_j(S))`。

它归一化、单调且整数值。对任意 `A,B subset E`，有 `pi_j(A union B)=pi_j(A) union pi_j(B)`、`pi_j(A intersect B) subset pi_j(A) intersect pi_j(B)`。因此由 `f_j` 的次模性和单调性，

`f_j(pi_j(A))+f_j(pi_j(B)) >= f_j(pi_j(A union B))+f_j(pi_j(A intersect B))`。

求和即得 `F` 次模。这一步也解释了同一资源、玩家连往多个槽的平行副本为何合法。

令右端槽集合为 `D`。定义

`G(S)=sum_{b in D: S intersect delta(b) nonempty} 1`。

这是右端邻点的整数 coverage 秩函数，归一化、单调、次模。它的多面体恰好是每槽总重数至多一的约束：取 `S=delta(b)` 得到槽上界，反方向对任意边集逐槽求和即可。这里按不同右端点求和，不能按每一条边重复加入同一个槽容量。

向量 `t` 在两个多面体中：右侧由逐槽饱和成立；左侧对任意 `S`，

`t(S) <= sum_j sum_{i in pi_j(S)} x_j(i) <= sum_j f_j(pi_j(S))=F(S)`。

故最大交重数至少为 `Q=sum_i q_i`，同时右端总容量给出上界 `Q`。由两 polymatroid 交整数性，可求整数解 `z` 达到 `Q`，于是每个完整槽都被恰好填满。

### 2.3 投回原资源并计算价值损失

令 `y_j(i)=sum_k z_{j,i,k}`。它是非负整数。对 `A subset P`，取资源 `j` 且玩家在 `A` 内的所有边，左秩约束给出 `y_j(A)<=f_j(A)`，所以 `y_j in Q_j`。它可能尚未是基；这对 Santa Claus 无害。利用 polymatroid augmentation，将每个 `y_j` 增广到原 `B_j` 的整数基。所有价值非负，故任一玩家的值都不会下降。基完成是在原资源上做的，不增添新的正价值资源。

现定义非增阶梯函数 `w_i(t)`：在 `[a_{i,j-1},a_{i,j})` 上取值 `v_j`，在 `t>=X_i` 上取零（零长度区间略去）。任一被整数匹配给槽 `k` 的资源，其区间与 `[k-1,k)` 有正长度交，所以其价值至少为右连续值 `w_i(k)`。因此基完成前的整数价值满足

`sum_j v_j y_j(i) >= sum_{k=1}^{q_i} w_i(k) >= integral_1^{q_i+1} w_i(t)dt = integral_1^infinity w_i(t)dt`。

第二个不等式由 `w_i` 非增且每段积分长度为一；最后一个等式由 `q_i+1>X_i`（整数 `X_i` 时也成立，零尾段不变）给出。于是

`U_i - sum_j v_j y_j(i) <= integral_0^1 w_i(t)dt <= max_j v_j`。

故每人值至少 `T-max_j v_j`。空资源、零秩或全零值时以最大值零约定处理，输出任意原整数基即可。

### 2.4 压缩槽保证关于编码长度的多项式时间

上述展开槽用于证明，不能在二进制巨大秩上逐单位建立所有槽。对每位玩家，把含有非整数内部断点 `a_{i,j}` 的完整槽各自保留；这样的“混合槽”至多 `n-1` 个。其余完整槽均完全落在单一资源区间内；对同一资源 `j` 的这些纯槽，合并成一个右端点，容量为槽数 `c_{i,j}`，且只连资源 `j`。

每个资源区间至多碰到其两端的两个混合槽，外加一个纯槽组，因此边和右端点总数均为 `O(|P||R|)`。压缩右秩改为 `G(S)=sum_{b: S intersect delta(b) nonempty} c_b`；仍是整数 coverage 次模函数。分数见证在混合槽上用原交长，在纯槽组上用整数 `c_{i,j}`。整数解填满每组后可在证明中概念性展开；纯组只有单一资源邻居，值完全相同，无须实际枚举槽。所有容量以二进制写出，端点、交长和容量的位长关于输入有理数和秩值编码长度为多项式。左侧 `F` 的 oracle 只需原 `f_j` 的多项式次查询。

基完成也不能逐单位循环。对当前独立向量 `a`，按每个坐标 `i` 依次增加其最大合法量 `min_{S containing i}(f_j(S)-a(S))`，可用强制包含 `i` 的次模最小化求出。以后只增加其他坐标，已饱和坐标不会重新获得增广余量。处理完所有坐标时，每个坐标都属于某个紧集合；由次模性及 `a` 的可加性，紧集合对并封闭，故其并 `P` 也紧，总重数即等于原秩。整数起点与整数秩给整数增量；这个紧集合论证也适用于有理起点的分数补基。只需每资源至多 `|P|` 次次模最小化，输出为原模型的二进制整数基向量。

## 3. 加最大作业与减最大资源之间的完整对偶桥

这一步不限两值，不调用 Theorem 3 的近似等价。令底集为同一个有限 `E`，对每个原秩 `f_j` 取 `K_j=f_j(E)` 和常向量 `z_j=K_j 1_E`。定义

`g_j(S)=K_j |S| + f_j(E\S)-K_j`。

该函数归一化、整数值、次模。增加元素 `i` 的边际为 `K_j-f_j(i | E\(S+i))>=0`，因为任一边际不超过 `f_j({i})<=K_j`，故它单调。对任一实数或整数原基 `a_j`，`b_j=z_j-a_j` 非负，并且

`b_j(S)=z_j(S)-a_j(S)<=z_j(S)+f_j(E\S)-K_j=g_j(S)`，

`b_j(E)=z_j(E)-K_j=g_j(E)`。

反过来，对偶基 `b_j` 有 `b_j(i)<=g_j({i})=f_j(E-i)<=K_j`，而利用补集约束可得 `z_j-b_j` 是原基。对同一 `z_j` 再对偶一次恰还原 `f_j`。所以该补向量映射双向保持分数基、整数基和所有原项身份。

### 3.1 Theorem 21 推出 job-matroid 的加最大项舍入

给原 job-matroid 分数基 `x_j`，公共非负尺寸 `p_j`，每机 `L_i=sum_j p_j x_j(i)<=T`。令 `C=sum_j p_j K_j`。对偶资源实例的分数基 `z_j-x_j` 给每人价值 `C-L_i>=C-T`，又总是非负。对其以阈值 `tau=max(0,C-T)` 使用 Theorem 21，得对偶整数基 `b_j`，每人值至少 `tau-p_max`。补回原作业整数基 `a_j=z_j-b_j` 后，每机

`sum_j p_j a_j(i) = C-sum_j p_j b_j(i) <= C-tau+p_max <= T+p_max`。

这是对每个已给可行见证的舍入合同，不需要 `T` 是最优或最小阈值。秩为零的项可直接去掉，基为零；剩余任一项 `j` 在任何整数基中至少有一个单位，故 `p_j<=OPT`。求可行 assignment LP 的最小阈值 `T_LP<=OPT` 后使用舍入，得到峰值至多 `T_LP+p_max<=2OPT`。若没有正秩正尺寸项则任意基给零峰。这里的 LP 求解按原论文的秩 value-oracle/次模分离合同，不能把“已给见证舍入器”单独说成已实现了完整求解软件。

### 3.2 job-matroid 舍入反推 Theorem 21

给原资源分数基 `x_j`，每人值至少 `T`，令 `C=sum_j v_jK_j`。因每项 `x_j(i)<=K_j`，有 `C>=T`。其对偶 job 分数基 `z_j-x_j` 的每机负载至多 `C-T`。使用加最大项舍入，得对偶整数基、峰值至多 `C-T+v_max`；补回原基后，每人值至少 `T-v_max`。因此两个已给见证舍入合同在这一显式桥下完整等价。

关键前提是所有项尺寸/价值为各玩家/机器共同的非负数，且每项选择整数 polymatroid 的一个基。普通 unrelated 矩阵的 `p_ij` 依机器而变时，`C` 不再统一，本桥没有推出一般 unrelated-machine 结果。Santa 独立向量可补基是非负 max-min 特有的安全步骤；makespan 端不能任意补独立向量，须先在对偶资源端完成基，再取补向量。

## 4. Lemma 22 中舍入真正支付的一步

若给定目标值 `V` 和 `alpha>=2`，已有同一原资源实例的重轻分解：重资源价值至少 `V/(2alpha)`，已合法整数地覆盖某些玩家；未被重资源覆盖的玩家 `U` 有轻资源分数见证，其值至少 `V/alpha`；轻资源价值都小于 `V/(2alpha)`。若初始重向量只是独立向量，先在原重资源中补成整数基，非负价值保证覆盖不减，再固定这份重分配。则只舍入轻资源即可使所有玩家最终值至少 `V/(2alpha)`。

严格地，对 `U` 限制各轻资源的 polymatroid。给定轻分数向量可能只是该限制 polymatroid 的独立向量；先在限制底集上补成分数基，非负性使 `U` 的值不降。Theorem 21 给 `U` 的整数独立/基向量，值至少 `V/alpha-max_{j in L}v_j>=V/(2alpha)`。将这些向量在原轻资源 polymatroid 中补成基，不减少 `U` 的收益；重资源分配保持原状，被重资源覆盖者已有单项值至少 `V/(2alpha)`。重资源与轻资源是不相交的原项，故不存在重复使用。不能直接声称所有玩家在重轻中间解都有 `V/alpha`，也不能把规范子程序里的无限重价值送入有限 `v_max` 的舍入定理。

这一贡献在给出上述共同中间见证后完成一般 `2alpha` 提升的最后一步。它没有支付构造规范 `infinity/1` 子程序、其多项式搜索、拒绝证书和两值 `alpha` 分支。取原局部搜索后端 `alpha=4+epsilon/2` 才得到一般 `8+epsilon`；两值 `4+epsilon` 使用 Lemma 22 的另一分支，不能由减最大项一式独自推出。

## 5. v1 原图证明中的精确失败位置与最小修正建议

### 5.1 右秩公式按边重复计容量

PDF 页 28、印刷页 27，Theorem 21 proof 将右秩印为 `f2(S)=sum_{e=(w,u) in S}d(u)`；PDF 页 30、印刷页 29 的 Theorem 23 proof 重复同式。该式是边上的 modular 函数，允许同一右端的两条边各用 `d(u)`，不编码总度上界。若保留此构造，至少须改为 `sum_{u:delta(u) intersect S nonempty}d(u)`。但只改这一处仍不能修复下一处的分数可行性。

### 5.2 只有相邻索引边不能传送任意累计余量

取十位玩家，四项价值均为一的资源；每项 polymatroid 都是十元素、秩三的均匀 matroid `U_{3,10}`。给每个 `j=1,2,3,4`、每人 `i` 都取 `x_j(i)=3/10`，这是原分数基，且每人值 `6/5`。再添加价值零、秩零的第五项，满足论文 `v_n=0` 的归一化。

原 proof 的递推 `d(u_ij)=floor(R_{j-1}+x_j(i))`、`R_j={R_{j-1}+x_j(i)}` 给出每人的容量向量 `(0,0,0,1,0)`。原边仅有 `w_j -> u_ij` 及 `w_j -> u_i,j+1`；因此十个正容量右端 `u_i4` 仅能从资源三和四接入。这两项左侧总秩只有六，无法饱和右侧总需求十。故“原分数解变成使所有右度紧的交多面体分数解”的断言在这个合法输入上失败。更局部地，第一项的 `3/10` 根本不能穿越容量为零的第二槽抵达第四槽。

Theorem 23 的逆向相邻图也有同类问题。在同一四项均匀拟阵分数基、尺寸均为一、末项零秩零尺寸的例子上，向上取整的容量是 `(1,0,0,1,0)`；第三项只连 `u_i3,u_i2`，两者容量均零，因此无法在左侧保留第三项的秩三基。故它声称的左侧全基分数见证也未构成。两个舍入结论仍由本页 §§2--3 得到。
