# 单正小端级联的完整查询立方体与可加费用

读取目的：检验近二困难性归约中“同一标签支付一次、供多个查询复用”的实际任务机制。本页给一个允许多级级联的精确反例边界；不提供一般 UM 算法或近二困难性。它比裸单位占位胶合多保留了查询**任务身份**，但使用更强的单正小端与两严格模式假设。

## 1. 精确身份、对象与量词

**ID / Version：`UM-SINGLE-HOME-CASCADE-QUERY-SEPARATION-v2`。** v1 的冻结陈述只要求各单查询；v2 改为同一批不交支持同时实现所有子集，另给剩余查询质量界。旧冻结字节保留，不把加强悄悄写入 v1。

**Objects / Domain / Definitions。** 显式有限 UM 矩阵，机器集 M 非空，全部时间为二进制非负有理数或∞。任务分为不交的 U、J：

- 每枚 u∈U 的全部有限端时间为 1，至少有一端，资格数不限。
- 每枚 j∈J 有唯一正小端 h(j)，时间 a_j∈(0,1)；其他有限端只能是 0 或 1，端数不限。
- 输入给同一 P 的两个完整实际调度 σ₀、σ₁，均满足最大负载≤1。σ₀ 把全部 J 留在 h(j)。
- 输入给非空 Q⊆J；σ₁ 把全部 Q 放在时间为 1 的端。

令 D={j∈J:p_{σ₁(j),j}=1}，Z={j∈J:p_{σ₁(j),j}=0}。于是 Q⊆D，Q∩Z=∅，J\(D∪Z) 在 σ₁ 必留 home。对 S⊆Q 定义

\[
 \delta(S)=\max_{i\in M}\sum_{q\in Q\setminus S:h(q)=i}a_q,
 \qquad \delta=\delta(\varnothing)\in(0,1].                 \tag{1}
\]

费用参数是在 D\Q 上任意固定的非负有理权 w_j；W=Σ_{j∈D\Q}w_j。本页只计非查询 J 任务实际走 unit 端的这些权，不计 U 重排、零端移动或其它对象。

**Exact Statement / Quantifiers / Conclusion。** 对每个满足上述全部假设的输入，可在确定性总位多项式时间构造两两不交的 A_q⊆D\Q（q∈Q），以及给定 S⊆Q 后输出完整调度 τ_S 的多项式算法，使所有 S 同时满足：

1. J 中实际走 unit 端的任务恰为 S∪A(S)，其中 A(S)=⋃_{q∈S}A_q；它们使用各自在 σ₁ 中的原 unit 端。
2. Z 全部固定到 σ₁ 的原零端；其余 J 回唯一 home。U 只在各自 σ₀、σ₁ 原端中选择。
3. 全部机器同时有

\[
 C_{\max}(\tau_S)\le1+\delta(S)\le1+\delta.                \tag{2}
\]

4. 令 c_q=Σ_{j∈A_q}w_j，则构造族的实际费用满足

\[
 \operatorname{fee}(\tau_S)=\sum_{q\in S}c_q,
 \qquad \sum_{q\in Q}c_q\le W.                            \tag{3}
\]

特别地，S=Q 时有严格负载≤1；S=∅ 的构造本身也≤1。至少一枚 q 的单查询模式费用≤W/|Q|。不交集合与权无关，故同一个构造对全部非负权同时成立。这里输出简洁支持与按需调度生成器，不输出指数多份调度。

**Assumptions / Scope。** 两个严格见证是输入，不是免费可计算的 oracle。没有把图 LP、配置分布或“不同比较实例各自可行”替换为同一 P 的两个实际见证。结论只针对明确费用；构造族费用可加不代表最优费用函数可加。

## 2. 直接机器弧图证明

下面采用独立审查者先于作者证明重构的机器图路线。另一份冻结证明用单位匹配对称差压缩出相同的单 parent 机制。

对每枚 d∈D 画带任务标签的弧 h(d)→σ₁(d)；对每枚 u∈U 画 σ₀(u)→σ₁(u)。允许平行弧和自环。由于 σ₁ 负载≤1，这些 unit 任务的目标互异，故整个图入度≤1。

删除全部 Q 弧得 H。每个 r_q=σ₁(q) 是不同的零入度根；记其前向可达顶点集为 R_q。各 R_q 两两不交：若两根的路径首次相遇，则相遇点有两个前驱；若一根能到另一根，则后者不再是零入度。根也不能到达有向圈，因为第一次进入圈的点会有两个入边。这里圈可存在于其它分量，不需要把它误删成全图无环。

定义

\[
 A_q=\{d\in D\setminus Q:h(d)\in R_q\}.                  \tag{4}
\]

其不交性来自 R_q 不交及每任务 home 唯一。给 S⊆Q，令 R(S)=⋃_{q∈S}R_q，按以下规则输出：

- q∈S 使用 σ₁(q)。
- d∈D\Q 且 h(d)∈R(S) 时使用 σ₁(d)。
- u∈U 且 σ₀(u)∈R(S) 时使用 σ₁(u)，否则使用 σ₀(u)。
- Z 使用 σ₁ 的零端；其余 J 使用 home。

因此每枚原任务恰分配一次，查询 unit 模式恰为 S，非查询 unit 支持恰为 A(S)。

**全机负载核对。** R(S) 内每台机器恰接一枚选中的 unit：根由其查询弧提供，其他可达点由 H 中唯一前驱提供。所有这些弧都是 σ₁ 匹配的子集，目标互异；原来在 R(S) 的 σ₀-unit 任务均被重排。选中弧的目标仍在 R(S)。

若 i∈R(S)，σ₁ 在 i 有 unit；所以任何以 i 为正小端的 J 任务在 σ₁ 都必须属于 D∪Z。Z 已归零；非查询 D 的 home 在 R(S)，全部导出；S 也已导出。唯一可能残留的是 Q\S，故

\[
 L_i(\tau_S)=1+\sum_{q\in Q\setminus S:h(q)=i}a_q
 \le1+\delta(S).                                         \tag{5}
\]

若 i∉R(S)，没有选中 unit 进入；留下的 U 仍为 σ₀ 的原匹配，正小端任务是 σ₀ 的子集，另加零负载的 Z。故负载≤1。两类机器同时给(2)。查询的 home 可以相同，也可以位于另一查询的激活域；这些情况均在(5)的残余总量中，没有假设查询 home 互异。

费用等于对实际支持 A(S) 求和；A_q 不交、w_j≥0，立即给(3)。整个论证允许任意多级 home→unit 级联与单位任务全局重排；没有假设各 home 可以独立付费清空。

## 3. 可构造性、零端与边界

图至多有 |U|+|D| 条弧。根可达域互不相交，一次按根标记即可输出全部 A_q，总支持量≤|D\Q|。给定 S，扫描任务并按上面的规则写出一次完整分配。验证两见证、计算 δ(S)、负载与费用只需多项式次有理加法和比较；分母乘积位长不超过输入分母位长总和。没有按处理时间数值、精度倒数或 2^|Q| 迭代。

Z 的零端在所有输出原生保留，机器上可有任意多个零任务。纯 unit/zero 任务若有零端，可固定零端后删除；但若外部还对这些零移动收费，必须另核费用。a_j=0 不属于本页正小端核心域，不能把一个可免费留零端的任务算成需收费的查询。空 Q 不在 Claim 量词内；空任务、纯单位实例等属于一般主目标，但本页不据这些子类宣称解决主目标。

不能删除的限制包括：每 J 唯一正小端；σ₀ 全 J 留 home；两模式严格负载≤1；本页指定的费用对象；残余 δ(S) 必须落在拟用弱阈值内。多正小端、σ₀ 预先导出、仅有阈值 T₀>1 的模式、其它收费均需另证。δ=1 时统一界可能为2，不能声称固定改善。此前近单位环的共有固定费并未被排除：其 mixed 峰为1+a，恰与本页允许的查询残余负荷相符。

## 4. 对近二归约的准确限制

若每个 home 的查询小负荷总量≤η，且某编译器声称每种单查询实际模式在负载≤1+η 时都须支付至少 F>0 的非查询 unit 费，那么(3)迫使 W≥|Q|F。一个 strict 全查询模式不能只支付一次 F 来支撑任意多次查询。

这已保留被读取的查询任务身份及其 σ₁ unit 目标，不只是裸 unit-presence。它说明单正小端、两严格模式的级联仍缺少共享标签费用；它没有给出一般源问题的 weak decoder，也不排除离开这些假设的实际构造。

**Dependencies。** 同一 P 的两个实际严格见证、唯一正小端、σ₁-unit 匹配、入度≤1的可达域不交及非负权求和；无新外部定理。与[两占位胶合](unit_presence_two_witness_sharp_gluing.md)的域和结论不同，不能互相无条件替换。与[部分 Min-Rep 费用桥](partial_minrep_linear_degree_source_and_fee_bridge.md)合用时，必须先证明具体编译器满足上述所有假设。
