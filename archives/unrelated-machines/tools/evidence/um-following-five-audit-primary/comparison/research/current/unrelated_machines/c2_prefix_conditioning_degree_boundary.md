# C₂ 负载证书不能免费提供深层真前缀容量

本稿记录一个精确的表示边界，供条件矩和联合容量路线使用。它不否定 `UM-TARGET-v1`，也不声称 C₂ 松弛本身的完整间隙；它证明：若只给到四阶的真实分配矩（通常记作 C₂-load），则深度四的真实前缀容量并不由该数据决定。若要求恢复指定来源分布的深层条件负载，必须取得额外信息；允许重新耦合或重求证书的算法不受此非识别例排除。

## 1. 矩与条件负载

每个任务有 one-hot 选择变量 `x_e∈{0,1}`（同一任务的两个机器 literal 互斥），令

```
y_S = E_μ[∏_{e∈S} x_e].
```

给定相容前缀 `F` 且 `y_F>0`，机器 `i` 的真实条件平均负载为

```
L_i(μ | F) = (Σ_{e∈E_i} p_e y_{F∪{e}}) / y_F.       (1)
```

因此深度 `|F|=t` 的标量条件负载需要 `t+1` 阶矩。条件 degree-one 负载 localizer 的矩项最高次数为 `t+3`，完整条件 C₂ 矩及其 localizer 需要最高 `t+4` 阶。由四阶表只能直接得到 `t≤3` 的标量条件负载，不能自动得到深度四的 continuation capacity。

若 `F` 的概率为零，(1) 不定义；算法必须裁剪该分支或另给条件证书，不能把除零视为容量结论。

## 2. 两个真实最优、低阶相同的来源

**修复说明。** 旧见证让任务5、6以相同 `3/2` 时间互补分到A/B，完整条件B负载因而恒为 `3/2`；旧审计只检查任务5的literal边际0/1，没有验证正文/账本所称的整机负载。这里显式替换见证，保留 `UM-C2-PREFIX-CONDITIONING-DEGREE-v1` 的原存在性陈述、定义域和结论（同一矩阵、真实OPT2、四阶相同、条件B负载0/1）；不把旧见证伪装成已正确核验。

取机器 `A,B,C`，阈值 `T=2`。任务1–4在A、B上均为零时间。任务5在A、B均耗时1，用bit `z_5=0` 表示5→A、`z_5=1` 表示5→B。任务6在A、B均为零时间，两个来源中均固定6→A。任务7仅在C上可用，耗时2。对任务1–4，`z_r=1` 表示选A，`z_r=0` 表示选B。

令 `μ_even`、`μ_odd` 为五位bit的偶、奇Hamming重均匀来源，各有16份不同调度。每份A、B负载为0和1的某种排列，C负载恰为2；任务7给 `OPT≥2`，每份实际调度又达到2，故两个来源都是真实最优分布。

任意至多四个端literal的乘积，若one-hot不相容则为零；否则它只固定至多四个非平凡bit。任务6、7的literal是常量，不增加所见bit数。因此偶、奇来源有相同补全计数，全部 `|S|≤4` 的实际one-hot矩相同，包括同一处理时间矩阵定义的 `M₂` 与负载localizer。

取前缀 `F={z_1=z_2=z_3=z_4=1}`。两个来源都有 `y_F=1/16`。偶来源下 `z_5=0`，完整B负载为0；奇来源下 `z_5=1`，完整B负载为1。相应 `y_{F∪{x_{B,5}}}` 分别为0与 `1/16`，是五阶条目。这里比较的是式(1)定义的**完整机器负载**，并非把literal概率冒充处理时间。

这仅证明指定来源 `μ` 的条件平均负载不能由共同四阶数据唯一恢复。两个来源均可行，算法也可以改变耦合；本例不证明“所有可行的下一步选择相反”，更不推出一般联合舍入算法不存在。

## 3. 可核验范围与复杂度

上述 parity 事实可由 32 个 bit 串直接枚举核验；每个支撑调度的两台机器负载、`y_F=1/16` 及五阶差异均用整数计数得到。给定显式四阶表和 `F`，式 (1) 的分子、分母只需多项式次有理数加法与交叉相乘；但若要在本例准确恢复指定来源的深度四条件负载，则需要额外的五阶信息。深度 `t` 的完整条件 C₂ 一般需要 `t+4` 阶；显式存储所有条目随 `t` 指数增长。

## 4. 研究含义

这是一条 `limits` 而不是主目标反例：同一矩阵同时存在两份真实、`T` 可行的低阶来源，低阶数据无法唯一识别指定来源的深层条件负载。它精确排除以下未付义务：“把四阶 C₂ 证书重复条件化若干步，就自动得到共同真实容量”。可回收接口有三种：

1. 输入高阶/全 prefix 的条件 oracle，并证明其编码长度与查询时间位多项式；
2. 每步重算一个新的残余证书，并证明条件 PSD 与容量局部化；
3. 使用不依赖深层前缀的联合舍入或交换机制。

不能把真实最优分布的存在当作上述 oracle，也不能把有限 parity 枚举升级为一般调度困难性。
