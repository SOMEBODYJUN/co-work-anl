## 审查结论

**Exact v2 与作者 Proof v2 均通过。未发现 fatal、隐藏结构假设或未修复的严格边界问题。**

1. 作者确实使用已冻结 v2 的同一 `I>T/2` 染色族。β 和费用权不参与重新染色，故此结论只是固定族的筛选，没有暗中调用新的全局可行调度。
2. 若 q 不合格，实际超载为严格 `C_i(τ_q)>βT`。未标 q 的机器负载≤3T/2≤βT，故超载机必须标 q。在标 q 机器，负载≤T 加其他查询旧端量，所以超载强迫其他查询旧端量>cT，进而全部查询旧端量也>cT。为每个坏查询选择最小编号超载机是确定性的，不同坏查询的选择因机器唯一颜色而互异。坏数≤Rβ 的单射证明完整。
3. G 取全部实际合格查询，用精确有理回算即可识别。`|G|≥d−Rβ`；若 Rβ<d，则此数至少1。全族支持不交、权非负，故 G 的费用总和≤W，确有查询同时满足实际负载界与费用≤W/(d−Rβ)。未把“存在低费用”与“存在合格”分开选成两个查询。
4. η=0 时所有查询旧端量为零，Rβ=0、全部 d 个合格；费用≤W/d。v1 的“严格超过 d”确已撤去，而非将错误隐藏在等价改写中。
5. η>0 时，Rβ>0 用重机严格质量阈值推出 `Rβ<M/(cT)≤ηd/c`；Rβ=0 单独使用 ηd/c>0。这也覆盖总旧端质量 M=0 但上界参数 η>0 的情况。因此严格合格数与 `floor((1−η/c)d)+1` 的整数表达均正确。
6. W=0 时平均值就是0；作者始终对 fee 使用≤，未从合格数量严格不等式错误推出 fee<0。各费用式的分母都正：c≥1/2、T>0、η<c、d≥1。
7. 分组界的严格阈值正确处理了 `c/η` 为整数的情况：重机有 k 个源查询时，`kηT>cT` 强迫 `k≥floor(c/η)+1`，而不是错误使用 ceil(c/η)。不同源机查询组不交，得 `Rβ s≤d`，所以 `Rβ≤floor(d/s)`。s≥2，故合格数至少 `d−floor(d/s)≥ceil(d/2)>0`，费用分母合法。零质量查询只会增加组内 query 数，不会破坏该必要条件。
8. F 推论只把 G 中已经实际构造出的合法 singletons 代入物理费用下界，再利用总费用≤W；`W≥|G|F` 推理有效。Rβ=d 时主式仅是 W≥0，未错误保证非空 G；分组域中则另有正的整数数量保证。背景费用、退款和其它费用没有混入非负改派权合同。
9. 复杂度包括源查询质量求和、严格比较、β 与 η 的有理运算、整数除法及逐 q 的实际负载回算。s 可能数值很大，但二进制位长为输入位长量级，不按 s 迭代。原染色输出总支持有限、所有计算只涉及输入有限实际端；仍为按总输入位长的确定性多项式时间。

本结果不建立一般 UM 近似算法、OPT gap、完整子集 cube 或全局 novelty。两个实际可行见证仍为输入。以上审查未修改旧 v1 候选或其独立错误记录。
