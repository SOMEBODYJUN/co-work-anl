# β 查询计数与费用候选：独立 Exact-first 审查

审查者：general_query_response_review。2026-10-18。

本轮只收到 parent 的候选精确陈述，未读取任何新增作者证明或其他审查者文件。此前 v2 已闭合的染色算法及其已审定性质可用。

**独立结论：以 Rβ 表达的主结论成立。逐 query 小负载的派生式在 `0<η<β−1` 时成立；若允许 η=0，则“严格超过”存在真正边界反例。η=0 应改成全部 d 个查询合格。**

## 1. 主结论证明

固定 v2 的同一染色族。令 `c=β−1`，所以 `1/2≤c<1`。对机器 i 记查询旧端总量

\[
S_i=\sum_{q\in Q:\sigma_0(q)=i}p_{i,q},
\]

并记高查询负载机器集 `Hβ={i:S_i>cT}`、`Rβ=|Hβ|`。

v2 算法给每个触发机器唯一颜色，具有两个性质：

- 若机器 i 没有标记为 q，则 `C_i(τ_q)≤3T/2`。
- 若机器 i 标记为 q，则所有该机非查询原任务均已在 τ_q 中改派，因而

\[
C_i(τ_q)\le T+\sum_{r\in Q\setminus\{q\}:\sigma_0(r)=i}p_{i,r}\le T+S_i.
\]

称 `q` 为坏查询，如果 `Cmax(τ_q)>βT`。因 `β≥3/2`，坏查询的超载机器 i 必须标记为 q。由后一负载界，必有 `S_i>cT`，所以 `i∈Hβ`。

每个坏查询任选一个超载机器。不同坏查询不可能选到同一机器，因为同一机器只有一个标色。故坏查询到 `Hβ` 存在单射，坏查询个数至多 Rβ，合格查询个数 g 满足

\[
g\ge d-R_\beta.
\]

如果 `Rβ<d`，则 `g≥d−Rβ≥1`。支持不交给出全族非负费用之和≤W，因此合格子族的费用之和也≤W，其中至少一项满足

\[
\operatorname{fee}(τ_q)\le\frac Wg\le\frac W{d-R_\beta}.
\]

该 q 的实际负载同时≤βT。无需改动 v2 染色，族仍不依赖权重与 β。Rβ、每个 τ_q 的合格性以及给定权后的最小费用均可用有理数精确计算，仍为总输入位长多项式。

实际上 `Rβ≤d`：每个高查询负载机器都必须拥有至少一枚正旧端 query，而不同机器的原 query 集不交。

## 2. 逐 query 小负载派生与严格整数计数

假设每个查询的旧端时间≤ηT，`0<η<c`。记全部查询旧端质量 `M=Σ_i S_i≤ηTd`。

若 `Rβ>0`，由重机阈值严格，有

\[
R_\beta cT<\sum_{i\in H_\beta}S_i\le M\le\eta Td,
\]

故 `Rβ<ηd/c`。若 `Rβ=0`，由于 `η>0,d>0`，同一严格不等式仍然成立。

因此

\[
g\ge d-R_\beta>\Bigl(1-\frac\eta c\Bigr)d.
\]

因为 g 为整数，精确保证是

\[
g\ge K_\eta:=\left\lfloor\Bigl(1-\frac\eta c\Bigr)d\right\rfloor+1
=d-\left\lceil\frac{\eta d}{c}\right\rceil+1.
\]

`0<η<c` 保证 `1≤Kη≤d`。于是至少一个合格查询费用≤`W/Kη`，特别也满足候选所写的较弱界

\[
\operatorname{fee}(τ_q)\le\frac W{(1-\eta/c)d}.
\]

若 `W>0`，上面较弱的实分母界事实上可取严格小于；若 `W=0`，所有非负费用为零，因此只能保证≤，不可声称费用严格小于零。

## 3. η=0 的严格计数反例及修复

η=0 时，每个 query 的旧端时间都为零，因此 `S_i=0`、`Rβ=0`，全部 d 个查询均合格，费用存在≤W/d。

但“严格超过 `(1−η/c)d=d` 个合格查询”不可能成立。

最小具体反例：T=1、β=3/2，两台机器 H,A，一枚 query q；q 在 H 上时间 0、在 A 上时间 1，其余端无穷。σ0 放 H、σ1 放 A。此时 d=1、η=0，唯一输出 τ_q 的 makespan=1，恰好一个合格查询，却无法严格超过 1 个。

建议修复合同为：

- `0<η<β−1` 时保留严格“超过”，及上面的精确整数 Kη；
- `η=0` 时全部 d 个合格，费用≤W/d。

如需统一较弱措辞，对 `0≤η<β−1` 写“至少 `(1−η/(β−1))d` 个”即可，费用实分母式在 η=0 也仍有效。

总查询质量 M=0 但采用正上界 η>0 时，并无反例：全部 d 个合格，且 d 严格大于 `(1−η/c)d`。真正例外是参数 η 本身为零。

## 4. 可选的更强计数

还可从每枚 query 的大小上界得到比质量界更强的整数分组界。若 `0<η<c`，令

\[
s=\left\lfloor\frac c\eta\right\rfloor+1\ge2.
\]

每台高查询负载机器至少需要 s 枚源 queries，否则至多 `(s−1)ηT≤cT`，不满足严格重机阈值。机器的源 query 组互不相交，故

\[
R_\beta\le\left\lfloor\frac ds\right\rfloor,
\qquad
g\ge d-\left\lfloor\frac ds\right\rfloor,
\qquad
\min_{q\text{ 合格}}\operatorname{fee}(τ_q)
\le\frac W{d-\lfloor d/s\rfloor}.
\]

特别地，`η<c` 已保证至少 `ceil(d/2)` 个合格查询。这是可选强化，不是原候选成立所需的额外假设。

**最终审查：主结论通过；派生式除 η=0 的严格计数句需修正外通过。未依赖任何新增作者证明。**
