# 阅读范围和对象

本批完整读取 `heavy_matching_residual_and_escape.md` 与 `heavy_light_saddle_certificate_and_cycle.md`，并与经典两树、配置证书、共享终端和价格凸化审查比较。两源研究同一类 unrelated-machines 舍入接口，却回答不同问题：第一源给出只删边的安全必要条件过滤器，并构造简单支撑和共享小端反例；第二源把重任务匹配与轻任务残余 LP 写成一个可核验的 saddle 充分条件，并给出最小二循环说明最佳响应不必停机。它们都明确不解决 `UM-TARGET-v1`，也没有给一般困难性结论。

稳定身份为 `UM-HEAVY-MATCH-FILTER-v1`、`UM-SIMPLE-SUPPORT-GAP-v1`、`UM-ESCAPE-MATCH-GAP-v1` 与 `UM-HEAVY-LIGHT-SADDLE-CERTIFICATE-v1`。下文分别记录安全性、原模型反例、条件正面结果和开放义务。

# 一、重边匹配残余过滤

## 1. 过滤器定义与安全性

给合法输入 (P,T\ge0)，先保留 (D_j=\{i:p_{ij}\le T\})。把 (p_{ij}\le T/2) 的端称小边，其余存活端称大边。令 (N) 为无小边任务，(U_i) 为唯一小端在 (i) 的任务，(F_i=\sum_{s\in U_i}p_{is})，并令 (H) 为任务—机器大边图。先检查 (H) 是否覆盖 (N)。对每条大边 ((j,i))，强制 (j\to i)，覆盖全部 (N\cup\{j\})，并尽量匹配 (U_i) 中的任务；定义可卸载权 (W_{ij})。若不存在该匹配，或
\[
p_{ij}+F_i-W_{ij}>T,
\]
则删除该边，重复直到无边可删或覆盖失败。

安全定理是：每轮仍保留所有 (T)-可行调度使用的边；拒绝必推出 (OPT(P)>T)。证明依赖一个 (T)-可行调度中所有大边任务自动形成容量一的匹配。若该调度把 (j) 放在 (i)，它离开 (i) 的唯一小端任务可同时被匹配到其它大边，卸载量不超过 (W_{ij})，故 (p_{ij}+F_i-W_{ij}\le T)。同步删边归纳保持安全。

匹配子程序按 (p_{is}) 非增扫描 (U_i)，逐任务增广，得到在固定强制大边和必选 (N) 下的最大权可选匹配。该性质只适用于任务权与边无关的情形；源没有把它误写成任意加权匹配。每轮至多 (e) 条边查询，最多 (e) 个删除轮，总查询数 (O((e+1)^2))，有理比较、匹配和分母位长均多项式。接受只表示未被必要条件拒绝，不表示存在 (T)-可行调度。

## 2. 过滤器在经典与简单支撑族上的边界

在经典两棵 (k)-叉树族中，(T_0=1+1/k) 有配置证书，而真实 (OPT=2-1/k)。对 (T_0\le B<2-1/k)，末端父的大边若进入就必须承担不可充分卸载的小边，式中的左端至少 (2-1/k>B)，故过滤器逐层删除所有进边，最终拒绝；在真实 OPT 阈值处安全性保证不拒绝。由此它在该族上增加了配置证书没有的必要信息。

把每个末端的平行终端改成 (k) 个不同终端，并加入相邻终端的 (k-1) 个单位占位任务后，每个任务只有两台可用机器、每个无序机器对至多支持一个任务，有限时间仅为 (1/k,1)。该 `UM-SIMPLE-SUPPORT-GAP-v1` 族仍有 (OPT=2-1/k)，配置 LP 在 (T_0) 可行。makespan 小于 2 时，占位任务占满 (k-1) 个终端，至多一条星任务能下传，从而保留原下界；沿一条占位路径可构造达到 (2-1/k) 的调度。终端配置按占位任务的分数拆分给出完整任务覆盖，说明把支撑图简化为简单二部图仍不能消除配置 gap。

## 3. 共享小端逃逸与过滤固定点

在简单支撑族给所有占位任务增加同一共享机器 (z)，时间 (1/2)，其它任务不能去 (z)，得到 `UM-ESCAPE-MATCH-GAP-v1`。每个占位任务现在有三个端点，不能直接沿用二端点下界。正文重新证明：当负载低于 (2-1/k) 时，树的激活传播使至少四个末端父同时各下传两条星任务；每簇 (k-1) 个占位任务中至少一件必须去 (z)，于是 (z) 至少接四件半单位任务，负载至少 2，矛盾。原路径调度不使用 (z)，所以 (OPT=2-1/k)。

配置证书把 (z) 取空配置；对每条新边可以单独构造逐边 LST 证书。更强的 GHMR 过滤器在 (T_0=1+1/k) 首轮也不删任何边：对每条被强制的大边，都能把可选小端任务匹配到不同孩子/终端；(z) 没有大边查询。因而该族同时通过配置可行性与每次独立匹配必要条件，但它们没有共同的全局容量分布。精确失败机制是：每个查询可把其它占位任务假定留在 (z)，单查询最优不保证可同时扩展；共享 (z) 的真实负载必须跨查询联合控制。

这三个结论的准确范围是过滤器合同和给定配置证书的合取，不是所有匹配强化、所有配置层级或一般算法的 impossibility。有限审计验证列出的参数和重放，不能替代解析证明或一般 hardness。

# 二、重轻角色与自洽 saddle

## 4. 重轻残余模型

取 (T>0)、(\beta\in[1/2,1))。保留 (E_T=\{(i,j):p_{ij}\le T\})，把 (p_{ij}>\beta T) 的边称 heavy，把不超过 \(\beta T\) 的称 light。heavy placement (H) 是 heavy 边上的部分匹配，且没有 light 端的任务必须被覆盖。对未覆盖任务使用 light 端分数 (x)，定义
\[
R(H)=\min_x\max_i\left(a_i(H)+\sum_{j\notin J_H}p_{ij}x_{ij}\right).
\]
对价格单纯形 (\Delta=\{\lambda\ge0:\sum_i\lambda_i=1\})，令
\[
\mu_j(\lambda)=\min_{i\in L(j)}\lambda_i p_{ij},\qquad
 g(H,\lambda)=\sum_i\lambda_i a_i(H)+\sum_{j\notin J_H}\mu_j(\lambda).
\]
残余 LP 强对偶给出 (R(H)=\max_{\lambda\in\Delta}g(H,\lambda))。

## 5. Saddle 充分条件和整数输出

若存在 admissible (H) 与 (\lambda^*\) 使 (\lambda^*) 是残余 LP 最优对偶，且 (H) 在 (g(\cdot,\lambda^*)) 上全局最小，则对任意 (H')，
\[
R(H')=\max_\lambda g(H',\lambda)\ge g(H',\lambda^*)\ge g(H,\lambda^*)=R(H),
\]
所以 (H) 全局最小化 (R)。给定有理 (\lambda^*)，第二个条件化为一次最小费用匹配/流，因而是可核验的充分证书。

若 (R(H)\le T)，轻边最大时间至多 \(\beta T)，有序槽舍入给
\[
L_i\le R(H)+\beta T\le(1+\beta)T.
\]
因此若 (\beta\le1-\varepsilon)，该证书导出 ( (2-\varepsilon)T) 的实际调度。但它是存在性/验证接口：正文没有给出从任意 (P,T) 找到这样的自洽 (H) 的算法。

## 6. YES 实例上的纯 saddle 二循环

对任意 \(\beta\in[1/2,1))，令 \(\delta=(1-\beta)/4)、(a=1-\delta)、(b_1=\beta+\delta)、(b_2=\beta+2\delta)、(c=\delta)。两台机器和三个任务的处理时间为
\[
p(A)=(a,a),\quad p(B)=(b_1,b_2),\quad p(\ell)=(c,\infty),
\]
其中 (A,B) 只能走 heavy 边，(ell) 只能走 light 边。两种 heavy placement (H_1,H_2) 的残余峰值分别为 (1) 与 (a<1)，所以 (OPT=a\le T=1)。但 (H_1) 的最优对偶偏向机器 1，按该价格 (H_2) 严格更便宜；(H_2) 的最优对偶偏向机器 2，按该价格 (H_1) 严格更便宜。因此没有纯 ((H,\lambda)) saddle，尽管承诺 YES 实例存在。

(eta=1/2) 时矩阵 (g(H_r,\lambda_s)) 为
\[
\begin{pmatrix}1&3/4\\3/4&7/8\end{pmatrix},
\]
每行最大值由自身价格列取得，但每列最小值由另一 placement 取得；这是纯策略无 saddle、凸化可能有混合 saddle 的最小精确结构。它只否定“残余对偶→重匹配→重新定价”必然停机或必有纯固定点，不否定非局部增广、混合信息、配置相关性或其它舍入合同。

# 三、比较与后续义务

1. `UM-HEAVY-MATCH-FILTER-v1` 是安全必要条件过滤器：拒绝声称 (OPT>T)，接受不声称可行。共享 (z) 族说明逐条最优匹配和独立 LST 证书缺少共同容量账本。
2. `UM-HEAVY-LIGHT-SADDLE-CERTIFICATE-v1` 是一个可验证的自洽充分条件：它把对偶价格与 heavy placement 的量词交换压缩成一个 saddle 点，但源不提供一般 saddle 搜索器。逐价格条件 (\forall\lambda\exists H) 不能自动变成同一 (H) 对所有价格有效。
3. 两源都只处理实际合法矩阵和明确的任务端点；它们没有给六人 SPE 覆盖 half 结论，也没有近二 hardness。有限程序审计、经典两树引用和外部文献优先权均按各自审查保留。
4. 后续若要扩展过滤器，必须把多台共享小端的残余容量同时耦合，并保留多项式位复杂度和整数回填。若要扩展 saddle 路线，必须证明一般输入存在/可找到近似 saddle，或给出不依赖纯 saddle 的全局增广规则。

两个来源已完整读取、比较并归入本审查。其独有内容（安全过滤、最大权匹配证明、简单支撑 gap、共享逃逸固定点、saddle 强对偶证书、YES 二循环）均保留；未成熟的一般算法与 hardness 义务明确标为开放。
