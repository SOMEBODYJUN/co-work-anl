## 7. 完整单机配置也分别能延伸到完整配置LP

本节新增 **UM-MACHINE-CONFIG-PROBE-GAP-v1**。它把第4节的“其余机器仅守计数”加强为真实配置LP延伸，原两个Claim的身份不改。本节复用boss2在第2节已入库的紧凑族；新增贡献是全部单机配置的**真实配置LP延伸**，不是再命名一次反例族。boss1先从低成本深树的条件配置探针出发，收到boss3的路径修复后独立核查，再在本族找到以下紧凑证书；不把来源组件算作独占新结果。

### 7.1. 精确合同、结论与有限边界

对合法P和有理T≥0，称其通过完整单机配置探针，如果

\[
\forall i\in M\ \forall C\in\mathcal C_i(T)\ \exists y^{i,C}:
\quad y^{i,C}\text{满足原始完整配置LP，且 }y^{i,C}_{i,C}=1. \tag{MP}
\]

每个延伸点在**全部**机器满足配置容量、归一化和逐任务覆盖；固定机器的配置恰是C，因而C外的所有任务在该机边际为0。不同(i,C)允许不同的完整y，既不要求共同未条件化y，也不要求跨探针的联合分布。即使能够检查指数多个C，本合同也不包含这些额外一致性。只反复删去无延伸的配置，在下面实例没有第一次删除。

**Exact Statement。** 对每个整数k≥2，第2节同一个多项式规模实例在T=1通过(MP)，且OPT=2−1/k。因此在正OPT输入上，满足(MP)的实例/目标对的sup OPT/T为2。第3节GPC₂、第4节过滤无起点与(MP)可以在同一实例同时成立，**不声称每个条件延伸也满足GPC₂或嵌套过滤**。

(MP)是本族的强性质，**不是一般T整数可行性的必要条件**：可行实例也可能有某个本地配置无法延伸。安全程序只能删去无延伸的配置，不能因为发现任意一个失败配置就拒绝目标。本族因全部配置起初都有延伸，恰好令这种删配置规则没有第一次删除。

比值下界直接是2−1/k；任意统一ε>0取k>1/ε。上界来自任选一个(MP)延伸，投影到LST再用UM-ST-ROUND-v1。正OPT下T=0不可能通过：空配置探针必须仍覆盖正处理任务；因此无需定义0/0。一般输入的零/空边界不被本正值反例族覆盖，也没有被改写；空任务或每任务可走零边有其真实零调度。

### 7.2. 配置证书的两个装配事实

令a_b为X_b在V_b的边际，正常块的V配置为：{X_b}权a_b，全k个Z权1−a_b。于是每个Z在本块R的需求为a_b。允许指定一个中心取确定的Z子集，此时该中心a_b=0、缺失Z的R需求为1、保留Z为0。

1. **全局机装配。** X的剩余需求为1−a_b。未固定G时，若Σ_b a_b=2k，剩余总量恰为G=N−2k；把这些有理需求依次填入G个单位槽即可，各槽用单任务/空配置。若一台G固定为空，则需Σa_b=2k+1，剩余恰G−1。若一台G固定{X_a}，则a_a=0，先扣掉这一个单位需求，再把余量填其他G−1槽。k≥2给G≥4，分母或剩余机器数不会退化。
2. **块内装配。** 选一集合E的Y完整送z。块b在R上的总需求是k−|E∩Y_b|加该块所有Z的R需求。每项需求在[0,1]；只要总量≤k+1，就能用相同的有理单位槽填充，配置均为单任务/空。若某R固定空配置，改用其余k槽；若固定单任务，先扣下该任务的单位需求，再用其余k槽。z以概率1取E，合法当且仅当|E|≤k。

这里不把“总量足够”用于稀疏路径：本族每个Y/Z都能使用本块的**全部**R，才允许上述填槽。填槽使一项任务可跨两个槽，表示为两个机器各自的单任务配置边际；不需要假装这些配置已组成整数调度。

### 7.3. 全部合法配置的分类延伸

因为T=1且时间严格正，V上的合法配置恰为{X}或任意Z子集，G上为空或单X，R上为空或单Y/Z，z上为任意至多k个Y。以下穷尽这些类型。没有特别说明时，其他块a=1/k；所有逃逸都指选择互异的整项Y进入E。

| 固定机器及配置 | a及中心配置的修改 | 逃逸集合及容量核对 |
| --- | --- | --- |
| V_a固定{X_a} | a_a=1；其余a_b=(2k−1)/(N−1)<1/k；Σa=2k | 本块送k−1个Y去z，R需求k+1；其他块Z总需求ka_b<1，不逃逸；|E|=k−1 |
| V_a固定r个Z的子集（r可为0） | a_a=0且中心取该子集；另选b≠a令a_b=2/k；其余1/k；Σa=2k | a块Z需求d=k−r，送max(d−1,0)个Y；b块Z需求2，送1个Y；总逃逸≤k；两块R需求均≤k+1 |
| G固定{X_a} | a_a=0，另b取2/k，其余1/k；中心a取全部Z；Σa=2k；X_a由固定G完整承担 | 仅b块送1个Y；扣除X_a后其他X需求恰G−1 |
| G固定空 | 取k个不同块a_b=2/k，其余1/k；Σa=2k+1 | 这k块各送1个Y，|E|=k；X余量恰由其他G−1槽填满 |
| R_(a,l)固定空或单Y | a_a=0，另b取2/k，其余1/k；a中心全Z；Σa=2k | 仅b送1个Y；a块只有k个Y，可避开指定空R；指定单Y时先扣掉它，余k−1个Y用其他R |
| R_(a,l)固定单Z_(a,s) | 同前，但a中心取除Z_(a,s)外的全部Z | 仅b送1个Y；a块该Z需求1、k个Y需求1，固定Z占指定R，Y双射到其余k台R |
| z固定任意C，|C|≤k | 全部a=1/k，中心保持原分布 | E=C；从原R配置中删去C中Y的出现，余配置权重保留（可变空）；所有其他任务边际不变 |

所有a在[0,1]。第一行严格界等价于k(2k−1)<N−1，即k>1；第二行2/k≤1。除固定中心外，局部需求公式是k+ka_b−|E∩Y_b|。表内逐类满足装配事实；最后一行也可以直接装配，R总需求只会降低。因此每类都得到实际完整配置y，并恰好固定所要求的C，(MP)得证。

### 7.4. 构造复杂度、反驳范围与下一步

给展开实例及显式(i,C)，以上证书可确定性在其总位长的多项式时间内生成。中心至多两配置，全局和局部单位槽填充的正项总数线性于需求项数与机器数，z一配置；每配置的任务清单长度也多项式。系数只用k、N−1及其有理和差，贪心填槽不会产生新分母，故分子分母位长多项式。该声明是**本显式族的证书生成**，不声称枚举全部配置或精确求通用配置LP为多项式。

此结果已排除把“每一单机配置都分别能在完整配置LP里实现”当作统一低于2阈值舍入的充分信息，也包含全部单边条件配置探针，因为每条可用边的单任务配置可被固定。仍然没有排除需要一个共同base y的条件分布恒等式、完整SA/LS层级、跨机器相关性、条件块切面或相对OPT算法。第5节随B变化的跨块切面仍修复本族；不存在与它的矛盾。GPC₂与本节(MP)只是独立合取，未构造共享的条件pair数据。

**同一族上怎样增加有效信息。** 在T=1，任何强制V_a={X_a}的配置LP延伸都须把该块至少k−1的Y总边际送z：k个Z已全部外送，加上k个Y，总2k的单位需求面对k+1个R槽。假如这些延伸还来自一个共同base，且对每个a至少满足该块Y逃逸坐标的条件混合恒等式，则非负性给Σ_s x_(z,Y_a,s)≥(k−1)a_a。全局X容量又迫Σa_a≥2k，故z负载至少(k−1)Σa_a/k≥2(k−1)>1，矛盾。此处只需把各探针与同一个base的相应逃逸一阶矩联结；并不需要假设已经存在完整全局分布。这是第5节已有条件块切面的同一计数机制，不另立新Claim。它精确解释了为何每个延伸本身真实可行，却无法共同实现；一般如何有效选择、分离并舍入这种共同信息仍开放。
