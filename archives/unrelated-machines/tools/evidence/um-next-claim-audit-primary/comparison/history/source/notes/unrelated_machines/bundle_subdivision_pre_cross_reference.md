# 成束任务的二阶相容性、计数传播与细分障碍

本文研究一个具体候选：在配置LP之外加入两机器间的任务相关性，或用可计算的强制负载传播识别整数瓶颈。它们确实消除既有两树实例，但任务细分会恢复上确界间隙2。由此得到可复用的预处理工具和准确失败范围，**没有得到UM-TARGET-v1的近似算法，也没有得到计算复杂度困难性**。

基线定义、两树族及已知结果来源见[经典正文](model_and_classical_barriers.md)。本文的推导由boss2及内部子研究者独立汇集；新颖性、独立论文价值和外部同行评审未认证。局部一致性的乘积拼接与任务细分都是基本工具；不能把下述推论包装成新的全局调度定理。

## 1. 精确合同与三个身份

一般输入始终为UM-MODEL-v1。对有理阈值T≥0，配置分布y_i支撑在C_i(T)，机器质量1，任务覆盖恰1。写x_ij=Pr_{S∼y_i}[j∈S]。

本文的具体身份是：

| ID | 精确作用域及结论 |
| --- | --- |
| UM-BUNDLE-MOMENT-v1 | 对每k≥4的既有两树实例，仅在每个末端平行任务束加入式(1)后，配置可行阈值恰为θ_k=2−1/k。是一个实例族的强化效果。 |
| UM-CARDINALITY-CLOSURE-v1 | 对任意合法P和有理T≥0，下面的确定性删边闭包保留每个makespan≤T调度，按(P,T)总位长多项式终止；拒绝上述两树的全部T<θ_k。接受不保证可行，更不输出近似调度。 |
| UM-PAIR-SUBDIVISION-GAP-v1 | 定义第4节的完整两机器配置耦合LP。即使机器图为简单二部图、每任务恰两台可选机，其sup OPT/T_PAIR仍为2；第3节闭包在所给细分族的T_k=1+1/k处不删任何边。 |

精确对象、量词、依赖、证据与异议另登记在[主题账本](../../unrelated_machines/CLAIMS.md)。三个身份均不改变UM-TARGET-v1。

## 2. 原两树实例上的二阶修复

令B为末层父机器u与终端机器v间的k个任务：p_uj=1/k、p_vj=1。父端另有incoming任务a，耗时1。对配置S记N_i(S)=|S∩B|。每个整数分配都满足N_v=k−N_u，因此以下是有效的跨机器线性配置约束：

\[
\mathbb E_{y_u}\binom{k-N_u}{2}
=\mathbb E_{y_v}\binom{N_v}{2}. \tag{1}
\]

它只耦合一个任务束。若需要逐任务表达，定义q_i,jℓ=Pr_{y_i}[j,ℓ∈S]，对不同j,ℓ∈B加入

\[
q_{v,j\ell}=1-x_{uj}-x_{u\ell}+q_{u,j\ell}. \tag{2}
\]

式(2)逐对求和就是(1)；证明只需整数指示变量的(1−X_j)(1−X_ℓ)恒等式。单机器凸包没有包含这个跨机器等式。

**证明UM-BUNDLE-MOMENT-v1。** 若0≤T<θ_k<2，则v的每个可行配置至多含一条B任务，式(1)右侧为0。左侧非负，故u的每个正质量配置均有N_u≥k−1。若同时含a，其负载至少1+(k−1)/k=θ_k>T，矛盾。因此a在u的边际为0。

自底向上，若一个内部点的每个孩子对相应incoming任务的覆盖均为0，任务精确覆盖强制这个点对全部k条outgoing小任务边际为1。由于y是非负概率分布，每个正质量配置都含全部这k条小任务，负载已为1；不能再接耗时1的自身incoming任务，因为T<2。于是其incoming边际同样为0。最终根间大任务两侧边际均为0，与覆盖1矛盾。没有概率独立假设，整条树的所有任务都保留。

T=θ_k时，经典正文的整数路径调度给Dirac配置分布，满足所有整数有效约束，故强化阈值恰θ_k。这里只证明该族，不证明一般强化间隙小于2，也未给该指数列LP的多项式求解器。

旧证书在每个末端束的父端以总质量1/(k−1)选择incoming加一条small，其余质量选择全部small。因此对任意两条不同small，父端同时遗漏二者的概率为(k−2)/[k(k−1)]，而终端同时选择二者的概率为0；聚合式(1)的残差为(k−2)/2。这是它被切掉的具体原因，不是数值求解器的现象。

## 3. 不需配置oracle的计数删边闭包

初始化D(j)={i:p_ij≤T}，空域立即拒绝。保持不变量：每个makespan≤T的合法调度σ都满足σ(j)∈D(j)。每轮从同一组域计算全部删除条件，最后同步删边；按固定任务、机器索引枚举，直到无边变化或某任务空域。n=0立即接受，只处理有有限边的活跃机器。

先记F_u=Σ_{h:D(h)={u}}p_uh。若某F_u>T，立即拒绝。对每个候选j→i：

* F_i^{¬j}=Σ_{h≠j:D(h)={i}}p_ih，是除j外的单域任务强制负载。
* 对v≠i，B_iv^{¬j}={h≠j:D(h)={i,v}}；这些任务若不到v就必须到i。置R_v=T−F_v。j仍有候选i，所以不可能是v的单域任务，F_v无需再扣除j。
* 对整数q=0,…,|B_iv^{¬j}|，令K_ivq={h∈B_iv^{¬j}:p_vh>R_v/(q+1)}。v在完成单域任务后仅余R_v，故其中最多q个能放v。等号不列入K，因为q+1项可能恰好装满。
* 令b_ivq为K_ivq的p_ih总和减去其中至多q个最大的p_ih之和；空和及删去全部项时为0。令r_iv^{¬j}=max_q b_ivq。

如果

\[
p_{ij}+F_i^{\neg j}+\sum_{v\ne i}r_{iv}^{\neg j}>T, \tag{3}
\]

就删除i∈D(j)。这里的max不与其他q求和，以免重复收费；不同v的任务束、单域集合以及j两两不交。未拒绝不保证存在调度。

**安全性。** 固定任意makespan≤T的调度，假设它仍在D中且σ(j)=i。单域任务必须在其唯一机器，故v只余R_v。对每个v和q，K中至多q个任务可在v，其余在i；为了下界在i的负载，允许这q个恰好为p_ih最大的任务。因此i从此任务束承担至少b_ivq，进而至少r_iv^{¬j}。对互不相交的束、单域任务及j求和，(3)与L_i≤T矛盾。每个同步删除都不属于任何T可行调度，所以同步删除也保持不变量；空域或强制超载是真实不可行证书。零值和T=0均不例外，没有除以处理时间。

**残余容量与单调性。** 不能粗略地以T代替R_v，否则健全性仍在，但域收缩后过滤强度可能下降。这里对保留的j→i，式(3)左端随其他域缩小或T降低不减。新增二元束贡献非负界；束任务h被迫到i时，新增p_ih强制负载补偿其从束中消失所减少的至多p_ih。若h被迫到v，令a=p_vh，R'_v=R_v−a：对旧K_q，若h不在其中，同q的界保留；若h在其中且q=0则强制超载；若q≥1，则

\[
(R_v-a)/q<R_v/(q+1).
\]

所以旧K_q去掉h包含于新K_{q−1}；删掉一个任务同时将允许去v的名额减少一个，剩余p_ih尾和不会减少。其他新增强制负载只降低邻束残余容量。T降低使K扩大。故删除算子在域包含关系下单调，任意合法删除序列均被同步穷尽闭包覆盖；小T的幸存域包含于大T的幸存域。正式实现采用同步轮，毋须假设扫描巧合地选择了正确次序。

**总位复杂度。** 设E≤mn是有限边数。每个非终止轮至少删一边，至多E+1轮；每轮至多E个候选，每候选至多m个束，每束至多n+1个q，每项筛选/排序/求和至多O(n log(n+1))个有理操作，故保守总界O(m³n⁴log(n+1))足够。n=0直接接受；只处理活跃机器也可将m换成至多E。所有F、b、r和左端是至多n项输入时间的和/差；额外阈值除法仅为(T−F_v)/(q+1)。所有有限时间及T的分母积位长不超过输入总位长，其再乘q+1只增加O(log(n+1))位。域变化不产生新处理时间，逐轮没有嵌套分母增长；比较用整数交叉乘积，故每次操作及总程序均按总位长多项式。

**对原两树族的作用。** T<1时根间大任务无域。1≤T<θ_k时，初态底层束在q=1有K=B，因为p_vh=1>T/2，故r_uv≥(k−1)/k。给父端incoming候选加上其耗时1，式(3)删去它。底层全部incoming边因而强制到上一层父机；其k条outgoing小任务合计1，加自身incoming的1>T，继续删incoming候选，逐层达到根间任务无域。这是一条合法的自底向上删除序列，前述域单调性保证正式同步闭包覆盖它，即使还触发了其他删除也不丢失拒绝。T=θ_k时已知可行整数调度被安全性保留，故不会错误拒绝；T≥θ_k同理。因此该族的过滤阈值恰为OPT。

**可计算下界。** 将全部有限处理时间的分母相乘为D，令整数矩阵P*=DP；log D不超过输入分母总位数。取U=Σ_j min_i p*_{ij}，逐任务选最小边给一个makespan≤U的实际调度。由接受向上单调，在整数[0,U]二分求最小未拒绝值H，只需O(log(U+1))次上述闭包调用；U=0直接返回0。因为D·OPT是整数且对应可行调度不会被删，B(P)=H/D≤OPT。D、U及二分中点的位长均为输入位长的多项式。它是数值下界，不能代替主目标所需的具体近似调度。

第5节给更简单的失败机制：在非空双域、无平行任务的初态中，每束至多一任务。此时F_v=0、R_v=T；每条剩余边时间≤T使q=0的K为空，q≥1则至多一项且全部被减去，所以所有r_iv=0、F_i=0，没有任何第一次删除。

## 4. 两机器完整配置耦合究竟增加什么

本节只考虑每任务恰有两台不同的可用机器。机器图以任务为边，允许平行任务。除机器配置y_i外，为每对不同机器u,v引入联合分布z_uv(S,R)，边际分别为y_u,y_v；正质量支撑必须满足对每条端点恰{u,v}的任务j，1_{j∈S}+1_{j∈R}=1。没有要求不同机器对的z来自同一个全局联合分布。令T_PAIR为这个LP的精确可行阈值。

整数调度给一族Dirac分布，所以它是有效松弛。它包含式(1)和(2)，但不是所有三机器或更高阶边际一致的hierarchy。

**单共享任务引理。** 若u,v至多共享一条任务j，普通配置边际已足以构造z。无共享任务时取乘积。恰一任务时写a=x_uj、1−a=x_vj，对兼容块取

\[
z(S,R)=
\begin{cases}
y_u(S)y_v(R)/a,&j\in S,\ j\notin R,\ a>0,\\
y_u(S)y_v(R)/(1-a),&j\notin S,\ j\in R,\ a<1,\\
0,&\text{其他情形}.
\end{cases} \tag{4}
\]

第一块的两侧事件质量均为a，第二块均为1−a；逐行和逐列求和恢复原边际。a=0或1的零分母块没有正质量，直接置0。因此在简单机器图上，完整两机器配置耦合与普通配置LP等价。不能由每对存在耦合推出全局联合分布存在。

有显式有理配置证书时，边际求和及式(4)的乘除在证书位长上多项式；输出支持至多Σ_{u<v}s_us_v，其中s_i是给定机器支持数。这只是证书变换，不是求解未知指数列LP的算法。

## 5. 任务细分保留整数障碍及配置证书

**通用细分引理。** 给每任务恰两端点的实例P和有理H>0，为原任务e=(u,v)新增机器w_e，替换成两个任务e_u,e_v：

\[
p'_{u,e_u}=p_{u,e},\quad p'_{v,e_v}=p_{v,e},\quad
p'_{w_e,e_u}=p'_{w_e,e_v}=H,
\]

其余边不可用。记新实例P'。对n>0及n=0都成立的安全界为

\[
\min\{\mathrm{OPT}(P),2H\}\le\mathrm{OPT}(P')
\le\max\{\mathrm{OPT}(P),H\}. \tag{5}
\]

当OPT(P)∈[H,2H]时，OPT(P')=OPT(P)。n=0时两者实际都为0。**不可**把此等式扩到OPT<H：单任务时间(0,7)、H=1时，原OPT=0，新OPT=1。

上界：原任务在u则e_u留u、e_v放w_e，原任务在v则反之。旧机器负载不变，每个新机器负载H；空任务另行处理。下界：若某个新调度C<2H，则每个w_e至多接一条子任务，至少一条在其外端。任选一个外端恢复原任务，旧机器负载不增，于是OPT(P)≤C。反证给式(5)下界，包含等号OPT=2H的情况。

**配置证书提升。** 给T≥H的原证书，旧机器配置把每个任务换成自己的子任务；中间机器以权x_ve选择{e_u}、以权x_ue选择{e_v}。两权之和1，负载H≤T，每个子任务的两端覆盖和恰1。新机器图简单且二部：每条任务连接一个旧机器与唯一的新机器，每对最多一条任务。因此第4节构造全部z。

大小m'=m+n、n'=2n；处理时间继承原有理数并新增H。即使使用稠密矩阵编码也是输入长度的多项式。给定显式证书的支持总数增加至多2n，位数受原证书和H的编码长度控制。

**证明UM-PAIR-SUBDIVISION-GAP-v1。** 对每k≥4的经典两树实例取H=1，θ_k=2−1/k∈[1,2]。式(5)给细分OPT=θ_k，原T_k=1+1/k的证书提升为两机器完整配置耦合证书。因此

\[
\frac{\mathrm{OPT}(P'_k)}{T_{\rm PAIR}(P'_k)}
\ge \frac{2-1/k}{1+1/k}=2-\frac3{k+1}\longrightarrow2.
\]

所有该LP可行证书投影为普通配置证书，再由UM-ST-ROUND-v1得到OPT≤2T，故上确界也不超过2。这里没有声称T_PAIR=T_k；不需要求出精确阈值。

初态在T_k处每任务仍有两端可用，机器图简单，无单域。第3节末段说明计数闭包没有第一步删除。因此“先做该闭包再解两机器耦合配置LP”的可行性合同同样保留这个间隙。它不能仅凭所得阈值保证统一(2−ε)T的输出。

这是**方法障碍**，不是UM-TARGET-v1的否定。细分新机器的capacity-one信息在单机配置中存在，但仅沿实际共享任务对耦合不足以把它传递回两个旧端点；需要同时涉及路径两端与中间机器的信息。加入真正三机器一致性、先消去这种中间机器、不同松弛或OPT相对分析均未被排除。

## 6. 研究价值、审查与证据边界

新增内容是对一个明确候选的完整“切原族→细分绕过”推导，以及不含knapsack oracle的安全传播接口；不是已知配置gap本身，也不是新近似比。基本条件耦合和细分变换很可能是标准工具的直接应用，新颖性未认证。它们解释了为什么消除单个反例族不足以升级算法：跨端点的信息可被一个局部容量机器隔开。同存档boss4已在公屏消息`485df9a3a60a413b90f14bf3f1242ae4`独立提出更一般的长链细分及固定大小coalition独立见证障碍；本文长度2证明是交叉重构，不以独立发现冒充独占或新颖性。该长链结果不自动排除多机器overlap一致性。

[规范精确审计](../../../tests/audits/unrelated_machines/pair_coupling_subdivision.py)验证实际配置证书、全部机器对耦合、旧证书二阶残差，并对小族穷举全部细分调度、逐一压回。另有独立且不导入规范核心的审计及计数闭包核验；范围、版本、代码哈希、运行命令见[冻结证据](../../../evidence/runs/unrelated_machines/bundle_subdivision_audit.json)。重跑输出到scratch，不覆盖冻结结果。一般命题依赖本文证明，有限计算不替代证明。

实际独立重构、冻结hash、审查发现和仍存异议见[独立审查](../../reviews/unrelated_machines/bundle_subdivision_review.md)。主目标仍OPEN；当前最关键义务是一个跨容量一中间机器保持信息、并在一般多可选机器上位多项式可构造的机制，而不是再对旧两树的局部不等式增加常数余量。
