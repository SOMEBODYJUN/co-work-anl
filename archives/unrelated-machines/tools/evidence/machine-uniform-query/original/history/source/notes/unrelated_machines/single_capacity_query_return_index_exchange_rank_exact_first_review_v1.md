## 2. 单容量语义与全部量词

域中 T、B 为正二进制有理数，T≤B<2T。每个有限内部时间满足 B/2<p_hj≤T。因此任何两件任务若同在内部机器，其总时间>B；任何内部峰≤B的调度都至多每机一件。反之，任意覆盖指定任务集的资格 matching 因各p_hj≤T而给峰≤T的真实调度。

故对每一个指定边界子集 X（不只论文列出的特殊模式），以下三项等价：A∪X可在峰≤B内部执行；A∪X可在峰≤T内部执行；内部资格二分图有覆盖A∪X的matching。此等价只及H，没有推断任何外部机器的负载。B=T也有效。两端严格不等号与上界闭端点均按原文保留。

A可以为空、任意多端、带单端强制位置或任意内部资格；不要求树/环或任何身份对称。无资格的job会使包含它的模式不可行，不破坏条件命题。H若为空，因k≥2，对齐模式不可行，主条件命题为空真；测试封装仍有2k台outside机，未将空H误称完整普通UM的零机实例。

Q、R各自任务身份不同且与彼此、A均不交，确保下面四个边界原jobs均不同。k≥2且i≠j，故任取一对的论证适用，也给全部k(k−1)个错配。

## 3. 独立的 matroid 重构

令N为内部资格二分图在job侧的transversal matroid：job集合独立恰指存在覆盖它的matching。此处只使用标准matching/matroid性质，不用处理时间近似。

固定i≠j，令

    C=A∪(R\{b_i,b_j})，
    x=q_i，y=q_j，u=b_i，v=b_j。

两份对齐见证给C∪{x,v}及C∪{y,u}独立，故C独立。在N/C中，{x,v}、{y,u}独立。尤其u和v都不是loop。Inactive不可行正是C∪{u,v}不独立，所以{u,v}在N/C中秩1，即u,v平行、closure相同。

若{y,v}不独立，因v非loop则y在cl(v)=cl(u)，与{y,u}独立矛盾。因此{y,v}独立；同理{x,u}独立。返回原图，分别得到

    C∪{y,v}=A∪X_(j,i)，
    C∪{x,u}=A∪X_(i,j)

可匹配，因所有真实执行时间≤T，均是原jobs的峰≤T完整内部实际调度。

**Rank截断审计。** 没有假定原图最大matching恰|A|+k，也没有假定H恰满载。N/C的秩可大于2；上述只用两元素独立性和u,v平行。如果想在秩2 matroid中表述，可将N/C截断到2：它有两元素独立见证，截断保留全部大小≤2的独立性。同样，先收缩A再截断到k也安全，因为所有当前边界模式大小恰k、截断不改变这些集合的独立性。不得把截断当成实际删除机器/资格；它只是证明语言，输出仍在原图。

## 4. 不需 inactive 承诺的具体原job增广算法

输入任意两份实际可行对齐调度。按单容量等价，它们是matching M_i覆盖C∪{x,v}、M_j覆盖C∪{y,u}。

1. 从M_i删去x的执行边，保留matching M覆盖C∪{v}。所有C的任务和v仍实际有且只有一个目的机。
2. 在原内部资格图中，从尚未匹配的y做一次标准交替增广搜索；中间只经当前matched jobs及真实有限资格。如果到达M空闲机器，翻转该路径，得到覆盖C∪{v,y}的matching，即错配X_(j,i)。输出此调度。
3. 若y无增广路，则搜索并增广u，得到覆盖C∪{v,u}的matching，即inactive。该步必成功，证明如下。

对第3步，只看原图上job集合C∪{v,y,u}。M大小|C|+1；第二份见证M_j限制本来就覆盖C∪{y,u}，大小|C|+2，所以M不是该图的最大matching。标准增广路定理保证M存在增广路。该图在job侧只有y、u未匹配。y起点的全部增广已在第2步排除，故至少一条从u开始。它只移动C∪{v}中现有原jobs，不需要经过未匹配y；翻转后任务集合恰C∪{v,u}。

此证明涵盖有空闲H机器的情形；不要求两份见证占用同一机器集合，也不要求H恰有|A|+k台机器。交替路径可经过任意多辅助jobs，所有移动都沿原有限端，其真实时间≤T。一次增广只给每台机器至多一件，不会遗漏A或新增匿名占位任务。

**活跃与空闲分支。** 第2步成功时读入y、返回u，得到所需错配；第2步失败时y未被实际放入M，第3步把u加回，所有Q都不在内部，得到inactive。两个分支都没有把原job拆分。原文“至少一项”不声称恰一项：两模式本可同时可行；本算法任选其一。

在inactive不可行的承诺下，第3步的合法输出会矛盾，故第2步必成功。交换i,j运行同一构造给反方向错配。这既证明主要关系，也给它的构造版。

算法可不输入见证：先对两份对齐job集合分别作matching判定并构造，若某份失败就如原文报告；若均成功，按上述构造。这里没有要求在一个对齐模式不可行时仍输出inactive或错配。

## 5. Outside-private 完整封装

对每个具体原边界job j加唯一outside机O_j，互相不同且与H不交，唯一新增资格是j在O_j时间T。A无outside端。给内部输出模式X的matching之后，把每个不在X的边界原job放自己的O_j。

因此每件A、Q、R原job都恰一次：A和X在H，其余边界在各自O_j；每台H至多一件、每台O_j至多其唯一job，所有真实时间≤T。故封装峰≤T。即使内部机器空闲，outside的存在也不影响实际合法性。

这种封装是合法完整ordinary UM矩阵，**但模式X本身仍是对调度边界去向的外部指定/投影，封装没有自动强制这个模式**。尤其不能把“inactive X_∅=R不可行”误解为“所有boundary outside”的调度不可行；后者是另一个模式X=∅，本合同未排除。封装不提供纯身份gadget的物理实现，只验证列出的局部输出可补成全原jobs测试调度。

若真实compiler中多个边界任务外端共享变量机，重新分配使outside jobs集合改变，可能造成外部负载冲突。当前证明没有修补这些负载；只能承诺内部模式的交换。局部矩阵满足单容量并不能推出任意外接公式strict可行。

## 6. 位复杂度、合同边界与结论

资格图由|A|+2k个原jobs、|H|台机器与显式有限资格构成。给见证时最多两次交替搜索/一次成功增广，按显式图规模多项式；不输入见证时用标准matching多项式构造。输出是每个指定模式内原job的具体原机器，outside补全需O(k)条赋值。T、B与p的比较及复制按二进制有理数位长进行，没有依数值或分母展开。dense输入时全部dense项计入输入长度，仍多项式。

本次Exact-only独立重构闭合全部主要数学/算法陈述，未发现standing fatal。它是标准matching交换的直接局部后果，不称新matching定理。主不可能合同是：在固定内部辅助A、每内部机器弱阈值下单容量的网络中，若所有单索引对齐可用且inactive被禁，则同样严格T可用所有索引错配。它不覆盖内部medium/tiny共居、bundle、多尺度、辅助集随模式变化、全局外部负载保护或任何未述fullformula，也不提供一般UM hardness反面。
