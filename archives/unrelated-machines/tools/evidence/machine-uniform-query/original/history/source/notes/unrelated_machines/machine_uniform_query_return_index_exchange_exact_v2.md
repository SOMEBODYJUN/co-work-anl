## 1. 明示局部普通 UM 与所有原任务

给显式有限内部机器集 H，显式辅助原任务集 A，两个边界原任务族 Q={q_1,...,q_k}、R={b_1,...,b_k}，k≥2。A、Q、R 两两互斥，族内任务身份也都不同。全部原任务数 N=|A|+2k。

给正二进制有理阈值 T>0。每台 h∈H 有一显式非负有理数 s_h；任意原任务 j∈A∪Q∪R 的该机条目只能为 s_h 或∞。即一台内部机上的全部有限原端处理时间相同，允许 s_h=0，也允许 s_h>T；不同机器 s_h 可以完全不同，资格图任意。输入可以是稀疏显式有限边或完整 dense 矩阵，但规模均按所用实际完整编码计。没有外加预载、其它任务或逻辑关系。

全部 A 必须在 H 实际执行。对边界子集 X⊆Q∪R，称 X 为 strict 可行内部模式，当且仅当 A∪X 的每枚原任务整件且恰一次合法执行于 H，所有 H 的实际负载同时≤T。边界中其它任务必须在接口外部执行；不把它们丢弃、复制或拆分。

可用以下完整普通 UM 的测试封装显式实现“其它任务在外部”：每个边界原任务 j 新增互异私有 outside 机 O_j，仅该 j 可在 O_j 以时间 T 执行；A 没有 outside 端。模式要求恰 X 使用 H、其余边界 jobs 在各自 O_j。这时内部可行等价该模式全部 N 枚原任务的完整实际峰≤T。但若真实归约将这些 outside 端接到变量环或其它共享原机器，本 Claim **仅保证内部可替换性**，不保证改后的外部模式与锁定负载可全局扩展。

## 2. 模式与精确结论

定义 inactive 内部模式 X_∅=R；aligned_i 模式 X_i={q_i}∪(R\{b_i})；mismatch(j,i) 模式 X_{j,i}={q_j}∪(R\{b_i})。这些模式明确读具体原 q_i 与 b_i 的实际身份，而不是机器是否有某件 unit 的 presence。

对每个上述显式输入，任意不同 i,j：

    若 aligned_i 与 aligned_j 在 T 可行，而 inactive 在 T 不可行，
    则 mismatch(j,i) 与 mismatch(i,j) 均在同一严格阈值 T 可行。

特别，所有 k 个 aligned 模式在 T 可行且 inactive 在 T 不可行，便强制全部 k(k−1) 个错配模式都在 T 可行。若一个 weak 阈值 B≥T 的接口合同禁止 inactive，则 inactive 在 T 也不可行；因此它不能同时要求“每个索引可选择、必须查询、而所有≤B模式的 query 与 return 必同索引”。B 可任意显式有理数≥T，不另假设 B<2T。

精确构造算法：给任意两份 aligned_i、aligned_j 实际 strict 内部调度，可确定性总位多项式输出以下至少一项：

1. inactive 在 T 的完整内部实际分配；
2. mismatch(j,i) 在 T 的完整内部实际分配。

交换 i,j 得另一方向。输出内部模式含全部 A；测试封装中再将不属内部模式的每枚边界任务放自身 O_j，便输出所有原 N 件任务恰一次的完整实际峰≤T 分配。对不提供两份调度的输入，算法也可先按显式资格求 strict 模式判定及匹配，找到见证或可靠报告某个 aligned 本身不可行；没有计算隐藏全局源解的前提。

## 3. 时间与容量的位复杂度合同

每台内部机的 strict 整数任务容量可取

    c_h = min(N, floor(T/s_h))   (s_h>0)，
    c_h = N                     (s_h=0)。

若 s_h>T 则 c_h=0；空 H 或零容量行允许，可能令前件不可满足而非产生非法算术。s_h=0 单列处理，无除零。N 是实际显式任务数，所有容量都截断到 N。

算法只需使用这些有理比较/整数除法与显式容量匹配。可以直接使用容量网络；即使选择把每机展开成 slots，也至多 |H|N 个，不按未截断 T/s_h、时间分母或二进制参数数值生成巨大对象。所有有理/整数位长、资格扫描、模式检查、全部任务实际目的地输出与负载回算按总输入编码长度多项式。没有有限枚举充当一般证明、也没有新增通用软件。

## 4. 已有范围、技术扣除及未覆盖机制

单容量 v1 的内部端满足 (B/2,T]、T≤B<2T 时，strict 每机至多一件。该情形不要求逐机的有限时间完全相同，但其 strict 可行模式仍只由资格匹配决定，因此可先把有限时间统一为 T 而不改变可行模式，再适用此版容量交换。此句是 strict 模式的特例关系，不声称两版输入矩阵逐项相同。
