# 给定目标不能被免费删除：两机 Partition 搜索障碍

## 精确障碍

考虑 `UM-PERMANENT-BUFFER-HELD-CYCLE-PATH-v1` 的输入矩阵，但把具体目标 `τ` 从输入中删除，只保留初态 `σ`、阈值 `T` 和矩阵。要求一个确定性位多项式程序在所有“存在某个目标调度 `τ` 满足 `C_max(τ)≤T`”的实例上构造这样的 `τ`（随后再调用给定目标路径构造器）。这个搜索义务已经包含 NP-hard 的 Partition，不是正文路径证明可以自动提供的步骤。

给定 Partition 实例 `w_1,…,w_n∈Z_{>0}`，`Σ_j w_j=2B`、`w_j≤B`，令 `T=2B`、两台机器。加入两个 anchor 任务 `u_1,u_2`：`u_1` 只有机器1可用且时间 `B`，`u_2` 只有机器2可用且时间 `B`。每个 residual 任务 `j` 在两台机器上的时间均为 `w_j`。取初态 `σ` 把 `u_1` 及所有 residual 放在机器1，把 `u_2` 放在机器2。则所有已用端和所有有限端均不超过 `T`，`C_max(σ)=3B≤2T`；机器1的实际最大件为 `M_1=B` 且 `S_1=3B=T+M_1`，机器2有 `S_2=M_2=B≤T+M_2`，所以正文的实际最大件局部 promise (6) 甚至成立。目标容量 `T` 被 anchors 各占 `B`，因而存在 `τ` with `C_max(τ)≤T` 当且仅当 residual 权重能分成两组各和 `B`，即原 Partition 有解。候选 `τ` 的负载与 anchor 可行性均可在输入位长多项式时间验证。

因此，若有一个总位多项式算法在承诺“某个 `τ≤T` 存在”时输出未知目标，即使保留正文的局部 promise，也能通过验证输出在多项式时间内解 Partition（除非 `P=NP`）。若算法还要在无解实例报告不存在目标，则直接给出 Partition 判定器。这个构造的 `H` 为空（`U=2T`，故 `h_i=0`），所以它不攻击给定 `τ` 的三阶段容量证明；它准确说明未知目标选择是独立的全局整数搜索义务，而不能从路径构造器接口中删去。

## 与局部 promise 的关系

这次加 anchor 的构造明确满足 `S_i≤T+M_i`，因此把未知目标搜索限制到正文的实际最大件局部 promise 仍然保留 Partition 障碍。与此同时 `H` 为空（`h_i=0`），路径定理在给定目标时只处理普通安全迁移；该事实不反驳给定 `τ` 的三阶段证明，也不声称局部 promise 下不存在其他目标选择算法。它准确限制的是把给定目标当成“可由输入矩阵和 `T` 免费生成”的推论：至少需要一个独立的全局整数选择/舍入定理，不能从 held-cycle 三阶段证明中删除 `τ` 量词。

## 可复用结论

- `held_cycle_path` 的输入接口必须继续显式接收完整 `τ`（或等价的全局整数证书）。
- “存在容量 `T` 的目标”与“能在多项式时间找到该目标”应分成两个 Claim；前者是可行性承诺，后者是搜索义务。
- 该障碍没有数学真值升级：它基于标准 Partition 复杂度假设，仅排除无条件的多项式目标生成，不排除配置 LP、随机/准多项式或附加结构下的目标选择。
