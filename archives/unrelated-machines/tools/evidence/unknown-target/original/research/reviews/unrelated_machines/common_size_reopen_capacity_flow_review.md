# 共同尺寸可重开容量流的独立复核

复核先按 `UM-COMMON-SIZE-REOPEN-v1` 的精确输入重构，再检查 Fraction 反例和整化条件。结论只覆盖给定冻结核心、共同尺寸资格边和有理流证书，不涉及从一般矩阵寻找该结构。

若残余任务 `j` 在资格端均耗时 `q_j`，有理流 `x` 满足列和1且机器分数负载加 `q_max` 不超过剩余容量，则有序槽匹配给出实际整任务，允许接收机增载；更精确的支持最大项 `r_i(x)` 条件同样成立。若每个支持连通分量内 `q_j` 相同，可改用整数槽位最大流，消除 `q_max` 加性余量。一般端点时间不能用每任务最小值代替：两机三任务的 `p=[[2,100,2],[100,2,2]]` 在容量3下整型不可行，但错误的最小值流会报告分数可行。等端两机三件 `q=2,b=(3,3)` 则分数容量通过而整型峰值为4，说明流证书不是整性。

一般矩阵可分流的 Farkas 价格条件

`Σ_i λ_i b_i ≥ Σ_j min_{i:p_ij<∞}(λ_i p_ij)`

是有理 LP 的精确判定/阻塞证书；它不是不可拆分调度的充分条件。

审计脚本使用 `Fraction` 穷举8个分配状态及显式价格差，覆盖上述边界。有限审计不升级一般算法，且统一 `q_max` 头部余量可能回到经典二倍界。
