# 对象身份与增量关系

本批三源不是新模型。它们都处理同一个固定两目的地 unrelated-machines 参数族：每个 query q_r 只有 H_r:a_r 与 A_r:1 两个有限端，每个 x_r 只有 A_r:1 与共享 R:b_r 两个有限端，收费任务 f 只有 R:c 与 S:1 两个有限端；所有原任务必须完整执行。pattern K 只把 q_r 的 owner 指定到 A_r，费用只计算 f 是否真正由 R 改到 S，x_r 的权为零。

已有正文《多见证共享作业费用与共同容量精确合同》已经承载同一族的精确公式、两批冻结 JSON 审计和边界。本文只记录本次新读三份文字的独有审查层，避免把作者证明、程序源码审读、Exact-first 重构重复当作新定理。三源的共同稳定结论是在声明域内保留：原实例 OPT(P)=1；任意 pattern 的 OPT_K=min(2,max(1,B_K))，其中 B_K=sum of b_r over r in K；闭阈值 1<=beta<2 的费用按 B_K、c+B_K 三分支；多 singleton 不自动形成一个共同全开 strict-1 见证。v1 的空集严格不等式错误由 v2 限制为非空 K 修复，旧字节仍保留。

# 作者 Proof v2：完整证明承重处

作者证明不是一句“共享 R 容量”直觉，而是逐任务给出完整 actual。

1. 初态 sigma_0 将 q_r 放 H_r、x_r 放 A_r、f 放 R，逐机负载不超过 1。若完整峰小于 1，则 x_r 不能在其 A_r 的 unit 端，f 不能在其 S 的 unit 端，所以所有 x_r 与 f 被迫同在 R；条件 c+sum b_r>=1 给出 R 下界，得到 OPT(P)=1。
2. 对每个 singleton r，sigma_r 只改变 q_r 到 A_r、x_r 到 R、f 到 S，其余原任务保持初态。这是完整 actual，峰为 1，且 query owner 改变集合恰为 {q_r}。证明明确不把 singleton 列表拼成一个共同 sigma_1。
3. 对任意 K，作者给出 f 改到 S 的上界和 f 留在 R、把 q_K 与原 x 同放 A 的上界。小于 2 的任意 actual 中，q_r 在 A_r 已占 unit，故 x_r 必在 R；这给 R 至少 B_K 的必要负载。若 B_K>=2，第二构造达到峰 2；若 B_K<2，第一构造达到 max(1,B_K)，从而得到精确 OPT_K。
4. 对闭阈值 beta，B_K>beta 直接不可行；B_K<=beta 且 c+B_K<=beta 时 f 留在 R 的费用 0 构造可行；B_K<=beta<c+B_K 时 f 必须到 S，费用 1 构造同时给出上界。作者单独处理 beta=2，避免把严格小于 2 的强制论证越过等号。
5. 容量 s 只是把 b_r 取为 1/s，因而 B_K=|K|/s；非空 K 的 singleton 必收费时逐项得到 |K|(beta-c)<B_K<=1。作者明确空 K 不可放入这个严格求和，正是 v1 的失败机制。

证明的适用域仍是显式两目的地、互异机器、完整原任务和正有理参数。它没有给 generic LP、source decoder、跨实例预算、NP-hardness、近似比或任意 unrelated-machines 输入的结论。

# Exact-first 独立重构：唯一缺口与修复

59d6a0427b206c6125eb 先只读 v2 Exact 而不调用作者 Proof，自行重建原实例下界、pattern 的 `<2` 正规化、OPT_K 和闭阈值费用三分支。它在 v1 语句中找到唯一明确缺口：第 7 项没有声明 K 非空，空模式满足前件真空而 B_empty=0，导致错误的 0<0。修复后，独立重构在声明域没有发现 standing fatal。

重构还明确了几个容易被错误升级的量词：

- `<2` 只强制 q_K 对应的 x_K 去 R；它不授权把未选 x_r 从完整 actual 中删除，也不把 R 改写成匿名容量。
- `B_K>=2` 时可用 q_K 与 x_K 同在 A 的峰 2 构造，因此 OPT_K 的截断值 2 是完整 actual 上界，不是只由必要条件推出。
- beta=2 时 f 可留 R，不能沿用 `<2` 的收费强制；beta<1 时由 OPT(P)=1 所有 pattern 都不可行。
- 均匀容量 s>=2 且 beta>=3/2 时 singleton 可能 fee 0，这是共享并发容量吞掉近 2 收费门槛的真实边界，不是程序失效。
- 原实例所有非 query 费用只有 f 的权 1；多个 singleton 的费用重复触发同一 f，不是把 p 个不同任务的费用相加，也不是一个共同全开见证。
