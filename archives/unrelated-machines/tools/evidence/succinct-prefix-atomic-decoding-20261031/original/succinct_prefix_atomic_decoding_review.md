# 前缀原子证书解码桥的独立审查

审查对象：`UM-PREFIX-ATOMIC-DECODING-v1`，正文 `research/current/unrelated_machines/succinct_prefix_atomic_decoding_bridge.md`。

## 先陈述再重构

给定部分分配前缀权 `π(S)`，要求空前缀为 1、one-hot 守恒、非负前缀权和完整原子满足逐机局部化。逐任务选择任意正延伸；最后正权原子必须逐机负载不超过 `T`。

## 独立核对

对当前前缀 (S)，未处理任务 (j) 的所有延伸权之和等于 `π(S)`，故只要当前权为正就至少存在正延伸。完整前缀的正权由局部化不等式排除超载机器。查询次数至多为有限端数，精确有理比较不依赖枚举完整调度集合。

边界逐项核对：空任务直接返回；`T=0` 时正负载原子权被局部化器强制为零；零处理时间端不引入除法；不可用端不在任务域中。两机三件单位任务、`T=1` 的 8 个完整分配均有机器负载 2，因此所有原子权都必须为零，与权重总和 1 矛盾。

## 独立精确运行

审计程序 `tests/audits/unrelated_machines/succinct_prefix_atomic_decoding.py` 使用 `fractions.Fraction` 构造 Dirac 与均匀证书，运行前缀贪心并逐机重算负载。结果包括可行两任务例负载 `(1,1)`、`T=0` 零负载例、不可行两机三单位任务的全原子排除，以及 5 个异质 Dirac 例全部通过。

## 结论与限制

证明没有把查询器的生成或全阶局部化器的指数验证偷换成多项式算法。它相对全阶矩提取桥的真实增量是：把指数原子族替换为可调用的前缀评估接口，并给出线性于端数的确定性解码。由此留下的唯一主桥义务是：从任意 `P,T` 生成该接口，或生成可核验的 `FAIL⇒OPT>T`；现有半单位选择 NP 障碍说明不能把它当作免费 oracle。未发现声明范围内的逻辑漏洞；外部评审和新颖性未记录。
