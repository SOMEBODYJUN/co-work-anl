# 逐玩家归一化菜单的 unit／tiny 阈值保真与指数规模：冻结 Exact v1

候选 ID：UM-NORMALIZED-XOS-THRESHOLD-MENU-SIZE-OBSTRUCTION-v1。

状态：独立精确陈述，供新的 Exact-only 审查者先行重构；本文件不含作者证明。它是显式逐玩家归一化转换的规模下界，不是一般 Santa Claus、UM 或全局源归约的不可能性。

## 对象与参数

固定任意有理常数 η∈(0,1)。对每个整数 t≥1，令 U 为含 N=2t 个不同资源的集合，并令

    d=⌊ηt⌋，   r=d+1。

因此 0≤d≤t−1，1≤r≤t。允许 ηt<1，此时 d=0、r=1，不把该退化误写成需要至少两个资源。

给 K≥1 个显式 indexed 加性 clauses。clause s 的系数为非负有理 w_{s,u}（u∈U），满足

    Σ_{u∈U} w_{s,u}=1。

系数可以为零，indexed clauses可以重复。归一化排除了全零 clause；若一个外部表示额外列了冗余全零 clause，可先删除，不改变下面 f，且只会减少其表示规模。定义归一化 XOS 菜单值

    f(B)=max_{s∈[K]} Σ_{u∈B}w_{s,u}，   B⊆U。

要求同时满足以下两个逐集合保真条件：

1. 对所有 T⊆U、|T|=t，有 f(T)=1。
2. 对所有 B⊆U、|B|≤d，有 f(B)≤η。

这些是对全部集合的数学量词，不把指数多个 T/B 显式列成输入。

## 精确结论

每个满足上述条件的显式菜单都必须有

    K ≥ binom(2t,t) / binom(2t−r,t−r) ≥ 2^r。

若保留额外冗余全零 indexed clauses，同一下界已由非零归一化 clauses承担，故总 indexed 数也满足该界。重复 clauses和零系数不能绕过结论。

特别地，对任何先固定的 η>0，随显式资源数2t增长，有 K≥2^{⌊ηt⌋+1}，所以该菜单不能以源输入长度的多项式规模显式输出。没有声称当η随输入趋零时仍有统一的指数常数，也没有声称上述下界对所有η,t精确达到。

## 对逐玩家 source normalization 的严格含义

考虑一名普通加性玩家，每个 u∈U 的原值均为1/t。其显式输入只有2t个条目，各值和资源编号用 O(log(t+1)) 位，总长度 O(t log(t+1))。所有 t-subsets 原值为1，所有至多d个资源的集合原值≤d/t≤η。

若某逐玩家转换要求在同一资源宇宙U上，用非负、总量恰1的显式 XOS clauses同时保住这两类阈值，那么上式给出指数状态数量，排除了这个普适的显式多项式归一化 shortcut。没有允许辅助资源、额外玩家或全局一致性约束被偷偷写入此接口。

此结论不排除：使用额外资源或玩家的全局归约；只在特定可达分配上保真；不要求全部t-subsets都达1；允许unit YES损失；保留未归一化 clauses；使用另一种经证明可计算的隐式表示；或从特定源直接构造归一化菜单。尤其，它不提供 normalized YES V=1／NO V≤η 的 hardness 源，也不把一般 Santa Claus 的 degree reduction 自动转成该源。
