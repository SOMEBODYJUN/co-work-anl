# 全局基数匹配探针与紧凑共享逃逸间隙

主目标UM-TARGET-v1仍OPEN。本文完成“保留资源任务身份、多槽匹配能否修复共享容量”的接口核验：全局基数匹配给安全的位多项式过滤，固定全行下界时一次查询已涵盖所有资源子池；但一族多项式规模的实例同时通过全部查询、全部单机配置条件计数见证及GPC₂，整数最优值仍趋近2。第7节进一步证明每一合法单机配置都可分别强制并延伸到完整配置LP；仍不排除共同条件分布、跨机器同时容量或OPT相对算法。

来源：匹配子程序是[GHMR的任务权增广](heavy_matching_residual_and_escape.md)的标准容量扩展；紧凑族是[容量一资源星](minimal_star_contraction_and_capacity_gap.md)加全局激活缺口及低成本共享逃逸，本轮主研究者直接构造、内部审查者独立重构。共享逃逸的机制来自boss3既有族及其公屏162的低成本参数攻击；本稿不用两树/高度放大。原资源机制见BLMRS原文§2.1.2，已取得版本/定位沿用manifest。没有全球新颖性、独立论文价值或外审认证。

## 1. 精确的全局单行查询

对象为UM-MODEL-v1。输入合法P、有理T≥0；初始域D_j={i:p_ij≤T}，空域拒绝。当前域只删边。令n为任务数，对每机器i定义

\[
 h_i=\min\{p_{ij}:i\in D_j\},\qquad
 c_i=\begin{cases}0&\text{空行},\\n&h_i=0,\\
 \min(n,\lfloor T/h_i\rfloor)&h_i>0.
 \end{cases} \tag{1}
\]

每个当前T调度在i上至多安排c_i个任务；c_i只是必要基数上界，不是负载容量。

对每个存活边j→v，固定它并去掉j，暂时禁止其余任务放v。令

- Q_vj={a≠j:v∉D_a}：必须在v外完成的任务；
- B_vj={a≠j:v∈D_a}：可留v或外送的任务，任务权w_a=p_va。

在机器M\{v}上以容量c_i找覆盖全部Q_vj的b-matching，并最大化被匹配B_vj的总权W。没有这样的匹配，或

\[
 p_{vj}+\sum_{a\in B_{vj}}p_{va}-W>T, \tag{2}
\]

就标记删除j→v。同步删一轮，重算(1)，至拒绝或无删除。称为**全局单行基数过滤**。查询中的匹配给一个全部任务分配：匹配任务去对应外机，未匹配B与j留v。它仅保证v的真实负载最小、其他机器任务数≤c_i；其他机器真实负载可能超过T。

`UM-GLOBAL-ROW-COUNT-FILTER-v1`：对所有上述P,T，该过滤确定性总位多项式，保留每个T可行调度的全部边；拒绝蕴含OPT>T，接受没有调度保证。

**安全性。** 若当前域保留T调度σ且σ(j)=v，将σ中去v外的任务限制到Q及B，得到覆盖Q的容量匹配。σ在v的真实负载不小于(2)左侧。因此不删σ的边；同步删边及重算row min仍保σ，归纳成立。T=0只剩零边，c_i=n或0，逐任务任取零边即零调度；空任务直接给空分配。

**精确匹配与总位长。** 每机器复制c_i≤n个槽，任务只能用其当前域对应的槽。先增广覆盖Q，再将B按非增p_va依次增广，不能增广则跳过。覆盖Q的可增广集合是收缩横截拟阵；也可直接用GHMR的每权前缀最大基数证明，得到最大任务权。任务权依赖a而非目的边，不能把此贪心扩大到任意边权。每查询至多n次增广，图至多mn槽及ne条边（e为原存活边数），均多项式。非终止轮至少删一边，查询总数≤e(e+1)。h_i来自输入，floor用精确整数除法，c_i截断n避免复制二进制巨大容量；权和的公分母位长至多输入分母位数总和。输出过滤域/见证均为多项式大小。规范代码不实现通用近似算法或目标搜索。

### 为什么无需枚举同一下界的全部资源子池

固定全行有效下界H_i≥0及由其得到的同一组c_i。对任意R⊆M\{v}，子池查询只保留D_a⊆R的必选任务及v∈D_a、D_a\{v}⊆R的可外送任务，按同样权最大化卸载。若全局查询有v负载≤T见证，限制该匹配到子池上述任务：每个必选任务仍在R，匹配的可选任务也必在R；未匹配可选子集的非负权不超过全局未匹配总权。因此子池也通过。全局R=M\{v}本身是一个子池，故全局查询恰支配全部这些R查询。

此处H/c必须固定。若每个子池依据仅涉其内的任务重新提高H_i，就不是本等价合同；不能声称本过滤支配这些更强规则。(1)用全当前行min，是针对该行的最大通用逐任务下界。

## 2. 多项式规模的紧凑族

固定整数k≥2，N=2k²，G=N−2k。机器：N个中心V_a、G个全局机G_g、每块a的k+1个局部机R_a,ℓ，以及一个共享机z。任务如下，其余边不可用。

| 任务 | 全部有限时间 |
| --- | --- |
| X_a，a∈[N] | V_a及全部G_g，均1 |
| Y_a,s，每块k个 | 本块全部R_a,ℓ上1，共享z上1/k |
| Z_a,s，每块k个 | V_a上1/k，本块全部R_a,ℓ上1 |

机器数m=2k³+6k²−2k+1，任务数n=4k³+2k²；显式稠密或稀疏输入均为k的多项式，数值仅{1/k,1,∞}。与前稿k块/缺口1族不同：本稿是N块/缺口2k，加共享z，故另立身份。

**整数最优θ_k=2−1/k。** 假设B<θ_k<2。每全局机至多接一个X，故至少N−G=2k个中心收到X。每个这样的中心若保留≥k−1个Z，负载至少θ_k；所以至少两个Z去本块R。k+1台R每台至多接一个单位任务，k个Y中至少一个必须去z。至少2k个不同块各送一Y，z负载≥2k/k=2>B，矛盾。上界：选任意2k个活跃块，X留中心、一个Z去本块R、其余Z留中心，k个Y占其余k台R；其他X分别给G，其他块全部Z留中心、Y用k台R，z空。最大负载恰θ_k。

## 3. 完整配置及全部两机器见证

T=1时，V_a选{X_a}权1/k、选全k个Z权(k−1)/k。每G_g对每X_a选单项，权1/N。每R_a,ℓ对每Y_a,s选单项权1/(k+1)，对每Z_a,s选单项权1/[k(k+1)]；z总选空。机器权和1，所用配置负载≤1。X总覆盖为1/k+G/N=1，Y覆盖1，Z覆盖(k−1)/k+1/k=1。

GPC₂沿[前稿§4](minimal_star_contraction_and_capacity_gap.md)的完整单机边际/不双选合同。G–G将X_a和X_(a+1 mod N)配对，权1/N。相同块R–R及V–R沿前稿公式（仅使用块内k，不使用总块数）。V_a–G的耦合为：

\[
\begin{array}{c|c|c}
V_a&G_g&\text{质量}\\\hline
\{X_a\}&\{X_b\},b\ne a&1/[k(N-1)]\\
\{\text{全}Z_a\}&\{X_a\}&1/N\\
\{\text{全}Z_a\}&\{X_b\},b\ne a&1/N-1/[k(N-1)].
\end{array} \tag{3}
\]

N=2k²、k≥2保证末项非负。左首行总量1/k，每个右列1/N；所有正质量配置不交。其余机器对支持任务集不交，取乘积，包括所有与空z的pair。故GPC₂(1)可行。没有声称这些pair可共同拼为全局分布。

## 4. 每一机器都可以在全局基数见证中完全空置

初始row min在V及z为1/k，c=k；G及R的row min为1，c=1。下面构造**全部任务避开任意指定机器v**的分配，只满足这些任务数上界。它不是T调度。

基线：选2k个活跃块，按整数上界调度分配。活跃中心接X及k−1个Z，总任务数k；非活跃中心接k个Z；所有G/R至多一任务，z空。

1. v=V_a：选2k个不含a的活跃块，X_a给某G（N−1≥2k且G≥1）。块a的k个Z占k台R，一个Y占余下R，其余k−1个Y给z，任务数≤k。其他块按基线。X总数及全局槽数恰配平。
2. v=G_g：选2k+1个活跃块，其余X用剩余G；每活跃块只外送一个Z，其他照基线。N≥2k+1。
3. v=R_a,ℓ：使a非活跃、选2k个其他活跃块；块a的全部Z留中心，k个Y恰用其余k台R。
4. v=z：采用基线。

全部数目不等式在k=2也成立。给任意存活边j→v，从该avoid-v分配移除j并给v，其他机器计数只减，v真实负载仅p_vj≤1。因此全部边的第1节精确最优查询均通过，首轮零删除。

还有更强的准确结论：对**任意**机器v及**任意**C∈C_v(1)，从avoid-v分配移走C并把C完整放v，就得到“v精确取C、其余机器仅按c计数”的全部任务见证。故即使检查每一个单机配置的这种全局计数延伸，本族也通过；此句不假称指数多配置检查可多项式实现。见证在v满足真实负载，在其他机器不满足一般负载约束。

极小超载星无起点：中心删一个最小Z后仍θ_k>1；G删一项后N−1>1；R删一项后2k−1>1；z删一项后N−1/k>1。每任务至少四可用机器，既有单/双域计数闭包也无起点。因此与这两种预处理交替仍无变化。

`UM-COMPACT-COUNT-ESCAPE-GAP-v1`：上述全部k≥2族满足OPT=θ_k、GPC₂(1)可行、极小星与既有计数闭包无起点、全局单行基数过滤首轮不删边，并有每机每配置的计数延伸见证。故这些必要条件的合取不允许相对接受T统一保证(2−ε)T（任何固定ε>0，取k>1/ε）。仅配置投影/ST已给任意接受实例OPT≤2T；若先消元，则用原消元定理恢复到max(2T,T)=2T。所以该合同在正OPT输入上的上确界gap恰2。无须声称接受对一般T单调、阈值可多项式求得或T_CONF在本族恰1。

## 5. 失败机制、核验与下一义务

这不是再次遗漏资源任务身份：全局匹配已覆盖所有没有v的任务，容量亦允许多槽。失败在其他机器的任务数不是共同真实负载：活跃中心能在计数k内接一个X及k−1个Z，却有负载θ_k；一个查询可以把这类超载移到其他中心。z的k槽只在当前被精确检查的中心确需全部卸载时使用，其他查询不保同一个负载见证。所有单机配置分别通过仍不修复这一点。

可回收：安全精确查询、全池支配同下界子池的引理、多项式规模攻击族、显式完整pair和avoid-v证书。重试必须让多个中心的激活/卸载与共享z容量**共同**成立，或引入与该计数见证不同的信息；不能把逐机最优匹配拼成调度。通用条件块切面分离、可求解耦合与统一舍入仍未闭合。

已有[条件块计数机制](joint_matching_completion_and_block_cuts.md)也能修复本族，不能宣称本文绕过它。对1≤B<θ_k，设r_B=k−⌊k(B−1)⌋≥2。每块有效切面是Σ_s x_(z,Y_a,s)≥(r_B−1)x_(V_a,X_a)，因为X在中心时至少r_B个Z外放，k+1局部槽迫至少r_B−1个Y去z。全局G的单位槽给Σ_a x_(V_a,X_a)≥2k，于是z分数负载≥2(r_B−1)≥2>B，任何配置证书都被排除；B=θ_k由整数调度可行。因此沿用该机制可恢复本族阈值恰θ_k。这只是旧条件块证明的直接适配，不另立新成果；剩余义务是一般可分离性/统一舍入。

规范审计：`tests/audits/unrelated_machines/row_count_probe.py`枚举小矩阵，独立全分配oracle核每次查询的精确最小行负载及过滤安全；`compact_count_escape.py`核配置/全部pair，实际运行k2全部边查询；`independent_row_count_escape.py`不导入上述实现，独立构造全部avoid-v分配、pair校验与单块真实转移的精确对称DP。实际参数、Python版本、源hash、运行命令、有限范围和未查范围在`evidence/runs/unrelated_machines/row_count_escape_audit.json`；输入k2与单机配置证书分别存examples及certificates。所有运算为Fraction/整数，无误差容忍；有限计算不是普遍证明。冻结独立审查见`research/reviews/unrelated_machines/row_count_escape_review.md`。

Truth：声明范围有自足证明并按实际覆盖独立攻击。Value/Mechanism：明确完整身份/多槽仍不替代多机共同负载。Novelty：标准匹配与已有资源机制的专门接口扩展，全球新颖性未认证。Ambition：没有统一近似突破；下一步应攻共同条件容量，避免继续只加强逐查询最大撤离值。

## 6. 同时检查真实负载的精确中心预算

本节另立`UM-COMPACT-MULTIROW-EXTENSION-v1`，不改变前两个v1的身份。仍仅研究第2节的显式族。设V为全部N个中心，G=N−2k。给任意机器集U、被固定机器v∈U及任意C∈C_v(1)，要求完整分配σ同时满足：

\[
 \sigma^{-1}(v)=C,\qquad L_i(\sigma)\le1\ (i\in U),\qquad
 |\sigma^{-1}(i)|\le c_i\ (i\in M). \tag{4}
\]

这里所有机器仍守同一初始row-min计数，U中的机器再守真实负载；不同(U,v,C)不要求共享见证或多机边际。不是条件配置LP或完整交叠层级，不主张求解一般(4)的多项式oracle。

**精确命题。** 对每k≥2，若|U∩V|≤G，则对每v∈U、每C∈C_v(1)，均可用下列确定性显式构造输出(4)见证，运行时间按族的实际编码长度为多项式。这个统一预算G是尖锐的：存在|U∩V|=G+1、v=z、C=∅使(4)不可行。

**构造骨架。** 设O=V\U，所以|O|≥2k。基线选2k个O中心活跃，按第2节达到调度分配；只有这些O中心真实负载可能超过1，其余机器已同时守真实负载。以下“活跃”只指X留在自身中心。若某个必须守真实容量的中心b需额外活跃，就令它只接X_b，全部k个Z外放R，一个Y留R、其余k−1个Y去z；称为一次完整卸载。b负载1，局部R各一单位，z负载(k−1)/k<1。以下各分支最多一次完整卸载或等量局部卸载，不能在多个分支同时借用z。

- **v=V_a。** 单机配置只能是{X_a}或Z_a的子集。若C={X_a}，使a完整卸载，再选2k−1个O中心按基线活跃；其余X恰用G台全局机。若C⊆Z_a，X_a给G，选2k个O中心活跃；设d=k−|C|，将其余d个Z给d台R，再把max(0,d−1)个Y给z，其余Y给剩余R。v恰取得C，z至多接k−1个Y。
- **v=G_g。** 若C={X_a}，需选2k个活跃中心并避开a。若O\{a}够用，全部从中取；否则|O|=2k、a∈O，用O\{a}并从U∩V取一个b完整卸载。此时U∩V非空且b≠a。把X_a固定给v，其余非活跃X双射到剩余G。若C=∅，需2k+1个活跃中心；O够用就全取O，否则用全部2k个O及一个U中心b完整卸载，剩余X恰占G−1个全局机。
- **v=R_a,ℓ。** 若C=∅，使a不活跃，选2k个O中心但避开a；唯一可能的短缺仍是|O|=2k、a∈O，此时用一个U中心b完整卸载补位。块a全部Z留中心，k个Y占其余k台R。若C是一个Y，可排列本块Y，使该任务在指定R；若本块活跃，外放的一个Z用另一台R。若C是一个Z，则以该Z为本块外放任务，k个Y用其余k台R；本块未活跃时其余Z留中心、X给G，仍合法。其余块按基线，不需额外完整卸载。
- **v=z。** C是至多k个Y。从基线中将这些Y直接移到z，其他负载只减，且z恰取C。

这些操作只重排真实任务，保每机计数；所有U中心均不活跃或只接X，单个局部卸载产生的z总负载不超过(k−1)/k，z分支则不超过1。G/R单位时间下计数等于真实负载。边界补位b只在O恰2k且需避开一个O中心或空置一G时出现，此时|U∩V|=N−2k≥1，故存在，并且b不在被固定R的块。构造扫描任务与机器即可，不枚举U或配置族。

**尖锐反例。** 取G+1个中心加入U，并令z∈U、v=z、C=∅。此时Y必须全部去R。若某U中心接X，真实负载≤1迫全部k个Z去本块R，加上k个Y共2k个单位任务，但仅k+1个单位槽，k≥2时不可能。因此所有X只能去G台全局机或其余2k−1个自身中心，合计至多G+2k−1=N−1个X槽，不能覆盖N个X。其余U可取空或加入全部非中心机器，矛盾均保持。更多中心被要求真实容量时同样不可行，故G是上述全(U,v,C)命题的精确最大中心预算。

**含义和边界。** 即使把全部非中心机器都放进U，并让除2k个中心外的所有机器同时守真实容量，每个单独配置pin仍有见证；所有机器全都守真实容量却不可能在T1完成。任意固定r的独立r机器真实容量/单配置探测也不能单凭这一合同统一低于2，因为取k使G≥r即可通过全部查询而OPT→2。见证之间未保共同相关性，不能把此命题说成全层级或一般算法障碍。有限审计与追加冻结攻击由`multirow_count_extension.py`、`multirow_count_extension_audit.json`及原审查末节连接；前阶段冻结证据和hash不改写。

## 7. 完整单机配置也分别能延伸到完整配置LP

本节新增 **UM-MACHINE-CONFIG-PROBE-GAP-v1**。它把第4节的“其余机器仅守计数”加强为真实配置LP延伸，原两个Claim的身份不改。本节复用boss2在第2节已入库的紧凑族；新增贡献是全部单机配置的**真实配置LP延伸**，不是再命名一次反例族。boss1先从低成本深树的条件配置探针出发，收到boss3的路径修复后独立核查，再在本族找到以下紧凑证书；不把来源组件算作独占新结果。

### 7.1. 精确合同、结论与有限边界

对合法P和有理T≥0，称其通过完整单机配置探针，如果

\[
\forall i\in M\ \forall C\in\mathcal C_i(T)\ \exists y^{i,C}:
\quad y^{i,C}\text{满足原始完整配置LP，且 }y^{i,C}_{i,C}=1. \tag{MP}
\]

每个延伸点在**全部**机器满足配置容量、归一化和逐任务覆盖；固定机器的配置恰是C，因而C外的所有任务在该机边际为0。不同(i,C)允许不同的完整y，既不要求共同未条件化y，也不要求跨探针的联合分布。即使能够检查指数多个C，本合同也不包含这些额外一致性。只反复删去无延伸的配置，在下面实例没有第一次删除。

**Exact Statement。** 对每个整数k≥2，第2节同一个多项式规模实例在T=1通过(MP)，且OPT=2−1/k。因此在正OPT输入上，满足(MP)的实例/目标对的sup OPT/T为2。第3节GPC₂、第4节过滤无起点与(MP)可以在同一实例同时成立，**不声称每个条件延伸也满足GPC₂或嵌套过滤**。

(MP)是本族的强性质，**不是一般T整数可行性的必要条件**：可行实例也可能有某个本地配置无法延伸。安全程序只能删去无延伸的配置，不能因为发现任意一个失败配置就拒绝目标。本族因全部配置起初都有延伸，恰好令这种删配置规则没有第一次删除。

比值下界直接是2−1/k；任意统一ε>0取k>1/ε。上界来自任选一个(MP)延伸，投影到LST再用UM-ST-ROUND-v1。正OPT下T=0不可能通过：空配置探针必须仍覆盖正处理任务；因此无需定义0/0。一般输入的零/空边界不被本正值反例族覆盖，也没有被改写；空任务或每任务可走零边有其真实零调度。

### 7.2. 配置证书的两个装配事实

令a_b为X_b在V_b的边际，正常块的V配置为：{X_b}权a_b，全k个Z权1−a_b。于是每个Z在本块R的需求为a_b。允许指定一个中心取确定的Z子集，此时该中心a_b=0、缺失Z的R需求为1、保留Z为0。

1. **全局机装配。** X的剩余需求为1−a_b。未固定G时，若Σ_b a_b=2k，剩余总量恰为G=N−2k；把这些有理需求依次填入G个单位槽即可，各槽用单任务/空配置。若一台G固定为空，则需Σa_b=2k+1，剩余恰G−1。若一台G固定{X_a}，则a_a=0，先扣掉这一个单位需求，再把余量填其他G−1槽。k≥2给G≥4，分母或剩余机器数不会退化。
2. **块内装配。** 选一集合E的Y完整送z。块b在R上的总需求是k−|E∩Y_b|加该块所有Z的R需求。每项需求在[0,1]；只要总量≤k+1，就能用相同的有理单位槽填充，配置均为单任务/空。若某R固定空配置，改用其余k槽；若固定单任务，先扣下该任务的单位需求，再用其余k槽。z以概率1取E，合法当且仅当|E|≤k。

这里不把“总量足够”用于稀疏路径：本族每个Y/Z都能使用本块的**全部**R，才允许上述填槽。填槽使一项任务可跨两个槽，表示为两个机器各自的单任务配置边际；不需要假装这些配置已组成整数调度。

### 7.3. 全部合法配置的分类延伸

因为T=1且时间严格正，V上的合法配置恰为{X}或任意Z子集，G上为空或单X，R上为空或单Y/Z，z上为任意至多k个Y。以下穷尽这些类型。没有特别说明时，其他块a=1/k；所有逃逸都指选择互异的整项Y进入E。

| 固定机器及配置 | a及中心配置的修改 | 逃逸集合及容量核对 |
| --- | --- | --- |
| V_a固定{X_a} | a_a=1；其余a_b=(2k−1)/(N−1)<1/k；Σa=2k | 本块送k−1个Y去z，R需求k+1；其他块Z总需求ka_b<1，不逃逸；|E|=k−1 |
| V_a固定r个Z的子集（r可为0） | a_a=0且中心取该子集；另选b≠a令a_b=2/k；其余1/k；Σa=2k | a块Z需求d=k−r，送max(d−1,0)个Y；b块Z需求2，送1个Y；总逃逸≤k；两块R需求均≤k+1 |
| G固定{X_a} | a_a=0，另b取2/k，其余1/k；中心a取全部Z；Σa=2k；X_a由固定G完整承担 | 仅b块送1个Y；扣除X_a后其他X需求恰G−1 |
| G固定空 | 取k个不同块a_b=2/k，其余1/k；Σa=2k+1 | 这k块各送1个Y，|E|=k；X余量恰由其他G−1槽填满 |
| R_(a,l)固定空或单Y | a_a=0，另b取2/k，其余1/k；a中心全Z；Σa=2k | 仅b送1个Y；a块只有k个Y，可避开指定空R；指定单Y时先扣掉它，余k−1个Y用其他R |
| R_(a,l)固定单Z_(a,s) | 同前，但a中心取除Z_(a,s)外的全部Z | 仅b送1个Y；a块该Z需求1、k个Y需求1，固定Z占指定R，Y双射到其余k台R |
| z固定任意C，|C|≤k | 全部a=1/k，中心保持原分布 | E=C；从原R配置中删去C中Y的出现，余配置权重保留（可变空）；所有其他任务边际不变 |

所有a在[0,1]。第一行严格界等价于k(2k−1)<N−1，即k>1；第二行2/k≤1。除固定中心外，局部需求公式是k+ka_b−|E∩Y_b|。表内逐类满足装配事实；最后一行也可以直接装配，R总需求只会降低。因此每类都得到实际完整配置y，并恰好固定所要求的C，(MP)得证。

### 7.4. 构造复杂度、反驳范围与下一步

给展开实例及显式(i,C)，以上证书可确定性在其总位长的多项式时间内生成。中心至多两配置，全局和局部单位槽填充的正项总数线性于需求项数与机器数，z一配置；每配置的任务清单长度也多项式。系数只用k、N−1及其有理和差，贪心填槽不会产生新分母，故分子分母位长多项式。该声明是**本显式族的证书生成**，不声称枚举全部配置或精确求通用配置LP为多项式。

此结果已排除把“每一单机配置都分别能在完整配置LP里实现”当作统一低于2阈值舍入的充分信息，也包含全部单边条件配置探针，因为每条可用边的单任务配置可被固定。仍然没有排除需要一个共同base y的条件分布恒等式、完整SA/LS层级、跨机器相关性、条件块切面或相对OPT算法。第5节随B变化的跨块切面仍修复本族；不存在与它的矛盾。GPC₂与本节(MP)只是独立合取，未构造共享的条件pair数据。

**同一族上怎样增加有效信息。** 在T=1，任何强制V_a={X_a}的配置LP延伸都须把该块至少k−1的Y总边际送z：k个Z已全部外送，加上k个Y，总2k的单位需求面对k+1个R槽。假如这些延伸还来自一个共同base，且对每个a至少满足该块Y逃逸坐标的条件混合恒等式，则非负性给Σ_s x_(z,Y_a,s)≥(k−1)a_a。全局X容量又迫Σa_a≥2k，故z负载至少(k−1)Σa_a/k≥2(k−1)>1，矛盾。此处只需把各探针与同一个base的相应逃逸一阶矩联结；并不需要假设已经存在完整全局分布。这是第5节已有条件块切面的同一计数机制，不另立新Claim。它精确解释了为何每个延伸本身真实可行，却无法共同实现；一般如何有效选择、分离并舍入这种共同信息仍开放。
