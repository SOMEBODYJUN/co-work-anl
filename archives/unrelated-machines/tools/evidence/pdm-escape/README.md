# pDM threshold bridge finite audit

This directory preserves source `2ff9d538ae90f44b6e38`, a 1362-byte exact
Fraction audit record. It reports one (d=3,n=2,m=3,b=4) instance with no
perfect matching, 648 assignments checked, `OPT=13`, and best loads
`(12,11,13)`. The record's own scope is a finite observation: it attacks the
naive inference that no perfect matching forces a near-two NO value. It does
not refute the pDM threshold theorem, which still gives the integer lower
bound `OPT >= T+1` for valid NO instances, and it makes no claim about all gap
amplifications or all unrelated-machine algorithms.
