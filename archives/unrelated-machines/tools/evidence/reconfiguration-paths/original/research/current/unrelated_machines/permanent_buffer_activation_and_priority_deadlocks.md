# 永久缓冲激活的锐分数窗口与迁移优先级死锁

本文接续[剪枝首步锐界](pruned_first_move_and_transient_peak.md)，研究其后真正缺失的全程容量不变量。得到一个精确激活表示、锐分数窗口、两种失败机制及给定目标的可检验全程路径条件；**没有证明一般全程路径存在，也没有未知目标求解器或一般次二近似算法**。四个新身份独立于旧首步 Claim，原声明范围不变。

## 1. 给定目标的永久缓冲表示

沿用 `UM-MODEL-v1`。给定有理 (T\ge0,T\le C\le2T)，实际初态 \(\sigma\) 使用的每条端时间不超过 (T)，且 \(C_{\max}(\sigma)\le C)；另给具体目标 \(\tau\)，\(C_{\max}(\tau)\le T\)。本文只把改变任务 \(J_\Delta=\{j:\sigma(j)\ne\tau(j)\}\) 直接迁到目标端，每件至多一次。

令 \(s_j=\sigma(j),t_j=\tau(j),a_j=p_{s_jj},b_j=p_{t_jj}\)。不动任务在机器 (i) 的负载记为 (f_i)，改变任务原负载与目标负载分别为

\[
 A_i=\sum_{s_j=i}a_j,\quad Q_i=\sum_{t_j=i}b_j,\quad
 S_i=f_i+A_i\le C,\quad f_i+Q_i\le T.
\]

设 \(U=\max\{2T,C+T/2\}\)。已迁子集 (R\subseteq J_\Delta) 的源端移出量与尚未迁入目标量为

\[
 D_i(R)=\sum_{j\in R:s_j=i}a_j,\qquad
 B_i(R)=\sum_{j\notin R:t_j=i}b_j.
\]

**`UM-PERMANENT-BUFFER-ACTIVATION-v1`。** 对全部上述输入及全部 (R)，有

\[
 L_i(R)=S_i+Q_i-D_i(R)-B_i(R),\qquad
 L_i(R)\le U\iff B_i(R)\ge S_i+Q_i-U-D_i(R).
\tag{1}
\]

定义固定激活阈值

\[
 h_i=\max\{0,S_i+Q_i-U\}.
\tag{2}
\]

则 (D_i(R)\ge h_i) 当且仅当机器 (i) 在**所有后续直接迁移排列的全部前缀（含当前零步前缀）**中局部负载均不超过 (U)。这里局部只断言 (i) 的负载；不预先要求这些排列在其他机器上也守容。该量词不可改成“在全部已经全局守容的排列中”，否则必要性可能是空真。

此外

\[
 0\le h_i\le T/2,\qquad 3h_i\le A_i.
\tag{3}
\]

对统一分数选择 (x_j=\lambda\)，同时满足

\[
 \sum_{s_j=i}a_jx_j\ge h_i,\qquad
 \sum_{t_j=i}b_jx_j\le U-S_i
\tag{4}
\]

的**全输入普适常数** \(\lambda\in[0,1]\) 恰为 \([1/3,1/2]\)。这是分数 cover/packing 的锐窗口，不是整数迁移合同。

**证明。** 当前负载是未迁源任务、不动任务与已迁入任务之和，立即得到(1)。任意后续顺序在 (i) 的最大可能负载恰 (S_i+Q_i-D_i(R))：先迁入全部剩余目标任务，再迁出 (i) 上的剩余源任务可达到它；两组任务不交，因为 (s_j\ne t_j)。非负性给其他顺序均不超过它，因此(2)精确刻画局部永久安全。所有机器激活后，全部剩余任务任意顺序均全局守住 (U)。

由 (S_i\le C,Q_i\le T-f_i\le T)，得 (h_i\le\max(0,C+T-U)\le T/2)。若 (h_i>0)，则

\[
 h_i=S_i+Q_i-U\le A_i+T-U.
\]

又 (A_i\le C)，且 (2C\le3(U-T))：当 (C\le3T/2) 时右端为 (3T\ge2C)；当 (C\ge3T/2) 时右端为 (3C-3T/2\ge2C)。因此 (3h_i\le3A_i-3(U-T)\le A_i)。(h_i=0) 时同式直接成立。

若 (\lambda\in[1/3,1/2])，(3)给源覆盖，而 (\lambda Q_i\le T/2\le U-C\le U-S_i) 给目标 packing。下端锐例为两机器、每机两任务，源端均 (3T/4)、目标为另一机且均 (T/2)，取 (T>0,C=3T/2)：(A_i=3T/2,h_i=T/2) 强制 \(\lambda\ge1/3\)。上端锐例把源端改成 (T)，取 (C=2T)：(Q_i=T,U-S_i=T/2) 强制 \(\lambda\le1/2\)。所以普适窗口准确。

(T=0) 时所有被用端、不动负载与阈值均零；空任务、无改变任务、零端与单可用端均照上述定义处理。锐性只用正 (T)。输入、负载、阈值及集合验证都可在总编码位长的多项式时间精确处理；这里不包含求未知 \(\tau\) 或求符合(4)的整数 (R) 的承诺。

## 2. 分数余量不保证一次性整数激活集合

**`UM-STATIC-ACTIVATION-COVER-OBSTRUCTION-v1`。** 存在 (T=1,C=2,U=5/2)、四机器七任务的合法实例，\(\operatorname{OPT}=T\)，给定初态和目标满足第1节全部条件，但不存在一个子集 (R) 同时满足

\[
 D_i(R)\ge h_i\quad\text{及}\quad
 \sum_{j\in R:t_j=i}b_j\le U-S_i\quad(\forall i).
\tag{5}
\]

第1节窗口的每个统一分数选择仍可行。实例却有每件仅直迁一次、峰值 (23/10<U) 的完整路径。

**原始输入。** 三台机器 (A,B,C_0) 各两任务，初态全留原机、每个源端为1；每件只有表中另一个目标端可用。第四机 (Z) 有一件只在 (Z) 可执行、时间1的固定任务；其他端一律不可用。

| 源机 | 目标端时间 |
| --- | --- |
| (A) | (B:3/5, C_0:3/5) |
| (B) | (A:3/10, C_0:1/5) |
| (C_0) | (A:3/10, B:1/5) |

前三机 (S=(2,2,2),Q=(3/5,4/5,4/5),h=(1/10,3/10,3/10))，原始接收预算均为 (1/2)。任何满足 packing 的 (R) 都不能含 (A) 的任一出边，因为单件目标 (3/5>1/2)；源覆盖却要求从 (A) 移出至少 (1/10)，矛盾。第四机不改变这个矛盾。全目标前三机负载不超过1、第四机恰1，且其固定任务强迫 \(\operatorname{OPT}\ge1\)，所以 \(\operatorname{OPT}=1\)。

完整好序为

\[
 B\!\to A, A\!\to B, B\!\to C_0, C_0\!\to A,
 A\!\to C_0, C_0\!\to B.
\]

逐步前三机负载依次是

\[
 (2,2,2),\ (23/10,1,2),\ (13/10,8/5,2),\
 (13/10,3/5,11/5),\ (8/5,3/5,6/5),\
 (3/5,3/5,9/5),\ (3/5,4/5,4/5).
\]

因此(5)的充分性成立：若有这种 (R)，任意顺序先执行 (R) 都守容，随后全部机器已激活，余下任意完成。但它不是一般路径存在性的必要条件。错误步骤是把“逐阶段释放出的接收容量”冻结成原始预算 (U-S_i)，而不是分数点本身不守容量。

## 3. 两种源端优先级的参数化真死锁

**`UM-TRANSIENT-PRIORITY-DEADLOCK-v1`。** 对每个有理 (T>0)、\(3/2<c<2\)、\(0<d<1/3\)、\(1/2<q\le1\)，下面四机器八任务实例有 \(\operatorname{OPT}=T\)、每个初态负载 (C=cT\)、全部有限端不超过 (T\)、每件恰两端。给定表中目标 \(\tau\)，在容量 \(U=(c+1/2)T\) 内，每步从**当前安全的未迁任务**选源端 (a_j) 最大者，或选 (a_j/b_j) 最大者，均不论平局如何处理而停在未完成、无任何安全直接迁移的状态。加上“仅从未激活源机器迁出”限制仍失败，但该受限策略先停在允许动作耗尽的状态；其余 helper 任务全局仍可安全迁移，不能把两种死锁语义混写。

令 \(b=(1-d)/2\)，下标 (i\in\{0,1\}\)、\(\bar i=1-i\)。初态全部任务在表中源端；目标全部在另一端。

| 任务 | 数量 | 源端时间 | 目标端时间 |
| --- | --- | --- | --- |
| core任务 | 每个 (A_i) 两件 | (A_i:cT/2\) | (A_{\bar i}:bT\) |
| feed任务 | 每个 (H_i) 一件 | (H_i:T\) | (A_i:dT\) |
| helper交换任务 | 每个 (H_i) 一件 | (H_i:(c-1)T\) | (H_{\bar i}:qT\) |

初态每机 (cT\)，目标 core 每机 (2bT+dT=T\)，helper 每机 (qT\le T\)。若有最大负载严格小于 (T\) 的调度，两 feed 因源端为 (T\) 必须进入 core。四 core 任务每件无论在哪个 core 上都至少用 (bT\)，故两个 core 的总负载至少 (4bT+2dT=2T\)，矛盾。因此最优值恰 (T\)。

两 feed 是最大源端的严格第一层：\(T>cT/2,(c-1)T\)。它们也是比率的严格第一层：

\[
 1/d>3,\qquad c/(1-d)<3,\qquad (c-1)/q<2.
\]

两次 feed 均安全，因为各目标起初只收到自己的 feed，\(c+d<c+1/2\)。故两规则都被迫先迁两 feed；唯一平局是它们的顺序，对后果无影响。此后两 core 负载均为 \((c+d)T\)，任一 core 任务迁移会使目的负载

\[
 (c+d+b)T=\left(c+\frac{1+d}{2}\right)T
 =U+dT/2>U.
\tag{6}
\]

两 helper 交换任务仍可依次安全完成：两 feed 迁出后 helper 负载为 \((c-1)T\)，收一次 (qT\) 后最多 \((c-1+q)T\le cT\)。完成它们后，仅剩四 core 任务，(6)使所有直接单步均不安全，因而是全局真死锁。初态 helper 激活阈值为 \((q-1/2)T>0\)，feed 的源移出量 (T\) 立即使它们激活；若禁止从已激活源迁出，策略在两 feed 后已无允许的安全动作，仍有未激活 core。

**完整路径与准确 minimax。** 先交替迁四 core 任务：\(A_0^0,A_1^0,A_0^1,A_1^1\)，再迁两 feed、两 helper 交换任务。这条路径峰恰 \((c+b)T<U\)：第一件 core 造成该峰；后续 core 波前最多 \((c/2+2b)T\le(c+b)T\)，最后 core 为 (2bT\)，feed 补到 (T\)。helper 步骤也不超过初态 (cT\)。

反向、重复迁移或其他绕路也不能低于 \((c+b)T\)：从初态到指定目标的任何单件路径必有第一次改变某件 core 的步骤；在此之前，其目的 core 的两件原任务仍在，总负载至少 (cT\)。第一次迁入又增加 (bT\)。因此到指定目标的单件路径最小峰值准确为 \((c+b)T\)，并非只给一条可行路径。

当 (d\downarrow0\) 时，这个可实现峰与预算 (U\) 的差为 (dT/2\)，而贪心下一步超额也是 (dT/2\)。这是给定目标下的选序失败；它既不反驳一般 (U\) 路径猜想，也不限制允许回退重排、原子共同批次或更强初始化的算法。全族参数只需常数次有理运算，原矩阵输出和证书位长多项式。

## 4. 单件解锁函数图的可检验全程路径

**`UM-PERMANENT-BUFFER-UNLOCK-PATH-v1`。** 保持第1节给定实际 \(\tau\) 的全部输入。令 \(H=\{i:h_i>0\}\)、\(R_0=M\setminus H\)。从 \(i\in H\) 出发的改变任务 (j) 称 eligible，当且仅当 \(a_j\ge h_i\)。定义

\[
 G=\{i\in H:\exists\text{ eligible }j,
       \ t_j\in R_0\ \text{或}\ b_j\le U-S_{t_j}\}.
\tag{7}
\]

以下图条件可在总编码位长的多项式时间内判定：每个 (H) 顶点在 eligible 有向图中，经 (H) 内路径可达 (G)（长零路径允许）。它当且仅当存在为每个 (H) 顶点选择一条 eligible 出边的函数图，使每个有向环都含一条初态安全边 \(b_j\le U-S_{t_j}\)。若图条件成立，可确定性位多项式构造每件只直迁一次的完整 \(\sigma\to\tau\) 路径，全程负载不超过 (U)。

一个易检验的充分条件是：每个 (i\in H) 至少有两件不同 eligible 任务；它们可以有相同目标，不能把多重任务丢成一条无重图边。此时上述图条件自动成立。

**函数图选择。** 对 (G) 中的每点选一件(7)的见证任务。对其他点，沿反向 BFS 求到 (G) 的最短距离，选一条使距离严格下降的 eligible 边。所选环必经过 (G)，否则距离沿环严格下降矛盾。环上的 (G) 见证不可能指向 (R_0)，故必为初态安全边。反之，若已有这样的函数图，从任一点沿所选边追踪，最终到达 (R_0) 或一个含初态安全边的环；离开 (H) 的尾点或安全环边的源点属于 (G)，故满足可达条件。

**完整执行顺序。** 暂不执行未选任务，也不提前迁入环的附树任务。先处理所选图的全部有向环：在一个尚未处理的环上，先迁一条初态安全边 (u\to v)。此时该环没有已执行的所选入流，目的机仍在初态，因而负载不超过 (S_v+b\le U\)；源端移出量至少 (h_u\)，使 (u) 永久安全。随后沿该环的反向顺序执行其余所选边，每步目标都是已经永久安全的机器，源也随之激活。不同函数图分量之间没有所选边，处理另一环时仍保有相同初态条件。

全部环处理完后，以 (R_0\) 及已处理环为安全根，从根向附树外层执行所选边；每步目标已永久安全。终止于 (R_0\) 的分量同样从根外展。这样每个 (H) 源恰执行一条 eligible 边并激活。最后执行全部未选任务的任意排列，由第1节每台机器的永久安全性，全程守住 (U\)。任务原端与目标端不同，故没有实际自环迁移；所选源各一件也不会选择同一任务两次。

**两备选为何充分。** 令 (W\subseteq H\) 为**全部**不能到达 (G) 的顶点。若 (W\ne\varnothing\)，每个 (W) 源的两件 eligible 任务都必须指向 (W)，且都不是初态安全边。因此其目标时间 \(b_j>U-S_{t_j}\ge T/2\)。目标容量 \(f_i+Q_i\le T\) 使每台机器至多有一件这种大入边。于是 (W) 内边数一方面至少 (2|W|\)，另一方面至多 \(|W|\)，矛盾。零边不影响计数；(T=0\) 时 (H\) 为空。

输入为给定的完整 \(\sigma,\tau\)，并非未知目标 oracle；图扫描、BFS、函数图分解及输出至多 \(|J_\Delta|\) 步均多项式，全部负载与比较是输入有理数的多项式位长运算。当前规范实现只覆盖这个给定目标的证书合同。

**失败语义不能升级。** 可达条件失败，只表示这种单件解锁证书不存在，不表示 \(\operatorname{OPT}>T\)，也不表示没有全程 (U\) 路径。例如两机互为目标，每侧一件源时间1、目标时间 (3/5\) 的任务，另四件源时间 (1/4\)、目标时间 (1/10\) 的任务。取 (T=1,C=2,U=5/2\)，每侧 (h=1/2\)。唯一 eligible 是大任务，形成无安全边的二环，故 (G=\varnothing\)。然而先迁全部八件小任务，再迁两件大任务，峰值 (12/5<U\)。多件合力释放余量是真正仍缺的机制。第3节整个优先级坏例族却满足两备选条件，故同一输入可由共同函数图选择成功，而局部优先级失败。

## 5. 主目标前沿、证据和准确失败范围

激活表示把全程问题改写为：在容量 (U\) 内逐阶段取得全部源移出阈值，同时避免提前耗尽尚未激活机器的共同接收余量。一次性静态 packing-cover 和两个源端优先级都不解决这道义务；继续微调这些分数没有现成证明支持。单件解锁函数图给出了实际可算的正面证书，但其失败不排多件合力路径。一般 (U\) 全程路径存在性/可计算性仍 OPEN，即使已给 \(\tau\)；未知目标、统一 \(\varepsilon\) 与总位多项式进展更未闭合。给定目标的路径算法不能免费升级为 `UM-TARGET-v1` 的调度算法。

Truth：以上四个准确身份有自足推导；审查覆盖及冻结哈希见[独立审查](../../reviews/unrelated_machines/permanent_buffer_activation_review.md)。Value/Mechanism：锐分数窗口、可核验永久容量状态、共同函数图路径及明确的历史占用/动态释放失败；Novelty：未认证；Ambition：没有得到一般近似或困难性突破。没有导入外部定理，也没有把有限搜索未见反例视为全程证据。

实际有理审计：`tests/audits/unrelated_machines/permanent_buffer_activation.py`；冻结结果：`evidence/runs/unrelated_machines/permanent_buffer_activation_audit.json`。它检查固定输入的全部迁移子集、所有优先级平局分支、原始两端矩阵最优值、好路径、函数图选择器和边界。有限核验只作 checks，不承担一般证明。尚未实现无条件的一般路径构造器。
