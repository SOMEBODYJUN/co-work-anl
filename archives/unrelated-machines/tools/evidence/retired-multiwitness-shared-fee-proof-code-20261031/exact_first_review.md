# 多见证共享收费合同的独立全子集重构与空集边界攻击

审查对象：`negative_hardness_work/global_decoder/multiwitness_shared_job_fee_exact.md`，作者给定 SHA256 `018a57a9dc367a7287fbaa1806b93f81bf76582978dbdf0e3236b9664b726ad1`。本审查先只读 Exact，未获、未读作者 Proof。以下推导自行重建，不调用作者证明。

## 1. 结论与必须修复的唯一已找到缺口

Exact 的第1–6项成立，第7项在 `K` 非空时成立。原陈述没有要求 `K!=empty`，故其严格盒式不成立：空模式 strict1 可行，空集内“每个单查询都必收费”真空为真，但结论成为 `0<B_empty=0`。

建议把第7项开头改为“若一个非空 `K` strict1 可行……”；或空集单列。修复后未找到 standing fatal。下述是一般量词证明，有限枚举仅另核计算。

## 2. 完整原任务的无约束 OPT 精确为1

初态将全部 `q_r` 放 `H_r`、全部 `x_r` 放 `A_r`、`f` 放 `R`。逐机负载为 `a_r<=1`、1、`c<=1`、0，故上界1。

若完整峰 `<1`，任何 `x_r` 都不能在其 `A_r` 上执行（那里时间1），而 `f` 也不能在 `S`（时间1）。因此全部 `x_r` 与 `f` 必共同在 `R`，负载为 `c+sum b_r>=1`，矛盾。故 OPT=1。这也说明条件 `c+sum b_r>=1` 真正用于原实例下界，不能省掉后仍宣称 OPT1。

对单查询 `r`，实际安排 `q_r->A_r,x_r->R,f->S`，其余 `q->H,x->A`。所有原 jobs 一次，逐机峰为1。查询初始 `a_r` 可任意正小。

## 3. 子集模式在峰严格小于2时的实际正规化

固定任意 `K`，不先假设其可行。若 pattern K 的完整实际峰 `<2`，则每个 `r in K` 的 `q_r` 已在 `A_r` 占1，故 `x_r` 不能仍在 `A_r`，必须在原 `R` 端。它们在 `R` 上的真实总量恰为 `B_K`。

对 `r notin K`，若其 `x_r` 在 `R`，可将其移回原 `A_r`。该机没有 `q_r`，恢复后只负载1；`R` 负载下降。由于已知原实例 OPT1，讨论任何候选最优值时峰必至少1，这次恢复不增加峰。对给定 `beta>=1` 的可行性也不增加峰。

因此在 `<2` 域，除是否移动 `f` 外，精确正规分配如下：

| 原机器族 | 完整实际负载 |
| --- | --- |
| `H_r,r notin K` | `a_r` |
| `H_r,r in K` | 0 |
| `A_r,r in K` | `q_r=1` |
| `A_r,r notin K` | `x_r=1` |
| `R` | `B_K+c`（f不改派）或 `B_K`（f改派） |
| `S` | 0（f不改派）或1（f改派） |

空 K 也包含在表中，全部 `A_r` 接 `x_r=1`，保证正规峰仍至少1。

## 4. 全子集 OPT，不遗漏达到2的分支

令 `M=max(1,B_K)`。若 `M<2`，第3节中把 `f` 放 `S` 得完整实际峰 `M`。反过来任何峰 `<2` 的模式都在 `R` 接 `B_K`，又由原 OPT1 有峰至少1，故峰至少 `M`。

若 `B_K>=2`，任何 `<2` 完整模式都将被上述 R 下界排除。另一方面无需把 `x_K` 送 R：将 `q_K` 放其 A，其余 jobs 全按初态安排。每台查询 A 接两枚单位任务，其余原机均不超过1，故完整峰恰2（K非空，此分支自然非空）。

结合得 `OPT_K=min(2,max(1,B_K))`，包括 `B_K=1,2` 的等号和空 K。

## 5. 全子集费用的闭阈值严格边界

对 `1<=beta<2`，强迫 `x_K->R` 给必要条件 `B_K<=beta`，也由把 f送S给充分条件。若 `B_K>beta`，费用为 infinity，表示指定 pattern 无实际可行分配。

当 `B_K<=beta`，费用为0恰当且仅当 f仍在R可行，即 `c+B_K<=beta`。等号在 fee0 分支；若 `B_K<=beta<c+B_K`，f必须去S、费用恰1。由第3节给出的具体分配分别达到费用0或1。因此 Exact第3项成立，没有把费用从负载中匿名化。

在 `beta=2`，对任意 K，上一节让 `q_K` 与 `x_K` 共居A、f保R的实际分配直接 fee0。此点不能用 `<2` 时强迫 `x_K` 去R的论证；Exact已把它单列，正确。

## 6. 特例、多个 strict 见证与第7项修复

`b_r=c=1` 时，任何非空 `K` 在 `<2` 可行只可能 `|K|=1`，且此时 f所在R若不移会负载2，必须费用1。每个单例 strict1可行，但 `|K|>=2` 最优值2。给定 p个单例见证不能替代全开strict见证，因此不反驳旧双见证 theorem。

取任意 `beta<2`、`b_r=1`、`beta-1<c<1`，单例 `B=1<=beta<c+1`，故始终必费1；收费任务初态真实时间c<1、改派后真实时间1，确是指定非unit到unit的 owner 改派费。

`b_r=1/s` 时 `B_K=|K|/s`，第5节逐项乘s便是 Exact第6项；所有等号方向正确。若 `s>=2`，则任何单例 `c+1/s<=1+1/2<=beta`（beta>=3/2）可 fee0。`s=1,c=1` 的单例恰到2才允许fee0。

现在要求 `K` 非空且 strict1可行，则 `B_K<=1`。每个 `r in K` 的单例在 `beta>=1` 都可行，因为 `b_r<=1`；单例必收费恰为 `c+b_r>beta`。对非空 K 求和得到

`|K|(beta-c)<B_K<=1`。

空K不能把零项严格不等式相加成严格式；这就是原版第7项缺口。修复后，`beta>=3/2,c<=1` 给 `beta-c>=1/2`，从而 `|K|/2<1`，即 `|K|<=1`。

## 7. 位复杂度与范围审查

`B_K` 由至多p个输入有理数求和，分母乘积的位长至多原输入分母位长总和。比较 `B_K` 与1、2、beta及 `c+B_K` 均为总位多项式；上述达到分配只对每个原 job 写一个原机器编号，不展开分母、s或逆小时间。

参数 `a_r>0`、`b_r>0`、`c>0` 保证没有零值特殊除法；p>=1用于原初态存在一枚x的单位负载。所有机器互异与所有有限端限定是承重：若添加资格或令 A合并，推导将改变，不能保持该Exact身份。
