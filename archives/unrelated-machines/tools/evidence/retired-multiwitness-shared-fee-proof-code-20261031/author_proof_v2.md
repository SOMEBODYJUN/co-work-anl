# 多见证互斥查询的共享任务收费：自足证明与适用边界

本文只证明同目录 Exact-only 冻结陈述 `multiwitness_shared_job_fee_exact_v2.md`，不冒称独立审查者的攻击记录。原v1第7项遗漏K非空，空集给0<0反例；v2已显式修复，不倒改旧冻结原件。

## 1. 原实例的实际见证及全局最优值

初态 σ₀ 把 q_r 放 H_r、x_r 放 A_r、f 放 R。各 H_r 负载 a_r≤1，各 A_r 负载1，R负载c≤1，S负载0，故 C_max(σ₀)=1。

对任意 r，定义 σ_r：只把 q_r 放 A_r、x_r 放 R、f 放 S，其余原任务保持 σ₀。A_r 上只剩原 q_r，负载1；R 上只剩原 x_r，负载 b_r≤1；S 上是原 f，负载1。其余机器与初态相同。因此 σ_r 是覆盖全部2p+1原任务的同一P实际严格负载1见证，且 query owner 改变集恰为 {q_r}。

现在独立证明无约束 OPT(P)≥1；不能仅凭 σ₀ 中存在 unit 任务就推出它。假定有完整实际调度 C_max<1。每个 q_r 的 A_r 端时间1不能使用，所以全部 q_r 在 H_r；每个 x_r 的 A_r 端时间1不能使用，所以全部 x_r 在同一 R；f 的 S 端时间1也不能使用，所以 f 在 R。于是 R 的真实负载 c+Σ_r b_r≥1，矛盾。结合 σ₀ 得 OPT(P)=1。此论证也覆盖 a_r=1 以及边界 c+Σb=1。

## 2. 任意查询子集的准确 pattern 最优值

固定 K⊆[p]，记 B=B_K。

先给两份完整原任务上界构造：

- 构造 I：q 按pattern固定；r∈K 的 x_r 放 R，r∉K 的 x_r 留 A_r；f 放 S。每个 A_r 恰有 q_r 或 x_r 一枚 unit，H_r 负载0或a_r，R负载B，S负载1，故完整峰为 max{1,B}。
- 构造 II：q 按pattern固定；全部 x_r 留 A_r；f 留 R。r∈K 的 A_r 有 q_r+x_r 两枚 unit，其余 A_r 仅x_r；故峰≤2。若K为空，其峰1。

所以 OPT_K≤min{2,max{1,B}}。

再证下界。全局 OPT(P)=1 已给任意pattern的峰≥1。若某pattern调度峰 C<2，则每个 r∈K 的 A_r 已有指定 q_r，时间1；同编号原 x_r 不能也在 A_r，否则该机负载2。因此这些 x_r 全部在 R，R 负载至少 B，无论其它 x_r 和f如何选择端。故 C≥max{1,B}。若假定 C<min{2,max{1,B}}，它同时满足 C<2，与刚才必要界矛盾。于是准确式成立，包括 B=1、B=2、K为空和 B>2 的情形。

上界两构造都是原P实际调度；没有将R当匿名容量、丢弃未选 queries 或未激活 x。最优值在有限调度集中取得，无连续极限。

特别地，OPT_K≤1 iff B_K≤1。

## 3. 闭阈值 β∈[1,2) 下的最小改派费

任何 C≤β<2 的pattern调度中，第2节强制全部 r∈K 的 x_r 在 R。因此 B_K>β 时不可能有该pattern实际调度，F_β(K)=∞。

若f不改派，则它在R上贡献真实c，故 R负载至少c+B_K。因此 fee0 可行的必要条件为 c+B_K≤β。它也充分：q按pattern，激活x全进R，未激活x全留A，f留R。所有A负载恰1，H负载≤1，R负载c+B_K≤β；S空。这是一份完整fee0实际调度。

若 B_K≤β<c+B_K，则任何β内实际调度都不能将f留R，必须真正改派原f到其原S端，收费1。第2节构造I恰好峰max{1,B_K}≤β，确实费1，故这个case的最小费用为1。只有f的改派收费；所有x虽可能迁移，但其权均0，未把背景负载或任务数冒称费用。

三case互斥且覆盖全部输入，等号 c+B_K=β 精确属于fee0分支，等号 B_K=β 精确属于可行分支。对β≥2，构造II对所有K都费0；对β<1，由OPT(P)=1所有pattern均不可行。

## 4. 真正多见证的阈值2与非unit旧端

取全部 b_r=c=1。每个 singleton K={r} 有 B_K=1，故 pattern OPT为1；但只要 C<2，q_r 迫x_r到R，若f留R便有两枚unit、负载2。因此singleton的全部完整C<2 actual都必须移同一f。全家p个singleton各至少费用1，总p；整个非query任务权宇宙仅f权1，其余x权0，W=1。

任意 |K|≥2 有 B_K≥2，pattern OPT精确2。所以p≥2时，没有可作为双见证查询分离σ₁的完整strict全开调度。把每个query的不同σ_r合写成一个σ₁正是无效步骤。另一方面，σ₀与任意一个σ_r之间的双见证定理只有一个query，它可支付这枚f，没有矛盾。

β=2时构造II允许q与x同住A；f不动，所以所有pattern费用0。故在这个多候选见证合同里，收费强制阈值精确2。

对任意固定β∈[1,2)，选择有理 β−1<c<1（必要时另选任意正c）。仍取b_r=1，则 c+B_{\{r\}}=1+c>β；每个singleton仍必须改派f。此时它的旧端c是真正非unit、新端1是unit。它的旧端须近unit才能将阈值推近2，不能因此称为tiny激活费。a_r却可全部任意tiny而不改变结论。

## 5. 容量s与收费/并发的精确折衷

令1≤s≤p为整数、b_r=1/s。域内条件自动成立，因为Σb=p/s≥1。对任意K，B_K=|K|/s，代入第2–3节便给全部容量s公式；没有新的整数舍入。strict1正好允许至多s个查询同时激活。

singleton在β阈值fee0 iff c+1/s≤β。s≥2、c≤1时左边≤3/2；所以β≥3/2时任何singleton都有完整fee0实际调度。这精确解释了提高R的严格并发容量为何失去近二单读出收费。

异权版本也有同一限制。若非空K strict1可行，则B_K≤1；若其中每个singleton都在闭阈值β必收费，因b_r≤1≤β可用第3节得到b_r>β−c。对至少一项的非空K逐r求和为 |K|(β−c)<B_K≤1。β≥3/2、c≤1时 β−c≥1/2，故 |K|<2。K为空时pattern strict1、费用0，逐元素收费前件真空成立；它不满足0<B_K，所以明确不在本严格和式的非空域内。该结构只能把至多一个可共同strict激活的查询强制收费；不能把p个互斥singletons误读成同标签的p个同时服务测试。

## 6. 构造复杂度和与既有星的合同区别

原P共2p+2机器、2p+1任务、4p+2条finite条目，dense总(2p+2)(2p+1)项。全部分配只需逐原任务选择表中两个端之一。计算B_K及负载用至多p项有理加法，位长被输入有理分母位长之和加多项式项控制。选择第2节两构造中较优者、判断第3节三case及输出相应实际分配，都是确定性总位多项式；不按s数值、分母、1/a或1/(2−β)循环。

旧多输出可用性星：读不同预载状态中host开/关，有两份全端实际模式。这里固定同一普通P；读的是原q_r落H_r还是A_r，以及原f是否从R到S。R同时接收不同x_r才造成互斥。没有任何预载任务或边随模式改变。p+1份actual不构成两份“全off/全on”actual，因此不能直接套旧两全模式预算；旧定理本身未被反驳。

数学结论只是这个完整可解参数族的精确接口。它尚未解决共同标签的多测试fanout、外接容量、源NO解码或预算桥。不存在一般计算困难性或主目标反证。
