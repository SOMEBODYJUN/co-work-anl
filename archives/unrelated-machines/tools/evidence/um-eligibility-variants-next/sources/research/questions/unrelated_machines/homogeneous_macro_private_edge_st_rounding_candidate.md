# 同质大宏占位下任意私有边的 ST 舍入候选

本稿记录一个比共同资格组更宽的正面结构接口。它保留的承重结构是：宏任务数等于 home 数，宏只在 home 上运行，并且对每个 home `h`，所有可到达该 home 的宏边处理时间都是同一个 `P_h>T/2`（与宏身份无关）。因此任何阈值 `T` 可行解都在每个 home 恰放一个宏，任意宏完美匹配都会产生同样的 home 残余容量。所有私有任务可以有任意逐件资格边，边处理时间可随机器变化，只要求每条有限私有边不超过 `δT`。固定宏占位后，私有任务的 LST 分配 LP 与 ST 槽舍入给出 `1+δ` 负载界。

这是标准 LST/ST 机制在该结构合同上的自足重构，不能宣称新颖；研究价值在于精确隔离了共同资格、唯一 home、等端 tiny 并非必要条件，而宏占位同质性仍承重。`UM-TARGET-v1` 仍开放。

## 1. 结构与给定阈值合同

机器分为 home 集 `H` 与 sink 集 `Z`。宏任务集 `B` 满足 `|B|=|H|`，宏任务只允许在 `H` 上运行。对每个 `h∈H`，所有有限宏边 `(h,b)` 的处理时间都是同一个有理数 `P_h`，且 `P_h>T/2`；宏边图允许任意交叠，但必须有 `B` 到 `H` 的完美匹配。私有任务集 `J` 任意；私有任务 `j` 的有限资格集合 `A_j⊆H∪Z` 可任意交叠、为空或不共同，边处理时间为任意非负有理数 `p_{ij}`。

给定 `T>0` 与 `0≤δ<1`，检查：

```
|B|=|H|,
每个 home 的宏时间 P_h>T/2,
每条有限私有边 p_ij≤δT,
宏边图有完美匹配。
```

先求任意宏完美匹配。固定它后，在每个 home `h` 上留下容量 `T−P_h`，每个 sink 容量 `T`，对私有任务运行剪枝 LST 分配 LP：

```
Σ_i x_ij=1                         (j∈J),
Σ_j p_ij x_ij ≤ T−P_h             (i=h∈H),
Σ_j p_ij x_ij ≤ T                 (i∈Z),
x_ij=0 (i∉A_j),  x_ij≥0.
```

若 LP 不可行，返回 `FAIL`；若可行，对每台机器按 ST 有序单位槽匹配舍入私有任务，并把固定宏放回匹配的 home。输出满足

```
L_i≤(1+δ)T  (所有 i∈H∪Z).
```

**完备性。** 若原实例有 `C_max≤T` 的调度，则 `P_h>T/2` 且 `|B|=|H|` 迫使每个 home 恰有一个宏，因此宏边图有完美匹配。任取一个完美匹配重新放置宏；每个 home 的宏负载仍为 `P_h`，原调度的私有任务分配仍满足同一组容量 `T−P_h`（home）和 `T`（sink），所以 LP 有整数可行点。ST 舍入保留每个私有任务的有限支持，且每台机器增加不超过该机分数支撑中的最大私有处理时间 `≤δT`；home 加回宏后负载至多 `P_h+(T−P_h)+δT=(1+δ)T`，sink 至多 `T+δT`。

LP、完美匹配和有序槽匹配都是显式规模的位多项式过程；有理分数比较用交叉相乘。零时间私有边允许保留，空任务直接输出；`T=0` 单独按零边检查。

## 2. 未知 OPT 的承诺候选

`UM-HOMOGENEOUS-MACRO-PRIVATE-PROMISE-v1`：不给 `OPT`，承诺在真实 `OPT` 处每个 home 的宏时间满足 `P_h>OPT/2`，且每条有限私有边满足 `p_{ij}≤δOPT`，其中固定 `δ≤δ̄<1`。令 `Q` 为所有有限处理时间分母乘积，取任意合法分配给出网格上界 `U`。在网格 `t=k/Q` 上测试：`t≥max_h P_h`、宏边图有完美匹配、删去 `p_{ij}>t` 的私有边后上述 LP 可行。测试单调：容量 `t−P_h` 与 `t` 增大，私有资格边只增加；宏匹配图不变。二分最小接受 `t*`，承诺保证在 `t=OPT` 通过，故 `t*≤OPT`。

在 `t*` 上 ST 舍入的加性误差是 `δOPT`（而非必须是 `δt*`），因此

```
C_max≤t*+δOPT≤(1+δ)OPT≤(1+δ̄)OPT.
```

这给该承诺结构类固定 `ε=1−δ̄` 的实际调度。若 `δ` 只逐实例小于1而无统一上界，则不声称统一 `ε`。承诺不提供一般输入的结构识别或宏分解。

## 3. 准确范围和边界

本候选同时去掉：

- 私有任务的唯一 home（每个 `A_j` 可含任意多个 home 与 sink）；
- 共同出口资格（不同任务的 `A_j` 可完全不交）；
- 组内等端 tiny 时间（每条边只需 `≤δT`，可随任务和机器变化）。

仍承重：

- `|B|=|H|` 且宏只在 homes；
- 对每个 home 固定宏时间 `P_h` 与宏身份无关，使任意宏完美匹配给出同一 home 容量；
- `P_h>T/2` 用于在 `OPT≤T` 时证明每个 home 必有一个宏；
- 私有边的统一小尺度 `δT`，负责 ST 的单机加性误差。

若宏时间依赖宏身份，固定宏匹配会改变各 home 的残余容量，必须把宏匹配和私有舍入联合处理；若宏数不等于 home 数，某些 home 可能没有宏或有多个宏；若私有边允许大于 `δT`，标准 ST 加性项不再给统一低于2。上述边界是证明适用条件，不是一般模型的困难性结论。

## 4. 与现有接口和主目标的关系

`weighted_group_joint_slot_rounding.md` 允许异质私有尺寸和宏-home匹配，但要求唯一 home 与组内共同资格；本候选反向固定宏占位，允许完全任意私有资格和逐边小尺寸，并用标准 LP/ST 直接得到 `1+δ`。两类结构没有一般包含关系。

这是一项结构性回收，不是主目标突破：一般矩阵没有给出同质大宏分层，如何识别/生成这样的宏与 homes 仍未解决。标准 LST/ST 结果是该候选的直接工具，全球新颖性和独立论文价值未认证。
