## 当前可承重的 scoped 结论

在有限显式菜单中，组 `g` 的每个 indexed state 系数 (p_{gsu}ge0) 为二进制有理且列和为一，正支撑 LP

\[
\sum_s\lambda_{gs}=1,\qquad
\sum_{g,s:u\in P_{gs}}\lambda_{gs}\le1
\]

给出逐资源跨组独立抽态。对资源 (u)，正支撑容量保证每个阈值 (t) 的尾概率和不超过一；独立性和凹弦界得到

\[
\mathbb E\max_g p_{g,s_g,u}\ge(1-1/e)\sum_g\mathbb E p_{g,s_g,u}.
\]

有限 level 的有理条件期望逐组固定 state 可确定性去随机化，操作次数及分母位长按显式 state/incidence 输入多项式控制。最终真实不交 bundle 的总质量严格大于 (5n/8)，并给出

\[
 h_{\ge\delta}, h_{>\delta}>
 \frac{5/8-\delta}{1-\delta}n\quad(0\le\delta<5/8)
\]

的相应严格计数；两种高端语义在互补低端时保持区分。

完整 `P_gate` 保留 root pin、每组自身 gate connector、每个 state 私有机、资源 unit 端以及所有未选/零 incidence 作业。令 `β*` 为不交 bundle 的组数比例和最小组质量的最大平衡值，则前向调度和 `C<2` 的反向解码共同给

\[
\operatorname{OPT}(P_{gate})=2-\beta^*.
\]

FSLP 可行时，取阈值 `δ=3/8` 得多于 `2n/5` 个高质量组，构造峰值小于 `13/8` 的完整实际调度。在 v2 质量 LP 中，`z` 是 state 质量、`x` 是 resource claims；初始 claim 概率和受容量控制，条件化后不重复套用初始容量不等式。

旧 NSW 参数勘误只适用于其 explicit normalized / all-allocation / FSLP 量词：

\[
 h_{\ge\delta}<\gamma_{hi}n
\Longleftrightarrow
 |\{g:r_g<\delta\}|>(1-\gamma_{hi})n.
\]

它不把这两个不同参数改写成同一 `γ`，也不把正支撑 FSLP 结果推广到一般不相关机或旧 flat menu。
