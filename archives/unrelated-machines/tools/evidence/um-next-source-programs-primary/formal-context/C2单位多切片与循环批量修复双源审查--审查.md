# 处置范围

本批实际阅读两个当前正文的完整数学内容，并对其引用的既有 C2、菜单、槽舍入、固定槽凸包和长链记录做了交叉核对。两个来源的对象不同：第一个是全局次数四的负载伪矩松弛，第二个是给定实际调度上的周期菜单局部优化器及其修复失败族。不能把它们合并成同一个松弛、同一个初始化合同或同一个近似结论。

正文中的稳定身份为 `UM-C2-LOAD-UNIT-GAP-v1` 与 `UM-ROBUST-CYCLIC-BATCH-OPT-v1`；同一循环正文还包含 `UM-BATCH-SUPPORT-REPAIR-NO-v1`、`UM-FORK-MINCOST-ROUND-REPAIR-NO-v1`、`UM-COORDINATE-REPAIR-ST-GAP-v1`、`UM-OPT-HULL-LONG-CHAIN-LOCAL-GAP-v1` 与 `UM-OPT-HULL-CLOSED-CYCLE-WEAK-LOCAL-GAP-v1` 等边界身份。本文只归档其实际证明和证据，不把“主目标仍 OPEN”改写为算法结论。

# 一、单位任务 C2-load 族

## 1. 定义域和精确命题

对每个整数 (m\ge 3)，实例有 (m) 台相同机器、(n=m+1) 个单位任务，(p_{ja}=1)，阈值取 (t=n/m=1+1/m)。正文的 `C2-load(t)` 只包含全局次数四 PSD 矩、one-hot 守恒和次数一的逐机负载 localizer；它明确不加入三阶条目逐项非负，也不加入完整单机配置约束。

构造的兼容伪矩对包含 (k\le4) 个不同任务的端集 (S) 定义为

\[
 y_S=\frac{\prod_a(t)_{c_a(S)}}{(n)_k},
\]

其中 (c_a(S)) 是端集在机器 (a) 上的次数。递推
\[
 y_{S\cup\{(j,a)\}}=\frac{t-c_a(S)}{n-k}y_S
\]
给出任务守恒和 (L((N_a-t)x_S)=0)；正文还说明负载 localizer 的全部条目为零。因此约束核的主要工作是证明二次空间上的 (M_2\) PSD。

正文以任务 harmonic/机器零行和核分解二次空间：一次块、对称 harmonic 块和反对称 harmonic 块两两正交。对称块的 Gram 化为
\[
 K_S(B,C)=\alpha\left(F-\frac m{n-2}H+\frac d{(n-1)(n-2)}\right),
\quad \alpha=\frac{t^2}{n(n-3)},
\]
在 (n=m+1) 时由逐行 Cauchy–Schwarz 得正定；反对称块为
\[
 K_A(C,D)=\frac{t^2F}{(n-1)(n-2)},
\]
也正定。由此构造给出全部 (m\ge3) 的自足 C2-load 证书，而非只给有限参数的数值 PSD 现象。

## 2. 间隙、边界和伪矩性质

真实调度的最优峰值为 2：(m+1) 个单位任务不能全部分开，且把两个任务放在同机即可达到 2。C2-load 的平均负载下界是 (t)，构造达到该阈值，所以该松弛在此族上的整数比为
\[
 2/t=2m/(m+1)\longrightarrow2.
\]
结合正文引用的经典两倍舍入上界，正文把普通 `C2-load`（精确定义为上述端剪枝版本）的全类整数间隙上确界判为 2；这不是某个贪心在单一实例上失败。

证书不是概率分布。任意三个不同任务同机的三阶矩是 (-1/m^4)，所以加入三阶单项式非负就会排除该证书。对 (T<2)，完整 `CONFIG(T)` 每台机器至多容纳一个单位任务，共只能覆盖 (m<m+1) 个任务，因此 CONFIG 阈值为 2。本族只说明 C2-load 不蕴含 CONFIG 可行性，也不说明 C2 与 CONFIG 合取仍有趋二间隙；更强系统的支配关系必须另证。

## 3. 证据和可信度

正文给出 rank
\[
 \operatorname{rank}(M_1)=1+m(m-1),
\quad
 \operatorname{rank}(M_2)=1+m(m-1)+\frac{m^2(m-1)(m-2)}2,
\]
并用 `c2_unit_multislice_gap.py` 做 (m=3,4) 的完整精确 M2/约束审计、(m=3,\ldots,8) 的指定 Gram 公式核对；`c2_unit_multislice_independent.py` 用独立整数 Bareiss 路线复核并覆盖 (m=2) 失败边界。已有 `C2前缀满载与单位多切片有限审计` 已登记这些冻结运行及有限范围，本批把当前正文的全称证明、伪矩性质与较强 CONFIG 边界补进统一正文。

这些运行记录支持代码、哈希和所列参数，不代替正文中对 (m\ge3) 的块分解证明。m=2 的 PSD 失败、三阶负条目和 CONFIG 不可行是反对扩大范围的有效边界；它们不是对所有更强松弛的反例。

## 4. 用途与后续义务

可回收用途是准确关闭一个旧问题：只靠普通四阶全局负载共同矩和次数一 localizer，不能期待统一小于二的负载阈值。下一步应把研究对象明确升级到三阶非负、完整配置或有效的前缀/计数局部化，再分别分析其舍入；不能在正文中把该族当作原模型困难性或可解性结果。C2 族输入本身显然易解，故其价值是松弛边界而非复杂度下界。

# 二、循环批量优化器与修复障碍

## 5. 正面局部优化器

给定有理 (T>0)、实际合法调度 \(\sigma\) 且 (C_{\max}(\sigma)\le2T)，只使用 (E_T=\{(i,j):p_{ij}\le T\})。菜单项 (e=(u,v,S)) 从机器 (u) 一次迁出非空任务子集 (S)，定义撤离量 (r_e) 和到达量 (c_e)。若不同机器组成的循环中每处 (c_{e_{t-1}}\le r_{e_t}-\lambda)，则每个参与机器下降至少 \(\lambda\)。

正文的显式菜单引理把菜单项建成有向图：边 (e\to f) 表示目的地/源机器衔接且 (c_e\le r_f-\lambda)。强连通分量中存在严格转向即可找到闭走步；通过比较重复机器两次出现的入出量并剪接，可在多项式时间内消去重复源机器。对于 \(\lambda=0\)，还必须保留至少一个严格转向，不能把普通有环误当作改善循环。

为了避免把所有任务子集当作免费输入，正文用 (h=\eta T/(2n)) 和整数收益 (z_j=\lfloor p_{uj}/h\rfloor) 做每个有向机器对的精确背包压缩。每个精确收益只保留最小到达成本的代表，收益总和至多 (Q=\lfloor4n/\eta\rfloor)。任意真实每机余量至少 \(\eta T\) 的批次被替换为代表后仍保留至少 \(\eta T/2\) 的余量，因此菜单找不到 \(\eta T/2\) 循环时，真实 \(\eta T\) 循环也不存在。

每轮所有参与机器至少下降 \(\lambda=\eta T/2)，总工作量初值至多 (2mT)，成功轮数至多
\[
 \lfloor 2mT/\lambda\rfloor=\lfloor4m/\eta\rfloor.
\]
菜单、图搜索和固定次数有理运算的位长都受输入长度及 (1/\eta) 多项式控制。准确结论是“固定 \(\eta\) 下的确定性局部优化器及位复杂度闭合”；当 \(\eta) 是输入变量时只能说关于 (1/\eta) 多项式，不能误写成关于 \(\log(1/\eta)\) 多项式。

优化器终态没有真实 \(\eta T\) 批次循环，但不保证 makespan 有统一改善；参与机器可能不是当前瓶颈。T=0、空任务和 m=1 的分支在正文中单独处理，不能把零余量循环结论外推到这些分支。

## 6. 无界批量和单目的地边界

三机族中，A 有两个大任务，B、E 各有 (2k) 个小任务。当前负载均为 2；把两个大任务分别移到 B、E 并把各 (k) 个小任务移回 A 可达到 1。对任意 lex 改善，若某大任务离开其当前机器，对应叶机至少要迁出 (k) 个小任务；若不迁大任务，A 接收任何小任务会超载。因此最少支持为 (k+1)，且某一机器最少迁出 (k) 件。该计数论证排除固定任务预算或固定单机迁出预算的普适单调修复合同，但不是复杂度困难性。

三机分流合流核心进一步说明：在 (C=2-\theta) 的坏状态中，唯一保持 makespan 不增的非平凡调度必须让 A 同时向 B、E 迁出任务，并让 E 向 B 迁出任务；这需要多目的地释放和接收。正文先证明裸三机核心的 (T=1) assignment-LP 点实际上唯一是最优整数点，因而不能冒充给定 LP 支撑的舍入反例，再加入 (N=8k) 台带私有任务的 H 机器构造正支撑有理点，证明所有最小总处理成本槽匹配共同诱导坏的机器分配，(C_{\max}=2-1/k\)。因此准确否定的是“任意可行 LP 点 + 最小成本槽匹配 + 每机至多一个迁出目的地且 makespan 不增的修复”这一合同。

这里仍不能扩大成配置投影、所有槽算法或所有 LP 点的失败：该正支撑点在 A 上的大任务质量违反目标 1 配置点的某些基数强化；正文明确保留配置初始化作为未解决路线。

## 7. 真实最优凸包、长链与闭环

正文另把固定槽结果与真实最优凸分解连接起来：在相同机器、总工作量守恒的族中，任何逐机负载非增的重分配都只能保持每台机器负载不变，所以 `UM-COORDINATE-REPAIR-ST-GAP-v1` 能把该类完整槽初始化停在趋二状态；这只排除逐坐标非增修复，允许接收机暂时上升并保持全局峰值下降的算法不在范围内。

`UM-OPT-HULL-LONG-CHAIN-LOCAL-GAP-v1` 用真实最优凸组合和全部最小成本槽输出，把严格 lex 改善的最小任务支持增至 (d+1)，最小端点机器数增至 (d+2)。它还有一个重要正面边界：按链尾到链首逆序释放空位，允许中间 lex 变坏但最大负载不增，即可逐件到达最优。因此它不能被记录成一般 reconfiguration 困难性。

`UM-OPT-HULL-CLOSED-CYCLE-WEAK-LOCAL-GAP-v1` 把链尾接回已满 root。对每条闭环以 (z_l\in\{0,1\}) 表示是否向第二端迁移，因 (1+a>B_k) 得 (z_0\le z_1\le\cdots\le z_h)。sigma 只激活一条最便宜的环；任何不同且最大负载不增的分配必须新迁出一条原留 root 的任务，并被迫激活整环，故最小非平凡任务支持和参与机器数均为 (d+1)。有限精确枚举和独立整数缩放审计覆盖所列 (k,d) 参数，但不承担一般算法下界。单任务路径允许极小临时超额 (c=1/k^2) 后即可逃逸，最小路径峰值为 (B_k+c)，这正是该障碍的边界。

这些长链/闭环结果强化的是“给定真实最优凸包初始化后的局部邻域合同”边界，未排除允许无界批量、暂时增载、全局重求解或直接使用已知最优分解的算法。它们与三机分流反例的机制不同：前者主要是容量释放路径/闭环的支持下界，后者是多目的地分流需求。

# 三、跨源关系与未解问题

1. C2 单位多切片证明了普通 C2-load 的松弛间隙；周期批量正文研究给定整数调度的局部修复。一个不能用来推出另一个的 SDP、LP 或初始化结论。
2. 周期菜单的背包编译闭合了“给定菜单如何在位复杂度内找固定余量循环”的算法义务；它没有从原始 assignment-LP 自动生成可接受菜单，也没有给 UM-TARGET-v1 的统一近似比。
3. 无界批量、无界循环长度、单目的地限制、逐坐标不增、严格 lex 邻域、弱最大负载不增邻域分别是不同合同。审查记录保留这些量词，不能用某个反例偷换另一个。
4. 真实最优凸包和配置投影应继续作为独立身份处理。闭环族的完整配置分布是真实最优调度凸组合诱导的，因此可用于检验“配置点自动消除所有局部障碍”的说法；但它仍不排除允许暂时超额或全局批处理的算法。
5. 可继续判别的正面义务是：如何从具体有效的配置/共同容量对象构造多源多目的地批次，如何同时控制新的最大负载，以及是否能把周期局部优化器嵌入统一近似算法。负面结果不等于主目标已证伪，也不等于任何算法困难性。
