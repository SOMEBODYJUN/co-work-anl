# 共同大任务选择的独立集阈值障碍（候选）

**候选身份：`UM-INDEPENDENT-SET-BIG-RESIDUAL-INTERFACE-v1`**
**认知层：** 精确归约与有限 Fraction 审计；不是新的主目标困难性定理。
**作用：** 给“先共同选择大任务位置、再用一次残余流补齐”的接口一个最小的 NP 障碍；明确该障碍的间隔只到 `4/3`（或带私有任务的 `5/4`），不能把它误报成统一 `2-epsilon` 困难性。

## 1. 精确输入族

输入是最大度 `Delta` 的简单图 `G=(V,E)`、整数 `k>=1`。取一个有理阈值 `alpha`、正有理 `h` 和整数 `r>=1`，满足

```
1 < alpha < 2,       r*h = alpha - 1,       Delta*h <= 1.
```

（固定实例可取 `Delta=3, h=1/3, r=1, alpha=4/3`。）为比较端点，下面也给出允许 `r=0, alpha=1` 的简化变体。机器集是 `M=V`；处理时间未列出的位置为 `infinity`。任务数为 `k+r|V|+|E|`，因此固定参数时构造和编码均为图规模的多项式。

任务如下：

* 有 `k` 件宏任务 `B_1,...,B_k`，每件在每台图机器上时间 `1`。
* 对每个顶点 `v`，有 `r` 件私有微任务 `P_{v,1},...,P_{v,r}`，每件只可在 `v` 上执行，时间 `h`。
* 对每条边 `e={u,v}`，有一件边微任务 `Q_e`，只可在 `u,v` 上执行，时间 `h`。

令 `alpha_G` 表示图的独立数，避免与调度阈值 `alpha` 混淆。候选命题为

\[
  \operatorname{OPT}(P_{G,k,h,r})\le \alpha
  \quad\Longleftrightarrow\quad
  \alpha_G\ge k. \tag{IS-TH}
\]

更精确地（`k>=1`）：若 `alpha_G>=k`，则 `OPT=alpha`；若 `alpha_G<k`，则 `OPT>=min{2, alpha+h}`。这里的 `2` 分支来自两件宏任务落在同一机器；当 `alpha+h<=2` 时得到 `OPT>=alpha+h`。端点 `r=0,alpha=1` 同样满足阈值等价和 `OPT=1`/`OPT>=1+h` 的陈述。

## 2. 双向证明

### 独立集给出的调度

取大小 `k` 的独立集 `I`。把 `k` 件宏任务分别放到 `I` 中的不同机器（`alpha<2`，每台机器至多一件宏任务）。每个私有任务放在自己的顶点。

由于 `I` 独立，每条边至少有一个未占位端。把边任务 `Q_e` 定向到任意未占位端。占位机器 `v in I` 的负载为

\[
1+r h=1+(\alpha-1)=\alpha.
\]

未占位机器至多接收 `deg(v)` 条边任务，故负载至多

\[
rh+\deg(v)h \le (\alpha-1)+1=\alpha,
\]

其中使用 `deg(v)<=Delta` 和 `Delta*h<=1`。所有任务均已安排，因此 `OPT<=alpha`。又因每件宏任务时间为 `1` 且 `k>=1`，`OPT>=1`；当 `r>=1` 时占位宏机器还强制私有负载 `rh=alpha-1`，所以 YES 实例确有 `OPT=alpha`。端点 `r=0,alpha=1` 由宏任务给出 `OPT=1`。

### 阈值调度推出独立集

设存在调度使 `C_max<=alpha<2`。任何机器至多放一件宏任务；令 `I` 为承载宏任务的顶点集合，则 `|I|=k`。若 `u,v in I` 且 `e={u,v}`，则 `Q_e` 只能放在 `u` 或 `v`。任一 `v in I` 还必须承载其 `r` 件私有任务，总负载至少 `1+rh=alpha`，因此没有容量给 `Q_e`；矛盾。故 `I` 独立，得到 `alpha_G>=k`。

若宏任务位置 `I` 互异但不独立，取其内部边 `e={u,v}`。`u`（或 `v`）上的宏、全部私有任务和 `Q_e` 已产生

\[
1+rh+h=\alpha+h.
\]

若调度把两件宏任务放在同一机器，则该机负载至少 `2`；因此任意调度均有 `C_max>=min{2,alpha+h}`。

### 固定宏集合后的残余通过量（更强的接口读法）

固定一个宏占位集合 `I`（要求 `|I|=k`），先放置全部私有任务。每个顶点因此消耗 `rh=alpha-1`；边微任务在未占位顶点有容量 `1`，在占位顶点有容量 `0`。由于每条边任务大小为 `h` 且 `Delta*h<=1`，所有非内部边 `E\setminus E(G[I])` 可以同时放入未占位端，内部边只能完全未安排。于是固定 `I` 的残余分数吞吐也恰为

\[
F_I=|E|-|E(G[I])|, \qquad D_I=|E(G[I])|.
\]

这里没有把分数残余 LP 误当整数充分条件；本族中相同尺寸和零/一容量恰使该固定状态的分数与整数缺口一致。`I` 的共同选择仍等价于寻找大小 `k` 的独立集。

## 3. 两个固定参数实例

### 3.1 `r=0, h=1/3, alpha=1`：最强的本地间隔

最大度三图独立集是 NP 完全问题。取 `h=1/3`、`alpha=1`、无私有微任务。则

* `alpha_G>=k` 时 `OPT=1`；
* `alpha_G<k` 时 `OPT>=4/3`。

因此，若能对这类输入多项式地判定或构造 `C_max<=1`，即可解最大度三图独立集；在 `P!=NP` 下，该联合 big 选择/残余补全接口不能是一般的精确多项式子程序。该构造也给出该子类的 `4/3` 间隔（不是接近 `2` 的间隔）。

### 3.2 `r=1, h=1/3`：固定 `alpha=4/3` 且保留私有占位

仍取最大度三图，加入每个顶点一件 `1/3` 私有任务。此时 `alpha=4/3`，YES 实例 `OPT=4/3`，NO 实例 `OPT>=5/3`，得到 `5/4` 的比值间隔。它更贴近“占位后残余容量”的接口，但间隔比 `r=0` 更弱。

### 3.3 任意固定有理 `alpha in (1,2)` 的精确阈值

给定固定有理 `alpha`，选常数整数 `r>=max(1,ceil(3(alpha-1)))`，令 `h=(alpha-1)/r`。最大度三图满足 `Delta*h<=1`，因此同一双向证明给出 `OPT<=alpha` 当且仅当 `alpha_G>=k`。这说明“精确判断一个给定 `alpha<2` 的共同 big/残余状态”在每个固定阈值上都保留 NP 障碍；其 NO/YES 乘法间隔一般随 `h` 变小，不能用来声称接近二的近似困难性。

## 4. 该障碍的准确范围

1. 这是精确阈值/联合选择的 NP 障碍，不是 `UM-TARGET-v1` 的统一 `(2-epsilon)` 反面证明。`r=0,h=1/3` 的间隔只有 `4/3`；`r=1,h=1/3` 的间隔只有 `5/4`。已知更强的 `3/2` 下界也不由本页取代。
2. 归约只说明：把宏任务位置 `I` 作为共同状态、再在固定 `I` 上补边微任务，不能在全输入上假设有一个免费多项式选择器。它不排除同时重选宏与微任务的其他算法，也不排除使用更强配置/割信息。
3. 任务时间只有 `{1,h}`，图机器数和任务数均为图显式规模的多项式；该候选没有数值展开或伪多项式步骤。固定 `h` 时所有时间是常数位长。
4. `k=0`、`E=empty`、`r=0` 等退化边界需按原模型分别处理；本页的比值结论假设 `k>=1`。每个任务仍至少有一个有限端。
5. 这是对“共同容量状态”的局部否定：即使剩余问题只是相同尺寸 `h` 的边任务，宏占位集合的可行族仍可编码任意图独立集（固定 `r=0` 时是阈值 `alpha=1` 的简化）。不能把该局部障碍升级为一般近似困难性，亦不能反向声称主目标已失败。
