# 共同资格私有组的加权出口流与联合有序槽舍入

本稿给出一个正面结构接口：不要求私有组总负载有正下界，也不固定接收机器数；同一个网络联合选择宏任务位置与整组接收机器。主目标 `UM-TARGET-v1` 仍OPEN；一般矩阵如何获得本稿的唯一home、共同资格和等端体积结构，尚未解决。

精确身份为 `UM-WEIGHTED-GROUP-JOINT-SLOT-v1` 和 `UM-WEIGHTED-GROUP-PROMISE-APPROX-v1`。标准有理LP、有序单位槽和整数流是已知工具；新增合同是它们与组出口需求及真实前缀的组合，不认证全球新颖性或独立论文价值。内部独立重构、冻结审查及有限证据从§8进入；外审未记录。

## 1. 对象、量词和准确合同

显式给机器不交并 `H∪Z`，总机器数至少一。全部任务不交分成宏任务集B和私有组 `J_h (h∈H)`。宏任务仅在H可用，每件至少有一条有限端，耗时可随home不同。对每个h给共同资格 `E_h⊆Z`，允许为空；每件 `j∈J_h` 恰在 `{h}∪E_h` 可用，全部有限端时间同为非负有理 `w_j`。写 `W_h=Σ_(j∈J_h)w_j`。所有原任务、机器和资格均显式列出，没有紧凑任务重数。

**UM-WEIGHTED-GROUP-JOINT-SLOT-v1（给定阈值）。** 对所有上述输入、二进制有理 `T≥0, 0≤δ<1/2`，假设

`W_h≤T，w_j≤δT，全部有限宏端 p_hb>T/2`。

存在统一确定性总位多项式算法，返回FAIL或完整合法实际分配；成功时同时满足

`L_h≤(3/2+δ)T (h∈H)，L_z≤3T/2 (z∈Z)`。

若OPT≤T，算法必成功，所以在此假设域内FAIL蕴含OPT>T。成功不判定原T整数可行。机器数、组数及接收机数均可增长。宏端大于T仍允许存在，算法剪去它们。

**UM-WEIGHTED-GROUP-PROMISE-APPROX-v1（未知最优值）。** 对所有上述结构和 `0≤δ<1/2`，不给T，承诺在真实OPT处 `W_h≤OPT, w_j≤δOPT` 且全部有限宏端 `p_hb>OPT/2`。存在统一确定性总位多项式算法输出实际完整分配，满足 `Cmax≤(3/2+δ)OPT`。OPT0和空任务包括在内。固定δ时，这个结构类有统一改善 `ε=1/2−δ>0`；允许δ趋向1/2时不声称统一ε。

两合同都不提供从一般P生成这种分组的算法。它们改变了假设，不能替代UM-TARGET-v1。未知OPT的promise也不被当作可免费识别的性质。

## 2. 一个共同的加权出口LP

先设T>0。定义home的虚拟出口量

`d_h(T)=max(W_h−T/2,0)，0≤d_h≤T/2`。

给每个h一个私有旁路标签 `⊥_h`，仅当d_h=0时可用；旁路没有实际机器，最终不接任何任务。LP变量为 `a_bh≥0`（仅p_hb≤T的有限宏端）、`y_hz≥0 (z∈E_h)`，以及d_h=0时的 `y_h⊥≥0`。要求

`Σ_h a_bh=1 (b∈B)，x_h:=Σ_b a_bh≤1 (h∈H)`，

`Σ_(z∈E_h)y_hz+y_h⊥=x_h`，

`Σ_h d_h y_hz≤T (z∈Z)`。

无旁路时对应变量为0。x只是简写，所有系数均是显式有理数；这是规模多项式的普通有理LP，不是配置LP或整数oracle。不要求LP解为极点。

**必要性。** 若有真实T调度，宏端>T/2使每个home至多一个宏。取它的宏分配给a。占用home h若d_h>0，其私有出口总量e_h满足

`e_h≥W_h−(T−p_hb)>W_h−T/2=d_h>0`。

令e_hz为其中送到z的真实体积，取 `y_hz=e_hz/e_h`。每个占用home送单位token，且 `d_h y_hz≤e_hz`；故每sink加权总量≤真实负载≤T。d_h=0的占用home走旁路，未占用home的a,y均零。共同资格保证这一单位token允许接收该组所有任务。LP因而可行。

等端体积是将真实sink工作量与d_h使用同一单位的理由；不能在异端时间时省略这个假设。

## 3. 同一个整数流联合选择宏任务、home和槽

取得任意有理LP解。对每个真实sink z，把正y_hz按d_h非增序（同值按home编号）连接成连续区间，每个h区间长度y_hz。用单位槽切开；h连接与其区间正交长的槽。槽数为 `ceil(Σ_h y_hz)≤|H|`，边权取交长。零d_h的y也允许出现，排序到末尾。

建有向网络：源→每宏b（容量1）；b→h_in（原宏端满足p≤T，容量1）；`h_in→h_out`（容量1）；h_out→所有与h正交长的槽（容量1）；每槽→汇（容量1）。若d_h=0，另加h_out→汇的容量1旁路。

LP解及上述交长给这个网络值|B|的分数流：源/宏/home部分用a，下游槽部分用y的交长，旁路用y_h⊥。home守恒正是LP中的同一个x_h。网络全为整数容量，因此确定性增广路能找到值|B|的整数流。

每条宏路径选一个合法home；home容量1保证不同宏不共用home。非旁路路径还选一个真实sink槽，槽容量1保证每槽至多选一个home。这里没有先分别固定宏匹配与接收匹配，因而不需要把两个独立证书拼接。

**同时负载界。** 若sink z的第r≥2槽选了home h，由排序，其前一个完整单位槽内所有d值都至少d_h。故选中d_h可收费给前槽的分数加权量。首槽至多增加 `dmax≤T/2`。所有前槽互不重叠，所以对每个z同时有

`Σ_(h被整数流送z)d_h≤Σ_h d_h y_hz+dmax≤3T/2`。

空槽、最后不足单位槽及没有被选中的槽均不影响收费。这个证明是经典ST有序槽机制在home-token上的应用；保留中间home容量才能同时守住宏任务身份。

## 4. 真实任务恢复：每组的离散误差由home支付

未占用home把其私有任务全部留原处，负载W_h≤T。占用home h设 `τ=1/2+δ<1`。

若W_h≤τT，不撤任务。否则按原任务编号扫描一个前缀并送到流选定的sink，直到留下的真实私有负载≤τT。此时W_h>τT≥T/2，故d_h>0，路径不可能走旁路。

最后一件撤离之前，出口体积严格小于W_h−τT；该件至多δT，故实际出口

`e'_h < W_h−τT+δT = W_h−T/2 = d_h`。

若根本不撤，则 `e'_h=0≤d_h`。每件任务都具有共同E_h，因此整段前缀在所选sink上合法，且耗时仍是w_j。零尺寸任务只增加有限扫描次数，全部任务撤完后留量0，故过程终止。

选中宏时间≤T，留量≤τT，因而每occupied home负载≤(3/2+δ)T；旁路home因d_h=0有W_h≤T/2，也满足此界。由§3，对每sink

`L_z=Σ_(h送z)e'_h≤Σ_(h送z)d_h≤3T/2`。

关键是实际出口不超过虚拟d_h；不能逐组把δT加到sink上。所有组舍入误差由各自home的δT余量支付。

## 5. 零值、总位复杂度和失败语义

T0先检查每任务是否有零端；若全有就逐任务选零端，否则FAIL。合同内私有任务全零；若存在宏，其有限时间>0，故OPT≤0不可能。空任务直接返回空分配。Z或E_h为空不妨碍零需求旁路；正需求占用home没有接收端时，LP会正确禁止它。

普通有理LP的确定性位多项式可行性算法提供一个多项式位长的有理可行解或正确不可行结论。LP变量/约束数均为显式输入的多项式。此处依赖标准有理LP多项式可解性，不依赖浮点近似可行或精确SDP假设。

y_hz≤x_h≤1，每个区间最多跨两个槽。网络大小是输入多项式；每次BFS增广至少1，总流量至多|B|，因此至多|B|次增广。排序、交长和负载都用有理加减比较；分母乘积位长至多被使用分母位长之和。前缀总共扫描至多全部私有任务数。输出恰全部原任务的一个机器标签，总位长多项式。

因此整个算法总位多项式，包括LP、造槽、流、扫描和输出。代码目前实现的是**给定精确LP见证后的验证和实际舍入**，不实现通用位多项式有理LP后端；这项软件范围与完整数学算法分开记录。

舍入的成功保证只使用p_hb≤T及home至多一宏，不使用p_hb>T/2。宏下界只用于§2的OPT≤T必有LP见证。因此阈值子程序可在没有宏下界时运行并保持成功界，但其FAIL此时不能自动被解释为OPT>T。

## 6. 不知道OPT：单调LP测试和整数网格二分

先检查全部任务零端；能全选零端就输出零调度。若δ=0但有正私有任务，则不在promise域；可拒绝。其他情况继续。取Q为输入所有有限时间分母之积；bitlen Q至多输入分母位长之和。每个原调度负载及OPT都是1/Q的整数倍。

在网格t=k/Q上测试：`W_h≤t, w_j≤δt`，且§2LP(t)可行。**不测试宏端>t/2。** 随t增加，宏可用边只增加，d_h(t)只下降，sink容量只增加；d_h变0时新增旁路。旧可行a,y可继续使用（保留旧sink流即可），故接受条件单调。

逐任务任取一个有限端形成合法调度，令U为其全部处理时间之和。U≥OPT，且QU为整数，位长多项式。promise下OPT处满足§1条件，故测试接受OPT；由单调性也接受U。若U未被接受则可报告promise域外，不作一般实例不可行判断。

在整数区间[0,QU]二分最小接受k，记t=k/Q。至多 `O(log(QU+1))` 次LP测试；这是编码长度界，不是按Q或U数值枚举。OPT在网格且被接受，所以t≤OPT。promise还给全部宏端 `p_hb>OPT/2≥t/2`，故t上全部阈值合同成立，输出

`Cmax≤(3/2+δ)t≤(3/2+δ)OPT`。

t0时若被接受，LP只能使用零宏端且私有全零，直接输出零端即可。δ0的全零私有情况也由同一网格处理；无需除以δ。若无宏，全部私有留home即可，仍满足声明界。

## 7. 与已有结果的关系、限制和接续义务

[共同资格组Hall流](hall_group_joint_flow.md)用固定q接收槽及组负载下界获得 `q(2+δ)/(q+1)`。本稿使用真实尺寸d_h的加权LP和有序槽，去掉该正下界及q；接收机数仍不固定。它不是修改旧Claim的量词，旧身份保持不变。在两者共同适用时可运行两算法取更好的实际调度；并未宣称本比率逐参数总更小。

[固定sink占位舍入](fixed_sink_occupation_rounding.md)和[完整profile池](shared_sink_joint_macro_assignment.md)分别有固定接收维数、完整资格及work包络等不同合同。本稿允许不完整资格，但一组的任务必须共享同一E_h，且所有有限端耗时相同。

新增可复用机制是 `真实出口下界→home虚拟尺寸→带home容量的共同槽流→出口不超尺寸的前缀恢复`。所用ST原始机制已登记于LITERATURE的ST1993（Theorem2.1，PDF3/印463及Corollary2.3，PDF6/印466）；原文不声称本稿这个分组合同。标准工具扣除后，本稿只是一个结构扩展，全球优先权及独立论文价值未认证。

若组内任务接收资格不同，单位home-token到某sink不保证该sink能接整个前缀；若接收端时间不同，d_h y_hz不再自动被真实负载支配。宏端不大于T/2时，一个home的真实T解也可有多个宏，单位home容量不再是必要条件。这些是证明适用条件，不是对应更一般模型的困难性结论。

下一承重义务是对一般任务身份和异端容量构造仍可联合舍入的表示；不能把本类的给定分组当一般输入的免费分解，也不能把本结构类的固定δ统一余量升级为UM-TARGET-v1。
