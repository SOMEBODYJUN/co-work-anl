## 2. 集合对象与弱递推的独立核对

配置分布在每机的有限任务子集上，跨机器只要求任务边际覆盖和1，没有共同 law。负载直方图保留所有机器和全部负载0..K坐标。弱递推每个 branch 的每一行质量都是同一个 θ_i；仅 aggregate 在前一弱层，正文明确没有逐 branch 的 perspective hull 约束。这与随后定理及反例使用的是同一对象。

允许任务删边后没有 finite 端是明示扩域，不是把普通 UM 合法输入条件悄悄删除。若当前 E_j 为空，θ 和为1不可能；CONFIG 的该任务覆盖也恒0，故两侧均空。前层为空时弱层空；反向配置的前缀限制也排除产生不一致边界。

### 2.1 弱点到 CONFIG

从最终弱点递归取有限 j 层 witnesses。对每机、每阶段，把 own branch 的 own row 作为 selected 流，其余 branches 的该行之和作为 skip 流。两者合计为旧行；own selected 质量 θ_r，跨 r 总量1。容量面和非负性迫所有越 K 的 selected 流为0。逐机得到从负载0出发的单位分层 DAG 流。

每条有限路径每个阶段只取 selected 或 skip，故记录的是带原任务标签的子集，不会重复选择任务。其实际总处理量就是末层负载，且沿路径始终≤K。任务 ℓ 在机 r 出现的边际为该层 selected 总量 θ_{r,ℓ}，跨机器和1。末层直方图正是原弱点。此方向没有引入跨机共同路径分布。

a=0 时 selected/skip 同起止负载但仍是不同阶段弧变量，故不同零任务没有按负载合并。∞ 端没有 selected 弧；不可用 own branch 按0处理正确。

### 2.2 CONFIG 到全部弱前缀

对任何 CONFIG 的实概率点，按真实前缀定义 v⁺、v⁻。own row v⁺ 的质量为 x_r；非 own row 在 x_r<1 时的质量是

    x_i · (1−x_r)/(1−x_r)=x_i。

当 x_r=1，任务精确覆盖使所有其它 x_i=0，而 v⁻=0，因此末分段确实是0、既不丢质量也不作0/0。若 r 不可用，则 x_r=v⁺=0；其行由其它 branches 的 x_i v⁻ 累加恢复，总量仍1。

跨 branches 累加，每行得到 v⁺+v⁻。own branch 中正质量来自包含当前任务的原配置；非负处理时间保证“前缀负载+当前任务”不超过该完整配置负载≤K，因此容量面成立。平移 own v⁺、保留 v⁻ 后就是下一真实前缀直方图。由空前缀归纳，aggregate 确实在此前弱层，不是免费取真实 hull。由此得到每个前缀的两侧包含，覆盖所有实概率点。

### 2.3 退化输入

- j=0：各机仅空配置，P₀ 与初始 h⁰ 完全一致。
- K=0：只能选择 zero 端；负载弧可以平行但任务标签仍独立，证明不除 K。
- 某任务无资格：两侧同时空，如上所核。
- m=1、空任务、静止目的地、zero/∞ 混合：没有使用 m≥2、正处理时间或所有资格非空的隐藏假设。

## 3. LP 与位复杂度核对

正文的显式 flow 描述足以写出线性系统：每机层0..j、负载0..K；每一阶段的 skip/selected 弧独立，selected 只在 finite 且不越界时存在；节点流守恒；初始点单位供给；末层用 y_{r,s} 作为退出流。后一个写法也统一覆盖 j=0，此时没有阶段弧，末层退出量直接等于初始 Dirac。

每机 selected 路径恰对应一配置，逐机 flow 混合与配置分布互转；每任务跨机 selected 总流1正是额外覆盖等式。因此它与前述 CONFIG 投影相等。正文明确这些跨机行破坏纯网络 TU 的自动整数结论，没有误称完整 LP 可整数求解。

skip 弧 O(mj(K+1))，selected 弧至多所有前缀 finite incidences 乘(K+1)，末层 y 及节点数由 m(j+1)(K+1) 控制。式(3) 的 +1 正确保 j=0。`E_[j]` 在该计数中按前 j 个任务的全部 finite incidences 理解；即使只用 m(j+1)(K+1) 的较粗界，selected 弧数也已被控制，这不影响所陈复杂度。

整数 a 只用于计算节点下标；flow 行与任务覆盖行的非零系数为±1，供给/覆盖右端为0或1。所有弧流与 y 均处于[0,1]，可行多面体有界。标准精确有理 LP 的 feasibility、可行点及 Farkas 证书有显式总位长的多项式界；有理线性目标必须另计 L_obj，正文已明说，没有精确实数比较前提。

当 K 用 binary 输入时，展开 K+1 个负载坐标确是数值 K 的伪多项式量，不是 poly(log K)。正文没有把这个 LP 宣称一般 UM 的位多项式精确整数 oracle。

## 4. 向下舍入可靠 NO 的逐项核对

T>0、n≥1、固定有理 δ∈(0,1) 时 q=δT/n>0，K=⌊n/δ⌋=⌊T/q⌋。先删 p>T 资格后，每剩余 finite a=⌊p/q⌋都在0..K，落入整数模型；删空的任务可按允许无资格的分支可靠拒绝。

给原 actual T 调度，其端全部保留；每机

    Σ⌊p/q⌋ ≤⌊Σp/q⌋≤⌊T/q⌋=K。

因此逐机点配置给舍入 CONFIG 可行，也即该 LP 可行。逆否才是可靠结论：LP infeasible⇒原 OPT>T。LP feasible 不承诺原实际调度，正文没有偷换这一方向。正 p 舍入成0也不删除任务，selected 标签机制仍保留覆盖。

固定 δ 时 K=O(n)，构造与有理 floor 运算按原始总位长多项式。若 δ 作为输入，依赖数值1/δ而非其对数已经明示。T=0 的逐任务 zero 端检查及 n=0 空调度分支正确避开 q 的未定义。

## 5. 四机六任务的独立完整有限回算

本审者只从正文原表重写六个任务的两端，使用精确整数/Fraction 独立枚举原合法 assignments，未读或调用 source audit。结果：

| 前缀任务数 | 原 assignments 数 | C≤3 数 | C≤3 的实际负载向量 | actual OPT |
|---|---:|---:|---|---:|
| 4 | 16 | 2 | (3,3,2,2)、(2,2,3,3) | 3 |
| 5 | 32 | 2 | (3,2,3,3)、(2,3,3,3) | 3 |
| 6 | 64 | 0 | 无 | 4 |

另逐行核正文每机两配置都负载3、每个原任务覆盖恰1。j₂ 只有时间3端，给 CONFIG 阈值≥3；证书给≤3，所以恰3。

独立指定 A 的 z¹、z²：own row 各取2态半量，另一候选行取3态半量，机3/4各取2/3态各四分之一。核得每 branch 每行质量1/2、aggregate 等于 h₄、容量面成立，输出

    h₅=(δ₃,δ₃,(δ₂+δ₃)/2,(δ₂+δ₃)/2)。

真实 H₅ 的两份 actual assignments 的机3/4均恒3，故此弱 h₅ 不在 H₅。继续按正文 B 两 branch 取各自2态半量、另一候选行3态半量，核得所有行质量与 aggregate 同时正确，最终 h₆=(δ₃,δ₃,δ₃,δ₃)。这些只是校准例子，不替代一般等式证明。

解析下界也核通：C<4 时前四任务每件在任一合法端至少2，任一机不可能放两件，所以仍只有 D/O 两个匹配。D 的1/2机已3而阻塞 A；O 的3/4机已3而阻塞 B。正文 D+A→1+B→3 的完整六任务分配负载(4,3,3,2)，故 exact OPT=4。同步除3后的4/3差距是精确缩放。

若要求 B 的 aggregate 来自真实 H₅，机3/4在任何 aggregate 的≤2坐标都为0；非负拆分及 own 容量面迫 θ₃=θ₄=0，不能满足和1。因此“真 H 系统此时空、弱系统非空”的区分正确。

## 6. 真共同 hull 与方法边界

Φ 是负载的一位编码，不是各机负载值本身。真实 H_j 只取完整 capacity-K feasible 前缀 assignments 的这些共同原子。坏 own-load 坐标为0是非负暴露面：任何正权原子都不能有坏坐标，所以每个正原子都可沿该 machine 分支加入当前任务。逐 branch perspective membership 因而是保住真正共同相关性的一种充分合同；aggregate-only 弱化没有此性质。

正文没有从环境维数多项式推出 hull 的多项式 membership、生成或原子解码，也没有从这条充分合同推出所有算法必须使用它。

CONFIG 趋二族的调用被隔离为方法边界的既有依赖。对原 CONFIG 证书逐配置下舍入，仍逐机满足整数容量 K，因此这些实例确实通过本页 LP；于是“该 LP feasible 就相对原配置阈值 T 统一输出 <(2−ε)T”的合同不可能。此处不能推出相对真实 OPT 的统一次二算法不存在，正文也明确没有这样说。
