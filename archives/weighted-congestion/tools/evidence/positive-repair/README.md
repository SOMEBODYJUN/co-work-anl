# 端点面积与正修复证据

正式入口为[精确核验](../../../state/计算/端点窗口与社会修复的精确核验--计算.md)和[审查范围](../../../state/审查/端点面积与正修复的审查范围--审查.md)。13主源完整原字节156575字节，在`original/`及`source-manifest.json`保双冻结commit/path、源ID、SHA256。四份全文比较依赖在`comparison/`和独立manifest，不计本批done。

三程序仅依赖标准库、输入内嵌，数学断言均整数/Fraction，无随机、solver、容差。实际按--output合同产生三个完整`replay-*.json`，每条stdout摘要另存`.stdout.json`，stderr均空。`replay-comparison.json`记录命令、环境、exit、完整产物字段差异及文件hash；三产物与冻结报告逐字节相同。显示小数不进入断言；端点stdout只有显示摘要，精确分数在完整产物，不可互换。

原件未覆盖。单个d32证书不证明全状态反例，两有限literal实现不替代RT/SD/联合转移的一般证明；raw/near-degree审计在另一批，不混记成这里的运行。外审、新颖性和一般速度优势均未认证。
