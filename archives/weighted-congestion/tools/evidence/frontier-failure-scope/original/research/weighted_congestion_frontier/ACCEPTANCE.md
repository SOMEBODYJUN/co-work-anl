# 数学与交付验收

## 本次题目与唯一完成标准

本次共同研究集中判定：是否存在绝对常数 C≥1 和整数 d0≥2，使所有 d≥d0、所有 MODEL.md 中次数至多 d 的博弈都存在 (C d/ln d)-PNE。它是 WC-TARGET 全类门槛问题中的具体匹配上界问题，不改变 MODEL 的对象和既有结果身份。

完成须对该命题给出完整一般证明或严格否定证明。肯定证明中的 C、d0 不依赖博弈规模或权重。否定须证明：对每个 C≥1、每个整数 d0≥2，存在整数 d≥d0 和该模型中的博弈，不存在 (C d/ln d)-PNE。关键证明经独立重构和攻击，边界、外部定理适用条件与实质反驳已经处理；正文、审查、必要代码及证据按原规范入库，相关入口与账本更新并确认推送 main。外部评审和新颖性按实际情况记录。

重要 claim 的审查覆盖：精确 ID/version 和全部量词；所有 proof obligations；零成本、退化策略、极端权重和次数端点；外部定理适用条件；审查者先依据精确问题自主重构关键瓶颈，再阅读冻结证明攻击；fatal objection 的处理；后续文献与优先权；计算代码、参数、seed、精度、误差控制和实际结果；远端 commit 与文件 hash。

Truth、Value、Novelty、Mechanism、Ambition 分别记录。Paper Fact、Interpretation、Conjecture、Observation、Evidence、Canonical Record 保持各自层级。一般证明决定普遍命题，有限计算提供其实际范围内的证据；尚成立的致命 objection 阻止状态提升。

## 研究材料的保存

精确 lemma、bridge、反例、obstruction、严格失败机制和可复用实验按研究材料保存。子类界、有限实例和方法限制按其真实范围保存，不据此宣布主目标解决。可接续的候选按候选保存；完成材料所需核验后立即 checkpoint 到 main 并按需分享冻结入口，不创建研究分支。重要 claim 的状态提升再执行相应完整证明与独立攻击要求。主目标仍开放时继续追关键义务。

失败记录给出依赖、具体失败步骤、否定范围、回收结果和重试条件。改变表示或机制后，选择下一项能判别竞争解释的动作。

用户停止、实际运行限制或确无可判别下一动作时交接：写清已知、最关键未解义务、证据范围、停止原因和下一项行动，保存并推送实质成果。保存研究材料或完成交接不代表题目完成。

## 协作程序验收

每个 Work 对话使用程序生成或已记住的发布标识统一发言和提交；本地 `work.py` 加 txt 凭据能从空目录恢复，也能接续已有项目。配置一次后 `read`、`send`、`sync`、`checkpoint` 直接复用。子 agent 在内部按研究需要并行协作。

公屏是异步消息流，同级 boss 可自由研讨有启发的未完成 idea，不要求先成稿、独立审查或提交文件；同题独立工作与多路线可并行。读屏保留研究工作树，发言可恢复，并发消息均可读取；成果消息核对已推送文件的 hash。同步保留未提交成果，具体冲突可诊断，checkpoint 的远端确认可复查。纯本地测试与实际 GitHub 收发分别记录；技术核验和消息赞同不决定数学真值。

## 论文者的交付门槛

按 prompts/PAPER_WRITER.md 和 SOURCES.md 中的原文执行。正文有明确数学主语与作者主张，贡献逐一接到冻结证明和精确旧结果；条件、论证、引用完整可连续阅读。首次、最优、锐等表述有对应优先权核查。

完整成稿通读，实际导出逐页检查，保存编译命令和覆盖范围。尚无可成文贡献时交付真实贡献缺口；已有独立成果可以先行成文。写作交付与主目标成功各自验收。

## 清晰者与 Pro 交接的门槛

按 prompts/CLEANER.md 产生实际 PRO_BRIEF，而不是只提供提示词或仓库链接。未读过仓库的审读者能从材料独立重述模型、正反完成条件、可调用事实以及每条障碍的精确排除范围；关键定义、承重条件和尚存实质异议没有因压缩被隐藏。

已证方法障碍、严格断言反例、开放义务与有限观察分开。正文只保留接题必要材料，按需工具有可直接使用的接口，未排除方向不配预设 idea 清单。完整审计与历史不成为 Pro 的默认阅读负担。关键来源与审查层级可追，内容核对问题已处理，命名目录和入口一起推送。独立审读未发生时如实标明，不宣称该项通过。

需要导出时从同一已确认推送的 commit 生成任务、数学主材料及必要附录，manifest 列实际文件/hash和源版本，解压后核对实际内容、引用与自足性。缺少关键材料、审读或导出分别报告，不把设计流程写成流程已经完成。此门槛不替代主问题的一般证明或严格否定证明。

## 提取者的交付门槛

按 prompts/EXTRACTOR.md 重建数学内容。工具或结构有精确接口、量词、承重条件、原作者与不可变来源、实际证明或候选义务、具体复用或检验、反例边界和实际文献检索范围。

独立工具可以在 WC-TARGET 之外有价值。其一般化与当前主目标之间的桥梁按实际证明记录。提取后的文件应让下一位研究者直接使用；有真实增量才进入 toolbox 和研究地图。
