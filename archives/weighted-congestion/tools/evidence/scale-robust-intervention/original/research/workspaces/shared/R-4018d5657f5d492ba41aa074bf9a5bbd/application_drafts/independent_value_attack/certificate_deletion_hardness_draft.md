# 恢复统一平方根拼接合同的最小单位费用资源干预：Max-Cut 归约草稿

状态：完整作者推导草稿，尚未独立攻击；不主张全球新颖性。此文优化指定的统一包络合同，不分类更强实例校准、其他势、或真正均衡。

## 精确问题

固定 `d=7, beta=3`。每个正费用资源至多两种可动权值，其类型边从重到轻定向。允许把选定资源常数化，从而用 `p_e sum_i w_i t_{w_i}` 作势并去掉该资源的类型比例约束。每常数化一个资源收费1。未干预的资源只要求 shared_scale_gluing.md (8) 的统一双排序合同。

此时 `(d-1)/(beta-1)=3=beta`，所以每条未删除的类型边 `a -> b` 强制 `t_b/t_a=3`。写 `h_v=log_3 t_v`，等价于 `h_b-h_a=1`。

**候选定理。** 上述最小干预问题 NP-hard；给定整数预算的判定版本 NP-complete。即使全部资源为 `c_e(x)=x^7`、每资源正好两名专属可动玩家、每玩家只有 `empty/{e}` 两动作、并且原游戏本来已有全空精确 PNE，结论仍然成立。

## 从无权 Max-Cut 的归约

输入一个无向简单图 H=(V,E)，`m=|E|`。给每个原顶点 x 一个中间权型。对每个无向边 xy（固定任意端点标签顺序），引入四个仅属于该 gadget 的新型 `L+,H+,H-,L-`，所有 L 型权值低于所有原顶点，所有 H 型高于所有原顶点；所有权值互异。

加入两条各三条资源边的路径：

1. `x -- L+ -- H+ -- y`；按严格权序定向为 `x -> L+`, `H+ -> L+`, `H+ -> y`。从 x 走到 y 的高度净增为 `+1-1+1=+1`。
2. `x -- H- -- L- -- y`；定向为 `H- -> x`, `H- -> L-`, `y -> L-`。从 x 走到 y 的高度净增为 `-1+1-1=-1`。

因此两条路径全部保留分别要求 `h_y-h_x=+1`、`-1`，不能同时发生。任一3-edge路径删去任意一条后只留下两个不连端点的树片；在给定端点任意实高度时，两个私有内点总能赋值使余下两条边成立。

于是，对于任何固定端点高度，该 gadget 可保留的最大边数恰为

`4 + 1{|h_y-h_x|=1}`。

这里内点不接其他 gadget，因此逐边最优能够同时取得。

令 `Q(h)=#{xy in E: |h_y-h_x|=1}`。由颜色 `floor(h_x) mod 2`，每条被 Q 计数的边都跨割，所以 `Q(h) <= MaxCut(H)`。反向，任一割把两侧原顶点高度分别设为0和1，所有跨割边都满足绝对高度差1，因此 `max_h Q(h)=MaxCut(H)`。

总资源边数6m，从而精确等式

`maximum kept edges = 4m + MaxCut(H)`，

`minimum interventions = 2m - MaxCut(H)`。

因此是否有不超过 `2m-k` 个干预，等价于 H 是否有至少 k 条跨割边。

## 符合加权拥塞输入的实现

为每条有向类型边 a->b 建一条独有资源 e，费用 `x^7`；创建两名专属玩家，权分别为a、b，菜单各为 `empty/{e}`。同一权型可以在多个专属玩家上出现；没有其他潜在用户。类型图就是上面的构造图，每资源最多两型。

类型权可选择从1到 `|V|+4m` 的不同整数，按 L、原顶点、H 三块排列，位长多项式；玩家数12m、资源数6m、菜单总大小多项式。全部空动作给原游戏成本0，故本来就是精确 PNE。硬度完全来自优化指定证书的最小干预，不来自原均衡不存在或难找。

对给定删边集，选每个保留分量根高度0，沿边传播整数 `+/-1` 并检查冲突，即可多项式认证可拼。高度绝对值不超过顶点数，所以可用整数高度（或有理 t=3^h）给 polynomial-bit YES；判定问题属于 NP。

## 边界与用途

- 最小费用**删到森林**是另一更保守问题，单位费用可取任意生成森林，非负费用可用最大权生成森林；不要与本定理混同。本合同允许保留平衡环，恰好使最优可行保留边集变成困难的最大相容子系统。
- 本定理不排除近似/参数化干预算法，也不排除真实有限边际区间在原图上已可行。
- 逐步发现冲突圈并删资源仍可构成精确有限求解器或启发式，但不能因诊断多项式而宣称最小干预整体多项式。
- 若删资源费用由模型误差 radius `beta(M-m)/(beta+1)` 产生，本单位费用归约不能自动继承；需要另证这些费用可由该归约的正资源范围实现。当前只证明外生单位干预费用版本。
