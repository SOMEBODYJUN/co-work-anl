# 稀疏递峰锚定门：独立 literal 攻击与边界核验

2026-10-21。来源：repair_design agent 给出的候选与显式参数；此记录是另一研究者在知悉候选后的独立重推，不是先验盲审、外审或新颖性认证。

**最终更正后的结论。** `2(n-2)` 资源的递峰相邻门能够保留修复、完整稳定集合和社会 OPT 压缩三个接口；RD 已自动阻止前沿逃逸，不需额外屏障。repair_design 在后续推导中指出这一强化局部事实，我另行重推确认。我们初次按“旧总u、新最小峰”拼接的担忧没有对应实际翻位：未新触发的门mover成本完全不变，故不能避掉那些大u。下文保留这一失败路线的准确范围。资源数改善的代价是峰值跨度；要同时指定任意小前沿税才需要次数随n增长。

## 1. 固定对象与 literal sides

单等权类 `n>=3`，玩家0到n-1，权w>0，二元动作位b_i。对j=1,...,n-2建两条独有资源构成门 `T_j=(0,j,j+1)`，三位的选侧依次为 `b_0, 1-b_j, b_{j+1}`，即 xor `(0,1,0)`。两侧同费用c_j，记 `z_j=c_j(w),u_j=c_j(2w),v_j=c_j(3w)`、`d_j=3v_j-2u_j-z_j`。

令相对位 `x_i=b_i xor b_0`（x_0=0）。门触发当且仅当 `x_jx_{j+1}=10`。所以没有触发当且仅当相对后缀是 `0*1*`，恰等于原串至多一次相邻变化的前沿F_n，计数2n。

门不触发时两侧人数2+1，社会费w(2u_j+z_j)；触发时3+0，社会费3wv_j。因此所有完整状态都满足

`W_plus(s)=W_base(s)+K+w sum_{j triggered} d_j`，

`K=w sum_j(2u_j+z_j)`。

这里触发数量本身未必下降，不能沿用完整三元门的“不制造新触发”命题。

## 2. 修复与社会下降

任一非法状态存在某j满足10。翻玩家j至anchor，使x_j从1变0。门T_j由全同侧变成mover独侧，mover费用由v_j降至z_j。仅另一可能受影响门是T_{j-1}（j=1时无），它至多被新触发，新mover费用至多v_{j-1}。所有其他mover门不存在；不含mover的门完全不变。令v_0=d_0=0。

所以若基体mover成本处处<=B，

`v_j > alpha(B+z_j+v_{j-1})`                                  (RD-sparse)

保证该步严格alpha改善。更精确地，若左侧减去右侧>=rho>0，则原始个体改善残差 `C_old-alpha C_new>=rho`。

每步只有一个相对位1变0，且anchor不动；j只可能在1,...,n-2，所以至多n-2步结束。x_{n-1}不翻也不妨碍到达0*1*。

触发能量变化至多 `-d_j+d_{j-1}`。当基体次数<=p，由总加权成本插入界，基体社会上涨至多 `(p+1)wB`。故

`d_j-d_{j-1} > (p+1)B`                                    (SD-sparse)

保证完整W严格下降。若差至少 `(p+1)B+sigma`，每步完整W至少降w sigma。这同时证明完整社会最优在F_n，且 `OPT_plus=K+min_F W_base`，不要求稳定点存在。

## 3. 更强局部事实：RD自动禁止前沿逃逸

对从前沿出发的单玩家翻位，逐个检查含mover的门。若新门仍未触发，则两端mover都属于pair，个人门费均为u_j（见第4节）；若新门触发，旧mover必是singleton，门费z_j变v_j。因此mover的门费逐门不降；离开前沿时至少一个门严格触发，个人门费净增至少min_j(v_j-z_j)。

而RD-sparse直接给

`v_j-z_j >= (alpha-1)z_j+alpha v_{j-1}+alpha B+rho > B`。

基体个人费至多下降B，所以**任何从前沿离开的翻位都严格增加个人完整成本**。因alpha>=1，该偏离也不可能是严格alpha改善。因此RD本身已同时给核外出口和核内无逃逸；SD仍是社会目标的独立合同。

初次攻击使用了下述粗屏障：

一个直接充分屏障是

`B+sum_j u_j <= alpha min_j v_j`。                         (ESC)

它确实充分，但在RD下冗余，而且可以失败而实际无逃逸。具体n4、alpha1、B1、p2、v1=4、v2=8、D2，令c_j(x)=v_j(x/3)^2。RD两余量分别23/9与19/9；社会d1=d2-d1=8>3；但粗ESC左边 `1+u1+u2=19/3` 大于右边minv=4。literal枚举仍确认每一条F外逃偏离的门费上涨>B。

更强的 `min v > alpha(B+sum u)` 也安全，但不是上述必要阈值，勿把两者说成等价。

## 4. 保前沿翻位的精确个人门成本

设s,t均在F且仅玩家i翻位。对每个含i的门，前后都不触发。若mover在旧门为singleton，翻后必全同侧；若在新门为singleton，翻前必全同侧。两者矛盾。所以mover在两端必都属于pair，个人费恰为u_j。

因此可定义按玩家的常数

`U_0=sum_{j=1}^{n-2} u_j`，

`U_i=u_{i-1}+u_i` (i>=1，越界u_0=u_{n-1}=0)。

**只对这一条保前沿翻位**，两端的mover总门费都恰等于U_i；不能宣称某个玩家在所有前沿状态的门费总恒定。例如anchor在内部边界门可以是singleton，但那种状态的anchor翻位会离开前沿。

若RD-sparse成立，完整alpha-PNE集合精确等于

`{s in F: C_i^B(s)-alpha C_i^B(t) <= (alpha-1)U_i for every F-preserving one-player flip s->t}`。

证明三部分：核外由RD排除；核内逃逸由第3节从RD推出的严格成本上涨排除；核内保前沿偏离由两端同一U_i给精确式。这个集合可以为空，定理本身没有凭门产生均衡。

## 5. 对repair_design显式参数的逐式攻击

给定alpha>=1、p>=0、B>0、rho,sigma,epsilon>0，令

`m=n-2, A=2alpha, Q=4[(alpha+p+1)B+rho+sigma]`，

`v_j=Q A^(j-1), S=sum_{k=0}^{m-1} A^k`。

选整数D>=1满足 `delta S <= min{1/(4alpha),epsilon/Q}`，其中 `delta=(2/3)^D`，并用

`c_j(x)=v_j (x/(3w))^D`。

写 `zeta=(1/3)^D=delta 2^(-D)`，则u_j=delta v_j、z_j=zeta v_j。

- 个人修复：j>=2时 `v_j-alpha(vprev+z_j+B)=v_j(1/2-alpha zeta)-alpha B >= Q/4-alpha B >=rho`；j1没有prev，界更强。用了alpha zeta<=alpha delta<=1/4。
- 社会修复：`d_j=(3-2delta-zeta)v_j`，系数>=9/4，且j>=2的v差>=Q/2，故d差>=9Q/8>(p+1)B+sigma；j1更强。
- 逃逸：`sum u=Q delta S<=Q/(4alpha)`，同时alpha B<=Q/4，因此 `alpha(B+sum u)<=Q/2<Q=min v`。这满足比ESC更强的屏障。
- 基线：sum u<=epsilon，故 `K=w(2+2^-D)sum u<=3w epsilon`。同样每个U_i<=epsilon，核内容差至多(alpha-1)epsilon。

因此这些预算兼容，粗逃逸预算只是额外成立而非必需。峰值 `Q(2alpha)^(n-3)` 的数值可指数大，但有理位长线性增长；D的充分数量级应准确写成 `O(n log(2alpha)+log^+(Q/epsilon))`，而不是含可能负数的未截断log(Q/epsilon)。

**不要求小税时的新边界。** 若不要求sum u<=epsilon，也不要求粗ESC，则只需选D使alpha zeta<=1/4，并保证社会kappa正且足够大（例如D>=1已有kappa>=4/3）。Q/A不变就同时满足RD、SD，故D=O(log(2alpha))足够，与n无关。全状态稳定核实现并不本质要求degree随n增长；使前沿基线/近似容差小才产生该n依赖。

多项式编码范围需明确alpha,B,rho,sigma,epsilon,w为正有理数，p为非负整数，显式输出高次单项式（或其稠密系数数组）；D和系数位长对这些输入位长及n为多项式。它不保证degree与原完整门同阶，也不保证固定输出degree时能容纳任意n。

## 6. n=3/n=4端点

- n3只有T1；非法串仅010/101，修复翻玩家1；U0=U1=U2=u1，峰递增条件退化为单门条件。
- n4有T1,T2；翻j1只消T1，无前门；翻j2可把触发T2搬到T1。相对串110中修复j2得100，触发数量保持1，但因d2>d1能量严格下降。下一步j1得000。这是必须保留的非单调触发数例。
- Anchor与最后玩家都不参与指定修复，但都必须进入完整偏离验收；ESC覆盖他们离F的偏离，保F恒u证明覆盖其余。

## 7. 保留价值与下一步

一般证明值得单独保存为O(n)资源、可调小前沿基线的稳定核实现。它不是改进原有近次数反例的即得推论：为了保持小税，门D可能随n线性增加，应用到次数预算紧的下界时必须重新比较完整门的资源/次数预算。不要求小税时D可独立于n，但核内容差U_i可能极大。实际优化问题可改成“在指定输出次数D与容差epsilon下，最少门资源/最小峰跨度能否做到”，这比只展示无限制幅度构造更接近部署合同。
