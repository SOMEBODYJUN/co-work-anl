# 共同幂混合全局最小点的线性障碍

## 精确命题身份

ID/version：`WC-COMMON-POWER-MIXTURE-MINIMIZER-OBSTRUCTION-v1`。这是可完整证明的方法障碍，不是 WC-TARGET 的否定证明。本文经过独立重构与冻结攻击；新颖性和外部评审未认证。

**Exact Statement / Objects / Domain / Quantifiers.** 对每个整数 d≥32，存在一个 MODEL 博弈 G_d，恰有四名玩家、四个资源，每名有选择玩家有两个单资源策略，其余两名只有一个策略；所有玩家权重和费用系数为正有理数，每个费用为 a_e x^d。G_d 有精确 PNE。另一方面，对每个非零非负 Borel 测度 μ 于 (0,∞)，若下式在全部有限状态中有限，定义

    P_μ(s) = Σ_e a_e ∫_(0,∞) x_e(s)^p dμ(p).

则 P_μ 的每个全局最小点都不是 α-PNE，适用于每个实数 1≤α<d/16。μ 可以依赖 d 和整个 G_d；允许任意有限幂的非负线性组合及满足上述有限性条件的连续混合。约定 p>0 时 0^p=0。μ=0 必须排除。

**Scope.** 对象是使用原费用系数 a_e、对全部资源采用同一个非负幂混合规则的全局选态目标。结论不涵盖各资源任意不同规则、目标中的任意符号系数、依玩家总费用的非线性目标、非可分目标或其他选态机制。G_d 的精确 PNE 明确阻止将本定理误读为非存在下界。两名背景玩家只有一个策略；若算法先消去固定用户，把背景平移进费用再重新按展开后各次数选择规则，便不再是本文精确定义的原系数共同幂混合目标，此预处理未被排除。

**Dependencies.** 下文显式成本和势差恒等式；非负测度积分；几个初等幂差估计。没有导入外部博弈存在定理。

**Evidence / Status / Objections.** 一般证明如下，配套 Fraction 程序核验显式参数、证明不等式及整数幂/端点混合。有限计算不证明实指数和连续测度结论。独立审查及证据合同见末节；内部审查未发现所述范围内fatal objection，未外审。

## 1. 同一个四玩家实例

固定 d≥32，写

    R=d/16,  A=d²+1,  K=d(d+1),  W=K^(4d).

两名有选择玩家分别记 H 和 L，权重为 W 和 1。四个资源为 h_0,h_1,l_0,l_1，费用如下：

| 资源 | 费用 c_e(x) | 固定背景用户 |
|---|---|---|
| h_0 | R x^d/W^d | 无 |
| h_1 | x^d/(A W)^d | 一名权重 (A−1)W 的玩家 |
| l_0 | x^d | 无 |
| l_1 | R x^d/W^d | 一名权重 W−1 的玩家 |

H 的策略是 {h_0} 或 {h_1}；L 的策略是 {l_0} 或 {l_1}。两名背景玩家各只有表中对应资源的单一策略。所有权重和系数严格正，游戏有限并属于指定模型。

H 在 h_0 的成本为 R，在 h_1 的真实偏离成本为 1。L 在 l_1 的成本为 R，在 l_0 的真实偏离成本为 1。这两项选择相互独立。所以状态 (H选h_1,L选l_0) 是唯一精确 PNE；其余每个状态都含一个 R→1 的严格改善。下文把 H选h_0 和 L选l_1 称为两个“坏选项”。

## 2. 逐个幂的两个目标差

令 p>0，r=p−d，并定义

    δ_X(p)=1−(1−1/X)^p,
    z_A(p)=A^r δ_A(p),
    D_H(p)=W^r [R−z_A(p)],
    D_L(p)=R W^r δ_W(p)−1.

D_H(p) 恰为 H 使用坏选项而非好选项时，目标 Σ_e a_e x_e^p 的增量；D_L(p) 是 L 的对应增量。背景资源的旧负载真实保留，不把偏离后的负载冻结。

例如 H 的好选项的目标增加为

    [(A W)^p−((A−1)W)^p]/(A W)^d
      = W^r A^r δ_A(p),

而坏选项增加为 R W^r。L 的坏选项增加为 R W^r δ_W(p)，好选项为 1。

接下来证明存在同一个 κ>0，使

    κD_H(p)+D_L(p)<0                   (★)

对每个实数 p>0 都成立。

## 3. 一个对所有正实幂同时成立的严格分离

设

    a=1−1/(2d),   b=1−1/(4d),
    κ=1/[4R W^a] = 4/[d K^(4d−2)].

κ 是严格正有理数。用到如下初等估计：

1. 若 0<p≤1，则 δ_X(p)≤1/X；若 p≥1，则 δ_X(p)≤p/X。因此 p≤d+1 时总有 δ_W(p)≤(d+1)/W。
2. A≤4^d，故 A^(−1/(2d))≥1/2。
3. 若 1≤p≤A，则 δ_A(p)≥(p/A)(1−1/A)^(p−1)≥p/(4A)。最后一步可由 (1−1/A)^(A−1)>1/4 得到；后者等价于 (1+1/(A−1))^(A−1)<4，由二项式展开和 Σ_(j≥0)1/j!<3 即得。
4. 若 p≥A，则 δ_A(p)≥δ_A(A)>1/2。这也可由 Bernoulli 不等式对 (1+1/(A−1))^A 应用而得。
5. κW=K²/(4R)≥16R；κ≤1。
6. A^(A−d)≥4R/κ。具体地，右侧为 16R² K^(4d−2)≤d^(12d−4)，左侧至少 d^(2d²−2d+2)，且 d≥32 时 2d²−2d+2≥12d−4。

现在按 r 分三段，最后一段再按 p 分两种情况。

**第一段：r≤a。** 此时 p<d+1，且 r≤b。因此

    R W^r δ_W(p) ≤ R(d+1)W^(b−1)
                      =R(d+1)/K=1/16,
    D_L(p)≤−15/16.

另一方面 D_H(p)≤R W^r≤R W^a，故 κD_H(p)≤1/4。得到 (★)，事实上左侧≤−11/16。

**第二段：a≤r≤b。** 此时 1<p<A。由估计2、3，

    z_A(p)≥(p/4) A^(r−1)≥p/8.

又 R=d/16≤p/16，所以 z_A(p)−R≥p/16>0，D_H(p)<0；第一段对 D_L(p) 的上界仍成立。因此 (★) 严格成立。

**第三段：r≥b，且 p≤A。** 仍有 z_A(p)−R≥p/16。于是

    κD_H(p)+D_L(p)
       ≤W^r p [R/W−κ/16]−1
       ≤−1,

第二步是估计5。

**第四段：r≥b，且 p≥A。** 由估计4、6，

    z_A(p)≥A^r/2≥A^(A−d)/2≥2R/κ.

因为 κ≤1，z_A(p)−R≥R/κ。再用 δ_W(p)≤1，

    κD_H(p)+D_L(p)
       ≤−R W^r + R W^r−1 =−1.

四种情况覆盖全部 p>0，证明 (★)。分界 a,b,p=A 处都由弱端点估计给出严格负总差，不留端点漏洞。

## 4. 任意非负混合及全部最小点

原目标对两个独立选择可分离。由有限性假设，两个差

    Δ_H=∫D_H(p)dμ(p),    Δ_L=∫D_L(p)dμ(p)

存在且有限；例如它们是两份非负有限目标增量之差。

积分 (★) 后有 κΔ_H+Δ_L<0。理由是 μ 非负且非零，而被积函数对每个 p 都严格为负；用正函数水平集的可数并即可验证严格性，不能因为 μ 支持无原子而把严格负积分改为零。

所以 Δ_H<0 或 Δ_L<0。若 Δ_H<0，则每个全局最小点都必须让 H 选坏选项；否则改变 H 一人就严格降低目标。若 Δ_L<0，同理 L 在每个最小点都选坏选项。每个全局最小点因而包含一个当前成本 R、真实偏离成本1的玩家，对全部 α<R 违反 α-PNE 的弱不等式。有限状态保证全局最小点存在，完成证明。

## 5. 与已存障碍的区别及范围

- `power_of_total_cost_obstruction.md` 的目标是玩家总费用的幂和；本目标是资源负载的共同幂混合，不能由那里直接替代。
- `weight_bands/README.md` 的标准 Shapley 势坏最小点是特定单一规则；本命题在一个 G_d 内同时量化到依完整游戏选择的所有非负共同 power-mixture，含连续混合。
- 可分序势障碍要求全部改善边下降；本结论直接攻击全部全局最小点。虽然 G_d 有精确 PNE，整个目标族都选不到它，故此处不是把“某边上升”误推成“最小点不好”。
- 目标族仍很窄：保持原 a_e、各资源共享 μ，以及 μ≥0，是承重条件。证明没有否定可分目标任意依游戏选择，更没有否定非势选态或全类 O(d/ln d) 的存在。

可回收的新方法是：把两个独立构件的全局选态失败写成目标族参数的两条线性函数，再以一个严格点态正组合对整个连续参数族分离。今后扩大目标族时，应先检查这种分离是否仍能成立，不能仅检查每个单独幂的坏例然后交换量词。
