# 相邻锚定门的最小规模实现：递峰修复、逃逸屏蔽与可控前沿税

状态：内部候选，已给一般证明；有限有理 literal 资源核验见同目录审计。并非全球优先权或外审声明。

## 1. 对象、用途与新增内容

基体为标准加权拥塞游戏，个体成本不乘玩家权重：

\[
C_i^B(s)=\sum_{e\in s_i}c_e(x_e(s)),\qquad
W_B(s)=\sum_iw_iC_i^B(s).
\]

基体资源费用为非负系数多项式，次数至多 \(p\)。考虑一个有序等权类
\(A=(0,1,\ldots,n-1)\)，\(n\ge3\)，类内权重 \(w>0\)，每人恰有两个互异资源子集动作，标签为 0、1。其他类与跨类基体资源可以保留。先写一个类，多个不交类逐类使用同一合同即可。有效正数 \(B\) 满足该类每名玩家在全部基体状态的成本至多 \(B\)。

前沿 \(F_n\) 是相邻位至多变化一次的位串。本文没有把非笛卡尔积前沿当作普通子游戏；“核心偏离”始终指两端在前沿的真实单玩家翻位。若多个类同时修复，总前沿为它们 \(F_n\) 的乘积。

既有完整锚定门使用 \(\binom{n-1}{2}\) 个资源对。本文改为 \(n-2\) 个相邻锚定门，证明：

1. 它们是全部锚定三元检测器中，精确识别该前沿所需的最少门数。
2. 递峰费用能给有限真实 \(\alpha\)-改善修复；局部单翻恒等式证明同一合同也阻止前沿逃逸，社会下降仍须独立合同。
3. 全部合同可同时由显式有理多项式满足，而且前沿社会增量及近似容差可指定任意正预算。

这不宣称相同门费用下修复成立，也不把资源数减少说成免费：峰值增长、次数和编码代价必须一起报告。

## 2. 稀疏门、局部成本及最小门数

令 \(m=n-2\)。只对 \(j=1,\ldots,m\) 加门

\[
T_j=(0,j,j+1).
\]

每门是两件全新资源，只有三名指定玩家使用。三人的选侧为动作位分别 xor \((0,1,0)\)；两侧采用同一非负系数多项式 \(c_j\)。不同门及基体资源不交。记

\[
z_j=c_j(w),\quad u_j=c_j(2w),\quad v_j=c_j(3w),\quad
d_j=3v_j-2u_j-z_j,
\qquad v_0=d_0=u_0=u_{m+1}=0.
\tag{1}
\]

仅当三位动作是 010 或 101 时三人同侧，称为触发。触发时每人费用为 \(v_j\)；未触发时两人各付 \(u_j\)、一人付 \(z_j\)。

**命题 A（最少检测门）。** 在全部允许的锚定三元 \((0,j,k)\)、\(1\le j<k<n\) 中，一族三元的“全部未触发域”恰为 \(F_n\) 当且仅当它包含全部相邻三元 \((0,j,j+1)\)。所以最少门数恰 \(n-2\)，本实现用 \(2(n-2)\) 个新资源。

**证明。** 固定锚点位 \(b=s_0\)，令 \(x_i=1\) 表示 \(s_i\ne b\)。锚定门 \((0,j,k)\) 触发当且仅当 \((x_j,x_k)=(1,0)\)。前沿恰要求后缀 \(x_1,\ldots,x_{n-1}\) 非减；检查相邻下降 10 已充要，所以所有相邻门足够。

必要性：若缺门 \((0,j,j+1)\)，取后缀
\(0^{j-1}10\,1^{n-j-2}\)。它的唯一逆序对是 \((j,j+1)\)，故所有其他锚定三元都不触发，但该串不是前沿。证毕。

最小性只针对这一明示锚定三元检测族和每门两个独立资源的实现；不对一般拥塞实现、共享资源或利用基体排除非法态作下界。

## 3. 两个合同：真实改善修复与社会下降

在非法类选择任意相邻下降 \(x_j=1,x_{j+1}=0\)，只翻玩家 \(j\)，使它与锚点同位。它不会翻锚点或末位。

**引理 B（局部修复计数）。** 此翻位消去门 \(T_j\) 的触发；只有 \(T_{j-1}\) 可能新增触发。翻位者在 \(T_j\) 的新成本恰为 \(z_j\)，其全部新门成本至多 \(z_j+v_{j-1}\)。异位人数 \(\sum_{i\ge1}x_i\) 减 1。因此指定修复至多 \(n-2\) 步进入前沿。

**证明。** 非锚点玩家 \(j\) 仅参与 \(T_{j-1},T_j\)。在 \(T_j\) 中旧动作是 \((b,1-b,b)\)，三人同侧；新动作是 \((b,b,b)\)，中位者 xor 后独用一侧，成本 \(z_j\)。前门的新成本至多 \(v_{j-1}\)，其他门不变。非法状态至少有一个后缀 0，异位人数初值至多 \(n-2\)，每步严格减少；无相邻下降时恰在前沿。证毕。

给定 \(\alpha\ge1\) 和正余量 \(\rho,\sigma>0\)，两个可核验合同为

\[
v_j-\alpha(z_j+v_{j-1}+B)\ge\rho
\quad(j=1,\ldots,m),\tag{R}
\]

\[
d_j-d_{j-1}\ge(p+1)B+\sigma
\quad(j=1,\ldots,m),\tag{S}
\]

**定理 C（两个合同的准确作用）。**

- R 保证每步指定修复都是完整游戏中的严格 \(\alpha\)-改善，因此前沿外无 \(\alpha\)-PNE；它还保证全部前沿逃逸均不是严格 \(\alpha\)-改善。
- S 保证每步修复严格降低完整加权社会成本，因而完整社会 OPT 在前沿。

**证明。** 由引理 B，mover 旧完整成本至少 \(v_j\)，新完整成本至多 \(B+z_j+v_{j-1}\)，故 R 给真实偏离差至少 \(\rho\)。

每个门在任意状态的加权社会成本是未触发基线 \(w(2u_j+z_j)\)，加上触发时罚项 \(wd_j\)。该步消去 \(T_j\)，仅可能新增 \(T_{j-1}\)。由 S 归纳 \(d_j>d_{j-1}\ge0\)，故门社会成本下降至少 \(w(d_j-d_{j-1})\)。基体单次偏离的社会上涨至多 \((p+1)wB\)：对进入资源 \(y=x+w\)，逐单项式有
\(y^{k+1}-x^{k+1}\le(k+1)wy^k\)，退出资源不增。这一既有插入界的前提完整保留，不能用 mover 个人改善替代。因此完整社会成本至少下降 \(w\sigma\)。任意前沿外状态都有社会下降出口，所以不可能社会最优。

最后证明逃逸。一次前沿到前沿外的单翻中，每个原门均未触发。对含 mover 的门：若新时仍未触发，mover 前后都在二人组，故成本同为 \(u_j\)；若新时触发，mover 旧时必须独用，成本由 \(z_j\) 变为 \(v_j\)。至少有一个后一类门。R 蕴含

\[
\alpha v_j-z_j
\ge \alpha^2B+(\alpha^2-1)z_j+\alpha^2v_{j-1}+\alpha\rho
\ge B+\alpha\rho.
\tag{E-local}
\]

因此新增门的 \(\alpha\)-偏离差至多 \(-B-\alpha\rho\)，其余未触发门只贡献非正项 \(-(\alpha-1)u_j\)。基体偏离差至多 B，总差至多 \(-\alpha\rho<0\)。证毕。

这个屏蔽论证不需要比较最高与最低门峰值，也不需要 \(\sum u_j\) 很小。只给旧成本全局上界会丢掉“未触发门单翻两端个人成本恰相等”的关键结构；较大的共同基线在 \(\alpha>1\) 时进一步阻止改善。

## 4. 全部稳定集合、成本选择和原游戏边界

定义每名玩家的保前沿门成本

\[
U_0=\sum_{j=1}^m u_j,\qquad
U_i=u_{i-1}+u_i\quad(1\le i\le n-1),\tag{2}
\]

其中越界项为零，特别 \(U_1=u_1\)、\(U_{n-1}=u_m\)。

**定理 D（稀疏门的完整稳定公式）。** 在 R 下，完整游戏的全部 \(\alpha\)-PNE 恰为

\[
\left\{s\in\mathcal F:
C_i^B(s)-\alpha C_i^B(s^{\oplus i})
\le(\alpha-1)U_i
\text{ 对全部保前沿翻位}\right\}.\tag{3}
\]

多个类时使用各类的 \(U_{a,i}\)；没有加门的玩家/类必须照常检查真实基体偏离，不能从公式中删掉。

**证明。** 定理 C 的 R 结论排除全部非前沿稳定点和全部离前沿严格改善。对保前沿翻位，任一含 mover 的门前后均未触发。若 mover 旧时独用，翻后会加入另一侧二人而触发；若新时独用，则旧时触发。因此 mover 前后都属于二人组，在该门两端成本恰为 \(u_j\)。逐参与门求和即为 \(U_i\)，完整偏离差恰为基体差减 \((\alpha-1)U_i\)。证毕。

全前沿社会基线仍为

\[
K=w\sum_{j=1}^m(2u_j+z_j),\qquad W_+(s)=W_B(s)+K\quad(s\in\mathcal F).
\tag{4}
\]

这是局部门未触发时的计数，不是本候选声称的新恒移定理。故 R 下可以在 (3) 的精确容差集内最小化基体社会成本再加回 K，得到全部 \(\alpha\)-稳定解中的真实最优。若同时有 S，完整社会 OPT 也等于 \(K+\min_{\mathcal F}W_B\)。稳定质量保证仍须比较 (3) 与前沿社会最优，不能自动推出二者相等。

\(\alpha=1\) 时 (3) 的容差恰零，精确稳定集合双向对应受限核心；\(\alpha>1\) 时可能新增近似稳定点。若要原核心近似稳定集合完全保持，另给核心全部正 \(\alpha\)-margin 的最小值 \(g_\alpha>0\)，并确保 \((\alpha-1)\max_iU_i<g_\alpha\) 即可；这是一个显式充分 gap 合同。

新增资源后得到的是另一个游戏 \(G_+\)。其稳定点不是未加门 \(G_B\) 的解。只有门原已属于待求解实例，且 R 用原资源数据验证通过时，公式才作为该原实例的无修改压缩算法；此时不能重新设计系数。对基体原偏离逐项再检验是另一项独立合同。

## 5. 显式有理施工：线性资源和任意小税/容差

现在给两个合同的一套同时可行参数。取任意有理数
\(\rho,\sigma,\varepsilon>0\)，令

\[
A=2\alpha,\qquad
Q=4\bigl[(\alpha+p+1)B+\rho+\sigma\bigr],\qquad
v_j=QA^{j-1},\qquad
S_m=\sum_{k=0}^{m-1}A^k.
\tag{5}
\]

选整数 \(D\ge1\)，使

\[
\zeta\le\frac1{4\alpha},\qquad
\delta S_m\le\frac{\varepsilon}{Q},
\qquad\delta=(2/3)^D,\quad\zeta=(1/3)^D,
\tag{6}
\]

并取实际资源费用

\[
c_j(x)=v_j\left(\frac{x}{3w}\right)^D.
\tag{7}
\]

所有资源均为非负有理单项式，无新玩家、权重或动作标签。

**定理 E（有预算的线性规模 compiler）。** (5)–(7) 满足 R、S，并有

\[
\sum_j u_j=Q\delta S_m\le\varepsilon,
\quad \max_iU_i\le\varepsilon,
\quad K=w(2+2^{-D})Q\delta S_m\le3w\varepsilon.
\tag{8}
\]

故可预先指定每类社会增量预算 \(K\le K_{\rm budget}\)（取 \(\varepsilon\le K_{\rm budget}/(3w)\)），或近似偏离加性容差预算 \((\alpha-1)U_i\le\tau\)（\(\alpha>1\) 时取 \(\varepsilon\le\tau/(\alpha-1)\)）。两项可同时给出。

**证明。** 由 (6)，\(\alpha\zeta\le1/4\)，而 \(D\ge1\) 给
\(\kappa=3-2\delta-\zeta\ge4/3\)。

对首门，R 的左边至少 \(3Q/4-\alpha B\ge\rho\)。对 \(j\ge2\)，

\[
\begin{aligned}
v_j-\alpha(z_j+v_{j-1}+B)
&=v_{j-1}[A(1-\alpha\zeta)-\alpha]-\alpha B\\
&\ge \tfrac\alpha2v_{j-1}-\alpha B
\ge\tfrac\alpha2Q-\alpha B\ge\rho.
\end{aligned}
\]

所用 \(Q\) 当然大于 \(4(\alpha B+\rho)\) 且大于 \(4(B+\rho)\)，所以上述两个端点均成立。社会方面 \(d_j=\kappa v_j\)。首差 \(d_1-d_0=\kappa Q\)，后续差为 \(\kappa QA^{j-2}(A-1)\ge\kappa Q\)；由于 \(Q> (p+1)B+\sigma\)，S 成立。

最后由 (6) 和 \(z_j=2^{-D}u_j\)，直接求和得 (8)。前沿逃逸已由 R 和局部单翻恒等式处理，不需要额外放大 D。证毕。

这里没有把无限大幅度或无限次数当输入；D 可用有理乘幂逐步比较 (6) 找到，有限终止。若 \(\alpha,B,\rho,\sigma,w,\varepsilon\) 有理，全部输出也有理。

## 6. 必须共同交付的规模和代价

| 项目 | 确切或渐近预算 |
| --- | --- |
| 新门/新资源 | \(n-2\) / \(2(n-2)\)，在命题 A 的检测族内最少 |
| 新玩家、权重、动作标签 | 均为 0 |
| 新玩家-动作-资源隶属项 | \(6(n-2)\) |
| 指定修复步数 | 至多 \(n-2\) |
| 输出最大次数 | \(\max(p,D)\) |
| 峰值 | \(v_m=Q(2\alpha)^{n-3}\) |
| 每类前沿状态数 | \(2n\) |
| 社会增量、逐玩家近似容差 | 分别至多 \(3w\varepsilon\)、\((\alpha-1)\varepsilon\) |

因为 \(S_m\le mA^{m-1}\)，充分次数为

\[
D=O\!\left(n\log(2\alpha)+\log n+
\log^+\!\frac{\alpha Q}{\varepsilon}\right).
\tag{9}
\]

这里 \(\log^+x=\max(0,\log x)\)；这只是上界，实际应报告由 (6) 精确选出的 D。对固定正有理输入，峰值可随 n 指数增长，峰值位数为
\(O(\operatorname{bits}Q+n\operatorname{bits}\alpha)\)。资源系数
\(v_j/(3w)^D\) 的分子分母位数为
\(O(\operatorname{bits}Q+n\operatorname{bits}\alpha+D[1+\operatorname{bits}w])\)。所有 \(n-2\) 个系数的总编码量还要乘资源数；没有将指数峰值说成数值温和。

这给“少资源、提高次数”的另一条可审计设计曲线，未证明在给定次数下优于完整门，也未证明本递峰幅度或次数最小。若目标次数上限为 d，必须实际检查 \(p\le d,D\le d\)。一旦失败，只说明此 compiler 未认证，不否定其他稀疏实现。

## 7. 实用交付合同

机制设计交付至少应包含：基体与新增资源的明确分解；原/新游戏标签；\((n,w,p,B,\alpha)\)；每门实际 \((z_j,u_j,v_j,d_j)\)；R、S 及派生 E-local 的有理 slack；资源数、最大次数、峰值与系数位数；实际 \(U_i,K\)；所选稳定态的全部真实偏离 slack。需要近似核心集合完全保持时再交 \(g_\alpha\) 与 gap 检查。

只要求快速合法化时可以仅用 R 输出前沿修复路径，但不能宣称该终点稳定、社会成本未上升或核心算法收敛；需要社会下降时加 S。R 已给完整稳定集合的公式，但核心稳定点的存在和求解仍是独立义务。全部前沿枚举仍可能随类数指数增长。这里优化的是干预规模和预算，未解决一般紧凑输入的均衡搜索复杂度。
