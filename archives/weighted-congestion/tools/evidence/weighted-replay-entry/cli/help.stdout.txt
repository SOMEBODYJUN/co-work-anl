usage: replay.py [-h] [--list] [--timeout TIMEOUT] [--report REPORT] [script]

Replay frozen WC audit code in a disposable source-layout mirror. The curated
repository separates proof, review, code and evidence. Older exact checkers
used relative siblings and overwrote their own output files. This runner
restores those layouts only inside a TemporaryDirectory. Frozen records in the
repository are never output destinations. --report is an explicit new result
file and refuses to overwrite an existing one.

positional arguments:
  script

options:
  -h, --help         show this help message and exit
  --list
  --timeout TIMEOUT
  --report REPORT
