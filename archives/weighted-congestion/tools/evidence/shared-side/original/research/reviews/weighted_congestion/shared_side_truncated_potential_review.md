## 自主重构阶段：实际得到什么

自主重构得到以下义务，而没有独立先行闭合整份一般证明。

1. 在全反位状态，light 的主资源真实负载是 W_v，侧负载至多 w+m u；它单方翻位后的主资源负载是 u+w，侧负载至少 w。因此 UF 已使 αC_light≤C_light(偏离)，足以处理全部 lights。
2. hub 的主资源成本差为 F_v(u)−αF_v(u+W_v)=−M_v。应构造侧势，使 hub 的真实 α成本差不超过势的单点下降量与其 source light 重置误差之和，再用 UF 支付源预算。
3. 对一条 side，若 source 位上有 k 个 hub，固定 light 时，同位 hub 的两项负载为 w+ku 与 (m−k+1)u；异位 hub 的两项负载为 (m−k)u 与 w+(k+1)u。source 自身属于 H 时也必须按这个真实单方负载计算，不能在真实偏离里让 light 跟随翻位。
4. 朴素精确 Rosenthal 势与把单边 α差投影到零附近的势都不能直接闭合声称预算。比如 m=2、单项式高次数、w趋零时，它们的 source 变化导数可有约 d/2 倍端价，而 A_d 只有 d/ln d 量级。这里失败的是这两种势选择；不是定理反例，也没有排除另一种截断势。

之后阅读冻结稿，作者的 α倍纯 hub Rosenthal 底势加正部补偿，提供了自主阶段尚缺的机制。

## 逐项承重义务与攻击结果

### 标量常数及截断预算

对 x∈[0,1]，次数 k≤d 时 x−x^k≤x−x^d≤c_d；k=0 的左侧非正，k=1 为零。微分给 x=d^(−1/(d−1)) 处的最大值 c_d。α≥A_d 等价于 αc_d≤α−1，所以 1−αx^k≤α(1−x)。冻结稿的 (1)→(2) 成立，量词包括全部实 α≥A_d。

令 y=r+t>1，则 y^k−(y−1)^k≥y^(k−1)；来自 (1−1/y)^k≤1−1/y。先用上项标量式乘 y^k，再取正部，得到冻结稿 (3)。k=0 单独给零左侧，不能把 k−1 次幂公式机械套入，但作者已经单独处理。

将单项式缩放后相加时，作者用的是 `[Σ a_k z_k]_+≤Σ a_k[z_k]_+`，a_k≥0，方向正确。常数项对正部贡献为零，费用差中也为零。求 r 的望远镜和后，最后放宽使用 α≥1，因此 (4) 和 (TR) 完整成立，包括 m=0、零多项式和常数项。

把 TR 的 base increment 换为 W、external shift 换为 u，取 m=1，若差为负则由右侧非负直接处理，若为正则乘 W，正好得到 (M)。W=0 另行处理正确。对 F(x)=x^d 将 (M) 通分，确实推出全部 R=W/u>0 上的奇环标量界，故 A_d≥T_d 是证明推论，无需预先假设。没有循环引用 T_d。

### UF 聚合及预算不重复

UF 等价于每名 light 的 ΣP_j≤F_v(u+w)−αF_v(W)，P_j=αG_j(w+m u)−G_j(w)≥0。先汇总该 light 全部 side，再乘它的 w，才对同源 light 求和，因此没有为每条 side 重复领取主预算。

w≤W 与 F_v 单调给中间上界 W[F_v(u+W)−αF_v(W)]，即便单独关注右侧可能有符号也不影响逐项上界；事实上 UF 本身已使各 light 的原右侧非负。之后 (M) 给 ΣH_j(m_j)≤M_v。空 light 集时为空和，F_v(u)−αF_v(u)≤0 正确。

### 固定 light 势边际及真实单方偏离

带 light 副本的第 r 名 hub 边际为 max{αG(ru),G(w+ru)}，由 G 单调和 α≥1，它位于 [G(w+ru),αG(w+ru)]。无 light 副本边际为 αG(ru)，同样位于 [G(ru),αG(ru)]。

离开旧副本的势边际至少旧费用，加入新副本的势边际至多 α新费用，故真实 `旧费用−α新费用≤旧势−新势`，冻结稿 (D) 的符号正确。该式不要求改善动态收敛。固定 q 是真实偏离检查所需的 light 不动，未偷换为联合偏离。

### source 重置、self-membership 和空 side

source 翻位后，规范势定义会重置其所有 light；真实成本比较仍固定原 light。作者把这两个不同状态明确分开，其差仅为 H(new other-count)−H(new old-count)≤H(m)。n 在翻位后计算，因此 source∈H 时的 hub 计数变化已纳入，不会漏掉自身；source∉H 与空 H 也由同一公式覆盖。多个同端点 side 按索引累加，无需假设拓扑简单。

### 局部最小点和均衡端点

状态空间有限非空，实值势有全局最小点，从而有单点局部最小点。无需算法终止性或势值有正离散间距。在该点，每个 hub 的侧 α差≤source 预算≤M_v，恰被主资源 −M_v 吸收。light 已由 UF 获得更强式。保留原动作由 α≥1 自动成立。

所有式均为弱不等式。零费用和零偏离费用没有取商，故不存在 0/0 漏洞；弱端点 α=A_d 也无严格改善阈值损失。允许 L 为空、J 为空、H 为空、F/G 为零或有常数项。

### 显式量级及范围

c_d=(1−1/d)exp(−ln(d)/(d−1))≤exp(−z)，e^z≥1+z 给 A_d≤1+1/z≤2d/ln d，d≥2 时所有分母正，代数方向正确。

该结论始终依赖共同 hub 权、UF、每 side 唯一 light、同费动作副本、每 light 唯一 source。它只限制该结构类构造路线，不能升级成全模型存在上界，也没有判定用户唯一目标。作者对此边界陈述准确。没有导入需核实适用条件的外部定理。

## 后置抽象审查：AS＋源预算势命题（新 Claim，不改原 UF 命题）

本节是完成上述冻结稿攻击后，应 boss 请求抽取并审查的另一项 Claim；不是在首次冻结前自主发现或独立重构整份新证明。其精确身份是 `WC-SHARED-SIDE-BUDGET-POTENTIAL-v1`：共同权 hub、unique-light side、unique-source light 的相同有限结构；d≥0、α≥1；H、M、E 沿用冻结稿定义，但不假设 UF，也不假设 α≥A_d。

新假设仅为每名 light ℓ（source v）的

    F_v(W_v)+Σ_{j:ℓ(j)=ℓ}G_j(wℓ+m_j u)
      ≤ α[F_v(u+wℓ)+Σ_{j:ℓ(j)=ℓ}G_j(wℓ)]              (AS)

及每 source v 的

    Σ_{j:o(ℓ(j))=v}H_j(m_j) ≤ M_v.                   (B)

结论：E 的任一单 hub 翻位局部最小点，配以全部 light 与 source 反位，是 α-PNE。新 Claim 的 degree-domain、α-domain 和假设均不同，必须另列 ID，不可静默改写原 `UF-v1` 身份。原 UF 命题保留其原范围。

**审查结果：成立。** 冻结稿第三、四节的势边际 (L)、成本差 (D)、重置 (R) 只使用非负性、单调性和 α≥1，不使用 d≥2、A_d 或标量 TR。对 hub，直接使用假设 (B) 即闭合 −M_v+source-budget≤0。对 light，当前真实成本≤AS左侧，偏离真实成本≥AS右侧括号，因此 AS 本身就给当前≤α偏离，正是所需弱式。有限局部最小点的存在论证不变。

d=0 时，任意侧费用常数 G≥0 使 H_j(m)=Σ[(1−α)G]_+=0；M_v=(α−1)F_v≥0，因此预算自动满足。AS 也自动满足，因为该 light 的全部费用在任何负载下相同。α=1 时，势边际区间退化成真实费用，H与M仍有限、非负，整个证明全为弱式，不需要严格正余量。d=0、α=1同时发生时亦然。全部零费、零偏离、空light/side/H、source∈H边界继续覆盖。

原定理在 d≥2、α≥A_d 与 UF 下，已由冻结稿证明 (B)。UF 给 `α·AS左侧≤AS括号`；α≥1、费用非负，故它还推出较弱 (AS)。所以原 UF theorem 可作为新抽象命题加标量预算推论的特例，但新命题无须经过 A_d。这个依赖是单向的。

### 非 UF 实例与边界独立复验

新增独立脚本 `tests/audits/weighted_congestion/independent_shared_side_budget.py`，配套输出 `evidence/runs/weighted_congestion/shared_side_truncation/budget_boundaries.json`，不导入作者或前一审计脚本。它从实际资源集合重算每次偏离，全部用 Fraction。

两项显式非 UF 实例都只有一个 hub v、一个 light ℓ，u=w=1，唯一 side 的 H={v}，无其他资源；每个资源均有两个同费副本。

1. d=0，F=G=1，α=2。AS 为 2≤4，H=0≤M=1；UF 要求 2≥4，故失败。全部状态都是精确 PNE。
2. d=2，F=G=x²，α=11/10。AS 为 5≤11/2，H=4−11/10=29/10≤M=44/10−1=17/5；UF 要求 5≥11/2，故失败。而 α=11/10<A_2=4/3，故也确实落在原定理 α-domain 之外。两种动作在任意对手位下均使该玩家付主/侧费用 1+4=5，全部状态都是精确 PNE。

代码同时核验：α=1 非零二次费用时 H=M=3；d=0、α=1无side时 H=M=0；全部零费且 H为空时 H=M=0。每例都检查两个全反位状态的全部真实单方偏离。它们证明 AS+B 与 UF 的假设确有区别，有限核验不替代新命题的一般势证明。
