## 一、先于正文的独立重构

### 1. 固定 light 的排序边际

对固定 side 的 hub 集按权重非增、同权按固定身份排序。若插入权 a 的玩家，其前面总权 z、后缀前缀为 q_r，插入边际必为

    G(x+z+a)+Σ_r[G(x+z+q_r+a)−G(x+z+q_r)].

后缀每个权不超过 a，故长度 a 的区间 [x+z+q_r,x+z+q_r+a] 与初段 [0,x+z+a] 的并无间隙覆盖至真实总负载 Y。对非负 G' 积分，插入边际至少 G(Y)。这里依赖非增排序，若任意排序就不能沿用覆盖论证。

设整个 side 最小 hub 权为 A。初段内，起点 q_r≥rA 且 q_r≤a，故后缀覆盖数至多 floor(a/A)；加初段后至多 1+a/A。初段外，长度 a、起点间距至少 A 的区间几乎处处重叠数至多 ceil(a/A)≤1+a/A。常数项 G(0) 只领取一次。因此原始独立重构给出的边际至多 (1+a/A)G(Y)。固定身份的排序保证删去/插入时其他玩家次序不变。

**加强后的再次独立核对。** 设后缀第 r 权为 b_r≤a，Y_r=x+z+q_r+a。非负多项式凸，故末端短区间平均导数较大：

    [G(Y_r)−G(Y_r−a)]/a
    ≤[G(Y_r)−G(Y_r−b_r)]/b_r.

又 b_r≥A、Y_r−b_r=Y_(r−1)，逐项乘回并求和得

    ΔP≤G(Y_0)+(a/A)[G(Y_m)−G(Y_0)]≤(a/A)G(Y_m).

常数、线性、零费用和空后缀均成立。原区间覆盖下界不变，最终边际为 [G(Y),(a/A)G(Y)]。因此最终 α≥R 足够；弱冻结的 α≥1+R 已被加强替换。

### 2. 重置与局部 source 比例

重置一个 light 权 w，排序前缀之间仍相距至少 A。导数界 G'(t)≤dG(Y)/Y、nA≤Y 给 dw/A 倍最坏侧费用；积分区间重叠给 1+w/A 倍。故 κ_d(w/A)=min{dw/A,1+w/A} 可付。

令 source 权 a_v，t=w/a_v。κ_d 单调、凹且过原点，因而 κ_d(ct)≤max{1,c}κ_d(t)。所以局部参数

    R=max({1}∪{a_v/A_j:v∈H_j≠∅}),
    K=max({1}∪{a_o(l)/A_j:l∈L_j,H_j≠∅})

分别控制真实 hub 边际和 source 重置；二者不必等于全局 hub 权比。全部 H_j 为空时 R=K=1，侧势恒零，无需定义 A_j。

### 3. 源预算的承重步骤

固定 source v，UFhet 保证每名 light 的完整 side 预算满足

    Σ_j[αG_j(T_j+U_j)−G_j(w_l)]
    ≤F_v(a_v+w_l)−αF_v(W_v).

左侧非负，且每项至少 (α−1)G_j(T_j+U_j)。所以全部 side 同时领取该 light 的一次主预算后，重置不超过

    K/(α−1) Σ_l κ_d(w_l/a_v)
                 [F_v(a_v+w_l)−αF_v(W_v)].

第八节 8.4 的两分支先证明这个不含 K 的和至多 dF_v(a_v+W_v)；这一步只需 α≥1。再用 (α−1)²≥Kd 和单调性 F_v(a_v)≤F_v(a_v+W_v)，总重置至多主资源 α 差额 M_v。不是逐 side 重复领取完整主预算。

## 二、冻结稿逐项攻击

- **量词和模型。** R,K 由有限正实 hub 权定义且≥1；最终 α≥R≥1、(α−1)²≥Kd≥2 合起来保证 α≥1+√(Kd)>1，故 α−1 的分母合法。所写存在界仍依赖 R,K 和 UFhet；正文没有把它升级成绝对常数的全类界。全局比 R0 的推论由 R,K≤R0 合法推出。
- **S1 初段覆盖。** 后缀步长≤a 保证区间无缝；最小步长≥A_j 保证上界。有限端点的多重覆盖是零测集，不能按闭区间端点直接计最大重数，但正文正确采用几乎处处积分论证。
- **S2 极端外场。** 固定 light 重置到目标副本时，其新 light 总权始终≤T_j；所有积分端点≤T_j+U_j。n=0、S=∅、H_j=∅ 时左侧为零，不需要除零。Y>0 仅在 H_j 非空时使用。
- **S3 跨 source 权比。** source 不必参加该 side，因而只用 R 不够；K 显式包含 a_o(l)/A_j，堵住了把 source 权错误当成该 side 权范围的缺口。若该比例<1，单调性给系数1；若≥1，凹性给该比例。
- **UFhet 到 S5。** Σ_jP_lj≤主预算是一整名 light 的约束，且 P_lj≥(α−1)G_j(maxload)。空 H_j 的收费可以从实际重置中省去，但在 UFhet 中保留仍合法。各 light 的主预算在 UFhet 下各自非负。
- **第八节调用。** 8.4 的最终倍率域 α≥1+√d 不能直接照抄成这里的前提；真正调用的是其证明中加权和≤dF 的中间引理，该中间引理只需 α≥1。第九节已明确这一区别。T=0 时没有 light 项；T≤1 的丢负项、T≥1 的超可加重组均合法。K 的乘入只发生在这个中间界外。
- **真实偏离。** hub 翻位时先固定所有 light，S1 控制的确是真实侧成本；随后 source light 的重新反位只是势比较中的误差项。不能把这次重置算作真实联合偏离，正文没有这样做。
- **主资源及 light 核查。** 全 anti 时 hub 当前主负载 a_v，偏离后 a_v+W_v；light 当前主负载 W_v，偏离后 a_v+w_l。当前 side 负载至多 T_j+U_j，偏离后至少 w_l。UFhet 给 αC_l(current)≤C_l(dev)，强于所需不等式。
- **退化和端点。** 常数与零多项式的导数为零、常数边际单独领取一次；无 light、无 side、空 H/L、重复 side、source 同时在 H、source 不在 H 及没有 source light 的 hub 都不改变上述估计。弱等号端点直接按 MODEL 不等式处理，没有费用商或 0/0。

冻结对象未发现 fatal objection。最终上界中的 R 没有声称最优；全部 hub 同权时 R=K=1 且 d≥2，(H) 恰为 α≥1+√d，与第八节一致；这里没有更差的阈值。

## 四、范围攻击：异权 side-only 不应冒认 exact 势

异权 hub、无 light、F_v=0 的二元对称 side-only 模型并非总有 exact PNE。一个有理整数例：三名 hub 权为 (1,2,3)，每 pair 各有一组副本，费用

    G_12(x)=2100x²,  G_13(x)=1130x²,  G_23(x)=499x².

每人位 b 使用其两个 incident pair 的 b 副本。三个“优先反位”方向为 1→3、3→2、2→1，其改变同位为异位的收益分别满足

    1130·15=16950>2100·8=16800,
    499·16=7984>1130·7=7910,
    2100·5=10500>499·21=10479.

全同位时任意玩家均能改善；其他六个状态中，同位 pair 的一端优先反位它，因此也能严格改善。逐八个状态用 Fraction 重算，最佳纯状态倍率恰为 20896/20875>1。这个例只否定 exact PNE 的擅自推广；它远不否定目标量级，也不反驳本节的 α 界。

pair-only 的统一 2-PNE 已受既有资源支持界覆盖，不能将上述小例包装为新的全类下界。真正开放的是去掉无界 R,K 与 UFhet 的全多支持状态选择。


## 五、第二审查者的独立重构与最终冻结攻击

第二审查者先只读精确 MODEL、第八节同权陈述及作者给出的异权候选 statement，未读第九节证明，自行重构了降序前缀势、删除边际的区间覆盖、逐 light 重置及局部 source 参数 K 的缩放。该阶段候选前提为 α≥1+R、(α−1)²≥Kd。独立报告之后，才阅读整份正文 SHA-256 为 `cfe1785868b7a1ec98b06e3d0c43275fe6c6a5e4e1edf3a674814748b094e57b` 的冻结稿；没有发现仍成立的致命反驳。

阅读这份较弱冻结稿后，第二审查者提出了下述严格的凸性加强。它不是最初 statement 盲重构时已经取得的结论，也不归为作者原稿的现成事实。令被删 hub 权为 a，后缀权为 b_r≤a、q_r=Σ_(t≤r)b_t，且 y=x+z、Y_r=y+a+q_r、Y_0=y+a。非负系数多项式 G 的导数非减，所以在共同右端点 Y_r 下，长度 b_r 的短尾平均斜率至少长度 a 的长尾平均斜率：

    G(Y_r)−G(Y_r−a)
    ≤(a/b_r)[G(Y_r)−G(Y_r−b_r)]
    ≤(a/A)[G(Y_r)−G(Y_(r−1))].

全部自变量均非负；b_r>0、b_r≤a 和 b_r≥A 分别保证除数合法、尾均值比较方向以及第二个比较。后缀求和望远镜，再用 a/A≥1 和 G(Y_0)≥0，得到

    G(total)≤ΔP≤G(Y_0)+(a/A)[G(total)−G(Y_0)]
                       ≤(a/A)G(total).

下界仍由后缀步长≤a 的区间无缝覆盖证明。常数、线性、零费用及没有后缀时同样成立；没有删除常数项或对零费用作商。于是 α≥R 足以吸收 hub 的真实侧成本比较损失，原先 α≥1+R 可以放宽。K 与逐 light 重置预算不变。

作者采纳该加强并重新冻结后，第二审查者读取最终整份正文 SHA-256 `d23fecbe030e027efc458072208283de2e800d40570e3d9ea2c2ca619d228a15`，对以下差异和承重接口重新攻击：

- 条件由 α≥1+R 改为 α≥R 后，R≥1 且 (α−1)²≥Kd≥2，仍推出 α>1；S5 中除以 α−1 合法。
- S1 上界使用的是凸性短尾均值比较，随后新副本插入边际≤R 倍真实新成本；所有同权 tie 始终按固定身份排序，所以插入和删除保持其余用户次序。
- 局部 K 包含 source 不在 H_j 的情况；不能只用 side 内部 R 代替 K。若 a_source/A_j<1 则用 κ 的单调性，否则用过原点凹函数的次齐次性。
- UFhet 使每名 light 的完整主预算非负，全部 side 只共同领取一次；因此把 κ(w/A_j) 放大为 Kκ(w/a_source) 时不反转符号。
- 固定 light 的真实 hub 偏离与随后仅用于势比较的 source light 重置仍分开；source 自己属于某些 H_j 时也由目标副本的完整 U_j 和 T_j 控制。
- α=max{R0,1+√(R0d)} 的全局权比推论满足最终两条件；R=K=1 时由 d≥2 恰恢复第八节阈值。它们没有消去一般实例无界的局部 R,K。

最终结论：最终冻结的第九节一般证明未发现仍成立的 fatal objection，结论仅为所写 UFhet 子类的全 anti α-PNE，不是全类 WC-TARGET 的肯定或否定证明。

第二审查者还在 clone 外从零实现了 Fraction 诊断：按最终加强式检查 1500 个删除边际、1500 个重置；160 个 UFhet 完整实例中枚举 728 个势局部最小点和 3964 个真实偏离不等式，其中 91 个实例局部 K 严格小于全局 hub 权比，28 个实例使用 α<1+R，23 个取 α=R；另检查 84544 组源标量中间不等式。全部通过。这些临时代码及运行没有登记为持久冻结资产，不能用本段替代正式审计证据；最终可复用的两路代码及冻结结果以第九节 9.5 和本审查第三节为准。有限诊断不证明一般实数参数命题，第二审查的一般依据是上述凸性与预算推导。

## 六、单副本边际锐性补充的最后差异核对

作者在第9.4节另加入单副本边际锐性及与真实存在性的区分后，正文 SHA-256 为 `cb93819d29d2ca37618883eb9fbaac46c7bbe65e4e42027674c80f3694a73581`。独立核对该新增段：G(x)=x、a=RA、后缀 n 个 A 给 ΔP=(n+1)RA、c=(R+n)A，故其比确为 (n+1)R/(R+n) 且固定 R 时趋于 R。这个过程允许 R 为任意≥1实数，没有把渐近 n 当成有限 game 的边际端点取得。

单 side、二元同费副本的 exact PNE 说明也成立：在有限状态中取绝对负载差最小者；若某玩家可严格降费，单调费用给当前负载严格大于偏离后负载，翻位会严格减小绝对负载差，矛盾。费用恒定/为零时没有严格改善，不影响此论证。因此新增段没有把方法损失升级为存在性下界。此次差异不改变第九节定理及前述审计程序。
