# 拥塞时钟与局部矩账本的全部陈述

严格双扫环可以经锚定时钟编译成全状态无α-PNE，但时钟次数要支付完整成本B、真实余量η和全部非法态；没有统一跨实例的次数效率。三次保次数失败、统一低泄漏预算非必要、43次稀疏证书和80次完整uniform证书是不同对象，均不宣称最优次数。保front的相位商和端点差不自动保证全部front有出口。

身份子集的局部成本压缩保所有状态/偏离成本，不保原资源或算法效率；暂态dual可行不表示暂态必要。异权全成本刚性是有限非负表示锥的射线/支持结论，既不排改变玩家/权/标签的均衡lift，也不排≤D资源数量压缩。奇环dual的无界mover支撑是特定selector合同，不是无PNE族。
