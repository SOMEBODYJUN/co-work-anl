## 37/33 四玩家有限权证书

原子卡的核心小定理是：玩家权只取 1 或 2、每种至多两人、策略族任意有限、资源延迟任意非负二次多项式时，存在一个真实权重缩放的 \(37/33\)-近似势模板。单资源势 \(F(k,l)\)（行是轻玩家数、列是重玩家数）为
\[
\begin{array}{c|ccc}
F(k,l)&l=0&l=1&l=2\\\hline
k=0&0&296/33&1354/33\\
k=1&1&629/33&2279/33\\
k=2&5&37&109
\end{array}
\]
对12条加入边，原卡用 Fraction 精确检查
\[
w_iL_{\mathrm{new}}^2\le\Delta F\le(37/33)w_iL_{\mathrm{new}}^2.
\]
定义 \(\Phi(s)=\sum_e a_eF(k_e,l_e)\)；删除资源的势损失由旧成本下界控制，加入资源的势增量由新成本上界控制。若玩家的旧成本大于 \(37/33\) 倍偏离后成本，\(\Phi\) 严格下降；有限状态空间保证严格改善序列终止。常数和线性费用用各自的精确离散势，再以非负系数线性组合覆盖任意非负二次多项式。

从 \((0,0)\) 到 \((2,1)\) 的两条加入顺序给出模板最优性：
\[
F(2,1)\ge1+4+32=37,\qquad
F(2,1)\le33\alpha,
\]
所以统一真实权缩放的边际夹逼模板必须满足 \(\alpha\ge37/33\)。这只是该模板、该人数范围和该缩放约定的最优性；它不是所有 weighted congestion games 的近似阈值，也不构成存在必须达到 \(37/33\) 的博弈下界。

现有[有限双权近似势与非对称精炼目标的不同合同](有限双权近似势与非对称精炼目标的不同合同--资料.md)已经保存同一 \(37/33\) 表和边际合同；本对象保留原子候选卡的来源身份和其与14候选的关系，不另造重复定理。

## 已有更强版本和不可混用的量词

原子卡第二轮已发现允许类型缩放、每类人数不受两人限制的 \(64/59\) 版本。现有双权资料保留其共同 type scaling：
\[
F_{min}=8S_2(l)+S_2(k)+2lk(k+1)+4l^2k,\qquad
F_\theta=F_{min}+2\theta kl,
\]
并取 \(\theta=3/8\)、\(\lambda_1=1,\lambda_2=59/32\)、\(\alpha=64/59\)，得到所有整数 \(k,l\) 和所有非负多项式分项共享同一缩放的边际夹逼。故不能再把 \(37/33\) 当作该有限权线的最新最好上界；它只保留为更窄的人数/模板证书。

现有[有限权类别三角排序势](../定理/有限权类别三角排序势--定理.md)进一步允许全局至多 \(k\) 个不同实权，给出根 \(A_{d,k}\) 的一般近似 PNE 存在和固定背景/窄权簇扩展。它的成本约定、玩家乘子、次数和量词与 \(37/33\) 小表不同；不能因都称“有限权”而把一个结论直接替换另一个。

全类 \(Cd/\ln d\) 的旧 OPEN 状态也不能继续照抄：现有 weighted-congestion 入口已整理全状态无 \((d/10)\)-PNE 族和相应量词。子类 \(37/33\)、\(64/59\) 势证书与全类非存在族保持独立。

## 14 个候选的去向

原子卡的候选可按以下层次保留：

- A01：有限权字母表下自动合成离散资源势，先问 \(\{1,2\}\) 类型是否有跨任意人数的统一 \(37/33\) 或更强模板；需要全 \(\mathbb Z_+^2\) LP/势、bit complexity 和文献查重。
- A02：权重 \(\{1,3\}\) 或一般有限字母表的 exact-potential 分类。curl 方程给
  \[
  2c(t+3)-3c(t+2)+c(t)=0,
  \]
  其形式解为 \(a+bt+d(-1/2)^t\)；充分性、非负单调约束和已有有限权分类仍需正式证明/查重。
- A03：异质 \(L_p\) 聚合下达到已知 \(r^{\frac12(1/p-1/q)}\) 存在阈值的 smoothed 算法；不能把一般存在阈值突破写成算法结果。
- A04：相关噪声下截断倒数引理；边际密度上界和 union bound 给有限的 \(\mathbb E[\min\{a/Y,B\}]\) 估计，适合作为附属工具，不宜独立成主项目。
- A05/A06：混合 sum/max 的逆序结构和等价成本表示优化；需先排除只是既有边际/LP重写。
- A07/A08：树/单环或两个 matroid 交的结构存在/近似；必须先做最小反例，不能以“matroid 交换直觉”代替证明。
- A09/A10：weighted matroid 动态算法与 finite-type PoS 曲线；严格区分有限终止和多项式步数、存在阈值和社会成本。
- A11：budget-balanced cost-sharing 干预恢复 potential；需与已有 Shapley/cost-sharing 分类核对。
- A12：priority-based matroid 游戏的参数化复杂性；已有 priority 框架覆盖部分一致/不一致情形。
- A13：只对窄势模板证明能力下界；不能偷换成全类 \(d\) 近似势不可能。
- A14：一般 \(d\) 或人数 \(n\) 的全类下界扩展；重要但不适合作为短周期主目标。

来源把 A01 定为第一优先查重+全人数证明，A02 定为 24 小时 novelty gate，A03 为结构化备选；本文不把任何一项升级为已选定研究问题。

## 相关文献排雷和模型边界

原卡实际检查 Harks–Klimm–Möhring 的 weighted potential 分类、Hansknecht–Klimm–Skopalik 的一般二次 \(4/3\) 与两玩家 tight 结果、Caragiannis–Fanelli 的多项式费用势、CGGPW 的一般下界/复杂性、Pocas 等统一近似势、mixed objectives/complementarities、Takazawa 的优先级模型和 smoothed FPTAS。排雷的关键是：

- 一般二次 weighted congestion 的存在界早已达到 \(4/3\)，两玩家约 \(1.054\) 的 tight 结果不能被 \(37/33\) 误写成两玩家突破；
- Lp/matroid 聚合的存在与排序框架已有文献覆盖，简单“给 Lp 加权”不形成新定理；
- 有限 priority delay 的旧开放方向已有后续处理；
- CGGPW 的下界是 \(\Omega(\sqrt d/\ln d)\) 而非误传的 \(\Omega(d/\ln d)\)；
- 作者稿、会议摘要和撤回公开稿的状态不能替代逐定理阅读或新颖性认证。

这些排雷是来源报告的文献定位；本对象不据“没有搜到”宣称新颖，也不把某篇撤回稿当作已接受定理。weighted-congestion 与 local-potential-games、fair-goods、CAG/SPE 保持模型隔离。

## 证据、实现和复用边界

37/33 的12条边是原子卡明确记录的 Fraction 精确证书；各类型最多两人的浮点 LP 扫描和各 \(q,d\) 的有限组合只属于探索证据。四玩家小表可证明模板最优性，但不证明全人数、任意权重、全部 ordinal potential 或全局最优 PNE 阈值。

后续若继续 A01，应首先：

1. 在全 \(\mathbb Z_+^2\) 上构造统一 \(F\) 或给出最小不可行 LP/Farkas 证书；
2. 验证加入边的所有边界、空资源和零费用情况；
3. 处理有理表示与 bit complexity，并把严格改善终止和多项式时间分开；
4. 与 \(64/59\) type scaling、\(A_{d,k}\) 三角排序势及已有 finite-weight 文献比较；
5. 若 \(37/33\) 被已有上界支配，转为模板最优性/自动证书或 A02 的有限权 curl 分类，而不是继续把旧数值包装成新全局阈值。

本对象是原子拥塞选题来源图和小证书的资料入口，不新增全类定理、反例或外部新颖性主张。第三阶段可将它连接到现有 \(37/33\)、\(64/59\)、有限权类别和全状态下界对象，边的解释必须保留不同玩家数、权重缩放、费用和势量词。
