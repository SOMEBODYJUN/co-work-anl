# 来源角色

`toolbox/README.md` 是加权拥塞存档的工具入口，要求每个工具先说明精确输入、结论、承重条件、来源和复用场景；列出的正占用核交互秩面、锐截断与闭包只是导航，不能替代对应数学正文。上游 `.gitattributes` 要求 `polish_skill/idea-novelty-auditor/references/idea_novelty_risk_audit.md` 的行尾空格逐字保留，以稳定 Markdown 硬换行。

编译器 `LICENSE` 是 CC0 1.0 Universal 法律文本：在适用法律允许范围内放弃著作权及相关权利，并在放弃无效时提供非独占、不可撤销、免版税的许可后备；文本明确不放弃专利或商标，也含按原样提供、无保证以及第三方权利/同意责任限制。这里仅记录资产许可证，不作法律意见，也不把 CC0 扩张到其他文件。

`fix_macro_param_prefix_substitution.txt` 描述宏参数 `orig` 与 `orig_len` 的前缀替换缺陷：按声明顺序的字符串替换会把 `\\orig_len` 换坏成类似 `140b_len`，导致 Linux kernel `.altinstructions` 独立构建出现未定义引用。建议按参数名长度从长到短替换，并修改 Rust 后端通用汇编预处理与 x86 GAS 宏状态展开；源文件没有补丁或测试，因此不登记为已修复。

`optimization_passes_future.txt` 是编译器优化计划，列出现有 constant folding、copy propagation、DCE、GVN/CSE、简化、CFG 简化、LICM、inline、if-conversion、narrowing、常数除法、IPCP 和 IV strength reduction，并建议后续加入 SCCP 与指针/复杂归纳变量强度削减扩展。它是计划记录，不证明候选 pass 已实现或验证。

# 复用与边界

这些资产供数学清洗、文档构建和上游编译器维护使用；不改变加权拥塞模型、PNE 量词或任何定理真值。若未来提交宏替换补丁，须另读代码、添加回归测试并以新来源指纹登记；优化计划应区分计划、已实现与已验证。`legacy-cleanup` 与 `main` 的同路径副本按冻结指纹视为一个来源版本，每个 source ID 只登记一次。
