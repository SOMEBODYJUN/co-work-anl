# CB01：两容量 BMKP 的联合标签只给条件模块

输入为公共非负有理重量/利润、容量集合 `{1,C}`（两个容量模式）、物品至多使用一次、硬容量、最大化各箱利润最小值。目标是每个固定 `ε>0` 的确定性总位长多项式时间 `(2/3−ε)` 近似。报告把母文的单容量 profile 变换分别作用于两种容量，再把每物品的两套状态、profit bucket 和 cheap/expensive 标记合为 joint type；所有 long bins 的 expensive 物品取全局 critical union，按类型保留最重供给。

报告给出的交换引理是条件的：joint label、各容量 rounded feasibility、同类利润桶宽 `δ`、long 中全部 expensive 皆 critical 都已给定时，同型 critical 与 noncritical 对换保持 long 标签式、short 实容量不增，利润损失至多每次一个桶宽。它没有证明两份 profile 能同时存在、没有解决同一物品的供给冲突、没有把 matching 与 cheap LP 拼成同一见证，也没有重新处理高利润 singleton 的预处理。因此它只能补充既有 BMKP 三模块对象，不能写成总算法或近似定理。最小两箱容量 1/2、同一物品在不同容量中被标 heavy/light 的玩具只说明 union-critical 的必要性；报告未完成算法级穷举。

与已入档对象的具体差异是：`双容量BMKP候选的三模块与完整目标` 已分别保留 L1 critical 恢复、L2 嵌套 matching、L3 允许 discard 的 LP 舍入及参数/边界纠错；本源将它们放回“跨容量共同可行性仍未证”的反方框架，不能用 L1/L2/L3 的单模块检查替代 joint construction。

# CB02：copies SD-EF1 的前缀系统和有限范围

三人、任意类型集合；类型 `g` 有 `c_g∈{1,2}` 个非全体副本（`c_g=3` 的全体副本在 pairwise prefix 差中抵消），每人每类型最多拿一件，所有副本分完；每个观察者的类型排序可不同。SD-EF1 的计数形式是对任意观察者 `i`、比较者 `j` 和 `i` 的排序前缀 `P`，`|A_i∩P| ≥ |A_j∩P|−1`。这等价于从 `j` 包中删除对 `i` 最优的一件后，`i` 的包对该序随机占优。

报告将列和为 `c_g` 的 0/1 矩阵视为多序 prefix b-matching；`c=1` 可看作一人的正颜色，`c=2` 可看作未选中人的负颜色，尝试用交替路径消除最早坏前缀。平均分数点只能给成对误差 2，不能替代所需的误差 1。首次承重义务是任意类型数的三人交换/增广不变量或最小精确反例；`n=2`、至多四类型和随机样本均不构成主结果。

已入档的完整有限证据是 9216 个严格 profile（固定第一人排序后 16 个重数模式×24² 两个其余排序），每个 profile 枚举所有 81 个分配，均找到 SD-EF1，最少 9 个证人；`boundary` 明确这是 finite exhaustive evidence、无独立形式化证明。该结果与一般 partition matroid 负例不能互换，因为 copies 的同型副本对每个 agent 等值。

# CB03：K8/K12 只保存障碍和候选覆盖路线

K8 为类别大小 `(3,3,2)`、每类 cap 1、总 cap 2；K12 为四类各 3、每类 cap 1、总 cap 3。四个非负 additive 估值与预定人序要求完整可行 EF1，且 `i<j` 时 `i` 不 envy `j`。母文已表明三人路线的 top-i favorite 分散条件在四人 key case 失效；报告提出以每个 allocation 的 valuation chamber/多面体比较区域覆盖整个非负锥，先从 K8 开始。

仓库材料只支持有限范围：K8 有 864 个标号可行分配；报告和交叉证据检查了 seed 20261020 的 1,000 个值域 0..20 profile，未见失败；K12 的更大有限样本也未覆盖连续锥。`top-i` 旧路线无可行分配不等于 ordered-EF1 失败，普通 EF1 与 ordered 加强版不能混写。首要义务是 K8 的完整 chamber 覆盖或有理不可满足证书，再谈 K12 或四人一般 laminar。

# CB04：二平行类 Hall 翻转是局部工具，不是 rank-2 总解

在无 loops 的二平行类模型中，每个 agent 的成本为 `1[触达 A_i]+1[触达 B_i]`，全物品分配；报告复核了 missing-word 图、最大 matching、交替可达集和增广翻转。修正后的关键是翻转前必须选择全局未匹配物品；随意选择 `e∉T` 不保证未匹配。其结论是 `m≥n` 时构造完整 EF，`m<n` 时每人至多一件的分配给 EFX；这不是任意 rank-2 EFX 定理。

三平行类时“异于 missing coordinate”可能使 owner bundle 同时触达两类，owner-pure 机制失效；loops 又允许别人非空包成本为零。仓库有限证据包括三人 3–8 件的 12,825 个 word multiset EF 回归，以及额外 rank-cap=2 的 1,000/1,000/250 随机 profile（n=3,m=9 无/有 loops；n=4,m=8 有 loops）均未见 EFX 失败。这些只是有限证据，不能扩大量词。

# CB05–CB07：保留为迁移接口与排雷

**CB05。** ladder spanning-tree base 具有无界 rank/corank；固定 rank/corank 给总权重界 `C=r`，cactus 只是 partition matroid，均不构成非平凡图定理。真正义务是任意边序下局部交换/路径分解给出不随 ladder 高度增长的 prefix 误差；报告没有运行玩具，也没有定理。

**CB06。** 报告把随机 full-information clipped RM+ 限在有界多线性势的二元 identical-interest game，拒绝把问题改成 generic SGD。关键危险是 positive-part clipping 破坏无偏势漂移，必须逐步控制估计噪声、最佳动作误判和 regret state 持久效应。`local-potential-games` 对象已保存同一随机接口和一个单代理两动作噪声例：无偏观测下真实势期望可下降；该例只否定错误 Lyapunov 推理，不是 RM+ 不收敛反例。

**CB07。** 每人两策略且每策略最多两个资源时，affine latency 的 Rosenthal potential 可写受限二次形式，但其 incidence 矩阵列至多四个非零不等于任意 PSD QUBO；必须先刻画可表示的局部二次型并检查低度 Local-Max-Cut 文献。报告建议 2–5 人整数小例枚举，未执行。weighted-congestion 中已有两策略无纯均衡和局部势反例，但那些实例不等价于本候选的“任意 size-2 策略列表求任意 PNE”量词。
