# 拥塞结构势与规范形账本的全部陈述

要求全部改善边下降的序势、仅让某个全局最小点稳定、资源边际夹逼与存在PNE是不同量词。全动作2^E允许全空精确PNE，仍可有严格改善环，故方法障碍不等于全状态无均衡。资源签名与degree局部维数是固定模板的表示界，不提供无界玩家/动作族的统一规模截止。全状态selector的dual须保其支持/真实边，不可用任意局部一致矩替换。

整数单位单项式规范形依有限严格余量，其反例存在等价不保证保持原实例β、资源数或一般算法效率；全类端点闭性不表示有单游戏取得sup。密度/份额、尾部、两权/有限权类的势各带不同参数。A_(d,k)<d对每个有限k成立，固定d时k增大趋d，不能把固定k的o(d)推广全类；不过逐有限游戏取其实际k可以给d-PNE存在，这一准确推论在总合同解释。
