# 循环窗口前沿的扭转相位商

本页给真实两动作拥塞游戏的状态表示及费用恒等式，不把同一类的玩家合成一个可跳跃相位的玩家。模型为有限非空玩家与资源、与资源无关的正玩家权，成本为所选资源费用之和，不乘自身权重。单方偏离固定其他动作并按含移动者自身的新负载重算。严格 α 改善是旧成本大于 α 倍新成本；α-PNE 满足全部相反弱不等式。资源费用为非负系数多项式，允许零费。

## 完整窗口对象与前沿

取整数 m≥2、N≥1、p≥0。玩家为 P_(a,j)，0≤a<m、j∈Z/NZ，同类权为 w_a>0；全局顺序 pos(a,j)=jm+a。取有限测试 τ=(a,b,K,o)，a≠b、1≤K≤N、o∈{+1,−1}。每个测试、每个 distinguished clone h=P_(a,j) 建一对新资源 e_(τ,j,0)、e_(τ,j,1)，两侧及该测试的所有 index 共享费用 z_τ x^p，z_τ≥0。不同测试资源互异。

令 δ=1[a>b]。h 的动作0用侧0；窗口用户 u=P_(b,j+δ+k modN)，0≤k<K，动作0用侧

\[
 \sigma(h,u)=1[\operatorname{pos}(u)>\operatorname{pos}(h)]\mathbin{\mathrm{xor}}1[o=-1]. \tag{1}
\]

动作1总用另一侧；其他玩家不用该对。每人的两个动作取所有参与资源的并集，恰保留这两个动作。**每个类必须至少参与一个测试，零系数资源也保留为不同资源。** distinguished 玩家参加自己的 pair，窗口类每个 clone 恰参加 K 个 pair；故每人两个动作非空、互不相交，确为不同 MODEL 策略。角色名称不要求 w_a>w_b。

类前沿是沿 j=0,…,N−1 至多一次相邻位变化的串。它有唯一相位 x∈Z/(2N)：

\[
B_x(j)=\begin{cases}1[j<x],&0\le x<N,\\1[j\ge x-N],&N\le x<2N.\end{cases} \tag{2}
\]

全0和全1分别为相位0、N；总共恰2N个不同串。相位 x→x+1 翻 clone x modN，x→x−1 翻 clone x−1 modN。N≥2 时这两个邻居互异，且恰为保前沿的全部单人翻位；N=1时二者指同一翻位。审查另证明两前沿的 Hamming 距离为两相位在2N圆上的最短距离：沿任一长度≤N的相位路径，每步翻不同 clone。它直接给上述邻居完备性。

## 全状态扭转协变及商边

定义同时作用于全部类的 T：玩家 j 移到 j+1 modN，跨末端者额外翻位，即

\[
(Ts)_{a,j}=s_{a,j-1}\ (j\ge1),\qquad (Ts)_{a,0}=1-s_{a,N-1}. \tag{3}
\]

将 h 所有的资源对移到 index j+1；h 跨末端时同时交换资源两侧。写对应玩家的 wrap 标志 ε_h、ε_u。全序比较满足

\[
1[\operatorname{pos}(u')>\operatorname{pos}(h')]
=1[\operatorname{pos}(u)>\operatorname{pos}(h)]\mathbin{\mathrm{xor}}\varepsilon_h\mathbin{\mathrm{xor}}\varepsilon_u. \tag{4}
\]

恰一方 wrap 时先后反转；两者同 index 或同 wrap 时先后保持。轻用户变换后的实际侧为

\[
(s_u\mathbin{\mathrm{xor}}\varepsilon_u)
\mathbin{\mathrm{xor}}(\sigma(h,u)\mathbin{\mathrm{xor}}\varepsilon_h\mathbin{\mathrm{xor}}\varepsilon_u)
=(s_u\mathbin{\mathrm{xor}}\sigma(h,u))\mathbin{\mathrm{xor}}\varepsilon_h.
\]

这正是对应资源的侧交换。窗口集合保留、同类权保留、映射资源同费，所以全部真实负载及对应玩家成本保留。单人 flip F_i 满足 TF_i=F_(Ti)T，故当前和真实偏离后费用都保留。这是**全部2^(mN)状态**的协变，不只沿某条 sweep。协变本身允许每测试任意共享函数 c_τ；关键是 generator 映射保费，特别是同测试全部 index 及两侧同费。

逐位代入(2)得到 TB_x=B_(x+1)，T^N 为全局补位，T^(2N)=id。前沿空间( Z/(2N) )^m上的对角平移自由，每轨道恰2N个状态，故规范化 x_0=0 后商状态恰有(2N)^(m−1)个。记 r_a=x_a−x_0：

| 原真实移动 | 商坐标变化 |
| --- | --- |
| 类0 forward / backward | 全部 r_a 同减1 / 同加1 |
| 类a≥1 forward / backward | 仅 r_a 加1 / 减1 |

移动的类、方向及对应 clone 标签均保留。不同标签可落在同一商边；固定坐标0没有冻结类0，也没有合法化任意相位跳跃。原全局 sweep 只是前沿空间的一条特殊路径。

## 单测试真实端点费用表

用 T 将 mover 类 c 的相位归零，另一相关类相位记 r mod2N。先除去系数 z_τ，写 old/new 为 O_(τ,c)(r)、Q_(τ,c)(r)。

若 c=a，mover=P_(a,0)，令 v_k=δ+k modN、σ_k=1[pos(b,v_k)>pos(a,0)] xor1[o=−1]，n_0(r)=#{k:σ_k xor B_r(v_k)=0}。它只参加该测试自己的 pair，故

\[
 O_{\tau,a}(r)=(w_a+n_0(r)w_b)^p,\qquad
 Q_{\tau,a}(r)=(w_a+(K-n_0(r))w_b)^p. \tag{5}
\]

若 c=b，mover=P_(b,0)，列它参加的 K 个窗口，h_k=−δ−k modN、σ_k=1[pos(b,0)>pos(a,h_k)] xor1[o=−1]、e_k(r)=1[B_r(h_k)=σ_k]。则

\[
 O_{\tau,b}(r)=\sum_{k=0}^{K-1}[(K-k)w_b+w_ae_k(r)]^p,
\quad Q_{\tau,b}(r)=\sum_{k=0}^{K-1}[(k+1)w_b+w_a(1-e_k(r))]^p. \tag{6}
\]

理由是 mover 所在窗口的第k个位置：当前同侧轻用户恰 K−k 名，目标侧含自己恰 k+1 名。a<b 时 k=0 的窗口全部在 distinguished 之后，其余窗口按跨末端分段；a>b 时 distinguished index=N−1−k，同index时类序 b<a，仍恰 t≥k 与 mover 同侧。方向负仅同时补全部轻用户侧，不改轻用户之间同侧关系。因此(6)覆盖任意类序、K=N及 wrap，并计入偏离者自己。

一般相位的 forward 贡献取 r=x_other−x_c。backward 是前驱相位 x_c−1 的 forward 反边，其 old/new **为 Q(r+1)、O(r+1)**。所以两方向 α-margin 分别是 O(r)−αQ(r) 和 Q(r+1)−αO(r+1)，不是简单互为负数。乘 z_τ 后对全部测试相加，得真实总端点成本。p=0时 mover 自重正，参与资源所用负载均正，无0^0边界；(5)为1、(6)为K。非负多项式逐单项式相加即可。

## 覆盖假设修复、证据与用途

旧 freeze 没有要求每类参与测试。m=3、N=2却只有(0,1,1,+)时，缺席类2的空/空动作是同一MODEL策略；标签商有16点，真实策略商只有4点。因此原精确纯状态计数的域有实质遗漏，审查在首次登记v1前加上覆盖和零费资源保留条件。协变和单测试代数表本身不受影响；严格逐类改善的输入与本批显式反例本来就覆盖每类。不能追认旧未修域也有同样真实计数。
