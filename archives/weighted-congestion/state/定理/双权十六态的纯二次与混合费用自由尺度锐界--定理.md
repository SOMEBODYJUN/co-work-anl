# 双权十六态的纯二次与混合费用自由尺度锐界

采用[九态模板](双权九态网格的纯二次与混合费用自由尺度锐界--定理.md)的模型，真实权重1与2，每个资源每类潜在使用者至多3。正重尺度 \(h\) 共同可选，轻尺度1。资源纯二次费用 \(c_e(x)=a_ex^2\) 且 \(a_e\ge0\)。规范单资源的状态为 \((k,l)\in\{0,1,2,3\}^2\)。往 \((k+1,l)\) 与 \((k,l+1)\) 的加入边下界分别为 \((k+1+2l)^2\) 和 \(h(k+2(l+1))^2\)，同一边势增量的上界为下界乘 \(\alpha\)。

十六态模板的最小 \(\alpha\) 为
\[
 h_* =\text{方程 }481h^2-332h-848=0\text{ 的正根},\qquad
 \alpha_* =\frac{1+9h_*}{9+4h_*}=\frac{194+52h_*}{50+130h_*}\approx1.03686970638950.
\]

## 两圈下界

把每条加入边写为两条差分约束，正向权是 \(\alpha\) 乘加入成本，反向权是负加入成本。沿闭圈求和得 \(\alpha U\ge D\)，其中 \(U\) 为沿正向边的成本和，\(D\) 为反向边的成本和。这与[固定权边际圈比](../等价/固定权向量边际夹逼的最大圈比--等价.md)使用同一差分判据，这里将真实负载与势的重尺度分开。

| 有向圈 | \(U\) | \(D\) |
| --- | ---: | ---: |
| 00→01→11→10→00 | \(9+4h\) | \(1+9h\) |
| 01→11→21→31→32→33→23→13→03→02→01 | \(50+130h\) | \(194+52h\) |

前比导数分子77为正，后比导数分子−22620为负。两比在唯一正根 \(h_*>0\) 相交，故其最大值对任意 \(h>0\) 都不小于相交值，其它尺度严格更高。

## 显式达界势和逐边验证

下文以 \(h=h_*\)、\(a=\alpha_*\)，令 \(T=1-9a+9h=4ah\)。行按轻数 \(k\)，列按重数 \(l\)。
\[
F=\begin{pmatrix}
0&T&T+16h&T+52h\\
1&1+9h&T+16h+25a&T+52h+49\\
1+4a&1+16a+9h&1+16a+9h+36ah&T+52h+113\\
1+13a&1+41a+9h&1+41a+9h+49ah&T+52h+194
\end{pmatrix}.
\]
用 \(a=(-323+481h)/485\) 与 \(h^2=(332h+848)/481\) 将每边的两个余量 \(F(y)-F(x)-c\) 和 \(ac-F(y)+F(x)\) 约化为 \(u+vh\)。以下规则给可直接复算的全部24边核验。对每个 \(0\le k,l\le3\)，若 \(k<3\)，取 \(y=(k+1,l)\)、\(c=(k+1+2l)^2\)；若 \(l<3\)，取 \(y=(k,l+1)\)、\(c=h(k+2(l+1))^2\)。以上逐行逐列取矩阵差，各约化一次。48个余量中17项恰为0，其余31项的有理下界均至少 \(136099/6062500>0\)。下界取正根隔离 \(1.7170098<h<1.7170100\) 中相应端点，\(v\ge0\) 取左端、\(v<0\) 取右端。根隔离由原二次式端点异号及正根唯一性给出。

对任意每类每资源潜在使用者至多3的原有限纯二次博弈，用 \(a_eF\) 作该资源势。对严格 \(\alpha_*\) 改善，真实移出成本大于 \(\alpha_*\) 倍加入成本，因为共有成本非负。各资源使用同一玩家尺度，求和后总势严格下降。有限全局势最小点给弱 \(\alpha_*\)-PNE。上述锐性是有限共同尺度模板的锐性。下节给出混合费用共同最优；原博弈类的最坏倍率仍需独立证明。

## 非负混合费用的共同尺度

对 \(c_e(x)=a_{e,0}+a_{e,1}x+a_{e,2}x^2\)，三类系数非负。要求一个共同 \(h>0\) 适用各资源及全部单项式。纯二次第一条四圈仍要求 \(a\ge(1+9h)/(9+4h)\)。线性费用的圈
\[
00\to10\to20\to30\to31\to32\to22\to12\to02\to01\to00
\]
给 \(U=6+12h\)、\(D=18+6h\)，故还需 \(a\ge(3+h)/(1+2h)\)。前者严格递增、后者严格递减，在 \(7h^2-5h-13=0\) 的唯一正根相交。令 \(h\) 为此根，则最优混合倍率
\[
 a=h-5/7\approx1.0516487802368586.
\]
任意其它正尺度至少有一圈给严格更高的下界。

常数势取 \(F_0(k,l)=k+hl\)。令 \(F_1,F_2\) 为以下矩阵，第二个矩阵全部整体除以7：
\[
F_1=\begin{pmatrix}
0&2h&6h&12h\\
h-5/7&3h+9/7&6h+5&12h+7\\
3h-15/7&3h+37/7&6h+11&12h+15\\
6h-30/7&6h+5&6h+18&12h+24
\end{pmatrix},
\qquad
F_2=\frac17\begin{pmatrix}
0&52&52+112h&52+364h\\
7&7+63h&395+21h&395+364h\\
-13+28h&-73+175h&843-84h&843+364h\\
-58+91h&-198+350h&1410-203h&1410+364h
\end{pmatrix}.
\]
分别按上一节加入边位置取 \(c=(k+1+2l)^d\) 或 \(c=h(k+2(l+1))^d\) 且 \(d=1,2\)。用 \(ah=13/7\)、\(h^2=(5h+13)/7\) 把每项上下余量化为 \(u+vh\)。在有理根隔离 \(1.76593449452<h<1.76593449453\) 上取相应端点。每阶各有16项精确为零，其余32项的最小正有理下界分别为 \(2115609623/175000000000\) 与 \(9038536541/175000000000\)。所以两套矩阵分别给其单项式全部24加入边，常数矩阵亦满足。非负系数线性组合给所列混合资源费用势。按同一原游戏严格改善论证，完整有限局存在弱 \(a\)-PNE。纯二次的较低合同与非负混合的共同合同分别有各自尺度，混合值的锐性仍限本有限模板。
