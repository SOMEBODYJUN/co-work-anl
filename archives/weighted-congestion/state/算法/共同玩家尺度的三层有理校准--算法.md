# 共同玩家尺度的三层有理校准

本算法对给定有限实例和给定倍率，判断三种指定势接口能否支持**同一玩家跨全部资源共同的正尺度**。YES给全部严格目标改善下降及有限终止；NO只否定该接口，不能判原游戏无均衡。输入若为有理显式数据，可逐行独立验证有理证书；一般实数域的充分性仍由同一不等式成立，不宣称其精确可计算。

## 模型、背景及固定势的精确最优倍率

有限非空玩家/资源，玩家正权w_i与资源无关，每人非空有限资源子集菜单，允许空动作。资源费用是非负系数次数≤d多项式，成本C_i为所用资源费用之和，不乘自身权。真实单人偏离冻结别人，重新计入自身。

对资源e，B_e为每个动作都用e的玩家，U_e为部分动作使用的可选玩家。记b_e=Σ_(i∈B_e)w_i、ĉ_e(x)=c_e(b_e+x)。必用玩家不必全局固定，但其在自身偏离中保留e；ĉ_e二项展开仍非负系数且次数不增。每个局部子集T⊆U_e均分别可实现，不要求跨资源同时自由实现。对i∉T设a_(e,T,i)=ĉ_e(W(T)+w_i)≥0。

给定F_e且F_e(∅)=0，真实插入边际m=F_e(T+i)−F_e(T)必须满足

\[
h_i a_{e,T,i}\le m_{e,T,i}\le\alpha h_i a_{e,T,i},\qquad h_i>0. \tag{1}
\]

零费用边须m=0；正费用边须m>0，否则这份固定势不支持任何有限倍率。检查通过后，对有正费边的玩家定义L_i=min(m/a)>0、U_i=max(m/a)，则取h_i=L_i给

\[
\alpha_F=\max\{1,\max_iU_i/L_i\}. \tag{2}
\]

这是**固定这些F**仅优化共同尺度的精确最小倍率：任一可行h均须h_i≤L_i、U_i≤αh_i≤αL_i。无正费边的玩家取h_i=1，不加倍率限制。例如一个玩家在两个费用1的资源有给定势边际1、100，各资源分开可重标精确，但共同校准固定势需α=100；重新缩放资源势是下节不同问题。

## 固定有理α≥1的三种线性可行性接口

有限玩家的正h和全部势可整体同乘正数，无损要求h_i≥1，即h_i=1+g_i、g_i≥0。**字典系数是非负锥混合**；若额外要求系数和为1，就不能直接沿用此齐次归一化。

| 接口 | 变量与原始条件 |
| --- | --- |
| 自由资源集合势 | 每个非空T的F_e(T)、h_i；满足(1)、F_e(∅)=0。沿添加路径的非负下边际已推出F_e(T)≥0 |
| 给定有限字典 | F_e=Σ_rθ_(e,r)G_(e,r)，θ≥0；把每条Δ_iG的实际有理值代入(1)，逐资源取系数但跨资源共享h_i |
| 完整状态图 | 每状态φ_s及h_i≥1；每条真实偏离(s,t,i)满足φ_t−φ_s≤h_i[αC_i(t)−C_i(s)]。势可整体平移至非负 |

固定有理α时全为有理线性约束。写成Ax≤b、x≥0后，YES是逐行可核的有理x；NO是

\[
y\ge0,\qquad A^{\mathsf T}y\ge0,\qquad b^{\mathsf T}y<0. \tag{3}
\]

因为任何可行x会给0≤(Aᵀy)ᵀx=yᵀAx≤yᵀb<0。Farkas替代和有理多面体有理点性质给固定有理α的证书完备性。原实现先用有理两阶段单纯形求候选，YES重验原矩阵，NO另求并重验(3)；pivot上限、数值/表异常或无已核证书均只能UNKNOWN。实现有上限不损害已验证证书的正确性，但不是完备运行或位多项式承诺。

## 真实偏离、终止与终点证书

令Φ(s)=Σ_eF_e(T_e(s))。偏离删除D、加入A、保留H；保留费用C_H≥0且负载不变。由(1)，

\[
\Phi(t)-\Phi(s)\le h_i\{\alpha[C_i(t)-C_H]-[C_i(s)-C_H]\}
\le h_i[\alpha C_i(t)-C_i(s)]. \tag{4}
\]

故字典YES⇒自由局部YES⇒状态图YES⇒α-PNE存在；不声称逆向。任何严格α改善使势严格下降，有限状态不能重访，任一持续严格α改善过程终止于α-PNE。α>1时不保证全部精确改善终止。正成本到零成本仍有严格负势差，旧新均0不要求下降，全程不除玩家费用。

可执行流程为：验证真实输入和cost oracle；给定α求并独立验势证书；从起点任选严格α改善；终止后再扫描该状态全部原合法偏离，保存非负残差αC_dev−C_current。最后这张表单独证明推荐状态稳定，不要求信任求势器。若只校准采样边，证书只覆盖样本；除非另证闭合，不能推全游戏终止/稳定。

## 次数基线的自足来源

将可选用户按权重非减排列，令

\[
P_{e,\uparrow}(T)=\sum_j u_jc_e\left(b_e+\sum_{\ell\le j}u_\ell\right).
\]

对插入权w、插后可选负载Y>0，d≥1时

\[
w\widehat c_e(Y)\le\Delta_iP_{e,\uparrow}\le d w\widehat c_e(Y). \tag{5}
\]

下界：凸费用下，相邻重a≥轻b、共同终点z时，重先轻后的贡献减轻先重后为ab[(c(z)−c(z−a))/a−(c(z)−c(z−b))/b]≤0。把升序中的插入者逐次移到末尾只降低势，末尾边际恰wĉ(Y)。上界：任意旧顺序插入前缀X、后缀v_j的边际为wĉ(X+w)+Σ_jv_j[ĉ(z_j)−ĉ(z_j−w)]。对单位单项式x^p，差≤pwz_j^(p−1)，除wY^p后≤u^p+p(1−u)≤p≤d，u=(X+w)/Y；常数项边际恰w乘常数。逐非负项相加即(5)，零费直接用不等式。

因此字典含此势时取h_i=w_i、α=d，再整体缩放至h≥1；d=0取α=1。三接口均有认证基线max{1,d}。给定次数上界过松时可用实际最高次数；代码保守使用系数数组声明的次数仍是合法上界。此基线不来自未核外部定理。

## 倍率优化与计算规模的准确边界

固定F有(2)；固定h的图接口另由[圈比阈值](../定理/固定玩家尺度图势的圈比阈值--定理.md)精确决定。若势和h同时变化，每个固定有理α仍是LP，但把α也作变量含αh双线性项。认证二分的NO低端L、YES高端U仅包住**下确界于闭区间[L,U]**；不能因L不可行就说下确界严格大于L，也不保证一般端点取得或有理最优。[有理输入无理局部阈值](../反例/有理实例的无理局部校准阈值--反例.md)直接排除后一误读。

原游戏最佳稳定倍率又不同：有限状态逐个取最大真实偏离比，正/0记无穷、0/0不增最大值；再对状态取最小。其有限最优为有理数且取得，基线保证至少有一个有限值。[唯一精确均衡而图接口NO](../反例/唯一精确均衡与共同尺度图势不相容--反例.md)说明稳定状态可直接枚举，无需先有校准YES。

记S=Π_i|S_i|。下降步数≤S−1；若显式图存在严格改善边，其正最小预算δ=min h_i[C_i(s)−αC_i(t)]>0，还≤floor[(φ_start−minφ)/δ]。有理势公分母D另给floor[D(φ_start−minφ)]。这些数值可能巨大，不能自动推出紧凑输入的位多项式。局部插入边数Σ_e|U_e|2^(|U_e|−1)，字典变量Σ_eR_e+n，自由局部变量Σ_e(2^|U_e|−1)+n，图变量S+n；必须计入生成矩阵和寻找/排除每步真实偏离的成本。
