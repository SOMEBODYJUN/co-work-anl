# 整数规范形与空交核心的精确核验

## 资源与可复现入口

[provenance](../../tools/evidence/template-normal-forms/provenance.json)逐项记录源ID、全部冻结定位、字节SHA256、大小及保全位置；[original](../../tools/evidence/template-normal-forms/original/)保原始代码、输入、三个历史报告及完整审查，不覆盖历史证据。新执行结果在[replay](../../tools/evidence/template-normal-forms/replay/)，逐结构比较规则和结果在[replay-comparison](../../tools/evidence/template-normal-forms/replay-comparison.json)。

在original目录运行以下命令均只输出stdout：

```sh
python3 tests/audits/weighted_congestion/template_certificates/verify_integer_normal_form.py
python3 tests/audits/weighted_congestion/template_certificates/verify_antichain_core.py
python3 tests/audits/weighted_congestion/template_certificates/independent_antichain_core.py
```

第一程序的默认fixtures保持原相对布局，可用 `--input` 显式指定；`--output` 独占创建新结果，不覆旧文件。后两程序输入硬编码于源码。它们大量使用assert，应以普通Python运行，不用 `-O`。这里的执行环境为Python3.12.14；实际命令路径与源hash保存在新结果中。

## 整数规范形：22例、136原状态

源码有两个实际不同的成本oracle：原资源多项式Horner评价；目标为显式逐个单位单项式资源及真实负载求和，目标不回读原系数。完整审读了清分母/取商、退化dummy、逐状态端点、marker放大、16例固定seed73471有理生成器及全部输出合同。

实际复跑输出101,990字节，与完整冻结报告逐字节相同，全部字段相同。22例共136个原状态、115个取商后状态，341次状态-玩家成本、859次真实偏离成本、440次弱均衡等价；10个动作被合并、2个全零dummy例，含104次正到零偏离及137次零到零偏离。另K=2常数marker检查296次当前成本、666次偏离成本、59次原零成本变1。

真实全状态无53/50-PNE三人实例另先按 $w\mapsto w/2,a_{e,k}\mapsto2^ka_{e,k}/3$ 有理化，24次成本核对证明恰缩为原1/3。严格marker实验的原端点 $286/267$，取 $\alpha=953327/890000$，$K=6$，八态最小新余量 $1539/178000>0$，891个实际新资源，marker后端点 $12013/11215$。所有八态见证及全部资源/动作重数在报告保留。等式边界只验证所选margin为零，不据此声称等式时一定有均衡。

## 作者核心：5固定fixture

原始成本逐资源Fraction计算，按包含极小集、所有必选背景、二项式平移构造核心；程序未导入理论模块。五例覆盖重叠必选/可选用户、固定玩家、分数权/系数、全删、零费和无必选背景。124次原偏离提升、64次自身动作基项恒等式、32次单位复制偏离检查通过。

新结果与历史wrapper内result除command路径外全部相同，源码hash亦相同。全删分支中作者程序枚举出一个空active内部record，仅用它lift回原精确PNE，不把它当作模型允许的空玩家游戏；独立实现则明确返回无core，两种报告计数不能混加。原wrapper的运行时元信息与新的stdout分开保存，没有改写旧报告。

## 独立核心：6fixture、98原状态

独立源码有自己的字面成本oracle；多项式平移用逐次乘 $(x+B)$，而作者程序使用二项式系数。6例共98原状态、16核心状态，在六个有理倍率 $1,4/3,3/2,2,5,100$ 核出56个最小偏离成本分解、92个超集偏离比较、48个非空洞均衡提升。整数例硬编码验证 $(x+2)^2=x^2+4x+4$，构建13个单位资源、24次成本检查；单向提升反例是原110/101而核心10/1。

新输出与冻结wrapper的完整嵌套result精确相同。规范源码hash与[审查迁入合同](../审查/有限择证与规范形的审查范围--审查.md)一致。本轮只重跑规范版本，没有冒称原会话临时路径仍存在或再次执行。
