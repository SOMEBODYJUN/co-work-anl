# 类前沿与同类时钟的精确核验

本资源保存可重放的原代码、显式输入和真实有限证据，不将运行报告替代一般证明。数学对象分别为[扭转相位商](../定理/循环窗口前沿的扭转相位商--定理.md)、[24资源端点反例](../反例/严格双扫环的不同步稳定前沿--反例.md)、[64资源任意次数compiler障碍](../障碍/有序同类三元时钟保留严格均衡--障碍.md)及[全前沿条件编译](../定理/同权类前沿全覆盖的全状态编译--定理.md)。两种12玩家游戏完全不同，第三个有理输入则是9玩家条件编译演示。

其中十项独立输入、程序、运行与专门审查的36个语义单元及正式去向，另逐源列于[closure-provenance.json](../../tools/evidence/class-front/closure-provenance.json)。它们各有独有内容：64资源例的全部偏离证书及独立全态统计、条件编译的全部216行选择器、独立条件边界和版本修复均有明确正文/原证据去向；这份补充核对复用下述同一次六程序真实运行，不增加运行次数。第19项后续线性正文仍仅作比较来源，不以引用代其owner完成逐源整理。

## 三个固定输入的不同逻辑地位

24资源例：α=21/20的严格24步双扫环；相位(0,4,0)六端点全<-9/50，却两内部clone margin>1/5。它不是α-PNE；不能用于“所有类内clock都不能编译”的一般结论。

64资源例：同权谱、同次数和同倍率但八测试不同。相位(0,0,1)对全部12翻位精确margin<-1/2，所以是真正strict exactPNE。有限表加上任意前沿对所有允许clock偏离的2w→2w或w→3w一般引理，才给任意次数compiler障碍。

9玩家条件例：216前沿全部有保front出口，B=16553910168/815730721、η=1410469765084842635603/1070401852096200000000；16个base α-PNE全在前沿外。标准预算最小D11，分离预算D4；后者输出最高次数仍8。有限全态核验确实消除这16个基体均衡，但不证明预算最优D，也不给增长族。
