# 十四资源构造与缩权族的精确复现

[crossover证据目录](../../tools/evidence/crossover/)保存原源码、输入、冻结报告和来源hash。[replay.py](../../tools/evidence/crossover/replay.py)只在隔离临时目录恢复历史相邻文件布局，不改原件；[本轮报告](../../tools/evidence/crossover/replay-results.json)记录四程序exit0及全部比较。原程序各执行一次，不再把Boss后续源码阅读说成第二次独立运行。

## 原检查器和完整数据的实际对应

| 程序 | 实际工作 | 冻结输出/证书 |
|---|---|---|
| verify_degree32.py | 七mask字面负载，16态/64偏离，三种零边界，14个高次数参数，固定权极限 | degree32_certificate、degree40_failure_certificate、fixed_weight_limit_certificate、fixed_degree_scan |
| verify_limit.py | 原/调谐辅助完整表，原m1..12和调谐m1..3扫描，m3完整有理证书，M13/M52统一界 | scaled_limits、finite_scans、retuned_m3_certificate、uniform_bounds |
| main_check.py | 不导入前者，显式策略/系数重建32/40/极限，另对源上界叶片直接幂到Bernstein变换 | main_check_results |
| check_independent.py --write | 独立形式变量成本和八证人、调谐辅助/有限m1..3、m≥20有理方向界 | independent_evidence |

前两程序默认完整重算并与原JSON对象比较，后两新输出也分别与原JSON全字段相等，合计十份冻结数学报告没有差异。需要的 `source_degree32/certificate.json` 是同仓另10源批的依赖，完整拷贝并hash核验，不在本18源内重复认领。

## 有限反例、失败和端点

degree32报告保存全部16态的当前四人成本、四个真实偏离成本、四比值、所选证人和严格9/5余量；最佳倍率约1.800488032325864，极小态 `0110,1001`。全部成本正，第七二次资源对保证每人始终使用一个正负载资源。零/零判为不阻塞、正/零判无穷、零/正比为0的三种规则另有断言，不靠实际输入没有零成本来省略模型边界。

degree40全态报告与固定权极限报告证明固定权继续升幂会失去9/5障碍。固定极限因子精确为 $5235403/2930833$，极小态 `0111,1000`，小于9/5；[失败对象](../反例/固定权重十四资源族升幂失去九五障碍--反例.md)给连续性到全部足够大整数次数的推论。扫描高次数为 $1,2,4,8,16,24,31,32,33,40,48,64,128,256$；其中参数1仍保留末对二次，**实际总次数是2，不能将它称作 $\mathcal G_1$ 实例**。

缩权原/调谐极限因子为 $65/34$、$100/49$；有限m3的完整16态证书含巨大精确有理数，最佳约2.0131229640941752，全部模板余量正。原扫描m1..12均严格9/5，调谐m1、m2失败、m3成功。统一有理界另覆盖原M13与调谐M52；独立报告改进调谐至M20。一般无限量词和三次根锥不是从这些有限扫描推出来的，见[常数族](../定理/十四资源缩权族的常数无均衡界--定理.md)和[模板定理](../定理/十四资源既定偏离模板的三次根阈值--定理.md)。

复现driver另完整检查四个全态文件均恰有16不同位串，并解析64行中880个精确有理字段；独立辅助和有限表及其有理余量也随整个JSON比较。小数只作显示，严格结论由 `Fraction` 与整数符号比较承担；使用 `sys.set_int_max_str_digits(0)` 是允许大整数十进制输出，不是数值容差。

## 实参数证书的逻辑角色

`main_check.py` 从89/50消元必要式独立构造1760个整数多项式，对输入证书的1768个有理叶片直接作幂基到Bernstein变换，核全部系数严格负，并核每个区间的叶片连续无缝覆盖。它不用作者递归分割程序或hash替代符号不等式，因此能支持[固定次数拓扑分离](../定理/十四资源非对称例与对称两列拓扑的三十二次分离--定理.md)的全实参数前提，而非把采样当普遍证明。[对称源上界正文](../定理/三十二次两攻击源包络上界--定理.md)负责全部参数消元和无遗漏域。

## 复现和接续

在结果仓库根运行：

```bash
python3 archives/weighted-congestion/tools/evidence/crossover/replay.py
```

可用 `--out 新路径` 保存新报告，拒绝覆盖既有文件。隔离布局只修复原源码迁移后 `Path(__file__)` 指向的相邻输入位置；原源码hash均保持不变。`provenance.json` 对14个本批源码/数据及1个依赖逐hash，另 `curation-source-manifest.json` 覆盖完整18个处置源版本。

该证据覆盖固定16态实例、指定扫描和整数叶片符号核验，不认证全部十四资源拓扑最优常数、全类增长率、外审或全球新颖性。旧OPEN与后续全状态线性下界的关系已在各正文明确，不由本有限程序替代其证明。
