# 对称两列与三十二次源证书的精确核验

## 对象与证据包

本资源对象支持[完整两列归约](../定理/对称两列拓扑的单项式两攻击归约--定理.md)及[三十二次源上界](../定理/三十二次两攻击源包络上界--定理.md)。证据包为[相对根目录](../../tools/evidence/symmetric-source/provenance.json)：10个冻结源版本全部逐SHA-256验证后原样保存于 `symmetric-source/original/<原路径>`，每个源的两个完整commit/path、ID、blob及内容hash均在该provenance中。两份源提交中这些文件内容相同，不能把它们称为独立实现。

原作者与审查者的三份程序不经改写地复制至独立执行目录；运行会覆盖的结果留在 `replay/`，不覆盖冻结原输出。新增[复现驱动](../../tools/evidence/symmetric-source/replay_suite.py)只做原件hash核对、隔离复制、普通Python执行、stdout/stderr留存及报告比较，不承担新的数学归约。运行命令，在结果仓库根：

```sh
python3 archives/weighted-congestion/tools/evidence/symmetric-source/replay_suite.py
```

使用正常断言模式；源32检查器及driver拒绝 `-O`。输出及逐字段差异在[本轮重放报告](../../tools/evidence/symmetric-source/replay-comparison.json)。所有数学计算使用标准库整数和 `fractions.Fraction`；随机输入只用于固定种子的有限字面状态套件，不用于符号证书证明。

## 作者字面状态与归约接口检查

[原程序](../../tools/evidence/symmetric-source/original/tests/audits/weighted_congestion/source_topology/verify.py)独立用资源成员集合生成负载和玩家成本，再与按 $m$ 压缩的全部重/轻偏离公式相等比较。输入为：

- $n=1,\ldots,6$、$w\in\{1/8,1/2,1,2,4\}$，各3个固定种子 `20261014` 的次数1至8非负有理多项式样本；
- $n=1,\ldots,4$、$w\in\{1/2,1,2\}$ 的零成本、零主资源、零边资源边界，共48例；
- $d=128,w=1/32,n=4,5,6$ 的显式强证书及其主多项式平移，共6例。

合计144个游戏输入。对每个字面纯状态，程序构造所有玩家的真实翻位，并在 $\alpha\in\{1,11/8,3/2,2,5/2\}$ 下核对margin；另对每个输入及每个 $\alpha$ 检查轻稳定区间、反射不交、左右平移恒等式及可用时的单项式转换。高倍率判定用精确式 $2\alpha(\alpha-1)\ge1$，不用浮点根。

| 冻结字段 | 实际重放值 | 准确解释 |
| --- | --- | --- |
| `cases` | 144 | 输入游戏数 |
| `literal_states` | 4948 | 枚举字面状态数 |
| `literal_deviations` | 28992 | 对这些状态的不同单人翻位数；每个还在多个α下比较 |
| `orbit_alpha_checks` | 720 | 144×5个游戏/倍率检查 |
| `high_factor_reductions` | 17 | 被有限输入触发的高倍率归约 |
| `translated_nonzero` | 0 | 此套件触发的高倍率无PNE实例没有非零左端平移 |
| `direct_polynomial_reductions` | 16 | 额外直接严格两测试的转换 |
| `exchanged_players` | 6 | 直接测试中的倒权并交换玩家分支 |

不能把 `translated_nonzero=0` 改写为该分支已由这些17次实例覆盖。程序确实在每个合法平移端点直接检查恒等式；下述独立套件另有刻意构造的非零平移实例。作者输出与冻结[原报告](../../tools/evidence/symmetric-source/original/evidence/runs/weighted_congestion/source_topology/results.json)逐字段完全一致。

## 独立内部审查及实现

[独立审查](../../tools/evidence/symmetric-source/original/research/reviews/weighted_congestion/source_topology_review/review.md)记录：先读模型并重建全状态瓶颈，再读候选接口和完整证明；这是内部数学审查，非外审或新颖性认证。独有修订内容为：v2的 $\phi$ 界实际覆盖全部 $w>0$；v3在 $\rho$ 界下保留并转换 $N=1$ 右支；两种不同的倒权操作中只有后续源正规化交换 $F,G$。对应完整论证、常数费用/零费用/单位权/次数零、整数中心及弱稳定边界已并入定理正文。

[审查程序](../../tools/evidence/symmetric-source/original/tests/audits/weighted_congestion/source_topology_review/check_review.py)不用作者的多项式数组/状态oracle，而用次数到系数的字典表示，单独构造动作资源、逐偏离更新负载。240个种子 `314159` 样本取次数0至6、$n=1,\ldots,4$ 和权 $1/100,1/2,1,3/2,10$；另25个退化输入及4个 $d=400$ 显式输入，合计269个游戏输入。4个强输入分别测试普通左证书、混合主边多项式的弦替换和常数删除、$\alpha=3/2$ 时 $b=1$ 的非零平移、以及低于 $\phi$ 的右侧单轻玩家转换。

每个输入对 $\alpha\in\{7/5,3/2,5/3,2,3\}$ 执行，因此原报告的 `games=1345` 是 **269×5个输入/倍率组合**，不是1345个互异游戏。`literal_states=20400` 也按这五个倍率重复计数。全部12次无PNE组合中10次左支、2次右支；两类都真正到达合法源测试。与[冻结审查输出](../../tools/evidence/symmetric-source/original/evidence/runs/weighted_congestion/source_topology_review/review_results.json)逐字段完全一致。该套件不检验精确无理端点 $\rho$；端点成立来自定理中的严格整数论证。

两套字面状态检查仅核验列明的有限输入、分支和恒等式；一般实域定理来自完整分析证明。没有用随机没有找到反例替代一般证明。

## 源32全区间证书核验

[原检查器](../../tools/evidence/symmetric-source/original/tests/audits/weighted_congestion/source_degree32/verify.py)首先核对解析有限域接口 $(56/55)^{32}<89/50$，独立字面代入消元式及Bernstein变换，再逐个重建全部 $1\le n\le55,1\le k\le32$ 的整数多项式。它读取[完整证书](../../tools/evidence/symmetric-source/original/evidence/certificates/weighted_congestion/source_degree32/certificate.json)全部1760记录、1768叶，重新算所有Bernstein整数系数，逐项判负、核对最大值和向量hash，并递归核对完整无遗漏的二分叶覆盖。最大二分深度2，需二分的5个 $(n,k)$ 与全部叶路径列在源上界正文，亦从输入重提取至本轮报告。

这是证书完整数据的实际逐项算术审计，不是只读JSON摘要；在解析域约化之后，它证明整个实域，而非有限网格。检查器生成器拒绝覆盖既存证书，本轮只验证既存数据，不调用生成器。它不能独自证明未编码的解析消元；该部分已在正式定理中自足重建。

重放数学字段为 `VERIFIED`、`F_32 <= 89/50`、1760多项式、1768叶、最大深度2及精确整数/Fraction，与冻结[源32报告](../../tools/evidence/symmetric-source/original/evidence/runs/weighted_congestion/source_degree32/verification.json)全部一致。耗时是本机重跑值，**不要求等于历史1888ms**。历史报告额外的日期、Python版本、原工作室命令、`PROOF.md` hash和当时仓库map检查计数仅作为历史环境证据原样保留；当前迁移后的中文正文和路径不同，不能声称该旧hash或309节点/357边等计数是本结果树的新验证。

另一个历史实现 `tests/audits/weighted_congestion/crossover/main_check.py` 直接在每个叶片区间计算Bernstein系数，不导入作者包、不用中点递推，其独立1768叶检查和实际迁移路径由[非对称分离对象](../定理/十四资源非对称例与对称两列拓扑的三十二次分离--定理.md)负责。本对象不重复登记该程序来源；没有因审查自报而冒称本包独立运行过它。

## 比较、关系与局限

本包保留两条不同证据关系：字面状态oracle支持两列压缩和转换接口的有限实现可信性；完整符号证书与解析约化联合证明源上界。它们不能互相替代。源32加一般两列归约产生拓扑上界，再与独立非对称实例比较产生分离；这是有共同次数和模型前提的多源推导，不能把源32 alone画成全类存在界。

已有[普遍阈值闭端点](../定理/普遍近似均衡阈值的闭端点--定理.md)说明有限实例阈值采用弱不等式且达到；本包的严格反证及sup比较不用假设全类sup被取得。已比较[潜在用户支持势](../定理/资源潜在用户支持的总成本势--定理.md)，它给固定支持子类存在界，和这里随 $n$ 变化的对称拓扑不同。已全文比较后续全状态线性下界：其每态出口包含全部类前沿及非法位串修复，不由环或本包有限套件推出；旧全文“全类OPEN”因此不再作为当前状态。

本轮没有记录外部同行评审、最佳常数或全球新颖性。实际已通过的源证书不等于新的d泛化证书；拓扑归约也不涵盖异质轻权或不对称费用。后续可复用driver重验文件身份和完整算术，也可在改变参数后新建证书，须保留独立的解析域约化及全部叶覆盖义务。
