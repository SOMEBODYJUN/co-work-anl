# 有序尾部冻结的作者全阶段核验

本对象保存[有序权组尾部冻结定理](../定理/有序权组尾部冻结--定理.md)的作者实现及完整冻结输入。程序已全文读取，报告全部43游戏、15密集参数、32划分参数和元数据已逐项阅读，并与独立实现、参数锐式和历史审查比较。本轮原样运行一次，完整JSON及全部字节与冻结原报告一致。

证据为[原样程序](../../tools/evidence/weight-classes/tail-author/verify_ordered_tail_freezing.py)、[冻结报告](../../tools/evidence/weight-classes/tail-author/frozen-report.json)、[本次输出](../../tools/evidence/weight-classes/tail-author/replay-report.json)、[运行及完整比较](../../tools/evidence/weight-classes/tail-author/replay-manifest.json)、[来源清单](../../tools/evidence/weight-classes/tail-author/provenance.json)。它保持作者实现身份，不因复跑变成独立发现或新盲审。与使用单独原始Shapley函数的独立版之区别见[既有核验对象](权类别与局部权带的精确核验--计算.md)。

## 输入合同及阶段参数

`audit(weights, strategies, coeffs, groups)`接收正有理权、每人非空有限资源子集策略族、非负有理多项式系数（按次数递增）和玩家的有序非空组划分。原函数主要检查数学不等式，没有为任意外来输入重新验证全部这些合法性条件；本批固定输入满足它们，命令行也不提供任意游戏文件的输入接口。

程序令d=max_e(len(coeffs[e])−1)，即由保留的系数向量长度取共同次数上界；即使最高项为0也不自动压缩这个d。资源潜在用户U_e由其是否出现于某个合法策略定义，而不是由某个当前状态定义。对当前组B_j中U_{e,j}=U_e∩B_j非空的资源，固定

\[
 a_{e,j}=\min_{i\in U_{e,j}}w_i,\quad
 R_{e,j}=\frac{\max_{i\in U_{e,j}}w_i}{a_{e,j}},\quad
 L_{e,j}=\sum_{i\in U_e\cap\bigcup_{k>j}B_k}w_i,
 \quad\beta_{e,j}=(1+L_{e,j}/a_{e,j})^d.
\]

A=max Rβ；若没有任何潜在使用，则设A=1。这些参数与当前实际组用户、此前选择及后来真实负载分开，不在偏离时重新选a、R、L。

玩家费用是所选资源延迟之和，不乘其权。`cost(state,i,choice)`从其他玩家实际使用的资源重新求负载，再加入i自己的权；值为None的尚未冻结者被忽略。它排除i的旧使用，所以即使state[i]仍是旧策略，也能准确求任意choice的偏离成本。

## 作者的势差份额接口

设阶段j此前实际冻结背景为h_e，当前组在资源e上的用户集合S，m=|S|。`stage_phi`计算

\[
 \Phi_j(s)=\sum_e\frac{\beta_{e,j}}{a_{e,j}}
 \sum_{\varnothing\ne T\subseteq S}
 \frac{(|T|-1)!(m-|T|)!}{m!}\,
 w(T)c_e(h_e+w(T)).
 \tag{1}
\]

这里先平移延迟，再用w(T)乘它；没有把早组总成本变化加到份额总成本中。空S不贡献，零费用和空策略不需要除成本。

作者的`stage_marginal(state,j,i)`定义为

\[
 D_i(s)=\Phi_j(s)-\Phi_j(s_i=\varnothing,s_{-i}).
 \tag{2}
\]

第二项只是势的代数评价；∅即使不是i的合法策略也可用于定义边际，不会把它放进阶段最小化的合法候选集合。同一玩家两次合法选择的式(2)具有相同的删除后基准，因此D_i(s′)−D_i(s)=Φ_j(s′)−Φ_j(s)。

一般数学上式(2)由标准子集势恒等式等于缩放Shapley份额，但此实现没有另写原始Shapley概率求和来对照它；阶段份额直接来自同一个势。独立版的`phi_direct`另行计算原始份额，并独立实现`potential`，提供不同的实现交叉检查。两种代码界面不应说成相同独立性；作者仍用另写的真实成本函数检查最终费用及比较链。

## 全阶段、全部平局和最终偏离

程序从全None前缀开始。每个阶段、每个已有冻结前缀，枚举当前组合法策略族的完整笛卡尔积，计算式(1)，保留**全部**并列全局最小点，扩展下一阶段。没有随机选一个最小点，没有重新打开已冻结组。

所有阶段完成后，对每个最终profile和每名玩家，先把后组置None恢复该玩家所属阶段的状态，再对它的每个合法策略验证

\[
 C_i(s^{\rm final})\le D_i(s^j)
 \le D_i(t_i,s^j_{-i})
 \le A C_i^j(t_i,s^j_{-i})
 \le A C_i(t_i,s^{\rm final}_{-i}).
 \tag{3}
\]

源码最后一环直接检查C_i^j≤C_i^{final偏离}，并另检查首末最终均衡不等式；A≥1由参数定义保证乘上A合法。它还分别检查旧费用被旧边际控制、阶段最小点不增玩家边际、以及新边际的上包络。后组玩家在最终Nash偏离中维持自己的最终策略，不对偏离重新反应。

`stage_candidates`数的是每个前缀下实际评估的当前组策略组合总数；`stage_minima`数的是各阶段、各前缀保留的最小候选总数，包括末阶段；`final_profiles`是终结前缀列表长度。程序不另设去重集合，本批各策略族无重复且组为固定划分，因此不同分支的先前选择会保留到最终profile，不能混同独立版显式去重的实现步骤。

所有43个`cases`已逐条实读，原报告每条保存players、degree、alpha、完整weights/strategies/coefficients/groups，以及四项运行计数。没有只检查seed或总计。例39（报告从0编号）费用为(0,0,1/3)，89阶段候选、28阶段最小、16最终profile、224合法策略比较；这实质覆盖大量平局分支。例3是常数费用游戏但参数A=2，说明参数保证可以宽松，不能把大A当作实际无精确均衡的证据。

全部43例合计：511候选、164阶段最小、64最终profile、664合法策略比较。每个玩家的合法策略循环**包括原策略**，也包括只有一个策略玩家的自比较。由完整报告各例的players×final_profiles求和得到305个自策略比较，其余359次真正改变策略；这是已有记录计数的精确解释，不是额外一次运行。报告没有列出64个最终策略组合或664条链的数值，不能称为完整逐终态静态证书。

## 两密集等权群的有限参数比较

15个记录取d∈{2,3,4,8,16}，每个d取n∈{d,d²,2d²}，先组n人各重M=dn，后组n人各重1。程序仅计算这些群参数，没有另构造15个完整策略游戏或运行15次冻结树。

逐项精确检查

\[
 \beta=(1+n/M)^d=((d+1)/d)^d<11/4,
 \qquad\frac{(M+n)^d}{M^d}=\beta.
 \tag{4}
\]

它还取总潜在支持2n、最小个体份额q=1/(nM+n)，计算

\[
 \frac1{1-(1-q)^d}\ge\frac1{dq}.
 \tag{5}
\]

报告完整记录每个d、n、M、β、2n、q和高次倍率，全部大分数已读取且属于字节比较范围。**程序检查的是11/4，不是3，也不是e。**任意d≥2时β<e来自一般解析证明，不能把本数值检查冒充对e的精确比较。

式(5)作为旧高次份额工具的比较，须对应全体玩家潜在可用、且费用为非零x^d的资源。作者这部分只核对参数公式，没有对一个任意零费游戏认证该倍率适用；一般正文已有此必要条件和早期修正。该数值比较不证明游戏不存在更好PNE，也不证明旧工具实际输出很差。

## 带标号有序划分的参数锐式核验

`ordered_partitions(n)`递归加入最大标号n−1：或放入已有某组，或作为单元素组插入某个组间位置。删除最大标号可唯一恢复父划分及该选择，因此它保留全部玩家标号、每个有序非空划分一次；没有按等权轻玩家置换取商。内部组元素按插入标号自然递增，不额外把组内排列当不同划分。

对一重H及K个单位轻玩家，计算每个有序划分的

\[
 A(\mathcal B)=\max_j\frac{b_j}{a_j}(1+L_j/a_j)^d
\]

并比较[参数锐式](../障碍/潜在尾部参数的锐界--障碍.md)

\[
 \min_{\mathcal B}A(\mathcal B)=\min\{H,(1+K/H)^d\}.
 \tag{6}
\]

输入H∈{1,3/2,2}、K∈sorted({1,2,⌈H²⌉})、d∈{1,2,3,5}。H=1时只有K=1、2，另外两H各有三种K；因此共有32参数点，不是36，也没有d=0端点。

| H | K列表 | 每个K的带标号划分数 | 四个次数合计检查 |
|---|---|---|---:|
| 1 | 1、2 | 3、13 | 64 |
| 3/2 | 1、2、3 | 3、13、75 | 364 |
| 2 | 1、2、4 | 3、13、541 | 2228 |
| 合计 | | | 2656 |

当K=⌈H²⌉还检查最小值H。全部32条原记录逐项读取；(H,K,d)=(2,1,1)最小值是3/2而非H，所以不能把所有记录都描述成H。其余31点本列表恰得H，但任意H、K、d的一般结论由三分情况证明承担。

此处32点/2656带标号计算，与独立全流程64点/10112带标号计算、另一独立程序12点/8661轻玩家置换商组型计算是三份不同证据。它们均是潜在保证参数的核验，不构成无PNE反例；对应允许空策略的锐式游戏始终有全空精确PNE。
