# 资源可分证书的精确核验

## 保存资源与精确运行

原始脚本、规范实际输入、完整历史输出和两份内部审查保存在[separable-certificates/original](../../tools/evidence/separable-certificates/original/)；[provenance.json](../../tools/evidence/separable-certificates/provenance.json)列完整冻结提交、源ID、字节指纹与保存路径。原源的两个冻结定位字节相同，在inventory合为一个来源版本；本轮通过clean show读取实际blob，并核保存资源的SHA256，不增加重复分母。

在该original目录运行：

```sh
python3 tests/audits/weighted_congestion/marginal_potentials/verify_multipliers.py --output ../replay-multipliers.json
python3 tests/audits/weighted_congestion/ordinal_potentials/verify_finite_bundle_bridge.py
python3 tests/audits/weighted_congestion/template_certificates/verify_template_certificates.py
```

第一程序d=2,4,8,16分别排除6/5,2,4,10，层数20,24,27,68，Q=8,16,32,128。有限总玩家数十进制位数分别19,29,41,143；程序用精确整数幂和递推与Fraction检查严格gap，不展开人数或状态。完整数值、gap位长和指纹见[新运行](../../tools/evidence/separable-certificates/replay-multipliers.json)。

第二程序通过298项：180项直接有限幂和与作者递推函数的交叉比较及单调性；54项固定复制整数的端点/窄gap/小η/整点检查；64项两玩家三资源非匿名F_e的平均恒等式。它import作者finite_ratio作被比较器，其他局部公式独写，不能说是第二独立完整多尺度证明实现。stdout由provenance保存，原脚本完整可跑。

第三程序逐资源重建真实成本，38项成本压缩、80项偏离margin、101个目标×状态Hamming唯一性检查通过。枚举81个{-1,0,1}二阶矩阵及固定seed241015的72个有理小矩阵，精确顶点枚举核出52个primal和101个dual；无容差/不采信LP状态。全部新JSON与完整冻结输出逐字段相同，包括Python版本、源码/input hash和所有selector/margin，见[新运行](../../tools/evidence/separable-certificates/replay-template.json)。

## 程序中除最小点引理外的独有功能

完整保留有限动作的资源签名压缩与严格替代实现。将全部动作位置组成有限集P，对每非空签名S⊆P及次数0≤k≤d设列(S,k)。同签名资源同次数非负系数相加为a_(S,k)。状态s下玩家i的基函数为

    b_(S,k)(s,i)=1[(i,s_i)∈S]·(Σ_(j:(j,s_j)∈S)w_j)^k.

逐项展开给C_i(s)=Σ a_(S,k)b_(S,k)(s,i)；未使用资源的空签名可删，因为在所有合法动作成本均为零。给每状态选一个单人偏离σ(s)=(i,t_i)，对应行B_s=b(s,i)−αb(t_i,s_−i,i)。实现直接核Ba等于全部真实margin，并核严格正primal与归一化λ≥0、λᵀB≤0的dual相斥。一般有限维替代理论不由有限枚举证明，本资源只保存其实现及实际案例。

真实输入另含三玩家权(16,2,5)、六资源混合一次/二次费用的固定53/50无PNE实例，全部8个状态的selector/margin在输入与完整输出保留。它是固定次数有限例，不能推出增长阶；非空主模型仍允许输入中另一组的空策略、零费、常数费、未用资源以及单动作异质策略族。零资源字样在旧审查意指零费用资源，本输入确有至少一资源，不声称测试了MODEL之外的E=∅。

## 审查范围与关系线索

多尺度与同游戏序势审查曾先重构关键瓶颈再攻击冻结证明；最小点审查对旧障碍是informed核查，新Hamming等价则为独立提出并重算。历史审查稿hash有其时间和范围，不能把历史whole-file hash说成当前整合稿hash。实际保存资源hash以provenance为准。全部均属内部审查；未外审、未认证优先权。

本轮不把exact_audit中有限动作替代程序擅自升格为已清洗的通用对偶正文，其另有来源和owner。这里保存了程序所有函数、真实输入和完整输出，供相关理论批次接续。关系仅表为实现/有限检查，不能从这些计数导出全类数学结论。
