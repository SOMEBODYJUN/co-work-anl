# 双排序混合势的作者有理核验

本资源保存[两权类别双排序混合势](../定理/两权类别双排序混合势--定理.md)的作者实现及冻结结果。原程序与2373字节报告已经全文读取，和原定理、[独立两权审计](权类别与局部权带的精确核验--计算.md)及[历史审查范围](../审查/权类别排序势与共占高度的审查范围--审查.md)实际比较。本轮原样执行一次，输出文件、完整stdout与冻结原报告全部字节相同。

证据为[源码](../../tools/evidence/weight-classes/order-blend-author/verify_order_blend.py)、[冻结原报告](../../tools/evidence/weight-classes/order-blend-author/frozen-report.json)、[本次新报告](../../tools/evidence/weight-classes/order-blend-author/replay-report.json)、[实际运行及完整对照](../../tools/evidence/weight-classes/order-blend-author/replay-manifest.json)、[来源清单](../../tools/evidence/weight-classes/order-blend-author/provenance.json)。作者实现身份保持不变；复跑不等于另一套独立实现或新的盲审。

## 单资源真值判据

两类权a≥b>0，旧人数m、n，费用c(x)=x^p。`paths`从有限求和直接计算

\[
 D=a\sum_{j=1}^m(ja)^p+b\sum_{j=1}^n(ma+jb)^p,
 \qquad
 U=b\sum_{j=1}^n(jb)^p+a\sum_{j=1}^m(nb+ja)^p.
 \tag{1}
\]

对每个输入分别新增一名重类或轻类用户，重算新D、U及新总负载Y，检查

\[
 0\le\Delta_aD\le aY^p,\quad\Delta_aU=aY^p,
 \qquad
 \Delta_bD=bY^p,\quad bY^p\le\Delta_bU\le\max(1,p)bY^p.
 \tag{2}
\]

常数单项式p=0也包括，使用max(1,p)以覆盖这个端点。由于插入者权正，Y>0，归一化边际除以wY^p时分母正；不把这项网格中的除法推广到零费用资源。

每个插入再对λ∈{1/10,1/3,1,5}取F=D+λU、d=max(1,p)，用精确有理数计算

\[
 \alpha(\lambda)=\max\left\{\frac{1+\lambda}{\lambda},
 \frac{1+d\lambda}{1+\lambda}\right\},
 \quad h_a=\lambda a,\quad h_b=(1+\lambda)b,
\]

并检查h_iY^p≤Δ_iF≤α(λ)h_iY^p。没有在这些断言中使用近似代数根。

六对权为(1,1)、(3/2,1)、(2,1)、(13/2,2/3)、(1000,1)、(1,1/1000)；p=0至12，m、n分别0至6。每个输入两种插入，共6×13×7²×2=7644个单项式插入检查；四个λ给30576个混合检查。旧人数0覆盖某类缺席，新增后被插入类可有7人。等权对(1,1)保留明确的重/轻类别计数及插入标志，不能临时按权相等把同一次边际的类别切换。

报告保存了上述全部网格定义，并记录两个有限观察极值：

| 被记录的量 | 精确值 |
|---|---|
| 降序重权插入Δ_aD/(aY^p)的最小值 | 321221696678340759981 / 1779197418239532716881 |
| 升序轻权插入Δ_bU/(bY^p)的最大值 | 12066220495792924792495220066012001001 / 1012066220495792924792495220066012001 |

这只是给定网格上的最小／最大值，报告没有给达到它们的输入索引。它们不是所有实权和所有人数下的锐常数，不能据此收紧一般定理中的0或d包络。

## 二十四个完整游戏枚举

`game_audit`创建单个`Random(7102026)`，依次处理(d,A)=(3,2)、(7,3)、(13,4)，每组八个游戏。程序用整数恒等式A²−A=d−1先认证这些根，再取精确λ=1/(A−1)。这里的λ依次1、1/2、1/3，不应说成都来自上一节四个λ的网格。

每个游戏四名玩家、四个资源，权为(a,b,a,b)。每组内case编号偶数用(a,b)=(7,1)，奇数用(5/3,2/7)。每名玩家的策略族由∅、{0,1}、{1,2}加一个随机资源子集构成，再按首次出现顺序去重，所以各有3或4个合法策略。保留资源1的偏离、空策略、不可比资源集及可能的第四资源使用均进入实际状态枚举。

资源3恒为零多项式。资源0、1、2的常数项和一次项分别从0、1、2取，d次项为分子、分母各1至3的正有理数，其他项为0。随机流连续生成所有策略和系数；没有每个游戏重置seed，也没有输入所有非负多项式。

程序枚举每个策略族的完整乘积，缓存每个状态的真实成本和势。成本直接从真实资源负载计算，势由式(1)按资源每个系数累加D+λU。对每个玩家i和每个合法策略，包括原策略，检查

\[
 \Phi(s')-\Phi(s)\le h_i[A C_i(s')-C_i(s)].
 \tag{3}
\]

若C_i(s)>AC_i(s′)，另计一次严格α改善并检查Φ(s′)<Φ(s)。在每个状态扫描全部单人邻居，判定是否全部不降势；是则检查该状态满足全部A-PNE弱约束。保留资源的较强负校正项没有单独写成程序判据，但完整新旧状态及费用保留该资源，式(3)是一般推导的弱化形式。

冻结结果为：

| 项目 | 数量与解释 |
|---|---|
| 游戏 | 24，即三个(d,A)各八例 |
| 状态 | 4868，各游戏策略乘积总和 |
| 合法策略比较 | 74612，包括原策略 |
| 严格α改善 | 18125，每次均另断言严格降势 |
| 单边局部势最小状态 | 26，逐个检查A-PNE；未另统计全局最小点 |

四名玩家在每个状态各有一个自策略，因此自比较为4×4868=19472，真正改变策略的比较为55140。不能把74612全部称为非平凡移动；独立版18888项不含自策略，计数和输入域不同。

### 存在性的实际难度边界

所有24个游戏中，每名玩家都可以选∅。全空状态每人费用0，而所有合法偏离费用非负，所以它是**精确PNE**。这是输入的直接数学性质，不依赖本程序查到的26个局部最小点。

因此这些游戏是完整状态、真实偏离与势差实现的测试，不能被称为只有近似均衡、或对存在倍率构成困难的实例。18125条严格改善仍是对任意枚举状态的真实检查，但不能从大量检查数推断这些游戏给出一般近似保证的锐性。程序也未枚举一个所有玩家都没有空策略的游戏族。

## Decimal显示与真正认证的界线

`run`在局部Decimal上下文把精度设为60，对d∈{2,3,4,10,100,1000}计算

\[
 A_d=(1+\sqrt{4d-3})/2,\quad
 \lambda_d=1/(A_d-1),\quad
 A_d^2-A_d-(d-1),
\]

仅把十进制字符串写到`optima_display_only`。这些值没有进入任何成本、势或边际断言；源码没有检查残差大小、符号、区间包含或精确根方程。

全部六条显示记录已全文读取。原残差依次为`0E-59`、`0`、`-2E-59`、`2E-59`、`-6E-58`、`0E-57`；完整60位A和λ字符串在原／新报告中逐字保全。`0E-59`这样的显示结果不证明所存十进制数就是精确代数根，更不证明它位于根的哪一侧。

这与[独立一般k三角审计](三角类别势的独立有限核验--计算.md)的34374项浮点诊断不同：后者实际执行带容差assert，本程序的Decimal部分连这种不等式断言都没有。一般最优包络参数由定理解析求解两包络相交给出；“最优”仅指该包络族的λ平衡，不是原游戏真实最优近似率。三个游戏根(2,3,4)则已有独立的整数恒等式认证，不能和六条显示记录混为一谈。
