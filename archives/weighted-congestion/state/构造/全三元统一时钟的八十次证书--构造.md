# 全三元统一时钟的八十次证书

## 全部输入、动作和有限结论

成本为所用资源费用之和，不乘玩家权；单人偏离后按真实新用户集合计费。固定四人权\((1,1/2,1/4,1/8)\)、\(\alpha=21/20\)，每人恰有动作0和1。基体G由下表四对互补资源组成，每侧费用\(zx^3\)。签名+表示动作s使用侧s，−表示使用侧\(1-s\)，0表示不参与。

| 签名 | z |
| --- | --- |
| (0,0,+,+) | 1593928/421875 |
| (0,+,+,0) | 452978/421875 |
| (+,−,−,−) | 23816/5859375 |
| (+,+,−,−) | 855968/17578125 |

取全部三个三元\(T_{012},T_{013},T_{023}\)，每个T新建两资源，与旧资源及其他对互异。在T的局部顺序按模式\(p=(0,1,0)\)规定动作\(s_i\)使用侧\(s_i\mathbin{\mathrm{xor}}p_i\)，不参与者不使用该对。两侧同费，且**全部T使用同一幅度与次数**：

\[
c_T(x)=M(x/W_T)^{80},\qquad
M=2\alpha B=\frac{396506327}{234375000},
\]

\[
(W_{012},W_{013},W_{023})=(7/4,13/8,11/8),\qquad
B=\max_{s,i}C_i^G(s)=\frac{56643761}{70312500}.
\]

各玩家的两个动作分别合并全部规定的旧、新资源。动作非空且互异，不能另外加空动作或所有资源子集。

**结论。** 这个输出次数恰80的有限游戏没有21/20-PNE；原八条同序双轮边仍严格21/20改善，其余八态由“最早与anchor动作不同的玩家翻回anchor动作”给严格出口。此游戏同时不满足原编译器的统一低漏充分预算(U)。结论是一个固定实例；不声称80是实际最小可行次数，不给一般常数倍次数编译器，也不提供倍率随次数增长的族。

## 全16态的真实有理证书

对指定状态s与移动者r，写\(m_G(s,r)=C_r^G(s)-\alpha C_r^G(s^{\oplus r})\)。对T中r当前所用侧与翻位后所用侧，其真实负载分别记为\(l_T(s,r)\)和\(l_T(s^{\oplus r},r)\)，两者都包含该状态中r自身的权重。总margin精确为

\[
m(s,r)=m_G(s,r)+M\sum_{T\ni r}
\left[\left(\frac{l_T(s,r)}{W_T}\right)^{80}
-\alpha\left(\frac{l_T(s^{\oplus r},r)}{W_T}\right)^{80}\right].\tag{1}
\]

费用相同的互补资源对保证\(m(s,r)=m(1-s,r)\)。因此下列八态及其逐位互补恰穷尽全部16态。区间是精确有理外包；所有下端点严格大于1/500。

| s | 指定r | \(m(s,r)\)的有理区间 |
| --- | --- | --- |
| 0000 | 0 | [7/2000,9/2500) |
| 0001 | 3 | [73/10000,37/5000) |
| 0010 | 2 | [13461/10000,6731/5000) |
| 0011 | 2 | [81/10000,41/5000) |
| 0100 | 1 | [2913/1000,29131/10000) |
| 0101 | 1 | [11699/10000,117/100) |
| 0110 | 1 | [2203/1250,141/80) |
| 0111 | 1 | [101/10000,51/5000) |

把上面全部权、基体系数、M、W与实际用户集合代入(1)，即可用正分母通分核验每个区间，不需要浮点容差。完整精确分数及64组当前/真实翻位成本由对应冻结输出保留。

原环为

\[
0000\to1000\to1100\to1110\to1111\to0111\to0011\to0001\to0000.
\]

表中0000、0001、0011、0111及其互补就是这八个环态，指定出口与原环一致。其他表行与互补为环外八态，指定玩家为最早异位者。这些出口都属于原有两个合法动作中的另一动作，始终只翻一人。每个状态至少一个严格正α-margin，才推出无α-PNE；这里确实覆盖全部状态，未把单环当作非存在证明。

## 统一预算91与实际可行80的区别

同一基体的八条环边最小真实余量为

\[
\eta=\frac{49676111}{6750000000},\quad L=3,\quad\delta=12/13.
\]

原全三元统一编译器的保守充分条件是

\[
\delta^D\le\frac\eta{4\alpha^2BL},\qquad
\frac\eta{4\alpha^2BL}=\frac{1241902775}{1798552699272}.\tag{U}
\]

有理整数幂与正分母交叉相乘给出

\[
(12/13)^{80}>\frac{1241902775}{1798552699272},
\]

\[
(12/13)^{91}\le\frac{1241902775}{1798552699272}
<(12/13)^{90}.
\]

因为\(0<12/13<1\)，91是满足(U)的最小非负整数次数。它只是该充分预算的门槛。全状态表已经证明D=80可行，所以(U)对**原全部三元、统一M、统一次数、同费010/101架构本身**也不是必要条件；逃离(U)不要求先删T013或改变两侧费用。不能由此说实际最小次数等于80，亦不能说(U)的普适条件障碍被反驳。

相同基体的稀疏非统一43次证书使用别的clock选择，次数更小；其作用与本对象不同。这里专门排除“只有先放宽原全统一架构才能逃离(U)”的误读。[同费三元的degree≤3保边障碍](../障碍/同费锚定三元时钟的三次保边障碍--障碍.md)仍成立，80也没有越过那个障碍的量词。
