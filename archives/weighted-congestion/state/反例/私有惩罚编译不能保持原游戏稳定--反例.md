# 私有惩罚编译不能保持原游戏稳定

对每个实数 $K>1$，原游戏只有一名权1玩家，两个动作分别用互异常数资源a、b，费用1和K。其唯一精确PNE选择a；选择b的真实改善比为K。

新建该玩家私有资源p，常数费用K，只加入原动作a，形成新动作 $\{a,p\}$ 和 $\{b\}$。新游戏两动作费用分别为 $1+K$ 与K，所以唯一精确PNE选择b。但同一原动作b在原游戏费用K，偏离a费用1，因此原游戏稳定因子恰为K。任意给定有限近似容忍都可由更大K违反。

所有费用非负常数、权正、动作有限非空，属于次数0的标准模型，没有费用比零或策略含糊。它只反驳“向动作加惩罚求新均衡，就自动得到原游戏相同稳定解”；不反驳具有完整原偏离比较合同的固定lift，也不反驳为研究新游戏而明确增加资源的构造。

原独立程序在K100直接核新唯一PNE及原遗憾100，本轮输出与冻结记录逐字段一致；任意实K的量词由上述两费用比较直接证明，详见[审计对象](../审查/有限稳定决策的实现审计与版本范围--审查.md)。因此调用原游戏修复/前沿算法时，应检测原本存在的资源和其支配合同；若实际改变游戏，必须另证明原游戏输出的真实偏离保证。
