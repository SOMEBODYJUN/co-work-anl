## 2. 所审模型与逐项数学结论

模型是有限标准加权拥塞游戏：资源无关的正玩家权，非空有限资源子集菜单，允许空策略；费用为非负系数次数至多整数 $d$ 的多项式；玩家成本为资源费用之和。真实偏离重算包括自身的新负载，$\alpha$-PNE 使用全部弱不等式，严格改善使用相反的严格号。单策略固定玩家可吸收为非负背景。

潜在降权图以**可动玩家身份**为顶点，有异权潜在共资源就按严格降权定向；高度 $h$ 计路径顶点，满足 $h\le k$，其中 $k$ 是全局可动权值数。下表给实际核对理由和保留范围，而非只列审查结论。

| 主题 | 实际核对的推导 | 必须保留的边界 |
| --- | --- | --- |
| 根的唯一性 | $f_h(x)=\sum_{j<h}((d-1)/x)^j-x$ 严格递减；$f_h(1)\ge0,f_h(d)<0$ | $d\ge2,h\ge1$；有限高度的根严格小于 $d$ |
| 精确反演 | $t=(d-1)/\alpha$ 时，$(t-1)f_h(\alpha)=t^h-(d-\alpha)$ | $t>1$ 与 $t<1$ 分支的不等式方向先相反，取对数后都给 $h>\mathcal H_d(\alpha)$ |
| 连续与等号 | $\alpha=d-1$ 直接用 $f_h=h-(d-1)$；连续值为 $d-1$ | 不除零；无 $\alpha$-PNE 的整数高度至少 $\lfloor\mathcal H_d(\alpha)\rfloor+1$，等号不能混入坏侧 |
| 最小边界 | $d=2,\alpha=1$ 走连续分支；$\alpha\ge d$ 已有有限高度保证 | 不能声称这一域存在无 $\alpha$-PNE 游戏 |
| 共享玩家秩 | 潜在同资源 $w_i>w_j$ 迫 $r_i<r_j$，同资源同层必等权 | 不能每资源另排序后直接相加，也不能把层当全局代表权 |
| 三角插入 | 排列 $(h,\ldots,b+1,1,\ldots,b)$ 在 $b<r,b=r,b>r$ 分别给全重、空、全轻后缀 | 三个边际区间方向固定；等权插入可置本层末尾 |
| 全部偏离 | 删除旧端点取下界、新增新端点取上界，保留成本非负 | 空策略、零费、偏离到零费用均有效；无成本除法 |
| 有限下降 | 同一资源可加势在全部严格倍率改善下降 | 不等于多项式时间的最佳偏离或均衡搜索 |

其中

\[
 \mathcal H_d(\alpha)=
 \begin{cases}
 \log(d-\alpha)/\log((d-1)/\alpha),&1\le\alpha<d,\ \alpha\ne d-1,\\
 d-1,&\alpha=d-1.
 \end{cases}
\]

完整一般证明已在[精确反演与过渡](../定理/高度势的精确反演与线性过渡--定理.md)保存；上表不把闭词长链、游戏无均衡和标量根比较合并成一个结论。

## 3. 独有交付接口：给定目标的有理证书

原审查附加推论不要求先求 $A_{d,h}$。给相容共享玩家秩和目标 $\alpha\ge1$，设

\[
 t=(d-1)/\alpha,\qquad T=\sum_{j=0}^{h-1}t^j.
\]

若 $T\le\alpha$，以 $\lambda_b=t^{b-1}/T$ 归一化，令
$S_r=\sum_{b\le r}\lambda_b$。三角边际为
$S_rw\ell(Y)$ 至 $[1+(d-1)S_{r-1}]w\ell(Y)$，而有限和恒等式给

\[
 \alpha S_r-[1+(d-1)S_{r-1}]
 =(\alpha-T)/T\ge0.
\]

所以共同玩家乘子 $q_i=w_iS_{r_i}$ 直接给目标倍率的势。这一证明没有 $t-1$ 分母，等号、$t=1$、$h=1$ 均覆盖；$\alpha\ge d$ 时所有有限 $h$ 自动通过。整数 $d$、有理 $\alpha$ 使全部混合系数为有理数。完整可复用输出和失败含义见[给定倍率的有理三角高度证书](../定理/给定倍率的有理三角高度证书--定理.md)。

**与先有工作的关系。** 已完成的三角重构审查在严格有理上根 $Z<\beta$ 下已使用同一归一化，并给精确余量 $\beta/Z-1$；独立三角程序也对有限类型参数检查 $Z\le a$。本来源不是重新发明此代数。其独有整理是直接以目标 $\alpha$ 为输入，明确任意相容玩家秩、弱端点、反演等价及证书用途。它没有新附程序、运行命令或冻结数值报告；本轮未为重复代数再运行既有程序。

当 $T>\alpha$ 时，检查没有认证目标。不能由此推出原游戏无 $\alpha$-PNE；实际边际可能更好，其他势或精确均衡也可能存在。这一范围与原审查所说“只需核秩增长及有限和”的验证接口一致。

## 4. 渐近量词核对及负向输入的限界

原审查专门解释固定 $c\in(0,1)$ 的误差：

\[
 \mathcal H_d(cd)=
 \frac{\log d+\log(1-c)}{\log(1/c)}+o_c(1).
\]

分母较 $\log(1/c)$ 只差 $O(1/d)$，乘上 $O_c(\log d)$ 的分子，误差为 $O_c(\log d/d)$。因此不是把常数误差误写成 $o(1)$。固定 $x\in(0,1)$ 的反演再给
$h/\log d\to a\in(0,\infty)\Rightarrow A_{d,h}/d\to e^{-1/a}$，以及零、无穷两个高度比端点；它是势族保证曲线，不是真实最坏游戏临界曲线。

最小坏游戏量 $H_c(d),K_c(d)$ 分别在全部无 $cd$-PNE、次数至多 $d$ 的游戏上取最小，空集取 $+\infty$。逐游戏 $h\le k$ 给 $H_c\le K_c$，不要求同一游戏实现两个最小值。必要 $\Omega_c(\log d)$ 不能证明坏游戏集合非空。

上方向的正确顺序为：固定 $c$，再固定整数 $n>1/(1-c)$，然后对所有充分大整数 $d$ 调用无 $(1-1/n)d$-PNE 的完整全状态/同次数族。其 $b=1-1/(2n)$、最小满足
$b^g\le(192d^2)^{-1}$ 的 $g\ge2$ 给
$g\le13n\log d$；修复不添可动权值给 $k=g+1$，同一 clone 零玩家序列逐层共占给 $h=g+1$。上述账本可以核对，但全状态出口仍须另证。

非一致近次数边界也被明确检查：无 $(d-1)$-PNE 必要 $h,k\ge d$；固定 $b>0$ 的
$\mathcal H_d(d-b)\sim d\log b/(b-1)$ 在 $b=1$ 连续解释为 $\sim d$，$0<b<1$ 的两负号相消。不能从固定 $c$ 结论推得任意 $c_d\uparrow1$ 的统一对数深度。

本审查**没有**独立核验参数族全部真实相位、所有非法状态和同次数修复。后来 source:68fad804ec5946cb296f77dc5b336308a66abf12:research/reviews/weighted_congestion/structural_reconstruction/additive_near_degree_review.md#8-固定-n-原定理的阈值及固定-c-推论 才专门把固定 $n$ 原阈值接入其已逐态重建的统一条件。这个较后的完整输入状态已在[最小失稳对数桥](../定理/最少失稳权类与潜在高度的对数桥--定理.md)准确保留，不反向扩大早期 depth_independent 审查的历史范围。
