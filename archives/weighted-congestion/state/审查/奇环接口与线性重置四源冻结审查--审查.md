# 实读范围与关系

四份冻结 JSON 在 `legacy-cleanup`（68fad804…）和 `main`（aefc58ea…）的同路径版本逐字节相同。这里逐字段读取了 `verification.json`、`exact_evidence_20261014.json`、`audit_checks.json` 和 `recovery_provenance.json`，并回读 `odd_ring_linear/README.md`、`odd_ring_linear.md`、`odd_ring/cohort_lower_bound_and_envelope.md`、正系数接口定理、线性重置下界定理、次数障碍、状态独立审查和精确核验计算稿。四源之间要保持角色差异：前两份是数学/实现冻结输出，第三份是参数与包络检查，第四份是恢复链路 provenance。

现有完整正文已经给出 `OC-INTERFACE-v1`：奇数环 hub/cohort 二动作拥塞游戏，全部资源费用为正系数单项式，所有 cohort 玩家独立行动且可重于自己的 hub。若每点 `N_i,Q_i>0` 且闭环乘积

`G=∏_i n_i N_i Q_i/(M_i P_i)>1`,

则存在正系数 `q_i,p_i` 同时满足 light/hub 严格差，每个纯状态都有严格 `α` 改善。现有 `OC-AMPLIFIER-v1`/`OC-AMPLIFIER-LIMIT-v1` 再将一个线性 reset 节点与 `2m−1` 个 degree-`d` buffer 节点闭合，推出每个 `d≥2` 的显式有限下界。本文只把四源的冻结输出准确挂接到这些正文，不重新声称一条超出既有正文的新定理。

# 3. `6986cf93b4b900c0c569`：审计检查、重置和连续包络诊断

# 5. 关系、失败机制与处置

四源共同支持以下稳定关系：正系数接口的充要条件是给定 `N_i,Q_i>0` 后 `G>1`；线性 reset 通过精确标量因子将该条件实现为有限游戏；偶数/奇数 parity、aligned-light 和 equal-hub edge 是完整状态证明的机制。现有次数障碍进一步说明该**接口证书**不能在固定次数上无限提高；后续 `linear_degree_allstate_lower_bound.md` 是另一套全状态构造，不能由本批引用自动吸收。

必须保留的缺口包括：`d=100,1000` 等大参数行没有全部 profile 枚举；`audit_checks` 的 Decimal envelope 不是区间证明；provenance 的 byte-identical 不等于数学验证；有限实际小游戏不等于全类上界/下界的最优性；文献优先权、外部同行评审和 `WC-TARGET` 全类阈值仍未由本批认证。四个来源均处置为 `integrated`：独有内容去向是本审查中分别的 exact local witness、amplifier parameter table、audit/envelope diagnostics 和 recovery crosswalk。
