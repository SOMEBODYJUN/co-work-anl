# 读取范围和证据边界

本审查逐项读取五份冻结 JSON，并把它们和同目录的主/旧版本二元来源、已有《循环复制与锚定时钟十源有限审查》、`uniform_clock_budget_barrier` 正文及相关审计程序比较。库存中的每份来源均有 `legacy-cleanup` 与 `main` 两个绑定；本批五个路径的库存摘要分别给出稳定 ID `8f7ea04f0d2979348714`、`8b6bb0751834fc2bf17e`、`8af5a02ef3f9a6810342`、`47e32bb73b234cac573a`、`201bc788e57ef63887d7`，冻结文件 SHA256 依次为 `a9d7efb7888faf2ad5092573347bce11da672b4ce91b667e81d70d80b3ac1d88`、`7f94dc38f1d5f06042e098d6ed3bb5f6cda79f76f093ca36375675ed2e1953d5`、`3e9f4180f0693749cdd814a1f382d24d6f0a9a8c71d6c8d957079cb428d7161f`、`e38930db0cb32fa5ef5a86f1a1d98ea1eef5edd2968112a396c6bace0e298b71`、`c45a1daf5ff6e86e933a646ea25b00f7105e5887dab2a73bb39de8847034d73b`。正文中的数值均来自有理数/整数检查；超长分数只在冻结 JSON 中保留，正文使用其结构性结论和可核验摘要。

五源的共同限制是：它们是循环复制/锚定时钟线的独立或半独立算术证据，不是一个新模型。`independent_*` 报告的“独立”是代码路径、硬编码输入或程序外重建意义上的独立；它不自动等于数学证明，也不把同一冻结输入变成不同实例。每个结论必须按其输入、量词和状态空间保留。

## 1. 独立 margin padding：所有 D 的固定结构核验

`independent_clock_margin_padding.json` 的 scope 明确为“supporting all-D fixed-structure padding proof”。它使用 `fractions.Fraction`，无随机 seed；记录 `alpha=21/20`、四个权重、四个 `gamma` 和四个 `K`，并完成 `literal_state_player_checks=384` 与 `monomial_player_checks=2277`。它逐项检查 degree cap `0,1,3,43,100,1000`。其中 `1000` 行实际以 `[0,100]` 的 monomial degrees 进行（报告本身如此记录），因此不能把该行误写成 degree 1000 的逐单项式穷举。

六个 cap 都报告 `padding_positive=true`、`two_private_realization_cost_equivalent=true`、`b_survives_every_clock_obeying_budget=true`。低次数行的结构数据可直接复核：cap 0 的 `coarse_efficiency=1`，cap 1 为 `3/2`，cap 3 为 `27/8`；cap 43、100、1000 的效率与 epsilon/预算上界均以精确大分数保存。这个结果支持如下固定结构命题：在报告所编码的私有资源两动作等费、非空互不相交 antichain、以及给定预算量词下，padding 的严格正余量可沿所列 cap 保留，且指定的 `b` 对所有满足预算的时钟继续存活。

它没有证明“任意时钟合同都可这样 padding”，没有证明新费用、不同 anchor/phase、不同基体或任意高次数的统一编译，也没有提供循环外合法策略的全局结论。与既有十源审查中的 `clock_margin_padding.json` 相比，本源独有的去向是：把“所有 D”的固定结构断言和两个等价性检查写成独立回归证据；旧源已经承载的同一固定 degree-43 例不重复改写为新定理。

## 2. 独立 full-uniform D=80：固定输入的全状态证书

`independent_full_uniform_clock_degree80.json` 只审一个固定输入 `examples/weighted_congestion/anchored_actual_clock_degree43.json`，scope 直接写明“D=80; no asymptotic claim”。参数为四个 base 权 `1,1/2,1/4,1/8`、三个 clock resources（`012,013,023`）、`alpha=21/20`、`B=56643761/70312500`、`eta=49676111/6750000000`、`L=3`、`delta=12/13`、`M=396506327/234375000`，统一次数固定为 80。报告同时记录统一预算阈值 `1241902775/1798552699272`，首次满足的整数次数是 `uniform_minimum_degree=91`，并明确 `uniform_budget_fails_at80=true`、`uniform_budget_succeeds_at91=true`。

全状态部分实际枚举 16 个状态、64 个玩家成本、64 个偏离、16 个 strict canonical exits，并检查互补成本对称及 weak-zero 边界；`canonical_rational_lower_bounds` 给出 cycle 下界 `1/500`、illegal 下界 `1`。因此它支持的是固定 16 状态统一时钟游戏在 D=80 下的严格出口证书。D=80 通过实际全状态检查，而保守的统一预算门槛到 D=91 才满足，这二者必须并列：后者是充分预算的参数门槛，前者是一个固定实例的实际证书，不能声称 80 最优、91 必要，或把预算门槛当作所有输入的最小次数。

这份来源的独有内容是独立的全状态复算及其输入/程序 SHA（`input_sha256=e436bf86b889eb30439a4024e288f7b8b1db694960800fb871a522f24459419e`，`source_sha256=08c277f091239891fd0090c666c9e3d7cd26762c1b445d5d90b4e4b61b1f7937`）。它与十源审查中的 `full_uniform_clock_degree80` 属同一固定对象，去向是补充独立读取和边界说明，不另建“D80 新证明”。

## 3. 独立统一预算：必要参数扫描而非充分性定理

`independent_uniform_clock_budget.json` 的标题是“锚定三元统一泄漏预算的独立有理区间审计”，scope 明确写出：`alpha<R` 是真实严格循环的必要条件之一，但不充分，且不从抽样推出一般定理。所有计算使用有理区间和确定性上界。参数为

- `alphas={1,3/2,3,7}`；
- `eta_over_B={1,1/1000}`；
- degree choices 为 `D_min,D_min+1,2D_min`，并考察 `p=0,D-1,D,D+1,2D`。

审计通过五类检查：所有 anchor 满足 `delta >= (R+1)/(R+2)`；最小 D 满足预算而 D-1 失败；`D>(R+1)log(4 alpha^2 L)`；`D>2(alpha+1)log(2 alpha)`；以及 `q>(alpha+1)log(q)` 的有理 log 上界。总量为 71 个 weight vectors、323 个 anchors、2264 个参数 cases、33960 个 q checks、7 个等权 case，最大最小次数为 1914；最小认证 gap 是正分数，并位于 weights `(1/4,1/4,1)`、anchor 0、`alpha=1`、`eta/B=1`、`D=8`、`p=0`、`q=8`。

这里最有用的数学信息是预算不等式的离散边界和 gap 方向，而不是一个抽样“证明”。它与既有 `uniform_clock_budget_barrier` 的解析障碍相互印证：本源提供更宽的有限参数回归（2264/33960），但不改变正文中的量词，也不证明任何真实严格循环的充分条件。独有内容去向为“有限必要参数审计”字段；已有三元锚定预算正文继续承担一般实数输入的解析推导。

## 4. 线性 degree 多类组装：小参数的资源与修复身份

`linear_degree_multiclass_assembly.json` 报告 `status=all exact assertions passed`，使用精确有理/整数运算。三组全状态样例为 `(m,N,K,degree)=(3,3,2,2),(4,3,2,3),(3,4,2,3)`；对应状态数分别为 512、4096、4096，全玩家偏离 4608、49152、49152，非法 class repairs 384、4096、6144，参与性检查 18、24、24。它还列出单类 clock 的 8 个 N/degree 样例（N=3..10），每个给出 bitstrings 和 repairs；这些计数是资源组装与非法态修复的回归，不是 PNE 消失定理。

该源有两个需要接续的精确边界。第一，`clock_twist_boundary` 在 N=4、degree=3、clock amplitude `11/7` 下记录 all-zero anchor clock cost `88/63`，对应 twisted player cost `176/189`，并明确“base symmetry does not extend to the anchored clock game; proof uses it only before adding clocks”。因此不能把 base 对称性直接延伸到加钟后的 anchored 游戏。第二，`integer_degree_certificate` 给出 `base_F20=10604`、比较指数 `524288`、归纳身份 `2F(k)-F(k+1)=24k^2+k-49>0`（k≥20），并在多个 dyadic endpoint 做 exact integer checks；其 scope 自己限定为补充解析归纳，不是对全部 p 的有限枚举。

与旧的单类 cycle/clock 文件相比，本源独有的是多类资源数量、非法 class repair 和 class-aware clock twist 边界。它没有把小参数 `m≤4,N≤4,K=2` 外推到目标规模 `p≥2^20`，也没有把“all exact assertions passed”升级成一般多类编译器定理；正文仅把它接到后续多类组装、修复成本和全状态筛选的开放接口。

## 5. 统一预算完整回归：较大有限网格与一个实际三元组

`uniform_clock_budget.json` 使用 64 项奇次 log 展开和确定性有理误差界
`2*z^(2N+1)/((2N+1)(1-z^2))`。它枚举 35 个权重向量、6 个 alpha、3 个 `eta/B`，共 121 个 anchor configurations、1800 个 parameter cases、9000 个 q checks，最大 D=237；`status=all exact assertions passed`。实际 triad 另给 weights `(16,2,5)`、`alpha=21/20`、`B=2002`、`eta=677/20`、`delta=21/23`、`R=8`、`L=1`、`D=62`，并保存 6 个 cycle margins、归一化 ratio interval 和 8 个 profiles。

该报告的实际三元组是“strict double-sweep base game”的有限证书，scope 明确说不是新的 target-scale nonexistence family。它与独立预算报告的关系是：前者是较大的确定性网格加一个真实 triad；后者是另一套独立参数/边界配置。两者应分别保留，不能把 1800 cases 和 2264 cases 相加后写成“全参数空间已验证”。

## 与先有正文的衔接和处置

1. **与《循环复制与锚定时钟十源有限审查》：** 本批的 D80、padding、统一预算和几何边界与十源中同名固定对象相交；因此本文件只补独立路径、独有计数和量词，不复制一套“新循环定理”。
2. **与《统一低泄漏锚定预算的次数效率》：** 五源都保留“预算是充分门槛/必要参数约束的有限检查”与“实际 D80 证书”之间的区别。D80 通过不能推翻 D91 的保守门槛，因为门槛不是必要条件。
3. **与多类/全状态线：** 小参数组装只提供资源身份、修复计数和对称性破缺边界；目标规模的覆盖、全状态 PNE、非法态修复和 `p≥2^20` 仍需各自的证明或冻结证据。
4. **冻结与增量：** 两个绑定 commit 的同一路径在库存中视为同一来源版本；本批没有把旧摘要或旧图当完成依据。JSON、命令、程序/输入 SHA 和本审查的稳定 ID 是第三阶段可追溯入口。

## 结论、用途与缺口

**完整固定结论：** 列出的 padding 等价性/存活检查、固定输入 D=80 的 16 状态统一时钟证书、有限预算网格的精确不等式回归、小参数多类资源组装身份，以及 dyadic 整数归纳的已列端点。

**有限实验或回归：** 所有计数、参数扫描、实际 triad、单类 clock repair 和程序 SHA。它们适合重放、代码回归和发现边界，不替代抽象证明。

**条件结论：** padding 结论依赖报告固定的权重、gamma/K、同费私有资源、预算量词和 monomial 检查范围；多类组装依赖小参数与显式正幅度；D80 依赖指定 anchored_actual_clock_degree43 输入。

**障碍和未完成方向：** 统一时钟的通用充分构造、任意费用/anchor/phase、高次数和多类全规模编译、目标规模全状态 PNE 消失，以及外部新颖性/同行复核仍开放。不能从这五源推出任意 weighted-congestion 游戏无 PNE，也不能把“最大最小次数 1914/最大 D 237”解释为理论最优。
