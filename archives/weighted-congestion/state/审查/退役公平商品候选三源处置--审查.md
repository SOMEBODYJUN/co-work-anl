# 模型身份与阅读范围

这组三源属于退役的 `fair_goods` 选题，不是 weighted-congestion、unrelated-machines 或 customer-attraction 模型。它们讨论共同约束下的 EF1/SD-EF1、MMS、fPO 和公平商品分配；候选报告明确把 Paper Fact、公开问题、候选 idea、有限枚举和新颖性分开。本页完整读取候选报告、候选 JSON 和独立标量核验，原件、哈希、有限证人数值和结构检查见 [retired-fair-goods-20261031](../../tools/evidence/retired-fair-goods-20261031/)。

# 候选报告和候选清单

`candidate_report.md`（18,369 bytes）将 FG01（四人 laminar EF1 的 8/12 件 key matroid 瓶颈）和 FG02（goods-with-copies 的 SD-EF1，先三人）列为首两名；FG03–FG05 是保留候选，FG06–FG10 因后续论文已覆盖或原题过大而淘汰/改写。报告只把这些作为 2026-10-20 的选题地图，不承诺二十天解决，也明确写出“未发现后续”不是新颖性认证。

## FG01：四人 laminar EF1 的 key 实例

报告重述母论文的结构边界：三人加强版已有归约；四人完整 laminar 目标可归约到 K8（8 件、三类、每类 cap=1、总 cap=2）和 K12（12 件、四类、每类 cap=1、总 cap=3）两个 ordered no-envy 加强实例。它给出精确的完整分配计数（K8 864 个标号分配/36 个无标号 partition，K12 31,104/1,296）以及旧 top-i separation 条件在 K8 上没有可行分配的复现。

报告提出的 idea 是覆盖连续估值比较区域：先列出有限 partition 菜单，再把“每个 partition 都违反某条公平/次序不等式”编码为有理线性可满足性，抽取人工交换引理或有理反例。当前 5,000 个 K8、500 个 K12 整数 profile 样本都找到证人，但这只是有限枚举；连续非负估值、零值和 ties 的全称覆盖仍是第一 proof obligation。普通 EF1 与 ordered no-envy 加强版必须分开，强化命题失败不能直接否定普通 EF1。

## FG02：goods-with-copies 的 SD-EF1

报告把 goods-with-copies 限定为：类型 g 有 \(c_g\le n\) 个等值副本，每个 agent 每类型至多拿一件；对每个观察者 i 的价值排序前缀 P，要求

\[
|A_i\cap P|\ge |A_j\cap P|-1
\]

这与 SD-EF1 相容。一般 partition matroid 的 SD-EF1 反例不能直接迁移，因为 goods-with-copies 的同类副本等值；报告提出把列和固定的二元矩阵 \(x_{ig}\) 通过 alternating exchange 修复最早坏前缀，先做 n=3。其首义务是证明一个会终止的三人混合 multiplicity prefix-repair lemma，不能用独立舍入的误差 2 代替误差 1。

冻结候选里对 n=3、四个非 universal 类型、multiplicity 1/2 的 9,216 个 profile 全枚举每个 81 个分配，均找到 SD-EF1 证人；更大的随机样本也没有反例。但这仍是有限证据，不能宣称任意类型数或任意人数的 SD-EF1 存在。

## 其他候选的准确状态

- FG03 是三人、两类各三件、cap=1 的 EF1+fPO 同步问题，依赖正权 welfare face、KKM 和 prefix-price interlacing；尚未运行 36 个分配的 support-cone 枚举。
