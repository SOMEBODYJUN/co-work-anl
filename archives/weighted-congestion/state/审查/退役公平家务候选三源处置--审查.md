这组三源属于退役的 `fair_chores` 选题，不是 weighted-congestion、unrelated-machines 或 customer-attraction 的数学对象。它们研究不可分割家务、EF/EFX、公平成本和低秩 matroid/平行类结构；候选报告明确要求独立保留模型身份、区分 Paper Fact、作者猜想、有限搜索、内部攻击和外部审稿。本页逐字读取 rank-2 引理、候选报告和 candidates.json；原件、SHA、字段校验和分类见 [retired-fair-chores-20261031](../../tools/evidence/retired-fair-chores-20261031/)。

# FC-LEMMA-R2-2C-v1：两平行类无 loops 的局部引理

引理的输入是 n 个 agent、m 件 indivisible chores。每个 agent i 将物品划成两类 \(A_i\sqcup B_i=M\)，允许其中一类为空但没有 loops；成本是

\[
c_i(S)=\mathbf 1[S\cap A_i\ne\varnothing]+\mathbf 1[S\cap B_i\ne\varnothing].
\]

这正是两个容量 1 的平行类组成的 rank≤2 partition matroid。引理声称：当 \(m\ge n\) 时存在 complete EF 分配且可多项式构造；当 \(m<n\) 时存在 complete EFX 分配（每个 agent 至多一件）。不要求 PO。\(n=1\) 是平凡边界。

证明把每件物品写成 binary word \(b(e)\in\{0,1\}^n\)，第 i 位表示它属于 i 的 A/B 类。

**全部 \(2^n\) word type 出现。** 互补 word pair 有 \(2^{n-1}\) 个；当 \(n\ge2\) 时至少有 n 个。取 n 个互不重叠的 pair type，每个 type 各取一件物品给一个 agent，其余物品任意分配。每个 bundle 对所有 agent 都同时触达两类，成本均为 2，因此 EF。枚举 word 不破坏多项式性，因为该情况要求 \(2^n\le m\)。

**存在缺字 w。** 构造二部图 \(H_w)：左侧为 agents，右侧为物品，i 与 e 相邻当且仅当 \(b_i(e)\ne w_i\)。因为 w 未出现，每件物品至少有一个邻居。若 H_w 有覆盖所有 agent 的 matching，先给每人一件 matching 物品，再把剩余物品交给任意邻居。每个 agent 自己的成本是 1；别人的非空 bundle 对其成本至少是 1，故 EF。

若最大 matching F 的大小 \(k<n\)，从未匹配 agents 沿交替路得到可达 agent 集 S 和 item 集 T，满足 \(|T|<|S|\)、S 的所有 H_w 邻居都在 T，且可以让每个 i∈S 轮流成为未匹配 agent。若每个单坐标翻转词 \(w^{(i)}) 都出现，从每个 type 取一件物品会产生互不相同的 \(e_i\in T\)，矛盾于 \(|T|<|S|\)。因此存在 i∈S 使 w^(i) 仍缺失。先沿交替路让 i 未匹配，再把 w 翻转 i 位；因为 \(m\ge n>k\)，存在一件**全局未匹配**的物品 e，且 e∉T，故其原 i 位等于 w_i，翻转后 i 与 e 相邻，matching 增长 1。重复至多 n 次得到覆盖所有 agents 的 matching。

这个“全局未匹配 item”修正是本源内部攻击后明确补入的承重细节；只知道 e 不在 T 不足以保证它未被 matching 使用。作者给出 trie/hash 的缺字维护、增广 matching 和 O(n³m) 保守复杂度，空间 O(nm)。源记录了内部 cross-field/boss4 攻击和修正，但没有外部审稿或新颖性认证。

引理的边界也写得很清楚：两平行类无 loops 不能直接扩到三平行类或 loops。三类时“与缺字不同”可能使 owner bundle 同时触达两个类；loops 时别人的非空 bundle 对 i 的成本可能为 0，“自己成本 1”步骤失效。更高 rank、partition/laminar matroid 和 general matroid 仍是候选方向，不是已证推广。

本引理可作为一个局部组合工具保存，但当前状态仍是 `complete internal proof / no external review`，不应被写成一般 matroid chores EFX 定理。

# 候选报告与 candidates.json 的独有内容

候选报告（21,813 bytes）是 2026-10-20 的重新选题报告。它明确区分 Paper Fact、公开问题、作者猜想、有限 toy search、内部审查和外部新颖性；没有把旧 UM 目标或 weighted-congestion 约束强加到 fair_chores。报告把 FC-01（rank≤2 matroid chores 的 EFX 分类）列为首推，把 FC-02（混合图单圈/仙人掌 EFX 定向）列为第二深挖；还保留 FC-03（精确三件三值 chores MMS）、FC-04（五人公共双值 EFX）、FC-05（常数 EFX 多项式初始化）、FC-06（三人九件 EFX）等后备，淘汰已被后续论文覆盖的 FC-07/FC-08。

报告的价值不在于已解决这些候选，而在于精确记录研究入口和最危险障碍：

- FC-01 的三类/loops 扩张可能立即失效，不能把二类引理外推；
- FC-02 的 unicyclic/cactus 可能被低树宽算法覆盖，或者单圈只是树算法的直接延伸；
- FC-03 的三值 quota 可能被已有 balancing 框架覆盖；
- FC-04/FC-06 接近公开大问题，不能许诺短期解决；
- FC-07 的 \(\Delta\)-EFX 只是把 binary EFX 乘最大/最小成本比的简单推论，应淘汰；
- FC-08 已有 2026 结果，不能原样重选。

报告还给出有限搜索和复现实务边界：固定 seed 的 toy scripts 只覆盖有限 rational/integer profiles；“没有失败”不是成功概率或新颖性认证；`construct_rank2.py` 检查 complete allocation、EFX 以及 m≥n 时 EF，但不是一般求解器。

`candidates.json` 将这些内容结构化为 8 个候选，给出每个 candidate 的精确 input domain、quantifiers、mother papers、core mechanism、dangerous obstacle、falsification test、first proof obligation、latest overlap check、novelty_certified=false 和 twenty_day_solution_claim=false。它把 FC-LEMMA-R2-2C-v1 标为 `complete_local_proof_internal_attack_no_external_review`，推荐 FC-01/FC-02。
