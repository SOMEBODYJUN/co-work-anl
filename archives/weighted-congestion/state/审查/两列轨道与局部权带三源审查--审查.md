## 两列对称游戏：完整轨道公式

候选稿的对象是一个权 1 玩家和 n 个权 w 的轻玩家。资源为两列 `a_0,…,a_n` 与 `b_0,…,b_n`；主资源 `a_0,b_0` 费用为同一个非负有限次多项式 P，副资源费用为 Q。重玩家只能选整列 A 或 B；轻玩家 i 在 `{a_0,b_i}` 与 `{b_0,a_i}` 间二选一，成本是所选资源费用之和，权只进入资源负载。量词是每个整数 n≥1、实 w>0 和每个 P,Q，逐个参数游戏成立；稿件不声称对 n、w 或多项式次数取上确界后的全类最优值。

利用列交换，把重玩家固定在 A；令 m 为和重玩家同列的轻玩家人数。所有同址轻玩家可由标签置换合并成一个轨道，m=0,…,n。直接按当前和单方偏离后的负载重算，重玩家当前成本与换列成本是

\[
 h_m=P(1+mw)+(n-m)Q(1+w)+mQ(1),\qquad h_{n-m},
\]

同址轻玩家的当前/偏离成本（m≥1）为

\[
 A_m=P(1+mw)+Q(w),\qquad D_m=P((n-m+1)w)+Q(1+w).
\]

异址轻玩家的偏离比是相邻轨道的倒数：当前为 `D_{m+1}`、偏离为 `A_{m+1}`。对零偏离成本使用扩展比 `r(C,D)=C/D`（D>0）、`+∞`（D=0<C）、以及 `1`（C=D=0）。因此轨道 m 的必要且充分倍率是

\[
 q_m=\max\left(1,r(h_m,h_{n-m}),r(A_m,D_m)_{m\ge1},r(D_{m+1},A_{m+1})_{m<n}\right),
\]

完整实例的最优纯均衡倍率为 `min_{0≤m≤n} q_m`。每个轨道由合法纯状态实现，列交换和轻玩家置换穷尽所有状态；每个玩家恰有两个策略，所以以上比值也穷尽全部非平凡单边偏离。若某个 q_m 有限，有限轨道最小值给出端点包含的 α-PNE；全 q_m=∞ 时使用扩展实数表述。对非负多项式域，除 P=Q=0 外偏离成本为正；P=Q=0 时倍率为 1。

验证程序没有使用浮点或随机数。它枚举函数系数 `(0)`, `(1)`, `(0,1)`, `(1,0,2)`, `(0,0,0,1)`，权重 `1/10,1/5,1/2,1,2`，n=1,…,5，共 `625` 个参数 cases、`15500` 个 literal profiles 和 `80000` 个 literal deviations；每个实际偏离比都与轨道公式逐项相等。它还做 `64` 个反向乘法检查。冻结报告列出的固定反例为 n=3、w=1/5、P(x)=x、Q(x)=x²/2，四条轨道的 q 值分别由行 `m=0,1,2,3` 给出 `66/61,157/156,71/56,81/46`，所以实例阈值恰为 `157/156`；同时文献式两类保守证书取到 `61/66<1`。这只反驳“那两个保守证书总是该拓扑的真实门槛”，不改进全类已知下界，也不主张文献证书本身错误。

独有内容去向是“完整状态商 + 三类真实偏离 + 粗证书损失”的固定模型证明和精确反例。候选稿自己保留了 `WC-R2-ORBIT v1`、`WC-R2-COARSE-LOSS v1` 的未外审、未认证新颖性状态；有限枚举只支持实现和该实例，不替代对 P,Q,n,w 的进一步优化。不能把一条改善循环写成阈值证明，也不能因为 `min q_m` 已可计算就宣称一般参数最优上界。

## 局部窄权带：既有代数定理的精确回归

`weight_bands/verification.json` 的 scope 明确为“Finite exact verification supplements, but does not prove, the general theorem”。seed 为 20261014，所有核心比较是 Fraction；诊断十进制不参与断言。冻结结果为 `status=all assertions passed`，具体为 `share_cases=1858`、`pair_ordering_checks=13213`、`positive_identity_checks=224`，另有一个多资源游戏、curl 障碍、dense augmentation、linear obstruction 和 sharp selector。

验证程序复现了当前 README 的两条代数排序。对有限非空正权用户集、非负多项式费用和总费函数 `F(x)=x c(x)`，逐项核对 Shapley 份额效率、精确边际 `H(S)-H(S\setminus{i})=φ_i(S)`、普通份额随权不减、每权份额随权不增及

\[
 \min_j w_jc(W)\le φ_i(S)\le\max_jw_jc(W).
\]

源码对单项式 `x^q` 展开，并把其余玩家指数固定后检查 README 中的正系数恒等式；它没有用已有研究程序作为库导入。随后在任意有限策略族（含空策略、多资源和一个恒零费资源）上检查 scaled Shapley potential 的边际恒等式和局部 `R`-PNE 界。冻结多资源例有 108 states、1404 deviation checks，最小势态是两个，`R=7/4`；这支持固定有限实例的回归，而一般存在性仍由 README 的代数证明承担。

本报告还固定记录两个结构性障碍。第一，单资源两用户权 1 与 13、三次总费给 `κ=273`，而按各自权分别归一化会要求同一混合差同时等于 `κ` 与 `κ/13`，所以这种“分带后各自归一化”没有普通集合势；它不排除带玩家乘子的加权势。第二，dense augmentation 在 d=7、M=49、L=3 时列出 128 states、每带四个潜在用户和唯一最小 mask；linear obstruction 在 d=7,8,10,20,50,100 上记录 `rho=delta/2`，都满足 `rho≥d/6` 且 `rho>1`。这些是标准 Shapley 选择器的机制障碍和锐性示例，不能写成游戏不存在纯 PNE 的下界，因为同一族可能有精确 PNE。

`sharp_selector` 另审 R=2、m=2,3,5,10,20、d=m² 的有限参数，验证

\[
 \frac{W}{m+1}[1-(1-1/W)^{d+1}]\le\delta_m\le\frac{W}{m+1},
\]

并记录 rho=delta−1/m 的显示值及是否大于 1。它支持“该势选择器的因子可逼近 R”的固定序列核验，不是 `a_*(d)` 的普遍下界。

与已归档的《局部窄权带的 Shapley 份额势》比较：该定理文件承载无次数/人数限制的代数证明与潜在用户量词；本源只承载 seed 固定的有限 exact replay、障碍和选择器数值。与《局部 Shapley 包络与尾部冻结的审查范围》比较：其历史审查已经记录独立采样证明、tuple 势等价和尾部冻结五段链；本源没有把“有限验证通过”提升为外部审查或新颖性认证，也没有改写已修正的零费条件。

## 可复现接口、失败边界和接续

两列验证命令是 `python3 tests/audits/weighted_congestion/two_column_orbits/verify.py`，生成的 evidence 由程序拒绝随机和浮点；局部权带验证命令是 `python3 tests/audits/weighted_congestion/weight_bands/verify.py`，默认与冻结 `verification.json` 逐字段比较，`--generate` 只允许写入新路径。两者均适合第三阶段回放和回归。

两列需要继续的数学方向是对完整 `q_m` 公式做参数优化，寻找中间轨道控制族；固定反例不能替代全参数族的 lower-bound 或 upper-bound 证明。局部权带需要继续的方向是跨远权带的统一势、不同选择器和全局阈值；现有 `R`-PNE 界是局部潜在用户比的存在性机制，标准 Shapley 选择器的线性损失和混合差障碍没有把所有非势方法排除。
