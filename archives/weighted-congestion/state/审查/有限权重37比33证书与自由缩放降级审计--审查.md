# 来源、模型与比较范围

本批三源属于退役 multi-lane 的 finite-weight 原子拥塞/局部势探针。源码和 JSON 均完整实读；相关 `finite_weight_scaled_potential.md` 降级笔记也逐段旁读。精确证书与有限 LP 输出不是同一证据等级：前两份给出一组可逐项复核的有理局部势不等式，第三份是浮点 HiGHS 可行性二分在有限人数上的数值包络。

## 1. 37/33 固定模板的精确证书

### 输入和局部势模板

`exact_certificate.py`（ID `26ea39fc1f727569d697`，1706 字节，SHA-256 `9098bf368444d68ffa62ebf7f7e0763ea0e3c590162effe75fdbe3e415fa13ab`）针对两个玩家类型：轻权重 1、重权重 2。资源状态用 \((k,l)\in\{0,1,2\}^2\) 表示当前资源上轻/重玩家人数；加入轻玩家的边权为 1，加入重玩家的边权为 2；二次延迟按加入后的总负载平方计算。脚本先以 SciPy `linprog` 找数值可行点，再把每个状态限制为有理数，最后逐条用 Fraction 验证 12 个加入边不等式。

目标因子为

\[
\alpha=\frac{37}{33}.
\]

冻结 JSON（ID `93c6f2ebd4d98a8dbdbe`，2074 字节，SHA-256 `c0e7d938f7aa9e2862a2cff9814de9b3655728501f4311fc272d5a59c3e392db`）给出状态函数：

| \((k,l)\) | \(F(k,l)\) |
|---|---:|
| (0,0) | 0 |
| (0,1) | 296/33 |
| (0,2) | 1354/33 |
| (1,0) | 1 |
| (1,1) | 629/33 |
| (1,2) | 2279/33 |
| (2,0) | 5 |
| (2,1) | 37 |
| (2,2) | 109 |

每条加入边的真实成本 `cost` 与势边际 `marginal` 都是有理数；最大比值恰为 37/33。脚本运行输出 `CERTIFIED 37/33 12 marginal inequalities; all arithmetic rational`，并重新生成的 JSON 与冻结 exact_certificate.json 逐字段相等。

### 两条路径给出的模板下界

从状态 (0,0) 到 (2,1) 有两条顺序路径：

- 轻、轻、重：边成本和为 \(1+4+32=37\)；
- 重、轻、轻：边成本和为 \(8+9+16=33\)。

任何满足固定真实权重缩放模板

\[
w,c(L+w)\le \Delta F\le \alpha w,c(L+w)
\]

的同一终点势，都必须有 \(37\le33\alpha\)，故 \(\alpha\ge37/33\)。这证明的是**该局部边际区间模板**的最优性；它不是所有势、所有玩家缩放、所有原子拥塞博弈的最优近似均衡阈值。

### 可迁移的有限结论

相关降级笔记给出该模板的构造解释：对任意非负二次延迟，资源势可用该二次 \(F\) 与常数/线性精确势按非负系数组合；有限 profile 状态因此保证严格 \(37/33\)-改善序列终止。这里的量词仍限于有限人口、权重类型 `{1,2}`、每种类型至多两名玩家的证书模板；终止性不等于多项式改善步数，也不等于存在阈值最优的 PNE 算法。

## 2. 自由 type-scaling 的有限包络结果

`scaled_envelope_results.json`（ID `c139fd0450a8ce054dc6`，55,735 字节，SHA-256 `b3b488515bacf92d60ca60acd7adb67be02cbdd7050172932d13bde0e223c9d9`）记录另一条更强模板的数值探针：heavy 类型允许自由正缩放 \(h\)，对 \(n_1=n_2=N\) 的有限状态 LP 以浮点二分搜索最小 alpha。七个 N 值为 1、2、3、5、10、20、35；摘要如下：

| N | alpha（二分） | h 近似 |
|---:|---:|---:|
| 1 | 1.0000000000 | 1.600000 |
| 2 | 1.0269168336 | 1.684728 |
| 3 | 1.0368697062 | 1.717010 |
| 5 | 1.0472975617 | 1.751406 |
| 10 | 1.0564959769 | 1.782245 |
| 20 | 1.0623802273 | 1.802223 |
| 35 | 1.0653624589 | 1.812424 |

每个条目还给出一个浮点 `F` 矩阵、`h_fraction` 近似、`max_constraint_violation`（随 N 增大到约 \(2.5\times10^{-11}\)）和 `alpha_fraction_guess`。这些数字严格低于 37/33，说明放松 type scaling 后固定有限状态的最优值可能显著更好；但它们不是有理证书，也不是所有 N 的统一构造。

该结果的限制必须保留：

1. 只检查七个有限 N，不能外推任意人数；
2. LP 可行性和二分使用浮点求解器，残差非零，不能代替 exact rational proof；
3. JSON 没有证明 `h`、状态函数或 alpha 在 N→∞ 的极限；
4. 不能从有限包络宣称 64/59、37/33 之外的全人数新上界。

相关 `finite_weight_scaled_potential.md` 已明确把 37/33 降级：存在对每种类型任意人数的 64/59 构造，故 37/33 不能作为该实例类的最佳新上界；自由 type scaling 的有限 LP 只是继续寻找更强模板的探针。该笔记同时提醒 HKS2014、Caragiannis–Fanelli 2021 和有限权重文献的查重义务，不能用本批数值声称新颖性。

## 结论分层、独有内容和后续

**完整有限证明/证书：** 37/33 的 3×3 状态有理势值、12 条边际不等式及两条路径下界；脚本运行后与冻结 JSON 相等。

**有限数值实验：** 自由 heavy 缩放的七个 N 包络、浮点 alpha/h/F 矩阵及残差；它们是候选搜索证据，不是定理。

**失败/降级机制：** 37/33 的“最佳新上界”叙事被自由 type scaling 的数值结果和 64/59 全人数构造降级；任何把该模板最优性写成所有 approximate potential 或 PNE 阈值最优性的说法都越界。

**未建立：** 没有全人数自由缩放的最优常数，没有公开文献查重完成证明，没有近似 PNE 多项式算法，也没有把有限势终止性推广为改善步数界。第三阶段可沿稳定 ID 连接“固定真实缩放的精确模板”“自由缩放有限包络”“已有64/59降级证据”，但三者保持不同证据等级。
