# 单根模块的冻结报价与固定延续提升

这是原游戏解的单向固定lift接口。模块可有环；能否删除由完整冻结报价证书决定，不由“局部存在均衡”或拓扑标签自动决定。

## 模块分解与完整合同

有限正权资源子集游戏，费用非负且有限、成本不乘权，偏离按冻结他人的新负载。保留非空玩家集N₀及仅由保留玩家潜在使用的核心资源E₀。其余资源分成互不相交模块M，每模块仅接一个保留根r(M)；被删玩家各仅属于一模块，全部原策略只用本模块资源。不同模块可以共享根，不能共享其他玩家或资源。核心可任意有环。

对每模块和根的每个**原合法动作**a，给内部完整延续y_M^a；同一β≥1下要求：根固定a时全部删除玩家对原合法偏离β稳定。并定义

\[
q_M(a)=C_{r,M}(a,y_M^a)\ge0,\qquad
D_M(a,b)=C_{r,M}(b,y_M^a)\ge q_M(b)\quad\forall a,b. \tag{G}
\]

D必须冻结**当前动作a已选的延续**，不能改用偏离后b的延续重新求均衡。

构造替代H：保留根权和全部核心原费用，每模块对每原动作a加根独享常数资源z_(M,a)，费用q_M(a)，a使用它并保留其E₀部分。每个原动作的私有标签保持策略映射单射，不因核心投影相同而合并。非负常数不增多项式次数上限d≥0；若替代资源集为空，可添无人使用的零费资源满足模型非空。

固定lift L(u)取根原动作不变，每模块填y_M^(u_r)。它不依α（β固定）。**对每个α≥1，H的每个α-PNE均提升为原G的max{α,β}-PNE。** β=1时同一lift对全部实α原倍率提升；β≤目标α亦同。

## 逐真实偏离证明

对根r，当前费用由q定义恰有C_r^G(Lu)=C_r^H(u)。偏离原动作b时，核心其他根固定，逐模块(G)给C_r^G(b,(Lu)_−r)≥C_r^H(ψ_r(b),u_−r)。所以H的α稳定直接给

\[
C_r^G(Lu)=C_r^H(u)\le\alpha C_r^H(\psi_r(b),u_{-r})
\le\alpha C_r^G(b,(Lu)_{-r}).
\]

每名被删玩家的全部偏离只在其模块，根固定时由合同为β稳定，非负成本使其也为max{α,β}稳定。全部玩家覆盖，无多人同步重平衡、无0/0或资源特定权。模块多根时独立常数通常不足，须保留边界交互或另证新接口。

## 如何找表、失败分别说明什么

小模块对每根动作枚举内部β均衡列表，再枚举这些列表的笛卡尔积，逐q/D检(G)。给定表验证成本是全部内部偏离及|S_r|²根成本评估；搜索最坏指数，不是一般位多项式预处理。

| 失败 | 正确结论 |
| --- | --- |
| 某根动作无条件β均衡 | 该动作下的子游戏无β-PNE，阻止本全动作lift合同；不判原G无解 |
| 某组延续D(a,b)<q(b) | 只否定这一报价组，可改延续或保模块 |
| 全部有限组合都拒绝 | 该私人成本接口无法处理此模块，不判原G或其他接口无解 |
| H无α-PNE | 本lift未提供解，不能反推原G无α-PNE |

### 条件均衡延续也能报价错误

根权1、两叶权2和1，共享资源e费用x，两叶另可选各自私有常数3和1；根动作0不用e、动作1用e。取y^0为重叶退出/轻叶使用，y^1为重叶使用/轻叶退出。两侧内部均精确稳定，但q(1)=3，冻结y^0后根进入只付D(0,1)=2<3。即使树模块也不能任意挑两侧条件均衡；[挂树递归](单核心挂树的私人成本提升--归约.md)用其特定阈值构造保证交叉报价。

### 原均衡不一定反向投影

根权1、叶权2，共享e费用x；根另可选私有5/2，叶另选私有3。树贪心在根使用时可按平局让叶也使用，报价q(1)=3；不用时叶用e，冻结进入成本3，所以这是一组合法报价。原状态“根用e、叶私有3”却是精确PNE：根付1，叶进入付3平局。它投影到上述H后根付3，可改私有5/2，故不再PNE。合同只保证所选固定lift，不保任意原状态成本或所有原均衡反向投影。

原审计在同一树上另选根使用时叶退出，得到合法更低报价q=(0,1)、D=[[0,3],[0,1]]；不要把它和前一贪心报价3混成一张表。两者共同说明报价选择和单向范围。

### 一个可删的有环模块

根权1、内部玩家权1和2，内部可选{e,f}或各自不同私有0资源；根只可能用e；c_e=x、c_f=x²。两个内部玩家都取私有0，在根两动作下精确稳定；q=(0,1)、D=[[0,1],[0,1]]满足(G)。内部潜在关联有环，所以条件报价可认证树之外的特定模块，不保证任意有环模块可删。

本轮原程序对上述树/有环表，五外部私有价格×四α下所有所测核心均衡，逐真实冻结偏离核50个lift，并保存错误稳定报价2<3；这不是任意根动作数的枚举证明，一般多动作由(G)证明承担。程序、完整报价矩阵及真实重放见[精确核验](../计算/共同尺度与原游戏修复的精确核验--计算.md)。它是已有单核心挂树合同的条件推广，关系按实际冻结比较判断，不改树定理、外审或新颖性状态。
