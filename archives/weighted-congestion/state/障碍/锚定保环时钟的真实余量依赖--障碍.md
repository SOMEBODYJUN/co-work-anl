# 锚定保环时钟的真实余量依赖

本文采用有限加权原子拥塞模型：有限非空玩家和资源，玩家正实权重不随资源改变；每人有非空有限的资源子集策略族，允许其中有空策略。资源费用是非负系数多项式，玩家成本为其所用资源费用之和，不再乘权重。偏离固定他人动作并按新用户集真实重算负载。严格 α 改善指旧成本大于 α 倍偏离后成本，α-PNE 要求每个合法单方偏离的相反弱不等式；零费用直接用不等式处理。

## 九、固定结构与纯三次费用也必须控制真实环余量

### 精确命题

**ID/version：** `WC-ANCHORED-MARGIN-DEPENDENCE-OBSTRUCTION-v1`。中文数学名称：锚定保环时钟不可消去真实环余量依赖。此为独立新Claim，不改变前述实际差分接口。

固定四玩家、权重 `(1,1/2,1/4,1/8)`、两个动作、倍率 `α=21/20`。对每个整数 `D≥0`，存在一个有理系数、全部资源费用为正系数三次单项式的有限拥塞博弈 `G_D`，满足以下结论。

1. 从0000按玩家0,1,2,3翻至1111，再同序翻回0000的八条边都是严格α改善。
2. 对锚点0及全部允许三元 `T012,T013,T023`，允许添加任意多个互补资源对。三元局部模式为010时三人共用一侧，101时共用另一侧；对内两侧费用相同。每对费用可为任意非负系数、次数至多D的实多项式，三元、次数、幅度均可不同，也可省略某些三元。
3. 只要添加这些时钟后保留上述八条边的严格α改善，状态0101和1010就仍是α-PNE；事实上各玩家翻位的α改善差均严格小于 `−K_min/2<0`，其中下文的 `K_min` 是一个与D无关的显式正常数。

旧资源、旧成本和旧两个动作必须保留，仅把时钟资源加入动作。结论仅限制这项固定锚点、同费互补三元、必须保环的架构，不限制改变相位、两个时钟侧采用不同费用、辅助玩家、其他拓扑或不保留原环的构造。

因此，不能有一个仅依赖输入次数、人数、权重和倍率、而不依赖真实环余量或其他实例数据的有限通用次数上界：这些参数在本族中全部固定，但每个预定的次数上限D都被某个 `G_D` 阻止。它不是全类均衡存在定理，也不阻止在精心选择的输入环增长族上实现次数控制。该句是原稿历史状态；后续全状态线性下界另行否定原全类目标，见末节。

### 构造：共同私有费用压低环余量

给定整数 `D≥0`，写

`Q_D=(3/2)^D`，

`ε_D=min{η/2, (α−1)K_min/(8Q_D)}>0`，

`t_i=(γ_i−ε_D)/(α−1)>0`。

给玩家i的两个动作都加入一个仅由该玩家使用的新私有资源。令其费用为

`c_i(x)=t_i (x/w_i)^3`。

无论该玩家选哪个动作，该私有资源负载总是w_i，因此其成本恒为t_i。全部费用仍为正系数三次单项式，玩家权重、动作数及原资源均不变；也可改用常数费用t_i，但不需要这一额外允许。定义添加私有资源后的基体为 `G_D`。

任何玩家i翻位的α改善差都减少 `(α−1)t_i=γ_i−ε_D`。所以两条指定环边的改善差恰为 `ε_D>0`。而在b，其稳定gap变为

`K_i'=K_i+γ_i−ε_D>K_i≥K_min`，

因为 `ε_D≤η/2<γ_i`。互补状态同理。

### 保环时钟的必要真实总预算

对三元T=(0,i,j)，写其总费用为非负多项式f_T；任意多对同结构资源可逐项相加。令

`S_T=f_T(w_0+w_i)+f_T(w_0+w_j)+f_T(w_i+w_j)`。

对时钟在每玩家指定环边上的α改善差记为g_i。根据真实用户群，三元T给玩家0、i、j的三项分别为

`f_T(w_0+w_j)−α f_T(w_0+w_i)`，

`f_T(w_0+w_i)−α f_T(w_i+w_j)`，

`f_T(w_i+w_j)−α f_T(w_0+w_j)`。

故精确相加得到

`Σ_i g_i=−(α−1)Σ_T S_T`。

时钟的两半环margin相同；若添加后保留全部严格环边，则每个i都有 `ε_D+g_i>0`。求和给出必要条件

`Σ_T S_T < 4ε_D/(α−1)`。

此处没有使用统一δ、统一幅度、同次数或充分低泄漏预算。

### 任意状态的逐列实际效率上界

取任一三元T，令其总权W，三种pair负载的最大值为m。三种pair负载之和为2W，所以 `m≥2W/3`。对任一参与该三元的玩家、任一状态，该时钟资源当前负载 `l_cur≤W`；偏离后负载为正。对每个 `0≤k≤D`，因 `Q_D≥1`，

`l_cur^k−α l_post^k ≤ W^k ≤ Q_D m^k ≤ Q_D[(w_0+w_i)^k+(w_0+w_j)^k+(w_i+w_j)^k]`。

其中k=0时左侧为1−α<0，右侧仍为正，上式也成立。将各不等式乘以多项式的非负系数并求和，可得时钟在b对每个玩家的α改善差

`h_i^H(b) ≤ Q_D Σ_T S_T`。

结合保环必要预算和ε_D的定义，

`h_i^H(b) < Q_D 4ε_D/(α−1) ≤ K_min/2`。

于是总游戏在b的α改善差严格满足

`h_i^{G_D+H}(b)=−K_i'+h_i^H(b)<−K_min/2<0`。

每人仅有两个动作，这就检查了全部合法偏离。因此b仍是α-PNE。所有旧资源、私有资源及时钟对都保留全体动作互补对称性，1010同样如此。证明完毕。

### 机制、精确边界与可复核范围

共同私有费用不改变精确成本差，却会减少α>1时的改善margin。它使环余量趋零，同时保持原环外均衡的稳定gap远离零。固定次数时，每单位合法环预算能产生的真实margin有限，所以保环必要总预算无法破坏该均衡。若α=1，除以α−1的构造失效，本命题固定α=21/20，不声称覆盖该边界。

本结果说明真实环余量依赖本身不可从通用保环编译器中删除；它不证明已有充分预算的 `ln(B/η)/ln(1/δ)` 是最优，也不证明任何特选增长族必须失败。D80全三元统一幅度证书与本族没有冲突：它使用未padding的固定输入，环余量没有被压至ε_D。

配套规范审计 `verify_clock_margin_padding.py`，只读取规范JSON的基体、按字面单资源用户群重算；针对D=0,1,2,3,7,20,80,100核查原数据、私有三次资源的恒定费用、全部16态互补、全部8条padding后环margin、κ逐列粗界、真实预算恒等式和稳定gap。一般证明是上文非负列不等式与必要总预算；有限审计不替代任意D的证明。
