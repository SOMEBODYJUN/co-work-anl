# 同费锚定三元时钟的三次保边障碍

## 模型、固定基体和精确结论

成本采用有限加权原子拥塞模型：玩家权重为正且不随资源变化；每人选择一个合法资源子集，成本为所用资源费用之和，不再乘自己的权重。每次偏离固定其他人的动作，并按新用户集合重算负载。α-PNE指全部合法偏离都满足当前成本不大于α倍偏离后成本；严格α改善的margin定义为当前成本减α倍真实偏离后成本。

固定四名玩家，权重为

\[
(w_0,w_1,w_2,w_3)=(1,1/2,1/4,1/8),\qquad \alpha=21/20.
\]

每人恰有动作0和1。每个下表签名引入两个不同资源，两侧费用相同，均为\(zx^3\)。签名0表示不使用该资源对；+表示动作\(s_i\)使用侧\(s_i\)；−表示动作\(s_i\)使用侧\(1-s_i\)。各行资源互异。

| 签名 | z |
| --- | --- |
| (0,0,+,+) | 1593928/421875 |
| (0,+,+,0) | 452978/421875 |
| (+,−,−,−) | 23816/5859375 |
| (+,+,−,−) | 855968/17578125 |

由此得到基体G。动作只合并这些指定资源，不额外给玩家空动作或任意资源子集。

允许的新增时钟为任意有限个资源对，其三元只能是\(T_{012}=(0,1,2),T_{013}=(0,1,3),T_{023}=(0,2,3)\)。在T的局部顺序\((0,a,b)\)中设模式\(p=(0,1,0)\)，参与者i在动作\(s_i\)使用侧\(s_i\mathbin{\mathrm{xor}}p_i\)。所以局部动作010或101恰使三名参与者完全共用一侧。每对两侧必须同费；可为任意次数至多3的非负实系数多项式。不同T可以独立选费，可以为零或省略，也可以重复资源对。它们加入原来的两个动作，不增加动作或玩家。

**命题。** 对任意\(\lambda>0\)，先把G全部费用乘\(\lambda\)，再加任意上述时钟H，得\(G'=\lambda G+H\)。只要\(G'\)在边\(0000\xrightarrow{0}1000\)和\(1100\xrightarrow{2}1110\)上的α-margin均非负，那么在0101和1010，每个玩家的唯一非平凡翻位α-margin均严格负。因此这两态仍是α-PNE。特别地，保留基体全部八条严格α改善边的同次数时钟不能将它锁成全状态无α-PNE。

结论覆盖全部实非负系数，而非有限参数扫描。它只限制这个固定基体、anchor0、指定010/101关联、两侧同费及degree≤3；不排除更高次数、其他anchor/phase、两侧不同费、辅助玩家或其他拓扑，也不排除次数\(D=cp\)且\(c>1\)的其他编译器。

## 环和环外精确均衡

基体有同序双轮环

\[
0000\to1000\to1100\to1110\to1111\to0111\to0011\to0001\to0000,
\]

移动者依次为0,1,2,3,0,1,2,3。前四条真实margin为

\[
(\gamma_0,\gamma_1,\gamma_2,\gamma_3)=
\left(\frac{55201793}{7500000000},\frac{1725121}{234375000},
\frac{248398189}{33750000000},\frac{49676111}{6750000000}\right)>0.
\]

补反全部动作位会交换每对等费资源的两侧，因此后四条margin重复前四条。可是\(b=0101\)有以下当前/真实翻位后成本：

| i | 当前成本 | 翻位后成本 |
| --- | --- | --- |
| 0 | 32540497/375000000 | 37816003/140625000 |
| 1 | 581175629/3375000000 | 373299779/562500000 |
| 2 | 18078389/187500000 | 56643761/70312500 |
| 3 | 158884799/1687500000 | 26108689/112500000 |

每行当前成本严格小于翻位后成本，故b是精确PNE；1010由互补对称性也是精确PNE。相应α-margin为

\[
\left(-\frac{122240519}{625000000},
-\frac{17706129787}{33750000000},
-\frac{234206903}{312500000},
-\frac{1009308211}{6750000000}\right).
\]

因此严格改善环本身不等于全状态无均衡；本障碍明确指出同次数修复仍留下的两个状态。

## 有限列如何覆盖全部允许时钟

设\(W_T=\sum_{i\in T}w_i\)。对每个T与\(k=0,1,2,3\)，考虑一对同费\((x/W_T)^k\)的标准化时钟列\(H_{T,k}\)，共12列。任意\(F_T(x)=\sum_{k=0}^3 a_{T,k}x^k\)恰是这些列按非负系数\(a_{T,k}W_T^k\)的和；有限个重复资源对也并入该系数。由此实非负系数的整个锥被精确覆盖。

对一个资源子游戏K定义\(\gamma_j(K)\)为第j条前半轮环边的α-margin，\(h_i(K)\)为b处玩家i翻位的α-margin，并写

\[
v_i(K)=(\gamma_0(K),\gamma_1(K),\gamma_2(K),\gamma_3(K),h_i(K)).
\]

这些量对资源费用系数线性，叠加资源就相加向量。取四个非负分离向量

\[
u_0=(3,0,0,0,1),\quad u_1=(4,0,0,0,1),\quad
u_2=(3,0,1,0,1),\quad u_3=(0,0,0,0,1).
\]

下面列出基体内积和各T四个次数列内积的最大值；所有基体项严格负，全部时钟列非正。

## 分离证明

非负线性组合给每个i

\[
u_i\cdot v_i(G')=
\lambda u_i\cdot v_i(G)+
\sum_{T,k}a_{T,k}W_T^k\,[u_i\cdot v_i(H_{T,k})]<0.
\]

第一项严格负，全部新增项非正。\(u_i\)的前四坐标非负，仅可能使用第0和第2条环边，最后坐标为1。假设两条总margin\(\gamma_0(G'),\gamma_2(G')\ge0\)，即有\(h_i(G')<0\)。此证明不要求另两条前半轮边非负。两侧同费使新增资源也保留全动作互补对称性，所以1010有相同结论。每人只有一个非平凡新动作，已覆盖全部合法翻位；自偏离自动满足α-PNE不等式。正数\(\lambda\)任意，故基体统一缩放不提供逃路。
