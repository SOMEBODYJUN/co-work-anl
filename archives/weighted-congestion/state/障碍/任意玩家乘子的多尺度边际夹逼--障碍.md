# 任意玩家乘子的多尺度边际夹逼

有限非空玩家集和资源集；玩家权重为任意正实数，每人的非空有限策略族由资源子集组成，允许空策略、异质策略族及零费用。资源负载为使用者权重之和，玩家成本是所用资源费用之和，**不再乘玩家权重**。α-PNE 指每个玩家每个合法单方偏离均满足 C_i(s)≤αC_i(t_i,s_{−i})，偏离后重新计算真实负载；成本零时直接使用不等式。以下各对象保留更具体的范围。

## 精确陈述


固定整数 d≥2，定义

\[R_d(t)=\frac{(d+1)(1+t)^d+t^{d+1}}{d+(1+t)^{d+1}},\qquad
\rho_d=\sup_{t>0}R_d(t).\]

**任意乘子障碍。** 对每个实数 1≤a<ρ_d，存在有限正实权向量
w=(w_1,…,w_n)，使不存在集合函数 F:2^N→R 和正数 h_i，同时对
所有 i 与所有 S⊆N\{i} 满足

\[h_i(w(S)+w_i)^d\le\Delta_iF(S)\le a h_i(w(S)+w_i)^d.\tag{1}\]

F 与 h 可以依赖完整有限权向量，没有匿名性、连续性或统一生成规则假设。


设 κ*_d(w) 是对固定有限权向量使夹逼可行的倍率inf，κ*_d=sup_w κ*_d(w)；不假定乘子inf达到。结论同时给 κ*_d≥ρ_d>d^((d−1)/(d+1))，而构造d因子夹逼给κ*_d≤d，故κ*_d/d→1。

## 完整有限多尺度证明

同端点路径强制相邻尺度乘子增长

假定 (1) 可行。将每个等权类的玩家置换，对 F 及 h 同时平均。
边际不等式保持，故可设每类乘子相同。权为 b_j 的类记 β_j=h_j/b_j。

取一个权 b 的重玩家和 K 个权 εb 的轻玩家，轻重密度比为 s>0。
分别按重末与重先顺序插入这个子集。从空集到同一端点的势增量相同，
而其成本路径和（除以 h_heavy b^d）为

\[A=(1+K\varepsilon)^d+s\varepsilon\sum_{k=1}^K(k\varepsilon)^d,
\quad B=1+s\varepsilon\sum_{k=1}^K(1+k\varepsilon)^d.\]

因此 1/a≤r_{ε,K}(s)=A/B≤a。它对 s 严格递减：写 A=u+sv、B=1+sz，
则 u>1、0<v<z，导数分子 v−uz<0。固定 t>0、K=⌊t/ε⌋，ε→0 时

\[r_{\varepsilon,K}(s)\longrightarrow
R_s(t)=\frac{(d+1)(1+t)^d+s t^{d+1}}{d+1+s((1+t)^{d+1}-1)}.\tag{2}\]

这里只取有限区间上的幂函数黎曼和；不对未知 F、h 取极限。

选 t_0 使 R_1(t_0)>a，再选 λ>1 使 R_λ(t_0)>a。
因为 t^{d+1}/((1+t)^{d+1}−1)→0，能先选小 t_1，再选 B_0>λ
使 R_{B_0}(t_1)<1/a。严格间隙与 (2) 给 δ>0，使 ε<δ 时两不等式
同时成立。递减性说明这些测试分别强制 s>λ 与 s<B_0。

选有限整数 ℓ≥1 使 λ^ℓ>B_0，选 0<q<min{δ,t_0,t_1,1}。
建立权 b_j=q^j、j=0,…,ℓ 的类，每类有
N_j=⌈max{t_0,t_1}/b_j⌉+1 名玩家。每个相邻类测试都能选够
⌊t_0/q⌋ 名轻玩家，强制 β_{j+1}/β_j>λ。
第 0 类与第 ℓ 类也能选够 ⌊t_1/q^ℓ⌋ 名轻玩家，强制 β_ℓ/β_0<B_0，
与前面连乘矛盾。玩家数虽可很大但有限，所有权严格正。这证明第一项。


## 近线性量级与匹配的夹逼上界


取 y=d^{2/(d+1)}、t=y−1，有
R_d(t)>(d+1)y^d/(d+d²)=d^{(d−1)/(d+1)}。
另一方面，集合函数

\[H_d(S)=\frac{w(S)^{d+1}+d\sum_{i\in S}w_i^{d+1}}{d+1}\]

的增量满足 w_i(w(S)+w_i)^d/d≤Δ_iH_d(S)≤w_i(w(S)+w_i)^d：
令 x=w(S)/w_i，将归一化增量展开为
1+Σ_{k=1}^d binom(d,k)x^k/(d+1−k)，逐系数比较即可。
于是 dH_d 提供因子 d 的夹逼；第一项对每个 a<ρ_d 的障碍迫使 ρ_d≤d。
因此 ρ_d/d→1。


## 有理参数的有限构造与压缩核验接口


For rational α,t0 with R_1(t0)>α, all parameters can be rational and finite. One direct selection is

    D0=α((1+t0)^(d+1)−1)−t0^(d+1)>0,
    λmax=(d+1)((1+t0)^d−α)/D0>1,
    λ=(1+λmax)/2.

Then (M5) follows by cross multiplication. Set t1=1/(α+1), which satisfies (M6)'s limiting requirement because

    t1^(d+1)/((1+t1)^(d+1)−1) ≤ t1^d/(d+1)<1/α.

Let D1=((1+t1)^(d+1)−1)−αt1^(d+1)>0 and choose

    C=λ+1+(d+1)(α(1+t1)^d−1)/D1.

Then C>λ and R_C(t1)<1/α. Find finite L with λ^L>C. Search integers Q≥2 until the two exact tests

    r_{1/Q,floor(Qt0)}(λ)>α,
    r_{Q^(−L),floor(Q^L t1)}(C)<1/α

both hold. Convergence guarantees termination. Taking q=1/Q gives the finite construction above. This search need only check adjacent and extreme class ratios, so it does not require explicit δ or uniform numerical sampling.

The test program computes the enormous but finite path sums through the exact recurrence

    S_0(K)=K,
    S_p(K)=((K+1)^(p+1)−1−Σ_{r=0}^{p−1}binom(p+1,r)S_r(K))/(p+1),

where S_p(K)=Σ_{k=1}^K k^p. The integer divisions are asserted exact. This provides compressed finite certificates even when expanding all clones would be impractical. The certificates witness failure of (M1) and do not enumerate pure game states or prove equilibrium nonexistence.


本节保留原始乘子稿的有理参数选择和幂和递推；当前重构的q<min{δ,t₀,t₁,1}确保floor测试至少一人。实际程序用Q依次倍增，并精确检查两个有限测试，不对未知F,h取极限。
