# 资源身份与范围

本对象记录四份冻结上游 Markdown 资源。它们是写作与审计规范，不是 weighted-congestion 模型的数学命题，也不改变任何已有对象的定义、定理或开放状态。legacy-cleanup 与 main 中的同路径字节按冻结指纹视为同一份资源，不重复计算。

四个来源的冻结指纹、大小和完整阅读范围见 [证据清单](../../tools/evidence/mathematical-academic-writing-upstream-20261031/manifest.json)。本轮通过 `clean show` 导出后逐字读取，并与本存档已有的审查、论文和证据目录比较；未运行上游写作工具，也未声称 render-bound 或 execution-bound 验证。

# 资源内容

## 数学学术写作技能说明

`SKILL.md` 将任务分为 draft、analysis、revision、review、verification 等模式，并要求先锁定读者、主来源、记号、假设、量词、支撑证据和验证深度。其核心顺序是数学/统计有效性、范围和证据准确性、来源与记号保真、体裁、直接性、简洁性。它要求把对象—假设—结论—支撑—范围依赖链写清，并把证明、推导、实验、模拟和图示使用不同证据强度的动词。该材料还规定：来源冲突或疑似错误不能静默改写；需要时应标出缺失证据和可达验证层级。

在本存档中的用途是审查 `weighted-congestion` 正文、反例和有限运行时的陈述强度，特别是区分完整证明、条件合同、有限程序结果和未决路线。它不提供任何拥塞模型的新假设或结论。

## 数学完整性参考

`mathematical_integrity.md` 给出逐项检查：对象域与边界、量词和逻辑方向、可容许性条件、等式/界/极限、记号锁定、证据阶梯、数值与图形屏障、来源和引用完整性。证据阶梯把 formal proof、verified cited theorem、exact derivation、worked example、counterexample、simulation、deterministic computation 等分开，并规定不能用模拟或有限数值运行的语言冒充证明。它还要求保留样本/参数/单位/容差等会改变解释的数值，并在修订前后检查记号、假设、含义和证据强度是否变化。

对本存档的接续意义是：任何有限状态枚举、回归输出或数值残差只能按其真实计算范围引用；固定参数、全状态和极限量词必须在正文中显式写出。该参考不替代实际数学推导。

## 研究论文工作流

`research_article_workflows.md` 按摘要、引言/贡献图、相关工作、定理/证明/方法、结果讨论、结论、审稿意见和回复意见给出组织顺序。它要求贡献逐一绑定到问题和后文支撑，使用“we prove/derive/observe/estimate”等与证据一致的动词，区分历史优先、技术依赖、方法比较和经验比较，不从标题或记忆推断文献内容。

本存档可将其用于线性全状态论文和前沿报告的结构检查；它不提供新的相关工作事实，也不允许新增未核验的 novelty 或 hardness 声明。

## 来源与推导审计

`source_and_derivation_audit.md` 规定审计先固定 claim、主来源、辅助来源、要求验证深度与实际达到的 text/source/execution/render 层级；再按 typographical、ambiguous、internally inconsistent、unsupported、incorrect 分类；对每个差异记录位置、原文、问题、决定性证据、范围、权威和修正文案。它要求重建定义域、假设、量词、端点、符号、极限/期望/优化交换和特殊参数，并在来源冲突时保留最小冲突集，不因多数用法或后来的材料默默覆盖主来源。

本存档的用途是审查历史前沿结论、代码输出与论文陈述之间的关系。当前本资源阅读达到 source-bound；没有将任何来源写作规范误当成具体模型的证明。

# 处置与接续

四个来源均为 `retained`/`integrated resource`：其独有内容已由本资源对象和证据 manifest 保全；不建立数学定理节点，不合并到 weighted-congestion 的问题、定理或反例。以后若使用其中的写作流程，仍须对每个具体数学断言重新检查其真实来源、量词、证据与验证深度。
