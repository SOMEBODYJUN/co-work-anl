# 中心面独立投影的有限精确核验

## 源程序和职责

centered_face_independent.py 是退役 topic-selection 的独立 Fraction 程序，源文件大小4,029字节，SHA-256 为8c4290a55b565056972f821900e10af6d96fb89010ec6b04a501f90762e9bc28；legacy-cleanup 与 main 版本内容相同。程序自报不使用 QP optimizer、浮点容差或新颖性断言，默认输出到 stdout；本次运行将输出重定向到新的 evidence 文件，没有覆盖冻结源。

程序将支持图的所有完美匹配排列顶点写成 0/1 向量，在这些排列顶点的仿射方向上做精确 Gram 投影；随后检查行和、列和、方向正交及最小坐标。输入边必须构成有完美匹配的相对内部支持，且所有边都必须被至少一个完美匹配覆盖；非法边界 \(n=1,\) 空边和越界边均应抛 ValueError。

脚本还断言 singleton centered、star4 minimum=0、odd_subdivision minimum=−1/28，并对非法边界输入验证抛 ValueError。输出 JSON 的 limits 明确为 finite exact checks; no general classification or novelty claim。

## 方法含义与限制

这是排列顶点凸包所在仿射面的欧氏投影；方向由顶点减第一顶点后做独立化，Gram 方程使用 Fraction 高斯消元。投影满足行和/列和为1且与所有方向正交。它支持的是三张具体支持图的中心面几何核验，不是所有二分图支持的中心投影非负定理。

与 Nash v2 的局部势、pathwidth/K4 有限审计相比，本程序只处理支持图排列面几何；它不检查势函数、KKT、精确 NE 分离或 RM+ 收敛。与 budget-games 的克隆合并/超梯度对象相比，它没有克隆不变性、连续偏好或预算均衡量词。不能由 star4 centered 推断所有 star 或所有树支持图 centered，更不能由 odd-subdivision 单例推出一般困难性。

本次仅运行源程序的固定三例和非法输入断言，没有扩展随机样本、没有重建一般分类、没有外部同行审查或新颖性认证。处置为 finite-exact-audit：将源程序和运行 JSON 放入 local-potential-games evidence，正式审查仍保留有限范围。
