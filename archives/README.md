# 研究存档目录

第一阶段实读确认四个主要问题家族和一个独立数学工具专题；不能按用户回忆或目录数量宣布“三个问题已解”。

- [主动原子客户的两阶段设施博弈](facility-games/README.md)：共同目录双设施φ与任意设施数因子二已有内部证明和独立稿件；一般异构二仍候选，部分结构ρ已证明。不能概括成整个设施家族已解。
- [顺序客户吸引的半覆盖](customer-attraction/README.md)：一般半覆盖与六人仍OPEN；五人已有完整类型域精确计算机辅助证明。原文与审查的独立性边界需阶段二逐项整理。
- [加权原子拥塞博弈的近似纯均衡](weighted-congestion/README.md)：原Cd/log d全类存在目标已有内部严格否定；有限d精确阈值与后续结构发展未全闭合。旧问题页仍有OPEN表述，须追读后续。
- [不相关并行机突破因子二](unrelated-machines/README.md)：当前暂停，原目标及一般反面均未闭合。配置LP gap=2只否定对应比较合同，不能当作原题困难性。
- [正占用核的表示与交互阶数](positive-kernels/README.md)：有内部秩暴露面、锐预算和闭包结果；尚无通用均衡桥。来源于拥塞工具不等于逻辑推出任何均衡目标。

以上保留阶段一的家族入口。双设施φ稿件具体修订的当前定向审查范围，以阶段二正式正文为准；“已有稿件/内部推导”不等于所有版本已经独立认证。

## 后续允许新增的方向

旧退役选题中还有真实的公平分配/chores、拟阵交换与girth、相关间隙、BMKP与预算克隆等数学材料；学习目录也有独有证明和模型。它们全部在冻结来源清点里，阶段二逐份读取后按真实问题创建新存档或子存档，不能因“退役/学习/历史”而整类丢弃，也不能在未读正文前虚造已解档。

父问题下的具体范围用subarchives；跨模型通用工具可以独立成工具存档。子档之间只有在第三阶段读证后才建立逻辑、迁移或启发关系，目录从属本身不是证明依赖。
