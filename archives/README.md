## 后续允许新增的方向

旧退役选题中还有真实的公平分配/chores、拟阵交换与girth、相关间隙、BMKP与预算克隆等数学材料；学习目录也有独有证明和模型。它们全部在冻结来源清点里，阶段二逐份读取后按真实问题创建新存档或子存档，不能因“退役/学习/历史”而整类丢弃，也不能在未读正文前虚造已解档。

父问题下的具体范围用subarchives；跨模型通用工具可以独立成工具存档。子档之间只有在第三阶段读证后才建立逻辑、迁移或启发关系，目录从属本身不是证明依赖。
