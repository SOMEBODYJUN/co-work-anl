# 顺序客户吸引的半覆盖

存档ID：`customer-attraction`。

有限单位客户、有限共同主题目录，提供者顺序观察完整有序历史各选一主题，客户价值在最终覆盖者间均分。当前目标恰六人每个完整历史纯SPE覆盖数至少为最优六主题覆盖数一半；一般人数为父问题。

## 原始状态与待整理边界

一般半覆盖与六人仍OPEN；五人已有完整类型域精确计算机辅助证明。原文与审查的独立性边界需阶段二逐项整理。

这是实读来源的阶段一定位，不是重新证明或状态升级。

## 内容位置

- [问题身份](问题--问题.md)
- `state/`：按数学对象类别组织自足Markdown，可随清洗增加新类别。
- `workspaces/`：Boss/清洗者个人临时研究，可自由保存未成熟内容。
- `papers/`：论文稿件及其必要依赖，保留与正式数学对象的对应。
- `tools/`、`evidence/`：本题计算程序、真实输入与核验证据；说明对象放state对应类型。未来确有需要再接本题Agent/CLI，不预装空运行时。
- `prompts/`：本题启动、当前任务与后续Agent选择；当前不强行部署求解Agent。
- [本层超图](map/README.md)：阶段三逐边建立，详细对象仍链接本存档正文。

当前阶段一脚手架；源文件没有因为已被分配到本目录就算清洗完成。
