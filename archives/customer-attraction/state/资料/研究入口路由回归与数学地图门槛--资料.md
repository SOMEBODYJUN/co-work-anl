# 研究入口路由回归与数学地图门槛

## 来源性质与测试夹具

`tests/test_active_research_routing.py` 是仓库入口检查器的隔离回归，不定义客户模型、均衡或覆盖定理。每个测试在临时目录复制 `research/active_research.json` 中的入口、角色提示词、运行手册、程序、提交器、退役原件清单、数学入口和兼容重定向；再把 `research/check_active_research.py` 的 `ROOT` 指向该临时目录。这样测试可改写副本而不改变实际工作树、冻结原件或正式数学正文。

夹具还为 Markdown 本地链接补建目标文件，以便测试只攻击路由检查逻辑。它不凭空生成证明内容；若目标原文件在真实仓库中存在，才复制或触碰相应临时目标。

## 通过与拒绝的路由合同

`test_current_routes_pass` 要求当前检查器确认活动目标为 `Q-CAG-HALF`、存档为 `customer-attraction`、角色集合恰为 `boss/cleaner/editor`，并且存在至少一个本地链接。其余测试向隔离副本注入错误，要求检查器抛出特定 `ValueError`：

| 注入变更 | 约束被保护的对象 |
| --- | --- |
| 程序或提交器默认从 `customer-attraction` 改回旧 `shared` | 独立运行与 checkpoint 默认不得回退旧题 |
| 旧绑定被接入 unrelated-machines 新提示词 | legacy save 与新题 prompt 不能混绑 |
| 兼容重定向追加旧任务文本 | 退役角色不能复制当前任务 |
| 角色表新增 reviewer 或把 editor 指向 cleaner | 当前角色数和角色 receipt 必须与清单一致 |
| 退役原件追加字节 | 归档原始字节保持不变 |
| README 加入旧题无条件主攻行 | 根入口不得出现 stale unconditional 指令 |
| README 或数学入口增加断链 | 活动导航中的本地链接必须存在 |
| 数学入口旁新增未登记证明文件 | 新共享数学文件必须出现在数学地图入口 |
| 个人 workspaces 新增未完成草稿 | 私人草稿不强制进入共享数学图 |
| 删除数学入口所指文件 | 不能留下 broken active navigation |

`test_new_shared_proof_requires_a_mathematical_map_entry` 特别区分共享数学文件和个人草稿：新证明文件先被检查器拒绝，写入数学入口链接后才通过；工作区中的未完成个人推导则不触发共享地图要求。

## 与既有入口和历史记录的比较

`research/check_active_research.py` 是实际被测程序；`research/active_research.json` 提供活动入口、角色、旧存档归档和兼容重定向的 manifest。`research/CATALOG.md` 将该测试列为“新题默认、角色正文与导航失效的隔离回归”，并明确其是有限计算核验、不代替一般证明。历史 `research/customer_attraction/CURATION.md` 记录过 14 项通过及入口/链接/退役字节检查数量；本次只实读测试源和相关入口说明，没有把历史计数当作本次重跑结果。

该测试与 `tests/README.md` 的四个数学复现入口不同：前者保护研究入口、角色和数学地图路由，后者只规定有限证书测试命令及 evidence/runs 位置。两者都属于复现基础设施，不能因测试通过而改变任一数学对象的真值、证明状态或模型身份。

## 处置与接续

本来源 `integrated` 到本资源对象，保留其独有的隔离副本方法、旧题回退阻断、角色 receipt 对齐、退役原件字节保护和共享数学地图门槛。它不是 CAG-HALF 的定义或证明；第三阶段只能把它作为“工作流回归—数学入口完整性”资源节点，不建立通向覆盖定理的推导边。未来若修改 `active_research.json`、角色文件或数学入口，应在新临时副本中重跑这组回归，并将实际退出状态与版本哈希写入 tools/evidence，而不是复用历史 `CURATION.md` 的通过数字。
