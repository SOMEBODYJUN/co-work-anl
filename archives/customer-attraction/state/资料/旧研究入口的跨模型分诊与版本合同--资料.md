# 旧研究入口的跨模型分诊与版本合同

## 资料身份与读取范围

这是一份CAG时期的**全仓历史入口资源**，不是共同数学模型或新定理。载体置于客户吸引存档只表明当时主攻的历史语境；设施、拥塞、调度及退役选题各自独立，不能由路径从属推断模型包含或逻辑依赖。四份主源全文已读：`ROADMAP.md`保研究量词和自由路线；`questions/README.md`保九行问题分诊；`GROWTH.md`保共享数学资产与个人备份的不同合同；`BRANCHES.md`保六分支收口的具体来源定位。另一本批主源Q-CUBIC有独立[自足问题页](../../../facility-games/subarchives/nonlinear-costs/state/问题/立方客户费用的共同目录普遍阈值--问题.md)。

本文比较已有正式对象的实际适用范围和当前记录状态，没有重审所有被链接长证明或重跑其有限审计；逐对象全文或选区范围记在[比较manifest](../../../../tools/evidence/facility-front-primary/comparison-manifest.json)。旧页“唯一主攻”“只用main和wcg/board”“三个角色”等属于来源当时的调度语境，不覆盖现行AGENTS及结果分支规则。

## 旧路线保留的真实数学义务

旧Q-CAG-HALF是：有限单位客户、有限非空共同主题目录，任意正人数$m$名单位提供者顺序观察全部有序历史各选一主题；终局客户价值在覆盖者间均分；对**每份完整历史纯SPE**证明$2W\ge\operatorname{OPT}_m$。空主题、重复选择、零客户及任意离轨历史平局均保留。当前清洗树主攻是其**恰六人**实例，一般人数作为父问题仍保留；不能用旧“任意人数”指令替换当前任务范围。

[完整模型](../定义/共同目录完整历史模型--定义.md)解释为何必须沿给定策略的真实偏离后继，而不能冻结在轨后继。旧路线提出的未闭合义务是利用真实早期偏离与后继最优性控制根遗漏覆盖；若沿安全值、策略锥、运输或支付接口，需要跨节点的全局补偿。已有逐步非负、逐人保底或根总税反例排除相应桥，必要条件模板坏点并非原博弈反例。原目标反例必须给实际单位客户与同一份完整SPE证书。

这张路线没有固定数学方法、名额、研究工具或能力上限；有限实例只检验具体候选，LP、算法或枚举不是默认任务。旧“三四人定理不继续特例扩张”是当时主攻安排，不否定其他资料的保存价值。[五人半覆盖](../定理/五人半覆盖--定理.md)已有全类型精确证书；[至多六极大覆盖](../定理/六极大联合预算半覆盖--定理.md)的“六”是目录中不同包含极大覆盖数，不是任意目录的六名提供者。二者都不能把恰六人任意目录目标勾为已解。一般研究方向审查还保留[跨前缀共同支付缺口](../审查/一般半覆盖研究方向复核--审查.md)。

拥塞下界否定旧目标的逻辑是其排除倍率与$d/\ln d$之比随$d$无界；它不是把设施费用立方当作拥塞次数$d=3$。同理，设施的存在完整客户NE选择与CAG的每份全历史纯SPE是不同量词。该表是来源分诊关系，不产生跨题的数学推导边。

## 共享入库与个人备份的不同合同

`GROWTH.md`保留的核心是每份可复用资产沿“前提、推导、算法、证据、限制”恢复。它不要求每个纯理论结果必须有软件；而是实际存在算法或实验时，证明和证据合同都可追踪。每个命题有中文数学名、读取条件、精确ID、全部同时成立的假设；同文不同命题分别保量词和审查等级。目录按内容作用，不按作者、Boss、ZIP或提交者代号组织。

| 内容 | 原合同及现树承接方式 |
| --- | --- |
| 未解问题、反例搜索、待审证明 | 一题写清输入类、目标、量词、已知边界及缺口；现树保相应`state/问题`、`想法`、`候选`等实际类型，不因旧`questions/`路径就认定未解 |
| 可审陈述和证明 | 先定义对象和全前提，再写定理、关键引理、依赖、核心推导及未消除义务；历史原段的复制不构成新的自足证明 |
| 程序 | 按输入和输出合同有唯一规范实现；两设施与任意设施数原有并列包，改变费用模型须独立合同。声明位复杂度、失败行为及输入限制，不用一个包容纳不相容模型 |
| 学习讲义 | 连接实际定义和证明，不能把教学重构当外审或把未重新写出的原已证结果退为数学开放题 |
| 输入、证书、运行 | 输入与输出证书分开，报告实际版本、种子、规模及未核范围，不覆盖冻结记录。有限通过、达到证书、最优性证明和普遍定理分别标记 |
| 独立核查 | 检查关键假设边界与输出声称，独立oracle不调用被测同一求解核心；探索审计不因文件名带test而成为一般证明 |
| 外来稿、历史源码与过时推导 | 留原状态、源路径与替代对象；旧稿不作为当前命题的唯一入口，独有未完成数学仍应保留 |
| 个人备份 | 未完成、未核验甚至错误尝试均可持续保存，README留问题、当前材料、卡点和恢复路径；普通备份不以共享入库检查为门槛，也不要求每次发公屏 |

正式共享流程是问题合同、自足稿、必要规范程序及独立检查、逐命题登记、实际受影响的入口和关系，最后运行对应检查。原`claims.md`、`review_status.json`、`assets.json`、`graph.json`、`source_crosswalk.json`、`catalog.json`及`learning/manifest.json`各有不同作用：命题身份、逐命题五轴状态、资产、带全部共同前提的超边、来源对照、名称读取条件及教学入口。原`build_catalog.py`、`check_wc_assets.py`、`build_map.py`、`build_crosswalk.py`、`check_assets.py`等是旧结构工具名，本批没有把它们当现树必须运行的命令，也没有虚报执行。

同一ID的费用、实例类、续局选择量词不能悄悄扩大；范围改变建版本并解释旧版本是否仍真。分别记录原主稿完成度、现行Markdown覆盖、内部审读、外审、软件实现；原稿与新稿冲突先保冲突和问题，实际消除反驳后才升状态。测试通过和Git发布都不自动升级数学真值。图中有限检查、反例、推导分别标语义，不能把checks或attacks改为derives。现树阶段二正文和阶段三超图分开，关系需逐条解释共同前提和真实证据。

源文的main统一保存、一个对话一clone、不创建研究分支、根README短地图、日期进展另存等均保为当时协作合同。本轮现树的结果分支和公屏名称从当前AGENTS读取。旧入库指南与既有[治理入口审查](../审查/customer-attraction治理入口与账本边界--审查.md)有内容重叠，但本页具体保留旧全仓的版本规则、模型分包和九行跨题分诊，不仅写“治理重复”。
