# 用途、边界与第三阶段关系

该资源的可复用用途是：

1. 通过 `original_path` 和 SHA-256 追踪旧入口的确切版本，解释为何旧相对链接不能在当前目录直接运行；
2. 区分“导航/操作提示被替代”和“数学 claim 被退休”，防止历史切换被误读为证明删除；
3. 给第三阶段提供历史来源关系：历史入口可作为来源/迁移边，但正式对象和当前证据必须指向规范地址。

该资源本身不包含新的数学证明、反例、算法或六人 SPE 结论。`customer-attraction` 的实际定义域、量词、纯 SPE 结果、有限证书与开放问题仍由当前 state 对象和 evidence 目录承载。其他 weighted-congestion-frontier 历史 prompt 也保持独立存档身份，不能因迁移目录而混入客户吸引模型。
