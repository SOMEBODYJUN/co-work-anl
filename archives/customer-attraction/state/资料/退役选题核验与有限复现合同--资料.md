# 退役选题核验与有限复现合同

## 资料身份与读取边界

VERIFICATION.md 是 retired_topic_selection/independent_review/research/topic_selection 的工程和数学资产核验报告。它把工程回归、有限数学重放、参数反算、导入合同边界、仓库登记和文献/新颖性状态分开。原始候选记录共45条，包含跨线同题和版本重复，不能当45个互异开放问题；结构审计也不自动证明来源事实或数学结论。

冻结来源在 legacy-cleanup 提交 68fad804ec5946cb296f77dc5b336308a66abf12 与 main 提交 aefc58eac3fc6eb5d7a47d087dd2c62b5aa9974c 内容相同。原文件大小6,373字节；本批完整实读正文、脚本表、输出含义、安全复现规则和 boss17 合并范围。它是跨模型的资料对象，不能因为历史载体位于 CAG 入口就迁入 CAG 数学主线。

## 工程与登记核验

报告记载 work 23、checkpoint 47、board 27、collaboration 17，共114项工程回归通过。这些检查覆盖本地隔离Git remote、新分支首发、恢复、独立公屏、main保持不变、scope与凭据审计等。它们验证协作程序和登记合同，不是任何数学命题的证明；不应将114 passed写成数学覆盖率或外部审查。

仓库登记检查了 catalog、map、crosswalk、assets 和旧 main active-routing 合同。旧 active-routing 仅保兼容；新题实际路由仍由显式 branch/save/board 和启动回执核实，不能混称为同一合同。第一阶段工程/导航 checkpoint 8cc87ba84e429968e4acdc08f07c20b760015289 是工程状态，不是数学突破。

## 各子线的有限数学资产

- **Atomic games。** toy_checks.py 的 toy_output.json 检查改进环、短策略有限动态、有限LP势和格外失败；SciPy只提候选，证书用 Fraction。
- **Nash equilibria。** toy_checks.py 和 toy_checks_v2.py 重放单步恒等式、噪声、导数和宽三图证；旧版本未覆盖的范围不能从 v2 名称推断。
- **Fair goods。** toy_checks.py、copies_exhaustive.py、verify_frozen.py 覆盖 K8/K12 随机估值、copies有限穷举和五个冻结极小证书的标量重算；不构成一般 EF1/SD-EF1/MMS 定理。
- **Fair chores。** construct_rank2.py、mixed_extension_toys.py、rank_toys.py、rank2_cap_toys.py 的秩构造、图定向、带配额MMS和 rank-cap-2 toy 必须区分。两类触达数与 rank cap2 不是同一模型；对应两平行类引理、cactus障碍和有限结果已在 fair_chores 审查对象单独处置。
- **Generalized assignment。** toy_audit.py 的 transversal、pair穷举、joint交换和参数反算，只是接口玩具，不是完整BMKP算法实现。
- **Cross-field battle。** toy_checks.py 的9,216 copies profiles、12,825 rank2 word multisets和K8随机1,000例是独立整数检查；有限值域不替代任意权重或全域证明。
- **Capacity import contract。** complete_rounding_capacity_counterexample.py 的精确可分解/完整整数可行性区分，只否定“所有物品必须完整装入”的字面子合同，不否定允许 unused 的BMKP定理。

每个脚本的固定 seed、域和输出均由原源与冻结 evidence/runs/topic_selection/记录；生成候选 JSON 的短期脚本不作为数学资产保存。没有把“无反例”或少量通过写成全域存在性，任何有限样本都不产生新颖性认证。

## 安全复现合同

源要求把相应 tests/audits/topic_selection/<line>/ 子目录的 Python 脚本复制到新的临时目录，在那里运行，避免覆盖冻结 JSON。verify_frozen.py 需要同线的 toy_results.json 和 copies_exhaustive_results.json 作为只读输入；广义指派脚本要求临时目录有 evidence/ 子目录。依赖是标准库、NumPy，原子势 LP 另需 SciPy；版本写在 selection_validation.json，换 Python/NumPy/SciPy/Git 后应重新核对 Fraction 证书，不能只接受浮点LP输出。

工程回归命令按报告逐一替换测试 pattern，包含 test_work.py、test_checkpoint.py、test_board*.py 和 test_collaboration*.py。命令和参数属于历史复现合同；本对象没有重新运行这些测试，也不把报告的通过字段当本轮新实验。
