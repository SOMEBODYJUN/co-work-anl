# 来源对象与当前数学身份

本对象整理一份5556字节的一般付款工作稿。它不是完整half证明；独有内容是把已闭合的端点重选、静态信用和局部操作放回各自的域及同一source预算，明确指出当时真正停止的位置。原文的旧作者身份与“六名研究员”是历史记载，不是本轮身份或后台运行声明。

模型始终为有限单位客户、有限非空共同主题目录，m名单位提供者按全部有序历史顺序选择主题，终局客户在覆盖者间均分；保空主题、重复选择、零客户与任意离轨平局。固定任一完整纯SPE σ、实际叶 B、实际收益 u_i 和覆盖 W=Σ_i u_i；OPT_m为m个目录主题的最大覆盖。恰六人的目标仍要求**每份**完整纯SPE均达到half。本资源中的所有存在性、同构和有条件付款均不替代这个全称目标。

# 重选孩子与扩大分析域是不同合同

在实际前缀 h_i 强制主题 A 后，可考虑全部完整孩子SPE见证。实际行动 A=B_i 只保原实际端点。若每个所选备选孩子都逐叶满足进入者 d_i≤u_i，不同first-deviation子树互不相交，逐个替换仍保实际路径和实际节点IC，因而可拼成同一实际叶的完整纯SPE。

逐叶cap凸包、逐行动均值cap、全行均值cap则是三种依次放宽的分析对象；均值可行不保证每个端点逐叶过cap，也不声称整份彩票可执行为纯或混合SPE。实际tag限制和见证身份保留，后继的IC只属于该见证的真实偏离。准确三域及其双式见[可信端点三域](../引理/可信端点均值cap的三域与松弛信用--引理.md)。原source仍可取原σ，不能因为背景重选而默换source。

# 一份原source共同账及其未证金额

在所写全行均值cap背景域的同一共享最优点，令 L 为删除进入槽后平均负载，t_x=1/(1+L_x)，p支持最大主题t价格，ρ_x=Pr_p[x∈A]，w_x=ρ_xt_x²，γ=max_TΣ_{x∈T}t_x。L为行动质量m−1的合法分数目录负载，故

\[
Q_{\rm stat}=(m-1)\gamma-\sum_xL_xt_x\ge0,
\qquad \operatorname{OPT}_m\le(2m-1)\gamma-Q_{\rm stat}.
\tag{STATIC}
\]

后式逐客户用 1_{c_x^*>0}≤(c_x^*+L_x)/(1+L_x)，再对最优m主题各用最大价格γ。Q_stat是既有静态余量，不是一份新的实际利润。

每行shadow LP有 μ_i≥0、η_i，使对该域全部端点 w·ell_i≤η_i+μ_i d_i。原source强制主题后仍沿原σ，定义

\[
I_i=u_i-E_pd_i^{\rm orig}\ge0,\quad
R_i(A)=\eta_i+\mu_i d_i^{\rm orig}(A)-w\cdot\ell_i^{\rm orig}(A)\ge0.
\]

其对偶差只有一份

\[
G=\sum_i\mu_iI_i+\sum_iE_pR_i(A)\ge0.
\tag{CREDIT}
\]

η_i可负，μ_i u_i不是第二份actual利润。写原source负载为ell_i^0(A)，具体定义

\[
D=\sum_iE_{A\sim p}\sum_{x\in A}
\frac{t_x^2(\ell_i^0(A)_x-L_x)^2}{1+\ell_i^0(A)_x},\qquad
\operatorname{Cov}=\sum_iE_{A\sim p}\sum_x
(\mathbf1_{x\in A}-\rho_x)t_x^2\ell_i^0(A)_x.
\]

它们分别是同一L上的倒数精确余量和原query中心化线性功；详见[定量付款问题](../问题/真实重放协方差的定量付款--问题.md)。同一倒数展开给

\[
W-m\gamma=D-\operatorname{Cov}
             +\sum_i(1+\mu_i)I_i+\sum_iE_pR_i.
\tag{SOURCE-BAL}
\]

因此足够但仍未证明的金额界为

\[
\operatorname{Cov}\le D+\sum_i(1+\mu_i)I_i+\sum_iE_pR_i
                         +(\gamma+Q_{\rm stat})/2.
\tag{PAY?}
\]

一旦同域同source上(PAY?)成立，2W≥(2m−1)γ−Q_stat≥OPT_m。上面没有除γ或W，零客户亦保留。域的紧性、强对偶、G的非负或有限搜索尚未分离，都不证明(PAY?)。

# 原稿还保留的未成熟入口

原工作稿另列单query凸化、条件信息以及正loss交换：有限Doob能量或Vp≤γ本身没有支付累计prefix乘子；静态slack正确也不提供一个可行且改进shadow的孩子交换。这里保存其**原稿所述停界**，没有把这些导航条目冒称本批分别完整重审了对应原稿，更未新增对这些来源的done。

最后一条direct工作稿入口将TAN-PAY集中到某个实际负载银行，并声称在其KKT合同内可限为γ/2；本批未读其direct正文，故只保该入口与待查合同，不把导航中的一句话升为通用PSD/SPE或已证付款定理。精确原路径完整保留在[主源原件](../../tools/evidence/common-payment-working-primary/original/GENERAL_PROOF_WORKING.md)，接续必须实际读取其定义、系数及映射义务。

原稿还明确Popt/Rep/Out类等价重述不产生新钱，并允许换路直接支付OPT−W；本资源不把某一候选失败扩大为所有方法不可能。未成熟内容按这个精确缺口保留，不因未闭合而退休。
