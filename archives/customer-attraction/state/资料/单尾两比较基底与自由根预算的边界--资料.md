# 一位剩余玩家的准确总覆盖基底

在[共同目录模型](../定义/共同目录完整历史模型--定义.md)固定任意合法非空旧有序历史，客户旧负载b_x≥0为整数，旧并集P={x:b_x>0}；旧历史可能全为空主题，所以P允许空。仅剩一位玩家，在所有合法主题中取真实最佳回复C。记δ=|C\P|，u=Σ_(x∈C)1/(b_x+1)，总福利W=|P|+δ。这里W包括过去全部覆盖，不是只剩余玩家利润u。

新覆盖客户各付1，旧覆盖客户分母至少2，故

\[
u=\delta+\sum_{x\in C\cap P}\frac1{b_x+1}\le\delta+|P|/2.
\]

对任意两个合法比较主题T₁,T₂（可重复/为空），末位改选T_j时每个T_j\P客户都给1，其他收益非负，因此真实BR给|T_j\P|≤u。于是

\[
|T_1\cup T_2|\le|P|+|T_1\setminus P|+|T_2\setminus P|
\le|P|+2u\le2(|P|+\delta)=2W.
\]

这不需无平局或非零客户，不除W，P空时也全真；旧负载任意大亦不改式。根稿3307B将它作为更强背景归纳的r1基底，不认领新颖性或原half新已证范围。当前[任意背景两尾三比较定理](../定理/两名剩余三比较任意背景半覆盖--定理.md)已有**另一个更宽局部接口**；它用两名真实玩家与三比较的共同S,Z,V,L余量权重6,1,2,5，不是这个简单r1证明免费归纳而来，也不是五名尾部/六人主定理。

# 自由根与已经付费的根修复不同

root-only计划τ要求每个正深度子博弈都是完整有序历史纯SPE，只根指定动作可任意。固定该完整菜单，W是指定根动作后的覆盖，Δ=max合法根动作真实收益−指定根收益≥0。已有常数三root保险把HALF(m)与全体这种root-only计划的稳健式O≤2W+3Δ等价；构造是合法全历史工具，不证明式子无条件对一般m成立。

更强FREE-ROOT不付根regret，直接要求O≤2W；其空根augmentation后果用k个理性尾部比较OPT_(k+1)，以及根空tight等号族，均已有R2d91来源。原R65起初独立想同候选，父方定位旧稿后归还身份，本批不重认首创。

[现子树价格归纳](../候选/真实子树价格向量的共同静态背景归纳--候选.md)完整保该root-only菜单和紧族：根选合法空，r名尾部在所有历史选含r客户的大主题A，另r个互不交单客户主题；各尾部A收益r/c_A≥1而单客户偏离≤1，故正深度SPE，W=r、OPT_(r+1)=2r。其它根孩子可各贴完整BI。等号族说明若FREE成立其常数不能统一严格提高，不证明普遍FREE；一般m/恰六人没有由它闭合。五人half已另证时，付费稳健式可条件接出，这是后来的状态，原2026-10-24未证明原half/稳健预算的事实保留。
