# 零源与特定回放松弛不能支付末主题重置

## 准确量词与完整原模型

采用单位客户、单位提供者、有限非空共同目录与全部有序历史纯SPE。客户均分，终局收益u、福利W；调和势Phi_b定义及精确删除边际见[三主题重置对象](末主题提前的势下降与新枝重置税尖锐性--反例.md)。在任意真源h，余k人，实际叶z的末主题C提前源后沿同一σ所得真叶zC；源IC松弛Γ=u_source(z)−u_source(zC)≥0。

被否候选是Phi_b(z)−Phi_b(zC)≤(k−1)Γ；下面Γ=0、势差1，所以**任意固定有限实系数乘同一Γ都失败**。另可同时否定对本文这条特定回放链的IC松弛作任意有限加权的付款。并不否定所有其他真IC组合、共同报价或跨枝信用。

## 七名单位客户与21节点策略

主题A,B,C,D，客户类型：仅A一名、仅C两名、B/C两名、A/B/D两名。根A，第二人见A/B/C/D后分别B/C/D/B；第三人完整表：

| 首/次 | A | B | C | D |
|---|---|---|---|---|
| A | C | C | C | C |
| B | C | C | A | C |
| C | B | A | A | C |
| D | C | C | C | C |

(A,C)与(C,A)同计数，末位分别C/B；平局依历史保留。每个客户类型M的n_M名不同客户，对选择a_i的玩家贡献 $n_M/\#\{j:a_j\in M\}$（a_i∈M时）。按定义代入末位16行全部合法行动，指定动作均最优；本批报告完整保存16×4个有理值。第二人真实偏离值按A/B/C/D：

| 首主题 | 真实续局下的四值 | 规定 |
|---|---|---|
| A | (3/2,2,2,1) | B |
| B | (2,5/3,3,1) | C |
| C | (2,2,2,2) | D |
| D | (2,2,2,1) | B |

根真实四值(2,2,2,1)，规定A合法平局最优。21个有序决策节点全部最优，是完整纯SPE，不只认证一条在轨路径。

实际z=(A,B,C)，收益(2,2,3)，W=OPT_3=7。原末C提前后zC=(C,D,C)，收益(2,2,2)，W=6；源收益2→2，Γ=0。客户类型逐项给
\[
 \Phi_0(A,B,C)=9,\qquad\Phi_0(C,D,C)=8.
\]
势差1>任何有限系数×0。将每类客户复制正整数t次，所有节点收益同比例、完整最优性不变，Γ=0、势差t；实际W=OPT=7t、提前枝W=6t。此为解析整数族，非浮点小误差；不是一般或六人half反例，两个所列分支福利也都满足half。

## 正确新枝税等号，及特定回放链的零松弛

固定提前C作背景，新末两人(D,C)。强PAIR给
\[
 \Phi_0(A,B,C)-\Phi_0(C,D,C)
 \le\sum_{x\in D\setminus C}{1\over(\mathbf1_C(x)+1)(\mathbf1_C(x)+2)}.
\]
D\C恰两名A/B/D型客户，不在C中；右边2/(1·2)=1，准确支付势差。缺的不是局部强PAIR，而是把这个新枝税接到同一实际福利预算。

现在只沿“提前C后回放原主题”的指定链：在(C)节点强制第二人选原A，末位真实回复B，叶从(C,D,C)变(C,A,B)。第二人的D与A收益均2，IC松弛0。最后节点当前B就是所回放的原第二主题B，松弛也0。删第二人后前后叶(C,C)/(C,B)，其势分别6/7，删位势变化1；最后删位势变化0。因此任意有限乘子的源Γ和这两个回放IC均只能付0，而有符号reset为(1,0)、总势差1。

这精确限制了付款失败的作用域：同一源IC加**这条回放链**的IC不足；没有证明全部完整树IC的锥不可能付出，也没有排除不同钱包或报价。三主题族源Γ=1/2而本例Γ=0，两者参数及策略不可互换。
