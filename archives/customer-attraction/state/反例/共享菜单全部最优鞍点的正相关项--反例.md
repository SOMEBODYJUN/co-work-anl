# 对象与被否定的准确加强

有限单位客户、有限非空共同目录，m名单位提供者；固定一份全部有序历史上的完整纯SPE σ，保空主题、重复行动、零客户和任意平局。实际位置i强制主题A后沿同一σ完成，删掉当前i槽的其余m−1槽客户负载记ℓ_i(A)，其真当前收益为d_i(A)=Σ_{x∈A}(1+ℓ_i(A)_x)^{-1}≤u_i。设
\[
 K=\frac1m\sum_i\operatorname{conv}\{\ell_i(B):B\in\mathcal S\},
 \quad F_p(L)=\sum_x\frac{\rho_x}{1+L_x},
 \quad\rho_x=\Pr_{A\sim p}(x\in A).
\]
每个L是m−1份合法目录行动的分数负载。对一个真正max_p min_{L∈K}F_p(L)鞍点(p,L*)，令γ=F_p(L*)、t_x=(1+L*_x)^{-1}，定义
\[
 I=\sum_i[u_i-\mathbb E_p d_i(A)]\ge0,
\quad C=\sum_i\mathbb E_p\sum_{x\in A}t_x^2(\ell_i(A)_x-L_x^*),
\]
\[
 D=\sum_i\mathbb E_p\sum_{x\in A}
 \frac{t_x^2(\ell_i(A)_x-L_x^*)^2}{1+\ell_i(A)_x}\ge0.
\]
精确倒数展开给W−mγ=I−C+D。欲证明W≥mγ只需C≤D+I；欲经静态价格界证明half，可进一步放宽至C≤D+I+γ/2。下例只反驳**C≤0**，且排除通过有利选择最优鞍点或角色运输来修复这个符号。没有反驳这两条完整付款条件。

# 原银行输入及完整策略身份

沿用已证[笛卡尔银行完整策略](笛卡尔银行完整根菜单的低值自洽分布失败--反例.md)，不是新造游戏。一般m≥2有m个经济客户e_0,…,e_{m−1}，m−1个互不交的双客户银行块B_0,…,B_{m−2}，目录含所有(a,b)={e_a}∪B_b。终局经济/银行占用人数n_a,n_b下利润是1/n_a+2/n_b。

为使本页的SPE前提可核，完整控制器如下；“新”均按此前完整有序历史判断，规定中的最小未用按固定标签序。

| 模式 | 规定及实际偏离后的更新 |
|---|---|
| 根 | 规定(0,0)；任意真实根动作都作锚进入BASE |
| BASE非末位 | 复制锚经济、取最小新银行；不等规定联合动作时，新银行转PUNISH并固定此次银行为目标，旧银行转EXIT |
| BASE末位 | 取最小新经济、复制锚银行 |
| PUNISH非末位 | 两坐标各取最小新标签；新银行继续且目标不变，旧银行转EXIT |
| PUNISH末位 | 新经济、复制固定过去目标 |
| EXIT | 此后始终两坐标各取最小新标签 |

EXIT已有银行重复，余人足有新银行，指定者得3达到上界。PUNISH末位前指定者得3；末位可取新经济和一个已占银行得2，最优。BASE非末位规定收益2+1/(m−1)>2；任意改变经济、银行或两者的偏离，新银行会被固定目标末位复制，旧银行已有共享，偏离者经济至多1，利润≤2。BASE末位收益2最优。根任何动作重锚，同型叶的根利润都m/(m−1)。这些不变量覆盖再次偏离和平局，证明全部有序历史的SPE，非180个实际前缀菜单代替全树。

取m=6：共16客户、30主题，实际叶为
\[
 (0,0),(0,1),(0,2),(0,3),(0,4),(1,0),
\quad u=(6/5,11/5,11/5,11/5,11/5,2).
\]
因此W=12，全部客户可由6主题覆盖，OPT=16。银行坐标以下压成一个坐标，负载与查询边际按**每位**银行客户计，求和时乘银行大小2。

# 固定均匀查询：全局负载极小不等于外层鞍点

先取p在30主题均匀，经济边际1/6、银行边际1/5。固定锚负载l≥8/3，经济Jensen下界为
\[
 \frac16\left[\frac1{1+l}+\frac5{1+(5-l)/5}\right].
\]
此式在l≥8/3递增；银行Jensen贡献至少1。证书(L)同时取等，且ρ在全部16客户上正，严格凸性使此**固定p**最小负载唯一。因此
\[
 \min_{L\in K}F_p(L)=71/44,
 \quad C=3269/7260>0,\quad I=1147/900,
 \quad D=81349/54450,
\]
\[
 W-6F_p(L^*)=51/22=I-C+D>0.                    \tag{UNIFORM}
\]
为保留原有理数的解析来由，根全部查询利润6/5；末位非锚查询利润2、锚查询7/6。中间行令l=i−1∈{1,2,3,4}，非锚查询利润2；五个锚查询中，规定银行一项仍走实际BASE而利润11/5，其余四项利润1+1/(l+1)。故中间IC各49/150−2/[15(l+1)]，末位IC5/36，合计1147/900。

所有非锚查询有C_1=795/484、C_i=−105/484(i≥2)。均匀p下第一行C均值1341/968、末行−147/968；中间行C均值
\[
 -175/968+2(3l-7)/605-1/60.
\]
最后一项不能漏：规定银行锚查询的删槽银行负载0，其他四个锚查询的该负载1。相加即3269/7260，D再由逐客户BAL或同一精确账得上述值。此处仅解析复核原记录，无新180菜单程序运行。

p均匀不是外层max_p的最优查询。因此(UNIFORM)不能独自反驳只要求真正鞍点C≤0的版本。

# 真正鞍点及全部最优选择的量词闭合

改取p*均匀于25个非锚主题(a,b)，a∈{1,…,5}。其经济0边际0，其余经济和银行边际均1/5。任意L∈K的非锚经济总负载≤7/3；Jensen给
\[
 F_{p^*}(L)\ge \frac1{1+(7/3)/5}+1=37/22.
\]
负载(L)取等。同时在L*上，每个非锚主题价15/22+1=37/22，锚主题价3/11+1=14/11严格较低。因此(p*,L*)确为全局minimax鞍点，γ=37/22；不是只核固定p的KKT。

对每个非锚查询T，删槽的被查询经济负载在根为4，在其余五行均0；被查询银行负载始终1。因t_ea=15/22、t_Bb=1/2，直接得
\[
 C_1(T)=(15/22)^2(4-7/15)=795/484,
\quad C_i(T)=(15/22)^2(0-7/15)=-105/484\ (i\ge2).
\]
所以C=(795−5·105)/484=135/242>0。对所取均匀p*，六行真查询利润为6/5,2,2,2,2,2，故I=4/5；BAL给
\[
 D=2017/1210,\qquad
 W-6\gamma=21/11=4/5-135/242+2017/1210>0.       \tag{SADDLE}
\]

进一步，任意全局最优共享负载L都使F_p*(L)=γ。该函数在全部非锚经济与银行坐标严格凸，固定这些坐标为(L)；经济总负载5再固定锚坐标。因此全局primal L*唯一。任意外层最优p在此L*上必有F_p(L*)=γ；由于锚主题严格较便宜，p不能给锚主题正质量。所有最优p都支持于上述25主题。

允许角色查询运输：每行ν_i仍为概率分布且(1/6)Σ_iν_i=p。其全部查询各沿对应真实行菜单，整主题IC仍各一份；因为各ν_i非负，平均p不含锚也迫每行不含锚。每行C_i(T)在整个允许支持恒定，故
\[
 \boxed{C(\nu_1,\ldots,\nu_6)=135/242>0}
\]
对**每个**最优外层p、每个保该平均边际的角色运输成立；改变L*的列实现q也不改变C。这里没有把所取p*的D、I数值提升为对所有p/运输分别恒定；恒定的只有上述C。

# 结论及证据边界

本例否定“存在有利全局鞍点/角色运输使C≤0”的加强，也否定更强的全鞍点符号版本。它仍满足γ=37/22<2=W/6；(SADDLE)的真实D与IC支付完整C，所以不否定SHARED、C≤D+I、较弱half付款、ROLE或half。正确方向是保住具体正信用并证明共同金额，不是再用KKT删除相关项。
