# 实际均匀缩放负载的弱付款桥

## 模型、被否定的量词与保留的代数

采用[共同目录完整历史模型](../定义/共同目录完整历史模型--定义.md)：有限单位客户、有限非空共同主题目录\(\mathcal S\)，\(m\ge1\)名单位提供者依次观察全部有序历史各选一个主题。客户在最终覆盖他的提供者间均分。纯策略在每一有序历史（包括离轨历史）指定动作，纯SPE要求各子博弈中对沿同一完整策略继续的真实偏离均最优。允许空主题、重复选择、零客户和任意历史平局。

固定一个实际终局，客户负载\(c_x\)、总福利\(W=|\{x:c_x>0\}|\)，令

\[
\alpha=\frac{m-1}{m},\quad g(T)=\sum_{x\in T}\frac1{1+\alpha c_x},\quad
M=\max_{T\in\mathcal S}g(T),\quad
G=\sum_{x:c_x>0}\frac1{1+\alpha c_x}.
\]

**被否定的弱桥**是全称陈述：每个输入、每份完整纯SPE都满足
\(W\ge(m-\tfrac12)M\)。本对象给出对每个整数\(m\ge4\)的严格反例。该\(M\)只是固定实际均匀缩放背景的查询值，不能当成真正静态混合安全值。

对任何终局和任意\(m\)个比较主题\(T_1,\ldots,T_m\)，记比较负载\(d_x\)。逐客户

\[
\mathbf1_{d_x>0}\le\frac{d_x+\alpha c_x}{1+\alpha c_x}.
\]

求和给出两条始终有效、不要求SPE的代数：

\[
\operatorname{OPT}_m\le\sum_jg(T_j)+\alpha\sum_ig(A_i)
\le(2m-1)M,
\qquad
\operatorname{OPT}_m\le mM+W-G.                 \tag{1}
\]

第二式用\(\alpha c/(1+\alpha c)=1-1/(1+\alpha c)\)于\(c>0\)。弱桥若成立确实足以推出half；它失败不能逆推half失败。精确税充分桥\(mM\le W+G\)比弱桥更有余地；它也已经由另一个13人证书否定，见下文，不能恢复为开放候选。

## 四主题单位客户族

对每个整数\(m\ge2\)，目录为\(\{A,B,Q,D\}\)，不同单位客户按兴趣类型压缩如下。

| 兴趣主题 | 单位客户数 |
| --- | ---: |
| \(\{A\}\) | \(m-1\) |
| \(\{Q\}\) | 1 |
| \(\{A,D\}\) | 1 |
| \(\{B,Q,D\}\) | \(m(m-1)\) |

共\(m^2+1\)名单位客户。四覆盖两两不同，\(B\)虽为\(Q,D\)的真子集，仍是原目录中的合法动作；删去它会改变要认证的博弈。

先在全部整数状态\((r,q,e)\in\mathbb Z_{\ge0}^3\)定义辅助策略\(\beta\)：未来\(r\)人各选两个总奖金为1的资源\(Q,D\)，已有负载分别为\(q,e\)，当前选中资源的收益为其最终负载的倒数。\(r=0\)无行动；\(r>0\)时递归求两个孩子的规范续局，比较当前人的最终奖金，较大者为指定行动，等值选\(Q\)。有限逆向归纳使\(\beta\)在每个状态都是纯SPE。未被选的零负载资源不计算倒数。

原博弈对任意\(|h|=t<m\)的有序历史，记主题计数为\((a,b,q,d)\)、剩余人数\(r=m-t\)，指定：

1. 若历史全为\(B\)（空历史也满足），\(t<m-1\)时选\(B\)，末位选\(A\)。
2. 否则按\(\beta(r,q,a+d)\)选\(Q\)或\(D\)。

此处只是构造一份可按计数计算的完整策略；一般SPE不受计数依赖或统一平局约束。

## 全部有序历史的最优性

在非全\(B\)历史，从当前选\(Q\)或\(D\)起，后继不再选\(A,B\)。以前的\(A\)数\(a\)固定，每个非\(A\)提供者从共同大块得到同一收益

\[
C(a)=\frac{m(m-1)}{m-a}.
\]

\(Q\)的额外奖金为\(1/q_{\rm final}\)，\(D\)的额外奖金为\(1/(a+d_{\rm final})\)。因此辅助\(\beta\)恰好保证规定行动在\(Q,D\)间最优。改选\(B\)仅得\(C(a)\)，严格更低。

若\(a\ge1\)，改选\(A\)最多得\(m/(a+1)\le m/2\)；规定行动严格大于\(C(a)\ge m\)，故不获利。

若\(a=0\)，先前已出现\(Q\)或\(D\)。当前首次改\(A\)与当前改\(D\)都把辅助第二资源背景从\(d\)变为\(d+1\)，余人数相同，故两个真实分支的后继\(Q,D\)序列完全相同。前者从私有大块得\(m-1\)，后者从共同大块得\(m(m-1)/m=m-1\)，额外奖金又同为\(1/(1+d_{\rm future})\)。两个偏离收益相等，所以\(A\)不超过最优\(Q,D\)。

在全\(B\)历史且非末位时，遵从策略的终局为\(B^{m-1}A\)，当前收益\(m\)。改\(A\)最多得\(m\)；改\(Q,D\)后不再有\(A\)，共同大块给\(m-1\)，额外最多1。末位选\(A\)得\(m\)，\(Q,D\)也得\(m\)，\(B\)仅得\(m-1\)。这穷尽所有历史和所有行动，故该策略对每个\(m\ge2\)都是完整纯SPE。

不能以固定优先\(Q\)的短视贪心替代\(\beta\)：两个零背景资源、三人时贪心路径\(Q,D,Q\)使首人得\(1/2\)，首人改\(D\)后的贪心续局\(Q,Q\)使其得1，违反根最优性。

## 查询差、真正安全值和六人含义

实际\(B^{m-1}A\)上每名收益\(m\)，所以\(W=m^2\)。\(A\cup Q\)覆盖全部客户，以重复主题补足\(m\)次选择得\(\operatorname{OPT}_m=m^2+1\)。令\(\Delta=m^2-m+1\)，实际负载给

\[
g(A)=\frac{m^2}{2m-1},\quad g(B)=\frac{m^2(m-1)}\Delta,\quad
g(Q)=1+g(B),\quad g(D)=\frac m{2m-1}+g(B).
\]

\(m\ge2\)时\(g(B)\ge g(A)\)、\(g(Q)>g(D)>g(B)\)，故\(M=g(Q)\)，而

\[
(m-\tfrac12)M-W=\frac{m^3-4m^2+3m-1}{2\Delta}.
\]

\(m\ge4\)时分子\(m^2(m-4)+3m-1>0\)。\(m=4\)有17客户、\(W=16\)、查询向量\((16/7,48/13,61/13,388/91)\)，弱桥缺口\(11/26\)。\(m=6\)有37客户、\(W=36\)、\(\operatorname{OPT}_6=37\)、弱桥缺口\(89/62\)；其half余额仍是35。

对真正静态混合安全值\(v_m\)，对手必须独立于抽中的查询预选\(m-1\)个主题。合法静态列\(B^{m-1}\)对四个纯查询给\((m,m-1,m,m)\)，所以\(v_m\le m=W/m\)。本族满足\(W\ge mv_m\)，以及

\[
2W-\operatorname{OPT}_m=m^2-1>0,
\qquad W+G-mM=\frac{m(m-1)}\Delta+\frac{m^2}{2m-1}>0.
\]

因此本族没有否定精确税桥，也没有否定真正安全值聚合；参考[静态混合安全值](../定理/静态混合安全值的锐目录计数界--定理.md)。

## 另一个有限13人证书否定精确税桥

这里必须保留旧源§5的后续状态，不能把“本族未反驳”误写成“该桥仍未反驳”。六主题依次为\((A,B,T,D,E,P)\)，13名提供者的36名单位客户类型为

| 兴趣主题 | 人数 |
| --- | ---: |
| \(A\) | 2 |
| \(B\) | 2 |
| \(T\) | 1 |
| \(T,D\) | 1 |
| \(T,E\) | 1 |
| \(A,D,E\) | 3 |
| \(B,D,E\) | 1 |
| \(P\) | 25 |

完整策略由[冻结有限自动机](../../tools/evidence/fractional-load-boundaries/original/research/workspaces/customer-attraction/R-c50fecc37aa44fb4a69a2122bb70e5fe/security/refined_tax_k10_packet.json.gz)定义：从根起按每个观察动作沿该标号边转移，在所得节点执行指定行动。27243个节点中18675个是决策节点，每个均有六条观察边；计数沿边恰加该动作，深度从0到13，全部节点可达。不同等计数历史允许不同节点（只有27132种计数）。因此所有有序历史均得到唯一策略动作。

从叶逆序计算规定终局\(z(v)\)，逐节点逐行动验证
\(u_{a(v)}(z(v))\ge u_b(z(\mathrm{child}(v,b)))\)。该封闭证书的112050项含自身比较均用36个单位客户及整数公分母\(\mathrm{lcm}(1,\ldots,13)\)精确复跑通过，最小差0。由有限完美信息博弈的一步偏离原则，这认证完整纯SPE；它不是只认证在轨路径。

实际路径\(P^{10},A,A,B\)，前十二人收益\(5/2\)、末位3，\(W=33\)。\(A,B,T,P\)覆盖全36人，故\(\operatorname{OPT}_{13}=36\)。实际客户负载桶为\((5,2),(3,1),(3,0),(25,10)\)（人数、负载）。\(\alpha=12/13\)时

\[
(g(A),g(B),g(T),g(D),g(E),g(P))
=(65/37,39/25,3,2381/925,2381/925,325/133),
\quad G=708669/123025.
\]

于是\(M=3\)、\(13M-W-G=29481/123025>0\)，单一遗漏主题\(T\)已使精确税桥失败。合法静态对手列\(A,B,T,P^9\)给查询收益\((5/2,3/2,3/2,5/2,5/2,5/2)\)，仍有\(v_{13}\le5/2\)、\(W-13v_{13}\ge1/2\)。本例half余额30。

后续指定算术还排除把同一实际背景缩率改成\(\alpha=1\)的修复：此时查询向量\((5/3,3/2,3,5/2,5/2,25/11)\)，基本覆盖税\(J=359/66\)，故\(13M-W-J=37/66>0\)。同一主题\(T\)对所有原角色的冻结替换查询总和也为39，仍超过\(W+J\)。这是旧完整证书的算术后果，不能称新SPE构造或一般人数族。

## 证据、关系与接续

[核验对象](../计算/分数负载四主题族的全历史核验--计算.md)保留原85节点证书、规范族构造、13人自动机、独立标准库审计和本次重放。原四人动作表与规范\(\beta\)构造在13个离轨节点不同，二者分别已通过全历史检查；不能用规范生成表覆盖原证书。

本反例与[分数覆盖前缀预算](../引理/分数覆盖的真实前缀利润预算--引理.md)研究不同接口：本对象排除固定实际缩放背景的一种付款，后者直接支付真实路径上的前缀最终利润，其证明不依赖被否定桥。与[分数尾水位](../引理/分数尾水位的共同查询信用与利润守恒--引理.md)的联系是共同的查询付款问题；水位允许改辅助负载，但它本身未支付真实跨分支激励，不能直接补上本桥。

无限族由上述解析论证承担；有限复跑验证公式与实现。内部独立审查存在，未认证外审、全球新颖性或最小性。一般六人half和真正安全值聚合没有被这些反例否定；后续可另选背景或构造直接真实分支支付，但不能重新提出已否定的固定实际精确税桥。
