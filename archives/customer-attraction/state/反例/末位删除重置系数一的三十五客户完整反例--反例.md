# 被否定的精确命题

在[共同目录完整历史模型](../定义/共同目录完整历史模型--定义.md)中，固定一份m人完整纯SPE。原末位删除后，保留者仍按原完整策略的真实有序历史执行；末位只是从每个原真实完成叶移去，并非重新选择较少人数SPE。对于任一保留者节点，原规定叶z的当前收益为u、原末位收益为ℓ；在该节点强制任意合法T，原策略完成后再删原末位，当前所得记U(T)。原候选是
\[
 \max_T U(T)\le u+\ell.\tag{LD1}
\]
等价地，若规定叶删除给当前退款R，删后计划的后悔ρ应满足ρ+R≤ℓ。它要求**规定叶一份末位利润支付其它孩子重置后的收益**，不是逐叶份额守恒。以下例子在合法原模型中精确否定这个辅助全称命题。

# 单位客户与完整行动表

三名单位提供者，共同有标签A、B、T、C。24名不同客户构成K，另有不同客户a、b和九名集合C₀，全部互不相同；覆盖集合为
\[
 A=K\cup\{a\},\quad B=K\cup\{b\},\quad T=K,\quad C=C_0.
\]
共35名单位客户。用兴趣类型记为ABT:24、A:1、B:1、C:9。T虽非全局极大，仍是合法目录行动。删除T会改变问题。

首位选A；第二位观察首位A/B/T/C分别选B/A/C/A。末位在全部16个有序前缀的规定如下，行是首位、列是次位：

| 首位\次位 | A | B | T | C |
|---|---|---|---|---|
| A | B | C | B | B |
| B | C | A | A | A |
| T | B | A | A | A |
| C | B | A | A | A |

连同根与4个第二层节点，这是1+4+16=21个全部决策节点。所有平局选择均显式保留；例如AA可在B/C之间平局，本表选B。

# 全部子局最优性的自足核对

末位四行动收益按A/B/T/C排列如下；表中规定行动的收益均等于该行最大值。

| 前缀 | 规定 | 四收益 |
|---|---|---|
| AA | B | (25/3,9,8,9) |
| AB | C | (17/2,17/2,8,9) |
| AT | B | (17/2,9,8,9) |
| AC | B | (25/2,13,12,9/2) |
| BA | C | (17/2,17/2,8,9) |
| BB | A | (9,25/3,8,9) |
| BT | A | (9,17/2,8,9) |
| BC | A | (13,25/2,12,9/2) |
| TA | B | (17/2,9,8,9) |
| TB | A | (9,17/2,8,9) |
| TT | A | (9,9,8,9) |
| TC | A | (13,13,12,9/2) |
| CA | B | (25/2,13,12,9/2) |
| CB | A | (13,25/2,12,9/2) |
| CT | A | (13,13,12,9/2) |
| CC | A | (25,25,24,3) |

每格直接由24个核心客户按当前总覆盖次数均分，再加其私有或C₀客户得到。例AA末位选B给24/3+1=9；AC末位B给24/2+1=13。

固定上述真实末位回应后，第二位的真实四孩子收益依首位A/B/T/C分别为
\[
 (17/2,13,8,9),\ (13,17/2,8,9),\ (9,9,8,9),\ (13,13,12,9/2).
\]
规定B/A/C/A均为最优。根四行动分别完成ABC、BAC、TCA、CAB，根收益为(13,13,12,9)，所以A最优。逆向核对覆盖全部有序历史，故这是一份完整纯SPE；未只核实际路径，也未冻结偏离后的原actual后缀。

实际叶ABC，收益(13,13,9)，W=35。所有客户已覆盖，故OPT₃=35；half余量2W−OPT=35。

# 删除怎样改变孩子账本

删原末位后，规定根路径AB，根收益仍13，退款R=0。根改T时，原策略真实响应是C、A，原叶TCA给根24/2=12；移去这个孩子的最后A，留下TC，根独得24。于是
\[
 24>13+9=22,\quad\rho=24-13=11>9,\quad \rho+R-\ell=2.
\]
根全部删后行动收益为(13,13,24,9)。其余四个保留历史也明确如下，收益仍按A/B/T/C排列：

| 保留前缀 | 规定 | 原完成→删后完成 | 删后四收益 | 当前退款 | 后悔 |
|---|---|---|---|---:|---:|
| A | B | ABC→AB | (25/2,13,12,9) | 0 | 0 |
| B | A | BAC→BA | (13,25/2,12,9) | 0 | 0 |
| T | C | TCA→TC | (13,13,12,9) | 0 | 4 |
| C | A | CAB→CA | (25,25,24,9/2) | 12 | 0 |

[总退款势](../引理/因果删位的总退款税与最小共同税储备--引理.md)准确解释这个失败。规定ABC删C，删者利润P=9、丢失独占客户e=9，故H=P−e=0；偏离TCA删A，P'=13、e'=1，H'=12，全部退款给根。原IC松弛Γ=13−12=1，因此真实增益恰为12−0−1=11。原actual退款H=0的任何有限倍数都无法支付这个正后悔；不能据此否定保留偏离叶势差的正确恒等式。

# 用途与下一步

此例可作为删尾修复候选的精确压力输入，要求新的付款保留偏离分支的退款、独占损失变化和原Γ。它不说明所有删位失败、没有较少人数可信修复、人数常数2不可用、一般half为假或此实例最小。与[任意深度单叶付款障碍](../障碍/任意深度子博弈的删除缺陷与单叶付款障碍--障碍.md)的任意长尾背景族也不是同一反例：这里无背景、真实根已经失败系数1，完整实际根W=OPT。
