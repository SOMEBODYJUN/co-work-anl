# 唯一最优组合的全遗漏不能由实际福利支付

## 结论与准确量词

在有限单位客户、共同主题目录、依完整有序历史选主题、终局在覆盖者之间均分价值的模型中，以下辅助命题为假：

> 对每份完整历史纯SPE，总能选一个达到最优覆盖的主题组合，使其全部未被该SPE覆盖的客户数不超过该SPE的实际覆盖数。

下面固定提供者数为 \(m=2\)，对每个整数 \(k\ge3\) 给出一个有限实例及一份完整纯SPE。**\(k\) 是客户重数参数，不是提供者数。** 唯一最优无序主题对为 \(TQ\)，而

\[
W=13k-4,\qquad \operatorname{OPT}_2=14k-4,\qquad
L=|O\setminus C|=14k-6>W.
\tag{1}
\]

因此更换最优组合也无法修补此辅助命题。这里只要求存在一份这样的SPE，不声称此输入的所有SPE都具有相同遗漏。它也不反驳两人半覆盖，更不反驳当前六人主问题：本族始终有

\[
2W-\operatorname{OPT}_2=12k-4>0.
\tag{2}
\]

旧27客户例已有一个最优组合被遗漏14人而实际覆盖13人，但还有其他最优组合仅遗漏7人，故只否定“每个最优组合都可这样支付”。[旧例的准确量词](零背景保护遗漏与超额利润价格--反例.md)与本例的“存在一个有利最优组合也不行”不可混同。

## 有限单位客户与共同目录

共同目录恰为 \(A,B,T,Q,R,S\)。每行表示相互不同的单位客户，其喜欢的主题恰为所列字母；同一行的重数不引入有权客户。

| 兴趣集合 | 客户数 |
| --- | ---: |
| \(A\) | \(4k-2\) |
| \(ARS\) | \(2k\) |
| \(B\) | \(5k-2\) |
| \(BRS\) | \(2k-2\) |
| \(BTRS\) | \(1\) |
| \(BQRS\) | \(1\) |
| \(T\) | \(3k-1\) |
| \(TR\) | \(2k-1\) |
| \(TS\) | \(2k-1\) |
| \(Q\) | \(3k-1\) |
| \(QR\) | \(2k-1\) |
| \(QS\) | \(2k-1\) |

这12类在 \(k\ge3\) 都有正整数重数，总客户数为 \(27k-10\)。设

\[
a=6k-2,\qquad b=7k-2,\qquad p=8k-2.
\]

主题大小依次为 \((a,b,b,b,p,p)\)。六个主题作为**客户集合**两两不同，大小并非两两不同。这个表述消除了作者原稿“主题大小为……，两两不同”的歧义，也保留独立审查已作的纠正。

由客户表直接得到：

- \(A\) 与 \(B,T,Q\) 分别不交，\(T\cap Q=\varnothing\)；
- \(|B\cap T|=|B\cap Q|=1\)；
- 每个 \(X\in\{A,B,T,Q\}\) 都有 \(|X\cap R|=|X\cap S|=2k\)；
- \(|R\cap S|=4k\)。

这是合法共同目录的一个特例。模型中的重复行动、离轨历史和任意平局均保留；证明没有将两人选同一主题的情况删除。构造自身不需空主题或零客户，但这不构成对一般模型这些边界情形的排除。

## 全部有序历史上的策略与收益

第一人根节点选择 \(A\)。第二人在六种首主题后的回复全部规定为

\[
A\mapsto B,\quad B\mapsto S,\quad T\mapsto R,\quad
Q\mapsto S,\quad R\mapsto S,\quad S\mapsto R.
\tag{3}
\]

两人选择 \(X,Y\) 时，第二人的收益由单位均分定义等于

\[
u_2(X,Y)=|Y|-\frac{|X\cap Y|}{2}.
\tag{4}
\]

即使 \(X=Y\)，该式仍给 \(|X|/2\)，所以没有漏掉重复行动。用上节全部交集，得到完整末位收益表：

| 首主题／末主题 | \(A\) | \(B\) | \(T\) | \(Q\) | \(R\) | \(S\) |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| \(A\) | \(a/2\) | \(b\) | \(b\) | \(b\) | \(b\) | \(b\) |
| \(B\) | \(a\) | \(b/2\) | \(b-1/2\) | \(b-1/2\) | \(b\) | \(b\) |
| \(T\) | \(a\) | \(b-1/2\) | \(b/2\) | \(b\) | \(b\) | \(b\) |
| \(Q\) | \(a\) | \(b-1/2\) | \(b\) | \(b/2\) | \(b\) | \(b\) |
| \(R\) | \(a-k\) | \(a\) | \(a\) | \(a\) | \(p/2\) | \(a\) |
| \(S\) | \(a-k\) | \(a\) | \(a\) | \(a\) | \(a\) | \(p/2\) |

指定回复在各自行都达到最大值。非零“指定收益减其他收益”的差仅为

\[
4k-1,\quad k,\quad \frac{7k-2}{2},\quad
\frac12,\quad 2k-1,
\]

其余差为零；这些数在整个参数域都为正。回复选择使用合法平局，没有额外规定统一破平局规则。

第一人偏离时必须沿式(3)的**真实回复**计算，而不能让回复停在实际路径的 \(B\)。六种根选择的终局收益分别是

\[
u_1(A,B)=a,\quad
u_1(B,S)=u_1(T,R)=u_1(Q,S)=b-k=a,
\quad
u_1(R,S)=u_1(S,R)=p-2k=a.
\tag{5}
\]

所以根选择 \(A\) 也是最优。六个末节点加一个根节点就是全部七个决策历史；每个节点比较全部六个动作，共42项含自身动作的比较，即35项非自身比较。两人各仅行动一次，以上已覆盖每个子博弈全部单方选择，故式(3)与根动作构成完整历史纯SPE。

## 唯一最优组合的完整枚举证明

实际路径是 \(AB\)，两主题不交，故 \(C=A\cup B\) 与 \(W=a+b=13k-4\)。最优候选 \(TQ\) 也不交，覆盖 \(2b=14k-4\)。下表列出允许重复的全部21个无序主题对，按相同值合并；各行的对数合计为21。

| 主题对 | 对数 | 覆盖数 | \(TQ\) 覆盖减该覆盖 |
| --- | ---: | ---: | ---: |
| \(TQ\) | 1 | \(14k-4\) | \(0\) |
| \(BT,BQ\) | 2 | \(14k-5\) | \(1\) |
| \(AB,AT,AQ,BR,BS,TR,TS,QR,QS\) | 9 | \(13k-4\) | \(k\) |
| \(AR,AS,RS\) | 3 | \(12k-4\) | \(2k\) |
| \(AA\) | 1 | \(6k-2\) | \(8k-2\) |
| \(BB,TT,QQ\) | 3 | \(7k-2\) | \(7k-2\) |
| \(RR,SS\) | 2 | \(8k-2\) | \(6k-2\) |

除 \(TQ\) 外，所有差在 \(k\ge3\) 都严格为正。因此唯一最优无序主题对是 \(TQ\)；若记录有序组合，则仅有 \(TQ\) 与 \(QT\)，二者的客户并集是同一个 \(O=T\cup Q\)。没有尚可交换到的另一个最优客户并集。

## 全遗漏与净缺口不能混为一项

只有两名 \(BTRS,BQRS\) 客户同时属于 \(C=A\cup B\) 和 \(O=T\cup Q\)，因此

\[
I=|C\cap O|=2,\qquad
L=|O\setminus C|=14k-6,\qquad
E=|C\setminus O|=13k-6.
\tag{6}
\]

于是

\[
L-W=k-2>0,\qquad
L-E=\operatorname{OPT}_2-W=k.
\tag{7}
\]

实际覆盖中属于最优并集外的 \(E\) 是不可无理由删去的回款。要求“全部遗漏 \(L\) 都由 \(W\) 支付”比证明半覆盖所需的净额关系更强；这个强桥已经失败，净缺口关系没有被本例否定。遗漏比例趋于

\[
\frac{L}{W}=\frac{14k-6}{13k-4}\longrightarrow\frac{14}{13}.
\]

在最小参数 \(k=3\) 时，共71名客户，\((W,\operatorname{OPT}_2,I,L,E)=(35,38,2,36,33)\)，半覆盖余量为32。这里“最小参数”只指本族写出的范围起点，不是全模型中客户数或目录规模的最小性。

这一身份与[半因子勘误](../障碍/遗漏份额支付的半因子勘误--障碍.md)相接：从某种查询只能付到 \(L/2\) 不能直接宣称半覆盖；即使强化到支付 \(L\)，本族也阻断了全称版本。后续若要保留遗漏账户，须解释 \(E\) 的信用如何进入真实有序历史的预算。

同一族还有独立处置的[保护价格推论](../推论/唯一最优遗漏族的保护价格--推论.md)：对全部实际遗漏客户 \(D\)，精确匹配查询与客户标记上界给 \(B_D(u_A)=2k-2>k=u_B-u_A\)，进一步排除用尾部超额利润支付该价格的强式。比率趋二只给固定倍数至少二的必要条件，不证明二充分，也不把同一底层族重新记为新的游戏反例。

## 证明、审查与发现输入分别保留

[逐客户与线性证书](../计算/最优遗漏族的逐客户与线性证书--计算.md)保存七份冻结来源、作者固定 \(k=3\) 审计和独立全参数审计。独立实现把每个差写成线性多项式 \(\beta+\alpha k\)，以 \(\alpha\ge0\) 和 \(f(3)\ge0\) 认证整个半直线，严格项再检查 \(f(3)>0\)。因此全参数结论不是从有限抽样外推；其完整解析证明正是上文。

原发现JSON是另一份14类客户输入，正式证明采用12类客户输入。二者在两人终局收益、主题对覆盖及给定完整策略上相同，但三重交集不同；[两份输入的等价范围](../等价/两份最优遗漏输入的二人收益等价--等价.md)给出具体证明和反向边界。不能将它们描述为同一份客户表，也不能从优化器的历史成功状态推出数学最优性、最小性或外部审查结论。

本对象的性质是**原模型内、辅助桥的完整反例族**。当前六人半覆盖仍须由其自身的论证或合法六人反例决定，不能把目录恰有六个主题误读为本例有六名提供者。
