# 三人截断共同次模根饱和的九比五下界

取三个有序单位提供者，目录为 \(\{A,B_1,B_2,B_3\}\)。在至多三个不同标签上定义归一值。令 \(k\) 为集合中的外标签数。若不含 \(A\)，值为 \(3k/5\)；若含 \(A\)，值为 \(1+k/5\)。标签 \(A\) 的边际为 \(1-2k/5\)，可加入时 \(k\le2\)。外标签边际分别为 \(3/5\) 和 \(1/5\)，取决于是否已含 \(A\)。这些边际在域内单调递减且非负。

所有有序历史均规定 \(A\)。按三个有标识玩家的随机排列边际，当前角色各类比较如下。当前之前所有标签种类及重数相同的历史，剩余角色都选 \(A\)，所以表覆盖全部有序历史。\(B,C,D\) 表示互异外标签。

| 有序过去（可交换） | 规定 \(A\) | 已在过去出现的外标签 | 未出现的外标签 |
| --- | ---: | ---: | ---: |
| 空、\(A\)、\(AA\) | \(1/3\) |  | \(1/3\) |
| \(B\)、\(AB\) | \(13/30\) | \(7/30\) | \(2/5\) |
| \(BB\) | \(11/15\) | \(1/5\) | \(3/5\) |
| \(BC\) | \(3/5\) | \(3/10\) | \(3/5\) |

表中每行都直接在其真实强制后的终局取份额，故策略是完整纯SPE。实际全选 \(A\)，有 \(K=W=1\)、\(u=1/3=K/3\)。三个外标签的比较值 \(9/5\) 是唯一最优支持。根饱和三人域的最坏福利比至少 \(9/5\)。此例尚未确定全域锐值。

该点不能全域单调次模延拓。\(\{A,B_1,B_2\}\)、\(\{A,B_1,B_3\}\) 各值 \(7/5\)，交值 \(6/5\)，故其四标签并集值至多 \(8/5\)，而单调性要求至少 \(9/5\)。
