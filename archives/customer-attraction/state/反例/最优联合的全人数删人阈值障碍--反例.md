# 精确模型和两个全称量词

采用[有限单位客户、共同集合目录和完整有序历史纯SPE](../定义/共同目录完整历史模型--定义.md)。所有提供者单位权；最终每名客户在覆盖它的玩家间均分。删除玩家后，保留**整个原共同目录及所有客户**，允许重新选择任意完整SPE，不强制保旧行动或旧策略。

任取整数m≥2、偶整数t≥4、整数d≥1及整数0<ε<t/2，置

\[
L=d+(m+1)t/2+\varepsilon.
\]

取m个两两不交的L客户块A₁,…,A_m。主题T在每块取t名标记客户，另含d名私有客户；共同目录恰为这些m+1个主题。客户总数mL+d，每名仍为不同的单位客户。L−t=d+(m−1)t/2+ε>0且d>0，故全部主题非空、覆盖两两不同，T确有U=⋃A_i之外的客户。

同一个目录满足：

1. **每份m人完整纯SPE**的实际终局都是每个A_i各一次，覆盖恰U，所有人收益L，并且W=OPT_m=mL。
2. 对**每个1≤s<m、每份s人完整纯SPE**，根先选T，此后选s−1个不同块。故每份较少人数均衡都覆盖d名U外私有客户，其联合不包含于U。

第二条排除“允许重选所有续局后仍能在原联合内重新均衡”的无信用删除闭包，比只将旧行动直接删掉更强。它没有断言一切带额外状态、误差或信用的删位归纳都不可能，也不是half反例。

# 含T的全部有序历史：强制fresh块

考虑任意总人数s≤m及非终结历史，已有q≥1次T，长度ℓ<s；此前可以有重复块和多次T。不同已用块至多ℓ−q个，因此未用块至少m−ℓ+q，足够当前及以后各选不同fresh块。

按剩余树高同时对所有这样的有序历史倒归纳。所有孩子仍含T，归纳假设使其后继只选fresh块。当前选fresh块的最终收益恰为

\[
L-t+\frac{t}{q+1}.
\]

改选旧块，该块先前至少已有一位，收益至多(L−t)/2+t/(q+2)，严格较小。改选T，则T总人数至少q+1，收益至多(mt+d)/(q+1)。fresh对这个上界的差至少

\[
L-t-\frac{(m-1)t+d}{q+1}
\ge L-t-\frac{(m-1)t+d}{2}
=d/2+\varepsilon>0.
\]

末位同样直接成立，归纳基无缺失。因此在**每份SPE、每个含T历史**，当前只能选一个尚未用的块。不同fresh标签间的所有平局仍保留，不把等计数历史绑定为同一动作。

# 原m人：所有实际均衡均最优

对无T且块互异的历史作倒归纳。当前选fresh块后，后继继续补齐m个不同块，自己最终得L。当前改T时，上节适用于该真实孩子，最终为一位T和m−1个不同块，偏离者收益

\[
d+(m-1)t/2+t=L-\varepsilon<L.
\]

当前复制旧块时，不论其后的真实策略怎样变化，已有同块祖先使其最终收益至多L/2；不需要为无T重复区假设匿名策略或后继排序。因此fresh严格最优。根属于无T互异区，全部m人SPE实际只走不同块，最终各块恰一次。

不用T，m槽最大覆盖为mL；含T时至多再选m−1个不同块，且L>t，故其最大覆盖为

\[
(m-1)L+t+d
=mL-(m-1)t/2-\varepsilon<mL.
\]

所以全部m人均衡确实实现原最优联合。无T重复区可按有限逆向归纳补全；其非T孩子仍在重复区，T孩子进入已经处理的含T区，树高严格下降，不存在循环定义。

# 每个较少人数：根T，随后不同块

固定s<m，在任意无T历史中当前改T，之后由含T归纳只选fresh块。设最终s−1个非T块行动的计数为c_i，Σc_i=s−1；过去可以重复。当前T的收益为

\[
d+t\sum_i\frac1{1+c_i}.
\]

对整数c≥0有1/(1+c)≥1−c/2，因此上述收益至少

\[
d+t[m-(s-1)/2]
=L+(m-s)t/2-\varepsilon>L.
\]

当前选任一块的收益始终不超过L，故每个无T历史的当前行动都必须为T。根无T，于是实际先T；以后含T，只能选不同fresh块，T恰一次。这同时证明所有较少人数、全部SPE及全部有序历史的分类，而非挑一条可补全路径。

其实际覆盖可写为d+mt+(s−1)(L−t)：其中d名私有客户在原U之外。因此联合包含失败与福利大小是不同性质；本族不是把旧的2→3人口福利下降实例换一个名字。

# 两个严格端点均不能免费加入

ε=0时，无T互异区的T分支与fresh块均得L。可选择根T、以后fresh，并将重复区按BI补全为m人完整SPE，故“全部m人避免T”失效。

ε=t/2时，取s=m−1，在无T互异区选择fresh到底；T偏离的最终收益也为L，旧块复制仍不优。含T子枝按前述fresh规则、重复区按BI补全，得到一份s人无T完整SPE，故“全部较少人数必须T”失效。两个边界构造适用于任意m≥2；原程序只有限检查m2…6，不用该有限范围外推一般端点。
