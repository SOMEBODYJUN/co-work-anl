# 合法单位客户实例和反驳对象

本例只反驳“任意完全对称、实际动作全异的终局都满足B(min_i u_i)≤W”。它不是完整SPE，不能反驳相同价格候选在完整SPE上的量词，更不能作为六人半覆盖反例。采用真实集合目录而非重复标签：X,Y各10主题，每块对每个五元素主题子集放一个不同单位客户，恰喜欢该子集、对另一块无兴趣。共有2·binom(10,5)=504客户。二十主题两两不同，关联多重集在块内所有置换及交换块下不变。

十名提供者实际各选不同主题：一个X、九个Y。X玩家独自覆盖binom(9,4)=126客户，收益126；九个Y覆盖全部252个Y客户，置换对称使每名收益252/9=28。亦可逐客户核：一名所选Y主题覆盖的客户中，56个含唯一未选Y主题而由4人分享，70个不含未选主题而由5人分享，56/4+70/5=28。因此
\[
W=126+252=378,\qquad\min_i u_i=28.
\]
实际最小收益在majority组，不能用“minority一定满足LO”替代“最小者满足LO”。

# 一份确实违反强价格桥的实查询

给每个二十主题权1/5，τ4。每个客户恰喜五主题，所以每个截断query覆盖为1，C(z)=504。
\[
B(28)\ge C(z)-28\tau=504-112=392>378=W.
\]
这里只给合法查询下界，不宣称B(28)恰392或已经求出其LP最优值。权1/5是证明比较，不是客户价值1/5或玩家混合行动。minority玩家收益126而非28，故不与[轨道低交叠价格定理](../定理/最大质量分区与轨道交叠的全实权价格证书--定理.md)矛盾。

# 为何任何行动顺序都不可能是完整SPE

若先走minority、后走九个majority，真正末位收益28，改选一个新X主题时覆盖126；其中与先前X主题共同客户binom(8,3)=56，各只得一半，其余70独享，偏离收益126−56/2=98>28。这个直接静态尾部计算只用于末位真实无后继节点，不能拿它无视其它顺序中的可信后继。

任意其它顺序也不行：最后两位中至少一位majority，收益均28。若其为末位，[真正末位全客户价格端点](../推论/真实末两人全客户分数价格端点--推论.md)迫B(28)≤W−28；若其只在倒二，[完整SPE克隆税端点](../引理/倒二克隆税的四类真实比较--引理.md)迫B(28)≤W−κ_10·28<W。均与上面的同一终局query下界矛盾。因此**不存在任何定义于全部历史的纯SPE以此行动多重集为终局**，并非只排除一个列明顺序；不需要假设终局为静态NE。

# 精确十主题最优覆盖与像界共存

若比较组合用r个不同X和10−r个不同Y，则未覆盖客户数为binom(10−r,5)+binom(r,5)，上参数小于5的项取0。任意重复可用新主题补足到十个不同主题而不降覆盖，所以这些r枚举控制真正OPT_10。r5时只漏两客户；r≤4或r≥6至少漏6。因此
\[
OPT_{10}=504-2=502<2W=756.
\]
所以上述强价格桥失败和[双像结构half](../定理/两块目录的双自同构像覆盖与支撑门槛--定理.md)完全相容：d10≥min(k10,m10)给OPT_10≤2W，与SPE无关。也不反驳较弱、带真实后继超额的[开放价格接口](../候选/后继超额保留的最小收益价格桥--候选.md)，因为其全称对象首先要求完整SPE。
