# 五阶截断共同次模的正根均匀付款反例

## 命题与精确模型

存在一个七标签、五名单位提供者按序各选一次的有限共同目录博弈。其共同值 \(C\) 只在至多五个不同标签的集合上定义，满足 \(C(\varnothing)=0\)、全部域内单调性及递减边际。提供者收益是个体副本均匀随机排列的期望边际。该博弈有一份定义在全部有序历史的纯子博弈精炼均衡 \(\sigma\)，实际有序路径 \(s=(0,0,0,0,1)\)，实际福利 \(W=1\)。每个在根实际终局出现的标签 \(a\in\{0,1\}\) 满足

\[
C(\{0,1\})-C(\{0,1\}\setminus\{a\})\ge \tfrac{1}{10}W.
\]

固定唯一最优五槽比较支持 \(J=(2,3,4,5,6)\)。令 \(\ell_\sigma(h)\) 是从有序前缀 \(h\) 沿同一原表 \(\sigma\) 得到的五人终局，\(u_i(z)\) 是终局 \(z\) 第 \(i\) 人的收益。第 \(i\) 人在实际前缀强制选 \(a\) 的真正查询为

\[
V_{i,a}=u_i(\ell_\sigma(s_{<i}a)),\qquad Q_J=\sum_{i=1}^5\sum_{a\in J}V_{i,a}.
\]

本例 \(C(J)=\mathrm{OPT}_5=9/8\)、\(Q_J=53/40\)，所以

\[
D_J=4W+Q_J-5C(J)=4+\tfrac{53}{40}-5\cdot\tfrac98=-\tfrac3{10}<0.
\]

因此，要求在上述五阶截断模型、两个根删除边际至少为 \(W/10\) 的每份完整纯 SPE 和每个合法五槽比较元组上都满足 \(5C(J)\le4W+Q_J\) 的陈述为假。比较支持唯一且查询和对五槽排列不变。因此，即使量词弱化为“给定每份完整纯 SPE，至少有一个最优比较元组满足此式”，此 \(\sigma\) 仍给出反例。

## 冻结输入与完整动作表

令 \(I=\{0,1\}\)、\(B=\{2,3,4,5,6\}\)。坐标 \((b,k)\) 的第一分量 \(b=\sum_{a\in S\cap I}2^a\) 是零基位掩码，第二分量 \(k=|S\cap B|\) 是不同外部标签数。下表覆盖全部定义域。空格对应多于五个不同标签。

| \(b\) | \(k=0\) | \(k=1\) | \(k=2\) | \(k=3\) | \(k=4\) | \(k=5\) |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 0 | 0 | 9/40 | 9/20 | 27/40 | 9/10 | 9/8 |
| 1 | 9/10 | 9/10 | 9/10 | 9/10 | 9/10 | |
| 2 | 4/5 | 1 | 1 | 1 | 1 | |
| 3 | 1 | 1 | 1 | 1 | | |

域内单调与递减边际也可直接从表读出。外部标签的边际在位掩码 0 为 \(9/40\)，在掩码 1 或 3 为 0，在掩码 2 从 \(k=0\) 的 \(1/5\) 降至其余 \(k\) 的 0。添加标签 0 时，若不含标签 1，边际为 \(9/10-9k/40\)；若已含标签 1，边际从 \(1/5\) 降至 0。添加标签 1 时，若不含标签 0，边际从 \(4/5\) 降至 \(1-9k/40\)（\(k\ge1\)）；若已含标签 0，边际恒为 \(1/10\)。这些数值在各自有定义的域上非负，并随可加入的其他标签增加而不升。

唯一最优支持是 \(B\)，因为其值为 \(9/8\)，其余所有已定义值至多为 1。根占用两个标签，按标签 0、1 删除的福利差依次为 \(1-4/5=1/5\) 与 \(1-9/10=1/10\)。

## 定义级精确验证

对任意五人终局 \(z\)，以 \(S_i(\pi)\) 表示在个体排列 \(\pi\) 中先于第 \(i\) 人出现的其他玩家所选标签集合，则

\[
u_i(z)=\tfrac1{120}\sum_{\pi\in\mathfrak S_5}\big[C(S_i(\pi)\cup\{z_i\})-C(S_i(\pi))\big].
\]

排列的是五个有标识副本，遇到重复标签只在组成集合时去重。每个有序历史 \(h\) 的当前玩家为 \(i=|h|+1\)。检查器把每个合法强制动作 \(a\ne\sigma(h)\) 接到 \(h\)，随后用同一 \(\sigma\) 走完，再核 \(u_i(\ell_\sigma(h))\ge u_i(\ell_\sigma(ha))\)。因为有限完备信息树的每个玩家只行动一次，全部此类不等式就是完整纯 SPE 的定义级条件。精确检查通过全部 399 条未取商单调性、546 条域内基本递减边际、2801 个历史、16806 条非自身偏离，其中 1193 条等号。逐一添加元素的有限望远镜把基本相邻递减边际传给域内任意包含前缀。实际收益为 \((19/100,19/100,19/100,19/100,6/25)\)，和为 1。

## 与 R275 两份原证书及单位客户的边界

R275 的原正根登记 `M-1aaa01ac999f425d919258cb7baa70ed` 保持其原冻结输入、原有序路径 \(00011\)、原完整动作表及固定支持 \(J\)，所证固定锥目标是 \(C(J)/W=88/57\)。本反例使用同一根删除边际条件、标签和比较支持，改变输入、原完整策略、实际路径与研究的表达式。新的负 \(D_J\) 与 \(9/8\) 不改变原 \(88/57\) 的原始/对偶结论，也不声称最差效率超过二。

相邻无 floor 登记 `M-f053891e740544609ea09d43150edcd1` 的冻结点为 \(\mathrm{OPT}_5/W=2\)、\(D_J=-1\)，其原实际占用两标签的根删除边际都为 0。实际上其原完整动作表的固定策略锥也强迫这两项均为 0。写 \(x=C(\{0\})\)、\(y=C(\{1\})\)、\(z=C(\{0,1\})\)。原有序历史 \((1,0)\) 的实际 1 与偏离 0 分别到终局计数 \((3,2)\)、\((2,3)\)，给 \(g_1=(y-x)/2\ge0\)。历史 \((0,0,0,0)\) 的实际 0 与偏离 1 分别到 \((5,0)\)、\((4,1)\)，给 \(g_2=x-y/5-4z/5\ge0\)。于是 \((5/2)g_1+(5/4)g_2=y-z\ge0\) 且 \((1/2)g_1+(5/4)g_2=x-z\ge0\)。单调性给 \(z\ge x,y\)，故 \(x=y=z\)。旧点因此不含正根删除边际的反例。本构造使用另一份完整动作表解决这个限制。

本点不存在保持可见 \(C\) 的同标签非负客户目录。对任意外部标签 \(a\in B\)，\(C(\{0,a\})=C(\{0\})=9/10\)，意味着外部标签的所有正质量客户都属于标签 0。于是五个外部标签的联合质量至多 \(9/10\)，与 \(C(B)=9/8\) 冲突。全部五人终局收益保真也不可能，因为对每个非空至多五标签支持可补重复至五槽，收益总和恢复该集合的值。上述不等式也排除统一正倍数的实现。

本点还无法延拓成在七标签全部子集上单调次模的集合值。令 \(A=\{0\}\cup(B\setminus\{2\})\)、\(A'=\{0\}\cup(B\setminus\{3\})\)。若存在全域延拓，则 \(9/8=C(B)\le C(A\cup A')\le C(A)+C(A')-C(A\cap A')=9/10\)，矛盾。因此本结论反驳五阶截断共同单调次模 Shapley 的正根版 UP。单位客户原版 UP `M-ad5065e7d73146cf920522804d5ae2b9`、全域次模版本及单位客户 half 各自保留原状态。
