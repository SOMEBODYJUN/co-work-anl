# 被否定的两个存在排列上界

采用[共同目录完整历史模型](../定义/共同目录完整历史模型--定义.md)。有限单位客户、有限非空共同目录、m单位玩家按完整有序历史选主题，空主题/重复/零客户/任意平局皆保。固定完整纯SPE σ，原实际叶Z₀及W。取任意达到O=OPT_m的带索引元组T，允许重复，对π置H_k=(T_π(1),…,T_π(k))、Z_k=finish_σ(H_k)，Z_m是全部强制的最优元组。

\[
D_\pi=\sum_{k=1}^m u_k(Z_k)
\]

只收每步**最新强制角色**在该真实完成叶的利润。不同于在原actual-prefix第k节点只偏离一次；后者保原过去，前者把过去整个换成已选最优前缀。

BILL-UP-fixed声称每份原SPE、每个最优T存在π使D_π≤W；更弱BILL-UP-exists允许存在某个最优T和π。以下旧证书两者同时反驳。另BILL-LOW声称每个最优T/π都有D_π≥O/2，本批**未判**；LOW加任一个UP本可推出half，但UP失败后停止这套两桥模板，不以有限LOW阴性扩样继续冒一般证据。

# 同节点IC不能免费跨前缀合账

Z_(k−1)在H_(k−1)后按σ规定动作，Z_k在同节点强制主题，故Γ_k=u_k(Z_(k−1))−u_k(Z_k)≥0。可是k≥2这些左项位于不同已强制最优前缀，不等于原actual u_k(Z₀)。令ΔP_k、ΔV_k分别旧j<k和后j>k终局收益和差，则

\[
W(Z_k)-W(Z_{k-1})=\Delta P_k+\Delta V_k-\Gamma_k.
\]

按每个角色的起止位置望远镜：ΣΔP=O−D_π，ΣΔV=Σu_k(Z_(k−1))−W，ΣΓ=Σu_k(Z_(k−1))−D_π。代回只得O−W=O−W，没有UP上界。旧行动固定仍会因新覆盖者改变分账；非根ΔP不得省，详[中继恒等式](../引理/非根跨枝福利中继恒等式--引理.md)。
