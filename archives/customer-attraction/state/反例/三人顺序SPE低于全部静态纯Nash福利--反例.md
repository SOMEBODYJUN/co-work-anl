# 三人顺序SPE低于全部静态纯Nash福利

## 精确身份与作用

在 [共同目录完整历史模型](../定义/共同目录完整历史模型--定义.md) 中，存在三名单位提供者、四个两两不同的共同主题、十六名不同单位客户，及定义于全部有序历史的一份纯 SPE σ，使

\[
W(σ)=15<16=\min_{z\in\mathrm{PNE}}W(z)=\operatorname{OPT}_3.
\]

PNE 指同一实例的同时行动主题博弈中的纯 Nash 均衡。本命题否定全称辅助桥
“对每个实例及每份纯 SPE，其福利至少达到同实例最差静态 PNE 的福利”。
此前 “SPE 终局可能非 PNE”这一先有结论 不足以推出这一更强失败：即使终局非 PNE，仍可能存在另一个更差福利 PNE；此例排除那个可能。

这不否定 Q-CAG-HALF，不否定聚合安全值桥或最低静态 CCE 福利桥。反例本身满足半覆盖；它不声称客户数、主题数或人数最小，也不扩大到异构目录或带权提供者。

## 单位客户与完整策略

主题标签为 0、1、2、3。每行表示该数量的不同单位客户；重数不是提供者权重。

| 喜欢的主题 | 不同客户数 |
| --- | ---: |
| {1} | 1 |
| {0,1} | 2 |
| {0,1,2} | 2 |
| {1,3} | 3 |
| {2,3} | 3 |
| {0,2,3} | 5 |

四个覆盖两两不同，总客户数为十六。根选 0。第二人在首主题 0、1、2、3 后分别选 3、2、1、0。末位完整策略如下，行是首主题，列是次主题。

| 首 / 次 | 0 | 1 | 2 | 3 |
| --- | ---: | ---: | ---: | ---: |
| 0 | 3 | 3 | 3 | 3 |
| 1 | 3 | 3 | 3 | 3 |
| 2 | 3 | 3 | 1 | 1 |
| 3 | 3 | 2 | 1 | 1 |

尤其历史 (1,3) 和 (3,1) 具有相同计数，末位却分别选 3 和 2；二者都为并列最优。这里完整保留历史依赖平局，未把策略限制为计数规则。

## 所有子博弈的最优性

末位每个历史的最大收益如下。上述策略逐格达到此值，核对方式是将四个合法行动逐一代入均分公式。

| 首 / 次 | 0 | 1 | 2 | 3 |
| --- | ---: | ---: | ---: | ---: |
| 0 | 23/3 | 7 | 37/6 | 14/3 |
| 1 | 7 | 9 | 11/2 | 5 |
| 2 | 37/6 | 11/2 | 20/3 | 11/2 |
| 3 | 14/3 | 5 | 11/2 | 6 |

固定该末位策略，第二人每种行动的最终收益如下；各行指定的 3、2、1、0 均达到行最大值。

| 首 / 次人候选 | 0 | 1 | 2 | 3 |
| --- | ---: | ---: | ---: | ---: |
| 0 | 11/3 | 9/2 | 25/6 | 14/3 |
| 1 | 9/2 | 7/2 | 5 | 5 |
| 2 | 14/3 | 11/2 | 14/3 | 11/2 |
| 3 | 17/3 | 11/2 | 5 | 5 |

根分别选择 0、1、2、3 后，原完整策略的真实后继给首人收益
(17/3,11/2,5,14/3)。因此根选 0 严格最优。至此全部二十一处决策节点最优，给定策略是完整纯 SPE。实际路径 (0,3,3) 收益 (17/3,14/3,14/3)，覆盖十五。

## 静态均衡全集与最优覆盖

静态收益只依赖终局计数。四主题三玩家恰有二十个非负计数向量，总和均为三。下表对非 PNE 给出一个盈利偏离见证：位置按排序后的主题行动串从零编号；“位置 i→a；g”表示该玩家改选 a 的收益增量为 g。不存在盈利偏离的行即 PNE。

| 计数 (q0,q1,q2,q3) | 福利 | 静态判定 / 盈利见证 |
| --- | ---: | --- |
| (3, 0, 0, 0) | 9 | 位置 0→1；增益 7/3 |
| (2, 1, 0, 0) | 13 | 位置 0→2；增益 7/3 |
| (2, 0, 1, 0) | 12 | 位置 0→1；增益 7/3 |
| (2, 0, 0, 1) | 15 | 位置 0→1；增益 5/6 |
| (1, 2, 0, 0) | 13 | 位置 0→2；增益 7/3 |
| (1, 1, 1, 0) | 16 | 位置 0→2；增益 1/2 |
| (1, 1, 0, 1) | 16 | 位置 0→2；增益 1/2 |
| (1, 0, 2, 0) | 12 | 位置 0→1；增益 7/3 |
| (1, 0, 1, 1) | 15 | 位置 0→1；增益 5/6 |
| (1, 0, 0, 2) | 15 | 位置 0→1；增益 1/3 |
| (0, 3, 0, 0) | 8 | 位置 0→0；增益 11/3 |
| (0, 2, 1, 0) | 16 | 位置 0→0；增益 1/2 |
| (0, 2, 0, 1) | 16 | 位置 0→0；增益 1 |
| (0, 1, 2, 0) | 16 | 位置 1→3；增益 5/6 |
| (0, 1, 1, 1) | 16 | PNE |
| (0, 1, 0, 2) | 16 | PNE |
| (0, 0, 3, 0) | 10 | 位置 0→0；增益 1 |
| (0, 0, 2, 1) | 13 | 位置 0→0；增益 1 |
| (0, 0, 1, 2) | 13 | 位置 0→0；增益 1 |
| (0, 0, 0, 3) | 11 | 位置 0→0；增益 2 |

所以恰有两组 PNE 计数 (0,1,1,1)、(0,1,0,2)，覆盖均为十六；它们的所有玩家排列同样静态稳定。主题 1、2、3 已覆盖全部十六客户，故 OPT₃=16。

## 证据、依赖和接续

仅依赖 CAG-MODEL、均分收益定义及有限逐历史比较，不导入外部福利定理。反例发现使用规范全集逆向归纳，最终核验将类型展开为不同单位客户，按定义重算全部八十四项（含自身行动）真实 SPE 比较，以及二十个静态终局中的全部单方偏离；独立脚本不导入规范求解器或其证书验证器。

实例、完整策略、原字节审计、冻结结果与内部审查已按原相对布局保全，见[精确核验资源对象](../计算/三人静态纯Nash福利比较的定义级核验--计算.md)。本轮重放输出与冻结完整结果逐字段全等，包括84项SPE比较及20个静态终局全部盈利偏离。

失败机制是不同历史中的合法平局允许根偏离面对不同真实后继。本例的(1,3)和(3,1)是同计数、不同合法回复；计算收益可按计数缓存，策略不能因此改为计数规则。即使改用同实例另一静态PNE，其福利仍均为16，不能修补支配桥。
