# 真实尾平稳均值的额外查询封顶

## 被否定的构造与本次证据身份

[3963B完整原文](../../../../tools/evidence/root-repair-and-stationary-interfaces-primary/original/c57e4ec366e7af1be467/research/workspaces/customer-attraction/R-2d91ff13b4b44effbe7e78a60470bcc7/security/stationary_extra_fractional_boundary.md)定义SF-root：任意合法背景b、余r≥2名完整纯SPE，强制根A后尾为B_2(A),…,B_r(A)，令P(A,B)为r−1名真实后继中标签B的频率。取平稳主题分布pi，定义客户边际pi_x=sum_(A含x)pi_A，再用L_x=r pi_x作为确定分数背景，要求所有纯查询的价sum_(x∈T)1/(b_x+1+r pi_x)≤根actual u。stationarity确实给随机完整叶的平均客户负载E_pi c_x(Z(A))=r pi_x，但这不自动控制全部查询。

## 唯一平稳分布及全部查询价格

六强制根叶依次(0,3,4),(1,3,4),(2,3,4),(3,0,1),(4,0,1),(5,0,1)。所以P的X行在3/4各给1/2，Y行在0/1各给1/2，第2/5列零。平稳方程先迫pi2=pi5=0，再迫两组总质量各1/2、四剩余坐标相等，故唯一pi=(1/4,1/4,0,1/4,1/4,0)。新增核验直接代回piP=pi，平稳方程加归一化秩6，与此解析唯一性一致。

固定均值SF-root与[完整随机列的插入税/平稳身份](../引理/完整槽插入税与跨角色价格恒等式--引理.md)不同；也不同于只评价同一个查询分布的二次型，不能由此直接否定每个stationary strong-push合同或所有自由菜单。在这个固定P内另选平稳分布不能修复；改变P是另一构造，未由此否定，更一般选择仍须明确它的量词和付款。
