# 十八主题 private 点的固定路径单标签扩充障碍

设六位单位提供者共享十八旧标签，编号 0–5、6–11、12–17 分别是实际、比较、回复标签。保留 private 点每个物化旧兴趣型的全部旧成员资格及质量 \(m_i\)。只加一个标签 \(Z=18\)，允许每个旧类型独立任意分出质量 \(0\le z_i\le m_i\) 加入 \(Z\)，其余不加入。前六个实际行动仍为 \((0,1,2,3,4,5)\)。全策略及所有平局可重新选。此结论排除实质量盒中的解，亦排除有理清分母或固定整数拆分的解。

记 \(p_i=\sum_{j<4}b_{ij}\)，\(u_j\) 为第 \(j\) 个实际行动的旧利润，均用 0 基。旧目录的倒二行动 \(a=5,12,\ldots,17\) 各有严格正的最坏真实回复偏离收益。纯旧回复的利润排序不受添加新标签影响，故这些分支若要支持给定路径，必须以 \(Z\) 作最后回复。至少要求下述行 \(B_a\)，无需再用限制旧行动者收益的交叠减税行。

- \(B_a\) 为 \(-\sum_i z_i/(p_i+b_{ia}+1)\le-\theta_a\)，\(\theta_a\) 为该分支十八个旧末回复的最大利润。
- \(S_j\) 为 \(\sum_i z_i/(\sum_{l<j}b_{il}+6-j)\le u_j\)，因为实际前缀偏离 \(Z\) 时，后面至多 \(5-j\) 人加入任一客户。
- \(U_b\) 为 \(\sum_i z_i/(p_i+1+\beta_{ib})\le u_4\)，其中 \(\beta_{ib}=b_{ib}\) 对旧回复 \(b\)，而 \(\beta_{iZ}=1\)。这是倒二行动 \(Z\) 后以 \(b\) 为最后回复的倒二激励。
- \(R_{b,a}\) 为 \(L_b(z)\ge L_a(z)\)，这是 \(Z\) 作为倒二行动后最后行动 \(b\) 对任意旧行动 \(a\) 的真实末位最优性。其中旧 \(b\) 的 \(L_b(z)=\sum_i m_i b_{ib}/(p_i+1)-\sum_i z_i b_{ib}/[(p_i+1)(p_i+2)]\)，而 \(L_Z(z)=\sum_i z_i/(p_i+2)\)。

将每条选用行写成 \(c_s\cdot z\le d_s\)。下表各组非负乘子令 \(C=\sum_s\lambda_sc_s,\ D=\sum_s\lambda_sd_s\)。盒给精确下界 \(C\cdot z\ge \sum_i m_i\min(0,C_i)\)。表内 gap 是该下界减 \(D\)，全部严格为正，因此排除所有 19 个可能末位回复 \(b\)，包括最有利的平局选择。
