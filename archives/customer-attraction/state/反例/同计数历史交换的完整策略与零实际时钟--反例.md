# 被排的交换接口

固定[共同标签目录模型](../定义/共同目录完整历史模型--定义.md)的完整纯SPE。交换两个已发生动作后，必须从新的**有序历史**继续同一σ；不能把原尾原样移植，再仅以对称终局收益或计数匿名为由称它是真偏离叶。本页两个完整例子排这个辅助接口，以及仅由原根actual尾时钟支付交换残差的加强；不反half。

# 两单客户例：身份并非只置换收益

三人，A={x}、B={y}不交。根A，第二位A后B、B后A；末位AA→B、AB→B、BA→A、BB→A。完整7节点全部最优：AA/BB后未覆盖主题收益1严格最高；AB/BA后二者均1/2。第二位两行动真实收益都1/2；根A/B各经ABB/BAA得1。

actual ABB收益(1,1/2,1/2)，前两位交换后真叶BAA仍按位置给(1,1/2,1/2)；冻结旧尾则为BAB，收益(1/2,1,1/2)。原先A角色移到第二位置后所得1/2，不能把原1直接随身份搬过去。三种叶W都2=OPT₃。三人是“已交换两个动作后还留未来回复”所需最少人数，不主张其它全模型最小性。

# 五客户例：整个旧群体也发生净损失

三人，A/B/C两两不交，大小2/2/1。根B；第二位在A/B/C后分别B/A/A。全部末位表：

| 首\次 | A | B | C |
|---|---|---|---|
| A | B | A | B |
| B | C | A | A |
| C | B | A | A |

AA后B、BB后A各得2；CC后A/B均2，选A。AC/CA后B、BC/CB后A各2严格最好。AB/BA后A/B/C都给末位1，所以AB选A、BA选C均合法。第二位每节点恰三行动，真收益按A/B/C为：首A后(1,2,1)，首B后(2,1,1)，首C后(2,2,1/2)，规定B/A/A均最优。根三叶ABA/BAC/CAB的根收益(1,2,1)，故B最优。已覆盖1+3+9=13个全部ordered节点、39含self比较。

actual BAC收益(2,2,1)，W5=OPT₃；交换前两动作后AB的真回复A，叶ABA收益(1,2,1)、W4。若搬原尾C则ABC，收益(2,2,1)、W5。AB与BA前缀客户负载完全一样，末位最大收益也一样1，前两人的总收益却4→3。两个第二层节点又恰互惠选择另一个大主题，且相对其它行动严格更优，仍不授权同尾耦合。

固定两旧玩家的同一标记a=1_A+1_B。BA后真尾C从未hit标记，clock0；AB后真尾A稀释两名旧A客户，clock
\[
 {2\over(\rho+1)(\rho+2)}.
\]
ρ0时旧群体租金4−3=1，ρ1时差1/3，反向交换取相反号。不是BR强制的统一有利方向。[双分支时钟引理](../引理/标记真实历史交换的双分支时钟与终局净债--引理.md)保留它作为两尾有符号差；把它换成原actual零clock便直接错。

若同一末位节点两个BR的末位收益相等，旧群体总收益差恰等最终福利差，因为W=Σu；这只解释差的来源，不提供符号。不能任意翻转整个策略的平局后还假定全树仍SPE，本页仅对明确给定的完整表主张可信性。
