# 抽象势菜单删除边际反例

完整实读 1,787 B，并以 Fraction 运行 exit 0。程序硬编码匿名 exact-potential 表 F/G 与完整 13 个有序历史策略，核 39 个动作比较；实际 `(B,C,C)`，payoffs `(0,1,1)`，W=2。所有两玩家背景下的单动作 utility 非负；真实菜单分别为 `{{C,C},{A,B}}`、`{{B,B},{B,C}}`、`{{B,C}}`。

它构造分布 q，使每个固定 action 的期望 utility 为 `3/4`，并对所有真实 menu 用 p 检查 menu cap `3/4`；因此 `cap-W/3=1/12>0`。这精确排除“任意匿名对称精确势都自动给真实菜单 cap≤W/m”的更宽证明路线。

但 F/G 是任意匿名势表，非 CAG 客户覆盖收益；程序输出自身写明 `broader symmetric exact-potential game; not CAG`。所以该反例不是 customer-attraction 的 SPE、half、static CCE 或 unrelated-machines 反例。对象处置为 integrated 抽象势障碍。
