# 被否定的是纯组合均等基准

采用[完整有序历史共同目录模型](../定义/共同目录完整历史模型--定义.md)：有限单位客户、有限非空共同目录、m名单位提供者，终局覆盖者均分，保空主题、重复、零客户与任意离轨平局。对任意合法m主题元组T定义静态组合利润u_i(T)，置

\[
P_m=\max_{T\in\mathcal S^m}\min_i u_i(T).
\]

T只是一份共同选题组合，不要求静态NE或动态SPE。被检验的普遍桥EG为每份完整纯SPE的actual福利W≥mP_m。它不同于隐藏混合query对静态对手的安全值v_m，也不同于最坏纯背景的末位θ_m；不能只因都含min/max互换它们的量词。

下面对每个整数m≥2反EG，且同时给共同付款证书的显式可行点。它既不反half，也不分离扩张ROLE，没有搜索或固定人数扫描。

# 全部有序历史的单位客户与常值策略

取互不相交的单位客户块C_j、E_j（j=1,…,m），大小分别m和m−1。共同目录为

\[
A=\bigcup_j C_j,\qquad T_j=C_j\cup E_j.
\]

共有m+1个不同主题，所有m块C、m块E均互不交，客户总m(2m−1)。m≥2使各私有块非空；m1退化不在本族人数范围。每个合法有序历史都规定A，包含所有过去曾偏离、重复选T_j的历史；不删除任何离轨选择。

在任一当前节点，过去T_j出现次数为t_j，t=Σ_jt_j≤m−1，余下规定动作全A。当前遵从A后，最终A玩家数m−t，每个C_j负载m−t+t_j，因此

\[
U_A=m\sum_j\frac1{m-t+t_j}.
\]

若当前改T_k，未来仍全A；C_k因当前A换成T_k仍被当前覆盖，最终负载同为m−t+t_k，私有E_k负载t_k+1。所以

\[
U_{T_k}=\frac m{m-t+t_k}+\frac{m-1}{t_k+1},
\]

\[
U_A-U_{T_k}=m\sum_{j\ne k}\frac1{m-t+t_j}-\frac{m-1}{t_k+1}\ge0.
\]

因为1≤m−t+t_j≤m，每个前项至少1，第一和至少m−1，第二项至多m−1。此证明逐**所有**合法历史与全部T_k比较；规定A及任意等值偏离按平局选A。因此常值策略是完整纯SPE，不是只验根叶或静态NE。

机制也已被[旧常值A的全历史iff](../构造/实际遗漏全共享的常值均衡近二族--构造.md)覆盖：这里|A\T_k|=m(m−1)=m|T_k\A|，恰为CONST等号。本源不认领常值均衡机制首次；独有保留是其精确P_m及付款接口用途，不能将不同参数/共享主题支架的旧族原位改成同一个原件。
