# 逐人静态安全值末位保底的精确反例

## 候选及反例

对共同目录与 (n) 位提供者，令
\[
b_a(h)=\sum_{x\in S_a}\frac1{h_x+1},\qquad
\theta=\min_{h\in\mathcal S^{n-1}}\max_a b_a(h).
\]
候选“任意完整纯 SPE 中每位提供者收益至少 (	heta)”为假。

来源 `44ef31ca794614c1c6c0` 给出 (n=4)、12 主题的完整纯 SPE，实际路径标签为 ((8,4,5,0))，客户按 4095 个非空兴趣类型压缩为 26,171,145 名单位客户。精确数值：

| 量 | 值 |
|---|---:|
| (	heta) | 6,135,346 |
| 实际 (u_1,u_2,u_3,u_4) | 6,135,345；6,135,380；6,135,380；6,135,371 |
| (W) | 24,541,476 |
| (OPT_4) | 24,541,532 |
| (2W-OPT_4) | 24,541,420 |

所以 (u_1=	heta-1)，但 (W/OPT_4=6135369/6135383>1/2)。这只否定逐人静态 (	heta) 保证；它不是 half 反例，也不否定最后两位的 (	heta) 下界。

## 完整 SPE 证书

保存策略为每个长度 0–3 的有序历史指定一个动作，共 (1+12+12^2+12^3=1885) 个节点。独立审计逐历史、逐 12 个行动计算原策略真实续局收益，检查 22,620 个比较，其中 20,735 个为非自身行动，最小严格差为 1。根部各行动给第一人的收益为：标签 0–3 为 6,135,344，4–7 为 6,135,342，8–11 为 6,135,345；根选 8 是最佳回应。

(	heta) 的有限穷举检查全部 \(\binom{14}{3}=364\) 个三人前缀计数和 12 个末位动作；(OPT_4) 检查 \(\binom{15}{4}=1365\) 个终局计数，唯一最优为标签 0、1、2、3 各一次。构造的 Möbius 扰动和统一正偏置只用于生成该实例；一般偏置定理不能回填上传偏置的全称保证。

该证书保留完整历史、重复主题和任意平局，证明的是一个有限辅助断言失败，不能替换逐人 residual、首步税桥或一般聚合安全桥的定义。
