# 同一σ标签与缺失的策略量词

actual前三h、强制第四T_i后的B_i,C_i，定义R_(0,i,j)=σ₆(h,T_i,B_j)仅i≠j，R_(1,i,j)=σ₆(h,T_i,C_j)全部i,j；Z_e=σ₆(A₁,…,A₄,R_e)。原9164B README全文保这一身份，forced第五位只用原源IC，只有真末回复R/Z在各自节点用BR。空/重复/任意平局不规范化。

以下构造只做**客户主题会员的共同凸实现**及指定必要行保存。即使所有会员能由同一非负客户测度实现，也还没有给σ在所有有序历史的行动和IC；整数缩放成共同目录输入也不自动产生SPE。固定支持的成功/失败均不越过这个量词缺口。

# 阈值R与条件独立Z的完整实现

每个旧hist质量h≥0，R轨道边缘质量r_g∈[0,h]。取共同t均匀在[0,h]，令R_g=1_(t<r_g)，于是所有R交叠同时为min(r_g,r_f)，不是任意pairwise矩拼凑。按所有0,r_g,h断点切有限slabs；每slab全部R位确定。h0时无质量，不定义条件比。

在slab质量w>0内给每轨道Z的质量y_(s,g)∈[0,w]，以y/w为条件会员概率，独立生成各Z。有限二元立方体所有赋值及乘积概率形成非负凸组合，精确实现各Z边缘。旧行及Z→Z行在R固定后对Z仿射，因为

\[
U_{p_a}(Z_e,R_e)-U_{p_a}(Z_f,R_e)
=(z_e-z_f)/(p_a+1+r_e).
\]

故只需所列线性行成立即可保存。这里条件独立是构造一个松弛点的会员实现，不对原SPE或客户作独立性假设。

若还加PAIR(Z_e,Z_f)，交叠以非负系数进入真行（强PAIR左边移项后+G）。其最大值≤min(y_e,y_f)。用slab内第二个共同阈值令全部Z嵌套，同时达到每对min；所有仅依Z边缘的旧仿射行不变，所有上述正交叠行不减。R-Z交叠在R固定的slab也线性，因此共同嵌套构造同时保存，不只逐对自说可行。

此证明要求每一被保存行在Z-Z交叠上确实非负、其它依赖只为已保留的仿射会员。加入新带负交叠或更高联合项时必须重审，不能从“cube已实现”继承任意后续行。

# 固定旧R/Z二维边缘的失败只否这个完成域

若另固定旧每个(R_g,Z_g)边缘，记v_g=|R_g∩Z_g|、o_g=|Z_g\R_g|。在共同阈值R下，Z_g在R_g内/外分别放最低t区间，可同时最大化与各R_f的交叠：r_f≤r_g时min(v_g,r_f)；r_f>r_g时v_g+min(o_g,r_f−r_g)。
