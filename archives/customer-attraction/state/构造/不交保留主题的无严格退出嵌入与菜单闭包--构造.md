# 旧游戏、条件和全树构造

固定[共同目录模型](../定义/共同目录完整历史模型--定义.md)的一份n人完整纯SPE σ，n≥2。令η≥0为其**所有旧有序决策历史**的规定最终收益统一下界，而非只沿actual。对旧主题T记
\[
 \delta_T=\min_{S\text{ 旧目录}}|T\cap S|,\quad
 L=\max_T(|T|-\delta_T/2).
\]
取整数J>0，要求
\[
 \boxed{J/2\le\eta,\qquad J\ge L.}\tag{NEW}
\]
增加J名不同的新单位客户，旧主题全不覆盖它们，新主题B恰覆盖这J人；增加一名新首位玩家。新旧目录标签均保，B不与旧客户交叠。

在n+1人所有有序历史上定义策略：

1. 过去尚无B时规定B。
2. 过去恰一个B时，擦除它，按所余旧有序历史执行σ。
3. 在首次出现第二个B的每个最小前缀下面，独立选一份完整逆向归纳SPE，之后全部沿它行动。

这些首次第二B子树两两不交；从第三域无法回到前两域。有限非空行动集保证第三域子SPE存在。第二域删B后旧前缀长度合法，恰有n个旧角色位置可供执行，保每一旧离轨有序历史及任意原平局。

# 为什么所有节点都最优

恰一个B的节点，规定旧行动与任一旧偏离之间，B与旧客户不交，双方真实后继都逐字等于旧σ，因此继承其完整IC。改B会进入第二B子树；不论那里的可信回应怎样，当前在B上最多J/2，不超过规定旧收益η。

尚无B的节点，规定B后进入第二域，后来不再选B，当前得J。若改旧T且不是末位，下一位规定首次B，此后完成旧σ；终局共有n个旧行动。若已为末位，终局共有n+1个旧行动。n≥2保证偏离T之外至少有另一个旧主题S，所以其利润至多
\[
 |T\setminus S|+\tfrac12|T\cap S|
 \le |T|-\delta_T/2\le J.
\]
额外旧覆盖只会降低收益，B不影响旧客户。第三域由所选完整BI给最优性，故新策略为完整纯SPE。实际新首位B，随后完整旧actual原样保留，W'=W+J。

此证明移除[旧不交保留构造](不交保留主题的增人数全历史嵌入--构造.md)额外的严格退出条件|T|/2>J/n；旧构造本身仍正确，其53单位客户审计仍属旧完整策略，不能把本新拼合的所有离轨平局自动认作与旧动作表逐项相同。本组主件明确给出了上述新证明，未取得的independent原稿不借引用冒称已全文。

n1不可直接放宽：旧目录只有一个三客户主题，η3、δ3、L3/2，J2满足NEW；但新根规定B仅得2，改旧T后下一位B使它独得3，故该控制器失败。若另加J≥max_T|T|，无B域直接由主题大小封顶，上述构造对n1有效。零客户/空旧主题不会造成公式除零；若条件不可满足则不作存在保证。J>0使B有新客户；当前允许同覆盖标签，但此B本来也与所有旧覆盖不同。

# 菜单量及通用的逐字提升合同

以下先只假设某份新完整SPE确有“根B、每个B开头且后来仅旧行动的历史逐字旧σ”的性质；不要求它一定由NEW生成。记旧actual终局z、福利W，实际位置i强制旧行动A后沿σ真实回应的完整n槽终局为Z_i(A)，含当前行动，不删除当前。对旧查询分布p令
\[
 J_T(z)=\sum_{x\in T}{1\over1+c_x(z)},\quad
 \psi_i(p)=\min_A\mathbb E_{T\sim p}J_T(Z_i(A)),
\]
\[
 L_z(p)=\mathbb E_pJ_T(z),\quad M=\max_TJ_T(z).
\]
每个菜单含实际行动列，故ψ_i(p)≤L_z(p)≤M。U是候选“对每个p，Σ_iψ_i(p)≤W”，这里不证明它普遍成立。

任意新查询分布写p'=αδ_B+(1−α)p，α∈[0,1]；α1时任取旧p。新actual B只有一个覆盖者，故B的fresh查询值J/2。对新位置i+1，把偏离限制为旧A，真实叶仍含单个B加旧Z_i(A)，从而
\[
 \psi'_{i+1}(p')\le\alpha J/2+(1-\alpha)\psi_i(p).
\]
根只用实际B列即有
\[
 \psi'_1(p')\le\alpha J/2+(1-\alpha)L_z(p).
\]
这些是限制最小化候选列所得的上界，不声称新菜单只有这些列；其它新合法列无需删除。

# 无权、加权及实际cap的条件闭包

若旧U成立，则相加给
\[
 \sum_{i=1}^{n+1}\psi'_i(p')
 \le(1-\alpha)(W+M)+\alpha(n+1)J/2.
\]
只要
\[
 \boxed{M\le J,\qquad (n-1)J/2\le W,}\tag{C}
\]
两个端点都≤W+J，新U成立，包含α0/1、任意查询支持和平局。

更精确地，给定λ∈Δ_n，写E=nΣ_iλ_iψ_i(p)−W，提升权重λ'=(1,nλ)/(n+1)。逐项代入得
\[
 \boxed{E'\le(1-\alpha)E
 -(1-\alpha)[J-L_z(p)]
 -\alpha[W-(n-1)J/2].}\tag{WEIGHT}
\]
这清楚保两项新余量。它是同一指定p、λ的条件关系，不证明原任意游戏有有利λ或共同付款。

实际新cap恰M'=max(M,J/2)。若旧M≤W/n且(C)成立，则M≤min(W/n,J)≤(W+J)/(n+1)，后一个不等式分J≤W/n和J≥W/n清分母即证；J/2≤(W+J)/(n+1)恰等价(C)第二式。因此新M'≤W'/(n+1)。

NEW构造条件足以保证(C)：旧actual至少有一旧主题S，逐客户J_T(z)≤|T|−|T∩S|/2≤|T|−δ_T/2≤L≤J；又旧actual n人每人≥η，故W≥nη≥nJ/2。这里W≥nJ/2比(C)第二式稍强，但η全历史假设对构造仍承重。

# 用途、证据和未闭合的目标

这是一项任意旧游戏上的条件变换及菜单闭包。它说明满足U或actual cap平均界的旧点不会被这类合条件逐字提升变成相应反例；不能凭闭包断言初始所有游戏已满足U，也不能把新首位保留主题迭代当作任意六人目录归约。原root明确把菜单代数与全树可信构造分开，本页保留这个区分。

本组根CLAIMS/GENERAL_WORKING/失败路线均全文；上述证明是知情解析重构，无新BI/LP/菜单程序运行。旧[菜单盲审资源](../审查/预留菜单盲审三源实质复核--审查.md)的400历史/2800比较及343有序静态背景已有充分独立证据，本次0重跑，亦不借它证明这条新一般控制器。后续可把(C)用于确已构造的策略变换，或寻找新的跨真实孩子预算；一般U、Mpath与half均未由此页闭合。
