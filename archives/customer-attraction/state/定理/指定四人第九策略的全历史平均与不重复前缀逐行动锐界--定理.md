# 指定四人第九策略的全历史平均与不重复前缀逐行动锐界

固定四人、共同目录 \(\{0,1,2,3,4\}\)、客户价值均分及 [第9棵完整形式策略](指定四人不重复比较前缀平均锥的锐比三十三除十六--定理.md)。全部156个有序历史的动作如下，按深度和五进制字典序读取。

| 深度 | 动作 |
|---:|---|
| 0 | 2 |
| 1 | 00202 |
| 2 | 0000020022022200002020022 |
| 3 | 00002000200220022000020000202222200000022220202002020022020202220222220220222202020020222020200020200022222022000220202222220 |

令 \(R_{h,j}\) 为规定行动的收益减去先改 \(j\) 再沿同一策略完成的真实收益。记 \(J=\{1,2,3,4\}\)、\(W\) 为实际 \(2222\) 覆盖、\(O_J\) 为比较覆盖。两套条件分别是

- 对全部156个有序历史要求 \(A_h=\frac14\sum_{j\in J}R_{h,j}\ge0\)。
- 对长度0至3的不重复 \(J\) 前缀 \(h\)，每个 \(j\in J\setminus\{h_k\}\) 的 \(R_{h,j}\ge0\)，共64个比较。

**定理。** 在非负客户型质量且 \(W>0\) 上，两套条件的 \(O_J/W\) 最大值依次为 \(7/4\) 与 \(11/6\)。要求 \(J\) 最优时，两最大值各自仍可达到。

## 全历史平均

对一个客户型 \(M\) 记 \((a,x,y,z)=(\mathbf1[2\in M],\mathbf1[1\in M],\mathbf1[3\in M],\mathbf1[4\in M])\)，则 \(w_M=a\)、\(o_M=\mathbf1[a+x+y+z>0]\)。在重复历史 \(h=(2,2,2)\) 规定2，四个比较终局是 \(2221,2222,2223,2224\)。该平均行的单型系数
\[
s_M=\frac{3a}{16}-\frac{x+y+z}{4(1+3a)}
\]
直接由份额计算。只用此行，乘子为4，得到逐型余项
\[
\frac74w_M-o_M-4s_M
=a+\frac{x+y+z}{1+3a}-o_M\ge0.
\]
若 \(a=1\)，右端为 \((x+y+z)/4\)。若 \(a=0\)，右端为 \(x+y+z-\mathbf1[x+y+z>0]\)。乘各型非负质量后求和，得到 \((7/4)W-O_J\ge4A_{(2,2,2)}\ge0\)。

取掩码 \(4,5,9\) 客户数 \(20,8,21\)，共49位单位客户。\(W=28\)、\(O_J=\operatorname{OPT}_4=49\)，且全部156条 \(A_h\ge0\)。按深度0至3，各组最小余量依次为 \(7/2,0,0,0\)，零行数依次为 \(0,2,1,1\)。唯一使用的行与三个正质量型的余项皆为零。此点在仅平均未使用比较行动的筛选行中有负项，例如 \(h=(1)\) 的整数余量为 \(-25/18\)。因此两套平均行不能简单以包含关系处理。

## 同一不重复前缀的逐行动比较

取三条真实行 \(R_{(2),1},R_{(2),3},R_{(2,3),4}\) 各乘1。前两条规定终局 \(2222\)，偏离终局 \(2122,2322\)；第三条规定终局 \(2322\)，偏离终局 \(2342\)。相加的单型系数是
\[
\frac a2+\frac a{3+y}-\frac{x+y}{1+3a}-\frac z{1+2a+y}.
\]
于是 \((11/6)w_M-o_M\) 减去这一系数，得
\[
a\left(\frac43-\frac1{3+y}\right)+\frac{x+y}{1+3a}
 +\frac z{1+2a+y}-o_M\ge0.
\]
若 \(a=1\)，扣去 \(o_M=1\) 后的首项为 \(1/3-1/(3+y)\ge0\)，另外两项非负。若 \(a=0\) 且 \(x+y\ge1\)，该项已付 \(o_M=1\)；若 \(a=x=y=0\)，最后正项为 \(z=o_M\)。因此在保留64条比较的锥中，\(O_J\le(11/6)W\)。

取掩码 \(3,5,9,17\) 客户数 \(3,12,3,4\)，共22位单位客户。\(W=12\)、\(O_J=\operatorname{OPT}_4=22\)，全部64条比较非负，按深度0至3的零行数依次为 \(1,3,5,5\)。三条使用行与四个正质量型的余项均取零。这个达到点在 \(h=(2,2,2)\) 对整个 \(J\) 的平均余量为 \(-1/4\)。逐行动条件确实蕴含在相同历史对相同备选动作的平均条件，后者在固定策略上只给锐比 \(33/16\)。

两份上界的证明都只使用表中固定的 \(\sigma\) 与 \(J\)。采用 [标准库复验程序](../../tools/evidence/distinct-prefix-average-sharp-33-over-16/verify_strengthened_fixed_cones.py) 可逐历史重建两点，验证31项解析余项并核两份比较组最优性。[精确证据](../../tools/evidence/distinct-prefix-average-sharp-33-over-16/exact-strengthened-check.json) 保存全部余量、三条逐行动行及一条全历史平均行的逐型系数。
