# 固定背景下恰三名剩余玩家的5/3利润界

客户集 $N$ 有限，客户价值均为一；共同主题目录 $\varnothing\ne\mathcal S\subseteq2^N$ 有限。单位提供者依次观察全部有序前史，各选一个目录主题；客户价值在所有最终覆盖者之间均分。允许空主题、重复选择、零客户和任意离轨平局。固定一份在**所有合法有序历史**定义的纯SPE，偏离后始终沿这同一份策略在改变后的历史继续；相同负载的不同有序历史不必使用同一续局。完整定义见[共同目录模型](../定义/共同目录完整历史模型--定义.md)。

固定任意合法有序前缀，客户背景负载 $p_x\in\mathbb Z_{\ge0}$ 是该前缀真实选择的覆盖次数；截取给定策略的子树仍是固定背景下的完整纯SPE。下面多项式的非负性也对实数 $p\ge0$ 成立，但本页博弈定理量化的是这个单位玩家模型的合法前缀，并未把任意实向量自动当作可到达历史。零分子份额一律定义为零，包含分母同时为零的情况。

## 1. 利润对象与结论

此后恰有三名玩家，按后缀相对位置编号1、2、3，给定SPE的实际路径记为 $(A,B,C)$。

定义三名剩余玩家的总利润和单人利润

\[
R_p(X,Y,Z)=\sum_x\frac{\mathbf1_X(x)+\mathbf1_Y(x)+\mathbf1_Z(x)}
 {p_x+\mathbf1_X(x)+\mathbf1_Y(x)+\mathbf1_Z(x)},
\qquad
U_p(X;Y,Z)=\sum_{x\in X}\frac1{p_x+1+\mathbf1_Y(x)+\mathbf1_Z(x)}.
\tag{1}
\]

零分子项取零。令 `u_1,u_2,u_3` 为真实三位的利润，则
`R=R_p(A,B,C)=u_1+u_2+u_3`。对任意三个合法比较主题 `(T_1,T_2,T_3)`，有

\[
\boxed{R_p(T_1,T_2,T_3)\le\frac53R_p(A,B,C).}\tag{2}
\]

特别地，定义 `F_3(p)=max_{T_1,T_2,T_3}R_p(T_1,T_2,T_3)`，得到
`F_3(p)≤(5/3)R`。这是**剩余玩家利润**界；非零背景下它不等于总覆盖。
常数作为全部合法背景的统一常数是锐的：空前缀属于本类，取一含三名客户的大主题及两个独立单例，三主题两两不交；每个有序历史均选大主题的完整策略达到 `5/3`。在任意节点，选择大主题的最终收益至少为 $3/3=1$，偏离任何单例的最终收益至多一，故这份全树策略为纯SPE；实际利润为三，比较三个主题可得五。

## 2. 同一策略的真实回复和八类 slack

把固定原前缀省略在记号中。令
`L_i=σ_3(A,T_i)` 为实际第一位行动 `A` 后第二位偏离 `T_i` 的真实末位回复；
令 `Q=σ_2(C)`、`R'=σ_3(C,Q)` 为第一位偏离合法主题 `C` 后的真实后两位路径。
这里 `R'` 是主题，前节的 `R` 是利润总和。

以下 slack 都非负：

| slack | 定义 | 合法比较 |
| --- | --- | --- |
| `K_Q` | `3u_1−Σ_x3·1_Q(x)/(p_x+3)` | 第一位偏离 `Q`，真实偏离终局负载至多 `p_x+3` |
| `K_R'` | `3u_1−Σ_x3·1_R'(x)/(p_x+3)` | 第一位偏离 `R'`，同上 |
| `P_i` | `u_3−U_p(T_i;A,B)` | 实际末位节点相对 `T_i` |
| `Z_i` | `u_3−U_p(L_i;A,B)` | 实际末位节点相对 `L_i` |
| `S_i` | `u_2−U_p(T_i;A,L_i)` | 实际第二位节点偏离 `T_i`，跟随真实 `L_i` |
| `V_ij`，`i≠j` | `U_p(L_i;A,T_i)−U_p(L_j;A,T_i)` | 真实末节点 `(A,T_i)` 相对合法 `L_j` |
| `F` | `u_1−U_p(C;Q,R')` | 第一位偏离 `C`，跟随真实 `Q,R'` |
| `J_i` | `U_p(R';C,Q)−U_p(T_i;C,Q)` | 真实末节点 `(C,Q)` 相对 `T_i` |

共同目录使跨节点主题均为合法行动。根保底仅用偏离后的最终负载上界，
未冻结后两名行动；其他回复也全部属于固定原 SPE。

取原三人根证明的同一加权和

\[
G=2K_Q+3K_{R'}+17\sum_iP_i+2\sum_iZ_i+12\sum_iS_i
  +4\sum_{i\ne j}V_{ij}+14F+\sum_iJ_i\ge0.\tag{3}
\]

## 3. 背景恒等式与二次多项式

固定一名客户，记其背景为 `p`，主题 membership 为
`a,b,c,q,r∈{0,1}`，并令
`s=a+b+c`、`d=Σ_i1_{T_i}`、`ell=Σ_i1_{L_i}`、`h=Σ_i1_{T_i}1_{L_i}`。
其中 `d,ell∈{0,1,2,3}`，`r` 对应主题 `R'`。
记 `α=a/(p+s)`、`β=b/(p+s)`、`γ=c/(p+s)`，零分子仍取零。

展开真回复比较时，配对项 `h` 的系数仍恰消去。例如

\[
\begin{aligned}
\sum_iU_{p,x}(T_i;A,L_i)
 &=\frac d{p+a+1}-\frac h{(p+a+1)(p+a+2)},\\
\sum_{i\ne j}V_{ij,x}
 &=\frac{d\ell-3h}{(p+a+1)(p+a+2)}.
\end{aligned}\tag{4}
\]

故客户对式 (3) 的贡献为

\[
\begin{aligned}
G_x={}&29\alpha+36\beta+57\gamma-\frac{6q+9r}{p+3}
 -\frac{17d+2\ell}{p+a+b+1}-\frac{12d}{p+a+1}
 +\frac{4d\ell}{(p+a+1)(p+a+2)}\\
&-\frac{14c}{p+c+q+r}+\frac{3r}{p+c+q+r}
 -\frac d{p+c+q+1}.
\end{aligned}\tag{5}
\]

若 `c=q=r=0`，两项共同分母可能在 `p=0` 为零，它们的分子也为零，按零项处理。
定义

\[
\rho_p=50\frac s{p+s}-30\frac d{p+d}-G_x.\tag{6}
\]

这给逐客户恒等式 `50R_{p,x}(A,B,C)−30R_{p,x}(T_1,T_2,T_3)=G_x+rho_p`。
其非负性可以一次证明全部背景，而非只检查有限个背景值。

定义

\[
P_0(p)=0,\quad P_1(p)=(p+2)(p+3),\quad
P_2(p)=(p+1)(p+3),\quad P_3(p)=(p+1)(p+2).
\]

由于式 (5)、(6) 的非零分母只能为 `p+1,p+2,p+3` 或其中相邻两个的乘积，
余项乘 `(p+1)(p+2)(p+3)` 恰是二次多项式

\[
\begin{aligned}
N_{abcqr;d,\ell}(p)={}&(50s-29a-36b-57c)P_s(p)-30dP_d(p)
 +(6q+9r)P_3(p)\\
&+(17d+2\ell)P_{a+b+1}(p)+12dP_{a+1}(p)
 -4d\ell(p+3-2a)\\
&+(14c-3r)P_{c+q+r}(p)+dP_{c+q+1}(p).
\end{aligned}\tag{7}
\]

换言之 `rho_p=N(p)/((p+1)(p+2)(p+3))`。

## 4. 全部系数非负，而非有限背景外推

`(min c_0,min c_1,min c_2)`；三个最小值允许由不同 `(d,ell)` 取得。

\[

## 5. 对五人及一般人数的可用接口

任意 `m≥3` 的真实路径，固定末三名之前的原有序前缀，客户背景记为 `b_x`，
实际末三人总利润记为 `V=u_{m-2}+u_{m-1}+u_m`。任取达到 `OPT_m` 的
`m` 个比较主题，客户比较重数为 `d_x∈{0,...,m}`。
对全部 `binom(m,3)` 个不同比较索引三元组应用式 (2)，恰得

\[
\boxed{\sum_x\sum_{j=1}^3
 \binom{d_x}{j}\binom{m-d_x}{3-j}\frac j{b_x+j}
 \le\binom m3\frac53 V.}\tag{8}
\]

约定非法二项式系数为零。即使比较主题重复，索引三元组仍然合法，客户计数公式亦成立。
若客户被最优组合覆盖，挑选一个覆盖它的索引；含该索引的 `binom(m-1,2)` 个三元组
每个贡献至少 `1/(b_x+1)`。式 (8) 因而另给

\[
\operatorname{OPT}_m\le\frac{5m}{9}V+\sum_x\frac{b_x}{b_x+1}.\tag{9}
\]

恰五人时背景只计前两位，系数是 `25/9`。式 (8) 保留真实最优重数 `d_x`，
式 (9) 是便于使用的粗化；两者都不能单独被称为五人半覆盖。
本稿没有恢复已失败的一般背景总税 `F_k≤R+tau`：`5/3` 是比例预算，而不是税预算。


## 6. 比较、审计与接续

[三人根锐界](三人锐福利界--定理.md)使用同一八类真实回复和权重。本页的新增义务是非零背景下的利润目标及全部背景的二次多项式证明；不能仅在根恒等式的分母中添加 $p$ 后宣布结论。$p=0$ 是本定理特例，同时提供整个合法背景类上统一常数 $5/3$ 的匹配下界；不声称每个固定非零背景自身都有该最坏比。

[非零背景总税反例](../反例/非零背景总税--反例.md)否定的是加性预算 $F_k\le R+\tau$，与此比例界不冲突。本证明不依赖两人税、较弱的三人142/81界、静态PNE或匿名平局。

式(8)保留最优元组每名客户的真实重数，式(9)丢弃部分重数信息；它们都是一般人数的合法必要条件。六人时式(9)系数是 $10/3$，还含前缀项，不给 $2W\ge\operatorname{OPT}_6$。零背景五人半覆盖已有[独立证书](五人半覆盖--定理.md)，原稿“不声称/未证五人half”只限制本推导，不能读成五人问题当前仍开放。恰六人仍见[问题页](../../subarchives/six-providers/问题--问题.md)。

[精确证书资源](../计算/三四人背景利润精确证书--计算.md)保留两份互不导入的原实现、原冻结报告和本轮原实现重放。主实现从(7)枚举512个整数系数三元组，并在2048个原membership上核对八类slack展开；独立原实现从原始slack作公共分母的精确多项式除法，重构同一512类并验证配对项消去。本轮复跑不是新增独立审查者。对有限背景的等式检查用于发现抄录/实现错误，任意背景结论来自完整符号系数的非负性；没有使用有限游戏抽样或LP最优值作证明。

关系判断：零背景根锐界是特化及权重来源；四人背景定理是不同的独立结果，不因人数相邻而依赖本定理；一般尾部提升使用背景利润对象与索引子集接口，其中当前无条件数值实例使用四人常数。第三阶段再依这些理由建超边，本页未生成图。
