# 五人共同最大主题的六十一行有理福利界

## 1. 陈述、量词与当前位置

客户集有限、客户价值均为一；共同主题目录是有限非空**标签**集，每个标签覆盖一个客户子集。五名单位提供者依次观察完整有序历史后各选一个合法标签；终局每名客户的价值在其覆盖者之间均分。固定任意一份在全部合法历史指定行动的纯 SPE。空主题、同覆盖异标签、重复选择、重复比较索引、零客户以及任意依赖完整历史的离轨平局全部保留。相同负载不代表相同续局。完整约定见[共同目录模型](../定义/共同目录完整历史模型--定义.md)。

令实际终局覆盖人数为 $W$、最优五主题覆盖为 $O=\operatorname{OPT}_5$，且

\[
K=\max_{S\in\mathcal S}|S|.
\]

目录有限非空保证最大值存在；达到它的主题不必是实际第一主题，也不必出现在下面的十个固定标签中。**所有行使用同一个真实 $K$。** 本证书证明

\[
\boxed{O\le\beta W,\quad
\beta=\frac{183538199237294659142159872004505983652023685928609569}
{90987354041588112882665017023745484527941187490861917}}
\tag{1}
\]

其中 $2<\beta<5043/2500=2.0172$，约为 $2.017183609421193$。$W=0$ 时使用普通非严格不等式，由证书得 $O=0$，不定义效率比。

这是原 `FIVE-SHARED-K-EXACT-v1` 的历史精确上界。当前[五人半覆盖定理](五人半覆盖--定理.md)已经证明更强的 $O\le2W$；原 README 和原评审中的 HALF(5)“OPEN”仅为原稿当时状态。本页保留独有的 61 行整数证书、共同容量消去机制及独立实现核验，不把较弱结果误写成当前纪录。它不认证松弛 primal 的最优性、真实 SPE 实现、反例或六人结论。

## 2. 同一策略中的路径、强制动作和索引

取达到 $O$ 的五元组 $(T_1,\ldots,T_5)$，保留全部索引，允许主题重复。固定标签次序 `ABCDEUVWXY`，从零编号。为区别福利 $W$，字符主题 `W` 在公式中写为 $W_0$。

| 记号 | 同一原策略给出的有序路径 | 优化者与强制者 |
|---|---|---|
| actual | $(A,B,C,D,E)$ | 五位均在自己的真实节点优化。 |
| second | $(A,E,U,V,W_0)$ | 在 $(A)$ 强制第二位选 $E$；第三至第五位依原策略。 |
| third | $(A,B,E,X,Y)$ | 在 $(A,B)$ 强制第三位选 $E$；第四、第五位依原策略。 |
| AB 的第 $i$ 路 | $(A,B,T_i,X_i^{AB},Y_i^{AB})$ | 第三位强制 $T_i$，后二位真实优化。 |
| AE 的第 $i$ 路 | $(A,E,T_i,X_i^{AE},Y_i^{AE})$ | 第三位强制 $T_i$，后二位真实优化。 |
| Sbranch 的第 $i$ 路 | $(A,T_i,U_i^S,V_i^S,W_i^S)$ | 第二位强制 $T_i$，后三位真实优化。 |

被强制者在被强制分支上不额外获得“最优性”。相关偏离受其原节点 IC 控制。若两个完整有序历史完全相同，同一策略自然给相同回复；客户型定价允许更大的代数域，不额外要求相同负载的不同历史使用同回复。

对每条固定路径 $\pi$，在该路径前三位之后，第四位强制选 $T_i$ 时的真实末回复为 $L_i^\pi$。对一个客户 $x$ 定义

\[
d=\sum_i1_{T_i}(x),\quad
\ell_\pi=\sum_i1_{L_i^\pi}(x),\quad
h_\pi=\sum_i1_{T_i}(x)1_{L_i^\pi}(x).
\tag{2}
\]

所有 $T_i$、固定标签和菜单回复都是共同目录中的合法查询，未将不同分支的收益直接计入实际福利。客户份额一律为会员位除以该路径总负载；**分子零时份额为零，包括总负载也为零**。

## 3. 本证书使用的全部行定义

以下均写成 $G_r\ge0$。所有收益都是所写路径上的真实终局收益。固定路径第 $j$ 位收益记为 $v_j^\pi$，actual 上记为 $u_j$。族 $F$ 第 $i$ 条路径的相应收益记为 $v_{i,j}^F$。

### 3.1 真节点保底与固定路径的末回复

在真正第 $j$ 位优化节点，客户前缀负载为 $p_j(x)$。对任意合法主题 $Q$，

\[
K_{\pi,j}(Q)=v_j^\pi-\sum_{x\in Q}\frac1{p_j(x)+6-j}\ge0.
\tag{3}
\]

偏离后所有尚未行动者至多都覆盖同一客户，所以真实偏离收益不低于所写保底，再由原节点 IC 支付。末位时这是精确最佳回复。`sum-opt` 是对五个 $T_i$ 求和；族交叉行 `F:π:j:sum-Z` 是在路径 $\pi$ 第 $j$ 位对族 $F$ 的全部五个 $Z_i$ 求和。`actual:j:sum-SZ` 是对 Sbranch 的五个 $Z_i^S$ 求和，含义相同。

本证书中 `second:5:O` 为

\[
5v_5^{second}+\sum_x\frac{p_5(x)}{p_5(x)+1}-O\ge0.
\tag{4}
\]

它由五个最优主题的末位比较与逐客户
$d/(p+1)+p/(p+1)\ge1_{d>0}$ 得到。所有比较属于同一个末节点。

固定路径前三位负载记 $p$、第四位会员位记 $b$，$\Delta=(p+1)(p+2)$。本证书的末回复行是

\[
\begin{aligned}
S_\pi&=5v_4^\pi-\sum_x\left(\frac d{p+1}-\frac{h_\pi}{\Delta}\right),\\
V_\pi&=\sum_x\frac{d\ell_\pi-5h_\pi}{\Delta},\\
Z_\pi&=5v_5^\pi-\sum_x\frac{\ell_\pi}{p+b+1},\\
D_\pi&=\sum_x\left(\frac{\ell_\pi-5\delta}{p+1}+\frac{d\delta-h_\pi}{\Delta}\right),
\quad\delta=1_D(x).
\end{aligned}\tag{5}
\]

依次对应 `reply:S/V/Z/topic-D`。$S$ 是第四位五次真实偏离 IC；$V$ 是五个真末回复节点各比较五个同菜单主题；$Z$ 是原末位比较五个菜单主题；$D$ 是五个真末回复节点各比较固定主题 $D$。例如 $D$ 行直接将
$U_p(L_i;T_i)-U_p(D;T_i)\ge0$ 对 $i$ 求和，故所写 $5\delta$ 不应换成 $d$。本证书只用 second 的 $D_\pi$。

两条固定偏离行是

\[
F^{second}=u_2-v_2^{second}\ge0,\qquad
F^{third}=u_3-v_3^{third}\ge0.
\tag{6}
\]

### 3.2 三个五索引族

AB、AE 族内按 $(T_i,X_i,Y_i)$ 编号 $0,1,2$，Sbranch 按 $(T_i,U_i,V_i,W_i)$ 编号 $0,1,2,3$。所有索引求和保留重复槽。

| 活跃行类 | 精确含义 |
|---|---|
| `AB:F3` | $5u_3-\sum_i v_{i,3}^{AB}$。 |
| `AE:F3` | $5v_3^{second}-\sum_i v_{i,3}^{AE}$。 |
| `Sbranch:F2` | $5u_2-\sum_i v_{i,2}^{S}$。 |
| `AB/AE:5:sum-Y` | 五个真末节点各比较同族全部五个 $Y_j$，共25项。 |
| `Sbranch:5:sum-W` | 五个真末节点各比较全部五个 $W_j^S$，共25项。 |
| `Sbranch:3:K:Y` | 五个真第三位在 $(A,T_i)$ 各比较固定 $Y$；客户分母为 $1_A(x)+1_{T_i}(x)+3$。 |
| `Sbranch:3:sum-W` | 上述五个真第三位各比较全部五个 $W_j^S$，共25项。 |
| `F:5:offdiag:r` | 同族第 $i$ 个真末位比较 $Q_{j,r}^F$，对全部 $i\ne j$ 求和，共20项。 |

表外带固定路径名称的 `sum-X/Y/SU/SV/SW` 均按(3)定义；其具体路径、位置、查询族和查询列完整编码在第5节的行名中。例如 `AB:actual:2:sum-Y` 是 actual 第二位对五个 $Y_i^{AB}$ 的保底比较，不是把 AB 第三位当第二位。

最后三条 PAIR 行使用保留一次交叠的真正末两人引理。若背景为 $b(x)$、真实末两人为 $M,N$，定义

\[
H=v_M+v_N+\sum_{x\in M}\frac1{(b+1)(b+2)},\quad
f(Q)=\sum_{x\in Q}\frac1{b+1},\quad
g(Q,R)=\sum_{x\in Q\cap R}\frac1{(b+1)(b+2)}.
\]

对任意合法 $Q,R$，

\[
H-f(Q)-f(R)+g(Q,R)\ge0.\tag{7}
\]

证明：令首人偏离 $Q$ 后的真末回复为 $Z$。将“原首人比较 $Q$”“真回复 $Z$ 比较 $R$”“原末人比较 $Z$”三条 IC 相加，再用 $g(M,Z)\le g(M,M)$，即得(7)。这是交叠系数 **1** 的强式；不能以交叠系数2的剩余利润公式替代。

AB、AE 的 `pair:12:query_equal` 对同索引查询 $(X_j,Y_j)$ 应用(7)，Sbranch 的 `pair:23:query_equal` 对 $(V_j^S,W_j^S)$ 应用，均对 $i\ne j$ 求和。逐客户设 $A_i=1/(b_i+1)$、$G_i=1/((b_i+1)(b_i+2))$，查询位为 $m_i,n_i$，总数为 $M_* =\sum m_i,N_* =\sum n_i$、交叠数 $J=\sum m_in_i$，其系数恰为

\[
4\sum_iH_i-(M_*+N_*)\sum_iA_i+\sum_i(m_i+n_i)A_i
+J\sum_iG_i-\sum_im_in_iG_i.
\tag{8}
\]

它保留查询在同索引的真实交叠；$J$ 不能改成边际总数乘积。全部项只依赖本族直方图。以上真实节点语义也与[五人证书活跃行证明](../证明/五人证书活跃行--证明.md)及[末两人交叠比较](../引理/末两人重叠比较与任意索引聚合--引理.md)的统一机制一致。

## 4. 完整客户域、分离与证书恒等式

每个真实客户映入下列扩大域：十个固定会员位 $a\in\{0,1\}^{10}$；共享最优重数 $d\in\{0,\ldots,5\}$；AB、AE 各一个五个三位会员型的直方图；Sbranch 一个五个四位会员型的直方图；三套满足

\[
0\le h_\pi\le d,\qquad0\le\ell_\pi-h_\pi\le5-d
\tag{12}
\]

的菜单对。两个三位族各有 $\binom{12}{7}=792$ 个直方图，四位族有 $\binom{20}{15}=15504$ 个。每族第一位 $T_i$ 的总数必须等于同一个 $d$。允许各族直方图独立、菜单只满足(12)，放松了真实历史一致性，因此扩大域上的非负证书对真实实例有效；不需要证明扩大域列都能实现。

写每条行 $G_r=\sum_xg_r(x)+k_rK$。第5节给61个正整数 $L_r$，并设

\[
D=48223297642041699827812459022585106799808829370156816010,
\quad
B=97275245595766169345344732162388171335572553542163071570.
\tag{13}
\]

$B/D=\beta$，乘子 $\lambda_r=L_r/D$。对客户型 $\tau$，令 $w=1_{a_A+\cdots+a_E>0}$、$o=1_{d>0}$，定义

\[
R(\tau)=120\left(Bw-Do-\sum_rL_rg_r(\tau)\right).
\tag{14}
\]

所有小份额分母均整除120；$R$ 是精确整数。给定 $a,d$ 后，加权行分数分解为固定项、三族各自直方图分数及三套各自菜单的仿射项。(8)只在本族产生乘积，没有活跃的跨族直方图乘积；(10)、(11)只依赖固定位及 $d$。故可以分别最大化三族分数，再分别在

\[
(\ell,h)=(0,0),(d,d),(5-d,0),(5,d)
\tag{15}
\]

四角最大化菜单分数。对每个 $a,d$ 得到 $R$ 的准确条件最小值，而非抽样或不保重叠的边际近似。

原独立实现重构了全部活跃系数，在全部 $1024\cdot6=6144$ 个条件态上得到最小值0、43个条件最小值为0、无负条件；各族穷尽792/792/15504直方图并筛共同 $d$。160个缓存上下文只减少重复评分，不缩小6144数学域。缓存键保留族、前缀负载、跨菜单系数，且 Sbranch 另保留固定 $Y$ 会员位；固定路径收益常数不被缓存吞并。大整数乘法使用 Python 整数与 NumPy object 数组，无浮点容忍。

共同容量列另满足

\[
\sum_rL_rk_r=
\sum_{i\in\{2,6,7,8,9\}}L_{MAX:i}
+78(L_{KRS:3:4}+L_{KRS:5:3})-88940L_{KCAP:4}=0.
\tag{16}
\]

把(14)对全部真实客户求和，得到确切恒等式

\[
\boxed{BW-DO=\sum_rL_rG_r+\frac1{120}\sum_xR(\tau_x)
-K\sum_rL_rk_r
=\sum_rL_rG_r+\frac1{120}\sum_xR(\tau_x)\ge0.}
\tag{17}
\]

因此(1)成立。若按客户型重数 $n_\tau$ 求和，可将最后一项写为 $\sum_\tau R(\tau)n_\tau/120$。没有从非负加权行推得负的 $K$ 遗项，也没有逐行挑选不同“容量”。
