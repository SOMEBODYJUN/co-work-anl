# 固定三人六标签策略的任意背景共同静态安全对偶

以已登记的「三人六标签固定分组策略的共同静态安全对偶」中同一 43 历史策略 $\sigma$ 及同一固定背景分布 $Q=(01,02,03)/3$ 为准。允许任意客户背景负载 $b_x\ge0$，各客户的 $b_x$ 可不同。合法有序前缀所给整数负载是其特例。以 $P$ 记仅三个剩余提供者的实际利润和。对所有非负客户质量，只要全体真实 IC 成立，就有 $\mathbb E_Q f_B(a)\le P/3$ 对所有六个合法查询。因此 $P\ge3v_3(b)$，支付 AGG0 在此完整策略的全部合法背景切片。

逐客户令 $m$ 为兴趣掩码。给实际三主题及各偏离真实完成叶的兴趣命中数 $j\in\{0,1,2,3\}$。用真实收益 $\mathbf1_{a\in m}/(b+j)$，零分子项取零。实际三角色的客户利润总和是 $j/(b+j)$，当 $j=0$ 取零。候选行取 $P/3-\mathbb E_Q f_B(a)$；将原静态分布留在查询抽样以前固定。下面是各查询使用的非负真实 IC 乘子表。每个条目标明历史、当前强制替代及权。空历史以 $\varnothing$ 表示。

| 查询 | 非零乘子 $(h,\text{alternative};\lambda)$ |
| --- | --- |
| 0 | $(\varnothing,3;1/6),(0,0;1/6),(0,1;1/6),(1,0;1/6),(02,0;1/6),(13,0;1/3)$ |
| 1 | $(\varnothing,3;1/3),(0,1;1/3),(03,1;1/3),(05,1;1/3)$ |
| 2 | $(\varnothing,4;1/3),(0,1;1/3),(03,2;2/3),(40,2;1/3)$ |
| 3 | $(\varnothing,3;1/3),(0,1;1/3),(02,3;1/3),(03,3;1/3)$ |
| 4 | $(\varnothing,4;1/3),(0,1;1/3),(02,4;1/3)$ |
| 5 | $(\varnothing,5;1/3),(0,1;1/3),(02,5;1/3),(03,5;1/3)$ |

扣除这一非负加权 IC 后，各客户型的余项是 $c_0/(b+1)+c_1/(b+2)+c_2/(b+3)$。乘以严格正的 $(b+1)(b+2)(b+3)$ 得次数至多二的多项式。附标准库入口从固定策略、真实终局及上表25个权重独立生成全部 378 组精确三系数，逐个验证三个幂系数非负，常数项和一次项各有64个正系数，全部二次项为零。故每个客户的任意非负背景都可单独代入，所有类型与非负质量相加后给总行。取任意静态查询混合 $p$，最小竞争背景上的期望至多上述固定 $Q$ 上的期望，后者至多 $P/3$，于是 $v_3(b)\le P/3$。

原零背景证书中的某些乘子不能原样续用。例如旧查询 1 的兴趣掩码 2 项，在背景 $b$ 的余项是 $-b/[6(b+1)(b+2)]$。此处使用表中的新整行乘子，所有客户共用同一组，固定竞争分布仍是原 $Q$。一般完整策略、任意剩余人数的 AGG0 仍待证明。
