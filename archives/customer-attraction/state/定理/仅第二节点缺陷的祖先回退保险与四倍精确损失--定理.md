# 输入必须包含旧根同主题的真实回退

采用[完整有序历史共同目录模型](../定义/共同目录完整历史模型--定义.md)：有限单位客户、有限非空共同目录、单位提供者，保空主题、重复动作、零收益与任意有序离轨平局。固定人数m≥3。旧完整计划的规定首两行动为(C,T)，其规定叶根收益u、第二人收益v。选中C孩子的第二节点可不理性，但每个第二行动之后的整个子树均为真正纯SPE。按这些**已经给定**的真实完成叶，第二节点最大遗憾为δ>0，即每个旧第二行动a的利润均≤v+δ，且最大值达到v+δ。不是只检查实际尾部。

另须对**每个**旧根主题A给出一份完整孩子SPE R_A，使旧根强制A后最终利润≤u。这里包括A=C；R_C可以与有第二节点缺陷的原C孩子完全不同。这一存在条件等价于u≥M_m，其中

\[
M_m=\max_A\min_{\rho\in\operatorname{SPE}(A)}u_1(A;\rho)
\]

是无额外祖先承诺的真实门槛。有限树保证极值达到。旧根在一份有缺陷计划中的IC不能保证其原C孩子是SPE，更不能凭空得到R_C。其他原根孩子可以由R_A重新补全，不要求保留它们的旧selector。

任取正有理s≥δ。以下以有理块大小记账；取同一个正整数L同时复制全部旧客户与新增银行客户，清除s及原有金额的分母。所有旧利润、δ、W、OPT和银行规模一起乘L；不能只放大银行。新主题目录为旧主题与银行主题的**完整Cartesian乘积**，两坐标客户宇宙互不交，因此每个旧A和银行q都可联合作为真实行动A∪q。

在此合同下，存在保留旧坐标规定整条路径的完整纯SPE，并精确满足

\[
W'=W+(m+1)s,\qquad O'=O+(2m-2)s,
\qquad 2W'-O'=(2W-O)+4s. \tag{1}
\]

O是旧实例OPT_m。共同复制后等式整体乘L。本结论没有给出满足全部前件的half坏旧种子。

# 银行任意前缀上的下限与完整core-fill

银行资源两两不交：X大小2s，Y大小(m−2)s，Z₀,…,Z_(m−3)各s，恰m个资源。除以s后容量向量为(2,m−2,1,…,1)，总容量2m−2≥m。在任意已选p次的有序前缀，若负载为l_r、容量为c_r，则

\[
\sum_r(c_r-l_r)_+\ge\sum_rc_r-p\ge m-p.
\]

尚有人行动时总有未满资源。对剩余人数逆归纳可证：**该前缀的任意完整银行SPE，其当前人最终收益至少s**。末位选未满资源即得至少s；一般步当前人改选一项未满资源后，未来每个真正SPE规定节点按归纳都得至少s，所以不会选择当时已经满的资源，因为那种行动即使以后无人再选也严格低于s。因此当前所选资源以后至多填至容量，当前偏离收益至少s，再用当前IC得结论。有限BI随时存在，可在每个具体first-exit永久固定一份；该结论不需要平局按负载匿名。

对全局根银行为X或Y的分支，使用如下core-fill孩子：此前只选X/Y且各自不超容量时，规定任一预先选定的未满core；首个Z或core过填出现后，在该整个子树永久采用一份完整银行BI。clean路径剩余槽数恰等于core剩余容量，总m次选择最终X两次、Y(m−2)次，每个规定者最终得s。改另一未满core也继续clean并得s；改已满core无条件低于s；改Z无条件至多s。dirty孩子本来完整SPE，逆归纳得到所有clean节点IC。因此这是根强制X/Y后的完整孩子SPE，强制根的保险收益恰s。不能让未来负载重新“看似clean”时返回原模式。

根强制任一Z_j时，其自身总大小s，故任意完成叶的根保险收益≤s；孩子可任取完整银行BI。已用一次的Z₀被再选的收益至多s/2，所以任何真正银行SPE的规定未来行动不会再选Z₀。

# 选中根Z₀之后的高低孩子

令n=m−1≥2。根Z₀已占；尾部可用X大小2s、Y大小(n−1)s、n−2个未占Z，另有重复Z₀这一低价选项。下面每个策略均定义在其完整有序子树，且BI出口一经选定永久锁定。

**高孩子H。** 尾首人强制X后，以后每个有序历史均规定Y。已有至少一个X和全局Z₀，最终Y次数至多n−1，规定Y收益至少s；改X因已有一次X至多s，改任一Z至多s。故H为完整后缀SPE，规定完成中首X独享2s。

**低孩子L_X。** 尾首人强制X后，下一人规定X，此后用H的全Y策略。下一人依从X得s；改Y后余者全Y，最终Y恰n−1次，也得s；改任一Z则该整个出口固定完整BI，偏离者无条件至多s。更深子树分别为H或BI，故L_X完整，首X最终收益s。

**低孩子L_Y。** 尾首人强制Y后，只要尾历史仍全为Y，当前人规定X。首个非Y若为X，之后永久全Y；若为任何Z，之后永久BI。纯Y节点规定X独享2s；改Y且还有人时，下一人X、之后全Y，偏离者最终Y收益s；若已末位，改Y得(n−1)s/n<s；改Z至多s。已有X后用H的比较，Z出口用BI。因此L_Y完整，首Y收益s。不能在首个Z出口之后仍用“尚无X所以选X”的规则。

**低孩子L_Z。** 尾首人强制任一Z后取任意完整银行BI；强制者收益至多s，重复全局Z₀时至多s/2。

n=2即m=3时没有未占Z，但额外Z₀偏离仍在；H只剩一个Y，L_X下一人X，L_Y下一人X，各个终端比较仍成立。本构造不包含m=2，不能把Y大小设0后沿用证明。

# 一次联合选模，全部联合偏离

新全局根规定(C,Z₀)。其选中孩子的旧坐标执行给定第二节点缺陷计划。第二人规定(T,X)；只有**整个联合行动恰为(T,X)**才选高孩子H，任何其他联合第二行动(a,q)均选低孩子L_q。即使q=X而a≠T，也必须用L_X，不能奖励所有X行动。

模式由这一次完整联合第二行动固定，之后旧策略只读旧有序投影，银行策略只读银行有序投影，不因后面改变旧主题而重选模式。第二人规定收益为v+2s；任意联合偏离的旧收益≤v+δ、银行收益≤s，故总额≤v+δ+s≤v+2s。s=δ允许平局。每个更深节点两坐标分别为完整后缀SPE，任何同时改两坐标的合法行动，其利润增量等于两个非正增量之和；所以完整联合IC成立，而非只核单坐标偏离。

对其他全局联合根(A,q)永久使用旧fallback R_A。若q为X/Y，银行用上述core-fill孩子；若q为任一Z，银行用完整BI孩子。实际根在选中孩子沿X,Y^(m−2)，Z₀不被重复，银行利润s，旧利润u。任意联合根偏离旧利润≤u、银行≤s，故总利润≤u+s。特别是A仍为C而只把Z₀改为X/Y时，必须使用R_C；否则根可能面对原有第二缺陷带来的不可信旧后继。所有非选中根孩子均为固定两坐标SPE之积，至此整棵新树完整。

# 福利、零端点和其他修复器的量词

实际银行路径为Z₀,X,Y^(m−2)，覆盖s+2s+(m−2)s=(m+1)s。所有m个不交银行资源总量(2m−2)s，以m个槽各选一个可全覆盖。任何新m元组的两坐标覆盖分别不超过各自OPT；反向把旧最优m元组与银行全部m个资源逐槽配对，完整Cartesian目录保证合法。故OPT准确相加，得到(1)，不是只有上界或下界。

δ=0时不造零大小银行。在本最弱fallback合同下，保留已理性的C孩子、其余根孩子贴R_A，根实际u且其他完成≤u，直接补为保旧actual的完整SPE；若原完整计划确实只有该第二节点不理性，δ=0时它自身已经完整SPE。不得将正s构造直接代入s=0制造空银行。

这不同于[仅根缺陷的三倍保险](多主题独立保险的三倍根修复与半覆盖等价--定理.md)：那里旧根以下本来全部完整，保险总OPT为(2m−1)s、half稀释3s，不能直接套在有second缺陷的旧计划上。

后来[真实门槛的统一/异质前缀修复](真实退出缺陷的统一与异质前缀修复--定理.md)确实可用于本输入，并可改善成本。取j=2，给定(C,T)之后的真尾；其逐位真实缺陷为δ₁=(M_m−u)_+=0及δ₂=(M_(m−1)(C)−v)_+。原给定每个第二孩子本来是真SPE，所以该行动的孩子最小值不超过其给定利润，故δ₂≤δ。异质编译只标记位置2，在δ₂>0时给精确half损失3δ₂；δ₂=0时可直接重贴最小孩子，不添银行。统一j=2的5D只是较粗版本。本历史4s构造仍正确，但不是最优修复器，也不能把后续3δ₂倒填为5045B原独审已经证明的成本或其当时先验。

[可信换位](../引理/可信相邻换位与固定计数坏点正常形--引理.md)所得δ=(M_C−d_T)_+只提供一个second缺陷接口；仍需逐实例核本页u≥M_m等条件。若将本局嵌入更早祖先，新增客户及所换后继会改变其真实查询利润，必须另核旧/新祖先收益cap，不自动保祖先IC。它既不修任意散布缺陷，也不证明一般half。
