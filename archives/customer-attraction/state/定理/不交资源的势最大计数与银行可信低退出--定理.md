# 资源工具的完整域

本工具先在有限非空**单资源选择**游戏上陈述：资源R有非负大小a_R，每名单位玩家恰选一个资源，固定过去负载b_R∈Z_≥0，余r≥0人，终局同资源者各获a_R/(b_R+q_R)。资源可以看作两两不交客户块；这不是原一般目录中任意交叠集合。a_R任意非负实数时是算术资源游戏，若要表示有限单位客户的实际集合，须使各非零块大小为整数，或有理后共同清分母；多个零大小标签也应与数学集合目录的唯一空集分清。下文银行块严格正，投影无别名问题。

对新增计数q≥0、Σq_R=r定义

\[
\Phi_b(q)=\sum_R\sum_{t=1}^{q_R}\frac{a_R}{b_R+t}.
\]

分母始终正，0大小/空和无0/0；可行q有限，存在全局最大元。

**定理。** 每个Φ_b全局最大新增计数q，均可由一份在全部有序历史定义的完整纯SPE实现。不是说所有SPE都势最大，不是把任意静态PNE按任意次序实现，也不推广为交叠目录结论。

# 按剩余人数构造全部孩子

r0时直接终端。r>0，取q_R>0的资源最终利润v_R=a_R/(b_R+q_R)，规定当前选其中v_R最大的R*。对每个合法当前动作D分别接完整孩子。

若q_D>0，令孩子背景b+e_D、目标q−e_D。任一r−1计数q′有

\[
\Phi_{b+e_D}(q')=\Phi_b(q'+e_D)-a_D/(b_D+1)
\le\Phi_b(q)-a_D/(b_D+1)
=\Phi_{b+e_D}(q-e_D).
\]

因此目标仍是更新背景的全局最大计数，归纳可实现；强制D者最后恰v_D≤v_(R*)。

若q_D=0，在更新背景任取一个全局最大剩余计数，归纳给完整孩子。当前者无论后续如何收益≤a_D/(b_D+1)。对任意q_R>0，合法交换q−e_R+e_D和原最大性给

\[
\frac{a_D}{b_D+1}-\frac{a_R}{b_R+q_R}
=\Phi_b(q-e_R+e_D)-\Phi_b(q)\le0.
\]

故该偏离收入≤min_(q_R>0)v_R≤v_(R*)。选中R*的孩子属第一种，当前得v_(R*)、最终新增计数恰q；其他所有有序孩子各为真完整SPE，当前逐行动最优，完成归纳。不同完整历史可以使用不同的最大目标/平局，没缩成计数Markov策略。根前缀无祖先IC承诺，本工具只实现所问子博弈。

与前批[贪心辅助反例](../反例/高收益席位与贪心终局不能替代完整可信退出--反例.md)并不矛盾：资源大小3、2，三人全局势最大计数是A两次/B一次，Φ=13/2；q_A为0、1、3时的Φ分别11/3、6、11/2，均较小。定理按最终利润v_B=2>v_A=3/2先选B，给可信有序路径(B,A,A)；myopic先选A给(A,B,A)却根IC失败。相同最优计数的存在实现不等于每个顺序都可实现；这是对既有例的知情解析校准，未运行程序或重造其七节点证明。

# 连续bank前缀的四类强制动作

取m≥2、1≤j<m、k=m−j≥1、尺度s>0，目录是不交bank B₁,…,B_j各2s，Y大小ks，k−1个leaf各s。正实s给资源游戏的同尺度结论；有限单位客户应用取有理s并整体清分母。固定正常前缀B₁,…,B_(i−1)，1≤i≤j，强制当前D；后继r=m−i≥1。强制者不用理性，只求后继完整SPE使其利润≤s。

leaf本身总大小s；过去已用B再选负载≥2，两者raw≤s，任取真BI孩子即可。

若D为fresh B，当前背景有i个bank各1、其余j−i空；指定后继每空bank一次、再复制D一次、Y共k−1次。槽数(j−i)+1+(k−1)=r。固定背景的边际席位a_R/(b_R+t)中，严格>s的席位恰空bank首席j−i个和Y前k−1席，合r−1个；指定计数全部取尽，再取D第二席=s。其他未取席位≤s，且各资源所取为初段，故是全局势最大，定理给完整后继SPE；D最终负载2，当前得s。k1时Y部分为空，同式合法。

若D=Y，指定后继每空bank一次（j−i+1个），Y再k−1次，总r。**k1必须单列**：当前Y已raw≤s，指定计数选全部r个空bank首席2s，所有其他席位≤s，因此势最大；不能在此误说严格>s席位只有r−1。k≥2时严格>s的席位是空bank首席j−i+1个与Y总负载第2,…,k−1席k−2个，恰r−1；再取Y总负载第k席=s，其他未取≤s，故目标势最大。定理实现后Y总负载k，当前得s。

四类穷尽全部保险主题；每强制D有完整孩子、不同D子树不交，可一起拼为合法菜单。所证是连续distinct-bank正常前缀i≤j的合同；工具的任意背景域不自动等于已经另证的任意interleaved marked合同。

# 奖励路径及产品接口

正常i≤j规定B_i，其正常孩子继续奖励，其余D贴上述低孩子。正常bank利润2s，非正常≤s。前j个bank都一次后，剩k位在**每个有序尾历史**永久选Y：若已有c次非Y，当前和将来全Y使总Y数k−c、当前得ks/(k−c)≥s；改bank已有旧覆盖者给≤s，leaf≤s。因此全尾SPE，向前倒归纳给完整奖励SPE，实际B₁,…,B_j,Y^k，利润(2s,…,2s,s,…,s)，W_bank=(m+j)s；m个不交块各选一次给OPT_bank=(2m−1)s。

与旧坐标Cartesian拼合须在进入每个强制孩子时固定投影模式，之后不因另坐标动作变化重新切换；bank自身真SPE没有免费修复旧坐标未来缺陷或更早祖先IC。完整产品支付由[前缀修复定理](真实退出缺陷的统一与异质前缀修复--定理.md)另证。这里是同银行合同的另一条势最大递归证明，未用静态PNE自动SPE，也不替代旧clean/BI审查先验。
