# 真实四人模型及未筛菜单

四名单位玩家、零根背景，三个互不交经济资源各a名单位客户，两个互不交银行各b名单位客户，a,b为任意正整数；两类客户也不交。共同目录完整3×2共六个资源对，客户合计3a+2b。保留重复行动、全部有序历史及所有真实平局。

根强制A、第二再强制B，R(A,B)仅要求第三、第四在此**原四人分母**下使用真正完整两人纯SPE。根与第二被强制不要求BR，B不能先预筛。d=u1、v=u2，

\[
 \theta(A)=\max_B\min_{z\in R(A,B)}v(z),\quad
 H_A(1)=\min_{B,z\in R(A,B)}[d(z)-v(z)+\theta(A)],
 \quad H(1)=\max_AH_A(1).
\]

本定理对每个A同时证明θ(A)=(a+b)/2、min(d−v)=−a/2，因而H_A(1)=b/2>0。它只排这个零背景四人资源家庭的负H来源，非所有目录、人数或背景的H非负，更非half福利界。

8276B参数稿全文是主要来源。读序是父方先指定一次全参数诊断，signed先独立做收益排序grid，父方后来给短解析论证，signed再从资源/全部联合偏离/真grandchild身份攻击并补全。不是无提示独立发现或首次资源族；本次知情重构亦不冒外审。5777B先前单点H=1/2是同家庭a3/b1的历史，不能倒过来让一个点证明全参数。

# 所有末位BR逐坐标最优

在任意完整前三历史，末位最大化经济与银行利润之和，目录完整，所以联合BR iff两个坐标都BR。任一非最优坐标可单独改变严格改善，全部坐标最优之积亦最优。此判断保所有平局，不绑定匿名或计数选择器；后面任一指定第三孩子的末位规则都要在该准确有序历史为BR。

固定根经济为E、银行为C。下文每个根可独立重标签，不限某个根主题。

# θ上界：每个第二行动都给真实两尾退出

固定任意强制第二经济F。

- F=E时：第三选fresh经济G，第四选另一fresh经济；第三得a，第四BR，第二经济份额a/2。
- F≠E时：第三选唯一第三资源G，三个资源各一旧用户，第四按真实平局复制第二F；第三得a，第二得a/2。

第三在经济坐标已达裸上界a，其任何其它经济行动后的第四可任选真实BR，指定所得仍最优。因此这给全部第三行动/第四节点的完整经济两尾SPE，而非冻结第四。

固定任意强制第二银行D。

- D=C时：第三、第四都用另一银行；第三b/2。若第三改C，则该银行已有前三用户，第四严格选空的另一银行，第三只得b/3。指定最优，第二b/2。
- D≠C时：前两位各一银行。第三任选银行后，第四严格选其另一银行，终局2+2。第三每种选择都b/2，第二也b/2，完整两尾可信。

这两个真实子策略之积对全部第三联合行动仍SPE，因偏离利润差逐坐标相加，两个坐标均非正。每个第二联合B因此有一个真R(A,B)叶令其利润恰(a+b)/2，得到

\[
 \theta(A)\le(a+b)/2.\tag{UPPER}
\]

# θ下界：一个联合强制控制所有真正耦合尾

第二选**同根经济E、异根银行D**。银行前两位不同，所以无论第三的经济/银行行动及任何允许的跨坐标平局选择，第四的银行BR都严格恢复2+2；第三银行利润恒b/2，不可因另一经济分支被提高来补偿。

经济前两人同E。第三若再选E，第四经济必须fresh，第三只a/3；第三若选fresh，第四必须另一fresh，第三经济a。a>0，保持任意第三银行行动不变而只改fresh经济会严格改善，故**每一份真正joint两尾SPE**的第三都必须fresh。第二经济于是a/2，银行b/2。这不是假设所有joint尾能分解，而是用银行恒值排除了补偿。

因此该第二联合强制在每个真R中都得(a+b)/2，

\[
 \theta(A)\ge(a+b)/2,\qquad \boxed{\theta(A)=(a+b)/2.}\tag{THETA}
\]

# d−v的全菜单下界及真正达到叶

只需末位BR即可限制银行差：根、第二银行相同则同资源同利润；不同则末位恢复2+2，两位各b/2。故银行对d−v总贡献0。

根、第二经济相同也差0。若分别E,F不同，经济情况为

|第三经济|第四真实经济BR|根减第二|
|---|---|---:|
|复制根E|唯一未用资源|−a/2|
|复制第二F|唯一未用资源|a/2|
|第三资源G|三资源各一用户后的任一真实平局|−a/2、0或a/2|

所以全部末位BR叶、尤其全部真正grandchild叶均d−v≥−a/2。

下界可由真两尾SPE达到：第二在两个坐标均与根不同；第三选唯一第三经济资源、任选银行；第四经济复制根，银行选第三的另一银行。经济三资源各一次时第四复制根为真实平局BR，银行亦严格BR。第三经济a已达裸上界，银行对所有行动恒b/2，因此其指定联合收益a+b/2最大。每个其它第三联合行动后任选真实第四BR补满整个子树，指定第三仍不会更好，所以是一份真正完整grandchild。该叶根经济a/2、第二a，银行均b/2，d−v恰−a/2。

结合(THETA)，对所有根A

\[
 \boxed{\min_{B,z\in R(A,B)}(d-v)=-a/2,\qquad
 H_A(1)=H(1)=b/2>0.}\tag{H}
\]

原始六主题可编号(0,0),(0,1),(1,0),(1,1),(2,0),(2,1)。a3/b1时叶(0,2,1,5)给d2、v7/2、θ2，故H1/2，是同一一般式的达到例，非参数扫描或half反例。
