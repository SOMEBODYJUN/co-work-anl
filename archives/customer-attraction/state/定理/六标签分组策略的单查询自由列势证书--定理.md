三名玩家共同动作集{0,…,5}，全部有序历史可观察。Φ₃、Φ₂分别是三元、二元无序多重集上的**任意有符号实函数**；定义uᵢ(z)=Φ₃(sort z)−Φ₂(sort(z删位置i))。不假设非负收益、单调、DR或客户实现。固定完整形式策略σ：根选0；首行动a<3时第二位选3，否则选0；末位在历史(a,b)后，从b所属三标签组中选此前未用的最小标签。每组有三标签，故全部1+6+36=43个节点都定义，实际叶034。

假定此σ在该势收益中满足全部真实IC，即Γ(h,a)=u_{|h|+1}(finishσ(h))−u_{|h|+1}(finishσ(ha))≥0。Φ₃是同一精确势，但完整SPE仍须由这些真实续局IC保证，不能只检静态换行动。位置以下用一基、标签和历史用零基。

对二元背景v定义fᵥ(t)=Φ₃(sort(v+t))−Φ₂(sort v)，取p₂=p₅=1/2，其余零，记Fₚ(v)=Eₚfᵥ(t)。Zᵢ(B)、Vᵢ(B)、Hᵢ(p)与[自由列候选](../候选/实际位置自由删槽列的聚合查询预算--候选.md)相同，只把客户查询换成上述势删除边际。记总效用U=Σᵢuᵢ(034)，避免把非CAG效用和叫覆盖。

## 显式零余项付款

令Mᵢ,B=Fₚ(Vᵢ(B))−Hᵢ≥0。则对任意Φ₂、Φ₃均精确成立

$$\begin{aligned}
U-\sum_iH_i={}&M_{1,3}+M_{2,1}+M_{3,0}\\
&+\Gamma(\varnothing,3)+\Gamma((0),1)
+\tfrac12\Gamma((0,2),2)+\Gamma((0,3),2)\\
&+\Gamma((1,5),0)+\tfrac12\Gamma((2,5),0)
+\Gamma((3,1),5)\\
&+\tfrac12\Gamma((3,2),5)+\tfrac12\Gamma((5,0),3).
\end{aligned}\tag{E}
$$

各系数非负，故完整IC使U≥ΣᵢHᵢ。它对这一个策略与p的**整个有符号匿名势锥**成立，包含所有实现该策略的CAG客户实例；不是只检查一个36客户点。

证明可以直接用下表复核，不依赖优化器。Pabc表示Φ₃({a,b,c})，Qab表示Φ₂({a,b})，重复标签保重数。

| IC；系数 | 精确势展开 |
|---|---|
| Γ(∅,3)；1 | P034−Q34−P013+Q01 |
| Γ((0),1)；1 | P034−Q04−P012+Q02 |
| Γ((0,2),2)；1/2 | P012−P022 |
| Γ((0,3),2)；1 | P034−P023 |
| Γ((1,5),0)；1 | P135−P015 |
| Γ((2,5),0)；1/2 | P235−P025 |
| Γ((3,1),5)；1 | P013−P135 |
| Γ((3,2),5)；1/2 | P023−P235 |
| Γ((5,0),3)；1/2 | P015−P035 |

规定的三列分别为V₁(3)=01、V₂(1)=02、V₃(0)=03。把表中九行加权求和，P013、P135、P235等交叉势消去，恰得

$$U-F_p(01)-F_p(02)-F_p(03).$$

再加三菜单余量即(E)。例如Fₚ(02)=(P022+P025)/2−Q02，重复查询2确用P022，不能替换成fresh主题势。离轨历史15、25、31、32、50的末位行是付款组成，不能只保实际03路径或冻结后继。

## 精确坐标证据及与既有结果的区别

六标签三元多重集56个、二元21个，共**77个自由势坐标**；另三变量H₁,H₂,H₃，总80。不是80个势再加H。原程序先用浮点LP找支持，再在该支持上Fraction高斯消元，逐80坐标核等式并检查所有乘子非负，原JSON保存全部77坐标和12个非零项。本轮未改原入口一次执行，输出与冻结JSON逐字节相同，详见[原程序合同](../程序/自由删槽列的原始发现与精确核验合同--程序.md)。

既有[同一固定分组策略的共同静态安全对偶](三人六标签固定分组策略的共同静态安全对偶--定理.md)同样用01/02/03，已覆盖整个**非负客户锥的全部p**。它的全兴趣类型非负余项不适用于任意有符号势；本页在环境类更宽而查询量词更窄，保留独有九IC零余项机制。由于三个背景各可分配到对应实际位置，该既有定理还给固定σ的全部p CAG-AFC，不能误称本单p证书是该σ当前唯一结论。
