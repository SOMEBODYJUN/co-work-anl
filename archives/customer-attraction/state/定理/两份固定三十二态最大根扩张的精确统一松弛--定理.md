# 两份固定三十二态最大根扩张的精确统一松弛

固定[最大根三十二态的两个原系统](../程序/最大根三十二态拆分的两份浮点不可行诊断--程序.md)。保留质量严格大于 \(10^{-10}\) 的旧原子 \(a\)，记旧质量 \(x_a\)，每个旧原子可向根最大主题与四个真实后继的 \(z\in\{0,1\}^5\) 拆分非负质量 \(y_{az}\)，满足 \(\sum_z y_{az}=x_a\)。旧质量照原程序分别以 JSON 解析后的 `Fraction(str(v))` 或 `Fraction(exact_mass)` 读取，保持原边缘和原总质量。对每行 \(i\) 允许同一个 \(t\ge0\)，要求 \(\sum_{a,z} A_i(a,z)y_{az}+t\ge0\)。目标为最小化 \(t\)。

| 固定输入 | 原系统 | 精确最小 \(t\) |
|---|---|---|
| 72 支持，保存的十进制质量按原程序有理化 | 540 行，含 AP 和根历史行 | \(39573170198126625479863/114000000000000000000000\) |
| 65 支持，`exact_mass` | 236 行，无 AP 和根历史行 | \(12406197488207545300181345254156935793975/33625231693246534564111099661179845265856\) |

两值均严格为正，因此两份固定旧边缘在各自原行域都不可零松弛拆分。

## 两条原行共同给下界

在旧原子 \(a\) 上，令 \(u_a\) 为 ABCDE 实际路径首位 A 的份额，\(d_a=\sum\texttt{AB\_hist}[4:]\)，\(c_a\) 为四位 `second_hist` 中坐标 3 的加权会员数。令 \(b=z_0\)。冻结原函数 `rows` 给出共有的 `max:cap:second:menu3` 和 `max:BNS:optimal-sum`
\[
C_{az}=5b-c_a,\qquad B_{az}=400u_a-75b-(5-4b)d_a.
\]
将两条松弛约束分别乘 \(71/76\)、\(5/76\) 相加。每个保留原子在两输入中都满足 \(d_a=1\)，故
\[
71C_{az}+5B_{az}=2000u_a-71c_a-25d_a+20(d_a-1)b
=2000u_a-71c_a-25.
\]
消去该原子所有拆分变量后，得到
\[
t\ge -\frac1{76}\sum_a x_a(2000u_a-71c_a-25).
\]
以原质量逐项有理求和得表中两值。原子资格、两条系数、原报告中该行的存在及两份原输入和报告的 SHA 由下方核验器逐一核对。

## 两份精确原始证书达到下界

[72 支持拆分](../../tools/evidence/phase3-fixed-maximum-lift-exact-uniform-slack/ap_binary_discovery.json)和[65 支持拆分](../../tools/evidence/phase3-fixed-maximum-lift-exact-uniform-slack/exact_optimum_primal_joint_terminal.json)各列出 83 个不同的正拆分，其余拆分为零。`source_atom` 是按原输入顺序筛过阈值之后的零基位置，`bits` 依最大根及四后继排序。各份证书在精确算术下有原边缘和、非负质量及全部对应原行的非负松弛。72 支持的两条组合行取等，其余 538 行严格正。65 支持在 21 条原行取等，包含两条组合行，其余 215 行严格正。

[标准库核验器](../../tools/evidence/phase3-fixed-maximum-lift-exact-uniform-slack/verify_fixed_lifts.py)检查冻结原行函数、原输入、原浮点报告的 SHA，验证原行顺序、每个原子质量约束、两条下界的精确和，并用原有理行函数检验全部 540 或 236 行。它抽取冻结源码中的纯有理行函数，不运行求解器。已运行 `python -I -B archives/customer-attraction/tools/evidence/phase3-fixed-maximum-lift-exact-uniform-slack/verify_fixed_lifts.py .` 的同字节草稿，两个结果均通过。原始证书只需给定有理拆分即可验证。

精确结论适用于两份指定旧点、各自既有最大根扩张和各自固定行集。修改旧边缘、将两个行集混用，或扩展到原策略是否可实现，属于不同命题。
