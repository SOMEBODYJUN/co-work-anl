# 模型、同一库存与结果层次

有限单位客户、有限非空共同目录，m≥1名单位提供者观察全部有序历史依次选主题，客户在终局覆盖者间均分。固定完整历史纯SPE σ、actual叶B、利润u_i、W=Σu_i，允许空主题、重复、零客户及任意离轨平局。固定任一合法m比较元组T，O=∪T_i、C=∪B_i、I=O∩C、R=O∖C；只在T最优时才有|O|=OPT_m。

[固定元组共同primal](../候选/固定比较元组的线性共同付款证书--候选.md)给同一次INIT、actual正付款H、source-current d及I补余J；I付清后只R进入来源客户保持图。使用其中完整source合同：每客户所有来源库存Σαp_αx≤1，每origin总future A_αx≤p_αx，初边≤p_αx/c_Wα(x)，目标是真query叶上严格future规定context。这里的R来源由包含x的query动作发出；后文v≥2/路径界需这个支持条件。不能把广义密度定理允许的任意额外注入也赋此路径性质。

本页证明更大局部付款族ALL及ROW合法、自动密度/单context完整IC、价格和结构性质；最终同一actual角色所有contexts的共同ROLE仍未证。原四稿的“未得五人half”仅是此机制历史：当前[五人half](五人半覆盖--定理.md)另有独立证明，不能倒推这些更强付款系统已可行；六人目标也未由本页闭合。

# ALL的精确线性域与非空性

natural context t=(g,i)规定动作a_t=σ_i(g)，原叶V_t=finishσ(g)，真正actual-prefix reset叶A_t=finishσ(B_<i,a_t)。对输入客户x∈R∩a_t，记v=c_Vt(x)≥1、a=c_At(x)≥1、h=h_tx≥0。

R在任何actual主题都未覆盖，因此A中x的coverer恰为当前i及Q={j>i:x∈(A_t)_j}，|Q|=a−1。边目标固定为τ(t,j)=(A_t,<j,j)，并保原有序history，不作同计数合并。允许

\[
0\le z_j\le h/a\ (j\in Q),\qquad
L=h-\sum_jz_j,\qquad L\le vh/a.\tag{ALL}
\]

边上限已推出h/a≤L≤h，故等价于

\[
 h/a\le L\le\min(h,vh/a),\qquad
 \sum_jz_j\ge (a-v)_+h/a.\tag{RANGE}
\]

全部future边满h/a的uniform点给L=h/a，故任意给定h都有局部点；h0全零，a1时Q空、Lh。对固定σ/B/T所有分母是常数；用金额z而非h乘未知比例，整个有限DAG约束保持有理线性。

# 来源反链、全图密度与一次whole-IC

每内部边≤h/c_A、非负current和严格角色递增，给每origin/client的次随机流；同origin在一个role层的全部context输入和≤初始future量。不同origin到同context先合h，输出可按各自输入比例拆回，零输入不作比例，不为每标签另领库存。

固定非actual目标s的首次actual差异位置k。其所有reset父可以很多，但父role必为k且reset叶均为V_s；否则reset的首次差异位置不能产生s。父边对目标密度c_Vs(x)h_sx贡献≤父h_x。该层来源质量反链和直接source边cap共同给

\[
 f_{sx}:=c_{V_s}(x)h_{sx}\le
 \sum_{\alpha:i(\alpha)=k}p_{\alpha x}
 +\sum_{\alpha:i(\alpha)<k}A_{\alpha x}\le1.\tag{DENSITY}
\]

证明没有使用“NEW边必满”或唯一父；所有ALL选择同时成立。R无past actual或actual-prefix R出口；actual-prefix目标不套非actual首次差异公式。原[广义密度定理](同客户来源保持流的加强初始化与节点密度--定理.md)给相同反链的完整来源域。

ALL的L_x≤f_x/c_A(x)，先合整个action，再调用actual节点强制a_t的一条完整IC：

\[
 \sum_{x\in R\cap a_t}L_x
 \le\sum_{x\in R\cap a_t}f_x/c_A(x)
 \le D_t:=\sum_{x\in a_t}1/c_A(x)\le u_i.\tag{WHOLE}
\]

不是按客户重权IC；current的x是来源标签，actual角色i未必覆盖x。令e_t=u_i−D_t≥0，精确退款为

\[
 u_i-\sum_RL_x=e_t+\sum_{x\in a_t\setminus R}1/c_A(x)
 +\sum_{x\in R\cap a_t}\big[(1-f_x)/c_A(x)+f_x/c_A(x)-L_x\big]\ge0.
\]

空action无正输入，零客户全式0；正输入/正action与IC保证必要正分母及u_i>0，不以删除零/空域取得结论。

# 与旧raw/同客NET的严格区别

记A中新coverer数n、共同future数c、V中离开coverer数ℓ，当前玩家共同，故a=1+c+n、v=1+c+ℓ。旧raw固定每NEW边h/a，current=(1+c)h/a；再加optional-common均满足ALL。uniform全满也是共同角点。

[旧同context同客户NET](完整利润鲜广播消元与同客户取消--定理.md)取消min(n,ℓ)份同价正负项，按客户密度f=vh缩放后，最少保留NEW总流(a−v)_+h/a，current达到min(h,vh/a)。[来源保持原核](../引理/来源客户保留的最大系数退款与支持条件--引理.md)已明确同客户取消与严格增载；这些不是本页新发现。旧完整利润归一化流仍可跨客户重采，不能把其整条流直接叫本来源保持流。

ALL增加的是：必要出流可以移到任何真实reset future coverer，包括COMMON，不必留在旧NEW recipient中。包含关系可在**局部允许计数数据**上严格，不表示每个context都严格，更没有给出一份旧ROLE失败而ALL成功的完整SPE。

例如a4/v3：A有当前、一个COMMON、两个NEW，V另有一个lost-past；lost-past是off-history覆盖者，actual过去仍不覆盖R。当前价1、COMMON后继单位价0、两个NEW后继各2。令H=h/4：

|局部合同|最小价格/每单位h|
|---|---:|
|raw固定NEW、COMMON为0的单点|3/2|
|固定两NEW满、COMMON可选|5/4|
|旧NET取消一份NEW后加optional-COMMON|1|
|ALL只给COMMON一份、两NEW为0|3/4|

固定NEW家族费用6H−t、NET家族费用5H−t，0≤t≤H，分别为5H和4H；ALL必要出流仅H，可全给COMMON，current3H，故3H最小。取h≤1/3保f=3h≤1。它只比较局部多面体和给定价格，不声称这些数据已经完成为新SPE/目标反例，不能用价格改善支付全树。

# 可分价格、固定路由修复与恒等资金

固定非负actual角色价格λ，后继同质单位费用ψ_j排序ψ_(1)≤…≤ψ_(q)，q=a−1、d=(a−v)_+。h>0时事后设β_j=az_j/h，ALL为0≤β≤1、Σβ≥d，其单位目标为λ_i+Σβ_j(ψ_j−λ_i)/a。先选全部ψ_j<λ_i；不足d时补最便宜其余项。整数d的盒切面存在0/1最优点，平局也可有分数点，所以

\[
 \Psi_t(x)=\min_{k=d,\ldots,a-1}
 \frac{(a-k)\lambda_i+\sum_{j=1}^k\psi_{(j)}}a.\tag{PRICE}
\]

角色严格增加使反向递推有限；单位系数只是齐次成本，不允许任意节点独立注一单位后借IC。λ恒1时每单位费用仍1，连同INIT/I付款的总金额仍|O|，没有新增资金或支付常数价格cut。

对固定可行ALL流冻结所有下游比例ρ_sj(x)=z_sjx/h_sx，零输入节点任选uniform。令π_s为每数学单位进入s后的终端角色付款概率向量：

\[
 \pi_s=(1-\sum_j\rho_{sj})e_{i(s)}+\sum_j\rho_{sj}\pi_{\tau(s,j)},
 \quad\pi_s\ge0,\quad\sum_l\pi_s(l)=1.
\]

给定当前输入h，删子边j质量0≤δ≤min(z_j,min(h,vh/a)−L)，留回当前，再按冻结比例重算下游，付款向量改变δ(e_i−π_childj)。从j转给另recipient q的0≤δ≤min(z_j,h/a−z_q)，保持current，向量改变δ(π_childq−π_childj)。重算整个非负图后DENSITY仍有效，不要求下游另有一单位空闲密度；合流由线性叠加处理。便宜方向可改进给定价格，能否同时适合所有actual剩余容量仍是条件，未证所有实例都能修复。此段是ALL的可分齐次比率合同，不能未经核对套到下节的固定整行ROW上限。

# 更大的ROW族：同一context的整行退款共享

保所有source/目标、边上限、同客户守恒，把逐客L_x≤v_xh_x/a_x换成

\[
 \sum_{x\in R\cap a_t}L_x\le u_i.\tag{ROW}
\]

uniform点C0=Σh_x/a_x≤Σf_x/a_x≤D_t≤u_i，故非空。固定输入H=Σh_x，从uniform边取消总量

\[
 \Delta=\min(H,u_i)-C0\in[0,H-C0]
\]

并各留回原客户current，即达到**最大总current**min(H,u_i)。H−C0恰是uniform全部边量，所以可分数取消到该值；没有客户重采。退款使用不超过同一context的u_i−C0，不是新增实际券。

上游取消后，下游每客户输入不增；将旧current和全部子边按新h/旧h同一比例缩小，保持每客户守恒/edgecap/非负，整行current也不增，ROW继续成立，允许下游合流。可按角色顺序从uniform全图构造这些选择。ALL由WHOLE蕴含ROW；ROW可使用别客户密度或query未用退款，故可更宽，但不声称每给定context严格。

给定输入的较窄上限β_*u_i、β_*=max_x(v_xh_x)≤1也容uniform，因为C0=Σf_x/(v_xa_x)≤β_*Σ_R1/a_x≤β_*D_t。空支持取β_*0。β_*若h也是变量就不是固定线性系数，不能把这个事后max窄版冒同一个ROW LP。

ROW使不同客户共享同一固定u_i，故PRICE逐客户独立DP不再适用，应保联合context分配/整个有限LP。取消导致输入单调下降时的比例重算合法；一般加流/重定向还须重查后继ROW，不能沿用ALL修复方向免费越过整行cap。旧[标量CLIP](同节点安全净券与最大标量剪枝--定理.md)已有整行退款思想，旧完整利润归一化可重采；这里是在每客户edgecap/来源库存下留回原客户，不能把两份钱包合领。

# 最少输出面的严格增载与五人路径界

仅对上面**由含x的source/reset动作实际到达**的R natural context，旧叶已有先前owner和当前两名coverer，v≥2。取ALL中的局部最少总输出Σβ=d，则若外送正，a>v，child的旧叶就是A、其旧负载为a。因此每非终端边同时严格增角色和同x旧负载；不是任意ALL共同边/ROW边都增载。

一基角色i余r=m−i+1，a≤r给

\[
 \text{future总量}/h=(a-v)_+/a\le(r-2)_+/r.
\]

source owner i的真实query负载w≥2，第一natural角色≥i+1。若一条路径有n个natural-to-natural边，其第n条父role≥i+n、旧load≥w+n−1；能外送须role+oldload≤m，故

\[
 n\le\left\lfloor\frac{m-i-w+1}{2}\right\rfloor.
\]

m5时natural最早role2，所以r≤4，外送比例至多1/2；r3时至多1/3、r≤2可全留current，每source路径至多一条natural边。它是选定最少输出核的结构，不限制同role有多少不同actions/contexts，也不支付其总费用。

# 同一共同证书的条件结论与接续

用ALL或ROW替换原R-FLOW，仍保同一INIT、H、I补余J与每角色

\[
 F_i=d_i+H_i+J_i+\sum_{t:i(t)=i,x\in R}L_{tx}\le2u_i.\tag{ROLE}
\]

允许[可变归属](../候选/可变归属付款与逐客户初始化条件--候选.md)时必须连同OWN/OWN-CAP/INIT的可行性一起保持，H/r/source/J随同一点重算；不保证任意OWN点可初始化。canonical选择+uniform流使去ROLE后非空；有限DAG及库存使它是非空紧凸有理LP。客户守恒给|O|=Σ_iF_i，故任一共同ROLE点推出|O|≤2W，最优T才给half。

一般ROLE点存在性未证。ALL可用PRICE消元R，ROW须保联合LP；共同容量的非负价格分离仍只是同一可行性等价，不是新资金不等式。来源归属、局部接收者自由、单context退款和不同context共同钱包分别记账，不能拼各自有利点。四稿作者/合同前重构/全文后读与旧来源范围另在[版本审查](../审查/全未来付款族的来源与内部核查版本--审查.md)逐项保留；本批为解析清洗，0新程序/有限例，未新增一般福利、外审或新颖性认证。
