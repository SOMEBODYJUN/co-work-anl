# 七极大至多两单例块半覆盖

## 精确范围

模型是 Q-CAG-HALF-6：有限客户集、有限非空共同主题目录，六名单位提供者按固定顺序观察全部有序历史并选主题；允许主题重复、空主题、零客户和任意平局依赖。客户在最终覆盖者之间均分，`W` 是给定完整历史纯 SPE 的覆盖客户数，`OPT_6` 是六个目录主题可达到的最大并集大小。

本定理另加结构条件。目录中恰有七个 distinct inclusion-maximal 覆盖集 `B_0,…,B_6`。若至多两个最大集具有 singleton-incidence block，即存在客户只属于该最大集，则每份完整历史纯 SPE 都满足

\[
2W\ge OPT_6.
\]

条件中保留内部非极大主题、重复主题、空主题、零客户和所有离轨历史；它们不能被从模型中删除。结论只覆盖该结构子类，未闭合无条件六人 `Q-CAG-HALF-6`。

## 为什么 `OPT_6=U`

令 `U=|B_0\cup\cdots\cup B_6|`。至多两个最大集有 singleton block，因此至少五个最大集没有 singleton 客户。选择一个没有 singleton block 的最大集作为六主题组合省略项，例如 `B_6`。由于 `B_6` 的每个客户也属于另一最大集，省略它不损失并集，故

\[
OPT_6=U.
\]

将实际完整历史中的最终最大动作重标为 `B_0`。剩下五个早期位置的成员集合记为 `E\subseteq\{0,1,2,3,4\}`。对每个客户类型，令 `I\subseteq\{0,…,6\}` 是其最大主题 incidence；最终覆盖类型为

\[
J=E\cup\bigl(\{5\}\text{ if }0\in I\bigr).
\]

因此每个客户类型都由 `(I,E)` 表示，最终覆盖数为 `|J|`。对 `|I|\ge2` 的类型，允许全部 incidence；singleton 类型只需额外处理至多两个有 singleton block 的最大集。两种轨道按这两个 singleton 集是否包含实际最终集 `B_0` 分开。

## 可复用的真实行

完整历史纯 SPE 的实际末位动作给出最后一位 best-response 行 `L_j`；实际末两位的真实后继给出 genuine two-remaining tax 行 `T_{jk}`。这些行来自原策略在全部有序历史的真实 IC，不把 SPE 改成静态 NE，也不合并不同计数历史。另有动态 maxima 的 mixed-floor 行 `M_t`，其形式为

\[
u_t\ge c/6+P A_t+Vb_t\ge b_tU,
\qquad M_t=u_t-b_tU,
\]

其中

\[
b=(1/21,2/37,1/16,2/27,1/11,7/72).
\]

逐客户把这些真实行按非负有理乘数相加，得到 `W-U/2` 的下界。所有行都保留真实历史的收益与覆盖含义；它们不是从一个静态覆盖向量推出来的松弛行。

## 两个有理乘数组合

行顺序是 `M0,…,M5,L0,…,L6,T00,T01,…,T66`，其中 `T` 按 `combinations_with_replacement(range(7),2)` 排列。对每个允许类型 `(I,E)`，把目标系数写为 `1_{J≠∅}-1/2`；由于 `OPT_6=U`，非负残差即表示 `W-U/2` 的可支付性。

### 实际最终集属于两个 singleton block 的轨道

可取 singleton 集 `I={0},{1}`，并允许所有 `|I|\ge2`。非零乘数为：

\[
M_0=M_1=M_2=M_3=133/207,
\]

\[
L_1=4/23,
\qquad L_2=L_3=L_4=L_5=L_6=2/23,
\]

以及

\[
T_{01}=31/207,;T_{02}=19/207,;T_{03}=4/69,
\;T_{04}=T_{05}=T_{06}=19/207,;T_{13}=7/207.
\]

独立脚本逐列检查 3904 个 `(I,E)` 类型，最小残差为

\[
34955/3308688>0,
\]

出现在 `(I,E,J)=(1,0,32)` 的编码类型。

### 实际最终集不属于两个 singleton block 的轨道

可取 singleton 集 `I={1},{2}`，并允许所有 `|I|\ge2`。非零乘数为：

\[
M_0=416/635,
M_1=833/1270,
M_2=167/254,
M_3=84/127,
\]

\[
L_1=10/127,
\qquad L_2=L_3=L_4=L_5=L_6=16/127,
\]

\[
T_{01}=T_{02}=25/127,
\]

\[
T_{03}=T_{04}=T_{05}=T_{06}=T_{13}=T_{14}=T_{15}=T_{26}=3/127.
\]

同样逐列检查 3904 个类型，最小残差为

\[
30253/9473184>0,
\]

出现在 `(I,E,J)=(2,0,0)` 的编码类型。

两组残差严格为正，因此各自给出 `W-U/2\ge0`，从而 `2W\ge OPT_6`。

## 审计脚本及证据等级

`audit_singleton_two_maxima.py` 只使用 Python `Fraction`，枚举全部允许 `I` 和五位早期成员集合 `E`，直接重算 `J`、`M`、`L`、`T` 行和有理残差；脚本没有浮点容差或随机样本。预期输出为：

```text
with_final {'columns': 3904, 'minimum': '34955/3308688', 'arg': (1, 0, 32)}
without_final {'columns': 3904, 'minimum': '30253/9473184', 'arg': (2, 0, 0)}
```

这是一个有限列集合上的精确有理行组合证书。README、coordination 和 workspace 文件只记录研究目标、读序和身份元数据；它们不提升该条件证书的数学等级。脚本通过也不证明七个极大集模型之外的输入，不证明存在任意六人完整 SPE，也不证明无条件 `Q-CAG-HALF-6`。

## 缺口与接续

若三个或更多最大集有 singleton block，上述两条乘数组合不再覆盖所有 singleton 类型；该情况是当前结构缺口，不是反例。后续若要推广，必须增加真实跨枝付款或新的末位/倒二 IC 行，不能把 singleton 客户任意归入 dense 行。至多两个 singleton block 的证书可作为第三阶段中“条件定理由真实 IC 行和有理残差支持”的节点，并与动态局部门槛、五人 half 和七极大其他条件对象保持分离。
