# 二值背景四人剩余利润的有理重权界

## 1. 模型、固定前缀与精确结论

客户集 $N$ 有限，每名客户价值一；共同主题目录 $\varnothing\ne\mathcal S\subseteq2^N$ 有限。恰五名单位提供者依次观察全部有序前史，各选一个目录主题，客户价值在最终覆盖者之间均分。固定任意一份在**所有合法有序历史**指定动作的纯SPE，保留任意历史依赖平局；偏离后始终按同一原策略在改变后的历史继续。空主题、重复选择、零客户、前缀主题与后续主题相同均允许。完整模型见[共同目录模型](../定义/共同目录完整历史模型--定义.md)。

固定任意合法的单提供者有序前缀 $h=(T_0)$，不要求它位于原策略的根实际路径。客户背景为 $p_x=\mathbf1_{T_0}(x)\in\{0,1\}$，之后四人继承原完整策略，构成同一目录上的纯SPE。按剩余相对位置把其实际主题记为 $(A,B,C,D)$、收益记为 $u_1,\ldots,u_4$。定义

\[
R_p(T_1,T_2,T_3,T_4)=\sum_x\frac{e_x}{p_x+e_x},\quad
e_x=\sum_{i=1}^4\mathbf1_{T_i}(x),\quad
F_4(p)=\max_{(T_1,\ldots,T_4)\in\mathcal S^4}R_p(T_1,T_2,T_3,T_4),
\]

\[
V_4=R_p(A,B,C,D)=u_1+u_2+u_3+u_4.
\]

零分子份额取零，包含同时为零的分母。对每个上述前缀及每份原完整SPE，

\[
\boxed{F_4(p)\le\beta V_4,\qquad\beta=\frac{22869393}{11445824}.}
\tag{B4}
\]

精确差值是

\[
\frac{1499}{750}-\beta=\frac{2622713}{4292184000}>0,
\qquad 2-\beta=\frac{22255}{11445824}>0.
\]

这是同背景的**剩余四人总利润**界，非零背景时不等于完整覆盖，也不是 $\operatorname{OPT}_5$。若 $V_4=0$，(B4)仍成立，不定义效率比。本页不声称任意 $p\ge2$ 的背景界、常数最优性、锐性或新颖性。原稿更早流传的 $206549/103375$ 是浮点限分母近似；已完成的精确证书使用上面的唯一 $\beta$。

## 2. 原十二行：保持同一策略的真实节点

固定任意合法四比较主题，记 $O=R_p(T_1,T_2,T_3,T_4)$。令剩余首位偏离到其实际末位主题 $D$ 后，原策略给出的真实分支为 $(D,Q,R,S)$，对应剩余位置收益为 $z_D,z_Q,z_R,z_S$。被强制选择 $D$ 的人只通过其原节点的偏离比较控制；分支上真正优化的后继是 $Q,R,S$。

客户在七个主题中的会员位写为 $\eta=(a,b,c,d,q,r,s)\in\{0,1\}^7$。这七个标签可能是相同主题；在全部二元会员域上核验只扩大真实可实现域，不要求主题互异或给同一历史选择不同动作。

记

\[
D_4(p)=(p+1)(p+2)(p+3)(p+4),\qquad
\tau_p(v)=\frac1{p+1}-\frac1{p+v+1},
\]

\[
\delta_2(p,v)=\tau_p(v)+\mathbf1_{v=2}\frac{2p^2}{3D_4(p)},\quad
\delta_3(p,v)=\tau_p(v)+\mathbf1_{v=3}\frac{p^2+p}{D_4(p)}.
\]

实际前两位后，末两人合法背景为 $p+a+b$。定义

\[
H=u_3+u_4+\sum_x\frac{c_x}{(p_x+a_x+b_x+1)(p_x+a_x+b_x+2)}.
\tag{H}
\]

这里 $c_x$ 是实际主题 $C$ 的会员位，税付在实际末两人的首位 $C$，不是前一位 $B$。按[固定背景两人税引理](../引理/固定背景两人税界--引理.md)，每个合法比较对在此背景下的利润均不超过 $H$。其证明用实际首节点、实际末节点及首位偏离后的真实末位回复三项最优性，另加非负交叠余项；[任意背景四人利润定理](固定背景四人利润界--定理.md)已当页给出完整恒等式。

使用以下十二个全局非负slack；所有求和遍历客户 $x$。

| 行 | 定义 | 合法节点或论证 |
|---|---|---|
| $K_T$，$T=C,D,Q,R,S$ | $u_2-\sum_x\mathbf1_T(x)/(p_x+a_x+3)$ | 实际第二位节点改选合法 $T$，偏离终局负载至多 $p+a+3$ |
| $E$ | $4u_4+\sum_x\delta_3(p_x,a_x+b_x+c_x)-O$ | 实际末位四次比较的聚合 |
| $P$ | $2H+\sum_x\delta_2(p_x,a_x+b_x)-O$ | 六个比较索引对的两人税聚合，除以三 |
| $F$（代码 `current_IC`） | $u_1-z_D$ | 剩余首位在原节点偏离 $D$，跟随真实 $Q,R,S$ |
| $L_{QS}$ | $z_Q-\sum_xs_x/(p_x+d_x+3)$ | 真实节点 $(h,D)$ 改选 $S$ 的负载保底 |
| $L_{RC}$ | $z_R-\sum_xc_x/(p_x+d_x+q_x+2)$ | 真实节点 $(h,D,Q)$ 改选 $C$ 的负载保底 |
| $L_{RS}$ | $z_R-\sum_xs_x/(p_x+d_x+q_x+2)$ | 同一真实节点改选 $S$ |
| $L_{SB}$ | $z_S-\sum_xb_x/(p_x+d_x+q_x+r_x+1)$ | 真实末位节点 $(h,D,Q,R)$ 改选 $B$ 的精确比较 |

共同目录保证所有跨节点主题均合法。负载保底没有冻结任何偏离后的行动；所有后继可依原策略改变。$P,E$ 的非负性可直接从下述逐客户差核验。客户在四个比较主题中的重数为 $e\in\{0,\ldots,4\}$ 时，

\[
\begin{aligned}
g_P(p,v,e)&=\frac{e(4-e)}{3(p+v+1)}+\frac{e(e-1)}{3(p+v+2)}+\delta_2(p,v)-\frac e{p+e}\ge0,
&&v=0,1,2,\\
g_E(p,v,e)&=\frac e{p+v+1}+\delta_3(p,v)-\frac e{p+e}\ge0,
&&v=0,1,2,3.
\end{aligned}
\tag{Agg}
\]

六个比较对中恰 $e(4-e)$ 对覆盖该客户一次、$\binom e2$ 对覆盖两次，后者份额为 $2/(p+v+2)$；故上述两个计数分子准确。比较主题即使重复，**索引**对仍是六个。独立原审计另在四比较主题全部16种会员型、$p=0,1$ 上直接求和六对，分别检查96个 $P$ 状态和128个 $E$ 状态，最小值均为零。更广的非负多项式证明见任意背景四人正文。

## 3. 精确权重与逐客户余项

十二个非负有理乘子如下，行名与上一节对应。

| 行 | $\lambda$ |
|---|---:|
| $K_C$ | $488349/1430728$ |
| $K_D$ | $647477/2146092$ |
| $K_Q$ | $437575/1430728$ |
| $K_R$ | $216063/715364$ |
| $K_S$ | $6096731/17168736$ |
| $E$ | $2024261/5722912$ |
| $P$ | $3698651/5722912$ |
| $F$ | $14501425/11445824$ |
| $L_{QS}$ | $68801/2861456$ |
| $L_{RC}$ | $22255/2861456$ |
| $L_{RS}$ | $8912/536523$ |
| $L_{SB}$ | $1235617/11445824$ |

尤其 $\lambda_E+\lambda_P=1$；这控制了比较利润 $O$ 的总系数，不能随意修改比较目标。

以下给出余项的完整有限公式，避免将证书只写成常数。固定客户背景 $p\in\{0,1\}$ 和七会员位 $\eta$，设

\[
k=a+b+c+d,\quad t=d+q+r+s,\quad
v_A=\frac a{p+k},\ v_B=\frac b{p+k},\ v_C=\frac c{p+k},\ v_D=\frac d{p+k},
\]

\[
z_D^x=\frac d{p+t},\quad z_Q^x=\frac q{p+t},\quad
z_R^x=\frac r{p+t},\quad z_S^x=\frac s{p+t}.
\]

零分子仍取零。先将全局 $-O$ 项移除，十二个客户贡献是

\[
\begin{aligned}
K_\ell^x&=v_B-\frac\ell{p+a+3},\qquad\ell=c,d,q,r,s,\\
H_x&=v_C+v_D+\frac c{(p+a+b+1)(p+a+b+2)},\\
P_x^0&=2H_x+\delta_2(p,a+b),\qquad E_x^0=4v_D+\delta_3(p,a+b+c),\\
F_x&=v_A-z_D^x,\\
L_{QS,x}&=z_Q^x-\frac s{p+d+3},\\
L_{RC,x}&=z_R^x-\frac c{p+d+q+2},\qquad
L_{RS,x}=z_R^x-\frac s{p+d+q+2},\\
L_{SB,x}&=z_S^x-\frac b{p+d+q+r+1}.
\end{aligned}
\tag{Rows}
\]

以表中对应乘子定义

\[
\rho^{\mathrm c}_p(\eta)=\beta\frac{k}{p+k}
-\left[\sum_{\ell=c,d,q,r,s}\lambda_{K_\ell}K_\ell^x
+\lambda_EE_x^0+\lambda_PP_x^0+\lambda_FF_x
+\lambda_{QS}L_{QS,x}+\lambda_{RC}L_{RC,x}+\lambda_{RS}L_{RS,x}+\lambda_{SB}L_{SB,x}\right].
\tag{Rho}
\]

这里求和符号按五个**主题标签位置**配对：例如 $c$ 对 $K_C$ 乘子，$q$ 对 $K_Q$；若会员位相同，仍保留五项，不作集合去重。

全部 $2\cdot2^7=256$ 种允许客户类型上的 $\rho^{\mathrm c}$ 非负，其中17项为零。下一节表格给出固定实际四位后对全部八种 $q,r,s$ 的准确最小值，包含完整允许域，并非游戏抽样。

令 $G^{\mathrm c}$ 为十二个**全局**非负slack以这些乘子的加权和。由于 $E+P$ 的归一化，逐客户求和精确得到

\[
\boxed{\beta V_4-O=G^{\mathrm c}+\sum_x\rho^{\mathrm c}_{p_x}(\eta_x)\ge0.}
\tag{Identity}
\]

任意有限客户数和目录大小均由此求和覆盖，不需要固定其上界。最大化合法比较元组即证明(B4)。

## 4. 二值域的省校正版与完整最小余项表

在 $p\in\{0,1\}$ 中，(Agg)的两项 $\delta_2,\delta_3$ 都可直接换成 $\tau_p(v)$。完整 $p,v,e$ 域分别有30、40项，全部非负。若需不用程序逐项核验，可从任意背景四人正文的两张非负系数表分别减去校正的清分母分子：$P$ 表仅在 $v=2$ 减 $2p^2$，$E$ 表仅在 $v=3$ 减 $p^2+p$，再代入 $p=0,1$，所有条目仍非负。

因此可使用两个更小、仍合法的全局slack

\[
P^{\mathrm u}=2H+\sum_x\tau_{p_x}(a_x+b_x)-O,\quad
E^{\mathrm u}=4u_4+\sum_x\tau_{p_x}(a_x+b_x+c_x)-O.
\]

保持相同 $\beta$ 和十二个乘子，将(Rows)中的 $P_x^0,E_x^0$ 同样省去校正，定义新余项 $\rho^{\mathrm u}$。精确有

\[
\rho^{\mathrm u}_p(\eta)=\rho^{\mathrm c}_p(\eta)
+\lambda_P\mathbf1_{a+b=2}\frac{2p^2}{3D_4(p)}
+\lambda_E\mathbf1_{a+b+c=3}\frac{p^2+p}{D_4(p)}\ge\rho^{\mathrm c}_p(\eta)\ge0.
\tag{Uncorrected}
\]

省校正版也满足(Identity)，只需将 $G^{\mathrm c},\rho^{\mathrm c}$ 同时替换为 $G^{\mathrm u},\rho^{\mathrm u}$。两版均有17个零余项；$p=0$ 时两版逐项相同。它们不能混用余项。

## 5. 发现过程、独立原审查与应用限制

原生成器用浮点LP寻找活跃行，选择13个线性独立方程后，以 `Fraction` 高斯消元恢复十二个乘子与 $\beta$，再检查全部256个有理余项。浮点求解器成功或浮点最优性都不是上述定理的前提：表中有理常数、合法节点和完整余项非负性本身就是可核验证书。没有证明它在十二行锥中最优。

独立原审查不导入生成器、优化器、旧审计或旧 `RHOMIN`。它分别从旧公共分母多项式与终局均分利润重构十二行，两种转写在256状态共3072项完全一致；再核对校正版全部256余项与省校正版全部256余项。校正版最小正余项在 $p=0,1$ 分别为 $22255/34337472$、$4774397/103012416$。脚本、完整JSON、原审查全文及本轮原实现重放见[精确证书资源](../计算/二值四尾有理证书与双实现核验--计算.md)。本轮重放不是新增独立审查或外审。

接入更大的索引系统时，必须从**新**余项按八个 $q,r,s$ 取最小值，重建新系数；不能只替换旧 $1499/750$ 为 $\beta$，却保留旧证明的余项下界。校正版和省校正版之间也须按(Uncorrected)同步更换。

后续 `check_new_binary_four_tail_payment.py` 和其冻结JSON已实读：它对一个指定五人必要条件松弛点的实际尾部与最大根分支尾部，使用省校正版及其自己的 `NEW_RHOMIN`，共检查17546个指定合法比较族，没有负行。这个结果仅说明该有限付款测试没有排除那个点；该点未被证明可补全成SPE，也不构成half反例。本批仅比较其应用范围，未认领该后续程序/报告的全部来源处置。

原正文写“没有获得HALF(5)”描述本辅助机制的成果范围。当前[五人根半覆盖](五人半覆盖--定理.md)已有另外的完整证书；本辅助定理仍有独立内容，不能因被更强根结果超越而丢弃背景利润与余项机制。恰六人仍见[六人问题](../../subarchives/six-providers/问题--问题.md)，其实际前两人背景可能为二，本页单提供者前缀范围不能自动替代六人所需尾部定理。

关系判断：[任意背景四人利润定理](固定背景四人利润界--定理.md)提供十二行机制和校正，本页在原五人单前缀限制域中重新选权；省校正是该二值域内更强余项版本；两人税是承重依赖；五人根half是不同结果；后续付款检验属于指定松弛点上的有限检查。第三阶段再按这些具体理由建边，本批不生成图。
