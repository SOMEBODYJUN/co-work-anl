# 同一总人数下的逐人候选

采用[共同目录完整历史模型](../定义/共同目录完整历史模型--定义.md)：有限单位客户、非空有限共同真实集合目录、原总人数m≥1、单位提供者，全部有序历史纯SPE；允许空主题、重复行动、零客户和任意离轨平局。固定原实例的OPT_m，候选FLOOR要求每个合法有序前缀后的每份完整子SPE，其当前玩家满足

\[
u\ge t:=\operatorname{OPT}_m/(2m). \tag{FLOOR}
\]

分母和OPT均属于原总人数m；祖先行动可以不理性。它比仅量化完整根SPE实际角色的DIRECT更强，沿实际路径求和足以推出half。反向未证，不能把下述FLOOR反例归约称为half正规形。FLOOR也不是聚合末位值W≥mθ_m；那些对象的优化次序和量词不同。

原6615B作者稿与2221B父审当时把FLOOR/PARTICIPATE列OPEN。后来[完整银行反族](../反例/笛卡尔银行目录的逐人分数门槛反族--反例.md)已在每个m≥5的空根否定DIRECT，因而亦否定本全前缀FLOOR。其一般归约仍正确，历史OPEN按下面后续推论更新。

# 任意旧目录上的fresh-petal引理

向任意m人旧实例加入m个新主题E₁,…,E_m，每个含B>0名不同单位客户；各瓣客户互不相交，并与全部旧客户不交。B为整数，目录只作扩充，不加玩家、不限制共同动作。

**结论。** 任意合法有序历史后的任意完整纯SPE都不会选择过去已出现的新瓣。若当前被强制选择此前未用的新瓣，则在任意完整孩子SPE中后继都不再选它，当前利润恰B。因此每个新实例子SPE当前收益至少B。

按剩余人数归纳。非终局过去至多有m−1次行动，故总有未用瓣。末位选未用瓣得B，选已用瓣至多B/2，故后者严格劣。更早节点的全部孩子都是子SPE，由归纳假设，当前先选的未用瓣在每个真实孩子后继均不再被选，当前独得B；选已用瓣仍至多B/2。旧主题可能更好，但不会使已用瓣成为最佳动作。此证明同时量化过去曾错误重复选瓣的所有离轨历史，不删除其固定背景。强制者本身无需理性；后继的子SPE性质已足以保证其瓣不再被选。

B=0时所有瓣覆盖相同空集、严格比较消失，不在本引理中伪造m个不同空主题。零OPT没有FLOOR坏点，后面的归约自然只用B>0。

# 从任意FLOOR坏点得到同m私有退出坏点

假设原FLOOR有反例。将坏点的子SPE任意向根补为一份完整SPE，再在这份有限完整树中选深度最大的坏节点h。令u<t是其当前利润。h的全部proper旧后代历史的规定当前利润都至少t，包括全部偏离子树，不仅actual尾部或各列平均。

取有理u<s<t，复制每个旧单位客户L次，并使B=Ls为正整数。旧利润/福利/OPT全部乘L，人数m不变；加入上述m个B客户新瓣。对h以下构造：

1. 对尚未出现新瓣的proper后代，保留旧σ的规定动作。
2. 在**第一次**出现新瓣的每个边界孩子，一次选定整份有限BI子SPE。各边界子树互不重叠，以后不重新切回旧模式。
3. 在h规定当前选择一个新瓣。

由深度自底向上核验第1类节点：改另一旧主题，其后仍是原同一σ，原IC按L缩放保持；改新瓣，其后采用已经固定的完整孩子，fresh-petal引理使当前只得B<Lt，严格劣于规定旧收益。第2类整棵子树本来可信。h的每个旧主题A后旧续局当前收益Ld_A≤Lu<B，而每个新瓣当前恰B，故规定新瓣严格优于全部旧动作。这里保全部旧动作及任意旧平局，没有将原策略挪入删人游戏。

再向根逐祖先选最佳动作，其他孩子任取完整SPE，即可扩成新完整SPE。指定h可能成为离轨历史；FLOOR量化全部合法前缀，所以仍是反例。原m槽最优元组还在新目录，故

\[
\operatorname{OPT}^{new}_m\ge L\operatorname{OPT}^{old}_m>2mLs=2mB.
\]

于是FLOOR有反例，当且仅当某同人数扩充实例含m个等大独立私有新瓣，且某完整SPE在某合法前缀选瓣恰得B，同时OPT_m>2mB。只保存了单节点坏差；新实际福利没有被控制。

原稿用[末两人保底](末两人逐人保底与全人数弱福利界--定理.md)和合法前缀的目录计数界排除坏节点只剩一/两人的情形：两人各至少OPT_m/(2m−1)>t（OPT>0）。这是最深坏点的定位工具，不是全m门槛证明；m=1直接最大主题最优，m=2的两尾界也不被归约反驳。

# PARTICIPATE的后来反证及一个实际根推论

原参与原则声称：在任意旧目录加m个B客户独立新瓣后，若OPT_m>2mB，则没有完整SPE在任何合法节点选瓣。它与上面的全前缀FLOOR等价，所以现已为假。这里可不用找最深节点，直接把已发表银行全参数合同代入归约。

银行原件第1–9节已全文实读。m≥5时，旧客户为m个经济单例及m−1个两客户银行块，完整Cartesian主题为{e_a}∪B_b。原BASE/PUNISH/EXIT控制器覆盖全部有序历史、所有联合及再次偏离，且

\[
u_1=\frac m{m-1}<t=\frac{3m-2}{2m},\qquad
W=2m,\quad OPT_m=3m-2.
\]

其全部proper历史当前利润至少2：BASE中间为2+1/(m−1)，BASE末位2，PUNISH中间3/末位2，EXIT3。PUNISH目标固定为进入时已经出现的过去银行；再次fresh偏离不能改目标，used偏离永久EXIT。正是这份全树合同使全部proper旧节点超过t<3/2，而不能只拿一条实际收益序列代替。

取任意有理m/(m−1)<s<(3m−2)/(2m)，共同复制L使B=Ls整数，再加m瓣。根以外全旧历史保原银行控制器；首次新瓣后各贴完整BI子树。根改任意旧主题只得Lu₁<B，选任意新瓣恰B。故可让根实际选择新瓣并构成完整SPE，同时OPT_new>2mB。此族每个m≥5均直接否参与原则，已知银行例不是half坏例，新扩充的福利也未由本论证核定为half坏例。

例如m5取s=51/40、L40、B51；旧13客户复制为520名，新增5瓣255名，共775名单位客户、20旧主题加5新瓣。根严格选瓣得51，而OPT_new≥40·13=520>510=2mB。此处只需显示合法最优覆盖下界，不声称520是新精确OPT，也不声称已经枚举其BI策略表或运行775客户实例。

# 一个小整数、完整显式的参与反族

还可用平局给无需任意BI填表的全参数族。对上述m人银行游戏，令L=m−1复制全部旧单位客户，加入m个各B=m客户的独立新瓣。规定根选择E₁。若根/历史尚未出现任何新瓣，则旧主题坐标仿原BASE/PUNISH/EXIT控制器；首次出现新瓣后永久进入POST-PETAL：当前及后继各选最小未用经济标签、最小未用银行的旧完整主题对，任何再次偏离后仍留该模式。

POST-PETAL深度t的过去至少含一次新瓣，因此旧银行已用种类至多t−1，未用银行至少(m−1)−(t−1)=m−t，足够剩余人数；经济未用数亦足。沿指定续局，每个新选旧pair两坐标都独占，收入3L。任意旧主题收益至多裸3L，任意新瓣收益至多B≤3L（m≥2），所以全部再次联合/重复偏离均不改善。这个数量不等式在后来出现更多新瓣后仍成立，给全子树SPE。

在尚全旧的proper历史，原规定收入至少2L≥B，新瓣偏离进入POST-PETAL后只得B；旧动作仍沿原银行控制器，故全部原IC保持。根选任意旧主题仍按原银行形式得Lu₁=(m−1)m/(m−1)=m，而选任意新瓣独得B=m。根指定E₁是合法平局BR。由此显式定义全部有序历史纯SPE，任意离轨重复和平局均保，不是只给actual路径。

实际根一瓣，后m−1人选互异经济/银行旧pair，覆盖新瓣m名客户、m−1个经济克隆块及全部m−1个银行克隆块，因此

\[
W=m+3(m-1)^2=3m^2-5m+3.
\]

任一m槽组合若用r≤m−1个旧主题，旧覆盖≤3Lr、新瓣覆盖≤B(m−r)，上界随r严格增加（3L−B=2m−3>0）。在r=m−1取到上述W；若r=m，旧最多覆盖L(3m−2)=3m²−5m+2，比W少1。故精确OPT=W。客户总数L(3m−2)+mB=4m²−5m+2，主题总数m(m−1)+m=m²，均是真实单位模型。

当m≥5时，根u₁=B=m且

\[
\operatorname{OPT}_m-2mu_1=m^2-5m+3>0.
\]

所以这是每个m≥5的PARTICIPATE与FLOOR反族，实际根就选择瓣，却**每份这里规定的实际策略全效率**。m5给77客户/25主题/W=OPT53；m6给116客户/36主题/W=OPT81。它不声称这些规模最小、所有SPE全效率或原half反例；m2…4同控制器合法但本差额不正。该族由Root与本清洗者在已知两原稿及银行全树合同后作知情解析组合，不冒原2026-10-24作者发现，不新跑任何控制器或整数实例。
