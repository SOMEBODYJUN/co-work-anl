# 范围、原稿缺口与现结论

单位客户、有限非空共同目录、n≥1提供者、全部有序历史任意完整纯SPE。至多三个**不同非空客户覆盖集**，可附空主题、可有重复或同覆盖异标签。不合并策略标签；证明只数终局物理覆盖，仍在原有序历史上做偏离。令终局覆盖为S，W=|S|，OPT_n为最多n个主题并集的最大值。则OPT_n≤2W。

原2179字节稿开头允许三个非空主题再附空主题，末段却说“空主题存在时最多两个非空主题”；后者只有目录总大小≤3时自动成立。下面补正利润论证，确保证明在开头较大域也成立。该补充调用当前每位玩家的IC，不能再说全证明只用了最后一位的子局。

# 空行动与零客户

若所有主题覆盖空集，则W=OPT_n=0。否则取一个覆盖非空的合法主题B。任一玩家在任一前缀真实强制选B，任何后继下每个B客户负载至多n，故该偏离收益≥|B|/n>0。IC使规定动作收益严格正，所以每个actual行动均非空。这个论证保所有平局，不要求以后冻结或只选极大主题。

因此若终局只有一个不同非空覆盖A，所有n位都覆盖A，末位利润正好W/n；即使存在任意多个空标签亦如此。

# 按实际使用覆盖分类

n1时唯一玩家最优，W=OPT₁。以下n≥2。

若使用三个不同非空覆盖，全部可覆盖客户已经覆盖，W=OPT_n。若使用恰两个A、B，最多遗漏一个非空覆盖C。令D=C\S。末位改选C时D中每客户独享，故|D|≤u_n≤W。所有比较并集都在S∪D内，OPT_n≤W+|D|≤2W。

若只用A，最多有两个未用覆盖B、C；不存在的一个取空集仅作记号，不添加行动。末位在actual前缀A^(n−1)真实改到B会独享B\A，因此|B\A|≤W/n；同理|C\A|≤W/n。于是

\[
 \operatorname{OPT}_n\le|A\cup B\cup C|
 \le W+|B\setminus A|+|C\setminus A|
 \le(1+2/n)W\le2W.
\]

若实际只存在一个或两个非空覆盖，不等式更强。没有使用任何SPE终局为静态NE的假设；末位分支后面确无玩家，所以没有冻结续局的问题。
