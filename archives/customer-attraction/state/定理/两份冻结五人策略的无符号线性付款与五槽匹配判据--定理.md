# 两份冻结策略的逐类型无符号付款与槽位刻画

固定两份原完整五人七标签动作表 \(\sigma_{252},\sigma_{48}\)，实际路径分别为 00011、01010。两表的实际标签计数均为 \(c(0)=3,c(1)=2\)。记外部标签集合 \(X=\{2,3,4,5,6\}\)。对任意恰五槽标签多重集 \(T\)，令 \(d_B\) 为接受槽位数，重复标签按槽计。给定槽排列 \(\pi\)，第 \(i\) 个位置在同一原策略的实际有序前缀强制选择 \(a=\pi_i\)，然后从改变的节点沿原策略完成到 \(z_i(a)\)。以 \(n_B(z)\) 表示终局 \(z\) 对类型 \(B\) 的负载，以 \(c_B\) 表示实际终局对其负载。该类型从排列得到的全部查询系数为
\[
P^\sigma_B(\pi)=\sum_{i:\pi_i\in B}1/n_B(z_i(\pi_i)).
\]

## 净与无符号的逐类型等价

对任意固定策略及比较槽排列，若 \(d_B=0\)，查询没有一项命中 \(B\)，所以 \(P_B=0=d_B/(1+c_B)\)。若 \(d_B>0\)，净需求中的外部信用 \(\mathbf 1[c_B>0,d_B=0]\) 为零。因此逐类型满足净需求当且仅当逐类型满足无符号需求 \(P_B\ge d_B/(1+c_B)\)。同理适用于排列分布的期望。这一等价依赖于逐类型不等式，聚合后只知带信用预算时不能删去信用。

[原逐类型证书](两份冻结五人策略的净线性费用逐类型匹配--定理.md)直接给出对任意非负类型重数、每个恰五不同标签支持 \(J\) 的无符号付款 \(\sum_i M_i(\pi_i)\ge Q(c,J)\)。若同一策略在这些客户上是完整 SPE，逐项实际前缀 IC 给 \(Q(c,J)\le\sum_i M_i(\pi_i)\le W\)。任一最优并集可由恰五不同标签实现，因可将不满五个标签的最优支持扩充，最优性使包含关系取等。因此对每个最优并集，均有一个恰五槽元组使 \(F\le Q\le W\)。若指定原来带重复槽的元组，实际覆盖并集和 \(E\) 可保留，负载 \(d\) 与支付排列需重算。

该全支持合同中 \(W\) 前的系数 1 在两锥都可达到。取七个彼此不交的单标签客户组，重数按标签顺序为 \(3,2,1,1,1,1,1\)。[旧遗漏付款证书](../../tools/evidence/fixed-five-player-omission-payments/fixed_omission_exact.json)已记录这一共用完整SPE客户点，本次从两原动作表独立核全历史真实偏离。此点对 \(J=23456\) 有 \(F=Q=5=W\)，证书排列真实总付亦为 5。该支持覆盖 5 而最优覆盖为 8，所以取等支付的是全五异标签支持合同的锐性。两冻结锥的全支持精确最大覆盖比 \(8/5\) 是[既有独立覆盖对偶](两份显式完整策略锥的全支持精确最大覆盖比--定理.md)，其结论没有提供上述线性费及实际前缀付款。

## 两表对任意五槽的精确刻画

称查询 \((i,a)\) 可用，当 \(a\) 为 0 或 1，或 \(a\in X\) 且 \(z_i(a)\) 的外部子序列恰为单个 \(a\)。精确结论是，排列逐类型支付无符号需求当且仅当每个查询可用。

必要性适用于实际路径只含 0、1 的任意策略。若某个外部查询 \((i,a)\) 在其真叶里重复了 \(a\)，取 \(B=\{a\}\)。若其真叶还有别的外部标签 \(b\)，取 \(B=\{a,b\}\)，即使 \(b\) 未入比较槽也允许。此时 \(c_B=0\)，需求为 \(d_B\)，而 \(d_B\) 项查询份额中该项严格小于 1，其它项至多 1，故不能付款。

充分性使用冻结真叶的下表。对每个可用行设 \(\Delta_b=\#_b(z_i(a))-\#_b(\mathrm{actual})\)。从真叶计数直接核对
\[
\Delta_a+\sum_{b\ne a}\max(0,\Delta_b)\le1.
\]
左边是所有 \(B\ni a\) 的负载增量 \(n_B(z_i(a))-c_B\) 的最大值。因此每个命中的查询贡献至少 \(1/(1+c_B)\)，逐项相加给 \(P_B\ge d_B/(1+c_B)\)。这是使用同一实际前缀和真实后继的分母界。

由此可把每个比较槽视为一个顶点，与其可用位置建边。Hall 条件精确刻画哪一些五槽多重集存在付款排列。对两份策略分别可用表取交，得到共用纯排列的刻画。共用随机排列也给同一可行性条件。因为对任意 \(B\subseteq X\)，每个排列的查询系数均不超过需求 \(d_B\)，期望达到需求迫使正概率的每个排列对所有这些类型都取等，进而由必要性论证知只能使用共用可用位置。逐策略的随机排列同理。这是逐类型或对所有非负客户重数的结论，Hall 失败仅表示不存在逐型付款的排列或分布。固定完整 SPE 锥上的聚合付款允许用其它会员型的余额，须单独检验。

## 精确复验

[独立净费与无符号费复验](../../tools/evidence/fixed-five-player-unsigned-q-and-slot-matching/verify_net_q.py)核两份原件 SHA-256、完整动作域、实际有序终局和原客户重数。每策略对原点、零点和上述共用十客户点各核 2801 个有序历史、16806 项非自身真实偏离。每策略另核全部 21 个五异标签支持、每支持 120 个排列及每排列 127 个逐型比较。通过集合与原净额证书逐排列相同，各策略分别有 432、402 个通过。核原证书每支持保存的首排列、五真叶及完整 127 列有理余项。新输出另给按 60 缩放的无符号余项，保存为 [net-q-independent.json](../../tools/evidence/fixed-five-player-unsigned-q-and-slot-matching/net-q-independent.json)。

[独立槽位复验](../../tools/evidence/fixed-five-player-unsigned-q-and-slot-matching/verify_hall_standalone.py)读取同两原件并核完整动作域、真叶和可用行的最大负载增量。它遍历每份策略全部 16807 个带重复有序比较及各自 127 个非空类型，以整数计算逐型净费和无符号费，检查两者的通过条件都与可用位置完全一致。[hall-standalone-exact.json](../../tools/evidence/fixed-five-player-unsigned-q-and-slot-matching/hall-standalone-exact.json)给全部 70 行真叶及可用位、21 个支持的首排列和计数、五槽多重集按不同标签数的数量。

两程序均仅用标准库。运行时传入含两份原件的仓库根路径，标准输出可与相应 JSON 比较。
