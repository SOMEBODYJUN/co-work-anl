# 七极大六人含早覆盖私有块的条件半覆盖证书

## 定理（条件范围）

设有限客户的包含极大目录恰有七个不同集合 B₀,…,B₆，六名提供者按完整有序历史依次选择主题，客户在终局被覆盖者间均分。固定任意完整历史纯 SPE，保留原模型中的重复行动、空主题、零客户和任意平局。

把实际终局最后一个极大行动重标为 B₀。取一个达到静态最优 OPT₆ 的六极大组合为 B₀,…,B₅，省略 B₆。对客户 x，令 I_x ⊆ {0,…,6} 为其所属极大目录指标集，令 J_x ⊆ {0,…,5} 为实际根路径六个行动的位置集合。末位重标号给出：位置 5 在 J_x 当且仅当 0 在 I_x。

若对每个 included singleton 客户 I_x={j}（1≤j≤5），其在实际前四行动中的某一位置 0,1,2,3 或实际倒数第二行动位置 4 被覆盖；I_x={0} 的客户由最后 B₀ 自动覆盖；省略的 I_x={6} singleton 不受限制，则：

    OPT₆ ≤ 2W,

其中 W 为终局覆盖客户数。因此该条件子类满足六提供者半覆盖目标。

“前四或倒二”条件是第二个脚本证明的范围；更强的“仅前四”条件由第一个脚本单独给出。两者均只约束 included singleton，|I_x|≥2 的客户不受该私有块条件限制。

## 证书的行和逐客户目标

对 singleton incidence 使用私有后缀 floor

    alpha_t = 1/12    (t=0,…,5),

对 |I|≥2 使用共享后缀 floor

    beta = (1/21, 2/37, 1/16, 2/27, 1/11, 7/72).

设 E=J∩{0,1,2,3,4}，末位位由 0∈I 强制，定义实际路径的份额行 M_t、真实末位最佳回复行 L_j，以及真实倒二位两人税行 T_jk。每一行均按完整历史真实后继计算，而非把计数状态当作原模型。对 allowed 的 (I,E) 列，目标系数是：

    1[J≠∅] − 1/2,  若 I≠{6};
    1[J≠∅],          若 I={6}.

### 仅前四覆盖的 exact 证书

audit_private_early.py 的 allowed 条件是：

* singleton I={1},…, {5} 必须在 E 的前四位中出现；
* I={0} 由末位强制；
* I={6} 不限制。

它枚举 4,054 个合法字面列（包括非 singleton、六类 singleton 和省略 singleton），对每列以 Fraction 计算所有 M/L/T 行。非负乘子为：

| 行 | 乘子 |
| --- | ---: |
| M₀,M₁,M₂,M₃ | 207/355, 417/710, 253/426, 133/213 |
| M₄,M₅ | 0, 0 |
| L₀ | 0 |
| L₁,…,L₆ | 8/71（各） |
| T₀₀ | 0 |
| T₀₁,…,T₀₆ | 7/71（各） |
| 其余 T_jk | 0 |

脚本断言所有残差非负，计数为 4,054，最小残差为：

    49/2130 > 0,

取值列为 I={0}, E=∅, J={5}（位掩码 (1,0,32)）。因此把每个客户列按其重数求和，得到 W−OPT₆/2≥0。该结果是有限列的解析证书，因为列域按七个 I 位和五个自由实际会员位完整枚举，而非抽样客户实例。

### 前四或倒二覆盖的 exact 证书

audit_private_early_or_penult.py 把 allowed 条件放宽为：I={1},…, {5} 的 singleton 至少在 E 的前四位或位置 4 出现；I={0} 末位强制，I={6} 不限制。它枚举 4,059 个合法列，使用另一组非负乘子：

| 行 | 乘子 |
| --- | ---: |
| M₀,M₁,M₂,M₃ | 17/28, 58/95, 49/78, 27/41 |
| M₄,M₅ | 0, 0 |
| L₀ | 0 |
| L₁,…,L₅ | 9/98（各） |
| L₆ | 1/5 |
| T₀₁,…,T₀₅ | 9/83（各） |
| 其余行 | 0 |

所有残差仍为非负，计数为 4,059，最小残差为：

    3538309/71456112 > 0.

将逐客户残差按实际客户重数求和，给出 W−OPT₆/2≥0，故同样得到 OPT₆≤2W。

## 证明状态与边界

两个脚本都是标准库 Fraction 的定义级枚举：它们逐个生成 I、E，重算 shares、末位行和两人税行，再断言残差非负；不是浮点 LP，也不只检查一条实际路径。README/说明文件保留了客户定义域、量词和证书系数。

条件不能删除。对于“仅前四”证书，included singleton I={4} 在前四不出现且 E={4}、J={4} 的字面列给出负残差 −1/30；因此第一个证书不能覆盖允许 singleton 在倒二才出现的实例。第二个证书正是通过扩大 allowed 域并更换乘子解决这组列。若 included singleton 在前四和倒二均未覆盖，第二证书也不适用；这保留 unrestricted mixed singleton 缺口。

这个定理没有证明任意七极大六人实例，也没有证明一般目录数、提供者数或任意客户类型的 Q-CAG-HALF。它是严格条件子类结果：完整历史 SPE、最优六极大组合、末位极大重标号和私有 singleton 的早期覆盖条件均是定理假设。未成熟的“全混合私有块”必须继续作为开放问题，不能把本证书推广到缺失列。

## 与相邻对象的关系

已有无 singleton 的七极大六人证书和七极大私有块审查分别处理 dense 子类与旧错误扩展；本对象新增的是 included singleton 在前四或倒二被覆盖时的两套 exact 系数证书。它不重写静态最优组合论证，也不把旧负列当作 SPE 反例。当前六人一般目标仍 OPEN，后续若去除本条件，必须补出缺失 singleton 列的真实续局付款或构造逐历史通过的反例。
