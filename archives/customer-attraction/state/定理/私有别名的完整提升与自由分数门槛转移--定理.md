# 原输入、自由背景与编译主题

原输入是任意有限单位客户、有限非空共同标签目录S，实际玩家m≥1；保空主题、同覆盖不同标签、重复行动与全部有序历史平局。令D=max_A|A|，取整数P>D、L≥m。每经济主题A变成L个标签(A,a)，每别名增添P名只喜欢该别名的不同单位私有客户；原客户喜欢所有经济题含自己的别名。玩家数不变。输出每标签有正独立私有块，因此覆盖两两不同，即使旧题为空或同覆盖也合法。

对实数竞争质量s≥0定义真正自由分数值

\[
\delta^{[s]}=\min_{q\in\Delta(S)}\max_{A\in S}g_A^{[s]}(q),\quad
g_A^{[s]}(q)=\sum_{x\in A}\frac1{1+s q_x},\quad
q_x=\sum_{A\ni x}q_A.
\]

它也等于max_p min_q Σ_x p_x/(1+s q_x)：有限查询单纯形上线性、紧凸背景单纯形上凸连续，minimax适用。标准δ_m对应s=m−1；额外一槽τ_m=δ_(m+1)(0)对应s=m，实际玩家仍m。这不同于整数静态竞争元组的v_m、iid自洽值或真实根菜单。

# 所有完整新SPE都fresh；指定旧SPE可以提升

任意新历史深度<m，每个经济题都有未用别名，因为同经济题已用别名至多m−1<L。当前复制旧别名(A,a)时，P名私有客户及全部原A客户均已被一位过去玩家覆盖，故收益

\[
u\le(P+|A|)/2\le(P+D)/2<P.\tag{1}
\]

从末位向前归纳，后继都用fresh别名时，当前fresh的P私有客户保持独占，收益≥P。因此每份完整新SPE在每个有序历史只选fresh，含过去别名重复的离轨历史。原客户也已重复是只需P>D的理由；若错用P/2+D会无故强化成P>2D。fresh保底依赖理性后继，非任意非理性尾。

固定任意旧完整SPE σ。对每个新有序历史投影其**有序经济历史**，按σ选经济动作，再选该题最小未用别名。任意fresh偏离后的经济续局仍是同σ的真实后继，当前利润都是P加旧经济利润，所以fresh IC等价于旧IC；旧别名偏离由(1)严格排除。整张提升动作表是完整新SPE，不仅在实际路径成立。

指定提升的actual利润、福利和最优覆盖精确为

\[
u_i'=P+u_i,\quad W'=mP+W,\quad OPT_m'=mP+OPT_m.\tag{2}
\]

最后等号上界：任意m新题最多覆盖m个私有块、原经济部分至多OPT_m。下界：把旧最优m元组各次出现配fresh别名；L≥m足够，不要求旧最优题互异。

定理只对给定旧σ构造提升；别名历史可携带额外信号，**不把任意新策略逐点商成某张旧完整策略**。全部新SPE fresh的结论和这个指定提升量词应分别使用。

# 任意竞争质量的精确值与双边误差

固定新背景Q_(A,a)，聚合q_A=Σ_aQ_(A,a)。原客户部分只依经济聚合q。某个A别名的背景不超过q_A/L，故该经济题内最大私有查询值至少P/(1+s q_A/L)。均匀分配Q_(A,a)=q_A/L同时达到所有A的下界。因此

\[
\boxed{\delta_{new}^{[s]}=\min_q\max_A\left[g_A^{[s]}(q)+\frac{P}{1+s q_A/L}\right].}\tag{3}
\]

这不是两个独立极小值相加。取旧最优查询p*，均匀分到别名。任意新背景的旧客户收益≥δ^[s]，私有部分用1/(1+t)≥1−t得

\[
\sum_{A,a}\frac{(p_A^*/L)P}{1+sQ_{A,a}}
\ge P-\frac{Ps}{L}\sum_Ap_A^*q_A
\ge P-Ps/L.
\]

反向，将旧最优背景均匀分到别名，任意查询的原客户部分≤δ^[s]、私有部分≤P。故

\[
P+\delta^{[s]}-Ps/L\le\delta_{new}^{[s]}\le P+\delta^{[s]}.\tag{4}
\]

左误差可细化为Ps p*_max/L。双界量化**所有**自由分数背景，不要求真实SPE背景、不允许竞争者观察查询抽样，也不要求新策略匿名。

# 标准强聚合桥的条件归约

令Δ=mδ_m−W，取s=m−1。由(2)(4)，指定提升满足

\[
\Delta-\frac{mP(m-1)}L\le m\delta_m'-W'\le\Delta.\tag{5}
\]

若某真实旧输入/完整σ已有Δ>0，选整数L≥m且L>mP(m−1)/Δ就保留严格正差。反向，若所有此类输出的全部指定提升都满足强桥W'≥mδ_m'，任取旧输入和σ并令L任意大，由(5)迫Δ≤0。这是任意原输入的表示归约，不局限regular、固定题数或固定人数；**这些源没有给强聚合Δ>0旧种子**，所以不产生强桥反例。

m=1时竞争质量零，误差为零，δ'_1=P+δ_1，提升与(2)仍成立。零旧客户、空题、同覆盖旧标签和任意重复经济行动均不需除W或δ。

# 额外一槽的逐人缺口及已知种子

实际玩家仍m，改取s=m、τ_m=δ^[m]。精确(3)中的分母是1+mq_A/L，不是增加一名真实玩家。由(4)和逐人平移，任意actual位置i有

\[
\varepsilon_i-Pm/L\le\tau_m'-u_i'\le\varepsilon_i,
\qquad\varepsilon_i=\tau_m-u_i.\tag{6}
\]

已有ε_i>0时，L≥m且L>Pm/ε_i保严格逐人失败；反向对全部输出提升的逐人floor也可令L→∞归约到任意旧输入。L≥m已足够fresh，不需要L≥m+1。

为何旧逐人候选曾足够：取旧最优分数背景q，n_x=mq_x；任意m比较题的覆盖次数d_x整数非负，逐客户1_(d_x>0)≤(d_x+n_x)/(1+n_x)。记g_A(m,q)=Σ_(x∈A)1/(1+mq_x)。总第一部分Σ_xd_x/(1+n_x)≤mτ_m；第二部分Σ_xn_x/(1+n_x)=mΣ_Aq_Ag_A(m,q)≤mτ_m。因此OPT_m≤2mτ_m。若每个u_i≥τ_m会给half，但这个逐人前提现已失败，不能把充分性当真值。

[完整笛卡尔银行反族](../反例/笛卡尔银行目录的逐人分数门槛反族--反例.md)实际玩家m、D=3、完整有序历史SPE给u_1=m/(m−1)、τ_m=3/2−1/(2m−1)，故

\[
\varepsilon_1=\frac{2m^2-9m+5}{2(2m-1)(m-1)}>0\quad(m\ge4).
\]

这是空根真实完整SPE的种子，不来自任意非零背景局部floor，也不是整数v_m逐人失败的自动替代。任意P>3配充分大L即给同人数fresh私有别名逐人反例，但输出half仍成立。m=5时ε_1=5/36，条件为L≥5、L>36P；标准强桥的m5误差则是20P/L，仍缺真实Δ_5>0。两种缺口不能混用。

同[正则私有填充证书](../定理/正则共享超图私有填充的自由分数鞍点--定理.md)，q题、h-uniform/d-regular共享核、K>2d给

\[
\tau_m=\frac{K-d}{1+m/q}+\frac d{1+mh/q}.
\]

actual fresh玩家u_i=K−ℓ_i，要在该特殊表示取得逐人失败，准确条件是

\[
\ell_i>\frac{(K-d)m}{q+m}+\frac{dmh}{q+mh}.
\]

源未给满足条件的正则损失SPE，不能据自然碰撞样本不成功重开一般逐人floor为待证。一般额外逐人已经由银行族否定；此公式只是表示证书。

# 不保持的三种目标

较弱桥W≥(m−1/2)δ_m在平移后多出P/2福利余量：其反向差额上界是旧差额减P/2，不能沿用(5)的缺口保持。ADM的新强制旧别名孩子把当前私有收益减半，可能让旧经济收益超过旧cap的尾变成合法端点；新D不能简单商回旧D，所有强制重复格必须保留，未有ADM缺口保持定理。

由fresh支配，任何完整新SPE实际私有覆盖mP，所以W'≥mP；任意新最优覆盖≤m(P+D)<2mP。因此**全部输出完整SPE自动half**，尤其包含指定提升。作者原稿只需提升范围，独审指出这个直接加强；它不反推旧half，且强辅助桥坏例即使今后存在也不否原half。

[K>2D等大小填充](../引理/等大小私有填充的全历史损失游戏与菜单条件--引理.md)输入为非负共享核、要求q≥m、编码fresh损失游戏；本表示是任意旧输入、每题L别名、P>D、精确保指定经济σ。二者不是同一转换或彼此免费改常数。旧Cartesian私有坐标产品也是相近表示工具，本源不认领加私有客户或产品想法首次，不把归约称共同付款突破。
