# 原稿的身份与需要更正的两处

工作室7412字节稿与current的7451字节版本有相同数学内容，后者补了候选身份、清洗与审查先验。本页保留这个历史状态，以下结论由完整证明承担。先前正式页复述的原公式把核心客户包含在f内，又单独加c/n；该中间偏离下界不成立。仅一个覆盖c>0客户的主题时，根f=c，当前真实利润c/n，不会达到c+c/n。错误发生在中间式，并不否定原最终福利下界，后者可用下述核心外计数修复。

另一个原说法是τ_inc与原主题分数覆盖不同。若二者覆盖的是同一全目录并集V，这不正确：把子主题权重移给一个包含它的极大覆盖不增加费用，反向极大覆盖本来就是可选主题。因此二者的最优值相等。若比较的是最优n主题并集D而非V，必须明确不同目标域，不能仅按名称区分。

# 模型与互不重叠的客户划分

有限单位客户、有限非空共同目录、n≥1个单位提供者，全部有序历史上的任意完整纯SPE；保留空主题、重复选择、同覆盖标签、内部子主题和任意平局。令B₁,…,B_s为不同包含极大覆盖，V=∪B_j，U=|V|，C=∩B_j，c=|C|。每个主题标签固定路由到包含它的某个B_j，完整B_j归属自身。路由只作计数，不改变实际策略。

若U=c，则s=1（允许U=c=0），末位选择完整极大覆盖可严格增加每个尚未覆盖客户的收益，因此每份终局W=U。当前任何玩家真实偏离到完整B₁又都能保至少c/n，本页所有福利结论直接成立；不计算0/0。以下U>c。

对x∈V\C令I_x={j:x∈B_j}，w_I为该核心外类型的客户数。只有非空真子集I⊊[s]参与以下公式；单例是私有块，大小至少2的是共享非核心块。在长t前缀令p_j为此前归属j的行动数，r=n−t，p_I=Σ_(j∈I)p_j，定义

\[
 f_j^*(p,r)=\frac{w_{\{j\}}}{p_j+1}
 +\sum_{\substack{I\ni j\\2\le|I|\le s-1}}\frac{w_I}{p_I+r}.
\]

没有同路由后继时它是核心外直接付款下界；有同路由后继时用总收益支配和归纳，不无条件声称每个偏离都取得f_j^*。

# 关联LP及非单调预算的后缀包络

对r≥1定义

\[
B_*(r)=\min\left\{\sum_j\beta_j:
 \beta_j\ge1\ (w_{\{j\}}>0),\quad
 \sum_{j\in I}\beta_j\ge r\ (w_I>0,2\le|I|\le s-1),\quad\beta\ge0\right\}.
\]

它是有限有理覆盖LP；β_j=r总可行，若U>c则B_*(r)≥1。最小值存在。置D_t=t+B_*(n−t)，E_t=max_(t≤q≤n−1)D_q>0，故E_t随t不增，即使D_t并不单调。

取LP最优β及y_j=p_j+β_j。私有客户的系数y_j/(p_j+1)≥1；共享客户的系数(p_I+Σ_Iβ)/(p_I+r)≥1，因而

\[
 U-c\le\sum_j y_j f_j^*\le D_t\max_j f_j^*.
 \tag{COUNT}
\]

此处没有核心类型，不能再把相同客户加进右边的f。

# 全部有序历史的真实续局证明

对剩余人数同时量化所有有序前缀归纳，证明当前玩家的规定终局收益至少

\[
 \ell_t=c/n+(U-c)/E_t.
\]

在任一长t前缀，真实强制当前选择使f_j^*最大的整个B_j，后继仍按同一完整σ在改变后的历史行动。

若没有后继行动路由j，则私有块最终负载≤p_j+1；每个共享核心外客户的负载≤p_I+r；每个核心客户的负载≤n。当前真实偏离收益至少c/n+f_j^*≥ℓ_t，这是COUNT和D_t≤E_t的结论。

若有一个后继在深度q>t路由j，其真实主题A⊆B_j。在这一**同一终局**中，当前玩家覆盖该后继覆盖的每个客户，分母相同，所以当前总收益至少该后继总收益。归纳给后继≥ℓ_q；E_q≤E_t又给ℓ_q≥ℓ_t。这里不先删核心再比较两个人的收益。末位没有后继，落入第一种。当前IC把真实偏离保底转给规定动作，归纳完成。

actual路径上逐人求和，收益总和等于覆盖，得

\[
 \boxed{W\ge c+(U-c)\sum_{t=0}^{n-1}\frac1{E_t}.}\tag{DYN}
\]

系数至少1/2时，OPT_n≤U≤2W，实际还给U≤2W−c。不是将互斥分支福利相加：每个当前偏离只使用同分支后继的总收益保证。

# 原LP的结论如何保留

原B(r)使用全部类型，包括核心I=[s]（s1时又将核心作私有）。在U>c的域，原约束包含B_*的全部约束，故B(r)≥B_*(r)，相应原后缀包络E_t^old≥E_t。DYN于是推出**以原B(r)、原E_t写出的原最终式仍成立**。本页更换了错误的中间付款式，并给可以去掉核心需求的较强版本，不把原最终定理整体否定。

β_j=r/2对r≥2总满足私有需求；r1若有私有块须取β_j≥1，不能用1/2。这恢复原标量上界t+sr/2（r≥2）及n+s−1（r1）。单调性只能通过后缀包络转移，不能省略。

# 分数覆盖推论与准确目标域

令τ为核心外正关联类型的非负分数覆盖最小总重，即每个正I要求Σ_Iα≥1。因U>c，τ≥1，核心覆盖Σ_jα≥1自动成立；故τ也等于V用全目录主题覆盖的分数覆盖数。取β=rα，私有需求由r≥1保证，得B_*(r)≤rτ。

H_t=t+(n−t)τ=n+(τ−1)(n−t)随t不增，且对q≥t有D_q≤H_q≤H_t，所以E_t≤H_t。因此

\[
 W\ge c+(U-c)S_n(\tau),\qquad
 S_n(\tau)=\sum_{r=1}^n\frac1{n+(\tau-1)r}.\tag{FRACTIONAL}
\]

τ≤2时每项≥1/(2n)，所以half成立。τ≤3且n≥7时也严格超过half：令f(x)=1/(3−2x)，凸性给梯形和≥积分，故

\[
 S_n(3)=n^{-1}\sum_{t=0}^{n-1}f(t/n)
 \ge\tfrac12\log3-\frac1{3n}.
\]

级数log3=2Σ_(k≥0)(1/2)^(2k+1)/(2k+1)>1+1/12+1/80=263/240，故n≥7时右边>263/480−1/21=1681/3360>1/2。n6、τ3则S₆(3)=2509/5040<1/2，只是此系数未达门槛，不是游戏反例。
