# 公共基础旧目录的逐项用途

这是模型定义、精确命题、来源与研究入口的旧用途索引。共同名词不替代模型；旧根目标/清洗/图要求不能覆盖现行恰六人与三阶段规则。

本页处置原目录的 14 条记录，不处置这些路径所指源文件的全部数学。记录编号是原 JSON 的零起始 `entries[index]`。完整字段原文、字段是否存在、原路径及两种关联键见[逐项绑定数据](../../../../tools/evidence/catalog-semantic-resources/catalog-semantic-records.json)；[总合同与当前校正](旧研究总目录的字段语义与版本边界--资源.md)解释版本、字节和证据层级。

## 角色解释

| 原 role | 原 Markdown 角色含义 |
| --- | --- |
| `navigation` | 阅读导航；真值查精确正文及账本 |
| `obstruction` | 方法障碍；否定范围以正文为准 |
| `definition` | 定义与模型；不隐含跨模型定理 |
