# 静态同时行动的完整证明

有限单位客户和共同非空目录，m≥1单位提供者。固定静态纯NE终局a，c_x是客户x的负载，W=Σ_x1_(c_x>0)=Σ_i u_i。取达到OPT_m的比较主题T₁,…,T_m，k_x为这些主题覆盖x的次数。

在同一其他玩家行动固定的静态偏离中，i改选T_i的每客户分母≤c_x+1，所以

\[
 u_i(a)\ge u_i(T_i,a_{-i})\ge\sum_{x\in T_i}\frac1{c_x+1},\qquad
 W\ge\sum_x\frac{k_x}{c_x+1}.
\]

对k_x≥1有1_(c_x>0)+k_x/(c_x+1)≥1：c_x0时第二项≥1，c_x>0时第一项已为1。因此

\[
 \operatorname{OPT}_m=\sum_x1_{k_x>0}
 \le W+\sum_x\frac{k_x}{c_x+1}\le2W.
\]

空主题、重复、零客户和平局不影响此静态证明。调和势Φ(a)=Σ_xH_(c_x)的单人加入边际正好是其利润，但以上已经给直接逐客户证明，不依赖势最大化。

# 逐关联局部模板及两个精确限制

核心单独处理或为0时，真实路由计数p_j、剩r人，形式表达式f_j=w_{j}/(p_j+1)+Σ_(I∋j,|I|≥2)w_I/(p_I+r)。非负权y要逐客户支付并集，需

\[
 y_j\ge p_j+1\ (w_{j}>0),\qquad
 \sum_{j\in I}y_j\ge p_I+r\ (w_I>0,|I|\ge2).\tag{P}
\]

这些是此**计数模板**的约束，不直接证明当前每个偏离在所有后继下取得f_j。若有同路由后继，必须用其真实总收益支配和同时全历史归纳，见[动态关联预算修正版](../定理/极大关联LP动态预算半覆盖--定理.md)。有核心时还必须从f剔除核心，不能再加c/n重复付款。

原提议统一y_j=p_j+r/2对共享约束有效，对私有约束仅r≥2有效；末位r1会少1/2，须改y_j≥p_j+1。原稿的t+sr/2不能不分末位就当作全历史可行预算。若已证明某真实当前可保max f_j且Σy≤2m，则P给U≤2m max f_j；这是单节点的条件关系，仍不自行给全路径W≥U/2。

# 完整二分关联确实排除总权重2m

令m≥1，目录为2m个极大主题L₁,…,L_m、R₁,…,R_m，客户x_jk仅属于L_j和R_k。每个主题大小m，客户总m²，选全部m个左主题即达OPT_m=m²。

空根p0、r=m时，P要求y_(L_j)+y_(R_k)≥m。将m²条式相加，每个变量出现m次，得mΣy≥m³，所以Σy≥m²；所有y=m/2可行达到。m>2时最优模板费用m²>2m，明确否定这个单层非负乘子模板普遍2m闭合。它没有给完整纯SPE，更没有给half坏例。

原稿随后称任意只选极大主题的m人终局，若选a个左、m−a个右，则W=m²−a(m−a)≥3m²/4。这漏了重复选择。准确地，设终局出现ℓ个**不同**左主题和k个**不同**右主题，则

\[
 W=m(\ell+k)-\ell k,\qquad \ell+k\le m.
\]

只有ℓ+k=m（全m次选择不同）时才得到原3m²/4下界。m3三人都选L₁时，W3<27/4，直接反驳原“任意终局”表述；该终局最后一位改L₂收益3而原为1，不是SPE，所以这也不产生主问题反例。源未证明该家族任意SPE都无重复，本页不补造此结论。模板费用证明完全不依赖错误的福利旁注，仍然成立。

[完全二主题关联LP根预算障碍](../障碍/完全二主题关联LP根预算障碍--障碍.md)使用K_s，原这里是K_(m,m)，二者是不同客户构造：前者OPT_m=ms−m(m+1)/2，后者OPT_m=m²；不能把同为分数顶点覆盖的论证当同一实例。
