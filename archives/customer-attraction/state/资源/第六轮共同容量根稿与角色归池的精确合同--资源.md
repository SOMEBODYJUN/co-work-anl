# SAFE确实解决的负项与CLIP不解决的净容量

对natural context(g,i)，规定主题a、规定完成叶B，完整利润v=u_i(B)>0；在actual前缀强制同一a并沿原策略完成为A，D=u_i(A)≤u_i，e=u_i−D≥0。两叶coverer差的正价P、负价N逐客户满足

\[
v-D=P-N,\qquad D-N=J+L>0.
\]

后一式因两个完成叶共同coverer至少含当前人，逐客户共同数/(c_Ac_B)>0。故F=N+e∈[0,u_i]，从该context gross当前整行βu_i统一退βF，净行系数β(D−N)/u_i非负。past正价仍保原actual(j,x)合法标签；不把负off-prefix coverer假配成某位过去玩家的实际券，也不调用过去人在强制叶中的假IC。每个β仍是对原完整query的一次常数，退款后的净系数不另购买同一整条IC。

删原正边总价c≤min(P,F)，并同步少退c，守恒仍为v=(u_i−F+c)+(P−c)。最大取消给current min(v,u_i)、外送(v−u_i)_+。同一原注入与同一v分母下固定子边后须重算流；新β≤旧β，但少退会增加current，所以新正负载只保证不超过旧**gross**，不保证不超过旧**net**。局部最少传播也不等于全图cap最优。u_i=0时非空query不可能零收益，活动context不存在，不能做0/0。

这些内容已有[完整SAFE/CLIP定理](../定理/同节点安全净券与最大标量剪枝--定理.md)，本两入口是其主线位置与责任说明，不重新认领同一数学。局部非负已经解决，不能把“如何假配负项”继续列为当前根本缺口；仍未付的是source当前、各context current与past实际券的合计。

# 同角色归池、全O cap2与fresh核分别初始化

past金额z必须先核原出口确在actual角色j的券域，正量蕴含u_j>0。之后允许将它在同角色全部实际份额上按统一系数z/u_j分配，总金额仍z；这是同一角色钱包内归池，不调用过去IC，不跨角色退款，也不凭此新增容量。

对full-O每个来源客户一单位，owner在actual前缀作合法query，将一单位在真实完成叶coverer中均分：current到实际行，past到合法实际终点，future到真实更深规定context。使用同一合法全客户SAFE/CLIP核，最终角色净金额A_j非负，严格future图有限守恒给

\[
\sum_jA_j=|O|=\operatorname{OPT}_m.
\]

因此若能对同一选择证明A_j≤2u_j（全部j），则OPT_m≤2Σu_j=2W。固定客户券各自限制是比同因子角色总量限制更强的接口；归池只放宽分配，并未证明这一ROLE-CAP2普遍成立。不能给每个source/context分别用一份2u_j后仍称同一个cap。

# 全图HIT是终点界，局部均价不是终点价

一个合法SAFE概率行的当前吸收为p_i=(D−N)/v，其他角色recipient为p_j=q_j/v。每个j的正价至多Σ_(x∈a)1/(c_Ac_B)≤D−N，所以p_j≤p_i；fresh行和合法CLIP删边也满足。此条件恰等价于“包含当前i的非空角色子集上均匀分布”的凸组合：对0<t≤p_i取U_t={j:p_j≥t}，以质量(1+|U_t|)dt混合uniform({i}∪U_t)，各坐标积分精确还原p。

因此给当前价λ_i和recipient**后续整图续价**z_j，局部行满足

\[
p_i\lambda_i+\sum_jp_jz_j
\le\max_U\frac{\lambda_i+\sum_{j\in U}z_j}{1+|U|}.
\]

它的精确抽象范围见[均匀行与局部价格](../定理/净券行均匀子集凸包与局部价格--定理.md)。future z_j不能直接替成角色j的actual终点价格；那样会漏后续传播。也不声称每个抽象极值行都由真实游戏实现。

固定同一核及actual角色集K，k=|K|。当当前i∉K时，按future角色逆序归纳：K内recipient终值至多1，外K至多h=k/(k+1)，当前吸收对K贡献0。一个子集内有a≤k个价1、b个价≤h，均价(a+bh)/(1+a+b)≤h，故最终落K比例≤k/(k+1)。到K并不被假定立即停止；K内只用终值≤1。past为合法终点，不产生逆向非终端边。

合法owner INIT本身也是包含源角色的均匀子集行。若M_i为源角色质量，则对同一全部来源/核的所有K同时有

\[
A(K)\le M(K)+\frac{k}{k+1}M(K^c),\qquad \sum_jA_j=\sum_iM_i.
\]

这是真正跨全部context、客户重采和来源的终点约束，强于单行HIT；不是总访问次数界。将高于λ_i的其他角色终点价降序列为λ_(1),…,λ_(l)>λ_i，逐层对HIT积分给每单位源价格包络

\[
H_i(\lambda)=\frac{\lambda_i}{l+1}+\sum_{s=1}^l\frac{\lambda_{(s)}}{s(s+1)}.
\]

完整域及后来的fresh来源时间界见[跨context终点定理](../定理/净券跨节点角色命中与来源后缀界--定理.md)。全O不能继承fresh“不早于source”支持：O∩C来源可以在INIT即流向past。常数角色价只给M≤M；源库存M不等actual利润向量u，HIT及价格表示仍不推出角色cap1/cap2或共同费用≤W。
