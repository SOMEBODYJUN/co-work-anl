# 加权拥塞旧目录的逐项用途

这是加权原子拥塞的旧用途索引。真实全状态无近似PNE、仅有改善环、指定selector/clock架构障碍、局部势存在界和有限审计分别保留。原目录同时包含奇环拓扑、线性全状态下界和后续结构方法；“全类OPEN”须回到精确命题，而不能拿某个旧标签覆盖后续相反结果。此页未重新证明全部下界或认证论文优先权。

本页处置原目录的 501 条记录，不处置这些路径所指源文件的全部数学。记录编号是原 JSON 的零起始 `entries[index]`。完整字段原文、字段是否存在、原路径及两种关联键见[逐项绑定数据](../../../../tools/evidence/catalog-semantic-resources/catalog-semantic-records.json)；[总合同与当前校正](旧研究总目录的字段语义与版本边界--资源.md)解释版本、字节和证据层级。
