## SOURCE-NET 原消息的完整数学合同

原事件 `976fefcca689420cbd3794cbe6d84525`（seq217）明确承认“同一 Hall-A 的 gamma/f/eta 下，所有角色 source 当次费用同时可付”，同时指出 reset 后多 query incoming 与正 IC 税尚未付。其数学已经进入[同时源付款定理](../定理/实际取消的同时源付款与入流余额--定理.md)及[内部核读](../审查/固定价格取消与入流付款的内部核读--审查.md)。

固定同一最优比较并集 O 与 actual 覆盖 C，令 R=O\C、G=C\O、净源量 Delta=OPT−W。Hall 取消后残源 rho 的总量为 Delta，共同钱包满足 sum eta_i=W。对同一原 actual 前缀的真实查询 s，完整收益 D_s、当次吸收 A_s 与非负整行 IC 系数 w_s=A_s/D_s 给

\[
K=\sum_s w_su_{i(s)}
=\Delta+\sum_{s:D_s>0}\frac{A_s}{D_s}(u_{i(s)}-D_s)
=\Delta+E_\rho,\qquad E_\rho\ge0.
\]

证明只用全吸收守恒 sum A_s=Delta 与原完整 SPE 的真实查询 IC：D_s≤u_i。D_s=0 的查询不能有正吸收，费用取0。它给 K≥Delta；要推出 half 还需同一系统 K≤W。逐行 `K_in≤eta−K_src` 只是原净预算的拆分，并未证明该不等式。SOURCE-NET 付过的 source 不能再另领一次 u_i，旧查询叶捕获者的收益也不能免费移入 reset 后的不同历史。

原消息还明确允许更宽的[自由 query 与起点价格](../算法/自由查询与自由起点的单位采购价格--算法.md)以及[自由删源总价](../候选/自由删源总价与半覆盖的充分接口--候选.md)。若仅求 `min sum q_x kappa_x≤W`，可以放弃旧逐行 Hall 钱包；但不能再将自由低价与另一 Hall 点的 SOURCE-NET 信用相加。消息没有证明这些付款证书与 half 等价，也没有要求所有方法必须沿其建议路线。
