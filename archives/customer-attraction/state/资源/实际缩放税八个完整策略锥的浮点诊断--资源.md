# 候选与独立的覆盖代数

采用[共同目录完整历史模型](../定义/共同目录完整历史模型--定义.md)，实际终局逐客户负载c，人数m≥1，置α=(m−1)/m、gα(T)=Σ_(x∈T)1/(1+αc_x)、Mα=max_Tgα(T)、Gα=Σ_(c_x>0)1/(1+αc_x)。被研究的动态桥是

[

c0时右侧d；c>0,d0时右侧非负；c>0,d≥1时右侧=(d+αc)/(1+αc)≥1。求和即OPT_m≤mMα+W−Gα。因此(D)若在所给SPE成立便足half，但(A)的普遍性不证明(D)。空主题、重复、无兴趣客户及零客户不破(A)，零客户使用不等式而不除福利。
