# 合法大背景策略锥与三尾价格模板

## 资源入口及两个问题的区别

[原件与完整来源清单](../../tools/evidence/legal-background-second-order/source-manifest.json)逐一保存十二源的SHA、冻结定位及原字节。理论承重见[显式方差界与二阶值](../定理/合法大背景的整数分数误差与二阶交叠值--定理.md)。本页另保存三尾线性证书模板，不把二阶成本游戏、必要行锥和真正原CAG完整SPE混成同一个可行域。

原security README把一般FF/extra逐人合同列作OPEN；[银行族](../反例/笛卡尔银行目录的逐人分数门槛反族--反例.md)已更新为失败。原README亦明确actual-insertion加强式已由十三人三十六客户反例撤回，有限阴性不能复活它。根聚合、特殊人数和六人half分别保留独立量词。

## 合法背景发现器：实际生成什么

`high_background_probe.py`（原ID `9e034c472f2d6ffbb772`）对固定兴趣阶数k建全部k元类型incidence矩阵M，初始权按循环轨道同值，从而各主题等大。给定权后在全部有序历史递归选一个最小交叠成本行动；用这些**固定完整策略**的真实比较行建立LP，约束主题大小均为1，最大化根交叉成本减 $(r-1)k/K$。八组 `(r,K,k)` 各60次的源码上限共480；保存文件不是480份完整运行日志。

原目标使用未缩放交叠D并去掉恒定自身大小1。合法过去P全1时 $d_T=k$、$C=D/k^2$、$s=1/k$；所有行和为k，故均匀查询与均匀背景双边给

$$\tau_{r-1}(C)=[1+(r-1)k/K]/k^2.$$

原excess是 $k^2[L_1-\tau_{r-1}]$，不能直接当实际C成本差或有限B收益差。保存JSON `d1de014dc093ed268858` **仅一条历次最佳点**：r3/K6/k2/iteration0，原excess约−1/6，15类型、43个完整历史行动；它不独立认证480次扫描结束，也不是严格反例。

`nonuniform_background_probe.py`（`edc88aa7c851404edb4c`）取每个坐标1–4的合法P、全部非空类型，令L=M/d、D=M/d²，LP强制Lw=1。先给定完整成本策略和查询p优化类型权，再解静态tax查询，四次交替；五组r/K各100初始点，源码上限2000次，但失败可提前break。固定p交替不等于共同全局最优。保存 `075418a816f776aa2bde` 仅r3/K5、P=(3,4,2,3,1)、iteration0/alt0一最佳点：只有全兴趣类型权13，31历史，excess=0；不能从该一条推出全部试验阴性或一般不等式。

两程序用浮点LP和近似平局选策略。即使保存策略有完整历史，它也只是**二阶成本**的策略，尚无有限B完整SPE资格。类型浮点权的单位客户实现、零比较及余阶均需额外处理。

## 扩大矩阵域与中断前身

`general_pairwise_cone_probe.py`（`a46dd2144ae9c94598b4`）把类型Gram锥扩大到任意非负对称C，六组r/K各80初始点、最多四次交替，变量坐标界[0,1]。其cost写成“对角+终局总和−一个对角”，净值正是 $C_{aa}+\sum_{j\ne i}C_{a,z_j}$。`general_pairwise_independent_base_probe.py`（`624e5ece86dfcc077468`）再把对角基项换成独立非负d_a，六组各100点；目标为 $d_a+\sum_{j\ne i}C_{a,z_j}$，静态tax也同步改用d。二者均没有本批冻结的candidate输出；源码尝试不能当见证已产生。任意C/独立d均不可直接叫合法客户交叠实例。

`pairwise_matrix_probe.py`（`9b0d5d16390df342688b`）是集合值BI前身。对每个行动后继集合，最小化玩家可选行动的“最坏成本上限”，再保留不超过该cap的子终局；这正利用每个偏离分支可独立选择可信续局。源码循环r3/4/5、K3/4、各2000随机矩阵，但README只声称手动中断，没有完成计数/终止输出。本轮保留程序，不补造中断前缀长度、不重复大扫描。

## 三尾十三行价格模板及原报告的版本边界

`probe_three_tail_price.py`（`deef97e1f207e69fd297`）不是完整SPE搜索。原子由整数过去负载p、五个会员位 `(a,b,c,q,r)`、查询质量t及聚合会员d、ell表示。令 $s=a+b+c$，`alpha=a/(p+s)`、`beta=b/(p+s)`、`gamma=c/(p+s)`，s=0时均0；另有 `zc=c/(p+c+q+r)`、`zr=r/(p+c+q+r)`（各分子为零时置0）。按源码顺序十三行是

| 行名 | 原子系数 |
|---|---|
| KQ, KR | alpha−q/(p+3)，alpha−r/(p+3) |
| P, Z | t gamma−d/(p+a+b+1)，t gamma−ell/(p+a+b+1) |
| S+V/t | t beta−d/(p+a+1)+d ell/[t(p+a+1)(p+a+2)] |
| F, J | alpha−zc，t zr−d/(p+c+q+1) |
| KB, KC | alpha−b/(p+3)，alpha−c/(p+3) |
| LCA, LCB | gamma−a/(p+a+b+1)，gamma−b/(p+a+b+1) |
| KT, KL | t alpha−d/(p+3)，t alpha−ell/(p+3) |

目标为 $\mathbf1_{p+s>0}+t\,alpha-\min(1,d)$。程序只问是否有十三个非负乘子，使逐原子组合不超过目标；有限原子域为 $p=0,\ldots,p_{max}$，五位遍历32，$d\in\{0,1,t\}$、$ell\in\{0,t\}$，故共 $192(p_{max}+1)$ 行。d与ell的相关性、共同真实客户和完整策略均未由此独立原子域强制。可行证书需先证明行均为真实有效必要行且域覆盖正确，不能以字段名替代。

冻结JSON `dec2a5c46e8193082600` 有t=3…16十四记录，$p_{max}=t-3$，行数192…2688均匹配；每项HiGHS status2，即这个有限非负乘子模板不可行。当前源码默认`--max 12`只产生t3…12；冻结到16的报告须额外参数`--max 16`才具有匹配范围。没有保存当时命令，不能声称默认入口直接生成该完整报告。所有记录均无coefficients或exact_pass，属于浮点不可行报告，无精确Farkas乘子；不证明原游戏反例或不可能存在其他证书。一般t≥1是探索动机，不是这些十四t已证普遍结论。
