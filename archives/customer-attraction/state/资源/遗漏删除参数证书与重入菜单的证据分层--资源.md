五份主稿共23593B，已逐份核冻结 size、SHA256与 Git blob SHA1并完整读取。它们在上一批只作必要比较；本批才按实际认领作为 primary 清洗。原件和以下全部新证据见[独立目录](../../tools/evidence/omitted-deletion-parameters-and-reentry-primary/README.md)。没有把先前比较阅读倒填成早已 primary done。

本批 `full_tree_duality` 两源已取得并重放：`audit_omitted_deletion.py` 与 `omitted_deletion_independent_audit.json` 共同确认删前目标可实现、删去一名 `topics=[3]` 客户后目标对完整可信菜单不可实现；新证据只补足该有限审计的当前 clean 来源和隔离复现，不替代参数全集证明。对应四源批次的 gluing 两源另归入共同客户粘合障碍对象。

## 数学去向

- [遗漏删除与无界根门槛](../障碍/实际遗漏客户删除与可信根门槛的无界敏感性--障碍.md)给实际客户表、全集递推的量词、全部参数有限证书的覆盖证明、六前缀严格切口、任意整数单客户族及关键末层严格而非全树 strict 的边界。
- [同步重入菜单](../定理/有限跨树重入的同步菜单与静态极限--定理.md)完整保存任意 \(m,d\) 的端点归约、产品同步、通用位置集等价、有限支撑界、并集成本、七客户冲突及全部重入的静态极限。没有证明通用位置分布或总安全付款存在。
- [变基线未证阈值](../想法/变基线银行强分离的未闭合阈值接口--想法.md)保短导航末段 \(a=(x+y)/(r+1)\) 和 \((x-a)/(x/2+y-a)\) 的未闭合合同；仅作明确数值假设下的代数，不虚构客户模型。

变基线导航的大部分全码银行 no-go 已由[上一批正式对象](../障碍/二进制全码银行的加载者真实偏离--障碍.md)完整吸收，本批不重复定理。重入 README 的数学和范围全部被主稿定理及本资源覆盖，故逐源记录可用 duplicate；不是只读标题或目录就退休。

## 原作者与独审到底做了什么

原删除作者主张：规范参数实现枚举211收益线、65分点、129代表，另独立展开在 \(t=0,1/2,3/4,1\) 的有序历史，并给正例完整阈值策略。原独审从定义直接计算客户分数，未导入规范 solver，重建删除前后252个计数态和端点全集，以及第二次 \(F\) 前六前缀强制 \(D\) 的唯一终局。独审又明确逐行检查作者 `verify.py` 的参数覆盖论证，**没有重跑全部129代表**。其先验是独立端点重建和对已有证明/代码的实读审查，不能改称全部范围 statement-first 或全参数独立复跑。

本批已知作者与独审全文，是 proof-aware 的定义级新实现；没有外审或新颖性认证。新实现不依赖那些缺失原件，数值一致不代表同 SHA 原程序成功复用。原证明中无界整数族的全称基础是完整参数覆盖及齐次缩放，有限 \(s\) 回归不能替代它。

原稿文件角色也分别保留：`reduced.json` 为唯一正文输入，`verification.json` 为作者当时的全参数证据，`threshold_certificate.json` 是完整策略；`discovery.json`、`minimize.py`、`minimal.json`、`reduced_input.json` 为发现/约简来源，`parameter_scan.json` 和 `breakpoints.json` 是初始探索。不能以早期扫描替代最终参数证据。此说明仅来自已读主稿，不假称本批实读了这些缺件或尚未加载的代码。

重入作者明确未独立审查、未外审、未提交/发布个人稿；本批不借删除方向的独审身份认证另一方向。其单次 PRODUCT-MENU-TIME 产品分离原理来自旧稿，现行[全前缀菜单候选](../候选/均匀通用时间的完整前缀菜单与关联预算--候选.md)已有完整量词合同；本批重入定理仍给自足证明，同时把新增范围准确定位在多次真实重入、恰 \(d\) 集、\(\binom md\) 接口和实际并集成本。源称“层次”只保证 \(M_1\ge\cdots\ge M_m\)，七客户的固定查询冲突不被误写成所有相邻 minimax 层都严格。

源另提醒，某些旧完整 SPE 已否定一根纯完整列同时封顶全部查询；该旧例不随本稿重新给出。本批不把这条历史边界提升为自由混合菜单的反例，也不以标量排序或有限阴性扩样代替真正的干预成本。要否定混合菜单或付款，必须保其各自优化次序和全称合同。

## 与删除/安全值旧边界的关系

删除客户且允许重选全部策略，不等于[删固定提供者背景并保策略](../引理/固定插入共同池与删除后的原策略激励界--引理.md)。前者可使目标在任何策略下消失，后者给原策略缺陷上界；没有一个简单强弱包含关系可越过不同输入操作。

全部重入得到 \(v_{m+1}\)，不等于逐人 \(v_m\)、纯末位 \(\theta_m\) 或某个根真实菜单值。\(W\ge mv_{m+1}\) 仍是该稿的开放付款接口；已知更强局部菜单失败不能自动判这个更弱总预算为假。所有新对象已有解释的关系判断，不把来源链接直接当作 phase-three 全图。
