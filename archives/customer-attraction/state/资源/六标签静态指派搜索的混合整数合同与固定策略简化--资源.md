# 六标签静态指派搜索的混合整数合同与固定策略简化

## 精确辅助域与搜索目标

4781B发现程序、3039B简化程序和1218B冻结发现报告三源均全文读取。采用标签集$P=\{0,\ldots,5\}$，三人依次选择尚未出现的标签；辅助终局是三个不同标签。给二元/三元无序子集一个有符号整数潜势$F$，辅助收益为

$$v_i(a,b,c)=F(\{a,b,c\})-F(\{a,b,c\}\setminus\{a_i\}).$$

这不是单位客户收益，可能为负；辅助游戏禁止重复，而原[共同目录完整历史模型](../定义/共同目录完整历史模型--定义.md)保留重复与全部离轨历史。必须经精确回放、正客户编译及重复历史补全，才能拿它作为原模型接口反例。发现脚本的文件头也明确只是一个命名静态指派桥攻击，不是Q-CAG-HALF扫描。

实际路径硬编码$A=(0,3,4)$，目标支持$T=(1,2,5)$，二者不交。归一化

$$F(034)=F(03)=F(04)=0,\qquad F(34)=1$$

使实际三收益$(-1,0,0)$、总和$-1$。所有不同三元组的辅助覆盖总和是

$$w(S)=3F(S)-\sum_{B\in\binom S2}F(B).$$

程序要求$w(T)\ge w(S)+1$对其余19个三元组成立，故T为该有限域唯一最优支持；再要求全部六个T排列的冻结指派成本

$$\sum_i[F(A_{-i}\cup\{T_{\pi(i)}\})-F(A_{-i})]\ge0.$$

这比实际辅助福利$-1$高。此处只搜索原接口的一个六标签、三人、不同动作结构，不声明所有辅助潜势或所有原共同目录都已搜索。

## 第一程序的251变量和1243约束

$F$共有$\binom62+\binom63=35$个整数变量，各在$[-10,10]$。每个不同二历史$(a,b)$及剩余c有二进制$y_{abc}$共120，表示最后动作；第二动作二进制$z_{ab}$共30。另有各30个连续$p^2_{ab},q^1_{ab}$及6个$u^1_a$，界$[-30,30]$。总251变量，其中185整数、66连续。

对每个首动作，z一热；每个不同二历史，y一热。选中y时，三元F最大，等价于末位辅助边际最大（删去末位的二元F对其候选相同）；并把$p^2$、$q^1$绑定到相应第二/第一人的最终边际。选中z时要求相应$p^2$不小于所有合法第二动作的值，再把$u^1_a$绑定到对应真实后继。根要求$u^1_0\ge u^1_a$。还固定$z_{03}=1,y_{034}=1$。

| 约束组 | 数量 |
| --- | ---: |
| z/y一热 | 36 |
| y选择的末位最优性 | 480 |
| y选择的两个收益等式（各双向） | 480 |
| z选择的第二最优性 | 150 |
| z与根收益绑定（双向） | 60 |
| 根最优性 | 6 |
| 四归一化与两固定选择 | 6 |
| 目标唯一最优 | 19 |
| 六冻结指派 | 6 |
| 合计 | 1243 |

所有条件化约束用BIG=100。F差在$[-20,20]$，连续收益与两F项的链接表达式幅度至多50，两个连续收益差幅度至多60，因此未选中时100确使这些行无额外限制；这来自本程序的有限边界，不是无界潜势的通用常数。

SciPy `milp` 的目标是全零，只找可行点，55秒时限；“Optimal”在这里不意味着客户数、支持数或违例强度最优。代码对整个返回向量取最近整数，距离大于$10^{-5}$只置一个标志，并不拒绝输出，也不精确重验写出的F/策略。原报告保存status/message/变量/约束及F/策略，没有运行环境、版本或可校验最优性证明。本次不重新执行优化器；保存报告的数学有效性由[独立整数回放](../计算/静态指派两代见证的精确回放与编译分界--计算.md)另核。

## 固定已发现策略的70变量简化

第二程序从同目录`probe_disjoint_assignment.json`只读取`second`和`last`，并不使用其旧F作约束值或初值。实际A、目标T仍硬编码。策略固定后，对全部不同前缀直接写末位/第二/根辅助收益不减；保四归一化、目标唯一性及六指派。另添35个非负整数绝对值上界s，约束$s_B\ge\pm F_B$，最小化$\sum_Bs_B$。

这有70个整数变量、255行：末位120、第二30、根6、归一化4、唯一目标19、指派6、绝对值70。F在$[-10,10]$、s在$[0,10]$。只在**这个已固定策略和这些边界**中简化；没有寻找所有策略的最小客户数或最小主题数。源码断言solver状态0再四舍五入F，没有精确对偶证明。写出的`assignment_witness.json`明确仍标“integer discovery witness; requires exact replay”。

冻结简化见证是已有来源 `850a9b379cc0c33f9ee6`，作为比较依赖保存，非本批新增认领。其13个非零F、L1=15是直接整数计数；本次未跑优化器，故不新认证它的精确L1最优性。与原发现的29非零、L1=132相比，策略相同，但F和辅助最优覆盖/指派数值有真实变化，不能把两报告混作同一组F。

## 如何复现与如何接续

原程序依赖NumPy/SciPy，发现入口没有外部输入但会旁写同名JSON；简化入口要读取确切冻结发现报告并旁写witness。若需重新搜索，应各在隔离目录保存原件/版本/solver状态和完整输出，随后用独立精确整数/单位客户审计核验；55秒阴性或不同最优点不能升级为全范围无解。原件和完整合同在[证据入口](../../tools/evidence/static-assignment-search-primary/README.md)。

本批成熟内容是实际程序的有限数学合同、两代见证的独有数值和精确回放；未成熟/未认证内容包括全潜势搜索、跨策略最小性、通用编译的算法新颖性和六人half。后续若拿真实偏离预算作目标，应使用[真实净差匹配候选](../候选/真实最优组合的净差匹配与共同付款--候选.md)，不能把本冻结后缀攻击算成其反例。原文件头及signed领域仍完整保留，不因旧或不在主线丢弃。
