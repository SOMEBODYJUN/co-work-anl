# 新密度组件已付什么，仍缺什么

[NEW-CAP定理](../定理/同客户来源保持流的加强初始化与节点密度--定理.md)对客户保持核给初始边
\[
\widehat q_{ijx}=\min\{p_{ix},1/\delta_{ix}\}/c_{W_i}(x),\quad
\delta_{ix}=c_B(x)+1-1_{x\in B_i},
\]
仍允许同一次初始化。对每个source/client库存和≤1、每初始边≤source库存/c_W、严格未来有序DAG，来源质量在同角色层构成反链；目标首次偏离位置k固定所有reset父角色为k，因此多父也有
\[
f_{tx}=c_{V_t}(x)h_{tx}
\le\sum_{i(\alpha)=k}p_{\alpha x}+\sum_{i(\alpha)<k}A_{\alpha x}\le1.
\]
它不靠唯一父，不给actual-prefix终点同一个界。于是每个非actual context的current可由一条完整query IC支付；支持保持、初始密度、每context whole-IC和optional-common合法性已付，不能继续列为该新核缺口。它不是旧fresh ν重采流的免费费用界，换核/初始化必须重算J和总账。

同角色跨context仍待付。共同future边全满时，同动作a的current合并为Σ_xH_ax/c_Aa(x)，反链给逐客户Σ_aH_ax≤1。固定a可用(max_xH_ax)u_l付款；但Σ_a max_xH_ax未被限制为1，所以不同action不能各领一次u_l。同action压缩已经去重为旧uniform-reset捕获流，不重新认领新机制。

residual进一步设θ_s=A_s/D_a（D_a0则A_s0取θ0），V_s=finish(g)、z_s=u_l(finish(g,B_l))、ell_s=u_l(V_s)−z_s、e_a=u_l−D_a，得精确ROLE-TRY：
\[
A_l=\sum_{s,x}\frac{h_{sx}}{c_{V_s}(x)}

\]

# ADM：有利全端点MIN不等旧菜单MAX

固定actual路径B和u_i。在actual前缀h_i强制经济主题A，只要求之后尾部是完整子SPE，不重新要求被强制当前玩家最优。令R(h_i,A)为全部这种终局，
\[
D_{iA}=\{y\in R(h_i,A):d_i(y)\le u_i\},\quad D=\bigcup_{i,A}D_{iA}.
\]
每格非空由原σ提供；实际经济行动格也放开其它cap合法完成，不固定为{B}。G_p(y)=Σ_xp_x/(1+c_x(y))，待证
\[
M_{adm}=\min_{Q\ on\ D}\max_T E_Qins_T(y)\le W/m,
\]
有限minimax等价∀p min_(y∈D)G_p(y)≤W/m。旧全续局包络固定actual列且对其它格取MAX描述最坏实现，不能交换min/max得到此有利MIN候选。

表示本身已付：给每个经济主题L≥1+max|D_iA|个同覆盖标签，在actual非零信号孩子分别贴全部cap端点的旧完整尾SPE，尾按经济历史忽略信号；actual零标签续原路径。每actual节点偏离收益≤u_i，故全标签孩子可同时拼成一棵完整纯SPE。反向逐端点经济商和IC给任何保经济路径的信号SPE菜单都属于D。因此M_adm等于允许有限别名、有利保路径SPE的最小路径菜单值。固定p只需一个端点，双信号够逐p归约；一棵树同时装同格多个端点通常需足够多标签，不能把双信号混同全实现。

actual末位BR给ins_T(B)≤u_m。倒二位对p独立采样A,A′，同一前缀背景选每格cap合法末位BR，末两人去相关给E G_p≤E d_A≤u_(m−1)，故
\[
M_{adm}\le\min(u_{m-1},u_m)\quad(m\ge2).
\]
早期利润可更低，该式不推出W/m。递归替换更晚尾可能抬高先前强制者收益、破d_i≤u_i的祖先cap，晚节点IC不自动保留旧格合法性。
