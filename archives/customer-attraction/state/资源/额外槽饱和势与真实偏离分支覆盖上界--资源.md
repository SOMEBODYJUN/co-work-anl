# 纯额外槽静态计数成立

对恰m个竞争主题的多重集合B，b_x=c_x(B)，定义q_B(T)=Σ_(x∈T)1/(1+b_x)，

\[\theta_{m+1}=\min_{B\in\mathcal S^m}\max_{T\in\mathcal S}q_B(T).\]

下标m+1包括被报价的额外query，真实游戏仍m人。对任意比较元组T₁,…,T_m，重数d_x，逐客户有1_(d_x>0)≤(d_x+b_x)/(1+b_x)。求和且Σ_xb_x/(1+b_x)=Σ_jq_B(B_j)，得

\[OPT_m\le2m\max_Tq_B(T),\qquad OPT_m\le2m\theta_{m+1}.\]

这是既有静态计数，也由更强OPT_m≤2m v_(m+1)、v_(m+1)≤θ_(m+1)推出。v允许对m槽背景作混合，θ只取纯多重集；两者不能与限制于某节点真实终局列的Mfull直接认同。

原聚合候选W≥mθ_(m+1)若成立即给half；更强逐人u_i≥θ_(m+1)则已错误。完整Cartesian银行族m≥3有经济m个singleton与m−1个双客户银行，每主题配一经济和一银行。当前完整SPE的u₁=1+1/(m−1)、W=2m、OPT=3m−2。对任意m槽背景，有一个经济计数≤1、有一个银行计数≤1，全部配对合法给最大query≥1/2+2/2=3/2；取经济各一次、银行各至少一次（某银行两次）达到该值，故本族 **θ_(m+1)=3/2**。m≥4时u₁<θ；该族仍W=2m>mθ，故不否聚合。这个整数计数论证无需把分数/混合/纯背景值说成相等。

# 自由进入势有全局最大，但不生成指定SPE尾

给t>0，允许任意有限主题多重集合q，Φ_t(q)=Σ_xH_(c_x(q))−t|q|、H₀=0。若可覆盖客户数L、|q|=k，则Φ≤L H_k−tk→−∞，且每固定k只有有限多重集，故全局最大q*存在。空主题只减t，零客户也不破坏存在性。

向q*加一合法主题不能增势，给max_TΣ_T1/(1+c_x(q*))≤t；删一个已有主题不能增势，给该 occurrence当前收益≥t。这只是固定多重集的一槽插入/删除结论。若|q*|≤m，补任意主题至m槽只降query，于是θ_(m+1)≤t；其逆否θ>t⇒每个全局最大都超过m槽正确。不能倒推没有小局部饱和集，也不能把某个SPE尾等同Φ全局最大。

原未证步骤是由θ>t和完整策略树推出实际收益u_i≥t或聚合W≥mt。强制早期不同主题会重启多个后继，不是一槽potential变化；一般集合目录没有所需交换律。新增全局最大存在性没有付这笔动态差。

# 真实偏离分支的覆盖上界

固定同一完整σ、实际位置i，实际收益u_i>0。强制合法A，k=|A|>0，后继全部按原σ得到完整m槽分支z_i(A)，偏离者d_A=Σ_(x∈A)1/c_x(z)>0。IC给d_A≤u_i。令K=max主题大小。其他m−1主题的总incidence≤(m−1)K，在A内用了Σ_(x∈A)(c_x−1)，所以

\[W(z_i(A))\le2k+(m-1)K-\sum_{x\in A}c_x.\]

Cauchy给(Σc_x)(Σ1/c_x)≥k²，因第二项=d_A，得

\[W(z_i(A))\le2k+(m-1)K-k^2/d_A
\le2k+(m-1)K-k^2/u_i.\]

第二步因−k²/d随d递增。A空时另用W(z)≤(m−1)K，不写0/0。若u_i=0而有非空A，真实d_A≥|A|/m>0与IC矛盾，因此非零问题的u_i>0条件自然满足；零目录实例单独为0。过去主题仍在同一个完整分支中，计在m−1个其他主题，不漏掉固定前缀。

特别|A|=K时W(z_i(A))≤(m+1)K−K²/u_i。这是 **每个真实最大主题偏离分支的覆盖上界**，不是actual根W下界，未比较旧玩家跨分支收益；它不证明聚合theta或half。
