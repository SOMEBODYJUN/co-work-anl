# 被诊断的是哪一个数学对象

两份README都在2026-10-24研究一般人数、有限单位客户/共同目录、全部有序历史纯SPE的half，原时点未找到主目标反例。本页把它们的程序导航和原判断绑定到精确数学对象；不把一个辅助接口反例写成half反例。

固定完整σ、actual叶和负载c_x，C为actual并集、W=|C|，u_i为actual收益。真实强制查询d_i(T)从actual第i前缀改T后沿**同一σ全部改变后的后继**完成，故d_i(T)≤u_i。端点信用e_T=Σ_(x∈T)1/(1+c_x)，自信用g_i=Σ_(x∈S_i)1/[c_x(c_x+1)]，R₀=Σ_(x∈C)1/(1+c_x)=Σ_i g_i，J₀=W−R₀。比较m元组T_i并集U、O=|U|、比较负载k_x，S=Σ_i d_i(T_i)≤W。

逐客户1_(k>0)≤(c+k)/(1+c)，给O≤J₀+Σe_Ti。标准H4是：**∀实例与完整SPE，∃一个最优元组及一个共同排列**使Σ_i(e_Ti−d_i(T_i))≤R₀。它若成立给half，但不等于∀元组/排列、同query重复m次、逐行债务≤g_i。

# owner、重复信用与实际外部信用

把整个U分成Q_i⊆T_i，不只分遗漏客户；这些块不自动是合法主题。P_U=Σ_(x∈U)1/(1+c_x)不依赖owner，REP=Σ_(x∈U)(k_x−1)/(1+c_x)≥0，J_out=Σ_(x∈C\U)c_x/(1+c_x)≥0。有Σe=P_U+REP及精确J₀+P_U−O=J_out，于是对所选tuple/permutation：

|接口|恰需真实查询收益总和S达到|
|---|---|
|标准H4|O−W+J_out+REP|
|去重复owner端点、仍只用R₀|O−W+J_out|
|保全部精确松弛的净差匹配|O−W|

只换owner既不改变P_U也不改变REP总额，不能免费删除J_out。父方1588B写J_U=Σ_(x∈U)c_x/(1+c_x)，O=J_U+P_U，右预算W−J_U=R₀+J_out。因此Σ_i(p_i−d_i(T_i))≤W−J_U恰是最弱净差匹配，不是标准H4已获证明。详细蕴含已自足保在[IH端点边界](../资料/最优排列调和债与归属端点薄化的边界--资料.md)和[真实净差共同付款](../候选/真实最优组合的净差匹配与共同付款--候选.md)，不新造一个同义主定理。
