# 静态最坏分母是一种独立充分证书

在真实actual前缀i，未来包括当前至多r_i=m−i+1名覆盖客户，因此真实强制主题利润至少Σ_(x∈T)1/(b_i,x+r_i)。SPE给u_i不低于这个下界。它保合法，但可能把真实后继理性丢得过多。

2916B原稿允许λ_i,j≥0，要求逐客户

\[
\sum_{i,j}\lambda_{i,j}\left(\frac{q_{i,x}}{c_x}-\frac{1_{x\in T_j}}{b_{i,x}+r_i}\right)
\le2\,1_{c_x>0}-1_{x\in U}.
\tag{STATIC}
\]

原稿右侧印作“2,1”，这里明确解释成2乘覆盖指标，不改变其后推导的目标。左侧与客户重数内积是非负的静态IC组合，故STATIC若存在可证half。它不是保全部真实hat分母的动态锥；不可行也不证明真实游戏失败。

# 单点族上可行当且仅当m≤2H_m

原族有2m不同单位客户y₁…y_m、x₁…x_m，2m个共同singleton主题。actual槽S_i={y_i}，比较槽T_j={x_j}，两族不交，W=O=m。若需要完整SPE实现，任一历史选择尚未覆盖的singleton、actual历史优先选对应y_i即可：每步已有至多m−1客户使用而目录有2m个，未用主题利润1为上界；全部历史都可如此完成。这是对源同一singleton输入的知情解析补全，不是新游戏扫描或原代码验证。

对y_i，STATIC恰给Σ_jλ_i,j≤2。对x_j，actual前缀负载0，STATIC恰给Σ_iλ_i,j/r_i≥1。于是所有列求和得到

\[
m\le\sum_i\frac{\sum_j\lambda_{i,j}}{r_i}\le2\sum_{r=1}^m\frac1r=2H_m.
\tag{NEC}
\]

这个必要条件也充分：若m≤2H_m，对每个i,j取λ_i,j=1/H_m。每列加权和Σ_i1/(H_mr_i)=1，每行和m/H_m≤2，所以全部2m客户约束同时成立。由此精确可行当且仅当m≤2H_m；m1也含在内，不只原数值报的m2/3/4。

m4时2H₄=25/6>4，m5时2H₅=137/30<5；m−2H_m从5起严格递增（下一步增1−2/(m+1)>0），故对整数m≥1，恰m≤4可行、m≥5不可行。这个全参数解析构造/分离不依赖求解器容差、输入case数量或旧输出文件。

# 同序全可信L是另一候选

2406B原稿固定完整actual路径z及actual前缀h_i，定义强制A后跨**全部完整纯SPE续局**的当前最低收益L_i(A)：未来玩家须在全部有序历史可信，当前A已被强制，不要求它自身在这个受迫节点最佳。任何一次真实固定σ查询d_i(A)属于其可选域，故L_i(A)≤d_i(A)≤u_i(z)。原候选是

\[
\forall\text{达到OPT的有序}T=(T_1,\ldots,T_m),\quad
\sum_iL_i(T_i)\ge O-W.
\tag{ORDERED-L?}
\]

它要求每个最优有序tuple在相同位置配对都成立，比“存在一个optimaltuple/permutation的真实d净差匹配”强；各i的最低续局可来自互不相容的离轨树，不能把其未来收益视作一份actual钱包。产品全可信L非加也不自动反这个矩阵候选，见[产品全续局对象](../资料/全续局产品转移与全部最优元组攻击--资料.md)；真实d的存在净差另见[共同付款候选](../候选/真实最优组合的净差匹配与共同付款--候选.md)。

# fresh下界何时充分、何时不够

若X⊆A\C(h_i)，强制A后任何后继里每个x最多有r_i名覆盖者，故当前利润≥|X|/r_i。于是L_i(A)≥|A\C(h_i)|/r_i，而实际SPE的u_i≥同一下界。对遗漏M=U\C(z)，a_i=|M∩T_i|，仅可推出

\[
\sum_iL_i(T_i)\ge\sum_i\frac{a_i}{r_i},\qquad
W=\sum_iu_i\ge\sum_i\frac{\max_j a_j}{r_i}.
\]

m10、各a_i=1时两条右侧都H₁₀=7381/2520，合计7381/1260<10=|M|。这只是说明这两个粗界本身不足以推出所需遗漏/净差付款，不是提供一个具有这些实际参数的SPE反例。不能把纯数列a_i当已构造客户策略。
