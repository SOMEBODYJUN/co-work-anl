# 共同倒二独审的范围与输出版本

四源的原字节、指纹和本轮一次重放保存在[证据目录](../../tools/evidence/common-penultimate-independent-review-primary/)，逐源来源见`source-manifest.json`，精确比较结果见`verification.json`。

## 审查实际证明了什么

独立审查先从定义重建重复A前缀，发现仅用末位标量预算不足，再重建同一真实前缀下S/Z/V三族比较。其承担的义务包括：偏离T_i后仍使用原完整策略R_i；所有有序i≠j的交叉回复查询均合法；T_i重复时同一历史的R_i一致；零客户与空主题不产生零分母。对G=S+Z/(2m)+V/m逐客户重算后严格消去同索引交叠，按a=0,p=0、a=0,p>=1、a=1,p=m−2分支和双线性角点证明half。

这些机制已完整收入[菜单引理](../引理/真实末两人菜单交集消去--引理.md)与[共同包含定理](../定理/倒二主题共同包含半覆盖--定理.md)。独审记录了原发现阶段形式边界的3−m→2−m纠错；当前冻结主稿已使用2−m，不能继续说现主稿仍错。负形式余项只排除这套逐客户证书的无条件推广，不是SPE或half反例。

末节另给比较主题数k与总人数M分离的全参数角表：A内客户p>=k−2即得2W>=OPT_k；最优M覆盖另有至多k主题支撑时才得M人half。该独有解析内容现单独保全于[比较数负载阈值定理](../定理/比较主题数控制的倒二客户负载阈值--定理.md)。既有规范审计资源只记录28644次有限广义检查，未另立这一无限参数结论；本次归档补齐该数学去向，不把它称为新发现或外审。

历史旧JSON不能被倒填为曾检查k,p推广。当前冻结脚本包含该追加循环，运行它产生v2；没有保存旧代码版本，因而本次只比较旧JSON共有字段，没有编造或复跑一份不存在的旧程序。输出`general_target=OPEN`是其历史一般目标状态，未被有限通过改变。

本轮以普通Python实际运行冻结脚本一次，exit=0，输出与v2字节全同。复现（省略`--output`只打印；指定输出用独占创建）为：

```sh
python3 archives/customer-attraction/tools/evidence/common-penultimate-independent-review-primary/common_penultimate_audit.py
```

断言不能用`python -O`删除。程序与规范程序为同一实现，故本轮是同实现复放，不是新独立求解器。任意m或k,p结论分别由正式正文的解析证明承担；主目标的一般六人范围没有因此闭合。

关系语义是“内部解析审查”“同字节实现/输出版本”“公式有限检查”，不是有限计算推出普遍定理。数学证明与资源各保稳定身份，第三阶段据实际解释建边。
