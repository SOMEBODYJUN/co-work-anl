# 旧52客户独立程序究竟核验什么

[2078B原程序](../../tools/evidence/historical-root-replay-and-suffix-implementation-primary/original/audit_old_assignment_counterexample.py)只导stdlib：Path、product/permutations、Fraction、Counter、json/hashlib，不导作者求解器、收益模型或证书核验器。它按源文件所在原目录向上取`R-a0bb57fa24044a8794bc7991918a19c6/static_matching/static_matching_counterexample.json`。准确输入为32574B、SHA256 `9e7cf1437a7b03fe89d843d4ae20efa3c6a4137373098ed1220d4370656a5245`；原JSON的22个兴趣块展开为52个不同单位客户，而非给客户加权。

程序只消费`instance`与`certificate.actions`，不信任原JSON的welfare/optimum/all_assignments等结论字段。令z(h)沿该完整有序策略完成历史h，定义

\[
 \widehat u_i(z)=\sum_{x:z_i\in L_x}\frac{12}{\sum_j\mathbf1_{z_j\in L_x}},\qquad
 W(z)=\sum_x\mathbf1_{\exists j:z_j\in L_x}.
\]

代码用整数`12//load`。固定输入m=4时load∈{1,2,3,4}均整除12，所以恰为真实收益的12倍；不能把这种取整实现当任意m的通用有理核验器。源最后断言m=4等固定值，不证明换成负载5后的取整也正确。

对每层i=0,…,3，枚举全部h∈{0,…,5}^i和全部a∈{0,…,5}，核

\[
 \widehat u_i(z(h))\ge\widehat u_i(z(h,a)).
\]

这保真实改变前缀后的整条原策略回复，没有冻结后继，也没识别同计数不同顺序；259个节点、1554项含自身比较（1295非自身）。有限完美信息博弈的逐节点最优性因此认证**这一份**完整纯SPE，未枚举所有SPE。

另枚举6⁴=1296个有序终局求OPT并取全部最优支持，断言唯一支持{0,1,4,5}；对这四题的24排列T，核冻结替换总费

\[
 Q(T)=\sum_i u_i(B_1,\ldots,B_{i-1},T_i,B_{i+1},\ldots,B_4).
\]

这里有意冻结其它实际行动，**不是**改变前缀后继续σ的真实偏离。原程序最后断言52客户、m4、B=(3,3,2,2)、W47、OPT52、minQ48，且输出全部24值的频数。

[611B冻结输出](../../tools/evidence/historical-root-replay-and-suffix-implementation-primary/original/old_assignment_counterexample_replay.json)全部字段为scope/source_sha256/clients/ordered_nodes/IC_including_self/ordered_terminal_profiles/actual/payoffs/W/OPT/optimal_supports/static_cost_histogram/status。四利润均47/4，24值12个48、12个293/6；scope明确是旧FOMA-EXISTS反例独立重放，不是新游戏或half反例。

其反驳量词是“每实例每SPE存在某最优元组/匹配使Q≤W”：本例所有最优元组恰为0145排列，minQ48>47。唯一最优支持可直接由只喜欢1/4/5的客户和{0,2}/{0,3}两块推出；两价格类也由两个同3实际角色和两个同2角色的冻结查询表解析给出，详见完整反例正文。W47≥OPT/2=26，且较弱Q≤(1+1/4)W并未被它否定。

代码没有main guard，import即运行上述全循环并以exclusive-create模式写`old_assignment_counterexample_replay.json`，再打印compact JSON；原文件为pretty JSON，不能假称stdout与文件同字节。已有旧origin代码SHA23fa9300…绑定同输入9e7cf143…的成功执行，以及当前完整策略/唯一最优/24匹配的解析证明足承重；其代码与此2078B实现不同。这里保611B为这份独立实现的**历史原报告**，没有把旧origin的执行日志移接成2078B本次成功，也未另跑熟悉52输入。

# 后缀程序的逐客户cut和必要性

[3420B程序](../../tools/evidence/historical-root-replay-and-suffix-implementation-primary/original/attack_suffix_inventory.py)的唯一外部文件为`evidence/certificates/customer_attraction/root_tax_failure.json`。本地27707B原文件SHA256 `59fd58d85a3c3b989837467eb3523286d1f5ee529b0f119cd4d263bef6984111`已全部读，259个有序action使m4/k6、actual B=(0,0,0,5)。代码只读`strategy.actions`；security/expected中的61客户、u=(9,9,9,11)、W38/OPT61等字段**不进入LP**。

固定一个排列T为ABCD的24种分配之一。对每非空兴趣类型L⊆{0,…,5}，记a_i=1_(B_i∈L)、t_i=1_(T_i∈L)、b=Σa_i、t=Σt_i。若t>0，对每t_i=1定义

\[
 d_i=b+1-a_i\ge1,\quad p_i=1/t,\quad
 n_i=\sum_{j\ne i}a_j(1-t_j),\quad
 r_i=p_i-\frac{n_i}{td_i},\quad
 H_j=\sum_{i\ne j}\frac{t_i a_j(1-t_j)}{td_i}.
\]

r_i=0当t_i=0；最后H式只对t_i=1求和。d_i是冻结替换i后的覆盖负载；n_i计实际覆盖而其比较槽不覆盖的其它角色；H按**收款角色j**归集，不能按owner重命名。t0时r/H都0。单类型真实实际利润为u_j(L)=a_j/b（b0时0）。源`cut(T,start)`恰返回

\[
 c_{T,k}(L)=\sum_{i\ge k}r_i(L)+\sum_{j\ge k}H_j(L)
              -2\sum_{j\ge k}u_j(L).\tag{CUT}
\]

对每个t>0客户，Σ_j H_j=Σ_(i:t_i=1)n_i/(td_i)，而Σ_i r_i=1减同一总量，故Σ(r_i+H_i)=1；t0时该和0。这样CUT确是同一次初始化的后缀库存减后缀两份利润，没有凭空增钱。

代码零基start1/2/3对应一基suffix2/3/4；`len(result)`只选择当前兴趣类型的U列，不是另一角色。

必要性在同一次full-SAFE/合法CLIP初始化下成立：r_i=d_i^{cur}+b_i^{future}且owner i的future只能最终支付actual j≥i。对S_k后缀，其future不能流到后缀外，若共同剩余预算Aout≤2u−dcur−H，则

\[
 b^{future}(S_k)\le Aout(S_k)\le2u(S_k)-d^{cur}(S_k)-H(S_k),
\]

代回得r(S_k)+H(S_k)≤2u(S_k)。第一处是≤，因为更早owner还可向此后缀送款。CUT正值才是违反这个必要条件，不是half违反。k1恢复全局目标；末位端点由真实末位query与H各≤u_m已付。允许I-future直接付owner之前actual角色的别的图不满足原时间合同，须重算库存/余额，不能借本cut否定。

# 固定策略LP的真实量词、输出及停止点

变量w_L≥0覆盖全部63个非空兴趣类型，Σw=1。对固定259动作策略的所有非自身偏离建立1295条真实有序IC；每行是alt−on，约束row·w≤0。它没有强制ties严格，故保弱IC。全部126个无序四槽重复组合与T0=(0,1,2,3)的覆盖差给OPT行，要求T0达到最大，**没有要求唯一最优**。空兴趣类型不影响任何利润/覆盖，省去它不改变本分离问题。

客户质量归一是固定策略锥的齐次放松，不是直接列出一个新单位实例。若将来有满足所有精确行的有理正分离点，可清公分母展开成单位客户；此历史负报告未给这样的点或精确否定证书。零总质量未进Σw=1域，原模型零客户仍合法且cut为0；变量也不额外强制每主题非空或两主题不同。

对每个固定公共k=2,3,4分别求

\[
 \max_{w,z}z\quad\text{s.t. IC、OPT、}w\ge0,\ \sum_Lw_L=1,
 \quad c_{T,k}\cdot w\ge z\ \text{对全部24排列T}.\tag{LP_k}
\]

代码以SciPy/HiGHS浮点求解，三次w可不同。攻击量词是寻找“存在一个公共k、同一w使全部24排列在该k都坏”；若一般情形每个排列各在不同k坏，这三LP并未穷尽`∀T∃k`的联合条件。即便某w在这24排列全被排除，还须检查其它并列最优多重集，才能排除所有最优T。

每个返回w坐标由`Fraction(float(v)).limit_denominator(10**7)`有理化，重算1421条IC+OPT原行最小slack和24cuts最小值；输出不保存w、不核有理化Σw仍恰1、也不恢复精确对偶。因此这些负数仅是历史数值未分离及返回点检查，不能当精确锥最优上界或“该策略所有w都通过”的证明，更不证一般cut/ROLE/half。
