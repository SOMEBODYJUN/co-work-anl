# 给定合法前缀之后的首两人，不是任意两位置

5227B整码和6439B整报告是两个主来源；源所有数组已读，原字节在[四源证据](../../tools/evidence/two-player-iid-and-actual-pair-security-probes-primary/README.md)。另两主件[两人iid面探针](两人安全最优查询面的有限同分布覆盖探针--资源.md)测试不同P目标，不能拿其统计补本报告。这里给原全整数菜单的完整数学合同，严格分开精确组合层、浮点静态LP和原有限扫描；没有本次原程序、求解器或新数学实现运行。

采用[原有限单位客户共同目录模型](../定义/共同目录完整历史模型--定义.md)，有限非空共同目录、单位提供者，观察全部有序历史，保空/重复/零客户/任意离轨平局。软件用p个带标签主题；非空兴趣类型S⊆{0,…,p−1}的非负整数重数w_S表示不同单位客户。它允许两个标签相同覆盖，属软件扩展；原集合目录中同覆盖主题只能算一个，不能默许任意记录均有p个不同真实集合。

输入(p,r,k)，k∈ℤ₊ᵖ是**此前**行动计数，余r≥2人，总m=r+|k|。这些k可由相应主题的合法有序历史形成，单位客户过去负载为b_S=Σ_{a∈S}k_a。算法只求给定前缀后的子SPE，不保存祖先策略和激励；“可补齐离轨子局”为完整根策略不等于该前缀在根SPE实际到达。相同计数的前史诱导同构余局，但完整策略仍允许各有序历史独立破平局。

此源最小化余局**第1、第2位**实际收益之和s，不对一般不同i,j循环。比较值为

\[
v_r(k;w)=\max_{\pi\in\Delta_p}\min_{y\in\mathbb Z_+^p,\ |y|=r-1}
 \sum_a\pi_a\sum_{S\ni a}\frac{w_S}{1+\sum_{b\in S}(k_b+y_b)}.\tag{1}
\]

对方静态元组可重复/相关，观察π但不观察本次查询；计数枚举等同所有有序竞争元组，因为这里只通过负载进入收益。它不同于不允许重复、分数背景或真实回复菜单的安全值，也不是θ的min-max。得分score=s/(2v_r)用浮点v；v=0时代码设inf不除零。零客户时此约定不形成一个效率结论。

[全位置候选](../候选/全位置成对安全值候选与有限锥判别范围--候选.md)要求原零根完整SPE的每对不同实际位置uᵢ+uⱼ≥2v_m(0)，其真v和位置范围不能被本首两人子局扫描代替。任意合法背景首对2v则已被[PB-extra全反例](../反例/任意合法背景的前两人额外槽安全值--反例.md)排除；本有限小样本ratio未低于1不恢复该全称为OPEN。PB原精确背景的actual不可达另有[审查](../审查/实际前缀的关联预算与PB背景可达性复核--审查.md)，不能把合法沉没输入自动视为在轨。

# 全整数收益表和可实现终局集合

令L=lcm(1,…,m)，𝒟_d={z∈ℤ₊ᵖ:|z|=d}。终局列表q=k+z，z∈𝒟_r。对在q中实际有人选择的标签a，L倍收益

\[
\operatorname{pay}(q,a)=\sum_{S\ni a}w_S\frac{L}{\sum_{b\in S}q_b}.\tag{2}
\]

分母介于1与m，L整除其所有可能值；无除零、无舍入。实现`forms[q,a,S]`只在q_a>0且a∈S时填L//负载，其余为0；后面每个被比较a都确在相应终局中。`forms@w`使用np.int64而非任意精度，因此必须限定整数范围。本原六配置m≤6、L≤60、p≤6、D≤63、w≤100，单项收益总和≤60·63·100=378000，两个收益之和也远小于int64上限；对这组生成规则可据界排除溢出，不能推广任意输入同样安全。

用新增行动计数z缓存余局的全部可实现终局**索引集合**R_z。终局|z|=r时R_z={对应k+z的索引}。递推

\[
H_z=\max_a\min_{i\in R_{z+e_a}}\operatorname{pay}(q_i,a),
\qquad
R_z=\bigcup_a\{i\in R_{z+e_a}:\operatorname{pay}(q_i,a)\ge H_z\}.\tag{3}
\]

这是[完整历史终局全集算法](../算法/完整历史纯SPE终局全集--算法.md)在固定背景的准确版本，threshold[z]存H_z。必要性：任一当前SPE收益至少每个离轨孩子全部子SPE收益的最小值；充分性：选中孩子实现目标终局，其他孩子各用达到最小值的子SPE，其有序后代互不相交，故当前行动最优。对子局层数归纳给全部可实现终局且非空，平局/零收益保留。

**缓存集合不把策略Markov化。** 同计数有序历史共享可实现集合，展开每份完整策略时可分别选择不同集合成员，特别是不同离轨惩罚。该程序不输出完整树或枚举每份策略；若需具体证书，可沿[可信续局菜单](../算法/可信续局菜单与完整策略重构--算法.md)逐有序历史展开并定义级核验，不能把一份终局计数称作已存全策略。

# 同一份完整SPE的首两动作如何锁定

穷举所有有序a,b，包括a=b。置e=e_a、e′=e_a+e_b，遍历

\[
i\in R_0\cap R_e\cap R_{e'},\quad
\operatorname{pay}(q_i,a)\ge H_0,\quad
\operatorname{pay}(q_i,b)\ge H_e.\tag{4}
\]

这些条件对“存在一份完整子SPE以a,b开头并到q_i”为必要充分。必要性是该策略沿真实前两孩子的子SPE限制和各层激励。充分性先在二行动孩子实现q_i；第二层选b，其他孩子最小收益惩罚使其合法；再根选a、其他孩子同样拼惩罚，恰保前两行动。因此(4)没有把两个不同SPE的首人/次人分别挑出再相加，也不需要把相同计数历史合成同动作。

在所有(4)中以整数组合`(pay(q_i,a)+pay(q_i,b),a,b,i)`取字典序最小。首项给所有完整子SPE首对收益的真实最小值s；其余只在同值时确定存哪组标签和终局索引。报告中的first_two_actions有序，terminal只是总终局**计数**（包含k），不是完整有序尾行动或全策略。程序`assert best is not None`由(3)非空和可沿根选合法行动的性质支持。

这个首对全集性不同于固定形式策略锥中只抽一个默认证书。另一个1.69MB pair_security_cone_probe_report资源未在本批读取、认领或认证；不能从名字借来该锥扫描的范围/运行。

# 静态LP与数值停止层

对每个y∈𝒟_(r−1)及查询a，代码查终局q=k+y+e_a的pay(q,a)/L，形成精确静态收益矩阵再转float。查询LP为

\[
\max_{\pi\ge0,\sum\pi=1,v\ge0}v,
\quad v\le\sum_a\pi_af_{k+y}(a)\quad\forall y.\tag{5}
\]

分母查询自己带+1，r−1竞争槽没有漏掉固定k。v≥0不改变非负收益游戏的最优值。代码assert LP success才取v和π；没有精确原始/对偶证书、rational恢复或独立矩阵复算。整数全集菜单能保证s层在输入界内精确，不能因此把score或v_float也称精确值。

原main有guard；导入只定义类/函数，无本地项目模块依赖。CLI默认--iterations4000、--seed831014、--output pair_security_probe_report.json；输出路径相对源码目录。一个random.Random在所有六配置顺序共用。每配置it从0开始：每逢it%5=0重新独立从[0,0,0,1,1,2,3,5,8,13,21]逐列抽w；其它it若已有finite最佳记录，则从**该最佳点**复制w，随机1…4次选择坐标加{−8,−3,−1,1,3,8}并截在[0,100]。若尚无best则也重新抽，不默许每组恰有1200次有效突变或所有样本互异。

score改善超过1e−11才替换本配置best；score<1−1e−8打印CANDIDATE并只break当前配置内循环，后续配置仍继续。每配置完成后覆output一遍，最后stdout只打印elapsed和best_ratios。保存的每项best可能是带改进阈值的保留值，并非全部浮点score的字面最小。原报告每配置只有iterations和best，不存全部1500输入、阈值R表、完整σ、每次LP日志或对偶。

# 可复用的结论和仍未支付的量词

此源保留两项精确算法内容：(3)的全历史可实现终局集合，以及(4)的指定首两动作同策略兼容判据。它们可用于有限输入产生真正首对最小值，若将来得到严格候选仍应输出完整有序策略、定义级核IC、精确恢复静态安全上下证书并核全部单位客户；目前报告的float未产生候选，不能从9000条阴性推出普遍pair。

[末两人定理](../定理/末两人逐人保底与全人数弱福利界--定理.md)已在任意合法前缀保末两各自≥θ≥v；本六配置余3…5人，首两不等末两。当前[五人half](../定理/五人半覆盖--定理.md)与三人已知福利界也不反推全部pair或r背景2v。已否的全合法背景PB、尚须自身论证的实际前缀专用版本、零根全位置pair及half分别保量词。

本资源与[两覆盖/成对工作区](两覆盖结构与成对安全工作区的准确接续--资源.md)里5375B背景策略锥探针不同：后者先随机固定一份完整形式策略再交替重权，本文对每个整数输入的全部SPE可实现终局作集合递推；不把两个浮点阴性表互相升级为执行或精确上界。与固定ΣCᵢ查询预算、首对iid P₂、SSR、θ逐人反例也不混同。阶段二已实读判断关系，第三阶段超图未预建；没有原扫描重演、外审、blind或新颖性认证。
