# 正占用核旧目录的逐项用途

这是正占用核的函数、锥、闭包、秩及禁支撑质量资源索引。其非负表示工具可独立于博弈使用；目录角色和与拥塞的启发不构成一般均衡桥。

本页处置原目录的 9 条记录，不处置这些路径所指源文件的全部数学。记录编号是原 JSON 的零起始 `entries[index]`。完整字段原文、字段是否存在、原路径及两种关联键见[逐项绑定数据](../../../../tools/evidence/catalog-semantic-resources/catalog-semantic-records.json)；[总合同与当前校正](旧研究总目录的字段语义与版本边界--资源.md)解释版本、字节和证据层级。

## 角色解释

| 原 role | 原 Markdown 角色含义 |
| --- | --- |
| `navigation` | 阅读导航；真值查精确正文及账本 |
| `representation` | 表示或证书接口；不自动给出待求系数 |
| `review` | 实际审查记录；只覆盖所列版本与义务 |
| `audit_code` | 有限计算核验；不代替一般证明 |
| `frozen_evidence` | 冻结输入、证书或结果；不原位覆盖 |
| `source` | 来源或历史判断；不作为现行结论 |
