# 合法背景嵌入与完整成块归约

每个合法主题A和k≥2都有
\[
 v_{k-1}(b+\mathbf1_A)\ge v_k(b).\tag{EMBED}
\]
对固定p，左边只在静态竞争者的一个槽固定为A后优化余k−2槽，属于右边原k−1槽对手域的子集，故最小值不减；再max_p保持。它用同一共同目录和同一query独立性，不调用SPE。

若PB-extra普遍成立，固定某根m人原SPE，令s=v_(m+1)(0)。沿其**同一actual路径**依次按(1,2),(3,4),…分组。在每个pair之前的合法背景b、余r，由(EMBED)沿已有前缀迭代得v_(r+1)(b)≥s，所以该两位原最终利润和≥2s。m奇数时最后一位的真实BR收益v1(b)≥v2(b)≥s；m1也同理。于是条件上W≥m v_(m+1)(0)。强前提同样给W≥m v_m(0)。这些是有效蕴含，没有重新选择子SPE或各对各用不同实际叶。

静态共同目录账给OPT_m≤2m v_(m+1)(0)：对任意静态m槽分布Q，L=E_Q c(D)是m份合法主题分数负载，令g(T)=Σ_T1/(1+L)、M=max_Tg(T)。逐客户1_(d_x>0)≤(d_x+L_x)/(1+L_x)使任意最优m主题覆盖≤mM+Σ_xL_x/(1+L_x)≤2mM；倒数Jensen给M≤max_T E_Q查询价。取min_Q并用有限minimax，得该预算。因此PB-extra若真则half；假前提的条件归约仍准确，但不是正面证明。强前提可再用v_m≥v_(m+1)给相同half推论。

沿一份实际路径的成块证明事实上只使用那些pair节点的前提；放宽到实际路径专用合同须另给全称定义与证明，不能拿一般背景PB失败自动否定，或反过来当它已经成立。恰余2人时已有真实末两人保底θ2(b)≥v2(b)≥v3(b)，所以两原首对式均成立；失败只可能更早。

# 可信首利双阈值只是更强充分义务

对某h,b,r，强制当前T后允许所有完整孩子SPE终局，记其集合R(h,T)，
\[
 \ell_T(h)=\min_{z\in R(h,T)}u_{current}(z),\qquad
 M_r(h)=\max_T\ell_T(h).
\]
各有序孩子可独立取当前收益最坏的完整子SPE，再让根取最大，故M恰为无祖先终局承诺的最低可实现SPE首利。原指定策略可以依全部有序历史；若按计数缓存，必须保全部可信终局而不是固定一个匿名selector。

任一完整SPE实际首动A满足a1≥M_r(h)、a2≥M_(r−1)(h,A)。所以
\[
 M_r(h)+M_{r-1}(h,A)\ge2v_{r+1}(b)\tag{TH?}
\]
对所有可实现首动A成立，会足够PB-extra；要求所有合法A又更强。两个最小值未必能在同一个实际终局共同达到，因此TH分离不能自动反PB。第二位在原(h,A)真正复制A后，旧根与复制者同枝同主题等利，但只能把其偏离收益下界转为第二位原利润下界；不能把**复制枝**旧根利润替成**原枝**a1。这是首对付款未闭的真实跨枝点。

# 最小坏人数确实给出的proper-history信用

在所有合法背景输入中选PB-extra失败的最小剩余人数r，令t=v_(r+1)(b)>0。每个根真实偏离分支和每个更深proper有序历史至少余2人时，由最小性该子局首对满足自身PB，再由(EMBED)至少为2t；最后一人≥t，末两人各自也≥t。故每个真根分支的后继总利润≥(r−1)t。

这仍不意味着每名后继≥t。写q_j=u_j−t，只得
\[
 q_j+q_{j+1}\ge0\ (2\le j<r),\qquad q_{r-1},q_r\ge0,
\]
实际坏点则q1+q2<0。四维数列(−2,−1,3,0)已满足这些标量约束而首对负；它只是信息不足的数值例，**不是SPE或PB证书**。需另用跨主题完整IC才能支付首对欠债；不能把proper配对预算升级成逐人保底。
