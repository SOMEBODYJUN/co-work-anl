# 三份原件和旧推论的准确数学身份

4317B root_envelope、1759B六人根入口、1371B新表示入口共7447B全文实读。前者明确承认来自已有 AP/BNS 的显式根推论，不认领数学新颖性；后两者是版本导航，不自动认证所有被链程序或内部审查。本批保全其独有比较槽量词、另一完整短证、旧587点诊断和DIRECT后来反驳，不重造既有更强交换定理。

固定[原共同目录完整历史纯SPE](../定义/共同目录完整历史模型--定义.md)，总人数 m>=3，实际首位收益 r，最大主题大小 K。比较槽数 s 是**任意正整数**，不改变实际人数 m。原稿给

\[
H=(m-1)^2r-(m-2)K,\qquad OPT_s\le sH+(m-1)K/m.
\]

这里 OPT_s 允许合法主题重复；s不必等于m，不能把比较槽重新解释成游戏人口。零客户不除K、r或W。

# 原源独立短证的全部付款步骤

在原根强制最大主题 M，沿同一完整策略得(M,F2,...,Fm)。根在该分支收益 v<=r；只调用原根IC，不把被强制者当分支优化者。令 D_j=|M\F_j|、E_j=|F_j\M|，D=sum_{j>=2}D_j、d=D_m。共同目录最大性给E_j<=D_j。对M客户终局负载q，

\[
D=\sum_M(m-q)\le m(m-1)(v-K/m)\le m(m-1)(r-K/m).
\]

这是整数q=1,...,m的逐项关系，q=m时零项，不把它外推到任意实负载。真实末位主题L在M内份额最多v-d/(m-1)，M外最多E_m<=d，所以末位收益e<=v+(m-2)d/(m-1)。末位之前M外总负载至多D-d。

末位可查询任意原目录Q；对外部整数负载a用1/(a+1)>=1-a/2，对M内部只用分母<=m，得到

\[
|Q\setminus M|+|Q\cap M|/m
\le v+D/2+\frac{m-3}{2(m-1)}d
\le v+\frac{m-2}{m-1}D\le H.
\]

第二步要求m>=3与0<=d<=D。整个目录共同受同一真实分支约束，未对每个Q另选一份方便后继。对s个比较主题求和，设并集内/外于M的客户数为I/J，得到J+I/m<=sH；只用一次I<=K的内部信用，故OPT_s<=sH+(m-1)K/m。不能误将该信用也乘s。

# 与当前更强全玩家交换界的精确关系

[任意实际玩家的最大主题倒二交换引理](../引理/最大主题倒二保底交换的任意实际玩家界与锐投影--引理.md)已给，对任一实际玩家i及任意Q，

\[
m|Q\setminus M|+|Q\cap M|\le K+c_m(mu_i-K),
\quad c_m=(m-1)^2-\frac{m^2(m-3)^2}{2(3m^2-7m+2)}.
\]

取i=1，令H_new=K/m+c_m(r-K/m)，则可同样对**任意s**推出OPT_s<=sH_new+(m-1)K/m。由于r>=K/m，c_m<=(m-1)^2，这包含旧包络；m3系数相同，m>=4系数严格改善，但若r=K/m数值仍可同线。新证明保更多真实末两人比较，不能因旧根推论同线就把不同乘子/客户交叠余项判为相同。

取s=m，旧式等价OPT_m<=(2-1/m)K+(m-1)^2(mr-K)，m6为OPT6<=150r-139K/6。原稿称它排除旧587行点：r=K/6、O1、K=4782519/24475573。这里只按原明列标量理解其饱和矛盾，原587点/完整约束数据不在本批实读范围；没有因三数代入就认证那点的全部行、原始/对偶或SPE实现。饱和时mr-K=0，任何该真实游戏必须O<=(11/6)K，而原数违反；问题是旧必要系统遗漏共同真实最大分支，不是主模型已有反例。

# 六人入口和DIRECT旧OPEN的后来状态

1759B入口把根包络、原实际首主题后的背景lift、同源query闭包、六人精确诊断和一般机制分开；它明确否定把五人零背景定理直接套到五尾、否定把旧44/60不可读整包补写成已复跑。本批同样只保导航和原声明，不新增那些代码/JSON实读或运行。五人已证、六人仍缺付款的身份不互相覆盖。

1371B新表示入口把DIRECT-v0与PREFIX-DIRECT-v0区分：前者只空根每份完整SPE的逐人OPT_m/(2m)门槛，后者扩到所有合法旧前缀、门槛仍按原总m/OPT_m。PREFIX=>DIRECT，最小剩余人数归约只对更强量词合法，未证明两者等价。它所导航三窗口环不是完整SPE、末位真实BR失败，所以这个环自己不否定DIRECT。

但入口“两项均OPEN”已是旧时点。[已整理的准确版本资源](DIRECT与前缀门槛的历史量词和后来反驳--资源.md)给真正银行完整SPE族：u1=m/(m-1)、W2m、OPT3m-2，m>=5时OPT/(2m)>u1。因此DIRECT一般全称已假，包含空前缀的PREFIX也假。它们仍只是half的充分加强，不因失败推原half假。原三窗口的“本例未反驳”与后来的银行真反驳完全相容；不得把后者功劳或真实数据倒填给前者。

同资源还分清m>=4的extra-slot和Mfull已被另外精确范围否定，真正安全聚合未由此族否定。根入口旧数值改善、内部独立推导、过去未保存远端文件都不变成新的数学认证。
