# 旧命题登记的不相关机全部陈述

本登记中的 UM 主目标量化全部普通非负有理处理时间矩阵，包括零端、∞和无有限端任务的分支处理，并要求统一 ε 与确定性总位多项式实际调度。已知有序槽 ST 是一般二倍地基；CONFIG、弱 coalition、固定行/槽、C2/K2/SH3 层级的阈值趋二障碍不等于相对真实 OPT 的算法不可能。

受限结构如共同资格私有组、固定大宏占位、有限 sink、共同尺寸/倍率、树/仙人掌/反馈秩、小支撑或 XOS 显式菜单各有精确附加域。给定矩、给定真实两份 σ、给定 T、原身份保持、逐机共同容量和未知 OPT 搜索不能省略。有限 backend 检查不认证完整 all-input 软件。NP-hard 的见证选择或源 SC/PCSP 事实需要实际物理 compiler、全部低负载 σ decoder 及固定参数规模，不能直接否定主目标；SCHA/P≠NP 等假设仍作为条件。完整源文也保留撤回的 sharpness/能垒/高低 γ 解释及其修复身份，不把旧摘要升级。

这些是冻结登记的完整原陈述与来源定位，属于资源对象而非本批新证明。原 source 相对链接只在原 current/claims.md 目录解释；下面用原文块保留，避免把历史链接改绑到新资源目录。公式、所有非表格正文、候选和逻辑规则不因计数去重而删除。现行纠错和实际比较见[总合同](旧命题登记与研究超图的范围和版本合同--资源.md)。
