# 设施审查旧目录的逐项用途

这是设施模型的旧审查文件用途索引。独立性、审查版本、实际输入与已执行范围要回到审查原件，不由目录role=review授予全稿或外审认证。

本页处置原目录的 5 条记录，不处置这些路径所指源文件的全部数学。记录编号是原 JSON 的零起始 `entries[index]`。完整字段原文、字段是否存在、原路径及两种关联键见[逐项绑定数据](../../../../tools/evidence/catalog-semantic-resources/catalog-semantic-records.json)；[总合同与当前校正](旧研究总目录的字段语义与版本边界--资源.md)解释版本、字节和证据层级。
