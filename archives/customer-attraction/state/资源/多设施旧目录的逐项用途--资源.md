# 多设施旧目录的逐项用途

这是任意设施数、连续/整数cap、冻结超载、盒构造及复杂度的旧用途索引。子集Nash化保持极大不增/极小不减的独立RANGE引理，并不交付一般逐坐标盒求解器或canonical实现；候选与原OPEN范围保留。

本页处置原目录的 42 条记录，不处置这些路径所指源文件的全部数学。记录编号是原 JSON 的零起始 `entries[index]`。完整字段原文、字段是否存在、原路径及两种关联键见[逐项绑定数据](../../../../tools/evidence/catalog-semantic-resources/catalog-semantic-records.json)；[总合同与当前校正](旧研究总目录的字段语义与版本边界--资源.md)解释版本、字节和证据层级。
