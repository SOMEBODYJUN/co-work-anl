# 原候选与现在的准确状态

在[共同目录完整历史模型](../定义/共同目录完整历史模型--定义.md)中，固定原总人数m≥1、有限单位客户/单位提供者、有限非空共同目录。每个合法有序历史h保留原过去负载，剩余玩家完整纯SPE可在全部离轨历史指定任意最佳回复平局。原稿IND-HALF是：在每个合法历史、每份完整子SPE，每名剩余玩家的最终利润都至少t=OPT_m/(2m)，OPT_m始终是**原m槽目录覆盖**，不是删除祖先后的OPT_r。

6405B草稿于2026-10-24把该逐人桥列为未否，解释安全值/MIN-PI反例并不逻辑推出它失败。这个历史推理正确，但候选当前已被[笛卡尔银行完整SPE反族](../反例/笛卡尔银行目录的逐人分数门槛反族--反例.md)否定：每m≥5，零根有u₁=1+1/(m−1)、OPT_m=3m−2，且OPT_m−2mu₁=(m²−5m+2)/(m−1)>0。m5即u₁5/4<13/10，差1/20。该真SPE反族仍有W2m、2W−OPT=m+2>0，**逐人floor失败不等于half失败**。

原三人X/Y单策略锥未分离不构成正面证据；本批不运行那份旧程序、不扩大锥扫描、不恢复旧OPEN。原稿所说“没有成熟新可靠正面组件/没有新反例/未申请新独审”保其作者时点，下面的价值是必要归约与一个明确非可信摘要排错，不另认领一般方法不可能性。

# 最小剩余人数的坏点只给ORDER

若在一个固定原实例内存在IND-HALF坏点，固定同一m、OPT_m和t，在该实例全部合法历史及全部完整子SPE中取剩余人数r最小的坏点。有限目录、人数及有序纯策略集合均有限，最小r存在。失败者可取当前首位：若在严格未来，其真实子历史就是更小r的坏点。

对于该给定原σ、任意合法强制当前行动a，令Z(a)是真实改变history后沿同σ的完整叶。当前节点完整IC给d(a)≤u<t；该分支每名严格后继位于更少剩余人数的合法子局，最小性给其真实最终利润各≥t。因此

\[
 \text{每个根行动分支：当前d(a)<t，全部严格未来利润各≥t。}
\tag{ORDER}
\]

祖先不删除、t不随r改变，不能把这条归约改成新r人零背景游戏。r1不可能坏：令b为原m−1个合法过去槽，末位最佳回复M=max_A Σ_(x∈A)1/(1+b_x)。任一最优m槽的覆盖逐客户≤(a_x+b_x)/(1+b_x)，右边恰由m个比较槽及m−1个过去槽的查询价相加，均≤M，故OPT_m≤(2m−1)M。由此M≥OPT_m/(2m−1)≥t。[合法前缀静态门槛](../引理/合法前缀的最小调和最优增量静态门槛--引理.md)含同一一般插入证明。空客户、重复槽和m1均无零分母问题。

最小性使用的是**真正完整SPE**的全部孩子，不是任意给定回复表。ORDER丢失了这些孩子相对其它合法行动的全部IC，不能独自封闭归纳。

# 完全二分边目录给精确门槛处的摘要排错

对每个整数d≥4，取K_(d,d)的左右各d个顶点作为2d名单位客户，目录为所有跨侧边的两个端点集合，共d²个合法主题。真实人数m=2d−1。固定任意根边(u,v)，回复菜单让后2d−2位各选择一次与根边相邻、又不同于根边的全部2d−2条边，任意固定排列。每个根行动都用同样定义的菜单。

这是合法终局响应表，未声称给出可信完整策略。其精确数值为：根两个端点各被d位覆盖，所以根利润2/d；每个尾部邻边在根端点分1/d，自己的外端点只自己覆盖，利润1+1/d。取d条完美匹配边覆盖全部2d名客户，再重复补足m槽，所以OPT_m=2d。原半阈值恰t=d/(2d−1)。

对d≥4，d²−4d+2>0（d4时2，随后递增），故

\[
 2/d<d/(2d-1)=t<1<1+1/d.
\]

所有根分支都给同样根收益，因此**全部根行动比较成立**；每个分支所有尾部都严格过该精确t。这确实满足ORDER，而非把阈值另调低的弱toy。

但是最后一位的规定边连接一个根端点和外端点w。它行动之前w尚未覆盖；取与w在对侧且不是根端点的任一外顶点z，z的唯一邻根边已被前一位尾部玩家选过，负载恰1。目录合法边(w,z)使末位偏离得1+1/2=3/2，严格大于原1+1/d。它没有后继可用威胁改变这个值。因此该菜单不是SPE，也不属于最小坏点归约所要求的输入。

这证明“全部根IC+全部根列的尾部逐人高于原t”不能替代真实孩子IC；没有证明不存在真坏点，也不构成IND-HALF或half反例。该特定摘要已停止，无需继续扩造同形响应菜单。与[重复惩罚末位外选项障碍](重复惩罚的末位外选项与无背景移植--障碍.md)都暴露末位收益，但目录/参数不同，不是同一个游戏。

# 工作稿其余动态接口的停界

原§1固定同一最优T/owner、actual前缀query、Hall-A裸取消域Γ₀，不保局部δ和SOURCE-NET；每world可共同选路径与取消，目标只总期望费用V₀≤W，不要求逐人NET。对阈值U_owner，令B(i,a;x,U)为该真实叶的future coverer中U_j>U_owner者。若B空，终端价r(i,a)=u_i/D_i(a)；否则逆角色取

\[
 v(i,a;x,U)=\min_{j\in B,\,b\ni x}v(j,b;x,U).
\]

source仍固定(owner,T_owner)，非owner可任意合法含x重查，不能事后换source。严格角色增加及终点阈值排序支持每state边际，整条IC仍在无条件期望后只乘一个确定常数。这与[较宽自由重查终端定理](../定理/共同优先级下自由合法重查的终端吸收界--定理.md)同域，已存在的合法性不重新造为本源新成果。

高价终点token的激活后继可达域必须封闭于所有可选便宜终端，否则逆推min会走掉；但图的这种封闭没有合并不同客户在同query的广播项，也没给W的共同预算。进一步放弃rank或重排最低价/取消域仍只是另一个充分付款放宽，本源明示不以此改名作为新推进。

原§3还拒绝用净调和势静态增量推出根低不可能：MIN-PI已被[15748单位客户真SPE](../反例/有限凹窗口的最小调和势增量保底反例--反例.md)否定；该例没有击穿OPT/(2m)只是事实，不保证较弱桥真。现在银行族另行击穿后者，不撤销合法前缀静态插入界。真正共同资金仍须全部孩子IC的新关系，不能只用ORDER、高价可达集封闭或现有恒等式。
