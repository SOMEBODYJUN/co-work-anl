# 精确保留激励数值的折叠与末层方向边界

本对象使用[固定人数覆盖矩表示](../定理/固定人数完整策略的覆盖矩表示--定理.md)。两个障碍的对象不同：第一份策略是合法完整SPE，但没有低效率；第二份策略只有末层最优，明确不是SPE。二者均不反驳六人half。

## 1. CR-4：OPT外客户的精确数值折叠失败

对每个 \(m\ge2,p\ge m+1\)，取 \(p\) 名单位客户与 \(p\) 个互不相交的单客户主题，类型 \(w_{\{a\}}=1\)。完整策略在每个长度小于 \(m\) 的有序历史选最小尚未出现标签。由于已出现标签少于 \(m<p\)，处处有新标签，包括重复偏离后的历史。

当前选新标签得1，后续只选尚未出现标签；改选其他新标签仍得1，改选旧标签至少与一名前人分享、至多得 \(1/2\)。故全部有序历史上最优，确为完整纯SPE。根路径 \((1,\ldots,m)\)，\(W=\operatorname{OPT}_m=m\)。

假设任意新非负客户资料 \(w'\) 保持这份同标签完整策略的全部真实比较**数值**和根 \(W\)。由表示定理，它保持全部单/双主题矩：

\[
C'(a)=1,\quad C'(ab)=2,\quad
C'(a)+C'(b)-C'(ab)=\sum_{B\supseteq\{a,b\}}w'_B=0.
\]

非负性使每个含两个标签的类型质量为零，各单点再由 \(C'(a)=1\) 唯一固定。因此任意选定的最优 \(m\) 标签组合外，仍有 \(p-m\) 个单位客户；允许改变客户身份、总数及任意非负重分配也不能将其消掉。空兴趣客户自由添加无济于事。

这不是仅针对删客户操作的障碍。其承重合同是“保持全部比较行数值及W”，而非“同一策略仍为SPE、W与OPT不变”。

## 2. 更弱不等式合同可以折叠

在同一例中，用 \(m\) 名全兴趣客户替代原全部 \(p\) 客户，每个主题都覆盖这 \(m\) 人。任何完整策略的每位收益都是 \(m/m=1\)，全部比较变零；原策略仍为SPE，\(W=\operatorname{OPT}_m=m\)，OPT外客户消失。

当前允许同覆盖异标签，故该折叠直接合法。若额外要求恰 \(p\) 个不同覆盖集合，折叠先产生重复标签，须商掉后才满足该额外模型，不能称其保持原不同目录。旧源在此强调distinctness，是额外边界，不应混入本次原模型。

当 \(m=1\)，全部大小为1的互不交主题亦可折成一名全兴趣客户，保留所有一人终局数值；双主题矩不在一人表示空间，所以第一节的唯一性证明确实不能扩到 \(m=1\)。

## 3. CR-6：全部末层激励仍不够

对每个 \(m\ge2\)，取标签0的空主题及标签 \(1,\ldots,m\) 各覆盖一名不同单位客户。定义完整形式策略：前 \(m-1\) 位在每个历史都选0；末位选最小尚未出现的非空标签。

每个末层历史长度 \(m-1\)，至少一个非空标签未出现。末位指定收益1，改选其他新标签得1、旧标签至多 \(1/2\)、0得0。因此**所有**末层真实比较非负。

根路径 \((0,\ldots,0,1)\)，所以

\[
W=1,\qquad\operatorname{OPT}_m=m.
\]

任一早期玩家却可改选非空标签，之后的早期玩家仍选0，末位选另一个新标签，使偏离者获得1，超过原收益0。故这份形式策略不是SPE。\(m\ge3\) 时 \(2W<m\)，仅说明“末层最优”这一放松不能保证half；\(m=2\) 也非SPE，但福利恰为half。

表示定理仍对它给 \(\operatorname{span}\Gamma^{last}=\operatorname{span}\Gamma\)。反例由此精确区分“有符号线性span相同”与“非负比较锥足以替代”：早期方向不可因span等式删除。这里使用空主题，正合原模型允许的边界，不应在清洗中删去。

## 4. 证据与接续

源正式稿和工作稿均包含CR-6；独立审查逐项证明CR-1至CR-5，不把其独审认证范围倒填到CR-6。CR-6在本轮按上述完整策略直接重构，原代码另检 \(m=2,3,4\)。原不交SPE检查 \(m=1,\ldots,4,p=m+1\)，完整比较计数及精确残差见[计算资源](../计算/覆盖矩表示与非负实现的精确核验--计算.md)。

第一障碍不排除改变数值但保持不等式的一般折叠，也不否定[自适应稀疏化](../定理/覆盖矩锥极射线与自适应类型稀疏化--定理.md)。第二障碍指向早期真实激励的正方向作用，不声明所有前层行均独立必要。后续应明确所要求的压缩合同及真实SPE条件，不能把两份反例拼成原六人目标的反例。
