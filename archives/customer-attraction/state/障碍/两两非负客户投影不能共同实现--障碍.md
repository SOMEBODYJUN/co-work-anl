# 两两非负客户投影不能共同实现

[完整二主题纠错定理](../定理/固定完整策略的二主题耦合二倍界--定理.md)认证固定系统的精确值2。该达到点已经修复旧 \(15/7\) 点的局部收益秩缺陷：每一对标签的六个收益都确实来自同一份局部客户质量，而且15份局部质量全部非负。它仍不是一份全目录客户实例。

下面分开证明两个失败：只看这些两两覆盖数，它们不能拼成全局**非负**客户资料；再指定原数组的三标签终局收益后，连一份全局**有符号**客户资料也不相容。第二个结论不由第一个结论自动推出。

## 1. 完整的两两客户数据

标签 \(0,\ldots,5\)，全部单标签覆盖数为
\[
C_0=C_3=\frac89,\qquad
C_1=C_2=C_4=C_5=\frac{20}{27}.
\]
对每个 \(a<b\)，令 \(C_{ab}\) 是保存数组在支持 \(\{a,b\}\) 的总收益。局部三类非空质量由
\[
m_a=C_{ab}-C_b,\quad
m_b=C_{ab}-C_a,\quad
m_{ab}=C_a+C_b-C_{ab}
\tag{1}
\]
唯一给出：

| 标签对 \((a,b)\) | \(C_{ab}\) | 只喜欢 \(a\) | 只喜欢 \(b\) | 同时喜欢 |
|---|---:|---:|---:|---:|
| (0,1) | \(32/27\) | \(4/9\) | \(8/27\) | \(4/9\) |
| (0,2) | \(32/27\) | \(4/9\) | \(8/27\) | \(4/9\) |
| (0,3) | \(8/9\) | 0 | 0 | \(8/9\) |
| (0,4) | \(26/27\) | \(2/9\) | \(2/27\) | \(2/3\) |
| (0,5) | \(8/9\) | \(4/27\) | 0 | \(20/27\) |
| (1,2) | \(34/27\) | \(14/27\) | \(14/27\) | \(2/9\) |
| (1,3) | \(26/27\) | \(2/27\) | \(2/9\) | \(2/3\) |
| (1,4) | \(34/27\) | \(14/27\) | \(14/27\) | \(2/9\) |
| (1,5) | \(20/27\) | 0 | 0 | \(20/27\) |
| (2,3) | \(26/27\) | \(2/27\) | \(2/9\) | \(2/3\) |
| (2,4) | \(34/27\) | \(14/27\) | \(14/27\) | \(2/9\) |
| (2,5) | \(20/27\) | 0 | 0 | \(20/27\) |
| (3,4) | \(32/27\) | \(4/9\) | \(8/27\) | \(4/9\) |
| (3,5) | \(8/9\) | \(4/27\) | 0 | \(20/27\) |
| (4,5) | \(20/27\) | 0 | 0 | \(20/27\) |

全部数都非负；各对在共享标签上的总质量也都等于同一个 \(C_a\)。每对另补“该对两个标签都不喜欢”的质量 \(2-C_{ab}\ge0\)，便可把15份局部投影的**总质量都设成2**。所以缺口并非只是局部客户总量未对齐。

原校验器对每对直接用这三类质量恢复纯 \(a\)、纯 \(b\)、两种混合计数下两标签各自的全部六个收益，共90项精确重建。这里只用数值覆盖区间是不够的，但本点确实通过了完整六收益重建。表格由保存数据直接提取，见[完整算术记录](../../tools/evidence/complete-pair-correction/replay/sparse-upper-identity-and-gluing-gap.json)。

## 2. 仅两两覆盖数已不能全局非负拼合

任意真实客户的覆盖函数必有
\[
\boxed{C_{03}+C_{04}-C_0-C_{34}\ge0.}
\tag{2}
\]
逐客户证明很短。若客户喜欢0，则其左侧贡献为
\(1-\mathbf1_{\text{喜欢3或4}}\ge0\)；若不喜欢0，则贡献为
\(\mathbf1_{\text{喜欢3且4}}\ge0\)。按非负客户质量求和即得 (2)，不需要把客户解释为随机变量，也不要求主题覆盖互异。

上表却给
\[
\frac89+\frac{26}{27}-\frac89-\frac{32}{27}
=-\frac29<0.
\tag{3}
\]
因此不存在任何一份共同非负客户质量同时实现这15个局部投影，不论给全局客户总量再加多少不可覆盖客户。

同一失败也可直观看成：局部对 \((0,3)\) 的两个专属质量都为零，若全局质量非负，标签0和3就必须在所有正质量客户上有相同覆盖；于是它们分别与4的并集应同大。但上表 \(C_{04}=26/27\)、\(C_{34}=32/27\) 不同。这里利用的是假设存在全局非负实现后的必要性，未擅自合并原形式策略中的标签。

这不否定只给单、双标签 \(C\) 值的**有符号**扩展。按[一般表示定理](../定理/共同客户收益的正边际与平衡贡献--定理.md)，截断 \(C\) 总能以有符号质量实现；(2) 的非负性依赖客户质量非负。下一节才针对额外指定的三标签收益排除共同有符号实现。

## 3. 原三标签收益连共同有符号实现也不可能

三位提供者分别选择不同标签 \(a,b,c\) 时，任何共同集合函数的 Shapley 收益满足
\[
U_a[abc]=\frac13C_a+
\frac16(C_{ab}-C_b+C_{ac}-C_c)
+\frac13(C_{abc}-C_{bc}).
\]
交换 \(a,b\) 并相减，三标签覆盖数消去，得到普遍线性身份
\[
\boxed{
U_a[abc]-U_b[abc]
=\frac12(C_a-C_b+C_{ac}-C_{bc}).
}
\tag{4}
\]
这来自三个提供者的完整随机顺序边际，或直接由已证正边际公式展开；不使用单调性、非负性或任何SPE条件，故对共同有符号客户也成立。

保存数组在根支持 \(\{0,3,4\}\) 给
\[
U_0[034]=\frac13,\qquad U_3[034]=\frac{10}{27}.
\]
于是 (4) 左侧为 \(-1/27\)。由同一数组的单、双标签数据，右侧应为
\[
\frac12\left(\frac89-\frac89+\frac{26}{27}-\frac{32}{27}\right)
=-\frac19.
\]
两侧相差 \(2/27\ne0\)。由于 (4) 中 \(C_{034}\) 已消去，不能通过任意选择另一个三标签覆盖数修复这个指定的收益差。

因此全126收益数组没有共同有符号客户实现。这个失败比“没有非负实现”更强，但它使用了三标签收益；不能倒推仅那15份二主题数据也没有有符号扩展。

## 4. 与旧 \(15/7\)、共同矩层及原模型的关系

旧 \(15/7\) 点连单独一个二主题六收益系统都没完整耦合，本点修好了每对局部关系，固定约束最优值也降到2。但每对分别有真客户，不足以保证一份共同客户；题目中的原模型从头到尾要求同一客户集、同一目录覆盖映射，不能让每个终局或标签对更换客户资料。

在这同一完整策略及固定比较上，已核的直接共同有符号矩加非负终局收益层值为 \(8/5\)，真非负共同客户层值为 \(33/23\)。本点达到2与这两个更强系统的上界一致地说明它不属于它们；本文给出的两条显式分离关系使这种排除无需只靠比较优化值。

本点的258形式激励、2520稀释和全部二主题等式都通过，并不构造真实SPE。不能称它为三人半覆盖等号游戏、六人反例或“存在另一目录实现同一收益”的证据。标签是否允许重复不改变这一判断：两种非实现性都在固定标签数据本身已经出现。

可继续使用的是[二倍定理](../定理/固定完整策略的二主题耦合二倍界--定理.md)的明确七行上界，以及这里对共同实现义务的精确失败机制。若扩展到其他策略或希望更强福利界，需要补入真实共同矩或客户资料，同时保持全部有序历史激励；逐对验证本身不能完成这一任务。
