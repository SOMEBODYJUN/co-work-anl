# 整终局势与真倒二菜单联合停界

## 对象与精确范围

固定六个有序实际主题 (A_1,ldots,A_6)、六个比较主题 (T_1,ldots,T_6)。在倒二节点强制 (T_i) 后，末位的真实回复记为 (R_i)。每类单位客户记录实际会员掩码、比较目录大小 (d)、回复目录大小 (ell) 及同索引交叠 (h)。这里把以下条件行同时放入一个有限线性系统：

* 真实倒二菜单的 (S,Z,V) 三类行，并保留 (G=S+Z/12+V/6)；
* 每个实际位置、比较位置和真实回复位置的安全 floor 与报价行；
* 实际末位对全部目录的报价、倒二对六个 (T_i) 的源 IC；
* 每个 (R_i) 在其 (T_i) 分支上对全部实际、比较和回复目录的真实末位最佳回复行；
* 在需要时加入 catalog-private 席位谱行（仅属于一个合法目录主题且被实际终局遗漏的客户）。

系统还把“对六个 actual 与六个 optimal 标签的所有六槽多重集合 (Q)，均有 (Phi(Q)le W+C(A))”作为**未证明的必要假设**。这一步不是把条件系统提升为合法完整策略；它只定义要检验的松弛。

对固定 (d)，((ell,h)) 的合法凸包顶点是 ((0,0),(d,d),(6-d,0),(6,d))。因此按共同置换对称化可把客户类型有限化。势的最大化枚举的是全部
[
{23\choose6}=100947
]
个十八目录的六槽多重集合，而非抽样。

## 普通总势点：全部十八主题势行仍不够

浮点 LP 只用于找支撑；随后由活跃行作有理高斯消元，并逐行用 Fraction 验证，得到 (W=1) 的精确点
[
O=\frac{189078419985}{92257812011}>2.
]
该点有 19 个正类型，全部 (d=1)；物化后为 114 个客户类型、缩放因子 (27677343603300)。独立审计得到单位客户数 (56723525995500)，并逐一核验：

* 全部 100947 个十八主题六槽混合势的最大值恰为
  [
  P_{18}=W+C=\frac{189078419985}{92257812011};
  ]
  因而势超额为 0；
* 实际末位对全部十八目录的最佳回复、倒二对六个 (T_i) 的源 IC、以及每个 (R_i) 在 (T_i) 枝上的全部目录末位 BR，最小精确余量均为 0；
* 这不包括真实倒二改选实际末主题或改选回复主题的后继约束。恰在这些遗漏处，倒二改 (A_6) 的最不利真实回复仍有严格增益
  [
  \frac{168357318739}{9225781201100},
  ]
  改任意 (R_i) 也有严格增益
  [
  \frac{480277410963}{9225781201100}.
  ]

所以该点通过所列全部势和末两位菜单行，却不是 SPE。它只排除了“总势候选一旦成立，再加 actual/optimal 混合势和真倒二菜单即可免费收尾”这一接口。

该普通点对 catalog-private 席位谱还不够强：全局遗漏私有量为
[
\frac{1914025884453}{2306445300275},
]
而六个第一席所需的 (W) 为
[
\frac{476569664063}{461289060055}=1+\frac{15280604008}{461289060055}.
]
因此它不应被写成通过私有谱的点。

## 加入私有席位谱的点：更强仍非 SPE

把私有总预算和六个逐玩家席位预算加入同一系统，得到另一个 (W=1) 的精确有理支撑点
[
O=\frac{1477223727431}{726719158212}>2.
]
该点有 18 个正类型，其中一个 (d=2)、其余 (d=1)；独立物化为 117 个客户类型，缩放因子 (21801574746360)。它通过：

* 全部十八主题混合势枚举，且
  [
  P_{18}=W+C=\frac{2985241636889}{1453438316424},
  ]
  与预算精确相等；
* actual 末位、倒二对六个比较主题的源 IC、每个 (R_i) 在 (T_i) 枝上的全目录最佳回复；
* 现行 catalog-private 定义下的 108 个席位行。前六大席位相同，前四实际收益恰等该值，末两收益更高。

然而它仍不是完整 SPE：倒二改 (A_6) 的最不利真实回复严格增益为
[
\frac{34953296381}{968958877616},
]
改任意 (R_i) 的严格增益为
[
\frac{32131453849}{726719158212}.
]
所以加入全局私有遗漏谱并没有替代同源 actual/reply 的真实续局约束。

## 私有席位行的可复用推导

若有 (s\le m) 个不同合法主题 (T_j)，令 (a_j) 是 (T_j) 中 catalog-private 且实际遗漏的客户量，则当前席位谱推出
[
W\ge \left(1-\frac1m\right)\sum_j a_j+\frac1m\sum_j|T_j|.
]
当 (a_j>0) 时，(T_j) 必为极大主题：任一合法真超集都会覆盖该私有客户，矛盾。故可取每个 (T_j) 的第一席 (a_j+(|T_j|-a_j)/m)。当 (a_j=0) 时，用最大极大主题的剩余席位补足；其任意 (k\le m) 席位至少为 (|T_j|/m)。选出的席位总数不超过 (m)，得到上式。

这条推导只适用于已定义的合法目录和 catalog-private 客户；不能把一个未记录额外目录中的 `mask=0,d=1,ell=0` 自动称为私有客户。

## 证据、复现与边界

独立审计程序仅读取保存的正类型质量，物化十八主题并枚举 100947 个多重集合；本轮在结果分支工作区复跑了普通点和 private 点，二者均输出 `all18_potential_excess=0`，actual-last、optimal-source、reply-full-catalog 三类最小余量均为 0。复现材料集中在 [`potential-menu-joint/replay`](../../tools/evidence/potential-menu-joint/replay/)：脚本、两个正类型输入和两个 JSON 输出。

审计确认的是有限松弛系统的精确可行性，不是 LP 最优性：浮点 dual 记录没有认证，故不能把 (O) 称为该系统的精确最优值。也没有枚举完整有序历史、早期玩家真实偏离或任意离轨平局，因此没有完整 SPE 证书。两个点都不反驳六人半覆盖目标；它们把下一步义务精确定位为把 actual/reply 同源真实续局行加入同一共同付款预算，或改用不重复花费 (W) 的其他机制。

与已有“真实终局推送构造与自由背景义务”及“实际遗漏谱”正文的关系是障碍和边界：本对象提供了更强的联合有限停界，但保留同样的真实续局缺口；不把势行、静态最优交换或末位菜单行误读成 SPE。
