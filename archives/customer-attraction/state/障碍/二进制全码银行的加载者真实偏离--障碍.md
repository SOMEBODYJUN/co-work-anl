# 二进制全码银行的加载者真实偏离

这是共同目录单位客户模型中的指定惩罚模板障碍，不是 half 反例。原稿自查完成、待独立审查的先验身份保留；本批已知其完整证明并作解析重构，不能称为新盲审。结论量化固定合法前缀后的**全部真实两人 SPE**，但排除的三人路径顺序明确为 \(L_i,B_i,B_i\)，不直接排除同计数的每个排列。

## 1. 任意编码长度的实际客户构造

取整数 \(d\ge2\)，目标集合是首位为0的全部 \(d\) 位串，大小 \(k=2^{d-1}\)。每坐标 \(a\) 有两个银行块 \(H_{a,0},H_{a,1}\)，各含 \(h\) 名不同单位客户，所有银行块两两不交。令

\[
H_i=\bigcup_{a=1}^d H_{a,i_a},\quad
H=\bigcup_{a,v}H_{a,v},\quad L_i=H\setminus H_i.
\]

客户组核 \(X_i\) 两两不交且非空；遗漏集合 \(Y_i\) 可任意相交，但与全部 \(X_j\) 和银行不交。共同目录包含且只包含下列覆盖集合，重复集合可识别：

\[
C_i=X_i,\quad A_i=X_i\cup Y_i,\quad
B_i=X_i\cup Y_i\cup H_i,\quad L_i.
\]

记 \(G=\max_i|X_i\cup Y_i|\)，取整数 \(h>6G\)。任何主题的非银行收益至多 \(G\)。银行主题 \(B_i\) 实现全部首位0的位串，\(L_i\) 实现其补串、即全部首位1的位串；因此每个完整 \(d\) 位银行选择都是合法主题。只需 \(2d=O(\log k)\) 个银行块编码 \(k\) 个目标，目标相关背景实质不同。

固定目标 \(i\)。合法前缀让各 \(j\ne i\) 选 \(C_j\) 一次，目标组选 \(A_i\) 一次，再选 \(L_i\) 一次；前缀内部次序可固定任意一种。它有 \(k+1\) 个行动，尚余三人，因此全人数为 \(k+4\)。拟指定后缀是

\[
\boxed{L_i,\ B_i,\ B_i.}\tag{S}
\]

当前加载者若按 (S) 选第二次 \(L_i\)，收益恰为 \(dh/2\)。

## 2. 末位与冻结比较确实全部可行

指定末位前，银行侧 \(H_i\) 已被一次 \(B_i\) 覆盖，补侧已被两次 \(L_i\) 覆盖。选择 \(B_i\) 的银行收益为 \(dh/2\)。任何不同 \(B_j\) 至少改错一个坐标，将该块收益由 \(h/2\) 降至 \(h/3\)；任何 \(L_j\) 首位必与 \(B_i\) 不同，也有同样损失。至少损失 \(h/6>G\)，即使补入全部非银行收益仍不能更好。\(C_j,A_j\) 至多 \(G<dh/2\)。故指定末位 \(B_i\) 是最佳回复。

现在只为检查冻结行，错误地规定加载者改行动后两个后继仍都选 \(B_i\)。加载者选 \(L_i\) 得 \(dh/2\)；不同 \(L_j\) 在某些坐标把分母2改为3，其余不增；任意 \(B_j\) 至少在首位0这一坐标面对两次固定 \(B_i\)，分母为3，而原 \(L_i\) 在另一侧分母为2，所以总银行收益至多 \(dh/2-h/6\)。非银行最多 \(G<h/6\)，\(C_j,A_j\) 也不足。因此这张**冻结后继**行的全部比较通过。

这说明仅核末位与冻结行不能认证 SPE；真实续局在偏离后必须重新沿同一完整策略执行。

## 3. 真实偏离后的所有两人 SPE 都平衡银行

让当前加载者改选任意 \(B_j\)，\(j\ne i\)。银行已有 \(L_i,B_j\) 两次行动，余两人。以下各步量化这个子博弈的任意完整纯 SPE，所有平局仍允许。

**两名后继都选银行。** 任一银行主题在任何后继下，所含每个块的最终负载至多4，所以银行收益至少 \(dh/4>G\)。非银行主题的全部收益至多 \(G\)。末位显然排除非银行；倒二强制任意银行主题也有这个不依赖续局的下界，故真实倒二同样排除非银行。

**末位逐坐标必选少数位。** 末位前每个坐标有三次银行选择，无平局。逐坐标取少数位所得完整串在目录中。若某坐标选错，改成这个串在该坐标至少把 \(h/3\) 提至 \(h/2\)，增益 \(h/6\)；3比0时增益更大。损失所有非银行收益至多 \(G<h/6\)，所以每个末位最佳回复的银行串都必须恰是逐坐标少数位。

**倒二不能造成三者同位。** 记倒二银行串为 \(P\)。若某坐标的 \(L_i,B_j,P\) 三者相同，末位必取另一侧，该坐标最终3比1，倒二获 \(h/3\)；其他坐标最终2比2，倒二至多获 \(h/2\)。于是倒二全部收益至多

\[
dh/2-h/6+G<dh/2.
\]

但倒二可真实改选 \(L_j\)，即 \(B_j\) 的补串。此前 \(L_i,B_j,L_j\) 每个坐标都为2比1，任何真实末位最佳回复由上段必须选少数位，最终全部2比2。该偏离只算银行就给 \(dh/2\)，矛盾。因此没有三者同位坐标，实际终局在每个坐标都恰为2比2。

因为 \(i\ne j\)，两个首位0编码至少有一个不同坐标，故在该坐标 \(L_i\) 与 \(B_j\) 相同。要达到2比2，两个后继均必须选相反位，所以二人的银行串都不同于 \(B_j\)，不能再选主题 \(B_j\)。此前已排除 \(C_j,A_j\)；其他组主题不含 \(X_j\)。因此组核 \(X_j\) 只被旧前缀的 \(C_j\) 和当前偏离者 \(B_j\) 覆盖。

加载者在任何真实两人 SPE 后得到

\[
\boxed{u(B_j)\ge dh/2+|X_j|/2>dh/2=u(L_i;\text{(S)}).}\tag{4}
\]

遗漏贡献非负，证明没有使用 \(Y_j\) 私有性。所有可选真实惩罚均给严格获益，故不存在以指定有序后缀 (S) 继续该合法历史的完整纯 SPE。这是全 \(d\)、全共享遗漏范围的解析结论。

## 4. 顺序边界：不能把 (S) 升级成计数不可实现

原有限报告是四个 \(d=2,3,4\) 实例（包括共享遗漏）中指定目标不在终局全集。当前 clean 源 `b099cfb45b42ccda7e71`（10545B，SHA-256 `829cc98c9244e4c0999a6e77a08d96893b15aa89449a7cb8ae847ca9ca294a1b`）与 `86b62e461fb25274692c`（4834B，SHA-256 `e9d908fd848b6d5cf2f7eede9fe454fbf65578f7256848a20ca8ea71539e584c`）已经完整读取。按脚本所需 `customer_attraction` 精确求解器依赖重建隔离布局后，原脚本实际运行 exit 0、stderr 为空，生成报告与冻结 JSON 逐字节相同；独立 checker 返回 PASS。证据包保存源原件、依赖副本、标准流和逐字段检查。

为核实这个量词区别，本批新写定义级程序，单次检查不同的明确输入：\(d=2\)、编码 \(00,01\)、\(|X_0|=10,|X_1|=1\)、\(Y_0=Y_1=\varnothing\)、\(h=61>6G=60\)。在合法前缀 \(C_1,A_0,L_0\) 后，全集递推给：

|---|---|
| \(L_0,B_0,B_0\) | 否 |
| \(B_0,L_0,B_0\) | 否 |
| \(B_0,B_0,L_0\) | 是 |

三者终局计数相同。成功顺序的最终收益为 \((193/3,193/3,61)\)；首个子博弈门槛为 \(193/3\)。加载者 \(L_0\) 的冻结行最大值仍为61，真实改 \(B_1\) 后唯一终局给当前 \(123/2>61\)，两名后继都不选 \(B_1\)，银行全部2比2。结果只认证这个新输入与固定前缀后的三人子博弈，不声称此前前缀属于原六人根 SPE 实际路径。

程序用客户类型的正整数重数表示不同单位客户；\(Y\) 为空时 \(A_i=C_i\)。为保原稿标签，代码保留两个别名。识别这些同覆盖行动不改变这里的全集存在性：对最后一层显然成立；逐层归纳，两个别名有同一投影子博弈终局全集、同一收益和同一门槛，重复的可选分支不会改变合并后的集合。因此此顺序边界也适用于去重的实际集合目录，不靠增加客户或异质提供者。

采用的精确全集递推是

\[
E(q)=\bigcup_a\{z\in E(q+e_a):U_a(z)\ge M(q)\},\quad
M(q)=\max_b\min_{z\in E(q+e_b)}U_b(z).
\tag{5}
\]

必要性来自当前激励及每个孩子都必须为 SPE；充分性是为选择行动保留目标孩子，为每个备选行动各选达到其最小当前收益的孩子。该分支收益不超过 \(M(q)\)，所以当前最优。子树逐层独立拼合，任意相同计数的不同有序历史仍可选不同续局；缓存集合不限制策略为计数函数。本次165个计数态和三种顺序成员判断见[新检查与输入](../../tools/evidence/tail-disagreement-bank-loader-and-gluing-primary/README.md)，没有冒称原程序或原四例复跑。

## 5. 与相邻障碍的关系及可接续范围

本族的跨目标背景由位串改变，不属于原稿提及的“相同银行背景、两末位成对交换”停界。当前真正起作用的是全码目录让倒二可改补串，继而强迫最后两人平衡并释放 \(X_j\)。它也不同于[根外尾差异恒等式](../引理/最大线性主题根的外部尾差异与条件保底--引理.md)：后者不预设银行，并只在给定保护条件下比较根与尾均值。两者未被证明相互推出。

扩大 \(h\)、增加编码目标或改变 \(Y\) 的交叠都不修复 (S)。若继续此模板，须改变加载者非银行奖励、可用位串或另一个实际假设，使 (4) 的全续局偏离失败；不同顺序必须按自身真实激励处理，不能从本停界自动退休。
