# 一个池的五项准确账本

采用有限单位客户、共同标签目录及完整有序历史纯 SPE；不同标签允许同覆盖，平局、空主题、重复、零客户保留。固定一个合法前缀的负载 a。某个真实 child 的实际尾为 T,C^r，r≥1；原末位选择 C 是该节点真正的 BR。旧叶负载 c=a+1_T+r1_C。另强制此 child 当前选 C，执行**同一完整策略**在改变历史后的 r 人真子 SPE，背景为 a+1_C。

若这个新尾有最后一个标签不等于 C 的 Q，记之前 k 人负载 p、之后 ℓ 个 C，k+1+ℓ=r。覆盖不同版亦可使用，之后只要求覆盖等于 C；别名与全空的零退化如[四项税引理](../引理/稳定B的末异标签四项税与全历史重置刻画--引理.md)。设其四项非负税为 A′、E′、γ′、ζ′。该引理无稳定假设的恒等式给
\[
\sum_{Q\setminus C}\frac1{a+1}-\sum_{C\setminus Q}\frac1{a+r+1}
=A'+E'+\gamma'+\zeta'.\tag{1}
\]
原叶最后 C 对 Q 的真实 BR 松弛是
\[
\eta=\sum_{C\setminus Q}\frac1{a+1_T+r}
-\sum_{Q\setminus C}\frac1{a+1_T+1}\ge0.
\]
把 η 加到式(1)，两组差分逐客户化简为
\[
\boxed{K_{T,C}(Q)=\eta+A'+E'+\gamma'+\zeta',}\tag{2}
\]
\[
K_{T,C}(Q)=
\sum_{Q\cap(T\setminus C)}\frac1{(a+1)(a+2)}
+\sum_{(C\setminus Q)\setminus T}\frac1{(a+r)(a+r+1)}.
\]
两个核都恰为旧叶的 1/[c_x(c_x+1)]，出现的 c≥1，无零分母。特别地
\[
K_{T,C}(Q)\le K^{max}_{T,C}:=
\sum_{x\in T\triangle C}\frac1{c_x(c_x+1)}.
\]
这是五项非负量的**一个**池。不能分别给 η、四项税各付一个完整 K；更不能把不同 Q 或互斥 child 的 K 相加后认为已经由原路径钱包支付。若 Q 是 C 的覆盖别名，全部差集为空，η 与四项税也都为零；标签不同不排除这一情况。

## 两种不同的旧人付款失败

下述只构造给定合法前缀后的二人完整子 SPE，未证明该前缀能成为根实际路径。

先取三个不交主题 A、B、C，固定前缀 A^k C^c，k,c≥1，主题大小 |A|=k+1、|B|=1、|C|=c+1。余二人的完整策略是首位 B；末位在 B 后选 C，在 C 后选 A，在 A 后选 C。末位所选未新增拥挤主题收益 1，另外未用主题亦至多 1，重复主题严格低于 1。首位选 A、B、C 的真续利润均 1，所以此子策略完整 SPE。

旧 child (B,C) 与首位改 C 后真 child (C,A) 比较，旧 A 玩家总收入原为 |A|=k+1，之后 A 被新末位选一次时旧总额为 k，准确损失为 **1**，与 k 无关；旧 C 总收入不变。每位旧 A 原利润 (k+1)/k、后利润 1。此处保留总人数，不能把旧人总收益误当单客户收益。该比较中
\[
K_{B,C}(A)=\frac1{c+2},\qquad \gamma'=K_{B,C}(A),
\]
其余四项皆零。令 c 趋大，说明没有绝对常数乘这个特定 K 就能支付所有旧人的净损失。

第二个版本取前缀 A^k B^b C^c，b≥1，并改 |B|=b+1，其余同上；三种裸边际仍为 1，完全相同的二人策略继续完整 SPE。现在
\[
K^{max}_{B,C}=\frac1{b+2}+\frac1{c+2}\to0.
\]
若 k=1，指定那位旧 A 玩家在上述两叶间损失 1，但旧 B 玩家总额增加 1，所以旧人**合计净变化为零**。该版本只反“任一指定祖先的损失由 Kmax 绝对倍数支付”；不能称它反驳旧人合计净损失的 Kmax 界。源稿给的两类失败必须各保付款对象。

## 任意多完整真分支共享一个末端租金池

固定整数 n≥2、K≥1、s≥1。取彼此不交客户块 Q、R₁,…,R_K（各 ns 人）以及 Y、X₁,…,X_K（各 s 人），共同目录
\[
B=Q\cup\bigcup_jR_j,\quad
T=(B\setminus Q)\cup Y,\quad
P_j=(B\setminus R_j)\cup X_j.
\]
共有 K+2 个覆盖不同的标签。下面是一份明确的**全有序历史**策略：非末位恒选 B；末位若此前没有 T 则选 T，否则选 B。

任意末节点，若此前 P_j 次数 a_j、T 次数 t，当前 P_j 相对 B 的差为
\[
\frac s{a_j+1}-\frac{ns}{n-a_j}\le0,
\]
T 相对 B 的差同式换 t。t=0 时 T 与 B 平局，t≥1 时 B 最优。非末节点，P_j 不改变将来最后 T/B 的选择，仍由此差式不增利；已有 T 时当前 T 亦不增利。尚无 T 时当前从 B 改 T 会把末位 T 改成 B，两叶全局主题计数相同，只交换当前/末位角色，当前遵循 B 比偏 T 多
\[
\frac{ns}{n-1}-s=\frac s{n-1}>0.
\]
故所有过去混合过 B、T、多个 P_j 的离轨历史也覆盖，得到完整纯 SPE。

actual 为 B^(n−1)T。root 强制 P_j 后真叶 P_j B^(n−2)T。对原 root B 及 K 个 P_j 源，最后 T 的四项税全零，均有同一个 Q=B\T，租金
\[
\epsilon=\sum_Q\frac1{n(n-1)}=\frac s{n-1}.
\]
因此不加权 Σ源 ε=(K+1)s/(n−1) 可任意大，而使用的是同一组 Q 客户。此例不声称这和大于 W（W 自身随 K 增），更不反具有正确权重容量的付款。

在此族，B 满足稳定条件，恒 B 亦为完整 SPE，故 root 最小真 SPE 利润
\[
M=|B|/n=(K+1)s.
\]
当前策略 root 利润 h=M+s/(n−1)，每个 P_j 强制 root 分支都平局。K 条分支的复用不把有效赤字 h−M 扩大为 K 份。精确覆盖和静态最优为
\[
W=(K+1)ns+s,\quad
OPT_n=(K+1)ns+\min(n,K+1)s.
\]
上界因为每个主题只多一个不交小块，最多 n 个小块，底层 B 块总和固定；有 B 加 n−1 个替代主题时达到 n−1 小块，若不取 B、取至少两个不同替代主题则底层全部覆盖，可取 min(n,K+1) 个小块（n≥2）。所以式中上界确实可达，且半覆盖有正余量。这不是 half 反例。

一般共同 b,n,B 下，对末端遗漏 Q_v⊆B、权重 λ_v≥0，精确有
\[
\sum_v\lambda_v\epsilon_v=
\sum_{x\in B}\frac{\sum_{v:x\in Q_v}\lambda_v}{(b_x+n-1)(b_x+n)}.
\]
若每个客户上的括号≤1，一个 B 池足够；原 IC 并未自动给出这些跨源 λ。此客户容量是下一步实质义务，不能靠发现很多平局分支绕过。
