# 两个目标必须分别计算

采用[共同目录完整历史模型](../定义/共同目录完整历史模型--定义.md)。令全目录客户并集为\(U=|\bigcup_{a=0}^{p-1}S_a|\)，固定m槽的最优覆盖为\(\operatorname{OPT}_m\)。若对某个实际角色能证明\(U\le(2m-1)u_i\)，当然能推出较弱的\(\operatorname{OPT}_m\le(2m-1)u_i\)，因为\(\operatorname{OPT}_m\le U\)。但前者失败不否定后者，特别当目录主题数大于m时，不能把全目录支持作为m槽比较组合。

1127365B原JSON已完整解析：全部1023个克隆坐标、11111条动作、十个顶层字段都被本批检查器消费。其scope本身明确写“Auxiliary total-catalog-union bound failure only”，说明J有10题而n5、实际OPT5=5、ui1，不是strong逐人反例。完整原件和[一次精确检查](../../tools/evidence/graph-cone-individual-and-catalog-union-primary/catalog-union-point-exact.json)保留，未沿用文件名把它分类为half或预定逐人桥反例。

# 十名单位客户与原完整动作

共同主题标签0,…,9，各含一个互不相同的单位客户；没有其它兴趣客户。按mask1,…,1023排列的克隆向量恰在\(1,2,4,8,16,32,64,128,256,512\)十坐标为1，其余全0。五位提供者均单位权，目录非空；全部历史允许重复、离轨和弱平局。

保存的动作表在每个\(h\in[10]^{<5}\)均指定一个尚未在h出现的标签。原表不是仅给根路径：各深度分别有1、10、100、1000、10000条，无缺漏、重复键或非法动作。完整11111动作与[86客户五人安全反例](../反例/五人首位收益低于真正混合安全值--反例.md)的完整动作函数逐项相同，但这里的客户是新十单例重数，不能把86客户的W85、OPT86或安全值2262/139移来使用。

这份表在新客户点仍是完整纯SPE，证明不需要重新搜索均衡。在任一合法有序历史h，规定动作a未出现；以后所有规定行动仍选择其当时未出现标签，所以当前a不再被重复，最终收益恰1。当前若改选b，后继同样不再选已经出现的b，故其真实最终收益为

\[
u(h,b)=\frac1{1+\#\{t\in h:t=b\}}\le1.
\]

这是按**偏离后的**同一完整动作表继续，不冻结原尾词。无论h此前是否重复、是否沿根处方发生，论证都成立；所有未用b给平局1，所有已用b严格较差。因此每个子博弈当前动作最优，建立完整有序历史纯SPE。

实际路径为(4,5,6,7,8)，逐人收益全1，实际覆盖W5。任何五个不同单例主题覆盖恰5，重复只会少覆盖，故

\[
U=10,\qquad \operatorname{OPT}_5=W=5,\qquad u_1=1.
\]

从而辅助目标\(U\le9u_1\)严格失败，差为1；真正五槽目标的差\(\operatorname{OPT}_5-9u_1=-4\)，更弱\(\operatorname{OPT}_5-10u_1=-5\)，half余量\(2W-\operatorname{OPT}_5=5\)。全目录十题集合J不是合法五槽比较支持。

更一般，p≥m个等大小不交单例主题上，任何每个历史选未用标签的完整策略都按同样理由为SPE，W=OPT_m=m、各u_i=1，而U=p。取p>2m−1便直接排除全目录辅助上界；这是目标差异的简单解析解释，不依赖保存JSON的特殊11111动作，不声称新的反例机制或最小性。
