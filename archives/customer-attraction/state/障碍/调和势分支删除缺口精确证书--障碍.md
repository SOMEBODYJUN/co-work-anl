# 精确对象

对终局 `z` 令 `c_x(z)` 为客户负载，`H_r=Σ_{j=1}^r1/j`，并定义

\[
\Phi(z)=\sum_x H_{c_x(z)}.
\]

删除玩家 `i` 的主题但保留其他主题时记作 `z^{-i}`。客户分账恒等式给出

\[
u_i(z)=\Phi(z)-\Phi(z^{-i}).
\]

因此 SPE 在节点 `h` 对 prescribed action `A*` 与强制 action `A` 只保证两侧的“自身动作边际”满足

\[
\Phi(z_{A^*})-\Phi(z_{A^*}^{-i})
\ge
\Phi(z_A)-\Phi(z_A^{-i}),
\]

不能推出 `Φ(z_{A*})≥Φ(z_A)`；右侧删除势差是分支相关的未知量。

# 完整有限证书

共同目录为

\[
T_0=\{1,2\},\ T_1=\{2\},\ T_2=\{1,3\},\ T_3=\{0,1\},\ T_4=\{0,3\},\ T_5=\{3\},
\]

四类单位客户的兴趣签名分别为 `{T0,T1}`、`{T0,T2,T3}`、`{T2,T4,T5}`、`{T3,T4}`。三名提供者的证书指定根、全部六个单动作历史和全部三十六个双动作历史，共 43 个历史节点；冻结验证器用有理数精确检查 215 个偏离。

证书 prescribed 路径为 `(T1,T3,T4)`；根强制 `T0` 后按同一证书真实续局得到 `(T0,T0,T4)`。两枝根收益均为 1，因此强制动作是 SPE 平局。对应负载向量可取 `(0,1,0,1,1,0)` 与 `(2,0,0,0,1,0)`，从而

\[
\Phi_{\rm actual}=H_2+3=\frac92,
\qquad
\Phi_{\rm forced}=2H_2+2=5,
\]

两者相差 `-1/2`；删去根动作后的势为 `7/2` 与 `4`，删除差同为 `-1/2`。两枝福利都为 4，且精确核得 `OPT_3=4`。

# 处置与边界

这是真实完整历史纯 SPE 上的有限障碍：它否定“每个当前动作都沿 terminal harmonic potential 上升”的证明步骤。它不否定任意替代势函数，不否定完整逐偏离 Farkas 接口，不构成低福利 SPE，也不反驳 `Q-CAG-HALF`。后续路线必须显式支付分支相关删除势差，或引入能控制它的状态变量；不得把静态对称混合 Nash 的调和势最优性转移到顺序 SPE。
