# 对象与精确量词

在有限共同目录模型中，取六个主题 `0,…,5`，六类客户掩码的单位重数为

| 兴趣掩码 | 重数 |
|---|---:|
| `{0}` (`1`) | 1 |
| `{0,1,2}` (`7`) | 2 |
| `{1,3}` (`10`) | 1 |
| `{4}` (`16`) | 1 |
| `{3,4}` (`24`) | 1 |
| `{5}` (`32`) | 3 |

总客户数为 9。给定候选 JSON 的 28 个计数状态动作表，把它投影为完整有序策略：对每个长度 (d=0,1,2) 的有序历史，按其计数状态取动作，随后沿同一动作表补到三步。独立 `Fraction` 复放逐节点比较真实后继收益；因此这里的 SPE 断言量词是“这一个输入、这一个完整动作表、全部 (6^0+6^1+6^2=43) 个决策历史和全部六个单步动作”。

审计报告给出的实际路径是

\[
(5,2,3),\qquad (u_1,u_2,u_3)=(3,2,2).
\]

末局负载按九名客户为

\[
(0,1,1,1,0,1,1,1,1),
\]

即七名客户负载一、两名未覆盖。故实际福利 (W=7)，二层占用
\(sum_x\min(c_x,2)=7\)，普通调和势和截断势也均为 7。比较主题 `(1,4,5)` 覆盖八名客户，枚举三步有序终局得到

\[
\operatorname{OPT}_3=8,\qquad W=7<8.
\]

## 完整历史纯 SPE 核验

独立脚本 `run/verify_two_layer.py` 对每个有序历史 (h) 和每个动作 (a) 计算原策略后继与偏离后继的个人均分收益差。总计 258 个比较，其中 188 个严格、最小 slack 为 0，全部非负。`two_layer_occupancy_audit.json` 与该复放的路径、收益、历史数、比较数、严格数、最小 slack 和最优值一致。

这一步保留了离轨历史和重复动作。它证明固定策略是完整纯 SPE；它没有把根路径或静态终局最优误认为顺序 SPE，也没有把一次候选 `linprog` 的浮点可行性当作证明。

## 来源候选与发现目标

`two_layer_occupancy_probe.py` 使用 (q=6,r=3) 的随机权重、逆序 Markov 动作选择和 `scipy.optimize.linprog`。它在全部单步偏离不增收益的线性约束下，比较实际终局二层占用与候选比较主题覆盖的新客户；只在有限随机策略和至多 12 个比较主题中搜索。候选 JSON 的权重是九客户重数的浮点归一化，报告目标为 (-1/9)。用同一整数客户展开后，目标精确为

\[
\frac{7}{9}-\frac{8}{9}=-\frac19.
\]

因此浮点发现被精确化为固定实例证据，但发现程序本身没有给出一般存在性或最坏比率定理。`run/` 的复放和源 SHA/冻结提交清单保存在证据包。

## 可用结论、失败机制与接续

该点严格否定以下辅助命题：对所有共同目录实例和所有完整纯 SPE，实际终局二层占用（以及同一负载下的普通/截断调和势）至少达到 (operatorname{OPT}_m)。这里缺口是 (8-7=1)，而所有实际被覆盖客户只有一次覆盖；二层截断没有额外价值。

它仍满足

\[
2W=14>8=\operatorname{OPT}_3,
\]

所以没有反驳六人半覆盖目标，也没有证明九客户点在所有三人或所有人数中的最差性。已有五客户两人障碍把这一机制压缩成 `W=4, OPT_2=5`；已有十一客户三人势障碍则采用不同的负载分布，给出 `Phi=Psi=21/2<11`。这些对象共享“实际势/占用不足以支付最优覆盖”的联系，但客户输入、人数和量词保持独立。

后续若研究全局 half，应跨真实离轨分支支付实际终局与比较终局之间的差额，不能把本固定障碍升级为普遍反例。若研究无拥挤族的效率上界，本对象只提供 `OPT/W=8/7` 的有限点；趋 (3/2) 的 Q/B 族和其他浮点探针必须分别引用，不能由本点推导。
