# 静态充分简化的准确量词

固定原零根m人游戏，令τ=δₘ₊₁(0)为自由目录分布的竞争质量m的插入价极小最大值。曾设想用如下SAFE-ACTION替代未来完整IC：对每个合法过去及剩余人数r，总有一个当前主题A，使**任何**r−1个未来动作只要每名未来者最终收益≥τ，都不能令当前者收益低于τ。该静态断言为假。

以下解析例仅否这条替代，不把“未来者收益足够大”写成未来者是最佳回复；也不把其失败当全局逐人门槛的原SPE反例。全局逐人门槛后来已由[笛卡尔银行完整反族](../反例/笛卡尔银行目录的逐人分数门槛反族--反例.md)独立否定，两件证据的逻辑域不同。

# 七环的真正优化值

客户是C₇的七条边eⱼ={j,j+1}，各一名单位客户；主题Sⱼ={eⱼ₋₁,eⱼ}，下标模7。m3、零过去。对任意主题分布q，每条边负载3(qⱼ+qⱼ₊₁)，查询Sⱼ给两个倒数之和。均匀q令每个查询恰14/13，给τ≤14/13。

反向，最大查询至少七查询均值，而每边出现两次，故
\[
\max_Tg_T(q)\ge\frac27\sum_{j=0}^{6}\frac1{1+3(q_j+q_{j+1})}
\ge\frac2{1+6/7}=\frac{14}{13}.
\]

末步是倒数凸性，七边平均负载恒6/7。因此τ=14/13是真正自由最优值，不是固定背景的单边上界。

# 每个动作都可被高收益未来压低，但该未来不可信

对任意当前Sⱼ，令未来依次Sⱼ₋₁,Sⱼ₊₁。当前两个边客户都被两人分，u_current1；每名未来有一个独享客户和一个二分客户，u_future3/2。因此1<14/13<3/2，对每个当前行动由旋转同构均成立，没有静态SAFE-ACTION。

但在有序前缀(Sⱼ,Sⱼ₋₁)后，原指定末位Sⱼ₊₁只得3/2；改Sⱼ₊₃能覆盖两条全新边、得2，严格增1/2。故这条未来元组不是SPE续局。要归纳全局门槛，不能仅保未来每人已过τ而删除其真最佳回复及更早离轨IC。
