# 固定尾深最坏保底不足半覆盖

这是一个精确的“信息缺口”障碍。它排除的弱化模板保留了实际固定前缀后的全部 \(k\) 人真实尾部子博弈，却把每个早期玩家的真实偏离收益删掉，只留下逐主题的最坏拥挤保底。即使这些保底允许任意非负、非均匀组合，也不足以推出半覆盖。

## 1. 整数族与弱化条件

固定 \(k\ge1\)，取 \(m\ge2k+1\)，令 \(n=m-k\)、\(L=k+1\)。客户分成互不相交的目录主题：

- \(E\) 含 \(n\) 个单位客户；
- \(Q_1,\ldots,Q_m\) 各含 \(L\) 个单位客户。

实际路径为 \(E^n,Q_1,\ldots,Q_k\)。前 \(n\) 位规定选 \(E\)，尾部的 \(k\) 位在任意有序历史中选择尚未出现的最小下标 \(Q_j\)。

弱化条件只要求两件事：固定前缀后的 \(k\) 人策略在其全部有序历史上是真实纯 SPE；每个早期位置 \(i\le n\) 和每个目录主题 \(T\) 都满足
\[
u_i\ge\sum_{x\in T}\frac1{b_i(x)+m-i+1},
\]
其中 \(b_i(x)\) 是实际前缀在 \(i\) 前的负载。它不要求 \(i\) 位改选 \(T\) 后再沿真实策略计算后继收益。

## 2. 福利、最优覆盖与半覆盖缺口

沿实际路径，早期每位收益为 \(n/n=1\)，尾部每位收益为 \(L\)，故
\[
W=n+kL=m+k^2.
\]
因为 \(n\ge L\)，选择 \(E\) 和任意 \(m-1\) 个 \(Q\) 主题给出
\[
\operatorname{OPT}_m=n+(m-1)L=(k+2)m-2k-1.
\]
两倍差为
\[
\operatorname{OPT}_m-2W=k(m-2k-2)-1.
\]
取 \(m\ge2k+4\) 时严格为正，并且固定 \(k\) 让 \(m\to\infty\) 时 \(\operatorname{OPT}_m/W\to k+2\)。

## 3. 早期最坏拥挤保底逐项成立

在位置 \(i\le n\)，实际前缀只有 \(i-1\) 个 \(E\)。改选 \(E\) 的保底为
\[
\frac n{(i-1)+(m-i+1)}=\frac nm\le1=u_i.
\]
改选任一 \(Q_j\) 的保底为
\[
\frac L{m-i+1}\le\frac L{k+1}=1=u_i.
\]
目录只有这些主题，所以所有 \((i,T)\) 保底成立；任意非负线性组合仍只产生非负余额，不能支付上式的严格负 \(2W-\operatorname{OPT}_m\)。

## 4. 尾部确实是完整纯SPE

固定 \(E^n\) 后，尾部任意历史至多使用 \(k-1\) 个 \(Q\)，而目录有 \(m>k\) 个 \(Q\)，所以未使用主题总存在。规定选择未用 \(Q\) 时，后继继续避开它，当前收益为 \(L\)。偏离到已用 \(Q\) 时最终收益至多 \(L/2\)；偏离到 \(E\) 时收益至多 \(n/(n+1)<1<L\)；偏离到另一个未用 \(Q\) 时仍得 \(L\)。因此固定前缀之后的整个尾部有序子博弈都满足真实最佳回复，包括所有重复、离轨和任意未用主题平局。

## 5. 缺口和边界

第 \(n\) 位早期玩家实际得1；若改选一个新 \(Q_j\)，按同一后继规则，尾部会使用其余未用 \(Q\)，偏离者得到 \(L=k+1>1\)。所以完整策略在早期节点并非 SPE。\(k=2,m=9\) 时 \(W=13,\operatorname{OPT}=31\)，已经有 \(31-26=5\) 的半覆盖缺口；这只是弱化系统的显式缺口，不是原模型反例。

该构造明确说明：末两人菜单、固定尾深全部后继最优性和早期最坏分母保底，仍没有替代早期真实偏离后的后继最优性。若要继续证明六人 half，必须把这类偏离分支的真实续局收益或另一个全局付款机制纳入；不能把弱化障碍升级为一般不可能性。

README 中提到的 iid 前缀流、非均匀 deficit 探针和自由分数探针是其他对象；本页不据未领脚本声称其结果，也不把有限审计写成原模型普遍界。
