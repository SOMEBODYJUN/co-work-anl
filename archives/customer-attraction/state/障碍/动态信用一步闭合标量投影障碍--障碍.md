# 动态信用一步闭合标量投影障碍

源文完整实读 3433 字节（SHA-256 `46612875983e83739d3968fff56673ebf15d38db57837e3862119e2d10385e3b`，source ID `7b48988bdfe9ac257f82`，blob `de1dfece904456cf31102db54ad9c52cc1ceaedc`）。它研究一个归纳投影：固定背景、r=3、四主题，给每个首动作一个尾菜单，只保留根真实分支收益比较以及 `F_{r-1}≤2P`、`M_{r-1}≤G+P` 两个子局标量 half 条件。

30 个单位客户由 mask 2/3/4/5/8/9 的重数 9/1/7/3/7/3 构成。根四个分支收益均为 5，实际 `(0,2,2)` 的覆盖 W=14，三个主题 1,2,3 合计覆盖全部 30，因此 OPT=30，投影账本出现 `2W−OPT=-2`。但在真实历史 `(0,2)`，规定末位选 2 只能得 `9/2`，改选 1 得 `19/2`；该菜单不是 SPE。

因此该障碍精确说明：只保留两个子局 half 标量和根比较，丢弃子局内部 IC，不能闭合任意人数归纳。它不否定保留真实子局策略的归纳，也不提供原 Q-CAG-HALF 的完整反例。与 exact JSON 的关系是同一有限分离的解释页；与 random probe 的关系是数学说明和浮点搜索分开。

与 `背景新增覆盖余额与首步分解--引理` 对照，精确望远镜允许某一步余额为负而由后续正余额支付；本障碍阻止的是更强的“每个子局仅以两个标量封装即可支付”规则。本对象不迁移到 unrelated-machines，后续仍需保留真实末位/早期偏离信用或构造完整 SPE 反例。
