# 数学身份

有限单位客户、有限非空共同目录、m≥1名单位提供者，任意完整有序历史纯SPE σ。客户终局在其所有覆盖者间均分，空主题、重复标签、零客户与离轨平局保留。本页整理一项一般共同请求耦合探索：已证固定叶的概率表示，未证一个完整跨行动付款机制；障碍是**当前构造中的缺口**，不是任何耦合皆不可能的定理，更不是原六人half反例。

# 一份共同随机排列实现固定叶利润

任意给定完整终局z，对每个被覆盖客户x记覆盖角色集合S_x(z)，大小c_x(z)>0。给角色独立同分布连续优先值U₁,…,U_m，或等价地抽一个均匀随机角色排列。把x交给S_x(z)中优先值最小者。对任意i∈S_x(z)，交换对称性和无平局给
\[
 Pr(i\text{得到}x)=1/c_x(z).
\]
故角色i的获客数期望等于其原均分利润
\[
 E\#\{x:i\text{得到}x\}=\sum_{x\in z_i}1/c_x(z)=u_i(z).
\]
同一角色排列可用于全部客户、全部固定合法偏离叶；每个叶单独的边际仍正确，不需要各客户独立排列。客户间或叶间可有相关性。这个随机化只耦合分析中的收费事件，不是原玩家看到的新信号，不改变σ或原IC。

# 固定状态边际不等于自适应到达后的转移

原探索希望在递增角色请求状态(i,A,x)中，读取σ在实际前缀强制A后的真实叶，将遗漏客户质量在有关后继覆盖者间均分，并将请求递送到更晚角色。对一个**预先固定**状态，随机优先确能表示均分边际。

但若“到达该状态”的事件E本身依赖同一优先值，条件分布Pr(获胜｜E)未必均匀。最小概率示意已经足够：S={1,2}，E={U₁<U₂}，无条件角色1获胜概率1/2，而在E下为1。它只是说明条件化失效；没有构造一份CAG反例或否定所有可能的独立随机化。

所以从每个固定状态的正确边际，不能推得一个自适应旧流在全图中保持其原条件转移。原稿记录matching内部亦指出：若匹配/动作选择依赖潜在provider优先值，给定动作后的query利润分布随之改变；另抽独立排列可恢复单叶1/c，却同时失去想用的跨query取消。这是本构造的未解兼容性，不是一般不存在结论。

# 同角色多action请求还需共同预算

设实际叶覆盖为C，最优m主题元组覆盖为O，记客户集合I=O∩C、R=O\C、G=C\O。它们分别为交集、实际遗漏和实际OPT外客户；这里I是集合，与其他付款页的标量IC松弛不同。W=|I|+|G|，OPT_m=|I|+|R|，所以要支付的净遗漏为|R|−|G|。

实际第i个节点对每个合法A有单独的完整查询IC
\[
 u_i\ge d_i(A),
\]
其中d_i(A)是该真实偏离叶的**整位**利润。同一角色从不同来源接到多个不同A时，各条正确客户边际并不保证每次随机实现至多选择一个行动；也不保证期望查询系数总和≤1。若用非负系数λ_{i,A}求和，合法直接预算只是
\[
 \sum_A\lambda_{i,A}d_i(A)
 \le u_i\sum_A\lambda_{i,A}.
\]
要把右侧换成u_i，须另有Σ_Aλ_{i,A}≤1，或给出带明确补偿的共同机制。逐边改为随机排列没有证明这个条件。客户质量守恒、角色严格增加和整位行动预算是不同义务。

原探索准确尚缺：选择最优元组匹配、遗漏客户owner及跨query耦合，使位置加权收费超额至多由|G|一次支付，同时保原IC松弛且不重复使用任何来源银行。若能得P满足OPT_m−W≤P≤W，才闭合half。[终局遗漏份额](../引理/终局遗漏客户的顺序偏离份额--引理.md)已证每枝真实分母与排列预算，不自动给共同P；本页也未增加这样的下界。

# 何时这项表示可继续使用

固定叶利润的随机优先表示可作为任何合法联合构造的边际工具。如果新构造只重新表示原均分，未改变可共同支付的请求集合和上述系数预算，就尚未提供新的全输入付款组件。原稿的“停止重排”是对这种无新增关系操作的研究建议，不能扩成不可解定理。
