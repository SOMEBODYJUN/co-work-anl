## 精确模型和需要超过的成本

有限不同单位客户；有限非空共同集合目录；m名单位权提供者观察完整有序历史依次各选一主题，终局在覆盖者间均分。重复主题、所有离轨历史和平局保留。

固定整数k≥4，m=k+1。所有块彼此不交，|X_i|=2、|Q_i|=3（1≤i≤k），|E₀|=|E₁|=4；A_i=X_i∪Q_i，D=E₀∪E₁。合法目录**恰为**

\[
C_i=X_i,\quad H_i^e=A_i\cup E_e\ (e=0,1),\quad
P_{ij}=A_i\cup A_j\ (i<j),\quad D.
\]

只考察目标z=(C₁,…,C_k,D)。前k位最终各得2；末位D得8，是真BR，因为H、P各报价8、C报价1。目标覆盖W=2k+8。至多⌈k/2⌉个P覆盖全部A_i，再用D覆盖水库，剩余槽可重复合法主题；m槽足够且这是全部客户，所以O=OPT_m=5k+8，旧差g=O−2W=k−8。k≥9时g>0只是未修复目标的差额。

在正常前缀h_i=(C₁,…,C_(i−1))，i≤k，令ℓ_i(T)为强制当前T后，**所有完整有序历史纯尾SPE中**当前玩家最终收益的最小值；M_i=max_Tℓ_i(T)，δ_i=(M_i−2)_+，R=Σδ_i，Δ=maxδ_i。有限完美信息树有有限非空纯SPE集，极小值达到。按[异质真实退出修复定理](../定理/真实退出缺陷的统一与异质前缀修复--定理.md)，这条目标经该编译的精确新差为g−(2R+Δ)，故严格反例种子必须满足g>2R+Δ。这里没有把该充分攻击检验提升为所有可能目录改造的成本下界。

## 主原稿：全有序历史的新鲜成对主题地板

固定正常前缀h_i，令n=k−i+2为当前起剩余人数，假定k≥2n。在h_i之后添加l<n个**任意**动作，称某A_j被污染，当其中一个添加动作碰过它；正常前缀的X单层背景不计污染。每个合法动作最多碰两个组，所以未污染组至少k−2l≥2(n−l)，尤其至少两个。

对剩余人数n−l逆向归纳，同时证明此类每个有序历史中每份完整纯SPE的当前玩家最终收益至少8。末位选择两个未污染组a,b的P_ab：Q块均无旧覆盖；各X块仅可能由正常前缀盖一次，每组收益至少3+2/2=4，总计至少8。

归纳步强制当前选择这样的P_ab。任何更深真实SPE中的当前玩家由归纳均最终得至少8。若未来玩家选择碰a或b的主题，忽略其未来拥挤后收益已经严格小于8：

| 后继动作 | 只用当前P已覆盖这一事实的收益上界 |
| --- | ---: |
| 碰一个所选组的P | 5/2+5=15/2 |
| 碰两个所选组的P | 5 |
| 对所选组的H | 5/2+4=13/2 |
| C | 2（宽界；所选组C实际至多1） |

这些上界只会随未来覆盖增加而降低；D不碰两组。因此每个真正SPE后继都避开两组。强制者保留插入时收益至少8；原完整SPE的当前最优性遂给其实际收益至少8。关键是归纳覆盖每一更深历史的当前玩家及每份真实孩子，不假定惩罚配合，不冻结后继，也不只核实际路径。任意重复、任意有序历史平局均已包含。

在h_i强制固定未污染P_ab时，它在**每份**真实尾SPE中都不再被碰，所以

\[
\ell_i(P_{ab})=10-|\{a,b\}\cap\{1,\ldots,i-1\}|\in\{8,9,10\}.
\]

不主张每个i上三值都可取。条件k≥2(k−i+2)等价于i≥⌈(k+4)/2⌉。从该位置到k共有⌊k/2⌋−1位，各δ_i≥6，因此

\[
R\ge6(\lfloor k/2\rfloor-1),\quad\Delta\ge6,\quad
2R+\Delta\ge12(\lfloor k/2\rfloor-1)+6.
\]

偶k右端6k−6，奇k为6k−12；全部k≥4都严格大于k−8。本源单独即解析排除全k的严格修复种子，未使用有限扫描。

## 相关更强证明：好组条件与精确较大缺陷

完整读过的 `paired_reservoir_family_floor.md` 及其独审给出更强但同范围下界；它不是本6486B稿的新发现，也不附带该两相关源的done。

任意有序历史后，称组j为好组，若Q_j负载0且X_j负载≤1；称全暴露组，若Q_j负载≥1。每个覆盖Q的合法主题同时覆盖全部X，因此全暴露组的X负载亦≥1；Q=0、X≥2的组既非好也非全暴露，不能偷并分类。

若剩r人时至少2r个好组，则每份真纯尾SPE的每位尾玩家最终收益≥8，且任何实际尾动作均避开当前已有的全暴露组。证明仍对r归纳：**任意**强制动作至多损失两个好组，孩子保2(r−1)；当前取两好组P使两组全暴露，孩子归纳保护两组，当前可保至少8。触碰旧全暴露组的C、H、P上界依次1、13/2、15/2，均小于8，从而排除它们。重复C可使X由1到2而失好，但至多损失一个组，计数仍正确；并不要求所有强制动作本身避开旧组。

应用到正常位置⌈(k+4)/2⌉≤i≤k−1，至少两组未被正常C使用；强制这两新组的P后剩k−2好组，尾人数r=k+1−i满足k−2≥2r，故ℓ_i(P)=10、δ_i≥8。此区间长⌊(k−4)/2⌋。位置i=k取P_kj、j<k，尾末位避开两组，强制者恰得5+4=9，所以δ_k≥7。因此

\[
R\ge8\lfloor(k-4)/2\rfloor+7,\quad\Delta\ge7,
\]
\[
2R+\Delta\ge16\lfloor(k-4)/2\rfloor+21\ge8k-19,
\qquad(8k-19)-(k-8)=7k-11>0.
\]

k=4、5时前区间为空，另算i=k的7，不存在负区间长度。raw主题大小≤10还给前述两组均未使用的位置M_i=10；i=k各动作即时报价≤9给M_k=9，但全k障碍只需下界。此加强说明原倒二收费21不是唯一大缺陷，后期线性多位均有不可消去的高可信退出。
