# 实际与最大根双路径二百六十六行的精确障碍

## 1. 放松域及量词

记录实际五步 $(A,B,C,D,E)$ 与强制最大根后的真实五步 $(M,A_2,A_3,A_4,A_5)$。客户型为十个主题的隶属 $b\in\{0,1\}^{10}$ 及最优五项索引重数 $d\in\{0,\ldots,5\}$，共6144型，每型质量 $x_{b,d}\ge0$。$W$ 只统计实际前五主题并集；$O=\sum x_{b,d}\mathbf1_{d>0}$，$K=\sum x_{b,d}b_5$。

该域没有指定最优五项各自的隶属，也没有全历史策略的一致性。真实游戏可投影到必要行域，反向不成立。这里的整数点仍是放松点。

## 2. 固定的266行

精确系数保存在 `audit.py::joint_rows`，并以 `Fraction` 独立重建。

| 家族 | 行数 | 合法语义 |
|---|---:|---|
| 根偏离 | 1 | 实际根利润至少为强制最大根利润 |
| 最大主题大小 | 11 | 十个路径主题的大小上界及最优五索引总大小上界 |
| 单节点比较 | 108 | 实际5节点和最大根后4节点，各有10个主题 IC、最优重数行、覆盖行 |
| 真实两尾 | 114 | 两路径各有并集税、最优索引对税、十主题有重复无序对55行 |
| 三尾、四尾 | 6 | 两路径各有一条三尾重数行及两条已有四尾界 |
| 真第三位投影 | 22 | 两路径各对10个重复主题及最优元组投影 |
| 加权根界 | 4 | 四组已证明的 $Br-CK-O\ge0$ |
| 合计 | 266 | 强制根不获得不存在的局部优化行 |

四组加权根常数是 $(80,71/5)$、$(70,423/35)$、$(1920/29,11393/1015)$、$(5840/91,2627/245)$。原审计另用对应非负权重重算常数。真第三位行的七行来源与144型投影见[包络引理](../引理/真实第三位投影的五人最大根包络--引理.md)。这里的行数不代表“所有可能合法行”。

## 3. 十二型整数见证

下表所有 $d=1$，位次严格为 $(A,B,C,D,E,M,A_2,A_3,A_4,A_5)$。

| 0001000000 | 3 |
| 0001100000 | 1 |
| 0010000000 | 1 |
| 1011011011 | 1 |

| 1110011110 | 3 |

逐客户份额给

\[
\begin{aligned}
W&=16,&O&=33,&K&=7,\\
(u_1,\ldots,u_5)&=(2,5/3,3,23/6,11/2),\\
(v_1,\ldots,v_5)&=(2,2,11/4,4,21/4).
\end{aligned}
\]

266个行余量全部非负，最小值零；原 JSON 逐行列出余量，本次重建逐项相等。若这266行与客户质量非负约束的非负线性组合能推出 $2W-O\ge0$，该点也应满足；实际 $32-33=-1$，矛盾。因此这个固定必要行锥不足以证明半覆盖。

## 4. 原有理点、核验和边界

另一冻结点有22个非零有理型，$W=1$，

\[
O=\frac{34448005135819031}{15885481876069672},\qquad
O-2W=\frac{2677041383679687}{15885481876069672}>0.
\]

本次原审计重建两点的34个非零型与全部532个已保存余量，输出同冻结报告。没有重跑发现 LP，没有声称点是该放松的最优解。[原件和复现](../../tools/evidence/maxroot-gamma-shared-menu-primary/README.md)保留完整系数与余量。

整数质量不能补回目录索引和全树策略一致性。因此它不是原模型反例，不与[五人半覆盖定理](../定理/五人半覆盖--定理.md)冲突。后续可加入共同菜单、索引相容性或其他真实分支关系；其有效性需另证，不能将这个特定锥的障碍外推为更大的锥或整个方法不可能。
