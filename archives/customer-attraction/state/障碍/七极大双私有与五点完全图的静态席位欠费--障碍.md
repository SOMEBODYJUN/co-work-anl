# 完整实例与所限制的步骤

采用[共同目录完整历史模型](../定义/共同目录完整历史模型--定义.md)。客户为两个不同私有客户 $p_0,p_1$ 和十名互不相同客户 $x_{jk}$，其中 $2\le j<k\le6$。目录恰含七个标签，其覆盖为

\[
B_0=\{p_0\},\qquad B_1=\{p_1\},\qquad
B_j=\{x_{jk}:k\in\{2,\ldots,6\}\setminus\{j\}\}\quad(2\le j\le6),
\]

无序下标按同一客户理解。七个覆盖均非空、不同且两两不可比：两个单例含独有客户；任意两个四客户覆盖的交集仅为对应一条边，因此互不包含。共同核心为空。只有 $B_0,B_1$ 有全目录私有块，各大小1；五个其余标签各含四个共享客户，每名共享客户恰属于一对标签。

本对象限制[静态席位权重证书](../引理/极大关联的静态席位权重证书--引理.md)的一个具体充分步骤。它使用核心外席位

\[
f_j(k)=p_j/k+q_j/6,\qquad1\le k\le6,
\]

以全部42席中的第六大值为 $\nu$，并令 $a_j=1+\#\{k:f_j(k)>\nu\}$。私有客户只要求 $y_j\ge a_j$；非私有、核心外客户要求其关联标签的权重和至少6。这是[修正后的共享专属合同](../资源/极大关联席位原稿的字面合同与核心私有勘误--资源.md)，不把私有客户重复强制为 $y_j\ge6$。

# 第六席与十九单位最优权重

两条私有路由的席位都是 $1/k$；其余五条路由的每席都是 $4/6=2/3$。全局严格大于 $2/3$ 的只有两个私有首席，故

\[
\nu=2/3,\qquad a_0=a_1=2.
\]

无私有块的五条路由没有私有下界。权重问题恰为

\[
\min\sum_{j=0}^6y_j,\quad y_0,y_1\ge2,\quad
y_j+y_k\ge6\ (2\le j<k\le6),\quad y\ge0.\tag{P}
\]

十条完全图边约束求和，每个顶点出现四次，给

\[
4\sum_{j=2}^6y_j\ge60,\qquad \sum_{j=0}^6y_j\ge4+15=19.
\]

取 $y_0=y_1=2$、其余每个 $y_j=3$，全部约束成立并达到19。因此是准确最优值，不只是一次浮点求解或未达到的下界。

同一结论的非负对偶证书为：两个私有下界各权1、十条边约束各权 $1/4$。每个私有变量负载1；每个完全图变量负载 $4/4=1$；对偶目标 $2+2+6(10/4)=19$。这与上述原始点匹配，直接证明弱对偶等号，不依赖优化器。

六人因子二的这一充分接口要求 $\sum_jy_j\le2n=12$，所以本实例使其失败。有效的静态保底 $W\ge n\nu=4$ 没有被反驳；只是它与这套权重条件无法单独支付所需的全并集半覆盖。

# 该目录仍有真实半覆盖保证

全并集大小12。选择两个私有标签和任意四个完全图标签，共六主题，已覆盖全部客户：完全图中只省略一个顶点，不存在两端都省略的边。因此 $\operatorname{OPT}_6=12$。

更强的真实付款来自已有[分数覆盖数至多9/2的六人定理](../定理/六人分数覆盖条件半覆盖--定理.md)。赋 $B_0,B_1$ 各权1，其余五标签各权 $1/2$。每个私有客户得到总权1，每条边客户两端各半，总权1；总成本为 $2+5/2=9/2$。所以此目录的**每份完整有序历史纯SPE** 都有 $W\ge6$。这一步复用已有全历史定理，不构造或运行一份新完整策略，也不声称最差福利恰为6。

原笔记说“两块以上私有的剩余缺口”是原探索时的语境。本实例不能继续用作当前两私有情形尚无half证明的证据：后继定理已经覆盖它。它仍精确保存了指定静态席位权重方法的失效机制，与[四极大静态欠费](静态席位统一因子二与四极大欠费--障碍.md)属同一种付款步骤的不同真实关联实例；不同实例不能按来源时间自动连成数学推导。
