# 实际遗漏客户删除与可信根门槛的无界敏感性

被反驳的 DEL-OMIT 接口是：若目标终局可由某份完整纯 SPE 实现，删掉该终局实际没有覆盖的客户后，允许**重选全部离轨续局**，目标仍可由某份完整纯 SPE 实现。本对象给真实单位客户反例，并给单名客户删除引起可信根门槛无界跳变的固定五人五主题族。它远离 half 违规，不改变[共同目录模型](../定义/共同目录完整历史模型--定义.md)或[已有五人定理](../定理/五人半覆盖--定理.md)。

## 1. 输入与目标收益

主题次序为 \((A,C,D,E,F)\)，五名单位提供者，共同目录由这五个互异覆盖集合构成。每行重数表示不同单位客户；只有 \(E\)-private 行先用辅助实参数 \(t\in[0,1]\)。

| 兴趣类型 | 重数 |
|---|---:|
| \(A\) | 3 |
| \(AC\) | 7 |
| \(AD\) | 1 |
| \(CD\) | 1 |
| \(E\) | \(t\) |
| \(ACE\) | 1 |
| \(ACDE\) | 2 |
| \(CDE\) | 1 |
| \(ACF\) | 5 |
| \(DF\) | 2 |
| \(CEF\) | 2 |
| \(DEF\) | 10 |

非参数行共35名客户。目标计数及一个实现顺序为

\[
c=(2,1,0,0,2),\qquad (F,F,C,A,A).
\]

它覆盖全部35名非参数客户，遗漏全部 \(E\)-private 客户，收益依顺序为
\((23/3,23/3,7,19/3,19/3)\)，福利35，与 \(t\) 无关。\(t=0\) 时仍保留合法且不同于其它主题的 \(E\)。实参数只作共同代数分析；所有用来反驳原单位客户接口的实例都在下面整数化。

## 2. 全部可实现终局与可信门槛

令 \(R_t(q)\) 为计数前缀 \(q\) 后、余下 \(5-|q|\) 名玩家的**全部**完整有序历史纯 SPE 可实现终局计数。选择标签 \(a\) 的收益为
\(U_a(z;t)=\sum_{B\ni a}w_B(t)/z(B)\)，仅在 \(z_a>0\) 时使用。定义

\[
M_t(q)=\max_a\min_{z\in R_t(q+e_a)}U_a(z;t),
\quad R_t(q)=\bigcup_a\{z\in R_t(q+e_a):U_a(z;t)\ge M_t(q)\}.
\tag{1}
\]

终局层为 \(R_t(z)=\{z\}\)。这是[可信续局菜单](../算法/可信续局菜单与完整策略重构--算法.md)的必要充分递推：当前任何策略都必须应对每个孩子的真实续局，其收益至少为该孩子最小值，给必要性；反向对实际孩子保目标，对其它孩子各选达到最小当前收益的子 SPE，可独立拼接所有有序子树，给充分性。缓存的是可实现集合，不要求同计数的两个有序历史采用同一动作。

对本表完整计算得到：

| 参数区间 | 根终局全集 \(R_t(0)\) | 根可信门槛 \(M(t)=M_t(0)\) |
|---|---|---:|
| \(0\le t<3/4\) | \(\{(2,1,1,0,1)\}\) | \(33/4\) |
| \(t=3/4\) | \(\{(2,1,1,0,1),(2,0,1,1,1),c\}\) | \(7\) |
| \(3/4<t\le1\) | \(\{(2,0,1,1,1),c\}\) | \(7\) |

尤其

\[
\boxed{c\in R_t(0)\iff t\ge3/4.}\tag{2}
\]

门槛是对子 SPE 全集取最坏续局后再选行动，不是静态安全值，也不是某棵指定策略的实际根收益。

### 为什么有限有理计算覆盖所有实参数

五主题五人有126个终局计数。每个占用标签收益为一条仿射线
\(\alpha_{z,a}+t\beta_{z,a}\)：当 \(a\ne E\) 时斜率0，\(a=E\) 时斜率 \(1/z_E\)。将全部终局的全部占用标签收益取并集，恰有211条不同线。枚举任意两线在 \([0,1]\) 的交点，加端点，共65个分点；每个分点和相邻开区间中点合计129个代表。完整的线、切点和129行递推结果保存于[参数证书](../../tools/evidence/omitted-deletion-parameters-and-reentry-primary/single-new-run/output/parameter-partition.json)。

在任一开区间里，全部可能终局收益线的弱序固定。终层集合固定；若所有孩子集合与收益比较的达到关系固定，则 (1) 的 min/max 达到者及筛选集合也固定，向上归纳可知所有 \(R_t(q)\) 恒定。真实节点比较只来自这些已列出的线，没有漏掉未被某个默认策略选中的终局。恒等相等的线一直相等，交点另作精确计算，所以任意平局没有丢失。

新定义级 Fraction 计算在全部129代表上直接执行 (1)，得到上表。两条常数线 \((\alpha,\beta)=(33/4,0),(7,0)\) 本身都属于211条线。每个开区间内 \(M_t(q)\) 由固定达到关系选出某条候选线；若根所选线在中点等于上表常数而斜率非零，该点就是它与相应常数线的交点，应已列入分点，矛盾。因此门槛常数也覆盖整个开区间。全部分点直接精确计算。这个论证将完整有限证书提升为 (2) 与门槛公式的全参数证明，不是从129个任意样本外推。

程序还在 \(t=3/4,1\) 各展开一棵完整有序策略，实际顺序 \((F,F,C,A,A)\)，每棵781个决策历史、3905项含自行动比较（3124个不同备选）。[两棵新证书](../../tools/evidence/omitted-deletion-parameters-and-reentry-primary/README.md)保存全部动作，另在所有129代表检查这个指定顺序的成员条件。程序与证明只用上表客户输入及定义，没有依赖缺失旧 solver 或旧 schema。

## 3. 删除后短切口排除所有策略

\(t=1\) 是36名实际单位客户，\(c\) 可实现且唯一遗漏客户为 \(E\)-private。删除它变成 \(t=0\)，由根全集知 \(c\) 对任何完整策略都不可实现，已经否定 DEL-OMIT。

还能定位每种目标顺序共同面对的严格切口。任何目标顺序都有第二次 \(F\)，其此前计数必为
\((a,c',0,0,1)\)，\(0\le a\le2,0\le c'\le1\)，共六态。删后在每态强制 \(D\)，(1) 的完整终局集合都唯一为 \((2,1,1,0,1)\)，当前收益 \(47/6\)，而若继续原目标的第二次 \(F\)，当前最终仅 \(23/3=46/6\)。[六态精确记录](../../tools/evidence/omitted-deletion-parameters-and-reentry-primary/single-new-run/output/deletion-six-prefix-cut.json)给每项集合和值。因此每一种目标顺序都存在严格赚 \(1/6\) 的偏离，且任何合法子 SPE 都无法惩罚。这不是“原先那一棵策略删后失效”的弱结论。

关键末层开关也可直接从客户表计算。历史计数 \((2,0,1,0,1)\) 后五行动收益为

\[
(17/3,\ 77/12,\ 23/4,\ 17/3+t,\ 25/4).
\]

\(t<3/4\) 唯一最佳为 \(C\)，\(t=3/4\) 时 \(C,E\) 平局，\(t>3/4\) 唯一最佳为 \(E\)。选择 \(C\) 使旧 \(D\) 获 \(47/6\)，选择 \(E\) 时旧 \(D\) 仅 \(20/3\)，目标 \(F\) 的 \(46/6\) 位于两者之间。遗漏客户不改变在轨任何收益，却通过离轨末回复切换改变更早威胁。一个末节点只能解释机制；全部参数充分性仍由上一节完整证书承担。

## 4. 一名实际客户的无界门槛影响

对任意整数 \(s\ge1\)，令 \(q=4s+1\)，全部35名固定客户类型重数乘 \(q\)，\(E\)-private 原有 \(3s+1\) 名，删一名后剩 \(3s\) 名。归一化参数为

\[
t_+=\frac{3s+1}{4s+1}>\frac34>
t_-=\frac{3s}{4s+1}.
\]

收益齐次性和全参数结果给

\[
c\text{删前可实现、删后不可实现},\quad
M_+=7q,\quad M_-=(33/4)q,
\quad\boxed{M_--M_+=(5/4)q\longrightarrow\infty.}
\tag{3}
\]

这里仅删一个单位客户，不是减一个有理客户权重。目标在轨收益为原五数乘 \(q\)，福利 \(35q=140s+35\) 不变；删前总数 \(143s+36\)、删后 \(143s+35\)。五个目录主题全选可覆盖所有客户，故最优福利就是各总数，目标明显仍满足 half。

关键末节点的 \(E-C\) 收益差在删前为 \(+1/4\)、删后为 \(-3/4\)，两端严格。没有证明全树所有激励都严格，不能称 strict-SPE 族。一般 \(s\) 来自全区间与齐次缩放；新程序 \(s=1,\ldots,30\) 仅补核这些代数式。

## 5. 真正否定的接口与审查先验

本族否定：删除实际遗漏客户后保目标可实现；单名遗漏客户对可信根门槛有统一绝对 Lipschitz 常数；仅凭在轨收益不变就认为完整可信威胁不变。它不否定允许显式续局切换信用的参数归纳，也不自动否定任何总福利或真正安全值桥。

还有一项可保留的一般参数结构：固定一份完整策略，终局行动不随 \(t\) 改变，每条真实 IC 都是 \(t\) 的仿射弱不等式。因此它在 \([0,1]\) 的可行参数域是有限闭半空间的交，即闭区间，允许为空或单点。完整动作表总数有限，固定目标计数的可实现参数集就是所有实现该目标的策略可行区间的有限并，所以它也是闭集。这解释了 (2) 的边界可包含 \(3/4\)，但不给删除后的目标保留性或门槛连续性；不同策略区间可在边界出现或消失，仍需支付实际续局切换。

与[保原子策略删背景的激励缺陷界](../引理/固定插入共同池与删除后的原策略激励界--引理.md)不同：那里删的是固定过去提供者背景、保同一策略映射；这里删客户、允许全部策略重选，仍保不了目标。与[单叶钱包任意深度障碍](任意深度子博弈的删除缺陷与单叶付款障碍--障碍.md)也不是同一个量词。

原独立审查从定义重建 \(t=0,1\) 端点及六前缀短切口，称逐行检查作者参数程序但没有重跑129代表；原作者另称全参数分区和完整证书。本批取得五份当前 clean 源并完成约简重放与参数投影核对，故此前“旧代码/JSON 本地缺 blob”只保留为历史证据状态，不再描述当前源。实际命令、源码 SHA、全部输出和证据身份见[资源](../../tools/evidence/omitted-deletion-parameters-and-reentry-primary/README.md)及本批证据包。
