# PC的准确人数与独立性

固定[单位客户共同目录模型](../定义/共同目录完整历史模型--定义.md)任意m≥1及任一完整历史纯SPE，实际福利W。客户集、**整个目录**保持不变，另看n=m+1玩家同时行动的静态游戏，令

\[
C_n=\min_{\mu\in\operatorname{CCE}_n}\mathbb E_\mu W(s).
\]

CCE允许任意相关/玩家不对称分布，每人对每个固定主题T都满足E u_i(s)≥E u_i(T,s_−i)。不是顺序偏离，不看见抽样s后再挑T；有限游戏CCE非空紧，最低值达到。未证候选为

\[
\boxed{C_{m+1}/(m+1)\le W/m.}\tag{PC?}
\]

PC比较**跨人数平均值**，不是已失败同人数C_m≤W，也不同于仍需独立判断的弱桥W≥(1−1/(2m))C_m。后者的[占用LP](较弱CCE福利桥的占用LP表示与边界--候选.md)是相同技术但不同目标，不能混用反例。

# 安全下界与正确的条件half归约

静态安全值v_n(0)=max_p min_(q∈S^(n−1)) E_(T∼p)Σ_(x∈T)1/[1+c_x(q)]，竞争元组在独立查询之前联合确定。有限minimax和紧性给最优p*。对任何CCE，每位固定行动约束按p*混合得

\[
E_\mu u_i(s)\ge E_{s,T}u_i(T,s_{-i})\ge v_n(0),
\quad C_n\ge n v_n(0).
\]

即使s玩家之间相关，T仍独立且s_−i为合法n−1槽背景，所以最后一式逐背景成立。原顺序SPE没有被用于这条静态事实。

再用已证[静态额外槽预算](../引理/合法前缀的静态额外槽预算与条件归约--引理.md)OPT_m≤2m v_(m+1)(0)。承重理由可简述：对任意m槽竞争混合Q，L=E c、M=max_TΣ_(x∈T)1/(1+L_x)，Jensen给max_T E_Qf(T)≥M；最优m元组逐客户覆盖≤(d_x+L_x)/(1+L_x)，d项≤mM，而L是总质量m的合法主题混合，L项也≤mM。故OPT_m≤2mM≤2m max_T E_Q f；对Q取min即得该界，无SPE假设。

若PC成立，则W≥m C_(m+1)/(m+1)≥m v_(m+1)，合静态界便2W≥OPT_m。这只证明**条件蕴含**；PC比自由安全聚合W≥m v_(m+1)更强，未来若PC失败也不否定自由安全或half。当前五人half另证，不能倒推PC。

# 完全任意CCE的精确计数LP

将任一CCE按玩家置换均匀对称化，福利不变、每人全部固定行动约束仍成立。每个无序主题计数q（Σq=n，允许重复）代表其全部有序排列的均匀分布；令c_x(q)客户负载。对固定T，把n个玩家各自单独删当前动作再插入T，客户x∈T的总收益为

\[
R_q(T)=\sum_{x\in T:c_x>0}\frac{n+1}{c_x+1}
+n\,|T\setminus\{x:c_x>0\}|.
\]

c>0时，原覆盖x的c人各改T得1/c，共1；其余n−c人各得1/(c+1)，总(n+1)/(c+1)。c0时n人各得1，故单列n；没有0/0。

对称分布下每人对T的期望偏离损失恰[E W−E R_q(T)]/n，因此精确有

\[
C_n=\min_{\theta_q\ge0,\ \sum\theta_q=1}\sum_q\theta_qW(q),
\quad \sum_q\theta_q[W(q)-R_q(T)]\ge0\quad\forall T.
\]

必要性由CCE各人约束相加；充分性由每个q均匀打乱玩家，再以上式除n得每人每固定T约束。不是只检iid，也不是把聚合约束施在不对称原分布就声称各人成立。此LP计算的是n=m+1静态CCE，原m-SPE福利另给。
