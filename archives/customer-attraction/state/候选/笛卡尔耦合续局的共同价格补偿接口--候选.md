# 开放问题的准确输入与已知对象

采用[完整历史CAG模型](../定义/共同目录完整历史模型--定义.md)，有限正个不交单位客户分量、相同m≥1、非空真实集合目录，联合动作是完整Cartesian主题。固定联合游戏任意完整有序历史纯SPE σ；后继可以跨坐标依赖全部历史与平局。候选问：能否在这种真实耦合下建立从分量信息继承的共同补偿预算，从而控制实际最小收益处的全客户价格？源没有给一般补偿公式、证明或coupled-policy分解，本页仍保开放。

对任意联合终局，各分量实际投影仍是合法**终局**，所以u_i=Σ_j u_i^j、W=ΣW_j，但不自动是分量均衡终局。菜单曲线及价格按[表示定理](../定理/笛卡尔目录的共同质量覆盖与非负价格卷积--定理.md)有F_prod(t)=ΣF_j(t)和达到的非负价格拆分。设a_j=min_i u_i^j，a=min_iΣ_ju_i^j，则a≥Σa_j；若另有各B_j(a_j)≤W_j，纯代数已给B_prod(a)≤W，不需把投影策略先冒认为SPE。真正缺少的是这些投影预算或可支付其超支的跨坐标机制。

因此不能用“原游戏收益可加”替代“任意联合SPE坐标独立”。同一坐标在同样本坐标历史后，可因另一个坐标过去不同而选择不同可信续局；单坐标偏离会改变其余坐标收益。P1只从给定分量完整SPE构造一份乘积SPE，P4只说明已有效的分量价格预算在这些指定乘积中保持。天真独立乘积不能放大既无违反的分量策略。

# 全仓已有的反面与正面条件

已有[三人福利非可加反例](../反例/笛卡尔目录的福利非可加性--反例.md)：三行各a客户、两色各q客户，整数q≥a≥1，六主题为行/色乘积。两个分量每份SPE均全覆盖，但联合完整SPE可沿((0,0),(0,1),(1,0))，收益((a+q)/2,a/2+q,a+q/2)，只覆盖W=2a+2q，低于分量最优和3a+2q。中间人改行本可增a/2，却触发末位在色平局中转而分享其中间人的色，损q/2；可信跨坐标平局正好补偿。这一已完成反例否定所有联合SPE最差福利自动可加，不是本三源的新反例或审计运行。

它也没有否定本候选的价格目标。本轮从该已读解析族可直接比较菜单曲线
\[
F_{prod}(t)=a\min(t,3)+q\min(t,2).
\]
该指定策略最小收益v=(a+q)/2；利润在t2前斜率(a+q)/2>0，t2到3斜率(a−q)/2≤0，其后负，故
\[
B_{prod}(v)=a+q=W/2\le W.
\]
q=a时t2..3同为最大，仍达到。这是本轮解析对照，不是缺失audit原结果，也不把一族中的通过当任意coupled-policy定理。福利组合失败与最小价格桥失败是不同对象。

正面方面，已有[全体玩家续局支付唯一的乘积分解](../定理/全体玩家续局支付唯一的乘积分解--定理.md)假设每分量**每个合法历史**的全部SPE对全部m名玩家收益向量相同，包括已经行动者；则联合可实现SPE终局集合恰为分量集合乘积。它足以排除额外coupled终局，不声称联合策略必须字面独立，也不是必要性分类。只知分量根福利唯一或末位本人收益唯一不足；上面的色平局改变前缀玩家收益，正违反该强条件。

# 与根价格和安全值目标的衔接

若一般联合完整SPE能在某个实际最小收益位置得B_prod(v)≤W，最优m查询和mv≤W便给half；三主源没有证明这个全称预算。更弱的[真实后继超额价格候选](后继超额保留的最小收益价格桥--候选.md)允许右侧W+Σ_(j>i)(u_j−u_i)_+，其实际最小位置的half推导已有独立正式页，也尚未普遍闭合；不要把它和本较强W预算混为同一断言。

真正oblivious静态安全值在菜单乘积中可加，但其对手不知道本次抽样查询。它不控制能观察全部历史的后继，已有[静态安全值定理](../定理/静态混合安全值的锐目录计数界--定理.md)也不保证每个SPE玩家达到该静态值。覆盖矩/客户分数负载表示保菜单数值，仍不能免费把任意完整策略的根IC投影成各分量的根IC；需要实际控制跨坐标续局或另给强条件。
