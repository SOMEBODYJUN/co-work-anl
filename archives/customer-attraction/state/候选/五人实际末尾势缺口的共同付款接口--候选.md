# 已证上界和未证下界分开

在五人零背景共同目录游戏固定任意完整有序历史纯SPE，实际终局为A,B,C,D,E，收益u₁,…,u₅，总覆盖W=Σu_i，O=OPT₅。目录为有限非空标签集合，空主题、重复选择、同覆盖不同标签、零客户、离轨历史和任意弱平局均保留。令
\[
 P=u_1+u_2+u_3,\quad h=O-W\ge0,\quad d=u_4,\quad e=u_5.
\]
q为实际前三主题的客户负载；令
\[
 \Phi_q(T,R)=\sum_x\sum_{k=1}^{1_T(x)+1_R(x)}\frac1{q_x+k},\quad
 \Gamma=\max_{T,R\in\mathcal S}\Phi_q(T,R)-\Phi_q(D,E)\ge0.
\]
本文完整重构的无条件上界是
\[
 \boxed{P+\Gamma\le\frac{49W-13O}{36}.}\tag{UP}
\]
由它得到一个**充分候选**：若所有五人完整SPE另满足
\[
 \boxed{P+\Gamma\ge\frac{23}{72}O,}\tag{PAY}
\]
则五人半覆盖成立。原文和原独立审查没有证明(PAY)。仓库后续已有[五人半覆盖证明](../定理/五人半覆盖--定理.md)，这校正了原入口的“half仍OPEN”，但不能反推(PAY)成立。

# 三条合法事实在同一实际终局付款

定义
\[
 F_q(T)=\sum_{x\in T}\frac1{q_x+1},\quad
 g_q(T,R)=\sum_{x\in T\cap R}\frac1{(q_x+1)(q_x+2)},\quad t_q(T)=g_q(T,T).
\]
固定五个达到O的比较索引T_j，并让R_j=σ₅(A,B,C,T_j)。所有下列预算都取自原同一策略及实际D,E，不能从互不相容的后继另取较大收益。

**倒二真查询。** [倒二真实查询行](../定理/倒二真实查询行及三人返还边界--定理.md)给
\[
 \sum_{j=1}^5U_q(T_j,R_j)\ge O-W+t_q(D).
\]
而原倒二节点的每一真实偏离不优于d，因此
\[
 5d\ge h+t_q(D).\tag{1}
\]
这里的回复随T_j变化，不把其固定为实际E。

**末两人强PAIR。** [重叠比较引理](../引理/末两人重叠比较与任意索引聚合--引理.md)证明，对于任意合法T,R，
\[
 d+e+g_q(D,D)\ge F_q(T)+F_q(R)-g_q(T,R)=\Phi_q(T,R).
\]
实际\(\Phi_q(D,E)=d+e+g_q(D,E)\)，相减并对T,R取最大得到
\[
 \Gamma\le g_q(D,D)-g_q(D,E)=t_q(D\setminus E)\le t_q(D).
\]
对每个x∈D\E，其倒二收益为1/(q_x+1)，而税为该值除以q_x+2；D∩E只增加倒二收益。因此
\[
 \Gamma\le d/2.\tag{2}
\]
这是强PAIR对**两槽势增量**的控制；把势直接叫作尾两人收益会少掉重叠项。

**末位真预算。** [真实前缀利润预算](../引理/分数覆盖的真实前缀利润预算--引理.md)在五人最后位置给
\[
 O\le W+4e,\qquad e\ge h/4.\tag{3}
\]
可直接看出：五个最优主题的末位查询各不超过e；其和至少为比较并集上的Σ1/(b_x+1)，b为实际前四负载。逐客户O−(W−e)不超过该和，故O≤W−e+5e。该逐客户界在无覆盖、重复最优槽及零客户时仍有效。

# 线性消元和常数

由(1)(2)有Γ≤min(d/2,5d−h)。结合(3)及P=W−d−e，得到
\[
\begin{aligned}
 P+\Gamma
 &\le W-h/4+\min(-d/2,4d-h)\\
 &\le W-h/4-h/9=W-13h/36.
\end{aligned}
\]
最后一步仅有两种情形：d≤2h/9时，4d−h≤−h/9；d≥2h/9时，−d/2≤−h/9。于是得到(UP)，无需假定h>0或除以h。

若(PAY)成立，则
\[
 \frac{23O}{72}\le\frac{49W-13O}{36}
 \Longrightarrow49O\le98W\Longrightarrow O\le2W.
\]
这是条件蕴含，不能把尚未证明的左端下界隐藏在“消元完成”一词里。

# 与旧ONE-GAP和局部安全盈余的关系

令v₅是原共同目录上五人零背景的静态混合安全值：查询分布与四槽对手配置独立，之后按原均分份额付费。它不是实际末位收益u₅，也不是在q背景上的局部两人安全值w(q)。原更强候选为
\[
 P+\Gamma\ge3v_5.\tag{ONE-GAP}
\]
[静态混合安全值的锐目录计数界](../定理/静态混合安全值的锐目录计数界--定理.md)给O≤9v₅，因此3v₅≥O/3≥23O/72；O>0时最后一步严格。故ONE-GAP足以推出(PAY)，反向并未得到证明。

原付款稿引用旧两单点五人例，给实际路径(0,1,1,1,0)、P=7/6、Γ=0、O=2、v₅=1/3，并指出把ONE-GAP右端改为3u₅会失败。本14来源没有该旧例的完整策略原件，故此处只保留其**引用及逻辑用途**，不新增完整SPE资格认证：原给定数字满足P≥3v₅和P≥23O/72，却不足以付所引用的3u₅=3/2。一个关于u₅的加强失败，不能否定关于v₅的原候选。

本批真正保有完整策略及原独立核验的，是[十三客户反例](../反例/实际五人尾部势缺口的局部安全盈余反例--反例.md)：实际Γ=1/5、u₄+u₅−2w(q)=1/10，否定局部安全盈余支付；同时P+Γ−3v₅=188/255>0、P+Γ−23O/72=1337/360>0。因此它也没有解决或否定上述两个全局候选。

# 形式临界点与零规模边界

若只从本接口考察O>0、W=O/2，并且消元链全部取等，则必有
\[
 d=O/9,\qquad e=O/8,\qquad\Gamma=O/18,\qquad P=19O/72.
\]
此外Γ=d/2迫D上的每个单位客户都不在实际前三主题，也不在E：在D\E上税/收益比例1/(q+2)只有q=0时达到1/2，在D∩E上税为0而收益为正。因此D与A∪B∪C∪E不交、d=|D|。这些只是该旧接口的**必要取等条件**，不证明有这样一份完整SPE，更不是half锐性认证；其他真实节点还可排除它们。

W=0时根改选任意合法主题至少获其大小的五分之一，故所有主题覆盖空、O=0；所有式子均为0，无需定义O/W。h=0时同一消元仍成立。背景q来自实际前三步；不能把零背景五人半覆盖定理直接套成带既有用户负载的五人游戏，也不能把这里三个早期收益换成六人中任意三人的收益。

# 来源价值与下一步义务

原付款稿和独立审查共同贡献了(UP)、常数23/72、取等必要条件及u₅/v₅的纠错；即使后来half已由另一证明完成，这些仍是可复用的接口和未决加强。原预算分支的十三客户见证则精确排除一条局部支付捷径。本次对本页证明只做解析重构，数学程序执行0；十三例的一次原独审另在反例页列出，不重算为本页新执行。

若接续(PAY)或ONE-GAP，需从同一原策略的真实早期子树获得尚缺的共同下界，或给出对应全称命题的合法完整SPE反例；只检查一个尾部、分别满足个体安全值、在必要行锥找到坏点，都没有支付这份下界。第三阶段应分别记录“已证上界”“充分候选蕴含”“局部加强被反驳”“half后续已证”四种关系。
