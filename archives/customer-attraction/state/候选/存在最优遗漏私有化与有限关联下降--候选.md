# 一步合法变换和承重存在量词

模型为[有限单位客户共同目录及全部有序历史纯SPE](../定义/共同目录完整历史模型--定义.md)，人数m≥1任意。给实例I和完整SPE σ，实际有序终局z、覆盖客户集K、W=|K|。可选择一个**真正最优**m主题元组C，O=∪C，故|O|=OPT_m(I)。对每个不同单位客户x∈O\K，从C中原本覆盖x的主题选owner t(x)，删除其对其他主题的兴趣；其余客户完全不变，得I'。相同类型的多个单位客户可分别选owner，不能强制整类相同选择。O外的原遗漏客户不修改。

无条件有：每个主题覆盖只缩小，所以OPT(I')≤OPT(I)；C仍覆盖全部O，因为O∩K客户不动，O\K客户由C中的owner保留，所以反向不等式成立，**OPT精确不变**。旧z上没有修改客户被覆盖，因此其覆盖K、W和全部玩家收益精确不变。最后一条只算同一个叶，不能推出旧σ仍为SPE，更不能推出有任何新SPE实现旧z。真实离轨威胁的可信性正可能改变。

以下四候选都对**每个I、每份完整σ**要求**存在某个真正最优C、全部逐单位owner以及某份I'的完整纯SPE τ**：

| 名称 | τ的实际终局要求 |
| --- | --- |
| E-path | 等于原有序主题路径z；同覆盖别名合并时作自然映射 |
| E-count | 等于原终局主题计数；同样明确映射 |
| E-cover | 实际覆盖客户集合恰为K |
| E-defect | 实际福利W'≤W，不要求路径、计数或覆盖身份 |

有E-path⇒E-count⇒E-cover⇒E-defect。计数相同给覆盖相同使用的是固定改造目录，而改造又未影响旧z上的任何客户。OPT已保持，故E-defect等价于坏差OPT−2W不减。四项均未证明；不可把预先固定C的全称版本与这里的存在C互换。

E-path/E-count/E-cover若普遍成立，单步所得实际覆盖仍为K，因而C的实际遗漏全是只属于一个主题的客户，可直接调用[私有遗漏锐界](../定理/实际遗漏私有席位谱与锐界--定理.md)。E-defect的新路径却可能遗漏旧K中的共享客户，不能单步声称所有新遗漏私有。

# 最弱E-defect的条件性有限下降定理

**条件命题。** 假设E-defect在上列全部输入上成立，则对全部人数m及全部实例、每份完整纯SPE都有

\[
\operatorname{OPT}_m\le(2-1/m)W.\tag{D}
\]

证明时可暂保留有限主题标签，允许同覆盖别名。定义非负整数

\[
L(I)=\sum_{x\in N}|\{a:x\text{喜欢标签}a\}|.
\]

从任意(I0,σ0)出发。每轮依假设选最优C、owner和新完整SPE，保持OPT，福利不增。先检查本轮所选最优O的实际遗漏O\K：若每一客户全局只喜欢一个主题，则这些客户各属于某个极大全局私有块。原因是其唯一主题若严格包含于另一个合法覆盖主题，该客户也会喜欢后者，矛盾；故唯一主题本身极大。私有遗漏定理的条件“**某个**最优并集的实际遗漏全为极大全局私有”成立，即得该轮(D)。O\K为空时同样立即停机。

否则至少一个被改造遗漏客户原来喜欢两个以上标签，本轮将其兴趣缩为单个owner，其他修改也只删除，故L严格下降至少1。继续对新实例及所选完整SPE应用假设；最优比较和owner可以逐轮改变。非负整数L不能无限严格下降，最终必停在上述私有遗漏情形。末轮OPT等于初始OPT、末轮W≤初始W，将私有锐界向前传回即得(D)。无须保留原路径、原遗漏身份、同一C或同一σ。证毕。

该推导只把**未证E-defect**转成已知条件定理的前提；它不是E-defect的证明，也不是一般(D)的无条件证明。它若成立会给一般锐常数2−1/m，强于half；不能把“这条路线足够强”误写成已解决六人目标。

# 同覆盖标签不能直接商给定策略

主题缩小后可能出现同覆盖标签。对SPE可实现的**覆盖主题多重集**，复制或删除同覆盖别名不改变集合；但一份给定历史依赖策略不能直接商掉。

可用集合值BI证明前一断言。剩余零人时按覆盖映射相同。归纳时，相同覆盖别名的孩子博弈在映射后有同样可实现终局集合，当前人在任一映射叶的收益也相同。其每行动最低可实现当前收益相同，故门槛max_a min_child u_a不受复制/删别名影响；门槛以上可保留叶的映射并集也相同。每个有序历史的后继子树仍独立重构，这保留了任意历史依赖平局，没有施加计数策略约束。

因此E-defect有限下降可全程保留标签，末轮再合并；也可每轮合并，L只会进一步下降。若以无别名集合目录表述假设，每轮先合并、在商目录用E-defect、再任选代表提升即可。E-path/E-count的表述则必须在定义时固定相应标签映射，不能据此声称给定别名σ原样仍为SPE。

# 已知反例与真正的反例搜索义务

[固定最优私有化分离](../反例/固定最优遗漏私有化的完整可信性分离--反例.md)给m3、OPT36、原可达W34。固定全Y比较后owner唯一，全部新SPE W36；改选全X比较却保原有序终局。它证明选择C的存在量词承重，未否定本页任一存在C候选。

E-defect的真正反例必须给原完整σ，并对**全部真正最优元组、全部逐单位owner选择**证明新实例每份完整SPE福利都严格高于原W。只否定原σ、原路径、原计数、一种C、一种owner或整类统一owner均不够。相比之下，[原P0有限探针](../程序/可信全菜单与遗漏私有化的双攻击合同--程序.md)允许owner来自任意原兴趣而非某个最优C，并要求原计数可实现；其300提案、33原终局的阴性记录不核验本页E-defect的精确量词。
