# 同一原策略的真实响应自洽背景

模型为[共同目录完整历史模型](../定义/共同目录完整历史模型--定义.md)。有限单位客户、有限非空共同标签目录、m≥2名单位提供者，保空主题、同覆盖不同标签、重复行动、全部离轨历史与任意平局。固定完整纯SPE σ，实际叶z=(B₁,…,Bₘ)，收益uᵢ，覆盖W=Σuᵢ。位置i在其实际有序前缀强制A后沿**同一原σ**完成，得真实叶Yᵢ(A)；删当前槽后的客户竞争负载记kᵢₓ(A)。所有真实IC给

\[
d_i(A)=\sum_{x\in A}\frac1{1+k_{ix}(A)}\le u_i.\tag{1}
\]

给主题分布p，定义主题边际及客户平均竞争负载
\[
q_T(p)=\frac1{m(m-1)}\sum_iE_{A\sim p}\#\{j\ne i:Y_i(A)_j=T\},\quad
\mu_x=(m-1)q_x,\quad g_T=\sum_{x\in T}\frac1{1+\mu_x}.
\]
q是分布，每个客户qₓ是其兴趣主题的总概率。SC条件为supp(p)⊆argmax_T g_T；此时G=E_p g_T=max_T g_T。它**不要求p=q**，也不要求q自由最小化所有主题插入价。源调用此前自洽点存在性，本文不以收缩性替代SC最优反应的存在证明。

# 保留静态竞争税，而非先丢掉它

置Q=E_qg_T=(m−1)⁻¹Σₓμₓ/(1+μₓ)。SC保证Q≤G。最优m元组的客户负载为dₓ，逐客户
\[
\mathbf1_{d_x>0}\le\frac{d_x+\mu_x}{1+\mu_x}.
\]
第一部分是m个合法主题价格之和，至多mG；第二部分恰(m−1)Q。因此
\[
\boxed{OPT_m\le mG+(m-1)Q.}\tag{2}
\]

由此依次有三条不同强度的**存在SC点**付款候选：mG≤W；(m−1/2)G≤W；以及最弱的
\[
\boxed{mG+(m-1)Q\le2W.}\tag{NET-SC?}
\]
后一式相对中式保留了(m−1)(G−Q)的静态总信用，即W预算中一半的该信用。它们是half的充分接口，源没有证明任何一般付款。m5代入是5G+4Q≤2W，不是五人新定理；当前[五人half](../定理/五人半覆盖--定理.md)来自另一完整证明。

若人为换成固定实际负载μ=(m−1)c(z)/m，恒等式会退为旧实际精确税目标；已有十三人反例只攻击那个**另一个背景**。不能把其反驳直接传给q(p)的SC存在付款，也不能因为完整根菜单另已失败而自动给本删当前槽边际定真假。

# 精确因果分解与未支付的相关债

固定过去的主题分布为
\[
r_T=\frac2{m(m-1)}\sum_{j=1}^m(m-j)\mathbf1_{B_j=T}.
\]
令R(A)为全部i强制A后的真实叶中严格未来j>i的主题计数，总量m(m−1)/2归一。每列R(A)也是概率分布。过去槽在每个强制叶均保持实际过去，所以**逐主题恒等**
\[
\boxed{q(p)=\tfrac12r+\tfrac12Rp.}\tag{3}
\]
R是列随机矩阵，故p↦q(p)的全变差Lipschitz常数≤1/2。这只是固定σ下的概率算子，不是完整SPE付款定理。对同一个价格函数g，
\[
G-Q=\tfrac12(G-E_rg)+\tfrac12(G-E_{Rp}g)\ge0.\tag{4}
\]
两个非负数来自SC价格最大性；不能把它们不经收益比较地视为实际已付利润。非理性的复制响应也可满足(3)，说明半固定过去的计数约束没有独自编码未来真实最优性。

设Dᵢ(v)=E_{A∼v}dᵢ(A)。对任何v，(1)给ΣᵢDᵢ(v)≤W。如果另能选一个SC点使
\[
\sum_i[D_i(p)+D_i(q(p))]\ge mG+(m-1)Q,\tag{TWO-QUERY?}
\]
则两份**原实际位置**的真实IC钱包共同推出NET-SC?。第二项必须在相同实际前缀强制q抽出的主题并真实回应；不能把被抽到的离轨竞争者自己的利润搬回实际位置，也不能让互斥叶各领一次W。源在这里明确留缺口，没有由(3)的几何级数支付它。

零客户G=Q=W0；m1直接最优、无需上述m−1归一。源第四/五轮的历史OPEN不覆盖当代五人定理；六人及一般half未由本页闭合。本文全读源及现行失败账本，解析重构(1)–(4)，0 LP/随机搜索；证据见[原件与读取账本](../../tools/evidence/mixed-sc-normalization-and-root-audits-primary/README.md)。
