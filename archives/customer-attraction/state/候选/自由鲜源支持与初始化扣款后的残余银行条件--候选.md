# 原目标固定，采购source可换合法主题组合

在[完整历史共同目录模型](../定义/共同目录完整历史模型--定义.md)中固定任意m≥1、有限单位客户和非空共同目录的一份完整纯SPE σ、实际叶Z、覆盖C、收益u_i及W=|C|=Σu_i。空主题、重复行动、零客户和全部离轨平局保留。原OPT_m始终取同一个实例的原值，令M=max(OPT_m−W,0)。M0时half目标已成立，不建立零分母source。

当M>0，3363B原尝试允许选任意合法m主题元组T′，只要求

\[
 F_{T'}=(\bigcup_iT'_i)\setminus C,\qquad |F_{T'}|\ge M.
\]

固定每个x∈F的owner i满足x∈T′_i，取0≤ρ_x≤1且Σρ=M。每role仍只有这一个source主题T′_i，允许不同roles重复主题。source query均在原actual前缀强制该合法主题、再沿同一σ真实完成；fresh客户在全部actual过去负载为0，故无INIT past份额。

T′不必仍是原最优元组；所要支付的量仍是**原M**，不能改成新并集大小−W。原最优元组至少提供一个足够fresh支持的选择，但这不保证其中任何选择好付。ρ是分析源量，不改变原单位客户价值、目录、策略或actual。

这是[自由删源TOTAL-TRIM](自由删源总价与半覆盖的充分接口--候选.md)的净目标思想的接续：原固定最优O下删|G|比较源使剩源OPT−W；当前再放宽可供source的合法tuple。两者都不把删掉源解释为actual G运输，不提供旧η、SOURCE-NET或另一份G信用。此处不声称新净券采购与旧gross Bellman总价是同一个优化，也不将其费用有利项拼接。

# 单次换主题的精确fresh支持余量

从原最优T、并集O出发，R=O\C、G=C\O，所以M=|R|−|G|。用合法A替换T_j，记E_j=T_j\∪_(k≠j)T_k为该主题在原tuple中的独占客户。新并集=(O\E_j)∪A。因此fresh损失是(E_j∩R)\A，新增fresh是(A\O)\C，两者不交，得到

\[
 |R'|=|R|-|(E_j\cap R)\setminus A|
 +|(A\setminus O)\setminus C|,
\]

\[
 |R'|-M=|G|-|(E_j\cap R)\setminus A|
 +|(A\setminus O)\setminus C|.
\]

右侧非负才保证这次新tuple仍可保足M source。丢失I=O∩C中的客户不直接减少fresh支持，但也不是新增actual资金。即便A是全目录最大fresh主题，只要净R损超过同一余量，就不能免费替换。多次接受新source组合时须重算整个当前fresh并集、同一个原M、owner、价格和context输入；不能每一步重新领取原|G|。

这个计数式只审source支持合法性，不优化路由或证明能找到满足下文钱包的替换序列。没有构造新游戏或扫描“最大fresh”主题样本。

# 初始化current的同一条IC与残余钱包

固定一份T′、owner、ρ和合法INIT方案。对owner i的真实query叶V_i=finish_σ(Z_{<i},T′_i)，source current精确吸收

\[
 \alpha_i=\sum_{x:o(x)=i}\rho_x/c_{V_i}(x).
\]

设其完整query利润为D_i、fresh部分为D_i^F、C部分为Y_i，原actual完整IC给D_i=D_i^F+Y_i≤u_i。因每客户ρ≤1，α_i≤D_i^F≤D_i≤u_i。若D_i^F>0，置θ_i=α_i/D_i^F≤1，e_i=u_i−D_i≥0，则

\[
 \alpha_i=\theta_i(u_i-Y_i-e_i).
\]

它是**同一source query**的整条IC乘单一标量、退同叶C与slack后的精确current金额；不是按客户重权IC或旧source过付。D_i^F0时α_i0、θ_i取0，不除零。一role只一个source主题的条件防止多个query各自再占整份u_i。

INIT其余captured总量注入natural contexts，记b_t≥0、其role汇总B_j=Σ_(i(t)=j)b_t、H=Σ_jB_j。本文B_j是**输入金额**，不是所选主题T′_j。源守恒为

\[
 M=\sum_i\alpha_i+H.
\]

先从同一actual钱包u_i扣α_i，只剩u_i−α_i≥0用于这些captured输入的最终净券。该分拆不继承η或SOURCE-NET。

\[
 \sum_{j\in F_q(x)}t_{qj}(x)
 =f_q(x)[c_q(x)-1]/c_q(x).
\]

出口进入父真叶的规定主题context并保真父见证；F空时captured量为0。允许把某客户全部captured量给其中一个合法future coverer，不等于能任意指定整个B向量、换任意新query或移到过去。B_j必须由这些合法出口共同产生。

在当前接合中，这项自由用于**INIT形成b_t**；接着冻结一份合法fresh净券核，用新的b_t重算全部流、β和终点金额。内部核须保持[SAFE/fresh](../定理/同节点安全净券与最大标量剪枝--定理.md)与[HIT](../定理/净券跨节点角色命中与来源后缀界--定理.md)的行概率/PRICE条件；可用已证保该条件的合法删正边核，不是任意集中。

# captured输入上的后缀HIT

fresh净核无past出口，future角色严格增加，故从role j的输入终点只能在j或更后。对K⊆[m]，令k_j=|K∩{j+1,…,m}|。j∈K时仅用最终进入K比例≤1；j∉K时去掉不可能到达的早期目标，再用全图HIT给≤k_j/(k_j+1)。若A(K)包括INIT current与captured图的最终净金额，线性求和得

\[
 A(K)\le\alpha(K)+B(K)+
 \sum_{j\notin K}\frac{k_j}{k_j+1}B_j.
\tag{RESIDUAL-HIT}
\]

这对**同一份**源、输入、内部核及重算后的图同时成立。空K为0，全K给守恒M；不是到K即强停，也不是同一外源质量可给多个K各自重复领券。对单目标K={i}，j>i无法到达、j=i比例≤1、j<i各≤1/2，所以

\[
 A_i\le\alpha_i+B_i+\tfrac12\sum_{j<i}B_j.
\]

这里的A_i已是安全非负净券金额，不是新的整行IC系数或原gross费用。把多context金额共同汇到同一actual role再比钱包，不能每个context各领一次u_i。

# BANK只是足够的共同容量条件

若能共同选择合法source、trim、INIT出流和固定合法内部核，使全部i满足

\[
 \boxed{B_i+\tfrac12\sum_{j<i}B_j\le u_i-\alpha_i,}
\tag{BANK?}
\]

则上式给A_i≤u_i；同一净券图的总金额ΣA_i=M，因此M≤W，推出**原OPT**≤2W。这是有效的条件推论，不是BANK总能实现、也不与实际cap可行等价。原两稿和本次均没有给共同存在性证明、可行LP、严格分离或新的全输入福利界。

把所有BANK相加，仅作代数即可见其粗包络要求

\[
 M+\tfrac12\sum_{j=1}^m(m-j)B_j\le W.
\]

额外项来自对每个后续目标分别使用同一“最多一半”上界；实际流仍只守恒M，**没有**真的多付该额外金额。因此这不是一般净券流的必要费用界，不可用它作原模型失败证据；它只是说明该逐role充分条件可能比净付款≤W更强。

末位真实BR确给每个合法主题A的fresh大小|A\C|≤u_m：在末位actual前缀，fresh客户旧负载零，强制A时各贡献1，而完整IC给该query利润≤u_m。但它没有控制来自多个互斥source叶合计的B_m，不能逐主题套一次便声称最后钱包已满付。
