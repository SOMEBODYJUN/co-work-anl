## 代码实际定义的计数对象

令 ([p]={0,ldots,p-1})，每个非空客户类型用兴趣集合 (Ssubseteq[p]) 表示，并给出非负质量 (w_S)。`counts(p,n)` 枚举

\[
 \mathcal C_{p,n}=\{c\in\mathbb Z_{ge0}^{p}:\sum_{a=0}^{p-1}c_a=n\}.
\]

矩阵 `M` 的行按掩码 (S=1,ldots,2^p-1) 排列，(M_{S,a}=1_{{ain S}})。对终局计数 (c)，代码计算

\[
 d_S(c)=\sum_{a\in S}c_a,qquad
 \pi_{a,S}(c)=
 \begin{cases}1/d_S(c),&a\in S, d_S(c)>0,\\0,&\text{否则},\end{cases}
\]

并以矩阵乘法得到

\[
 u_a(c;w)=\sum_{S\ne\varnothing}\pi_{a,S}(c)w_S,qquad
 W(c;w)=\sum_{S:d_S(c)>0}w_S.
\]

这正是单位客户在终局被所有覆盖者均分的**计数表示**；代码没有把 (w_S) 强制为整数客户重数。

`Fast.run` 的内部递归把计数前缀 (k) 当作唯一状态。若 (k) 尚未达到总长度，先递归每个孩子 (k+e_a)，再定义

\[
 \theta(k)=\max_{a\in[p]}\min_{z\in R(k+e_a)}u_a(z;w).
\]

对动作 (a) 的孩子，只保留 (z\) 满足 (u_a(z;w)\ge\theta(k)-10^{-8}) 的终局；终局 (k=c) 时返回相应的单点。根集合 (R(0)) 是这个**计数状态 DAG** 的可达终局并集。它把相同计数的不同有序历史合并，因而不等同于原模型中“每个有序历史可有独立续局”的完整策略空间。`run` 从 (R(0)) 中取所有正计数主题的最小收益

\[
 v=\min_{z\in R(0)}\min_{a:z_a>0}u_a(z;w),
\]

并以 (max_{c\inmathcal C_{p,n}}W(c;w)) 作静态计数上界，报告 (2nv/\max W)。这只是计数状态地板比率。

主程序使用 `numpy.random.default_rng(2277)`，按

\[
(p,n)=(5,3),(6,3),(6,4),(7,4),(7,5)
\]

分别进行 (3000,3000,2000,1000,500) 个随机权重向量。权重来自稀疏的小整数分布，逢更小的比率才覆盖 `floor_best.json`，若浮点比率小于 (1-10^{-7}) 才打印 `FAIL` 并退出。这个循环没有穷举客户目录、权重、平局或完整有序策略；`floor_scan.py` 的作用在本批是冻结运行依赖和有限地板探针，既有 `floor_best.json` 的具体记录已经在 [R-275 固定策略锥与地板扫描有限记录](R275固定策略锥与地板扫描有限记录--计算.md) 中单独登记。

## 分数锥攻击的 LP

`fractional_cone_attack.py` 从 `cone_floor_attack.Cone` 继承上述递归，并缓存 (U_{c,a}=u_a(c;w)) 与阈值。对一个根可达目标终局 (z)，`policy(z)` 遍历所有长度小于 (n) 的有序历史 (h)。在历史 (h) 的计数为 (k) 时，它选取第一个满足下列条件的动作：目标 (z) 属于该动作的孩子集合 (R(k+e_a))，且 (U_{z,a}\ge\theta(k)-10^{-8})。对每个偏离动作 (b)，它在孩子集合中选取使 (U_{y,b}) 最小的终局 (y)。若把这些被选终局记为 (z_h) 和 (z_{h,b})，代码内存中的行是

\[
 \Gamma_{h,b;S}
 =\pi_{a_h,S}(z_h)-\pi_{b,S}(z_{h,b}),
 \qquad \Gamma w\ge0.
\tag{IC}_{h,b}
\]

这只代表由当前浮点权重生成的一个固定动作表和一个固定孩子选择表的局部比较。它没有把所有完整策略的量词合并成一组统一约束。

对目标终局 (z) 令

\[
 q_S=1_{\{d_S(z)>0\}},\qquad
 \alpha=\frac{n-1}{n},\qquad
 g_S(z)=\frac{1}{1+\alpha d_S(z)},
\]

并对指定动作 (a) 令 (g_{a,S}(z)=1_{\{a\in S\}}g_S(z))。脚本构造的 LP 是

\[
\begin{aligned}
 \min_{w\ge0}\quad& \sum_S\bigl(q_S+g_S(z)-n g_{a,S}(z)\bigr)w_S,\\
 \text{s.t.}\quad& \Gamma w\ge0,\qquad \sum_Sq_Sw_S=1.
\end{aligned}
\tag{LP}_{z,a}
\]

目标可以写成 (W(z;w)+G(z;w)-n g_a(z;w))，其中 (G(z;w)=\sum_{S:d_S(z)>0}w_S/(1+\alpha d_S(z)))。等式只归一化目标终局覆盖到的类型质量；它不是某个完整 SPE 的实际福利 (W/\operatorname{OPT}) 归一化。SciPy/HiGHS 在源中按双精度求解，没有保存 LP 对偶，也没有把小数权重恢复为整数客户。

主循环使用 `default_rng(8932)`，参数为 ((5,3,20),(6,4,20),(7,5,20))。每个随机向量取值于 `[0,0,0,1,2,4,8,16]`，按根终局的 (W(z;w)) 从小到大取前三个目标，再遍历 (a=0,ldots,p-1) 解上述 LP。最多只有 (60) 个随机权重向量、(3\times p) 个目标/动作组合（上限 (1080) 次 LP），而非所有权重或所有策略。若当前最优目标小于 (-10^{-7})，程序才打印 `BRIDGE FAIL`；冻结运行没有触发该分支。

## 冻结候选 `fractional_cone_best.json`

JSON 顶层字段逐项如下：`p=7`、`n=5`、`weights` 长度 (127=2^7-1)、`target=[1,1,0,2,1,0,0]`、`a=0`、`slack=0.19999999999999996`，以及长度 (2801) 的 `policy`。(2801=\sum_{j=0}^{4}7^j) 正好是该 (p,n) 的所有非终端有序历史数；若把每个节点展开成六个偏离动作，代码内存中的 (Gamma) 行数是 (2801\times6=16806)。

保存向量的唯一非零坐标是 Python 下标 (94)，即掩码 (95=1+2+4+8+16+64)，对应

\[
 S=\{0,1,2,3,4,6\},qquad w_S=1.
\]

对目标 (z=(1,1,0,2,1,0,0))，有 (d_S(z)=5)，且动作 (a=0\) 属于 (S)。因此 (q_S=1)、(alpha=4/5)，LP 目标在这一坐标上的系数为

\[
 1+\frac1{1+(4/5)\cdot5}
 -5\frac1{1+(4/5)\cdot5}
 =1+\frac15-5\cdot\frac15=\frac15.
\]

快速重放得到支持归一化 (q\cdot w=1)、目标值 (0.19999999999999996)、目标 ID (340)、(2801) 个历史节点和 (16806) 个潜在偏离行；这些是记录字段与公式的值级一致性检查。

必须保留一个序列化边界：`fractional_cone_attack.py` 先用随机权重建立 `policy` 和其隐含的 `terms`，随后 LP 才输出新的 `out.x` 写入 `weights`。JSON 的 `policy` 只保存每个历史的 `h` 和所选动作 `a`，没有保存每个偏离孩子的终局 `terms`，也没有保存生成策略时的原始随机权重。因此仅用 JSON 不能重构原始 (Gamma) 矩阵；把保存动作表在新权重下重新生成的 (Gamma) 当成原 LP 约束会改变问题。浮点阈值 (10^{-8}) 还会使同一目标在重新加载小数权重时发生动作表平局变化。这是候选和可审计精确证书之间的实质缺口。

## 失败机制与量词边界

这组三源没有发现桥失败，但“没有失败”有四个具体限制。

1. **状态压缩。** (R(k)) 合并了同一计数的不同有序历史；原 Q-CAG-HALF 量词要求对每一份完整历史纯 SPE 检查，不能由计数 DAG 的可达终局并集替代。
2. **固定策略锥。** (Gamma w\ge0) 只覆盖一次 `policy(target)` 生成的动作/孩子表；它不包含所有平局续局、所有目标终局或所有共同目录。
3. **浮点和序列化。** 阈值容差、SciPy 双精度和小数 JSON 会改变边界平局；`policy` 不含隐含终局 `terms`，无法独立重建原 LP 行。即使固定锥 LP 的 slack 为正，也不等于普遍桥成立。
4. **分数权重及归一化。** (w_S) 是非负实数，支持等式是 (q\cdot w=1)。这不是整数单位客户多重集，也不是 (W/\operatorname{OPT}_6) 的归一化，故不能从 `slack=0.2` 推出六人福利界。

相关对象的量词必须分开：同一目录的 `cone_floor_attack.py`/`cone_best.json` 与 `floor_best.json` 已有独立有限记录；`common_query_regret_counterexample.md` 是另一个经过完整历史审计的六提供者 30 客户见证，但只反驳辅助的 common-query 最小收益桥，且 (W=25,\operatorname{OPT}_6=26)，没有反驳 half；`padded_residual_uniform_floor.md` 则只证明特定残余族的四收益地板。它们都不能与本分数 LP 合并成任意目录结论。

因此本页的可复用内容是计数状态系数、固定策略锥 LP 的目标定义、(p=7,n=5) 的保存坐标和有限值级重放；未决内容包括完整有序历史的共同续局、整数客户有理证书、LP 对偶/行重建以及对所有六人 SPE 的半覆盖量词。任何后续升级都必须补齐这些缺口，不能把本页的有限扫描升格为六人 half 定理。
