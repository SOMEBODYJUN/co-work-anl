# 原表的身份和实际保全

源 `9ddb1502995eb9e435eb` 的[完整3252B原表](../../tools/evidence/continuous-old-query-cut-data/related/continuous_refinement_cuts.json)已经在前批作为比较原件保存；本批正式处置该来源，继续共用同一字节文件而不重复复制。两冻结提交的SHA-256均为 `aa696d0ebbb1e5b1ccc3b593c5f5a4bcac4cf411966dfd9499192d8170fb5c36`。全文只有两个顶层字段：scope说明每个有理cut为合法priced-hidden-reply投影，cuts按原序保存全部32个八元组。每个元组的八个坐标与所有有理字符串均已实读。

本表**没有**保存输入点路径、slack、W、迭代轨迹、LP状态或最优性证书。它的用途是恢复实际采用的有限必要行集合。下文的余量和点身份来自逐项读取相关冻结输入及当前精确计算，不伪装成原JSON已有字段，也不凭现存32条倒推历史上每轮发现顺序。

相关[迭代精化程序](../程序/连续旧查询切面的迭代精化程序--程序.md)默认从空cut列表开始，在5043行基图上交替求浮点点和最多32个新的连续价格方向。其verify分支把**这32条**加到同一5043行基图，得到5075行；不自动先加另一份64表。另一联合程序则先保64表，`--latest`再加本32条及其它行，因此这些阶段不能只按文件名或条数混同。

# 必要行的数学范围与八坐标

固定任意有限单位客户、有限非空共同目录、恰六名单位提供者的完整有序历史纯SPE。客户在终局覆盖者间均分；保空题、重复选题、零客户、所有离轨历史及任意平局。取同一实际路径 \(A_1,\ldots,A_6\)，实际利润为 \(u_1,\ldots,u_6\)。索引分支产生的R/Z均为同一目录的合法主题，不把强制某R/Z的行动宣布为其节点最优。完整定义见[联合必要点](索引主题与实际B分支的联合必要图有理点--计算.md)。

每条为 \((i,m,f,d,q_i,\alpha_m,\alpha_l,\mu)\)：i是从0起的实际源位置，m为被强制的R/Z成员选择（0/1），(f,d)是回复族及索引对角标记，qi选择两个比较索引r,s的 \((T_r,B_r,C_r,T_s,B_s,C_s)\) 中一位作为合法末查询Q；最后三个是非负有理价格。不是三种新的策略概率。

令 \(n=5-i\)，实际源前负载为p，实际末位前负载为ell，强制位t、查询位q，则
\[
\psi_i(p,\ell,t,q)=\min_{0\le s<n,\ g\in\{0,1\}}
\left[\frac{t-\mu g}{p+t+s+g}
+\frac{\alpha_m s+\alpha_l g}{\ell+1}
+\frac{\mu q}{p+t+s+1}\right].
\]
首项在原两个分子都为0、分母也为0时取0；等价地分别按零分子份额定义。n个真实后继的中间价格相同，所以它们只经覆盖数s出现，最后位为g；这是完整隐藏位最小化的精确压缩，不是独立性假设。

由源IC、实际末位共同报价及真实分支末位对Q的IC非负相加，单个合法强制主题满足
\[
u_{i+1}+[(n-1)\alpha_m+\alpha_l]u_6
\ge\sum_x\psi_i(p_x,\ell_x,t_x,q_x).
\]
再对(f,d)同一带索引类相加，主题数为30或6。hist质量h、组重数m_g、R或Z边缘质量t_g给右侧
\[
\sum_{h,g}m_g[(h-t_g)\psi_i(p,\ell,0,q_g)+t_g\psi_i(p,\ell,1,q_g)].
\]
t_g是质量而非概率，含隐含00质量的h−t_g必须保留。此行只依hist和回复一阶边缘；新Z必须另代入。详细合法性推导及无负价格条件见[共同末价投影引理](../引理/共同末位报价与隐藏回复投影--引理.md)与[64切面对象](旧查询回复的六十四个有理分离切面--计算.md)。合法性对一般原模型成立，求出一份固定支持图点却不提供反向SPE实现。

# 实际全表分布和与64表的差异

32条元组互不相同，全部异索引；本任务不将互不相同的参数元组说成线性独立行。

| 坐标 | 完整32条中的分布 |
| --- | --- |
| 实际源 | 第3位15条、第4位17条 |
| 强制成员 | R 17条、Z 15条 |
| 回复族 | f=0、f=1各16条 |
| 对角标记 | 32条全d=0，每条聚合30个带索引主题 |
| qi=0,…,5 | 5、6、6、5、6、4条 |

与旧15013B的64表逐八坐标比较，只有21条元组重合，11条只在本表；本表与旧表前32条仅17条重合。完整差集保在[当前报告](../../tools/evidence/continuous-query-refinement-data/four-stage-cut-audit.json)。因此本表不应因“旧表已有64条”被丢弃，也不能取旧表前32条替代。但参数不同可能仍给同一行或同一锥方向，当前差集不认证11条全是独立新方向。

所有选择都处于同一合法的非负价格族，当前数据并不提供这个连续族的闭包证书。原程序的浮点LP、有理化和元组去重只解释有限发现机制；无新cut或达到给定轮数都不是原六人问题已解。

5075点的[完整816661B原件](../../tools/evidence/continuous-query-refinement-program/related/continuous_refinement_exact.json)SHA为 `abac45f78980d02f2bd056758a96653aa0bc0d8b87571820a5742397dc490246`。实际有1905列、179个正坐标、16hist，O=1，原字段base_rows=5043、continuous_cut_rows=32、verified_rows=5075。当前从全部hist质量重算O和W，并核每hist六T恰一份会员；没有凭元数据直接认最优值。

# 保留与接续

本32条、旧64条及新Z处的有限检查可用于定位某个候选必要点在哪些方向被切掉；不能将32与64的行数直接相加当独立秩。当前已补换Z处的这些连续cut，不等于旧5108条都已在新Z处独立核过，也不把原10344报告提升为全新认证。

继续原自适应搜索应按[精化程序](../程序/连续旧查询切面的迭代精化程序--程序.md)准确恢复5043基图及开关，另存新版本/执行事件；证明全域half或构造反例仍须跨越固定16hist支持和完整历史策略缺口。来源、有限切面、阶段点及后继重排的关系在此保留，供第三阶段据实际证据建立关系，不引入旧图当完成。
