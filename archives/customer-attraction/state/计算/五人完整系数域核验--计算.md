# 五人完整系数域证书的程序、输入与重放

## 资源对象与证据种类

本对象保存[五人主定理](../定理/五人半覆盖--定理.md)真正使用的完整输入和可执行程序，以及证明未活跃使用但有独有数学内容的局部切面。系数域穷举证明的是任意有限规模实例；它不是有限客户数、有限目录或指定平局规则的游戏搜索。

程序入口为[run_audits.py](../../tools/half5-exact/run_audits.py)，它只是运行器、指纹和额外标量核对，不是新独立证明器。依赖Python 3及主程序所用NumPy；局部程序只需标准库Fraction。运行Python时不要加`-O`，原程序以断言表达证明义务。

从仓库根运行：

```sh
python archives/customer-attraction/tools/half5-exact/run_audits.py
```

默认报告目录为`archives/customer-attraction/evidence/half5-exact/replay/`；`--output`可另选输出目录。输入和两个原核验器保持原字节；逐行交叉程序只将原来不存在的包路径改为当前同目录。可查看[provenance.json](../../evidence/half5-exact/provenance.json)的源/目标路径、双冻结定位、SHA及每项变换。

本批33源版本、66冻结定位全部实际核对等于已读内容；来源表与逐源目标在provenance。两个重复manifest只合并字节相同内容，独有局部切面、强化gamma、历史输出范围、内审发现和正余项推论均有去向。三份旧五人界及后续一般工具只是相关比较，本批不勾选它们。

本阶段只留下关系的明确证据：主定理由局部投影、末对强式和主整数证书共同闭合；正余项推论由同一主证书导出；MAXROOT另一界和未活跃切面保留独立用途。三级超图交第三阶段，不自动建立边。
