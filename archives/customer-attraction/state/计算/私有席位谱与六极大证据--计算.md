# 私有席位谱、六极大系数及路径障碍的证据资源

## 对象、原件和复现位置

证据根为[private-seats](../../tools/evidence/private-seats/)，[source-manifest.json](../../tools/evidence/private-seats/source-manifest.json)逐文件记录源ID、两个完整冻结提交、源路径、字节数和SHA-256。本轮16份原件的字节均与冻结inventory一致：15份本批清洗源，另附已经由[模型对象](../定义/共同目录完整历史模型--定义.md)代表的`model.md`，仅作两份原审计的hash依赖，不据此重复勾选模型源。

证据原件保持原相对目录和原内容。原Markdown中的历史相对链接是冻结文本的一部分，不自动被改成新知识树；正式入口使用下列已整理对象与本资源链接：

- [六极大无私有强化界](../定理/六极大无私有强化覆盖界--定理.md)：全历史直接负载保底、67组完整系数和七人以上解析界。
- [九名以上提供者、至多六极大强化界](../定理/九人以上六极大强化覆盖界--定理.md)：混合包络、私有多项式和共享解析和式。
- [动态超集席位引理](../引理/动态超集席位保底--引理.md)：阈值容量单调与真实后继子主题支配。
- [五至八人合法路径收费障碍](../障碍/六极大动态席位合法路径收费--障碍.md)：四份完整整数构造和精确排序值。
- [实际遗漏谱与条件性锐界](../定理/实际遗漏私有席位谱与锐界--定理.md)：固定遗漏块、真实触块计数、完整谱、锐all-big例与共享遗漏边界。

## 无私有五六人的完整证明数据

[系数JSON](../../tools/evidence/private-seats/evidence/runs/2026-10-10/customer_attraction_six_maxima_no_private_certificates.json)含$n=5$的15条、$n=6$的52条规范长度$n-1$路径。每条矩阵为$n\times6$、元素整数0至12、每行和12，统一分母12；全部56种六坐标残余incidence质量任意非负。

[原审计代码](../../tools/evidence/private-seats/tests/audits/customer_attraction_six_maxima_no_private.py)不导入仓库模型、规范求解器或旧审计。`check_coefficients`自行枚举规范路径，核对完整集合、无重复、每条矩阵全部元素和每种incidence的有理系数。全部3752项系数最小值恰为1/2。这个**完整有限系数域检查**与正文加权恒等式共同构成任意客户质量的普遍证明；不是有限实例无反例。

同一代码另包含独立的集合值续局菜单求解、展开完整有序历史策略及逐偏离核对。菜单对每个偏离子历史保留可独立选择的全部SPE续局；动作计数只缓存可能菜单，不将策略约束为计数函数。选定结果实际展开成有序策略后核对每个合法节点。

本轮完整原脚本重放报告为[replay/six-maxima-no-private.json](../../tools/evidence/private-seats/replay/six-maxima-no-private.json)，结果为92个有限游戏、63209个计数状态、39811项历史保底比较、9051项九人混合保底比较、24份完整策略、30820个有序决策历史、199398项真实偏离比较。67组证书及3752项系数全部通过。有限游戏包含交叉六极大、核心遗漏子主题、空主题、重复标签、零客户和三例有私有质量的九人目录。

复现命令（从仓库根运行，输出需为尚不存在的文件）：

```sh
python3 archives/customer-attraction/tools/evidence/private-seats/tests/audits/customer_attraction_six_maxima_no_private.py --output /tmp/private-seats-no-private-new.json
```

## 四个收费障碍的字面客户核验

[四例数据](../../tools/evidence/private-seats/evidence/runs/2026-10-10/customer_attraction_six_maxima_seat_obstructions.json)完整保存所有正整数incidence重数、合法路由串、最优支持和逐位席位值。它们分别$n=5,6,7,8$，预算比例为$46/97$、$55/112$、$140687/282485$、$3283/6624$，均小于1/2。

[原审计](../../tools/evidence/private-seats/tests/audits/customer_attraction_six_maxima_seat_obstructions.py)不导入模型或求解器，将块扩成18884个不同单位客户，检查六个主题两两不可比、空核心、所有合法主题支持的最大覆盖、每次排序全部600个有理席位，以及156项直接加入收益。[本轮报告](../../tools/evidence/private-seats/replay/six-maxima-seat-obstructions.json)重现全部数值。

```sh
python3 archives/customer-attraction/tools/evidence/private-seats/tests/audits/customer_attraction_six_maxima_seat_obstructions.py --output /tmp/private-seats-obstructions-new.json
```

这些程序不验证该四条路径能成为均衡路径，也没有构造完整SPE福利反例。其结论只是否定特定任意合法路径收费式。后续联合预算使用额外真实membership、末位最佳回复和末两人税，所以与这些反例没有逻辑冲突。

## 实际遗漏谱的旧实现与本轮独立有限回放

[原共享脚本](../../tools/evidence/private-seats/tests/audits/customer_attraction_uncovered_private_spectrum.py)从规范`customer_attraction`包导入`Instance, ExactSPESolver`，随后直接用具名单位客户集合重算极大主题、全局私有块、实际遗漏、完整谱、每位收益及最优并集。原脚本自身不审查它导入的枚举器。其[冻结报告](../../tools/evidence/private-seats/evidence/runs/2026-10-23/customer_attraction_uncovered_private_spectrum.json)包含全部255个三客户非空目录与$m=1,2,3$，共765个目录人数对、1599条有序SPE路径、3660项逐位置比较，以及$m=1,\ldots,6$的all-big全前缀计数检查和$m=1,2,3,6$零实例。

本轮完整读过该脚本，没有将缺少规范包的环境声称为原脚本复跑。另写[private-spectrum-independent.py](../../tools/evidence/private-seats/replay/private-spectrum-independent.py)，它**不导入仓库模型或枚举器**，在每个字面有序历史递归保存每个动作自己的全部子菜单。某动作终局可被支持，当且仅当当前收益至少所有动作菜单最低收益的最大值：必要性来自各偏离子历史的最优性，充分性来自各离轨子树可独立选最低收益续局。以此保留全部历史依赖平局及所有可实现有序路径，再从实际客户集重算谱。

[本轮独立报告](../../tools/evidence/private-seats/replay/private-spectrum-independent.json)重新得到765、1599、3660、1599（满足私有遗漏条件的路径数）四个计数，所有不等式通过；all-big各$m$的前缀计数为1、3、10、35、126、462，全部行动比较数为1、6、30、140、630、2772，与旧报告一致。这个有限独立实现加强了实现核对，但普遍定理仍只由解析阈值归纳和覆盖代数承担。

```sh
python3 archives/customer-attraction/tools/evidence/private-seats/replay/private-spectrum-independent.py --output /tmp/private-seats-spectrum-new.json
```
