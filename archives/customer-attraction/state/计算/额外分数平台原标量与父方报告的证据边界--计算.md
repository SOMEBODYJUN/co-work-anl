# 九项断言的完整公式

记L=3r/Q、a=f(1+L)、h=g(1)、H_R/H_D如数学页，Δ=d(a+2h)、u=3df(3)、s=d[a+2g(r+1)]，θ=3(L−1)/(r−1)，U为数学页的真实剩余总利润。代码所有量为精确Fraction，不用float或容差。

| 作者checks字段 | 实际被计算的条件 | 数学职责 |
|---|---|---|
| query_support | a<h | 全regular query在每段一个R、两个D最优 |
| gradient_support | H_R>H_D | regular背景负梯度在三个R最优 |
| singleton_query | Δ>1/(M+1) | singleton不超过全目录query cap |
| singleton_gradient | 3dH_R>max{1/[Q(M+1+L)²],1/(HM+1)²} | singleton不超过支持背景的线性负梯度 |
| strict_local_deficit | Δ>s>u | 旧PB当前利润严格低于extra静态平台 |
| child_mixture | 0≤θ≤1 | 子背景混合概率合法 |
| hot_denominator | 1+(r−1)θ/3=L | F三个热点加旧1后的负载恢复 |
| outside_denominator | (r−1)(3−θ)/(Q−3)=L | 其他R块负载恢复 |

其中singleton_gradient的R上界用11名M背景客户所在的较大导数；M+1层导数更小，D客户查询率1。它不是把singleton当整块。九个true只证明指定数值的这些条件；不能由此推全部参数族、全历史SPE、静态一般聚合或root half。全目录KKT为何足够及混合如何变合法主题均由数学页解析证明承担。
