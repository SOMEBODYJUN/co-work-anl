# 动态信用联合一步闭合有限探针

## 1. 定义与约束行

源文件完整实读 1,581 B，SHA-256 为 `626b875306ffb916b30e3c55902f447a64eff4bf10e8673f46305793e6c513b4`，稳定清洗 ID 为 `d33998326f4e4a417569`，冻结 blob 为 `d31614620e56358c844d10a038d70d8664fe55ae`。程序固定 `r=3,k=4`，客户类型是非空四位 mask (1,ldots,15)，尾响应是有序长度二的多重集。它用 `Fraction` 计算 `util`、`profit` 和 coverage，但优化器仍是 SciPy 浮点 `linprog`。

随机种子固定为 `942`。每一轮为每个根动作 (ain{0,1,2,3}) 随机生成一个尾响应 `response[a]`；实际根路径固定为 `(0,) + response[0]`。其 coverage 等式向量为 `cov[T]=1` 当实际路径至少命中 mask (T) 的一个主题。

对每个动作 (a)，程序加入以下两类行：

1. 当 (a>0)，根实际路径 `(0,...)` 与偏离路径 `(a,...)` 的单客户 `util` 差行；
2. 对每个替代尾 `q`，加入 `2*profit(response[a],(a,),T)-profit(q,(a,),T)` 的利润行，以及
   [
   1_{response[a]\text{ 覆盖 }T}1_{a\notin T}+profit(response[a],(a,),T)-1_{q\text{ 覆盖 }T}1_{a\notin T}
   ]
   的覆盖—利润联合行。

LP 变量是 mask 权重 (w_Tge0)，约束为所有上述行的加权和非负，且 `cov·w=1`。目标是

[
  sum_Tigl(1_{{1,2,3\}\text{ 覆盖 }T}-2,1_{{0,\mathrm{response}[0]\}\text{ 覆盖 }T}igr)w_T,
]

即把三个非实际根主题的覆盖与实际路径覆盖的两倍放在同一投影目标中。程序仅在 `res.fun < -1e-8` 时恢复有理权重并打印 witness；没有构造对应完整策略或均衡证书。

## 2. 确定性重放

直接执行源脚本成功，输出保存在 `replay/joint_one_step_probe.stdout.txt`：

```text

{2: '9/14', 3: '1/14', 4: '1/2', 5: '3/14', 8: '1/2', 9: '3/14'}
minrow 0
```

所以第 10 次试验（0-based `trial=9`）找到 response map

[
R_0=(2,2),\quad R_1=(1,2),\quad R_2=(2,3),\quad R_3=(2,3),
]

以及非零权重

[
w_2=9/14,;w_3=1/14,;w_4=1/2,;w_5=3/14,;w_8=1/2,;w_9=3/14.
]

输出的 `gap=1/7` 是该 LP 目标的有理重构值；`minrow=0` 表示约束行只达到非负边界，并没有严格安全裕量。其余 mask 权重为零。该 witness 是对所写局部行的可行分离，不是对所有 response map 的结论。

## 3. 与同主题探针和精确对象的区别

`动态信用一步闭合随机LP探针` 使用相同 (r=3,k=4) 和同类随机尾，但它只加入根动作行与两倍尾利润行；已记录 trial 2 的 gap (1/16)。`动态信用一步覆盖LP探针` 则使用覆盖等式、utility/profit 行和覆盖目标，记录 trial 9 的 gap (1/5)。当前源把利润与覆盖两类行放进一个 LP，得到 (1/7)；三者是不同约束系统和不同目标，不得把数值 gap 相加或视为同一证书。

`动态信用一步闭合标量反例` 的 exact JSON 给出 (W=14,mathrm{OPT}=30,2W-mathrm{OPT}=-2)，但在历史 `[0,2]` 上末位偏离使指定菜单不是 SPE。当前联合探针也没有完整历史策略、离轨续局或 `verify_certificate`，所以其 gap 不能升级为 Q-CAG-HALF 的反例。`动态信用一步闭合标量投影障碍` 解释了为什么两个局部标量不足以闭合全局，而本页只增加一个有限联合行集，未解决该障碍。

固定策略 floor LP、背景末位利润余项和分数覆盖真实前缀引理分别研究固定策略、终端余项和真实路径预算；它们提供比较语义，不改变本探针的有限随机 LP 量词。所有结果仍留在 customer-attraction 动态信用模型。

## 4. 处置与开放边界

本对象保留一个可确定重跑的有限浮点联合投影 witness，不能称为完整 SPE、精确客户实例、通用一步闭合否定或一般福利下界。要升级结论至少需要：把 response map 嵌入完整有序策略、对所有离轨历史给出最佳回应并通过精确证书、说明随机探针覆盖的输入量词，及把一步投影 gap 与真实终局福利/OPT 建立合法望远镜关系。当前均未完成，因此不迁移到 unrelated-machines，也不替代既有 exact scalar obstruction。
