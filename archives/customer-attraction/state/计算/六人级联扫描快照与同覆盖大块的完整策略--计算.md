# 对象与完整模型

两源分别是2566B的[发现历史](../../tools/evidence/r70-cascade-scan-data/original/cascade_scan.json)与2566499B的[最佳完整证书](../../tools/evidence/r70-cascade-scan-data/original/cascade_scan_best.json)，分别保存多个种子的搜索摘要和一个最佳点，不是两份独立完整见证，也不是各完成二十轮的实验。全字段、七条历史、六个正客户类型及19608条有序动作均已读取；原始字节和逐源身份保于[证据清单](../../tools/evidence/r70-cascade-scan-data/source-manifest.json)。

使用[共同目录完整历史模型](../定义/共同目录完整历史模型--定义.md)的标签接口：六名单位权提供者依次观察全部有序历史，每人从七个共同标签选一次；客户是不同的单位客户，重数只压缩相同兴趣。终局选择兴趣类型B中标签的人数为q(B)，该类型每个覆盖者得n_B/q(B)。福利W等于覆盖客户数、也等于六人总收益；OPT₆是至多六主题的最大覆盖，可重复补足为六次。

纯策略须在每个h∈{0,…,6}^{<6}规定动作；任何替代动作后必须沿同一策略在改变后的历史完成。全部离轨历史、重复标签和弱平局保留。软件允许同覆盖异标签，主集合目录中的同覆盖集合则只出现一次；本页不在原动作表中删除别名后继续假定策略不变。数学模型允许空主题、全零客户等边界，但这份保存输入没有空覆盖标签且客户总数为11，不能把它当这些边界的数值回归。

# 实际生成与认证链

相关生成器来自另一个工作室：R-64201…/counterexample/[cascade_attack.py](../../tools/evidence/cascade-original-nine-boss3/original/f08bcbcb7a5f6f2bd41b/cascade_attack.py)，源IDf08bcbcb7a5f6f2bd41b、11920B、SHA256`8da523673bf451f63bbdedc79a0efa906492481e4d18e61274a6873df7ddd8c8`。已全文读该原代码及导入的model、certificate、exact、__init__四文件；[程序正文](../程序/锚点缺口级联的完整策略锥与三个版本输出合同--程序.md)保其完整版本合同。本两表的字段与当前版本相容，未保存足以唯一绑定实际生产版本、命令、NumPy/SciPy环境和LP选择的证据；不能仅据文件同名或共同路径称已逐字节重放。

其实际流程如下。

1. 枚举p维计数。取L=lcm(1,…,m)，本例m6为60，用整数收益系数L·1[a∈B]/q(B)。动态规划保存**全部可实现SPE终局集合**，不是给同计数历史统一动作：R(q)=∪ₐ{z∈R(q+eₐ):uₐ(z)≥max_b min_{y∈R(q+e_b)}u_b(y)}。子树可独立选择可信续局，所以计数缓存不丢完整有序历史量词。
2. 从当前最差终局构造一份完整有序动作图；未选动作取当前玩家最不利的可信子树，奇数轮可随机破平局。固定图后，全部真实IC定义G r≥0，根福利w r=1、r≥0；浮点LP最大化某比较支持J的覆盖v^Jr。这不是在所有策略上优化。
3. 浮点点经限分母或活跃行消元恢复有理数，必须对所有G、非负性及归一化精确回代；成功后通分并除gcd得到单位客户重数。一次有理可行点不附带精确对偶上界。当前p7、anchors2、m6不满足p−anchors=m，故每轮只选种子覆盖最高的至多四个比较支持，不保证枚全七个。
4. 每逢严格改善，调用[规范完整证书核验器](../../tools/evidence/cascade-original-nine-boss3/dependencies/customer_attraction/certificate.py)：核完整有序键域、所有真实偏离及声明根计数，然后写best。其`verify_certificate`不调用终局全集求解器；原生成器虽导入ExactSPESolver，main使用自有Engine。保存后对端点扰动再入队；扰动下一轮重新求SPE，不能沿原策略免验。

当前生成器的rng常量64201是代码事实；原JSON没有seed字段，不把它补进历史参数。它每次改善覆盖best文件、每个已记录轮次覆盖主历史，因此两份冻结表是累计发现摘要与最后改善见证。第0轮new_best、最终best、保存target相容，但缺实际写盘事件，不能恢复每轮全部种子、LP状态或中间更优点。

生成器的整数点乘可在大客户数时切换Python整数，收益系数数组本身却用int16，不能承诺任意m均无溢出；本保存m6的系数不超过60，没有这个边界问题。浮点发现、精确给定图认证和全体SPE结论是三个不同层次，见[固定策略重数锥](../定理/固定完整策略的客户重数锥--定理.md)。

# 不重复数值扫描的完整SPE证明

原数据全量检查已确认：**任意决策历史后的规定动作均为0或1**。固定任意有序历史h，设其中s人选过单客户标签，q_j人选过单客户j。当前照规定选A，其后各人仍都选A，不论如何在两个别名间切换，最终A用户数为6−s。因此

\[
u_{\rm prescribed}(h)=\frac6{6-s}\ge1.
\]

改选另一个大块别名后，后继仍都覆盖A，收益相等。改选单客户j后，后继只选A，所以该偏离者得

\[
u_{j}(h)=\frac1{q_j+1}\le1.
\]

这些比较对全部h、全部合法替代均成立，且沿原策略的真实改变后子树；由每人只行动一次，所存完整图就是纯SPE。离轨历史可任意包含重复单客户；并未把路径冻结，也未将不同有序历史同标签化。s=0时五个单客户偏离都恰好打平，故不能删除非严格IC或声称策略严格。

此解析证明覆盖19608×6=117648项非自身比较；这是合同基数，**不是本次逐项数值重算的次数**。每个历史另一个A标签都平局；s=0的历史共有1+2+…+2⁵=63个，额外315个单客户平局。因此解析给19923项非自身平局和97725项严格比较。给定表已全量核对其前提，没必要重跑成熟大块输入的完整收益扫描。

还能直接确定**此实例**的最坏SPE福利：任何SPE实际终局若从未覆盖A，则末位遵从只能得至多1；此时改A可独得6，矛盾。因此每个SPE均覆盖A，W≥6；上面的保存策略达到6，所以min_σW=6、真实最坏比OPT₆/min_σW=11/6。这个解析结论比原字段“lower_bound”更精确，但不更改原字段、不声称LP最优或全部六人实例上界。half余量2W−OPT₆=1，本点满足half。
