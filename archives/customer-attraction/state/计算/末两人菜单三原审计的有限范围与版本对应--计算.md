# 三份原审计与其数学合同

本页是原程序和版本证据的计算对象。相应数学结论分别保存在[共同包含半覆盖](../定理/倒二主题共同包含半覆盖--定理.md)、[末两位同主题单早期例外](../定理/末两位同主题单早期例外半覆盖--定理.md)和[少量早期遗漏平方阈值](../定理/倒二主题少量早期遗漏平方阈值--定理.md)，不重复建立同一半覆盖定理。

采用[共同目录完整历史模型](../定义/共同目录完整历史模型--定义.md)：有限单位客户、有限非空共同目录、单位提供者、全部有序历史上的纯 SPE；空主题、重复选择、零客户和任意离轨平局均保留。以下程序的输入是单客户会员位及明确整数参数，**没有输入或枚举完整游戏及完整 SPE**。每个客户对整条真实 IC 的贡献可以为负；只有整行 IC 在给定 SPE 上非负。有限公式核验不能省去真实行的合法性证明。

六份原字节、双冻结来源及 SHA-256 保存在[证据目录](../../tools/evidence/direct-global-original-audits-boss3/README.md)与[源清单](../../tools/evidence/direct-global-original-audits-boss3/source-manifest.json)。两个冻结提交 `68fad804ec5946cb296f77dc5b336308a66abf12`、`aefc58eac3fc6eb5d7a47d087dd2c62b5aa9974c` 对每项给同一源版本；本批未重写原件。三个脚本仅依赖 Python 标准库，均用 `Fraction` 和普通未优化 Python 执行断言，不导入游戏求解器、LP 程序或本地 helper。

## 公共真实菜单与三种不同付款

固定原 SPE 实际末两人前的有序前缀，客户负载为 $p$，实际末两主题为 $A,B$。任取允许重复的 $m$ 个比较主题 $T_i$，由同一策略在改变后历史产生真实末位回复 $R_i$。[菜单引理](../引理/真实末两人菜单交集消去--引理.md)给三族非负整行 $S,Z,V$，分别来自倒二查询 $T_i$、实际末位查询 $R_i$、各真实末位节点互查 $R_j$。其中 $V$ 对全部有序 $i\ne j$ 求和。组合为

\[
G=S+\frac{Z}{2m}+\frac Vm\ge0.
\]

统一本页记号：$a=1_A,b=1_B,d=\sum_i1_{T_i},\ell=\sum_i1_{R_i}$，$h=\sum_i1_{T_i}1_{R_i}$。令 $c=p+a+b,w=1_{c>0},o=1_{d>0},\alpha=a/c,\beta=b/c$，零分子份额取零，则

\[
G_x=m\alpha+\frac\beta2-\frac d{p+1}
-\frac\ell{2m(p+a+1)}+\frac{d\ell}{m(p+1)(p+2)}.
\tag{1}
\]

这是从 $S_x=m\alpha-d/(p+1)+h/((p+1)(p+2))$、$Z_x=m\beta-\ell/(p+a+1)$、$V_x=(d\ell-mh)/((p+1)(p+2))$ 消去 $h$ 得到。三个程序对应的付款各不相同：

| 原程序 | 结构域与补偿 | 逐客户余项 |
| --- | --- | --- |
| `common_penultimate_theme_audit.py` | $A\subseteq E_j$ 对全部早期实际主题成立，故 $a=1\Rightarrow p=m-2$ | $\rho=2w-o-G_x$ |
| `audit_early_exception.py` | 实际末两位均选 $A$，早期有 $m-3$ 位选 $A$ 和指定一位选 $B$；$R=u_B-\lvert A\rvert/m\ge0$ | $Q=2w-o-G_x-\mu(u_B(x)-a/m)$，$\mu=m(m-4)/(2(m-2)(m-1))$ |
| `audit_few_exceptions.py` | 选 $r$ 个早期实际角色含全部例外，其余角色均包含倒二主题 $A$；$m\ge(r+1)^2+1$ | $Q=2w-o-G_x-\mu K_x$，使用下面的联合 $K$ |

少例外程序的 $e$ 是所选 $r$ 个角色对该客户的覆盖数，

\[
K_x=\frac e{p+a+b}-\frac{ra}{m}
+\frac{r\beta-e/(p+a+1)}{m-1},\qquad
\mu=\frac{m(m-1)^2}{m(m^2-3m+3)-r(m^2-2m+2)}.
\tag{2}
\]

式(2)只在零分子时使用归零约定；$e>0\Rightarrow p\ge e>0$。其整行是早期真实改 $A$ 保底与实际末位改例外主题的联合补偿，不能与第二行单一粗保底 $R$ 混同。第二个脚本中的 `ell` 实际是本页的**比较重数 $d$**，`d` 是本页的**回复重数 $\ell$**；另两个脚本采用本页顺序。对照表必须先作这次变量换名，不能直接用相同变量名拼接。

## 共同包含程序：位模式、压缩域与八个多项式恒等式

原输出源 `4023770371c5196e4587` 与原程序源 `91a002b325c54b79d79e` 对应。本轮原程序输出与冻结 JSON 逐字段、逐字节相等，保留 Python `3.12.14`。

- `full_binary_identity_cases=3584`：$m=3,4$，全部 $a,b\in\{0,1\}$、$p=0,\ldots,m-2$ 与全部 $2m$ 个比较/回复会员位。每次直接从原始 $S,Z,V$ 计算并核对聚合式；仅对 $a=0$ 或 $p=m-2$ 的结构域断言余项非负。
- `compressed_cases=127856`：$m\in\{3,4,5,6,7,11,31\}$，全部结构允许的 $a,b,p,d,\ell$。对每个 $d,\ell$，重建可行交叠的两个边界 $h=\max(0,d+\ell-m),\min(d,\ell)$，相同边界只记一次。$m\le7$ 时还直接计算二次规模的 $V$；$m=11,31$ 仅检查消去后的余项。它没有逐一枚举中间 $h$ 或所有二进制模式；中间 $h$ 的消去依赖恒等式本身。
- `polynomial_corner_identities=8`：在 $a=1,p=m-2,d\ge1$ 时，分别对 $b=0,1$ 和四个 $(d,\ell)=(1,0),(1,m),(m,0),(m,m)$ 角值，比较原式与正文角表。在各角代入后，以正分母 $L=2m^2(m-1)(m-1+b)$ 清分母，差成为次数至多四的多项式；程序在五个互异整数 $m=3,\ldots,7$ 验得精确零。因此这一步是有次数上界的多项式恒等式核验，不是以五次采样代替全参数符号判断。

次数上界需要读者核对代入后的式子，不能由输出字段 `degree_bound=4` 自行证明：例如 $L\cdot m/(m-1+b)=2m^3(m-1)$、$L\cdot b/(2m)=bm(m-1)(m-1+b)$，而四角的 $d\in\{1,m\},\ell\in\{0,m\}$ 不会产生高于四次的项。正文角表同样只有除数 $m,m-1$，清分母后满足该次数界。

脚本的 `shifted` 表又列出八个角值在 $t=m-3\ge0$ 下的分子/分母系数，断言系数非负且分母常数正。**程序没有自动将这张系数表与上述角式连接**；本轮逐项作了这一步人工代数核对。例如 $b=0,d=\ell=m$ 的角值分子/分母是 $(2t^2+9t+8)/(2t^2+10t+12)$，$b=1,d=m,\ell=0$ 是 $(2t^2+11t+16)/(2t^2+10t+12)$，与表中 `[8,9,2]`、`[16,11,2]` 一致。其他六项也是相应显式角式的直接平移。由此解释了系数正性的作用，未把一个断开关联的数组自检当成独立全参数证书。

任意 $m$ 的结论仍依赖已有定理的完整 $a=0$、$d=0$ 分支、真实 IC 与双线性四角论证。本程序没有检查审查稿的比较个数 $k\ne m$ 推广；不能把另一份 `common_penultimate_audit_v2.json` 的范围放到本输出下。

## 单早期例外程序：完整小人数会员与任意人数角式的关系

原程序源 `d1959b83f7a78511ebb5`、冻结输出源 `fb9feb751f521b9ecac3` 对应已有单例外付款稿。此时实际末两位都是 $A$，所以背景为 $p=(m-3)a+b$，实际 $A$ 角色份额为 $a/((m-1)a+b)$，原式(1)的 $m\alpha+\beta/2$ 变成 $(m+1/2)u_A(x)$。代码的 `direct` 从原始三个求和重构，`qvalue` 则使用已经消去交集的式子；二者在以下明确范围逐项相等且非负。

- `binary_membership_cases=21504`：$m=4,5,6$，四种 $a,b$ 与全部 $T_i,R_i$ 二进制会员，共 (4(2^8+2^{10}+2^{12})) 个单客户模式。
- `corner_checks=2400`：人数为 $4,\ldots,100,127,1000,1000000$，共100个；每人数四种 $a,b$，分别检查零比较重数分支的两个端点与正比较重数分支的四角，共 $100\cdot4\cdot6$。额外核对四类客户的显式角式，并检查 $0\le\mu<1/2$。

本轮还对[原付款稿](../../tools/evidence/r44b24-tail-20261101/original/direct_global/majority_with_early_exception.md)四类客户的零比较分支、全部角值和符号作解析复核：$a=b=0$ 的正比较分支为 $(d-1)(1-\ell/(2m))\ge0$；$a=0,b=1$ 四角均至少 $3/2-\mu>1$；$a=1,b=0$ 四角中唯一可能为零的端点给零，另一个边界含 $m-4\ge0$；$a=b=1$ 四角严格正。所有分母在 $m\ge4$ 下为正，零比较分支也逐项非负。因此未发现该条件付款论证的代数或真实行缺口。这里的内部复核不改变原稿发现时的候选标签，不冒充外部评审。

其 half 适用域并无新增：$m\ge5$ 时，平方阈值 $r=1$ 已包含本例的全部路径，**也包含 $B\supseteq A$**，因为条件是“至多一位不包含 $A$”，而非“恰一位必须遗漏 $A$”；$m=4$ 已有一般 half。若 $B\supseteq A$，共同包含定理也直接适用。保留本脚本的独有内容是另一套 $R,\mu$ 和四类付款公式。

## 少例外发现程序：有限背景范围与范围外失败

原程序源 `c2b02f37c7ddd8bc3c47` 的输出文件名为 `few_exceptions_audit.json`；本批没有另外领取它。其历史冻结原件已由 Boss6 保存于[原报告](../../tools/evidence/r44b24-tail-20261101/original/direct_global/few_exceptions_audit.json)，相应版本说明为[早期例外与尾部 LP 审计版本](../资源/R44b24早期例外与尾部LP审计版本--资源.md)。本轮复跑与该历史报告逐字段、逐字节相等。

准确结果是40个参数对、125424个客户角点、最小 $Q=0$，$r=1,\ldots,8$。每个 $r$ 取阈值 $M=(r+1)^2+1$ 及人数 $M,M+1,M+7,2M,1000$。$a=1$ 时程序使用结构强制的 $p=m-2-r+e$；$a=0$ 时，人数不超过170才遍历全部 $p=e,\ldots,m-2$，更大人数只取代码明确列出的若干端点和相邻值。因此 $m=1000$ 的回归**不是全部合法背景 $p$ 的穷举**。所有被选 $a,b,e,p$ 上检查零比较重数的两端点和正比较重数的四角。它还验证 $\mu\le U_0$、$\mu\ge m/(m-1-r)$、A内因式和阈值多项式的所选参数等式，但没有自动完成任意 $m,r$ 的多项式系数演算；全参数证明仍在平方阈值正文。

程序末尾刻意保留范围外点

\[
(m,r,a,b,e,p,d,\ell)=(5,2,0,0,2,2,1,0),\qquad Q=-\frac{76}{93}<0.
\]

此时 $5<10=(r+1)^2+1$。这是该统一系数逐客户模板在充分阈值外的失败，**没有给出完整策略或合法 SPE**，不能改写为五人或六人 half 反例。特别五人 half 现已有别处完整证明，与这里的负模板余项不冲突。

本脚本的125424不能替换为规范 `customer_attraction_few_exceptions.py` 的54240，亦不能替换为 `few_exceptions_independent_audit.py` 的1056384；三份程序的参数集合、原始行重构和多项式检查方式不同。[既有精确审计对象](倒二菜单条件证书精确审计--计算.md)保存规范实现，本页保存此前未处理的发现期实现。

## README 的独有路线说明及当前接续边界

原 README 源 `c0c75ee752794922d678` 将共同包含、少例外、两份重复前缀 LP 和 `ordered_early_floor_lp.py` 放在同一研究接口中。其独有判断在此保全：共同机制是同一真实菜单的跨回复最优性消去交集；少例外联合 $K$ 避免单独早期粗保底在已覆盖 $A$ 的客户上再次耗费预算；大量早期遗漏时 $A$ 内客户要求较大统一 $\mu$，$A$ 外客户给出上界，平方阈值来自两侧相容性。原 README 的一般低负载付款义务没有完成。

该入口明确将 `repeated_prefix_lp.py` 作为发现原统一 $G$ 的浮点工具，将 `repeated_prefix_sharp_lp.py` 的数值最优值与真正锐福利界分开；固定 $G$ 后只补有序早期最坏分母与末位查询的负松弛点也不必是 SPE。相关原代码和运行已由[末菜单系数发现资源](末菜单系数模板的发现与缩放证书--计算.md)保存，本批不再运行这些其他来源。后续[固定菜单非均匀付款障碍](../障碍/固定末菜单的非均匀前缀付款边界--障碍.md)给明确行锥的全人数解析否定，仍不能据此否定允许重新选择菜单系数、更早真实分支或其他论证的半覆盖目标。这里没有把原 README 的“下一步”变成强制研究路线。

原 README 的一般 Q-CAG-HALF 保持开放；现在须同时承认五人无条件 half 已有完整证书，恰六人全称 half 仍开放。本批关联的已有数学对象及证据用途已逐一解释；三级超图留待第三阶段，不凭目录关系造推导边。
