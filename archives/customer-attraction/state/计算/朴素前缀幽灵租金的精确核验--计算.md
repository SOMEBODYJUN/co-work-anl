# 朴素前缀幽灵租金的精确核验

## 1. 来源与实际运行

原说明和验证程序均来自两个冻结提交且字节相同；原件保存在[证据目录](../../tools/evidence/prefix-ghost-rent-boundary/)。验证程序只使用Python `Fraction`和有限枚举，不调用优化器、随机数或外部数据。

在仓库根的隔离复制件上实际运行：

    python original_verify_prefix_rent_boundary.py

退出码为0，stdout为：

    {'exact': True, 'full_history_comparisons': 1022, 'prefix_errors': 7, 'sum': '1879/840', 'root_W': 2, 'naive_budget_excess': '199/840', 'closed_form_cases_checked': 100}

完整stdout和运行元数据见[verification.stdout.txt](../../tools/evidence/prefix-ghost-rent-boundary/verification.stdout.txt)与[verification-metadata.json](../../tools/evidence/prefix-ghost-rent-boundary/verification-metadata.json)。

## 2. 检查内容

程序逐个枚举最多9位的二主题有序历史。对每个前缀和两个候选动作，沿完整策略补足剩余动作，比较规定选择 \(A\) 与每个偏离的收益；共核对1022项，确认严格支配策略在所有这些历史和续局下均无改进偏离。

随后对 \(h=0,\ldots,6\) 逐项计算
\[
\frac{2h}{(h+1)(h+3)}+\frac{h}{(h+1)(h+2)},
\]
精确求和得到 \(1879/840\)，并核对根福利为2和超额 \(199/840\)。最后对 \(c=1,\ldots,100\) 比较直接求和与
\[
3H_c+\frac5{c+1}+\frac3{c+2}-\frac{13}{2}
\]
的有理值，全部相等。

这是一份定义级算术核验，不是对所有目录或所有完整SPE的搜索，也不证明任何替代权重的全局可行性。程序保存的1022项只服务于本两主题构造；不要把有限枚举扩大成任意人数一般定理。

## 3. 与全仓材料的比较及接续

比较阅读了已有跨分支去相关预算定义和完整策略树平均障碍。它们分别使用真实跨分支查询和IID前缀流，量词及乘数都与本页的辅助 \(\Omega\) 电路不同。已有对象中关于某种全分布预算失败的记录不能替代本次两源的精确边界；反之，本次两源也不能否定加权transport或六人half。

程序未构造固定人口的全局客户质量、没有给出候选权重的线性规划，也未执行原说明中未提供的其他发现脚本。证据只保留原件、可复现stdout、元数据和来源manifest，避免把一个局部负搜索写成完整福利障碍。
