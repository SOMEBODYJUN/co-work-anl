# 极大关联结构保底的精确复现与正文指纹差异

本资源支撑[层族关联定理](../定理/层族极大关联的锐福利界--定理.md)和
[单例缺一归属定理](../定理/单例缺一极大归属的真实中继保底--定理.md)的有限实现核验。
原始程序、原报告和必需的规范求解器包按冻结指纹保存于
[maximal-incidence证据目录](../../tools/evidence/maximal-incidence/PROVENANCE.json)。
审计需Python标准库，断言必须开启；无需浮点求解器或外部LP。

## 层族审计究竟检查什么

程序的 `protection_test` 直接展开客户、真实前缀、即时最优极大行动和所有指定长度的未来行动，
比较领导者最终收益与最小后继收益；这部分不调用SPE算法。
`check_spe` 则调用已单独清洗的[完整历史终局全集算法](../算法/完整历史纯SPE终局全集--算法.md)，
对每个合法计数前缀的全部可实现终局检查新选主题的玩家收益、根福利及核心改进。
计数用于枚举全部可实现终局，不限制一个给定策略的历史依赖回复。

本轮完整重放结果：

| 检查 | 范围/次数 |
| --- | ---: |
| 穷举保护目录/人数案例 | 221 |
| 对这些案例的保护比较 | 42,045 |
| 种子88219生成的加权层级案例 | 300 |
| 这些案例的随机保护比较 | 30,000 |
| 合计有限SPE案例 / 根终局 | 521 / 757 |
| 规范求解器累计计数状态 | 85,962 |
| 新玩家主题保底比较 | 67,941 |

“加权”仅指客户块复制成不同单位客户，不改变提供者单位权模型。
输入包括严格三极大层级、至多两个任意内部子主题、遗漏核心、零客户、空主题、重复标签、唯一极大覆盖及一人。
程序另外直接重算交叉关联目录的收益 $(4,5,5)$；那是保护引理的反例，并没有将其认证为完整SPE福利反例。

## 必须保留的历史指纹差异

原冻结报告与本轮报告的所有数学计数、案例范围及反例字段一致，审计、`model.py` 和 `exact.py` 的SHA-256也一致。
但旧报告记录的证明文件哈希与当前冻结来源不同：

| 正文 `laminar_incidence_bound.md` | SHA-256 |
| --- | --- |
| 旧报告所记录 | `b30da493a922ebf8fa625c6307c276710248c42c4f33cb3119267845b6748755` |
| 当前冻结来源及本次重放 | `e950f932126c382f985082e5f06d12406b4a10fbe1c95845f5a4ab7971c2e9f8` |

原报告未改写。本次的 `original/research/current/customer_attraction/laminar_incidence_bound.md`
是当前清单冻结字节，并非强行恢复成旧报告记录的哈希。没有在本轮取回那份旧哈希正文，因而不猜测差异由哪次文字修改造成。
本次对当前冻结正文另行实读、核对证明，并用未修改审计完整重放。
审计只是将正文哈希写入报告，不会自动验证自然语言证明；不能据运行通过宣称文字论证形式化认证。
另一个正常差异是执行耗时。详细差异见[比较记录](../../tools/evidence/maximal-incidence/replay/comparison.json)。

## 单例缺一审计究竟检查什么

该脚本先以Fraction核对6,895个整数标量支付边界及770个同背景利润恒等式；
再用种子80915生成10个有限目录，加上3个边界输入，共13项，含合法非零前缀、空主题、一人及唯一极大覆盖。
逐例保存了实际单位客户类型、前缀、剩余人数、首位全集阈值、静态 $\theta$、全部终局数量、最小SPE剩余利润和最优剩余利润。

它检查首位最坏可实现收益至少为 $\theta$，每个剩余终局利润至少为 $r\theta$，以及 $F_r\le(2r-1)\theta$。
还保存七极大主题的单例/缺一范围见证，以及中间关联平均 $-1/8$ 的菜单，后者明确写 `SPE_certified:false`。
本轮该报告与原冻结JSON逐字段完全一致。

两个SPE部分共用规范求解器，所以不是两个独立SPE实现；结构定理的独立内部审查属于另一份文字证据。
13项或521项有限成功均不替代全称证明。

## 复现命令与依赖边界

从结果仓库根执行：

```sh
python3 archives/customer-attraction/tools/evidence/maximal-incidence/original/tests/audits/customer_attraction_laminar_incidence.py
python3 archives/customer-attraction/tools/evidence/maximal-incidence/original/tests/audits/customer_attraction_extreme_membership_theta.py
```

默认向stdout输出，`--output` 只创建新报告并拒绝覆盖已有报告。不要使用 `python -O`。
现有重放文件为[层族报告](../../tools/evidence/maximal-incidence/replay/laminar.json)和
[单例缺一报告](../../tools/evidence/maximal-incidence/replay/extreme.json)。
规范 `customer_attraction` 包从已清洗证据目录复制，并再次对每个文件核对冻结SHA-256；
原始正文副本是层族审计的哈希依赖，正式知识正文仍以上述定理文件为入口。
