# R-373d 唯一残余族的独立精确核验与有限攻击程序

## 实际读取与重放

完整读取 `unique_residual_family_audit.json` 的七个报告对象、全部类型重数、六个标签、回复表、6×6末位收益矩阵、根值、21个含重复标签对、\(W\)、\(\operatorname{OPT}\)、\(R\)、B4余量和 half 余量。随后用 `clean show --out` 导出 `verify_unique_residual_family.py`，逐行核对：

1. 断言参数域 \(d>3g>0\) 且 \(d-g\) 为偶数；
2. 按位掩码展开十二类单位客户；
3. 对每一行计算第二位玩家的六个 `Fraction` 收益并检查指定回复最大；
4. 检查根节点六个动作的值相同；
5. 检查客户数、实际收益、21个无序对、最优对 `TS`、交叠和残余公式。

脚本实际运行成功，输出七个参数案例，首例与报告一致：\((d,g)=(5,1)\) 时客户71、实际福利35、最优覆盖38、残余36、残余超福利1、half余量32。由于脚本所有中间量都为 `Fraction` 或整数，验证排除了浮点舍入导致的假松弛。

## 两个只保留范围的程序

`menu_pure_attack.py` 构造 `StrategyCone(p,m,actions)` 的终端策略锥，对每个候选查询解一个非负权重 LP，把 LP 解限制为锥内有理点后再调用 `independently_verify`。它只处理源树中可加载的示例，且只在 `value>2/(2m-1)` 时写弱菜单越界证据；没有越界输出不等于普遍安全定理。结果树缺少它导入的 `customer_attraction_strategy_lp`、示例和证书目录，本轮未运行，保留为待复现程序源。

`query_existing.py` 读取每个示例及配套完整策略证书，重建实际路径，计算福利、各主题查询值，以及对每个客户计数向量的
\[
 \mathrm{gap}=mO-(m-1)W-\sum_j q_jV_j.
\]
它取最大的 gap 作为有限查询诊断，未给证明、未声明完整枚举，也没有预设 tie-breaking 统一化；依赖目录同样不在结果树，本轮未运行。

## 证据等级与用途

`verify_unique_residual_family.py` + 报告属于**完整有限精确重放**，支持上一个对象的逐参数二人反例结论。两个独立程序属于**程序源/有限实验协议**：算法语义已读，运行边界明确，不能升级为反例、定理或全域安全结论。原报告中42项比较包含自身；它证明给定两阶段策略的局部完整SPE检查，不能被误写为六人全历史SPE。
