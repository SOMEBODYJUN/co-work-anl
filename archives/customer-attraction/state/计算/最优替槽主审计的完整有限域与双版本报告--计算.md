# 最优替槽主审计的完整有限域与双版本报告

## 原源码和完整内建输入

4933B `audit_optimal_exchange_kernels.py`只import标准库Fraction、itertools、math、pathlib、argparse、json；不导入SPE求解器、原作者程序、payoff库或外部数据。整数bitmask表示主题客户集合，全部输入在main内构造，外部依赖清单为空。完整[806目录显式列表](../../tools/evidence/general-proof-and-optimal-exchange-primary/replay/complete-built-input-catalogues.json)和[输入域说明](../../tools/evidence/general-proof-and-optimal-exchange-primary/replay/input-domain.json)与原码一并保存。

n依次0,1,2,3,4；每n以全部$2^n$个mask中不重复取1到min(3,$2^n$)个作为共同目录。对应目录数1,3,14,92,696，共806。目录没有重复mask标签；T或B内允许重复选主题。m取1,2,3；T枚举目录的所有有重复组合中覆盖数达到最大者，只保每多重集的规范排序，**不是额外遍历T的m!排列**；B枚举同目录全部有序m元组。n0真实涵盖空客户目录{空主题}，其它目录也可含空主题，重复选择不会被过滤。

## 每配对实际调用的检查

原check_case对每(T,B)直接求O、各客户a/c、同槽保护标记及J，按以下原控制流断言：

| 检查 | 精确执行范围 |
|---|---|
| BER | p=0,1/3,1/2,2/3,1五点，逐客户Fraction gain≤loss |
| 实现覆盖恒等式 | 仅m≤2且p=1/2，枚举全部2^m替槽bit词，检期望cover=OPT+gain−loss |
| HARM | 一次精确H_c与整数Beta右侧比较 |
| MATCH | 直接用二项系数比值构出平均右侧，没有显式枚举m!配对置换 |
| ANCHOR | 每个满足T[j]==B[j]的**同槽索引j**各检一次；保护该主题，用m−1剩余槽组合系数 |
| KERNEL | α=1,2,3三整数点，Beta用factorial比值精确计算 |

Beta实现只收正整数参数。这里未测全部正实α、连续所有p、α0稳定延拓、所有部分多锚或一般m；这些普遍解析式由[交换核定理](../定理/最优替槽的参数核与锚定调和预算--定理.md)承担。m3仍核BER五点，但不枚举2³实现去核期望恒等式。函数没有完整策略、收益、IC、half或FLOW/NET调用。

它为静态合法替槽公式实现、空客户/空主题/重复槽边界提供精确有限回归。m>3、n>4、目录大小>3、重复标签目录、全部连续参数及任何顺序SPE激励均不在该运行的穷举范围。命中率、COV、递增捕获、源付款、incoming余量、全树TREE-F及六人half没有被本原程序测试。PASS不能担任这些结论的证据；一般证明须回到真实合法元组和完整IC的独立数学论证。
