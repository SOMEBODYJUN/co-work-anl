# 探针逻辑

脚本从另一工作区导入 `background_pair_probe.py`，随机取 n/k、density 和 0 或 1–19 的整数 weights，最多 75 次。每个实例由策略锥产生矩阵和实际路径；对均匀、单位和随机查询分布交替五轮：SciPy `linprog` 在锥约束/welfare=1 下更新 weights，再用 SLSQP 更新 simplex 上的 p，记录浮点 (p^THp) ratio、branches/actions 并写回 JSON。

它依赖未在本批认领的另一工作区源码，使用浮点 LP/SLSQP 和有限随机 trials，没有 exact customer multiset、完整 ordered-history certificate、Fraction replay 或 external solver-independent witness。JSON 的 75 次记录只反映一次 discovery 轨迹。

现有 exact nonempty strong-aggregate 反例已否定更强 `ΣG<=ΣD`；本探针 best ratio<1 不改变该边界，也不否定弱 `ΣG<=W`、自由完整菜单或 Q-CAG-HALF。处置为 retained discovery source，不迁移到 unrelated-machines。
