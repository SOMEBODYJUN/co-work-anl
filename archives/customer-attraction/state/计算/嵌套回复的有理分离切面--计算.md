# 同一策略中的两种Y必须分清

采用有限单位客户、有限非空共同目录的六人完整有序历史纯SPE，终局价值在覆盖者间均分；空题、重复行动、零客户和任意离轨平局保留。实际路径为 \(A_1,\ldots,A_6\)，B专指实际末题A6。

从实际前三前缀h强制第四步为一个合法的显式旧回复主题T，即某个带索引 \(R_e\) 或 \(Z_e\)。真第五、第六题记为 \(Q_T,R_T\)。这里的新 \(R_T\) 不应与被强制的旧 \(R_e\) 混同。第五位若改B，真实末回复为
\[
Y_T=\sigma_6(h,T,B).
\]
另对六个任意合法比较题 \(T_i\)，令
\[
Y_i^T=\sigma_6(h,T,T_i),\qquad
d_x=\sum_i1_{T_i}(x),\quad L_x=\sum_i1_{Y_i^T}(x).
\]
单个Y_T与六菜单回复Y_i^T是不同对象；原程序的y与L分别表示它们。强制T或T_i只要求合法，不把被强制行动本身当节点最佳。全部真回复来自同一策略；隐藏盒子的扩大仅放松必要条件，不赋予任意独立回复表以SPE身份。

原[4993B程序](../程序/实际第四步强制新回复的嵌套投影程序--程序.md)提供25行，包括第五位改B后的真实中间IC、Y_T末位查询及容量、强PAIR等。**本冻结五条权重都没有选择middleB或任何依单y位的行。** 因而它们不使用特定B→Y_T的中间偏离接口；仍有三条使用下面G中的真实第五位T_i菜单IC，不能反过来说它们全无中间IC。

# 实际使用的真行和最大投影

对客户记实际会员六位a、实际份额 \(u_j=a_j/\sum a\)，零分子取0；p是前三负载，强制题会员t、新尾会员q、r，令 \(b_g=p+t\)、\(z=b_g+q+r\)、\(\ell=\sum_{j\le5}a_j\)、\(D=(b_g+1)(b_g+2)\)。本表九种行的单客户式为：

| 行名 | 系数及全客户非负性的来历 |
| --- | --- |
| source | \(u_4-t/z\)，实际第四位改T的真源IC |
| lastB | \(r/z-a_6/(b_g+q+1)\)，真末位R_T对合法B的查询 |
| E | \(6r/z-d/(b_g+q+1)\)，真末位对六T_i的查询和 |
| Pq、Pr | \(u_6-q/(\ell+1)\)、\(u_6-r/(\ell+1)\)，实际末位对Q_T/R_T的共同报价 |
| H2r | \(u_2-r/(5+a_1)\)，实际第二位的安全偏离 |
| H3q、H3r | \(u_3-q/(4+a_1+a_2)\)、\(u_3-r/(4+a_1+a_2)\)，实际第三位安全偏离 |
| G | 下面三族真菜单IC的非负组合 |

安全分母来自剩余提供者数量的上界，不冻结实际偏离后的动作。所有这些量的**全客户和**才非负，不要求每个客户系数非负。

保同索引交集 \(I=\sum_i1_{T_i}1_{Y_i^T}\)，有 \(\max(0,d+L-6)\le I\le\min(d,L)\)。三族真IC的单客户式为
\[
S=6q/z-d/(b_g+1)+I/D,\quad
Z=6r/z-L/(b_g+q+1),\quad
V=(dL-6I)/D.
\]
S是Q_T对六T_i的第五位偏离和；Z是真R_T对各Y_i^T的末位查询；V是各Y_i^T在其T_i历史后互查的末位IC和。因此
\[
G=S+Z/12+V/6
=6q/z+r/(2z)-d/(b_g+1)-L/[12(b_g+q+1)]+dL/(6D).
\]
I项精确抵消，不是假设两菜单会员独立。零分子份额仍取0。

给定表中非负权λ，令Jλ为这些行的加权和，全客户和非负。定义
\[
\psi_\lambda(a,d,t)=\max_{q,r\in\{0,1\},\ L\in\{0,\ldots,6\}}J_\lambda(a,d,t,q,r,L).
\]
真实隐藏值在域内，所以 \(\sum_x\psi_\lambda\ge\sum_xJ_\lambda\ge0\) 是普遍必要行。这里取**最大上包络**；不能套用另一类priced-hidden行的最小化方向。对固定q,r，I消去后J对L仿射，故原程序只查L=0/6仍得同一最大值。y不出现在本五条，添选单Y位也不改变其值。

# 从旧回复组到有名索引平均

每hist的六比较词组成八桶直方图，轨道组为 \((f,diag,w_i,w_j)\)。从三显式态提取被强制主题边缘：member0取10+11，member1取01+11；记每个有名边e的质量为t_e、hist总质量为h。对所选轨道ct=30或6，令 \(\bar t=\sum_e t_e/ct\)，则该hist对切面的贡献是
\[
(h-\bar t)\psi(a,d,0)+\bar t\psi(a,d,1).
\tag{A}
\]
这是**平均**而非裸求和，所以原row的hist底项系数直接是ψ(a,d,0)。隐含00在h−t̄中保留。只用边缘，不用1306个旧R–R辅助交叠；仅改那些交叠、K或未使用的单Y变量不能改变本五条负余量。

本次[独立核验器](../../tools/evidence/nested-reply-projection-cut-data/audit_five_cuts.py)不导入原raw/parse/row/discover，也不求LP；按S/Z/V含I式枚举完整L=0,…,6及可行I，另逐有名i,j边直接平均而不用原组重数公式。对输入列承载的12种(a,d)、两种t及五cut共120系数，5760个含交集隐藏状态全部核I抵消、端点与全域最大值相等；16hist含零质量全部保留。

五个式(A)的精确和逐一等原slack，全部严格负；第一条例如
\[
-\frac{179799525967547663502905318316518929169516299663604860609}
{118677371615053570335099947486918830972133387102693144145360}<0.
\]
其余完整分数、所有80份hist贡献及全部权重保在[当前定义级结果](../../tools/evidence/nested-reply-projection-cut-data/five-cut-definition-audit.json)和原件中。这排除的是**保持此点所列实际/hist/旧回复边缘**的完整SPE完成，不排其他权重、支持、目录或策略。
