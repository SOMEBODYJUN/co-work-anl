本对象完整处理429B冻结报告，不把空 `survivors` 当一般模型定理。生成程序3726B、相关交叉核验程序2686B及其3839B样本表均实读。程序的完整合同见[双客户池程序](../程序/双客户池的可信尾局搜索程序--程序.md)；[原报告](../../tools/evidence/two-pool-tail-search-data/original/two_pool_tail_search.json)保留全部十二字段。本次有一次未改原程序的完整入口运行，以及另写的定义级小样本核验；两种证据分别说明。

## 有限客户族、固定前缀和指定路径

有四组互不相交客户块 $X_i,A_i^{\rm priv}$，$i=0,1,2,3$，大小分别为 $x,a$；另有互不相交的 $B_1,D_1^{\rm priv},B_2,D_2^{\rm priv}$，大小为 $b_1,d_1,b_2,d_2$，且与前八块不交。每块包含相应数量独立单位客户。这里大写客户块与同字母主题标签须区分。

所有六位提供者共享18个**带标签**主题：对每个 $i$ 有
\[
 A_i=X_i\cup A_i^{\rm priv},\quad B_{i1}=X_i\cup B_1,
 \quad B_{i2}=X_i\cup B_2,\quad C_i=X_i,
\]
再加 $D_r=B_r\cup D_r^{\rm priv}$，$r=1,2$。标签按
\[
 (A_0,B_{01},B_{02},C_0,\ldots,A_3,B_{31},B_{32},C_3,D_1,D_2)
\]
编号0至17。客户终局价值在覆盖者之间均分，重复动作合法；零块不删，因而空主题或相同客户集的不同标签仍在18动作集合中。

**固定前三位的有序历史**为 $(C_0,C_1,C_2)=(3,7,11)$。前三组 $X_i$ 各已有一名覆盖者，第四组尚无覆盖者；没有固定背景覆盖任何私有块或 $B_r,D_r^{\rm priv}$。接着只研究第四、五、六人的子博弈，指定路径为
\[
 (C_3,D_1,D_2)=(15,16,17).
\]
指定第四人的终局利润恒为 $x$，三个末段动作的利润为 $(x,b_1+d_1,b_2+d_2)$。固定前缀加指定尾路径本身不是完整策略；本计算未验证前三人的任何激励，也未给每个三人之前的离轨历史规定行动。

冻结域是
\[
 x=6,\quad a=4,\qquad (b_1,d_1,b_2,d_2)\in\{0,\ldots,18\}^4.
\tag{D}
\]
注释所谓首个“5/3 row”对应 $(x+a)/x=10/6$，不是已证福利比，更不表示 $\mathrm{OPT}_6/W=5/3$。原报告没有静态最优覆盖字段，但本目录可直接解析：写 $S=b_1+d_1+b_2+d_2$，指定六人路径覆盖 $W=24+S$；四个 $A_i$ 加 $D_1,D_2$ 正好六主题，覆盖全部 $40+S$ 个客户，因此
\[
 \mathrm{OPT}_6=40+S,\qquad \frac{W}{\mathrm{OPT}_6}=\frac{24+S}{40+S}\ge\frac35>\frac12.
\]
这是这些集合的直接覆盖计算，不是搜索返回的SPE结论。即使指定路径可被实现，它在当前四组参数下也不会给六人half反例；不能把将来增加组数的放大设想计作当前六人实例。

## 全部平局下的精确三人尾局条件

用 $u_j(q,s,t)$ 表示固定前三步之后，末三人选择 $q,s,t$ 时第 $j\in\{4,5,6\}$ 人的真实终局利润。原程序计算每个 $18^3=5832$ 有序终局，所有主题都可在每一步选择。

末位在 $(q,s)$ 后的全部最佳回复为
\[
 L(q,s)=\arg\max_t u_6(q,s,t).
\]
第五人的最小可信回复门槛是
\[
 F_5(q)=\max_s\min_{t\in L(q,s)}u_5(q,s,t).
\]
给定第四人行动 $q$，可以出现在某份完整历史两人纯SPE中的终局对恰为
\[
 P(q)=\{(s,t):t\in L(q,s),\ u_5(q,s,t)\ge F_5(q)\}.
\tag{P}
\]
**必要性：**末位必须BR；第五人实际收益不能低于每个偏离动作所选的末位BR收益，而后者不低于该动作下的最小BR收益。**充分性：**指定 $(s,t)\in P(q)$；对第五人的其他行动 $s'$，选择达到 $\min_{t'\in L(q,s')}u_5(q,s',t')$ 的末位BR。有限集合保证极小值存在；所有真实离轨回复都是BR，指定行动对第五人最优。任意弱平局保留，不能只取最有利或某个固定末位BR。

因此第四人的可信门槛为
\[
 F_4=\max_q\min_{(s,t)\in P(q)}u_4(q,s,t).
\tag{F}
\]
同样的逐子博弈构造给出：**指定 $(C_3,D_1,D_2)$ 可由固定前三步后的某份完整历史三人纯SPE实现，当且仅当**
\[
 (16,17)\in P(15)\quad\text{且}\quad F_4\le x.
\tag{T}
\]
各第四人偏离动作下，可分别选择使其利润最小的可信两人续局；所有选择都在有限子树中，故能拼成一份完整有序历史策略。反向必要性来自每个已选可信续局的利润至少为相应极小值。此处是指定子博弈路径的存在判据，不是“每份续局都满足”的福利定理，也不把计数策略当作原模型的限制。

原程序 `next_floor` 对应 $12F_5$，`next_ok` 对应式(P)，`root_floor` 对应 $12F_4$。`tail_ok` 只查式(T)第一项，`root_ok` 查第二项，二者同时成立才入 `survivors`。三旧背景加至多三人，使每个正负载属于1至4，公倍数12清除全部分母；系数表和批量计算都是整数，没有浮点平局容差。域(D)客户总数至多112，利润乘12至多1344，因此被掩蔽不合法续局的 $10^{12}$ 哨兵不会被合法收益碰到。

## 两个预过滤不等式及十二字段

在指定 $(C_3,D_1)$ 后，末位选 $D_2$ 利润 $b_2+d_2$。改选任一 $B_{i1}$，所得 $x/2+b_1/2$：$X_i$ 原有一覆盖者，且第五人 $D_1$ 已覆盖 $B_1$。改选任一 $B_{i2}$，所得 $x/2+b_2$。故末位BR必要地满足
\[
 2(b_2+d_2)\ge6+b_1,\qquad d_2\ge3.
\tag{PF}
\]
这只是两个必要比较；例如改 $A_i$ 或重复 $D_1$ 的比较也由完整尾局算法处理，未由预滤替代。

| 原字段 | 原值与语义 |
| --- | --- |
| `scope` | necessary final-C three-mover tail, not complete initial-game SPE |
| `old_groups` / `fresh_groups` | 3 / 1，即三个已覆盖的 $X_i$ 和一个新 $X_3$ |
| `x` / `a` | 6 / 4，固定而非优化变量 |
| `pool_range` | 闭区间[0,18]中的整数，含零 |
| `parameter_order` | x,a,b1,d1,b2,d2，避免把两个池的私有块交换 |
| `pre_filter` | actual last D2 vs B1 and B2，准确指式(PF) |
| `prefilter_pass` | 103474组参数通过式(PF) |
| `exact_BI_checked` | 103474组均进入完整18标签反向归纳 |
| `actual_D1_D2_tail_supported` | 38130组满足 $(16,17)\in P(15)$，不代表前三人或第四人的激励 |
| `survivors` | 空表：没有参数同时满足式(T)两项 |

两组斜杠行分别包含两个原字段，合计十二字段。独立整数计数确认总参数 $19^4=130321$，通过103474，预滤淘汰26847。被淘汰者已违反一个真实末位BR比较，所以没有跳过可能实现指定路径的参数。

## 一次原入口复现与新的门槛诊断

[原程序运行记录](../../tools/evidence/two-pool-tail-search-program/rerun/execution.json)记录唯一一次未改3726B代码的原 `main`，经 `runpy` 加只读 `sys.setprofile` 观察函数返回；这不是未加包装的普通CLI。原数组、参数、函数返回均未修改；主函数1次，系数表1次，批函数809次，最后一批50组，全部103474组。运行约16.869秒，stderr空，原码前后SHA相同；生成429B JSON与冻结报告**逐字节相等**，SHA为 `0c138c7cfe67d5327c1b258fc78c56d9dd7d714bdc8b412ed18e927db10e2c6d`。

[被动批记录](../../tools/evidence/two-pool-tail-search-program/rerun/captured-batches.json)另外保留每批计数、门槛直方图和极小值。新的诊断为：

- 全103474组的最小 $12F_4=84$；指定第四人利润乘12仅为72。
- 支持指定两人尾局的38130组，其最小 $F_4=7$、最大35；另外65344组连指定两人尾局都不支持。
- 首个达到支持者最小门槛的参数为 $(6,4,0,7,4,3)$，故即使末两人可信，第四人也有至少 $7-6=1$ 的严格可信偏离。

这是本次原运行的附加观察，不冒称429B历史报告已存这些门槛。结合预过滤的必要性，可准确排除域(D)全部130321组的指定路径。它不排除别的 $x,a$、池大小大于18、其他前缀或实际路径，也不排除同一目录的其他纯SPE；“六人half已证”及“双池族无任何反例”均不是结论。

## 独立单位客户核验及接续

[独立入口](../../tools/evidence/two-pool-tail-search-data/independent_client_audit.py)不导入原oracle、NumPy或规范SPE求解器，而把整数池逐个展开成单位客户，直接对固定前缀及全部5832个有序末段终局数覆盖者，再按式(P)(F)递推。一次新运行对[历史3839B样本表](../../tools/evidence/two-pool-tail-search-data/related/tail_oracle_crosscheck.json)的十二组参数逐一核对门槛和两个支持布尔量；四个相关字段全部一致，完整BR集合与可信对存于[新结果](../../tools/evidence/two-pool-tail-search-data/unit-client-audit.json)。其中第一组 $(6,3,3,3,3,3)$ 确有 $F_4=6$ 且指定路径受支持，说明该oracle并非机械拒绝所有路径；它的 $a=3$ 在域(D)之外。

同次新增全零客户样本：仍保留18标签、全部5832叶，每个末位动作均为BR，每个第四人分支全部324对可信，门槛0，指定路径受支持。这项退化验证不属于原103474组统计。十二旧样本加零例共75816叶，约2.188秒；没有重跑作者的canonical crosscheck或第二次全参数扫描。旧样本表的每例 `canonical_count_states=1330` 是历史规范求解器字段，本次不称重现了其调用或内部状态计数。

**后续独立来源清洗补充：**[完整历史纯SPE终局全集](<../算法/完整历史纯SPE终局全集--算法.md>)现已在完整冻结规范包和原五层路径下另执行一次普通原CLI，约0.424秒，新3839B报告逐字节等冻结表；这补齐的是作者交叉入口的当前运行事件，十二点的1330计数状态也在该事件重现。它不是上段自主单位客户核的一部分，不增加那两次自主入口的叶数，不重复完整103474参数扫描，也不认证初始六人完整策略。全零客户仍只由自主单位客户入口处理，原canonical实例构造器直接接收零x/a会拒绝正重数类型。

随后仅对新观察到的首个极小参数另跑[单例入口](../../tools/evidence/two-pool-tail-search-data/audit_minimum_case.py)，再加5832叶，独立确认 $F_4=7$、指定两人尾局可信而三人指定路径不可信。[单例明细](../../tools/evidence/two-pool-tail-search-data/minimum-supported-tail-case.json)中例如第四人改 $A_0$，在全部可信两人续局的最低利润就是7；$b_1=0$ 时 $B_{i1}$ 与 $C_i$ 覆盖相同，算法仍保留不同标签及其全部弱平局。两次新定义级核验合计81648叶，只认证这些14参数点及预滤整数计数；有限全域结论仍依赖已逐字节复现的原完整搜索，而非伪称另一份独立全域证明。

与[九客户两池完整三人SPE](../构造/两诱饵池目录的九客户完整均衡边界例--构造.md)有共同的单位客户集合设计，但该构造无旧背景、仅六标签、附43个有序历史的完整策略。本对象有三个固定旧提供者、18标签，只考察后缀；不能把九客户策略直接贴到这里，更不能免费增加影子玩家搬运。后续可按(D)外新域另行搜索，或固定一个通过(T)的参数后构造并核验前三人的完整离轨策略。这里保留的精确尾局条件、所有平局与有限排除域，就是这份空报告可复用的内容。
