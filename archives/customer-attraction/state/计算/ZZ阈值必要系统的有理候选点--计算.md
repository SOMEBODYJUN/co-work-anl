# 同一模型中的R、Z与固定旧点

模型仍是有限单位客户、有限非空共同主题目录、六名单位提供者依全部有序历史行动，终局客户在覆盖者间均分。空主题、重复行动、同覆盖标签、零客户及任意离轨平局均保留；[完整定义](../定义/共同目录完整历史模型--定义.md)中的σ必须在所有有序历史定义。

为解释必要行，设σ是一份完整纯SPE，实际路径A₁,…,A₆，h=(A₁,A₂,A₃)。强制第四位Tᵢ后的真两尾为Bᵢ,Cᵢ，定义

\[
R_{0,i,j}=\sigma_6(h,T_i,B_j)\quad(i\ne j),\qquad
R_{1,i,j}=\sigma_6(h,T_i,C_j)\quad(\text{全部 }i,j),
\]
\[
Z_e=\sigma_6(A_1,A_2,A_3,A_4,R_e).
\]

两族共有30+36=66条带索引边。R、Z在各自源是真末位回复，强制的前一步并未被假定最优；必要点里的同名主题标签不反过来给出这样的σ。旧图含最优比较行时，T六元组须具备相应最优比较身份。

固定源是[attractive_nested_exact.json](../../tools/evidence/combined-branch-master-program/dependencies/research/workspaces/customer-attraction/R-c4f1ef099fad483c9f81283b61eb0b53/six_astra/attractive_nested_exact.json)，源ID `dfc2594ca7e3f26b6d7f`，816498B。其1905列包括K一列、16个hist、194组各三态的582个joint-reply及1306个R-R辅助交叠。hist记录实际六位a及六词wᵢ=(Tᵢ,Bᵢ,Cᵢ)的八桶计数，词序为000至111。组g=(family,1[i=j],wᵢ,wⱼ)保索引相等与词相等之别，不能把同词非对角删掉。

在质量H的hist内，三存量x₀₁,g、x₁₀,g、x₁₁,g是(R_g,Z_g)质量，隐含00为H减三者。固定R边缘

\[
q_g=x_{10,g}+x_{11,g},\qquad 0\le q_g\le H.
\]

本点保K、hist和全部194个q_g；不保旧Z边缘、旧R/Z二维边缘或1306个辅助交叠的原值。K仅作为原图容量参数原值携带，不是由本页代表原子重新定义的“最大主题大小”。

# 阈值层与1905坐标的恢复

在每个H>0的hist上共同定义R_g=[0,q_g)，切点为{0,H,q_g:g}。对相邻正长度层s=[l_s,u_s)，令m_s=u_s−l_s、r_sg=1[u_s≤q_g]。记录weight记z_sg。于是

\[
x'_{10,g}=\sum_{s:r_{sg}=1}(m_s-z_{sg}),\quad
x'_{11,g}=\sum_{s:r_{sg}=1}z_{sg},\quad
x'_{01,g}=\sum_{s:r_{sg}=0}z_{sg}.\tag{1}
\]

零态为Σ_{s:r=0}(m_s−z_sg)，R边缘仍q_g。所有R-R交叠同时变成min(q_g,q_f)，不是分别挑选不相容的两两交叠。K/hist保持原值。这给出旧1905坐标的仿射映射；K直接携带，其他会员矩由原子积分恢复。

# 一个明确的共同会员完成

每个R层内R位都固定。取第二个共同坐标v∈[0,m_s)，同时设

\[
Z_g\cap s=\{v<z_{sg}\}.\tag{2}
\]

按{0,m_s,z_sg:g}再次切层。每个正小段的R、Z位都确定，质量是相邻断点之差；全部断点有理且质量非负。当前25个R层产生42条正质量代表原子，逐原子将固定actual六位、按八桶展开的六个T/B/C词、66个R位和66个Z位连接成156位串。标签的精确次序由报告theme_labels保存，原子表含hist、R层号、Z断点和质量，足以重新生成整份会员测度。

这不是原脚本的唯一完成。原说明允许在R层内条件独立生成各Z；这里选共同嵌套Z。两者具有相同z_sg，而所用旧坐标与Z→Z行在R固定后只依这些边缘和仿射量，所以都实现同一个已验证的必要点。不同Z-Z交叠尚未由本数据指定；式(2)把它们取为各层min，不能据此免费认证任何后续新行。

42数的是规范词序下的**带权代表原子**，不是42个单位客户或一份42客户SPE。若要保持六比较索引的交换对称命名，可以对每条原子连同T/B/C、R/Z的全部相关索引同时取6!种置换平均，至多42·720条带权记录；不能只置换T而冻结相应R/Z标签。此平均不改变所用hist/轨道矩，但未在本页认证全部未聚合索引IC。全部权有理，统一清分母后可用单位客户副本实现这些会员，仍没有构造完整σ。

保留所有156个有名槽，包括可能空或同覆盖的主题，不要求它们两两不同。所有hist的d=1是本固定支持的性质，不是给一般共同目录问题添加比较主题不交假设；六个T在该会员测度上覆盖全部质量。独立积分得到

# 六十个Z→Z槽到底认证什么

对实际前四负载pₐ和任意两带索引边e,f，真实Z_e在强制R_e后的末位节点必须满足

\[
\sum_x\frac{1_{Z_e}(x)-1_{Z_f}(x)}{p_a(x)+1+1_{R_e}(x)}\ge0.
\]

固定R层后的贡献是(z_se−z_sf)/(pₐ+1+r_se)。按边族对和四索引的相等模式相加，得到2×2×15=60槽；66²个有序边对保索引重数，不按覆盖集合去重。18槽因第一族禁止对角而为空，另有恒等自比较槽，不能把60叫60个独立约束。

本点60个精确聚合余量为29正、31零，无负值。新核把42个156位原子直接代入上式、逐个索引边对积分，全部60分数与先前独立层质量审计逐项相等；报告保完整向量。最小0不是均衡严格性的结论，零也包含空槽；模型本来允许弱平局。这里核的是这些指定必要关系，不是任意未列查询或完整离轨策略。
