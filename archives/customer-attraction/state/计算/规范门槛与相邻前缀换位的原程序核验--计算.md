# 原程序、真实输入及一次复现

原2687字节Python程序及991字节冻结报告均全文实读。程序只用标准库Fraction、lru_cache、product、Path、json，五份目录/人数直接写在源码中，无外部输入。执行前检索结果仓库及本会话缓存的脚本/报告名，只有库存候选与本次导出，未见同SHA已有成功复现；于是复制原字节到新空replay目录执行一次，assert开启，exit0、stderr空。

新报告991字节与冻结报告逐字节相同；实际命令、代码/报告SHA、UTC起止和输出在[execution](../../tools/evidence/netcap-bubble-primary/replay/execution.json)。完整[stdout](../../tools/evidence/netcap-bubble-primary/replay/stdout.txt)、[stderr](../../tools/evidence/netcap-bubble-primary/replay/stderr.txt)和[新报告](../../tools/evidence/netcap-bubble-primary/replay/netcap_bubble_exact_audit.json)保留。程序用 `open('x')` 新建报告，后续须另建空目录复制原码复现，不能直接在含保存报告的replay目录重跑；原件没有修改。

# 递归端点与三个检查的真实域

对给定有限目录和m，程序计算完整终局的Fraction均分收益。终端历史h的ends(h)={h}；当前角色i=|h|时，先求全部行动孩子集合，再取 floor=max_a min_{z∈ends(h,a)}u_i(z)，合并所有孩子中u_i(z)≥floor的端点。它由有序历史索引，未把固定策略的平局压成计数策略。

FLOOR检查遍历每个历史h及每个原动作尾z，验证 z∈ends(h) 当且仅当所有未强制后缀角色均过各自门槛。每个深度都有k^m个(h,尾)对，所以每例为(m+1)k^m项。它使用同一递归实现及其threshold字典，不是第二独立求解器，也未枚举全部完整策略树。

COPY检查遍历每个强制孩子端点z、未来j及复制原进入行动A后的所有候选孩子端点z′，仅保u_j(z)≥u_j(z′)的对；若A本来就是该角色规定行动，还排除z′≠z。对保留对核同主题收益相等及净成本差。此处Γ非负来自显式收益筛选，不是从一份已保存固定σ的所有离轨策略逐项读出。各对的局部身份与有限代数正确，不将108对冒称同一全局策略证书。

BUBBLE检查遍历每个根可实现终局作为actual路径、每个i<m、查询A及两强制行动(h_i,A,b_i)后的尾SPE端点。换位到(h_i,b_i,A,Y)，检查新端点属于其孩子端点集、删除负载相等、进入收益相等，以及净成本差=M(h_i,A)−u_{i+1}(z)。其genuine尾可搬运，但没有检查搬运后就是原σ在到达行的source分布；也没有行容量、η相消或付款金额测试。

# 证据边界与接续

有限QA没有求净cap LP、输出其对偶、构造协方差付款或核任何六人实例；它也没有验证任意多源流的到达质量等于下一actual-prefix行source。一般[相邻换位引理](../引理/相邻实际前缀换位的保背景续局与净成本差--引理.md)由完整尾部策略同构及代数承重。原报告自己声明非HALF证据，本次保持该范围。

三主来源已全文实读并逐原指纹保全，见[证据说明](../../tools/evidence/netcap-bubble-primary/README.md)；两数学/程序对象按恒等证明与有限实现关系相连，不把一份程序对同定义的回算冒称独立证明或外部审稿。五人现另证half与当前六人目标均不由这五个输入裁决。
