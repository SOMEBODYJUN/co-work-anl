# 原搜索的准确数学与实现合同

设$B\subseteq[p]$为非空客户兴趣mask，质量$w_B\ge0$，终局计数$c$满足$\sum_ac_a=m$。主题$a$一个提供者的收益系数为

\[
 f_{c,a}(B)=\frac{\mathbf1_{a\in B}}{\sum_{b\in B}c_b},\qquad
 C_c(B)=\mathbf1_{\sum_{b\in B}c_b>0}. \tag{1}
\]

只在实际有该提供者的终局取正分子，未覆盖客户项为0。`Search`枚举各深度计数、全部终局、全部非空类型和大小$\min(m,p)$的比较支持。以$L=\mathrm{lcm}(1,\ldots,m)$整数化(1)。当前保存m5/m6均$L=60$，系数能放入int16；任意大m、巨大整数权下没有溢出守卫，不能把有限机器整数实现无条件宣称任意规模精确算术。

对固定质量，集合值BI为

\[
 M(c)=\max_a\min_{t\in R(c+e_a)}u_a(t),\qquad
 R(c)=\bigcup_a\{t\in R(c+e_a):u_a(t)\ge M(c)\}. \tag{2}
\]

它涵盖完整历史可实现**终局集合**：当前对不同动作的子树可独立选一份子SPE；保存集合的计数缓存不要求相同计数有序历史统一回复。源码整数输入比较用容差0，float输入改用$10^{-8}$，后续cone选择另用$10^{-7}$；不能把float路径称为精确集合值BI。

`cone`以扩充状态$(i,t)$固定一份策略：$i$是当前计数的索引，$t$是希望达到的终局索引。规定行动选能保$t$的一个动作；其余动作选择一个真实可达终局作为偏离孩子，`min`模式取对偏离者最低收益，`any`模式从不超过当前可付值的孩子中抽取。相同$(i,t)$复用只构造一份图，不宣称每份SPE都匿名。记录`[i,t,a,branches]`保全部$p$个改变历史后的孩子目标。

每个完整图的真正非负行是

\[
 \Gamma_{h,b}=L[f_{z(h),\sigma(h)}-f_{z(hb),b}],\qquad
 \Gamma w\ge0. \tag{3}
\]

程序删除零/重复行，转float后解固定图客户锥LP：$w\ge0,\Gamma w\ge0,C_{\rm root}w=1$，最大化**选定**比较支持覆盖。`all_j=false`只选进入LP前质量上一个最大比较支持；`true`才逐个支持求解并选最好成功值。新质量恢复后没有重新运行BI或全面精确验收；若非all-j，更没有在本轮LP内重新最大化全部比较支持。

`record.ratio`来自优化前seed的集合值最小福利终局；随后`random_roots`可改实际被优化的root，但不重算该ratio。`cone_value`来自优化后新质量，不能把两个数视为同一输入的两个认证效率。源码只有潜在越2时打印“需要精确全历史核验”，没有自动做该核验或保存对偶。浮点optimal及有限未越界均不证明整个策略类的上界。

# 保存图如何覆盖全部有序历史

本轮独立标准库核不导入原搜索或数值库。按每层计数元组的字典序重建$i$及终局$t$的索引，逐行检查合法范围、唯一键、目标包含旧计数、每行$p$个孩子，以及规定行动的孩子目标仍等于$t$。每条边增一个合法动作，最后一层孩子必须恰为该终局计数；所有非终局孩子键都存在，所有保存键从根可达。

因此每个有序历史$h$从根沿它的动作序列得到唯一$(i,t)$，并继承该键的规定行动。归纳向下，规定终局就是$t$，强制$b$后的真实终局就是`branches[b]`；对所有可达键检(3)便覆盖这份完整有序策略的全部节点IC。还用整数路径重数检查第$d$层恰$p^d$个有序历史。没有物化全树，不能把逻辑覆盖数量冒充实际逐键展开次数。
