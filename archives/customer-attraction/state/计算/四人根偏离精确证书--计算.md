# 四人真实根偏离的完整会员域精确核验

## 资源合同

本资源对应[四人1499/750福利定理](../定理/四人真实根偏离福利界--定理.md)。
两份程序分别从逐客户的终局均分收益重抄12个slack、12个乘子与128系数表；互不导入，也不导入LP、SPE求解器、规范模型或发现程序。
只依赖Python标准库，使用 `fractions.Fraction`，没有浮点容差、随机种子或外部输入。
主程序唯一可选输入 `--output` 只是输出路径，并以排他创建模式写入；独立程序只向stdout输出。

程序迁入本存档时保持原字节。两者没有以相对路径读取外部资源，故目录迁移无需改程序或任何运行资源路径。
主程序的 `source_sha256` 只读取自身字节，迁移后值保持一致。

## 两份程序实际核对什么

主审计直接重建实际背景、真实根偏离路径的均分份额，独立重建 $P,E,F,K_T,L$。
每个会员型的12个slack逐客户值**无需分别非负**；其客户总和的非负性来自定理中的SPE节点比较。
程序只断言加权恒等式及余项符号，避免把局部会员型误认作一个均衡。

| 检查 | 主审计 | 独立审计 |
| --- | ---: | ---: |
| 实际背景 $AB$ 与四比较主题的全部会员位，核对配对下界 | 64型 | 64型 |
| 实际背景 $ABC$ 与四比较主题的全部会员位，核对末位下界 | 128型 | 128型 |
| 实际 $ABCD$ 与根偏离后继 $QRS$ 全域，核对128余项表 | 128型 | 128型 |
| 最小余项、零余项数 | 非负；由表可见4个零 | 最小0；4个零 |
| 独立 $O$ 符号检查 | $O=0,1$共256个完整恒等式，另核对乘子和为1 | $O=-17/3,0,5/7$共384个完整恒等式，另核对乘子和为1 |
| 一般分母与聚合实现核对 | $m=1,\ldots,8$，1200项 | $m=1,\ldots,9$，1320项 |
| 一般最优索引对计数实现核对 | $m=2,\ldots,8$，3076项 | $m=2,\ldots,9$，7172项 |

主程序的1200项还包含逐客户真实分母与最坏分母的比较；独立程序的1320项是其独立聚合循环，计数定义不同，不能将二者视为同一覆盖域的两个计数。
两份程序均逐一检查12个乘子与相应完整表，主程序显式检查全部乘子非负，独立程序抄录的12个整数均正。

128型枚举是固定七个主题标签下每个客户可能会员位的**完整系数域**，不是128个有限游戏。
所有有限客户实例都能按这128型分组，所以其余项判号加任意非负整数重数求和覆盖任意客户数。
SPE量词和各slack的非负性仍需数学证明；两份脚本不会验证整个策略树，也不声称其枚举能认证SPE存在或全称量词。
一般人数接口的全称证明是定理正文中的分母单调性和索引配对计数；有限 $m$ 核对只检查实现，没有证明任意人数half。

## 本轮重放与历史记录比较

从冻结源导出的两个原字节程序实际执行成功：

```sh
python3 archives/customer-attraction/tools/evidence/four-player-bound/customer_attraction_four_player.py
python3 archives/customer-attraction/tools/evidence/four-player-bound/customer_attraction_four_player_independent.py
```

保存的本轮输出为[主重放JSON](../../tools/evidence/four-player-bound/replay/customer_attraction_four_player.json)和[独立重放JSON](../../tools/evidence/four-player-bound/replay/customer_attraction_four_player_independent.json)。
主重放JSON与历史主报告完全相等。
历史独立报告另有人工加入的 `claim`、`source_sha256`、`scope` 三个元信息字段；该程序本身不输出这三个字段。
删除历史记录的这三个字段后，其全部计算字段与本轮输出完全相等。
历史报告中的脚本SHA与实际交付原字节一致；没有把带元信息的历史文件冒充本轮stdout。

本批完整实读四人原稿、两份源码与两份历史输出，检查原稿的节点前缀和分母，并实跑两份源码。
复跑确认算术与源码身份，不新增外部同行评审，不认证最优常数。
当前[五人half](../定理/五人半覆盖--定理.md)另有更强的系数域和真实分支；本资源不为五人旧界或六人目标提供额外证明。

关系判断：这是四人定理的精确算术实现与复跑证据，不是其SPE量词的独立来源；与三人或五人审计共享方法并不自动形成数学推导边。
