# 随机锥安全搜索与背景二元精确回归

## 1. 对象和量词

这三份来源属于同一轮 R275 `direct_global` 探索，但承担两种不同证据。`random_max_utility_gc.py` 在已经定义的计数状态锥 `Cone(p,n)` 上取伪随机权重，按固定随机种子 8932 对 `(p,n)=(5,3),(6,4),(7,5)` 各做 20 次迭代，再从每次根节点的前三个候选目标上解有限 LP。它寻找的是给定有限状态压缩、给定候选策略和给定权重集合里的数值边界；它没有枚举所有纯策略、所有客户目录、所有历史或所有平局。

`verify_background_pair_circuit.py` 是另一条精确 `Fraction` 回归。它枚举有限的 `h,r,s` 与二元成员变量，检查两个四类成员恒等式和一个三元差分恒等式，并加测一项 `r=2,s=1` 的特例和 1000 个 `h` 的收费上界。这个程序检验的是局部代数电路，不是客户吸引模型的完整 SPE 搜索。

因此本文同时保留有限浮点候选、有限精确回归和未完成的一般桥接义务，不把它们合并为一个全称定理。

## 2. 随机锥脚本的实际结构

脚本从 `cone_floor_attack.py` 导入既有 `Cone` 实现。每次迭代为 `len(f.M)` 个目录权重从 `{0,0,0,1,2,4,8,16}` 抽样，建立固定权重的计数锥，取根节点覆盖量排序前三个 target。对每个 target，源程序计算固定策略的 `gamma` 行、`loads`、覆盖指示 `covered` 和

\[
 g_c=\frac{\mathbf 1\{load_c>0\}}{1+(n-1)load_c/n},
\]

再以 `objective = gc - coefs[target,a]` 解

\[
 \min_x\; (g-c_{target,a})^\top x,
 \qquad \Gamma x\ge0,
 \qquad \mathbf1_{\{load>0\}}^\top x=1,
 \qquad x\ge0.
\]

脚本只更新当前最小浮点目标 `best`，若发现 `best<-10^{-7}` 就打印 `BRIDGE FAIL` 并退出；否则完成三组有限样本后打印 `DONE`. 这种停止条件最多能发现一个数值负例，不能从“未发现负值”推出所有策略的安全桥。

冻结的 `random_max_utility_gc_best.json` 给出一个边界记录：

| 字段 | 值 |
|---|---|
| `p,n` | 5, 3 |
| `target` | `[0,1,1,1,0]` |
| `a` | 1 |
| `weights` | 30 维向量，只有索引 13 的权重为 1（其余为 0 或负零） |
| `slack` | 0.0 |
| `policy` | 31 个历史到动作映射，包含根空历史和长度 1、2 的有序历史 |

这是一条“恰到边界”的有限浮点记录。它没有负桥余量，也没有随 JSON 一起提供有理对偶、LP 证书、所有策略枚举或完整 SPE 偏离表。与前一份 R275 固定锥记录合看，应该把它归为候选/诊断，而不是已证明的全称安全值。

## 3. 本轮重放边界

我把两个 import 依赖和三份冻结源复制到本对象的证据目录，并核对了 manifest 中的字节数和 SHA。用这些依赖启动随机脚本，实际先重现了 `p=5,n=3,iteration=0` 的边界输出 `slack/W 0.0`, `target [0,1,1,1,0]`, `a 1`；完整随机 LP 扫描没有在本轮执行时限内完成，因此不声称打印了最终 `DONE` 或重新生成了冻结 JSON。该边界和冻结 JSON 一致，但一致性不等于全扫描重放或数学证明。

这项限制保留了浮点求解、权重随机性、候选前三筛选和策略 tie-breaking 的实际风险。若要升级为可重放运行，后续应固定 SciPy 版本、保存每个迭代的 LP 状态/seed、用有理化或独立对偶检查验证零边界，并单独证明计数锥和完整策略空间之间的映射。

## 4. 背景二元电路的精确结果

`verify_background_pair_circuit.py` 用 `Fraction` 逐项枚举：第一段遍历 `h=0..15`、`r,s=1..11`、`xa,xb∈{0,1}`；第二段遍历 `h=0..15`、`r,s=1..9` 和 `xa,xc,xb∈{0,1}`；第三段遍历 `h=0..999` 与 `xb∈{0,1}`。源代码按四种成员情况给出误差：仅 `a`、仅 `b`、两者都在、两者都不在，并断言误差非负；另验证 `r=2,s=1` 的特殊恒等式和三元误差差分。实际运行输出为：

```json
{"status":"pass","exact_finite_algebra_checks":11984,"scope":"Regression only; general identities proved by four membership cases in note"}
```

这个 11,984 项检查是可复现的精确有限回归。它支持相应背景交换/二元电路的逐情况算术，没有客户目录、均分收益、完整有序历史或六人纯 SPE 的量词，所以不能直接推出 `Q-CAG-HALF-6` 目标。原程序自身把一般恒等式归因于四种成员情况；本文保留该证明责任，不用有限样本替代推导。

## 5. 与既有对象的关系和未决缺口

本对象依赖前一批 R275 固定锥/地板扫描记录中的 `Cone` 和 `floor_scan` 定义，但新增内容是随机权重搜索的停止逻辑、一个零浮点余量的具体 5×3 记录，以及 11,984 项 `Fraction` 局部恒等式回归。它与五人 q32、六人安全审计和后续十三人桥纠错保持独立，不把“锥内零余量”当作完整策略半因子。

保留的缺口有三类：随机锥只搜索预先构造的状态锥；完整 LP 扫描本轮没有跑完；二元电路回归没有把局部恒等式接到客户均分和所有历史的全局预算。未来若要接续，应先给出锥到完整纯 SPE 的逐历史映射，再给出有理零余量证书和共同预算付款，而不是继续累积未审计的随机样本。
