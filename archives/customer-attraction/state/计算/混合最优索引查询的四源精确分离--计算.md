# 混合最优索引查询的四源精确分离

本计算没有分离指定点。原程序在四种源上各算60个混合比较行，全部240个精确值严格正，`negative_count=0, negative_rows=[]`。这是明确有限银行的阴性结果，不是完整扩展可行、所有(P7)实例冗余或原SPE已补全的证明。

## 1. 准确输入与模型

普遍行的模型是五名单位提供者、有限单位客户、有限非空共同带标签目录、每份全部有序历史纯SPE，保留非单射覆盖、空主题、重复、零客户及全部平局。每次偏离仍沿同一原σ。被计算的输入则是必要条件有理点，不是已给出完整σ的真实游戏。

唯一输入 `exact_current_source_own_index_v1.json` 的字节SHA为 `29e0b3e0c07884ad2565999c373db36ff32ea4b77c79a61ef52e12cdc8e3286e`，52,499B、63个严格正有理原子。它保十旧位bits、五最大根位max_bits、AB/AE各8格、Sbranch16格直方图、三个menus_lh及exact_mass。每直方图总五，共同首位计数d相同。[成熟输入原件](../../tools/evidence/five-root-parent-audits-primary/source-root/research/workspaces/customer-attraction/R-d3981c0168644971803a9c3380ed687c/round8_five/certificate/exact_current_source_own_index_v1.json)全部字段本次再次消费。

文件内 `source_sha256=da80d967ea3223c878375ef04aba8aa245ef4b4bc764b5aad225e2bb4e3ca5a3` 指其上游6750行浮点发现 `trueH_own_index_discovery.json`，不是本输入字节SHA。`source_rows=6750/minimum_source_exact_slack=0` 是恢复输入的旧系统声明，本计算不重构6750行。另一个同为63原子的actual13_v1输入SHA5930c355...不可与29e0互换，见[两历史归因](../程序/两种第三位历史的共同目录抬升与分离归因--程序.md)。原报告绝对source路径是旧环境记录，当前从同SHA已存原件读取，不补原argv。

## 2. 混合比较菜单的普遍公式

使用[七行投影及3×6表](../引理/真实第三位投影的五人最大根包络--引理.md)：对真正第三位、合法五槽D/J菜单，

\[
17040u+1085K-2679\sum_xj_x/(p_x+3)-\sum_xF(p_x,d_x)\ge0.\tag{P7}
\]

真实节点与表值在[补全程序合同](../程序/真实第三位投影的菜单补全与续价合同--程序.md)亦列全。D/J只需合法，不需最优；原推导未用最优性。

固定五比较索引T₁…T₅，客户会员数d。对固定合法Q、会员q∈{0,1}，任选r个不同索引保留T，其余5−r槽全放Q，再平均全部 $\binom5r$ 个子集。保留会员数s的超几何概率给

\[
\boxed{F_{mix}(p,d,q,r)=
\sum_{s=0}^r\frac{\binom ds\binom{5-d}{r-s}}{\binom5r}
F(p,s+(5-r)q).}\tag{1}
\]

越界二项式为零。即使标签重复，索引子集仍分别计数。同一个全局均匀索引子集同时用于所有客户；线性期望允许用每客户的超几何边缘求和，不是假设各客户独立选子集。每个混合D菜单合法，(P7)的其余源/J项相同，平均只将F换成(1)，仍为必要行。没有为每客户另选目录主题或改变σ。

## 3. 四源上下文与两个有限银行

Q固定银行为十旧标签 `ABCDEUVWXY` 加z₀…z₄，共15个；同一个Q用于整条源查询。

| source | 客户背景 | 当前客户收益 |
|---|---|---|
| max | z₀+z₁ | z₂/Σz |
| actual | a+b | c/(a+b+c+d+e) |
| second | a+e | u/(a+e+u+v+w) |
| indexed | a+θ₀ | θ₁/(a+Σθ)，按Sbranch直方图求和 |

前三源J银行各23个：15个固定标签各重复五次、原五比较opt、AB/AE各两个回复菜单、Sbranch三个菜单。indexed银行亦23个：15固定重复、opt、Sbranch三个菜单，再加每个原索引自己θ₀/θ₁/θ₂/θ₃各重复五次的own0..own3。后四者依赖原索引θ，必须保匹配，不是把跨索引菜单总数复制五次。

对原子a、质量mₐ，固定源上下文权重n=1，indexed按其型nθ。精确行值为

\[
\mathcal L_s(Q,r,J)=\sum_a m_a\sum_\theta n_\theta
\left[17040u_{a\theta}+1085m_a^{max}
-\frac{2679j_{a\theta}(J)}{p_{a\theta}+3}
-F_{mix}(p_{a\theta},d_a,q_a(Q),r)\right].\tag{2}
\]

固定源内层仅一项；indexed为完整16型直方图。$m^{max}$ 是裸最大主题z₀会员，与质量mₐ不同。零分子份额取零。

## 4. J在整个源上选择，不能逐客户切换

J只在式(2)的线性查询部分出现，与Q、r无关。定义

\[
C_s(J)=\sum_a m_a\sum_\theta
\frac{n_\theta j_{a\theta}(J)}{p_{a\theta}+3}.
\]

原程序在整条源的23候选中选 $J_s^*\in\arg\max C_s(J)$；实现以J与opt的行差累加，等价于此最大化。没有让每客户各选J。对银行内所有J，

\[
\mathcal L_s(Q,r,J)-\mathcal L_s(Q,r,J_s^*)
=2679[C_s(J_s^*)-C_s(J)]\ge0.\tag{3}
\]

因此每源只需显式算同一个最强J下15×4=60行；不是把5520条都实际循环。240个显式结果经(3)还逻辑涵盖该固定银行 $4·23·15·4=5520$ 个组合。这只属于本点、本银行和r=1..4，不是任意合法J或完整投影扩展可行。
