# 末两人保底的完整有序策略精确核验

本资源服务于[末两人逐人保底及全人数推论](../定理/末两人逐人保底与全人数弱福利界--定理.md)，
不承担该定理的普遍量词。程序只依赖Python标准库及读取所在仓库提交号的Git。
原程序、冻结报告、逐源指纹和本轮重放报告一并保存在
[last-two-floor证据目录](../../tools/evidence/last-two-floor/PROVENANCE.json)。

## 实际检查内容

`utility` 从主题标签兴趣位掩码及单位客户重数直接计算每份完整终局收益；
`verify_policy` 要求策略恰覆盖所有合法有序决策历史，再逐节点比较原策略每个偏离后的真实续局。
未导入规范 `ExactSPESolver` 或外来求解器，故没有把同负载历史误合成一个固定回复。
`check_spe` 对每个实际两人前缀重算局部 $\theta(P)$，并对每个即时最大主题的**所有**末位最佳回复验证逐人保底。

程序还核验目录计数预算、逐人 $K/n$、总福利等于收益和，以及消去 $K$ 的有理系数。
边界包含大整数背景 $10^{40}$、零客户、空覆盖标签、同覆盖标签、不感兴趣客户、单主题，
并把零人和一人单列；并未将零人纳入末两人定理。

| 范围/结果 | 数量 |
| --- | ---: |
| 两主题三人，三个非空兴趣类型重数各取0、1、2 | 27个输入 |
| 三主题两人，七个非空兴趣类型重数各取0、1 | 128个输入 |
| 全部完整策略 | 13,824 |
| 其中通过全部历史最优性的完整SPE | 1,248 |
| 边界与种子20261010生成的选定完整策略 | 45 |
| 末节点数值历史检查 | 1,842 |
| 末两人有序历史检查 | 2,297 |
| 逐客户差值/标量检查 | 24 / 3,472 |

运行确实出现相同主题计数但不同末位回复的合法完整SPE；本轮重放所有断言通过。
与原冻结报告比较，只有 `base_commit` 随本结果仓库而改变，数学计数、种子、脚本SHA-256及全部结论字段相同。

## 复现

从结果仓库根执行（不要使用 `python -O`）：

```sh
python3 archives/customer-attraction/tools/evidence/last-two-floor/original/tests/audits/customer_attraction_last_two_floor.py
```

结果输出到stdout；[本轮报告](../../tools/evidence/last-two-floor/replay/report.json)和
[原冻结报告](../../tools/evidence/last-two-floor/original/evidence/runs/2026-10-10/customer_attraction_last_two_floor.json)
分别保留。脚本有显式 `__debug__` 检查，防止禁用断言的运行被错当通过。

该程序能查实现及所列有限范围的错误；它未穷举任意客户、任意目录或任意人数。
源稿的普遍证明、内部审查与本轮可复现检查是不同证据层级。
