# R-3002 根行必要条件点与独立满立方审计

- **稳定 ID**：R-3002-batch-20261031
- **类型**：计算
- **来源**：八个 R-3002 源，清单见 `tools/evidence/R-3002-batch-20261031/source-manifest.json`。

该批的对象是旧六人根行/查询行的必要条件松弛。`baseline_exact_primal.json` 的 36 类型点满足 235 条旧根行，`K=1`、`O=21/5`，QL 标量余量严格为负；因此指定旧行系统不足以推出该标量不等式。这个负余量没有 SPE 语义。

`audit_root_rows.py` 独立重建五个 root requery 证书，在最多 `2^21=2097152` 个 membership 状态上检查系数残差；五个证书的 `min_residual=0`、`zero_states=1`，并都在旧 exact point 上得到负分离余量。`audit_requery_merged.py` 以合并后的路径玩家收益重算四个证书，最小非零类型整数残差为 210、120、190、180，确认其局部行代数与来源历史一致。

`augmented_point_audit.json` 保存 3889 条旧生成器关系加五条标量 root 行的精确可行点；五条新 slack 中四条为正、一条为零，W 约为 0.477，仍是必要关系点。它不包含终局策略动作、完整历史偏离或平局选择，所以不能称纯 SPE，也不能作为六人目标的半覆盖反例。重跑旧生成器受缺失的冻结 `six_maxroot`、`query_closure` 与 `general_payment` 树阻断，阻断证据已保存并写入 validation。

接续时应使用这些对象作为“旧必要行不足”的关系证据，另行补齐合法共同目录、六提供者完整历史和终局任意平局条件；不要把线性分离余量升级为模型结论。
