# 真尾利润与共同末价组成什么必要行

数学模型为有限单位客户、有限非空共同目录、六名单位权提供者依次观察全部有序历史选主题，终局按覆盖者均分客户价值。空主题、重复选择、零客户及所有离轨平局保留。固定同一份完整纯SPE \(\sigma\)，真实偏离后沿它在改变后的有序历史继续；目标问题量化每份完整SPE，而非选择一种有利续局。

实际路径记为 \(A_1,\ldots,A_6\)。在实际前三位后强制第四位选比较题 \(T_a\)，其真实第五、六题为 \(B_a,C_a\)。定义

\[
R_{0,a,b}=\sigma_6(A_1,A_2,A_3,T_a,B_b)\ (a\ne b),\quad
R_{1,a,b}=\sigma_6(A_1,A_2,A_3,T_a,C_b)\ (所有a,b),
\]
\[
Z_e=\sigma_6(A_1,A_2,A_3,A_4,R_e).
\]

这些R/Z都是目录中的合法主题；本程序在别的实际源节点强制选它们时，只需其合法性，不把其原节点的最佳回复身份搬过去。变量member=0取R，member=1取Z；三轨道为 `(0,0)`、`(1,0)`、`(1,1)`，有序边数分别30、30、6。同索引与同会员词不同，重复主题不合并掉槽数。

取原程序源编号 \(i\in\{1,2,3,4\}\)，对应实际第 \(i+1\) 位。源前客户负载 \(b_x=\sum_{k\le i}1_{A_k}(x)\)，实际前五位负载 \(\ell_x=\sum_{k\le5}1_{A_k}(x)\)，实际源收益为 \(u_{i+1}\)，共同末位收益为 \(u_6\)。强制该源选一个R/Z主题F，客户会员位t；其后有 \(r=5-i\) 名按同一策略行动的真实后继，客户总会员数z取0至r。

可用任意合法背景的尾利润常数为

\[
\beta_1=1,\qquad\beta_2=3/2,\qquad\beta_3=5/3,\qquad\beta_4=1499/750.
\]

后两者分别来自[三人背景利润](../定理/固定背景三人利润界--定理.md)、[四人背景利润](../定理/固定背景四人利润界--定理.md)；两人由[两人税界](../引理/固定背景两人税界--引理.md)及逐客户税不超过实际尾利润一半得到。这里应用于强制F之后的真实子SPE，背景是 \(b+t\)。没有使用五人根half代替五人任意背景利润，因此循环不包含实际第一位所需的r=5。

对某一合法比较r元组或其凸平均，令客户比较总利润为 \(R_c\)。给定两个**整行共同**非负数 \(\alpha,\gamma\)，定义

\[
\Psi(b,\ell,t,R_c;r,\alpha,\gamma)=
\gamma R_c+\min_{z=0,\ldots,r}
\left\{\frac{t-\gamma\beta_rz}{b+t+z}+\frac{\alpha z}{\ell+1}\right\}.
\]

零分子项取0，涵盖分母同为0。对一个强制主题F有

\[
u_{i+1}+r\alpha u_6\ge\sum_x\Psi(b_x,\ell_x,t_x,R_{c,x};r,\alpha,\gamma).
\]

这是[真实后继利润与共同末价下包络](../引理/真实后继利润与共同末价的离散下包络--引理.md)的实例。三笔非负账是：源IC给实际源收益至少强制F后的收益；背景利润定理给 \(\beta_r\sum z/(b+t+z)\ge\sum R_c\)，乘 \(\gamma\)；实际最后节点对每个真实后继主题的查询给 \(r u_6\ge\sum z/(\ell+1)\)，乘 \(\alpha\)。再把真实z替成每客户有限最小值得到上式。

\(\alpha\) 支付同一实际末位的钱，\(\gamma\) 支付同一强制分支的尾利润比较，两者不是任意逐客户价格。各客户最小z可以不同；这样消去真实后继只放松必要条件，没有构造一份共同真实后缀，更没有把多个互斥分支的利润直接相加成根福利。

# 四种“子菜单”实际比较元组

六个合法比较槽 \(T_1,\ldots,T_6\) 的会员数为d，选中的两个索引为a,b，会员为 \(t_a,t_b\)。不同比较槽允许代表相同主题。通式先指定k个覆盖会员，再从N个剩余索引中均匀选n个；其中D个覆盖该客户，于是

\[
R_c=\sum_{j=0}^{n}
\frac{\binom Dj\binom{N-D}{n-j}}{\binom Nn}
\frac{k+j}{b+t+k+j}.
\]

非法二项式系数为0，零分子份额为0。这里每客户只是计算一份共同随机索引平均的期望，不能按客户分别选择不同的比较主题。

| q | 比较元组及 \((k,N,D,n)\) |
| --- | --- |
| opt_subset | 六个索引中均匀选r个不同槽；\((0,6,d,r)\) |
| opt_include_i | 必含T_a，余r−1个从其它五槽均匀选；\((t_a,5,d-t_a,r-1)\) |
| opt_exclude_i | 排除槽a，从其它五槽均匀选r个；\((0,5,d-t_a,r)\) |
| opt_include_ij，r=1 | 仅T_a；\((t_a,5,d-t_a,0)\)，忽略b |
| opt_include_ij，r≥2且a≠b | 必含T_a、T_b，余槽不放回；\((t_a+t_b,4,d-t_a-t_b,r-2)\) |
| opt_include_ij，r≥2且a=b | 先放两次T_a，再从其它五槽选r−2个；\((2t_a,5,d-t_a,r-2)\) |

最后一行是允许重复行动的合法r元组，**不是无重复r索引子集**。这也是源文件名“subset”不能代替实际公式的地方。r=1时include_i和include_ij虽然参数标签不同，却给相同查询；96结构不表示96个线性独立行方向。原代码helper还识别self、actual及wi/wj单主题重复查询，但本报告的discover只遍历表中四个q，不能把未搜索的helper接口计入结果。

程序对一整个轨道的N=30或6个强制F主题均匀平均，上式左边仍是 \(u_{i+1}+r\alpha u_6\)。在hist内，会员词w出现 \(n_w\) 次，同索引组重数为 \(n_{w_a}\)，异索引组为 \(n_{w_a}n_{w_b}-1_{w_a=w_b}n_{w_a}\)。每组以重数/N加权，保留词相同而索引不同的情形。

指定member的一质量取该组01、10、11中相应位为1的质量之和，零质量是hist质量减它；R/Z以各自边缘分别进入，不需要二者独立。`states`把相同 \((b,\ell,t,R_c)\) 合并为有理权w，并另从hist求 \(u_{i+1},u_6\)。K、R-R overlap对这些投影没有贡献；当前hist由列分块识别，不能用 `hist_column_old` 作新下标。

# 浮点筛选、精确接受与空结果的逻辑

固定上述一个结构，给每个有质量的状态k引入自由变量 \(\eta_k\)。对全部 \(z=0,\ldots,r\)，原LP加入

\[
\eta_k\le\frac{t_k}{b_k+t_k+z}
+\frac{\alpha z}{\ell_k+1}
+\gamma\left(R_{c,k}-\frac{\beta_rz}{b_k+t_k+z}\right),
\qquad\alpha,\gamma\ge0.
\]

HiGHS最小化 \(r\alpha u_6-\sum_k w_k\eta_k\)，再加源收益得到gap。价格没有人为上界，但求解是浮点；文件不保存LP矩阵、成功/失败状态或对偶。`sol.success`为假时直接跳到下一结构；成功时仅在gap严格小于当前best时更新best，best初始为 `(0,None)`。

只有浮点gap小于 \(-10^{-8}\) 才尝试将两个价格按 `Fraction(float).limit_denominator(1000000)` 有理化。然后精确重算

\[
S=u_{i+1}+r\alpha u_6-\sum_k w_k\Psi_k.
\]

若 \(S<0\)，才展开1905列行、断言其点积等于S并加入selected。行的hist列承载源收益、末价及t=0基线，指定joint列补t=1与t=0之差；K与overlap列系数为0。源码依赖浮点变量界，有理化后未另断言价格非负；未来复用非空cut必须显式核 \(\alpha,\gamma\ge0\)。即使未来保存一条S<0的行，它也只分离该输入点；合法性来自前述真实策略证明，并非负值本身。

本原文件没有一条这样的记录，故没有alpha/gamma可恢复，也没有精确S或row点积证据。`best_float=[0,null]`在通常有限浮点返回值下意味着未记录成功LP的负gap，仍与部分乃至全部LP失败后跳过兼容。它不证明96次均成功，不证明每个连续价格最优值都精确≥0，不覆盖其它q、r=5或新支持。空selected也不等于“全部候选精确核验通过”：没有被选中的候选未走上述精确认证分支。
