## 本轮四路重放及真正独立性

上传原稿唯一Python代码块已精确抽成[可运行原代码](../../tools/evidence/global-security-budgets/uploaded_checker.py)，原Markdown未改动，清单记录抽出块的指纹。该代码实际展开89个单位客户，不调用优化器。合并主审计用压缩兴趣类型与Fraction直接重算；89独立实现不执行或导入上传代码、主审计或规范SPE求解器，只AST读取 `WEIGHTS` 与 `POLICY` 的字面数据，并将原始／对偶概率独立转录；36独立实现直接从数学构造展开不同单位客户。

本轮四路均实际运行并通过，结果分别是[上传原实现](../../tools/evidence/global-security-budgets/replay-uploaded.json)、[主合并实现](../../tools/evidence/global-security-budgets/replay-combined.json)、[89独审摘要](../../tools/evidence/global-security-budgets/replay-independent89-summary.json)及[36单位客户独审](../../tools/evidence/global-security-budgets/replay-independent36.json)。89独审还重生五份完整输出，均在 `replay-independent89/`。

从证据目录运行以下命令；`NEW_MAIN.json` 和 `NEW_INDEPENDENT_DIR` 须尚不存在：

```sh
python original/tests/audits/customer_attraction_root_security_uploads.py --output NEW_MAIN.json
python uploaded_checker.py
python original/tests/audits/customer_attraction_global_decorrelation_independent.py --output-dir NEW_INDEPENDENT_DIR

```

这些是同一模型定义的不同实现层核验，不是四条普遍定理证明。主程序单人／零客户／同覆盖标签／故意非SPE拒绝边界均通过；独立89还核验非平凡单人目录、全部1296有序终局的份额守恒、OPT与故意修改根动作后的三项违规。

89独审历史文字提到上传源不存在时读取 `certificate_data.json` 的fallback。当前CLI先新建输出目录并将 `HERE` 改到那里，fallback会指向该新目录，因此按上述CLI在源缺失时不能自动找到原快照。本包完整保留上传源，实际执行始终从它AST提取，本轮不依赖也不宣称检验了该fallback。该入口限制不影响已经完成的有理认证。

两TSV还与本轮重生文件逐字节相同；快照、四矩阵、完整 `results.json` 与本轮重生文件全部嵌套字段相同。主合并报告亦全部字段相同。36冻结独审报告比程序直接stdout多一个 `audit_source_sha256` 元数据，本轮核为保全原程序的真实SHA-256，其余所有运行字段完全相同；没有把这个差异隐去或误称数学冲突。

主合并报告的三组数据分别为：

前两例各259节点1554比较，36例43节点258比较；61和89静态背景各216个，36例36个。61证书用查询 $(13,11,10,11,0,0)/45$ 和纯竞争背景 $(0,0,5)$ 匹配值9；该对偶六行收益为 $(9,9,9,9,9,7)$。主报告另存每位玩家真正安全差、half余量及全部输入指纹，原字段完整保留。

89独审记录1554项中320平局、1234严格，最小严格松弛 $1/6$；同计数历史不同回复组数为零仅是这份策略的事实。根未覆盖类型10、24、26共四人。完整JSON还保留全部最优终局多重集与标签支持、静态五个活跃背景、原始最小非活跃松弛 $2931/26546$、对偶查询4松弛 $47254/13273$、静态下界与条件福利式的数值余量，未因正文只需一个OPT见证而删除这些独有数据。

89的非安全最优查询 $\widehat p$ 给总 $\kappa=-1/48$、总 $e=43/12$、$G=57/16$。36未用标签查询给总 $\kappa=G=-1/2$、总 $e=0$；同一36实例的安全最优均匀分布则总 $\kappa=10/9$、总 $e=31/18$、$G=17/6$。这些数分属不同查询，不能交叉拼成一个预算。

负向控制也保留在完整输出：两主题两人的全0策略产生两项 $-1/2$ 违规；把真实89证书根动作2改成0后，偏离2的差为 $-4$，偏离3、5各为 $-7/3$。因此独立核验器实际能拒绝错误策略，而非只计算在轨福利。
