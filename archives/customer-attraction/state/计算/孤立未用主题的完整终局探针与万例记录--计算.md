# 孤立未用主题的完整终局探针与万例记录

## 检验的候选与模型身份

4140字节原程序和300字节报告全部实读，两个冻结来源分支内容相同，见[来源清单](../../tools/evidence/isolated-option-original-two/source-manifest.json)。R84根README只把本方向列为未证的孤立外部主题探索；本页保留这一状态，不因程序使用精确算术就把有限输入提升为一般定理。

有限单位客户、有限非空共同标签目录、覆盖映射允许非单射，$m\ge1$名单位提供者依完整有序历史选标签，终局在覆盖者间均分客户价值。写标签为$C_0,\ldots,C_{p-2},P$（$p\ge2$），要求$P$的$q>0$名客户与所有$C_a$不交。不同$C_a$可以重叠或同覆盖，原模型允许空覆盖、重复行动、零客户和任意离轨平局；下文随机生成器另有更小输入范围。

令$R(0)$为完整根纯SPE的全部可实现终局计数，$c_P$为P选择人数。所检候选是

\[
c\in R(0),\quad c_P=0
\quad\Longrightarrow\quad
\forall a<p-1\text{ with }c_a>0:\quad
u_a(c)\ge q.\tag{ISO}
\]

同一主题的实际玩家最终收益相同，因此按已占用主题检查即可覆盖该终局每名玩家。P未被使用时，冻结其他人的终局行动改选P会独得$q$；(ISO)说这些特定静态偏离均无利。真实顺序偏离会改变后继行动，可能诱发后继也选P；这个跨分支问题不能由静态偏离收益代替。一般SPE不必是静态PNE，而已知非PNE例也未自动满足“一个与全旧目录不交、实际未用的P”这个特别结构。

## 原程序的精确集合值递推

客户按喜欢的标签位掩码$B$压缩，整数重数$w_B$仍代表不同单位客户。设$L=\operatorname{lcm}(1,\ldots,m)$。终局计数$x$上，一个**确实选择a**的玩家的整数化收益为

\[
V_a(x)=\sum_{B\ni a}w_B\frac{L}{\sum_{b\in B}x_b}.
\]

只要$a$已占用，式中所有相关分母属于$1,\ldots,m$，源码的`L // n`就是整除后的精确值。`utils`也给未占用标签计算一个数组项，但那不是不存在玩家的收益；递推只在$a$孩子的终局读其$a$项，主循环又用`if c[a]`排除未占用主题，未把这些数组项当实际利润。

对非终局计数$k$，原`rec`计算

\[
M(k)=\max_a\min_{x\in R(k+e_a)}V_a(x),\qquad
R(k)=\bigcup_a\{x\in R(k+e_a):V_a(x)\ge M(k)\}.
\]

终局层$|k|=m$返回单集$\{k\}$。输入的重数非负，故源码把阈值从0起算合法；没有支持负客户价值的声明，也没有为任意外部畸形输入做完整校验。

必要性：任何当前SPE规定收益必须至少覆盖每个偏离孩子可能给出的最小收益。充分性：选中孩子取目标$x$的子SPE，其他孩子各取达到相应最小值的子SPE，在互不相交的有序子树拼合。达到最大最小值的孩子至少提供一个被保留终局，故集合非空；弱比较保留全部平局。这与[可信续局菜单](../算法/可信续局菜单与完整策略重构--算法.md)的集合值公式相同，原程序是另一个只依赖标准库的简短实现。

按计数缓存的是全部可实现**集合**。它没有要求两段同计数有序历史使用同一动作或同一平局；充分性的拼合恰允许分开选择。另一方面，`frozenset`只保终局计数，既不枚举完整策略，也不输出一份完整策略证书。正例若被发现，仍应为保存的终局重构全历史见证并独立检查；不能把一个计数向量直接称作完整策略表。

## 两种生成模式的完整范围

`unit`按下列顺序消费同一个`random.Random(seed)`：人数从$3,4,5,6$等概率选，标签数$p$从3至6，名义旧客户数$n$从3至10，孤立客户数$q$从1至4。然后从$n$客户的全部非空子集中不放回抽$p-1$个不同集合，作为旧主题。逐旧客户压缩兴趣掩码；没有任何旧兴趣的客户不写入类型。最后加入兴趣只含P的$q$客户。因此实际总客户至多$n+q\le14$，不一定恰为$n+q$。

这一模式的旧主题非空且覆盖两两不同，P也非空且不交；没有测试一般模型的空主题、同覆盖别名或零客户输入。所有实例仍允许重复选择同一标签，完整SPE集合含全部离轨历史和任意平局。输入生成没有去重，所以10000次生成不等于10000个不同博弈。

`weighted`模式的人数从3至7、标签数3至7，q从1至30。对每个非空旧标签兴趣掩码，重新抽一次密度阈值自$0.15,0.3,0.6,1.0$，以对应随机比较决定是否保留，再赋1至30的整数重数；最后加入P类型。这里的weighted是客户类型重数，整数展开后仍为单位客户模型，不是异权提供者。它可能产生空旧标签或同覆盖标签。冻结报告没有运行该模式，不能借unit的阴性统计替它背书。

参数默认seed1301、cases10000、modeunit，可选输出路径。程序每生成一个输入就完全求该输入的$R(0)$，只扫描$c_P=0$的终局，再对每个$c_a>0$检查`V_a(c) < q*L`。遇到第一项严格失败即保存案例序号、m/p/q、全部类型、终局计数、缩放利润和L并退出；没有失败则继续。没有搜索额外背景、限制完整策略为计数函数或固定一份平局策略。

## 可直接证明的边界，及尚缺的跨分支部分

以下是本次在读清候选后给出的解析范围说明，不是报告中已有的实验字段。

**最后两名实际玩家。** 若完整SPE终局没有选P，最后一人改选P会独得q，所以其实际收益至少q。若还有倒数第二人，假设他实际选旧主题A，末位实际选旧主题B。在倒二改选P后的历史，末位仍可选B；删去A的覆盖只会减少旧客户负载，加入P不影响旧客户，故他选B的收入至少原末位收入，因而至少q。此时末位选P只有$q/2<q$，所以每个真正最佳回复都选旧主题。倒二的真实偏离最终独得q；原IC迫使倒二实际收入也至少q。m1只用末位论证，q0则非负收益直接成立。这个证明保所有原来的平局及所有偏离子局，不冻结末位规定动作。

因此(ISO)对m1、m2已由上述论证成立，对任意m的实际末两位也成立。向更早位置延伸时，偏离后的多名后继可能一起改变旧主题；原实际路径上末两位的利润下界不足以控制那些新子局，尚需新的论证。

**小外部主题范围。** 令$K=\max_a|C_a|$。任何当前玩家选一个最大旧主题，每个客户的最终分母至多m，因而保证$K/m$，与后续如何行动无关。每份完整SPE中的实际收益都至少$K/m$，所以$q\le K/m$时(ISO)直接成立。这只是一个充分条件；原探针并未把所有输入限制在这个条件内。

[同人数不交目录扩充](../定理/同人数不交目录扩充的完整策略保持--定理.md)在小外题条件下另证明可保指定旧完整策略，量词和用途不同。[新私有花瓣退出](../定理/新私有花瓣的全历史退出与逐人门槛正规形--定理.md)需要m个等大新瓣，以保证每个历史都有未用瓣；这里仅有一个P，不能移用其“从不重选新瓣”的证明。两篇相关正式对象及旧模型页均已全文比较；旧页的严格集合目录身份不用于缩小本页当前标签模型。

## 用途、保存状态与后续关系

本页保留一个可精确复现的有限诊断、集合值实现合同以及候选仍缺的跨分支问题。它不提供(ISO)的一般证明，也没有发现(ISO)反例；更不证明任意实例都有合适的孤立P，或从(ISO)自动推出六人半覆盖。

若继续此对象，正候选需要原输入、P不交条件、完整有序策略及全部真实IC；若要证明一般(ISO)，应直接处理原目录、任意人数和真实后继，而不能只增加阴性样本。上述末两位论证和$q\le K/m$范围可作为已付条件接口，未解决其余输入。

阶段三的真实关系是：源码**实现**可信终局集合递推；冻结报告及当前同字段重放**支持有限输入记录**；末两位和小P论证**给出候选的条件特例**；m瓣退出与同人数安全扩充**只作范围比较**。本轮未把旧图导入为完成，也不生成不具论证的half关系边。
