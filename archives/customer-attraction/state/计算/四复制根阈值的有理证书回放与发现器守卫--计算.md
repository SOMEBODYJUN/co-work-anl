# 数学身份及本次增量

采用[共同目录完整历史模型](../定义/共同目录完整历史模型--定义.md)。根实际收益为 r，目录确切最大主题大小为 K，实际福利为 W；任意六个合法比较主题的并集人数记 O。空主题、重复、零客户和全部平局均保留。K=0时全部量为0，直接处理，不定义 r/K。

[最大根四复制条件](../推论/最大根四复制支持线的近饱和半覆盖条件--推论.md)已给完整分支、合法行与模型桥。本页新增实际源码实读和有理回放证据，不另造一个一般福利定理。四个主源分别是浮点发现程序、发现输出、精确检查输出和父方回放输出；最后两个文件SHA-256均为 a7915fca38c75476c6999c36bd6359f1224ea3117148c6cac5284886a22e8440，逐字节相同，仍保留不同路径身份。

## 浮点程序优化的对象

`fourcopy_threshold.py`调用 `fourcopy_discover.build(6,4)`，得到五条长度6路径、16个主题会员位、65536型及命名行。令 v_T 为根强制最大主题后的真实根利润，行 G_j 的覆盖列系数为 o_j∈{0,-1}，则试图恢复

\[
Bv_T+C\mathbf1_T-o=\sum_j\lambda_jG_j+\rho,
\qquad\lambda_j\ge0,\quad\rho\ge0.
\]

程序设 x=λ/B、y=C/B、z=1/B，求最大化 2z-y；具体使用不等式 `rows*x-root*y<=vT`，等式 `-ocoef*x-z=0`，x,z非负而y自由。若这些行真实有效且恢复精确，则 (2-C)/B 是保证 Br+CK≤2K 的根收益阈值。该变量替换与LP返回成功本身不提供有理可行性、严格正 z 或最优性证书。

原浮点输出保留全部40个活跃乘子、五路径、B_float=85.42975291349731，B的有理近似7270427617/85104163，C=-1190490761/95968941，threshold_float=0.16861758728837822，状态明确为“float discovery; exact recovery required”。每个浮点近似分别限分母到10^8，不能据这些字符串推定精确余项非负。

## 必须保留的发现器行守卫

路径为 P₀=(0,1,2,3,4,5)，P₁=(0,5,6,7,8,9)，P₂=(0,1,5,10,11,12)，P₃=(0,1,2,5,13,14)，P₄=(0,1,2,3,5,15)。P₄的倒二者被强制选原末主题；只有末位仍真实优化。因此 `PAIR:4` 不能援引真实末两人最优性。发现器却无条件向每枝加入PAIR，原核验器也只算其系数，不检查该数学前提。这是程序行库的适用限制，不能将任意该发现器输出直接转成福利界。

本份发现输出及恢复后的具体证书均没有任何PAIR乘子，因而这个缺陷不进入本证书。回放入口在调用原核验器前显式拒绝非零 `PAIR:4`，并检查各FLOOR仅用于最后一次强制后的真正优化者。没有修改冻结原程序或声称修好它的一般接口。未来复用行库应在建模时移除此非法行；只重新数值优化而未守卫，仍不能作证明。

## 精确证书与逐型回放

恢复后的证书给

\[
B_*={819860302362953413\over9596894100000000},\qquad
C_*=-{1190490761\over95968941}.
\]

40个非零有理乘子保全在原JSON；它们只使用CAP、COPY、合法FLOOR和LAST。所有乘子非负，LAST乘子之和精确为1，覆盖列因而精确消去。原标准库核验器按会员mask独立于浮点发现矩阵重新构造每行，用整数公分母检查全部65536型；本轮实际执行一次，并把结果的所有字段与原检查和父方回放比较：

| 项目 | 本轮结果 |
|---|---|
| 类型数 | 65536 |
| 最小整数余项 | 0 |
| 零余项型数 | 3 |
| 公分母 | 1151627292000000000 |
| 原实际六位分组 | 全部64项base_minima逐字段相同 |
| 两份冻结报告 | 与本轮回放完整对象相同 |

这次是复用并实读原核验器的执行，另加数学行守卫，不称第二套独立实现。o=0/1列已经解析消去，不能把65536型报告改称131072个博弈，也不能把64分组称64个SPE实例。

由逐型非负余项、真实行语义及实际根IC r≥v_T，求和得 O≤B_*r+C_*K。再取最优六元组得OPT₆同界。每位都能安全查询最大主题，故W≥K，因此

\[
{r\over K}\le {2-C_*\over B_*}
={138242864300000000\over819860302362953413}
\approx0.1686175850953687
\quad\Longrightarrow\quad\operatorname{OPT}_6\le2W.
\]

这是具体有效支持线的充分条件。精确阈值与浮点目标略有差异，未证明它在该模板最优，更没有关闭任意根收益情况下的一般六人问题。
