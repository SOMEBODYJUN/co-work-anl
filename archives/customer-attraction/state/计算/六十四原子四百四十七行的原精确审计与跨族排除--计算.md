# 当前结论与四件证据的职责

\[
O=\frac{8363664784315903689704558089054357126675}
{4068102908761874395856338287104148755886}>2,
\quad O-2W=\frac{227458966792154897991881514846059614903}
{4068102908761874395856338287104148755886}>0.
\tag{1}
\]

这个点精确满足437旧行加10条同族末位异索引行，共447行，最小余量0。它证明**这个指定有限必要系统尚不足以推出半覆盖**，没有给出完整SPE，也没有精确最优对偶。后续真实跨族查询上包络在同一个点为负，因而已排除它作为所要求真实SPE投影的可能性，见下文；“还没补齐策略”已不足以描述当前这一固定点的状态。

# 模型及64原子的准确身份

一般模型是有限单位客户、有限非空共同**标签**目录，m名单位提供者按完整有序历史行动，客户在最终覆盖者间均分。空主题、同覆盖标签、重复行动、零客户、任意离轨历史及弱平局均保留。本页是五人必要投影；[五人半覆盖](../定理/五人半覆盖--定理.md)已有另行完整证明，当前六人目标没有因本页获得证明或反例。

旧输入为77420B `five_player_indexed_bound.json`，SHA256 `18e074ba51357dfa03090fe9b97b8ff868b9c83b2687c7da7ff6f7b39489abe1`。其 `primal.atoms` 恰64条，每条的十位 `bits` 按A,B,C,D,E,U,V,W,X,Y排序；保存的实际/命名路径是ABCDE、AEUVW、ABEXY。AB_hist、AE_hist为五个三位词的八桶直方图，second_hist为五个四位词的十六桶直方图，桶序均按二进制字典序；menus_lh保另外三个旧菜单的(l,h)量。原子含质量分子，但本点**不沿用旧质量**，只沿用以上描述及顺序。

三族直方图都是同一个比较索引T的投影。各自非负、各自有五份不能保证它们有一个与所有真实历史同时相容的共同索引实现，更不能保证完整策略IC。原子中没有所有真实主题的完整联合会员表。新增质量向量64项恰与旧数组一一对应；重排或改描述会换掉矩阵。

每个原子的福利系数\(w_a\)是ABCDE中至少一位为1；比较系数\(o_a\)由比较T覆盖记录给出。对质量\(x_a\ge0\)，\(W=\sum_aw_ax_a\)、\(O=\sum_ao_ax_a\)。这份有限LP归一为W1，不是客户总质量1。原447报告里的O是比较覆盖坐标；它没有认证真实游戏的全目录OPT或一份完整策略。

# 十条同族异索引末位行为何必要

每族有五个索引词\(z_i\)。AB、AE两族词长a3，固定前缀会员负载p分别为A+B、A+E；Sbranch词长a4，固定前缀p为A。词\(z_i\)按该真实分支余下行动顺序排列，最后坐标\(z_{i,a-1}\)是末位真回复。令

\[
D_i=p+\sum_{r=0}^{a-2}z_{i,r}+1\ge1.
\]

对每个查询位置\(k=0,\ldots,a-1\)，同目录使第i分支的末位可以改选第j分支位置k的主题。没有后继被错误冻结。对全部20个有序\(i\ne j\)末位真实IC求和，逐客户系数为

\[
\begin{aligned}
c_k
&=\sum_{i\ne j}\frac{z_{i,a-1}-z_{j,k}}{D_i}\\
&=4\sum_i\frac{z_{i,a-1}}{D_i}
 -\left(\sum_jz_{j,k}\right)\sum_i\frac1{D_i}
 +\sum_i\frac{z_{i,k}}{D_i}.
\end{aligned}\tag{2}
\]

因此每族每k有\(\sum_ax_ac_{a,k}\ge0\)，共3+3+4=10条。第一行是审计的字面有序索引构造，第二行是发现器压缩公式；它们的等价性由拆掉对角项直接得到。末位源正确时，式(2)不要求每个客户单独系数非负，也不要求主题互异；索引份数不能按同覆盖或同词去重。

旧437行通过原 `evaluate_atom` 前缀生成，其中十位、三族直方图及menus_lh的旧合同保持不变。新审计复用这一旧函数，故没有宣称对全部447行给出第二套独立矩阵。旧437行的命名和完整原证书保存在同包 `source-root/evidence/certificates/customer_attraction/five_player_indexed_bound.json`；[旧索引对象](五人索引偏离双证书--计算.md)负责其已清洗的数学来历。

# 4393B发现器的真实合同

原发现器顶层导入NumPy/SciPy，从旧17182B审计文件截取 `def check(` 之前的6476B并exec，另动态载入3172B `offdiagonal_closure.py`。后者向上查找实际canonical包，故不能用同名空stub代替运行依赖。本证据包保旧输入、全原代码及四个真实canonical模块；本轮未导入发现器或canonical包，也没有执行这些LP。

程序对同一64描述组装437+10系数矩阵\(G\)，约束\(Gx\ge0\)、\(w^Tx=1\)、\(x\ge0\)，浮点最大化\(o^Tx\)。这约束固定支持，不遍历全部客户类型。原代码在读取result.fun及dual之前没有先检查result.success；不能把后续改版的成功守卫倒加到这个4393B版本。

原始可行点恢复取浮点x>10⁻⁸的支撑，取\(|Gx|<10^{-7}\)的近紧行加W1，用Fraction消元；不一致或欠定返回None。恢复成功还精确核非负、W1及全部447余量才可记原始可行。对偶尝试把乘子及上界近似到分母不超过10⁹的有理数，并查乘子非负、64列剩余系数非负；即使通过，也只给这64支持的上界。本次保存报告明确exact_optimality_verified=false，没有可用的精确对偶或一般界。不能从一个好原始点推出最优性，更不能从受限最优推出全模型结论。

# 后来的跨族单行精确排除

把第一族真路径记为\((A,B,T_i,R_i,S_i)\)，第二族为\((A,T_i,H_i,I_i,J_i)\)。在前一族末位查询后一族\(I_j\)，按\(i\ne j\)求和是必要IC。设一个客户在A/B的负载为p，AB词的分母\(D_i=p+t_i+r_i+1\)，另一族I会员位为\(z_i\)，\(M=\sum_i z_i\)。其系数仍为

\[
4\sum_i\frac{s_i}{D_i}-M\sum_i\frac1{D_i}+\sum_i\frac{z_i}{D_i}.
\]

两直方图只共享t；将每个t组规定的z1个数优先放在倒数最大的AB位置，得到最后一项的最大值H。于是任何相容真实联合都必须满足\(\sum_xw_x[4\sum_i s_i/D_i-M\sum_i1/D_i+H]\ge0\)。包络是**上界**，故连这个最大许可值为负就足以排除所有相容耦合，不要求各客户最优匹配能同时实现。

[原独立二值审计](共享索引跨族单行的原独立二值审计--计算.md)已经对同64描述枚举合119个局部相容五位赋值，核贪心最大值与枚举相同。其原入口既有一次0.03915265199975693秒的889B字节一致事件，本次充分复用，新增运行0。对本447质量的精确上包络是

\[
-\frac{246556679589157821100021245278144532469}
{24408617452571246375138029722624892535316}<0.
\tag{3}
\]

因此本点虽然通过447行，仍不能来自上述真实共同目录SPE投影。旧437权重的另一负值是\(-954426063207450783420104003253158341997/12700855566796283525031229648379596588740\)，不可替换成本点(3)。这一单行原审计没有重验447；本次447原审计又没有重跑该单行，二者按完整输入SHA共同使用，范围互补。
