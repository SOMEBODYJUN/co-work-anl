# 内嵌控制器、单位客户压缩与列构造

m6时，六经济客户e0..e5、五个各含两名不同单位客户的银行B0..B4。共同主题(a,b)={ea}∪Bb，共30个；主题索引按product顺序为5a+b。代码用11个坐标压缩16客户，银行坐标乘2是两个同覆盖单位客户，未改变玩家或客户权重。

两源码从开头到`from fractions import Fraction as F`之前1450B完全相同，SHA256为`4a7ef2e9c6e02451e9e8f3129c44dc1f8377f75799e1e63c15c8cdeab3c69dd9`。这是相同控制器/列构造字节，不能称两份独立策略实现。

控制器遍历整个有序h：任意根动作作锚进入BASE；非末位复制锚经济/取新银行，偏离时新银行转PUNISH并固定目标、旧银行转EXIT。PUNISH目标不随以后新银行更新，末位复制该过去目标；EXIT永久取双新标签。末位BASE取新经济并复制根银行。lru_cache的key是完整历史元组，不是计数态。它与已证[全m银行完整SPE](../反例/笛卡尔银行目录的逐人分数门槛反族--反例.md)同一控制器；完整历史理性仍依该解析定理，不由本脚本重新核全树。

代码的finish递归执行同一action，实际叶为
\[
 z=((0,0),(0,1),(0,2),(0,3),(0,4),(1,0)),
\quad u=(6/5,11/5,11/5,11/5,11/5,2),\quad W=12.
\]
对每个实际位置i和全部30动作b，先固定实际有序前缀z_<i，再强制b，之后沿同一控制器重新finish，**删除同一i槽**后计cols[i,b]。因此恰6×30个位置—行动列，每列有5个合法主题负载；不是180个不同叶、更不是全部有序历史的IC枚举。过去实际前缀保留，偏离后尾部没有冻结。代码未逐项断所有query收益≤u_i，亦未检查全部离轨IC；SPE身份是已证依赖。

# 共同有理背景与KKT合同

设ℓ_i(A)为上述真列，K=(1/6)Σ_i conv{ℓ_i(A)}。查询p边际ρ，F_p(L)=Σ_xρ_x/(1+L_x)，银行客户按乘2求和。固定L*及t=(1+L*)^{-1}，真实当前收益d_i(A)=Σ_(x∈A)1/(1+ℓ_i(A)_x)。二者都用
\[
 C=\sum_iE_p\sum_{x\in A}t_x^2(\ell_i(A)_x-L_x^*),
\quad D=\sum_iE_p\sum_{x\in A}
 \frac{t_x^2(\ell_i(A)_x-L_x^*)^2}{1+\ell_i(A)_x},
\]
\[
 I_i=u_i-E_p d_i(A),\qquad W-6F_p(L^*)=\sum_iI_i-C+D.
\]
I_i≥0来自真SPE；D≥0逐项成立。源码计算全部这些量，但其BAL显式断言是总量式，不是报告另有一套逐行余额审计。

两者硬编码相同L*：e0为8/3、其余五经济各7/15、五银行各1。每行q只支持以下主题索引：

| 角色 | 索引、主题与概率 |
|---|---|
| 1 | 5=(1,0):1/5；20=(4,0):7/20；25=(5,0):9/20 |
| 2 | 10=(2,0):1 |
| 3 | 0=(0,0):3/5；10=(2,0):1/5；15=(3,0):1/5 |
| 4 | 5=(1,0):1 |
| 5 | 5=(1,0):1 |
| 6 | 0=(0,0):1 |

两程序都断每行非负/和1，及跨6行平均负载恰L*。另计算全部30列在每行的最小e0负载，断为1,1,2,3,4,5且均值8/3。之后以ρt²为权，逐行计算所有列的线性负梯度收益，断q正支持列取该行最大值。因此L*确为相应**固定p**的凸极小负载，不是数值优化输出。

# 全部最优查询的量词由解析闭合，不是假称代码枚举

“存在有利的另一个最优p或另一个q实现可使C≤0”也已由[完整解析反例](../反例/共享菜单全部最优鞍点的正相关项--反例.md)排除。程序没有一个`unique_primal`断言或最优p枚举；它给的是可用于解析证明的精确鞍点和矩阵常值事实。

具体地，任意全局最优共享负载必须使F_p*最小为γ。ρ在五个非锚经济与所有银行上正，严格凸性固定这些坐标为L*；每个删槽列经济总负载5，再固定锚坐标，故全局primal唯一。任意外层最优p在L*的均价必须γ，不能给严格便宜的锚主题正质量。因此全部最优p都支持同25主题，每行C常数再闭合全部保边际运输。不同q实现不影响C的定义。

这是数值证书加普遍凸论证，不是程序新遍历所有p、所有历史或所有SPE。恒定结论是C；上表D_i/I_i和总D/I只属于所取均匀p*，不说它们在所有最优p或运输下分别不变。
