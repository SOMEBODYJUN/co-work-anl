# 输入合同与全覆盖限制

固定[共同标签目录模型](../定义/共同目录完整历史模型--定义.md)的一份完整纯SPE σ，m人actual z，收益u_i、覆盖C、福利W。这里另限制存在m主题覆盖**全部输入客户**，所以OPT_m=N，遗漏R=N\C，实际最优外G=C\O=∅；没有G取消资金。这个G是集合差，不是H4退款G或其它fresh符号。

原4573B check_natural_full_cover不生成游戏/策略，读指定examples和完整certificate，解包strategy/certificate/自身actions，检查历史无重复且键集等于Σ_(d<m)S^d；在每节点强制每合法动作后沿改变历史的同σ完成，用Fraction核所有真实IC。actual收益之和为整数W。它枚举全部非降m多重集，只保覆盖N者，再枚举各不同排列；无全覆盖最优则assert拒绝，不是一般OPT求解器。

客户重数是不同单位客户。零客户时R空、成本0；正重数且无人喜欢的客户会使全覆盖合同不可满足，不能静默丢掉后仍声称OPT=N。目录空主题、重复行动及同覆盖标签在数学定义保留。该程序不导入项目模型或solver，有main guard，必需至少一个case名；--out若给定会覆盖写，且stdout额外print使末尾格式不必与文件字节一致。本批0调用。

# 等份自然价：每次返回actual前缀

对客户类型j的任一遗漏客户x，状态(i,a)要求x∈a。令Z_i(a)=finish_σ(z_<i,a)、D_i(a)=u_i(Z_i(a))。实际过去完全未覆盖x，所以Z_i(a)对x的负载为c=1+|F|，F={ℓ>i:x∈Z_i(a)_ℓ}；D>0且原IC给D≤u_i。

每单位到达流在当前吸收1/c，再把每个future coverer各送1/c。到达ℓ时使用其action Z_i(a)_ℓ，但重新读取**原actual前缀**z_<ℓ的真实σ完成。原checker的递归为
\[
 \boxed{P_j(i,a)={u_i/D_i(a)+\sum_{\ell\in F}P_j(\ell,Z_i(a)_\ell)\over1+|F|}.}\tag{EQPRICE}
\]
角色严格增加，故有限且可memoize。m末位时F空、P=u_m/D。不是持续旧叶的固定尾，也没有把全部均分客户算为单个重客户。

归纳P≥1：u_i/D≥1，若所有后继≥1，分子至少1+|F|。这同时显示额外税由原真实IC松弛产生。当前费用是吸收量除D乘整条当前IC的左边u_i，合并所有客户/来源后仍只有同一个query系数，不能按客户随意重权原收益差。

本检查器**固定等份路由**，只优化初始owner和共同最优顺序。它不实现[自然捕获Bellman](../算法/自然捕获路由的Bellman价格与Hall取消--算法.md)允许把全部captured份额送到最便宜future的更自由优化。二者在同输入满足V_Bellman≤P_equal；可用自由度不同，不将本原递推叫Bellman全路由最优。

# 所有owner与共同顺序的精确优化

固定一份有序全覆盖最优元组T，类型j可放在任意i使T_i覆盖它；没有owner容量或其它耦合，且所有复制客户费用线性，所以
\[
 K(T)=\sum_{j\subseteq R}w_j\min_{i:T_i\ni j}P_j(i,T_i).
\]
逐类型取min可同时达到；允许把同型不同客户拆给不同owner也不会更低。然后对**全体**有序最优T取min，不每客户另选不同排列。原程序在价格相等时按较小i选owner，并保第一次达到最小/最大成本的共同顺序。

自然流每客户总吸收1，费用精确分解
\[
 K=|R|+\sum_{s=(i,a)}{A_s\over D_s}(u_i-D_s)
   =\operatorname{OPT}_m-W+E,\qquad E\ge0.\tag{TAX}
\]
A_s为所有客户等份流在该query的吸收；严格角色使全部流最终吸收。因G0，这里的最小价至少遗漏量，没有其它取消。要K≤W仍须E≤2W−OPT；写出这个旧IC税等式不等于证明付款。更一般SOURCE-NET的η_i=u_i(I)+γ_i只是一份总W的钱包，source先付后incoming不能另领W；[自由取消与固定delta的区别](../算法/自然捕获路由的Bellman价格与Hall取消--算法.md)也不能因本全覆盖无G而跳过。
