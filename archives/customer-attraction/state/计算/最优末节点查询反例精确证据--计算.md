## 真正逐项核验的内容

两脚本都只用Python标准库和精确有理数，不导入规范SPE求解器、浮点LP、原模型模块或彼此的函数。它们共享**同一份输入和完整策略证书**，各自直接计算客户覆盖人数及收益。因此独立性是实现层面的，不是两份不同反例或新增独立审稿。

第一脚本还按四个非零Boolean势重建全部127个signed重数，再核对每个输入重数等于 signed 加13；检验全部128个子集上的调和势。它不能由128项子集势检查推出重复历史的SPE，所以另按真实客户收益遍历全部400个节点。

| 核验项 | 结果与责任 |
|---|---|
| 完整有序策略域 | 1+7+49+343=400个节点，无缺项、重复或越界动作 |
| 真实节点行动比较 | 2800项，含400项自身动作；全部非负，1557项等号 |
| 非自身比较 | 2400项，其中1157平局、1243严格亏损，无盈利偏离 |
| 实际路径与支付 | E,G,A,C；390,389,390,390；总福利1559 |
| 四主题多重集最优 | 全部210种，唯一最优BCDF覆盖1562 |
| 实际末节点查询 | 七项均重算；四个最优主题各390，总1560，超过福利1 |
| Boolean构造 | 全部127类型及128势值精确一致；偏置仅13 |
| 静态安全值对偶 | 全部35个不同三标签背景，七行最大4889/14，小于最小实际收益389 |

在四位玩家中，原证书的每位策略都可依全部有序前缀改变；两个相同计数前缀的动作确有不同。本页没有把这份完整SPE当作同时PNE检验，也没有冻结偏离后的行动。

## 独立报告新增的七个根偏离

第一人改选后，按照证书在改变后的历史继续，得到：

| 首行动 | 真实完整终局 | 首人收益 |
|---|---|---:|
| A | A,D,E,G | 389 |
| B | B,D,E,G | 389 |
| C | C,D,E,G | 389 |
| D | D,A,C,E | 389 |
| E | E,G,A,C | 390 |
| F | F,D,E,G | 389 |
| G | G,A,C,E | 389 |

根实际E严格优于六个替代行动，但其他节点有大量平局，所以不能据此称整个策略为严格SPE。原第二报告还保存七项静态安全对偶值，正文完整列出；并未仅保留最大值。

## 正确使用证据

这个固定实例的完整策略认证足以反驳正文准确写出的全称命题；不用也没有借“搜索未找到更坏实例”作证明。唯一最优性有独立解析证明及210多重集穷举交叉核验。静态安全对偶只是上界 $v_4\le4889/14$，没有求解或宣称最优安全值。

实际根税884和half余量1556均为正；资源只支持“最优组合末节点查询总额支付”失败。不同的[61客户根税反例](../反例/四人实际根总税--反例.md)以及[34客户逐人安全值反例](../反例/三人逐人混合安全值--反例.md)不与本例合并成同一证书。后续在其他菜单、定价或静态逼近测试中再次使用此输入，也不会扩大本反例的逻辑范围。

全部七源的独有数学、数据、代码和报告均有明确去向。原“独立审计”身份按原来源保留，本轮准确称为两原实现重放，没有新增外部审查、新颖性或最小性认证。关系已说明数学理由，第三阶段另行建图。
