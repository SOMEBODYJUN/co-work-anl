# 固定三人策略锥的全查询价格证书

## 已认证的条件结论

本对象采用[固定完整SPE策略锥的有限价格合同](../等价/固定完整SPE策略锥的有限价格合同--等价.md)。四个共同目录标签为0、1、2、3，三名玩家按顺序行动。固定下面给出的完整纯策略 \(\sigma\) 后，令 \(r_B\ge0\) 为全部15种非空兴趣类型的任意非负实重数。

**精确证书证明的条件结论。** 对每个使同一份 \(\sigma\) 成为完整纯SPE的 \(r\)，对两个实际占用标签 \(a=0,3\) 均有

\[
 \mathcal B_r(u_a(r))\le2u_a(r),
 \qquad
 \mathcal B_r(u_a(r))+u_a(r)\le W(r).
 \tag{1}
\]

每个 \(\mathcal B\) 都取全部非负分数查询的上确界。结论覆盖这个固定策略的整个非负重数锥，包含零客户、零福利和物理覆盖重复的边界；原单位客户模型的整数点当然包括。空兴趣类型重数任意，因其收益与覆盖恒为零，不进入15维矩阵。

这是有有限有理证明载体的条件结论，不是把有限几个重数样本外推为一般定理。条件中的固定策略不能删掉：它既不量化同一16客户实例的其他所有SPE，也不量化任意三人策略，更不回答六人半覆盖目标。

本轮原样运行两次verify，每份证书一次；随后另从完整有序历史独立重构约束，逐项核两份证书的1800个残差坐标。没有运行build、LP或SPE搜索。

## 一、同一份完整有序策略

根动作是0。一人历史后的动作依次为

| 一人历史 | \((0)\) | \((1)\) | \((2)\) | \((3)\) |
| --- | ---: | ---: | ---: | ---: |
| 第二人动作 | 3 | 2 | 1 | 0 |

最后一人的动作由完整两人历史决定：

| 第一人＼第二人 | 0 | 1 | 2 | 3 |
| --- | ---: | ---: | ---: | ---: |
| 0 | 3 | 3 | 3 | 3 |
| 1 | 3 | 3 | 3 | 3 |
| 2 | 3 | 3 | 1 | 1 |
| 3 | 3 | 2 | 1 | 1 |

共 \(1+4+16=21\) 个决策历史。每个节点的三个非自偏离均按这**同一张图**继续到底，合计63个比较。实际根路径为 \((0,3,3)\)，计数为 \((1,0,0,2)\)。

这份图不能压缩成仅依主题计数的策略。例如历史 \((1,3)\) 和 \((3,1)\) 的计数相同，但规定的最后动作分别为3和2。所有离轨历史均保留，最佳反应允许平局。

令 \(\Gamma_\sigma\) 的一行为当前规定动作的最终收益系数减去相应真实偏离收益系数，坐标按非空兴趣位掩码1至15排序。63个比较都非零，去掉重复后恰39个不同有理行；原证书的乘子下标按这39行的Fraction字典序排列，使用从0起的编号。不能把“39行”误作只检查了39个节点或偏离。

本轮另导出的[完整行与逐历史映射](../../tools/evidence/fixed-policy-price/replay/tstar-independent-duals.json)保留39行全部坐标，并给63个比较各自的历史、规定动作、偏离动作、对应行号及源实例松弛。未用缓存的终局集合替代具体历史的回复。

## 二、16客户见证点与非PNE机制

两份证书内嵌相同的源实例，已与冻结[原实例](../../tools/evidence/fixed-policy-price/original/examples/customer_attraction/worst_pne_welfare_failure.json)全文逐字段相等核对：

| 兴趣标签集合 | 单位客户数 |
| --- | ---: |
| \(\{1\}\) | 1 |
| \(\{0,1\}\) | 2 |
| \(\{0,1,2\}\) | 2 |
| \(\{1,3\}\) | 3 |
| \(\{2,3\}\) | 3 |
| \(\{0,2,3\}\) | 5 |

根路径覆盖15名客户，唯一未覆盖者的兴趣为 \(\{1\}\)。用标签0、1、2可覆盖全部16名，故 \(\mathrm{OPT}_3=16\)。实际收益为

\[
 u_0=\frac{17}{3},\qquad u_3=\frac{14}{3},
 \qquad W=u_0+2u_3=15.
 \tag{2}
\]

这16客户只是产生并见证 \(\sigma\) 的一个重数点。证书的39行和1800个残差坐标都使用全部15种兴趣类型，允许在原点没有出现的类型后来获得正重数；没有把全锥偷偷限制成表中六类。

原文件名中的非PNE有具体含义。若固定其他两人的终局动作3、3，让第一人从0改选1，他在静态终局 \((1,3,3)\) 得6，大于 \(17/3\)，增益 \(1/3\)。但真实顺序偏离到1会引发策略回复2、3，终局为 \((1,2,3)\)，第一人只得 \(11/2<17/3\)。根的全部四种比较如下：

| 根动作 | 固定他人终局动作时的收益 | 按完整策略继续的终局 | 真实顺序收益 |
| ---: | --- | --- | --- |
| 0 | \(17/3\) | \((0,3,3)\) | \(17/3\) |
| 1 | \(6\) | \((1,2,3)\) | \(11/2\) |
| 2 | \(14/3\) | \((2,1,3)\) | \(5\) |
| 3 | \(11/3\) | \((3,0,3)\) | \(14/3\) |

因此“终局动作组合不是静态PNE”与“完整策略是SPE”相容。63个真实比较已全部核过，不是仅靠这张根表认证离轨理性。此处不额外声称已重新计算该实例全部最差SPE或全部静态PNE。

## 三、两套60项证明如何覆盖无限查询与整个锥

四维完整普适查询集 \(V_4\) 有30个点，理论完备性见[有限顶点定理](../定理/非负分数价格的有限普适顶点--定理.md)。两原证书均保存这30个向量，原verify重新精确枚举并要求整个有序列表相同；并非只检查保存列表中的几个点合法。

对每个 \(a\in\{0,3\}\) 和 \(z\in V_4\)，记

\[
 g_B(z)=\min\left(1,\sum_{b\in B}z_b\right),\quad
 \tau=\sum_bz_b,\quad
 u_a=\ell_a\cdot r,\quad W=w\cdot r.
\]

两种目标分别是

\[
 c^{\mathrm{floor}}=g(z)-(\tau+2)\ell_a,
 \qquad
 c^{\mathrm{plus}}=g(z)-(\tau-1)\ell_a-w.
 \tag{3}
\]

每份JSON给每一对 \((a,z)\) 一个有理 \(\beta\) 和稀疏非负乘子 \(\mu\)，使全部15个坐标满足

\[
 R=\beta w-\Gamma_\sigma^{\mathsf T}\mu-c\ge0.
 \tag{4}
\]

本批逐份检查了所有乘子索引、符号、全部坐标残差及覆盖的 \((a,z)\) 对。所有 \(\beta\le0\)。对每个 \(r\ge0,\Gamma_\sigma r\ge0\)，直接得到

\[
 c\cdot r
 =\beta W-\mu\cdot(\Gamma_\sigma r)-R\cdot r
 \le\beta W\le0.
 \tag{5}
\]

式(5)没有除以福利，所以 \(W=0\) 同样成立。再对完整 \(V_4\) 取最大值得式(1)。有限检查之所以给全实重数、全查询的条件证明，原因正是这些逐坐标有理恒等式加上普适顶点定理，而不是因为“样本很多”。

| 项目 | tstar证书 | price_plus_u证书 |
| --- | ---: | ---: |
| 占用标签×完整查询 | \(2\times30\) | \(2\times30\) |
| 有理证明项数 | 60 | 60 |
| 非零乘子条目 | 272 | 281 |
| 残差坐标核对数 | 900 | 900 |
| \(\beta=0\) 项数 | 18 | 8 |
| \(\beta<0\) 项数 | 42 | 52 |
| 最大 \(\beta\) | 0 | 0 |
| 最小逐坐标残差 | 0 | 0 |

最大 \(\beta=0\)并不表示全部 \(\beta=0\)。两份原始JSON的全部120行证明、30个查询、完整策略、源输入和说明字段均已完整实读并原字节保存；本轮新输出另保存1800个残差的完整值，而非只给“通过”摘要。

### 一项可直接看懂的证书

tstar中，标签0、查询 \(z=e_1\) 对应查询下标5，证书取 \(\beta=0\)，仅第35行乘子为3。第35行可由根的“选0相对于真实偏离到1”的比较得到：

\[
 \Gamma_{35}=\ell_0(0,3,3)-\ell_1(1,2,3).
\]

对每个兴趣类型，至多三名玩家分摊，故

\[
 \mathbf1_{1\in B}\le3\,\ell_{1,B}(1,2,3).
\]

因此

\[
 c+3\Gamma_{35}
 =\mathbf1_{1\in B}-3\ell_{1,B}(1,2,3)\le0
\]

逐坐标成立，恰是该稀疏上证书。它说明单主题价格候选被一条真实根偏离支付；其他混合查询需要原表中相应的多个行，不能用这一例代替全部60项。

## 四、同一锥内可直接推出的福利界

下面是由已核证书得到的限定推论，不是原16客户点的数值观察。取实际最小收益 \(v=\min(u_0,u_3)\)。三名玩家的收益和是 \(W=u_0+2u_3\)，所以 \(3v\le W\)。给任意三个最优目录标签各放一单位查询质量，重复选择也按重数计入，便有

\[
 \mathrm{OPT}_3\le\mathcal B_r(v)+3v
 \le5v\le\frac53W.
\]

于是该**固定三人策略锥**内有 \(W\ge\frac35\mathrm{OPT}_3\)，包括零值边界。这个推论不把三人换成六人，也不删掉固定 \(\sigma\) 条件；更不证明全部三人SPE都满足同样界。式(1)第二式另外给出各占用标签的 \(\mathcal B_r(u_a)\le W-u_a\)，弱价格界 \(\mathcal B_r(u_a)\le W\)随非负收益立即推出，不需另运行price模式。

在具体16客户点，两个完整价格值实际为

\[
 \mathcal B(17/3)=6,\qquad
 \mathcal B(14/3)=15/2.
\]

本轮逐30点比较均在唯一查询下标4、向量 \((0,1/2,1/2,1/2)\) 取得。该查询覆盖值为 \(29/2\)，总质量 \(3/2\)，代入即得两个值。其一般最优性依赖完整 \(V_4\) 的比较；它们并不达到式(1)中的普遍锥上界。

## 五、原程序的真实验证合同

原程序有build和verify两种操作。build从所指16客户输入调用规范求解器选一份最差终局证书，对每个目标在 \(w\cdot r=1\) 上运行SciPy/HiGHS提出对偶系数，再以分母上限 \(10^9\) 还原Fraction，并逐坐标核非负残差。若有理恢复失败，它报错；浮点成功本身没有被当成精确证明。build会写入指定文件并覆写既有内容。

本批没有调用build，没有重建发现过程。实际执行的是两次verify，它：

1. 从内嵌实例与策略调用规范定义验证器，核全部21历史、63非自偏离。
2. 从完整有序历史重新构造真实终局和39行 \(\Gamma_\sigma\)。
3. 精确再生 \(V_4\)，要求给定列表逐项完全相同。
4. 遍历两个实际占用标签与全部查询，拒绝缺失／重复证明、越界或重复乘子索引、负乘子及负精确残差。
5. 根据实际 \(\beta\) 重算是否全部非正及其最大值。

一个容易误读的接口是：verified=true表示这些上证书有效；程序允许一般上界的 \(\beta\) 为正，并在输出另给all_bounds_nonpositive。因此要得到式(1)，还须核实际返回的all_bounds_nonpositive=true及maximum_beta≤0。本轮两份均明确返回true与0，新外层检查也直接断言这两个条件。

保存JSON中的scope、source_file、row_count、all_bounds_nonpositive、universal_policy_claim等字段不是原verify逐一认证的说明字段；它重建实际行数和上界状态，也不从source_file重新读原实例。原输入由内嵌source_instance定义。本批外层另外与冻结原实例比较，并核存储row_count=39、非正标志及不作通用策略声明均和实际一致。不能因JSON写了某个声明，就把它当成验证器已经检查过的结论。

verify不使用SciPy、不调用优化器，也不调用已导入的ExactSPESolver搜索。其标准输出是新核验报告，不改写输入证书。代码还支持price目标行，但本批没有第三份price证书或第三次验证执行。正常输入验证不被扩大为对任意畸形JSON的全面拒绝保证。

## 来源处置与接续

本批三个来源分别是一个可核验的证书程序和两套不同目标的精确证明载体；已经完整保留代码的两个操作、全部原件字段及实际验证范围。基础实例源6360dcaaef6a3f2f5a4e及既有五依赖仅作核对，没有因此额外done。

前一查询清洗批只保存了原稿对这120项证书的历史指向；本批补齐实际代码、全部证明和精确复验。这个新增证据可以替换“尚未重建该具体证书”的当前使用限制，但不能改写前批当时没有运行它的事实。

接续若要覆盖新策略，应从全部有序节点重新建 \(\Gamma\) 并提供相应证明；若只改变同锥内重数，本页式(1)可直接复用。完整策略并、全树整数模型、普遍早期价格桥和六人半覆盖仍有各自义务，不能从一个固定锥的成功直接跨越。
