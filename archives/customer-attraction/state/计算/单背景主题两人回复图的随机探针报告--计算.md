# 原报告的准确身份

主源[完整JSON](../../tools/evidence/fresh-arbitrary-reply-probe-data/original/fresh_arbitrary_probe.json)只有130B、六字段，SHA-256为 `e444f6a49b0e20becece58c11b96437fb5f190e008d3f4d2b67aacd90d7bd02a`，两个冻结提交逐字相同。本轮已全文读它和[2412B原生成程序](../../tools/evidence/fresh-arbitrary-reply-probe-program/original/probe_fresh_arbitrary_reply.py)，其完整接口另见[配套程序对象](../程序/合法单题背景的任意末回复策略锥探针--程序.md)。文件名的arbitrary对应末位回复图可任意抽取；背景仍是同一道合法主题H重复L次，原表L=1。

原表记录一轮七标签、12000次抽样的浮点LP搜索到达末尾返回分支，全部12000次得到求解器success，未触发严格小于−10⁻⁸的早返条件。它没有保存实际回复图、各图LP值、客户权重、随机seed、求解器版本或逐次状态。这里保留的是历史结果的原始陈述与准确程序含义，不声称本轮重新见证了那12000次调用。

本轮没有运行原run/main或LP。程序任务另做一次明确指定seed=0的合成回复图算术接口核验；该事件与历史抽样完全区分。单H背景预算的普遍非负性由[既有精确四乘子证书](背景菜单的有限证书--计算.md)承担，不由12000这个样本数承担。

源码默认参数是q=6、cases=10000、seed=71215、background=1。本表的q和cases明显不是默认值；原表未保存seed，即使默认值在源码中可见，也不能据此补填历史seed为71215。我们也不知道历史是从CLI调用还是由外部调用run后写出的相同格式。

末尾分支固定返回上述六键；一旦成功LP满足 `res.fun < best-1e-8`，则写另一种含background、actual、reply、compare、deficit、weights、case、seed的witness并立即返回。因此当前六键不是一个已保存负例，也没有记录负例权重。比较阈值允许[−10⁻⁸,0)中的小负浮点数不触发；本表不保存这些值，不能从best=0排除它们。

每满1000次循环，源码会打印进度，末尾还打印报告。本源没有附带这12行历史stdout，本轮不补造日志。原程序不清除旧witness文件，单看某目录中是否存在witness也不能据此把它绑定到本表。

# 客户编码、合法前缀与完整两人策略

基础模型见[共同目录完整历史定义](../定义/共同目录完整历史模型--定义.md)：有限单位客户、单位提供者、有限非空共同目录，全部有序历史上的纯SPE；允许重复动作、空覆盖和所有离轨平局。本程序用有标签目录0至q−1编码，可能有不同标签覆盖相同客户，不要求每题有正客户。

对每个非零位掩码 \(m\in\{1,\ldots,2^q-1\}\)，记

\[
I_a(m)=((m\mathbin{\gg}a)\mathbin{\&}1),\quad w_m\ge0,\quad \sum_m w_m=1.
\]

在q=7时正好127型，顺序是整数m=1至127。m=1仅接受标签0，m=2仅接受1，m=4仅接受2，m=8仅接受3，m=16仅接受4，m=32及64仅接受额外标签5及6，m=127接受七题。全零型不接受任何题，对收益与覆盖无贡献，故省去；总质量归一化也省去了零客户的平凡情况。

LP变量是归一化非负实质量，不是127个单位客户，也不是提供者权重。删去全零型后，任何仍有客户的整数实例除以剩余总人数即进入这个单纯形；精确有理质量可清公共分母恢复有限单位客户，因收益、IC和目标均齐次。浮点质量逐项近似成有理数并删除小坐标，则必须再核IC与归一化，不能自动继承这一实现事实。本原表根本没有质量向量。

角色在程序内固定为

\[
H=0,\quad A=1,\quad B=2,\quad T=3,\quad S=4.
\]

这五个是不同动作标签；覆盖集合可以相同。它不是对给定q所有字面角色重合型的枚举，若通过增加重复覆盖标签表达别的角色配置，须另说明目录与策略的变化，不能直接称为这12000次已覆盖。

背景是合法前缀 \(H^L\)，本表L=1。客户负载 \(p_m=L I_H(m)\)，新客户恰为I_H=0。两个剩余玩家实际依次选A、B。完整末位回复图为函数

\[
r:\{0,\ldots,q-1\}\to\{0,\ldots,q-1\},\qquad r(A)=B.
\]

它给首位每个可能选题a之后的真实末位动作r(a)，并不把所有偏离后的回复冻结成B。固定一个这样的r，加上首位选择A，就给这个两人子博弈的完整纯策略。它没有指定H以前玩家的最优性，也没有给其它前缀后的子树，因此不能认定H前缀在一份更长完整根SPE中实际可达。

# 每个回复图的127变量、48条IC与目标

在固定背景下定义逐型和总体收益

\[
v_m(a,b)=
\begin{cases}
I_a(m)/(p_m+I_a(m)+I_b(m)),&I_a(m)=1,\\
0,&I_a(m)=0,
\end{cases}
\quad U(a,b)=\sum_m w_m v_m(a,b).
\]

这正是单位均分的分母，包括a=b时同题两人各占一份。原NumPy实现用`where=c>0`加零输出处理无人覆盖的坐标。所有候选客户型共用同一张回复图r。

对每个首选a，末位改成其它b不能提高收益：

\[
R_{a,b}=U(b,a)-U(r(a),a)\le0\quad(b\ne r(a)).
\tag{1}
\]

对首位每个非实际行动a，其后继仍按r：

\[
R^{\rm first}_a=U(a,r(a))-U(A,B)\le0\quad(a\ne A).
\tag{2}
\]

因此每图有q(q−1)+(q−1)=q²−1条行；q=7时是42条末位行与6条首位行，共48条、6096个型系数。这些全部非严格IC对这份固定两人策略是充分必要的，包含所有q个末位历史；“完整”限于这个子博弈，不表示抽样穷尽所有策略或完整原根树。

记 \(P=U(A,B)+U(B,A)\)，\(\Delta=\sum_m w_m(1-I_H)\max(I_A,I_B)\)，比较新覆盖 \(C_F(T,S)=\sum_m w_m(1-I_H)\max(I_T,I_S)\)。每次LP最小化

\[
f=P+\Delta-C_F(T,S)
\tag{3}
\]

并满足(1)、(2)、w≥0、Σw=1。目标只与固定比较题T、S有关，程序没有另求freshOPT₂；若找到严格负值，它已足以反驳对应P+Δ预算，因为freshOPT₂至少是该比较对的覆盖。没有负值则不能仅凭本次固定角色抽样推出所有主题对都满足预算。

这里只计末两人的利润P，旧前缀提供者仍保有客户份额，所以P不是整局福利。对新客户，末两人的利润总和等于新增覆盖；因此(3)也可写为 `2Δ + old_tail_profit − C_F(T,S)`，与背景菜单证书的目标完全一致。

# 12000样本是什么，满额可行又说明什么

每轮先独立生成q个`rng.randrange(q)`值，再强制r(A)=B。故在固定A、B下可取的图有 \(q^{q-1}=7^6=117649\) 个。抽样有放回，没有去重；原表12000是抽取次数，不是不同图数，更不可能穷尽117649图。seed、抽取序列及去重数均未保存，当前无法把历史第i轮绑定到某张具体回复图。

所有图都有一个共同、精确、与抽样无关的可行点：令w₁₂₇=1、其它权重0。唯一客户接受全部七题，背景负载L，任意有序尾对的每人收益都是1/(L+2)。于是42条末位IC和6条首位IC全部为0，归一化成立，而且该客户不是新客户，有

\[
f=\frac{2}{L+2}=\frac23\quad(L=1).
\tag{4}
\]

所以每个精确策略锥与单纯形的交都非空，原表feasible=12000不挑出特殊可信回复图，也不构成“找不到反例”的额外数学证据。所有题在此点覆盖相同，这是程序允许的目录；它只证明锥非空，不要求这些图在覆盖互异且严格最佳回复的实例中可实现。

可行点(4)也不说明LP最优值就是2/3，更不能证明best=0是最小值。精确LP在非空紧单纯形截面上有有限最优值；结合下一节的独立证书可得每图最优值处于[0,2/3]，具体值没有被本表保存。

# 后续四IC证书为何覆盖所有这些回复图

[背景菜单的有限证书](背景菜单的有限证书--计算.md)已给合法H背景的逐客户恒等式与全L≥1非负余项。此处明确把它接入本程序的48行，而不是重复一轮发现LP。

在(2)中取a=B、H，分别记R_B、R_H；在(1)中取a=A、b=T、S，分别记R_T、R_S。这四行都≤0。逐型设

\[
s_B=v_m(B,r(B))-\frac{I_B}{p_m+2}\ge0,\qquad
s_H=v_m(H,r(H))-\frac{I_H}{p_m+2}\ge0.
\]

分母最多p+2直接保证这两项安全差非负。令a,b,t,s,h是本客户对A、B、T、S、H的会员位，\(D(p)=(p+1)(p+2)\)。已有证书余项为

\[
\rho_F=a[(1-t)(1-s)+ts]+(1-a)(b/2+2ts)\ge0,
\]
\[
\rho_O(p)=(1-b)(2-3a/2)+(t+s)(3-a)
+(p-1)[1-(a+b)/2+t+s]\ge0\quad(p\ge1).
\]

把原保底行换成相应真实偏离行，得到逐客户等式，再按w求和：

\[
f+\tfrac12R_B+R_H+R_T+R_S
=\sum_m w_m\left[\frac{\rho_m}{D(p_m)}+\tfrac12s_B+s_H\right]\ge0.
\tag{5}
\]

由于四R≤0，推出f≥0。这是对每张回复图、每个精确可行质量和所有整数L≥1的证明；它不是把12000次浮点无发现外推到未抽到的图。原表现在的接续价值是标识这个发现搜索的准确范围，而不是在已有证书之后再证明一次无界结论。

程序任务的[共享合成接口核查](../../tools/evidence/fresh-arbitrary-reply-probe-program/cone-contract-audit.json)只选q=7、L=1、明确人工seed=0，得到r=[6,2,6,3,0,2,4]。它执行原AST的数组/行构造片段一次，不调用原run/main或LP，逐项比较6223收益项、6096个IC系数、127目标项与独立Fraction公式，并核127个(5)余项。四行零基下标是43、42、8、9，乘子分别1/2、1、1、1。

该核查没有把浮点说成有理逐字相同：最大收益及IC误差均1/54043195528445952，目标误差1/27021597764222976；精确公式和余项另外保存。合成seed=0不是历史seed，单图算术核不是12000图重放，也不是新发现的普遍证书。本数据任务仅读取、解释并绑定该共享结果，未重复运行其算术。

# 一般背景反例、代码限制与接续边界

[52客户实际前缀反例](../反例/实际前缀的剩余利润与新增覆盖--反例.md)的完整四人根SPE在真实前缀(A,B)之后有P=17、Δ=0、freshOPT₂=18。这里旧覆盖并集为34客户，六个合法主题大小16、18、9、9、16、16，没有主题H等于该并集。因此它不能被本程序的p=L·I_H表达，不能说原12000次已经搜过该实例，也不与(5)矛盾。

若擅自将旧并集加作H，原尾首利润8必须至少达到H保底34/3，原策略立即不再是SPE。相同0/1负载值不等于相同合法目录查询能力；“合法背景”“单合法主题背景”“任意外生背景”不是同一域。

原CLI只接受整数参数，没有主动校验q至少5、L非负、cases非负等数学条件。本报告q7/L1/cases12000满足所述域；不能由这份合格输出认证所有参数调用。源码使用浮点HiGHS，失败状态只是不增加feasible，不保留原因；进入负阈值分支后的Fraction近似与删除w≤10⁻⁸坐标也没有精确重新核验。因此即使以后出现witness，仍需恢复单位客户和逐历史SPE检查，不能仅凭文件名认定为反例。

另已全文比较相邻的[3601B全比较对探针](../../tools/evidence/fresh-arbitrary-reply-probe-program/related/probe_fresh_global_two.py)：它从随机客户质量挑选近最佳回复，按(L,actual,response)去重，循环背景长度，遍历含重复的全部无序比较题对，并会更新best。本源直接抽回复图、不去重、固定L和五个角色，且best不更新。这两类输出的cases、policies、solved、best不是可互换的统计量。

本包[数据合同与来源绑定](../../tools/evidence/fresh-arbitrary-reply-probe-data/README.md)保原表、六字段静态解释、实际代码入口和共享有限核范围。可复用的是127型编码、48行的真实后继含义、非空锥机制以及证书映射；缺失的历史seed/样本/各LP最优值保持缺失，不为清洗补造。一般背景预算已经有完整反例，根半覆盖问题仍须使用其自己的量词和证据。
