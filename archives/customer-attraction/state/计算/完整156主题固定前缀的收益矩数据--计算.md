# 数据身份与本轮增加的认证

主源 `4fb7add9aa294a3da316` 是3395493B的[完整原收益矩](../../tools/evidence/full156-tail-parent-report/original/research_5/full156_tail2_kernel_10344.json)，SHA-256为 `876f063e9e88679c8803011775b04a4b707b8b586dfd3a840fd056f9ddcef3d4`，两冻结提交同字节。本轮经 `clean show` 取得原件并核共享保全件逐字节相同，遍历全部19字段、156个F整数和两张156乘156整数矩。原件继续共用，未重存另一份大矩或改写原字段。

本轮新增的[独立核验器](../../tools/evidence/full156-payoff-kernel-data/verify_kernel_atoms.py)完整展开六个比较索引的会员排列，再将R阈值段及Z前缀阈值切成1590个客户类型，以非负整数重数直接计算收益。全部48828个F/G/U整数与冻结文件严格相等。它没有导入原生成器的 `canonical` 或 `moment`，没有运行LP、原入口或尾策略枚举；这是读过作者实现后的另一种知情精确实现，不称盲审、外审或新颖性认证。

配套[生成器对象](../程序/完整156主题的阈值物化收益矩生成器--程序.md)负责原入口复跑；既有[两人尾报告](完整156主题固定前缀的两人尾报告--计算.md)负责定义级尾终局判断。后者明确当批没有第二份客户矩重构，本页补这一层证据，保留其原阅读时态。

# 目录、共同会员与单位客户

采用[共同目录完整历史模型](../定义/共同目录完整历史模型--定义.md)。六名单位提供者依次选择同一有限目录；客户价值一，最终在覆盖者间均分。完整目录依次为
\[
A_1,\ldots,A_6;\quad T_1,\ldots,T_6;\quad B_1,\ldots,B_6;\quad C_1,\ldots,C_6;
\]
以及各66个 \(R_{k,i,j}\)、\(Z_{k,i,j}\)，其中 \(k=0\) 时 \(i\ne j\)，\(k=1\) 时允许所有 \(i,j\in\{1,\ldots,6\}\)。故总数为 \(6+18+66+66=156\)。数据下标从0开始；描述符与标签顺序逐项认证，固定前缀下标为 `[0,1,2,3]`，旧实际尾为 `[4,5]`。

在原必要图的命名中，令 \(h=(A_1,A_2,A_3)\)，\(B_i,C_i\) 是强制第四步选 \(T_i\) 后的第五、六主题，\(R_{0,i,j}\) 对应历史 \((h,T_i,B_j)\) 的末回复，\(R_{1,i,j}\) 对应 \((h,T_i,C_j)\) 的末回复，\(Z_{k,i,j}\) 对应 \((A_1,\ldots,A_4,R_{k,i,j})\) 的末回复。物化后它们只是156个具体合法主题的名字，不能从命名继承最佳回复或完整策略。

输入[point](../../tools/evidence/full156-tail-parent-report/original/research_5/combined_branch_master_exact.json)含1905列：1个K、16个hist、582个joint-reply、1306个overlap。每个hist给六个实际A会员位，以及八个三位模式 \((T,B,C)\in\{0,1\}^3\) 的计数，计数和6。其16质量中恰10项正。joint-reply按它之前最近的hist列归属；582项中525项的 `hist_column_old` 不等于当前列下标，这个旧地址只作历史标签，不能据其索引当前列。已核每组旧标签一致且16组一一对应。

194个原回复组各保存状态01、10、11，遗漏00质量等于hist质量减这三项之和。本轮全部核为非负。取 \(R\) 的边缘半径为状态10与11之和，在该hist的共同质量区间 \([0,h]\) 上置 \(R_g=1[t<r_g]\)。[pair输入](../../tools/evidence/full156-pair-master-point/original/pair_master_exact.json)有364项当前hist、阈值段、回复组与Z质量。其29段在各正hist内相邻无缝覆盖 \([0,h]\)，每段含全部合法组；每个R会员位与半径位置相符，每个Z质量 \(y_{s,g}\) 满足 \(0\le y_{s,g}\le |s|\)。在段内令各Z为共同局部坐标的前缀 \([0,y_{s,g})\)，故全部主题在同一客户空间中联合实现；这里用到了明确共同阈值，而不只是一组可疑的两两交叠表。

对每个hist的六个模式多重集，枚举全部不同的有名索引排列，数目
\[
N_h=\frac{6!}{\prod_{v\in\{0,1\}^3}n_v!}.
\]
每一排列分得相同质量。在每个R段再按所有Z质量切开，得到49个子段；对子段宽度 \(w\) 和每个排列，客户质量为 \(w/N_h\)。采用原尺度
\[
S=28489412161994643877007580059596446489735466497254085120000
\]
时，全部 \(S w/N_h\) 都是正整数。这一尺度为所有hist质量、R半径及Z段质量分母最小公倍数的720倍，且 \(N_h\mid720\)，故整化有精确理由，未作舍入。各hist产生类型数依次为600、30、18、36、180、660、30、6、12、18，总计1590，所有类型实际互异，重数和恰为S。

[完整客户类型表](../../tools/evidence/full156-payoff-kernel-data/unit-customer-types.json)保留每类156位主题会员掩码及十进制整数重数。掩码第i位对应第i个标签，正重数表示该数量的不同单位客户，不是加权玩家。其规范类型列表SHA-256为 `87d207363bf7e9401b47c7a8be10cb8e7b23227fcd0a8cfbd2198893c21abccd`，编码约定见证据说明。每类恰有一个T位为1，因此六个T主题划分全部客户，\(\operatorname{OPT}_6=S\)，归一化最优福利为1。

# F、G和U是什么

以下用客户类型x的归一化质量 \(\mu_x=n_x/S\)，其中 \(n_x\) 是该类型的单位客户整数重数。令 \(p_x\in\{0,1,2,3,4\}\) 是固定过去 \(A_1,\ldots,A_4\) 对该类型的覆盖次数，\(a_x,b_x\in\{0,1\}\) 是两个剩余主题的会员位。定义
\[
F_a=\sum_x\frac{\mu_x a_x}{p_x+1},\qquad
G_{ab}=\sum_x\frac{\mu_x a_xb_x}{(p_x+1)(p_x+2)}.
\]
则选择a的第五位在末位选择b时，最终收益为
\[
U_{ab}=F_a-G_{ab}
=\sum_{x:a_x=1}\frac{\mu_x a_x}{p_x+a_x+b_x}.
\]
求和只在 \(a_x=1\) 处有贡献，无零分母。a=b也按两名玩家选择同一主题处理，没有删去对角线。\(G\) 对称，但 \(U\) 一般不对称；末位收益为 \(U_{ba}\)。\(U_{ab}+U_{ba}\) 仅为剩余两人利润，过去四人仍取得份额，不能当作六人总覆盖。

原存储分母
\[
Q=1709364729719678632620454803575786789384127989835245107200000=60S.
\]
所有整数分子除以Q得到归一化收益，除以60则得到上述S个单位客户实例的真实收益。所需分母 \(p+1\) 和 \((p+1)(p+2)\) 均整除60，因为p从0到4。独立核验逐类累加重数乘 \(60/(p+1)\) 与 \(60/((p+1)(p+2))\)，再求F减G；没有将浮点值恢复为分数。

全部F有15种值，G有198种值，U有365种值；G恰324个零，U无零。对每对不同主题已核
\[
G_{aa}+G_{bb}-2G_{ab}>0.
\]
左侧是以正权 \(1/((p+1)(p+2))\) 计的对称差质量，故所有156个覆盖集合不同；这解释原aliases为何恰为恒等映射，而不是仅核其长度。

# 与原运行、必要图和尾枚举的关系

完整读取7510B原生成器后，已实读同批[复跑比较](../../tools/evidence/full156-kernel-generator/rerun/comparison.json)和[执行记录](../../tools/evidence/full156-kernel-generator/rerun/execution.json)：未改源码和输入，原默认入口一次、`--with-welfare` 一次均退出0。默认重生的全部18个数学/身份字段与本原件相同，只有seconds改变，故新kernel字节哈希改变；福利模式继而绑定该新kernel哈希。没有把数学相等说成全文件字节相等。本报告任务没有再次执行原入口。

原point的 `verified_rows=5108` 与pair的 `rows=10344` 是两个阶段的元数据；文件名10344标识选用后者Z阈值完成。原point的1306个overlap和K不参与这个客户矩生成，但已完整读取且核非负；本轮没有重验5108/10344全部必要图不等式，也没有以原min-slack字段代替新认证。相关[阶段账本](../资源/显式回复主图的阶段点与未闭报价账本--资源.md)和原combined master说明仍缺actual第五位改Z后的真实新后继。共同有限客户实现填补的是“这些具体主题可在同一实例中存在”，并未补那些完整历史激励。

[旧停界资源](../资源/完整阈值目录固定四前缀的可信尾停界--资源.md)先保存解析判据与历史报告，明示当时未读大矩；[当前两人尾报告](完整156主题固定前缀的两人尾报告--计算.md)已经按全部平局定义给出此固定前缀的六个可信终局 \((C_i,B_i)\)，其福利均严格高于half，旧A5有正可信缺陷。这里不重跑该终局枚举。当前新增客户实现与既有定义级尾结论可共同使用，但不能将固定前缀的二层策略量词提升为六人完整树，更不能提升为任意目录的一般sixhalf。
