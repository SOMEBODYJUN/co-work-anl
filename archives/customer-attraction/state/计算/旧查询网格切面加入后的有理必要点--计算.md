# 原模型与固定支持之间的量词

数学来源是有限单位客户集N、有限非空共同目录 \(\mathcal T\subseteq2^N\)，六名单位权提供者依次观察全部有序行动，各选一主题。客户在最终覆盖者间均分，故 \(u_k=\sum_{x\in A_k}1/c_x\)，\(W=\sum_k u_k=|\bigcup_k A_k|\)。完整纯策略是 \(\sigma_k:\mathcal T^{k-1}\to\mathcal T\)，SPE要求每个k、每个有序前缀h（包括离轨）及每个合法F均满足源IC：按σ在h行动的收益不少于强制F后沿同一σ真实后继完成的收益。空主题、重复选择、零客户、所有离轨平局均保留；同负载不同历史不强制同后继。

固定任意这样一份σ，actual主题为A₁,…,A₆。六比较主题T₁,…,T₆来自同一目录；36floor和旧查询行本身只需T合法，继承图的8条OPT单换另需T元组真正达到OPT₆。令h=(A₁,A₂,A₃)，在h强制第四位T_j后的真尾为B_j,C_j，且
\[
R_{0,j,k}=\sigma_6(h,T_j,B_k)\quad(j\ne k),\qquad
R_{1,j,k}=\sigma_6(h,T_j,C_k)\quad(所有j,k),
\]
\[
Z_e=\sigma_6(A_1,A_2,A_3,A_4,R_e).
\]
强制的动作不因此成为其新节点的最佳回复。所有这些标签合法且来自同一σ，才可同时使用真实源、共同末价与容量约束。

数据只保指定标签的客户会员及辅助量，没有列出共同目录所有动作，更没有为全部有序历史指定σ。O=1是正比较覆盖时的齐次归一化；O=0及零客户实例不能用该归一化代替，但未归一化的必要行仍有效。具体16hist全都d=1，这是此固定支持的特征，不是一般游戏中客户只能属于一个T的假设。

# 四态质量与交叠辅助量的准确边界

固定hist质量x，组g的三个显式权分别为 \(y_{01},y_{10},y_{11}\)。隐含质量和边缘为
\[
y_{00}=x-y_{01}-y_{10}-y_{11},\qquad r_g=y_{10}+y_{11},\quad z_g=y_{01}+y_{11}.
\]
本次全部194组的 \(y_{00}\ge0\)，其中139组为0。每个group变量是**一个索引等号类的共同会员质量**，不是已经乘了边数的总客户质量；读出行时才乘轨道重数。不同group三态也不构成互斥客户分割，不能把582个权相加当总人数。完整194组四态、R/Z边缘和重数保在 [joint-state-ledger.json](../../tools/evidence/old-query-grid-necessary-point/joint-state-ledger.json)。

对不同g,h，原 `attractive_nested.py` 只给辅助量o约束
\[
0\le o_{gh}\le r_g,\qquad o_{gh}\le r_h.
\]
本次全部2612条上界通过。1306个o中1113个等于 \(\min(r_g,r_h)\)，193个严格较小。如果把储存o**逐字当作实际集合交质量**，还应有Fréchet下界 \(o\ge\max(0,r_g+r_h-x)\)；当前189个坐标违反这条额外解释要求。完整189例的列号、父hist、储存值及上下界保在 [point-audit.json](../../tools/evidence/old-query-grid-necessary-point/point-audit.json)，不能将其隐去后称原1905个权就是一份共同客户分布。

一个可直接复核的例子是0基列944：父hist列117，x为 \(84257521892866540736888424333193/972107803945250124507893651043072\)。两个组分别是 `(0,0,001,001)` 与 `(0,0,010,010)`；后者r_h=x，前者
\[
r_g=\frac{90336644108925020014650245658629}{1296143738593666832677191534724096}>0,
\]
但储存 \(o_{gh}=0\)。若R_h已占满这个hist，则与R_g的真实交必为r_g，故0不能是原样集合交。

这不是新发现的必要行错误，也不推出固定支持全域不可实现。原图有意利用这些交叠在原始行中均为非负系数的方向：在每个hist区间[0,x]上同时令 \(R_g=[0,r_g]\)，所有R交立即为min；再令
\[
Z_g=[0,y_{11}]\cup[r_g,r_g+y_{01}],
\]
即可保每组R/Z四态，因为 \(r_g+y_{01}\le x\)。这给一个有限有理断点的共同会员实现，所有193个储存交叠只向上增加；原交叠上界仍成立，非负交叠原始行不减，其它不读这些交叠的行不变。所用符号性质已从原构造和本点追加行的实际依赖核对，详见 [共同阈值构造](../构造/回复会员阈值的共同凸抬升与对角预算拆分--构造.md)。这是**换交叠坐标后的这层会员完成**；本次没有输出或整图认证一个新抬升点，也没有由共同会员给出全部历史SPE。加负交叠或其它高阶联合条件时不能沿用这个单调理由。

# 覆盖、收益与44条新行的当前精确回代

\[
O=\sum x\,1[d>0]=1,\quad
W=\sum x\,1[s>0]=\sum_{i=0}^5\sum x\frac{a_i}{s}
=\frac{348849746216199535907980629211183}{729080852958937593380920238282304}.
\]
六个u的精确分数均保在审计报告；近似依次为0.044055035875、0.044247074909、0.054053492445、0.071988118653、0.125405985400、0.138729112730。这里总hist质量也为1，是因为该支持全d=1。字段真实值为
\[

\quad
O/2-W=\frac{15690680263269260782479489929969}{729080852958937593380920238282304}.

36floor按actual位置i=0,…,5、member=R/Z和轨道(0,0)/(1,0)/(1,1)枚举。轨道c=30/30/6，组重数n_g由具体六索引边枚举。直接计算
\[
c u_{i+1}-\sum_{\text{hist},g\text{属轨道}}
\frac{n_g\,r_g\ \text{或}\ n_g\,z_g}{\sum_{k<i}a_k+6-i}.

全部36个值非负，9个为0、27个为正。合法性是实际源强制任一同目录回复后，每客户总分母不超过前缀负载加剩余人数，再用源IC求和；它不需要指定隐藏尾或让强制动作变成BR。
