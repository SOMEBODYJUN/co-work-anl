## 实际对象和代码输入

令 \(p\) 为共同主题数、\(n\) 为提供者数。对每个非空客户兴趣集合 \(S\subseteq[p]\) 设非负质量 \(w_S\)；代码把单位客户类型的整数重数放松为非负实数。终局计数向量 \(c\in\mathbb Z_{\ge0}^p\) 满足 \(\sum_a c_a=n\)，而兴趣类型的终局负载是

\[
 d_S(c)=\sum_{a\in S}c_a.
\]

主题 \(a\) 的单位客户收益行是

\[
 u_a(c;w)=\sum_{S\ni a}\frac{w_S}{d_S(c)},
\]

其中 \(d_S(c)>0\) 对所有有贡献项自动成立；不覆盖的类型贡献为零。终局覆盖福利行是

\[
 W(c;w)=\sum_{S:S\cap\operatorname{supp}(c)\ne\varnothing}w_S.
\]

`floor_scan.py` 的 `Fast(p,n)` 穷举所有终局计数向量与全部 \(2^p-1\) 非空兴趣掩码，构造上式的 `coefs`、覆盖矩阵 `cov` 和类型列。它的递归 `R(k)` 只以计数向量 \(k\) 为状态：对子状态 \(k+e_a\) 先递归，令

\[
 \theta(k)=\max_a\min_{z\in R(k+e_a)}u_a(z;w),
\]

再在每个孩子中保留满足 \(u_a(z;w)\ge\theta(k)-10^{-8}\) 的终局。这里的 \(R(k)\) 是该**计数状态 DAG** 的可实现终局集合；完整模型允许同一计数下不同有序历史拥有不同续局，所以不能把这个递归当作全部完整策略的递归。

`run(w)` 从根集合 \(R(0)\) 中取所有被使用主题的收益，令

\[
 v=\min_{z\in R(0),\,a:c_a(z)>0}u_a(z;w),\qquad
 \operatorname{OPT}_{\rm root}=\max_{z:\sum z=n}W(z;w),
\]

并报告 \(2nv/\operatorname{OPT}_{\rm root}\)。这是一项计数状态递归下的地板比率，不是完整 SPE 的 \(\operatorname{OPT}/W\)；`OPT` 只是在同一权重下对所有终局计数的最大覆盖。

## `cone_floor_attack.py`：固定锥 LP 候选

`Cone` 继承同一 `Fast` 表示。给定 \(w\)，它复用计数递归 \(R\) 并保存各状态阈值。给定目标终局索引 `target`，`policy(target)` 展开一个有序历史树：在每个历史 \(h\)，选第一个满足目标终局仍属于相应孩子的动作且目标收益超过 \(\theta(k)\) 的动作；其它动作的孩子选择该孩子中当前收益最小的可实现终局。对选定动作与每个偏离动作，程序写出客户类型系数差

\[
 \Gamma_{h,a;S}=\pi_{\sigma(h),S}(z_h)-
 \pi_{a,S}(z_{h,a}),
\]

其中两个终局都沿这棵生成的计数兼容策略继续。于是 \(\Gamma w\ge0\) 是这一个固定动作表的浮点 SPE 行约束；它不是所有完整策略的并集，也没有把同计数不同有序历史的自由续局量词纳入。

对支持 \(J\)（脚本枚举大小为 \(\min(p,n)\) 的主题子集）令

\[
 o_{J,S}=1_{S\cap J\ne\varnothing}.
\]

每次 LP 解的是

\[
 \min_w\ u_a(z;w)\quad\text{s.t.}\quad
 \Gamma w\ge0,\; w\ge0,\; o_J\cdot w=1,
\]

再把目标乘以 \(2n\) 写成 `ratio`。这条归一化只固定支持主题所触及的类型总质量，不是实际根福利 \(W\) 的归一化；因此该字段不能解释为 \(\operatorname{OPT}/W\)。脚本使用 SciPy/HiGHS 浮点 LP，没有保存 LP 对偶，也没有 Fraction 恢复或整数客户证书。

冻结 `cone_best.json` 的目标是 \(p=7,n=5\)，目标终局计数

\[
 z=(0,1,1,1,2,0,0),
\]

目标动作 `a=4`，支持 \(J=[0,1,2,3,4]\)，127 个类型坐标中有13个非零小数权重。其支持行归一化为1，目标效用为 `0.1111111111111111`，从而

\[
 2n\,u_4(z;w)=1.1111111111111112.
\]

为使候选点可复核，以下列出这13个非零类型（掩码位 \(0,\ldots,6\) 对应主题编号；其余114个类型权重为零）：

| 兴趣集合 | 小数权重 |
|---|---:|
| \(\{0\}\) | 0.1111111111111111 |
| \(\{1\}\) | 0.1291666666666667 |
| \(\{2\}\), \(\{3\}\), \(\{4\}\) | 0.1236111111111110（各） |
| \(\{2,5\}\), \(\{3,5\}\), \(\{4,5\}\) | 0.0555555555555556（各） |
| \(\{1,6\}\) | 0.0375000000000000 |
| \(\{2,6\}\), \(\{3,6\}\), \(\{4,6\}\) | 0.0430555555555556（各） |
| \(\{1,5,6\}\) | 0.0555555555555556 |

这些数是保存的浮点坐标，不是经过分母清理的整数单位客户；证据 JSON 保留完整127坐标和2,801个节点动作表。

生成树有 2,801 个有序历史节点和 16,806 条含自身动作比较（\(2,801\times6\)）。这个数值大于1只表示该固定计数策略锥的归一化目标没有把该点压到 \(1/(2n)\) 以下；它没有给出低福利完整 SPE、\(\operatorname{OPT}>2W\)，也没有证明任何普遍 floor。

同目录未纳入本次三源认领的 `fractional_cone_attack.py` 还以同一 `Cone` 递归尝试分数桥目标；其冻结 `fractional_cone_best.json` 的 \(p=7,n=5\) 记录是目标 \([1,1,0,2,1,0,0]\)、动作 \(a=0\)、slack \(0.2\)，没有触发 `BRIDGE FAIL`。这只是旁证性的有限阴性搜索，不能把该脚本的有限迭代或其小数策略表并入本页三源的重放结论。

## 实际重放与浮点边界

我用 `work.py clean show` 实读三份冻结源，保存原字节、源 ID、大小和 SHA-256 于[证据清单](../../tools/evidence/R275-direct-global-cone-floor-20261031/manifest.json)。随后运行[记录重放器](../../tools/evidence/R275-direct-global-cone-floor-20261031/replay/verify_records.py)：

* `floor_best.json` 的 \(v\)、`opt`、终局计数和比率在源代码重放中逐项相同；
* `cone_best.json` 的目标、支持归一化、目标效用、比率和最小加权 \(\Gamma w\) 在小数重载下相同（最小残差约 \(-2.5\times10^{-16}\)）；
* 由于源策略在 \(10^{-8}\) 阈值内按“第一个可行动作”解平局，小数重载会改变 865 个节点的动作表。故重放器把策略表差异记录为浮点 tie-sensitivity，而不把它包装成字节级或有理精确复现。

这些边界正是有限候选与结论的区别：若要升级为真实单位客户的完整 SPE 证书，必须固定每个有序历史的后继、用 Fraction 重建全部 \(\Gamma\) 行、清分母得到整数重数，并独立枚举同一目录的所有 (m)-主题终局覆盖；本批三源没有完成这些步骤。

## 与已有对象的比较和接续

同目录 `README.md` 把 Q-CAG-HALF 标为 OPEN，并把这组三源归为 exploratory floating-point policy-cone diagnostics；`common_query_regret_counterexample.md` 则有独立的九主题、30单位客户、六提供者完整 SPE，证明辅助的 \(F(T)\le W+\min_i u_i\) 失败，但其 \(W=25,\operatorname{OPT}_6=26\) 仍满足 half。该完整反例不能被本三源的 LP 比率替换，反过来也不能把本三源解释为该反例的证书。
