# R-171 可信低根发现有限探索

## 程序与候选域

源脚本完整实读 4,767 B，SHA-256 `7f749456b5a6dd3b53152161996db4251c8b06d286580f2f5f8e291b97e6cde3`，稳定 ID `cc2b103c4eac0db152c4`，blob `278e1d5100148db0012b75403e3441bcac570112`。它固定七主题、五玩家，初始客户类型权重为：mask 1→3、2→4、12→6、20→6、25→2、26→2、32→10、64→10，其余 mask 为零，总客户数 43。目标终局为 `(1,1,1,0,0,1,1)`，低根 cap 为 `5/43`。

每一步先由 `ExactSPESolver` 找出可实现终局，再要求目标满足低根约束。`credible_cone` 按四种 mode（uniform/max payoff/max welfare/min welfare）选取每个有序子历史的可信续局菜单；程序向策略锥追加首位收益约束 `cap*welfare - payoff >= 0`。随后枚举全部 21 个大小五的主题组合 (J)，以浮点 LP 生成客户质量，只有在有理恢复、策略锥精确检查、整数克隆、规范 `verify_certificate` 和 `independently_verify` 都通过时才接受。

它记录的 `best` 是 `OPT/W`，不是首根收益，也不是所有 SPE 的最坏比率。任何 `ratio>2` 才可能成为 half 目标的候选，且还需检查对象是否代表原模型的完整均衡量词。
