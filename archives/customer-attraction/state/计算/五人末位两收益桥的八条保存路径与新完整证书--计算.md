# 五人末位两收益桥的八条保存路径与新完整证书

## 1. 两式不是half，且一般式已有反例

原3622B程序和13976B全部JSON实读。它攻击

\[
\mathrm{A}:\quad 2u_i\ge u_m\ (i<m),\qquad
\mathrm{B}:\quad 2\sum_{i<m}u_i\ge(m-1)u_m.
\]

B等价于$2W\ge(m+1)u_m$，是聚合C2；这不是原half目标。当前一般A已被[三人七客户完整策略](../反例/逐人末位二倍保底的七客户反例--反例.md)否定，收益$(3/2,2,7/2)$。一般B也已被[三人23客户完整策略](../反例/二十三单位完整策略的收益倍数与均摊桥反例--反例.md)否定，收益$(5,6,12)$、46<48。七客户例只令B恰等，不能用它单独反B；23客户才给严格反B。

本报告固定五人七标签、seed20261022、trials_run1000，无反例字段或完整策略。它记录八次两个比值任一严格改善；最佳individual23/14<2、aggregate44/57<1。它不证明任一一般桥，也未决定五人特殊B即$W\ge3u_5$；当前五人half另有完整证明，不能由辅助桥状态倒推主目标未证。

## 2. 原搜索的有序路径量词

每试验独立生成127个非空兴趣mask：以0.1概率给1…20整数客户，否则0；调用整数集合值后端获得全部可实现根计数q。每个$q_a>0$尝试以a为末位，`path(k,last)`沿集合递推的合法孩子按标签顺序取**第一条**实现q且以a结尾的路径；不是列出所有有序路径。

固定q和末位标签时，所有同q的路径有同一终局利润多重集，删掉一个末位利润后较早最小值及和也相同，故第一条可实现路径足以评价这两个比值。最后一步只检查$k+e_a=q$且$q\in E(k)$：此q只能来自该孩子，成员资格恰含最后行动的最优性。其它层明确检查目标在孩子集内且该动作收益达到所有分支最低值的最大值。它保的是**可实现路径**，没有把策略强制成计数规则。

收益按scale60整数算。若`min(us)==0`就**跳过整条**，故原比值报告不含零利润路径。不过在这里的正确SPE域，只要某非空兴趣型有正客户，每名玩家均可选命中该型的主题、无论后继怎样至少分得1/m，因而每个实际SPE利润都严格正。真正零过滤只涉及全零有效客户输入；此时A/B的加法形式均为0≥0，不需要定义0/0。因此不把该过滤宣称为遗漏某个真实的“早期零、末位正”SPE反例。主CLI只开放trials、seed、必填output，实际p7/m5写在run默认参数，CLI不能修改它们；run对m1的空前缀min未给通用校验。

若ind>2或agg>1，才调用规范求解器`certificate(on_path=z)`与`verify_certificate(...).assert_valid()`，并保存完整instance/strategy。这个正例分支没有走到：原1000报告没有证书，不能从代码存在就声称原八条图已canonical核验。无命中时只存scope、m/p、trials_run/seed、records和两best字段。旧argv、库版本、逐输入日志、运行时间都未保存。

## 4. 本次补的是新图，而非恢复原未存图

仅回算一条路径的利润还不足以认证其SPE资格。本次标准库固定核在这七份输入各独立作一次集合值逆归纳，缓存792个计数状态；trial707第二路径复用同输入集合，不再次求解。对每条保存path，规定其在轨前缀的下一动作；所选孩子继续同目标，未选孩子各挑对当前人利润最小的可实现子SPE，递归展开所有有序孩子。

必要/充分证明与[完整终局全集算法](../算法/完整历史纯SPE终局全集--算法.md)一致：目标动作收益达到$\max_b\min_{E(k+e_b)}U_b$，且不同有序子树可独立拼接。随后**不用递推成员资格代替IC**，另按新表每个字面历史、每个强制行动真实完成，直接核规定列最大。

每张新图有2801有序决策节点、19607含self比较，16806非自身比较均非负；八图合计22408个“图×节点”、134448非自身比较，133989严格、459平局。它们的全动作按depth/lex层串、全部收益payload和逐节点索引保在证据包`last-record-00…07-new-policy.json`。

**身份限制：八张是本次新构的具体完整策略，不是作者未保存的同一动作图。** 原报告只提供客户表和在轨path；本次确定性选择未选分支，使这些path现在各有可复用全图证书。新图不同也不会改原scaled利润，因为它们保同一在轨终局。不能把本次严格/平局数量回填原1000扫描，亦不能据它认证未保存的其余试验。

原记录两best字段均逐条精确回算一致；本轮没有重跑1000次随机、原后端/规范包、自测或LP，只有与global原图共同的一次新定点核进程。真正运行与复现见[证据](../../tools/evidence/rd28-exact-outcomes-and-static-backgrounds-primary/README.md)。[末位份额后续审查](../资源/末位份额候选的两路径松弛与可信尾筛选--资源.md)中必要松弛点与真实两尾门槛另有对象，本八份完整图不替那些弱点补合法性。
