# R216 的实际数学范围

R216 README 将研究拆成四条分支：`global_proof`（一般价格和真实路径）、`earlier_menus`（固定恰三名剩余玩家的背景利润候选）、`credible_search`（完整树和结构种子的有限攻击）、`new_representation`（条件交集 Gram 表示）。这四条不能合并成一个“六人缺口已被攻击”的数学对象。特别是：

* `credible_search/README.md` 的 `gap_m3p6i0` 是 $m=3,p=6$、首位收益归一为 $1$、两种根比较各运行 45 秒；记录只找到数值候选 $OPT-W=2$，MILP 上界未闭合。
* `gap_m4p5i1` 是 $m=4,p=5$、第二位收益归一为 $1$；两种位置各运行 45 秒，只见 $OPT-W=1$，优化仍不足。
* `structured_gap_attack.py` 使用集合值 BI 的全部根终局、完整有序策略重构、固定非空类型的策略锥 LP 和顶点反馈。BI 的缓存是同背景下可实现终局的集合，不是把终局计数当 Markov 策略。
* `structured_gap_m5p7.json` 的 seed 是 $216741$，实际迭代 $0$ 至 $8$ 后主动停止；23 个客户的末位份额点和 14 个客户的私有循环 padding 只形成结构种子，最高仍是已知 all-big 值 $4$，不是一般桥的正证据。

这些记录的共同真值是“有限运行没有闭合一般命题”。它们不能证明 $OPT_m-W\le m u_i$，更不能直接证明 $OPT_m\le 2W$。对归一化还要保留目标差异：归一 $u_i=1$ 时寻找 `gap > m` 只瞄准逐人机会候选，half 仍要求直接验证 $OPT_m-2W>0$。

# 真实根支撑的可复用界

令一份完整纯 SPE 的实际覆盖集合为 $U$，$W=|U|$。取一个最优合法 $m$ 元组 $T_1,\ldots,T_m$，令 $O=\cup_jT_j$、$OPT_m=|O|$。若强制每个 $T_j$ 后，沿同一原策略产生的真正后继主题都不触及 $O\setminus U$，则每个 $T_j$ 的新覆盖客户付出 1、已覆盖客户至少付出 $1/m$。写

$$a_j=|T_j\setminus U|,qquad b_j=|T_j\cap U|.$$

真实一步激励给 $u_j\ge a_j+b_j/m$。取 $j$ 为相应位置并求和：

$$W\ge\sum_j a_j+\frac1m\sum_j b_j
   = |O\setminus U|+
rac1m|O\cap U|.$$

因此

$$OPT_m\le W+(1-\frac1m)|O\cap U|$$
       \le (2-	frac1m)W.$$

这个推导不要求正客户、不要求 $W>0$，$m=1$ 时等式也成立；它只要求真后继不泄漏到根遗漏客户。

若允许泄漏，令 $B\subseteq O\setminus U$ 为所有真实位置/最优主题查询后的真后继可能触及的根遗漏客户并集。每个遗漏客户在最坏情形只剩 $1/m$ 的付款，得到

$$W\ge |O\setminus U|-|B|+\frac{|O\cap U|+|B|}{m},$$
rac{|O\cap U|+|B|}{m},$$

故

$$OPT_m\le (2-\frac1m)W+(1-\frac1m)|B|.\tag{1}$$

这明确指出半覆盖的承重缺口是一个**并集** $B$；把不同偏离叶的福利相加会重复计算真实预算。对六名提供者，若要有 $OPT_6>2W$，(1) 强制 $|B|>W/5$。这只是必要的泄漏规模条件，不是反例构造。

界的常数不可由这条代数改进：取一个大主题 $A$ 含 $m$ 个客户，再取 $m-1$ 个互不相交的私有单客户主题。全历史恒选 $A$ 是 SPE，因为在有 $a$ 个先前 $A$ 选择、还剩 $r$ 位时，选 $A$ 得 $m/(a+r)\ge1$，任何私有主题至多得 1。于是 $W=m$、$OPT_m=2m-1$，比值正好 $2-1/m$。

# 森林末位候选与有限证据

森林候选把相同兴趣集合的单位客户压成带整数重数的类型点，主题—类型二部图假设为森林。定义静态末位阈值

$$\theta_m=\min_{\sum_a k_a=m-1}\max_{T\in\mathcal S}\sum_{x\in T}\frac1{1+k_x},
\qquad k_x=\sum_a k_a\mathbf1_{x\in a}.$$

自然候选是：森林关联图中每份完整纯 SPE 的每位玩家收益至少为 $\theta_m$。若候选成立，则对任意背景 $k$，令 $M(k)=\max_T\sum_{x\in T}(1+k_x)^{-1}$，对最优 $m$ 个主题覆盖次数 $d_x$ 有

$$\sum_x d_x\le mM(k)+(m-1)M(k)=(2m-1)M(k),$$

因为 $1\le(d_x+k_x)/(1+k_x)$ 对 $d_x>0$ 求和后，$k_x$ 项可按 $m-1$ 个背景主题重新计数。再对背景取最小可得 $\theta_m\ge OPT_m/(2m-1)$；所以逐人阈值若真，确实推出森林类的 $(2-1/m)$ 福利界。这个推导是条件蕴含，不是阈值候选的证明。

实际程序的证据边界如下：

* `probe_forest_floor.py` 是 3,678 字节的 exact solver 生产器，固定种子 `202610231`，生成 240 个连通类型树实例，参数 $p\in\{4,5,6\}$、$m\in\{3,4,5,6\}$。每个实例枚举全部 $m-1$ 背景计数、计算精确 Fraction 阈值，并检查完整 SPE 根终局中使用主题的收益。原报告顶层 `found_counterexample=false`、`universal_claim_proved=false`，240 个记录中没有坏例。
* `probe_forest_floor_cone.py` 是 5,315 字节的策略锥攻击器，固定种子 `202610232`，80 个 $p=5,6,7,8$、$m=3,4,5,6$ 的样本。它把固定种子支持上的类型重数作为非负 LP 变量，约束原策略的所有 IC 行以及每个背景的一项原权重最佳菜单 $\ge t$，最大化 $t-u_i$。报告 `counterexample=false`、`universal_claim_proved=false`；浮点层没有可精确重构的正点，不能写成“80 个锥已证明候选”。

这两个报告的可接续内容是参数域、seed、有限记录格式和 LP 行语义；缺少的是所有森林图、全部有序历史证书、LP 精确对偶以及从坏终局到同一前缀的拼接引理。特别是，负结果不支持一般森林定理，浮点约 $10^{-17}$ 的正舍入也不支持反例。
