# 对象与来源身份

来源是 `R-373daba10913464c93771a808d88fce3/credible/fixed_bridge_mult2.json` 的 1873 字节 JSON，SHA-256 为 `808c20a5fa44dcb11d91924a63849825e3fc7a3c984dd4433eeb5d6c5e885bbc`。它不是独立的博弈模型或新策略：`fixed_bridge_attack.py` 读取已有三人、六主题逐人安全值证书的完整策略，在线性策略锥中优化客户类型重数，再将有理顶点整数化。

因此本对象保留“固定策略锥中的有限证书”身份。策略锥只描述这一份完整策略成为 SPE 的客户重数，不等于所有完整 SPE 的并集；优化器原本是浮点候选生成器，最终结论以下面的 Fraction 重放为准。

## 精确重放

整数客户重数向量按非空六主题掩码顺序排列，非零项为：

| 客户兴趣掩码 | 重数 |
|---:|---:|
| 2 | 23 |
| 4 | 28 |
| 11 | 15 |
| 16 | 23 |
| 25 | 15 |
| 34 | 7 |
| 36 | 2 |
| 43 | 21 |
| 45 | 36 |
| 48 | 7 |
| 56 | 21 |

总客户数为 (198)。策略给出的全部有序历史动作共 (1+6+36=43) 个节点；对每个节点的六个强制动作逐项用单位客户均分公式重算，共 258 项（含自身动作）。最小激励松弛为 0，110 个非自身比较严格，43 个自身比较取等，没有负松弛。因此该整数化策略确实是当前输入上的完整历史纯 SPE。

实际路径为
\[
(0,3,4),\qquad (u_1,u_2,u_3)=(48,48,42),\qquad W=138.
\]

枚举全部56个允许重复三元组，唯一达到最大覆盖的组合为
\[
(1,2,4),\qquad \operatorname{OPT}_3=198.
\]
所以本例的半覆盖余量为 (2W-operatorname{OPT}_3=78)，并非六人主命题的反例。

## 固定桥目标的含义与数值

原脚本在策略锥中把目标写成
\[
\langle \mathbf 1_{\operatorname{cover}(1,2,4)},w\rangle
-\langle \mathbf 1_{\operatorname{cover}(0,3,4)},w\rangle
-2\,u_1.
\]
整数化后这就是
\[
\operatorname{OPT}_3-W-2u_1=198-138-2\cdot48=-36.
\]
脚本报告的归一化目标 (-6/23) 正好是 (-36/138)。这说明在这份固定策略和这组客户重数上，实际根玩家的两倍收益足以覆盖最优覆盖与实际福利之间的 60 单位差；该候选没有发现“二倍根收益不足”的攻击。

同一策略的 `mult=3` 文件（另一个来源）给出不同重数、(W=103)、(\operatorname{OPT}_3=145)、(u_1=69/2)，对应目标 (145-103-3(69/2)=-123/2)。它同样只是有限的三倍试探，不能替代本对象的二倍核验，也不能合并成一个统一定理。

## 与既有对象的边界

该有限证书与[三人逐人混合安全值反例](../反例/三人逐人混合安全值--反例.md)共享原始 34 客户策略证书，但客户重数经策略锥重选，故不能把 34 客户的逐人安全值缺口 (v_3-u_1>0) 转写成本对象的二倍根支付失败。它也与[零背景保护遗漏与超额利润价格反例](../反例/零背景保护遗漏与超额利润价格--反例.md)及[唯一最优组合的全遗漏支付](../反例/唯一最优组合的全遗漏支付--反例.md)不同：后两者反驳的是遗漏客户的强支付桥，本对象只检验一个固定策略锥中的数值目标。

本来源没有证明所有策略锥、所有完整纯 SPE 或任意六人共同目录都满足二倍根支付桥；它只提供一个已验证的正向有限实例。后续若研究该桥，应把“固定策略锥候选”“精确整数化重放”和“全模型量词”分开，并先寻找目标值为正的完整证书，再讨论是否能扩展到六人。
