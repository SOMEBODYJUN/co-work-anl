# R18 平方根到达收费的动态归纳搜索

## 来源身份和代码合同

本对象对应冻结源 `c3da7e69c42b7800323f`，实际冻结路径是 `dynamic_induction/sqrt_arrival_search.py`，不是其依赖文件 `step_profit_search.py`。源文件 1,413 字节，SHA-256 为 `191f8233be3bdfae468e4dc9c062cab5bf6da0f78396279b9750474d24fbab35`。它以 `from step_profit_search import *` 导入组合函数、`Instance`、`CustomerType` 和 `ExactSPESolver`；依赖源的稳定 ID 是 `5878a511362d7d461809`，1,608 字节，SHA-256 为 `37ad28e1c86f75b4fb9d24f172a98fdbefc318bd5faf576529f0392fb3aba3d9`。本轮先按 ID 实际导出两个冻结源，再使用已保存的纯 SPE 精确模型依赖运行，完整过程和字节指纹在 [evidence manifest](../../tools/evidence/R18-dynamic-two-agent/manifest.json) 中。

依赖模型的数学合同是：有限标记主题目录；每位单位玩家依完整有序历史选择一个主题；客户是带正整数重数的主题子集；终局中同一客户重数在其被选择主题之间均分。`ExactSPESolver` 递归枚举每个前缀计数的全部纯 SPE 终局计数集合。它不声称混合 SPE、策略输入位复杂度或多项式算法；本源脚本也没有生成完整策略证书。

## 源程序实际计算的量

给定实例 I，源程序先构造 `S=ExactSPESolver(I)` 并调用 `S.outcomes()`。对每个可达的前缀计数向量 b 及行动主题 a，令 `b' = b + e_a`，`r = |I| − Σ_j b_j`。

源程序定义静态“剩余背景利润” `F_I(b)`：在所有非负整数向量 d 且 `Σ_j d_j = r` 中，最大化 `Σ_C m_C · D_C/(B_C+D_C)`，其中 `B_C = Σ_{j∈C} b_j`，`D_C = Σ_{j∈C} d_j`，`m_C` 是客户重数。于是 `gap = F(b) − F(b')` 是把一个行动槽固定到主题 a 后，静态最优未来背景利润的下降；它不是完整 SPE 的真实总收益差，也没有对所有历史的终局选择求和。

随后只保留满足以下条件的终局计数 z ∈ `S.outcomes(b')`：

1. 主题 a 在 z 上的终局效用 `u_a(z)` 不低于 `S.threshold(b)`；这使行动 a 和该终局在计数层的纯 SPE 递归筛选中相容；
2. 代码逐客户累加只对包含 a 的客户的平方根到达收费 `Q_a(b,z) = Σ_{C:a∈C} 2m_C · (√(B_C+1) − √B_C)/√Z_C`，其中 `Z_C = Σ_{j∈C} z_j`。

它最大化 `deficit = float(gap) − Q_a(b,z)`，找到第一个正值就停止。`gap` 由 `Fraction` 精确计算，而平方根收费最终转为 Python `float`；因此这是一个针对该收费候选的有限数值障碍搜索。

## 独立重放和正缺口见证

以源代码固定的 `Random(912343)`、最多 1,000 个随机实例执行。第 108 个实例首次得到正缺口；标准输出保存在 `run.stdout`。实例有 5 名玩家、3 个主题 0、1、2，客户类型及重数为：{0}→6、{1}→4、{0,1}→3、{0,2}→5、{1,2}→7、{0,1,2}→1。

取前缀 `b=(2,1,0)`，行动 `a=1`，子前缀 `b'=(2,2,0)`，以及终局计数 `z=(2,3,0)`。独立 `verify_instance.py` 重新建立同一实例，重新计算组合最大值和纯 SPE 集合；JSON 见 [verify_instance.json](../../tools/evidence/R18-dynamic-two-agent/verify_instance.json)。结果为 `F_I(b)=323/30`，`F_I(b')=67/15`，所以 `gap=63/10=6.3`。

前缀 b 的静态最大值由剩余计数 `d=(1,1,0)` 达到；子前缀的最大值由 `d=(0,1,0)` 或 `d=(1,0,0)` 达到。终局 z 属于 `S.outcomes(b')`，而主题 1 的效用与前缀阈值均为 `u_1(z)=threshold(b)=67/15`。这不是被阈值筛除的离轨计数：它正好处于行动 a=1 的阈值边界。

四类包含主题 1 的客户给出的收费分别是 `8(√2−1)/√3`、`6(2−√3)/√5`、`14(√2−1)/√3`、`2(2−√3)/√5`。总收费 `Q_1(b,z)=22(√2−1)/√3 + 8(2−√3)/√5 ≈ 6.2198630323056685`，因此 `63/10 − Q_1(b,z) ≈ 0.0801369676943313 > 0`。

正量约为 8.0×10⁻²，远高于本次浮点运算的舍入尺度；但收费本身仍是实数近似，不应改写成有理精确等式。精确部分（F、gap、阈值和终局效用）及运行统计 `count_states=56, terminal_states=21, retained_outcomes=65` 均由独立重算保留。

## 这个结果能说明什么

它给出一个具体的有限模型和一个计数层纯 SPE 可实现的动作/终局，使代码提出的平方根到达收费不足以覆盖静态未来利润机会下降。也就是说，若归纳证明固定使用上述 `Q_a(b,z)` 作为唯一偿还项，则该候选在这个见证上失败；至少需要改变收费、增加非局部项，或限制其适用域。

它不能推出：

- 所有非局部势函数或所有动态支付都失败；
- 当前六人、六主题 Q-CAG-HALF-6 问题存在半覆盖反例；
- `z` 对一份完整有序历史策略已被展开为完整离轨证书；
- 静态 `F_I` 就等于完整 SPE 的真实总剩余收益；
- 任意人数、任意客户目录的统一不等式已被证伪。

与既有 [R-18 动态利润机会与非局部势边界](../障碍/R-18动态利润机会与非局部势边界--障碍.md) 的关系是：旧对象给出大主题族和五人背景的精确有限差值，说明单步终局收益差不能直接承担长历史利润机会；本对象进一步针对一个平方根形式的局部到达收费找到正缺口。两者都属于有限审计/候选障碍，不是完整六人定理。与 [R-18 占用背景安全有限审计](../计算/R-18占用背景安全有限审计--计算.md) 一样，精确枚举边界和运行依赖必须随证据保存，不能把有限搜索计数升级为全称结论。

## 接续用途

后续若要修复这条归纳路线，应至少完成以下一项：证明一个包含额外背景租金或跨客户耦合项的势函数；证明平方根收费在额外结构（例如客户族限制、单调性或共同支持条件）下覆盖当前缺口；或将 `F_I` 改为与完整 SPE 续局一致的动态价值并重新搜索。任何修复都要保留 `B_C=0`、空主题、重复覆盖、平局和离轨历史的边界，不可由这个正见证删掉原模型中的合法实例。
