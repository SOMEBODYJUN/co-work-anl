# 一般反族的数学内容

README 将 CAG-MODEL、Q-CAG-HALF 保持为开放目标。其一般完整计划反族把已有分数覆盖前缀递推放宽到任意完整计划，并保留每层所有有序历史上的最大 regret 总和
\[
B=\sum_i \max_{h\text{ at depth }i}R_i(h).
\]
对该反族，实际路径末位在全部历史都是最佳回应，但前面行动可以不可信；因此它不是完整纯 SPE 的反例，也不是删除回放的可信后继。README 的精确主张是排除人数无关的 `OPT\le 2W+C B` 形式（在所给反族中 `OPT-2W` 随人数增长），而不是排除 Q-CAG-HALF 本身。

同一 README 还记录一条更窄的保留全历史 factor-two 计划尝试：若要求每个完整历史 forced payoff 对 prescribed payoff 至多 2 倍，并希望证明
\[
OPT_m-2W\le C B,
\]
则反族只强迫绝对系数 \(C\ge1\)。它没有反驳 \(C=1\)，没有证明任何普遍 C 存在，也没有把形式 factor-two 计划误标为 SPE。`B=0` 的情形正好回到完整 SPE 目标，因此一个真正的 `C=1` 证明会关闭 Q-CAG-HALF；当前仍开放。

README 进一步区分三个层次：

1. ASD 的特定删除回放只给实际路径误差；本反族不是已经核实的删除回放，不能用它否定更细的删除来源归纳。
2. 可信前缀编译器中的 Delta 依赖完整 SPE 后继的最低退出收益；不能用任意后继的 regret 代换。
3. 全历史同层 regret 比实际路径误差更强，但定义级反族仍不足以给人数无关的半覆盖支付桥。

# 程序和 JSON 的精确核对

脚本 `audit_all_history_regret.py` 逐个 `m=2,\ldots,6` 枚举所有有序历史和强制动作。它验证：

- 由 `complete` 生成的实际叶、每个深度的最大 forced-action regret、`B` 和闭式公式一致；最后一位在每个历史都是最佳回应。
- 加入公共客户数 `q` 只平移所有分支收益，不改变每个历史的 regret 差；定义级公式的 `W`、`OPT`、`F_m(m)`、加权误差和可信退出 Delta 均通过精确分数断言。
- factor-two 计划的规则在所有枚举历史上满足单步收益不超过二倍（同时检查更宽的 `(m-1)/L` 因子），并得到 `C>=1` 的数值边界；没有生成 `C=1` 反例。

JSON 的代表性数据为：

| m | 全历史数 | B | 实际 W | OPT | `OPT-2W` |
|---:|---:|---:|---:|---:|---:|
| 2 | 3 | 0 | 2 | 2 | -2 |
| 3 | 13 | 1/2 | 2 | 3 | -1 |
| 4 | 85 | 5/6 | 2 | 4 | 0 |
| 5 | 781 | 13/12 | 2 | 5 | 1 |
| 6 | 9,331 | 77/60 | 2 | 6 | 2 |

factor-two 分支使用 `L=floor(m/2)` 的大主题/单例规则；其 `half_bad_difference` 在 m=5、6 为 0，说明有限例达到半覆盖等号附近，但仍不构成 SPE 计划或一般反例。总计 10,213 个有序历史与 60,276 个强制动作核查通过。
