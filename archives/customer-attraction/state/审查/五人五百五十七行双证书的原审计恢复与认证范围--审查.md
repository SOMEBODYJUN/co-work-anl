# 五人五百五十七行双证书的原审计恢复与认证范围

## 1. 恢复了什么，精确结论是什么

本页承接[增强索引系统的全型定价与可行点分离](增强索引系统的全型定价与可行点分离--审查.md)当时明确缺少的原审计程序、原报告和双证书输入。2026-11-02从冻结来源逐件恢复后，原独立程序对51个正乘子执行一次全型精确核验，原父审程序对67个正有理原子执行一次557行核验，均成功。后一报告与冻结822字节报告逐字节相同；前一报告除实际耗时外全部字段相同。

因此，下文指定的**同一557行扩大类型域**、非负客户质量及归一化 $W=1$ 下，最大比较覆盖确为

\[
\boxed{\beta_*=
\frac{178528430822287579296070598592537012737}
{87421565922360356032366460363114422206}}
\approx2.042155490337931.
\]

上界来自覆盖整个允许类型域的对偶不等式，下界来自达到同值的67原子有理可行点；两边都不依赖浮点求解器的终止判断。这个值大于2，说明这557条必要行单独不足以推出半覆盖。它不宣称某个共同目录存在达到该比值的完整SPE，也不宣称比较覆盖自动等于该目录的真实最优覆盖。[五人半覆盖](../定理/五人半覆盖--定理.md)使用更强信息，二者并不矛盾。

## 2. 模型投影和允许域

原模型为有限单位客户、有限非空共同目录、五名单位提供者依全部有序历史行动、终局客户价值在覆盖者间均分。固定任意完整历史纯SPE $\sigma$。实际路径记作 $ABCDE$；在原第二位改选 $E$ 后跟随同一策略得到 $AEUVW$；在原第三位改选 $E$ 后得到 $ABEXY$。字母 $W$ 在路径中是主题标签，福利另以数学符号 $W$ 表示。三个索引族来自同一五个比较主题 $T_1,\ldots,T_5$，允许重复主题和重复索引，不能重新选离轨续局的平局。

每个压缩客户类型 $z$ 含下列数据。

| 数据 | 全部允许域和顺序 |
| --- | --- |
| 固定会员位 | `ABCDEUVWXY` 的任意十位，共1024种，实际五位全零也保留 |
| `AB_hist`、`AE_hist` | 五个索引的 $(t,r,s)\in\{0,1\}^3$ 词典序8格非负整数直方图，各格和5 |
| `second_hist` | 五个索引的 $(t,h,i,j)\in\{0,1\}^4$ 词典序16格非负整数直方图，格和5 |
| 共同 $d$ | 三族中 $t=1$ 的总次数相同，$d=0,\ldots,5$ |
| 三个旧菜单 | 顺序 `actual,second,third` 的 $(\ell,h)$，$0\le h\le d$、$0\le\ell-h\le5-d$ |
| 质量 $x_z$ | 非负实数；有理证书使用严格正的有理非零质量 |

三位直方图全域有 $\binom{12}{7}=792$ 种，四位有 $\binom{20}{15}=15504$ 种。共同 $d$ 是这个松弛所要求的跨族直方图一致性；原完整历史、相同历史的相同行动、所有未记录的真实偏离等没有全部编码。

设 $w(z)=\mathbf1_{a+b+c+d_0+e>0}$、$o(z)=\mathbf1_{d>0}$，其中 $d_0$ 是主题D的会员位，和共同索引次数 $d$ 不同。系统要求

\[
x_z\ge0,\quad W=\sum_zx_zw(z)=1,\quad
\sum_zx_zg_r(z)\ge0\quad(r=1,\ldots,557),
\]

并最大化 $O=\sum_zx_zo(z)$。只在来自真实SPE且比较主题选择真正最优五元组时，$O$ 才等于 $\mathrm{OPT}_5/W_{\rm original}$。零客户、空主题、重复主题以及零收益项没有删除；真实SPE若 $W_{\rm original}=0$，任一非空主题会让末位从零收益严格改善，故所有合法主题都空，$\mathrm{OPT}_5=0$。归一化只用于非零福利情形。

## 3. 437旧行和120新增行的实现来源

前437行采用[索引福利界](../定理/五人索引最优偏离福利界--定理.md)的完整定义：三条固定路径212行、AB/AE两族各71行、第二位索引族83行。原父审通过AST读取成熟 `customer_attraction_five_indexed.py` 中首次 `from pathlib import Path` 之前的定义前缀；调用 `evaluate(..., True)` 保留83行中的11条额外关联行。它没有执行该旧程序的证书载入、64点检查或旧全域对偶循环。

新增120行是10条末位去对角行和110条保一份交叠的同族两查询行。父审从五个索引展开为五条会员词，逐索引相加重建它们，既不导入发现定价程序，也不调用它的新增行求值器。

### 末位去对角的10行

固定一个客户与族内第 $i$ 条分支，令末位前缀负载为 $p_i$，实际末位会员为 $f_i$，某查询位置的会员为 $q_i$。对全部不同索引 $i\ne j$，真正末位最佳回应给出该客户贡献

\[
\sum_i\sum_{j\ne i}\frac{f_i-q_j}{p_i+1}
=\sum_i\frac{4f_i-Q+q_i}{p_i+1},\qquad Q=\sum_jq_j.
\]

每客户贡献可以负，只有全客户求和才是必要非负行。AB、AE分别有3个查询位置，第二位族有4个，合10行。分母始终是分支 $i$ 的真实末位前缀，不把分支 $j$ 的后继或背景搬过来。

### 保交叠两查询的110行

在每个真正末两人子局，背景为 $p_i$、实际尾会员为 $a_i,b_i$，定义

\[
H_i=\frac{a_i+b_i}{p_i+a_i+b_i}
+\frac{a_i}{(p_i+1)(p_i+2)}.
\]

零分子份额取零。对任意两个合法查询主题，其客户会员 $q_j,r_k$ 给强PAIR右端

\[
\frac{q_j+r_k}{p_i+1}
-\frac{q_jr_k}{(p_i+1)(p_i+2)}.
\]

强PAIR来自同一完整策略的三条真实最优性差及一个非负包含差；证明和全部五模式公式见[等号模式闭包](../引理/末两人比较三索引的等号模式闭包--引理.md)。父审按 $i=j=k$、$j=k\ne i$、$i=j\ne k$、$i=k\ne j$、三者全异逐项计数。三位族每族6个允许重复无序位置对，四位族10个，各乘五模式，合110行。这里交叠系数为1，不是弱两人税中丢掉额外交叠后的系数2。

所以父审的独立性应准确表述为：**复用已审437行定义，独立按字面索引重建120新增行**。它不等于557行全新独立实现，更不等于重新证明所有已存数学引理。

## 4. 51乘子全型上界的精确分解

原独审完全不导入发现用 `Universe`、`family_score` 或旧437求值器。它仅为最终51条正乘子重建需要的系数。把有理乘子写为 $\lambda_r=L_r/D$，其中所有 $L_r>0$，

\[
D=2010696016214288188744428588351631710738,\qquad
B=4106153908912614323809623767628351292951,
\]

则 $B/D=\beta_*$。完整51项整数值保留在[原对偶输入](../../tools/evidence/round4-pricing-resumed-boss2/original/exact_dual_overlap1.json)，其SHA-256为 `6cc1849b3808d773a317efd64c6ed6df59ce89a589a06a303e9edc297f3d9d34`。其余506行的乘子是零，不需要在该上界核中逐条评价。

对每个允许类型，需要

\[
Bw(z)-Do(z)-\sum_rL_rg_r(z)\ge0. \tag{1}
\]

固定十位和共同 $d$ 后，最终活跃式分成18条固定路径旧行、三族各自直方图分数，以及三个旧菜单的仿射项。直方图族之间没有仍待联合优化的乘积；存在的跨路径查询系数仅依固定会员位、背景和本族计数。因此可以对三个直方图族分别取最大，再相加。该分解针对这份51项支持成立，不是任意更强跨族系统均可分离的断言。

活跃的三条pair行都是 `query_equal`：$j=k\ne i$。令同族 $Q=\sum_jq_j$、$R=\sum_jr_j$、$K=\sum_jq_jr_j$，其系数为

\[
4\sum_iH_i
-\sum_i\frac{Q+R-q_i-r_i}{p_i+1}
+\sum_i\frac{K-q_ir_i}{(p_i+1)(p_i+2)}.
\]

这正是代码 `4*HH-(counts_u+counts_v)*AA+ownsum+overlap*GG-ownboth` 的定义依据，并保留同索引交叠 $K$。

旧菜单写成变量 $h$ 与 $\ell-h$，其域是 $[0,d]\times[0,5-d]$。仿射目标在 $(\ell,h)=(0,0),(d,d),(5-d,0),(5,d)$ 四角达到最大。$d=0$ 或5时角重复，仍覆盖整个允许域。故只需1024个十位选择乘6个共同次数，即6144个**条件最大化问题**；这不是6144个游戏或全部客户类型的数量。

小有理系数先用 `Fraction` 形成并断言乘120后为整数。直方图基础数组使用64位整数，但与大整数乘子相乘前转为Python任意精度对象整数，因此最终残余不依赖浮点容差。被核的整数是

\[
120(Bw-Do)-\max_{z\text{ 属该条件域}}\sum_r120L_rg_r(z).
\]

一次恢复运行得到：51正乘子、18固定旧行、6144条件、126个缓存分数上下文；最小残余0、84个零条件、负条件列表空。126是缓存键数量，不是另一个全域大小。由(1)乘任意非负质量并求和，结合所有行总slack非负，得到 $DO\le BW$。

## 6. 恢复、运行与复用的准确边界

五个主源完整阅读，包括原代码所有分支和三个报告所有字段。两个冻结提交的同内容来源保存在[逐源清单](../../tools/evidence/round4-audits-resumed-boss2/source-manifest.json)；本次不修改原件。只新增一个复现启动器，按原相对路径放入临时目录后执行原字节程序，不修写原算法。

原父审用来定位项目根的 `customer_attraction/__init__.py` 仅做文件存在性标记，没有导入其模型包；其准确691字节原件复用既存证据，未创造一个假的空包。旧437评价器也复用准确原件，SHA-256为 `f9a82e26fe977158fb60acb0fc8b14f6bf88b3188b024ca09491cb98138ef9e9`，执行范围仅定义前缀。

本批原独立全域入口1次、原父审67点入口1次；60点入口0次、旧437完整CLI0次、发现LP/列生成/完整SPE搜索0次。新全型报告仅 `seconds` 从原24.179453372955322变为12.275074481964111；这两个值是不同运行的程序内耗时。启动器计进程墙时分别约12.451秒和0.791秒，不能和程序内耗时混同。

代码、输入路由、原始stdout/stderr、新报告及比较结果见[证据入口](../../tools/evidence/round4-audits-resumed-boss2/README.md)。其独立性是源代码所述的系数实现独立性；本次原代码重放没有新增一套独立实现，也不是外部同行评审。

## 7. 用途、关系证据与接续

本页和原对偶输入、67点共同提供557模板精确最优性的上下界。与[557列生成轨迹](../计算/五人五百五十七行列生成的原始轨迹与点版本--计算.md)的关系是“精确认证与数值发现的版本对照”，不是浮点终止推出精确最优；与[437模板障碍](../障碍/五人索引偏离模板--障碍.md)的关系是加入120有效行后的更强必要系统，原64点和新67点必须分别检验。

对后续数学，若继续加跨族共同归属、根行或完整历史约束，应重新说明允许类型域、行的真实性、可行点版本和新的全域定价；不能把这里的51项分离结构直接用于任何增加了跨族乘积的目标。若希望得到原博弈中的取等例，还须另外给出共同目录、整数单位客户和每个有序历史上的策略，并核全部偏离；清除有理质量的分母不完成这些义务。

以上关系有公式和准确来源支持，留给第三阶段建边；本批不将旧关系图导入为正式完成。六人完整历史纯SPE半覆盖仍是独立目标。
