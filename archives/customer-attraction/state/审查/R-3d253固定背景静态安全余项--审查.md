# 读取范围与对象

冻结源是 4482 字节的个人审查材料；两个冻结提交定位同一字节。它不是 SPE 福利证明，而是任意非负背景 (b) 下的静态比较引理。目录 (mathcal S) 有限且非空，客户单位权，比较元组有 (r) 个主题，静态对手有 (s) 个主题。背景允许实数，动态使用时必须再证明它来自合法前缀。

对客户 (x)，比较元组负载为 (d_x)，定义
[
\phi_b(d)=\begin{cases}0,&d=0,\\d/(b+d),&d>0.\end{cases}
]
于是 (F_r(b)) 是 (r) 个合法主题的最大总剩余利润。对静态对手分布 (Q) 令 (L_x=E_Qc_x(B))，
(g_Q(T)=\sum_{x\in T}(b_x+1+L_x)^{-1})，(M_Q=\max_Tg_Q(T))。

# 精确余项恒等式

源给出逐客户非负余项
[
\rho(b,d,L)=\begin{cases}
L/(b+1+L),&d=0,\\
[d(d-1)+bL]/[(b+d)(b+1+L)],&d\ge1.
\end{cases}
]
逐式通分得到
[
\phi_b(d)+\rho(b,d,L)=\frac{d+L}{b+1+L}.
]
求和后，若 (mu_T=E_Q\#\{j:B_j=T\})，则
[
\sum_x\phi_{b_x}(d_x)+R_b(d,Q)
 =\sum_{j=1}^r g_Q(T_j)+\sum_T\mu_Tg_Q(T)
 \le(r+s)M_Q.
]
倒数函数的凸性给 (M_Q\le\max_T E_Q f_B(T))，有限 minimax 取最优 (Q^*) 后得到
[
F_r(b)+R_b(d^*,Q^*)\le(r+s)v_{s+1}(b),
\qquad F_r(b)\le(r+s)v_{s+1}(b).
]
取 (s=r-1) 得既有背景利润对象中的 (F_r(b)\le(2r-1)v_r(b))。源的新增价值是把余项写成逐客户完全精确的 (
ho)，并显式处理 (d=0,b=0) 及 (s=0) 端点。

# 与已有正文的核对

这与 `state/定理/背景剩余利润的分数门槛与同人数信用恒等式--定理.md` 的正余项
([d(d-1)+bL]/[(b+d)(b+1+L)]) 同一公式；本审查补充了任意 (r,s) 的联合记账和退化端点清单。它不新增动态支付定理，也不改变已有“比较负载余项不能免费跨真实子树望远镜”的边界。

当 (d) 取真实尾部负载时，余项包含真实背景份额；但此时左边只是给定真实尾部利润，不再是 (F_r(b)) 的最优比较。若 (d=d^*) 是最优比较负载，余项属于比较终局，不能换成原 SPE 的实际收益。不同真实分支若使用不同 (d^*,Q^*)，也不能直接相加成共同预算。

源逐项核对了 (d=0)、(d=1)、(b=0)、(L=0)、空主题、重复主题、零客户和 (s=0)；这些边界均保持分母正、零分子项取零。结果不使用 SPE 理性，因此适用于静态目录比较，但不能单独证明 Q-CAG-HALF-6。

## 证据与接续

源码原件与本审查的独立副本位于 `archives/customer-attraction/tools/evidence/r3d253-fixed-background-static-security-Boss8/`。后续若要接到动态结果，必须另证背景来自同一合法前缀、比较元组和实际子局之间的共同量词；不能把这个静态恒等式当作全树支付或六人 half 证明。
