# 来源身份与候选命题

主源 `5a27ad2a0e248e298382` 是 4,360 字节的 README，SHA-256 为 `2cbc9683978f466007ae75bf1ff62673c4ec8d82a25099ace916147d01363436`。它不是一个新的定理证明，而是对 `next_counterexample` 工作台的路线说明。README 明确把一般 Q-CAG-HALF 目标保留为 OPEN，并区分两个辅助候选：

- C1：对任意完整历史纯 SPE、任意 `i<m`，有 `2u_i ≥ u_m`；
- C2：聚合形式 `2W ≥ (m+1)u_m`。

README 还说明 C1 蕴含 C2，但任一候选即使成立，也不能单独推出六人半覆盖，因为与既有末位税式结合后，`m>3` 的系数仍不足以把福利压到二分之一。量词包括任意有限共同目录、单位客户整数重数、任意人数、每一份完整有序历史和全部离轨平局；不能以一条实际路径或友善平局替代这些量词。

# 已确定的数学状态

README 引用的七客户、三人四主题完整 SPE 反例已在结果仓库既有反例对象中自足保存。该实例收益为 `(3/2,2,7/2)`，因此 `2u_1-u_3=-1/2`，严格否定 C1；同时 `W=OPT=7`、`2W-(m+1)u_m=0`，所以它没有否定 C2，也不是半覆盖反例。README 另给出任意人数的两个不交主题等号族，说明 C1/C2 若成立时其常数不能直接改进，但该族达到 `W=OPT`，同样不触及主目标的下界。

README 的倒二人分支推导只证明 `i=m-1` 的二倍关系：把倒二人的偏离与末位任意回复逐客户比较，得到偏离收益至少为原末位收益一半，再用 SPE 最优性收回 `u_{m-1}≥u_m/2`。同一分母比较不能自动推广到更早位置；更早位置的可靠结论仍是调和型界，不能把 C1 当作已证桥。

# 相关搜索器的实际语义

我导出并阅读 README 所引用的四个搜索器及两份最佳 JSON，确认它们都是有限浮点侦察：

1. `search_terminal.py` 和 `search_clone_half.py` 枚举有限计数状态，做后向 floor 筛选并保存终局集合；它们用随机客户重数和固定步数寻找收益比，必须另做 ExactSPESolver/整数审计才能称反例。
2. `cone_attack.py` 对一份固定完整 SPE 策略，将每个真实历史的收益差组成客户质量锥，线性规划最大化早期玩家相对末位的 C1 缺口。代码只随机采样策略锥，数值 `lp_weights` 和目标值不能代替全锥枚举或有理对偶证书。
3. `cone_walk.py` 在 LP 极点与离轨平局边界之间随机回注策略，试图跨策略锥寻找半覆盖坏点；它仍是探索器，输出不自动给出合法完整 SPE。
4. `clone_best_5_5.json` 记录 `n=5,m=5` 第 3581 次的 `bridge_violation_ratio=0.8610389610389609`、`half_ratio=1.1373056994818653`；`clone_best_7_5.json` 记录 `n=7,m=5` 第 6714 次的 `bridge_violation_ratio=0.9921259842519685`、`half_ratio=1.049738219895288`。两者都是已采样权重下的最好点，不是穷尽最优值；半比值仍高于一，只能说明该有限样本未找到坏点。

README 还引用 `terminal_clone_equality_audit.py/json` 作为有限 Fraction 回归。既有清洗对象已说明该审计核对七客户 C1 反例的全部 21 个决策节点和 84 项含自身比较；其身份是有限复核，不是对所有策略图的新盲审或外审。本页把这些对象作为比较证据，不重复登记为新的主来源。

# 可复用边界与接续

可复用的工作接口是：先把固定完整策略的所有历史偏离写成客户质量锥，再对每个给定终局检查 C1/C2 目标；若 LP 找到正值，必须把客户质量有理化、清分母为单位客户，并用独立 ExactSPESolver 逐历史验证完整 SPE。边界平局必须保留，不能只选一个“友善”后继。

下一步应集中攻击尚未解决的 C2，或证明 C2 与跨枝支付项的必要补充；同时继续用 `cone_walk` 的边界行走检查七主题五人主目标。不能把“未找到 C1 反例”的有限随机记录写成 C1 证明，也不能把 C1 的既有反例升级成 Q-CAG-HALF-6 反例。相关原量词、目录非空条件和六人完整历史身份都保持独立。
