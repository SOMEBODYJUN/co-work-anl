## 指定重复尾模板的准确障碍

源文考虑单一公共奖金 `Q/B` 构造的任意尾长障碍。若实际尾部把同一 `D` 重复 `r` 次，一次 fresh `A_i` 偏离的真实尾部又预定为 `B_i` 重复 `r` 次，则在 `r>=2` 时，只比较末位的两个真实菜单就得到矛盾：实际路径要求 `d >= r c/2`，离轨路径要求 `d <= c/(r+1)`。这排除的是“同一 D 重复、同一 B 重复、由两末位菜单承担惩罚”的统一模板，未排除一般多层构造或带跨主题状态的 payment。

源文进一步指出：若最优主题对应的漏失块在真实偏离续局中仍无人覆盖，漏失客户块大小会直接进入该玩家的实际收益支付；只把 `X_i` 块份额从 `1/2` 调成 `1/(r+1)` 不足以越过 half。若要绕过障碍，多层公共奖金必须同时支付后继 fresh `A_j` 菜单并抑制早期 fresh `B_i` 偏离，单一大公共奖金不能免费完成两项。

这是对指定模板的解析否定，不是 Q-CAG-HALF 的一般反例。与现有“末位收益不可按人数均摊的全历史不交族”及“前缀耦合席位与尾水位边界增量审计”对照，该 README 只保留同一尾部重复模板的最小两菜单冲突，不重复更大反例、完整路径策略或精确程序证书。
