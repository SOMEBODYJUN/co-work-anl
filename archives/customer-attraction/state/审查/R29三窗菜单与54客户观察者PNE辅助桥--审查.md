# R29 三窗菜单与 54 客户观察者 PNE 辅助桥

## 1. 三窗环：局部收益算术但不是完整 SPE

环上每个客户 `e_i` 喜欢连续三窗 `A_i={e_{i-1},e_i,e_{i+1}}`，环长至少 9，玩家数为 3。固定根菜单 `(A_i,A_{i-1},A_{i+1})` 的前三窗并集覆盖五名客户，负载为 `(1,2,3,2,1)`，所以根收益为

\[
 u_{root}=1/2+1/3+1/2=4/3,
 \qquad u_{tail}=1+1/2+1/3=11/6.
\]

三个不交三窗达到 `OPT_3=9`，故门槛 `OPT_3/(2·3)=3/2`。根低于门槛，两个尾收益高于门槛；但第三位可以选择与前两窗不交的远窗，收益为 3，严格增益 `3-11/6=7/6`。因此这份菜单不是完整纯 SPE，且实际福利只有 `W=5`，仍满足 `2W≥OPT_3`。文本还给出 m≥4 的远窗 suffix 机制，但明确指出第二、三位的真实 IC 尚未闭合；它是障碍来源和边界记录，不是一般反例。

## 2. 54 客户观察者 PNE 辅助桥

脚本固定旧玩家主题 `A=1`，有六个主题和 54 个单位客户，类型掩码及重数完整保存在 JSON。对两个顺序尾玩家，脚本先计算每个第一尾动作的唯一最佳末位回复，然后检查一个辅助命题：每份固定旧玩家、每个尾 SPE 是否存在某个静态尾 PNE，使旧玩家收益不高于原尾 SPE。

实际输出为：

| 项目 | 精确值 |
|---|---|
| 固定旧主题 | 1 |
| 尾动作的最佳回复 | `[1,5,5,5,5,2]` |
| 第一尾动作的真实偏离收益 | `53/3,14,15,10,25/2,17` |
| 选定尾 `[0,1]` 的旧/第一/第二收益 | `(44/3,53/3,44/3)` |
| 静态尾 PNE | `[2,5]` 与 `[5,2]` |
| 静态 PNE 的旧玩家收益 | 21（两者均） |

脚本断言 `[0,1]` 的第一尾动作是最优动作，且 `[2,5]`、`[5,2]` 是全部静态尾 PNE。旧玩家在选定尾 SPE 的收益为 `44/3`，而所有静态尾 PNE 都给旧玩家 21，故该辅助桥命题为假。脚本实际运行 exit 0，生成 JSON 与冻结 JSON 字节一致。

## 3. 量词和用途边界

这个 54 客户对象固定了一个旧玩家主题和一个两人尾子局；它没有证明该固定过去来自原三人根纯 SPE，也没有构造完整根策略、客户福利比率或六人终局。它只否定“可观察静态尾 PNE 总能弱降旧玩家收益”的辅助替换桥。三窗环同样没有完整 SPE，不能用作 DIRECT/PREFIX 或 half 的反例。

与 R29 固定完整 SPE 锥的 15 源复核相比，本对象提供的是一个精确文本局部障碍和一个全枚举尾 PNE 辅助反例；两者都保留真实有序历史/根路径缺口。后来银行族承担完整根纯 SPE 的逐人门槛反驳，本对象不重复代替它。

## 4. 接续

若继续利用三窗环，必须先给第二、三位在所有前缀下的真实偏离约束，再构造完整策略；若继续利用观察者 PNE 结果，必须把固定尾收益接回同一根策略和客户支付预算。当前可安全复用的内容是精确收益、PNE 枚举和失败的辅助桥，不能把它们升级成六人 Q-CAG-HALF 结论。
