# 1. 本批来源和读取方式

本批完整实读两个冻结 JSON。原始字节、SHA-256 和来源路径保存在 `tools/evidence/cag-20261023-20261030/manifest.json`；两个来源在 legacy-cleanup 与 main 快照中的内容相同。没有把文件摘要当作证明：前缀源的 31 个动作记录、3 个逐位置水位行和全部嵌套字段逐项读取；水位源的 16 个 `rational_cases`、每例的 steps/query 计数、以及 `irrational_case` 的有理夹逼全部读取。

# 2. `customer_attraction_prefix_coupled_seats.json`：独立三人完整 SPE 与前缀耦合量

源的 scope 明确是 `independent finite numerical/definition audit; not a re-audit of the arbitrary-m proof`，source 是 `examples/customer_attraction/prefix_coupled_seats_strict.json`，且 `strategy_status` 明确写出“source JSON contains no strategy; independently completed one full SPE realizing its path”。因此它不是对源文件中不存在的策略做字段复核，而是独立补全了一个实现路径并验证其全历史最优性。

## 2.1 定义域、完整树与实际终局

实例有 124 个单位客户、5 个不同主题、3 个提供者。独立策略覆盖 31 个有序决策历史，含自身比较 155 项，非自身偏离 124 项；最小 slack 为 0，严格比较 121 项，平局 34 项。实际路径为
\[
(0,4,2),\qquad (u_1,u_2,u_3)=(37,30,28),\qquad W=95.
\]
最优覆盖见证是 `(0,1,2)`，给出 `OPT=100`。这说明实际终局福利距离最优覆盖 5 个单位，但 SPE 认证仍允许弱最佳回应和平局，不能称严格 SPE。

31 条 `actions` 记录逐历史保存：根动作是 0，第一位偏离历史 `[0]` 的后继动作是 4，另有 `[1]`、`[2]`、`[3]`、`[4]` 的五个单步后继；长度二历史共 25 条。该表覆盖全部有序历史，独立审计不只沿实际路径计算。

## 2.2 极大主题、私有质量和席位行

五个主题都被标记为 maximal。`private_sizes` 为

\]

## 2.3 与既有对象的关系

该文件与已有 `分数尾水位的共同查询信用与利润守恒` 不同：前缀源的三人策略是独立补全的真实单位玩家 SPE，而水位引理只对给定终局的辅助权重做静态负载代数，不自动产生新的 SPE。前缀源本身没有 arbitrary-m proof，也没有给出跨所有策略的客户主题覆盖结论。其独有内容是 31 历史、124 偏离、5 主题私有质量以及新旧席位和的精确比较；本批保留这些数据，不重复创建一个“六人 half” claim。

`mixed_private_irrational_stop` 的根方程是
\[

\]

\[
2^{-100}=1/1267650600228229401496703205376
\]
的严格有理区间给出
\[
\rho\in[896364335596578238699711011639/2^{100},
112045541949572279837463876455/158456325028528675187087900672],
\]
其中上下界按源文件原字符串保留；`common_gain_upper` 为
`371286264631651162796992193737/2164014935824807640196414217015`。它证明的是边界回归和夹逼处理，不是有理输出算法。

# 4. 量词、证据等级和处置

1. 前缀耦合席位：一个独立三人、124 客户、5 主题的完整有限 SPE 和席位聚合差异；`W=95<OPT=100` 是该实例事实，不能解释成一般 half 反例。它没有自带原策略，因此独立补全策略的行为和 source JSON 的“席位”数据需分开保存。
2. 水位回归：16 个有理例和一个无理夹逼支持既有共同信用引理的边界（同一客户池、根/背景返还、零端点与无理停点）；不自动保持真实策略的 SPE，不能从 `pass` 升级到全局福利或六人 half。
3. 与已有 fractional-load 正文：本批水位记录与 `分数尾水位的共同查询信用与利润守恒--引理.md` 互补；解析引理提供任意有限客户集、背景、根、尾与阈值的普遍构造，而本 JSON 只回归 16 个有理边界和一个无理停点。与 `分数负载四主题族的全历史核验--计算.md` 的四人完整策略证书也保持分开。
4. 本批没有反例、没有 general proof、没有 FPTAS/算法结论；保留为“完整有限 SPE + 静态水位边界”的增量审计。

# 5. 第三阶段接续
