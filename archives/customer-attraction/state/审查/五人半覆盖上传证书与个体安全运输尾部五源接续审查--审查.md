# 3. `compressed_34.json`：逐人安全失败而非福利反例

## 3.1 完整实读的模型与策略

该 JSON 的 `claim` 为“individual mixed-security bridge failure, integer compression”，`scope` 明确禁止把它读成 aggregate BR 或 half-coverage 反例。它含 3 人、6 主题 `X0,X1,X2,Y0,Y1,Y2`、13 个不重复客户类型，总单位客户数 34。`terminal_counts=[1,0,0,1,1,0]`，43 个完整有序历史 action（空历史、6 个深度 1、36 个深度 2）；首条路径为 `(0,3,4)`。

我逐字段读取了 13 个类型的主题集合和重数、43 条动作、primary/dual 安全分布、优化压缩字段。独立 Fraction 重放使用所有 216 个终局、258 个含自行动作比较和 36 个有序静态 rival 背景，不导入作者求解器。

## 3.2 精确结果与量词

重放得到：

\[
(u_1,u_2,u_3)=\left(\frac{29}{3},\frac{67}{6},\frac{67}{6}\right),
\quad W=32,
\quad \operatorname{OPT}=34,
\quad 2W-\operatorname{OPT}=30.
\]

所有 SPE 比较 slack 均非负；215 个非平凡偏离中 144 个严格输、71 个平局。给定 primary 与 dual 的最小/最大精确值均为

\[
v=\frac{2411}{246},
\]

且 6 个主题的 dual 查询全绑定。首位个体安全差为

\[
\frac{29}{3}-\frac{2411}{246}=-\frac{11}{82}<0,
\]

而 aggregate/half 量词仍为正：

\[
W-3v=\frac{213}{82}>0,
\qquad W-\operatorname{OPT}/2=15.
\]

因此该源确实是一个完整三人 SPE 上的**逐人混合安全值失败**，不是福利反例、不是半覆盖反例，也不提供全局最小性。`compression.fixed_source_p_strict_gap=13/681` 只是压缩 MILP 的源严格间隙；`objective=34`、`mip_gap=0`、`dual_bound≈34` 只证明该有限优化运行找到了 34 的候选，不证明所有候选中 34 全局最小。已有 `三人逐人混合安全值--反例.md` 已承载该数学对象，本批将该新冻结 ID 作为同一对象的独立原始输入和 Fraction 重放证据。

# 4. `discovery_360.json`：放大候选的独立边界

## 4.1 输入与 exact 重放

该 JSON 的 `claim` 为“candidate individual safety bridge failure”，scope 同样写明没有 aggregate BR 或 half-coverage counterexample。它有 3 人、6 主题、19 个客户类型，重数总和 360；策略表与 34 客户候选相同（43 节点、终局 `(0,3,4)`、相同终端计数）。我读取所有 19 个主题集合及重数、43 actions、primary/dual 和 `source_normalized_gap=187/108960`、`integer_scale=360`。

独立 Fraction 重放检查 216 终局、258 比较（215 非平凡、51 个平局）及 36 个有序静态背景，得到：

\[
(u_1,u_2,u_3)=(102,117,117),\quad W=336,
\quad \operatorname{OPT}=360,
\quad 2W-\operatorname{OPT}=312,
\]

并有

\[
\min_B E_p[f_B(a)]=\max_a E_Q[f_B(a)]=\frac{93177}{908}.

首位安全差为

\[
102-\frac{93177}{908}=-\frac{561}{908}<0,

# 5. `common_q_generator.py`：固定策略锥的候选算法，运行边界明确

## 5.1 源码结构

该 412 行脚本可编译为 Python 字节码，顶层对象为 `Space` 类、`grouped_seeds`、`rule_policy`、`main`、`common_q` 和 `batch`。它把：

1. 有序历史集合、客户主题掩码、终局类型、完整 policy 的逐动作 `Gamma` 行；
2. 静态 rival backgrounds `B`、静态支付矩阵和固定策略锥；
3. `linprog` 浮点安全值/半覆盖探索；
4. `Fraction` 精确行消元、有理点恢复、非负 residual 验证；
5. `common_q` 中“同一 Q 作用于所有 query、每个 query 独立 Gamma λ”的共同 Q LP；
6. `freeze` 将固定策略锥候选输出为压缩客户 JSON；

串在一个文件中。`common_q` 变量为 `Q_B` 与每个查询/每条 Gamma 行的 `lambda`，等式 `sum Q=1`，不等式逐主题逐客户类型；`exact_certified` 只在有理恢复后逐坐标 residual 非负时设为真。`batch` 还把 policy candidate 交给 `policy_patterns.candidates()`，并写 `cone_batch_results.json`、`new_cone_certificate_pack.json` 或 `unresolved_*.json`。

## 5.2 依赖和实际执行边界

脚本在缺少同目录 `policy_patterns.py` 时，即使传入 `--help` 也在顶层 import 阶段失败：

```text
ModuleNotFoundError: No module named 'policy_patterns'
```

因此仅凭本冻结源不能重建完整 batch；本批不把源代码历史摘要写成成功运行。仓库已有相邻 `archives/customer-attraction/tools/evidence/transport-round-obstacle-20261031/policy_patterns.py`，我以该版本补齐 `PYTHONPATH` 做了依赖范围试跑。使用绝对 replay 目录后，完整 `batch()` 成功处理 21 棵指定策略锥：总 Gamma 行 79149，五人七主题坐标行 889、五人/六人八主题坐标行 2040，所有 21 棵均 `feasible=true`、`exact_certified=true`、`Gamma_scale=60`；`cone_batch_results.json` 和 21 个 case 的 `new_cone_certificate_pack.json` 保存在 `transport-tail-common-q-20261031/replay/`，`run_metadata.json` 记录命令、依赖副本和 SHA。最初用相对 output 路径的试跑在写回时出现路径错误，已改用绝对路径重跑；该失败不影响最终 21 棵输出。

即使全部 batch 顺利结束，源码的数学量词仍是“指定完整 policy cones only”：`full_policy` 构造一棵固定 policy 的全部历史 Gamma 行，`common_q` 只为该锥寻找 Q/λ，`cone_half` 只遍历固定 cone 的有限 portfolio。它没有对任意完整 SPE、任意共同目录或六人目标作全称枚举。`exact_certified` 是有限候选证书的后验检查，不是普遍定理；LP 浮点搜索、有限 seed 和 `policy_patterns` 规则也不替代均衡数学证明。

已有 `共同静态Q证书生成器--计算.md` 审查了另一历史版本的共同 Q 接口；本源新增了可执行 `Space`/Gamma/half/candidate 管线和依赖阻塞信息，但语义边界相同：固定策略锥上的条件证书，不能连成六人半覆盖结论。

# 6. `two_three_tail_check.json`：指定路径的严格后继障碍

该 JSON 为 `status=PASS`，75 个单位客户、5 人、10 主题，目标路径 `[3,4,5,6,7]`，第四人历史 `[3,4,5]`，实际第四人收益 `151/10`。强制第四人偏离到动作 0 后，最后两人的全部 best replies 为 1、2；在这两个回复下第四人收益均为 `303/20`。故可信偏离收益下界为

\[
\frac{303}{20}=15.15,
\qquad
\frac{303}{20}-\frac{151}{10}=\frac1{20}>0.

`last_payoffs_after_deviation` 的 10 个主题向量逐项保留；第 0/3/4 组为 `143/10`，第 1/2 组为 `303/20`，第 5 组为 `69/5`，第 6--9 组为 `297/20`。该证书只覆盖“bare 25 omitted-pair populations”及这个指定四人前缀，结论是该路径在任何完整 SPE 中都不能成立。它不是对所有五人策略的反例、也不是当前六人 half 反例；它应接到 `末两人回复循环静态运输恒等式--定理.md` 和既有 transport-round 局部障碍，作为一条严格 deviation witness。
