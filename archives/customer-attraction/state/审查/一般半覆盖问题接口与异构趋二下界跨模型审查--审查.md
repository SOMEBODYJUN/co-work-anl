# 一般半覆盖问题接口与异构趋二下界跨模型审查

## 2. Q-CAG-HALF 的精确命题与共同支付接口

`customer_attraction_half_coverage.md` 明确目标：有限单位客户、有限非空共同主题目录、任意提供者数 `m`，提供者按固定顺序观察全部有序历史各选主题，客户价值在最终覆盖者之间均分。对**任意完整历史依赖纯 SPE**，根终局福利 `W` 应满足

\[
2W\ge \operatorname{OPT}_m,
\qquad
\operatorname{OPT}_m=max_{(T_1,\ldots,T_m)}|\cup_iT_i|.
\]

空主题、重复选择、零客户、任意离轨平局和所有有序历史均保留；不允许把离轨后继冻结成原路径，也不把 SPE 终局当静态 NE。文档引用 Deng 等 arXiv:2307.07174v2：两人有 `3/2` 结果，一般人数有趋近 2 的下界，§6 把超过两人的常数二上界写成猜想。目标状态仍为 OPEN。

`customer_attraction_general_handoff.md` 给出一条可替换的完整形式接口。固定完整策略 `sigma` 和比较主题 `T_1,...,T_m`，令 `Gamma` 行记录每个真实有序历史的原行动收益减去真实偏离后沿同一策略的收益，`c` 为实际覆盖系数，`o` 为比较主题并集系数。若能对每个完整策略和比较元组构造

\[
2c-o=\Gamma^{\mathsf T}\lambda+r,
\qquad \lambda\ge0,\ r\ge0,
\]

则与客户重数相乘便得 `2W >= |union T_i|`。文档明确这只是待证证书合同，不能循环引用 half 目标或形式 Farkas 语言宣称证书存在。

它还保留静态安全值候选：固定背景 `b` 和剩余人数 `r`，定义不观察查询抽样的 `v_r(b)`；已证 `v_m(0)>=OPT_m/(2m-1)`，所以 `W >= (m-1/2)v_m(0)` 足以推出 half。这是可替换候选桥，不是定理；逐人 `u_i>=v_m(0)` 已被完整 SPE 反例否定。文档强调真实离轨分支的后继可改变，固定早期乘子提升已由 52 客户反例击穿，但这不等于聚合安全桥不可能。

## 3. 异构两设施六顶点下界的精确内容

`tight_two_lower.md` 研究两家带标签设施各有两个**不同**允许位置，六名正有理客户，客户在覆盖后必须选一家可达设施，成本为含自身重量的实现总负载。设施目录不相交，允许跨对每格有两名共同客户；这是双设施同时选址模型，与 CAG 的顺序单位提供者模型完全不同。

给 `0<epsilon<1/4`，位置覆盖为

\[
C_A=\{x,y,z\},\quad C_B=\{x,y,t,b\},\quad
C_C=\{x,z,t,c\},\quad C_D=\{y,z,t\},
\]

设施 1 可选 `{A,B}`，设施 2 可选 `{C,D}`；四个合法布局的共同客户分别是 AC: `x,z`、AD: `y,z`、BC: `x,t`、BD: `y,t`，每格恰两名。客户严格占优逐次固定，四格的唯一 NE、CE 和 CCE 都是纯的。收益表为

\[
\begin{array}{c|cc}
 & C&D\\\hline
A&(1+9\epsilon,2+8\epsilon)&(2+8\epsilon,1+3\epsilon)\\
B&(2+13\epsilon,1+14\epsilon)&(1+11\epsilon,2+10\epsilon).
\end{array}
\]

改善环 `AC -> BC -> BD -> AD -> AC` 的最小改善比是

\[
\alpha^*(\epsilon)=\frac{2+10\epsilon}{1+14\epsilon}
=2-\frac{18\epsilon}{1+14\epsilon}.
\]

选任意正有理 `epsilon` 足够小，即排除所有 `alpha<2` 的完整设施 SPE；CE/CCE 也不能通过改变唯一续局挽救。`epsilon=1/1000` 清分母后得到 `(1000,1,1008,1002,10,6)` 和精确倍率 `335/169`。一般整数 `M>4` 的权重 `(M,1,M+8,M+2,10,6)` 给 `(2M+10)/(M+14)` 趋近 2。

该下界与现有 `facility-games/state/定理/异构双目录六顶点的唯一续局因子二下界` 是同一数学对象；本源独有的逐客户严格占优解释、CE/CCE 唯一性和任意严格递增同客户成本函数稳健性均已在该对象和成本扩展审查中保留。它不证明异构双设施上界 2，也不对 CAG half 目标提供反例或上界。

## 4. 跨模型关系与禁止的推导

| 主题 | Q-CAG-HALF | 异构双设施下界 |
| --- | --- | --- |
| 行动顺序 | 多个单位提供者依次选主题，完整历史可依赖平局 | 两家设施同时选带标签位置 |
| 客户价值/成本 | 单位客户价值，终局在覆盖者间均分 | 正权客户，成本为实现总负载，设施最大化服务重量 |
| 目标 | 每份完整纯 SPE 福利至少 `OPT/2` | 设施偏离倍率近似因子，证明统一上界至少 2 |
| 证据 | 真实离轨 Gamma 行、完整历史策略锥 | 四格唯一 NE/CE/CCE 和改善环 |

因此不能从六顶点异构下界推出 CAG 六人 half 反例，也不能把 CAG 的共同支付接口移植成双设施负载倍率证明。两种模型均出现“任意平局/完整离轨”字样，但量词对象不同：CAG 需要每个有序历史纯策略，双设施需要每个带标签布局一个客户 NE 续局。
