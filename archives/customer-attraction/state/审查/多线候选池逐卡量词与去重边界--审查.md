# 对象身份与阅读范围

该对象是 `history/retired_topic_selection/multi_lane/research/topic_selection/candidate_pool.json` 的语义审查，不是把候选卡改写成定理。冻结文件在 `legacy-cleanup` 提交 `68fad804ec5946cb296f77dc5b336308a66abf12` 与 `main` 提交 `aefc58eac3fc6eb5d7a47d087dd2c62b5aa9974c` 均有定位；`clean show` 导出字节数为 85,125，SHA-256 与 frontmatter 一致，JSON 顶层为 59 个对象。本文逐对象解析了所有字段，并将卡片中出现的结果文件、母文和后续审查与仓库现有正文对照。

候选池是历史选题索引：`origin=A` 表示卡片标作作者明确问题，`B` 表示作者建议方向，`C` 表示团队派生限制或扩类。这个标签不证明当前仍开放，也不证明新颖。`status` 是当时研究流程状态，不是数学真值：`probe` 是应立即做硬检查的试攻，`reserve` 是储备方向，`needs_verification` 是缺文献/量词/反例核验，`exclude` 是淘汰、合并或已由已有接口覆盖的记录。

本文采用四种数学证据标签来防止过度升级：

- **候选**：卡片的 `exact_question`、`minimal_target` 和 `known_overlap` 描述待研究问题及最低成果，不构成结论。
- **完整证明/条件结论**：仅在仓库已有独立正文或证书明确承重时引用，并保留其输入范围；candidate_pool 本身没有把这些结果写成已证。
- **有限实验/审计**：保留脚本、JSON、枚举规模和复现入口；有限样本不外推到全参数。
- **障碍/淘汰/反例**：记录卡片所指的失败机制或已覆盖接口；它只关闭相应量词，不能顺势否定更窄或更宽的其他模型。
