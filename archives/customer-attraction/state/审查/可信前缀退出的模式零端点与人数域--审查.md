# 五个实质义务逐一保留

1. **同根低出口和永久模式。** 最初Y出口最终Y总d次；fresh F出口最终F两次、其他银行各一次、Y共d−1。任意clean出口当前收益cap s，与以后怎么BI补全无关；该出口后永久退出clean，在各坐标选真正完整BI子树。不能后来计数恰巧重合就重返clean，模式取决首次异常有序历史。
2. **d1端点。** fresh F出口Y cap0，规定Y阶段不存在；最后复制F与改Y都收益s。d≥2时正常Y收益ds/(d−1)∈[s,2s]。不能用含d−1分母的中间式冒d1已覆盖。
3. **正常后缀全历史。** 正常银行前缀后的永久Y策略使Y最终负载≤d，故规定Y至少s，任一银行/叶偏离至多s。它不是只actual尾，离轨子博弈也必须合法。
4. **首次联合动作偏离。** 对所有(A,T)，不是只逐坐标偏离，旧坐标贴真正达到ell_i(A)的完整孩子，银行坐标贴对应低续局；当前偏离≤ell_i(A)+s≤u_i(z)+2s。其后两坐标永久独立按本坐标的**有序历史**读策略，任何联合收益差是两个非正真实差之和；不把一个坏坐标冻结成normal continuation。原旧主题A_i+异常银行也在量词内。
5. **OPT相加、共同清分母和Δ0。** 两客户宇宙不交/实际完整Cartesian目录使福利与OPT逐坐标相加，旧/新增客户须一起复制清分母，不能只把bank整数化。Δ0用真正孩子SPE达到floor在每个正常节点向前拼，使原目标实现；不造零银行或取含0/0的极限。
