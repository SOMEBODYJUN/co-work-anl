# R-171 可信低根接续与有限候选边界

## 1. README 的量词与已知种子

冻结 README 共 2,095 B，SHA-256 `17dacad4de0cb2f6e058163c5cc09e355a70ad60d630fb923990f3820ad6006b`，稳定 ID `f9e2f6cfcb88db161bc1`，blob `d8fc7f99ffb21716dc36cface209b0cba2b513a8`。它重申原 CAG-MODEL：有限单位客户、有限非空共同目录、任意人数、全部有序历史纯 SPE 与任意离轨平局；并明确“没有新增一般证明、主目标反例或承重辅助结论”。

已知低根种子来自旧三人 23 客户收益不平衡例，再加两个各含 10 客户的独立主题。五人、七主题的目标根计数为 `(1,1,1,0,0,1,1)`，可实现根收益 5，最终福利和最优覆盖均为 43。README 把它作为接续起点，而不是独立 padding 定理或本轮新结果。

`low_root_discovery.py` 从真实全集 SPE 终局菜单抽取完整有序策略，再在固定策略锥内优化非负整数客户重数；额外加入 (u_1/W\le5/43) 的低根约束。浮点 LP 只生成候选，接受端点要做有理恢复、全部真实比较行检查、规范证书和独立 Fraction 全历史验证。相同计数历史不被强迫共用同一续局。

README 记录的默认 seed `319221`、8 棵完整策略和每棵 21 个五主题比较组合，接受 168 个精确原始点，仍只有 `OPT/W=1`。本轮用冻结依赖做 `--steps 1` 重放，得到 21 个 accepted endpoints、`W=43`、`OPT=43`、ratio 1，与种子边界一致；这不是对 README 所述完整 8 步的替代重放。

## 2. 相关脚本的角色分层

- **可信低根发现。** 目标是寻找同一低根约束下的可验证端点；没有全策略枚举，也没有声称存在或不存在任意低根反例。
- **count-Markov MILP。** `count_milp.py` 只在按计数状态共享动作的候选子类中优化；随后把动作展开到所有有序历史并用完整策略锥/独立验证器检查。它不是所有完整历史 SPE 的 MILP 表示，更不是复杂度或下界证明。
- **minimum-root。** 固定 p=7,m=5 和一个目标终局，随机选择 credible continuation 菜单，在线性锥中最小化首位玩家份额；每个接受端点仍须 Fraction 恢复、整数克隆、规范证书与独立全历史检查。它研究“低根候选”，不直接最大化 OPT/W。
- **finite_attempt_summary.json。** 这是三组 credible walk 与四组 count-Markov MILP 结果的冻结摘要；它把固定策略/有限运行的比率、超时和 infeasible 状态分开记录，不能将 JSON 字段当作普遍命题。

## 3. 对已有 R-171 对象的比较

`R-171接续工作区主张边界与开放义务--审查` 已把 credible、稀疏租金、遗漏和早期激励路线分开：固定策略的正 half 余量、低根探索和局部动态预算都没有关闭任意人数 Q-CAG-HALF。当前 README 与近期 R-171 coupling、dynamic-credit、direct-cover 页面一致地保留“候选生成 ≠ 全策略量词”。

如果有限摘要出现 `OPT/W>1`，它只说明某个已验证完整策略端点的福利低于其整数最优覆盖。要成为原目标反例还需 (OPT/W>2)，并且策略、所有离轨历史、平局和客户输入都必须完整可复核。摘要中的最高 credible-walk 比率为 `171/100`，最高 count-Markov 小实例为 `3/2`，都没有达到 2；p=7 的大型 MILP 还包含 time limit 和 infeasible 结果，不能读成统一否定。

## 4. 处置与未覆盖边界

本 README 作为 integrated 审查/路线页保留。独有内容是低根种子、可信续局验证义务、count-Markov 子类边界和后续必须寻找真正新机制的路线判断。它没有产生：

- 任意目录、任意人数的低根存在/不存在定理；
- `2W<OPT` 的完整策略反例；
- 一般算法、MILP 下界、hardness 或 unrelated-machines 结论。

摘要、候选脚本和 finite replay 各自按证据层级保存；不能通过重复同一固定策略、扩大阴性步数或重跑同一 count-Markov 子类来冒领新的承重信息。
