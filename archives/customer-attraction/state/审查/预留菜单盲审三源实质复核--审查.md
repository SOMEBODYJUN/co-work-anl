# 预留菜单盲审三源实质复核

三份主源全文为2738B结果JSON、4857B审查稿、5437B标准库程序，共13032B。其独有内容是对**给定**四人完整策略及静态有理鞍点的另一份定义级实现和报告；53客户反例本身已有[构造](../构造/五十三单位四人完整策略与内生水位基准--构造.md)、[静态鞍点](../计算/五十三单位静态安全值的有理鞍点--计算.md)和[出处资源](../资源/正深度静态安全地板反例的单位数据与审查出处--资源.md)，本页不再授予一个新反例身份。

本轮另完整读取真实1549B游戏及43258B证书，包括400个动作和全部非动作字段。五份原件逐项核size、SHA256、Git blob等于冻结清点；两冻结提交的每项主源字节相同。[证据包](../../tools/evidence/boss6-reservation-review/README.md)保存五原件、双冻结定位、400动作可逆视图及纯数据自查。当前没有执行原入口、收益/IC/OPT重算、静态枚举、LP或新游戏搜索。以下区分原报告、代码逻辑和已有充分数学证据，不把取源成功或字段齐全当成数学验证。

## 1. 被否定的量词及模型身份

采用[共同目录完整历史模型](../定义/共同目录完整历史模型--定义.md)：有限单位客户集N、有限非空共同目录𝒮，m名单位提供者观察全部有序历史依次选主题，允许重复；终局z中每名覆盖者从客户x获得1/cₓ(z)。策略在每个合法历史上给出动作，SPE比较一个偏离时必须沿该动作后**同一策略的真实后继**完成，任意平局和离轨历史均保留。

定义原空根、原总人数的真正静态安全值

\[
v_m(0)=\max_{p\in\Delta(\mathcal S)}\min_{B\in\mathcal S^{m-1}}
\sum_{T\in\mathcal S}p_T\sum_{x\in T}\frac1{1+c_x(B)}.
\]

竞争元组在查询抽样实现之前确定，可以任意相关；不是所有竞争者均从p独立抽样。下标m含查询本人，另外仅m−1个槽；也不是extra-one值v₍ₘ₊₁₎，不是到达历史h后的剩余人数值vᵣ(b)。被反的命题为

\[
\forall(N,\mathcal S,m)\ \forall\text{完整纯SPE }\sigma\ \forall i\in\{2,\ldots,m\}:\quad
u_i(z(\sigma))\ge v_m(0).
\tag{PD}
\]

固定见证在实际正深度前缀(B)的第二人即失败，故无需在离轨节点寻找违例。本页只证明一个策略足以否定(PD)，不声称该游戏所有SPE都如此。

一般模型保留空主题、零客户、重复选择以及所有离轨平局；本具体输入恰有七个两两不同的非空主题、53名客户，不据此删除一般域中的退化情形。客户重数展开为不同单位客户，不是加权玩家、主动客户设施模型或分数背景模型。四人辅助桥审查归父档；[恰六人半覆盖](../../subarchives/six-providers/问题--问题.md)仍要求每份六人完整纯SPE满足2W≥OPT₆，本见证不改变人数或目标身份。

## 2. 两个真实输入和独立实现的边界

原程序只导入`fractions`、`itertools`、`pathlib`、`json`。输入仅为相邻`../security/positive_depth_floor_game.json`和`../security/positive_depth_floor_certificate.json`；不导入规范模型、SPE求解器、发现器、作者审计或优化库。给定完整策略和有理分布仍是外部输入，故这是独立**核验实现**，不是独立发现或独立构造策略。

主题0…6为X0,X1,X2,Y0,Y1,Y2,B。客户按兴趣位mask压缩，全部类型与重数是

`4:1,27:4,29:3,30:3,31:2,32:1,43:3,45:3,46:3,51:3,53:3,54:3,59:2,64:19`。

程序将每行正整数重数逐客户展开；最后19名仅喜欢B，且与前34名旧客户不交。它核四人七主题、总数53、覆盖集合两两不同及B块不交。冻结实际JSON的主题索引及重数均合法；这是固定输入审计，不是对任意恶意JSON的完整schema验证器。

程序读取400个动作行，用`h not in actions`拒绝重复历史，以全部长度0…3的七元有序历史集合核键域恰等，并核动作合法。原证书还含终局计数(1,0,0,1,1,0,1)及security的value/primary/dual，全部已读。报告31字段中的raw路径仅标输入来源，不是原运行日志或哈希绑定。

文件名含`blind`；4857B稿声明只读上述原始输入、未调用源求解器和审计。三件原件没有完整先验通信记录，因此不能由文件名推断未知陈述/未知证明的审查时序。本轮已读原稿和既有对象，是知情实质复核；它不是外部同行审查或全球新颖性认证。

## 3. 完整SPE的精确核验为何充分

原代码先为全部7⁴=2401个完整有序叶设`leaf[z]=z`，再按深度3、2、1、0反向令

\[
\operatorname{leaf}(h)=\operatorname{leaf}(h,\sigma(h)).
\]

这从完整动作表重建续局，不用证书声称的目标终局代算收益。当前玩家位置为|h|，对每个合法b比较

\[
u_{|h|}(\operatorname{leaf}(h))-
u_{|h|}(\operatorname{leaf}(h,b))\ge0,
\tag{IC}
\]

收益对展开的53个单位客户直接以Fraction求和。右侧在强制b后走真实后继；不会把在轨后继冻结，也不会因同负载而识别两个有序历史。每个玩家只在其层行动一次，所有节点满足(IC)即足以逆向归纳认证该完整策略为纯SPE。

原报告记录：

| 全历史检查量 | 原值及精确范围 |
|---|---|
| 决策历史 | 1+7+49+343=400，含空根及全部离轨 |
| IC比较 | 400×7=2800，含自身动作400项 |
| 非自身比较 | 2400项，其中2219严格、181平局 |
| 最小非自身差 | 0，不能改称严格均衡 |
| 实际路径 | (6,0,3,4)=(B,X0,Y0,Y1) |
| 最终收益 | (19,29/3,67/6,67/6)，和为W=51 |
| 根强制收益 | 六个旧主题均29/3；B为19 |
| 四主题最优覆盖 | 枚举全部2401个有序比较元组得OPT₄=53 |

W51也可直接从上述终局看出：旧singleton2、5各漏一名，其余51名覆盖；(6,2,4,5)覆盖全部53，因此最优值无需相信搜索器标签。根强制旧主题的29/3不是根实际收益，实际首人得到19。

本轮400动作可逆视图覆盖全部原动作，并未重算这些2800差值。其数学存在性另有已完成的充分证据可复用：[原始字面审计](../程序/不交保留字面策略的原始单位审计与十四处平局恢复--程序.md)已经逐项比较positive-depth的400动作与endogenous策略映射完全相同；两游戏客户索引/重数相同，仅B/P显示名不同。既有399非空节点2793比较加七根比较，充分覆盖这个同一策略映射。menu原报告仍作为自己的实现层保存，不把它与此前运行合称同一次执行。

## 4. 静态值的上下界互相匹配

真实security字段的查询分布为

\[
p=(570,570,1197,570,570,1197,1174)/5848,
\qquad t=28481/2924.
\]

代码核p非负、归一，对全部7³=343个**有序**三竞争词（含重复及所有排列）直接计算p的查询期望，核每项≥t且最小恰t，原报告48个有序词取等。故p给v₄(0)≥t。收益只依静态负载，343词等价覆盖84个多重集；这个简化不应用到动态策略历史。

上界使用与查询抽样独立的一份静态竞争分布Q：

| 三竞争主题 | 概率分子，分母14620 |
|---|---:|
|012|370|
|016|3941|
|026|1481|
|126|1481|
|346|4089|
|356|1629|
|456|1629|

代码核每个支持恰三合法主题、概率非负且和1，再对全部七个纯查询核E_Q f_B(T)=t。任意查询混合p′的最坏收益≤E_QE_p′f=t，因此v₄(0)≤t。这一上下界夹合不依赖LP状态、数值容差或强对偶软件。程序即使给定了候选value，也仍逐项证明它。

已有[有理鞍点正文](../计算/五十三单位静态安全值的有理鞍点--计算.md)自足给完整84列非负余量和七行上界；八个紧多重集为012、016、026、126、345、346、356、456，每个均六排列，故对应48个有序紧词。345虽未入Q支持，仍必须检查。此处复用这份充分证明，不以只核七个Q支持替代343词下界。

结论精确为

\[
v_4(0)=28481/2924,
\quad v_4(0)-u_2=647/8772>0.
\]

同例还有

\[
W-4v_4(0)=8800/731>0,\qquad 2W-OPT_4=49>0.
\]

因此它没有反驳真正聚合安全支付W≥mv_m，也没有反驳half。原报告scope的“does not refute”是本例证据范围，不能读成那些命题已证。

## 5. 预留提升条件与三份策略载体

原代码另从真实集合求旧主题大小(23,23,21,23,23,21)，每个δ_T=min_S|T∩S|均11，根预留门槛(|T|−δ_T/2)依次为(35/2,35/2,31/2,35/2,35/2,31/2)。J=19。它从以B开头、后续历史动作均旧主题的43个决策节点取规定最终收益最小值η=29/3，核

\[
19/2\le\eta,\quad \max_T(|T|-\delta_T/2)=35/2\le19,
\quad \min_T|T|/2=21/2>19/3.
\]

这些数值满足[不交保留主题的条件构造](../构造/不交保留主题的增人数全历史嵌入--构造.md)的P/R/L，但menu代码没有读取旧三人策略或逐字比较继承域，不能据此声称验证了任意输入的一般提升，或这份表逐字保留全部旧平局。一般证明由该构造对象承担。

事实上本审查输入是43258B positive-depth表σ₀；35766B endogenous表与σ₀全400动作相同、文件字节不同；43455B literal表σ₁在保留域14个末位节点改了平局，386个动作相同。详见[逐项比较和解析拼合](../程序/不交保留字面策略的原始单位审计与十四处平局恢复--程序.md)。本menu审查不读literal表，不能把2219/181严格/平局统计自动挂到σ₁。相同实际路径和相同v₄也不证明两个完整策略函数相同。

2026-10-24原稿开头写一般half、聚合、Mfull和Mpath OPEN；它只说本固定见证不反这些接口。当前不能整句照抄为现状：[强菜单历史审查](../../subarchives/six-providers/state/审查/静态列与查询投影的历史审查及强菜单停界--审查.md)已比较后来真正零根银行反族，完整根菜单Mfull及整数extra-one逐人桥均被反驳；其数学理由和精确域另见[extra-one边界](../问题/自由extra-one与iid安全值边界--问题.md)。这些后来反例不是从53单位例推导而来。全路径Mpath、真正聚合以及half均须按各自精确量词判断，不能由单位置失败迁移；五人half已有独立定理，恰六人主目标未被本页解决。

## 7. 运行合同和本轮证据边界
