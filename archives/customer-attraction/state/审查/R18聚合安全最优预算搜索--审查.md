# 对象与量词

冻结源 `b30308997af9e90106e8` 是 3,761 字节的 Python 探索脚本（SHA-256 `c84cf294c0894381293c2683bb215cc917551f4520b395b91c7e96fd3e043333`）。它固定 `n=3,m=6`，质量坐标是 63 个非空主题掩码。脚本没有把“所有三人完整历史纯 SPE”作为量词；它只在一个硬编码的完整响应策略和随机选出的有限质量分布集合上搜索。源码开头也明确把结果标为 exploratory floats，并要求独立 exact reconstruction 才能成为结果。

对每个非空客户类型 `T⊆{0,…,5}`，`hit[T,x]` 是主题 x 是否命中客户。历史长度从 0 到 2，策略 `policy` 的响应规则是：根选 0；只有一个历史动作时，在两个三主题组之间切换；长度为 2 时从与上一动作相反的半组中取尚未出现的最小主题。`term(h)` 递归得到完整长度 3 的终局。这个规则只给出一份策略，不能代表全部 SPE。

# 程序的实际计算

1. 对每个历史和每个偏离动作，计算终局分摊向量差 `row(policy(h),term(h))−row(a,term(h+(a,)))`，取去重后的矩阵 `G`。浮点约束 `G w≥0`、`∑_T w_T=1`、`w_T≥0` 的随机线性目标 LP 产生若干候选质量分布 `w`；每轮再以 `[0,10^{-4},0.005,0.05,0.2]` 的混合系数与固定 `base` 分布混合。这里 `G w≥0` 是该固定策略对当前质量分布的弱激励不等式，未检查严格性，也未检查所有历史的独立 tie 处理。
2. 令 `z=term(())`，`c_T=1[T∩z≠∅]`，故 `W=c·w` 是该终局覆盖质量。对所有长度 `n−1=2` 的可重复背景 `B` 枚举 `F_B[a,T]=hit[T,a]/(1+∑_{x∈B}hit[T,x])`。
3. `security(F,w)` 计算浮点 minimax LP：选查询分布 `p∈Δ_6` 和标量 `v`，使每个背景行满足 `v≤(F_Bw)·p`，最大化 v。该 v 是对静态重复背景集合的一个 LP 安全值。
4. `M[i,b,a,T]` 为玩家位置 i 被强制改成 b 后、其余终局动作形成的后继背景下的同类分母。程序以 `numpy.einsum('b,a,ibat,t->',p,p,M,w)` 汇总查询成本 `C`，报告 `budget=W−C` 和 `strong_gap=W−3v`。此成本不是完整历史上每个偏离节点的独立收费证明；它依赖脚本选定的后继和同一 p 的乘积抽样。

# 实际重放

我用 `clean show` 导出冻结源，并在隔离证据目录运行：

```text
python3 search_optimal_budget.py --samples 30 --seed 741
```

输出依次记录 iteration 0 的 `budget≈0.0706218`、iteration 2 的 `budget≈0.000215208`，以及 iteration 15 的边界点。最终摘要为：

- `samples=30`、`seed=741`、`root=[0,3,4]`；
- `minimum_budget=0.0`、`minimum_strong_gap=0.0`、`negative_budgets=0`；
- 保存点 `w=δ_{63}`（63 维向量只有最后一个坐标为 1），`p=δ_0`，`W=1`，`v=1/3`，`min_spe_slack=0`。

该结果与仓库既有的最小输出对象一致；本次新增证据保留完整源副本、stdout、两个 JSON 输出和 manifest。`min_spe_slack=0` 表示保存点有零松弛/平局，不是严格 SPE 证明。所有数值由 NumPy/SciPy 双精度产生，输出没有有理化的原始/对偶 LP 证书；因此不能把 `0.0` 当作符号等式，更不能把任意微小负浮点值当作反例。

# 与既有对象的关系与边界

既有 `R-18 聚合安全最优预算最小输出` 已保留同一 iteration 15 的 785 字节字段记录，但只存输出 JSON；本稿补充了源代码的历史量词、策略硬编码、LP 约束和独立 30 次重放。`R-18 随机最优预算搜索器` 采用随机客户质量、LCM 整数化逆向归纳和另一个背景量词；两者都只给有限浮点搜索，不能互相升级为全称结论。

`实际末前背景的聚合安全值候选 LAST` 的背景是某份完整策略实际前缀，并提出 `mM_b≤W` 的开放候选；本脚本把所有可重复长度 2 背景放进一个静态 LP，再沿单一硬编码终局策略累计 C。背景量词、策略量词和成本定义不同，不能把这里的 `W−3v` 或 `budget` 当成 LAST 的证明。

`静态安全值与聚合保底的精确核验` 及 `总安全预算的精确证书与独立审计` 使用固定客户输入、完整策略和有理/Fraction 重算；本脚本没有这些精确证书，也没有复核前述 6 人主问题的所有历史。脚本生成的 `w=δ_{63}` 是全体客户都被至少一个终局主题覆盖的退化质量分布，不能推出一般客户分布、一般 n,m 或 Q-CAG-HALF-6 的半覆盖结论。

# 可复用内容、失败机制与接续

可复用的是三个明确接口：

- 固定有限策略可用 `G w≥0` 先筛选质量分布，再把激励筛选与静态安全 LP 分离；
- 静态安全值的背景矩阵可由主题命中计数直接构造，适合转换成 Fraction 并做原/对偶证书；
- `budget=W−C` 与 `strong_gap=W−nv` 可作为有限实验的双指标，但必须逐项报告 n、m、策略、背景全集、seed、样本数和浮点误差。

未解决的关键缺口是：枚举所有完整策略、所有质量分布的激励锥，证明 `C` 的真实收费与历史偏离一致，并将 LP p/v 恢复为有理对偶证书。下一步若继续，应先固定一个小 `n,m`，把 G、F、M 全部转为整数/有理矩阵，逐历史核对后继背景和每个偏离动作；随后才可判断是否存在严格负预算或仅有退化零点。不能把脚本的随机目标和 30 次重放当作穷尽搜索。
