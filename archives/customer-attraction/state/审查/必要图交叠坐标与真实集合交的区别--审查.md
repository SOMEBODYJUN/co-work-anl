# 两事件真实交叠的精确条件

在一个hist客户空间内，总质量h≥0，两个R事件的边缘质量为r、s，拟定交叠为v。四个原子质量必为
\[
v,\quad r-v,\quad s-v,\quad h-r-s+v.
\]
四者非负且和h，因此必要且充分条件是
\[
\boxed{\max(0,r+s-h)\le v\le\min(r,s).}
\tag{F}
\]
充分性直接用这四个非负原子作为两个集合的四种会员型。所有量有理时，统一清分母即得有限单位客户实现；这只涉及这两个集合。

如果LP只要求v≥0、v≤r、v≤s，就漏掉00原子非负的下界。特别是h>0、r=s=h而v=0时，原上界全通过，真实交叠却必须为h。表中精化点列992正是这种情形：所属hist当前列117，两R边缘均为该hist的全部正质量，而保存的overlap是0。网格点列944也有一R覆盖整个hist、另一R质量为正，却保存v=0，依(F)同样不可能。

这否定的是**原1905个坐标逐项保持数值时**的字面集合交解释。它不否定一个只宣称满足有限松弛不等式的有理点，也不排修改辅助量或其他会员后实现目录。其scope原已标necessary graph、not SPE；不能把此诊断改写成原模型反例或整个固定支持不可行。

即使每对都满足(F)，多个事件的全部指定交叠仍可能共同不相容，见[两两客户投影的共同实现障碍](../障碍/两两非负客户投影不能共同实现--障碍.md)。所以补每对下界与证明整张共同会员图存在是不同步骤。

# 为什么正交叠抬升可另行修复这层

保同一hist质量h及全部R边缘r_g∈[0,h]。在[0,h]上取共同坐标t，定义
\[
R_g=\{t<r_g\}.
\]
则全部R同时满足 \(|R_g\cap R_q|=\min(r_g,r_q)\)，自动满足(F)；不是逐对分别找互不相容的实现。

若被保留的普通行均具有
\[
A_\ell(h,r,\text{其它固定量})+\sum_{g<q}c_{\ell,gq}v_{gq}\ge0,
\qquad c_{\ell,gq}\ge0,
\]
而每个旧v只受非负及两条上界，那么将v统一改为min只会增加这些普通行余量；上界也重新显然满足。由此可在**确已核清非负系数的行族**中保可行。遇到负交叠系数、更高阶矩或新增真实IC，须重审，不能从点通过原图就自动得到这个系数条件。

每组自己的(R_g,Z_g)三态质量亦可在共同R背景上保留：设11质量为a_g、01质量为b_g，则在R_g内令Z_g条件概率为a_g/r_g，在其外为b_g/(h−r_g)；零质量区域无需定义比率，对应分子由原四态非负性必为0。再在各区域附加独立辅助坐标，就能同时实现各组自身二维边缘。分有限个阈值小段并枚举有限组的二元会员型后，所有质量仍有理，统一清分母即可有限单位客户化。这个构造没有保任意指定的跨组R–Z或Z–Z矩；后续新查询约束仍须另验。它不是对原博弈作独立性假设。

原[共同阈值及对角拆分构造](../构造/回复会员阈值的共同凸抬升与对角预算拆分--构造.md)进一步按R阈值分层并重新选择Z，适用的每个行族与固定/可变边缘合同都须保留。当前诊断不将“原辅助量不相容”扩大成“没有这种重分配完成”。

# 不同缺口不能互相代替

连续旧查询切面只依hist和R/Z一阶边缘。对已被这些cut切掉的点，若仅把R–R辅助交叠抬成min，所有该族cut余量保持不变。因此修复字面交叠本身不能修复那些负cut。混合5043点的后64及32表全负、网格4971点被64表全切，均已在对应数据对象中实际代入。

同样，共同客户会员存在并不提供完整有序历史SPE。即便某次阈值物化产生合法156主题目录，指定旧路径仍可能被真尾偏离击破，见[固定前缀两人尾报告](../计算/完整156主题固定前缀的两人尾报告--计算.md)。这里依次有原图数值可行、原坐标可物化、允许抬升后的会员可实现、全部真实IC及完整策略几个不同命题。

本页可用来阻止把overlap字段名称当客户实现证书，给后续补矩或物化提供准确起点；开放问题仍可保留。阶段三可分别登记四个点到此局部诊断、条件阈值构造及真实尾反驳的关系，不把它们压成同一种“失败”标签。
