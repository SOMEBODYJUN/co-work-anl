# 参数重标及严格距离到底否定什么

旧静态反族的m是**竞争槽数**；在本顺序游戏真实人数m≥2中它改名k=m−1。设

\[
C=k(k+1)=m(m-1),\quad h=k+2=m+1,\quad P=k+3=m+2.
\]

两个core各C名单位客户，各有h个“本core加P名全目录私有客户”的叶，另主题B只含两core。指定p*均匀全部2h叶，k槽纯背景q0=B^k。精确静态值与非最坏统一距离是

\[
v_m=C/(k+1)+P=2m+1,\qquad
\delta=\frac{C}{2k(k+1)}-\frac P{4h}
=\frac{m}{4(m+1)}>0.
\]

原审查核的是：这个指定p*安全最优，且对**每份**完整纯SPE、**每个**强制根动作，原同一策略的m−1真实尾列B(a)都满足F_(p*)(B(a))≥v_m+δ。存在这个p*已足反驳“每个安全最优p*都必有真实根尾接触列”，不证明所有安全最优p均无接触，也不否定可以另选某个p取得接触的存在版本。

尾列只含m−1个后继，不含强制根；相应M_tail≥v_m+δ与含根m槽Mfull是不同优化问题。两稿当时将一般Mfull列OPEN属于历史时点；当前[银行完整根列反族](../反例/银行完整根列的两查询最小分离--反例.md)另已在m≥4否定一般Mfull。不能把那条当前状态倒填成本严格尾例已反Mfull，也不能因本例不反而继续写普遍Mfull仍开放。当前五人half亦已有别证，本例与一般聚合安全/六人half仍各保量词。

# 静态标量余项的完整符号域

对任意k槽背景q，若X/Y叶总数为u,w、各具体叶计数为r_i，t=u+w=Σr_i，则

\[
F_{p^*}(q)=\frac C2\left(\frac1{k-w+1}+\frac1{k-u+1}\right)
+\frac P{2h}\sum_i\frac1{r_i+1}.
\]

原独审逐项核两种整数不等式。把其差通分，得到可直接复核的完整余项：

\[
\frac1{k-z+1}-\frac1{k+1}-\frac z{k(k+1)}
=\frac{z(z-1)}{k(k+1)(k-z+1)}\ge0\quad(0\le z\le k),
\]
\[
\frac r2-\frac r{r+1}=\frac{r(r-1)}{2(r+1)}\ge0\quad(r\in\mathbb Z_{\ge0}).
\]

前式z0/1、后式r0/1均取等；k≥1使全部分母为正，m2/k1边界也合法。它们是整数槽域的身份，不能悄悄将z或r改任意非负实数：0<z<1或0<r<1会改变符号。

以\(R_k(z)=z(z-1)/[k(k+1)(k-z+1)]\)记第一余项，可以写出原静态预算的精确非负分解：

\[
F_{p^*}(q)-v_m-t\delta
=\frac C2[R_k(u)+R_k(w)]
+\frac P{2h}\sum_i\frac{r_i(r_i-1)}{2(r_i+1)}\ge0.
\]

因此q≠q0时t≥1，F−v≥δ；q0唯一纯最坏。q=B^(k−1)+一片叶时u/w为1/0、唯一非零r=1，两余项都0，故F−v=δ。原审查的“恰δ”指**所有非最坏静态背景域**的最小差；并未证明某个真实SPE尾列必能达到δ，不能把这个静态sharp值改成真实菜单域的sharp值。

# 真实末位排除与fresh/copy的承重例外

全部尾为B^k时，强制根B后的最后玩家留B值2k、改叶值2k+3；强制根为X叶时，最后留B值2k+1、改Y叶值2k+4。两种真实最后节点均严格改善3，Y根对称。根本身可非最优，但其后仍是原完整σ的真实SPE子局，所以每根尾都排q0。再用同一p*平均，任意混合这些真实尾列的Q均满足max_T E_Qf_B(T)≥E_QF_(p*)(B)≥v+δ，得到M_tail下界；没有按query选择不同背景。

审查特别保全fresh/copy归纳的全历史量词：在**同一零初始背景的m人游戏**每个有序历史，至少有新鲜叶；若以后不复制它，私有客户独享且core总负载≤m，偏离收益≥P+C/m=v；若以后复制，较晚玩家在该真实离轨分支享归纳地板，选同主题者最终收益相等，当前亦≥v。最后位置给归纳基，当前SPE最优性传回处方收益。

这个命题只保各节点当前及未来的最优行动者，不把此前被外部强制固定的根也变成当前最优。原独审明确：任意强制根a的已固定玩家不在地板结论中；主稿(D)只对实际完整SPE路径所有角色断言u_i≥v。core负载≤m也包含此m人游戏内已经发生的历史，不声称额外任意旧背景再加m玩家仍有同一数值地板。

最优覆盖的审查是独立计数：m槽至多取m个私有块、最多覆盖两core，故OPT≤mP+2C；h=m+1>m，能取m片不同叶且两组都有，达到等号OPT=3m²。结合地板有W≥m(2m+1)，所以OPT/W≤3m/(2m+1)<3/2。这里m(2m+1)是福利**下界**，不是声明所有SPE恰取该W或所有SPE都达到OPT。
