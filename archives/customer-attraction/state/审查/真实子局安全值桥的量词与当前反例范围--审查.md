# 四种静态对象不能共用一个“安全值”符号

固定原有限单位客户共同目录、合法有序背景h、负载b、余r名单位角色，以及该子游戏的一份完整有序历史纯SPE σ。任一强制首动作A后的真实剩余列为Z(A)=(A,Y_A)，含首动作共r槽。记d_A为该首位最终利润，u=max_A d_A。真实原IC给d_A≤u；偏离之后仍沿同一σ，不冻结尾部。

给额外查询T定义价格q_b(T,z)=Σ_{x∈T}1/(b_x+1+z_x)。分母中的1是查询自身。以下对象的槽数全部明确为r：

| 对象 | 精确定义与量词 |
|---|---|
| 整数静态v_{r+1}(b) | max_p min_{B∈S^r} E_p q_b(T,c_B)；静态B不观察查询实现，有限minimax等于min_Q max_T E_Q q_b(T,c_B) |
| 自由分数B_r(b) | min_{z∈r conv{1_A}} max_T q_b(T,z)；负载是均值分数，不是原玩家的新行动 |
| iid λ_{r+1}(b) | 另一个r+1人静态对称iid Nash的共同利润；查询面对r名iid对手，不是任意相关整数对手 |
| 完整真实根菜单K | K_{T,A}=q_b(T,c_{Z(A)})；保首动作r槽，再加查询，不是删当前槽的r−1槽菜单 |

对任一整数背景混合Q，Jensen给E_Q q_b(T,c_B)≥q_b(T,E_Qc_B)，且均值在r conv{1_A}内；所以v_{r+1}≥B_r。iid对手是允许的整数背景混合之一，静态对称Nash的最大查询值为λ，故λ_{r+1}≥v_{r+1}≥B_r。这里没有宣称三者相等。首位≥λ的EI比首位≥v更强。

root源把EI写成v符号、又在各轮区分WP和Mfull，不能仅按缩写把不同基准合并。真正iid候选及其修正见[七客户EI反例](../反例/额外一人iid收益桥的七客户银行根反例--反例.md)，整数弱化的当前状态见[自由extra-one边界](../问题/自由extra-one与iid安全值边界--问题.md)。

# 零背景银行反例：普遍个体桥与自由完整菜单均已失败

[银行完整SPE族](../反例/笛卡尔银行目录的逐人分数门槛反族--反例.md)有m个经济单位客户、m−1个互不交2客户银行块，目录为全部经济singleton与一个银行块的Cartesian组合。已有BASE/PUNISH/EXIT控制器在**全部有序历史**可信，任一真实根行动收益均
\[
 u_m=1+1/(m-1),\qquad W=2m,\quad OPT_m=3m-2.
\]
惩罚目标固定于过去银行，全部再次偏离也有定义；这里复用该完整证明，不把静态矩阵虚构成SPE。

自由分数背景的匹配双边证书给B_m(0)=3/2−1/(2m−1)>u_m（m≥4）。故同一族已经从零根否定整数extra-one首位≥v_{m+1}以及更强EI。m=3时B_3=13/10<u_3，不能用这一下界否EI；但七客户同族的均匀静态四人iid Nash有
\[
 \lambda_4=g_4(1/3)+2g_4(1/2)
 =65/108+2(15/32)=665/432>3/2,
\]
其中g_{n+1}(p)=[1−(1−p)^{n+1}]/[(n+1)p]。差17/432直接否三人根EI；这是iid计算，不能用δ值替它。

对完整真实根矩阵K，任一列混合Q的均值仍是m槽合法分数负载。相同Jensen证明max_T(KQ)_T≥B_m>u_m，所以
\[
 M_{full}:=\min_Q\max_T(KQ)_T\le u_m
\]
的普遍断言亦假；不是只举一个不好的列混合。对称菜单NE存在不保证低值，所有菜单NE的值至少Mfull，故“存在低值NE”的NQ也被否。

更精确的[两查询分离](../反例/银行完整根列的两查询最小分离--反例.md)对m≥3取p2均匀支持(1,0)、(2,1)。每一真实根列都满足p2^TK[:,A]≥4/3+1/(2m)，支持两列取等，故
\[
 p_2^TKp_2=4/3+1/(2m),\quad
 p_2^TKp_2-u_m={(2m+1)(m-3)\over6m(m-1)}>0\quad(m\ge4).
\]
这同时否弱全p-WP及WP2；每个单点p却严格安全，所以最小unsafe支持恰2。m3只等号，m2这个异银行二query尚不存在，不能延伸严格失败范围。Mfull全菜单精确值另为2−1/m−1/[3(m−1)]；它不是固定p2的数值，m4分别是59/36与35/24。

以上全部是原模型真实零根证据，已经覆盖源“零根弱WP/自由Mfull仍OPEN”的陈述；应保存为历史时态。银行族2W−OPT=m+2>0，故它没有反half或全实际路径聚合付款。逐人OPT/(2m)也只从m≥5被该族否，不能因此否定聚合安全值。

# 合法背景PB反例仍成立，实际前缀迁移另有障碍

[PB完整背景反例](../反例/任意合法背景的前两人额外槽安全值--反例.md)取k3,d20,q12,Q2063,t10,H100000,M10^9，余r2475。目录含分段Cartesian regular及全部客户singleton；指定b可由这些singleton的有限重复合法实现，且已覆盖全体客户。前三位真实利润u=dkf(k)，其中f(c)=11/(M+c)+1/(M+c+1)、g(c)=12H/(HM+c)。同一个合法query分布对**每个**r槽整数竞争元组（含singleton及重复）保证
\[
 K_p(B)\ge s=d[f(1+rk/Q)+(k-1)g(r+1)]>u.
\]
Fill/Copy/Punish/Greedy在所有regular历史的自身IC、Greedy水位、singleton严格劣势及首次singleton后BI补全共同承担完整子SPE证明；正有理标量不替代这些全树条件。

记D(p)=E_p d_A、C(p)=p^TKp。于是前两位和2u<2v_{r+1}(b)，否任意合法背景PB；每个真实完整列Z(A)也是合法r槽元组，同一p逐列下界又给D(p)≤u<s≤C(p)，并对所有Q有max_T(KQ)_T≥s>u。全背景SELF、弱WP、Mfull同时被同一旧证据否。这是统一所有B的量词推论，不是任意找一个矩阵entry大。

“b合法”不要求b在所选根SPE的actual路径上。该背景可作为某个完整根SPE的离轨子局存在，并不强制祖先选择它；背景已覆盖全部客户，也不是根福利亏损。源R5-PB-EXTRA-NO-v1保留为真正完整子SPE反例，不改成伪菜单。

[最后D-singleton障碍](../障碍/PB大背景的最后单例偏离--障碍.md)进一步证明：保原目录、原参数、精确b、之后2475个regular实际动作，任何实现b的有序前缀都不能在根SPE实际路径上。其R类实际总负载上界L=495120001823260迫使存在最后D-singleton，实际收益≤1/HM；它真改regular，无论后继如何响应，都保证240/(M+L+2)>1/HM，严格差由240HM−(M+L+2)=23504878998176738>0承担。

该障碍排除的是指定背景的**在轨移植**，不推翻PB合法背景构造，不自动解决actual-prefix弱PB、LAST或half。改目录/参数/背景也不由该障碍排除。相同模型下，离轨存在与实际前缀是两个独立量词。
