# 五人局部组件独立重构的真实节点门槛与复现范围

## 1. 审查对象、原完成状态及本次范围

原文审查已导入的 `CA-FIVE-HALF-EXACT-v1` 五人证明包。原审查者先重建局部语义，再对照现存审稿，写出不导入证明包Python、发现器或仓库求解器的独立标准库实现。它重建了全部36局部组件、47,872个系数状态及冻结主系统所用的全部向外取整源表。这是真实交付的**独立局部实现**；其独立性是实现与语义重建的独立，既非证明发现认领，也不是外部同行评审。

本次完整阅读三个来源，并消费冻结JSON每个字段与36条记录；又完整消费当前七份组件JSON的所有字段、乘子和数组，核对其SHA与原报告及成熟重放报告全部相同，比较36条状态数、零数和非负结果。原47,872态已有成熟精确重放，本次没有再运行这一整套计算；新[绑定检查](../../tools/evidence/direct-swap-local-components-resumed-boss3/fixed-interface-audit.json)明确记录 `newly_replayed_coefficient_states=0`。原报告不含它自身Python或 `row_manifest.json` 的SHA，本次也不补造这些历史运行绑定。

证明使用有限单位客户、五名单位提供者、有限非空共同**带标签目录**与全部有序历史纯SPE。覆盖映射可非单射，保留空主题、重复、零客户及所有平局。每份局部代入均来自同一原策略；相同有序历史自然同回复，同负载但不同顺序不必同回复。全二元会员域可包含不可实现的独立位型，逐系数非负仅扩大证明域，并不授权给同一历史两个不同动作。

当前[五人半覆盖](../定理/五人半覆盖--定理.md)已有完整证明。[既有证书复核边界](五人证书复核边界--审查.md)区分全主域整数闭合、局部组件和入口复现；本页补清这一份后续局部实现的具体交付及门槛。它没有提供第二份全主域6144状态的主恒等式实现，也不将局部状态数充当全主域状态数。

## 2. 全五角色路径与首个真优化者

原实现给每条路径补足五角色，角色索引全局零起始。表中“first”之前是被强制指定的角色；这些角色只通过其原真实源节点的偏离比较付款，不能在强制分支上自行调用最佳回复。其后仍按同一原策略，故才是真优化者。

| 局部族 | 完整路径：first |
|---|---|
| DEEP | `TABCD`:1；`TQHIJ`:2；`TAQEF`:3；`TABQG`:4 |
| BG2 | `ATBCD`:2；`ATQEF`:3；`ATBQG`:4 |
| BG3 | `ABTCD`:3；`ABTQE`:4；`ABTDF`:4 |
| PC2 | `ATEFG`:2；`ATQHI`:3；`ATEQJ`:4 |
| PC3 | `ABTEF`:3；`ABTQG`:4；`ABTFH`:4 |
| MAXROOT | `TABCD`:1；`TDQRS`:2；`TADXY`:3 |
| 可选 MAX-BG2 | `ATBCD`:2；`ATDEF`:3 |

对路径 $P=(P_0,\ldots,P_4)$ 的客户位 $b_T$，代码独立计算

\[
\operatorname{pay}(P,i)=\frac{b_{P_i}}{\sum_{j=0}^4b_{P_j}},\qquad
\operatorname{floor}(P,i,T)=\frac{b_T}{\sum_{j<i}b_{P_j}+5-i}.
\tag{1}
\]

零分子份额直接为零。角色 $i$ 真正优化时，客户求和的 `floor−pay≤0` 来自强制该角色选T之后最多剩 $5-i$ 个负载，不冻结其后行动。代码 `raw_ic` 断言 $\mathrm{first}\le i\le4$。

`true_switch(source,child,i,first)` 又断言两条路径前 $i$ 项一致且 $i\ge\mathrm{first}$，返回子枝角色 $i$ 最终收益减源枝同角色最终收益。非正性是在**源**真节点应用IC，子枝该角色可以是强制者。这个区分尤其防止把 MAXROOT 的 `TDQRS` 中D、`TADXY` 中D，或DEEP/BG/PC的强制Q/F误作其强制节点的优化者。

同覆盖异标签也不改变这些门槛；门槛来自实际有序历史的构造，而非客户负载是否碰巧相同。

## 3. raw、bound、源列与价格的方向

DEEP/BG/PC的多数 `raw` 是“左查询减右界”的非正表达式，不能将raw本身当成非负松弛。CAP虽是正会员位，仍需共同外部K作bound。实际意义如下：

| 键族 | 每客户raw | 客户求和后的外部bound |
|---|---|---|
| CAP | 主题会员位 | 同一裸大小帽K |
| IC | 安全查询减本真节点角色最终收益 | 0 |
| TRUE | 同角色强制子枝最终收益减源真节点最终收益 | 0 |
| ACTUAL | 在原实际角色节点的合法安全查询 | 对应原实际 $u_i$ |
| DEEP ROOT | 强制根T在真实后继叶的最终收益 $v_T$ | 原根 $u_1$ |

所有原乘子均逐项读取为 `Fraction` 并非负。BG/PC每组件在完整会员域的余项形式为

\[
\rho=v_T+\sum_k\lambda_k\operatorname{raw}_k-\gamma(\text{可见位})\ge0.
\]

因而在加入一次源节点真实IC后，

\[
u_{\mathrm{source}}+\beta K+\sum_i\alpha_i u_i-\sum_x\gamma_x
=(u_{\mathrm{source}}-v_T)
+\sum_k\lambda_k(\operatorname{bound}_k-\operatorname{raw}_k)
+\sum_x\rho_x\ge0.\tag{2}
\]

CAP乘子和给β，ACTUAL同角色乘子和给α，TRUE/IC bound均为零。DEEP则直接将 ROOT 的正乘子α对应于 $\alpha(u_1-v_T)$；其右侧目标 $|Q\setminus T|$、$\gamma|T|$ 和 $\zeta|T\cap Q|$ 按源公式保留，不能照搬BG的符号。

PC隐藏回复H只以合法主题身份进入原实际末位查询

\[
\sum_{x\in H}\frac1{1+\mathbf1_A+\mathbf1_B+\mathbf1_C+\mathbf1_D}\le u_5.
\]

这里价格是原实际 $u_5$，不是离轨H的真实末位收益。当前所有非零ACTUAL价格确在第五位。PC2的 `u_coefs` 只存附加价格，转换主行须再加**一次**源 $u_2$；PC3的 `u_coefficients` 已含源 $u_3=1$，不能再加。独立程序逐角色比较CAP和、ACTUAL和以及源列，防止多发一份源利润。

BG2可见位顺序ATQ，BG3为ABTQ，PC为ABCDTQ。隐藏会员位被全域非负证书逐客户消去；这不要求每客户可自行挑选一份真实策略。对多个比较主题索引代入时，共享外部 $u_i,K$ 才能按重复次数计预算，不能把互斥分支利润改称同一实际福利。

## 4. TAX与MAXROOT的两个门槛

### 4.1 两人税只能用于首人也是真优化者的子局

固定末两人前负载p，实际末两题C,D，
$f(X)=\sum_X1/(p+1)$、$g(X,Y)=\sum_{X\cap Y}1/[(p+1)(p+2)]$。首人强制T后的真实末回Q，三项真IC相加给

\[
u_C+u_D-f(T)-f(S)+g(T,S)+g(C,Q)\ge0.
\]

以 $g(C,C)\ge g(C,Q)$ 得
$H=u_C+u_D+g(C,C)\ge f(T)+f(S)-g(T,S)$，进一步支配比较两人总利润 $f(T)+f(S)-2g(T,S)$。独立实现 `tax_raw` 正是后者减H。

首人C必须真优化，才能使用第一项IC。原通用PC2 TAX解析器曾未排除 `fourth` 路径：`ATEQJ` 的第四位Q被强制，first=4，因此不能在此调用末两人税。独立实现加硬断言 `first[tag]≤3`。当前五份PC2组件全部没有TAX键，故这个未来输入解析风险**不承重于当前证书**，没有修改冻结原包。接续添加TAX输入必须重新过门槛，不能因当前通过而默认任意新键合法。

### 4.2 MAXROOT只以正B转回原根收益

MAXROOT使用三条表列真实路径，保留各自末两人和末位收益。对五个合法比较索引的十个索引对应用两人税，固定每个被最优并集覆盖的客户的一个覆盖索引，含它的四对各至少给 $1/(p+1)$；由此给

\[
\tfrac52H+\sum_x\frac{p_x}{p_x+1}-O\ge0.
\]

五次真实末位查询同理给
$5u_{\mathrm{last}}+\sum_xc_x/(c_x+1)-O\ge0$。重复主题仍保留五个索引，不作集合去重；空主题不破坏计数。

同一裸大小最大主题T满足 $|T|=K$。每份MAXROOT有22个非负乘子，六个含O行的乘子和精确为1，所以O消去后余项只剩10个主题位；原实现分别代 $o=0,1$ 断言余项完全相同。两份界的B均正，才可由原根真实IC将 $Bv_T$ 换为 $Bu_1$；负的K系数照原式保留。复制分支旧角色的其他收益没有套用原根上界。

每份当前域 $2^{10}=1024$ 态、56零余项；还检查余项乘245803508760为整数。JSON保留的历史 `states=12288,zero_types=672` 来自旧扩展域，不是当前消O实现的状态数。原审查者首次将672误作当前零数而断言停止，随后改为重建并核当前域56；本页保留这次历史失败和修正，不伪造成最初一次就通过，也不据12倍比例声称重跑了旧扩展域。

可选MAX-BG2在实际第一题A后强制T，第三位再复制该枝末题D。其 $B=\lambda_{FORCED}$，K列为 $\gamma_T+\sum\lambda_{CAP}$，A列为 $\gamma_A$。当前删去未活跃回复位，以7主题位和比较重数 $d=0,\ldots,5$ 组成768态、19零余项；旧JSON1536/38相应保留。它的局部正确性已审，不等于它必是最终主恒等式的活跃依赖。

## 5. 向外取整必须保持外部列身份

冻结尺度 $S=10^6$。$u_i,K$ 和客户类型数量均非负，故收益/K的左侧系数取ceil、右侧每个γ取floor，均使“左减右”增大。负γ也不例外。DEEP的γ、ζ是上界预算的系数，故取ceil；负系数仍是向上取整。MAXROOT负K系数亦取ceil，变得较不负，方向正确。

原实现从精确JSON重建并逐字段比较冻结 `row_manifest.json`：

| 表 | 冻结索引及转换 |
|---|---|
| BG九项 | BG2 `[0,1,3,5,11,12]` 后接BG3 `[0,1,2]`；K ceil，γ floor，源角色位置分别1、2 |
| PC八项 | 全五个PC2后接全三个PC3；K与收益列ceil，γ floor；仅PC2附加一次源 $u_2$ |
| DEEP三项 | 每项 `[ceil(Sα),ceil(Sβ),ceil(Sγ),S,ceil(Sζ)]` |
| MAXROOT主行 | 第一组件的 `(ceil(SB),ceil(SC))=(46313177,-7412362)` |

manifest列出的六份来源SHA分别对应实际六文件；可选MAX-BG2不在这六份主表来源内。局部审查报告记录的七输入SHA包括它，故“manifest六哈希”与“报告七输入”不是冲突。当前原报告没有附manifest自身SHA，不能把这项历史逐字段比较自动升级成某个未记录字节版本的运行绑定。

## 7. 复现入口和实际完成层级

原脚本仅用Python标准库，依赖工作目录下 `customer_attraction/proofs/half5_exact_v1/components/` 七份JSON及根 `row_manifest.json`。脚本**没有main guard**，导入即执行全部循环，并覆盖自己相邻的JSON报告。它不能在当前重构目录盲目原位执行：包的实际保存位置已是[组件目录](../../tools/half5-exact/components/)，应在独立复现目录恢复旧路径布局并复制原脚本，或显式审查路径适配后运行。路径适配不应修改或覆盖冻结证据。本次没有做该完整复跑。

已有便携原局部核验器与这份独立全局路径核验器的表达不同：前者按局部索引定义族行，后者从五角色完整路径收益和首真节点门槛重建，原审查交付可视为不同实现；两者的精确输入和数学机制是同一份证明的组成部分。53条主行的组合、共享K列与全主域整数恒等式应继续读[五人定理](../定理/五人半覆盖--定理.md)及[复核边界](五人证书复核边界--审查.md)，本页不声称替代它们。

所有IC均是弱不等式，没有为平局额外选择有利回复；全零客户与K=0不需除以这些量；标签重合仅缩小真实会员域。当前结论不推广五人包的价格、数值表或有限状态域到六人，也不是一般背景五人证明。
