# 固定背景收益切片的后继独立秩审查

这份审查确认的是一个静态、固定背景、双主题席位重分配切片中的**全部有符号客户恒等式**，并保存后继程序对其有限参数范围的精确复现。一般共同目录半覆盖问题仍开放；结果没有给出全树 SPE 付款，也没有给出其不可能性。

三份来源分别是 4,461 字节的[后继审查程序](../../tools/evidence/fixed-background-circuit-basis/related/check_fixed_background_rank.py)、375 字节的[有限审查报告](../../tools/evidence/fixed-background-circuit-basis/related/fixed_background_rank_review.json)、3,390 字节的[解析审查稿](../../tools/evidence/fixed-background-circuit-basis/related/fixed_background_rank_review.md)。对应源 ID 为 dc16c13a3d177b155261、b5644b42ce76842a15e2、29186a82220f6a599450；三者的另一冻结提交为 aefc58eac3fc6eb5d7a47d087dd2c62b5aa9974c，字节身份见[来源清单](../../tools/evidence/fixed-background-rank-review/source-manifest.json)。原件沿用上一批已保存的唯一副本。

原审查稿自述先从定义独立重构，再检查作者完整稿及附录；本整理保存这一来源叙事，但不把它当成新近盲审的事实。本次已知并完整比较作者原文与既有整理，所新增的是三源完整处置及后继原入口的一次隔离复现。这是内部数学审查，不是外审、全球新颖性认证或一般半覆盖定理。

## 1. 精确对象与全部客户类型

沿用[共同目录完整历史模型](../定义/共同目录完整历史模型--定义.md)中的单位客户、单位提供者和均分收益。此处只取其静态收益定义，不要求这些计数来自某个 SPE。

取两个不同的目录标签 \(a,b\)，以及与它们在**标签身份上**不交的有限集合 \(D\)。各 \(c\in D\) 有固定正整数提供者计数 \(v_c\)，允许 \(D=\varnothing\)。标签不同不要求覆盖集合不同，也不要求彼此覆盖不交。令
\[
k=\sum_{c\in D}v_c,\qquad M\ge1,\qquad
q_j=j e_a+(M-j)e_b+v\quad(0\le j\le M).
\]
总人数为 \(M+k\)。对形式兴趣类型 \(B\subseteq\{a,b\}\cup D\)，一个实际选择主题 \(t\) 的提供者得到
\[
U_t(q;B)=\frac{\mathbf1_{\{t\in B\}}}{\sum_{s\in B}q_s}.
\]
分子零时记零；被保留的收益行中，分子非零意味着被选择主题有正计数，故分母正。重复选择、零客户、空主题及同覆盖标签均可进入实际模型；形式类型矩阵则同时列出所有可能兴趣模式。

保留 \(2M\) 行
\[
A_j=U_a(q_j),\qquad Z_j=U_b(q_{M-j}),\qquad 1\le j\le M.
\]
\(Z\) 的反向索引承重。令
\[
T=\left\{\sum_{c\in C}v_c:C\subseteq D\right\},\quad d=|T|,\quad
C_{t,j}=(t+j)^{-1}.
\]
\(d\) 是不同子集负载数，既不是背景总人数 \(k\)，也不是背景标签数。

客户是否喜欢 \(a,b\) 给四类列：

| \(a,b\) 会员 | \(A_j\) | \(Z_j\) |
|---|---:|---:|
| 00 | 0 | 0 |
| 10 | \(1/(j+t)\) | 0 |
| 01 | 0 | \(1/(j+t)\) |
| 11 | \(1/(M+t)\) | \(1/(M+t)\) |

每个 \(t\in T\) 可由背景模式实现，并可独立添加 \(a,b\)。因此全部恒等式 \(\sum\alpha_jA_j+\sum\beta_jZ_j=0\) 恰等价于
\[
C\alpha=C\beta=0,\qquad \mathbf1^\mathsf T(\alpha+\beta)=0. \tag{1}
\]
这是对所有形式客户类型成立的有理线性核。对所有非负客户实例成立的等式也必须逐类型成立，故其等式核相同；这绝不等于刻画非负客户锥、真实目录的实现锥或 SPE 不等式锥。若只保留某个给定实例中实际出现的类型，秩可以下降。

## 2. 主文三结论的实际证明

**秩与核维数。** 对任意 \(h\) 个不同负载和 \(h\) 个不同正整数席位，Cauchy 子矩阵非奇异：若 \(\sum_j x_j/(z+j)\) 在这 \(h\) 个非负负载处为零，乘分母后分子次数至多 \(h-1\)，故恒零，再由各极点留数得到全部 \(x_j=0\)。于是 \(\operatorname{rank}C=\min(d,M)\)。

当 \(d<M\) 时，常数行不在 \(C\) 的行空间。否则 \(1=\sum_t\lambda_t/(j+t)\) 对全部 \(j=1,\ldots,M\) 成立；乘 \(\prod_t(j+t)\) 得一个首项为 1、次数 \(d\) 而有 \(M>d\) 个根的多项式，矛盾。因此 (1) 最后一式在 \(\ker C\oplus\ker C\) 上独立，得到
\[
\operatorname{rank}(A,Z)=\min(2M,2d+1),\qquad
\dim\ker(A,Z)=\max(0,2M-2d-1). \tag{2}
\]

**显式完整基。** 当 \(d<M\)，令 \(P(z)=\prod_{t\in T}(z+t)\)、\(J_0=\{1,\ldots,d+1\}\)。对 \(J=J_0\) 或 \(J=J_0\cup\{r\}\)、\(r=d+2,\ldots,M\)，置
\[
h^J_j=\frac{P(j)}{\prod_{\ell\in J\setminus\{j\}}(j-\ell)}
\quad(j\in J),\qquad h^J_j=0\quad(j\notin J).
\]
严格真分式的部分分式展开
\[
\frac{P(z)}{\prod_{j\in J}(z-j)}
=\sum_{j\in J}\frac{h^J_j}{z-j}
\]
在 \(z=-t\) 给 \(Ch^J=0\)，在无穷远比较 \(1/z\) 项给
\(\sum h^{J_0}=1\)、\(\sum h^{J_0\cup\{r\}}=0\)。
故一组基为
\[
(h^{J_0},-h^{J_0}),\qquad
(h^{J_0\cup\{r\}},0),\quad(0,h^{J_0\cup\{r\}}).
\]
每个新增向量有独占的 \(r\) 坐标，给独立性；数目 \(2M-2d-1\) 与 (2) 相同，给张成。清分母、移项后得到两侧正系数的非空等式，但“正项”不赋予任意方向合法的激励乘子。程序中的 basis 是**显式残数构造**，不是由消元器重新发现任意核基；消元独立检查其秩，逐列零积检查它确在核内。

**四槽独立性。** 对 \(D\ne\varnothing\)、\(r>s\ge1\)、\(M=r+s\)，四行
\[
U_a(q_r),\quad U_b(q_s),\quad U_a(q_s),\quad U_b(q_0) \tag{3}
\]
线性独立。选一个正背景负载 \(t_0\)：a-only 的负载 \(0,t_0\) 两列构成分母 \(r+t,s+t\) 的非奇异二阶 Cauchy 矩阵，迫使两个 a 行系数为零；b-only 的同两列、分母 \(r+t,M+t\)，再迫使两个 b 行系数为零。这排除了只重调这四槽系数的提升，不排除更多槽或背景收益回路。例如一个单位背景、\(M=3\) 的六行有唯一回路；不能由 (3) 推成“非空背景无回路”。

这些证明完整对应[固定背景双主题收益切片的完整有理回路](../定理/固定背景双主题收益切片的完整有理回路--定理.md)主文；后继审查没有提出一个不同模型的替代理论。

## 3. 附录审查：聚合背景与全部单位背景

对非空背景、\(M\ge2\)，加入
\[
H_j=\sum_{c\in D}v_c U_c(q_j),\qquad 0\le j\le M.
\]
\(H_j\) 是全部背景提供者的总收益；单客户值为 \(t/[jx+(M-j)y+t]\)，分子零时取零，不是每位背景提供者的平均值。

设 \(T^+=T\setminus\{0\}\)，
\(K^+=\{x:\sum_jx_j/(j+t)=0\ \forall t\in T^+\}\)。
全部 \(3M+1\) 行关系 \(\alpha A+\beta Z+\gamma H=0\) 恰由
\[
\begin{gathered}
x,y\in K^+,\qquad \sum_j(x_j+y_j)=0,\\
\gamma_0=\sum_jx_j/j,\quad \gamma_M=\sum_jy_j/j,\quad
\sum_{j=0}^M\gamma_j=0,\\
\alpha_j=x_j+j\gamma_j,\qquad
\beta_j=y_j+j\gamma_{M-j}
\end{gathered} \tag{4}
\]
参数化。背景-only 给 \(\sum\gamma=0\)；a-only 的正负载利用
\(t/(j+t)=1-j/(j+t)\) 给 \(x\in K^+\)，零负载给 \(\gamma_0\)；b-only 对称；ab-both 给 \(\sum x+\sum y=0\)。四分支也证明充分性。

令 \(h=\dim K^+=\max(0,M-d+1)\)。若 \(h=0\)，只剩内部 \(\gamma\) 的 \(M-2\) 个自由度。若 \(h>0\)，同一根计数证明使 \(\sum x+\sum y=0\) 是独立约束；总核维数为 \(2h-1+M-2\)。两支给
\[
\operatorname{rank}(A,Z,H)=\min(2d+2,2M+3). \tag{5}
\]
非空背景和 \(M\ge2\) 均不能悄然删去。

再设背景有 \(k\) 个不同标签、**每个恰一位**，且 \(k\ge M\ge2\)，纳入所有 \(k(M+1)\) 条逐主题背景收益。对任意两背景标签 \(c,e\)，其关系系数差记为 \(\delta_j\)。背景单标签客户给 \(\sum\delta_j=0\)；交换客户是否喜欢 \(c,e\)，取背景负载 \(t=1,\ldots,k-1\)，a-only、b-only 分别给
\[
R(t)=R(-M-t)=0,\qquad
R(z)=\sum_{j=0}^M\frac{\delta_j}{z+j}.
\]
乘分母后，零和条件把分子次数降至至多 \(M-1\)，却有 \(2(k-1)>M-1\) 个不同非极点根。于是 \(\delta=0\)，所有背景标签的系数相同，回到 (4)，此时 \(d=k+1\ge M+1\)。

因此 \(N=2M+k(M+1)\) 行的核恰由 \(M-2\) 个内部同支持效率差生成：
\[
E_j-E_1=0\quad(2\le j\le M-1),\qquad
E_j=jA_j+(M-j)Z_{M-j}+H_j,
\]
秩为 \(N-M+2\)。内部 \(q_j\) 有相同支持；端点 \(q_0,q_M\) 缺一个活动标签，不能并入这些效率差。\(M=2\) 时差集为空。该结果不覆盖任意非单位背景的全部逐主题收益，也不禁止改变背景配置或使用切片外顶点。

后继程序只在有限点核对 (5) 及单位背景秩，不生成聚合核基、不检查作者附录的六收益恒等式、不构造单位背景效率基。以上无限参数结论来自解析论证，不能由报告里的 90 和 8 倒推。

## 4. 4,461 字节程序的完整合同

程序只导入标准库 Fraction、itertools.product、json、Path；不导入作者程序、CAG 模型、SPE 求解器或 LP。主入口有 name guard，无参数解析，始终运行写死的五组检查，向**程序同目录**覆盖写 fixed_background_rank_review.json，并在 stdout 打印紧凑 JSON。所以必须在隔离目录复现，不能直接在原件目录运行。

- rank 将矩阵复制成 Fraction，按列找非零主元，归一化并对主元上下所有其他行消元；空矩阵返回 0。它计算秩，不返回核基、主元证书或行操作轨迹，也没有通用不规则输入检查。
- rows(v,M) 以 \(A_1,\ldots,A_M,Z_1,\ldots,Z_M\) 排行。客户列按整数 mask 从 1 到 \(2^{|D|+2}-1\)，主题 0 是最低位，省掉全空类型。00 且非空背景的零列仍在。省全空列不改变秩或恒等式。
- basis(T,M) 对 \(d\ge M\) 返回空列表；其余按第 2 节显式公式输出。main 检查完整行秩、基向量矩阵秩及每个基向量与每一客户列点积为零。完整基长度来自代码构造，不另有一条 len(B) 断言；结合秩等于理论核维与逐列零积，实际足以认证有限点的独立完整基。
- background_rows 的 aggregate=True 使用分子 \(\sum_{c\in B}v_c\)，输出 \(H_0,\ldots,H_M\)。False 使用某标签会员指示，按 j 再按背景标签输出每位收益；main 只把此分支用于全单位背景。它不是把一般非单位背景总收益误作每位收益。
- 四槽索引为 r−1、M+(M−s)−1、s−1、2M−1。第二项是 \(Z_{M-s}=Z_r=U_b(q_s)\)，不是 \(Z_s\)；最后项是 \(Z_M=U_b(q_0)\)。
- 所有数值比较使用 Fraction 精确等式；没有容差。断言必须开启。以 Python 优化模式执行可能跳过断言及其中的 rank 调用，最终仍写 passed，故“看见 passed”本身不足以证明实际核验发生。
- 若中途断言失败，不产生本次完整新报告；旧文件可能仍在。此次使用全新目录并绑定 exit、源指纹与新文件，避免把陈旧输出当成新通过。

作者程序的枚举按 product((0,1),repeat=p)，含全空列，主题 0 为慢变位。本源是最低位 mask 且省全空列；两矩阵比较需要对应的列置换及删去零列，不能只按数组下标直接比。本源消元对主元上下行进行，作者实现为前向消元；它们语义一致而代码不同。“独立”准确指此处直接从会员与最终计数建列、没有导入作者实现，不意味着历史审查者从未阅读作者公式。
