## 3. 完整枚举与精确优化合同

对每个a,b∈{0,…,4}，程序在h+(a,b)算首位、末位及两人利润P=first+last，保全部25对，包括非最佳回复和不可作父SPE的对。固定a时，末位BR是所有达到最大last的b；从这些真实BR取首位最低收益ell_a，再取M=max_a ell_a。结果为

| 首位行动a | 全部末位BR | ell_a |
| --- | --- | ---: |
| 0 | {1} | 157/30 |
| 1 | {0} | 157/30 |
| 2 | {0} | 14/3 |
| 3 | {0,4} | 77/15 |
| 4 | {1} | 103/20 |

所以M=157/30。纯父资格恰是b∈BR(a)且first(a,b)≥M：其它有序孩子可分别选达到其ell的末位BR，当前偏离值至多M。代码得到全部纯有序末两行动与利润：

| (a,b) | 剩余两人利润 |
| --- | ---: |
| (0,1) | 157/15 |
| (1,0) | 157/15 |
| (3,4) | 53/5 |

纯最小157/15不是把任意终局或末位BR直接当父SPE最小值。

### 枚举全部截点为何给全最优

对每个固定首位a，允许末位在BR(a)中混合，概率λ_b≥0、Σλ=1，首位收益约束Σλ_b first(a,b)≥M。目标Σλ_b P(a,b)线性。这个概率单纯形加一条半空间的每个极点，或者是一个可行原点，或者恰由一低一高两个首位收益跨门槛的点组成；有三个正概率时可作非零扰动保归一化及取等的收益约束，故不是极点。相等端点已作为可行原点保留。

脚本先放所有纯可行点，再遍历每行动全部有序(lo,hi)∈BR(a)²，条件严格为u_lo<M<u_hi，并取
\[
t=\frac{M-u_{lo}}{u_{hi}-u_{lo}},\qquad
\lambda_{lo}=1-t,\quad\lambda_{hi}=t.
\tag{1}
\]
因此它遍历了每个首步LP的全部必要极点，比较全部a后的最小值，不只检查预先给定的一张混合证书。代码对所有达到最小值的候选再assert概率和1、非负/BR支持、首位收益≥M及目标值一致。

由此得到凸化最小311/30、严格差1/10，最优候选为首位3、末位0概率7/10/4概率3/10。唯一有自由度的BR行正是a3；其低/高点首位收益77/15、82/15，两人利润154/15、53/5。若末位0概率x，首位门槛要求x≤7/10，而两人利润53/5−x/3严格随x下降，故唯一最优x=7/10。

0/1两行动的利润157/15严格更高，2/4的唯一BR给当前值低于M，不能被当前采用。因此在此固定两人子博弈，允许首位自身再混合也不降低最小值：每个被采用首位分支的收入至少M、分支利润至少311/30，总利润只是这些分支的凸组合。达到最低只能纯选3。其余四个离轨末位节点各有唯一BR，所以这也是完整行为混合子SPE的唯一最优实际混合，而非仅一个低成本可行点。

这里的M来自最后一位全部真BR，等于原纯门槛。它与[多层凸递归发现器](../资源/纯续局凸化的精确点对探索与投影候选版本--资源.md)从relaxed孩子逐层重算widehat M不同：本独审不导入那个发现器，也没有重跑其浮点投影隶属LP。
