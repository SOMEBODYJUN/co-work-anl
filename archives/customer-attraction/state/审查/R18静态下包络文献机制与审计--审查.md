# R18 静态下包络文献机制与精确审计边界

## 1. 来源身份和清洗范围

本审查完整读取两个已认领来源。`literature_mechanism/README.md` 是 6,991 字节的工作台说明，SHA-256 为 `b23111c1dc3d48854a52659306b23542238c96ce173b3065c9437ab073425256`；它同时记录文献核验、一个精确 SPE 证书和仍开放的 GAP 候选。`audit_static_lower_envelope.py` 是 2,506 字节的独立 Python 审计脚本，SHA-256 为 `d053e5b86e385dd6e072e19d93c8487ea40015ba306300d8ed6536b310d5b77a`。脚本不导入项目内 CAG 求解器，而是从冻结的 25 客户证书逐客户展开，独立计算收益和福利。

README 还引用了同目录的静态证书 JSON；本轮用 `clean show` 只读导出并核对了最小证书（源 ID `c20cc352a689a12bc1de`，SHA-256 `3f4b85458c34b742755dc025c06949e84803ed5e867476c45aa4c80c2846e9de`）和完整审计（源 ID `098b9ccdc86ad20cd4d7`，SHA-256 `e46a7c80767c6f81d5b14c9d65adae4dc3d5a2c484b393088dab508e2fec3fad`）。这两个相关源不是本次认领对象；它们的只读副本仅作为本审计的输入证据保存在 `R18-literature-mechanism-agent/`。

## 2. 模型接口和文献导入边界

目标模型是有限单位客户集 (N)、有限非空共同主题目录 (mathcal Ssubseteq2^N)、(m) 名单位权提供者按固定顺序各选一个主题；每个客户在覆盖者之间均分，终局福利为覆盖客户数。完整纯 SPE 要求每一个有序历史上的后继策略都最优，目标是每个完整历史的终局福利至少达到六主题最优覆盖的一半。README 明确保持该目标 OPEN。

README 记录的文献机制都带有不能删除的条件：

- Deng 等工作在 §6 仍把超过两名玩家时的上界 2 写成猜想；这不能替代共同目录、全历史 SPE 的证明。
- Vetta 的 valid-utility 条件给单调次模静态行动博弈的半福利界。覆盖游戏的固定终局满足单调次模和总分配恒等式，但该结论针对静态 Nash 偏离。
- Bachrach–Syrgkanis–Tardos–Vojnović 的 ((1,1))-coalitional smoothness 结论要求 strong Nash 的联合偏离阻挡机制；顺序 SPE 只有单个行动者改变后真实后继重新响应，不能直接替换。
- Konda–Chandan–Grimsman–Marden 的 round-robin best response 是固定其他行动下的 myopic 更新，不是一次完整历史上的预见性 SPE。把轮数取为 1 也不改变后继策略会响应的事实。
- Groenland–Schaefer 的 extension-parallel 网络拥塞结论依赖路径结构；任意共同主题目录未给出该结构表示。Shapley 分配只说明固定动作下每个覆盖客户按 (1/c_q) 分摊，不能为顺序偏离稳定性加上新假设。

因此“覆盖分摊是 Shapley 值”“静态有效效用条件成立”以及“存在 myopic sequential update”都只能作为模型关系或导入警示，不能直接推出一般完整纯 SPE 的半覆盖结论。

## 3. 静态下包络为何不能替代真实离轨分支

固定一个终局动作向量 (a=(a_1,ldots,a_m))，对客户 (q) 的覆盖者集合记为 (C_q(a))，则
[
 u_i(a)=sum_{qin a_i}\frac1{|C_q(a)|},
 qquad \sum_i u_i(a)=W(a),
]
并且 (u_i(a)ge W(a)-W(a_{-i}))。这些都是固定动作向量的静态恒等式。

SPE 的行动者 (i) 在实际历史 (h) 上改选 (T) 时，比较的是
[
 u_i(\text{实际终局})
 \ge u_i(\text{由 }h,T\text{ 及真实后继策略产生的离轨终局}).
]
离轨后继可以改变其主题，因此右侧的客户覆盖数不是把其他玩家动作冻结后的静态向量。README 给出的简单两人定义级例子已经显示：若第二人的行为规则在首人选 (A) 后选 (B)、在空主题后选空主题，首人动作的参与边际可为 3 而其终局收益只有 1；这不是所有静态策略组合上的 valid-utility 条件。把一整张行为策略表当成一个静态动作也会遇到同一问题，因为表中每个节点的后继主题随首人偏离一起改变。

这正是本对象与已有 [R105 交叉分支审查](R105交叉分支与regret修复障碍接续审查--审查.md) 的共同接口：任何把真实离轨终局替换为“固定对手多重集”的求和，都已经换了模型。它也与 [R-18 动态利润机会边界](../障碍/R-18动态利润机会与非局部势边界--障碍.md) 相容：单步终局收益差不能独自支付失去动作槽及背景租金变化的非局部缺口。

## 4. 精确 25 客户、3 人、4 主题证书

### 4.1 输入与策略树

主题为 (A,B,C,D)，客户类型及重数为：

| 喜欢主题 | 客户数 |
| --- | ---: |
| (A) | 3 |
| (B) | 8 |
| (C) | 1 |
| (B,C) | 1 |
| (A,B,C) | 3 |
| (A,D) | 2 |
| (C,D) | 3 |
| (A,C,D) | 2 |
| (B,C,D) | 2 |

总客户数为 25。冻结证书的根动作是 (D)。第二人的动作规则在首人 (A,B,C,D) 后分别为 (B,D,B,B)。第三人的规则覆盖 16 个长度二历史；第三人每个历史的指定动作均达到其真实延续收益最大值。于是整棵树共 1+4+16=21 个决策节点。

沿实际路径 (D,B,B)，三人的收益为
[
 (u_1,u_2,u_3)=\left(\frac{23}{3},\frac{20}{3},\frac{20}{3}\right),
 \qquad W=21.
]
根动作的真实后继收益按 (A,B,C,D) 顺序为
[
 (7,20/3,15/2,23/3),
]
所以 (D) 严格优于其他根动作。第二人在每个首行动后的指定选择都达到该行最优值；第三人的 16 行由冻结证书逐行核验。因此这是一个完整纯 SPE 证书，而不是只验证了实际路径的局部最优。

### 4.2 静态纯 Nash 的完整枚举

同一客户实例的静态动作空间大小为 (4^3=64)。独立审计把 25 名客户逐个展开，对每个静态向量 (z) 检验每个玩家的四个单点改动作。结果恰有 6 个纯 Nash：(A,B,C) 的所有排列；每一个的覆盖福利都为 25，且 (mathrm{OPT}_3=25)。因此同一实例满足
[
 \min\{W(z):z\text{ 是静态纯 Nash}}=25,
 \quad W(\text{该完整 SPE})=21.
]
这严格否定加强桥
[
 W(\text{任一完整纯 SPE})\ \ge\ \min\{W(z):z\text{ 是同实例静态纯 Nash}}.
]
它没有否定主目标，因为 (21\ge25/2)。证书只说明静态下包络与顺序 SPE 之间不能建立该逐实例福利比较。

### 4.3 审计覆盖范围

`audit_static_lower_envelope.py` 的检查数量是可数且可复现的：

- 21 个有序历史，深度 (0,1,2) 的每个节点都与 4 个动作比较，共 84 个延续收益比较；
- 逐客户计算 25 人的单位收益，不使用类型计数压缩；
- 枚举 64 个静态动作向量，并为每个非均衡向量保留一个严格改善玩家、动作和精确改善量；
- 断言 6 个静态纯 Nash 全部福利 25、实际 SPE 福利 21、最优覆盖 25。

本轮将脚本与冻结最小证书置于 `R18-literature-mechanism-agent/`，独立重放生成的 `replay.stdout.json` 与冻结完整审计的 SHA-256 一致。该重放是有限证书复核，不是对任意主题目录或任意玩家数的穷举。

## 5. README 提出的 GAP 候选及当前状态

README 记录了一个比半覆盖更强的候选：对每个玩家 (i)，若其实际终局收益为 (u_i)，则
[
 m u_i\stackrel{?}{\ge} \mathrm{OPT}_m-W.
\tag{GAP}
]
对所有玩家求和即可得到 (W\ge\mathrm{OPT}_m-W)，所以 GAP 若对完整纯 SPE 成立就足以推出半覆盖。最后一个行动者的版本可以直接验证：把任意最优比较元组 (T_1,ldots,T_m) 与实际覆盖并集 (C) 比较，末人改选 (T_j) 可获得 (T_j\setminus C)，对 (j) 求和得到缺口的下界。早期行动者的真实后继会随其改选变化，不能把这些缺口逐项保持给同一行动者；`gap_floor_probe.py`、`gap_sparse_probe.py` 与 `gap_cone_lp.py` 只提供有限搜索接口。

因此 GAP 仍是待证候选。有限随机样本或固定策略锥中的线性优化没有给出通用定理；同样，四人或更高人数的公开摘要没有提供可直接合并为共同目录全历史 SPE 的完整动作矩阵。本审查不把这些数值或文献摘要升级为正面结果。

## 6. 可接续结论与明确限制

1. 可复用的负面结论是：静态 PNE 的最坏福利下界不能逐实例包住完整纯 SPE 的福利；静态 smoothness、Shapley 身份和 myopic 更新都不足以完成该替换。
2. 可复用的正面接口是：固定终局仍保有单调次模、客户级均分和 Shapley 解释；任何新证明必须把真实离轨后继纳入收益比较，并明确支付重复覆盖、比较并集外客户和删除当前玩家的项。
3. 该证书不是 `Q-CAG-HALF` 反例，不能与已有 R-18 动态利润机会族、R105 零 regret 修复障碍或其他客户模型合并成更强结论。每个对象的客户类型、量词、玩家数和终局历史必须保持独立。
4. 继续研究的合理方向是寻找 GAP 的真实早期玩家反例，或建立可处理后继改变的非局部势/总支付关系；在此之前，半覆盖命题状态保持 OPEN。
