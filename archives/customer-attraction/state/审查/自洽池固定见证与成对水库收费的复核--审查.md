# 删当前池化与保留静态信用的三个充分目标

固定m≥2及同一完整SPE σ，实际路径B、W=Σu_i。actual位置i在原实际前缀强制A后，沿同σ真实完成Z_i(A)，只删当前i槽得V_i(A)。对主题概率p定义

\[
q_T(p)=\frac1{m(m-1)}\sum_i\sum_Ap_A\#\{j\ne i:Z_i(A)_j=T\},
\quad \mu_x=(m-1)\sum_{T\ni x}q_T,
\]
\[
g_T=\sum_{x\in T}\frac1{1+\mu_x},\qquad
G=\sum_Tp_Tg_T,\qquad Q=\sum_Tq_Tg_T.
\]

q质量1、μ竞争质量m−1；p不是q，查询独立重抽。SC指supp(p)⊆argmax_Tg_T，所以在SC上G=max_Tg_T且Q≤G。m1不使用这个含m−1分母的构造；唯一玩家直接选最大主题即可覆盖最优。零客户所有量为0，不形成0/0。

任意m个合法比较主题T₁,…,T_m（允许重复），并集U、覆盖重数d_x。因d_x≥1对x∈U成立，逐客户有

\[
|U|\le\sum_{j=1}^m g_{T_j}
+\sum_x\frac{\mu_x}{1+\mu_x}
\le mG+(m-1)Q\le(2m-1)G.\tag{1}
\]

第一步来自1≤(d_x+μ_x)/(1+μ_x)，再把μ项求和扩大到全客户；它是静态代数，没有假定σ终局为PNE或把后继联合视为势最大者。父方复核因此区分以下三个充分目标：

| 在同一SC上的付款条件 | 对half的作用 |
|---|---|
| mG+(m−1)Q≤2W | 直接保留Q的钱包，由(1)足够 |
| (m−1/2)G≤W | 使用Q≤G后的较强充分条件 |
| mG≤W | 又更强，若成立则OPT≤(2−1/m)W |

m5相应为5G+4Q≤2W、(9/2)G≤W、5G≤W。不能因为最强桥未付就说half路线必须失败，亦不能把第一式已保留的Q信用拿去另一账本再付一次。一般half可以绕开这些机制，当前五人half的[另一证明](../定理/五人半覆盖--定理.md)不倒推出它们已成立。

自由分数安全值δ=min_q max_Tg_T≤G；真正整数竞争槽安全值v满足δ≤v。因此SC付款不反向推出mv≤W。该q是删当前、平均actual位置所得池化背景；[银行完整根菜单](../反例/笛卡尔银行完整根菜单的低值自洽分布失败--反例.md)中的K保根共m槽再加一个query，及其NQ/Mfull反例，是另一接口，不能将银行59/36的数字移给本q。

一般混合SC存在可由连续单纯形固定点证明；存在不付款。成熟[自洽池资源](../资源/自洽池与多槽交换的审查合同及旧池化反例--资源.md)已自足保留这一定义、DIAG和存在性，不重授固定点理论。原父稿说三桥“尚未对全部SPE证明”，本批材料也没有一般证明或否定其适当SC存在版本。

# 原固定p协方差计算的含义

程序均匀取actual角色I，独立A~p，样本为其删当前竞争元组V_I(A)，令L_x为该客户负载、μ_x=EL_x、α_x=1_(x∈A)。真实平均

\[
D=E\sum_x\frac{\alpha_x}{1+L_x}\le W/3.
\]

定义C_cov=Σ_x E[α_x(L_x−μ_x)]/(1+μ_x)²，以及非负

\[
R=\sum_xE\frac{\alpha_x(L_x-\mu_x)^2}
{(1+\mu_x)^2(1+L_x)}.
\]

逐样本倒数展开恒等式给D−G=−C_cov+R。源码确assert这一恒等式并把C_cov−R存为`weighted_covariance_minus_weighted_curvature`，即G−D；它不是将C_cov或R各自存成一个已付款总额。表中635项13539/340340乘三正是3G−W，因为D=W/3；16项还要加回W/3−D=1/9，不能混成同一客户输入。

这些是两指定p的原精确结果；源没有在所有SC上证明C_cov≤R+W/3−D，也没有将固定16/635两例提升为任意policy定理。没有导入作者程序是实现独立性，两个旧见证事先已知，不能称盲发现。
