# 两步安全归纳失败与策略锥精确边界

## 来源范围与共同模型

两份来源都使用 CAG 共同有限主题目录模型：单位价值客户，单位提供者顺序选择主题，客户在最终覆盖者之间均分；策略在全部有序历史上定义并要求纯 SPE。它们不是异构设施模型，也不是按提供者同时行动的客户负载博弈。空主题、重复主题、离轨历史和平局都保留。

两份源在 legacy-cleanup 提交 68fad804ec5946cb296f77dc5b336308a66abf12 与 main 提交 aefc58eac3fc6eb5d7a47d087dd2c62b5aa9974c 的内容相同。源文本是研究记录和精确证书说明；下文区分固定策略/固定证书上的精确事实与任意完整SPE或任意客户类型的全称目标。

## policy_security_source：固定安全锥和86客户完整树

### 二十一棵固定策略锥

来源给出一组不同于既有36、61、89客户树的完整形式策略：

- 19棵 n=5,m=7 树；
- 1棵 n=5,m=8 树；
- 1棵 n=6,m=8 树；
- 共 95,349 个有序节点、709,573 项比较、20,971 个精确坐标恒等式。

在每棵固定完整形式策略的全部非负客户类型重数锥上，存在一个共同合法静态 Q 支付所有查询。证书使用全 Γ、w≥0 和 W=1 归一化，未删去真实离轨行；查询可以使用全部真实历史的非负 Γ 乘子，Q 不依赖查询分布 p 或客户类型重数 w。因此这是固定策略锥的精确存在证书，不是对任意完整策略、任意目录或六人half的证明。

菜单和规则与既有三锥不同：包含动态有序组触发、两标签菜单，以及三组 (2,2,3) 的横截补集、跨组边、定向回复、组核心加横截四种关联。三种每历史平局选择（随机、先前玩家份额最小/最大）分别保留。浮点搜索只生成候选；最终证书和独立检查使用 Fraction。源没有声称每条规则都实现七个不同极大主题，也不能把21棵固定树累计成一个普遍Q定理。

### 五人十极大主题的完整SPE

另有一棵五人、十极大主题、86个单位客户的完整纯SPE。根路径为
\[
(4,5,6,7,8),\qquad
(u_1,\ldots,u_5)=(81/5,86/5,86/5,86/5,86/5),
\]
实际福利 W=85，最优覆盖 OPT=86，静态安全值 v_5=2262/139。根玩家的严格安全亏损为 51/695，后四人的盈余均为 644/695，总余额 505/139>0。全部 11,111 个有序决策历史和111,110项比较都按 Fraction 检查；十个极大主题两两不同且互不包含。

客户类型由两组五标签的25种遗漏对（通常重3，特殊对 (4,9) 重4）、分别遗漏单个特殊标签的辅助群（各重4）以及两特殊私有群（各1）组成。生成快照参数 Space(5,10), seed=401, mode=root_min 和目标终局计数只用于复现。该树没有共同 Q 全锥上界认证；固定安全分布和少量交替查询的聚合值为1，未发现正的双早位 δ，都不能升级为整个客户锥的证明。

### 2+3 尾部目标的不可能证书

同源还给出一个五人两组结构的必要可信失败。两组各五标签的25种遗漏对各重3，共75单位客户；尝试路径为 (3,4,5,6,7)。真实前缀 (3,4,5) 后，第四位偏离到0，末位在十个主题上的收益为
\[
(143/10,\ 303/20,\ 303/20,\ 143/10,\ 143/10,\ 69/5,\ 297/20,\ 297/20,\ 297/20,\ 297/20).
\]
末位只能选1或2，二者都给偏离的第四位 303/20，而目标第四位收益为 151/10，故该路径在每个完整SPE中都不可能实现。two_three_tail_check.py 只使用 Fraction 和25个单位类型，是两层必要比较的独立检查；它是一个指定目标路径拒绝证书，不是完整策略树的福利half反例，也没有证明所有参数或所有路径都失败。

## security_chain_source：113客户中的两种局部归纳失败

### 两个被否定的局部接口

对固定背景负载 b 和 r 名剩余玩家，定义静态安全值
\[
v_r(b)=\max_{p\in\Delta(\mathcal S)}
 \min_{B\in\mathcal S^{r-1}}
 \sum_A p_A\sum_{x\in A}\frac1{b_x+1+c_x(B)}.
\]
源曾希望沿实际首动作 A 证明
\[
u_A+(r-1)v_{r-1}(b+A)\ge r v_r(b)
\tag{Full-step}
\]
或弱一些的
\[
u_A+(r-\tfrac32)v_{r-1}(b+A)\ge(r-\tfrac12)v_r(b).
\tag{Weak-step}
\]
它们是逐步把静态安全值传给顺序福利的局部归纳式，不是 Q-CAG-HALF-6 本身。

### 113单位客户的精确失败

输入有三名单位提供者、六主题共同目录、113名不同单位客户，完整纯策略有43个有序历史和258项动作比较。策略根选0；第二位在首主题属于 {0,1,2} 时选3，否则选0；第三位在有序历史 (a,b) 后，选择 b 所属三标签组中最小尚未出现主题。该规则在全部43个历史有定义。

实际路径为
\[
z=(0,3,4),\quad
u=(95/3,110/3,110/3),\quad
W=105,\quad \operatorname{OPT}_3=113.
\]
匹配静态鞍点给出
\[
v_3(0)=\frac{1035446642}{32182199},\qquad
v_2(\mathbf1_0)=\frac{10259}{318}.
\]
代入两步式得到确切负差
\[
\frac{95}{3}+2v_2-3v_3
=-\frac{571165576}{1705656547}<0,
\]
\[
\frac{95}{3}+\frac32v_2-\frac52v_3
=-\frac{7739134297}{20467878564}<0.
\]
更短的夹逼也足够：查询 p=(1,1,2,1,1,2)/8 在21个无序竞争背景上的最小值为385/12，故 v_3≥385/12；固定背景0后，竞争者以3/5、2/5取1、2时六个纯查询值中最大为484/15，故 v_2≤484/15。这给 Full-step 左差至多 -1/20，Weak-step 左差至多 -17/120，不依赖鞍点求解器把候选误作最优。

### 全局债务望远镜仍为正

源没有把逐步失败误写为全局失败。令 r_i=n-i+1、b_i 为实际过去背景、t_i=v_{r_i}(b_i)，并定义
\[
d_i=u_i-t_i+(r_i-1)(t_{i+1}-t_i),\qquad i<n.
\]
精确望远镜恒等式为
\[
\sum_{i<n}d_i=W-nv_n.
\]
所以目标弱桥等价于总债务 \sum d_i≥-\tfrac12v_n，而不是要求每个 d_i≥0。在113例中，首债
\[
d_1=-\frac{571165576}{1705656547}<0,
\]
末债 d_2=467/53>0，但净量仍为
\[
W-3v_3=\frac{272790969}{32182199}>0,\qquad
W-\frac52v_3=\frac{790514290}{32182199}>0.
\]
因此这是真实局部归纳失败、而非福利或half反例。两路独立 Fraction 审计逐项重放43历史、258比较；优化器只用于早期候选，未用于数学认证，未认证113客户最小性、世界新颖性或外部同行审查。

静态 iid 基准还可给出 n v_n≤Z_n≤OPT_n，但它不约束任意顺序SPE的实际 W。全局弱桥和六人目标仍需控制完整历史的逐偏离约束。

## 与既有对象的比较和去向

1. [逐人安全与全树流增量审查](../审查/逐人安全与全树流增量审查--审查.md)已保存34、360客户完整SPE中的局部安全值失败、全树流和固定策略锥障碍；本批113客户给出同一三人六主题模型中两个明确一步归纳式的精确负差，并以净债正值保留局部/全局差别，不重复创建34/360反例。
2. [完整策略树平均与独立同分布福利桥](../障碍/完整策略树平均与独立同分布福利桥--障碍.md)已证明每个真实逐历史偏离必须有独立 Γ行，并保存删除位置余项不能丢弃的恒等式；113客户例正是该“总债务可正而首债为负”现象的具体算术实例。它没有把本批的局部式误升成流平均失败。
3. [极大关联前沿审查与七极大边界](../审查/极大关联前沿审查与七极大边界--审查.md)的七极大 n≥7 证书和五/六人轨道缺口，和本批五人十极大86客户树使用不同极大数与量词；本批不能补齐其七极大缺失轨道，也不能推出六人half。
4. [四人根税独立上传与传输接口增量审计](../审查/四人根税独立上传与传输接口增量审计--审查.md)处理四人61客户根税和传输整合；本批的三人113与五人86来源是不同输入和不同局部安全接口，不能合并为一般税定理。

## 处置、接续与限制

两源均处置为 integrated 到本审查对象。固定策略锥证书、指定路径拒绝证书和113客户局部负差各自保留其精确模型、输入、量词和复现信息；没有把它们合并成一个“安全失败”定理。它们共同支持的接续方向是：寻找能容纳负的早期 d_i 而仍控制总债务的全树不等式，或直接证明/反驳六人half；不能用 Full-step、Weak-step、固定 Q 锥、有限浮点搜索或单一完整SPE替代全称目标。

本对象没有运行新程序，使用来源写出的完整 Fraction 数值和与既有对象的逐段比较；没有外部同行评议、新颖性认证或六人half结论。
