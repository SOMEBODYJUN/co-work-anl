README 的研究路线是：Q-CAG-HALF 在一般共同目录、任意人数和全部有序历史纯 SPE 上仍开放；五人已有闭合材料，六人及一般人数不应从五人图直接外推。下一步要保留中间玩家跨分支偏离和真实后继，研究统一支付源收益、实际末位价格和分母返还，不能先冻结后继再套静态复制归约。

README 引用的固定见证使用六名提供者、五主题和45个单位客户。`exact.json` 与 `verify.py` 的精确递归枚举根及固定首主题孩子的全部有序历史纯 SPE：终局计数唯一为 `q=(1,1,1,2,1)`，根可实现路径为 `(0,3,3,4,1,2)` 与 `(0,3,3,4,2,1)`。规范求解器和独立单位客户实现分别核验3906个决策历史/15624项偏离及3906个历史/19530项含自身比较，最小激励松弛为0。

见证的路径收益为 `(31/3,23/3,23/3,20/3,19/3,19/3)`，福利 `W=45=OPT_6`。若第四位把主题4静态复制为主题0并冻结其他行动，收益从 `20/3` 变为 `41/6`，静态增益为 `1/6`；但真实偏离触发后继重置，路径为 `(0,3,3,0,4,1)`，收益变为 `37/6`，真实增益为 `−1/2`。静态与真实之间的 `2/3` 损失来自 `{0,4}` 客户分母从2变3。计数唯一也不能冻结离轨策略。

这否定的准确辅助命题是：在所有首主题为固定 `T` 的纯 SPE 后继中，达到最小先入主题收益的后继，必存在对“把任一后继动作静态改成T并冻结其余动作”稳定的最低叶。它不是 SPE 定义，也不是半覆盖等价命题；见证本身没有福利损失，不能作为 Q-CAG-HALF 反例。

接续时应保留真实后继及其分母重置损失，或证明该损失可由共同银行支付。旧的 `OPT≤W+Σc/(c+1)` 仍是开放候选；README 明确不把旧候选和有限阴性扫描当作新成果。
