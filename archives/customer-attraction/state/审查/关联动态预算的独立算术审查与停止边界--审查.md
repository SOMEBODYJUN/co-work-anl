# 一般LP接口确可修复，不能按原中间式原样引用

长度t前缀的路由数为p_j，r=n−t≥1、p_I=Σ_(j∈I)p_j。核心外辅助值是

\[
f_j^*(p,r)=\frac{w_{\{j\}}}{p_j+1}+
 \sum_{\substack{I\ni j\\2\le|I|\le s-1}}\frac{w_I}{p_I+r}.
\]

只对非核心类型定义

\[
B_*(r)=\min_{\beta\ge0}\left\{\sum_j\beta_j:
 \beta_j\ge1\ (w_{\{j\}}>0),\quad
 \sum_{j\in I}\beta_j\ge r\ (w_I>0,2\le|I|\le s-1)\right\}.
\]

β_j=r保证可行，有限LP最优可达，U>c使B_*(r)≥1。设D_t=t+B_*(n−t)、E_t=max_(t≤q≤n−1)D_q，E_t随t不增。取最优β及y_j=p_j+β_j，按每个私有/共享客户的系数分别计数：

\[
U-c\le\sum_jy_jf_j^*\le D_t\max_jf_j^*.
\tag{COUNT}
\]

对所有有序前缀同时逆向归纳，当前实际偏离到f_j^*最大的**完整**B_j。如果之后无人路由j，私有客户终局负载≤p_j+1，共享非核心负载≤p_I+r，核心负载≤n，直接收益至少c/n+f_j^*。如果有后继路由j，其真实主题A⊆B_j；在该同一终局中偏离者逐客户支配后继的**总收益**。后继归纳下界为c/n+(U−c)/E_q，q>t、E_q≤E_t，故两分支均保证c/n+(U−c)/E_t。末位只能是第一分支，当前SPE最优性把偏离保证转给规定动作。于是

\[
\boxed{W\ge c+(U-c)\sum_{t=0}^{n-1}1/E_t.}\tag{LP}
\]

原LP若保留核心约束，其B(r)≥B_*(r)，原后缀包络也更大，故原最终(LP)仍由较强修正版推出。被否定的是两条字面中间保证，不是最终福利式或half。该完整重构已在[正式动态预算](../定理/极大关联LP动态预算半覆盖--定理.md)存在，本页承担原独立审查的准确来源和异议，不再认作新定理。

原统一β_j=r/2只在r≥2时支付私有需求；r=1须另外取β_j≥1。这与[原动态路由机制](../定理/极大关联LP动态预算半覆盖--定理.md)的分情形一致，不能从作者势路线中省略的端点直接外推。

# 两个不同的中间式真反例

**核心双算。** n=1，目录B₁={x,a}、B₂={x,b}，C₀={x}。原f将核心w_[2]=1放入共享和，给f₁=1+1=2，又另加c/n=1，字面声称收益≥3；实际唯一玩家选任一合法主题都恰得2。两动作并列最优，完整纯SPE存在。修正f₁^*=1后c/n+f₁^*=2。这是一般候选中间式的最小反例，不反六人half。

**同路后继。** n=2，目录为大小100与1的两个不交极大覆盖。在首位选大主题之后，末位重复大主题得50，换小主题得1，故必须重复；首位实际得50，而p=0时f₁^*=100。末位在“小主题”历史后也必须选大主题（100>1/2）；根选大主题得50，选小主题得1，因此这还给出完整严格续局的纯SPE。它否定“任何偏离直接获得f_j^*”的独立保证；正确证明使用同路后继50的归纳支配，不使用错误分母100。两例均由原脚本核算，但完整SPE理由来自本段解析，不由脚本搜索得到。

# 分数覆盖身份、产品支配和真实增量

令τ_inc为极大主题上的非负分数覆盖最小总重，每个正客户类型I要求Σ_(j∈I)α_j≥1。对非空V，它恰为整个V由**合法主题**覆盖的普通分数覆盖数τ_V：把任意内部主题权移给一个包含它的极大主题，总重不变且不减覆盖；反向极大主题本来合法。U>c时，即使只列非核心约束，至少一条约束已使Σα≥1，核心自动覆盖，所以修正残余LP仍同值。U=c时先用W=U，不能把空残余LP最优0代入正客户的τ公式。

对任意最优n主题并集D⊆V，限制目标客户只会减约束，故τ_D≤τ_V=τ_inc。此静态参数比较不许可从博弈删除内部行动或客户。

取β=rα得B_*(r)≤rτ_inc；t+rτ_inc随t不增，故E_t≤t+rτ_inc，(LP)推出

\[
W\ge c+(U-c)S_n(\tau_{inc}),\qquad
S_n(\tau)=\sum_{r=1}^n\frac1{n+(\tau-1)r}.\tag{SUM}
\]

既有[真实前缀利润预算](../引理/分数覆盖的真实前缀利润预算--引理.md)对任意非空可覆盖D、O=|D|和可行总权τ，令实际P_i=Σ_(j≤i)u_j，给

\[
O\le P_{i-1}+r\tau u_i,\quad
W\ge O F_n(\tau),\quad
F_n(\tau)=1-\prod_{r=1}^n(1-1/(r\tau)).\tag{PRODUCT}
\]

简证其关键付款：第i位前真实客户负载b_i，定义g_i(T)=Σ_(x∈T∩D)1/(b_i(x)+r)。每个真实改选T的后继负载≤b_i+r，所以g_i(T)≤u_i。逐客户有O≤Σ_(j<i)g_i(S_j)+rΣ_Tz_Tg_i(T)；同一实际终局的负载≤b_i+r，使旧项g_i(S_j)≤u_j。得到前缀式并以非负因子1−1/(rτ)递推。整个过程保留原完整σ，不混用离轨旧利润。

PRODUCT的系数对全部n≥1、τ≥1支配SUM的系数。令a=1/τ，归纳得

\[
\prod_{s=r+1}^{r+t}(1-a/s)\ge r/(r+at).
\]

归纳步清正分母的差为a(1−a)(t+1)≥0；将F_n望远镜展开成Σ_r(1/(rτ))∏_(s>r)(1−1/(sτ))，逐项得到F_n≥S_n。这个解析支配不依赖原脚本的n=5,6,7样本。

历史审查时已有F₅(7/2)=8656/16807>1/2，F_n随n非减；n≤4另用当时一般人数定理。因此τ_D≤7/2是全人数half充分类。τ_inc≤2、τ_inc≤3且n≥7、以及每个非核心客户度数≥d且s≤2d（均匀α=1/d）给出的half类全部已被包含。当前[恰六人9/2定理](../定理/六人分数覆盖条件半覆盖--定理.md)更只要求某个最优D的τ_D≤9/2，依靠额外真实末对关系；不是把PRODUCT直接代τ=9/2。

这不等于支配全部(LP)或带c加法信用的(SUM)。PRODUCT的U·F_n≥U·S_n，不能自动推出U·F_n≥c+(U−c)S_n。动态LP又把私有需求1和共享需求r分开，其B_*(r)可能优于统一rτ。原独立审查明确保留此一般接口的真实增量，所撤回的是“阈值half新增覆盖范围”的解读。
