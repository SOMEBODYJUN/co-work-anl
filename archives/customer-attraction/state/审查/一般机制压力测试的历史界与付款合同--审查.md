# 前缀编译与末层金额：两个一般工具的输入缺口

原新增前j位可信退出编译适用合法(m,j)，把旧赤字gap改成gap−(2j+1)s；m5、j1/2/3/4代入分别减3s/5s/7s/9s。即使取银行s=退出缺陷Δ，也还要旧赤字与Δ的控制；等价攻击表示本身不给新福利界。沿旧策略删除后的局部regret，与在真正完整孩子SPE集合中极小当前收益得到的Δ，分别有不同域，不能仅凭都是“缺陷”替换。成熟[编译/读序审查](前缀编译与阈值端点的真实审查读序--审查.md)另保具体证明与证据。

末层多孩子工具固定actual叶B及仅换末位的孩子V^α。p_j(F)=Σ_(x∈F_j)1/c_F(x)，j<m为prefix sender。承重的共享金额合同是

\[
\sum_\alpha\lambda_{\alpha j}p_j(V^\alpha)\le p_j(B),\qquad\lambda\ge0.
\tag{AMOUNT}
\]

标准正价q_(α,jm)=Σ_(x∈B_j∩(B_m\V_m^α))1/[c_B(x)c_α(x)]。末位只换一个动作使p_j(V^α)≥p_j(B)/2；正利润sender有Σ_αλ≤2，零利润sender无客户、q0不除零。末位原负载c≥2客户被移走时，c−1个sender共同贡献≤2/c；c1无sender。因此全部孩子合计输出≤2p_m(B)。这是任意合法叶代数，不需SPE；更深cut改变整个suffix，不能沿用这两个负载恒等式。完整定理、锐族及固定输入最大列式复用[末层cap2](../定理/末层多孩子金额预算的锐两倍列容量--定理.md)。

**旧单孩子系数回推不供应AMOUNT。** 任意m≥2、n≥1客户的目录{A,空题}，全部有序历史恒A为完整SPE：跟从利润正、改空题0。B=A^m时各p_j(B)=n/m；末位强制空得到V，sender有p_j(V)=n/(m−1)、q=n/[m(m−1)]。旧λ_j=1回推的每个retained为n/m、末位共收n/m，总额恰W=n且所有角色旧系数1，却每个sender输入n/(m−1)>n/m，违反AMOUNT。缩λ至(m−1)/m也会同时缩小所支付的债，不能隐去差额。完整零端点与合同分离复用[已存引理](../引理/单孩子系数回推不能代替源金额预算--引理.md)，不重复授新数学。

需要另构造跨孩子共同份额，使所有sender总额各≤自身actual利润并扣已有direct/suffix支出；局部cap2没有完成这一初始化。原DEEP-CAP2在当时未证也无反例，有限旧证书未分离不提升真值；其当前可用合同以[源金额续审](源金额与坐标双预算的内部续审和有限校准--审查.md)为准，不凭本8源宣告一般付款已闭合。
