# 1. 连续窗口区间租金源

冻结源 `67dd19b565beb22ad3db` 是 `interval_independent_audit.json`，大小 802 字节、SHA-256 `90b5a4e116f4b58bc52632b880863d77072a7764d00c7bafdfc5c7462e8bf26f`。它的状态为 `independent exact finite audit; universal proof in review`，计数 `cases=151586`、`seed=171021`。模型允许任意有限实际主题路径、零客户、重复主题和任意窗口，但窗口必须从前缀终点紧接开始并包含中间所有槽位；reserve `rho>0` 是代数参数，不是目录行动，也不使用 SPE 最优性。

父方的逐客户排名证明给出：若前缀负载为 `b_j(x)`、窗口新增命中为 `q_j(x)`、全路径命中数为 `c_x`，并令 `Gamma` 为加权窗口覆盖上界，则

\[
E_j^{(rho)}=\sum_x b_j(x)\left(\frac1{b_j(x)+rho}-\frac1{b_j(x)+q_j(x)+rho}\right),
\qquad
\sum_j theta_jE_j^{(rho)}\le Gamma\sum_{x:c_x>0}\left(\frac1{rho+1}-\frac1{rho+c_x}\right).
\]

该 JSON 是该解析引理的有限实现核验，不替代证明。其精确边界表为：稀疏族 `q=1,2` 与错误细界相等，`q=3` 的差为 `1/180`，`q=8` 的差为 `89/1680`，`q=64` 仍为严格正有理数；`rank2_cost=1/4`。另一条 `1010` 路径说明两个宽二窗口可以同时收费到第二次命中，撤回“第二次命中只能被一个非零窗口收费”的加强，但不攻击 Gamma 原界。

若取消“紧接前缀”的连续性，可取 `m=2q`、单客户先命中一次后跳过 `q-1` 个槽位再命中 `q` 次，并令第 `j` 行只打到第 `q+j` 槽、权重 `1/j`。此时 `W=Gamma=1` 而费用为

\[
\frac{H_q}{(rho+1)(rho+2)},
\]

随 `q` 发散。这是否定稀疏跳过的路径级支付界，不是完整 SPE 或 Q-CAG-HALF 反例。既有 `R-171区间路径租金有限审计与非连续槽反例` 与连续窗口审查页承载主推导；本源新增的是 151586 计数、固定 seed 和精确边界表。

# 2. 早期真实菜单负载缺陷源

冻结源 `2413e95a47f7e647a302` 是 `early_menu_load_defect_audit.json`，大小 351 字节、SHA-256 `5d0d64a13cec377149338a9515f82bdd3281d630a9f0bf38a4ff31f93ae1349f`。状态为 `all exact local algebra checks passed`，范围明确写着 `finite implementation audit, no SPE claim and no general welfare proof`。计数为：`identity_and_envelope_cases=14288`、`parametric_corner_cases=540`、`relaxed_range_sharpness_cases=300`、`unloading_actual_rent_cases=352`、`global_actual_residue_cases=80`，seed=`202610215`。

对象固定任意合法有序历史 `h`、当前主题 `A`、真实中继 `M_A` 和真实末位 `B`。偏离主题 `T` 必须沿同一完整策略重放真实中继 `M_T` 与末位回复 `R_T`；不能冻结为 `M_A`。以真实前缀负载 `p`、真实中继负载 `ell_A`、偏离中继差 `Delta_T` 写 `d=p+ell_A`，逐客户差额

\[
xi_T=\frac1{d+1}-\frac1{d+Delta_T+1},\qquad
zeta_T=\frac1{(d+1)(d+2)}-\frac1{(d+Delta_T+1)(d+Delta_T+2)}.
\]

有限审计核对 `G_0=G-tau epsilon(mu)`、`delta(mu)=epsilon(mu)-V/tau^2`、参考背景角点包络、Gamma 范围、全卸载 `epsilon_*<=3P_M/8` 及根包络的局部条件。由真实末位回复得到的 `V/tau` 信用只能给条件性消元；`epsilon` 的一般实际福利支付、完整全树运输和 Q-CAG-HALF 仍未完成。`tau<1` 需要先归一化后乘回，不能直接套 `tau>=1` 的角点论证。

既有 `早期真实菜单负载缺陷引理独立审查` 与 `早期菜单负载缺陷独立Fraction审计` 已承载解析恒等式、epsilon/delta 关系、零缺陷条件和固定 SPE 边界。本源独有的是上述实现级计数和 seed；全仓另有更强版本的 43776/14592/10944 等计数，但属于不同脚本/版本，不可回填成该冻结 JSON 的字段。

# 3. 处置与开放边界

两个源版本均 `integrated` 到本页、各自原始证据副本和已有计算/审查对象。区间源保留连续窗口是承重条件、稀疏跳过的调和发散和 rank-2 失败；菜单源保留真实中继随偏离改变、epsilon/delta 的带符号缺陷和只在单调/卸载条件下为零的边界。任何有限 `passed`、有限计数或固定路径输出都不能升级为任意完整历史纯 SPE 的支付定理、一般混合安全值、静态 CCE 桥或六人 half 结论。
