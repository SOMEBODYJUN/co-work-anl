# 对象与审计边界

这五份源不是新的六人半覆盖证明。两个 JSON 是冻结运行结果，两个 Python 是
不导入模型、求解器或另一审计的独立 `Fraction` 重建，Markdown 是随后对正式
机制稿的逐式交叉审查。它们共同审计 `CA-TERMINAL-TIE-QUOTIENT-LIFT`，并应
与“固定乘子提升的商空间边界”障碍对象和“末回复规范化的条件性对偶提升”定理
分别相连；不能把有限通过读成一般输入证书或 half 结论。

## 独立三人重建

`customer_attraction_terminal_tie_independent.py` 固定三位玩家和三客户
`AB,C,BC`，主题类型顺序为 `A,B,AB,C,AC,BC,ABC`，从 13 个完整有序历史
逐项计算真实终局收益。它检查全部 `13*3=39` 个指定/偏离比较，并以
`Fraction` 重建同计数末位规范化：

* 273 个全类型变换恒等式、63 个互反行恒等式、63 个按未覆盖类型分解的恒等式
  全部通过；原策略根终局为 `(C,A,C)`，实际和最优三主题福利均为 `3`。
* 自然目标 `d=2c-o=(1,-1,1,1,1,1,1)` 的重选早期乘子 `(2,1,1)` 给出
  `r=(0,0,1,1/2,5/6,2/3,1)`。运输后余项含负坐标 `-1/2`，但用
  `-2 tau_AC+3 tau_CB`（两条真实末位互反行）支付后得到
  `(0,0,0,0,4/3,2/3,1)`，故该证书可严格提升。
* 同一目标的固定早期乘子 `(4,1,2)` 给规范余项
  `(0,0,1,0,1,0,1)`，运输后为
  `(0,-1/2,1/2,-2,1/3,0,1)`。合法单位客户质量
  `w=(0,0,1,1,0,1,0)` 对它的内积是 `-3/2`，而所有结构性末位等式在该
  `w` 上为零；因此没有等式空间修正或任何额外非负原行能够保持这组固定乘子。

该失败是一个固定证书提升障碍，原实例仍满足 `W=OPT_3=3`，不构成半覆盖
反例。

## 商空间审计的独有回归

`customer_attraction_terminal_tie_quotient.py` 在同一三人实例之外做三类精确
回归：

1. **四边真实消去。** `m=3,n=4` 的 40 节点策略中，逐行检查 840 个类型
   系数；四条真实运输边的误差严格为零，但两个改变叶的 incumbent 入流分别
   为 `(0,1,-1)` 与 `(-1,0,1)`，所以“误差为零”不等于每个局部入流都为零。
2. **跨计数支付。** `m=2,n=4` 的单行误差精确为 `(-1/6,0,0)`。它不在
   一个固定计数 reciprocal 行的张成空间中，却由跨计数系数 `2/5` 和 `-3/5`
   的两条真实 reciprocal 行共同支付。这确认跨计数商空间扩大，但不提供任意
   目标的全局证书。
3. **局部二次判别。** 对三组 `q`、`b` 和有限系数枚举共 8019 次，系数
   恒等式与全部非空类型恒等式一致；另一个 `q=(1,0)` 例明确发现只用
   `N=pJ` 会漏掉 `p=0` 的外部 singleton 约束。故局部二次判别必须额外要求
   `eta_i=0` 对所有 `q_i=0` 的分量成立。
