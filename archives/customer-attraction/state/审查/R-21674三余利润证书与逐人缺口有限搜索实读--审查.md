# 1. 对象和范围

本页处理 R-21674 工作区的 20 个冻结源版本。模型是有限单位提供者按完整有序历史选择客户目录，客户在覆盖者之间均分；本批实际数学分支固定在“根后恰三名余下提供者”的利润机会、逐人收益缺口、有限策略锥和条件 Gram 切面。它没有把 R-216 的历史入口改写为六人一般结论。与既有《六人协调前沿与逐人缺口探索的范围证据》衔接时，仍保留空主题、重复主题、零客户、离轨历史和任意平局的模型语义；本批没有新增真实客户/SPE 实例。

原字节、冻结 commit、大小和 SHA-256 见 [source-manifest](../../tools/evidence/R21674-20261031/source-manifest.json)，脚本实际运行输出见 [evidence README](../../tools/evidence/R21674-20261031/README.md)。本页所说“重放”均指 `clean show` 取出的冻结代码在临时依赖适配后运行；没有把本地缓存当作源版本。

# 2. 三余利润机会的精确证书

## 2.1 源定义

`earlier_menus` 的 `audit_three_profit_opportunity.py` 明确声明：在固定合法背景、剩余三名单位提供者和所有 $8^3$ 二值菜单成员/全部八个实际成员枚举上，审计候选

$$F_3(p)-R\le 3u_A,$$

其中 $F_3(p)$ 是三名余下提供者对比较主题的最大总利润，$R$ 是实际三名余下提供者的利润和，$u_A$ 是第一个余下提供者的收益。它的代码没有调用项目游戏求解器，也没有用浮点发现：对 4096 个状态构造 12288 个有理系数，公共倍数分母为 544124，12 个乘子分子为

$$
(519972,117252,13770,56748,133446,11475,442,15623,14853,12558,31620,2295).
$$

输出 `three_profit_opportunity_audit.json` 报告 `negative_coefficients=0`，三个系数族的最小值均为 0；`profit_endpoint_certificate.json` 报告 93 行、960 个状态、2880 个系数，`min_coefficient_slack=0`。代码注释把从有理二次分子到任意背景 $p$ 的延伸写成“quadratic formula”；本页接受的数学范围仍是该代码枚举的三余利润证书接口，未把它扩展到任意余数、总覆盖或六人 half。

## 2.2 独立重放

在本批临时把同批 `probe_tax_endpoint.py` 与 `probe_branch_endpoint.py` 以其原模块名放入独立目录后，重跑 `certify_profit_endpoint.py`：LP `success=True`，浮点目标和为约 `1.7092684755680687`；将所有非零权重以分母上限 $10^6$ 转为 Fraction 后，`maxden=1000000` 时最小 slack 为 0，负 slack 数为 0。较小分母仍有负 slack，说明精确重构阈值是这次运行的一部分，不能把未经重构的浮点乘子当证书。

因此本批可以把三余的“利润机会 ≤ 三倍首位收益”作为**条件结论**接入后续数学链：它只支付三名余下提供者的利润机会，不直接支付客户覆盖，不给出 $OPT_6\le2W$，也不说明任意完整历史都满足该候选前提。

# 3. 统一乘子探针的失败边界

这些脚本用有限背景、有限二值成员或有限 $	au/k$ 采样寻找非负线性乘子。它们的可行性状态是障碍证据，不是一般不可能性定理。

| 探针 | 实际重放 | 数学处置 |
|---|---|---|
| `probe_branch_endpoint.py` | $n=3,4,5,6,8,10$，分别 960、5280、19008、54912、308880、1244672 行；全部 HiGHS infeasible | 固定行族下没有找到统一乘子；不排除改变行族或证明路线 |
| `probe_tax_endpoint.py` | $n=3$ 的 $(960,93)$ LP feasible；$n=4,5$ 的 $(5280,93),(19008,93)$ infeasible | 三余端点仍有局部可行证书，但不随人数自动延伸 |
| `tail_three_price_probe.py` | $k=3,4,5,6,8,10,15,20,30,50,100$ 的含最小项 LP 全部 infeasible | 不能把有限三余价格行直接提升为尾长不变式 |
| `probe_opportunity_coeff.py` | cover 的 $C=2,2.25,2.5,2.75,3$ 全部 infeasible；profit 的 $C=2,2.25,2.5,2.75$ infeasible，$C=3$ feasible | profit 的 $3u_A$ 只在本行族出现；cover 版本没有同一常数 |
| `probe_three_endpoint.py` | $	au=1,1.25,1.5,2,2.5$ feasible；$	au=3,4,5,10,25$ infeasible | 这是一个参数有限切片，不能描述所有比例 |

`template_primal.py` 和 `template_realize.py` 把 LP 权重尝试实现为对称客户分布，`template_realize.py` 还对排列轨迹重分配；本批阅读了其构造，但没有把浮点 LP 解升级为真实 SPE，因为源码没有对所有完整历史逐项给出 exact IC/BR 证书。

# 4. 条件 Gram 切面

`gram_probe.py` 在固定 $P=6,N=3$ 策略锥上以真实非负客户平方形式构造条件 Gram cuts。18 次迭代的目标保持约 1.5；负核数从 8 变化，最后一次降为 0，输出的最坏特征值最后为 0。对应冻结的 197381B `gram_probe.json` 记录了 85 条 cuts、3054 个命名变量和 `dual_beta=1.5`。

这说明在**固定的策略锥和给定条件平方行**内，切面可以消除该次浮点负核；它没有给出完整真实客户矩，因为源没有提供一个经这些切面验证的非负客户质量与完整菜单/SPE。已有正文中的 Gram 正性必要条件仍适用：若 $G_{ij}=\sum_x1_{x\in S_i}1_{x\in S_j}$，则 $z^TGz=\sum_x(\sum_i z_i1_{x\in S_i})^2\ge0$；本源只提供局部切面搜索，不能替代真实客户实例。

# 5. 逐人缺口与有限 MILP

## 5.1 三人/四人数值 MILP

`gap_m3p6i0.json` 是三人六主题、首位收益归一 1 的两次 45 秒 HiGHS MILP。两次均 `status=1`（time limit），变量 1098、约束 2504；记录的 incumbent objective proposal 为 2，但 MIP gap 分别 0.75 与 2.3048，dual bounds 分别 -3.5 与 -6.6097。`gap_m4p5i1.json` 是四人五主题、第二位收益归一 1 的两次 45 秒运行；变量 3935、约束 9682，均 time limit，第一项 objective proposal 为 1、MIP gap 14、dual bound -15。数值 incumbent 不是上界，也没有完整策略的 exact IC 证明，故两源均只作为有限障碍/候选记录。

## 5.2 五人七主题结构种子

`structured_gap_m5p7.json` 的范围写明“finite full-history policy-cone attack on $OPT-W\le m u_i$”，seed 为 216741，`universal_result=false`，`best_float=4.0`。9 个迭代记录从 `big`、`reply`、`overlap` 和私有 padding gadget 反馈策略锥；第一条 `big` 记录有 `counts=[5,0,0,0,0,0,0]`、`rows=1260`、精确 `gap/utility=4`。`selected_exact` 只给出一个已重建的点：$W=5$、$OPT=9$、utility $=1$、chosen portfolio 为五个主题；其余迭代的 gap 多为浮点值（例如 2.184426...），没有逐历史 Fraction 证书。

因此“出现 $OPT-W=4$”不能称作五人完整纯 SPE 反例：该文件只把一个策略锥候选和一个 exact selected point 存下来，且 `universal_result=false` 表示有限攻击没有证明普遍违反。`structured_gap_attack.py` 与 `prefix_cut_benchmark.py` 的导入依赖其他工作区模块；本批没有伪造缺依赖运行，保留其源码语义和失败边界。

# 6. 结论、去向和后续接续

1. **条件结论**：固定恰三名余下单位提供者、固定合法背景、指定收益行族的 `F_3(p)-R\le3u_A` 有完整有理系数证书接口；它可以作为后续跨文件证明的局部桥。
2. **有限实验**：branch/tax/price/three-endpoint、opportunity coefficient、Gram 和 gap MILP 的范围与退出码全部入证据目录；可行/不可行/超时分别标记。
3. **候选**：五人七主题的 $W=5,OPT=9$ selected point 和三人/四人数值 incumbent 仍是候选或障碍，不是真实客户 SPE 反例。
4. **开放缺口**：需要把三余利润证书与根覆盖客户预算、所有真实后继、完整历史 IC/BR 接起来，或构造满足六人模型且 $OPT>2W$ 的真实客户反例；本批没有完成其中任一项。
5. **模型边界**：重复/空主题、零客户、离轨历史、任意平局均未被删除；R-21674 的 workspace metadata 不含数学内容。Q-CAG-HALF 仍为 OPEN。
