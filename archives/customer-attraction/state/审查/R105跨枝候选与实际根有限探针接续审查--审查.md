# R105 跨枝候选与实际根有限探针接续审查

README 明确研究目标仍是 Q-CAG-HALF，状态 OPEN。本批增量包括一个初始零修复候选、50000 次实际根版本有限探针和文件清单说明；它们没有提供一般 half 证明或主目标反例。

## 1. 候选与探针

zero_repair_candidate.json 记录一次候选：四主题整数客户、背景主题 0、旧路径 (2,1)、旧策略末位菜单 [2,2,1,2]，旧福利 105，删后最大 SPE 福利 104。它是生成零regret修复障碍的先导样本，后来被 18 客户解析 witness 替代；不能把这一个 JSON 误称成一般反例。

actual_root_probe.json 记录另一个更强限制：要求被删除主题必须是空背景三人完整 SPE 的实际根动作。固定 seed 420261024，4 主题，50000 次随机试验，found=false。字段 scope 明确这是有限候选特异负证据，不能推断实际根桥成立/失败，更不能推断 Q-CAG-HALF。

README 进一步说明：一般合法离轨背景的零regret桥已被 18 客户 witness 否定，但实际根单删版本尚无见证；后续应寻找修复后的真实离轨菜单信用，不应继续累加零误差随机扫描。

## 2. 模型边界和现有对象关系

三源都保持顺序单位客户/单位提供者共同目录模型。它们与上一份 R105 zero-regret Markdown/JSON障碍直接相连：一般合法背景修复被精确否定；实际根版本仅得到 50000 次没有找到候选的有限状态。

因此处置层级为：candidate（单个候选）、finite exploration（50000 trials）、open bridge（实际根版本）。没有任何项可以升级为完整策略、全部历史或六人 half 结论。原件与哈希见 evidence manifest；本批未执行 Git commit、push 或 clean done。
