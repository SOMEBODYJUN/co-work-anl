# 三价模板与均匀质量证书的范围审查

## 结论与处置

六个源已逐字读取。它们应合并为本审查对象，而不新造一个“普遍三价定理”：两个 Python 模板是同一末端行系统的两种目标常数，使用 SciPy `linprog` 浮点求解；三个 JSON 是同一800行有限系统上已经给出的有理乘子向量。六源的独有内容、精确哈希和隔离复现保存在[证据目录](../../tools/evidence/terminal-three-price-templates-boss4/)。

* `three_price_template.py` 与 `three_price_template_weak.py`：`integrated` 到本文的有限模板审查。它们的差异是目标右端的 `tau*al` 与 `(tau+1)*al`，不能把两者输出合成同一个不带条件的界。
* `three_price_template_weak.json`：`integrated` 为弱模板的冻结输出；它逐参数记录 HiGHS 状态和由浮点向量 `limit_denominator` 得到的字符串，不是逐行 Fraction 证书。
* 三份 `uniform_mass_*_certificate.json`：`integrated` 为本文的精确证据。每份都明确 `rows=800`、`exact_nonnegative=true`、`min_exact_slack=0`；它们只证明各自保存的800行合同上存在非负乘子，不证明模板之外的策略或客户实例。

两个冻结提交 `68fad804ec5946cb296f77dc5b336308a66abf12`（legacy-cleanup）与 `aefc58eac3fc6eb5d7a47d087dd2c62b5aa9974c`（main）下同路径内容一致；本次按源ID保留两提交定位，语义对象只写一份。

## 模板实际定义的有限系统

两份程序都遍历
\[
(a,b,c,q,r)\in\{0,1\}^5,
\qquad (d,\ell)\in\{(0,0),(1,0),(1,\tau),(\tau,0),(\tau,\tau)\},
\]
所以有 `32*5=160` 个状态行；每行的分母含 `pbg`，本次源调用的 `pbg=0`。每一行建立七个列系数（源码注释为 `kQ,kR,P,Z,S,F,J`）并要求非负乘子 λ 使其支配右端。SciPy 的目标是最小化七个 λ 的和，边界为 λ≥0。程序循环
\[
\tau\in\{1,3/2,2,3,4,6,10,30,100\}.
\]

强模板的右端为
\[
(\tau\alpha+\beta+\gamma)-\frac{\min(1,d)}{p_{bg}+1},
\]
弱模板改为
\[
((\tau+1)\alpha+\beta+\gamma)-\frac{\min(1,d)}{p_{bg}+1}.
\]
其余行和列相同。程序随后把 HiGHS 浮点结果按最大分母 `10^6` 转成 `Fraction` 字符串；源码没有逐行把这些字符串代回原始有理不等式，因此这些模板结果的正确状态是“有限浮点搜索/显示”，不是 exact dual certificate。

## 两个模板的实际输出

强模板隔离重放得到：τ=1、3/2 可行，τ=2、3、4、6、10、30、100 报 HiGHS infeasible。弱模板的冻结 JSON 与重放给出 τ=1、3/2、2 可行，其余六个 infeasible；τ=1 的弱输出 λ 为 `(0,0,1,0,0,0,0)`，τ=3/2 为 `(11/108,1/6,2/3,2/27,2/9,1/6,1/9)`，τ=2 为 `(7/36,1/3,5/9,5/72,5/18,1/3,1/6)`。强模板的 τ=3/2 显示向量为 `(11/216,1/12,17/24,17/216,17/72,1/3,1/18)`。这些分数来自浮点向量的有界分母近似，不足以单独认证精确可行性，更不能把“τ≥2（强模板）或 τ≥3（弱模板）未找到可行浮点点”写成普遍不可能性。

强模板的求解没有一个冻结同名 JSON 源；本次运行生成的输出仅作为复现证据。它只能支持“按强目标写出的160行浮点模型在这九个参数上的运行状态”，不能替换后文的精确800行证书。

## 三份800行有理证书

三份证书的 λ 都有八个坐标，且每个报告给出 `rows=800`、`min_exact_slack=0`、`exact_nonnegative=true`：

| 证书 | λ（按源文件顺序） | 精确承重范围 |
|---|---|---|
| `uniform_mass_three_halves_certificate.json` | `(0,0,20/23,0,6/23,21/23,0,43/46)` | 保存的三半目标800行 |
| `uniform_mass_two_certificate.json` | `(12/215,48/215,141/215,5/86,10/43,192/215,24/215)` | 保存的二价目标800行 |
| `uniform_mass_two_kappa_certificate.json` | `(8/411,32/411,91/137,61/822,122/411,532/411,16/411,262/411)` | 保存的二价 κ 目标800行 |

`min_exact_slack=0` 表示至少一行恰等号，并不表示所有行严格正；`exact_nonnegative=true` 只说明源生成器对其输入行检查非负。三个向量的坐标数和模板的七列也不同，不能把它们机械拼成同一个 λ 或把任一向量迁移到另一套列定义。

这些精确证书可以作为[末回复转移的删槽表示与共同早期乘子锥](../方法/末回复转移的删槽表示与共同早期乘子锥--方法.md)中“有限列锥存在共同乘子”这一接口的固定行实例；它们没有给出该方法要求的所有真实早期行、全部完整历史或客户非负实现。它们也不能替代[固定背景下恰两名剩余玩家的税界](../引理/固定背景两人税界--引理.md)的逐客户 SPE 证明：后者的量词是任意合法前缀与真实离轨回复，而本批证书只看保存的800行合同。

## 与现有对象的比较

1. [二支持末段审计与全历史相邻锥有限证据](二支持末段审计与全历史相邻锥有限证据--审查.md)中的 `terminal_pair/audit.py` 是 Fraction 逐客户恒等式审计，并由正分子给出普遍结构结论；本批模板不是同一程序，也没有客户输入或全历史 SPE 枚举。
2. [末回复转移的删槽表示与共同早期乘子锥](../方法/末回复转移的删槽表示与共同早期乘子锥--方法.md)规定了共同 λ 的配对列锥条件；本批三份 λ 可作为特定有限列集的证据，但源未提供配对列清单、行到真实历史的映射或 Farkas 反例，所以不自动满足该方法的完整合同。
3. [固定背景下恰两名剩余玩家的税界](../引理/固定背景两人税界--引理.md)保留任意真实 SPE 的三个偏离比较和正交叠余项；本批没有证明其 `tau` 模板覆盖该引理的全部 `(A,B,T,S,Q)`。
4. 现有各类静态安全锥/末端价格审查已经把“固定策略锥证书”和“普遍半覆盖桥”分开。本批沿用该分层：有限行证书可供第三阶段关系检查引用，但不产生 Q-CAG-HALF-6 的反例、证明或普遍价格常数。

## 缺口与后续接续

* 若要把模板升级为精确命题，需保存完整有理行矩阵、逐行代回每个 λ，并明确 `pbg`、历史节点、客户类型和真实离轨回复的映射；当前冻结源没有这些输入。
* 若要解释 τ=3 以后 infeasible 的数学原因，不能由一次 SciPy 运行推断；应给出有理 Farkas 分离或普遍反例，并说明强/弱右端是哪一个对象。
* 三份800行证书的生成脚本、列顺序和源数据未在这六源中出现；当前只接受 JSON 自身的精确状态，不反向编造生成过程。
* 继续研究时应把本对象当作“固定有限合同证据”，与真实客户、完整策略、任意平局和重复主题的模型接口逐项对齐；任何新定理都必须重新声明量词。

本对象保留六源全部独有内容，正式状态为：两模板的有限搜索已隔离复现；三份800行非负乘子记录为精确有限证据；一般 SPE、普遍价格界和六人半覆盖仍开放。
