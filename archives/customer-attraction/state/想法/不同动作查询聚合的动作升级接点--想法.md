# 原模型与想法的准确位置

有限单位客户、有限非空共同目录，m≥1单位提供者，固定全部有序历史纯SPE σ、actual叶B、利润u_j；允许空主题、重复和任意离轨平局。源客户标签、current金额和actual角色利润不是同客户物理券的同一概念。本页保存5253B未完成推导及1513B入口的独有接点，不宣称新共同付款、半覆盖定理或一般不可能性。

同role j、合法action a的真正actual-prefix query为A^(j,a)=finishσ(B_<j,a)，客户价格向量z_(j,a,x)=1_(x∈a)/c_A(x)，D_(j,a)=Σ_xz≤u_j。分母只在x∈a使用。对natural context t=(g,j)，原规定叶V_t、规定a_t，原raw来源保持正差核的两叶共同coverer数r_t(x)≥1，输入h_tx给

\[
 g_{tx}=h_{tx}r_t(x)/c_{A^{j,a_t}}(x).
\]

当前加全部正边精确守恒；这不是full-profit重采核，也不能给任意ALL/ROW选择沿用同一r因子。[完整query覆盖引理](../引理/同角色来源的完整查询覆盖范数与四叶余项--引理.md)已自足给该合同、有限cover范数/对偶及四叶余项，本页不重授一次。

# 真正缺少的是一个共同系数预算

把同角色可由query向量覆盖的全部非负来源合成g_j(x)，需要同一组λ_(j,a)≥0同时满足

\[
 g_j(x)\le\sum_a\lambda_{j,a}z_{j,a,x}\quad\forall x.
\]

求和后每action仅用一次完整IC，得Σ_xg_j≤u_jΣ_aλ_(j,a)。若另有已从g分开的标量初值d_j，则Σλ≤2−d_j/u_j足付该role全部2u_j；u_j0时合法正query/source不存在，零点单独处理。不把d里已经并入g的初值再加一次；[LAST引理](../引理/最后归属的嵌套遗漏支持与同查询退款--引理.md)已明确这种初值记账的两种等价式。

该系数上界只是充分合同，也可改求更弱跨角色总金额；这里未得任一普遍界。逐客户库存、单context f≤1或每context≤u_j都不能给同role跨actions的共同预算。

R=O∖∪B只在旧uniform-reset角点可消去r因子：current=h/c_A。固定(j,a)的所有histories共用一个reset分母，合成客户系数η_(j,a,x)；uniform初始R查询若action=T_j，也与自然来源合到同一个系数，不能先领独立u_j。origin同role层质量反链给每x的Σ_aη≤1，故每action max_xη≤1并可用一条完整query付该组。

但不同a可在不同x达到各自最大，逐x Σ_aη≤1不推出Σ_a max_xη≤1。这个逻辑缺口本身不是已实现的真SPE反例；[旧uniform去重](../引理/同角色来源的完整查询覆盖范数与四叶余项--引理.md)已明确其状态，也未因本次重构变成新核/新HIT容量。

# 四真叶与需求几何不能免费补总账

同一off-history g的return叶U_t=finishσ(g,B_j)及原叶V_t满足ℓ_t=u_j(V_t)−u_j(U_t)≥0；actual-prefix query松弛e_t=u_j−D_(j,a_t)≥0。四真叶只给

\[
 u_j(V_t)+u_j-D_{j,a_t}-u_j(U_t)=\ell_t+e_t\ge0.
\]

ℓ是规定action优于return的正优势，不是可从current删掉的负退款；若换用return利润须另付该source差额。source原推导没有得到超出这些已保IC的共同符号。

末位在固定有序prefix h的负载b_x已确定，任意action a的收益是Σ_(x∈a)1/(b_x+1)，因而确实对同一客户价格向量作线性选择。尚有后继时，真实收益变成

\[
 d_h(a)=\sum_{x\in a}\frac1{b_x+1+c_x(\text{σ在}h+a\text{后的真实尾})}.
\]

尾随a改变，天然分母向量依action而变；不能未经另证就当共同价格、在不同histories间套普通revealed-preference/循环单调。这个限制没有证明每个具体游戏都不存在某种其它线性表示，也不是所有菜单几何路线不可能；它只定位尚缺的真实跨历史关系。

# 同题利润相等的动作升级接点

固定一个合法source-owner i的真实query叶W_i=finishσ(B_<i,T_i)。若未来receiver j在**同一完整叶**也选T_i，则逐客户均分规则直接给

\[
 u_j(W_i)=u_i(W_i)=D_i(T_i)\le u_i(B).
\]

这是同题玩家各项分母完全相同的恒等式及owner的一条完整actual-node IC；不是说在另一个reset叶或新分支中两人仍有相同收益，也没有为多个receivers各发一份owner钱包。

若receiver选其它主题a'只与source客户x重叠，其完整收益可含T_i外其它客户；这些额外客户可能参与使a'最优。source提出的接续是把这种“动作升级”与最优比较组合的交换、或receiver可复制的actual主题真实IC共同耦合。尚未给出精确跨history/跨action不等式、共同λ或容量修复存在性。

[静态等槽交换曲线](../引理/最优比较元组的等槽替换曲线与调和积分--引理.md)只由最优性控制O外覆盖，不能倒转成遗漏付款；[ALL/ROW族](../定理/全未来覆盖者与整行退款付款族--定理.md)只扩大合法路由，不增加总资金。下一项结果须明确同一σ/T/source点上的完整行、共同价格系数或总金额关系，不能再以单query退款/旧阴性充当跨action付款。

source保留的末对C′≤W/(2H_m+1)是正确既有组件，不付这里的不同动作总费；精确复用与当前真值另见[综合资源](../资源/菜单聚合与根协方差的审查域及综合边界--资源.md)。本想法仍未完成，未被本推导的停止点否定，也未提供一般六人half或新有限例。
