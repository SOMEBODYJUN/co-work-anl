# 定义与一般恒等式

令有限标签集为P，势Φ定义于全部非负整数计数q且|q|≤3，收益为

\[
u_a(q)=\Phi(q)-\Phi(q-e_a),\qquad q_a>0,
\quad W(q)=\sum_aq_au_a(q).
\]

取不同标签a、b，记q=2eₐ+eᵦ、r=eₐ+2eᵦ，及纯三人收益pₐ=uₐ(3eₐ)、pᵦ=uᵦ(3eᵦ)。定义

\[
\Delta=W(r)-W(q),\qquad
E=u_a(q)-u_b(r)-\frac32(p_a-p_b),
\]

\[
R_a=\Phi(2e_a)-\frac92p_a,
\qquad R_b=\Phi(2e_b)-\frac92p_b.
\]

则对任意这样的势表，准确恒等式为

\[
\boxed{\Delta+3E=R_a-R_b.}
\tag{1}
\]

这里没有客户表示、单调、DR、策略或SPE假设；只使用同一个删除势。若增加Rₐ=Rᵦ，才得到E=−Δ/3，不能略去修正项后用于任意势表。

# 证明及纯态调和的充分条件

写X=Φ(q)、Y=Φ(r)、P₀=Φ(eₐ+eᵦ)、A=Φ(2eₐ)、B=Φ(2eᵦ)。直接删除一名玩家给

\[
W(q)=3X-2P_0-A,
\qquad W(r)=3Y-2P_0-B,
\]

\[
E=X-Y-\frac32(p_a-p_b).
\]

两式相加立刻得(1)。特别地，若对a、b满足

\[
\Phi(2e_c)=H_2\Phi(e_c),\qquad
\Phi(3e_c)=H_3\Phi(e_c),\qquad c\in\{a,b\},
\]

则p_c=(H₃−H₂)Φ(e_c)=Φ(e_c)/3，故R_c=0。于是

\[
\boxed{E=0\ \Longleftrightarrow\ W(2e_a+e_b)=W(e_a+2e_b)}.
\tag{2}
\]

这是这两个三人计数之间的等价，不是所有人口层同支持效率E条件，更不是共同客户表示的充分性。空主题、不同标签覆盖相同、零质量或收益平局不会影响代数；若a=b，两式退化为零，原程序仅列a<b避免重复。

# 共同signed客户为何必须满足双支持恒等式

若同一组可能有负号的客户质量w_T定义

\[
u_a(q)=\sum_{T\ni a}\frac{w_T}{q(T)},
\]

按客户是否同时喜欢a、b分为只喜欢a、只喜欢b、两者都喜欢及都不喜欢。两者都喜欢的客户在q、r中负载都为3，给uₐ(q)−uᵦ(r)的贡献抵消；只喜欢一边的贡献分别为w_T/2、−w_T/2。因此

\[
u_a(q)-u_b(r)=\frac12(C_a-C_b)
=\frac32\bigl(u_a(3e_a)-u_b(3e_b)\bigr),
\]

其中C_c=Σ_{T∋c}w_T。这证明E=0，即使w允许负值仍成立。任何非零E都排除共同signed表示；但在已知纯态调和的删除势类内，这个分离与同一对计数的Δ≠0完全等价。它不增加一条线性独立的障碍。

# 如何接续

在继续构造有限势条件时，可用(1)先分辨双支持行与终局守恒是否独立；若没有纯态调和，应显式保留Rₐ−Rᵦ。即使全部十五对均过，也只检查每个二标签支持的两个三人计数，仍不能代替跨人口的同支持效率、共同非负客户或任意历史SPE。当前强点已经在共同signed表示之前失败；本引理不证明六人半覆盖，也不声称外部新颖性。
