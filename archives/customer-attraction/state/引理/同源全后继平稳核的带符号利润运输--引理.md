# 完整历史源与任意平稳分布

采用[共同目录完整历史模型](../定义/共同目录完整历史模型--定义.md)。固定任一完整纯SPE σ及任意合法有序源h，余r≥2人，旧负载b_x≥0为此前实际动作数，可离轨。源规定收益u；强制合法主题T后，其余n=r−1个**同一σ的真实后继**依次为F₁(T),…,F_n(T)。源在此叶的收益v(T)，后继终局收益总和J(T)。旧前缀仍参与稀释这些收益，J不是新局的覆盖数。

在有限非空主题标签目录上定义随机核K(T,A)=#{j:F_j(T)=A}/n。任取概率π满足πK=π；有限随机矩阵至少有一个平稳分布，无须不可约、唯一或每主题正质量。重复主题按后继出现次数计，空主题和同覆盖不同标签保原σ身份。

令M_n=⌊n²/4⌋、κ_r=n/(n+M_n)。则

\[
\boxed{u\ge\mathbb E_\pi v(T)\ge\frac{\kappa_r}{n}\mathbb E_\pi J(T).}\tag{ST}
\]

第一步是同一个源对每个T的真实IC；第二步仅用共同目录/单位均分/平稳性，不要求强制T成为该节点最优，不把不同T枝上的J当同一路径的后继利润。

# 逐客户带符号行及所有零端点

固定客户x，t=1_(x∈T)、z=Σ_j1_(x∈F_j(T))∈{0,…,n}，b=b_x。源与后继平均的客户贡献分别R=t/(b+t+z)、F=z/[n(b+t+z)]，零分子项取0。平稳性对每客户给E_π z=nE_π t。逐型有

\[
R-\kappa F-\frac{\kappa}{n(b+1)}(nt-z)\ge0.\tag{D}
\]

t=z0时取0，避免0/0。t0,z≥1时左边为κz/n·[1/(b+1)−1/(b+z)]≥0。t1时乘正分母n(b+1)(b+1+z)，分子

\[
n(b+1)-\kappa[n(b+1)+z(n-z)]
=\kappa[(b+1)M_n-z(n-z)]\ge0.
\]

因为b≥0、整数z使z(n−z)≤M_n。对T按π平均，散度项逐客户恰消失；再对客户求和得第二个ST。这里散度单个型可正可负，不把它当另一个非负预算。

背景特定系数κ_r(b)=n(b+1)/[n(b+1)+M_n]亦由相同代数成立；不同客户b_x不同，不能把各自系数免费抽成一个作用于整体J的共同大系数。统一取b0的最小值才给ST。零客户全0，n1时M1=0、κ2=1成立；r1未定义该核，不除n0。

# 常数、局部锐性与真实义务

r2…6的κ依次1、2/3、3/5、1/2、5/11。仅保(t,z)及平稳一阶等式时常数锐：b0，取整数k使k(n−k)=M_n，给(t,z)=(1,k)质量1、(0,1)质量n−k。总质量正，归一化后Ez=nEt；直接得R/F=n/[n+k(n−k)]=κ。n1可取k1，第二质量0。这个两状态是局部代数松弛，不给完整主题目录/同一σ/全部历史IC，故不是原模型反例或真实SPE锐性证书。

原粗递归若仅用ST和同一公共静态值的末位保底，给余3…6源的系数2/3、8/15、2/5、18/55；加末两位各1，总六人为216/55，低于原目标所需11/2。保为指定粗递归不足，不将216/55误称已证的actual W/OPT新常数，也不排其它运输或全树付款。

[末两人回复循环静态运输](../定理/末两人回复循环静态运输恒等式--定理.md)在n1用同一两人利润差望远镜，还构造共同安全背景Q并对每个查询给零余项。这是不同目标的更精细结构；本ST只控后继利润平均。现有多后继平稳封顶反例也不否ST，因为它们否的是对actual W的封顶，而非本带κ的枝平均。
