# 原完整策略、共享域与具体未付款

采用[有限单位客户共同目录完整历史模型](../定义/共同目录完整历史模型--定义.md)，m≥1，目录有限非空，保空主题、重复行动、同覆盖不同标签、零客户及任意历史依赖平局。σ是定义于全部有序历史的原纯SPE。位置i在实际前缀强制A后，仍沿同一σ完成改变后真实历史；删当前同一i槽，得到负载z_i(A)。d_i(A)=Σ_(x∈A)1/(1+z_i(A)_x)≤u_i。

共享域和查询为
\[
 K=\frac1m\sum_i\operatorname{conv}\{z_i(B):B\in\mathcal S\},
 \quad F_p(L)=\sum_x\frac{\rho_x}{1+L_x},\quad
 \rho_x=\Pr_{A\sim p}(x\in A).
\]
K非空紧凸，每个L是m−1份合法目录行动的分数负载，不必是一个纯SPE终叶。F对p线性、对L连续凸，凸minimax给真正鞍点(p*,L*)和值γ。所请求∀p min_K F_p≤W/m是较强充分接口；min_K max_p与max_p min_K相等本身没有证明这个界。K包含于全体m−1份合法分数目录背景域，所以限制K的minimax值至少为全分数域的静态安全值，方向不能反转。

本页完整保原tree7205B、shared review5947B及direct algebra review2394B中的一般代数。共享VAR/BAL和等价几何已在[既有共享资源](../资源/第十一轮共享负载的凸信用与共同付款停界--资源.md)、[共同Gram核](共享真实菜单的等价格Gram核与KKT协方差分解--引理.md)保留，以下先列准确合同，再给原稿独有的真实末位需求转移。

# 任意实现的KKT支持及原共同总账

固定p及其极小L*，令t=(1+L*)^{-1}、w=ρt²。任何实现
L*=(1/m)Σ_iΣ_B q_i(B)z_i(B)的正质量列，均最大化w·z_i(B)。否则把该支持列少量移向更大w·z的合法列，会给F严格负方向导数，矛盾。这对非唯一实现及ρ_x=0坐标仍真，不除ρ。

因此
\[
 G_{\rm KKT}=m w\cdot L^*-\sum_i\mathbb E_{A\sim p}w\cdot z_i(A)\ge0.
\]
置I_i=u_i−E_pd_i(A)≥0，并定义
\[
 C=\sum_i\mathbb E_A\sum_{x\in A}t_x^2(z_i(A)_x-L_x^*),
\quad
 D=\sum_i\mathbb E_A\sum_{x\in A}
     \frac{t_x^2(z_i(A)_x-L_x^*)^2}{1+z_i(A)_x}\ge0.
\]
逐客户倒数展开给
\[
 W-mF_p(L^*)=\sum_i I_i-C+D
 =\sum_i I_i+G_{\rm KKT}+D-\operatorname{Cov}_{\rm all},
\]
\[
 \operatorname{Cov}_{\rm all}
 =\sum_{i,x}t_x^2\operatorname{Cov}_{A\sim p}
                         (\mathbf1_{x\in A},z_i(A)_x).
\tag{BUDGET}
\]
G_KKT只控制去相关的ρ权重，不控制同一query的membership与真实后继负载相关性。一般付款Cov_all≤ΣI+G_KKT+D未由此推出。零ρ坐标的membership几乎处处零，全部式自然消失。

# 同一个固定切线游戏只作代数表示

对任意固定非负t，终局Z中当前主题所含客户都有c_x(Z)≥1，逐项
\[
 \frac1c=2t-t^2c+\frac{(1-tc)^2}{c}.
\]
令g_t(A)=Σ_(x∈A)t_x、v_A=t⊙1_A、V_Z=t⊙c(Z)，则
\[
 u_i(Z)=u_i^t(Z)+E_i^t(Z),\quad
 u_i^t(Z)=2g_t(Z_i)-v_{Z_i}\cdot V_Z,
\quad E_i^t(Z)=\sum_{x\in Z_i}\frac{(1-t_xc_x(Z))^2}{c_x(Z)}\ge0.
\tag{TAN}
\]
切线利润具有共同对称PSD碰撞核Σ_(x∈A∩B)t_x²，并可写成
Σ_(x∈Z_i)(2t_x−t_x²)−Σ_(j≠i)Σ_(x∈Z_i∩Z_j)t_x²，可能为负。

固定原真实节点h，obey和forced-A均按原σ各自完成真实尾，整主题IC slack Γ_hA=u_i(obey)−u_i(dev)≥0只给
\[
 u_i^t(obey)-u_i^t(dev)
 =\Gamma_{hA}-E_i^t(obey)+E_i^t(dev),
\]
即切线偏离增益≤E_i^t(obey)−E_i^t(dev)，并不保证非正。原σ不是自动的切线SPE，见[已发表诊断](../障碍/切线策略与动态首利摊派的真实边界--障碍.md)。同一静态终叶上的二次势
\[
 \Phi_t(Z)=\sum_x[2t_xc_x-t_x^2c_x(c_x+1)/2]
\]
删单一玩家的形式边际等于u_i^t；早期改动作同时改变真实后继，不能当作只变一个角色的势差。

同一完整叶确有
\[
 \sum_iE_i^t(Z)=\sum_{x:c_x(Z)>0}(1-t_xc_x(Z))^2.\tag{ONE-LEAF}
\]
但共享D=Σ_i E_A E_i^t(Z_i(A))在不同角色/查询的互斥真实叶上取误差，不是同一Z的左边。不能用ONE-LEAF把这些误差都向一份actual银行收费。未覆盖客户不在右边；不能给c=0凭空加入(1−0)²=1。

# 真鞍点额外结构不使方差自动消失

在真正(p*,L*)，g_t(A)≤γ对所有合法A，p*正支持上取等。输入特征v_A因而共处一个等L1价格超平面，不固定其平方范数。精确规范式为
\[
 w\cdot L^*=\sum_x\rho_xt_x(1-t_x)
 =\gamma-\sum_x\rho_xt_x^2
 =\gamma-\mathbb E_{A\sim p^*}\|v_A\|^2.\tag{SN}
\]
支持输入的切线基准是2γ，碰撞核仍PSD；这两点未给适应性碰撞的金额界。[既有银行鞍点](../反例/共享菜单全部最优鞍点的正相关项--反例.md)有正C，故Bregman误差和原IC slack必须保留；它只否零C，不否完整付款或half。

# 同一真实倒二前缀的末位需求律

以下需m≥2，固定**实际倒二前缀**，其旧负载β来自前m−2行动。令A∼p*为当前强制query，B(A)为原σ在该有序历史的真实末位最佳回应。另取独立A'∼p*，定义
\[
 Z_A=(\text{prefix},A,B(A)),\quad
 Z_{A,A'}=(\text{prefix},A,B(A')).
\]
第二叶是历史(prefix,A)上末位改选合法整主题B(A')的结果，不说它是该历史原规定回复，也不将前缀换成(prefix,A')。末位真IC给
\[
 \Gamma(A,A')=u_{\rm last}(Z_A)-u_{\rm last}(Z_{A,A'})\ge0.
\]
置a=t1_A、b=t1_B。末位切线利润准确为
2g_t(B)−b·(tβ)−b·a−||b||²。
在iid平均中，own B(A)与cross B(A')的边际分布相同，故独立动作项、旧背景项、norm项全部相消，own-minus-cross切线差为
−Σ_xt_x² Cov(1_(x∈A),1_(x∈B(A)))。
将TAN代入原Γ，得到精确
\[
 \boxed{\operatorname{Cov}_{\rm term}
 =\mathbb E_A E_{B(A)}^t(Z_A)
 -\mathbb E_{A,A'} E_{B(A')}^t(Z_{A,A'})
 -\mathbb E_{A,A'}\Gamma(A,A').}\tag{DEMAND}
\]
这是原真实末位整主题IC以非负系数p(A)p(A')组合的共同关系，没有客户逐项重权IC。等价代数本身对固定t和任意输入分布也成立；鞍点价格用于后面的SN和r_β展开，不是将Γ另重权。没有冻结另一query的整个原尾：这里只把其末位合法主题拿到当前真实末节点比较，末位后已无后继。

当前倒二的删槽负载是z_current(A)=β+1_(B(A))，固定β不贡献协方差。因此Cov_term正是BUDGET里这个实际倒二query行的协方差项，不是一个可任意挪给其他位置的新金额。

# 转移到当前D需要准确的SWAP差

在同一own叶(prefix,A,B)，对A∩B两位的误差份额相同，相消；非公共客户最终负载β+1。因此设
\[
 r_\beta(T)=\sum_{x\in T}
                \frac{(1-t_x(\beta_x+1))^2}{\beta_x+1}\ge0,
\]
逐客户得
\[
 \boxed{E_B^t(prefix,A,B)-E_A^t(prefix,A,B)
                  =r_\beta(B)-r_\beta(A).}\tag{SWAP}
\]
当前倒二query行的共享误差确为D_current=E_A E_A^t(Z_A)，因为在A上c=1+z且1−tc=−t(z−L*)。DEMAND原来用的却是follower own误差；它横跨多个(prefix,A)，也不能当作原actual末位行的D_m。

因此准确而非仅上界的式子为
\[
 \boxed{\operatorname{Cov}_{\rm term}=D_{\rm current}
 +\mathbb E_A[r_\beta(B(A))-r_\beta(A)]
 -\mathbb E_{A,A'} E_{B(A')}^t(Z_{A,A'})
 -\mathbb E_{A,A'}\Gamma(A,A').}\tag{DV}
\]
最后两项是被减去的非负量。中间r_β差是此转移仍须共同支付的具体债；不能把follower own误差直接替换为D_current。

展开r_β得
\[
 r_\beta(T)=F_\beta(T)-2g_t(T)
       +\sum_{x\in T}t_x^2(\beta_x+1),\quad
 F_\beta(T)=\sum_{x\in T}\frac1{\beta_x+1}.
\]
支持A有g_t(A)=γ，而合法回复B只保证g_t(B)≤γ，所以
\[
 r_\beta(B)-r_\beta(A)=F_\beta(B)-F_\beta(A)
 +2(\gamma-g_t(B))
 +\sum_x(\mathbf1_B-\mathbf1_A)t_x^2(\beta_x+1).
\]
等价主题价只消去输入的g价。即使B也价γ，F_β差和β加权norm差仍在；末位BR比较的背景是β+1_A，不是F_β的裸背景，KKT的ρt²·L也不提供这两差的符号。故未得Cov_term≤D_current，更未支付全部早期响应协方差。

# 单调插入势不能免费变成单叶误差银行

固定同一t，在任意非负整数负载b定义
\[
 R_t(b)=\sum_x[H_{b_x}-2t_xb_x
                    +(t_x^2/2)b_x(b_x+1)],\quad H_0=0.
\]
这就是倒数调和势减上述二次势。整主题插入的准确边际是
\[
 R_t(b+1_T)-R_t(b)=r_b(T)\ge0.
\]
所以SWAP的r_β差的确是同一个固定势在β+B与β+A的差，不是随意标量。但沿原完整树，强制另一query会改变β和原选择尾，两条rollout不是同一嵌套负载序列；共同固定t没有取消真实重置端点。

对一个**已覆盖**客户c≥1，准确有
\[
 R_t(c)-(1-tc)^2=H_c-1-(t^2/2)c(c-1).
\]
右边可以正：仅代数代入c=2、t=1/2，单叶误差为0而R_t(2)=1/4。这是标量说明，不是新SPE输入或数值实验。c=0时R_t(0)=0，而未服务客户根本不计入ONE-LEAF误差；不能延用该c≥1比较式并制造一单位误差。调和部分尚存，因此原actual平方误差并不自动支配全部插入误差。

# 审查时序、边界与当前结论

原7205B末段说推导保存后direct11检查§2–4：iid相消、原IC符号、SWAP、展开、势边际均通过。2394B审查保留“原DV不等式成立但精确等式更强”的版本反馈；当前主稿已收紧成上面的等式。两原件体现这一内部修改，不应消掉审查先验或把旧措辞当成现主稿矛盾。review特别限定c≥1且另警示c0，未背书任何未证付款、外审或新颖性。

m1没有倒二/末位二人比较，DEMAND不在其域；其K={0}、单人BR和共享公式另直接成立。空/重复主题、β=0、ρ=0、零客户及平局不影响所有在域恒等式。标签历史保留，cross叶只作真实末节点合法偏离。

后续[实际切线银行](../候选/实际负载切线银行与共同误差付款--候选.md)在同一K有B_act≤γ/2，但误差差和改变前缀重置到这份银行的T-PAY仍未证。对m5最后两位这里只得DV，前三位还另有真尾变化；现[五人half](../定理/五人半覆盖--定理.md)另证不倒填此路线。一般/六人目标未由DEMAND/SWAP或势表示解决。
