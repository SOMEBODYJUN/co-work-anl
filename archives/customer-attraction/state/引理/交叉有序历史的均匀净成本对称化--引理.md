# 固定行、规范门槛与交叉记录

采用[有限单位客户、共同非空目录、完整有序历史纯SPE模型](../定义/共同目录完整历史模型--定义.md)，任意\(m\)。空主题、重复、零客户、离轨平局均保留。固定进入行\(i\)、其实际前缀\(h\)，取未来角色\(j>i\)、同一个有序中间序列\(z\)及主题\(A,A'\)。两份raw记录为
\[
y_1=(h,A,z,A',\tau_1),\qquad
y_2=(h,A',z,A,\tau_2).
\]
记进入角色利润\(r_1,r_2\)，当前角色\(j\)利润\(c_1,c_2\)。raw尾\(\tau_1,\tau_2\)可任意；以下代数不要求它们是SPE，也不把混合称为原游戏SPE。

对任意历史\(g\)，规范门槛是
\[
M(g)=\max_T\min_{v\in\mathcal R(g,T)}u_{|g|+1}(v),
\]
其中\(\mathcal R(g,T)\)为强制\(T\)后全部完整孩子SPE终局。相同计数历史的剩余游戏同构，保持每个后缀行动及收益，故\(M(g)=M(b_g)\)。这识别的是规范门槛全集，不要求原\(\sigma\)在同计数历史用同尾，更不令原对偶历史乘子\(\lambda_g\)相同。详细必要/充分拼接见[门槛域](逐历史均值门槛的受限实际标签域--引理.md)。

# 半半混合保留什么

两处各以\(1/2\)使用\(\tau_1\)、\(1/2\)使用\(\tau_2\)。在当前角色\(j\)之后，两个交叉前缀已有相同计数，因此对任何固定尾\(\tau\)，两处的完整负载相同；进入者和当前人交换主题时其利润也交换。于是新两处的根利润和与当前利润和都为
\[
R_{\rm sym}=C_{\rm sym}=\frac{r_1+r_2+c_1+c_2}{2}.
\]
两处合计的完整负载分布仍为\(\tau_1\)、\(\tau_2\)各一份，故每个完整负载shadow总和保留。删除的是同一角色\(i\)，两处根行动本来就是\(A,A'\)各一份，故删除进入槽的shadow总和也保留。中间角色和严格尾角色的合计利润保留；根增加的半差额恰由当前角色减少的同一半差额抵消。

# 净cap的双倍转移

使用单一净成本
\[
B_i(y)=d_i(y)+\sum_{k>i}[M(y_{<k})-u_k(y)]
=2d_i(y)-\sum_{k\ge i}u_k(y)+\sum_{k>i}M(y_{<k}).
\]
两处各自的中间及当前前缀不因尾混合改变，所以这些\(M\)项不变。当前之后的两个交叉前缀计数相同，对任一固定尾的后继\(M\)相同，所以混合后后继\(M\)总和也准确保持。剩余角色合计利润保持，而根利润和增加\((c_1+c_2-r_1-r_2)/2\)，故
\[
\boxed{\Delta\!\sum_{\rm pair}B_i=c_1+c_2-r_1-r_2.}
\tag{NET-TRANSFER}
\]
相比只约束根进入收益的旧mean-cap，这个净cap变化是其半差额的两倍，第二半来自当前角色利润的反向变化。全raw域移除孩子SPE实现门，并未免费满足全局NET-cap；右端仍可为正或负。

若\(\tau_1,\tau_2\)为原\(\sigma\)的真实cross-child尾，令\(v_1,v_2\)是原\(\sigma\)在\((h,A,z)\)、\((h,A',z)\)两处当前规定利润。原完整IC给\(c_1\le v_1\)、\(c_2\le v_2\)，所以
\[
\Delta\!\sum_{\rm pair}B_i\le v_1+v_2-r_1-r_2.
\tag{NET-IC}
\]
这里\(v_1,v_2\)是两份跨根真实分支值，不能换成实际路径的固定\(u_j\)。该上界也没有固定非正符号。

# 同一全局乘子的定价及可行边界

若已经明确定义允许所有这些raw标签叶的统一净cap域，并有同一\(w\)、同一\(\mu\ge0\)及该行\(\eta_i\)，使
\[
r_i(y)=\eta_i+\mu B_i(y)-w\cdot\ell_i(y)\ge0
\quad\text{对每个允许raw叶},
\]
则混合保概率总和及shadow，直接给
\[
\boxed{\Delta\!\sum_{\rm pair}r_i
       =\mu(c_1+c_2-r_1-r_2).}
\tag{NET-DUAL}
\]
共同\(\mu\)必须来自显式单一净约束；它不是把旧任意\(\lambda_g\)归一化。此式只是同一净成本的合法定价，不是一份新银行。

若原pair在所选最优\(Q_i\)中有正支持，则原列约化成本为零。所有新raw列约化成本非负，故当\(\mu>0\)时(NET-DUAL)迫使该pair的cap变化非负。这是最优性限制，未支付其金额。若某次操作的变化\(\le0\)，则它在**同一全raw、仅有该净cap约束**的域中不增总cap且保shadow，因而可行；一般操作却没有这个符号。若仍保实际标签单点、逐历史均值floor或其他约束，必须另外逐项核验，不能由这一条件推断可行。

# 与旧可信混合及真实重放的差别

旧[交叉mean-cap转移稿](../../tools/evidence/credible-cap-fixedpoint-primary/original/research/workspaces/customer-attraction/R-cd789330fc7141299ac491bbb3ffa420/round12/geometry/cross_history_mean_cap_transfer.md)只给根cap半差额。尾\(\tau\)在固定当前动作之后虽可按同计数移植，其混合仍可能改变当前人、中间人及更早祖先的最佳回复，不能自动留在完整孩子SPE域。本页使用全raw统一净成本，绕开该资格门的同时保留完整有符号(NET-TRANSFER)，没有把旧半差额免费变成可行操作。

[同一前缀行动平衡交换](同前缀行动平衡交换的半份约化成本界--引理.md)也保双系数，却要求同一行主题平衡和逐原源容量；本页pair对称化没有证明实际协方差流满足这些条件。[真实重放](../算法/固定进入槽的真实后继重放与一次势预算--算法.md)已给\(P_i\to Q_i\)的非负保守路径及一次signed净cap望远镜；还须将本页一组保守pair操作放进**同一所选\(Q_i\)**和**同一原源容量**中，让全部净变化共同望远镜，并把自适应对角功降到足够的单查询variance金额。单个pair代数和其shadow守恒没有给该联合下降，不能逐pair取正部后重复领源银行。
