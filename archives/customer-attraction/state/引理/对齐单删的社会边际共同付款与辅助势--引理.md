# 固定背景、决策身份和社会边际

在[共同目录完整历史模型](../定义/共同目录完整历史模型--定义.md)固定一个合法有序外前缀，客户负载为b_x≥0，余r≥2个原身份执行同一份完整有序历史纯SPE σ。背景不随删位抽样改变；空主题、重复、零客户及全部离轨平局保留。以下单叶代数对任意非负整数背景也成立，用作原游戏则背景必须合法。

对r身份任意叶z，客户x被其中t_x位覆盖。只计这r身份的利润和

\[
U_b(z)=\sum_x f_{b_x}(t_x),\qquad
f_b(0)=0,\quad f_b(t)=\frac t{b+t}\ (t\ge1).
\]

记u_i(z)为i的均分利润，q_i(z)=U_b(z)−U_b(z\setminus i)为其**社会边际**。对i覆盖的客户，

\[
q_{ix}=\begin{cases}
1,&b_x=0,t_x=1,\\
0,&b_x=0,t_x\ge2,\\
\dfrac{b_x}{(b_x+t_x)(b_x+t_x-1)},&b_x>0.
\end{cases}\tag{1}
\]

旧客户的q是删除i后固定背景角色获得的退款，不是i独占客户数。q_i≥0，逐客户得

\[
\sum_iq_i(z)\le U_b(z),\qquad
\sum_iq_i(z)=E(z)\quad(b=0),\tag{2}
\]

其中E是恰被一个剩余角色覆盖的客户数。旧客户的不等式是t b/[(b+t)(b+t−1)]≤t/(b+t)，因为b≤b+t−1；新客户直接按t1或t≥2核。

# 单叶退款递推

删除另一身份d≠i，i在共有客户上的退款是1/[c_x(c_x−1)]，c_x=b_x+t_x；非共有客户退款零。记总退款R_i^d(z)。对每个i覆盖客户，另一剩余覆盖者恰t_x−1个，因此

\[
\boxed{\sum_{d\ne i}R_i^d(z)=u_i(z)-q_i(z),\qquad
\sum_{d\ne i}u_i(z\setminus d)=r u_i(z)-q_i(z).}\tag{3}
\]

b0/t1直接给零退款，不套0/0。这是具体客户分享核的Shapley删除递推，不认一般递推新颖性。

# 同一原历史、角色和查询的signed预算

原任意历史h当前身份i，规定S=σ_i(h)，强制同一合法目录查询A后仍依σ；两个真实完整叶为z_S、z_A。原IC余量Γ_i(h,A)=u_i(z_S)−u_i(z_A)≥0。

若一个物理单删因果回放真正重建到同一h，定义其偏离差
g_i^d(h,A)=u_i(z_A\setminus d)−u_i(z_S\setminus d)。它是回放计划的真实偏离差，回放未假定为SPE。全d≠i均能对齐时，(3)相减得

\[
\boxed{\sum_{d\ne i}g_i^d(h,A)=-r\Gamma_i(h,A)+q_i(z_S)-q_i(z_A).}\tag{4}
\]

原实际路径没有违反σ的过去行动，所有单删在其相应删后历史可对齐。各实际位置i使用同一个查询T_i跨全部d，并利用共同规定叶z，得

\[
\sum_i\sum_{d\ne i}g_i^d(h_i,T_i)
=-r\sum_i\Gamma_i+\sum_iq_i(z)-\sum_iq_i(z_{i,T_i}).\tag{5}
\]

右边至多U_b(z)−Σ_iq_i(z_{i,T_i})，空背景可用E(z)替代U_b。查询叶社会边际是负信用，不能丢掉后再给每个删位一份福利。更不能将左端改成Σ_d max_A g_i^d，或把各Cartesian坐标独立选择的A^d叫同一A。

# 任意离轨历史的坏过去修正

全局回放删除一个过去角色d时，ghost实际重建σ_d(h_<d)，未必等于记录h_d。令B(h)为过去不相符角色，G为其余d≠i（所有未来删除均合法）。从全身份形式式减去B的形式退款行，得到真实对齐子集上的

\[
\boxed{\sum_{d\in G}g_i^d
=-(r-|B|)\Gamma_i+q_i(z_S)-q_i(z_A)
-\sum_{d\in B}[R_i^d(z_A)-R_i^d(z_S)].}\tag{6}
\]

Γ系数是r−|B|，不是r−1−|B|。因Γ、R_i^d(z_A)非负，且同一规定叶满足Σ_B R_i^d(z_S)≤u_i(z_S)−q_i(z_S)，

\[
\sum_Gg_i^d\le q_i(z_S)+\sum_BR_i^d(z_S)-q_i(z_A)
\le u_i(z_S)-q_i(z_A).\tag{7}
\]

坏过去身份合用一份当前钱包。对每个h重新固定记录中的ghost动作也能造局部对齐计划，但这些计划不自动拼成同一份全局物理回放策略。原错误“任意h自动全对齐”由父方指出，作者稿已改，独审明确审的是改正版本；本页不继承旧错误。

# 公共完整行质量及不同删位乘子的残余

在同一实际路径，任取λ_(i,A)≥0且每角色完整行质量L_i=Σ_Aλ_(i,A)≤1。将(4)按λ相加：

\[
\boxed{\sum_{i,A}\lambda_{i,A}\left[\sum_{d\ne i}g_i^d(h_i,A)+q_i(z_{i,A})\right]
+r\sum_{i,A}\lambda_{i,A}\Gamma_i(h_i,A)
=\sum_iL_iq_i(z)\le\sum_iq_i(z).}\tag{POOL}
\]

故共同signed行和查询边际已由一份社会边际支付。λ以完整原角色/历史/查询为单位；按不同离轨context分别给行质量1不能再合为同一actual池。

若不同d的系数为λ_(i,A)^d，最大公共部分是λ_(i,A)^common=min_(d≠i)λ_(i,A)^d。逐删位减去它得非负残余，公共部分可用POOL，残余回到各自退款IC或别的耦合。min不能用平均或最大替代。同一实现的随机查询跨全部d后可对式(5)取期望；各d独立选择查询没有这个共同预算。

# 保留r个决策身份的辅助全树

在原r身份、原完整树上另定义终局收益

\[
\bar u_i(z)=\frac1{r-1}\sum_{d\ne i}u_i(z\setminus d)
=\frac{r u_i(z)-q_i(z)}{r-1}.
\]

决策节点没有删除，σ在每个原历史都可使用，不存在ghost错位。式(4)给真正全树偏离差

\[
\bar u_i(z_A)-\bar u_i(z_S)
=\frac{-r\Gamma_i+q_i(z_S)-q_i(z_A)}{r-1}
\le\frac{q_i(z_S)}{r-1}.\tag{8}
\]

沿任一从内部历史依σ继续的路径，所有规定叶同为z，当前及未来角色的正regret和至多U_b(z)/(r−1)，空背景至多E(z)/(r−1)。r固定为整个辅助游戏身份总数，不能在深层重置为当时剩余人数。这里是辅助近似激励，未给物理r−1人SPE。

令原调和势Φ_b(z)=Σ_xΣ_(k=1)^(t_x)1/(b_x+k)。原u_i与q_i分别是Φ_b和U_b的单人删除边际，故Ψ_b=rΦ_b−U_b的边际为r u_i−q_i。对旧客户b>0，势第t增量及相邻差是

\[
h_b(t)=\frac r{b+t}-\frac b{(b+t)(b+t-1)},\quad
h_b(t)-h_b(t+1)=\frac{(r-2)b+r(t-1)}{(b+t)(b+t-1)(b+t+1)}\ge0.
\]

增量非负；新客户首增量r−1，之后r/t，且r−1≥r/2。Ψ因此是单调凹的资源势，其归一化Ψ/(r−1)产生辅助效用。

# 一般凹价值的删除算子与可行域

对单调凹整数资源价值f(0)=0，只在0≤t≤r定义

\[
(D_rf)(t)=\frac{(r-t)f(t)+t f(t-1)}{r-1}\quad(t\ge1),\qquad D_rf(0)=0.
\]

置a_t=f(t)−f(t−1)≥0且非增。增量为[(r−t)a_t+(t−1)a_(t−1)]/(r−1)≥0；对2≤t≤r，其与前一增量之差为

\[
\frac{(r-t)(a_t-a_{t-1})+(t-2)(a_{t-1}-a_{t-2})}{r-1}\le0.
\]

t1或t2出现的零系数a0项直接省略，无须定义a0；t>r不能继承系数非负。D_rf保持单调凹，且(D_rf)(t)/t正是删掉另一身份后Shapley分享的平均。

空背景原覆盖核f(t)=1_(t>0)被变成D_rf(1)=1、D_rf(t)=r/(r−1)（2≤t≤r），已非原单位客户只首次覆盖价值1的核。凹闭包不能充作原CAG输入类的删除闭包。
