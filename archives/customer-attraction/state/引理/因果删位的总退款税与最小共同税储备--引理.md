# 合法背景、角色及因果提升

采用[完整历史模型](../定义/共同目录完整历史模型--定义.md)。固定一个合法有序背景，原剩余活跃角色按完整纯SPE σ行动。背景可以离轨；其玩家仍参加终局均分，且不在删位中。固定删除若干原活跃位置L，至少保留一名。新完整计划τ这样定义：按原相对位置重建每个新有序历史，在被删位置读取**当前重建历史**上的σ动作，在保留位置读取新历史给定行动。遇到尚未指定的保留位即用σ继续，最后的虚拟删位也补完。每个新完整终局y有唯一提升原叶z，删除L恰得y（背景保留）。

任一新节点的规定完成y与强制合法T后的完成y_T，提升为同一原节点的两个真实σ孩子z、z_T。故当前原角色i有
\[
 \Gamma_T=u_i(z)-u_i(z_T)\ge0.
\]
被删虚拟行动会随新过去变化，不得冻结为原actual删者主题。此τ定义全树，但通常不是删后物理SPE。

# 全部幸存者的退款守恒

对一个提升叶z，把背景和所有未删活跃者统称幸存者。客户x有删者覆盖数d_x、幸存者覆盖数t_x，总覆盖c_x=d_x+t_x。若幸存者j覆盖x，则t_x≥1，退款为
\[
 R_j(z)=\sum_{x\in S_j(z)}\left({1\over t_x}-{1\over c_x}\right)
       =\sum_{x\in S_j(z)}{d_x\over c_xt_x}\ge0.
\]
零负载客户不进和式，不发生0/0。背景玩家的R_j也必须计入。记P_L(z)为删者原利润和，e(z)为原叶被覆盖、删除后完全失去的客户数，定义
\[
 \boxed{H(z)=P_L(z)-e(z)=\sum_{j\text{ 全部幸存者}}R_j(z)\ge0.}\tag{H}
\]
证明：t>0时该客户全部幸存退款为t·d/(ct)=d/c，正是删者原份额；t=0<d时删者份额1、删除损失1，退款0。逐客户相加即得。它与[合法背景退款守恒](合法背景因果删位的退款税与储备损耗守恒--引理.md)中“活跃退款+背景退款”的式子相同；这里H已同时包含两者。

删后当前物理收益为U_i(y)=u_i(z)+R_i(z)，所以真实偏离增益
\[
 \boxed{g_T=U_i(y_T)-U_i(y)=R_i(z_T)-R_i(z)-\Gamma_T.}\tag{IC}
\]
令ε_i(z)=H(z)−R_i(z)≥0，立即有全历史精确式
\[
 \boxed{g_T-[H(z_T)-H(z)]
   =\varepsilon_i(z)-\varepsilon_i(z_T)-\Gamma_T
   \le\varepsilon_i(z)-\Gamma_T.}\tag{RP-H}
\]
这里每个量按各自真实孩子重算，未把同一actual P_L重复支付互斥孩子。

# 同规定叶的后缀储备

固定一个新节点h及其规定提升完成z。令n为尚未行动保留活跃者数（含当前），I_fixed(z)为背景及已行动保留者的退款和。因总H包括所有幸存者，未来退款和为H−I_fixed，于是
\[
 \boxed{\sum_{i\text{ 未来}}\varepsilon_i
       =(n-1)H+I_{fixed}.}\tag{RES-H}
\]
沿规定行动，最终提升叶不变，当前角色退款从未来移入I_fixed，n减少1，右边恰减少ε_current≥0。沿偏离则完成叶、H、I_fixed同时变化；RES-H没有给一个跨任意孩子单调的银行。n1时余额为I_fixed而非必为0：过去玩家仍可收款。

如果给每名保留活跃角色收终局税H，并在其节点选择τ规定行动时返还该节点ε_i（按该节点规定完成定义），则任一非规定单步偏离的净增益由RP-H减去ε_i后≤0。有限完美信息博弈的单步偏离原则因而给τ一份**转移收益辅助游戏**的完整SPE。这不是新客户、合法主题或原均分收益，因此不能代入只对原较少人数物理SPE成立的half定理。单独按角色收自身R_i也会恢复原提升收益，已见[成熟因果删除引理](因果多删位的全历史退款与锐乘法误差--引理.md)；本页共同H税记录的是另一个清楚的付款表示。

# 固定角色集上的最大退款共同税

令J为本次变换中**全部保留活跃角色**，在所有节点固定，包括已行动者，不含原固定背景；至少一名。定义
\[
 M(z)=\max_{j\in J}R_j(z),\quad\varepsilon_i^M(z)=M(z)-R_i(z)\ge0.
\]
M≤H。由IC得同样精确式
\[
 g_T-[M(z_T)-M(z)]
 =\varepsilon_i^M(z)-\varepsilon_i^M(z_T)-\Gamma_T.\tag{RP-M}
\]
未来n人误差和为
\[
 \boxed{\sum_{i\text{ 未来}}\varepsilon_i^M=nM-H+I_{fixed}
       \le(n-1)H+I_{fixed}.}\tag{RES-M}
\]
它作为显式非负和总≥0；不能由右端三个带符号项分别解释预算。沿规定边恰减少当前ε_i^M；若把max的角色集每步改为尚未行动者，原全局终局税就被改变，需另证，不能直接沿用这里的单步付款。

M的“最小”准确限于此类：在每个终局用一个共同标量税P(z)，同时要求所有j∈J的P−R_j≥0，则必要且充分P≥M。它不宣称在角色专用税、历史返还或一般可信修复之间最优，更不支付实际福利漂移。

# 只删末位的较弱界与失败接口

删除一名末位时，任一保留者的逐客户收益最多翻倍，故U_i(z_T^-)≤2u_i(z_T)≤2u_i(z)。令ρ为删后最大后悔，规定叶退款R_i，则
\[
 \rho+R_i\le u_i(z).
\]
原末位在其真实节点可复制当前角色的实际主题，每名客户的分母最多由c变c+1≤2c，因此u_last(z)≥u_i(z)/2。于是普遍有效的较弱表述为
\[
 \boxed{\rho+R_i\le u_i(z)\le2u_{last}(z).}\tag{2L}
\]
这不证明系数1。35客户完整例中ρ11、R0、u13、u_last9，恰显示LD1失败而2L仍成立。

若只删末位，也可取末位原利润ℓ(z)作势，因为R_i(z_T)≤ℓ(z_T)，但H=ℓ−e比它准确保独占覆盖。35例规定叶ℓ9/e9、偏离叶ℓ'13/e'1，所以Δℓ4与ΔH12相差8，正是e的变化；不能丢掉它后仍声称同一退款势。
