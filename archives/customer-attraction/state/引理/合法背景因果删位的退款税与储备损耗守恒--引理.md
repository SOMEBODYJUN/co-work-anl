# 全部有序新历史的因果回放

采用[有限单位客户共同目录完整历史模型](../定义/共同目录完整历史模型--定义.md)。固定合法有序背景h₀、负载b、已覆盖集P=supp b，其后r名单位玩家沿原完整纯SPE σ行动。h₀可以离轨；不把任意整数负载自动当成可由指定数量旧玩家产生的历史。空主题、重复标签、零客户、所有有序离轨历史及任意平局均保留。

固定任意剩余原位置集D用于删除，保留位置仍按原相对次序。对删后任意新有序历史，从h₀按原位置重建：保留位读新历史已经给定的动作，遇D中的虚拟位就在**当前已重建的精确有序历史**查询σ并插入规定动作；下一保留位采用该提升历史的原σ动作。末尾虚拟位也完成。这定义整个删后计划τ，不是只删除actual终局的固定主题。

在任意保留角色i、任意新历史h，规定行动和改任意合法A后沿τ完成，分别提升为同一原节点的两个原σ真实孩子叶z_S、z_A。因此可用原全部子局IC
Γ_i(h,A)=u_i(z_S)−u_i(z_A)≥0。更早保留者偏离后，后续虚拟动作随提升历史改变；不能冻结为原actual删者主题。τ通常不是删后物理游戏的SPE。

# 精确退款、全历史后悔与辅助税游戏

任一提升叶z，客户x有固定背景b_x、被删覆盖者数d_x、保留覆盖者数t_x，总负载c_x=b_x+d_x+t_x。对当前保留玩家覆盖的客户有t_x≥1，故c_x−d_x=b_x+t_x≥1。物理删除D带来的非负退款为
\[
 R_i^D(z)=\sum_{x\in S_i}\frac{d_x}{c_x(c_x-d_x)},
 \qquad u_i(z\setminus D)=u_i(z)+R_i^D(z).
\]
这是1/(c−d)−1/c的逐客户恒等式；删后物理利润仍含固定旧背景分摊。

同一新节点的真实单步偏离增益准确为
\[
 \boxed{u_i(z_A\setminus D)-u_i(z_S\setminus D)
 =-\Gamma_i(h,A)+R_i^D(z_A)-R_i^D(z_S).}\tag{IC-REFUND}
\]
所以精确后悔是对右边取max_A，因规定动作自身给0而非负，并有
\[
 \rho_i(h)\le\max_A[R_i^D(z_A)-R_i^D(z_S)]_+.
\]
保留原严格IC可抵消一部分退款差，比只用最大退款更精确。若对**全部新历史与全部合法A**都有Γ_i(h,A)≥R_i^D(z_A)−R_i^D(z_S)，τ才是删后完整SPE；本来源没有证明普遍满足该条件。

在删后物理游戏对保留玩家i收取终局依赖税R_i^D，则净收益精确回到其原提升叶收益。每个物理完整有序终局均可按上述规则唯一提升，故税函数有定义，τ确为这个**改变收益的辅助游戏**的完整SPE。不能把它称为原单位客户物理游戏的另一个SPE，也不能直接代入只对原模型精确SPE的较少人数福利定理。

此退款IC与[既有因果多删位合同](因果多删位的全历史退款与锐乘法误差--引理.md)是同一逐客户代数；本原稿进一步显式保固定背景收款和下述储备损耗。已有乘法近似或一份actual叶后悔预算也没有免费移除全部新历史的税。

# 同一叶删者利润的全部去向

记U_D为提升叶z中D的原利润和，E_D^new为b_x=t_x=0<d_x的客户数：它们原背景未服务且只由删者覆盖。对固定旧背景每名玩家也有份额退款；合计
\[
 R_{\rm bg}^D=\sum_{x:b_x+t_x>0}
             \frac{b_xd_x}{c_x(b_x+t_x)},
\]
其中零负载无贡献；b=t=0时单独定义为0，不用0/0。保留者退款在同一客户的总和为t_xd_x/[c_x(b_x+t_x)]。当b+t>0，两种退款相加恰为d/c，即删者原来在此客户的总利润；当b=t=0<d，删者原共同得1，删除后客户完全消失，没有退款收款者。于是
\[
 \boxed{U_D=E_D^{new}+\sum_{i\notin D}R_i^D+R_{\rm bg}^D.}\tag{CONSERVE}
\]
所有项非负。无背景时R_bg=0，所有保留者退款恰为U_D−E_D^new。原actual叶的U_D不能给互斥偏离叶的退款重复提款；每个提升叶有各自的完整守恒。

# 储备的精确批量损耗

在同一背景b下，原剩余玩家利润和为U，原背景外实际新覆盖为W_new。把活跃利润分成新客户的W_new和旧客户的U_old，则
\[
 V_b(z)=W_{new}+U=2W_{new}+U_{old}.
\]
物理删除D后新覆盖恰减少E_D^new，活跃利润变为U−U_D+Σ_(i∉D)R_i^D。代入CONSERVE即得
\[
 \boxed{V_b(z\setminus D)=V_b(z)-2E_D^{new}-R_{\rm bg}^D.}\tag{LOSS}
\]
删者原利润和保留者退款在这个储备中抵消；实际留下双倍新独占覆盖损失和旧背景收到的退款。固定同一提升叶后，批量损耗只依赖D，不依物理删除次序；分次背景退款望远镜为同一背景的最终份额增加。此结论不假设任一步删后计划理性，更不保证修复时终叶仍不变。

D为空时所有变化0；D删全部剩余玩家时保留和为空，新独占损失是全部W_new，旧背景接收全部旧客户活跃利润，LOSS仍给删后V=0。r=0可作空和代数终端，不需把零人策略当归纳前提。任何客户若c=0则不进原利润或退款；有当前保留覆盖的客户始终有正分母。

若能从τ构造真正删后完整SPE η，仍需另控V_b(η)−V_b(τ)。LOSS没有这项修复成本；IC-REFUND的正部位于不同真实孩子，也不提供跨枝共同付款。

# 一步背景储备与失败归纳接口

令总最终覆盖W含P，旧背景玩家最终总利润U_past。因W_new=W−|P|、U=W−U_past，
\[
 V_b(z)=2W-|P|-U_{past}.
\]
实际当前S的原最终利润u，在原实际孩子将S记入固定背景后有
\[
 V_b(z)=|S\setminus P|+u+V_{b+1_S}(z_{tail}).\tag{STEP-V}
\]
定义总覆盖补全F_r(P)=max_(T₁,…,T_r)|P∪∪T_j|，F₀(P)=|P|。记G=F_r(P)、H=F_(r−1)(P∪S)、δ=G−H≥0，候选缺口D_h=G−|P|−V_b(z)。代入STEP-V精确得
\[
 \boxed{D_h=\delta-u+D_{hS}.}\tag{GAP}
\]
r0时D=0。归纳若只假设孩子D≤0还须付δ≤u；[已有十一客户实际路径](../反例/在轨最优补全损失的逐期收费--反例.md)的实际第二步δ=3>5/2=u已否此逐步加强。更重要的是，这里的整体背景RESERVE也已由另一旧证书反驳，见[同批精确真值校正](../资源/背景储备候选的后续反驳与退款归纳边界--资源.md)。精确LOSS/退款IC不依赖该候选真值，仍有效。

# 原根删位压力与正确修复方向

原稿复用[既有实际根删第二位族](../障碍/真实根删位的小后悔与向上可信修复差--障碍.md)的m5,a1：原W10、删者独占e0、删者原利润2、同actual总退款2。无旧背景，LOSS给原V20和回放V20，没有免费增加。每份真正四人SPE均W'=11，所以真实修复储备变22，比回放多2；此例恰等于实际总退款，根后悔只有2/3。它只核量纲，不证明普遍修复增量≤退款，也不是新零后悔反例或half反例。

对任意真正同目录m−1人SPE η，写W_η=W−e_i+d_i，其中d_i可正、零、负；令Δ_m=OPT_m−OPT_(m−1)。若子人数已有OPT_(m−1)≤αW_η，则
\[
 OPT_m-2W\le\Delta_m-\alpha e_i+\alpha d_i-(2-\alpha)W.
\]
归纳需要某个可信删后福利的**上界**以及同一最优边际付款，不能以只保证不向下损失的修复代替。保真实子局slack的准确恒等式已在[有符号修复引理](删位归纳的有符号修复差与锚定最优边际--引理.md)完整保，LOSS仍不控制d_i。
