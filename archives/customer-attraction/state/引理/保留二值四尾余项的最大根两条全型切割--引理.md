# 保留二值四尾余项的最大根两条全型切割

## 1. 真实分支与结论

沿用有限单位客户、五位单位提供者、有限非空共同标签目录及任意完整有序历史纯SPE模型。标签覆盖不必单射；空主题、重复选择及所有离轨平局保留。记实际根利润为 $u$，全目录最大覆盖大小为 $K$，五个最优比较索引的覆盖并集大小为 $O=\mathrm{OPT}_5$。若 $K=0$，全部值为零，结论直接成立。

强制根选择任意大小恰为 $K$ 的合法标签 $T$，以后继续原完整策略。真实四尾为 $(A,B,C,D)$，强制根最终利润为 $z\le u$。根本身在这条分支不必最优，四位后继却是该子博弈的真实SPE。以下两条关系同时对所有这种实例与策略成立：

\[
\boxed{2809914000\,O+24089689022\,K\le146401652371\,u,}\tag{1}
\]
\[
\boxed{5619828000\,O+13417823981\,K\le153757088490\,u.}\tag{2}
\]

保存文件中的 `ratio_for_basis=11/50,13/50` 是发现器选择对偶活跃基时的参数，**不是**式(1)、(2)的适用条件。完整有理证书一旦逐型成立，两条行对全部合法 $u/K$ 都有效。它们是必要关系；没有认证这些行最佳、达到或单独足以证明半覆盖。

## 2. 必须保留的当前二值余项

设客户在根主题的会员位为 $t\in\{0,1\}$，在实际四尾的会员位为 $a=(a_0,a_1,a_2,a_3)$，$n=\sum a_i$。客户给四尾总利润、强制根利润的贡献是

\[
V=\frac n{t+n},\qquad z_x=\frac t{t+n},
\]

仍约定零分子为零。对四个合法比较索引，客户出现 $e\in\{0,\ldots,4\}$ 次，对比利润为 $R_e=e/(t+e)$。

使用[二值背景四尾两斜率定理](../定理/二值背景四尾两斜率利润界--定理.md)的**当前**证书

\[
\beta_0=1999/1000,\qquad\beta_1=5/3.
\]

将实际第一尾强制改成实际末尾 $D$，再按原策略得到真实后继 $(Q,R,S)$；其客户会员位为 $(q,r,s)$。没有把这一强制首尾当作最优节点。下列局部行都按同一个客户计算，但其全体客户之和来自真实策略的合法不等式：

对路径 $y$ 的真实位置 $i$，

\[
K_{y,i,h}=\frac{y_i}{t+\sum y}-\frac{h}{t+\sum_{v<i}y_v+4-i}.
\]

实际路径 $y=a$ 可用 $i=0,1,2,3$，离轨路径 $y=(a_3,q,r,s)$ 只用 $i=1,2,3$；$h$ 是七个标签中任一个的会员位。这是强制复制合法标签后的保底行。末位四查询和最后两位六索引对行分别为

\[
E_y=4\frac{y_3}{t+\sum y}-\frac e{t+y_0+y_1+y_2+1},
\]
\[
P_y=6\left[\frac{y_2+y_3}{t+\sum y}
+\frac{y_2}{(t+y_0+y_1+1)(t+y_0+y_1+2)}\right]
-\frac{e(4-e)}{t+y_0+y_1+1}
-\frac{e(e-1)}{t+y_0+y_1+2}.
\]

第二行是原真实末两人索引对预算，并非任意离轨双回复可相加；其合法性已在所引二值四尾定理证明。另有第一尾真实IC

\[
F=\frac{a_0}{t+n}-\frac{a_3}{t+a_3+q+r+s}.
\]

当前十三个非零乘子如下，未列行取零；K行的字母 $a,b,c,d,q,r,s$ 对应 $a_0,a_1,a_2,a_3,q,r,s$。

| actual:1:K:d | $8706046/175619625$ |
| actual:1:K:q | $59145206/175619625$ |
| actual:1:K:r | $19421614/58539875$ |
| actual:1:K:s | $22038942/58539875$ |

令 $r_h$ 为这些局部行，定义

\[
\rho(t,a,e)=\min_{q,r,s\in\{0,1\}}
\left[\beta_t V-R_e-\sum_h\lambda_h r_h\right].\tag{3}
\]

成熟证书已在完整1280压缩型/4096原始会员型通过精确核验；式(3)的160个值及各自达到的辅助位已完整保存于原raw独审。逐客户原余项不小于式(3)，各行全局slack非负，所以任一四比较索引都满足更强的

\[
\sum_x\left[\beta_{t_x}V_x-R_{e_x}-\rho(t_x,a_x,e_x)\right]\ge0.\tag{4}
\]

这不是只从裸两斜率数值界推出的新断言，而是保留其具体证书的余项。也不能替换成旧 $1499/750$ 证书的最小表；[旧保留余项对象](二值四尾保留余项与对齐补余信用--引理.md)使用不同系数及不同残差。

## 3. 同一最大分支上的192个充分局部类型

固定达到 $O$ 的合法比较五元组，客户在五个**索引**中出现 $j\in\{0,\ldots,5\}$ 次。删去一个索引后，四元组出现次数为 $j$ 或 $j-1$。因而五补元的平均比较贡献与平均保留信用是

\[
\bar R(t,j)=\frac{5-j}{5}\frac j{t+j}
+\frac j5\frac{j-1}{t+j-1},
\]
\[
\bar\rho(t,a,j)=\frac{5-j}{5}\rho(t,a,j)
+\frac j5\rho(t,a,j-1),\tag{5}
\]

系数为零的项直接省略，因此不调用 $j=0$ 时的 $e=-1$ 或 $j=5$ 时的 $e=5$。定义

\[
B_x=\beta_t V-\bar R-\bar\rho.
\]

式(4)对五个四元组分别成立，取平均得 $\sum_xB_x\ge0$。这里只用同一最大根分支；未向五条互斥根分支收取五份福利。

另定义末位五查询行的客户贡献

\[
L_x=\frac j{t+a_0+a_1+a_2+1}-5\frac{a_3}{t+n}.
\]

真实末位可逐个改选五个比较标签，故 $\sum_xL_x\le0$。令

\[
f_x=(a_0,a_1,a_2,a_3,-B_x,L_x,z_x,t),\qquad o_x=\mathbf1_{j>0}.
\]

全部局部类型为 $(t,a,j)\in\{0,1\}\times\{0,1\}^4\times\{0,\ldots,5\}$，共192种。其全局约束是

\[
\sum_xa_i=|S(A_i)|\le K\quad(i=0,1,2,3),\quad
\sum_x(-B_x)\le0,\quad\sum_xL_x\le0,
\]
\[
\sum_xz_x=z\le u,\qquad\sum_xt=K,\qquad\sum_xo_x=O.\tag{6}
\]

这里 $j$ 的压缩没有删除标签或合并历史：五比较索引只通过对称的全索引平均出现，故计数充分；真正动态尾路径仍来自完整原策略。

## 4. 两组精确局部乘子及求和

对每一局部型，以下两个乘子向量 $\gamma$ 都满足

\[
\gamma\cdot f_x-o_x\ge0.\tag{7}
\]

| 坐标 | 第1组 | 第2组 |
|---|---:|---:|
| bare0 | $1486666711/702478500$ | 同左 |
| bare1 | $1522176569/702478500$ | 同左 |
| bare2 | $4063524019/1685948400$ | 同左 |
| bare3 | $2802120463/1123965600$ | 同左 |
| negative_retained_binary | $5/4$ | $5/4$ |
| last_query | $0$ | $0$ |
| root_profit | $146401652371/2809914000$ | $5125236283/187327600$ |
| T_size | $-299417419987/16859484000$ | $-97566378899/8429742000$ |

前七个乘子均非负，最后一个允许负数，因为 $T\_size$ 是式(6)中的等式。两组逐型最小余项都是0，各有8个零型；保存的每组7个选基类型都互异且为零型。完整384项有理slack保存在本次固定核结果中。没有把这些选基类型称作游戏，更没有声称存在一份SPE同时达到它们。

求和式(7)，再用式(6)，给

\[
O\le\left(\sum_{i=0}^3\gamma_i+\gamma_7\right)K+\gamma_6u.
\]

两组的 $K$ 系数分别为

\[
-\frac{12044844511}{1404957000},\qquad
-\frac{13417823981}{5619828000}.
\]

清分母即式(1)、(2)。最后查询行在发现器的可用列中保留，但这两组最终乘子为零；不能声称这两条切割靠它承重。相反，四主题各不大于真正全目录最大值 $K$、同枝保留预算和根 $z\le u$ 都在求和中使用。

## 5. 使用边界与证据身份

[最大主题根容量切割](五人最大主题根容量切割--引理.md)用整数总负载包络和裸两斜率平均，得到较简洁的四条行；本文额外保留逐类型余项和各尾主题大小，形成两个不同切割。没有据此断言逐行严格支配旧四行，或它们合成的整个标量松弛已达到半覆盖。两条新行可以作为已有真实模型必要约束追加使用。

原发现器用非负局部客户质量的LP松弛和浮点活跃基得到候选，再用有理消元恢复乘子、逐192型判号。这样的局部松弛允许远多于真实完整SPE的配置；证书从真实策略推出必要条件，不反向实现策略。当前五人完整half已有另一个更强证明，本页仍保留这个独立可复用的辅助工具，不迁移为六人结论。
