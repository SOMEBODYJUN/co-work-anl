# 准确的零背景节点

有限个码c_1,…,c_n∈{0,1}^q，a,b,q正整数，对所有i≠j，Hamming距离满足d≤dist(c_i,c_j)≤q−d，d≥1。每源R_i有a个不同单位客户；每保险单元I_(t,s)有b个不同单位客户，t1..q,s0/1；全部块不交。令P_i=∪_t I_(t,c_i(t))、Pbar_i=∪_t I_(t,1−c_i(t))。有限非空共同目录含A_i=R_i∪P_i和B_i=R_i∪Pbar_i，所有玩家仍单位。

这里只看这些客户全无过去覆盖、当前强制一个主题后仅余末位的准确零背景两人游戏。对含大量旧锚点的多玩家节点不能照搬。6911B主稿四节全文与1632B入口主读，源为自查未独审的构造尝试，非新一般福利关系或新颖性认证；没有有限搜索。

# 真实末位自利比较，覆盖全部合法替代

强制A_i后，末位B_i得a/2+qb；同主题A_i得(a+qb)/2，更低。不同源j给新源a。设h=dist(c_i,c_j)：A_j与A_i保险相同q−h单元，B_j相同h单元；两者至少d个已覆盖单元，均分损失至少db/2，故末位值均≤a+qb−db/2。

所以

\[
 db\ge a\quad\Longrightarrow\quad
 a/2+qb\ge a+qb-db/2,
\]

保证B_i为真实BR；强制B_i后A_i对称为BR。这里db≥a是使用公共距离下界的**充分条件**，不说任意未取紧d的必要条件。所有2n主题、全部新源替代和相同主题均已比较，没有靠BI出口强迫非BR。

在每个根A_i/B_i分别规定其互补末位，根都得qb+a/2，任选规定根，便得完整两人纯SPE。未来确实分享当前新源R_i一半；这不同于只复制旧银行、后继经济仍fresh的旧控制器。

# 自利源复制并不便宜，且此两人机制最优

n≥2时存在一对不同码，距离区间非空迫2d≤q。连同a≤db给qb≥2a，当前根收益qb+a/2≥5a/2。该预算并未被低收益压住：根的q个保险单元在互补回复下全部独享。n1距离约束真空，不能推d≤q/2或qb≥2a；完整互补回复和下一段最优性仍直接成立。

同源互补覆盖a+2qb。任意不同源两主题保险并集最多(2q−d)b（两码或一补码的不同数均≤q−d），总覆盖≤2a+(2q−d)b≤a+2qb。相同主题覆盖更少，同源互补可达。因此在该原两人输入

\[
 \boxed{W=OPT_2=a+2qb.}
\]

这是准确BR原语的福利边界，非一个新的两人正面项目，也不是低福利完整多玩家构造。

# 为什么多玩家重锚还没有SPE证书

若normal前面许多人反复覆盖一个锚P_0，别的码主题会含很多Pbar_0的fresh保险。倒二偏离到它后末位互补回复恰不覆盖这些fresh保险，偏离者独享它们；normal P_0收入已被许多人均分。只分享新源a/2没有控制这笔新保险收益，中间IC可能失败。观察全部有序历史、换模式名、首次BI出口不能替代当前裸收益cap。

若先将所有保险加载到非零旧负载h，加入当前覆盖者后给末位的单元边际差只为

\[
 \frac b{h+1}-\frac b{h+2}=\frac b{(h+1)(h+2)},
\]

而非b/2。零背景db/2码距付款随真实背景改变；不能继续原比较保证新源复制。这是两种具体未付款，不构成所有保险方法不可能。

真正还需完整控制所有中间玩家愿意normal低收益，同时在每个真实进入历史上保留源复制支持/全部未来BR。原稿没找到此机制，没有给任意m低福利路径，也没有以旧银行大小/更多副本/被支配Cauchy式替代它。源外支持可来自别的未覆盖源，不自动是actual W；参[遗漏源账](遗漏源份额恒等式与固定银行控制器的资本界--引理.md)。

# 势形式：正确定位ghost误差，不提供新共同钱

回到原任意有限共同目录、m、完整SPE σ。固定actual位置i与actual前缀，在该节点强制A后原σ真叶为Y_i(A)，删当前这一动作A的多重集为R_i(A)，保留所有过去和真实未来。Φ(y)=Σ_xH_(c_x(y))，H0=0。当前真实利润d_i(A)=Φ(R_i(A)+A)−Φ(R_i(A))，独立ghost主题T加入完整Y后收益g_i(A,T)=Φ(Y_i(A)+T)−Φ(Y_i(A))。

逐客户边际递减给源式

\[
 g_i(A,T)-d_i(A)\le
 \Phi(R_i(A)+T)-\Phi(R_i(A)+A).\tag{P}
\]

为自足连接已有完整列插入税，记k_x=c_x(R_i(A))，更精确为右侧减

\[
 \delta_i(A,T)=\sum_{x\in A\cap T}\frac1{(k_x+1)(k_x+2)}\ge0.
\]

这是同一已知重叠税代数：T客户的ghost边际比向R直接插入少且仅在A∩T差上述项，当前d正好扣Φ(R+A)−Φ(R)。它不新增无条件共同支付；源也只把(P)作为旧去相关义务的解释。

即使A,T iid同分布p，R_i(A)随查询和真实后续重置改变。多人SPE分别最大化各自收益，不是一个最大化Φ的单一响应者；不能用潜势“循环单调性”宣布右侧均值≤0。已证[银行完整根菜单](../反例/笛卡尔银行完整根菜单的低值自洽分布失败--反例.md)的原四人输入有p使ghost均值59/36>真实当前4/3，差11/36，正说明逐行免费去相关不普遍真；本页不重跑旧银行或将它变成half反例。

仅剩一名真实后继时已有[全槽池末两行](均匀全槽池的末两行与共同Jensen储备--引理.md)用其真BR/双查询交换和税支付。多个后继换另一查询分支的早期动作时，更晚回复随完整历史改变；冻结另一整个尾部便失真，仍缺同一actual W上的跨位置响应抵扣。m5早三行、m6早四行的义务不因(P)改名消失，当前five别证亦不证明这个更强逐行桥。源与本页均未报它为新half资金。
