# 最大主题同线证书的不同交叠信用

同一个根利润／最大主题大小上界，可以由不同非负合同组合证明；标量直线相同，不代表逐客户剩余相同。冻结 maxroot_envelope.json 的两份被标量去重跳过的记录，恰提供一个需要保全的例子。本文只从已经完整核准的记录抽取这一不同交叠信用，不重跑发现搜索，也不声称新的全局福利常数。

## 1. 模型与同一条标量界

原模型的客户集 $N$ 有限且单位权重，五位单位提供者顺序行动，有限非空共同目录为
$\mathcal S\subseteq2^N$。固定任意完整有序历史纯 SPE $\sigma$，允许空主题、重复行动、零客户和任意历史依赖平局。记实际第一位最终利润为 $u$、最大主题大小为 $K=\max_{T\in\mathcal S}|T|$。

任选达到 $O=\operatorname{OPT}_5$ 的合法索引五元组，令 $d_x\in\{0,\ldots,5\}$ 为每个客户的覆盖索引数，
$D=\sum_xd_x$、$S_2=\sum_xd_x^2$。重复比较主题按索引分别计数。

两份证书具有相同参数

\[
B=\frac{89090}{1753},\qquad C=\frac{29147}{3506},
\]

均证明 $O\le Bu-CK$。原 JSON 中：

* $\rho=21/100,11/50$ 使用末两人并集税行 $P$；
* $\rho=23/100,6/25$ 使用末两人最优索引对税行 $Q_{\rm pair}$。

这里 $\rho$ 是发现阶段的扫描参数，不是正式命题对实际 $u/K$ 的假设。它在有理证书中被精确消去，故每份恢复后的线性关系分别对全部原模型实例成立。

## 2. 真最大根分支与合法行

选任意达到大小 $K$ 的合法主题 $M$，在根强制选择它，之后沿同一原策略得到

\[
(M,B_2,B_3,B_4,B_5).
\]

根在该枝的收益为 $V$，其余收益为 $v_2,\ldots,v_5$，原根给 $R=u-V\ge0$。被强制根不被当作新枝优化者。记 $p_x=\mathbf1_M(x)+\mathbf1_{B_2}(x)+\mathbf1_{B_3}(x)$，使用

\[
\begin{aligned}
\mathrm{CAP}_j&=K-|B_j|,\quad j=2,3,4,5,\\
J&=v_3-\sum_{x\in B_5}\frac1{\mathbf1_M(x)+\mathbf1_{B_2}(x)+3},\\
L&=5v_5-\sum_x\frac{d_x}{p_x+\mathbf1_{B_4}(x)+1},\\
H&=v_4+v_5+\sum_x\frac{\mathbf1_{B_4}(x)}{(p_x+1)(p_x+2)},\\
P&=\frac52H+\sum_x\frac{p_x}{p_x+1}-O,\\
Q_{\rm pair}&=10H-\sum_x\left[
\frac{d_x(5-d_x)}{p_x+1}+\frac{d_x(d_x-1)}{p_x+2}\right].
\end{aligned} \tag{1}
\]

这些总合同均非负。$J$ 是真第三位在 $(M,B_2)$ 改选合法末主题的最坏分母保证；两位后继仍能任意改变回复。$L$ 是真末位对五个最优索引主题的精确比较和。$P,Q_{\rm pair}$ 来自同一个真实末两人历史的两人税界，十个不同最优索引对保留其重数。完整节点推导见[根分支谱行](五人最大主题根分支交叠谱界--引理.md)第3节。

## 3. 两个完整乘子表示

两种表示的全部合同乘子如下，未列非零行之外的候选行不参与证明：

| 合同 | $P$ 表示 | $Q_{\rm pair}$ 表示 |
|---|---|---|
| $R$ | $89090/1753$ | $89090/1753$ |
| $\mathrm{CAP}_2$ | $8089/3506$ | $1/2$ |
| $\mathrm{CAP}_3$ | $9673/3506$ | $9673/3506$ |
| $\mathrm{CAP}_4$ | $9475/3506$ | $9475/3506$ |
| $\mathrm{CAP}_5$ | $4475/1753$ | $4475/1753$ |
| $J$ | $3960/1753$ | $3960/1753$ |
| $L$ | $565/1753$ | $565/1753$ |
| $P$ | $1188/1753$ | $0$ |
| $Q_{\rm pair}$ | $0$ | $297/1753$ |

每个表示有八个非零乘子。二者有相同 $B,C$，但改变了第二槽大小 cap 和末两人比较组合，逐客户余项因此不同。

对客户型 $b=(c,a_2,a_3,a_4,a_5)\in\{0,1\}^5$、$d\in\{0,\ldots,5\}$，令
$s=\sum b$、$V_x=c/s$，零分子时取零；$c=\mathbf1_M(x)$、$a_j=\mathbf1_{B_j}(x)$。
各行客户系数由 (1) 直接取得，其中 cap 系数为 $c-a_j$。按所选表示定义

\[
\rho_\star(b,d)=B V_x-Cc-\mathbf1_{d>0}
-\sum_{h\ne R}\lambda_h r_h(b,d).
\]

两者在全部192个允许客户型上的精确重数条件最小值为：

| $d$ | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---:|---:|---:|---:|---:|---:|
| $e_P(d)$ | 0 | 0 | $113/1753$ | $226/1753$ | $339/1753$ | $452/1753$ |
| $e_Q(d)$ | 0 | 0 | $3803/17530$ | $7309/17530$ | $3/5$ | $1343/1753$ |

准确含义是 $e_\star(d)=\min_b\rho_\star(b,d)$，而非选定一条策略续局取得此最小值。原作者函数逐型读取后的全记录检查已验证这些值；完整原件、2112个记录／类型组合的核对及六点导出在[发现与恢复计算对象](../计算/最大主题包络发现与有理恢复--计算.md)。

逐客户求和给精确非负恒等式

\[
Bu-CK-O-\sum_xe_\star(d_x)
=B(u-V)+\sum_{h\ne R}\lambda_h\,\mathrm{row}_h
+\sum_x[\rho_\star(b_x,d_x)-e_\star(d_x)]\ge0. \tag{2}
\]

所有合同乘子、总合同和增强客户余项均非负。因此两种谱关系都对任意客户数量、任意原共同目录与任意完整纯 SPE 成立。它们不是对192个游戏的抽样。

## 4. 另表示保留的更大信用

较强谱为

\[
e_Q(d)=\frac{(d-1)_+}{5}
+\frac{297}{35060}(d-1)_+(4-d).
\]

与 $e_P(d)=113(d-1)_+/1753$ 的准确差为

\[
\boxed{e_Q(d)-e_P(d)
=\frac{297}{35060}(d-1)_+(20-d)\ge0,\quad d=0,\ldots,5.} \tag{3}
\]

若 $d\ge2$，差严格为正。于是同一个 $B,C$ 下，$Q_{\rm pair}$ 表示提供

\[
\boxed{O+\sum_xe_Q(d_x)
\le\frac{89090}{1753}u-\frac{29147}{3506}K,} \tag{4}
\]

它比该直线的 $P$ 表示逐重数保留更多最优主题交叠信用。这里的 $e_Q$ 恰与已有 pair-envelope 谱相同，但其根利润／大小系数不同，不能把两条线合并成同一证书。

用
$\sum(d-1)_+=D-O$、
$\sum(d-1)_+(4-d)=5D-S_2-4O$ 清分母，得到

\[
\boxed{26860O+8497D-297S_2+291470K\le1781800u.} \tag{5}
\]

该式与已整理 pair-envelope 的 $K,u$ 系数不同；这里并未用改换两个系数的方式复制旧谱，而是从冻结另一个完整乘子表示与其精确剩余导出。

## 5. 去重范围、源位置和使用边界

原同作者分实现 audit 按 $(B,C)$ 去重，对相同正标量直线只检查第一份表示。为核准四条标量界，这样的范围选择足够；若目标是保全乘子与交叠余项，就不能由“同线”推出“同剩余”。它在本直线上检查的是 $P$ 表示，未检查 $\rho=23/100,6/25$ 的 $Q_{\rm pair}$ 表示。本批因此对全部11个存储记录作192型精确核对，识别出五个不同 $(B,C)$ 和六个不同乘子表示，没有重跑11次浮点发现。

必要后续比较另完整读到boss16_maxroot_review/README第1节：它独立重构了原支持行，并明确记录另一audit已核第一条新旧直线的两种乘子表示。因此这里的“去重跳过”只指本包所领同作者audit的准确范围，不声称所有历史核验均遗漏此变体，也不声称现在才首次出现该证书。该后续审查的新包络与266行分离属于另一个来源对象，本批只比较其旧证书审查部分，不追加处置或重跑其程序。

新表示仍使用第三位 $J$。当前真实节点证明把它作为根源有效；如同既有含 $J$ 包络，也可在实际第二位强制最大主题后仅重记前两个槽，使用真实历史 $(A_1,M)$。不能把强制第三位当作最优者来宣称本式对前三位都有效。共同 $K$ 必须保持为同一目录最大值。

式 (3) 的严格交叠改进不意味着一般半覆盖已由此支付，也不认证完整松弛的最优值、斜率锐性或某个坏点的SPE实现。本对象保全的是冻结证书中实际存在、被标量去重掩去的一种表示及其准确数学后果。更强谱与其他实际来源的联合付款仍须另给完整证书；当前五人整体结论见[五人半覆盖定理](../定理/五人半覆盖--定理.md)。

原命题采用集合目录；若软件扩展为同覆盖异标签并保留各完整标签历史，此证明的成员位域只会扩大而仍有效。该扩展不改变canonical原定义，也不影响空主题、重复选择和任意平局在原模型中的保留。
