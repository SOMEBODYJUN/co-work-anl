# 有限对象和准确结论

取有限端点集合E。每个Y有进入者收益d(Y)∈R及shadow值H(Y)∈R，固定上限u。假设逐叶可行集E_cap={Y∈E:d(Y)≤u}非空，置H_cap=max_{Y∈E_cap}H(Y)。在有限共同目录完整历史游戏中，E可以是同一进入历史后的完整孩子SPE端点；见证标签可保留。这里不把任意raw重置叶自动当成E中的可信端点。

定义
\[
 \mu_0=\max_{Y\in E:\ d(Y)>u}
       \frac{(H(Y)-H_{\rm cap})_+}{d(Y)-u},
\]
无违反列时取μ₀=0。有限性和正分母给μ₀有限且非负。对任意μ≥μ₀，
\[
 H(Y)-\mu(d(Y)-u)_+\le H_{\rm cap}\quad(Y\in E), \tag{1}
\]
\[
 \boxed{\max_{Y\in E}\{H(Y)-\mu(d(Y)-u)_+\}=H_{\rm cap}.}\tag{2}
\]
证明分两类：d≤u时罚为零、H≤H_cap；d>u时由μ的定义，μ(d−u)≥(H−H_cap)_+，故仍有(1)。在E_cap上达到H_cap的端点罚零，给(2)反向不等式。无需连续前沿、凹性或均值约束强对偶。

# 为什么它没有产生共同预算

若E是固定实际节点的可信孩子端点，原完整σ在每个强制主题后的真实查询收益都满足d_i(A)≤u_i。因此每个原source列的铰链罚**逐点为零**，取期望仍为零。它没有[全行均值cap线性对偶](可信端点均值cap的三域与松弛信用--引理.md)中的正项μ_i(u_i−E_pd_i)=μ_iI_i。将铰链写成线性μd会在可行列错误引入另一项，不能作为免费银行。

若某次reset产生d>u_i，其罚μ(d−u_i)可能很大，仍需真实付款；若reset叶不属于原E，(1)根本没有给该叶约束，必须另证可信闭包或显式扩大分析域。μ只存在于这一有限输入，未给统一数值界或总位多项式计算算法；输入接近cap的违反列会使比值任意大。
