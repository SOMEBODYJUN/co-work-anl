# 六人共享真两尾联合消元与分行消元的精确差

取[同一最大潜力主题的真实两尾与实际钱包联合投影](共同最大潜力主题的两尾跨实际钱包投影--引理.md)的六行，沿用该页编号 $r=0,\ldots,5$、原始类型 $v=(a_1,\ldots,a_6,x,o)$ 以及真实共用的 $(y,t)\in\{0,1\}^2$。记 $h=a_1+a_2+a_3+x+1$，$D=a_1+a_2+a_3+a_4+1$，$\theta=o/6$。固定任意六个全局非负权 $\lambda_r$。比较同一组行与同一预算的两个系数

$$
 m(v)=\min_{y,t}\sum_r\lambda_r A_r(v,y,t),\qquad
 s(v)=\sum_r\lambda_r\min_{y,t}A_r(v,y,t).
$$

## 何时完全相等

逐行先减掉自己的最小值。所得六个残量均非负，所以 $m-s\ge0$。等号当且仅当正权行的最小化状态集合有公共元素。无正权行时，交集取全四态。具体的集合如下。二位状态按 $(y,t)$ 排列。

| 原行 | 全部最小态 |
| --- | --- |
| 0，真实第四源 IC | $\{11\}$ 若 $x=1$，否则全四态 |
| 1，同一 $X$ 的最大性 | $\{00,01\}$ |
| 2，$T$ 的裸大小 | $\{00,10\}$ |
| 3，分支真实末位 BR | $\{01\}$ |
| 4，分支两尾 PAIR | $\{10,11\}$ 若 $h=1$，否则 $\{11\}$ |
| 5，actual RC | $\{00,10\}$ |

第 0 行用分母的单调性，第 1 和 2 行直接读出。第 3 行在 $t=0$ 非负，在 $t=1$ 为负，且此时 $y=0$ 严格优于 $y=1$。第 4 行只有 $-H$ 随尾态变化。$H(0,0)=0$，$H(0,1)=1/h$，$H(1,0)=1/h+1/[h(h+1)]$，而 $H(1,1)-H(1,0)=(h-1)/[h(h+1)]$。第 5 行从 $t=0$ 到 $t=1$ 的严格增量为 $(D+1-\theta)/[D(D+1)]$。故仅有正权的行 2 或 5 与正权的行 3 已足以强制每个类型严格改善。其他正权搭配由交集判定，包括 $x=0$、$h=1$ 和全零权。

## 两个互斥选择的定量代价

若 $t=0$，第 3 行相对行最小值至少多出 $(h+1-\theta)/[h(h+1)]$，可取 $y=1$ 达到这个下界。若 $t=1$，第 2 和第 5 行的加权额外代价恰为 $\lambda_2+\lambda_5(D+1-\theta)/[D(D+1)]$。于是

$$
 m(v)-s(v)\ \ge\ \min\left\{
 \lambda_3\frac{h+1-\theta}{h(h+1)},\
 \lambda_2+\lambda_5\frac{D+1-\theta}{D(D+1)}\right\}
 \ \ge\ \min\left\{\frac7{36}\lambda_3,\ \lambda_2+\frac7{36}\lambda_5\right\}.
$$

第二个不等式用 $h,D\le5$、$0\le\theta\le1/6$ 及 $1/z-\theta/[z(z+1)]$ 在正整数 $z$ 上递减。如果只有行 2、3、5 可有正权，第一个不等式逐型取等号。令 $a_1=a_2=a_3=a_4=x=o=1$，则 $h=D=5$，$\theta=1/6$，第二个不等式也取等号。这给定量统一界的尖锐子族。

## 原固定权的有限精确检查

对原正文权 $(4096,800,71,384,512,900)$，全部 256 个类型各核四尾态。最小差 $1632/5$，例如 $v=(1,1,1,0,0,0,0,0)$，此处 $(m,s)=(0,-1632/5)$。最大差 $1760$，例如 $v=(0,0,0,0,1,1,1,0)$，此处 $(m,s)=(8288/3,3008/3)$。全零型给 $(m,s)=(0,-1152)$。附脚本以有理数逐项重建，并核对每个类型的全部 64 种权支撑对交集判定的结果。

若每型的客户质量 $z_v$ 非负，预算右端相同，逐型差乘 $z_v$ 求和恰是两式松弛之差。原固定权下只要总质量正，这一差为正。该比较只使用这六行的分行消元与联合消元。更早的 H3/MP 完整参数族、完整策略实现和六人半覆盖须按各自约束另行证明。
