# 共同最大潜力主题的三尾前接不等式

固定六人完整纯SPE的一条三行动有序历史，按原策略继续得到第四行动A。
在加入A后的背景下选定一个全目录最大潜力主题X。这个**同一个X**可向前
接到第四位的真实偏离源：对每个合法查询Q，成立下文的常数10不等式。
最大性所用权重不改成三尾最坏分母权重。

## 1. 模型、量词及真实后继

采用[共同目录完整历史模型](../定义/共同目录完整历史模型--定义.md)：
有限单位客户、有限非空标签目录、完整有序历史纯SPE，保留空覆盖、同覆盖
异标签、重复行动、零客户及任意历史依赖弱平局。

固定同一完整策略σ和任意合法三行动有序历史h；h可以离轨。令b_j为该历史
对客户j的负载，故0≤b_j≤3。令A=σ4(h)，a_j为其会员，P_j=b_j+a_j。
记u为在h按σ继续时第四位的最终收益，并固定

\[
f_P(T)=\sum_{j\in T}\frac1{P_j+1},\qquad
X\in\arg\max_{T\in\mathcal S}f_P(T),\qquad F=f_P(X).
\tag{1}
\]

有限非空目录保证最大者存在；任取一个后固定。X不能随客户或Q更换。
如果h是根实际前三历史，则A=A4、u=u4，X也可直接使用实际末两位容量
投影已经选定的标签。

仅强制第四位在h选择X，其后沿同一σ的真实有序后继取

\[
Y=\sigma_5(h,X),\qquad Z=\sigma_6(h,X,Y).
\tag{2}
\]

用x,y,z表示相应会员，第四位偏离收益及末位收益分别为

\[
v=\sum_j\frac{x_j}{b_j+1+y_j+z_j},\qquad
t=\sum_j\frac{z_j}{b_j+x_j+y_j+1}.
\tag{3}
\]

u与v不能混同；没有冻结A之后的原两行动，也没有赋予受迫X额外最优性。

## 2. 常数10的全类型必要式

置

\[
\kappa_X=\sum_j\frac{x_j}{b_j+3},\qquad
L_b(X,Q)=\sum_jq_j\left(\frac{x_j}{b_j+3}
                              +\frac{1-x_j}{b_j+1}\right).
\tag{4}
\]

则对全部合法Q同时成立

\[
\boxed{10u-9\kappa_X\ge L_b(X,Q).}
\tag{H3-X}
\]

等价地，其左侧余量为

\[
10u-9\sum_X\frac1{b+3}-\sum_Q\frac1{b+1}
+\sum_{X\cap Q}\frac2{(b+1)(b+3)}\ge0.
\tag{5}
\]

可以对任意固定合法菜单作非负平均。平均表示若干合法纯标签查询的合账，
不是新的可行动分数主题。系数与全部客户共同固定。

### 四份真实预算

下列全局量均非负：第四位的`u−v`，同一X最大性给出的`F−f_P(Y)`、
`F−f_P(Z)`，以及真实末节点的

\[
BR_Z(Q)=t-\sum_j\frac{q_j}{b_j+x_j+y_j+1}.
\]

这些是求和后的全局预算，不声称每个客户自己的激励项非负。令n=b+1，
逐客户定义

\[
\begin{aligned}
E={}&\frac{10x}{n+y+z}-\frac{9x}{n+2}
-q\left(\frac{x}{n+2}+\frac{1-x}{n}\right)\\
&-\frac{x-y}{n+a}-\frac{2(x-z)}{n+a}
-\frac{z-q}{n+x+y}.
\end{aligned}\tag{6}
\]

直接展开得到精确恒等式

\[
10u-9\kappa_X-L_b(X,Q)
=10(u-v)+[F-f_P(Y)]+2[F-f_P(Z)]+BR_Z(Q)+\sum_jE_j.
\tag{7}
\]

### 全部局部余项的解析非负证明

n∈{1,2,3,4}，a,x,y,z,q∈{0,1}。当x=0时，

\[
E=\frac{y+2z}{n+a}-\frac{z}{n+y}-\frac{qy}{n(n+1)}.
\]

对a,q取最不利值，四种(y,z)的统一下界依次为下表左栏。当x=1时，q的
系数为`1/(n+1+y)−1/(n+2)≥0`，负的最大性项在a=0最小；取q=0、a=0
给下表右栏。

| (y,z) | x=0时E的下界 | x=1时E的下界 |
|---|---|---|
| (0,0) | 0 | `2(7−n)/[n(n+2)]` |
| (0,1) | `(n−1)/[n(n+1)]` | `(−n²+6n−2)/[n(n+1)(n+2)]` |
| (1,0) | `(n−1)/[n(n+1)]` | `(n−1)(4−n)/[n(n+1)(n+2)]` |
| (1,1) | `(2n−1)/[n(n+1)]` | 0 |

在n=1,2,3,4时全部非负。式(7)因此证明(H3-X)。这里b≤3是实质条件，
没有将该系数10不经检查地推广到任意更大背景。

零客户时全部和为零；空主题和相同覆盖不影响任何分母。整个证明不除以
收益、缺额、主题大小或客户数，也不使用严格最优性。Y的倒二最优性在这份
四预算证明中未使用，但完整SPE仍提供它；下节限定的扩展锥会用到。

## 3. 指定七预算逐型锥的精确最优性

本节只评价一个明定的代数证书族，**不宣称常数10在真实SPE上锐利**。

在受迫X之后的真实两人子局令m=b+x，

\[
f^X(T)=\sum_j\frac{t_j}{m_j+1},\quad
g^X(T,R)=\sum_j\frac{t_jr_j}{(m_j+1)(m_j+2)},\quad
U^X(T,R)=f^X(T)-g^X(T,R).
\]

令s=U^X(Y,Z)、t=U^X(Z,Y)。对合法L,R定义

\[
TP(L,R)=s+t+g^X(Y,Y)-f^X(L)-f^X(R)+g^X(L,R)\ge0.
\tag{8}
\]

其完整付款用`J_L=σ6(h,X,L)`：

\[
\begin{aligned}
TP(L,R)={}&[s-U^X(L,J_L)]
+[U^X(J_L,L)-U^X(R,L)]\\
&+[t-U^X(J_L,Y)]+[g^X(Y,Y)-g^X(Y,J_L)].
\end{aligned}\tag{9}
\]

前三项依次是Y的真实偏离、L后J_L的真实末位比较、Y后Z对合法J_L的
真实比较；最后一项逐客户为非负的`y(1−j_L)/[(m+1)(m+2)]`。

取七个非负全局权`(C,α,β,γ,η1,η2,η3)`，分别用于第四位改X、两条最大性、
Z查询Q，以及`TP(Q,X),TP(Q,Q),TP(X,X)`。从目标
`Cu−(C−1)κ_X−L_b(X,Q)`减去这些预算所得逐客户余项记E_w。
完整显式128型系数及公式保在工作稿`maxb_h3_pair_strength.md`第3节。
以下四型直接代入即得：

| 型 (b,a,x,y,z,q) | E_w |
|---|---|
| A=(0,0,0,0,0,1) | `γ+η1+3η2/2−1` |
| B=(0,1,0,0,1,0) | `β/2−γ−η1−η2−η3` |
| D=(0,0,1,1,0,0) | `(C+2)/6−β−η1/6−2η2/3+η3/6` |
| H=(0,0,1,1,1,0) | `(1−γ−η1)/3−5η2/6` |

若全部128型余项非负，则

\[
E_A+3E_H=-\eta_2
\quad\Longrightarrow\quad \eta_2=0,\quad\gamma+\eta_1=1.
\]

又有精确对偶恒等式

\[
\boxed{C-10=14E_A+12E_B+6E_D+6E_H+\eta_1+11\eta_3\ge0.}
\tag{10}
\]

四预算解`(10,1,2,1,0,0,0)`可行，故此七权逐型锥的精确最小值是10。
C=10时，上式与A、B、D行强制η1=η2=η3=0、γ=1、β=2。另两型

\[
E(0,1,0,1,0,1)=\frac{\alpha-1}{2},\qquad
E(3,0,1,0,1,0)=\frac{6-5\alpha}{20}
\]

给`1≤α≤6/5`。两个端点均有完整128型有理非负证书；E对α仿射，故全
最优面恰为`(10,α,2,1,0,0,0), 1≤α≤6/5`。这是精确证书与凸性论证，
没有进行数值参数扫描；新增三份TP在此目标的最优证书中均为零，不说明
它们在别的目标或更多联合信息下无用。

## 4. 旧来源关系、有限接口及恢复资产

`AP_(29/2)=H3-X_(10)+(9/2)(u−κ_X)`。

因此本式加SAFE支付该特定旧AP行。旧BNS最大者针对`1/(b+3)`，与此处
`1/(b+a+1)`最大者的身份不同，不能只替换名称来证明本式。

未知XQ只带正系数，可以沿用旧共同上包络作必要放松。若后续加入含负XQ的
物理相容行，则这些坐标必须按新合同成为真实交叠，原规范min结论不再自动
成立。17轨道本身不包含新标签X，不据它们单独声称推出所有SAFE。
