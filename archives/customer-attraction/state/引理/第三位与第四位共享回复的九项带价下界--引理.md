# 第三位与第四位共享回复的九项带价下界

## 任意真实源与全目录报价

采用[共同目录完整历史模型](../定义/共同目录完整历史模型--定义.md)：有限单位客户、有限非空共同目录、单位玩家，固定一份任意完整有序历史纯SPE σ。空主题、重复主题、零客户及全部离轨平局保留。以下可在任意合法真实源h使用，余r≥4人，背景客户负载pₓ为非负整数，源规定者沿原σ的最终收益为u。

任取合法B,C,Z。在h强制B，然后仍沿同一σ得到

\[
(h,B,D,M_1,\ldots,M_{r-4},E,F).
\]

只有B被强制；D、各M、E、F均是在各自完整真实前缀的规定行动。源u和强制者在新叶的收益U_B由源IC比较，不能把新叶B也称最优。两套客户价格πₓ,ρₓ非负，并有全目录合同

\[
\pi(H):=\sum_{x\in H}\pi_x\le v,\qquad
\rho(H):=\sum_{x\in H}\rho_x\le w
\quad\text{对每个合法主题 }H.
\]

v,w是两个各自有来源的钱包，K=max_H|H|。它们可以由不同真实节点给出，但各项系数均须付款。

固定九个任意非负权α,β,γ,δ,ε,ζ,η,θ,ι。对单客户用b,c,z,d,e,f记B,C,Z,D,E,F会员位，s=Σ_j1_Mj∈{0,…,r−4}，q=p+b，v₀=q+d+s。定义

\[
\begin{aligned}
H={}&{\alpha b-\beta d-\delta e-(\gamma+\delta)f\over v_0+e+f}
 +{\beta c\over q+r-1}+{\gamma c\over v_0+e+1}\\
&+{\delta(c+z)\over v_0+1}
 -{\delta(e+cz)\over(v_0+1)(v_0+2)}
 +\varepsilon\rho d+\zeta\rho e+(\eta\pi+\theta\rho+\iota)f.
\end{aligned}\tag{H}
\]

若第一项分母零，则p=b=d=s=e=f=0，分子也零，定义其值零；其它分母正。令

\[
\psi(p,r,b,c,z,\pi,\rho)=
\min_{d,e,f\in\{0,1\},\ 0\le s\le r-4}H.
\]

结论为

\[
\boxed{\alpha u+\eta v+(\varepsilon+\zeta+\theta)w+\iota K
\ge\sum_x\psi(p_x,r,b_x,c_x,z_x,\pi_x,\rho_x).}\tag{NINE}
\]

这里ψ还依赖所固定九权，略去该参数以便书写。一般性由下述解析恒等式承担，不由有限有理网格外推。

## 九个非负关系的真实节点

U_D,U_E,U_F均是上述同一强制B真叶的最终收益。九关系依次为

| 权 | 非负关系 | 节点及理由 |
|---|---|---|
| α | u−U_B | 原源h的IC，偏离B后保持真后继 |
| β | U_D−Σ_C1/(p+1_B+r−1) | h,B后的第一真后继D可安全查询C；后继可全部变化，单客户最终负载至多p+1_B+r−1 |
| γ | U_F−Σ_C1/(p+1_B+1_D+Σ1_M+1_E+1) | 真末F在其原完整前缀查询C，分母精确 |
| δ | U_E+U_F+Σ_Eg−f₀(C)−f₀(Z)+g(C,Z) | 真末两人E,F在背景v₀下的强PAIR |
| ε | w−ρ(D) | D是共同目录合法主题 |
| ζ | w−ρ(E) | E是共同目录合法主题 |
| η | v−π(F) | F是共同目录合法主题 |
| θ | w−ρ(F) | 同一个F亦可用另一价格合同，另付θw |
| ι | K−|F| | 最大主题大小合同 |

PAIR行中f₀(X)=Σ_X1/(v₀+1)，g(X,Y)=Σ_(X∩Y)1/((v₀+1)(v₀+2))，Σ_Eg=g(E,E)。保留一份C∩Z交叠，不能用普通两利润税替换后还沿用(H)。

为使本页自足，证明该强式。背景v₀下实际末两人是(E,F)，令R是先人强制C后的同一σ真实末回复。记U(X,Y)=f₀(X)−g(X,Y)，则三IC为

\[
I_1=U(E,F)-U(C,R)\ge0,\quad
I_2=U(R,C)-U(Z,C)\ge0,\quad
I_3=U(F,E)-U(R,E)\ge0.
\]

原末位仅把R作为合法查询，没冻结强制后的末位。展开有

\[
U(E,F)+U(F,E)+g(E,E)-f_0(C)-f_0(Z)+g(C,Z)
=I_1+I_2+I_3+g(E,E)-g(E,R)\ge0,
\]

最后余项是E\R上的非负税。此即[末两人强比较](末两人重叠比较与任意索引聚合--引理.md)的相同合同。

把表中九项按权相加，逐客户份额展开后**恰等于**

\[
\alpha u+\eta v+(\varepsilon+\zeta+\theta)w+\iota K-\sum_xH_x.
\]

特别δ行实际份额的负号给(H)中的−δe、−δf，而税项给−δe/((v₀+1)(v₀+2))，查询交叠给−δcz/同分母。所有原关系非负，再用Hₓ≥ψₓ即得(NINE)。

中间M只以其会员总数s进入全部这些项，每个0≤s≤r−4都能由某组二元会员实现。因此局部字面域恰压缩为8(r−3)候选；r4时中间M为空，仍有D,E,F三位真后继与八态。逐客户取最小的隐藏会员未必能联合实现一份策略，但扩大局部选择域只削弱右端，必要式仍有效。若再加身份相关M项，应重证该压缩。

## 六人的两个源保持不同背景

令实际六主题为A₁,…,A₆，收益u₁,…,u₆；a_j为单客户会员位。任取六个合法比较索引T_i，重复/空均允许。先在实际第四位源强制T_i，再在另一个实际第三位源强制已得到的B_i：

\[
(A_1,A_2,A_3,T_i,B_i,C_i),\qquad
(A_1,A_2,B_i,D_i,E_i,F_i).
\]

前一源背景p+a₃，后一源背景p=a₁+a₂；它们是不同历史。B_i、C_i作为具体共同目录主题在两处始终共享身份；未要求其它回复相同，也未将A₃保留在后一源背景。用(NINE)于后一源，r4、B=B_i、C=C_i、Z=A₆。

取πₓ=1/(a₁+a₂+4)，v=u₃。实际第三位在(A₁,A₂)查询任意H，后续三人即使全覆盖该客户也至多p+4，故其真实IC给π(H)≤u₃。取ρₓ=1/(a₁+⋯+a₅+1)，w=u₆，实际末位精确最佳回复给ρ(H)≤u₆。这两项均是全目录报价，适用于新旧分支产生的所有合法主题。

\[

=(44,1,7,2,6,7,1,7,2),\qquad\text{总和 }77.
\]

单索引成本是45u₃+20u₆+2K。六索引逐项求和得到

\[
\boxed{270u_3+120u_6+12K
\ge\sum_x\sum_{i=1}^6\psi(p_x,4,b_{ix},c_{ix},a_{6x},\pi_x,\rho_x).}\tag{SIX}
\]

β1保留首后继D_i的安全IC，δ2保留末两人强PAIR；该行不是把三人尾机械当作两人尾，也不是[第三位完整16词菜单投影](真实第三位六索引菜单的完整直方图投影--引理.md)的同一隐藏域。后者是直接强制T_i后的三尾及全16词联合直方图；这里把旧第四位所得B_i再作为新第三位查询，消去新D_i,E_i,F_i，同时保留旧(B_i,C_i)联合会员。两者均为必要行，各自背景和投影方向不可混用。
