# 两次强制回到同一个有序源

采用[共同标签目录完整历史模型](../定义/共同目录完整历史模型--定义.md)：有限单位客户、有限非空共同目录、完整有序历史纯SPE σ；空主题、同覆盖异标签、重复、零客户和任意离轨平局均保留。固定任意真实源历史h，尚余k≥3位，客户过去负载p，原规定当前收益r。另固定整局actual末位收益u、其过去负载ell，以及同一共同目录最大主题大小K（用公共上界也可）。h可以离轨；除非h是actual前缀，不把r换成一个actual收益。

任意合法T,Q，从h强制T后真续局为(H₁,…,H_(k−3),B,C)；再**回到同一个h**强制第一枝产生的合法C，原σ给(G₁,…,G_(k−3),J,V)。这不是继续添加玩家。两枝同源r可分别比较，但被强制T/C者不被假设在其新枝最佳回复。保第一枝C与第二次源行动C的同一主题，以及两边可跨枝查询的B/J/V身份。

对客户x写t,q,b,c,j,v为相应会员，s=Σ1_H、s'=Σ1_G，z₁=p+t+s+b+c、z₂=p+c+s'+j+v。零分子份额为零；对应会员非零时其终局分母必正，不把有符号分子先合并后在0分母求商。

# 三十四条真实预算

用“预算B_a减逐客户特征E_a之和非负”的统一方向，完整坐标为：

|坐标与数量|外部预算|单客户特征|
|---|---|---|
|sourceT、sourceC，2|r、r|t/z₁、c/z₂|
|price:e，e=b,c,j,v，4|u|e/(ell+1)|
|cap:e，同四主题，4|K|e|
|last1:e，e=t,q,b,j,v，5|0|e/(p+t+s+b+1)−c/z₁|
|last2:e，e=t,q,b,c,j，5|0|e/(p+c+s'+j+1)−v/z₂|

|safeJ:e，e=t,q,b,c,v，5|0|e/(p+c+s'+2)−j/z₂|
|price:s、price:ss，2|(k−3)u|s/(ell+1)、s'/(ell+1)|

source两行是h同一原当前者的真实单步IC；last是对应真末位对合法主题的查询；safe是对应真倒二玩家改题后至多再有一名覆盖者的保底。因此safe不冻结改题后的末回复。price来自actual末位可查询目录每个真后继，middle逐个加总；cap同理。每行只在对所有客户求和后非负，单客户特征可正可负。

任意34维非负实数θ（实现用有理数）定义E_θ=Σθ_aE_a、B_θ=Σθ_aB_a。客户无关的同一组θ先加完整真行，得到B_θ−Σ_xE_θ(x)≥0。再置
\[
 \Gamma_\theta(p,ell,t,q)=\min_{b,c,j,v\in\{0,1\},\ 0\le s,s'\le k-3}E_\theta,
\quad \boxed{B_\theta\ge\sum_x\Gamma_\theta(p_x,ell_x,t_x,q_x).}\tag{CONE}
\]
左减右精确等于各真非负行θ加权之和，加Σ(E_θ−Γ_θ)。这是一般局部必要行，未给r、u、K在全局共同福利中的付款。

# 计数压缩的准确“精确”域

两组middle会员在这些特征中仅以s/s'及同价线性成本出现。每个0…k−3整数都由某个二元串实现，所以扩大隐藏二元域的最小值**恰等于**16(k−2)²个计数候选的最小值。k3/4/5/6分别16/64/144/256。它不假设σ按无序计数行动，也不声称每个局部最小赋值能在同一完整σ中同时实现。

若middle加身份相关IC或异价，则须重做此压缩。任意真实h只有0≤p≤m−k和0≤ell≤m−1的一般背景范围；actual源另有二者关系，不能直接移用旧五人窄表。全部原余项以实际主题身份保留，比先各枝独立最小化更强，但还未构造一般主乘子。
