# 标记、分支与正分母域

采用[共同目录完整历史模型](../定义/共同目录完整历史模型--定义.md)。以下恒等式对任意完整策略σ成立，**不要求SPE**；应用SPE时仍需所有原有序节点真实最佳回复。客户/目录有限，空主题、同覆盖标签、重复、零客户和任意离轨平局均保留。

对真实有序历史h，记b_h(x)为过去负载，c_h(x)为从该h按同一σ完成后的总负载。固定非负标记incidence a_x，可为一个已有主题指标或固定旧群体的主题指标和；后来玩家不加入分子。ρ>0时无额外限制；ρ0只允许a_x>0⇒b_h(x)>0。定义
\[
 J_a(h)=\sum_{x:a_x\ne0}{a_x\over\rho+b_h(x)},\quad
 R_a(h)=\sum_{x:a_x\ne0}{a_x\over\rho+c_h(x)},\quad L_a(h)=J_a(h)-R_a(h).
\]
ρ0且a为旧群体时，R恰该群体最终利润；ρ>0仅为代数reserve，不引入幽灵玩家或新合法行动。零标记项直接不求分母，尤其不约定0/0。

# 一条完整真实尾的时钟

从h按σ真正出现的后续主题为S_(d+1)…S_m，d=|h|，沿该同一分支过去负载记b_t。用每次hit使分母加1，逐客户望远镜得
\[
 \boxed{L_a(h)=\sum_{t=d+1}^m\sum_{x\in S_t:a_x\ne0}
 {a_x\over(\rho+b_{t-1}(x))(\rho+b_t(x))}\ge0.}\tag{CLOCK}
\]
不能跳过任何真实hit再重排其名次。对同前缀客户负载的h,h'，使用**同一a**，J相同，所以
\[
 \boxed{R_a(h')-R_a(h)=L_a(h)-L_a(h').}\tag{EXCHANGE}
\]
它不是单一根actual时钟预算：两个尾各用自己的真实后继。同计数只保证相同b，不保证c或R相同。[三人完整反例](../反例/同计数历史交换的完整策略与零实际时钟--反例.md)有L(BA)=0、L(AB)=2/[(ρ+1)(ρ+2)]，实际旧群体利润4→3；末位最佳值相同也不消差。

# 固定全行权之后的客户incidence净流

有限有向图顶点v为具体真实有序历史h_v；每边e:u→v仅连相同b的两端，带固定标记a_e及与客户无关的非负全行权λ_e。ρ0逐边正标记须有共同前缀正负载。令
\[
 d_v(x)=\sum_{e:\,head(e)=v}\lambda_ea_e(x)
       -\sum_{e:\,tail(e)=v}\lambda_ea_e(x).
\]
有限换序得到
\[
 \boxed{\sum_e\lambda_e[R_{a_e}(h_v)-R_{a_e}(h_u)]
 =\sum_{v,x:d_v(x)\ne0}{d_v(x)\over\rho+c_v(x)}
 =-\sum_v L_{d_v}(h_v).}\tag{FLOW}
\]
最后将L对signed incidence线性延伸，不把其每项称非负租金。全部J项逐边同b抵消；ρ0若b_v(x)=0则每入/出标记在x都0，d_v(x)=0，故合法。

逐顶点逐客户d_v=0足以完全抵消交换债；按固定主题标记分别守恒更强，也足够。**只有标量Σ入λ=Σ出λ并不够**。五客户同一σ取BA→AB标A、AB→BA标B，各权1，标量平衡，但总债−1（ρ0）：A旧持有者从2变1，B持有者仍2。ρ=1、2时分别为−1/3、−1/6。

不能逐客户另选λ，再称同一组原玩家激励行。边的代数反向存在也不代表反向的真实BR非负行存在。FLOW给检验表示，不自动构造可购买的激励乘子。

# 哪种归并合法

先完整算出各h_v真实终局客户负载z=c_v，再设d_z=Σ_(v:c_v=z)d_v。则
\[
 \sum_{v,x}{d_v(x)\over\rho+c_v(x)}
 =\sum_{z,x:d_z(x)\ne0}{d_z(x)\over\rho+z_x}.\tag{TERMINAL}
\]
ρ0且z_x0时各原b_v(x)亦0，d_z(x)=0。此归并只收集同一个已确定收益函数的端点，没有改变任何历史的策略或真尾。它弱于逐顶点守恒，但不能反过来先按相同prefix count规定唯一续局。AC/CA例可有两个非零历史标记，合到同一真实终局后净标记0，精确债也0。
