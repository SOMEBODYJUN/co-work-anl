# 模型与真实比较的四个对象

任意有限单位客户N、有限非空共同**标签**目录、m≥1单位提供者，固定全部有序历史上的纯SPE σ，actual叶B与actual利润u_i(B)、W=Σ_i u_i(B)。允许同覆盖/空标签、重复行动、零客户和任意离轨平局。主题标签的覆盖集合相同也不把有序历史合并；以下写交并差时指它们的客户覆盖集合。

7169B主稿全部七节已全文实读，来源是旧局部关系，非新福利/新颖性或外审认证。其关键是**在同一旧历史复制首偏离源行动**，而不是换名字调用actual-return或actual-prefix reset。固定非actual context t=(g,ℓ)，g为当前ℓ之前的完整有序历史；令k<ℓ为g与B首次不同的位置，a=g_k，b=σ_ℓ(g)。定义
\[
A=\operatorname{finish}_\sigma(g),\qquad
Q=\operatorname{finish}_\sigma(g,a).
\]
下表区分四叶，避免把不同IC和钱包互换。

|对象|当前之前的历史|当前行动|之后|
|---|---|---|---|
|A：原规定完成|g|b|原σ|
|Q：源行动复制|同一g|a=g_k|原σ|
|actual-prefix reset|B的实际前缀B_<ℓ|b|原σ|
|actual-return|同一g|实际B_ℓ|原σ|

a是真在旧g的第k位出现过的行动，一般已不是最初比较最优元组owner的T_i。代数其实对**任意**k<ℓ、a=g_k都成立；选首偏离k是为同客户来源提供真实见证，不是额外假设计数策略。

# 同客户流的来源支持须单独保留

对原客户保持的actual-prefix reset图，固定非actual目标t。任一reset父能到达t，其角色必须是首差异k，父的reset行动必须为a：否则actual-prefix重置后首次差异位置或行动与g不符。所有这些父的reset规定叶等于A；父可有多个、原父历史可不同，不能叫唯一父。直接INIT若进入t，其query-source角色也必须为k、强制行动为a。

若使用canonical比较来源的INIT，以及每条正边或optional-common边只发送**父当前行动所覆盖的同一客户**，则间接输入客户在父行动a内、在接收规定行动b内；直接输入客户本来在初始query行动a内，并由接收者b覆盖。于是
\[
h_{tx}>0\quad\Longrightarrow\quad x\in a\cap b.
\tag{SOURCE-SUPPORT}
\]
这是主稿所用来源域。必须同时保持原客户、不在边上跨客户重采，也不把最初T_i代替已经改变的首偏离行动a。

**与广义密度的边界。** 当前[来源密度定理](../定理/同客户来源保持流的加强初始化与节点密度--定理.md)的GENERAL-DENSITY允许更宽query-source合同：初始source行动未必覆盖x，只要求注入到真实future coverer并满足同客户库存/边cap。在这个广义域，直接source可不含x，不能仅由f≤1推出本式的x∈a。应用本引理时，应保上述canonical/action支持条件，或直接另设h只支持a∩b；不得把广义密度悄悄加强成来源覆盖。后面复制代数对已选J=a∩b独立成立，不需要流存在。

# 一条真实复制IC与同枝均分

在真实历史g，当前选a是一个合法偏离，之后仍按同σ。因此
\[
\ell_t^{\rm copy}=u_\ell(A)-u_\ell(Q)\ge0.
\tag{COPY-IC}
\]
这里SPE只用于整行动优势非负，未按客户重权IC。Q中第k与第ℓ位都选a，单位提供者对每个喜欢a的客户得到相同1/c_Q份额，所以
\[
u_\ell(Q)=u_k(Q).
\tag{COPY-EQUALITY}
\]
这个等式不需要SPE，但**u_k(Q)含未来强制行动**，不是原actual u_k(B)，也未必是过去k的prescribed完成利润。不能从等式直接领k的actual钱包或买一条过去k的IC。

令J=a∩b、P=a∖b、M=b∖a，记J_A=Σ_(x∈J)1/c_A(x)，J_Q、P_Q、M_A同理。两个当前完整行动的利润为u_ℓ(A)=J_A+M_A、u_ℓ(Q)=J_Q+P_Q，故
\[
\ell_t^{\rm copy}=J_A-J_Q+M_A-P_Q\ge0.
\tag{ROW}
\]
所有分母仅在对应叶确覆盖该客户时使用；空集合按零和。a=b时Q=A、全部差和松弛0；J空时没有tracked复制税，但ROW仍保源外/规定外完整行动利润，不偷删它们。

# 共享客户的响应税严格在未来

对x∈J，A与Q在ℓ之前完全相同，当前ℓ在两叶都覆盖x。因此
\[
c_Q(x)-c_A(x)=\sum_{j>\ell}
[\mathbf1_{x\in Q_j}-\mathbf1_{x\in A_j}],
\]
\[
\boxed{\frac1{c_A(x)}-\frac1{c_Q(x)}
=\sum_{j>\ell}\frac{\mathbf1_{x\in Q_j}-\mathbf1_{x\in A_j}}
{c_A(x)c_Q(x)}.}
\tag{STRICT-FUTURE}
\]
这是同两片真实叶的精确倒数差，不靠忽略past/current税。对J求和并代ROW：
\[
\boxed{\sum_{x\in J,\ j>\ell}
\frac{\mathbf1_{x\in Q_j}-\mathbf1_{x\in A_j}}{c_A(x)c_Q(x)}
=P_Q-M_A+\ell_t^{\rm copy}.}
\tag{MIGRATION}
\]
右侧保正源外复制收益P_Q、规定行动源外收益M_A及整行IC松弛。它们发生在A/Q旧历史，不是actual客户并集C/G中的现成库存。

因x∈a∩b，A中k已选a、ℓ选b都覆盖x，c_A(x)≥2。每个正future项（Q_j覆盖x、A_j不覆盖）满足
\[
\frac1{c_A(x)c_Q(x)}\le\frac12\frac1{c_Q(x)}.
\tag{HALF-COLUMN}
\]
接收者j在Q的ℓ之后，是真prescribed尾部角色，域合法；“一半”是它在**同一Q叶**的该客户份额，非actual u_j(B)容量，亦非全部流质量减半。

为明确其有限可加范围：若0≤f_tx≤1，固定本t和某个j>ℓ，将上述正项只在该recipient求和，合法得到
\[
T_j^+(t):=\sum_{x\in J\cap(Q_j\setminus A_j)}
\frac{f_{tx}}{c_A(x)c_Q(x)}\le\tfrac12u_j(Q).
\]
再对j求和只给本Q真实未来利润和的一半，不能变成h输入的一半，不能把不同t的互斥Q各领一份actual未来W。此处是本次将逐客户同叶界显式求和的直接解析后果，不是原单客户脚本测试了多客户共同cap。

# 加权tracked输入的有符号余项

输入h_tx≥0仅在J可正，令f_tx=c_A(x)h_tx。原NEW-CAP/来源反链在其原合法INIT/EDGE域给非actual context f_tx≤1；缺少该域时f≤1应作为另一个明确前提，不从任意注入免费得到。未输入的J客户补f=0。

记δ_x=1/c_A(x)−1/c_Q(x)。对任意**一个整行标量**θ_t≥0，定义
\[
R_t(f,\theta)=\sum_{x\in J}(f_{tx}-\theta_t)\delta_x.
\]
由MIGRATION完整求和立即有
\[
\boxed{\sum_{x\in J}f_{tx}\delta_x
=\theta_t(P_Q-M_A+\ell_t^{\rm copy})+R_t(f,\theta).}
\tag{WEIGHTED}
\]
θ乘一次完整COPY-IC；非负性只允许θℓ_copy作为已知符号项。f≤1既不固定R的符号，也不给Σ_tθ_t≤1。不能为每个x选一份IC、再因逐客密度≤1宣称总系数≤1；也不能只看tracked客户的未来项符号就把ROW的M/P项任意删掉。R是输入权重与真实跨枝响应差的有符号错配，属于已有客户重权/水位余项的同类难处，不认新已付信用。

# 回推修复域不修复共同金额

可将u_k(Q)作完整过去利润claim交给[单孩子共同prefix回推](前缀请求回推的单调价格与祖先规范化--引理.md)：A/Q共享ℓ之前前缀，在切点ℓ把Q的过去请求送回A的非负父利润分解；列次随机界针对**同一个孩子Q、同一父A、已合全部prefix请求**。A若仍离轨，沿已给强制祖先栈可继续修复真实prescribed域。

这不证明所有t、所有Q、已有suffix请求和别的来源共同列系数仍≤1。不能每次回推另领一份A，更不能A不是actual时直接称actual钱包。[同父列余量](同前缀父列余量与未来重叠份额的共同回推--引理.md)也只把明确H-overlap未来子份额与prefix共同放入单孩子列cap，未将全部Q未来利润都送回actual。

与[同角色完整query覆盖](同角色来源的完整查询覆盖范数与四叶余项--引理.md)的四叶RECT比较不同，本复制选择a保tracked客户当前覆盖，所以严格未来式更干净；但它没有把RECT正offhistory slack变成退款。与[同query uniform退款](最后归属的嵌套遗漏支持与同查询退款--引理.md)也不同：后者的同action contexts共一个actual-prefix reset叶，source-copy Q一般随旧g变化，不能按相同a就合并成一个actual查询。

# 全人数、末位与当前停止范围

任意m代入：ℓ=m无未来，故J_A=J_Q，M_A−P_Q=ℓ_copy≥0，tracked δ与R均为0。源外支付仍发生各旧历史，没有自动汇成actual末位钱包。m5的ℓ4只有角色5，ℓ3有4/5，ℓ2有3/4/5；逐recipient HALF-COLUMN不构成共同质量半收缩或跨叶cap。

所有节点相加仍要同时支付不同来源/历史的M_A/P_Q、R_t、COPY-IC系数与Q未来利润claim，且与同一次初始化d/H/J共享actual两份预算。ROLE或FRESH-RESIDUAL需要这条共同金额关系；这里没有给出它，也没有反驳所有其它共同支付方式。源旧“没有五人half”仅指本关系未闭合，当前[五人half](../定理/五人半覆盖--定理.md)由另证完成，不倒推本copy框架已可行，六人/一般目标亦未由本引理支付。

源审计只检m5单共享客户算术，不能承担一般量词、整行IC或来源图支持证明。一般式由本页同叶均分、两集合利润与倒数差逐式证明；原实现/全部484报告和入口所引已成熟组件/实际审查范围另见[资源](../资源/首偏离源复制的算术审计与分支入口范围--资源.md)。本次所有原程序/新数学checker0，来源密度、uniform去重和前缀回推均不重授新机制。
