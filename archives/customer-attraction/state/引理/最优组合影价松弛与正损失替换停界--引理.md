# 原模型及零损失gate究竟给什么

采用[有限单位客户、共同非空目录、完整历史纯SPE](../定义/共同目录完整历史模型--定义.md)，任意m，保空主题、重复和任意离轨平局。固定实际叶B、负载c、利润\(u_i\)、\(W=\sum_i u_i\)。定义冻结替换成本
\[
f_i(T)=\sum_{x\in T}\frac1{c_x+1-\mathbf1_{x\in B_i}}.
\]
从全部覆盖最优m元组及行分派中联合最小化\(Q=\sum_i f_i(T_i)\)。对等大小removed token/row集合I与actual source角色集合J，有精确复制退还
\[
f_i(B_j)=u_j-R_{ij},\qquad
R_{ij}=\sum_{x\in B_j\setminus B_i}\frac1{c_x(c_x+1)}\ge0.
\]
若用\(B_J\)替换\(T_I\)后的净覆盖损失\(\delta_{IJ}=0\)，混合仍最优，因此联合最小性只给
\[
X_{IJ}:=\sum_{i\in I}f_i(T_i)-\sum_{j\in J}u_j
+\max_{\pi:I\simeq J}\sum_{i\in I}R_{i,\pi(i)}\le0.
\tag{ZERO-GATE}
\]
证明是保其余token原行，把\(B_{\pi(i)}\)置于移除行，得到另一最优方案成本\(Q-X_{IJ}\ge Q\)。它不需均衡，本质是无权覆盖最优性和静态联合选择，非真实后继激励。

\(\delta_{IJ}>0\)时新方案不再最优，故此比较不限制X的数额。原round11冻结QA在已有1953客户三人完整SPE上记录I={0}、J={1}的\(X=165\)、\(\delta=2\)；同输入实际\(B=(0,3,4)\)、\(u=(1733/3,1736/3,1736/3)\)、\(W=1735\)、唯一最优支持\(\{1,2,5\}\)、\(Q=1736\)。这只否定在ZERO-GATE后无证插入单位价格\(X\le\delta\)。该旧实例本就满足\(2W-\mathrm{OPT}_3=1730>0\)，不是half反例；原报告为既有证书公式QA，本批只完整读报告与既有正式反例，未重新执行程序或声称新发现。

本源尝试将最优source token换成真实未来覆盖者，再令离轨孩子SPE在shadow上极端。首先缺的是**可行替换映射**：交换两个叶动作，不自动在新有序前缀形成完整SPE；共同目录只保动作合法，不保未来最佳回复和进入cap。没有构造该映射，所以不能用“shadow已极大”支付尚未证明属于同域的新端点。

# 逐叶cap确能分布于完整纯选择器

固定原完整σ的实际路径B及\(u_i\)。所有\((B_{<i},A\ne B_i)\)是不同首次偏离孩子，子树互不相交。每个孩子选任意完整纯尾SPE且该强制进入者收益\(d_i(A,e)\le u_i\)，保原实际路径后可同时拼接：实际节点全部偏离都被cap，离轨节点各由选定完整见证负责，故仍是同一实际叶的完整纯SPE。原σ证明每个孩子非空。

因此先逐叶截断后的
\[
\operatorname{conv}\{\ell_i(A,e):e\text{可信},\ d_i(A,e)\le u_i\}
\]
可由这些cap可行见证的分布表示。若同一A的行混合有多个见证，可在抽分析查询之前独立抽取**所有**首次偏离孩子的见证，得到一份完整纯SPE；对这些全策略的乘积分布产生所需条件菜单边际。这是关于完整纯SPE选择器的数学分布，不额外宣称可执行的无协调混合SPE。

更大的均值cap集合
\[
\{E_q\ell_i(A,e):E_qd_i(A,e)\le u_i\}
\]
可以用低收益抵消逐叶高收益端点；它仍由真实孩子SPE见证产生合法静态负载，但上述点态cap拼接不再证明它分布于同实际叶完整纯选择器。现行[三域](可信端点均值cap的三域与松弛信用--引理.md)明确这一点，全行版也保原σ查询源。两域紧性或shadow最大化解存在，都不是数值银行。

# 最优组合的t价格松弛与精确客户余量

取删除槽共享域的同一查询/背景鞍点\((p,L^*)\)，总目录行动质量m−1，令\(\rho_x=\Pr_p[x\in A]\)并置
\[
t_x=(1+L_x^*)^{-1},\quad g_t(T)=\sum_{x\in T}t_x,
\quad\gamma=\max_T g_t(T),\quad
H_{\rm bg}=\sum_xL_x^*t_x,
\quad Q_{\rm stat}=(m-1)\gamma-H_{\rm bg}\ge0.
\]
在所有覆盖最优m元组中选\(K_t=\sum_jg_t(T_j)\)最小者；有限性保证达到。记其客户次数\(k_x\)、并集O，定义
\[
P_{\rm opt}=m\gamma-K_t=\sum_j[\gamma-g_t(T_j)]\ge0,
\]
\[
S_{\rm opt}=K_t+H_{\rm bg}-|O|
=\sum_{k_x>0}\frac{k_x-1}{1+L_x^*}
+\sum_{k_x=0}\frac{L_x^*}{1+L_x^*}\ge0.
\tag{SLACKS}
\]
第二式逐客户由\((k+L)/(1+L)-1=(k-1)/(1+L)\)导出；O外只剩背景贡献。因此有精确静态账
\[
\boxed{\mathrm{OPT}_m=(2m-1)\gamma-Q_{\rm stat}-P_{\rm opt}-S_{\rm opt}.}\tag{STATIC}
\]
此式不需要后继理性；主题价格上界和分数目录合法性给两份非负性即可。空主题、重复比较槽和零覆盖均保留。

设原查询源仍为σ的强制叶，\(I=\sum_i[u_i-E_pd_i^0]\ge0\)。围绕同一\(L^*\)定义
\[
C=\sum_iE_p\sum_{x\in A}t_x^2(\ell_i^0(A)_x-L_x^*),\quad
D=\sum_iE_p\sum_{x\in A}\frac{t_x^2(\ell_i^0(A)_x-L_x^*)^2}{1+\ell_i^0(A)_x}.
\]
倒数恒等式给\(W-m\gamma=I-C+D\)。联合(STATIC)，
\[
2W-\mathrm{OPT}_m=2(I+D-C)+\gamma+Q_{\rm stat}+P_{\rm opt}+S_{\rm opt}.
\]
所以丢掉非负S后，尚未证明的充分付款是
\[
\boxed{C\le D+I+(\gamma+Q_{\rm stat}+P_{\rm opt})/2.}\tag{PAY-OPT?}
\]
若S也全部保留，条件恰等价原half，不再是一条新金额不等式。

# 优化最优元组只重分配同一固定差额

关键恒等式是
\[
\boxed{P_{\rm opt}+S_{\rm opt}=m\gamma+H_{\rm bg}-\mathrm{OPT}_m,}
\]
右端与选哪份最优元组无关。最小化Kt使P增大、S等量减小，不能把“有利选择最优组合”再作一份独立钱包。P小则其所有非负主题价缺额之和小；P=0时每个比较槽均有最大t价。P大只在PAY-OPT?中放宽阈值，没有证明两种情况与混合协方差的真实全历史金额联系。

旧ZERO-GATE最小化的是冻结\(f_i\)成本和无权覆盖选择；这里KKT背景极大化的是\(\rho t^2\)对重复竞争负载的加权分数。没有证明二者极端对象相同，也不能免费识别其source token或替换。
