# 一份实际根利润可支付任意根混合的末位规范化

在[共同目录模型](../定义/共同目录完整历史模型--定义.md)固定m≥2、完整纯SPE σ，实际根最终利润u₁。每个合法根主题T的同一原策略真实叶写Z_T=(T,H_T,A_T)，H_T是中间m−2行动，A_T是真末位，b_x(T)为H_T的负载。原根真实收益d_T=Σ_(x∈T)1/[1+b_x(T)+1_(x∈A_T)]，全部根IC给d_T≤u₁。

删这位根但保留q_T=(H_T,A_T)，它只是n=m−1人目标，未必SPE。令B_T是删后在固定H_T下任意真末位最佳回复，
\[
f_0(X)=\sum_{x\in X}\frac1{b_x+1},\quad
f_T(X)=\sum_{x\in X}\frac1{b_x+1+1_T(x)},\quad
r_T(X)=f_0(X)-f_T(X)=\sum_{x\in X\cap T}\frac1{(b_x+1)(b_x+2)}.
\]
A_T最大化f_T、B_T最大化f₀；两条BR方向给末位利润增加ℓ_T=f₀(B_T)−f₀(A_T)≥0且
\[
\ell_T\le r_T(B_T)-r_T(A_T)
\le P_T:=\sum_{x\in T\setminus A_T}\frac1{(b_x+1)(b_x+2)}.\tag{1}
\]
正退款变化只来自原末位未覆盖的T客户，而非把两互斥叶所有退款相加。对这些客户2/(b+2)≤1，故
\[
2\ell_T\le2P_T\le d_T\le u_1.
\]
因此对**任意合法根主题分布p**，
\[
\boxed{2E_p\ell_T\le2E_pP_T\le E_pd_T\le u_1.}\tag{2}
\]
这是凸组合一次钱包，不是对所有T不带权求和；任意固定离轨背景不自带最后的根u₁行。

可保更细信用。置
\[
e_T=|T\setminus(\bigcup H_T\cup A_T)|,\quad
a_T=\sum_{x\in T\cap A_T}\frac1{1+b_x+1_{A_T}(x)},\quad R_T=d_T-e_T-a_T\ge0.
\]
P_T内b0客户恰e_T，各给2P一单位；其余b≥1有2/(b+2)≤2/3，相对于根份额给
\[
\boxed{2P_T\le e_T+\tfrac23R_T\le d_T.}\tag{3}
\]
最后一步保留a_T≥0。空T、零客户、空末位均按非严格有限和；m2时H空、R_T0、P_T=e_T/2。该正面付款完全来自原真实根子树和两次末位BR，不修复更早玩家。

# 条件统一价格输入必须用真正可信门槛

令n=m−1≥2。调用较小人数的统一真实价格表示时，输入是：一份只依n的λ∈R_+^(n−1)，对**该人数全部实例、全部末位BR目标**z，统一满足
\[
F_\lambda(z):=2W(z)-OPT_n+\sum_{j<n}\lambda_j[M_j(z_{<j})-u_j(z)]\ge0.\tag{UP}
\]
这里M_j(h)=max_X min_{y∈R(h,X)}u_j(y)，R(h,X)是强制X后真正完整子SPE全部终局。M不是保留原策略的一次偏离、不是真实含T背景门槛、更不是actual regret。有限树使min/max达到；g_j=M_j−u_j保留符号，目标未可信时可正或负。

原7393B稿以HALF(n)和该actor的[统一价格表示全文](../../tools/evidence/induction-and-unified-price-primary/related/research/workspaces/customer-attraction/R-ab4b3c24c8f949198e194dd45bb66105/construction/uniform_signed_defect_prices.md)作为(UP)存在性的调用合同。该12107B来源本批全文比较，但不额外认领其全部银行/产品证明来源、不把本批主源的条件调用冒作新价格存在性发现。下述转移对任何满足(UP)的λ直接成立，不需要构造λ，也不默认λ=2。

把q_T的末位A_T改为B_T得到q_T⁺，符合(UP)末位BR要求。所有j<n的精确有序前缀完全相同，其M_j逐项不变。令Δ_j(T)=u_j(q_T⁺)−u_j(q_T)，
\[
\Omega_\lambda(T)=\sum_{j<n}(2-\lambda_j)\Delta_j(T).
\]
终局所有角色利润和等于覆盖，故
\[
\boxed{F_\lambda(q_T^+)-F_\lambda(q_T)=2\ell_T+\Omega_\lambda(T).}\tag{4}
\]
用F_λ(q_T⁺)≥0和(1)即得
\[
\boxed{OPT_n\le2W(q_T)+\sum_{j<n}\lambda_jg_j(T)+2P_T+\Omega_\lambda(T).}\tag{5}
\]
Ω有符号；末位小利润增加不保证其他角色利润转移小，不能删掉正Ω，也不能把有符号g截成不同目标的actual regret。

# 原实际根及尚未支付的全树条件

取实际根T=S₁，W(q)=W−e₁。令Δ_m=OPT_m−OPT_n，(5)给
\[
OPT_m-2W\le\Delta_m-2e_1+\sum_{j<n}\lambda_jg_j+\Omega_\lambda+2P.
\]
再用实际同叶(3)，得到一个足够但**未证明**的付款目标
\[
\boxed{\Delta_m+\sum_{j<n}\lambda_jg_j+\Omega_\lambda+\tfrac23R\le e_1.}\tag{PAY?}
\]
比先找整份物理修复更直接，但(5)本身不是PAY?成立的证据。M_j已经重新优化全部真实子SPE；为了计算它而换孩子后，旧含T的Γ退款式不直接适用于新叶。(2)只付末位规范化，不能在各深度退出树重发u₁。

若另外已有全2价格，Ω恰0，(5)退为OPT_n≤2W(q_T)+2Σg_j+2P_T。这正是原MP/exact-M候选价格，不能从“存在某λ”推断λ可取全2。原源没有证明这一额外选择，本批也没有建立它。m5、n4时可调用原稿已知四人HALF给某个真实价格；若额外采用原未证MP₄，才得OPT₅−2W≤Δ₅−e₁+2(g₁+g₂+g₃)+(2/3)R，仍保g和R未付项。当前[五人半覆盖](../定理/五人半覆盖--定理.md)已由另一完整证书证明，本页不恢复源当时的全局未证状态，也不冒称该归纳路线支付了它。

n1即m2时上述末位规范化(1)–(3)仍成立，价格向量为空，可直接用单人BR；(UP)形式调用段专用于n≥2，不制造零维更早玩家或零人SPE。
