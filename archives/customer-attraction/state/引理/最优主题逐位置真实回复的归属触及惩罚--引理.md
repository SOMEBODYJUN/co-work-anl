# 固定的是一份完整策略，不是唯一均衡

源2228B position_aware_reply_bound以任意m≥1单位提供者、共同有限目录、完整有序history纯SPE σ为域。固定源所用的任意最优有序m元组(T₁…T_m)，并集O，actual叶(A₁…A_m)并集U、福利W。每个actual前缀h_i强制当前T_i后沿**同一σ**所有改变后的有序历史完成。该给定纯策略的后继确定，不意味着模型只有一个SPE或所有平局相同。

r_i=m−i+1，touch_i(x)为这个真实强制分支上是否有后来的动作覆盖x。每个O客户选一个含它的比较槽i作owner；各块不交分O，块不要求是目录主题，当前仍强制整个合法T_i。此分配只用于下界，不能改actual策略、冻结未来或把某个同主题的两个位置query合并。

# 一次真实IC支付各客户的安全份额

若owner客户x∈O\U，原actual过去不覆盖它。强制当前T_i后，touch为假时当前独得1；touch为真时总覆盖者至多r_i，当前至少1/r_i。故该客户贡献≥1−(1−1/r_i)touch_i(x)。若x∈O∩U，当前强制主题仍覆盖它、全局最多m覆盖者，所以至少1/m，与分支touch无关。

每个位置的actual u_i≥该真实强制收益，丢其它非负客户项、再对各位相加，只用每个actual收入一次。令b_i为分给i且被touch的遗漏客户数，得

\[
W\ge |O\setminus U|-\sum_i(1-1/r_i)b_i+|O\cap U|/m.
\]

用|O|=遗漏+交集、|O∩U|≤W，得到

\[
\boxed{\operatorname{OPT}_m\le(2-1/m)W+\sum_i(1-1/r_i)b_i.}\tag{PBR}
\]

它只用真实各分支的当前份额下界，没有把互斥分支未来收益相加，也没主张强制行动自身为BR。m1权重0，给OPT₁≤W，零客户全0，无需删除ties或除福利。

# owner最小化与六个位置的不同信用

各遗漏客户的owner可独立选，定义

\[
\beta(x)=\min_{i:x\in T_i}(1-1/(m-i+1))\,\mathbf1_{touch_i(x)}.
\]

任一未触及出现给β0；否则在所有出现位置中取最便宜的位置。于是

\[
\boxed{\operatorname{OPT}_m\le(2-1/m)W+\sum_{x\in O\setminus U}\beta(x).}\tag{OWN}
\]

这对每个所固定最优有序元组都成立，不把元组的全部排列归成同一β。重复主题在不同位置的actual前缀和真实后继可能不同，最小值保其索引。owner不产生额外独立份额银行。

m6的权重依序5/6、4/5、3/4、2/3、1/2、0。因此若某完整六人SPE真有OPT₆>2W，OWN必要求Σ遗漏β>W/6。任何在T₆出现的遗漏客户可归末位而β0，因为本来没有后继；即使某早期出现被touch也不改变这一零价。要支持严格反例，只能有所有可用最优出现均被足够早的真实后继触及的遗漏质量。

若每个遗漏客户至少有一个未触及出现，全部β0，得到OPT_m≤(2−1/m)W。若B是覆盖所有这些触及客户的较粗集合，则β≤(1−1/m)1_B，退化为根支撑定量界；六人严格反例须|B|>W/5。β保位置比这个统一最坏权更细，但没有证明Σβ≤W/m，也没有付款一般六人。
