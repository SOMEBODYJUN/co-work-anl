# 同一见证、同一行及允许端点

采用[共同目录完整历史模型](../定义/共同目录完整历史模型--定义.md)，任意人数、有限单位客户、有限非空目录，保空主题、重复、零客户和任意离轨平局。固定进入行i及强制主题A，在其精确历史后给定一份**完整纯孩子SPE见证**，规定终局为z。对任意未来角色\(k>i\)，在真实历史\(h=z_{<k}\)强制任意合法T，随后执行**同一见证**，得到z′。其整名玩家IC差
\[
\Gamma=u_k(z)-u_k(z')\ge0.
\]
这是该分支值，不是原实际路径的固定\(u_k\)。原源全部未来角色规定；新叶只有\(j>k\)仍为其新前缀处的规定子SPE角色。\(i<j\le k\)的动作/有序前缀未变，但其最终收益可变。

规范门槛为\(M(g)=\max_B\min_{v\in\mathcal R(g,B)}u_{|g|+1}(v)\)，内层用当前角色坐标。完整SPE规定叶的规范松弛
\[
s_j(y)=u_j(y)-M(y_{<j})
\]
在z的所有\(j>i\)及z′的\(j>k\)均非负。强制进入角色i不加floor。

选定一个有限raw分析域及其**固定同一行对偶**，要求z、z′都属于其允许列。若实际行动tag仅留原实际端点，则同tag改尾可被排除，以下不等式不能静默覆盖它；释放tag或跨行重索引必须明示，后者还改变价格及钱包。域范围见[受限实际标签均值门槛](逐历史均值门槛的受限实际标签域--引理.md)。

# 单次floor缺额的全部祖先展开

对每个严格未来有序历史g，当前角色为j，置
\[
\Delta_g(y)=\mathbf1_{y\text{延伸}g}[M(g)-u_j(y)].
\]
取固定非负价格\(\lambda_g\)，并定义
\[
F(y)=\sum_g\lambda_g\Delta_g(y),\qquad
F_{\rm tail}(y;k)=\sum_{j>k}\lambda_{y_{<j}}s_j(y).
\]
两端尾部均是各自真实见证续局，所以\(F_{\rm tail}(z;k),F_{\rm tail}(z';k)\ge0\)。对\(i<j<k\)，新floor缺额为\(u_j(z)-u_j(z')-s_j(z)\)；对k为\(\Gamma-s_k(z)\)；严格后继的floor为负松弛。故精确地
\[
\boxed{F(z')=
\sum_{i<j<k}\lambda_{z_{<j}}[u_j(z)-u_j(z')-s_j(z)]
+\lambda_h[\Gamma-s_k(z)]-F_{\rm tail}(z';k).}
\tag{RESET-FLOOR}
\]
减去原源\(F(z)=-\sum_{j>i}\lambda_{z_{<j}}s_j(z)\)，得到
\[
\boxed{F(z')-F(z)=
\sum_{i<j<k}\lambda_{z_{<j}}[u_j(z)-u_j(z')]
+\lambda_h\Gamma+F_{\rm tail}(z;k)-F_{\rm tail}(z';k).}
\tag{DIFF}
\]
所有受影响早期未来祖先都在第一项中；不能只保偏离者的\(\lambda_h\Gamma\)。源/目标严格后继的历史可以不同，只各自按自己的固定lambda坐标求和，没有识别为同一叶。

# 单一对偶的有符号分数账

若该域固定对偶的约化成本为
\[
R(y)=\eta+\mu d_i(y)+F(y)-\operatorname{score}(y)\ge0,
\qquad\mu\ge0,
\]
对两端的**定义等式**相减，结合(DIFF)得到
\[
\boxed{\begin{aligned}
\operatorname{score}(z')-\operatorname{score}(z)
={}&\mu[d_i(z')-d_i(z)]
+\sum_{i<j<k}\lambda_{z_{<j}}[u_j(z)-u_j(z')]\\
&+\lambda_h\Gamma+F_{\rm tail}(z;k)-F_{\rm tail}(z';k)
+R(z)-R(z').
\end{aligned}}\tag{ONE-SHOT}
\]
其中\(\eta\)实数，不需非负；\(\operatorname{score}\)可为固定删除槽shadow。丢弃负的目标\(F_{\rm tail}(z';k),R(z')\)给合法上界，但正IC差和祖先损失仍未被原源容量付掉。\(d_i\)的变化是有符号且乘\(\mu\)，不得假设某任意reset仍在进入cap以下。

一个历史若原源未到达，便没有该源的floor盈余库存，即使\(\lambda_g>0\)。两端允许、可行LP及存在对偶都没有给\(\lambda_h\Gamma\)的总金额界。

# 复制进入主题的精确残差

若本次\(T=A\)，新叶z′的进入者和偏离者选同一主题、单位权重相同，逐叶有\(d_i(z')=u_k(z')\)。因此ONE-SHOT的cap与偏离者项合成为
\[
\boxed{\mu[d_i(z')-d_i(z)]+\lambda_h\Gamma
=\lambda_hu_k(z)-\mu d_i(z)
 +(\mu-\lambda_h)d_i(z').}\tag{COPY-CANCEL}
\]
只有在**额外条件**\(\lambda_h=\mu\)下，才消去重置叶收益，成为\(\mu[u_k(z)-d_i(z)]\)。原逐历史mean-floor对偶没有证明各历史价相等、\(\lambda_h\)的普遍界或任意价正规化；不能免费删去\((\mu-\lambda_h)d_i(z')\)。\(u_k(z)\)也不是原实际角色k的一份现成银行。

后续[统一净成本复制引理](规范门槛均值域与复制偏离的精确成本--引理.md)通过**显式改变约束**使进入收益和所有未来floor合并为一个净成本，才得到单一价格下的同主题相消。那是新分析域，不是本页旧任意\(\lambda\)的价格正规化；中间祖先损失和原源容量仍然存在，不能叠加两个域的有利项。

# 连续reset、一次源容量与剩余义务

若一条按角色向后的reset序列始终保同一允许域、固定\(\eta,\mu,\lambda\)及分数，则完整对偶势差可以有符号望远镜；非负守恒流聚合时同一源初始质量只用一次。这不允许把ONE-SHOT每条边的祖先损失、IC差或势差替为正部后继续引用原相消。所选目标端点或Dual可行性，没有证明需求能按相容历史到达概率落入同一源floor/约化成本库存。

主源3465字节全文实读；对比credible的FLOOR-RESET/EXCESS、现行floor/复制/真实流对象，独有非统一\(\mu,\lambda\)残差在此完整保留。源是matching的一份有符号单次账，不是总金额审查通过；本批无程序源、无finite scan、无新增盲审/外审或新颖性认领。精确原件和去向见[证据](../../tools/evidence/credible-transposition-reset-primary/README.md)。

原稿五人未由本账得half不覆盖现行另证五人定理；六人或一般人数共同付款仍未由ONE-SHOT/COPY-CANCEL闭合。关系是同一见证IC与规范floor→精确reset账、同主题等收益→条件相消；接入真实协方差流仍有明确容量与量化义务，正式超图留第三阶段。
