# 固定有序策略、fresh客户与库存

在[共同目录模型](../定义/共同目录完整历史模型--定义.md)固定有限目录、m≥1和完整**确定**策略σ，实际叶Z=(Z₁,…,Z_m)、actual覆盖C。下面纯流证明不使用策略最优性，故不须σ为SPE；付款接口才另需完整IC。

全仓已有[加强初始化与节点密度](../定理/同客户来源保持流的加强初始化与节点密度--定理.md)的更一般SOURCE定理。此页保R65独立重构的严格特化：取source α=k、p_(αx)=ρ_k(x)、A_(αx)=该source总注入≤ρ_k，逐边SOURCE即INIT；只用fresh客户和新增future正边，可选共同边取0，无actual终点。R65还额外要求source当前T_k覆盖x。进一步删减这些边的子流按DAG逐角色单调比较仍不增加密度，但不能继承wholeIC付款。这里只将原稿合同、精确前缀式与父审核对归位，不重复认领已有一般主定理。取固定fresh客户x∉C，客户标签全程保留，不在不同x间重采。

每source角色k允许actual前缀强制主题T_k，Y^k=finish_σ(Z_<k,T_k)，非负库存ρ_k(x)只在x∈T_k时可正，且

\[
\sum_k\rho_k(x)\le1.\tag{INV}
\]

初始只向Y^k上未来coverer j>k的真实natural context s=(Y^k_<j,j)注入，逐边b_s^k(x)≤ρ_k(x)/c_(Y^k)(x)，每source全部注入≤ρ_k(x)，余量可吸收/不用。非coverer不注入。这两个上界是明确INIT合同，不能只保总量而丢逐边分母。

多source action时保(k,T)标签，库存总和仍按每客户≤1，证明相同；不是每个action各另领单位库存。

# 不重采的递推及有限质量DAG

正x incoming的context t=(g,i)规定a_t=σ_i(g)必须覆盖x，规定叶B_t=finish_σ(g)，actual-reset叶A_t=finish_σ(Z_<i,a_t)。合计输入h_t(x)，置

\[
v_t(x)=1/c_{B_t}(x),\qquad\beta_t(x)=h_t(x)c_{B_t}(x).
\]

正输入时a_t覆盖x，所以分母正；零输入/非coverer需要统计时可令β0，不写1/0。只沿j>i且x∈A_(t,j)\B_(t,j)的原正边发出，价q_tj(x)=1/[c_(A_t)(x)c_(B_t)(x)]，实际边流允许分数减少，但必须≤

\[
\beta_t(x)q_{tj}(x)=h_t(x)/c_{A_t}(x).\tag{EDGE}
\]

receiver s=(A_t<j,j)的规定叶恰A_t。因x不在actual C，A_t在i以前没有x，当前a_t覆盖x。令U为A_t未来coverer、V为B_t未来coverer，则c_A=1+|U|，总正外送≤h_t|U\V|/(1+|U|)<h_t（h_t>0），未送非负吸收。角色严格增加、每客户质量不复制、有限有序树，故为有限DAG。无需负载单调，更不假定会重采的旧标量核满足本递推。

任意删正边只在**纯流非增**意义允许；不因此自动保wholeIC退款。后面density对这些子流皆成立。

# 首偏离、角色cut、合流共同分母

**R65合同特化。** 每个正生成receiver s，若其有序历史相对actual首次不同于角色k，则k<role(s)，且

\[
0\le\beta_s(x)\le\sum_{q\le k}\rho_q(x)\le1.
\tag{PREFIX-DENSITY}
\]

所以h_s(x)≤1/c_(B_s)(x)。证明三步：

1. 若parent t=(g,i)有正x边进s，则a_t覆盖x，actual Z_i不覆盖x，故a_t≠Z_i。A_t此前等actual，在i第一次不同；receiver历史A_t<j的首次偏离恰i。因此同receiver所有natural parents的角色均等唯一k，动作均为receiver历史第k个动作，reset完成叶全部是同一个B_s。直接source q注入同理只可能q=k。

2. 保留source标签，来自q的x质量沿严格递增角色、非增质量流前进，切在角色k前，其到达该角色全部natural contexts的incoming总和≤ρ_q(x)。只有q<k可到role k，故

\[
\sum_{t:role(t)=k}h_t(x)\le\sum_{q<k}\rho_q(x).\tag{CUT}
\]

source k直接库存尚未进入role k natural节点，和这部分不重复。不是分别给每parent一个ρ再相加，而是同一层cut共同控制。

3. 同receiver所有parent分母是c_Bs，源k的直接注入同样ρ_k/c_Bs，所以

\[
h_s(x)c_{B_s}(x)
\le\rho_k(x)+\sum_{t:role(t)=k,reset(t)=B_s}h_t(x)
\le\sum_{q\le k}\rho_q(x)\le1.
\]

这覆盖直接源和多个递归parent同时合流。actual context不可能有正fresh输入，无须指定其first-deviation k。零库存/零客户全零，空主题/重复/历史依赖平局不改证明；没有把同计数但不同ordered history合并。

# 准确的结论强度

该证明是每客户非增质量+同receiver共同分母的全图推论，强于只初始注入β≤1，但**只逐context**。对全部fresh客户可取β_*t=max_(x∈a_t\C)β_t(x)≤1（空支持为0）。它不证明同actual角色l的Σ_(role(t)=l)β_*t≤1，更不直接给费用和≤2u_l−d_l−H_l−J_l。不同context的max可来自不同x，不能把cut中的h直接当β或把跨客户库存视作同一实际钱包。

合法wholeIC核可把β_*≤1接成每context L_t≤u_l，仍非同角色所有L总和cap。原父方039只独立核此INV/INIT/EDGE纯DENSITY，未重新审所引核；准确接口及例子见[初始化与付款边界](../资料/重置密度的初始化守卫与整行付款边界--资料.md)。原HALF/FRESH-RESIDUAL未由此闭合，现五人根定理亦不自动支付该候选共同cap。
