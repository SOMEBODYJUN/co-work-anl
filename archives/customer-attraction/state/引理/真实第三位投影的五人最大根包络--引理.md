# 真实第三位投影的五人最大根包络

## 1. 对象与真实分支

固定任意完整有序历史纯 SPE $\sigma$。实际第一位最终利润为 $r$，共同目录最大主题大小为 $K$，最优五项索引元组覆盖人数为 $O=\operatorname{OPT}_5$；其客户重数 $d_x\in\{0,\ldots,5\}$ 保留重复索引。选大小为 $K$ 的合法主题 $M$，仅强制根改选 $M$，后继全部使用同一 $\sigma$，得到 $(M,A_2,A_3,A_4,A_5)$，利润为 $v_i$。根 IC 给 $r-v_1\ge0$。被强制根不被当作新分支的优化者。

每客户记 $b=(c,a_2,a_3,a_4,a_5)\in\{0,1\}^5$、$s=\sum b$，客户份额为 $v_{i,x}=b_i/s$，零分子时取零。全部 $(b,d)$ 有 $32\cdot6=192$ 型，这是客户系数域，不是192个游戏的抽样。

代码槽号从零开始。`size:j` 是 $K-|A_{j+1}|$；对真后继 $i=1,\ldots,4$，`IC:i:j` 是

\[
v_{i+1}-\sum_x\frac{b_j}{p_i+5-i}\ge0,\qquad p_i=\sum_{k<i}b_k.
\]

它保留当前偏离后其余行动者全部可能覆盖同一客户的最坏分母。`opt:i` 对最优五个合法索引求和，得到 $5v_{i+1}-\sum_xd_x/(p_i+5-i)\ge0$。

令 $p=c+a_2+a_3$、$H=v_4+v_5+\sum_xa_4/[(p+1)(p+2)]$。真实末两人税行是

\[
\begin{aligned}
\mathrm{r2:opt}&=10H-\sum_x\left[\frac{d(5-d)}{p+1}+\frac{d(d-1)}{p+2}\right]\ge0,\\
\mathrm{r2:O}&=\tfrac52H+\sum_x\frac p{p+1}-O\ge0.
\end{aligned} \tag{1}
\]

这些行只用同一真实子游戏的合法比较。原行语义和[最大主题同线证书](最大主题同线证书的不同交叠信用--引理.md)相同，不把离轨福利加入实际福利。

## 2. 任意真实第三节点的七行投影

前缀现在可为任意两个主题，客户负载 $p_x\in\{0,1,2\}$。$K$ 仍是全目录裸大小上界，不要求此前选过最大主题。选

\[
H_*\in\arg\max_{T\in\mathcal S}\sum_{x\in T}\frac1{p_x+3},\qquad K_h=\sum_{x\in H_*}\frac1{p_x+3}.
\]

有限非空目录保证存在，包括零客户。强制第三位选 $H_*$，后继真选择 $Q,R$，相应利润为 $V_H,V_Q,V_R$，原节点利润为 $u$。每客户用 $h,q,t$ 表示这三主题隶属。任选五个合法比较索引，其重数为 $j_x$；另保留最优元组重数 $d_x$。令 $B=V_Q+V_R+\sum_xq/[(p+h+1)(p+h+2)]$。

| 权重 | 非负总行 |
|---:|---|
| $17040$ | $u-V_H$ |
| $9000$ | $K_h-\sum_xq/(p+3)$ |
| $10080$ | $K_h-\sum_xt/(p+3)$ |
| $600$ | $5V_R-\sum_xd/(p+h+q+1)$ |
| $1085$ | $K-|H_*|$ |
| $360$ | $5B-\sum_x[(5t+d-2td)/(p+h+1)+2td/(p+h+2)]$ |
| $2679$ | $5K_h-\sum_xj/(p+3)$ |

第一行是原节点偏离，第二、三、七行来自同一个加权最大主题，第四行是末位 IC，第五行是最大裸大小，第六行是末两人税对五个 $(R,T_j)$ 对求和。没有给予被强制的 $H_*$ 优化者身份。

展开七行，写为

\[
17040u+1085K-2679\sum_x\frac{j_x}{p_x+3}+\sum_xG(p_x,d_x,h_x,q_x,t_x)\ge0.
\]

逐客户对八个隐藏比特取最大，恰有 $\max_{h,q,t}G=-F(p,d)$：

| $p\backslash d$ | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---:|---:|---:|---:|---:|---:|
| 0 | 0 | 960 | 1220 | 1480 | 1740 | 2000 |
| 1 | 0 | $1665/4$ | $2745/4$ | $3785/4$ | $4825/4$ | $5865/4$ |
| 2 | 0 | 320 | 524 | 728 | 932 | 1136 |

144个组合的有理检查验证 $-F-G\ge0$ 及每个 $(p,d)$ 达到最大。将这些非负余项加入七行得

\[
\boxed{17040u+1085K-2679\sum_x\frac{j_x}{p_x+3}-\sum_xF(p_x,d_x)\ge0.} \tag{2}
\]

取 $j=d$ 为 `trueH:opt`；同主题重复五次给 $j=5\mathbf1_T$，为 `trueH:repeat:T`。$d$ 与 $j$ 承担不同角色，不能混同。

## 3. 全部有理包络及其余项

令 $q_h(b,d)$ 为已定义行的客户系数。每份证书的非负乘子在全部192型满足

\[
\epsilon(b,d)=B\frac c{s}-Cc-\mathbf1_{d>0}-\sum_h\lambda_hq_h(b,d)\ge0.
\]

因此对任意客户数都有完整恒等式

\[
\boxed{Br-CK-O=B(r-v_1)+\sum_h\lambda_h\operatorname{row}_h+\sum_x\epsilon(b_x,d_x)\ge0.} \tag{3}
\]

每条线分别全域有效，无需实际 $r/K$ 等于发现参数；$K=0$ 亦无须作除法。下列全部未列乘子为零。
