# 固定输入、背景与运输量词

这是已证[旧银行完整SPE](../反例/笛卡尔银行目录的逐人分数门槛反族--反例.md)的m6固定点，不是新游戏。六经济客户e0..e5、五个双单位客户银行B0..B4，共16单位客户；30主题(a,b)={ea}∪Bb，索引5a+b。实际叶(0,0),(0,1),(0,2),(0,3),(0,4),(1,0)，利润(6/5,11/5,11/5,11/5,11/5,2)，W12、OPT16。全部有序历史理性继承BASE/PUNISH/EXIT解析控制器；下面没有把任意菜单当SPE。

实际位置i强制A后沿同一σ完成，删掉当前同i槽，得其他五槽客户负载ℓ_i(A)。固定共享极小背景L*为e0负载8/3、其余经济7/15、每银行1，t=(1+L*)^{-1}。定义
\[
 c_i(A)=\sum_{x\in A}t_x^2(\ell_i(A)_x-L_x^*).
\]
银行每块压一个坐标、乘2仍表示两位单位客户。p为全部30主题均匀时，各角色查询运输ν_i应满足
\[
 \nu_i(A)\ge0,\quad\sum_A\nu_i(A)=1,
 \quad\sum_{i=1}^6\nu_i(A)=1/5\quad(A\in\mathcal S).
 \tag{T}
\]
最后一式是平均(1/6)Σ_iν_i=p，不能强求每行仍等于p。所求C_min=min_ν Σ_i,A ν_i(A)c_i(A)，背景L*固定，不同时优化另一个背景或另一个查询边际。

# 原可行运输与精确对偶

取第i行只查经济a=i−1的五个银行主题，各1/5，即角色1索引0..4、角色2索引5..9，依此到角色6索引25..29。每行质量1，每主题总质量1/5，故满足(T)。其值为
\[
 C=(48-5\cdot105)/484=-477/484.
\]
原报告同时给出6个行势和30个列势：
\[
 \alpha=(137,-105,-105,-105,-105,-105)/484,
\]
\[
 \beta_A=-89/484\ (a=0),\qquad \beta_A=0\ (a\ne0).
\]
由完整成本表，根锚列48=137−89，其他锚列至少−194=−105−89，非锚各行分别795≥137及−105=−105。因此180个对偶约束α_i+β_A≤c_i(A)全部成立。任何可行运输的成本至少
\[
 \sum_i\alpha_i+\frac15\sum_A\beta_A
 =\frac{137-5\cdot105-89}{484}=-477/484.
\]
与可行运输相等，证明
\[
 \boxed{\min_{\nu\text{满足}(T)}C(\nu)=-477/484.}
\]
这是原命名packet的确切最小值，不仅找到某个非正点；不需要枚举所有运输或假设最优解唯一。

# 三种不同相关项，不能迁移结论

uniform30的未运输值C=3269/7260>0；原report称`diagonal_C`，实际意思是每行都使用相同p的平均，不是成本矩阵的迹。运输后C=−477/484，D=1289/2420，IC=4/5，固定F=71/44不变，故
\[
 IC-C+D=51/22=W-6F.
\]
这解释为什么只凭uniform未运输C>0不能反驳“存在有利运输”的版本。

另一方面，真正最优p*只支持25个非锚主题，值γ37/22。任何保持p*的运输都没有锚质量，成本表每行在全部允许列恒定，故C=(795−5·105)/484=135/242>0。再加已证唯一primal/全部最优query排锚的解析论证，这个正值覆盖每个全局最优p及其保边际运输，见[完整正C反例](../反例/共享菜单全部最优鞍点的正相关项--反例.md)。uniform30不是外层最优查询，两个结论不冲突。
