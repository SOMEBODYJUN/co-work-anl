# 同一真实分支，不另加目录结构

任意有限单位客户、非空共同标签目录、任意m≥1单位提供者，固定全部有序历史纯SPE σ及actual叶B、actual利润u_i(B)。保空标签、同覆盖标签、重复选择、零客户与任意历史平局。3485B源稿是初等必要关系/探索记录，未独立外审或认证新颖性，没有闭合half。

固定actual位置i及其实际前缀，在该节点强制任意合法主题T，之后执行**同一原σ**得真实叶z^T。查询者收益
\[
d(T)=\sum_{x\in T}1/c_x(z^T)\le u_i(B)
\]
由actual节点完整行动IC给出，不冻结后继。对每个j>i，S_j是这片叶上的实际规定行动，定义同叶利润分割
\[
I_j(T)=\sum_{x\in S_j\cap T}\frac1{c_x(z^T)},\qquad
E_j(T)=\sum_{x\in S_j\setminus T}\frac1{c_x(z^T)}.
\]
单位均分与子集关系立即给
\[
u_j(z^T)=I_j(T)+E_j(T),\quad
0\le I_j(T)\le d(T)\le u_i(B).
\tag{INTERSECTION}
\]
这不说后继的整利润≤查询者，也不用互不交客户假设。

# 任一真正有效保证的超额必须有主题外来源

取ℓ_j为角色j在其**z^T真实到达历史**上的任意有效利润下保证，ℓ_j≤u_j(z^T)。E_j≥0及INTERSECTION给
\[
\boxed{E_j(T)\ge[\ell_j-d(T)]_+
\ge[\ell_j-u_i(B)]_+.}\tag{SUPPORT}
\]
不能把只对原actual节点有效的阈值，或未证逐人OPT/(2m)，当成此离轨历史的保证。

一个无额外目录假设的可用保证：该历史过去负载为b_x^j、剩r_j=m−j+1人含自己。当前任取Q，之后每人至多给某客户加一次，故在Q客户上最终负载≤b_x^j+r_j。完整当前BR因而保证
\[
\ell_j^{\rm coarse}:=
\max_{Q\in\mathcal S}\sum_{x\in Q}\frac1{b_x^j+r_j}
\le u_j(z^T).
\]
分母至少1；背景b是这条真实分支的历史，不用原actual背景代换，也未令σ只依计数。此界常很弱，但是真保证而非指定punisher的任意收益。

# 同叶联合收款：客户总份额只有一次

同一T的全部j>i可以兼容相加，因为T外每个客户在所有覆盖者间总支付至多1：
\[
\begin{aligned}
\sum_{j>i}E_j(T)
&=\sum_{x\in(\cup z^T)\setminus T}
\frac{\#\{j>i:x\in S_j\}}{c_x(z^T)}\\
&\le |(\cup z^T)\setminus T|.
\end{aligned}
\]
因此
\[
\boxed{|(\cup z^T)\setminus T|
\ge\sum_{j>i}[\ell_j-d(T)]_+
\ge\sum_{j>i}[\ell_j-u_i(B)]_+.}\tag{JOINT}
\]
更精确的左侧是ΣE_j本身；若过去玩家也覆盖这些T外客户，后继只拿其中部分份额，不能把整个人数当作它们独享现金。查询者当前选T，所以它没有T外份额；过去者的份额也未被再次领用。

# 末位真实fresh外选项

令U为原actual遗漏客户，P为z^T末位之前真实前缀的客户并集。任意合法Q提供至少|Q∩(U∖P)|名完全新客户，末位可各独享1，无更晚响应。故其真实BR≥max_Q|Q∩(U∖P)|，由SUPPORT
\[
E_m(T)\ge
\left[\max_Q|Q\cap(U\setminus P)|-d(T)\right]_+
\ge\left[\max_Q|Q\cap(U\setminus P)|-u_i(B)\right]_+.
\]
这是同一分支末位的保证；U在原actual前缀本来fresh，但被查询枝提前覆盖的部分已在P内，不能仍计作fresh。i=m时没有后继，JOINT右侧空和0；m1、零客户、空T都按同样定义处理，无需除W。

# 未付的是跨分支转换

支持池是这片z^T的T外客户，可包括原actual遗漏且不在T内、查询后才被覆盖的客户。它不是原actual覆盖C，也不保证由W统一支付。对不同T逐枝相加，会重复领取同一客户在不同互斥叶上的一份支付。

尤其将T映到其末位所选S_m(T)，再从actual前缀直接强制S_m(T)，已进入另一个有序历史和真实后继；不能保留旧T枝的惩罚负载。有限目录只保证主题标签映射有循环，不保证完整历史/负载循环，更没有已证明的望远镜。因此本页的同叶JOINT不是跨T共同钱包，亦非half充分证书。

与[源复制](首偏离源行动复制的严格未来迁移与加权余项--引理.md)共同使用单位同叶均分，但对象不同：本页比较查询T与各真实后继交集，给其外部支持下界；源复制在旧g主动改当前行动为较早a，追响应税。两者都不能把离轨利润直接当actual钱。已有[净退款根账本](../资源/净退款根账本的版本订正与静态组件边界--资源.md)的条件最小坏点曾用指定t保证后继外部利润，本页只使用实际已证ℓ_j，不重新启用已假的一般逐人门槛。

原一般half和six目标未由这条必要关系解决；当前五人half另证也不自动支付跨分支支持池。一般性完全由同叶子集份额与有效保证推导，0新数学运行/原程序，不将它升为普遍惩罚不可行定理。
