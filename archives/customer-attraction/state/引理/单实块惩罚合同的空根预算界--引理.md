# 仅排明确的空根惩罚合同

4815B原稿为构造检查点，不是任意目录结构定理、PB子SPE失效或目标反例。本页完整保它的正面计数及限定范围，修清退化参数，不将方法失败说成一般half证明。单位客户/单位提供者、共同非空标签目录、全部有序历史纯SPE，允许同覆盖/空标签、重复行动、零客户与任意平局。

先取一个非平凡段：正整数k≥2、n≥1、q>0，r=k+n。每个real块含q位不同单位客户，每个dummy块含Hq位不同单位客户，块彼此不交；H有限非负，若H有理可共同缩放成整数人数，未引入加权提供者。目录regular主题任取ℓ个不同real块，并取固定排序前k−ℓ个dummy块，1≤ℓ≤k。比较覆盖上界还保原目录合同：每个合法主题在本段至多含kq位real客户，dummy客户限于这k−1个块；regular或其singleton等子主题满足，任意另加主题则须重核。real块总数至少r+1、至少2k。

指定实际路径前k人都选同一个含k个real块的F，之后n人各选一个不同的新real块及全部前k−1个dummy块。这里“新”排除F及已被尾选的real块。假设存在完整SPE以此为actual；所有离轨动作仍必须在原共同目录合法并各自真实最优，不能仅给一个路径计数就宣布SPE。

# 实际末位的一次真实换块

每个copy玩家最终收益q；实际覆盖为r个real块及全部k−1个dummy块，故
\[
W=q[r+(k-1)H].
\]
actual末位单实块主题的收益为
\[
q+(k-1)Hq/n.
\]
real块至少r+1保证还有一个完全fresh块。末位把最后一个dummy块换成这额外fresh real，形成合法ℓ=2主题；其余块不变，之后没人，真实收益增量为q−Hq/n。末位BR必使
\[
\boxed{H\ge n.}\tag{LAST}
\]
这一步只在k≥2有dummy可换；不能把原简写直接套到k=1。

# 最后copy的真实惩罚枝及Jensen

令最后copy玩家偏离到k个完全fresh real块。至少2k个real块保证可与F的k块全不交，此前k−1个copy不覆盖这些块。偏离之后的n人可以随完整历史改变；只另加明确合同：

**在这一真实偏离后的规定续局，每位后继在本段最多选择一个real块。**

这是被检验架构的限制，不是SPE自动性质，也不是冻结原actual尾。如果c_a为k个查询块的最终负载，则每个c_a≥1且Σ_ac_a≤k+n。倒数Jensen给偏离者
\[
d\ge q\sum_{a=1}^{k}\frac1{c_a}
\ge\frac{qk^2}{k+n}.
\]
其actual收益q，真实当前IC只能在
\[
\boxed{n\ge k(k-1)}\tag{HIT}
\]
时压住该偏离。不需要旧PB的(G)条件，不假设未来匿名或同计数同回复。

# 联合覆盖预算

由上述全目录合同，任意r个合法主题至多覆盖krq位real客户及全部k−1个dummy块，因此
\[
\mathrm{OPT}_r\le q[kr+(k-1)H].
\]
只是上界；不要求real宇宙一定有kr个块可达这个数。合并actual覆盖及LAST/HIT：
\[
\begin{aligned}
2W-\mathrm{OPT}_r
&\ge q[(2-k)r+(k-1)H]\\
&\ge q[n-k(k-2)]\\
&\ge qk>0.
\end{aligned}
\]
所以这一literal单实块惩罚合同无法产生超二倍actual路径。结论没有排除多real动作、其它目录、不同actual路径或其它完整SPE。

同样的求和适用于**同一k-copy阶段、同一n尾人数、同一完整偏离中**逐段满足上述fresh/至多一real命中合同的互不交Cartesian段：copy实际收益是Σq_s，联合Jensen是Σq_s k²/(k+n)，末位可逐段换块（它已无未来），得相同H_s约束及总余量至少kΣq_s。不能由“目录Cartesian”免费假设后继策略逐段独立，或给参数不同的段各调用一条独立copy-IC。

# 参数边界与仍开放的构造自由度

- k=1没有dummy，LAST的换dummy理由不适用；指定r=1+n条one-real实际行动覆盖r个不同real块，每主题只有q客户，所以W=OPT_r=rq，直接保half及正余量，不需要H≥n。
- n=0时不使用Hq/n。若k≥2，最后copy可改k个fresh real，得kq>q，指定路径本身已非SPE；k1是一人直接最优。
- q=0且H有限时所有块空，W=OPT=0，只保非严格空和结论；原qk>0限非平凡段。不限制一般模型零客户。

若允许惩罚者一次选多real，HIT的Σc≤k+n前提消失；这只是简单障碍消失，不是已有可信惩罚。每个多real规定动作还须压住将共享查询块换成fresh块的合法替代；其后更晚回复又是另一个真实子树。若先用很多real动作饱和宇宙，使fresh外选项消失，这条计数没有排除它，但饱和动作自己也在共同目录、原copy可直接入场，全部历史IC仍需构造。

actual遗漏U=N∖C在每个actual前缀负载都是0，不能继承合法PB高背景的flattening。空根构造只能在进入后制造U拥挤，同时支付末位其它fresh U外选项和全部扩张主题入口；这是一项真实未成义务，不断言U私有或所有目录有交换结构。
