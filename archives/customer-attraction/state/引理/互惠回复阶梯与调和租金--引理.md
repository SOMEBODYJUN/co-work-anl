# 跨前缀互惠回复阶梯与调和租金

## 精确阶梯恒等式

固定一个完整策略树中的有序前缀 (H)，余下 (r\ge2) 个活跃位置和主题对 ((a,b))。令 (K_H^r) 为互惠末位回复链引理中的核。把一份枢轴 (b) 追加进前缀，同时令活跃复制数从 (r) 减到 (r-1)，总人数不变，则对任意 (a)

\[
K_H^r(a,b)-K_{H+b}^{r-1}(a,b)
=\delta_H(b):=\sum_{x\in b}\frac1{(h_x+1)(h_x+2)}. \tag{1}
\]

两边的收益部分总计数相同，差异只来自 (f_H(b)) 与 (f_{H+b}(b))，故 (1) 是逐客户精确恒等式。

从 (H_0,r_0) 及 ((a_{-1},a_0)) 出发，在每一步真实末位历史读取回复 (c_t)，令

\[
a_{t+1}=c_t,\quad H_{t+1}=H_t,c_t,\quad r_{t+1}=r_t-1.
\]

末位最优性与核对称给出

\[
K_{H_t}^{r_t}(a_{t-1},a_t)
\le K_{H_t}^{r_t}(a_t,c_t)
=K_{H_{t+1}}^{r_{t+1}}(a_t,c_t)+\delta_{H_t}(c_t). \tag{2}
\]

把 (T) 步相加，若 (g_x) 是构造阶梯对每个客户的新增命中数，则内部项按调和差精确望远镜：

\[
K_{H_0}^{r_0}(a_{-1},a_0)
\le K_{H_T}^{r_T}(a_{T-1},a_T)
+\sum_x\left(\frac1{h_x^0+1}-\frac1{h_x^0+g_x+1}\right). \tag{3}
\]

空前缀时租金为 \(\sum_x g_x/(g_x+1)\)。这是代数虚拟负载的解释，不是目录动作，也不是含该动作子博弈的 SPE 结论。

## 适用边界

- 阶梯读取的是原完整策略在各个**具体离轨历史**上的真实末位回应；没有冻结后继。
- 它最多走到 (r=1) 的末两人核；端点通常仍不是实际根路径。
- 跨前缀的债在这一特殊“把当前回复移入前缀”的组织下闭合；任意改变前缀的运输不满足 (1)。
- 租金和端点核尚未由实际根福利支付，也没有把整组最优主题并集接到一条真实路径。因此该引理不证明 `Q-CAG-HALF`。
