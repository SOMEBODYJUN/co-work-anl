# 比原最小菜单不同的输入顺序

采用有限单位客户、非空共同真实集合目录、m≥2名单位提供者的[完整有序历史模型](../定义/共同目录完整历史模型--定义.md)。给1≤j<m、目标终局z=(A₁,…,A_m)，以及(A₁,…,A_j)后完整SPE π实现该真尾。前j位仍可不理性。

对每个早期实际前缀h_i及每个合法旧主题A，**事先固定任意一份真正完整后继SPE**ρ_(i,A)，包括正常A=A_i。令d_i(A)为当前强制者在此指定真孩子的最终收入。设

\[
D_\rho=\max_{i\le j,A}(d_i(A)-u_i(z))_+.
\]

这里不要求ρ先取真实最低孩子。8886B原root_regret审查就是这个fixed-ρ合同；其审查起点是父方消息给出的构造规则，在未读待写作者稿前重构。后4838B父方稿才用ell最小值逐节对照作者。不能将二者的原输入顺序互换。

# 固定菜单的准确编译

取正有理s≥D_ρ，d=m−j。增加j个各2s银行、一个ds的Y和d−1个各s叶，全部不交且与旧客户不交；目录是旧与m个保险主题的完整Cartesian并集。存在全历史纯SPE保旧坐标z，保险实际路径B₁,…,B_j,Y^d，精确有

\[
W'=W+(m+j)s,\quad O'=O+(2m-1)s,\quad
O'-2W'=O-2W-(2j+1)s.\tag{P}
\]

承重bank全树证明已在[统一/异质前缀定理](../定理/真实退出缺陷的统一与异质前缀修复--定理.md)完整保存，此处不把同一证明记成新发现；原独审独有的fixed-menu证明如下。

每个正常保险前缀后，强制任一当前T均有真完整低退出L_(i,T)使当前保险利润≤s。已占bank/leaf raw即≤s；Y-clean先填fresh bank再Y，允许提前仍clean的Y，终局Y共d；F-clean先其他fresh bank、再Y到d−1、最后复制F，d1无Y阶段；dirty首次出口永久BI。正常前j银行后，全部尾有序历史永久Y为真SPE，任何之前尾偏离也不破其≥s利润和替代≤s。

正常第i位收益u_i+2s。首个任何联合异常(A,T)后永久进入**所指定**ρ_(i,A)×L_(i,T)，偏离利润为

\[
d_i(A)+\operatorname{bank}_i(T)\le d_i(A)+s
\le u_i+D_\rho+s\le u_i+2s.
\]

这包括只改保险而A=A_i，不能继续原不可信计划；亦包括只改旧行动而T=B_i。退出后的每个坐标仅读本投影历史，联合IC差等于各真坐标IC差之和≤0，模式永久不重新触发。前j全正常后用π和全Y完整尾的积；从正常节点倒归纳给全树SPE。

正常保险覆盖(m+j)s，保险m不交块总数(2m−1)s；最优上界逐坐标成立，完整Cartesian又把旧m元最优和m保险块按槽配对达到，故最优精确相加，得(P)。所有有理记账用同一L同时放大**旧、新**客户，不能只放大保险，人数/单位权不变。

D_ρ=0时无需正保险：从输入真尾倒推，正常孩子保留修好目标，其他旧行动各贴指定ρ，d_i(A)≤u_i保证原节点理性，z本身可实现完整旧SPE。无需零块或极限。空旧主题、重复、0客户及任意离轨平局全部保留。

# 最小菜单特化、可用上界与不能倒推的方向

原作者定义ell_i(A)=min_真孩子收入、M_i=max_Aell_i(A)、D=max_i(M_i−u_i)_+。对任意fixedρ有ell_i(A)≤d_i(A)，故D≤D_ρ；选择每个达到ell的真孩子才使D_ρ=D。不能从一个任意fixed-menu的D_ρ断言已精确求得D，也不能将非SPE冻结叶作为ρ。

若仅给每个(i,A)真完整退出策略并证明其当前利润≤统一有理U_i，那么D_U=max_i(U_i−u_i)_+同样足够，因为D_ρ≤D_U；上述策略论证可直接使用该表，不需精确枚举M。这个U表结论由fixed-menu合同直接代入，后来[有符号修复的U表](../定理/双侧有符号缺陷的真实供给修复与有限字典最小性--定理.md)是更广保符号版本；不倒填原8886B已审后来signed全文。

j=1时成本为3s，复得已有root-only常数；成本相同不宣称各有序处罚的时间安排与旧root构造相同。

若O−2W>(2j+1)D_ρ且D_ρ>0，取s=D_ρ并清分母就得真half反例；无此种子由本独审提供。D_ρ较大只会稀释攻击，不是已证所有坏目标皆可被同一免费修复。对完整实际SPE可以特意选原真实孩子使d_i(A)≤u_i，故D_ρ0；不能说任何任意孩子表对真SPE都必D_ρ0。
