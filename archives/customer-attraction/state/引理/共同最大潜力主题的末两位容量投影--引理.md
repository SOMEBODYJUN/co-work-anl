# 共同最大潜力主题的末两位容量投影

本文保留既有共同最大潜力主题及RC机制，将同一个合法主题同时接入倒二封顶、
真实末位报价和全目录裸大小容量，再消去它的会员。得到一个五个非负参数的
通用必要族；其中一条在六人第九固定支持必要点上精确为负。该点排除不证明
六人半覆盖，也不把早已成立的最大主题选择或RC重新认作新定理。

## 1. 模型、同一背景与共同标签

采用[共同目录完整历史模型](../定义/共同目录完整历史模型--定义.md)。客户有限、
每人价值为一；目录为有限非空标签集，允许空覆盖、同覆盖异标签和重复行动。
固定同一完整历史纯SPE中一个尚余两人的合法有序历史，其客户整数背景为
`p_x≥0`，规定后两题为A、B，真实最终收入为u、v。历史可以离轨；仅当它是
六人actual前四历史时，才令A=A5、B=A6、u=u5、v=u6。

记

\[
f(Q)=\sum_x\frac{q_x}{p_x+1},\qquad
g(Q,R)=\sum_x\frac{q_xr_x}{(p_x+1)(p_x+2)},\qquad
U(Q,R)=f(Q)-g(Q,R).
\tag{1}
\]

其中q、r为标签覆盖的0/1会员。U正是两题终局中第一题行动者的收益。
K是**整个共同目录**的裸大小上界，可以取真实最大主题大小；不能只界一份
已列子菜单或在不同预算中更换K。

选择一次

\[
X\in\arg\max_{Q\in\mathcal S}f(Q),\qquad F=f(X).
\tag{2}
\]

有限非空目录保证存在，无需正客户或严格最大性。选择不依赖客户或所查主题。
另取两份长度m≥1的合法有序菜单 `Q_1,…,Q_m`、`R_1,…,R_m`，允许重复及
任意覆盖别名，置

\[
\bar f_Q=\frac1m\sum_i f(Q_i),\quad
\bar f_R=\frac1m\sum_i f(R_i),\quad
\bar g_{QR}=\frac1m\sum_i g(Q_i,R_i),\quad
\bar r_x=\frac1m\sum_i r_{ix}.
\tag{3}
\]

平均表示固定合法查询的全局平均，不是一个可行动的分数主题。

## 2. 通用五参数必要式

对任意五个非负实数 `λ,β,γ,δ,ε`，令

\[
k_x=\frac{\lambda b_x+\beta\bar r_x}{(p_x+1)(p_x+2)}
+\frac{\varepsilon}{p_x+1}
-\frac{\gamma}{p_x+a_x+1}-\delta.
\tag{4}
\]

则有

\[
\boxed{
(\lambda+\beta+\varepsilon)u+\gamma v+\delta K
-\lambda f(B)-\varepsilon\bar f_Q
-(\beta+\varepsilon)\bar f_R+\varepsilon\bar g_{QR}
+\sum_x(k_x)_+\ge0.
}
\tag{MP}
\]

这里t₊=max(t,0)。参数在本次固定子博弈的全部客户和类型上共同固定，不可逐
客户或逐hist选权再借同一收入；不同子博弈或另一次合法应用可以另选参数。
式(MP)保留全部非负参数，零参数面无需除法或单独假设。对任意指定参数，它
在完整客户类型重数上是一条齐次线性必要式；正部只作用于由客户类型和固定
参数确定的系数。

### 证明

[共同F势上限原文](真实末回复的共同潜力上限与重叠参数端点--引理.md)已经证明
同一个X对所有合法T,S同时给出

\[
u\ge U(T,X),\qquad
u+f(X)\ge f(T)+f(S)-g(T,S).
\tag{5}
\]

为明确其量词，令Y为同一策略在强制X后的真实末回复。第一式的非负分解为

\[
u-U(T,X)
=[u-U(X,Y)]+[U(Y,X)-U(T,X)]+[f(X)-f(Y)].
\]

前两项分别是原倒二IC及强制X后的真实末位IC，最后一项用全目录最大性。
第二式则令Y为强制T后的真实回复，分解为

\[
u+f(X)-f(T)-f(S)+g(T,S)
=[u-U(T,Y)]+[U(Y,T)-U(S,T)]+[f(X)-f(Y)].
\]

每次分解内部共享同一个真实Y；并未让强制动作成为最优者。两个分解所用的
X始终是(2)选定的同一个全目录合法标签。

现将以下五条非负行按左列乘子相加：

| 乘子 | 非负行及来源 |
|---:|---|
| λ | `u−U(B,X)`，(5)查真实末题B |
| β | `u−(1/m)Σ_i U(R_i,X)`，(5)对固定菜单求平均 |
| γ | `v−U(X,A)`，原真实末位节点查询合法X |
| δ | `K−|X|`，全目录裸大小上界 |
| ε | `u+f(X)−bar f_Q−bar f_R+bar g_QR`，(5)对配对菜单求平均 |

将X的会员记为x_x。相加所得恰为(MP)左端把正部和换成 `Σ_x k_x x_x`。
逐客户0≤x_x≤1给

\[
(k_x)_+-k_xx_x\ge0.
\tag{6}
\]

加入(6)即证明(MP)。没有声称逐客户IC本身非负，也没有把取正部的客户集合
当作目录中的某个主题。所有五份全局预算都在表中明确支付。

## 3. 六人实际末两位的一条紧凑实例

令p=P为实际前四负载，A=A5、B=A6；取m=6，配对菜单为此前真实分支中的

\[

\]

\[
\frac1{P+a_5+1}=\frac1{P+1}

\[
\kappa_x=
\frac{12a_{6x}+24a_{5x}+6d_C(x)-(P_x+2)(P_x+9)}
{(P_x+1)(P_x+2)}.
\tag{7}
\]

对应实例是

\[
\boxed{

-16\bar f_B-52\bar f_C+16\bar g_{BC}

\tag{MC6}
\]

本式对全部客户类型有效，不局限某16个hist，也无需最优六题重数d=1。
重复菜单项、空题、零客户、任意弱平局和同覆盖异标签均沿原证明保留。
