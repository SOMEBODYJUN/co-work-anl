# 命题、模型与原稿状态

[4140B完整原稿](../../tools/evidence/fractional-cover-safety/original/fractional_cover_safety.md)已正常 `clean show` 全文读，SHA-256为 `0494f814d2ff53de3fed810470f3a249dc352b6b41fe70afcdab590f7eb5c587`，两冻结提交同字节。原稿自标“自行推导候选、尚待独立数学审查”。本页逐式重构了其静态证明、锐例、极限及条件式，并核对先有对数查询结果与后续纠错；不把原候选标签当作证明，也不冒称外部审查。

采用[共同目录完整历史模型](../定义/共同目录完整历史模型--定义.md)的有限单位客户、有限非空共同主题目录 \(\mathcal S\) 和单位提供者。空主题、重复选择、同覆盖异标签与零客户允许。去掉完全不属于任何主题的客户后，剩余客户集记为N，\(U=|N|\)。这些被去掉的客户对所有行动的收益、覆盖及最优值均为零；没有从目录删除任何动作。

对非零实例 \(U>0\)，定义覆盖**整个目录联合N**的分数集合覆盖数

\[
\tau^*=\min\left\{\sum_{A\in\mathcal S}z_A:
z_A\ge0,\quad\sum_{A\ni x}z_A\ge1\quad(x\in N)\right\}.
\tag{1}
\]

有限目录中每题赋权1可行。将总重限制在目录大小以内，得到非空紧可行集，故最小值取得。每个客户的覆盖约束都给 \(\tau^*\ge1\)；若目录有k个标签，\(\tau^*\le k\)，逐客户选择一题还给 \(\tau^*\le U\)。权重只用于静态覆盖，不是提供者权重，也不允许在原博弈中把分数主题当作单次行动。

给定整数 \(n\ge1\)，竞争元组 \(B\in\mathcal S^{n-1}\) 可有重复，\(c_x(B)\) 是其中覆盖x的槽数。定义

\[
f_B(A)=\sum_{x\in A}\frac1{1+c_x(B)},\qquad
v_n=\max_{p\in\Delta(\mathcal S)}\min_{B\in\mathcal S^{n-1}}
\sum_Ap_Af_B(A).
\tag{2}
\]

对手可以知道查询分布p，且竞争行动之间可以任意相关；它不能看见本次抽出的A以后再选B。对固定p，允许随机相关B不改变最小值，因为目标对其分布线性。有限minimax另给静态对偶，但下面下界直接构造一个同时抵御每个B的p，不需要交换max/min。

**静态下界为**

\[
\boxed{v_n\ge\frac{U}{n+\tau^*-1}\qquad(n\ge1,U>0).}
\tag{FC}
\]

U=0时 \(v_n=0\)，单独处理，不必把 \(\tau^*=0\) 代入可能出现零分母的公式。这里是空背景安全值；非零合法前缀后的总利润、fresh覆盖或背景安全值没有被本命题自动包含。

# 一个查询分布同时保证所有人数

对目录分布p记客户命中概率

\[
q_x(p)=\sum_{A\ni x}p_A.
\]

选择使

\[
\Phi(p)=\sum_{x\in N}\log q_x(p)
\tag{3}
\]

最大的 \(p^*\)。这与最大化连续**背景**的 \(\sum_x\log(1+\operatorname{load}_x)\) 是不同优化问题。

存在性与正性需要说明。均匀目录分布使每个可覆盖客户的q为正，得到有限值 \(M_0\)。所有q≤1，所以其余对数项不正；若某个 \(q_x<e^{M_0}\)，则 \(\Phi(p)<M_0\)，不可能改善该初始值。因此可把最大化限制到每个 \(q_x\ge e^{M_0}>0\) 的非空紧集上，连续目标取得最大值。故 \(p^*\) 存在，全部 \(q_x=q_x(p^*)>0\)，即使部分主题的概率为零也无碍。p本身不必唯一或有理，本证明不依赖这两项性质。

对每个合法主题A，沿可行单侧方向 \(p^*+t(e_A-p^*)\) 的导数非正，得到

\[
0\ge\sum_x\frac{\mathbf1_A(x)-q_x}{q_x}
=\sum_{x\in A}\frac1{q_x}-U.
\]

因而

\[
\boxed{g(A):=\sum_{x\in A}\frac1{q_x}\le U
\quad\text{对每个合法A}.}
\tag{4}
\]

按 \(p^*\) 加权平均，\(\sum_Ap_A^*g(A)=U\)，所以正概率主题的(4)都取等；没有要求零概率主题也取等。

取任意(1)的最优分数覆盖z。先用每个客户的覆盖约束，再用(4)，得到

\[
\sum_x\frac1{q_x}
\le\sum_x\frac1{q_x}\sum_{A\ni x}z_A
=\sum_A z_Ag(A)
\le\tau^*U.
\tag{5}
\]

固定任意竞争元组B，重复主题按槽数求和，(4)又给

\[
\sum_x\frac{c_x(B)}{q_x}
=\sum_{A\text{ 为B的一个槽}}g(A)
\le(n-1)U.
\tag{6}
\]

令 \(a_x=q_x/(1+c_x(B))>0\)。Cauchy–Schwarz给

\[
\left(\sum_xa_x\right)\left(\sum_xa_x^{-1}\right)\ge U^2.
\]

其余项也可直接写为
\(\sum_{x<y}(a_x-a_y)^2/(a_xa_y)\ge0\)，所以这里没有关于客户独立性或负载同分布的假设。由(5)—(6)，

\[
\begin{aligned}
\sum_Ap_A^*f_B(A)
&=\sum_x\frac{q_x}{1+c_x(B)}\\
&\ge\frac{U^2}{\sum_x(1+c_x(B))/q_x}
\ge\frac{U}{n+\tau^*-1}.
\end{aligned}
\tag{7}
\]

同一个 \(p^*\) 由固定目录和客户集决定，与n无关；(7)对每个n的每个静态B分别成立，证明(FC)。这是一个安全策略下界，不声称 \(p^*\) 对每个n都达到安全值最优。例如两个不交主题大小2和1，(3)的概率为(2/3,1/3)，n=1时查询期望为5/3，而 \(v_1=2\)。也不把这个随机设计当作顺序玩家能够隐藏的承诺：真实后继观察首动作的机制在此没有出现。

# 先有对数查询证明与真正的改进

[旧静态人数预算来源](../资源/静态随机删槽工具与安全聚合的旧边界--资源.md)已经使用同一个(3)，先证(4)，再把 \(p^*\) 的正支持主题各赋权1，若其个数为ℓ，得到

\[
v_n\ge U/(n+\ell-1).
\]

因为每个q_x>0，这ℓ题确实覆盖N，故 \(\tau^*\le\ell\)。本源把这一整数支持覆盖改成任意最优分数覆盖，得到(5)，所以改进的是有限n下分母中的结构参数。旧来源已证明固定目录 \(nv_n\to U\)，不能将该极限重新算作本源首次结果。

取每个目录题权1即得 \(v_n\ge U/(n+k-1)\)；这只是较粗推论。重合较多的目录可能 \(\tau^*\ll k\)。例如三个客户和三道两客户主题，分别遗漏一个客户；每题权1/2给 \(\tau^*\le3/2\)，把三条客户约束相加给总重至少3/2，故恰为3/2。此时主界为 \(3/(n+1/2)\)，而只用题数的界为 \(3/(n+2)\)。这是参数改进的解析例，不额外宣称主界在这组参数上取等。

[连续对数背景价格的后续纠错](../资源/连续对数势价格与安全值极小极大的入口界限--资源.md)撤回的是把 \(\log(1+\text{背景负载})\) 极值误认作自由分数安全minmax鞍点的推断。这里(3)优化查询命中概率，(7)直接逐个竞争B成立，不使用被撤回的Jensen方向。两种对数用途不能因名称相似而互相证伪或共享最优性。

# 任意目标集版本及既有OPT安全界

本页的同一证明还给一个明确的解析推论。保持**原共同目录和全部竞争元组不变**，取任意非空可覆盖客户子集C，令 \(\tau_C\) 为用原目录覆盖C的最低分数总重。在C上最大化 \(\sum_{x\in C}\log q_x\)，并把(4)—(7)中的N、U换成C、\(|C|\)。原收益还包含C外的非负项，故

\[
\boxed{v_n(\text{原实例})\ge\frac{|C|}{n+\tau_C-1}.}
\tag{8}
\]

这是静态矩阵的逐项下界，未断言删去C外客户后原SPE仍是SPE，也未删除任何合法主题。C=空集另作零下界。取C为某个最优n题并集，给每个比较题一次权重便有 \(\tau_C\le n\)，由(8)恢复

\[
v_n\ge\frac{\operatorname{OPT}_n}{2n-1}.
\tag{9}
\]

(9)已由[静态混合安全值锐目录计数界](../定理/静态混合安全值的锐目录计数界--定理.md)独立证明。本页补的是(FC)与该先有结论之间的推导关系，不另认领(9)。仅用全目录的τ*时，τ*不自动≤n，因为整个目录联合可能需要更多比较题覆盖；不可将 \(\tau_N\) 与最优并集的 \(\tau_C\) 混用。

# 锐例、非整除情形与锐性量词

取k≥1个两两不交的等大主题，每题L≥1名单位客户。则 \(U=kL\)，每题有私有客户，覆盖约束迫该题权至少1，故 \(\tau^*=k\)。令 \(n-1=kh\)，h为非负整数。竞争者在每题固定放h个槽，每个纯查询都给

\[
\frac L{h+1}=\frac{kL}{n+k-1}
=\frac U{n+\tau^*-1}.
\tag{10}
\]

这个不观察查询的确定元组给安全值上界，配合(FC)得到等号。相应对数查询是均匀分布，q_x=1/k；(5)、(6)及Cauchy同时取等。k=1覆盖每个人数，h=0覆盖n=1；对任意固定k，还有全部n≡1 mod k的无限取等序列。没有要求这些静态竞争者构成任何均衡。

这证明不能对所有可实现参数三元组 \((U,n,\tau^*)\) 都把(FC)严格提高；没有证明每个非整数τ*、每个人数或每个参数组合都能取等，也没有完整刻画其最优参数函数。

已有[不交单客户安全值分类](../定理/不交单客户安全值的独立背景取等分类--定理.md)还能精确说明这里的整除限制。写 \(n-1=kh+r\)，\(0\le r<k\)，把该定理按L倍客户展开，得

\[
v_n=\frac Lk\left(\frac{k-r}{h+1}+\frac r{h+2}\right).
\tag{11}
\]

均匀查询抵御所有整数负载的下界由凸倒数的整数割线给出；对偶把r题放h+1槽、其余h槽，并均匀置换题名。r=0时(11)就是(10)，r>0时比 \(kL/(n+k-1)\) 严格大。这是已知静态精确值的比较，未重跑该分类的有限审计，也不把允许相关的对偶替换成独立同分布对手。

# 固定目录极限及一个自足上界

对固定非零目录，U和τ*固定。由(FC)，

\[
nv_n\ge\frac{nU}{n+\tau^*-1}.
\]

为完整说明上界而不借顺序支付，取n个主题的静态终局z，使调和势 \(\sum_xH_{c_x(z)}\) 最大；有限目录保证存在。对每个玩家槽i和每个合法主题A，势最大性给

\[
f_{z-i}(A)\le u_i(z),
\]

因为两边分别是将A或原动作插回同一z−i后的势增量。于是均匀随机删z的一槽得到一个合法静态竞争分布Q，对每个查询A都有

\[
\mathbb E_Q f_B(A)\le\frac1n\sum_i u_i(z)
=\frac{W(z)}n\le\frac Un.
\]

任意查询分布的最坏纯背景至多这个平均背景值，所以 \(nv_n\le U\)。此静态最大势终局虽是静态纯NE，但没有把顺序SPE与静态NE的福利作比较。

因此得到量化夹逼

\[
\boxed{0\le U-nv_n\le\frac{U(\tau^*-1)}{n+\tau^*-1}},
\qquad\boxed{\lim_{n\to\infty}nv_n=U.}
\tag{12}
\]

τ*=1时所有n都取 \(v_n=U/n\)。原稿给的另一条合法上界为 \(nv_n\le Z_n\le\operatorname{OPT}_n\le U\)，来自[静态iid凹势基准](../定理/静态独立同分布安全基准--定理.md)；其中iid最优分布与(3)的查询设计并非同一个一般对象。若目录和客户随n变化，U、τ*也可能变化，不能从固定目录的(12)推出全输入统一收敛或统一动态覆盖比。

# 完整SPE全覆盖：两条尚需付款前提的条件式

现在另取原顺序游戏中的一份**完整有序历史纯SPE**，根实际覆盖数为W。所有实际与离轨节点、重复行动和弱平局仍须满足同一策略的最佳回复。前面没有使用任何这些动态IC。

若另外有强付款桥 \(W\ge nv_n\)，由(FC)及W为整数，才能推出

\[
W\ge\left\lceil\frac{nU}{n+\tau^*-1}\right\rceil.
\tag{13}
\]

要使右边超过U−1，精确条件为

\[
\frac{nU}{n+\tau^*-1}>U-1
\quad\Longleftrightarrow\quad
\boxed{n>(U-1)(\tau^*-1)}.
\tag{14}
\]

W≤U于是强迫W=U。此处严格大于不可随意换成大于等于；等号边界时本下界可能只给U−1。若“强桥”只对所给一份SPE成立，结论也只针对该份；只有对该游戏每份完整SPE都成立时，才能说每份均全覆盖。

若另有较弱付款桥 \(W\ge(n-1/2)v_n\)，则

\[
W\ge\left\lceil\frac{(n-1/2)U}{n+\tau^*-1}\right\rceil,
\]

同理在

\[
\boxed{n>(U-1)(\tau^*-1)+U/2}
\tag{15}
\]

时条件性地全覆盖。U=0平凡，U=1亦由上述整数和正分母分别处理；这些取整推论依赖单位客户，不应直接套用非整数质量总和或非零前缀的后继利润。

因此，在满足(14)或(15)的人数与固定目录中若构造一份遗漏客户的完整SPE，会分别否定对应付款桥在该实例上的成立。反证对象是指定桥，未必是half；本文没有给这种策略或反例，也没有从条件后果反推桥成立。

已有[真实前缀分数覆盖预算](分数覆盖的真实前缀利润预算--引理.md)不依赖这两条桥，而直接用真实偏离得到

\[
W\ge U\left[1-\prod_{r=1}^{n}\left(1-\frac1{r\tau^*}\right)\right].
\tag{16}
\]

固定目录下乘积趋零，结合整数福利也会在足够大人数后无条件全覆盖；例如乘积严格小于1/U即可。不能因“最终全覆盖”另有正确机制，就把(14)—(15)的具体阈值改写成已经无条件证明。静态安全下界与真实前缀预算使用同一覆盖参数，却有不同的支付内容和收敛界。

对恰六人，[分数覆盖9/2条件定理](../定理/六人分数覆盖条件半覆盖--定理.md)针对任意比较集C，使用真实末两人关系及早期IC证明 \(\tau_C\le9/2\Rightarrow2W\ge|C|\)。它不靠(13)的未补强桥，也不是把(FC)中的参数直接代9/2所得。一般最优六题并集只自动有 \(\tau_C\le6\)，而全目录τ*可能更大；本静态引理没有消除这些动态缺口。
