# 对象、量词与结论

在[共同目录完整历史模型](../定义/共同目录完整历史模型--定义.md)中只取两名提供者。固定任意一份**完整**纯SPE策略σ。设第一人实际选A，第二人在该历史选B=σ₂(A)，实际覆盖为C=A∪B，W=|C|。对任意两个合法目录标签T、S，令

\[
R(T,S;C)=|(T\cup S)\setminus C|,
\qquad R_2(C)=\max_{T,S\in\mathcal A}R(T,S;C).
\]

最大化允许T=S，不要求这两个主题最大化原全客户覆盖，也不为不同客户分别选择主题。有限非空目录保证最大值存在。

**引理。** 对每份上述完整纯SPE及每对T、S，

\[
\boxed{\frac9{10}R(T,S;C)\le W.}
\tag{1}
\]

因此 \(9R_2(C)\le10W\)。这是外部残余的上界；它不声称真实SPE可达到10/9的残余比，也不是任意人数的结论。

# 同一策略中的十条合法比较

令

\[
U(X,Y)=|X\setminus Y|+\frac12|X\cap Y|,
\qquad u=U(A,B),\quad v=U(B,A).
\]

U(X,Y)是自己选X、另一人选Y时的终局收益，因单位价值均分而有u+v=W。取**这份σ**在两个根偏离后的真实回复

\[
Q=\sigma_2(T),\qquad R=\sigma_2(S).
\]

Q、R均是目录中的整主题，不能用另一个均衡或另一个客户各自最有利的回复替换。下面G均为非负的全客户收益差。

| 真实决策节点 | 必要行G | 非负乘子λ |
| --- | --- | ---: |
| 实际末位，在A后选B | v−U(T,A) | 3/10 |
| 同上 | v−U(S,A) | 3/10 |
| 同上 | v−U(Q,A) | 1/5 |
| 同上 | v−U(R,A) | 1/5 |
| T后的末位选Q | U(Q,T)−U(S,T) | 1/10 |
| S后的末位选R | U(R,S)−U(T,S) | 1/10 |
| T后的末位选Q | U(Q,T)−U(R,T) | 1/5 |
| S后的末位选R | U(R,S)−U(Q,S) | 1/5 |
| 根实际选A，偏离T后按σ回复Q | u−U(T,Q) | 1/2 |
| 根实际选A，偏离S后按σ回复R | u−U(S,R) | 1/2 |

前八行来自三个末位子博弈的最佳回复，最后两行来自根的最优性，全部允许等号。它们只是原程序22行中的十行；证明不需要把目录缩成六个不同主题，也不需要额外的根单主题保底行。

# 逐客户恒等式及非负余项

固定一名客户x，写六个0/1会员位

\[
(a,b,t,s,q,r)=
(1_{x\in A},1_{x\in B},1_{x\in T},1_{x\in S},1_{x\in Q},1_{x\in R}),
\quad n=t+s,\ e=q+r.
\]

两人收益的逐客户系数是 \(U_x(X,Y)=x_X(1-x_Y/2)\)，从而可直接展开表中每个G的客户系数Gₓ。定义

\[
h_x=1_{a\lor b}
-\frac9{10}1_{a=b=0,\ n>0}
-\sum_{j=1}^{10}\lambda_jG_{j,x}.
\tag{2}
\]

将上述二值收益代入并合并，得到以下完整闭式。b仍取0或1，e取0、1或2；不需要假定会员位独立发生。

| a | n=t+s | 余项hₓ |
| ---: | ---: | --- |
| 0 | 0 | e/10 |
| 0 | 1 | 9b/10 |
| 0 | 2 | 4/5−e/10+9b/10 |
| 1 | 0 | 0 |
| 1 | 1 | 3/4−e/10 |
| 1 | 2 | 7/5−e/5 |

这六式覆盖全部64种六位会员模式。各式显然非负：后三个非平凡最小值分别为3/5、11/20、1；其余为非负整数位的非负倍数或零。这里hₓ逐客户非负，但每个Gⱼ,ₓ不必逐客户非负；使用SPE约束时必须先按同一整主题将客户系数求和。

对全部客户求和，(2)成为精确恒等式

\[
W-\frac9{10}R(T,S;C)
=\sum_{j=1}^{10}\lambda_jG_j+\sum_xh_x\ge0,
\tag{3}
\]

因为λⱼ≥0、每条整主题真实IC的Gⱼ≥0及每个hₓ≥0，得到(1)。证明完成。

# 重复、空主题与边界情况

六个角色A、B、T、S、Q、R允许相同。若T与S是**同一个行动标签**，确定性策略给Q=R；对应比较可重复或成为零行，恒等式仍成立。若T、S只是覆盖集合相同的两个不同标签，完整有序历史可能为它们指定不同的平局回复，不能擅自合并Q、R；本证明保留两条真实历史并仍然适用。其它角色重合也只限制实际可出现的会员模式，不会破坏已经对全部64模式成立的恒等式。

空主题的会员位全0；没有客户时所有量都0，证明不用除W或残余。若W=0，(3)直接给任意T、S的残余0。没有任何严格最佳回复、正客户数、归一化或不同覆盖集合假设。
