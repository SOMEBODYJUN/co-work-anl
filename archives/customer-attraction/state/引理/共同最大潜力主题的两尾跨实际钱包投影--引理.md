# 同一最大潜力主题的真实两尾与实际钱包联合投影

此页将原真实IC、PAIR和RC在同一Y,T上合账，再一次性消去两尾会员。既有PAIR与RC不被重新认领为新来源。新接口保留真实第四源分支中的T与实际末两位查询T为同一个合法标签。

## 1. 模型与固定身份

有限单位客户、有限非空共同标签目录，恰六人，任意完整有序历史纯SPE。实际标签为A1,...,A6。保留空覆盖、同覆盖异标签、重复行动、零客户与全部弱平局。

逐客户记实际位a1,...,a6，b=a1+a2+a3，P=b+a4，D=P+1。取一次全目录f_P最大合法标签X，会员x，F_X=Σx/D。K为全目录最大裸大小，与X不必由同一标签达到。

在真实历史(A1,A2,A3)强制第四人选X，随后沿固定策略的真实后继得到Y,T，会员y,t。令h=b+x+1，则该分支最后两人的背景分母为h。另O为任意六合法标签的覆盖并，o为其会员，θ=o/6。O不是新行动。

## 2. 六份真实预算

定义分支两尾钱包逐客户系数

\[
H(y,t)=\frac y{h+t}+\frac t{h+y}+\frac y{h(h+1)}.
\]

以下每行写作ΣA_r≤B_r，保留同一个真实Y,T。

| r | 逐客户A_r | 共同预算B_r |
|---|---|---|
| 0 | x/(b+1+y+t) | 实际u4 |
| 1 | y/D | F_X |
| 2 | t | K |
| 3 | (θ−t)/(h+y) | 0 |
| 4 | (a6+θ)/h−a6θ/[h(h+1)]−H(y,t) | 0 |
| 5 | (t+θ)/D−tθ/[D(D+1)] | 实际u5+F_X |

第0行是第四源真实偏离IC；第1行来自同一actual P下X的全目录最大性；第2行是合法T的真实大小帽。第3行是该分支真实末节点的六查询BR平均，再弱化到o/6。

第4行来自这一个真实四行动前缀(A1,A2,A3,X)的两人PAIR。一般背景h−1、真实末两标签Y,T，记f(Q)=Σq/h、g(Q,R)=Σqr/[h(h+1)]。对任何合法Q,R，令V为第五人在该前缀改Q后的真实末回复。第五源IC、V对R的末BR、原T对同一V的末BR三份相加，并加非负g(Y,Y)−g(Y,V)，给

\[
f(Q)+f(R)-g(Q,R)\le u_Y+u_T+g(Y,Y).
\]

取Q=A6，并对六合法R平均。平均会员d/6减弱为o/6时，其系数1/h−a6/[h(h+1)]严格正。因此第4行成立。A6虽来自实际路径，仍是共同目录合法标签；不搬用实际u6支付分支钱包。

第5行是actual前四历史上的RC。一般共同f_P最大值F_X满足f_P(Q)+f_P(R)−g_P(Q,R)≤u5+F_X：实际第五源改Q的真实IC、其真实末回复V_Q对R的BR以及F_X−f_P(V_Q)≥0共同支付。这里取Q=T、R为六查询平均；系数1/D−t/[D(D+1)]严格正，故允许覆盖并减弱。V_T不要求等于产生标签T的另一分支末回复，绝不冻结那条分支的后继。

## 3. 任意六个全局非负权的联合投影

任选λ0,...,λ5≥0，它们在一次应用中对所有客户固定。记

\[
\Psi_v(y,t)=\sum_{r=0}^{5}\lambda_r A_r(v,y,t),
\qquad m_\lambda(v)=\min_{y,t\in\{0,1\}}\Psi_v(y,t),
\]

其中v=(a1,...,a6,x,o)覆盖全部256个布尔类型。则普遍有

\[
\boxed{
\lambda_0u_4+\lambda_5u_5+(\lambda_1+\lambda_5)F_X+\lambda_2K
-\sum_v m_\lambda(v)z_v\ge0.}
\tag{PROJ}
\]

证明：令μ_{v,y,t}为真实共同会员质量，Σ_{y,t}μ=z_v。每份原预算R_r=B_r−ΣA_rμ≥0。逐型最小值给ρ=Ψ−m≥0，故有恒等式

\[
\lambda_0u_4+\lambda_5u_5+(\lambda_1+\lambda_5)F_X+\lambda_2K
-\sum_v m_\lambda(v)z_v
=\sum_r\lambda_rR_r+\sum_{v,y,t}\rho_{v,y,t}\mu_{v,y,t}\ge0.
\]

m可以为负；质量等式的乘子没有符号限制。必须取最小值，并保全部四尾态与全部256原型。分别对六行独立消去Y,T通常会弱化该联合投影；此处不宣称每次严格改进，也不宣称拥有整个共同客户律或完整策略的充分条件。

## 4. 一份精确整数实例

取

\[
(\lambda_0,\lambda_1,\lambda_2,\lambda_3,\lambda_4,\lambda_5)
=(4096,800,71,384,512,900).
\]

则PROJ为

\[
4096u_4+900u_5+1700F_X+71K-\sum_v m(v)z_v\ge0,
\]

其中

\[
\begin{aligned}
\Psi_v(y,t)={}&4096\frac{x}{b+1+y+t}+800\frac yD+71t
+384\frac{\theta-t}{h+y}\\
&+512\left[\frac{a_6+\theta}{h}-\frac{a_6\theta}{h(h+1)}
-\frac y{h+t}-\frac t{h+y}-\frac y{h(h+1)}\right]\\
&+900\left[\frac{t+\theta}{D}-\frac{t\theta}{D(D+1)}\right],
\quad m(v)=\min_{y,t}\Psi_v(y,t).
\end{aligned}
\]

全部256型系数及四态最小值可由上式直接重建。工作包universal_true_x_tail/的完整780变量、52质量式、608行系统发现了此实例；精确证明只使用上述六行。Main另从字面份额独立重建1024个四态值与全部257个切面系数。具体有限点的负值只在六人计算正文绑定原点后使用，不从某点支持外推本页普遍性。
