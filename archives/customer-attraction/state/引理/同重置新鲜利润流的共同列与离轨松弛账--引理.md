# 固定原博弈与同一次残余账

采用[共同目录完整历史模型](../定义/共同目录完整历史模型--定义.md)：有限单位客户集N、有限非空共同主题目录、任意m≥1名单位提供者，依次观察全部有序历史各选一个主题，终局每客户在覆盖者间均分。固定全部有序历史上的完整纯SPE σ。空主题、重复行动、同覆盖不同标签、零客户和任意离轨平局均保留。

actual叶为B，覆盖C、利润u_l，W=Σ_lu_l=|C|。固定一个合法比较m元组T，O=∪_iT_i、I=O∩C、R=O∖C；只有T最优时|O|=OPT_m。同一次坐标分割先付current d和实际正券H，再按**该次**I-future重算补余J，满足

\[
d_l\le u_l,\qquad H_l+J_l\le u_l(B;I),\qquad
|O|=\sum_l(d_l+H_l+J_l+K_l).
\tag{LEDGER}
\]

分割、H/J的精确定义与条件证明见[交集互补接口](最优交集客户的互补付款与新鲜余量接口--引理.md)。本页的K专指从该次R入口**重新计算**的fresh利润ν核，不能继承原完整利润v核的β或费用。待证的扩展合同是：每份原完整SPE，能否共同选一个最优T、合法坐标剪枝、I付款及fresh路由，使

\[
\boxed{K_l\le Q_l:=2u_l-d_l-H_l-J_l\quad\text{对全部 }l\text{ 同时成立。}}
\tag{FR?}
\]

Q_l≥0由前两项预算得到，但未证明足付K_l。原RESIDUAL-CAP另限于full-SAFE/合法CLIP及其原出口；I直接付款与ν重算已扩大接口。扩展合同即使成立也不自动实现原限定路由。一个固定T、固定比例或固定ν路由失败，则不足以否定这里的存在量词。

# fresh核的局部定义与守恒

自然context t=(g,k)保留完整旧有序历史g，规定动作a_t=σ_k(g)、规定叶V_t=finish_σ(g)。其actual-prefix重置为

\[
A_t=\operatorname{finish}_\sigma(B_{<k},a_t).
\]

对x∈a_t∖C，两叶均由当前k覆盖它，c_A(x),c_V(x)≥1。新增重置coverer j给正价1/[c_A(x)c_V(x)]，消失coverer给同价负项。按角色及客户合并为q_tj、P_t=Σ_jq_tj、N_t。因为A_t的过去都是actual主题、都避开N∖C，正接收角色只能j>k，目标是A_t的真实prescribed context；消失coverer可在过去或未来。

设ν_t=u_k(V_t;N∖C)、D_t^F=u_k(A_t;N∖C)。对每客户数coverer之差后相加，得到

\[
\nu_t-D_t^F=P_t-N_t,\qquad
\nu_t-P_t=D_t^F-N_t
=\sum_{x\in a_t\setminus C}\frac{|\operatorname{cover}_{V_t}(x)\cap\operatorname{cover}_{A_t}(x)|}{c_V(x)c_A(x)}>0
\tag{LOSS}
\]

（最后严格性以ν_t>0为条件）。合法R入口或正fresh边都带一个当前动作覆盖的fresh客户作见证，故h_t>0时ν_t>0。同一真实context先合并全部incoming金额h_t，再置β_t=h_t/ν_t；零输入且ν_t=0的节点跳过。各正边发β_tq_tj，current留β_t(ν_t−P_t)。它们非负且和为h_t；角色严格递增，有限DAG最终全部吸收。

这里β_t按**全部fresh利润**重采，而非固定原来源客户。即使跟踪origin标签，后来输出的客户x也可能不在该origin的T_i。客户保持核使用逐客户系数，属于另一核，不能把它的密度或费用直接移入本ν图。

# 同一新叶的精确共同列

固定角色k和目录标签a，令\(\mathcal G_{k,a}\)为所有已生成、角色k且规定a的自然contexts。它们的旧叶V_t各异，重置叶却全为A=finish_σ(B_<k,a)。对j>k及x∈a∩A_j∖C，总正金额与以A中j份额为单位的密度分别是

\[
F_{\mathcal G,j,x}
=\sum_{t\in\mathcal G}\frac{\beta_t\mathbf1_{x\notin(V_t)_j}}{c_A(x)c_{V_t}(x)},\qquad
\boxed{\Lambda_{\mathcal G,j,x}
=\sum_{t\in\mathcal G}\frac{\beta_t\mathbf1_{x\notin(V_t)_j}}{c_{V_t}(x)}.}
\tag{MERGE}
\]

所以Σ_(t∈G)β_tq_tj=Σ_(x∈a∩A_j∖C)Λ_(G,j,x)/c_A(x)。这是逐边定义相加的精确恒等式，不是Λ≤1的结论。

原稿“经济动作a”的分组在此按同一合法标签解释；仅客户集合相同的不同标签，原σ仍可给不同有序后继，不能据此合并。可合并的实质条件是同一原actual-prefix查询叶及同一边定义。

若目标r=(A_<j,j)首次偏离actual的位置为k，则其任何reset父的角色必为k：角色l的reset叶在l前等于actual，且在l取其规定非actual动作，故首次差异为l。它的动作也必须是a。直接初始化另外只能来自owner k在该位置的query a；若其逐客户注入为θ_jx/c_A(x)，总密度为θ_jx+Λ_(G,j,x)。初始θ≤1不控制这个和。此推导允许多个父，绝不把不同旧历史认成一个节点，也不把每context β≤1变成同角色共同付款。

# 真实ell的共同加权位置

对t∈G定义

\[
X_t=u_k(V_t;C),\quad W_t=\operatorname{finish}_\sigma(g,B_k),\quad
w_t=u_k(W_t),\quad \ell_t=\nu_t+X_t-w_t\ge0.
\]

ell来自**旧g上**改actual主题B_k的一条完整IC。B_k⊆C，因此w_t全是C利润。W_t依g变化，通常不是actual-prefix叶。任意非负β加权，精确有

\[
\boxed{\sum_{t\in\mathcal G}\beta_tw_t
=\sum_{t\in\mathcal G}h_t+\sum_{t\in\mathcal G}\beta_tX_t
-\sum_{t\in\mathcal G}\beta_t\ell_t.}
\tag{ELL-GROUP}
\]

组内共同重置的D^F=u_k(A;N∖C)、Y=u_k(A;C)、e=u_k−u_k(A)≥0固定，负项N_t仍依旧叶变化。令Γ=Σ_tβ_t，LOSS给

\[
\boxed{K_{\mathcal G}=\sum_t\beta_t(\nu_t-P_t)
=\Gamma D^F-\sum_t\beta_tN_t
=\Gamma(u_k-Y-e)-\sum_t\beta_tN_t.}
\tag{RESET-GROUP}
\]

由ν_t=w_t−X_t+ell_t，还可写K_G=Σ_tβ_t(w_t−X_t−P_t+ell_t)，此式中的ell为**正号**。ELL-GROUP没有把不同真实返回叶的w_t合成一份actual u_k或actual I/G钱包，也没有给Γ共同上界。

固定h_t=β_tν_t及各β_tq_tj时，current由守恒唯一指定为β_t(ν_t−P_t)。再扣β_tell_t会使同量质量没有合法出口。此处排除的是固定图中的重复退款步骤；若另改分母、扩边或跨节点抵扣，必须重算h/β、全部合流与终端，并重新证明合法性。它不排除ell在新共同构造中有用。

# 全源主题IC与二次偏离叶

每个T_i都是旧g上的合法行动，故原完整SPE给

\[
\nu_t+X_t\ge Q_t(i):=u_k(\operatorname{finish}_\sigma(g,T_i)).
\tag{SOURCE-IC}
\]

非负λ_ti且Σ_iλ_ti≤1时可合法平均为ν_t+X_t≥Σ_iλ_tiQ_t(i)。若λ按incoming来源比例取值，它只约束来源组成；整体放大h不改变这个归一化比较，不能据此控制未归一化Σβ。

Q_t(i)保留旧首偏离，再于g后强制T_i，不能替换为finish(B_<k,T_i)。其中较早角色的利润也不因此成为该角色原prescribed利润。将这些叶投回自然利润会留下共同请求、旧叶项，可能产生循环；原稿未给SOURCE-IC到FR?的联合不等式。保原全树约束的这种比较仍是可接续想法，尚非已付容量或half证明。
