# 固定原策略和源匹配

固定[共同目录完整历史模型](../定义/共同目录完整历史模型--定义.md)任意m≥1、完整纯SPE σ、actual覆盖C/福利W和各位u_s。取一个最优索引m元组(T_j)，U=∪T_j、R=U\C、G=C\U；每个U客户选一个owner，Q_j⊆T_j且Q_j不交分割U。owner块只是记账，不假设它是合法主题。重复主题仍有独立槽j。

对每个槽到角色的双射π，把x∈Q_j∩R的单位源放在真实query (π(j),T_j,x)。query始终从**原actual前缀**强制完整合法主题、沿同一σ改变后的全部有序历史完成；每个π给合法递增捕获证书，没有玩家实际随机化。

对全部m!个π的证书作等权平均。在给定(s,j)上，每个该owner客户恰得1/m源，所有角色合计1。它等价于q_sj=1/m的双随机源矩阵：各槽列和/各角色行和均1。平均发生在证明空间，不是构造隐藏混合行动/混合SPE；游戏、原σ和actual叶都没改。

# 全部角色同时得到源负载≤1

对s强制T_j的完整真实叶Z_s(T_j)，令D_s(T_j)为当前**整主题全部客户**利润。x∈R在原actual过去从未覆盖，故它的当前份额r_sj,x=1/(1+未来真实覆盖数)。只计算初始化在该行的即时吸收：

\[
A^{src}_{s,j}=\frac1m\sum_{x\in Q_j\cap R}r_{s,j,x}
\le \frac{D_s(T_j)}m.
\]

D>0时w^src_sj=A^src_sj/D≤1/m；D=0时owner即时吸收必0，约定w0，不引入0/0或免费资源。对每个s独立求和全部m槽，

\[
L_s^{src}=\sum_jw^{src}_{s,j}\le1.\tag{SRC-CAP}
\]

如果T_j=T_k，同一真实query的分母D相同，应先把各槽吸收相加再用唯一整行乘子；(A_j+A_k)/D=w_j+w_k。上式因此保重复/空主题，不是为同一IC重复领取D；零客户、零收益和平局同样无碍。m1的源即时吸收全在唯一角色，仍满足结论。

这个同时cap优于一个固定π只给根/单个初始化主题的控制，但没有证明整行总负载≤1。完整query的吸收还含从较早不同真实叶重新进入的质量。分解A_s,a=A^src_s,a+A^in_s,a并用同一D，才有L_s=L_s^src+L_s^in。SRC-CAP不含L_s^in，不给后者任何界。

# 必须继续使用同一个实际钱包

[递增捕获付款](../候选/递增捕获的根后悔付款与带符号行容量--候选.md)按客户守恒后，以w=A/D给|R|≤Σ_sL_su_s。对完整SPE，若进一步获得Σ_s(L_s−1)u_s≤|G|才给OPT≤2W。SRC-CAP只能支付初始化portion，不能把“ΣL^src u≤W”和另一个“incoming≤W”相加后还称只花一份W；真实剩余容量是共同的Σ_s(1−L_s^src)u_s，另有G信用，二者均需同一次总账。
