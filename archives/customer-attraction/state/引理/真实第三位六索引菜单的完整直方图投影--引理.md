# 真实第三位六索引菜单的完整直方图投影

有限单位客户、共同有限非空目录、恰六名单位提供者，给定任意完整有序历史纯SPE。空主题、重复行动与全部离轨平局保留。实际路径记(A,B,C,D,E,F)，任取六个合法比较槽T₁…T₆，允许重复或为空，不要求先选最优。

在实际有序前缀(A,B)强制第三位T_i，沿**同一原σ**得到
\[
(A,B,T_i,F_i,B_i,C_i).
\]
后三位是真优化者；被强制的第三位不借枝内最优性。不同索引回复都在共同目录，能在其它枝查询，但不要求这些分支可同时出现于一次终局。若比较主题相同，同历史自动同回复；放宽成员位独立只扩大下面消元域。

## 客户坐标及完整原始行

对每个客户令实际六位\(\alpha=(\alpha_1,\ldots,\alpha_6)\in\{0,1\}^6\)，隐藏第i枝四位\((t_i,f_i,b_i,c_i)\)。定义
\[
p=\alpha_1+\alpha_2,\quad p_f=\sum_{j\le4}\alpha_j,\quad\ell=\sum_{j\le5}\alpha_j,
\quad d=\sum_i t_i.
\]
所有d=0…6和α全64类都保留，包括实际/比较并集均未覆盖但可被别的真实回复覆盖的客户。

为清分母，以下份额全乘60。实际一人份额\(s_j=60\alpha_j/\sum_k\alpha_k\)，分子0定义0；隐藏\(z_i=p+t_i+f_i+b_i+c_i\)，令\(s_i^T=60t_i/z_i,s_i^F=60f_i/z_i,s_i^B=60b_i/z_i,s_i^C=60c_i/z_i\)，同样零分子取0。原玩家人数仍六、客户仍单位；乘60只是系数表示。
\[
D_i=60/(p+t_i+f_i+b_i+1),\quad D_i^1=60/(p+t_i+3),
\]
\[
A_i=60/(p+t_i+f_i+1),\quad G_i=60/[(p+t_i+f_i+1)(p+t_i+f_i+2)],
\]
\[
H_i=s_i^B+s_i^C+b_iG_i,\quad
H_0=s_5+s_6+60\alpha_5/[(p_f+1)(p_f+2)].
\]
这些数均为整数；各正份额分母1…6与税分母2/6/12/20/30均整除60。

下表g_ρ是逐客户系数，另有全局κ_ρK项，K为目录最大主题大小。除CAP的κ=360外，κ均0。未把K写成每名客户的任意独立变量。

| 行名 | g_ρ(α;隐藏六词) |
|---|---|
| source | 6s₃−Σ_i s_i^T |
| cap:3 | −60Σ_i c_i；另加360K |
| fixedfloor:actual:1:3 | 6s₂−[60/(α₁+5)]Σ_i c_i |
| fixedfloor:actual:5:q，q∈{1,2,3} | 6s₆−[60/(ℓ+1)]Σ_i q_i，其中q_i分别f_i/b_i/c_i |
| fixedpair:actual:1:3 | 6H₀−[60/(p_f+1)]Σ_i(f_i+c_i)+[60/((p_f+1)(p_f+2))]Σ_i f_ic_i |
| fixedpair:actual:2:3 | 同前将f_i换b_i |
| floorfamily:1:3:off | Σ_(i≠j)(s_i^F−c_jD_i¹) |
| floorfamily:3:1:off | Σ_(i≠j)(s_i^C−f_jD_i) |
| floorfamily:3:2:off | Σ_(i≠j)(s_i^C−b_jD_i) |
| floorfamily:3:3:all | Σ_(i,j)(s_i^C−c_jD_i) |
| pairfamily:1:1:all_distinct | Σ_(i,j,l两两不同)[H_i−(f_j+f_l)A_i+f_jf_lG_i] |
| pairfamily:2:2:all_distinct | 同前将f换b |
| pairfamily:2:3:query_equal | Σ_(i≠j)[H_i−(b_j+c_j)A_i+b_jc_jG_i] |

计每个q的fixedfloor分别一行，合计15个支持行名。对每行有
\[
\mathcal G_\rho=\sum_xg_\rho(x)+\kappa_\rho K\ge0.\tag{R}
\]

## 行合法性的全部真实节点

Source是实际第三位在(A,B)分别改T_i后按真σ完成的六条IC。原第三位终局收益u₃乘6×60，隐藏负项为每个强制进入者真终局份额；没有声称T_i在其强制枝内最优。

CAP来自每个C_i合法主题大小≤K，六式相加乘60。fixedfloor的第二位/末位在原实际节点分别查每C_i或F_i/B_i/C_i；第二位保守分母α₁+5允许其后四人全部改变，末位分母ℓ+1是精确查询。隐藏F_i保守查询C_j的分母p+t_i+3同理允许后两人改变；隐藏末位C_i对F_j/B_j/C_j没有后继，分母精确D_i。它们都在相应真实前缀比较，而非冻结某条原actual尾。

强PAIR来自[末两人保留重叠](末两人重叠比较与任意索引聚合--引理.md)：同一真实末两人子局背景b、实际X/Y，H=u_X+u_Y+Σ_X1/((b+1)(b+2))；任意T/S有
\[
H-f(T)-f(S)+g(T,S)=I_1+I_2+I_3+g(X,X)-g(X,Q)\ge0.
\]
Q是当前改T后原末位真回复，三IC非负，余项在X\\Q上非负。故overlap系数是**1**，不是弱税界的2。将它用于原实际E/F或每枝真B_i/C_i，查询对应合法隐藏回复，即得表中pair行；同主题/空查询仍合法。

每个索引和都保有序及重复槽：off为30项、all为36项、query_equal为30项、all_distinct为120项。特别all_distinct每固定i有20查询对，不去重成10；其隐藏聚合可写
\[
20\sum_iH_i-8[n_q\sum_iA_i-\sum_iq_iA_i]
+n_q(n_q-1)\sum_iG_i-2(n_q-1)\sum_iq_iG_i.
\]
其中q=f或b、n_q=Σq_i。query_equal的整式为
\[
5\sum_iH_i-(n_b+n_c)\sum_iA_i+\sum_i(b_i+c_i)A_i
+n_{bc}\sum_iG_i-\sum_i b_ic_iG_i.
\]
这些是字面有序求和恒等式，不把各互斥分支总利润各叫一份实际福利。

## 完整隐藏域和最大化方向

任取非负乘子L_ρ，令
\[
h_L(\alpha;\omega_1,\ldots,\omega_6)=\sum_\rho L_\rho g_\rho,
\quad\kappa_L=360L_{cap:3},
\]
\[
\gamma_L(\alpha,d)=\max_{\substack{\omega_i\in\{0,1\}^4\\\sum_i t_i=d}}
 h_L(\alpha;\omega_1,\ldots,\omega_6).
\tag{P}
\]
最大值存在。各活跃行对六索引同时置换不变，故完整16词的六次多重集表示不丢信息：t0的8词直方图计数和6−d，t1的8词计数和d。对d0…6合计binom(21,15)=54264个多重集，背景p0/1/2共162792态。它不是“每个t组只一个回复词”的限制；后者只是另一个真子域，其不可行不能反全域。

每个真实客户的隐藏词都在(P)域内，所以逐客户γ_L≥h_L。由(R)非负和，得到对**每份**原完整SPE及任意六比较槽的必要行
\[
\boxed{\sum_x\gamma_L(\alpha(x),d(x))+\kappa_LK\ge0.}\tag{AB}
\]
逐客户最大隐藏词未必可共同实现一份σ；只扩大上界仍合法，不用可实现性倒推。改用最小值一般不能从\(\sum h_L+\kappa K\ge0\)推出(AB)。活跃行只看实际A…F而不看另七个固定分支位时，投影可以保这六位；不能把任意含其它位的行同样删位。

## 准确复用及不是福利闭合

(P)/(AB)是固定六人、固定真实第三位菜单结构的完整有限系数域结论；客户数量无上界通过求和处理，不是全目录/全策略枚举算法。指定两组整数L可生成两条具体必要行，其全部448=64×7整数系数及精确点分离需另核证书，不由本引理免费得到。

将一份可见类型分布代入(AB)得到严格负，只能证明那份保留必要系统点不能有这种真实六索引菜单延拓；不能把它称完整SPE或half反例。原whole-family发现器的浮点不可行、两词限制子域、完整直方图和独立整数投影核验是不同证据等级。这里不建立2W≥OPT₆，也没有一般人数推广、外审或新颖性声明。
