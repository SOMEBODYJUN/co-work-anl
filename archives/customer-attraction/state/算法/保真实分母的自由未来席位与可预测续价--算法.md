# 固定原叶、真实分母和允许的自由度

采用[共同目录完整历史模型](../定义/共同目录完整历史模型--定义.md)，有限单位客户、有限非空共同目录、单位玩家任意m≥1，固定完整有序历史纯SPE σ、actual叶Z及u。空主题、重复行动、零客户和所有离轨平局仍合法。固定最优合法T、owner分块Q_i⊆T_i、R=O\C及**预先**给定、与激活无关的残源0≤ρ_x≤1。以下角色用1,…,m编号。

遗漏客户x到达s=(i,a,x)，a是真目录中含x的主题。由同一σ的actual-prefix完成

\[
 Y_i(a)=\operatorname{finish}_\sigma(Z_{<i},a),\quad
 D_i(a)=u_i(Y_i(a)),\quad f_i(a,x)=|\{j>i:x\in Y_i(a)_j\}|.
\]

actual过去不覆盖R，真实负载c=1+f，f≤m−i。正输入主题含x给D>0，完整IC给r_i(a):=u_i/D_i(a)≥1。流在此仍吸收q/c；余量分为f份q/c，允许送到**任意f个不同的未来角色**J。它们无需在旧叶覆盖x，每位可查任意含x合法主题，甚至可重查原source主题。共同目录及f≤m−i保证选择存在。

这是一项证明中的packet分配，不声称旧玩家真的转移收益或改写原SPE。角色严格升高，末位f0，输入质量最终恰吸收一次。汇总客户与来源后的query吸收A_(i,a)只用唯一whole-IC系数w=A/D；随机控制须先全部积分才形成确定常数。故

\[
 \sum_{x\in R}\rho_x=\sum_s A_s
 =\sum_s w_sD_s\le\sum_i u_i\sum_{a}w_{ia}=:K.
\tag{PAY}
\]

D0时无正吸收、w置0。被取消的客户仍留在完整主题及D中；不把逐客户分拆当作客户加权IC。source首动作仍强制T_owner，改变的只是其后接收角色/合法查询，不改变首步吸收1/c。

# 普通等份流的命中及残源协方差

把固定等份分流视为单粒子随机选择current吸收或f个出口。固定不含source的目标角色集H，在当前之后还有k个目标时，首次/曾命中H的概率≤k/(k+1)。逆角色归纳：某非目标状态f个出口中有t≤k个目标，其余的续命中值至多k/(k+1)，所以

\[
 \Pr(hitH)\le\frac{t+(f-t)k/(k+1)}{f+1}\le\frac{k}{k+1}.
\tag{HIT}
\]

跨过目标只会减少后续k。源在H内则已命中为1；k0时0。证明只用不同未来出口和等份，不用它们是真future coverer。单个nonowner角色的所有query总到达≤ρ_x/2，多角色H的界只控制曾命中，不能拿它上界各角色访问次数之和。该核仍保[原等份角色定理](../定理/递增等份捕获的角色命中与残源协方差界--定理.md)的组合合同，与把captured全部集中一角色的重分配不同。

在同一owner势/同一actual取消γ下取ρ=1−γ，若原单位边际ℓ_x=d_x−e_x且owner处e_x0，query利润D=Σ_xd_x、吸收A=Σ_Rq_xd_x、w=A/D，则

\[
 w\sum_x\ell_x-\sum_Rq_x\ell_x
 =\sum_Rq_xe_x-w\sum_xe_x
 \le\sum_{x\in R\cap a:i\ne o(x)}(\rho_x/2-w)e_x-wE_I.
\tag{RHO-COV}
\]

这是原RHO-COV的同一代数与单行到达应用；e取该owner势的原非负误差，E_I=Σ_(I∩a)e。不能换owner后保原零误差，也不能逐query另挑γ。该式仍没有共同actual钱包的误差总上界。

# 可预测激活：出口替换后须保原时间检查顺序

先为各状态预定J及接收query，允许依固定p和预定价格选择，不能观察未来激活再挑角色。全部客户共用独立Ber(p)角色位。owner未active不注入；到active状态后，无active出口则全吸收，否则跳到J中**时间索引最早**active者。到达(i,a,x)事件为只依i之前位的E_s与V_i1的交集，因为每次挑i只检查先于i的出口未激活。

置q_s(p)=P(E_s)。以dp/p积分无条件吸收，或等价条件owner已激活再以dp积分，得到

\[
 A_s(x)=\int_0^1q_s(p)(1-p)^{f_s}\,dp.
\tag{ABS}
\]

source q1，吸收1/(f+1)。nonowner E_s强迫更早owner激活，所以q_s≤p，

\[
 A_s(x)\le\int_0^1p(1-p)^f\,dp
 =\frac1{(f+1)(f+2)}=\frac1{c(c+1)}.
\tag{BETA}
\]

与[原最早激活定理](../定理/最早激活中继的可预测吸收与角色联合包络--定理.md)相同的可测性证明适用任意预定f个未来出口；不要求旧coverer身份。source归一保证总吸收ρ；同role互斥到达给单客户联合进入积分≤ρ/2。按费用重新排列“检查谁先active”会暴露角色之后位，从而不再属于此证明。若γ、owner或控制看未来位再改，不能沿用上述独立性；这是与全world自由选择的另一个域。

# 普通PRICE：最低的f个不同角色，首动作固定

定义V_i(x)为从i自由选择合法含x主题的最小后续普通费用。未来状态严格更晚，逆序计算

\[
 \boxed{V_i(x)=\min_{a\ni x}
 \frac{r_i(a)+\sum_{j\in J_f^*(i,a,x)}V_j(x)}{f_i(a,x)+1}.}
\tag{PRICE}
\]

J_f^*为i之后续价最小的f个**不同**角色，f0取空和；重复选择同一低价角色不合法。给定a，各出口等权，所以最小f项确实达到最小。对每i,x选一个argmin主题和集合，所有父来源均可使用同一规则；成本线性、无跨客户共享容量，故各客户可同时达到各自V。source只将式中a固定为T_owner，不能把首步也自由最小化后仍称保旧初始化。

V≥1由逆角色归纳：当前r≥1，各child V≥1，分子≥1+f。原自然等份路由（真future coverer及其规定主题）是允许选择之一，所以本固定T/owner的自由最小价不高于原自然等份价。它没有包含所有“captured集中到最便宜真child”的另一Bellman族；那族分配不等份。本普通控制与该族都可放入[任意未来query金融算法](任意未来查询的完整行采购价与对偶--算法.md)的更宽域，该更宽算法可集中全部余量，不能反称本PRICE已实现它的最小价。

# ACT-PRICE：有序几何权与不同最优化

固定p并条件当前已active，选择a和不同未来角色j₁<⋯<j_f。无active出口概率(1−p)^f；首active为j_l的概率p(1−p)^(l−1)。因此完整激活最优续价为

\[
 \boxed{V_i(x;p)=\min_{a,J}
 \{(1-p)^f r_i(a)+\sum_{l=1}^{f}p(1-p)^{l-1}V_{j_l}(x;p)\}.}
\tag{ACT-PRICE}
\]

权重和1、V≥1；有限逆推给下界和达到。a/J是固定p下不看未来位的选项，原时间次序不能按价格排序。PRICE的无序最便宜f项一般不替代此有序几何和。source固定首动作后，该条件费用对p∈[0,1]积分就是单位源总采购费；最优控制可依p预定，有限选择可用确定平局规则保持可测。未声称最优值仍是单个有理多项式或原审计已求其精确积分。

原程序实现PRICE及其强制source，再用**这份普通最优控制**作可预测激活的多项式积分。它没有实现ACT-PRICE的逐p最小化，也没有枚举所有角色集合、检查多角色H、测试价λ或求共同NET政策。对不同λ分开选标量最便宜控制只得到不同方案，不能拼成一个同时满足全部行的政策。
