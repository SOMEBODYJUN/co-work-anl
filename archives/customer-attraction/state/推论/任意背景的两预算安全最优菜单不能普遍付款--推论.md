# 必须固定同一完整策略的两张真实菜单

采用[共同目录完整历史模型](../定义/共同目录完整历史模型--定义.md)，保单位客户/玩家、有限非空共同目录、空/重复/零客户、所有有序历史及平局。固定合法背景b后的r≥2人子局、同一份完整纯SPE σ、其actual首主题A*和首两人最终利润α、β。强制根选a后的真实r−1尾记B₁(a)；在actual第二节点(A*)强制a后的真实r−2尾记B₂(a)。定义d₁(a)、d₂(a)为这两个真实叶中强制a的当前利润。原两节点IC分别给d₁(a)≤α、d₂(a)≤β。

原6180B稿构造

\[
 Q_1(a)=A^*+B_1(a),\qquad Q_2(a)=A^*+a+B_2(a).
\]

各恰r个合法静态竞争槽。Q₁把root查询a替成actual A*，Q₂就是second查询的完整r槽叶；均不是声称新SPE。对额外查询T设K_j(T,a)=Σ_(x∈T)1/[b_x+1+c_x(Q_j(a))]，背景不能观察T。

这里B₁(A*)就是actual根孩子，包含实际第二节点；它与B₂各行必须来自**同一σ**。不能给每个根/第二孩子任取独立最低SPE后仍称保actual两张菜单。真正离轨孩子可拼合而actual孩子受原叶承诺，准确范围见[可信包络](../资源/固定实际路径的可信门槛与全菜单包络--资源.md)。本合同不是L的逐孩子当前收益极小化。

令t=v_(r+1)(b)为r槽静态对手加一个query的真实安全值，取安全最优p（有限博弈保证存在），列a与查询T独立同分布p，

\[
 C_j(p)=\sum_{a,T}p_ap_TK_j(T,a)\ge t.
\]

每个固定a的Q_j(a)合法，安全最优查询对它至少t，再平均即可。要推首对PB，充分加强式是**存在一个安全最优p**使C₁(p)+C₂(p)≤α+β。任意低价非最优p没有2t下界；要求全部p都付款又是更强量词。该充分条件不与PB等价。

# 对角税和未付的联合差

对客户x∈a，设ℓ₁为B₁(a)负载、ℓ₂为B₂(a)负载。直接多插一个竞争行动得到

\[
 K_1(a,a)=d_1(a)-\tau_1(a),\quad
 \tau_1(a)=\sum_{x\in a\cap A^*}
 \frac1{(b_x+1+\ell_{1,x})(b_x+2+\ell_{1,x})}\ge0,
\]
\[
 K_2(a,a)=d_2(a)-\tau_2(a),\quad
 \tau_2(a)=\sum_{x\in a}
 \frac1{(b_x+1+\mathbf1_{x\in A^*}+\ell_{2,x})
 (b_x+2+\mathbf1_{x\in A^*}+\ell_{2,x})}.
\]

非空a有τ₂>0；τ₁可为0。故非空a的**两项对角和**严格低于α+β，不是说每个K₁对角都严格低于其原利润。空主题贡献0，零客户边界不作虚假严格号。

记D_j=Σ_ap_ad_j(a)、e₁=α−D₁≥0、e₂=β−D₂≥0，则恒等式

\[
 \alpha+\beta-C_1-C_2
 =e_1+e_2+(D_1-C_1)+(D_2-C_2)
\]

保两次真实IC松弛，但跨主题联合去相关差仍未被对角税支付。Q₂虽为second子局full-slot菜单，也不能调用未证weak-push；Q₁不含原root查询a，不能套旧完整根profile规则。两项不能重复领取同一尾利润。

原稿衔接[可信相邻换位](../引理/可信相邻换位与固定计数坏点正常形--引理.md)：固定(A*,a,B₂(a))整尾移到(a,A*,B₂(a))，新第二人的旧root利润须达到相应真实threshold才可补成子SPE。高门槛欠额不因重排消失；门槛给资格，不自动付联合混合差。

# 当前一般加强式已严格失败

原主稿和818B README写PB-extra/JOINT未证、保持OPEN；冻结原件原样保留，但现有[任意合法背景PB反例](../反例/任意合法背景的前两人额外槽安全值--反例.md)已给一份真实完整子SPE和合法b，使

\[
 \alpha+\beta=2u<2s\le2v_{r+1}(b)=2t.
\]

在这**同一份σ**形成上述Q₁/Q₂。对每一个安全最优p，各C_j(p)≥t，因此

\[
 \forall p\in\operatorname{Argmax}v_{r+1}(b),\quad
 C_1(p)+C_2(p)\ge2t>\alpha+\beta.
\]

所以连“存在一个安全最优p能付联合菜单”的全合法背景断言也假。这是既有PB反例的直接量词推论，不是新参数搜索、另造SPE或由两个有限点猜出的否定。它不要求计算PB反例的精确安全值，已有同一查询下界s>u就够。

该PB背景巨大且已满覆盖，原参数直接在轨迁移另有[最后D-singleton障碍](../障碍/PB大背景的最后单例偏离--障碍.md)。本推论不否只限定实际根前缀的弱化、不提供half反例，也不证明所有不同菜单机制都失败。
