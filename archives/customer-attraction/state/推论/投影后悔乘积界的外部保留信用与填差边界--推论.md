# 对象、定义域与两个已证输入

本页是Root在整理[真实后悔乘积界](../审查/全历史后悔稳定界与真实后缀退出的解析复核--审查.md)
和[客户投影精确账](../引理/客户投影的全历史后悔与共同外部信用--引理.md)时所得的直接组合。
母结果已分别证明；下面补全组合证明和一个非常简单的付款边界，
不把它称为新一般half定理、有限实验或原问题反例。
[已全文读取的版本与关系说明](../../tools/evidence/projection-product-retained-credit-integration/derivation-scope.json)
保两页SHA和完整快照。本次没有运行原程序或新数学checker，不新增冻结来源done。

固定m≥1，有限单位客户N和有限非空共同标签目录，主题允许空覆盖、同覆盖不同标签和重复选择。
固定一份**全部有序历史**纯SPE σ。原根无既有玩家背景；actual叶B、覆盖C、福利W=|C|。
任取O⊆N，假设有非负分数主题覆盖z，对每个x∈O满足Σ_(T含x)z_T≥1，
总重κ=Σ_Tz_T≥1。O不必最优，z是给定数学见证，不免费假设能求出它。
O空时亦可取任意κ≥1的主题权，以下式子仍成立。

投影游戏只保O的客户价值，**保留所有原标签与原σ整棵后继树**；它一般不是SPE。
记I=|C∩O|、E=|C\O|，则W=I+E。
actual第i位节点h_i的规定全收益为u_i，分成O内v_i和O外e_i；全部e_i之和恰E。
在h_i强制合法A后按原σ走，记外部收益e_i(A)，原完整SPE松弛
Γ_i(A)=u_i−u_i(A)≥0。定义同一投影计划的真实后悔和保留信用

\[
 \delta_i=\max_A\{v_i(A)-v_i\}\ge0,
 \qquad c_i=\min_A\{e_i(A)+\Gamma_i(A)\}\ge0.
\]

规定行动本身也在A中，故最大后悔非负，且极值因有限目录达到。
逐A有v_i(A)−v_i=e_i−e_i(A)−Γ_i(A)，因此

\[
 \delta_i+c_i=e_i,\qquad
 \sum_i\delta_i+\sum_i c_i=E.\tag{1}
\]

这是同一actual路径的精确账。不能把各层所有离轨节点的最大后悔塞进(1)，
也不能先改用另一份子SPE再沿用这些c_i或E。

# 加强的乘积下界

令r_i=m−i+1，

\[
 F_m(\kappa)=1-\prod_{r=1}^m\left(1-\frac1{r\kappa}\right),
 \qquad
 w_r(\kappa)=\prod_{s=1}^{r-1}\left(1-\frac1{s\kappa}\right).
\]

κ≥1使每个因子在[0,1]，故0≤w_r≤1，空积w₁=1。
则同一原SPE满足已证推论

\[
 \boxed{W\ge |O|F_m(\kappa)
       +\sum_i c_i
       +\sum_i[1-w_{r_i}(\kappa)]\delta_i.}\tag{2}
\]

亦可把额外非负信用写为

\[
 \mathcal C_\kappa(\sigma,O)
 =E-\sum_i w_{r_i}\delta_i
 =\sum_i\{(1-w_{r_i})e_i+w_{r_i}c_i\},\qquad
 0\le\mathcal C_\kappa\le E.\tag{3}
\]

(3)是对**同一笔**E的精确拆分，不能将c_i、δ_i或E另各全额注入别的付款池。

证明先把鲁棒乘积定理用在投影后的完整计划：它虽非SPE，定理允许任意完整计划，
其actual后悔恰δ_i，故

\[
 I\ge |O|F_m(\kappa)-\sum_iw_{r_i}\delta_i.
\]

加E再代(1)，立即得(2)(3)。为说明这里没有隐藏SPE假设，也可直接重构母递推。
在投影游戏的actual第i位，令b_i(x)为过去覆盖人数，

\[
 g_i(T)=\sum_{x\in T\cap O}\frac1{b_i(x)+r_i}.
\]

真实强制T后客户最终覆盖者不超过b_i+r_i，所以v_i+δ_i≥g_i(T)。
逐客户用分数覆盖和过去actual主题得

\[
 |O|\le\sum_{j<i}g_i(B_j)+r_i\sum_Tz_Tg_i(T)
 \le P_{i-1}+r_i\kappa(v_i+\delta_i),
 \quad P_i=\sum_{j\le i}v_j.
\]

过去玩家在同一actual叶分母至多b_i+r_i，故第二不等式的过去部分确≤P_(i−1)。
于是P_i≥(1−1/(r_iκ))P_(i−1)+|O|/(r_iκ)−δ_i。
从P₀=0迭代；后续传播乘子恰w_(r_i)，最后P_m=I，完成全部证明。
O空时v/δ均0、Σc=E=W，式(2)只是W≥W；O=N时E/c/δ均0，退回普通乘积下界。
零客户、空主题和平局不需额外排除。

# 不能把纯外部填差继续列作普遍待证条件

若O为最优m主题并集，可用这m个主题（含重复）给分数覆盖κ=m。
对某个具体σ和O，

\[
 \mathcal C_m(\sigma,O)
 \ge[1/2-F_m(m)]\operatorname{OPT}_m\tag{4}
\]

当然是由(2)推出half的一个**充分数值证**。它不是half的必要条件，
也不是仅靠原SPE性质就总会成立的开放候选。

直接看当前六人模型中六个客户、目录为六个不交单例主题A_j={j}。
完整策略在每个历史都选一个过去未选的主题，例按最小标签破平局。
任意t<6步历史至多覆盖t个客户，余6−t人至少有同数未用主题。
规定选新主题后，所有后继继续选新主题，当前得1；改为过去已用主题后后继仍选新主题，
当前至多1/2；改另一未用主题也得1。因此这是一份覆盖全部离轨历史的纯SPE。
根W=OPT₆=6，最优客户并集唯一为O=N；它完全满足half。

每客户只在其单例主题中，任何分数覆盖都要求每个z_j≥1，故κ≥6。
对O=N，\(E=\delta_i=c_i=\mathcal C_\kappa=0\)。
而对所有κ≥6，非负因子的乘积给

\[
 F_6(\kappa)\le\sum_{r=1}^6\frac1{r\kappa}
 \le H_6/6=49/120<1/2.
\]

所以(4)在此例严格失败，即使可任取最优O和最省的分数覆盖也失败。
这**只反驳“单靠这笔外部信用必须填足乘积界到half之差”**的普遍要求；
不是六人half反例，也不反式(2)。例子显示母乘积下界在没有外部客户时仍可很松，
不能把所有松弛都归因于可由E退款支付的损失。

# 接续用途与关系

式(2)保留了粗做Σδ≤E时被丢掉的两种贡献：精确c_i，以及早期后悔经后续乘子折扣后剩余的预算。
它可用于具体投影和具体分数覆盖的核算；对κ足够小或另有内部覆盖信息时也可能直接有用。
但统一half还需要其它真实结构或更紧的覆盖推导，不能把已由六单例反掉的普遍(4)留作未证明目标。
