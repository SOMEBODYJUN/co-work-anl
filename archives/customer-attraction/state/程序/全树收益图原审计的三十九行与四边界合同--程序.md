# 完整五源、实际模型和一般表示

README1221B、原audit9064B、母稿7815B、首报告12950B、v2报告13428B共44478B，均本次真实normal取得、全文读及核size/SHA256/Git blob。两个报告的全部25/26顶层字段、13行动、39×7系数、39slack、15分量、10商弧、两循环和四边界全部读，不以计数/状态代替原数学。无外部运行输入缺件：脚本硬编码完整数据，**不读任何JSON/模型/证明文件**。原件见[证据](../../tools/evidence/outcome-payoff-graph-five-primary/README.md)。

取m,p≥1，有限单位客户/单位提供者/非空共同标签目录，全部有序历史完整纯策略σ，允许空主题、同覆盖标签、重复动作、零客户和任意平局。收益型F_(q,a)(D)=1_(a∈D)/q(D)，分子零时取0；q_a>0使正分子分母正。σ可先是形式策略，不预设在某个w上可实现。每条Γ是规定完成收益型减强制当前行动后**沿同一σ真实完成**的收益型，不是静态冻结偏离。

原母稿§1–3与现正式[SCC商定理](../定理/真实收益比较图的强连通商与非负流编译--定理.md)同域：全顶点数V=p·binom(m+p−2,p−1)，每顶点都在某末前缀强制行动中出现；相同端点的真实行可合并保一个实现见证。记抽象边界e_v−e_u的锥为K_D、L:e_v↦F_v，则真实行锥精确为L(K_D)。SCC内部两向路径给任意符号的H_SCC，选每分量代表ρ后
\[
\operatorname{cone}(\Gamma)=H_{\rm SCC}+
\operatorname{cone}\{F_{\rho(D)}-F_{\rho(C)}:C\to D\}. \tag{1}
\]
逐边用代表差加两个内部差得一向包含；反向把代表到源、见证跨边、目标到代表三段真实路径相加。故SPE客户锥等价于w≥0、H_SCC·w0和全部代表跨边差·w≥0，原全部离轨最优性未删。SCC给的是已知可逆子空间，L可增加lineality，商DAG不保证像锥pointed；原README也明确此限制，后续[映射零流引理](../引理/收益型映射核与真实行锥的完整双向空间--引理.md)已准确刻画额外方向。

对目标d，原非负行/客户余项证书d=Γᵀλ+r、λ,r≥0，等价于d=Σ_(C→D)μ_CD(FρD−FρC)+z+r，μ,r≥0、z∈H_SCC；正/负内部差按两向路径编译，不须固定旧早期乘子。一般half取根覆盖c、任意至多m主题比较覆盖o和d=2c−o；(1)只换表示，没有构造所有σ/比较所需的μ,z,r。

原母稿还完整给单位整数与实数锥的对应：固定有限σ/o时Γ和d均有理。若实w≥0、Γw≥0有d·w<0，以**正**倍数放大可使d·w≤−1；该非空有理多面体有有理点，清分母得整数重数上的同一严格坏例，编码互异单位客户且每个原SPE弱比较仍保。反向整数也是实数。有限维Farkas于是把“该固定锥上普遍非负”与非负行+逐型非负余项证书等价；不由此宣称目标证书已存在。空兴趣客户贡献0可省，零客户用不等式而非效率比。m1的图为根所选收益顶点的偏离星，p1任意m只有一个收益顶点和零行，全部表示/证书等价仍成立；一般边界由解析证明，四个程序案例不承担全域穷尽。

# 9064B实现的实际流程

仅标准库argparse/json/defaultdict/deque/Fraction/product/comb/Path，无规范game solver、LP、科学包、作者helper、随机源或外部数据。五个模块函数vector_add/vector_sub/rank/analyse_strategy/main和五个analyse内部函数terminal/vertex/payoff/reach/path全文读；本轮0import/CLI/main/函数调用/原数学核、新checker和LP。

analyse_strategy(p,n,sigma)按深度生成全部有序history，assert键集全。terminal沿每个新有序历史的σ走到n；vertex(h,a)在h强制a后完成，返回计数与当前a。payoff直接遍历全部非空mask1…2^p−1，用Fraction给型向量；有分子时占用分母正。代码不把同计数历史的行动绑同，也不以某w正支持删型。

每h/每a形成真实u→v，在邻接set合并端点边（保self），witness.setdefault只记该边第一个真实(h,a)；rows/endpoints仍按全历史键保全部行。图顶点全出现的证明来自末层强制任意a，不来自随机抽样。可达集为每顶点自写DFS，按remaining最小顶点取相互可达组，分量内排序、代表取最小者；没有图包或特定实例SCC列表输入。

path用排序邻接BFS并保前驱，再把路径每弧映到其真实历史见证。对每分量全部有序(u,v)（含u=v空路径）逐路径相加Γ，assert等于Fv−Fu；internal_rows则为每u的Fu−F代表（含代表零向量）。本例26次路径核不是26条SCC生成行、26个非零环或26份策略。它不将选出的完整路径及乘子写入报告，只留合计与两条指定循环行定位。

对每条不同端点边（含loop）assert“代表跨差+目标内部差−源内部差=原行”，收不同分量ID弧。再从商图每分量显式reach，assert不会回起点来核DAG；不是只信某SCC包的返回顺序。母稿一般锥等式和lin(K_D)的证明是解析：拓扑势对每跨弧严格增加，抽象双向锥表示不能含跨弧正系数；此处有限path/恒等式/DAG只是实现的定义级审计，不负责证明所有参数。

terminal_ties双重遍历全部长度n−1有序前缀，只在排序相同且规定动作不同才收rows[h,σg]；当前仅BC/CB两互反行。rank以Fraction行作Gaussian消元，每次首非零pivot归一并消其它行，当前输入均为Fraction故确是精确有理秩；vector_add/sub的普通zip不验证任意外来向量长度，实际源码生成同维坐标。analyse只检查σ键集，没有完整参数/动作schema诊断；数学域n,p≥1和动作合法，非法外部调用可能越界或缺终局键失败。
