# 三重早期覆盖的原作者系数生成器与十字段报告

本对象对应源`5bac2c33a9112ba907b7`的1926B原作者程序及源`85961fbb929b166658cb`的1847B原作者报告。它补足原作者入口的执行合同、完整十字段输出与本轮实际重放；[父方含交集审计器](三重早期覆盖的含交集系数审计器--程序.md)是另一份3409B原实现，[完整残差有限表](../计算/三重早期覆盖的完整残差有限表--计算.md)已经保存全64项表及五端点解析重建，不把这三种身份混为一次独立证明。

## 数学对象与完整历史量词

采用[共同目录完整历史模型](../定义/共同目录完整历史模型--定义.md)。客户有限、每个客户价值一；六名单位权提供者面对有限非空共同目录，依次观察全部有序行动，各选一个主题。固定任意一份定义于所有合法有序历史的纯SPE，实际叶为$(E_1,E_2,E_3,E_4,A,B)$。实际收益$u_i$按客户在最终覆盖者间均分，$W=\sum_i u_i$为覆盖数。空主题、重复选择、零客户和任意离轨历史平局均保留。

本证书的正面条件是

\[
\mathrm{P3}:\quad\forall x\in A,\qquad
p_x:=\sum_{i=1}^4\mathbf1_{E_i}(x)\ge3.
\]

它是对每名$A$客户的量词，未要求某三个固定早期主题分别包含整个$A$。P3下结论为$2W\ge\operatorname{OPT}_6$；无P3时只能保留下文有符号残差界，不能由本程序宣称一般六人half。

任取六个合法比较主题$T_i$，允许重复，令$O=|\bigcup_iT_i|$。$R_i$为同一原完整策略在实际前四步后强制第五人选择$T_i$所得的真实末位回复。设

\[
U_p(X,Y)=\sum_{x\in X}\frac1{p_x+1+\mathbf1_Y(x)}.
\]

实际倒二偏离、实际末位查询、各强制分支末位互查分别给

\[
\begin{aligned}
S&=\sum_i[u_5-U_p(T_i,R_i)]\ge0,\\
Z&=\sum_i[u_6-U_p(R_i,A)]\ge0,\\
V&=\sum_{i\ne j}[U_p(R_i,T_i)-U_p(R_j,T_i)]\ge0,\\
G&=S+Z/12+V/6\ge0.
\end{aligned}
\]

共同目录保证所有$R_j$在查询节点合法。$V$含30个有序索引对，强制选择$T_i$的第五人未被当成该分支最优者；全部续局沿同一原策略，不冻结实际后继。单客户原始三行含同索引交集$h=\sum_i\mathbf1_{T_i}\mathbf1_{R_i}$，系数为

\[
S_x=6a/c-d/(p+1)+h/D,\quad
Z_x=6b/c-\ell/(p+a+1),\quad
V_x=(d\ell-6h)/D,
\]

其中$D=(p+1)(p+2)$。因此$G$中的$h$精确抵消；这不假设比较会员与回复会员独立。三行合法性及全参数消交集另见[真实末两人菜单交集消去](../引理/真实末两人菜单交集消去--引理.md)。

早期位置$i=1,\ldots,4$在原实际节点改选$A$后，记旧负载$q_i(x)=\sum_{j<i}\mathbf1_{E_j}(x)$，该客户的最终总负载至多$q_i+7-i$，故

\[
H_i=u_i-\sum_{x\in A}\frac1{q_i(x)+7-i}\ge0.
\]

这是真实IC加安全下界，没有将后继改成静态在轨叶。实际末位改$A$另给$L=u_6-U_p(A,A)\ge0$。以上全部行在无P3时已经成立，P3只用于局部余项符号。

## 原程序逐式实现的系数与域

对每名客户记有序实际会员位$(e_1,e_2,e_3,e_4,a,b)\in\{0,1\}^6$，$p=\sum_i e_i$，$c=p+a+b$，$w=\mathbf1_{c>0}$。比较重数$d=\sum_i\mathbf1_{T_i}$、回复重数$\ell=\sum_i\mathbf1_{R_i}$、$o=\mathbf1_{d>0}$。原函数`share(v,c)`在$v=0$时返回精确零，因此$c=0$的全零实际会员型仍合法；其它分母也始终为正。

`coefficients(es,a,b,d,ell)`不读取博弈，直接返回

\[
\begin{aligned}
G_x&=6a/c+b/(2c)-d/(p+1)
-\ell/[12(p+a+1)]+d\ell/[6(p+1)(p+2)],\\
H_{i,x}&=e_i/c-a/(q_i+7-i),\qquad
L_x=b/c-a/(p+a+1),\\
Q&=2w-o-G_x-\sum_i\lambda_iH_{i,x}-\mu L_x,\\
\lambda&=(1/3,1/2,1/2,2/3),\qquad\mu=3/2.
\end{aligned}
\]

零分子份额同上。代码早期下标从0起，其`sum(es[:i])+6-i`正是数学下标从1起的$q_i+7-i$。$a=1$时$p+a+1=p+2$，末位查$A$的分母正确。

`main()`枚举全部64个实际六位型及独立的$d,\ell\in\{0,\ldots,6\}$，共$64\cdot49=3136$个精确`Fraction`值。它另把$a=0$或$p\ge3$的值放入受限数组，该域有

\[
\bigl(16+\tbinom43+\tbinom44\bigr)\cdot2\cdot49=2058
\]

个投影类型。此程序没有枚举$h$；父方含交集程序保3528个受限含$h$型，其角色是另行核对原始三行抵消。2058不是游戏数、SPE数、客户数或目录数限制，也不要求所有形式型能共同来自某份新SPE。

原程序显式断言的常数是受限数2058、受限最小值0及受限负值数0。由每个真实客户都属于被检查域，结合上面的真实行与恒等式

\[
2W-O=G+\sum_i\lambda_iH_i+\mu L+\sum_xQ_x
\]

可对任意非负整数客户重数求和；P3下每个$Q_x\ge0$。比较元组任意，取最优六元组得到half，零客户也成立。这一步是完整系数域证明的全称提升，程序独自不验证输入策略是否为SPE，也没有从某个松弛点构造SPE。

## 原报告的全部十个顶层字段

所有有理数均按`Fraction`最简字符串写出；计数为JSON整数。原报告仅有以下十个字段：

| 字段 | 冻结值 | 准确合同 |
|---|---|---|
| `status` | `exact local coefficient verification only` | 字面范围声明；不表示一般六人主问题已解。 |
| `lambda` | `['1/3','1/2','1/2','2/3']` | 四个真实早期位置的非负权，按实际顺序排列。 |
| `mu` | `'3/2'` | 实际末位改$A$的非负权。 |
| `complete_restricted_state_count` | 2058 | 上述P3投影域的完整枚举规模。 |
| `restricted_minimum` | `'0'` | 仅受限2058个$Q$的最小值。 |
| `restricted_negative_count` | 0 | 受限2058个$Q$的负数个数。 |
| `unrestricted_state_count` | 3136 | 全64实际位型乘49种$d,\ell$。 |
| `unrestricted_minimum` | `'-1079/360'` | 全3136个$Q$的最小值。 |
| `unrestricted_negative_count` | 273 | 全3136个局部$Q$中为负的个数；不是负$\rho$实际位型数。 |
| `rho_actual_membership` | 全64键有理字符串字典 | 键为$e_1e_2e_3e_4ab$；每键取49个$Q$之最小，保留实际顺序。 |

令$\rho(e,a,b)=\min_{0\le d,\ell\le6}Q(e,a,b,d,\ell)$，无P3时仍有

\[
2W-\operatorname{OPT}_6\ge\sum_x\rho(e(x),a(x),b(x)).
\]

这里是下界，不把最坏化后的$\rho$与实际$Q_x$混写成恒等式。[完整残差有限表](../计算/三重早期覆盖的完整残差有限表--计算.md#完整64项rho表)已给全部64项可查表及五端点重建；原作者JSON同表完整保留。64个$\rho$有22负、2零、40正；**273个负$Q$不等于22个负$\rho$**，因为前者逐$(e,a,b,d,\ell)$计数，后者每个实际位型只算一次。受限最小0与全域最小$-1079/360$也并不矛盾。

对$a=1$再按早负载$p=0,\ldots,4$取最坏，$360\rho$下界依次为$(-1079,-299,-93,2,42)$。因此若$n_k$是$A$内早负载恰$k$的客户数，

\[
2n_3+42n_4\ge1079n_0+299n_1+93n_2
\]

亦为half充分条件；该预算没有被证明对每份SPE自动成立。负形式余项不构成P2或一般六人half的原模型反例。本生成器不读取或认证另两份探索脚本的浮点LP不可行性，未提供Farkas证书。

本轮[重放包装器](../../tools/evidence/threefold-early-author-generator/replay_original.py)实际执行原1926B入口，未导入其函数或改写数学代码。包装器拒绝自身优化模式，子进程移除`PYTHONOPTIMIZE`，以未优化Python 3.12.14运行，保护原`assert`。原入口退出码0、stderr0字节、stdout356字节，[旁写报告](../../tools/evidence/threefold-early-author-generator/threefold_penultimate_exact.json)1847字节。全部十字段及输出字节与冻结作者JSON完全相同；本轮还将输出与Boss按源ID重新导出的1847B报告直接比较，仍逐字节相同。

## 独有去向、关系与接续

本源独有内容是原作者生成函数、无输入且旁写文件的执行行为、全部十字段合同，以及与原作者报告逐字节一致的真实入口重放。父方含$h$独立实现、完整64表和五端点重建的已有正文继续承担各自证据层级，不重复伪造新的数学发现。
