# 三种量和Jensen余项的精确实现

在actual位置i，代码为每个标签a重新完成原策略，再删该i槽得到B_i(a)。对每名单位客户逐一算
\[
 \rho_x=\sum_{a\ni x}p_a,\quad
 c_a=c_x(B_i(a)),\quad\mu=\sum_ap_ac_a.
\]
三个金额分别为
\[
 D_i=\sum_ap_a u_i(y_i(a)),\quad
 C_i=\sum_x\rho_x\sum_a\frac{p_a}{1+c_a},\quad
 F_i=\sum_x\frac{\rho_x}{1+\mu}.
\]
代码没有把平均倒数和均值倒数混成同一数；Jensen信用直接按原余项累计
\[
 J_i=\sum_x\rho_x\sum_a
 \frac{p_a(c_a-\mu)^2}{(1+c_a)(1+\mu)^2}.
\]
逐角色断C_i−F_i=J_i、e_i=u_i−D_i≥0及u_i−F_i=e_i+(D_i−C_i)+J_i。所有均值负载在0…2、Jensen分母在1…3，由两个单位竞争槽的模型得，不是切换到额外第三槽。

Ftotal由三行F字符串重新转Fraction求和，断Ftotal−W=199/60。没有计算δ/free背景最优查询或求解混合安全值。
