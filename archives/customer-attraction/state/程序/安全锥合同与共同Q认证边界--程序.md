# 安全锥合同与共同 Q 认证边界

## 精确逐人失败证书

五人、10标签、29类兴趣类型展开为86个单位客户。策略在全部 \(1+10+100+1000+10000=11111\) 个非终端有序历史上定义动作；加上 \(10^5=100000\) 个终端历史，完整树共有 111111 个节点。精确重放共比较 111110 项，其中 11111 项是选择自身动作的平凡比较；其余 99999 项偏离比较中，74562 项严格、25437 项取等。路径 (4,5,6,7,8) 的收益为
\[
(81/5,86/5,86/5,86/5,86/5),\quad W=85,\quad OPT_5=86.
\]
静态 oblivious security value 为 v_5=2262/139，首位差
\[
v_5-u_1=51/695>0,
\]
所以逐人 u_i≥v_n 桥失败。但
\[
W-5v_5=505/139>0,\qquad 2W-OPT_5=84>0,
\]
故不是 aggregate 或 half 反例。给定的 exact primal 与 dual 分布只认证这个固定证书的个体桥失败。

## 固定策略锥和共同 Q

21个固定策略锥的非负客户权重满足各自 IC 后，可推出该固定策略的 W≥n v_n；另有三个固定锥的 aggregate 桥。三人六标签固定分组策略存在共同 Q=(1/3,1/3,1/3) 型精确证书，适用于该策略的43历史 IC 锥。以上都量化在指定策略，不是任意完整策略。

合法背景随机探针只生成静态矩阵并求浮点 LP；若未独立检查概率向量合法性、完整策略树和全部 IC，不能称为模型反例。六个命名 common-Q JSON 虽报告 success=true，但缺少策略、客户权重、精确乘子、残差和来源绑定，只是有限诊断。

因此合同映射是：逐人失败为精确完整 SPE；固定策略锥为策略受限保证；随机聚合候选为条件静态下界；浮点 common-Q 为未认证诊断。逐人失败不否定聚合桥，21锥不覆盖所有策略，六人 half 仍无普遍证明。
