# 真实偏离与强均匀目标

采用[共同目录完整历史模型](../定义/共同目录完整历史模型--定义.md)。$m\ge1$ 名单位提供者依次观察完整有序历史，每人从同一份 $p\ge1$ 个可区分标签的目录选一题，有限单位客户的价值由终局覆盖者均分。允许空主题、重复、同覆盖异标签、零客户、离轨历史及任意平局。固定完整纯策略 $\sigma$，令实际路径为 $s$，实际覆盖为 $W$。在实际前缀 $s_{<i}$ 强制第 $i$ 位选择标签 $a$，再沿同一 $\sigma$ 执行改变后的历史，记该位终局收益为 $V_{i,a}$，置 $A_a=\sum_i V_{i,a}$。

对任意恰 $m$ 槽比较多重集 $T$，令 $O(T)$ 为其主题并集覆盖。两份程序都寻找[真实前缀均匀组合强接口](../候选/真实前缀均匀组合接口--候选.md)的正违例

\[
F(T)=mO(T)-(m-1)W-\sum_{a\in T} A_a. \tag{1}
\]

和式计入每个槽，覆盖只看支持。这个目标比较的是各角色在其原实际前缀的真实后继，既没有冻结实际后缀，也没有累计强制多个比较槽。若对所有 $\sigma$ 所定义的完整纯SPE及所有比较多重集都能证明 $F\le0$，则对最优多重集用 $V_{i,a}\le u_i$ 与 $\sum_i u_i=W$ 可得 $\operatorname{OPT}_m\le(2-1/m)W$。弱平均接口的违例多扣一份 $W$，即 $F-W$。强目标的正点只直接否定相应强接口，若要判断半覆盖还须核 $2W<\operatorname{OPT}_m$。

# 固定策略锥浮点入口

`uniform_portfolio_cone.py` 先选一个完整动作图，再放开全部非空兴趣类型 $B\subseteq[p]$ 的重数 $x_B\ge0$。全无兴趣的客户对各收益及覆盖贡献零。对任一终局计数 $q$，定义类型 $B$ 的主题 $a$ 收益系数 $f_{a,B}(q)=\mathbf1_{a\in B}/\max(1,\sum_{b\in B}q_b)$。其中调用者传入的 $q$ 含当前动作 $a$，所以分子为一时分母本就为正。

`cone_data` 从根递归遍历每个有序历史及其所有孩子，并保存强制每个动作后的真实终局。对每个 $h$ 及非自身备选 $a$ 写一行

\[
G_{h,a;B}=f_{\sigma(h),B}\bigl(q_\sigma(h)\bigr)-f_{a,B}\bigl(q_\sigma(ha)\bigr),
\]

其中 $q_\sigma(h)$ 是从 $h$ 按 $\sigma$ 完成的终局计数。收益缓存以终局计数和当前动作作键，动作策略仍以有序历史作键。行未去重，共 $(p-1)\sum_{d=0}^{m-1}p^d$ 条。$W$ 的列按实际终局覆盖取0或1，$A_a$ 的列通过实际路径每个位置和相应强制孩子求和。此构造正是[固定完整策略的客户重数锥](../定理/固定完整策略的客户重数锥--定理.md)的浮点实现。

对测试的每个 $T$，SciPy HiGHS 求 $\max F(T)$，约束为 $x\ge0$、$Gx\ge0$、$W=1$。规范化按实际覆盖，既不是总客户数也不是最优覆盖。任一非零有效锥点都有 $W>0$，并有 $\sum_B x_B\le mpW$，因为实际末位改选任意标签都能取得该标签客户质量的至少 $1/m$。全兴趣类型一单位构造非空截面。归一化排除的是有效质量全零的平凡目标点。正浮点值超过 $10^{-7}$ 才写候选 JSON 并终止，记录轮次、规模、比较组合、实际路径、浮点违例值、严格大于 $10^{-10}$ 的坐标及原动作证书。LP失败即抛错。该分支只保存浮点点及动作图，未恢复有理重数、核新点的逐历史精确IC或验证精确正目标，删微小坐标也可能改变这些量。无正浮点报告没有精确对偶上界。

默认100轮，首位置参数可改次数。种子374957，对 $(p,m)$ 从 $(4,3),(4,4),(5,3),(5,4),(5,5)$ 中选择，每个非空兴趣类型独立从 `[0,0,0,0,1,2,3]` 抽整数重数。若最低SPE福利为零则跳过。其余只从最坏根终局计数中取字典序最小者，并调用规范 `certificate` 得一份完整策略。规范构造在可实现指定终局的当前行动中默认取首个，非实际孩子则取使当前偏离者收益最低的可信终局中的字典序首个。策略固定后，锥点的客户重数可以与种子完全不同，原路径不必仍是新实例的最低SPE福利路径。全程无动作图去重，也不枚举全部最坏路径或离轨平局。

原比较循环为 `combinations(range(p), min(p,m))`，所有实际采样规模均 $p\ge m$，因此只测恰 $m$ 个不同标签。源码另有 $p<m$ 的补位分支，固定把缺少的槽全部给最小索引标签。两者均不足以覆盖带重复的通用式(1)。依[支持端点归约](../引理/真实查询均匀接口的支持端点归约--引理.md)，固定非空支持 $S$ 后，最坏补法把剩余 $m-|S|$ 槽全给 $S$ 中 $A_a$ 最小者。若同时优化客户重数，该最小者可随重数改变，故应枚举每个合法支持的所有端点。仅因重复不改变覆盖而删掉查询槽，会改变(1)。

以下精确控制例直接显示补位差异。三人、两道不交主题，标签0覆盖六名客户，标签1覆盖一名。令全历史策略总选0。规定动作收益至少 $6/3=2$，偏离到1收益至多1，故全部历史为SPE。实际 $W=6$，$A_0=6,A_1=3$，同一支持覆盖7。固定补0给 $F(0,1,0)=-6$，补1给 $F(0,1,1)=-3$，后一值还是全部四个多重集的最大值。这个比较证明两种补法的目标不同，两个值均为负。

# 固定策略的精确多重集入口

`uniform_portfolio_search.py` 的 `attack(instance, cert)` 读取同一完整动作表，直接沿指定有序分支走到叶，并用规范 `Fraction` 收益计算每个 $V_{i,a}$。它先按标签保存全部角色的 `deviation_values` 及其和 `deviation_costs`，再通过 `combinations_with_replacement(range(p),m)` 枚举全部 $\binom{p+m-1}{m}$ 个比较多重集。比较次序对(1)无影响，最大值相同就保枚举首个元组。返回 `gap` 为精确 $\max_TF(T)$，`query` 为相应元组，`actual` 与 `welfare` 为实际路径及其覆盖。返回字段 `optimum` 保存的是该元组的 $O(T)$，一般不等于真正的 $\operatorname{OPT}_m$。`attack` 自身不验证证书，调用处负责合法性。

默认入口以文件名连接冻结 `examples/customer_attraction/*.json` 和 `evidence/certificates/customer_attraction/` 同名文件。缺同名文件或证书没有**顶层** `actions` 就跳过。通过后构造 `Instance` 及 `StrategyCertificate`，先用规范核验器检查每个有序历史，再做精确扫描。外壳中另有完整 `strategy` 的 JSON 仍可被默认入口跳过，因此不能由输出总数反推冻结仓库的完整策略总数。

可选 `--random` 在默认处理之后执行。种子22291，1000轮各从 $\{3,4,5\}$ 独立选 $p,m$，再按与锥入口相同的重数列表采样。对每个最坏根终局计数生成一份规范完整策略，扫描全部比较多重集，首个严格正 `Fraction` 值出现时再核该证书并打印实例、策略和结果。即使穷尽所采种子中的最坏终局计数，也仍只抽取每个计数的一份策略，且不查非最坏终局策略。随机阴性不输出逐锥/逐证书计数、精确最优余量或最终摘要，只每50轮报告进度。

# 本轮重放与关系

两份主源在两个冻结提交中的字节分别一致。原脚本、共享规范依赖与冻结输入清单、复现方法、三次运行日志和独立复算见[证据包](../../tools/evidence/uniform-portfolio-legacy/README.md)。

- 浮点原入口默认100轮完成，最后为 `finished 100 best -0.0`，未生成候选文件。该浮点记录只涉及被抽到的动作图与不同标签组合。日志不提供每个锥的精确最优证书。
- 精确原默认入口在19对冻结同名文件中使用9份顶层完整证书。另10对因缺顶层 `actions` 跳过。9份的最大 `gap` 是 `collision_free_occupancy` 的 $-2$，全部严格为负。独立逐客户 `Fraction` 程序逐一复算465个有序决策历史、1987个非自身偏离及1996个有序比较元组，核对原311个比较多重集的最优输出，也核对 `cone_data` 在这些动作图上生成的真实IC和目标列。`portfolio_matching_failure` 的 `optimum` 字段为44，实际全局覆盖最优为45；`residual_counterexample` 对应9与10。
- 精确原随机入口完成1000轮且未输出 `FOUND`。它重复默认9份证书输出，其后最后打印 `random 950`，符合源码每50轮打印且无结束摘要的约定。运行退出码为0，未出现正点验收事件。独立审计只重算默认9份与上述补位控制例，未逐一复验这1000轮所生成的全部动作图。

既有[强接口完整策略锥搜索](../资源/均匀真实组合强接口的完整策略锥搜索合同--资源.md)同样优化(1)并按 $W=1$ 归一，但枚举全部重复多重集、抽取不同可信子续局，并对正点另设有理恢复及两套全历史核验。因此不能用它的验收步骤或80／162锥记录替代此处 R-c9208 的运行。[固定输入强组合攻击](均匀强组合攻击的输入与整数验收边界--程序.md)与本浮点源共享不同标签支持的遗漏，前者以指定证书输入且有另外的整数恢复分支。[既有17份精确探针](<../../../../tools/evidence/phase25-material-attachments/20261103-boss6-triage/ab6c9ae4611b97c2c7c7.md>)改用支持端点且筛入不同证书范围。两处共同样本的 `coverage_opportunity_failure` 与 `worst_pne_welfare_failure` 分别给余量 $17/3$、$137/6$，和本轮 `gap` 相差一个符号，不能把17和9累加成独立证书覆盖。

[两名剩余玩家跨分支恒等式](../定理/两名剩余玩家跨分支平均偏离恒等式--定理.md)在零背景、两比较槽时解析证明式(1)的非正性。它的任意背景版本约束剩余利润，不能据此忽略更多玩家的真实后继。[背景归纳尾部余量障碍](../障碍/均匀组合背景归纳的尾部余量--障碍.md)反驳的是直接舍去尾余量的归纳步骤，根强接口在其完整SPE族恰取等。[八客户均匀排列失败](../反例/均匀最优主题排列预算的八客户失败--反例.md)计算冻结后缀的查询，[最优前缀插入账](../资源/净遗漏预算与最优前缀付款的历史接口--资源.md)使用累加强制前缀，两者都与式(1)的真实单步查询不同。第三阶段可分别记录公式实现、完整锥理论、端点补全、有限验证及量词比较关系。一般强接口及六人半覆盖的全称结论没有由这些重放确立。
