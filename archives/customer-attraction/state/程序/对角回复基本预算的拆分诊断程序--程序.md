# 实际职责：对一个混合点找拆分后的负预算

主源 `ae3a69e8e041bfd1b8f5` 的[3061B原程序](../../tools/evidence/diagonal-basic-author-check/original/diagonal_basic_check.py)已由 `clean show` 全文取得，SHA-256为 `fd76a39897e3ae1c9ec5abaf6dcea117eeb23fb10b42307710cdae71774af9e2`，两冻结提交同字节。程序只计算C族16类R基础行和12类Z基础行分别对30个异索引、6个同索引相加的56个有理余量，并列出其中严格负者。

它没有构造3949行、求解LP、寻找新的点或验证完整SPE。输出中的“fixed exact 3949-point”是输入的历史身份。真实代入的是旧3889图点的K、历史质量、R边缘，加同目录阈值文件给出的新Z及RZ边缘；旧点中原有Z质量和RZ交叠被舍弃。不能将结果称为“旧3889点原样的五条负行”，也不能移给后来3945行拆分图的新点。

本轮在隔离目录唯一执行原入口一次，得到与原README列出的五类负行一致的精确结果。再按逐客户真实收益、四状态质量独立计算当前点的全部56行，负行和最小值与原输出逐字相同。28条同名合行全部非负；五条负行各与另一索引部分恰好抵消。这是保存对角变量却只约束合行会遗漏预算的具体例证。

# 原必要条件的模型和量词

采用[共同目录完整历史模型](../定义/共同目录完整历史模型--定义.md)：有限单位客户，有限非空共同主题目录，六名单位权提供者依次观察完整有序历史选主题；每个客户在最终覆盖它的提供者之间均分价值。目录允许空主题，不同人允许重复选题；零客户情况和任意离轨平局均保留。六人目标量化所有这种输入以及每一份完整历史纯SPE，而不是只找一份续局。

固定任意完整纯SPE \(\sigma\)、实际路径 \(A_1,\ldots,A_6\)，以及六个合法比较主题 \(T_1,\ldots,T_6\)。若用于归一化最优覆盖，再取这些T为一个最优六主题元组。令 \(h=(A_1,A_2,A_3)\)；强制第四位选 \(T_i\) 后，按同一 \(\sigma\) 的真实第五、六主题为 \(B_i,C_i\)。被诊断的C族为

\[
R_{ij}=\sigma_6(h,T_i,C_j),\qquad
Z_{ij}=\sigma_6(A_1,A_2,A_3,A_4,R_{ij}),\quad 1\le i,j\le6.
\]

R、Z都是真末位回复，可以在各自历史查询目录中任意合法主题。强制第五位选C或R的收益只能由偏离前的第五位IC约束；不能把强制者也当作该节点的最佳回复。B族 \(R_{0,i,j}=\sigma_6(h,T_i,B_j)\) 仅取 \(i\ne j\)，是输入中仍存在的另一族；本诊断不输出它的预算。

因为每条真实索引边的偏离、末位查询和容量本来分别成立，将它们分别对 \(i=j\) 和 \(i\ne j\) 求和仍是必要条件。这里同索引是标签索引相同，不是会员词或主题覆盖相同；两个不同索引的词相同仍留在异索引部分。此论证也不要求策略仅依赖计数。满足有限行的有理测度，即使能共同实现所有会员位，仍没有给出 \(\sigma\) 在所有有序历史的行动和IC。

令某hist质量为 \(H\)，其各回复轨道的R边缘为 \(r_g\)。生成器对所有 \(0,r_g,H\) 排序切成非空区间 \([l,u]\)，在每段上固定

\[
R_g=\mathbf1\{u\le r_g\},\qquad 0\le y_{[l,u],g}\le u-l.
\]

阈值变量weight就是该段内Z的质量。故程序应聚合

\[
z_g=\sum_s y_{s,g},\qquad v_g=\sum_s R_g(s)y_{s,g},
\]

其中 \(v_g\) 是RZ交叠质量。新的四状态质量为

\[
(m_{00},m_{01},m_{10},m_{11})=(H-r_g-z_g+v_g,\ z_g-v_g,\ r_g-v_g,\ v_g).
\]

本轮逐条核全部321变量描述符与阈值规则完全一致：10个正历史共25段；B族130个变量、C族191个。187变量为0，117达上界，17严格在界内，所以134个正变量和17个内部变量与作者元数据相符；这核的是当前保存值的位置，不重演浮点顶点恢复。所有变量上下界及全部194组新四状态质量均非负。相对旧点，56组Z边缘、29组RZ交叠改变，K、历史质量和R边缘不变。完整组级账见[新旧矩量账](../../tools/evidence/diagonal-basic-author-check/hybrid-moment-ledger.json)。

# 56条行的完整矩量公式

每个hist把八个字典序会员桶 \(w\in\{0,1\}^3\) 按hist重数展开为六个词 \(w_i=(t_i,b_i,c_i)\)。固定一条C族边 \((i,j)\)，记 \((t,b,c)=w_i\)、\(y=c_j\)，实际六会员位为 \(a_1,\ldots,a_6\)，并设

\[
p=\sum_{k\le3}a_k,\quad p_a=\sum_{k\le4}a_k,\quad
\ell=\sum_{k\le5}a_k,\quad L=\sum_{k\le6}a_k,
\]
\[
\delta=p+t+y+1,\qquad D=(p_a+1)(p_a+2),\qquad
d=\sum_i t_i,\quad n_B=\sum_i b_i,\quad n_C=\sum_i c_i.
\]

对该组写 \(r=|R|,z=|Z|,v=|R\cap Z|\)，均是该hist内的质量而非0/1位。下列 \(s(n,q)=n/q\) 在分子0时按原 `share` 取0，包括0/0；其它出现的分母为正。定义

\[
V_Z=\frac z{p_a+1}-\frac vD,
\quad V_R=\frac r{p_a+1}-\frac vD,
\quad Q=s(a_5+a_6,L)+\frac{a_5}D.
\]

下表为一个hist、一条边对行的贡献。不是每个客户类型贡献本身非负；必要性是对全部客户和相应索引边求和之后的非负性。

| R行名（16类） | 矩量贡献 | 真实来源 |
| --- | --- | --- |
| source | \(H[s(b,p+t+b+c)-s(y,p+t+y)]+r\,s(y,(p+t+y)\delta)\) | 历史 \((h,T_i)\) 的第五位由B_i改C_j，接真实R_ij |
| terminal_own_B、terminal_own_C、terminal_own_T | \((r-Hq)/\delta\)，q分别b、c、t | R_ij末位查询B_i、C_i、T_i |
| terminal_opt_average | \((r-Hd/6)/\delta\) | 对六T的末位查询平均 |
| terminal_actual_1至6 | \((r-Ha_k)/\delta\) | 查询六个实际主题 |
| terminal_B_average、terminal_C_average | \((r-Hn_B/6)/\delta\)、\((r-Hn_C/6)/\delta\) | 查询六B或六C的平均 |
| reverse_terminal | \(Hs(c,p+t+b+c)-r/(p+t+b+1)\) | 原C_i查询R_ij |
| price | \(Hs(a_6,L)-r/(\ell+1)\) | 实际末位查询R_ij |
| capacity | \(-r\)，全行再加30K或6K | R_ij是合法主题，K为目录最大主题大小 |

这里三个“平均”是六个合法查询的不等式平均，不把分数会员当新主题。R的source中，\(r\) 项来自对二元R精确展开偏离收益；分母为0的可能性只有y=0，此时该份额按share为0。

| Z行名（12类） | 矩量贡献 | 真实来源 |
| --- | --- | --- |
| source | \(Hs(a_5,L)-V_R\) | 实际第五位改R_ij，接Z_ij |
| pair | \(HQ-(r+z)/(p_a+1)+v/D\) | 实际末两位对R、Z的强PAIR，保正交叠项 |
| price | \(Hs(a_6,L)-z/(\ell+1)\) | 实际末位查询Z_ij |
| capacity | \(-z\)，全行再加30K或6K | Z_ij合法主题容量 |
| actual0至actual5 | \(V_Z-Ha_k/(p_a+1)+a_kr/D\) | Z_ij在前四位加R背景查询A_k；代码0编号对应数学1编号 |
| ownR | \(V_Z-r/(p_a+2)\) | 同节点查询R；重复主题仍增加提供者负载 |
| reverseR | \((r-z)/\delta\) | R_ij在其原末位背景查询Z_ij |

例如对二元r、z的逐客户收益，\(z/(p_a+r+z)=z/(p_a+1)-rz/D\)，故积分后为 \(V_Z\)。同理得 \(V_R\) 和实际主题查询项；若只保r、z而丢掉v，这些行会改变。强PAIR中的Q来自固定实际前四位的背景，不是根福利或两个任意查询者利润和。

程序逐正hist遍历36条有序边，只取 \(g=(1,\mathbf1\{i=j\},w_i,w_j)\)。按stage、diag、name求和；capacity在全部历史累加后只加一次30K或6K。这样得到 \(2(16+12)=56\) 行，两部分相加恢复原28个合行。此前[拆分图程序](对角回复预算拆分的基础图程序--程序.md)已独立审过全局局部系数与逐列合回；本轮不重复其73728种局部情况和106680个矩阵系数审计，也不把行相加恒等式升级为“新增秩严格等于28”。

# 入口副作用、依赖与可复现边界

源没有 `main` 保护，也不解析参数。直接运行和import都会读固定路径、计算并覆盖同目录status；传 `--verify` 不会选择一种只读核验模式。它从自身祖先向上寻找存在 `work.py` 的根，再固定进入旧six_astra目录，修改sys.path并导入 `new_reply_budget` 与 `actual_fifth_nested`。用到前者PAT、NAMES、share和后者BASIC；这些模块继续导入其它旧模块以及NumPy/SciPy。原诊断自身用Fraction，未调用这些依赖的build、main或linprog。

R的16值有长度断言，Z列表与BASIC仅zip，没有单独长度断言；完整代码版本和名称顺序是合同的一部分。原代码也没有显式检查列数、组完备、变量唯一性、slab范围、weight非负、source_sha256、O/W或元数据行数。错误输入可能抛出KeyError，也可能被聚合或zip静默接受；“rows=56”只表示初始化56个键，不证明输入完整。程序不要求全部余量非负，exit0表示计算成功，不能解释为必要行通过。

[执行记录](../../tools/evidence/diagonal-basic-author-check/rerun/execution-event.json)保存一次未改原入口运行：Python3.12.14，assert开启，`-B`且清除PYTHONOPTIMIZE，耗时0.963秒、exit0、stderr0、stdout938B；生成status与stdout逐字相同。运行在clone外的新目录；49个冻结文件与1个非执行根标记前后SHA均不变。完整库存并不意味着49个文件都被本入口读取；其目的是保存版本及证明这次诊断没有改输入。未执行原阈值求解、完整3949行verify、split CLI、3945行构造或优化。

[新增局部脚本](../../tools/evidence/diagonal-basic-author-check/inspect_diagonal_input.py)读取全部保存坐标，并只复用此前独立审过的逐客户utility定义 `literal()`，不调用该审计的main或原图程序。它在当前10个正hist的360条边上枚举四状态，共1440次状态评价、40320个局部系数，得到全部56余量与28合行。其输入文件身份、全变量描述符/上下界、194组四状态及W/O核查均保在[当前点核查](../../tools/evidence/diagonal-basic-author-check/input-and-local-check.json)。这次有限代入与此前全域系数恒等式审计是不同事件、不同范围。
