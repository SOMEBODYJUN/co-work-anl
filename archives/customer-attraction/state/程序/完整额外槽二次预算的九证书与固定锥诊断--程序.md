# 被测全称、固定输入与有限诊断的范围

\[
K_i(T,A)=\sum_{x\in T}\frac1{1+c_x(Z_i(A))},\qquad
\sum_i p^TK_i p\le W\quad\text{对每个合法查询分布 }p.
\]

T与列A独立同law p。被测右侧是actual覆盖W，**不是**平均强制利润ΣD_i，也不是末位θ、真正minimax值、Mfull或Mpath。因此强ΣCplus>ΣD的381/34客户反例不自动否FTA；这些有限未命中也不恢复已被否定的强桥。额外查询是静态比较，不更改原SPE人数。

# 2892B：在可读取的旧完整证书上优化p

然后actual覆盖给W，精确构造H_(T,A)=Σ_i K_i(T,A)，转double。起点为均匀分布、全部k个纯点和每个无序标签对上的1/2混合，共1+k+binom(k,2)。对每起点以SLSQP最小化−pᵀHp，解析梯度−(H+Hᵀ)p，box[0,1]、Σp1，ftol10⁻¹¹、maxiter300。只按res.fun取最好，不检查或保存每次res.success/残差，所以不是全局二次最优证书。

取最优浮点x后，每坐标先F(float(v)).limit_denominator(10⁶)，截非负再按精确总和归一；最后用原Fraction H精确计算该**新有理查询**的value及gap=value−W。源码会对每份保存查询都这样复算，不限正候选。它不是一个独立于当前程序的验证器，也不证明该有理p仍为SLSQP极大点。归一可能产生很大的共同分母；不能把10⁶误说成最终每个p分母上界。
