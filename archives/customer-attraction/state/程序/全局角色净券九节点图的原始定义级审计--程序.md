# 固定抽象图，不是一个CAG实例

4598B原程序只依标准库Fraction、itertools.product、Path、json；全部ROWS、FUTURE、角色数5、注入和价格域都写在源码内，**没有外部游戏、策略或输入文件**。九个state=(角色,字母context)是抽象历史标签；同role的a/b保持不同。它没有给客户兴趣、合法主题、actual策略或全有序历史IC，不声称这些任意混合行共同来自某个CAG/SPE。

它实际回归[全context终点HIT定理](../定理/净券跨节点角色命中与来源后缀界--定理.md)及其价格推论。已发表4675B原HIT主稿本批全文读取、核精确原字节；一般证明已经成立，不因本审计另造一条同数学定理或认领新支付。合法CAG净券行满足当前概率支配recipient的理由在[局部凸包](../定理/净券行均匀子集凸包与局部价格--定理.md)及其合法核域；这里仅检查明示抽象行。

# 阈值重构核的是什么

源码不止检查p_j≤p_i，还取断点{0,p_i,全部其他p_j}。相邻lo<hi之间以mid筛出p_j≥mid的recipient，加current成S，使用混合质量(hi−lo)|S|。各段贡献到S每个坐标的量均hi−lo。因此当前坐标积分p_i、recipient j积分p_j，总混合质量Σp=1，恰恢复同一概率行。

它重构的是等价阈值混合，不要求恢复原来两个成分的同一分解。例如0a的阈值表示是(5/9)U{0,1,2,3,4}+(1/3)U{0,1,3}+(1/9)U{0}，与原两triplet混合不同而概率相同。`local_threshold_mixtures=9`是一state一次恢复，不是全混合空间穷举或九种CAG客户证明。

# 真实终点递推和多context的作用

角色逆序时每个future child已算完，代码同role b/a的次序任意无害，因为future角色严格大于当前。对state s、当前i，终点向量T_s递推为

\[
 T_s=p_i e_i+\sum_{j<i}p_j e_j+
 \sum_{j>i}p_jT_{\mathrm{FUTURE}(s,j)}.
\]

它保current吸收、past券终止、future分支与合并；每个正future指针必须存在且角色更深。归纳ΣT_s=1。没有把past送回早期context产生循环；也没有把来到目标集合K的future节点强制全部停下。

例如4a/4b没有future，终点即各自p；3a有1/10质量去4a，给

\[
 T_{3a}=(7/60,7/60,19/60,5/12,1/30).
\]

3b有1/6质量去4b，给

\[
 T_{3b}=(13/72,13/72,13/72,7/18,5/72).
\]

同角色3的两个context终点确不同，不能合并为仅按role的状态。3a到future4再由past终点回角色3，使最终角色3质量5/12大于局部current2/5；这不是源到集合的访问次数或source-order结论。此fixture可有源4到过去终点，不属于仅fresh来源的因果支持额外域。

# 三类全图检查及完整原计数

固定K不含源角色i、k=|K|，HIT给T_s(K)≤k/(k+1)。理由是局部均匀子集行中，future目标在K的续值至多1、外K的至多h=k/(k+1)，past终点也满足相同界；一个subset含a≤k个价1和b个价≤h，其平均(a+bh)/(1+a+b)≤h。按严格future图归纳闭合，是已有一般HIT的直接应用。

原程序对每state枚举全部2^5集合，但只在i∉K分支assert并加计数，因此每state有2⁴=16项，合9×16=144。含i集合未算进此数；空K确包含在内。它不是144个输入图、客户集或SPE。

价格检查对每state枚举λ∈{0,1,2}⁵，243种，按高于λ_i的其它角色价格降序为λ_(1)…λ_(l)，核

\[
 \sum_jT_s(j)\lambda_j\le
 \frac{\lambda_i}{l+1}+\sum_{k=1}^l\frac{\lambda_{(k)}}{k(k+1)}.
\]

这是终点HIT层积分，允许并列、零/常数价和l0；源码测试9×243=2187项，不能把此网格单独叫所有实价格穷举。一般非负实价格结论由已证明的层积分承担；局部recipient价不能直接冒终端价。

多源注入有两组：所有state s注入1/(i(s)+1)，或仅0a/0b各注入1、其它0。它们按角色合并的源库存分别是M=(2,1/2,2/3,1/2,2/5)、总量61/15，及M=(2,0,0,0,0)、总量2。最终A_j=Σ_s b_sT_s(j)。对每组全部32个K（含空/全）核

\[
 A(K)\le M(K)+\frac{|K|}{1+|K|}M(K^c),
\]

共2×32=64项。同一role的两context均计入相应M，不能漏一个或每context单领一份实际u_i。程序同时保总质量1的终点行，但没有检查M与任何游戏actual钱包的关系。

360B冻结JSON全部字段：status="passed"；scope为一固定role-coupon mixture DAG、定义级、非game/SPE scan；roles5、history_contexts9、local_threshold_mixtures9、global_target_set_checks144、global_weighted_price_checks2187、multisource_cut_checks64，claims_actual_wallet_capacity=false、claims_half=false。当前不重新执行以补passed/exit，也未把上面两终点行或M向量回填为原JSON字段。
