# 固定全支持鞍点的线性等式

记p_t=Σ_(a∈t)p_a、q_t=Σ_(a∈t)q_a，对新重数w，
\[
 F_a(w)=\sum_{t\ni a}\frac{w_t}{1+2q_t},\qquad
 H_a(w)=\sum_{t\ni a}\frac{w_tp_t}{(1+2q_t)^2}.
\]
固定p/q后分母不含w，故均为线性函数。两程序施加归一化Σw=1，及a1,…,5的F_a−F_0=0、H_a−H_0=0，共11等式；没有把全支持非均匀向量误作单列或只核一个支持。

F等价使p为固定q下的最佳查询。固定p的背景目标Φ_w(p,s)=Σ_t w_tp_t/(1+2s_t)凸可微，在s=q的坐标导数为−2H_a；H全等使所有单纯形可行方向的导数0，故q全局极小化此凸目标。于是(p,q)是真正自由分数鞍点，δ_3=F_0=Φ_w(p,q)。这是**新w精确满足行时**的结论；不是旧数值鞍点四舍五入便自然最优，也不只靠SC的查询支持等价。完整一般证明与边界见[类型线性引理](../引理/固定分数鞍点的类型线性证书与真实孩子上界--引理.md)。

三人逐角色均值付款仍是：在actual位置i强制a，完成真实叶Z_i(a)，只删当前i槽一次，μ_it=E_(a~p)c_t(Z_i(a)_{−i})；定义
\[
 F_i^{\rm role}(w,p)=\sum_t\frac{w_tp_t}{1+\mu_{it}},\quad
 W(w)=\sum_tw_t\,\mathbf1_{\{c_t(z)>0\}},\quad
 \mathrm{FG}=\sum_iF_i^{\rm role}-W.
\]
同名F_a是静态纯查询列，此处F_i^role是实际位置均值，须区分。源FG按各角色平均负载后分别倒数再求和，不是635发现器将角色也平均后取倒数的mG。真正IC只付同强制查询与同一后继的相关对角；[静态KKT余量](../引理/自由分数鞍点的真实菜单均值KKT余量--引理.md)不能自动给u_i≥F_i^role。
