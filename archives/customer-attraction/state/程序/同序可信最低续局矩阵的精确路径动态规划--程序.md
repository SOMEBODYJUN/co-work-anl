# 被计算的全称候选

采用[共同目录完整历史模型](../定义/共同目录完整历史模型--定义.md)，有限单位客户、m≥1个单位玩家及有限非空共同主题目录，保空主题、重复选择、零客户、所有有序history及平局。对实际可实现纯SPE有序路径a和其第i位前缀计数k_i，令

\[
 L(k_i,t)=\min_{z\in R(k_i+e_t)}u_t(z),\qquad
 O(T)=\left|\bigcup_{i=1}^mT_i\right|.
\]

R为该前缀后全部完整纯SPE可实现终局；强制t之后后继必须可信，但不要求t在受迫节点本身最佳。原SM候选为每个实际可实现a、每个有序比较元组T∈𝒮^m，都有

\[
 \delta(a,T)=W(a)+\sum_iL(k_i,T_i)-O(T)\ge0.
\]

不限最优比较、不限同一最优支持的一个排列，也不禁止比较主题重复。因actual IC给u_i(a)≥max_tL(k_i,t)，若SM普遍成立，取最优T便有OPT≤W+ΣL≤2W。这个充分推论不等于SM已经证明。

L最小化当前真实玩家利润，含自己的已选动作；不是额外查询G、静态minimax值或某份固定σ的真实偏离d。特别当t=a_i时，L也可能由改变actual后继的另一子SPE取得。本程序确计算这个较强的原SM；[保actual合同](../资源/固定实际路径的可信门槛与全菜单包络--资源.md)的SM*在actual列保u_i、离轨列才用L，不能拿本程序的cost当同一固定策略完整菜单的成本。

真正首次离轨孩子的L极小化可同时贴合，不是笼统的“所有离轨最低值不相容”。不能免费同时贴合的是嵌套actual孩子还保原叶这一要求。程序并未声称完成这项替换，也未优化TB、Mpath或U包络。

# 固定q时全部actual路径的合法域

`check(instance)`先用规范ExactSPESolver求根全部R(0)和精确OPT。对每个q∈R(0)固定其W和每主题终局利润u_t(q)。若前缀count为k，下一实际动作a只有在

\[
 k_a<q_a,\quad q\in R(k+e_a),\quad u_a(q)\ge M(k)
\]

时可取；M(k)=max_b min_(z∈R(k+e_b))u_b(z)即规范threshold。它既保证可继续达到q，又保证当前能通过选择其他孩子最低可信回复而最佳；逐层使用恰枚举全部实现q的有序纯SPE路径。不是只取q的任意排列，也不是强制一个匿名selector。各有序离轨孩子可以分别作可信选择，相同count缓存不锁其平局规则。

内部`L(k,t)`缓存全可信孩子中u_t的最小，与原actual q不同也允许；所有分数用Fraction，根结果/threshold由精确有限后向归纳提供。源码不依赖外部策略证书、随机种子、LP或浮点判断。

# 为什么(k,mask)合并无损

初态`((0,…,0),0)`成本0，两条见证序列均空。第i层状态含actual前缀k与已选比较主题支持mask，另保存最小cost及一条actual path和comparison tuple。每一步先任取**比较**主题t，累计L(k,t)、mask加t；再取一个上述可实现的actual动作a，迁移到(k+e_a,mask∪{t})。

归纳不变量是：该状态保存所有到此的合法actual路径和有序比较前缀中最小ΣL。两个到同(k,mask)的历史未来选择集合相同：当前L只依k，固定q的actual合法性只依k/q，最终覆盖只依比较支持mask。未来既不读取旧path顺序也不读取比较旧重数，所以可丢较大cost、保其最小者。重复比较主题仍每次支付一个L，只在最后覆盖里去重；并未把有序m元组降成仅有不同主题的集合。

每层actual count总和恰加1、比较长度恰加1，故层号可由|k|恢复。终态k=q时，对每个mask评价cost+W−cover[mask]。`cover`在全部2^p掩码上按客户兴趣是否相交计算真实单位覆盖，既非topic大小之和，也非比较出现次数之和。未来相同保证此终态最小化等于全部q路径/全部有序T的精确最小化；再对所有根q最小化即原SM的有限输入检验。

只在新cost严格小时覆盖状态，平局保先遇见证；跨q/终态的best也仅比较余量，不按整元组字典序破平局。sorted roots、动作循环和字典插入顺序产生某一见证，不宣称该见证是所有平局中字典序最小。与上一pair minpair比较整个tuple的规则不同。

# best、bestopt和停止规则

返回元组七槽依次为

\[
 (\delta,q,\text{actual path},\text{comparison tuple},\sum_iL,W,O(T)).
\]

`best`为全部比较元组的最小余量；`bestopt`只保cover[mask]==OPT的终态，但仍覆盖**全部**有序最优比较，不只找一种可过的排列。两者可以在不同actual q/path取得；相同最小余量也可保存不同T/cost。完整19记录见[同序可信最低续局矩阵的精确路径动态规划](<同序可信最低续局矩阵的精确路径动态规划--程序.md>)。

main仅在`bestopt[0]<0`时停止后续文件。若best<0而bestopt≥0，已经是较强原SM的反例，源码仍会继续扫；因此“未break”不是全比较无负值的逻辑判据。当前19份保存的best和bestopt均严格正，属原有限报告，不冒新DP执行或普遍证明。

每个row把best/bestopt七个槽**全部转str**，q/path/T成为Python tuple字符串，stats也是`SolverStats(...)`字符串；这些不是机器可直接当JSON数组的策略证书。stats的retained_outcomes是所有缓存状态保留终局集合大小之和，不是根SPE路径数、完整策略数或IC比较数。
