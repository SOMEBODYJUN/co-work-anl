# 来源和共同定价对象

三个原源码全部实读：price_aligned.py 9981B（`6abfdbd433c3caa9fb85`，SHA `463dfcfd6f861cc1980300c8731ebc863c0dd953500708650beddc8878997808`）；block_price.py 5989B（`9696e5508b316b275db5`，`ec463fa88801122bf492cdebb2a5f6e8d709466dc151044f209b7a6d4c65a260`）；price_root_hist.py 4034B（`50eda919bac4b2d5f231`，`c04608c76953f789db2969913b8cf1c6e85291dcbd66868aa627365eb4df68e8`）。双冻结path/blob及原字节在[来源清单](../../tools/evidence/global-prices-five-boss3/source-manifest.json)。两JSON全字段/全部负列在[计算页](../计算/两份索引定价报告的全部负列与冻结对偶核对--计算.md)分别主处置。

这些是[原共同目录单位客户模型](../定义/共同目录完整历史模型--定义.md)的**必要条件投影**上的列定价，不是寻找完整策略或直接验证SPE。有限共同目录、单位客户/提供者、完整有序历史、空题/重复/同覆盖标签/零客户和任意离轨平局不改变；投影没有承担所有这些历史的IC。

原子含十位η（顺序ABCDEUVWXY）、AB/AE各一个总数5的三元会员直方图、Sbranch一个总数5的四元会员直方图，以及三旧菜单 $(\ell_f,h_f)$。三族共享T会员总数d，须

\[
0\le d\le5,\quad0\le h_f\le d,\quad0\le\ell_f-h_f\le5-d.
\]

每原子实际覆盖系数 $W=1_{\eta_A+\cdots+\eta_E>0}$，比较覆盖系数 $O=1_{d>0}$。其整数会员坐标不等于已具备完整策略的游戏。对行 $G_n\ge0$、候选非负乘子λ及β，定价残差

\[
\rho(a)=\beta W(a)-O(a)-\sum_n\lambda_nG_n(a).
\tag{1}
\]

若全型ρ≥0，非负原子质量及必要行才给O≤βW。一个合法原子ρ<0只排除**该候选对偶**的全型有效性；单列无需也通常不满足全部G≥0，不能当作SPE或可行低福利原始点。

# price_aligned：一个36活动行对偶的特殊全型分离

## 确切输入与被允许的行支持

程序固定读next_credible/reopt_aligned.json。此冻结文件81882B、SHA `0bce38e76961db95c79fbd1c86ce79c1364a48cbcc7bc9bce42727d1b2fe2e69`，2196个names/λ、原64列point、β1.9844871781654265，浮点原始objective1.9844871781654252。它是64限制列问题，不能由β<2推全型或原五人结论。

Price只取λ>10⁻¹⁰，并要求每个活动名字在硬编码expected集合中；其它2196行未必有此分离结构。当前正支持恰36，非零小λ没有被截掉。程序读canonical five_indexed原文件到第一个`from pathlib import Path`之前，只exec定义，避免其后全437/对偶审计；四新增rows来自offdiagonal/crossmenu/menutax/alignedtax。offdiagonal在import时会读取原437证书，但不运行其main。相关原字节和SHA在[依赖包](../../tools/evidence/global-prices-five-boss3/related-and-runtime-manifest.json)，不能以别处canonical完整审计成功冒本定价运行。

TH是5分到8型的792个直方图，SH是5分到16型的15504个直方图。按共同d分组，其数量分别

\[
N_T(d)=\binom{8-d}{3}\binom{d+3}{3},\qquad
N_S(d)=\binom{12-d}{7}\binom{d+7}{7}.
\]

TM/SM预计算当前/查询份额、最坏负载逆分母、两人H和菜单重数等浮点特征；它们不是新的收益模型。

## 为什么可分，而不是任意跨族行都能分

固定十位η、第三旧菜单的ℓ₂及共同d后，本活动集仅有以下残余跨族耦合：AB对齐税依Sbranch统计 $v+w$ 与 $\operatorname{dot}(v,w)$；AE跨菜单行依Sbranch的w；AB及Sbranch与旧L₂都只通过已固定ℓ₂耦合。程序先为每个可能统计预取AB/AE条件最大值，再逐Sbranch直方图合并。

旧菜单0/1各自只在线性目标中出现，因此在可行平行四边形四角 $(0,0),(d,d),(5-d,0),(5,d)$ 取最大；ℓ₂固定时，h₂仍枚举其可行整数区间。随后循环全部1024十位、ℓ₂0..5和d0..5，记录每个十位的最小ρ。菜单角点理由是线性，不是将未知跨族交叠当边缘乘积。

这是对**当前通过expected的特殊活动支持**的完整有限域分解；NumPy/float最大化仍不是有理非负证书。加入另一个依赖未保留统计的活动行会使此分解失效，而不是仅改λ即可通用。

`check`用seed91302取80组随机合法原子，比专门分离分值和原Fraction定义求出的加权分值，容差10⁻⁹；它不是80次全域证明。run还对更新的选中列核分离值和direct_score的浮点一致性，未恢复有理对偶。当前本批不运行check/run/main，历史80字段只保原JSON语义；全部保存列的独立于该浮点分离器的Fraction行复核见计算页。

# block_price：七个完整块，联合仍是启发式

默认dual为next_credible/reopt_added.json，128131B、SHA `bdf1fe3ffaf6d557dd276b57be6556a530abf80589124565c11c34b97a6e6e80`。它仍是2196行，允许原64列加aligned首个负列，共65列；β2.0301065945804266、活动37。与后来2396精确点同β不代表本对偶属于2396行。

check(seed85012)取20组原子，逐2196行核vector/direct的浮点系数差，再对最多9个块候选核向量/逐标量分值；返回20是样本组数。默认CLI为30重启/8pass/seed20261021，原报告则restarts20，当前没有旧argv。--output直接覆写、父目录不自动创建；导入block也会compile向量定义，main guard只阻止真正search。本批未导入block或启动其20重启，保存23列另做固定复核。

# price_root_hist：固定38旧质量的不同列域

## 输入、原primitive行序与完整hist域

此4034B程序不使用前两个2196对偶。默认读root_full_hist_completion.json（3158752B、SHA `42b0e7f8299cbfdb470e3782b2761c9259387229ed7840ea83faea3dc678747c`），该报告9770列、1326行、38个等式，浮点margin0.004587247205899999。old来自34584B enhanced_2396_exact_obstruction.json（SHA `ce1f9d8b1036256b7e40e1eb5c990fdcc4f33c7fed3f2aa796bdf8245b9d0c4f`），不是65个自由定价原子。

run会将root_menu_completion.py读到`# Maximize a common margin`之前exec，构造1310个primitive行/1216个(a,t,v)列；v为四个真实根后继会员。旧每原子T0/T1两质量组有76个等式，而full-hist列预先固定每列的总T次数，所以只需38个旧原子质量等式。λ长1310+16、ν长38，source仅检查长度/λ近非负；真正行序一致另需绑定，不能靠长度推断。

为解决这一接口疑点，本批只exec该原primitive前缀**一次**，未执行linprog行：其1310 names及spec与冻结root_full前1310项逐项相同，A为1310×1216。事件见[接口绑定](../../tools/evidence/global-prices-five-boss3/root-primitive-interface-execution.json)。这不是root_hist.run，也不再核B的53根精确点。

每固定旧原子a，根回复共同五索引的会员类型是 $(t,v_0,v_1,v_2,v_3)\in\{0,1\}^5$。全hist把5−d分到T0的16格、d分到T1的16格，数量

\[
N_H(d)=\binom{20-d}{15}\binom{d+15}{15}.
\]

当前38旧原子皆d1，所以每原子62016型，若运行共2356608个atom-hist，而不是仅扫描旧9770列。包内[输入/域索引](../../tools/evidence/global-prices-five-boss3/root-histogram-input-and-domain-index.json)完整解析原9770描述符、行families及dual形状，但未将原point53个float正列认证成精确可行点。

## 16off的二次项与所选列的Fraction范围

设某hist的五行会员为(tᵢ,vᵢ)，$u_{ij}=v_{ij}/(t_i+\sum v_i)$，$D_{ij}=1/(t_i+\sum_{s<j}v_{is}+4-j)$，零收益按0。新增off系数是

\[
G^{off}_{jk}=\frac15\sum_i\left[4u_{ij}-\frac{\sum_l v_{lk}-v_{ik}}{t_i+\sum_{s<j}v_{is}+4-j}\right].
\]

给off乘子矩阵L，记counts=Hv、denoms=HDEN，则加权off分成线性部分减去 $\sum_{j,k}\mathrm{denoms}_jL_{jk}\mathrm{counts}_k/5$。source的einsum正是在整个联合hist上算这项，未把各回复边缘独立最大化。

定价分值是λ·列+νₐ，取每a全域最大，正>10⁻⁸的选择存positive_columns；每a的最大值都存best_by_atom，enumerated_atom_histograms计遍历型数，不是游戏/策略数。它检验的是指定必要完成LP的一个浮点对偶列条件，非原模型全称结论。

source对每原子选中的hist用direct_off的Fraction定义重算16个off系数，但primitive列仍由原**浮点A**平均，λ/ν仍float，最终只核浮点总分差<10⁻⁸。因此不能把“selected coefficients replayed using Fraction”扩成全部1310 primitive的独立有理推导或精确对偶认证。

本批root_hist导入/run/CLI/full-hist枚举/direct_off调用均0；只做上述一次原primitive前缀行序绑定及现输入字段域核对。B的[38原子/53根原审查恢复](../计算/增强三十八原子与五十三根直方图的原审查恢复--计算.md)承担另一个完整精确可行点及旧L2/L1负行继承，不能借本定价程序认证其全SPE。当前输入中的9770浮点列、53个正float、后来53精确描述符及38旧质量分别保身份。

三个原main的输出路径都可覆写，不在原存档路径启动搜索。有限负列、全域列选择、启发式局部选择、真实SPE与可补全性是不同等级；当前五人half已有别证，六人主目标未由这些定价程序解决。
