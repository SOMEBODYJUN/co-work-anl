# 两个全称候选与三份原输出

在[共同目录完整历史模型](../定义/共同目录完整历史模型--定义.md)中，单位玩家依次观察全部有序历史；固定一份完整纯SPE σ，实际叶 z=(S₁,…,Sₘ)，利润 uᵢ、覆盖 W=Σuᵢ。主题可空、玩家可重复选择、零客户及任意离轨平局均保留。程序使用可区分的六标签接口；同覆盖标签能否合并另须核历史反应，不能自行删动作。真实偏离须在改变后的历史沿同一 σ 完成。

actual末前背景 bₓ=Σ_{i<m}1_{x∈Sᵢ}，单阻挡额外查询核及值为

\[
K_b(T,A)=\sum_{x\in T}\frac1{1+b_x+\mathbf1_{x\in A}},\qquad
L_b=\min_q\max_T(K_bq)_T=\max_p\min_A(p^TK_b)_A.
\]

q、p均为合法目录分布，查询抽样与阻挡独立。这是 actual m−1 过去槽加一个阻挡槽、再额外查询的静态游戏；不是根自由 m−1 槽安全值、任意背景PB、全部位置真实菜单或固定实际终局查询最大值。两份probe分别攻击 **每份根完整SPE的 u₁≥L_b** 和 **mL_b≤W（LAST）**。固定p只得到

\[
\ell_p(x)=\min_A(p^TK_b(x))_A\le L_b(x).
\tag{1}
\]

精确且真实SPE的正 \(\ell_p-u_1\) 或 \(m\ell_p-W\) 足以反相应候选；非正不证明候选，甚至不证明该一个点的真正 L_b 已获付款。静态 OPTₘ≤2mL_b 及其条件推导仍有效，LAST只是half的充分桥。[后来完整反族](../反例/末菜单全列精确税付款的完整SPE反族--反例.md)已否这些一般辅助候选，见末节；原阴性时态不改写。
