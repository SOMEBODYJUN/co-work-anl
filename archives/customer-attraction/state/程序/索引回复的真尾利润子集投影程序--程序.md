# 来源和可复用结论

主源 `72c498d7803e037d9c4b` 是[完整5730B原程序](../../tools/evidence/continuous-query-refinement-program/related/tail_reply_subset.py)，SHA-256 `9f812b0381186aa8546a038416b6335424673cbf1f895e8da40f7b6f4baadfdc`，两冻结提交同字节。全文已读所有函数、96个结构的优化、参数有理化、精确行回代和文件输出。原件复用既有消费者存档，不另保存修改后的“原码”。

该程序强制的是已有带索引回复主题R或Z，比较的是六个T标签抽出的r元组；它不枚举完整SPE的回复子菜单，也不构造策略树。冻结[空切面报告](../计算/回复子菜单查询的空切面报告--计算.md)中 `selected=[]`、`best_float=[0,null]`。本次不为重现空输出再运行发现LP；只实际核原函数的离散比较、状态压缩和线性系数。历史搜索、当前有限函数认证、一般数学合法性各有不同证据。

# 完整历史、真尾和同一个末位价格

使用有限单位客户、有限非空共同主题目录、六位单位提供者的均分模型。固定一份定义于全部有序历史的纯SPE \(\sigma\)，保空主题、重复行动、零客户和全部弱平局，实际路径为 \(A_1,\ldots,A_6\)，实际最终收益为 \(u_1,\ldots,u_6\)。比较标签 \(T_1,\ldots,T_6\) 来自共同目录；这些投影行自身对任意合法六元组都成立，并不使用最优性，虽然输入大图把它们命名为opt并另含最优单换条件。

R/Z标签沿用旧图：在 \(h=(A_1,A_2,A_3)\) 强制 \(T_j\) 后，真尾为 \((B_j,C_j)\)，
\[
R_{0,j,k}=\sigma_6(h,T_j,B_k)\quad(j\ne k),\qquad
R_{1,j,k}=\sigma_6(h,T_j,C_k),
\]
\[
Z_{f,j,k}=\sigma_6(A_1,A_2,A_3,A_4,R_{f,j,k}).
\]
每族共有30+36=66个带索引标签。这里只把这些合法主题作为较早实际节点的强制查询，**不要求R或Z仍是新节点的最佳回复**，也不冻结其原生成历史的后继。

源码i为零基实际位置，取1、2、3、4，即真实第2、3、4、5位。强制该玩家选一个X=R或Z之后，有 \(r=5-i\in\{4,3,2,1\}\) 名真实后继 \(Y_1,\ldots,Y_r\)，必须沿同一 \(\sigma\) 的改变后历史继续。对客户x定义
\[
b_x=\sum_{k=1}^{i}1_{A_k}(x),\quad
\ell_x=\sum_{k=1}^{5}1_{A_k}(x),\quad
t_x=1_X(x),\quad z_x=\sum_{j=1}^{r}1_{Y_j}(x).
\]
\(b+t\) 是强制分支的尾部背景，\(\ell\) 是整局原实际末位背景，两者不能混同。每个Y仍是共同目录主题，故可在**同一个原实际末位节点**合法报价。

既有背景利润定理给
\[
F_r(b+t)\le\beta_rV_r,
\qquad(\beta_1,\beta_2,\beta_3,\beta_4)
=\left(1,\frac32,\frac53,\frac{1499}{750}\right),
\]
其中 \(V_r=\sum_x z_x/(b_x+t_x+z_x)\)，\(F_r\) 是同背景任意r个合法主题可得的最大**剩余利润**，非全局覆盖。r=1来自末位BR；r=2由[背景两人税界](../引理/固定背景两人税界--引理.md)及逐客税不超过实际两尾利润一半得出；r=3、4使用[三人背景利润](../定理/固定背景三人利润界--定理.md)和[四人背景利润](../定理/固定背景四人利润界--定理.md)。这些正式定理的模型、量词和结论接口已核；本任务不重做其原符号证书。六人根强制后剩五人，需要另一个背景定理，不能由五人零背景half免费填 \(\beta_5=2\)，所以代码没有i=0。

# 下包络和合法行的自足证明

取任意合法比较r元组，客户比较重数为q，令 \(R_{c,x}=q_x/(b_x+t_x+q_x)\)。全部零分子份额取零，包括同时零分母。对共同非负标量 \(\alpha,\gamma\)，三条非负整行是
\[
u_{i+1}-\sum_x\frac{t_x}{b_x+t_x+z_x}\ge0,
\]
\[
\beta_r\sum_x\frac{z_x}{b_x+t_x+z_x}-\sum_xR_{c,x}\ge0,
\qquad
ru_6-\sum_x\frac{z_x}{\ell_x+1}\ge0.
\]
第一条是实际源节点的真实偏离IC；第二条只向强制源后的真r人子SPE应用背景定理；第三条把r个Y逐个向原实际末位查询，保重复槽，花恰r份 \(u_6\)。后两条分别乘 \(\gamma,\alpha\)，与第一条相加，再对每个客户把实际z换为 \(0,\ldots,r\) 上最小值，得到
\[
u_{i+1}+r\alpha u_6\ \ge\ \sum_x\psi(b_x,\ell_x,t_x,R_{c,x};r,\alpha,\gamma),\tag{1}
\]
\[
\psi(b,\ell,t,R_c;r,\alpha,\gamma)
=\gamma R_c+
\min_{0\le z\le r,\ z\in\mathbb Z}
\left\{\frac{t-\gamma\beta_rz}{b+t+z}
+\frac{\alpha z}{\ell+1}\right\}.\tag{2}
\]
零分母只在b=t=z=0出现，此时分子也为0，原 `frac` 返回0。\(\alpha,\gamma\) 属于整行共同预算，不能改成任意逐客乘子却仍用同一左边。各客户的最小z无须拼成一份真实后缀；消元只放松必要条件，不创造可实现策略或把互斥分支利润相加为实际福利。完整同类接口见[真实后继利润与共同末价的离散下包络](../引理/真实后继利润与共同末价的离散下包络--引理.md)。

# 四个比较元组族与对角重复

以下用j、k表示回复标签的两个比较索引，避免与实际位置i混淆。给定客户，六个T会员位的总数为d，已知 \(t_j=1_{T_j}\)、\(t_k=1_{T_k}\)。`comp_rc`返回比较元组均匀抽样下 \(q/(b+t+q)\) 的精确均值，不是把平均q直接代入非线性分母。

| q参数 | 实际比较元组 | 已知会员K；剩余总体N、其中会员D；抽样槽数n |
| --- | --- | --- |
| opt_subset | 六标签中均匀r个不同索引 | 0；6、d；r |
| opt_include_i | 含j，另在其余五槽抽r−1 | \(t_j\)；5、\(d-t_j\)；r−1 |
| opt_exclude_i | 在除j外五槽抽r | 0；5、\(d-t_j\)；r |
| opt_include_ij，r=1 | 只用 \(T_j\)，忽略k | \(t_j\)；5、\(d-t_j\)；0 |
| opt_include_ij，r≥2且j≠k | 含j、k，再从其余四槽抽r−2 | \(t_j+t_k\)；4、\(d-t_j-t_k\)；r−2 |
| opt_include_ij，r≥2且j=k | **两次** \(T_j\)，再从其余五槽抽r−2 | \(2t_j\)；5、\(d-t_j\)；r−2 |

最后一行是允许重复主题的合法r元组，不能称无重复的r子集。主题覆盖相同也不删除索引槽。统一的超几何公式为
\[
R_c=\sum_{a=0}^{n}
\frac{\binom Da\binom{N-D}{n-a}}{\binom Nn}
\frac{K+a}{b+t+K+a};\tag{3}
\]
非法二项式系数置0。源码断言 \(0\le D\le N\)、\(0\le n\le N\)。因为比较均值 \(R_c\) 只在(2)外层以 \(\gamma R_c\) 线性出现，先对比较元组求均值再做z最小化恰当；没有将一般的“平均”与“最小”随意交换。

源码另留 `self`、`actual0`至`actual5`、`wi0`至`wi2`、`wj0`至`wj2` 的辅助查询分支：把指定主题重复r次，令q=r乘会员位，再算同一利润份额。但发现器的QUERIES仅是上表四个opt名称，这些辅助分支未被搜索。字符串分派只看前缀及末字符，不是严密通用参数解析器，任意未知名称可能误落wj分支。

# 直方图、轨道平均和完整线性系数

输入按 `point['columns']` 原序扫描；hist记录实际六位a及六个三位词 \(w_j=(T_j,B_j,C_j)\) 的八桶计数H，桶词按字典序。随后joint-reply归最近的hist，以 \(g=(f,\delta,w_j,w_k)\)、状态 \((R,Z)\) 存质量，\(\delta=1[j=k]\)。三种轨道ORBS为(0,0)、(1,0)、(1,1)，前两者各30个有序异索引对，后者6个对角索引。相同三位词不等于索引对角。

若选member=0就查询R，member=1就查询Z。给定组，t=1质量是所有该会员位为1的状态质量和，t=0质量为hist质量减该和。程序不要求显式三状态之和等hist质量，隐含00已被正确计入t=0。它不读取旧R/R overlap辅助量；K及overlap列的系数均为0。

组的有序索引重数为
\[
c_g=\begin{cases}H(w_j),&\delta=1,\\
H(w_j)H(w_k)-1[w_j=w_k]H(w_j),&\delta=0.
\end{cases}
\]
除以n=6或30，恰为均匀索引对的概率。每种轨道分别平均一族合法行，左边仍是 \(u_{i+1}+r\alpha u_6\)；并未把三族或所有结构的利润免费同时使用。

`states`把相同 \((b,\ell,t,R_c)\) 的质量合并为 \(m_k\)，同时用hist计算实际 \(u_{i+1},u_6\)。只保非零状态；对有效规范化输入有 \(\sum_km_k=1\)。合并只用(2)的充足变量，不改变该族参数下的函数值。零hist不参与状态质量，但 `coefficient_rows` 仍对其正式列生成系数，不能只比较正支持列。

系数函数直接返回长度与原columns相同的有理向量。每hist先放 \(a_{i+1}/\sum a+r\alpha a_6/\sum a\)，再对该轨道每组减去 \((c_g/n)\psi(t=0)\)；每条会员位为1的joint列再减 \((c_g/n)(\psi(1)-\psi(0))\)。所以点积恰等
\[
u_{i+1}+r\alpha u_6-\sum_km_k\psi_k.\tag{4}
\]
这是对原输入布局的线性必要行，不是将选定点的负数硬编码为常数。

输入合同需要非负质量、完整组/状态布局、正确hist归属、\(\sum_wH(w)=6\)、d等于六T会员数、joint的所选一边缘在hist质量内。原代码只在实际访问处查部分边界，不校验全部字段、完整性或共同客户实现；重复键会覆盖，缺组也不保证被拒绝。公开helper接受任意cut字典，未显式阻止负alpha/gamma；合法性要求仍是有理 \(\alpha,\gamma\ge0\)。本次冻结输入已有完整结构审计，不能将成功调用泛化为任意JSON验证器。

# 96个LP方向、有理化和空结果的精确语义

结构域为
\[
4\text{个位置}\times2\text{个会员选择}\times3\text{个轨道}\times4\text{个比较族}=96.
\]
对每个方向，令状态k的质量 \(m_k>0\)，LP变量为 \(\alpha,\gamma\ge0\) 及自由变量 \(v_k\)。对每个z=0,…,r添加
\[
v_k-\frac{z}{\ell_k+1}\alpha
-\left(R_{c,k}-\beta_r\frac{z}{b_k+t_k+z}\right)\gamma
\le\frac{t_k}{b_k+t_k+z}.
\]
目标最小化 \(r u_6\alpha-\sum_km_kv_k\)，外加常数 \(u_{i+1}\) 得gap。固定alpha/gamma时最优v等离散下包络，因此这个LP搜索整条非负参数族。该事实描述优化模型，不认证一次浮点求解的全域结论。

原调用是scipy `linprog(..., method='highs')`，未自设尺度或容差，也未保存每次状态、目标、基或对偶。所有 `sol.success=False` 都直接跳过，包括失败或无界情况；不能把它们算作“精确无负行”。`best=(0,None)`只在成功解的gap严格小于当前best时更新。只有浮点gap低于 \(-10^{-8}\) 才把两个参数以 `Fraction(float).limit_denominator(1000000)` 有理化，再精确核(4)严格为负，最后生成完整系数向量并断言其点积等该slack，才加入selected。

因此保存的负slack若存在，会有固定有理参数及一份精确点值，但有理化可能丢掉浮点负gap，不构成精确最优性或完整参数覆盖证明。未来复用非空cut还应明确核精确参数非负；源码依赖浮点变量界，没有在有理化后单独断言该数学前提。

本冻结六字段输出的selected为空，best_float是初始化哨兵 `[0,null]`。这只说明没有被记录的严格负浮点best，也没有保存精确负cut；它不证明96次LP全部成功、精确最小gap为0、程序未遇失败、或该必要点对所有参数完全不分离。scope的“exactly negative … rows”在空列表上不提供任何具体负证书，更不说明输出数量应非零。该报告与本源码的输出结构相容，但没有程序SHA或逐调用日志，不能仅凭两件文件同在冻结树中反推当次全部执行细节。

# 原入口与默认点绑定

程序仅导入标准库、numpy和scipy，没有项目模块依赖。numpy在源码中未实际使用，但导入仍要求可用；scipy只在discover中求LP。默认源为HERE上一级的 `research_3/continuous_refinement_exact.json`，`--point`后一个字符串可改源，`--tag`改HERE内输出basename，默认 `tail_reply_subset_cuts`；没有正式参数解析或verify分支。路径按实际字串解释，输入缺项或坏参数会报错；未知旗标不会自动得到想象的审计模式。

main完整读取point，调用discover，再添加scope、输入路径字符串、输入字节SHA和源W，写HERE下tag.json，并打印除selected外的JSON及一行 `negative directions`。stdout不是单份纯JSON。保存字段共六个：best_float、selected、scope、source、source_sha256、source_W。选中cut若非空含i/member/orb/q/alpha/gamma/slack；best记录的是浮点参数，不替代这些精确字段。原入口会覆盖同名输出，应在隔离位置运行，不能把默认调用视为只读验证。

实际冻结源点为[连续旧查询精化点](../计算/连续旧查询精化图的有理可行点--计算.md)，816661B，SHA `abac45f78980d02f2bd056758a96653aa0bc0d8b87571820a5742397dc490246`。其1905列、5075旧必要行、179正列与原W身份已有独立数据对象及唯一原verify证据；本次不重跑5075图。它和5108 combined点有相同K、hist、W却有124坐标不同，不能因W相同换输入。旧报告中的绝对路径只保历史来源定位，以字节SHA绑定当前保存件。

旧点还有165个overlap辅助量低于字面交叠的Fréchet下界；本程序忽略这些列，不自动修复它们。行计算的投影接口成立，与全部旧坐标可由同一客户空间实现、以及存在完整SPE，是三个不同要求。空搜索报告对后两者都没有认证。
