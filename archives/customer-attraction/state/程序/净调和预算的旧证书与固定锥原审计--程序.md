# 模型、同一比较元组与已有解析对象

六源共48595B全文实读，三个原JSON的全部字段保原字节。采用[单位客户共同目录完整历史模型](../定义/共同目录完整历史模型--定义.md)。实际完整纯SPE终局负载c、福利W；恰m槽最优比较元组负载d、并集O，A为实际并集C的O外客户数。定义

\[
 B=\sum_x\sum_{j=1}^{d_x}\frac1{c_x+j},\qquad
 D=\sum_x\frac{d_x}{c_x+1},\qquad
 G_B=B-W-A,\quad G_D=D-W-A.
\]

原存在型候选为：对**每份**完整SPE，**存在某个**最优恰m元组使G_B≤0；D版更强。已有[净预算条件证明](../证明/终局净预算的元组支持量词与条件付款--证明.md)和[支持极点资源](../资源/最优元组净调和预算的支持极点与旧族诊断--资源.md)完整保B≤D、正余项、half条件推导、固定支持凹性极点最小化及四族解析公式。本页补原实现、完整报告及实际新事件，未给同一数学另授定理身份。

`multiplicity`是不同但兴趣相同的单位客户数，不是加权提供者或不可分割加权客户。重复比较槽、空覆盖主题、同覆盖不同标签以及完整有序历史平局均属模型合法边界；这批程序的固定十个非空实例不是这些边界的全量测试。

# audit_known：精确给定策略验证与存在量词的最小值

原程序从`examples/customer_attraction/<name>.json`读实例，从`evidence/certificates/customer_attraction/<name>.json`读策略；按`strategy`或`certificate`外壳取actions。缺terminal_counts时，从根沿给定动作表完成并重算。规范StrategyCertificate解析拒绝重复有序history；规范verifier先检查所有合法决策节点恰有动作，再对每节点每个不同当前动作沿**同一完整策略**真实完成，并以Fraction比较当前玩家利润。每人只行动一次，所以这些完整单步偏离恰给纯SPE。计数`checked_deviations`排除了自身。

它没有调用ExactSPESolver，没有逆推产生新策略，也没有把相同计数的有序历史强行并为一个策略节点。导入原包时虽然载入exact模块，真正执行的证书核验只用model/certificate。

`all_minimal_optima`函数名的minimal不是“仅包含极小支持”：它逐一枚举1≤|S|≤min(m,p)的**所有**不同标签支持，按覆盖找出全部最优支持，再把m−|S|个额外副本全部放在S的一个标签上（无额外副本时仅一次）。B在每个固定支持补槽单纯形上凹、D线性，outside在该支持内固定，因此其全局最小值都可在所枚举的整数极点取得。此依据已在支持极点资源逐步证明，不是用有限样例猜凹性。

于是`minB`和`minD`精确实现相应存在型预算；二者可以选不同q。比如worst_pne一行的minB q=(1,1,1,0)，minD q=(0,1,2,0)，后者D平局不影响最小值。`largest_extreme_B`仅为**所枚举极点**的最大值，不是B对全部补槽元组的全域最大值；B凹时内部可以更大。

# audit_families：114个预算计算，不认证无限族SPE

原程序仅构造兴趣类型及指定actual/比较计数，再调用上面的budgets；未给这些族创建完整actions或调用verifier。29个n=2,…,30各计算sharp、fractional、collision_free，另n≥4计算prefix，共114个预算对象。prefix在n2/3是JSON null。每预算记录B/D/W/outside/missing/G_B/G_D。

| 原字段 | 指定实际与比较 | 原断言 |
|---|---|---|
| sharp | 大题A实际重复n次；比较A和n−1个单例 | B=D=n−1/(n+1)，outside0 |
| fractional | 实际B^(n−1)A；比较A^(n−1)Q | B=nH_n、D=n(n+1)/2，两gap≤0 |
| prefix，n≥4 | 实际AB^(n−1)；比较全部n叶 | −G_B=−G_D=(n−1)/2+2/(n+1) |
| collision_free，k=n−1 | 实际C₁,…,C_k,D；比较A₁,…,A_k,D | G_B=G_D=−1 |

这些公式和无限参数数学已由支持极点资源及其所链的原族证明承担。此入口只做有限精确算术回归；sharp原“literature”只是原来源描述，不在本次新增外部归属认证。没有枚举这些家族的全部SPE或数百万有序历史。

# attack_known_cones：八个数值阴性目标与未触发的精确尾段

该程序沿四份已有完整策略actions固定所有真实分支，变量是p题全部2^p−1个非空兴趣类型重数w≥0、Σw1。各节点/非自身动作的真实完成收益差≤0构成完整策略锥。它从原实例全部最优支持极点中选择原G_B最小的q；只有该q支持恰有m个不同题时继续。

对任意其它非空支持S、|S|≤m，加约束cover(S)−cover(q)≤−10⁻⁶，强制原比较支持在归一化权重下唯一覆盖最优。这一1e−6是固定浮点间隔，不是一般整数实例的精确隔离常数。分别最大化B−W−outside和D−W−outside，全部系数虽由Fraction构造，交给linprog时均转float。
