程序是[有限层基数凹化](../定理/有限层匿名边际势的基数凹化--定理.md)和[22环原例/凹化例](../反例/匿名边际势的自由列亏损与凹化保持--反例.md)的定义级有限核验资源。输入在源内完整固定为22标签、三人、M=21、L=43，不接受外部实例，不导入原作者较早C22实现、父方审计或CAG求解器。仅用标准库Fraction、itertools、json、pathlib；所以“独立”是定义与实现的来源合同，不是外审或全球新颖性认证。

## 代码的真实检查范围

原7005B程序全文实读，势phi按完整定义给出：0/1层零，二元重复21、相邻10、非邻不同11加均匀F₃平均，三元22加F₃；psi添加人数二次项。choose/finish定义完整有序策略，根0、二位后继a+1、末位相邻重复第二项否则重复第一项。收益删除指定位置的一个槽，保重复行动。

| 检查单元 | 真实枚举及精确断言 |
|---|---|
| 全部多重集层 | 大小0、1、2、3分别1、22、253、2024；全部凹化势非负、零层归零；记录每层全部不同值。 |
| 一阶边际 | 背景大小0、1、2分别22、484、5566项，最小43、32、2，最大43、43、14；逐项非负。 |
| 二阶方格 | 背景大小0、1分别484、10648项，a,b有序且允许a=b；范围[-11,0]、[-79/2,-19]，逐项≤0。 |
| 终局效用平移 | 全部22³=10648有序终局，对每个角色逐项核u′=u+1。 |
| 完整历史IC | 1+22+484=507有序节点，每节点22项含原行动比较，共11154；原/凹化行差相等且≥0，最小0。 |
| 二槽查询 | 全部253无序背景，均匀查询原值仅11/12、凹化仅12/13；逐背景平移1。 |
| 静态安全上界 | 对每个纯查询t，均匀22个重复背景(a,a)的期望原11、凹化12；与均匀查询下界匹配。 |
| 实际自由菜单 | 原/凹化各3位置×22强制动作=66列，合计132；原最小(11,11,12)，凹化(12,12,13)。 |
| 两种严格亏损 | 原/凹化总效用25/28；自由列差均9，3v−U均8。 |
| 非CAG | 凹化单主题43、重复二元86≠129/2；三重复收益13迫主题价值39，而邻查询2<13、实际总28<39。 |

“11154比较”包含自身，不能再称11154个非自身偏离；“132列”是两势各66，不是每份策略有132不同动作。程序只核本C22参数，**一般有限层存在L,M及全域DR的证明来自解析定理**。原非CAG证据不提供客户集合，绝不成为六人half计算反例。
