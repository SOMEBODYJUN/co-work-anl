# 有序终局集合的精确递推

记 \(R_h\) 为有序前缀h之后全部完整纯SPE可实现的**有序终局**。原leaves(h)以完整h为cache键，不是按计数商并；终局长三时 \(R_h=\{h\}\)。未终局时i=|h|为当前零起算位置，令
\[
\ell_a(h)=\min_{z\in R_{h+a}}u_i(z),\qquad
M(h)=\max_a\ell_a(h),
\]
\[
R_h=\bigcup_a\{z\in R_{h+a}:u_i(z)\ge M(h)\}.
\tag{ALL}
\]
每个孩子非空，有限树极值达到；达到M的孩子保证本层非空。相同计数可以理论缓存可实现集合，但本程序实际缓存的是有序prefix与完整有序pay元组，不把(0,1)和(1,0)当一个策略节点。这里共1+7+49个决策prefix，另有343终局prefix。

必要性：一份完整SPE的当前实际终局收益至少应对每个合法孩子的最小可实现当前收益，因而≥M。充分性：保所选终局及其孩子完整SPE，给其他孩子各贴达到其最小值的完整SPE，当前IC成立，各孩子子树互不相交。该证明是[既成可信续局菜单算法](../算法/可信续局菜单与完整策略重构--算法.md)的有序终局版本，不从有限样本外推。

# build实际只选一个最小惩罚补全

仅在base∈R_空时，build从该目标递归。当前规定动作是z[i]；规定孩子保同一z。每个其他孩子a，选
\[
z_a=\arg\min_{y\in R_{h+a}}\bigl(u_i(y),y\bigr),
\]
第二项是有序终局整数元组的字典序破平局。ALL保证当前收益不低于该最小值；递归为每个有序孩子独立建表，写满57个动作。目标z属于相应孩子集合，故规定孩子与前缀一致。代码还对每个重构节点、全部七个真实偏离完成再assert原收益不低于偏离。

这里返回的是**一棵确定的**极小惩罚策略。极小孩子足以实现每个可行终局，不等于枚举实现同终局的全部策略；完整可信MENU还允许收益不超过当前阈值的非极小孩子，有限抽样亦不穷尽全部策略。不能拿这个默认选择器代替每份完整SPE量词。

随后cover直接由原mask整数重数算覆盖，枚举84个允许重复的无序三元组取真实最优，并造含rows/path/profits/welfare/optimal/optimal_tuples/actions七字段的结果。actions按(历史长度,历史元组)排序。它不是读取5149自报的最优性或动作；反过来，本批没有运行build，因而**不称当前重构动作与5149逐字节相同**。既有179证书已独立证明PAB可由完整SPE实现，原发现归属与当前算法兼容，但这不补造新原生运行载体。

# 默认只读与新候选输出的真实合同

argparse在顶层解析，仅有可选--output，无人数、目录、种子或目标参数，无main guard。默认即使不写文件仍会执行全部BI和重构数学，不能把“只打印”误作没有计算。

stdout依次给P后目标是否可达、七个根孩子最小当前收益、完整根目标是否可达三个诊断；若根目标可达，再打印**不含actions**的结果摘要。因此默认stdout不是完整证书，也不是一个可直接当5149使用的单一JSON文档。七字段完整动作表只在显式--output路径写出。

写入发生在BI、重构、全部IC和最优覆盖计算之后；若目标不可达则没有结果或输出文件，也未另raise。若给--output：

1. 将同目录prefixed_refund_counterexample.json作为冻结路径resolve，输出路径resolve相同则ValueError。
2. 用open('x')创建新文件，已有文件不会被覆盖，亦不建立缺失父目录。
3. 写完整七字段缩进JSON加LF；没有临时文件原子替换承诺或失败清理回滚。

resolve检查及exclusive-create保原指定冻结文件和其他既存路径，但本批没有执行这些分支做新测试。原VALIDATION记曾默认重跑后冻结SHA不变，是历史作者陈述；程序本身不读取冻结内容、无前后SHA比较或旧报告比较。
