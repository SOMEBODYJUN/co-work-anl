# 精确候选及后续真值

采用[有限单位客户共同目录完整历史模型](../定义/共同目录完整历史模型--定义.md)：m名单位提供者按全部有序历史各选一次，终局客户价值均分；保空主题、重复行动、零客户及全部离轨平局。实际末位收益u_m，福利W=Σu_i。被测聚合桥为
\[
\mathrm{C2}:\quad (m+1)u_m\le2W.
\]
它不是逐人强桥u_m≤2u_i。旧[七客户三人完整SPE](../反例/逐人末位二倍保底的七客户反例--反例.md)收益(3/2,2,7/2)，反逐人桥而C2恰等；不能据它否C2。当前一般C2另被[23客户三人完整策略](../反例/二十三单位完整策略的收益倍数与均摊桥反例--反例.md)严格否定：m3、W23、u₃12，46<48。恰五人的W≥3u₅也已有[十单位完整策略反例](../反例/十单位五人完整策略的末位份额反例--反例.md)：实际44013、收益(3/2,3/2,3/2,2,7/2)、W=OPT₅=10，故6u₅−2W=1。后者781个完整有序历史的资格由成熟精确证书承担，本批全文比较该正文而不重跑其核验。三份真输入、其完整策略与下文两个必要点各保身份；五人反例不能只从三人反例或通用不交DD补位推得，也不违反[五人half](../定理/五人半覆盖--定理.md)。

原tree入口写一般C2为OPEN、称未破该候选，是其写作时点；原更强逐人失败已及时停止的历史也保留。下面两个松弛点不是真C2反例；不同程序/输入版本及真实证据不能合并。

# 完整策略锥随机攻击器做了什么

2436B `attack_terminal_share.py`没有main guard，导入即执行；ROOT为当前cwd，动态加载`tests/audits/customer_attraction_strategy_lp.py`，再导规范Instance/CustomerType/ExactSPESolver。固定seed131313，依次配置(m,p,reps)=(3,4,150),(4,5,100),(5,5,50)。每个非空兴趣mask以概率1/2保留，保留者整数重数1…15；不随机删离轨历史。

每输入先由精确solver枚举全部可实现有序SPE路径，选末位收益/max(1,W)最大的path，恢复一张完整有序证书，再在**该固定图**的全部非空兴趣类型锥内、W=1下最大化末题收益。HiGHS给候选，分母≤10⁷有理化失败时用活动行顶点恢复；精确非负/全部锥IC及归一通过才比较。`best`贯穿三组不重置，stdout打印新高与组完成标记，不保存全部输入或逐案结果。

若(m+1)share>2，才整数克隆，并调用helper的独立全历史直接比较；保存instance/actions/path/payoffs/W与`ratio=(m+1)share/2`到`terminal_share_counterexample.json`后退出。ratio是**候选违反倍率**，不是OPT/W。源码允许软件标签同覆盖，与当前共同标签目录定义一致；若迁移到只限不同覆盖的旧集合目录子模型，仍须另核合法性，不能直接商掉标签。

本五源没有该反例JSON或冻结stdout，入口只历史报告未找到；不能把配置合计300次当作已证明完成300输入、所有锥精确阴性或一般C2。该程序既没有导出全部负目标有理对偶，也没有穷尽目录或策略。当前未导入/执行它，未复扫旧成功或阴性。

# 全类型两命名路径的必要系统

1926B `terminal_share_symbolic.py`定义p=2m−1个主题，非空兴趣mask1…2^p−1，质量x_B≥0。实际命名路径a=(0,1,…,m−1)，根改实际末题后的命名路径s=(m−1,m,…,2m−2)。对路径L，第i位的终局收益行u_i^L与保守偏离行
\[
v_{L,i,T}(B)=\frac{1_{T\in B}}{m-i+\sum_{j<i}1_{L_j\in B}}
\]
逐客户有理定义。实际全部i、source的i≥1与全部p主题加u_i^L−v_{L,i,T}≥0，再加原根真实比较u₀^a−u₀^s≥0。source根是被强制动作，不加虚假最优行。总行数p²+1，m3为26行31类型，m5为82行511类型。

每个保底分母仅用“至多所有尚未行动者覆盖该客户”，所以真实SPE若有这些路径必满足行；这些行没有指定改变后所有历史的完整子SPE。两条命名路径的末位行均为精确无未来BR。W=1按实际覆盖归一，最大化实际末位份额，不是目录实例遍历或全树SPE优化。

该文件有main guard；参数为位置整数m列表，默认3/4/5。主分支调用float LP，输出status、objective_last_share、candidate_share=2/(m+1)，将正类型/非零边际以分母≤10⁶的字符串打印并旁写`terminal_share_symbolic_m{m}.json`。这些形似有理的float近似本身**没有精确可行/对偶验收**；不能因字面分数就认证最优。当前primary没有默认m4输出；另一[NPZ诊断](../计算/末位收益比例的两路径松弛与完整终局筛选--计算.md)是不同原程序/类型域，不能从相同末位比例推输入字节或正类型数相同。
