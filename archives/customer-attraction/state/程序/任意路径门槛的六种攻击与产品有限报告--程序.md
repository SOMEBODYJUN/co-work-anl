# 任意路径门槛的六种攻击与产品有限报告

## 共同对象与执行身份

六原码全部函数、循环、guard及三个JSON全部记录实读。对象是[TB-ANY](../候选/任意路径可信门槛的终端福利预算与见证锥--候选.md)：任意路径z的W(z)+ΣΘ(prefix)≥OPT，其中Θ由完整纯SPE孩子全集给出。缓存**集合/值**不锁给定策略的平局；原模型的空主题、重复、别名、零客户及有序离轨全保。

当前全部原import/main/function、精确BI/路径扫描、LP、随机及新数学checker0。规范四模块沿前批已全文同SHA复用；没有将源MD的3250/76或JSON的finite exact字样写成本次执行。源码和报告都缺原argv/环境/stdio/时间/包SHA，不补造历史指纹。SAIC第七程序及其完整报告由[插入预算审查](../审查/实际终局插入预算与未缩放税桥的同一性--审查.md)单列。

## 1. 精确任意路径J攻击：2559B

`attack_arbitrary_path_threshold.attack(instance)`先规范solver.outcomes()，再以count k缓存cost：终端返回(integer W,空路径)，非终端在所有合法下一动作选最小(children value,path)，随后加Fraction Θ(k)。相同值按元组的路径字典序破平局。返回值就是精确J(0)，不是只在SPE路径搜索；零客户也定义完整。

只有J<OPT才返回完整instance/path、各步thresholds、W/OPT/cost/gap及`path_is_spe`。后者同时核根count属于全集且该具体有序path由某SPE实现；负TB-ANY不要求此字段true。没有导出一份完整σ/独立验证器报告，亦无此必要来否任意路径版；要否actual TB必须另外保path可实现。

guard主入口seed20261024，五组(p,m,次数)=(3,4,1000),(4,4,1000),(5,4,500),(5,5,500),(6,5,250)，每个非空type重数独立0…11，零重数略。名义合3250输入；遇负立即stdout JSON并SystemExit，否则只stdout有限阴性摘要，不写文件。MD说3250及另外4旧例均无失败；该main本身没有那4旧例循环，本组也没有这次完整日志，保作者历史声明而非重建同进程。没有CLI参数解析，`--verify`不会切只读。

## 2. 局部MARGINAL-FLOOR探针：2702B

先完整求解根全集，它递归访问所有合法count前缀，所以遍历solver._thresholds覆盖所有非终端count，不只actual均衡前缀。对过去覆盖支持support，过滤尚未覆盖type，用恰min(slots,p)个不同主题的组合求最大残余覆盖；单调覆盖/允许补重复保证与至多slots槽等价，slots0保唯一空组合。

每前缀余r比较Θ(k)与F_r−F_(r−1)，首次严格失败返回instance、prefix_counts、remaining、三个精确值及gap；成功无返回。guard seed202610241，五组(p,m,次数)=(4,4,500),(5,4,1000),(6,4,1000),(6,5,500),(8,4,500)。先每私有mask赋0…79，再2p个随机mask覆盖字典值，也可能覆盖先前私有值；不是保持每个私有块正数。结束方式与前程序相同，仅stdout。

原MD明确收到既有反例后停止，没有完成输出证据；不能把源码名义轮数当实际执行数，更不能将未完成阴性作证明。局部floor已可由成熟十五客户解析反例否定，当前无必要再跑此探针。

## 3. 一份完整策略上界锥：4236B

`coefficients`按指定完整actions沿每个真实history补到终局，为所有2^p−1非空type形成**float**当前收益向量和所有非self Γ行；不另检查任意脏动作表的完整性，main提供规范worst_certificate。没有Fraction恢复，也未把Θ值写进固定Γ。

`best_path`对完整有序history缓存，终端为覆盖float行，非终端选当前weights下最小孩子后加σ从本history真实完成的当前收益行；回传总系数和任意路径。σ可依顺序，故这里不能仅count缓存。它最小化W(z)+Σv_i^σ这个Θ的上界；若精确负，足反TB-ANY。

main seed202610242，(p,m,提案数)为(5,4,35),(6,4,35),(7,4,20),(6,5,20)。重数0…7，非私有mask另以.35概率候选，私有mask总参与但可为0。每图最多4轮：先选path，再遍历并随机打乱全部min(p,m)标签比较支持；解非负type、全部Γ及**总客户质量1**的float LP。比较支持无需在新权重下最优，严格超过任一合法覆盖已够否TB-ANY。

每次LP tested加1，即使优化失败；失败不选best，所有比较都失败则停止该图。成功最小目标<−10⁻⁷只打印numerical-only候选、path/comparison/weights/actions并退出，未有理化/未全树精确核/不写文件。全部负点仍须按完整有理行恢复；循环有限阴性也不证明这个策略族没有精确分离。

## 4. 独立局部前缀见证锥：6982B

`discover`先以精确J挑一个seed最小任意路径，再从seed全部≤m主题支持取一个最大覆盖支持作为比较，未来LP不要求其仍最优。每个路径前缀独立取(a,target)使该节点首收益恰Θ；`expand`构建完整局部SPE，未选行动孩子取该当前角色收益最低的可信终局、同值随机选择。

节点key是(counts,target,forced)，不同有序history可共享这个状态；forced仅根用，后继不带forced。共享固定选择可展开成每个局部根的完整有序图，count严格递增无环。它保合法见证，但也约束了若干相同key的选择，不枚全部可能的独立局部见证。所有生成的非self精确Fraction行最后按字面向量去重，重复IC系数删除无损；不能删不同系数行或把这些根强迫与任意路径glue。

局部首利cap行、任意路径cover行、比较cover行均固定，maximize compare−cover−Σcap，在type≥0、所有见证Γ≥0、**总客户质量1**下调用HiGHS。精确正点会因Θ≤每个见证首利给TB-ANY反例；本实现只存float，不能自动称真反例。coeff分子有a时所用终局包含a，分母≥1，不造0/0。

main seed721924：6旧输入(root_tax/individual_security/coverage_opportunity/global_decorrelation/worst_cce/eight_cce)，另4组(p,m)=(4,4),(5,4),(5,5),(6,5)各8个稀疏seed，每个无放回选p+4个以内type、重数1…16；每seed随机见证两次，合76。MD报告最高浮点gap0，无独立完整日志或正点JSON。若gap>10⁻⁸，源码才在自身目录写`tb_independent_prefix_discovery.json`，包括全部精确行字符串/节点/根/目标和浮点重数；否则不写发现文件。LP失败raise，不作无反例处理。当前没运行这76个实例/LP，未据0统计证明任何候选。
