# 输入复用与真正固定的动作图

3138B源码及6270B完整JSON已按冻结size/SHA核同并全文读取。它针对一般ADM作一份固定完整策略的发现尝试，不枚举固定人数的全部策略。当前0原import/入口、0规范BI/完整树重构、0 LP/随机或新数学程序；只解析报告字段，保原数值身份。

模型与ADM全部cap端点定义见[全端点资源](../资源/可信全端点菜单的别名复核与静态付款下界--资源.md)及[可信全端点菜单的别名复核与静态付款下界](<../资源/可信全端点菜单的别名复核与静态付款下界--资源.md>)。此处终局保全部m=4玩家，插入查询额外加一槽，不删除被强制玩家。

程序读取既有`examples/customer_attraction/root_tax_failure.json`的61客户、六标签A…F输入，调用

```python
ExactSPESolver(ins).certificate(on_path=(2,3,0,0))
```

然后以返回的完整`cert.actions`固定策略σ。它不读取旧root-tax的27707B证书，也不直接使用旧恒A前三位、末位固定优先序的控制器。旧[根总税反例](../反例/四人实际根总税--反例.md)的actual为AAAF、W38；这里强制的actual是CDAA。按同一输入表仅对该路径展开，A、C、D两两不交，故实际利润为(11,10,15,15)，W51；这是路径客户表的解析代入，非本次重跑BI或全历史认证。不同actual和离轨动作图不能借旧税探针的锥对偶认证。

已完整读规范model/exact/certificate/init四模块；certificate默认在非actual孩子选使当前强制者收益最小的子SPE终局，平局选排序首项；actual有序前缀取指定路径，其余节点选首个admissible动作。它返回全部1+6+36+216=259个有序决策键。该规则只重构**一份**完整SPE，不是全部完整策略。当前没有生成或保存这259动作；冻结报告也不含动作表、全部IC矩阵或菜单计数，不能以它替代一份可独立核的原始/对偶证书。

# 全类型重权、真实IC与完整插入菜单

原客户只用于选出σ；优化变量w放开全部63个非空兴趣掩码B=1…63，而非仅原12个正类型。实数非负重数用于发现，有理点统一清分母才可解释成不同单位客户；主题可能空或同覆盖、所有动作始终共同可选。

`term(h)`按原**有序**history递归追加acts[h]，终端返回六维计数。缓存键仍为history，未按计数统一σ。对每个history h、规定a及每个b≠a，生成行

\[
C_{h,b;B}=\frac{\mathbf1_{a\in B}}{c_B(term(h))}
-\frac{\mathbf1_{b\in B}}{c_B(term(h,b))}.
\]

当前被选主题在对应叶中实际出现，非零分子时分母正；`payoff`仍将零分母项置0。所有过去、当前和改变后的真实后继都计入叶负载。完整非自身比较原有259×5=1295行，源码在float域按`np.unique`去重，报告记325行；325不是决策历史数、全部SPE数或当前重算结果。全部符号仍为规定收益减真实偏离收益，弱锥为Cw≥0。精确理论复用[固定完整策略锥](../定理/固定完整策略的客户重数锥--定理.md)，但本程序从收益矩阵形成到求解都用NumPy float，没有Fraction证书。

实际终局z=term(∅)，令a_B为被z覆盖指示。全程以a·w=1即**actual福利归一**，不是总客户质量归一。零质量w=0不在此截面，原模型零客户的福利不等式直接为0≤0，不以归一化排除它。每个actual位置i=0,…,3、每个强制动作t=0,…,5形成term(path[:i]+(t,))；对这24个来源的终局计数去重为菜单E_σ，再置

\[
K_{y,t;B}=\frac{\mathbf1_{t\in B}}{1+c_B(y)},\qquad
H_y(p)_B=\sum_t p_tK_{y,t;B}.
\]

这里外部query与强制动作独立。端点计数相同则插入行相同，故菜单去重合法；报告没有保存去重后的菜单数或各格对应，不能补造。所有强制行动仍含actual、空/重复或同覆盖标签。

# 严格唯一尾是充分条件，零裕量并非该条件

如果**全部有序history**的每个不同标签偏离都满足严格C_hw>0，那么末位严格唯一，逐层反向归纳其余尾策略也唯一。对固定actual前缀强制当前动作后，全部尾SPE便只有σ的那一尾；原完整IC又保当前cap，所以D的经济终局恰为这份actual完整菜单E_σ。此时若某p严格使min_(y∈E_σ)G_p(y)>W/m，才是一般ADM的反例证书，而仍须独立验输入、严格IC和分离。

这个归纳是已有[全部历史严格唯一例](../反例/全部历史严格唯一均衡与静态PNE福利的分离--反例.md)及成熟ADM的同一充分逻辑，不是本批新一般定理。允许同覆盖信号时，若仅要求不同经济行动严格，还需在经济商或每个相关尾的端点层证明唯一；不能忽略信号诱发的其他后继。本代码更强地比较每个b≠a的**标签**，不先商同覆盖动作。

弱IC时只有E_σ⊆D：原σ的每个强制孩子是可信尾且当前收益不超actual，但D还可含别的cap合法尾。因此min_D G_p≤min_Eσ G_p，单独分离Eσ并不保证分离D。反之，只要某个Eσ端点够低便足以给该p一个D中低端点；一次局部发现的负gap不是对所有p或整个锥的上界。

# 第一个LP与两步交替的准确方向

第一个LP在w≥0、a·w=1下最大化自由变量δ，要求Cw≥δ·1。源码只assert SciPy success，保存`strict_margin_max=res.x[-1]`，没有精确对偶或逐坐标有理上界。

后续入口条件却是`strict>=-1e-9`，**不是**strict>0。设置η=min(strict/100,10⁻⁶)。对本报告strict=-0.0，η=0，接下去仅保弱IC；若strict是容差内小负数，η还会为负，甚至允许小的Cw负值。正严格唯一尾不能由这条容差条件取得。

初始化依次为15个两标签支持的均匀p及一个六标签均匀p，共16个起点；每起点最多8轮。每轮先固定p解

\[
\max_{w,t}t:\quad w\ge0,\ a\cdot w=1,\ Cw\ge\eta,
\quad H_y(p)\cdot w\ge1/4+t\quad\forall y\in E_\sigma.
\]

若数值失败只break该起点。随后固定这份w解查询LP

\[
\max_{p,v}v:\quad p\ge0,\ \sum p=1,\quad
\sum_t p_tK_{y,t}(w)\ge v\quad\forall y\in E_\sigma,
\]

记录gap=v−1/4。查询更新没有限制仍在原support内；`support`字段只是**起始**支持。第二个LP未检查`pr.success`就取pr.x。两步交替不是对联合(p,w)的全局优化，不能给没找到正gap的精确全域上界。

每轮都保存浮点p/w、gap和min(Cw)。gap>10⁻⁶时内外两层均早停；最终只按gap降序留前5条。因此源计划上限16×8不等于已存128次成功，也不能从5条恢复总LP次数、失败点或全部查询轨迹。没有严格阳性后再恢复有理客户、重算全部IC、精确分离或枚举全部D的验收流程。
