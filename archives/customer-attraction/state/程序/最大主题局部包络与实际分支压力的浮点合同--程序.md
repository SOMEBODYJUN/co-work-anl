# 五份资产和共同模型

五主源依次3655/3238/5403/3550/8429B，共24275B。原件及两个冻结来源位置见[证据包](../../tools/evidence/Boss7-resume-rcd-envelopes/README.md)和[源清单](../../tools/evidence/Boss7-resume-rcd-envelopes/source-manifest.json)，五份JSON中的本页三份已逐字段读完；[完整字段索引](../../tools/evidence/Boss7-resume-rcd-envelopes/complete-json-field-index.json)保每个嵌套键、数组位置和值，包括全部支持质量、活跃乘子和求解消息。这里解释其全部数学和程序合同，不用一个success标记替代审查。

背景是五名单位提供者、任意有限单位客户、有限非空共同标签目录、每个完整有序历史上的纯SPE。空覆盖、重复选择、同覆盖异标签、零客户与离轨任意平局都允许。每客户终局被c人覆盖时每人得1/c。下列列域扩大了真实实例产生的客户类型；它们只检查列出的必要行，未编码一份完整历史策略。

两个不同的必要条件系统分别用稳定子身份 `customer-attraction/single-maximum-root-branch-local-envelope-63-types` 与 `customer-attraction/actual-and-maximum-root-branch-pressure-6144-types` 寻址；它们的浮点报告仅是各自发现记录，不能互换为同一优化问题。

# 单条真实最大主题枝的局部包络

`max_theme_local_envelope.py`的build(k=5,mode)使用k+1=6位
\(b=(b_0,\ldots,b_5)\)：0为最大主题C，1为合法比较T，2,…,5为强制C后原策略真实终局的其余四主题。仅删全部六位为0的无贡献型，恰63型。这个k是终局提供者人数，不是目录大小。令
\[
 c=b_0+b_2+b_3+b_4+b_5,\quad
 C(b)=b_0,\quad r(b)=b_0/c,\quad
 F(b)=b_1/(5\text{ if }b_0=1\text{ else }1).
\]
分子零的份额定义为0。非负质量z_b下归一\(\sum C(b)z_b=1\)，并加根收益帽\(\sum r(b)z_b\le\alpha\)，最大化\(\sum F(b)z_b\)。63型中的质量为实数；没有逐单位客户或全策略实现性断言。

`last`的10行，均按≤0录入：

* 大小5行：b_q−b₀，q=1,…,5，表示每个已命名合法主题大小不超过C。
* 真末位5行：\(b_q/(b_0+b_2+b_3+b_4+1)-b_5/c\)，q=0,…,4。末位自身查询冗余而省去；T和C都保留。

`node`沿行动列表A=(0,2,3,4,5)，在j=1,2,3，即真实第二、三、四位各对六个合法主题加地板行
\[
 \frac{b_q}{\sum_{a\in A[:j]}b_a+5-j}
 -\frac{b_{A[j]}}c\le0,\qquad q=0,\ldots,5.
\]
这是每个原节点改选q、其后仍沿原σ完成时的最坏分母保证，不是冻结末位。故node共10+18=28行；本批没有node报告，不补造其结果。

`tail`还在同枝的末3/4人加既有[三人任意合法背景利润界](../定理/固定背景三人利润界--定理.md)β₃=5/3、[四人任意合法背景利润界](../定理/固定背景四人利润界--定理.md)β₄=1499/750。它们约束的是该剩余子树的总利润V与同背景任意合法比较元组的Σe/(p+e)，并非把零背景覆盖界平移过去；截取原完整σ的真后继子树满足所需SPE。对剩余人数r及六标签任意r重组合Q，行是
\[
 \frac{\sum_{q\in Q}b_q}{\sum_{a\in A[:5-r]}b_a+\sum_{q\in Q}b_q}
 -\beta_r\frac{\sum_{a\in A[5-r:]}b_a}{c}\le0.
\]
零分子时首项0；重复索引依发生次数累加。r=3有\(\binom83=56\)行，r=4有\(\binom94=126\)行，共210=28+56+126行。没有把多个互斥枝的尾收益重复计入实际W。

命令行仅`--mode last|node|tail`，默认last；k=5和8个α硬编码。依赖NumPy、SciPy/HiGHS；`Fraction`保存若干输入常数，转LP后仍为浮点。根帽依次1/5,21/100,11/50,6/25,1/4,3/10,1/3,2/5。八次求解后才以`open('x')`写旁路文件：last为自身`.json`，其他为`_node.json`或`_tail.json`；已有文件会拒绝覆盖，不自动建目录。main guard防止导入求解。stdout仅保path和每点去掉support、active_multipliers、message后的字段，不等于完整保存报告。

# 实际路径加最大主题根枝：另一个234行系统

`max_root_actual_pressure.py`使用10位b：实际五位置0,…,4及根强制真实最大主题后五位置5,…,9；另加最优比较五元组的覆盖重数e∈{0,…,5}。全域\(2^{10}\cdot6=6144\)型，**包括十位全零但e>0的类型**，这类客户未实际覆盖却贡献比较覆盖，不能删掉。令路径P上的负载c_P、收益份额u_{P,j}=b_{P_j}/c_P，w=1[实际五位至少一个1]，o=1[e>0]。归一Σwz=1，最大化Σoz。所有行以≥0录入。

对实际路径j=0,…,4和最大根枝j=1,…,4，令p为该枝当前之前负载、r=5−j：每节点对全部10个已命名标签加
\[
 u_{P,j}-\frac{b_q}{p+r}\ge0\quad(q=0,\ldots,9),
 \qquad5u_{P,j}-\frac e{p+r}\ge0.
\]
最大根枝第一个玩家被强制，不给它枝内最佳回复，只用后面的原根IC。九节点共99行。

定义比较五索引的r子集利润
\[
 B_r(p,e)=\sum_{d=1}^r\binom ed\binom{5-e}{r-d}\frac d{p+d},
\]
组合数非法下标按0。每枝r=2,3,4给
\(\binom5r\beta_r\sum_{\text{该尾}}u-B_r(p,e)\ge0\)，β₂=3/2、β₃=5/3、β₄=1499/750，共6行。β₁=1来自真末位BR；β₂=3/2由[固定背景两人税](../引理/固定背景两人税界--引理.md)及逐客户g_p(B,B)≤V/2得到；β₃、β₄正是上段两个任意合法背景定理。每个r子集均为合法槽元组，故可逐个应用后求和，重复覆盖标签不妨碍索引子集计数。

每枝r=2还设
\[
 H=\sum_{\text{该尾}}u+\frac{b_{P_j}}{(p+1)(p+2)}.
\]
逐客户有H=R_p(B,C)+g_p(B,B)=P_p(B,C)+τ_p(B去C)，其中B、C是该枝末两主题，R是两人收益和、P是两主题势增量、τ是B去C的差集税。因此代码虽对全部B加g_p(B,B)，仍与三IC差集势税一致。用旧三IC两尾税得到10H−B₂(p,e)≥0；并对10标签任意可重复二组合(q,s)给
\(H-(b_q+b_s)/(p+b_q+b_s)\ge0\)，零分子定义0。每枝1+55行，两枝共112。两尾税的q背景、真实后继和额外重叠项见[精确三IC重构](../引理/固定两尾势缺口的三项真实比较--引理.md)，不把H误叫实际尾利润。

最后17行是实际根利润减最大主题根枝第一位利润；10行b₅−b_q；最优平均大小5b₅−e；每个实际i的最坏分母大小界5u_i−b₅。总99+6+112+17=234。最大性是目录全局事实在已命名主题及五个最优索引上的必要投影，未定义其余目录/所有节点。

程序无参数，main内构型并用HiGHS浮点求解一次。输出旁路同名JSON，以`open('x')`拒绝覆盖；stdout去掉support和active_dual。无精确恢复、全树、真正最优五元组搜索或游戏认证。报告11根字段是status/types/rows/success/message/O_over_W/actual_utilities/max_size/rootmax_utilities/active_dual/support；其中status=`floating_template_only`、types=6144、rows=234，正常success。原数值为

\]
实际收益向量
\((0.12310230304854988,0.10914855703362411,0.14553140937816547,0.2637823044656974,0.35843542607396334)\)，

# 全仓比较、运行和可接续边界

这两个系统的对象、归一和可见分支不同：63型是单根枝、C归一、单T的F；6144型是实际加最大根枝、W归一、五索引覆盖。另[107行根查询族](五根查询族仿射压力的精确可行证书与行合同--程序.md)有所有五个比较根枝的仿射平均，而本234行有最大主题/更细尾税；未证明相互包含，2.2608与2.4456不作同域强弱排名。成熟[最大主题标量预算](../障碍/最大主题标量预算--障碍.md)的四变量精确常数83705/36641也是不同投影；旧437/557/728行模板及其输出不在本批新主源范围。

最大主题钱包与倒二加强已有充分解析/精确证据，故本批只重构合同，不再运行这两作者LP。三报告没有历史argv、执行事件或软件指纹，不能补造当年生成时序；base模式字段的缺失照实保留。当前[五人半覆盖](../定理/五人半覆盖--定理.md)已另证，这些旧弱模板不据此获得完整SPE反例身份。它们也没有证明当前六人目标。所有本页原程序本次调用数为0；本证据包唯一新数学调用是另页限定107行证书审计，与本页浮点输出严格区分。
