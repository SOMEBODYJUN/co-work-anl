# 最优支持冻结指派锥探针与有限阴性

## 1. 准确目标与完整策略输入

源为6361字节 `probe_static_opt_matching.py`，两个冻结定位同一blob `b0870510d6bfd92a6d20a2d1113215a49b029d9d`、SHA-256 `8f97417562dcf18c7d62804228bea6e1077396297b1fb050f56d884965b4dd94`。它攻击一个静态辅助接口，不是直接最大化OPT/W。

固定共同目录的p个标签与m名玩家，完整有序策略σ在每个长度小于m的历史给一个动作；包括重复动作、同计数不同顺序、所有离轨历史及任意指定平局。`StrategyCone`先要求动作字典的键恰为全部决策历史，再为每个历史h和不同备选a形成真正沿σ继续的收益差行Γ。源依赖把相同非零行合并，但不把历史压成匿名策略：某权重向量满足全部去重行，当且仅当它满足原全部历史激励。

对非空兴趣类型A⊆{0,…,p−1}，w_A≥0为有理重数。根实际路径z=(z₁,…,zₘ)由σ决定，实际覆盖指示行记为c_z，W=c_z·w。程序将W归一为1；本入口只收2≤m≤4、m≤p≤6，不处理m1、p<m或W0的锥。

其静态查询冻结除i以外的实际动作，再把i替换为a：

$$F_i(a;z)=\sum_{A\ni a}\frac{w_A}{1+\sum_{j=1}^m1_{z_j\in A}-1_{z_i\in A}}.$$

它通常不是“在actual前缀改a、以后沿原σ继续”的真实偏离收益。完整SPE的Γ约束作用于真实偏离；目标函数F却保留冻结的实际后缀，二者不能同义替换。

给m个**互异**标签支持J和其排列π，记q_(J,π)·w=Σ_iF_i(π_i;z)。候选要求存在最优比较支持与某个便宜排列，使该总和≤W。每个最优覆盖中actual未覆盖客户贡献至少1，故该候选若真足以推出OPT≤2W；源并未证明这个存在量词。

## 2. 浮点发现LP与精确接收合同

`try_cone`枚举全部 `combinations(range(p),m)`。对每个拟最优J，以非负w和自由裕量t为变量，解

$$\max t\quad\text{满足}\quad \Gamma w\ge0,\quad c_z\cdot w=1,$$
$$c_K\cdot w\le c_J\cdot w\quad(\text{全部互异m支持 }K),$$
$$q_{J,\pi}\cdot w\ge1+t\quad(\pi\text{遍历}J\text{的全部排列}).$$

LP用SciPy/HiGHS浮点求解；失败、或浮点t<10⁻⁷时跳过。正值不立即接收：

1. 先将每个浮点坐标转为分母至多10⁷的Fraction，检查w≥0、W=1和**每条**LP不等式。
2. 若失败，固定浮点大于10⁻⁸的质量支持和t列，用归一化行及距紧至多10⁻⁷的活跃行作精确Gaussian消元；必须满秩，再重新检查全部行。
3. 若精确t≤0或恢复失败，丢弃此数值候选。
4. 精确复核 `cone.verify(w)` 与W1，再求全部互异支持的精确覆盖最优值；对**全部并列最优支持**逐一算所有排列最小成本。只有这些最小值的最小者严格大于1才返回。

因此即使某J满足LP，另一个并列最优支持可能提供便宜排列，后检仍会拒绝。恢复阶段的阈值只用于选活跃行；最终可行性和严格分离均用Fraction，不将浮点误差认证为反例。失败或无输出不提供精确对偶、统一非负最优值或不可行证明。

接收对象会写非负有理权、清分母并除公因子的整数克隆、根路径、W1、最优值、所有最优支持最小成本及完整策略动作表。整数化在数学上保全部线性IC和严格成本差；本入口不另调用独立单位客户核验器。后续如发布新反例，仍宜按原模型直接重算整数客户全历史，而不能仅引用docstring里的“exact”。

## 3. 互异支持与重复元组的边界

在p≥m时，覆盖的最优**数值**可由m个互异主题达到：小支持可添标签，覆盖不减。因此程序算OPT值不因只枚举m子集而漏掉更大覆盖。

但是“存在某个最优m元组及便宜排列”的预算量词还允许重复主题。最优小支持用重复补齐可能与添互异标签有相同覆盖、不同静态费用；程序未枚举这些重复元组。它的最终后检准确域只是所有互异m支持和排列。若某个保存点的唯一最优覆盖必须用m个标签，所有重复元组自然非最优，才可直接推广为全部最优元组反例。源的docstring没有写出这个条件；本清洗显式保留，不能从一般接收对象直接断言已覆盖所有重复比较选择。

零客户类型可取w_A=0，物理重复标签也可能经相同兴趣关联出现；这与源没有枚举重复**比较槽**是两件事。空兴趣客户不影响任何收益或覆盖；本程序的2^p−1变量省去它们。空主题和零收益行不被禁止，但W1意味着全零实例不在扫描内。
