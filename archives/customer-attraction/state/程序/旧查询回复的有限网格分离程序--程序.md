# 同一原策略中的强制主题与旧查询

固定有限单位客户、有限非空共同主题目录，以及六名单位权提供者依次观察全部有序历史选主题的任意一份完整纯SPE σ；每个客户在最终覆盖它的提供者间均分。实际行动 A₁,…,A₆，收益 u₁,…,u₆；福利等于被覆盖客户数，也等于收益和。令 h=(A₁,A₂,A₃)，在h强制第四位选合法比较主题T_a后，真第五/六位为 B_a,C_a。索引a,b取1至6，显式标签为

\[
R_{0,a,b}=\sigma_6(h,T_a,B_b)\ (a\ne b),\qquad
R_{1,a,b}=\sigma_6(h,T_a,C_b)\ (全部a,b),\qquad
Z_e=\sigma_6(A_1,A_2,A_3,A_4,R_e).
\]

这些主题来自同一目录和同一策略，不把强制动作当作其新节点的BR。程序可在actual前五源再次强制某R_e或Z_e；该新枝的后继被投影消去，不认成另一个已有的同名回复。允许空主题、重复标签、相同覆盖集合、零客户，以及任意离轨历史上的平局。固定一份完整策略只是保其所有同源身份，结论对每一份此类SPE成立。六个T只需合法，下面的行不要求其达到OPT；继承图的其它OPT单换行有另外条件。

八字段 `cut=(i,member,f,diag,qi,mode,aa,mu)` 的前三类索引必须分开：

| 字段 | 语义 |
|---|---|
| i=0,…,4 | 实际第i+1位源，隐藏后继数n=5−i；不是轨道的比较主题索引。 |
| member=0/1 | 强制主题分别取R_e/Z_e。 |
| (f,diag) | `GS=((0,0),(1,0),(1,1))`；轨道分别为family0非对角、family1非对角、family1对角，边数c=30,30,6。没有family0对角。 |
| qi=0,…,5 | 合法旧查询依次为T_a,B_a,C_a,T_b,B_b,C_b；不是实际A的六位。 |
| mode | `all`给全部n个后继同一价格aa；`last`只给最后后继aa，中间价格为0。 |
| aa,mu | 非负有理价格和强制分支末位查询Q的IC乘子；容量乘子β全0。 |

一般 `row/psi` 调用不验证所有枚举字段；源码对任何非`all`的mode都走last分支。这里的正式合同只使用上述两个合法字符串和给定范围，不把任意外来JSON自动当成已验证的cut。

# 隐藏会员最小化与精确行读出

对一个客户，a∈{0,1}⁶是actual会员，`p=sum(a[:i])`，`ell=sum(a[:5])`。令t为强制主题会员、q为查询主题会员，隐藏后继f₁,…,f_n，g=f_n，z=p+t+Σf。设置α为全部aa或仅末项aa，定义

\[
\psi_i(p,\ell,t,q)=\min_{f\in\{0,1\}^{n}}
\left\{\frac t z+\frac{\sum_j\alpha_jf_j}{\ell+1}
-\mu\frac g z+\mu\frac q{p+t+\sum_{j<n}f_j+1}\right\}.
\]

零分子份额按0。非零分子对应正分母，因此p=t=Σf=0时没有非法0/0。`psi`调用任意尾长核心；中间价格同值，固定中间1位数s与末位g后，字面2ⁿ域压成2n候选。固定n=1时all与last的α完全相同，不只是aa=1时相同。

由[共同末位价格投影引理](../引理/共同末位报价与隐藏回复投影--引理.md)，对轨道各边应用源IC、实际末位查询所有合法后继的价格行、分支末位查询Q的IC，再取客户最小值得

\[
c\,[u_{i+1}+N_\alpha u_6]-
\sum_{e\in E_{f,diag}}\sum_x\psi_i(p_x,\ell_x,1_{F_e}(x),1_{Q_e}(x))\ge0,
\quad N_\alpha=\begin{cases}n\,aa&mode=all,\\aa&mode=last.\end{cases}
\]

这一不等式可以直接按一条边复核：源IC为 `u_{i+1}−Σ_x t_x/z_x≥0`；对每个真实后继F_j，actual末位查询它给 `u_6−Σ_x f_{j,x}/(ell_x+1)≥0`，分别乘α_j；强制分支末位查询Q给 `Σ_x[g_x/z_x−q_x/(p_x+t_x+Σ_{j<n}f_{j,x}+1)]≥0`，乘μ。三类非负行相加，恰得 `u_{i+1}+Nαu_6−Σ_x h_x≥0`；再加每个客户的 `h_x−ψ_x≥0` 并对轨道求和，即上式。

因此它对任意原模型SPE有效，不受当前16hist支撑限制；零客户时所有客户和与收益均为0。价格支出须按Nα计入共同预算，不能免费替换不同历史的收益。一般合法性是解析恒等式，有限程序重放不替代其量词证明。

`PAT=product((0,1),repeat=3)`按字典序编码索引词w=(1_T,1_B,1_C)。hist给六个索引在八种词中的计数H_w。`groups(hist)`的非对角边重数为 `H_w H_v−1_(w=v)H_w`；对角只保w=v且重数H_w。其实现确实将对角w≠v排除，不可把所有词对都乘H_w。

`row(cols,cut)`返回Fraction向量，以行点积≥0为约定。hist列放预算 `c*(a_i/Σa+Nα*a_5/Σa)`，扣所有边的t=0基值。相同group的joint-reply列若state[member]=1，放 `−重数*(ψ(t=1)−ψ(t=0))`；其他组、K和overlap列为0。state=(1,1)保同一组R/Z会员，但一条行只读所选member。源代码依赖“每个hist后跟自己的joint块”的列序，使用最近hist而不核 `hist_column_old`，也不负责证明joint三态质量和≤hist、交叠可实现或原图全部约束。

# 九千九百个候选与保存规则

`discover`读JSON全部columns，将权转Fraction。它先计算六个actual收益，再对每个member/轨道/Q按hist收集q=0/1、t=0/1质量。t=1质量由joint三态边缘取得，t=0为相应hist轨道质量减去t=1。此处没有float阈值截断；合法输入的质量条件仍须由输入图或另行核验承担。

参数网格恰为

\[
aa\in\{0,1/8,1/4,1/2,1,2\},\qquad
\mu\in\{0,1/2,1,2,4\}.
\]

5源×2member×3轨道×6Q=180个不含mode的结构。原循环含两mode、六aa、五μ，共10800槽；跳过last且aa=0的900槽，留下all每结构30项、last每结构25项，总9900。跳过的是明显零价格模式重复；i=4的其它all/last重复没有删除。

每个候选精确计算上述预算减ψ总和，只有严格 `<0` 才进入candidates。排序按 `(Fraction余量,完整cut元组)`；之后以 `cut[:6]` 去重，即**包含mode**的结构键，只保每键排序最前的负候选，并在达到64项时停止。因而同一个系数向量可以因不同mode或查询索引被保存多次；最多64项也不等于全部负结构。相同精确余量时以完整元组字典序决定顺序，不按参数数值大小另排。

`candidates_checked`记录全部9900次有效候选计算，`negative_candidates`记录截断前所有严格负参数点，`selected`才是去重/截断结果。程序对每个selected重新用 `row` 与全部点权做精确点积，断言其等于聚合阶段的保存值。没有使用 `-O` 时这些断言生效；负性已经由精确筛选保证，不是一个浮点容差判断。

独立命令要求两个位置参数：输入点和输出JSON路径；会覆盖指定输出。报告另保存scope、输入路径和直接抄录的W字段，不计算或核对W，也不绑定输入SHA。发现器不验证原图、归一化或SPE，不重优化补行后的点。对一个固定合法输入，本有限网格的全部9900项确被穷尽；这个准确的有限阴性结果仍不约束网格外的有理价格、连续族或更多查询主题。
