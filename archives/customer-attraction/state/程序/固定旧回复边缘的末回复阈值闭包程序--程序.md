# 原程序解决的有限问题

主源 `9c82a1b1090372077fec` 的[原码](../../tools/evidence/full156-pair-master-point/related/zz_threshold_closure.py)为8353B，SHA-256为 `959d52f297152b1f2ae5e07834c56ed94f87a5cef0cf252acf2a2d0071a0b7eb`，两冻结提交同字节。全文包括导入、四模式、阈值分层、旧图代换、60行构造、浮点可行性、精确恢复及verify分支均已实读。

程序给定一个旧必要图点，固定其hist质量、K和旧回复R的边缘，把全部R放进同一个阈值联合分布，重新选择末回复Z，再要求旧图和全部所列Z→Z聚合行成立。**旧Z边缘、旧(R,Z)二维边缘及旧R-R辅助交叠并未固定。** 目标是零目标的有限可行性，不是最小化福利，也不是生成完整策略。

本次唯一原默认入口 `zz_threshold_closure.py --verify` 精确通过3949行、321个变量，最小余量0；没有求发现LP。另逐项读取三个冻结输出的全部898个变量，独立核元数据绑定、质量界和180个Z→Z行。split/cross的旧图不由这项局部核重新认证。具体原事件、来源与可重放清单见[证据说明](../../tools/evidence/zz-threshold-closure-program/README.md)。

# 真末回复的身份与行的来源

仍用[共同目录完整历史模型](../定义/共同目录完整历史模型--定义.md)：有限单位客户、共同有限非空主题目录、六名单位提供者按全部有序历史行动，客户在终局覆盖者之间均分。空主题、重复行动、零客户以及任意离轨平局均保留。

为说明必要行，固定一份完整纯SPE σ，实际路径为A₁,…,A₆。令h=(A₁,A₂,A₃)，六个比较主题为T₁,…,T₆，强制第四位Tᵢ后的真两人尾为Bᵢ,Cᵢ；旧图中的最优单换行还要求T元组是真最优比较元组。定义带索引边

\[
E_0=\{(0,i,j):i,j\in[6],i\ne j\},\quad E_1=\{(1,i,j):i,j\in[6]\},
\]
\[
R_{0ij}=\sigma_6(h,T_i,B_j),\quad R_{1ij}=\sigma_6(h,T_i,C_j),\quad
Z_e=\sigma_6(A_1,A_2,A_3,A_4,R_e).
\]

共30+36=66条索引边。R、Z是在各自源历史的真末位回复；强制的第四/第五行动本身不被当作最佳回复。令客户x在实际前四题的负载为pₐ(x)。对任意e,f∈E，Z_f是同目录合法查询，因此

\[
\sum_x\frac{\mathbf1_{Z_e}(x)-\mathbf1_{Z_f}(x)}{p_a(x)+1+\mathbf1_{R_e}(x)}\ge0.\tag{1}
\]

分母始终正；零分子贡献0。这里只在最后一步改选主题，没有冻结偏离后的未来行动。按边族对和四索引的相等模式相加，得到程序的60个槽。给定SPE推出这些行；有限行点没有提供这样的σ，不能反向沿用标签的真实来源。

# 输入坐标与阈值仿射代换

四个源点使用同一1905列描述：1个K、16个hist、194组各三态的582个joint-reply、1306个旧R-R交叠。hist给实际六会员位a、六个比较索引词wᵢ=(Tᵢ,Bᵢ,Cᵢ)的八桶计数和质量H；八词按000至111排序。回复组

\[
g(e)=(\mathrm{family}(e),\mathbf1_{i=j},w_i,w_j)
\]

保留索引相等与词相等的区别，不能把相同词的不同索引合并。三存量x₀₁,x₁₀,x₁₁是未归一化质量，隐含x₀₀=H−x₀₁−x₁₀−x₁₁；R边缘q_g=x₁₀+x₁₁。程序按最近hist绑定joint列，并要求构图返回的全部列去掉weight后与源点JSON序列完全相同。它不提供一般输入结构验证器；当前三个源点的全1905列及194组四态另经独立核对，均非负，0≤q_g≤H，零质量hist的三态皆0。

对H>0取切点集合{0,H,q_g:g}，按相邻点生成正质量层s=[l_s,u_s)，记m_s=u_s−l_s。令

\[
r_{s,g}=\mathbf1[u_s\le q_g],\qquad 0\le z_{s,g}\le m_s.
\tag{2}
\]

z是该层Z_g的质量，不是互斥类型质量；不能把所有z相加当客户总量。R在同一[0,H)中定义为[0,q_g)，所以层内R位固定。每层每组记录hist_column、left、right、group、r五个描述，再附有理weight。零质量hist不生成层，不作条件除零。

旧坐标恢复为

\[
x'_{10,g}=\sum_{s:r_{s,g}=1}(m_s-z_{s,g}),\quad
x'_{11,g}=\sum_{s:r_{s,g}=1}z_{s,g},\quad
x'_{01,g}=\sum_{s:r_{s,g}=0}z_{s,g}.
\tag{3}
\]

R边缘仍q_g，hist及K不变，R-R交叠改为min(q_g,q_f)。隐含00由r=0层的m_s−z得到。故各组有真实非负四态，但一般不等于源点的旧四态；旧交叠是辅助坐标，不能不经证明认作原真实集合交。

源码形成长度1905的base及各列对z的稀疏mapping。对每个旧行\(\sum_j M_{ij}x_j\ge0\)，精确代入\(x=base+mapping\,z\)，得到

\[
b_i+\sum_v A_{iv}z_v\ge0.\tag{4}
\]

这就是旧行在新Z处的重新约束；不能从原旧点PASS直接继承其值。所有实际路径覆盖和比较覆盖只依hist，故W与O固定。本次三个源点的16个hist均d=1、总质量O=1；独立从a中是否有1重算W。程序自身只是打印/保存源JSON的W，写死O为1。

# 六十个聚合行与共同会员实现

四索引按首次出现重编号，如(5,2,5,5)成为(0,1,0,0)，共有15种模式。源码对每层的66²个有序边对逐个累加；族对有4种，故预置60行。对e=(f,i,j)、e'=(g,k,l)，其层贡献是

\[
\frac{z_{s,g(e)}-z_{s,g(e')}}{p_a+1+r_{s,g(e)}}.\tag{5}
\]

不再乘层质量，因为z已经是质量；相同组的源、目标项会相消。重复词、相同主题或对角索引仍按各自出现重数进入相等模式。E₀禁止i=j，造成族对00/01/10/11实际分别只有7/10/10/15个非空模式，合42个；另18槽为空。因此60不是60个独立非空约束，最小余量0可能来自空行。

式(2)的任意可行z都能作共同会员实现：在质量m_s的层内，对所有Z_g取条件独立二元位，概率为z_{s,g}/m_s；各位赋值的乘积概率乘m_s给有限非负原子质量。R位已确定，因而(3)、全部旧R-R交叠、所用R-Z交叠以及(5)均同时得到正确积分。有理输入产生有限有理质量，可清分母为单位客户副本。独立性是构造手段，不是对原SPE或客户的额外假设。

这一证明只实现上述会员量和所列聚合行；没有给全部有序历史的行动、每个后继的真实续局或完整IC。它也未控制新增Z-Z交叠的任意线性式；后续正交叠强PAIR采用另一层共同阈值来同时达到min，见[强配对闭包程序](末回复阈值层的强配对闭包程序--程序.md)及[共同凸抬升](../构造/回复会员阈值的共同凸抬升与对角预算拆分--构造.md)。

# 浮点发现与精确验证的不同承诺

非verify分支将(4)转为−Az≤b，每行除以该行系数绝对值与常数绝对值的最大值，零尺度改1。用HiGHS、零目标、层界及primal/dual容差10⁻⁹寻找可行点。浮点失败只说明该次受限问题的求解状态，没有精确不可行证书，更不排全客户域。

成功先保存`PREFIX_float.npz`。随后把值<10⁻⁹的变量置0，距上界<10⁻⁹者置上界，其余列为free；取缩放残差绝对值≤10⁻⁹的行，移去已固定坐标，以Fraction Gauss–Jordan恢复free值。exact_solve要求满列秩及一致性，失败会断言退出。恢复后重新精确查所有层界和全部行，才写exact报告；status最后写。因此恢复异常可能留下新的NPZ和旧exact/status，不能以文件共存证明它们同次成功。

成功exact有十字段：scope、source_sha256、W、O、rows、variables_count、minimum_slack、positive_variables、free_vertex_variables、variables。free计数是此次浮点筛选后送入消元的列数；不能凭它证明全多面体唯一性或福利精确最优。报告没有对偶、完整策略或一般可行性完备保证。

verify仍先重建当前模式的旧图和全部新行，再按保存variables数组位置读取weight；只断言长度、0≤weight≤层质量和所有Fraction余量非负，然后打印行数、变量数、最小余量及源W。它**不比较保存的变量描述、source_sha256、rows、variables_count、O/W或其他报告元字段**；列输入描述的对齐断言不能代替输出变量描述的对齐。必须启用assert，不能用Python -O。下面独立接口核补当前三个输出的这些绑定，但不把局部核升级成三种全图原重放。

# 与已知材料的差别和接续用途

[固定二维诊断程序](固定二维回复边缘的共同阈值诊断程序--程序.md)固定旧(R,Z)二维边缘，在共同阈值R域内连最有利完成仍有六个负Z→Z行。本程序允许Z边缘重排，所以默认3949点可行不与之矛盾。新增内容是可复核的仿射搜索/验证合同与实际可行分层表，而非宣称旧点原坐标整体可实现。

[对角预算拆分](对角回复预算拆分的基础图程序--程序.md)改变旧图；[跨实际源共同报价](旧回复跨实际源的共同报价图程序--程序.md)再加跨源报价和最优单换。它们分别作为本程序模式输入，不能把不同hist/R边缘点混合成同一个共同实现。[强配对闭包](末回复阈值层的强配对闭包程序--程序.md)进一步加RZ/ZZ强PAIR及共同min完成，属于不同程序和点。已有[交叠审查](../审查/必要图交叠坐标与真实集合交的区别--审查.md)解释旧辅助上界为何不足以认作真实集合交；这里通过明确共同阈值实现指定新交叠，仍须重新检查受影响的行。

后续若改变R联合、固定/放开另一组边缘、加入带负交叠或更高联合项的真关系，必须重审表示和约束；不能从“complete cube”一词继承全部历史IC。该程序保留有限低福利必要点及共同会员实现，不提供六人half反例或证明，不处理整个客户类型域的不可行性，也不把有限输入里的零质量跳过解释成从模型删除零客户、空主题、重复或平局。来源、实现、有限检查和后续扩展关系在此说明，阶段三再按真实关系登记。
