## 对象、输入和真实策略范围

本对象完整保存 4772 B 的 [原程序](../../tools/evidence/joint-pair-policy-cone/original/pair_joint.py)，并解释其固定路径混合整数模型；没有重跑原 main、candidate、任何原 helper 或 MILP。两份同目录保存表的逐字段处置及一次新定义级诊断见[配套计算对象](<../../../../tools/evidence/phase25-material-attachments/20261103-boss6-triage/cb7f28db7aa9af6d8014.md>)。原首行即说明只是候选生成，数值界不证明定理。

收益与完整历史激励条件沿用[共同目录完整历史模型](../定义/共同目录完整历史模型--定义.md)，行动域采用该页另列的软件**有限标签扩展**：n 名单位提供者依序观察完整有序历史，从 k 个共同标签中选择主题；单位客户在最终覆盖自己的提供者之间均分。客户按非空兴趣集合 M⊆{0,…,k−1} 压缩，质量 w_M≥0；类型编号为通常的低位掩码，标签 a 对应 bit a，数组下标 M−1。整数重数表示多个不同单位客户，有理重数可统一清分母；实数质量是候选搜索域，浮点坐标不是自动合法的单位客户实例。全零兴趣类型对所有收益和覆盖均无贡献而省去。

定义页的主约定是严格集合目录 \(\mathcal S\subseteq2^N\)，不是把同覆盖别名天然视为不同集合。本程序明确保留每个原标签及全部标签历史。覆盖互异时可直接按严格集合目录解读；有别名时，所证完整σ首先是有限标签SPE。合并别名须另证指定全历史σ在商后的历史上良定义并保持全部真实偏离，本页不默认其可下降，不删别名，也不自动将标签扩展的见证迁成严格集合目录的同一输入。

所有标签始终可选，允许空主题、相同覆盖的不同标签、重复行动以及任意平局。原问题量化全部完整有序历史策略；本程序主动限制为 **计数策略**：令 q_a 是先前选择 a 的次数，规定动作 σ(q) 只依赖 q，不能对同计数而顺序不同的历史选择不同平局。模型不删除离轨节点，但这种统一选择限制确实小于一般完整策略域。精确找到一份该类 SPE 可以作存在见证；在此类没有找到不能排除其他历史依赖 SPE。

程序把 n 定为 path 的长度，主入口默认 k=6、path=(0,1,2,3)，数学上 intended 域为 k≥1、n≥3、path∈{0,…,k−1}ⁿ、合法概率分布 p 与 Q。没有外部旧背景输入：这里 Space(n,k) 是空根，不能借依赖文件另有 residual_space 就称支持任意前缀。固定 path 的前两行动形成尾安全问题的合法背景；实际终局也被固定，策略及客户质量仍为变量。

## 两种静态分布和目标方向

在质量 w 上定义真正的静态安全值

\[
v_r(b;w)=\max_{p\in\Delta_k}\min_{H\in[k]^{r-1}}
\sum_M w_M\frac{\sum_{a\in M}p_a}{1+b_M+c_M(H)}.
\]

竞争主题在查询随机实现之前固定，允许相关与重复；不能观察查询后改选背景。相同多重集的静态行相同，所以枚举无序多重集即可，但没有因此商掉完整策略的有序历史。设固定 path 为 z，前两位最终收益和为 d(w)=U_{z₁}(z;w)+U_{z₂}(z;w)。尾背景 b_M=1[z₁∈M]+1[z₂∈M]，剩余 n−2 人，其静态对手有 n−3 个槽。对固定合法 p,Q，令

\[
\ell_p(w)=\min_{H\in\operatorname{Multi}_{n-1}[k]}
\sum_Mw_M\frac{\sum_{a\in M}p_a}{1+c_M(H)},
\quad C_Q(w)=\max_a\sum_BQ_B\sum_{M\ni a}\frac{w_M}{1+b_M+c_M(B)}.
\]

根查询给 ℓ_p≤v_n(0)，尾固定对手分布给 C_Q≥v_{n−2}(b)。故实际两步候选 PAIR 的左差 g 满足

\[
g=d+(n-2)v_{n-2}(b)-n v_n(0)
\le D=d+(n-2)C_Q-n\ell_p. \tag{1}
\]

模型用 t≤每个根 p 平均行、h≥每个尾 Q 平均查询行，最小化 d−nt+(n−2)h。固定 w 时正负系数推动 t=ℓ_p、h=C_Q。对于非负归一质量，这两值在 [0,1]，因而源码对 t,h 的 [0,1] 界没有丢失这一精确最优选择。

若给出严格负的**精确**可行点，还需合法 p,Q、非负有理质量及完整真实 IC，才可凭 (1) 反驳该固定空根 PAIR。非负目标只是 g 的一个非负上界，不能推出 g≥0。浮点负数、时间限制、没有 incumbent 或固定分布搜索都不是一般安全链、覆盖 half 或任意完整 SPE 的结论。PAIR 的条件望远镜作用见[两步安全链对象](../候选/两步安全链的条件归并与有限探索边界--候选.md)。

## 二元控制器如何编码完整可信性

令 \(\mathcal C=\bigcup_{d=0}^{n-1}\{q\in\mathbb Z_+^k:\sum q=d\}\)，节点数
\(N=\binom{k+n-1}{n-1}\)。每个节点 q 和标签 a 有二元 z_{q,a}，并要求 Σ_a z_{q,a}=1；所选标签就是 σ(q)。固定 path 每个前缀的对应 z 被上下界同时设为 1。另有连续 U_{q,t}，表示当前计数继续按选定策略后，终局中标签 t 的份额函数。

终局计数 c 的表达式为

\[
E_{c,t}(w)=\sum_{M\ni t,\ c(M)>0}\frac{w_M}{c(M)}.
\]

辅助坐标 t 可以暂未被选择；若 c(M)=0，helper 采用零贡献。它不宣称这是额外插入一人的反事实收益。承重 IC 的规定行动和偏离行动都真实出现在各自终局，相关分母必正。非终局的 E_{q,t} 定义为 U_{q,t}。归一 Σ_Mw_M=1 后，所有这样的终局表达式在 [0,1]。

源码对每个 (q,a,t) 写两条 big-M 行

\[
U_{q,t}-E_{q+e_a,t}+z_{q,a}\le1,
\qquad U_{q,t}-E_{q+e_a,t}-z_{q,a}\ge-1. \tag{2}
\]

z_{q,a}=1 时强制等式传播；z=0 时由两项均在 [0,1]，两行自动成立，所以 M=1 在此归一域足够。对每个 b≠a 再写

\[
U_{q,a}-E_{q+e_b,b}-z_{q,a}\ge-1. \tag{3}
\]

当 a 被选中时，(3) 正是规定最终收益≥偏离 b 后真实后继最终收益；未选中时自动放松。不存在选择后把偏离后继冻结成实际路径的问题：q+e_b 的控制器另有完整下游约束。

由于 q 的总量逐层增加，(2) 从末层向前确定每个 U 为该策略的真实终局份额。把 σ(q) 提升为 σ(h)=σ(count(h))，(3) 就逐一适用于每个有序历史 h 的所有非自身偏离；自身比较恒等于零。于是**精确可行模型**给一份完整纯 SPE。反过来，任何与 path 一致的计数型完整 SPE、合法归一质量，若满足本模型的全兴趣剔除及固定 p/Q 条件，填写其真实份额、t=ℓ_p、h=C_Q 就满足这些行。因此这里的 big-M 形式在该受限计数域没有放松真实 IC；数值求解容差和策略域限制仍须另算。

模型维数逐项为

| 对象 | 一般数量 | k=6,n=4 |
|---|---:|---:|
| 非空类型 w | 2ᵏ−1 | 63 |
| 计数节点 N | binom(k+n−1,n−1) | 84 |
| 连续 U | kN | 504 |
| 二元 z | kN | 504 |
| t,h | 2 | 2 |
| 总变量 | 2ᵏ−1+2kN+2 | 1073 |
| 质量等式 | 1 | 1 |
| 每节点选择及传播/IC | 1+k(2k+k−1) | 103 |
| 根背景行 | binom(k+n−2,n−1) | 56 |

| 总行 | 1+N[1+k(3k−1)]+binom(k+n−2,n−1)+k | 8715 |

## 全兴趣去除及其版本后果

当前冻结代码无条件执行 `upper[s.k-1]=0`，即 w_{全标签}=0；没有独立 strip 开关。全兴趣质量 λ 对任一四人终局每人贡献 λ/4，一般 n 人为 λ/n，任何完整策略的 IC 系数为零。根 v_n 和真实前两题后的尾 v_{n−2} 同样增加 λ/n，故 PAIR 系数为 [2+(n−2)−n]λ/n=0。固定的**合法归一** p,Q 也有相同性质。

因此删除全兴趣客户保持严格 PAIR 负例及全部 IC；若原严格负点存在，其余质量必正，可再齐次归一至总质量 1。零客户游戏及纯全兴趣游戏本来 PAIR=0，归一搜索不会把它们当严格负候选。这个解析剔除论证已经收在[两步安全链对象](../候选/两步安全链的条件归并与有限探索边界--候选.md)，本次没有另跑同一个平凡校准。

然而 [joint_0012_345.json](../../tools/evidence/joint-pair-policy-cone/original/joint_0012_345.json) 保存 w₆₃=0.9999999999999981；这违反当前固定零上界近 1，不能用约 10⁻¹³ 数值容差解释。该文件与当前字节的 MILP 可行输出不一致。历史可能存在去除之前的版本，但缺旧代码/完整 argv/进程证据，不能把猜测写成已恢复的运行历史。另有 joint_0123_all 也呈全兴趣停点、其 strip 表无 incumbent，仅作为相关版本线索保存，不代替本三源或重核它们的数学。

## 实际依赖、执行顺序与全部输出

程序通过同目录动态导入 5887 B 的 pair_attack.py；后者再按其自身 `parents[5]` 定位旧 transport_round 中的 22102 B common_q_generator.py，并在该模块顶层导入 6608 B policy_patterns.py。本次这三件均全文实读、绑定字节；稳定副本与具体路径见[证据 README](../../tools/evidence/joint-pair-policy-cone/README.md)。NumPy、SciPy 的 MILP/Bounds/LinearConstraint、稀疏 coo_matrix 是外部数值依赖。这里不导入 canonical customer_attraction 精确求解器。

实际只调用 Space(n,k)、tail_tensor(s,path[:2]) 和解后 full_policy：Space 用 L=lcm(1,…,n) 保存整数终局 pay，生成全部有序历史、终局计数和静态背景；tail_tensor 生成真实两步背景后的 n−3 槽静态矩阵；full_policy 从所有叶子反向恢复规定终局和全部偏离终局，再对相同整数收益行去重、去零以生成 Γ。去重的是相同线性行，所有历史已先覆盖。依赖里的 outcomes、synthesize、saddle、attack、rational_point、freeze、候选库生成和 main 都不被本入口调用；不能借其存在宣称本保存表已有精确认证。

`candidate(k,path,p,Q,seconds)` 创建上述模型，再以 `milp(..., time_limit=seconds, mip_rel_gap=0.0)` 求解一次。计时在构造矩阵之后开始，只测这次 solver 调用，非总墙钟；time_limit 不是精确停止时长承诺。返回时不要求 success，而逐字段保存 status、k、n、path、p、Q、tail_rivals、实际 solver seconds、整数 milp_status、原 message、fun 或 null、variables、binaries、rows 共 14 项。

若 z.x 不是 None，直接对每节点 z 坐标取最大者（并列保最小标签），并未先精确检查整数性、one-hot、变量界或全部 MILP 行。其后附加 weights、count_policy、floating_min_full_Gamma、full_policy、actual_root_counts 五项，总计 19 项。full_policy 是真正全部 ordered 历史，而 floating_min_full_Gamma 只是去重非零整数 Γ 在 float w 上计算再除 L；原码没有 Fraction 恢复、容差分类或负数拒绝。尤其没有保存 U、完整 z、t/h、每行余量、节点数、对偶界或完整 OptimizeResult，无法仅从 JSON 重演全部数值求解状态。

CLI 默认 `--k 6 --path 0,1,2,3 --tail all --seconds 45`，`--output` 必需。根 p 被设为均匀；tail 为 all 或逗号整数标签集合时，Q 对所有仅含 chosen 标签的无序 n−3 元组赋相同权重，再除总数。这是对多重集均匀，n>4 时不是各槽 iid 均匀产生的多项式权重。tail 名单重复不增权；模型候选函数自身接受外部 p/Q，却没有校验其概率性质。main 只运行一个 MILP，不是随机扫描。

输出通过 write_text 覆盖目标文件，父目录不自动创建；stdout 删去 weights、count_policy、full_policy 三大数组，其余包括 minΓ 和 rootcounts 保留。无运行环境、源码 SHA、原命令、退出状态或计时起点 metadata。两个当前主报告实际 path=0012、Q 支撑 3/4/5，与默认 path/tail 不同；约 50 秒字段也不等于已知 `--seconds 50` 请求。没有原 argv 时不能补造历史命令。

## 异常、边界及接续用途

数学合同要求有效标签和 n≥3；源码没有系统输入验证。短 path 会使 n−3 的多重集枚举或 path[0:2] 的后续使用失败；非法 path 标签可能在 z 键或数组处报错。k≤0、错误维度 p/Q、非数值 seconds 也不属于已验证域。n>3 且 chosen 与目录无交集时 Q 总和为零，归一产生无效值；n=3 的唯一尾背景是空元组，对任何 chosen 都满足空集条件。k=1 时唯一非空类型同时是全兴趣，Σw=1 与该质量上界 0 精确冲突。若某退化设置使 full_policy 去零后的 Γ 为空，直接 np.min 亦无空集分支。这里不把未处理异常冒成“安全”返回。

原模型的任意平局仍可出现；本数值 argmax 只恢复一份统一计数选择，不能证明其他平局不存在。空题和同覆盖标签始终在完整行动域，零客户的数学平凡性与程序强制 Σw=1 必须分开。没有从测试结果删这些情况，也没有用非必要图点代替 SPE。

与[旧固定完整策略锥程序](<../../../../tools/evidence/phase25-material-attachments/20261103-boss6-triage/99cf885c91440b214c23.md>)相比，本程序把 σ 也作为二元变量，但只在计数子类里联合选择；旧程序固定 σ 后交替 p/Q/w，并非本1073变量模型。与[首对安全值探针](合法背景首两人安全比的有限探针与三个取等点--程序.md)相比，本目标含尾安全补偿，不是 u₁+u₂≥2v_n。已知[任意背景首对额外槽反例](../反例/任意合法背景的前两人额外槽安全值--反例.md)也不自动反驳这个含尾项且当前空根的命题。既有单步亏损、固定21锥证书与本有限模型不能互相顶替。
