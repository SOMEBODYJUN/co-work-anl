# 原程序实际承担什么

[1887B原件](../../tools/evidence/terminal-tax-fixed-policy-probe/original/tax_probe.py)已全文实读，SHA256为 `8f72ad4dc8464ef17883bce8f273faefe55152dd31b35aeee136c8bcf3579e21`，两冻结提交相同。程序固定n=4名提供者、k=6个共同主题标签，先构造一份完整形式策略，再在保持该策略全部真实激励的客户重数锥中，优化全终局税候选的亏损。它不是只检查根路径，也不是枚举全部完整策略。

直接依赖只有标准库、NumPy和SciPy；本源不导入规范SPE求解器。模块顶层会构造全部259个策略动作，导入并非没有计算，但只有main guard中的15个LP与打印在直接运行时发生。名字 `seed` 是12类客户的整数重数字典，**不是随机数种子**；本源没有RNG、循环随机实例或命令行参数解析。

# 目标是全终局税，归一化是总客户质量

设四行动终局z对类型M的覆盖次数为

\[
c_M(z)=\sum_{a\text{ 为 }z\text{ 的一个位置}}\mathbf1_{a\in M}.
\]

重复动作逐位置计算。对任意非负质量向量x_M定义

\[
W(z;x)=\sum_M\mathbf1_{c_M>0}x_M,\quad
\tau(z;x)=\sum_M\frac{c_M}{c_M+1}x_M.
\tag{1}
\]

c=0的税项为0。税是研究中的分母预算，不是另外向客户征收或改变玩家效用。对固定比较支持C，覆盖为 `O_C(x)=Σ_M 1_(M∩C≠∅)x_M`。待搜索的违反方向是

\[
V_C(x)=O_C(x)-W(z;x)-\tau(z;x)>0.
\tag{2}
\]

源码传给最小化器的cost恰为−V_C，故 `res.fun` 为 `W+τ−O_C`，stdout `value=-f` 则为相反方向的最大违反值。不能漏掉W，或将正的最小安全余量当反例。

完整终局税候选是 `OPT₄≤W+τ`。由于覆盖客户1≤c≤4，有τ≤4W/5，所以该候选若普遍成立会给OPT₄≤9W/5；一般m则给(2−1/(m+1))W。候选本身仍需证明，不能由预算上界或有限阴性计算推出。零客户时所有量为0，不使用除W或严格不等式。

对上述AAAF旧例，18个客户负载3、12个负载4、8个负载1，因此

\[
\tau=18\cdot3/4+12\cdot4/5+8\cdot1/2=271/10,
\quad W+\tau-OPT_4=41/10>0.
\tag{3}
\]

这来自旧客户表的静态代入，不是新发现的全局税证明。与只计前三步的负余量1/2完全不同。

本源每次LP约束是 `Σ_M x_M=1`，即非空兴趣客户总质量归一化；不是W=1。新质量可能分给seed未使用的51种类型。任意非零有理点清分母可回到整数单位客户，但浮点数、截断后的坐标与原seed客户不能互相替代。没有兴趣的零掩码客户对所有收益和覆盖贡献0，可以删除；主题空覆盖、相同覆盖标签仍保留在目录中。

# 完整有序树如何变成1554行真实IC

函数 `coef(a,z,M)` 返回 `1/c_M(z)`（a∈M时）或0。其合同要求当前行动a确实在终局z中出现，因而非零分子时分母至少1；这是所有实际调用分支满足的前提，不是任意外来参数的通用错误处理。`cvec`只是将该函数按63类型列成向量，本源main未使用它。

`optimize(sigma)`中缓存递归 `end(h)`：历史长度恰为n时返回有序叶h，否则追加sigma[h]继续。于是 `end(h)` 和 `end(h+(a,))` 分别是规定行动与强制偏离后沿**同一完整动作图真实续局**的终局。改变后继不是把原尾行动冻结；历史元组也没有按计数合并。

对每个sigma键h及六个行动a，规定a₀=sigma[h]，源码生成

\[
\Gamma_{h,a;M}=\frac{\mathbf1_{a_0\in M}}{c_M(\mathrm{end}(h))}
-\frac{\mathbf1_{a\in M}}{c_M(\mathrm{end}(h,a))}.
\tag{4}
\]

零分子项按0。(4)是规定收益减偏离收益，LP用 `A_ub=-Γ,b_ub=0`，即Γx≥0。所有过去玩家也计入分母；只输出当前玩家收益不等于删掉背景拥挤。

每名玩家在每条子博弈路径只行动一次，因此逐个有序节点比较其全部改选、以后沿原策略，即与完整纯SPE等价。所有弱平局由非严格不等式保留。这里保259×6=1554行，其中259条是自身比较的恒零行，非自身1295条；不去除零行，也不去重相同IC。63列给97902个有理系数。真实四人叶分母1…4，Γ乘12后为整数；这只是精确表示的便利，不是原源码实际用了整数LP。

完整策略来自已认证旧例能解释初始输入，但(4)对**任何合法完整形式策略**都成立。调用者必须给所有6进制长度<4历史的合法动作；源码没有schema检查，缺键、额外过长历史或非法动作可报错或破坏合同。函数仍读取全局n=4、k=6、masks，不是单凭传入字典就自动适应任意人数/目录的API。

# 十五个比较、数值求解与main的实际输出

`optimize`先取得root=end(())，再按每类型计算act=c_M(root)。比较遍历全部 `combinations(range(6),4)`，共15个四个不同标签的支持。对静态四槽最大覆盖，任何更小支持都能扩到四个不同标签而不减少覆盖，因此这些比较足够覆盖真正OPT₄；实际SPE动作仍允许重复。这个归约适用于**覆盖项**，不表示所有真实偏离策略或重复计数目标均可任意去重。

每次求解

\[
\min_{x\ge0}\ (\mathbf1_{c>0}+c/(c+1)-\mathbf1_{M\cap C\ne\varnothing})\cdot x,
\quad\Gamma x\ge0,\quad\mathbf1\cdot x=1.
\tag{5}
\]

Γ先由Fraction精确形成，再转NumPy浮点；cost也是有理式转浮点，使用SciPy HiGHS。成功返回者才加入opts，失败和无界等非success都跳过，无单独报告。若没有成功者，最后 `min(opts,...)` 抛错。数学上对合法完整策略，全兴趣类型M=63质量1使所有行动收益1/4，故每个截面都非空；又被总质量单纯形界住，真实(5)是有界问题。数值失败不是数学不可行性的证书。

返回三项为 `(最小成功fun,其比较支持,其浮点解),root,gam`。只比较成功者的float值；没有精确对偶或对所有失败项的排除。浮点平局保opts中最早加入的支持。

原main无输入参数，直接优化默认sigma一次，先打印 `value/comparator/root`。然后只取w>1e−8的坐标，以 `Fraction(float).limit_denominator(1000000)` 有理化，取全部分母最小公倍数转成整数wi，再精确计算1554个Γ·wi并打印 `weights/minGamma`。它没有断言minGamma≥0，没有核整数重构后目标符号、真正OPT或归一化误差，也没有使用规范证书验证器。即使打印minGamma非负，也只认证固定动作图在该新整数点满足这些已生成行；正的严格税违反还须另算(1)—(2)。源main没有写JSON、候选文件或持久日志。

不能把这段代码说明成“只有通过精确反例验证才输出”。无论f正负它都执行上述有理化打印；若截断/有理化破坏可行性，原程序也仍会打印负minGamma。正式证据必须明确区分float发现、整数点IC与真实税目标。

# 七客户打印点及锐性范围

原main的整数点为B、C、D各一名客户，另四名客户同时喜欢A,E,F，共七单位客户。沿同一sigma实际仍AAAF，四人都从这四名客户各得1，故W4；这四名客户终局负载4，其余未覆盖，税16/5。四题A,B,C,D覆盖全部七客户，所以OPT₄7，

\[
W+\tau-OPT_4=1/5>0,
\quad\frac{W+\tau-OPT_4}{\sum x}=1/35,
\quad\frac{W+\tau-OPT_4}{W}=1/20.
\tag{8}
