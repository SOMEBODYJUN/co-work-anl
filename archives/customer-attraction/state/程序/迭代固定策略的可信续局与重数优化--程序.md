# 数学输入与两层证据

本6661B程序处理共同目录中p个标签和m位依次行动的单位提供者。每位观察全部有序历史，在每个客户的终局覆盖者之间均分该客户价值。非空兴趣类型B⊆{0,…,p−1}的r_B≥0是发现阶段的实质量；最终整数克隆表示不同的单位客户，不是不可分加权客户。空兴趣类型收益与覆盖均为零，可不进入127维表；空主题、相同覆盖标签、重复选择和全部离轨平局保留。

Search的组合接口要求p,m为正整数；原入口三种种子含固定前五标签，直接使用该入口还需p≥5。实际报告p7/m5合法。零福利输入没有专门的比率分支，不能把本发现入口当作处理零客户的完整通用验证器；完整模型仍允许该边界。

本批三原件共1074563B，均用`clean show ID --out`取到独立路径核冻结SHA。两大JSON的每条history/action、每个克隆坐标及全部元数据都已遍历；无损视图可逐值解码回原JSON。保存点、完整字段与当前执行身份在[迭代固定策略的可信续局与重数优化](<迭代固定策略的可信续局与重数优化--程序.md>)，原字节及精确依赖见[证据](../../tools/evidence/iterative-fixed-strategy-20261103b/README.md)。

# 计数缓存的是集合，完整树仍保留有序历史

对终局计数q（|q|=m），程序预计算

\[
 P_{q,a;B}=\begin{cases}1/(\sum_{b\in B}q_b),&a\in B,\ q_a>0,\\0,&\text{否则},\end{cases}
 \quad U_a(q)=\sum_BP_{q,a;B}r_B,
 \quad W(q)=\sum_{B:B\cdot q>0}r_B.
\]

在实际被选行动的收益比较中q_a>0，分母必正。程序对未占用标签的辅助收益坐标置0。p7/m5有462个终局计数、330个决策计数，合792态。

自深向浅，终端R(k)={k}；非终端令

\[
 M(k)=\max_a\min_{q\in R(k+e_a)}U_a(q),\qquad
 R(k)=\bigcup_a\{q\in R(k+e_a):U_a(q)\ge M(k)-10^{-8}\}.
\]

**去掉容差且精确求值**时，这是[完整纯SPE终局全集递推](../算法/完整历史纯SPE终局全集--算法.md)。同计数子博弈可实现的终局集合相同，允许缓存；不要求不同有序历史使用同一动作或同一个续局。当前NumPy实现使用浮点和绝对容差，故生成的集合只作近似候选，不能借精确递推定理直接认证。

根从R(0)选W最小的一个终局target，并在全部\(\binom p{\min(p,m)}\)个最大大小比较支持上求最大覆盖；p7/m5为21个支持。这里返回的`seed_ratio_float`是当前实质量的近似OPT/W；它与后面的固定策略LP目标、最终整数游戏的真实比率是三个层次。

# 真实可信续局展开

在每个**有序**历史h，维护期望终局t与计数k。选满足t∈R(k+e_a)、U_a(t)≥M(k)−10⁻⁸的动作a，写actions[h]=a。规定孩子继续t；对每个b≠a，从

\[
 \{d\in R(k+e_b):U_b(d)\le U_a(t)+10^{-8}\}
\]

挑选真实孩子目标，并递归全部p个孩子。五模式分别偏好最低偏离者收益min、最高收益max、最低福利lowW、最高福利highW，以及不附加筛选的uniform；并列时用同一随机数生成器选择。树键仍是h；并不合并(0,1)与(1,0)。p7/m5输出2801个决策节点及16806条非自身行动边。

精确菜单的非空性、合法性及uniform的全策略正支持见[可信续局重构](../算法/可信续局菜单与完整策略重构--算法.md)。此处浮点容差和有限采样不继承精确认证或穷尽性；尤其不同孩子若被容差误纳，只有后面的精确固定锥恢复能承担最终接受点的合法性。

# 固定完整树后的线性合同

对每个h及b≠σ(h)，沿这**同一棵**完整树分别完成规定行动和强制b后的真实续局，得q_h、q_hb。激励行

\[
 G_{h,b;B}=P_{q_h,\sigma(h);B}-P_{q_{hb},b;B}.
\]

固定树成为纯SPE恰等价于r≥0、Gr≥0。完整树不能只验根路径，偏离以后也不能冻结原尾部。[固定完整策略的逐目标对偶](../等价/固定完整策略的逐目标半覆盖对偶--等价.md)证明这个等价及其完整量词。

当前浮点策略生成器先按(终局索引,规定行动,偏离终局索引,偏离行动)去重，再以NumPy浮点行去重为A。对一个指定比较支持J解

\[
 \max v^J\cdot r\quad\text{s.t. }Ar\ge0,\ w\cdot r=1,\ r\ge0,
 \quad v^J_B=\mathbf1_{B\cap J\ne\varnothing}.
\]

这次每轮只试“当前种子最优支持j，加至多三个随机支持”，去重后至多四个；不是每轮解全部21个LP。报告`rows`是这一步浮点A的行数，不能自动等同另建Fraction锥的去零去重行数。保存的常0策略碰巧两者均1260行。

若浮点值严格刷新当前best（阈值10⁻⁸），才重新创建精确`StrategyCone`。它由全树再生Fraction矩阵G，另解一个固定J的LP；原浮点重数可被更换，并非逐坐标给原向量盖精确印章。helper先限分母10⁷核原始点，必要时从近活跃行做精确消元，再核非负、全部IC及w·r=1。`certified`只表示精确原始可行；对偶β、μ还需另核

\[
 \mu\ge0,\qquad \beta w-G^{\mathsf T}\mu-v^J\ge0.
\]

只有β等于恢复点目标时才输出精确最优对偶。`exact_export`清分母并除整体gcd，将其转为单位克隆；直接逐历史检查后再调用规范证书器，精确枚举全目录OPT，保存真实OPT/W。固定J的`objective_value`一般只≤真实`ratio`，不能将两者无条件混同；双保存点中恰都相等。

无对偶的可行点仍是有效完整SPE输入，但不给该固定锥最优上界。有对偶也只覆盖指定σ和J；要统一到全部策略和全部比较主题，还欠独立全称论证。

# 队列、扰动、重复和输出

三个初始实向量按mask索引，未列项均0：big是1:m和2^a:1（a=1…p−1）；reply是2:1、4:1、8:1、9:1、16:1、17:2、26:1、28:1；overlap是1:10、2:4、4:8、6:2、8:16、12:1、16:32、17:1、24:2。后两者还给a≥5的单例2^a各加1。这些是原种子，并非最终保存的九客户向量。

各轮优先按下标取队列，超出队列才随机取；it≥3且it≡3 mod4时做三次坐标增加，每次增加当前max(r.max(),1)乘0.01、0.05或0.2之一。注释称“integer perturbations”，实际运算是实浮点扰动。五模式按min/max/lowW/highW/uniform循环。完整动作表的Python hash用于seen去重，属于有限搜索控制，不是数学同构判定或无碰撞证书。

局部LP成功后将原浮点out.x追加队列，source名LPn引用的是这层浮点向量，不表示第n轮已有导出的精确实例。重复策略或本轮没有成功LP都会跳过记录；日志缺编号不能仅凭缺号判定哪一种原因。报告只在成功记录后覆盖写output；不会自动创建输出父目录，也不拒绝已存在文件。原CLI默认p7/m5、rounds20、seed20261021；报告未保存argv、rounds或环境，不能由默认参数补造原运行事件。

保存报告有14条日志，编号0、1、2、4、5、6、7、8、10、11、14、15、18、19；只有0带ratio_exact=9/5，batch仅一棵完整树。完整数值在双保存点正文逐项列出。13条LP_float=1.8，一条为1.6，不能据有限阴性声称9/5为一般五人上界。当前五人half由[独立普遍定理](../定理/五人半覆盖--定理.md)承担；恰六人仍开放。
