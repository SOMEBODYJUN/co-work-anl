# theta_attack的交替目标、真实值和终止

对所有非负背景计数b、Σb=m−1与查询a，定义

\[
J_{b,a,S}=\frac{\mathbf1_{a\in S}}{1+\sum_{t\in S}b_t},\qquad
\theta(x)=\min_b\max_a J_{b,a}x.
\]

源码counts枚举全部背景计数，joining保存形状(\(\binom{p+m-2}{p-1}\),p,2^p−1)的数组；这是静态收益计数合并，不强制原σ匿名。每轮先对**每个背景**各选argmax_a，平局选首索引，再在Gx≥0、wx=1、x,t≥0下最大化t且要求所选各行J_{b,a_b}x≥t。所得t是theta的可行下界；随后重新计算全部max/min的真浮点theta并比较，不能把固定响应选择器的LP当theta全局凹优化。

最多12轮；LP不成功即返回此前best，未严格提升10^−9也停止；None可表示本调用未拿到成功点。所有浮点SPE约束、归一与theta重算都是候选生成，未调用有理锥verify或输出原始/对偶证书。它优化适应背景的θ，**不**优化真正不观察抽样查询的混合安全值v。

main使用Random(6712)，依次读取aggregate_theta_failure、individual_security_failure、root_tax_failure、prefix_balance_failure、root_stationary_kernel、eight_cce_welfare_gap六个examples；每例四次，从该原输入最坏终局中抽样，再以uniform_credible构完整锥。换质量后未重选σ，但完整G保持原σ的可行性；没有要求它仍为新输入最坏SPE。打印seed名、sample、p/m、theta_per_W、W_per_theta、m−1/2、根计数、压缩行数；theta>1/(m−1/2)+10^−8才写theta_float_candidate.json并仅break当前例的四次循环。该文件只保存p/m/theta/weights/actions对，没有整数实例和独立验证，后例可覆盖。没有冻结输出，因此本次不补造当年24次探索结果。

弱θ桥后来已有[全k复制反例](../反例/不交复制块的弱末位门槛与真正安全值--反例.md)，故该探针的直接目的已被真实构造替代；源码仍保存一种可复用固定策略搜索接口，并不证明这条桥或一般half。

# union_extension_attack攻击的究竟是哪一个量

它读取对象式actions[{history,action},…]的证书；不是seed_source的[history,action]对。缺该结构、p>7或m>5直接跳过。p和m由动作/历史推断，随后StrategyCone严格检查整个所推断树；代码并未从对应实例JSON验证目录规模或另读原客户质量。动作列表转dict会覆盖重复历史；本九输入无重复且键域完整。

固定原σ的根覆盖系数w_S∈{0,1}。对每个恰min(m,p)不同标签支持J，令

\[
l_{J,S}=\mathbf1_{S\cap J\ne\varnothing}(1-w_S),\qquad
\max_{x\ge0,Gx\ge0,wx=1}l_Jx.
\]

l_Jx是比较主题并集**未被实际σ覆盖的客户质量/W**。非负覆盖允许将小支持补到该大小，因此覆盖所有至多m比较主题；但它不是OPT/W，也不是净差(OPT−W)/W。原actual覆盖在比较并集外的客户没有在目标中抵扣。

LP只提浮点proposal。每次改善10^−9，先将每坐标limit_denominator(10^7)；若非精确Gx≥0或wx≠1，再调用recover_vertex。只有恢复成功且全部精确检查通过，exact_ratio才是有理数；否则可为null，best仍可能记录该更高浮点proposal。保存一个精确可行原始点证明**可达到的下界**，不证明这个固定锥或该J的最优上界。未输出精确对偶，浮点成功和阴性不能充作普遍证书。

当精确比>1，才清分母、构整数单位客户、调用规范完整历史verify并写union_extension_counterexample.json，显式标auxiliary union-extension而非half反例。这里即使遗漏>W，仍可能因actual-only客户使净差≤W。main按文件名字典序扫描当前证书glob，累计每个有效输入记录并逐次覆盖run；遇第一份精确阳性则停止。未记录全部跳过文件、失败LP或实际glob全集。
