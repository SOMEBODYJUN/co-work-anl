# 固定游戏、固定路径和全部真实续局

1942B原码全文读取，双冻结身份及原字节在[源清单](../../tools/evidence/menu-price-and-prescribed-prefix-audits-primary/source-manifest.json)。它导入已正式保存的[bigint_controller_attack](../../tools/evidence/bigint-interval-bi-and-controller-cone-primary/source-root/research/workspaces/customer-attraction/R-5662d5cb0e5845a980ed10a3b3224cb1/research_1/bigint_controller_attack.py)中的Attack、ExactPayoffs、solve、HERE；进一步需要旁侧[full18_cone_attack](../../tools/evidence/bigint-interval-bi-and-controller-cone-primary/source-root/research/workspaces/customer-attraction/R-5662d5cb0e5845a980ed10a3b3224cb1/research_1/full18_cone_attack.py)、NumPy及SciPy。依赖的完整递推和整数区间证明在[控制器程序对象](十八主题控制器的整数区间逆归纳与浮点策略锥--程序.md)。本入口不调用控制器采样或浮点锥优化。

输入是一份有限原模型客户表：六名单位权提供者、共同有限目录、单位客户的正整数multiplicity紧凑表示、终局覆盖者均分。代码通过计数背景缓存同构后缀游戏的**全部可实现SPE终局计数集合**；不同有序历史仍能各选自己的策略和平局，不是拿一个局部selector代替所有续局。

设完整终局计数为t，标签a在t中的60倍收益为J(t,a)=Σ_{x∈a}60·nₓ/loadₓ(t)。对深度d的计数背景q、每行动a的孩子O(q+eₐ)，依赖代码求

\[
 m_a(q)=\min_{t\in O(q+e_a)}J(t,a),\quad
 f(q)=\max_a m_a(q),\quad
 O(q)=\bigcup_a\{t\in O(q+e_a):J(t,a)\ge f(q)\}.
\]

每个孩子集合非空；离轨孩子可独立取实现最小收益的完整SPE，故该max-min是当前人的精确可保证阈值。整数区间只作筛选，区间重叠时Python大整数回退，真实相等全部保留。这里的“security floor”限定**同一给定输入的完整SPE续局集合**，不是所有任意未来行动的最小值、不是只选某一平局、也不是所有游戏的共同常数。

# 六步指定实际路径的输出合同

本入口硬编码path=(0,1,2,3,4,5)，target=(1,1,1,1,1,1,0,…,0)，深度d=0,…,5时qⱼ=1_{j<d}。它没有读取输入中的actual_path字段；必须明确目录前六标签就是待检查的指定顺序，且players=6、至少六题。虽Attack读取players，solve和本入口写死六层，不能推广称任意人数工具；源码未做这些schema/正重数/非零总数验证。

每层取`floor[d][qi]=(ft,fa)`，这是某个达到f的行动fa和该行动最坏续局的一个终局ft；最小值或最大值相等时只存所选见证，不输出所有等值见证。代码记录：

| 字段 | 精确含义 |
|---|---|
| depth / current_actual_label | 当前深度与指定行动标签topics[d] |
| actual_terminal_retained_here | target是否属于O(q)，即某种剩余行动顺序能达到这份终局计数 |
| actual_terminal_retained_after_actual_action | target是否属于O(q+e_d) |
| actual_player_u_over_total | J(target,d)/(60N)，N为全部multiplicity之和 |
| best_security_action_label | 某个达到f的行动标签topics[fa] |
| SPE_security_floor_over_total | J(ft,fa)/(60N)=f(q)/(60N) |
| strict_floor_gap_over_total | [f(q)−J(target,d)]/(60N) |
| floor_minimizing_terminal_counts | 选出的ft全部目录计数 |

只看到target在O(q)中，不能认证剩余指定**有序**路径：终局计数不记顺序。要判断指定当前行动还需它的孩子保留target以及当前收益不低于f。反之任一前缀严格gap>0，已足以排除任何完整SPE沿该指定路径；代码本身不归纳为单一PASS/FAIL字段，只输出六组事实。

原main级代码解析两个位置参数`input`和`prefix`，按helper的HERE读取输入，运行Attack/ExactPayoffs/solve后逐层print JSON。最终报告含status、input原字符串、old_actual_path、old_actual_counts、old_actual_welfare_over_total、checks和累计seconds，写HERE/(prefix+'_actual_prefix_audit.json')，会覆写已有同名文件，不创建父目录。没有main guard；导入本文件也会解析argv、求解和写文件。必须在隔离布局运行，不能以import作无副作用检查。报告不带输入SHA、代码SHA或包版本；这些须另记，不由input字符串认证。
