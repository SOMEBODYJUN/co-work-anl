# 独立门槛多锥与人口预算的三份原攻击器

## 对象、模型和本次证据身份

三份主源2532、9000、3951B，共15483B，全部docstring、函数、分支和main完整实读，核原inventory大小、SHA256及Git blob。两冻结提交同字节，是三份实现，不是六次运行。规范`customer_attraction`四模块另从在仓同SHA原件全文核读；`population_cones.py`还依赖同目录`multicone_attack.py`的三个helper。实际原件、依赖、逐来源处置及审查范围见[证据目录](../../tools/evidence/dynamic-threshold-three-attacks-primary/README.md)。本次没有导入/调用原程序，没有运行规范BI、定义级证书验证、LP、随机、旧成功回放或新数学搜索。静态解析和文件指纹检查不冒这些执行。

采用[共同目录完整历史模型](../定义/共同目录完整历史模型--定义.md)：有限单位客户，p≥1个共同主题标签，m≥1名单位提供者依次观察全部有序历史各选一次；客户价值在终局覆盖者间均分。兴趣B的整数重数r_B表示不同单位客户，保空覆盖主题、同覆盖异标签、重复、零客户和全部离轨平局。无兴趣客户对全部值贡献零，攻击器的type变量只列非空B。

合法前缀计数k的完整纯子SPE终局全集记R(k)，终局c中实际选择a的单人收益为
\[
 U_a(c;r)=\sum_{B\ni a}\frac{r_B}{\sum_{b\in B}c_b},\qquad
 \Theta(k)=\max_a\min_{c\in R(k+e_a)}U_a(c;r).
\tag{1}
\]
分母含当前a而正，全部极值存在。规范求解器保
\[
 R(k)=\bigcup_a\{c\in R(k+e_a):U_a(c)\ge\Theta(k)\}.
\tag{2}
\]
[完整历史全集算法](../算法/完整历史纯SPE终局全集--算法.md)给必要充分性：当前规定叶须支配每个行动孩子最小可信收益；反向在各异有序孩子独立拼最低收益后继即可。缓存集合和值只利用子博弈同构，不把给定策略限成计数函数。

同样拼接证明Θ(k)恰是该节点**完整局部SPE首人收益的最小值**。固定actual完整σ、路径a、福利W和前缀h_i，未证TB是W+ΣΘ(h_i)≥OPT_m；TB-ANY把a放宽为任意合法路径。actual下u_i≥Θ_i且Σu_i=W，所以TB若真足half。任意路径没有这条福利上界，TB-ANY负例不自动是TB或half负例。一般TB、TB-ANY、POP及六人目标均未由三程序解决。

## 1. `attack_tb_any.py`：终端取福利的精确J

`attack(inst)`用规范Fraction全集门槛，并对所有count前缀缓存
\[
 J(k)=\begin{cases}W(k),&|k|=m,\\
 \Theta(k)+\min_aJ(k+e_a),&|k|<m.\end{cases}
\tag{3}
\]
每个非终端遍历全部合法a，比较`(孩子值,完整后缀路径)`，同值取路径字典序最小者。递归展开恰给J(0)=min_a[W(a)+ΣΘ(a_{<i})]，不要求路径是SPE。终端W不可删；[MP门槛和](../候选/真实门槛任意路径的累计预算与不可拼合边界--候选.md)的终端0是另一候选。

仅当精确J<OPT才返回实例、path、W、OPT、J、gap、rows、`path_is_SPE`。rows逐前缀列规定action、所有合法b的精确L_b字符串与Theta=max L_b；不会只保一条给定σ的孩子。SPE字段实际构造`set(solver.ordered_outcomes())`，判断这条**有序**路径是否可由某完整SPE实现，不仅判断终局count。它没有导出完整σ或调用`verify_certificate`；若字段false，其负点仍可否TB-ANY，不能否actual TB。非负时返回None，不返回一份通用非负证书。

main有guard，`--trials`默认400、`--seed`默认2026102401；每轮独立均匀选p∈{3,4,5}、m∈{3,4,5,6}，每个非空type重数从九项列表(0,0,0,1,2,3,5,10,20)均匀抽一个，零项省去。零客户输入仍合法。发现负点向stdout打印`TB-ANY counterexample`、iteration、seed及上述全记录后break；每50轮打印一次iteration/elapsed，含第0轮；循环正常耗尽才打印`finite negative only`、trials、seed、elapsed。没有文件读写、输出路径参数或无反例时的逐输入记录。默认400是计划轮数，本组三主源没有其完整stdout，不能据main补造一次400轮完成事件。

## 2. `multicone_attack.py`：独立见证、实际锥和已修复的mode

### 完整局部见证构造及行的准确含义

`local_certificate(solver,prefix)`以原实例Θ选第一个(a,target)：target属于强制a孩子全集且U_a(target)=Θ。这个a不必单独被预认作argmax L；等号本身加target合法性就保证当前最佳条件。`expand`在规定孩子继续target，其它每个b孩子选按(U_b(终局),终局字典序)最小的可信叶，并继续展开**所有**有序孩子。根强制first，后续选首个good动作，good同时要求target在该孩子全集且当前收益≥该节点floor；assert保选择合法。因每个孩子最小收益≤Θ，整个根也最佳，首利恰Θ。

actions用完整有序history作键，包含prefix以下所有非终端节点，长度逐层增至m，不要求不同顺序同count共用选择。各actual前缀另调用一次，所得见证可以互不一致，不强迫与actual或其它见证粘合。它们是**根也最佳**的局部SPE，不是[强制任一比较行动后的孩子续局](../反例/强制最优行动收益不支配局部均衡首值--反例.md)。

`data_from_actions(p,m,actions,prefix)`置D=lcm(1,…,m)，type按数值mask1…2^p−1排列；`leaf(h)`沿给定actions真实完成，返回包含过去prefix的整个终局count。对实际占用a定义整数行
\[
 P_{a,c}(B)=D\,\mathbf1_{a\in B}/(B\cdot c).
\]
每个当前history以规定收益减每个非self真实偏离收益，得Γ_{h,b}=P_{a,leaf(h)}−P_{b,leaf(h,b)}。分母1…m都整除D；零行删除，字面相同的整数行以set去重，无损于Γr≥0。没有删不同系数的离轨比较。行和目标在转换给NumPy之前均为Python整数，不是R-d51整数搜索的int64 dot实现。helper不独立验证任意外来脏actions完整性；上述合同以其完整合法生成输入为前提。

### TB与TB-ANY是两个不同调用域

`attempt(inst,path=None)`在改path之前保存`mode='TB' if path is None else 'TB-ANY'`。

TB分支取最坏福利终局集合中字典序最小z，再取该z的第一条可实现有序path；调用`certificate(z,on_path=path)`展开actual完整σ，并把它全部全历史IC加入行集。只选这一份actual证书，不枚该输入所有σ。显式完整tuple path分支不加actual IC，z由该path计数给出，所以攻击更强的TB-ANY。两个分支都沿path的m个前缀各加独立局部见证的全部IC及首利行。

固定比较支持C是原实例所有大小1…min(p,m)的标签组合中覆盖最大者，平局为组合迭代的第一项。它在新质量下不必仍最优：coverage_new(C)≤OPT_new就够。记A为固定path占用标签集合，v_i为见证首利，则目标系数是
\[
 f_B=\sum_iP_i(B)+D\mathbf1_{B\cap A\ne\varnothing}
       -D\mathbf1_{B\cap C\ne\varnothing}.
\]
LP在r≥0、Σ_Br_B=1和所有Γr≥0下min f·r，HiGHS使用float输入；行空时本程序传A_ub/b_ub为None。`value=result.fun/D`是**总客户质量归一为1**的预算差，不是已缩放整数实例的W差，也不是比较覆盖归一1。

如果某精确点满足这些行，每份独立见证仍是相应局部SPE，虽未必继续最小化Θ；故Θ_new(h_i)≤v_i,new。严格f·r<0便有
\[
 W_{new}(a)+\sum_i\Theta_{new}(h_i)
 \le W_{new}(a)+\sum_iv_{i,new}<coverage_{new}(C)\le OPT_{m,new}.
\tag{4}
\]
TB模式还保actual整棵策略可信；TB-ANY模式不需path可信。反向每个真正TB负例都能取其actual σ、各前缀达到Θ的见证、一个最优比较C，形成某个负多锥；但本实现只生成所述canonical见证及原最优C，不穷尽这个完整有限架构。一个固定锥的浮点非负不证明所有锥非负。

### 有理恢复是有后核的发现器，不是完备算法

`rational_vertex(x,rows)`只保x_j>10⁻⁷的support，以Σr=1起始；逐行挑当前float支撑上残量绝对值≤10⁻⁶的候选活跃Γ行，以Fraction高斯消元，要求凑满support维数的独立方程。逆代后将其它坐标补0，精确检查每个坐标非负、和恰1、**全部**所传Γ行非负；任一步不合格返回None。依赖的候选行若不增秩可跳过，最终全行检查阻止由此误收不合法点。它不用任意实数有理逼近定理来保证这套容差/截support/基选择一定找到有理点；退化、微小支撑或未凑满秩均可能漏掉真实负点。

LP失败返回`LP failure`及message；fun≥−10⁻⁷直接标`nonnegative cone minimum`，这个status含数值容差；更负才标float proposal并恢复。恢复None标`unreconstructed float proposal`，恢复后精确目标≥0标`nonnegative rational proposal`。只有精确目标<0才清所有质量分母为整数重数、新建单位客户实例，规范BI独立于原固定行重新算各Θ、W、OPT、具体path的SPE可实现性，assert W+ΣΘ<OPT；**TB模式另assert is_spe**。此冻结9000B实际代码已有该mode和断言，旧审查记录的`report.get('actual')`失效guard不再存在。

精确返回`exact TB counterexample`或`exact TB-ANY counterexample`，除原p/m/value/path/constraints/comparator/mode外带整数instance、`exact_cone_objective`、W、OPT、sumTheta、path_is_SPE和每见证prefix/action/target。exact_cone_objective仍对应总质量1的有理点，整数W等相差清分母scale；scale没有单列，但可由总客户数取得。报告没有保存原完整actual/actions、局部actions、Γ矩阵、恢复mass或对偶，只有见证描述；它足供从新实例/path重新求真预算，却不是原策略森林的独立逐行证书包。程序也未调用定义级`verify_certificate`。

main有guard，trials100、seed2026102402；p∈{4,5}、m∈{3,4,5}，每type重数从(0,0,0,1,2,5,10,20)抽取。默认TB；`--arbitrary-path`使每位独立均匀选标签构完整tuple path，进入TB-ANY。只在status以`exact `开头时打印全负点并break；每10轮进度记录best_scaled_cone_minimum/latest，正常耗尽打印`finite cone attack only`。best初始10⁹，LP失败无value便不更新；失败不等于通过。未附本次输入、stdout或确切运行次数，不从默认100或历史“未找到”补造执行。

## 3. `population_cones.py`：独立人数见证和混尺度IC

POP断言同一目录上Σ_{r=1}^m Θ_r(空前缀)≥OPT_m。若TB-ANY普遍成立，添加无人喜欢的空主题再走m次空动作，过去负载始终0且W0，就得POP。存在可覆盖客户时任意历史某非空主题给严格正收益，空主题0从不成为局部SPE规定行动；添加它不改Θ，零覆盖时全部0。因此负POP足否TB-ANY，不自动否actual TB或half；动态Θ_r不能换成静态不观察安全值。

`attempt(inst)`对每r=1…m重建同目录同客户的r人game，取根最低首利局部完整SPE，合其全部IC。各r行原清分母尺度D_r=lcm(1,…,r)，行直接相并：不同正尺度不改单行Γr≥0，无需强制全部行乘到D_m。首利**目标**必须统一尺度，代码确乘D_m/D_r再相加，最后减D_m coverage(C)。D_r整除D_m，整数比准确。所选C仍是原m槽最优支持，未来不必最优。

由每个新质量下仍可信的r人见证，Θ_{r,new}≤其首利。故此独立人数森林的精确负点使ΣΘ_{r,new}<coverage_new(C)≤OPT_{m,new}。不同r游戏不是同一m人actual路径，不应把它们的后继利润拼成同一W。原`initial_theta`是seed实例的r个根值，恢复后`theta`才是清分母新实例的根值；两者单位和输入均不同。

LP同样用Σr_B=1、type≥0、混尺度IC和HiGHS；failure返回status/message。非负/容差范围返回`nonnegative cone minimum`、value、p/m/constraints/initial_theta。负float后复用上述有理恢复；恢复None或恢复目标≥0仍返回`negative float proposal`，没有multicone的两个细分status。精确负才整数化、各人数重新BI、assert新根值总和<新OPT，返回`exact POP / TB-ANY counterexample`、整数instance、theta、sumTheta、OPT、exact_cone_value。没有path、actual SPE断言或完整森林/行输出，这与其仅否POP/TB-ANY的合同一致。

main有guard，trials100、seed2026102403；p∈{4,5,6}、m∈{3,4,5,6}；每type从(0,0,0,0,0,1,2,5,10)抽取，五个0保其实际稀疏概率。exact状态打印全记录后break，每10轮进度，耗尽打印finite cone attack only。没有原JSON或stdout附在本三件，故原README所述定向root-tax锥无负点仍是原MD历史报告，本次既未读该测试输出也未重做其数值。

## 接口、实现边界和接续用途

三源码导入均由guard隔开搜索，但import仍装载规范包，后两件还立即导NumPy/SciPy，POP再导同目录multicone。三件main都只stdout、无文件写入、无通用`--verify`接口；重定位运行须把原件根加PYTHONPATH，POP的兄弟模块也须可导。依赖镜像保原路径，不擅改原字节。

数学合同是正人数、非空标签目录；multicone显式path入口另须合法完整**tuple**路径。源码没有完整path接口验证，短词/列表等不能冒受支持输入。POP的空行情况没有multicone的rows guard：它直接将`np.array(rows)`传A_ub；p=1时无非self比较，所有rows为空、所得数组是一维而非二维约束矩阵。源码没有对此适配，本次只作静态识别，未调用SciPy确认具体异常；main只采p≥4不能替程序取得p≥1全部边界实现认证。规范软件还允许m0，但三攻击器不承担零人数扩展。零客户和空主题不因此从数学命题删除。

固定锥实严格负点可取同有理面上的有理点、放大成整数单位客户，是[原Theta资料](../资料/动态局部门槛的独立见证锥与人口预算--资料.md)已经证明的存在归约；不能把它误读成上述启发式`rational_vertex`必成功。冻结mode修复现由9000B代码本身确认，原guard的两时点历史仍保原独审。此处完整代码清洗补足旧资料明确尚未读py的证据缺口，不回改前批的真实执行身份。

全仓实际比较还包括：[R-f81六攻击合同](任意路径门槛的六种攻击与产品有限报告--程序.md)的同策略上界/独立前缀锥没有这里的有理恢复后核；[R-d51多节点锥](真实门槛累计的整数集合搜索与多节点策略锥--程序.md)最小化单独ΣΘ上界，不含本TB-ANY的终端W，也不含这里的actual锥；[R-f399门槛筛查](真实门槛与归属响应税的有限原审计合同--程序.md)枚全部可实现有序path，区别本J的全部合法path；[门槛跳变审查](../审查/遗漏类型分支行的Farkas符号与门槛跳变--审查.md)表明固定σ线性首利不能跨tie面改名为Θ，独立见证上界方向保住这一点。

本次新增的是三原程序的实质合同、已修guard的当前冻结字节身份、混尺度理由和实现/输出缺口，非新的覆盖不等式。真正剩余义务仍是把多个互不相容的局部最低首利见证共同付入单一actual覆盖预算，或给严格精确负实例；更多有限阴性、默认样本数、一个固定锥非负float都不填该缺口。阶段二只解释这些关系，不复制旧超图或造新连接。
