# 真分支、实际交集和SRC

本节使用代码的零起角色i,j,ell；输出source_j、cut_i、target_l均加1，forced_topic和leaf标签保持零起。记B_j为actual标签b_j覆盖的客户集。

程序预存每个切点i=1,…,m−1及全部主题t的真孩子
\[
 y^\alpha=finish(b_{<i}\cdot t),\quad c_\alpha=c(y^\alpha),
 \quad u_j^\alpha=u_j(y^\alpha)\ (j<i).
\]
root切点i=0没有固定旧源j<i；i>ell不会改变已经选择的目标主题，故不贡献请求。i=ell的当前目标分支也包括在内，不只测严格更早分叉。相同叶若来自不同切点仍保留各自历史资格；原有同题/平局分支未删。

对j<i≤ell，精确请求为
\[
 q^+_{\alpha j,\ell}
 =\sum_{x\in B_j\cap(B_\ell\setminus W^\alpha_\ell)}
       \frac1{c_B(x)c_\alpha(x)}.
\]
这里W^alpha_ell是**子局目标角色所选主题的覆盖集**，不是子局前缀覆盖并集。类型代码条件正是b_j、b_ell都在客户接受集且y_ell不在。固定旧源j<i仍选择B_j，支持上c_B≥2、c_alpha≥1，分母有定义。

SRC是每个源单独的孩子利润预算
\[
 \sum_{\alpha:j<i_\alpha}\lambda_{\alpha j}u_j^\alpha\le u_j(B),
 \qquad\lambda_{\alpha j}\ge0.
\]
成本用旧角色j在该孩子的利润，不是切点行动者或目标的利润。没有Σλ≤1、λ≤1、共同孩子容量或所有源必须选同一孩子的约束。将这些权重解释成一个分支概率分布会改变候选。

# 为什么程序恰好消去全部请求

固定ell，对j<ell定义
\[
 \rho_{j\ell}=\max_{\alpha:j<i_\alpha\le\ell}
                    \frac{q^+_{\alpha j,\ell}}{u_j^\alpha}.
\]
无有效正比时取0；u_j^alpha=0时非负单位客户和固定旧源保证q+=0，代码assert此事实并将比设0。于是任意SRC可行请求的目标值至多
\[
 L_\ell=\sum_{j<\ell}u_j(B)\rho_{j\ell}.
\]
每个正比源选一个最大孩子，放λ=u_j(B)/u_j^alpha，其余0，便同时达到**此固定目标的**全部源最大。零预算或无正比源取0。因此L_ell是全部非负λ的精确最大值，不需要LP求解器。

实现对切点i、主题t递增遍历，只在ratio严格更大时更新，正比平局保留首先遇到的孩子；重复叶不影响最大值。每个目标重新从全部u_j(B)预算开始。不同目标的witness数组一般是不同可行λ，不能把26个最大值及其饱和预算当成一份共同请求向量同时花费。分别求最大对“所有λ、每个目标”的坐标命题是正确的，但不提供跨目标的联合付款。

逐客户c_B≥2给q+≤u_j^alpha/2，从而ρ≤1/2和L_ell≤(1/2)Σ_(j<ell)u_j(B)。这只是前缀总利润粗界，并未被2u_ell(B)支付。实际目标的真IC不能把多份更早分叉的不同旧源利润都换成同一次复制叶中的利润；全利润COPY2失败也不能抹掉q+的实际交集支持。
