# 原程序寻找什么

[完整3601B原件](../../tools/evidence/fresh-global-two-probe-program/original/probe_fresh_global_two.py)的 SHA-256 为 `6b5bf041c279d9d4def418444b266bdd8b4afdca46f336ea6cc28fa18857830c`。两冻结提交同字节，已通过正常 `clean show` 全文读取。程序不是给定策略的精确验证器，也不读取客户实例；它随机选择两人尾局的完整纯策略，在该策略保持最佳回复的非负客户权重锥内，以浮点 LP 尝试使

\[
P+\Delta-C_F(T,S)<0.
\tag{1}
\]

背景限定为共同目录中同一题 \(H=0\) 重复 \(L\ge1\) 次，之后恰有两人。对每个抽中策略，它比较**全部无序主题对**，包括重复题对；“全比较”不表示枚举了全部策略、全部背景或全部纯 SPE。

这一合法单题背景范围已有[四项非负乘子及符号余项证书](../计算/背景菜单的有限证书--计算.md)，证明其全部 \(q,L\)、客户分布和完整尾 SPE 均有 \(P+\Delta\ge\operatorname{freshOPT}_2\)。本程序的有限未命中不是该普遍结论的证明。本次核验的作用，是核实它的浮点矩阵和真实数学模型之间的接口，以及已有解析证书如何接入它的原 IC；没有重做旧证书的384行扫描或默认2000批搜索。

# 客户、合法背景与完整尾策略

采用[共同目录完整历史模型](../定义/共同目录完整历史模型--定义.md)：有限单位客户、共同合法主题、顺序行动、终局均分，同一策略包含所有有序离轨历史和任意弱平局。程序以 \(q\) 个标签 \(0,\ldots,q-1\) 编码目录，允许零权重使某些标签为空或覆盖相同。令

\[
\mathcal M=\{1,\ldots,2^q-1\},\qquad z_a(m)=\mathbf1\{\text{掩码 }m\text{ 含标签 }a\}.
\]

类型 \(m\) 的非负权重为 \(w_m\)。全零掩码的客户不属于任何主题，对收益和覆盖均无贡献，故省略。原 LP 允许实权重并规范化 \(\sum_m w_m=1\)，是非零客户实例的齐次缩放。精确非负有理权重可统一乘分母得到有限单位客户重数；一般浮点输出本身不构成这样的整数实例证书。全零客户实例另行平凡成立，未由此单纯形表示。

程序令

\[
p_m=Lz_0(m),\qquad F=\{m:z_0(m)=0\}.
\]

因此每个旧客户负载恰为 \(L\)，新客户负载为零，且已有覆盖并集恰是合法目录题 \(H=0\)。这里不是为每个类型自由指定旧负载，也不是任意多题前缀。前缀 \(H^L\) 合法，不代表它已经沿某份完整根 SPE 实际发生；本程序没有给前 \(L\) 位指定策略或检验其最优性。

定义单客户收益和聚合收益

\[
v_m(a,b)=
\begin{cases}
\dfrac{z_a(m)}{p_m+z_a(m)+z_b(m)},&z_a(m)+z_b(m)>0,\\
0,&z_a(m)+z_b(m)=0,
\end{cases}
\qquad U(a,b)=\sum_m w_m v_m(a,b).
\tag{2}
\]

`utils[a,b]` 正是 (2) 的浮点系数列；第一下标是被计算收益的当前玩家，第二下标是另一个尾玩家。对于同题重复选择，若客户属于该题，分母是 \(p_m+2\)，不能把两个同题玩家并成一次覆盖。

两人完整尾策略由首动作 \(A\) 与回复函数 \(r:\{0,\ldots,q-1\}\to\{0,\ldots,q-1\}\) 给出。实际末回复为 \(B=r(A)\)。\(r(a)\) 在每一个合法首动作历史后定义，包含离轨及重复动作；程序没有只保实际路径，也没有把首位偏离后的后继固定为 \(B\)。但不同背景 \(L\) 的策略独立抽样，不是一个跨全部根历史的完整策略证书。

# 策略如何抽样，哪些平局得以保留

`run(q,cases,seed,max_background)` 使用局部 `random.Random(seed)`，第零基 `case` 的背景长度为 \(1+\text{case}\bmod\text{max_background}\)。每种非空类型先独立取指数随机数，再乘随机选出的 \((0,0,0,1,1,3)\) 中一项，得到仅用于**挑策略**的临时权重。全零则跳过该次。它不把这些临时权重作为待保存的最坏点，之后 LP 会另选权重。

对每个首动作 \(a\)，计算所有末位收益 \(U(b,a)\)，在距离浮点最大值不超过 \(10^{-9}\) 的候选中随机选 \(r(a)\)。再计算首位沿各自真实回复的收益 \(U(a,r(a))\)，为每项加独立的 \([0,10^{-9})\) 随机扰动后取最大者为 \(A\)。因此抽样器保留某些近似平局选择，却不枚举全部平局；临时样本上选出的动作也可能略低于严格的未扰动最大值。后续 LP 的 IC 才是此策略在**重新选择权重后**应满足的合同。

`seen` 的键为 \((L,A,(r(0),\ldots,r(q-1)))\)，只在同一背景长度去重。理想完整策略数为每个 \(L\) 的 \(q^{q+1}\)，其中有些策略锥可能不可行；原程序不遍历这个集合。默认 \(q=6\) 时每个 \(L\) 有 \(6^7=279936\) 个形式策略，2000个随机尝试远不是完整枚举。若某次全零或重复，直接 `continue`，甚至会略过相应整百进度输出；日志条数不能反推出每次尝试都求解。

# 每个固定策略的全部 IC 与目标

所有原不等式按“偏离减指定收益”写入矩阵 \(M\)，要求 \(Mw\le0\)。完整行顺序为：

| 顺序 | 行数 | 对全体客户求和后的不等式 |
|---|---:|---|
| 先按首动作 \(a\)，再按末位偏离 \(b\ne r(a)\) | \(q(q-1)\) | \(U(b,a)-U(r(a),a)\le0\) |
| 再按首位偏离 \(a\ne A\) | \(q-1\) | \(U(a,r(a))-U(A,B)\le0\) |
| 总计 | \(q^2-1\) | 全部两人尾子博弈最佳回复条件 |

每个末位节点对全部标签比较，首位偏离沿所给回复函数，因此在精确权重下这些条件对该完整两人策略是必要且充分的。自身行动比较是恒零行，故未存入。所有不等式弱化为非严格形式，容纳平局；没有另假定唯一最佳回复。它们对完整 \(L+2\) 人根策略仅构成此特定子树的条件，不能证明过去玩家也最佳。

写

\[
P=U(A,B)+U(B,A),\quad
\Delta=\sum_{m\in F}w_m\max(z_A(m),z_B(m)),
\]
\[
C_F(T,S)=\sum_{m\in F}w_m\max(z_T(m),z_S(m)).
\]

新客户给两位尾玩家的总利润等于其实际新覆盖，旧客户仍给尾玩家分数利润。所以 \(P=\Delta+P_O\)，而 \(P\) 一般不等于整局覆盖或 \(\Delta\)。每个 LP 是

\[
\min_w\sum_m c_m(T,S)w_m,
\quad Mw\le0,\quad\sum_mw_m=1,\quad w_m\ge0,
\tag{3}
\]
\[
c_m(T,S)=v_m(A,B)+v_m(B,A)
 +\mathbf1_F(m)[\max(z_A,z_B)-\max(z_T,z_S)].
\tag{4}
\]

(4) 聚合恰为 (1)。比较对来自 `combinations_with_replacement(range(q),2)`，共 \(q(q+1)/2\) 个；并集覆盖对换序不变，重复对允许只用一题，故逐对检查足以覆盖这个目录的 \(\operatorname{freshOPT}_2\)。这里全比较的是 fresh 并集，不是 \(U(T,S)+U(S,T)\)，不应与[任意背景两人税界](../引理/固定背景两人税界--引理.md)的目标混同。

默认每个抽中策略有63个类型、35条 IC 和21个 LP。原代码没有变量规模保护、参数有效性校验或超时选项；正常使用要求 \(q\ge2\)、`cases` 非负、`max_background` 正整数。\(q=1\) 时原空行数组并未显式整理为二维约束形状；不能将模型的平凡单题情形当作已验证的程序边界。类型数随 \(q\) 指数增长。

# 输出、容差与历史空记录的准确含义

命令行参数为 `--q 6 --cases 2000 --seed 71213 --max-background 4`，默认输出名 `fresh_global_two_probe.json`。这些是源码默认值，不是旧报告已保存的历史调用命令。程序只依赖标准库、NumPy、SciPy，无本地数学模块、外部客户输入或隐藏 JSON 依赖；`linprog(...,method='highs')` 为浮点求解。

`best` 初始化为0，`found` 初始化为null。只有 `res.success` 且 `res.fun < best-1e-9` 才更新，原 `deficit` 保存的是带符号的目标值，负数才表示违反 (1)。源码文档中的“positive deficits”应理解为亏损量为正，不能把保存字段的符号反转。若新 `best < -1e-8`，保存后提前返回；在两阈值之间的小负纪录则继续搜索。

| 返回字段 | 源码合同 |
|---|---|
| cases | 正常结束为请求的尝试次数；早停时为当前零基索引加一，包括此前全零或重复的尝试 |
| policies | 去重集合大小；不是全部可行策略数或完整 SPE 数 |
| solved | 实际调用 LP 的次数，调用失败也加一；不是成功次数 |
| best | 初始0以来超过更新容差的负纪录；不能表示所有 LP 最优值、所有结果的精确最小值或正的最小值 |
| seconds | `run` 内部墙钟差，不含整个启动过程，不能跨环境当作性能保证 |
| found | 仅当前负纪录的浮点摘要；若未满足更新规则则 null |

一条负纪录含 q、长度为L的背景零列表、actual、全q项reply、比较对、浮点目标、超过 \(10^{-9}\) 的浮点权重、零基case与seed。省略小权重可能改变归一化或 IC；程序不重新归一化、不做有理恢复、不保存精确对偶、也不检验被截断权重的完整策略。因此即使有 `found` 也只是待精确审计的发现线索。失败求解仅跳过，未保存失败数、状态或原因；正常 shell 退出不保证每个 LP 成功。

旧报告的六字段为 `cases=2000, policies=643, solved=13503, best=0.0, seconds=24.15056276321411, found=null`。\(643\times21=13503\) 与六题、每策略21对的完整查询次数吻合；它不记录 q、seed、最大背景、版本SHA、逐LP状态或命令，不能把默认值直接升级为历史参数，也不能把13503次调用升级为13503个精确零最优值。其122B原表已全文比较，全部字段与身份由[阴性报告数据正文](../计算/单背景主题两人全比较探针的阴性报告--计算.md)承担；该旧事件与下文84次新事件分别保存。

# 已有合法 H 证书怎样接入这些原行

此节复用[背景菜单证书](../计算/背景菜单的有限证书--计算.md)的解析结果，并给出它与本程序矩阵之间的完整恒等式。它不是由84次未命中外推的新定理。

令首位和末位的正向 IC 为

\[
I_X=U(A,B)-U(X,r(X)),\qquad
J_X=U(B,A)-U(X,A).
\]

\(I_A=0,J_B=0\)，其余是本程序相应原行的相反数。对 \(X=B,H\) 定义逐客户非负的安全余项

\[
K_X=U(X,r(X))-\sum_m\frac{w_mz_X(m)}{p_m+2}\ge0.
\tag{5}
\]

因为真实末回复至多再覆盖一次，(5) 对任意 \(r(X)\) 均成立。于是原证书的两个地板正是 \(I_B+K_B\) 和 \(I_H+K_H\)，没有把真实后继固定为实际B。

逐类型写 \(a=z_A,b=z_B,t=z_T,s=z_S,h=z_H\)，\(D(p)=(p+1)(p+2)\)，并令

\[
\rho_F=a[(1-t)(1-s)+ts]+(1-a)[b/2+2ts],
\]
\[
\rho_O(p)=(1-b)(2-3a/2)+(t+s)(3-a)
 +(p-1)[1-(a+b)/2+t+s].
\tag{6}
\]

所有位均为0或1，旧客户 \(p\ge1\)，故 (6) 非负。合法H合同使新客户恰为h=0、p=0，旧客户恰为h=1、p=L。逐客户展开再求和得到

\[
\boxed{
P+\Delta-C_F(T,S)
=\tfrac12 I_B+I_H+J_T+J_S
 +\tfrac12K_B+K_H
 +\sum_m w_m\frac{\rho_m}{D(p_m)}.}
\tag{7}
\]

所有右端项非负。因此每个精确可行策略锥的每个比较 LP 均有目标下界0，任意有限目录、全部L和所有弱平局均被覆盖。若题名相同，相应 IC 为零或乘子合并，(7) 仍成立；本程序的重复比较对没有例外。

原证书还允许各旧客户有不同正负载，只要其并集本身恰为合法题H；这是 (6) 的符号推论，不是本程序输入域的扩张。程序只生成统一重复次数L。不能免费把已有并集加为一题：新增偏离会改变 IC 和原 SPE。

# 全仓比较、后续纠错与接续用途
