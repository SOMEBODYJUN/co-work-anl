# 固定查询和LP的精确目标

P=(0,0,1/2,0,0,1/2)，即p=(e_2+e_5)/2。源码从每actual位置i强制每A、依原finish完成后删去i槽，平均其余两行动槽，以M(M−1)=6归一，重建q；不是从冻结JSON读q，也不是将完整三槽负载当竞争两槽。所得
\[
q=(5/12,1/6,0,1/3,1/12,0),\qquad
\mu_t=2\sum_{a\in t}q_a.
\]
每独立查询a的系数行g_{a,t}=1_{a∈t}/(1+μ_t)，g_a(n)=Σ_tn_tg_{a,t}；q与μ不依客户重数，故这些全为预先可构造的有理系数。

真实自洽的固定支持条件是g_2=g_5且g_2≥g_a对全部六a。置e_t=g_{2,t}−g_{5,t}、s_{a,t}=g_{2,t}−g_{a,t}，目标c_t=3g_{2,t}−w_t。因固定p两支持各半，在等式e·n=0上G(p)=(g_2+g_5)/2=g_2，所以c·n正值才是此p的3G−W反证。不能在未满足支持等式时将3g_2−W当3G−W。

源码的单次LP精确定义为
\[
\begin{aligned}
\max_{n\ge0}\quad &c\cdot n,\\
A n&\ge0\quad(258\,\mathrm{IC}),\\
s_a\cdot n&\ge0\quad(a=0,\ldots,5),\\
\mathbf1\cdot n&=1,\qquad e\cdot n=0.
\end{aligned}
\tag{LP}
\]
共63变量、264不等式、两等式；自比较零行和重复支持约束也保留。Σn=1是齐次锥的归一化，用于每客户目标的发现；不是限制原输入必须只有一个客户。若有有理严格正候选，可统一放大成非负整数单位客户。若全零客户，付款本来为零无需归一化，不能从LP遗漏n=0推出模型排零。

# 活跃集有理重构如何产生已保存的证书

所有不等式行合并为B=(A;s)，并仍以Γ/s非负方向书写。SciPy返回的是最小化−c、负不等式−B的边际，源码取raw_lam=−result.ineqlin.marginals，raw_gamma=result.eqlin.marginals[1]，归一化边际另记raw_nu=result.eqlin.marginals[0]。这些只是浮点选形，不能直接作为有理证明。

exact_dual_from_active_set实际执行以下有限重构，**不是把每个乘子独立四舍五入**：

1. 仅保raw_lam>10^−8的行索引active；未知量是这些乘子与一个γ。对每客户型t，构造列向量(B_{r,t}:r∈active；e_t)。
2. 用浮点筛选abs(−c_t−Σactive B_rt raw_λ_r−e_t raw_γ)<10^−7的类型列，称tight；这些列给候选精确线性方程ΣB_rt λ_r+e_tγ=−c_t。
3. 系数与右端仍为原Fraction，采用精确Gauss–Jordan：逐变量找非零pivot、整行归一、消去其它所有行；矛盾零行通过assert排除，返回rank与free变量数。
4. 若有free变量，才先以Fraction(raw).limit_denominator(10^6)给这些自由坐标有理值，pivot坐标由精确方程反解；不活跃λ置0。若free=0，解完全由精确线性系统决定，不靠逐乘子逼近。

这一步选tight列时**没有把归一化ν列加入未知量**；随后main才把raw_nu用limit_denominator(10^7)还原成ν。源码不是对任意非零ν情形都保证重构成功的通用转换器。当前保存结果ν=0、active system rank21、free_active_multipliers0，且SC不等式乘子均零、20个真IC乘子正，正是前一资源的完整原证书。浮点阈值只建议活跃形状；正确性由下一精确残差/符号层承担，不由容差本身承担。
