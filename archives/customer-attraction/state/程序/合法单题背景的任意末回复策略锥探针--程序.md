# 原件、发现任务与当前证据

主源 `4b92e1ba3e4d5ec1de8a` 为2412B，[完整原码](../../tools/evidence/fresh-arbitrary-reply-probe-program/original/probe_fresh_arbitrary_reply.py)的SHA-256是 `efdfe17ac4a1751fc784c2c833e59d6fb5443935d6fce4c19aca148a5f191a12`，两冻结提交同字节。已全文读取run、参数、随机图、LP和两种输出分支；主码没有本仓模块或数据输入依赖。

它随机抽固定两人子局的完整末回复表，再在该策略的线性可行域里寻找客户质量，使“剩余利润+新增覆盖−指定两题的新覆盖”严格负。背景只来自同一个合法目录题H的重复，不能搜索一般多题前缀。`complete`指每个被抽回复表的两人IC完整，不指枚举全部回复表或验证整局根策略。

对应[130B历史报告](../计算/单背景主题两人回复图的随机探针报告--计算.md)实际参数为q=7、cases=12000、L=1、feasible=12000、best=0、seconds约32.26，**不是默认10000次**。报告没有seed、回复图清单或最优值表。本次不重新求历史12000个LP，也不猜其seed；只做一个明确标为合成输入的无LP算术核，并把已有合法H解析证书接到这个策略锥。证据与实际范围见[说明](../../tools/evidence/fresh-arbitrary-reply-probe-program/README.md)。

# 模型、主题标签与客户类型

采用[共同目录完整历史模型](../定义/共同目录完整历史模型--定义.md)：有限单位客户、有限非空共同标签目录，单位提供者依全部有序历史选题，客户在终局覆盖者间均分。空主题、重复行动、同覆盖标签、零客户及任意离轨平局均保留。

程序q是动作标签数，不是提供者人数。背景为合法题H=0连续重复L≥1次，之后恰有两人；固定实际首动作A=1、其末回复B=2、比较主题T=3、S=4。至少需要q≥5。H/A/B/T/S是五个不同标签，但覆盖集合可以相同；源并未证明这种固定标签角色穷尽给定q下所有字面重合型。任意末回复可重复任意合法动作，也可选H、A、B、T、S。

客户兴趣类型为非零位掩码m=1,…,2^q−1，最低位对应H=0。记χ_a(m)为第a位，归一化质量w_m≥0、Σ_mw_m=1。每一主题可因其所有会员型权重为0而为空；两标签可以在所有正质量型上同覆盖。全零掩码被省略，因为它不影响任何收益或本目标；全部零客户/全零质量也被归一化排除，但不能产生严格负目标，所以这不删去负例搜索所需的失败情形。完整模型仍保零客户，其目标等式为0。

对该类型，背景负载p_m=Lχ_H(m)，fresh标志为1[p_m=0]。L≥1时恰为1−χ_H。单客户收益系数

\[
u_m(a,b)=\begin{cases}
\dfrac{\chi_a(m)}{p_m+\chi_a(m)+\chi_b(m)},&\chi_a(m)+\chi_b(m)>0,\\
0,&\chi_a(m)+\chi_b(m)=0.
\end{cases}\tag{1}
\]

`utils[a,b]`就是这个向量，当前玩家选a、另一人选b；当a=b时分母有两个提供者，不能把重复动作只算一次。汇总收益U(a,b)=Σ_mw_m u_m(a,b)。源码用NumPy浮点除法计算，而数学系数在整数L下是有理数。

若获得精确有理可行质量，统一清分母可实现为有限单位客户。源码输出的近似有理化权重没有经过这一必要的精确可行检查，不能直接据其Fraction字符串认定单位客户SPE。

# 固定回复表的完整两人策略锥

一次随机表ρ∈{0,…,q−1}^q为每个首动作a指定末位动作ρ(a)，并强制ρ(A)=B。两人策略是“当前首人选A；任意合法首动作a之后末人选ρ(a)”。给定固定背景，这张表覆盖全部q个末位决策历史。

源码每条矩阵行表示“偏离收益−规定收益≤0”。末位全部比较是

\[
U(b,a)-U(\rho(a),a)\le0
\quad(a\in[q],\ b\ne\rho(a)),\tag{2}
\]

共q(q−1)行。首位全部比较是

\[
U(a,\rho(a))-U(A,B)\le0\quad(a\ne A),\tag{3}
\]

共q−1行，偏离后确实跟随该表在新历史的ρ(a)，没有冻结原B。故矩阵总行q²−1；q=7时为42个末位行+6个首位行=48行，127个非零掩码列。行不要求严格，全部平局可以合法保留。

在精确实数意义下，(2)、(3)和w≥0恰描述这张给定表的完整两人子局SPE锥；Σw=1只是其归一化切片。它不是静态PNE约束，不只查实际末位历史，也不在相同负载的不同过去之间强制同策略。源码没有验证前缀H^L的过去玩家会在根选择H，因而不提供“该前缀在根实际到达”的证书。固定子SPE可在其余子树及祖先做逆向选择延伸，但不保证祖先选择这个前缀。

## 每个回复锥必定非空

对任意ρ，把全部质量1放在m=2^q−1，即所有q题共同覆盖唯一加权客户。每次两尾选题都给每人1/(L+2)，所以全部(2)、(3)等号成立，不管随机表如何指定回复。其fresh覆盖为0，本目标为2/(L+2)>0。q=7、L=1时就是mask127、目标2/3。

因此数学上每个这种归一化锥都非空。历史feasible=12000是12000次求解器成功标记；它不能当作12000种不同客户实例、非退化策略或新增覆盖机制的覆盖率。这一直接解析观察不需要再跑LP。

# 目标是指定比较的新覆盖缺口

令P=U(A,B)+U(B,A)，Δ=Σ_{p_m=0}w_m max(χ_A,χ_B)，C_F(T,S)=Σ_{p_m=0}w_m max(χ_T,χ_S)。源码目标系数就是

\[
f_m=u_m(A,B)+u_m(B,A)
+1[p_m=0]\,[\max(\chi_A,\chi_B)-\max(\chi_T,\chi_S)],
\]

故最小化f·w=P+Δ−C_F(T,S)。负值会违反P+Δ≥freshOPT₂，因为指定比较覆盖不超过freshOPT₂。反过来，不分离这一个固定T/S角色的有限采样，不能证明所有比较或全部游戏无负例。

P是后两人获得的利润，旧客户仍给分数收益；Δ只数新客户实际覆盖。二者不等，也不是完整终局覆盖。新客户上P贡献恰等于Δ，故目标也可写2Δ+P_old−C_F(T,S)。这一目标是[新增覆盖余额](../引理/背景新增覆盖余额与首步分解--引理.md)在两个剩余人和指定比较元组处的版本。

每次调用linprog使用HiGHS、A_ub=上述矩阵、b_ub=0、A_eq全1、b_eq=1、所有变量非负。没有显式行缩放、求解器容差options或精确对偶输出。精确约束给固定策略锥，浮点`success`则只属于数值求解状态；两者不能混作原报告已经给出有理策略证书。

# 合法H证书为何排除本域的精确负值

这里已经有[合法背景菜单有限证书](../计算/背景菜单的有限证书--计算.md)，证明H^L后任意完整两人纯SPE满足P+Δ≥C_F(T,S)。它的正确性来自四个真实非负行及逐客户余项，不来自本探针未命中。为给出与矩阵的明确联系，记

\[
C_B=U(A,B)-\sum_mw_m\frac{\chi_B}{p_m+2},\quad
C_H=U(A,B)-\sum_mw_m\frac{\chi_H}{p_m+2},
\]
\[
L_T=U(B,A)-U(T,A),\qquad L_S=U(B,A)-U(S,A).
\]

首位可偏离到合法B或H，之后至多再有一个覆盖者，故两个C是安全保底；末位在同一A后可查T、S，故两个L非负。证书为

\[
P+\Delta-C_F(T,S)=\tfrac12 C_B+C_H+L_T+L_S+\sum_mw_m\frac{\rho_m}{(p_m+1)(p_m+2)}.\tag{4}
\]

令a,b,t,s,h为A/B/T/S/H会员位。fresh型h=0,p=0的余项为

\[
\rho_F=a[(1-t)(1-s)+ts]+(1-a)[b/2+2ts]\ge0;
\]

旧型h=1,p≥1的余项为

\[
\rho_O=(1-b)(2-3a/2)+(t+s)(3-a)
+(p-1)[1-(a+b)/2+t+s]\ge0.\tag{5}
\]

这同时处理所有L≥1，而不是用少数L试验外推。H必须是合法可查询主题且恰表示旧覆盖并集；本程序的p=Lχ_H正好满足它。

若把(2)、(3)的单客户行记M，则C_B等于首位B偏离行的负值，加逐客户非负保底差κ_B=u_m(B,ρ(B))−χ_B/(p+2)；C_H同理有κ_H。因此在**任意**固定回复图中逐列有

\[
f+\tfrac12M_{first,B}+M_{first,H}+M_{last,A,T}+M_{last,A,S}
=\tfrac12\kappa_B+\kappa_H+\frac\rho{(p+1)(p+2)}\ge0.\tag{6}
\]

由于Mw≤0，(6)就是该锥的一个明确非负目标证书，四行乘子与ρ无关，只是保底差随ρ变化。这解释了为什么合法H域不能出现精确负目标；它不声称目标最优值一定为0，更不把原best字段改写为精确最优值。

一般合法多题前缀没有这个H，(4)不能免费使用。已知[52客户实际前缀反例](../反例/实际前缀的剩余利润与新增覆盖--反例.md)在实际前缀(A,B)后有P=17、Δ=0、freshOPT₂=18；其旧并集34客户不是六道合法题之一。加进这道并集H会改变目录和原SPE，不是无害补符号。所以本H证书与一般GLOBAL已被反驳的状态不矛盾，本探针也没有在该一般域搜索。

# 随机采样、best及两种返回路径

`random.Random(seed)`是局部生成器。每轮独立抽q次rng.randrange(q)，随后把actual位置覆盖为B；被丢弃的那一次抽样仍消耗随机流。在ρ(A)=B条件下，共有q^(q−1)张表，程序有放回均匀抽取，不去重、不保存访问集。q=7共有117649张表，12000轮即使全不重复也未穷尽它们。没有保存seed便不能用默认seed反推历史表序列。

`best=0.`在初始化后**从未更新**。每次成功仅增加feasible；若res.fun<best−10⁻⁸，即低于−10⁻⁸，立即构造候选、写witness、打印并return。没有继续寻找最负值。因此正常结束返回的best恒为0，是阈值哨兵，既不是已求目标的最小值，也不是精确LP下界。介于−10⁻⁸与0之间的浮点结果不会触发返回。

负候选分支仅保res.x中w>10⁻⁸的坐标，再逐项Fraction(float(w)).limit_denominator(1000000)；不重新归一化，不核全部IC，不重算有理目标或验证分数依旧负。保存deficit仍为原float res.fun，不是裁剪/有理化后点的目标。故fresh_arbitrary_witness.json只会是待审候选；字符串像分数不构成精确策略证书。

| 返回路径 | 数据及行为 |
| --- | --- |
| 首次低于阈值 | q、background=[0]*L、actual=1、完整reply、compare=[3,4]、float deficit、稀疏有理字符串weights、0基case、seed；写脚本旁fresh_arbitrary_witness.json并早返。 |
| 全轮结束 | q、cases、background_repetitions、feasible、best=0、seconds六字段；没有seed、回复表、逐LP状态或精确权重。 |

每1000轮打印cases/feasible/seconds进度；非成功LP静默跳过，不区分不可行、无界或数值失败。`seconds`从utils/目标构建之后、循环开始前计时，不是完整进程墙钟时间。main最后总把run返回值写fresh_arbitrary_probe.json并打印；命中时stdout还会重复候选，进度行加最终行整体不是单份JSON。未命中不会删除旧witness，不能用两个文件共存推断它们同次产生。

# 参数、运行依赖与输入边界

main的四个整数参数默认是`--q 6 --cases 10000 --seed 71215 --background 1`，后者传给L。没有verify参数，也没有只读检查已有witness的入口；未知参数由argparse拒绝。输入全部由参数生成，不读客户文件或历史报告。NumPy用于数组，SciPy用于linprog；Fraction只用于候选导出，itertools.product在本原码中未实际使用。

HERE=Path(__file__).parent，两个输出都位于脚本旁，不由工作目录选择；直接写文件会覆盖同名结果。导入有main保护，不会自动运行搜索。代码不验证q≥5或L≥1：q过小在固定T/S索引处失败；L<0不代表合法负载，不能用于上述数学范围；L=0会成为全fresh空前缀的另一边界；cases≤0则不做任何LP却仍可返回best0。其指数级2^q−1列也没有参数规模保护。上述是静态合同，不是本次额外制造的失败运行。

# 本次无LP核到底执行了什么

[独立接口核](../../tools/evidence/fresh-arbitrary-reply-probe-program/audit_cone_contract.py)通过AST读取原run的初始化及首轮构行片段，截在linprog赋值之前，只执行这些未改算术语句一次；不调用原run/main，不替换求解器，不写原程序输出。合成输入明确为q=7、L=1、seed=0，得到ρ=[6,2,6,3,0,2,4]；这个seed和回复表**不声称是历史12000轮中的任何一轮**。

另一侧从每个掩码的真实单位份额独立生成6223个有理收益、48×127=6096个IC系数及127个目标系数。原AST侧是float，因此核保存精确浮点误差，未伪称二进制浮点与有理数逐字相同：收益/行最大误差为1/54043195528445952，目标最大误差为1/27021597764222976，均小于2⁻⁵⁰。

随后把(6)接入该合成锥：零基首位行43乘1/2、首位行42乘1、实际末位查询行8与9各乘1，127个逐型等式与非负余项全部用Fraction核实。全mask127的归一可行证书也精确核同。完整矩阵、行标签、目标、误差及余项保[报告](../../tools/evidence/fresh-arbitrary-reply-probe-program/cone-contract-audit.json)。本次AST算术片段1次、原函数0次、原main0次、LP0次；没有重做已有384行H证书的发现或其全表审计，也没有复放历史12000轮。

# 相邻探针与可迁移范围

另全文比较3601B[probe_fresh_global_two.py](../../tools/evidence/fresh-arbitrary-reply-probe-program/related/probe_fresh_global_two.py)：它先抽随机客户权、从该权的近最佳回复挑策略，循环若干背景长度并对策略去重，然后枚举全部含重复的无序比较对。它会更新best，具有不同阈值和输出；本源则直接抽任意回复图、固定L/A/B/T/S且不去重。不能把两者的cases、policies、solved或best字段互换，也不能把一份输出当另一入口重放。

原搜索保的是合法单题背景、固定标签模板内的一种发现途径；共同H解析证书给的是这个域的普遍非负结论。一般多题背景的失败、前缀必须根实际发生的额外义务、三人以上尾部与六人half仍是不同问题。可复用资产是完整两人IC矩阵合同、有限浮点输出的正确读法、明确无效的best最优解释，以及(6)将已有真实证书接入每个策略锥的关系。阶段三可据此分别登记来源、实现、有限接口检查与解析排除，不把无负采样升级成全域定理。
