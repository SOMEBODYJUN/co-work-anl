# 一次固定见证攻击的真实对象

本页完整保存3670B block_cone_probe和809/1030/1113B三份报告的实现与全部数字，入口和另两随机代码见[背景/首两步筛查](合法背景聚合与两步安全余额的随机终局筛查--程序.md)。[七源清单](../../tools/evidence/background-pair-and-three-fixed-witness-cones-seven-primary/source-manifest.json)保14018B原字节、两个冻结来源、blob与SHA。原件不修改，亦未为重建缺失actions/质量或补运行事件重跑LP、规范solver、BI或随机种子。

采用相同单位客户均分及完整有序历史。k为主题数，r为**从空背景开始的总玩家数**，三输入r4/5而非六人。初始每个非空兴趣类型M都用Random(seed).randrange(1,10)取1…9名客户，故种子点的主题非空且覆盖互异；后续客户LP允许各w_M变零，可能产生同覆盖标签，其标签树不自动下降为严格集合目录中的指定策略。

每个种子先用ExactSPESolver对全部k²个有序首两行动A,B及其孩子SPE终局q，按[两门槛兼容条件](合法背景聚合与两步安全余额的随机终局筛查--程序.md)筛选，然后只以精确U_A(q)+U_B(q)最小选一个组合。这里没有把尾安全值纳入选树目标，不能称选到了最坏B2树。并列时沿有限遍历取首个；frozenset的终局遍历次序没有额外固定排序。接着ordered_outcomes(q)取首个首两步匹配的有序路径，再certificate(q,on_path=path)补成**一份**完整有序策略σ，所有离轨孩子由规范实现分别补全。只取一份σ，不枚举同一终局的所有完整策略。

# Γ保全树；p和Q只在种子点算一次

gamma从cert.actions逐节点对每个a≠σ(h)，沿同一σ分别完成规定和强制动作后的真实终局，逐类型用Fraction作收益差，再转float。G包含全部

\[
(k-1)\sum_{d=0}^{r-1}k^d
\]

行；不含自身，但**不去重、不删全零行**。没有冻结偏离前的原后继，也不把同计数的不同有序节点绑成一行动。

在种子客户质量上，调用background_probe.security两次：空根r人安全值与实际前两动作后的r−2人安全值。根查询p取负res0.ineqlin.marginals；尾对手Q取res2.x[:-1]。理想精确极小LP中前者是查询对偶分布、后者是背景原始分布；原security没检查success、非负/归一及有理残差，不能由marginals字段就授予精确证书。

固定这一次p/Q，变量为全部非空类型w≥0及自由vL、vU，约束

\[
\sum_Mw_M=1,\quad Gw\ge0,\quad
v_L\le\beta_Cw\ (|C|=r-1),\quad
v_U\ge upper_aw\ (a=0,\ldots,k-1),
\]

目标为

\[
\min\ d\cdot w-rv_L+(r-2)v_U,
\]

其中d为σ实际首两人收益行，β_C由固定p平均全部根查询，upper_a由固定Q平均尾查询，尾过去包含真实A、B，尾对手长r−3。vL/vU在这份源码中是自由实变量，与后期两套程序给t/z非负边界的写法不同；非负收益且合法p/Q时最优有效端值本来非负，但原程序仍按其真实自由界保存。

[既有PAIR程序](<../../../../tools/evidence/phase25-material-attachments/20261103-boss6-triage/99cf885c91440b214c23.md>)已完整证明正确方向：对合法精确p/Q，vL≤v_r(0)、vU≥v_(r−2)(A+B)，因此上述目标是实际B2 gap的**上界**。严格负且经完整有理后核才足以否PAIR；0或正上界不能证明实际gap非负，也不能证明该完整策略锥或一般PAIR安全。本码对每树只解一次主客户LP，没有交替p/Q、随机锥极点重启、全子路径扫描或剔除全兴趣类型。

# 输出、全兴趣面与后期版本比较

本码有main guard，无参数解析；默认依次probe上述三组，若返回fun<−10⁻⁸就停止后续组。单次probe先打印policy/k/r/seed/path/nodes，再打印RESULT/fun/success；随后无论有无负值都用write_text覆盖脚本旁block_cone_k_r_seed.json，且不补最终换行。import仅载函数和NumPy/SciPy/规范包及本地background_probe；原码未禁pycache。`product`和稀疏csr_matrix/vstack导入未用，矩阵实际是dense NumPy vstack。原报告未附stdout或运行事件，不补造完成时间、exit0或精确零重放。

本码保全兴趣客户坐标。其真实PAIR系数零已由[候选页](../候选/两步安全链的条件归并与有限探索边界--候选.md)证明；父方metadata也仅复用这个标量零式。报告不保w，不能认定这三次LP最优点实际就是该平凡面。也不能因未去全兴趣就宣布所有失败均无信息：它们仍真实保存三个固定p/Q的有限浮点未命中，但没有全锥证明。
