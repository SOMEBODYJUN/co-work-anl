# 明确目录及为何终局集合可按计数缓存

采用[共同目录完整历史模型](../定义/共同目录完整历史模型--定义.md)。取n个不交客户块，每块16名不同单位客户、四主题A/B/C/D，兴趣型及重数为A:2、BD:4、AC:6、CD:3、ABCD:1。共同目录是各块四题的**并集**，不是Cartesian一次同时选所有块；人数与主题数均m=4n，客户总16n。全部有序历史、重复行动及任意弱平局保留。

对某块局部终局计数(a,b,c,d)，已占用标签的收益为
\[
U_A=2/a+6/(a+c)+1/(a+b+c+d),\quad U_B=4/(b+d)+1/(a+b+c+d),
\]
\[
U_C=6/(a+c)+3/(c+d)+1/(a+b+c+d),\quad
U_D=4/(b+d)+3/(c+d)+1/(a+b+c+d).
\]
零分母项只在该资源无人覆盖时取0。程序预存四个标签的数值表，但激励比较只读取已经被强制选择而确占用的动作收益；不能将其缺席标签表值当作规范模型中“缺席玩家收益”。

计数前缀s后全部纯SPE可实现的终局集合记R(s)。叶R(s)={s}；非叶各孩子非空，令
\[
F(s)=\max_a\min_{q\in R(s+e_a)}U_a(q),\quad
R(s)=\bigcup_a\{q\in R(s+e_a):U_a(q)\ge F(s)\}.\tag{1}
\]
必要性来自每个真实孩子都有完整SPE续局；充分性是在选中孩子采用q，其余不同有序孩子各取使当前偏离收益最小的完整子SPE，当前收益≥F便可同时拼合。子树不交，递归结束于叶。这刻画所有历史依赖SPE的可实现**终局**，计数缓存不强制同计数有序节点共享同一行动或后继。程序未枚举全部完整动作图，也没有输出这些图的认证DAG。

# last-low截面究竟枚举了什么

对固定目标z及阈值u=13/4，低收益标签集L={a:z_a>0,U_a(z)≤u}。程序递归枚举所有坐标0≤s_a≤z_a，并要求剩余低收益行动总数Σ_{a∈L}(z_a−s_a)=1，记录F(s)。该条件确保非终端，但代码**没有额外强制s包含指定首动作**。若根孩子可实现，则沿其某条真实路径的最后一个L行动之前必经过这个枚举集合的相容部分；若整个更大枚举集合都F(s)>u，当前低收益者可保证更高，矛盾。所以严格全截面阻断是可靠充分排除条件，枚得过多不损该方向。

B目标的某些枚举前缀可能还未包含强制B，因此不是恰好相容截面。其余A/C/D目标本动作计数2且为低收益，剩余低行动1使相应前缀仍至少含该动作一次。不能把同一裸截面计数对所有列都描述成“只枚根相容前缀”。

# 真孩子的uniform-D替代诊断

在R(e_a)中另筛被强制根最终收益≤13/4的终局，计算独立查询在n个D主题间均匀抽样的额外份额，取最大。其分母含新查询+1，最后再除n；不是在某个固定D上查询或对整个目录求minimax。

| 列 | n2 admissible数 / best_value / strictly_above_u | n3 admissible数 / best_value / strictly_above_u |
|---|---|---|
| A | 11 / 69/20 / true | 60 / 101/30 / true |
| B | 8 / 187/60 / false | 39 / 283/90 / false |
| C | 6 / 133/40 / true | 35 / 197/60 / true |
| D | 6 / 359/120 / false | 35 / 551/180 / false |

报告逐项保存达到best的target与该根actor_payoff。n3的替代target使用另一块q_E=(1,1,2,0)，而非原四指定target；不能将“原指定目标不可实现”扩大成所有低根收益孩子都不存在。B/D最大值不足，只否这次固定uniform-D诊断，既不证一般FM，也不排其他query分布或改造目录。条件复制菜单n4的静态矩阵超价仍缺真实可实现性，见[平稳查询与复制菜单资源](../资源/平稳查询与复制菜单的有限证据合同--资源.md)。

# 六局部轮廓的有限分类

程序检查根集合每个终局的每块局部计数是否在
\[
\mathcal Q=\{(1,0,1,2),(1,0,2,1),(1,1,2,0),(2,0,0,2),(2,0,1,1),(2,1,1,0)\},
\]
并数是否至少两块q₀。`root_outcomes_outside_six_local_profiles`按每个(root终局,块)异常递增，严格说是异常块对计数；本两份均0，所以也表示无异常根终局。`root_outcomes_with_two_q0_blocks`按根终局计，两份亦0。全部Q组合中至多一个q₀的数量5^n+n5^{n−1}分别35/200，恰等根集合大小，配合前述包含关系便得**n2、n3这两个输入**集合相等。代码还支持n1，但本批没有n1主报告；任意n仍不能由此外推。
