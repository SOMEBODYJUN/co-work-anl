# 实际资源模型与插入目标

原4120B程序探索共同目录的另一种匿名精确势游戏。每个资源j由一个非空兴趣标签集I_j、非负权w_j和参数t_j∈[0,1]给定，同兴趣集可有多个不同参数资源。m名相同玩家各选一次标签；终局计数q使该资源负载c_j=Σ_(a∈I_j)q_a。资源对一名覆盖者的收益是w_j t_j^(c_j−1)，不是一般CAG的w_j/c_j。计数和重复选择保留，标签可为空覆盖或同覆盖。

令f_t(0)=0、f_t(c)=Σ_(k=0)^(c−1)t^k，定义

\[
\Phi(q)=\sum_j w_j f_{t_j}(c_j),\qquad
u(q,a)=\Phi(q)-\Phi(q-e_a)
=\sum_{j:a\in I_j}w_jt_j^{c_j-1}.
\tag{1}
\]

只对q_a>0算玩家收益，命中a的资源负载必正。t=0时第一份边际0⁰按1、以后为0；程序对零负载显式设收益系数0。冻结其它玩家的单人换题效用差等于势差，所以这是精确势游戏。

每个资源边际序列d_k=t^(k−1)满足任意阶完全单调关系

\[
(-1)^r\Delta^r d_k=t^{k-1}(1-t)^r\ge0
\quad(k\ge1,r\ge0).
\]

非负资源混合保此性质。但“使用几何完全单调核”不等于本程序默认采用调和客户核，亦不保证任何顺序福利桥。

对固定实际终局q，定义

\[
\begin{aligned}
W_\Phi&=\sum_aq_au(q,a)
 =\sum_{j:c_j>0}w_jc_jt_j^{c_j-1},\\
E_a&=\Phi(q+e_a)-\Phi(q)=\sum_{j:a\in I_j}w_jt_j^{c_j},\\
J&=\sum_aq_aE_a=\sum_jw_jc_jt_j^{c_j},\\
M&=\max_aE_a,\qquad G_\Phi=W_\Phi-J.
\end{aligned}
\tag{2}
\]

WΦ一般不是覆盖资源总权，更不是单位客户覆盖数。原程序变量`credit=c_actual*(tv**c_actual)`对应的是J的逐列系数，**不是**GΦ。其每查询最大化

\[
\boxed{\ mE_a+J-2W_\Phi\ },
\tag{3}
\]

寻找辅助VI `mM≤WΦ+GΦ`的候选违约。程序没有求OPT，也没有直接测试原六人half。

# 三种率模式与全部CLI

| 模式 | 资源列 | 参数来源与准确范围 |

# 一份固定计数策略的真实后继和IC

`states(k)`递归列总数k的全部p维弱组合，建立k=0…m的层。每轮先为当前资源列抽种子权：独立exponential值乘以概率.35的保留位，其余为0。它们只用于选策略，随后LP可重新选择所有非负权重。

给每个终局z和q_a>0的标签a，程序建每资源收益系数向量F[z,a]，以及总利润系数WF[z]。从终层向前，固定每个计数q的全部孩子已决定终局z_b，计算种子值F[z_b,b]·w_seed。通常在距最大值不超过10⁻⁹的行动中随机选择；random-policy则任意随机选一个标签，不要求它是种子最佳回应。最终保存σ(q)和沿它的终局final[q]。

这是一个在所有计数状态**同时一致**的确定策略。令有序历史h的动作是σ(counts(h))，便在全部有序历史定义一份完整策略；同一计数历史的动作和后继计数相同。对该份策略检查计数行足以检查所有有序历史，因为收益也只依终局计数。它仍只搜索计数策略族，不是全历史策略的通用净化或穷尽。

每个非终计数q、规定动作a=σ(q)及所有b，行向量为

\[
\Gamma_{q,b}=F[\operatorname{final}(q),a]
 -F[\operatorname{final}(q+e_b),b].
\tag{4}
\]

第二项先改当前动作，再沿**同一σ**真实完成，不冻结后继。当前t固定后，这些行对资源权w线性；w≥0和Γw≥0即使该份计数策略在此资源游戏中是SPE。种子近似平局或任意random-policy不是最终可信性保证，最终候选仍需精确验收LP行。

默认m3/p6的非终计数有1+6+21=28个，每个比较六动作，168行含28自身零行。其有序提升对应1+6+36=43个决策历史及258含自身比较；二者不能混称168个有序节点或把减少行数说成删了离轨历史。终局计数56个。共用/资源独立模式63列，mixture441列。

# LP、归一化与浮点输出的全部边界

每轮固定t和σ之后，对p个查询各调用一次SciPy/HiGHS：

\[
\max_{w\ge0}\ (mE_a+J-2W_\Phi)(w),\qquad
\Gamma w\ge0,\qquad WF[\operatorname{actual}]\cdot w=1.
\tag{5}
\]

这里归一化的是**实际总利润WΦ=1**，不是资源总质量1、势值1、OPT1或原CAG覆盖1。目标和IC对w齐次，正WΦ候选可缩放进入此切片；WΦ=0的情形未被(5)覆盖。尤其t0可使重复覆盖资源收益全零，不能从归一化不可行直接推出一般VI。

代码用A_ub=−Γ、b_ub=0和w的非负bounds表示不等式；没有非负客户的1/c系数或共同客户表示约束。默认预算至多300份采样策略×6查询=1800次LP调用，遇正候选、异常或非法参数可提前停止，未附报告不能称实际完成1800次或穷尽任何锥族。

求解失败时仅跳过该查询；success时算完整res.x上的浮点value。best初始−10⁹，仅改进超过10⁻⁸才打印best记录，包含iteration、模式、value、actual终局计数和query。全部失败或非正迭代预算可留下哨兵；它不是一般上界。打印`finished iterations best`也不是每个LP均成功或存在精确对偶的证明。

value>10⁻⁶时保存首个候选，并raise SystemExit结束全部探索。条件输出有11个顶层字段：scope、players、topics、t、seed、iteration、query、actual、value、weights、sigma。actual是**计数**而非有序路径；sigma逐非终计数给动作；共用t保存为字符串，另两模式保存浮点列表。weights逐保留列存mask/value/t，只有w>10⁻⁹者被写下。程序在完整res.x算目标后才丢小权，没有对截断后的权重重新核IC、WΦ=1或正目标。

候选写在原码旁固定`geometric_kernel_candidate.json`，会覆盖已有文件并加末换行，没有独占写入、文件版本或运行过程保全。它没有有理恢复、清分母、精确收益/IC/目标复验、完整有序策略证书或独立审计；没有保存全部LP状态/原始对偶、依赖版本和全部CLI开关。输出只供下一步精确可审候选，不能按success或文件名授“精确反例”。本五源没有这个候选、几何stdout或执行事件；原README也只称工具，未给精确正反例或一般结论。本批LP与该脚本新增运行均0。

# CAG调和核下是同一VI；一般OPEN已有后继纠错

原入口及原凹势稿将CAG版VI标OPEN。必须先按定义确认式子，不能借另一个缩放桥的失败改状态。CAG调和势Φ=Σ_xH_(c_x)在零背景实际终局满足

\[
W_\Phi=W=\sum_x\mathbf1_{c_x>0},\quad
E_a=\sum_{x\in a}\frac1{1+c_x},\quad
M=M_1,
\]
\[
J=\sum_aq_aE_a=\sum_{c_x>0}\frac{c_x}{1+c_x}
 =W-G_1,\qquad G_1=\sum_{c_x>0}\frac1{1+c_x}.
\tag{6}
\]

因此这里的无背景、未缩放目标**逐式等同于**

\[
mM+J\le2W
\quad\Longleftrightarrow\quad
mM_1\le W+G_1.
\tag{7}
\]

[十三人原独审](../审查/十三人静态宽限与最优组合平均的原独立审计--审查.md)和[未缩放程序合同](未缩放插入信用的浮点终局与完整策略锥探针--程序.md)已完整认证另一13人、36不同单位客户、六非空互异主题的同一SPE packet：actual计数(2,1,0,0,0,10)、W33、OPT36，M₁3、G₁359/66。于是J=1819/66，

\[
13M_1-W-G_1
=13M+J-2W=37/66>0.
\]

所以一般CAG的(7)已经为假，旧OPEN是原时点，不能继续作当前全人数状态。这是α=1直接算术，不是从α=12/13的另一目标迁移。本批全文比较成熟证明与已有成功全SPE资格，复用112050比较认证，未重跑该packet或创建新实例。

CAG边际还有`1/k=∫₀¹t^(k−1)dt`，所以允许任意非负测度几何混合的资源类包含调和核；该全混合类的一般VI也不能靠“完全单调”救回。但本脚本mixture只有指定七率网格，不能把上述CAG反例自动称作该网格的保存点、默认m3实验成果或本脚本已发现候选。恰六人同式、不同预算及原half目标仍按各自量词判断；m13的辅助桥失败不反half。
