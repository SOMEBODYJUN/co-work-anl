# 精确输入、程序身份和已有数学对象

这是[固定最优遗漏私有化分离](../反例/固定最优遗漏私有化的完整可信性分离--反例.md)的后续独立程序资源，不是新底层游戏或另一条私有化反例。原发现者的自含自审另保在该反例页；本源不导入其脚本，也不导入仓库模型、求解器或证书检查器。其数学合同仍由[完整历史共同目录模型](../定义/共同目录完整历史模型--定义.md)解释：每名有限单位客户在覆盖者间均分，三名单位提供者观察全部有序历史后各选一次主题，任意离轨平局保留。

程序从冻结`aggregate_theta_failure.json`读取六标签X0,X1,X2,Y0,Y1,Y2及三人数。九种跨X/Y二兴趣各一客户、九种各含两个X和两个Y的四兴趣各三客户，逐重数展开为36名不同单位客户。收益用`Fraction`逐单位相加，重数不当成非单位玩家或加权单客户。

原完整策略为：根选X0；首标签在X时第二位选Y0，否则选X0；第三位选第二标签所属组的最小未出现标签。它定义于全部43个决策历史。程序对每个历史、六个行动沿该同一策略真实完成后比较收益，共258项，包含43项自身动作及215项真正改变动作。冻结报告的最低比较松弛为0，实际有序路径为z=(X0,Y0,Y1)，收益(10,12,12)，W=34。全X或全Y均覆盖全部36客户，故OPT3=36；上界直接来自客户总数，无须优化器。

# 指定改造和全部完整SPE递推

原z只遗漏单位编号5、8，原兴趣分别为{X1,Y2}、{X2,Y2}。指定最优C=(Y0,Y1,Y2)后二者在C内唯一owner均为Y2。程序只将这两名客户兴趣缩为{Y2}，其余34名完全不变。该C仍覆盖36客户，所以新OPT仍为36；旧叶z上的收益与覆盖保持，并不证明旧策略仍为SPE。

程序为旧、新和有利改造各独立建立递归，缓存键为完整**有序历史**h。令R(h)是其子博弈的全部纯SPE可实现有序叶集合；终端R(h)={h}，当前位置i=|h|时

\[
 F(h)=\max_a\min_{v\in R(h,a)}u_i(v),\qquad
 R(h)=\bigcup_a\{v\in R(h,a):u_i(v)\ge F(h)\}.
\]

必要性：任何完整SPE在未选行动a的后继也是子SPE，给当前人的偏离收益至少该分支可实现最小值。充分性：对要实现的叶保留其子SPE，对每个未选分支独立取达到最小值的子SPE；叶收益达到F即阻止全部当前偏离。有限归纳保证极值可达及集合非空。两个不同历史即使负载相同也没有强制共用平局；递推允许重选全部离轨子树，而非只尝试原策略修补。

|X0|6|10—10|12|0|
|X1|5|19/2—11|12|0|

报告另完整保存首选Y0后的六行末位最佳回复表：第二位依次选X0/X1/X2/Y0/Y1/Y2时，末位最佳回复分别为{Y1,Y2}/{Y2}/{Y2}/{Y1,Y2}/{Y2}/{Y1}；第二位收益为10、19/2、19/2、9、12、12，根收益为12、12、12、9、12、12。第二位因此必须转向未用Y，旧X侧惩罚失去可信性。这里X0分支的根上界10仅量化**子SPE续局**；任意非均衡叶(X0,X1,X2)的根收益为12。

新R(∅)恰为Y0,Y1,Y2的六个排列，唯一计数(0,0,0,1,1,1)，全部W=36。旧实例R(∅)共有48条可实现有序路径，最低W=34，根门槛10。旧、新递归各覆盖259个有序历史状态，其中43个非终端、216个终端；这些是有限树规模，不是259份完整策略。新报告没有枚举全部完整策略图，也无此必要：集合值递推穷尽可实现叶。

# 存在最优比较的边界

同一程序另取真正最优C'=(X0,X1,X2)，只把上述两遗漏客户分别归X1、X2；精确检查原**有序**z仍属于新R(∅)，福利34。它允许另选整份完整SPE，不声称原给定策略图原样保持。

因此指定全Y的结果反驳“对任意预先固定最优C，总存在owner与某新完整SPE使W不升”，连同其更强的保原路径、计数、覆盖版本。它没有排除**存在某个最优C**和逐单位owner的[E-path/E-count/E-cover/E-defect](../候选/存在最优遗漏私有化与有限关联下降--候选.md)；全X恰说明这种区别承重。旧36/34和新36/36都满足half，也不反驳一般锐常数。有限阴性的P0随机提案及浮点全菜单锥由[双攻击合同](可信全菜单与遗漏私有化的双攻击合同--程序.md)另承接，不与此精确两实例穷尽混并。
