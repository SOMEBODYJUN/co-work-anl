# 同一策略身份与八字段合同

固定单位客户、共同目录的六人完整有序历史纯SPE，实际行动为 A₁,…,A₆。令 h=(A₁,A₂,A₃)，强制第四位选合法比较主题 T_a 后真后继为 B_a,C_a。旧图显式保留

\[
R_{0,a,b}=\sigma_6(h,T_a,B_b)\quad(a\ne b),\qquad
R_{1,a,b}=\sigma_6(h,T_a,C_b)\quad(所有a,b),
\]
\[
Z_e=\sigma_6(A_1,A_2,A_3,A_4,R_e).
\]

这是同一策略定义的合法目录标签；并不要求被强制的行动在新历史上最优。其会员凸实现也不替代全历史IC，见[共同阈值与对角拆分](../构造/回复会员阈值的共同凸抬升与对角预算拆分--构造.md)。下面的行本身只需 T 元组合法，不要求它达到OPT；联合主图的另八条最优单换才有OPT条件。

保存的 `cut=(i,member,f,diag,qi,am,al,mu)` 定义如下。

| 字段 | 真实含义与实际枚举 |
|---|---|
| i | 0至4，源为actual第 i+1 位；其后 n=5−i 人，源余尾长6−i。没有对actual末位另开此投影。 |
| member | 0强制 R_e，1强制 Z_e；不是源玩家编号。 |
| (f,diag) | `GS=((0,0),(1,0),(1,1))`；两非对角族各30个有序索引对，对角族6个。没有(0,1)。 |
| qi | 0至5，从 `(w_a+w_b)` 取位，即 T_a,B_a,C_a,T_b,B_b,C_b；不是实际行动 A 的六位。 |
| am,al | 所有中间后继的共同非负价格与末后继价格；n−1个中间后继各付am，最后一个付al。 |
| mu | 强制分支末位针对上述合法旧查询Q的真实IC非负乘子。 |

`PAT` 为按字典序排列的八种三位词 `(1_Ta,1_Ba,1_Ca)`。每个hist的八个整数计数和为6。源位置i与轨道索引a,b是不同下标，不因源码都使用短变量就合并历史。

# 精确下包络和分层行

对一个客户令实际六位为 a，`p=sum(a[:i])`，`ell=sum(a[:5])`，强制主题会员t、查询会员q。隐藏中间会员总数为s，隐藏末位会员为g。程序取

\[
\Psi_i(p,\ell,t,q)=\min_{0\le s\le n-1,\ g\in\{0,1\}}
\left[
\frac{t}{p+t+s+g}+\frac{a_m s+a_l g}{\ell+1}
-\mu\frac{g}{p+t+s+g}+\mu\frac{q}{p+t+s+1}
\right].
\]

零分子份额取0；非零项的分母为正。调用 `projected_by_count` 时，alpha为 `(am,)*(n−1)+(al,)`，beta全0。原始 n 个二元后继有2ⁿ种赋值；这里因所有中间成本相同，只需2n个(s,g)。这是逐客户**最小值**，不是选最有利真实后继；对真实后继的非负余项以及源IC、实际末位共同价、分支末位IC给出

\[
c\,[u_{i+1}+((n-1)a_m+a_l)u_6]
\;\ge\;\sum_{e\in E_{f,diag}}\sum_x
\Psi_i(p_x,\ell_x,1_{F_e}(x),1_{Q_e}(x)),
\quad c=|E_{f,diag}|\in\{6,30\}.
\]

源实际收益和共同末位收益须按这一系数支付；强制R/Z后新生成的后继被投影消去，不能冒充先前图中的同名R/Z。局部式合法性来自一般引理，未要求客户只在这16种hist支持上。有限支持限制在当前点的发现及核验范围。

`row(cols,cut)` 输出与输入列等长的Fraction向量，约定行点积非负。hist列先写 `c*(own+((n−1)am+al)*last)`，再扣掉所有轨道在t=0时的基线。词对(w,v)的非对角重数为 `H_w H_v−1_(w=v)H_w`，对角只在w=v时为H_w。对应joint-reply列若 `state[member]=1`，再写

\[
-N_{w,v}\,[\Psi_i(p,\ell,1,q)-\Psi_i(p,\ell,0,q)].
\]

这恰将二元t的仿射插值补齐；state=(1,1)同时贡献两个member的边缘，但每条行只取指定member。K列和overlap列在本行均为0。程序用最近出现的hist绑定后续joint列，没有检查 `hist_column_old` 引用，也没有完整输入schema验证；因此列顺序、group重数和非负质量是调用合同。本次逐组检查了原点的194组joint三状态及各组总质量不超过其hist质量，未由此声称全部overlap或原4971条行已经审过。

# 三乘子LP的方向与认证边界

`sufficient_stats` 将有理权转为float，分别收集各hist及轨道中的t=0/1、q=0/1质量，再按(p,ell,t,q)合并。每结构只保留质量大于10⁻¹²的状态；丢小质量或负质量不是数学认证，也不是输入修复。

每结构LP用三个价格变量和每个保留状态的辅助变量z。对所有2n个(s,g)加 `z≤该分支仿射值`，目标是

\[
\min\{c((n-1)a_m+a_l)u_6-\sum_\omega m_\omega z_\omega\}.
\]

在正状态质量下，最小化目标会将每个z推到其所有上界中的最小者，即Ψ；外层才在价格间最小化完整slack。价格域为0至1000；i=4无中间后继，am特别固定为0。任意非负有理价格的行合法性不受1000限制，但此次发现没有搜索盒外，且没有为盒内最优值给精确对偶证书。

枚举总数是5个源×2个member×3个轨道×6个Q=180。`attempted` 对每个调用增加，包括求解失败的LP；它不等于180个成功优化证明。`find_cuts` 仅在 `sol.success` 且含源收益的float slack<−10⁻⁸时取候选，把每个价格按 `Fraction(float).limit_denominator(1000000)` 有理化，再由 `row` 完整重建Fraction系数，但此函数第二次筛选的点积仍用float。随后按float slack排序，返回最多maxcuts条 `(float_slack, cut, rational_row)`，默认32；没有在有理化改变参数后重新求最优。

独立命令入口把maxcuts设为64，对每个返回行与原点精确权做Fraction点积并断言严格负，才保存cut和精确slack。因此当前保存的负割是精确分离证据，而空结果、截断后的64个结构及报告字段 `negative_structures` 均不是完整负结构数或无割证书。当前正常解释器执行了这些assert；没有使用 `-O`。

命令报告只有scope、输入路径、通用参数界、LP计数、selected表，没有输入SHA绑定或LP最优证书。主程序也没有核验原点的必要图可行性。一次发现不执行重新优化；补行后的新点须另行生成和核验。
