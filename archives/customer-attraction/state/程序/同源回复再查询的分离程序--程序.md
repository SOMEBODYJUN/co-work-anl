# 同源回复再查询的分离程序

## 原件、实际依赖和本轮范围

主源`fc07ebb90129de65f3b8`为4424B Python，SHA256 `b458f25360e3e35416f571b31af6dcc0418e6b1eb30894a8bde3965b03e0434a`，两冻结提交同字节。完整原件和[证据](../../tools/evidence/early-reply-requery-program/README.md)保全，不修改冻结源码。

直接仓库依赖是`old_query_reply_cuts.py`的PAT/GS/groups及`terminal_portfolio_cuts.py`的parse/qvec；两模块4128B、5223B已全文读取。前者顶层又导入2908B `customer_attraction.priced_hidden_reply`，本次亦全文读并保原件；该投影核心在本源运行中只被加载，本源的`candidates/psi`不调用它，三个依赖的main均未运行。NumPy、SciPy/HiGHS和稀疏矩阵接口属于浮点发现层。

本轮唯一原CLI在共享823005B、5180行必要图点上运行默认24个LP，成功保存5条精确负行；没有运行384结构的`--all-queries`、旧网格/连续分层发现器或任何完整主图。该点的完整接口检查复用上批同SHA结果；联合v2中相应五行的独立定义核验由配套数据对象另承担，未在本程序任务重复计算。

以下沿用[共同目录完整历史模型](../定义/共同目录完整历史模型--定义.md)：有限单位客户、有限非空共同主题目录、六名单位权提供者依次观察全部有序历史；客户价值在最终覆盖者间均分。空主题、重复行动、零客户和任意离轨平局均允许。程序只生成每份完整纯SPE必须满足的局部行，不能从一份必要点生成完整SPE或六人half反例。

## 两个分支必须回到同一个有序源

实际路径为(A₁,…,A₆)，实际收益u₁,…,u₆。索引i=0,…,3表示实际第i+1位，其真实有序前缀h=(A₁,…,Aᵢ)，源收益u=uᵢ₊₁，尚余k=6−i≥3人。

在同一h强制当前选合法主题T，按同一完整策略σ完成；其最后两题为B、C，中间k−3个后继为F₁,…,Fₖ₋₃。然后**回到h**强制当前选这一个C，沿σ的另一条真实续局，最后两题为J、V，中间后继为F′₁,…,F′ₖ₋₃。

这不是在第一枝走到C后继续增加玩家，也不把两个不同历史的源收益视作相等。两次都是同一个h的合法单步偏离，故各自与同一个原规定收益u比较。第一枝末题C又充当第二枝被强制的主题，其客户会员必须相同；第二枝末位V查询第一枝B时，也保留同一个B主题。被强制T或C无需在其新节点上是最佳回复，真实末位C、V才有各自末位IC。

T在应用中取旧显式图的R_e或Z_e。旧图在actual前三h₃强制第四题T_j后得到真后继B_j,C_j，并定义

\[
 R_{0,j,l}=\sigma_6(h_3,T_j,B_l)\ (j\ne l),\quad
 R_{1,j,l}=\sigma_6(h_3,T_j,C_l)\ (j,l\text{任意}),
\]
\[
 Z_e=\sigma_6(A_1,A_2,A_3,A_4,R_e).
\]

这些旧标签是共同目录合法主题，但本次两枝中新生B,C,J,V不能与旧B_j、C_j或R_e按字母名识别。实际末位A₆及其付款u₆始终是另一个明确的全局对象；本源隐藏变量B不是“默认查询A₆”的别名。

## 七条真实行与六参数合同

记全局实际末位前背景负载ℓ，实际源前负载p，共同目录最大主题大小或公共上界K。对每客户，t,b,c,j,v分别为T、B、C、J、V会员，s=Σ1_F、s′=Σ1_F′，q为合法查询Q的会员。令

\[
 z_1=p+t+s+b+c,\qquad z_2=p+c+s'+j+v.
\]

参数按源码顺序为(a,γ,d,e,f,μ)，其中0≤a≤1，其余五个非负；源码第二项名`cw`，原稿写c，这里γ避免与客户会员c混淆。f是容量乘子，不是回复轨道family编号。

| 原真实行 | 权 |
|---|---:|
| 同源h原规定收益u−强制T后的当前收益 | a |
| 同源h原规定收益u−强制C后的当前收益 | 1−a |
| 第二枝真实末位V改查询第一枝B的IC | γ |
| 全局actual末位A₆改查询J的IC | d |
| 同一actual末位改查询V的IC | e |
| 共同容量K−|V| | f |
| 第一枝真实末位C改查询Q的IC | μ |

相加得到

\[
 u+(d+e)u_6+fK-\sum_xH_x\ge0,
\]
\[
 H=\frac{at-\mu c}{z_1}
 +\frac{(1-a)c-\gamma v}{z_2}
 +\frac{\gamma b}{p+c+s'+j+1}
 +\frac{dj+ev}{\ell+1}+fv
 +\frac{\mu q}{p+t+s+b+1}.\tag{1}
\]

零分子份额取0；有符号分子可按各原份额分别解释。非零t/c/v均出现在对应终局，故其分母正；其余分母至少1。源码`share`按此处理，不对零客户做效率比除法。

源付款恰是a+(1−a)=1；真实末位两条价共付d+e；容量只付fK。跨互斥分支利润没有被无条件相加。这是已有[同源重配权引理](../引理/共享真实末回复的组合查询投影与同源重配权--引理.md)的程序化应用，原2869B `weighted_early_reply_requery.md`已明确不认领新的均衡机制或全局结论。

## candidates与精确隐藏最小值

`candidates(i,p,ell,t,q)`枚举s,s′∈{0,…,k−3}及b,c,j,v四个二元位，恰16(k−2)²项；i=0,1,2,3对应256、144、64、16项。每项返回`base+co·parameters`的精确Fraction表示：

\[
 \operatorname{base}=c/z_2,
\]
\[
 \operatorname{co}=\left(
 t/z_1-c/z_2,
 b/(p+c+s'+j+1)-v/z_2,
 j/(\ell+1),v/(\ell+1),v,
 q/(p+t+s+b+1)-c/z_1\right).
\]

它恰等于(1)。`psi`对全部候选取

\[
 \psi_i(p,\ell,t,q;\theta)=\min H.\tag{2}
\]

两个中间序列的成员只以各自总数出现，故这个计数枚举等于两个**独立扩大二元位域**上的字面最小值；没有要求全策略按计数行动，也没有证明这些隐藏赋值都可同时来自真实σ。真两枝赋值包含于扩大域，所以ψ≤真实H，得到合法必要行

\[
 \boxed{u_{i+1}+(d+e)u_6+fK\ge\sum_x\psi_i(p_x,\ell_x,t_x,q_x;\theta).}\tag{3}
\]

本源是从客户成本H取**最小下包络**，与[嵌套第四步程序](实际第四步强制新回复的嵌套投影程序--程序.md)先组合非负slack再取max的写法方向不同，两者各自保持不等号。不能将最大和最小因同叫投影而互换。

两个函数都用无容量上限的`lru_cache`；缓存只复用相同参数的精确计算，不提供额外数学证明。正式源范围i0…3；随意传i≥4会使相应候选域为空或不再属于此两枝末两位合同，程序没有通用参数验证。

## 16个查询及二值强制会员的正确读出

`terminal_portfolio_cuts.qvec`按以下次序提供16个查询值：

| 0基索引 | 数学查询 |
|---|---|
| 0,…,5 | actual主题A₁,…,A₆ |
| 6,…,11 | 旧词w_j,w_l对应T_j,B_j,C_j,T_l,B_l,C_l |
| 12 | 本次被强制的T自身，故q=t |
| 13,14,15 | 除去j,l后的其余索引，对T、B、C三个旧主题族分别作均匀查询 |

最后三项不是分数新主题。若j=l，余5索引；否则余4。它们是同一真实末位C对若干合法主题IC的非负归一平均，客户会员平均为

\[
 \bar q_r=\frac{\sum_w h_w w_r-(w_j)_r-\mathbf1_{j\ne l}(w_l)_r}
 {5-\mathbf1_{j\ne l}},\quad r=0,1,2.
\]

同一个C承担该平均，(1)线性依赖q，所以合法。原头部注释只说13查询，函数本版本在给hist时实际返回16项；不能据旧注释删掉后三项，亦不把旧13项局部审查冒作16项源码审计。

旧hist存六索引八词的非负计数，`oq.groups`给三轨道(family,diag)=(0,0),(1,0),(1,1)，边数ct=30、30、6。非对角词对重数n=h_wh_v−1_{w=v}h_w；对角只w=v且n=h_w。member0/1分别选旧R/Z作T。

`row`约定点积≥0，对轨道各边的(3)作**归一平均**。K列0系数为f；每hist列的系数为actual源份额+(d+e)actual末份额，减

\[
 \sum_g\frac{n_g}{ct}\psi_i(p,\ell,0,q_g(0);\theta).
\]

对应所选轨道且state[member]=1的joint列再放

\[
 -\frac{n_g}{ct}\left[\psi_i(p,\ell,1,q_g(1);\theta)
 -\psi_i(p,\ell,0,q_g(0);\theta)\right].\tag{4}
\]

qi12时q随t变化，代码分别调用qvec(...,0)与qvec(...,1)，没有误冻结q。其它joint和全部overlap列为0；三显式joint状态01/10/11读出t=1边际，00由hist扣余项。完整每轨道Σn=ct，源/actual末价/K才各按上述权付一次。

这一行与旧[有理网格](旧查询回复的有限网格分离程序--程序.md)和[连续分层](旧查询回复的连续分层分离程序--程序.md)采用的未除ct行不同；即使正比例缩放不改必要性，列系数、余量和图中记录身份不能直接混用。`row`以最近hist绑定随后joint，未核hist_column_old；列布局、全质量和乘子合法性是调用前提，不是函数返回Fraction便自动满足。

## 六参数发现LP与两次float筛选

`find_cuts(cols,ys,queries=(5,),sources=range(4))`先调用pc.parse：输入质量转float，聚合hist会员、R/Z边际和actual六收益u；K另从所有kind=K列float求和。对每个结构，将正质量严格大于10⁻¹²的状态按(p,ℓ,t,q)合并，丢掉其余状态；它不验证负质量是否合法，也不修复浮点舍入或输入缺列。

令m_s>0为保留质量。LP有六个参数和每状态一个自由变量z_s，对每隐藏候选加

\[
 z_s-\operatorname{co}_{s,h}\theta\le\operatorname{base}_{s,h}.
\]

最小化

\[
 (d+e)u_6+fK-\sum_s m_sz_s,
\]

预算中的uᵢ₊₁在求解后加上判断符号。因m_s>0，理想精确LP会把z_s推至全部上界的最小值，即ψ。发现参数盒为a∈[0,1]、其它五参数∈[0,1000]；一般行的合法性只需非负，不受1000上限限制。但程序没有盒内精确最优证书，也未搜索盒外。

源层流程明确分三步：

1. HiGHS返回success且uᵢ₊₁+fun<−10⁻⁹，才提出候选。
2. 六参数逐个用`Fraction(float).limit_denominator(10^6)`重构，再由`row`生成完整有理行；函数内第二次点积筛选仍把行与点权都转float，要求<−10⁻⁹。返回的是(float slack,cut,Fraction row)，未在此精确证明负性。
3. **独立CLI入口**才对每个返回行与原有理ys作完整Fraction点积并assert严格负，然后写精确slack。

因此其它调用者只用`find_cuts`返回值时，必须自己补第3步。原码有理化后未显式检查a∈[0,1]及其余参数非负；当前五项的共同参数逐项合法，任意外来cut仍需复核。没有使用`-O`运行本次入口，断言实际生效。

默认4源×2member×3轨道×1查询A₆共24LP；`--all-queries`换16查询，共384LP。attempted计调用数，包含失败求解，并非成功最优证明数。此程序没有maxcuts或64截断，按第二次float slack升序返回全部通过项；这不是按精确Fraction重新排序，也没有合并相同系数行。

未保存LP中间解、失败状态、每个未入选结构的精确对偶或实际负性过滤原因。所以“未selected”不能直接解释成严格不可分离；有限样本阴性不证明原模型普遍结论。

## 可复用条件与当前缺口

`candidates/psi/row`本身用有理数；`find_cuts`是浮点发现器；CLI最后的精确负点只证明该指定必要点被合法行分离。补入新行后必须对新图的同一个点重新优化/恢复，原点没有自动继承可行性，反之一个被切点也不证明全图不可行。

命令需要两个位置路径，输出父目录必须存在，同路径会覆盖；只有`--all-queries`这一字符串被额外识别，没有完整输入/参数验证或标准help流程。未提供argv会在读路径时失败。这些控制流边界来自实读，没有为清洗故意触发失败入口。共享输入列顺序、唯一K列0、非负质量、六索引词以及所有乘子范围均须由调用端保证。

一般证明来自七条同策略真实行和最小值方向；有限24LP及指定五行独立核验各有自己的范围。未提供有限单位客户共同实现、完整有序历史策略、任意离轨IC或全类型半覆盖证书。已有来源/实现/数据使用关系保存在本包，第三阶段图未改，不认领新颖性或外审。
