# 恰六人半覆盖

存档ID：`customer-attraction/six-providers`。父存档：`customer-attraction`。

恰六名单位权提供者、任意有限单位客户和有限非空共同目录；每一个完整历史纯SPE覆盖数≥最大六主题覆盖数/2，允许空、重复、零客户及任意离轨平局。

## 研究入口

恰六人半覆盖仍开放。用[数学研究 Main](../../../../prompts/research-runtime.md)启动，在 `start` 指定 `--save customer-attraction --subarchive six-providers`。新 RUN 引用[恰六人原题](问题--问题.md)和[共同目录完整历史模型](../../state/定义/共同目录完整历史模型--定义.md)，从当前要解决的证明义务选择已有对象和超边。

## 内容位置

- [问题身份](问题--问题.md)
- `state/`：按数学对象类别组织自足Markdown，可随清洗增加新类别。
- `workspaces/`：Boss/清洗者个人临时研究，可自由保存未成熟内容。
- `papers/`：论文稿件及其必要依赖，保留与正式数学对象的对应。
- `tools/`、`evidence/`：本题计算程序、真实输入与核验证据。
- [现行登记](../../../../research/registry.json)：研究时用 `research show` 和 `research context` 按对象 ID 取原文与超边。
