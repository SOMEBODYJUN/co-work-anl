# 4067B程序的输入、算术与每个函数

程序仅用标准库Fraction、itertools.product、math.comb、Path、argparse、json，没有外部输入文件，不导入发现者代码、规范CAG包、LP、浮点库或随机发现器。run内所有参数和客户字典显式固定。

rank是流式精确行消元，basis按pivot排序；每个已有basis在其pivot前为零，逐pivot消去后不会重新引入先前pivot。它只返回秩，不求完整SPE约束矩阵Γ，也不返回非负Farkas乘子。comps穷尽总数m的非负计数向量；payoff只在q_a>0时调用，因此类型包含a时分母≥q_a>0，不包含a直接Fraction0。空类型不在行列域中。

moments直接计算非空|A|≤m交集矩。check_game先断言两字典全部这些矩相等，再对每个p进制m长有序path：由path计数q，依**每个玩家位置**a∈path比较两字典支付，并比较该叶覆盖。重复a在path中会按位置重复比较，所以ordered_payoff_checks不是不同(q,a)行数、不是玩家行动偏离数。它不构造任一策略、不做逆向归纳，也不枚举SPE。全历史策略保持来自相同完整叶支付表的逻辑证明。

finite_difference_identities=190，实际循环m1…19及s1…m，Σm=190，逐项精确比较

$$\sum_{j=0}^{s-1}\frac{(-1)^{s-1-j}\binom{s-1}j}{m-s+1+j}
