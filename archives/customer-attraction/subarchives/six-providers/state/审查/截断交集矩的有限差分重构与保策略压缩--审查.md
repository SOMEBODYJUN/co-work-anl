# 全部终局收益的精确秩

固定m≥1位单位提供者，p≥1个共同标签P=[p]。非空兴趣类型B⊆P的重数r_B为非负有理数；整数重数表示不同单位客户，空兴趣客户不影响收益/覆盖。空主题、同覆盖异标签和反复选题均允许。定义交集矩

$$z_A(r)=\sum_{B\supseteq A}r_B,\qquad \varnothing\ne A\subseteq P.$$

总数为m的终局计数q∈Z_{≥0}^p中，仅对q_a>0定义

$$f_{q,a}(B)=\frac{\mathbf1_{a\in B}}{q(B)},\quad q(B)=\sum_{b\in B}q_b;$$

分子零时整项定义零，非零时分母≥1。令x_j(B)=1_{j∈B}，V_{m,p}是所有非空|A|≤min(m,p)单项式x_A=∏_{a∈A}x_a的Q线性空间。

对K=supp(q)，逐Boolean点有

$$f_{q,a}(x)=x_a\int_0^1t^{q_a-1}
 \prod_{b\in K\setminus\{a\}}[1+(t^{q_b}-1)x_b]dt.$$

x_a=0两边为零；x_a=1时积分是t^{q(B)−1}，准确给1/q(B)。因此它是无常数项、支持包含a且位于K的多线性多项式，次数至多|K|≤m，故全部收益行都在V_{m,p}。

反向固定非空A、s=|A|≤m，选a∈A并取q_a=m−s+1，其他A中标签各一次。最高次x_A系数的有限差分为

$$\begin{aligned}
\gamma_{m,s}
&=\sum_{j=0}^{s-1}(-1)^{s-1-j}\binom{s-1}j\frac1{m-s+1+j}\\
&=\int_0^1t^{m-s}(t-1)^{s-1}dt
=\frac{(-1)^{s-1}(m-s)!(s-1)!}{m!}
=\frac{(-1)^{s-1}}{s\binom ms}\ne0.\tag{1}
\end{aligned}$$

其余单项式只在A真子集上。按s递增消去真子集项，便从这些合法m人收益行恢复全部x_A。单项式在非空类型域仍独立：若某组合在全部非空点零，它在空点也自动零，补回空点后由Boolean Möbius反演所有系数零。因此

$$\boxed{\operatorname{span}\{f_{q,a}:|q|=m,q_a>0\}=V_{m,p},\qquad
D_{m,p}=\sum_{s=1}^{\min(m,p)}\binom ps.}$$

m1时收益行正是x_a，p1时所有收益只有x₁/m，这两个边界同在证明中。有限程序190组系数和20组秩只核实现，不取代任意m,p的非零系数/三角证明。

# 同矩精确保留全部有序历史纯策略及最优覆盖

两份资料r,r′对所有非空|A|≤m有相同z_A，当且仅当它们有相同的全部m人终局逐玩家收益表。正向由收益属于V，反向由全张成推出与每个x_A正交。对任何固定完整历史形式策略σ，任意节点h及偏离b沿**同一σ的真实续局**产生两个有序叶，SPE行是它们相应玩家收益之差，所以每一个比较数值都保持。包括离轨历史、同计数而回复不同的历史、弱平局和规定动作自比较。

因而在同一标签域，两份合法实例有完全相同的全部完整历史纯SPE集合及每份策略的路径与收益；这是保整个叶支付表的结果，不是将策略匿名化/限制为计数Markov。程序本身不枚举σ或验证Γ，数学等价由上述理由成立。

至多m个不同标签J的覆盖行是

$$1-\prod_{a\in J}(1-x_a)
=\sum_{\varnothing\ne A\subseteq J}(-1)^{|A|+1}x_A\in V_{m,p}.$$

因此全部m人终局覆盖、全部比较组合覆盖及其最大值OPT_m均保持。核变化不能保持W却改变OPT_m来创造新的效率比；若涉及m+1标签，已经超出这个合同。

覆盖坐标C(T)和交集坐标z_A经上述容斥/Möbius变换互相可逆，所以与父档覆盖矩表示是同一环境空间的不同基。线性同空间不提供非负激励乘子，也不提供合法矩锥的所有对偶余项。

# 有理非负压缩及标签边界

令矩列v(B)=(1_{A⊆B})_{1≤|A|≤m}∈{0,1}^{D_{m,p}}，每个非空B的列非零且非负。若r的正类型数大于D，支持列有非零有理依赖δ，且δ必含正负两符号，否则非负非零列不可能相消。取

$$t=\min_{\delta_B>0}r_B/\delta_B>0,\qquad r'_B=r_B-t\delta_B.$$

新r′非负、保持所有矩、支持外不增新类型，至少一个原正类型消失。有限重复得至多D个正类型。全部算术有理，最后统一清分母L，逐份重数展开为不同单位客户；收益、福利及OPT_m统一乘L，全部SPE与效率比保持。不声称总客户数不变、标签数有界或位复杂度为多项式。

m≥2时

$$|S_a\triangle S_b|=z_a+z_b-2z_{ab}$$

以及单主题大小z_a都保持，因此原空主题和不同/相同覆盖关系均保持。m1只保单主题大小，不能推覆盖是否相同；坚持原标签不合并时叶表/SPE仍按标签保持。若另行把相同覆盖标签商掉，那是改变策略定义域的操作，不是原逐标签完整策略集合的一一对应。

父档锥对象证明m≥2全部非空类型为不同极射线，这与自适应压缩相容：每份实例可选自己的至多D支持，不等于存在一个预先固定真子集生成所有实例。原独审也没有将坐标非负代替真正非负客户锥。

# 奇偶核与显式15类型到8类型

设p=m+1。E在每个非空偶基数B放一名客户，O在每个奇基数B放一名客户。对任意非空|A|≤m，至少一位标签在P\A，翻转这位就在奇偶超集间配对，故

$$z_A(E)=z_A(O)=2^{p-|A|-1}.$$

E的客户总数2^{p−1}−1，O是2^{p−1}，却具有相同完整m人收益表、所有SPE、W及OPT_m；所有p标签同时覆盖的总数相差1，是超出可见阶的信息。m2/p3的直观例是E三类型{12,13,23}和O四类型{1,2,3,123}，各单主题2、两两交集1。

独立原程序另给p4/m2显式压缩：原r_B=1对全部15个非空类型；压缩r′_B=2对8个奇基数类型，其余0。任意非空|A|≤2有

$$z_A(r)=2^{4-|A|}=2\cdot2^{4-|A|-1}=z_A(r').$$

所以正类型从15变8≤D₂,₄=10；**实际单位客户从15变16**，并非客户总数减少到8。每主题大小8、每对交集4、每对对称差8。终局重复同主题时每位4、W8；两个不同主题时每位6、W12。这些支付表直接相同，不需要调用任何策略求解器。该例未运行有理列消元算法，是从核手写出来的显式见证；一般压缩由前节证明，发现者另一8252B脚本的随机实例消元是不同实验。

# 合法矩锥和低次局部正性仍有实质约束

三标签数据z₁=z₂=z₃=1、z₁₂=z₂₃=9/10、z₁₃=1/10，各对满足0≤z_ij≤min(z_i,z_j)，却违反共同非负客户逐点有效行

$$x_1x_2+x_2x_3-x_1x_3\le x_2,$$

其矩余量为9/10+9/10−1/10−1=7/10>0。x₂0时左边−x₁x₃≤0，x₂1时x₁+x₃−x₁x₃≤1，故这是所有Boolean类型包括非空类型的真实约束。这不是合法CAG反例，而是不合法低阶矩点。

同样，二次多项式

$$P=x_2-x_1x_2-x_2x_3+x_1x_3$$

只在010和101取1，其他六点取0，故逐点非负。但P不能是固定至多两个标签会员位的cylinder指示函数之非负有限组合。若某正系数原子覆盖正点101，它至少遗漏一个坐标，翻转该坐标仍在原子里；对应零邻点001、111、100均非空。任何非负组合在这些P零点都只能各项零，矛盾。因此这个不可分解结论**直接在删除空类型后仍成立**，不需要假定空点等式。

父档[真子目录非负块独审](../../../../state/审查/真子目录非负块的独立审查与非空类型补全--审查.md)对一般p的另一族r_p、任意真子目录非负函数给更广结论，并以交错和补回空点；p2非空反边界另论。这里P恰是其p3、区别标签2的特例，选正点101使三个零邻点都非空，故是更短特例证明。不能把这一步冒称一般p的空点补全已由本源审过，也不把次数2与标签支撑2混同。4067B独审程序没有测试这两个局部障碍；它们的解析审核及发现者8252B程序检查分别保留。
