# 对象和处置范围

本页记录三份尚未逐源登记的浮点探针。三份文件都是程序源码，没有随源版本绑定的运行输出、argv、环境或精确证书；它们的独有内容是代码定义的优化域和失败边界。先前 `full-terminal-crosscap` 程序对象已经文字读取 `probe_path_menu.py`、`probe_full_push.py`，但没有把本批三个 source id 写入 `source_ids`；本页补上准确 provenance，并把新读的 `probe_full_dag.py` 与 R-275 固定六人输入分开归档。三源共享的冻结双提交内容逐字节一致，不能按两个提交计两套数学实验。

模型背景仍是有限单位客户、有限共同主题目录、提供者按全部有序历史行动、终局客户在覆盖者间均分。代码中的 `bits` 对每个非空主题掩码给一行，客户重数向量 `w` 是浮点质量；不是自动转回单位客户，也没有删除空主题、重复动作或离轨历史。

## `probe_path_menu.py`（source `547e882b4d3ad9496bf3`）

冻结文件大小 4315 字节，SHA-256 `c140c6e92cd83bec93a2f6fd74d7d22b36abc2f00f986f70b9f72a1f2ff4b33f`。`make_policy(n,k,w,rng,mode)` 从终局深度向根回推，按客户重数计算每个动作的即时终局收益；近似并列动作以 `1e-8` 浮点容差判定。`mode=0` 随机选并列最大者，`mode=1` 取最小标签，`mode=2` 用历史前缀收益和打破并列。这是一个启发式固定动作表：即使局部收益由当前浮点 `w` 最大，它也没有 Fraction 激励重放、精确最佳回复或对所有同计数历史的独立证明。

`build` 对每个有序历史和每个非规定动作构造

\[
\gamma_t(h,a)=\rho_t(\sigma(h),\operatorname{out}(h))-\rho_t(a,\operatorname{out}(h,a)),
\]

并移除绝对值小于 `1e-10` 的行。`full=False` 沿 actual 路径收集去掉当前强制动作的背景，`full=True` 保留完整终局计数；二者不是同一个付款接口，不能互换。返回的 `gamma`、背景集合、查询系数和 actual 覆盖向量只是浮点 LP 的输入。

`cap_lp` 用 SciPy/HiGHS 在固定背景集合上选择非负归一化客户质量，使每个背景的查询值同时封顶；这只是在已给动作表和已给背景集合上的有限 LP。原文件没有保存调用参数、输出或执行成功日志。本页没有重跑该搜索。

## `probe_full_push.py`（source `39ddf73bc1d5bf25a5fe`）

冻结文件大小 3039 字节，SHA-256 `51c6ee4e50eb04b1254401f1f1285d3b5a56518b645f6765fbc4d913a3b7ba63`。它依赖同目录 `probe_path_menu`，`tensor` 对每个查询行 `a`、强制源列 `b` 和兴趣类型 `t` 计算

\[
T_{a,b,t}=\sum_{i=1}^{n}\frac{\mathbf 1_{a\in t}}
 {1+\langle\mathbf 1_t,Z_i(b)\rangle},
\]

其中 (Z_i(b)) 是 actual 前缀第 (i) 位强制 (b) 后沿固定动作表得到的**完整**终局。`query_opt` 先枚举单点和二点线段临界点，再以 SLSQP 最大化对称矩阵二次型；它不是全单纯形的有理全局优化器。

`main` 在 `gamma` 激励行和当前查询债务约束下交替求客户质量 LP 与查询分布；每轮均使用 NumPy/SciPy 浮点值，只有 `1e-9` 改善阈值和 `1e-9` 收敛判据。它保留完整有序激励行，但没有精确 IC、dual 证书、全 p 证明、SPE 完整动作表核验或单位客户整数化。文件自身不包含生成的 `full_push_n{n}_k{k}.json`，因此不能声称某个正 gap 已被本源实际发现或复现。

## `probe_full_dag.py`（source `d5e889cb5255c08b5461`）

冻结文件大小 2561 字节，SHA-256 `52a1b9930000272bd6533f4deb314c8e461cdbd0bf431facd2e4e59418df2225`。它把 `ROOT` 下的 R-275 `direct_global/padded_residual_m6_dag.json` 作为固定输入；当前保存输入为六名提供者、九个主题、5440 个计数/目标节点，实际路径由 DAG 规定动作展开。脚本从节点动作和目标向量重建全部非自身激励行 `gamma`，沿 actual 路径收集每个合法强制动作的完整终局背景，并以 R-486 helper 的 `cap_lp` 计算客户分布。

脚本固定 NumPy seed 48692，最多 25 个随机起点，每起点至多 15 轮：先在 `gamma` 与当前债务约束下用 HiGHS 求客户质量，再用 SLSQP 选查询分布，记录 `gap=n*cap-c\cdot w`。输出状态字面量是 `floating discovery only; full-terminal path-menu support`；这清楚表明它是一个六人九主题**固定 DAG 动作表**的有限浮点发现器。没有 Fraction 恢复、全节点重新验证、整数客户展开、SPE 全策略枚举、SLSQP 全局性保证或全六人模型的量词。源码本身不含 `full_dag_best.json` 结果，也没有运行日志；输入 DAG 的已有精确菜单封顶对象是另一个固定菜单算术（见相关对象），不能把该输入的 75/23 saddle 证书倒填成此脚本的交替搜索结果。
