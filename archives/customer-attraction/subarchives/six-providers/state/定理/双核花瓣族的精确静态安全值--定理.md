# 量词、实例与结论

采用[原共同目录完整历史模型](../../../../state/定义/共同目录完整历史模型--定义.md)：有限不同单位客户、有限非空共同主题目录、单位提供者顺序观察全部有序历史、终局客户在覆盖者间均分。原主问题允许空主题、重复行动、零客户及任意离轨弱平局；本页只给其中一个非空显式实例族，不把一般策略限制成计数策略。

取整数n≥2、K≥1。两名不同客户构成核心A，另2(n−1)名客户构成B，K名不同私客c₁,…,c_K与A、B互不相交。目录恰为

$$A,\quad B,\quad C_j=A\cup\{c_j\}\quad(1\le j\le K).$$

总客户2n+K、目录K+2个标签，提供者可重复选任何标签。真正静态安全值为

$$v_n=\max_{p\in\Delta(\mathcal S)}\min_{H\in\mathcal S^{n-1}}
 \mathbb E_{a\sim p}\sum_{x\in a}\frac1{1+\operatorname{load}_H(x)}.$$

竞争元组H在抽取查询a之前固定；对偶允许H的任意联合分布Q，但Q不能观察这次查询。它不要求n−1个竞争者同分布、独立或来自真实顺序菜单。定义

$$D=2Kn+4K+n,\qquad s=4K/D,\qquad v=2-2/D.$$

**结论：对全部整数n≥2、K≥1，v_n=v。** 查询最优分布为p_A=0、p_B=1−s、p_{C_j}=s/K。对偶最优分布为：以概率α=n/D取B^{n−1}，其余概率取B^{n−2}与一个均匀C_j。

# 原始查询：对每个不观察查询的整数背景保证v

固定任意竞争元组H。把其中每一个A替换成任一C_j，不改变核心或B负载，只增加某一私客负载，从而不增加上述p的期望查询收益。因此下界只需检查不含A的H，原H的收益不低于替换后H。

记H中C主题总数r，0≤r≤n−1，其中C_j计数为q_j，Σq_j=r。B竞争者n−1−r名。查询期望准确为

$$F(H)=(1-s)\frac{2(n-1)}{n-r}
+s\left(\frac2{r+1}+\frac1K\sum_{j=1}^K\frac1{q_j+1}\right).\tag{1}$$

每个q_j是非负整数，故

$$\frac1{q_j+1}-\left(1-\frac{q_j}2\right)
=\frac{q_j(q_j-1)}{2(q_j+1)}\ge0.$$

因此私客平均至少1−r/(2K)，无须假定r≤K；该粗界即使为负仍有效。将s=4K/D、v=2−2/D代入式(1)的下界，通分化简得

$$\begin{aligned}
F(H)-v&\ge (1-s)\frac{2(n-1)}{n-r}
+s\left(\frac2{r+1}+1-\frac r{2K}\right)-v\\
&=\frac{2r(r-1)[2K(n+1)+r+1]}{D(n-r)(r+1)}\ge0.\tag{2}
\end{aligned}$$

所有分母正。r=0或1时可以取所有q_j为0或1，式(2)及私客界同时取等；r≥2时右边严格正。于是这个查询对每个合法H至少收益v，即v_n≥v。证明覆盖重复竞争主题以及任意排列，不从有限参数表外推。

# 对偶背景：对每一个纯查询同时封顶

取α=n/D∈(0,1)。Q以概率α令全部n−1人取B，否则令n−2人取B、一人均匀取C_j。它在查询抽取前确定。直接按客户均分得到

$$U_Q(B)=\alpha\frac{2(n-1)}n+(1-\alpha)2=v,$$

$$U_Q(C_j)=3\alpha+(1-\alpha)\left(2-\frac1{2K}\right)=v,$$

$$U_Q(A)=2\alpha+(1-\alpha)=1+\alpha\le v.$$

最后不等式等价D≥n+2，对n≥2、K≥1成立。所有纯查询均不超过v，任意混合查询也如此，因此v_n≤v，与原始下界相等。

Q可直接实现成n−2位竞争者确定选择B，最后一位独立抽取B（概率α）或各C_j（各概率(1−α)/K）。所以它甚至可由**不同边缘的独立**行动生成；本例静态安全值比iid基准低，不能归因为“竞争者必须相关”。承重区别是没有强迫每位对手取同一个查询分布。若再均匀打乱位置，会得到另一等值的可交换联合分布，静态收益因排列不变而不变。

# 与完整历史SPE的共同校准

以下另要求K≥2，以便末位能选另一花瓣。对每个长度小于n的有序历史h定义同一完整纯策略：根选A；其余非末位选B；末位若过去全B选C₁，若恰有一次非B且为C_j则选编号最小的另一C_l，其余情形选B。历史含任意重复A/C、任意排列及离轨动作均有定义。

令ℓ为当前历史非B行动数。以下每项收益都沿**当前改选后的同一完整策略**完成，而不冻结后继。任一被使用主题的终局收益为B的2(n−1)/b、A的2/ℓ′、C_j的2/ℓ′+1/c_j，其中b、ℓ′、c_j分别为相应终局正计数。

| 非末位前缀 | 当前选B的真实最终收益 | 改选非B的真实最终收益 |
|---|---|---|
| ℓ=0 | 末位补一个C，B共n−1，收益2 | A使末位改B，得2；C_j使末位改另一C，得2 |
| ℓ=1且唯一非B为A | 末位仍B，得2 | 再A得1；任意C_j得2 |
| ℓ=1且唯一非B为C_j | 末位补另一C，B共n−2，得2(n−1)/(n−2)>2 | A得1，同C_j得3/2，不同C_l得2 |
| ℓ≥2 | 未来全B，得2(n−1)/(n−ℓ)>2 | A≤2/(ℓ+1)，C≤1+2/(ℓ+1)≤5/3 |

第三行的非末位情形只会在n≥3出现；n=2没有对零分母求值。非末位ℓ≤n−2，所有实际分母正。根处ℓ=0，A、B、任一C真实最终均得2，故根规定A也最优。

在末位，过去ℓ=0时C收益3，优于A的2与B的2(n−1)/n；ℓ=1唯一A时B和每个C均得2，A得1；ℓ=1唯一C_j时B与不同C_l均得2，重复C_j得3/2，A得1；ℓ≥2时B收益2(n−1)/(n−ℓ)>2，其他行动≤5/3。因此规定末位动作全最佳。

这穷尽全部有序决策历史及合法行动，证明这份策略为纯SPE。它允许关键弱平局，不声称每份SPE都取该实际路径，也不删除其他任意平局策略。

实际终局AB^{n−1}，每人收益2，故W=2n。取B和min(K,n−1)个不同C达到

$$\operatorname{OPT}_n=2n+\min(K,n-1).\tag{3}$$

含B后余下最多n−1次行动只能增加同数私客；不含B最多覆盖2+min(K,n)名客户，对n≥2不优于式(3)。于是

$$W-nv_n=\frac{2n}{D}>0,\qquad
2W-\operatorname{OPT}_n=2n-\min(K,n-1)>0.$$

固定n而K→∞时第一余量趋零。本族接近真正强聚合等号，仍不否定它；K=1虽有上述静态闭式，但缺“另一花瓣”，不能宣称本完整策略成立。
