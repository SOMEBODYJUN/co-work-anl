# 从真正终局菜单构造完整可行种子

给定p≥1、根目标计数q、m=Σq≥1和2^p−1个整数克隆数，initial_vector先用ExactSPESolver求所有背景计数k的完整纯SPE可实现终局集合R(k)。这套集合值逆向递推为

$$M(k)=\max_a\min_{c\in R(k+e_a)}u_a(c),$$
$$R(k)=\bigcup_a\{c\in R(k+e_a):u_a(c)\ge M(k)\}.$$

每个孩子菜单非空；菜单按计数缓存不等于将策略强制计数化。完整双向数学证明见[终局见证等价](../../../../state/等价/终局见证DAG的完整历史可实现性--等价.md)，源码exact.py也明示同一合同。

先要求q∈R(0)，再以s=W(q)>0归一化。seed最前n=2^p−1个连续客户坐标为clones/s。状态与变量索引顺序准确复制旧dag.build：先每个计数k的全部可扩展终局y_{k,c}及非终端阈值t_k，再按k/行动/目标排列z_{k,c,a}与x_{k,a,c}，以防热启动向量错位。编码为：

- 非根Y(k)=R(k)，根只保Y(0)={q}，相应y置1，其余0；每叶y_{c,c}=1。
- t_k=M(k)/s。
- 对每个保留目标c，**单独选**合法a，使c∈R(k+e_a)、u_a(c)≥M(k)，将z_{k,c,a}置1。不同c可以选不同a。
- 对每个合法偏离行动a，从R(k+e_a)选使u_a最低的d；平局按终局计数字典序选，令x_{k,a,d}=1。这是每行动的共同低收益孩子。

于是所有二元坐标为0或1，子目标包含性成立，规定收益≥t≥每个惩罚收益。每个非根历史有唯一父节点，沿当前目标c选择z动作，规定孩子继续c、其他孩子继续相应x目标，即可展开一份完整有序历史策略。不同目标在同计数上回复不同是合法且必要的，不是需要净化掉的缺陷。

归一化和big-M=1的理由也需保留：任意非零根完整SPE的每个实际玩家均能查询任意主题T并至少得|T|/m，故W(q)≥|T|。除以s后所有主题质量、客户类型质量、子博弈单人收益和阈值都在[0,1]。未选中的z/x不等式因此自动松弛，以上精确有理编码满足旧DAG的完整有界约束。程序随后转numpy浮点；理论存在性不依浮点残差阈值成立。

# 审计的stub没有进行MILP优化

check_seed先取得seed，再把w.dag.milp替换为本地only_check函数。旧dag.build仍完整建立同一稀疏约束A、行界及变量界，但这个替代器仅计算

$$\begin{array}{ll}
\text{row_lower}=\max_i\max(l_i-(Av)_i,0),&
\text{row_upper}=\max_i\max((Av)_i-u_i,0),\\
\text{variable_lower}=\max_j\max(L_j-v_j,0),&
\text{variable_upper}=\max_j\max(v_j-U_j,0),\\
\text{integrality}=\max_{j:I_j>0}|v_j-\operatorname{round}(v_j)|.&
\end{array}$$

所有量以numpy浮点求得，断言五者最大值<10⁻¹²。stub返回x=seed、fun=c·seed、status0和message“seed only; no optimization”；这个status0不是HiGHS全局最优性。整个audit main没有调用WarmSolver.__call__、HiGHS.run/setSolution或固定锥exact_optimize/LP。

build从seed中的z/x选定目标，按全部有序历史展开StrategyCone，再以旧helper.independently_verify逐客户类型Fraction直接比较实际与每个强制行动后的真实终局。helper不调用规范certificate verifier，包含自身行动比较；但与发现器共用旧代码/Instance/终局接口，故应称“独立收益循环复核”，不能称整套solver和算术均独立。`Fraction`虽在3471B脚本自身导入未直接使用，精确部分实际发生在依赖helper中。

两层职责不同：浮点残差检查完整模型编码与索引，Fraction检查展开策略在原整数克隆输入上的真实IC。即使5项都显示0.0，也不把浮点模型逐行等式当精确有理证书。9844B模块导入时仍要求numpy、scipy及私有_highspy接口可导入，虽然这份audit不调用该优化器；代码合同不能简化为“标准库独立审计”。
