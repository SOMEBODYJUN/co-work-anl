# 对象和真实量词

本页整理四份发现源：899B旧36报告、3049B原程序、5508B保险浮点报告、5455B保险probe，共14911B。全部实际通过`clean show`全文读取；两份原程序均在隔离的原布局中原字节执行一次、exit 0且stderr空，生成的两份发现JSON分别与冻结原件逐字节相同。另有独立标准库有理核验。原字节、依赖、运行记录及核验程序见[证据入口](../../tools/evidence/boss5-shared-covariance/README.md)。这不是新游戏、一般福利定理或外部审查。

采用有限单位客户集N、有限非空共同主题目录S、m名单位权提供者依次观察全部有序历史各选一主题；客户在全部最终覆盖者之间均分。空主题、重复行动、零客户和任意历史平局在一般定义中均允许，见[完整历史模型](../../../../state/定义/共同目录完整历史模型--定义.md)。本页两个具体输入分别无空主题且客户非零，不能由此缩窄一般问题。

固定一份完整纯SPE σ，实际叶z、收益u_i及W=Σ_i u_i。位置i保实际有序前缀，强制A后沿**同一σ**的真实后继完成，再删除当前i槽，所得其余m−1个主题的客户负载记ℓ_i(A)。不是冻结在轨尾，也不是另选一份有利续局。真实当前偏离利润为

\[
d_i(A)=\sum_{x\in A}\frac1{1+\ell_i(A)_x}\le u_i.
\]

每行可独立选列分布q_i；共享负载域和查询目标为

\[
K=\frac1m\sum_i\operatorname{conv}\{\ell_i(B):B\in S\},\quad
L=\frac1m\sum_{i,B}q_i(B)\ell_i(B),\quad
F_p(L)=\sum_x\frac{\rho_x}{1+L_x},\quad \rho_x=\Pr_{A\sim p}(x\in A).
\]

每个L是m−1份合法分数目录行动的负载；本页不把它替换为任意坐标cap、实际负载缩放或同一p自推送的受限域。客户压缩重数w_x只表示若干同覆盖的不同单位客户，上述各和应乘w_x，不是改成加权提供者。

# 为什么要区分可行点、固定查询极小点与真鞍点

对任意L≥0令t_x=(1+L_x)^{-1}，定义

\[
I=\sum_i[u_i-\mathbb E_p d_i(A)],\quad
C=\sum_i\mathbb E_p\sum_{x\in A}t_x^2(\ell_i(A)_x-L_x),
\]
\[
D=\sum_i\mathbb E_p\sum_{x\in A}
\frac{t_x^2(\ell_i(A)_x-L_x)^2}{1+\ell_i(A)_x}.
\]

由逐客户恒等式

\[
\frac1{1+z}=\frac1{1+l}-\frac{z-l}{(1+l)^2}
+\frac{(z-l)^2}{(1+l)^2(1+z)}
\]

直接得到

\[
\boxed{W-mF_p(L)=I-C+D.}\tag{BAL}
\]

此式不要求L极小；I≥0来自原完整SPE，D≥0逐项成立。因此可行有理点上精确BAL与C的符号，不能认证该点最优。若L由q实现，固定p凸极小性的充分必要一阶条件是：q_i每个正支持列都最大化

\[
V_i(B)=\sum_xw_x\rho_xt_x^2\ell_i(B)_x.
\]

负梯度符号必须如此。定义正支持残差

\[
R=\max_{i,B:q_i(B)>0}\{\max_{B'}V_i(B')-V_i(B)\}.
\]

R=0时有固定p的精确KKT；R>0可沿单行质量转移严格下降目标，故该q对应的L不是极小点。固定p最优另不等于外层max_p min_L的真鞍点，还须核查询活跃性。

SHARED候选是对每个p都有min_K F_p≤W/m；有限凸minimax将它转为存在一个共同L封住所有纯查询。它是一般half的充分桥，尚非本页证明的结果。C≤0只是更强的辅助符号要求；完整付款C≤D+I以及允许额外half余量的较弱付款不能因C>0自动判失败。

# 三人旧36客户：有理点精确，但其最优性实际不成立

主题0,1,2为X组，3,4,5为Y组。每跨组二元兴趣各有1客户；每种“两X两Y”兴趣各有3名不同客户，总9+27=36。根选0；第二位首标签在X时选3，在Y时选0；末位取第二位所属组中此前未用的最小主题。冻结策略JSON逐项给全部1+6+36=43个有序节点。实际叶034，u=(10,12,12)，W=34；同组三主题覆盖全部36。

本次独立读取原输入和43节点表，对每节点六个行动共258条IC逐一用Fraction核非负。因此本例SPE身份在这份三人完整树上另有实际全历史检查；这与保险的180实际前缀检查不同。

全部真实删槽背景按强制行动0,…,5排列为

| 实际角色 | 六个删槽背景；例如01表示主题0与1各一份 |
|---|---|
| 1 | 34，34，34，01，01，01 |
| 2 | 01，02，01，04，03，03 |
| 3 | 03，03，03，03，03，03 |

原程序固定p=(0,0,1/2,0,0,1/2)，数值求解SLSQP后将每坐标分别限制分母至10000，得到

\[

\quad q_2=(0,1,0,0,0,0),\quad q_3=(1/6,\ldots,1/6).

每行确实非负且精确归一。真实p查询利润逐行都是(10,12,12)，故I=0，独立核验确认原JSON的硬编码`IC_sum="0"`在这个输入上正确。以此q构成L时，完整有理结果为

\[

\approx10.272902708553012,
\]
\[
C=\frac{-2945446159470261845066309387726687909687417765013}
{2278879101159456348728912972992835101266996491200}<0,

\[

{2278879101159456348728912972992835101266996491200},\quad
W-3F_p(L)=\frac{10164901299466394918296813}{3195211788472614602485024}=D-C>0.

但是

\[

所以冻结q不只是“尚未认证最优”：它**不是**精确最优点。原注释称有理化候选须过单纯形及KKT，但实现只有前者assert；后者只打印残差，没有断零。冻结scope谨慎写最优性未认证，冻结JSON又没有保存这个残差；本页补上实际程序与文字之间的区别。

原脚本还只对BAL作精确断言、将I写死为0、并未逐项核43节点完整IC。本次独立核验补齐这些固定输入义务，未将原代码改成另一个版本。原运行浮点minimum=10.272902708553012、success=True，原有理化q与冻结记录相同；浮点值与有理值显示相同小数不消除上述严格正残差。

该可行点已足证明**此p**的min_K F_p≤F_p(L)<34/3；不证明其他p，也未证明一般C≤0。后续[旧36全查询自由列精确值](../../../../state/计算/三十六客户自由删槽菜单的全查询精确值--计算.md)已证明较强的倒数先平均菜单预算对全部p最大值164/5<34，所以经Jensen该实例整个p单纯形也满足SHARED。164/5是另一线性菜单游戏的总值，不能写成这里固定p凸目标的极小值。

# 六人保险：浮点JSON保存发现，probe末段另有精确恢复

经济客户e0,…,e5各一名；银行B0,…,B4各含两名不同单位客户，所有块互不交。共同主题(a,b)={e_a}∪B_b，共30个三客户主题，共16客户。若经济/银行占用人数为n_a,n_b，收益为1/n_a+2/n_b。

两原程序在所有有序历史用BASE/PUNISH/EXIT控制器，不把同计数历史识别。任意根行动作实际锚点；BASE非末位复制经济锚并取新银行，联合行动偏离若取新银行则进入PUNISH、将**此次过去银行**固定为处罚目标，若取旧银行则进EXIT。PUNISH非末位取双新标签、旧银行偏离转EXIT；末位取新经济并复制固定目标。BASE末位取新经济并复制根银行；EXIT永久取双新标签。

完整SPE来自[全m控制器解析定理](../../../../state/反例/笛卡尔银行目录的逐人分数门槛反族--反例.md)：EXIT有银行重复，因此剩余新银行数足够、指定收益3达裸上界；PUNISH非末位指定收益3，末位新经济加任一已占银行得2且最优；BASE中间指定收益2+1/(m−1)>2，任何改变经济或银行的联合偏离被既有银行共享或固定目标复制压至≤2；根重锚收益恒1+1/(m−1)。这些不变量覆盖再次偏离，给全部有序历史量词，不能用下面180个列替代。

实际叶为

\[
z=((0,0),(0,1),(0,2),(0,3),(0,4),(1,0)),\quad
u=(6/5,11/5,11/5,11/5,11/5,2),\quad W=12,
\]

而六主题可覆盖全部16客户。probe重建6×30=180个实际位置强制列，并用11坐标压缩16客户，银行求和乘2。固定p均匀于30主题，ρ经济=1/6、银行=1/5。

前段SLSQP返回success=True，冻结JSON全部六行30个q坐标及11个L坐标均保原字节；其标量为F≈1.6136363636363837、C≈0.450275478779787、D≈1.4940128525170422、I≈1.2744444444444554、W−6F≈2.3181818181816976。原浮点断言仅总BAL误差<1e−8，success不构成精确最优证明。本次从冻结q重建L/F/C/D及真实I，与冻结字段最大误差约1.09×10⁻¹⁴，行和最大误差约2.23×10⁻¹⁶；这些是固定报告的一致性检查。

不过把**整份probe**称“仅浮点”也不准确：冻结代码在写出发现JSON后，对m==6继续用LP寻找实现指定有理L的q，将LP坐标限制分母至100000，再精确断每行单纯形、全部11负载等式、最小锚负载、BAL、C>0以及正支持KKT。LP或有理化若失败会在精确断言停下；它没有承诺任意m有这种证书。m来自argv，无参数解析、main guard或默认值；不应直接导入当无副作用模块。旧36程序同样顶层即执行，并按`parents[6]`读取两个仓库布局依赖。两原程序都会覆盖自身附近的JSON，所以本次只在临时布局执行并另存输出。

probe的精确段另写`insurance_shared_covariance_m6_exact.json`，不会将其精确标志混入先写的5508B浮点报告。其稀疏q为

# 后续纠错、复用及停界

固定uniform30的C>0仅否定“每个固定p最优负载均C≤0”。uniform30不是外层最优查询，故本批四源自身不直接关闭“只要求真鞍点零C”的加强。后续[双精确证书](../../../../state/计算/共享菜单固定查询与全局鞍点的双精确证书--计算.md)与[独审](../../../../state/计算/银行共享鞍点独审的真实输入与全量词边界--计算.md)区分了该量词：改用25个非锚主题均匀查询p*，同L*构成真正鞍点γ=37/22；锚主题价格14/11较低，非锚价37/22。严格凸性加经济槽总数给全局primal唯一，互补性迫每个最优查询都无锚支持。

整个非锚支持上各角色C值恒为795/484及其余五行−105/484，所以**每个**外层最优p及每份保持其平均边际的角色查询运输均C=135/242>0。不同q实现也不改变C。这一更强量词是后续解析论证，详见[全部最优鞍点正相关反例](../../../../state/反例/共享菜单全部最优鞍点的正相关项--反例.md)，不是本次发现probe枚举所有p、历史或SPE。均匀p*的D=2017/1210、I=4/5不自动升为全部最优运输下分别恒定。

这里固定uniform30有71/44<2，真鞍点有37/22<2=W/6，故两者仍有足够BAL付款。C正反驳零C加强，未反驳C≤D+I、SHARED、较弱half付款或六人half。当前五人half另有证明；旧稿五人开放时态不回写成当前结论，六人目标仍按其独立[问题](../../问题--问题.md)接续。

本页与现有对象的关系是：保留原发现和软件证据合同，补充旧36严格正KKT残差与当前原字节复现；数学后续由既有正C反例/精确证书承接，未建立一个新银行反例身份。可复用独立`verify.py`检查固定输入字段，或`run_original.py old36|insurance`在临时原布局重放。若研究一般付款，仍须在同一原K、同一完整σ、同次查询及真实后继IC中控制混合C，不能丢掉D/I，也不能把单一可行点阴性诊断当普遍符号证据。关系判断已在此按来源、实现、有限检查和后续加强分开；第三阶段超图由协调者统一维护。
