# 跨枝完整利润金额归一仍不足以得到单列 cap1

2026-10-24，coupling。**精确辅助候选反例；父方、credible 与 independent 已分别解析重构通过。** [credible 逐类型审查](../credible/review_amount_cap1_family.md)、[independent 先重构后对照](../independent/amount_cap1_family_review.md)保留实际范围；父方另重放 n=3，原输出逐字匹配。无外审或新颖性认证。任意人数一般模型允许这些输入。构造对每个整数 n≥3 成立，不以有限计算证明全称。它没有反驳 Q-CAG-HALF；事实上本族实际福利等于最优福利。

## 1. 被否定的精确候选

固定一份完整有序历史纯 SPE σ，令 parent 叶 P 为其实际根叶，角色数 m。分枝索引为 α=(iα,Tα)：在 P 的真实前缀 P_<iα 后，强制当前主题 Tα，随后使用同一 σ，得真实偏离完成叶 Wα。**同一 cut 可以有多个不同 forced 主题。**

对每个 j<iα 和 l≥iα，定义标准 prefix 回推正价

    qα,jl = Σ_{x∈P_j∩(P_l\Wα,l)} 1/[cP(x)cWα(x)]。

记 p_j(F) 为角色 j 在完整叶 F 的利润。允许非负完整利润 claim 系数 λα,j，并给每个 sender j 同一 parent 的**总金额预算**

    Σ_{α:j<iα} λα,j p_j(Wα) ≤ p_j(P)。              (AMOUNT)

AMOUNT-CAP1 候选声称每个 l 的 prefix 正价共同输出满足

    Σ_{α:iα≤l} Σ_{j<iα} λα,j qα,jl ≤ p_l(P)。      (CAP1?)

以下家族严格否定 CAP1?。它没有否定“同一 W、所有输入系数均≤1”的既有列次随机合同：本族不同 sender 选择不同 W，且所用单行系数可大于一。

## 2. 单位客户、共同目录与 parent 叶

取 m=n+1。令 X_1,…,X_n,Y_1,…,Y_n 两两不交，全部客户价值一，且

    |X_j|=2， |Y_j|=2(n−1)。

共同有限目录含恰 2n+1 个主题

    A_j=X_j∪Y_j， T_j=Y_j   (1≤j≤n)，
    D=∪_{j=1}^n X_j。

所有玩家单位权，允许重复主题。X_j 仅属于 A_j、D；Y_j 仅属于 A_j、T_j。

规定 root 路径为

    P=(A_1,…,A_n,D)。

其利润和福利为

    p_j(P)=2n−1  (j≤n)， p_m(P)=n，
    W(P)=n(2n−1)+n=2n²。

全部客户已由前 n 个 A_j 覆盖，因此 OPT_m=W(P)=2n²。

## 3. 完整有序历史 SPE 的自足构造

称历史 h 为 fresh-A 历史，当且仅当其所有行动都是两两不同的 A_j。包括空历史。按有限树从叶向根逆向构造 σ：

1. 在长度 t<n 的 fresh-A 历史，规定最小下标的未用 A_j。
2. 在长度 n 的 fresh-A 历史，规定 D。
3. 在任何其余有序历史，选择已经构造完毕的真实子续局中使当前玩家利润最大的行动；平局任取固定标签序最小者。

该递归在全部有序历史定义，包含任意重复、任意 T_j 以及任意 D 历史。一个历史一旦非 fresh，其 T、D 或重复 A 缺陷在所有后代永久保留，因此第三类是封闭子树，按定义满足 IC。须证明前两类 override 也最优。

### 长度 n 的 fresh-A 历史

全部 A_j 已各用一次。最后人选 D 得 n；选任何 A_j 得 |A_j|/2=n；选任何 T_j 得 |Y_j|/2=n−1。故 D 是合法最佳回复。

### 长度 t<n 的 fresh-A 历史

规定新的 A_j 后，后续仍是 fresh-A，最终所有 A_j 各出现一次、末位选 D。当前利润为 2n−1。逐类检查任何偏离：

- 改用另一个未用 A_j，后续也是上述 fresh-A 路径，仍得 2n−1。
- 改用已用 A_j，前缀已有相同主题，最终每名该主题玩家的利润至多 |A_j|/2=n≤2n−1。
- 改用任何 T_j，无论真实后继如何，利润至多 |T_j|=2n−2<2n−1。
- 改用 D：若 t≥1，至少一个 X_j 已被前缀 A_j 覆盖，当前在该两客户块最多得一；其余 D 客户各最多得一。因此利润至多 2n−1，与后继无关。
- 剩下 t=0 改用 D。此后最后玩家不可能选任何 T_j，因为在同一最后历史改用 A_j 保留全部 Y_j 利润，并严格增加正的 X_j 利润；T_j 被 A_j 严格支配。故最后玩家选某 A_j 或 D，其行动触及至少一个 X_j。root 的 D 在该块最多得一，在其余 D 客户各最多得一，仍至多 2n−1。

末条使用的是同一份递归策略在真实离轨最后历史的最佳回复，没有冻结后继。由逆向构造，所有第三类后继已是完整子 SPE，所以最后最佳回复可合法使用。所有 override 最优，σ 因而是全部有序历史纯 SPE。任意同标签收益相等的平局均被保留为允许选择；没有声称全部平局选择都给本族路径。

## 4. 不同末位 forced 主题造成同一列过订

对每个 sender j≤n，单独取分枝

    α_j=(m,T_j)， Wαj=(A_1,…,A_n,T_j)。

这些是同一最后节点的不同真实 forced 行动；没有后继须冻结。Wαj 中，X_j 只由 A_j 覆盖，Y_j 由 A_j,T_j 两人均分，故

    p_j(Wαj)=2+(n−1)=n+1。

而在 P 的末位 D 利润回推正边上，只有 X_j 两名客户有贡献：其 cP=2、cWαj=1。因此

    qαj,jm=2/(2·1)=1。

仅对 (α_j,j) 设

    λαj,j=(2n−1)/(n+1)，

其余系数均为零。每个 sender 的 AMOUNT 正好等于 p_j(P)。同一 recipient m 的总正价为

    Σ_j λαj,j qαj,jm = n(2n−1)/(n+1)
                       = [(2n−1)/(n+1)] p_m(P)。

当 n≥3，系数 (2n−1)/(n+1)>1；当 n→∞，该系数趋于二。因此如果一般 AMOUNT-CAP2 成立，二无法统一减小。这个 sharpness 只针对这一精确 prefix 正价合同，不是关于 HALF 锐例的新声明。

本族每个 sender 选择一个不同 α_j，分枝索引不能错误限制成每个 cut 至多一个孩子。输入系数大于一的来源是**金额归一**：p_j(Wαj)<p_j(P)，并非每个相同完整利润 claim 系数仍≤1。

## 5. 尚未支付的义务与复现范围

末位 cut 的一般 AMOUNT-CAP2 可由 p_j(P)≤2p_j(Wα) 和同客户全部 prefix coverer 计数得到；见父目录的[终层证明](../parent/terminal_amount_cap.md)。这里给它的 sharpness，不证明更深 cut 的二。

多尾分枝中，p_j(P)/p_j(Wα) 可随尾长增长。真正 DEEP-AMOUNT-CAP2 若成立，必须使用原 σ 在真实尾部全部有序历史的理性，或给不同的一般金额耦合；不能把终层的逐客户二分之一界无证外推。
