# 完整根菜单的交叉pair加强：已有根反例与背景解析pair

2026-10-24，round7/security。研究对象是任意人数、任意有限共同目录和每份完整有序历史纯SPE的一般Q-CAG-HALF。本文只处理本轮提出的一个普遍候选，不开展固定人数或结构类正面研究。**一般half、根extra-one及一般聚合安全值仍OPEN。** 下列根反例是重放旧资产后的新用途，不是新游戏；大背景pair是已完成独审构造中的显式两枝计算。没有外审或新颖性认证。

## 1. 候选与逻辑强度

固定合法背景b和r人完整纯SPE。强制首位选A，随后跟随同一原策略，所得完整r槽叶为Z_A，首位收益为d_A；真实首位最优收益u满足d_A≤u。令

\[
K_{B,A}=G_B(Z_A)=\sum_{x\in B}\frac1{b_x+c_x(Z_A)+1}.
\]

本轮交叉pair候选为

\[
d_A+d_B\ge K_{B,A}+K_{A,B}.\tag{PAIR?}
\]

即使把左边换成2u，下面的空背景旧游戏仍反驳该加强。若(PAIR?)普遍成立，取A,B独立同分布p便给

\[
\sum_Ap_A d_A\ge p^TKp.
\]

每列Z_A是合法r槽静态竞争背景，所以对真正安全最优p，右边至少v_(r+1)(b)。因而(PAIR?)会蕴含首位u≥v_(r+1)(b)，进而蕴含已被分离的任意背景PB-extra。这已是一个不需要找pair的逻辑停界。§3另给出该PB构造中的显式pair。

## 2. 空背景pair已由旧348客户完整SPE分离

来源为另一桌面[完整根菜单义务](../../../R-d22a706a03c5499d941a6a97f94128a8/induction/full_root_menu_mixed_obligations.md)中已记录的高插入2-cycle及其[原冻结证书](../../../R-d22a706a03c5499d941a6a97f94128a8/representation/high_insertion_2cycle_348_exact.json)。这里没有修改客户、主题或策略。

游戏有六主题0,…,5、三位玩家、348个不同单位客户。原证书给定全部43个有序决策历史的行动。独立重放不导入原求解器，从客户兴趣类型计算全部258项含自身比较，等价于215项真实偏离，全部SPE激励成立。强制根六种行动的真实叶依次为

\[
(0,3,4),(1,3,4),(2,3,4),(3,0,1),(4,0,1),(5,0,1).
\]

每个根行动都有d_A=u=147/2。取A=2、B=5，逐单位客户重算得到

\[
K_{5,2}=K_{2,5}=159/2,
\qquad d_2+d_5=147<159=K_{5,2}+K_{2,5}.
\]

所以(PAIR?)在空背景真实根即失败，亏空为12；所有d都等于u，故这不是低收益列的根IC松弛造成。

**该pair不能继续升级。** 同一分布p=(δ_2+δ_5)/2具有

\[
p^TKp=\tfrac14(130/3+159/2+159/2+130/3)=737/12<147/2=u.
\]

并且原第0列的最大查询值为69<u。所以该游戏没有反驳iid对角条件p^TKp≤u、自由完整菜单Mfull≤u、根extra-one或者聚合安全值。实际根叶(0,3,4)福利为230；本计算没有产生half反例。

## 3. 已审PB背景构造中的显式pair

复用[任意背景PB完整SPE](../../round5/menu/pair_attack.md)的全部参数与原策略：k=3、d=20、q=12、t=10、r=2475、Q=2063、H=100000、M=10^9，

\[
f(c)=\frac{11}{M+c}+\frac1{M+c+1},\qquad
g(c)=\frac{Hq}{HM+c}.
\]

主题A在每段选real块1，主题B在每段选real块2，二者均选两dummy块。它们均不同于规定Fill主题F。若根强制A，后继原策略只存在该一个偏离者，执行Punish直到每段A块负载达到t，随后Greedy；B根枝完全同理。

因为每段只有一个被偏离根选中的real块，每段恰需t−1=9次热点增加，总Punish数为180。在每段，Punish结束时热点负载10，另有180−9=171个不同非热点块负载1，剩1891个real块为空。后继Greedy数为2475−1−180=2294，先填完这些空块。最终非热点总负载为r−t=2465<2(Q−1)，所以Greedy从未需要把任何非热点块增至3。所有非热点最终负载至多2；这一步不依赖字典序的具体选择。

所有r人每段都选两dummy块。因此两条根枝首位收益均**恰为**

\[
d_A=d_B=d[f(10)+2g(r)].
\]

B在A根枝是每段非热点查询，A在B根枝亦然。查询另外插一份自身，故

\[
K_{B,A},K_{A,B}\ge d[f(3)+2g(r+1)].
\]

严格分离只需

\[
f(3)-f(10)>2[g(r)-g(r+1)].\tag{*}
\]

解析地，左边大于7q/(M+11)^2，右边小于2q/(HM^2)，而7HM^2>2(M+11)^2。因此(*)成立，得到显式(PAIR?)严格反例；程序另用Fraction核对其确切有理下界。

这里没有声称枚举48,495,120客户的大树。完整SPE合法性来自已独立审查的原构造；本文只对两条指定根枝作上面的精确计数和查询界。原背景已覆盖全部客户，所以该pair不反驳空背景原half，也未证明这个背景是原根SPE的实际前缀。

## 4. 保留候选的准确范围

以C(p)=p^TKp、D(p)=Σp_Ad_A为记号，有以下充分蕴含，反向均未证明：

\[
\text{PAIR?}\Longrightarrow [D(p)\ge C(p)\ \forall p]
\Longrightarrow[C(p)\le u\ \forall p]
\Longrightarrow[M_{\rm full}\le u]
\Longrightarrow[u\ge v_{r+1}(b)].
\]

倒数第二箭头直接由有限零和minimax：M_full=max_p min_Q p^TKQ≤max_p p^TKp≤u，因为对每个固定p，Q=p是该最小值的一份合法独立列分布。无需K对称。最后箭头因为完整菜单的竞争背景只是全部r槽静态背景的子集。

此外，D≥C已被旧[34客户加空主题游戏](../../../R-d22a706a03c5499d941a6a97f94128a8/representation/terminal_pushforward_D_lt_C.md)在空背景根严格否定；同例C<u，所以不能否定较弱条件。PAIR及D≥C的失败不能传给仍开放的后面各式。

任意合法背景版本的整条链已被原PB反例否定。若改成原根SPE的实际前缀，必须保留前面玩家的真实最优性；不能从任意背景证明中偷渡。只证明空背景首位extra-one，也不能在带背景孩子直接归纳。本文没有取得把真实背景信用支付给这些开放条件的新通用关系。
