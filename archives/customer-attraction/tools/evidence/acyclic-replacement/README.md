# 无环真实替换证据

正式数学见[条件引理](../../state/引理/最早归属客户的无环真实替换付款--引理.md)，准确程序范围见[双实现资源](../../state/计算/无环真实替换的双实现精确核验--计算.md)。

manifest.json保全两冻结提交的来源路径和SHA。original/只保存冻结原字节，replay/是本轮输出。运行 run_replay.py 在临时目录恢复原路径后执行两份原程序；验证两报告与原字节相同，临时树自动删除。路径标记不是数学实现，不被原程序导入。

作者完整输出含63个兴趣类型行，独立输出含60个归属行及两人全部四种失败匹配。有限源点核验不证明一般见证存在；后者已有完整SPE反例。审查记载的被审引理SHA与冻结版不符，正文和manifest均明确记录。
