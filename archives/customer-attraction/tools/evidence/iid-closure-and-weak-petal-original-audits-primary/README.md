# 八客户与花瓣原作者精确审计

本目录保存四份冻结原件，共15282字节，见[source-manifest.json](source-manifest.json)。每份与父方逐件`clean show`导出的字节数、SHA256匹配；两个冻结来源提交和原路径均保留。

数学与程序合同在[正式正文](../../../state/程序/八客户静态封顶与花瓣弱桥的原始精确审计--程序.md)。程序以不同单位客户定义收益，完整小树中的每次偏离都沿同一指定策略的真实后继完成。不得将有限小树、百人历史类型界、全参数解析证明互换。

- `original/audit_iid_closure.py`及`iid_closure_audit.json`：八客户21节点84项真实比较、有理安全双证书及Q(√669)静态Nash计算；全q最优和任意共同iid混合的范围另依解析证明。
- `original/audit_weak_iid.py`及`weak_iid_audit.json`：循环末回复的三个完整小树、百人固定背景与类型界、100/53的有理切口。
- `comparison-and-runtime.json`：22份实读相关依赖的指纹、三个小树与旧成功循环独审的对应，以及100/53报告字段对齐；0新原CLI、0旧成功重跑、0新数学入口、0solver。

两份原py都无main保护，导入就会执行断言并打印JSON；它们本身不写邻接JSON文件。本轮未导入/执行，不将冻结JSON称为本轮stdout。现有补充报告`new_fixed100.t`覆写错误已在正式正文说明；本目录冻结原报告的1969/2000切口正确，旧报告未改。
