# 任意背景双主题误差的枢轴租金与正测度

## 同一总人数的静态对象

有限单位客户N、有限非空共同标签目录，各标签t覆盖A_t。取不同标签a/b、整数r≥s≥1及任意非负整数背景主题计数z。**允许z_a/z_b正**，其它背景支持数也无上界。定义
\[
q=z+r e_a+s e_b,\quad q'=z+s e_a+r e_b,
\quad n=|z|+r+s.
\]
两终局总人数相同n。U_t(q)只在q_t>0时求值，是一名单位提供者原收益。背景玩家总收益
\[
B_z(q)=\sum_{t:z_t>0}z_tU_t(q),
\]
z0时空和0；不访问未占用t的U。C_b=|A_b|也可写成nU_b(n e_b)，不把大小当已实现顺序利润。下面先是静态逐客户代数，**不要求q、q′为SPE、真实续局或同一策略下两条枝**。

令h=r−s、
\[
E_{ab}^{r,s}(z)=rsU_a(q)+r(r-s)U_b(q')-s^2U_a(q')-(r-s)C_b.
\tag{1}
\]
对客户x记α=1_(x∈A_a)、β=1_(x∈A_b)、d=Σ_t z_t1_(x∈A_t)。d是背景提供者人数，不是客户价值。所有含a/b的U有至少s个该主题玩家，分母正；背景未覆盖且α=β0时背景贡献约定0，不用0/0。

## 精确枢轴租金与两种总租金支付

只在枢轴A_b上的背景租金为
\[
R_{z,b}(q')=\sum_{x\in A_b}\frac{d_x}{d_x+r+s1_{x\in A_a}}.
\]
q′的β1客户负载确是d+r+sα。逐客户的(1)系数为

| α/β | E贡献 |
|---|---:|
| 0/0 | 0 |
| 1/0 | s h d/((d+r)(d+s)) |
| 0/1 | −h d/(d+r) |
| 1/1 | −h d/(d+r+s) |

d0四项均0。于是精确
\[
\boxed{E_{ab}^{r,s}(z)+hR_{z,b}(q')
=s h\sum_{x\in A_a\setminus A_b}\frac{d_x}{(d_x+r)(d_x+s)}\ge0.}
\tag{2}
\]
只付枢轴上的租金，不需每个误差重新整份B_z。非负单位客户给R≤B_z(q′)，所以E+hB_z(q′)≥0。另对q的总租金逐客户相加：

| α/β | E+hB_z(q′) | E+hB_z(q) |
|---|---:|---:|
| 0/0，d0 | 0 | 0 |
| 0/0，d>0 | h | h |
| 1/0 | h d(d+r+s)/((d+r)(d+s)) | h d(d+2s)/((d+r)(d+s)) |
| 0/1 | 0 | h²d/((d+r)(d+s)) |
| 1/1 | 0 | 0 |

故也E+hB_z(q)≥0，任意θ∈[0,1]可用θB_z(q)+(1−θ)B_z(q′)。r=s时h0且E0；z0时所有d0，恢复无背景双主题身份。空题、零客户、同覆盖不同标签不破坏四分类。正性要求共同非负客户；若在线性松弛中允许有符号客户质量，等式仍线性成立，但≥0与R≤B不能继承。

## 固定枢轴与背景时，误差是同一正测度

再取c≠b（允许c=a），保持**同一向量z、同一b/r/s**。即使z同时含a/b/c，各客户d仍固定。令γ=1_(x∈A_c)，由四分类直接相减
\[
E_{ab}-E_{cb}=s h\sum_x\frac{(\alpha-\gamma)d_x}
{(d_x+r)(d_x+s+r1_{x\in A_b})}.
\tag{3}
\]
定义
\[
k_{b,z}^{r,s}(x)=\frac{s h d_x}{(d_x+r)(d_x+s+r1_{x\in A_b})}\ge0,
\quad\mu(A)=\sum_{x\in A}k(x),
\]
\[
K=-h\sum_{x\in A_b}\frac{d_x}{d_x+r}.
\]
则对所有合法非枢轴标签a，E_ab=K+μ(A_a)。β0时K贡献0、μ系数正好四格1/0；β1/α0给K，β1/α1相加化为−hd/(d+r+s)，故是精确表示。这个固定K使不同a的负租金可以共同消去，优于每个E另付总背景。

对任意有限非负有向边权λ_ac，
\[
\sum_{a,c}\lambda_{ac}(E_{ab}-E_{cb})
=\sum_x k(x)\sum_{a,c}\lambda_{ac}(1_{x\in A_a}-1_{x\in A_c}).
\]
若每个标签的总入/出权相同，内和逐客户0，误差精确相消；链a₀→…→a_ℓ仅留μ(A_a₀)−μ(A_aℓ)，不随长度累积。这里背景z必须真的是同一计数向量，不能把每条实际分支各删去活动玩家得到的不同背景重新都记z；枢轴或r/s变化也会改核。形式图平衡不保证这些边就是某完整SPE的原IC或有可用非负乘子。

## 三人活动块的整数小误差

r2/s1时，β0核d/[(d+2)(d+1)]、β1核d/[(d+2)(d+3)]。整数d≥1满足
\[
(d+2)(d+1)-6d=(d-1)(d-2)\ge0,
\]
\[
(d+2)(d+3)-10d=(d-2)(d-3)\ge0.
\]
故β0核≤1/6，β1≤1/10，d0核0。整数性在相邻根之间承重，不推广相同常数到任意实d。对P=(A_a\A_c)∩cov(z)，(3)给
\[
E_{ab}-E_{cb}\le |P\setminus A_b|/6+|P\cap A_b|/10
\le |P|/6.
\]
交换a/c给下界，所有负差仍显式在同一测度，不把上界当已赚信用。任意总人数、任意背景支持都成立，未限制仅一个第三标签。
