# 存在式遗漏私有化：精确量词与有限下降桥（候选未证）

2026-10-24。目标为一般人数、一般共同有限目录、全部有序历史纯 SPE。**下面的私有化存在性均未证明；固定最优元组版本已失败。** 本页的条件性有限下降推导是自审稿，尚未独立审查。

## 1. 一次合法变换

固定实例 I、完整 SPE σ、实际终局 z、实际覆盖 K、W=|K|。选择一个真正最优 m 元组 C，令 O 为其覆盖联合。对每个单位客户 x∈O\K，选择 C 中某个原本覆盖 x 的主题 t(x)，删除该客户对其他所有主题的兴趣。其他客户完全不变。重复客户按不同单位客户各自选 owner，不能强制同一原类型全给同一 owner。

得到 I'。主题标签暂作路由记号；若删除兴趣后出现相同覆盖主题，最后合并相同覆盖，并映射历史。原目录允许空主题、重复行动，m不变。

这次变换有两条无条件事实：

1. **OPT不变。** 任何主题客户集合只会缩小，因此 OPT(I')≤OPT(I)。原最优 C 仍覆盖全部 O：原实际已覆盖的客户兴趣不动，原遗漏 x 的 owner 属于 C。所以反向不等式也成立。
2. **原终局的实际覆盖和全部玩家收益不变。** 被修改客户没有一个在 z 被覆盖，其余客户的所有兴趣完全保留。但原策略未必再为 SPE，也未必存在其他 SPE 实现原终局。

第2条的最后一句是核心，不能从同一路径数值不变跳过所有真实离轨比较。

## 2. 四个不同的全范围候选

以下每项都对每个 I、σ量化，并要求**存在某个真正最优 C 和 owner 选择**。它们不预先固定 C。

| 候选 | 新实例要求存在的完整 SPE |
| --- | --- |
| E-path | 实际有序主题路径为原 z（合并标签后作自然映射） |
| E-count | 实际主题计数为原终局计数（同样处理合并） |
| E-cover | 实际覆盖客户集合恰为原 K |
| E-defect | 任意实际终局 z'，但 W(I',z')≤W(I,z) |

蕴含依次为 E-path⇒E-count⇒E-cover⇒E-defect。OPT自动保持，所以 E-defect 等价于半覆盖坏差 `OPT−2W` 不减。不能把其中一个版本的有限核验写成另一个版本。

E-path、E-count、E-cover 中任何一条若普遍成立，单步已经把某个最优联合的实际遗漏变为单主题私有，且W、OPT不变，可直接调用现有私有遗漏定理。

E-defect单步没有这个性质：新 SPE 可以漏掉原来覆盖的共享客户。其充分性需要下面的有限下降论证。

## 3. E-defect的条件性有限下降

**条件命题。** 如果 E-defect 对上述全部输入普遍成立，则对全部输入都有

\[
\operatorname{OPT}_m\le(2-1/m)W.
\]

**证明。** 从任意 I₀、σ₀ 出发。每轮用 E-defect 选择 C、owner 及新完整 SPE，得到 I₁、σ₁，依次继续。每轮 OPT保持，实际福利不增。

令有限整数

\[
L(I)=\sum_{x\in N}|\{T\in\mathcal S:x\in T\}|
\]

为客户—主题 incidence 总数。在暂时保留标签的表示下，如果某个被修改遗漏客户原来喜欢至少两个主题，本轮 L 严格下降。合并重复覆盖主题只会进一步降低 L，不会增加它。

若本轮所选最优 C 的实际遗漏客户本已各只属于一个主题，就无须继续：这些客户都是全局私有，且其唯一主题必为包含极大主题，已有 `CA-OPTIMAL-PRIVATE-OMISSIONS-2M1-v1` 给该实例 OPT≤(2−1/m)W。否则该轮严格降低非负整数 L。因而有限步后必到前一种情况。

末轮 OPT 等于原 OPT，末轮 W不大于原 W，故把私有遗漏锐界向前传回即得结论。证毕。

因此 E-defect 比“足以证明half”更强：它会给一般锐常数2−1/m。目前没有证明该归约，也没有证明一般锐常数；Q-CAG-HALF仍OPEN。

## 4. 相同覆盖标签的处理义务

为避免把标签当成新输入特权，可用如下标准集合值逆向归纳事实：复制或删除同覆盖行动标签不改变可实现终局的主题覆盖多重集。证明对剩余人数归纳：映射相同覆盖后，别名孩子的后继可实现集合相同；每个行动的最低可实现当前收益相同；`max_a min_child u_a` 门槛不变，保留叶的并集也不变。各有序历史仍独立重构子树，不能把给定标签策略图直接商掉后宣称它仍为 SPE。

有限下降证明只需要新 SPE存在及其实际福利，不需要把一份给定别名策略原样商掉。若要证明 E-path/E-count，本页表格中的标签映射仍应在正式陈述中明确。

## 5. 已知边界和下一步

已有36客户例表明，固定最优 C=全Y可导致全部新SPE福利从可达34升至唯一36；换C=全X则原有序终局仍可达。因此存在量词承重，不能从每个最优集合分别尝试失败推断共同存在版失败，也不能只检验旧策略是否依旧最优。

检验 E-defect 的真正反例必须给出一个原完整SPE，并对**全部最优元组和全部逐单位owner选择**，证明新实例全部完整SPE福利都严格高于原福利。只排除原计数不够；只测试一种类型整体owner也不够。对被固定C覆盖以外的原遗漏，本页变换保持其兴趣，不能偷偷删除来扩大可选变换范围。
