# 同一初始化与原来源时间合同

有限单位客户/有限非空共同目录、任意m≥1、固定完整有序历史纯SPE σ，保空主题/重复/零源/任意平局。固定actual B、一个合法m比较元组T、同一次坐标初始化和第一实际正价列H。O为T覆盖，current d_i与future source b_i分割余库存r_i，r_i=d_i+b_i，|O|=Σ_i(r_i+H_i)，d_i≤u_i/H_i≤u_i。

本页**另要求原full-SAFE或合法CLIP的源因果合同**：owner i的future来源最终只能支付给actual角色j≥i。允许客户重采，合同跟踪owner时间，不是同客户物理券。它不是所有允许提前付I的流的公理。是否用最大current d_i=min(r_i,u_i)不影响下述推导，但不能跨初始化保旧r/H/余额。

# 每个后缀的必要不等式

S_k={k,…,m}。若原剩余role预算A_j^out≤2u_j−d_j−H_j同时成立，owner在S_k的future库存不能付到S_k以外，因此

\[
 b(S_k)\le A^{out}(S_k)\le 2u(S_k)-d(S_k)-H(S_k).
\]

代b+d=r得

\[
 \boxed{\sum_{i\ge k}(r_i+H_i)\le2\sum_{j\ge k}u_j.}\tag{SUFFIX-NEC}
\]

第一处仅≤：更早owner也可能向此后缀支付。必要性不依坐标比例/后续具体路由，不给充分性。k1恰|O|≤2W，T最优才是原half；不得把含k1的整组存在性当已证新全输入不等式。k=m中末位无future，r_m可由一条完整query付u_m，H_m≤u_m，所以该端点已过。m1无proper suffix，仅全局目标。

原限制机制允许共同选择最优T/匹配。一个坏排列不否定它；若同一真实实例所有最优元组都被某proper必要cut排除，才否定该受限RESIDUAL-CAP，仍非half。这里未给这种真实实例。
