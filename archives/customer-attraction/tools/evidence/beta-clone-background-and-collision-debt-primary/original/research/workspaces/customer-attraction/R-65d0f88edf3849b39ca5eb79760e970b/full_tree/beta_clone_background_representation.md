# 背景利润的 Beta-clone 静态表示：可信补全未解

2026-10-24。个人探索草稿；作者逐式核对，未独立审查，无新颖性或外审声明。对象来自任意一般 CAG 合法背景 b 和任意剩余人数 r；没有把受限的 fresh 行动树称为原模型。**一般 half 仍 OPEN，本文不提供 SPE 保持。**

## 1. 精确的非负有理构造

固定有限原目录的标签集合 A。对每个原主题 a 建 q 个 clone 标签 `(a,j)`，q>=r。对于一个原单位客户 x，其原兴趣标签集合为 B_x，固定背景负载为整数 b_x>=0。以下先用非负有理客户质量书写；有限项的共同分母可清除，得到完全由不同单位客户构成的合法实例。

令 L=q|B_x| 为 x 的相关 clone 标签数。若 b_x=0，就给一个质量为1、喜欢全部 L 个相关标签的客户。若 b=b_x>=1，则对相关标签的每个子集 R 放置质量

\[
w_R=b\,\frac{|R|!(b+L-|R|-1)!}{(b+L)!}.
\tag{1}
\]

这些质量非负有理。R 为空时其客户无人可覆盖，可删去。它等价于下列概率分解：取 P 的密度 `b(1-p)^(b-1)`，条件于 P=p，独立把每个相关 clone 以概率 p 放入 R。对一个指定 R 积分即为(1)，并且所有 R（含空集）的质量和为1。不同原客户的这些构造相加。

## 2. 互异 clone 终局完全实现背景利润

考察任意所有 clone 标签互异的长度 r 终局。对原客户 x，设其中 k 个所选标签的原主题喜欢 x。k=0 时所有贡献均零。k>=1 时，条件于 P=p，被覆盖概率为 `1-(1-p)^k`；这 k 位玩家完全对称，所以每位的期望份额为

\[
\frac1k\mathbb E[1-(1-P)^k]
=\frac1k\left(1-\frac b{b+k}\right)
=\frac1{b+k}.
\tag{2}
\]

b=0 时直接得到同一公式1/k。由于 deterministic 客户质量正是上述有限兴趣型分布，期望只是有限质量求和，(2)是所构造确定实例的精确收益。客户的总覆盖质量恰为

\[
\frac{k}{b+k}.
\tag{3}
\]

于是，每个互异 clone 终局的各玩家收益与原背景游戏的对应原主题终局完全一致；其福利等于原背景游戏剩余玩家的总利润，而非原客户的覆盖数或包含旧玩家的全局福利。

## 3. 无限制 clone 游戏的最优值也精确保留

定义原背景 r 人最优剩余利润

\[
F_r(b)=\max_{T_1,\ldots,T_r}\sum_x\frac{c_x(T)}{b_x+c_x(T)},
\]

c=0 项按零计。构造游戏的最优 r 槽覆盖恰为 F_r(b)，乘上清分母倍数时两侧同倍缩放。

证明：q>=r，故任何原主题元组都可用互异 clone 实现，(3)给 `OPT_clone>=F_r(b)`。反过来，在任意 clone 元组中，把某次重复使用的 `(a,j)` 换成同一原主题的一个未用 clone `(a,j')`。在每个原客户的随机兴趣分解中，若它原本不喜欢 a，覆盖不变；若喜欢 a，相关互异所选标签数增加1，覆盖概率 `k/(b+k)`不降。因此逐原客户总覆盖不降。反复 freshen 全部重复后得到同一个原主题投影、全部标签互异的元组，其福利由(3)不超过 F_r(b)。故原元组亦不超过该值。

构造中若不同 clone 的覆盖集合恰相同，可保留标签，或按已存重复覆盖商引理处理；静态收益与最优值结论不依赖它们两两不同。

## 4. 受限树的准确范围及原模型缺口

在只允许当前选择未用 clone 的受限树中，从任意全部互异 clone 历史出发，按投影原有序历史运行原完整 SPE，并选任一未用 clone。各候选行动以及其真实受限后继始终全部互异，(2)逐条保持原 SPE 比较。因此它是这个**受限 fresh 树**的完整 SPE。原主题可重复，只是每次用不同 clone。

这不完成对原 CAG 的归约，因为原 clone 游戏仍允许重复已经使用的 clone。重复偏离后的原投影续局若直接照搬旧策略，后来玩家的收益已不再由(2)计算，不能断言其仍最优。将重复孩子任取 BI 填满也不自动控制偏离者最终收益。需要新的可信补全定理才可将原背景完整 SPE 提升成 unrestricted clone 完整 SPE。

一个仅静态的有利事实不足以填这个缺口：在其他行动冻结时，给当前玩家一个 fresh clone `(a,j')`，其利润不低于复用同原主题的旧 clone `(a,j)`。条件于 P=p，并固定其他不同 clone 的覆盖负载 Z，旧 clone 已有 n>=1 位使用者时，两种利润差为

\[
p(1-p)\left[\frac1{1+Z}-\frac1{n+1+Z}\right]\ge0.
\tag{4}
\]

对 P、Z 取平均及对原客户求和即可。但式(4)冻结其余终局标签；完整 SPE 的后继会响应 fresh/reused 选择，故不能直接使用它排除动态复用偏离。

## 5. 与一般 half 的关系

若未来另证所有原背景 SPE 都有上述 unrestricted fresh-clone lift，则原一般根 half 将蕴含任意背景的半剩余利润界 `2P_r(b,sigma)>=F_r(b)`，因为被提升实际叶福利为 P_r、最优值为 F_r。本文只给静态身份和受限树身份，**未证 lift，也未证任一 half**。不能由该条件归约或任意背景 extra-slot floor 的已知失败断言其可行或不可行。
