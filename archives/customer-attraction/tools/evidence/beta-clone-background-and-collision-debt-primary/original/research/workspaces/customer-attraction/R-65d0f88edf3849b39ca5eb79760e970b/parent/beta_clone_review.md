## 原子博弈

类型及数量为 AB:36、C:3、AC:36、BC:10；仅 AC 客户有背景一。
对每位 AC 客户 x 增加只含 x 的合法 P_x 主题，先各选一次，得到合法背景。
再有前缀 A，剩两玩家。当前选 A/B/C 后，末位规定 B/A/A；
其末位三行动收益表依次为 (21,22,22)、(24,17,20)、(27,23,31/2)，
所以这些规定均是 BR。当前真实收益为 (24,22,22)。P_x 偏离始终≤1，
在该两人子局不会击穿规定策略；对其余孩子填完整 BR，构成完整局部 SPE。
再用有限 BI 向其他孩子和祖先扩充，得到一个包含它的完整原 SPE。
没有证明该历史在根实际到达。

## 不可补全的重复孩子

Beta 表示已经吸收背景，clone 游戏不再执行上述 36 个背景动作。
对 b=1 客户，P 均匀分布于 [0,1]，相关 clone 的兴趣条件独立 Bernoulli(P)。
背景零客户对应 P=1。

在 clone 前缀 A_0 后，fresh A_1、末位 B_0 给当前收益 24；
末位 B/C 并列 22，可按原策略选择 B。若当前重复 A_0，末位全部类别为：

| 行动类别 | 末位收益 | 当前重复者收益 |
| --- | ---: | ---: |
| fresh A | 22 | 19 |
| fresh B | 22 | 21 |
| fresh C | 23 | 25 |
| 重复 A_0 | 18 | 18 |

每个 singleton clone 总质量 1/2，收益至多 1/2，其他未用的 A/C clone
与 fresh 行同行，B 的相同覆盖副本合并后不改变收益。
因此所有真正末位 BR 都属于 C，重复者必获 25>24，无法补成规定 fresh 合同的 SPE。

独立关键积分为

\[
\int_0^1[p(1-p)/2+p^2/3]dp=7/36,
\quad
\int_0^1[p(1-p)+p^2/3]dp=5/18.
\]

于是当前重复者得 36/2+36·7/36=25，fresh C 末位得
3+10+36·5/18=23。没有把当前盈利偏离建立在不可信末位选项上。

## 有限单位客户实现与审计范围

作者用每主题三个 clone：一个 AC 客户涉及 A、C、P_x 各三个，共九标签。
每个兴趣 pattern R 的有理质量为 `1/[10*binom(9,|R|)]`，
乘 2520 后均为非负整数。空兴趣客户可删；B 三个相同集合必须合并。
这是有限单位客户、共同目录的真实空背景实例。

另一独立脚本仅取本局部用到的 A_0,A_1,B_0,C_0 与每个 P_x 的一个 clone，
积分边际后用公共因子 60 展开为 5100 名单位客户（含零兴趣客户）。
它核查原 39 标签两人子局的 1560 项比较及该较小 clone 目录的局部全行动表。
它没有枚举作者完整三 clone 目录的全部 SPE；完整目录多余选项的排除由上述
类别穷尽与有理 pattern 对称性承担。两份有限实现不冒充同一个输入文件。

父方对定义、边界、singleton 目录合法性、BI 向上扩展和两实例范围均未发现
fatal objection。静态全鲜份额恒等式仍保留；失败的是给定完整策略的直接保留。
