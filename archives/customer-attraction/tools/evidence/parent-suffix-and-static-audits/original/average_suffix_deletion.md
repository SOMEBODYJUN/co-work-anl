# 对全部实际删位选择共同支付的后缀误差预算

2026-10-24。一般输入组件 `B16-AVERAGED-SUFFIX-DELETION-v1`。
父方解析证明；独立研究员仅见合同后重构成功，随后与旧虚拟回放正文比较。
没有外审或新颖性认证。**Q-CAG-HALF 仍 OPEN。**

## 1. 固定的对象与完整策略

固定任意原模型 m>=1 人完整历史纯 SPE sigma，实际主题 z=(S_1,...,S_m)，
客户实际负载 c_x，福利 W。b_j(x) 为 j 之前的实际覆盖数。令

    D = |{x:c_x>=2}|.

对每个 i<m，固定实际 i 之前的有序前缀，并将 S_i 仅作为原策略的一个固定虚拟
过去行动回放。删去其实际客户负载，保留 i+1,...,m 的原完整子策略。
该子策略在所有新有序历史上通过插回这个**固定** S_i 查询原 sigma。
不声称删后理性。令 R_ij 为这个删除后 child 在原实际 j 节点的最大真实单步正
regret，i<j；其强制叶的后继仍按原完整策略改变。

这是 m−1 种固定前缀后缀游戏，不是同一个 m−1 人完整根游戏。尤其 i>1 时
原较早角色都已固定，R_ij 不包含任何 j<i 的偏离。

## 2. 前缀包络的精确聚合

对 i<j 定义

    K_ij = sum_(x in S_i) 1/[b_j(x)(b_j(x)+1)].

因为 x in S_i 时 b_j(x)>=1，所以分母严格为正。若 S_i 空则 K_ij=0。
[背景删除包络](deletion_regret_envelope.md)的合法查询最大值恰为 K_ij：
非零删除项只在 S_i 上，查询合法主题 S_i 实现它的全部支持，别的查询不会更多。

原同叶中 j 的返还为

    A_ij = sum_(x in S_i cap S_j)1/[c_x(c_x-1)].

两位都覆盖的客户必 c_x>=2。由真实原 IC 与包络，

    R_ij <= K_ij-A_ij.                                  (1)

同时旧 [虚拟回放界](../../R-4ffa8b85fa8847e09e45dcafc8e1326f/deletion/virtual_replay_regret.md)
给 `R_ij<=u_j-A_ij`：单删的偏离退款不超过该偏离者的原收益，再用原实际 IC。
所以可以合法组合为

    R_ij <= min{u_j,K_ij}-A_ij.                           (2)

每个右端非负，因实际退款 A_ij 也不超过两个上包络。这里的退款差机制是旧资产，
不将它认领为新；本页保留的是全部真实前缀 K_ij 的共同聚合。

固定 j，按客户数过去覆盖者，直接得

    sum_(i<j) K_ij = sum_(x:b_j(x)>0)1/[b_j(x)+1].        (3)

固定 c_x>=2 的一个客户，它给每对有序角色 i<j 的实际退款相同，覆盖者对数
为 c_x(c_x−1)/2，故它对 sum_(i<j)A_ij 的贡献恰为1/2。于是

    sum_(i<j)A_ij=D/2.                                  (4)

把 (2) 求和，并分别使用两个包络，得到全输入不等式

    sum_(i<j)R_ij + D/2
       <= sum_(i<j)min{u_j,K_ij}
       <= min{sum_j (j-1)u_j,
               sum_j sum_(x:b_j(x)>0)1/[b_j(x)+1]}.
                                                               (ASD)

尤其每个正 b_j 的价格至多1/2，每个实际已覆盖客户在至多 m−1 个这些 j 中
出现，因此

    sum_(i<j)R_ij <= [(m-1)W-D]/2.                       (5)

对 m>=2，将 i 在1,...,m中均匀选择（i=m 的后缀空），相应删除后的实际后缀
总 regret 期望至多 `[(m-1)W-D]/(2m)`。这是一个共同 W 支付的平均误差界，
不需对各删位单独发一份 W。m=1、零客户、重复、空主题和平局直接涵盖。

## 3. 这与旧回放界和一般归纳的关系

旧式 (5)/(9) 对每个固定删位给 `sum_(j>i)R_ij<=sum_(j>i)u_j−sum_(j>i)A_ij`。
本页精确保留真实前缀下的 K_ij，并计算所有删位选择的退款和为 D/2；
它不是仅将旧的固定 q 系数重新命名。它仍是实际节点误差预算，不是新 half 界。

**准确的两个缺口：**

1. i>1 时，若要把整个 m−1 人根游戏一起回放，原 j<i 玩家偏离可能使第 i 位
   的虚拟动作也改变。此时删掉的主题不再是跨枝固定的实际 S_i；ASD 没有支付
   那些较早玩家的误差。只选 i=1 可避免这一项，却失去平均挑选删位的自由。
2. ASD 只在各原实际后缀节点计误差；原离轨 child 也会受删除影响。一般人数归纳
   只可应用于完整 SPE，不能对这份仅有实际节点误差控制的策略免费调用。

因此它为删位路线提供了一份量化的共同误差预算，但未控制真正跨所有分支的修复
费用。不得从“存在平均误差小的删位”推出“存在可保真或小损失的精确 SPE 删位”。

### 较早实际节点可以保留误差，不能省略

使用旧正文的因果虚拟回放 tau_i 删除任意位置 i，可得到定义在所有新历史上的完整
策略。令 r_ij 为其原实际存活角色 j 的 regret。j>i 时 r_ij=R_ij；j<i 时，
原 IC 仍对应原同角色的真实偏离，但虚拟删除动作可以改变，只能在此使用旧包络
`r_ij<=u_j-A_ij`。将它与后缀新包络合账，全部有向覆盖者对的退款为 D，得

    sum_i sum_(j!=i)r_ij
      <= sum_(i<j)min{u_j,K_ij}+sum_j(m-j)u_j-D
      <= (m-1)W-D.                                      (VR)

第一行不弱于旧的第二行，可严格保留晚位置的真实前缀信息。它确实计入了较早
实际节点，却仍没有统一支付改变分支后的新叶，因此也不能将 tau_i 当成精确 SPE。
未证明任何从实际节点总 regret 到低损失可信修复的定理。
