## 实际检查与有限范围

原件SHA256固定为`6ae7857876244ad2286a57ac49c1548748b6287b20995edb3027eb80e6d68719`。独立程序重新定义所有255客户类型、1287决策计数、10296条含自身IC、六个相对私有块和全部对偶列。37449个有序决策历史被显式枚举，每个对应已精确认证的计数行；其299592项行动比较由这些行表示，并非逐历史重新求解不同策略。

检查结果为：给定策略SPE成立、精确根收益1、最小块5/3；固定策略锥的255列对偶余量非负，其中15零、240正；客户质量乘6成为66名单位客户；路径ABBBBB、福利36、OPT60、福利比3/5。28种六不同标签集覆盖允许重复的至多六主题OPT；五槽实际孩子最优值为28/3、首步损失2/3（规范化单位）。

这里只认证一个完全给定的六人八标签策略及其固定策略LP，不认证全部六人SPE、全部目录、任意历史依赖策略或一般half。不声称点唯一最优，不将新增精确点称为旧JSON已有证书。
