# 固定背景静态安全值比较及精确客户余项

2026-10-24。下文是从定义的全范围静态引理，不是 SPE 福利证明。基础论证明确沿用 [既有不观察查询的混合安全值正文](../../../../current/customer_attraction/oblivious_security.md) 的共同目录预算、倒数凸性和有限 minimax；此处只推广到固定背景未来利润，并保留该预算中的精确余项，不认领 Jensen 或原空背景定理为新发现。本轮仅作个人审查材料。

有限单位客户集为 N、有限非空共同目录为 S。固定任意非负背景负载 b（允许实数；原游戏合法前缀产生的非负整数背景当然包含）。取整数 r≥1，定义 r 个比较主题的最优未来利润

\[
F_r(b)=\max_{T_1,\ldots,T_r\in S}
\sum_x\phi_{b_x}(d_x),\qquad
d_x=\sum_{j=1}^r\mathbf1_{x\in T_j},
\]

其中 d=0 时 `φ_b(0)=0`，d>0 时 `φ_b(d)=d/(b+d)`。因此 b=d=0 不产生 0/0。

对整数 s≥0，定义不观察抽样实现的静态安全值

\[
v_{s+1}(b)=\max_{p\in\Delta(S)}\min_{B\in S^s}
\sum_Ap_A f_B(A),\qquad
f_B(A)=\sum_{x\in A}\frac1{b_x+1+c_x(B)}.
\]

s=0 时竞争元组唯一为空，故 `v_1(b)=max_A Σ_{x∈A}1/(b_x+1)`。

## 1. 对任意静态对手分布的精确恒等式

取 Q∈Δ(S^s)，令

\[
L_x=E_Q c_x(B),\quad
\mu_T=E_Q\#\{j:B_j=T\},\quad
g_Q(T)=\sum_{x\in T}\frac1{b_x+1+L_x},\quad
M_Q=\max_Tg_Q(T).
\]

这里 `Σ_T μ_T=s`、`L_x=Σ_{T∋x} μ_T`，故 s=0 时全部 μ 和 L 自动为零，不需要定义 `μ/s`。

固定任意 r 个比较主题及其负载 d。定义逐客户**精确**余项

\[
\rho(b,d,L)=
\begin{cases}
\displaystyle\frac{L}{b+1+L},&d=0,\\[6pt]
\displaystyle\frac{d(d-1)+bL}{(b+d)(b+1+L)},&d\ge1.
\end{cases}
\]

所有分母严格正，ρ≥0。直接通分给每客户精确恒等式

\[
\phi_b(d)+\rho(b,d,L)=\frac{d+L}{b+1+L}.
\tag{1}
\]

因此令 `R_b(d,Q)=Σ_xρ(b_x,d_x,L_x)`，有

\[
\boxed{
\sum_x\phi_{b_x}(d_x)+R_b(d,Q)
=\sum_{j=1}^r g_Q(T_j)+\sum_T\mu_Tg_Q(T)
\le(r+s)M_Q.}
\tag{2}
\]

这里 ρ 是该指定代数比较的精确差额，不能直接称为该引理全部参数下的最优全局常数。

## 2. 安全值比较

倒数函数在正数上凸，故每个合法查询 T 都有

\[
g_Q(T)\le E_Qf_B(T),\qquad
M_Q\le\max_T E_Qf_B(T).
\]

由(2)，对任意 Q 和任意比较负载 d，

\[
\boxed{\sum_x\phi_{b_x}(d_x)+R_b(d,Q)
\le(r+s)\max_T E_Q f_B(T).}
\tag{3}
\]

有限 minimax 给 `v_{s+1}(b)=min_Q max_T E_Qf_B(T)`，且极小者 Q* 存在。因此对每个安全值对偶最优 Q* 及每个比较负载 d，

\[
\boxed{\sum_x\phi_{b_x}(d_x)+R_b(d,Q^*)
\le(r+s)v_{s+1}(b).}
\tag{4}
\]

取达到 F_r(b) 的比较元组，得到

\[
\boxed{F_r(b)\le(r+s)v_{s+1}(b),\qquad
F_r(b)+R_b(d^*,Q^*)\le(r+s)v_{s+1}(b).}
\]

特别地，`F_r(b)≤(2r−1)v_r(b)`。空背景 b=0 时未来利润就是覆盖，此基础比较退回既有 `OPT_r≤(r+s)v_{s+1}(0)`。

## 3. 可保留的背景部分与不能免费完成的收费

在 d>0 客户上可拆成

\[
\rho=\underbrace{\frac{d(d-1)}{(b+d)(b+1+L)}}_{\text{比较主题的重复覆盖}}
+\underbrace{\frac{b}{b+d}\frac{L}{b+1+L}}_{\text{固定背景份额的乘积项}}.
\]

故上式确实保留非负背景信用

\[
R_{\mathrm{bg}}(b,d,Q)
=\sum_{x:d_x>0}\frac{b_xL_x}{(b_x+d_x)(b_x+1+L_x)}.
\]

它依赖**比较元组** d 和静态对手分布 Q。若 d 取真实尾部负载，则 `b_x/(b_x+d_x)` 恰为该真实终局中固定前缀的客户总份额，但(4)左侧此时只是实际尾部利润，失去了 F_r 的最优比较。如果 d 取最优比较负载 d*，该份额来自比较终局，不能替换成原 SPE 实际前缀最终收益。若不同真实分支使用不同 d* 或 Q*，这些信用也不能免费跨子树相加或望远镜。此处没有提供这些缺失关系。

## 4. 退化端点核对

- d=0、b=0：实际项为零，ρ=L/(1+L)，(1)严格按定义成立；当L=0时ρ=0。
- d=0、b>0：ρ=L/(b+1+L)，无需借用含 `(b+d)` 的第二支公式。
- d=1：重复覆盖部分为零，ρ=bL/[(b+1)(b+1+L)]；b=0或L=0时ρ=0。
- s=0：L=μ=0，全部分母仍正，(2)–(4)保持；不存在空分布的归一化。
- b=0、d≥1：ρ=(d−1)/(1+L)；d=1的逐客户比较取等，d≥2的差额为正。
- 空主题、重复主题、零客户及所有主题均空：公式和 minimax 仍有定义，全部总和可为零。

这里的各式不使用 SPE 理性；它们对同一目录内任意合法比较元组和静态对手分布成立。
