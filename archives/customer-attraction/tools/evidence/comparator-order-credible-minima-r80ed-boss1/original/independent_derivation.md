# 独立一般推导（候选，未证）

## 目标与记号

固定完整历史依赖纯 SPE `sigma`，根终局 `z`，实际福利 `W`。固定任意最优比较元组 `T_1,...,T_m`，并集大小 `O=OPT_m`（若取最大元组）。对实际路径位置 `i`，前缀负载 `b_i(x)`，剩余槽 `r_i=m-i+1`。

## 已证可直接调用的关系

真实一次偏离给 `u_i >= max_A sum_{x in A} 1/(b_i(x)+r_i)`；任意分数覆盖总质量 `tau` 给 `O <= P_{i-1}+r_i tau u_i`，从而得到工作稿式(8)-(10)。这些关系保持真实后继，但质量 `tau` 可随 m 增长，不能直接给半覆盖。

## 新候选（尚未证明）

尝试把“比较主题顺序”作为一个可选耦合，而不是固定 `T_i`。每个主题的出现位置影响真实一次偏离的未来槽数；若能用真实路径收益 `u_i` 吸收一个主题被提前/推迟时的分母损失，再加上客户已经被覆盖的单位信用，可能得到 `O <= W + sum_i L_i(T_i)` 的同序矩阵不等式。关键风险是不同主题共用客户时，位置交换不保持后继树，不能直接使用静态交换。

另一个可能的全局对象是每个历史 h 的最小 SPE 续局收益 `ell_h(A)=min_{z in R(h,A)} u_i(z)`。SPE 给当前收益至少 `max_A ell_h(A)`；若对一个最优元组能证明 `sum_i ell_{h_i}(T_i) >= O-W`，即闭合 `O<=2W`。目前没有一般证明，且 `ell_h` 的最小续局会在不同主题间跳变。

## 下一步

1. 先验证同序矩阵候选在一般二值支持下的交换不等式是否有可证明的局部形式；
2. 若局部形式需要支付后继重置，尝试把重置量写成同一历史行的 `Gamma` 非负组合；
3. 若仍缺共同钱包，记录精确断点并转向完整菜单或新表示。
