## 2. 排除对角菜单比较

考虑q条真实路径中的同一后继位置，编号 `i=1,...,q`。令该节点固定前缀的客户
负载为 `p_i(x)`，剩余人数为 `k`，行动者最终收益为 `v_i`。令共同目录中的
比较菜单 `Q_1,...,Q_q` 的客户会员位为 `a_j(x)`。
在每个**固定**有序历史和每个**固定**比较索引 `j`，SPE 最优性及最多k个剩余
玩家覆盖该客户，给

`v_i >= sum_x a_j(x)/(p_i(x)+k)`。

因此可以只对整行索引对 `i != j` 求和，而不是先把全部比较求和后忘掉对角。
写 `a(x)=sum_j a_j(x)`，得到必要行

`(q-1) sum_i v_i - sum_x [ a(x) sum_i 1/(p_i(x)+k) - sum_i a_i(x)/(p_i(x)+k) ] >= 0`。

当k=1时分母精确，是实际末位最佳回复比较；k>1时是合法保底。
选择集合 `{(i,j):i!=j}` 与客户无关，故不存在按客户择行。

`offdiagonal_probe.py` 在原坐标上实现27行：三个旧末位对异索引T比较；
两个第三位族各两个后继位置对T/X/Y；第二位族三个后继位置对T/U/V/W。
原冻结64原子点违反其中8行。特别在AE族末位对异索引R比较，令
`p=a+e`，八格直方图元为 `(t,r,s)`，设

`z=sum_i s_i/(p+t_i+r_i+s_i)`，
`D=sum_i 1/(p+t_i+r_i+1)`，`r=sum_i r_i`，
`C=sum_i r_i/(p+t_i+r_i+1)`，

新增必要行逐客户系数为 `4z-rD+C`。
原点的精确总slack为

`-2350274614365061193348939000536717958363 / 10160684453437026820024983718703677270992 < 0`。

所以**任何保留这个点全部既定坐标的补全**都不可能成为原游戏的完整 SPE。
这不只是某种随机排列或某个选定菜单重构失败：该系数只依赖已冻结直方图，
任何更细分客户、重排索引、补充其他目录主题都保留这个负值。
新增菜单主题也不能删除原共同目录中合法的异索引R偏离。

## 3. 末两人税的固定索引子和

调用现行 `two_remaining_tax.md` 的真实两人税定理。固定某个真实末两人子博弈b，
背景客户负载为 `p_b(x)`；真实第四、第五位最终收益为 `v4_b,v5_b`，第四位主题
会员为 `d_b(x)`。定义

`H_b=v4_b+v5_b+sum_x d_b(x)/((p_b(x)+1)(p_b(x)+2))`。

对任意两个**固定**共同目录主题Q,R，该定理给

`H_b >= sum_x [(q_x+r_x)/(p_b(x)+1) - 2q_x*r_x/((p_b(x)+1)(p_b(x)+2))]`。

本目录没有加强该两人税定理；只保留不同合法比较行的索引子和。

取一组g个真实子博弈b，它们的背景可以不同，先写

`H=sum_b H_b`，`D1(x)=sum_b 1/(p_b(x)+1)`，
`D2(x)=sum_b 1/(p_b(x)+2)`。

设两个长度q的比较菜单为 `(Q_j)`、`(R_j)`；对每个客户记
`a=sum_j 1_Qj`、`c=sum_j 1_Rj`、`d=sum_j 1_Qj*1_Rj`。
逐个固定b与主题索引，再对所有b求和，给三种必要行：

- 全部q²个比较索引对：`q²H - sum_x [q(a+c)D1 - 2ac(D1-D2)] >=0`。
- 同索引q个比较对：`qH - sum_x [(a+c)D1 - 2d(D1-D2)] >=0`。
- 异索引q(q-1)个比较对：`q(q-1)H - sum_x [(q-1)(a+c)D1 - 2(ac-d)(D1-D2)] >=0`。

后两行相加恰为第一行，但第一行本身不蕴含两条子和各自非负。
客户上的`d`仅用于计算一组已固定主题对的收益，不参与选择比较索引。

更一般，长度s、t的菜单全积比较给

`stH - sum_x [(t*a+s*c-2ac)D1 + 2ac D2] >=0`。

同族直方图直接给任意两列的dot `d`；旧T/L菜单的dot就是原坐标h。
因此同/异索引税无需新客户坐标，也无需假设两个不同族的匹配方式。
对跨族菜单仅使用全积税时，已知各自计数a,c就足够。

## 7. 真实根最优偏离：可补全的必要信息与尚缺菜单相关性

2396行新坏点已由另一研究员独立重构全部系数与有理质量，见
`../next_global/review_2396.md`、`.py`、`.json`。其新增1959行×38原子全部从固定索引
的原利润定义展开，与作者系数逐项一致；没有把该点升级成SPE。

`root_menu_completion.py` 固定38旧原子及其质量，新增根偏离后的真实路径符号
`(T_i,K_i,L_i,M_i,N_i)`。对每个旧原子a与共同T会员位t，用16种四后继会员
`v=(k,l,m,n)`细分客户，变量 `z_{a,t,v}` 表示均匀根偏离索引i下的客户质量。
若原子T重数为d，强制

`sum_v z_(a,1,v)=mass_a*d/5`，
`sum_v z_(a,0,v)=mass_a*(5-d)/5`。

该合同是必要投影；它不要求原纯策略在不同有序历史使用相同续局，也不声称平均
条件足以恢复逐索引最优性。新增1216变量、76等式、1310条必要行包括：

- 根实际u1不小于五个最优主题根偏离真实收益的平均；
- 四个后继真节点对旧21个主题/菜单的平均比较（末位精确，早期最坏分母）；
- 同一根分支内T及四回复主题的比较；旧10个真实优化节点对四个新根菜单的平均保底；
- 新根分支的真四人、三人后缀对十个固定主题的全部带重复比较元组，分别使用已证
  1499/750和5/3背景利润界；新真末两人对旧21菜单全积的税界。

这1310行对z线性。`recover_root_completion.py` 将浮点严格可行解恢复成92个正
有理细分变量，并逐条精确验证76等式和1310严格不等式，最小slack约0.005280749949。
证书为 `root_menu_completion_exact.json`。因此这些根局部必要条件仍不能否定固定坏点。

但不能由单索引细分直接宣称四个根回复菜单共享同一目录。对该92-cell点按T会员
条件独立地分配五个根索引，最后回复N相对新根四回复菜单的异索引BR失败；
`check_independent_root_menus.py` 只排除这一独立提升。
更强地，固定92-cell边缘分布，枚举其全部96种可支持的五索引回复直方图，

全部96列的 `A^T lambda + E^T nu <= 0`，而 `nu·b≈0.2494503269>0`。
见 `root_coupling_obstruction_exact.json`。这排除**该92-cell细分**的全部耦合，

为避免把一次坏细分误当成不可补全，`root_full_hist_completion.py` 直接以完整
五索引根回复直方图为列：每列固定一个旧原子及五份 `(t,k,l,m,n)`，T总数为d，
每旧原子的列质量和为原mass。1310旧行按各索引整行平均；再加入16条四根后继

`(1/5) sum_i [4u_(j,i) - sum_(ell!=i) v_(k,ell)/(t_i+sum_(r<j)v_(r,i)+4-j)] >= 0`。

这些是固定整行索引的SPE必要比较。有限列包含每T组内会员常量的全部角点及上述96

`root_full_hist_completion.json` 保存完整列和质量。它仍不是完整SPE，也没有穷尽所有
