## 本轮实际执行

[reproduce.py](reproduce.py)已执行一次。它先检查全部11份原件指纹，再在临时目录运行两个未修改的原程序各一次，最后直接重建两份旧报告所存的单位客户策略。

- 作者p5枚举：260标号顶点、27排序型、171315行组合。
- 独立审计：3004系统，其中1351奇异；p0至p4整集合相等。
- 旧两个查询模式列表展开后均恰为V5，原SHA与历史比较报告一致。
- 两份选定策略：187个有序历史、748个真实偏离，全数非负松弛；点上完整价格分别2和3。
- 优化器运行0次，第二实现p5全枚举0次，历史28条浮点策略探索未重新优化。

[执行清单](replay/replay-manifest.json)给出命令、版本、运行时间、原／新hash及精确比较范围。[新五维报告](replay/vertices-report.json)和[新独立报告](replay/independent-report.json)除各自顶层seconds外与原报告所有字段相同；原新全字节不同，计时没有被删除。stdout和stderr也保留。记录具体点的精确核验不认证其整个策略锥。

## 复现

从仓库根选择一个不存在的新目录：

~~~sh
python3 -E -B archives/customer-attraction/tools/evidence/fractional-query-vertices/reproduce.py --output-dir NEW_QUERY_REPLAY
~~~

只需Python标准库；使用正常assert模式，不加-O。入口拒绝已有输出目录，并且不改动frozen/。两个原程序本身使用可覆写输出；入口只让它们写各自临时副本，再复制结果。两程序都没有自带原码指纹字段，指纹由外层来源／运行清单绑定。

原报告的历史独立性不因本轮重跑而增加。原理论稿对所有p的证明、p≤4的独立整集合比较、作者p5精确表、点上SPE核验、固定锥上证书及一般六人半覆盖目标各有不同量词，正文已分别写清。
