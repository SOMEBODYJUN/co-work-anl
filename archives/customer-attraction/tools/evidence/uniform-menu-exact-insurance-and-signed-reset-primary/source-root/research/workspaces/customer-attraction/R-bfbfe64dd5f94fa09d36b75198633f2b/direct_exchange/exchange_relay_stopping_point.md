# 最优替换不能免费把共享 relay 接回实际福利

2026-10-25。一般探索停点，不是新的定理资产。Q-CAG-HALF 仍 OPEN。

## 对象与正确净需求

采用 CAG-MODEL，固定任意有限共同目录、任意 m 和一份完整历史纯 SPE。实际终局为 s=(S_1,...,S_m)，实际并集为 U，W=|U|。任取一个覆盖最优的 m 主题组合 (T_1,...,T_m)，令

    O = union_i T_i,
    M = O minus U,
    E = U minus O.

则需要支付的是

    OPT_m - W = |M| - |E|,

即 half 等价于 |M| <= W+|E|。本任务从头保留 E；没有采用已被完整两人 SPE 否定的 |M|<=W。

## 尝试的静态交换输入

令 P_i=T_i minus union_(j != i) T_j 为第 i 个最优 token 的组合内独占块。对每个合法目录主题 A，用 A 替换 T_i 的最优性给

    |P_i minus A| >= |A minus O|.                 (1)

右侧的 O 外客户被完整保留。更一般地，删除任意 k 个最优 token，插入任意 k 个合法主题，也给“最优组合真正丢失客户数 >= O 外真正新增客户数”。这是现有最优块交换的直接实例，并非本任务新增的承重关系；已有 cross_role_optimal_exchange.md 中的 delta>=0 涵盖该输入。

这说明 E 的存在会迫使最优组合中的每个 token 留下相应独占损失。例如对每个实际主题 S_j，(1) 给 |P_i minus S_j| >= |S_j minus O|。但这些是各自的基数约束，不是按玩家收益分母加权的客户匹配。

## 真实同枝 relay 的准确部分

在任意合法前缀，当前玩家强制选完整主题 A，随后沿同一原策略走到真实离轨叶 z。记当前收益为 d；任取一个后来者，其动作 B、收益为 v。由于 A 上每名客户给选择 A 的当前玩家和选择 B 的后来者相同份额，有精确恒等式

    d-v
      = sum_(x in A minus B) 1/c_x(z)
        - sum_(x in B minus A) 1/c_x(z).          (2)

因此可以合法写 v <= d + v(B minus A)。若 v>=t，则

    d >= t - v(B minus A).

这些量全部在同一个真实叶 z；没有把离轨旧玩家利润换成实际 s 上的旧玩家利润。

设 A=T_i 后，将 B minus T_i 再拆成 (B intersection (O minus T_i)) 与 (B minus O)。前一部分可能由其他最优 token 覆盖，后一部分受(1)的基数交换约束。但(1)没有将这两部分的离轨利润归入实际 W，也没有给出一种兼容所有真实分支的同一运输。

## 未通过的关键跳步

试图把(1)变成按 1/c_x(z) 分母付款，需要至少下述两项之一：

1. 同一离轨叶内，O 外客户到 P_i minus B 的运输，且目的客户有不小于源客户的份额；
2. 跨最优 token、跨真实分支的耦合，能把这些离轨 complement 利润共同记到实际叶 s 的 W 与 E，而不重复使用同一利润。

单主题或全块最优覆盖的基数比较均没有建立这两项。单独知道所有合法 A 的 |A minus O|<=|P_i minus A|，不能直接宣称存在对所有 A 同时兼容的客户匹配；也不能把 |.| 替换为一个依 z 改变的倒数负载权重。这里没有证明该运输不可能，只是没有证明它成立。

将(2)沿递归 relay 求和时，未消去的 v(B minus T_i) 仍来自各自真实离轨叶。它们不自动组成实际 W 的子份额；最优 token 编号也不能消除分支改变。这正是本次直接交换尝试的停止位置。

## 在一般论证中的承重状态

没有新的关系可以插入一般稿现有 BG 正的孩子机会损失付款处，也没有控制现有 DIRECT-EARLY 中的早期总债。上述交换输入属于既有静态部分；(2)只是同枝均分公式的精确展开，不应包装成一般福利进展。

将完全相同的推导代入 m=5，(1)、(2)仍成立，但三个早期玩家所触发的真实 complement 利润没有得到共同预算。因此本任务不能推出任意五人共同目录的 OPT_5<=2W，当然也没有推出任意人数结论。

本任务没有生成辅助反例、没有继续固定规模搜索、没有把无突破解释为原目标为假。下一次值得继续的输入应是上述两项运输/耦合之一的真实全范围证明，或一个能直接支付净需求 |M|-|E| 的不同机制；仅重述静态最优替换不足以继续。
