# 被否定的是向上修复合同

在[共同目录完整历史模型](../定义/共同目录完整历史模型--定义.md)中，从一份m人完整纯SPE的**实际路径**删第二位，因果插回原第二动作构成m−1人完整回放计划τ。τ可以在全部有序新历史定义，仍不预设为删后SPE。本文给每个m≥3、a≥1的单位客户实例，使
\[
W(\tau)=W=2ma,\quad
\sum_i\rho_i^{actual}=\frac{2a}{m-2},\quad
\sum_i\sup_{|h|=i-1}\rho(h)=\frac{4a}{m-2},
\]
而真正删后游戏的**每一份**完整纯SPE都有W′=W+a。于是不存在与m无关的绝对C，能保证存在真实删后SPE满足W′≤W(τ)+C乘上述任一regret总量。该合同要求向上误差小，和只控制向下福利损失不同；这不是half反例。

# 单位输入与完整原策略

整数m≥3、a≥1。四不交客户块|A|=2a、|B|=2a(m−1)、|C₁|=|C₂|=a；目录为A、B、Q₁=A∪C₁、Q₂=A∪C₂。复制a倍时每个客户都是不同单位客户，不改变提供者单位权。四主题真实互异，不用虚拟复制标签。此族复用[既有多花瓣完整SPE](../反例/独立同分布福利支付--反例.md)的J=2，新增对象是实际删第二位后的修复分离。

原m人策略：根取A，其它非末位取B；末位按过去非B（A或Q）动作个数s含重复决定：s=0取Q₁；s=1且唯一小主题A取B；s=1且唯一小主题Q_j取另一Q；s≥2取B。这规定所有有序离轨历史与平局。

完整IC按同一策略真实续局核：末位s0时Q给3a，优于A2a、B2a(m−1)/m；s1只A时B与新Q各2a；s1只Q时另一Q与B各2a，A只a、重复该Q只3a/2；s≥2时B给2a(m−1)/(m−s)>2a，而小主题至多2a/(s+1)+a≤5a/3。对非末位，s0或s1只A时规定B得2a、小偏离≤2a；s1只Q时规定B得2a(m−1)/(m−2)>2a，小偏离≤2a；s≥2时规定B得2a(m−1)/(m−s)>2a，小偏离≤5a/3。根取A得2a，改B后末位Q，改Q后末位另一Q，两类根偏离也各得2a。故全策略纯SPE，实际AB^(m−1)，全员2a，W=2ma。

# 同一回放叶的退款与全部regret

令n=m−1。原第二位在每个历史都是B。在新历史首行动后虚拟插回B，再按原σ解释后续有序历史，得到因果计划τ：根A、其余非末位B、末位同s规则。实际AB^(m−2)覆盖A∪B，W(τ)=2ma。删除者原收益2a、独占客户e₂=0；每个存活B提供者额外获得2a/(m−2)，总退款2a。[实际单删共同退款](../引理/实际单删后缀的共同退款与全回放界--引理.md)只对固定回放/原策略激励计账，不会把τ变成理性策略。

τ根规定A给2a。强制B后真实回放末位取Q₁，存活B共m−2人，根得2a(m−1)/(m−2)，所以ρ_∅=2a/(m−2)；根强制Q后末位另一Q，根仍2a。任何非根非末位历史，规定B的终局至少一个非B（必要时由末位Q产生），B人数≤m−2，规定收益至少2a(m−1)/(m−2)>2a，改任何小主题收益≤2a，故此类全部历史regret为0。

τ末位只有“此前恰一Q”坏型：规定另一Q得2a，改B得2a(m−1)/(m−2)，regret同根。s0时Q3a最佳；s1只A时B严格优于Q；s≥2时B严格优于小主题。实际末位此前只有A，因此实际路径仅根有regret。根和末层均可达到所述正值，其他层全部历史为0，所以两个和都是**恰值**，不是上界。所有规定收益正；全历史最大最佳强制收益/规定收益比恰1+1/(m−2)。

# 所有真实删后SPE均必须增加a福利

在真正n=m−1人游戏，一旦过去已有一个非B，任何当前小主题因核心A已被覆盖，收益至多核心a加私有a=2a；若后继全取B，当前选B至少得|B|/(n−1)=2a(m−1)/(m−2)>2a。从末位反向归纳，此后所有人严格取B，与平局无关。

全B终局不可能：末位B仅|B|/n=2a，偏离Q得3a。第一非B不可能A：之后全B，选A得2a，改Q后仍全B且自己得3a。所以每份完整纯SPE终局恰一Q和m−2个B，
\[
W′=|B\cup Q|=(2m+1)a=W+a.
\]
有限共同目录保证完整纯SPE存在，因而不是空量词。这里允许全策略重选，不只是局部修补τ；所有重选都必须付向上a。于是实际regret合同要求C≥(m−2)/2，全层sup合同要求C≥(m−2)/4。固定a=1、m→∞时两种加法误差趋0，必要向上福利差仍1。复制a不会把小regret变为零，不能误写零regret反例。
