# 末段锚点改选后的双真实孩子缺陷账

2026-10-24，continue_general_budget。全范围有条件解析关系；root 与 budget_attack 在只收到公式后分别独立重构。这里只组合原末位最佳回复与既有最后非 B 四税分解，不声称外部新颖性。Q-CAG-HALF 仍 OPEN；本文没有给不同根分支一份共同福利预算。

## 1. 两个真实孩子及记号

采用 CAG-MODEL：任意有限单位客户、有限非空共同目录、任意人数、任意完整有序历史纯 SPE。固定任意合法前缀，其客户负载为 a_x。固定该前缀的一个真实孩子，其路径为 \(T,C^r\)。

其中 r>=1，T、C 是合法主题，允许 T=C。可以取 T 为这条真实路径的最后一个非 C 行动；下述恒等式只用到其后确为 r 个 C。

在当前节点强制选择 C，随后沿同一原完整策略执行，得到另一真实孩子。这个孩子的 r 人 suffix 背景是

    b'_x = a_x + 1_(x in C).

若新孩子全为 C，则不定义最后非 C，也不使用下一节的五项式。否则令 Q 为新孩子的最后非 C 行动；在它之前有 k 个新 suffix 行动，之后有 ell 个 C，k+1+ell=r。令 p_x 是这 k 个行动的负载。

原真实 T C^r 叶的完整负载记为

    c_x = a_x + 1_(x in T) + r 1_(x in C).

前缀可任意，且无需把相同负载的不同有序历史合并。事实上，只要原 C 末位是最佳回复、新孩子是完整 suffix-SPE，即使两孩子分别取自不同完整 SPE，以下关系仍成立；使用同一原策略只是直接保证两个孩子均真实且可信。

## 2. 精确的五项非负分解

原叶末位 C 对合法主题 Q 的真实最佳回复松弛为

\[
\eta_Q=\sum_{x\in C\setminus Q}\frac1{a_x+\mathbf1_{x\in T}+r}
-\sum_{x\in Q\setminus C}\frac1{a_x+\mathbf1_{x\in T}+1}\ge0.
\tag{1}
\]

在新孩子的最后非 C 节点，记当前实际收益 u_Q、真实改 C 收益 d_C，以及

\[
G_C=\sum_{x\in C}\frac1{b'_x+p_x+\ell+1}.
\]

沿用最后非 B 四税的定义：

\[
\begin{aligned}
A'_Q&=\sum_{x\in Q\setminus C}
 \left(\frac1{b'_x+1}-\frac1{b'_x+p_x+1}\right),\\
E'_Q&=\sum_{x\in C\setminus Q}
 \left(\frac1{b'_x+p_x+\ell+1}-\frac1{b'_x+r}\right),\\
\gamma'_Q&=u_Q-d_C,\qquad \zeta'_Q=d_C-G_C.
\end{aligned}
\tag{2}
\]

四项分别非负。前两项用 0<=p_x<=k 及 k+1+ell=r；第三项是该真实节点 IC；第四项是任意真实后继对 C 的逐客户最大拥挤保底。四税恒等式给

\[
\delta'_Q:=\sum_{x\in Q\setminus C}\frac1{a_x+1}
-\sum_{x\in C\setminus Q}\frac1{a_x+r+1}
=A'_Q+E'_Q+\gamma'_Q+\zeta'_Q\ge0.
\tag{3}
\]

定义当前槽的一次扰动池

\[
\begin{aligned}
K_{T,C}(Q)
={}&\sum_{x\in Q\cap(T\setminus C)}
 \frac1{(a_x+1)(a_x+2)}\\
&+\sum_{x\in(C\setminus Q)\setminus T}
 \frac1{(a_x+r)(a_x+r+1)}.
\end{aligned}
\tag{4}
\]

则有精确的双孩子式

\[
\boxed{K_{T,C}(Q)=\eta_Q+A'_Q+E'_Q+\gamma'_Q+\zeta'_Q.}
\tag{5}
\]

因此新孩子中真正更早的 \(\gamma'_Q,\zeta'_Q\)，以及另外两项拥挤税，只能使用同一份 K，不能给每项各复制 K。它还保留原末位行的已付松弛 eta，而非把它重复算成未付差额。

## 3. 证明及统一核

把(1)加到(3)。在 Q\C 上，若 x 不在 T，两个倒数完全相消；若 x 在 T，剩余 1/(a+1)-1/(a+2)。在 C\Q 上，若 x 在 T，两个倒数完全相消；若 x 不在 T，剩余 1/(a+r)-1/(a+r+1)。这恰是(4)，故(5)成立。

使用原真实叶负载 c，可把同一个池统一写为

\[
\boxed{
K_{T,C}(Q)=
\sum_{x\in Q\cap(T\setminus C)}\frac1{c_x(c_x+1)}
+\sum_{x\in(C\setminus Q)\setminus T}\frac1{c_x(c_x+1)}.}
\tag{6}
\]

两种客户均有 c_x>=1，故无零分母。这正是额外查询的倒数边际核 1/c-1/(c+1)，但只是核相同；没有因此取得最优索引交换的共同容量。

对所有可能 Q 可用同一个上界

\[
K_{T,C}(Q)\le K^{\max}_{T,C}
=\sum_{x\in T\setminus C}\frac1{c_x(c_x+1)}
+\sum_{x\in C\setminus T}\frac1{c_x(c_x+1)}.
\tag{7}
\]

若同时考察多个 Q 或多个互斥孩子，(7)不是每个孩子各自拥有的一份现金；只有选定一个真实孩子时(5)才是本次单槽转移的账。

## 4. 对接最优索引交换时的精确边界

既有 Bernoulli 最优索引交换按每一条真实叶分别成立，并支付该枝 O 外的查询税 L_out=sum c/(1+c)。其未付返还池 R_out=sum_(c>0)1/(1+c) 必须继续保留。本式没有支付 R_out，也没有把 K 转成实际根路径利润。

尤其，K 中的 c 是原 T C^r 真实叶的负载；若该叶本身是某个强制最优主题后的离轨枝，它就不是原实际路径的负载。不同根枝、反复 last-switch 后不同叶所出现的同一客户，不能按(6)重复领取原实际份额。两条 E2/Bernoulli 上界也不能相减得到 K 的符号预算。

本式新增的可用关系是：一个旧真实末位 BR 行，确实能给另一真实孩子的四项税一份同槽缺陷上界；它不是“只要所有税非负便能共同支付”的证明。缺少的仍是跨不同根枝及反复替换的客户/角色容量耦合，或其他直接控制净遗漏的机制。

## 5. 税池不能直接付款旧玩家返还：两个解析反例

以下都是合法前缀后的完整两人 suffix-SPE，只否定指定局部付款接口，不是 Q-CAG-HALF 反例。构造及第一例由 budget_attack 提出，continue_general_budget 独立逐行重构；第二例为同族的背景改动。

取共同目录恰为三个互不交主题 A、B、C。先令整数 k>=1、c>=1，

    |A|=k+1, |B|=1, |C|=c+1,
    前缀为 k 个 A 和 c 个 C（任意固定顺序）。

还剩两人。在这个固定前缀后，规定当前 B 后末位 C，当前 C 后末位 A，当前 A 后末位 C。三种当前行动的最终收益都恰为 1。给定某个当前主题后，未被当前选择的另一个主题的末位收益为 1，而复制当前主题的收益严格小于 1，因此规定的三个末位行动全是最佳回复。这定义了整个两人子博弈的完整纯 SPE，不仅是一条叶。

比较其真实叶 (B,C) 与当前强制 C 后的真实叶 (C,A)。旧前缀在 A 上的总利润从 k+1 降到 k，在 C 上的总利润不变，故旧前缀总利润恰损失 1。取 k=1 时，单个旧 A 玩家已损失 1。

但新 C 孩子的最后非 C 是 Q=A，r=1；在(5)中

\[
\eta_Q=A'_Q=E'_Q=\zeta'_Q=0,
\qquad
\gamma'_Q=\delta'_Q=K_{B,C}(A)=\frac1{c+2}.
\tag{8}
\]

令 c 增大，便严格排除任何统一常数 M 下的“旧前缀净利润损失 <= M K(Q)”；甚至只剩一个真实未来玩家也失败。该例没有否定 Kmax，因为其另外包括 B 的 1/2 池。

再把 B 改成有整数 b>=1 个旧前缀覆盖者，取 |B|=b+1，固定前缀为 A^k B^b C^c，三个两人行动规则不变。每个当前收益仍为 1，三个末位仍为最佳回复，故仍是完整 suffix-SPE。此时

\[
K^{\max}_{B,C}=\frac1{b+2}+\frac1{c+2}\longrightarrow0
\quad(b,c\to\infty).
\tag{9}
\]

取 k=1，指定的旧 A 玩家仍恰损失 1。因此甚至较大的 Kmax，也不能以任意统一常数直接付款某个指定祖先（包括可以位于根的旧 A 玩家）的利润损失。这里旧 B 玩家总共恰获利 1，抵消旧 A 的损失，旧前缀的**总净利润变化为零**。这第二例不排除 Kmax 支付全部旧前缀总净损失的候选；第一例排除的只是更小的 Q 依赖税池。

前缀玩家在这些例中是固定背景；没有声称这些指定前缀动作在完整根博弈中也是最优。因此两个反例只适用于“任意合法背景下的局部利润传递界”这个精确范围。它们足以说明，(5)的五税共同池与旧玩家返还必须分账，不能直接把前者当作后者的幅度。
