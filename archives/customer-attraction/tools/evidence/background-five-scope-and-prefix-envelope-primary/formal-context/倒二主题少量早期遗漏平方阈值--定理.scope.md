# 倒二主题少量早期遗漏的平方阈值

## 精确陈述和真实比较

采用[完整历史模型](../定义/共同目录完整历史模型--定义.md)的任意有限单位客户、有限非空共同目录和单位提供者。固定任意一份定义于全部有序历史的纯SPE，其实际末两主题为A,B。若存在整数r>=1，使前m−2个实际主题中至多r个不包含A，且

\[
\boxed{m\ge(r+1)^2+1,}\tag{H_r}
\]

则实际根覆盖满足2W>=OPT_m。这里“不包含A”指整个集合关系A⊆E失败；一个例外仍可覆盖A的部分客户。目录大小、离轨行动及其关联没有额外限制，空主题、重复、零客户和任意历史平局均允许。平方阈值是充分条件，未证必要或锐。

阈值给m>=5、r<=(m−3)/2，所以可以从实际早期角色中选**r个不同位置**E_1,…,E_r，包含所有例外；不足r个时用实际包含A的角色补足。其余m−2−r个主题都包含A。不含例外的m>=3情形还可直接用[共同包含定理](倒二主题共同包含半覆盖--定理.md)，无需提高到本页阈值。

任取m个合法比较主题T_i，O=|⋃T_i|。固定实际早期有序前缀h，其负载为p_x；R_i是原策略在(h,T_i)的真实末位回复。按[菜单消去引理](../引理/真实末两人菜单交集消去--引理.md)，

\[
\begin{aligned}
S&=\sum_i[u_A-U_p(T_i,R_i)]\ge0,\\
Z&=\sum_i[u_B-U_p(R_i,A)]\ge0,\\
V&=\sum_{i\ne j}[U_p(R_i,T_i)-U_p(R_j,T_i)]\ge0,\\
G&=S+Z/(2m)+V/m\ge0.
\end{aligned}\tag{1}
\]

每个早期角色E_j在其**原实际节点**可改A并随后沿同一策略行动；每个A客户最终至多被m人覆盖，所以u_Ej>=|A|/m。实际末位在(h,A)还可改E_j，所以u_B>=U_p(E_j,A)。因而联合补偿

\[
\boxed{K=\sum_{j=1}^r\left[u_{E_j}-\frac{|A|}{m}
+\frac{u_B-U_p(E_j,A)}{m-1}\right]\ge0.}\tag{2}
\]

早期偏离后的后继从未被冻结；式(2)的两类非负差来自各自合法的原节点，可用非负乘子相加。
