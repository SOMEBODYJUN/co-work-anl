## 精确靶与实际边界

攻击的辅助全称候选为：原 CAG-MODEL 的任意完整历史纯 SPE、任意实际玩家 i，
`OPT_m-W <= m*u_i`。它若成立可经求和推出 half，但本轮没有提升其状态。
更强的 `(m-1)*u_i` 版本也不能由以下有限结果判定。

- `gap_m3p6i0.json`：复用旧 `next_boss/full_tree_milp.py`，m=3、p=6、首位收益归一为1；比较组合包含/不包含根主题分别运行45秒。均只发现 `OPT-W=2` 的数值候选，MILP上界未闭合。
- `gap_m4p5i1.json`：同工具，m=4、p=5、第二人收益归一为1；两种比较组合位置分别45秒，只发现 `OPT-W=1`，优化明显不充分。
- `structured_gap_attack.py`：对结构种子求集合值BI的全部根终局，选 `(OPT-W)/min_used_utility` 最大者；重构完整有序历史可信策略；全非空类型重数锥LP再优化；顶点反馈给BI。它复用仓库已有完整策略锥接口，不把计数缓存变成计数Markov策略。
- `structured_gap_m5p7.json`：seed=216741，m=5、p=7，实际完成迭代0至8后主动停止。新种子是23客户末位份额反例与14客户残余循环的私有padding；最高数值仍为已知all-big值4。所选all-big点已Fraction重构并逐历史重放。它只是实现控制，不是一般桥的正面数学证据。

同类顶点迭代仓库已有大量有限运行；本轮没有新承重点，故没有继续增加重复样本。

## 可加入完整树MILP的前缀包络

以下是直接分母推导，不是新的half机制，也没有作求解性能声称。
固定一个有序前缀h，长度t，余下k=m-t位。旧玩家i<=t在h中选主题a。
令b_B为前缀选中兴趣类型B中主题的次数；r_B为其非负客户重数。
对**任意**后续策略、任意终局（无需SPE），该旧玩家最终收益U_(h,i)满足

    sum_(B contains a) r_B/(b_B+k)
      <= U_(h,i)
      <= sum_(B contains a) r_B/b_B.

理由是每个涉及的B满足b_B>=1，最终负载c_B介于b_B和b_B+k之间，逐客户取倒数再求和。
因此两端都是r的合法线性表达式，可不加二进制变量地加入全树MILP。
既有 `full_tree_milp.py` 当前只使用统一盒约束、终局收益定义与选中边传播，未显式加入这些中间历史行。
它们不改变精确整数可行集，但可能加强分支定界的连续松弛；是否有实际收益需要另做固定版本对照。

再启动优先条件：有新的解析桥可被具体分离；出现全历史可核验候选；或新有效不等式确实改善已知可行点的求解。
没有这些变化时，不把有限无反例样本继续堆积为研究进展。
