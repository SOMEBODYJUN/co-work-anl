## 共同分布为何成立

对旧直方图质量 h 及每个 R 轨道质量 q_g，把区间 [0,h] 在所有 q_g 处切分。每段质量 w>0，整段固定 `r_g=1_{q_g≥段上端}`。全部正质量旧直方图共给25个确定 R 模式。其 R 边缘仍恰为 q_g，任意两个 R 的共同质量同时为 min(q_g,q_f)。旧行中这些交叠只带非负系数，因此使用这个共同阈值分布合法。

每个固定 R 模式、每个轨道只保留 Z 的质量 z_g∈[0,w]，共321变量。对实际倒二背景 a，在该模式上新增真末位查询恰为

\[
\frac{z_e-z_f}{a+r_e+1}.
\]

这里是**模式内的质量**；r 已确定。所有旧行以及全部新增 Z→Z 行对这些 Z 位联合仿射，未出现 Z_e Z_f。因此在各模式内独立取 Z 位，其概率为 z_g/w，即给出全部会员位的共同分布，准确实现每一行的期望。也可再按各 z_g 作共同阈值切分，得到有限个完全确定的 (R,Z) 模式；两种构造对所列行等效。

同轨道所有标签在这个构造中取相同位，是所选子支撑，**不是**从轨道平均推断标签相等。将该分布对六个比较索引统一置换平均，保持旧直方图及全部等号类，便得到对称的完整标签分布。因而它同时满足该图中各字面行的对称平均约束，不仅是彼此不一致的 pairwise 矩。没有由此构造出所有有序历史的策略。
