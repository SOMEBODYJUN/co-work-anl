# 真正安全桥状态及最优客户投影

2026-10-25。Boss13 子研究员从 CAG-MODEL 定义独立推导。对全部有限单位客户、非空共同有限目录和任意 m 有效；全部有序历史、重复和任意平局量词不变。本文没有一般 half 证明、目标反例或真正安全值反例。下列候选准确标为未证。

## 1. 目前可以确认的强桥状态

原真正安全值为

`v_m = max_p min_(B in S^(m-1)) E_(A~p) sum_(x in A) 1/(1+c_x(B))`。

B 不观察查询 A 的实现。当前仓库共享 `general_half_proof.md` 第5节仍将 `W>=m v_m` 和 `W>=(m-1/2)v_m` 列为 OPEN。实际读取 `R-ab2c6df20538474c948f5f24e59437ee/` 后，材料是任意背景逐人 extra-one 的边界、末位完整菜单候选及二次 meta-Nash 与菜单 minimax 的静态差；没有空根真正强聚合反例的参数和全历史证书。父方进一步核对后通知，相关最新线索仍只有口头候选，不能据此变更 OPEN。

静态 CCE/PNE 福利失败、iid 桥失败、非 CAG 匿名势例和不可信复制威胁均不补齐这个缺件。本文未把它们再次当作真正安全桥反证。

## 2. 合法弱化：删最优并集外客户，保留全部主题查询

固定任意 m 主题最优并集 O。定义投影收益

`u_i^O(z)=sum_(x in S_i intersect O) 1/c_x(z)`，

并定义

`v_m^O = max_p min_B E_(A~p) sum_(x in A intersect O) 1/(1+c_x(B))`。

目录仍是原全部主题；投影后的相同主题可视为不同标签，重复标签不影响 minmax 值。只有客户估值被限制到 O。非负性立即给 `v_m^O<=v_m`。投影目录以 m 个主题覆盖全部 O，故投影实例的 `OPT_m` 恰为 `|O|=OPT_m(original)`。已有静态安全值证明合法应用于投影客户，给

`OPT_m <= (2m-1) v_m^O`。                         (P1)

所以以下是准确的、比未限制客户安全桥更弱的一般充分候选：

> SEC-OPT? 对每份原完整纯 SPE，存在一个最优并集 O，使
> `W >= (m-1/2) v_m^O`。

可以等价取所有最优并集中的最小 `v_m^O`。候选若成立，由(P1)推出一般 half。本文没有证明 SEC-OPT?；它仍可能严格强于 half。

这个弱化确实会严格降低数值：取 k>m>=2 个互不交单位 singleton 主题。原 `v_m=1-(m-1)/(2k)`；任一最优 O 含 m 个客户，投影后 `v_m^O=(m+1)/(2m)`，两者严格分离。证明均由均匀查询给下界、对称随机选择 m-1 个不同被保留 singleton 给对偶上界。没有在此开展特殊规模正面研究；这一全参数族只验证两个比较对象确实不同。

## 3. 不合法的替换：只允许查询最优组合的主题

若只允许 p 支持在某个最优组合中的主题，而仍允许 B 选原目录，(P1)通常失败；不能拿这个更小的值继续用同一个 `2m-1` 常数。

以下是全参数精确静态反例。取 m>=2 个互不交块 A_j，各含 K>=2 客户；每块指定一个私有点 a_j。再加主题 C，含每个 A_j 的其余 K-1 名客户。目录仅为 `A_1,...,A_m,C`。原最优 m 主题必须取全部 A_j，覆盖 mK：任何含 C 的 m 元组合至少漏掉某个 a_j。

把查询限制到 A_j 后，固定背景 `C^(m-1)` 使每个查询恰得

`1+(K-1)/m`。

因此受限值 t 满足 `t<=1+(K-1)/m`。当

`K > (2m-1)/(m-1)`，

有 `(2m-1)t < mK=OPT_m`。例如 m=2、K=4 时 `3t<=15/2<8`。这只是静态比较常数的反例，没有声称任何坏 SPE；主题 C 的查询正是原静态预算不可丢掉的共同目录项。最优并集 O 在这里等于全部客户，合法客户投影不会误删 C。

## 4. 客户投影不继承 SPE，但其真实后悔有一次性预算

**来源去重：** 本节是在先独立重构后对稿时确认的旧组件。精确来源为 `R-b659ddeec819493bb10dc58441fa7b3d/refund/shared_refund_projection.md` 的 PROJ-IC/PROJ-RESERVE/PATH-REFUND，旧式还保留每个真实偏离的外部剩余信用，强于这里只写出的(P4)。更早的同一“原IC加收益变化”原则见 R-105 的 `parent/deletion_regret_envelope.md` 与 R-4ffa 的 `deletion/virtual_replay_regret.md`；玩家删位全树版本见 R-d398 的 `round4_general/induction/causal_deletion_refund_conservation.md`。不认领为新付款机制。

记 E 为 O 外客户，任意有序历史 h 的原策略续局为 z(h)，强制当前主题 T 后仍运行同一原策略的终局为 z(h,T)。令当前角色为 i。原完整 SPE 给

`u_i^O(z(h,T))-u_i^O(z(h))`

` <= u_i^E(z(h))-u_i^E(z(h,T))`。                (P2)

右端可以为负，必须保留真实分支，不能冻结后继。定义投影节点后悔

`r_i^O(h)=max_T [u_i^O(z(h,T))-u_i^O(z(h))]`。

原动作也是可选 T，所以 `r_i^O(h)>=0`；非负客户收益和(P2)给

`0<=r_i^O(h)<=u_i^E(z(h))`。                     (P3)

沿任意固定历史 h 后原策略实际续局，把(P3)只对这条路径上的各剩余角色相加，得

`sum_remaining r_i^O(h_i) <= sum_remaining u_i^E(z(h))`。

特别地，空根实际路径满足

`sum_(i=1)^m r_i^O(h_i) <= |C_actual \ O|`。        (P4)

外部客户即使实际被多人覆盖，其利润总和也只计一份，因此(P4)没有重复花费同一客户。结论量化全部原历史，但不能把互斥分支上的不同(P4)再相加。投影策略通常仍有正后悔，不能直接应用任何只对完整 SPE 成立的投影游戏福利定理。

旧 PROJ-RESERVE 更精确地给 `r_i^O(h)+min_T u_i^E(z(h,T))<=u_i^E(z(h))`，因此实际路径还可保留各节点 `min_T u_i^E` 的总额。这里的身份是保留全部原标签和原策略的、节点误差不均匀的近似 SPE 计划；不是同一 projected game 的精确 SPE，更不是把投影策略替换为另选的一份 SPE。

## 5. 真正未闭合的关系与 m=5 压力测试

令 `W_O=|C_actual intersect O|`、`E_actual=|C_actual \ O|`。原净差为

`OPT_m-W=|O\C_actual|-E_actual`，

不能把需求替成纯遗漏数。SEC-OPT? 的具体付款义务为

`(m-1/2)v_m^O-W_O <= E_actual`。                  (P5?)

(P4)证明 E_actual 足以支付投影后实际路径的真实节点后悔总量；它**没有**证明(P5?)左端小于这些后悔，也没有控制不同查询分支的共同安全债。因此(P4)是一条通用投影转移关系，不是 half 承重付款已经完成。

m=5 时，同一未证义务是 `9v_5^O/2<=W_O+E_actual=W`，配合(P1) `OPT_5<=9v_5^O` 条件性推出 half。当前没有无条件推出该式，不能报告五人压力测试已经通过。

下一条信息价值高的判别是直接证明或给出真正全历史 SPE 反例否定(P5?)，而不是只在完整安全值 v_m 上继续扩大有限阴性搜索。若发现未投影强桥反例，应先精确计算这个反例各最优 O 的 v_m^O；反例可能源于所有最优并集外的客户把 v_m 抬高，此时 SEC-OPT? 仍有独立意义。
