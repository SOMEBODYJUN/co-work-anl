# 个体安全、去相关与尾部流增量

## 共同对象与已有正文

十份来源均使用共同目录、单位客户、顺序单位提供者、客户在最终覆盖者间均分及完整历史纯 SPE 的 CAG 模型。它们应与 shared facility 或 unrelated-machines 证书分开。已有稳定正文已经承载主要数学对象：

* [后继安全值与完整树精确审计](../计算/后继安全值与完整树精确审计--计算.md)承载 1885 节点去相关、43 节点个体安全和全树流原始重放；
* [三人逐人混合安全值反例](../反例/三人逐人混合安全值--反例.md)承载 34 客户完整 SPE；
* [自适应后继与真实菜单障碍](../障碍/自适应后继与真实菜单安全值--障碍.md)承载去相关式 (D)、真实菜单式 (M) 和任意 \(n\ge3\) 的菜单编译族；
* [完整策略树平均障碍](../障碍/完整策略树平均与独立同分布福利桥--障碍.md)承载全树流恒等式和非 SPE 分离向量；
* [尾部利润界向总人数提升](../推论/尾部利润界向总人数提升--推论.md)承载 \(F_k(b)\le\beta_kV_k\) 条件下的任意人数提升。

本页把本批新导出的运行字段与这些对象逐项对齐，说明哪些是重复审计，哪些有独有历史候选内容。

## 去相关桥和个体安全值：失败的量词必须分开

### 四人 adaptive decorrelation

`bd875beb7f1944154abb` 的 exact JSON 检查 1885 个 ordered nodes、22620 个 action comparisons、26,171,145 个单位客户的压缩权重。实际根为 \((8,4,5,0)\)，root utility 为 6,135,345；两指定 deviation themes 为 4 和 9，真实后继分别为 \((2,3,11)\) 与 \((6,7,3)\)。收益矩阵为
\[
\begin{pmatrix}6135342&6135349\\6135349&6135345\end{pmatrix},
\]
故均匀查询时 adaptive mean 为 \(12270687/2\)，independent mean 为 \(24541385/4\)，差 \(-11/4\)。`free_menu_cap=6135345`，源字段明确这只是 universal decorrelation 反例，不否定 half 或 mixed-security bridge。该运行与已有[自适应后继障碍](../障碍/自适应后继与真实菜单安全值--障碍.md)完全相同对象，处置为 `integrated`。

`0d95efeb88adc5463938` 是独立内部审查的 Markdown，而非 JSON。全文复核了一后继去相关恒等式的 minimax 方向、四人矩阵和自由菜单 cap；还复核三人 36 客户根菜单 \(z_1=11>u_1=10=v_3\)，以及每个 \(n\ge3\) 的 Möbius 编译族。审查的结论边界很清楚：排除指定 (D)/(M)，不判断一般逐人 \(u_i\ge v_n\)、总桥 \(W\ge nv_n\) 或 half。它补的是独立文字审查和量词校正，不是新定理。

### 34 客户与 360 客户安全候选

`70a225d01e7d689d1883` 的 exact run 重放 34 客户、13 customer types、43 histories、258 action comparisons、215 非平凡偏离（144 严格输、71 平局）。实际路径 \((0,3,4)\)，收益 \((29/3,67/6,67/6)\)，\(W=32\)、\(\operatorname{OPT}=34\)，真正静态安全值 \(v=2411/246\)。第一位差为
\[
29/3-2411/246=-11/82<0,
\]
而 \(W-3v=213/82>0\)、half margin \(W-\operatorname{OPT}/2=15\)，所以这是逐人安全值反例而不是福利反例。binding query matrix determinant 为 \(-12055/48\)，primary optimum 唯一，GB 为 \(60/41\)。它直接合并到现有 34 客户反例。

`a37ba8208186189c11c4` 是同一 34 客户压缩候选的完整独立 JSON：全部 216 terminal profiles、258 continuations、36 ordered static backgrounds、1548 continuation-background entries 均评估，security value 的 lower/upper 均为 \(2411/246\)，rank 为 6，determinant 为 \(-12055/48\)，actual welfare 32、OPT 34，aggregate security margin \(213/82\)，GB \(60/41\)。`9603788cc9ab53b8d9ac` 的独立文字审查再次逐客户展开并重算同一行列式、唯一性和 budget；它不提供全局最小性或优先级声明。两者都是同一对象的独立实现/审查，保留 raw 版本，处置为 `integrated`。

`6be47bc0797b53c84494` 则是 360 客户候选的独立 exact review。它验证 3 players、6 topics、360 unit customers、19 types、43 policy nodes、216 terminal profiles、258 continuations；215 deviations 中 164 严格输、51 平局。安全值为 \(93177/908\)，实际首位收益 102，差
\[
102-93177/908=-561/908<0.
\]
实际福利 336、OPT 360，\(W-3v=25557/908>0\)、half margin 156，GB 正值。它是早期候选，现有 34 客户构造已更小；本页保留它作为“历史搜索和独立复核都正确”的候选证据，但不另立最小反例对象，也不宣称 360 客户具优先性。

## 全树流分离：负向量不是 SPE 反例

`b991ca30daf6314edd54` 的 `full_tree_flow` JSON 精确记录了三个层级：

* original36：\(W=34,\Psi=97/3\)，\(G=(0,1/2,31/18)\)，unit-flow remainder \(-5/9\)，harmonic remainder \(-5\)，且 258 full comparisons 的 exact check 通过；
* depth-only separator：权重只在 6 个节点，\(G_3=607489/216\)，\(W-\Psi=-472195/36\)，negative full rows 57，`full_strategy_is_SPE=false`；
* node-averaged separator：43 个节点、15 个非零节点权重，node-average row 最小为 0，但 \(W-\Psi=-1085816540911589/12\)，同样不声明完整 SPE。

`379d7599d93910cb6dc4` 是独立 lift-and-flow JSON，提供相同对象的更细字段：252 个 lift pointwise enumeration checks；原 36 客户的 node_average_min 为 0、negative full Gamma 为 0；depth separator 的 node_average_min 为 \(-80210/9\)、negative full Gamma 57、total mass 80935；node separator 的 node_average_min 为 0、negative full Gamma 59；另有非均匀 \(n=4) identity，\(W=10,\Psi=775/81\)，unit-flow remainder \(16/81\)，harmonic remainder \(-41/81\)，node_average_min \(-14/9\)，negative full Gamma 6。

这些字段证明的是：固定深度/节点平均的流乘子模板会丢失逐偏离信息。负向量有 \(\Gamma w<0\) 行，不能冒充完整 SPE 或 Q-CAG-HALF 反例。它们与[完整策略树平均障碍](../障碍/完整策略树平均与独立同分布福利桥--障碍.md)整合；正面的 36 客户流恒等式仍只说明 \(-5/9\) 是被丢弃的余项，不否定一般强 iid 桥本身。

## 尾部提升与总人数边界

`c7b73d6fbb280dc7583b` 是独立数学审查 Markdown。它逐行确认四人尾部提升：若所有合法非零背景和完整子局均满足
\(F_4(b)\le(1499/750)V_4\)，则对任意 \(n\ge4\)
\[
\operatorname{OPT}_n\le(n/2-1/750)W.
\]
审查明确要求使用实际有序前缀、真实后继、整数背景和最大主题 \(K\) 的 \(K/n\) 保底；不允许把零背景五人根界替代背景版四人前提。它还确认一般 \(k\) 公式 \(n/2-k/2+\beta_k\) 及全树平均流的独立障碍。该来源整合到现有[尾部利润提升推论](../推论/尾部利润界向总人数提升--推论.md)，并补充其已实读的量词审查。

`a0b7ba352b8f55edd896` 是 2026-10-10 的 general-gluing manifest，列出 individual security failure、iid benchmark、full-tree averaging、selected cones、tail-four-all-n、random-prefix exchange 和 seven-maxima checkpoint 等 claim，并明确六项限制：没有任意人数 half 证明或反例，没有 aggregate security bridge 结论，iid separation vectors 不是 full SPE，selected cones 不量化任意 complete policy，seven-maxima 只对 \(n\ge7\) 完整，没有外部同行审查。它是总览/版本索引，处置为 `integrated`，不单独建数学对象。
