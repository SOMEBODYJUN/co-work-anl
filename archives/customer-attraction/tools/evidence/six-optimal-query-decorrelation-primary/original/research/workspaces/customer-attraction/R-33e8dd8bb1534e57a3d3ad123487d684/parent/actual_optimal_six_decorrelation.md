# 实际六人节点：重选最优六元组也不能免费去相关

**准确状态：** 原模型中的明确六人完整纯 SPE 辅助反例；精确程序已核验全部有序历史，唯一指定研究员的独立单位客户实现也已复核通过，父方重新运行并对照全部结果。不是 half、ROW、六人主目标反例，未声称外审或新颖性。复用旧34客户机制，不把旧客户输入或旧势恒等式当成新发现。

## 精确被否定 Claim

对每个 CAG-MODEL 六人实例、每份完整历史纯 SPE σ，及其每个恰余三人的**实际有序前缀 h**，存在一个达到 OPT6 的六槽元组 T=(T1,…,T6)，使均匀独立索引 j,l 满足

`E_j U_b(Tj;Bj,Cj) >= E_{j,l} U_b(Tj;Bl,Cl)`，

其中 (Bj,Cj) 是同一 σ 在强制 Tj 后的真实两名后继，b为h的客户背景负载；右边只计算移植后的静态份额。这个 **存在最优元组的非负去相关桥** 为 FALSE。反例在实际路径而非仅在离轨历史，且所有最优六元组均使用六个不同主题。

它不否定存在非均匀、非最优查询分布的版本，不否定使用全路径利润支付有符号亏损，更不否定半覆盖。

## 输入与策略的可恢复身份

另增加三个彼此及与旧客户完全不交的合法主题6,7,8，每个各有18名不同单位客户；客户总数88，目录共九主题，提供者恰六。

完整策略由 [自足生成及核验程序](actual_optimal_six_decorrelation.py) 规定：对全部有序历史做精确逆向归纳，通常取最小标签最佳回复；在以下节点使用经逐项确认最优的固定动作。

- 实际前三步依次选6,7,8，记h=(6,7,8)。
- 在h，选0。
- 在(h,a)，若a<3选3；若3≤a<6选0；若a∈{6,7,8}则选3。
- 在(h,a,b)，若a,b<6，则选b所在三标签组内未在a,b出现的最小标签；若a为银行主题且b=3，选4。

其他动作由同一个逆向归纳程序确定，绝不随被检查的最优组合重选。所有强制分支以及祖先都属于这份完整 σ；若相同主题/历史重复出现，动作仍由唯一历史键给定。程序中的每次固定动作都断言其收益等于该节点九个合法动作的最大值。

再由不调用逆向归纳终局集合求解器的定义级 `verify_certificate` 检查整棵树：**66,430个有序决策历史，531,440项非自身偏离，全通过**。这是一个有限反例的全部量词检查，不是有限无反例代替一般证明。

## 准确失效机制与仍可回收的信息

沿用旧 [三人尾部去相关恒等式](../../../../workspaces/customer-attraction/R-e05f01e191354b028004b433016ae1c9/three_remaining_decorrelation_residual.md)。对第一个最优元组：

`Δ = 第一后继真IC + 跨枝末位真IC + 删除中间行动后的返还`

`−11/72 = 5/36 + 0 − 7/24`。

两个真实后继的合法 IC 正信用不足以支付有符号返还。被强制选银行时，源获得9，真实后继为旧两人SPE(3,4)；被强制选5时，后继为(0,1)。这两个合法续局不能先混成独立尾而不记录损失。

实际源收益29/3，而六个查询的真实收益和为56；净缺口OPT6−W=2，所以 ROW 在本例仍有很大余量。实际前三位的54利润与已覆盖客户都是潜在共同支付来源；本例只禁止将返还或总去相关项免费删掉。
