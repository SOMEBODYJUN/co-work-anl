# 最优六索引也不能免费去相关：准确的六人辅助边界

状态：个人研究备份，定义级全历史精确核验通过；不是六人 half、ROW 或目标反例，也不声称外审或新颖性。原 34 客户及原三人策略均为旧资产；本页只核对“最优六索引均匀查询能够修复旧负去相关”这一可能加强，并给真正六人中的嵌入。

## 被否定的准确陈述

在 CAG-MODEL 中，任取恰六名提供者、完整历史纯 SPE σ、恰余三人的合法有序源 h，以及任意达到 OPT6 的六槽主题元组 T。均匀独立取 j,l∈{1,…,6}。原策略在 (h,T_j) 后的两主题为 (B_j,C_j)。假定

`E U_b(T_j;B_j,C_j) >= E U_b(T_j;B_l,C_l)`。

这个**对任意 h、任意最优六元组**的加强为 FALSE。这里的 h 可以离轨；右边只作静态计算，不能称为真实回复。原半覆盖和实际路径 ROW 都没有被否定。允许重选最优六元组使该式成立的存在性版本也没有被本例否定。

## 实例、策略与全部量词

取现有单位客户输入 `examples/customer_attraction/individual_security_failure.json`，其来源正文是 [原三人完整 SPE](../../../../current/customer_attraction/individual_security_counterexample.md)。它有六个不同主题，34 名不同单位客户。增加一个合法空主题 EMPTY，人数改为六；不改变客户或其兴趣。

在精确有序历史 h=(EMPTY,EMPTY,EMPTY) 后，保留旧三人完整 SPE：源选 0；首主题 a<6 后第二位选 3（a<3）或 0（a≥3）；前两主题 a,b<6 时末位选 b 所在三标签组中尚未出现的最小标签。相对历史出现 EMPTY 时任取真实最佳回复。其他有序历史及其全部祖先按逆向归纳选择最大收益动作，平局取最小标签。

这确实扩成六人的一份完整 SPE：原子树中原六动作的比较不变，新增空动作收益为零；其余节点直接取精确最大收益。程序先生成完整树，再由独立的定义级 `verify_certificate` 检查，不调用 SPE 终局集合求解器。

复核覆盖 19,608 个有序决策历史与 117,648 项非自身偏离，全部为 Fraction 比较。所生成整局实际路径为 (2,5,0,1,3,4)，W=OPT6=34。因此主目标在本例上有充足正余量。

## 最优六索引与损失

取 T=(0,2,2,5,5,5)，其并集覆盖全部 34 名客户，所以确为最优六槽元组。源 h 的背景 b=0。

| 量 | 精确值 |
| --- | ---: |
| 真实对角查询均值 | 29/3 |
| 独立移植两主题的查询均值 | 241/24 |
| 对角减独立 Δ | −3/8 |
| 第一后继真实 IC 均值 I | 3/8 |
| 跨枝真末位 IC 均值 J | 0 |
| 删除中间行动后的有符号返还 | −3/4 |

逐项验证 `Δ=I+J+返还`。完整交叉格中的末回复是原 σ 在 (h,T_j,B_l) 的规定动作；不是在另一节点重选的有利回复。

这沿用旧 [三人去相关恒等式](../../../../workspaces/customer-attraction/R-e05f01e191354b028004b433016ae1c9/three_remaining_decorrelation_residual.md)，不重新认领恒等式。新增限制是：即使查询为**均匀、最优、六槽**，真实后继 IC 的正信用仍可能不足以吸收返还负项。

六个互不相同的原主题构成另一个最优六元组 (0,1,2,3,4,5)，其 Δ=0，而返还仍为 −2/3，恰由 I=5/12、J=1/4 支付。因此本例保留了“重选一个最优六元组”的可能性。全部四个最优三元组的 Δ 则均为 −5/18；三槽与六槽存在性不混用。
