## 定义级审计，不调用规范递推

`audit_padded_residual_dag.py` 只使用 Python 标准库，未导入 `customer_attraction` 的求解器、递推或验证器。审计把压缩重数展开为30个不同单位客户，并以 Fraction 重算全部收益。

证书 DAG 有5440节点，其中2437决策节点和3003终端节点。每节点记录此前主题计数与承诺续局终端计数 target；每决策节点另外记录指定行动与九个行动各自的孩子。

逐节点检查了：

1. counts 和 target 均为合法非负整数向量，target 总人数为六且逐坐标至少 counts。
2. 九个孩子全部存在，行动 a 的孩子 counts 恰为父 counts+e_a。
3. 指定行动孩子的 target 等于父 target；终端 counts=target。
4. 当前指定行动在父 target 中的真实收益，不小于任意行动在对应孩子 target 中的真实收益。
5. 全部节点从根可达；深度 d 的输入历史质量恰为9^d，故所有九叉有序历史均得到一个定义。

第3项从终端反向归纳，证明每节点 target 确为展开策略在该节点的实际续局终端计数。于是第4项是原模型所要求的真实一次偏离比较，而不是冻住未来行动的静态比较。第2与5项把策略展开到全部有序历史；同计数节点可以复用，但没有遗漏任何有序历史。全节点比较因此证明所有子博弈最优性。

共核验21933项精确行动比较，其中14160项严格、7773项平局；DAG 展开覆盖66430个有序决策历史和531441个终端历史。计数压缩只用于表达保存策略，证明通过有序历史到节点的确定展开而成立。
