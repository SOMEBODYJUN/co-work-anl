# 终端共同菜单切割的负载直方图条件分解

状态：任意人数和任意有限菜单族的精确表示/定价引理；不是半覆盖支付证明。
该引理说明本目录的727/728/737列定价为什么可覆盖完整直方图宇宙，也给出把
`round4_coupling` 的同目标族多菜单联合支持函数并入定价的方法。
原命题Q-CAG-HALF仍OPEN；五人模板最优点不是可补全SPE或真实OPT证书。

## 1. 任意q,m的对象

取同一完整历史依赖纯SPE中的有限个记录族f。每族记录q个真实末位决策历史；
客户x在族f的第i个历史有背景负载p_fi(x)∈{0,…,m−1}、实际末主题会员f_fi(x)。
所有族共享索引标签ℓ_i(x)（例如某最优比较主题的会员位）；允许标签取任意有限集合。
各族压缩直方图h_f记录足以恢复该族全部p、f和其自身合法查询菜单位的索引元组。
同一客户的各族只需在每个共同标签上有相同索引个数，除此之外不预设独立耦合。

定义族f的**负载签名**

    L_f(ℓ,c) = #{i : ℓ_i=ℓ, p_fi=c}.

它确定每标签中逆分母1/(c+1)的多重集、总和D_f，以及共同标签边缘个数。
定义实际源收益A_f(h_f)=Σ_i f_fi/(p_fi+1)；它仍由完整本族直方图决定。

考虑任意有限个切割r。每条切割有一个源族s(r)、一个目标族t(r)，以及目标同一索引
元组中的若干菜单位z_i^j、非负权α_j,β_j。令

    a_r = Σ_j [α_j+(q−1)β_j],
    B_r(h_t) = Σ_j β_j Σ_i z_i^j,
    v_ri = Σ_j (β_j−α_j) z_i^j.

真实末位最佳回复比较及标签内重排给出必要条件Σ_x U_r(x)≥0，其中

    U_r(h_s,h_t) = a_r A_s(h_s) + Φ_r(L_s,h_t),
    Φ_r(L,h) = −B_r(h) D(L)
                 + Σ_ℓ Σ_k d_{ℓ,(k)}(L) v_{r,ℓ,(k)}(h).

两列都按非降序排列。这里同一目标元组的全部菜单共享一个匹配；不能逐菜单分别最大化。
这是`round4_coupling`一般联合包络的原定义，本文新增的是条件化之后的全列定价分解。

## 2. 精确定价分解

令每族的有限允许直方图集合为H_f；固定外部客户位掩码、共同标签边缘和菜单交叠端点。
容许的直方图只需满足上述共同标签边缘，而不预先固定支持。任取族内线性分数g_f(h_f)
及非负切割乘子λ_r。其全宇宙最大分数为

    max_(h_f) [Σ_f g_f(h_f)+Σ_r λ_r U_r(h_s(r),h_t(r))].

它**恰好等于**

    max_(L_f) Σ_f max_(h∈H_f : signature(h)=L_f)
      [g_f(h) + (Σ_(r:s(r)=f) λ_r a_r) A_f(h)
        + Σ_(r:t(r)=f) λ_r Φ_r(L_s(r),h)].                 (★)

外层只枚举可由本族某直方图实现的签名，并检查共同标签边缘一致。
空条件纤维舍弃。若固定外部掩码还带有只依赖共同边缘的项，可在外层直接加回。

证明：按所有L_f分割原来的有限笛卡尔积。固定这些签名后，每条U_r的源依赖仅剩
A_s(h_s)，而全部非线性重排代价Φ_r已经是单个目标族h_t的函数。因此目标严格分成
各h_f的函数之和，且各条件纤维独立，最大值之和等于和的最大值。最后取所有签名最大值。
该证明没有交换max/min、没有假设真实跨族会员独立，也没有损失直方图类型。
它精确优化的是所写边缘包络松弛，而非完整SPE实现集合。每条r内部多菜单共享匹配，
不同r的支持函数已经各自最大化；(★)不强迫所有r共同使用一个全局匹配。

每标签有n_ℓ个索引、背景负载有m种可能时，签名数最多
Π_ℓ binom(n_ℓ+m−1,m−1)。这是有限精确算法，不声称对m或q多项式。
五人AB/AE末位背景为p_fixed+t+x，因此标签t内只有两个负载；签名仅需h_t=#{x=1,t}。
固定共同d时只有(d+1)(6−d)个条件，最大12。这解释本目录完整定价的低维条件枚举。

## 3. 与更强共同客户运输的边界

(★)直接容纳同一目标族的任意多个菜单及任意非负D/O联合权，包括OO、DD、DO和不等权。
同时加入多个源族时，只需枚举各源负载签名；737行程序实现了两个源的特例。

如果同一联合切割把**不同目标族**的菜单放进一个共同匹配，目标分数的联合直方图
不再由各自h_t确定；(★)不能把它们拆开。需要保存这些目标族的共同元组，或者处理
多边缘运输。即使(★)包含全部现有末位包络，它也不包含早期偏离后全部真实续局的
可信最优性，所以没有给出一般half结论。

## 4. 本轮精确机制边界

717行模板已精确最优于2.042123288694711；新增10条AB源跨族末位单菜单包络后，
727行模板精确最优仍为2.0421101417004013。两个值均有正有理原始与全宇宙整数对偶证书。
727原始点又被一个**真正联合**OO行分离：AB源查询second族的V,W；两条单O行均严格正，

独立内部攻击：`round5_coupling`研究员按全源L分割重证(★)，检查同族/多源循环情况，
未发现数学异议；这不是外审或一般half证明。

## 5. 真实末两人轨道行与混合联合支持的统一扩展

该分解不依赖逆分母重排的特殊形状。一般地，若一条必要包络可写成

    U_r(h_s,h_t) = G_r(h_s) + Φ_r(T_s,h_t),

其中T_s是源直方图的某个有限签名，则把(★)中的源项换成Σλ_r G_r即可；同一证明成立。

对任意q、任意m，保留交叠的末两人查询轨道行恰有这一形状。源i的两人背景为p_i，
源实际动作A_i,B_i，客户贡献H_i只依本源元组。固定目标同族的两菜单位z_i,w_i，
以及总数B=Σz、C=Σw、K=Σzw后，每种(i,j,k)相等模式的行均是

    n_orbit Σ_i H_i + Σ_i C_orbit(p_i,z_i,w_i; B,C,K).

n_orbit只依q和相等模式。`round4_coupling`已逐模式推导C；这里不改它的SPE证明。
对源与目标作标签保持匹配时，第一项不变，第二项是成本矩阵只依背景p和目标元组
(z,w)的运输最大值。因此T_s可取按共同标签和**两人背景负载**的计数直方图。
同source/target的多对查询、多种轨道先作任意非负组合再统一最大化，也仍为此形式。

更强的统一接口是：将同source/target的末位D/O比较与末两人轨道比较放入**同一次匹配**。
此时不能只保存两种负载各自的边缘直方图。应保存源的联合向量签名

    T_s(ℓ,c_two,c_last) = #{i : label_i=ℓ, p_two,i=c_two, p_last,i=c_last}.

混合查询成本同一槽同时依赖两个背景，边缘直方图不能决定它们的相关；联合向量签名
才决定完整源成本类型的多重集。固定T_s后，整个联合运输支持函数只依赖目标族h_t，
源实际A/H项仍是本族函数；由一般分解式得到全宇宙精确定价。若记录更多真实层，
将该层用到的背景负载都放进同一个联合向量即可。条件纤维要求该联合向量确实由本族
直方图实现，而不是任意拼接各边缘。

这给出了统一实现边界：同一source/target的terminal+pair共同匹配无需截断原子支持，
而可由联合源负载签名条件化后按族定价。跨多个目标族共同菜单的联合元组仍未保存，
需要更强多边缘运输；可信的更早玩家比较也没有由该表示自动产生。一般half仍OPEN。

这项扩展经`round5_coupling`独立攻击；对方指出混合联合支持必须使用联合负载向量，
一般不能只固定两种边缘负载分布。此处已按该真实异议修正；但同一实际末两人
分支的相邻背景有特殊唯一恢复性质，见下一节。单独逐row支持函数的分解
仍可只保存相应各边缘；两种模型的匹配量词在此明确区分。

## 6. 相邻两阶段的联合负载可由两个边缘唯一恢复

上一节的一般警告对于任意两个背景成立，但同一真实末两人分支有额外结构：

    p_last,i = p_two,i + a_i,  a_i∈{0,1}.

因此在每个共同标签内，两个边缘负载直方图**已经唯一确定其联合向量签名**。
写a_c=#{p_two=c}、b_c=#{p_last=c}，以及
x_c=#{p_two=c,p_last=c+1}；取x_−1=0。则

    x_c = a_c + x_(c−1) − b_c,
    J(c,c+1)=x_c,  J(c,c)=a_c−x_c.                       (†)

证明：p_last=c的客户恰来自(p_two=c,不增载)与(p_two=c−1,增载)，所以
b_c=a_c−x_c+x_(c−1)。从c=0递推给出唯一x；其余联合格子均为零。
给定有限边缘可用(†)并检查0≤x_c≤a_c及最顶层尾部计数来判断兼容。
真实分支保证这些条件；条件定价时则应显式检查，不把不兼容边缘混入。

故本题同一真实末两人菜单的terminal+pair共同运输可以只枚举两种负载边缘，
再按(†)恢复联合成本类型。仍不可把它们作为两个独立matching分别优化；恢复后
应对同一联合向量成本矩阵作一次支持函数最大化。多层或任意多个背景没有由此
自动唯一恢复；向量签名仍是通用正确接口。

(†)由`round5_coupling`研究员发现并提示，本文独立逐格重证。它减少统一终端/末两人
支持函数闭包的状态空间，不给出福利不等式或半覆盖结论。

另一名`round5_independent`研究员独立重构§1–3，检查self-loop与多源有向环、上包络方向，
未发现致命异议；并给出跨不同目标族共同匹配不由其边缘决定的q=2最小例。
