# 六标签固定策略的客户边界与分离逼近

原来源已证明固定策略、固定比较的真客户层值为 \(33/23\)，并给出通过添加一份22客户种子来区分全部标签的扰动论证。本页把保存的有理点清分母、逐项写出单位客户整数族，进一步明确该族的真实 \(\operatorname{OPT}_3\)。这是原证书与原扰动机制的显式展开，不是另一份浮点搜索或新一般效率定理。

**模型身份必须保留。** 原七层优化使用六个可区分标签的闭锥，允许相同覆盖标签；边界点确有0、3两标签覆盖相同。若采用[集合目录定义](../定义/共同目录完整历史模型--定义.md)中的 \(\mathcal S\subseteq2^N\)，不能把该边界点直接称为“六个不同覆盖主题”的实例，更不能无证明地合并两个标签后保留同一历史策略。下面 \(N\ge1\) 的整数族六个覆盖集互异，因此同时满足集合目录和允许重复标签的更宽表述。全部重复选择、离轨历史及平局在两种表述下都保留。

## 1. 固定完整策略

三人共同目录标签为 \(\{0,1,2,3,4,5\}\)，分成 \(X=\{0,1,2\}\)、\(Y=\{3,4,5\}\)。

根选0；第二位在首标签属于 \(X\) 时选3，否则选0；末位在第二个标签所属组三个标签中，选前两位尚未使用的最小标签。任意两步有序历史至多用掉该组三个标签中的两个，所以末位在全部历史都有合法动作。

该规则定义全部43个决策节点，根路径为
\[
(0,3,4).
\tag{1}
\]
[原独立校验器](../../tools/evidence/common-shapley-coupling/original/verify_coupling.py)已在本批实际运行，为下面有理客户点与22客户种子分别检查全部258条原策略完成激励，包括43条自比较和全部215条真正偏离。所得非严格不等式保留平局；本页不规定原模型只能使用这一平局选择器，只证明这是一份完整纯SPE。

## 2. 清分母的198单位边界点

原真客户层保存的11个非零类型质量分母最小公倍数为138。将全部质量乘138，得到下表 \(w^{(0)}\)；其中整数重数表示相互不同的单位客户，未引入加权客户或非单位提供者。

| 兴趣类型mask | 喜欢的标签 | \(w^{(0)}\) |
|---:|---|---:|
| 2 | \(\{1\}\) | 23 |
| 4 | \(\{2\}\) | 28 |
| 11 | \(\{0,1,3\}\) | 15 |
| 16 | \(\{4\}\) | 23 |
| 25 | \(\{0,3,4\}\) | 15 |
| 34 | \(\{1,5\}\) | 7 |
| 36 | \(\{2,5\}\) | 2 |
| 43 | \(\{0,1,3,5\}\) | 21 |
| 45 | \(\{0,2,3,5\}\) | 36 |
| 48 | \(\{4,5\}\) | 7 |
| 57 | \(\{0,3,4,5\}\) | 21 |

未列类型人数为零，总人数198。每条固定策略激励对客户质量齐次线性，清分母不改变符号；所以原有理可行点的完整SPE证书直接变成这个单位客户点的完整证书。

实际路径 (1) 的三人收益为
\[
(u_1,u_2,u_3)=(48,48,42),\qquad W=138.
\]
比较集合 \(T=\{1,2,4\}\) 覆盖全部198客户，故该**特定实例**
\[
\operatorname{OPT}_3=198,\qquad
\frac{\operatorname{OPT}_3}{W}=\frac{33}{23}.
\tag{2}
\]
这里把固定比较识别为真实最优有直接覆盖证明：没有任何比较能覆盖超过全部客户，\(T\) 已覆盖全部。它不是从“固定比较层的最优值”自动推断而来。

所有正重数类型都同时含0、3或同时不含它们，所以0与3覆盖完全相同；原验证器还逐对核准这是唯一相同覆盖标签对。边界的这个性质必须保留，不能删标签而不检查由此丢失的有序历史信息。

## 3. 同策略的22单位区分种子

复用已经共享的 [root_stationary_kernel.json](../../tools/evidence/stationary-pair-transport/examples/customer_attraction/root_stationary_kernel.json)。该种子 \(w^{(1)}\) 包括六个单标签类型，重数依标签0至5为
\[
(1,3,1,1,3,1),
\]
以及类型 \(\{0,1,2,3,5\}\)、\(\{0,2,3,4,5\}\) 各6名客户。总人数22。每个标签均有至少一名私有客户，所以六个覆盖集两两不同。

原校验器已实际检查：同一份43节点策略在这个种子上满足全部258条激励，并核六标签全部15对覆盖不同。其根路径收益与两个覆盖数为
\[
(u_1,u_2,u_3)=(6,6,5),\quad W=17,\quad C(T)=19.
\tag{3}
\]
这里的19只用于构造与最优性比较，不需把该种子的每个最优集合或所有SPE再作重复枚举。

## 4. 六个覆盖互异的显式整数族

对任意整数 \(N\ge1\)，取不相交客户副本并按兴趣类型相加：
\[
w^{(N)}=Nw^{(0)}+w^{(1)}.
\tag{4}
\]
其16个正重数类型完整列为：

| mask | 喜欢的标签 | 单位客户重数 |
|---:|---|---:|
| 1 | \(\{0\}\) | 1 |
| 2 | \(\{1\}\) | \(23N+3\) |
| 4 | \(\{2\}\) | \(28N+1\) |
| 8 | \(\{3\}\) | 1 |
| 11 | \(\{0,1,3\}\) | \(15N\) |
| 16 | \(\{4\}\) | \(23N+3\) |
| 25 | \(\{0,3,4\}\) | \(15N\) |
| 32 | \(\{5\}\) | 1 |
| 34 | \(\{1,5\}\) | \(7N\) |
| 36 | \(\{2,5\}\) | \(2N\) |
| 43 | \(\{0,1,3,5\}\) | \(21N\) |
| 45 | \(\{0,2,3,5\}\) | \(36N\) |
| 47 | \(\{0,1,2,3,5\}\) | 6 |
| 48 | \(\{4,5\}\) | \(7N\) |
| 57 | \(\{0,3,4,5\}\) | \(21N\) |
| 61 | \(\{0,2,3,4,5\}\) | 6 |

客户总数为 \(198N+22\)。任意一条真实有序历史激励的松弛是边界点松弛的 \(N\) 倍加种子松弛，二者均非负，所以同一策略对**每个** \(N\ge1\) 都是完整纯SPE。此论证保留原目录和全部有序历史，而不是只证明实际根路径均衡。

六个单标签类型仍均为正，因此六覆盖互异。根收益和福利按客户线性相加：
\[
\boxed{
(u_1,u_2,u_3)=(48N+6,48N+6,42N+5),\qquad
W=138N+17.
}
\tag{5}
\]
固定比较 \(T\) 覆盖 \(198N+19\)。

## 5. 全族真实最优覆盖与逼近值

任意至多三个标签的支持 \(S\ne T\)，至少缺少 \(T\) 的一个标签。在边界点副本中，这分别遗漏标签1、2或4的私有客户，损失至少 \(23N\)；边界点的 \(T\) 原已覆盖全部客户，没有其他客户可补偿该损失。

种子总共22人，\(T\) 覆盖19人，所以改成任何 \(S\) 从种子部分最多增加3人。故
\[
C_{w^{(N)}}(S)-C_{w^{(N)}}(T)\le-23N+3<0
\quad(N\ge1).
\]
因此 \(T\) 是唯一最优无序支持；三个标签的六种排列同样达到最优，重复标签的三元组不达到它。得到
\[
\boxed{
\operatorname{OPT}_3=198N+19,\qquad
\frac{\operatorname{OPT}_3}{W}
=\frac{198N+19}{138N+17}
=\frac{33}{23}-\frac{124}{23(138N+17)}.
}
\tag{6}
\]
\(N\to\infty\) 时，从下方趋近 \(33/23\)。例如 \(N=1\) 为220个单位客户，实际收益 \((54,54,47)\)，\(W=155\)、\(\operatorname{OPT}_3=217\)，比值恰 \(7/5\)。

原真客户层的对偶对同一固定策略和固定 \(T\) 给上界 \(33/23\)，而这个六覆盖互异族逼近它。因此给目录加“六覆盖互异”的额外要求后，该固定目标的上确界仍为 \(33/23\)。本文没有证明这个额外子类的上确界不被某个别的点达到，也没有把它改称所有完整策略或所有比较集合的统一最坏值。

全部这些实例均满足三人半覆盖，既不是六人反例，也不是原三人半覆盖反例。其用途是把闭锥边界、单位客户清分母、标签可区分性和真实最优覆盖逐项对齐。

## 6. 复现与本轮新增计算的范围

原七层精确验证记录在[计算对象](../计算/固定完整策略的七层共同客户证书--计算.md)。本轮另提供 [derive_unit_family.py](../../tools/evidence/common-shapley-coupling/derive_unit_family.py) 与[结果](../../tools/evidence/common-shapley-coupling/replay/derived-unit-family-and-pair-gap.json)，其工作仅是：

* 验原有理点和22客户输入的SHA，取138清分母并对账全部整数重数。
* 核明文策略规则与原43个动作完全相同，计算根收益、比较覆盖和类型表。
* 对边界点、种子及 \(N=1\) 的42个至多三标签支持作小型算术对账。
* 提取旧 \(15/7\) 点缺失二主题等式的 \(2/21\) 余量，供[障碍正文](../障碍/同支持守恒与局部客户耦合的严格间隔--障碍.md)使用。

该补充没有重跑优化器、没有再枚举完整树激励，也不是新增原始独立审查。全 \(N\) 的SPE和最优覆盖由上述线性叠加与私有客户损失证明承担；原策略的两个基点完整激励已由实际运行的原验证器承担。原22客户来源复用既有资产，不重复计入本批五源done。
