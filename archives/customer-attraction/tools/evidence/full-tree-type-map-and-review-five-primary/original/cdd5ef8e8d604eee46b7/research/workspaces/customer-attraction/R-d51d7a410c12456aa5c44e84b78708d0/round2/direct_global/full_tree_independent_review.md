# 全树映射行锥障碍：独立审查

2026-10-21。审查对象为同轮 `../full_tree/type_map_and_mapped_circulations.md`。本审查不提升一般 Q-CAG-HALF；该目标仍 OPEN。

## 先重建、后读证明

本审查首先只读取 `extra_lineality_exact.json` 中的客户重数、人数、主题数和完整策略。尚未读取作者证明或作者审计时，用本目录 `audit_extra_lineality.py` 独立重建以下对象：每个有序历史的真实终局、均分收益型向量、全部真实偏离行、精确 Gaussian 秩以及按双向可达性定义的 SCC。不调用规范 solver、作者矩阵生成器、LP 或作者审计。

结果见 `extra_lineality_independent_audit.json`：40 个有序决策历史、120 个行动比较（含 40 条自行动零行）全部满足 SPE；50 条零 slack 行的型向量张成空间秩为 2。给定的三条真实行逐坐标恰为

```
r = (0, 1,    1/3, -1,   -1/3, 0, 0),
s = (0,-1/2, -1/3,  1/2,  1/3, 0, 0),
t = (0,-1,   -1/4,  1,    1/4, 0, 0).
```

有精确恒等式 `r+(2/5)s+(4/5)t=0`，三行的秩为 2。正关系对每行分别解出其负向，故它们张成的二维空间包含于行锥的 lineality。反向，任何 lineality 向量的正、负两份非负表示与可行客户向量点积后，所用全部行都必须是零 slack 行；所以 lineality 包含于这 50 行的二维张成空间。上下界相等，完整 lineality 秩恰为 2。该上界事实上只需要可行客户向量，毋须严格正重数；本例严格正，因此没有退化客户支持的额外疑义。

收益图有 30 个顶点、29 个 SCC，唯一非平凡 SCC 为 `B@(1,2,1)` 与 `C@(1,1,2)`；其所有内部边的型像空间秩为 1。审计程序把图边定向为“选定→偏离”，作者定义是反向；整体反向不改变 SCC 或 SCC 内行的张成空间，故不影响结论。r 的两端不在同一 SCC，却有非负真实反向证书。由此作者指出的“仅商掉抽象 SCC 像不能保证剩余行锥 pointed”障碍成立。

实际终局计数 `(1,1,2)`，覆盖为 24。逐份收益为 `B:91/12, A:25/4, C:61/12, C:61/12`，与作者表述一致。三主题可由四人全部覆盖，所以福利已最优；这不是一般半覆盖的反例。

## 通用代数部分的文字审查

随后读取全文。未发现承重异议：

1. 全收益型空间等于无常数项、次数至多 `min(m,p)` 的 Boolean 多线性空间。正整数占用支撑 T 的最高单项式系数由作者积分恒符号、非零；按支撑大小三角消元成立。所有收益顶点在全主题类型上的值恒为 `1/m`，所以其差的张成空间就是该线性泛函的核。后一句也可直接用仿射跨度的线性代数证明，无需再次三角消元。
2. 顶点数 `p*binom(m+p-2,p-1)`、映射秩与核维数计算正确。核向量总质量为零来自全主题类型评价。覆盖函数对至多 m 个主题的支撑作容斥，因此也位于同一截断空间；可行交集矩仍受非负类型质量约束，正文没有错误放松该条件。
3. `lin(A R_+)=span{A_e: e 被某个非负 At=0 支持}` 的两向证明正确。有限条边的见证可以相加，形成同时支持全部可逆行的非负映射环流。映射环流只要求抽象净流量落在 `ker L`，确实弱于图环流净流量为零。
4. `m=1`、`p=1` 时秩公式分别给出 D=p、D=1，收益差维数 D−1；空主题与零客户只改变可行质量，不破坏通用代数。重复行动计数明确保留。

审查结论：上述有限完整 SPE 障碍及其承重的通用线性代数自洽，独立定义级精确核验通过。没有一般福利预算或外审/新颖性结论由此产生。

一般直接目标仍须保留实际仅覆盖客户的 slack：对最优覆盖 O，记 `H=|O\C|, G=|C\O|`，则 `OPT−W=H−G`，真正要证的是 `H<=W+G`，不能删去 G。全树结果提示任何跨真实分支付款若先仅按抽象 SCC 压缩，会遗漏可逆方向；合法付款须允许完整型映射后的正环流，而不只允许图环流。
