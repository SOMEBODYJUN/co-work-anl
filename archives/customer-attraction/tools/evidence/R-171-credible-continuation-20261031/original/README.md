# 可信低根种子的接续边界

本目录接续 Q-CAG-HALF 的原模型：有限单位客户、有限非空共同目录、
任意人数、全部有序历史上的纯 SPE 与任意离轨平局。**没有新增一般证明、
主目标反例或承重辅助结论。**

`low_root_discovery.py` 是有限候选生成程序。起点是旧三人 23 客户收益不平衡例
加两个各含 10 客户的独立主题；五人、七主题，目标计数
`(1,1,1,0,0,1,1)`，可实现根收益 5，`W=OPT=43`。这是接续时已知的种子，
不是本轮新结果，也不声称一般独立 padding 定理。

程序从真实全集 SPE 终局菜单抽取完整有序策略，再固定该策略优化非负整数客户
重数。附加 `u_1/W <= 5/43` 保留低根性质。浮点 LP 只提候选；接受的重数均
须有理恢复并满足全部真实比较行；新纪录另经规范证书及独立 Fraction 全历史
检查。相同计数历史没有被强迫使用同一续局。

默认种子 `319221`、八棵完整策略、每棵全部 21 个五主题比较组合的接续尝试，
接受 168 个精确原始点，仍仅得到 `OPT/W=1`。这是这八棵固定策略与指定
低根约束的有限边界；没有精确最优对偶、全策略枚举或普遍数学结论。
