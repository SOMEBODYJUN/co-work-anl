# 四复制阈值精确回放

数学与限制见[计算对象](../../../state/计算/四复制根阈值的有理证书回放与发现器守卫--计算.md)。

`source-manifest.json`区分4个主源及3个只作比较的原依赖；`original/`保持全部源字节。主报告的两个路径同SHA，仍各自保全。`replay.py`先排除强制倒二者PAIR行，再调用实读过的原标准库核验器；`replay.json`为本轮65536型实际输出，逐字段等于两份冻结报告。

运行 `python3 replay.py` 只用标准库。它不重新发现/恢复系数，不运行浮点优化，不证明浮点目标最优。复用原核验器不称独立新实现。
