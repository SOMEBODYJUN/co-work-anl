# 改进近饱和交换：任意实际玩家版本

状态：2026-10-21 解析候选，版本 v2。本文件扩大此前
`penultimate_floor_exchange.md` 的 root-v1 **陈述范围**，没有静默改写旧版本。
root 已独立重构旧版核心证明并报告未发现致命异议；本文件把任意实际玩家、
包含固定过去和当前人为倒数第二/最后一位的边界单独写全。没有外审或新颖性认证。
Q-CAG-HALF 一般目标仍 OPEN。

## 精确命题

采用 CAG-MODEL，m>=3，K=max_(T in S)|T|。固定任意完整有序历史纯 SPE
及其实际终局收益 u_1,...,u_m。对任意实际玩家 i、任意最大主题 C、任意合法主题 D，
令 E_i=m u_i−K，则 E_i>=0，且

    m|D\C|+|D intersect C| <= K+c_m E_i,       (A)

其中

    H=3m^2−7m+2>0,
    c_m=1+m(m−1)/2+m(m−3)(m−1)^2/H
       =(m−1)^2−m^2(m−3)^2/(2H).

于是对任意 i，

    OPT_m <= (2−1/m)K+c_m E_i.               (B)

取实际收益最小者，有 m min_i u_i<=W、W>=K，故

    OPT_m <= (2−1/m)K+c_m(W−K).              (C)

c_3=4、c_4=95/11、c_5=311/21；m>=4 时严格小于旧 (m−1)^2。
(C) 是一般但较弱的上界，绝不等于证明 OPT<=2W。m=1 直接最优；m=2 沿既有
两人定理处理，本命题不将 m=2 的旧末位边界混进来。

## i<=m−1：保留原固定过去的真实 C 分支

在玩家 i 的**实际有序历史**改选 C，然后依照同一完整策略继续。前 i−1 个
动作保留实际过去，未来动作可以全部改变。令当前偏离者在这个完整终局的收益为
v<=u_i，e=m v−K>=0。客户负载为 q_x。记该分支真正倒数第二、最后主题为 P,L，
各自收益为 p,t，并定义

    d=sum_(x in C)(m−q_x),
    d_P=|C\P|, d_L=|C\L|, r=|L\C|,
    a=(m−2)/(m−1), beta=(m+1)/(2(m−1)).

因为当前玩家确实选择 C，所以每个 C 客户有 1<=q_x<=m。逐客户差值给

    d<=(m−1)e.                               (1)

每个其他实际/离轨主题大小至多 K，故其 C 外客户数不超过遗漏 C 的客户数。
特别 r<=d_L。令 z_x 为**真正倒数第二节点之前**所有动作在客户 x 上的负载。
直接把各动作的 C 外关联数相加，得到

    sum_(x outside C) z_x <= d−d_P−d_L.       (2)

这里无需声称前缀有恰 m−3 个非 C 动作。若 i<P，前缀包括当前的 C 动作，但它
在 C 外贡献零、遗漏 C 的缺额也为零；若 i=P，则 P=C、d_P=0，前缀有 m−2
个已固定动作，(2) 仍成立。其他已固定过去也参与相同缺额预算。

当前偏离者和 P 在 P intersect C 的客户份额相同，P\C 每项至多 1，C\P
每项至少 1/(m−1)，所以

    p−v <= a d_P.                            (3)

i=P 时此式就是 p=v、d_P=0，不能把当前人误当成另一个未来人，但比较本身有效。

在这个真实倒数第二节点，偏离 L 的任何真实后续收益都至少
sum_(x in L)1/(z_x+2)。L intersect C 每项至少 1/m；L\C 使用整数不等式
1/(z+2)>=1/2−z/6，再用(2)，得到

    p >= (K−d_L)/m+r/2−(d−d_P−d_L)/6.

结合(3)、v=K/m+e/m、d_P<=d−d_L，推出

    r <= 2e/m+2a d−2(a−1/m)d_L.              (4)

终局 L 与当前 C 玩家的重叠项相消，给 t−v<=r−d_L/(m−1)。在同一真实末位
历史改选 D，对 D intersect C 的每个客户至少得 1/m，对 D\C 用
1/(z+1)>=1−z/2；末位之前 C 外总关联数至多 d−d_L。于是

    [m|D\C|+|D intersect C|]/m
       <= v+d/2+r−beta d_L.                 (5)

对 r 同时使用 r<=d_L 和(4)，两条直线的交点界给

    r−beta d_L
       <= (m−3)e/H + m(m−2)(m−3)d/[(m−1)H].

m=3 时第一条直线斜率 1−beta=0，右端为零，同样有效。再用(1)，完整得到
Q<=K+c_m e<=K+c_m E_i，即(A)。这只用给定完整策略的真实分支，不要求固定
过去在离轨分支上重新最优，也不要求同负载历史同回复。

## i=m：当前就是最后一位，另作直接证明

在真实末位前缀后令当前假想改选 C，当前收益 v<=u_m。对该“原过去+C”终局
定义 d=sum_C(m−q_x)，仍有 d<=(m−1)(m v−K)<=(m−1)E_m。原过去的 C 外
总关联数至多 d。真实末位最优性相对任何合法 D，直接给

    u_m >= |D intersect C|/m+|D\C|−d/2.

因此

    Q<=m u_m+(m/2)d
      <=K+[1+m(m−1)/2]E_m
      <=K+c_m E_m.

没有把假想末主题 C 冒称为原策略真实回复。最后一步来自 m>=3 时
c_m−[1+m(m−1)/2]=m(m−3)(m−1)^2/H>=0。所有 E_i>=0 来自任意玩家改选最大
C 后的 K/m 最坏负载保底。

## 从(A)到(B)(C)以及剩余承重义务

固定任意 m 个最优主题 D_j，允许重复。将(A)求和，最优并集在 C 外的每个客户
至少得到 m 的总权重，在 C 内至少得到 1；先不重计地计一次，再用最优并集在
C 内覆盖至多 K，给(B)。选 min_i u_i 得(C)。这些步骤允许空主题和零客户，
没有除以 K、W 或 E_i。

本版本没有消除跨分支误差支付。`exact_strengthened_projection.py/.json` 给
五人合法非负客户型及实际动作序列，满足旧全部实际节点 AP、所有加权最大主题
的 BNS-C，并同时满足本(A)对每个 i、每个未加权最大 C、每个 D 的全部必要行，
仍有比较并集>2W。它没有完整策略，**不是 SPE 反例**。这说明单靠汇总这些
加强后的行仍不能支付一般误差，必须加入尚未表示的中间玩家真实可信性或换全局机制。
