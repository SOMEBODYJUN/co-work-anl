# 本轮策略几何草稿（2026-10-24）

对象：任意有限共同目录、任意 m、单位客户、全部有序历史纯 SPE；Q-CAG-HALF 仍 OPEN。

## 当前承重问题

对任意完整形式策略 σ、根覆盖行 c 和任意 m 元比较覆盖行 o，构造全树真实 IC 行 Γ 的非负乘子 λ，使 `2c-o-Γ^T λ>=0` 逐兴趣类型成立。旧 span 定理不给乘子非负性。本轮尚无全输入构造。

## 已停止的匹配桥试探

曾试候选：对每个给定最优元组 T 及其并集 C，设实际并集 U、E=|U\C|，是否可排列 π 使冻结实际其他行动的静态偏离和 `Dπ<=W+E`。因 `Dπ>=|C\U|`，若成立足以推出 half；但强式为假。

四单位客户 x,y,b,c，四个两两不同主题 `A={x,y}`、`B={b,c}`、`T={x,y,c}`、`D={x,y,b}`。两人完整策略根 A，第二人 `A→B,B→D,T→D,D→T`。末位指定收益依次为 2,2,2,2；根四行动的真实收益依次为 2,3/2,2,2。因此是完整 SPE。实际 W=4，OPT=4，选比较元组 (T,D) 时 C=U，E=0。其两种静态偏离匹配均为 `5/2+2=9/2>4`。

这只否定“每个给定最优元组”的候选；A,B 也是最优，因此没有否定“存在某个最优元组”的弱版，更不是 half 反例。机制与既有非 PNE 反例近同，只留此简短边界，不另立成果。

`matching_probe.py` 是该明确一般候选的按需攻击器，使用保存的完整全树策略锥与比较元组最优性约束，浮点只生成候选。它不证明一般正面关系。350 个旧 m4p5 锥/元组无正点后，旧两人残余策略锥立即给出可有理化的上述点；有限无反例没有意义提升。
