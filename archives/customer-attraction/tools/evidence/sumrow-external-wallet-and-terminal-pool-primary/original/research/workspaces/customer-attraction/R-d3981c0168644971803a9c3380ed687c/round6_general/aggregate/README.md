# 第六轮真实查询总支付：当前精确边界

2026-10-25。研究对象始终是一般 Q-CAG-HALF：任意人数、有限共同目录、单位客户、单位玩家、每个完整有序历史的纯 SPE。主目标仍 OPEN。本目录为个人未闭合工作备份，不是一般福利定理；没有固定人数扫描、没有新主目标反例、没有外审或新颖性认证。

- [SUMROW 接续与单份外部钱包](sumrow_and_one_external_wallet.md)：从既有真实最优查询账本接续，证明删去任意客户子集后的一份路径联合 regret 合同，并给出真正能把互斥分支预算压回实际 W 的占用流恒等式。前者不把限制策略变成 SPE，后者支付社会覆盖差而非当前玩家的分享差。两者之间没有已证转换，故没有闭合 SUMROW 或 MG。
- [推导尝试和停止点](attempts_and_boundary.md)：记录已当场丢弃的最大主题强化、分支拼合缺口、MG 与较强遗漏门槛的区别，以及同一一般义务的 m=5 代入。没有把失败助手当作一般目标的反例。

本轮实质判断：没有得到新的足以闭合一般 half 的跨枝共用付款。下一步若继续，须提供一个真正作用于全部后继 IC 的变换，把当前收益分享差变成同一占用流上的社会差，或另造不经该接口的通用机制。重写 Q/L 账本、扩大旧策略锥阴性检验、或继续增加只对更强助手的障碍，都不构成该步。
