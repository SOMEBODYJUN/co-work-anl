## 1. 先固定否定的强桥

给定 m 人完整历史纯 SPE，强制根选择 a 后沿同一策略的实际后继 m−1 个主题记为 B(a)。对查询分布 p 定义

`F_p(B)=sum_T p_T sum_(x in T) 1/(1+c_x(B))`。

一个可能过强的安全最优查询特化为

> 对每个安全最优 p*，至少有一个合法根行动 a，使 F_p*(B(a))=v_m。

下面对每个 m≥2 给原模型实例；存在一个显式安全最优 p*，对**每份**完整 SPE 和**每个**根行动 a，反有

`F_p*(B(a)) >= v_m + m/[4(m+1)] > v_m`.             (A)

因此不能把“p* 是静态安全最优”解释为“某个真实根尾列必须是其静态最坏背景”。更强地，真实尾菜单的混合 minmax 值

`M_tail=min_Q max_T E_Q f_(B(a))(T)`

也至少为式(A)右端，所以不存在仅用这些尾列、共同 cap 到 v_m 的静态对偶。

本页**不**否定“存在另一个安全最优 p* 有某条接触列”的量词，也不否定 cap 到根收益 u 的额外一槽 Mfull；Mfull 列包含根自身，本页尾列没有根。

## 2. 任意人数实例与精确安全值

令 k=m−1≥1，取

`C=k(k+1), h=k+2, P=k+3`。

两个不交 core X,Y 各 C 个单位客户。主题 B=X∪Y。每个 core 有 h 个叶主题，每叶由该 core 加其自己 P 个私有客户组成；所有私有块互不交。目录共2h+1个主题，客户总数2C+2hP；全部客户是不同的单位客户。

取 p* 为全部2h个叶的均匀分布，q0=B^k。静态安全值为

`v_m=C/(k+1)+P=2k+3`。                           (B)

这里重述匹配证书以使正文自足。面对 q0，每叶查询收益恰为(B)，B查询收益为2k，故 q0 是合法静态上界。

对任意 k 槽背景 q，令 b 为 B 槽数，r_i 为各叶计数，u,w 分别为 X、Y 组叶槽总数；t=u+w=k−b。则

`F_p*(q)=C/2 [1/(k−w+1)+1/(k−u+1)]`

`          +P/(2h) sum_i 1/(r_i+1)`。

对整数0≤z≤k，

`1/(k−z+1)−1/(k+1) >= z/[k(k+1)]`，

且每个整数r≥0满足 `r/(r+1)<=r/2`。因此

`F_p*(q)−F_p*(q0) >= t [C/(2k(k+1))−P/(4h)]`

`                      =t (k+1)/[4(k+2)]`。         (C)

故 p* 保证(B)，与 q0 上界匹配；q0 是 p* 的唯一最坏纯背景。若q≠q0，t≥1，式(C)给出(A)中的δ=(k+1)/[4(k+2)]。这个静态 δ 本身是精确的：q=B^(k−1)+任意一叶时取等。

## 3. 为什么全部真实根尾列排除 q0

固定任意完整纯 SPE 和任意强制根行动 a。假如后继尾部 B(a)=B^k，考察这条真实分支的最后玩家。

* 根 a=B 时，末位留 B 得 `2C/(k+1)=2k`；改一片任意叶得 `C/(k+1)+P=2k+3`。
* 根 a 是 X 叶时，末位留 B 得 `C/(k+1)+C/k=2k+1`；改一片 Y 叶得 `C/k+P=2k+4`。根为Y叶时对称。

两种情况下都有恰为3的严格改进。最后节点属于原完整策略，故违反其真实末位最佳回复。于是每个 B(a)≠q0，式(C)证明(A)。强制根本身可以非最优；只用了它之后仍为真实 SPE 子博弈这一事实，没有把不同分支的后继拼成一个静态策略。

这是任意深度完整策略中的一条必要排除，但(A)量化每份完整SPE的整个根菜单，不是假菜单里补几行末位约束。

## 4. 回收：本族所有深度实际玩家反而都获得 v_m

这里使用标准的 fresh-action/copy 向后归纳，不主张这个归纳原理的新颖性。固定任意有序历史，当前之前至多m−1个行动，而每组有 h=m+1 片叶，所以总有未用过的叶L。

假设所有较晚位置在全部有序历史后的真实SPE收益已至少为v_m。当前改选L：

1. 若以后无人复制L，它独享P名私有客户，core总负载最多m，因此最终收益至少 `P+C/m=v_m`。
2. 若以后有人复制L，该较晚玩家在这个真实离轨分支的收益至少为v_m；单位玩家选同一主题时最终收益完全相等，所以当前改选者也获得至少v_m。

最后一位对应第一种情况，建立归纳基。当前最优性再给其实际收益≥v_m。此归纳同时覆盖全部有序历史与任意平局，并允许前缀已经包含B或重复叶。

故每份完整SPE满足

`forall i: u_i>=v_m,  W>=m v_m`。                   (D)

精确最优覆盖是 `OPT_m=mP+2C=3m^2`：m个不同叶且两core各至少一叶达到；任何含B的组合减少一个私有块，不可能超过它。于是本族还由(D)给 `OPT_m/W<=3m/(2m+1)<3/2`。

这解释了为何不能把(A)的严格菜单余量计作“亏损”：真正根收益与未来利润有额外信用。它也说明本族不适合作为一般half坏构造的长期主线。
