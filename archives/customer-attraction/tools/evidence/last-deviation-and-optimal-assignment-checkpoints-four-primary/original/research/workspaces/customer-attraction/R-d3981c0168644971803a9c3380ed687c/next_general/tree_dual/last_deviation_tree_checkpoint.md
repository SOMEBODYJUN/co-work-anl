# 末偏离树与真正最优比较的交换信用：未闭合探索

2026-10-24。**身份：未完成研究 checkpoint，不是一般半覆盖证明，不是新的全局福利界。** 本文保存下一轮可直接检查的全树几何与尚未支付的项。没有以 Farkas 存在性或等价目标替代通用乘子构造。

## 1. 完整有序终局上的末偏离树

固定任意有限非空共同目录 S、m>=1 以及完整形式策略 sigma；此节的树结构甚至不先假定 sigma 是 SPE。每个有序终局 v=(v_1,...,v_m) 是独立顶点，即使若干顶点的主题计数相同也不合并。

令

    D(v)={i: v_i != sigma_i(v_<i)}.

唯一满足 D(v)=empty 的顶点是 sigma 的实际根终局 z。若 v!=z，令 k(v)=max D(v)，并定义

    parent(v)=finish(v_<k(v), sigma_k(v_<k(v))),

其中 finish 始终沿同一份原 sigma 补齐全部后继。因为 k(v) 是最后一次偏离，v 自身恰是该历史把当前动作强制为 v_k 后沿原 sigma 得到的终局。因此

    Gamma_v = u_k(parent(v)) - u_k(v)

正是一条真实节点 IC。反过来，每条非规定动作的节点 IC 唯一得到一个这样的 v，其最后偏离位置就是该节点角色。

由于 parent(v) 与 v 在 k 以前完全相同，而 parent 在 k 及以后全部沿 sigma，

    D(parent(v)) = D(v) minus {k(v)}.

所以全部非平凡 IC 构成以 z 为根的有向树（边从 parent 指向 child），共 |S|^m-1 条边。沿根到叶的边角色严格递增。对某个非根顶点 v，全部出边正好是在其规定后缀位置 j>k(v) 处强制非规定动作的真实比较；不应把角色 j<=k(v) 的其他历史比较虚构成该顶点的出边。

这没有规范化 sigma、没有把同负载历史合并，也没有改变任何离轨平局。SPE 只在树建立后用于 Gamma_v>=0。|S|=1 或 m=1、空主题、零客户和收益为零都无特殊除法问题。

## 2. 非负边乘子的真实入出账

给边 parent(v)->v 任意非负乘子 lambda_v。对终局 v 和角色 i 定义

    beta_(v,i) = sum_(w:parent(w)=v, k(w)=i) lambda_w
                 - 1_(v!=z, i=k(v)) lambda_v.

则严格按终局和角色重排有限和得到

    sum_(v!=z) lambda_v Gamma_v
       = sum_v sum_i beta_(v,i) u_i(v).

这只是把全部真实 IC 的现成非负组合写成树账，不宣称已经构造了付款乘子。它暴露了一个不能隐藏的缺口：非根顶点只有入边角色 k(v) 的负利润项，而正出边只能使用较晚角色。把该点的全部后继利润当作入边旧角色的同一份收入并不合法；客户部分交叠时，它们的收益支持可以不同。若扩展为多个来源 token，必须同时保留其它 token 的负载变化和角色总容量。

同一终局内的角色换位确有精确运输：若 w=swap_(ij)(v)，则 u_i(v)=u_j(w)、u_j(v)=u_i(w)，其他角色收益保持。这个等式不允许直接把 w 的 IC 当成 v 的原入边：任意历史依赖 sigma 下，交换后最后偏离位置可以改变，甚至被推到更晚。也不能把只追踪一个 token 时的等值交换误读为全部 token 总价值已经付清。

## 3. 改为真正最优比较可合法加入的交换行

令 T_1,...,T_m 是一个真正达到 OPT_m 的合法元组，C*=union_j T_j。允许重复、空主题以及冗余槽。设

    Q_j = T_j minus union_(ell!=j) T_ell,
    a_j = |Q_j|.

用任何合法 A 替换最优槽 j，不得增加覆盖。因此每个 A,j 均有明确非负行

    a_j - |A minus C*| - |A intersect Q_j| >= 0.       (EX)

证明只需注意 A\union_(ell!=j)T_ell 是不交并 (A\C*) union (A intersect Q_j)。这是一条对全部输入有效的最优性关系；若改为任意比较元组则不能使用。若某 a_j=0，EX 立即给每个合法 A 都包含于 C*，并非允许除以 a_j；全零输入直接处理。

在单位客户类型语言中，EX 是逐客户覆盖系数的非负线性行，故可以像真实 IC 一样被赋非负乘子。它可能支付 offpath 主题在 C* 外的收益支持，但目前没有给出与上面末偏离树同时成立的通用乘子。不能仅因 EX 新增了若干合法行，就声称原目标已缩小或已证明。

## 4. 本轮实际停点

记 actual 覆盖 C，I=|C intersect C*|、G=|C minus C*|、D=|C* minus C|。直接目标是

    D <= I+2G,

即 OPT_m<=2W。允许 G 作为真实已覆盖外部客户的付款；没有另要求每人、每题、每期或任意背景的强保底。

尚未构造非负 lambda_v、EX 乘子以及逐类型非负余项，使它们的总账确实等于上述缺口。尤其尚未证明：

1. 所有 offpath 出边正利润可由入边负利润及 EX 共同支付；
2. 从全部最优终局排列发出的同时 token 运输可到达 actual 角色，并使每个 actual 利润的总使用不超过两份。

这两点均是未付全局项，不是局部代数可以免费补回的余项。没有证据据此否定 Q-CAG-HALF，也没有把这些接口当作成熟一般组件。若后续未真正给出付款，应保留本身份而停止包装。
