# 冻结最优指派攻击：强桥已假，弱桥的准确未付式

2026-10-24。任意人数、任意有限共同目录、每份完整历史纯 SPE。没有新增一般 half 福利界，没有扩固定人数锥或增加阴性样本。下述旧证书均已实际读原文核对；本页不是其再发现或新颖性声明。

## 1. 两条已被旧完整 SPE 否定的合同

已读 [round7 FOMA 工作稿](../../../R-cd789330fc7141299ac491bbb3ffa420/round7/transport/frozen_optimal_assignment_working.md) 后，root 转来并已核对 [最优静态匹配反例](../../../R-a0bb57fa24044a8794bc7991918a19c6/static_matching/optimal_static_matching_counterexample.md)。该旧证书与 FOMA-EXISTS 完全同量词：m=4，W=47，OPT=52，唯一最优支持 {0,1,4,5}，所有24个匹配中最小冻结总额 K=48>47。因此 **FOMA-EXISTS 和 FOMA-ALL 均为 FALSE**，不能继续列 OPEN。

这个反例实际四人的收益都为 47/4。因此即使有保留低福利的等收益规范化，也不能用“等收益后强 FOMA 成立”来填这个缺口。

一个更便于忽略 bonus 的候选是：存在最优元组 T，使 full-actual 额外查询 base

    B(T;Z)=Σ_j Σ_(x∈T_j)1/(1+c_x(Z)) ≤ W。

它若真，可用均匀指派推出 K≤(1+1/m)W。但 root 随后指出并实际核对了 [71客户唯一最优遗漏反例](../../../R-d22a706a03c5499d941a6a97f94128a8/exchange/unique_optimum_omission_obstruction.md)：实际 A,B 不交，W=35；唯一最优 T,Q 不交，OPT=38；二者各有一个客户位于实际 B 内，其余36个均 actual-fresh。因此

    B(TQ;AB)=36+2/2=37>35。

其两种冻结指派都给 K=75/2。故这个 base≤W 合同也为 FALSE；不能删掉实际覆盖外部部分后仍用原 W 宣称已付款。此旧例不否定 K≤(1+1/m)W。

## 2. 一条只使用最优性的全输入交换关系

以下是覆盖最优性的直接交换行，不使用 SPE，也不认证新颖性。它可合法添加到真实历史 IC 旁，但尚未支付动态捕获。

固定任一最优 m 元组 T，O=∪_j T_j，定义它相对这个元组的独有块

    P_j=T_j \ ∪_(k≠j) T_k。

对每个合法目录行动 A、每个 j，用 A 替换第 j 个最优槽，最优性给

    |A\O| ≤ |P_j\A|,

等价地

    |A\O|+|A∩P_j| ≤ |P_j|。                         (OPT-EX)

证明：替换只删除 P_j\A，并且新添 A\O；若新增多于删除，就会严格超过 OPT。重复主题的 P_j 可以为空，空主题及零实例也均保留。

令实际终局为 Z=(S_i)，C=∪_iS_i。对任意置换 π，将 (OPT-EX) 用于 A=S_i、j=π(i) 并相加，得到

    Σ_i |S_i\O| + Σ_i |S_i∩P_π(i)| ≤ Σ_j |P_j|。       (OPT-MATCH)

由于每个实际在 O 外的客户至少被一次实际主题覆盖，进一步有

    |C\O| + max_π Σ_i |S_i∩P_π(i)| ≤ Σ_j |P_j|。       (OPT-OUT)

这给一个真实但仅静态的外部覆盖/最优独有块运输预算。尤其最优元组的独有客户总量至少为 |C\O|。它没有把 P_j 变成全目录私有块；任意未来行动仍可同时触及多个 P_j，所以不能据此调用已有全局私有席位归纳。OPT-EX 的系数为单位客户数；也不能擅自换成终局价格 1/(1+c_x)，因为原 T 没有被假定最大化加权覆盖。

尝试将 (OPT-EX) 作用于真实偏离尾中的捕获行动时，目前只得到：捕获行动在 O 外的客户越多，其在每个 P_j 内可覆盖的客户越少。若捕获行动完全包含于 O，右侧不提供额外损失；O 内的共享客户也没有出现在这些 P_j 行中。缺少的仍是由全部尾部 IC 将这类 O 内捕获共同付回原实际利润的关系。

## 3. 当前保留的弱目标及真正缺口

按旧文已经提出的弱化，仍可尝试

    存在最优 T，使 K(T;Z)≤(1+1/m)W。                 (WFOMA?)

本页没有证明、没有反驳这个弱化，也不把它认领为新候选。

固定一个最小冻结指派并重标为 T_i 对应角色 i。沿原 σ 的实际前缀强制 T_i，得到完整真实终局 Y^i。记真实当前收益 D_i，e_i=u_i−D_i≥0，冻结收益 F_i=u_i(T_i,Z_−i)，适应税 E_i=F_i−D_i。则原 IC 给的是 e_i≥0，弱桥实际需要另证

    Σ_i E_i ≤ Σ_i e_i + W/m。                         (UNPAID-W)

这不是已获的新预算；它是明确要购买的额外 W/m 信用。既有最小指派的交替环不等式只涉及实际客户交集，不能直接约束 actual-fresh 位置的真实后继捕获。第2节 OPT-EX 能补入覆盖最优性，但目前没有把捕获税的共享部分送入合法的负环或共同钱包。

若转直接覆盖净预算，则不必支付全部冻结成本。令 f_i(x)=c_x(Z)+1−1_(x∈S_i)，仅对 x∈T_i 使用，定义准确的静态退款

    R(T,Z,π)=|C\O|
      +Σ_(x∈O\C)(d_x−1)
      +Σ_(x∈O∩C) [d_x/(c_x+1)+t_x/(c_x(c_x+1))]。

其中 d_x 是最优元组内出现次数，t_x 是匹配后同时属于 S_i,T_i 的位置数。逐客户恒等式给

    OPT−2W = Σ_i(E_i−e_i)−R(T,Z,π)。

所以一个直接够用但尚未证明的支付是

    Σ_i E_i ≤ Σ_i e_i + R(T,Z,π)。                    (UNPAID-NET)

本式保留全部实际 C 外客户和覆盖交叠的准确退款，没有把 base 或 frozen 行误当真实偏离。也不能仅因 R 非负，就把 (UNPAID-NET) 当成已证。当前未找到把 OPT-EX、最小指派交替环与所有真实 off-history IC 共同组合为这条预算的乘子。

## 4. 停止线

本轮没有再生成固定人数数据。已经消除两个错误 OPEN 状态：强 FOMA、最优 full-actual base≤W。保留下来的实际义务只有 (UNPAID-W) 或更贴近原题的 (UNPAID-NET)；本页的静态交换行没有闭合它们。后续若继续，应提供这两式之一的真实共同付款，而不能再把 BONUS 展开、最优指派对偶或重新命名的完整树 BI 当成福利进展。
