# 聚合自由列：父方一般势余额与准确停点

2026-10-24。以下是对原 CAG-MODEL 全部输入成立的代数表示，**不是新资金不等式或half证明**。候选及其固定策略证书见 [AFC正文](../aggregate_security/aggregate_free_column_candidate.md)。

固定原完整SPE的实际路径B、利润u_i及W。对实际位置i强制A，执行同一原策略得到z_i(A)，仅删当前槽得到v_i(A)。固定查询分布p，并为每个位置任取与查询T独立的列混合q_i。记调和势Φ(z)=Σ_x H_(c_x(z))，以及

    Θ=Σ_i E_(A~q_i) G_p(v_i(A)),
    Γ_iA=u_i(B)−u_i(z_i(A))≥0。

边际势公式给当前偏离收益d_i(A)=Φ(z_i(A))−Φ(v_i(A))，而G_p(v)=E_TΦ(v+T)−Φ(v)。逐列相减，精确得到

    W−Θ = Σ_i E_A Γ_iA
           +Σ_i E_(A,T)[Φ(z_i(A))−Φ(v_i(A)+T)]。       (BALANCE)

每个q_i质量为1，因此实际利润求和正好为W；中间删槽势逐列消去，没有替换非根旧玩家收益。v_i(A)+T是静态m槽比较元组，**不声称是SPE端点**。最后跨势项无已证符号，也不能把Φ当作全体尾玩家联合最大化的目标。

若对每个p能选q_i使BALANCE右边非负，则AFC成立；只证明纯查询或固定一份策略的证书不足以得到这个全输入结论。有限minimax随后给一个m−1槽共同静态竞争分布，使所有查询收益≤W/m，进而W≥m v_m；已有静态界给OPT_m≤(2−1/m)W。m=5仅有依赖未证AFC的9W/5，不是无条件新界。

父方在 [独立审计](audit_free_column_certificate.py) 中从原36单位客户重建258条真实IC、全部菜单列、全查询有理原始/对偶，以及固定策略的80坐标12项零余项势证书。原始=对偶=164/5，W=34；最初讨论中口算(11,11,12)有误，旧坏查询正确三最小值为(11,19/2,12)。该修正不影响精确势证书。所有数字重算并反算核对，未据此提高一般候选状态。

同一审计还检查BALANCE在零客户、空主题、一人及旧例的精确等式。旧例采用有理最优p/q时，W−Θ=6/5、IC松弛64/15、跨势项−46/15；跨势项不能先丢弃。一般依据仍是上述解析恒等式，有限回归不是证明。

更强“任意匿名边际势也有AFC”现已被 [非CAG反例](../fresh_analytic/anonymous_potential_boundary.md) 否定，即使收益非负、各层势单调。父方未读稿独立重构并完成 [全历史审计](audit_anonymous_potential.py)。所以不能期待只用匿名精确势恒等式生成所有策略的非负证书；CAG的一般候选仍开放，必须额外使用递减客户份额、覆盖守恒或其他真实结构。
