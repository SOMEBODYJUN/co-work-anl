# 固定完整策略的两套精确价格证书

本目录对应[固定三人策略锥的全查询价格证书](../../../state/计算/固定三人策略锥的全查询价格证书--计算.md)，其一般代数合同见[固定策略有限合同](../../../state/等价/固定完整SPE策略锥的有限价格合同--等价.md)。

[PROVENANCE.json](PROVENANCE.json)列出三份本批来源、所指冻结实例及五份已在前批完整读取的运行依赖。每条有稳定来源ID、冻结提交、原路径、保全或相对引用路径、实际恢复路径、字节数和SHA256。所有均来自68fad804ec5946cb296f77dc5b336308a66abf12。

original/保留6400字节原证书器、两套25084／25680字节原JSON和615字节原实例。五份依赖直接引用相邻已保存资源，不制造另一个未说明的代码版本。

## 实际执行

[reproduce.py](reproduce.py)已运行一次，包含两个原verify各一次，以及两目标的直接有理残差重构。没有调用build、LP或SPE求解器搜索。

- 同一个21节点完整有序策略，63非自偏离，39个不同非零矩阵行。
- 两个实际占用标签×30个完整查询，每份60项有理证明。
- 两份共553条非零乘子、1800个逐坐标残差，全部残差非负；所有beta非正，最大0。
- tstar有18个beta为零，price_plus_u有8个，其余严格负。
- 两份内嵌实例与冻结615字节实例解码后完全相同，输入证书字节未改变。
- 点上福利15、OPT16、收益17/3和14/3；完整价格分别6和15/2。

[执行清单](replay/replay-manifest.json)记录两个原stdout、运行版本和时间，以及全部检查统计。两个独立duals文件另逐项保存完整矩阵、全部比较到行号的映射、每份900个残差以及源点根偏离表。

这些数学上证书量化同一策略的整个非负重数锥；它们不是一般策略证明。原verify的verified字段还须结合重新算出的all_bounds_nonpositive与maximum_beta读取，本批两项均核为true和0。说明性字段不替代实际计算。

## 复现

从仓库根选择不存在的新目录：

~~~sh
python3 -E -B archives/customer-attraction/tools/evidence/fixed-policy-price/reproduce.py --output-dir NEW_FIXED_POLICY_REPLAY
~~~

仅需Python标准库，使用正常assert模式。入口逐文件核hash，在临时目录恢复两源码、规范模块和证书路径；原verify只读证书。入口拒绝覆盖已有输出目录，不更改保全原件。

build是原程序另一个接口，会依赖NumPy/SciPy、运行求解和LP并覆写指定文件；本目录复现没有执行它，也没有复现作者寻找乘子的过程。原来源没有保存本轮新stdout对应的历史运行报告，不声称逐字节重现一个不存在的旧报告。
