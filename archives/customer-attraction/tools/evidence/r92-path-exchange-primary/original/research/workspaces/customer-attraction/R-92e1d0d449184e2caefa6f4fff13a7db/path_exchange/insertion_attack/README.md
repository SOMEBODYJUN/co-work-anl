## 五客户完整SPE：第二人克隆根反而使根收益上升

目录只有不交主题 A、B，分别包含3名、2名不同单位客户；人数 m=4。
根选A，其余完整策略如下（无省略历史）。

|历史|选择|历史|选择|
|---|---|---|---|
|A|B|B|A|
|AA|B|AB|A|
|BA|A|BB|A|
|AAA|B|AAB|B|
|ABA|A|ABB|A|
|BAA|B|BAB|A|
|BBA|A|BBB|A|

指定实际终局为 ABAA，根收益 3/3=1，第二人收益2。
在历史 A，第二人改选A后，沿同一完整策略的真实后继为 BB，故终局AABB，
根与克隆者收益均3/2。原持有者收益增加1/2；第二人因原收益2更高而无利可图。
根改选B的真实终局为 BAAB，根收益2/2=1，故根的选择也最优。

全部15节点和全部15非自身偏离以 `Fraction` 从定义独立核验。
完整输入、策略和两个路径保存在 `clone_gain_m4.json`；`check_clone_gain.py` 不调用SPE求解器。
本例实际福利和最优福利均为5；它只反驳克隆外部效应的单调性，不反驳半覆盖。

## 精确克隆分解

固定一个真实历史h，其前缀中已有一个选择A的玩家。当前玩家实际选B，
真实后继为某有序序列，终局为z。让当前玩家改选A，然后沿原完整策略真实执行，
终局为z'。对每个x∈A记：

- b_x≥1 是固定前缀h的客户负载；
- I_x=1[x∈B]；
- k_x、k'_x分别是两个真实分支中当前玩家之后的客户负载；
- d_x=b_x+I_x+k_x。

每个已经固定的A持有者的收益变化满足恒等式

    U_A(z')−U_A(z)
      = −sum_(x∈A\B) 1/[d_x(d_x+1)]
        +sum_(x∈A) (k_x−k'_x)/[(b_x+1+k_x)(b_x+1+k'_x)].

第一项是只替换当前行动而冻结后继时的直接拥挤损失；第二项是两个
**真实**后继之间的响应差。无需同计数同续局假设。SPE只给

    u_current(z) >= u_current(z') = U_A(z'),

故响应差至多可由当前玩家和原A持有者的收益差支付；没有逐项非正结论。
在本例的第二人节点，直接损失=1/4，响应收益=3/4，净变化=1/2。

## 探索中发现的计算盲区

`clone_probe.py` 对随机输入用规范 `solver.certificate(on_path=...)` 检查克隆收益变化，
2000个四主题三人输入未找到上升，追加四主题四人探针也未找到。
这并非克隆单调性的证据：规范certificate在离轨子树总选最小化当前偏离者收益的SPE。
克隆者与原A持有者同终局收益相等，因此这种规范选择同时刻意最小化原持有者收益。
上面的合法证书需要在离轨AA子博弈重选另一平局续局，默认certificate会遗漏它。

下一步若需要一般的删除插入支付，须控制上述响应差的**跨节点加权总和**，
不能假定单个克隆节点使原持有者收益下降。仅重做规范certificate随机搜索不能区分该候选。
