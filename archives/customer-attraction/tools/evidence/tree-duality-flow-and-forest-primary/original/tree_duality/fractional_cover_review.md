# 分数覆盖递推的独立审查

审查对象来自根代理本轮推导，不是 tree_duality 独立发现。设 O 是任意可由目录覆盖的比较客户集合（尤其为某个 OPT_n 并集），非空时设主题非负权 λ_T 逐客户覆盖 O，且总重 τ=Σ_Tλ_T。可规范取 τ≥1。

沿任意完整 SPE 的实际路径，令第 i 位行动前背景负载为 b_x，剩余人数 r=n−i+1，实际最终总负载为 c_x。令 u_i 为实际最终收益，P_(i−1)=Σ_(j<i)u_j 为过去玩家的**最终收益**和。

每个主题 T 的真实偏离后总负载逐客户最多为 b_x+r。因此 SPE 给

u_i ≥ Σ_(x∈T)1/(b_x+r).

对覆盖权 λ 加权，得 τu_i≥Σ_(x∈O)1/(b_x+r)。另一方面，过去玩家的最终收益之和准确等于Σ_x b_x/c_x（b_x=0项为零）；因 c_x≤b_x+r，故

P_(i−1)≥Σ_(x∈O)b_x/(b_x+r).

两式以 r 和1为系数相加，得到严格有效的统一不等式

|O| ≤ P_(i−1)+rτu_i.

于是 P_i≥(1−1/(rτ))P_(i−1)+|O|/(rτ)。因 τ≥1，所有仿射映射斜率非负，直接递推 P_0=0 得

W≥|O|[1−∏_(r=1)^n(1−1/(rτ))].

P_(i−1)>|O| 时不需要另外假设或截断，原始不等式仍成立、递推也仍有效。O空时结论直接为零。任意历史依赖平局、空主题及重复行动均不影响证明。

承重细节：不能将 P_(i−1) 偷换成前缀覆盖量；必须保留过去玩家的最终均分收益。这个证明没有要求未来最佳回复额外性质，仅用每次真实偏离的最坏终局负载上界及当前 SPE。

范围限制：取 O 为 n 个最优主题的并集时只得到 τ≤n；此信息自身不足以推出任意 n 的半覆盖。若 τ 另满足乘积≤1/2，则给相应结构类的半覆盖。
