# 奇偶三角不能保证共同客户平方正性

本对象保存原命题 CC-TRI-NO 的完整解析构造与量词边界。它反驳的是截断客户矩条件之间的蕴含，不是原模型中的福利命题。构造的某些客户类型质量为负，因而**不是合法单位客户实例，也没有 SPE 反例身份**。

对有限标签集 \(P\)、类型 \(B\subseteq P\)，沿用
\(\chi_E(B)=(-1)^{|E\cap B|}\)、
\(p_E=(1-\chi_E)/2\)、\(P_E=\sum_Bw_Bp_E(B)\) 以及覆盖矩
\(C(T)=\sum_{B:B\cap T\ne\varnothing}w_B\)。
固定阶 \(m\) 可见全部 \(|T|\le m\) 的覆盖矩。符号 \(w\) 在以下反方向构造中可以取负，只作为线性资料；[对称差闭合定理](../定理/可见奇偶矩的对称差闭合--定理.md)的非负前提仍必须保留。

## 1. 准确的分离命题

对 \(m=2\) 以及每个整数 \(m\ge4\)，存在一个共同有符号整数数组 \(w\)，满足：

1. 任意至多 \(m\) 个标签的完整投影均非负，投影包括空会员模式且共用同一总质量。
2. 任意 \(\max(|E|,|F|,|E\triangle F|)\le m\) 的奇偶三角
   \(P_{E\triangle F}\le P_E+P_F\) 全部成立，循环形式亦成立。
3. 一个在每个 Boolean 客户上非负、在空类型处为零、可用至多 \(m\) 阶覆盖矩表达的明确平方，其 \(w\)-加权和严格为负。

因此，前两类条件不能保证共同非负客户实现，连共同平方正性都不能保证。第3项的空类型为零还说明：改变未被任何标签覆盖的客户数，或者允许另选总质量，都无法保留这些可见覆盖矩而修复它。

## 2. 四位底例及全部局部投影

在四个虚拟会员位 \(y_1,\ldots,y_4\) 上取下表质量，未列类型为零：

| 类型 | 质量 |
|---|---:|
| \(\varnothing\) | \(3\) |
| \(\{1\},\{2\},\{3\},\{4\}\) | 各 \(-1\) |
| \(\{1,2\},\{1,3\},\{1,4\},\{2,3\},\{2,4\}\) | 各 \(1\) |

总质量为 \(4\)。一位奇偶质量为
\((P_1,P_2,P_3,P_4)=(2,2,1,1)\)，双位奇偶质量为

\[
P_{12}=P_{34}=2,\qquad
P_{13}=P_{14}=P_{23}=P_{24}=1.
\]

按 \(00,10,01,11\) 的顺序，两位完整投影只有以下三类：

| 两位支持 | 完整投影质量 |
|---|---|
| \(\{1,2\}\) | \((1,1,1,1)\) |
| \(\{3,4\}\) | \((2,1,1,0)\) |
| 一位取自 \(\{1,2\}\)、另一位取自 \(\{3,4\}\) | \((2,1,0,1)\)，按坐标顺序交换中间两格 |

全部格均非负；再投影给所有一位和空支持。注意这些是完整局部投影，不是仅覆盖矩单调或次模。

## 3. 全部可见三角与一个明确负平方

取五个索引 \(A_0=\varnothing,A_i=\{i\}\ (1\le i\le4)\)，记
\(d_{ij}=P_{A_i\triangle A_j}\)。它恰是二分图 \(K_{3,2}\) 的最短路度量：两组为
\(\{0,1,2\}\)、\(\{3,4\}\)，同组不同点距离 \(2\)，跨组距离 \(1\)。因此所有五点三角都成立。

这些三角确实覆盖 \(m=2\) 的全部可见奇偶三角。两个不同 singleton 给 \(0,i,j\) 的三角；singleton 与含它的 pair 给同一类；两个不同 pair 只有共用一个索引时，其对称差才至多二位，正好给 \(i,j,k\) 三角。相同或空方向的情况退化为等式或非负性，互不交 pair 的四位对称差不在可见域。

另一方面，取

\[
z=(2,2,2,-3,-3),\quad \sum_{i=0}^4z_i=0,\qquad
g=2+2\chi_1+2\chi_2-3\chi_3-3\chi_4.
\]

\(g(\varnothing)=0\)，而 \(g^2\) 的 Boolean 多线性化次数至多 \(2\)，逐客户非负。逐类型计算：

\[
\begin{aligned}
\sum_yw_yg(y)^2
&=-(16+16+36+36)+(64+4+4+4+4)\\
&=-104+80=\boxed{-24}.
\end{aligned} \tag{1}
\]

空类型贡献为零，负号来自四个 singleton 的负质量。这个精确平方已经排除共同非负实现，不需要数值特征值。

也可写成负型行。对任意实零和向量 \(z\) 和任意字符索引 \(A_i\)，

\[
\sum_{i,j}z_iz_jP_{A_i\triangle A_j}
=-\frac12\sum_Bw_B\left(\sum_i z_i\chi_{A_i}(B)\right)^2.
\]

共同非负客户使左端不大于零。本底例左端却等于 \(12>0\)。这是确定的平方证书，而不是把所有三角检查误称为矩阵正半定。

## 4. 任意 \(m=2\) 或 \(m\ge4\) 的完整块提升

令 \(d=\lfloor m/2\rfloor\)，取四个互不交的 \(d\) 标签块
\(V_1,\ldots,V_4\)。对每个物理类型 \(B\subseteq\bigcup_jV_j\)，置

\[
y_j(B)=|B\cap V_j|\bmod2,\qquad w_B=w_{y(B)}.
\]

每个虚拟模式有
\(L=2^{4(d-1)}\) 个物理原像，故总质量为 \(4L\)。不是把原先负质量变成正客户；有符号身份一直保留。

### 完整投影非负

准确人数条件给 \(3d>m\)：\(m=2\) 时 \(d=1\)，每个 \(m\ge4\) 也成立。所以一个至多 \(m\) 标签的支持至多完整观察两个块。

在一个未完整观察的块中，至少还有一位未观察。固定已观察位后，两种全块奇偶都有同样多的完成；因此已观察部分在投影中均匀，且与虚拟奇偶取值的限制无关。把未观察位求和后，支持投影是一个至多二虚拟位的底例非负投影乘以正的均匀因子。故它的所有格均非负，各支持间也因来自同一个 \(w\) 而一致。

### 所有可见三角成立

物理字符 \(\chi_E\) 的加权和，只有当 \(E\) 是若干完整块的并集时才可能非零：在某个块里只取非空真子集，会在同一奇偶纤维内成对抵消。

对非空 \(|E|\le m\)，若 \(E\) 不是完整块并集，则
\(P_E=2L\)。若是，它至多包含两块，故 \(P_E\) 为底例对应奇偶质量的 \(L\) 倍，属于 \(\{L,2L\}\)。

完整块并集构成对称差子群；\(E,F,E\triangle F\) 中不可能恰有两个方向属于该子群。三个都属于时退化到底例可见三角；至多一个属于时，非空情形的三个值为
\((2L,2L,pL)\) 或 \((2L,2L,2L)\)，\(1\le p\le2\)，所有三角成立。若有空方向，另两个方向相同，直接取等。这论证了所有可见方向，不是仅检验四个块标签。

### 一个仍可见的负平方

令

\[
g_V=2+2\chi_{V_1}+2\chi_{V_2}-3\chi_{V_3}-3\chi_{V_4}.
\]

平方只含空字符、单块字符和双块字符，故最高支持为 \(2d\le m\)；并有 \(g_V(\varnothing)=0\)。利用每种虚拟类型的原像数，

\[
\boxed{\sum_Bw_Bg_V(B)^2=-24L<0.} \tag{2}
\]

结合覆盖基展开，(2) 是当前可见资料确定的非负客户行。一般规模命题由以上投影、字符与子群证明建立。

## 5. 边界、审核及如何接续

\(m=3\) 时 \(d=1\) 不满足 \(3d>m\)，局部支持可能观察三个完整块；本构造和证明均未覆盖它，不能把命题写成“所有 \(m\ge2\)”。同样，本族没有保证全部低于 \(m\) 阶资料与某个真客户数组相同；奇数 \(m\) 时坏平方的最高次数可为 \(m-1\)，已经阻止这种额外结论。它不同于[旧四字符数组](../定理/可见奇偶矩的对称差闭合--定理.md)保留所有较低阶 uniform 矩的性质。

原独立评审逐项重构了底例、负型恒等式、全部块提升及 \(m=3\) 缺口。本轮原程序的有限审计覆盖 \(m=2,4,5\)，检查每个相应支持的完整投影及全部有序可见三角；其中 \(m=4,5\) 使用相同八标签数组，但可见支持域不同。原程序可选的 \(m=6\) 扩展本轮未执行，原报告也未含它。解析命题不能用有限样本范围代替。

下一层[整数格障碍](全部可见低度平方的整数格缺口--障碍.md)进一步说明，全部指定低度平方也可能不够；它采用另一份底例，不能与本对象的质量 \(3,-1,1\) 混并。本对象仅限制客户资料的替代表示。若还加入完整真实激励后研究半覆盖，仍须另行分析；这里没有对该联合系统或六人目标给出否定结论。
