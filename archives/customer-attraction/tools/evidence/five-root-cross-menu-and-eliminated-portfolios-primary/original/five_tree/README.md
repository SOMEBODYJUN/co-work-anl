# 根最优查询末位 × 第二位查询末位菜单

目标仍是原单位客户、单位提供者、任意共同有限目录、恰五位提供者、任意完整历史依赖纯 SPE 的 `OPT_5 <= 2W`；未完成。本文给出现有联合模板漏掉的一条真实跨枝末位比较及完整系数域的条件定价实现，不把松弛点当作 SPE。

固定任意一份原完整策略 `sigma`，实际第一主题为 `A`。选择达到 `OPT_5` 的五个索引主题 `T_1,...,T_5`，允许重复。定义同一原策略的两族真实终局

`r_i=(T_i,X_i,Y_i,Z_i,K_i)`，以及 `s_j=(A,T_j,H_j,I_j,J_j)`。

这里第一条由根强制 `T_i` 后沿原策略，第二条由真实第一行动 `A` 后强制第二行动 `T_j` 再沿原策略。强制者不冒充其分支的优化者。根族末位的真实节点为 `h_i=(T_i,X_i,Y_i,Z_i)`，其收益为 `v_i`。

共同目录保证每个 `J_j` 在每个 `h_i` 都合法。第五位没有后继，故原 SPE 的 25 条精确比较为

`v_i >= sum_(x in J_j) 1/(1+c_hi(x))`。

全部 `(i,j)` 相加，交换有限求和，得到

`G = 5 sum_i v_i - sum_x Jcount_x Droot_x >= 0`，

其中 `Jcount_x=sum_j 1_(x in J_j)`，`Droot_x=sum_i 1/(1+t_ix+x_ix+y_ix+z_ix)`。分母计四个有序位置，主题相同也逐位置计数。重复最优主题和重复 `J_j` 都按索引重复计；空主题、零客户和任意历史平局不影响。这里的比较始终在同一原 `sigma` 中，未冻结任何早期后继。

若每客户根直方图按 `(t,x,y,z,k)` 排列为 32 类型，则其逐客户系数为

`5 sum_tau n_tau k/(t+x+y+z+k) - c sum_tau n_tau/(1+t+x+y+z)`，

其中零分子项取零，`c=Jcount_x`。第二位查询族的 16 类型按 `(t,h,i,j)` 排列，因此 `c` 是末位 membership 的总数。

## 与现有模板的关系

`R-bfb.../five_only/combined_root_penultimate.py` 的 root-query 族末位已有十个固定主题和本族菜单比较，以及向旧 `L_i` 菜单的旧路径信息；未包含这里对 AB/AE/second indexed 后继菜单的比较。搜索两份最近工作区的源文件后，`round13/certificate/max_menu_last_pricing.py` 有同类的单个最大主题根分支末位比较，但来源节点不是本条的五个最优根查询节点。底层末位 SPE 比较不主张新颖性；本条新增的是联合模板未保留的具体跨块耦合。

独立语义盲重构由同团队 `five_independent` 完成，接受这 25 行及求和式的节点、分母、退化与任意平局范围；这不是独立全域对偶审查或 HALF(5) 证明。

## 完整类型定价，不截断支持

`cross_root_last.py` 继承同行完整联合模板，仅增加一条 `CrossRootLast:second-J`。固定第二位查询族的末位计数 `c in {0,...,5}` 后，新行的加权系数仅为根直方图的线性函数：

`5 lambda share_K - lambda c den_4`。

对每个 `c`，第二位族仍枚举全部满足共同最优重数 `d` 和末位计数 `c` 的 16 类型五索引直方图；根族仍枚举全部 32 类型五索引直方图并保留同一 `d`；其他旧族和三个旧回复菜单采用原完整定价。六个 `c` 的并恰为原允许域，故六次条件最小余项的最小值就是加入此行后的全域最小余项。没有假设两个族在真实实例中独立；允许独立直方图是包含真实实例的必要条件放松。

实现通过修改根目标中的 `share_K`、`den_4` 系数，并限制第二族的完整 `(d,c)` fiber，复用原定价及其直接逐客户行校验。发现算术仍为浮点；尚未恢复有理二倍系数证书，不提升为福利界。
