# 无祖先承诺的规范门槛

采用[共同目录完整历史模型](../定义/共同目录完整历史模型--定义.md)：有限单位客户、有限非空共同主题目录\(\mathcal S\)、单位提供者顺序选择，允许空主题、重复、零客户和任意离轨历史平局。固定任意合法有序历史\(h\)，其过去客户负载为\(b\)，尚余\(r\ge1\)人。

令\(\mathcal R(h,X)\)为当前人强制选\(X\)后，未来采用某份完整纯孩子SPE产生的终局全集，置
\[
\ell_X(h)=\min_{z\in\mathcal R(h,X)}u_{\rm current}(z),
\qquad M_r(h)=\max_X\ell_X(h).
\]
有限游戏保证非空、最值达到。每份完整SPE在\(h\)的当前收益至少\(M_r(h)\)：节点IC对每个备选孩子的真实选择比较，而该选择不小于该孩子最小值。反向对各有序孩子独立取当前收益最小的完整子SPE，再让当前人选其最大者，可实现当前收益恰为\(M_r(h)\)。因此它等于全部完整SPE当前收益的最小值；这里的min用**同一当前人**收益坐标。

本页门槛没有附加祖先终局收益上限或其他承诺。给定目标孩子端点可补成当前SPE，当且仅当其当前收益不低于该M。相同负载/剩余人数的两个历史有后缀游戏同构，故全集门槛只依\((b,r)\)；这不要求原\(\sigma\)在同计数历史指定同尾。完整机制见[终局全集](../算法/完整历史纯SPE终局全集--算法.md)和[可信菜单](../算法/可信续局菜单与完整策略重构--算法.md)。

# 固定尾部时AB与BA的准确可实现条件

取\(r\ge2\)、主题\(A,B\)，给定在\((h,A,B)\)后的完整\(r-2\)人尾部SPE \(\tau\)，其规定终局首两利润为\(\alpha,\beta\)。记
\[
\mu=M_r(h),\qquad\mu_A=M_{r-1}(h,A),\qquad
\mu_B=M_{r-1}(h,B).
\]
此节\(\mu\)为门槛记号，不是后文其他分析域的cap乘子。则
\[
\boxed{(A,B,\tau)\text{可补成 }h\text{处完整SPE}
\iff\alpha\ge\mu,\quad\beta\ge\mu_A.}
\tag{AB}
\]
必要性分别在根和第二节点用规范门槛。充分性先在\(A\)孩子使用指定\(B,\tau\)，其余第二动作各拼达到当前收益最小值的完整尾SPE；\(\beta\ge\mu_A\)保证第二人最优。再在根其他第一动作各拼最小收益孩子，\(\alpha\ge\mu\)保证根最优。不同有序子树不相交，兼容。

将整棵\(\tau\)按后缀历史从\((h,A,B)\)重标到\((h,B,A)\)。两个前缀负载相同，每个后续节点的规定叶、任意真实偏离叶及收益都保持，所以重标尾仍是SPE。最终完整计数不变，首两角色利润交换为\((\beta,\alpha)\)。同理
\[
\boxed{(B,A,\tau)\text{可补成 }h\text{处完整SPE}
\iff\beta\ge\mu,\quad\alpha\ge\mu_B.}
\tag{BA}
\]
\(r=2\)时尾为空，\(A=B\)时\(\alpha=\beta\)，两式照常成立。

若原\((A,B,\tau)\)已来自一份完整SPE，且\(\beta\ge\alpha\)、\(\alpha\ge\mu_B\)，就能得到新SPE，首对为\((B,A)\)、同终局负载及福利。具体可保原根除B外全部孩子；它们给根收益\(\le\alpha\)。新B孩子由(BA)补成，根收益\(\beta\ge\alpha\)，故根仍最优。这里重选了B孩子，并非原固定\(\sigma\)在B分支的真实偏离；不能让原\(\sigma\)自动采用搬来的尾。

# 同规定终局负载的子树替换保留严格祖先比较

更一般，在任意合法历史\(g\)把子SPE换成另一份子SPE，若两者的规定终局有相同完整客户负载，则每个严格祖先的每个真实强制动作完成叶都保持负载：原完成不经过g者未改；经过g者先前动作未改，接到的新规定叶负载相同。祖先自己的行动固定，因此其各项利润、整IC以及该祖先的额外查询完成收益均保持。

g不必为根实际路径可达。此性质保的是**g外的严格祖先比较**；g子树内部菜单可以改变，所以不能宣称Mpath/WP或其他菜单坏性保持。相邻实际位置换位时，目标终局计数与原叶相同，故可用此性质嵌回全部更早祖先，得到完整根SPE，不是删除祖先后的局部游戏结论。

# 固定PB坏点及固定终局计数的极端结构

为准确保留旧PB应用，定义不观察查询实现的静态整数安全值
\[
v_k(b)=\max_{p\in\Delta(\mathcal S)}\min_{D\in\mathcal S^{k-1}}
E_{T\sim p}\sum_{x\in T}\frac1{b_x+1+c_x(D)}.
\]
固定实例、\(h,r\)，令\(t=v_{r+1}(b)\)。若满足\(\alpha+\beta<2t\)的完整SPE集合非空，在其中选第一利润\(\alpha\)最大者。若\(\alpha<\beta\)，必有
\[
\boxed{M_{r-1}(h,B)>\alpha.}\tag{PB-BARRIER}
\]
否则增序换位保首对总和与PB坏性，却提高第一利润到\(\beta\)，矛盾。选择集合只以首对总和坏定义；若另加不保持于换位的“第一利润<t”等条件，就不能自动引用这个极端论证。

更直接地，固定任意可由完整SPE实现的**终局主题计数**\(q\)，在其有限个完整实现中选实际收益向量字典序最大者。对每个相邻严格上升\(u_i<u_{i+1}\)，有
\[
\boxed{M_{m-i}(h_i,S_{i+1})>u_i.}\tag{LEX-BARRIER}
\]
反之若门槛\(\le u_i\)，局部换位保q及更早收益，将第i项提高，违反字典序最大性。福利与OPT只依实例和终局覆盖，所以若q为假设half坏计数，重选此lex实现保持其坏性；菜单条件则没有这个保持保证。

# 真正half坏计数的最后低利润跨越

任意完整SPE的末位收益有
\[
\boxed{\operatorname{OPT}_m\le(2m-1)u_m.}\tag{LAST}
\]
证明：令L为实际前\(m-1\)主题负载，末位最佳回复给每个主题\(T\)的插入价\(g(T)=\sum_{x\in T}(1+L_x)^{-1}\le u_m\)。取最优m主题负载d，逐客户
\(\mathbf1_{d_x>0}\le(d_x+L_x)/(1+L_x)\)。求和后第一项是m个最优主题插入价，至多\(mu_m\)；第二项为前\(m-1\)实际合法主题插入价和，至多\((m-1)u_m\)。证毕。

若q满足\(\operatorname{OPT}_m>2W\)，则W>0且m≥2；由(LAST)，
\[
u_m>\tau:=\frac{2W}{2m-1}>\frac Wm.
\]
在q的lex最大实现中必有某\(u_i<\tau\)，取最后一个这样的位置，则
\[
u_i<\tau\le u_{i+1},\qquad
\boxed{M_{m-i}(h_i,S_{i+1})>u_i.}\tag{LAST-DIP}
\]
只得到门槛严格大于\(u_i\)，**没有**得到门槛\(\ge\tau\)。这个必要结构没有排除half坏计数，也没有把不可换位价值支付给同一OPT比较。末位静态上界与两步资格门都不能单独闭合half。

# 固定目标移植的唯一第二节点缺陷与最小regret

固定原SPE在h的根实际收益\(\alpha\)。任意强制第一主题T后，原\(\sigma\)真实第二动作记C，真实叶首对收益为\((d_T,c_T)\)，故根IC给\(d_T\le\alpha\)。将其整尾移植为\((C,T)\)，目标第二人收益为\(d_T\)，新根收益为\(c_T\)。在C后其他第二动作分别选当前收益最小的完整孩子SPE，保指定T尾。

令\(M_C=M_{r-1}(h,C)\)。该固定目标叶下能达到的最小第二节点regret恰为
\[
\boxed{\delta_{TC}=(M_C-d_T)_+.}\tag{DEFECT}
\]
所有别的第二动作都不可能低于各自孩子最小收益；取这些最小值时达到其最大值。目标T的孩子最小值本来\(\le d_T\)，所以是否在max中包括目标行动都不影响正部，得到恰好值而非仅上界。

若\(c_T\ge\alpha\)，保原根除C外全部孩子，新根仍最佳回复；除这个指定第二节点外所有正深度节点均为完整子SPE。若\(\delta>0\)，整个计划仍不是SPE。这也不是“只有根有缺陷”的合同，不能免费套根修复器。嵌回更早祖先时，新规定叶来自原强制T分支，未必与原h实际叶同负载；本段不自动获得上一节context保持性。

由\(d_T\le\alpha\)，直接有
\[
\boxed{\delta_{TC}\le(\alpha-d_T)+(M_C-\alpha)_+.}\tag{SLACK-SPLIT}
\]
当\(M_C\le\alpha\)时低阈值障碍被该根真实偏离IC松弛\(\alpha-d_T\)上界；高阈值\(M_C>\alpha\)仍多一份未付量。没有证明这同一松弛可跨多个T重复使用。若T就是原根实际动作，则\(d_T=\alpha\)，这份源松弛为零，恰剩\((M_C-\alpha)_+\)。

# 最小PB坏人数信用及当前真实状态

原稿还引用正确的条件归纳输入：若取任意合法背景PB-extra失败的最小真实剩余人数r，则每个proper历史的前两最终利润和满足其自身PB，再由静态嵌入\(v_{k-1}(b+\mathbf1_A)\ge v_k(b)\)至少为\(2t\)。嵌入来自将一个静态竞争槽固定A后缩小对手可行域；剩余最后一人收益也至少t。因此每个真实根分支的后继总利润至少\((r-1)t\)，但不能提升为每位后继各自\(\ge t\)，也不强迫\(\mu_B\le\alpha\)。这些proper-history配对信用没有支付高阈值封闭链或SLACK-SPLIT的混合支持总额。

旧主稿将PB-extra与half都标OPEN，当前必须分开：[任意合法背景PB-extra已被完整解析构造否定](../反例/任意合法背景的前两人额外槽安全值--反例.md)，其大背景不是根half或实际前缀反例；本页极端结构和条件蕴含仍正确。五人half另证成立，六人每份完整纯SPE目标未由这些换位付款闭合。[最小收益移至末两位的福利障碍](../障碍/最小收益移至末两位的福利代价--障碍.md)也说明不能无条件排序所有收益；它与本页有门槛的保计数局部换位相容。关系为全集门槛→准确可实现性、同负载替换→极端正常形、末位静态界→必要last-dip、固定叶→最小regret；正式超图留第三阶段。
