# 查询支持生成的真实策略闭包：完整 SPE 与严格分离保留

2026-10-23，mixed_menus。身份：全输入的初等解析归约，未独立审查；不声称新颖性，不是支付或半覆盖证明。

## 1. 闭包定义与完整历史合法性

固定有限共同目录 S、人数 m>=1 及完整有序历史纯 SPE σ。取非空种子动作集 B⊆S。定义

    C_0=B,
    C_(n+1)=C_n ∪ {σ(h): h∈C_n^i, 0<=i<m}.

空历史也包含在定义中，所以无需把实际首动作另加到种子。由于 S 有限，序列在某有限步稳定，记闭包 C。此处允许所有重复有序历史，不能仅取沿 σ 的可达历史或仅按计数取历史。

稳定性给 σ(h)∈C 对每个 C 上的非终局有序历史 h 成立。故可将 σ 直接限制为 C 目录上的纯策略 σ|C。任意这样的历史 h 及偏离 T∈C，其后逐步按 σ 行动仍在 C 中；因此整个真实终局与原 S 游戏的同一有序历史、同一偏离终局完全一致。原全部 IC 中包含这个比较，故限制后仍是完整 SPE。

空历史的规定行动属于 C，沿规定边重复此论证，原实际完整路径全部保留。故客户集不变时实际 W 不变。所有边界包括空主题、零客户和任意历史平局。

## 2. 根及完整前缀菜单

取查询分布 p 支持在 B 中。在合法前缀 h 的后续闭包应用中，取种子为 B 加上 h 中出现的全部主题，把 h 固定，再只对其后剩余 r 个位置应用上述构造。加入旧主题保证 b 仍由同一限制目录的合法前缀实现，不能把合法背景条件悄悄换成冻结外部背景。对每个闭包根行动 A∈C，限制游戏中的完整真实根终局正是原 Z_h(A)。因此查询矩阵是原矩阵的查询行/根列限制。

于是：

- 若原 Mfull 有严格分离 p，即每个原根列都满足 p^TK_(·,A)>u，则闭包限制游戏的每个根列也严格大于相同的 u；实际当前行动和其收益均保留。
- 若原 WP 在 p 失败，则其二次值只用 p 支持上的行和列；全部这些终局保留，因此相同 p、相同 u 的失败原样保留。
- 在空背景整局闭包中，原实际每个前缀均保留。对每个位置 i，闭包菜单只删掉一些原合法列，故 min_(A∈C) g_p(Z_i(A)) >= min_(A∈S) g_p(Z_i(A))。因此任何原完整前缀菜单的严格分离也保留，实际 W 和 m 均相同。

这些陈述不是说闭包游戏的菜单值必须等于原值；删列可使最大查询值升高。也不允许把闭包目录误称为原查询支持 B 本身。

## 3. 原半覆盖目标的比较主题闭包

取 B 为某个最优 m 元组中出现的不同主题，故 1<=|B|<=m。其并集仍可在 C 中用 m 个主题实现，所以

    OPT_m(C)>=OPT_m(S).

C⊆S 给反向不等式，故两者相等。上节又保留原完整 SPE 及实际 W。因此任何原半覆盖真正反例也有一个相同人数、相同客户集、相同 W/OPT 的策略生成闭包反例。

这是对所有输入有效的恢复/删行动归约；并未产生固定极大主题数或特殊正面类。

## 4. 对一般证明的用途与限制

可以在研究某个指定 query 分离时，先删掉从该 query 支持无法按完整 σ 闭包生成的行动，而不会损失该分离。可以在直接研究原 half 时，以某个最优比较元组为闭包种子。

但本归约没有给 |C| 或生成轮数的统一界，也不减少 m。每个新动作可能来自不同的离轨有序历史；所有这些真实子树仍必须保留。用“不断选择一个新支持外动作”的有限规则代替 C 的全部历史闭包，并没有得到本结论要求的对象。闭包自身没有给共同静态列分布，更没有支付跨分支 suffix coalition regret。
