# 独立重构与弱逐人保底攻击

2026-10-21，Boss6 研究员6.6。个人探索备份；没有改变共享Claim状态，没有git或外发。

主目标 Q-CAG-HALF 仍 OPEN。这里从原始模型独立重构：唯一直接的共同目录保底是每名实际玩家 `u_i≥K/m`，K是最大主题大小；静态安全值逐人桥已经失败，不能替代真实后继。欲得到 half，可另试更弱的 `u_i≥OPT_m/(2m)`；该命题比聚合half更强，但不由已失败的逐人安全值桥推出。

根本瓶颈：若某玩家收益很小，他在真实节点改选每个最优主题后，后继能够分别改变并拥挤该主题；这些不同真实续局的外部覆盖与最佳回复尚无共同预算。目录共同、均分收益和后继自身可信性是可能承重的结构，不能冻结后继或将逐主题菜单独立拼合。

`probe_floors.py` 将已有完整策略固定后，在全客户重数锥内最大化比较覆盖/某实际主题收益，并对更弱候选 `OPT≤K+m u_i` 做攻击。浮点LP仅发现候选；有理原始点需完整Γ精确核验，正式反例还需另行定义级核验。指定策略锥的失败攻击不构成一般正面结果。
