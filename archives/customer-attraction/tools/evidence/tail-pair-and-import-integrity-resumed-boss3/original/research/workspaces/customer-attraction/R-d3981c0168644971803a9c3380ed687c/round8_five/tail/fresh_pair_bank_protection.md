# 五块新遗漏的真实末二保护：最后大银行的可信拥挤停界

2026-10-25，Boss14/tail；counter 构造的独立机制检查。状态：下述参数引理及其对原整数点的排除有解析证明；不是 HALF(5) 定理，不排除所有部分保险参数。没有依赖完整 BI 的数值门槛。父方与 counter 尚未独立复核本文新引理；无外审/新颖性认证。

## 1. 精确模型与参数引理

在原有限单位客户、单位提供者、共同非空目录、完整有序历史纯 SPE 模型中，固定任意有序前缀 h，恰余两人。所有后继行动和平局均来自同一原完整策略。设目录客户分为互不交的五个遗漏块 X_0,...,X_4 与银行客户，满足：

1. 每个 X_i 有 ell>0 名单位客户；h 尚未覆盖任何 X_i。
2. 每个合法主题属于以下之一：纯银行主题；一个完整 X_i 加银行；两个完整 X_i,X_j 加银行。没有切割 X_i 的主题。
3. 对每个 i<j，目录含一个指定 pair 主题 R_ij，恰覆盖 X_i union X_j 加非负银行。没有额外的双遗漏主题；同覆盖重复标签若存在可以按同样上界处理。
4. 令 h 的银行负载为 q_x。单遗漏主题的银行单独价格 sum 1/(q_x+1) 都严格小于 ell；纯银行主题单独价格都严格小于 2ell；每个 R_ij 的银行单独价格都严格小于 ell/2。

**结论。** 每份此真实末二子博弈的完整 SPE 中，两人必选 R_ij 与 R_kl，且 {i,j} disjoint {k,l}。第一人经济块利润为 2ell，末位经济块利润也为 2ell；银行利润另加且非负。因此每人最终总利润至少 2ell。该结论保留所有平局，所用严格性仅为明确参数假设。

**证明。** 当前人若选 R_ij，仍有三个未被其覆盖的 X 块。末人选其中任意两块的 pair，经济收益为 2ell，银行非负。此时纯银行主题收益严格小于 2ell；单遗漏主题收益至多 ell 加其原银行单独价格，仍严格小于 2ell。与 {i,j} 有交的另一 pair，经济收益至多 3ell/2（重复同一 pair 更只有 ell），银行收益至多其原单独价格<ell/2，故总收益也严格小于 2ell。因此末位每一个最佳回复都必须是一条经济块不交 pair。当前人的经济块绝不被稀释，真实偏离 R_ij 保证至少 2ell。

于是当前人的 SPE 收益至少 2ell；每一个非 pair 行动即使不再被后继拥挤，其收益上界已严格小于 2ell，不能被选。当前必选某 R_ij，前段论证再保证实际末位 pair 与之不交。没有冻结末位回复，也没有把最优平局重新指定为有利于前人的回复。

本引理是两层真实 IC 与 fresh pair 间隙，不是把固定路径的必要安全行当作完整均衡。空主题自动属于纯银行上界；重复行动允许，但参数证明把重复 pair 排除为严格劣解。ell=0 不满足本引理，不能由除法延伸；全零实例仍直接满足原 half。

## 3. 少量 pair 银行保险仍不能改变尾部选择

保持参数引理假设，允许银行客户也属于 R。令 B 是一个已由偏离者选择的银行主题，其客户在 h 的负载 q_x>=1。记 F_B 为 B 中属于至少一个 pair 主题的银行客户集合。

因为真实末两人是两条不同且经济块不交的 R：

- 若每名银行客户最多属于一个 R，则偏离者的同叶银行利润至少

      sum_(x in B minus F_B) 1/q_x
      +sum_(x in F_B) 1/(q_x+1).                      (BANK-ONCE)

- 不限制银行客户的 R 关联数时，仍至少

      sum_(x in B minus F_B) 1/q_x
      +sum_(x in F_B) 1/(q_x+2).                      (BANK-TWICE)

这些下界逐客户计真实后继覆盖次数；没有说已保险客户必被后继选中的 R 覆盖。在原 A4 的两块各30银行客户此前均无负载，h中q=1；若每客户最多挂一个R，(BANK-ONCE)给

    u_deviator >=60-|F_B|/2 >=30 >20.

因此只要每个 pair 的原银行单独价格仍<15，便算把 A4 的全部60客户分配给不同R，这个独特 R 会员的保险机制也无法修复第三位目标20。要逃离这个已证停界，必须至少破坏一个承重假设，例如某个 pair 的银行价达到15、单遗漏主题银行价达到30、纯银行主题银行价达到60，或者让同一银行客户属于多个 R。这些只是离开引理范围的必要方向，不是修复足够条件。

15 是这里“交一块的 pair”经济亏损30/2的保守严格门槛；相等时不能排除历史平局，不能把<擅自改成<=。

## 4. 单挂最后银行的更弱、但不需小银行价的停界

以下只针对原 A4 型纯银行主题 B：0<|B|=b<3ell，原目录中覆盖整个 B 的主题仅有 B 本身，其他单遗漏或纯银行主题可以含 B 的真子集。允许将 B 客户附加到 pair，每个 B 客户最多属于一个 R，且 R 的新增银行只能来自 B。允许仍有其他银行与单遗漏/纯银行主题，但它们不能成为覆盖全部 B 的额外主题。固定前缀使每名 B 客户的负载恰为1，且所有 X_i未触及，尚余两名。

**结论：** 每份完整 SPE 中，已有 B 提供者的最终银行利润严格大于 b/3。单位客户还给出利润至少 b/3+1/6。

**证明。** 若利润≤b/3，则每个 B 客户都必须被后两人各覆盖一次：每名客户的最小份额为1/3，平均达到最小值只能逐客户均达到。因此后两主题都覆盖整个 B。独特 R 会员假设使至多一条 pair Rstar 能覆盖整个 B；其他整银行覆盖主题只有 B 本身。

末位选 B 时仅得b/3，而无论前一个整 B 主题是 B 或 Rstar，都还存在一条经济块完全新的 pair，可得2ell，严格更高。因此末位只能为 Rstar。

若前人也是 Rstar，末位重复该 pair 的收益为经济 ell 加银行b/3<2ell，严格低于经济块新 pair 的2ell。所以前人只能是 B。但前人此时利润b/3<ell；改任意 pair，即便被末位同时拥挤两个 X 块，其经济收益也至少ell，银行非负，严格更高。违背该真实当前 IC。

原ell=30、b=60时给已有A4玩家收益至少121/6>20，仍排除原第三位目标20。这里未给60甚至45，也未允许 Rstar 同时从其他未覆盖银行获得额外奖金。原 b=2ell 时，末位重复 Rstar 若要补足5ell/3到2ell的缺口，至少需要额外 ell/3 的末位银行收益；这说明“再拿第三/第四银行的未覆盖信用”确实是可能改变本窄机制的一个方向，但没有证明其完整可信性。

### b<3ell 的局部阈值不能无条件改为 b<=3ell

取每个 X_i 一名客户、B有三名客户、目录为B及十个K5 pair。只有R_01额外包含全部B客户，其余R不含银行。固定前缀B，尚余两人。规定当前选R_01；最后人在前主题也是R_01时于并列最佳回复中选R_01，其余前主题后选R_01（它此时也是最佳回复）。两次R_01各得经济1+银行1=2；新经济块不交pair也只能给2。因此这个真实末二完整SPE使旧B提供者恰得1=b/3。

全部离轨分支也可直接核：当前改B仅得1；改与01经济块不交的pair，末位选R_01，当前得2；改交一块的其他pair仅得3/2。故当前R_01最优；末位各分支R_01均最佳。这个例子只认证局部阈值的平局锐性，前缀B并不声称来自五人根的指定实际路径，也不反驳half。

## 5. 依赖、核验与真值边界

一般推导只用原完整历史 IC、单位客户均分公式、五个新块及明确的目录/价格假设。原点输入与既存 BI 诊断分别在 counter 的 `insurance_security_lp.json` 与 `diagnose_private_insurance.json`；本文不将最差SPE福利233当作证明前提。

`verify_fresh_pair_protection.py` 以 Fraction 从精确整数点独立计算银行价、逐主题末位上界及所有真实当前pair分支的每个末位最佳回复；这是定义级局部算术QA。任意满足参数的实例结论来自第1节证明；脚本另核对第4节的八客户局部阈值例。一般 HALF(5)、任意部分保险参数及根45门槛均未因此闭合。
