# 全树收益图、全部单点稀释与单调覆盖守恒仍有9/4障碍

研究备份，2026-10-21。采用CAG-MODEL。这里给一个**精确证明模板障碍**，不是客户实例，也不是Q-CAG-HALF反例。一般主目标仍OPEN。全部有限证书已由本目录不导入LP的Fraction验证器从定义核验；尚未独立他人审查，无外审或新颖性声明。

## 精确对象与命题

对人数m、标签数p，收益顶点是v=(q,a)，其中q为总和m的非负整数计数，q_a>0。真实客户的收益类型行为

\[
 F_{q,a}(B)=\frac{\mathbf1_{a\in B}}{q(B)},\qquad q(B)=\sum_{b\in B}q_b.
\]

分子零时取零。固定完整有序历史策略σ；从h照原策略执行的终局计数为q_h，在h先改选b后照同一原策略执行的终局计数为q_{h,b}。不冻结后继，不统一同计数历史的策略。

考虑比真正共同客户表示更宽的抽象非负收益变量y_(q,a)。保留以下全部必要条件：

1. **全树真实边：** y_(q_{h,b},b)≤y_(q_h,σ(h))，对每个有序决策历史h、每个b。
2. **全部最锋利同标签单顶点稀释：** 对每个q,r和q_a,r_a>0，
   \[
   y_{q,a}\le\kappa(q,r;a)y_{r,a},\qquad
   \kappa(q,r;a)=\max_{B\ni a}\frac{r(B)}{q(B)}.
   \tag{1}
   \]
3. **全部同支持覆盖守恒：** 存在C(T)，对每个总数m的q，
   \[
   \sum_aq_a y_{q,a}=C(\operatorname{supp}q).
   \tag{2}
   \]
4. **全部可见覆盖单调性：** C(∅)=0，且C(A)≤C(B)对A⊆B、|B|≤m成立。

式(1)的锋利性直接逐类型验证：a∉B时两行都零；a∈B时F_(q,a)/F_(r,a)=r(B)/q(B)，最大者类型达到常数。真正客户同时满足(2)，因为每个被覆盖客户的所有提供者份额和为1。

**命题MT-9/4。** 存在m=3、p=6、来自一个22单位客户完整纯SPE的真实全树，以及126个顶点的非负有理y，满足以上1—4，而实际根终局q*及某个三主题比较组合J满足

\[
 \sum_aq_a^*y_{q^*,a}=1,\qquad C(J)=\frac94>2.
 \tag{3}
\]

因此，全树图边、全部同标签逐类型最优稀释、同支持总支付守恒与覆盖单调性联合仍不足以推出半覆盖。该命题只针对所写明的放松；不否定共同客户表示或增加Shapley一致性后的机制。

如果希望C定义在全部2^[p]上，可令

\[
 \widetilde C(T)=\max\{C(A):A\subseteq T,\ |A|\le3\}.
\]

它是全局非负单调扩张，且在|T|≤3时等于C(T)。所以允许全局单调扩张也不排除此障碍。

标签为0,…,5，分成X={0,1,2}、Y={3,4,5}。完整σ定义为：根选0；第二位见首主题在X时选3，否则选0；末位选**第二位主题所属组**中最小的尚未出现标签。两位前缀至多占用两个标签，故末条总有定义。

## 有理证书与为何不是共同客户

`monotone_candidate.json`逐项给全部126个(q,a)的有理y和43个历史行动；无需相信浮点LP的最优状态。验证器检查以下有限全集：

| 检查 | 数量 |
| --- | ---: |
| 原22单位客户的SPE比较 | 258 |
| 抽象y上的真实图边比较 | 258 |
| 全部非自同标签有序顶点对的锋利稀释 | 2520 |
| 总数3的q的支持总支付 | 56 |
| 含空集的可见支持 | 42 |
| 全部支持包含关系，含等号 | 233 |

实际计数q*=(1,0,0,1,1,0)，比较J={1,2,4}。精确总支付为1和9/4。

有两条很短的独立分离证据，说明这些伪收益没有共同客户表示。第一条是必要的覆盖次模性：证书给出

\[
 C(\{4,5\})=\frac34,\quad C(\{3,5\})=\frac{31}{40},\quad
 C(\{3,4,5\})=\frac{23}{20},\quad C(\{5\})=\frac5{12}.
\]

于是

\[
 C(345)+C(5)-C(45)-C(35)=\frac1{24}>0.
 \tag{4}
\]

这违反共同非负客户覆盖函数的次模性。

更基本地，伪收益连共同**有符号**客户表示的线性一致性也不满足。三人计数q=2e_a+e_b时，真正均分行必有

\[
 F_{q,a}=\frac{2k_a-k_b+k_{ab}}6,
 \quad k_T(B)=\mathbf1_{B\cap T\ne\varnothing}.
 \tag{5}
\]

证明可将客户分成a-only、b-only、ab三类，或直接逐类型核验。因此任何共同（允许有符号的）客户质量都要求

\[
 y_{2e_a+e_b,a}=\frac{2C(a)-C(b)+C(ab)}6.
\]

本证书在a=0,b=1时左边为3/8，右边为7/24，差为1/12。同支持总支付仅控制各主题收益之和，并不固定主题间的Shapley份额；全部单标签稀释也没有恢复这些跨主题线性关系。

式(4)和(5)都只是必要条件的分离证据，不是声称增加其中任一条件就足以一般闭合半覆盖。
