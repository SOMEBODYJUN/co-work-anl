## 原独立实现的真实责任

direct不导入父方核验器、仓库CAG模块、solver或第三方数学库。唯一数据文件是兄弟parent/suffix_envelope_input.json；程序先按单位位置字面展开6000客户，再建十二覆盖集合并assert不同，独立写收益/安全/自复制税/相对势逐项和式。势枚举前才按(完整兴趣,背景)重分组；这个120组加速不改变值。

原代码检查72个SAFE和18563个全部目录比较多重集；报告只存SAFE count/min，**没有存全部72个slack**。六suffix对象则全部保存profit、tax、budget、最大势、最小余量、一个最大元组及域/索引。每个倒二query先枚举所有真实末位BR，再算当前min/max；原report完整保存十二行，父方只保存其中七盈利行。

输入指定路径W2940、OPT6000、差120；全部SAFE/ENV成立，规定末位已BR，但七倒二query对每个真正末位BR都严格盈利。它是指定条件不足的有限证明，路径不可能补成完整SPE；不是半覆盖反例，也不否定ENV对真实SPE的普遍必要性候选。
