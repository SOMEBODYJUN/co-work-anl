# 模型与三个不同层次

取有限正个k≥1分量CAG，客户集N_j彼此不交，各有有限非空真实集合目录𝒮_j及相同m≥1名单位提供者、同一行动次序。联合客户是这些不同单位客户的不交并，联合每步动作是**完整**Cartesian目录
\[
\mathcal S=\{\bigsqcup_j A_j:A_j\in\mathcal S_j\}.
\]
不同元组在某个N_j内覆盖不同，所以联合主题是真实不同集合，不借重复标签扩目录；分量空主题、零客户及实际重复选择均保留。零个分量不在此k≥1的价格分拆合同内。

以下区分：指定分量完整策略的乘积、菜单自身的分数覆盖/价格、任意耦合联合SPE。前两层的精确恒等式不能免费证明第三层分解。全历史模型见[定义](../定义/共同目录完整历史模型--定义.md)。

# P1：指定完整SPE乘积和根量可加

每分量给一份定义于全部有序历史的纯SPE σ^j。联合策略在每个有序元组前缀投影到各坐标，分别跟随对应σ^j。任一联合偏离元组改变每坐标的行动后，该坐标仍沿其同一完整策略在真实偏离历史的回复。当前玩家的联合收益是各坐标收益和，各分量偏离增益皆非正，故总增益非正；每个联合历史同理。这构造一份完整纯SPE，保留全部离轨平局，不把同计数的不同历史合并。

该选定策略根收益u_i=Σ_j u_i^j、W=Σ_j W_j。事实上终局覆盖可加对任何联合终局均成立。菜单最优值也有与策略无关的等式
\[
OPT_m^{prod}=\sum_jOPT_m^j.
\]
一向由任意联合m主题投影给分量合法m主题；另一向把每分量最优m个选择按玩家索引配对，得到合法联合m主题并达到和。缺少完整Cartesian动作时反向未必成立。

这里W可加只针对给定终局/指定乘积策略，绝不是对**所有联合SPE取最小**也可加。[已有三人反例](../反例/笛卡尔目录的福利非可加性--反例.md)恰区分二者。

# 真正oblivious静态安全值也可加

用[静态混合安全值](静态混合安全值的锐目录计数界--定理.md)的准确顺序：查询分布μ先定，对方选m−1个可任意相关的合法主题背景，但不能看见本次抽出的查询T；查询份额为f_B(T)=Σ_(x∈T)1/(1+h_B(x))。令
\[
v_m(0)=\max_\mu\min_{B\in\mathcal S^{m-1}}\mathbb E_\mu f_B(T).
\]
则v_m^{prod}(0)=Σ_jv_m^j(0)。下界独立抽各分量最优查询，每个固定联合背景的投影都是合法分量背景，期望份额相加。上界用有限minimax的分量最优**对偶背景分布**，独立抽各坐标m−1元组，再按位置合成联合背景；它独立于查询，对每个纯联合主题的期望份额至多分量值之和，所以也界住任何相关查询分布。两边均达到；m1的空背景同理。

这不是观察查询后再布置后继的适应性值，也不证明任意SPE玩家收益≥v_m。对指定乘积策略W−m v_m的聚合差相加；能否为一般耦合SPE支付安全值是另外义务。

# P2：每个坐标共享同一个分数质量t

对t,v≥0定义
\[
F_j(t)=\max_{z\ge0,\,\sum_Az_A=t}\sum_{x\in N_j}\min(1,\sum_{A\ni x}z_A),\quad
B_j(v)=\sup_{t\ge0}[F_j(t)-vt].
\]
权重只是比较组合，不改变提供者纯行动。固定t可行z为有限单纯形，最大值达到；t0全部权0。

任意联合权数组的每个坐标边际都具有**相同总质量t**，客户分数负载只取决于其坐标边际，故F_prod(t)≤Σ_jF_j(t)。反向对t>0取各自最优边际z^j，并置
\[
z_{A_1,\ldots,A_k}=\prod_j z^j_{A_j}/t^{k-1}.
\]
对其余坐标求和恰得z^j，因而达到所有分量最大值之和。t0不作除法，直接全零。因此
\[
\boxed{F_{prod}(t)=\sum_jF_j(t)\quad\forall t\ge0.}
\]
不是把一个t拆成Σ_jt_j；这是整个菜单的精确恒等式，与实际策略是否坐标独立无关。

# P3：达到的非负价格下卷积

每个F_j连续、分段线性、凹、非减且最终常数。可用有限LP表示：z≥0、Σz=t、0≤f_x≤1、f_x≤Σ_(A∋x)z_A，最大化Σf_x；凹性亦由混合可行权与截断覆盖的凹性直接得到。到t=|𝒮_j|给每主题权1便覆盖所有可覆盖客户，其后把剩余质量加到任一主题不降覆盖，所以饱和。

对全部v≥0，
\[
\boxed{B_{prod}(v)=\min_{v_j\ge0,\,\sum_jv_j=v}\sum_jB_j(v_j),}
\]
且最小值达到。任意价格拆分均由P2给Σ_jF_j(t)−vt≤Σ_jB_j(v_j)，是一向。

v0时只能取所有v_j0，选择足够大的共同t使各F_j饱和便给等式。v>0时ΣF_j(t)−vt最终趋−∞，有最大点t_*。若t_*>0，最优性给
\[
\sum_jF'_{j,+}(t_*)\le v\le\sum_jF'_{j,-}(t_*).
\]
非减性使两侧分量斜率非负；可在每个闭区间[F'_{j,+},F'_{j,-}]选v_j，合计v。它们是各凹F_j在同一t_*的支持斜率，所以B_j(v_j)=F_j(t_*)−v_jt_*，求和即等式。若t_*0，则v≥ΣF'_{j,+}(0)；给各v_j至少其右斜率并分配剩余非负价格，合计v，支持直线给各B_j(v_j)=F_j(0)=0。这也覆盖空客户/空主题分量，不需负价格或不可达到的inf。

# P4：最小玩家价格预算的条件保持

对P1选定的分量策略，令a_j=min_i u_i^j，并假设B_j(a_j)≤W_j。各分量最小者可以是**不同玩家**，只需
\[
a:=\min_i\sum_j u_i^j\ge\sum_ja_j.
\]
每个B非增，由P3及可行拆分a_j得到
\[
B_{prod}(a)\le B_{prod}(\sum_ja_j)\le\sum_jB_j(a_j)\le\sum_jW_j=W.
\]
不把第一个≥误写等号。因最优m查询给OPT_m≤B_prod(a)+ma、ma≤W，可得该产品策略half；但各分量预算是实际输入前提，不是本页给任意分量自动证明的性质。[最大质量/交叠条件](最大质量分区与轨道交叠的全实权价格证书--定理.md)可在其明示域提供分量预算，超出域仍需另证。若各分量各自有W_j≥cOPT_m^j，求和也保持同一福利系数，不靠比值除零。

# 任意耦合策略的边界与来源状态

联合完整策略允许一个坐标未来如何破平局依赖所有坐标历史。于是单改一个当前坐标可以改变别处未来收益；任意联合SPE的投影未必是分量SPE。P2–P3仍是菜单恒等式，但不能在投影终局上免费假定B_j(a_j)≤W_j。若各分量每个历史的**全体玩家**续局收益向量唯一，已有[支付唯一分解](全体玩家续局支付唯一的乘积分解--定理.md)另给终局集合分解；这是额外强条件，不由P1推出，也不要求联合策略字面独立。
