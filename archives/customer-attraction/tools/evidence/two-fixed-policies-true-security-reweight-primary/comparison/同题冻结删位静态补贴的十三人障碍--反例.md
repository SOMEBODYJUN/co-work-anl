# 同一删位同题量：SA的现行状态

在[共同目录单位客户完整历史模型](../定义/共同目录完整历史模型--定义.md)，固定完整纯SPE实际叶z、n人、覆盖福利W。逐角色i删其实际行动、在同位置改为同一合法主题T、**其它叶行动保持冻结**，定义
\[
D_T(z)=\sum_{i=1}^n u_i(T,z_{-i}).
\]
全人数SA候选为每份完整SPE每个T都有D_T≤(n+1)W/n。[本批原程序](../资源/同题冻结删位总额的完整策略锥与精确恢复探针--资源.md)检验的正是这个量；它的三小参数阴性不能延续原“SA remains open”作当前全称状态。下面复用一份已经完成全SPE认证的旧实例，直接反该SA。

# 36个不同单位客户、六个不同真实主题

n13、主题A,B,T,D,E,P。客户兴趣及整数人数如下：

| 兴趣 |人数|
|---|---:|
|{A}|2|
|{B}|2|
|{T}|1|
|{T,D}|1|
|{T,E}|1|
|{A,D,E}|3|
|{B,D,E}|1|
|{P}|25|

所有覆盖主题两两不同。这是单位客户、单位提供者的原集合目录，无需同覆盖标签扩展。T恰含三名客户：只接受T者、接受T/D者、接受T/E者各一。

完整策略σ采用[旧冻结自动机](../../tools/evidence/fractional-load-boundaries/original/research/workspaces/customer-attraction/R-c50fecc37aa44fb4a69a2122bb70e5fe/security/refined_tax_k10_packet.json.gz)。压缩原件SHA256 `bad2b15d1abe89d9fa8671df84de8638a4b1ca46279712baa5482abb2bdf18ce`，372216B。它有27243节点、18675决策节点，每决策节点六条观察边，深度0…13、主题计数沿每边增加相应动作；每个有序历史从根按观测行动唯一转移，再执行该节点规定动作，故定义完整策略。相同计数历史可到不同节点，没有将所有SPE限制成计数策略。

其完整SPE真实性复用[已正式认证的旧证书](实际均匀缩放负载的弱付款桥--反例.md)及[已成功全自动机审计](../计算/分数负载四主题族的全历史核验--计算.md)：原36客户逐单位展开、所有节点可达/深度/每条观察边均核，112050项含自身真实IC全部非负、最小差0。底向上从每个规定/偏离孩子沿同一σ比较，有限一步偏离条件给完整SPE。本批没有重新读取全部压缩节点、跑旧audit、另写checker或重授一次PASS；已认证对象是本推论的明确已有前提，而非只凭实际路径杜撰的SPE。

实际叶为P十次、A两次、B一次。P的25客户各被十人覆盖，A侧5客户各被两人覆盖，B侧3客户各被一人覆盖；T的3客户全未覆盖。实际收益为前十二人各5/2、末位3，W=33。A,B,T,P覆盖宇宙36，故OPT₁₃=36。

# 十三次冻结替换的直接证明

任取i，删去z_i后剩余实际标签仍只在{P,A,B}。这三个标签都不覆盖T的三个客户；插入T的当前角色于是独享三客户，收益恰3，与i是哪一位无关。因此
\[
D_T=13\cdot3=39,\qquad\frac{D_T}{W}=\frac{13}{11},
\]
\[
D_T-\frac{14}{13}W
=39-\frac{14}{13}\,33=\frac{45}{13}>0.
\]
这直接反全人数SA的一个合法主题，不需查询最优性、分数背景、改变真实后继或任何新扫描。若用一般逐客户式D_T=Σ_(x∈T,c>0)(n+1)/(c+1)+n|T\C|，同样由c=0得到39。
