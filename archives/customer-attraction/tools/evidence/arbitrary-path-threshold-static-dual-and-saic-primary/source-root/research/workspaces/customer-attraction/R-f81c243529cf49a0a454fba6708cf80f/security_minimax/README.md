## 本轮完成的辨认

尝试的自由分数背景

\[
\Lambda_s(b)=\min_{q\in\Delta(\mathcal S)}\max_{A\in\mathcal S}
\sum_{x\in A}\frac1{b_x+1+s q_x},\qquad
q_x=\sum_{T\ni x}q_T,
\]

**完全是旧对象** \(t_{s+1}(b)\)。整数 \(s\ge0\) 时这一参数映射与旧定义逐式一致；允许实数 \(s\ge0\) 只是静态参数延拓，不产生新的动态桥。

- [旧自由分数接口](../../R-077c0cacfba24288be91dee1acf6d484/security/free_fractional_security.md)：已有凸 minimax、平方价格 KKT、切线下界、合法前缀嵌入和静态覆盖预算。
- [旧额外一单位接口](../../R-51ca8c2b36184c41818099bc490374ca/security/extra_mass_interface.md)：本轮想用的 \(s=r\) 正是已有 EXTRA-ONE-LEADER，不是新门槛。
- [旧几何均值对偶及动态债务](../../R-cd789330fc7141299ac491bbb3ffa420/round3/relay/endogenous_fractional_transport.md)：已有 \(p/y=\max_z(2\sqrt{pz}-yz)\) 推出的联合凹对偶、齐次比值和真实条件尾负载 Cauchy 余额。因此本轮独立重推同一对偶也不新增数学资产。

独立重推时核对的精确边界：\(b_x\ge0\)、有限非空目录、空主题及零客户均可；共轭变量可统一截断到 \(0\le z_x\le(b_x+1)^{-2}\)，然后在紧凸集上使用 minimax。覆盖系数 \(\operatorname{OPT}_m\le(m+s)\Lambda_s(0)\) 的上述形式限空背景；一般背景不能漏掉其利润项。\(s=0\) 时背景分布不影响目标，不能额外要求它支持平方价格最大主题。这些是边界核对，非新证明组件。

## 未支付的真实义务

真正静态安全值 \(v_m\)、自由分数 \(t_m\)、iid Nash 福利 \(Z_m\) 保持不同身份。逐人 \(u_i\ge v_m\)、全分布去相关和弱 iid 福利桥已失败；本轮没有复活这些桥。

对完整 SPE 的全部真实根分支，仅知道当前收益 cap 所有真实偏离收益，仍未由此构造一份对独立查询统一有效的自由背景，也未支付全路径 \(W\ge m v_m\) 或更弱 half 预算。完整根菜单及全路径菜单仍是充分而未闭合的候选；静态凸对偶和 KKT 不能支付真实后继的自适应债务。
