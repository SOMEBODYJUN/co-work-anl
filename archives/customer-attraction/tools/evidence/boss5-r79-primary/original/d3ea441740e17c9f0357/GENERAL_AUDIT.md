# 一般路线独立审查：静态交换、Mfull 与 waterfill 的动态缺口

日期：2026-10-24。身份：本轮独立 proof-audit 分支。对象固定为原始 Q-CAG-HALF：任意有限共同目录、任意人数、全部有序历史的纯 SPE。本文只作独立审查与可复用缺口记录，不提升主命题状态。

## 结论

目前没有一般证明，也没有完整目标反例。已读并重构 `general_half_proof.md`、`owner_hybrid_transport.md`、`fractional_tail_waterfill.md` 以及完整根菜单 `full_root_menu_mixed_obligations.md`。这些正文中的静态代数和单叶 max-flow 关系在各自量词下成立；它们尚未组成可跨真实历史树支付 `OPT_m-2W` 的组合。最短未解义务仍是：把互斥离轨叶的局部信用接成一份全树非负支付，并且每个实际福利单位只花一次。

## 1. owner-hybrid 运输的审查

令 `O` 为固定最优 m 槽并集，`B` 为任意一个完整合法 m 槽终局，`Q_i` 为 owner 分割。`HYB`/`HHYB` 的逐角色子集不等式由“替换角色子集后扩回合法主题，覆盖不超过 `|O|`”直接给出；对 `B` 的 O 外利润，命题 A/B 的有限最大流割条件也逐式成立。关键是这些结论是 **固定单叶静态容量证书**：

* 命题 A 可把该叶 O 外原利润送到该叶的真实遗漏 `R=O\\C`；命题 B 可把调和份额送到 owner-error 库存。二者是可选证书，不是两笔可相加的钱。
* 流边允许指向更早 owner 或跨多个角色。若一条边要解释为原 SPE 的 IC 支付，必须位于某个真实节点的“当前行动—沿原 σ 续局”比较中；任意强制 OPT 前缀或散布锚定后的终局并不自动保留那个节点的原续局。
* 对互斥离轨叶 `B^q` 分别运行 max-flow，不能把各叶容量相加：它们使用同一实际叶 `I` 利润/`G` 取消量作为库存，但发生在不同历史分支。除非另有权重和全树守恒，直接求和会重复花同一份 `W`。

因此正文中的 `SOURCE-NET`（source 初始化可由同叶 `η_i=u_i(I)+γ_i` 支付）是准确的局部关系，但只支付初始化吸收；中间节点的 `K_i^in` 尚没有 `η_i-K_i^src` 的通用上界。将 `K_i^src` 与 `K_i^in` 分开是必要的，不能把首轮支付推广为全树支付。

## 2. Mfull 菜单接口的逻辑范围

完整 `r` 槽矩阵 `K_{t,a}` 的充分条件
\[
\min_Q\max_t(KQ)_t\le u
\]
若对每个背景、每个剩余人数都成立，则确实推出 `u_i\ge v_{m+1}(0)`，再结合共同目录安全值预算可得 half；这条“若 Mfull 则 half”的归约量词没有发现漏洞。

但现有 SPE IC 只给实际节点的真实比较
\[
u_i(h)\ge d_{h,A}=u_i(Z_{h,A}),
\]
其中偏离后续沿原 σ，且查询行动与其续局相关。`K` 的列是任意完整 r 槽静态竞争背景，行与列独立；一般没有理由把某个 `Q` 的静态列均值识别为真实 `d_{h,A}`，也不能把同一节点的一个真实续局替换成另一列后继续使用 IC。故 Mfull 仍是开放的动态菜单命题，而不是由 minimax、meta-Nash 或 waterfill 自动推出。

## 3. waterfill 的适用边界

fractional-tail-waterfill 的共同信用、根/背景返还和尾利润守恒是给定终局的代数引理。降权后的辅助权不是原单位玩家实例；它不继承原 σ 的 SPE，且不同离轨叶的水位/低尾池可能不同。若将同一低尾缺口分别用于多个叶，或在降权对象上再次调用单位玩家归纳，会改变博弈对象/重复计账。它只能作为单叶水位控制，不能直接支付互斥子树的跨树捕获债务。

## 4. 一条可复用的全树检查标准

任何声称闭合 half 的新桥至少需要同时给出：

1. 对每个实际 IC 行 `(h,i,A)`，明确它对应的真实续局终局；
2. 一份全树权重/流，使每个 O 外缺口 token（扣除可取消的 G token）只被送入一次 IC 钱包；
3. 对每个真实玩家或全局总量给出容量界，使用的是实际终局福利 `W=Σu_i`，而不是每个离轨叶各自的 `W(B^q)`；
4. 证明所有锚定/重置后仍处于该 IC 行的历史前缀，或显式支付改变后继的代价。

缺任一项时，静态 max-flow、调和势、终局 waterfill 或 Mfull 都只能给候选接口，不能推出 `|O\\C|−|C\\O|≤|C∩O|`。

## 5. 审查后的精确状态

* 已证（在各自量词下）：真实 SPE 行、分数覆盖前缀预算、owner-hybrid 单叶 max-flow、调和交换核、waterfill 终局守恒、Mfull 若成立则推出 half 的归约。
* 已否定或不应重试：逐人安全值、逐步非负债务、静态 CCE/iid 福利桥、势上升排序、把同叶 A/B 两流相加。
* 未决且一般：跨真实分支的共同非负支付；Mfull 的动态证明或完整目标反例；中间角色 `K_i^in` 的剩余容量界。

本审查不改变 `Q-CAG-HALF=OPEN`，也不把辅助路线失败升级为原命题失败。
