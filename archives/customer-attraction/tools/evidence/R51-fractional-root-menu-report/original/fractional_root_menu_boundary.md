# 真实根菜单的自由分数化仍不足以支付首人

2026-10-21。个人备份中的定义级辅助边界；一般半覆盖、真正聚合安全值桥、自由分数逐人桥均仍OPEN。未认证外审、新颖性或最小性。

用既有36客户三人反例：主题为X0,X1,X2,Y0,Y1,Y2。每个跨组对各一客户；每个“两X两Y”兴趣四元组各三客户。首人选X0；第二人选相反组的最小标签；末人在第二人所属组中选最小未用标签。此规则完整定义全部43处有序决策历史，实际收益(10,12,12)，W34、OPT36。定义级脚本重新展开36个不同客户，Fraction核验258项行动比较，没有调用原审计或规范BI。

首人选任何X主题，真实后继是(Y0,Y1)；选任何Y主题，真实后继是(X0,X1)。把这两个真实背景先取均值负载，再评价查询，允许任意混合参数lambda，所得分数背景是

    L(lambda)=(lambda,lambda,0,1-lambda,1-lambda,0).

令g_A(lambda)=sum_(x in A)1/(1+L_x(lambda))。每个g_A对lambda凸，故M(lambda)=max_A g_A(lambda)凸；交换X,Y把lambda变成1-lambda且不改变M。因此

    M(1/2) <= [M(lambda)+M(1-lambda)]/2 = M(lambda).

在lambda=1/2时，四个普通标签的值为139/15，两个菜单中从未出现的标签X2,Y2的值为161/15。因此这个**分数化真实根菜单**的最优cap恰为

    min_lambda max_A g_A(lambda)=161/15 > 10=u1,

严格差11/15。旧整数菜单值是11；Jensen确实降低值，但降低后仍不能支付首人。

这里还可允许任意总重二的分数负载，只要只用四个标签X0,X1,Y0,Y1。对组内交换及两组交换平均，凸目标不增加；平均后恰为上面的lambda=1/2背景，所以最优值仍是161/15。故不仅两列凸包，真实根菜单的整个标签支持也不足。

这不否定自由分数门槛：总重二均匀分布到六主题时，各标签计数1/3，每个查询值为

    3/(1+2/3)+18/(1+4/3)=333/35 < 10.

因此若要证明自由分数逐人桥，分数背景仍可能必须使用所有真实根后继菜单以外的主题。不能把“分数化”本身当作去掉真实菜单限制的理由。
