本对象采用[完整历史原模型](../定义/共同目录完整历史模型--定义.md)，重点是五人的**必要条件投影**及其证书合同。原来源研究一般人数 half 并称开放，这是当时研究状态；现行[五人半覆盖](../定理/五人半覆盖--定理.md)已有更强结论，六人全目录主目标仍不能由本批升级。源内“改进五人上界”是其相对旧模板的历史比较，不称现行最优博弈界。

## 557行系统及全型域

旧[437行系统](../定理/五人索引最优偏离福利界--定理.md)包含三个固定终局路径 actual=ABCDE、second=AEUVW、third=ABEXY；各真实行动与固定主题/索引主题/旧末回复菜单比较，三类偏离族与实际末两人税比较。完整旧行生成器和全部域已由[旧双证书资源](../计算/五人索引偏离双证书--计算.md)保全，本批未改这些行。现在在同一域加入10条真正末位去对角行及110条**保一份交叠**的同族两查询五模式行，合437+10+110=557。

单个压缩客户 atom 的全部字段如下，位序与数据不可互换：

| 字段 | 数学含义和精确允许域 |
|---|---|
| bits | 依 ABCDEUVWXY 排列的任意十位；1024种全保留，包括实际五主题全0 |
| AB_hist | 五个索引的 (t,r,s) 二元词典序8格非负整数直方图，背景 a+b+t、实际尾部 r,s |
| AE_hist | 同样8格，背景 a+e+t、实际尾部 r,s；其菜单含义仍属于该族 |
| second_hist | (t,h,i,j) 词典序16格直方图，背景 a+t+h、实际尾部 i,j |
| 共同 d | 三直方图各格和5，第一位 t=1 的总数相等，d∈{0,…,5}；不假设更多跨族匹配 |
| menus_lh | actual、second、third 三旧回复菜单的 (ell,h)，0≤h≤d、0≤ell−h≤5−d |
| 客户质量 | 非负实数 w_z；单位客户SPE经除以实际 W>0 得这种点，逆向未证 |

每个8格直方图共 C(12,7)=792 种，16格共 C(20,15)=15504 种。同 d 是这个声明域**唯一**跨族直方图限制，完整主题归属、相同历史策略一致性等仍被放松。目标 W=Σw_z1_{bits前五位有1}，O=Σw_z1_{d>0}。O 是同五个比较主题的并集，只有真实SPE投影中选真正最优五主题时才等于 OPT₅；任意松弛点不自动有此含义。

10个新末位行在每族以自身最后行动对其每一位置菜单作 i≠j 比较，AB/AE各3、second4；客户系数为
\(\sum_i[4f_i-K+z_i]/(p_i+1)\)，pᵢ为**完整末位前缀**负载。110行来自[五等号型](../引理/末两人比较三索引的等号模式闭包--引理.md)的强式：三位族允许重复的位置对各6，四位族10，每对五型，合30+30+50。此处 overlap coefficient=1，不是此前普通弱税的2，更不是“剩一/两人”的缩写。

## 一个全型对偶为什么可有限精确定价

假设557行逐客户系数为 sᵣ(z)，非负乘子 λᵣ 满足对域内**每个** z

\[
\beta\,1_{W(z)>0}-1_{d(z)>0}-\sum_r\lambda_r s_r(z)\ge0. \tag{1}
\]

乘客户质量求和，用557行总slack≥0，立即得 O≤βW。这是通用系数证书；检查某一有限生成列集合不够。真实五人SPE映入该扩大域时也得 OPT₅≤βW。必要行推导与全域(1)两项均必须成立，不能因浮点定价停止便省略其中任何一项。

固定十位和 d 后，原声明域是三个有限直方图集与三个菜单矩形的直积。原独审记录：**所选最终51个活跃乘子**的加权分数可写成固定项＋三族各自分数＋三菜单仿射项。新末位及110个同族 pair 行都只涉及本族背景/查询联合计数，不引入跨族直方图乘积；最终活跃 pair 行仅3条，均 query_equal。对于该特定证书，以上分解保全条件最大值。

写 r=ell−h，菜单域变矩形 [0,d]×[0,5−d]。仿射目标在四角达到最大，换回 (ell,h) 为 (0,0),(d,d),(5−d,0),(5,d)。d0或5造成重角不影响完备性。于是所有1024×6=6144个条件最大化可覆盖全域，不需枚举三个直方图的笛卡尔积。不能将此结论无条件推广为“任何新增跨族行/任何dual都可如此分离”；[跨族引理](../引理/跨族末两人菜单的共同锚点与运输界--引理.md)另证明160个常锚点行的特殊加法性质。

原最终对偶的精确值为

\[
\beta=\frac{178528430822287579296070598592537012737}
{87421565922360356032366460363114422206}
\approx2.042155490337931>2. \tag{2}
\]

原51乘子的共同分母 D=2010696016214288188744428588351631710738，β缩放分子 B=4106153908912614323809623767628351292951，B/D=(2)。原独审从18条活跃固定路径旧行、各局部hist行和交叉菜单计数重建；query_equal literal 系数写为

\[
4\sum_iH_i-\sum_i\left[a_i(B_q+C_q-z_i-w_i)-b_i(K_q-z_iw_i)\right],
\]

这里 B_q,C_q,K_q 是查询计数，**不是证书分子 B**。每个小系数用 Fraction 形成并检查×120整数，先普通整数数组，乘大乘子前转任意精度 object 整数。原残余是
\(120(B\,1_{actual>0}-D\,1_{d>0})-\max\_weighted\_score\)。原记录6144条件、126缓存score contexts、最小整数残余0、84个零条件、无负条件，约24秒，无optimizer。dual SHA256=6cc1849b3808d773a317efd64c6ed6df59ce89a589a06a303e9edc297f3d9d34。

**本轮边界：**该dual JSON、原 full_pricing.py、exact_dual.py、独审py/json本地均缺。不能新核51个具体权重/6144残余，也未新跑原CLI。上段是已完整读过的原数学审查合同及其正确系数证书方法，保原内部审核身份，未冒本轮全型再认证或外审。

## 新60点的精确核验与补全排除

选定 JSON SHA256=11a26c56faca5a3331a4f2ab002455aa6ca115f999ddde2eced6f1edd39c0825。60个 exact_mass 都正，直方图/共同d/三个menus完整合法。本轮新入口复用旧已保存437行直接 evaluator 的**函数前缀**，仅给此新60输入求值，不运行其旧点、原CLI或全域loop；新增10+110行在新入口直接按定义重建。因此“557行本轮全重算”属实，“557行全新独立实现”不属实。所得

\[
W=1,\quad O=\frac{2725847356017648591471919167969344197315230264965724495326063}
{1334877864577492211163101746002771267620679960595833383468365}>2,
\]

全部557行与JSON逐值一致、70行零。由此它确实否定**此557行松弛单独蕴含 O≤2W**，不能称原博弈half反例。

其新增跨族行却为负。令
\(D_*=8009267187464953266978610476016627605724079763575000300810190\)。本轮一次新定义入口对全部220个跨族 pair-orbit 行，在每个客户标签组内枚举不同 target tuple 配对取最大，得恰两条负行：

| 行（菜单位置从0起） | 精确总slack |
|---|---|
| AB source / AE 的 R,S，即位置1,2，j=k≠i | −418058084905719698435797557678947212405584977791912172052053 / D_* |
| AB source / second 的 I,J，即位置2,3，j=k≠i | −787666402463169489247192662090163381396856775798217752504989 / D_* |

共13200个原子上包络系数，5256个去重合法配对；5280次 E/F 闭式吻合、9600次常锚点 additive row 吻合。前两负行都属 sourceAB，p=a+b+t 组内常值，其负值是每种配对共同的 literal 必要行缺额，不依赖选了某个不利配对。因此不存在保这些记录边缘的完整SPE补全；排除不是“某一次独立lift失败”。

另单独核了 AB末位 source 对 AE 的 R,S 的共同 OO 行：

\[
-1996456868586172483674258348477230789698004041227208957222543/D_*<0.
\]

两个分别offdiag包络也已各自为负。该新点的排除**不能**归因于 joint 强于 separate；一般严格加强由[末位定理](../定理/真实末位菜单的共同归属上包络--定理.md)的q2代数例证明。原作者报告162个joint末位行中22负、9720匹配检查，而且每条负joint都已有负component；本轮只核上面指定一条，未冒重核全部162。原64点另有两个single component都正而joint负的原报告，原42点亦有旧匹配报告，均未重跑。

加行排除此60点，不等于排除所有 O>2 点。原61点已经加入160常锚点行仍O>2，正说明排点与普遍模板界不同；原数据本地缺，本轮不冒新认证那个61点。完整SPE与真实OPT仍比任何这些有限必要行更强。

## 独审入口中的其他对象与后续状态

2744B独审入口将四件任务并列，不能把其审查身份相互代用。shared_envelope_review 检查逐客户 extrema 并给合法两客户 global gap；full_pricing_review 只为51λ全域上界负责。iid_bridge_status_audit 与 iid_mixture_cap_review 是另外两份MD，本轮只为入口解义完整旁读，无primary receipt。

前者由既有八客户完整SPE的 W6 和任意静态CCE福利≥544/87，利用对称iid Nash 属CCE，推导 Z₃>6，否定更强 W≥Zₙ；其显式 Nash 给 Z₃=(4344−156√669)/49。这个闭包已由[正式iid反例](../反例/独立同分布福利支付--反例.md)自足保全，并非新实例、非half反例，亦未否 W≥nvₙ。后者区分共同边缘iid的任意latent混合与不同边缘独立乘积：前类因各query对共同q凸、Jensen可被均值q同时压低，八客户最优cap=(1448−52√669)/49>2；不同边缘独立产品却达到真实44/23。故不能声称必须相关。原二次数域审计1728 Jensen实例仅属其原记录，本批不将入口阅读冒作那两primary或新的数域运行。其独有完整数学可继续从对应来源整理。

原独审对“不同真实续局的分母向量不一致”的初始判断是研究动机，未证明无任何一般支付路线。静态smoothness、冻结回复、非负前缀债和错误普遍税lift各有原障碍域；不可从入口描述推出原half不可能。本批不做新颖性认证或外部同行评审。
