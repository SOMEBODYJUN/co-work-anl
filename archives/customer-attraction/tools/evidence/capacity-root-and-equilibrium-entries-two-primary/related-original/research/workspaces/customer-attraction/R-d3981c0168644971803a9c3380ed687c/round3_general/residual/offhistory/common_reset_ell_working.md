# 同 reset 的 fresh 列与真实 off-history IC：未闭合推导

2026-10-24，residual/offhistory。对象是任意有限单位客户、共同有限目录、任意人数、全部有序历史上的原纯 SPE。主目标与 FRESH-RESIDUAL 均 **OPEN**。本稿未得新的共同容量不等式；下面把真 ell 接到共同 reset 的位置写清，避免将逐节点约束误当多来源付款。

## 1. 精确共同列

固定 actual 叶 Z、覆盖 C，角色 k 与行动 a≠Z_k。置 A=finish(Z_<k,a)。同一组 G_(k,a) 包含所有当前角色为 k、规定行动为 a 的已生成自然 context t=(g,k)。其规定叶记 B_t，fresh 分母为 ν_t=u_k(B_t;N\\C)，原流系数为 β_t=h_t/ν_t。

若未来目标 r=(A_<j,j) 的首次偏离 actual 的位置为 k，则任何原正 reset 边的 parent 都在同一个组 G_(k,a)。证明只用有序前缀：在角色 l reset 得到的叶在 l 以前等于 actual；若其后继首次偏离 actual 于 k，必有 l=k 且 reset 行动为 a。直接初始化另外只能来自 owner k 的 query a。不能把同叶但不同有序历史混同。

对 x∈a\\C 且 x∈A_j，来自这一个 parent 组的 fresh 列密度（以 A 中 j 对 x 的份额 1/c_A(x) 计）恰为

    Λ_(j,x) = Σ_(t∈G_(k,a), x∉(B_t)_j) β_t/c_(B_t)(x).

因此

    Σ_(t∈G_(k,a)) β_t q_tj
      = Σ_(x∈a∩A_j\\C) Λ_(j,x)/c_A(x).

若同一个 owner-k 初始 query 还给 r 注入 θ_(j,x)/c_A(x)，则总 incoming 逐客户密度为 θ_(j,x)+Λ_(j,x)。坐标初始化保证初始 θ≤1，但没有保证其与 Λ 的和≤1。若能证这个逐客户界，则 h_r≤ν_r；这仍强于真正需要的角色净券容量，而且即使逐 context β≤1成立，也不能直接把同角色全部 context 相加。

本式的实际用途是指出需要被 IC 支付的共同量。它不是 Λ≤1 或 FRESH-RESIDUAL 的证明。

## 2. ell 在该共同组中的真实位置

对每个 t，令

    X_t=u_k(B_t;C),
    z_t=u_k(finish(g,Z_k)),
    ell_t=ν_t+X_t−z_t≥0.

此 ell 来自真实 g 上返回 actual 主题 Z_k 的完整 IC。因为 Z_k⊆C，z_t 完全是 C 收益。组内 reset 叶 A 固定，故 D_F=u_k(A;N\\C) 固定。fresh LOSS 给

    ν_t−D_F=P_t−N_t.

合并两式得到精确关系

    D_F=z_t−X_t−P_t+N_t+ell_t.

令 Γ=Σ_tβ_t。该组当前净券恰为

    K_(k,a)=Σ_tβ_t(ν_t−P_t)
             =ΓD_F−Σ_tβ_tN_t
             =Σ_tβ_t(z_t−X_t−P_t+ell_t).

这已经是在同一个 reset A 上的共同加权关系，不能再将每个 t 的 u_k 独立领一次。但它没有给 Γ 的上界；最后表达中的 ell 为正号。若保持原 ν/P、同一流和质量守恒，就不能从净券再额外减去 β_t ell_t。另改分母、删边或重算流需要另立量词，不能称为原 ν 路由已经给出退款。

组内真实返回叶 finish(g,Z_k) 依 g 改变，z_t 是互斥真实叶的收益。尚未证明 Σβ_t z_t 可由同一 actual k 钱包或同一实际客户券共同控制。把 z_t 各自支配于一份 actual u_k 也无合法理由：它们不在 actual-prefix。

## 3. 比较所有源主题：有真 IC，但未得到总权重

在每个真实 t，上游任何最优源主题 T_i 仍是合法行动。写

    Q_t(i)=u_k(finish(g,T_i)).

完整 SPE 的确给 ν_t+X_t≥Q_t(i) 对所有 i。对任意 λ_ti≥0、Σ_iλ_ti≤1，因收益非负，还有

    ν_t+X_t ≥ Σ_i λ_ti Q_t(i).

它保留完整真实后继，不能将 Q 替换成冻结未来收益。若 λ 取按来源 incoming 比例 h_t^i/h_t，则该约束只限制来源组成；整体放大全部 h_t^i 时不变。要将未归一化的来源权重直接放进右边，仍须另外证明其和≤1，正是当前缺口之一。

这不排除全部目录 IC 与最优 T 交换共同产生一个新的跨 context 约束。当前尚未找出这种约束；本稿没有将“可与全部 T_i 比较”算成一般福利推进。

## 4. 真实非零 fresh 核种子及其准确域

`positive_fresh_candidate.json` 保存一个用于检验上述普遍候选的真实有限实例和完整策略；`audit_positive_fresh.py` 不导入发现程序，逐个重放全部156个有序历史、780项含自身行动的完整 IC。客户按主题兴趣 mask 的整数重数给出，展开后均为单位客户。

以0为起始标签：actual Z=(3,4,2,2)，u=(114,106,199/2,199/2)，W=419，OPT_4=434。actual 外客户共19个。

在 g=(0)、当前角色2（数组下标1），规定 a=1，

    B_t=(0,1,2,2),   A=(3,1,2,0),
    ν_t=10,  D_F=10,  P_t=1,  N_t=1,
    ν_t−P_t=9,  ell_t=29/4.

唯一正 fresh 边到角色4，q=1。故“真实 SPE 一定没有正 fresh reset 边”的更强假设是错的，且 ell 可严格为正时仍有真实正边。该例只用于核的非零域验证，**不是合流容量反例，也不是 Q-CAG-HALF 反例**。

尤其，对此例任何最优 T 及任何匹配，R-only 每个 owner 的库存都不超过 |R|≤19，而全部 actual 收益至少199/2。因此 R-only 极大 current 初始化把所有 fresh 来源当期吸收，没有初始 future source，不能声称上述自然 context 被该初始化实际到达。若在该 context 人工注入质量，只验证允许任意自然 context 注入的 ν 核，不验证目标初始化。没有继续把这一非目标注入扩成局部合流专项。

另直接核了原 all-O 坐标极大 current 初始化：能够生成 g=(0) 的初始查询必须是 owner1 的 T_1=0。最优主题多重集唯一为{0,1,2,3}；六个此类匹配的该行剩余分别为959/12（两次）、277/4（两次）、467/6（两次），均≤u_1=114，所以其最小 future 均为0。自然角色1在 actual 空前缀只规定3，不能作为另一个正 reset parent 到 g=(0)。因此这种极大 current 选择亦不实际到达该正边。允许非极大 current 的合法分配可能刻意注入它，未声称所有允许剪枝均不可能到达。

## 5. 接续义务

真正要证的仍是同一最优 T、坐标剪枝、I直接付款、R真实初始化和从头重算的 ν 路由共同满足各角色 K_l≤2u_l−d_l−H_l−J_l。上面的 Λ 精确式和 ell 组内式都没有完成该不等式。

下一条有实质价值的关系必须把不同真实 g 的返回收益 z_t 或全部源主题比较，接到同一实际剩余钱包；不能只对任意外生注入证明局部安全，也不能以无正边的旧 fixture 回归称目标 fresh 传播已被真实激活。
