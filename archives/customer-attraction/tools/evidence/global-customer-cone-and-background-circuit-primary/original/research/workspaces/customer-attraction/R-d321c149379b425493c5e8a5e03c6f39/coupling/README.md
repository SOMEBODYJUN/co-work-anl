# 共同非负客户耦合：本轮工作备份

2026-10-21；目标 Q-CAG-HALF 仍 OPEN。本目录均为研究备份，未经独立外审。

- `global_pair_moment_coupling.md`：把二阶覆盖矩精确改写为带根割锥；由整数二次正性给任意人数的全局客户耦合不等式。给一个**任意人数**的共同有符号客户族：全部终局收益非负、全部锋利同主题稀释、同支持守恒、覆盖单调和全部两标签局部非负矩均成立，但全局三标签耦合严格失败。该族不是合法客户实例，亦非half反例。
- `arbitrary_background_pair_circuit.md`：任意多标签背景的正项回路夹逼、隐藏客户信用及其可用性边界；五人最小七槽提升障碍的精确满秩证书。
- `verify_coupling.py`：独立标准库 Fraction 检查。通用恒等式和不等式由正文证明，有限数值检查仅审计实现。
- `verification.json`：冻结本次运行输出。
