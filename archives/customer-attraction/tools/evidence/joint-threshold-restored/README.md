## 本次新增的实质判断

signed作者的一个固定参数策略、counter的一般参数规定控制器和root原始BI合成表不完全相同。它们代码都自含单位客户收益且互无模型导入，说明实现依赖分离；counter已收合同及后续动作/费用规则，不能因此称机制无提示独立发现。作者程序使用循环经济标签，counter用最小非根标签；root用`min(feasible)`按根利润和动作索引选最低可信叶，并对其余第二行动选最低第二利润的真实末位BR。

具体有两项可复用差异：

- a2/b1/q2、强制根4=(0,1;0,0)：作者保存叶(4,11,12)，counter规则给(4,3,20)，root保存叶也为(4,3,20)。两者同根收益4、第二收益5，显示相同机制的具体标签不同。
- a3/b1/q2、根0：counter规则给(0,19,32)，银行由第二全异根、末位全复制根，根/第二收益(7,8)；root原表给(0,16,35)，银行由第二全复制根、末位全异根，原表根/第二收益(7,7)。同一最低根值有实质不同的达到叶，不应把所有实现称同一策略。原作者固定输入程序不包含此参数。

这些差异由已读源码规则、资源计数手算及原保存动作直接比较，未运行任何一个控制器、效用或BI函数。没有把原输出的根利润标量用作新执行事件。

三份完整根策略都规定根0，对所有根后的有序历史补齐动作并比较所有根替代；aggregate另一入口只认证强制根后的孩子，不含根IC。K36单点的47988项包含1333自身和46655非自身；counter六点240198为显式gap比较，root七点150912则把全部末位收益的BR分类与第二/根IC合计，操作口径不同。目标叶与低退出叶仍分开，signed费只作代入，均非half负种子。
