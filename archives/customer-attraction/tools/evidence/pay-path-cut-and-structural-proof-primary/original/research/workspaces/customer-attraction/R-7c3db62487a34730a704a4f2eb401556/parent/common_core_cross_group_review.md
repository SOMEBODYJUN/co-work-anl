# 独立审查：任意尾数、任意跨组脚印的共同奖励屏障

2026-10-23，主代理内部解析审查。先收到原 RT-r 精确陈述独立重构，
后与 harmonic 分支分别核对跨组加强；最终读取 construction 的 CC-r-v2。
本页不认证外审或新颖性，不改变一般 Q-CAG-HALF。

## 精确审查范围

任意 k,r≥1；不交块 X_j、P_j、B、E，所有大小非负整数。
目录含 C_j=X_j、A_j=X_j∪P_j、D=B∪E；其余每个主题要么是
X∪P 的任意子集，要么是 B 加上 X∪P 的任意子集。只有 D 允许碰 E，
所有公共主题均含全部 B。假定一份完整纯 SPE 的实际路径为
C_1,...,C_k,D^r。

CC-r-v2 结论 a_k≤x_k/2，以及同一目录中任意纯局部 A⊇C_k 的
β(A)=|A∩X|/2+|A∩P|≤x_k，均通过本次内部审查。
均匀 x_j=x、a_j=a 时，OPT=k(x+a)+b+d，故 2OPT≤3W。
非均匀组只有最后组结论，不能偷换为全部 j 的结论。

## 独立重构的机制与攻击

实际末位 D 的真实最佳回复比较给纯局部 β(T)≤U=(b+d)/r，
公共脚印 β(V)≤d/r。最后 C 改 A_k 后，全部 X 仍至少覆盖一次，
新增 P_k 覆盖一次；每个响应者可在任何真实历史选择 D 保证至少 U。
因此纯局部收益至多 U；碰到 P_k 会严格低于其 β 上界，不能被选。

有两个纯局部响应时，后一个改 D 可保证 (b+d)/(r−1)>U，故至多一个。
d>0 时纯局部不能在公共响应之后；若唯一纯局部在公共之前，
公共响应实际至多 b/(r−1)+d/r，而真实改 D 可保证 (b+d)/(r−1)，
严格更高。因此纯局部和公共脚印不能混用。

全公共时 B 的每人份额固定为 b/r。响应者真实保证与实际末位上界
共同迫使其脚印收益逐客户精确达到 β(V)=d/r；因此 P_k 不被再触及，
X_k 也不能被两个响应者覆盖。若仅有一个纯局部，则相同目标结论直接成立。
最后 C 的 A_k 偏离至少得 a_k+x_k/2，其原收益为 x_k，完成比较。

关键严格性检查：U>0 由反证分支 a_k>0 和末位菜单保证；r=1 不用
r−1 分母；d=0 则末位比较强制所有公共脚印为空，至多一个纯局部已足够。
b=0 和空块均不破坏逐客户上界。所有反事实都保留原策略的真实后继，
没有使用静态 Nash 或冻结未来。

query 变体的新增客户若属于旧 X，则响应者所得从 β 中的 1/2 严格降至
至多 1/3；若属于 P，则从 1 严格降至至多 1/2。故所有响应避开 A\C_k。
原 C_k 客户至多再覆盖一次，偏离者得到至少 β(A)。U=0 时末位比较
直接给 β(A)=0，避免借用正 U 分类的严格步骤。
