# C7只否定“未来利润保底足够”的静态安全动作引理

2026-10-24。**不是完整SPE反例，不否定GLOBAL-EXTRA-FLOOR、2m逐人OPT界或Q-CAG-HALF。** 本页仅记录一次明确一般候选的精确检验；没有扫描人数、目录或参数。

## 1. 所检验的一般引理

本轮真正候选GLOBAL-EXTRA-FLOOR为：原零背景m人完整SPE的每个实际玩家均有

    u_i ≥ δ_(m+1)(0),
    δ_(m+1)(0)=min_(q∈Δ(S)) max_T Σ_(x∈T)1/[1+m q_x].

它若成立，由既有静态比较OPT_m≤2mδ_(m+1)得到half。这里δ的竞争质量是整个根人数m；不能换成当前位置余r人的局部δ_(r+1)(b)。

一个曾考虑的归纳简化是：固定根m、任意合法旧前缀及剩余r人，取t=δ_(m+1)(0)。是否必有某个合法A，使任何r−1个未来动作只要每位未来玩家最终利润≥t，就不能把A玩家的利润压到t以下？若这条静态SAFE-ACTION成立，未来玩家保底的深度归纳就能给GLOBAL-EXTRA-FLOOR，而无需另外使用他们的完整IC。

下例否定这条静态简化。它不能取代对未来最佳反应的分析。

## 2. 七个单位客户、七个共同主题

客户是七环C7的边e_j={j,j+1}，索引模7。每个客户价值一。主题S_j恰包含与顶点j关联的两个边客户，即{e_(j−1),e_j}。人数m=3，旧背景为空。

对任意主题分布q，自由分数竞争质量为3；边e_j的负载是3(q_j+q_(j+1))。统一q_j=1/7时，每条边负载6/7，每个主题插入值为14/13，所以δ_4≤14/13。

反向，对任意q，最大主题值至少主题均值，而每条边在该均值中出现两次。因此

    max_T g_T(q) ≥ (2/7) Σ_(j=0)^6 1/[1+3(q_j+q_(j+1))]
                 ≥ 2/[1+6/7] = 14/13.

第二步是倒数凸性，七条边的平均负载恒为6/7。故**真正自由分数值精确为δ_4=14/13**，不只是某个固定背景上界。

## 3. 每个当前动作都有“高利润未来”压低配置

当前选任意S_j。令两位未来玩家分别选S_(j−1)、S_(j+1)。当前的两个边客户各被两人分享，利润为1。每名未来玩家各有一名独占边客户和一名共享边客户，利润均为3/2。于是

    u_current=1 < 14/13 < 3/2=u_future1=u_future2.

该构造对所有七个当前主题由旋转同时成立，故没有SAFE-ACTION。它不是只对一个动作失败。

但这些未来动作**不是SPE继续**：在前缀(S_j,S_(j−1))之后，指定末位S_(j+1)只得3/2，改选S_(j+3)可得到两个完全未覆盖边客户，利润2，严格改善1/2。因此本例没有给原游戏的完整SPE，更没有给GLOBAL-EXTRA-FLOOR反例。

## 4. 正确停止线

已经证伪的只有“所有未来玩家利润≥全局门槛”这一静态充分替代。全局门槛、逐人2m u_i≥OPT_m及原half仍OPEN。未来真实SPE的最佳反应和更早离轨IC不能继续丢弃；本页不据此宣称全局门槛不可能证明。
