## 1. 全部13行确实来自同一份完整策略

记原完整实际路径为 `(A,B,C,D,E)`。在第三位精确历史 `(A,B)`，过去负载
`p=1_A+1_B`，当前原收益为 u。选同背景权重 `1/(p+3)` 最大的一个合法主题 H，
强制当前改选 H，随后沿原σ得真正 Q,R。逐客户 hidden bits 为 h,q,r，完整分母
`s=p+h+q+r`，`V_H=h/s,V_Q=q/s,V_R=r/s`，零分子项取零。

令 M 为共同目录的一个最大裸主题（代码 m），Z 为原最大根分支的末位合法主题
（代码 z=`max_bits[4]`）。X,Y 为旧固定合法主题。三个旧索引 family 中的菜单
也全部由同一目录中的合法主题组成；不要求它们是 H 分支的真实回复。

当前整数支持为：

| 行组 | 权重 | 合法性 |
| --- | ---: | --- |
| source IC `u−V_H` | 8251 | 第三位原节点偏离 H 后沿原σ |
| H 加权大小分别支配 Q、R | 4703，5446 | 同背景同一个最大 H |
| 真 R 对五个 OPT 主题的末位 IC 和 | 165 | `5V_R−d/(p+h+q+1)` |
| 裸 M 大小支配 H | 307 | `|M|−|H|>=0` |
| 真 Q,R 两人税对 `(X,Y)`、`(Y,Z)` | 92，66 | 同一固定背景 `(A,B,H)` |
| AB 的末位菜单 × OPT 的两人税和 | 2 | 全部25个合法比较对 |
| H 加权大小支配 AE 的五末位菜单 | 925 | 五个同目录比较主题 |
| Sbranch 的 `(U,X),(U,V),(U,W),(V,OPT)` 税和 | 15，7，17，4 | 长度5/1或5/5的全笛卡尔比较对 |

各行均为同一原σ的必要关系；没有 AP、BNS 或将祖先原利润当作这个新孩子的
利润 cap。强制第三位的 H 不被假装成最优动作，但其后 Q,R 所在的末两人子博弈
确为原完整 SPE 的一个子博弈，允许应用末两人税。

为核对税公式，背景 `b=p+h` 下令

    Htax=V_Q+V_R+q/[(b+1)(b+2)].

旧两人税精确给 `Htax>=R_b(T,S)`，其中比较两主题的剩余玩家总利润为

    R_b(T,S)=(t+s−2ts)/(b+1)+2ts/(b+2).

它由同一原σ的三条真实IC及非负交集余项得到，不需要将原σ终局视为静态NE。
对长度 n_a,n_b 的菜单逐对求和，其会员次数 a,b 给

    n_a n_b Htax − (n_b a+n_a b−2ab)/(p+h+1) − 2ab/(p+h+2)>=0,

与 `raw_blocks.tax` 一致。相同菜单、重复主题及同一槽的对角项无需删除；全部
笛卡尔对都是合法比较。这里的“原行”指该747行/投影模板的合法基础行，其中税行
本身是上述三IC的已证组合，并非声称每条税行都是一条单节点IC。

## 2. 八个 hidden 状态取最大：方向正确

固定这13个非负整数乘子，对一个真实客户 x 令 `G_x(h,q,r)` 为加权原行系数。
同一份原策略给全部客户共享的真实 H,Q,R，故

    sum_x G_x(h_x^true,q_x^true,r_x^true)>=0.

定义投影系数 `phi_x=max_(h,q,r in {0,1})G_x(h,q,r)`。逐客户取最大只是向上松弛，
所以 `sum phi_x>=sum G_x(true)>=0`。不要求各客户分别选出的最大 hidden 状态
能拼成同一套真实主题，必要性仍保持；也不能把这一步解释成逆实现性或完整消元。
相反，若取最小则无法得到这个方向。代码保留全部八状态，未用逐客户假最大性
或局部IC去删状态。

最终13个整数乘子本身给出一个精确定义的行。它们由有理乘子近似取整而来只属
发现过程；合法性只需最终乘子非负，分离只需最终 exact slack 严格负。

## 3. 单 cut 的条件化 family 分解

先固定旧十位 bits、最大根五位 bits 与共同 OPT 会员次数 d。d 虽由 AB_hist 读出，
在定价时必须作为三个 family 的**共同已固定参数**；每个 family 的 hist 都限制
到这个 d。再固定 hidden 状态 h,q,r。

检查 `raw_blocks`，AB 只含本族 mY 与 d，AE 只含本族 mY，Sbranch 只含本族
mU,mV,mW 及其同族乘积。没有 AB×AE、AB×Sbranch 或 AE×Sbranch 项。因此，
若旧 score 在这些固定参数下已有三族相加的分解，新 raw score 保持同一分解。
所谓独立最大化是在原定价模板的条件化矩形域中；若另增加跨族一致性限制，须
重新核对，不能无条件宣布真实游戏全部关联都已枚举。

对单条投影行的乘子 `mu>=0`，有限域上有精确关系

    max_hist [old(hist)+mu max_state G(hist,state)]
      =max_state max_hist [old(hist)+mu G(hist,state)].

mu=0 也成立；负乘子则不能把它当作同一 max 公式。固定 state 后，三族可分别
最大化再相加，前提正是上段已固定 d 和旧背景参数。单纯先 max 三族原行再把其
结果凑成一个不存在的共同 hidden，是另一个操作，不能混同。

## 4. 当前13支持集可把八状态精确压成两状态

对一个 tax，唯一 q/r 依赖的 family 常数是 `n_a n_b Htax`。先将这些项移入
fixed，不能把包含 Htax 的整个 family 字典直接说成 q/r 无关。

按当前整数权重，AB 贡献 `2*25=50`，Sbranch 贡献
`15*5+7*25+17*25+4*25=775`，合计825。加上原 fixed 中两条税的
`92+66=158`，总 Htax 系数恰为 **983**。

完成这一步后，每个 family 的剩余项只依赖 h,p 与本族计数。AE 的 cap 本来
就不依 q,r；真 R 对 OPT 的末位行只含共同固定 d，可完整留在 fixed。
故存在精确分解

    G(hist,h,q,r)=F(context,h,q,r)+G_AB(hist_AB,h)
                              +G_AE(hist_AE,h)+G_S(hist_S,h),

从而

    phi(hist)=max_h [max_(q,r) F(context,h,q,r)
                    +G_AB(hist_AB,h)+G_AE(hist_AE,h)+G_S(hist_S,h)].

`max_(q,r)F` 在固定旧 bits、d、max_bits 和 h 后只需四个数。因此单 cut 正乘子
定价可在 h=0/1 外层各运行原条件化32状态流程，保持精确，且无须扩展 family
hist 的维数。这个压缩依赖**当前13支持集**：例如将来加入一个 R 对非固定族菜单
的末位查询，其 `menu_count/(p+h+q+1)` 会造成 q 与 hist 交互，必须重新检查。

对本次固定整数权重还可更精细：扣除所有 q/r 无关常数后，其 q/r 相关项恰为

    Fqr=(983q+1808r−8251h)/(p+h+q+r)
        −(4703q+5446r)/(p+3)−165d/(p+h+q+1)
        +983q/[(p+h+1)(p+h+2)].

第一个分式在 h=q=r=p=0 时按零分子项取零。它只依 p,d,h,q,r，所以四数最大
本身可按 `(p,d,h)` 的36个条件缓存，而不是随其余 old/max bits 重算。任何这样
实现仍应精确核对最终系数等于原 max8；此简式不自动适用于修改后的乘子支持。

## 5. 多 cut 不能误用同一个 hidden 状态

若已有多条分别定义的投影行 `phi_l=max_state G_l`，正乘子和应定价为

    old+sum_l mu_l phi_l
      =max_(state_1,...,state_L) [old+sum_l mu_l G_l(state_l)].

即使各行原本都由同一个物理 HQR 导出，**分别向上投影后的数值**也不能强制共用
同一个 state。简单例子是两行在两个 state 上的值分别为 `(1,0)`、`(0,1)`：
各自 max 之和为2，共用 state 后 max 和只有1，会低估待定价系数。
本节压缩后同理：分别投影的多 cut 一般需要各自的 h_l 外层，而不能免费共用 h。
先把原行按乘子相加再投影可另定义一个合法新行，但那是不同于“已有各 cut
正乘子和”的系数，必须单独说明与证明。
