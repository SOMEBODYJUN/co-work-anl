## 精确强版

任意五人原模型、任意完整历史纯 SPE，实际主题为 A1,...,A5，实际最终收益
为 u1,...,u5，W=sum ui。对每个合法目录主题 C，都有

    4W - 5u1 - 4|C| + |A1| >= 0.                 (AU)

C 无须最大，也无须包含 A1。若 C 为最大主题，K=|C|>=|A1|，则

    4W >= 5u1 + 3K.

保留裸大小的 (AU) 更强：`W-K >= (5u1-|A1|)/4`。右端非负，因为实际
A1 每个客户的最终负载至多五。该结论不是 `OPT5<=2W`；尚须对照最优覆盖付款。

## 合法 SPE 行与精确恒等式

在实际第 i 位的有序前缀改选 C，依同一原策略行动，最终负载至多
`b_i(x)+6-i`，其中 b_i 是该实际前缀负载。因此真实 IC 给出

    R_i(C)=u_i-sum_(x in C)1/(b_i(x)+6-i) >= 0,

对 i=2,3,4,5 分别取权重 5/4,19/9,11/3,4。逐客户 actual membership
为 a=(a1,...,a5)，query membership 为 c，s=sum a。分子为零的收益项取零。
定义

    rho(a,c)=4*1[s>0]-5a1/s-4c+a1
             -sum_(i=2)^5 lambda_i*(ai/s-c/(sum_(j<i)aj+6-i)).

全部 `2^6=64` 种允许状态都有 rho>=0。于是精确恒等式

    4W-5u1-4|C|+|A1| = sum_(i=2)^5 lambda_i R_i(C)+sum_x rho(a_x,c_x)

证明 (AU)。这里只用各偏离终局的负载上界，没有冻结任何后继；不将相同计数
的历史认同。任意平局和全部离轨历史由原完整 SPE 的 IC 提供。重复、空主题
与零客户均在上述 64 状态中，所有使用的分母至少为一。
