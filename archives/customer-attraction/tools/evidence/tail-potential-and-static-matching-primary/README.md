## 输入身份与复现

所有主源与重放依赖在`source-root/`按完整原路径保留。运行原静态匹配入口时必须恢复固定的examples集合，因glob会消费新增输入；原main会覆写邻接JSON。应先在独立目录按清单校SHA恢复所需入口及其输入，不在原件上执行。ONEGAP正缺口时原main不另存其最坏完整策略；本包不能把另一个W85证书当作W84最坏策略。

M2四背景的前缀长度分别1、2、2、3，全部是合法主题前缀，但不能说四个都是同一五人博弈恰剩两人的完整子局。保险族的正参数只定义一个合法子族，完整模型的空主题、重复、零客户、全部离轨历史和平局仍保。五人半覆盖已另证；一般ONEGAP、弱静态匹配与六人目标不因有限阴性而关闭。

来源、比较和第三阶段关系的逐项依据在[relationship-review.json](relationship-review.json)与[comparison-manifest.json](comparison-manifest.json)。它们从实际公式、程序语义和输入身份产生，不导入旧图冒充本批完成。逐源done仅在父方显式checkpoint并确认所有资产已推送之后提交。
