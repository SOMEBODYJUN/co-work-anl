# 独立一般机制研究与交叉攻击

本目录只存本轮独立研究资产，不表示共享命题已提升。目标始终为一般 `Q-CAG-HALF`；未证明该目标，也没有合法反例。

- `disjoint_policy_gluing.md`：无界分块的局部政策调度粘合充分引理及其half边界。父方发现、本人逐客户独立重构：共同封块cap与全员L保底直接给OPT≤mL+τ≤(2−1/(n_max+1))W，故其本身不能产half反例，跨块人数重分配也已受控。它把现有弱 theta 复制例的可复用部分抽象成可检查合同；并非该复制例的新发现。
- `child_profit_state_review.md`：独立审查通过的归纳松弛反模型。每child甚至P≥5F3/8、根菜单最优，仍W30<61/2；AAAA末位偏C使其非SPE。另完整回放原259节点SPE，证实机会损失F4−F3=25>18=2u1。
- `audit_child_profit_state.py`及两份JSON：全部61单位客户、所有6×216子局元组、1296根元组、1554完整策略比较的独立有理审计。未读取relay probe实现，未导入规范SPE求解器。

研究经过：先固定精确模型，独立从背景剩余利润归纳与全局stationary交换思考。最初考虑的弱 `(m-1/2)theta_m` 充分桥已由父方指出现有复制反例，读原证明后立即停止。一般根—后继交换的逐客户支付在中间关联时不成立；最小坏子局归纳仍需要跨真实分支的激励状态。以下粘合引理是有用但不闭合一般目标的构造接口，不能据此继续以复制低比率实例代替一般研究。
