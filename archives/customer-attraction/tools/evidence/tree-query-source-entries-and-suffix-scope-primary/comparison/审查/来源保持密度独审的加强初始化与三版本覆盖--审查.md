# 加强INIT的两种独立证明，仍只一份整行IC

固定最优或任合法比较元组T、owner i及x∈T_i；t=c_T(x)≥1、p1/t。actual B，强制T_i真叶W_i。d=c_B(x)+1−1_(x∈B_i)≥1，w=c_Wi(x)≥1；未来W-new数n、W-lost数n_-，w=d+n−n_-。原actual正款P_B后余r=p−P_B∈[0,p]。加强逐未来边cap为min(1/d,p)/w，总qhat=n min(1/d,p)/w。

要证(r−qhat)_+≤1/w。若d<t，r≤p且w≤d+n≤t+n，故wr≤wp≤1+np=wqhat+1。若d≥t，则qhat=n/(dw)，可从原坐标计数重证而不用未来密度：令n_B为actual coverer中比较元组对应角色不含x的个数，k=d−n_B，则1≤k≤min(d,t)、r=k/(td)。因此

\[
 wr-w\widehat q=(kw-nt)/(td)
 =[kd-kn_-+n(k-t)]/(td)\le k/t\le1.
\]

取正部合法。作者正文另用kw−n min(d,t)≤kd≤td统一两种，和独审相符。先合客户再一次完整IC给Σ_x(r−qhat)_+≤u_i(W_i)≤u_i。由r−min(r,qhat)=(r−qhat)_+，原current缺口b_i=(Σr−u_i)_+≤Σmin(r,qhat)，故在cap内比例分配future可保current≤u_i/原H；每条a_ijx≤p_ix/c_Wi、每owner总future≤p_ix。不是按客户应用IC。
