# 固定被动查询在原完整树上的稀释税

2026-10-24，tree8。任意人数、有限共同目录、每份完整历史纯 SPE；允许空主题与零客户。以下是对原策略树的评估合同，不把辅助负载或修改后的策略叫作原模型 SPE，也没有给 half 新的福利下界。与既有 `round2/tail/uniform_shrink_full_tree_tax.md` 的思路相近；此处保持原单位行动者，仅添加固定被动客户负载。

## 1. 整行 IC 在固定负载下的真实缺陷

固定任意非负实向量 q_x。它只用于代数评估，不声称能由合法目录玩家实现。对原合法完整叶 Z，记原负载 c_x(Z)、原收益 u_i(Z)。定义

    u_i^q(Z) = Σ_(x in Z_i) 1/[c_x(Z)+q_x],
    τ_i^q(Z) = u_i(Z)−u_i^q(Z)
             = Σ_(x in Z_i) q_x/{c_x(Z)[c_x(Z)+q_x]} >=0.

只在 x∈Z_i 上求和，故 c_x>=1。任一原合法历史 h 的规定叶 Z_h、强制当前动作 A 后的真实叶 Z_hA，原全树 IC 给 Γ_hA=u_i(Z_h)−u_i(Z_hA)>=0。因此

    u_i^q(Z_h)−u_i^q(Z_hA)
       = Γ_hA − τ_i^q(Z_h) + τ_i^q(Z_hA)
       >= −τ_i^q(Z_h).                            (ROBUST)

同一个 q 在全部真实历史使用；没有逐客户重权调用原 IC。ROBUST 保留实际 slack Γ 与两侧真实税的精确等式，故可以在需要时保留偏离叶退款，而不是只留粗下界。

## 2. 同一完整叶的共同税钱包

固定一个原完整叶 Z。对所有原行动者同时求和，逐客户恰有

    Σ_i τ_i^q(Z)
        = Σ_(x:c_x(Z)>0) q_x/[c_x(Z)+q_x].         (LEAF)

把被动负载的总份额定义为

    V_q(Z)=Σ_(x:q_x>0) q_x/[c_x(Z)+q_x].

则

    Σ_i τ_i^q(Z)
      = V_q(Z)−|{x:q_x>0,c_x(Z)=0}| <= V_q(Z).     (POOL)

q_x=0 的坐标不使用 0/0。若 q=1_T 来自一个合法主题 T，V_q(Z) 就是把一名被动 T 提供者插入 Z 后该提供者的真实份额收益；被覆盖客户的那部分精确等于所有旧玩家被稀释的利润，原未覆盖客户提供的是新覆盖而非旧税。

因此在**同一个** Z 的 prescribed 延续路径上，全部原角色的 ROBUST 损失可以由一份 V_q(Z) 同时支付；不是每个角色独立领一份该钱包。

若 A∼p 是一个独立于历史的固定合法主题分布，仅评估相应期望，令 ρ_x=P(x∈A)。二值 q=1_A 的期望税为

    E_p τ_i^A(Z)=Σ_(x∈Z_i) ρ_x/[c_x(Z)(c_x(Z)+1)],
    Σ_i E_p τ_i^A(Z)=Σ_(c_x(Z)>0) ρ_x/[c_x(Z)+1].  (MIX)

这与 reciprocal 混合 Hessian 的同客户价格一致，且同一 p 可在原完整树的所有 IC 中使用。

## 3. 同一税还具有一个固定的凹势

令 H_0=0，并定义只依赖完整叶负载的形式势

    Ξ_q(Z)=Σ_x Σ_(ell=1)^(c_x(Z))
                 [1/ell − 1/(ell+q_x)].

它的每客户增量非负且非增，所以是客户负载上的凹势。对任意角色 i，代数删除该角色后精确有

    τ_i^q(Z)=Ξ_q(Z)−Ξ_q(Z^(-i)).                  (POT)

对二值合法查询 q=1_T，内和直接望远镜化为

    Ξ_T(Z)=Σ_(x∈T) c_x(Z)/[c_x(Z)+1].             (SAT)

因此这里的税不是任意节点误差；它是同一个有界饱和势的边际。SAT 的端点范围或 concavity 本身仍不能支付不同叶取出的 POT：沿真实强制 rollout 展开时，会产生删除当前角色后该势的重置差，和原调和势 rollout 的问题相同。

## 4. 尚未完成的全树接入

固定 q 或 p 并不使 Z_h 在不同 h 下相同。若组合互斥兄弟的 ROBUST，右边会出现不同完整叶的 τ_i^q(Z_h)；POOL 只约束每个 Z 内所有角色合计，不约束每个互斥分支分别取出的税相加。对这种相加使用一次 V_q(actual) 是非法的。

因此本页不能证明添加被动查询后原 σ 仍为 SPE，不能证明子游戏全树修复的总成本仅为一份查询利润，也不能支付 sibling_hessian_and_reset.md 中所有 Δ。需要的仍是保持同一查询、同一真实历史域和 actual 总钱包的共同耦合。此项未证，没有据此提升任何 half 或 residual-cap 状态。
