# 八客户与四十二客户静态CCE原核验包

`original/`按冻结字节保留本批七份原件；`source-manifest.json`记录两个冻结提交的完整来源、源ID、原路径、大小和SHA-256。三个Python程序只有标准库依赖，客户与策略均硬编码，不读取旁边JSON作为输入。

`rerun/`是本轮对三个原字节程序实际运行得到的完整stdout。`replay_bundle.py`核七原件指纹、重新运行三程序并比较完整输出，核八客户两策略版本与末换行差别；`verification.json`是该包装器的真实输出。包装器是重放集成检查，未声称新增独立数学实现或外审。

从本目录运行：

```sh
python3 replay_bundle.py
```

原程序默认打印完整JSON；若额外给位置参数路径，会写入该路径。本包复跑只用默认stdout。八客户两版本各核21有序历史、84比较、20静态计数列、11个有序CCE支持与12项个体约束，最低CCE福利544/87，真正安全值44/23。四十二客户程序核21历史、84比较及20静态计数列，SPE福利32、最优42、固定对偶下界33；未提供达到33的CCE，不能称33为最低CCE锐值。

`comparison.json`记录与现有正式主审计/运行的字节身份，以及八客户原有序策略和简化计数策略的两处差异。`relationships.json`给本资源的人工关系判断，未生成第三阶段图。正式使用合同见[资源对象](../../../state/资源/八客户与四十二客户静态CCE分离的原核验合同--资源.md)。
