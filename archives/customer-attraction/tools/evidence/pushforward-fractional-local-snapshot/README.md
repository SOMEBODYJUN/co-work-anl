正式对象：[局部安全增量推送分数候选快照](../../../state/计算/局部安全增量推送分数候选快照--计算.md)。

`source-manifest.json`列六份已全文实读原件的源ID、双冻结提交、原路径、本地路径、字节数、SHA及生成器检索边界。primary是1635B浮点快照，related是113客户种子输入/完整43动作证书、安全README、相邻完整推送源码及extra接口；不把related文件额外计作本次done。

原件通过 `work.py clean show ID --out`取得，逐字节保留。`original`中的小数与负零均未修改。相邻程序的schema及包含根的三槽目标与本快照不同，故未称其为原生成器，也未运行原程序或LP。未找到生成器并不抹去快照：通过已保存权重和完整策略可给明确、独立可核的当前重建。

新 `verify_snapshot.py` 只用Python标准库，从原JSON十进制和相关完整动作表计算，不导入项目代码或其它代理实现：

- 对原十进制及binary64权重各核258条真实历史IC，二者各29条微负，不冒称原float精确SPE。
- 用小分母提出新有理权重，统一乘158得到585单位客户；43历史258IC全部非负，92条等号，六主题非空且彼此不同。
- 原113客户另核同一策略，原输入与新权重不混；本程序不重求旧证书的安全值最优性。
- 原p精确十进制总和不等于1，当前显式除以总和归一化。新删根两槽推送gap严格在1/400与1/380之间；含根三槽gap负。
- 给明确自由两槽负载(1/2,1/4,1/4,1/2,1/4,1/4)，六查询最大153/158<root1；只是可行上界，不声称最优分数安全值。
- 对全部216终局核收益之和等于覆盖及真正OPT；整数实例W516、OPT585、双倍half余额447。
