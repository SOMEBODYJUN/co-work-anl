# 合法背景利润与自由分数背景的静态接口

2026-10-22，个人解析备份。基础一般背景接口由 security2 提出，最小背景常数和
两系数模板最优性由 recursion2 推导；已相互即时交流。完整共同版本由
`../security2/background_fractional_interface.md` 保存。本页只保留可独立重构的证明。
没有动态 SPE 聚合定理；一般 Q-CAG-HALF 仍 OPEN。

## 对象

固定合法有序前缀，客户背景负载 b_x≥0，剩 r≥1 人，定义最优剩余利润

    F_r(b)=max_(T_1,...,T_r) sum_x d_x/(b_x+d_x)，

d_x 为 r 个比较主题的客户负载，d_x=0 项按0。任意非空背景中这不等于完整覆盖。
自由分数背景 y 为目录主题上的非负权重，总重 r−1；其客户负载为 L_x。

    w_r(b)=min_(y≥0,sum y=r−1) max_(T∈S)
              sum_(x∈T) 1/(b_x+1+L_x)。

此处 y 不观察查询 T 的实现，也不限制为实际负载的倍数。它是静态比较对象，
不是对真实适应性后继的替换许可。

## 一般静态比较及背景强化

r=1 时 F_1(b)=w_1(b)。设r≥2。若一个达到F_r(b)的比较元组覆盖的全部客户均有
b_x≥B≥0，令

    C_r(B)=max_(d=1,...,r) d(r−d)/(B+d)。

则

    F_r(b) ≤ [r+C_r(B)] w_r(b)。                         (S)

无需要求目录中其他客户满足背景下界。B=0 时 C_r(0)=r−1，得到普遍版本
F_r(b)≤(2r−1)w_r(b)。条件允许任意目录大小和任意合法背景。

证明取 c=C_r(B)/(r−1)。对整数1≤d≤r、b≥B和实数0≤L≤r−1，逐客户有

    d/(b+d) ≤ (d+cL)/(b+1+L)。                          (P)

清正分母后，差分子关于L仿射。因此只需L=0和L=r−1。前者为d(d−1)≥0；
后者等价于 c(r−1)≥d(r−d)/(b+d)，由定义和b≥B成立。d=0 时(P)亦显然成立，
且不需要该客户的背景下界。

固定任意自由背景y，记其最大纯查询收益为M。对比较元组逐客户求和(P)，d项
等于r个合法目录查询收益之和，至多rM；L项等于sum_T y_T乘该主题的查询收益，
至多(r−1)M。因此F_r(b)≤[r+C_r(B)]M。对y最小化即得(S)。

## 两系数模板的准确最佳性

只考虑下列明确的逐客户模板：统一常数 A,C≥0，要求对全部b≥B、d=1,...,r及
L∈[0,r−1]成立

    d/(b+d) ≤ (Ad+CL)/(b+1+L)，

随后用共同目录预算得到成本rA+(r−1)C。该模板的最小成本恰为r+C_r(B)。

d=1、L=0强制A≥1。再取b=B、L=r−1，得到对每个d

    rA+(r−1)C ≥ d(B+r)/(B+d)+(r−d)A
                  ≥ r+d(r−d)/(B+d)。

取d最大值得成本下界r+C_r(B)，而(P)的A=1、C=C_r(B)/(r−1)达到它。
这是指定模板最优性；没有声称(S)是F_r(b)/w_r(b)本身的锐常数。

背景B增大时C_r(B)减小，且C_r(B)≤r²/(4B)（B>0）。这给静态插值到r；
它不提供任何“每个真实玩家收益≥w_r(b)”或“实际剩余利润≥r w_r(b)”的动态支付。

## 真正剩余义务

当前节点行动A后，子 SPE 的总利润与A租金必须分别保留。不同A的真实子局可
独立选择不同的合法续局；(S)不把这些分支的收益汇总为实际路径的收入。
非空背景也不能将F_r或实际剩余利润替换成包括前缀租金的总覆盖。
