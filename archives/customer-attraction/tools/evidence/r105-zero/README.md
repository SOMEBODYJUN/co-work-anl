## 核验结果和运行边界

原背景唯一SPE为首C、末菜单(C,C,B,C)，旧完整叶覆盖18、尾部投影覆盖17。删除A后保留旧策略的两个实际节点后悔都为0；删除后唯一完整SPE为首D、末菜单(C,D,B,B)，福利16，OPT₂=17。复制客户t次给损失t而后悔仍零，排除仅依实际后悔向量的有限绝对修复费。

四个原三人根子局的唯一尾终局为(C,B)、(D,C)、(B,D)、(B,C)，根收益为5、13/2、11/2、6；实际根严格B。B子局有2份完整SPE，来自离轨平局；唯一的是尾终局，并非完整策略。本轮开发最初用过强的“各子局完整策略唯一”断言，断言在B子局失败后改为按真实唯一终局核对。最终成功报告保留真实完整策略数，不把这一诊断失败隐去或解释为原反例失效。最终程序一次完整执行成功；之前一次开发断言失败，无随机或MILP搜索。

本目录没有重复执行历史父方原入口。其实读代码、两输入与历史冻结报告分别已存于`parent-suffix-and-static-audits/`和`parent-review-and-frozen-audits/`；manifest记精确相对路径和SHA，避免将旧运行重复记成本批新运行。本轮只对该固定实例执行新精确程序，没有重新扫描50000个实际根候选。

历史五客户后缀例只证明保留策略可能不可信，尚可同福利重选；十八客户例补充“每份可信重选必损福利”。本反例不否定ASD/VR的实际退款解析界，也不否定额外使用实际根激励、被删利润、有符号退款或真实离轨菜单信息的修复合同。
