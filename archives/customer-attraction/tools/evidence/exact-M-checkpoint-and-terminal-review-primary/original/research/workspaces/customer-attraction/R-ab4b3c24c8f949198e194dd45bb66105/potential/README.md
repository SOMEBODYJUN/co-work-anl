## 一个尚无一般证明的成对候选

令 v_m 为原空背景、m−1 个静态竞争槽、不观察查询抽样的真正混合安全值。给定任意完整纯 SPE 的实际最终收益 u_1,…,u_m。候选为

    对每个 m≥2、每个 i≠j，u_i+u_j ≥ 2v_m。

它严格弱化逐人 u_i≥v_m 的要求，仍比聚合安全桥强。若对全部位置对成立，则对所有无序对求和得 (m−1)W≥m(m−1)v_m，即 W≥mv_m。结合既有 OPT_m≤(2m−1)v_m，得到 OPT_m≤(2−1/m)W；代入 m=5 将**条件性**给出 OPT_5≤9W/5。因此它若被一般证明，会无条件通过 m=5 的二倍测试；当前没有付清这个前提，不能报告已过。

有限 minimax 给候选的精确等价证书：对该具体实例和该位置对，存在一个合法 m−1 主题元组的分布 Q_{ij}，使所有合法查询 T 同时满足

    E_{B∼Q_ij} Σ_{x∈T} 1/(1+c_x(B)) ≤ (u_i+u_j)/2。

Q 可以依赖实例、策略及位置对。它不必由真实某个根菜单推送，不要求这些静态竞争元组本身是 SPE。

末两位的 pair 由既有任意背景末两人保底和安全值嵌入立即成立。任意早期 pair 的准确未付义务，是构造上面的 Q_{ij}，或以真实全树 IC 证明其 minimax 值不超过 pair 平均。删掉其余玩家再调用二人恒等式不合法：删位会改变实际背景及被保留玩家的真实续局。将中间动作冻结同样不能导出原 SPE 比较。实际叶均匀删位的静态背景已有 cap W/m 失败边界，故不能把该固定 Q 当作通用成对证书。
