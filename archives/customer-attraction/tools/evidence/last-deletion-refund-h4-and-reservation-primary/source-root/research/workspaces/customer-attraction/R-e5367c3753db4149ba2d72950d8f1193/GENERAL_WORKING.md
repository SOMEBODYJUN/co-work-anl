## 2. root 的直接推导：不交储备提升的菜单估计

这是一条对任意旧游戏的**条件性变换关系**，不是结构类扩张，也不是一般 half 的闭合。

旧 n 人完整策略为 sigma。实际叶 z、福利 W。对实际位置 i 和合法强制行动 A，
Z_i(A) 为同一原策略的真实终局（包含当前玩家）。对目录查询分布 p 定义

    psi_i(p) = min_A sum_T p_T sum_(x in T) 1/(1+c_x(Z_i(A))).

令 `M = max_T sum_(x in T) 1/(1+c_x(z))`。所有菜单均包含实际叶列，故 psi_i(p)<=M。
记一般候选 U 为：对每个 p，`sum_i psi_i(p) <= W`。
U 蕴含 Mpath 的平均时间充分预算，但此处不声称 U 对任意 SPE 成立或与 half 等价。

在旧客户外加入 J 个客户组成主题 B，增加一位首人。这里只**假设**存在完整 SPE sigma'：
根选 B，且每个以 B 开始、此后只含旧主题的有序历史都逐字执行旧 sigma。
其余历史必须另有完整 SPE；下面不以菜单代数证明它们可信。

对任何新查询分布，写 `p'=alpha delta_B+(1-alpha)p`。alpha=1 时任选旧 p。
在第 i+1 位，把合法偏离限制到旧行动并保留开头 B，得到

    psi'_(i+1)(p') <= alpha J/2 + (1-alpha) psi_i(p).

根菜单使用实际 B 列则给

    psi'_1(p') <= alpha J/2 + (1-alpha) M.

若旧策略满足 U，二式相加得到对**所有**查询分布的通用估计

    sum_(i=1)^(n+1) psi'_i(p')
      <= (1-alpha)(W+M) + alpha (n+1)J/2.             (L)

所以只要

    M <= J,                 (n-1)J/2 <= W,           (C)

U 在这次逐字提升下保持。两项只比较 (L) 的两个端点，不依赖查询支持或平局规则。

同样，新实际插入 cap **恰为** `M'=max(M,J/2)`。若旧 M<=W/n 且 (C) 成立，
则 M<=min(W/n,J)<=(W+J)/(n+1)：分别按 J<=W/n 和 J>=W/n 清分母即得。
B 项的要求恰是 `(n-1)J/2<=W`。因此实际 cap 的平均福利上界也保持；n=1 自动包含。

旧不交储备构造的条件是 `J/2<=eta`、
`J>=max_T(|T|-delta_T/2)`，其中 eta 为旧全部规定收益保底、
`delta_T=min_(S in catalogue)|T intersect S|`。这些已知条件足以给 (C)：
实际叶至少有一个旧主题，所以查询 T 的实际插入价值至多 |T|-delta_T/2；
另一方面 W>=n eta>=nJ/2。构造本身及全历史拼合复用
`R-6bb0323d87294932af2aa23b47b9d4ad/parent/disjoint_reservation_lift.md`，不认领为新。

本推导的新范围仅为菜单估计 (L) 和较弱的标量闭包条件 (C)。它说明这类逐字储备提升
不能把已经满足 U 的旧策略变成 U 的反例，也不能把已满足实际 cap 界的旧策略变成其反例。
它没有支付任意原游戏的 root reset 协方差，没有把 U/Mpath 提升为定理。

## 3. 新的全历史构造：移除旧的严格退出条件

独立审查从上述陈述自行重构后，另给出更简单的全历史构造。
对任意 n>=2 的旧游戏和完整 sigma，设全部旧有序历史的规定最终收益至少 eta，
`J>0` 为整数，且

    J/2 <= eta,    J >= L := max_T (|T|-delta_T/2).    (NEW)

在新游戏全部有序历史上规定：尚无 B 时选 B；恰有一个 B 时擦除该 B，执行对应旧 sigma；
出现第二个 B 后，在每个首次第二 B 子树独立选完整逆向归纳 SPE。

恰一个 B 的节点：旧行动之间的每条比较逐字等于旧 sigma 的真实 IC；改 B 的收益至多 J/2，
所以不能超过规定旧收益 eta。无 B 的节点：规定 B 后以后不再选 B，当前收益恰为 J；
若改旧 T，非末位时随后首次 B 发生，终局恰有 n 个旧行动，末位时则有 n+1 个旧行动。
n>=2 保证另有一个旧主题 S，偏离收益至多 |T|-|T∩S|/2<=L<=J。
第二 B 以下由完整逆向归纳保证。因此全部离轨历史均最优。

这移除了旧构造另需的 `|T|/2>J/n`，没有改变任何旧有序历史的规定行动。
n=1 时无 B 根改旧 T 可以只与 B 共存而独享 T，故上述策略另需 J>=max_T|T|；
旧目录仅一个三客户主题、J=2 已严格说明 (NEW) 不能无条件用于 n=1。
J>0 保证新主题与所有旧主题作为集合不同；不把两个空集标签偷换成两个合法集合行动。

独立证明、其余边界和旧构造来源见
[独立审查](independent/reservation_lift_independent_audit.md)。
它是任意旧游戏上的一般构造组件，不是新的受限目录福利项目。
