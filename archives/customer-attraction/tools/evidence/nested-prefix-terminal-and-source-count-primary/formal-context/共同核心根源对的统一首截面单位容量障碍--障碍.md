# 共同核心根源对的统一首截面单位容量障碍

9201B原稿§B给此精确模板一般障碍，全文已读；全仓现正文只有后续多源核对该旧障碍的必要提及，未发现一份完整独立证明，故本页保存其自足定义/量词/证明。原单链NP/后续多源核本身仍有效，不把此模板当一般证明必要条件。OE5实际完整26项claim 518aed418f4d60ed098d431aaefe33e7d1780c6e pushed/synced，本5 owner/in-progress/sourceSHA已核；相关JSON31853B已全文/全部字段与34事件角色读齐，保存截止142与后来MD截止149分别记录；未预称正文已推或done。

## 同人数双主题源和被排的完整合同

固定m≥3、原单位客户/共同目录/全部有序历史纯SPE σ，固定其actual路径。对长度k的actual前缀H_k，负载h_k，r=m−k−1，定义
\[
 f_{H_k}(b)=\sum_{x\in b}\frac1{h_k(x)+1},\qquad
 K_k(a,b)=f_{H_k}(b)+U_a(H_k+a+r b).
\]
右侧U按显示合法终局计数算，**不是**声称当前真强制a后未来都会选b；真实运输的回复行来自原具体末位历史H_k+b^r。逐客户对称式
\[
 K_{k,x}(a,b)=\frac{1_{x\in a\cup b}}{h+1}
 +\frac{1_{x\in a\cap b}}{h+r+1}
\]
解释单链NP为何合法；跨actual下一题的正税是z/[(h+1)(h+2)]，负交集项必须保。

被排的是以下**同时**要求的模板：有限个根主题对(a_j,b_j)，各固定非负全行权λ_j；每路径只用原NP合法互惠回复/actual前缀步，整个源权都穿过同一个第0→1 actual前缀截面；根源核本身支付全部OPT，Σ_jλ_jK0(a_j,b_j)≥OPT_m，未另外扣核心或加独立根信用；在每actual-hit客户x的该截面还要求
\[
 Q_{0,x}=\sum_{j\text{过该截面}}\lambda_j1_{x\in a_j^{cut}\cup b_j^{cut}}\le1.
\]
每条λ与客户无关，主题对可经多次合法回复变化，但不提前退出首截面/不在不同层启动。允许源提前终止、不同端点/额外信用/源先扣公共块都已换合同，不受本页排除。

## 对每个m≥3的原单位实例与完整证明

客户x,y₁,…,y_m互异，每题T_i={x,y_i}，共同目录**恰**这些m题。总人数m，OPT_m=m+1：全部m题覆盖全部客户，客户总数给上界。一个显式完整纯SPE是在每个有序历史都选最小未用题：深度t已用题种类≤t，未用数≥m−t，任何偏离孩子后仍足余人；规定未来永不重用已用题。当前选任一fresh题独享其私有客户，公共x最终总由m人覆盖，所以收益1+1/m；改已用题私有份额≤1/2，公共份额仍1/m，严格不利；改另fresh题平局。因此该全历史策略合法，根W=OPT=m+1。任取任何SPE的任意actual首题也必命中x，下面容量矛盾不需挑坏tie或低福利。

根f0(b)=2。若a=b，则所有m人都在此题，Ua=2/m，K0=2+2/m；若a≠b，当前a的私有客户独享一，公共x份额1/m，K0=3+1/m。因此所有根主题对
\[
 K0(a,b)\le3+1/m.
\]
令Λ=Σλ。非负权和完整根支付要求给
\[
 \Lambda\ge\frac{m+1}{3+1/m}
 =\frac{m(m+1)}{3m+1}>1\quad(m\ge3),
\]
最后严格性是m²−2m−1>0。

另一方面，所有合法主题都含x，原末位回复也必须从该共同目录选题，所以任意合法互惠更新后的主题对并集仍含x。每条定权源又全部过同第0→1截面，于是x的容量正好Q_(0,x)=Λ；actual首题含x，模板要求Q_(0,x)≤1。因此Λ≤1与前式矛盾。

这是所有非负源对组合/全部所述路径和任意actual首题的解析排除，不靠枚举流或有限阴性搜索。m1/2不在该严格参数域；零客户边界不是这个反例族，也不改变其作为普遍模板反例的合法性。

## 单核整合不是这个失败模板

取全部m个最优题作**一个**多源列表L，令d_L(x)客户会员重数。后续提出
\[
 \mathcal K_0(L)=\sum_x[1_{d>0}+(d-1)_+/m]
 =OPT_m+B_0,\quad B_0=\sum_x(d-1)_+/m\ge0.
\]
共同核心在并集位只计一次；跨actual前缀的正税只依该并集位≤1，不等于把很多独立根pair各自相同税相加。这个编码已不满足本页“若干独立根对都必须过同首截面支付整个OPT”的模板，故不受以上Λ矛盾否定。
