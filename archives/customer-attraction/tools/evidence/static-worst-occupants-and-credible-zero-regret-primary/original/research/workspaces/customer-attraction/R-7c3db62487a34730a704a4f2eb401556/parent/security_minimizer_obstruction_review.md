# 全人数静态最坏背景占用者收益桥：解析反例与独立核对

2026-10-23。本页记录主代理的任意人数构造和不调用优化器的证明。
security 分支先独立发现一竞争槽十客户反例；主代理收到其精确陈述后
独立提出以下全人数参数，security 又自行推导并核对同一族。
它只否定静态中继加强桥，不改变 Q-CAG-HALF 的 OPEN 状态。

## 被否定的精确候选

有 m≥1 个静态竞争槽。对查询分布 p 和槽主题元组 q，写

\[
 F_p(q)=\sum_x\frac{\alpha_x(p)}{1+c_x(q)},\qquad
 v_{m+1}=\max_p\min_{q\in\mathcal S^m}F_p(q),
 \quad\alpha_x(p)=\Pr_{T\sim p}(x\in T).
\]

候选声称：任意安全最优 p*、任意纯最坏背景 q、任意 q 中占用主题 d，
都有 U_d(q)≥v_(m+1)。下例对每个 m 都使纯最坏背景唯一，且它本身
也构成真正最优对手分布的全部支撑；仍有每个占用者收益低于安全值。

## 目录、量词及匹配证书

任取 m≥1，设

\[
 a=m(m+1),\quad h=m+2,\quad P=m+3.
\]

取两个不交核心 X、Y，各 a 名客户；每个核心有 h 个叶主题。
叶 A_(X,j)=X∪Z_(X,j)、A_(Y,j)=Y∪Z_(Y,j)，每个 Z 含 P 名不同私有客户，
所有 Z 彼此及与核心不交。另有主题 B=X∪Y；目录恰由这些 2h+1 个主题组成。
全部客户仍为单位客户，不引入带权提供者。

令 p* 均匀查询全部 2h 个叶，不查询 B。核心查询概率为 1/2，
每名私有客户查询概率为 1/(2h)。取 q0=B^m，则

\[
 F_{p^*}(q_0)=\frac{a}{m+1}+P=2m+3.
\tag{1}
\]

任意背景 q 中设叶主题总槽数为 t，各叶占用 n_j，X 组、Y 组叶总数分别 t_X、t_Y。
两核心负载为 m−t_Y、m−t_X。令 M=m+1。
每当整数 s≥1，

\[
 \frac1{M-s}-\frac1M=\frac{s}{M(M-s)}\ge\frac{s}{m(m+1)}.
\]

s=0 时增量为零。所以两个核心对 F 的合计增量至少
a(t_X+t_Y)/[2m(m+1)]=t/2。
私有项相对 q0 的下降为

\[
 \frac{P}{2h}\sum_j\frac{n_j}{n_j+1}
 \le\frac{P}{4h}\sum_j n_j=\frac{P t}{4h},
\]

其中对 n_j≥1 用 1/(n_j+1)≤1/2，零项直接为零。故

\[
 F_{p^*}(q)-F_{p^*}(q_0)
 \ge\left(\frac12-\frac{m+3}{4(m+2)}\right)t
 =\frac{m+1}{4(m+2)}t.
\tag{2}
\]

t>0 时严格为正；t=0 只有 q=B^m。因此 q0 是唯一纯最坏背景。
另一方面，面对固定 q0，每个叶查询收益都是 2m+3，B 查询仅为
2a/(m+1)=2m。因此任意查询分布面对 q0 至多获得 2m+3。
这与 (1)—(2) 匹配，证明 p* 真正最优、v_(m+1)=2m+3，纯 q0 也是真正最优对手。

但 q0 每位占用者的原收益为

\[
 U_B(q_0)=\frac{2a}{m}=2m+2=v_{m+1}-1.
\tag{3}
\]

这对全部 m≥1 是精确反例，不是数值或有限搜索判断。

## 返还债的准确边界

令 J_B(q)=Σ_(x∈B)1/(c_x(q)+1)，
ρ_B(q)=U_B(q)−J_B(q)=Σ_(x∈B)1/[c_x(q)(c_x(q)+1)]。
把查询标记 p* 换成占用标记 B 的额外槽差 δ^+=F_p*(q)−J_B(q)，则

\[
 \delta^+-\rho_B=F_{p^*}(q)-U_B(q)=1.
\]

所以“最优查询 + 最坏背景 + 精确自占用返还即可无债换标记”仍为假。
这没有否定加上真实剥离边的激励松弛 Γ 后的支付，也没有证明 q0
是任何实际完整 SPE 的终局。全部真实分支最优性仍是未被本静态例替代的义务。
