# 零在轨删除误差仍不能保证无损可信修复

2026-10-24；一般辅助桥的精确反例，个人研究备份。采用原 CAG-MODEL，
单位客户、单位提供者、有限共同目录、全部有序历史纯 SPE。
作者按定义解析核算与独立单位客户枚举完成；父方另从原始输入独立回放确认。
没有外审或新颖性认证。**Q-CAG-HALF 仍 OPEN。**

## 1. 被否定的准确一般桥

考虑 [DR 合同](../parent/deletion_regret_envelope.md)：固定合法背景 `b+d` 下
任意 n 位尾部玩家的完整 SPE sigma；删去 d 后，仍沿同一完整策略。
记旧实际尾叶为 q，`R_j` 为删后在旧实际第 j 节点、强制一个合法行动并
沿旧完整策略执行的最大正 regret。

本例否定下述修复步骤，**即使允许完全重选删后完整 SPE**：

> 若所有 `R_j=0`，则存在删后完整 SPE tau，使其尾部覆盖福利至少 `W(q)`。

更一般地，不存在仅由 n 和实际节点 regret 向量决定、在零向量处取有限值的
统一绝对误差函数 `F_n`，能对全部此类输入保证

    max_(tau in SPE(b)) W(tau) >= W(q)-F_n(R_1,...,R_n).       (REPAIR)

这里的 W 比较删除后游戏中的覆盖；本例取 `b=0`，故正是尾部主题并集。
否定来自一个合法 `n=2` 输入及其任意正整数客户复制，不是另开固定人数正面项目。
本结论不否定带有新枝信用、被删者收益、原福利或其他信息的修复定理。

## 2. 十八单位客户和一个合法背景主题

目录为 A、B、C、D。下表的每一重数编码该数量的不同单位客户；没有带权客户。

| 客户喜欢的主题 | 重数 |
| --- | ---: |
| B | 2 |
| A,B | 2 |
| C | 2 |
| B,C | 1 |
| A,D | 1 |
| A,B,D | 4 |
| C,D | 4 |
| A,C,D | 2 |

于是 `|A|=|B|=|C|=9`、`|D|=11`。旧固定背景是一位过去玩家选择 A，
即 `b=0,d=1_A`；其后有两位尾部玩家。原始机器输入在
[zero_regret_repair_witness.json](zero_regret_repair_witness.json)。

原尾部完整策略 sigma 为：首位选 C；末位在首位 A、B、C、D 后分别选 C、C、B、C。
两人尾部只有空历史和四个一行动历史，所以上述已列出**全部**尾部策略。

## 3. 原策略确为全部历史 SPE

保留背景 A 时，末位的收益为：

| 首位行动 | 末位 A | 末位 B | 末位 C | 末位 D | 唯一最佳回复 |
| --- | ---: | ---: | ---: | ---: | --- |
| A | 3 | 5 | 23/3 | 19/3 | C |
| B | 7/2 | 7/2 | 15/2 | 41/6 | C |
| C | 25/6 | 11/2 | 25/6 | 31/6 | B |
| D | 10/3 | 16/3 | 17/3 | 13/3 | C |

沿该唯一末回复菜单，首位选 A、B、C、D 的最终收益分别是

    (25/6, 11/2, 15/2, 31/6).

因此首位唯一选 C，原完整尾部 SPE 唯一，实际尾叶 `q=(C,B)`。
其尾部覆盖 `W(q)=17`；十八客户中只有 A,D 型的一个客户未被 B 或 C 覆盖。
若计入旧背景 A，原完整叶 `(A,C,B)` 的覆盖为18。

## 4. 删除 A 后，两个旧实际节点的 regret 都为零

只删除背景 A，保留完整策略 sigma。末位在首位 A、B、C、D 后仍按旧规则选 C、C、B、C。
沿该未修复菜单，首位选 A、B、C、D 的删后收益为

    (8, 17/2, 17/2, 8).

规定首位 C 已最优，故 `R_1=0`。在实际末节点首位为 C 时，末位选 A、B、C、D
的删后收益为

    (8, 17/2, 9/2, 8).

规定末位 B 唯一最优，故 `R_2=0`。因此不只是误差总和小，而是每个旧实际节点
都满足其全部真实单步比较，且规定删后实际叶仍是覆盖17的 `(C,B)`。

## 5. 任意可信修复都必须损失一个覆盖客户

删后在全部四个末位历史的收益为：

| 首位行动 | 末位 A | 末位 B | 末位 C | 末位 D | 唯一最佳回复 |
| --- | ---: | ---: | ---: | ---: | --- |
| A | 9/2 | 6 | 8 | 15/2 | C |
| B | 6 | 9/2 | 17/2 | 9 | D |
| C | 8 | 17/2 | 9/2 | 8 | B |
| D | 11/2 | 7 | 6 | 11/2 | B |

所有末位比较严格，故任何删后完整 SPE 都必须使用菜单 `(C,D,B,B)`。
在这个唯一可信菜单下，首位选 A、B、C、D 的收益分别为

    (8, 7, 17/2, 9).

因此首位唯一选 D，**删后唯一完整 SPE 是 `(D,B)`，福利为16**。
两名 C 型私有客户没有被 B 或 D 覆盖；其余十六客户被覆盖。
删后 `OPT_2=17`，由 `(C,B)` 达到。故本例远未违反 half。

这准确显示了未付的新枝：旧离轨首位 D 后末位被规定 C，首位 D 的收益只有8；
将该离轨子树修成可信的末位 B 后，首位 D 的收益变成9，超过原实际 C 的17/2。
这次改枝会改变首位选择，尽管原实际两个节点的 regret 均为零。

## 6. 任意绝对损失：整数复制

将每类客户复制 t 次，t 为任意正整数。每个完整历史、每个行动的收益和福利
都恰乘 t，因此所有严格比较及唯一原/新 SPE 保持，实际节点 regret 仍为 `(0,0)`。
旧投影福利为 `17t`，删后每个 SPE 福利为 `16t`，所需最小修复损失恰为 t。
若 (REPAIR) 成立，就要求 `t<=F_2(0,0)` 对每个正整数 t 成立，矛盾。

所以不仅 `F_n(0)=0` 的无损版本失败，任何固定有限初始误差费都无法只从
旧实际 regret 向量支付这项修复。这一结论也允许 F 依赖固定目录大小4。

## 7. 必须保留的范围限制及先例区别

背景 A 是**合法离轨前缀**。在相同目录的空背景三人完整游戏中，四个根行动后的
尾部 SPE 终局分别唯一为下表；在根的收益据此为5、13/2、11/2、6：

| 根行动 | 唯一尾部有序终局 | 根收益 |
| --- | --- | ---: |
| A | C,B | 5 |
| B | D,C | 13/2 |
| C | B,D | 11/2 |
| D | B,C | 6 |

因此原三人实际根唯一选 B，完整在轨叶为 `(B,D,C)`；**A 不是某份原三人 SPE 的实际根行动**。
本例不反驳 [ASD](../parent/average_suffix_deletion.md) 的实际根单删修复候选，
也没有否定以共同 W、被删者利润或更丰富全树信息支付的可能性。
它仅说明 DR 的一般合法背景版本不能单靠实际节点误差完成稳健福利归纳。

已有 [后缀盲审](../independent_general/suffix_deletion_corollary_blind.md)
给出过零实际 regret 而删后旧策略非 SPE 的五客户例。该例删后仍可重选 SPE 保持
原投影福利5，故没有证明本页的“任意可信重选均严格损失”结论。
本页对该逻辑缺口提供更强见证；不认领全球新颖性。

## 8. 核验与当前结论

[定义级独立审计](audit_zero_regret_repair.py)将十八单位客户逐个展开，
对原背景和删后游戏分别检查全部 `4^5=1024` 个完整两人策略，
并逐个原根行动分类三人游戏中的真实尾部均衡；不导入仓库求解器。
[完整冻结输出](zero_regret_repair_complete_audit.json)记录两份唯一 SPE、零实际误差、
全部末位收益表和原三人实际根排除 A。初版更窄的
[冻结输出](zero_regret_repair_audit.json)保留原字节。

父方另从原始十八客户输入独立回放，确认了相同的末回复菜单、实际误差及唯一修复福利。
解析证明由上面有限完整表与复制论证承担；检验没有扩大到一般 half。

本轮没有构成可闭合 `2W>=OPT` 的一般共同付款。新增结果是精确排除
“旧实际 regret 控制任意全树福利修复损失”这一桥。后续正面修复必须携带
改变后的离轨菜单或能支付其新根激励的额外信用；不能再把 `sum R_j=0`
当作存在同福利精确 SPE 的证据。没有因此产生可代入 m=5 闭合二的正面一般界。
