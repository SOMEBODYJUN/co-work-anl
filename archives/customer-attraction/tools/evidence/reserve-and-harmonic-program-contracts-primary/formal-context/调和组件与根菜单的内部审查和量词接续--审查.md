# 前缀调和核：保客户比较重数的准确去重

\[
 mW\ge\sum_xd_x\sum_i\frac1{b_i(x)+r_i}
 \ge\sum_xd_xa_m(c_x),\qquad
 a_m(c)=\frac cm+H_m-H_c.
\tag{HF}
\]

# 根菜单协方差和根IC松弛不能删

固定合法有序过去/整数客户背景b、余r位及同一完整σ。强制首行动a的真实完整列Z(a)=(a,z2,…,zr)含r槽；α_ax=1_(x∈a)、k_ax为只后继r−1槽的负载。真实根利润D_a=Σ_x α_ax/(b_x+1+k_ax)，额外独立query t对完整列的价
\[
 K(t,a)=\sum_{x\in t}\frac1{b_x+1+\alpha_{ax}+k_{ax}}.
\]
当前root最佳收益u=max_aD_a。p为任意主题分布，p_x=Pr_p(x∈a)，D(p)=E_pDa、C(p)=E_(t,a iid p)K(t,a)。逐客户用
\[
 \frac1{d+\alpha}=\frac1d-\frac\alpha{d(d+1)},\quad d=b+1+k\ge1,
\]
得
\[
 D-C=\sum_x\operatorname{Cov}_p(\alpha_{ax},1/(b_x+1+k_{ax}))
 +\sum_xp_x\mathbb E_p\frac{\alpha_{ax}}{(b_x+1+k_{ax})(b_x+2+k_{ax})}.
\tag{ROOT}
\]
第二项为非负self插入退款。整行root IC只给u−D≥0，因此u−C=(u−D)+covariance+self_refund；没有给可能负covariance付款。ROOT在[完整槽插入税引理](../引理/完整槽插入税与跨角色价格恒等式--引理.md)及[真实菜单协方差资源](../资源/真实菜单协方差与逃逸余项的审查合同--资源.md)已完整自足，不再认新公式。
