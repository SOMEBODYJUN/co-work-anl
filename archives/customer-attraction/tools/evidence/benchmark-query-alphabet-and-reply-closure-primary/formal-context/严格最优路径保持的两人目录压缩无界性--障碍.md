# 严格最优路径保持的两人目录压缩无界性

不存在只依人数的函数f(m)，使对每个共同目录实例、每份完整纯SPE，总可保至多f(m)题、含原实际路径及某个原最优m元组，并在保留目录用**任意重选完整策略**实现原来的同一有序实际路径。已在m=2、原全部决策严格且完整SPE唯一、原实际两题也是唯一最优对时失败。下面对每个整数L≥3构造L+1题，**任何**含实际两题的真子目录均失败。

## 原单位客户实现

置C=20(L+1)²，p=C−1，x_i=C+3i（0≤i≤L）。主题T₀,…,T_L。每个i<j引入a_ij个不同客户，其兴趣恰为这两题：
\[
 a_{01}=2,\quad a_{i,i+1}=6i+6\ (1\le i\le L-2),\quad
 a_{L-1,L}=6L+4,\quad a_{ij}=6(i+j)+6\ (j\ge i+2).
\]
再引入q_i=x_i−Σ_{j≠i}a_ij个T_i私有客户。每个a_ij≤12L，故Σ≤12L²<C，q_i>0整；所有客户是独立单位客户。于是|T_i|=x_i、|T_i∩T_j|=a_ij，且因各有私有客户，所有主题互异且包含极大。没有用带负重数、任意势矩阵或重复标签来冒充CAG。

## 两人终局公式和唯一完整策略

定义对称数值
\[
 P_{ij}=x_i+x_j-a_{ij}/2\ (i\ne j),\qquad P_{ii}=3x_i/2.
\]
首人选T_i后，末位改T_j的真实利润为P_ij−x_i；首人在该对的利润P_ij−x_j。重复主题亦由对角式给x_i/2。这里是两人精确公式，不把冻结回复替换早期SPE比较。

非邻接项P_ij=2C−3，邻边为
\[
 P_{01}=2C+2,\quad P_{i,i+1}=2C+3i\ (1\le i\le L-2),\quad P_{L-1,L}=2C+3L-5.
\]
它们从左到右严格递增，所有对角P_ii≤3C/2+9L/2<2C+2。故每个首题历史的末位唯一最佳回复R(i)=i+1（i<L），R(L)=L−1；未留任何平局自由。

沿这些真实回复，根利润依次
\[
 u_0=p,\quad u_i=p-2\ (1\le i\le L-2),\quad u_{L-1}=p-4,\quad u_L=p-1.
\]
所以根唯一选T₀，完整纯SPE唯一，实际有序路径(T₀,T₁)。

## 任意真子目录的第一遗漏指标

取任意保留目录𝒜，含T₀,T₁但不含全部题。令ℓ≥2为最小遗漏指标，j=ℓ−1，则T_{j−1},T_j保留、T_{j+1}遗漏。末位见T_j后，保留集合唯一最佳回复是T_{j−1}：左邻边高于所有非邻接和对角，更高右邻边恰被删。任意保留的更远主题都不影响这个结论。

根改T_j后这份**强制真实回复**给
\[
 j=1:\quad x_1-a_{01}/2=C+2=p+3;\qquad
 2\le j\le L-1:\quad x_j-a_{j-1,j}/2=C=p+1.
\]
原拟保路径(T₀,T₁)仍给根p，因为T₁在保留目录仍是T₀后的唯一最佳回复。因此根有严格获利偏离，任意重选其它续局都救不了该有序路径。此论证对每个真子目录成立，不只是一次删题或固定原动作表限制。

## 唯一最优性与不适用结论

不同题对覆盖为
\[
 |T_0\cup T_1|=2C+1,\quad |T_i\cup T_{i+1}|=2C-3\ (1\le i\le L-2),\quad
 |T_{L-1}\cup T_L|=2C-7,
\]
非邻对为2C−3(i+j)−6，重复题≤C+3L<2C+1。所以{T₀,T₁}是唯一无序最优对，实际W=OPT₂=2C+1。保原最优元组不额外要求任何题；目录大小仍必须L+1，随L任意大。

但只剩{T₀,T₁}时，末位互选另一题，根T₁得p+3>p，形成**反序**(T₁,T₀)，仍有相同无序多重集和最优福利。因此不反驳仅保无序终局、仅保福利或half违例保持的压缩。原实例本身福利最优，不是半覆盖反例。
