# 根重置局部账本的笛卡尔放大与平均预算分离

## 被否定的精确局部条件

在[原共同目录完整历史模型](../定义/共同目录完整历史模型--定义.md)中，用[根重置引理](../引理/根重置对恒等式与辅助尾份额协方差--引理.md)的D,e,K,R,J。一个过强的局部付款要求对任意完整纯SPE、任意合法历史及任意两行动A,T都有
\[
R(A,T)\le e(A)+e(T)+J(A,T),
\tag{L}
\]
等价于K(T,A)+K(A,T)≤2u。本对象给八提供者的完整合法反例，并对每个整数k≥1保留同样八名提供者，将违反量放大到9k/10。它不声称六提供者半覆盖失败。

## 八人基输入与完整策略凭据

有两个不交的16客户块j=0,1。每块四主题A_j,B_j,C_j,D_j，单位客户兴趣类型为

| 同块兴趣集合 | 不同单位客户数 |
| --- | ---: |
| {A_j} | 2 |
| {B_j,D_j} | 4 |
| {A_j,C_j} | 6 |
| {C_j,D_j} | 3 |
| {A_j,B_j,C_j,D_j} | 1 |

共同目录恰为这八主题，顺序标签0,…,7对应A0,B0,C0,D0,A1,B1,C1,D1；八名单位提供者依次选择。重数只是不同单位客户的压缩。

所给固定策略由[原DAG](../../tools/evidence/dynamic-flow-workspace/original/research/workspaces/customer-attraction/R-d22a706a03c5499d941a6a97f94128a8/counterexample/pure_menu_two_block_dag.json)的`CA_COMPLETE_SPE_DAG_v1`定义：根ID给起点，每节点含前缀计数、规定action、按八合法行动排序的全部children和终局target。任意有序历史沿其实际行动边行走，到达节点的action就是该历史的策略；计数每步加一，深度八结束。节点合并只是该**特定**策略的有限编码，没有要求任意同计数历史必须采用同一续局。

逐节点子树归纳是完整性证明：终局counts=target；每条行动边只加该行动，规定边的target等于父target；对父action=a及任意备选b，直接按32名单位客户检查U_a(target)≥U_b(child_b.target)。所有孩子已认证时，这就是该有序历史的所有真实偏离比较。DAG全展开覆盖所有历史。

本轮用原独立[核验器](../../tools/evidence/dynamic-flow-workspace/original/research/workspaces/customer-attraction/R-d22a706a03c5499d941a6a97f94128a8/counterexample/verify_pure_menu_dag.py)执行一次：13,872可达节点、6,435终局节点、59,496项含自身比较，其中50,732严格、8,764相等，最小松弛0；该核验器不导入规范模型、求解器或证书核验器。另由DAG路径重数精确数得2,396,745个有序决策历史、16,777,216个终局历史。不是逐条展开存储这两千多万条路径，也没有把13,872个DAG节点误称为同数的完整历史。

实际路径为
\[
(D_0,A_0,C_0,D_0,A_1,A_1,B_1,C_1),
\]
收益依次
\[
(13/4,21/4,17/4,13/4,13/4,13/4,17/4,21/4).
\]
所有32客户均被覆盖，所以W=OPT_8=32；选择A0,D0,A1,D1并重复补齐八次也给最优覆盖。

## 正重置、零局部付款与同分布平均的区别

每块按A,B,C,D写
\[
q_0=(2,1,1,0),\quad q_D=(1,0,1,2).
\]
强制根为D0（标签3）时，两块终局为(q_D,q_0)；强制D1（标签7）时为(q_0,q_D)。同一原DAG的真实分支为
\[
(3,0,2,3,4,4,5,6),\qquad(7,0,4,6,7,0,1,2).
\]
在其本块q_D中，根D的原实际收益为4/2+3/3+1/4=13/4，故D(3)=D(7)=u=13/4，两份e为零。两个根主题属于不同客户块，没有共同客户，故J(3,7)=0。

交叉查询总落在另一块q_0，得
\[
K(7,3)=K(3,7)=4/2+3/2+1/5=37/10.
\]
由RESET或逐客户重算，
\[
R(3,7)=2(37/10)-2(13/4)=9/10>0.
\]
因此(L)确实失败，且不能只以这些为零的当前松弛和共同税支付该正重置。

然而取p在3、7各半，同分布独立抽源和查询时，还会遇到两份对角查询。其正确**额外槽**值为
\[
K(3,3)=K(7,7)=4/3+3/4+1/5=137/60,
\]
所以
\[
G(p)=\tfrac14[2(137/60)+2(37/10)]=359/120<13/4=u.
\]
该p的ER=9/20、EJ=29/30、\bar e=0，故u−G=(EJ−ER)/2=31/120>0。对角共同客户税恰能抵消非对角正重置。原稿的逐对条件是平均封顶的充分条件，**不是必要条件**；本例不能重新解释为G(p)>u。

自由列混合甚至有显式安全解。各半选择3、7的完整根列时，八个查询的期望依次为
\[
(167/60,28/15,123/40,359/120)^{\oplus2},
\]
最大123/40<u。后来比较稿另讨论更优自由Q、匹配对偶及平稳源限制；本页不以这些较强结论证明(L)失败。平稳源限制与自由源、纯列限制亦各有不同量词。

## 每个整数k的笛卡尔放大

一般地，给定同人数n的任意CAG实例G及一份完整纯SPE σ。复制k≥1个客户集互不相交的分量，目录取完整笛卡尔积\(\mathcal S^k\)。主题元组(A1,…,Ak)在第j个客户副本上覆盖A_j；每名真实提供者仍只选一次元组。给每个完整联合有序历史按坐标投影，在坐标j执行σ的该投影历史行动，得到σ^{(k)}。

联合偏离到任意元组可逐坐标比较：每个客户只在一个副本内，收益为坐标收益和，每个分量沿自己的同一完整σ执行真实后继；各分量SPE不等式相加，故σ^{(k)}在**全部**联合有序历史均为纯SPE。这是既有[乘积分解定理](../定理/全体玩家续局支付唯一的乘积分解--定理.md)中不需支付唯一前提的独立乘积方向。没有声称所有联合SPE均坐标独立，亦未以此断言最差SPE福利一般可加。

对任意源元组A和查询元组T，客户不交给逐项精确可加
\[
D^{(k)}(A)=\sum_jD_j(A_j),\quad u^{(k)}=\sum_ju_j,
\quad e^{(k)}(A)=\sum_je_j(A_j),
\]
\[
K^{(k)}(T,A)=\sum_jK_j(T_j,A_j),\quad
R^{(k)}(A,T)=\sum_jR_j(A_j,T_j),\quad
J^{(k)}(A,T)=\sum_jJ_j(A_j,T_j).
\]
特别对八人基例每坐标取A_j=3、T_j=7：
\[
R^{(k)}(A,T)=9k/10>0,
\qquad e^{(k)}(A)=e^{(k)}(T)=J^{(k)}(A,T)=0.
\]
此构造有32k个不同单位客户、8^k个目录主题，仍为八提供者；给定乘积策略实际覆盖全部客户，所以W=OPT_8=32k。普遍k结论来自可加代数和全部历史的乘积SPE证明，本轮只实际核验基DAG，未计算展开任何巨大乘积策略树。

## 可复用边界与证据身份

失败约束是“每个根对先用其本地e和J支付，再求和”的局部证明接口；任何只累加这些零项的坐标独立付款也无法承担9k/10。它不排除别的跨分支信用、跨坐标非局部流、自由列混合、路径总预算或原half。反例族本身半覆盖余量为32k。
