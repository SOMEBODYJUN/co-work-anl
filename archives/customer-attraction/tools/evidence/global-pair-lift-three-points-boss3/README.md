## 结论的准确范围

三人点由真实5客户游戏实现，题0和2同覆盖、题4空；完整原31节点动作表仍保原样。商别名后四个不同集合的恒大题策略可直接证明，不能把31节点表直接删列。

四／五人点通过保存矩的全局部正性、全历史IC和共同二阶提升；给定lift高阶分别13/31项不符。更强的是Q减三叶交集为一个逐客户非负、空类型取零的三次行，点值分别−1/10、−1/25，因此排除**任何**非负共同实现，不只排所提供lift。它们仍为放松点，非客户SPE或half反例。

精确点值5/3、19/10、49/25是本轮对保存有理资料的核验，不认证原LP最优、未保存trial或所有形式策略。`self-check.json`只作最后静态交付核对，不再执行数学入口。
