# 定义与主候选

对[原模型](../定义/共同目录完整历史模型--定义.md)任意m≥1和任意长度<m的**有序**历史h，令ell(h,A)为强制A后全部真完整SPE使当前者所得的最小值，M(h)=max_A ell(h,A)。每份当前完整SPE收入≥M；反向每个主题各贴一个ell极小完整孩子，再选外层max主题，当前收入恰M。因此M是全部当前完整SPE中**当前人**收入最小值，不是整段总利润最小值。

对每条任意完整路径z=(A₁,…,A_m)，不要求z可信，定义价格和Σ_i M(A₁,…,A_(i−1))。候选MP是

\[
\forall z\in\mathcal S^m:\quad\sum_i M(h_i)\ge\operatorname{OPT}_m/2.\tag{MP?}
\]

F(h)=0在终端，否则F(h)=M(h)+min_A F(h,A)。有限动作展开给F(∅)恰为任意路径M和最小值，所以MP等价F(∅)≥OPT_m/2。这里F是**真实当前下包络的路径和**，不是旧背景最优剩余总利润F_r(b)=max_qΣ_x c_q/(b+c_q)。后者在大主题+单例族有无界局部Bellman系数，并不反驳MP；也不要求每个M的达到孩子兼容同一条最短路径。

计数可以计算整个真续局**全集**的价值，因为子博弈支付只依负载；不由此限制给定策略在同计数、不同顺序历史使用同一回复。现有[可信阈值价格候选](../问题/可信阈值路径价格候选--问题.md)的背景PRICE-HALF量化还更广，须区别根MP与任意背景版本；本稿不重命名或覆盖旧候选。

# 真尾输入的已证接口与条件加强

给任意目标z，长度j后的整个尾为完整SPE。前j位δ_i=(M(h_i)−u_i(z))_+，R=Σδ_i，D=maxδ_i；真尾每位u_i≥M(h_i)，早期u_i+δ_i≥M(h_i)。利用完整根福利Σu=W，精确得到

\[
W+R\ge\sum_iM(h_i)\ge F(\varnothing).\tag{1}
\]

只有再证明MP才能给O−2W≤2R≤2jD；这将强于[真实编译](../定理/真实退出缺陷的统一与异质前缀修复--定理.md)的2R+D成本。反之真实编译本身或五人half并不自动证明任意路径MP。对真SPE R=0，用未证MP推出half只是正确的条件推导，不能倒当证明。

# 任意路径的已证一般校准

K=max主题大小。任何历史强制最大主题，无论后续怎样每客户负载≤m，故ell(h,K主题)≥K/m、M(h)≥K/m。末位M≥θ_m，倒二M≥θ_m，后者由固定背景两人的对称差值恒等式U_p(A,B)−U_p(B,A)=f_p(A)−f_p(B)和全部末位BR量词给出。因此m≥2时**每条任意路径**均有

\[
\sum_iM(h_i)\ge\frac{m-2}{m}K+2\theta_m,
\quad \theta_m\ge\max\left\{\frac{O}{2m-1},\frac{2O-(m-1)K}{2m}\right\}.
\]

两个代入式分别为(m−2)K/m+2O/(2m−1)及2O/m−K/m，以1/(m−1)、(m−2)/(m−1)非负加权消K得

\[
F(\varnothing)\ge\frac{4(m-1)}{m(2m-1)}O.\tag{2}
\]

m2时第二权0，无除m−2；m1直接F=OPT₁。m≥5系数不足half，不提升状态。θ的两界逐客户来自O≤m b(h)+Σ_x h_x/(h_x+1)，后项同时≤(m−1)b(h)及(m−1)K/2；使用全部合法末位历史、非只实际SPE历史。零客户直接全0，不定义0/0。

旧校准族大主题含m客户、m−1个不交单例：任何历史选择大主题对每个孩子保至少1，因此M≥1；完整全大主题SPE沿全大路径每位恰1，故该路径每个M≤1，F=m、OPT2m−1。它说明若MP成立常数2无法作统一严格改进，不能证明MP。

# 七客户：最低价格孩子不能免费拼成同一SPE

m5，主题标签0,1,2,3，客户兴趣类型{1}:2个、{0,1,2}:4个、{2,3}:1个，共7单位客户，最大主题K=6。原稿报告规范全集逆归纳：路径(1,1,1,2,0)每层M=13/10，总13/2；全部根SPE终局W=7，OPT₅=7。逐孩子ell原保在threshold_path_nonrealizability.json。此批只全文读MD报告，没读该JSON或重跑求解器，不将这些精确数冒新计算。

“所有SPE覆盖7”有独立于枚举的原解析证明，可直接复用：每人至少K/5=6/5，故W≥6。若不选主题1，最多覆盖另5客户，矛盾。若选1且覆盖≤6，则不能选2/3，否则覆盖全部7；于是所有行动0/1。任何选0者所得4/5<6/5，故只能全1；全1末位改2得1+4/5=9/5>6/5，又矛盾。因此每份SPE必W7，不存在W≤13/2的真实SPE。

这否定“沿任意最小M路径，每层选达到当前M的孩子即可形成同路径低福利SPE”的拼合。各层最低收入来自可能不同的完整菜单，不保相邻选中孩子相容。它**不反驳MP**，因13/2>7/2；也不反驳(1)，该路径末位0利润4/5<13/10并非BR，不满足j≤m−1真尾合同。不要把终端动作强行理性化却保留旧M路径当原报告已验证。
