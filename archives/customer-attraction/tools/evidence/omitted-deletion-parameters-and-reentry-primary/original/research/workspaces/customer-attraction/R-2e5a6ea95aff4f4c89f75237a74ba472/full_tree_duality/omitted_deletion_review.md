# 实际遗漏客户删除边界的独立核验

2026-10-23，独立子任务复核；只在本轮个人工作区保存。原始输入、参数分区实现及原报告位于同actor的 `omitted_deletion/`。一般 Q-CAG-HALF 不受此辅助归纳反例否定。

## 1. 从定义重建全部可实现续局

未导入规范solver，用Fraction直接从客户表计算收益。对计数前缀q，递归终局集合 E(q)，令

\[
M(q)=\max_b\min_{z\in E(q+e_b)}u_b(z),\qquad
E(q)=\bigcup_a\{z\in E(q+e_a):u_a(z)\ge M(q)\}.
\]

这个计数态缓存不限制历史依赖：同一q之后的每个有序历史仍可独立选择集合中的任意续局；不同动作分支的惩罚续局可独立拼合。每个历史玩家只移动一次，因而公式恰是完整SPE定义。

独立程序访问252个计数态，得到：原36客户根终局集恰为

\[
\{(2,0,1,1,1),(2,1,0,0,2)\};
\]

删除唯一遗漏的E-private客户后，根终局集恰为

\[
\{(2,1,1,0,1)\}.
\]

这里主题顺序为A,C,D,E,F。目标(2,1,0,0,2)在删除前可实现、删除后在所有完整SPE中均不可实现。

## 2. 短不可实现切口

任何实现目标的有序路径都必有“第二次F”。在它之前，计数为

\[
(a,c,0,0,1),\qquad 0\le a\le2,\quad0\le c\le1.
\]

删后对这六个前缀，改选D之后的全部完整SPE终局都唯一为(2,1,1,0,1)，偏离者D获得47/6。若按原目标选第二次F，它最终仅获得23/3=46/6，故严格偏离获益1/6。这排除任何目标路径和任何完整续局选择，不依赖某棵固定策略在删除后是否失效。六个续局集合已逐一精确存于独立报告。

## 3. t=3/4 的末节点开关

保留35名已覆盖客户，给唯一E-private类型质量t。考虑末层前缀(2,0,1,0,1)，即A,A,D,F。五种行动的收益为

| 末行动 | 收益 |
|---|---:|
| A | 17/3 |
| C | 77/12 |
| D | 23/4 |
| E | 17/3+t |
| F | 25/4 |

故t<3/4时唯一最优C，t=3/4时C与E平局，t>3/4时唯一最优E。选C的终局为(2,1,1,0,1)，前D得到47/6；选E的终局为(2,0,1,1,1)，前D得到20/3。这两个值分别位于目标F收益23/3的上下。它解释了：降低根路径从不覆盖的客户质量，仍能改变离轨末回复，使早期偏离从可惩罚变成有利。

本节点的解析比较只说明核心开关。完整“目标可实现 iff t≥3/4”仍依赖下面的全树参数分区，不能只用一个末节点代替充分性证明。

## 4. 参数分区及无界单客户敏感性审查

已逐行检查root的 `omitted_deletion/verify.py`。它枚举每个五人终局中所用主题的全部仿射收益线，并取两两全部交点。任何真实节点只会比较这些线，故每个开区间的全部收益弱序固定；从终层向上归纳，E(q)和各层实现分支结构在该区间固定。恒等相等保留平局；全部交点另作精确计算，未把端点并入开区间。这足以使有限代表成为该一参数族的穷尽性证明，而不是随机抽样。其输出211条不同仿射线、65切点、129代表；本审查确认覆盖论证，未重新逐一跑129代表。

其全区间结论是目标可实现 iff t≥3/4，且根强制收益门槛

\[
M(t)=\begin{cases}33/4,&t<3/4,\\7,&t\ge3/4.\end{cases}
\]

对任意整数k≥1，令q=4k+1；将每个covered类型重数放大q倍，E-private客户取3k+1人，再删去1人。归一化参数为

\[
t_+=\frac{3k+1}{4k+1}>\frac34,
\qquad
t_-=\frac{3k}{4k+1}<\frac34.
\]

因此目标从可实现变成不可实现，根门槛从7q跳至33q/4，差为5q/4，随k无界。两个实际整数实例中，上述关键末节点的E−C收益差分别为

\[
(3k+1)-\tfrac34(4k+1)=\tfrac14,
\qquad
3k-\tfrac34(4k+1)=-\tfrac34.
\]

两端的这个关键开关都严格，故不是仅因端点平局的现象。**没有证明全树所有激励均严格，也没有声称strict-SPE。**

目标福利为35q；客户总数删除前35q+3k+1、删除后35q+3k。它们远离half违规；该族只是删除闭包与门槛Lipschitz式归纳的真实障碍。一般结论来自全参数分区及齐次缩放，有限k回归只检查代数实现。
