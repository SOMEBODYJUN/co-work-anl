# 全部真实尾与实际行动列的准确域

固定[原模型](../定义/共同目录完整历史模型--定义.md)任意m≥1、任意完整纯SPE σ，其实际终局z=(S₁,…,S_m)、u_i=u_i(z)，h_k=(S₁,…,S_(k−1))。R(h_k,A)含前k−1项保持h_k、第k位强制A、之后任一**完整纯SPE**的完整有序终局；第k位自身无需在h_k理性，也不是仅沿原σ一个指定孩子。对y∈R定义v_j(y)。

\[
D_{k,A}=\{y\in R(h_k,A):v_k(y)\le u_k\},\qquad
D^{\rm all}=\bigcup_{k,A}D_{k,A}.
\]

**A=S_k也包括所有cap合法的替代尾完成**，不只原σ终局。这是本定理的承重域。旧[共同付款接口资源](../资料/可信端点共同付款的接口合同与停界--资料.md)中有“实际tag仅保原端点”的受限域；不能把本D^all的成员资格自动转进那个更小D，亦不能靠名称同为D静默放宽其source/容量合同。下述回收常常恰落在较早实际行动列D_(j,S_j)，故删这些列会失去落点。

# 无祖先cap的真实拼合阈值

对任意有序历史h，令ell_T(h)=min_(w∈R(h,T))v_T(w)，μ(h)=max_T ell_T(h)，极小仅要求真完整后继SPE，**不给旁枝加祖先利润cap**。有限性给非空/达到。指定T孩子w可被补成h处选T的完整SPE，当且仅当v_T(w)≥μ(h)。必要性由每个偏离X至少面对ell_X；充分性保留指定T孩子，其他X各贴达到ell_X的完整SPE，当前选中利润≥全部偏离，各有序子树互不相交。原σ沿实际h_l给u_l≥μ(h_l)。

# 回收定理与完整有序证明

**定理。** 对任意k、A、y∈R(h_k,A)，若某j≤k满足v_j(y)≤u_j，则y∈D^all；不保证仍在原D_(k,A)。

取满足弱不改善的最大j。j=k直接由定义。j<k时，对j<l≤k有v_l(y)>u_l≥μ(h_l)。先在h_k保留强制A后已给的真尾SPE，用阈值将A理性化。再从l=k−1逐层退到j+1，规定实际S_l，选中孩子是刚构造、终局仍为y的完整SPE；利润严格过μ，所以为其他行动贴各自无祖先cap最低真孩子，理性化该层。

这些h_l确实是实际前缀，因为y在第k位之前保持实际行动。新旁枝由首个有序分歧区分，不改选中路径或已贴后继；同计数历史仍可有不同回复。最终得到(h_j,S_j)之后完整SPE，终局恰同一有序y，且v_j(y)≤u_j，故y∈D_(j,S_j)。第j位是强制者，毋须再将其理性化。本结论不说原σ就在这些旁枝实现y。

弱等号亦合法：若某后位恰等号，它就进入便宜集合使最大j后移；随后严格HIGH正用于理性化。空行动、重复选择、零客户均不影响有限最小值和弱IC，证明从未限制为计数策略。

# 总cap、加权cap和相邻两位

非成员的必要条件：对任何此种表示y∈R(h_k,A)，y∉D^all ⇒ 全j≤k严格v_j>u_j。**不是充要条件**，同端点仍可能通过其他位置/行动/尾表示进入D。

若前k总利润Σv_j≤Σu_j，则必有某不改善者，故y∈D^all。更一般，对λ_j≥0且Σλ_j>0，Σλ_jv_j≤Σλ_ju_j亦足够；全体严格改善会使该权重和严格增。结论只在总并集，不把D_(k,A)当前单人cap逐点改成总cap。

令E_(k,A)={y∈R(h_k,A):min_(j≤k)(v_j−u_j)≤0}，则∪E_(k,A)=D^all：右到左由当前cap，左到右由回收定理。

相邻版：原位置i行动C=S_i、收益α=u_i，下一位收益β=u_(i+1)。固定背景h_i+C+A和真尾，端点两角色利润c,a。若a≤β直接D_(i+1,A)；若a>β而c≤α，由a>β≥μ(h_(i+1))把A理性化，得到D_(i,C)。因此c≤α或a≤β足够，尤其c+a≤α+β足够。第二分支不可省实际行动列D_(i,C)。

# 全改善提升与最坏福利的准确规范化

若y∈R(h_k,A)对所有j≤k都严格改善，则同一向上拼合继续到根：先理性化A，再理性化实际S_(k−1),…,S₁，得到根**另一份**完整SPE，终局仍同一有序y。k1直接根理性化。这给覆盖性二分：y属于D^all，或可提升为根SPE且前k均严格改善；两项不必互斥，提升者也可能别表示进入D。

固定实例，先在所有完整SPE终局选W最小，再在这些选u₁最大，得到规范化z。有限目录使可实现经济有序终局为有限S^m子集，极值达到，不需策略表示的紧性。若此时y∈R(h_k,A)、W(y)≤W(z)却y∉D^all，提升给根SPE且v₁(y)>u₁；最小W迫使W(y)=W(z)，再与同W最大u₁矛盾。所以该规范化路径有

\[
y\in R(h_k,A),\quad W(y)\le W(z)\quad\Longrightarrow\quad y\in D^{\rm all}.
\]

此转移不是任意给定σ都成立。若W(y)>W(z)，最小福利性不矛盾；换harmonic势/利润向量次级极值也不能把更高W候选排除。它不是将一个高福利SPE替换原低福利SPE就解决最坏福利。

# 查询接点仍缺低值可信端点

固定目录查询分布p，t_x=Pr_(T∼p)[x∈T]，对**完整m槽**端点y定义G_p(y)=Σ_x t_x/(1+c_x(y))。若找某真y∈R(h_k,A)同时G_p(y)≤W/m且Σ_(j≤k)v_j(y)≤Σ_(j≤k)u_j，则本引理回收成D^all合法cap端点；只需任一前缀角色不改善即可。规范化时可用W(y)≤W(z)供应cap。不要把它与删当前槽的m−1背景SC查询合并。

定理没有生产这个低G且前缀不全改善（或不增W）的y。对D^all的harmonic势最大端点，势更大的可移植suffix-SPE若仍在某实际前缀强制一动作后，则它必须同时改善该前缀全部利润，否则已经回收而违反最大性。这只是必要条件，不是新付款钱包；还须真实IC控制静态高插入交换、后继SPE和前缀总额。

原文末两人菜单界min_D G≤min(u_(m−1),u_m)本身不足W/m；五人时若末两都大于W/5该路线当时未支付。当前[五人half](../定理/五人半覆盖--定理.md)另证，不会把本引理升级为一般低G构造，也不自动解恰六人。原capacity独审先主迁移后§5提升/规范化补审准确见[读序资源](../审查/前缀编译与阈值端点的真实审查读序--审查.md)。
