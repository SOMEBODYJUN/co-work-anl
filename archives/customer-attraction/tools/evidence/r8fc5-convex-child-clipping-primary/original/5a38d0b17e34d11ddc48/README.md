# 全深度向量归纳：精确状态与凸化停界

2026-10-23；个人探索，未提升共享 Claim。Q-CAG-HALF 仍 OPEN。

本轮尝试保留全部客户负载和全部主题查询收益的向量状态，而非压为
tail 总利润或标量 gap。精确集合值递推本身已有规范实现，不作为新结果。
本轮得到一个小而自足的真实模型边界：**即使保留完整终局向量，也不能先
对孩子 SPE 结果取凸包、再用父玩家激励截取。** 两人、三个主题、四名
单位客户已经严格失败；不是半覆盖反例。

- `convex_child_clipping_obstruction.md`：精确递推、四客户解析反例、独立
  全有序策略枚举、一个线性负载矩分离行，以及由此保留的准确义务。
- `audit_convex_child_clipping.py`：标准库 Fraction；先查零客户、空主题、
  一人边界，再直接枚举两人完整策略并逐历史验证，不调用规范求解器。
- `audit_report.json`：本轮实际输出。

这里没有可证明 half 的新全树不变量。若继续此方向，必须保留孩子结果
与父玩家收益的原子对应，或者另证扩大到公开抽签续局后的 half；后一
命题不是原纯 SPE 模型的形式等价。不能把凸化松弛的精确递推称作原模型
归纳，更不能靠重新加入更多线性查询坐标修复下述非交换性。
