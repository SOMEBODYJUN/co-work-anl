# 同支删除与旧玩家损失的共同信用

2026-10-23；研究备份，未经独立审查。一般 Q-CAG-HALF 仍 OPEN。

本目录只保存一个任意人数的终局代数引理及其精确审计，不是一般半覆盖证明。

- `same_branch_common_credit.md`：删除后旧前缀的逐客户正损失，与当前偏离者的绝对稀释返还，不重复占用实际覆盖客户的信用；每客户锐上界为 `1-1/d`，其中 d 是该真实分支的删前负载。
- `audit_same_branch_credit.py`：独立 Fraction 标量枚举、边界见证、完整有序历史逆向归纳和实际真实分支审计。
- `same_branch_credit_audit.json`：初版实际冻结运行的精确计数与结果。
- `same_branch_credit_audit_v2.json`：增加 m=1,…,64 单主题唯一完整 SPE 重入审计的现行冻结结果；初版未改写。

尚缺的承重步骤：把一个足以支付遗漏客户的真实子树构造转成**每客户总质量至多一**的信用耦合，或更弱的K加权容量合同，或证明多次重入的超支由新信用支付。同支锐界不提供这个归一，互斥分支也不能无权相加。接续请先读正文第 4—5 节。

已获解析停界：单主题唯一完整 SPE 若每个实际深度都任意删除全部未来者，精确共同信用之和为 `H_m-1`，四人已大于 W，人数增加时无界。这不是 strict 低于 `W/m` 或 `OPT/(2m)` 的内生阈值反例；本例在这些阈值下没有低收益玩家。
