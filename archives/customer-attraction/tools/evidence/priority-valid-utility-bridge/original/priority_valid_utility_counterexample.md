# 共同目录的预算平衡 valid utility 博弈仍可有任意差的纯 SPE

候选身份：`LB-PRIORITY-VALID-UTILITY-SPE`。状态：2026-10-21 本轮直接证明与定义级有限审计；已由另一研究员独立重构核对全部历史与valid-utility条件；尚未外审，新颖性未认证。它是一个外层假设反桥，**不是**匿名均分 CAG 的反例，不改变 `Q-CAG-HALF` 的 OPEN 状态。

## 精确命题

对每个整数 `m>=1`，存在一个 `m` 人顺序博弈，所有玩家有相同的有限非空目录，福利为单位客户的单调次模覆盖函数，个人收益满足

\[
u_i(a)\ge W(a)-W(a_{-i}),\qquad \sum_i u_i(a)=W(a),
\]

但存在对全部有序历史最优的纯 SPE，其福利为 `1`，而最优福利为 `m`。因此当 `m>=3` 时，单凭“共同目录+预算平衡 valid utility+单调次模覆盖福利”不能推出 `2W>=OPT_m`。这里分配具有玩家编号优先权，**并非匿名分配，也不是同质玩家的均分游戏**。

零客户另取唯一目录 `{emptyset}`，所有收益和福利均为零；直接使用乘法不等式，不给 `0/0` 赋值。

## 模型与完整证明

客户集为 `N={1,...,m}`，共同目录为全部 `m` 个 singleton：

\[
\mathcal S=\{\{1\},\ldots,\{m\}\}.
\]

玩家按编号 `1,...,m` 依次观察完整有序历史，每人选一次，可重复选择。终局 `a` 中，每个被覆盖客户的一单位价值全给覆盖它的最高编号玩家：

\[
u_i(a)=\sum_{x\in a_i}
\mathbf1\!\left\{i=\max\{j:x\in a_j\}\right\},
\qquad W(a)=\left|\bigcup_j a_j\right|.
\]

此公式也定义了玩家不参与时的收益：从覆盖者集合中删除它。无需把空主题加入可行目录。

**valid utility。** 对每个客户，覆盖指示函数单调次模；对客户求和仍单调次模。将 ground set 取为带玩家标记的行动对象也成立：一个客户是否被覆盖只是这些对象是否与固定的覆盖者子集相交。若移除玩家 `i` 损失一个客户，`i` 是该客户唯一覆盖者，故也必是其最高编号覆盖者，并取得该客户全部价值。因此逐客户有收益不小于移除边际。每个被覆盖客户有且只有一个赢家，故所有个人收益之和恰等于福利。这些结论对任意终局成立，不限于均衡路径。

**完整策略。** 第一名玩家选择 `{1}`；每个 `i>1` 在任何历史 `h=(a_1,...,a_{i-1})` 选择 `a_{i-1}`，即复制紧前玩家。

固定任意玩家 `i<m`、任意历史和任意当前行动 `T`。在该分支，玩家 `i+1` 复制 `T`，归纳可知所有后继都选择 `T`。特别是最后玩家 `m` 覆盖 `T` 的客户，其编号高于 `i`，所以当前玩家终局收益为零。当前玩家的所有行动均给零，策略行动因而最优。对最后玩家 `m`，任意 singleton 都给一，因为它总是自己所选客户的最高编号覆盖者；复制也是最优。这核对每个有序历史及每个偏离，故上述策略是纯 SPE。

在均衡路径所有人选择 `{1}`，所以 `W=1`。每人选不同 singleton 则覆盖全部 `m` 个客户，而总共只有 `m` 个客户，所以 `OPT_m=m`。`m=1` 时结论仍成立，`m=2` 时半覆盖恰取等号，`m>=3` 时严格违反半覆盖。

## 承重假设与解释

该例保留共同目录、单位客户、有限一次顺序行动、完整信息、所有历史 SPE、单调次模福利、收益边际下界及预算平衡。它破坏匿名均分：同一客户的不同编号覆盖者收益不相同。不可称其为“对称游戏”，只能称为“共同目录游戏”。

因此一般半覆盖证明必须利用比分配总和和个人边际下界更强的信息。比如匿名均分在每个客户处给所有覆盖者完全相同的份额；上述尾部复制链用编号把早期偏离者的份额压为零，均分规则不允许这个压低机制。后一解释只说明反例机制的承重，不是均分规则充分的证明。

文献归属：valid-utility 条件来自 [Vetta, FOCS 2002](https://web.mit.edu/6.454/www/www_fall_2004/gametheory/VettaNashEquilibria.pdf)。本构造为本轮直接推导；未认证其文献新颖性，也不声称优先分配本身新颖。
