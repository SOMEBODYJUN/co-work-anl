# 递增角色捕获流的客户命中容量

2026-10-23，mixed_menus。身份：任意人数、任意共同目录、完整原策略树上的一般组合关系；不需要 SPE，因此也不支付单独的行利润超额。root及credible均已独立重构上述逆归纳并确认；无外审或新颖性认证。Q-CAG-HALF仍OPEN。

## 1. 所用流与概率解释

复用credible/tail的 `../credible/increasing_role_capture_flow.md`。对一个实际遗漏客户x，每个状态(i,a,x)都读取原实际前缀下的同一原策略真实叶Z_i(a)。设F为该叶中在i之后覆盖x的角色集合，d=|F|。

在此状态的一单位流以1/(1+d)在当前吸收，并以相同份额送给每个j∈F的后继状态。每个后继角色严格大于i。把此分流看作一个随机粒子：它等概率选择“当前吸收”或某一覆盖它的更深角色，并在到达新状态后重复。同一客户的全部确定性分流就是这个有限吸收链的概率质量。

因此一条粒子路径至多进入每个角色一次。虽然不同路径可以在同一角色的多个主题状态合流，流入某角色的总质量仍恰是粒子曾进入该角色的概率；不能把各合流路径当成独立的一单位源。

## 2. 任意角色集合的命中界

固定目标角色集合J。粒子从角色s开始，且s不在J。令

    k_s = |J∩{s+1,...,m}|。

则

    Pr(粒子以后曾进入J) <= k_s/(k_s+1)。       (HIT)

特别地，k_s=0时概率为零；对任意单个非初始角色i，客户全部主题状态的合计流入至多1/2。

**集合量词必须保留：** 多行J的左端是首次/曾命中的概率，而不是sum_(i∈J)进入各行的总流入。同一条粒子路径可以先后进入J中多个角色。只有J为单行时，总流入才直接等于这一个命中概率。

证明不限制同角色的主题数，不合并等计数历史，也不替换真实后继。固定从某个角色s出发后尚可遇到的k个目标角色，对所有非目标状态按角色逆序归纳。当前直接后继中有t个目标角色（t<=k）和n个非目标角色。目标后继的命中概率为1；非目标后继按归纳至多k/(k+1)。当前吸收不会命中J，所以当前命中概率至多

    [t+n k/(k+1)]/(1+t+n).

与k/(k+1)的差精确为

    (k-t)/[(k+1)(1+t+n)] >= 0。

故对全部非目标状态成立。较小的剩余目标数只使上界更强；在初始角色代入k_s即得(HIT)。若从J内开始，命中概率当然为1。

这是一条真实流收缩，范围不同于“每条规定叶可以领取一笔H”。它对允许任意多次重置的整个递增角色吸收链仍成立。

## 3. 自由owner、matching和混合初始化

对x若有分数源q_s(x)>=0、sum_s q_s(x)=1，源所在主题可以随s不同，只要包含x。流对初始化线性，因此

    mass_x(hit J)
      <= sum_(s∈J) q_s(x)
        +sum_(s∉J) q_s(x) k_s/(k_s+1)。          (MIX-HIT)

原先每个客户选一个owner、比较索引到角色任选matching是q为单点的特例。对任意owner选择随机均匀matching时，源角色边际q_s=1/m，故单行i有

    total incoming_i(x) <= (i+1)/(2m)。          (UNIFORM-HIT)

这里对matching取平均，不要求各角色后的动作状态相同，也不以uniform matching规定实际证明只能使用这个选择。自由matching和客户owner始终保留。

## 4. 与标量IC付款的连接及限制

单个确定初始化中，令x的owner角色为s(x)。对角色i的源状态之外，任何客户的总流入均至多1/2；源角色上该客户只有其初始化状态的一单位流。

记D_i^R(a)为真实查询D_i(a)截在R上的利润。若角色i没有初始化于主题a，则该主题状态的总吸收满足

    A_(i,a) <= (1/2) D_i^R(a)，
    w_(i,a)=A_(i,a)/D_i(a)
          <= (1/2) D_i^R(a)/D_i(a) <= 1/2。      (NODE-CAP)

若a为该角色唯一初始比较主题，初始化客户可用系数1，其余客户仍用1/2。零分母必无正吸收，按w=0处理。

**尚未得到的量。** 同一行仍可包含很多不同主题状态；分别的(NODE-CAP)不能相加成L_i<=1。原完整child IC尚须约束这些互斥真实分支之间的主题竞争，并将总signed overload与实际G支付连接。本文没有证明Σ_i(L_i−1)u_i<=G，没有把命中界称为half或自由匹配的闭合。

本关系可直接加入后续剩余OPT槽库存流的客户级容量：对单行控制总流入，对任意行集合控制首次/曾命中量。它不容许对原IC按客户任意重加权；IC付款仍只能用每条完整收益比较的一个非负常数。

## 5. 同一owner取消库存后的节点势误差

采用credible实际G运输给出的取消量γ_x∈[0,1]，残源ρ_x=1−γ_x。这里源位置必须与shared owner势中的同一o(x)相符；不能改变源owner后仍用另一份势的owner零误差。

HIT对质量线性，所以R客户在非owner角色的状态总流入q_x<=ρ_x/2，在其owner角色只有初始源q_x=ρ_x（而owner势误差e_x=0）。

固定一个查询状态(i,a)，r_x=1/c_x(Z_i(a))，原完整收益D=sum_(x∈a)r_x；R当前吸收A=sum_R q_x r_x，w=A/D（零值按0）。令owner势的单位边际为ℓ_x=r_x−e_x，E_I=sum_(x∈I∩a)e_x。代入wD=A精确得到

    w sum_x ℓ_x−sum_R q_x ℓ_x
      =sum_R q_x e_x−w sum_x e_x
      <=sum_(x∈R∩a:i≠o(x))(ρ_x/2−w)e_x−wE_I。  (RHO-COV)

这是tail节点协方差式的残库存版本。它没有按客户改变IC系数；w仍是一整条合法查询IC的唯一标量。若γ_x=1，被取消客户仍在合法查询及D中，源q_x却为零，所以其贡献为−w e_x；取消量既减少需求，也保留原查询利润的稀释作用。没有给实际G第二份独立信用。

各状态正误差之和仍未被实际η行容量支付；尤其ρ、w及后续query选择须属于同一份共同构造，不能逐状态另挑取消客户。
