在[共同目录完整历史模型](../定义/共同目录完整历史模型--定义.md)固定同一份完整历史纯SPE。总人数任意，每个被用 source 节点真正剩两人。查询菜单只须是共同目录合法主题，允许来自其他记录族、重复、为空；不将其他分支回复当成本枝真实后继。

## 三条真IC及五个索引模式

source i 背景负载 pᵢₓ、实际两人主题 Aᵢ,Bᵢ。令

\[
f_i(T)=\sum_{x\in T}(p_{ix}+1)^{-1},\quad
g_i(T,S)=\sum_{x\in T\cap S}[(p_{ix}+1)(p_{ix}+2)]^{-1},\quad U_i(T,S)=f_i(T)-g_i(T,S),
\]
\[
H_i=U_i(A_i,B_i)+U_i(B_i,A_i)+g_i(A_i,A_i).
\]

对所有合法 T,S，[既有强PAIR](末两人重叠比较与任意索引聚合--引理.md)给

\[
H_i\ge f_i(T)+f_i(S)-g_i(T,S). \tag{1}
\]

自足地，Q 为同一策略在强制 T 后的真实最后回复。δ₁=U(A,B)−U(T,Q)、δ₂=U(Q,T)−U(S,T)、δ₃=U(B,A)−U(Q,A) 全非负。左减右等于 δ₁+δ₂+δ₃+g(A,A)−g(A,Q)，最后项在 A\Q 上求正权和。这里仅把 Q 移作原末位的合法查询，未冻结后继。H 含 self-tax，不能把它称作已由实际福利支付的纯两人利润。

取 q 个 source 节点及长度 q 的查询菜单 Mⱼ,Nₖ。固定客户，b=1ₓ∈Mᵢ,c=1ₓ∈Nᵢ，B=Σⱼ1ₓ∈Mⱼ,C=Σⱼ1ₓ∈Nⱼ,K=Σⱼ1ₓ∈Mⱼ∩Nⱼ。将(1)按三索引 i,j,k 的五种等号型分别求和，客户系数为 Σᵢ[n Hᵢₓ−L/(pᵢₓ+1)+M/((pᵢₓ+1)(pᵢₓ+2))]，其中

| 型 | n | L | M |
|---|---:|---|---|
| i=j=k | 1 | b+c | bc |
| j=k≠i | q−1 | B−b+C−c | K−bc |
| j=i≠k | q−1 | (q−1)b+C−c | b(C−c) |
| k=i≠j | q−1 | B−b+(q−1)c | (B−b)c |
| i,j,k全异 | (q−1)(q−2) | (q−2)(B−b+C−c) | (B−b)(C−c)−(K−bc) |

表由固定 i 后数 (j,k) 而得，五类计数合 q²，q1/2的空类系数全0。这与[同族等号模式](末两人比较三索引的等号模式闭包--引理.md)是同一计数；本对象新增处是 target tuple 来自不同族时怎样保留**同一个未知匹配**。

## 保共同锚点的逐客户运输

source 的 (pᵢ,Hᵢₓ) 与 target 的 (bᵢ,cᵢ) 各保相同已知索引标签 tᵢ，通常是同一 Tᵢ 对该客户的会员位。各标签组基数一致。允许 target tuples 在标签内任意置换，同时让所有被组合行使用同一置换。对每客户最大化上述行系数，得到真系数的上界；将这些上界按非负客户质量相加必须≥0。对固定 source/target 联合 tuple 域，任何预先固定的非负多行组合亦可在一个配对下共同最大化。若同时涉及多个不同 target 族，须保留其联合归属或处理多边缘兼容，不能把独立 pairwise 最优直接拼接。原代码仅处理单个 orbit 行，不冒称已优化任意 pair-orbit 联合权重。

某标签内将相同 source 状态归为 α 类计数 uα、相同 target tuple 归为 β 类计数 vβ，代价 Cαβ，则逐客户问题是

\[
\max_{n\ge0}\sum_{\alpha,\beta}C_{\alpha\beta}n_{\alpha\beta},\quad
\sum_\beta n_{\alpha\beta}=u_\alpha,\quad
\sum_\alpha n_{\alpha\beta}=v_\beta. \tag{2}
\]

其对偶为 \(\min\sum u_\alpha r_\alpha+\sum v_\beta s_\beta\)，约束 rα+sβ≥Cαβ，r,s自由。有限运输强对偶适用；整数边缘可展开成带重复的单位 slots，二分图指派多面体的整数极点给整数最优运输。因此(2)是该逐客户配对的精确极值，仍不保证不同客户最大化使用同一主题置换，更不保证整个历史策略兼容。此区别亦见[末位包络定理](../定理/真实末位菜单的共同归属上包络--定理.md)。

## 两个调和排序闭式

置 aᵢ=1/(pᵢ+1)、eᵢ=1/(pᵢ+2)、bᵢ=aᵢ−eᵢ。每标签 target 的 M、N、交叠数为 kₜ,lₜ,hₜ，union uₜ=kₜ+lₜ−hₜ；B=Σkₜ,C=Σlₜ,K=Σhₜ。以下客户表达式的总和均必要非负：

\[
\begin{aligned}
E_x={}&(q-1)\sum_i H_{ix}-(B+C)\sum_i a_i+K\sum_i b_i
 +\sum_t[\operatorname{Top}_{a,t}(u_t)+\operatorname{Top}_{e,t}(h_t)],\\
F_x={}&\sum_i H_{ix}-\sum_t[\operatorname{Bottom}_{a,t}(u_t)+\operatorname{Bottom}_{e,t}(h_t)].
\end{aligned} \tag{3}
\]

E 对应 j=k≠i，F 对应三者全等。可变分数 aᵢ(b+c)−bᵢbc 随 b+c=0,1,2 取0,aᵢ,aᵢ+eᵢ，即添加0/1/2覆盖者的调和增量。若 p 小，两个逐级增量都大；同向交换把较大会员数移到较小 p 可使总分不减。h≤u，且 a,e 对 p 有相同排序，故取嵌套 Top(u)、Top(h) 能同时达到两项最大；Bottom 同理。取 E 中正分数最大、F 中被减分数最小，均为原行上界。此处未丢 target 交叠，也没有假设 families 独立。

## 锚点内背景常值时的精确消配对

若 source 每组 pᵢ=pₜ，则五模式中 query 代价求和在该组只依 target tuple 的计数，任何标签保持置换均相同。source 只贡献 nΣHᵢₓ；target 贡献

\[
\sum_{\text{target tuples }z}\left[-\frac{L(z)}{p_{t(z)}+1}
 +\frac{M(z)}{(p_{t(z)}+1)(p_{t(z)}+2)}\right]. \tag{4}
\]

这不是将 per-client 最大值误称 global 实现，而是所有允许配对在该代价上本来相同。五人 AB/AE source 分别有 p=a+b+tᵢ 或 a+e+tᵢ，因此160个跨族 pair 行均有 source/target 直方图加法分离；另60个 second-source 行 p=a+tᵢ+hᵢ，可随配对变化。加这160行时仍须检查其他待定系数是否保持原定价分离，不能只因标题便假定。

任意总人数也有精确例：固定一个真正余三人的共同前缀 h，令倒数第三人依次强制 Tᵢ，后面两人沿同一策略实际选 Rᵢ,Sᵢ。对客户 pᵢ=pₓ(h)+tᵢ，组内常值。另取任何合法 Mᵢ,Nᵢ，保其同 Tᵢ 的联合会员数。nₜ=#{i:tᵢ=t}，aₜ=1/(pₓ(h)+t+1)，bₜ=1/((pₓ(h)+t+1)(pₓ(h)+t+2))。j=k≠i 的**literal**不等式为

\[
\boxed{(q-1)\sum_iH_i\ge\sum_x\left[(B+C)\sum_t n_ta_t-K\sum_t n_tb_t
 -\sum_ta_t(k_t+l_t)+\sum_tb_th_t\right].} \tag{5}
\]

直接在表第二行代入组常值即得，没有匹配最大化损失。B,C,K及组计数均依客户，不能移出客户和。共同前缀且余三人是关键前提；不适用于任意 source 历史。其任意人数有效性尚未给出从所有前缀到实际 W 的共同支付。
