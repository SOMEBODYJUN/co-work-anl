# 所有路线共用的真实偏离合同与弱界

在[共同目录完整历史模型](../定义/共同目录完整历史模型--定义.md)中，取正整数 $m\ge1$，固定一份在全部有序历史定义的纯SPE σ，actual $z=(S_1,\ldots,S_m)$、收益u、覆盖W，任意合法比较m元组并集C、大小O。空主题、重复、同覆盖异标签、零客户和平局均保留。每个真实节点强制A后，后继沿**同一σ在改变后的历史**完成；当前激励只给 $d_h(A)\le u_{\rm current}$，不能改成冻结actual后继的静态插入。

历史前缀负载b、余r人时，有逐客户保底

\[
u_{\rm current}\ge\max_T\sum_{x\in T}\frac1{b_x+r}. \tag{1}
\]

令最大主题大小K。实际位置i满足每客户 $b_x+r\le(i-1)+(m-i+1)=m$，故每位 $u_i\ge K/m$，从而 $W\ge K$。所以若某主题覆盖至少O/2客户，half立即成立；这只给任何输入可直接检查的充分情形，不修改题面或证明余下输入。W0时K0、全部合法主题空，比较覆盖也0，不取效率比。

独立重构试图把遗漏集合 $D=C\setminus\bigcup_iS_i$收费到实际利润。$|D|\le W$足够推出 $O\le W+|D|\le2W$，但仍未证。任意遗漏客户可分配给某个比较主题，不等于未来行动只触一个分配块：同一后继可在很多块各加少量负载，让多个近阈值机会同时失效。私有块“每行动消耗一个席位”的归纳不自动迁到任意交叠目录。未付的是总机会损失与该后继**真实最终利润**的共同关系。

# 末位完整额外槽菜单LAST及其精确静态结构

取actual前m−1位形成的客户背景b，对任意目录主题T、A定义

\[
K_b(T,A)=\sum_{x\in T}\frac1{b_x+1+1_{x\in A}},\qquad
M_b=\min_{q\in\Delta(\mathcal S)}\max_T\mathbb E_qK_b(T,A). \tag{2}
\]

q独立于查询T抽样。每列b+A是m个合法竞争主题，查询另占一槽；不把末位真实回复菜单或任意大背景额外槽值改名成M_b。既有静态目录计数给

\[
\mathrm{OPT}_m\le2m\,v_{m+1}(0)\le2mM_b.
\]

因此[LAST](../候选/实际末前背景的聚合安全值--候选.md)的 $mM_b\le W$是half的**充分候选**，不是等价或已证关系。末位BR只给 $u_m=\max_T f_b(T)$，不能换成W/m。LAST若失败也不能因此否定允许全部位置混合的更自由Mpath。

逐客户令

\[
f_b(T)=\sum_{x\in T}\frac1{b_x+1},\quad
H_b(T,A)=\sum_{x\in T\cap A}\frac1{(b_x+1)(b_x+2)},
\quad K_b=f_b-H_b.
\]

H_b是非负对称Gram核。有限minimax给

\[
M_b=\max_p\{f_b(p)-\max_AH_b(p,A)\}. \tag{3}
\]

最大化凹二次式 $J_b(q)=f_b(q)-H_b(q,q)/2$的KKT给

\[
K_b(T,q)\le K_b(q,q)=f_b(q)-H_b(q,q),
\]

支持主题取等，所以q是一个可行列并给 **上界** $M_b\le K_b(q,q)$。一般没有等号，也没有“最优行分布等于q”的结论；核对称不能消掉非对称的行项f_b(T)。

## 两不交主题例只区分最优行列，不反驳该例数值等号

根稿以整体除以2的有理记账写主题规模(3/2,1)。正式单位实例可取两个不交主题含3和2名客户，其核为

\[
K=\begin{pmatrix}3/2&3\\2&1\end{pmatrix}.
\]

凹二次最大者/最优列 $q=(4/5,1/5)$，最优查询行 $p=(2/5,3/5)$；直接有

\[
Kq=(9/5,9/5)^T,\qquad p^TK=(9/5,9/5),
\]

故此例 $M=9/5=K(q,q)$。原稿用它纠正**行列分布不同**，并不能把它升级成QP自响应严格大于minimax的反例。这个区别应与下面26客户真分离共同保存。

# 静态势、额外一槽与租金席位的独立重构

**静态势。** 对固定背景b，单人替换的调和势差等于静态利润差，故全局最大势m元组是静态PNE。任何额外插入T的收益不超过替换任一已有玩家后的收益，所以其插入价不超过每个已有玩家利润。但尚未证任意根SPE的W至少支付m倍该静态元组的最低利润；真实早期偏离会改变后继，不能把全局势最大终局直接指定为原σ的某个孩子。两人时可选一份最大势对的首主题，任意真实末位BR都保同样最大势；超过两人，真实suffix未必到达全局最大势，递归缺口仍在。

**任意背景逐人extra-one。** 原候选 $u_{\rm current}\ge v_{r+1}(b)$已被[PB-extra完整子SPE](../反例/任意合法背景的前两人额外槽安全值--反例.md)反驳，甚至前两人块也失败；不是仍开放候选。其r2475背景合法且已全覆盖客户，不能移作根实际前缀或half反例。后继[最后D单例障碍](../障碍/PB大背景的最后单例偏离--障碍.md)更排除该原构造直接在轨；本批来源只复核其范围，未另证明全部巨大构造。它不反驳actual末前LAST或自由Mpath。

**租金席位。** 可对正租金t考察可变主题槽数的辅助目标 $\Phi_b(q)-t|q|$。最大元上，正占用槽删除边际至少t，任何插入边际至多t。但它不是原固定人数的SPE，任意交叠又缺单席位交换性质。所需连续机会信用与真实后继利润关系没有建立，终局降权也不自动保SPE；现有水位工具指出这一可信性缺口，不可对降权对象直接调用原单位玩家的深度归纳。
