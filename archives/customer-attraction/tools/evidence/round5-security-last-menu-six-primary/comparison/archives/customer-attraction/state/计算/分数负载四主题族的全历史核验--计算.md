# 分数负载四主题族的全历史核验

## 原证书是什么

本对象保存并重新执行与[实际缩放付款桥反例](../反例/实际均匀缩放负载的弱付款桥--反例.md)相连的有限证书，同时说明两项正面引理的回归范围。所有源版本和SHA-256见[来源清单](../../tools/evidence/fractional-load-boundaries/source-manifest.json)。这里只认证列出的精确有限输入；任意人数无限族、分数覆盖递推及水位存在性由相应解析正文证明。

[原四人证书](../../tools/evidence/fractional-load-boundaries/original/evidence/certificates/customer_attraction/fractional_actual_load_failure.json)是没有自带客户输入的JSON，必须与[17单位客户输入](../../tools/evidence/fractional-load-boundaries/original/examples/customer_attraction/fractional_actual_load_failure.json)配对。主题编号固定为`0=A,1=B,2=Q,3=D`，四种客户为`A:3,Q:1,AD:1,BQD:12`，四名单位提供者最终均分客户。

`terminal_counts=[1,3,0,0]`只记录预期终局计数，不是SPE证明。证明数据是`actions`中的完整映射：`history`为长度0、1、2、3的有序主题序列，`action`为该历史指定动作。分别有1、4、16、64行，共85个决策历史，没有识别同计数历史。跟随规定行动的根路径为`[1,1,1,0]`即`B,B,B,A`。

原表必须原样保留。标准库审计另外按解析族的有限BI奖金策略生成规范表；两表在13个离轨节点上不同，包含历史`[1,2]`，但都分别通过全部历史最优性并有相同实际叶和标量结论。[逐点比较](../../tools/evidence/fractional-load-boundaries/certificate-comparison.json)列出差异。不能以相同终局或相同查询值为由声称它们是同一完整策略。

## 如何逐定义认证

[原标准库审计](../../tools/evidence/fractional-load-boundaries/original/tests/audits/customer_attraction_fractional_actual_load.py)不导入CAG求解器、规范验证器或发现器：

1. 将客户重数展开为不同单位客户，检查动作表恰覆盖全部\(\bigcup_{t=0}^3\{0,1,2,3\}^t\)，无重复键或遗漏。
2. 对每个历史\(h\)、每个当前动作\(a\)，先接上\(a\)，再沿该动作表的真实续局得到完整叶。对当前角色逐客户算最终均分收益，比较指定动作与全部四动作。
3. 检查根终局、每名收益、利润和福利守恒；对全部\(4^4=256\)个比较主题元组求最优覆盖，并分别验证保持有效的覆盖代数。

85节点共有255项非自身行动比较，最小SPE差0；因为每个子博弈的当前行动都最优，有限完美信息的一步偏离原则给完整纯SPE。缺一行的动作表被拒绝，另以零客户重跑同一完整表覆盖零福利边界。

本次原证书重放得到

\[
(u_1,u_2,u_3,u_4)=(4,4,4,4),\quad W=16,\quad\operatorname{OPT}_4=17,
\]

\[
(g(A),g(B),g(Q),g(D))=(16/7,48/13,61/13,388/91),\quad G=544/91.
\]

弱桥缺口\((7/2)M-W=11/26>0\)；精确税桥余额\(W+G-4M=292/91>0\)，half余额15。这三个符号不同的量不能混称“half反例”。

## 规范族及后续13人边界

同一审计从有限BI辅助策略独立生成\(m=2,3,4,5,6\)的完整有序表，节点数分别5、21、85、341、1365，非自身比较数分别15、63、255、1023、4095，全数精确通过。每项都检查\(W=m^2\)、\(\operatorname{OPT}_m=m^2+1\)、查询公式和弱桥差；只在\(m\ge4\)断言弱桥差严格正。

这些有限重放不是任意\(m\)的归纳。无限族的完整历史最优性已经在反例正文逐分支证明。特别地六人检查给\(W=36,\operatorname{OPT}_6=37\)，half余额35，只否定加强式桥。

为核实原文§5中“精确税桥也已失败”的后续状态，本次还实际执行旧13人[自动机审计](../../tools/evidence/fractional-load-boundaries/original/research/workspaces/customer-attraction/R-c50fecc37aa44fb4a69a2122bb70e5fe/security/audit_refined_tax_packet.py)。它读取冻结压缩packet，检查根、每条观察边计数递增、终端深度、所有节点可达，并从叶逆序核27243节点、112050项含自身IC；36客户逐单位展开，用整数公分母精确计算。最小差0，实际\(P^{10},A,A,B\)，\(W=33,\operatorname{OPT}_{13}=36\)，精确税缺口\(29481/123025>0\)。[结果](../../tools/evidence/fractional-load-boundaries/replay-refined-tax.json)是固定有限反例的完整认证，不是一般padding证明。

对同packet另运行[后续\(\alpha=1\)算术](../../tools/evidence/fractional-load-boundaries/replay-alpha-one.json)，得基本税付款及纯共同冻结查询付款都差\(37/66>0\)。该程序只重算已有真实叶，SPE合法性由前一全自动机审计承担。

## 两项正面工具的回归范围

[分数覆盖审计](../../tools/evidence/fractional-load-boundaries/original/tests/audits/customer_attraction_fractional_cover.py)使用`Fraction`检查640项产品/递推/单调性、4650项归纳乘积比较。有限SPE输入为：至多三标号主题时所有非空兴趣类型的0/1重数、人数1至4；另24个固定种子的四主题五人整数重数输入，部分含无兴趣客户。规范集合值求解器保留全部可实现有序路径。共576实例、2457路径、41182项前缀比较；每实例另验证一份完整动作证书，共15836节点，含12个零客户实例、92个含空主题实例。

该程序提供显式可行覆盖（含部分同类型客户比较集），没有计算分数覆盖最优值；576份完整策略不等于它为每条路径均导出一份独立策略。有限数据检验的是[真实前缀利润引理](../引理/分数覆盖的真实前缀利润预算--引理.md)的实现和边界，普遍真值由解析证明承担。[报告](../../tools/evidence/fractional-load-boundaries/replay-cover.json)记录精确范围。

[水位标准库审计](../../tools/evidence/fractional-load-boundaries/original/tests/audits/customer_attraction_waterfill.py)不导入作者核心或求解器。16个有理例检查私有客户正权停、零端点低于/等于阈值、初始高尾保1、重复尾、空主题、零客户、无尾部、\(t=0\)、背景返还放大；共49个全部客户子集分别检查替根\(Q\)与保留根插入\(J\)及同一客户池。需要部分停水时，fixture提供有理候选根，程序精确验证其等阈值及单调唯一性；它不是通用代数求根器。另对\(1/\sqrt2\)用严格有理二分，宽度\(2^{-100}\)，不用浮点残差冒充精确证明。[结果](../../tools/evidence/fractional-load-boundaries/replay-waterfill.json)只支持这些边界，普遍结论见[共同查询信用与守恒引理](../引理/分数尾水位的共同查询信用与利润守恒--引理.md)。

```sh
python3 replay.py --output-dir 新的结果目录
```

[复跑入口](../../tools/evidence/fractional-load-boundaries/replay.py)先核来源哈希，在临时副本执行未修改原审计，全部通过后才复制新结果；要求输出目录不存在，原冻结文件不被覆盖。全部依赖随证据保留，只需Python标准库。[本次总报告](../../tools/evidence/fractional-load-boundaries/replay-summary.json)汇总实际执行量。

数学关系分别是：四人完整策略与规范族实现反驳弱桥；13人自动机另行反驳精确税桥；产品与水位计算只是已证明引理的有限回归。三者不组成一般六人half的反证，也不反驳真正安全值聚合。既有独立内部审查覆盖范围已逐一核读；本次是源阅读、精确复跑与语义整理，未认领原发现、外审或新颖性。
