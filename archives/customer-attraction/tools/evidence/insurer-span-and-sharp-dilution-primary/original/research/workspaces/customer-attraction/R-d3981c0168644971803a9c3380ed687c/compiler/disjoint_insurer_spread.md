# 同根续局保险的多花瓣成本停界

2026-10-23。个人探索稿；完整解析证明、作者 Fraction 审计，待独立攻击。
一般 Q-CAG-HALF 仍 OPEN。本稿不是 half 定理或主目标反例。

## 1. 精确对象和结论

采用原 CAG-MODEL：有限单位客户、有限非空共同目录、m 名单位玩家、均分收益，
全部有序历史纯 SPE。重复和空主题、任意历史依赖平局保留。
本稿的新结论只涉及一个**独立保险组件**，而不是任意主组件。

保险目录记为 S，客户数 C 仅数目录并集内的客户。设

    K = intersection_(T in S) T,
    P = {T minus K : T in S}.

假定 P 的不同包含极大集合两两不交；不要求目录只有极大主题，内部可有任意
交叠子主题。极大覆盖按集合识别；不同标签同覆盖也不改变下面结论。
固定 m>=2 及同一个首位主题 A。令 V(A) 为首位已选择 A 后，所有完整后继
纯 SPE 给这位固定首人的最终收益集合；首人已不再行动，未要求 A 在根最优。

**同根跨度定理。** 对这个精确目录类，

    max V(A) - min V(A) <= C/(m+1).                 (D1)

更准确地，若 A minus K 非空，大小为 a，且两份续局分别使包含它的极大花瓣
被 q、q+1 名后继选择，置 k=q+1，则这两份续局的首人收益差为

    a/[k(k+1)] <= C/[k(m+1)].                      (D2)

任意两份续局对该花瓣的后继人数差至多一。因此 V(A) 至多含两个不同数值。
若 A=K，跨度为零。目录全为 K 的情形同样为零。

(D1) 对任意 m 锐：两个不交主题 X,Y，|X|=2s、|Y|=(m-1)s。固定首位 X，
后继可选 Y^(m-1)，也可选 X,Y^(m-2)，两份完整续局均可信，首人收益分别
2s、s。客户数 C=(m+1)s。原二主题构造的全部离轨策略见第 5 节。

## 2. 所用 singleton 事实的完整证明

考虑若干共同资源，n 名依次行动的玩家，每人选一个资源；在背景已固定后，
资源 j 被 k 名新玩家选择时给每位选择者非负、非增收益 f_j(k)。
纯策略仍读取全部有序历史。以下论证不施加同计数历史同平局。

**阈值席位。** 固定 L>0，令 d_j=max({0} union {k<=n:f_j(k)>=L})。
在某个资源计数前缀 p 后尚有 r 人，若

    R(p)=sum_j max(d_j-p_j,0) >= r,

则该前缀的每个完整纯 SPE 使所有剩余玩家各获至少 L。
证明对 r 归纳：加入任一玩家令 R 至多降一。当前人能选一个尚有席位的资源 j；
后继各由归纳获至少 L。若以后无人选 j，当前人的终局收益至少 L；若有人选 j，
他与该后来者的终局资源收益相同，也至少 L。因此 SPE 最优性给实际收益至少 L。

**终局 PNE。** 每个这种 singleton SPE 终局 q 都是同背景静态 PNE。
反设有静态盈利偏离，选行动顺序中最后一位有此偏离的人 i，实际资源 a、目标 b，
令 L=f_b(q_b+1)>f_a(q_a)。i 后的每位玩家都静态稳定，故各获至少 L；
其中不在 b 的人可偏离 b，在 b 的人则用非增性比较 q_b 与 q_b+1。
所以 i 后无人选 a。设 i 前前缀为 p，i 后资源计数为 t。资源 b 至少留有
t_b+1 个 L 席位，其他被后来者选择且不同于 a,b 的资源 j 至少留有 t_j 席位。
因此 R(p)>=1+sum_j t_j，阈值席位使 i 自己也至少获 L，矛盾。

**降低一个资源。** 若第二个 singleton 静态游戏只把资源 b 的函数由 f_b(k)
严格降低为 g_b(k)<f_b(k)，其他资源不变，则任意两游戏的 PNE q,q' 有 q'_b<=q_b。
否则取 d 满足 q'_d<q_d，两个 PNE 给

    f_d(q_d)>=f_b(q_b+1),
    g_b(q'_b)>=f_d(q'_d+1)>=f_d(q_d),

但 g_b(q'_b)<=g_b(q_b+1)<f_b(q_b+1)，矛盾。
若没有其他资源，人数守恒直接排除增加。

**同游戏占用差。** 如果每个正资源的 f_j 严格递减，则任意两个 PNE q,q'
在每个资源上的人数差至多一。若 q'_b>=q_b+2，取 q'_d<q_d。两个静态
最优性比较和非增性给

    f_b(q'_b)>=f_d(q'_d+1)>=f_d(q_d)>=f_b(q_b+1),

与 f_b 严格递减矛盾。交换 q,q' 得另一方向。
零资源不应用严格性；本稿后面只对非空极大花瓣使用此事实。

## 3. 为什么任意内部子主题不能被忽略，但可以动态删除

K 的每位客户始终被全部 m 人覆盖，给每人恒定 |K|/m。删去此共同常数后，
所有主题成为某个不交极大花瓣 B_j 的子集。
若有非空花瓣，则空主题是严格子主题；若全部花瓣为空，跨度已为零。

对任意历史、任意剩余人数 r 归纳，证明所有后继完整 SPE 在该节点都选极大花瓣。
r=1 时，严格扩张一个子主题会严格增加末位收益。
一般 r 时，归纳保证当前行动后，在其全部离轨子树中，后继只选极大花瓣。
固定此前每位客户负载 p_x。假设当前选 T proper subset B_b。此后 r-1 人
面对 singleton 资源，其中 B_b 的函数为

    f_b(k)=sum_(x in B_b) 1/[p_x+1_(x in T)+k], k>=1.

若当前改选 B_b，该函数变为

    g_b(k)=sum_(x in B_b) 1/[p_x+1+k] < f_b(k).

其他极大花瓣函数不变。两条真实后继策略限制到极大花瓣行动仍是完整 singleton SPE，
其终局由第 2 节是静态 PNE。因此扩张后的 B_b 后继人数 q'_b<=q_b。
当前扩张偏离的最终收益至少

    sum_(x in T) 1/[p_x+1+q_b]
      +sum_(x in B_b minus T) 1/[p_x+1+q'_b],

严格大于原收益。故严格子主题不可能最优，归纳完成。
这里没有把一个真实后继换成另一个后继；比较的是同一原策略在两项合法行动后的
真实完整子树。固定首位 A 即使是内部子主题，也在这个“任意历史”的量词内。

## 4. 同根跨度和客户成本

固定首位 A，删共同核心后令 A subset B_b，|A|=a>0，|B_j|=w_j>0。
由第 3 节，全部 m-1 位后继只选极大花瓣。背景只来自固定首位 A，因此其资源函数为

    f_b(t)=a/(t+1)+(w_b-a)/t,
    f_j(t)=w_j/t for j!=b.                         (D3)

这些正资源函数全部严格递减。第 2 节使任意两份后继完整 SPE 的终局都是
同一 (D3) 游戏的 PNE，并使 b 资源人数差至多一。若不同，写为 k-1 与 k。
首人的花瓣收益分别为 a/k、a/(k+1)，所以差为 a/[k(k+1)]。

在 b 人数为 k-1 的那份 PNE 中，恰 m-k 名后继选其他资源。
任何这些资源 j 的玩家都能静态改投 b，其改投收益为

    f_b(k)=a/(k+1)+(w_b-a)/k >= a/(k+1).

所以 w_j/q_j>=a/(k+1)。按其他资源人数求和，并使用 w_b>=a，得

    C >= sum_j w_j
      >= a+(m-k)a/(k+1)
       = (m+1)a/(k+1).                             (D4)

共同核心只会增大 C，不影响收益差。(D4) 与前述精确差相除即为 (D2)，
再用 k>=1 得 (D1)。不要求首位 A 最优，亦不要求两份续局从同一根策略选出。

## 5. 对可信编译的含义及边界

设旧主组件有一张完整策略 tau，除根以外每个子博弈都是纯 SPE，指定根 A 的收益 u，
真实根偏离收益 d_B，缺陷 Delta=max_B d_B-u>0。
用与主组件客户不交的保险组件作 Cartesian 目录。允许在不同联合根行动后选择
不同组件续局；但根以下每个分支要求两个坐标分别执行各自完整 suffix SPE，互不耦合。
若保险目录满足第 1 节结构，任何这种修复必须满足

    C >= (m+1)Delta.                                (D5)

证明固定被选保险根 Z，把指定联合行动 (A,Z) 与原最大偏离 (B*,Z) 比较。
旧坐标差 Delta 必须由同一个保险根 Z 的两个真实完整 suffix SPE 之收益差支付。
(D1) 即给 (D5)。这说明加任意多不交极大花瓣，或允许它们内部任意子主题，
均不能比已知二主题独立保险降低**总新增客户数**。

更一般，若保险由任意多个客户不交坐标组成，每个坐标满足第 1 节结构，
且根以下各坐标均独立执行完整 suffix SPE，同根总跨度至多
sum_l C_l/(m+1)。即使完整保险目录本身因 Cartesian 并集而有交叠极大主题，
这个坐标分解仍证明总客户成本至少 (m+1)Delta。

不能把新增客户数 C 直接替换为新实际福利或 half 稀释项 2W_ins-OPT_ins：
多花瓣保险可能实际漏掉客户，后二者是不同对象。本稿未排除这样一个保险因漏覆盖
而有较小 half 稀释项。也没有排除根以下继续跨坐标耦合、共享保险客户或一般交叠花瓣。

已知达到 (D5) 的两主题修复采用 |X|=2Delta，|Y|=(m-1)Delta，根后合规续局
H:全部 Y；同 X 根的惩罚续局 L_X:第二位 X、其余 Y；Y 根的惩罚续局 L_Y:
尚未出现 X 时选 X，之后选 Y。H 与 L_X 的深层任一历史，若已有 a>=1 个 X，
选 Y 的收益 (m-1)/(m-a)>=1，而改 X 的收益 2/(a+1)<=1。L_X 第二位两动均得 1。
L_Y 在尚无 X 时选 X 独占获 2，改 Y 至多 1；出现 X 后同前。因此全部离轨可信。

其实际和最优保险福利均为 C=(m+1)Delta，故已知修复的精确 half 门槛仍为

    OPT_old,m-2W_old > (m+1)Delta.

本稿没有找到跨过此门槛的旧 root-only 计划，也没有一般证明该门槛永远不能发生。

## 6. 来源、审计和接续判别

实际定位并读到的旧 root-only 编译为
`R-0f99797b33de46bfb498541a0bc5fae9/credible/two_theme_root_repair.md`。
它明确未找回传闻“只增两个总主题”的构造，其合法目录有 2p 个 Cartesian 联合主题，
不能误报为原目录只增加两个主题。该旧稿已证明所有独立二主题保险的锐成本。
本稿扩到任意多不交极大花瓣、内部子主题以及任意多独立此类坐标。

第 2--3 节 singleton 机制与动态删除工具已在共享正文
`research/current/customer_attraction/disjoint_maxima_bound.md` 完整证明；本稿为固定首人
观察者的新跨度对象重构它们，不认领这些工具的新颖性。
`audit_disjoint_insurer.py` 从显式单位客户独立计算全部收益，并独立实现集合值 BI，
核验多个内部子主题目录的任意 fixed-root 高/低续局、实际合法的全部偏离，以及
静态 PNE 和 (D1)。普遍量词由上述解析证明承重，不由有限审计承重。

另一个刻意有限的判别为 `three_theme_insurer.py/json`：m=3、p=3 时所有 81 张完整
两后继策略、全部 6561 对同根策略锥，所有非负客户类型，逐锥 LP 均有精确 Fraction
原始/对偶证书，最大同根跨度恰 C/4。该计算允许一般三主题交叠，但只证明这个有限
人数/主题范围；它不说明一般交叠目录也满足 (D1)，不是继续扩样的理由。

下一次有新判别信息的机制应明确改变 (i) 后继继续跨坐标耦合，(ii) 保险客户共享，
(iii) 真正交叠极大覆盖，或 (iv) 利用保险自身漏覆盖降低 2W_ins-OPT_ins，而非只调
不交银行大小。第 (iv) 的客户成本与 half 稀释成本区别尤其不能省略。
