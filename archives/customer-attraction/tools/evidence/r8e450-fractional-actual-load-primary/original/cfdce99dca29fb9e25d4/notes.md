# 实际终局分数负载的查询接口

状态：研究候选；一般 Q-CAG-HALF 仍 OPEN。非一般证明，非反例。

## 精确身份：CA-FRACTIONAL-ACTUAL-LOAD-WEAK-v1

对象、定义域和全部历史量词均采用 `research/current/customer_attraction/model.md`。
对任意 m>=1 及任意完整纯 SPE 的实际终局，客户覆盖次数记为 c_x，福利为 W。
令 alpha=(m-1)/m，g(T)=sum_(x in T) 1/(1+alpha*c_x)，M=max_(T in S) g(T)。

待证候选：`(m-1/2) M <= W`，量化全部上述实例及全部完整 SPE。
该候选没有证明；也可能比 half 更强而为假。

## 已成立的充分性代数

无需 SPE。取任意比较 m 元组，客户覆盖次数 d_x，比较覆盖为 O。
令 L_x=alpha*c_x。逐客户有 `1_{d_x>0} <= (d_x+L_x)/(1+L_x)`。
对实际所选主题 A_1,...,A_m，

    O <= sum_j g(T_j) + sum_x L_x/(1+L_x)
      = sum_j g(T_j) + alpha*sum_i g(A_i)
      <= m*M + (m-1)*M = (2m-1)*M.

因此候选足以推出 `O<=2W`，不需把分数负载误认为整数静态对手。
这复用了已有共同目录的 Jensen/预算结构；不声称文献新颖性。
零客户全部为零；m=1时M=OPT_1且SPE选最大主题，候选成立。

强版本 `mM<=W` 已由旧36客户例否定：参见
`R-64201cd12083425899e2d643ec9bc087/security_aggregate/README.md` 及其独立审计。
它不否定此处弱系数。真实静态安全值v_m满足v_m>=OPT/(2m-1)，
但不能据Jensen把本M与v_m按相反方向互相支付。

## 已执行的有限攻击

`probe.py` 对六份旧策略证书逐查询优化非负全重数锥，精确检查所输出有理原始点的全部
有序历史偏离。若有理化使slack为负，则不得当作合法点；本轮保存输出均非负。
目前未发现此弱桥反例。浮点LP及有限策略清单均不证明一般桥。

`outcome_probe.py` 复用旧整数公分母集合值求解器；启动时用规范 Fraction 求解器核对
零输入、全平局、m=1、单主题及随机/合法背景共80组，完整终局集合一致。
五人七主题2000次输入、2094个可实现终局；十二人四主题1000次输入、3286个终局，
均未违反候选。精确比值和产生新纪录的完整重数输入保存于JSON；没有把有限未反驳升级为真值。
