# 五人循环共同主题与最大根门槛的原证据

正式数学与全部范围见[计算正文](../../../state/计算/五人共同主题循环反馈与最大主题分支检验--计算.md)。

`original/`保六个本批主源原字节；`dependencies/`保固定67原子输入、原四尾ρ审计器，以及为解释必要行实际读过的反馈/根信用正文。四个dependencies都是关联资料，没有在本批六条回执中虚报完成。十源双冻结身份、原SHA256和本地位置见`source-manifest.json`。

`replay-001/`是按原相对路径搭建的隔离重放树。三份待生成JSON在运行前不存在，三个原入口各运行一次，均exit0、stderr空，三份生成JSON与各自冻结报告逐字节相同。`replay-inspection.json`保存运行参数、软件版本、SHA、每个保存点的浮点矩阵检查。原67原子输入的旧557行证书没有在这次重放重新认证。

`replay_and_inspect.py`只用原字节搭树与运行，另从原AST的优化前定义段取矩阵，核保存的16/18份support、对偶边际值和目标的一致性；它没有独立重写完整LP或给出精确有理最优证书。现有`replay-001`不可覆盖；若需重新运行，先把整份证据复制到新的临时位置并移走其中的`replay-001`，或在驱动中显式改为新的运行目录。勿在`original/`直接执行：原程序按自身位置寻找依赖并写同名JSON。

关键边界：共同主题探针只在184行/67会员变量下未发现正共同违约；基本63列最大根LP漏O≤5K，真分支511列版本补容量、真实第二位偏离和旧四尾信用，但二者均非完整SPE求解器。保留全部输出，不把加权support当单位客户完整策略，不把有限门槛表当所有t的精确公式。
