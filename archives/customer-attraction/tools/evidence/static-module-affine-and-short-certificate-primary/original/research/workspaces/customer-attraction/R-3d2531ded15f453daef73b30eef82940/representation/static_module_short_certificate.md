# 34客户模块仿射静态证书的独立简化

2026-10-24。仅为静态查询证明；没有证明任何模块并目录的指定完整SPE存在，也不声称EO/菜单反例。下文使每个模块的任意非负整数背景槽数t均有一个显式仿射下界，因而可以加总到任意模块数n。

## 1. 独立输入与结论

主题0,...,5，客户类型以兴趣mask编码：

    (mask,重数) = (4,1),(27,4),(29,3),(30,3),(31,2),(32,1),
                 (43,3),(45,3),(46,3),(51,3),(53,3),(54,3),(59,2).

客户总数34。查询分布为p=(10,10,21,10,10,21)/82。对任意背景计数q∈Z_+^6，t=Σq_a，记

    F(q)=sum_B r_B [sum_{a∈B}p_a]/[1+sum_{a∈B}q_a].

则对全部t（没有t上界）

    F(q) >= (2411-587(t-2))/246.                         (A)

## 2. Cauchy处理除t=2,3外的全部整数

令a_B=r_BΣ_{a∈B}p_a。直接对13类加总得

    A=sum_B a_B=901/41,
    S_a=sum_{B∋a}a_B=(1235,1235,1193,1235,1235,1193)/82.

因此S=max_aS_a=1235/82。加权Cauchy和Σq_a=t给

    F(q)>=A²/[A+Σ_aS_aq_a]>=A²/(A+St).

将此下界与(A)右端相减，清去正分母246(1802+1235t)，分子恰为

    P(t)=724945t²-3369701t+3281442.

P(0)=3281442>0，P(1)=636686>0。对t>=4，令s=t-4，则

    P(t)=724945s²+2429859s+1401758>0.

所以只需核t=2,3。此处不用枚举t=4,5,6，也不用对t>=7单独截断。

## 4. 任意n个不交模块加总

取n份不交34客户模块，目录为各模块6个主题的并（主题不跨模块）。查询先均匀选模块，再在该模块选p。任意2n+1个静态对手主题，在模块j中计数t_j，Σ_jt_j=2n+1。查询期望由(A)至少

    (1/n)Σ_j [2411-587(t_j-2)]/246
      =2411/246-587/(246n).

所以相应静态安全值v_(2n+2)至少此值。n=18时下界为42811/4428，比29/3高7/4428；对所有n>=18仍高，因为下界随n递增。n=17该下界尚低于29/3。

这个静态结论独立于SPE，也不能单凭同目录的模块并就构造所需跨模块完整续局。

## 5. 精确重放与证书缩减范围

`verify_static_module_bound.py`独立从13类与p定义计算t<=6的全部924计数，所得七个最小值与根方给表完全一致，报告在`static_module_exact_report.json`。该程序不导入规范SPE求解器或证书核验器。

此处Cauchy+21轨道是对924计数证书的解析缩减。资源逐项整数reciprocal支撑线在同组普通二主题背景的尝试不能同时使两个已用行动斜率抵消；因此没有宣称得到仅13条逐类型支撑线的更短证书。
