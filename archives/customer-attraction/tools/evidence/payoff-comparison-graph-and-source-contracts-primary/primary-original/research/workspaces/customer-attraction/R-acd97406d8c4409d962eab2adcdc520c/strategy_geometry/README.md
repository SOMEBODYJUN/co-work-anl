# strategy_geometry：一般完整策略的比较图与商空间

当前目标仍 Q-CAG-HALF，一般范围 OPEN。本目录为R-acd97406d8c4409d962eab2adcdc520c的子研究员草稿；没有git、共享地图或公屏操作。

## 当前可自足结果

- `payoff_comparison_graph.md`：任意固定完整策略的真实行均为收益顶点F(a,q)之差。强连通分量内任意有符号差可沿真实路径非负支付；原行锥精确分解为SCC内部空间与商DAG边锥，可删传递边。收益顶点由整数(a,q)唯一识别，上界p*binom(m+p−2,p−1)。另保存离散势与根福利的精确恒等式。核心SCC陈述已由cone_abstraction独立攻击确认；这只是无损结构，不构造一般半覆盖证书，不声称最大线性空间。
- `comparison_graph_audit.py` 与同名 `.json`：标准库Fraction从原始有序动作独立构造64个形式策略、5058项行/路径/势/福利恒等式；不调用规范锥构造或SPE solver。审计是实现核验，普遍性依据正文证明。
- `cone_abstraction/README.md`、`menu_quotient_audit.py`：子agent给任意深度收益菜单等价类的精确行锥商。四人两主题、正客户质量例严格扩大末节点相反行空间。它是图SCC二环机制的一个可解释特例。

下一步有价值义务：尝试利用CAG离散势格的额外关系，在上述比较DAG上对d=2c−o普遍构造流与非负余项。仅计算SCC不能保证目标属于行锥。

## 未闭合或停止的探索

- `markov_outcomes.py`：将全部有序历史SPE终局集与完整枚举的计数Markov SPE终局集比较。3题3人、3题4人、4题3人各20,000次seed14037、重数0..3抽样，未见已完成枚举的输入有差异。单次计数策略枚举超过200,000则跳过，旧运行未记录跳过个数；故这里只保存准确可重跑探索，不能称有限全集，更不能称一般Markov归约。程序允许重排在轨玩家主题；仅破坏原根或原有序路径不算该归约反例。
- `abstract_markov.py` 与 `abstract_markov_counterexample.json`：对一般匿名终局收益表，3题3人已有完整历史可达计数而计数Markov不可达。该表不满足CAG分母界（例如同一主题全占3席有正收益，但占2席另1席别题却收益零），不是合法客户实例。因此它只排除不使用CAG结构的泛状态归约证明。
- `probe_bridges.py`、`probe_existing_cones.py`：为同伴临时探测更强逐人/残余桥。既有3人6题、4人6题指定锥，以及new_policy_security_cones前8锥，未找到正值；仅浮点探索，不是精确上界证书。残余总量≤W桥已由global_proof另给真实两人反例，勿将这些有限无反例重用为正面结论。逐人O≤2m*u_i仍未由本目录证明或反驳。更大6人8题批次在开始后主动停止。
