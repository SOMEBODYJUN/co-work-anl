# 六名提供者半覆盖：本轮独立攻击

原模型恰六名单位权提供者、任意有限单位客户和非空共同目录、每份完整有序历史依赖纯 SPE，目标 `2W≥OPT6`。允许空主题、重复、零客户、全部离轨历史和任意平局。**状态 OPEN：尚无普遍证明或完整目标反例。** 一般 Q-CAG-HALF 同样 OPEN。

六名研究员使用同一份[整理输入](N6_BRIEF.md)各自独立研究，未分配固定方法。主方独立复核实质结果；持续探索不因一次阶段备份而终止。

## 仍缺什么

必须用同一完整策略的真实早期/倒二激励与共同报价、尾部利润联合付款，或者构造全历史可信策略。静态势和末价无法单独承担这一工作。现有3949行必要条件点也不是SPE，不能升级成目标反例。
