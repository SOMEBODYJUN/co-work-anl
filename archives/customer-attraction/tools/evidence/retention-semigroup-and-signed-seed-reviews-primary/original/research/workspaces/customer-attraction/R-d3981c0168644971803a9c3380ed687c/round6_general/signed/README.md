# 第六轮 signed 价格与严格种子攻击

2026-10-25。研究对象始终为任意人数、任意有限共同目录、单位客户、全部有序历史纯 SPE 的 Q-CAG-HALF。**没有找到真正统一价格，没有严格 `B+C<0` 种子，没有新 half 证明或目标反例。** 本目录仅为父方指定的个人接续；没有改共享稿、work.py 或 git，没有另开 subagent。

开工精确目标是检验真正统一价格 `lambda_i=2`，即既有全路径 `OPT_m<=2 sum_i M_i`（MP），并直接寻找带完整可信退出表的 signed 严格种子。`lambda=1` 是原 TB-ANY，`lambda=3/2` 只是中间候选；本轮没有重命名这些旧桥。主源 [peer signed 修复](../../../R-ab4b3c24c8f949198e194dd45bb66105/mixed/signed_credible_repair.md)、[LOW 下域](../../../R-ab4b3c24c8f949198e194dd45bb66105/parent/price_lower_cuts.md) 的等价表示不算已经证明付款。

## 全输入解析筛选

[signed_seed_screen.md](signed_seed_screen.md) 给严格种子的必要条件

`OPT_m-W > u_m + max_(i<m)u_i`。

它仅用真实 `M_i>=0` 和 signed 成本代数，对全部原输入、任意末位 BR 目标适用。由此 `W=OPT_m` 的旧 LAST 控制器、23 客户全覆盖核心等绝不能直接给严格 signed 种子；即使 exact-M 次可加，也不改变该必要条件。这是筛选，不是 universal price 或 half 证明。

同稿记录一个状态校准：既有 round5 保险族已经否定旧弱根 floor `M(empty)>=OPT_m/(2m-1)`（m>=4）。没有重启个体安全值研究；指出这一点是为了避免把被该已有族否定的 floor 加回 MP 推导。

## 指定有限攻击及范围

[attack_designated_seeds.py](attack_designated_seeds.py) / [精确输出](designated_seed_attack.json) 用规范完整续局全集，在旧 root-tax 原四人输入、同一客户表的五人代入、旧 23 客户核心的五人代入中，枚举所有末位 BR 路径并精确计算各 M。最小 signed 预算分别为 `15,34,22`；`lambda=2` 的最小值分别为 `11,97/3,19`。这三份指定 stress input 没有负点，没有全称推论，随后停止该类实例扩展。

[one_cone_seed_attack.py](one_cone_seed_attack.py) / [输出](one_cone_seed_attack.json) 是一次直接严格种子 LP 攻击。以旧 root-tax 的五人代入、目标 `A,A,A,A,F` 为锚，在每个正常前缀每个强制动作后选择当前收益最小的真实完整子 SPE，然后保留这些完整退出策略的全部真实 IC。放开六主题全部 63 种非空兴趣类型的非负客户重数，并以总客户质量一规范化。实际构造得到 471 个 `(前缀计数,目标终局)` 子树与 769 条不同 IC 行；缓存只复用这一份显式合法策略，不声称所有 SPE 都必须依赖计数。

LP 同时约束各强制动作的真实退出收益 `<=U_i`、目标末位 BR，并用 K_pm 的整数顶点逐行约束成本上图。六个五主题比较支持全部检验，故没有丢掉可能的最优比较支持。signed 最小浮点目标约 `0.4`；所返回有理可行点逐条精确复核 IC、退出上界、末位 BR，预算恰 `2/5`，不是负种子。该点没有输出完整策略 JSON，因为它不是目标反例，策略递归与所有 IC 均可由脚本重构。

同一固定退出策略锥内，`lambda=1,3/2,2` 的最低浮点目标分别为 `0.25,0.3125,0.375`。没有负价反例。**没有精确重构 LP 对偶，不能把这些浮点最优值称为该锥的严格下界证书，更不能据此证明任意共同目录无反例。** 这一锥仅冻结了一批指定真实退出策略；改变退出策略、目标路径或人数都会改变其范围。没有继续在该固定人数锥加行或扩扫描。

## 停止点

MP 的真实缺口仍是跨位置最低可信孩子不兼容。某个 M 的极小孩子可由完整 SPE 实现，并不能把任意路径上所有极小孩子合成一份总福利为 sum M 的 SPE。本轮没有支付这项差额。

下一步需要新的全输入不等式，或换一个确有净遗漏且通过上述静态必要筛选的目标、同时提供不同的真实退出控制器。这里没有提出“再扩大有限阴性样本”作为一般推进。

本轮均为作者推导与定义级计算；没有独立全文审查、外审或新颖性认证。五人仅是上述一般 MP / signed 公式的指定反例压力代入，不是五人正面项目，也没有无条件推出 `OPT_5<=2W`。
