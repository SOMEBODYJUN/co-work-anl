# 原接口的真实对象与更正范围

2996B的`generalized_child_routing.md`把递增路由从“旧分支未来覆盖者”扩到任意更晚含客户的合法query。这个扩大合法；本页保其完整金融含义，并只纠正原句“Equivalently, forgetting the flow decomposition”及其后自动满足COORD的推断。独立COORD覆盖证书仍充分，不能因错误的等价声称连同它一起撤回。

采用[共同目录完整历史模型](../定义/共同目录完整历史模型--定义.md)，固定完整纯SPE σ及actual叶、actual并集C/福利W、各位收益u_i。取一个最优m元组并集U，O=OPT_m；R=U\C、G=C\U，O−W=|R|−|G|≥0。actual第i前缀强制a后沿**原σ**完成Z_i(a)，当前完整收益D_i(a)≤u_i。客户x∈R在actual前缀从未覆盖；若x∈a，

\[
r_{i,a,x}=\frac1{1+|\{\ell>i:x\in Z_i(a)_\ell\}|}
\]

正是该客户对D_i(a)的贡献。不同query的Z各自沿其改变后的有序历史，不冻结未来，也不把上一query的旧续局搬到另一个历史。

# 任意更晚query的金融证书

对每个x初始化一次单位流。状态s=(i,a,x)接收f_s≥0，吸收f_sr_s，余f_s(1−r_s)可分配至**任何**更晚、含x的合法query (ℓ,b,x)，不要求ℓ在Z_i(a)里覆盖x，也不要求b为其旧行动。角色严格递增、末位r=1、输入不复制不丢失，有限守恒给每个x的总吸收1。路由是证明方选的证书，不是玩家行动/承诺，不声称选出的路径是SPE。

按query q=(i,a)汇总A_q=Σ_xf_qxr_qx。正A必D_q>0，定义唯一完整行乘子w_q=A_q/D_q；A=0时取w=0，避免0/0。于是

\[
|R|=\sum_qA_q=\sum_qw_qD_q\le\sum_qw_qu_i.
\tag{FINANCE}
\]

同一原IC的所有客户贡献先聚合，再只乘一次w_q。重复到达同一query不许再为不同客户各领取一份整行收益。“一次IC”不表示w_q≤1或同角色所有w之和≤1。

若以ρ_s=u_i/D_i(a)计每单位吸收金融费，最小剩余单位价满足

\[
V_s=\rho_sr_s+(1-r_s)\min_{\ell>i,\ b\ni x}V_{\ell,b,x}.
\tag{ARB}
\]

末位r1无需取空集最小；更早状态总有含x的末位query可用。固定输入下有限DAG逆推给达到策略；混合孩子不会改善最小值。任意孩子扩张只能使最小价不增，不自动付总费。完整证明、全行采购LP/对偶和自由净需求另见[现ARB对象](../算法/任意未来查询的完整行采购价与对偶--算法.md)，本页不把该优化重认成普遍K≤W定理。

# 独立逐客户COORD证书

另一种充分证书是直接选择w_q≥0，满足

\[
\sum_{q:x\in a_q}w_qr_{qx}\ge1\quad(x\in R).
\tag{COORD}
\]

求和只给R贡献D_q^R=Σ_(x∈R∩a)r_qx≤D_q，故

\[
|R|\le\sum_qw_qD_q^R\le\sum_qw_qD_q\le\sum_qw_qu_i.
\]

这套证明正确。错误是从FINANCE的w=A/D推得COORD。金融账只保总吸收，可能用该query的非R客户利润抵押tracked客户的较大密度。写D_q^N=D_q−D_q^R≥0（原稿上标C并不保证这些客户全属actual C），有精确式

\[
\sum_{x\in R\cap a_q}(f_{qx}-w_q)r_{qx}=w_qD_q^N.
\]

右侧已含在A=wD中，不能再当一份actual现金。若从流改取λ_q=max_x f_qx，的确得到逐客户覆盖；但λ_qD_q≥A_q，费用变了，不能仍沿用A/D的金融最优值。

# 真正完整SPE输入上的无界分离

为使更正自足，复述[已保留的全参数反族](../反例/完整行标量付款与逐客户覆盖的无界分离--反例.md)的承重部分；这是原父方给出的旧实例族，本批知情解析不是新构造或程序重跑。t≥0整数，t个common客户，A=common∪{a₁,a₂}，B=common∪{x}，两人共同目录{A,B}。规定根A，末位在A、B之后都A。令u=(t+2)/2。

|完整决策历史|规定行动收益|另一行动收益|
|---|---:|---:|
|根A与改B后原策略继续|u|u|
|A之后末位A与B|u|u|
|B之后末位A与B|(t+4)/2|(t+1)/2|

三节点穷尽全部有序历史，末行严格差3/2，其余平局保留，所以完整纯SPE成立。actualAA的W=t+2，最优AB的O=t+3，R={x}、G空、净需求1。

两个actual-prefix的B query都r_x=1、D=u。给任一B query单位源，金融费u/D=1；任何合法金融流ρ≥1又总吸收1，故金融最优恰1。COORD却要求两B行乘子和≥1，每行费u，故COORD最优恰u=(t+2)/2，差比无界。原w=1/u使x覆盖仅1/u；common完整利润t/2的抵押额t/(t+2)恰补总账。t0两值同1，t≥1分离，不能删端点。

m1也可见自动映射失败而净需求为0：等大主题A={p,q,z}、B={p,q,x}，σ选A，完整SPE；x在B吸收1、D3、w1/3，COORD仅1/3。这只反映射，不能替净需求正的两人族。原9030B父提/本侧独审和有限t0/t7样本的来源时间在比较快照保留，当前不认证其旧审计输出。

# 两种证书共用的剩余义务，不是已付款

对任一种证书自己的乘子定义L_i=Σ_aw_i,a。若再独立证明

\[
\sum_i(L_i-1)u_i\le |G|,
\tag{CAP}
\]

则|R|≤Σ_iL_iu_i≤W+|G|，从O=W+|R|−|G|得O≤2W。CAP是同一共享钱包的总条件，不是每个query各用u_i一次。FINANCE与COORD可以分别接它，但两边证书/乘子不自动相同。

原初始化分数匹配的L_i^src≤1，只付初始化portion，不含后续incoming；任意-child合法性也没有控制incoming。固定实例的实数LP不提供同时适用于所有客户类型重数的Farkas证书。零客户/空主题/零收益行照定义保留；它们不能凭除以0产生免费预算。真正接续仍需一个全实例实际行容量关系，而不是把“等价”或“无行重用”当作这个关系。
