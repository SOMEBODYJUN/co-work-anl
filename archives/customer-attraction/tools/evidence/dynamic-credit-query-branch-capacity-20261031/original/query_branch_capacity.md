# 最大入场主题的真实分支：A外利润与中间拥挤余项

2026-10-23。Q-CAG-HALF仍OPEN。这是一条任意人数的代数恒等式；root与direct_cover均从逐客户通分独立重构通过。它本身不新增后继SPE约束，不构成一般half中继。

## 精确陈述

固定任意合法有序背景b、余r>=1人。对合法主题T定义原入场分数

`f_b(T)=Σ_{x∈T}1/(b_x+1)`。

取其任意最大者A。在同一完整策略下当前强制选A，真实后继为R_1,...,R_{r−1}，其负载为k_x；包含当前A自身的完整剩余r槽终局不作任何冻结。记入场者收益

`v=Σ_{x∈A}1/(b_x+1+k_x)`，

后继在A外的总利润

`P_out=Σ_{x∉A}k_x/(b_x+k_x)`，

k=0项为0。定义

`D=Σ_{x∈A} k_x(r−b_x−2−k_x)/[(b_x+1)(b_x+1+k_x)]`，

`M=(r−1)f_b(A)−Σ_j f_b(R_j)≥0`，

`B=Σ_{x∉A} k_x(k_x−1)/[(b_x+1)(b_x+k_x)]≥0`，

B在k=0处取0。则精确恒等式为

`P_out=(r−1)v+D−M−B`。                                      (1)

D是有符号项。它仅在 `1≤k_x≤r−b_x−3` 时正，即部分后继覆盖A客户、但未达到高拥挤的范围。因此r<=3时D<=0。若当前节点原实际收益为u，且原策略在该节点满足SPE根最优性，则真实偏离A给v<=u，因而

`P_out≤(r−1)u+D−M−B`。                                     (2)

(2)仅引用该根节点的一项真实偏离比较；(1)不要求任何后继理性。M的非负性只来自A最大入场分数，B来自逐客户非负代数。不得把它们标成新的后继SPE slack。

## 证明

按客户分解尾部原入场分数：

`Σ_j f_b(R_j)=Σ_{x∈A}k_x/(b_x+1)+Σ_{x∉A}k_x/(b_x+1)`。

而A外逐客户有

`k/(b+1)−k/(b+k)=k(k−1)/[(b+1)(b+k)]`。

代入M和B便得

`P_out=Σ_{x∈A}(r−1−k_x)/(b_x+1)−M−B`。

A内逐客户通分：

`(r−1−k)/(b+1) = (r−1)/(b+1+k)+k(r−b−2−k)/[(b+1)(b+1+k)]`。

求和即(1)。所有有贡献分母均正，空主题、重复主题、任意背景和历史平局均保留。

## 为什么仍不能闭合half

(2)把一个最大入场主题所引起的真实分支中、后继在A外的利润上界，连到原当前收益和中间拥挤项D。它没有把该分支的P_out或D搬回原实际路径，也没有独立控制OPT。旧纯实际负载信用的失败不直接否定本式，但本式也没有修复那些失败。

目前最准确的剩余义务是：利用同一完整策略其他真实节点的独立偏离行，选择若干分支，使它们的正D由负D、真实激励松弛或最终福利共同支付。没有找到这一一般relay。
