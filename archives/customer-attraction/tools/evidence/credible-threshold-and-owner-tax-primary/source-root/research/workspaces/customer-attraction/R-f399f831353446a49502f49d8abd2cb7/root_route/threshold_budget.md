# 动态最小续局门槛：一般候选与真实缺口

状态：一般路线候选，未证明；没有目标反例。研究对象保持任意有限共同目录、任意人数、全部有序历史依赖的纯 SPE。

## 1. 精确候选

固定一个完整纯 SPE `sigma`，实际路径前缀为 `h_i`，剩余玩家数为 `r_i=m-i+1`。令 `R(h,A)` 是在历史 `h` 后强制当前玩家选合法主题 `A` 时，所有完整纯 SPE 续局的终局集合。定义

```
L_i(A) = min { u_i(z) : z in R(h_i,A) },
Theta_i = max_A L_i(A).
```

因为实际动作 `A_i=sigma_i(h_i)` 的一份 SPE 续局收益不低于该动作的最小续局收益，且 `sigma_i` 在该历史选择最大化自身收益，所以 `u_i >= Theta_i`; 因而

```
Σ_i Theta_i <= Σ_i u_i = W.
```

待判别的一般桥是

```
OPT_m <= W + Σ_i Theta_i.                 (THRESHOLD)
```

若成立，立即得到 `OPT_m <= 2W`。该候选比固定背景安全值 `v_r(b)` 更贴近真实子 SPE 可实现终局集合；`Theta_i` 允许当前行动按每个实际历史变化。

## 2. 为什么它不是已证关系

给定一个最优元组 `T_1,...,T_m`，若将某个最优主题放入实际历史 `h_i`，当前玩家的动态收益只受 `L_i(T_j)` 控制。未来响应者可以在该离轨分支重复覆盖最优客户，令当前收益很低；其重复覆盖福利属于该离轨终局，不能直接用根实际 `W` 支付。若用递归继续追踪这些响应者，新的历史不再是根实际路径的 `h_k`，而需要对所有离轨节点建立共同预算。这正是 THRESHOLD 的未闭合证明义务。

静态有效效用只能给

```
OPT-W <= Σ_i v_i,
```

其中 `v_i` 冻结实际其他行动；真实 SPE 只给实际动态偏离收益 `g_i <= u_i`。差值 `rho_i=v_i-g_i` 是报复损失，且可为正。因而不能把静态 valid-utility 证明直接套进 THRESHOLD。

## 3. 可复用的递归接口

对 `x` 属于最优并集但不属于实际并集，给它分配一个最优槽 owner `i(x)`。强制 owner 选择该槽并沿原策略得到离轨终局；若其余响应者覆盖 `x` 共 `k_x` 人，则 owner 从 `x` 得到 `1/(1+k_x)`，损失 `k_x/(1+k_x)`。逐客户相加得到

```
OPT <= 2W + R_owner,
R_owner = Σ_{x in OPT\actual} k_x/(1+k_x),
```

其中 owner 可在重复最优槽中选择使该税最小的槽。这精确隔离了 THRESHOLD 所需的全树支付：需证明这些离轨响应税可由 `W-Σ Theta_i`、共同客户或实际外部客户的一次性预算支付。把不同 owner 离轨树的响应福利直接相加会重复使用同一资源。

## 4. 当前判别

- 任意有限枚举只作候选压力测试；尚无完整 THRESHOLD 反例或证明。
- 现有全局交换核、owner 势、真实 IC 流都能控制单棵离轨树的覆盖/势，但尚未把多个互斥离轨树重置到同一份 `Theta_i` 钱包。
- 若后续能证明 `R_owner <= |OPT∩actual|+2|actual\OPT|`，则由 `OPT<=2W+R_owner` 还不能直接闭合；目标需要更强的共享支付（或直接 THRESHOLD）。因此该不等式只是诊断，不应升级为充分条件。

下一步：优先尝试 THRESHOLD 的递归 Bellman 证明，或构造一个完整 SPE 使 `OPT > W+ΣTheta_i`；两者任一都会明确该候选的价值。不要把抽样未反例当证明。

## 5. 有限压力测试（仅观察）

`experiments/check_threshold_candidate.py` 直接调用仓库 `ExactSPESolver`，对每个可实现的有序路径逐项计算 `W+ΣTheta−OPT`，并把随机种子、实例数和路径数写入 JSON。2026-10-24 的记录：

- 3 个主题、5 名玩家、全部 128 个二值兴趣类型子集：128 个实例、3288 条可实现有序路径，没有负 slack；正福利实例的最小 slack 为 1。
- 4 个主题、4 名玩家、seed=20261024 的 500 个随机二值类型输入：2969 条路径，没有负 slack。

这两项只说明候选通过有限精确筛查；它们不提供一般证明，也不提升候选状态。

## 6. 相关有限边界与线性表示障碍

同行的全量 `m=3`、3主题、全部非空二值类型支持（3984 个最优元组/完整 SPE 组合）未发现固定 owner tax 超过 `|I|+2|G|`；报告只是否定该有限范围内的一个加强桥，不是一般证明。另有动态对偶分析指出，固定 `sigma` 的 `Gamma` 锥只包含每个子树中该策略选定的续局；`Theta_i` 要在同一子树的全部 SPE 续局中取最小，跨 tie 面会跳变。因此不能把 `u_i>=Theta_i` 直接写成一个固定 Gamma-Farkas 证书。这个障碍否定的是一种证明表示，不是否定 THRESHOLD 或 Q-CAG-HALF。
