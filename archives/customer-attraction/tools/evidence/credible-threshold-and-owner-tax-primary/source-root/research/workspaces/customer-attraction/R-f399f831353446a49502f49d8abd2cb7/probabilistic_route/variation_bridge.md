# 条件桥：最优前缀链的单位净变分（CA-VARIATION-BRIDGE-v1）

**状态：条件引理/候选接口，不是 Q-CAG-HALF 的证明。**

本页把“最优前缀链每客户响应覆盖变化不重复”写成一个可逐客户核验的充分条件，并说明它如何由完整历史 SPE 的真实 IC 直接推出 `O-W<=W`。该条件没有被一般模型证明；任意后继可依赖完整有序前缀，因而条件可能失败。`random_position_exchange_boundary.md` 已给出随机排列不具位置对称性的完整三人 SPE，不能把本页条件自动当作一般性质。

## 1. 最优前缀链与真实 IC

固定任意完整纯 SPE `sigma` 的实际根终局 `Z^0=z=(S_1,...,S_m)`，以及一个合法最优元组 `T=(T_1,...,T_m)`，记 `O=W(T)`、`W=W(Z^0)`。固定任意排列 `pi` of `[m]`。

对 `k=1,...,m`，令

* `h^{k-1}=(T_{pi(1)},...,T_{pi(k-1)})`；
* `A_k=sigma_k(h^{k-1})`，即该前缀下原策略规定给第 `k` 位的动作；
* `Z^{k-1}` 为前缀 `h^{k-1}`、第 `k` 位取 `A_k`、其后沿原 `sigma` 的终局；
* `Z^k` 为同一前缀、第 `k` 位强制取 `T_{pi(k)}`、其后沿原 `sigma` 的终局。

于是 `Z^0` 是实际终局，`Z^m=(T_{pi(1)},...,T_{pi(m)})`，故 `W(Z^m)=O`。在历史 `h^{k-1}` 的完整子博弈最优性给出

```
    u_k(Z^{k-1}) - u_k(Z^k) >= 0.                 (IC_k)
```

注意 `Z^k` 的后继没有冻结为实际根后继；这是一个合法离轨历史后的原策略续局。

对客户 `x` 定义两个当前位份额（分母为对应终局中的最终覆盖数；指示元为 0 时整项定义为 0）

```
    s^-_{k,x} = 1[x in A_k] / c_x(Z^{k-1}),
    s^+_{k,x} = 1[x in T_{pi(k)}] / c_x(Z^k),
    d_x       = sum_k (s^-_{k,x} - s^+_{k,x}).
```

将 `(IC_k)` 按客户相加再按 `k` 相加，得到精确的真实 IC 总账

```
    sum_x d_x = sum_k (u_k(Z^{k-1})-u_k(Z^k)) >= 0.       (IC-sum)
```

令 `y^0_x=1[x in Z^0]`、`y^m_x=1[x in Z^m]`，并记 `Delta_x=y^m_x-y^0_x`。终局覆盖的望远镜是

```
    sum_x Delta_x = W(Z^m)-W(Z^0) = O-W.              (W-telescope)
```

## 2. 精确单位净变分条件与半覆盖推论

定义客户 `x` 的**单位净变分余项**

```
    V_x := Delta_x + d_x - y^0_x.
```

若沿选定的最优前缀链逐客户满足

```
    V_x <= 0  for every x,                              (UV)
```

等价地

```
    d_x <= 2 y^0_x - y^m_x.                             (UV')
```

则立即有

```
 O-W = sum_x Delta_x
     <= sum_x (y^0_x-d_x)
     = W - sum_x d_x
     <= W,                                             (1)
```

其中最后一步使用 `(IC-sum)`。因此

```
    O <= 2W.
```

由于 `T` 可以取任意最优 `m` 元组，这对 `OPT_m` 给出原目标。

`(UV')` 的四种客户类型含义如下：

| 实际根 `y^0` | 最优链终点 `y^m` | 允许的 `d_x` | 解释 |
|---:|---:|---:|---|
| 0 | 1 | `d_x <= -1` | 最优新增客户必须贡献至少一个单位的净新位份额；不能被响应分支的旧位份额抵销 |
| 0 | 0 | `d_x <= 0` | 两端都未覆盖的客户不能产生净旧位份额 |
| 1 | 1 | `d_x <= 1` | 已有且仍在最优并集中的客户至多提供一个单位净正信用 |
| 1 | 0 | `d_x <= 2` | 实际独有客户的端点损失已给一个单位裕度，`d_x<=1` 的更强检验足够 |

这四项正是“每客户的响应覆盖变化不重复”的可审计含义：一个实际未覆盖但最优新增的客户，整条链必须留下一个不可被后继响应抹掉的单位新位份额；一个两端都覆盖的客户，旧位份额的净增量不能超过一个客户单位。它不把不同客户的信用相加两次。

## 3. 一个更强、容易机器核验的单枢轴版本

`(UV)` 可以用更强的**单枢轴份额条件**直接核验：对每个客户 `x`，存在至多一个 `k_x` 使得 `s^-_{k,x}-s^+_{k,x}` 非零；若 `y^0_x=0,y^m_x=1`，该唯一差额为 `-1`；若 `y^0_x=y^m_x=0`，唯一差额非正；若 `y^0_x=y^m_x=1`，其绝对值不超过 1；若 `y^0_x=1,y^m_x=0`，其值不超过 1。则自动有 `(UV')`，从而推出 `(1)`。

该版本明确禁止同一客户在多个前缀分支中重复产生旧位份额。更一般的“净变分”版本允许多个非零差额，只要它们的带符号和仍满足 `(UV')`。

一个足够但更结构化的检查是：对每个 `k`，强制 `T_{pi(k)}` 后的未来覆盖者多重集与未强制 `A_k` 时的未来覆盖者多重集完全相同，并且同一客户只在一个 `k` 上发生当前位份额交换；这是固定后继的单枢轴特例。它保留了真实 `(IC_k)` 的量词，但显然不是一般 SPE 自动满足的性质。

## 4. 一般性边界与已知障碍

不能把 `(UV)` 从覆盖指示元的“至多一次 0->1/1->0”推出。后继可以在一个强制前缀后新增客户覆盖，再在后续强制步骤中改变覆盖者，产生多个正旧位份额项并抵销最终新增客户的负位份额。例如 `random_position_exchange_boundary.md` 的完整三人 SPE 已排除把随机最优前缀按位置交换的简化；它只说明位置对称桥失败，不否定 `(UV)` 作为条件接口。

同样，`(UV)` 不能由 `Z^k` 覆盖集合的单调性、静态替槽的 Bernoulli/Harmonic 预算或单个终局的 owner-error 自动推出。那些关系分别只控制覆盖指示、静态替换势或同一叶预算，并未控制 `d_x` 在互斥离轨前缀间的重置。

因此本页的数学身份是：

* **已证：** 对任何完整 SPE，若一条最优前缀链满足 `(UV)`，则 `O-W<=W`，证明只用真实 IC 总和和覆盖望远镜；
* **未证：** 任意完整 SPE 是否存在满足 `(UV)` 的最优元组排列，或是否可用全树随机化/流构造替代 `(UV)`；
* **未主张：** Q-CAG-HALF 已解决，或一般响应变化必然不重复。

## 5. 可复验记录

该条件桥不依赖数值实验；机器核验只需对给定完整策略、排列和全部 `Z^k` 逐客户计算 `s^-`,`s^+`,`V_x`。任何未来候选应同时核对所有离轨历史的 SPE 最优性以及 `(UV)`，不能只核在轨路径。
