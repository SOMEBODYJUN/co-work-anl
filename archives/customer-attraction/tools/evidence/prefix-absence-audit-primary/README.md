# 前缀缺席原算术审计证据

自足对象：[前缀缺席判据的原算术审计与有限改进表](../../../state/程序/前缀缺席判据的原算术审计与有限改进表--程序.md)。

`source-manifest.json`固定两主源5126B的inventory ID、双冻结提交、路径、大小、SHA-256与Git blob；`original/`保全原程序和原JSON全部字节。原程序只用标准库Fraction核有限标量公式；原JSON保8178个覆盖mask、171700个系数三元组、933与1156个m/k蕴含及17条改进，不是客户或完整策略证书。历史argv、环境及计时缺失，不追填。

本批不执行原程序，也不重跑已发表EF定义检查。`compare_saved_reports.py`仅将EF已有完整JSON的计数及5050组m/k筛选投影，与原报告全部七字段逐项比较；它不重算谐和数或系数。实际比较入口一次，结果`saved-report-comparison.json`，命令、stdout/stderr、退出码及真实耗时在`comparison/`。数据一致不等于原入口复现、独立新数学枚举或普遍证明。

`reading-review.json`区分全部实读与检索命中，记录已归档定理/资源、成熟EF实现和原MD/README的比较。`repository-related-search.txt`与`search-record.json`是全仓相关文本发现；命中不自动算完整阅读。`self-check.json`记录本批文件身份、链接与数学范围自查。

一般六人half仍未由本批解决；原17行仅显示谐和判据超出旧残余充分条件的有限参数，不认证单调性、锐性、外审或新颖性。正式登记及Git保存由Boss串行处理。
