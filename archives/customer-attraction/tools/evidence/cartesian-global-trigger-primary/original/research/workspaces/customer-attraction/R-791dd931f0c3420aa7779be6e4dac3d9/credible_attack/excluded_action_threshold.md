# 同一 joint-trigger 的精确偏离阈值：可能余量仅在前三位

2026-10-25。解析组件，作者证明；独立复核状态见父actor接续。它细化 README §1 的同一个完整策略，不是有限字典扩样，也没有新的 half 例或福利界。

沿用 README 的输入和固定脚本。某一在轨节点的各坐标 ell-menu 记 ell_c(b)，M_c=max_b ell_c(b)，当前脚本元组为 a。真实偏离动作必须满足整个元组 b≠a。固定的首次失配后 product-min 后继使偏离收益**精确**为 Σ_c ell_c(b_c)。因此真实偏离阈值为

    D = max_{b∈∏A_c, b≠a} Σ_c ell_c(b_c).

若存在非平凡坐标，写

    L_c^neq = max_{b_c≠a_c} ell_c(b_c)   (|A_c|>=2),
    epsilon = min_{c:|A_c|>=2}(M_c−L_c^neq).

则

    D = Σ_c M_c − epsilon.                                      (1)

**证明。** 所有 b≠a 是各事件 b_c≠a_c 的并。因此先固定一个这样的 c，其余坐标独立最大化，得到 L_c^neq+Σ_(d≠c)M_d；再对 c 取最大，恰为(1)。所有有限最大值达到。若各坐标均单行动，联合也无偏离，当前IC为空。

将每个在轨节点的条件改为 Σ_c u_i^c(script)>=D_i，按 README 同一逆归纳即给同一确定 trigger policy 的**充要**逐历史 IC 条件：离轨所有 product 子 SPE 已经合法，只有这些在轨比较待核验。它比保守条件 Σ delta_i>=0 精确。

## 严格最大者是承重条件

只要任一非平凡坐标有另一个最大 ell 动作（包括 a_c 自身不是最大者的情况），就有 L_c^neq=M_c，所以 epsilon=0。因而 epsilon>0 要求每个非平凡坐标的 a_c 都是其 ell-menu **唯一严格最大者**。这不是对原模型施加平局规则，而是公式(1)产生的必要条件。

正坐标权重会同时缩放 ell、M、L 和相应差额；故 epsilon 是各正权坐标相应差额的最小值，不能把每坐标排除脚本动作的差额相加使用。零权坐标应预先删除。

## 在末两位不能放宽旧聚合条件

任意完整联合 SPE 的末位行动，由完整 Cartesian 与收益可加，必须在每个坐标分别 BR。

在倒二节点，真实脚本孩子是这些局部 BR 的 product。因此倒二脚本收益满足

    u_(m−1)^joint >= Σ_c ell_c(k_c,a_c),                         (2)

因为 ell_c 是固定当前脚本行动后、所有局部末位BR中的最小当前收益。这里仅余一位玩家，局部完整suffixSPE恰为末位BR，没有假设更早坐标策略分解。

若每坐标 a_c 都是最大 ell 动作，(2)直接给 u_joint>=ΣM。若不是，每坐标取一个最大 ell 动作可以组成与脚本不同的合法元组，因此是真偏离；其固定触发后的收益为ΣM，IC也给 u_joint>=ΣM。故被这个精确trigger实现的脚本，在倒二位仍必满足旧 GT。末位同理，甚至逐坐标 gap 均为零。

因此 m=5 时，公式(1)相对旧(GT)可能新增的可信空间只在前三位；并且在哪一位使用非零排除余量，该位全部非平凡坐标必须具有唯一严格最大 ell 的脚本动作。第3位以后仍需通过真实可信的孩子把这笔潜在信用实现，不能只把 epsilon 写到路径预算右侧当作已付款。

有限字典9/5证书仅处理旧(GT)的非负混合，没有自动覆盖本精确修正。本文同样没有声称该修正实际能产生更差福利。下一步若使用它，应先给前三位严格menu最大者以及后续完整子 SPE 的同一实例；重复旧参数扫描不补充这些义务。
