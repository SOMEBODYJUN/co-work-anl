# 全坐标首次失配 trigger：可验证接口与本轮停止点

2026-10-25。**Q-CAG-HALF / HALF(5) 仍 OPEN。本目录没有 half 反例，没有新的福利常数。**
新增的是一个明确允许非可信坐标路径相互补贴的完整历史构造接口；26 个固定输入的混合字典已精确关闭于既知的 9/5，故不再扩大同类字典。一个五坐标例验证接口能实现各坐标自身均非 SPE 的路径，但其总比例仅 905/812。

## 1. 精确的全历史充分接口

采用原 CAG-MODEL。固定同一人数 m>=1，有限多个客户不交的坐标 c，各坐标有有限非空共同目录 A_c。联合目录是**完整 Cartesian** ∏_c A_c；一个联合动作在每个坐标选一个合法主题，其覆盖为各坐标覆盖之不交并。每坐标任选长度 m 的有序脚本 a^c，不要求它自身是局部 SPE 路径。

令 k_i^c 为该脚本在 i 之前的主题计数，R_c(k) 为完整历史纯 SPE 的真实终局计数全集。定义

    ell_c(k,b) = min_{q in R_c(k+e_b)} U_b^c(q),
    M_c(k) = max_{b in A_c} ell_c(k,b),
    delta_i^c = u_i^c(a^c) - M_c(k_i^c).

所有极值均在非空有限集达到。若每个 i 都有

    sum_c delta_i^c >= 0,                                      (GT)

则存在一份**全部有序历史上的纯 SPE**，其实际联合脚本为 (a_i^c)_c。

正有理坐标权重可缩放客户重数；先删除零权坐标，再共同清分母，得到不同的单位客户。原模型中的空主题、任意重复动作、零客户及平局均保留。该接口不声称 (GT) 对全部联合 SPE 必要。

### 一个确定的完整策略定义

在尚未失配的每个联合脚本前缀，执行下一脚本动作。若 i 是联合历史**第一次**不等于脚本的位置，当前联合动作写 b=(b_c)_c，则在**全部**坐标（包括 b_c=a_i^c 的坐标）进入一份从局部有序前缀 (a_1^c,...,a_(i-1)^c,b_c) 开始、达到 ell_c(k_i^c,b_c) 的局部完整 suffix-SPE。此后永久执行这些固定局部策略的 product；不因后来动作失配再次触发。

为消除选择自由，可用规范确定规则生成上述局部策略：终局目标在达到所需最小值的计数中取词典序最小；一个目标 q∈R_c(k) 的当前行动，在满足 q∈R_c(k+e_t)、U_t(q)>=M_c(k) 的主题中取标签最小；规定孩子保持 q，其他孩子各取当前行动收益最小且词典序最小的终局，再递归。这逐个有序历史定义动作，不要求同计数历史选择相同目标。

### 全部历史的 IC

固定任意首次失配位置 i 及任意联合动作 b。触发后各坐标后继均是完整局部 SPE，product 因收益可加而是联合 suffix-SPE。偏离者所得恰为

    sum_c ell_c(k_i^c,b_c) <= sum_c M_c(k_i^c)
                            <= sum_c u_i^c(a^c).

第一次失配后任一更深历史由固定的 product 子 SPE 覆盖。对尚未失配的脚本节点按 i 逆归纳，所有行动孩子已可信，以上比较验证当前脚本动作最优。不同第一次失配子树不交，可以同时选择其局部后继；全局历史不同而局部历史相同也允许不同续局。

末位 gap 在每坐标均 <=0，所以 (GT) 在末位迫使每坐标脚本末动作分别为 BR。空目录不允许；全空/零客户时各值为零，策略照常成立，不定义 0/0。

**审查：** sibling exact_tree 从仅含陈述的任务独立重构此充分性，见 [独审](../exact_tree/global_trigger_independent_review.md)。该审查包含一个 m=2 的“只切改变坐标”严格失败例，说明全坐标切换确实承重。外审与新颖性未认证。

## 2. 五坐标真 SPE 例：坏坐标可以被付掉，但未破 half

全部 m=5。第一坐标有五个互不交的主题，各 31 名客户，另有空主题；脚本为 (empty,empty,empty,0,1)。该坐标 W=62、OPT=155，所以局部覆盖比 5/2；前三位各有 gap −31。

其余四坐标均来自 `examples/customer_attraction/collision_free_occupancy.json` 的客户关联，统一改成 m=5，并加空主题。未缩放的四个主题为 A={x,a,b}、B={a,b,y}、C={a,b}、D={y,z}，五名客户 x,a,b,y,z 均单位。分别缩放 6、18、36、90 倍，脚本与未缩放 gap 为：

| 缩放 | 脚本（标签 0=A,1=B,2=C,3=D） | delta_1,...,delta_5 |
|---:|---|---|
| 6 | (0,0,2,3,1) | (1/6,1/6,−1/3,1/2,0) |
| 18 | (0,2,2,3,0) | (1/6,−1/3,−1/2,1,0) |
| 36 | (0,3,0,2,3) | (1/3,1/6,1/3,−1/6,0) |
| 90 | (3,0,0,2,3) | (1/6,1/3,1/3,−1/6,0) |

逐列相加，全部五位 aggregate gap 恰为零。因此第1节的确定策略定义提供全部有序历史上的联合纯 SPE。这五个局部脚本各自都违反至少一个局部 M 阈值，均非局部 SPE；并未把局部模板可行向量当成 SPE。

联合目录有 6·5^4=3750 个主题。每个坐标使用至多五个主题即可覆盖其所有客户，完整 Cartesian 允许对每坐标分别取最优五元组并按位置组合，所以真实 OPT_5 可加。本例

    W = 62 + (6+18+36+90)·5 = 812,
    OPT_5 = 155 + (6+18+36+90)·5 = 905.

故本例仅展示可信实现机制，**不推进最坏福利下界或上界**。全策略由上面的确定公式定义；无需把 3750^4 个有序决策节点逐项存盘。

## 3. 被精确关闭的有限字典

`joint_trigger_overlap_probe.json` 冻结全部26个局部输入（含空主题），每个都统一 m=5；它不依赖以后示例文件是否改变。对其全部289750条脚本逐条计算真实 BI threshold。末位 gap 严格负的脚本不能在任何满足(GT)的非负混合中有正质量，所以可删去这些**列**；并未从任何输入目录删除空主题/重复/离轨历史。余下68351条末位BR脚本按 (delta,W,OPT) 去重为17095列。

以 sum weight·W=1 归一化，要求各位 sum weight·delta_i>=0。该明确字典的精确混合最优值为9/5。精确原始点是大小 (5,1,1,1,1) 的不交银行坐标全选大主题，权重1/5；精确非负对偶为

    beta = 9/5,
    lambda = (2814/20407, 177282/102035,
              47838/102035, 359626/102035, 0).

对全部17095列，已逐项有理核验

    beta·W - OPT - sum_i lambda_i·delta_i >= 0.

故这个字典的所有非负混合（不限混合坐标数）确实 <=9/5。它**不覆盖其他局部输入，不覆盖所有联合 suffix 耦合，也不给一般 Cartesian 目录或原 CAG 的9/5上界**。第2节的五坐标例由另一个目标提取，随后使用有理线性代数恢复并精确核验；其证书中的权重以 W=1 归一化，乘812即上表整数缩放。
