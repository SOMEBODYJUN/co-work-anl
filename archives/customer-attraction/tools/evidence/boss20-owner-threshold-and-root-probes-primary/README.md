## 纠错与执行事件

- 原owner审查的HYB用M(J)正确，但Bernoulli/HHYB右侧须用E_J（owner动作不盖客户且owner在J），不能沿用M(J)。两人五客户例的合法B只反这个静态显示式，不提供SPE证书，不反正确运输或half。
- 原threshold MD的“每输入至少729条”错误：729是三标签六人全部合法路径上限；全兴趣唯一客户可达729，仅喜欢T0的唯一客户只有一条。39204条/2186输入、最小松弛1均保冻结报告身份，无当前重算。
