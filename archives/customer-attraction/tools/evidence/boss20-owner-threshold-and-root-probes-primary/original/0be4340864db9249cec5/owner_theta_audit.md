## Owner-hybrid 的逐式复核

固定最优合法元组 `T`，取不交分析 owner 块 `Q_i⊆T_i`，并集 `O`。对任意合法叶 `B`，令 `C_x` 为覆盖角色，`c_x=|C_x|`，以及 `M(J)={x∈O:o(x)∈J, C_x∩J=∅}`。将 `J` 槽由 `Q` 换成 `B`、其余槽扩为 `T` 后仍是合法 `m` 元组，因此联合大小不超过 `O`，从而

```
|⋃_{i∈J}(B_i\O)| ≤ |M(J)|.                         (HYB)
```

在 `J` 内独立替换的 Bernoulli 比较给

```
Σ_{y∉O}(1-(1-p)^{c_y(J)})
 ≤ Σ_{x∈M(J)} p(1-p)^{c_x(J)}.
```

除以 `p` 从 0 到 1 积分，分别得到 `H_{c_y(J)}` 与 `1/(1+c_x(J))`。在 `c_x(J)=0` 或 `c_y(J)=0` 时端点解释为 `1` 与 `H_0=0`，没有除零。

对外部真实利润 `b_i=Σ_{y∉O,,y∈B_i}1/c_y`，任意角色割 `J` 满足 `b(J)=Σ_y c_y(J)/c_y≤|M(J)|`。owner 到每个 `C_x` 的边容量 `1/c_x`（`c_x=0` 时到汇容量 1）因而饱和所有 source 边；自环删去不影响。调和版本使用 `kH_c/c≤H_k` 和每个 `x∈M(J)` 的出割 `(1+l)/(1+k+l)≥1/(1+k)`，同样通过有限最大流最小割。重复主题、空 owner、`c=0`、`k=0` 均有明确端点处理。

实际叶代入时，A 图的汇恰为 `R=O\\C`，角色边恰为 `I=O∩C`，得到

```
η_i = u_i - (out_i-in_i) = u_i(I)+γ_i,
Σ_i η_i = W.
```

若 `D_i(T_i)` 指同一强制 `T_i` 后沿原策略的完整收益，则 source 初始化吸收满足 `A_i^src≤D_i(T_i)`，所以 `K_i^src=u_i A_i^src/D_i(T_i)≤u_i`；局部取消选择确实可与同一 A 流同时扩充。

这份复核只支持同叶静态容量。图允许向更早角色转运，且不同强制叶的 `γ`、owner 边容量和真实 IC 行不一致；不能把 A、B 两张图的库存相加，也不能跨互斥叶把同一 `u_i` 或 `η_i` 再领一遍。`K_i^in`（传播到达的后继查询费用）没有由 `η_i-K_i^src` 支付，这是目前真实动态缺口。若后续把 `D_i` 截断到 R、换用另一个 continuation，或把任意静态 B 直接当原节点 IC，就会越过已证范围。

## 动态 Theta 的精确量词

在实际路径前缀 `h_i` 定义

```
R(h_i,A) = {从 (h_i,A) 开始的完整纯子博弈 SPE 可实现终局},
L_i(A)=min_{z∈R(h_i,A)}u_i(z),
Theta_i=max_A L_i(A).
```

有限完美信息博弈保证这些集合非空。设当前 σ 的实际动作是 `A_i`。其限制在每个孩子 `(h_i,A)` 后是一个完整 SPE 续局，所以该续局收益属于 `R(h_i,A)`；特别 `u_i≥L_i(A_i)`。若存在某个 A 使 `L_i(A)>u_i`，则 σ 在该同一孩子所选的续局也给当前玩家严格高于 `u_i` 的收益，构成根节点（该历史）的有利偏离，违背 σ 的 SPE 最优性。因此

```
u_i ≥ Theta_i,       Σ_i Theta_i ≤ W.
```

这里必须把 `R(h_i,A)` 解释为局部子博弈的 SPE 续局集合；若把它误写成“能与固定祖先策略同时延拓成全局 SPE”的集合，定义会不必要地缩小且上述最坏门槛需重新说明。反之，`R` 是所有局部 SPE 续局时，SPE 只给上述逐节点门槛，不给不同 A 或不同 i 的共同续局。

因此

```
SM: Σ_i L_i(T_i) ≥ O-W  =>  O≤W+Σ_iTheta_i≤2W
TB: O≤W+Σ_iTheta_i
```

的逻辑方向是对的，但 SM/TB 本身仍未证。有限枚举无负 slack 只作候选筛查；不能替代任意 m、任意目录的一般证明。固定 σ 的 `Gamma` 锥也不能直接证 Theta：`L_i` 在离轨 tie 面取各子博弈 SPE 的最小值，会随 tie 选择跳变，而固定 σ 的 Gamma 只含其一个续局。

## 可复用修正与下一检查

1. 在任何正式引用中显式写“局部子博弈 SPE 续局”，并在 `D_i(T_i)` 的定义中注明完整原策略 continuation；这排除了把静态叶利润错当 IC 的歧义。
2. 对 dynamic payment 必须保留 `(h_i,A)` 的历史标签以及同一真实 whole-IC 行；只保留主题计数或跨叶合并会失去 SPE 约束。
3. 继续攻一般证明时，真正待付对象是所有传播 `K_i^in` 与跨叶库存的共同支付，或直接证明 SM/TB；不要从 `ΣTheta_i≤W` 单独推出 TB。

本审查未生成 Q-CAG-HALF 证明或反例；它只确认了上述组件的可证范围和动态接缝。
