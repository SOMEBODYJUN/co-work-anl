# 动态 Theta 门槛：当前精确状态（Boss20 / route_theta）

日期：2026-10-24。本文是个人研究备份，服务唯一主目标 Q-CAG-HALF；不改变主目标 OPEN，也不把有限核验升级为一般定理。

## 对象与定义

固定任意有限共同目录、任意人数 m、任意完整历史依赖的纯 SPE σ。记实际有序路径前缀为 `h_i`，第 i 位尚余 `r_i=m-i+1` 人。对合法主题 A，令

```
R(h_i,A) = 从固定历史 (h_i,A) 开始的完整局部纯 SPE 所能实现的终局集合,
L_i(A) = min_{z in R(h_i,A)} u_i(z),
Theta_i = max_A L_i(A).
```

这里 `R(h_i,A)` 是该局部子博弈的全部 SPE 续局，不是限制为某一份祖先策略可以同时延拓的续局。有限完美信息保证集合非空。

## 已证关系：逐动作 IC 给出 `u_i >= Theta_i`

设实际动作是 `A_i`，实际 σ 的离轨续局终局 `z^sigma_{i,A}` 属于 `R(h_i,A)`。因此

```
u_i(z^sigma_{i,A}) >= L_i(A)
```

对每个合法 A 都成立。完整 SPE 在历史 h_i 要求实际收益不低于沿同一 σ 强制 A 后的收益，于是

```
u_i(actual) >= u_i(z^sigma_{i,A}) >= L_i(A)  (all A).
```

取 A 的最大值，得到

```
u_i(actual) >= Theta_i.
```

对实际路径求和并使用 `W=sum_i u_i`，得到无条件的

```
Σ_i Theta_i <= W.
```

这一关系是一般输入、全部有序历史和任意历史依赖平局下的定理；它本身不控制最优覆盖。

## 两个尚未闭合的候选

给任意最优 m 元组 `T_1,...,T_m`，设 `O=OPT_m`。尚未证明的同序矩阵候选是

```
SM: Σ_i L_i(T_i) >= O-W.
```

若 SM 对某个最优元组排列成立，则 `O <= W+Σ_i Theta_i <= 2W`。更弱但直接的动态门槛候选是

```
TB: O <= W + Σ_i Theta_i
```

以及更强的 TB-ANY：即使将 `h_i` 取为任意合法有序路径的前缀，仍有
`O <= W(path)+Σ_i Theta(h_i)`。这些候选都未证明，也没有目标 Q-CAG-HALF 的反例。

候选的精确 Bellman 形式（只用于判别，不是证明）是

```
J(k)=W(k)                                  if |k|=m,
J(k)=Theta(k)+min_A J(k+e_A)                otherwise,
```

其中 `k` 是主题计数前缀；`J(0)>=OPT_m` 等价于 TB-ANY。计数只缓存全部局部 SPE 终局集合，未施加匿名策略限制。

## 已知局部加强失败

不能把 `Theta_r(b) >= OPT_r(b)-OPT_{r-1}(b)` 作为递推前提。现有四人 `root_tax_failure` 的精确输入给出空背景 `OPT_4=61`、固定首位主题后的最优三槽覆盖 `OPT_3=51`，而集合值逆向归纳的根门槛为 `Theta_4(0)=9`，故边际为 10，严格有 `9<10`。这只否定该局部充分条件；它不否定 TB、SM 或 Q-CAG-HALF。

## 有限核验范围（观察）

已独立运行 Fraction 精确求解器对小目录/人数的随机与穷举实例，未发现 `W+ΣTheta-OPT<0`；该观察不提供一般证明。已知冻结运行包括 3 主题 5 人二值全集（128 实例、3288 条可实现有序路径）和 4 主题 4 人的随机样本；不继续扩样，避免以有限阴性替代证明。

## 真正剩余义务

要推进一般命题，必须证明 SM/TB 的跨分支共同支付，或构造满足 `OPT>W+ΣTheta` 的完整精确反例。早期偏离后继会改变全部动作；不能把不同 `R(h_i,A)` 的最坏续局收益相加后视为同一条实际路径的客户预算。固定策略 Gamma 锥只含一份选定续局，不能直接线性化 `L_i(A)` 在全部子 SPE 上的最小值。
