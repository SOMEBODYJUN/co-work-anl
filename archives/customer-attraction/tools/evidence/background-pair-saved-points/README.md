## 数学边界

原表所记是带尾PAIR：u1+u2+(n−2)v_tail−n v_root，不是plain首对不等式。原表声明300、60、120次完成循环，无去重证据，不能说已遍历480个互异锥或一般策略。三表所有prefix均缺失；B还含两个非零负质量。A/C的零或微负gap也没有精确可行性和严格反例证书。

唯一新核验使用全历史动作皆属于同一大块的解析式：历史深度d、已有r次大块时，选大块得n/(r+n−d)≥1，选单例得1/(既有单例次数+1)≤1。核4756节点/31737含self比较，无大收益矩阵、原main/helper/LP/solver/RNG调用均0。三新实例均保留原标签和同覆盖大块别名，有六名单位客户，提供者分别4、5、5；在该标签模型中，完整指定SPE的根与尾真安全值均1，PAIR为0，W/OPT依次2/3、5/6、5/6。该结论不认证原浮点输入、不恢复缺失背景，也不证明一般PAIR或六人半覆盖。

[严格共同目录定义](../../../state/定义/共同目录完整历史模型--定义.md)使用集合目录，同覆盖集不是多个不同元素。合并标签不自动保持原指定全历史策略和比较域；本包未另证商策略下降，不把三个校准称为严格集合目录的原输入。通用安全值/偏离推导也涵盖覆盖映射单射的严格子域。此次只作正文与元数据边界补注，原件/动作/唯一数学事件均保字节，0新数学。

本包与同伴另三张四人六题数据的定义核是不同输入和不同执行事件；没有相互冒认。比较了全前缀条件归并、旧固定策略库记录、113客户逐步付款反例以及巨大合法背景的plain首对反例，不重复它们的成熟核验。
