# 被拒绝的辅助候选和证明目标

采用[有限共同目录完整历史模型](../定义/共同目录完整历史模型--定义.md)：单位客户、单位提供者、非空有限真实集合目录；允许空主题、重复实际行动、全部有序历史和任意离轨平局。原832B candidate提出过：每个实例可选一份**最小福利**完整纯SPE，使某个全局最低收益者在末位或倒二。它不是原half命题；若成立，可对最差均衡的最小收益用真实末两人价格端点支付half，再由其它SPE福利不低于最差者推广。原候选已被明确否定，不继续标作待证定理。

记总人数m≥2、实际根福利W=Σ_i u_i。定义纯末位最坏背景值
\[
\theta_m=\min_{(T_1,\ldots,T_{m-1})\in\mathcal S^{m-1}}\max_{A\in\mathcal S}
\sum_{x\in A}\frac1{1+\#\{j:x\in T_j\}}.
\]
背景是全部合法m−1长元组，不只某均衡到达的前缀。它是min–max纯值，不是查询先抽样的混合静态值v_m。

# 一般门槛：即使更换整份策略也要付福利

[真实末两人保底](../定理/末两人逐人保底与全人数弱福利界--定理.md)对每份完整SPE的末两位分别给u≥θ_m。自足承重点是：给倒二前缀p，置f_p(A)=Σ_(x∈A)1/(p_x+1)，U_p(A,B)=Σ_(x∈A)1/(p_x+1+1_B)。逐客户有U_p(A,B)−U_p(B,A)=f_p(A)−f_p(B)。若倒二偏离到即时f_p最大主题A，对其**同一策略真实末位最佳回复B**有U_p(A,B)≥U_p(B,A)≥θ_2(p)≥θ_m，倒二最优性传给实际收益；实际末位直接最佳回复也达θ_m。

因此只要某份SPE的全局最小收益至少一次落在末两位，所有人收益都≥θ_m，故W≥mθ_m。若存在完整SPE σ_0福利W_0<mθ_m，则每份福利≤W_0的完整SPE，其最小收益的**全部出现位置**都早于末两位。任意更换完整策略使其最小者进尾部，福利至少增加mθ_m−W_0>0。全局最低值平局也包括；m2时前提不可能发生，零覆盖不满足严格前提。

同一终局多重集重排会保覆盖和收益多重集，但不保策略树可信性；若原W_0低于门槛，把最低者移到尾部的重排便不可能扩成完整SPE。这个障碍不局限局部交换，也不否定允许显式付费的变换，更不反驳half。

# 36个真实单位客户与两份完整策略

六主题X={0,1,2}、Y={3,4,5}。每个跨组pair放一个客户（9个）；每个“两X+两Y”兴趣集合放三个不同客户（9种×3=27个），总36，主题均为真实不同集合，每主题21客户。三名提供者，OPT_3=36（选整个X或Y）。任何有序末前缀(a,b)的最佳回复收益：a=b时15，a≠b时12，故θ_3=12。

令group(b)为b所属三主题块。两策略末位都在任意有序(a,b)后取group(b)中最小未出现主题。未归一化策略：根取0；第二人见首a后取另一组最小主题。实际路径(0,3,4)，收益(10,12,12)，W34。归一化策略只把“首a0之后第二人”改成1，其它第二节点及末位不变；根仍0，实际(0,1,2)，收益(12,12,12)，W36。

完整节点最优性可直接分类。末位总选新主题：过去同主题时同组新主题给15；过去同组不同主题时补本组第三主题给12、去另一组只给10；过去跨组时在任一组取新主题都给12，可按历史破平局。第二人重复首主题只能得9，选同组新主题可迫末位补第三项、得12；跨组选择在末位偏向第二组时也得12。所以两策略的每个第二节点均最佳。未归一化根选任意主题均得10；归一化根选0得12，其余行动按原续局只得10，根也最佳。所有43个有序决策节点均已定义，不是只检实际路径或静态NE。

# 全部SPE终局与恰两单位代价

每份SPE中第二人不重复首主题（9<12）。若前两主题同组，末位严格补第三个，三人均12，福利36；若跨组，第二人必须由末位取其组的新主题而得到12，否则仅10、低于同组偏离保底12。于是跨组SPE终局的minority必为第一人，收益(10,12,12)、福利34。

两样式都有上述完整策略及主题自同构像达到：同组全异有2·3!=12条有序终局；跨组且minority第一有6·3·2=36条，共48。前12条最低值12在全部位置出现，后36条最低值10只在首位。因此
\[
\min_{\sigma\in SPE}W=34,\quad
\min_{\sigma\in SPE:\,末两位含全局最小者}W=36,
\quad\Delta_{min}=2.
\]
这是该实例的恰值，不是所有实例的统一代价；一般只有mθ_m−W_0下界。本例W34仍远高于OPT_3/2，不是目标反例；真正混合静态值v_3=10也与θ_3=12不同，34≥3v_3不受否定。
