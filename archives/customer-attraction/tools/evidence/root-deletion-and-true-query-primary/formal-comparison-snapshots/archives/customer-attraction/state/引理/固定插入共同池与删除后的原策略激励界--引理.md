# 固定插入共同池与删除后的原策略激励界

## 一份终局的共同客户池

采用[共同目录模型](../定义/共同目录完整历史模型--定义.md)的单位分享公式。固定非负整数旧背景b、一个插入的单位主题A，以及n个后继主题组成的有序元组q；主题可空、重复。写$c_x(q)$为后继覆盖重数，$L_x=b_x+c_x$。插入者的收益、后继角色j的损失分别为

$$d_A(q)=\sum_{x\in A}\frac1{L_x+1},\qquad
\delta_j(q)=\sum_{x\in A\cap S_j(q)}\frac1{L_x(L_x+1)}.$$

后式涉及的客户有$c_x\ge1$，分母正。求和得到**一份**共同后继损失

$$E_A(q)=\sum_{x\in A:c_x>0}\frac{c_x}{L_x(L_x+1)}\le d_A(q).\tag{1}$$

旧背景玩家的合计损失为

$$E_{old}(q)=\sum_{x\in A:b_x>0}\frac{b_x}{L_x(L_x+1)}.$$

逐客户$(b_x+c_x)/[L_x(L_x+1)]=1/(L_x+1)$，故精确有

$$\boxed{E_A(q)+E_{old}(q)=d_A(q)-|\{x\in A:L_x=0\}|.}\tag{2}$$

原先无人覆盖的客户向插入者贡献一单位，不向任何旧玩家返还。式(1)不是每名后继各领一次$d_A$；同一客户的损失已经在n角色之间分配完。

这些是固定元组的代数，不要求q为SPE。b作为任意整数向量时公式仍真；若用于原博弈历史，必须另核b来自合法前缀，不把任意静态b自动当成可达SPE背景。

## 有额外跨叶容量条件才可搬运一组激励

对完整子策略在固定背景$b+A$下的一组真正单次偏离行e，设规定叶$z_e^+$、强制当前动作后沿同一策略续局的叶$z_e^-$、当前角色$j(e)$，以及非负权$\lambda_e$。保持同一**有序尾历史到动作的映射**，只删除背景A。两游戏相应激励差满足

$$\Gamma_e^{without}-\Gamma_e^{with}
=\delta_{j(e)}(z_e^+)-\delta_{j(e)}(z_e^-).\tag{3}$$

按叶z与客户x收集系数

$$\kappa_z(x)=\sum_{e:z_e^-=z}\lambda_e\mathbf1_{x\in S_{j(e)}(z)}
-\sum_{e:z_e^+=z}\lambda_e\mathbf1_{x\in S_{j(e)}(z)}.$$

若另有$\rho_z\ge0$使所有$x\in A$满足

$$\kappa_z(x)\le\rho_zc_x(z),$$

则将式(3)按固定叶分母合并，得到

$$\sum_e\lambda_e\Gamma_e^{without}
\ge\sum_e\lambda_e\Gamma_e^{with}-\sum_z\rho_zE_A(z).\tag{4}$$

当$c_x(z)=0$时所有当前主题成员指标均零，该客户不进入分式；无需制造0/0。$\kappa$可带符号，不能先对每条行取正部而还声称相同抵消。这里**没有构造**$\lambda$、$\rho$，更没有把不同叶的$E_A(z)$都替成同一实际叶钱包。(4)明确是一个额外占用容量条件下的搬运证书。

## 保留同一完整子策略后的普遍缺陷界

现设$\sigma$在背景$b+A$、n名后继的子博弈中是完整纯SPE，实际尾为q。删除固定A后保持同一子策略映射，不把它换成原更短历史上的另一个调用；新映射不必仍是SPE。角色j的实际较早尾负载记$p_j(x)$，$b_j=b+p_j$。定义其实际节点一次偏离的正激励缺陷

$$\varepsilon_j=\max_T\big[u_j^{without}(z_{h_j,T})-u_j^{without}(q)\big]_+,$$

其中每个$z_{h_j,T}$仍是原$\sigma$在改变后的有序尾历史上真实续局。令

$$k_j=\max_{T\in\mathcal S}\sum_{x\in A\cap T}
\frac1{(b_j(x)+1)(b_j(x)+2)},\quad
K_b(A)=\sum_{x\in A}\frac1{(b_x+1)(b_x+2)}.$$

原SPE给$\Gamma_j(T)\ge0$。对每个被查询主题T覆盖的客户，无A时终局负载至少$b_j(x)+1$，所以

$$\begin{aligned}
u_j^{without}(z_{h_j,T})-u_j^{without}(q)
&=-\Gamma_j(T)+\delta_j(z_{h_j,T})-\delta_j(q)\\
&\le k_j-\delta_j(q).
\end{aligned}$$

该右侧非负：实际规定主题本身合法，其真实叶为q，因此$k_j\ge\delta_j(q)$。取最大、再求和，并用$b_j\ge b$，得到完整一般结论

$$\boxed{\varepsilon_j\le k_j-\delta_j(q),\qquad
\sum_j\varepsilon_j\le\sum_jk_j-E_A(q)
\le nK_b(A)-E_A(q).}\tag{5}$$

减去的$E_A(q)$是一份原叶共同损失；没有把它给每人重复扣减。式(5)是合法上界，却没有证明它足够小以支付福利归纳。空A、零客户、重复主题等按非严格有限和处理；n=0时缺陷和与后继池都为零。

## 删除一般整数背景的完整扩展

原主稿单列了其root于2026-10-24另给的扩展，分支当时只核代数而不宣称完成独立盲审。本页重新给全推导，不倒填历史审查。保留背景b，删除任意非负整数背景d；原子策略在$b+d$下为完整SPE。对实际尾负载c，定义

$$\delta_j^d(q)=\sum_{x\in S_j(q)}
\frac{d_x}{(b_x+c_x)(b_x+c_x+d_x)},\quad
E_d(q)=\sum_{x:c_x>0}
\frac{c_xd_x}{(b_x+c_x)(b_x+c_x+d_x)},$$

$$K_j^d=\max_T\sum_{x\in T}
\frac{d_x}{(b_x+p_j(x)+1)(b_x+p_j(x)+d_x+1)}.$$

选中主题客户的分母正，$d_x=0$项为零。固定leaf去d的收益差是$1/L-1/(L+d)=d/[L(L+d)]$，对$L\ge1$非增。因此任何强制当前T的真实续局损失至多$K_j^d$；减去实际$\delta_j^d(q)$后与上一证明逐行相同，得到

$$\boxed{\varepsilon_j\le K_j^d-\delta_j^d(q),\qquad
\sum_j\varepsilon_j\le\sum_jK_j^d-E_d(q).}\tag{6}$$

这里没有声称删除d仍保SPE，或任意d可由原目录的某个玩家集实现；应用回原游戏时要核合法背景。这个扩展也未解除跨叶容量问题。

## 关系、状态与接续
