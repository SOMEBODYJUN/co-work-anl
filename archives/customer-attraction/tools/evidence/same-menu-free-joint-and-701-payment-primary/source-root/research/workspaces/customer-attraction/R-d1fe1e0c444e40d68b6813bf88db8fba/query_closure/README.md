## 独立信息增量

旧的单回复闭包只要求每个强制主题产生的隐藏末回复分别通过实际主题、最优主题、共同末位价格与容量约束。新信息是：这些隐藏回复本身都属于**同一个共同目录**，因此必须在彼此的真实末位节点合法互查。

这确实超出已闭包参数族。`same_menu_reply.json` 的 `old_387_closed` 指旧 `six_copy_free_results.json` 已保存全单回复闭包见证的精确点；不加互查时本扩展可行（共同源偏离松弛最优为 0），加互查后存在下述五条非负行，其精确投影余量为

`-16038180749/520640190552 < 0`。

同一条简洁五权行也排除当前 587 行精确坏点，余量为

`-15202606357/486378586656 < 0`。

所以这不是只在旧闭包参数上重新调权，也不依赖先认定某个12主题实现就是全部可能实现。

## 一般局部引理（任意总人数）

固定任意人数、完整历史依赖纯 SPE、任意真实倒数第二源历史 h。客户背景负载为 b，源规定者原收益为 r。固定共同目录主题 A，以及任意 L 个合法比较索引 T_1,...,T_L（可重复）。强制 A 后的真实末回复记 R；强制 T_j 后的真实末回复记 S_j。所有回复来自同一份原策略，强制者不假定最优。

实际整局末位收益为 u、实际末位前负载为 ell，共同最大主题大小为 K。取任意非负 alpha,beta,gamma,delta。对每名客户，a=1_A，d 是其在比较索引中的会员数，p=d/L。令

```
c_R = delta*((1-p)/(b+1)+p/(b+2)) - gamma/(b+a+1)
D_t(s) = t/(b+t+s)
         + s*(beta+alpha/(ell+1)+gamma/(b+a+1)-delta/(b+t+1))
psi = min(0,c_R) + (1-p)*min_s D_0(s) + p*min_s D_1(s),  s in {0,1}
```

零分子份额为0。则一般有效：

`r + alpha*u + beta*K >= sum_x psi_x`。

证明直接加以下真实非负余量（对 j 求平均）：

1. `r - U_b(T_j,S_j)`，权1；
2. `U_b(R,A) - U_b(S_j,A)`，权gamma；
3. `U_b(S_j,T_j) - U_b(R,T_j)`，权delta；
4. `u - P_ell(S_j)`，权alpha；
5. `K - |S_j|`，权beta。

这里 `U_b(Q,T)` 是背景 b 下末位选择 Q、此前新增 T 时的收益。第2和第3条是相互查询；共同目录是其合法性来源。和式等于左侧减去逐客户表达式，表达式为 `average_j D_t(s_j)+rbit*c_R`。再减独立二元最小值仅增加非负余量。

关键身份是 R 不随比较索引 j 改变。必须先对其系数求平均，再对 R 的会员位取最小；先逐 j 消去 R 会重新丢掉信用。S_j 可分别消去，只会放松，不要求每个最小赋值都能由 SPE 实现。

旧闭包分离使用 `A=A2, L=6, alpha=13/288, beta=11/288, gamma=11/12, delta=1`。`verify_same_menu.py` 独立按此闭式对全部448种 `(actual_bits,d)` 客户类型重算，精确等于通用图投影生成器。

## 多回复图与统一接口

`same_menu_reply.py` 同时保留强制实际 A1,...,A6 后的六个固定回复，以及对六个比较索引强制后的平均回复。所有实际回复在比较索引求平均时保持同一会员位。每一对不同回复均加入真正末位 IC；也保留所有实际查询、最优查询、同一 u 与同一 K 约束。

分离程序只用浮点选择非负权；保存的行在448客户型上使用 `Fraction` 精确重建，所有权非负且源 IC 总权归一为1。对任何原实例，真实回复给出该扩展系统的一个可行点，因此分离行是通用必要行，而不是对某个12主题目录的特殊限制。

父方可直接调用：

```python

# 仅 exact_cut_slack < 0 才是精确排除；weights 可保存后重新生成row。
```

`868610807437/2038243085243 ~= 0.4261566315253531 < 1/2`。

最终点另保存103个回复会员量的精确可行见证，逐条验证所有共同菜单交叉IC、同一源IC、价格及容量；所以此点在本工作区的指定同菜单末回复图松弛内已精确闭包；这只表示该指定局部松弛闭包，不表示完整SPE可实现，也不表示不存在其他图、更深查询或更强行。
