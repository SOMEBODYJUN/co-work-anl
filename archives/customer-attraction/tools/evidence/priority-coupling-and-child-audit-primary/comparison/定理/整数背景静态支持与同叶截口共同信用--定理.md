# 量词、收益与审查读序

有限单位客户、有限非空共同主题目录，单位玩家依次观察全部有序历史，保空主题、重复及任意平局。固定合法非负整数背景b_x，任意n人终局y，c_x是这n人的终局负载。以下静态式**不要求y是SPE**；用到真实child时必须另外给其完整子SPE身份，不能由静态支持反造它。

定义f_b(0)=0，f_b(d)=d/(b+d)（整数d>0），U_b(y)=Σf_(b_x)(c_x)，只计剩余n位利润，不含固定背景角色。比较槽数k≥1，

\[
 J_k(b)=\max_{T_1,\ldots,T_k}\sum_x f_{b_x}(d_x),\quad
 p_x(y)=\frac1{b_x+c_x+1},\quad
 \beta(y)=\max_{T\in\mathcal S}\sum_{x\in T}p_x(y),
\]
\[
 \lambda_{b,c}^{(k)}=\max_{d\in\{0,\ldots,k\}}
 [f_b(d)-d/(b+c+1)],\qquad \Lambda_k(y)=\sum_x\lambda_{b_x,c_x}^{(k)}.
\]

背景正时J_k是剩余利润最大值，不能换成全客户覆盖OPT_k。零分子/零负载直接取0，所有价格分母≥1。

# SUPPORT与固定同一混合Q

对任一合法k比较元组，d_x∈{0,…,k}。λ定义逐客户给f_b(d_x)≤d_xp_x+λ，求和后价格项是k个合法主题价格，故

\[
 \boxed{J_k(b)\le k\beta(y)+\Lambda_k(y).}\tag{SUPPORT}
\]

任意分布Q混合真实叶（若宣称真实child混合，则每叶需真SPE），先固定一个达到J_k的比较元组再取期望，得

\[
 J_k(b)\le k\beta_Q+\mathbb E_Q\Lambda_k(y),\quad
 \beta_Q=\max_T\mathbb E_Q\sum_{x\in T}p_x(y).
\tag{MIX}
\]

查询元组独立于抽叶，β_Q是max期望，非期望max；更不能让每个查询挑不同有利child后仍算同一Q。混合真实纯SPE叶只是静态支持平均，不宣称随机玩家策略为新均衡。

# λ的整数截断和显式B信用

k≥c时，λ最大可在0≤d≤c达到。c0时d0值0，整数d≥1给d/(b+d)−d/(b+1)≤0；b0,c>0时正d目标1−d/(c+1)，d1最大。b>0,c>0时整数相邻差

\[
 h(d+1)-h(d)=\frac b{(b+d)(b+d+1)}-\frac1{b+c+1}\le0
 \quad(d\ge c).
\]

可定义λ_b(c)=max_(0≤d≤c)h(d)，不依赖k≥c。实际n人叶c≤n，因此k≥n或实际剩余人数截口都可用；最后k0,c0单独定λ_b(0)=0，不误调用k≥1支持命题。

对b>0的每个整数d≥0，精确有

\[
 \frac c{b+c+1}-\left[\frac d{b+d}-\frac d{b+c+1}\right]
 =\frac{bc+d(d-1)}{(b+d)(b+c+1)}\ge0.
\tag{INT}
\]

b0,d0单独值c/(c+1)；b0,d≥1差为(d−1)/(c+1)≥0。因此对所有k≥1，

\[
 K_b(y)=\sum_x\frac{c_x}{b_x+c_x+1},\quad
 B_b^{(k)}(y)=K_b(y)-\Lambda_k(y)\ge0,
\]
\[
 J_k(b)\le k\beta(y)+K_b(y)-B_b^{(k)}(y).
\]

整数性关键：b1,c0,d1/2时h(d)=1/12>0=K，分数比较负载破B≥0/截断。允许Q平均整数叶不等于可把比较负载d改实数。b0时任意k≥1都有λ_0^(k)(c)=c/(c+1)（c0亦0），所以B0。

取k=n，任意实α的真实或任意叶slack L_α(y)=αU_b(y)−J_n(b)满足

\[
 \boxed{L_\alpha(y)\ge\alpha U_b(y)-n\beta(y)-K_b(y)+B_b^{(n)}(y).}\tag{SLACK}
\]

无需先知α是福利因子，但不证明L_α≥0。混合版用β_Q和相应期望，不将L当独立可任选非负变量。n0端点U=J0=K=B0另作平凡处理。

# 同一实际叶全部截口的唯一总额

固定初始整数背景a、其后r个actual主题S_1,…,S_r，最终新增负载ℓ。第i截口已固定背景b_i=a+过去负载、尚余actual负载c_i，所以b_i+c_i=a+ℓ=:L，价格1/(L+1)全cut固定。用λ_(b_i)(c_i)定义Λ_i，K_i=Σc_i/(L+1)、B_i=K_i−Λ_i≥0。

\[
 \boxed{\Theta_i=q_i+B_{i+1}-B_i,}\tag{CUT}

\[
 \boxed{\sum_i\Theta_i=\Lambda_1=K_1-B_1\le K_1
