# 全树真实银行行：离开、重入与尚未支付的费用

2026-10-23。个人探索区；仅此目录编辑。Q-CAG-HALF 仍 **OPEN**。

本分支检查 R-4243 的单条银行路径预算如何跨越互斥离轨子树。新记录是
[探索路径的精确离开/重入恒等式](bank_reentry_identity.md)：逐步改变主动作而保留每个真实节点规定的银行动作时，银行行和由覆盖段入口、出口及末端给出。每个客户有调和级的入口预算；它不能仅靠任一根路径的一单位客户资本支付。

这不是完整 SPE 反例。文中的显式重入树是合法完整纯策略，**未**证明它满足 SPE；因此它只反驳对任意银行策略树的单位容量望远镜。联合激励可能禁止或另付重入，其数学费用仍须研究。

证据脚本 [audit_reentry.py](audit_reentry.py) 从真实有序联合历史生成每个续局，逐客户 Fraction 重算行和与入口/出口恒等式，写出 [audit_reentry.json](audit_reentry.json)。不使用同计数同续局，也不以计算证明全称结论。

下一次有信息价值的行动：为一个 `0→1` 银行客户重入构造真实完整 SPE 模块，或证明保持主动作改银行动作的真实比较能共同支付全部入口费。若仍只给银行树、不处理该联合激励，就不再用此树作主目标反例搜寻。

完成一次针对真实 SPE 的有限判别：[probe_true_spe_reentry.py](probe_true_spe_reentry.py) 在 15 棵完整有序历史 SPE 上最大化“每步主收益不降”的探索路径银行费用，范围为 3×3 不交单块 Cartesian 目录、m=4,5,6。未找到超过根银行福利的路径；最大比例1/10，且这些最优路径的主收益改变量都为零。因此该小检查没有实现真正正主盈利的重入，不能作为一般预算证据，暂不继续同类扩样。精确记录见 [probe_true_spe_reentry.json](probe_true_spe_reentry.json)。

已读 R-171cd7 的 clock/reset 两 singleton 完整 SPE 族：那里的未支付量是稀疏租金 skip-premium；m=2q 时其终局两客户负载固定(q,q)，对无客户主标签探索，保持当前银行的真实收益差恒为0。故不能把那条真实SPE的premium发散直接当成本目录的银行Γ行发散，也不能将本形式重入树冒充该旧例的重新证明。
