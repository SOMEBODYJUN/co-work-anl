# 固定前缀的锚定安全预算与实际删除背景的准确停界

2026-10-24，个人研究 checkpoint。**Q-CAG-HALF 仍 OPEN。没有一般 half 证明或反例。** 本稿给可在任意合法前缀使用的静态预算及同叶储备支付，然后明确否定一个更强、仅用实际终局删除背景的充分路线。静态预算是共同目录逐客户预算的自然有背景扩展，不宣称新颖性；本轮没有找到能对一般人数支付查询项的新后继 IC。

## 1. 任意前缀及共同随机背景的精确预算

采用当前 CAG-MODEL。固定一个合法有序前缀 h，其客户负载为 b，尚有 r>=1 名 active 玩家。这里不改变一份给定完整策略，也不把同计数历史的续局合并。取任意 k>=1 个合法比较主题 T_1,...,T_k，其并大小为 O，逐客户比较计数为 d_x。

令 Q 为任意分布，支撑于 r-1 个合法主题组成的竞争元组；空元组允许用于 r=1。Q 不观察查询主题的实现。写

    f_Q(T) = E_Q sum_(x in T) 1/(1+b_x+c_x(Q)),
    t_Q = max_T f_Q(T),
    A_Q = E_Q sum_x b_x/(1+b_x+c_x(Q)).

所有分母正。设 L_x=E_Q c_x(Q)，并定义

    g(T)=sum_(x in T)1/(1+b_x+L_x),
    M=max_T g(T),
    A_mean=sum_x b_x/(1+b_x+L_x).

逐客户有非负余项

    (d+b+L)/(1+b+L) - 1_(d>0)
      = (b+L)/(1+b+L),          d=0;
      = (d-1)/(1+b+L),          d>0.

若 q 是 Q 各竞争槽的平均主题边际，则 L_x=(r-1)sum_(T containing x)q_T，故共同目录给

    O <= sum_(j=1)^k g(T_j)
         + sum_x L_x/(1+b_x+L_x) + A_mean
      <= k M + (r-1)sum_T q_T g(T) + A_mean
      <= (k+r-1)M + A_mean.

r=1 时竞争项为零，无需定义 q。reciprocal 的凸性逐主题给 g(T)<=f_Q(T)，逐祖先项给 A_mean<=A_Q。于是

    O <= (k+r-1)t_Q + A_Q.                         (ANCHOR)

**查询独立性承重。** 证明经过期望负载与平均边际，不能直接在同一随机元组 Q 中抽取竞争主题作查询，再称该相关查询由 t_Q 控制。

空背景 A_Q=0 时，极小化 Q 恢复既有 O<=(k+r-1)v_r(0)。因此本式是背景记账接口，不是新的安全值桥。

## 2. 同一真实终局删除背景支付祖先储备

固定一个 active 真实终局 S_1,...,S_r，客户 active 负载为 n_x；祖先实际总利润为

    B_actual = sum_(x:b_x>0) b_x/(b_x+n_x).

取任一 j，从这一**同一终局**删除 active 行动 S_j，并以其余 r-1 个 active 行动作为 Q_j。逐客户

    1+b_x+n_x-1_(x in S_j) >= b_x+n_x,

故

    A_(Q_j) <= B_actual.                            (RESERVE)

任何固定概率混合这些 Q_j 也保持此界。此处没有将一个离轨祖先利润替换为原路径利润；所比的是同一终局删除一个 active 行动后多加一份独立查询负载。b_x>0 保证右端分母正；b_x=0 项均为零。

若 k=m、r=m-1、前缀恰一个 sunk root A，则 (ANCHOR) 是 O<=2r t_Q+A_Q。由于 W=V_active+B_actual，若另证 2r t_Q+A_Q<=2W，便得到 root-only half。该查询支付并不自动由 (RESERVE) 得到。

## 3. 实际删除背景的弱总预算已失败

现在否定精确候选：对每个 sunk-root、余 r=m-1 人的完整子 SPE，从实际 active 终局删除一个行动得到的背景之任意自由混合中，总能找到

    J_actual := min_lambda [(m+r-1)t_(Q_lambda)+A_(Q_lambda)]
                 <= 2W.                            (AD-CAP)

只需复用 current/continuation_lemmas.md 的十四客户残余例，加一个空主题、加一个首位任意选择空主题的 sunk 玩家。不是扩展旧参数族来优化常数。

共同目录 A,B,T,D,E,empty。客户类型及重数为

| 类型 | 重数 |
|---|---:|
| B | 3 |
| T | 3 |
| AD | 2 |
| AE | 2 |
| BDE | 2 |
| TDE | 2 |

总人数 m=3。根指定 empty；在其孩子中，两名 active 玩家采用既有两人完整 SPE：当前选 A，末位对 A,B,T,D,E 分别回复 B,D,D,E,D；对当前 empty 回复 D。当前的六个真实完成收益分别为 4,4,4,4,4,0，末位回复均为最佳回复。其余根动作后，各子树独立选完整两人 BI SPE。这样全部正深度历史均为 SPE；根没有要求最优，且其实际收益 0，明确不是完整根 SPE。

实际叶 empty,A,B，收益 0,4,5，W=9。比较 A,B,T 已覆盖全部十四客户，所以 OPT_3=14<18。没有 half 反例。

两个实际 active 删除背景及全部查询值为

| 背景 | A | B | T | D | E | empty |
|---|---:|---:|---:|---:|---:|---:|
| empty,B | 4 | 5/2 | 5 | 5 | 5 | 0 |
| empty,A | 2 | 5 | 5 | 5 | 5 | 0 |

纯查询 T 在每列均得 5，所有格均至多 5。因此任意混合的最大查询值恰为 5；祖先 empty 的储备恒为零，

    J_actual = (3+2-1)*5 = 20 > 18 = 2W.

这是自由混合的精确下界与上界，不仅是均匀删除失败。

但是允许非实际背景 empty,D 时查询向量为 (3,4,4,3,4,0)，最大值为 4，预算只需 16<=18。D 正是原真实偏离 B/T 后出现的可信末回复。因此这个例子解释了应保留的动态信用：仅支付同叶祖先储备仍会丢失真实偏离惩罚主题。它不否定自由 Q 的锚定预算，也不否定 root-only half。

## 4. 计算、状态与后继义务

`audit_anchored_deletion_failure.py` 不导入规范模型、SPE 求解器或 LP，展开十四名不同单位客户，按 Fraction 核验全部42个正深度有序决策历史的252项含自身行动比较。它还枚举6^3个比较元组，核验 OPT_3=14、两删除列、非实际 D 列和根故意不最优。完整43节点策略保存在 `anchored_deletion_failure_exact.json`。

`anchored_deletion_probe.py/json` 是在已有19个实例上对716个根/一根前缀可实现终局进行的有限诊断；没有违反并不证明候选。该诊断没有主动加入允许的空主题及 sunk 空首位，恰未覆盖第3节的简单机制。保存这段失败过程用于避免把有限无反例误当支持。

后续全范围义务依旧是：使用同一完整策略的真实离轨后继，构造允许非实际主题的独立背景 Q，并支付查询项和**同一份 Q** 的祖先储备。自由 Q 版本在空背景特化为既有弱安全桥 W>=(m-1/2)v_m，而 sunk 空根特化为既有强聚合桥 W>=r v_r。它不是本轮已完成的新一般证明。停止扩展实际删除混合的同类扫描。
