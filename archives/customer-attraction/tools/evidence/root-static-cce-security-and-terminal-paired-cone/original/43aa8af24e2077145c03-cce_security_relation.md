# 聚合安全值与最低静态 CCE 福利：正确蕴含及严格间隙

身份：本轮辅助解析观察，未作独立审查；不解决 Q-CAG-HALF。
模型完整沿用 CAG-MODEL。n 是单位玩家数，目录有限共同。
这里 CCE 是静态同时行动博弈的 coarse correlated equilibrium，不是顺序 SPE。

## 1. 一般蕴含

任一静态 CCE 分布可先对玩家位置平均，仍是 CCE，福利不变。
对任一位置对称的 CCE Q，先抽 z∼Q，再独立均匀删除一个玩家位置 I，
得到 n−1 个主题的静态竞争分布 R。它不观察稍后查询的主题 a。
对所有合法 a，由 CCE 约束和位置对称性，

E_R f_R(a) = (1/n) E_Q Σ_i u_i(a,z_{−i}) ≤ E_Q W(z)/n.

有限静态 minimax 的对偶形式于是给

n v_n ≤ E_Q W(z).

取所有 CCE 福利的最小值得

**n v_n ≤ CCE_min。**

静态 CCE 存在，例如有限对称混合 Nash 存在，故最小值在紧多面体上达到。
因此候选桥 W_SPE≥CCE_min **蕴含** 强安全桥 W_SPE≥n v_n。
反向不由此成立，下一节有严格间隙。

## 2. 三个不交单客户主题：3 v_3=2，而 CCE_min=21/10

n=3，目录 A={x},B={y},C={z}。
均匀查询的最坏静态竞争组合是两个不同主题，查询期望
(1/2+1/2+1)/3=2/3；若两个竞争者同主题则为7/9。
对偶均匀抽三个不同主题对时，每一查询同样恰得2/3。
因此 v_3=2/3。

由于客户和主题完全对称，对 CCE 再平均主题标签置换不改福利和合法性。
只需记录三种负载型的混合概率：

| 负载型 | 福利 W | 一个固定行动的三位置总替换收益 H |
| --- | ---: | ---: |
| (3,0,0) | 1 | 7/3 |
| (2,1,0) | 2 | 19/9 |
| (1,1,1) | 3 | 2 |

这里 H=E[Σ_i u_i(a,z_{−i})]，标签平均后不依赖固定行动 a。
CCE 等价于 E(W−H)≥0。
逐型直接有

W − (9/10)(W−H) ≥ 21/10，

三型左端分别为11/5、21/10、21/10。
故每个 CCE 都有 E W≥21/10。
以概率9/10均匀抽(2,1,0)负载型，以概率1/10抽全异负载型，
则 E W=21/10且 E(W−H)=0，达到该下界。
所以 CCE_min=21/10>2=3v_3。

本例顺序 SPE 均依次选尚未覆盖的单客户主题，福利为3；
它仅区分两种候选桥的强弱，不是否定任何桥。

## 3. CCE 的逐客户负载核

对任一终局 z 和固定查询行动 a，客户 x∈a 的负载为 c。
在 Σ_i u_i(a,z_{−i}) 中：

- 若 c=0，全部 n 个替换查询都获得该客户，系数为 n；
- 若 c>0，c 个删除覆盖者的位置各贡献1/c，其余 n−c 个位置各贡献1/(c+1)，
  总系数为 1+(n−c)/(c+1)=(n+1)/(c+1)。

故可定义 h_n(0)=n、h_n(c>0)=(n+1)/(c+1)，并写

Σ_i u_i(a,z_{−i})=Σ_{x∈a}h_n(c_x(z)).

安全对偶允许任意(n−1)主题背景分布；CCE 给出的背景分布还必须由
一个 n 元对称分布“均匀删一位”产生。这个删除一致性是额外条件，
不能把任意安全对偶背景直接声明为 CCE。
