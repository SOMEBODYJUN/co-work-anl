## 1. 冻结 53 行不能原封不动施于五人后缀

设额外前置玩家选主题 (B_0)，令其客户会员位为 (b_x\in\{0,1\})。后面五人固定图仍记 `ABCDEUVWXY`；同一五人终局活跃负载为 (c_x)。这些玩家的物理收益份额为

\[
 u_{i,x}^{(b)}=\frac{\mathbf1_{S_i}(x)}{b_x+c_x}.
\]

取只有一个客户 (x\in B_0) 且目录只有唯一主题 (B_0=\{x\}) 的六人实例。全部真实与离轨主题都等于 (B_0)，完整纯 SPE 唯一；每人物理收益为 (1/6)。冻结活跃行 `actual:5:K:U` 若仍用原来五人分母，得到

\[
 u_5^{(b)}-\frac{\mathbf1_U}{p_5+1}
 =\frac16-\frac15=-\frac1{30}<0.
\]

此处 (p_5=4)。合法背景版本必须把分母改成 (b+p_5+1=6)。

冻结活跃容量行 `MAXROOT-NEW` 同样失效：在此实例 (K=O_5=1)，故

\[
46313177u_1^{(b)}-7412362K-10^6O_5
=\frac{46313177}{6}-7412362-10^6
=-\frac{4160995}{6}<0.
\]

即便主节点 IC 都改对分母，仍不能继续使用原容量投影表。原精确最大根关系的背景缺口也非舍入伪影：若

\[
B=\frac{94866177440}{2048362573},\quad
C=\frac{60732827017}{8193450292},
\]

则 (Bu_1^{(b)}-CK=7533873829/24580350876<1)，亏损为
(17046477047/24580350876\approx0.6935001511)。因此，若坚持该冻结的 (B,C)，单一全背景类型就要求至少这一大小的逐背景客户附加信用。

这些是原行使用范围的反证，不否定把全部局部原始乘子带入新背景类型域后重新消元的路线。

## 2. 哪些基础接口可精确带背景

固定同一完整六人策略，先固定前置主题 (B_0)。五人后缀的每个真实节点及每个强制偏离后继仍按原策略定义；不能将不同背景或不同分支的收益识别。

- 真节点安全分母：若后缀当前位置之后共 (k) 人，后缀既有负载 (p_x)，则
  \(v\ge\sum_{x\in Q}1/(b_x+p_x+k)\)。
- 实际末位共同定价：若后缀前四主题负载为 \(\ell_x\)，则每个合法目录主题 \(Q\) 都满足
  \(\sum_{x\in Q}1/(b_x+\ell_x+1)\le u_5^{(b)}\)。
- `PAIR` 引理逐字成立，只需用总背景 \(b_x+p_x\) 定义
  \(f(Q)=\sum_{x\in Q}1/(b_x+p_x+1)\) 和
  \(g(Q,R)=\sum_{x\in Q\cap R}1/((b_x+p_x+1)(b_x+p_x+2))\)。
- 所有真实偏离 IC 与共同 \(K\) 容量仍有效。

原证明的菜单数五来自比较索引数，而非剩余玩家数。如果检验六主题比较元组，菜单和直方图计数也必须改成六；不能只改物理分母。比如原 `O-floor` 在 (m) 个比较主题时成为

\[
 m u_{last}^{(b)}+\sum_x\frac{b_x+p_x}{b_x+p_x+1}-O_m\ge0.
\]

理由仍是 \(d/(b+p+1)+(b+p)/(b+p+1)\ge\mathbf1_{d>0}\)。这是有效但未必最强的逐类型信用。

## 3. 一条可直接使用的背景局部投影

原证明 (4.2) 的全部非负原始乘子在背景版仍合法。设被强制的后缀第三人之前活跃负载为 (p\in\{0,1,2\})，实际末位之前活跃负载为 \(\ell\in\{0,\ldots,4\}\)，查询主题会员位为 \(t,q\)。同一原策略强制 (T) 后真实末两回复会员位为 (f,g\)。令零分子份额取零，并定义

\[
\psi_b(p,\ell,t,q)=\min_{f,g\in\{0,1\}}
\left[
\frac{t}{b+p+t+f+g}+\frac g{20}
+\frac{f/8+g/5}{b+\ell+1}
-\frac14\left(
\frac g{b+p+t+f+g}-\frac q{b+p+t+f+1}
\right)
\right].
\]

则精确有效的背景版为

\[
 r^{(b)}+\frac{13}{40}u_5^{(b)}+\frac1{20}K
 \ge\sum_x\psi_{b_x}(p_x,\ell_x,t_x,q_x).
\]

证明完全复用原来的五个非负 slack：源节点偏离、(K-|G|)、实际末位查询 (F,G)、偏离枝真实末位查询 (Q)，乘子仍为 (1,1/20,1/8,1/5,1/4)。只把所有收益与价格分母中的外部背景位保留。

有限精确枚举给出

\[
\max_{p=0,1,2;\,\ell=0,\ldots,4;\,t,q\in\{0,1\}}
\bigl[\psi_0(p,\ell,t,q)-\psi_1(p,\ell,t,q)\bigr]=\frac14.
\]

在 ((p,\ell,t,q)=(0,0,1,1)) 取等，
\(\psi_0=17/24,\ \psi_1=11/24\)。所以一个不用重排主类型域、但可能较弱的合法修补为

\[
 r^{(b)}+\frac{13}{40}u_5^{(b)}+\frac1{20}K+\frac14|B_0|
 \ge\sum_x\psi_0(p_x,\ell_x,t_x,q_x).
\]

这只证明该局部行的背景修补；没有给其余投影或整个 53 行同样的 (1/4) 成本。

复现该常数：

```python
from fractions import Fraction as F
from itertools import product

def q(n,d): return F(n,d) if n else F(0)
def psi(b,p,l,t,z):
    return min(q(t,b+p+t+f+g)+F(g,20)
        +(F(f,8)+F(g,5))/F(b+l+1)
        -F(1,4)*(q(g,b+p+t+f+g)-q(z,b+p+t+f+1))
        for f,g in product((0,1),repeat=2))
a=max((psi(0,p,l,t,z)-psi(1,p,l,t,z),p,l,t,z)
    for p,l,t,z in product(range(3),range(5),range(2),range(2)))
assert a == (F(1,4),0,0,1,1)
```

## 4. 后缀总利润不能充当六人福利

设真实五人后缀活跃负载为 (c_x)，其总利润记 (P)，前置玩家最终利润记 (u_0)。精确恒等式是

\[
P=|\{x\notin B_0:c_x>0\}|
  +\sum_{x\in B_0}\frac{c_x}{1+c_x},\qquad
u_0=\sum_{x\in B_0}\frac1{1+c_x},\qquad
W=P+u_0.
\]

因此既不能把 (P) 当作新增覆盖，也不能在目标中删掉 (u_0)。

完整六人 SPE 的精确障碍：目录由六客户主题 (B_0) 与五个互不相交且位于 (B_0) 外的单客户主题组成。在每个完整有序历史上都规定所有剩余人选 (B_0)。这是完整纯 SPE：当前选 (B_0) 的最终收益为
(6/(\text{此前选 }B_0\text{ 的人数}+\text{剩余人数})\ge1)，而选任一单客户主题所得至多 (1)。该论证包括所有离轨历史和任意已选主题重复。

实际六人全选 (B_0)，故 (W=6,\ OPT_6=11,\ P=5,\ u_0=1)。于是

\[
2P=10<11=OPT_6,\qquad 2W=12\ge11.
\]

这严格排除“背景五人后缀总利润满足 (2P\ge OPT_6)”这一可能的错误 lift，即使前置玩家也是真正根最优者。更一般 (n) 客户大主题加 (n-1) 外部单客户主题，所有历史都选大主题，给完整 SPE 比率 (n/(2n-1)\to1/2\)。它不反驳一般 half，且表明若一般 half 成立，其常数不能统一改进。
