# 完整历史 SPE 的目标索引证书 DAG 与联合重数 MILP（研究候选）

目标仍是 Q-CAG-HALF：共同有限目录、单位客户均分、任意人数、每个完整历史依赖纯 SPE 的终局是否有 `2W >= OPT_m`。本目录没有该目标的证明或真正反例。只保存一个有限规模的搜索实现与精确等价性论证，尚待独立审查。

## 与已有资产的关系

- `research/current/customer_attraction/exact_solver.md` 已经证明按计数缓存**终局全集**不限制完整历史量词。本算法直接使用其极小可信续局原理，没有新增一个福利定理。
- `research/current/customer_attraction/credible_continuations.md` §3 和 `tests/audits/cone_attack_joint_milp.py` 已有联合客户重数与全部有序历史动作的正确 MILP；本目录不主张“首次联合 MILP”。
- 本实现的变化是把联合模型的证书节点从有序历史 `h` 改成 **`(前缀计数 k, 请求终局 q)`**，每对可以选不同动作，并共享每个 `(k,b)` 的一个可信惩罚目标。它覆盖全部可实现**终局和客户重数**，不枚举或保存每棵完整策略。
- `research/workspaces/customer-attraction/R-c4732bee2f7b4e50a70568170e3334ae/credible_search/markov_joint.py` 是每个计数 `k` 只选一个动作的受限候选器。本实现允许同一 `k` 的不同 `q` 选择不同动作，展开后可能有同计数不同动作的历史；没有 count-Markov 限制。
- 固定 `(m,p)=(5,7)` 时原有全历史编码有 `2p*(1+p+...+p^4)+127=39341` 个变量、19607 个二元变量和约394949行；当前目标 DAG 有32307个变量、31850个二元变量、约7.35万行。这里主要减少约束和连续变量，**二元变量反而更多**；没有声称普遍更快。更大 `m` 时两个表示各有不同组合规模。

## 变量及严格约束

固定人数 `m>=1`、主题标签数 `p>=1`、根目标终局计数 `q0`（总和为 `m`）及比较主题集 `J`。非空客户类型 `B⊆[p]` 的重数为 `r_B>=0`，先允许实数；若最后恢复有理点，再缩放为单位客户整数 clones。覆盖根目标的类型归一化为

`W(q0)=sum_{B:B·q0>0} r_B=1`。

记 `F_a(q)r=sum_{B∋a}r_B/(B·q)`，只在 `q_a>0` 时使用。`k` 是总和小于 `m` 的前缀计数，`q>=k` 是总和 `m` 的终局计数。令 `rrem=m-|k|`。

1. `y[k,q,a]∈{0,1}`，仅对 `q_a>k_a` 定义；`A[k,q]=sum_a y[k,q,a]<=1`。`A=1` 表示需要一份在计数 `k` 的子博弈实现终局 `q` 的证书，选中的 `a` 为其当前动作。
2. 非末层每个 `(k,b)` 有 `x[k,b,d]∈{0,1}`，`d>=k+e_b`、`|d|=m`，且 `sum_d x[k,b,d]=1`。它选一份偏离动作 `b` 后的可信惩罚子 SPE 终局。
3. 每个 `k` 有阈值 `0<=T[k]<=m`。

约束为：

- `A[0,q0]=1`；其他根目标的 `y=0`。
- 若 `|k|+1<m`，则 `y[k,q,a] <= A[k+e_a,q]`。
- `F_a(q)r >= T[k]-m*(1-y[k,q,a])`。
- 非末层：`x[k,b,d] <= A[k+e_b,d]`，且 `T[k]>=F_b(d)r-m*(1-x[k,b,d])`。
- 末层：`T[k]>=F_b(k+e_b)r` 对每个 `b` 成立；该子终局唯一，不需要 `x`。
- 根有效界 `s_a:=sum_{B∋a}r_B<=m` 对每个 `a` 成立。

目标为最大化 `sum_{B:B∩J非空}r_B`。可选 `--minimum 2.00001` 只搜索超过给定严格阈值的候选；浮点 `0.00001` 不是精确性证书。

可选 `--first-action a` 固定根所选动作，且加合法强化 `s_b<=m*F_a(q0)r`。不固定时根会在所有 `q0_a>0` 的动作中选择，不要求某个有序在轨路径。

实现还加了一组冗余而合法的松弛强化：

`T[k] >= sum_{B∋b} r_B/(B·k+rrem)`。

因为从 `k` 选择 `b` 后，在每种包含 `b` 的客户上，最终覆盖人数最多为 `B·k+rrem`，故任何真实续局的该动作收益均至少为右端。末层此式恰好就是唯一终局收益。

## big-M 为什么恰可取 m

任意根 SPE 的首位提供者偏离主题 `a`，至少可得 `s_a/m`，因为其覆盖客户最多与全部 `m` 名提供者均分。根实际收益不超过已归一化的福利一，因此 `s_a<=m`。该界适用于任何目标可实现的 SPE，加入模型不丢失目标终局。

模型直接施加 `s_a<=m` 后，每个被评价的 `F_a(q)r` 都在 `[0,m]`，每个 `r_B<=m`，总重数也有 `sum_Br_B<=sum_as_a<=mp`。阈值可以取所选惩罚收益的最大值，亦在 `[0,m]`。

因此未选中的 `y=0` 给出的 `F_a(q)r>=T[k]-m` 自动成立；未选中的 `x=0` 给出的 `T[k]>=F_b(d)r-m` 自动成立。没有凭经验选取大常数，也没有依赖浮点容差来论证界。

## 双向等价性：覆盖终局，不要求覆盖全部策略

**可行整数指示解 ⇒ 完整历史纯 SPE。** 从根目标 `(0,q0)` 开始递归。若节点的目标为 `(k,q)`，`A[k,q]=1`，其唯一 `y=1` 给动作 `a`。选中分支继续请求 `(k+e_a,q)`；每个其他动作 `b` 的分支继续请求 `x[k,b,d]=1` 的 `(k+e_b,d)`。依赖约束保证这些请求有证书，人数深度严格增加，故最终到达请求终局。全部子树都在完整有序历史键 `h` 下独立展开，实际选中收益为 `F_a(q)r>=T[k]`，每个真实偏离收益至多 `T[k]`。由剩余人数逆向归纳，每个历史的策略均是 SPE。末层情形由直接收益比较成立。根终局为 `q0`。

**某完整历史纯 SPE 实现 q0 ⇒ 存在模型解。** 对给定重数 `r`，令 `R(k)` 为已知规范递推返回的全部子 SPE 终局。对每个 `(k,b)`，选 `d[k,b]` 在 `R(k+e_b)` 中最小化 `F_b(d)r`，令对应 `x=1`，设 `T[k]=max_b F_b(d[k,b])r`。对每个 `q∈R(k)`，规范递推保证存在动作 `a`，使 `q∈R(k+e_a)` 且 `F_a(q)r>=T[k]`；只为该对选一个这样的 `y=1`。其余目标对取零。根只保留 `q0` 的证书即可。所有依赖约束及收益比较同时成立；big-M 界已经证明。

因此，同一 `k` 上共享 `d[k,b]` 不丢失任何可实现根终局：取**全部**子 SPE 集合里的真正最小值即可。但这种共享会丢掉某些非极小离轨完整策略，故本算法**不是完整策略图枚举器**。这里的等价性是每个 `r,q0` 是否可由某个任意完整历史策略实现；这已经足以联合搜索目标福利反例。

## 组合规模

令 `N=sum_{t=0}^{m-1} C(t+p-1,p-1)=C(m+p-1,p)`。

- `T` 有 `N` 个。
- `y` 的个数为 `p*C(m+2p-2,2p-1)`。
- `x` 的个数为 `p*C(m+2p-2,2p-1)-p*C(m+p-2,p-1)`，最后一项是省去的末层唯一目标。
- 请求目标对的个数为 `C(m+2p-1,2p-1)-C(m+p-1,p-1)`。

这些是有限接口的规模，没有输入位长多项式或任意规模可运行承诺。

## 数值候选如何成为精确证书

`full_history_milp.py` 使用 SciPy/HiGHS，仅将浮点 MILP 当候选动作生成器。若有整数指示候选：

1. 用上述目标请求递归生成所有 `sum_{t=0}^{m-1}p^t` 个**有序历史**上的动作。
2. 调用既有 `StrategyCone.optimize(J)`，从该完整策略的全部真实偏离约束重新做 LP；用 `Fraction` 或精确活跃行恢复归一化重数，并逐条检查。浮点 MILP 给出的重数不会直接被接受。
3. 有理重数缩放为非负整数 clones，调用规范 `verify_certificate` 从完整策略和单位客户定义再次核验。
4. 重新枚举最优主题组合，计算精确整数 `W,OPT`。只有 `OPT>2W` 才超过二。
5. 另外检测所有主题覆盖子集是否两两不同。优化使用可区分标签合同；若出现重复覆盖标签，仍保留合法的标签游戏证书，但**不会直接称作原集合目录模型的真正反例**，需要另做合法去重处理。

浮点 MILP 的“不可行”、上界、最优状态或超时均不作为数学结论。恢复失败只报告失败；没有候选时不构造证书。
