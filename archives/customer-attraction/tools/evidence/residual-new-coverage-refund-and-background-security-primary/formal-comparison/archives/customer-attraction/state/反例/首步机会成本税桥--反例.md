# 首步机会成本税桥

采用[固定背景收益与税的定义](../定义/固定背景剩余收益与税--定义.md)。被否定的是对所有合法背景、剩余人数及完整纯 SPE 的首步式

\[
F_k(b)\le u_{\rm first}+\tau_b(\mathbf1_A)+F_{k-1}(b+\mathbf1_A).
\tag{Bridge}
\]

这里只需在合法空前缀、\(k=3\) 给出一个完整反例。

## 输入与全部历史的策略

共同目录为 \(A,B,C,D\)，客户恰属于表中所列主题。每个重数表示不同的单位客户，没有加权客户或异构目录。

| 兴趣集合 | 数量 |
|---|---:|
| A | 2 |
| AB | 3 |
| C | 2 |
| BC | 3 |
| D | 2 |
| BD | 3 |

三叶 \(A,C,D\) 两两不交，各有两名私有客户和三名与中心 \(B\) 共有的客户；\(|B|=9\)，每叶大小五，总客户十五。

**每位提供者在每个完整有序历史恒选 \(B\)。** 这定义全部 \(1+4+16=21\) 个决策节点，而不只指定路径 \(BBB\)。实际每人收益三、福利九。

## 完整 SPE 的直接证明

固定任意另外两人的主题，比较当前人选 \(B\) 与任一叶 \(L\)。三名 \(B\cap L\) 客户在两种选择下都有当前人覆盖，且其他两人的覆盖不变，故它们的收益项相同。选 \(B\) 额外得到另外两叶各三名共有客户，每组的总贡献至少 \(3/3=1\)；选 \(L\) 额外得到其两名私有客户，总贡献至多二。因此

\[
u(B,s_{-i})-u(L,s_{-i})\ge1+1-2=0.
\]

于是 \(B\) 对任意两人的固定行动均弱占优。在所展示的完整策略里，当前人偏离后，后继仍按同一策略恒选 \(B\)，正适用这个比较；全部离轨节点也一样。故每个子博弈无盈利偏离。这里利用的是这个实例的特殊弱占优结构，没有把一般 SPE 等同静态 PNE。

## 最优值与严格违背量

空背景的 \(F_1(0)=9\)、\(F_2(0)=11\)、\(F_3(0)=15\)：一个中心覆盖九；中心加一叶覆盖十一，两叶只覆盖十；三叶覆盖全部十五。

实际首动作为 \(B\)。固定背景 \(b=\mathbf1_B\)，剩余两人的比较组合穷尽如下四类：

| 组合类型 | \(R_{\mathbf1_B}\) |
|---|---:|
| 两中心 | \(9\cdot2/3=6\) |
| 中心与一叶 | \(3\cdot2/3+6\cdot1/2+2=7\) |
| 同一叶两次 | \(3\cdot2/3+2=4\) |
| 不同两叶 | \(2(3/2+2)=7\) |

所以 \(F_2(\mathbf1_B)=7\)。背景 \(2\mathbf1_B\) 时，选中心得三，选任一叶也得 \(2+3/3=3\)，故 \(F_1(2\mathbf1_B)=3\)。首步税为 \(\tau_0(\mathbf1_B)=9/2\)。Bridge 的两端因而是

\[
15>3+9/2+7=29/2,
\]

严格差 \(1/2\)。只修补非零背景的论证无法排除此空背景失败。

## 为什么整条根税和主目标没有被本例否定

实际前两步总税为 \(\tau_0(2\mathbf1_B)=9(1-1/3)=6\)，故
\(F_3(0)=15=W+6\) 恰等。后两人的已证两人税式也恰等：

\[
F_2(\mathbf1_B)=7=3+3+9(1/2-1/3).
\]

子局最优七比实际后两人利润六高一，但余下税为 \(3/2\)；将整预算强行按 Bridge 分配，首步少掉 \(1/2\)。望远镜恒等式正确仍不能消除这个机会成本缺口。

本例 \(\operatorname{OPT}_3/W=5/3\)，\(2W=18\ge15\)。后续[四人根税反例](四人实际根总税--反例.md)才另行否定实际根总税；不能把二者身份合并。这里不声称十五客户具有最小性，也不否定一般或六人半覆盖。
