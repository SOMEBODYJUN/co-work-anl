# 末两负载支配安全值定理的独立审查

审查对象：同工作区 security/terminal_pair_load_security.md，2026-10-21 版本。审查者先独立重构主要代数，再读取原稿及其依赖 last_two_floor.md。范围是解析审查；未声称外审、新颖性或一般主目标解决。

结论：原稿 (H)→(T) 推导和第3节等价条件成立，未见未消除致命异议。

1. 真实早期利润确实为 P=Σ_{c_x>0}p_x/c_x；这是同一终局的单位均分恒等式，没有删除旧玩家，也没有调用离轨旧玩家收入比较。H逐项除以正分母给 P≥αu_A+βu_B。
2. 在同一真实早期有序前缀 h 后，末两人各至少 θ(h)。独立重构如下：令 f_h(T)=Σ_{x∈T}1/(p_x+1)，选最大化 f_h 的 A'。任意原策略在 hA' 后的真实末位最佳回复 B' 满足 U_h(A',B')−U_h(B',A')=f_h(A')−f_h(B')≥0，故偏离者收益≥θ(h)。倒二真实最优性把该保证传给实际收益，末位保底则由 θ(h) 的定义直接给出。全部历史依赖平局都保留。
3. θ(h)≥θ_m，因为 h后再接一个主题只是全部合法 m−1前缀的一部分。θ_m≥v_m 是纯最小最大≥混合最大最小；v_m≥OPT_m/(2m−1) 是已有独立安全值定理。因此 W≥mθ(h)≥mOPT_m/(2m−1)，没有使用开放的一般聚合安全值桥。
4. H在 A∩B 上等价于 p_x=m−2，在 A\B、B\A 上分别给 α≤L_A、β≤L_B。空差集取 L=m−2 合法，因为总和条件本身给每个变量≤m−2。存在非负 α+β=m−2 恰等价于 L_A+L_B≥m−2。
5. 第4节余项 R 的恒等式正确，但其条件确实被 α=β=0 的早期利润判据支配；原稿已明确这一点，因此未夸大为额外一般机制。
6. m=2、A=B、空主题、重复主题、零客户均不破坏公式。若实际 tail 主题为空，其收益0与末两保底迫使θ(h)=0。任何非空目录主题在有限背景/有限后继负载上均有严格正收益，因此θ(h)=0只可能全部目录主题为空。
