## 已核对的推进与当前缺口

末两主题记 `A,B`、早期负载 `p_x`。若存在 `alpha,beta>=0`、
`alpha+beta=m-2`，逐客户有 `p_x>=alpha*1_A(x)+beta*1_B(x)`，
则早期利润和至少为 `alpha*u_A+beta*u_B`。
末两人各至少为同前缀的最坏末位最佳回复值 `theta(P)`，故
`W>=m*theta(P)`，进而 `OPT_m<=(2-1/m)W`。
作者与主代理已独立检查关键代数；完整正文及审查将沿对应目录保存。
这是条件类结果，一般路径不满足该支配条件，不能删除它。

一个已即时排除的错误加强：把“例外主题不包含A”误当成“每个A客户均未被该主题覆盖”。
因此不能按例外主题的序号把所有A客户的偏离分母统一改成 `m-e`；
合法分母应逐客户记录此前真正遗漏次数。此纠正未用于上述负载支配证明。
