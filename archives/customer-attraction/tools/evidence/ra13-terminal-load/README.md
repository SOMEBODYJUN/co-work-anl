[mathematical-self-review.json](mathematical-self-review.json)记录实际数学自查和局限；[verify_package.py](verify_package.py)与[publication-check.json](publication-check.json)只查来源字节、依赖SHA、字段、归属和本地链接。字段通过不代替数学理解或证明。
