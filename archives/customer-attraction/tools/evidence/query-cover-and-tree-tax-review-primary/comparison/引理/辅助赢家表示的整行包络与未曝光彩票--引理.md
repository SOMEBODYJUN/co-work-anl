# 固定原策略，随机化只作不可见的付款耦合

有限单位客户、有限非空共同目录、m名单位玩家、全部有序历史纯SPE σ。actual z、利润u_i，actual前缀h_i后强制A的真完成叶y_(i,A)=finish_σ(h_i,A)。原IC给D_i(A)=u_i(y_(i,A))≤u_i。辅助彩票不会被原玩家观察，也不改变σ的纯策略或真实续局。

均匀玩家排列π下，把固定叶y的每客户归其覆盖者中priority最早者，记i获客户数V_i(y;π)。每覆盖者对该客户获胜概率1/c_y(x)，故E V_i(y)=u_i(y)。空客户无获胜/无分母。所有叶使用同一π是一种耦合；以下ENV只需每个固定叶的边际正确，不限制不同叶/客户怎样相关。概率空间和系数取有限且非负，所有期望/协方差有定义。

记G_(i,A)(ω)=V_i(z;ω)−V_i(y_(i,A);ω)，E G=Γ_(i,A)=u_i−D_i(A)≥0。系数依当前winner时，E[λG]不等于(Eλ)Γ；这个条件化债和整个完整u_i钱包能否支付不同。

# 确定整行包络：不用条件IC非负

任意随机λ_(i,A)(ω)≥0，若有确定c_(i,A)≥0使每ω λ≤c，则winner收入非负，逐点支配后取期望得

\[
 \boxed{\mathbb E\sum_A\lambda_{i,A}V_i(y_{i,A})
 \le\sum_Ac_{i,A}D_i(A)\le u_i\sum_Ac_{i,A}.}\tag{ENV}
\]

Σ_Ac≤1足够付一份u_i；更细地只需Σ_AcD_i(A)≤u_i。它们是充分条件，不宣称所有可付路线必须满足此包络。单固定查询A且0≤λ≤1已可用完整u_i，即便EλG<0；失败的可只是按Eλ缩小后的钱包。

对来源客户系数q_(i,A,x)(ω)各不同，x∈A上若0≤q≤c，先求赢家指示的非负支配再合整行，

\[
 \mathbb E\sum_{A,x}q_{i,A,x}1\{i\text{在}y_{i,A}\text{赢得}x\}
 \le\sum_Ac_{i,A}D_i(A).\tag{ENV-SOURCE}
\]

这在原整行IC前已汇总客户，未按客户权重调用IC。只有每状态Σ_Aλ_A≤1不等于Σ_A sup_ωλ_A≤1，前者在依当前priority选查询时不足，精确反例见[两诊断](../反例/优先权条件化与自适应查询的两项付款失败--反例.md)。原稿没证明自然priority路线会供应兼容c。

# 每角色一份未曝光彩票：predictable系数保原IC

预先独立抽π_1,…,π_m，**同角色全部查询共享π_i**。处理i之前只曝光较早角色的彩票，系数λ_(i,A)在此过去信息\mathcal F_<i可测，当前π_i未曝光且独立。固定叶winner边际于是给

\[
 \mathbb E[\sum_A\lambda_{i,A}G_{i,A}(\pi_i)\mid\mathcal F_{<i}]
 =\sum_A\lambda_{i,A}\Gamma_{i,A}\ge0.\tag{FRESH}
\]

若另有Σ_Aλ_(i,A)≤1，该条件下也直接得E[ΣλV_i(y;π_i)|过去]=ΣλD_i(A)≤u_i。但FRESH不构造这个row预算；多个来源/context仍可使同一角色总质量过大。第二诊断选行已看当前priority，不满足FRESH前提，不能拿它否这个未曝光合同。

missed source x∈R=O∖C的actual过去无人覆盖。当前查询含x时，若winner不是当前i，只能是未来j>i；在j的actual前缀以旧真实叶中winner所选合法主题再查询，角色严格递增，至多m步终止。固定同一globalπ还使每次handoff winner rank严格提前；FRESH不用同一globalrank，角色递增已够。单客户路径终止不合并多客户的不同查询，也不给同role多context一份新钱包。

当前彩票未曝光时取winner条件均值，是各查询真实coverer上的均匀capture核，回到旧increasing-role capture；不能把“新彩票”认作新来源保持或容量。换为每context再领一份彩票/利润，亦不解决整role共同预算。

# 客户独立彩票：精确定位R债，不支付它

每客户独立抽玩家排列π_x，在该客户所有叶保持其同一排列。令λ仅依R客户彩票；所有非R客户彩票（特别actual C）未用于决定λ。因此其winner变量与λ独立，actual对R赢家贡献为0。对固定i,A，展开协方差得

\[
 \boxed{\mathbb E[\lambda G_{i,A}]
 =(\mathbb E\lambda)\Gamma_{i,A}
 -\sum_{x\in A\cap R}\operatorname{Cov}
 (\lambda,1\{i\text{在}y_{i,A}\text{赢得}x\}).}\tag{COV-R}
\]

非R部分协方差为0；R部分G为负的偏离赢家指示。协方差不必统一非负，公式只定位可能放大的债，未给所需正协方差总额上界。共用一个global玩家排列通常不具这种客户独立性。丢掉协方差仍非法；恢复均匀未曝光抽样又回FRESH/旧核。

# 与half接续的严格条件，尚无构造

O为最优覆盖，C为actual覆盖，r=|O∖C|、e=|C∖O|，OPT=W+r−e。r≤e时OPT≤W已成立。否则若能对一次共同最优owner、取消e份遗漏来源后的r−e质量，构造守恒吸收流，使其收入恰为ENV-SOURCE左侧且每actual role有同一确定包络Σ_Ac_(i,A)≤1，则r−e≤Σu_i=W，得到half。

条件包括owner、取消、来源可生成性、守恒、winner耦合、同role全部query兼容包络；本源没有同时构造。它是旧整行钱包的真实接点，不是新增已经付清的覆盖分解。若走COV-R，正协方差与偏离叶old-C收入、未用actual行容量及e信用还须共同结算，不能换词抹债。

一般式在m5仍缺五组兼容包络，m6亦然。当前five别证不自动证明这个特定更强流程；没有新扫描/数值系数或无条件福利界。
