## 已发生且仅发生的两个数学事件

1. observe_original.py 的实际版本在隔离目录，用原 935 B portfolio_matching_failure 实例，规范 worst_certificate 一次，再调用未改 optimize 一次。21 个计数态、六动作策略、原 29×32 LP 一次；原 main 0、其余十八历史锥 0、随机主循环 0。sys.setprofile 只被动捕获。replay/ 保存完整策略、原结果、原局部变量、LP 参数与 OptimizeResult、solver 状态和实际执行日志。原件/四依赖/输入前后 SHA 不变。
2. audit_small_cone_exact.py 的实际版本独立从六动作与原单位客户定义构造全部 29×32 有理矩阵，目标/归一/右端共 1022 标量精确匹配；对已有求解器原始和对偶限分母恢复后逐行有理认证。另直接核原86客户与新mask14一客户各24项IC。原程序导入0、规范solver0、LP0。exact/保存一次事件、全部矩阵、原对偶、余量与48项比较。

原函数输出与 known 最后一条的六个共享字段相同，但旧报告无完整 σ，故不冒称旧全策略/历史driver重演；当前新策略实际(2,1)，与同实例另一份旧证书(4,0)区分。

该固定锥精确最大 ε=−1/2。对偶只用背景(1)、(2)包络，权2/3、1/3，给 3W/2−(2E(1)/3+E(2)/3)=一半“含标签1、不含标签2”客户质量。新原始点 mask14 权1达到。其余18历史条目不因此获得精确最优认证。

任意完整策略的全会员单客户都给可行 ε=−1/m，这仅为通用下界。原19条记录都回到该数值基线，不能倒置方向成一般上界。纯包络超2W即使存在，也不由OPT≤E*推出half反例，且与混合包络目标不同。

## 文件身份与复用

脚本保实际执行的原字节及当时 scratch 绝对路径。复现实验需另存修改路径的副本并记新事件；不修改本次脚本后仍称旧执行。replay/execution.json 是包装函数区间，replay/process-capture.json 是外层进程，精确事件也各保区间。没有性能最优性主张。

四个规范依赖、935 B 客户例与相关数学原件已在共享证据稳定保全，source-manifest.json 直接绑定其路径/SHA，不再复制大包。原运行目录的同字节源码/依赖副本不重复入库。source-to-object.json 逐源说明每个语义单元去向，comparison.json 保相关模型与旧缺文件时态。artifact-manifest.json 绑定本包与两正文；self_check.py 只静态校验字节、AST/JSON、已存事件结构、链接和回执，不调用数学入口。
