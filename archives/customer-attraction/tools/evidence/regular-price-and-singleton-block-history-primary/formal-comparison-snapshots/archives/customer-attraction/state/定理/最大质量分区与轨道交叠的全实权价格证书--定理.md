# 模型、价格和BPC-v2完整条件

有限单位客户N、有限非空真实集合目录𝒮，m≥1名单位提供者；固定任意终局S_1,…,S_m，允许实际重复。u_i=Σ_(x∈S_i)1/c_x，W=Σ_iu_i是终局覆盖。非负实主题权z只用于查询，不改变单位客户或玩家行动，
\[
\tau=\sum_Tz_T,\quad C(z)=\sum_x\min(1,\sum_{T\ni x}z_T),\quad
B(v)=\max_{z\ge0}\{C(z)-v\tau\}\quad(v\ge0).
\]
把任一坐标z_T>1截到1不变截断覆盖且不增非负成本，故有限紧盒内达到最大，v0也有效。不把任意查询归一化到质量一。

将N分成非空cells O（N空则单独W=OPT=0），固定一个实际provider i，定义p_O=|S_i∩O|/|O|。**最大质量MM**和**低交叠LO**为对每格
\[
|T\cap O|\le |S_i\cap O|\quad\forall T\in\mathcal S,\qquad
\sum_{j\ne i}|S_i\cap S_j\cap O|\le(m-1)p_O^2|O|.
\]
它们是此终局/此玩家的独立结构条件，不由SPE自动推出。重复实际主题可以存在，但每个重复玩家都在LO求和中另计一次。

在这些条件下，对每个有限非负实z，
\[
\boxed{C(z)\le(\tau+m-1)u_i,\qquad B(u_i)\le(m-1)u_i.}\tag{P}
\]
若i还为实际全局最小收益者，则
\[
B(\min_j u_j)\le W-u_i,\qquad
OPT_m\le(2m-1)u_i\le(2-1/m)W.
\]
最优m组合可重复，把每次出现置一单位查询质量，合并同主题后τ仍m、C为其真实并集。这里不假定i最后行动，也不需要SPE。

# 任意实τ的自足证明

记a=|S_i∩O|=p|O|、L_x为其它实际provider覆盖x的个数。p0时MM迫整格无目录覆盖，C_O=u_i(O)=0，不作除法。p>0时Cauchy–Schwarz及LO给
\[
u_i(O)=\sum_{x\in S_i\cap O}\frac1{1+L_x}
\ge\frac{a^2}{a+\sum_{j\ne i}|S_i\cap S_j\cap O|}
\ge\frac{|O|p}{1+(m-1)p}.
\]
令d_x=Σ_(T∋x)z_T。MM给Σ_(x∈O)d_x≤τp|O|；截断函数凹且非减，格内Jensen给C_O(z)≤|O|min(1,τp)。对p∈[0,1]、τ≥0，
\[
\min(1,\tau p)\le\frac{(\tau+m-1)p}{1+(m-1)p}.
\]
τp≤1时交叉相乘等价(m−1)τp≤m−1；τp≥1时等价1≤τp。两段均有效，m1也成立：右侧τp，饱和段一般是严格不等式，而非处处等号。原BPC稿关于m1“等号”的解释句过强，但其不等式和结论不受影响；例如p1、τ2给1<2。本页保正确标量论证，不把文字瑕疵报告为定理反例。

逐格相加即(P)第一式，减τu_i取最大得第二式。若i最小，W≥m u_i，故(m−1)u_i≤W−u_i；质量m的最优组合给其余结论。ui0时(P)直接迫C(z)=0，无需定义0/0福利比。

若有限关联保持群在q≥1个目录主题上传递，客户orbit O每人属于同样t_O个主题。双计数及主题传递性给|T∩O|=(t_O/q)|O|，与T无关。因此orbit-v1是MM取等号的特例，LO不变。原稿先将查询z按群平均：C凹且群不变，平均不降C，得到每主题τ/q和Σ_O|O|min(1,τp_O)。这是合法原证明；不能把平均查询误作平均实际终局或保持原收益的策略变换。

# 双块的逐orbit covariance与重复限制

两块X,Y各k≥2主题，关联在各块任意置换和交换下不变。实际m个主题全异，其中r个X、m−r个Y。固定X玩家且1≤r≤(m+1)/2。一个客户orbit由一块a个成员、另一块b个成员及a≠b时交换型组成；a=b不重复计orbit。t=a+b、p=t/(2k)，两个指定不同同块/跨块主题的共同会员概率分别
\[
\rho_s=\frac{a(a-1)+b(b-1)}{2k(k-1)},\qquad\rho_c=\frac{ab}{k^2}.
\]
有ρ_c≤p²，且
\[
\rho_s+\rho_c-2p^2=\frac{(a-b)^2-t(2k-t)}{4k^2(k-1)}\le0
\]
（a²≤ka、b²≤kb）。故
\[
(r-1)\rho_s+(m-r)\rho_c
=(r-1)(\rho_s+\rho_c)+(m-2r+1)\rho_c\le(m-1)p^2,
\]
乘|O|即LO。两系数非负是r门槛的承重点；严格minority以及等分时所有玩家均合格。

这不是所有最小收益者都合格：r>(m+1)/2时可取客户只喜整个一块的交换orbit，ρ_s1/2、ρ_c0、p1/2，LO就会失败。重复实际同主题的交集概率是p而非ρ_s，故此covariance推论只覆盖全异实际主题；一般MM/LO定理本身仍容许通过独立核验的重复。

# 仅一minority时的真正完整SPE推论

再假定m≥3、k≥m−1，任意定义于**全部有序历史**的纯SPE实际使用一个X主题和m−1个不同Y主题。minority收益记a，所有majority收益因终局对称同为b，W=a+(m−1)b。无需指定行动顺序或离轨平局，也不要求a≤b。

若a≤b，minority为合格最小者，由(P)得B(a)≤W−a。若b<a，最后两位至少一位majority：若末位属于Y，用真正末位端点B(b)≤W−b；否则倒二属于Y，用[真实克隆税端点](../引理/倒二克隆税的四类真实比较--引理.md)
\[
B(b)\le W-\kappa_m b,\qquad\kappa_m=(m+1)/[2(m-1)]>0.
\]
这些端点使用同一完整策略在真实偏离历史的回复，非终局静态NE。两种情况都给B(min(a,b))≤W，继而OPT_m≤W+m min(a,b)≤2W。minority首位时末位必majority，两分支还给B(min)≤W−min。

[末位/倒二全客户端点](../推论/真实末两人全客户分数价格端点--推论.md)和上述κ_m证明全文已比较。本推论可保有价格信息，尽管[双像几何](两块目录的双自同构像覆盖与支撑门槛--定理.md)早已不需SPE便证全异profile的half。不能把策略时间序任意重排来安置最小收益，[末两位正规化障碍](../障碍/最小收益移至末两位的福利代价--障碍.md)正排除无代价做法。
