# 直接遗漏查询覆盖：自由库存与最后价格义务

2026-10-23，Boss10/global。**一般候选，未证明；不是half结果。** 本稿脱离上一轮固定ghost恒等式及固定因果捕获链，直接面向任意人数、任意有限共同目录、全部有序历史纯SPE。它不以NET或WP成立为前提，没有固定人数/结构类正面结论或扩大数值扫描。

## 1. 每个位置只购买一份整行查询

固定原完整SPE \(\sigma\)、实际终局 \(Z\)、收益 \(u_i\)、实际覆盖 \(C\)。取任意一个最优 \(m\) 槽元组，联合为 \(O\)。记 \(R=O\setminus C\)、\(I=O\cap C\)、\(G=C\setminus O\)，集合大小依上下文使用。最优性给 \(|R|\ge|G|\)。

在原**实际前缀**位置 \(i\) 强制合法主题 \(a\)，之后沿同一完整 \(\sigma\) 的真实终局记 \(Z_i(a)\)。定义每个遗漏客户的真实查询收益坐标

\[
v_{i,a}(x)=\frac{\mathbf1_{x\in a}}{c_x(Z_i(a))},\qquad x\in R.
\]

分子非零时分母至少一；其余项取零。这些叶保留所有真实后继，未冻结未来或删除祖先。允许在每个位置选一个目录分布 \(q_i\)，仅将整条原IC按非负常数加权，故

\[
\sum_aq_i(a)\sum_{x\in R}v_{i,a}(x)
\le\sum_aq_i(a)u_i(Z_i(a))\le u_i.
\tag{1}
\]

这是原同一玩家的一份付款，不把不同客户分别作为独立IC权重。

## 2. 一个充分但未证的直接终点

尝试选择全部 \(q_i\) 及取消量 \(\gamma_x\in[0,1]\)，满足

\[
\sum_{x\in R}\gamma_x\le|G|,
\qquad
\sum_{i,a}q_i(a)v_{i,a}(x)+\gamma_x\ge1
\quad(x\in R).
\tag{COVER?}
\]

若成立，对客户求和并用(1)，立即得到

\[
|R|-|G|\le\sum_{i,a}q_i(a)u_i(Z_i(a))\le W,
\]

即 \(|O|\le2W\)。取消量在这里是**自由的**：尚不要求它等于上一轮某个Hall实际G流的终点库存。与NET不同，本式不要求被吸收的客户先沿一个确定的捕获祖先到达该查询；一次查询可同时吸收所有尚未处理的R客户，从而允许不同初始query库存合流与重新分配。这个自由度是否足以普遍可行，未知。

可以把 \(\sum_aq_i(a)\le1\) 改成等号，因为非负收益允许用任意合法主题补足概率；不要求目录包含空主题。\(R=\varnothing\) 或 \(|R|=|G|\) 时取消即可完成；这只是边界，不是一般成立性证明。

对仅根有regret \(\Delta\) 的root-only计划，(1)根处右端改为 \(u_1+\Delta\)，所以同一个(COVER?)若成立甚至给 \(\mathrm{OPT}\le2W+\Delta\)。这是比已知保险等价所需 \(2W+3\Delta\) 更强的要求，**不能无证把完整SPE版本移到任意root-only计划**。本稿不把该强robust版本列为默认前提。

## 3. 精确价格分离式

有限维凸分离给(COVER?)的准确对偶。对所有非负客户价格 \(p_x\)，必须且只须

\[
\boxed{
\sum_{i=1}^m\max_{a\in\mathcal S}
\sum_{x\in R}p_xv_{i,a}(x)
+\operatorname{Top}_{|G|}(p)
\ge\sum_{x\in R}p_x.
}
\tag{PRICE?}
\]

其中 \(\operatorname{Top}_{|G|}\) 是价格最高的 \(|G|\) 个单位客户的价格和。若压缩类型重数或取消质量为分数，则最后一段按分数质量取值。它正是 \(0\le\gamma\le1,\sum\gamma\le|G|\) 的最大价格收益。

必要性：将(COVER?)乘 \(p\) 求和，各位置的混合价格收益不超过其最大主题，取消价格不超过Top。充分性：可实现查询和取消的集合是紧凸集；加上坐标向下闭包后，若不包含全一向量，就有一个非负法向量严格分离它，恰违反(PRICE?)。这里仅证明精确对偶，不证明任一侧普遍成立。

更弱的**仅均匀价格**充分义务为

\[
\sum_i\max_a u_i(Z_i(a);R)\ge |R|-|G|.
\tag{ROW-MASS?}
\]

它本身已由(1)推出half，不需要(COVER?)的逐客覆盖。若全价格加强出现致命反例，不能因此否定(ROW-MASS?)或half；直接证明不必承担全部价格。

## 4. 真正未付的一步

原SPE约束的是未加权的整主题收益。一个违反(PRICE?)的 \(p\) 给的是多个客户、多个状态的加权收益缺口，**不自动给某原节点的可盈利主题**。把客户价格看成新的客户重数也不合法，因为原 \(\sigma\) 未必在新重数上仍是SPE。这是目前的精确缺口。

可能的正向工作是：利用全部深层真实IC和原最优元组的所有hybrid割，将任意坏价格割转成一条合法未加权偏离，或者仅对均匀价格证明(ROW-MASS?)。若只能把(PRICE?)重新命名成动态债，便没有增加证明。当前尚未找到这一分离引理，不声称(COVER?)比NET更弱或更强：两者的库存、行容量及取消兼容条件不同，未建立相互蕴含。

本轮没有为此开展实例扫描、固定策略锥或特殊正面类。一般Q-CAG-HALF及本稿三个问号都保持OPEN；仅(1)、充分归约和有限凸对偶是已核一般关系，不计作新的half突破。

## 5. 未执行的旧坏点投影与对象核清
