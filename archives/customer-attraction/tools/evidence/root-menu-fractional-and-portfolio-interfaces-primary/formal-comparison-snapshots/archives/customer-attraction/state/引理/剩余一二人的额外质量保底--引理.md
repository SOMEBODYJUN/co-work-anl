# 剩余一人和两人的额外分数质量保底

## 最后一人

固定任意合法过去负载b，剩一人。其在任意离轨历史仍选真实最佳主题，故收益

$$u=\max_{A\in\mathcal S}\sum_{x\in A}\frac1{b_x+1}=t_{1,0}(b).$$

对每个q和 $0\le\delta\le1$，分母中的额外质量 $\delta\alpha_x(q)\ge0$ 只会降低每个查询值。因此

$$t_{1,\delta}(b)\le t_{1,0}(b)=u.$$

这里不要求目录标签不同、客户非空或没有平局；空客户时所有值零，最大值仍存在。

## 最后两人

固定任意合法过去历史、剩两人的完整纯SPE。由已有末两人真实最佳回复保底，对每个玩家均有

$$u_i\ge\theta_2(b)\ge v_2(b),$$

其中 $v_2$ 是一名不观察查询实现的整数竞争者静态混合值。凸性给

$$t_{2,0}(b)=t_2(b)\le v_2(b).$$

因此 $u_i\ge t_{2,0}(b)$。而 $t_{2,\delta}(b)$的背景质量为 $1+\delta\ge1$，同一q下分母更大，故

$$t_{2,\delta}(b)\le t_{2,0}(b)\le u_i.$$

该论证逐人使用实际完整策略和所有离轨历史，未把倒二与末位冻结到同一后继，也不要求实际路径主题覆盖所有客户。它只承担r=2尾部，不推断r≥3。

## 与一般Extra合同的边界

这给出δ族在r≤2的普遍真值：$u\ge t_{r,\delta}(b)$。原extra接口将δ=1记为 $t_{r+1}(b)$，因此其小尾部陈述正确；失败只从r≥3的“一般完整SPE”量词开始。银行反族m=4的根有r=4，正好超出此引理范围。

与[真实末两人保底](../定理/真实末两人新增与保护分数价格--定理.md)及[静态混合安全值界](../引理/末位最坏背景值与目录计数界--引理.md)关系是定义层级：先由真实尾部最佳回复得θ，再由 $t_2\le v_2\leθ$ 迁移到自由分数。不能把r=2的尾部证明向前外推到早期玩家。无外审或新颖性认证。
