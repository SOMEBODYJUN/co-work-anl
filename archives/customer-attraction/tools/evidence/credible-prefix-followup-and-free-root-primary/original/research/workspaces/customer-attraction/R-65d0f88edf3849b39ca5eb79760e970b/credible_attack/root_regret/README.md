## 3. 更强背景归纳的终端付款，仅作基底核对

这是直接从均分定义得到的通用终端事实，不作新颖性声明。固定任意非空旧历史，其客户并集 P、整数负载 b_x；只剩一位玩家。令其最佳回复为 C，`delta=|C\\P|`，最终收益 u，福利 W=|P|+delta。旧覆盖客户在当前选择之后的负载至少2，因此

    u <= delta+|P|/2.

对任意两个比较主题 T1,T2，当前改选 Tj 时每个 `Tj\\P` 客户贡献1，故最佳回复性给 `|Tj\\P|<=u`。于是

    |T1 union T2| <= |P|+|T1\\P|+|T2\\P|
                     <= |P|+2u
                     <= 2(|P|+delta)=2W.

这是任意旧背景的 r=1 基底；多于一位后继时，当前偏离会改变所有后继，不能继续把 `|T\\P|` 免费下界为该当前玩家收益。需要跨真实分支共同预算才可归纳。这一基底不是 Q-CAG-HALF 的新已证范围。

没有证明 FREE-ROOT、augmentation 或 `OPT-2W<=3Delta`。根空 tight 族也不验证这些一般候选。仅凭四个有限锥没有反例，无法决定任意正深度 SPE 是否自动 half。
