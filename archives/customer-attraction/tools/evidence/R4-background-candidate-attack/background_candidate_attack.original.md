# 任意合法背景加强候选：准确展开与未付项

2026-10-24。**候选攻击记录；BG 未证、未反驳。下列实际孩子推论为自足解析引理，尚未独立审查。**

固定任意合法有序 prefix h，旧覆盖 U，尚有 r 人，固定该 prefix 后的任意完整历史纯 SPE。令

    C_h^* = max_(T_1,…,T_r∈S) |U∪T_1∪…∪T_r|,
    W_h   = |U∪实际尾部主题|,
    V_h   = 尚未行动者的实际终局收益总和。

候选为 C_h^*≤W_h+V_h。b=0 时就是一般 half；r=1 由当前真实最佳回复和客户边际贡献直接成立。

## 去掉固定基线

令 A_h=W_h−|U| 是实际新增覆盖，B_h 是 active 玩家从 U 中取得的最终总利润，R_h^*=C_h^*−|U|。新覆盖客户的全部利润均归 active 玩家，故

    V_h=A_h+B_h,
    候选 ⇔ R_h^*≤2A_h+B_h.                         (BG)

BG 比单纯对“背景也记为当前福利”的比值更强；B_h 只是一份 active 旧客户利润，不含背景玩家利润。

## 直接人数归纳真正给出什么

取达到 C_h^* 的 r 个比较主题。任选其中 T_j，在 h 强制当前选 T_j，再沿原完整策略走真实后继，得到分支 Y_j。记该枝 active 新覆盖 A_j、原背景 U 上取得的 active 总利润 B_j、当前收益 d_j、未来玩家总收益 V_j^tail。守恒为

    A_j+B_j=d_j+V_j^tail.

若候选已对所有 r−1 人孩子成立，那么其余 r−1 个比较主题在孩子 h,T_j 合法，且连同已固定 T_j 覆盖 C_h^*，所以

    C_h^*≤W(Y_j)+V_j^tail,
    R_h^*≤A_j+V_j^tail
           =d_j+2V_j^tail−B_j
           ≤u_current+2V_j^tail−B_j.              (IND)

最后一步只用 h 的真实当前 IC。IND 对每个 j 都成立；但没有理由把 V_j^tail、B_j 换成实际尾部对应量。

要由这一展开闭合 BG，尚需某个合法比较索引 j 或它们的混合满足

    2V_j^tail−B_j ≤ A_h+V_h^tail.                  (SWITCH?)

这是一个明确的充分跨叶支付义务，而不是从孩子归纳自动得到的式子。实际尾部、分支尾部和背景转移必须保留真实后继；不能用同覆盖、同负载、同一目录或删除祖先来断言 SWITCH。

## 只用实际孩子的最小反例必要结构

以下不需要任何离轨孩子已满足 BG，只需要当前实际主题 A 之后的**同一份原策略的实际孩子**满足 BG。

固定父背景 h，当前规定行动 A，实际孩子 hA，写 u 为当前玩家的最终收益，V_tail 为实际以后玩家总收益，W 为父/孩子共用的实际总覆盖。令

    C = C_h^*, C' = C_(hA)^*,
    δ = C−C',
    S = W+V_tail−C'.

δ≥0，因为任何孩子的 A 加 r−1 个主题都是父状态的 r 个合法主题。实际孩子 BG 恰给 S≥0。父候选的坏差额有精确分解

    C−W−u−V_tail = δ−u−S.                         (DEFECT)

因此父失败的充分必要条件是 δ>u+S，前提只有该实际孩子 BG。它既需要机会损失 δ 超过当前收益，也需要同一个实际孩子的 slack S 不能把它补回；只证明 δ>u 不够。

现在任取一个达到 C 的 r 槽最优元组 (T_1,…,T_r)，令 O=⋃T_j，并定义相对该元组的唯一新客户块

    P_j = T_j \ (U_h∪⋃_(k≠j)T_k),
    E_A = A \ (U_h∪O).

在实际孩子中使用其余 r−1 个主题合法，故

    C' ≥ |U_h∪A∪⋃_(k≠j)T_k|
       = C+|E_A|−|P_j\A|,
    δ ≤ |P_j\A|−|E_A|.                            (PRIVATE-LOSS)

结合 DEFECT，得到精确的全输入归纳推论：

> 若实际孩子满足 BG 而父失败，则对**每一个**达到 C 的最优 r 槽元组、对**每一个** j，均有
>
>     |P_j\A| > u+S+|E_A|.

S 与 δ 是同一个父/实际孩子的量，不依赖最优元组；E_A 可随最优联合 O 变化。外部新增 |E_A| 必须保留，不能从 PRIVATE-LOSS 中丢掉再声称等价。

特别地，任何一个最优元组有空 P_j（包括主题重复的情形）就排除父失败。若父最优覆盖已由至多 r−1 个主题达到，则重复补槽给这样的元组，故实际孩子 BG 已足以推出父 BG。这是一个一般归纳组件，不是对固定人数或目录子类另开研究。

## 独有块本身不提供 root 保底

不能把上述必要结构中的大块条件当作足够机制。已有 `research/current/customer_attraction/continuation_lemmas.md` 的十四客户完整 SPE 直接反驳以下保底：存在 r 个主题及互不交块 P_j⊆T_j、甚至这些 P_j 是比较元组的精确 unique 部分且避开当前实际行动 A，就保证首位收益至少 min_j|P_j|。

该证书有 r=2，最优主题 B,T 不交、各5客户，实际首主题 A 与 B∪T 不交，根收益4；五个离轨最佳回复及全部根收益已在所引正文逐项给出。因此两个精确 unique 块 P_B=B、P_T=T 都避开 A、大小5，却仍大于 root 收益4。实际第二位覆盖 B，实际总覆盖9，OPT_2=10，仍满足 half。

它不反驳 PRIVATE-LOSS/DEFECT：这些式子只是父失败的必要结构，而且父失败还须 δ>u+S。Boss 指出的旧 coverage_opportunity_counterexample 也已给 δ>u，因此不能把“所有 unique 残块比 u 大”或“机会损失 δ>u”当成新闭合。继续研究必须同时使用实际孩子 slack 小的约束，或另找新的真实全树支付。
