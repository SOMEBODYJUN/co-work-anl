## 已得到的准确范围

`repeated_tail_obstruction.md` 给单公共奖金 Q/B 构造的一个任意尾长障碍。
若实际尾部是同一 D 重复 r 次，且一次 fresh A_i 偏离的真实尾部拟定为
B_i 重复 r 次，那么 r>=2 时，仅末位两个真实菜单比较就已矛盾。
这是对该统一构造模板的解析否定，不是半覆盖反例。

一般观察：若最优主题对应的漏失块在偏离真实续局中仍无人覆盖，则它的大小
直接被该玩家的实际收益支付。故要越过 half，必须在漏失客户自身制造真实
拥挤；只把实际 X_i 块的份额由 1/2 降到 1/(r+1) 不足。
