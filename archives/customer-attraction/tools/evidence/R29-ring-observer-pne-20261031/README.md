# R29 ring menu and observer-PNE auxiliary bridge

The ring note is an exact local calculation for a three-window menu; it explicitly says the menu is not a complete SPE because a later player can choose a disjoint window and gain 7/6. The observer-PNE script/JSON is a 54-unit-customer, six-topic fixed-old-player calculation that falsifies an auxiliary bridge comparing every tail SPE with a static tail PNE. It is not a full-root equilibrium or half-coverage counterexample.

The observer script was run with `PYTHONDONTWRITEBYTECODE=1`; the resulting JSON is byte-identical to the frozen source JSON. The ring note is retained as a textual finite calculation, with its own quantifier boundary.
