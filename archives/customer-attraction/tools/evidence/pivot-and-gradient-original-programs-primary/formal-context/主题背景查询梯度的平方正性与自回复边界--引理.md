# 主题背景查询梯度的平方正性与自回复边界

这是原入口恢复的用户历史性质，4946B独审自记先原始陈述后重构，不以本次清洗主张首创、外审或一般half进展。单位非负客户和共同有限标签目录，背景b/d为任意非负实主题计数（代数量词，不称所有实背景都来自单位玩家前缀）。客户负载b_x=Σ_a b_a1_(x∈A_a)、d_x同理，定义额外查询
\[
J_b(a)=\sum_{x\in A_a}\frac1{1+b_x}.
\]
交换有限求和，精确
\[
\begin{aligned}
\sum_a(d_a-b_a)(J_b(a)-J_d(a))
&=\sum_x(d_x-b_x)\left(\frac1{1+b_x}-\frac1{1+d_x}\right)\\
&=\sum_x\frac{(d_x-b_x)^2}{(1+b_x)(1+d_x)}\ge0.
\end{aligned}
\tag{1}
\]
所有分母正，不要求背景总槽数相同、背景支持同一或无空主题。非负类型重数仅在各项乘同一非负系数；有符号客户时等式仍线性成立、正性未必。等号当且仅当每名实际客户看到b_x=d_x，不推出b=d。例如A12/B34/C13/D24四不同非空集合，b=e_A+e_B、d=e_C+e_D，各客户负载均1而计数不同。

令L(b)=Σ_x log(1+b_x)，这是非负正交域上的凹函数，梯度各坐标正是J_b(a)。切线不等式
\[
L(d)-L(b)\le(d-b)\cdot J_b
\tag{2}
\]
沿任意有向背景环求和，左侧望远镜0，右侧边权总和≥0。二长度循环给(1)，所有循环才对应更强有限势支持合同。

在一个有限背景状态集上，存在实势标签\(\ell_b\)使\(\ell_d-\ell_b\le(d-b)\cdot J_b\)对指定全部有向边成立，当且仅当无负有向环。必要性由求和；充分性添加对所有点零边的源，取最短路距离，三角不等式给所需势差。若图全有向成对，这就是全部长度环约束。可行势标签未必等于真实客户log势，更不保证存在共同非负客户表示；任意给出势标签的抽象收益表仍只是必要松弛。

## 真末位菜单的严格边界

固定任意共同早背景r。设b=r+e_s、d=r+e_t，且s在背景b中是末位BR、t在背景d中是末位BR，则J_b(s)≥J_b(t)、J_d(t)≥J_d(s)。代(1)左边恰
\[
-(J_b(s)-J_b(t))-(J_d(t)-J_d(s))\le0.
\]
右侧非负，所以每个平方为0。d_x−b_x=1_(x∈A_t)−1_(x∈A_s)，因此A_s=A_t作为客户覆盖集合。在不同覆盖子集目录中，最多一个主题能在“先看自己一次”后仍以自己为最佳回复；同覆盖不同标签仍可同时成立。量词对任意最佳回复，不依赖平局规则。它是静态末位必要性质，不把早期查询的真实后继冻结成同背景。
