# 末位克隆桥与真实策略锥边界攻击

## 新候选的精确身份

在 CAG-MODEL 中，令任意完整历史纯 SPE 的实际路径为 `(S_1,...,S_m)`，实际收益为 `u_i`，福利 `W=sum_i u_i`。攻击以下两个辅助命题：

- **已否定的逐人末位克隆候选 C1：** 对所有 `i<m`，`2u_i >= u_m`。Boss给出的三人四主题七客户实例有实际收益 `(3/2,2,7/2)`；独立审计全部21历史63偏离通过。
- **聚合末位克隆候选 C2：** `2W >= (m+1)u_m`。

C1蕴含C2。它们对所有有限共同目录、所有单位客户整数重数、任意人数以及每一个完整有序历史依赖纯SPE量化；没有固定或在轨友善平局。两者即便成立也没有单独证明半覆盖：结合已有末位税式只能给 `OPT_m <= W + 2(m-1)W/(m+1)-R`，当 `m>3` 其系数仍超过二。已有 `W>=H_m u_j` 是旧调和界，不在此重复申报。

### 已证的末两人分支

C1在 `i=m-1` 成立。令 `b_x` 是倒二人行动前的实际负载，末主题为 `T=S_m`。倒二人真实偏离T后末位原策略可任意回复B。逐客户有

`b_x+1+1_{x in B} <= 2(b_x+1+1_{x in S_{m-1}})`。

故偏离收益至少是原末位收益的一半；倒二人SPE最优性给 `u_{m-1}>=u_m/2`。这里对真实B无须最优性，全部离轨平局均保留。更早位置的同一保守分母仅给调和界，不能直接推广。

### 完整SPE等号族：任意人数、两个不交主题

取 `m>=2`。目录只有不交主题A、B，其单位客户数分别为 `m-1` 和2。完整策略：每名非末位玩家都选择A；末位在过去B次数 `b<=1` 时选B，在 `b>=2` 时选A。这指定了全部有序历史，且实际路径为 `A^{m-1}B`。

逐历史验证：

1. 若过去 `b=0` 且当前非末位，遵守A得到终局 `(m-1,1)` 的收益1；改B后末位会再选B，偏离收益也是1。
2. 若过去 `b=1` 且当前非末位，遵守A最终A次数 `m-2`，收益 `(m-1)/(m-2)>1`；改B得到B次数2、收益1。该分支只在 `m>=3` 存在。
3. 若过去 `b>=2` 且当前非末位，未来全选A，当前收益 `(m-1)/(m-b)>1`；改B收益 `2/(b+1)<=2/3`。
4. 末位若 `b=0`，选B得2，而选A得 `(m-1)/m<1`；若 `b=1`，A与B均得1；若 `b>=2`，A收益 `(m-1)/(m-b)>1` 而B至多2/3。

所以这是完整纯SPE。实际 `u_1=...=u_{m-1}=1`、`u_m=2`、`W=m+1`，C1与C2同时取等号。因此若这些候选为真，常数1/2和(m+1)/2均不可提高。此族福利等于OPT，不是主目标下界。

## 计算机制与准确边界

- `search_terminal.py` / `search_clone_half.py`：浮点全集后向归纳scout，保留全部终局集合，搜索末位/早期收益比；只用于发现候选。n5,m5与n7,m5稀疏整数搜索分别5000与10000次，未找到C1反例；该有限事实不证明候选。
- `cone_attack.py`：固定一份完整SPE策略，用每个真实历史的收益差行形成非负客户锥，对每个早期i分别最大化 `(.5u_m-u_i)/W`。n7,m5随机500个完整策略锥未找到正值。浮点LP记录不是精确证书，且没有穷举策略。
- `pair_cone_attack.py`：把目标扩展至任意两名实际玩家；目前只探索，没有结论。
- `cone_walk.py`：LP极点回注全集oracle，在边界平局处重选真实离轨策略，主动跨策略锥。正面目标max `OPT/W`；若坏点出现，必须先整数化并经规范 `verify_certificate` 全历史独立核验。
- `terminal_clone_equality_audit.py`：Fraction逐历史独立审计上述解析等号族，输出冻结摘要；这是有限回归，家族的一般证明在上文。

所有JSON中 `bridge_violation_ratio` 是scouting目标值，不是主目标反例；`lp_weights` 均为数值候选。只有精确整数输入+完整策略+独立定义级审计后才允许称真实SPE反例。
