- [同角色流引理](../../../state/引理/同角色未来覆盖密度与查询行聚合--引理.md)：一般流证明、source η/c0边界、同query一次完整IC与跨query缺口。
- [两审计的准确合同](../../../state/计算/同角色流聚合的原审计与父审切口--计算.md)：原入口各一次、全部原字段与字节相同结果。
