## 可移植复核

在本证据目录执行如下命令，输出目录须尚不存在；这会产生**新的**执行事件，而不会更改本轮已保存的事件：

```bash
python -I -B audit_saved_certificates.py --evidence . --output /new/cascade-exact-review
```

检查器仅用标准库，直接按单位客户定义计算。不需要下述发现器依赖，也不把有限正确性变成一般搜索上界。不得用Python的 `-O` 关闭其assert。

## 原发现器的依赖与布局

`dependencies/customer_attraction/`保原同SHA的 `__init__.py`、`model.py`、`exact.py`、`certificate.py`，大小分别691、8640、9943、6201B；冻结身份、原运行相对路径和既有复用来源见 `dependency-manifest.json`。它们先前已实读并充分处理，本批仅核同字节复用，没有重授主来源done。

原发现器还导入NumPy/SciPy；四份冻结发现输出没有版本/源码SHA/完整argv/标准流，包中不宣称恢复了它们的旧数值环境。原代码用位置 `parents[5]` 找仓库根，不能将文件随意搬到顶层后称未改入口已复现。若后人需要独立研究原发现器，可先仅恢复布局：

```bash
python -I -B restore_original_layout.py --destination /new/cascade-original-tree
```

该辅助脚本先核13件SHA再复制到全新目录，不import或执行任何发现器；本轮只写该低影响复制辅助工具，没有运行它。新探索须用独立输出路径，因为原CLI的主history及 `*_best.json` 是覆盖写。不要以一次新随机运行替换原缺字段版本或倒填旧未保存轮次。
