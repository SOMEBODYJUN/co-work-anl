# 共同随机优先下的真实偏离请求：一般探索 checkpoint

2026-10-25。主目标 OPEN，没有新正面金额。
原 m 人、单位客户、有限共同目录、完整历史纯 SPE，不固定后继。

## 1. 概率事实及量词

任意完整终局与客户 x，给覆盖者独立同分布连续优先值，把 x 交给最小者。
每名覆盖者获胜概率为1/c_x，所以期望获客数准确为原利润。
同一个随机角色排列可用于全部客户与全部合法偏离叶；每个叶各边际仍正确。
这些值只耦合数学中的收费事件，不是玩家观察的新信号，不改变原策略或 IC。

## 2. 真正需要的新关系

固定实际覆盖 C、最优覆盖 O，令 I=O∩C、R=O\C、G=C\O。
旧递增角色流在状态(i,A,x)读取实际前缀下强制 A 的真实叶，均分遗漏客户输入。
角色严格增加，逐客户质量守恒。**固定一个状态单独看**，随机优先可实现其均分边际。
若状态是否到达已取决于同一组优先值，则条件获胜概率不必仍均匀，
所以不能由固定状态的正确边际就宣称实现了旧流全部条件转移。

不同来源仍可在同一角色 i 提出不同动作 A，每条 IC 则对应一个完整 query。
正确客户边际不保证每个随机实现该角色只有一个动作，也不保证期望 query
收费系数之和不超过一。

matching12 独立指出同一条件化问题：让匹配/动作依赖潜在 provider 优先值，
会改变给定动作后的 query 利润分布；另用独立排列恢复1/c又丢失预期的跨 query 取消。
这说明当前构造没有完成，不证明其他耦合不存在。

欲接 HALF，需要额外证明：可选 matching、遗漏客户 owner 和跨 query 耦合，
使位置加权收费超额不超过 G，并保留原 IC 松弛、不重复付款。
这至少要求真正跨 action 的合并/选择机制；仅逐边改用随机排列没有完成它。
目前没有这样的构造或一般充分条件，不把候选当作已证。

## 3. 停止重排标准

若随机优先只重现旧均分边际，而没有改变合法支付的联合请求集合，
它不是新一般组件，应停止重排。当前尚未突破此点；不据此宣称耦合不存在。
没有固定人数扩张、没有新的阴性扫描。
