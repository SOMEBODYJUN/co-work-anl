## 唯一新数学检查事件

regenerate_and_check.py是本次实际执行的标准库检查器。它不导入原程序、规范模型/证书或LP，按原seed21062026与循环顺序再生成十二份完整2801动作策略，全部根路径与原十二条记录一致。regenerated/policy-00.json至policy-11.json保存**当前再生成**动作，合计1100090 B；历史没有完整动作表和执行环境，不将当前表冒称历史原字节恢复。

独立从均分定义、真实完整σ后继和Fraction核验：均匀127客户种子共201672条非自身IC，0违反；每轮8722条old严格、8084条fresh平局、最小old差26/5。全兴趣一客户点另有201672条非自身IC均等号；E*=9/5、W=OPT=1、ε=−1/5来自直接背景公式。种子W=OPT=124来自不同主题覆盖数2^p−2^(p−m)，不是新LP或另调用最优覆盖器。

regenerated/verification.json保存全部计数、每表SHA、每轮同计数异动作例子与事件范围。regeneration-execution.json、regeneration-stdout.txt、regeneration-stderr.txt保存一次实际进程信息和原样输出；检查器的执行字节SHA也保在记录内。源码执行后未改路径或内容。

本事件原main0、原optimize0、规范verify0、LP0。只认证再生成种子SPE与一个可行点，不认证十二份历史LP精确最优、不重放历史优化。成熟M2编译审计及portfolio单锥29×32有理原对偶证书均未重跑；其作用和身份见comparison.json。

## 原报告与新事件分层

original/中的报告完整保存所有顶层和十二条七字段记录。十二条均为m5,p7、16806非自身IC、17016总行、目标原字面−0.19999999999999996、显示支持mask127权1。该支持是优化后客户点，不是种子的127客户表；原只输出权>10^-9，不保完整解或对偶。

所有非空类型统一单位质量使任意逐历史fresh策略为完整SPE，由已完成M2的M=0,K=1特例和正式对象中的逐类型配对证明支持；不是任意不均匀正质量定理。全兴趣单客户给任意固定标签锥的ε=−1/m**可行下界**，有限求解结果返回同值不证明上界。严格集合目录与优化后可能出现的同覆盖异标签保持区分。
