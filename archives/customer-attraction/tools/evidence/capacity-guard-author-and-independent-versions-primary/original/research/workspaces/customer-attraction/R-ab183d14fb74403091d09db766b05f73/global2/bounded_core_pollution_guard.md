# 大外部主题下的有限核心污染容量守卫

2026-10-22，Boss6 global2。状态：自足推导；root初检与recursion2独立攻击均未发现数学缺口，recursion2还给出第2.1节离散加强，独立记录见 `../recursion2/bounded_core_guard_review.md`。不是一般Q-CAG-HALF证明，不宣称外审或新颖性。对象为CAG-MODEL的任意有限共同目录、单位客户和提供者、全部有序历史上的任意平局纯SPE。

## 1. 一般条件与结论

固定人数m≥1，取非空子目录G，每个T∈G配正整数容量k_T，且Σ_G k_T≥m。令C_T⊆T是只被G中T覆盖的客户集，a_T=|C_T|。C_T不要求对整个目录私有；不同C_T自然不交。取

    β_T=max_{U∈S\G}|U∩C_T|，   κ_T=min(k_T,m)，

outside为空时β_T=0。因此0≤β_T≤a_T。定义

    L_T = a_T²/[κ_T a_T+(m−κ_T)β_T] + (|T|−a_T)/m，

其中a_T=0时第一项定义为0（此时β_T=0）。若存在λ>0使每个T∈G均满足

    L_T≥λ，                 |T|<(k_T+1)λ，                 (1)

则每份完整纯SPE在每个合法非终局有序历史上的当前玩家最终收益均至少λ；在每个这样的历史，当前玩家都不选择已经出现至少k_T次的G主题T。

尤其根上W≥mλ。本结论允许outside主题任意大、任意多个，也允许outside实际被选。若另有OPT_m≤2mλ，则half成立。一个直接可核验充分条件是所有目录主题大小至多2λ；此时OPT_m≤2mλ。一般实例不保证存在此容量证书。

## 2. 同一真实终局中的污染下界

设某玩家选T，终局共有q名玩家选择T，1≤q≤κ_T。C_T只可能被这些T玩家和outside玩家覆盖。对x∈C_T，记outside覆盖者数为d_x。outside人数至多m−q，各outside与C_T交至多β_T，所以

    Σ_(x∈C_T)d_x ≤ (m−q)β_T。

若a_T>0，Cauchy给

    Σ_(x∈C_T)1/(q+d_x)
      ≥ a_T²/[q a_T+Σ_x d_x]
      ≥ a_T²/[q a_T+(m−q)β_T]
      ≥ a_T²/[κ_T a_T+(m−κ_T)β_T]。                    (2)

最后一步使用a_T−β_T≥0，使分母随q不减。若a_T=0，左侧与定义的核心信用均为0。其余T客户每名负载至多m，所以T玩家的完整收益至少L_T。

(2)不把污染当作新增福利，也不要求outside配合。它只在同一真实终局使用总污染量，不把不同分支的份额相消。

### 2.1 单位客户的离散均衡加强（recursion2提出）

a_T>0时令κ=κ_T、a=a_T、β=β_T，D=(m−κ)β，j=floor(D/a)，s=D−aj。核心信用可从Cauchy值加强为

    L_T^core,disc = (a−s)/(κ+j) + s/(κ+j+1)。              (4)

a=0时仍定义为0。把(1)的L_T换成此项加(|T|−a)/m，全部结论不变。

证明：固定a个正整数分母ℓ_x，总和至多N。若ℓ_x≥ℓ_y+2，把两者改为ℓ_x−1、ℓ_y+1，则

    1/(ℓ_x−1)+1/(ℓ_y+1)−1/ℓ_x−1/ℓ_y
      =1/[ℓ_x(ℓ_x−1)]−1/[ℓ_y(ℓ_y+1)]≤0。

因此固定总和时，倒数和最小由分母相差至多1取得；增加总和又使该最小值不增。在当前终局，ℓ_x=q+d_x、总和至多N(q)=qa+(m−q)β≤N(κ)=κa+D。对N(κ)均分即得a−s个分母κ+j、s个分母κ+j+1，给(4)。约束d_x≤m−q不影响此下界；放宽只会降低最小值。(4)至少为Cauchy项，在D不被a整除时严格更强。

## 3. 全部有序历史上的逆向归纳

对剩余深度归纳，量化每个有序历史，包括已含outside、已含超cap主题的离轨前缀。

在长度t<m的历史h，若每个G主题都已满，则t≥Σ_G k_T≥m，矛盾。因此存在未满Q∈G。当前真实改选Q后，Q计数至多k_Q。根据所有更深有序节点的归纳假设，之后一旦Q达到k_Q，后继不再选Q；故真实终局Q人数q≤k_Q且当然q≤m。由(2)，当前偏离收益至少L_Q≥λ。

另一方面，若当前选择已经满的T，终局至少有k_T+1名T玩家，所以不论后继如何，当前收益至多|T|/(k_T+1)<λ。SPE最优性排除所有已满T，并使当前指定行动收益至少λ。指定行动可以是一个未满G主题，也可以是outside。归纳完成；末位是同一论证的无后继情形。

不需要把同计数历史视为同回复，不冻结后继，不删除outside；所有偏离仍沿原完整SPE执行。

## 4. 精确污染租金恒等式及跨分支缺口

在第2节同一终局，令

    z_T=Σ_(x∈C_T)1/(q+d_x)，
    R_T=Σ_(x∈C_T)d_x/(q+d_x)。

这里R_T恰为全部outside玩家从C_T获得的总收益，逐客户有

    q z_T + R_T = a_T。                                      (3)

若q≤k_T，则k_T z_T+R_T≥a_T。因此相对无污染a_T/k_T信用的短缺全部是这些outside玩家在同一核心上的份额转移。不同核心不交，还得到Σ_T R_T≤全部outside玩家的总收益。

这个总和是同一终局的真实预算；不能把“偏离T分支的R_T”加总后直接记为实际路径outside收益。大outside的一般难点正是这项跨分支运输。若每个outside只大量污染一个核心，其逐核max β_T可能仍都接近a_T，(2)会失去联合稀疏信息。下一步应保留联合核心污染向量或可支持租金的资源约束，寻找跨所有真实分支的共同支付，而不是继续放松每个核心的独立最坏β。

## 5. 与先前守卫的关系

β_T=0时恢复全目录私有核心a_T/κ_T信用，并至少恢复旧a_T/k_T信用；β_T=a_T时仅得a_T/m。中间值给连续污染插值。先前small_outsider条件则可用收益严格上界排除全部outside，并保留a_T/k_T；两种条件互不替代。

一个允许大outside且实际可选的有限例子：m=2，G含两个不交八客户块A、B，k_A=k_B=1。另有八个公共外部客户E；对每个a∈A、b∈B，加入主题E∪{a,b}。每个outside大小10，β_A=β_B=1，取λ=7。核心信用64/9>7，G大小8<14，所有主题大小≤14，所以本条件给half；全目录没有私有客户。

具体完整SPE可令末位任意选最佳回复。首位选任意outside时，末位最佳是一个G块，收益15/2；首位收益19/2。首位选G块时，末位最佳是outside，首位收益15/2。因此根选outside最优，实际outside严格大于λ且确实被选；福利17、OPT_2=17。此小例只展示结论不依赖排除outside，并不声称超越已有两人定理。
