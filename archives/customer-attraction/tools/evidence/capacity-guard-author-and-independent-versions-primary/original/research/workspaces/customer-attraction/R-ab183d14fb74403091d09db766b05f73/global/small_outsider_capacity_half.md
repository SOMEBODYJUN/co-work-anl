# 小外部主题闭合的容量守卫与半覆盖充分类

状态：个人自足推导，independent已盲重构归纳并加强自动half推论，见同工作区 `independent/capacity_core_outside_audit.md`；没有一般Q-CAG-HALF证明，没有外审或全球新颖性认证。使用CAG-MODEL完整量词：有限单位客户、单位提供者、有限共同非空目录、全部有序历史纯SPE、任意历史依赖平局、允许重复与空主题。

## 1. 精确容量条件

在整个目录S中取非空子目录G。固定λ>0及各T∈G的正整数容量k_T。令a_T为T内只被G中的T覆盖的客户数；这些客户可以被S∖G中的主题覆盖，所以这里不要求全目录私有客户。假设

    Σ_(T∈G) k_T ≥ m，
    a_T/k_T + (|T|−a_T)/m ≥ λ，
    |T| < (k_T+1)λ                 对每T∈G，
    |U| < λ                       对每U∈S∖G。

则任意完整有序历史纯SPE从根沿自身策略所得路径满足：所有动作属于G，各T总出现次数不超过k_T，每位玩家最终收益至少λ。因此W≥mλ。

更精确地，上述结论对任意“仅由G主题组成、且各主题出现次数不超cap”的有序前缀之后的真实子局成立（逐人收益只针对剩余玩家）。它不声称任意已经包含outside或超cap动作的离轨前缀之后也满足λ。

## 2. 自足完整历史证明

称只含G且各count不超cap的合法前缀为合规前缀。根为空，合规。对剩余人数逆向归纳，并量化每个合规有序前缀及原策略的全部孩子。

固定长度t<m的合规前缀h。因为Σcap≥m>t≥Σ_G q_T，至少一个Q∈G尚未满容量。

当前若选outside主题U，则无论后继如何，当前收益至多|U|<λ。当前若选已满容量的T，则不论后继如何，终局至少有k_T+1个T覆盖者，其收益至多|T|/(k_T+1)<λ。这两类偏离无需任何关于孩子策略或孩子是否合规的假设。

当前若改选未满Q，得到的子前缀仍合规。更深合规节点的归纳假设保证原策略后继只选G且不超cap。因此真实终局中Q总数≤k_Q，Q的a_Q个相对G私有客户不被其他真实主题覆盖，每名至少给当前偏离者1/k_Q。其余Q客户每名总负载至多m，至少给1/m。该真实偏离收益至少

    a_Q/k_Q + (|Q|−a_Q)/m ≥ λ。

SPE最优性使当前指定行动收益≥λ，所以不能是上述两类严格低于λ的动作，只能在G中选未满主题。其孩子前缀合规，故归纳保证之后每个行动也合规且每个剩余玩家≥λ。

末位是同一论证的无后继情形。归纳完成。所有非合规孩子仍由完整SPE定义；仅因当前收益的无条件上界，不需要将它们的后继替换成任何指定行为。没有匿名计数策略假设，没有固定平局，没有删去原目录中的outside动作。

## 3. 半覆盖的准确充分条件

若该实例另满足OPT_m≤2mλ，立即有OPT_m≤2W。

**加强的自动推论（independent独立重构）。** 若所选容量之和恰为人数，Σ_G k_T=m，则自动有OPT_m<2W；**不要求G覆盖全部客户**。

证明：任取至多m个比较主题，删去重复后，其中属于G的子集记为H，outside主题有t个。因此|H|+t≤m。由每个主题的严格大小上界，

    |union 比较主题| ≤ Σ_(T∈H)|T| + Σ_(outside U)|U|
                    < λ(Σ_(T∈H)k_T + |H| + t)
                    ≤ λ(m+m)=2mλ≤2W。

目录有限，最优比较组合也满足严格不等式。若比较主题全为空，其覆盖为零，同样严格小于2mλ。这里|G|≤m已由每个cap≥1及容量和=m自动蕴含。

outside可以覆盖G并集之外的额外客户，也可以污染相对G私有核；其大小<λ仍使其不能在合规前缀上成为真实行动。G覆盖整个可覆盖客户并集的旧推论是本推论的子类。

更一般，若K=Σ_G k_T≥m，同一比较给出OPT_m<(K+m)λ，从而OPT_m/W<1+K/m。K>m时该式本身不保证half。也可以另用数值条件|union S|≤2mλ，而不要求cap总和恰m。所有这些都是可核验充分证书，不声称每个输入都有此类证书。

## 4. 零全目录私有、无界极大主题数量的例子

取任意m≥2。G有m个两两不交的三客户块B_i，每个k_i=1，λ=3。outside目录包括任意跨两个不同块的二客户主题，并可包括全部单客户主题。每个客户至少出现在一个outside主题，故没有全目录私有客户；相对G仍有a_(B_i)=3。每个outside大小至多2<3，所有容量条件成立，cap和=m。

结论更强：根路径必选m个不同的B_i，覆盖全部3m客户。若包括全部跨块二客户主题，则它们都不被任何B_i包含，彼此也不包含，因而不同包含极大主题数量随m无界。其最优并集的分数覆盖数恰为m：m个B_i给上界；每客户取对偶权1/3，任何B_i总权1、任何outside总权≤2/3，给下界m。因此它不要求分数覆盖数≤7/2。

此例只是说明条件能越过全目录私有、有限极大数量与低分数覆盖数的直接假设，不宣称排除了所有已知定理的间接推论，也不把一个例子当一般猜想证明。

## 5. 仍然缺失的跨真实分支预算

outside大小<λ承担了完全闭合：若允许某个outside大小≥λ，它可能成为真实后继并污染G-private核，原保底不再成立。不能将“实际路径没有outside”当先验假设，也不能以只相对最优组合私有代替这里的全域闭合。

下一步需要给大outside的污染寻找可跨真实分支收费的预算，或采用另一不变量。上述正面类没有解决一般人数、一般共同目录的半覆盖。
