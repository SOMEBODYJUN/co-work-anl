# 末对调和付款的 root 独立重构

2026-10-24。收到作者的定理陈述后，root 在读取完整作者稿前从原始定义重构如下；收到 menu9 的独立确认后再逐式对稿。内部独立解析检查通过，不是外审/新颖性认证，不闭合一般 HALF。

设 m≥2，A=B_(m−1)，B=B_m，k_x 是前 m−2 位实际负载。a=u_(m−1)，v=u_m，L=Σ_A1/(k+2)，C=Σ_(A\B)1/[(k+1)(k+2)]，C′=min(a,v)−L。末位合法复制 A 给 v≥L，a≥L，故 C′≥0 且 C−C′=(a−v)_+。

对每个较早实际位置 i，真实偏离 A 后的最终负载≤b_i(x)+r_i；其完整收益至少 q_i=Σ_A1/(b_i+r_i)，从原完整 IC 得 u_i≥q_i。不冻结未来、不要求复制者保护过去收益。

令 F=Σ_i≤m−2 q_i，s=H_m−3/2。逐客户 b_i+r_i≤(k+1)r_i，因而 F_x≥s/(k+1)。所以

    (k+1)(k+2)[F_x+2/(k+2)]−(2H_m−1)
      ≥k(H_m+1/2)≥0。

只在 A\B 上以右侧 C 系数求和，并保留 A∩B 的非负项，得 F+2L≥(2H_m−1)C。W≥F+a+v≥F+2L+2C′，故 W≥(2H_m+1)C′。作者精确退款 R+|a−v|+J+(2H_m−1)(a−v)_+ 亦逐项核对成立。

m=2 时 F 空和、H_2=3/2；A 空和 W=0 均乘法式处理。任意实际有序历史和全部离轨平局保留。上述只使用原模型可用的完整 IC。

以 Fraction 独立核算 m=5：H_5=137/60，1/(2H_5+1)=30/167，1/5−30/167=17/835。仍未控制任意最优指派的早期 Σ_(i≤m−2)(E_i−e_i)，因此不能推出 OPT_5≤2W；不能作为局部常数优化项目继续扩展。
