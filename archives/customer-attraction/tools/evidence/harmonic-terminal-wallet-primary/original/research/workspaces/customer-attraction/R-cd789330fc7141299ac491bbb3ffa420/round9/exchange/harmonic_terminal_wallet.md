# 一般人数的调和复制付款：末对冻结税的同一实际福利来源

2026-10-24，exchange9。对象是任意有限共同目录、任意人数和每份完整历史纯 SPE。**Q-CAG-HALF 与弱最优冻结指派界仍 OPEN。** 本页将上一轮末对 reduced-wallet 与所有较早位置的真实复制偏离合用，证明全输入组件

    (2H_m+1) C'_(m-1) <= W,    H_m=sum_(r=1)^m 1/r.       (HW)

它支付末对的一份同一钱包，不支付所有早期冻结税；不是本轮研究终点或一般 HALF 的新增已证范围。

## 1. 定义与新使用的复制行

固定原 SPE 实际叶 Z=(S_1,...,S_m)，m>=2。置 p=m-1、A=S_p、B=S_m、a=u_p、v=u_m，k_x 是实际前 m-2 人覆盖 x 的次数。沿用[上一轮末对钱包](../../round8/matching/terminal_frozen_regret_wallet.md)的

    L=sum_(x in A) 1/(k_x+2),
    C=a-L=sum_(x in A outside B) 1/[(k_x+1)(k_x+2)],
    t=min(a,v),       C'=t-L=C-(a-v)_+.

实际末位可以合法复制 A，所以 v>=L；逐客户 a>=L，故 C'>=0，且 C'<=C。上一轮同一背景的三个真实 IC 已给每个合法 T 的点态冻结行

    f_p(T)=a+C'-h_T,  h_T>=0,       f_m(T)<=v.              (TAIL)

新使用所有较早 actual-prefix 节点：对 i<=m-2，记 r_i=m-i+1、b_i(x) 为实际前 i-1 人覆盖 x 的次数，并令

    q_i=sum_(x in A) 1/(b_i(x)+r_i),      F=sum_(i<=m-2) q_i.

当前玩家在自己实际前缀改选 A，之后仍沿原完整策略。客户 x 的最终负载至多 b_i(x)+r_i，故原 SPE 比较给

    u_i>=q_i.                                            (COPY)

不冻结后继，不跨枝替换旧利润。因此同一份实际利润和满足

    W>=F+a+v>=F+2t=F+2L+2C'.                             (ONE-W)

每个较早角色只付自己一条完整复制行，末两位仍付各自实际利润。

## 2. 完整逐客户证明

令 s=H_m-3/2>=0。对 x in A，因为 b_i(x)<=k_x，且 r_i>=1，

    b_i(x)+r_i <= k_x+r_i <= (k_x+1)r_i.

故 F_x=sum_(i<=m-2)1/(b_i(x)+r_i) >= s/(k_x+1)。直接通分给

    F_x+2/(k_x+2) - (2H_m-1)/[(k_x+1)(k_x+2)]
      >= k_x(H_m+1/2)/[(k_x+1)(k_x+2)] >=0.               (CLIENT)

对 A outside B 求和，并保留 A intersect B 的非负项，得到

    F+2L >= (2H_m-1)C >= (2H_m-1)C'.                    (HARM)

代入 ONE-W 即得 HW。m=2 时 F=0、H_2=3/2，原式仍成立；A 为空、零钱包及 W=0 都用乘法式处理。没有使用 HALF、弱指派或离轨叶福利假设。

### 精确退款

令 R=sum_(i<=m-2)(u_i-q_i)>=0，J=F+2L-(2H_m-1)C>=0，则精确代数给

    W-(2H_m+1)C'
      =R+|a-v|+J+(2H_m-1)(a-v)_+.                        (REFUND)

J 的非负性由 CLIENT 承担。此式标明相应利润来源，不能把该来源再给另一张付款账免费使用。

## 3. 一般推导的五人压力测试和未付早期项

先得全 m 的 HW，再直接代 m=5：H_5=137/60，故对任意共同目录、每份五人完整纯 SPE，

    C'<=30W/167 < W/5,       W/5-C'>=17W/835.             (FIVE)

这不是五人专用加行或调系数。m=6 的同一式只有 C'<=10W/59，不能单独推出 C'<=W/6；这不是一般 HALF 反证。

为了直接检查目标，取任意最优 m 元组与排列，重标角色 i 的主题 T_i。定义

    D_i=u_i(finish_sigma(Z_<i,T_i)),
    e_i=u_i-D_i>=0,       E_i=f_i(T_i)-D_i.

上一轮末对精确分解为

    Q-W=C'+sum_(i<=m-2)(E_i-e_i)-e_m-h_(T_p).            (QTAIL)

因此 m=5 的弱指派候选仍需共同选择最优组合与排列，使

    sum_(i<=3)(E_i-e_i) <= W/5-C'+e_5+h_(T_4).

HW 把右边第一块无条件付成至少 17W/835，但左边三个早期真实/冻结差没有共同上界。因此**没有推出 OPT_5<=2W**。新组件只确定一块末对账的真实资金来源，不能作为研究终点；下一步继续一般早期全树交换或直接证明。

## 4. 来源、核验与限制

TAIL 及 C' 定义来自上一轮；本页新增的是所有 actual-prefix 复制 IC 对同一 terminal C' 的跨位置调和付款。没有新增末对代数或双随机匹配的新颖性声明。

HW 不依赖比较最优组合，对全部比较主题同时可用。不允许将 C' 免费叠加到已经使用同一早期复制行的 coordinate 或全树银行。未证明强已否定 Q<=W、弱开放 Q<=(1+1/m)W、早期冻结 regret 统一界或跨互斥 context 的共同钱包。
