# R-3d253 weak FLOW matching finite search

The frozen probe was read and replayed in two byte-identical dependency environments. Across 120 seeded random instances (each capped at 300 non-optimal paths), stdout reports no failure. The code tests a weak maximum-permutation matching inequality only; it does not construct an integer customer flow, shared role capacity, Bellman KAPPA budget, or complete SPE. The result is integrated as a finite negative search boundary for the existing free-acceptance and free-start algorithms.
