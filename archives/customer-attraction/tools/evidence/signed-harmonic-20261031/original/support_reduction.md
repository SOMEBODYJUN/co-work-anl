# 有符号 ghost 预算：支持量词归约与交换义务

个人研究稿，2026-10-23。一般 Q-CAG-HALF 仍 OPEN；本文的充分预算未证。
下面的恒等式和支持归约独立于有限扫描，但尚未经外部审查。

## 1. 基准与严格的充分性

固定一个完整纯 SPE 的真实终局，客户负载为 c，实际并集 A，W=|A|。
给一个比较主题支持 S，1≤|S|≤m，记 O=∪S，d_x=|{T∈S:x∈T}|，E=|A\O|。
令

    v_c(T)=Σ_{x∈T}1/(c_x+1),
    L(c,S)=Σ_{T∈S}v_c(T)=Σ_x d_x/(c_x+1),
    F(c,S)=Σ_x (H_(c_x+d_x)−H_(c_x)).

总有 F≤L。若 O 达到 OPT_m，以下任一存在型命题足以推出原 half：

    存在最优支持 S，使 F(c,S)≤W+E；
    存在最优支持 S，使 L(c,S)≤W+E。

因为每个 O\A 客户给 F 至少一，所以 |O\A|≤W+E；再加 |O∩A|=W−E 给 OPT_m≤2W。
但它们比 half 本身严格强。精确差额为

    F−W−E = OPT_m−2W
             +Σ_{x∈O\A}(H_(d_x)−1)
             +Σ_{x∈O∩A}(H_(c_x+d_x)−H_(c_x)).

因此不能把剩下的正 overlap premium 当成已由 half 自动支付。
例如若 c_x∈{0,1} 且 O⊇A，则 F≤W 已迫使 OPT_m≤3W/2。
既有无拥挤 3/2 无限族达到此额外结论的极限：m=k+1，F=2k+1，W=2k+2。

## 2. 可以完全消去最优元组中的重复槽

若一个最优 m 元组含重复主题，删去重复副本不改变 O，只会逐客户降低 d，故同时降低 F 和 L。
所以 half 所需的存在型桥只须研究至多 m 个不同主题的支持，无需把它再重复补满 m 槽。
这不是说“每个最优 m 元组”版本错误，而是没有必要承受这个更强量词。

如果某个最优支持 S 的大小 k<m，则 O 必须等于整个目录的并集：
若存在目录主题 X 含 O 外客户，S∪{X} 用至多 m 主题严格改善覆盖，矛盾。
于是这种情形必有 A⊆O、E=0。

反之，只要 OPT_m 尚未覆盖全部目录并集，每个最优支持都恰有 m 个不同主题，而且每个主题都含一个不在同支持其他主题中的私人客户。
否则删去一个冗余主题得到少于 m 主题的最优支持，落入上段矛盾。

## 3. 线性 ghost 预算是一个精确的静态子模目标

定义

    J_c(S)=Σ_{T∈S}v_c(T)+|A∩∪S|.

则

    L(c,S)≤W+E  ⇔  J_c(S)≤2W.

J_c 是主题支持上的“模块 query 价格 + 实际客户覆盖 bonus”，单调子模。
逐客户写成

    J_c(S)=Σ_{x∉A}d_x +Σ_{x∈A}(d_x/(c_x+1)+1_(d_x>0)).

充分桥的最弱自然版本成为：

    min { J_c(S): |S|≤m, |∪S|=OPT_m } ≤2W.       [OPEN]

这不要求所有最优支持达标，更不要求所有任意比较支持达标。

若仍要研究所有恰 m 槽元组，固定支持 S、k=|S|，其最坏/最好 L 分别为

    Σ_{T∈S}v_c(T)+(m−k) max_{T∈S}v_c(T),
    Σ_{T∈S}v_c(T)+(m−k) min_{T∈S}v_c(T).

把全部额外副本放到一个最大/最小 query 价格主题即可达到。Harmonic F 不具有这个线性极点归约。

## 4. 最小 J 最优支持的精确交换式

选一个达到 OPT_m 且 J 最小的支持 S。对 T∈S 和 X∉S\{T} 的任意目录主题 X，定义（使替换仍是支持而非重复副本）

    P_T=T\∪(S\{T}),
    D=P_T\X,       G=X\O.

用 X 替换 T 后的新并集恰为 (O\D)∪G；因此

    Δcoverage=|G|−|D| ≤0,
    ΔJ=v_c(X)−v_c(T)+|A∩G|−|A∩D|.

如果 |G|=|D|，则替换后仍最优，最小性给 ΔJ≥0，即

    v_c(T)+|A∩D| ≤ v_c(X)+|A∩G|.                (EX)

对满足上项未重复条件的真实实际主题 X=S_i，G⊆A，等势覆盖交换时进一步简化成

    v_c(T)−v_c(S_i) ≤ |D\A|.

覆盖损失严格正时，最优性本身不提供 (EX)，不能把它按连续扰动自动延伸。
完整 SPE 的新义务可定位为：当大部分替换都有正 coverage 损失时，利用这些客户在真实偏离及真实后继中的收益，支付 min J−2W 的正候选债务；现有交换恒等式没有做到这一点。

## 5. 删除与末位菜单的精确接口

写 F(c,d)=Σ(H_(c+d)−H_c)。删除实际玩家 i 的主题计数（客户上删除其 membership）有

    Σ_i [F(c−i,d)−F(c,d)] = Σ_{x:c_x>0} d_x/(c_x+d_x).

这是同一实际终局的纯代数式，删除后的局面不是自动获得的 SPE。

若实际末位主题 membership 为 b_x∈{0,1}，真实末位前缀负载 p_x=c_x−b_x，则

    F(c,d)+R(c,d,b)=Σ_x d_x/(p_x+1)≤|S| u_m,
    R=Σ_x[d_x/(c_x+1−b_x)−(H_(c_x+d_x)−H_(c_x))]≥0.

右端用了每个 T∈S 的真实末位最佳回复比较。R 非负逐客户来自递减调和增量。
若 d_x∈{0,1}，R 只来自末位与 O 的交集，贡献恰为1/[c_x(c_x+1)]。
因此 sufficient condition |S|u_m≤W+E+R 会闭合 harmonic 桥，但这不是一般已证性质。
不能仅把最后玩家上界代入 W 的平均收益。
