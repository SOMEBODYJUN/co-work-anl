# 可信惩罚与共享遗漏攻击（未审）

2026-10-24。研究目标仍为一般 `Q-CAG-HALF`。此区只保存本轮分工的探索；不改共享正文，不称有限阴性为证明。

## 已固定的精确检验对象

**C26（一般充分候选，非已知事实）**：对每个有限共同目录、每个人数、每份完整有序历史纯 SPE，以及每个实际位置 i，令 Z_i(A) 是在该实际历史强制 A 后原策略的真实完整终局，K_i(T,A)=Σ_(x∈T)1/(1+c_x(Z_i(A)))。候选断言 min_Q max_T E_Q K_i(T,A)≤u_i。

下面的有限实验只尝试为 C26 找到严格分离点；没有找到不能提升 C26，也不能推出 Q-CAG-HALF。

- `full_menu_cone_attack.py`：固定既有34客户完整策略的全部有序历史动作，对全部63种非空兴趣类型自由非负赋重，保留所有真实 SPE 比较。固定查询分布时用 LP 搜索 `min_A E_p K_i(T,A)>u_i`，再优化查询并交替。不冻结后继，不合并有序历史。浮点仅用于发现；严格反例必须另存整数客户、完整策略及逐行有理复验。

**P0（一般半覆盖的充分归约候选，非已知事实）**：若某 m 元组覆盖全部客户，任意完整 SPE 可实现终局 z 都可以把每个实际遗漏单位客户的兴趣改为原兴趣中一个主题（其他客户不动），令 z 仍为某个完整 SPE 可实现终局。若 owner 总能取于某个最优元组，则该比较并集保持，且遗漏变为全局私有，能调用既有私有遗漏结果。`privatization_attack.py` 只寻找这条全范围归约的反例，允许重选全部离轨子树；使用集合值 BI，不能把原策略不再最优等同于终局不可实现。

## 当前判断

真实共享遗漏构造尚未闭合：把私有花瓣扩为共享会同时降低比较联合的非重计大小；尾部集中惩罚又容易被未触及主题的末位偏离打断。这个观察不是一般定理，也不是某方法不可能的证明。

- `fixed_optimum_privatization_counterexample.md`、`audit_fixed_optimum_privatization.py`、`fixed_optimum_privatization_audit.json`：复用既有36客户底层例，精确否定**预先固定最优C**的私有化；新实例全部SPE福利36，原可达34。自含全树审计通过，独审待做。不是half反例。
- `existential_privatization_obligation.md`：明确E-path、E-count、E-cover、E-defect四种全范围候选，存在C版本仍未证。若最弱E-defect普遍成立，有限incidence下降会推出一般锐2−1/m，不仅half。条件推导自审，未独审。
- `full_menu_discovery.json`：C26在既有34客户完整策略锥的交替LP未找到严格分离，有限阴性不提升候选。
- `privatization_discovery.json`：P0初始300个提案中检验33个共享遗漏终局，未找反例。该初始脚本允许任意原兴趣owner且要求原计数可达，**没有覆盖E-defect的精确最优C量词**，不能拿来核验E-defect。
