## 精确对象及行

采用 CAG-MODEL，任意总人数 m、有限共同目录和单位客户。q 是合法已有动作计数，q 的总数至多 m−2。对合法主题 A，在强制当前加入 A 之后，余下玩家须在全部有序历史上构成纯 SPE；强制者本身不接受最优性约束。令

\[
\ell(q,A)=\min_{\kappa\in\mathrm{SPE}(q+e_A)}U_A(q+e_A;\kappa).
\]

这里 U_A 是那一名已加入 A 的玩家的终局收益。有限非空续局集保证极小值可达到。固定任意达到极小值的完整续局 κ_(q,A)，令 C 是其第一位后继的真实规定主题，z 为其终局。那么

\[
\boxed{\ell(q+e_C,A)\le\ell(q,A).}\tag{1}
\]

证明只需保留真实尾：κ_(q,A) 在第一行动 C 之后的完整子 SPE，是背景 q+e_A+e_C 上的合法尾。把 A 和 C 的加入顺序交换后，经济背景仍为同一个计数；这个尾可平移为定义 ℓ(q+e_C,A) 时的一个可行候选。两名 A 玩家（若 C=A）在该候选中也取得相同的均分收益。因此这个候选给原 U_A(z)=ℓ(q,A)，新极小值至多为它。

这没有声称将更小尾放回 κ_(q,A) 后，其第一后继 C 仍最优。新的尾可能降低 C 的收益并破坏其原 IC。下例严格展示这种情况。

更一般地，原尾 κ 不必达到极小值：只要 κ 是强制 A 后的一份完整 SPE，C 为其首回复、z 为其终局，同一可行候选论证就给 `ℓ(q+e_C,A)≤U_A(z)`。这允许保留旧 reset 规范形的整棵原零信号树，仅对交换后的 clone-A 施极小重置。

在旧 reset 规范形的重复标签辅助博弈中，先强制 clone-A，得到 κ_(q,A)；另先强制 clone-C，再在下一位强制 clone-A，即得到 κ_(q+e_C,A)。所以 (1) 可作为同一规范化完整策略的两条真实分支之间的非负行。对任意未规范化 σ 的实际原回复，则不能未经证明加入 (1)。最终覆盖证明若使用 clone 的共同查询性质，应保留辅助标签直到支付结束，再用根 W、OPT 保持回到原模型。

当原位置只剩三人时，写 q 的逐客户负载为 p，A、首回复 C、原末回复 S、交换后极小末回复 Z 的会员位为 t,c,s,z。S 和 Z 都是经济背景 q+A+C 下的真正末位最佳回复，因而有等式及额外极小性行

\[
\sum_x\frac{s-z}{p+t+c+1}=0,\qquad
\sum_x\frac{t(z-s)}{(p+c+1)(p+c+2)}\ge0.
\]

第二式是旧 A 玩家收益差，不是普通末位 IC。实现中若仅自由引入 Z 而不接共享身份，必要条件松弛可能选 Z=S 而使新行为零；尚不能据此声称切掉某个既有坏点。

## 一个严格的六人局部例

四个目录主题编号 0,1,2,3。客户按兴趣类型及单位重数给出：

| 兴趣主题 | 重数 |
| --- | ---: |
| {1} | 1 |
| {0,2} | 2 |
| {1,2} | 2 |
| {0,1,2} | 2 |
| {3} | 1 |
| {0,3} | 2 |
| {1,3} | 2 |
| {0,1,3} | 1 |
| {0,2,3} | 2 |

共 15 个不同单位客户；四个真实覆盖集合不同。总人数 m=6，固定过去有序历史 (0,1,1)，即 q=(1,2,0,0)，强制当前查询 A=3。

剩两人的完整纯 SPE 中，已加入 A 的最低收益为 71/30；一个达到者的规定尾是 (3,2)，故 C=3=A。把 C 前移，固定历史变为 (0,1,1,3)，再强制当前 A=3 后只剩末位。末位的最佳回复为 0 或 2；选择 0 时旧 A 玩家收益最低，为 13/6。因此

\[
\ell(q,A)-\ell(q+e_3,A)=71/30-13/6=1/5>0.
\]

原两人尾的第一位若选 3，再把其真实末回复 2 替为更伤 A 的末回复 0，第一位自身的收益也从 71/30 降至 13/6。其 outside-option 门槛为 67/30，大于 13/6=65/30，因此它会改选别的合法主题，这种尾替换不能免费作为原父节点的 SPE 子局。

`verify_minimum_reply_commutation.py` 从 15 个独立单位客户直接计算 Fraction 收益，穷举这项背景下全部 4⁵=1024 份完整两人策略；逐一检查全部末位历史和首位偏离，随后对全体合法 tail SPE 取 A 收益极小值。对交换后的一人尾则穷举全部四个动作。它不调用规范求解器，不把该局部严格例称为 Q-CAG-HALF-6 反例，也不声称 q 在某个坏根终局的实际路径上。
