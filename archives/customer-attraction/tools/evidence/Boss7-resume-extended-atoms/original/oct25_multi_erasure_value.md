## 1. 从条件保留定义独立推导 a 与 q

固定原 r 位决策身份、保留数 `1<=n<=r`、合法固定旧背景 b。所有 r 位仍在原有序树中行动，擦除只改变终局收益。对客户 x，原剩余覆盖者数 t>0；当前覆盖者 i 条件保留，再从其余 r−1 人均匀选 n−1 人。令 a(t) 为条件后的当前份额，`K~Hyp(r,t,n)` 为无条件 n 元子集里的覆盖者数，定义

`g_b(0)=0, g_b(t)=t/(b+t)`。

无条件保留后，所有保留覆盖者在该客户获得的利润和为 g_b(K)。t 位原覆盖者对称且各有保留概率 n/r，所以

`t(n/r)a(t)=E g_b(K)`。

令 `kappa=r/n`，则 `t a(t)=kappa E g_b(K)`。当前原份额为 `u(t)=1/(b+t)`；定义 `q(t)=kappa/(b+t)−a(t)` 后得到

`t q(t)=kappa[g_b(t)−E g_b(K)]>=0`，

因为 K<=t 且 g_b 单调。故逐客户、逐角色均有 `a_i=kappa u_i−q_i, q_i>=0`。这不依赖 SPE，也没有把旧背景玩家算成保留身份。

空背景时，g_0(K) 是 K>0 的指示量，故

`a(t)=r/(nt)[1−C(r−t,n)/C(r,n)]`，

`q(t)=r/(nt) C(r−t,n)/C(r,n)`。

这与新稿一致。背景 b>0 时不能继续套该组合数闭式；新稿改用条件超几何和正确。t=0 时资源贡献定义为0；n=r 时 a=u、q=0；r=1,n=1 也退化为零损失。

## 2. Q 只计剩余者，确是一份同实际叶的钱包

对同一个原 r 槽叶 z，令 `U_b(z)=sum_x g_(b_x)(t_x)`，它只计剩余 r 位玩家利润。对所有角色的 q 求和，逐客户有 t 个相同 q，因此精确为

`Q_n^b(z)=sum_i q_i(z)=kappa[U_b(z)−E U_b(z_K)]`。

背景原玩家的 `b/(b+t)` 没有进入 U_b。若将它误加进去，擦除使这部分增加，原单调方向就不能原样使用；正文没有犯这个错误。

上界可不靠近似证明：对 `0<=k<=t`，凹函数 g_b 从原点的弦界为 `g_b(k)>=(k/t)g_b(t)`，又 `E K=nt/r`，故

`0<=Q_n^b(z)<=(r−n)U_b(z)/n`。

空背景改写为

`Q_n(z)=r/[n C(r,n)] sum_(t=1)^(r−n) C(r−t,n)E_t(z)`。

因此单删只看 E_1；多删也看低重数共享客户。它们并不是每个删除子集可各自重复领取的池，而是一次平均擦除的同叶总损失。

## 3. 原真实行的共同付款及不能混池的历史量词

固定原完整 SPE sigma。在**一个给定原有序历史 h**，当前身份 i、同一个合法查询 A，对规定后按 sigma 继续和强制 A 后按 sigma 继续的真实叶记为 z_S、z_A。原 IC 的 `Gamma=u_i(z_S)−u_i(z_A)>=0` 给

`gain_a=−kappa Gamma+q_i(z_S)−q_i(z_A)`。

这是辅助 r 身份树上的真正行，任意离轨 h 也成立，因为没有删除原决策节点。但它并不让任意离轨行共享原实际叶 z 的 q_i(z)。

沿**同一原实际路径**的 h_i，所有规定叶均为同一个 z。对非负完整行系数、每个角色满足 `sum_A lambda_(i,A)<=1`，精确有

`sum lambda[gain_a+q_i(z_(i,A))]+kappa sum lambda Gamma`

`=sum_i(sum_A lambda_(i,A))q_i(z)<=Q_n^b(z)`。

左侧每条行包含其自身偏离叶的负信用以及原 IC slack，没有先取各删除身份/查询的最大值。行质量条件按每个角色**所有被使用查询的总质量**计算，不能对每个 A 各设1，也不能对每个离轨 context 各设1再放到同一个实际角色钱包里。

任意离轨 h 上仍可写局部 q_i(z_h)，但 z_h 通常不同；即使每个 h 各有一份局部质量<=1，也不能把这些钱包认作实际叶的 Q。新稿(4)只对实际路径声称共同池；(3)的全历史辅助行与(4)的同叶共同预算是不同量词，没有偷换。

若要解释为物理多删回放，必须同时保持保留角色 i、原历史 h 和查询 A。原实际路径所有过去行动按 sigma，因此所有相关保留子集可因果对齐。任意离轨 h 中，被擦去的过去行动若不同于 sigma 规定，则统一虚拟回放重建的原历史会改变；不能说这些物理回放自动全对齐。新稿对这一点的界限正确。

## 4. 辅助类闭包没有生产物理可信性

辅助资源价值为 `f_(r,n),b(t)=kappa E g_b(K_t)`，其对称分享为 f(t)/t=a(t)。加入第 t 个活跃身份时，条件该身份被样本选中后，其余活跃采样数 `L~Hyp(r−1,t−1,n−1)`，所以增量为 `E[g_b(1+L)−g_b(L)]`。用同一均匀样本耦合，L 随 t 不减；g_b 的离散增量非负递减，故 f 保持单调凹。

此处 r 个原身份仍作决策。原 sigma 在辅助收益下有预算化偏离行；它并非 n 人物理游戏的 SPE。辅助价值核也不同于原空背景首次覆盖核，单调凹闭包不能授权调用待证的 CAG half。原 round4 的虚拟计划同样允许全历史定义，却通常不是物理删后 SPE；本次没有跨过这一旧缺口。

## 5. 损失势全 t 闭式与端点的独立重构

不条件化身份保留后，`v=(n/r)a=u−ell`，其中

`ell(t)=1/(b+t)−(n/r)a(t)=(n/r)q(t)>=0`。

所以新稿的 q 合同和 ell 合同只是缩放后的**同一笔信用**。令 `psi(t)=sum_(s=1)^t ell(s)`、`H_b(t)=sum_(s=1)^t1/(b+s)`。在 r 个标签中固定一次均匀 n 元样本 J，把前 t 个标签视为覆盖者，记 `K_t=|J cap {1,...,t}|`。逐个加入标签 s 时，被保留的第 j 位贡献 `1/(b+j)`，故

`sum_(s=1)^t E[1{s in J}/(b+|J cap {1,...,s}|)]=E H_b(K_t)`。

每项左边正是 `(n/r)a(s)`，从而

`psi(t)=H_b(t)−E H_b(K_t)`。

在 t=r 时 K_r=n 恒定，因此

`psi(r)=H_b(r)−H_b(n)=sum_(s=n+1)^r1/(b+s)`。

ell 非负给 psi 随 t 不减，故对**固定**客户集合 B、固定背景 b、固定 r,n，在所有原 r 槽叶上共同有

`0<=Psi_B(z)<=sum_(x in B)sum_(s=n+1)^r1/(b_x+s)<=(H_r−H_n)|B|`。

这是终局势范围，不是一份独立于 Q 的预算，也不是每个分支各有一份范围。r,n 在删当前槽取边际时仍保持不变；若把它改成 r−1 核，就不是本公式了。

## 6. 整势流望远镜成立；当前删槽 reset 没有消失

把 `F(h)=Psi_B(z_h)` 看作完整原树每个节点的一个固定数。对单位根流量、内部节点入流等于出流的保守行动流 f，普通节点相消精确给

`sum_(h,A) f(h,A)[F(h)−F(hA)]=F(root)−E F(Y)`。

因而带符号整势差至多 `(H_r−H_n)|B|`。不需要干预流本身是 SPE；需要它确实是同一棵树上的一个保守流，不能用若干互斥分支各自单位流冒充单位共同流。各边差的**正部之和**不会由同一范围上界控制，新稿正确保留这一限制。

当前身份 i 对 B 的 ell 份额是离散势边际：

`ell_i^B(z)=Psi_B(z)−Psi_B(z\i)`。

所以个人损失差精确为

`ell_i^B(z_h)−ell_i^B(z_hA)=Psi_B(z_h)−Psi_B(z_hA)`

`−[Psi_B(z_h\i)−Psi_B(z_hA\i)]`。

第一个方括号可用上述整势流。第二项沿边删的是该边**当前身份**；下一层当前身份换了，不能把它当作同一个节点函数继续相消。若强行定义节点函数 `G(h)=Psi_B(z_h\i(h))`，到达 h 的前一条边却用的是 `Psi_B(z_h\i(parent(h)))`，内部节点正留下两种删槽身份的 reset 差。其符号不固定，范围也没有为每个内部节点额外付钱。正文 RESET 正是保留了这笔余项；没有漏掉它。

另须继续保持 B 的范围：取 B 为原实际覆盖集合 C，可得到与实际 W 成比例的**受限势**范围；RESET 中此时 ell_i 也只能计 C 内客户。实际路径上 C 外的规定损失为0，偏离叶上的 C 外损失是可保留的负信用；但在任意离轨干预节点，规定叶也可能覆盖 C 外客户，不能把其完整个人损失都称为 Psi_C 的边际。新稿明确写了“ell_i 仅计 B 客户”，故本身没有犯错；未来覆盖行分解若使用全历史流，必须保留这个受限客户集条件或另计 C 外项。
