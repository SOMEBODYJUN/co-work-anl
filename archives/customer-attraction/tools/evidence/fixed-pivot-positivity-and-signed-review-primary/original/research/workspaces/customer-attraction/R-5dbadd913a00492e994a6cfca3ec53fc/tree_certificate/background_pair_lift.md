# 共同非负客户的任意背景双主题回路提升

2026-10-23。个人研究草稿，尚待独立重构。采用 CAG-MODEL；本页各结论是逐客户的普遍不等式或恒等式，不要求策略为 SPE。一般 Q-CAG-HALF 仍 OPEN。

## 1. 对象与完整量词

有限客户集 N，有限共同主题标签集 P；标签 a 代表客户子集 A_a。客户均为单位价值。取不同标签 a,b，整数 r≥s≥1，以及任意非负整数主题计数向量 z∈Z_{≥0}^P。**允许 z_a>0、z_b>0**；z 可含任意多个不同标签。三个需要的终局计数均有同一总人数 |z|+r+s：

\[
q=z+r e_a+s e_b,\qquad q'=z+s e_a+r e_b.
\]

对于 q_c>0，U_c(q) 是终局中选 c 的一名提供者收益。定义背景提供者的总收益

\[
B_z(q)=\sum_{c:z_c>0}z_cU_c(q).
\]

因为 q≥z，所有调用的 U_c 都有正行动计数；z_c=0 的项不求值。若 z=0，则空和为零。对于客户 x，记

\[
\alpha=\mathbf1_{x\in A_a},\quad \beta=\mathbf1_{x\in A_b},\quad d=\sum_cz_c\mathbf1_{x\in A_c}.
\]

d 是客户看到的背景提供者数，而不是客户价值。上述定义仍适用于 z_a 或 z_b 非零。该客户给 B_z(q) 的贡献为 d/[d+rα+sβ]；若 d=α=β=0，约定贡献零（因为没有背景/所选行动覆盖它）。

记 C_b=|A_b|。定义原无背景双主题身份的误差

\[
E_{ab}^{r,s}(z)=rsU_a(q)+r(r-s)U_b(q')-s^2U_a(q')-(r-s)C_b.
\tag{1}
\]

## 2. 非负客户提升引理

**精确枢轴租金版（root独立重构后指出）。** 定义背景提供者仅在枢轴客户上的租金

\[
R_{z,b}(q')=\sum_{x\in A_b}\frac{d_x}{d_x+r+s\mathbf1_{x\in A_a}}.
\]

则第一张四格表直接给出更强的精确式

\[
\boxed{E_{ab}^{r,s}(z)+(r-s)R_{z,b}(q')
=s(r-s)\sum_{x\in A_a\setminus A_b}
\frac{d_x}{(d_x+r)(d_x+s)}\ge0.}
\tag{2a}
\]

只需在 A_b 上支付背景租金；没有必要冗余收费全部背景客户。R_{z,b}(q')≤B_z(q')，故下述较松版本随之成立。L2进一步将不同a共享b时的租金变化与正余项同时合并成一个正测度差。

**引理 L1。** 对上述全部对象，

\[
\boxed{E_{ab}^{r,s}(z)+(r-s)B_z(q')\ge0,}
\qquad
\boxed{E_{ab}^{r,s}(z)+(r-s)B_z(q)\ge0.}
\tag{2}
\]

故任意 θ∈[0,1] 也允许用 θB_z(q)+(1−θ)B_z(q')。r=s 时式子退化为零，z=0 时(1)恢复旧双主题恒等式。

**证明。** 设 h=r−s。每个客户给 E 的贡献为

| (α,β) | E 的贡献 |
| --- | --- |
| (0,0) | 0 |
| (1,0) | shd/[(d+r)(d+s)] |
| (0,1) | −hd/(d+r) |
| (1,1) | −hd/(d+r+s) |

对于 d=0，此表全部为零；没有使用 0/0。将背景总收益加入，逐客户余项如下。

| (α,β) | E+hB_z(q') 的贡献 | E+hB_z(q) 的贡献 |
| --- | --- | --- |
| (0,0), d=0 | 0 | 0 |
| (0,0), d>0 | h | h |
| (1,0) | hd(d+r+s)/[(d+r)(d+s)] | hd(d+2s)/[(d+r)(d+s)] |
| (0,1) | 0 | h²d/[(d+r)(d+s)] |
| (1,1) | 0 | 0 |

所有量非负，求和即得。此处非负客户假设不可省；这不是对任意有符号客户成立的身份。证毕。

## 3. 同背景、共享枢轴的误差精确相消

再取标签 c≠b；允许 a=c 时退化。对 E_cb 使用同一 r,s,z,b。虽然 a,c 的终局不同，但 z 的各主题计数固定；特别地，即使 z 含 a,b,c，以下仍逐客户成立。记 γ=1_{x∈A_c}。

**引理 L2（共享枢轴差分）。**

\[
\boxed{E_{ab}^{r,s}(z)-E_{cb}^{r,s}(z)
=s(r-s)\sum_{x\in N}
\frac{(\alpha-\gamma)d}{(d+r)(d+s+r\beta)}.}
\tag{3}
\]

右侧 d=0 的项为零，所有其余分母正。证明直接由 L1 的第一张四格表相减：β=0 时系数为 s(r−s)d/[(d+r)(d+s)]；β=1 时为 s(r−s)d/[(d+r)(d+r+s)]。

等价地，固定 b,z,r,s 后，令

\[
k_{b,z}^{r,s}(x)=\frac{s(r-s)d_x}{(d_x+r)(d_x+s+r\mathbf1_{x\in A_b})}\ge0,
\qquad \mu_{b,z}^{r,s}(A)=\sum_{x\in A}k_{b,z}^{r,s}(x).
\]

存在与 a 无关的常数 K（可直接取 K=−(r−s)Σ_{x∈A_b}d_x/(d_x+r)），使

\[
\boxed{E_{ab}^{r,s}(z)=K+\mu_{b,z}^{r,s}(A_a).}
\tag{4}
\]

这是共同非负客户给出的正测度表示。它比对每个 E 单独支付一次 B_z 更精确：共享枢轴下，大的负背景项是同一 K，能够消去。

**流形式推论。** 对任意有限非负有向边权 λ_ac，

\[
\sum_{a,c}\lambda_{ac}(E_{ab}-E_{cb})
=\sum_x k_{b,z}^{r,s}(x)\sum_{a,c}\lambda_{ac}
(\mathbf1_{x\in A_a}-\mathbf1_{x\in A_c}).
\tag{5}
\]

因此每个标签的入流等于出流时，整个误差和**精确为零**，不论有多少标签或多少回路，也不用逐个付背景总收益。对于从 a_0 到 a_l 的链，误差只等于 μ(A_a0)−μ(A_al)，不会随链长累积。平衡只对实际使用的 E_{ab} 端点要求；不能未经核验把任意真实策略树的回路宣布平衡。

## 4. 三人活动块的统一小误差

当 r=2,s=1，

\[
k(x)=\begin{cases}
d/[(d+2)(d+1)],&x\notin A_b,\\
d/[(d+2)(d+3)],&x\in A_b.
\end{cases}
\]

对整数 d≥1，第一项≤1/6，第二项≤1/10；d=0 时为零。证明分别是
(d+2)(d+1)−6d=(d−1)(d−2)≥0，
(d+2)(d+3)−10d=(d−2)(d−3)≥0。
故

\[
E_{ab}^{2,1}(z)-E_{cb}^{2,1}(z)
\le \frac16\bigl|(A_a\setminus A_c)\cap\operatorname{cov}(z)\bigr|,
\tag{6}
\]

还可把与 A_b 相交部分的1/6换成1/10。反向同理。这是任意人数、任意背景支持大小的界；没有假定只有第三主题一种背景。

## 5. 与一般目标的准确距离

L1—L2 提供一个可任意人数使用的非负客户补偿核，以及共享背景/枢轴下不累积的误差流。它们本身没有保证真实 SPE 的全树激励能按这种固定 z,b 的平衡流拼接；真实早期偏离可能改变 z。仍缺少将所有未覆盖最优客户的激励输入转成根路径二预算的中继机制。

不能把(5)的形式误差消去等同于得到所需真实激励的非负乘子，也不能省略离轨历史和任意平局。下一步需要：构造实际可用的平衡流，或给当 z,b 改变时仍有总成本控制的势。
