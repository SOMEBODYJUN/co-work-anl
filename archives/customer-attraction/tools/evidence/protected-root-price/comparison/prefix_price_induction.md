# 任意前缀归纳：仍开放的不变量及明确承重缺口

2026-10-21。探索记录，不是定理。一般 Q-CAG-HALF 仍 OPEN。

## 整体背景候选与已知局部障碍

固定任意合法有序背景，负载 `b`，剩余 `r` 人，并固定该子局任意全历史纯 SPE。记剩余玩家在其实际终局的总收益为 `P`，其新增覆盖为 `Delta`，至多 `r` 个主题在原背景未覆盖集上的最优覆盖为 `O_r(b)`。自然整体候选是

```
P + Delta >= O_r(b).                                  (GLOBAL)
```

空背景时 `P=Delta=W`，故该版本恰含一般 half。背景时绝不能把 `P` 等同于完整福利。

`R-2fc8878b4bdd4328bbc1bcf1df8ca831/background_induction/coverage_opportunity_step_obstruction.md` 已给 23 客户合法背景 `(2,5)`、剩三人的完整 SPE，否定直接首步机会式

```
u_first + fresh(A) + O_(r-1)(b+1_A) >= O_r(b).
```

该例首步缺口 `-1/10`，尾部实际整体余额 `48/10`，整条余额 `47/10`。因此只保留尾部余额非负的朴素归纳不足；没有否定 GLOBAL 本身。

## 新鲜价格候选

令 `F_b={x:b_x=0}`。一般人数的新候选是

```
B_(F_b)(u_first) <= sum_(later actual players) u_i.      (FRESH-PRICE)
```

恰一人时左侧零：末位最佳回应的收益至少每个主题在 `F_b` 的客户数。恰两人时本文同目录 `fresh_and_protected_tail_price.md` 已证明更强的两个备选预算。

但尚无一般归纳步。偏离一个主题后，子局的价格集变成 `F_(b+1_T)`；被 `T` 覆盖的新客户正是根价格目标的一部分。其后继利润与另一个子树的实际利润不能逐人比较。同负载前缀也不可强制同续局。上述两人结论不能把多名真实后继偷换成一个最佳回复者。

即使 FRESH-PRICE 为真，单独代入 `r` 个比较主题只给 `O_r(b) <= r u_first+P_tail`，不自动推出 GLOBAL。还缺一项把 `r-1` 份首位收益与实际新增覆盖共同支付的非局部预算。

## 保护价格更强候选

固定一个客户集 `D`，满足它与该子局完整实际终局及原背景均不交。两人已知

```
B_D(u_A) <= u_B/2,
max_T |T intersect D| <= u_B.
```

一个尚未证明、正在用完整策略锥攻击的更强二人候选是

```
B_D(u_A) <= max(0,u_B-u_A).                            (PROTECTED-SHARP?)
```

当 `u_A>=u_B`，此式已由实际末位逐主题保证成立，因为 `B_D(u_A)=0`。只有 `u_A<u_B` 的部分未知。若成立，对任意由两个比较主题覆盖的 `D` 有 `|D|<=u_A+u_B`：`u_A<=u_B` 用价格候选，`u_A>=u_B` 用末位 `|D|<=2u_B`。

该候选严格强于已知菜单价格界。在 `u_B/2<u_A<u_B` 区间，已知 `B_D(u_A)<=u_B/2` 不能替代它。共同目录允许首位进一步偏离真实回复 `R_T`；可能需要沿真实回复图重复使用这些行，不能只依赖目前三类菜单平均。

无克隆三类菜单还支持一族弱预算：对 `c in [1,2]`，取 `c S+(1-c/2)Z/tau+c V/tau`，有

```
sum_(x in D) min(1,d_x) <= c tau u_A+(1-c/2)u_B.
```

逐类型证明与已知保护价格相同；这族对未知区间没有消去缺口，不能作为更强候选的证明。
