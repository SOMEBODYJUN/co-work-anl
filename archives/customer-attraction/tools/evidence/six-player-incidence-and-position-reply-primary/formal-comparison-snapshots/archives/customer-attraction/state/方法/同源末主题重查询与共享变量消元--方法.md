# 同源末主题重查询与共享变量消元

状态：七行局部恒等式、任意剩余人数推广和共享变量消元边界已证并独立复核；它们只生成合法局部必要行，不完成全局半覆盖证明。

本条目整理 R-07e871 `three_certificate_comparison` 组。研究对象是完整有序历史纯 SPE；任何强制偏离都在同一个完整历史策略中继续，平局规则保留。这里的关键增量是把不同强制分支中仍然具有同一目录身份的真实末主题作为**共享变量**，在消元前联合处理。

## 1. 余三人同源重查询的七行恒等式

固定任意真实源历史 h，此后尚余 k>=3 人，背景客户负载为 p_x，当前规定行动者的终局收益为 r。强制源选 T，原策略真实后继记为 F_1,...,F_(k-1)，最后两位为 B,C。然后在**同一个历史 h**再次强制选第一分支产生的真实末主题 C，第二分支后继最后两位记为 J,V。Q 是任意合法查询；实际终位收益为 u_m，实际终位前负载为 ell_x，共同目录最大主题大小为 K。

对客户会员位 t,q,b,c,j,v 以及中间后继计数 s,s'，令

    z1=p+t+s+b+c,
    z2=p+c+s'+j+v.

七个真实非负 slack 的权重为：

| 来源 | slack | 权 |
| --- | --- | ---: |
| 源对 T 的 IC | r-a_T | 2 |
| 同源对 C 的 IC | r-a_C | 3/2 |
| 第二分支末位 V 查询第一分支 B | w_V-份额(B) | 1/2 |
| 实际末位查询 J | u_m-份额(J) | 1/4 |
| 实际末位查询 V | u_m-份额(V) | 5/12 |
| 共同容量 | K-|V| | 1/12 |
| 第一分支末位 C 查询 Q | w_C-份额(Q) | 1 |

加权七行恰等于

    (7/2)r+(2/3)u_m+K/12 - sum_x F_k(x),

其中

    F_k=(2t-c)/z1 +(3c-v)/(2z2)
        + b/[2(p+c+s'+j+1)]
        + j/[4(ell+1)] + 5v/[12(ell+1)] + v/12
        + q/(p+t+s+b+1).

定义 phi_k(p,ell,t,q)=-min F_k，最小值对 b,c,j,v∈{0,1}、s,s'∈{0,...,k-3} 取；零分子份额定义为零。逐客户加上 F_k-min F_k 后得到合法局部行

    (7/2)r+(2/3)u_m+K/12+sum_x phi_k(p_x,ell_x,t_x,q_x) >= 0.   (R)

证明只使用同一源历史的两个真实 IC、同一目录下的末位报价和容量，未把互斥分支的利润识别成同一数值。若 T=C，策略要求在同一历史下使用一致续局；相同覆盖的不同标签仍按同一身份约束处理。

## 2. 任意 k 的精确压缩

两条分支各有 k-1 个隐藏二元后继位，字面枚举为 2^(2(k-1))。在 (R) 中，中间 k-3 位只通过 s、s' 的总数出现；因此扩大位域后的最小值恰等于枚举

    16(k-2)^2

个 `(b,c,j,v,s,s')` 候选。`nested_requery_horizon.py` 以独立实现验证 k=3,...,7 的 48 个可见状态：字面与压缩最小值逐格相同，候选数从 16、64、256、1024、4096 压到 16、64、144、256、400。对 8 份六人完整有序历史纯 SPE，在 k=3,...,6 的全部 288 个源历史、每个合法 T,Q 上，共核对 3568 条不等式和恒等式，全部通过 Fraction。

源深度为 m-k 时，0<=p<=m-k，实际末位前仍有 0<=ell<=m-1；若源是实际路径上的对应位置才有 p<=ell<=p+k-1，离轨源不能擅自使用这个包含关系。

## 3. 共享变量先合并后投影严格更强

若两条合法关系都依赖同一个隐藏变量 z，分别消元给出

    sum_a lambda_a min_z h_a(z),

而先合并再消元给出

    min_z sum_a lambda_a h_a(z)
      >= sum_a lambda_a min_z h_a(z).

若各项的最小化赋值冲突，严格不等。最小合法例是两人、一个客户、唯一主题 T={x}：完整 SPE 中 r=1/2、K=1。源 IC 和加容量行分别为 A(g)=1/(1+g)、B(g)=1/(1+g)+g。分开消元得 2r+K>=3/2；共享同一 g 后 min_g[A(g)+B(g)]=2，得到 2r+K>=2，且真实 SPE 取等。严格增益来自共享目录身份，不是一个 SPE 反例。

因此“先分别投影每条分支，再把钱包相加”会丢失同一主题可被另一分支查询的约束。新行若含跨族同索引乘积，也必须保留联合极大化，不能只用各族边际直方图。

## 4. 可复用范围与证明边界

这一方法在任意总人数 m、任意 k>=3 的真实源节点有效；它是局部行生成器，可与实际末位统一价格、共同 K 和早期真实 IC 组合。它没有证明一组全局非负乘子能把所有客户类型的 `OPT-2W` 消掉，也没有把不同强制主题的真实回复菜单合并成同一全局目录。故它应归入“方法/条件结论”，不能归入一般 half 定理。
