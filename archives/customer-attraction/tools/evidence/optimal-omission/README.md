# 最优遗漏族的冻结来源与精确核验

数学入口：

- [完整辅助桥反例族](../../../state/反例/唯一最优组合的全遗漏支付--反例.md)。
- [12类与14类输入的二人等价及三人边界](../../../state/等价/两份最优遗漏输入的二人收益等价--等价.md)。
- [程序、证书和完整来源说明](../../../state/计算/最优遗漏族的逐客户与线性证书--计算.md)。

PROVENANCE.json列七份已全文读取的冻结来源、两个提交入口及SHA-256。original/保留原字节和原目录，未更改源码、报告或发现输入；相对依赖不存在，两个原脚本只用标准库及内置兴趣表。

replay/author-report.json和replay/independent-report.json来自两个原程序各一次本轮实际运行；均与对应冻结原报告全部JSON及字节相同。original-runs-manifest.json保存完整命令、Python版本、断言启用和比较结果。两个空stderr文件是实际执行收集，不是未运行占位。

audit_candidate_equivalence.py是本轮新写的定义级关系核验：读原候选JSON和作者代码字面GROUPS，分别展开71客户，检查两人完整策略、72终局收益、21并集及三人收益差。它不导入旧审计，不调用优化器，显式拒绝关闭断言。唯一一次新输出和运行记录保存在replay/candidate-comparison.json及candidate-comparison-manifest.json。

从仓库根可直接运行两个original/下的审计或本目录新比较程序；它们默认只写stdout，不覆盖已存证据。两个原程序依赖assert，须不用-O/-OO；本轮命令使用python3 -E -B。独立原程序可选--output采用独占创建，但需预先存在父目录。

原候选的优化成功状态只属历史发现元数据；没有原发现目标、搜索代码或最小性证书。本目录不将它升级为数学证明。两个原报告与新输出的身份和独立性均在计算正文说明；本轮重放不是新盲审。
