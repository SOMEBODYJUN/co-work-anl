# 同一策略末回复循环的完整债务身份

固定r>=2节点与原完整策略。强制A后末位回复q(A)，中间r-2动作B(A)。有限映射A->q(A)存在循环A1,...,A_l、q(A_j)=A_(j+1)，允许l1。Q为这些真实完整r槽终局的均匀混合，是查询独立的合法静态背景，不只保r-1尾。

\[
\Theta=\frac1l\sum_j(V_j-D_j)
=\frac1l\sum_j[\tau_b(B_j,A_j)-\tau_b(B_j,q(A_j))].
\]

对任意合法查询T，F_j(T)=sum_T1/[b+d_j+1+1_Aj]是该真末节点偏离收益；M_j(T)=sum_T1/[b+d_j+1+1_Aj+1_qj]是完整r槽后额外插入的静态值。L_j=V_j-F_j>=0由末位BR；H_j=F_j-M_j>=0，精确等于T∩q_j上1/[(b+d_j+1+1_Aj)(b+d_j+2+1_Aj)]之和。实际根u>=D_j，所以

\[
\boxed{u-\mathbb E_Q M(T)=\mathbb E(u-D_j)+\mathbb EL_j(T)+\mathbb EH_j(T)-\Theta.}

所有正余项均来自同一策略真实根/末节点，只有Theta未付。r2中B空、循环消去Theta，恢复正面界；更多后继时不能假定Theta非正或删去。这个恒等式不证明存在可支付的循环、更不证明任意自由菜单低值；换背景、同计数不同有序历史仍全部沿原sigma。
