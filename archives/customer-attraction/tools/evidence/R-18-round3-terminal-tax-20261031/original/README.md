# 一般半覆盖：本次主线程、准确状态与接续

主目标 Q-CAG-HALF 仍 OPEN；保留原模型的任意共同目录、任意人数、全部有序历史纯 SPE 及任意历史依赖平局。恢复依据为 main 的实际文件与原 Boss5 actor，而非聊天摘要。六个指定模型研究员独立推进；个人文件与未审候选不自动成为共享可靠结果。

## 已经改变的认识

`../round3_counterexample/regret_replication.md` 自足构造任意 k 个四客户块，给完整纯 SPE：m=2k、W=OPT=4k、所有实际收益2、静态总正遗憾 R=k/2。因此对任意固定有限 C，取整数 k>4C，R>C W/m。此结果排除以“人均福利量级总静态正遗憾”支付一般覆盖缺口的加强桥；由于本族完全覆盖，不排除允许 R 与 W 同阶的更弱桥，也不反驳 half。

Boss 独立检查：五态内部合法转移恰 E→Y、E→Z、Y→XY、Z→ZZ，槽数每步减少一；所有其他子树永久交给 BI。即时收益只随未来覆盖减少，唯一超出规定收益的 E→Z 偏离由规范续局补为 ZZ 后降到3/2，故全历史归纳成立。静态 Y→Z 份额为1/2+1+1=5/2，X→Z 为1+1/2+1/2=2。已重跑作者 Fraction 状态审计，并调用另一份零导入独审的 audit(1)、audit(2)，共263有序节点、1566含自身比较通过；这些有限结果只验证实现，一般 k 依赖写出的归纳证明。外审和新颖性未认证。

## 全终局税候选：仍开放

精确候选 FT：每个原模型完整纯 SPE 的实际终局负载 c 满足

    OPT_m <= W + tau_full,   tau_full = sum_{x:c_x>0} c_x/(c_x+1).

这是已有 `two_remaining_tax.md` §6 中未解决的较弱税候选，不是新提出的定理。若 FT 成立，tau_full≤mW/(m+1)，故足够推出 half。前 m−1 位根税的反例不直接否定 FT。

- `full_terminal_tax_probe.py`、`full_terminal_tax_probe_run.json`：对根税四人固定策略、经典 m=1..5 完整策略及两类五人可信续局变体，共14个指定锥，优化 `(比较覆盖−tau_full)/W`。最优浮点端点均用 Fraction 验证可行；没有大于1的端点。经典家族值为 `1−1/[m(m+1)]`。没有给所有这些锥恢复完整对偶，不能称为锥上的普遍上界。
- `full_terminal_tax_joint.py`、`full_terminal_tax_joint_m3p4.json`：复用已有 `cone_attack_joint_milp.joint_candidate` 全树约束，只替换一次目标行，并保存基础函数源码哈希。三人四主题固定路径012、001、000的数值发现后，重新对所得完整策略锥求有理可行点。分别得到1/2、13/18、11/12；它们是指定锥可行目标值，数值联合“最优”不称精确认证。
- `../round3_independent/full_tax_milp.py` 及运行：独立模型覆盖更多比较组合交叠类型，部分运行触及时限。无反例不证明 FT，超时没有数学真值含义。

本线程停止重复延长相同有限无反例搜索；优先解析控制跨分支菜单、低阶交集表示或可信异常子树。FT 与真正聚合安全值预算、弱逐人 OPT/(2m−1) 和 (OPT−W)/m 桥各自仍未闭合。

## 下一步与实际缺口

副本协议的有价值技术是“即时收益安全分支 + 少数显式可信异常分支 + 完整 BI 接管”，而不是增加有限样本。要把它用于主目标反例，须构造真正未覆盖客户，并保证最后惩罚玩家不能跨块套利；直接往 Z 加隐藏客户不能保持原证明。

正面证明仍缺少把不同真实偏离分支的收益/覆盖损失支付到同一实际福利的全局机制。不能冻结后继、合并有序历史的选择、强迫每期余额非负，或把抽象对称精确势性质当作 CAG 的全部结构。
