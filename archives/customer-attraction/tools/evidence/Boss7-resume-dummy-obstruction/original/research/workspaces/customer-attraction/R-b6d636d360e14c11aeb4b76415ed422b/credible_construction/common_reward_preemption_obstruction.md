# 公共奖池惩罚的抢先选择障碍

2026-10-23，Boss3 分支个人工作稿。一般 `Q-CAG-HALF` 仍 OPEN。
工作稿身份：`CC-COMMON-REWARD-PREEMPTION-v1`。父研究员已独立重构 j=k 的必要条件推导；
尚未提升为共享正式 Claim，不宣称外审或新颖性。
本文是一个可变人数构造模板的必要条件，不能外推到所有共同目录 SPE。
它解释把既有无拥挤 3/2 构造的一个末位惩罚者简单改成 r 个为何无效。

## 1. 模板及精确量词

取整数 k,r≥1，以及互不相交的客户集 X_1,…,X_k、Y_1,…,Y_k、P，
其中 |X_i|=b>0、|Y_i|=a≥0、|P|=t≥0。所有客户仍为不同的单位客户。
共同目录包括

```
C_i = X_i,       A_i = X_i ∪ Y_i,       B_i = X_i ∪ P,       D = P.
```

总人数 m=k+r。设某个完整纯 SPE 的实际路径为

\[
C_1,C_2,\ldots,C_k,\underbrace{D,\ldots,D}_{r\text{次}}.
\]

额外目录主题可以存在，但以下覆盖比结论只用于目录恰为上述主题的情形。
所有实际早期玩家收益为 b，末 r 人各得 t/r，实际覆盖 W=kb+t。

在第 j 位的实际前缀 C_1,…,C_(j−1) 处考察**同一完整策略**下偏离至 B_j 的
真实续局。设原来的 k−j 个 fresh C_l 中，至少 k−j−q 个行动仍在该真实续局出现，
各自属于不同的 l>j。这里 0≤q≤k−j；并不要求这些 C_l 出现在原来的位置。
这 k−j−q 名玩家的主题与 B_j 完全不交。

因此，偏离者的 B_j 客户最多分别被另外 r+q 名玩家覆盖。无论这些 r+q 人是否
理性、是否选择相同主题，偏离者在该真实分支的收益均至少

\[
\frac{b+t}{r+q+1}.
\]

实际收益为 b，SPE 的该节点最优性于是强迫

\[
\boxed{t\le(r+q)b.}\tag{1}
\]

这一步不冻结离轨后继。假设只统计真实分支中仍然出现的互不相交 C_l，
其他行动及其激励全部任意。

## 2. 末位最佳回复与不可突破的 3/2

实际最后一人选 D，收益为 t/r。在他的实际前缀中，每个 X_i 已被 C_i 覆盖一次，
每个 Y_i 仍未覆盖。因此改选 A_i 的收益为 b/2+a。末位最佳回复给

\[
\boxed{\frac tr\ge\frac b2+a.}\tag{2}
\]

合并 (1)、(2)，对每个上述实际早期节点都有

\[
\boxed{\frac ab\le\frac12+\frac qr.}\tag{3}
\]

**关键加强：取 j=k，后面本来就没有 fresh C_l，因此必有 q=0。**
所以任何该实际路径的完整 SPE 都必须 a≤b/2，完全不需要限制任何离轨续局。
目录恰为模板时，k 个 A_i 加 D 已覆盖全部客户，
并且 k+1≤k+r，故

\[
\operatorname{OPT}_{k+r}=k(b+a)+t,\qquad
\frac{\operatorname{OPT}_{k+r}}W
=1+\frac{ka}{kb+t}\le\frac32.
\]

所以只增加任意多个尾部惩罚者、保留 C_1,…,C_k,D^r 实际路径，无法把这个机制
提升到超过 3/2。末个 C_k 的抢先选择已足够否定它；所有离轨后继、完整历史平局
以及离轨其他早期玩家的转向都无需限制。

对更早的 j，式 (3) 另给一个局部计数义务：若尝试 a>b/2，每个 B_j 抢先选择分支都必须放弃
至少 r(a/b−1/2) 个原本互不相交的 fresh C 行动（整数时取上整）。这些额外早期
转向必须各自在完整子博弈中最优；它们不是可以免费增加的复制惩罚者。

但是 j=k 已经使此项义务不可能满足。因此改变这个实际路径上的离轨回复本身无效，
必须改变实际路径、公共奖池结构或主题家族。这个结论不排除通过多个不同奖池或更
复杂的递归状态得到更低福利；也不是一般 half 的证明。

## 3. 最小收益候选的独立状态

本次同时攻击候选

\[
\operatorname{OPT}_m-W\le m\min_i u_i.\tag{MG}
\]

它等价于对所有实际玩家 i 分别要求 OPT−W≤m u_i。若 (MG) 成立，则
min_i u_i≤W/m 直接推出 OPT≤2W。它与已经失败的 u_i≥v_m 不是同一个命题；
后者的反例不自动否定 (MG)。本分支没有证明或否定 (MG)。

末位 i=m 的版本有一个直接证明：任取 m 个最优主题 T_1,…,T_m，令 C 为实际
覆盖。实际末位改选 T_l 至少取得 |T_l\C|，故 u_m≥|T_l\C|。于是

\[
\operatorname{OPT}_m-W
\le |(\cup_lT_l)\setminus C|
\le\sum_l|T_l\setminus C|\le m u_m.
\]

这只使用实际末位最佳回复，不能把同一比较借给更早玩家。

`attack_minimum_gap.py` 在已保存的完整策略锥中直接最大化
v^J r−wr−m f_a(q)r，W=wr=1。一个严格正的有理可行点才会作为反例，之后会
展开单位客户逐历史独立核验。71 个锥的全部目标已恢复并逐坐标核验精确对偶；
另外两个锥各有一个目标的对偶恢复失败，不作全锥结论。详细数值见 README。

有限锥、浮点联合 MILP 的最优状态以及未找到正点，都不证明一般 (MG)。
