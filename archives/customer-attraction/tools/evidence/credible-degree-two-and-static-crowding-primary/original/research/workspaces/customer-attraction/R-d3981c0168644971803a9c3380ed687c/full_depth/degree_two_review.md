# 二元关联真实负驻留通量族：独立审查

2026-10-23。审查对象：`../shared_omission/credible_degree_two_negative_flux.md` 及其实现。审查人是 full_depth 子研究员；先按正文独立推导，再读作者代码核对策略。没有使用作者求解器或结果作独立计算输入。

**结论：在明确下述平局规则后，全部一般参数的完整 SPE 构造、theta 等式、负通量以及最优共享遗漏公式均通过本次内部审查。** 原文有一个可修的策略表述缺口；不是定理的致命反例。没有审查出 half 或 theta 反例，亦没有一般 half 证明。

## 1. 必须明确的平局规则

原稿§3把长度至少二时的组数平局写成“任意固定打破”，但§3.3需要：首两主题跨组后，第三人选第二个主题所在组。固定优先 X 之类的规则并不满足它：根在 X、第二人在 Y 时第三人会填 X，根最终得 H 而非 L，规定的全部根菜单和通量公式随之失效。

充分修复是：**在长度二的 1–1 平局选第二个主题所在组；其他组数平局可任意固定。** 更统一的可执行规则是所有平局都选最近一个历史主题所在组。作者实际代码已经使用这一统一规则，因此现有数值证据实现的是修复后版本。

这项修复不损害无重复节点最优性：在均势前缀 A=B 时，当前选择哪个组都会使该组成为严格多数，最终自己所在组均有 q+1−A 人。故不同的新组行动无差异。

## 2. 全历史策略完整性与新主题比较

令 m=q+1、S=qb+(q−1)a。无重复终局中，选某组且该组最终有 s 人的玩家收益为

    F(s)=S−[b(q+1−s)+a(s−1)]/2,

对 1<=s<=q 单调不减，因为相邻差为 (b−a)/2>=0。其端点是正文的 L 和 H；`L−S/2=(q−1)a/2>=0`。

任意无重复历史中，当前若改选一个先前已用主题，则该主题每个客户均至少被两名玩家覆盖，所以偏离收益至多 S/2。这是终局逐客户上界，适用于**任意**真实重复子树终局。故每个重复前缀下选任意有限 BI 产生的完整 SPE 都可以；重复历史不可能重新进入无重复历史，因而不存在“出口回切”或策略拼接循环。a=0 时可能取等，原模型允许这些平局。

对无重复长度至少二的前缀，记多数 A>=B、A+B<=q。

* A=q 时 B=0，当前是末位，选另一组新主题。当前可选的其他新主题同组同值，重复主题已由 S/2 排除。
* B=0、2<=A<q 时，遵循多数令自己最终在 q 人组，得 H。改少数组令自己最终为唯一少数组成员，得 L。
* B>=1 时，遵循多数的最终自己组人数是 q+1−B。若 A>=B+2，改少数组后原多数仍严格领先，偏离者组人数仅 B+1；由 2B+2<=q 得 B+1<=q+1−B。若 A=B+1，改少数组后暂时平局，无论后续取哪个组，偏离者最终人数至多 q−B，严格小于 q+1−B。若 A=B，选择哪组最终自己组人数都为 q+1−A。

F 的单调性证明全部新主题偏离无利。上述 A=B+1 的边界 `q=2B+1` 也正确：当前行动已可能结束游戏，两组各 B+1，偏离者人数正好 q−B。

第二人在单一根 v 后选相反组，修复后的 1–1 平局规则使其后填满第二人所在组，收益 H。同组新主题偏离也得 H；重复偏离至多 S/2。所有根动作 v 都使后 q 人选相反组全部主题，根得到 L。所以规定的根任意固定行动最优。至此全部有序历史，包括所有离轨重复历史，均有完整纯 SPE。

## 3. theta、驻留分布与逐客户通量

任意 q 个静态竞争行动只占至多 q 个标签，故有未用标签 v。若同组竞争行动总数为 t，则对 incident 邻居次数 n_w 使用 `1/(1+n_w)>=1−n_w/2`，得查询回报

    >=S−[b(q−t)+at]/2=L+(b−a)t/2>=L.

这里允许竞争主题重复；v 未用保证 incident 边的既有负载恰是另一端次数。把某组全部 q 个主题各用一次，未用组查询恰为 L，已用组查询为 `qb/2+(q−1)a/3<=L`，故 `theta_m=L`。没有把静态对手当作响应查询的对手。

各根真实尾部都为相反组全体，故 R 的跨组元素为 1/q、同组为零。它是不可约双随机矩阵；虽有周期二，有限不可约性仍保证唯一驻留分布均匀 `pi=1/(2q)`。因此总驻留差就是

    L−H=−(q−1)(b−a)/2.

独立逐客户计算也一致：跨组边在两个端点根分支中有 (I,K)=(1,1)，其他根中有 (0,1)，均匀系数为 `−(q−1)/(2q²)`；同组边在两个端点根有 (1,0)，同组其他根有 (0,0)，另一组 q 个根有 (0,2)，均匀系数为 `1/(2q)`。乘客户数 q²b 与 q(q−1)a，得到同一总差。

严格负通量的范围准确为 b>a；a=b 时为零。所有根回报恰好 L=theta，所以**没有**满足极端关联反证法最小坏点所需的严格 `d_i<theta`。该族只排除“菜单可信便足以使无条件均匀驻留根—尾差非负”，不能否定利用严格门槛的新预算。

## 4. 福利和相互共享遗漏

所有主题等大小且两两不同，故全为包含极大。a=0 时，K_(q,q) 每个顶点仍有 q>=2 个 incident 边，任意两个不同标签各自都有对方不含的客户；没有同覆盖或包含退化。

总客户数 `N=q²b+q(q−1)a`。任意 q+1 次行动至多选 q+1 个标签，因此至少 q−1 个标签未用；其两两之间每对至少有 a 个客户，所以漏掉至少 `a*binom(q−1,2)` 人。实际只用一个 X 和全部 Y，恰好只漏未选 X 之间的这些同组客户。因此

    W=OPT=N−a*binom(q−1,2)
         =q²b+(q−1)(q+2)a/2.

换成全部 X 加一个 Y 得另一个最优并集 O。它覆盖 C 遗漏的 X 内边，而遗漏 C 覆盖的 Y 内边；两边人数均为 `a*binom(q−1,2)`。当 a>0、q>=3 时 D=|O\C| 与 G=|C\O| 同时严格正，且每名客户兴趣恰为两个不同极大主题。它是 W=OPT 的比较并集交换，不是福利不足的证据。

## 5. 独立精确核验及限制

`audit_degree_two_independent.py` 展开不同单位客户，不导入作者程序、规范求解器或 LP。它逐一枚举全部无重复有序历史，独立执行最近组平局规则，并核对所有新主题偏离；重复偏离统一由 S/2 解析界承担，随后只需有限 BI 存在性，不复制作者的重复子树选择算法。另按静态竞争**多重集**遍历 theta、枚举比较支持核对 OPT、逐单位客户重算驻留系数，并核对 D、G、极大主题。

同七组参数共检查 4667 个无重复有序节点、19228 项新主题比较，全部精确通过。`degree_two_independent_exact.json` 保存输出。此处的节点数与作者全树10181/79726的计数不同，是因为本审计对重复历史采用解析统一上界；不能把二者数字相加后称作全树数量。

一般 q 的认可来自§2—4的解析推导；有限核验只检查实现与具体参数。没有外审、全球新颖性认证或一般 degree<=2 theta 保底定理。
