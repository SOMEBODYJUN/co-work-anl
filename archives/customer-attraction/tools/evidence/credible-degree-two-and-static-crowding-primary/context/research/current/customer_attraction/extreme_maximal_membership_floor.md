# 极大主题归属为单例、缺一或全体时：真实中继与驻留分布支付

命题身份：`CA-EXTREME-MAXIMAL-THETA-v1`、`CA-EXTREME-MAXIMAL-WELFARE-v1`。2026-10-23，完整解析证明；另一研究员在读取作者证明前独立重构，父方再逐式复核。一般 Q-CAG-HALF 仍 OPEN；本页证明无界人数、无界极大主题数的结构子类。外审和全球新颖性未认证。

**Exact Statement / Quantifiers。** 对每个原 [CAG-MODEL](model.md) 实例，若不同包含极大覆盖满足下述(H)，则对每个合法前缀、每个剩余人数 r≥1、该子博弈的每个完整有序历史纯SPE，首位以及全部剩余玩家收益均至少 theta_r(b)。空背景时，对每个 m≥1 的每个完整纯SPE，有下述(C)；没有改动 Q-CAG-HALF 的身份。

**Dependencies / Evidence。** 只用原模型、有限随机矩阵的平稳概率存在性、同终局包含比较及逐客户整数负载代数。独立内部审查见[审查](../../reviews/customer_attraction/extreme_maximal_membership_floor.md)，代码与冻结范围见末节。数值回归不是一般证明。

## 1. 精确范围与结论

模型是原 CAG-MODEL：有限共同目录、单位客户、单位提供者、全部有序历史的完整纯 SPE，以及任意历史依赖平局。原目录是覆盖集合的集合；证明也允许相同覆盖的不同标签。以下按**覆盖集合**去重后取包含极大主题 A_1,...,A_k。每个目录主题包含于至少一个 A_j。

对每个可覆盖客户 x，令 J_x={j:x∈A_j}。假设

    |J_x| ∈ {1,k-1,k}                                           (H)

（k=1、2 的重合分类按单例或全体解释）。客户不能被任何主题覆盖时可以删去。内部子主题任意：它们可以遗漏公共客户、互相交叠、不构成层族。

任意合法主题前缀产生背景客户负载 b；剩 r>=1 人时，定义静态末位最坏背景值

    theta_r(b)=min_(B in S^(r-1)) max_(A in S)
               sum_(x in A)1/[b_x+1+load_B(x)].

此处静态对手先定组合，查询再最佳回应；不是不观察随机查询的 minimax v_r。

**定理。** 在满足 (H) 的目录中，对于每个合法背景 b、每个 r>=1、每份完整历史纯 SPE，首位最终收益至少 theta_r(b)。此外该 SPE 中每位剩余玩家的最终收益均至少 theta_r(b)。

特别地，原空背景 m 人的每份完整纯 SPE 满足

    W >= m theta_m(0) >= m v_m(0) >= m OPT_m/(2m-1).

因此该结构类满足 Q-CAG-HALF，并有更强的 OPT_m/W<=2-1/m（非零福利时）。

(H) 自动涵盖至多三个包含极大主题的任何目录，也涵盖任意 k 的 sunflower 极大主题（各客户只属于一个或全部极大主题），以及一般的缺一归属。这里不是固定人数的常数改进。

## 2. 背景嵌入与最小人数的真实中继归约

对每个合法主题 A，r>=2，

    theta_(r-1)(b+1_A) >= theta_r(b).                         (E)

因为左侧的 r-2 个静态竞争主题加上固定 A，仅为右侧全部 r-1 个静态竞争组合的一个子集；max 查询的量词顺序未变。反复固定合法主题亦成立。

对固定结构类 (H)，假设定理的首位结论存在反例，取**剩余人数 r 最小**的反例，允许所有合法背景。目录/客户可固定，或在同一结构类中一并取最小 r；前缀不会改变 (H)。r=1 时首位恰取 theta_1(b)，所以 r>=2。

令 t=theta_r(b)，反例根实际收益 u<t。对每个极大主题代表标签 A_i，强制该根行动后沿原完整策略真实后继，得到长度 r 的终局 z^i；根在此分支收益 d_i<=u<t。

在这个真实分支第 j>=2 人的节点，剩 s=r-j+1<r。由最小性，同类目录的该真实子博弈首位收益至少 theta_s(b+此前真实前缀负载)，再由 (E) 至少 t。因此

    z^i 中每一名后继玩家的最终收益 >= t > d_i.              (R)

此处调用每个真实中继子博弈，不只调用根和末位。每个分支沿同一原策略执行，不交换两个有序前缀的续局。

若其中一个后继选 B⊆A_i，同终局和同背景下其收益不超过根 A_i 的 d_i，与 (R) 矛盾。因此每个后继 B 都**不包含于** A_i。每个 B 仍包含于至少一个极大主题，可任选其中一个 A_j 给它归属；这个 j 一定不同于 i。重复标签、同覆盖副本和纯公共子主题同样由该包含比较处理。

若 k=1，每个后继主题均包含于唯一 A_1，已经与上述包含结论矛盾；因此坏情形只需考虑 k>=2。

令 n_(ji) 为根 i 的真实分支中归属极大主题 j 的后继人数。于是

    n_(ii)=0,    sum_j n_(ji)=r-1.

定义列随机矩阵 R_(ji)=n_(ji)/(r-1)。取任意驻留概率向量 pi=R pi；有限随机矩阵总有这样的 pi，且不要求所有分量严格正。驻留式为

    sum_i pi_i n_(ji)=(r-1)pi_j.                             (S)

## 3. 逐客户的根—尾部差

固定客户 x，其背景 b_x记为 b。对根分支 i，令 I_i=1_{x∈A_i}，K_i 为 r-1 名真实后继对 x 的实际负载。每名后继 B 包含于其归属极大主题，所以

    K_i <= sum_(j in J_x) n_(ji).                            (L)

根在 x 上的收益为 I_i/(b+I_i+K_i)；后继**总**收益在 x 上为 K_i/(b+I_i+K_i)。定义根收益减后继平均收益的系数

    delta_i(x)=[(r-1)I_i-K_i]/[(r-1)(b+I_i+K_i)].             (D)

当 I_i=K_i=0 时，定义 delta_i(x)=0；不写 0/0。其他分母均严格为正。以下逐客户证明 sum_i pi_i delta_i(x)>=0。

### 单例归属 J_x={j}

在根 j 分支，由 n_(jj)=0 及 (L)，K_j=0，故 delta_j=1/(b+1)。其他根 i!=j 有 I_i=0、K_i<=n_(ji)。若 K_i>0，

    delta_i=-K_i/[(r-1)(b+K_i)]
           >=-n_(ji)/[(r-1)(b+1)].

K_i=0 时同一下界也成立。用 (S) 求和得到

    sum_i pi_i delta_i
      >= pi_j/(b+1)-sum_(i!=j)pi_i n_(ji)/[(r-1)(b+1)] = 0.

### 全体归属 J_x=[k]

每个 I_i=1，且 K_i<=r-1，所以 (D) 逐分支非负。

### 缺一归属 J_x=[k] minus {j}

根 j 有 I_j=0，K_j<=r-1。函数 K/(b+K) 在 K>=1 上不减（b=0 时为常数），故连同 K_j=0 的定义，

    delta_j >= -1/(b+r-1).                                  (M0)

其他根 i!=j 有 I_i=1，且由 (L)

    K_i <= r-1-n_(ji).

若 n_(ji)=0，则 delta_i>=0。若 n=n_(ji)>=1，由 (D) 对 K 的单调性，

    delta_i >= n/[(r-1)(b+r-n)]
             >= n/[(r-1)(b+r-1)].                           (M1)

应用 (S)、n_(jj)=0，

    sum_i pi_i delta_i
      >= -pi_j/(b+r-1)+sum_(i!=j)pi_i n_(ji)/[(r-1)(b+r-1)] = 0.

b可以为任意非负整数；r>=2确保上述 b+r-1>0。

## 4. 驻留支付与矛盾

把三个允许归属类型的逐客户非负式相加，得到

    sum_i pi_i d_i >= sum_i pi_i [根i分支后继总收益/(r-1)].

(R) 使每个右侧方括号至少 t；根最优比较使每个 d_i<=u<t。pi总和为一，于是

    u >= sum_i pi_i d_i >= t,

矛盾。首位定理因此成立。

再对任意给定完整 SPE 的每个真实后继子博弈用首位定理和 (E)，就得到每位玩家最终收益均至少该节点根 theta_r(b)。证明包含所有历史依赖平局。

### 任意合法背景的最优剩余利润

令 P_r(b,sigma) 为 r 名剩余玩家的最终收益和，定义同背景最优剩余利润

    F_r(b)=max_(q in S^r) sum_x c_q(x)/(b_x+c_q(x)),

c_q(x)=0 的项按零计。对任意 r 个比较主题的整数负载 c 和 r−1 个静态竞争主题的负载 d，逐客户有

    c/(b+c) <= (c+d)/(b+d+1).

c=0 单列；c≥1 时清正分母后的差为 c(c−1)+bd≥0。对客户求和，右侧是 r 个比较主题与 r−1 个竞争主题在同一静态背景下的查询收益和，至多 (2r−1) 倍该背景的最佳查询。取实现 theta_r(b) 的竞争组合，得到

    F_r(b) <= (2r−1)theta_r(b),
    P_r(b,sigma) >= r theta_r(b) >= r F_r(b)/(2r−1).

这比较相同背景的剩余利润，不把它与包含背景玩家收益的全局福利混同。

## 5. 共同核心的精确改进与锐性

令 C=intersection_j A_j，c=|C|。静态 theta 和 v 的查询都可限制为包含极大主题：把查询换成包含它的极大主题只会增益。静态竞争主题也可限制为极大主题：把竞争主题扩成其包含极大主题只会降低所有查询收益。在空背景的 m 人静态比较中，每个极大查询、每个 m-1 槽竞争主题都覆盖 C，所以核心收益恒为 c/m。

删去 C 后的极大主题目录记为 residual，则

    theta_m(0)=c/m+theta_m,residual(0),
    v_m(0)=c/m+v_m,residual(0),
    OPT_m=c+OPT_m,residual.

这里即使原内部子主题遗漏核心也成立，因为静态限制只用原本合法的极大主题。实际完整 SPE 的末位必选包含极大覆盖：若末位主题有严格合法超集，多出的单位客户给严格正收益。因此实际 W覆盖全部C，且 W>=c。

定理和静态安全值下界给 W-c>=m v_m,residual，因而

    OPT_m <= c+(2-1/m)(W-c).                                 (C)

c=0 时即普通 (2-1/m) 界。该常数在结构类中对每个 m 锐：一个 m 客户大主题，加 m-1 个不交单客户主题，取每个有序历史都选择大主题的策略。任何历史后的当前玩家及全部后继都选大主题时，大主题最终总人数至多m，收益至少1；偏离任意单客户主题的收益至多1。因此该策略在全部有序历史均最优，是完整纯SPE，且W=m、OPT=2m-1。m>=2 时，若给每个极大主题再加 c 个共同客户，极大主题交集恰为这 c 人；核心按每人c/m均分，原策略SPE比较不变，W=m+c、OPT=2m-1+c，在 (C) 取等。m=1 时 W=OPT_1，界自动为等式。此处只主张复用既有锐性族，不把内部新颖性当外审结论。

## 6. 一般目录的精确停界

本驻留支付利用客户只归属单例、缺一、全体。它没有证明任意中间归属的同一系数非负。

最小标量障碍：k=4、r=3、b=0，客户仅属于极大主题1、2。取各根分支后继归属为

    1 -> (2,3),   2 -> (1,4),   3 -> (1,4),   4 -> (2,3).

该归属矩阵无self分配，pi均匀驻留。若该客户每个分支的实际后继负载K_i=1，则

    delta_1=delta_2=1/4,    delta_3=delta_4=-1/2,
    sum_i pi_i delta_i=-1/8.

这只反驳不增加真实中继信用的逐客户驻留系数模板；它不是合法完整 SPE、不是一般 theta/v 桥或 half 反例。一般四个以上极大主题中含真正中间归属时，下一步需要新的跨客户或更细真实节点支付，不能原样外推本式。

## 7. 与现行结构资产的区别

现行 `research/current/customer_attraction/sunflower_maxima_bound.md` 的 sunflower 类包含于 (H)。现行 `laminar_incidence_bound.md` 要求各客户的 J_x 组成层族；它与 (H) 不可比：k=4 时，仅有一个二元归属 {1,2} 加私有单例即为层族却不满足(H)；不同的缺一归属彼此交叠且互不包含，满足(H)却不成层族。现行至多六极大主题 half theorem 不限制归属但固定极大数上限，本定理极大数无界且给更强的 theta floor。

输入范围的明确见证：任意 k>=7，给每个最大主题 i 一个私有客户 p_i（归属{i}），另给每个 i 一个缺一客户 y_i（归属[k] minus {i}）；定义极大主题 A_i 为所有归属包含 i 的客户。私有anchor保证各A_i互不包含，多个缺一归属不成层族，也非sunflower；本定理允许任意这些客户重数以及任意内部子主题。该见证只区分输入类，不声称这些对称实例的福利界本身困难或新颖。
