# R-2fc global_proof D：二层占用九客户探针

本包清洗三份同一路径源：精确报告 `two_layer_occupancy_audit.json`、其浮点 LP 发现输入 `two_layer_occupancy_candidate.json`、以及发现程序 `two_layer_occupancy_probe.py`。三源均由 Boss2 先认领，`clean show` 返回 0；原始 stdout/stderr 在 `clean-show/`，冻结 blob/大小/SHA 在 `source-manifest.json`。

## 源内容与量词

`two_layer_occupancy_probe.py` 固定 `q=6,r=3`，对非空客户掩码类型做随机权重，按一个 Markov 完整策略的逆序最大化生成终局，保留实际终局负载，再以浮点 `linprog` 在所有单步偏离约束下搜比较主题。目标是“实际二层占用量减去比较主题覆盖的新客户”；程序把 `objective<0` 当作发现。它只筛查有限随机策略、有限比较主题和浮点 LP 可行域，不枚举所有纯 SPE，也不提供精确存在性或半覆盖结论。

`two_layer_occupancy_candidate.json` 是 `q=6,r=3,trial=192,seed=29396` 的浮点候选。它把掩码 `1,7,10,16,24,32` 的权重写成 `1/9,2/9,1/9,1/9,1/9,1/3`（浮点近似），实际终端计数向量为 `(0,0,1,1,0,1)`，比较主题为 `(1,4,5)`，报告目标 `-1/9`。候选的加权结构恰好可整数化为九个单位客户，但原 JSON 的发现目标仍是浮点记录。

`two_layer_occupancy_audit.json` 是同一九客户结构的精确审计摘要：掩码重数 `1:1, 7:2, 10:1, 16:1, 24:1, 32:3`，完整策略实际有序路径 `(5,2,3)`，收益 `(3,2,2)`，`W=7`、`OPT_3=8`、普通调和势 `Phi=7`、截断势 `7`、二层占用 `7`。它检查 43 个有序决策历史和 258 个含自身动作比较，188 个严格，最小 slack 为 0。

## 独立复放

`run/verify_two_layer.py` 不依赖 LP：把六种掩码按审计重数展开成九个单位客户，以 `Fraction` 重算每个有序历史的真实后继和全部六个动作，断言每个动作 slack 非负；枚举全部 (6^3) 终局得到 `OPT=8`。它还把候选的 `(1,4,5)` 比较精确化为

\[
\frac{7}{9}-\frac{8}{9}=-\frac19,
\]

其中第一项是实际二层占用，第二项是比较主题覆盖的八个客户。运行结果在 `run/two_layer_exact_audit.json`，所有断言通过。`replay/` 以 `--trials 3 --seed 29393` smoke 运行原探针，退出 0 且 stderr 为空。

## 数学去向与边界

九客户点是五客户无拥挤障碍的来源之一：删去独立第三主题及冗余客户后可得到四主题五客户完整 SPE。九客户点本身已经给出 `W=7<OPT_3=8` 和二层占用 `7<8`，所以它否定“实际二层占用总能支配最优覆盖”的辅助桥；但 `2W=14>8`，不是 Q-CAG-HALF 反例。它也不证明所有完整 SPE 的最坏比率、所有 `q,r` 的上界或任意半覆盖保证。保留浮点候选和探针作为发现链与可复现实验，精确审计作为固定实例障碍。
