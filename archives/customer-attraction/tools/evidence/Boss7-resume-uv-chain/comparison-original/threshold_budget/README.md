# 动态门槛预算：候选（未证）

**状态：候选/探索，未证明，未外审，未称为定理。** 本笔记提出一个接在全树 `R(h)` 递推上的一般候选，目的在于把每个实际 SPE 的福利缺口支付成动态子博弈门槛。它不改变 Q-CAG-HALF 的量词，也不把有限测试当作一般证据。

## 精确对象

固定任意有限共同目录、任意 `m`，以及一份完整历史依赖纯 SPE `σ`。对实际根路径的长度 `i−1` 前缀 `h_i`，记实际终局为 `z`，实际第 `i` 位动作可不同于离轨动作。令

\[
R(h,A)=\{\text{从历史 }(h,A)\text{ 开始可由某个完整纯 SPE 续局实现的终局}\}.
\]

这里 `R(h,A)` 保留所有有序历史依赖的后继选择和平局；不冻结原路径，也不把同计数历史合并成相同续局。定义当前玩家在强制 `A` 后的最坏可实现收益

\[
\ell_i(h_i,A)=\min_{y\in R(h_i,A)}u_i(y),
\qquad
\theta_i=\max_{A\in\mathcal S}\ell_i(h_i,A).
\]

由当前节点的纯 SPE 最优性，实际收益满足 `u_i(z)≥θ_i`，故

\[
\sum_i\theta_i\le\sum_i u_i(z)=W(z).
\]

## THRESHOLD 候选

对任意一个 `m` 元组合法主题 `T_1,\ldots,T_m`，令 `O=|\cup_iT_i|`。候选断言

\[
\boxed{O\le W(z)+\sum_{i=1}^m\theta_i.}\tag{TB}
\]

若 (TB) 成立，立即得到 `O≤2W`，再对最优元组取最大即得 Q-CAG-HALF。一个看起来更强、且可直接验证为 (TB) 充分条件的同序矩阵断言为

\[
\boxed{\sum_{i=1}^m\ell_i(h_i,T_i)\ge O-W(z).}\tag{SM}
\]

因为 `θ_i≥\ell_i(h_i,T_i)`。`SM` 对主题元组的顺序似乎可任意重排；目前只需要为某个固定顺序证明，若成立可对任意最优元组直接使用。

## 有限精确测试（只作候选筛查）

使用仓库 `customer_attraction.ExactSPESolver` 的完整 `R(k)` 集合递推和 `Fraction` 收益。测试内容：

- `p=3`、所有 7 个非空客户类型的二值重数（`0/1`）全部输入；`m=2,3,4,5` 的全部可实现有序 SPE 路径；(SM) 全部通过。
- 随机非负整数客户重数（每类型 `0..4/5`），`p=3,m=4,5,6`，以及 `p=4,m=4,5` 的数百至千级样本；(TB) 与 (SM) 均通过。
- 对每个样本路径，直接计算每个实际前缀的 `R(h_i,T)` 最坏收益，不使用静态 PNE、匿名平局或冻结后继。

这些测试没有数学证明含义，也没有穷尽任意 `p,m`。

## 仍缺的严格步骤

1. 需要证明 (SM) 或直接证明 (TB)；仅由 `\ell_i(T)\ge |T\setminus U(z)|/(m-i+1)` 得到的逐客户下界不足以支付分散在多个最优主题中的缺口。
2. 分支 `R(h_i,T_i)` 的最坏终局彼此来自不同真实前缀；不能把某分支后继行动替换为另一分支的路径，也不能把 `\ell_i` 视为一个可共同实现的终局。
3. 可能的证明方向是顺序交换/充电：若强制 `T_i` 后未来玩家复制一个实际未覆盖客户而压低 `u_i`，则把其后继偏离到 `T_j` 的真实 SPE 不等式串成一个有限有向流，利用 `T` 的最优并集交换性把复制债务转为后续 `\ell_j(T_j)`；该串联尚未构造。
4. 还未发现完整有限反例。若出现反例，它只会否定 (SM)/(TB)，不自动否定 Q-CAG-HALF；需单独验证 `O>2W` 的完整所有历史 SPE。

## 可复用审计提醒

- `R(h,A)` 是完整纯 SPE 可实现终局全集；不能用一个固定 continuation selector 替代。
- `θ_i` 是实际路径前缀的动态门槛；不能换成静态 `v_r(b)`、`θ_r(b)` 或 iid 值。
- 这里的 `W+Σθ` 是同一实际福利和同一实际路径门槛的账，不是把不同离轨分支的福利相加。
