# 有容量余量的储备保护与共同核心 hub 中继阻断

2026-10-23。Boss10 credible_constructions 的解析结果；一般 **Q-CAG-HALF 仍 OPEN**。本稿没有构造主目标反例，没有声称得到一般半覆盖证明。第一节加强 Boss6 的对称储备保护工具；第二节对 root 提出的共核近同 hub 中继给任意真实人数的真实 SPE 阻断。不是有限阴性搜索的外推，尚待另一研究员完整独立审查。

## 1. 不需要全行动收益上界的容量保护

采用 CAG-MODEL。对任意合法前缀的一个向后封闭状态域，给定有限储备指标集。某储备称已触及，若固定前缀中有行动覆盖过其指定客户块中的任一客户；这些块彼此不交。一个行动至多触及 d 个尚未触及的储备，d≥1。固定 H>0，并要求：

1. 凡触及任何已触及储备的行动，其当前玩家的即时收益（保留过去、删去所有未来玩家计算）严格小于 H。
2. 每个 fresh 储备 r 都有一个合法专用行动 D_r，只触及该储备而不触及其他储备。若未来没有行动再触及 r，则这名 D_r 玩家的最终收益至少 H；允许其收益也来自储备之外的客户。
3. 子历史保持这些条件。储备数和剩余人数按真实行动更新，不删除过去行动。

若当前剩余 n≥1 名玩家、fresh 数 q 满足

    q ≥ d(n−1)+1,

则在该前缀后的**每个完整历史依赖纯 SPE**中，所有后续玩家收益至少 H，且没人触及在其行动前已经触及的储备。

证明对 n 归纳。n=1 时当前改选任意 fresh D_r 得至少 H，故即时收益<H的旧储备行动不能选。n>1 时改选 fresh D_r 只消耗一个储备，子局有 q−1≥d(n−2)+1 个 fresh 储备（d≥1）。归纳保证所有真实后继都不触及刚使用的 r，所以当前改选 D_r 收益至少 H。SPE 给实际当前收益≥H，排除旧储备行动。实际当前行动至多消耗 d 个 fresh 储备，余 q−d≥d(n−2)+1，故也可对子局使用归纳。所有比较执行原完整策略的真实后继。

这里没有假定所有行动收益≤H，也没有要求玩家收益恰为 H。q≥n 是 d=1 的特例。Boss6 均匀储备稿中收益恰 H 的上界仍有额外用途；本引理不能直接恢复其最后 B 次数上限。一般目录也未被证明具有这样的储备分解。特别地，碰到旧储备同时获得多个 fresh 储备奖励的复合行动仍必须满足条件1，不能免费忽略其总收益。

## 2. 任意人数、任意多个共核 hub 的后继排除

### 2.1 目录和静态 iid 条件

固定真实玩家数 r≥2，偶数 k≥r。核心由所有 k/2 元外围标签子集构成，每种恰有三名单位客户。因此核心总数 M=3*C(k,k/2)。外围主题 P_a（a=1,...,k）覆盖所有标签子集含 a 的核心（恰 M/2 名）及其专有 M/3 名客户。不同外围的专有块不交。

目录另含任意有限多个 hub H_h。每个 hub 覆盖整个核心以及一个额外客户集 R_h。R_h 避开全部外围客户；不同 R_h 可以任意相交。记 δ_h=|R_h|。目录恰为这些外围及 hubs。

考察 **n=r+1 名静态玩家**的对称 iid 候选：所有竞争者独立均匀选外围。令

    a_r = (1−2^{−(r+1)})/(r+1),
    e_r(k) = E[1/(1+Bin(r,1/k))].

外围查询收益为

    λ_(r+1) = M a_r + (M/3)e_r(k).

hub 查询收益为 2M a_r+δ_h。假定每个 hub 都满足该候选的 offsupport 条件，即

    δ_h ≤ (M/3)e_r(k) − M a_r.                         (H-cap)

这正是上式两种查询收益的比较，不是把 r 名真实玩家与静态 n=r+1 混同。若右侧为负，则没有非负 δ_h 满足条件，下面的有 hub 命题为空。外围对称性保证各外围查询同值；本文只用 (H-cap)，不把静态条件代替动态激励。

### 2.2 精确动态结论

**命题（共核 hub 中继阻断）。** 在 r 名真实玩家的上述游戏中，固定任意合法有序前缀，使至少一个 hub 已被选择，而且所有过去的外围行动互不相同。则其后的**每个完整历史纯 SPE 都只选择此前未选过的外围**。所以从空历史开始、在第一个 hub 出现前外围互异的任何真实 SPE 路径，均不可能再有第二次 hub 行动；hub 可以换标签或重复标签，结论相同。

这没有证明此前外围一定互异，也没有断言根收益总支配 λ_(r+1)。因此它排除的是这套共核、独立外围私有块、满足 iid cap 的 hub 中继；不是所有改变核心覆盖或外围奖励的嵌套中继。

### 2.3 先排除旧外围，不假定 hub 回复

实际上，固定任意已含一个 hub 的前缀，允许外围有重复。把每个外围私有客户块作为储备。已选过外围 a 计数 c_a≥1；若现在再选它，核心即时收益≤M/[2(j+c_a+1)]≤M/6（j≥1 个旧 hub），私有即时收益≤(M/3)/2=M/6，合计≤M/3。

另一方面，只要一个 fresh 外围私有块以后不再被触及，选择该外围者的私有收益就是 M/3，核心收益至少 M/(2r)>0。故第1节可取 d=1、H=M/3+M/(2r)。所有旧外围即时收益<H；hub 不触及任何外围储备，外围只触及自己的一个。k≥r 保证任意子历史的 fresh 外围数≥剩余人数。由第1节，每个真实 SPE 后继都不再选择旧外围。这里尚未排除 hub，而且不需要先排除它。

### 2.4 hub 对 fresh 外围的严格动态差

对余人数逆归纳。设当前前缀含 j≥1 次 hub、ℓ 个互异外围，尚余 n=r−j−ℓ 人。上一节已排除旧外围。若当前选 hub 或 fresh 外围，其子局仍满足本命题的结构；归纳保证未来只选 fresh 外围。

令 s=r−j−1=ℓ+n−1，故两种分支中共有 s 个与当前所比较 fresh 外围 a 不同的外围标签。因为所有核心 k/2 子集等重，这些标签的具体身份及未来选择次序不影响当前收益。将两种分支都补到 r 名玩家后比较：hub 的额外客户最终收益≤δ_h，fresh 外围私有收益=M/3；核心收益差只剩不含 a 的一半核心。因此

    U_hub − U_fresh ≤ M d_j + δ_h − M/3,

其中

    d_j = (1/2) E[1/(j+1+Z)],
    Z ~ Hypergeom(population=k−1, successes=k/2, draws=s).

这个差比较的是各行动的真实全程收益；未来全 fresh 已由人数更少的子局归纳承担，不是冻结原来的跟随者。

下面证明任意 j≥1 均有 d_j<a_r。对 0≤t≤1，抽样不放回的基本对称平均（Maclaurin 不等式；也可逐次把两个数平均来证明）给

    E[t^Z] ≤ (1−p+pt)^s ≤ ((1+t)/2)^s,
    p=(k/2)/(k−1)>1/2.

积分 t^j，得到

    2d_j ≤ E[1/(j+1+B_s)],  B_s~Bin(s,1/2).

另取独立 B_(j+1)~Bin(j+1,1/2)。条件于 B_s=z，严格凸性及 j≥1 给

    E[1/(1+z+B_(j+1))]
       > 1/(j+1+z).

j=1 时两边分母的均值相同而 B_2 非退化；j>1 时均值 (j+1)/2<j，严格号更直接。由于 s+j+1=r，故

    2a_r = E[1/(1+Bin(r,1/2))]
           > E[1/(j+1+B_s)] ≥ 2d_j.

代入 (H-cap)，

    U_hub − U_fresh
       ≤ M(d_j−a_r) − (M/3)(1−e_r(k)) < 0.

于是当前 hub 严格非最优，只能选 fresh 外围，完成逆归纳。零额外 hub 客户、任意多个 hub、额外客户相交及任意历史平局都被保留。整个结论是全历史 SPE 的真实最优性结论。

## 3. 下一步边界

这一结果显示，仅增加与旧 hub 同核心、仅附独占或互相交叠额外客户的 hub 链，不能在满足外围 iid cap 的前提下制造多个可信 hub 追随者。要绕开，至少要改变某些 hub 的核心覆盖、让 hub 覆盖外围私有客户，或允许静态查询支持包含 hubs。那些改变不满足本证明的差分和储备条件，必须重新分析。

非均匀独立储备的原 all-k,t 放大问题仍未解。本目录 asymmetric_reserve_probe.py 只对该明确猜想做有限精确反例诊断；asymmetric_t2.json 的239个 admissible 三组双储备数据没有找到目标路径，不构成其一般证明。它不承担本稿两个解析命题的量词。
