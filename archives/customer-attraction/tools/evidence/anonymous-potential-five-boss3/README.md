## 唯一新增数学执行

`replay_cyclic_entry.py` 在clone外独立runtime复制两原文件、导入受main guard保护的内核，透明记录并原样返回默认循环入口本来就有的两次solve。运行一次原 `__main__`，两个原LP；没有第三次graph solve，没有随机anonymous／potential／flow样本，没有两5000预算重跑，也没有已审84表／2520sharp复验。

`cyclic-replay-event.json` 记录实际命令、cwd、环境、耗时、输入／包装器SHA和明确次数。`cyclic-original-main.stdout` 是原入口输出，stderr为空；原没有冻结循环JSON，故 `cyclic-current-report.json` 是本次stdout解析件，不冒充历史逐字节重现。`cyclic-two-solve-results.json` 保同次两个原返回对象，包括浮点不可行文字和势投影的14条有理正流／五正背景。源循环入口第二断言只检查success；本次内核的 `exact_ok=true` 另照实保留。`run-output-manifest.json` 只对已经完成的输出作字节绑定，没有再执行LP。

普通图不可行另由精确循环收益表证明：所有实际IC／同题弧非负、W=1，但每个独立背景对均匀query期望3/5，故任何非负图流都会要求−1/5≥0。势投影可行条件于精确势，不把该无势循环变为客户博弈。
