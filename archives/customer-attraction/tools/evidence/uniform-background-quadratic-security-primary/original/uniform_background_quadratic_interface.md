# 均匀高背景中的真正安全值：精确二阶接口与提升缺口

模型仍为有限共同目录、单位客户、单位提供者、全部有序历史纯 SPE。这里研究扩大接口：每个可覆盖客户已有相同非负整数背景负载 B；另有 m>=1 名剩余玩家。背景不被声称已经由某个合法根前缀实现。设每个目录主题恰含 K 个客户，K=0 直接退化。有限目录可有相同覆盖的不同标签。

记 a=B+1，G_ST=|S cap T|，以及一个剩余终局 z=(S_1,...,S_m) 的主题计数向量 c。G 为非负半定Gram矩阵，G_SS=K。定义负Gram辅助游戏的玩家代价

    L_i(z)=sum_(j!=i) G_(S_i,S_j).

辅助游戏中每位玩家最小化 L_i；其 SPE 一样量化全部有序历史、保留任意历史依赖平局。原背景游戏的总剩余收益记 P_B(z)，其真正不观察抽样的安全值记 v_m(B)。原空背景根福利 W 与有背景的 P_B 不可混同。

## 1. 任意终局、任意玩家的统一误差界（已证明）

若玩家 i 所选主题中的客户 x 还有 k_x 名其他剩余覆盖者，则 0<=k_x<=m-1。恒等式

    1/(a+k) = 1/a - k/a^2 + k^2/[a^2(a+k)]

给出

    u_i^B(z) = K/a - L_i(z)/a^2 + R_i^B(z),
    0 <= R_i^B(z) <= K(m-1)^2/a^3.                 (1)

因此令 T=mK(m-1)^2/a^3，有

    P_B(z) = mK/a - [c'Gc-mK]/a^2 + R_P,
    0<=R_P<=T.                                      (2)

式(1)逐客户证明，式(2)用 sum_i L_i=c'Gc-mK。没有任何均衡假设，也没有改变玩家数。

## 2. 真正安全值使用零和重叠值（已证明）

定义

    H = min_(p in Delta(S)) max_(A in S) sum_T p_T G_TA.    (3)

对固定查询分布 p，竞争者的每一个主题都对查询造成线性重叠成本。因此在 m-1 个主题中最大化总重叠，精确等于

    max_(A_1,...,A_(m-1)) sum_T p_T sum_j G_(T,A_j)
       = (m-1) max_A sum_T p_T G_TA.

这里竞争组合在抽样前固定；重复选择达到等号。对(1)先取最坏竞争组合再取最优查询分布，统一误差界仍成立，得到

    K/a - (m-1)H/a^2 <= v_m(B)
       <= K/a - (m-1)H/a^2 + K(m-1)^2/a^3.         (4)

从(2)、(4)，

    P_B(z)-m v_m(B)
      = [m(m-1)H-(c'Gc-mK)]/a^2 + E_B,
    |E_B| <= mK(m-1)^2/a^3.                        (5)

这是静态安全值与给定终局的普遍二阶归约；它没有证明方括号非负。

### 不能用对称Nash的最小范数值代替H

取六名客户、四个三客户主题

    A1={1,2,3}, A2={1,4,5}, A3={2,4,6}, D={1,2,4}.

前三个两两重叠1，各与D重叠2。前三个均匀查询的各纯背景重叠为(5/3,5/3,5/3,2)，所以H<=2；固定背景D对每个纯查询重叠至少2，所以H>=2。故H=2。

另一方面 min_q q'Gq=5/3：给前三个各1/3达到5/3；设D质量s，其他总质量1-s，则

    q'Gq >= (5/3)(1-s)^2 + 4s(1-s)+3s^2
           =5/3+(2/3)s+(2/3)s^2 >=5/3.

前一不等式用前三主题的等相关Gram在固定总质量下由均匀分配最小化。于是两基准严格不同。使用最小范数值会无依据地加强安全目标，重复强iid/对称Nash基准与真正安全值的混淆。

## 3. 完整SPE极限的正确方向（已证明）

固定有限目录与人数。若同一完整策略sigma对一列B趋于无穷的背景游戏均为SPE，则它是负Gram辅助游戏的完整SPE。

证明：对每个有序节点h及偏离T，设实际与真实偏离续局的当前代价为L_actual、L_alt。两条续局仍来自同一sigma。SPE与(1)给

    L_actual-L_alt <= a^2(R_actual-R_alt)
                    <= K(m-1)^2/a.

令B趋无穷得到L_actual<=L_alt。有限但任意的全部有序节点均如此。若原来的策略随B变化，因为目录及人数固定、完整纯策略只有有限多个，可抽出同一sigma的无穷子列。这里没有把不同历史的平局回复合并。

逆方向必须带额外条件：负Gram的弱SPE本身不保证在任何大B仍为原背景SPE；二阶比较平局可能由三阶及以上项反转。若一个固定sigma的每个非平凡比较都有严格代价优势，并且其余比较的两个原收益恒等，则取所有正优势的最小值，用(1)统一控制余项，可保证它对充分大B成为背景SPE。未认证某个满足这些条件的反例。

若存在eta>0与无穷B序列的背景SPE，使

    m v_m(B)-P_B(z_B) >= eta/(B+1)^2,

则抽取固定完整策略子列并用(5)必得到一个负Gram完整SPE，满足

    c'Gc-mK >= m(m-1)H+eta.

故明确二阶规模的高背景聚合安全失败，必须先违反下节的二次候选。规模o(B^-2)的失败不受此结论排除。

## 4. 所留下的准确义务与原目标的距离

二次候选QG（**未证明、未反驳**）：对任意有限等大小集合目录、任意m、其负Gram成对代价游戏的每个完整纯SPE终局c，

    c'Gc-mK <= m(m-1) min_p max_A sum_T p_T |T cap A|.    (QG)

这是真正安全支付的二阶辅助问题；有限发现没有解决它。它不自动成为主线：即使QG成立，(5)只把背景聚合安全的最坏负差控制在O(B^-3)，没有给出所需精确非负性。

回到原Q-CAG-HALF还有三个独立缺口：

1. 原根背景为B=0，并非B趋于无穷；(1)的高阶余项在该处承重。
2. 等主题大小假设去除后，一阶比较先由主题大小决定；不能直接沿用同一二次策略。
3. 合法实现均匀背景需要真实前缀主题；它们继续在共同目录可选，其自身最终收益也进入根福利。不能把任意外生均匀负载免费加到原实例。

因此本接口只准确定位了一个可扩展极限及最小范数替换错误；没有证明原聚合安全桥、没有得到半覆盖，也没有新合法SPE反例。继续工作应优先解析QG或精确反例，并且只有在它能控制这些提升缺口时才投入后续计算。
