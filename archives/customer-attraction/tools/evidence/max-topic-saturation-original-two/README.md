# 最大主题近饱和的两份原审计来源

[正式计算正文](../../../state/计算/最大主题近饱和的逐客户证书与原有限审计--计算.md)完整解释了两份原件与所有报告字段。

`original/`保2997B代码及3689B报告，来源和SHA在`source-manifest.json`。`comparison/`是两份已经全文比较的正式对象快照，未在本批额外认领。`replay-once/`是唯一一次新原入口的隔离目录，含同字节源码副本、同字节完整报告、stdout摘要、空stderr与执行元数据。

从此目录复算时用一个尚不存在的输出位置：

```bash
python3 replay_original.py --out replay-new
```

包装器拒绝覆盖已有目录，并保持断言开启。原代码没有main guard，导入就会跑完整审计并覆写相邻报告；不要在`original/`导入或运行。复现只用标准库，不需网络、规范游戏包、随机数、浮点优化器或完整SPE枚举。

32751项是m2至14每个提供者关联mask的单客户代数检查。全人数证明、最终总大小条件和非SPE障碍的用途见正文；运行通过不取代这些数学判断。
