# 根最小均衡收益不能替代聚合安全值

此项是立即淘汰的辅助指标，未正式登记新定理。对固定实例取所有完整纯 SPE 根玩家收益的最小值 r。候选 W >= m r 是假的（它并非从一般半覆盖推出）。

`scan.json` 使用 seed 20261020、规范集合值精确求解器，首个随机实例已出现四人终局收益 (13/4,13/4,11/4,11/4)，W=12，而所有可实现有序 SPE 路径的根收益均为13/4，m r=13。OPT、完整策略尚未在本目录独立审计，因此这只是一条可复算的探索记录，不提升为 canonical。

该指标将首位优势误当成了所有人的聚合保底；后续不沿它推导主目标。更有价值的工作转向真实偏离分支及聚合静态安全值。
