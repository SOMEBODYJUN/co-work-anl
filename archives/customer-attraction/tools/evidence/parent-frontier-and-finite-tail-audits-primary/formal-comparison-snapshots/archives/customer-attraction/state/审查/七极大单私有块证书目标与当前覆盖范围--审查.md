# 正确静态最优与八客户反证

七个不同极大覆盖中，记X_{j}仅属B_j的客户，p_j=|X_j|。任一六主题比较可静态扩大到其合法极大容器，不减并集；若不足六种极大主题，可补到六种，仍不减。因此最佳比较可取七者中六个。遗漏B_j时且仅时丢失X_j，故

\[
\boxed{OPT_6=U-\min_{0\le j\le6}p_j.}
\]

这是静态最优组合的论证，不从博弈删除主题，不声称原σ可在缩目录继续SPE。只有p₆>0、其他p_j0时，min p_j0，所以OPT₆=U，而非U−p₆。原稿将唯一正私有块故意遗漏，一般选成次优组合。

旧独审的完整单位客户例为N={0,…,7}，

\[
B_0=\{0,1,2,3,4,5\},\quad B_1=\{0,6\},B_2=\{1,6\},B_3=\{2,6\},
\quad B_4=\{3,6\},B_5=\{4,6\},B_6=\{5,6,7\}.
\]

七主题逐对不包含，恰为七个极大覆盖；仅客户7私属于B₆。U8，B₁∪…∪B₆=N有六主题覆盖8；遗漏B₆的B₀…B₅只有7客户。这完整反证原覆盖等式，不需也没有指定一份SPE，更不是half目标反例；不称本轮新游戏/最小反例或运行全策略审计。
