# 动态可信首利不随剩余人数单调：一项辅助候选的严格反例

2026-10-24。Q-CAG-HALF、TB、TB-ANY、SM-opt-exists仍OPEN。本项只否定下面的修正单调候选，不能作为这些主候选的反例。本子任务没有改共享正文或提交git。

固定任意合法背景b和剩余人数r，记Theta_r(b)为该子博弈全部完整历史纯SPE中当前玩家的最低可实现收益；L_(r,b)(A)为强制当前选A后全部完整可信孩子中该玩家的最低收益。定义F_b(A)=sum_(x in A)1/(b_x+1)。本轮曾考虑全输入关系

    Theta_r(b) <= Theta_(r-1)(b+1_A)+F_b(A)-L_(r,b)(A).       (CM)

**结论：CM为假，且即使A为空也会失败。** 一般不能断言同一目录的最低SPE首利随人数增加而不增。

使用四个非空主题A,B,C,D和合法空主题E。39名不同单位客户的兴趣及重数为：

| 兴趣主题 | 重数 |
| --- | ---: |
| A | 2 |
| A,B | 4 |
| C | 3 |
| A,C | 1 |
| B,C | 5 |
| D | 8 |
| A,D | 1 |
| B,D | 6 |
| A,B,D | 1 |
| A,B,C,D | 8 |

同一目录上，1至4人的空背景Theta精确为

    (24, 33/2, 19/2, 65/6).

所以Theta_4(0)-Theta_3(0)=4/3>0。在四人根强制空主题E后，背景客户负载仍为0，后面恰是原三人游戏，且F_0(E)=L_(4,0)(E)=0。因此CM会错误要求65/6<=19/2。

`audit_corrected_monotonicity.py`不导入规范model或solver。它将重数展开为39名单位客户，按全部有序历史递归全部可实现有序终局，使用Fraction计算每个孩子minimum和max-min门槛。它分别为每个人数构造一棵达到最低首利的完整策略，再独立回放全部决策历史上的每个主题偏离。JSON保存全部策略。四个游戏分别核对5、30、155、780项真实IC。

这一精确回归只为检验CM而生成，不是固定人数正面研究，也不把没有找到别的反例当证明。将每类客户共同复制q次（q为任意正整数）会把所有收益与严格差同时乘q，故不存在仅因绝对幅度较小而忽略此失败的理由。

本例并不击穿POP：四个Theta的和为365/6，而OPT_4=39。也不击穿TB/SM。它只表明通过人数删除建立Theta逐步望远镜时，需要真实额外支付；立即收益与最低强制收益之差也不足以修正空动作删除。

另一次最短旧例边界：原`root_tax_failure.json`中，合法背景计数(A,B)的Theta为13；继续选A后末位Theta为11，而新增覆盖为0。因此Θ沿固定动作的直接单调，以及仅用新增覆盖补偿其下降的任何有限系数，都不是通用引理。此旧例重述不作为本轮新资产的主要贡献。

目前没有从这些边界推出任何TB/H4的新付款不等式。
