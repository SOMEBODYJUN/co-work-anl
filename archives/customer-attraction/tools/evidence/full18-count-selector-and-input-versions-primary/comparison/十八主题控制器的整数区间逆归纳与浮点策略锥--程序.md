# 精确原输入阶段与浮点新权重阶段分开

5852B程序与2708B完整报告是本两primary；实际所导入6548B `Attack` 和16045B默认种子是必要related。四件均正常show、size/SHA/blob核齐并全文实读，种子全部88条兴趣类型和全部大整数重数均保[原字节闭包](../../tools/evidence/bigint-interval-bi-and-controller-cone-primary/README.md)。当前0原import/main、0BI/IC/LP/随机、0新数学checker；报告中的时间与精确/浮点数均按原存储事件保留。

本对象在[原单位客户共同目录模型](../定义/共同目录完整历史模型--定义.md)中固定六人、18主题标签。88个非空兴趣类型各有正整数重数，表示有限但数量很大的不同单位客户；提供者仍全为单位权。主题字符串列表只给标签名，helper按0…17位置解释各客户的整数topics。没有删除重复行动、离轨历史、平局或把同标签数看成同一指定历史策略。

精确阶段求该**固定输入**的全部可实现SPE终局计数。随后只从这些计数构造若干完整有序历史控制器，再对88种固定类型支持重权，做浮点锥发现。前一阶段精确并不自动使后一阶段的新w成为精确SPE证书；也不覆盖支持之外其余非空兴趣类型。

## 共同分母60与大整数的安全区间

helper列全部总数0…6的18维非负计数组合。终局q总数6，类型j的负载c_j(q)≤6；`inv[q,j]`在正负载时为60/c_j，否则0。选择标签a的角色在该终局的60倍原收益为
\[
J(q,a)=\sum_{j:a\in M_j}\frac{60}{c_j(q)}w_j\in\mathbb Z_{\ge0}.
\]
60被1…6整除，当前行动a若含该类型，负载必正。`ExactPayoffs.val`逐项用Python大整数点积缓存J，避免把60位量级重数装进int64。脚本主递归深度写死0…6；不能因helper构造函数有m字段便把本精确入口称任意人数实现。

设S=Σw_j>0、Q=10¹²，取l_j=⌊Qw_j/S⌋，用int64形成
\[
L(q,a)=\sum_{j:a\in M_j}\frac{60}{c_j(q)}l_j,
\quad E(q,a)=\sum_{j:a\in M_j}\frac{60}{c_j(q)}.
\]
逐项取整误差在[0,1)，故
\[
L(q,a)\le\frac Q S J(q,a)\le L(q,a)+E(q,a).\tag{1}
\]
两区间严格分离时，直接决定比较；重叠时用缓存的精确大整数J比较。不是把1e−12附近当弱平局，全部真实平局由整数相等判断。

在本合法非负输入上Σl_j≤Q，故L≤60Q<2⁶³，E≤60·88=5280；源也assert 60Σl_j<2⁶³。固定六人保证helper的int8终局计数/负载及60/c均在其域。它没有另做通用输入schema、正总数或任意m分母合法性验证；本两依赖的实际18/6/88和正整数域已由字段实读核明，不推广到畸形输入。

`argmin`先取各候选区间上端的最小值B，只留下L≤B者；被删候选不可能是最小J。只余一项便可直接返回，余多项才逐个整数点积。`minima`在给定精确最小项的区间附近筛可能相等者，最后逐项精确cmp==0。因此两种筛选没有删去真正极小值或把区间相交误当精确相等。

## 终局全集的逆归纳，而非一张计数策略

对深度r计数状态b，令O(b)是从该背景可由某份完整纯SPE实现的完整终局计数集合。终端O(q)={q}。每个合法当前动作a的孩子集合O(b+e_a)已知，取
\[
m_a=\min_{t\in O(b+e_a)}J(t,a),\qquad f=\max_a m_a.
\]
递推恰为
\[
\boxed{O(b)=\bigcup_a\{t\in O(b+e_a):J(t,a)\ge f\}.}\tag{2}
\]
必要性：任一SPE选a后当前收益至少每个其它孩子的最小可实现收益。充分性：指定a孩子实现t，其它有序动作孩子独立取当前收益最小的完整SPE，J(t,a)≥f保证根最优。动作相同计数背景的后缀游戏同构，只需缓存集合；**不同有序孩子可各选不同策略**，并未假设任意SPE可被一张计数动作表替代。

代码先用(1)筛可能达到最大m_a的动作，再整数比较选一个floor端点；用精确cmp≥0过滤全部孩子终局，`unique`只去重同一完整终局计数。重复行动和平局均在(2)中，不要求严格最优或唯一最佳回复。其逻辑与[完整历史终局全集](../算法/完整历史纯SPE终局全集--算法.md)同一递推；这里的独有实现是区间筛选与大整数后备。

主程序对每个根终局以Python整数计算实际覆盖W(t)，对全部六个不同标签支持计算比较覆盖并取最大。非负覆盖下任意允许重复的六元组都可补成六个不同标签的支持而不减覆盖（18≥6），故该枚举给固定种子真正OPT₆。再从O(0)选覆盖最小终局，以Fraction保存OPT₆/W_min。上述是代码合同与递推证明，不是本次重新生成它的报告。

## 带目标终局的历史控制器

控制器状态为(b,t)：计数前缀b及指定完整终局t。初始t取根可实现集合；选规定a须t∈O(b+e_a)且J(t,a)≥f。规定孩子继续目标t；每个偏离动作c的孩子选让当前c收益最小的终局t_c。这些完整孩子都可实现，且当前规定收益不低于全部偏离收益，故递归展开为完整有序历史SPE。

偏离孩子最小值可平局：70%概率先从其中筛旧输入覆盖最小者，再均匀随机选；其余30%直接均匀选。规定动作也在全部可容许者中随机选。相同(b,t)状态合流，多个相同b但不同t保留不同状态；不是强迫所有同计数历史同回复。每个有序历史从初态沿其行动唯一转移，终层assert孩子计数就是目标终局。

每状态每个非规定动作存一个四元组(t,a,t_c,c)，表达
\[
J_w(t_c,c)-J_w(t,a)\le0.\tag{3}
\]
去重同一四元组不会漏IC：单位角色在相同完整终局及相同行动的收益相同。控制器全部状态和偏离边都纳入keys，不仅actual路径。给定这个控制器，合法新w若精确满足全部(3)，仍是原模型完整SPE；这不说明随机生成的控制器覆盖所有可能策略。

## 浮点权重锥、比较目标与退出条件

原主参数默认input `full18_vertex_seed.json`、prefix `bigint_controller`、trials8、seed664193。每trial编号被3整除时目标取固定种子最坏覆盖终局，其他trial从根集合均匀取；同一RNG串行消费规定动作、偏离平局、优先低覆盖硬币及LP首轮抽样。

`C.optimize(None,[array(target)],keys,C.initial,rng)`不调用helper的浮点`policy`。固定目标t、固定keys后，比较支持J由原初始浮点权重`C.initial`下的argmax一次选定；不会对新w自动更新到其真正最优支持。求解目标为max coverage_J·w，条件
\[
w\ge0,\quad W_t\cdot w=1,\quad\text{所加(3)行成立}.\tag{4}
\]
归一化是**目标实际覆盖1**，不是总客户质量1。即使J不是新w下最优，若未来有精确合法值>2，它仍足以给OPT₆>2W_t；当前报告并无此严格候选。

切面首轮取旧w下最紧1000行及至多1000个不重复随机行，随后每轮对全部keys数值检查，加入最多1500个违约>2e−9的最高行，至多80轮。没有新可加行、求解失败或达上限返回失败；成功时只保证记录的全部keys最大浮点违约≤2e−9。HiGHS primal/dual容差各1e−9，无Fraction恢复或精确重核新w。代码中的`side`额外目标分支在本入口默认调用未用；helper独立main也未进入。

每个成功trial记录一次结果；失败只stdout FAIL，不写占位trial。best仅在增加>1e−8时覆写`*_best_float.json`，其中才有weights、比较支持、目标计数、policy_by_depth与discovery。发现v>2+1e−6则印STRICT_TARGET_CANDIDATE并停，但**仍无精确候选验收器**；docstring要求精确恢复不是已经实现了恢复。主report的keys计数不是LP实际已加行数，nc/nr虽返回却未写report。
