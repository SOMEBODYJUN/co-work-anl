# 两早期包含条件报告的完整语义与新增核验

[正式计算对象](../../../state/计算/两早期包含条件的有限系数审计--计算.md)保存405字节源的全部十字段、实际行语义、有限域完整性和两套条件结论的区别。

* `original.json` 是冻结源 `ed3ef7914a7082563bef` 原字节，SHA-256 `9f23473ad97b4d4127c19f9643c3621ca1add12df42b61c662b5c9c0ea985a36`，两冻结提交相同。
* `verify_report.py` 是本轮新标准库直接会员位重构；不导入旧程序、系数函数、数值优化库或游戏求解器。
* `independent-report.json` 保十字段重构、全部15个零余项型、40个实际位型最小值、84个同索引签名重数及路径递推中间值。
* `independent-stdout.json`、`independent-execution.json` 记录本轮最终隔离运行、Python版本、断言启用、实际耗时及精确输出SHA。初次普通解释器已通过；补充拒绝优化模式后以 `-I` 执行最终版本，未重复执行旧入口。
* `source-manifest.json` 保源定位、同批配套程序证据与真实阅读比较范围。

从仓库根复核：

```sh
python3 -I archives/customer-attraction/tools/evidence/early-containment-report/verify_report.py
```

核验器先枚举 \(4^6=4096\) 个六对比较/真实回复会员向量，得到84个完整 \((d,\ell,h)\) 签名，逐项核可行交集区间与四桶多项式重数；再对40个实际会员型、84个签名直接按 \(U_p\) 份额算 \(S,Z,V\)，并与三个含交集公式及消交集式比较。3360残差全部非负，15零3345正；去交集对应1960型。同签名压缩表示163840个原始18会员位型，不是显式执行163840游戏，更不枚举完整SPE树。

四个常数另从单位需求的六步真实前缀递推算出，再核与产品式相同。全部十个原字段按解析JSON精确相等。这个新增数学核验是已知证明之后的独立实现，不冒原作者盲审、外审或新定理。

同批[配套程序](../../../state/程序/两早期主题包含倒二主题的系数审计器--程序.md)负责旧3118字节入口的运行，其[stdout](../early-containment-auditor/rerun/original_stdout.json)与本冻结原件405字节完全相同；[metadata](../early-containment-auditor/rerun/metadata.json)保原运行合同。报告任务没有运行该旧入口，只读取并核对同批交付。

计算结论只与原数学语义合用：\(S,Z,V,H,L\) 是全客户求和后由真实SPE保证的非负行，单客户系数可负；有限域检验的是最终余项。两个固定早期主题各自包含整个倒二主题是half证书的条件；遗漏重数的 \(F_6,\beta\) 则属于另一不要求该包含条件的引理。一般六人half未被本包证明，关系留阶段三据正文解释建立。
