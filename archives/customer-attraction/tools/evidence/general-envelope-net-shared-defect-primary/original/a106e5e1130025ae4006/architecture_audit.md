## 1. 先修复安全行的数学身份

固定任意可覆盖客户比较集 C，o_x=1_C(x)。给一个分数覆盖 z_T≥0，令总重 tau=Σ_T z_T≥1，满足 Σ_(T含x)z_T≥1 对 x∈C。令实际动作的客户会员为 e_i(x)，c_x=Σ_i e_i，w_x=1_(c_x>0)，u_i(x)=e_i/c_x（零分子取零），b_i=Σ_(j<i)e_j，r_i=n−i+1。

对每个合法 T，真实偏离及全部真实后继给 u_i≥Σ_(x∈T)1/(b_i+r_i)。对分数覆盖平均后，合法的非负**总行**是

    F_i = tau u_i − Σ_(x∈C) 1/(b_i(x)+r_i) ≥ 0.

它的客户系数为

    f_i(x) = tau e_i/c_x − o_x/(b_i+r_i).

单独的 1/(b_i+r_i) 是需求核，不是非负 SPE 行；不能丢掉 tau u_i 的付款成本。每行总和非负，不要求其每客户系数非负。

## 2. 任意人数的末两人投影确实可保留

n≥2，固定实际前 n−2 人历史，p_x=b_(n−1)(x)，A 为**实际倒二动作**，a_x=1_A(x)。既有实权菜单机制给任意 tau≥1 的合法行

    R_tau = tau u_(n−1) + u_n/2
            − Σ_(x∈C) 1/(p_x+1)
            + (1/4) |{x∈C∩A : p_x=0}| ≥ 0.                 (R)

A 不是“末位新增覆盖”。该式不需要 singleton 假设，也不需要末位极大引理。它从真实倒二源 IC、实际末位对回复主题的 IC、各真实末回复之间的互查共同得到。

简述自足消元：按归一化分数权 pi_T=z_T/tau，q 为查询会员概率，ell 为同源真实末回复会员概率，h 为查询与其回复的联合会员。D=(p+1)(p+2)，alpha、beta 是实际末两人的客户收益份额。三条总和非负的真实行有客户系数

    S_x=alpha−q/(p+1)+h/D,
    Z_x=beta−ell/(p+a+1),
    V_x=(q ell−h)/D.

组合 tau(S+V)+Z/2 消去 h，系数为

    tau alpha+beta/2−tau q/(p+1)
       +tau q ell/D−ell/[2(p+a+1)].

q 的系数严格为负；q≥o/tau，故以上不超过

    tau alpha+beta/2−o/(p+1)
      +ell [o/D−1/(2(p+a+1))].

在 ell∈[0,1] 取上界后，最后一项仅在 o=a=1,p=0 时为 1/4，其余最大值为 0，得到 (R)。这个论证对全部整数 p≥0 和任意总人数成立。

但它不是独立于人数的免费常数兜底：用最优 n 元组给 tau=n 时，(R) 的倒二收益成本是 **n u_(n−1)**。末位极大并不强制覆盖其余极大主题的私有客户。

## 3. 新的解析停界：只用前缀安全行与 R 不能一般闭合

### 精确 Claim

固定整数 n≥3、实数 tau≥1。只允许非负、与客户类型无关的乘子 lambda_1,...,lambda_(n−2),rho。使用第 1 节 f_i 和第 2 节

    r_tau(x)=tau e_(n−1)/c_x+e_n/(2c_x)
             −o_x/(p_x+1)+(1/4)o_x e_(n−1)1_(p_x=0).

如果逐类型残差

    Q(e,o)=2w−o−Σ_(i=1)^(n−2)lambda_i f_i−rho r_tau ≥0       (Q)

对**全部** e∈{0,1}^n、o∈{0,1} 成立，则必要有

    tau ≤ 2 H_n − 1,      H_n=Σ_(r=1)^n 1/r.                (B)

### 三类状态即足够证明

1. o=0，只有某个早期位 i≤n−2 覆盖：f_i=tau，其余使用行均为 0。故 tau lambda_i≤2。
2. o=0，只有倒二位覆盖：r_tau=tau，所有前缀行是 0。故 tau rho≤2。
3. o=1，全部实际位均不覆盖：每个 f_i=−1/r_i，r_tau=−1，1/4 补偿不触发。因此

       1 ≤ Σ_i lambda_i/r_i+rho
         ≤ (2/tau)(Σ_(r=3)^n 1/r+1)
         = (2H_n−1)/tau.

得到 (B)。这是解析证明，不依赖 LP 求解器或有限阴性搜索。

更直接的 Farkas 见证：对第 3 类客户列取权 1，对每个第 1 类列取权 1/(tau r_i)，对第 2 类列取权 1/tau。所有 f_i 和 r_tau 的加权总和恰为 0，目标 2w−o 的总和恰为

    −1+(2H_n−1)/tau.

若 tau>2H_n−1，该数严格为负，故任何非负乘子都不可能满足 (Q)。

### 对用户架构的含义与限制

* 对 tau=n、n≥3，H_n<(n+1)/2，故 (B) 严格失败。
* n=6 时，2H_6−1=39/10；该被截短的模板连 tau=9/2 都不能覆盖。既有 9/2 证书还使用末位安全行 F_6 和实际第四位查询末主题的 H4，所以不存在矛盾。
* 任何只在客户实际被倒二覆盖时触发的非负 bonus，对这里的三类状态都无帮助。
* lambda_i=kappa((n−i)/n)^gamma 的试探族只是这个模板的子族；调 kappa、gamma 不能越过该停界。若 kappa>0、gamma 固定、tau=n，甚至早期单覆盖状态的 n lambda_i≤2 就已经不可能统一成立。
* 这是**完整独立客户类型域**上的指定证书模板障碍。允许更强真实跨源行、类型间几何约束、条件分支乘子或其他表示时，本结论不排除成功。
* 三类列不是一份已构造的真实 SPE。尤其若选择 C 等于全目录并集、主动排除所有 o=0 类型，这个 Farkas 见证不适用；但这会改变比较域，且不能无条件要求全目录并集≤2W。
* 因此不能把这里的负目标当作 Q-CAG-HALF 反例，也不能把必要阈值当成 tau 以下可行的充分性。

## 4. 可直接采用的解析乘子来自已有递推

令 O=|C|，P_i=Σ_(j≤i)u_j，r_i=n−i+1。既有真实前缀利润引理给

    G_i=P_(i−1)+r_i tau u_i−O ≥0.

置 a_r=1/(r tau)、b_r=1−a_r，便有**精确等式**

    P_i=b_(r_i)P_(i−1)+a_(r_i)O+a_(r_i)G_i.

从 P_0=0 展开得到

    W = O[1−Π_(r=1)^n (1−1/(r tau))] + Σ_(i=1)^n L_i G_i,

    L_i = [1/(r_i tau)] Π_(s=1)^(r_i−1) (1−1/(s tau)) ≥0.   (L)

这已经是关于位置、总人数及 tau 的显式解析乘子，不需要先猜幂律。tau=1 仍合法，空乘积取 1。它只是把既有递推写成证书权，未改变已证范围。

若 tau=n，则

    0 ≤ 1−Π_(r=1)^n (1−1/(rn)) ≤ H_n/n → 0.

因此“转成积分并得到某个正下界”不足以得到 uniform half；所需的是对所有 n、tau≤n 的统一 1/2 付款。必须保留离散末端，证明跨源新行实际支付这项缺口。

## 5. 近边界不会迫使常数个极大主题

恢复既有 all-big 匹配族，**不是新构造**。对 n≥2：大主题 B_0 含 n 个客户，另有 n−1 个彼此及与 B_0 不交的 singleton 主题 B_1,...,B_(n−1)。规定每个有序历史的当前玩家均选 B_0。

任意历史长度 t，已有 a 个 B_0，尚余 r=n−t 人。遵循策略获得 n/(a+r)≥1；改选 singleton B_j 的最终收益是 1/(q_j+1)≤1，因为其后仍全选 B_0。因此这是全部有序历史上的完整纯 SPE，包括所有离轨历史。

    W=n, OPT_n=2n−1, tau_C=n, M=n,
    OPT_n/W=2−1/n →2.

该最优并集需要所有 n 个不交主题，删掉任一主题都会降低 OPT_n；实际路径上的每位玩家又对其余 n−1 个 singleton 偏离全部取等。故若 active 指“保留最优并集所需主题”或“真实在轨取等偏离主题”，active 数目都无绝对上界。末位只选 B_0，却遗漏 n−1 个 singleton。

这不反驳下述更窄的条件型猜想：**若存在严格违反 half 的实例，则能从某个最小反例构造出不超过 K 个极大主题的完整 SPE 严格反例。** 该命题尚缺明确定义的约化、全部历史策略重构及坏效率保留；不能由近边界或末位极大推断。

另一个相关递推跳步也已解析审查：mixed-floor 的 f_j 在转移 p→p+e_j、r→r−1 时，全部共享项不变，但 private 项下降恰为 w_{ {j} }/[(p_j+1)(p_j+2)]。所以完整 f_j 的无条件单调性为假。可保留的逐步亏损、q 步望远镜式及补偿势，见 [private_recurrence_audit.md](private_recurrence_audit.md)；补偿势单调不能代替真实福利付款。

## 6. 正向回收：带共享遗漏缺陷的任意人数上界

下面是已有混合席位预算的直接推论，不把重新发现旧预算称为新机制。唯一原来源是 `research/workspaces/customer-attraction/R-324fbf8f72b041578583b51189f13d1a/dynamic_budget.md` §2，尤其 (2.5)；该式与共享正文的私有遗漏席位谱兼容。

固定任意最优并集 O，实际覆盖为 C0，设

    I=|O∩C0|,
    Dp=|(O\C0)∩(全部极大全局私有块)|,
    Ds=|(O\C0)\(全部极大全局私有块)|.

故 OPT_n=I+Dp+Ds；Ds 只数实际遗漏、且在整个目录中至少属于两个极大主题的客户，不数所有共享客户。

只在比较元组内把每个最优主题扩成包含它的合法极大主题。并集不能超过 OPT_n，因此并集仍恰为 O。这不更改原策略、实际行动、目录或任何离轨续局。得到不超过 n 个极大主题的比较索引集 J。

对每个全局私有块 P_j，固定 Q_j=P_j\C0，令 a_j=|Q_j|、v_j=|B_j\Q_j|。既有席位谱总额 Lambda 满足 W≥Lambda，并且前 n 大席位之和至少为 J 内各第一席位之和，所以

    W ≥ Lambda ≥ Σ_(j∈J)(a_j+v_j/n)
      ≥ Dp+(I+Ds)/n.                                      (P)

保留实际在最优外覆盖的客户数 E=|C0\O|=W−I≥0。令 eta=1−1/n，由 (P) 得更精确的净差上界

    OPT_n ≤ (2−1/n)W + (1−1/n)(Ds−E).                     (D)

等价的非负账为

    [(2−1/n)W+(1−1/n)(Ds−E)]−OPT_n
      = W−Dp−(I+Ds)/n ≥0.

若丢掉 E 的信用，就得到较弱的 OPT_n≤(2−1/n)W+(1−1/n)Ds；不能在后续共同付款中再次重复花掉这份 E。

因此任意 n≥2 有一个可直接使用的充分条件与反例必要条件：

    Ds−E ≤ W/(n−1)  =>  OPT_n ≤2W;
    OPT_n >2W       =>  对每个最优并集 O，Ds−E > W/(n−1).

n=6 时，真正目标反例必须有 Ds>E+W/5。特别地它必须遗漏超过 W/5 个**全局共享**最优客户。它不同于既有根回复触及集合 B 的 |B|>W/5：两个集合的定义不同，不可合并。

Ds=0 恢复并在 E>0 时加强既有锐界 2−1/n；all-big 家族 E=Ds=0，恰取等。Ds>0 时 (D) 精确显示尚需支付的净缺陷，而没有声称所有 SPE 自动满足 Ds−E≤W/(n−1)。这个阈值作为旧预算的直接推论保存，不认领全球新颖性。

## 7. 下一项有信息价值的义务

活跃维度坍缩不是唯一可能途径。已有私有遗漏席位谱在无界 M 下证明：若某个最优并集的实际遗漏全为极大全局私有客户，则 OPT_n≤(2−1/n)W。它直接处理上面的高维近边界族，无需压到常数个极大主题。
