# 四人共同laminar约束

有限goods、四名代理、任意非负实可加估值v_i；各代理的包须满足同一个可四着色laminar独立集系统，所有物品完整分配。对每个预先指定代理次序，问是否存在完整可行分配X，同时满足goods EF1：对所有i,j，若X_j非空则存在g∈X_j使v_i(X_i)≥v_i(X_j\{g})；并且次序靠前i对靠后j满足v_i(X_i)≥v_i(X_j)。空包比较自动成立。

两个固定key为类别大小(3,3,2)、每人每类至多1且总至多2，以及(3,3,3,3)、每人每类至多1且总至多3。两key的连续估值全称命题和通往一般laminar实例的约化都是需要准确审定的承重接口；K8/K12的有限整数profile没有解决它们。

# 任意人数goods-with-copies

任意有限人数n、类型集G，类型g有整数1≤c_g≤n个等值副本。同一代理每类型至多一件，全部副本分完。用x_ig∈{0,1}、∑_i x_ig=c_g表示分配。每个代理按其类型偏好次序，对任意其他代理j及每个前缀P要求∑_{g∈P}x_ig≥∑_{g∈P}x_jg−1。这是SD-EF1；不附加PO。严格次序是这里明确的序数合同，含ties的扩展须另给约定。

任意人数、任意类型数的存在性仍OPEN；三人任意类型是受限目标，至多四非全体类型的9216个严格profile和较大随机样本只是有限证据。逐人舍入误差1一般只产生两人间误差2，不能直接推出目标1。

两对象分别见[候选、解析方法反例与前缀接口](../资料/可加公平与副本前缀目标的候选反例分层--资料.md)和[固定profile见证](../审查/退役公平商品有限玩具结果--审查.md)。它们不由EFX+fPO反例、三值chores或一般partition反例互相推出。
