# 模型和精确枚举域

四人、三类可加chores，重数(3,5,5)。前两人成本(20,1,7)，后两人成本(20,7,1)，完整分配。计数矩阵x_it为非负整数、每列和等于相应重数；同类标签不影响任何比较，所以此商域完整代表原实例的所有标号分配。

对一个矩阵，令u_ij=∑_t c_it x_jt。自身非空包最难删除的是其中成本最小物品m_i，所以准确因子为
\[
α(x)=\max\left(1,\max_{i,j}\frac{u_{ii}-m_i}{u_{ij}}\right),
\]
空自身包只给0左项；正数除0视为∞，0/0不给约束。这里必须删自身物品，不能照goods删对方。

枚举每列所有四部弱组合，共C(6,3)C(8,3)^2=62720矩阵，逐个按此式用有理数比较，最小值为23/22、恰4个最优矩阵，EFX矩阵0。此结论已按该计数域独立全枚举回算；它仍只是固定13件实例，不是任意参数分类。

一个见证为X_1=(0,3,3)、X_2=(1,2,0)、X_3=X_4=(1,0,1)。第1人成本24，最小自身物品成本1，删后23；其评价第2包为22，故下界23/22在此出现。其余人的自身成本依次22、21、21，最难删除后依次21、20、20；按各自评价其余包的最小成本分别24、21、21，全部达到至多23/22。

[固定边界与双oracle](../审查/三值家务EFX反例与公平fPO边界三源处置--审查.md)中“第1人删除R-cost item”是文字误写：X_1没有R类物品，正确是删成本1的物品。[142个删除子实例和473点网格](../审查/三值家务删除极小性与参数网格三源处置--审查.md)独立保留有限计数与21个失败点；它们不证明连续区域、全局最小件数或一般人数结论。
