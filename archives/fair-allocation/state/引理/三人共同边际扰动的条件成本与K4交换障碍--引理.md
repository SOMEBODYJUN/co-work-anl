# 共同边际给出的准确恒等式

三名无权玩家的纯策略为资源基B_i，资源e的成本d_e(t)依总使用人数t。取各玩家全支持基分布q_i，且资源边际共同为p_e；不同玩家独立混合，不要求同一玩家各资源独立。固定纯核B和0<ε<1，令x_i=(1−ε)δ_{B_i}+εq_i。

对玩家i，若其他两人的纯核在e上分别为b、c∈{0,1}，令r=(1−ε)b+εp_e、s=(1−ε)c+εp_e。选择e的条件期望成本恰为
\[
D_{i,e}=d_e(1)(1-r)(1-s)
+d_e(2)[r(1-s)+(1-r)s]+d_e(3)rs.
\]
因此两候选纯基S,T的成本差为∑_e(1_{e∈T}−1_{e∈S})D_{i,e}；若比较把同一q_i附在两个纯核上的扰动策略，则再乘1−ε。证明只需对其他两名玩家是否使用e的四个独立事件全概率展开，并对资源求和。

按其他核使用人数ℓ=b+c分组，这正是公共有效延迟
\[
\widetilde d_e^ε(k)=\mathbb E[d_e(1+
\operatorname{Bin}(k-1,1-ε+εp_e)+\operatorname{Bin}(3-k,εp_e))],
\quad k=1,2,3.
\]
两个二项量独立。以同一均匀随机数把一个Bernoulli(εp_e)替换成Bernoulli(1−ε+εp_e)，可见非减d_e给出非减有效延迟。式子是次数至多2的有理ε多项式；它没有自动给出原normal-form的纯perfect算法。

[固定有限审计](../审查/共同边际三人Nash有限审计--审查.md)保存p=(1/5,11/20,11/20,7/10)、三组延迟、5625次等式和计数5/11/3。该JSON没有完整基族和字典序规则，故不能用本通用恒等式反推那些计数。恢复基族、扰动分布与并列规则仍是精确重放义务。

# K4的强交换Hall证书

K4边编号0,…,5依次为01、02、03、12、13、23。取两棵树B={0,1,4}、C={2,3,5}。把e∈B与f∈C相连，当且仅当B−e+f与C−f+e都为生成树。直接逐边删加得到
\[
N(0)=\{2,3,5\},\qquad N(1)=N(4)=\{5\}.
\]
因此S={1,4}的邻集只有{5}，Hall不等式1<2排除任何全体元素都可同时单交换的双射，更排除strong base-ordering（后者还要求所有子集交换）。这不是一般基交换公理的反例，也不否定Nash存在或BMKP近似；仅阻断把任意graphic基对视为strongly base-orderable的拼接接口。
