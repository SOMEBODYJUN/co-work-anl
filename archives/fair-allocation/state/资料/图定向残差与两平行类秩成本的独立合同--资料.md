# 图定向残差与两平行类秩成本的独立合同

两套账本中的图goods定向和matroid-rank chores是不同模型，公平不等式方向也不同。本资源分别保其精确陈述与承重机制；图证明、rank2构造及root复核全文实读，广义rank2报告只读对应FC01段。原有限计数是历史证据，本批不重跑。原件见[总证据](../../../../tools/evidence/retired-topic-claims/README.md)。

## 端点可加goods图：残差定义及三项结果

每条物品边只可给一个端点，估值非负整数且可加。固定部分边后，$s_i\ge0$是$i$自己的固定价值，$h_{ij}\ge0$是$i$对给$j$的固定边的价值。每对余$m_{ij}$条对两端均值一的单位边，$x_{ij}+x_{ji}=m_{ij}$。完整EF恰为

$$R_i=s_i+\sum_jx_{ij}\ \ge\ h_{ij}+m_{ij}-x_{ij}\quad(i\ne j).$$

非邻接pair的$h$仍要检查。heavy边指至少一个端点值至少二，参数$k$为其数目；重数和价值均按二进制位长收费。

**FP-COUNTER-BALANCE-v1。** 五顶点$v,u,w,z,t$，唯一heavy为$vu$、两端值87；$uw,wz,zt$各100单位平行边。有EF：heavy给$v$，三包依次分为$(87,13),(74,26),(50,50)$，自身值$(87,87,87,76,50)$。叶$v$迫使heavy给$v$。若把非heavy端点内部包$wz,zt$都先50/50，设$uw$给$u$数$a$，则$w$不妒忌$u$需$a\le75$，$u$不妒忌$v$需$a\ge87$，矛盾。它只反驳“普通内部平行包全平分”的压缩，不反驳一般multigraph FPT；路径可传输非奇偶级收益。

**FP-FOREST-THRESHOLD-v1。** 若单位边简单支持为森林，任意非负整数$s,h$的完整残差可在位多项式时间判定并输出整数方向。树节点$i$从父$p$包拿到的可扩展数恰为$[L_i,m_{ip}]\cap\mathbb Z$。对孩子$c$令$U_{ic}=m_{ic}-L_c$、$S_i=\sum_cU_{ic}$；同时取全部$U$增加$i$自身价值并降低对孩子的可见价值，没有子包间权衡。于是

$$L_i=\max\left\{0,\left\lceil\frac{h_{ip}+m_{ip}-s_i-S_i}{2}\right\rceil,\ \max_c(h_{ic}+m_{ic}-U_{ic}-s_i-S_i),\ \max_{j\notin\{i,p\}\cup C_i}(h_{ij}-s_i-S_i)\right\}.$$

孩子不可行则拒绝；根以父输入零检查，向下给孩子恰$L_c$可恢复。跨树或非邻接$h$只是固定门槛，不耦合变量。无需逐单位边循环，稀疏$h$下算术次数$O(n+|\operatorname{supp}h|)$。安全预处理后枚举heavy方向给单位支持forest的$2^k\operatorname{poly}(bits)$推论，不解一般multigraph。原4200整数oracle实例核的是实现，不是普遍证明。

**FP-CHARITY-SIMPLE-v1。** simple无环边图、端点非负整数可加值、每边非负二进制删除成本，可用$3^k\operatorname{poly}(bits)$构造成本最小EF partial orientation。零/单正端边保留给有价值端点安全。heavy每边枚举两方向或删除，固定$s_i$与$i$对其他heavy包的最大可见值$q_i$。

单位分量有$s_i>0$或$q_i>0$时称anchored。任何EF部分解可补回全部单位边：两端自身值均至少一时，加边只使非接收端可见值至多一；active到零值端的边给零值端，使其变active且仍EF，再沿连通性传播。**simple承重**，平行或同pair heavy会破坏可见值至多一。无anchor分量若有环可全部定向；若为树，任何非空保留森林都需每点至少一入边，与边数少于顶点数矛盾，故其全部单位边必须删。剩余单位边的完整可行性为每点至少$b_i=\max(0,\max(q_i,\mathbf1_{\deg_H(i)>0})-s_i)$入边，用单位边节点流解。$b_i>\deg_H(i)$先拒绝，避免伪多项式。各branch只删必需树边，故任意非负删除成本亦成立；原1200次实验只核删边条数，不认证一般multigraph或新颖性。

## 不可加chores：两平行类引理与未解rank≤2目标

**FC-LEMMA-R2-2C-v1**来自independent_review。每个$i$有$A_i\sqcup B_i=M$，可空类但无loops，成本$c_i(X)=\mathbf1_{X\cap A_i\ne\varnothing}+\mathbf1_{X\cap B_i\ne\varnothing}$。所有物品完整分配。EF为$c_i(X_i)\le c_i(X_j)$；chores EFX为对**每件自身物品**$g\in X_i$（含零边际）有$c_i(X_i\setminus\{g\})\le c_i(X_j)$。$m\ge n$时有位多项式构造的完整EF，$m<n$时每人至多一件给EFX；不额外求PO。

给物品写$n$位word，位$i$记所属平行类。全$2^n$类型出现时，选$n$个互补pair，每包对每人均成本二；此时$2^n\le m$，不是指数扫描。若有缺字$w$，构造$i$邻接word第$i$位不同于$w_i$的物品。每物品有邻居；若有覆盖agents匹配，先各一件，再给剩余物品任一邻居，owner成本一、所有包非空，得到EF。

若最大匹配大小$k<n$，从未匹配agents交替可达$S,T$，有$|T|<|S|$，$S$的所有邻居在$T$。若每个单坐标翻字$w^{(i)}$都出现，选相应物品会给$|T|\ge|S|$，矛盾。取仍缺失的翻字，先沿交替路令该$i$未匹配，再选**全局未匹配物品**$e$。因$m\ge n>k$存在，且$e\notin T$，翻位后可增广。只选$e\notin T$不保证未匹配，是原稿已修的关键细节。至多$n$轮；trie找缺字不枚举全cube，保守$O(n^3m)$。

**TS-CHORES-RANK2-EFX-v1**仍是另一开放目标：任意$n,m$、个性化rank≤2拟阵成本，允许loops及任意多个平行类，成本为$\min(2,\text{触达非loop类数})$，求上述全删除量词的完整EFX。两类无loops只覆盖其子类。loops使他人非空包可能成本零；三类时“异于缺字”不再使owner成本一。三类触达数不截断的测试不是rank cap二；后补真正cap二的有限样本仍不证明全类。$U_{2,3}$两人三物品已说明更强EF可失败，但不否定EFX。

原内部独立性均按源记录：root重构图证明，rank引理经cross-field及boss4攻击后修正；本批读稿不是新一轮盲审或外审。一般heavy-multigraph FPT与一般rank≤2 EFX均未被这五Claim解决。关系是各受限算法/反例的适用域说明，图goods不迁移为rank-chores定理。
