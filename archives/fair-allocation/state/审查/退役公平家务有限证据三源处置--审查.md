# 阅读范围与模型分离

本页处置三个冻结的结果摘要 JSON。原件路径、blob、SHA、大小、字段检查和校验脚本见 [retired-fair-chores-results-20261031](../../tools/evidence/retired-fair-chores-results-20261031/)。`validation.json` 只做完整性/字段形状检查，不是数学证明；尚未认领的生成脚本没有被冒充为本批已重跑。

`construct_rank2_results.json` 与 `rank2_cap_results.json` 是不可分割 chores 的个性化低秩/平行类成本实验，服务于 `FC-LEMMA-R2-2C-v1` 及其未解决的 rank-cap-2 扩张。`mixed_extension_results.json` 是另一模型：简单图 (G=(N,M)) 的 signed additive endpoint orientation，每条边必须给某个端点，agent (i) 只评价 incident edge。其 (EFX^+_0) 语义是嫉妒时可从自己包删任意非正 item，或从对方包删对自己严格正 item；它与 chores-EFX 的删除方向不同。因此仙人掌反例不能移植成 rank-cap-2 反例，两类无 loops 的 rank 引理也不能推出图定向存在性。

# 1. 6be：两平行类无 loops 构造的有限运行

冻结文件 SHA-256=`de64d82efac0cbf667e6af8cf3594177a1861acd8657d8d2f9f72c4d112b94b4`，大小 356 bytes。记录局部引理 `FC-LEMMA-R2-2C-v1`、seed `20261020`、随机 (n=2,ldots,8)，每个 (n) 的 (min{n-1,n,2n,4n,100}) 各 100 例，另有每个 (n) 一个 full-cube 例，总数

[
7\cdot5\cdot100+7=3507.
]

结果字段报告最大 observed matching-flip rounds 为 2，并写明 `complete; EFX always; EF if m>=n; matching strictly increases`。这说明原型在所列输入上检查完整分配、EFX，并在 (mge n) 分支检查 EF；它不是全输入穷举。观察到 2 轮不能替代引理证明中的“至多 (n) 轮”论证，也不能推出常数轮算法。

相邻引理正文的模型是 (A_isqcup B_i=M)、无 loops，(c_i(S)=1[S\cap A_i\ne\varnothing]+1[S\cap B_i\ne\varnothing])；目标为 (m\ge n) 的完整 EF 或 (m<n) 的每人至多一件 EFX。结果文件只给运行聚合，不给新证明。承重仍是 word/Hall 缺字增广及“全局未匹配 item”修正；三平行类、loops、任意 partition/general matroid 均未被此文件覆盖。处置：`integrated-finite-evidence`，不把 3507 写成全部 rank-2 实例，也不把 full-cube 少数实例写成 (2^n) 域证明。

# 2. e5cd：混合图 (EFX^+_0) 的有限正面与仙人掌障碍

冻结文件 SHA-256=`715fc947fd2b4de815d1781aad500d7c17c4d4dd12b742381b996ed06ae319e9`，大小 1803 bytes。

## 小环穷举

| 图 | endpoint 值域 | profiles | 标记 | 结果 |
|---|---|---:|---|---|
| (C_3) | ({-1,0,1}) | 729 | `exhaustive=true` | `no_EFXplus0_witness=null` |
| (C_4) | ({-1,0,1}) | 6561 | `exhaustive=true` | `no_EFXplus0_witness=null` |

729 和 6561 分别是 (3^6,3^8)，即每条边两个端点编码的有限域。候选报告说明对应 toy search 对每个 profile 枚举全部 (2^{|E|}) 定向；JSON 保存的是聚合字段，所以只能说该有限编码域未见 checker 反例，不能说任意 signed rational cycle 有解。零值保留，因为可删非正项正是零值边界。

## 六点单圈加树枝

边为
[
(0,1),(1,2),(2,0),(0,3),(3,4),(2,5),
]
即三角环接长度二挂链和叶子。值域为 ({-2,-1,0,1,2})，seed `20261025`，10000/10000 个随机 profiles，每个 64 个 orientations，`counterexample_to_universal_EFXplus0=null`。这只是固定有限随机抽样内未失败；不覆盖任意整数/有理值，也不证明 unicyclic 存在性。

## 五点双三角 cactus 的局部反例

边为
[
(0,1),(1,2),(2,0),(0,3),(3,4),(4,0).
]
值域同上，请求 1000 个 profile，但只完成 687 个；seed `20261026`，每个 64 个 orientations。`trial=686` 的 `counterexample_to_universal_EFXplus0` 给出按六条边顺序的六对端点 utility：
[
(1,2),(-2,-2),(-2,-2),(-2,0),(-2,-1),(-2,0).
]
六对对应六条边，不是六个 agent 的效用向量。字段表示在此有限编码下 64 个定向均未通过 universal-(EFX^+_0) checker，故保留为一个**局部有限反例/障碍证书**。它没有完成其余 313 个 profiles，也没有给任意仙人掌的反例族；正确结论是不能把仙人掌普遍存在性当已知，而不是所有仙人掌都失败。后续若引用，必须读取 `mixed_extension_toys.py` 并复核 64 方向和判定器。

处置：`integrated-finite-counterexample-and-boundary`。保留图、值域、seed、完成数、方向数和端点对；不升级为 unicyclic/cactus 定理，也不迁移到 rank chores。

# 3. d096：三平行类 rank-cap-2 toy 的有限抽样

冻结文件 SHA-256=`e0d37e6b62c3fb25377ed8d3d69d0c1afc0cef95ec195bc106d3f47501f16162`，大小 737 bytes。三行都记有 `parallel_classes=3`、`rank_cap=2`、`counterexample=null`：

| (n) | (m) | loops | profiles | 每 profile 完整分配数 | seed |
|---:|---:|---|---:|---:|---:|
| 3 | 9 | false | 1000/1000 | (19683=3^9) | 20261027 |
| 3 | 9 | true | 1000/1000 | (19683=3^9) | 20261028 |
| 4 | 8 | true | 250/250 | (65536=4^8) | 20261029 |

`requested_trials=completed_trials` 只表示随机 profile 计划完成；profile 仍抽样。每个 profile 内部遍历 (n^m) 个完整分配，故是“profile 抽样、allocation 穷举”，不是 rank-cap-2 全域穷举。JSON 没有展开类标号、loops 位置、成本矩阵或 witness allocation，因此不能从聚合行补写未记录的普遍定义。它是开放目标“任意 rank≤2、允许 loops 和多个平行类”的 toy test；loops=true 未发现反例，不代表 loops 不会破坏两类引理中他人非空包成本至少 1 的论证。

处置：`integrated-finite-evidence`。保留 seed、profile 计数和 (3^9/4^8) 完整分配枚举；空 `counterexample` 只表示抽样未发现 checker 反例。下一步可按 item-word multiset 对称约简穷举，再用独立实现或 CP-SAT/ILP 寻找最小障碍；在此以前不得写 rank-cap-2 一般 EFX/EF 定理。
