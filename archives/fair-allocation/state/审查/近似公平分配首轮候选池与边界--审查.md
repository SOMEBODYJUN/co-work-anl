# 旧问题的边界修正

报告先逐项排除了若干容易误读的旧说法：

* additive chores 的 EF1+PO 已有 weighted EF1+fPO 结果；固定人数可多项式计算。能保留的是一般人数
  的算法边界或受限输入，不是“存在性仍未解决”。
* 一般 additive chores 的 EFX 存在性已被三值反例否定（报告引用 He--Tao 的 `n\ge4` 定理）。
  三人仍是独立问题，不能把一般存在性重新当主目标。
* bivalued chores 的 EFX 只在 `n=4` 得到报告所引的完整正结果；`n>4` 仍是另一量词。
  EFX 与 PO 的兼容性对 `n\ge4` 有严格正反例，不能写成无条件兼容。
* multigraph additive EFX 的 cancelable 类已有多项式算法；这和端点 goods 的 EF orientation
  不是同一模型。不能把 allocation 算法直接迁移成 orientation 定理。
* strongly EFX-orientable simple graph 已有完整刻画；“再研究二分图/树的旧空隙”不是本报告的新主线。
* personalized bivalued goods/chores 的 exact MMS 已有后续工作覆盖；两类型纯 chores MMS 不能再

* 三人小件数 chores 的旧门槛已经被后续结果推进，不能用旧的 `2n` 说法制造新颖性。

# 工具本质与可接续边界

报告把母文献按“分类工具、组合工具、视角转换、问题驱动”拆开。可复用的接口而非论文标题如下：

1. **图 orientation。** 二值边以偶数平分、奇数由种子吸收；simple heavy 固定后可变成度约束。多重图
   需要显式保留平行边重数和非对称可见值；现有 `FP-COUNTER-BALANCE` 只反驳“内部平行包全平分”的
   压缩，不是否定一般 FPT。
2. **冲突公平。** maximal partial allocation 可在完整分配不存在时仍有定义；uniform 情形可写成
   maximal equitable partial coloring。cactus/cograph 需要新接口状态，不能把 tree 的单根归纳当成环块证明。
3. **chores matching/deficient sets。** 四人二值和 `m<=2n` 等工具只在准确量词下可用；degree-2

   的最小动作是实现双 size 的交换或给出精确失败机制，而不是把 density greedy 的特殊结论改名。
5. **计数型 EFX。** join-graph 或分配图可用于 F13，但随机最小值不是连续估值空间的证明。
6. **MMS/在线资格。** 两类型 MMS 的二维几何和 weak/strong eligibility-aware 定义必须先完整读取，再谈
   exception 或 recourse；报告明确把 P09--P11 只当工具导入线索。

# 内部完整引理：complete multipartite 的 uniform maximal EF1

报告中唯一给出完整自足推导的是如下受限命题，单独不声称文献新颖性；完整证明另存为
[完全多部图均匀最大 EF1](../引理/完全多部图均匀最大EF1--引理.md)。

设冲突图是 complete multipartite，part 大小按
`s_1 >= ... >= s_k` 排列。每个 agent 的价值为 bundle 的基数。分配允许有未分配顶点，但每个已分配
bundle 必须是独立集；`maximal` 是任何未分配顶点都不能加入任何非空 bundle（及空 bundle若尚有）而保持独立。
则对任意正整数 `n`，存在可多项式构造的 maximal EF1 分配。

* 若总顶点数 `M<n`，把每个顶点单独给不同 agent。所有顶点已分配，EF1 与 maximal 立即成立。
* 若 `s_1>=n`，只用最大 part，把它均匀切成 `n` 个非空 bundle。其余 part 的每个点都邻接所有
  bundle，故不能补入；bundle 大小只差 1。
* 否则 `s_1<n` 且 `M>=n`。取最短前缀 `s_1,...,s_l` 使 `S=sum s_i>=n`，于是
  `S_prev=sum_{i<l}s_i<=n-1`，且 `l>=2`。令 `r=s_l`。对第 `i` 个 part，拆成 `k_i` 个大小 1 或 2
  的 bundle 当且仅当 `ceil(s_i/2)<=k_i<=s_i`。有
  \[
  \sum_{i=1}^{l}\lceil s_i/2\rceil
  \le S_{prev}-(l-1)\lfloor r/2\rfloor+\lceil r/2\rceil
  =S_{prev}-(l-2)\lfloor r/2\rfloor+(r\bmod2)\le n.
  \]
  末一步用 `S_prev<=n-1`；当 `l=2` 且 `r` 奇时右端至多 `n`，其余情形更小。又 `n<=S`，
  因而可从各 `ceil(s_i/2)` 逐个增大 `k_i` 直到总和为 `n`。选中 parts 的全部顶点按这些
  `k_i` 个 bundle 分配，未选中 part 的顶点全部邻接所有 `n` 个非空 bundle。大小差至多 1，
  且未分配顶点不可补入，故得到 maximal EF1。

这个引理的算法只需排序/前缀和和在每个 part 中按 1、2 分组，位复杂度对显式顶点输入为多项式。
它是 cograph/join 模块研究的 toy，不足以宣称 F03/F04 的 cactus 或 cograph 全类定理；当前存档不把
它与三值 chores、copies 或端点 goods 的模型合并。

# 有限实验与准确证据边界

报告记录四组确定性整数枚举；这些数字属于固定输入，不能提升为普遍结论：

1. 四人三 item-type 模板 `(3,5,5)`，前两人成本 `(20,1,7)`、后两人成本 `(20,7,1)`，按
   type-count 分配穷举 `C(6,3) C(8,3)^2 = 62,720` 个状态，EFX 数为 0。这是已知反例复核。
2. 固定成本 `(1,7,20)` 的所有非空坐标子实例 `0<=a<=3, 0<=b,c<=5, a+b+c<=12` 共 142 个，均有 EFX。
   这只说明该固定反例按删除 item 的极小性，不能证明 13 是一般最小件数。
3. 固定 `(3,5,5)`、`r=2..12`、`L=r+1..50` 的 473 个整数参数点中 21 个无 EFX；报告列出
   `r=7:L=20`、`r=8:L=22..23`、`r=9:L=24..26`、`r=10:L=26..29`、`r=11:L=28..32`、
   `r=12:L=30..35`，并观察它们落在 `2r+6<=L<=3r-1`。这是有限网格规律，不是实参数定理。
4. complete multipartite 构造在总顶点数 `1..30`、人数 `1..12` 的所有分拆共 343,536 个实例中，
   独立性、不重分配、maximal 和大小差检查均失败 0。它是实现核对，不替代引理证明。

报告声明整数中间量远低于 int64 且无随机步骤；当前结果分支没有对应 `exact_probe.py` 与报告中的三个
JSON，因此“可复现”仍应以冻结原件或后续补录为准。后续若补录脚本，必须把脚本、输入、输出哈希与
本文的四组量词分别登记，不能只保存数字。
