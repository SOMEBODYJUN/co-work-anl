# 身份与阅读范围

本页三个 source 分属三种 fair-allocation 对象：

1. two-agent/two-type additive goods 的 WEFX 与 fractional PO；
2. 四代理三类型 additive chores 的固定 probe 输出（此前 exact_probe 的结果）；
3. 三代理五件 additive goods 的 EFX 单调 Pareto completion obstruction。

它们没有共同 allocation 量词。原件、脚本、SHA、manifest 与字段验证在 [retired-fair-efficiency-and-probe-20261031](../../tools/evidence/retired-fair-efficiency-and-probe-20261031/)。

# 1. fair_fpo_independent.py：两代理 WEFX/fPO 的双 oracle

source ID `6fe26fc4bbecbc09db7a`，大小 4649 bytes，SHA-256 `182a7bbff5f36771281b9272606da8ad7163acae73089462a7cbb0abf9b6ca2e`。

脚本固定两代理、两类 goods 数量 (A,B)，values ((1,a))、((1,b)) 和正权重。`support_fpo` 用正社会权重比的公共区间判定 fractional PO；`domination_fpo` 在 ([0,A]\times[0,B]) 多边形的所有边界交点上用 Fraction 检查是否存在双方效用不降且一方严格提高。`instance` 逐个整数计数分配计算 WEFX 质量：对方 bundle 删除任一 item 后的最大残余进入比值，权重乘法全部精确有理数。

主程序遍历 (A,B\in\{0,1,2,3})、(a,b\in\{1/2,1,2,3})，共 256 instances、1600 allocations；每个 instance 要求 support 与 polygon oracle 相等。已知 (A=B=2,a=10,b=9) 输入断言唯一 EFX allocation 为 ((1,1))，最优 fPO-compatible quality 为 (10/11)，并检查显式 fractional domination witness。还检查 (a=b) 时 best quality=1、(a=k,b=k-1) 的 family 和 weights (w_1\in\{1,2,3\})。

这段代码把 ac128 边界笔记的“256/1600 两种判定一致”变成实际实现合同，但仍是有限整数/有理网格；它不证明任意 A/B、任意正有理 values、多个 agent 或多类 goods 的近似界。其正确处置为 `integrated-reproduction-method`，已知 2×2 反例仍是独立文献事实。

# 2. probe_results.json：三值 chores probe 的完整冻结输出

source ID `09cd80ea744e9a27eed1`，大小 1020 bytes，SHA-256 `5aca6a807c1134a43e2506d25df9f9067c80f2bac6d38e3fdbdeb5cc11fb9e74`。它是 `exact_probe.py` 的冻结输出，补充此前仅读 JSON 行的边界：

- `he_tao_reproduction`：4 agents、type multiplicities ([3,5,5])、cost rows ([20,1,7]) 两行与 ([20,7,1]) 两行、62720 allocation types、0 EFX types；
- `fixed_13_grid`：middle 2..12、large middle+1..50，共 473 点，21 个 nonexistence points；
- `deletion_minimal_probe`：固定 costs ((1,7,20)) 的所有非空坐标子实例，共 142 个，`nonexistence_instances=[]`；
- `multipartite_lemma_check`：总件数 1..30 的所有整数 partitions、agents 1..12，共 343536 cases，`failures=0`。

前三项与本档“删除极小性/参数网格”正文的 JSON 一致；第四项是 exact_probe 新增的结构 sanity check，验证 `multipartite_coloring` 的近均衡同 part bundle 约束。它不检查 EFX，也不证明任意 multipartite chores 存在性。该输出没有随机 seed，算术字段为 int64 exact、entries 至多 50、13 chores。

正确处置为 `integrated-finite-evidence`：保留 343536 这个完整已写出的输出字段，但不把它与三值 EFX 0/21 结果合并成一般 theorem。

# 3. personalized_efx_completion_independent.py：单调 EFX completion 的条件障碍

source ID `092251127b7b6ba4b3ca`，大小 4034 bytes，SHA-256 `b94cbc26e72d1acc9ff2dbaf33ac40d8e42a302e947fe3fd487333962cf2bfc0`。输入是三代理五 goods 的 additive values family

$$
(1,1,1,a,a),\quad(1,1,b,1,1),\quad(1,1,c,c,c),
$$

目标 allocation 是 agent 1 拿 goods 4、5，agent 2 拿 1、2，agent 3 拿 3；`audit` 穷举全部 (3^5) assignments，逐个 observer/recipient/item 检查 EFX（删除对方包中的每件 item），并用 Fraction 记录 utilities、violations、ordinary integral Pareto dominators。

基例 ((a,b,c)=(2,3,4)) 的 target utility 是 ((4,2,4))，target 本身 EFX；存在两个 strict Pareto dominators，但它们都非 EFX，因此 `completion_failure=true`，同时全域仍有其它 `efx_po_allocations>0`。这只反驳“从任意 EFX allocation 出发，总能逐点效用不降地补到 EFX+PO”的**单调 completion 路线**，不反驳 EFX+PO 存在性。

脚本还检查 (a\in\{7/4,2\},b\in\{2,3\},c\in\{5/2,4\}) 的 8 个 family profiles，断言 obstruction 当且仅当 (a<2) 或 (b>2)；边界 ((3/2,3,4),(2,3,2),(2,2,4)) 和空/零值/单 goods degenerate cases 作为独立 control。所有 assignments 与 dominance 均用 Fraction，无 scout imports、无浮点。

此源的身份是条件方法障碍，不是 EFX+PO nonexistence certificate。应标为 `integrated-reproduction-method`，并在第三阶段作为“反驳单调补全路线”关系连接到 fair_goods 的 ordered EF1/fPO 候选；不得把 `completion_failure` 重新命名成目标问题失败。

# 4. 逐源处置与跨模型边界

- `6fe26fc4bbecbc09db7a`：two-agent goods WEFX/fPO 双 oracle，有限 exact crosscheck；保留已知 10/11 counterexample boundary。
- `09cd80ea744e9a27eed1`：固定 trivalued chores probe 输出，整合 62720/473/142/343536 字段，保持有限且模型内部。
- `092251127b7b6ba4b3ca`：三代理 additive goods 单调 EFX completion obstruction，明确不否定 EFX+PO 存在性。

这三项不能连成公平—效率普遍定理：WEFX/fPO 使用 fractional goods 与权重；三值 chores 使用删除自身 item 的 EFX；monotone completion 使用 ordinary integral PO 与另一个 EFX 量词。第三阶段关系只能标为“有限复现”“已知反例”“方法障碍”和“模型对照”。
