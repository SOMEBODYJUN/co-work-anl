# 两容量联合类型与有限舍入审计

## 来源、版本和比较范围

相关工作也逐字旁读了 `generalized_assignment/TWO_CAPACITY_LEMMA.md`、`cross_field_battle/bmkp_algorithm_review.md`、`generalized_assignment/candidate_report.md` 和 `VERIFICATION.md` 的对应段落。候选稿给出 GA-03-L1 全局联合 critical 交换、GA-03-L2 两容量 short 匹配、GA-03-L3 允许弃置的 cheap LP 舍入；反方稿把这些称为“有希望的候选，非已证定理”，并列出 profile 输入、边界参数和算法级重放仍未完成的义务。本 JSON 是局部有限检查，不是该候选的完整实现。

## 审计对象和算术域

JSON 声明使用整数与 `fractions.Fraction`，联合 canonical 采用种子 `20261020`；其余有限审计为穷举。因而下面的“通过”只针对列出的有限输入、给定的随机种子和固定整数/Fraction 计算，不外推到任意容量、任意利润或任意 item eligibility。

### 1. Transversal merge

六个元素的邻接集合为

\[
\{0,1\},\ \{0,2\},\ \{1,2\},\ \{0\},\ \{1\},\ \{2\}.
\]

审计枚举 17 个基，并检查 136 对基。两组示例基为 `[0,1,2]` 和 `[3,4,5]`；一条强双射记录为 `0↦3,1↦5,2↦4`。在另一组 8 个随机结果中，分数成本为 `23/2`，整数选择成本为 11、9、10、10、10、10、9、11。两行均值审计分别记录

| \(\mu\) | raw mean | variance | variance bound | selected-cost mean | max selected error |
|---:|---:|---:|---:|---:|---:|
| \(3/2\) | \(3/2\) | \(3/4\) | \(3/4\) | 1 | \(3/2\) |
| \(5/4\) | \(5/4\) | \(17/144\) | \(5/8\) | \(17/12\) | \(7/12\) |

这证明了该小 transversal 输入上的枚举和数值恒等式，但没有证明所有 transversal matroid、所有基分布或一般成本保留舍入都存在同样的强双射。

### 2. Graphic K4 边界

图为 \(K_4\)，六条边编号按

\[
(0,1),(0,2),(0,3),(1,2),(1,3),(2,3)
\]

排列。审计选取两个基 `[0,1,4]` 与 `[2,3,5]`，测试全部 6 个双射，结论为：没有 strong base-ordering；因此“先在两个独立对中取最优，再简单合并”不能覆盖所有 graphic matroid。该记录是候选算法边界/障碍，非 BMKP 反例：它没有给出完整两容量实例的最优值缺口，也没有证明任何一般 hardness。

该 K4 编号与本批另一个 `nash_common_marginal_audit_2026-10-20.json` 的 Hall 记录相同（见对应审查正文）。两源的目标函数和模型不同，不能因为共享边集就合并成一个定理；可供第三阶段标记为“同一 combinatorial witness 的跨线复用”。

### 3. 两容量 pair 的穷举与两个失败机制

固定容量 `[2,4]`、6 个物品、重量域 `{1,2,3,4}`、利润全部为 1、每个目标利润 2。审计总共检查 8,192 个实例，其中 196 个可行；每个实例检查 15 种 pairing，`all_checks_passed` 为真。这个数字是有限输入大小的完整枚举，不是对任意 \(n\) 或任意利润的证明。

记录的 `uncolored_matching_failure` 使用重量 `[2,2,1,1]` 和容量 `[2,4]`。朴素分组 `[[0,2],[1,3]]` 与修复分组 `[[0,1],[2,3]]` 展示了不携带容量颜色的配对会把一个可由重新配对修复的实例判错。它支持 GA-03-L2 的“一个总基数匹配加一个 small-edge 配额”思路，但没有证明该匹配模型能处理候选稿的全部 short 结构。

`separate_capacity_optimization_failure` 则把容量设为 `[1,2]`，物品为 `(weight,profit)=(1,2),(1,2),(2,3)`。先在大容量箱取 `[0,1]` 是大箱局部最优，但剩余小箱收益为 0；全局可行 bundle 为 `[0]` 或 `[2]`，全局最小利润为 2。该有限例只说明“分别优化各容量”不能替代联合供给约束，不是对联合算法的反例。

### 4. Joint canonical 审计

联合 canonical 使用种子 20261020，3,000 个 Fraction 实例、4,927 次交换，\(\delta=1/100\)。设置为两个 long bin、每个 2 个 critical slot，以及一个含 2 个 slot 的 short bin。最小独立碰撞只有两个候选：

\[
a:(w,p)=(2/5,1/2),\qquad b:(w,p)=(3/10,1/2),
\]

容量为 `[1,2]`。两个联合槽的舍入重量均记为 `2/5`，critical slot counts 为 `[1,1]`。若每个容量独立取最重，两个槽都会取 `a`，发生同一物品重复使用；联合选择取 `{a,b}`。JSON 明确标注该碰撞“不是 joint lemma 的反例”。在所有 3,000 个样本中，固定 joint-type slot multiset 与 rounded load 被保留，short 重量不增加，short profit loss 小于 `2 delta`。

这部分直接支持候选 GA-03-L1 中“全局联合类型、全局取重、再把被换出的轻件放回 short/unused”的交换接口。它不覆盖标签构造、每容量 profile 是否真的满足母文 Lemma 8 的前提，也不覆盖算法枚举命中性；这些仍是条件结论。

### 5. 参数差式和全覆盖障碍

参数审计检查 901 个 \(\zeta=1/d\) 点（分母 100 到 1000），并验证

\[
\frac{2/3-15\zeta}{1+\zeta}-(2/3-16\zeta)
=\frac{\zeta/3+16\zeta^2}{1+\zeta}.
\]

该恒等式只说明候选稿的几何网格损失计算在这组显式参数上没有符号错误。相同记录再次包含重量 2、容量 `[1,1]`、分数 `[1/2,1/2]` 的 mandatory full coverage obstruction：若 LP 合同强制全部物品整数覆盖，则无解；因此 discard-allowed contract 是必要语义。

### 6. 两个 sanity checks

`two_exact_budget_obstruction` 使用分数 `[1/2,1/2]`、成本矩阵

\[
\begin{pmatrix}0&2\\2&0\end{pmatrix}
\]

和两个精确预算 1，结论是不存在同时满足两预算的整数基。它只排除“一个成本预算的定理可直接升级为两个精确预算”的字面迁移。

`independent_configuration_sampling` 的四个结果为 `[1,2,2,1]`，期望利润 `3/2`，OPT 为 2，比例 `3/4`。JSON 明确把 `3/4` 解释为 independent rounding 的损失，而不是 integrality-gap 证书；不能把这四个样本改写成 LP 与整数最优的通用间隙。

## 结论分层、独有内容和缺口

**有限实验/证书。** 8,192 个两容量小实例的穷举、3,000 个联合 canonical Fraction 实例、901 个参数网格、17 基/136 对基及 K4 六双射检查，均是可复现的有限算术证据；它们的输出已按原 JSON 保全。`all_checks_passed` 仅表示这些断言在列出的输入上通过。

**条件结论。** 若两容量 profile 已合法、昂贵项标签满足联合类型假设、short 只使用未占用昂贵物品，联合全局取重和 short 配额匹配的局部推导可以继续使用。该条件依赖候选稿中尚未完成的 profile 提取、边界 \(W_t=0\)、容量相等、空 long/short 类和未知 OPT 网格证明。

**障碍。** K4 无 strong base-ordering、独立取重的最小碰撞、分别容量优化失败、两预算精确可行性障碍和完整覆盖反例共同说明：独立容量舍入、独立配对或全覆盖 LP 都不是可直接替代联合算法的接口。

**没有建立的结论。** 本源没有运行完整 BMKP 算法，没有对任意固定 \(\varepsilon\) 给出总位多项式实现，没有证明 \((2/3-\varepsilon)\) 近似，也没有进行外部新颖性认证。候选稿引用的 ICALP 2026 母文、Chernoff 舍入或 generalized-assignment 文献不因本 JSON 而自动导入为已重审定理。

本源的独有内容是上述有限数字、联合碰撞、K4 边界和精确失败机制；去向为本审查正文与证据副本。第三阶段可将它们连接到 BMKP 候选的 `GA-03-L1/L2/L3`，同时保留“候选、有限审计、障碍”三种标签，不合并为单一主张。
