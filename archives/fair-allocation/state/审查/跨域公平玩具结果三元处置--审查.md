# 读取范围

冻结文件 `cross_field_battle/toy_results.json` 大小 665 bytes，SHA-256 `decc0be5a91c19a267ce46dac06f3a26cb5b537d5fd8ef8ef5e7f23260efd75c`，blob `54712f5835f5c9460248f8f2763ed4c5d93c1b5a`。它有三个并列字段，故本页只做三项有限证据的准确分栏；原件、manifest 和字段验证见 [cross-field-toy-results-20261031](../../tools/evidence/cross-field-toy-results-20261031/)。该聚合 JSON 不是桥接证明，也不把任一模型的结果导出到另一模型。

# 1. copies SD-EF1

`copies_sd_ef1` 记录 (n=3)、4 个 types、按 simultaneous type relabeling 归一后的 9216 strict profiles；每个 profile 枚举 81 个 allocations，`counterexamples=0`。这与 fair_goods 的 `copies_exhaustive_results.json`（同一 9216 计数）在有限 profile 域相互印证，但本源不提供新的普遍量词。正确模型仍是等值副本、每人每型至多一件和所有 observer-prefix 的 SD-EF1；一般 partition matroid 的可区分类别不在此域。

该字段的独有去向是 cross-field 的独立聚合计数和“每 profile 81 allocations”字段；它和 fair_goods 更大随机样本/最坏 witness 是不同 source，不合并为更多独立 profiles，也不宣称独立形式化证明。

# 2. 两类无 loops rank-2 chores EF

`rank2_chore_EF` 记录 3 agents、chores 数取 `[3,8]`、`word_multisets_tested=12825`，condition 精确为 `two loopless parallel classes per agent`，`EF_failures=0`。这是两类无 loops 局部引理的有限 EF 检查；与引理中的完整 (m\ge n) EF 目标相符，但字段没有说明每个 word multiset 的 profile 生成分布、每个 allocation 是否全枚举或 witness 数，因此不能补写未记录的算法量词。

它不能替代 `construct_rank2_results.json` 的 3507 构造运行，也不能替代证明中 Hall/缺字增广。更不能把 `EF_failures=0` 扩到三类、loops 或真正 rank-cap-2；这些边界在本档已有独立 d096/ec907 结果并保持开放。

# 3. K8 ordered no-envy / EF1

`key8` 固定 4 agents、8 goods、categories `[3,3,2]`，每 profile 864 个 complete feasible allocations；seed 20261020，valuation range inclusive `[0,20]`，1000 random profiles，`ordered_no_envy_and_EF1_failures=0`。这是一项独立于 fair_goods `toy_results.json` 的 K8 整数随机检查：后者有 5000 个 profiles、三种分布并保存最坏 valuation/witness，而本源只给 1000 和范围字段。二者不能简单相加为 6000 个独立样本，除非有逐样本去重记录（此 JSON 没有）。

`ordered_no_envy_and_EF1_failures=0` 只说明该 checker 在指定 1000 个 profile 未标失败；它不证明连续非负估值的 ordered no-envy+EF1，也不证明普通 EF1 的一般 laminar key 定理。K8 旧 top-separation 充分条件在另一个 toy source 中为零可行，二者应分开：加强条件失败不等于目标 EF1 失败。

# 4. 模型边界与处置

三字段的共同价值是把“相邻候选的有限正面运行”放在同一 cross-field ledger 中，同时暴露三组不同对象的量词：copies 是 strict-profile + 81 allocation 全枚举；rank2 是 word multiset 数量而非明示 allocation 量词；K8 是 integer valuation random + 864 feasible allocation enumeration。没有共同 valuation、cost 或 fairness 定义，因此不能形成 cross-field theorem、统一概率或桥接边。

处置为 `integrated-finite-cross-field-evidence`：保留字段、源 SHA、独有运行范围与与同模型结果的差异；第三阶段最多建立有限验证/模型对照关系。若要复现，应分别读取 copies、rank_toys 和 key toy 脚本；本批未把脚本认定为已读或已执行。
