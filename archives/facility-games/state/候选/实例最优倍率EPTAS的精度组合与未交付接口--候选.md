# 实例最优倍率EPTAS的精度组合与未交付接口

## 数学目标与当前真值层

两家带标签设施从同一有限非空目录选址，逐名正有理原子客户被覆盖后必须服务、独立混合、按含自身负载成本选设施。每个有序布局都指定精确客户NE，布局及整份续局可共同优化。目标是在原输入上输出完整精确续局，使设施倍率至多$\alpha^*(I)+\varepsilon$，其中$0<\varepsilon<1$为二进制有理数。

EPTAS的位时间合同是$f(1/\varepsilon)\operatorname{poly}(L+\ell(\varepsilon))$，多项式次数不依精度；争取$f=2^{O(1/\varepsilon)}$。整数参数$p\ge2$时等价写误差$1/p$和$2^{O(p)}\operatorname{poly}(L+\log p)$。不能省略读取长精度输入的成本，也不能把精确客户NE改成近似NE。

原6996字节问题页已完整实读。它给出明确正向组合及误差推导，记局部引理已闭合，但**尚未登记完整EPTAS定理、规范通用选择器、完整证书接口或一般位复杂度正式验收**。本页保留这些不同层次，未凭有限原型或无反例把候选升级为已交付定理。文中的2026-10-09投入和论文整合安排是原来源的历史研究约束，不是替代当前清洗指令的新任务。

## 原候选的六个准确接口

对每个布局，设其服务总权为$W$。$W=0$时直接保零收益NE；否则取$H=\eta W$。只对共同客户按$w>H$分重，其人数至多$1/\eta$；独占背景不参与重支持枚举，也不舍入任何权。

1. 对重客户枚举纯第一、纯第二、名义混合三态。
2. 真正外带$\Delta>H$迫使全部轻客户纯第二，$\Delta<-H$迫使它们纯第一。固定支持用负载差恒等式求点或整区间，并交全部原NE不等式。可保闭外带$\Delta\ge H$、$\Delta\le-H$；其端点合法，但不能说边界所有轻客户都被强制。
3. 同一重支持调用[已证明的近带补全](../算法/固定重支持近平衡精确补全的位多项式选择--算法.md)，若可行保一个带内精确NE。边界上不属于纯轻外带形式的NE由闭近带覆盖。
4. 每个局部菜单保全部闭外带片及带内代表；分别取两个坐标的最小值及见证，再对全部真实目的地取max，得到可实现惩罚威胁。两个坐标可用不同NE，不能把它们当一份同时达到的概率向量。
5. 在每个在轨片上解析优化$\max\{1,\widehat D_1/X,\widehat D_2/(W-X)\}$。两威胁之和正时取平衡点$W\widehat D_1/(\widehat D_1+\widehat D_2)$夹到闭片；两者零时任取合法点。零收益/正威胁不可行，零/零按收益约束处理。
6. 全布局取最佳在轨见证；每条真实单方偏离用相应坐标最小见证。两类带标签偏离的目的布局只有不移动时才可能相交，排除不动后没有规则冲突。其他布局也须指定合法菜单NE；可显式输出目录平方张表，不能只交在轨概率。

第2步的名义混合闭端点可变纯，须仍按原条件成本核；不能删同址、空覆盖、重复标签或平局。每个布局至少存在客户NE；但一张有限菜单的存在或一个测试的扫描成功，不自行认证所有上述实现合同。

## 相对误差组合的已写推导

令$C=(1+\eta)/(1-\eta)$。近带任意NE的两个收益均在$[(1-\eta)W/2,(1+\eta)W/2]$，所以两个近带NE相同坐标的相对失真不超过$C$。外带全谱精确保留。若原真正坐标最小为$m$、菜单最小为$\widehat m$，则

\[
m\le\widehat m\le Cm.
\]

真最小在外带时精确捕获，在近带时用该重支持的带内代表；零最小只能在外带，必须精确保留。对目的地取max后同样有$D\le\widehat D\le CD$。

原全局最优在轨NE若外带即可原样使用；若近带，换代表后的每坐标至少为原来的$1/C$。因而菜单组合最优倍率至多$C^2\alpha^*$。共同目录的简单基线给$\alpha^*\le2$：在最大reach地点同址均分，任何偏离收益不超过最大reach，其他布局任取NE。若所有reach为零则完整规则倍率1，不作除法。

取$\eta=\varepsilon/16$，有

\[
2(C^2-1)=\frac{8\eta}{(1-\eta)^2}
\le\frac{128}{225}\varepsilon<\varepsilon.
\]

因此，**若前述全局菜单构造、完整输出与位规模合同全部落实**，上述不等式给要求的加性精度。这个误差推导不靠舍入权，也不把$\alpha^*$替成某回应环或有限菜单自己的最优值。
