# 同址平衡正规形与异址交叠参数精确优化

## 输入、目标和参数

有限共同目录S、两个带标签设施、正二进制有理客户权、任意覆盖、强制服务、独立混合精确NE和实际条件负载，采用[原子模型](../../subarchives/common-many/state/定义/共同目录任意设施数模型--定义.md)。求全部布局及全部完整NE续局选择中的真正最优倍率$\alpha^*\ge1$及达到证书。设客户数n、合法地点数N，

\[
\kappa=\max_{s\ne t}|C_s\cap C_t|,
\]

没有异址对取0。同址可以有n名共同客户；本算法不会为同址做$3^n$支持枚举。共同目录是承重条件，不覆盖异质U1/U2。

原接口JSON用`weights,locations`，可省略U1/U2以允许全部地点；若提供则两者必须同时给出且集合相同非空。不同顺序/重复目录条目去重，地点覆盖重复客户也按集合处理。精确值用整数/有理字符串/Fraction，拒绝布尔、浮点、非正权及越界客户。主结果用`alpha/shared`字段，与静态phi程序的`factor/common`不是同一证书格式。

## 异址全部NE闭支持片

固定异址，私有背景A、B，公共正权$v_i$。令公共坐标$c_i=v_i(2p_i-1)$，总负载差$\Delta=A-B+\sum_i c_i$、总重$T=A+B+\sum_i v_i$。指定每客户状态为纯负、混合、纯正，记混合数m、纯项常数$K=A-B+\sum_{\rm pure}\pm v_i$。

- m=0时$\Delta=K$。
- m=1时必须K=0，$\Delta$可变。
- m≥2时$\Delta=-K/(m-1)$。

再交所有NE闭不等式：纯正要求$\Delta\le v_i$，纯负要求$\Delta\ge-v_i$，混合指定者要求$|\Delta|\le v_i$。得到空、点或闭区间；端点允许原指定混合者变纯。每个真实NE归于至少一个闭支持片，重复端点不影响最值。第一负载$x=(T+\Delta)/2$，第二$T-x$，指定混合概率$(1+\Delta/v_i)/2$。因此每片负载区间$[\ell,h]$、全部坐标极值及精确概率均可得到。共$3^k$状态，每态O(k)算术。所有区间有界闭，故最值达到，不需猜连续概率网格。

令$\mu(s,t)$是对手在t、本方去s的全部NE中第一负载最小值，仅对$s\ne t$计算。反向值由同一片第一负载最大值反射求得。设

\[
H(t)=\max_{s\ne t}\mu(s,t),\qquad R(t)=w(C_t),
\]

空最大值0。各实际偏离目的布局可独立选择对应坐标最小NE；不存在两家实际偏离需在同一有序布局指定冲突的情形。

## 对角正规形的完整理由

在同址t，任意NE两收益和R(t)，且每家向其他地点的最小可惩罚威胁均H(t)。若在轨负载x、y，则任何支持倍率a的规则必须$a x\ge H(t),a y\ge H(t)$，所以$a\ge2H(t)/R(t)$。取全部客户独立对半是精确NE并达到该下界。按无除法零约定，$R=H=0$给比0、R=0<H时该候选无有限比。因此同址最佳

\[
a_D=\min_t\max(1,2H(t)/R(t)).
\]

最高reach地点保证H(t)≤R(t)，所以总有有限$a_D\le2$；全零输入为1。

异址(s,t)先放松同址偏离限制，仅要求$a x\ge H(t),a(T-x)\ge H(s)$。每片上最小化

\[
f(x)=\max\{1,H(t)/x,H(s)/(T-x)\}.
\]

第一分式单调降、第二单调升，故精确最优在$x_*=T H(t)/(H(t)+H(s))$对区间$[\ell,h]$的clamp；分母全零则任选下端点，零负载按正威胁不可行/零威胁0处理。记所有异址片的最小放松值$a_O$。任何真实最优至少$\min(a_D,a_O)$。

若$a_O\ge a_D$，直接保最佳同址达到$a_D$。若某异址候选a严格小于$a_D$，则每地点u的同址候选都大于a，且a≥1，从而$H(u)>aR(u)/2$（R=0时同样无碍）。其在轨约束给$x\ge H(t)/a>R(t)/2$、$y\ge H(s)/a>R(s)/2$。因此第一家搬到t后取平衡同址收益R(t)/2，本来就不超过x，更不超过a x；第二家对称。所有同址偏离均安全，异址候选真实达到a。故算法真正最优为$\min(a_D,a_O)$。

**严格替换与平局必须保留。** 实现从最佳同址开始，只在异址a严格更小才替换。放松异址值若仅平局，不能按上述严格不等式保证平衡惩罚安全；改取平局同址即可。源码测试用四名单位客户、两地点覆盖全同：异址NE概率$(1,1/4,1/4,1/4)$负载$(7/4,9/4)$满足放松factor1，但第一家搬去对方地点得到平衡2而改善。完整模型仍有平衡同址精确SPE；这是排除不安全的平局替换，不是模型反例。

## 完整规则与位复杂度

在轨用选中NE；实际异址偏离用坐标极小见证；实际同址偏离用对半；未指定同址也对半；其他未指定异址用降序贪心纯NE。降序贪心及有理位长证明见[粒度对象](../定理/异址共有原子的粒度误差与近似续局--定理.md)。对任一未指定布局均能按需生成，因此保存O(N)个实际偏离见证和一条默认规则就描述完整续局。

仅N(N−1)/2个无序异址调用支持枚举，时间$O(N^2(n+\kappa3^\kappa))$有理算术，加输入/证书序列化。区间端点是输入和、除以至多k−1的整数；clamp目标再由端点和相除，概率再除正输入权，编码位长多项式。故固定异址交叠κ时位多项式；不是对一般κ的多项式，也不依赖同址交叠上限。源码的401客户/三地点测试只调用三次异址local且交叠≤1；200客户单地点根本不调用local，专门防止把同址巨大支持误纳κ。

## 真正检查的契约

`solve`计算最优并调用依赖`bounded_overlap.verify`检查达到；`shared_offdiag.verify`也仅委托这个达到检查器。它重算概率、成本、在轨及全部实际偏离，但不枚举支持、不证明输入`alpha`最优，也不认证说明字符串。完整默认可由上面数学理由扩充。

`continuation(instance,result,s,t)`解析地点并返回在轨、偏离或硬编码默认profile；**函数体不会自行调用verify**。其“after verifying result”必须作为调用者先验证的前提；篡改result中的已保存profile会被原样返回，不能把该接口当未可信数据验证器。带`factor/common`格式的独立CLI检查器则另会重算全部未指定布局，但不能直接消费本接口的`alpha/shared`格式。

原三程序及三测试的全读、隔离实际运行、依赖hash与语义攻击见[计算正文](../计算/共享目录旁支程序的接口与精确复现--计算.md)。这些运行不替代上面的全部支持完备性/正规形证明；反过来，达到验证通过也不证明作者宣称的实例最优性。与有限P/E/T/C菜单求因子不同，本算法用了**全部NE**的异址极值，不把两种最小量互换。新[稀疏目录阈值](../定理/单交叠目录三四地点的尖锐稳定阈值--定理.md)给一般下界，精确优化则给每个具体有理实例最优，二者用途不同。
