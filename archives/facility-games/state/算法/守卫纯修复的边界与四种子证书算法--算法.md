# 守卫纯修复的边界与四种子证书算法

两带标签设施目录任意有限非空，可不同、相交；有限正权客户有固定覆盖，覆盖后强制服务，客户成本为含自身的实现负载。设施先选址，客户观察布局后行动；设施最大化服务权。在轨布局配合每个合法布局的一份客户NE构成完整续局，因子$\alpha\ge1$只近似设施偏离，即所有真实偏离收益$L_j^\prime\le\alpha L_j$，客户均衡仍然精确。以下局部输出都是精确**纯**客户NE，不限制共同客户数，也不以一般因子二上界已成立为前提。

## 单步条件和必须保留的严格号

记$C_s$为行动s覆盖的客户集，$w(K)=\sum_{i\in K}w_i$。固定布局$(s,t)$，令$J=C_s\cap C_t$，私有负载$a=w(C_s\setminus C_t),b=w(C_t\setminus C_s)$；权$w_i>0$，纯向量$p_i\in\{0,1\}$表示在第一家，负载$x=a+\sum_{i\in J}w_ip_i,y=b+\sum_{i\in J}w_i(1-p_i)$。第一家客户稳定恰$x\le y+w_i$，第二家恰$y\le x+w_i$，因为改选后把自己的全部重量加入目的侧。

只有高负载侧可能改善，严格改善恰$w_i<|x-y|$。教材例负载$(9,5)$：重3者搬后成本8，严格下降；重4者搬后成本9，已经无严格改善，不能按$\le$执行移动。强制专属客户无选择，不能混入可移动集。

## 守卫修复及三种停止情形

给一个未稳定纯种子，固定**原低侧**Q和**原高侧**P的设施标签，初始$Q_0<P_0$，要求每名原低侧共有客户重至少$g_0=P_0-Q_0$。反复从原高侧尚未移动者中选最大权的严格改善客户，重量平局按全局固定ID，搬到原低侧；负载相等、首次反转或无改善立即停。

每步$0<w<g$，带符号差变$g-2w$，绝对差$|g-2w|<g$。未反转前候选只会删除、不增新客户：旧时过重者面对更小差仍不能改善。故移动权不增、无人反向或重复移动。停止时：

- 尚未反转且无候选：当前高侧无改善，低侧自动稳定。
- 负载相等：所有共有客户自动稳定。
- 权w造成首次严格反转：新差$g'=2w-g<w$；新高侧就是原低侧，其共有客户为此次移动者、以前移动者、初始低侧者。前两类分别重w和至少w；第三类由守卫重至少$g_0>w$。三类都重于$g'$，因此新高侧亦无改善。

所以输出NE，原低侧从未失去客户、收益不低于$Q_0$，至多$k=|J|$步，逐步扫描$O((k+1)^2)$算术。守卫用于保证反转后原低侧老客户仍够重；仅有差下降不推出首次反转即NE或指定收益保持。

下列是本页对教材文字算法的显式伪代码，**不是新增canonical实现或一次执行**：

```text
repair(seed):
  if seed satisfies every pure NE inequality: return seed
  fix original low/high labels from its unequal loads
  if an original-low common customer weighs less than initial gap: return discarded
  while original-high load exceeds original-low load:
    among common customers still on original-high with weight < current gap,
      choose maximum weight, then minimum global ID
    if none: stop
    move it to original-low
    if loads become equal or reverse: stop
  return final assignment
```

## 固定四种子和非空性

每个布局用同一全局ID，选共同集中最大$(w_i,-ID_i)$的h，预先只尝试四种纯分配；私有客户始终被迫留在唯一可达设施。

| 种子 | 第一家的共有客户 | 第二家的共有客户 |
| --- | --- | --- |
| 全第一 | J | 空 |
| 全第二 | 空 | J |
| h独第一 | $\{h\}$ | $J\setminus\{h\}$ |
| h独第二 | $J\setminus\{h\}$ | $\{h\}$ |

已经NE直接保留，否则守卫真才修复，假则丢弃；按0/1分配向量去重。无共同客户保唯一强制分配。不能等证明需要某个singleton时再临时加进菜单。程序的`prob_first=1`表示第一家、0表示第二家；固定原低侧标签和反转后重新命名当前低侧是不同规则，本算法只用前者。

每个保留者由上节证明是NE。全第一种子若第一侧不高则已稳定；若高，初始低侧没有共同客户，守卫为空条件，必可修复。故菜单F非空；全第二种子有对称保证。至多4份，局部代价仍$O((k+1)^2)$，每份见证O(k)坐标。不能由非空性推出“四份总够支撑全局因子二”；[候选坏环推导](../证明/四种子坏回应环的两分支推导与候选边界--证明.md)依赖A9.2中“全环最大客户恰是每边事先指定h”的论证；该步骤在链接正文中完整保留，不能由局部非空性替代。

## 由菜单双配额补出所有续局

先在**全矩形目录**建菜单，令$u_1(s,t)=\min_F L_1,u_2(s,t)=\min_F L_2$，以及

\[
D_1^F(t)=\max_{s\in U_1}u_1(s,t),\qquad
D_2^F(s)=\max_{t\in U_2}u_2(s,t).
\]

先min是续局选择者压低偏离者，再max是设施在全目录选偏离；两个min可以不同见证。它们不小于全NE坐标极小及其威胁，不能互换。若在轨菜单收益$(x,y)$满足$2x\ge D_1^F(t),2y\ge D_2^F(s)$，第一家每个实际偏离选第一坐标最小菜单，第二家每个实际偏离选第二坐标最小菜单；两目的布局族在轨外不交。其他所有布局用全第一种子的确定守卫修复。这样明确给完整纯NE规则，不留“其他布局任选”的未执行含义。

在只允许F的续局问题中双配额亦必要：任何第一家真实偏离的菜单后续收益至少为$u_1(r,t_*)$，稳定性因而迫$u_1(r,t_*)\le2x$；未改变行动也有$u_1(s_*,t_*)\le x\le2x$，故取全目录max得第一条，第二家相同。这也处理某家目录只有一个行动。两坐标min可以由不同元素实现，因为两个真实偏离布局族不交；没有要求某一离轨布局同时压低双方。在允许任意混合NE的原游戏中，菜单双配额只是充分证书接口。一般形式见[独立续局判据](../定理/独立续局的威胁配额与双颜色回应核心--定理.md)。

所有菜单求完后可扫描全矩形。原`solve`还从全目录u/D最大回应找到一个环，只扫描其两色点笛卡尔积；两环任一同菜单元素同时不低于两威胁，已精确稳定。零最大威胁也直接满足配额；长偶环的普遍充分性依下述候选论证，未因运行成功获认证。威胁从未在核内重算，任意删点没有此合同。

## 复杂度、输出与候选状态

$N_1N_2$布局每处至多4次修复，操作界$O(N_1N_2(n+1)^2)$。权为显式二进制正有理时，用输入分母积作位长分析；纯负载是子集和，分母位长不超过总输入分母位长之和，中间位长$O(L+\log(n+1))$。加减、比较和常数乘法均为位多项式，不按总整数重量逐单位工作。

紧凑证书是一在轨+$N_1+N_2-2$真实偏离+确定默认规则；全部概率0/1，也可显式列全矩形。原verify重算输入、客户ID、纯概率、负载、逐客户NE和每个且仅每个偏离，要求$1\le\alpha\le2$；它不重新求菜单、不验任意默认文字、不证实例最优。原生产者输出只是所扫描核内最佳菜单因子，可能错过核外更好布局，也不遍历全混合NE。原代码和先前真实测试见[计算对象](../计算/异构双目录四种子程序与五输入的精确复现--计算.md)，本批未重跑。

**候选定理A8.6的精确范围。** 对任意有限正实权原子客户及两个有限非空带标签目录，若A09的任意坏环排除路线成立，上述菜单算法在每个输入成功，得到一份因子2在轨纯设施布局和每个布局均为精确纯客户NE的完整续局。若权重二进制正有理且覆盖显式给出，则上述算术与位复杂度同时成立。前述局部NE/修复/菜单非空、位操作界和给定双配额证书的完整补全可独立使用，不依赖这条通用候选的升级。
