# 恰三地点低倍率归约的 YES 实例取到固定阈值

采用[三五地点固定倍率的全布局守卫](../归约/共同目录三五地点固定倍率的全布局守卫--归约.md)。《局部源的精确接口》给 (L)，《三地点固定1<a<σ：改变reach顺序后的守卫》给 (T3)、(G3) 及全布局表。

结论限于该归约产生的源 YES 实例，固定有理 $1<a<\sigma=(1+\sqrt3)/2$。模型为两家带标签设施共享恰三地点、同址合法、独立混合精确客户 NE、完整续局。以下复用源输出，未改变参数或客户权。

源定义 $R_A=J,\ R_B=R,\ R_C=L$，有 $R>J>L$。记 $V$ 为 BC 布局总覆盖权，$m_0=(V-Q)/2$，$h=m_0/a$，$k=\beta W$。AB 的唯一收益是 $(J,k)$，AC 的唯一收益是 $(h,L)$。令 $\mu$ 为 BC 中地点 B 一方在全部精确 NE 中的最小收益。(L) 给出源 YES 时 $\mu=m_0$，(T3) 给出 $V-m_0=J/a$ 与 $m_0=ah$。源 YES 的 AC 规则以达到 $\mu$ 的 BC 续局及 (G3) 支付全部真实偏离，故 $\alpha^*\le a$。

对任意完整续局，以下各类均有一项实际偏离满足 $v\ge ax$ 且 $v>0$。若 $x>0$，则任何 $\alpha<a$ 都违背稳定不等式。若 $x=0$，正偏离违反每个有限倍率。

| 在轨类 | 选定偏离与任意离轨 NE 下的保证 |
| --- | --- |
| AA | 当前收益 $x\le J/2$ 的一家去 C，获得 $L>aJ/2$ |
| BB | 当前收益 $x\le R/2$ 的一家去 A，获得 $J>aR/2$ |
| CC | 当前收益 $x\le L/2$ 的一家去 B，获得至少 $\mu=m_0>aL/2$ |
| AB | B 上设施当前收益 $k$，去 C 获得 $L>ak$ |
| AC | A 上设施当前收益 $h$，去 B 获得至少 $\mu=m_0=ah$ |
| BC | B 上设施当前收益 $x_B\ge m_0$，C 上设施的收益 $x=V-x_B\le J/a$。C 上设施去 A，获得 $J\ge ax$ |

三种异址的设施标签反射保全部收益和偏离约束，覆盖另三个有序布局。于是 $\alpha^*\ge a$，结合 AC 规则得 $\alpha^*=a$。源 NO 已由原表的严格不等式逐类给出 $\alpha^*>a$。同乘正整数公分母保全部客户均衡和倍率，故可直接用于二进制整数权输出。

添加两个空地点的保实例倍率桥随后把这两种输出的实际 $\alpha^*$ 原样传到恰五地点。YES 等式来自上表。五地点中心宏客户及桥宏原子的独立构造仍支付整个固定有理区间 $1<a<\phi$，包括 $\sigma\le a<\phi$。上述低段结论不给恰三地点在后一区间的分类。

## 源 NO 的逐实例正间隙

令 $g=\mu-m_0>0$。在 $AC$，所需倍率至少 $\mu/h=a+g/h$。在 $BC$ 若 C 方收益 $y>0$，由 $y\le J/a-g$ 得 $J/y\ge a+a^2g/J$，零收益情形更强。其余四类使用表中严格守卫。于是

$$\alpha^*-a\ge\min\{2L/J-a,\,2J/R-a,\,2m_0/L-a,\,L/k-a,\,g/h,\,a^2g/J\}>0.$$

该下界在统一清分母后保持，大小随原实例而变。
