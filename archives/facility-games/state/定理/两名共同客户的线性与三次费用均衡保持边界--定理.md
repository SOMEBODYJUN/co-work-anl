# 两名共同客户的线性与三次费用均衡保持边界

固定两家设施的一个带标签布局。私有客户在各自唯一可达设施被强制服务，形成负载背景 \(A,B\ge0\)。恰两名共同客户的正权分别为 \(u\le v\)。每名客户的成本按含自身重量的实际随机负载 \(z\) 取 \(z\) 或 \(z^3\)，比较条件期望成本。两家采用相同的费用函数。令 \(d=|A-B|\)。

纯客户NE集合始终保持。独立混合NE、CE、CCE的集合各自保持，当且仅当

\[
d=0,\quad\text{或}\quad d>u,\quad\text{或}\quad d=u=v.
\]

在 \(0<d<u\) 时，线性与三次费用的唯一全混合NE不同。在 \(d=u<v\) 时，两者都没有全混合NE，但一个真实单人混合区间的端点不同。至多一名共同客户时，对任意严格递增的同客户费用函数，这三类集合都保持。

## 两点反事实比较

交换设施标签后可设 \(\delta=A-B=d\ge0\)。共同客户 \(i\) 权 \(w_i\)，另一人 \(j\) 权 \(w_j\)，令 \(p_i,p_j\) 表示选高背景第一家的概率。客户 \(i\) 的第一家减第二家的实际条件负载差，在 \(j\) 去第一家或第二家时分别为

\[
d_+=\delta+w_j,\qquad d_-=\delta-w_j .
\]

同一反事实对的两负载之和均为 \(S_i=A+B+2w_i+w_j\)。费用 \(z^3\) 的两个差因此是

\[
D_\pm=\frac{d_\pm(3S_i^2+d_\pm^2)}{4}.
\]

纯状态的比较符号只由 \(d_\pm\) 决定，故纯均衡不变。若 \(d_-<0<d_+\)，客户 \(i\) 无差异需要 \(p_j=t_i=-D_-/(D_+-D_-)\)。在线性情形将 \(D_\pm\) 换成 \(d_\pm\)，阈值为 \((w_j-\delta)/(2w_j)\)。当 \(0<\delta<w_j\)，乘子 \(3S_i^2+d_+^2\) 严格大于 \(3S_i^2+d_-^2\)，故三次阈值严格更小。用 \(t_1,t_2\) 分别表示给小客户和大客户无差异的对方概率。

## 独立混合的完整分支

| 背景差 | 选第一家概率对的精确NE集合 |
|---|---|
| \(\delta=0\) | \((1,0),(0,1),(1/2,1/2)\) |
| \(0<\delta<u\) | \((1,0),(0,1),(t_2,t_1)\) |
| \(\delta=u<v\) | \((1,0)\) 以及 \((0,p_2)\) 对所有 \(t_1\le p_2\le1\) |
| \(u<\delta<v\) | 仅 \((1,0)\) |
| \(\delta=v>u\) | \((p_1,0)\) 对所有 \(0\le p_1\le1\) |
| \(\delta>v\) | 仅 \((0,0)\) |
| \(\delta=u=v\) | \((p_1,p_2)\in[0,1]^2\) 且 \(p_1p_2=0\) |

首两行的两名客户在对方纯行动时均有严格反向最佳回复，所以仅有两个反协调纯点和一个由两无差异式确定的全混合点。第三行中，大客户在小客户以正概率选第一家时严格选第二家；若小客户确定选第二家，则大客户无差异，小客户的最佳回复条件给 \(p_2\ge t_1\)。当 \(\delta>u\)，大客户严格选第二家，小客户面对它的确定行动按 \(\delta-v\) 的符号取最佳回复。最后一行的两人都弱偏好第二家，严格性恰出现在对方以正概率选第一家。各行为穷尽分支。第一行的阈值结论对任意严格递增同客户费用也成立，因为两个反事实恰为互换。

## 相关和粗相关的边界

这里只有两个动作。无条件固定改去某一家的偏离，只有在原推荐另一家时才有非零成本变化。按该推荐事件的概率加权后，CE 的同一方向约束恰为 CCE 的对应约束。

在 \(\delta=0\)，每名客户的两种线性反事实差同乘一个与对方行动无关的正系数，因此全部相关和粗相关的偏离不等式保持。当 \(\delta>u\)，大客户严格偏好第二家，对固定第二家的偏离在任何其第一家正质量上都获益，故 CE 与 CCE 均只支持大客户选第二家。小客户此时面对固定实际负载，最优集合由 \(\delta-v\) 的符号决定。当 \(\delta=u=v\)，两人都弱偏好第二家，相关或粗相关可行恰要求两人同选第一家的质量为零。以上各情形给完全相同的分布集合。

在 \(0<\delta<u\)，取线性全混合NE的独立乘积。它在三次费用下有一个正概率使用的行动严格较差。无条件改用最佳行动严格获益，对该推荐行动也有严格条件偏离。因此它既不属于三次CCE，也不属于三次CE。在 \(\delta=u<v\)，取三次阈值端点 \((0,t_1^\mathrm{cubic})\) 的独立乘积。小客户在线性费用下严格愿从第二家改第一家，故该分布同样被两种线性相关合同排除。由此三个均衡概念的保持边界一致。

若仅有一名共同客户，两项反事实实际负载由私有背景固定。严格递增函数只按两负载排序。未被允许或未被覆盖的客户无选址偏离。这也证明任意私有背景下两名共同客户是发生差异的最小数目。

取 \(A=1,B=0,u=v=2\)。线性全混合概率均为 \(1/4\)。三次两差为 \(5^3-2^3=117\) 与 \(3^3-4^3=-37\)，故唯一全混合概率均为 \(37/154\)。[既有三次反例](../等价/两设施同客户二次费用的均衡集合保持--等价.md)的共同权为2和3，落在同一个开分支。
