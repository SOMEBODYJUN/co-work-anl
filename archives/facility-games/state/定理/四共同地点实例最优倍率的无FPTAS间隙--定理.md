# 四共同地点实例最优倍率的无FPTAS间隙

## 精确输出合同与结论

有限显式客户，每名客户有严格正二进制有理原子权及显式覆盖。两家带标签设施共享有限非空目录，允许同址；已覆盖客户不得退出，独立随机化并最小化含自身重量的实际设施负载期望，设施最大化期望服务权。完整规则为每个带标签布局指定一个**精确独立混合客户NE**。\(\alpha^*(I)\ge1\)在全部纯设施在轨布局、全部在轨NE及全部完整规则上最小化设施单方偏离倍率，数学域允许实概率。

考虑确定性算法：输入原实例及0<ε<1，在\(\operatorname{poly}(L,1/\varepsilon)\)位操作内输出原实例的纯布局及完整精确NE规则，概率以显式二进制有理数表示，实际稳定倍率≤\(\alpha^*(I)+\varepsilon\)。**若P≠NP，这种加性FPTAS不存在，即使共同目录恰四地点且客户全为正二进制整数权。**同一归约也排除标准乘性FPTAS。

具体从非空正整数PARTITION列表\(b_1,\ldots,b_t\)出发，令\(n=2\max(t,2)\)，构造满足

\[
\text{YES}:\ \alpha^*(I)=13/10,
\qquad
\text{NO}:\ \alpha^*(I)\ge13/10+1/(100n^2).\tag{GAP}
\]

NO针对任意实概率在轨精确NE及任意完整惩罚规则。设施始终两家，四是地点数，n是补零后的变量客户数。与[三/五地点固定倍率判定](../归约/共同目录三五地点固定倍率的全布局守卫--归约.md)不同，本结论有按n逆多项式的精度间隙，且不依赖其归约、黄金比上界或局部极值oracle。

这是完整内部证明的整理，独立内部审查及有限审计已有记录；无外部同行评审或全面新颖性认证。原主源字节、源ID/SHA与双提交路线见[manifest](../../../../tools/evidence/small-catalog-primary-complexity/source-manifest.json)。

## 从条件成本到支持恒等式

固定布局，两独占背景A,B，共同客户权vᵢ、第一设施概率pᵢ。写

\[
X=A+\sum_i v_ip_i,\quad Y=B+\sum_i v_i(1-p_i),\quad\Delta=X-Y.
\]

两个条件成本是\(X+(1-p_i)v_i\)、\(Y+p_iv_i\)。因此NE等价于

\[
p_i=1\Rightarrow\Delta\le v_i,\quad p_i=0\Rightarrow\Delta\ge-v_i,
\quad0<p_i<1\Rightarrow\Delta=v_i(2p_i-1).
\]

设**真正**混合人数m，其余纯客户带符号和z，则

\[
(1-m)\Delta=A-B+z.\tag{S}
\]

这里m不是允许端点的名义混合人数。概率0/1归纯策略；任意实概率NE都满足(S)，所以后面的NO排除不局限有理可输出profile或有限菜单。完整支持几何另见[已整理负载谱](两设施原子客户的完整混合均衡负载谱--定理.md)。

## 近单位权编码：唯一混合者承载等分

令\(T=\sum b_j>0\)，补**辅助数字零**至\(a_1,\ldots,a_n\)，其中n偶且n≥4，原项数t≤n/2。定义实际变量客户权

\[
w_i=1+\frac{na_i-T}{16n^2T}.
\]

则

\[
\sum_iw_i=n,\quad w_i\ge1-1/(16n^2)>0,
\quad E:=\sum_i|w_i-1|\le1/(8n).
\]

最后一式由\(\sum|na_i-T|\le n\sum a_i+nT=2nT\)得到。辅助零对应的实际客户权接近1，绝不为零。

若\(\sum\sigma_iw_i=0,\sigma_i\in\{-1,1\}\)，整数\(\sum\sigma_i\)的绝对值≤E<1，所以它为0。代入定义得\(\sum\sigma_ia_i=0\)，正号恰n/2个、其aᵢ之和为T/2，给原列表等分。反向原等分子集至多t≤n/2项，可用辅助零补足n/2个，变量两侧权都恰n/2。因此

\[
\exists\sigma:\sum_i\sigma_iw_i=0\iff\text{源PARTITION为YES}.\tag{P}
\]

这同时覆盖一项源、奇总重、重复原数和重复实际客户权；客户身份显式保留。

## 四地点覆盖与全部参数

共同目录为{B,C,A,D}，记

\[
\alpha_0=13/10,\quad M=5n/2,\quad V=11n/2,\quad\tau=1/(2n),
\]
\[
q=13/(20n),\quad R=(143n^2+13)/(40n),\quad d=27n/10.
\]

| 客户 | 权重 | 覆盖 |
| --- | --- | --- |
| 大客户 | M | A,B,C,D |
| n名变量客户 | 各wᵢ | B,C |
| 交叉客户 | q | A,B |
| B私有 | n−q | B |
| C私有 | n | C |
| A私有 | R−M−q=(43n²−13)/(40n) | A |
| D私有 | n/5 | D |

共n+6名，均正权。reach为\(R_B=R_C=9n/2,R_A=R,R_D=d\)。所有n≥4均满足

\[
9n/2>R>d>M,\quad R-q>d>9n/4,\quad R>2n,\tag{O}
\]
\[
R=\alpha_0(V+\tau)/2,\quad R-q=\alpha_0(V-\tau)/2,
\quad2R-q=\alpha_0V.\tag{T}
\]

核心BC私有背景各n，共同客户是大客户及全部变量，服务总重V。

## 五种替代异址NE唯一

除BA外，各替代异址对只有大客户公共，它选某地点的条件成本就是该地点完整reach；由(O)严格选较小reach一侧。

BA有大客户和交叉q，独占背景差

\[
\delta=R_B-R_A=(37n^2-13)/(40n)>q.
\]

若大客户纯选B，则Δ≥δ+M−q>M，违反纯策略NE；若大客户真正混合，由其无差异式消掉自身，要求\(0=\delta+q(2p_q-1)\)，也不可能。故大客户纯A。交叉客户选B/A的条件成本分别2n/R，因2n<R而必纯B。于是全部替代异址NE的策略及收益唯一：

| 地点对 | 按所列地点顺序的收益 |
| --- | --- |
| B,A | 2n，R−q |
| C,A | 2n，R |
| B,D | 2n，d |
| C,D | 2n，d |
| A,D | R−M，d |

反射只交换设施标签。保护性偏离均落到这些唯一NE，故任意完整惩罚规则都不能降低其保证。

## 所有非核心在轨布局的守卫

同址任意NE两收益和为本址reach，较低家至多一半。下表不假定同址在轨均分；原在轨收益为0而偏离正收益时，倍率为无穷。

| 在轨类 | 必有偏离 | 倍率下界 |
| --- | --- | --- |
| BA、CA | B/C上设施去D | 27/20 |
| BD、CD | D上设施去A | (143n²−13)/(108n²) |
| AD | A上设施去B | 80n²/(43n²+13) |
| BB | 较低家去A | (143n²−13)/(90n²) |
| CC | 较低家去A | (143n²+13)/(90n²) |
| AA | 较低家去D | 216n²/(143n²+13) |
| DD | 较低家去B | 40/27 |

这些全部严格>131/100。可纯解析核验：第一、末行直接比较；第二/四行等于常数减正数/n²，n²≥16时代入16即为下界；第三/六行随n²增加，在16取最小；第五行>143/90。等价的全域代数证据是令z=n²−16≥0，各行减131/100并交叉相乘，正分母上的分子依次为

\[
80,\quad152z+1132,\quad2367z+36169,\quad2510z+38860,
\]
\[
2510z+41460,\quad2867z+44169,\quad463,
\]

全正。这是全n证明，不是只测n=4、6、8。五个替代异址无序对和四同址、再加BC及反射，覆盖全部16个带标签布局。

## YES：核心布局的精确最优与完整续局

在任意BC NE，X,Y≥n>0、X+Y=V。B上设施去A收益R，C上设施去A收益R−q。因此任意完整规则的倍率至少

\[
g(\Delta)=\max\{1,2R/(V+\Delta),2(R-q)/(V-\Delta)\}
\ge(2R-q)/V=\alpha_0.
\]

最后一步是把\(R\le\beta X,R-q\le\beta Y\)相加；不假定偏离NE可由选择器任意改变。

源YES时由(P)把变量纯分为各n/2，大客户选B的概率取

\[
p_M=1/2+\tau/(2M)=1/2+1/(10n^2).
\]

于是Δ=τ，\(X_*=(V+\tau)/2,Y_*=(V-\tau)/2\)。大客户无差异，每名纯变量因τ<wᵢ而满足NE。

完整16布局规则：BC用此NE，CB用反射，其他异址用上表唯一NE，每个同址客户各以1/2独立选择。对半同址的两个条件成本相等，所以精确合法。在轨BC两次去A的倍率由(T)都恰α₀；去D收益d、去对方同址收益9n/4，都<R−q。因为X*≥Y*，六次实际单方偏离全部受α₀控制。结合非核心守卫和核心普遍下界，YES精确\(\alpha^*=13/10\)。

## NO：任意实概率精确NE避开目标差值

核心BC中A−B=0。

若真正混合者恰一名且它是变量，则大客户纯，带符号重量绝对值M>n，而其他纯变量总重<n，不可能使(S)右端z=0。若唯一混合者是大客户，z=0恰要求变量带符号和为零，由(P)强迫源YES。故源NO时m≠1，包含端点退化为纯后的所有情形。

n偶使M=5n/2为整数。纯客户和可写\(z=N+e\)，N整数、|e|≤E≤1/(8n)。共同客户数n+1，故

\[
\Delta=(N+e)/(1-m),\qquad1\le|1-m|\le n.
\]

N=0时|Δ|≤1/(8n)，距τ=1/(2n)至少3/(8n)。N≠0时

\[
|\Delta|\ge(1-1/(8n))/n>\tau,
\qquad|\Delta-\tau|\ge1/(2n)-1/(8n^2)\ge3/(8n).
\]

所以任意实概率NE都满足\(|\Delta-\tau|\ge3/(8n)>1/(4n)\)，不是只排除了某类有限支持菜单。唯一混合者的整段连续支持仅在源YES可出现；NO时其余支持被近整数结构统一隔开。

若Δ<τ，用(T)得

\[
R/X-\alpha_0=\alpha_0(\tau-\Delta)/(2X)
\ge|\tau-\Delta|/(2V).
\]

Δ>τ时同理\((R-q)/Y-\alpha_0\ge|\tau-\Delta|/(2V)\)。因2V=11n，任意BC/CB在轨NE及任意完整规则的倍率≥\(\alpha_0+1/(44n^2)\)。所有其他布局>α₀+1/100，故全局至少α₀+1/(100n²)，证明(GAP)。这一步没有调用均衡求解器、同址正规形或旧NP归约。

## 编码位长与FPTAS反证

统一乘\(Q_{scale}=80n^2T\)，权重成为正整数。按上表顺序为

\[
200n^3T;\qquad80n^2T+5na_i-5T\ (i=1,\ldots,n);
\]
\[
52nT,\quad80n^3T-52nT,\quad80n^3T,
\quad86n^3T-26nT,\quad16n^3T.
\]

所有成本/收益同乘正数，NE、概率及倍率不变。源位长K下n=O(K)、logT=O(K)，最大权≤200n³T，总输出位长\(O(n(\log T+\log n))\)为多项式；公式不按T或数值总重迭代，中间整数位长\(O(K+\log n)\)。YES全16布局用0、1、1/2及p_M，概率总描述长度\(O(n\log n)\)。

假设题设加性FPTAS存在，取\(\varepsilon=1/(200n^2)\)，运行位时间为源多项式。YES输出实际倍率≤α₀+1/(200n²)，NO任何合法输出≥α₀+1/(100n²)。取中间阈值\(\alpha_0+3/(400n^2)\)，从输出计算在轨及六次实际偏离收益即可判PARTITION。显式有理输出长度受算法时间限制，分母乘积位长由输入/输出总位长控制，比较可整数交叉相乘，后处理也位多项式。与标准二进制PARTITION的NP完全性矛盾。

乘性FPTAS取精度1/(260n²)，YES有

\[
(13/10)(1+1/(260n^2))=13/10+1/(200n^2),
\]

同一阈值区分NO，无需导入普遍黄金比或其他上界。仅返回最优值的通常加性/乘性近似也受(GAP)限制；双侧加性估计取更小精度如1/(400n²)即可分离两区间。对常数成功概率的随机算法，这一论证只给NP⊆BPP；排除它需要NP不包含于BPP等相应假设，不能只写P≠NP。
