# 单交叠短目录的ρ稳定阈值与六客户锐族

## 精确模型与局部全部NE

两家带标签设施分别从有限非空目录$U_1,U_2$选址，目录可不同、相交；覆盖后客户必须选一家可达设施。有限客户权严格正，成本是所选设施包含自身完整重量的实现负载期望；客户独立混合，设施收益是期望服务重量。完整续局在每个有序合法布局独立指定一个精确客户NE。假设

\[
|C_s\cap C_t|\le1\quad(s\in U_1,t\in U_2),\qquad
\min(|U_1|,|U_2|)\le2.\tag{H}
\]

这是人数限制而非公共总重量限制；同一客户可覆盖多行、多列。合法同址亦满足(H)，故两目录共同地点最多覆盖一名客户。不能把本结论当多交叠模型、一般共同目录模型的锐常数。

记$R_s=w(C_s)$。无共同客户时收益唯一为$(R_s,R_t)$；唯一共同权w的两条件成本恰为$R_s,R_t$，不依赖其概率。因此$R_s<R_t$时收益$(R_s,R_t-w)$，反向时$(R_s-w,R_t)$，客户严格选择小reach方；$R_s=R_t=R$时第一收益为全部闭区间$[R-w,R]$，两端均纯NE。无交叠时的reach平局没有自由概率。严格选择时，给劣行动正概率会违反无条件改选优行动的CCE约束，故客户NE、CE、CCE皆唯一。

定义$q(z)=z^3-z^2-2z+1$、$\phi=(1+\sqrt5)/2$、$\rho=2\cos(\pi/7)$。由$\sin(4\pi/7)=\sin(3\pi/7)$得$q(\rho)=0$；$q(\phi)=1-\phi<0,q(2)=1$，且$q'>0$于$[\phi,\infty)$，故$\phi<\rho<2$且ρ为最大实根。

**结论。** 正实权输入满足(H)时存在纯客户NE完整规则及纯设施布局，所有真实偏离收益$v$满足$v\le\rho x$。若每个有共同客户的跨对reach不同，则可达某个$\alpha<\rho$。正二进制有理显式输入可在位多项式时间构造。对每个$1\le\alpha<\rho$，已有正整数$2\times2$输入排除所有完整独立混合NE甚至CCE续局，故本类最小普遍因子恰ρ。内部自足证明如下，外审及文献优先权未认证。

零收益一律用乘法不等式：$0\to$正数违反任意有限因子，$0\to0$不算严格改善。$r>1$的坏边同时要求$v\ge rx$和$v>x$，不由$0\ge r0$造边。

## 严格2×2分类：所有分支

先令两边恰两行动，所有有交叠跨对reach不同，客户续局逐格唯一。若每格所需因子至少$r>\phi$，每格存在上述严格坏边。正方形行动图无双向严格改善边、无三环，因此必须有四格有向环。

交换设施标签，让一个全局最大reach行动成为第二家的D；第一家最大reach为A，另一行为B，另一列为C。写$a=R_A\ge b=R_B,d=R_D\ge a,c=R_C$。若$d=a$，AD不能有交叠（否则违严格reach），双方都得各自目录最大reach，已精确稳定。因此$d>a$。AD中行得全reach a，无严格改善，四环方向必为

\[
AD\to AC\to BC\to BD\to AD.\tag{1}
\]

AC中行要改善到B，故$c<a$：若$c>a$行已得a；若$c=a$则无交叠、仍得a，均不能改善。BD→AD给$a\ge rb$；又AC→BC的严格改善不可能到非正收益，故$b>0$。

令AC交叠重X，无交叠暂记0。其行收益$a-X$，有$b\ge r(a-X)$及$0\le X\le c$。若$b\ge c$，

\[
b\ge r(a-X)\ge r(a-c)\ge r(a-b)\ge r(r-1)b,
\]

与$r>\phi$矛盾，含$b=c$边界。因此$b<c<a<d$。

令AD交叠重Z，无则0。AD→AC和AC→BC给

\[
X\ge a-b/r\ge(r-1/r)b>b>0,\qquad
Z\ge d-c/r>d(1-1/r)>0.\tag{2}
\]

两客户确实存在。若它们身份不同，同覆盖A使$a\ge X+Z\ge a+d-(b+c)/r$，即$rd\le b+c$；但$b\le a/r<d/r,c<a<d$，推出$r<1+1/r$，违$r>\phi$。所以AC、AD共有的是同一名客户x，$X=Z$，不是仅同重。

因$X>b$，B不覆盖x。令BC、BD交叠分别Y、T，无则0；二者均不是x，彼此可同一或不同。C覆盖x及可能的Y，故$c\ge X+Y$。全部收益为

| | C | D |
| --- | --- | --- |
| A | $(a-X,c)$ | $(a,d-X)$ |
| B | $(b,c-Y)$ | $(b,d-T)$ |

四坏边给$b\ge r(a-X),d-T\ge r(c-Y),a\ge rb,c\ge r(d-X)$。因此

\[
a\le\frac{r^2X}{r^2-1},\quad d\ge r(c-Y)\ge rX,\quad c\ge r(r-1)X.
\]

由$c<a,X>0$得到$(r-1)(r^2-1)<r$，即$q(r)<0$。取$r=\rho$矛盾。故至少一格所需因子严格小于ρ；无交叠的reach相等、缺交叠和其他客户身份关系均已覆盖。

## 固定纯平局规则及短目录提升

给全部带设施标签行动不同优先级h，全序按$(R,h)$升序。每格唯一共同客户选较小行动，其余强制，得到完整纯NE规则P。

2×2允许reach平局时，把四个带标签行动临时做成独立地点副本，保原覆盖，另给副本s私有权$\varepsilon h_s$。小正ε保持所有非零reach差，原平局按h严格分开；跨对交叠人数不增加。固定原分配下每方收益只加$\varepsilon h_s$。若原四格均非ρ稳定，每格选一条$v-\rho x>0$的真实偏离；有限四个严格余量在同一足够小ε下全保持，违上节。故原固定规则已有ρ稳定格；副本只用于证明，算法不求极限，也未把平局严格界升级为$<\rho$。

设短边为$|U_1|\le2$，在**全目录同一P规则**中逐行选$t(s)\in\arg\max_{t\in U_2}P_2(s,t)$，只保列集$T=\{t(s)\}$。若为2×2用上结论，第一家全部行动未删，第二家的全行最佳列仍在，故子矩阵稳定格对原目录所有偏离也稳定。只有一行则选其最佳列；两行却只有一保留列则在该列选第一家最佳行，二者均精确稳定。任意挑两列没有这个提升保证。全游戏严格交叠reach时，子问题给$\alpha<\rho$，提升保此因子。

对n客户直接计算各reach、交叠及P矩阵，扫描全行最佳列，再检查至多四格，保守$O((n+1)|U_1||U_2|)$有理运算，覆盖零客户。正有理$v>x\ge0$时精确比较$v\le\rho x$可用

\[
v^3-v^2x-2vx^2+x^3\le0;\tag{3}
\]

$v\le x$直接接受，$x=0<v$三次式拒绝。因$q(z)<0$于$1<z\le\phi$且在$[\phi,\infty)$严格增，(3)在所用全部域等价。权重和的公分母位长不超过输入分母位长之和，三次乘法只增常数倍，故为位多项式。输出完整纯规则可按优先级查询，无需混合平局。

## 六客户锐下界：全部续局均不能避开

目录$\{A,B\},\{C,D\}$不交。四名私有客户权$a_0,b_0,c_0,d_0$各只覆盖对应站；x权X覆盖A,C,D，y权Y覆盖B,C。假设

\[
a_0>c_0+Y,\quad d_0>a_0,\quad b_0<c_0+X.\tag{4}
\]

AC中x严格选C；AD中x严格选A；BC中y严格选B；BD全强制。四格全部NE及CCE收益唯一：

| | C | D |
| --- | --- | --- |
| A | $(a_0,c_0+X+Y)$ | $(a_0+X,d_0)$ |
| B | $(b_0+Y,c_0+X)$ | $(b_0+Y,d_0+X)$ |

环AC→BC→BD→AD→AC的比为$(b_0+Y)/a_0,(d_0+X)/(c_0+X),(a_0+X)/(b_0+Y),(c_0+X+Y)/d_0$。

取$X=1,d_0=\rho-1,a_0=1/(\rho^2-1),b_0=d_0-a_0,Y=a_0-\eta,c_0=\eta/2$。$q(\rho)=0$给$\rho a_0=d_0,1+a_0=\rho d_0$；$0<\eta<a_0$使全部权正并满足(4)。四比恰为

\[
\rho-\eta/a_0,\quad\rho/(1+\eta/2),\quad
\rho d_0/(d_0-\eta)>\rho,\quad\rho-\eta/(2d_0).
\]

给定$1\le\alpha<\rho$，选

\[
0<\eta<\min\{a_0,a_0(\rho-\alpha),2(\rho/\alpha-1),2d_0(\rho-\alpha)\}
\]

则每格均有严格大于α的真实偏离。先固定α、η，再在正性、(4)和四个$v>\alpha x$构成的有限严格开域内同时有理化六权，最后清共同分母为正整数。不能把含ρ的实公式直接叫有理输入。各格严格占优使CCE也唯一，所以不是仅由“NE唯一”推CCE唯一；任意混合或CCE续局均不能修复。

整数$(a_0,b_0,c_0,d_0,X,Y)=(44504187,35689587,1,80193774,100000000,44504185)$给有限最优$80193772/44504187>9/5$，其四格收益与先前[下界对象](../反例/相关客户续局与异构双目录的下界边界--反例.md)一致。该旧对象只证明严格模板锐性，本页补全受限上界；新[任意目录定理](单交叠任意目录的ρ纯续局与高区障碍--定理.md)再以同一2×2族给全类锐性。单个有理实例无需恰取无理ρ。
