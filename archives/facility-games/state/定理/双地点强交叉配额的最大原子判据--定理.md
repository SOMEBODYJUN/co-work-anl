# 双地点强交叉配额的最大原子判据

## 精确局部范围

固定[两个原子设施](两设施原子客户的完整混合均衡负载谱--定理.md)，reach R≥r>φR/2、共同总重C<qr，q=(√5−1)/2、φ=1/q，专属负载R−C,r−C。正实权可讨论正确性，显式正二进制有理权讨论算法。C0直接私有负载达标；C>0令最大共同权x、S=C−x。则有独立混合精确客户NE同时满足L_R≥qr,L_r≥qR，**当且仅当**
\[
S\ge R-r\quad\text{或}\quad x\le R-qr.
\tag{I}
\]
等号允许；r>φR/2和C<qr两个严格区间未改成闭域。菜单常用x≤(1−q)R只是(I)的充分子类，不是精确必要条件。存在时O((n+1)^4)有理运算、多项式位长构造局部见证；一般NE坐标极小值仍[弱NP难](../归约/指定设施均衡负载极小值的弱NP完全性--归约.md)，两个目标不同。

## 统一数值裕量与混合质量

缩放R1，δ=1−r，a=q²=1−q，则0≤δ<a/2；V=2−δ−C，U=V−2q=2a−C−δ，Z=V−2qr=2a−C+q³δ。配额等价−Z≤Δ≤U。由C<q(1−δ)得
\[
U>q^4-a\delta>q^4/2>0,\quad Z\ge U,\quad Z>3\delta/2,\quad V/2>q.
\]
这些只用总重/到达区间，不用x≤a。

m≥3名指定混合者（可概率端点）、其他纯总重P_A,P_B时，(m−1)Δ=−δ−P_A+P_B。若Δ=d≥0，C≥δ+(2m−1)d+2P_A≥δ+5d；若Δ=−e，C≥5e−δ。总重界给(C−δ)/5<U及(C+δ)/5<Z，所以至少三指定混合者的NE自动达配额。这里指定端点不得再计入纯总重。

## 外分支及不可能性

若S<δ且x≤1−qr，固定x在B，其余作[最大权纯改善](../引理/两设施纯改善的移动界与默认续局--引理.md)。任意中间分配LB−LA≤x+S−δ<x，所以固定x确稳定；终LB≥r−S>2r−1>q。若LA<qr，则LB−LA>Z>S，每个仍在B的其他共同客户都能严格移A，故终态其余全A，LA=1−x≥qr矛盾。

反之S<δ且x>1−qr时，x选A成本至少1−S>r，选B成本至多r，故严格选B。在此条件下，任一其他客户选A成本至多1−x<qr≤q，选B成本>r−S>2r−1>q，故严格选A。唯一NE为(1−x,r−S)，首配额失败。这是对**全部mixed NE**的否定，而非一个构造器返回失败。

## 内分支的初始NE与局部交换

S≥δ时，对除x外的盒截面Σc_i=−δ,|c_i|≤w_i，运行[两坐标端点交换](../算法/盒截面平方和的两坐标端点交换--算法.md)。其输出仅为所述端点邻域局部最优，非全局凸最大；具体582/654例亦保存在该对象；历史稿另说明可加一名最大共同权19，取R120,r110，总共同重65<110q、其余截面目标−10，故这个非全局输出例确能嵌入强弦域，不是域外反驳。全端点则令c_x0得Δ0。否则唯一内点权z、值d，令c_x=d，则Δ=d，两人无差异。交换保证纯+v满足d≤v、纯−v满足d≥−v，故是NE。坏正差d>0还保证纯+v权≥z、纯−v且v<z者有v≤d；负差对称。这些是后续实际用到的全部交换合同。

## 坏正差d>U的完整分支

若尚有纯A，质量恒等式和其权≥z≥d推出C≥δ+5d，与上面裕量矛盾，所以其余全B、总重δ+d。称权≥z者大，其余小者≤d。

1. 有小v∈[d/3,d]：将x,z,v指定混合，差(d−v)/2∈[0,v]，其余B，得三指定NE。
2. 无大且所有小<d/3：按非增权取总和首次达到d之前的非空前缀T<d，下一人v给d−T≤v，前缀每人≥v；把前缀m人及x,z混合，差(d−T)/(m+1)≤v，余者B。
3. 恰一大y、其他小总重T且δ+T≤2z：混合x,y,z，差−(δ+T)/2，所有小A，幅度≤z≤x,y。
4. 未在前3返回时至少一大且d≤δ：两大时δ+d≥2z≥2d；一大且δ+T>2z时2δ+d>3z≥3d。令x纯A，其余B，初LA=r−z−d、LB=r−x、gap G=x−z−d。LA>qr，因为2(z+d)≤C<qr且1−q/2>q。若LB<q，则x+δ>a，得C>a+2d，而C<q(1−δ)、d>q^4−aδ联合推出δ>a，矛盾。若G≥0已纯NE；G<0时|G|≤d，x在低侧、z及大客户≥d不能改善，只有小<d/3从B往A。首次反转前A增、B≥V/2>q；若先停已达配额；若反转，新正差<d/3≤δ/3<a/6<q^4/2<U，两侧此后都>q，任何严格纯改善保该共同下界，终达标。

前三分支的指定者幅度均受自身权界，纯客户在差的低侧或满足对应符号不等式，故不是仅满足负载方程的假NE；≥3指定者再按质量引理给配额。

## 坏负差−e<−Z的完整分支及宽条件修正

纯B若存在，其权≥z≥e，质量推出C≥5e−δ矛盾，故其余全A、总重e−δ。若有v≥e/3，将x,z,v混合，差−(e−v)/2，余者A，即三指定NE。否则其余皆<e/3。由C=x+z+e−δ、e>Z得e≤z<q³r；另U>q³r/3>e/3。

改x纯B、其余A，初LA=1−x、LB=1−z−e，G=z+e−x≤e。若G≤0已NE（高侧x优势<x）；若G>0且LB≥q，两侧都≥q，修复安全。剩下LB<q且G>0时，z≥e≥G不能移，x在低侧，只有小<e/3移A→B。B到q即安全；若先反转，新幅度<e/3<U≤Z，两侧已>q；若既未到q又无反转却停，则原留A小客户全可改善，故须全已到B，LB=r−z，而δ+z<a给r−z>q矛盾。

上述初LA≥q只在原菜单x≤a域直接成立。要证明完整(I)，不能漏较宽修正：坏负差本身迫x<1−qr。否则x−δ≥ar，C≥ar+2e，与C<qr推出e<q³r/2<q^4<Z矛盾。因而LA>qr；G≤0分支依此就达首配额，G>0的两种分支仍如上。这是去掉最大权上界时必须补的接口，非口头沿用窄域。
