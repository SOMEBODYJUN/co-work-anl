# 双设施双目录模型与完整精确续局

## 输入、时序与参与规则

有限客户集I，每名客户i有严格正原子权wᵢ；I可为空。有限物理地点集V，每个地点s覆盖集合Cₛ⊆I。设施1、2有各自有限非空目录U₁,U₂⊆V，先同时选位置，得到**带标签**布局(s,t)∈U₁×U₂。两目录可不同、可相交；同址合法但设施标签仍不同。不同地点可以覆盖同一客户集合，空覆盖地点也合法。共同目录分支额外要求U₁=U₂=S。

客户观察整个布局。没有覆盖者的客户不服务且无行动；只被一家覆盖的客户必须选它；两家都覆盖的客户须选其中一家，不能退出。客户独立随机化，最小化自己选定设施后、包括自身**完整原子重量**的实际总负载之期望。设施最大化收到的期望客户总权。模型没有距离、容量、开设费、第三设施、客户特有地点成本或相关随机化。

客户混合不是每次实现将权重拆开；一次实现中客户仍整名去一家。实际条件成本与设施期望收益是不同对象。共同目录k=2与[任意设施数原子模型](../../subarchives/common-many/state/定义/共同目录任意设施数模型--定义.md)一致；本定义还保留其未覆盖的U₁≠U₂分支。

## 固定布局上的精确客户NE

令\(A=w(C_s\setminus C_t)\)、\(B=w(C_t\setminus C_s)\)，公共客户重新编号为1,…,k，权wᵢ>0，pᵢ是选择设施1的概率。设施期望负载为

\[
X=A+\sum_iw_ip_i,\qquad Y=B+\sum_iw_i(1-p_i),\quad\Delta=X-Y.
\]

客户i选1的条件成本是\(X+w_i(1-p_i)\)，选2是\(Y+w_ip_i\)，差为\(\Delta+w_i(1-2p_i)\)。故独立混合精确NE恰要求

\[
p_i=1\Rightarrow\Delta\le w_i,\quad
p_i=0\Rightarrow\Delta\ge-w_i,\quad
0<p_i<1\Rightarrow\Delta=w_i(2p_i-1).
\]

不能把X、Y直接当成客户两条件成本；排除自身后计算背景又忘记加回自身也会改变模型。[完整负载谱](../定理/两设施原子客户的完整混合均衡负载谱--定理.md)保留名义混合支持的闭端点和单混合者整区间，精确覆盖全部NE。比如一个公共客户、A=B=0时任意p∈[0,1]都是NE，不是只能对半。

每个布局的NE集\(\mathcal N(s,t)\)非空且紧。可将公共客户按权非增依次放到当前较低私有背景侧，得到纯NE：对任一侧最后放入的公共客户，其重量不小于该侧最终负载差，该侧更早客户又更重，均无改善。NE条件给闭集合，概率域有界，因此坐标最值达到。该非空性不是黄金比存在定理的推论。

## 完整规则与设施稳定的量词

完整续局是函数σ，满足

\[
\sigma:U_1\times U_2\longrightarrow\bigcup_{(r,u)}\mathcal N(r,u),
\qquad\sigma(r,u)\in\mathcal N(r,u)\quad\forall(r,u)\in U_1\times U_2.
\]

选择在轨布局(s,t)，其客户NE收益为(X,Y)。给定α≥1，要求

\[
L_1(\sigma(r,t))\le\alpha X\quad(r\in U_1\setminus\{s\}),
\]
\[
L_2(\sigma(s,u))\le\alpha Y\quad(u\in U_2\setminus\{t\}).
\tag{SPE}
\]

全模型存在性目标是“对每个输入，存在一个纯设施布局和一份完整精确客户NE规则，使所有实际单方偏离满足(SPE)”。不是每个客户NE、每套规则都使设施稳定，也不要求每个离轨布局自身在设施层稳定。第一阶段设施同时行动，没有依次选择的有序提供者历史；因此与CAG六提供者完整历史纯SPE不同。

标签不可交换取商。第一设施偏离落在(r,t)，第二设施偏离落在(s,u)；若不同目录，反射布局(t,s)甚至未必合法。共同目录的对称性和同址正规形不能无前提移植到U₁≠U₂。

零在轨收益直接使用(SPE)：本方所有实际偏离收益都须为零。若用收益比描述，零/零在该约束中贡献0、正数/零为+∞，总稳定倍率仍至少1。没有实际偏离的单元素目录自然给空约束；全无客户/全零覆盖允许倍率1。

## 真实坐标极小与全目录威胁接口

定义

\[
m_1(s,t)=\min_{e\in\mathcal N(s,t)}L_1(e),\qquad
m_2(s,t)=\min_{e\in\mathcal N(s,t)}L_2(e),
\]
\[
D_1(t)=\max_{r\in U_1}m_1(r,t),\qquad
D_2(s)=\max_{u\in U_2}m_2(s,u).
\]

给定在轨NE能扩为α稳定完整规则，当且仅当\(D_1(t)\le\alpha X,D_2(s)\le\alpha Y\)。必要性来自任一实际偏离至少获得相应真实坐标极小值；max里含不动选项无碍，因为\(m_1(s,t)\le X,m_2(s,t)\le Y\)且α≥1。充分性在每个第一家实际偏离取第一坐标极小NE，每个第二家实际偏离取第二坐标极小NE。两族目的布局在排除不动后不相交，其余布局补默认NE，故没有冲突。这是[双目录精确算法](../算法/双目录交叠参数下的实例最优续局--算法.md)的数学接口，不代表这些极小值可统一多项式求出。

同一布局的m₁、m₂可由**不同NE**达到，不能把二者拼成一份同时达到的概率向量。m₂应由该布局第一收益的最大值反射求得，不是取达到m₁的第二收益。共同目录才可另定义只计异址的H(t)，再用[同址正规形](../算法/同址平衡正规形与异址交叠参数精确优化--算法.md)合法省同址支持枚举。

若预先给每布局非空有限菜单\(F(s,t)\subseteq\mathcal N(s,t)\)，菜单坐标极小u只满足m≤u。菜单惩罚可实现且单实例达到证书可以验证，但菜单最优不自动等于真正实例最优。找到回应环后也不能把D的max域由**全部合法目的地**改成环内；环只是搜索/证明工具，偏离合同仍是全目录。

令α*(I)为全部在轨布局与完整规则上的最小稳定倍率（无有限倍率时按扩展实数理解）。有理输入下有限最优值的有理性/达到与证书合同见上述精确算法，不从某个菜单证书的说明字符串继承最优性。

## 实数存在、编码算法及身份变更

存在性可在正实权上叙述；位复杂度与可执行算法另要求客户和覆盖逐项显式列出，权重为正二进制有理数。数学允许实概率NE；证书/算法若要求显式有理概率，须另证明其位长。精确有理字符串与API浮点的接受规则属于各具体程序接口，不能从模型定义统一猜测。

| 改动 | 必须重新核的对象 |
| --- | --- |
| U₁=U₂改成不同目录 | 反射布局的合法性、同址偏离、真实威胁域及常数界 |
| 独立混合改成相关或粗相关 | 局部均衡集合、条件成本及完整规则证书 |
| 允许退出、增加费用/容量 | NE条件及设施偏离的全套推导 |
| 正实权改为编码有理数 | 算术次数、中间位长、输入/输出长度 |
| 存在一份规则改成任意规则 | 主命题的量词；不能通过注释暗改 |

源model要求改变这些条件时明确新的数学身份；这条版本约束作为来源合同保存。原source里的历史链接和登记方式不替代当前清洗授权。本批未执行旧源操作指令。
