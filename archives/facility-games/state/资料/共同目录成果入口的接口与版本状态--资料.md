# 共同目录成果入口的接口与版本状态

## 入口身份与五种判断

原`research/current/shared/README.md`为共同目录双设施专题的数学入口，完整7,449字节已实读。它所说“黄金比普遍上界、位多项式构造、匹配下界”为源入口对成果的报告；不能用目录文字代替被引证明的逐式审查。本次同时核了现行[连续稿资源](双设施黄金比连续稿与固定菜单证明合同--资料.md)、[五处修订及待审范围](../审查/双设施黄金比稿的五处修订与待审证明域--审查.md)、精确算法、复杂度、粒度及近平衡/EPTAS正文。

必须分开的判断是：数学对象/量词是什么，来源主张了什么，实际证明整理到哪里，程序/证书真正核了什么，内审/外审/优先权到了哪一步。源README列“多轮内部审读”保其版本身份；**现行SC-PHI-E/A仍按修订后待targeted review记录**。当前审查明确要求cycle transport和polynomial constructor的新定向复核，不能由目录积极措辞、小域成功、TeX/PDF可读或没有主定理反例而升级为verified。

原README把主稿组织为两节主文及长附录、并将实例复杂度另成支线。当前已整理资源记录1125行/26页修订稿的实际身份和边界；本批没有冒认重读其TeX/PDF，也没有把README列出的每篇canonical来源都代为done。那些源各自的读取/处置依其receipt，不由入口的超链接自动继承。

模型首读应使用[双设施完整续局定义](../定义/双设施双目录模型与完整精确续局--定义.md)：S为共同目录、设施两家、客户精确独立NE、存在一份完整有序布局规则、设施偏离全目录。存在性、搜索位复杂度、单实例达到与真正实例最优是不同合同；本专题不是CAG六提供者的任意完整历史纯SPE。

## 同址正规形主源的逐节吸收

原`instance_complexity_barriers.md`完整10,010字节新读，源范围同一共同目录两设施模型，内部证明，无外审。各节数学去向为：

| 源节 | 独有内容与实际去向 |
| --- | --- |
| 模型及式(1) | 真异址m与H、标签反射、菜单极小不可替换；纳入新定义的接口边界并链接既有正规形 |
| §1，式(2)–(3) | α*=min{同址G、异址放松F}，并能在每个同址均用对半；完整下界/候选不安全时改同址/判定形式已由既有算法自足保全，本批不复制第二定理 |
| §2，式(4) | 全异址闭支持、clamp、有理位长、异址κ；既有正规形算法和完整谱已保全，见下段空实例约定 |
| §3 | ≤2地点、全同reach、单交叠至多两reach的全部结构证明，新增自足[精确稳定类](../定理/少地点与两种覆盖总重的精确稳定边界--定理.md) |
| §4 | 五客户、两reach、全局α*=14/13反例；已有[完整反例对象](../反例/两种覆盖总重的多交叠三地点不稳定例--反例.md)和真实原输入运行，直接复用 |
| §5 | 三地点固定a<σ、五地点固定a<φ的全局困难性和高倍率小地点未决；复用新全布局归约及前沿，保“除非P=NP，困难族需无界异址交叠”的边界，非参数下界 |

正规形的空值约定不可省：H的空max为0，单地点的空异址候选min为+∞；零分子/零为0、正分子/零为+∞，或直接用收益乘法不等式。全零覆盖仍得α*=1。异址κ的空max为0；时间界按空实例常数开销统一可写

\[
O\bigl(|S|^2[n+1+\kappa_{\ne}3^{\kappa_{\ne}}]\bigr),
\]

非空输入常见原式省略+1。所有同址Cₜ再大也不进入指数。源数学是对任意编码有理输入的精确优化；具体`shared_offdiag`的达到检查器不认证最优性，必须靠完整谱/正规形证明或重算支持给出最优。

一个异址F候选只是暂忽略同址偏离的放松值；若最优异址候选不安全，证明会换同址，而不是宣称那个在轨候选也合法。与[全交叉单交叠程序](../算法/全交叉单交叠双目录的区间最优与达到检查--算法.md)也要分清：后者要求所有合法交叉布局（含同址）交叠≤1，不能消费仅异址单交叠但同址很大的全部共同目录输入。

## 程序、证书与版本状态的实际意义

原README分别链接`shared_offdiag`、五地点构造器/两审计和一般`facility_spe`；其名称不能互换为同一个solver。已整理程序的区别是：

- 固定菜单φ生产者给可验证达到证书，未优化全部客户NE；全局φ与位多项式保证仍有自己的证明审查义务。
- `shared_offdiag`依全部异址支持和正规形求真正α*；其verify只核达到，说明字符串不是最优性证书。
- 独立完整规则检查器重新核NE及真实偏离；接受某份规则不证明全输入存在、最优或搜索时间。
- 五地点构造器只构造输入，原audit_case是有限精确支持检查；full-diagonal=false用已证正规形仍可求该实例全局α*，source_yes是源SUBSET SUM真值。
- 四地点审查已独立重构一般证明和有限运行，未冒认复现原作者未知上传包及自报次数；这不否定其可自足核的解析归约。

各原字节/真实命令/输出均链接既有计算资源，本批没有重跑成功数学程序。不能把本批文档/哈希/链接检查写成新的数学运行。

## 局部补全为何不等于已交付EPTAS

[近带算法](../算法/固定重支持近平衡精确补全的位多项式选择--算法.md)在固定布局、给定H>0、轻权≤H/重权>H、逐名指定重纯或真正混合支持下，精确判定并输出|Δ|≤H的NE；轻人数、最小权倒数与数值分母不受常数限制。k=0、|D|≤S、D>S、D<−S及平局边界已有完整内部完备性和位长证明。

[EPTAS候选](../候选/实例最优倍率EPTAS的精度组合与未交付接口--候选.md)另需要全部布局的重支持枚举、闭外带片与近带代表、两个坐标各自极小、全目的地max、在轨优化、完整精确续局及一般位复杂度。其相对失真组合C²与η=ε/16的加性误差推导已保存，但不能由局部引理或有限原型自动升级为通用规范算法交付。四地点无FPTAS与允许指数依赖1/ε的EPTAS候选相容。

## 阅读用途与接续

源README的三条阅读路线有实质区别：证明一般φ需模型/分离陈述/坏环/局部构造/算法全链；研究尖锐性与实例难度先分下界、地点数、固定倍率与精度gap；做新算法先核同址正规形，舍入/EPTAS先核粒度和精确近带接口。旧ROADMAP只是一份来源路线入口，不是方法白名单或本次清洗的新执行指令。源中的账本/历史稿链接保存出处身份，不从“当前”“已审”字样继承外部认证。

本批无新外文获取、外审、投稿操作或优先权认证。后续一般φ仍应在明确冻结版本上核任意坏环、全部菜单归属/反射、锚点无循环及强弦正负gap/端点/位复杂度；小地点结构/局部工具/复杂度结果各自可独立复用，不因主证明待审一并退回开放。形式关系已分别解释为定义、推导、限制、实现与有限验证，无CAG迁移或为连通造边。原三主源和逐节去向元数据见[manifest](../../../../tools/evidence/facility-model-frontier-primary/source-manifest.json)。
