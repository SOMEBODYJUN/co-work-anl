# 设施示例总入口与证明配对

原入口为5行850字节，标题“Inputs, not proof records”；两个冻结提交字节相同。它没有列任意k的贪心JSON，而是跨两个双设施目录给资源配对纪律。本次全文实读原入口并比较原始shared输入复核、黄金比有理族、异目录ρ分支与已保存证据；没有重新运行求解或借入口替这些独立源申报完成。原件和逐源hash在[manifest](../../../../tools/evidence/common-many-primary-register/source-manifest.json)。

这些资料均是设施先选址、正权原子客户独立随机选覆盖设施、含自身重量的条件负载成本、存在一份完整精确客户NE续局。共同目录两设施是任意k共同目录的特例；heterogeneous允许两设施不同目录，不能因此套用任意k共同目录搬到任意站的转移预算，也不同于六位顺序提供者均分客户收益的CAG。

原页要求每个输入与ASSETS内精确模型配对，生成输出及历史证书在evidence/certificates；这些是旧源位置。现在可执行原字节和已审正文见上表，具体重放快照各有固定manifest，不能在重构后以旧相对路径可点为证据。本批仅保留入口职责/模型和已有数学去向；既有753等有限审计记录也不在此重新计数、运行或认证为新覆盖。

此资源与各例是来源/资源配对关系；与普遍定理的关系是特定输入的实现或有限核验，不是输入→普遍命题的推导。任意设施数的65项登记另见[范围审查](../../subarchives/common-many/state/审查/任意设施数命题登记与证据分层--审查.md)。未改共享入口和图；后续可按各对象实际假设接续。
