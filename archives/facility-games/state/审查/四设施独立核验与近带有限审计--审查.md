# 结论范围

这三份原始 JSON 都是 `status=passed` 或 `all assertions passed` 的精确有限运行，但每份都把量词限制写在自身字段中。四地点源的 `yes/no` 是原PARTITION等分判定答案，支持枚举和解析对角guard核其归约性质；近带源把 `near_feasible` 作为固定 heavy-support central representative 上的有限可行性判定。程序通过只能证明这些输入上的断言，不把布尔字段改写成任意设施数、任意权重、完整均衡集合或多项式时间算法的定理。

三源均使用 `Fraction`，并声明没有浮点运算。原始字节、源哈希、基线提交和 replay 命令均保存在 [four-site-near-band-20261030 证据目录](../../tools/evidence/four-site-near-band-20261030/)；其中四地点 JSON 的基线为 `97d2805cdd6c4de4ce6eca25770a19a6783419ab`，两份近带 JSON 的基线为 `303c8fadbcaaeac0b30c201802857c8f68734a18`。

## 四地点独立支持审计

### 输入、真实谓词与计数

本源是两家设施、四个共同地点、正权原子客户的精确条件负载NE模型。当前已全文取得151行独立审计程序及对应构造器、完整证明；partition(src)精确枚举原向量等分子集，yes表示原PARTITION有解，而非支持/guard内部谓词。19例记录92496个support cells examined、17890 accepted cells、932718个条件费用比较，原等分YES8/NO11，YES完整规则在归一化/整数版本共96个实际偏离检查。它不是“存在FPTAS”的标签，也不是成功概率。

### 全部输入与精确数值

| n | 输入层数 | YES | NO |
|---|---:|---:|---:|
| 4 | 10 | 3 | 7 |
| 6 | 5 | 2 | 3 |
| 8 | 4 | 3 | 1 |

n=4的YES为[1,1]、[2,2]、[10^12+1,10^12+1]；n=6为[1,1,2]、[2,3,5]；n=8为[1,1,1,1]、[1,2,3,6]、[7,7,13,1]。完整19输入、全部分数、代码/旧报告SHA及模型合同见[四地点两设施精确支持审计](../资料/四地点两设施精确支持审计的完整合同--资料.md)。[1]的core guard为6136/4695；[1,10^12+1]实际为1416000000002832/1083461538463705，二者不同。

### 支持覆盖、解析guard与历史边界

程序对核心BC及五个其它无序非对角布局枚举所有闭三态支持，包含名义混合端点及一混合者区间，并从原条件费用核NE。它没有枚举全部对角支持，而以每个对角NE至少一方负载不超过reach/2及七个解析偏离guard排除低因子对角解；非核心五布局检查唯一NE。核心core_guard_lower_bound是全核心NE上的min max{1,R/X,(R−q)/Y}，并非任意内部标签。本19输入该值均<1.31，结合其它路径解析下界>1.31给全局最小倍率。YES构造完整16布局规则，NO全核心支持给正gap。

one_nominal_mixed_cells记录允许端点重叠的名义状态数，不是均衡数目。两份32/19例审计输入重叠，计数不合并；有限成功本身不证明全输入复杂度结论。原JSON“当时未取得原始audit package”的文字是历史事实，本轮已取得源码不追改其字节。完整全输入及位复杂度论证另见[四地点无FPTAS证明](../证明/四地点无FPTAS间隙的全支持与编码核算--证明.md)。该精确两设施模型与CAG六人顺序覆盖模型不同。

## 近带主审计：固定 heavy-support central representative

### 明确模型与生成器

`near_band_completion.json` 把范围写成 `fixed heavy support central representative only, not full EPTAS or global approximation`。生成器是边界案例加 1200 个随机案例，共 1322 例：

* (Hin{1/5,1/4,ldots,5}) 的有理取值来自 (U\{1,\ldots,5\}/U\{1,\ldots,5\})；
* light 数量在 (0,ldots,6)；
* light 权重形如 (Hcdot U\{1,\ldots,12\}/12)；
* 差值参数 (D=Hcdot U\{-120,\ldots,120\}/12)；
* heavy mixer 数 (k=U\{0,\ldots,4\})。

它执行的不是完整 EPTAS，而是固定 heavy 支持下的中心代表近带可行性检查。四个检查项是：

1. 对 light 支持做精确 (3^{\text{light}}) closure enumeration；
2. 直接检查含 weight (2H) heavy mixer 的条件成本 NE 不等式；
3. 检查精确的 total-difference identity；
4. 检查概率域约束。

### 结果与其正确解释

1322 例中 `near_feasible=388`、不可行 934，比例约为 (29.35\%)。每个可行记录包含有理数 `delta` 和 light probabilities；例如最小边界中，空 light 支持且 (D=0) 可行，含一个 heavy mixer、空 light 支持而 (D=1/8) 不可行；加入一个 light 权重 (1) 后同样的 heavy mixer、(D=0) 可给 light probability (1/2)。这些记录说明 heavy mixer 会改变近带可行域，但它们是实现输入上的条件成本比较，不是对所有 heavy patterns 的闭包定理。

从完整记录重新统计，heavy mixer 数 (k=0,1,2,3,4) 的样本/可行数分别为 (254/76,276/60,273/71,245/74,274/107)；light 长度 (0,ldots,6) 的样本/可行数分别为 (193/39,206/54,184/61,198/62,190/53,163/53,188/66)。这些分层数字仅描述这次生成器覆盖到的有限样本，不能外推单调性或概率。

主 JSON 的 `status=passed` 表示上述有限断言通过；`meaning=finite exact attack only; not a theorem proof` 则直接否定把结果写成普遍定理。特别是 `near_feasible=false` 记录是该固定代表模型的不可行证据，不是完整均衡模型的反例，除非另外证明代表模型与目标模型等价。

## 近带独立交叉审计

`near_band_completion_independent.json` 没有逐实例 records，而是给出另一份 Fraction 运行的汇总：

| 项目 | 数值 |
|---|---:|
| instances | 2004 |
| full_support_cells | 148990 |
| heavy_patterns | 8000 |
| near_cells | 4867 |
| selector_outputs | 2206 |
| comparisons | 13690 |
| monotone_light_moves | 756 |

参数为“400 background/2-weight instances × 3 eta，加上 800 个随机 `<=6-common` 实例与显式边界”。它声明 `all assertions passed; finite audit only`，并列出样本可能与其他审计重叠、没有 canonical EPTAS implementation、没有 general theorem。由于没有 per-instance records，不能从汇总反推与主审计的逐例交集、失败实例或 selector 的唯一性；它只提供独立生成器下的规模/计数交叉证据。

两份近带运行共享三个可接续事实：有理精确算术、light 支持至多六项的有限检查、heavy 支持模式被显式枚举或固定后再检查。它们不共享足够假设来推出一般 heavy 支持、任意 light 长度或全局近似比；`monotone_light_moves=756` 也只是独立审计中被检查的移动，不是所有 light move 的单调性证明。

## 关系、处置与后续边界

* `four_site_fptas_independent.json` **retained/integrated** 到本审查对象，作为已有四地点审计的独立有限核验；其 19 个实例、8/11 布尔分层、96 个 yes-certificate deviations 和未枚举对角支持但有解析排除的真实范围全部保留。
* `near_band_completion.json` **integrated** 到本审查对象，保留 1322 例的生成器、388/934 可行分层、(3^{\text{light}}) 枚举与 heavy-mixer 条件成本检查。
* `near_band_completion_independent.json` **integrated** 为同模型的独立规模交叉核验，保留 2004、148990、8000、4867、2206、13690、756 七项汇总及其重叠/无定理限制。

这些对象与 `共享流与多设施有限审计边界--审查` 的关系是“同一设施/共享流专题的独立增量证据”；不把本批运行计数当成原有 32 实例的追加样本。与 customer-attraction 存档没有可直接复用的共同定义域：其中四地点设施输入也有有限非空共同目录，但它是两设施/加权原子客户NE，近带对象是固定局部支持；均不同于六名单位提供者按完整有序历史行动并在终局覆盖者间均分的纯SPE目标。因此不得把近带的 `near_feasible`、四地点的 `yes` 或任何 guard 分数接成 Q-CAG-HALF-6 的证明。

可供后续研究的实际接点只有三项：

1. 提供一个可重复的 Fraction 全核心/非对角闭支持枚举模板，与解析对角排除及全布局实现比较；
2. 提供 heavy mixer 与 light move 的边界样例，供证明近带条件是否可推广时作反例筛选；
3. 提供四地点有限guard的精确有理下界，与已交付全称gap证明和位复杂度核算比较；有限运行本身不代替证明。
