# 三份异构回应核心、精确目标与长环来源补充审查

本审查逐字读取三份冻结来源的 `clean show` 输出，保留两个冻结提交版本的 source ref，不把相同路径的双版本折叠成一个未注明来源。三份来源分别是：`heterogeneous_independent.md`（通用因子二的逐行独立审计）、`response_core.md`（回应核心、纯菜单、目标可行性和单交叠精确求解的研究总注记）、`sparse_long_cycles_prior.md`（单交叠长回应环的参数化构造）。原件、blob、字节数和 SHA-256 见证据目录的 manifest；本审查不以标题、旧摘要或有限程序通过替代数学判断。

三份材料使用同一双设施异构模型：两家带标签设施分别从有限非空目录选择动作，物理同址仍按颜色保留；客户有正权和固定可达集，覆盖后强制选择可达设施，成本包含自身重量的实现总负载，客户续局按带标签布局逐一独立选择。设施收益是期望服务重量，完整规则的偏离在相应带标签布局上另选客户均衡。这个模型与六提供者、有限主题共同目录、覆盖客户在提供者间均分的 CAG 目标保持分离，不能从本批来源推出 CAG 的半覆盖命题。

## 1. 冻结来源身份与实际内容

### 1.1 `heterogeneous_independent.md`

`clean show` 实际读取的路径为 `history/source/audits/heterogeneous_independent.md`，来源 ID `efa54acf2e95f920660b`，blob `267b0a2addd313e68413bb8dbc3240f12ebacf98`，8503 字节，SHA-256 `43f5d5c2ac7c0ee41445997492a7edf554dd1e48aa406437ea28a312de3f87b5`。文本逐节审计 `universal_two.md` §§1--7，并复核 `upper.md` 的受限菜单定义；它明确声明结论只针对任意非空有限、设施特定允许集，不限制小侧动作数，客户可达关系和共同客户数均任意。

其数学承重包括：

* 菜单必须按带标签布局共享，两方向都保留全体共同客户单侧种子和单一指定客户种子；不满足低侧重量守卫的种子丢弃，严格改善使用 `w < gap`。
* `D` 是对完整对手目录的最大威胁，回应环只负责选顶点；配额见证 `L_s >= D(t)/2`、`L_t >= D(s)/2` 可逐布局指定离轨最小坐标，两个偏离族在带标签布局外不相交。
* 若坏环有重量至少 `1/2` 的可见客户，客户身份沿响应边传播；单人种子与守卫修复排除该情形。最大边后使用 `E`、`X` 和合法异色弦 `C--F`、`B--G`，分别处理 `h >= e/2` 和 `h < e/2` 两分支。来源特别检查了负 `h`、任意偶环长度、零威胁、同址和重复覆盖。
* 来源还给出四种子压缩的量词修复：在坏环可见客户全集中按 `(weight, global ID)` 选同一个最大客户，保证每条边预先选定的单客户种子都是真正使用的种子；由此得到每个布局至多四个纯见证的候选复杂度。
* 它把 `O(|U_1||U_2|(n+1)^3)` 的全 singleton 菜单算法和四种子 `O(|U_1||U_2|(n+1)^2)` 的实现边界写成位多项式构造，并明确“有限测试不是任意输入证明”。

该来源的独有价值是把最终通用二证明的量词、客户身份和两条异色弦逐项复核；它没有引入独立于当前 `异构双目录通用因子二的双色回应环证明` 的新模型。由于现行四种子对象仍把全称长环闭合保存为内部候选，本文保留“独立审计通过/状态未升级”的分离：来源的审计结论可以支持现行内部证明链，但不能单凭它把候选对象或主稿的 theorem 标签升级为外部认证定理。

### 1.2 `response_core.md`

`clean show` 实际读取的路径为 `history/source/notes/heterogeneous/response_core.md`，来源 ID `8b16fbb2b68bfae75765`，blob `93c4e8a02bec8c55ec7bd261a07ff0e22681d73e`，38071 字节，SHA-256 `32cf08d9deca38b7b355df12973ca6fec3a42c94e47608534fa5a10e8ce669a9`。它不是单一证明，而是将多条结果放在同一研究注记中；因此必须按子命题分别处置。

第一部分给出一般闭回应核心结构。对有限带标签动作集 `A,B`、每个布局非空允许续局集 `E(s,t)` 和非负收益，定义坐标极小 `m_1,m_2` 及全目录威胁 `D_1,D_2`。在轨收益 `(x,y)` 能否补成完整 `alpha` 稳定规则，恰由 `D_1(t) <= alpha x`、`D_2(s) <= alpha y` 判定；必要性用每个偏离后续局至少达到坐标极小，充分性用两类不相交的带标签偏离布局分别选择两个坐标的极小见证。按全目录最大极小回应画双色函数图，任意简单环的两个颜色子集保持原 `D_1,D_2`，从闭核心内的稳定见证提升到完整目录。这个部分与当前 `独立续局的威胁配额与双颜色回应核心` 的抽象定理一致；新来源提供了更长的解释、外部动作证书接口和“核心大小不自动有常数界”的提醒，但没有改变该定理的量词。

第二部分把闭核心应用到共同客户较少的路线：若每个跨对至多一个共同客户且较小目录至多两个动作，来源声称可由 `sparse_lower_prior.md` 的 `rho=2 cos(pi/7)` 短核心结果得到任意较大目录侧的尖锐 `rho` 保证；全目录威胁必须在共同动作上计算，目录特定外部动作需要单独的一个坐标不超过核心威胁的证书。该论述与现行单交叠 `rho` 对象兼容，但其“任意外部动作只需一个证书”的算法实现条件应保持为模块接口，不能改写成所有异构游戏都有 `rho`。

第三部分是守卫纯菜单和任意目录因子二的研究路线。来源完整重述全体单客户种子、修复、四种子压缩、`R` 菜单的坐标最小值以及任意长坏环的两分支推导；其 `Theorem 1B/1C` 与当前 `守卫纯修复的边界与四种子证书算法`、`四种子坏回应环的两分支推导与候选边界` 使用同一数学合同。当前正式对象将局部修复、菜单非空、双配额补全和位长视为已证接口，但将一般长环四种子闭合保留为 `candidate-proof-expanded-no-global-status-upgrade`。所以本来源中的“universal factor-2 construction passed”只能记录为来源主张及内部审计线索；本文不把它作为新的独立全称证明，也不把有限回归结果当作定理。

第四部分给出目标相关的局部精确可行性约化。固定私有负载 `A,B`、共同权重 `w_i` 和目标区间 `I=[2a-V,V-2b]`，若 `I` 严格位于零的一侧，令 `eta=min_{z in I}|z|`，仅保留 `w_i >= eta` 的战略客户，把更轻客户强制放到低负载侧并吸收到私有负载中。来源证明这是保持两个设施负载的 NE 双射；等号客户不能删除。它随后把约化实例交给阈值/MITM 精确构造，复杂度保留对战略客户数的指数依赖，因而不能称一般多项式核。该部分与现行 `阈值半表的精确目标与响应剪枝`、`两设施原子客户的完整混合均衡负载谱` 一致，独有内容是把“单侧分离区间”写成一个可组合的强制轻客户约化。来源同时给出 `(A,B)=(1,0)`、共同权重 `(2,4)` 的缺口例和 `beta=9/5` 的三权重例，说明即使质量可行，完整 NE gap 集也可能离散而非由单一重客户决定；这些是有限手算障碍，不是全局反例。

第五部分给出跨目录至多一个共同客户的精确实例求解器。无共同客户时收益固定；有一个共同客户时，非等 reach 下客户唯一去较低 reach，等 reach 下全部概率区间 `[A,A+w]` 都是 NE。对每个跨对计算真实坐标极小 `m_1,m_2`，再在可达第一负载区间上最小化 `max{1,D_1/x,D_2/(V-x)}`，平衡点 `x_0=V D_1/(D_1+D_2)` 后夹到区间，得到实例最优倍率而非仅有普遍上界。严格递增且两端使用同一客户成本函数时，局部 NE 对应保持不变，故该精确类可扩展到这些非线性成本。该内容与当前通用多面体和单交叠对象的接口相容；它不能外推到每个布局有两名以上战略客户的非线性情形，也不能把有限 `200` 或 `500` 次随机验证改写成算法正确性的解析证明。

第六、七部分列出实现名称 `r_menu_solver.py`、`cross_one.py`、测试数字和趋二下界输入。它们是可复现线索，原来源没有随本批提供每一个运行日志和代码冻结副本；本审查只保留文字原件，不虚称重新执行。现有正式证据中，局部 MITM、谱、显式续局多面体和六客户趋二族各有独立对象；来源中的测试数字要在再次使用时标为有限实验。

### 1.3 `sparse_long_cycles_prior.md`

`clean show` 实际读取的路径为 `history/source/notes/heterogeneous/sparse_long_cycles_prior.md`，来源 ID `bed86d526bb3854df269`，blob `ad81507416a3365f99519fd0ca3262a45fc5cd09`，4330 字节，SHA-256 `7f3866336511f7969b512a0fe0cc68b2303dd60dc61cedfeb43cc7e894fbb3cf`。来源只构造“回应核心可任意长”的正整数族，不声称超过 `rho` 的近似 SPE 反例，也不解决稀疏目录问题。

对任意 `n >= 2`，两目录各有 `n` 个站点，`M=4n^2`，reach 交错，列 `C_n` 无共同客户；每个其余跨对放一名独有共同客户，权重按相对行列距离给出，每站用正私有客户补足 reach。来源逐式计算固定列/行的唯一响应，得到唯一 `2n` 节点环 `C_1 -> A_2 -> C_2 -> ... -> C_n -> A_1 -> C_1`。因此任何同时对两种全目录响应函数封闭的非空精确核心必须包含全部动作。`n=3` 表格是一个有限手算检查，而且有布局倍率 `104/103 < rho`；它明确不是坏倍率例。

该来源的逻辑强度仅是“不能从单交叠条件自动推出与目录大小无关的短精确回应核心”。它没有证明无 `rho` 稳定布局，也没有否定利用客户身份、权重或近似威胁见证的压缩。现有 `单交叠精确回应核心的长环与亚rho坏族` 对象已经整合了这个普通长环，并另外保留参数更强的亚 `rho` 坏族；本批来源应作为普通正整数长环的原始证据，而非重新命名为坏 SPE 反例。

特别保留三个容易混淆的边界：

1. `response_core.md` 的抽象闭核心定理可使用真实 NE 的坐标极小，也可使用固定有限菜单，但整个证明必须从头到尾使用同一 `E(s,t)` 或同一菜单；不能在弦上换成全混合 NE 极小、在环上又换成四种子值。
2. 单交叠 `rho` 结果的共同客户上限是**每个合法跨目录对**至多一个，不是每个客户只出现一格，也不是全局共同重量上限。趋二六客户族恰使用每格两名共同客户，故不在该类中。
3. 回应核心闭合只保存全目录最大威胁，不保存全局最优倍率。显式多面体对象已经给出闭核最优可大于全局最优的抽象例；普通长环进一步说明精确核心大小可以随目录增长。

## 3. 结论、缺口和可接续工作

本批三源全部已实读、比较并保全。可作为正式数学正文使用的内容是：

* 独立续局的配额判据、全目录双色回应核心提升、分离目标区间的轻客户强制双射和单交叠至多一共同客户的精确夹逼公式；这些与现有对应定理/算法对象的模型和量词一致。
* 普通正整数长环的完整参数化、唯一回应函数和 `n=3` 手算表；它作为构造证据明确说明固定大小精确回应核心不由单交叠条件保证。

必须继续标为条件或候选的内容是：

* 任意异构目录四种子菜单的全称长环闭合及由此得到的普遍因子二算法。来源和独立审计都支持当前内部证明链，但现行对象仍把该环论证保留为 candidate；有限随机测试、代码通过和来源 theorem 标签都不改变该状态。
* `rho` 的任意外部动作模块化接续。它需要每个外部偏离提供一个实际坐标证书；没有证书的目录特定动作不能凭核心内结果自动处理。
* 非线性客户成本在每个布局超过一个战略共同客户时的求解。当前仅有单交叠精确类或显式有限多面体表示。

尚未解决的缺口包括：是否能在不升级四种子候选状态的前提下，用独立于大菜单的全称算法证明任意异构目录因子二；是否存在更强条件下的常数大小“近似威胁”核心；以及如何把现有有限测试、局部 MITM 和证书验证转成带输入模型的可审计复现记录。后续第三阶段可据此建立“配额判据 -> 闭核心 -> ρ/因子二条件结果 -> 普通/坏长环障碍”的关系证据，但不应把本批普通长环直接导入为半覆盖 CAG 结论。
