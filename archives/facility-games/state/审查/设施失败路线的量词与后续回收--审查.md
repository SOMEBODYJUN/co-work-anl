# 设施失败路线的量词与后续回收

## 主源身份和共同模型

57142字节485行原失败路线全文已读，共54节；FR13–43这31节按实际模型归本页，其余23节在[CAG真实顺序收费审查](../../../customer-attraction/state/审查/失败路线中的真实顺序收费与模板边界--审查.md)。原current入口19行1881字节强调独立模型、自足稿不等于外审，本批保持其导航责任而不从一个总表认证各全局定理。三设施问题另外完整读82行8631字节，独有模型和重复占位问题另成[自足问题](../../subarchives/common-many/state/问题/三设施重复占位的二倍完整续局--问题.md)。所有原件/两冻结来源/54节完整去向在[证据](../../../../tools/evidence/facility-primary-boundaries/README.md)。

本页主模型是有限正权原子客户、有限非空地点目录、带标签设施、覆盖时强制服务、客户独立随机化。客户条件成本c_if=w_i+Σ_(j≠i)w_jp_jf，设施收益L_f=Σ_iw_ip_if。完整续局在每个标签布局给精确客户NE，第一阶段稳定量词为**存在布局及一份完整续局**，而非任意NE续局都好。共同目录和异目录分开；费用扩展若改E[L³]另行定义，客户相关CE/CCE也另行定义。它们都不是顺序CAG均分模型。

## 需要区分的五个否定对象

1. 一个真实实例的**所有布局/全部续局**都破某倍率，才是模型下界。
2. 固定占位即使可任选NE都需近二，只限制该占位选择法；实例可在别处精确稳定。
3. 同占位一个特定NE所有离轨都破二，只否定该NE的选择；另一NE可能安全。
4. 一个全局势/lexmax/降q/列表算法选错，只否定那个算法及其前提，未排一般选择器。
5. 精确优化一个指定oracle强NP难，不证明任意因子二见证搜索难；没有总步数界也不等于已有超多项式下界。

原文每项负例都保其量词。后续规范贪心普遍全盒存在靠不同的截断交错势/归家构造，不使旧盒P极小或未截断lexmax规则重新正确。后续冻结静止超载允许非偏离设施保44而偏离者帽41，绕过的是“全普通设施统一帽”接口；不能替真正强迫偏离>2的坏在轨NE生成不存在证书。

## 算法时间与复杂性更新的实质内容

全局强NP困难的3-PARTITION族每站私有P=mB+1、公共总X=mB。重复占位会使某设施<(P+B)，全局lexmax第一坐标达到P+B恰等分；真实贪心每站一家、所有公共赋值已全盒，精确加权势达到PX+(mB²−Σa_i²)/2也恰等分。却可占齐各站、纯NE各家≥P，任何偏离把公共总X=P−1给偏离者已精确稳定。因此“此oracle难→因子二目标难”在同族直接失败。多项式邻域局部lexmax是充分PLS搜索问题，整数势位长多项式只给表示上界，不给多项式迭代或PLS难性。

双设施一般局部弱困难也不能直接换名为全局DEC_a：要控制所有竞争布局。两具体稀释/加背景移植失败仍真，但三站固定a=1及1<a<(1+√3)/2、五站每固定有理1<a<φ已有全布局弱NP完全归约；恰三/四站高阈值细分类不因此解决。三站σ处负私有预算只限制那套硬边/宏原子角色，不是全模型算法相变。五站NO间隙可指数小，不能由其直接排FPTAS；四站另构造PARTITION的1/(100n²)精度gap，YESα*=13/10、NO≥13/10+gap，取ε=1/(200n²)才给确定性加性FPTAS反证。地点数始终不是设施数。

共同目录双设施实例算法还有异址交叠参数精确多项式域；不能靠同址大客户数宣称难性。精确原子NE的支持会在舍入时突变，伪多项式DP不自动FPTAS；原输入/精确NE/输出显式有理完整规则合同必须保持。允许近似客户NE、固定精度PTAS或EPTAS候选是另问题，本页不把未交付选择器说成实现。
