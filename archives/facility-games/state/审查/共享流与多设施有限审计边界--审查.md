# 共享流与多设施有限审计边界

## 模型隔离

这十六份来源使用 shared customer、设施布局、共同客户概率、flow/rerouting、菜单响应环或多设施盒修复的语言。它们没有 CAG 的“有限非空共同主题目录、顺序单位提供者、客户在最终覆盖者间均分、完整历史纯 SPE”量词。因此本页所有 factor、reach、loads 与运行计数都保留独立模型身份。现有 [shared 黄金比例对象](../../../customer-attraction/state/定理/shared模型黄金比例菜单界与独立边界--定理.md) 和 [common-many 因子二对象](../../subarchives/common-many/state/定理/共同目录任意设施数因子二存在--定理.md) 是主正文；本页只补充本批冻结运行及其边界。

## shared/菜单与环审计

### 四种 seed、MITM 与 lazy ring

`eee4d91421456ae1c5cc` 的 four-seed 回归包含 1200 个 random instances、3 个 directed instances、2406 个 full/four-seed certificate checks、2038 个 pair-subset checks、3 个长度至少六的 cycle，four-seed 菜单最大条目为 3。`e0e4ec30b79797622082` 的 all-singletons 历史模式做 500 个随机证书检查、150 个 support 比较、4 个 directed checks、5 个四环；一般目录段另有 1500 个证书检查、102 个四环、13 个长度至少六的环，最大观测长度 6，最大报告 factor 为
\(80193772/44504187\)，并确认篡改证书会被拒绝。`388b3ea908c3a4133312` 将同一随机规模重跑为 `maximum_only` seed mode；一般段为 1500 检查、106 个四环、13 个长环，仍为最大长度 6、同一最大 factor，并拒绝篡改证书。

这三份报告证明的是各自 seed/menu 生成器和证书验证器在给定有限样本上的一致性。all-singletons 与 maximum-only 的计数差异说明 seed mode 是模型输入的一部分，不能把两次计数拼成一个更强定理。

`f0b5cc42a5891e1ab79e` 的 `lazy_ring` 只断言 30 个 lazy/full checks 通过：所有访问的 \(d\) 值与完整 MITM 值相同，完整最优值不超过 ring-restricted 最优值，且 NE/deviation certificates 两侧均核验。`cc6cb3d78ed59a2b117e` 的 MITM 回归通过 435 个 pair checks、12 个 global games。两者是算法实现的有限回归，不是任意布局的 ring 充分条件。

### shared phi 与强 chord

`b01949814ab883be55d8` 审计 753 个 games，最大观测 menu factor \(2013/1508\)。on-path 家族计数为 `guarded_pure=662`、`equal_reach_half=88`、`two_designated_mixers=3`；三 mixer strong-chord 样例的 private loads 为 \((40,39)\)，common weights 为 \((20,20,20)\)，最终 loads 为 \((277/4,279/4)\)。

`f7a5e472330bc37c4b91` 做 12000 轮 Fraction 分支审计，记录 11165 个 two-mixer、2795 个 dominant-feasible、54 个 infeasible，以及 positive/negative three、large-three、prefix/repair 等稀有分支。定向 `positive_prefix` 样例取 \(r=17/20\)，权重为 \((4/25,11/100,1/32,\ldots,1/32)\)，对应概率和为原 JSON 的精确分数，loads 为 \((4261/6400,4251/6400)\)；另有 local-not-global 目标向量 `[14,13,19]` 与更优向量 `[-14,-13,17]`，说明局部目标选择不等于全局最优。该运行只覆盖有限分支分类。

`02826e1e151409d8c738` 给出 on-path layout \((0,1)\)、family `strong_chord_positive_large_three`、三个首设施概率各 \(39/80\)、loads \((277/4,279/4)\)、factor 1，并检查 9 个 complete tagged layouts；源字段明确这是 selected C branch 的有限实例。`08bdbeccbf475436d39e` 给出 corrected integer instance 的 exact finite factor
\(499750/309017\)、layout \((0,4)\)、36 个 labeled layouts；其渐近 rational lower family依赖 `sharp_phi_lower.md` 的独立证明，不能由这一份 JSON 单独承载。它们与既有 shared 黄金比例对象合并，新增的是冻结 run 的计数、有限化限制和 corrected-instance 边界。

## equal-light 多设施审计

### 完整最小化与对抗性

`412c97fd6ab806d9cad7`（equal-light-flow）在固定网格和随机范围上完成 5242 instances、14995 legal assignments、7840 个优化域外 box assignments、5720 global minimizers、20066 个原始选项比较和 12280 solver augmentations；362 个实例有多个 global minimizers，另有 1 个 multiple reverse-reroute fixture、32 个 invalid inputs rejected。`41b0ab6732ba2f681e68` 在 4500 random cases、1000 identity cases 和 exhaustive grid 上检查 89521 assignments、7902 all-global-minima、6791 residual graphs、4015 个含 zero-cost cycle 的 residual graphs；还记录 1000 个 nonuniform path identities。两份均 `all_passed`。

这些数字支持：在 equal movable weight、原始优化域不预筛 box/H 的条件下，当前实现的 global-minimizer 与 box/H 检查相容。它们不证明 unequal-weight 的多项式时间，也不证明局部 NE 选择器。对抗性报告还给出两个独立边界：strict greedy 的 local NE 不推出 boxed lower bound；unequal path example 只击穿更强 selector。原文明确原始 ZIP 不可得，本轮用 checked-in audit 重建，不能把原 ZIP 的未读计数当证据。

`16b859d57c76b0432d4b` 的 continuation audit 为 80 random cases，最大核验 factor \(144/73\)，并记录 301 certificates、192 movable customers、1338 actual labeled deviations、5613 complete rule layouts；`1f7975b1376390625150` 的 greedy-box-global audit 为 1161 abstract inputs、1548 nonnegative states、210 H-attacks、200 foreign-return attacks、528 complete certificates、2556 actual deviations，最大核验 factor \(950/537\)。两者均明确：off-path/default 使用有限 pure improvements，只有 on-path flow 步骤具有 bit-polynomial 描述；没有一般多项式总时间证明。

### 补集变换与四设施枚举

`a5f8e5b9ba5fdc781d9e` 与 `7cb3ad91d724c7445430` 是同一 complement-reduction 线的两个版本。最终版本完成 448 compilations、5718 assignments、45372 deviations、534 source NE、224 greedy comparisons、232 strict steps、700 band inputs、9930 band states、179338 physical conditional cost comparisons；并重现 random unbounded NE outside box 和 minimal-band boundary。版本差异在 source hashes、binary speed import bits 与额外边界记录，数学状态相同：有限实现检查，通用结论仍依赖正文证明；不含 equilibrium oracle、PLS hardness 或 polynomial improvement bound。

`79d0b8c76eebaca202fa` 的 `four_site_fptas` 用 Fraction/整数枚举 32 个源实例，结果 `yes=8,no=24`，共 886344 个枚举、59340 个 accepted support cells、811138 个 conditional cost comparisons。示例源 `[1]` 在 \(n=4\) 的 factor 为 \(6136/4695\)，各十个无序 layout 的 factor 全部冻结在 JSON 中；supports 允许重叠且含端点，因此计数不是 distinct equilibria，也没有 canonical NE solver。该来源是四设施有限支持枚举与硬度探针，不是 FPTAS 定理，也不迁移到 CAG。

## 处置和接续

所有 16 个 raw JSON 原字节已冻结在 `archives/facility-games/tools/evidence/shared-flow-audits/`，`manifest.json` 记录 source ref、raw SHA-256、字节数及解析状态。处理方式为：

* shared seed/MITM/ring/phi/chord（eee、e0、388、f0、cc、b019、f7、028、08）`integrated` 到已有 shared 计算/定理对象，保留本页的有限量词和 seed-mode 差异；
* equal-light/greedy/complement（412、41、16、1f、a5、7cb）`integrated` 到 common-many 因子二及其审查对象，新增对抗性与复杂度边界；
* four-site FPTAS（79）`retained` 为独立的有限枚举审查，不并入因子二定理。

本批没有把任何运行计数提升成全称结论，也没有给 CAG 建迁移边。后续若建图边，关系类型只能是“有限验证支持”“反例限制更强选择器”“独立模型启发”；其共同前提必须明确写出 equal-light、shared customers 或 facility menu，不能只按“都出现 factor”连接。
