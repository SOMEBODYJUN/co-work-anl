# 离线讲义导出检查器的源码合同与真实输入绑定

本对象对应完整4,671字节learning/check_reading.py，SHAf4b1406a847bdefee3ba50ebfb36e4c10622b10f2d12648ed257adbcd04fa9af。已逐行读源码和真实最终HTML/audit/manifest输入身份；它检查源字节与导出结构的一致性，不判数学命题真假，不是NE证书检查器，也不执行浏览器或PDF视觉。源码保存为配套原件，不改任何函数、断言或输入来制造通过。

## 输入和真正依赖

脚本用Python3、标准库hashlib/json/pathlib/re/sys/collections.Counter，另依第三方lxml.html。命令只有一个位置参数：导出HTML路径；用resolve取得绝对路径，审计JSON路径恰为HTML路径字符串追加.audit.json。仓库根由脚本文件所在目录的父目录确定，所以脚本必须位于重建根的learning/内；把脚本孤立复制到别处会改变所读Markdown/manifest根。

审计JSON需sources列表，每项path/bytes/sha256；另需equations/mathErrors/sectionFallbacks。根learning/manifest.json需modules列表，每项path。所有source路径和JSON均属受信输入合同，脚本不提供通用模式验证。漏参数、漏文件、坏JSON/UTF8、lxml解析异常可能直接抛出异常，而不进入自建errors列表。

## 公式提取与显示归一化

source_formulas先删三反引号围栏和单行单反引号片段，再按正则抽取四种TeX定界：双美元、反斜线方括号、单美元单行、反斜线圆括号。它不是完整Markdown语法解析器；例如波浪线围栏、多反引号语法及任意嵌套不在显式规则内。

render_normalization把mspace的mu宽度转等价mkern，把SPE_alpha标签改成渲染器可用数学标签；split环境若任一行多于一个&则统一换aligned。末尾strip，其他数学字符串不作代数化简。

对每个源：实际字节数和SHA不符则记Source changed；从源提取归一化公式形成Counter。按sources中的索引寻找唯一section id=source-index；没有恰一section则记Missing source section并跳该源公式比较。该section所有encoding=application/x-tex的annotation文本strip后也形成Counter。两Counter必须完全相等，缺/多报前四项。重数受到核查，但不比较公式出现顺序，也不证明两个不同TeX串数学等价或渲染图像正确。

## 全局结构和退出合同

1. audit的source path集合须等于manifest所有module path集合；这是集合等式，不验证manifest其他教学角色/claim内容、原顺序或重复path重数。
2. 全HTML所有id计Counter，重名报Duplicate ID；所有以#开头的a/href须命中id。外部URL和其他普通相对链接没有在该循环逐个访问验证。
3. 全HTML的TeX annotation总数须等于audit.equations；audit.mathErrors非空或DOM含独立katex-error类均失败；sectionFallbacks非零失败。
4. script/src、link/href、img/src必须以data:起头；原HTML里小写url(...)的正则匹配值去掉空白/引号后也须data:。它核这些指定显示资源语法，不是任意HTML网络行为/脚本内容的完整审计。
5. 删除script/style/pre/code与katex子树后，普通可见文本不得残留双美元、反斜线方括号或形如双星号强调标记。它不遍历所有可能未渲染内联数学/Markdown语法，不检验截行、字体、交互和真实浏览器显示。
6. errors非空逐行打印并exit1；否则输出sources/equations/uniqueAnchors及三类零错误计数的JSON，正常exit0。未捕获输入异常亦会非零退出，须与已判定某个错误列表区分。
