# 两种覆盖总重的多交叠三地点不稳定例

两带标签设施可从同一目录$\{A,B,C\}$同时选址，允许同址。五名正权不可分客户被覆盖后必须服务，独立混合，以包含自身完整权的实际条件负载为成本；设施收益为期望服务总权。完整续局可在每个有序布局自由指定任一精确客户NE。下面的结论对所有这种规则成立，不是某个固定菜单的失败。

原JSON客户从0编号，权重及可达地点为：

| 客户 | 权 | 可达地点 |
| --- | --- | --- |
| 0 | 6 | A、B |
| 1 | 6 | A、B |
| 2 | 8 | A、C |
| 3 | 5 | B、C |
| 4 | 3 | B、C |

因此$R_A=R_B=20,R_C=16$，只有两种覆盖总权。$A\cap B$及$B\cap C$各有两名客户，故该例不满足单交叠条件。JSON精确写`locations=[[0,1,2],[0,1,3,4],[2,3,4]]`；原件及双冻结路线见[manifest](../../../../tools/evidence/shared-certificates-runtime/source-manifest.json)。

## 三种异址布局的全部NE负载

固定私有负载$A_0,B_0$和共同权$v_i$，若$p_i$是选第一家的概率，令$\Delta=L_1-L_2$。纯第一要求$\Delta\le v_i$，纯第二要求$\Delta\ge-v_i$，真正混合要求$\Delta=v_i(2p_i-1)$。以下直接使用这些条件，不把小菜单当全部NE。

- **AB：** 私有负载$(8,8)$，共同权$(6,6)$。纯NE各把一名共同客户放一边，负载$(14,14)$。两人都真混合时$\Delta=2\Delta$，所以$\Delta=0$、两概率均$1/2$，负载仍$(14,14)$。恰一人真混合要求另一纯客户的有符号贡献为0，但其为$\pm6$，不可能。两人全在同边违反高侧客户条件。因此全部NE只有这一负载对，虽然分配本身不唯一。
- **AC：** 私有负载$(12,8)$，一名共同权8。该客户选择两边的条件成本分别20、16，严格选C，唯一负载为$(12,16)$。
- **BC：** 私有负载$(12,8)$，共同权$(5,3)$。四种纯分配只有权3在B、权5在C满足条件，给$(15,13)$。恰一人真混合要求$4\pm3=0$或$4\pm5=0$，均不可能；两人都真混合要求$\Delta=-4$，却有$|\Delta|>3$，不可能。因此这里也是唯一NE负载对。

交换设施标签只反射负载。这覆盖六个有序异址布局，不要求客户NE对应连续。

## 对所有完整规则的下界

令$H(t)$为对手在t时、本方改去不同地点后不可再压低的最大收益。因异址全部NE负载已定，

\[
H(A)=16,\qquad H(B)=14,\qquad H(C)=15.
\]

在轨$(s,t)$收益$(x,y)$必须满足$\alpha x\ge H(t),\alpha y\ge H(s)$；即使未计算同址惩罚，这也是所有规则的必要条件。异址三类及任意同址NE因此分别有以下倍率下界：

| 在轨类 | 不可规避的倍率下界 |
| --- | --- |
| AB | $\max(14/14,16/14)=8/7$ |
| AC | $\max(15/12,16/16)=5/4$ |
| BC | $\max(15/15,14/13)=14/13$ |
| AA | $2H(A)/R_A=8/5$ |
| BB | $2H(B)/R_B=7/5$ |
| CC | $2H(C)/R_C=15/8$ |

同址下界只用两家收益和为$R_t$、至少一家收益$\le R_t/2$。各类的最小值是$14/13>1$，故任何布局和任何完整精确独立混合续局都不能构成精确稳定的设施选择。

## 匹配达到与意义

在轨取BC的纯NE收益$(15,13)$；所有异址取上面的NE，同址各客户独立对半。B设施改去A得12、改去C得8，均不超过15；C设施改去A得14、改去B得10，最大14。故这份完整规则的倍率恰$14/13$，与下界匹配：

\[
\alpha^*=14/13.
\]

本批用原JSON实际运行全支持`shared_offdiag.solve`及有限菜单`shared_phi.solve`，两者都给在轨`[1,2]`、收益`[15,13]`、倍率`14/13`；9个有序完整续局另直接核条件成本，见[计算正文](../计算/共享目录原始输入与四种子入口的接续复核--计算.md)。全称最优性由本页六类排除及达到证明承载，不来自求解器的`verify`。

它精确限制[实例前沿中“两reach且单交叠有精确稳定”](../审查/实例最优计算的参数与判定前沿--审查.md)的假设：不能删除单交叠。它既不是所有三地点实例的最坏常数，也不是关于任意客户模型或相关续局的结论；CAG共同主题目录、顺序六人纯SPE及半覆盖目标保持独立。
