# 相关客户续局与异构双目录的下界边界

## 放宽到CE/CCE不自动改善共同目录最坏门槛

两设施共同目录、客户强制参加，设施仍按客户联合行动分布的期望重量评估偏离。NE⊆CE⊆CCE，因此**若**原普遍φ上界成立，旧NE规则也给CE/CCE的φ上界；下界必须逐布局排全部CCE，不能只说“NE唯一”。当前全局上界[仍按修订待审层保存](../审查/双设施黄金比稿的五处修订与待审证明域--审查.md)。

已完整旁读canonical sharp_phi_lower：q=1/φ、给定1≤α<φ，取0<ε<min(1/16,q(φ−α))。六客户重
\[
(2q,\ 2-2q-\varepsilon,\ 1-q,\ 1-3q/2,
\ 13q/2-4+\varepsilon,\ 2-2q),
\]
六地点覆盖依次{1,6},{1,2},{1,3},{1,4},{2,3,4,5},{6}，reach依次2,2−ε,φ,φ²/2,2q,2q²严格降。每异址对至多一战略客户，其选择两边的成本是不同确定reach，较低者严格占优；其余客户强制，所以CCE本身唯一。

异址15对的排除可分：12/13/14/23/24/34中前站家移5，25/35/45中前站家移1，15中5家移2，16/26/36/46中6家移5，56中6家移1。除15外比例≥φ，15比例(2−ε)/(2q)>α。全部同址布局不论相关分布/理性，总服务重reach守恒，有一家≤半reach；站1..6分别让较小家移2,3,4,5,1,2，异址后CCE唯一，改善比皆>α。此覆盖全部36标签布局，故没有α-SPE，即使CCE续局也救不了。

这使用**修正版**w_5加ε的canonical覆盖重；旧原图按未经修正w_5会给R_5=2q−ε而原附录表用2q，本批不直接以那张旧表当证明。canonical给共同正有理扰动半径min{最小权/2,最小reach差/24,q²(φ−α)/(12(1+α))}，保所有严格方向与改善；任意CCE在同址仍用总量，不假设NE连续。故每α<φ有正有理下界，得到sup≥φ；未称有限有理实例恰取φ。完整普遍“恰φ”仍需上界前提。

## 两目录不同的ρ六客户改善环

这是另一个模型：设施1仅可选A,B，设施2仅C,D。六客户/顶点A,B,C,D,x,y正权a,b,c,d,X,y，自身可达，额外x可达A,C,D，y可达B,C。若a>c+y、d>a、b<c+X，则四布局客户CCE全唯一：AC共享x严格C；AD的x严格A；BC的y严格B；BD无战略共同者。payoff矩阵
\[
\begin{array}{c|cc}&C&D\\\hline
A&(a,c+X+y)&(a+X,d)\\
B&(b+y,c+X)&(b+y,d+X)
\end{array}
\]
改善环AC→BC→BD→AD→AC比例
\[
(b+y)/a,\quad(d+X)/(c+X),\quad(a+X)/(b+y),\quad(c+X+y)/d.
\]
令ρ为z³−z²−2z+1最大实根=2cos(π/7)，取X1,d=ρ−1,a=1/(ρ²−1)=ρ²−ρ−1,b=d−a,y=a−η,c=η/2。ρa=d、1+a=ρd；η足够小时所有权及严格客户比较真，四比为ρ−η/a、ρ/(1+η/2)、ρd/(d−η)>ρ、ρ−η/(2d)，皆趋ρ。因此每α<ρ有排全4布局的正实权，严格有限不等式的开放性给正有理扰动、清分母给正整数；即使允许CCE也无α稳定。

实际整数witness(a,b,c,d,X,y)=(44504187,35689587,1,80193774,100000000,44504185)，四比依次80193772/44504187、180193774/100000001、144504187/80193772、144504186/80193774，最小第一项>1.8。是严格选择的精确整数算术，非浮点均衡。

## ρ只对这个严格分支给模板上确界

归一X1，若四比皆≥r>1，前后两比给r²a≤a+1，即a≤1/(r²−1)；r2给d≥r(c+1)−1，r4和y<a−c给rd<1+a，从而a>r²(c+1)−r−1≥r²−r−1。联合得r(r³−r²−2r+1)<0，对r≥φ三次严格增且在ρ为0，故r<ρ；r<φ自然<ρ。逼近族证明该strict-choice/同向四环分支sup=ρ，**没有证明整个异构模型上界ρ**，也未移植到共同目录。
