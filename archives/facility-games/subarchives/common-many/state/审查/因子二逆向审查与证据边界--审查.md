## 从假想反例反推足够的数学义务

固定一个在轨精确客户 NE、设施 \(f\) 的正收益 \(a\)，以及一个实际偏离布局。要否定“该偏离后所有精确客户 NE 都使 \(f\) 收益超过 \(2a\)”，只需构造**一个**不超过 \(2a\) 的精确 NE，无需求出混合 NE 集上的真实坐标极小值。

可先找一个可行纯初态：偏离者负载至多 \(2a\)，每个超 \(2a\) 原子独占某个静止设施，其他所有设施负载至多 \(2a\)。[保帽修复](../引理/原子装箱与受帽纯均衡修复--引理.md)表明这个非空有限集合对完整游戏的严格改善封闭；平方负载势保证其中存在精确纯 NE。重客户达到自身重量这一绝对成本下界，普通客户不能改善加入它；这两步使结果在原完整游戏成立，不是只在删去重设施后的受限游戏成立。

若某地点有 \(h\ge1\) 家静止设施，逐站总重条件 \(W\le(h+1)a\) 足以给初态：从单原子箱出发合并所有合重至多 \(2a\) 的箱；若最后多于 \(h\) 箱，每对箱总和都大于 \(2a\)，两两求和会推出 \(W>(h+1)a\)。超帽箱必须始终是原始单原子。

于是反向看布局选择应保证什么：

- 源地点存续时，源客户总重恰为 \((h+1)a\)。若别的已占地点预算失败，把 \(f\) 移过去会将源的 \(a\) 坐标全部提高，目标旧、新坐标又都大于 \(a\)，从而升序字典序改善。原未占地点新增覆盖重量超过 \(a\) 也有相同反证。
- 源地点消失时，\(J\) 表示该地点原分配客户，总重 \(a\)。存续地点必须为 \(J\cap C_t\) 预留预算；否则搬入并接收这批客户，使新目标负载大于 \(a\)。关键附加检验为 \(w(J\cap C_t)\le a\)，它推出目标**旧**负载也大于 \(a\)，排序反证才有效。其余仍被覆盖的 \(J\) 客户重分配只会增加其他站负载。
- 原未占目标必须同时计入真正新增覆盖 \(N_r\) 和源客户 \(J\cap C_r\)。两者不相交，不能只保留 \(N_r\) 而遗失源客户。

全局升序字典序最大者恰排除以上所有预算失败；同一个可行候选族上的单客户转移还独立保证在轨客户 NE。这一逆向论证没有假设候选已经设施稳定，也没有构造跨全部离轨子博弈的设施最佳反应势。

## 会改变结论的具体异议

| 潜在错误 | 实质核查与正确范围 |
| --- | --- |
| 将站内均匀混合当成客户可分流 | 每个客户在一次实现中只选一家设施；条件成本是 \(w_i+(W_t-w_i)/q_t\)，不是 \(W_t/q_t\)。 |
| 只在客户 NE 中取字典序最大者 | 候选族是所有可行布局和站点分配；用于反证的修改不需要为 NE。 |
| 客户转移的字典序方向反了 | 严格改善给 \((W_t-w_i)/q_t>W_v/q_v\)；修改后的两站所有坐标都大于旧较低水平。 |
| 偏离者在轨负载可能为零 | 最大覆盖 \(R>0\) 时，全同址候选给每家 \(R/k\)，最大者最小值至少此数；\(R=0\) 单独精确稳定。 |
| 单设施源地点消失后遗失客户 | 两个强化预算显式保留 \(J\cap C_t\) 和 \(N_r+w(J\cap C_r)\)，被覆盖客户没有被允许退出。 |
| 大原子被迫给偏离者 | 纯初态偏离者总重至多 \(a\)，超 \(2a\) 原子均在静止设施上孤立；由初态总重条件排除。 |
| 装箱步骤暗用最优 NP 难求解器 | 只需两箱可合并就合并；至多 \(n-1\) 次，箱数保证来自两两和不等式。 |
| 重客户可以移至空设施 | 只会平局；NE 无须消除平局，过程只执行严格改善。 |
| 普通客户加入重设施使不变量破坏 | 目的成本大于 \(2a\)，出发成本至多 \(2a\)，故不可能是严格改善。 |
| 限制不变量集合遗漏原游戏偏离 | 所有原游戏移动都逐类处理；可能严格改善的移动仍留集合内。 |
| 纯 NE 不足以对抗混合偏离 | 自身混合期望成本是纯行动成本的凸组合；无纯改善即无混合改善。 |
| 多设施偏离要求同一子博弈不同续局 | 从固定带标签布局出发的全部实际单坐标偏离布局两两不同；不能按占用数合并。 |
| 其余布局没有续局 | 每个布局的有限严格纯改善确定一个精确纯 NE 默认值。 |
| 离轨布局也必须设施稳定 | 本定义只要求所有布局客户 NE，在轨布局设施不等式；否则已改变命题。 |
| 不同设施目录可以直接沿用 | 任意设施能移至任意被比较站点是四预算反证的关键；异构目录未由此证明。 |
| 概率位长小推出算法时间短 | 短证书与有限默认规则不控制全局搜索或改善步数。 |
| 对称菜单的无界威胁是模型无界下界 | 同一实例和在轨布局有不对称纯续局支持精确 SPE，见下节。 |
| 装箱中 2 不能降低意味着模型尖锐为 2 | 它只限制相同标量预算接口；布局与完整续局的最优常数另论。 |

等号 \(2a\)、\((h+1)a\) 都合法；空客户、单地点、重复覆盖、未服务客户、正有理或任意正实权，以及全部源/目标重数均已在主证明中保留。没有用有限浮点实验判断严格不等式边界。

## 两个相关障碍的精确否定范围

### 对称离轨菜单可产生无界假威胁

来源 symmetric_menu_obstruction.md 的实例以 \(q\ge3\)、\(k=q+1\) 为参数，地点 \(A,B,T\)，三名客户分别为：

| 客户 | 权重 | 可达物理地点 |
| --- | ---: | --- |
| \(H\) | \(q^2\) | \(A,T\) |
| \(e\) | \(1\) | \(A\) |
| \(b\) | \(a=q-\frac14\) | \(B\) |

在轨把 \(q\) 家放 \(A\)、一家放 \(B\)，\(H,e\) 在 \(A\) 内独立均匀混合，\(b\) 选 \(B\)。负载为 \(q+1/q\) 和 \(a\)，该候选是站内均匀族的全局字典序最大者。若 \(B\) 设施搬到 \(T\)，并强制离轨每个客户对同址设施给相同概率，\(e\) 必均匀选择 \(A\) 的 \(q\) 家。于是 \(H\) 在 \(A\) 的排除自身负载为 \(1/q\)，在 \(T\) 为零，精确最优反应迫使 \(H\) 全去 \(T\)。偏离收益倍率为

\[
\frac{q^2}{q-\frac14}>q,
\]

无界增长。

但取消这种额外对称约束后，任意实际偏离仍留下至少两家静止 \(A\) 设施。将 \(H,e\) 各自孤立在其中一家；若 \(B\) 还在就让 \(b\) 独占原 \(B\)，否则它未被覆盖。每名被服务客户只承担自身重量，故为纯 NE，偏离者始终零收益。不同实际偏离布局各取该纯 NE，其余用默认规则，得到同一在轨布局的精确 SPE。

因此不存在从“所有受限对称 NE 很坏”到“全部合法 NE 很坏”的推论。源材料没有声称每个布局都对称菜单失败；它精确排除把该字典序见证的离轨续局强制同址对称。

### 固定字典序布局本身也可迫近 2

来源 lexmax_boundary.md 对每个固定 \(k\ge2\)、整数 \(h\ge2\)，使用地点 \(A,T,Z_2,\ldots,Z_{k-1}\) 与客户：\(H\) 权重 \(h\) 可达 \(A,T\)，\(e\) 权重 1 只可达 \(A\)，每个锚点 \(Z_j\) 有权重 \(M=3(h+1)/4\) 的私有客户。令 \(a=(h+1)/2\)。

所有站内均匀全局字典序最大者的占用都为“两家在 \(A\)，每个锚点一家”，负载 \((a,a,M,\ldots,M)\)。原因是锚点重占会给某家至多 \(M/2<a\)；\(A,T\) 总重至多 \(2a\)，三家以上放在二者会有小于 \(a\) 的负载；两家全在 \(T\) 失去 \(e\)，分处 \(A,T\) 时站点分配原子性会使某家至多为 1。只有上述占用能达最小负载 \(a\)。

在该占用的**任意**在轨混合 NE 中，两个 \(A\) 设施收益之和为 \(h+1\)，至少一家收益至多 \(a\)。让它搬去 \(T\)，\(e\) 被迫留 \(A\)，\(H\) 在 \(T\) 成本 \(h\)、在 \(A\) 成本 \(h+1\)，所以全部离轨混合 NE 都把 \(H\) 给偏离者。该占用的最优倍率至少

\[
\beta_h=\frac{h}{a}=\frac{2h}{h+1}\longrightarrow2.
\]

均匀在轨配合源文显式纯偏离见证可达到 \(\beta_h\)。然而换成 \(A,T\) 各一家、每个锚点一家，让客户各自独占，就有精确 SPE：除 \(T\to A\) 外可选零偏离收益续局；\(T\to A\) 则把 \(H\) 留给静止 \(A\)，让偏离者只得 \(e\) 的重量 \(1\le h\)。故全实例最优仍为 1。

这比标量装箱障碍更强：它排除只更换同一个字典序布局上的在轨或离轨 NE 来统一突破 2；它没有排除其他布局下的亚二普遍定理。两份障碍源本轮仅作比较读取，没有因此申报其来源已完成清洗。

## 算法前沿和文献位置应怎样读取

本轮实际比较了 polytime_frontier.md 的开头更新、MF-PURE-CAP-POLY、全局 lexmax 强困难性与 PLS 局部搜索相关段落。结果与当前源定理一致：

- 原严格纯改善只保证有限终止；一旦有在轨状态，逐偏离初态可在多项式步骤中生成。
- 条件性位多项式修复需临时移走孤立重客户及设施，将剩余客户映成受限相同并行链作业，调用“从任意可行分配产生纯 NE 且不增加最大负载”的文献算法，再放回重客户。有理权用分母乘积整体缩放，整数位长仍多项式；不按分母数值循环。
- 全局 lexmax 第一坐标的精确阈值问题有强 NP 完全性；相关归约实例同时可以有易求精确 SPE，所以它不是求任意因子二证书的困难性。
- 多项式邻居的局部极大状态也足以给在轨 NE 与四预算，形成 PLS 搜索上界；不推出多项式时间，也不推出 PLS 困难。
- 后来贪心盒的普遍可行性与有限构造已推进，但一般二进制有理输入的位多项式在轨选择仍开放。当前有限改善实现没有实装所导入的多项式调度器。

这些条件算法有自己的证明和前提，没有倒灌成本页主定理的外部依赖。来源中的文献定位也分别保留：

| 原源列出的文献 | 在原源中的比较作用与边界 |
| --- | --- |

## 内部审查结论与仍开放的事项

在已固定的共同目录、正权原子、强制服务、独立混合、线性实际负载及存在型完整续局模型中，主证明建立所有 \(k\ge2\) 的因子二存在性。本次逆向检查未发现致命缺口；结论依据一般论证而非有限实验。该精确模型中“最优所需倍率随设施数无界增长”的分支被排除。

仍没有得到：2 的尖锐性；全 \(k\) 的黄金比例上界；统一常数严格高于黄金比例的新下界；任意输入的位多项式在轨构造；设施依赖目录下相同结论；外部同行评审或文献优先权认证。对每个固定 \(k>2\) 的下界也不能从整体包含 \(k=2\) 自动推出。

本次入库已判断：本审查指向主定理及其两个引理作为检查对象；两个障碍分别限制离轨对称菜单和固定布局选择；有限程序是证据资源而非普遍推导前提；历史仓库检查是交付 provenance，不能变成数学依赖。正式超图留第三阶段建立，未复制旧图或为连通制造关系。
