# 有理证书命题的独立审查与有限程序边界

## 来源、对象和范围

本对象整理一个**证书命题及其审查状态**，不是把内部审查标签当作新的存在定理。主稿 `main.tex` 的实际内容从模型定义读到第 2 节结尾：有限客户集 `I`、正权重 `w_i`、有限非空共同地点集 `S`、显式标号设施 `F={1,…,k}`（`k≥2`），每个地点覆盖固定客户子集，设施可在全部 `S` 中选址，客户在可达设施间独立混合并最小化条件拥挤成本。原稿的 `prop:certificate` 位于 `main.tex:214–221`；其假设是正二进制有理权重、显式客户—地点关联以及显式列出全部 `k` 个设施。

对应的 `REFEREE_REPORT_round1.md`、`REFEREE_REPORT_round2_proof.md` 与 `prop-certificate.md` 审查记录逐段比较。两轮报告均把该命题理解为“短描述的完整续局 + 有限精确生成过程”，并明确不把它解释为多项式时间搜索定理。`prop-certificate.md` 的独立 chunk map、假设账本、依赖账本和攻击日志均以 `thm:main`、`lem:packing`、`lem:capped` 为局部依赖；其 verdict 是在三处 S4 文字修订后 `closed: verified as written`。

## 主稿实际证明链

主稿先在每个布局 `s` 中把覆盖客户各自分配到一个已占地点 `t`，记该地点的客户总重为 `W_t`，若地点有 `q_t` 个设施，则该地点所有设施各以 `W_t/q_t` 的独立均匀混合承载。对所有布局和站点分配，以固定总序取排序后设施负载向量的第一个 lexicographic maximum。这个有限最大化是存在性的选择器；设施标签保留，因而不同单设施偏离 `s[f←r]` 是不同布局。

在最大化选出的 `(s,p)` 上，若客户 `i` 从其分配地点 `t` 改去另一个可达已占地点 `v` 会严格降低条件成本，则把 `i` 的整重重新计入 `v`，使 `v` 的全部 `q_v` 个坐标由 `b=W_v/q_v` 严格增大，而 `t` 的坐标仍高于 `b`；这会严格提高排序负载向量，矛盾。因此 `p` 是精确客户 NE。把最大单地点可达总重记为 `R`，全体设施的最小负载至少为 `R/k`。

对被移动设施 `f` 的原地点 `u` 记 `a=W_u/q_u=L_f(p)`。若 `q_u≥2`，最大化比较给出每个存续地点 `t` 的 `W_t≤(q_t+1)a`，每个原未占地点 `r` 的新增覆盖总重 `N_r≤a`。若 `q_u=1`，单设施地点的客户集 `J` 会随设施消失，正确不等式必须保留交叠项：

\[
 W_t+w(J\cap C_t)\le(q_t+1)a,
 \qquad N_r+w(J\cap C_r)\le a.
\]

这两个附加项不能被“源地点消失后原客户留在原处”的简化替代；它们承担了对 `J` 中仍可达、转移后会改变覆盖的客户的完整量词。

对总重至多 `(h+1)a` 的客户列表，`lem:packing` 反复合并总重不超过 `2a` 的两个部分。若停止后有至少 `h+1` 个部分，则任意两部分和都大于 `2a`，对所有成对不等式求和得到总重大于 `(h+1)a`，矛盾。因此可装进至多 `h` 个静止设施；大于 `2a` 的客户只能作为单独一部分。

`lem:capped` 从这样的纯分配开始，只执行严格改善的客户移动。重于 `2a` 且已单独占用的客户不会严格移动；其他客户不会加入这些重客户所在设施，因为目标条件成本超过 `2a`。若客户从 `h` 移到 `g` 严格改善，则

\[
 L_g+w_i<L_h\le2a,
\]

所以源、目标两负载仍受 `2a` 帽约束。势函数

\[
 \Psi=\tfrac12\sum_v L_v^2,
 \qquad \Psi'-\Psi=w_i(L_g+w_i-L_h)<0
\]

在有限纯赋值空间上严格下降，终止于纯精确客户 NE。结合 `q_u≥2` 与 `q_u=1` 两种转移构造，移动设施 `f` 的终局负载满足 `L_f(p')≤2a=2L_f(p)`。对所有真实单设施偏离选择这些纯续局；其他布局用固定默认改善规则从任意可行纯赋值开始，得到完整续局。`R=0` 时所有负载都为零，结论直接成立。

## 证书命题的精确结论

在正二进制有理权重、显式客户—地点关联和显式 `k` 个设施的编码下，命题保证存在一个**有限精确过程**输出：

1. 主稿定理中的选址 `s`；
2. 主路径客户均匀混合；
3. 该路径的 `k(|S|-1)` 个实际单设施偏离的纯客户 NE；
4. 覆盖全部其他布局的确定性默认规则程序。

路径混合概率只属于 `0` 或 `1/q`（`1≤q≤k`）；偏离续局为纯策略。每个纯配置至多存储每个客户一个设施标签；实际偏离的数量是 `k(|S|-1)`，在**显式列出设施**的输入长度下为多项式数量。每个负载是输入权重之和，或再除以一个不超过 `k` 的整数。把所有输入分母相乘，再乘一个至多 `k` 的整数即可给出单个负载的分母上界；精确比较的位长相对输入增加至多 `O(log k)`。

命题中“可检查”只涵盖已存储的主路径/实际偏离档案以及这些偏离的设施不等式；默认规则的正确性由势函数证明，程序不会展开指数多个布局来逐一验证。`main.tex` 的结尾明确写出：枚举所有布局和可行客户赋值、保留固定顺序的第一个 lexicographic maximum、执行有限 packing/改善过程，都没有给出关于输入位长的多项式运行时间界。故该对象是“多项式大小证书 + 有限穷举生成 + 默认规则的符号正确性”，不能写成 polynomial-time construction 或 efficient search。

## 审查比较与修订后的边界

round-1 报告曾指出两项容易误读的范围：

- “their client optimality”若被理解为涵盖指数多个默认布局，会超出已存储档案的可检查范围；修订后明确只指主路径和实际偏离的显式档案；
- 需把 heavy singleton 与普通设施的 `2a` 帽条件写清，以免把一个超过 `2a` 的客户与其他轻客户错误地放在同一设施。

round-2 独立重导了 `main.tex:31–221` 的量词、覆盖消失、孤立重客户、势下降、同时选择和有理证书，确认：

- `prop:certificate` 只声明有限穷举与多项式大小描述，不声明多项式搜索；
- lexicographic maximum 的并列通过固定总序解决；
- 默认规则是“最小索引可达设施 + 最小索引严格改善客户/最小化成本设施”，势函数保证每个布局终止；
- 负载分母额外因子至多 `k`，位长度仍为多项式；
- zero reach、空列表、重 singleton、平局、源地点消失和新覆盖客户均有局部处理。

`prop-certificate.md` 的 Pass A/Pass B 与这次对主稿逐段重读一致；未发现 S0–S3 正确性阻塞。剩余事项是出版模板和作者元数据，不影响当前数学命题的条件范围。

## 与现有对象的关系、用途和缺口

本对象为[共同目录任意设施数命题登记与证据分层](../任意设施数命题登记与证据分层--审查.md)补充一个聚焦证书命题的独立审查入口，保留该登记页关于“存在完整续局”与“运行时间责任”分离的边界。它还可被[共同目录任意设施数因子二存在](../定理/共同目录任意设施数因子二存在--定理.md)引用，说明该定理在有理显式输入上有短描述和有限生成过程，但不改变一般输入的算法复杂度状态。

当前未由这些来源得到以下更强结论：对一般实权重的有效编码、对隐式或二进制压缩的 `k`、对默认规则的多项式时间验证/搜索、或共同目录二设施黄金比与任意 `k` 因子二之间的最优统一常数。主稿的 theorem 是共同地点集下的存在性与因子二，证书命题只对其编码后果作条件说明。
