# 因子二的后续仓库审查、计数纠正与研究定位

## 所审命题与结论层次

本对象整理原审查 research/reviews/facility/arbitrary_facility_factor_two.md，日期 2026-10-02，审查对象为 SC-K-2-E 与原交付的逆向重构。它属于内部数学审查与条件性研究价值判断，没有外部同行评议或文献优先权认证。

[完整存在定理](../定理/共同目录任意设施数因子二存在--定理.md)的准确内容是：对所有有限共同目录、正实权原子客户、任意显式整数 \(k\ge2\)，在强制服务、独立混合精确客户 NE、实际负载含自身重量的模型中，存在带标签纯布局和一份完整精确客户续局，使所有单方换址收益至多为原收益的两倍。在轨可站内独立均匀混合，所有离轨可为纯 NE。有理显式输入给有限精确穷举构造，不给一般位多项式搜索。

原审查记载，与交付作者不同的内部审查路线检查了客户转站的字典序方向、源地点只余一家时的 \(J\cap C_t\) 预算、超重原子隔离、严格改善保帽及带标签续局兼容，未找到成立的致命反例。本轮重新读主证明和这些步骤，仍以实际论证作为结论依据；不会把“另一内部路线同意”当成证明替代物。详细逆向义务见[逆向审查对象](因子二逆向审查与证据边界--审查.md)。

## 历史独立枚举：1319 的单位须更正

原审查写作“独立穷举核查了 1319 个小实例的并列最优见证和 10162 次实际偏离”，并指向 tests/audits/kfac_independent.py 及 evidence/runs/kfac_independent.json。本轮已全文实读该程序和 JSON；其中确有 1319、10162、最大比值 \(28/15\)，但“1319 个实例”的解释不符合代码。

程序按四个 \((m,k,n)\) 组合

\[
(2,2,3),\ (3,3,4),\ (3,4,4),\ (4,4,5)
\]

分别生成 175 次随机输入，种子为 2123，客户整数权从 \(\{1,2,3,5,8,13,21\}\) 取值，各站点按随机过程进入客户菜单。至多有 700 次基础生成；全空菜单输入被跳过，程序也没有把重复随机输入去重。

对每个保留输入，程序的 lex_witnesses 确实枚举全部标签布局和客户站点分配，找到全部字典序并列最优见证；随后却只对**至多前三个**并列见证进行偏离检查。计数 cases 的自增就在这个见证循环内。因此：

| 冻结字段 | 实际含义 |
| --- | --- |
| cases = 1319 | 被检查的“输入＋选中在轨最优见证”对数，不是 1319 个不同输入 |
| deviations = 10162 | 这些选中见证上的实际单设施偏离检查总数 |
| max_pure_ratio = 28/15 | 所检偏离中，全部纯 NE 的偏离者最小收益除以其在轨收益的最大值 |
| singleton_deviations = 1478 | 源地点重数为一的所检偏离次数 |
| macro_opportunities = 4156 | 每次所检偏离累加重量大于该次 \(2a\) 的客户数；不等于实际构造并隔离了这么多重客户 |

min_pure_ne_deviator 对每个实际偏离直接穷举全部可行纯客户赋值，按“源负载不大于目标背景负载加自身重量”检验每个客户无严格改善，并取偏离者最小收益。整个程序只导入标准库，没有调用交付构造器。它有限验证存在某个低收益纯 NE；并未枚举全部混合 NE，也未保证对每个基础输入的所有并列在轨见证都检查。

这项源码追踪纠正的是统计单位，不改变一般因子二证明；相同更正已回填先前本档逆向审查中的继承表述。它也与 seed 20261003 的 612 输入、1728 个**全部**并列候选逆向审计不同，不能把两者混称或相加。该独立程序与小 JSON 本轮作为比较源实读，未因本对象整理而自动给它们申报来源完成。

## 文献背景的本轮定向核对

为核实本源的具体文献比较，本轮打开了 [IJCAI 2024 官方文章页](https://ijcai.org/proceedings/2024/315)及 [arXiv:2403.03114v2 原文](https://arxiv.org/html/2403.03114v2)，核读模型、加权章节和结论的对应陈述：原文允许设施依赖地点目录，Observation 4 给 \(k\) 倍存在界，Theorem 5 给黄金比例以下的下界，结论保留加权 \(\varphi\) 猜想；其 PoA=2 是福利比。这里的共同目录稳定因子二与福利比不是同一结论。

这项核对只验证指定历史文献的上述位置，没有进行截至今日的穷尽优先权检索，也不把原文当时的开放问题无条件标成整个领域今天仍开放。对本仓所交付成果，最佳常数和一般高效构造仍按其已证明范围保留未解；2025 学位论文 Two-Sided Facility Location Games（DOI 10.25932/publishup-69272）在原审查中未完成全文核查，本轮也未取得全文。

## 从规模依赖到共同目录常数的意义

原审查对研究价值的判断可准确分成三层：

**严格数学层。** 在本模型允许选择完整客户续局的条件下，共同目录类有与设施数无关的绝对稳定倍率 2，排除了该类最优所需倍率必须随竞争者数量无界增长的可能。不同目录未由此覆盖，最优常数仍未定。

**可复用证明机制层。** 全局排序极值给逐偏离重量预算；装箱允许隔离超重原子；纯严格改善在完整客户游戏中保持普通负载上限；标签使各偏离子博弈的选择可以拼接。它们共同支持定理，不是简单将双设施结论把参数改成多个设施。能否迁移成其他模型的通用定理，尚需分别证明。

**条件性发表判断层。** 原审查认为，若后续优先权调查及外部证明审查通过，本结果有潜力作为算法博弈论独立论文的核心。该判断不是录用承诺、外审结果或新颖性认证，也不支持跨数学领域重大突破的说法。保留的是原审查的条件性评价及其理由，不把主观评估升格成数学定理。

向非专业读者说明时，应说：在这些抽象条件下，可以选出一种设施布局和对所有布局都有效的理性客户分流规则，使任何单家搬迁所获客户总权重至多翻倍。必须保留“可以选择一套规则”的存在量词；原文非专业转述中“顾客重新作出理性选择”不能读成任意 NE 选择都保证两倍。

商店、医院、接入点可帮助解释参与者，却不是定理已解决相应工程问题的证据。模型未包含信号干扰、距离衰减、容量或动态需求；“两倍”指单设施搬迁收益倍率，不是等待时间、覆盖效率或福利保证。

## 下界、障碍与未解范围

当前已整理的范围是统一全 \(k\) 常数满足 \(\varphi\le C_{\mathrm{unif}}\le2\)：左端来自总体包含双设施，不代表每个固定 \(k>2\) 都已得到相同下界。并未证明 2 尖锐、全 \(k\) 的 \(\varphi\) 上界，或一般二进制有理输入的位多项式构造；短证书与有限搜索不等于高效搜索。

[固定字典序占用障碍](../障碍/固定字典序占用的二倍极限--障碍.md)排除只改同一选定布局的续局来统一突破二；[同址对称菜单障碍](../障碍/同址对称续局的无界假威胁--障碍.md)排除额外强制同址对称的离轨选择。这两族在完整模型都有精确 SPE，不能成为整体模型因子二下界或无界下界。

本对象完整处置原后续审查的严格结论、历史检查、研究定位、通俗解释与未解边界，并以实际代码纠正了一处统计解释。关系已判断为“主定理的内部审查及历史交付记录”“特定文献背景比较”“选择规则障碍的范围澄清”；不把工程类比、发表判断或历史测试计数作推导前提。正式超图待第三阶段建立。
