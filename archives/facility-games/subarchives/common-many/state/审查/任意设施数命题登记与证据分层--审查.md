## 共同合同与可以复用的证明链

有限客户各有正实权u_i，地点S有限非空，k≥2家带标签设施均可选S，同址合法。覆盖时必须选一家可达设施、客户独立随机化；客户i选f条件成本是u_i+Σ_(j≠i)u_jp_jf，设施收益是Σ_i u_ip_if。两者不同。完整续局σ在**每个标签布局**给精确客户NE，所求量词为

\[
\forall I,k\ \exists s,\sigma\ \forall f,r\ne s_f:
L_f(\sigma(s[f\leftarrow r]))\le2L_f(\sigma(s)).
\]

这允许选择离轨NE，不是任意NE都成立；离轨布局只要求客户最优，不要求设施在那里也稳定。零收益用不等式而非除零；零最大reach取空服务完整续局。存在性可用正实权；算法另需显式客户/关联、二进制有理权和显式k标签，关于k多项式不等于关于log k多项式。

站点t有q_t家、客户池J_t总重W_t。站纯/站内独立均匀的真实NE恰为
\[
(W_t-u_i)/q_t\le W_v/q_v\quad(i\in J_t,\ v\ne t\text{为原已占选项}).
\]
全部原选项都要检查，包括移动后可能出盒者。对全布局/全部合法站点赋值的升序设施收益lexmax，严格客户改善以及任一违反转移预算的设施重定位都会严格改善向量。因此它给精确NE和四预算。源u收益a=W_u/q_u，N_r为旧布局完全未覆盖而r新覆盖的重量：

| 源 | 其他已占t | 未开r |
| --- | --- | --- |
| q_u≥2 | W_t≤(q_t+1)a | N_r≤a |
| q_u=1 | W_t+w(J_u∩C_t)≤(q_t+1)a | N_r+w(J_u∩C_r)≤a |

孤儿项不得删除。预算把每存续站的客户装到h个静止设施：总重≤(h+1)a，用合重≤2a的箱对反复合并，终箱≤h；超2a者只容许一个真实原子独占。纯严格改善使半平方负载和变化u_i(L_g+u_i−L_f)<0，保持所有普通设施≤2a、孤立重客户不动，有限到原游戏NE。不同实际(f,r)改不同标签坐标，续局选择不冲突，其余布局用固定纯NE默认规则。此链不调用双设施黄金比定理；共同目录k2下界只把**统一所有k**的最优常数夹在φ与2，不自动给每固定k>2同下界。

规范贪心是另一条完整构造：已开站原池冻结，下一家得分W_t⁰/(q_t+1)，未开站按新增覆盖，最高分插入。末γ>0给q_tγ≤W_t⁰≤(q_t+1)γ、N_r≤γ和原home最大可达重数。冻单选项及u_i≥γ，归一化w_i=u_i/γ、c_t=W_t⁰/γ−q_t；X_t=c_t+Σ_(a_i=t)w_i−Σ_(h_i=t)w_i。截断价格排序与阈值组负离家计数的交错势给全盒0≤X≤1、原NE及H:(X_ai−w_i)/q_ai≤(1−w_i)/q_hi，微步≤∏|A_i|−1。H用来证明该构造推进，BOX-TO-2本身不要求H。源存续按当前盒装箱；单源消失回**原**池重置，以singleton原池并P满足w(P∩C_t)≤2γ保帽。该有限全类存在性不能由“原贪心初态已在盒”单独推出，也不由有限样本推出。

## 多项式时间、规范软件与审查的不同层级

MAX是从任意可行纯赋值位多项式到原受限相同机器NE且最大负载不增；RANGE还要求最小负载不降。纯严格改善本身同时保持全局最小/最大并有限终止，却没有一般位多项式步数，不能充作导入算法的实现。原账本声称已完成Gairing等STOC2004导入；现行[专门审查](受限同链调度导入的最大值与范围义务--审查.md)对未直接核得的强RANGE层保留合同。本文沿用这个明确边界，不重复认证原论文全文。

| 用途 | 所需调度合同 |
| --- | --- |
| 基本受帽离轨、单源重置、BOX-TO-2、AR、冻结超载基本η版、默认查询 | MAX；有限正确性可不用该时间导入 |
| 等q/分量/范围/轻分量在轨、含等q分支的列表星路径、双LPT及自适应AD首轮 | RANGE以保在轨收益或原区间，之后离轨MAX |
| 冻结超载另用残余分量种子最小值μ_C | 强化的时间界需RANGE，基本η版无需 |
| 两个直接DP及等重流在轨 | 不调用RANGE；接完整位多项式续局仍需MAX |

重数q不是相关机器速度的直接代换：原NE扣u_i/q_source，相关机器扣u_i/q_target；q=(1,2),u=2,W=(5,6)时原条件3=3而相关条件5>4。合法离轨纯赋值则每一家标签设施各作一台**相同**机器，条件没有错位。正确共单例取补归约是另一个反向仿射负载接口，不修复这个错误直接等同。

规范lexmax/greedy-box/equal-light-flow完整程序保存k(|S|−1)个实际偏离纯例外和默认规则，不打印指数多布局表。当前离轨及默认仍用有限纯改善；只有等轻权在轨流有已实现位多项式选择。等流拒不等移动权。现行DP未有canonical实现，数学DP输出未承诺H，而程序verify_on_path还额外检H，不能直接声称即插即用。原greedy报告str(∏|A_i|−1)在Python默认4300位十进制限制有已定位合法零步输入异常；另存适配只修该报告字段，下游int及其他巨大Fraction文本仍有边界，见[程序合同](../计算/规范贪心完整续局程序与选择器接口--计算.md)。因此“有限算法已实现”也不能升级成“原字节在所有合法编码上总能返回”。

## 五处必须保持的后续判断

1. **存在性旧OPEN已超越。** 三站链/高度二页仍有“更长路径/一般盒存在开放”的历史句，一般截断交错势已给任意合法canonical greedy完整盒NE。保留浅层更强的“每个约束势极小者都NE”、其独立整池证明及短算法；结构新ID去深度条件是一般存在+旧DP+BOX-TO-2联合，并非偷偷扩旧高度二ID。
2. **旧普通势和lexmax反例仍成立。** 深度三盒势、盒内未截断lexmax、下盒异权势溢出、固定布局势偏选坏NE是不同选择器；后续证明用截断势/归家，不反驳这些反例。不能只检查盒内可行偏离，或把单一坏NE升级成整占位没有好NE。
3. **等重旧新同域、同最优赋值集。** 归一化旧目标F/γ=N+Ψ。新无约束每个全局最优者皆满足下盒，故新最优在旧可行域，旧约束最优值与新相同且全体最优赋值集一致；新贡献是去冗余下界、每个极小者自动H及规范实现。任意等权客户NE不一定在盒，两个异轻权也不能照搬单位返路。
4. **晚开星保结论、修中间论证。** 移入中心后C_new=C_old+w<U，不能写C_new<C_old+w。同叶后续移动会降旧客户返回阈值V_j，故“永不低于其入场旧key”过强；实际V_j(new)=U+(w_j−w)≥U>C_new、以当前最近处理key归纳即足。外向星旧有限审计不作为这段内向星已运行证据。
5. **抽象与真实、证书与求解分开。** 普遍存在仅由真实贪心前向归一化进入抽象域；不反推每抽象输入真实可实现。共单例编译按显式设施k收费，二进制大q不免费；带区间版本求的是区间内NE，任意无区间NE不够。冻结超载/原池证书给成功时的完成器，未给所有输入成功证书生成，也救不了每个强迫偏离>2的坏在轨NE。
