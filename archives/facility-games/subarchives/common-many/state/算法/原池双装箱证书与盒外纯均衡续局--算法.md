# 原池双装箱证书与盒外纯均衡续局

## 可核验的证书合同

[共同目录模型](../定义/共同目录任意设施数模型--定义.md)取显式正有理权、显式k和标签设施。正覆盖规范贪心得原池J_t^0、q_t、末γ>0。在轨策略可为**任意显式有理、独立混合的精确客户NE**，只需逐家收益a_f≥γ，不要求站点纯或完整上盒。另对每q_u≥2的原池，给划分成q_u−1个删除箱：每箱重≤2γ，或恰一个权>2γ的孤立原子。标签、覆盖、概率、NE、收益和箱是否覆盖原池各人恰一次均可多项式检查。这是成功证书，未给所有输入必成功保证。

源u有q_u≥2时，丢弃在轨客户分配，把全部原客户重置回原贪心站。源静止家用其删除箱；其余站t仍有q_t个静止家，原池总重≤(q_t+1)γ，经[装箱引理](../引理/原子装箱与受帽纯均衡修复--引理.md)得每箱≤2γ或孤立巨原子。偏离目标原已占则移动者初空，原未占则仅获新增覆盖N_r≤γ。普通家全≤2γ、移动者普通，MAX受帽纯NE补全保其收益≤2γ≤2a_f。q_u=1调用[单设施原池重置](../定理/规范贪心占位的完整盒均衡与因子二续局--定理.md)，同样不使用新在轨分配。全k(|S|−1)例外互不冲突，默认纯NE补全其余布局。有限正确性自足，位多项式需[MAX合同](../审查/受限同链调度导入的最大值与范围义务--审查.md)。

这是[自适应AR](强制负载下界的自适应原池重置--算法.md)取所有ρ_u=γ的特例；AR可改用γ≤ρ_u≤源所有家最小收益，不可把这里的静态γ测试与强制池η下界混为同一条件。

## 双LPT充分测试

对每原池按非增权、输入编号破平局，逐个放当前最轻的q_t个箱（箱号破平局）。若每箱≥γ，则由总重≤(q_t+1)γ自动每箱≤2γ。独立再对同一原池从头装q_t−1箱，要求每箱≤2γ；这是比接口中允许巨原子的删除证书更强的测试。失败返回unknown，不等于没有可行划分。

全通过后，以首轮纯设施分配为初态，在**每个真实设施一台相同机器**的全覆盖游戏运行RANGE，得到纯NE并保持最小收益≥γ；此处不把站点q当机器速度，也不保证站点总重保盒。然后用上段重置接口。LPT排序、两轮显式装箱、核验均位多项式；求在轨纯NE需要RANGE而非仅MAX。
