# 四站汇聚轻路径的四步盒均衡

## 原模型与全部输入条件

在[共同目录正权原子模型](../定义/共同目录任意设施数模型--定义.md)的正覆盖显式输入上作规范贪心，末分数γ>0。冻结只有一个已占选项的客户及权≥γ的客户于其原站。轻客户分量恰为四站路径D—B—A—C，且**每边恰一名**可动客户：T权t、选项D/B、原在D；X权x、选项B/A、原在B；Z权z、选项C/A、原在C。0<t,x,z<γ。开站定向为D→B→A←C，重数记q_D=Q≥q_B=p≥q_A=r≥1，q_C=R≥r。没有要求R=r，也没有要求A初始下盒等号。

冻结背景总重为A的P_A、B的K、C的c、D的d；它们分别由原子构成，不合并为可动客户。初始总重为(P_A,K+x,c+z,d+t)，均满足q_sγ≤W_s≤(q_s+1)γ。冻结客户可跨分量有其他选项；其最终稳定性由全站完整盒给出。

**算法至多四次真实严格站点移动得到本站分量的完整盒精确客户NE。** 不同轻分量独立处理，联合其他具相应合同的分量构造器，可得整体盒NE。盒到[完整因子二续局](../定理/规范贪心占位的完整盒均衡与因子二续局--定理.md)仍需原池重置和受帽完成；此处的多项式结论使用该定理明示的多项式数学完成接口，不称当前有限greedy程序已实现全部接口。

## 五次检查、四种可能移动

客户w从s严格改去u的真实判断是(W_s−w)/q_s>W_u/q_u；成本不把原子拆开，比较两边加回相同自身重量才为条件成本。

1. 若c/R>P_A/r，移Z:C→A；否则留C。记此后A负载价A₀=(P_A+z)/r或P_A/r。
2. 若d/Q>(K+x)/p，移T:D→B。
3. 检X:B→A：T已在B时条件为(K+t)/p>A₀，否则为K/p>A₀；满足则移X。
4. T仍在D时再检一次D→B，满足即移。
5. Z在A时检A→C，严格改善即返回。

T只进入B一次，X只进入A一次，Z最多进入A再回C。第二次T检查允许X离开B后才激活T；最后T和Z检查改变的站点分别是B/D和A/C，彼此不干扰。

## 每一步保持完整盒

任何严格移动使源离开后的标准负载仍大于目标旧价≥γ，故保持源下盒；源上盒和目标下盒自动保持。如果源重数≥目标重数，目标溢出会推出
\[
W_u/q_u>\gamma+(\gamma-w)/q_u
\ge\gamma+(\gamma-w)/q_s\ge(W_s-w)/q_s,
\]
矛盾。因此Z首次进入A、T进入B、X进入A都保上盒。唯一可能逆重数的Z返回C，恰恢复其原总重c+z，不超过C原上盒；A下盒仍由返回严格性保证。无需全局优化或把溢出的原偏离删除。

## 三名客户的永久稳定

第一步后Z稳定：若进入A，其A外部价为P_A/r<c/R；若留C，c/R≤P_A/r。T若先进入B，之后B外部价至多(K+x)/p<d/Q，因为X只能离开；若等X离开才进入，则外部价K/p<d/Q。T不动时最后检查认证d/Q≤W_B/p。

X若进入A，其未来A外部价至多A₀，因为Z最多离开。T已进入B时，X离开后B价(K+t)/p>A₀；T尚未进时B价K/p>A₀且之后只可能增加。故X永不想回B。X若留B，T第一次检查已完成；T不可能在X未离开的情况下新激活，Z也不会因A未变化而新返回，因此第三步失败的严格测试即是最终稳定性。

Z若最初留C，A只可能增加，故始终稳定。Z若进入A，末次检查失败即稳定；返回时c/R严格小于A最终价(P_A+x)/r，此后A/C不再变化。全部冻结重客户在完整盒内满足(W_s−w_i)/q_s≤γ≤W_u/q_u，单选项客户自动稳定。每人选定站点后在本站独立均匀混合，就得到原游戏精确NE。

每分量只有三名移动客户、五次严格比较，所有理数和/交叉乘法有输入多项式位长；分量识别及规范贪心也多项式。这不是对所有汇聚图、每边多客户或一般盒优化的时间界。

## 四步上界确实达到

原JSON有五站A/B/C/D/R、k=9，私有原子分别105/200/214/340/100；X=(20,AB)、Z=(5,AC)、T=(50,BD)。每次贪心均是严格唯一最大者：
\[
D:390,\ B:220,\ C:219,\ D:195,\ D:130,\ B:110,
\ C:219/2,\ A:105,\ R:100.
\]
因此q=(1,2,2,3,1)、γ=100，A并非紧下盒且q_A≠q_C。四个严格移动的源外部价/目标价为：

| 移动 | 源外部价 | 目标价 |
| --- | ---: | ---: |
| Z:C→A | 107 | 105 |
| T:D→B | 340/3 | 110 |
| X:B→A | 125 | 110 |
| Z:A→C | 125 | 107 |

终总重(125,250,219,340,100)，全部原客户均稳定。轻图非星、无共同锚、三不同轻权、汇聚定向及不同重数，不能由固定等权、恒重数或一致有向路径的标签代替本算法。原报告的RANGE失败还按同重数站群的最小/最大价作保守比较，与此表具体客户旧/新价不同，见[审计](../计算/浅层归属几何与盒选择器的精确核验--计算.md)。

## 保留旧七步论证的独立内容

较早三轻客户稿额外要求q_C=q_A=r且P_A=rγ。它先按c/r>γ处理Z；随后优先移T，若T不改善但X改善则移X并固定于A，否则已稳定。

T先动时令M=K+x。d/Q>M/p和d+t≤(Q+1)γ给
\[
M+t<(p/Q)d+t\le p(Q+1)\gamma/Q+(1-p/Q)t
\le(p+1)\gamma.
\]
所以B无论X/T之后取哪一端都不溢出；D和C返回至多恢复原总重，Z两端重数相同，前向改善又保盒。此后可任选三名客户的任意严格改善，始终在盒内。

若T不动而X先进入A，X外部价始终≤A₀，而B价≥K/p>A₀，故可合法固定X；Z若原留C，也因c/r≤γ而可固定。剩余Z/T的任意严格移动同样保盒。固定者始终真实最佳反应，并非删掉其原动作后忽略偏离。

这段用原客户势
\[
P=\sum_s(W_s^2-\sum_{i:a_i=s}w_i^2)/(2q_s)
\]
逐严格移动下降。三名二选项客户仅八分配，整条路径无重访，合计≤七步。它是原受限域的独立有限状态证明；四步新算法扩大输入域并改选择顺序，而非只把同一随机测试数字写大。旧域实际10000例检查全部允许严格后缀，10969个后缀状态、单例最大4；该数字不等于整条路径的普遍七步定理。

七原审计中分别真实执行旧/新两程序，各一次。新程序20000例、3172重数四元组，含19357个A不紧和18001个A/C重数不同的输入，11例实际走四步，另有上述真实贪心四步例。有限样本不是通用证明；通用证明由前述逐客户稳定与盒不变量承担。旧稿“未证明一般存在性”的历史句已被后续一般交错势工作超越；一般位多项式选择仍未由本子类结果解决。
