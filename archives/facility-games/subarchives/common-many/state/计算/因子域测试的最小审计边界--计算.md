# 因子域测试的最小审计边界

## 固定证书与检查对象

来源 `tests/multi_facility/test_factor_domain.py` 先构造一个小型有效证书：`m=2` 个地点、`k=2` 个设施、三名正权客户，覆盖分别为 `{0}`、`{0,1}`、`{1}`；在轨布局为 `[0,1]`，客户纯分配为 `[[1,0],[1,0],[0,1]]`，两项真实单设施偏离分别移到另一地点。默认规则字符串是 `least-index initial pure assignment, then strict pure best responses`。

测试没有写自己的 NE 判据，而调用 `tests.multi_facility.definition_check.check_certificate(cert, all_layouts=True)`。该检查器会独立重算在轨和两个偏离的客户条件成本、概率可行性、设施负载和因子不等式，并穷举唯一未列带标签布局的纯 NE 存在性。源中 `deepcopy` 只替换 `factor` 字段，因此测试隔离的是因子域检查，不是重新生成证书。

## 两个回归断言

`test_valid_equilibria_do_not_excuse_subunit_factor` 依次把 `factor` 改为 `-1`、`0`、`3/5`、`999/1000`。虽然证书策略本身仍是有效 NE，但检查器必须抛出包含 `at least 1` 的 `AssertionError`。这验证近似因子的定义域是 `alpha≥1`，不能以“给定策略实际收益比为1”来接受小于1的声明。

`test_boundary_and_larger_factors_remain_valid` 用 `factor=1` 与 `factor=2` 重跑完整检查，并断言返回：

```text
actual_certificate_factor == "1"
actual_deviations_checked == 2
unlisted_labeled_layouts_checked == 1
```

因此该样例的实际证书倍率恰为1；声明2只是较松的合法上界。测试没有证明该实例的全局最优值、所有客户 NE 的最小威胁，也没有证明任意共同目录输入存在因子二续局。

## 与既有对象的关系和边界

本对象补充[因子二构造、布局障碍与交付检查的三种验证职责](../计算/因子二构造审计与交付检查的验证边界--计算.md)及[四份保存证书的显式续局](../计算/四份保存证书的显式续局与默认补全--计算.md)中关于 `check_certificate` 的输入域说明。前述对象已记录 `alpha≥1` 断言和独立成本检查；本源的独有内容是把该边界压缩成一个最小固定证书回归，并明确区分“有效 NE”与“合法近似因子声明”。

该源只提供有限单例测试，不承担普遍数学证明或复杂度结论。后续运行应保留其四个拒绝值与两个接受值，记录测试退出状态和检查器版本；不能把测试通过次数升级为全模型定理。来源处置为 `integrated` 到本计算对象，因子域判断和有限布局计数可供第三阶段作为实现证据边。
