# 仅向低重数修复的强制上返陷阱

## 量词

否定规则：“规范贪心原赋值出发，仅让客户严格改去最终重数不高于当前站的可达站，任意极大下降序列都会成为全原选项NE。”下例下降序列每步唯一，故任何该规则的顺序选择均无法绕过陷阱。它不否定盒NE存在、一般因子二或某个允许上返的算法。

## 六客户真实输入

k6，站序H,M,L，客户(64,H),(9,HM),(37,M),(5,ML),(2,ML),(20,L)。记多选客户Y9、Z5、T2。严格贪心H73,M44,H73/2,H73/3,M22,L20，无平局，q321、γ20、原总重(73,44,20)。站点纯/站内独立均匀客户从s改t严格改善当且仅当(W_s−w)/q_s>W_t/q_t，不能省去自重。

| 当前总重H,M,L | 唯一下降改善 | 外部成本比较 |
| --- | --- | --- |
| 73,44,20 | T:M→L | (44−2)/2=21>20 |
| 73,42,22 | Y:H→M | 64/3>42/2=21 |
| 64,51,22 | Z:M→L | (51−5)/2=23>22 |
| 64,46,27 | 无 | 仅下降边全稳定 |

初始Y的64/3<22、Z的39/2<20；第二行Z的37/2<22；第三行剩余下降选择均不改善。三步后所有盒仍成立，但T在L的外部成本27−2=25>46/2=23，严格想**上返**M。返后(64,48,25)是全客户NE：Y外部39/2≤64/3，Z外部20≤24，T外部23≤25；私有者无跨站选项，站内均匀自动。这个特定上返仍保盒，不构成任意上返保盒证明。

原稿还记较弱五客户星形(40,H),(8,HA),(4,HB),(21,A),(19,B)、k4。它的贪心H52,H26,A21,B19，q211、γ19。固定非增权一趟先8:H→A（44/2=22>21），后4:H→B（40/2=20>19），终H40,A29,B23；先移的8在A外部21>H20，故要上返。这是由原例补写的直接算术推导，未新运行程序；它不具有六客户例的所有下降顺序强制同一终点量词。

## 真实核验与用途

[原脚本](../../tools/evidence/facility-selector-frontier/original/tests/audits/kfac_descent_trap.py)从[六客户JSON](../../tools/evidence/facility-selector-frontier/original/examples/multi_facility/greedy_descent_trap.json)加载精确Fraction，核严格分数、每步唯一下降边、各步盒、唯一上返及最终全部原NE。一次真实运行PASS、stderr空；没有把无限模型定理交给有限测试。它说明“原归属最大重数”不能推出最终各客户永不向高q移动，支持一般改善—归位算法必须保留全部允许偏离。
