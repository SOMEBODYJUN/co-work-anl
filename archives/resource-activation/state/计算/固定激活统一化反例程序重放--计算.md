# 程序和算法范围

源程序为 1560 字节 Python 标准库脚本，使用 Fraction、itertools.product 和 json/pathlib，无随机种子、浮点判定或外部求解器。它固定
\[
x=(3/5,13/50,17/100,17/50,23/50),
\quad a=7/10,\quad b=2/5,
\]
检查 \(a\sum_{j<2}x_j+b\sum_{j\ge2}x_j\le1\) 且 \(a+b>1\)。

ratio(w) 的分母是 \(\sum_i x_iw_i\)。分子枚举全部 \(2^5=32\) 激活集；每个激活集的可行背包值取两者最大值：大尺寸激活物品中最大的权重，和小尺寸激活物品中最大的两项权重之和。随后程序枚举统一类正权 \(u\)（大类）与 \(v\)（小类）的离散值 \((1,0),(0,1),(1,1),(2,1)\)，并用 mask 允许任意零权 sub-support。程序断言一般权向量的 ratio 严格小于统一类候选的最小 ratio。

这是一个精确的有限搜索合同：它只穷举当前固定 \(x\)、五个物品、两种尺寸和给定有限统一权候选集合。连续权比 \(r\) 的全端点覆盖来自既有 C08 正文对象，不是此脚本自行证明的；不能把脚本的离散 \((u,v)\) 枚举误读成全实权统一化定理。

## 关系和限制

该程序是[固定激活统一化反例精确复核](固定激活统一化反例精确复核--计算.md)的可复现实现层；两对象共同承接 C08 fixed-\(x\) 路线障碍。它不构造全局 CRS，不优化激活向量 \(x\)，不证明连续权重端点覆盖，也不涉及 BMKP、weighted-congestion 或 CAG/SPE。

后续如要推进 C08，只能改变 \(x\)、改用全局 symmetrization/新不变量，或在特定自然物品类证明新的全称界。把此脚本成功运行描述成“固定激活统一化已完全分类”会超出实际量词。
