# 使用方式
1. 下载并将本精简ZIP上传给GPT Pro（如无法直接读取ZIP，可解压后上传00–05；06为溯源索引）。
2. 复制`00_MASTER_PROMPT.md`全文作为任务消息，要求直接执行。
3. 原始大ZIP自己保留，仅有明确证据争议需要时再提供对应文件，不让Pro重新清洗。
4. 最终目标仅为报告与离线HTML计算器。本包不包含已经完成的宏观预测或家庭计算器，不需要把未提供的家庭金额提前填写给聊天模型。

文件说明：
00_MASTER_PROMPT.md：主提示词
01_evidence_brief.md：已处理资料简报、口径错误与优先缺口
02_macro_evidence.csv：47条宏观/市场证据（含来源及状态）
03_method_playbook.md：具体GitHub模块与方法、输入输出及验收
04_prior_research.md：历次相关研究与本轮新增资料，区分核验状态
05_market_snapshot.json：本轮逐行复算的市场截面
06_file_audit.csv：原1214文件索引、SHA256、重复关系及初筛用途，不含文件原文

局限：文件级扫描和关键内容核对不等于逐条审计所有旧报告/新闻；尚未核实全部原始官方表，未跑GitHub预测代码，也未构建正式计算器。所有未验证材料已标记或列为后续补证，不将其作为已证明结论。
