先读适用的 [AGENTS](AGENTS.md)、[模型](research/current/customer_attraction/model.md)和[研究接续材料](research/customer_attraction/SYNTHESIS.md)。根四入口仅作路标，无需递归打开其中全部链接。接续材料固定原目标、可直接使用的关系、已失败的加强及尚缺的一步；随后按所研究的数学机制取一份正文及其实际审查。长总账、全部个人区和公屏不作为默认输入。

## 数学对象与目标

有限单位客户集 N，有限非空共同目录 S⊆2^N，m≥1 名单位权提供者依次观察全部有序历史，各选一个主题。终局客户 x 被 cₓ 名提供者覆盖时，每位覆盖者获 1/cₓ；uᵢ 为收益，W=Σuᵢ 是覆盖客户数，OPTₘ 是 m 个目录主题的最大并集大小。对每个完整历史依赖纯 SPE σ，欲证 **2W(σ)≥OPTₘ**。重复、空主题、零客户和任意离轨平局均属于原量词。

模型 → 全历史真实偏离比较 → 已证通用关系 → **尚缺一般福利控制**。静态安全值、根修复、查询菜单是可选路线；原目标不依赖其中某条候选为真。改模型、量词或范围必须另立 Claim。
