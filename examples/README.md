# Inputs, not proof records

[shared/tiny.json](shared/tiny.json) is a small common-catalog smoke input. The [heterogeneous](heterogeneous) inputs contain a strict factor-2 lower family, its undirected form, the restricted rho lower input and an alternating-cycle example.

Each input should be paired with its theorem's exact model conditions in [ASSETS.md](../ASSETS.md). Generated outputs and historical certificates are under [evidence/certificates](../evidence/certificates); an example alone proves no theorem.
