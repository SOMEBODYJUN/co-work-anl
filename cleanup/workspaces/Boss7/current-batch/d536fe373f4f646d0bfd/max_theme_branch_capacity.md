# 最大主题真实分支的总覆盖容量与三人首位缺口端点

状态：2026-10-21，作者解析推导，待独立攻击。只使用CAG-MODEL；一般Q-CAG-HALF仍OPEN。
此处不主张新颖性。已知的逐对最大主题饱和界与末两人保底可从共享正文及
`R-7e9f44beea424d469713364afe7dd180/independent_mechanism/max_topic_saturation.md`接续。

## 1. 纯终局总覆盖容量

任意m≥2名单位玩家终局，某玩家选择一个目录最大主题A，|A|=M；其终局收益为z，
总覆盖为W'。令其余玩家主题为B_j，客户最终负载为c_x。因为每个|B_j|≤M，

    W'−M ≤ Σ_j |B_j\A| ≤ Σ_j |A\B_j|
          = Σ_(x∈A)(m−c_x).

若c_x=m则该客户下面两端均为零；若1≤c_x≤m−1，则

    m−c_x ≤ (m−1)(m/c_x−1),

因为右减左恰为 `(m−c_x)(m−1−c_x)/c_x≥0`。
所以得到普遍纯终局不等式

    W' ≤ M+(m−1)(mz−M) = m(m−1)z−(m−2)M.       (C)

这不是福利下界，也没有要求该终局是均衡。它将所有其他主题在A外的并集容量，
交给同一条终局中A客户的负载缺口支付。

## 2. 任意早期历史的真实分支必要式

固定一个完整历史纯SPE、全部m名玩家及任意合法历史h，其当前玩家是i≤m−2，
该节点按给定策略继续时的当前收益为t。设全局最优m主题覆盖为O，

    L=O/(2m−1),     M=max_(T∈S)|T|.

当前玩家真实改选最大主题A，之后执行同一完整策略；所得整条终局中其收益为z，
总覆盖为W'。节点最优性给z≤t。不能将这个终局冒称为根SPE；根/当前玩家未必愿意选A。

同一真实分支的最后两名玩家各至少得L，原因是已有末两人安全值保底和
`theta_m≥O/(2m−1)`。这适用于全部离轨有序历史，并保留任意平局。
此外，位于当前玩家之后、末两人之前的每名玩家都可以真实改选A，其所得至少M/m；
共有m−i−2名这样的玩家。过去玩家在这条离轨终局中的收益只以下界零处理。
因此

    W' ≥ z+2L+(m−i−2)M/m.

与(C)结合，再用z≤t，得到

    [m(m−1)−1] t ≥ 2L+[m−2+(m−i−2)/m] M.       (B_i)

该式对任意合法历史的真实SPE当前收益成立，不限实际根路径。m包含全部固定过去玩家，
没有把背景剩余利润换成覆盖，也没有将过去玩家的离轨收益与根收益混同。

根i=1时再由O≤mM消去M，得

    u_1 ≥ [(2m^3−m^2−5m+3) /
            (m^2(2m−1)(m^2−m−1))] O.          (R)

该弱保底是O/m²量级，不能推出人数无关half。与单个末位保底结合的旧最大主题
逐对界给`u_1≥2O/[m(2m−1)]`；(R)的系数高出

    (m²−3m+3)/(m²(2m−1)(m²−m−1)) > 0.

此改进不控制一般早期最小收益或总预算，不能把它称为弱逐人O/(2m−1)桥。

## 3. 三人首位整数缺口桥已由此闭合

m=3时只有首位属于(B_i)，得到

    5u_1 ≥ 2O/5+M ≥ 11O/15,
    因此u_1≥11O/75.

对同一完整根SPE，已证三人锐5/3界给`W≥3O/5`，故

    O−W ≤ 2O/5 ≤ (30/11)u_1 < 3u_1          (O>0).   (D3)

全零实例直接满足非严格乘法式。末位及倒二的更强分数价格桥已在
`R-077c0cacfba24288be91dee1acf6d484/global_proof/terminal_menu_projection.md`
及相关分数扩展得到；这里新闭合的仅是三人根首位整数端点。

不得把(D3)改成任意背景后的倒三位置：三人根锐界只用于整条三人根SPE，
任意背景的三人剩余利润界不等于整条总覆盖。当前也未证明分数价格`B(u_1)≤W`。
