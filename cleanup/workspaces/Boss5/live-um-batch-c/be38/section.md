### R-40bb：完整克隆的多重集阈值、周期与首次达到

README 明确 UM-TARGET-v1 的原量词不改，当时主攻其否定，而主目标和一般反面仍 OPEN。它称六个内部 6.1-sol／max 研究者分别攻击困难性源、gadget、放大、量词、图接口和配置表示，并明确不把一致赞同当证明；这是源文件的协作记录，不是本次六次独立认证或新的人员部署。其可复用增量准确指向旧 `private_graft_and_resource_repetition.md` §8 的 `UM-COMPLETE-CLONE-MULTISET-PERIODICITY-v1` 及专门后审。

现正式承载对象为[完整机器任务克隆的多重集与最终周期](../定理/完整机器任务克隆的多重集与最终周期--定理.md)。输入是有限非空机器集、有限不可拆任务集、非负二进制有理处理时间及不可用端，每任务至少一个可用端，允许空任务与零 OPT。完整 q 克隆同时将每台机器、每个任务复制 q 份，每条原有限 incidence 扩成全部 q² 个同时间端；令其真实整数最优值为 O_q。它允许同一原任务类型的多份副本共居一台机器副本，与每 incidence 只取一个置换的 cover 不同。

删去有任一零端的整个任务类型，余下正类型的最短端总量为 U，最小正处理时间为 p_min。负载不超过 U 的多重集配置件数至多 K=⌊U/p_min⌋。以每行配置概率和为 1、每类型期望计数恰为 1 定义有限有理多重集配置 LP，最小可行阈值记 t₊。真实 q 调度按机器类型统计配置频率给此 LP；反过来，有理证书共同分母为 d 时，每种机器放 d 个配置副本，每类型恰 d 个 slots，再与 d 枚真实带标签任务逐一配对，得到完整实际调度。所有 q 的最优值都落在同一有限有理负载集合，因而

\[
t_+=\min_{q\ge1}O_q=\liminf_{q\to\infty}O_q.
\]

对任意实 T，置 S_T={0}∪{q≥1:O_q≤T}；它因不交复制而对加法封闭。S_T 含正整数时，模其最小正元的可达余数构成有限子群，每个余数取最小代表，即知足够大 q 属于 S_T 当且仅当 gcd(S_T\{0}) 整除 q。有限阈值族合起来给 O_q 最终周期，其最小正最终周期为 d*=gcd(S_(t₊)\{0})；收敛当且仅当 d*=1。这里不是相邻 q 单调，也不是总有极限；一般不能将 t₊ 写成原 0/1 CONFIG 或 assignment LP 阈值。

首次达到最佳值还可真正指数大。取 Sylvester 分母 e₁=2、e_(s+1)=1+∏_(h≤s)e_h，R_k=∏_(s≤k)e_s，机器分母为 e₁,…,e_k,R_k；放 k 枚全可用 unit 任务和每机一枚时间 1/D_i 的私有任务。总工作量给 O_q≥1，逐行整数箱数给

\[
O_q=1\iff \sum_i\lceil q/D_i\rceil\le q
\iff (\forall i)\ D_i\mid q\iff R_k\mid q.
\]

故首个达到数和最小最终周期都是 R_k，而原显式矩阵总二进制位长 L=Θ(log R_k)，R_k=2^{Θ(L)}。这是所有真实调度的容量下界，不是某个劣 LP 证书用了大分母。一般 Cramer／Hadamard 也只界共同分母的位长，不能免费输出指数多机器、任务和 q² 交叉端。

同一正文还给近二种子的真实坍缩：m 台机器、一件全可用 unit 任务、每机 m−1 件私有 1/m 任务，原 OPT=2−1/m，而完整 q=m 克隆的 OPT=1。它没有 NP-hard 源，只否定指定复制操作对任意种子自动保 NO／放大的合同，不排源相关精选接线、附加物理一致性或一般 UM 近二困难性。

### R-434a：三种成果各保自己的量词

该 README 同样主攻 UM-TARGET-v1 的反面，明确原命题及一般反面均 OPEN。它将完整结果放公共规范层，工作区只给三个具体入口；不是没有数学内容的模板。三入口原文对应节及现正式对象已比较，下列说明保留各自可调用内容，完整证明仍由所链正式对象承担。

**固定超载件数。** 旧 `top_two_pair_witness_boundary.md` §7 给 `UM-FIXED-ARITY-WITNESS-FILTER-v1` 及其 promise 排除。对先固定整数 r≥1，令 B_r(σ) 是每机最大至多 r 件处理时间之和再取全机最大，c₁=1、c₂=1/2、c_r=6^{−(r−1)!/2}（r≥3）。给合法 P 和有理 T≥0，位多项式过滤器要么可靠 FAIL⇒普通 OPT>T，要么输出全部原任务一次的保留端调度且 B_r≤(2−c_r)T。成功不控普通总负载，也不宣称相对 min B_r 的该因子近似。

r=3 的直接三流槽分别允许 p≤T、p≤T/2、p≤T/3，容量为 1、1、n；任意普通 T 调度可按每行非增次序进入这些槽，成功整数流给 B₃≤11T/6。一般固定 r 的证明仅枚举固定 δT 以上的 big 配置，tiny 进前缀时用更短 big 前缀的较大余量支付，再做一次覆盖全部任务的共同槽匹配；没有免费调用一般 CONFIG oracle。因此固定 ρ≥2−c_r 时，YES 为普通 OPT≤T、NO 为每个完整保留端调度都有 B_r>ρT 的 promise 在 P 中；ρ 的等号端点因 NO 严格号而保留。r 可随固定目标误差增长的归约族及一般总负载 NO 没被排除。

现[固定件数最终审查](../审查/固定件数过滤最终证明与不可用端字段纠错--审查.md)比[作者候选障碍](../障碍/固定件数超载过滤与严格次二障碍--障碍.md)进一步保存最终 canonical §7 的证明／审读，不能把后者候选状态静默改成新状态。软件只实现 triple 流和给定证书核验／舍入，一般有理 big-only LP 后端未交付。后继审查已纠正另一旧页对报告 `unavailable=true` 的误读：它指有限测试包含不可用端 None，并非完整 oracle 未提供；此字段纠错不消除真正未实现的一般 LP。

**有界重数接线。** 旧 `private_graft_and_resource_repetition.md` §9 对每原 incidence 取至多 c 个置换并集，允许置换重复、重复边合并，不额外加任务／机器／端。定义 MC_c 为单类型计数 0,…,c 的配置 LP，阈值 t_c。现[接线包络定理](../定理/有界重数克隆接线与共同循环坍缩--定理.md)给

\[
t_c(P)=\min_{q\ge1,\ Q\text{ 为 }c\text{ 接线}}\mathrm{OPT}(Q),
\qquad t_c(P)\le\mathrm{OPT}(Q)\le\mathrm{OPT}(P).
\]

前向按机器副本统计配置；反向按有理分母展开槽，与全部带标签任务配对，把已用 incidence 边按机器副本处至多 c 度着色，再将每色部分匹配补为置换。q<c 也可行：正权配置的单类型计数超过 q 会独自使该类型期望覆盖超过 1；不需要另加 q≥c。它是对精选接线取最小值的存在性包络，不是任意 c 接线均坍缩；identity-only 仍能保原值。

共同循环给特别强的反例。对上面的近二种子取 q=m，每条 incidence 都用同一 identity 和 x↦x+1 mod m，图为连通 2m 环。把 B-copy x 给 (x,x)；私有 (U_it,x) 在 (x−i) mod m<t 时移到 (i,x+1)，否则留 (i,x)。每私有类型在副本 i 占位 0、i+t 占位 2、其余占位 1，所以所有 m² 台机器负载恰 1，全部任务真实执行。原 t₁=OPT=2−1/m，但 t₂=1；有界度、逐 incidence 连通、共用平移接线和多项式 q 都不足以单独保证保 NO。这不能外推所有接线失败。

现对象保留共同循环见证由原审者读到有界重数陈述后贡献的来源，不能把参与构造后的审读称作完全盲审。原实现修复包括不可用端显式零坐标索引以及 m=2,…,17 总量更正。后继[证书实现与有限穷举](../计算/有界接线的证书实现与有限穷举--计算.md)还区分 81 个不同图、2448 次完整指派、额外复查一图的 256 次指派、22 份有序配置阵列与 8 种分布；这些计数不相互替代。没有 MC_c 优化器或源 decoder，给定分母证书的展开成本按数值 q、c 及实际输出规模计。

**允许 padding 的单一对数字母表。** 旧 `model_and_classical_barriers.md` §8 是 `UM-DENSE-LOGARITHMIC-ALPHABET-PADDED-EQUIVALENCE-v1`，由[私有填充等价](../等价/私有填充的对数字母表调度等价--等价.md)承载。对实际任务数 N≥2，H=bitlength(N)，令

\[
\mathcal A_N=\{1,N^2\}\cup
\bigcup_{j\ge2,\,2^j\le H}
\{\lceil(1+1/(8j))^r\rceil:0\le r\le\lfloor H/2^j\rfloor\}.
\]

去重后大小 O(log N)，仅依实际 N，不依原矩阵、阈值或 backend 改善 k。若此显式全有限正整数矩阵类有固定 α=2−1/k 的实际调度算法 B，则对原模型得到 2−1/(2k) 算法；逆向限制输入域，故统一改善的存在性等价。B 是假设 backend，不是已实现求解器。

固定 k≥2 后取 ℓ=⌈log₂(8kn)⌉、E=2^k·8k·ℓ、N=2^E，增加 N−n 枚私有 unit dummy 及私有机器。所有非私有 dummy 端、原任务到 dummy 端和未保留原端都为哨兵 N²。对首个 T≥OPT 的几何候选，原 n 个 active 任务每机至多积累 n 次加一误差，得到 OPT(Q)≤b(8kn/T)OPT+n，b=1+1/(8k)；任一完整 α 合格输出的峰均小于 N²，故全部 dummy 必走自己的真实私有边、全部原任务必落保留原端。回译强式界给 C≤αb² OPT< (2−1/(2k))OPT，量化任意合格完整输出，不只某个有利 YES 调度。

固定 k 时 N 是原 n 的固定次数多项式，次数可极大且依 k；目标完整矩阵的全部交叉端必须显式计费。不能读成二进制可变 k 下统一多项式，也不能把它替换旧 same-n 的 O(log² n) 身份。原有限审计仅作天文 dummy 块的完整低负载分类，没有真的物化这些矩阵或执行 B。现页已澄清旧表 E=256、320、448、1344 指 log₂N，实际 N 是 2 的对应次幂，不是这些整数本身。专门 review 只认证当时 §8 范围，不把新全文 hash 追授旧 §6–7。没有 NP 源、近二整数 YES／NO gap 或 source decoder。
