### R-56ef 的目标、六个规范入口和长期增量

README 自称“boss4 的共同容量与消元研究桌面”，明确唯一主目标 `UM-TARGET-v1` 尚未解决，当前责任是从任意普通 UM 矩阵 P 生成共同容量状态，输出同一份全原任务、全机器同时守界的实际次二调度，或给可靠 FAIL。局部可行、低缺陷和多项式单步均不足；总位复杂度、统一余量及一般输入生成义务仍由[任务级共同容量问题](../问题/任务级共同容量的算法义务--问题.md)承担。README 没有给一般生成器。

其六个规范入口已与冻结正文、现有自足对象及后续版本边界比较。它们是已有资产的历史导航，不因本工作区引用就增加一份数学证明或独立审查。

**原地拟阵指数外包。** README 精确指向 `minimal_star_contraction_and_capacity_gap.md` 的 §9，而非把前面的星收缩或固定拟阵数线性权衡认成同一新结果。[原地指数外包资源](../资源/原地拟阵指数外包的回路枚举与结构证明--资源.md)保原地基集 `A∪{b}`，`|A|=k≥3`，`1≤r≤⌊(k−1)/2⌋`，`w(a)=1/k`、`w(b)=1−r/k`。任意 q 个同基集拟阵都完整保留真实容量族 `{S:w(S)≤1}`，且所有共同独立集均严格轻于 `w₀=2−2r/k` 时，

\[
q\ge\left\lceil\binom{k}{r}/\binom{k-r-1}{r}\right\rceil
\ge\exp(r(r+1)/k).
\]

A 在每个拟阵独立，回路消去迫每个非 free 拟阵只有一个含 b 的回路，tiny 部分至少 r+1；一个回路至多排除分母所计的边界坏集，故得覆盖计数。精确最少数是覆盖设计数 `C(k,k−r−1,r)`，不是免费可算闭式。固定 `1≤B<2` 时取固定有理 `r/k=d<(2−B)/2` 得超原权重表位长 `Θ(k log k)` 任意固定多项式的拟阵数，不冒称 `exp(Ω(位长))`。严格阈值、原地、完整保留及所有接受集安全均承重；投影、动态/共享辅助、基约束或算法只选一个好集未被排除。固定独立私有辅助能化为横截拟阵收缩时才仍属此域。这是静态表示障碍，不是一般调度困难性。

**有界配置任务数。** [固定 K 槽余量与承诺搜索](../定理/有界配置基数的严格槽余量与承诺搜索--定理.md)区分两身份：给显式等式覆盖 CONFIG(T) 点，先把有任一零端的任务放零端并删除，若每正权残余配置至多 K 件，则任意共同覆盖槽匹配都满足 `L_i≤E_i≤(2−K^{−(K−1)})T`（K≥2），K1 为 T，K2/3 可用锐值 `3T/2,11T/6`。它限制配置基数，允许可选任务并集和时间跨度无界。严格前缀计数、整数类型、Abel 求和和行列式把局部严格不等式变成统一 K 余量；同一个全局匹配才把所有行界同时兑现。

另一个未知 OPT 算法须固定 K，并承诺至少一个普通最优调度每机至多 K 件无零端任务；枚举 `O(m n^K)` 小配置及负载和，搜索首个截断 CONFIG 可行阈值 `T*≤OPT` 再匹配。全部阈值不接受只能排除 K 基数调度，域外不能推原实例不可行。[版本与 K5 审查](../审查/有界配置审查的先验版本与K5阶乘反例--审查.md)还保旧弱余量、声明先行加强、后来知情读后之别，以及 K5 完整坏匹配 `287/144>2−1/5!` 的反阶乘例；K4/5未称锐，最佳匹配仍可为1。K 增长使余量消失且枚举次数增长，不给统一改善；现有代码是证书/有限匹配审计，未集成一般配置 LP 后端。

**永久消元及真单环是不同层次。** 冻结 `configuration_preserving_elimination_support_loss.md` 四节均已全文比较。[消元审查](../审查/配置覆盖坍缩与永久消元双源审查--审查.md)保零缺陷 full-rank 坏历史：真实 OPT1 初态经指定合法枢轴，永久固定后每个补全峰恰 `2−1/m`，但该具体方向会立刻违反 big-count；不能拿它反驳维护 CONFIG 的增强规则。后续激活提升让整条边际路径保完整 CONFIG，仍丢给定好支撑；双副本直和让同一方向两最大符号均坏，但该方向不是 circuit。

更强的[真单环](../审查/真单环双坏端点的三种实际基态与全支撑证明--审查.md)另立身份：奇 `D≥3,L=D+2,N=DL`，显式 N 个完整峰1旋转原子给真实初态；方向物理支撑为单个 4N 交替环，真支撑极小。整段 `[-γ,γ]` 保全部机器负载及完整 CONFIG(1)，端点没有任务整数化，而永久删除零端后的两完整支撑 OPT 都恰 `2−1/D`。下界针对任意完整调度：hard selector 所在 rail 若峰低于该值至少外送两 port，对应两单位 H 都被迫同一 Q 而撞载；上界逐原任务给出。它只关闭任意指定 circuit 试两最大符号的充分合同；换方向、保共同原子或重开端均未排除。原子本身已是最优输出，因此不是难实例。[先序与有理版本证据](../审查/真单环审查的Exact先序与有理参数版本证据--审查.md)还保独立基态差异、任意有理 θ 另计编码，以及 D7 未实际矩阵消元不能填 rank 251 的运行边界。

**小任务稳定接口。** [联合槽续审查](../审查/小任务联合槽与加权小端ST双源续审查--审查.md)把给定点算法与证书选择分开：正权配置至多 K 个 big，tiny 时间≤δT，`r_i` 为配置 tiny 工作最小值，`s_i` 为边际 tiny 工作，`b_i` 为最大支撑 tiny 件；同一任务—big/tiny 槽图的一次共同匹配给

\[
L_i\le\alpha_K(T-r_i)+s_i+b_i
\le(\alpha_K+\omega+\delta)T
\quad(s_i-r_i\le\omega T).
\]

big 用有界基数包络，tiny 用前一满槽收费；不同机器上的同一任务可有不同角色，不能分别舍入后拼接。给定点构造对二进制 K 仍统一位多项式，不枚举 n^K，也无需构造巨大 α_K 分母。固定 `ℓ≥2,0≤ω<1/2` 的明确 selector/root/leaf 族中，寻找这种稳定 CONFIG 点 NP 完全，依赖 perfect3DM 的完整归约；不是一般 UM 困难性。同源实际三值由 3DM 值 ν 和二部投影匹配值 μ 决定：`ν=q` 为1；`ν<q,μ=q` 为 `1+1/ℓ`；`μ<q` 为 `1+2/ℓ`。从已给源呈现计算二部匹配 μ 后，可构造整个族的 `(1+1/ℓ)` 实际近似；若 CONFIG1 可行则 μ=q，无需稳定证书就能输出峰≤`1+1/ℓ`。因此不能由某过强稳定证书难选就证明实际调度难，也没有从未标记 raw 矩阵免费识别模板的算法。有限 parity/大分母证据只核所列输入，未给一般稳定状态生成器。

**鲁棒环共享背景。** [最终共享 context 审查](../审查/鲁棒双端环共享背景最终范围与三半锐界审查--审查.md)明确不同 core 的机器和任务集互不相交，context 可跨已有 core 机器共享，却不能给 core 任务加第三端。`T>0,T≤B<2T`，每端时间在 `[0,T]`；碰撞和 `a_i+b_{i−1}>B` 当且仅当该环只余两 coherent phase。给整个实例一份峰≤T的完整实际 σ，任意显式 phase 向量保持 context 原端不动时，old/new core 差严格小于 `2T−B`，于是同一完整输出峰严格小于 `3T−B`；B≥3T/2 时所有相位弱 B 可行，不能从 strict 见证读取 near2 相位。三半阈值锐，`3T−B−e` 是上确界锐族，不说有限例达到包络。两 core 复用机器可破界，最终稿已修明 machine-disjoint 域；不把域外反例当域内反驳。本接口不寻找未知 σ，也不反驳改变资格的其他模型。
