### R-43b：给定实际目标的全程路径与未知 target finder

README 唯一数学正文链接是 `research/current/unrelated_machines/bundle_inflow_peeling_and_pruned_transient_sharpness.md`；两准确 Claim 为 `UM-LOCAL-BUNDLE-SHIELD-PATH-v1`、`UM-PRUNED-BUNDLE-PEELING-PATH-v1`。已全文比较同 SHA 冻结原稿及现[任务包共同入流剥离定理](../定理/任务包共同入流剥离--定理.md)，不另立同义数学对象。

它处理普通有限二进制非负有理不相关机：**完整实际初态 σ 与完整实际目标 τ 都是输入**。每件改变任务仅直接迁往 τ 一次；不动任务在机器 i 合为底载 $f_i\ge0$。记源量 $A_i$、目标来流 $Q_i$、初态负载 $S_i=f_i+A_i$、终态负载 $F_i=f_i+Q_i$。若 $0\le T\le C\le2T$，两实际被用端均不超过 T，且所有 $S_i\le C,F_i\le T$，则确定性总位多项式输出覆盖全部改变任务的排列，使**每个前缀的全部机器同时**满足

\[
L_i\le U=\max(2T,C+T/2).
\]

核心不是反复选择任意安全步，而是同一目标下的共同入流屏蔽：对逐机预算 $U_i\ge S_i$ 取 $h_i=(S_i+Q_i-U_i)_+$。每个正阈值源包及其补集都至少迁出 $h_i$，并有 $h_i\le U_i-S_i$ 时，先迁入阈值外的所选出口，按内部所选入流小于阈值剥离，逆删除序完成源包，再迁补集、最后释放保留核心。保留核心一次扣除全部内部所选来流，不能对多源重复使用容量。剪枝域可按单件或首次越阈值前缀有效选包，不调用精确背包。原统一预算实现曾漏掉核心向外所选出口，现定理和实现用阶段0修复；有限回放另由[给定目标审计](../计算/给定目标重配置的精确审计与版本纠错--计算.md)承担，本次未重跑。

给定任意源二分，$M_i=\max(a(P_i),A_i-a(P_i))$ 还给逐机 profile $U_i=\max(S_i+Q_i/2,F_i+M_i)$；两箱 LPT 可使 $M_i\le\max(a_i^{\max},2A_i/3)$。两机首步族给全输入类、每个参数下到指定不同 τ 的锐界，不声称锐初态来自 ST 输出。T=0、空改变集、平行弧与零端均保留。

因此 README 的“全部剪枝初态、给定 τ 的完整路径义务已闭合”准确；闭合的不是从原矩阵产生 τ。目标端剪枝由 τ 自带，源端剪枝承重。条件不成立只是本接口不适用，不能报告 `OPT>T`；U 可达或超过2T，不是最终次二近似。README 的下一步是从一般 P 产生未知目标的共同整数选择、可计算共同容量和统一实际余量，或者给可靠 FAIL。改矩容量恢复、非可加交换、真实源 decoder 是原件允许的并行方向，不是已经交付的算法。其“以 checkpoint 远端回执为准”只记录发表合同，本 README 未给实际 pushed 回执。

### R-443e：三种受限正面接口各自的输入责任

该 README 将长期资产存于公共专题目录，个人桌面只链接；本次逐项追溯三个原件与已清洗对象。它不是一个合并的一般 UM 算法。

**单 home 去环与一般有向需求桥。** 原链接 `home_unit_cycle_elimination_and_directed_token_bridge.md` 的冻结全文及现[单home正规化与一般有向需求树实际恒等](../定理/单home正规化与一般有向需求树实际恒等--定理.md)已比较。原任务不交分为 U、J：U 所有有限端耗1；J 的指定 home 耗 $a_j\in[0,1]$，其余有限端耗1，允许平行转移任务。给定一份完整实际 σ，逐简单有向环把环任务同时退 home，每环点变化 $a_j-1\le0$，至多 $|J|$ 轮得无环图。一般负载下不能同时撤回所有属于某个环的弧；该完整状态变换也不保证批内逐件峰值。

当 σ 峰 C 严格小于2，单位入度使 U 实际目的地前向可达域 R 为不交朝外树。保 U 位置及 home∈R 的 J 原端、其余 J 回 home 后，R 内负载仍是原负载，R 外为完整 home 总量 $b_i$。保峰还须 R 外 $b_i\le C$，全局 $b_i\le1$ 是足够条件；不声称 R 外逐机不增，C=2 的同容量森林推广有反例。一般简单无自环有向需求图允许环境环和根原入边，需求 $k_v\ge0$，零需求须原出度0。根树评分

\[
b(H)=\min\bigl(\{1\}\cup\{\deg_H^+(v)/k_v:k_v>0,\ v\in H\}\bigr)
\]

计入选中的正需求叶，令 $b^*=\max_H b(H)$。每正需求点只创建 $\min(k_v,d_v)$ 枚 child 与至多一枚 filler，另全实例一枚 unit 根任务，避免按 binary 需求数值复制。任意峰 $C<2$ 的实际调度解码 $b(H)\ge2-C$；反向须裁掉超需求孩子的整棵子树，再覆盖全部原任务，故真实 $\mathrm{OPT}=2-b^*$。未知好根树／调度仍没有由正规化免费产生。冻结正文后附匿名 token 的 M1 提升、给定聚合 M2 非扩展和完整 head×context PSD 块；它们是另一共同矩表示合同，不能倒填为 README 已交付全局选择或近二 gap。

**类型 profile 可生成与 max-profile 选择。** 原链接 `type_profile_compression_and_matching_rank_bridge.md`，源 `af0562c14e7407309d73` 的12953B冻结全文及现[类型压缩双源审查](../审查/类型压缩与仿射并行线双源审查--审查.md)已比较。对固定正有理 ε，单阈值 Santa 输入为显式非负有理估值、m≥1、n≥0，资源可闲置。cap、tiny 阈值、几何下舍与按类型分块给 $t=O_\varepsilon(\log(n+1))$ 个正类型和每玩家 $(n+1)^{O_\varepsilon(1)}$ 个显式 count-profiles；任意原值≥1的实际子集都有内含子集精确匹配一个 profile，舍下值≥$1/(1+\varepsilon)$。这仅生成菜单，不判定 YES、不读未知最优解，也不提供共同 profile 选择；固定 ε 的复杂度不等于对 $\operatorname{bit}(\varepsilon)$ 统一多项式。

对显式非空归一化 profile 菜单，每 profile 的 type 截断匹配值 $f_{ic}$ 是 weighted partition-matroid rank，$F_i=\max_c f_{ic}$ 却不必次模。private selector、逐 profile token 和真实资源 unit 端编译保留**全部未选 profiles 的原任务**，给精确 $\mathrm{OPT}_{UM}=2-V$，其中 $V=\max_{B_i\text{不交}}\min_i F_i(B_i)$。value-types 不能免费换成具体资源子集，四资源非次模反例阻止直接套用次模算法。空菜单另输出固定 OPT2 的 NO 分支，不送入非空菜单恒等式。原文 tiny cutoff 的特定字面删除断言已由101资源反例校正；改成可支付加性损失的小阈值及分块证明补齐已知合同，不是否定原主定理。README 记“已向同行分享”只保留作者报告，本次没有新发送或独立查验聊天历史。真正未解的是不交 max-profile 共同选择或有全 partial matching soundness 的真实源。

**整比双尺寸的中性精确修复。** 原链接 `divisible_two_size_neutral_repair.md` 的6832B冻结全文与现[批次边界及原任务修复证明](../证明/整比双尺寸的批次边界与显式任务修复原证--证明.md)已比较。m≥1台完全相同全资格机器，显式 k 件 Qδ macro、N件 δ tiny，Q≥1为 binary 整数、δ>0有理；从任意完整初态，不给 OPT 或目标。若 macro 件数差≥2，或直接迁一 macro 使两负载在旧区间内，或同时反迁 $q=Q-(\ell_s-\ell_v)\in[1,t_v]$ 枚 tiny，精确交换两机负载。纯负载势可中性，组成势 $\sum_i u_i^2$ 每批降至少2防循环。随后单 tiny 削平，至多 $\lfloor k^2/2\rfloor$ 个 macro 批次及 N 步达到

\[
\mathrm{OPT}=\delta\max\{Q\lceil k/m\rceil,\lceil(kQ+N)/m\rceil\}.
\]

结束时 macro 数只差至多1、最大值为 $\lceil k/m\rceil$，不是每机都等于该 ceil。majorization 与峰不增仅指**原子批次边界完整状态**，不保证逐件串行峰；任务编号列表可实现完整输出，count-state 审计本身不是通用矩阵求解器。完全同机、全资格、整比和共同 tiny 尺度承重，异端时间破坏交换恒等式。它是防循环正面控制组，不能外推一般 UM。

该 README 最后保留一般 $(P,T)$ 下的可计算共同容量、全机实际整数输出、统一余量、可靠 FAIL 与总位复杂度，或真实近二整数 gap 及完整 decoder；也明确沿 actual main 恢复先前给定 τ 任务包而不重复建树。这些义务由[共同容量问题](../问题/任务级共同容量的算法义务--问题.md)继续承担，三入口并列不会自动将它们闭合。

### R-4882：半单位选择边界及稀疏配置的版本推进

README 采用 `UM-MODEL-v1`，有限一般有理不相关机必须给全部原任务的真实分配，`UM-TARGET-v1` 仍 OPEN。其“全 δ<1/2 的半单位共同选择障碍与同行重复”是复用既有共同身份的说明，不在个人区再复制归约包。[联合选择审查](../审查/联合选择槽舍入三源精读--审查.md)与[半单位双程序资源](../资源/半单位共同选择与同资格计数调度双入口--资源.md)已全文比较：固定 $T=1,0\le\delta<1/2$，每任务唯一 small 端、处理时间仅1/2与1，未进大边匹配的任务被迫在唯一 small 端质量1，故共同 $A_\delta$ 见证就是半整数负载≤1的真实调度。逐 x 的3DM构造由激活下界与元素容量上界迫 exact matching；只否定该共同见证搜索接口。δ=1/2 时全 small 峰3/2使该构造失效，不能加端点，也不排绕开 Aδ 的一般算法。

主要链接为 `sparse_conditioned_configuration_gap.md` 与 `sparse_conditioned_configuration_review.md`。已全文读当前冻结 canonical `6a58c5bfa643bbb8225a`（SHA `88af645ff4ee5bd81afdeef2b67824ca34ed9183630c180373d1efa2d63c25f2`）及旧独立审查 `7682e69e379f27ca14ad`（SHA `17e724db2e201341dc267d1b6e75776a493e7f39c26847eb2bba37d79febbe1b`），并比较现[canonical增量](../审查/稀疏配置与强矩匹配双源增量审查--审查.md)、[旧审查来源整理](../审查/稀疏配置与子线性联盟来源审查新增--审查.md)及[星配置保持审查](../审查/极小星配置保持与稀疏收缩族独立冻结审查--审查.md)。此处必须分三个版本层次。
