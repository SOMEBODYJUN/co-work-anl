### R-3ca5：同质宏接口的真实假设与历史候选身份

README 的第一入口是 `homogeneous_macro_private_edge_st_rounding_candidate.md`，旧身份 `UM-HOMOGENEOUS-MACRO-PRIVATE-ST-v1` 及未知 OPT promise 版本。原候选和现[按 home 同质宏舍入](../算法/按home同质宏的任意私有边舍入--算法.md)均已全文比较。机器是不交的 H 与 Z；宏只在 H，数量 `|B|=|H|`，宏资格图有完美匹配，对每个 home h 所有可用宏边时间同为 `P_h>T/2`、与宏身份无关。私有任务可以跨任意多个 home/sink、有任意逐件资格及逐边非负有理成本，但所有有限私有边 `p_ij≤δT`，`0≤δ<1`。

真实 T 调度中每 home 至多一宏，宏数强迫每 home 恰一宏；同质性保证任意宏完美匹配都保相同的残余容量 `c_h=T−P_h`，sink 容量为 T。私有 assignment LP 在该容量上可行时，标准有序单位槽匹配的实际负载为分数负载加该机支撑最大件，故加回宏后全机至多 `(1+δ)T`。现正式对象显式保 `P_h≤T` guard，避免无私有任务或孤立 home 漏过冻结超载。若真实 OPT≤T 必成功；成功不意味着精确 T 可行，域内 FAIL 与结构合同不成立须分开。

不给 OPT 的承诺还需要 `P_h>OPT/2`、所有有限私有边 `p_ij≤δOPT`，以及固定 `δ≤δ̄<1`。分母乘积给位长受控的有理网格；测试只随阈值增大放宽容量和资格，不把 `P_h>t/2` 或 `p≤δt` 塞入二分谓词。最小接受 `t*≤OPT`，ST 误差按 `δOPT` 支付，得到 `(1+δ)OPT`。README 的一句“未知 OPT 候选”不能省去小边 promise 或固定余量。

这是标准 LST/ST 机制的结构应用，原件明确候选草稿、正式冻结审查待做、未认证新颖性；现有对象的知情重构不倒授历史盲审或通用软件完成状态。若宏时间依赖身份，任意匹配后的精确残余容量会变化；后续较弱 `3/2+δ` 的统一残余接口另有范围，不能据耦合困难断言全部正面方法失败。

### R-3ca5：共同量子流与精确组汇比例是两个更窄接口

README 将 `equal_quantum_arbitrary_eligibility_flow_candidate.md` 与 `group_sink_ratio_joint_slot_candidate.md` 并列为可回收机制。二者原件、正式算法及[三接口来源审查](../审查/任意资格三接口的来源与证明范围--审查.md)均已全文比较，不能合称“任意资格一般算法”。

**共同量子精确流。** [全占用同宏精确调度](../算法/全占用同宏下任意资格量子的精确调度--算法.md)要求每私有任务有唯一 home 和任意逐件 sink 集 E_j，但每个可用端都是同一个全局量子 `u>0`；宏数等于 home 数、宏在所有 home 可用且同耗时 `T/2<p≤T`。强制一宏/home 后，home 最多留 `r=⌊(T−p)/u⌋` 件，必须外送 `k_h=max(0,n_h−r)` 件；逐件真实资格流和 sink 件数容量 `q=⌊T/u⌋` 给精确双向见证，输出覆盖全部原任务。FAIL 当且仅当该结构上没有 T 调度，网络规模按显式任务/资格多项式，不按 T/u 数值建槽。

承诺真实 `OPT<2p` 且 H 非空时，可在 `{p+ku}∪{ku}` 与 `[p,2p)` 的 O(N) 个断点搜索原精确 OPT；无接受点只说明承诺域外。零量子、空图及冻结宏过载须各走分支。原稿称任意宏资格都会改变外送下界过强：若每 home 的宏时间仍固定且有完美匹配，资格变化本身不改变残余容量；身份相关时长或可变占用集合才重引耦合。原两件空交集例展示共同资格交集不能替代逐件图，但不强迫两 sink 都使用，现算法另给四件强制分裂例。私有尺寸不再共同量子时，精确件数流不再代表真实加权负载。

原程序虽称 flow checks，实际上重复同一调度枚举，没有实现流。现有[两种真正流与原枚举范围](../计算/任意资格量子流的两种实现与原枚举边界--计算.md)区分原 3001 次函数输入与新增 7162 例两流比较，以及 120 例原宏位置 OPT 的有限前段；两流共享新写的最大流底层，不称两套完全独立实现。有限记录不是未知 OPT 通用生产后端，本次不重跑或认领这些已处置来源。

**精确组汇比例联合槽。** [精确组汇比例算法](../算法/精确组汇比例的共同出口联合槽--算法.md)恢复唯一 home、组内共同 E_h，却允许异质私有尺寸 w_j；每个组—sink 对需精确 `p_zj=ρ_hz w_j`，并保 `W_h≤T`、`w_j≤δT`、`δ<1/2`、全部有限宏端 `>T/2` 及 `ρ_max<2`。其旧固定半截断合同给 home `≤(3/2+δ)T`、sink `≤(1+ρ_max/2)T`。固定 `δ≤δ̄<1/2` 和 `ρ_max≤ρ̄<2` 才有统一余量。

对 `d_h=(W_h−T/2)_+`，必要 LP 使用真实成本 `c_hz=ρ_hz d_h`；按该成本排序的单位槽与宏—home 部分在同一整数流里联合选宏、占用 home 和 sink，不能分别舍入后拼合。前缀的单件误差由 home 余量支付，真实出口到 sink 的成本不超过 c_hz。现正式对象补正原候选三处边界：须先剪去 `p_hb>T` 宏边；严格 `e_h>d_h` 只在 `d_h>0` 分支用，d=0 走旁路；正 d 且 E_h 空只迫使该 home 不占宏，不必令整个 LP 不可行。只有上界 `p_zj≤ρw_j` 不足以支持必要 LP，必须保精确比例或另证下包络。

后续有界畸变/可调截断另立身份，可扩大参数域；README 的旧候选和待审状态不能因后续审查而静默升级。三个接口都没有从一般矩阵免费生成相应同质宏、共同量子、共同资格或比例结构，也没有交付通用 LP/ST 全流程软件，更不关闭 UM-TARGET-v1。

### R-3ca5：四阶 C₂ 的指定来源信息边界与真正缺口

README 第二入口 `c2_prefix_conditioning_degree_boundary.md` 的冻结全文及现[四阶矩与指定前缀整机负载障碍](../障碍/四阶矩与指定前缀的整机负载--障碍.md)已完整比较。原件已明确修复：旧任务 5、6 互补的 3/2 时间令完整 B 负载恒为 3/2，只查一个 literal 的 0/1 不足；替代见证才保原存在性量词。

修复矩阵有 A、B、C 三机和七件任务：1–4 在 A/B 均耗 0；5 在 A/B 均耗 1；6 在 A/B 耗 0 且固定去 A；7 只在 C 耗 2。两个来源在前五 bit 的偶/奇 Hamming 重上各均匀取 16 个调度；全部支持都是真实 OPT=2 的完整调度。任意至多四个 one-hot literal 若不相容则乘积为 0，否则只固定至多四个非平凡 bit，因此两来源全部 ≤4 阶矩相同。前四任务均去 A 的同一前缀 F 在两边概率均为 1/16，偶/奇来源却使完整负载分别 `(1,0,2)` 与 `(0,1,2)`；相应第五阶 B₅ moment 是 0 与 1/16。

一般地，指定来源 μ 的条件负载为

\[
L_i(\mu\mid F)=\frac{\sum_{e\in E_i}p_e y_{F\cup\{e\}}}{y_F}.
\]

深度 t 的标量条件负载需 t+1 阶，degree-one 负载 localizer 需 t+3 阶，完整条件 C₂ 与该 localizer 最高需 t+4 阶；y_F=0 时不能除零。故四阶不能自动恢复指定来源的深度四真实续局容量，**不是所有可行下一步选择相反，也不是算法不可能性**。算法可重新耦合、重算证书或选别的真实来源；此例不证明一般 C₂、C₂+CONFIG gap 或 UM 困难性。

README 所说“审计与冻结运行已登记”须由既有[满载有限审计](../审查/C2前缀满载与单位多切片有限审计--审查.md)及独立程序资源承担。本次只全文比较记录，没有新跑 64 调度、1093 单项式或 PSD 消元，也不把同页单位多切片的其他参数 gap 嫁接到这个前缀见证。

该 README 的独有交接完整保留为：一般输入未有同质大宏分层；宏身份相关时长会耦合匹配与精确私有容量；四阶路线若超过深度三，必须提供高阶/紧凑条件 oracle 并支付编码与查询复杂度、重算残余证书及其条件可靠性，或采用不依赖深前缀的联合舍入。真实最优来源的存在不是免费 oracle。一般 UM 目标仍 OPEN，外审及新颖性未认证；上述限域接口、旧研究人数与当前六人 SPE 目标均不能混用。
