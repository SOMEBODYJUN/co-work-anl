### R-7f44：稠密普通整数等价不提供真实 near-two 源

README 的目标是历史反面主攻，明确主目标仍 OPEN。其唯一已入账增量是模型正文 §6 的 `UM-DENSE-SMALL-INTEGER-EQUIVALENCE-v1`；该模型稿及专门独立审查已全文比较，正式数学直接复用[稠密小整数调度的统一改善等价](../等价/稠密小整数调度的统一改善等价--等价.md)。

准确域是显式 `m×n` 矩阵、`m,n≥1`，全部端有限、正整数且属于 `{1,…,n²}`，这里 n 是实际任务数。全原模型存在某个统一严格次二确定性总位多项式实际调度算法，当且仅当此域存在；具体是先固定整数 `k≥2`，假设此域 backend 保证 `2−1/k`，可回译全模型的 `2−1/(2k)` 算法。固定 k 允许多项式次数依赖 k，没有可变二进制 k 的统一复杂度或未知 backend 的实现。空/零最优值、同 m/n、全体合格输出严格排除 `n²` 哨兵、强式回译和位复杂度均由现有自足证明承担。

该 README 原样强调“标准机制接口重构，不宣称原创困难性”。其独立审查只数学审了当时模型稿 §6，不能因全文 hash 就覆盖 §1–5 或后来追加 §7–8；独立重构、规范代码实读、262144个规范分配的有限复跑和 root 复核各有历史身份，见[模型与三正规形核验](../计算/精确模型与三种正规形的来源核验--计算.md)。这些证据不实现未知 backend、不替一般证明、不认证外审或新颖性。后来的同任务数 `O(log² n)` 字母表及私有填充 `O(log N)` 字母表是范围不同的已归档等价，不把这份 `{1,…,n²}` 摘要误改成固定有限调色板命题。

未闭合义务仍是：对每个固定改善量给真实 near-two 源 YES/NO gap，对**任意**低负载完整原调度给 sound source decoder，并保固定参数下机器数、任务数、位长和总时间多项式。正面原量词是“存在一个统一 ε>0 与一个程序，对所有合法输入”，其反面必须覆盖所有固定改善量和程序；只排一个 ε、一个槽匹配器或一个 LP 不够。没有找到算法、有限坏例和某个局部障碍都不关闭主目标。

README 所说物理复制、裸张量和占位探索未完成上述合同，按现有后续对象分别读取：一般 near-unit promise-PCSP 的抽象 hardness 不等于[物理 UM compiler 与全调度解码完成](../审查/近单位PCSP蕴含与物理复制义务最终范围审查--审查.md)；[固定层共同上容量张量逃逸](../定理/固定层共同上容量的整数张量逃逸--定理.md)已经有一般源乘积存在证明，但仍未实现 actual UM 应用；固定残余占位的可求格结构也没有给动态共同选择。不能用“探索未完”抹掉这些已证限域成果，也不能反向把它们升级成一般 near-two 困难性。
