原文件是一份持续追加的问题/接口账本，同时含直接证明、已修复结构算法、已反驳合同和大量指向别篇的结果陈述，不能把开头“OPEN obligations”机械套给所有附录，也不能把每个引用标签自动当作本批已核定理。本页保全它的独有问题身份和接续用途；其中直接证明与算法已拆入下列正式正文。原页当时优先反面研究是历史安排，不限定未来Solver的方法。

## 主目标和共同交付标准

非负二进制有理不相关机矩阵，m≥1、n≥0都是输入，任务不可拆分、每任务至少一条合法有限端。没有抢占、释放时间、先后关系、任务拒绝、通信或预测承诺等额外模型约束。正面目标要给统一ε∈(0,1)及确定性总位多项式过程，对所有合法输入输出**实际**峰≤(2−ε)OPT调度；ε不能随机器数、树高、尺寸比或精度趋零。没有合法端的任务可在域外直接识别；OPT=0必须实际输出零峰分配，不能除OPT或用正阈值搜索遗漏它。

原页的七项检验责任完整保留：

| 责任 | 需要的数学交付 | 最直接的边界核验 |
| --- | --- | --- |
| 更强下界/信息 | 定义B(P)并证明B≤OPT，解释为何已知坏配置不能仍令B=T | 在同一两树等坏族上符号代回，不能只改名字 |
| 实际分配 | 每件恰一合法机器，按对应p_ij求和 | 空/零/单端、强异端、长分母 |
| 全机容量 | 每台机器同时守界 | 两个瓶颈同时满载，非平均或期望结论 |
| 统一余量 | 常数ε与显式输入规模无关 | 让机器数、深度、尺寸比增长 |
| 总位复杂度 | 变量位长、oracle误差、总循环与输出规模 | 每步多项式不保证总步数多项式；不能免费枚举全部配置 |
| 强化系统可求性 | 分离/近似分离和舍入误差不吃掉改善 | 不把精确背包、配置或联合整数选择oracle当免费 |
| 反面路线 | 具体比值、复杂度假设、完整yes/no整数OPT gap与解码 | 固定某个ρ<2的困难性不排全部小ε改善 |
