# 来源与对象边界

本批三份冻结源全部 `clean show` 导出、全文读取并比较。它们均是仓库内部审查记录，不是外部同行评审，也不提供新颖性认证。`d45e652e9a9c66c8d850` 专审 half-unit joint-choice、promise-NO 与 `h+ℓ+s` 预算；`06d10007438f76920b5b` 审给定共同大边 H 的条件槽舍入、唯一小端选择 NP 障碍和 escape block cuts；`08e1e1abef90b6ce07b6` 审逐机跨度≤2 的前缀 LP、一次全局匹配和位多项式搜索。原件、SHA 和导出位于 `archives/unrelated-machines/tools/evidence/joint-choice-slot-20261031/`；receipt 草稿在 `cleanup/workspaces/Boss2/joint-choice-slot-receipts-20261031.json`。

三源属于同一方法链，但量词不同：给定 H 的条件结论、必须先找到 H 的 NP 障碍、已知逃逸族的块切面、逐机跨度结构的直接算法不能互相替换。

# 1. 给定 H 的共同匹配与槽舍入

给定合法大边匹配 H、目标 T 和剩余小边分数 `x`，只对未匹配任务作有序单位槽匹配。每个 `p_ij≤T/2` 任务的质量区间至多跨两个正交槽；槽容量和任务单位质量给 Hall 覆盖。按处理时间排序，舍入后每机负载不超过分数负载加支撑最大小端，得到

`C_i ≤ h_i + ((1+δ)T−h_i) + T/2 = (3/2+δ)T`。

该合同保持 H 不变；输入位长含 H、x、δ，槽数、排序、增广和有理端点都按显式矩阵总位长多项式。它要求 H 已给，不把选择 H 隐藏在槽匹配中；一般 LP 顶点证书可作为标准位多项式工具，但未认证生产求解器。

# 2. Half-unit joint-choice 与 3DM/promise 障碍

固定 `T=1`、`δ∈[0,1/2)`，有限时间仅 `{1/2,1}`，每个任务恰一个 small 端。未进入 H 的任务只能在唯一 small 端取质量 1，所以 `(A_δ)` 见证等价于实际 `OPT≤1`；负载是半整数，`1+δ<3/2` 迫使所有负载≤1。逐 x 3DM 归约：每 x 有三条激活任务，共享 root machine `R_x`；激活三元组机器有两条 half 关联端并一条大端选择；元素机器每列最多接一 unit。激活数 `r` 同时满足 `r≥q`（每 x 至少激活一次）和 `2r≤2q`（元素容量），故 `r=q`，提取 perfect 3DM；反向由 perfect matching 构造 H 与 assignment。重复三元组按列表索引，坐标按标签，q=0/孤立元素/空列表均有明确退化处理。

YES 的 `OPT=1`，NO 的 `OPT=3/2`；δ=1/2 时全 small 负载 3/2 使该归约失效，不能把端点写成已有算法。该障碍只针对“先找共同 H/`(A_δ)` 证书再舍入”的路线；不排除绕开 H 的一般调度算法。

`h+ℓ+s` 预算推论仍是同一受限构造：定义 `ℓ_i=Σ_{j∉J_H}p_ijx_ij`、`s_i=max{p_ij:x_ij>0,j∉J_H}`，在 `0<ε≤1/2` 下拒绝 root 留三 half（预算2）和激活 triple 仍留 half（预算至少2），反向匹配预算至多3/2，因此同样提取 3DM。ε=0 或 ε>1/2 的范围不能静默延伸。

# 3. Escape block cuts

对指定长链/末簇族、`1≤B≤θ_k=2−1/k`，令 `r_B=k−floor(k(B−1))`。`B<θ_k` 时 `r_B≥2`；每个 active bottom parent 至少外送 `r_B` 个星任务，配置边际逐层传播，底父边际总量至少 `r_B^(h−1)`，z 端分数负载至少 `(r_B−1)r_B^(h−1)/2≥2>B`（h≥3），故该族的配置系统不可行。`B=θ_k` 时系数归零，真实 Dirac 调度给可行性；把低 B 的系数冻结到端点会误删真实调度。切面是专用多机器 block 约束，不是一般配置分离 oracle、统一 gap 或近二算法。

# 4. 逐机跨度≤2 的直接 3/2 算法

删去 zero jobs 后，若每台非空行存在 `γ_i` 使 finite times 落在 `[γ_i,2γ_i]`，在目标 T 上解必要 LP：任务列和 1、分数负载≤T、严格 `>T/2` 质量≤1、严格 `>T/3` 质量≤2；当 `T<4γ_i` 另加总质量≤`floor(T/γ_i)`。按行时间降序铺单位槽，区间前缀质量保持各整数前缀计数；一次全局槽匹配同时满足所有行约束。令 `t=T/γ_i`：`t<2` 至多1件，`2≤t<3` 至多2件且第二≤T/2，`3≤t<4` 三件界为 `2T/3+T/2+T/3=3T/2`，`t≥4` 用普通 ST 加最大端≤T/2。全局目标搜索以正有限时间的有理 gcd 建格点，LP 可行性单调，U=Σ min_i p_ij 给有限上界，二分调用次数和槽图规模均位多项式；没有按 γ 大小数值循环。

此算法只针对逐机跨度≤2，行 γ 可相差任意倍数；不等同 common-b 两-small v2，也不覆盖任意 UM。相关有限审计只验证局部前缀表和 parity 实例，不代替全称证明或一般目标。

# 5. 交叉关系、证据和未决义务

三源形成准确的接口链：

* 给定 H 时，条件槽舍入可证 `(3/2+δ)T`；
* 选择 H 的 half-unit 子类由 3DM 给 NP 障碍；
* 特定 escape 族可由随 B 重算的 block cuts 排除；
* 逐机跨度≤2 直接跳过 H 选择，给独立的 3/2 算法。

仓库已有更广的 common-b 双-small-v2 正文/审查和有限 427 audit；本批不重复其 3DM/容量表结论，而保留 joint-choice 与 row-spread 的独有来源 SHA、读域、边界和外部 Karp/LP 工具依赖。未认证一般统一低于2算法、完整 H 分离、跨尺度联合舍入、生产实现、外部新颖性或主目标解答。程序重跑/有限审计只作证据，不能替代数学量词。

本批处置为受限接口审查；引用时必须注明是给定见证/指定逃逸族/逐机跨度类，并保持与一般 UM、common-b 双-small 和当前六人 SPE 目标的身份独立。
