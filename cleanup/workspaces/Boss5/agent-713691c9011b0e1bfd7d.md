## 独有内容和准确去向

PEER 的独有内容是“内部研究者的攻击/验证合同”，而不是一条新的算法或困难性结论：

1. 把每个子义务先拆为输入、量词、输出、已知障碍，再决定证明、构造、反例、文献或精确实验路线；
2. 将候选的边界攻击扩大到隐藏假设、同时守容、总位复杂度和外部定理条件；
3. 要求保留精确计算的实际输入与结果，明确有限检验不能代替一般证明；
4. 规定候选/反例/障碍按准确等级交给 Boss，带证据、异议和下一可检验步骤；
5. 规定内部 agent 不新建 Work 身份、不直接写 Git、公屏、私聊或共同登记。

这些内容应并入一个涵盖 `CLEANER/EXTRACTOR/MODELS/PEER`（以及本批其他角色提示词）的历史角色/同行边界资料对象，或作为 `历史角色提示词三件套` 的版本扩展；若改名，稳定对象 ID 不应被偷偷改变。原字节应进入与本批其余 prompt 共用的 evidence manifest，并记录两个冻结提交、blob、SHA、大小和“无数学 claim”的分类。
