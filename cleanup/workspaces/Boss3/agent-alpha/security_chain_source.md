# R2-LOCAL-SECURITY-INDUCTION-NO：两种一步安全值归纳均失败

输入是 CAG-MODEL：三名单位玩家、六主题共同有限目录、113名不同单位客户、固定均分、完整有序历史纯 SPE，允许所有历史依赖平局。本报告没有更改仓库 HEAD `8e214ad`。结论是下列两种局部接口为假；全局 `W >= (n-1/2)v_n` 及 `W >= n v_n` 仍未被否定。

## 1. 待检接口与反例数值

对固定背景负载 b、r 名剩余玩家，定义真正静态安全值

\[
v_r(b)=\max_{p\in\Delta(\mathcal S)}\min_{B\in\mathcal S^{r-1}}
\sum_Ap_A\sum_{x\in A}\frac1{b_x+1+c_x(B)}.
\]

对背景 b 后完整 SPE 的实际首动作 A，曾希望证明

\[
u_A+(r-1)v_{r-1}(b+A)\ge r v_r(b),\tag{Full-step}
\]

或只证明更弱的

\[
u_A+(r-\tfrac32)v_{r-1}(b+A)\ge(r-\tfrac12)v_r(b).\tag{Weak-step}
\]

以下113客户例在空背景、r=3同时否定这两式。实际首动作是0，实际终局与收益为

\[
z=(0,3,4),\quad u=(95/3,110/3,110/3),\quad W=105,\quad\operatorname{OPT}_3=113.
\]

匹配静态鞍点给出

\[
v_3(0)=\frac{1035446642}{32182199},\qquad v_2(\mathbf1_0)=\frac{10259}{318}.
\]

于是两个真实差分别为

\[
\frac{95}{3}+2v_2-3v_3=-\frac{571165576}{1705656547}<0,
\]
\[
\frac{95}{3}+\frac32v_2-\frac52v_3=-\frac{7739134297}{20467878564}<0.
\]

更短的非最优夹逼证书已经足够：p=(1,1,2,1,1,2)/8 保证 v3>=385/12；固定背景0后，令唯一剩余静态竞争者取1、2的概率为3/5、2/5，则 v2<=484/15。因而 Full-step 左差<=-1/20，Weak-step 左差<=-17/120。夹逼不假装给出真正最优值；上面的匹配鞍点另存于完整证书。

## 4. 尚可用的全局债务恒等式

在任意完整根 SPE 的实际路径上，令 r_i=n-i+1、b_i 为实际过去背景、t_i=v_{r_i}(b_i)。固定一个查询p，添加实际首主题作为竞争者使静态竞争背景集合缩小，故 t_{i+1}>=t_i；末位无竞争者，最佳回应给 t_n=u_n。

定义

\[
d_i=u_i-t_i+(r_i-1)(t_{i+1}-t_i),\qquad i<n.
\]

精确望远镜给

\[
\sum_{i<n}d_i=W-nv_n.
\]

因此目标弱桥恰等价于

\[
\sum_{i<n}d_i\ge-\tfrac12v_n.
\]

这项等价与单个 di>=0不同；本反例仅排除逐项非负的充分接口。末两人保底给最后一项 d_{n-1}>=0。

在113客户例中，t=(v3,v2,110/3)，首债 d1=-571165576/1705656547 为负，末债 d2=467/53 为正，故净债仍为

\[
W-3v_3=\frac{272790969}{32182199}>0,
\quad W-\tfrac52v_3=\frac{790514290}{32182199}>0.
\]

跨节点净债至少为-v_n/2仍是完整待证义务；本报告没有宣称负债总额存在任何普遍界。
