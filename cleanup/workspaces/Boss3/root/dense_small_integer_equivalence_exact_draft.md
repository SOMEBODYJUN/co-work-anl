# 正整数二次上界实例与一般不相关机二倍以下近似的等价性

本稿供主研究者整合到现有基础文件，不自行更新共享账本，不声称新算法或完整负面结论。

## 精确陈述

`UM-DENSE-SMALL-INTEGER-EQUIVALENCE-v1`。采用 UM-TARGET-v1 的二进制位复杂度、确定性、实际分配输出合同。以下两个存在命题等价：

1. 一般输入 `p_ij ∈ Q_{≥0} ∪ {∞}` 存在固定常数小于 2 的多项式近似算法；每任务有至少一个有限机器，`m≥1,n≥0`。
2. 在完全有限且严格正的子类 `p_ij ∈ {1,…,n²}`、`m≥1,n≥1`，存在固定常数小于 2 的多项式近似算法。

量化加强：若子类有确定性位多项式 `(2−1/k)` 近似算法 `B`，其中固定整数 `k≥2`，则一般输入有确定性位多项式 `(2−1/(2k))` 近似算法。反向是取子类限制，保留原改善量。

## 固定实常数的有理化

若算法保证 `(2−ε)`，其中 `ε∈(0,1)` 是任意固定实数，则取固定整数 `k≥max(2,ceil(1/ε))`，有 `1/k≤ε`，所以同一算法保证 `(2−1/k)`。这个存在性步骤不要求 ε 可计算，不把 ε 作为输入，也不要求从算法代码有效提取 k。反之 `ε=1/k` 已是合格常数。因此目标等价于 `∃k≥2 ∃A` 的可数命题。

算法的时间多项式及其指数允许依赖固定 k。本证明的小 n 分支使用 `m^n`，但只在 `n<8k` 使用，因而次数至多 `8k−1`。这确是固定 k 下的多项式；不声称统一于输入参数 k 的多项式，不声称 FPTAS 或有效寻找最佳 ε。

## 构造与证明

给一般输入 P。`n=0` 输出空分配。若每任务有零处理时间边，则逐任务选零边，输出值恰 0 的分配。反过来，由非负性，值 0 的分配必逐任务使用零边，所以这是完整的 OPT=0 判定。

以下设 OPT>0。若 `n<8k`，枚举至多 `m^n` 个分配，拒绝无限边，精确取最优。这覆盖全部小 n 边界。

现在 `n≥8k`。令 `ell_j=min_i p_ij`（仅对有限边取最小），并令

`L=max_j ell_j`，`U=sum_j ell_j`，`eta=1/(4k)`。

每任务有有限边，故 L、U 有限；OPT>0 排除所有 `ell_j=0`，故 `0<L≤OPT≤U≤nL`。上界 OPT≤U 来自逐任务选最小处理时间机器。取有理网格

`T_s=L(1+eta)^s`，`s=0,…,S`，其中 S 是首个 `T_S≥U` 的指标。

算法遍历全部这些 T，不需要知道 OPT。必有某个 T（第一个 `T_s≥OPT`）满足

`OPT≤T≤(1+eta)OPT`。

对每个网格 T 建立同样 m 台机器、n 个任务的完全有限正整数实例 Q_T。记 `H=n²`。若原边有限且 `p_ij≤T`，称为合格边，置

`q_ij=max(1,ceil(4kn p_ij/T))`。

对其余边，包括原来为 ∞ 的边和超过 T 的有限边，置 `q_ij=H`，并保留“禁止恢复”标记。合格边有

`1≤q_ij≤4kn≤n²`，

`p_ij≤T q_ij/(4kn)`，

`q_ij≤4kn p_ij/T+1`。

因此 Q_T 的全部条目都是 `{1,…,n²}` 中的整数，包括原来的零边现在变为 1。对 Q_T 调用 B；若输出使用任何“禁止恢复”边，则丢弃本次候选；否则将同一机器分配恢复为原任务分配。遍历完取原始 makespan 最小的保留候选。

下面证明至少有一个保留候选，且其质量足够。固定上述好 T。原最优分配的每条使用边均满足 `p_ij≤OPT≤T`，所以都是合格边。每台机器最多处理 n 个任务，故这一分配在 Q_T 中的每台负载至多

`4kn OPT/T+n`。

于是

`OPT(Q_T)≤4kn OPT/T+n≤(4k+1)n`。

记 `alpha=2−1/k`。B 的输出满足

`C_Q≤alpha OPT(Q_T)≤(2−1/k)(4k+1)n=(8k−2−1/k)n<8kn≤n²=H`。

任何使用标记边的分配，其某台机器负载至少 H，因为所有 q 严格正。上述严格小于 H 的输出因此不含标记边，必被保留。对其每台机器逐边恢复并求和，得到

`L_i(P)≤T L_i(Q_T)/(4kn)`。

故其原 makespan 满足

`C_P≤alpha(OPT+T/(4k))≤alpha[1+1/(4k)+1/(16k²)]OPT`。

置 `a=1/k`，有精确恒等式

`(2−a)(1+a/4+a²/16)=2−a/2−a²/8−a³/16≤2−a/2`。

于是 `C_P≤(2−1/(2k))OPT`。从全部候选取最小只会改善该上界。证明完毕。

## 位复杂度

固定 k 时，S 为 `O_k(log(n+1))`。原输入有理数的比较、最小值和求和均可用整数精确运算；所有分母乘积的位长至多各分母位长之和。网格 T 的分子分母长度至多原长度加 `O_k(log(n+1))`；形成 `ceil(4kn p/T)` 可用精确整数除法，且立即得到大小至多 n² 的结果。大于 T 的数值不需要按其值展开。

Q_T 有 mn 个条目，每条 `O(log(n+1))` 位，构造长度和每次 B 的调用时间均为原输入位数的多项式。网格次数为多项式。原分配恢复、标记检查及原有理数 makespan 的精确比较同样为多项式。小 n 枚举次数为 `m^{8k−1}` 上界，指数依赖固定 k 是允许的。

## 证明范围与负面路线

该等价性不证明任何一侧存在或不存在。其结论是：一般目标与“完全有限、严格正、数值至多任务数平方的整数”子类在存在固定二倍以下改善这一问题上相同。因此仅凭任意分母、极小正数、零最优值、无限资格标记或数值巨大不能得到一般目标的负面证明；这些特征已在明确位多项式归约中被消除，代价仅是固定改善量减半。

`ε` 非可计算也不是障碍：任何正实数包含某个正倒整数下界。若 ε 随输入趋零，或假设非标准无穷小，则已改变原固定实常数合同。逐实例严格小于 2 不能代替统一常数改善；比如标量上界 `2−1/m` 的改善下确界是 0。

有限坏例、配置 LP 间隙、局部修补下界均只反驳其明示机制，不反驳所有确定性多项式算法。确定性算法可数本身不提供排除所有算法的对角论证；任一固定实例都有可硬编码的最优分配，有限反例集合也可被有限表修补而保持多项式时间。仍需要适用全部算法的真正困难性论证；本稿没有给出它。

## 独立精确有限审计

同目录 `dense_integer_audit_draft.py` 不导入项目实现，只用 Python 标准库 Fraction 和整数。它检查 k=2,…,10000 的两项常数恒等式/严格上界；在四个 m=2,n=16,k=2 的原始有理实例上，各完整枚举 65536 个分配，独立算原 OPT 与舍入 OPT，再挑战所有满足 `C_Q≤(3/2)OPT_Q` 的分配，逐台检查恢复负载、标记边排除和 `7/4` 最终上界。实例包含零、∞、互异素分母和 333 位共同分母。另检查 n=0、OPT=0 及零/∞共存正 OPT 边界。有限检查不代替上述一般证明，也不声称求解 UM-TARGET-v1。
