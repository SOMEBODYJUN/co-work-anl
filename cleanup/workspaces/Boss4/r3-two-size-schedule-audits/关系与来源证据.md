# 原程序、限定证明与纠错的关系

本批两个新资源细化已有同机整比修复与fixed-work局部极小主对象，五主源分别数学/程序身份有实质去向，不重复授已成熟结论。阶段二判断如下，不改形式超图。

| 共同参与内容 | 关系 | 承重范围/证据 |
| --- | --- | --- |
| 同机全资格整数Q＋实际初态＋原子macro/tiny规则 | 一般精确修复证明 | q反迁合法、majorization/Ψ防循环、组合步数/精确M，非finite PASS外推。 |
| 原数学＋count-state原程序＋新count输出＋旧9f result0 | 实现/一次有限回归 | 类型置换商空间全部机器标号count-states、M/history非通用labels；结果全字段相同。 |
| 原数学＋独立labels程序＋新labels输出＋旧9f result1 | 独立实现/一次有限回归 | 不导作者core、全部actual labels内域/where真实去向，dict原文保留/字段相同，非作者同输入同路径承诺。 |
| fixed-work原族/OPT/三单动作＋review/code＋新fixed stdout/旧de9 | 限定single-move证明及实现 | 2225单动作/m3全59049actual，原stdout逐字节相同；程序不审多轮。 |
| 最终Hamming下界＋后续三件启动 | 对错误多轮外推的纠正 | 原单任务结论仍真，大最终改动与每批≤3相容，完整通式非本轮额外实验。 |
| 两尺寸neutral修复与fixed-work局部极小 | 结构子类正面接续/域比较 | Q=m/r1族有neutral+tiny路径；不能从单任务strict停滞说中性迭代失败，也不排异端/资格/固定支持障碍。 |
| 先statement重构→作者读后→canonical澄清→规范两run历史 | 来源/实现身份 | 旧review/rootrun与本轮三run分开，scratch别名未取字节，counts不是生产solver。 |

旧JSON/Boss2master只比较不重计done，来源字段/代码SHA实核；字节verifier不执行数学程序，不是新的数学认证。没有把有限参数扩大一般UM、把两个scope不同的state数量混成同一次穷举，或把支持公式核算当可行目标构造。

主问题仍需一般异端/共同资格/容量和未知调度保证；这里没有sourceNO/near2 hardness、源decoder或六人SPE推导，不为连通造边。Root依序推旧交付包前不称已推；当前包新对象自足无待拷旧包链接依赖。
