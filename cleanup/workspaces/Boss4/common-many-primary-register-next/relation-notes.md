# 本批关系判断

范围审查是三入口来源、65项身份和现有数学对象的scope/状态审查关系，不是把登记文字接成证明边。主定理链由定义、四预算、装箱、受帽纯修复、标签续局兼容共同推出；规范贪心另需原池/最大home重数、抽象交错势和原池重置。一般盒存在与旧DP及BOX-TO-2是联合推论，不能丢任一前提。

浅层势选择器的全称最优者性质和深度三反例分别保持；一般盒定理推广存在范围，却不推广那一个势规则。等重新旧同优化集是等价/性质强化和实现增量，非输入类扩张。MAX/RANGE是不同导入时间合同，当前有限软件是实现关系，旧有限审计仅有限检查关系。共单例接口是取补保偏离归约，二速度的位复杂度条件不得省。

示例资源与具体输入是来源/模型配对；与下界族/强弦定理是实例或有限核验，不是样本推导普遍结论。不与CAG半覆盖建倍率迁移。新增对象均非孤立，但本批不改旧图；正式超图阶段逐边建解释。
