# 完整终局见证弱gap攻击的关系判断

1. **可信菜单递推→联合终局见证。** 计数背景共享可实现终局集合，不共享所有历史的动作；z按目标终局另选行动，x保低收益孩子，t实现max-min门槛。既有可信菜单算法承担这套递归语义，本资源解释其联合w/根q/M1实现。计数净化候选并非其前提。
2. **联合MIP→固定锥精确认证是候选路径。** 前者只生成数值见证，后者展开所有有序节点并重做Fraction IC。固定锥精确对偶即使成功也不证明联合空间最优/数值不可行。本四旧与一新全部停在无incumbent，没有实际精确候选。
3. **真正弱gap与充分half分开。** 若每角色m u_i≥OPT−W，取最小收益给half；ROW和B(u_i)价格桥分别蕴含该角色弱gap。单角色正gap可以否这些更强辅助合同，但还不能自动反驳half；反向逻辑未证明。
4. **上一批个体比例目标不同。** first-floor研究u1≥OPT/(2m−1)，弱DAG研究actual主题收益与OPT−W。银行族否前者而不提供此目标反例，不能凭“weak”同名迁移真值。五人half另证不推出每角色净gap。
5. **数据是有限发现证据。** 四固定m/p/q/a/J+相对floor1e−6、两状态2两限时None，只有一个新代表性调用；与原报告除测量时间相同不叫全字节复现。结构尺寸检查验证实现合同，不证明精确不可行或任意输入界。
6. **标签/重复接口是适用边界。** 实际distinct J安全，重复J不是本helper已正确支持的合同；未来同覆盖标签候选须另对照主集合目录。它们限制可宣布反例的域，不改变保存原件或当前无候选事实。
