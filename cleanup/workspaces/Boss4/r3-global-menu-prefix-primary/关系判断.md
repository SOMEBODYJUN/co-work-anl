# 两个新对象的实质关系

本批逐源全读后独立判断，不导入旧图，不把共同使用LP误作推导边。现有五工作区审查只摘要登记固定G障碍；新障碍正文补自足推导及必要局部更正，计算资源承担尚未处置五主源的全部独有合同、输出和执行。

1. **末两人交集消去是定义/推导依赖。** 同一σ的S/Z/V真实行组合给G≥0及客户公式；固定G加R/L形成窄证书模板。三类型精确矛盾反驳该模板对全部类型的可行性，不反驳G恒等式、全部完整策略IC或half。
2. **V1浮点发现与解析障碍为发现/精确证明关系。** m3至10两次LP/人数的输出只属数值诊断；全m不可行由三类型与调和和不等式独立证明。m3活跃三行能精确恢复一个分离，但其他边际不因近似分数而自动精确化。
3. **V2是严格改变证书合同的扩充。** 它可重选G系数并加所有H_i，不受固定G不可行的直接结论约束；m3/m4有理证书逐类型非负加真实整行IC推出对应人数half。m5…13没有精确分离，当前数值失败不与别处五人half证明冲突，也不证明某人数模板不可能。
4. **矩形角点只是充分域有限化。** d0与正d分开，双仿射插值覆盖真实整数d/ell的放大域；未要求每个矩形点能拼成同一真实菜单SPE。m≥6路径即说明最坏保底与真实末两人不能替代早期后继理性，属于必要条件松弛分离。
5. **非均匀倒二价格的全实权定理不是V2。** 恰两名剩余的共同价格可由真实末位行支付，跨早期子树共同预算仍未闭。真实最优查询Q/L恒等式、UP双重和与静态安全桥各有不同目标，不能以本模板不可行转移反驳。
6. **旧OPEN由后续真实银行族更新。** 银行完整SPE的u1与OPT公式直接否定逐人OPT/(2m−1)从m4起的普遍保证；其福利仍half、聚合安全仍可付。该关系是后续纠错，非新的模型反例。原稿A-only错误则属局部代数更正，取ell0保原主结论；两种更正层级分开。
