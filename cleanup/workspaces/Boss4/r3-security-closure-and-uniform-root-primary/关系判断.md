# 本批三个新对象的关系判断

已逐项核量词、承重条件和证据，不复制旧图或用链接数量替代关系判断。三个正文当前均有明确实质关系；第三阶段可据下述合同建有解释的边，本批不另写共享图。

1. **引理实现重复检查归约，不证明候选。** 真实前缀UP候选定义双重和V_{i,a}，固定同一完整σ使A_a不依赖比较计数；本引理的单纯形分解将每个固定支持的最大违例归约到k个端点。它与334LP资源是“精确有限化→该固定输入实现”的关系。W归一化另需实际最后角色全部IC、非空客户类型及共同非负质量；不能用于缺真实末位行的松弛。

2. **新资源补已有UP有限探针，而非取代其精确性。** 原17实例Fraction核验固定客户；本四输入/三动作表改变客户质量，334浮点LP未导出候选，不带负最优值精确对偶。二者是同一开放目标的不同有限证据，不能合称任意完整策略已检查。LOCAL尾余量障碍只否定一种归纳支付，n=1的BG-UP纠错也不反驳这里n=m的根UP。

3. **重复端点与签名预算只有有限化启发关系。** 二者均在固定支持分配剩余副本；签名B使用凹性，Q使用线性且只量化最优支持，本引理使用真实查询仿射目标与全部支持。不能把其中一个预算成立/失败迁移成另一个。

4. **root弱报告是既有generic算法的另一实测配置。** 背景固定为六根真实尾（有重复），factor为12.5；它与all/13的32trace资源是同原码的不同目标域。v_R≥真正v_13，root正点最多反驳自由根菜单机制；当前全兴趣负点只给可行目标，不给全锥上界。all/onpath没有在本批运行。

5. **指定核反例与自由根菜单的反驳层级分开。** 旧13固定36客户的唯一stationaryπ及cap427/156否定指定核弱封顶；任意根混合29/12同例可付。新root探测未加stationary方程，不能拿旧反例直接否定它，也不能以本有限阴性修复指定核。独立根审计仍只认证旧固定输入。

6. **UP与静态安全桥的关系仅为各自条件推论。** UP借实际角色SPE行界Q≤mW条件推出(2−1/m)福利；静态安全桥用另一静态背景minimax和n·v目标。两者没有本批证明的蕴含边。完整终局推送先平均再取倒数的extra-one身份还有不同分母与已知局部反例，不参与端点证明。

7. **历史来源不是新定理。** security/README与工作室总README作为出处进入两个计算对象；八目录地图保后续阅读入口和开放合同，不代表当前已清理这些目录。源作者关于六研究员的陈述、两独审代码先验不改成本批新盲审或外审。五人half独立证书与六人half开放边界不升级任一安全桥。
