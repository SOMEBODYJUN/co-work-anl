# 新增五对象的关系判断

本批处于第二阶段语义清洗，不复制旧图或直接造第三阶段超边。以下关系已按参与者作用、共同前提与证据判断；Boss可按当前图阶段接续登记。

| 参与对象 | 联系及共同条件 | 证据和限制 |
| --- | --- | --- |
| 双设施双目录模型 → 新费用引理/短目录证明/守卫算法 | 定义实例化；均正权原子、固定覆盖、强制参与、含自身实现负载，两设施带标签 | A06.1、A08§1、A10.1及已清模型；不迁移到CAG。 |
| 新抽象配额/回应核心 + 新有限菜单 → 新守卫算法的完整补全 | 两个真偏离族不交，局部坐标极小达到，续局逐布局独立；有限F保证达到 | A7.1、A8.5；菜单min≥全部NE真实min，不能混用。 |
| 新守卫算法 + 全目录威胁 → 新候选坏环推导 | 非空纯菜单、固定全局ID、原低侧收益保护联合支持重客户及弦证明 | A8.2–4、A9.2–5；局部证明独立，通用2仍候选。 |
| 新候选坏环推导 → 新算法对任意输入成功 | 条件推导关系；若候选全称命题成立，回应图任意简单环核有双配额元素 | A9.1与A8.6；不把有限程序PASS当反向证明。 |
| 既有四种子程序/五输入计算 ↔ 新算法 | 实现和有限检查，原`make_menu/solve/verify`确用固定F、全目录威胁和一个核心扫描 | 旁读冻结程序及既有计算正文；本批不重跑，不证一般最优或全称完备性。 |

| 新费用引理 ↔ 既有二次费用等价 | 纯单调保持为共同基础；二次同客户同函数另由反事实和固定得全NE/CE/CCE等价 | A7.3与二次对象代数；一般递增不作整个混合谱保持。 |

暂无与顺序六提供者CAG、加权拥塞或无关机主问题建立合法推导/反驳/迁移边的证据；相同“收益/覆盖/候选”词汇不足以造边。来源关系可保五源到各正式对象；旁读源不是额外done。
