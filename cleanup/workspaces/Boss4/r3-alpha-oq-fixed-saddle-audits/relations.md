1. 跨分支总预算定义 + 静态安全值锐界 → OQ成立时的条件福利界：C_i≥v及W≥ΣC联合给W≥n·OPT/(2n−1)。一般定义已正式发表，本批不重复创建，不从有限报告补上未证动态上界。
2. 固定完整自动机 + 原p/Q精确鞍点 → 固定鞍点攻击域：全真实Γ与静态原/对偶约束共同保证变化质量时同策略SPE及同p/Q最优。该域严格限制鞍点身份，不等于整个策略锥，也不量化所有策略/查询/人数。
3. 原入口/真实helper/gzip → 一次实现复现：生成1766B原样输出，是本合同的有限实现证据。原SPE认证由同SHA既有全自动机审计另承担；本main没有重跑它。原p/Q上下夹值是精确鞍点证据。
4. 全兴趣单类型 → 精确可行零点：任意原形式策略IC0和每静态查询1/13直接证明点可行、C−W0。它只给最优值下界0；浮点最优0没有精确上证书，二者不合并成锥上定理。
5. alpha-one程序/JSON → 已有实际负载反例及全历史/标量计算对象：同SHA充分原执行，duplicate复用。其双37/66固定银行失败与OQ的原正余量可以在同一旧13输入并存，因为查询背景与资金不同；不存在反驳OQ或half的边。
6. 全p/逐人反例及指定锥正预算 → OQ的量词边界：全p失败使用非安全最优查询，逐人安全失败仍正总预算，特定锥/固定游戏正值又不全称。它们是范围比较而非一般OQ正证。
7. 完整策略不受限静态对偶/完整槽范数对象 → 不同未付接口：一个允许自由静态对偶与全树乘子，另一个有完整n槽背景的2n系数和协方差付款；都不能由本固定p推送规则的阴性认证或排除。
