# 四新对象的关系审读

本批沿用当前阶段二协议：已读map/README.md与档内map说明，三级图仍为draft-scaffold。以下给逐边可审的条件与证据；不运行map build，不为词同或图连通造边。

1. 鲜利润初始化与共同费用条件：真实actual-prefix源query及其每客户rho≤1 + 同一鲜利润F-FLOW/完整IC → BUDGET-GAP；再加未证F-BUDGET → M≤W；再加最优比较残源M=OPT−W → half。最后两步是条件边，不能只由鲜利润非负账推出half。
2. 局部均匀子集凸包：抽象概率行current支配 ↔ 包含current的uniform-subset混合；与真实coverer计数共同证明full/fresh SAFE/CLIP行适用。凸包 + 真正future续价给LOCAL-SUPPORT；HIT + 高价层积分才给TERMINAL-PRICE。该多前提关系不能简化成“局部actual均价控制终点”。
3. 正净券金额历史审查：SAFE DATA + 原正边子容量 + current≤beta u ↔ CONTROLLED-POSITIVE金额系统；严格future守恒给POSITIVE-MASS。该合同扩写前批SAFE的一段表示，保原shared先获关键提示/随后对稿的证据身份，不能当第二独立盲审或普遍cap证书。
4. 双份源因果审查：fresh INIT无past + actual-prefix reset支持 + SAFE/CLIP不增新边 → TIME；TIME + 全图HIT → suffix命中/价格。credible与root两种前缀证明是同结论的历史核验关系，不是两次新发现；full-O合法反例只反驳越域的TIME，不反驳half。
5. 与已有固定净列Hall钱包：本批概率/源时间为固定列P提供合法性和价格界，F-BUDGET另为只fresh源的充分费用条件。前者仍缺OWNER-NET，后者仍缺B_F≤W，互相不蕴含普遍可行，不能叠加预算。
6. 与同客户optional-common/变量p：源库存、分母与路由核不同，只有“各自需要一次同角色共同预算”的边界比较；没有已知不经额外证明的直接转换边。弱匹配的随机子集是另一抽样对象，不因“均匀子集”同词而建立推导。

四对象均有数学来源与兼容关系，不属孤立；本批已实际判断这些关系。正式超边留阶段三按以上共同条件登记。外部审查、新颖性及无条件六人half未认证。
