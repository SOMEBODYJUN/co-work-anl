# CAGN-TERMINAL-EXCHANGE 数学覆盖

## 条件交换路线

R-486 资源页只提供 README 导航和条件性主张。其可复用条件是：同一个完整有序历史纯 SPE 中取两个真实偏离/回复比较；两比较的终局多重集相同，并且背景负载、受影响客户组和其他组的负载变化显式相同。此时可把早期惩罚者与末位惩罚者的负载差写成一个二部匹配实例；若每个需要转移的惩罚者顶点都有满足负载失真等式的不同主题顶点，且匹配覆盖全部惩罚者，则交换后总收益等式保持，匹配证书可限制把碰撞自由 3/2 族扩张到更多惩罚者。

该条件引理不等于任意 SPE 都存在匹配。README 没有给出匹配图的完整顶点/边证明、惩罚者内部奖励与 reservoir 重叠的全量词，也没有完整六人 half 证书。因此只能复用为“在同终局、同负载条件下的条件障碍”。

## 有限审计的准确范围

`common_terminal_audit.py/.json` 只审计 14 个 literal cases 的 expanded-unit 算术；其结果不能推广到任意目录、任意人数或任意 SPE。`cf_m3p6.json` 是 m=3,p=6 的 ratio-one endpoint：保留完整动作图并在其全部有序历史上做 exact verification。`cf_m4p7_failed.json` 没有保留下来的候选，表示一次有限运行失败；不能把无候选、超时或浮点状态写成不可行性或最优性证明。

## 与现有 3/2 族的关系

三人碰撞自由族正式页给出任意 k 的存在型完整纯 SPE：路径福利 W=2k+2，OPT_{k+1}=3k+2，比例趋于 3/2；它不是六人半覆盖反例，也不声称所有 SPE 都实现该路径。R-486 只能作为尝试用匹配条件约束惩罚者扩张的入口，不能重包装成熟族为一般上界。
