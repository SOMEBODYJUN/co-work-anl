# CAGN-BR-SECURITY 数学覆盖

## 结论与量词

本组保留共同目录完整历史纯 SPE 模型的全部有序历史量词；有限探针和搜索结果只作证据，不升级为全称定理。

### SC-RED-FULL-INTEREST

设 P 是被全部主题覆盖的全兴趣单位客户集，|P|=lambda。把 P 从每个主题的覆盖中删除（反向加入则把以下差号全部反向）：任一完整终局中每位提供者都从每个 p∈P 得到 1/m，因此每位收益恒减 lambda/m，福利减 lambda；最优覆盖也恰减 lambda。对任一历史和任一单方偏离，P 的贡献对行动相同，故所有 IC/SPE 比较、真实续局和任意平局选择不变。若采用“加入 P”的方向，则收益加 lambda/m、W 与 OPT 同时加 lambda，静态 v_m 加 lambda/m；W-m v_m 与 OPT_m 同步平移。该变换不能制造或消除完整 SPE 反例。

### SC-CAP-IID

令 A,B_2,...,B_m 独立同分布于主题分布 p，令 f_B(A) 表示固定其余回复后第一位选择 A 的覆盖/安全观察。对称平均给出

    E f_B(A) = E[W(A_1,...,A_m)]/m <= OPT_m/m.

因此存在某个 B 使得其期望不高于 iid 平均，得到静态 m v_m <= OPT_m（或 v_m <= OPT_m/m，取决于 v_m 的定义方向）。这只是根静态上界；它没有给出任意完整 SPE 的福利下界，也没有把 iid 试验变成实际离轨续局。

### R105 有限候选与实际根探针

保留四主题整数客户、背景 0、旧路径 (2,1) 和末位菜单 [2,2,1,2] 的候选：旧 W=105，删主题后当前最大 SPE W=104。它是一个有限候选，不是一般 R105 定理。seed=420261024 的四主题、50000 次 actual-root probe 未发现新命中，仍是有限负证据。

可复用的 direct-cover 必要条件是：I=sum_R b、beta=max_R b、B=min_D b；若 B>I/alpha 且 qB>beta+floor(I/alpha)+r+1，则该前缀不可能是真实 SPE，因为末位 D-singleton 可严格偏离到含 q 个 R 的主题。另有 61 客户证书路径 (B,A,A,F)，收益 (9,13,13,11)，并有 V_(1,A)=9 < (3/4)13=39/4，击穿标量中继；这只约束该构造的中继，不替代全历史证明。

## 正式复用与缺口

复用共同目录完整历史模型、静态混合安全值锐目录计数界及 R105 直接覆盖/中继障碍页的原文条件；SC-RED 的 IC 不变性可直接作为变换说明。缺口是：R105 证明稿和 actual-root 探针均未给任意回复域的全称桥，不能把 105→104 或 50000 次未命中写成普遍福利/安全值结论。
