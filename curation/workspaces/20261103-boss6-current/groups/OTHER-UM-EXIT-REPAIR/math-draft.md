# 宏可退出时的共同匹配：定向修复数学草稿

本稿仅修复 `OTHER-UM-EXIT-REPAIR` 已定位的拒绝错误；正式正文候选为任务的两份输入审查页。不改冻结原件、实现和 Hall 其余论证。现行共同匹配和 profile 证明已充分，复用其成熟证明。

## 1. 定义域与单侧算法合同

机器为显式有限的 homes `H` 和一个共享 sink `z`。任务分成宏任务 `B` 与两两不交的私有组 `S_h`。每个私有任务只可在自身 home 和 sink 的非空子集上处理；宏任务的有限端点可为 `H∪{z}` 的任意非空子集。所有有限处理时间为二进制非负有理数。给定 `T≥0`、`0<η≤1`，每条有限宏任务 home 边严格大于 `T/2`，宏任务的 sink 时间没有此下界。

目标接口保持不变：确定性 `poly(输入总位长,1/η)` 算法返回 FAIL 或真实完整分配；成功时 `L_h≤T`、`L_z≤(1+η)T`，若 `OPT≤T` 则必成功。故 FAIL 蕴含 `OPT>T`；成功不保证精确 `T` 可行。

记 `b=|B|`、`h=|H|`。这里允许 `b>h`、`H=∅`。严格宏 home 阈值只限制留在 home 的宏任务数量，不限制直接退出的宏任务。

## 2. 模式、真实成本与共同完美匹配

各 home 的强制留 home 私有时间记 `F_h`，所有强制去 sink 的私有时间之和记 `F`。对一个可行的 home/宏模式或空模式，按原正文的真实覆盖问题生成实际撤离子集，精确最小可选私有 sink 成本为 `c*_{ht}`。复用保真实覆盖的 FPTAS，得到同一个实际子集及成本 `ĉ_{ht}≤(1+η)c*_{ht}`；`F_h+β_{ht}>T` 的模式不建边。

左侧放 `b` 个真实宏任务与 `h` 个 dummy，右侧放 `h` 个 homes 与 `b` 个互异 exit positions。宏→home 成本为相应 `ĉ_{ht}`；宏→任一 exit 的成本为该宏的真实 `p_{zb}`，无 sink 资格则不建该边；dummy→home 成本为空模式成本；dummy→exit 成本为零。退出位置是同一共享 sink 的组合占位，不各自获得一份 `T` 容量。求一次最小成本完美匹配；真实 sink 总负载等于匹配边成本之和再加 `F`，只在超过 `(1+η)T` 时返回 FAIL。

任意真实 `T` 调度中，每个 home 至多有一个宏任务。若其中 `k` 个宏任务留 home，则 `b−k` 个宏任务占 `b−k` 个 exit，`h−k` 个 dummy 占空 home，其余 `k` 个 dummy 占剩下的 `k` 个 exit。因 `0≤k≤min(b,h)`，这些计数对 `b>h` 同样成立。原调度因此给一个完整 `(b+h)` 阶匹配，且原私有撤离集合为每个选中模式提供同一个实际可行子集。

把该真实见证中宏退出成本记为 `R`，精确模式最小成本和记为 `C`，则 `F+R+C≤T`。算法求得匹配 `M` 的成本不大于同一见证匹配的近似边成本，因此

\[
L_z=F+\operatorname{cost}(M)
\le F+R+(1+\eta)C
\le(1+\eta)(F+R+C)
\le(1+\eta)T.
\]

误差只乘在可选私有 cover 成本 `C` 上。强制私有退出 `F` 与真实宏退出 `R` 各按真实成本计一次；没有逐 home 加 `ηT`，也没有逐 exit 复制共享预算。恢复时每个 home 恰选一个真实或空模式，每个宏任务恰出现一次，私有组不交，故产生真实完整调度。

所以 `b>h` 本身不能触发 FAIL。只有实际有限边图没有完美匹配，或最终真实 sink 总负载超过增广预算等经证明的条件，才触发单侧 FAIL。当所有宏都禁止退出时，才恢复旧 home-only 版本的必要条件 `b≤h`。

## 3. 两宏、一 home、一 sink 的精确可行见证

取 `T=1`、`H={h}`，无私有任务，宏时间表如下；破折号表示禁止端点。

|任务|home `h`|sink `z`|
|---|---:|---:|
|`b₁`|`3/4`|禁止|
|`b₂`|`3/4`|`1/4`|

两条有限 home 宏边都严格大于 `1/2`，故满足合同。这里 `b=2>h=1`。按行 `b₁,b₂,d`、列 `h,e₁,e₂` 排列，匹配成本矩阵为

| |`h`|`e₁`|`e₂`|
|---|---:|---:|---:|
|`b₁`|`0`|禁止|禁止|
|`b₂`|`0`|`1/4`|`1/4`|
|dummy `d`|`0`|`0`|`0`|

`b₁→h,b₂→e₁,d→e₂` 是合法完美匹配，匹配成本 `1/4`，真实调度为 `b₁` 在 home、`b₂` 在 sink，精确负载 `(L_h,L_z)=(3/4,1/4)`。home 边上的零是“无需撤离私有任务”的匹配目标成本，并不是把宏任务的实际 home 时间改成零。dummy→exit 也不生成任务或实际负载。该例严格反驳“`b>h` 推无完美匹配”，甚至已经精确 `T` 可行。

## 4. 保留的 profile 池结论

对显式不交 `H∪Z`、`Z≠∅`，每个 pool-enabled 任务必须在全部 pool 机器合法，并给 work `c_j≥0` 与正率 `a_z>0`，满足

\[
a_zc_j\le p_{zj}\le\rho a_zc_j,\qquad p_{zj}\le\beta T
\]

同时对全部 `z` 成立，其中 `ρ≥1,β≥0`。pool-forbidden 任务没有任何 pool 端点。其余 home/宏/私有组约定与上述共同选择相同。

设 `S=Σ_z1/a_z`，虚拟单 sink 时间设为 `c_j/S`。原 `T` 调度由下包络给出每台 pool 上 work≤`T/a_z`，故总退出 work≤`TS`；保持其 home 模式和宏去向得到虚拟 `T` 调度。正确的宏退出共同匹配故不漏掉 `b>h` 的原可行实例。成功得到实际退出集合 `E`，满足 `Σ_E c_j≤(1+η)TS`，homes 仍≤`T`。

按固定任务编号把 `E` 中每件放到实际当前负载最小的 pool 机器。令 `A=ρ(1+η)T`。每次放置前若所有实际负载均大于 `A`，上包络会给

\[
\sum_{j\text{ 已放}}c_j\ge\sum_z\frac{L_z}{\rho a_z}>
\frac A\rho S=(1+\eta)TS,
\]

与总退出 work 上界矛盾。故选中机器放前负载≤`A`，加上当前任务≤`βT`，每台机器在最后一次收任务后都≤`[ρ(1+η)+β]T`。完整资格保证这次选择合法。恢复按实际负载而非 `load/a_z`，其余 profile 包络、零值与位复杂度正文均保留。

该 profile 合同不覆盖任意资格、不完整 pool 或无界 profile；Hall 的同体积共同资格与 `q` 槽接口独立保留。一般矩阵结构提取与任意资格多预算恢复仍开放，本次修补不引入新的数学缺口。
