# 分数源路由的固定树条件出口

正式交付只含两项：对[原程序条件合同](../../../../../archives/customer-attraction/state/程序/分数源路由原递推的条件合同与缺失辅助件--程序.md)作定点数学修补，并原字节复用[自然捕获Bellman算法](../../../../../archives/customer-attraction/state/算法/自然捕获路由的Bellman价格与Hall取消--算法.md)。后者已经完整证明与原V逐式相同的有限DAG最小价，无须重新研究或用更广ARB算法冒充同一可行域。两资产现SHA见`coverage.json`的`assets`，数组每项仅含`path`和`sha256`。

## 递推现有的准确保证

固定同一完整历史纯SPE及actual路径P，提供全部actual-prefix真实query的**完整**终局和精确均分收益后，(1)–(2)就是一个确定的有限计算，不依赖`gen`。源客户R不在actual全程覆盖中，所以所有旧前缀对它都零覆盖；当前主题含x时，其真实分母才是1加当前query之后的coverer数，完整当前收益D也必为正。D须包含整主题所有客户，不能投影为源客户收益。

原V保当前1/c吸收，把其余质量集中给一个最低价真实后继coverer，并查询该后继在旧叶中的规定动作。新的query重新从**原actual前缀**读取同一原策略，不能继续上一偏离叶，也不能逐行改选另一份策略的有利终局。成熟Bellman正文已给下界、argmin达到及无共享容量时的线性合流。

因而原(2)精确给出在所限排列、逐源owner和自然后继路由中的最小整行金融费K星。所有来源先汇总同一query的吸收A，再仅用一次w=A/D。严格未来守恒与完整原IC给

\[
K=|R|+\sum_{i,a}w_{i,a}(u_i-D_i(a))\ge |R|.
\]

这是准确金融账，不是已经获得共同预算。目标K≤W+G要求同一方案满足

\[
\sum_i(L_i-1)u_i\le G,
\qquad L_i=\sum_a w_{i,a}.
\]

等价的IC税上界为$\sum w(u-D)\le W+G-|R|$。T最优时右端为$2W-\mathrm{OPT}_m$，若满足便充分推出half；half本身不承诺这份受限证书的IC税也已付款。

## 缺辅助件被分成两层

固定树层只需完整P、同一策略的完整Q_i(a)、精确pay和合法源域。源码未使用保存的`pref`，所以不能默认为`terminal_forced`自动补回旧前缀；辅助件若只返回后缀，合同就不成立。源码零收益的10^9只是哨兵，在合法tracked状态正D的数学证明中不出现。

外层有限遍历另需`gen`覆盖全部完整SPE树，或证明它覆盖本计算所需P及所有Q_i(a)的等价代表。完整历史终局全集算法只枚举可实现终局/路径并为各目标构造一份完整策略；它不枚举同一路径全部离轨策略。同actual路径的两份策略仍可能有不同D、F和规定child动作，故不能以每路径一个证书顶替`gen`。

## 三输入和相关成熟正文的去向

| 输入或依赖 | 本组实际处置 |
| --- | --- |
| 分数源路由原递推的条件合同与缺失辅助件 | 扩充最小合法query接口、接入成熟Bellman、补整行IC税和共同预算未证条件，并明确gen覆盖与终局证书的区别。原(1)(2)、原代码、缺件和原main有限域保留。 |
| 共同目录完整历史模型 | 只读精确引用；使用单位客户均分和全部有序历史SPE语义。相同覆盖不同标签不被合并，原main的集合目录域不扩大。 |
| 完整历史纯SPE终局全集 | 只读精确引用其完整证书与定义级核验；保其不枚举所有完整策略的准确保证。 |
| 自然捕获Bellman算法 | 正式第二资产，原字节复用；仅其固定真实query的条件最优性直接承担原V的数学出口。Hall取消和总费仍保该页未证上预算状态。 |
| SRC-CAP与任意子查询两证书勘误 | 只读引用并记录当前SHA；初始化容量不付incoming，FINANCE不自动投影成COORD，任意未来query不是原限定coverer路由。 |

原main仍仅n为2或3、目录大小4、人数3；先生成E再按其大小跳过的语义和缺旧运行记录均不变。没有运行原main，没有补造`enum_spe`，没有将有限域提升为一般共同预算证明。当前缺口精确停在同一方案的IC税/带符号行容量上界，以及原有限遍历辅助件的真实覆盖证据。
