# 2.5.1/2 临时协作域

本目录现在只有设计用schema，没有生产run、任务认领、定性结果或删除动作。运行、工作区与新公屏须按[操作设计](../research/CURATION_OPERATIONS.md)部署。详见[分步入口](../research/CURATION.md)和[程序规格](../research/PHASE25_PROGRAM.md)。

`schemas/classification-record.schema.json`只约束材料性质与调度记录，不是最终数学节点或超边schema。未来runs/workspaces属于临时机器层，不进入正式数学正文或研究上下文；有数学价值的产物须回写实际对象，交接完成后再退役临时设施。
