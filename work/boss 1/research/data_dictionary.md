# 数据字段、版本与经济含义

本轮截点2026-11-27（洛杉矶日期），来源发布日依原发布地记载。所有金额先核单位再作运算；亿元、百万元、千元不直接相加。以下词典约束专题、图与计算器。

| 数据/位置 | 单位、统计对象、时间 | 可用用途与禁止推断 |
|---|---|---|
| `data/gdp_quarterly_2026vintage.csv` | 单季实际GDP同比%，2021Q1—2026Q3，2026-10-20版 | 活动描述与回溯实验。累计同比不替代单季；修订后数据不称当时实时信息。 |
| `data/gdp_quarterly_2022vintage.csv` | 单季实际同比%，2016—2021，2022-01-18版 | 长样本拼接的旧段，重叠修订另列。网站迁移路径年份不是发布日期。 |
| `data/macro_china_pmi.csv` | 扩散指数，制造业与非制造业商务活动，月度 | 测方向和广度；50不是实际增速0的精确阈值。当前下载版无完整历史首发时刻。 |
| `data/macro_china_industrial_value_added.csv` | 规模以上工业实际同比%，月度/一二月合并 | 只作描述候选。供应商“发布时间”实际为统计月首日，不可当可得时点；一二月不拆填。 |
| `tasks/property_fiscal/property_releases.csv` | 金额亿元、面积万平方米，年度/前十月分别列 | 原发布水平长序列与当期可比同比并列；不同版本反推增速的差异保留。销售金额/面积是构成均价，不是同质价格指数。 |
| `tasks/property_fiscal/cities_price_202610.csv` | 70城新房及二手140行，环比/同比/年内平均指数 | 100为各自基期。等权平均不叫全国成交加权涨跌；昆明不能替所有房产城市。 |
| `tasks/property_fiscal/fiscal_releases.csv` | 亿元，一般公共预算与政府基金，中央/地方、本级/转移分列 | 土地毛收入不是自由现金；债务发行不当财政收入、再融资不当净需求。 |
| `tasks/property_fiscal/supplemental.csv` | 每行显式单位与时间：决算、发行、到期、政策、地方对照 | 预算、下达指标、发行、实付四阶段分开；福建到期本金与甘肃本息不可合并。 |
| `tasks/bank_research/regulatory_series.csv` | 按监管口径机构组，季度存量/累计利润 | 全国大行、股份、城商、农商不能只用平均数。LCR统计样本有限，不是全体小银行。 |
| `tasks/bank_research/statement_extract.csv` | 工行与兰州银行，统一百万元，2026中期/三季末 | 权益、CET1、RWA、拨备、逾期与现金分账。部分来源原表为千元，提取时转换。 |
| 银行输入JSON | 账面资产净额、已有准备、增量损失、资金流入，百万元 | 已净额入账的准备不再次抵扣权益。会计模型equity/RWA不是监管CET1比率。 |
| MA003收入消费 | 元/人，前三季调查收入和消费；名义/实际各有同比 | 包含实物和非银行到账，不是现金台账；均值不能解释分位家庭。 |
| MA008小微调查 | 2026Q3、7848有效问卷、支付宝活跃经营者框 | 当季样本结构6%公司/39%注册个体/55%未注册，服务84%；不套累计样本结构或全国企业权重。 |
| MA009股票回报 | MSCI China A Onshore，美元、含股息毛总回报，2026-10-30版 | 年历复利与滚动十年分列。不得改称人民币沪深300、净税费回报或所有个股。 |
| EQ001—003 | 人民币NET含股息年历回报；全国CPI月均2015=100及2025年12月同比 | 2016—2025累计实际回报约+13.78%；NET非家庭全部税费，月均近似年末，历史不推未来。 |
| JST审计修正 | 0/1危机指示、未知标签及6个宏观特征；固定时间切分 | 未知不当0，全特征缺失排除，部分缺失训练内插补。35+3行排除只在训练段，测试已见不重称验证。 |
| 计算器情景 | 元、月、年率、一次性冲击、区间、sourceId、assumption | 情景为可编辑压力假设。观测只提供方向/接口，不把宏观同比自动套入家庭或当概率。 |

## 缺失值和可用性

无逐平台经营现金、到期净缺口、银行逐平台敞口、逐地块完整成本和用户家庭合同，均不补“行业均值”。本轮用公开真实样本检验机制、量级和条件边界；缺失导致拒绝全国违约概率、逐城成交预测等用途，仍作主路径裁决。原始用户金额留空，由用户显式加载的合成例仅验工程。

来源与事件归并可复算：`python research/build_lineage.py`（从工作区执行，或在仓库根使用完整相对路径）。原47行证据及原核查状态保留，新材料使用新ID；统计文章的多个栏目、副本和官方解读不被重复当作相互独立的事实。
