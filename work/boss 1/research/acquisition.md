# 本轮采集与决定性缺口的处置

本轮先复用原包47条摘录、5份输入、工具内的检索/采集记录，再按承重问题定向查原发布。原47行的原文核查状态未被统一改成“已验证”。新来源、原始数字、复算脚本和阅读边界分别保存在source记录和专题目录。`source_lineage.json`将重复文章、同一统计事件和转载分开归并；组数不用于证据加权。

## 实际取得了什么

1. 统计局地产2019—2025七年原发布、2025/2026前十月、70城140条价格指数；财政2020—2025六年原发布、两期前十月、2025决算、2026预算及转移下达。地方的福建法定债到期本金、甘肃法定债到期本息、云南一次性收入与定南土地支出构成，足以检验“土地毛收入少多少就缺多少现金”和“2027必是统一到期墙”两项断言。
2. 统计局最新GDP、收入消费、10月活动与11月27日公布的前十月利润；央行10月金融数据的政府原稿转载。补了规上工业盈利改善、外需和实际居民收入仍增长这些最强抵消证据，没有只搜负面词。
3. 监管银行季度原附件和两个性质不同银行的中期、三季报，核资本/权益/资产净额/准备/关注逾期/流动性口径。国务院金融工作报告中的实际接管与资本补充进度单列，防止把“没有全国崩溃”写成“没有已经实现的机构风险”。
4. 原作者连续文章、研究摘要和历史真实数据库，分别保留分析动作、条件、失误和竞争解释。Pettis的日本银行危机历史表述、Batson早期销售判断和Wright不同年份价格叙述均接受反证检查。宏观观点不被机械转成概率输入。
5. MSCI官方股息再投总回报序列，修正“某日多数股票下跌推出十年普跌”的错位。中国月季活动实验使用真实下载面板，暴露了历史修订与简单基线比较失败。

## 访问失败怎样处理

北大小微报告PDF及摘要直接访问部分失败，实际只使用原机构搜索索引可见的摘要、方法和当季样本构成，明确没有逐页读全文。央行原域定向检索未取得目标完整原页，以地方金融主管部门原稿转载为替代，同源不计两份独立事实。部分官方网页动态加载或搜索快照旧，银行作者追到当期原始xls。对未获得完整中央平台退出原文的节点，仅以地方执行部门、政策研究和国务院结果交叉限定含义，不扩大为全国债权合同到期令。

实际查询、执行时间精度、结果与零结果在`research/searches/`和`acquisition/bridge-*.json`。专题未逐查询记录时分秒的批次保留当天日期精度，汇总登记时间不冒充检索时间。依赖顺序、反证链接与资料效用见各专题任务包。

## 缺口如何影响结论

| 未取得的决定性资料 | 本轮明确处置 | 能触发下轮修改的最小新证据 |
|---|---|---|
| 全国逐地块全部征地/开发/安置成本与履约/欠款 | 不给全国土地净现金跌幅；按毛收与支出两侧、地方实例判断 | 同县同地块净入库及对应已确权付款变化 |
| 全部平台2027现金与本金到期、续借承诺、债权归属 | 不给全国2027违约概率；政策退出与合同到期分开 | 一批同口径主体的季度未续本金和已确认现金缺口 |
| 银行逐平台隐性敞口和监管第二支柱个别要求 | 不把政府债或房地产总额分配给银行；公开资本线仅为参照 | 真实借款人清单、回收/核销和银行特定资本要求 |
| 全国贷款申请、拒绝、价格与企业需求匹配微观面板 | 不拆造信贷供求各自比例 | 同一批企业申请/拒绝及回款、投资资料 |
| 逐城可成交价与出售时长、用户家庭合同 | 计算器金额初始为空，情景可改；不自动执行买卖 | 用户实际合同、资产城市、挂牌成交/租赁可比样本 |
| 全量历史实时发布版本 | 拒绝把回溯活动实验称伪实时预测；不输出2027点数 | 有发布时间和历史版本的独立信息集及未使用留出期 |

这些缺口已改变可用结论的边界，并未阻止裁决主路径：调整已经发生，渐进承损与地区分化为首位路径，急性信用收缩是应准备的次位路径，有效收入修复须观察资金真正到账。
