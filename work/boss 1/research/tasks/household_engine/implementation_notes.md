# 实现、复算与适用边界

## 月内清算

1. 激活本月担保代偿，按合同确定本月到期本金、利息、费用；以公布路径和合同重定价日决定浮息。计算本月物价、收入及期初可用现金利息，结算此前已经到期的应收卖款。
2. 对仍持有的资产按各自年率及一次性水平冲击重估。金融总回报包括分红。无抵押的普通交易在交易日从证券账面移出已售份额，交易费一次扣除，净应收款在到账月进入现金。锁定/用途受限资产不能填补当下缺口。若证券已质押，整笔卖出且每笔贷款都明确允许同步解押时，委托锁定报价，交割前继续列为质押证券并维持合同逐月还款。成交日按此时欠本、当月利息、费用与可用补差结清；条件未满足，保留持仓与原债务。
3. 执行预先指定的减仓、出租或挂牌规则。挂牌确定等待时间；到交割当月才依据届时保守成交市价、折让、固定及比例费用计算所得。带押可过户时仅需自备净补差；不允许同步解押的各笔还要备足交割前结清本金、应计利息和费用。多笔抵押逐笔核销，成交当月不再重复扣本息。锁定、负权益补差不足、无替代住房或交通时维持持有，对正常候选排名记为动作受阻。相同月份的多套交割按输入资产顺序，各自已收现金可继续支付后项；可用不同挂牌月份编码次序。
4. 成交月移除该资产的租金和持有费，必要替代支出同时生效。收到当月实际出租收入后，依次支付基础与其他必要生活、持有与替代费用、各贷款本息、可选预算。普通还款后才从当月剩余现金扣除储备，执行提前还款，部分本金不能超过余额。未达最低额、预付窗口或费用等限制时保留资金，沿原合同运行，记录不可行原因。只填本金、利率和剩余月份时仍可算原合同；不会生成未经确认的提前还款或处置动作。明确输入零成本区别于没有输入成本。
5. 月末区分实际支付、未足额支出、未付合同本息。现金下限为零，未还本金留在合同余额里，未付利息、合同费及已约定的持有/替代费用列为应付款。未完成的一般消费预算不增列为新债。计划现金不足时记录三类缺口（偿债、必要与持有、可选预算）和时间，月末账面净值只供勾稽，正常可比净值与之后所有终值留空。没有替用户默认借款。

现金独立核对期初现金、全部现金流入与实付现金流出。净资产独立核对现金、在手与在途金融资产、实物估值、负债和应付款，另用上月净资产加当月收入、估值变动、成交价相对账面的变动、减费用、消费和尚未现金支付的新增合同义务交叉勾稽。合成样例全部 1,500 条路径的最大月末绝对误差分别小于 7×10⁻¹⁰ 元和 2×10⁻⁹ 元。名义与实际列分开。偿债比的分母为当月实际到账收入和租金，分子含定期合同本息和固定月费。收入为零且有到期款时显示 ∞。资产出售清偿和额外提前还本另列。

## 合同与策略比较

等额本息月供使用 rP/[1−(1+r)^(-n)]，零利率为 P/n，月末利息按期初本金乘合同名义年率/12。等额本金固定各期还本额；到期还本合同按月付息、末期结清。末期本金封顶。固定月供可录入合同约定，不足部分末期据余额结清。降月供固定余期、按新余额重摊；缩期限保留当前月供或等额本金步长，重算最后付款月。浮息只在合同重定价期重算。按本工具的月末预付约定，本月仍依原合同支付本息。

实际收入金额不明时由家庭填写，工程样例是持续标明的合成家庭。每个情景复用同一套外生参数。储备目标是逐月现金最低约束。触发挂牌与条件削减以期初可观察现金为依据，金融保护规则以当月可见的已到账资金、必要与已知到期支出为依据；计划行动没有未来市场价格信息。

合成示例产生 7×5×5×6×6×6×4＝151,200 项原始政策组合。固定 500 项默认上限。完整乘积小于上限时穷举全部。超限时保留基准，按维度轮转保留各类单动作；在预算内覆盖不同距离的维度配对，再在完整混合进位索引上等距加入组合。重复索引用整数组合去重，若有碰撞，用与样本空间大小互质的步长补齐。不会自动删去实际结果不好的候选。预付金额档同时考虑期初可用现金与按家庭已录入工资、必须支出、到期债务和储备求出的中性动作月预算，在真实情景的动作月再次核对资金。期初现金为 0 而本月已录入工资有结余时也能生成部分预付。在本样例中全部 32 个非基准单动作都可检索；未进入上限的组合没有获得最优性证明。

在每条路径均履约、守储备且没有违反执行条件的共同集合先确定，再求现金/财富/债务单目标优先序和最坏情景。Pareto 三轴为跨情景最低现金、最坏十年实际净资产、最高定期偿债比。共同可行集中按相同路径的最高十年实际净资产减本策略终值得后悔额，再取最大；相同参照在指定恢复路径产生复苏机会成本。十年真实终值为共同的元量纲。按每月现金、总债务、金融资产、房产、车、租金、待到账、净资产、未付金额、额外预还本金、毛成交款和可选支出 12 项逐一四舍五入至分，连同空值和截断长度比较全部情景的完整序列。结果相同的不同规则归入同一个 T 组；规则计数与经济轨迹计数同时保留。少于 15 个经济结果不同的合格方案时如实缩短短名单；所有方案均可筛选与导出。无合格集只列已跑方案中缺口较小者，并同时提示仍存在的合同或资金问题。待补资金为已观察现金缺口、储备缺口或动作执行资金短缺三者的最大值；它是观察到的局部缺口，不是保证十年成功的融资金额。

逆向试验逐点重跑额外工资折让、指定收入中断、交易延迟、房价、租金、联合折让，每个百分点或每一整月覆盖整个测试区间，记录之后重新可付的非单调路径。租售比较包括持有路径期末房屋价值和两条路径的现金约束，输出达到出售路径十年实际财富的最低起始月租及对应平均净租。预付搜索先以当月可用现金、余额、最低额和合同限制缩小集合，测试 50 个等距区间与合同端点，再对最高可行邻区间细化至分。间断或条件执行情形只应解读为“最高已测试可行额”。同合同撤去预付的重跑给出利息及现金差；两个不同行为政策的已付利息差不冒充提前还款省息。

## 示例的可证伪结果

- 28 万元期初可用现金、500 条确定性候选规则、三条无权重人工路径。全部规则有 416 种不同逐月轨迹；134 条在所有路径均可行，对应 105 种不同可行轨迹、6 种 Pareto 非支配、15 种去重短名单。125 条至少在一条路径出现资金缺口。结构延续、严重与恢复路径分别有 238、134、240 条可行规则。在未满足约束的项目中还包括动作合同或执行资金不足。
- 基准在严重路径第 101 月出现 1,871.73 元可选预算缺口。当月定期合同本息已付，月末未付合同本金仍约 51.53 万元，十年终值为空。独立保存的 18 万元期初现金压力用例在同路径第 26 月首次有 1,255.18 元计划资金缺口。人民币现金存量变化 10 万元会通过当期可用余额和利息路径改变耗尽月份，以上月份专属于这组录入。
- 在已跑且共同可行的合成候选中，S254 的最坏月末现金最高，约 24.69 万元。第 1 月出售权益组合、开始出租闲置房、削减可选预算并用现款结清车贷。S247 以十年实际财富衡量的最大后悔额为零，最坏现金约 11.44 万元；该方案采用阈值减持、出租、预付 7.75 万元缩短闲置房贷款期限及第 12 月挂牌车辆等动作。该比较只用于这组人工输入。
- 26 项 Node 回归、四笔共 146 期逐期 pmt/ipmt/ppmt 与余额对照已运行。固定来源为 vendor/numpy-financial/_financial.py，最大绝对误差约 2.09×10⁻⁹ 元。房产双抵押、延迟交割的第三个月手算为 240.50 元，与 JS 一致。质押证券 3,000 元、零利率杠杆 1,000 元、初始现金为零和必要生活 10 元的独立审计反例，允许且即时同步结清时月末为 1,990 元；延迟成交、合同费用、补差不足及禁止提前结清的分支分别复测。逐项数据见 checks.json、python_reference_checks.json 及样例结果。

## 运行与恢复

从任务目录运行。使用研究仓库的带 numpy-financial 环境执行对照。

~~~sh
node build_examples.js
python build.py
node --check engine.js
node --check ui.js
node checks.js
../../../../../.venv-methods/bin/python compare_python.py
~~~

正式报告可直接采用 scenarios.json，或执行 python build.py --scenarios 已冻结情景.json --output 指定计算器.html。冻结文件进入审查后，除非刻意重建三个合成试验设计，不要用 build_examples.js 改写正式研究参数。计算器 HTML 可复制单独运行，无外部字体、图表库、下载请求和运行服务。

作者环境有 Playwright Python 与 /usr/bin/chromium 包装器，但其实际可执行目标缺失；真实 file:// 浏览器操作未在作者环境跑通。独立审计已经指出多页隐藏 DOM 可导致绑定到错误的选择器；实现已改为卸载非活动结果页。verify_offline_ui.py 是供可用、获准的已安装真实浏览器执行的检查脚本。仅在真实运行成功后才会写出 offline_ui.json 与移动截图。其存在不能充当操作验收。后续版本审查需绑定实际 calculator.html 和 engine.js 哈希。
