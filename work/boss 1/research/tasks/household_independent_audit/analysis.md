## 离线界面与精确断点

`verify_packaging.py` 确认正式 HTML 内嵌计算代码、界面代码、演示家庭及正式情景均匹配。静态资源声明、样式及脚本未发现远程依赖，CSP 禁止网络连接。审计还发现旧界面在隐藏页和当前页重复使用相同选择器 ID，可能把切换事件绑定到隐藏控件。修订后的 `setTab` 移除非活动结果页的旧 DOM。这个修复仍需要真浏览器交互核验。

我对最终正式文件实际运行 `offline_replay.py`。Playwright 找到 `/usr/bin/chromium` 启动器，启动器尝试执行 `/usr/lib/chromium/chromium` 时报告文件不存在，子进程退出码 127。浏览器尚未创建，已观察交互、截图和浏览器下载均为 0 个。实际页面网络请求、控制台、手机排版、可见选择器、输入编辑、导入导出及图表重绘保留为待验。`offline_attempt.json` 保存实际命令、文件 URI、版本哈希、浏览器错误和待执行项目。`offline_replay.py` 的成功分支包含桌面、390/320 像素手机、CSV 内容、缺口截断、JSON 往返和截图操作，可在配有合法本地 Chromium 的环境直接继续。

```bash
cd 'work/boss 1/research/tasks/household_independent_audit'
../../../../../.venv-methods/bin/python independent_numeric.py
../../../../../.venv-methods/bin/python demo_replay.py
python verify_packaging.py --html '../../../formal/calculator.html' --scenarios '../../../formal/scenarios.json'
python offline_replay.py --html '../../../formal/calculator.html'
python assemble_review.py
```

界面启动受阻时返回 3，之前生成的数值和静态核对文件仍可读取。复现旧缺陷可另行运行 `../../../../../.venv-methods/bin/python preserve_old_failures.py`。
