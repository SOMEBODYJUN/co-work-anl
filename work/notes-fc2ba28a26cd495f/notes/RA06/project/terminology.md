# RA06 术语与记号对照

本表为工作记录；实际定义、例子和证明均已在两份正文对应位置保留。原文非标准拼写、原错式和新增订正分开处理。

| 原稿用语或记号 | 学习稿采用的含义与处理 | 正文位置 |
| --- | --- | --- |
| Lindeloff | 保留原拼写；标准拼写 Lindelöf。任意开覆盖有可数子覆盖。 | §1 |
| 第二可数 | 有可数拓扑基；度量空间中与 Lindelöf 等价，一般空间中仅有正向蕴含。 | §1 |

| T2 | Hausdorff 分离性。原稿重复两次均保留。 | §2.1 |
| 有限性 | 原稿实际用词保留，结合前后文解释为有限子覆盖的紧性；不静默改成“紧性”。 | §3.2 |
| 列紧 | 每个点列有收敛到本空间内的子列。 | §3.2 |
| 闭[Q001]性 | 引理“紧空间闭子集仍紧”清晰；括注字形保留候选。 | §2.4 |
| Hine Borel | 原标题拼写保留，学习章节采用 Heine–Borel。 | §3 |
| Q0,Qm | 二分闭方块；首次 Qm、半开右括号及后续差集选点下标分别保留原式并蓝色修正。 | §3.4 |
| E′、E^(n) | 导集及递归高阶导集；下降性的一阶情形另需 E 闭。 | §4 |

| (a,b)⊆R^n | 高维旁注恢复为坐标开区间的乘积，给出可数开长方体覆盖及不唯一例子。 | §6.5 |
| 局部连通 | 每点有连通开邻域基；用于开集 U 的分支为开，再用第二可数性计数。 | §7 |
