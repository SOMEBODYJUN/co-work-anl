## R019 的纸面位置与证明

P003-U06 中首维和 M 下标都是高干短右单肩，乘号后的 n 低而圆。P003-U07 右端的 k 有上回和下叉。P003-U07–U09 的列式首行、省写及 bu₃ 形末行位于 D 式与 P003-U10 之间。U10 的取 C* 式开头 M 下标确为同手单肩。“下文 P003-U10”给出了正确的纸面位置，两稿“同上文 D 式右侧”的回指与它对应。

P002-U22 给出 n 个生成元。用同组生成元分别决定第 i 个像和右式第 j 列，得到 n 阶系数阵，生成元可有关系。原尺寸 r×n 若 r 与 n 不等，便无法作 bIₙ−D 或取行列式。两稿保留纸面 r 形，蓝补证用 n 阶方阵。
