## 需要在初版恢复的原字、笔势和路线

- **p1 的代数数与整性。** 首行是 $\forall a$，范围和存在非零多项式的量词由有限维证明补出。集合大圈像 $O/Q$，整系数式后确有独立短竖和“不／为”、多项式样连字。原纸“$b$ 整于 $b$”的末字和前首同形，不能由标准定义代换字面。学习稿蓝区给出 $a_i\in A$ 的首一式。下一行圈符、首 $U/V$ 形和“根／和”须耐心保留。
- **p1 的尖点。** 题头后半较近“与参数”。“与”的上交竖与下回圈可对照 p7 U01。下一字符合“参”的数道下斜，末为“数”。原示意图的接点短勾、两支和右下孤点均留。分母 $x$ 上主笔与 $y^2$ 的 2 相似，旁有独立低弧，仍有分写 3 或原误写 2 的歧读。蓝区用评价同态的核证明正确分母为 $y^2-x^3$。U13 的两张重叠窄图显示，第一簇 $e$ 和 U/V 两段几乎同笔，第二簇为上下叠折，第三簇有独横和长钩，末簇为细上圈和下圈接右挑。图前无法逐字确定“也是这样的”或“是这样的图”。图证为 `audit/boss-recovery-2/p1-short-phrase-left-1200.png`、`audit/boss-recovery-2/p1-short-phrase-right-1200.png`。
- **p2 题头与上、下两条证法。** 题头第二字的离横、左折与右部弯斜可对照 p7 U02 “环”，前一字起势近彳，优先读“循环生成元”。保留 $n$ 后单横和邻点、第一次和式的上限 $n$、第二次上限 $n-1$、首一展开末的 $:0$ 形、求和中重复错用的 $a_i$ 及带余式式的两个 $g$。箭头由相反的两组原假设确认。第一组头近成员符，第二组右箭头清楚。也可与用之间有疑似“以”的短弧。图证为 `audit/boss-recovery-2/p2-title-first-two-1200.png`、`audit/source-units-800/CA07-P007-U02-800.png`。
- **p2 U05 的三字语尾。** 第一个笔组顶有紧凑厚点及弯折，下面另出小回钩，近“生／为”。第二簇左有小旋圈，中央高弓与大斜捺相交，较像 U14 后段的“成”。U06 的“有”是一长撇过横后下连圈，少这里的大交叉。第三簇左部笔尖大折，右边两竖间有叠圈，较像 U14 “一组”中的“组”。U06 的“限”有左侧独立竖和右部曲挑，U14 的“元”则起两平划、没有叠圈。由同手比较将本轮初看“为有限”改为原形“〔生／为形〕成组”，意思是前面的幂作为 $A$ 模的生成组。该词的首字仍保留小疑。图证为 `audit/source-units-800/CA07-P002-U05-800.png`、`proposals/ca07_math/recovery/crops/p2-U05-tail-1200.png`、`audit/source-units-800/CA07-P002-U06-800.png`、`audit/source-units-800/CA07-P002-U14-800.png`。

## 蓝色论证的复核

| 学习块 | 复核的关键步骤 |
| --- | --- |
| 006、007 | 有限维给非零关系。代数整数的求根多项式须首一，$1/2$ 排除仅用整系数的读法。术语表给结构同态、有限型、有限模、湮没子及商环。 |
| 010、012、014 | 用首一式逐次消掉最高项，次数严格下降，适用于有零因子的交换环。唯一性由首一式与商差相乘的次数给出。归纳对所有较低幂闭合，带余式路线在 $b$ 处求值，两个证明均给双包含。 |
| 018、024、026 | 矩阵第 $i$ 行展开 $bu_i$，$n$ 为生成元数，允许生成元有关系。伴随式给同时湮没，$A[b]$ 的情况用 $1$ 的展开。中间环 $C$ 保证乘积封闭与单位在模中。一般 $M$ 的逆向用忠实性和 $M^n$ 上的标量矩阵作用。 |
| 029、031 | $w$ 例的两条乘积式确定矩阵缺格。参数曲线从首一余式奇偶幂独立得到核，$t=t^3/t^2$ 且 $t\notin k[t^2,t^3]$，以首一式证整。保留奇点的局部环论证。 |
| 034、036、038 | 模作用下降前检查代表元，结合律、单位和分配律逐一继承。全模湮没子商去后忠实。算子模区分多项式与向量的实参，评价核是多项式环中的理想而非像环中的零化子。 |
| 041、043、045 | 可分别降低每个因子的指数到固定有限范围。模有限推出代数有限型，数值系数沿 $\iota(A)$ 提升至 $A$，不以单射为条件。代数整数的和积应用有限中间环，首一方程的根先放进由系数生成的有限环再接一次有限模扩张。 |
