## 附录｜八处发现及落字

### V2-F01　首加号、次项中隔与末下标

归属 CA07-R008。源单元 CA07-P001-U25。P1 U25 全式，从 b^n 的首加号、a₁b 次项上位组及中隔，到实末加号和 a 的末下标。

T013 第71行、S005 第26行均为 `b^n+a_1 b^{n-1}+\cdots+a_n=0`。T-V003 第75行已有「中间只有很淡的斜点」。S006 第38行只写「原次项高位的角折、点与弯笔按系数序次恢复为 $n-1$，不视为清楚的独立数字。」这里的高位组和中段斜点是分开的两处物理墨。

首加号形为隔开的薄横与长斜干，按相对位置读 +；次项高位组后一淡斜、一稍高远针点（针后有近透明细拖丝），中隔前无第三组加号，末 a 左宽横实穿长竖。末 a 的低字有左短鼻、圆肩及开底回卷，较近草写 n，异于同式高 n 的高硬起笔，也不同于末 =0 的左圈边长下伸。当前 T013/S005 均排 +\cdots+，T-V003 已有‘中间只有很淡的斜点’但未区分合计两枚原加号与补排加号，也未限定末 n；S006 现仅标次项高位形。

候选及差异

- **首一关系。首项后是留白两笔的加号；早晚加号之间次项后只有疏略笔；末系数字母较近低写 n。** 支持证据为首项右细挑靠向长斜干但停笔有白，位置在 b^n 与 a₁b 之间，足以作为书写分离的加；末项左横与竖真正交，余空一淡斜、一远针。末下标左短鼻直接接圆肩，下部杯口开放，像压低 n 的肩。 限制为末下标右尾内回比同式高 n 更圆、更长，读作 n 的原形置信度低于高 n；中隔两笔也没有全写三点。
- **把中隔行尾排成 `+⋯+` 的规范读式；末系数低字可视作未闭 0。** 支持证据为多项式系数可以按次数降编号，此处常数项也可记 a₀；末低字有回卷开口，特宽字体下可与末 =0 对照。 限制为没有第三组交叉或分笔加号；低字左短鼻与右卷之间无 0 的对侧整边，区别于同式末 0 上圆连到左面较长独边。常数项地位不能选择 n 或 0。
- **把疏斜和针点作次项高位尾，而中隔空缺。** 支持证据为针点的浅拖丝与高位捺一样细。 限制为两枚远离整个高位组且降落至基行附近，组内前已有更高的独点；省写多项式相邻项的位置恰在这里。

黑层最贴近原迹的办法是首后 + 和末前 + 各保一处；次项后按实形留淡斜和远针点。加号虽可读，首处精确形是分笔，有可见白隙。次幂 n−1 和低写 n 均明确标为较优恢复，记录末下标可保开放回卷而不裁唯一形。

- **正向检查** 原式的位置次序与首一关系一致，n−1 可由此及后文下降幂；以 a₁ 至 a_n 顺序编号时 a_n 表常数且没有冲突。另一种以幂作编号的规范可用 a₀，但不能据此回写原页。
- **反向检查** 把中隔细斜或针点任一强作附加 + 缺配对的相交/近接纵笔。把末字定为 0 也需要解释为何整个左圈边消失。恢复即使成立也不说明所有省项原来逐项写出。

建议落入对应目标

- `CA07-TRANSCRIPTION-013`　建议黑式为 `$b^n+a_1 b^{n-1}\text{〔一淡斜、一远针点〕}+a_n=0$`。同段说明首 + 分笔、末 + 交叉及末下标短鼻、圆肩、开卷并按 n 读。亦可留印刷 `+\cdots+` 但明确写中隔前的 + 是引入的排印符。
- `CA07-TRANSCRIPTION-V-003`　保次项高位角、点、弯，现句「中间只有很淡的斜点」改明两枚中隔墨；首项后横斜分开，末项前相交；常数项下标以 n 统一时说明未闭 0 是原形对照。
- `CA07-STUDY-005`　采用与 T013 相同的黑式、首末加号及 a_n 局部限定。
- `CA07-STUDY-006`　接第38行高位订明中隔是另两墨，原首末加号如何形成；概念公式的第三个 + 或以 a₀ 编号仅属蓝规范。当前 T013 和 S005 的 `+\cdots+` 均不得用未说明的第三个原加号来解释。

### V2-F02　低逗后的双隔笔

归属 CA07-R012。源单元 CA07-P002-U14。P2 U14 自 1 的低逗右侧至 b^{n−1} 左侧，远在两稿夹注的‘是’之后草写位置之前。

T022 第103行、S011 第81行均排 `1,\ldots,b^{n-1}`，夹注只在后面的生成语句交代恢复范围。原列表之后的字组的说明已在当前稿。

1 后有低斜逗，逗右先一向右上渐淡挑，接一较粗的短低斜；两稿写 1,\ldots,b^{n−1} 并局部形注‘是一组生成元’，未记逗后与 b 前的两隔笔。

候选及差异

- **1 后的粗低斜作逗；中隔另是一淡上挑、一略粗下斜，二者一起提示连续序列；b 前原无另一逗。** 支持证据为1200 见第一低斜与 1 距近，长度及垂向落底较像本行前一逗；第一中隔由暗根向右上渐淡，第二在近高度沿右下收；至 b 大段白。 限制为两枚中隔位置不同，不能把它们说成标准印刷省略号，也不能将第二点判断为与前低逗完全同形。
- **第一挑作省略，第二粗短斜并列作为后一逗，标准逗隔整个序列。** 支持证据为第二较粗、单独成笔，位置在中间空白右端，具一定分隔功能。 限制为它在较靠第一挑的中位，与 b 往前仍有大片空白，且呈向右下短扫，不像前低逗斜竖，因此不足以将 b 前第二逗当作独立原字符。

两稿可保原低逗和中隔两形，或印规范列记并一句标后逗的排印性。
