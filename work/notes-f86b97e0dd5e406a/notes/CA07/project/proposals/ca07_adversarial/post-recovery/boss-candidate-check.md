# CA07 恢复后新增候选的独立核验

本轮核验 8 组异读，重开 38 张实际使用的原生 800 或 1200 dpi 图。7 组接受一项读法，其中 6 组依据同手字形及本行位置作上下文恢复。图前短语保留未决。每组的正反检验、原坐标、实际图路径和 SHA-256 见同目录 `boss-candidate-check.json`。本轮范围为这些新增候选。

| 范围 | 结论及主要笔形 |
| --- | --- |
| R022 · P003-U12 | 接受「（找一个自然的方法）」。自有单撇与目样框，框内有相挤的厚转。然见左部两短横、右部交枝及独高点、底部连钩。P5 两个可对照的「个」均由上方开折和独垂构成，支持将这一行此前另有起笔的长弧解释为贴连的「一」。 |
| R005、R052 · P001-U12–U14 | 「的表示」为优先候选，仍未决。上横交斜与下方独立回折支持表。首 e/U 及末端两团可照该读法归并，首团和同手其他「的」有差别，末高环和下圈与前一主笔隔开。尖点图仍按两支、左浓墨、右下孤点记。实参数式支持图义。 |
| R002 · P001-U08 | 纸面接受「不可约多项式」。「不」与同页 U19 的「不」同形，「可」有左中小圈和右钩，随后另有纟样折和右大包弧。集合的正确定义另要求同一个首一整系数 $f$ 满足 $f(a)=0$。$2x-1$ 在 $\mathbb Z[x]$ 不可约而其根 $1/2$ 并非代数整数。 |
| R022、R030 · P003-U12、P005-U01 | 两处法右下长降以去的厶末点归属，括前及黑字短句末皆无需另录逗。两处长笔都相对于一个同样的去部下折右移，笔端圆重。P4 的 w 后和 P2 的 n 后可辨逗号都短且向左下锐收。 |
| R032 · P005-U07 | 红问读「1 哪来的」。哪的左口及右部深竖、来的两横与穿中竖，以及「的」的右兜笔均可对应。原问的 1 由实际取 $M=C$ 且 $1_C\in C$ 给出。一般忠实模的逆证仍用零化子。 |
| R047 · P002-U01 | 题头读「循环生成元。」。首字左双斜和右眼支持循，次字的高短横、下折与同手「环」相应。当 $T$ 的作用定义为乘 $b$ 时，$A[b]$ 作为 $A[T]$ 模由 $1$ 循环生成。 |
| R019 · P003-U06 | 首维保留 r 形。右只单上挑，同 P2 的 r 较近，和 U07 明确 k 的双出枝有别。数学矩阵尺寸由生成元的行列数定为 $n\times n$。 |
| R017 · P003-U04 | 接受「线性：」的连笔读法。首字和 P1「曲线」的线都有高短横下回卷、右部长交叉。次字有长竖旁，右侧由上斜落成横折后再转，分笔更支持性。 |

R023 的窄框中只见一枚黑点。保留该点的原位和独立性。恢复阶段的五份冻结文本及 39 张索引裁图继续按原字节存留。
