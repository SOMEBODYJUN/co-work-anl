合并后的第一份快照里，R022 的说明引向第二页的具体长除原行，现有来源无法直接支持这句，我当时保留了一项发现。当前实际核对了 `R022.problem`、`R022.backward_validation.result` 和 `I022.description`。三处把该句限定为数学判断。若把原分式解释为在原环中乘 \(\det(C)^{-1}\)，则 \(\det(C)\) 须为单位。首一长除靠首一项逐次消去最高次项。譬如在 \(\mathbb Z\) 中取 \(C=(0)\)，\(\det(C)\) 无逆，仍可用 \(f=T\) 对 \(g=T^2\) 作除法，得 \(g=Tf+0\)。蓝注所用伴随恒等式亦不需这个逆元。R022 的候选、取舍和直接来源保留，先前这一项发现已关闭。见[修订前确认](pre-fix-check.json)和[三字段修订记录](../../../audit/second-pass-4-merge/R022-wording-erratum.json)。
