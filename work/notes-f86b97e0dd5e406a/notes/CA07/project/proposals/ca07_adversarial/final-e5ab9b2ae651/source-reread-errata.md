# CA07 终审原图重读的两条勘误

本轮源先记录的原字节保持冻结。以下订正两处 400 dpi 分区粗记，依据本轮实际打开的原 PDF 原生图及原笔对照。两份正式正文相应位置已有保形说明。

## P1 商括内的末幂

- 本轮 400 dpi `p0001-r2c1` 的粗记将式子写成「含 y²−x³ 的括号」。同页曲线行 `CA07-P001-U11` 确有连续双弯的 3 形，商括内的末幂是另外一处墨。
- 回开 `CA07-P001-U15` 的 800 图及商括指数 1200 图。右侧 \(x\) 上的主笔由圆弧右鼓后向左下回，再以细尾向上挑，与本括 \(y\) 的 2 形同型。其下有一枚独立短弯，两笔之间有白隙。可比较「2 形加独立弯」和「分段的 3」。U11 真正的 \(x\) 高标是连续的双弯，U15 的高笔已收，低弯另起，更支持第一种。在 P1-r2c1 处改读为「含 \(y^2-x^2\) 的括号，末高 2 形下另有独立短弧」。
- 代入 \(x=t^2,y=t^3\) 时，\(y^2-x^2\) 映为非零的 \(t^6-t^4\)，\(y^2-x^3\) 则映为零。核仍须由首一除法和奇偶次数区分来证明。T009、T-V002、S030、S031 及 R006 已把这两处原笔和规范同构分开，无须改正式位置。

## P2 设有限生成元式的末低标

- 本轮 `p0002-r3c1` 粗记为「Auᵣ」。回开 `CA07-P002-U22` 的 800、1200 图，低标起干直，连接于右鼓圆肩，圆肩较长并向下收，末尾另有句点。相较 `CA07-P003-U06` 第一维 \(r\) 的高干和短平右挑，这里像带下降右边的 \(n\)。同页 `CA07-P002-U13` 的 \(n\) 同样由起干接高肩再落下，虽倾斜更大；`CA07-P002-U03`、`CA07-P002-U04` 还提供同手 \(n\) 的斜弧写法。
- \(r\) 和 \(n\) 都能作有限列的末指标，数学证明本身不能排除任一命名。这里以低标右边实际向下的弧和同手比较判 \(n\) 较近。把粗记末部更正为 \(Au_n\)。仍保留 \(Au_1\) 后的逗、短横和孤细迹。T027、T-V010、S015、S018 和 R015 的现有排写一致。
