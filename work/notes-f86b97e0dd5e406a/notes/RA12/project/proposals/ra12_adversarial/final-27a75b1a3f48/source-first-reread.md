# RA12 原图先读

这是固定三人组中非作者对抗审阅者对冻结版的新一轮独立先读。我此前参加过本篇初读、逐源裁图实查、恢复、第二遍和早期终审。本轮先逐张重开 7 张 400 dpi 整页、42 张原分区，以这一轮实际所见录下位置和字形，再打开冻结双稿和台账正文。此前记录只作为后续对读资料。
