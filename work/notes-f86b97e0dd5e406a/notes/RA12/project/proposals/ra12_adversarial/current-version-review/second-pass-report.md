## 对抗检验

- 开覆盖引理先由片内连续性得到相对开原像，再因各片在全域开而取并。闭覆盖拼接依赖局部有限性，可测拼接依赖可数性。局部有限可以由环带外的任一有界邻域检验，累积球不能替代环带。页末孤句只允许可数覆盖语境的补充说明。
- 简单函数按互不相交值层计算损失。取两个互不交正测度块，紧闭子集均等于对应值层，正确损失是零，原裸 $E$ 构成的两项差集之并却等于 $E$。这是原链出错的反例。另一个独立排印问题是原求和符号下无下标。
- 用几何预算得到共同闭集，若用低位 $2k$ 当分母则级数发散。有界化先排除两种无穷值，代 $f=-2$ 检验保号逆变换应使用 $1-|g|$。Egorov 三处待填用相同分额，第二处已知 $m(E)<\infty$ 后以好集测度给下界。补集不交可使次可加取等，严格总损失需要三项分别严格小于所给预算。
- P5 两条逐笔错误与校读分开。延拓输入须属于闭集 $E$ 上的连续函数，非空 $B$ 强制分离函数允许取 $1$。外测度段实际停在“分”，从可测分隔推出相加性只给充分性。反向 Lusin 需要以近似闭集的可数并覆盖全测度，再用 Lebesgue 完备性处理零测剩余。
- P6 失配尾集测度由可和预算控制。对 $E$ 取补把“每个阈值后总有失配”改成“存在阈值后始终相等”。只在偶数项失配的点可辨两种并交，单点零测失配反驳删去“几乎”，移动尖峰反驳将最终逐点相等强化成统一阈值或一致收敛。
