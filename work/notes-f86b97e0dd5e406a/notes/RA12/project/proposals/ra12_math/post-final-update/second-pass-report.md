## 数学正反复核

| 段落 | 推导与反测 |
| --- | --- |
| §1–2 | 外正规开集 \(G\supset E\)，\(m(G\setminus E)<\varepsilon/2\)，对其开区间分支的有限总和截取误差小于 \(\varepsilon/2\) 的有限并 \(U\)。两侧误差受 \(G\setminus E\)、\(G\setminus U\) 控制。反例 \(E=(0,1)\)、\(U=(0,100)\) 说明单侧差条件不足。对称差作用对象是集合，编号规范不改变集合。 |
| §3 | 开覆盖把相对开逆像提升为环境开集，其并为全局逆像。局部有限闭覆盖改用闭逆像，环境闭且仍局部有限。可数可测限制的逆像用迹 \(\sigma\)-代数和可数并。删去局部有限时，收敛列空间上的单点覆盖给逐片连续但全局不连续的反例。 |
| §4 | 有限测度下按误差 \(1/r\) 用坏尾集递减至空，把小尾界按几何数分配并用 \(N_r\) 取得统一阈值。\([0,\infty)\) 的 \(\chi_{[k,\infty)}\) 说明无限测度的全局推广失败。 |
| §5.1–5.4 | 简单函数取互斥值层与紧集，通过有限闭拼接和分片差的可加性成立。分别取 \(F_k\) 得共同闭交且几何损失严格小于预算，首项严格已够。\(2k\) 给调和系数，逐点收敛的 \(x^k\) 也不足。排除无穷值零集，量化有界 \(g=f/(1+|f|)\) 一致逼近，连续逆 \(g/(1-|g|)\) 成立。以 \(f=-2\) 反查无绝对值的原逆给 \(-2/5\)。 |
| §5.5 | B1 从共同闭交同时得到每项的限制连续；B2 的好域测度严格下界等价小坏集；B3 由内正规取在好域的环境闭 \(H_\delta\)。两个补集的次可加先用弱号，再由三份严格小份额合成严格总界。在互斥补集时次可加处可等号，故保真正稿原严格号并保留单独订正。 |
| §5.6 | 环带含零点且局部有限，\(E\cap A_k\) 各有限测度。所取环境闭片局部有限，闭并与限制连续成立。累计球覆盖有任一点反复出现在无限多个成员，不能替换环带。 |
| §6–8 | Lusin 逆由可数闭并除去零测集，闭片连续给 Borel 逆像，完备性给剩余零集的可测性。Urysohn 的二进阈值开集与 Tietze 的 \(2/3\) 余差几何级数闭合，无界延拓须在可能碰到 \(\pm1\) 的闭集上压缩，再取逆函数。Tietze 反推分离靠闭拼接和截断。外测度旁注的可测分隔通过 Carathéodory 给充分性，不能由残句推出无条件必要。 |
| §9 | 截断量化给逐点简单逼近，极限可测。逐 \(k\) 以全空间延拓、失配测度的几何尾界、相对于 \(E\) 的 De Morgan 和量词否定得到 a.e. 最终逐点恒等。偶数项失配的点可检出错换并交。点态阈值无法全局统一，连续三角尖峰给直接反例。反向的 a.e. 连续逼近依 Lebesgue 完备性推出可测。 |
