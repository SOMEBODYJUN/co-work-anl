## 整页观察

| 页 | 所见 |

| p0001 | 标题姓氏看近 Littewood，上半三条分别落在开区间并、连续和逐点一致。例题条件与“间”附近有右弯收笔，对称差式里左圆笔多一个，内并号等号之后的下限字位主要是一点。Lemma 左半是 \(f:X\to Y\)，Y 与下一 \(X\) 间有独立笔组，下一行明写存在量词。下半“注意”之后有一组左挑、点、钩形组合，另有逆像的两条公式和无限个、局部有限的限制，最末落在“要求可数个覆盖”。 |
| p0002 | 顶部 Lusin，\(f\) 条件右端见“则”，闭集、差集测度与限制同在定理。有限层证明中 \(f\) 左后有上下两点，分块一行可见 \(X_i\) 而旁行用 \(E_i\)。内逼近姓氏末段看近 Lebegue。中下连式写了两处整域 \(E\)，并号、和号和圆弧不完全对称。最后明写“对所有 \(x\)”。 |
| p0003 | 顶行先 \(F_\delta\) 后 \(F_k\)，\(F_k\) 上方有闭记；第一处误差分母 \(k\) 抬高，末处 \(k\) 较低。公共交集及其外括成行。两处“有界”分行，接着模值归一与直接写的带平方逆式。两处 Egorov 姓氏的中部草写有别。底右在不等式后另有黑横竖组合。 |
| p0004 | 开头把 Egrov 引入原证明，接小集合 \(G\)、B2 和“一致 \(f\)”。下一次取集是 \(F_\delta\cap(E\setminus G_\delta)\) 的子集，估计右边另有 B3。之后帽 \(F\) 的要求、三误差与两段集合运算在中部。末段原式用两球之差，写“但在 … 上的有一个闭集”并回指局部有限拼接。 |
| p0005 | 开头 Lusin 逆向提示，随后正常空间的等价命题，延拓行左写 \(f\in C(F)\)，右写 \(F|_E=f\)。分离函数明写存在号，右端在 1 之后系弧形，限制间有独立记号。Remark 的“可测分”出去到页边，下行 \(C=A\cup B\) 独立。页尾三项以 \(E\in M\) 开头，简单函数项逐点，连续函数项的箭头上写 a.e.。 |
| p0006 | 页首先接 \((1)\to(3)\)，右向单横杆后箭头，先 \(g\) 再 \(g_k\)，后者限制等式左首仍像裸 \(g\)。中部 Borel 后的姓氏终端至双长杆与点样，先列未定义 \(E_n\) 的零测度式。左缘有截断独立笔，续接“考察”，同一行在 \(F_k\) 后留右弧。下段外大交内大并，内并未见上标；“几乎”之后有大笔加竖叠小笔。好点集外并内交，两处上方 \(\infty\)；末行 \(N(x)\) 与 \(k\) 门槛后写 \(f=g_k\) 恒等。 |
| p0007 | 整页白底。由上到下、左右和重叠边缘未见标题、页码、图或延伸式。 |
