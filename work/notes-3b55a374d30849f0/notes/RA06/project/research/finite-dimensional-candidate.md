## 精确陈述

在实或复赋范空间 X 中，下列三者等价：

1. X 有限维。
2. X 的每个闭有界子集都紧。
3. X 的闭单位球紧。

结合度量空间紧与列紧等价，还等价于：对 X 的每个子集 M，M 列紧当且仅当 M 在 X 中闭且有界。这里必须把量词“每个子集”写清楚，不能把一个固定集合闭有界误当作整个空间有限维的定义。

## 先备：有限维子空间闭

有限维范数等价性已在学习稿中用标准基上界、Bolzano–Weierstrass 子列及反三角不等式证明，不依赖这里待证的刻画。若 Y 有基 e_1,…,e_m，则存在 c>0，使

$$\Big\|\sum_{i=1}^m a_i e_i\Big\|\ge c\,(\sum_{i=1}^m|a_i|^2)^{1/2}.$$

若 y_k=∑a_{k,i}e_i∈Y 且 y_k→x∈X，则上式作用于 y_k−y_l，表明每个坐标 a_{k,i} 是 Cauchy 数列，故收敛到某个 a_i。有限和的连续性给出 y_k→∑a_i e_i。极限唯一，x=∑a_i e_i∈Y，故 Y 闭。

## 先备：Riesz 引理

若 Y 是 X 的真闭子空间，0<θ<1，则存在单位向量 u，使 dist(u,Y)>θ。

证明：取 z∉Y。因 Y 闭，d=dist(z,Y)>0。由下确界定义，可取 y_0∈Y 使 ||z−y_0||<d/θ。令 u=(z−y_0)/||z−y_0||。对任意 y∈Y，y_0+||z−y_0||y 仍在 Y，因此

$$\|u-y\|=\frac{\|z-(y_0+\|z-y_0\|y)\|}{\|z-y_0\|}\ge\frac d{\|z-y_0\|}>\theta.$$

取下确界得结论。不要求 X 完备，也不要求距离取得最小值。

## 刻画的三个方向

有限维 ⇒ 每个闭有界子集紧：选基识别 X 与 R^m 或 C^m；范数等价保持闭性、有界性及拓扑。复数情形再识别 C^m 与 R^{2m}。欧氏空间 Heine–Borel 定理于是给出紧性。

每个闭有界子集紧 ⇒ 闭单位球紧：范数连续，闭单位球是闭有界集，直接应用前提。

闭单位球紧 ⇒ 有限维：反设 X 无限维。先选单位向量 u_1。假设已选 u_1,…,u_n，其线性张成 Y_n 有限维，故闭；又因 X 无限维，Y_n 是真子空间。由 Riesz 引理可取单位向量 u_{n+1}，使 dist(u_{n+1},Y_n)>1/2。因此对 i<j，有 ||u_j−u_i||>1/2。这个点列全在闭单位球内，却没有 Cauchy 子列，更没有收敛子列，与度量空间紧蕴含列紧矛盾。故 X 有限维。
