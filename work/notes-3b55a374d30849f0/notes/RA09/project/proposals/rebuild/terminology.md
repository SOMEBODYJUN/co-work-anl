# RA09 术语与记号对照

| 原稿记号或称谓 | 本稿采用的明确含义 | 条件或保留事项 |
| --- | --- | --- |
| Gδ / Fσ | 可数个开集的交 / 可数个闭集的并 | 定义适用于给定拓扑；单点的球交表达式需度量 |
| 距离 d(x,F) | inf{d(x,y):y∈F} | 非空 F 时为有限值；证明单列 F 为空的情况 |
| O(R^n) | 通常拓扑的开集族 | 原稿 B(O(R)) 的简记另作蓝色澄清 |
| B(R^n) | 开集生成的 Borel σ 代数 | n≥1 时基数为连续统 |
| M(R^n)、M | Lebesgue 可测集族 | 是完备的 σ 代数，严格包含 Borel 集族 |
| m、m*、m_* | Lebesgue 测度、外测度、内测度 | 第 4 页有界集判据明确使用闭集内逼近的内测度表达式 |
| Borel 测度 | 定义在 Borel σ 代数上的测度 | 原稿的具体例子为 Lebesgue 测度的限制，不宣称所有 Borel 测度相同 |
| L_c(E) | 本路线所用的可数开矩形覆盖族 | c 下标按实际图像保留；由并为开集确认覆盖元素在本路线取开 |
| E[条件] | {x∈E:条件成立} 的水平集简写 | 第 9 页反例把 E 重用于不可测集合，蓝块改写为 R^n 上的严格逆像 |
| Σ_f | {B⊂Y:f^{-1}(B)∈Σ_X} | 随源端集合族而变；当源族为 σ 代数时，Σ_f 也是 σ 代数 |
| σ拓扑 | 原稿的课堂称谓 | 原件未定义；保留原词，只证明具体所需的并、交、补封闭性，不另造定义 |
| δ基 | 原稿第 5 页“连续”旁的称谓 | 原件未定义；补充只说明通常拓扑基判别 |
| Rbar | [-∞,+∞]，带线性次序的序拓扑 | +∞ 邻域含(a,+∞]，−∞邻域含[−∞,b) |
| Σ_E、trace σ代数 | {E∩F:F∈M} | E 任意时均为 E 上 σ 代数；E 可测时等于包含于 E 的环境可测集族 |
| MF(E) | E 上 Lebesgue 可测的扩展实值函数族 | 本课定义以 E∈M 为前提；检验每个有限 a 的 E[f>a] |
| τ_E、τ_f | E 的相对拓扑；{B⊂R:f^{-1}(B)∈τ_E} | 最后一页补证明确区分定义域和目标空间 |
| 解析集、普遍可测 | Polish 空间的连续像；属于每个有限 Borel 测度的完备化 | 仅用于 M001 补证；正式来源见研究记录和正文就地链接 |
