### 数学检查 VS-M03

输入是假定任意 μ* 的 Carathéodory 族包含 B(Rⁿ)，n≥1。对 μ*(T)=∞，次可加性已迫使分割和为∞。对 μ*(T)<∞，ν_T(D)=μ*(T∩D) 在 Borel D 上是有限测度：有限次 Carathéodory 分割给下界，外测度可数次可加性给反向。解析非 Borel 集 A 对 ν_T 有 Borel 夹逼 B⊂A⊂C 且ν_T(C\B)=0，于是 μ*(T∩A)=ν_T(B)=ν_T(C)，补集同理，分割等式成立。因此 A 属 Carathéodory 族；不要求 μ* 局部有限、σ 有限，也没有 ∞−∞。依赖先陈述再使用。外部定理核查：Schlicht《Lecture notes on descriptive set theory》Prop.3.26 与 Lemma3.22（https://www.math.uni-bonn.de/ag/logik/teaching/2013SS/advanced%20topics/Lecture%20notes%20on%20descriptive%20set%20theory.pdf）支持解析集普遍可测及 Borel 夹逼；Moore《MATH 7870: Descriptive Set Theory》Theorem13、Corollary5 及 Baire 空间与无理数的同胚事实（https://pi.math.cornell.edu/~justin/Limited2Cornell/DST_lecture_notes.pdf）支持解析非 Borel 集移入 Rⁿ。此数学验证不用于推断旁注字形。
