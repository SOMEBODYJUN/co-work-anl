# RA11 数学上下文恢复者：候选正反向检验

本文件将“代回原定义/证明”的前向检验与“由后文反推必须满足的条件”的反向检验分开，避免把数学通顺误当成原稿笔画已确认。

## P001-U01：二进网格分层

### C1：`j=1,…,k2^k`，网格步长 `2^{-k}`，截断高度 `k`

**前向（定义 → 后文）**

令 `x` 满足 `f(x)<k`。存在唯一 `j∈{1,…,k2^k}` 使
`(j−1)/2^k ≤ f(x)<j/2^k`；在该层定义 `φ_k(x)=(j−1)/2^k`，故
`0≤f(x)−φ_k(x)<2^{-k}`。令 `k→∞` 即得有限值情形的逐点收敛。若 `f(x)≥k`，截断支取值 `k`，仍有 `φ_k(x)=k≤f(x)`。加倍网格时，每个旧层被细分成两个新层，新的下端点不低于旧下端点，从而 `φ_{k+1}≥φ_k`。

**反向（后文 → 定义）**

页底的误差界 `φ_k≤f≤φ_k+2^{-k}` 要求层间距正好 `2^{-k}`；证明中又出现按 `f(x)<k+1` 与 `f(x)≥k+1` 分类，说明有限层必须覆盖到约 `k` 的高度。单位长度有 `2^k` 个层、总高度 `k`，故需要约 `k2^k` 个 `j` 值；只有该上界能令每个 `f(x)<k` 落入某一层并使下端点取值有定义。

### C2：`j=1,…,2^k`，同一网格只覆盖 `[0,1)`

**前向（定义 → 后文）**

代回只得到 `0≤f(x)−φ_k(x)<2^{-k}`（当 `f(x)<1`）；对 `1≤f(x)<k` 的点，没有任何 `E_{k,j}` 覆盖，且它们也不在 `f≥k` 截断支，故 `φ_k` 不能按该定义赋值。不能推出全体 `x` 上的逐点极限或 `φ_k≤f`。

**反向（后文 → 定义）**

后文两类讨论明确涉及 `f(x)≥k+1`、`f(x)<k+1` 和截断值 `k`，而非固定高度 1；再由 `f(x)≤j/2^k` 的上端点估计反推，`j` 必须可达约 `k2^k`。因此 C2 与同页证明路线冲突。

### C3：`j=1,…,k` 或网格步长 `1/k`

**前向（定义 → 后文）**

把分母改成 `k` 会把误差变成 `1/k`，不能生成页中重复出现的 `2^{-k}`；把上界改成 `k` 也只提供 `k` 个层，无法在步长 `2^{-k}` 下覆盖 `[0,k)`。故至少有一个页内公式失配。

**反向（后文 → 定义）**

页中 `E_{k,j}` 的分母、逐级加倍图示和 `φ_{k+1}≥φ_k` 都要求二进制细化；后文极限估计以 `2^{-k}` 收敛，排除 `1/k` 网格。C3 只能作为防止把“等分”文字误读成 `k` 的反例。

## P005-U01：Egoroff 尾集

先固定标准候选定义：
`E_n(ε)=⋃_{r=n}^∞{x∈E:|f_r(x)−f(x)|≥ε}`。

### C1：完整 `E_n(ε)`（页边省略参数时写 `E_n`）

**前向（定义 → 证明）**

`E_{n+1}(ε)⊆E_n(ε)`；几乎处处收敛给出 `∩_nE_n(ε)=limsup_r{|f_r−f|≥ε}` 为零测集；`m(E)<∞` 时由从上连续性得到 `m(E_n(ε))→0`。逐个选 `n_j` 使 `m(E_{n_j}(1/j))<δ/2^j`，则 `F_δ=⋃_jE_{n_j}(1/j)` 满足 `m(F_δ)≤∑_jδ/2^j<δ`，在补集上一致收敛。

**反向（证明 → 定义）**

若后文同时出现 `m(E_n(ε))→0`、`m(E_{n_j}(1/j))<δ/2^j` 和 `F_δ=⋃_jE_{n_j}(1/j)`，则每一项都必须是“从 n 起的误差尾并集”；否则无法保证递减性、零测交集和几何级数估计。因此后文反推完整 C1。

### C2：`̅E_n(ε)`（上横线表示闭包或补集）

**前向（定义 → 证明）**

若上横线表示拓扑闭包，虽有包含关系，却不能由 a.e. 收敛推出 `m(∩_n\overline{E_n(ε)})=0`；闭包可增大到正测集。若表示补集，则集合随 `n` 增大，方向与页面所需的递减尾集相反，`m(∪_nE_n^c)` 也不会给出零测交集。

**反向（证明 → 定义）**

页面后续只使用 `m(E_{n_j}(1/j))` 的小量估计和其可数并。没有正则性、闭包测度或补集的额外条件；故反向要求上横线不能承担集合运算语义，最多是页边省写笔画。若原图确认横线为笔画的一部分，需在 recovery 中保留其不确定性而不能直接宣称 C2 正确。

### C3：`A_n(ε)`（主体字母读作 A）

**前向（定义 → 证明）**

只要另行定义 `A_n(ε)` 为同一个尾部并集，整个 Egoroff 证明在抽象层面仍能运行，说明数学本身不能区分 A 与 E。

**反向（证明/记号 → 定义）**

同篇已经用 `E` 表示底集及层集；P005 后续反复连接到 `E_{n_j}(1/j)`，未引入新族 `A_n`。因此跨页记号一致性反推主体应为 `E`。最终裁图仍须检查作者的 `E` 三横与 `A` 尖顶，数学只能提供支持不能替代视觉证据。
