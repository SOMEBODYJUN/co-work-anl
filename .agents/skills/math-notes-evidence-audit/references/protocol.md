# 执行细则

## 内容单元不能只按标题统计

把一条定义中的条件、一个公式、证明中的每个实质步骤、量词、选点、半径选择、另一条证明、反例、旁注、箭头和图形关系分别记录。A 和 B 各有自己的证明时，两条路线必须有各自的单元 ID；不能以一个“定理已收录”代替。句子拆分可依实际笔迹调整，但不要把整页当成一个无法核对的大单元。

来源 ID 示例：`RA03-P004-U012`。记录页码、像素框、所属区域、内容类型、原文/恢复文本、识读状态、转写目标、复习稿目标。位于重叠区的同一个源对象只分配一个 ID，但记录所有可见区域。箭头记录起点、终点和表示的关系；空白和未完成推导同样分配 ID。

每个新审阅者先制作自己的原图清单，再与现有清单求并。旧清单从未记录的 B，必须通过这一步进入检查范围；对现有清单打勾找不到被漏掉的 B。

## 图像阅读

先整页辨认版面与阅读顺序。默认六个重叠区是起点，不是充分条件。跨栏、长公式、页脚、页边旁注另做有坐标的裁图；对跨页证明同时打开前后页。必要时提高渲染分辨率，保留原图与增强图供比对。放大不会凭空恢复原图不存在的笔画，不用锐化伪影当证据。

每次区域报告至少说明：第一/最后可见内容、实际核对的符号或步骤、空白位置、是否与相邻区/页连续、发现的差异。一个报告可涵盖多区，但必须逐区列明，不能复制同一句“已检查”。记录真实图像调用路径或可用工具轨迹，不编造轨迹。

对页边和留白也做两次查看；整页看似空白仍检查中央、页边和浅色笔迹。自动空白候选不得自动通过。新增的裁图也须列入补充视觉证据；不能只生成不查看。

## 数学恢复

允许主动恢复，不遇难字就停止。按局部笔画和数学语境列候选。例如看似 `1/3` 的式子，需结合分子分母笔画、常数在上下文出现的位置和后续不等式核对。若 `1/2` 与 `1/3` 都能令证明成立，证明成立本身就不能排除其中任一个。

恢复记录应给可核验的简洁理由：候选式、使用的定理条件、关键计算、回代结果、逆向检查、相关前后页和回图观察。无需报告隐含思维过程。保留以下状态：

| 状态 | 含义 | 正文处理 |
| --- | --- | --- |
| 直接可读 | 原图足以支持读法 | 正常原文 |
| 上下文恢复 | 结合上下文重建，有记录 | 保留恢复标识与依据，不冒充逐字确认 |
| 原稿错误 | 原图明确，但数学不成立 | 转写保留；复习稿订正并蓝色解释 |
| 无法唯一恢复 | 多个候选仍不能排除 | 保留片段/裁图、中性定位、独立疑点表 |

老师自定义术语保留其定义及所有例子。网上标准定义与课堂约定不一致时先判定约定，不能以搜索结果替换老师定义。需要核验定理时优先原始论文、正式教材、大学讲义及官方文档；网页只验证数学，不证明作者写了什么。

对可枚举例子、数值和代数运算用程序正反算，并保存输入和输出。对一般定理写完整证明及依赖图；有限样本通过不等于定理证明。重点检查空集、零、端点、无穷值、严格/非严格不等式、零测集、有限测度条件、存在/任意、整列/子列、并/交顺序和非标准约定。

## 旧稿与复习稿

旧稿每个实质单元分别归为：原图确认、旧稿补充、需订正或需核对。不能只靠行数或文本相似度衡量保留。对每一条原图缺项和每一条旧稿独有内容说明去向。旧稿若含自己补的正确证明，保留并标注来源；错误内容记录旧式、订正和原因，不能静默移除。

保真转写按原页序。学习稿可调整知识顺序，但保留所有原路线和细节。补充技术放在依赖它的证明前；题目与完整解答相邻。不得新增课外任务代替原空位。

颜色沿用项目约定：原内容黑色；教师新增、模型补全和订正蓝色并写明类别；原留白/原待填红色且在原位置。可用 Obsidian `> [!info]` 蓝色 callout。公式不要包进 `<span>`，红色文字和公式分别处理。不以本地自定义 CSS 才能实现的颜色作为唯一交付形式。

这里“原留白”指原稿明确留给某个知识点、问题或证明的待填位置，不指空白物理页、页边空白或普通布局空隙；后者只用普通来源记录。同一条原“待证”与后面的自然纸面空间不生成两个红色任务。未明示实值/扩展实值等数学前提时，可给出明确范围内的蓝色补充；除非影响无法消除的原意判断，不自动新增识读疑点或要求用户补答。

## 三份并行与独立复核

批次依课次排序：第一批三份，完成本批的转写、比较、修订、连续三轮复核和审计，再进入下一批。并发低于三时按实际上限缩小批次。每个子代理只能读写分配目录；没有新子代理工具时如实报告，主代理自查不能冒充独立复核。

每次新审阅者只获得任务合同、原稿/当前稿路径、当前哈希、源与旧稿清单，不获得“上一轮没错”的结论。先保存盲读原图清单，再读取稿件。支持 `fork_turns="none"` 的环境使用该设置；这只控制上下文继承，并不能使同一个模型的错误在统计上独立。

作者初读后，另一位新审阅者完成第二遍全区检查。整合并锁定后，再进行规定的连续三轮全量核验。每轮需覆盖来源清单之外可能遗漏的原图对象。某一轮发现问题，修改后重置连续计数；只修改报告文字不等于内容修改，但不能借此改写正文而沿用旧哈希。

轮次记录：审阅者/任务/会话标识、角色、检查文件哈希、全量范围、独立清单、逐页差异报告、数学验证、发现列表、状态、时间及证据路径。重复报告或一位作者自查不得充当新独立轮次。报告即使无发现也要有实查内容。



真实阻塞的处理：正常情况下完成本批整套流程再进入下一批。某份若确因缺原件、损坏扫描或运行工具不可用而无法继续，在完成本批所有仍可执行的工作后，把它明确标为 blocked/未完成，保存完整交接与影响范围，再继续后续批次的独立工作。不得把阻塞项算作通过，也不得为凑齐批次猜写内容。一般疑字先保留明确未决，不用无限重读相同劣质像素阻塞全部其他笔记。

## 检查点与结案措辞

每页保存转写及覆盖状态，每次修订另存版本；复核报告追加保留，不覆盖历史。检查点列当前批次、当前页区、已锁版本、各课次状态、未决问题和下一步。中断不算通过。若内容仍有未决但全部记录已按规则完成，分别报告结构审计状态和内容未决状态，不用“全部确认”遮掩。

推荐结案：“规定的逐页逐区复核与版本审计已完成；当前未决 X 项，位置如下。”只有真实未决为零才能写该数为零。永远不要将此换成“已证明零遗漏、零错误”。
