# 数学手记逐页复核

以用户指定的原始 PDF 为识读证据，以历史 Markdown 为独立待保留材料。先建立完整转写，再编排复习笔记。不得用合理的数学推导冒充已确认的字迹。不得以程序通过代替视觉核对。

## 开始之前

1. 阅读项目根目录 `AGENTS.md`、`prompts/coordinator-prompt.md` 和 `prompts/worker-prompt.md`。读取本技能的 [详细规程](references/protocol.md) 与 [工具合同](references/tools.md)。若根目录路径不同，先定位项目根目录，勿猜测文件内容。
2. 实际检查文件、视觉工具、PDF 渲染工具、子代理能力及可用并发。支持时以 `fork_turns="none"` 创建新审阅线程；不支持时报告实际接口，采用新独立任务，不伪造参数。没有子代理时仍可转写和保存，但独立复核门槛保持未完成。
3. 先核实每份原稿与旧稿的对应关系、版本和文件哈希。缺少原稿的课次单列，不假装已复核。相同 PDF 的多个副本不能算多个独立来源。
4. 先运行 `scripts/selftest.py`。用 `scripts/prepare_pdf.py --help` 和 `scripts/audit.py --help` 获取真实命令，按工具合同建工作目录。程序只准备原图、裁图和记录模板，不伪造“看过”记录；模型必须实际读取自动生成的高分辨率裁图并填写候选与检验结果。

## 保真转写

1. 读取物理页数，逐页生成全页和重叠区域图。先看整页，再逐区逐行查看；为小字、页边、跨区公式和箭头加局部放大图。保留原始图，增强图只作辅证。空白检测仅生成候选，空白结论须两次视觉确认。
2. 为每个定义、条件、公式、证明行、反例、图形、箭头、旁注、重复内容、划去的可读文字、原留白和未完成推导建来源单元。为每个图标记元素与连线关系；不能可靠重绘就保留裁图及说明。
3. 先只看原图写逐页转写与来源清单，不读取旧稿来猜原稿。完成独立初读并保存后，才比较旧稿。原图不同读法与旧稿独有内容分别记录。
4. 模糊内容按“笔迹候选 → 前后页记号 → 定理条件与证明路线 → 前向推导与逆向验证 → 回图比较”处理。保留候选、简洁验证依据和局部图路径；不要求输出隐含思维链，只保留可核验的数学理由。
5. 分类为直接可读、上下文恢复、原稿数学错误、无法唯一恢复。数学一致只能支持恢复，不能证明原作者写的就是它。老师自定义概念优先按原定义、记号和例子保留，不强行套标准术语。

## 与旧稿对照并成稿

1. 为旧稿每个内容单元也建清单。逐条映射到新复习稿；原图没有的补充不得自动删除，注明旧稿来源，检查后保留或附具体订正理由。原稿错误在保真转写中保留，在复习稿中订正并用蓝色说明。
2. 输出相互独立的 `source-transcript.md`（原稿页序，保留内容与重复）和 `study-notes.md`（复习顺序）。复习稿可把工具移到证明前，但不得丢失 A/B 两条路线、各自细节、原反例与旁注，也不得以“类似可得”替代原证明。
3. 沿用用户模板：原有内容黑色；教师新增资料、模型补充证明与订正就地用蓝色块并标明来源类别；只有原留白/原待填用红色且留在知识点原位。识读不确定项用中性标识并进入独立疑点表，不污染红色约定。已补证明仍保留原留白标识，紧接蓝色完整解答，不重复制造任务。
   空白物理页、普通页边留空和排版间隙仅作普通来源记录，不标成红色待填。原“待证”及其后自然空白视为同一个待填位置，不重复建红色任务。未明示的标准数学前提优先在蓝色补充中限定适用范围；不自动归为识读疑点或新增阻塞任务。
4. 题目与完整答案相邻；完整目录；Obsidian 行内 `$...$`、块公式 `$$...$$`，callout 每行含 `>`。检查数学排版并查看代表性渲染；排版通过不等于数学正确。
5. 为源单元、旧稿单元和最终段落建立双向映射及稳定 ID。每条原图内容必须有去向，每条新增正文必须标来源或补充。覆盖表本身也需要新审阅者对原图检查，不能只验证已有清单。

## 独立复核与修改循环

1. 最多三个笔记任务同时运行，按用户要求以三份一批处理；并发上限不足则缩小批次。每位子代理只处理一份笔记，不再递归启动子代理，不修改其他笔记。主代理统一合并，防止共同写入冲突。
2. 每份笔记先完成第二次逐区视觉核查。第二位新审阅者先独立读原图并列清单，再打开稿件对比。记录每区实际核对点、差异、报告与任务 ID；不能只填“通过”。
3. 修改并锁定整份内容版本后，进行连续三轮全量复核。每轮使用新的审阅线程，每份笔记由非作者审阅者重新核对全部原图、全部内容清单、旧稿迁移、证明及成稿；轮间不共享“上一轮已通过”的结论作为证据。
4. 每轮明确列出遗漏、错读、数学错误、新疑点；若无则保留空发现列表和逐页实查报告。记录源文件、图片、转写、复习稿、映射与恢复决定的哈希。任何内容修改后重新锁定，连续无新发现计数归零；之前的报告保留为历史，不挪用给新版本。
5. 程序核对报告、哈希和覆盖记录，不认证代理是否真正看图。主代理另外抽查实际工具轨迹及关键区域，不能伪造审阅者、截图、模型名、检查次数或测试结果。
6. 如遇额度、超时或图像不可读，保存检查点、未完成页区、已提交文件和下一步。内容疑点保持认领并继续自动恢复；只有缺页、文件损坏或视觉工具确实不可用才允许真实阻塞。中断不算通过，也不把内容疑点交给用户判字。

## 审计与交付

按 `references/tools.md` 运行结构审计。缺页、漏区、无映射、过期哈希、无效证据、重复审阅线程或轮次不足，返回补查。`content_resolved=false` 时自动进入模型恢复队列并生成定向裁图；只有模型完成恢复、重新冻结并重跑要求的复核后才提交。全部条件满足后才称“已完成规定的复核流程”；有无法确认项则另报待确认数量和位置，不说零错或完全恢复。

交付每份笔记的保真转写、复习稿、来源与旧稿映射、数学恢复记录、疑点清单、逐页区域覆盖报告、各轮实查报告和最终机器审计。汇总所有课次状态与跨课记号差异；不擅自把老师的不同约定全局统一。

上游 `handwritten-math-notes-to-latex` 的数学检查和 LaTeX 规程可作补充；遇冲突时执行本项目用户明确要求。不得启用上游允许的图形省略或内容概括选项。
