# POTENTIAL-SECURITY-SCOPE：准确结论及比较边界

## COPY 的完整聚合结论

同一五人完整SPE及同一最优五索引元组的25个有序COPY界，完整推出 `5500u+975K−475D+12S2≥0`，并始终保同一实际根利润u和同目录最大K。

令客户x在最优五索引中的重数为d。对全部有序(i,j)，包括i=j与标签别名，查询项总和为

`Σ_(i,j) 1[x∈T_j]/(1+4·1[x∈T_i]) = 5d−4d²/5`。

25个右端求和为 `25(44u/3+13K/5)−(80/3)D`。因此

`5D−4S2/5 ≤ 1100u/3+65K−80D/3`，

乘15并移项即为目标。COPY逐对量化所有合法T,Q，故换成其他合法菜单仍使用同一σ、u、K；上述D/S2矩式专属该同一最优五索引，不能在不同菜单或互斥枝上另选利润源。

## 两人税在四谱中的准确贡献

固定背景恰两人税界完整推出五人真最大根末两人历史上的 `P≥0` 与 `Q_pair≥0`；它是四谱证明的局部贡献，独自不提供四份谱/矩结论。

在同一真实历史(M,B2,B3)，背景为p，实际末两人为(B4,B5)，令 `H=v4+v5+Σ_(x∈B4)1/((p_x+1)(p_x+2))`。两人税逐比较对给 `R_p(T_i,T_j)≤H`。对全部10个不同索引对求和，客户负载d的一次覆盖对数为d(5−d)、两次覆盖对数为binom(d,2)，故

`Q_pair=10H−Σ_x[d(5−d)/(p+1)+d(d−1)/(p+2)]≥0`。

客户在最优并集时选一覆盖索引；含它的四对各至少贡献1/(p+1)，包括两个比较标签均覆盖时 `2/(p+2)≥1/(p+1)`。所以 `(5/2)H≥Σ_(d>0)1/(p+1)`。添并集外非负项即得

`P=(5/2)H+Σ_all p/(p+1)−O≥0`。

全程只用该一历史的末两人预算，没把真最大根后的尾利润直接加成实际W。完整四谱还用根IC、共同K的CAP、真正第三位floor、真末位五查询、指定非负乘子及全部192客户型余项。old谱中P/Q乘子为零；两人税非该旧谱单独必要源。

## 匿名势结论及其它比较

完整Boolean表的调和反演唯一性，分别推出非负/整数实现判据和全部重复计数的相容性。两条边分开，未将“非负客户可实现”当成所有匿名计数表均可编译；未从提供者匿名推主题交换对称。

遗漏客户私有偏离的half条件要求同一个最优遗漏分割、每人至多一个集合及偏离后后继仍不覆盖；加入新不交F时保原实际路径的必要条件只付最后两人。后者不提供一般分割，前者也不保证不交目录扩张仍有保原路径的SPE。补位族早查询B/D后继T会覆盖新增遗漏客户，恰不满足私有偏离条件；它与条件half不冲突。

静态余项在任意r/s和非负实背景成立，但d*是比较负载、Q*是静态minimax对偶。完整根矩阵保当前根的r槽、再加一个query；全树流的每背景则有n−1槽。两者的同名安全值需分别跟踪人数，均未给把静态R换成同一实际SPE收益的等式。若另给最优query的精确运输流，静态 `OPT_n≤(2n−1)v_n` 确可与 `W≥nv_n` 合成 `(2−1/n)W` 上界；最优流的普遍存在不在本包方法中断言。

actual13_v1是指定6751必要行版本的63个正有理atom，W1、比较O>2；没有共同目录/完整σ逆实现，也不满足“任意拟定匿名势可编译”的输入形式。非负atom与源系统可行声明不能替代Möbius的完整Boolean数据，更不能变成五人真实half反例。
