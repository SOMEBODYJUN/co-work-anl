## 模型与真实末位 IC

共同模型是有限单位客户、有限非空**带标签**共同目录，标签可有相同覆盖或空覆盖；单位权提供者依次行动、观察完整有序历史，客户在终局由全部覆盖者均分。完整纯策略 `sigma` 在每个合法有序历史定义；完整 SPE 要求每一节点、每一合法单方行动都沿给定策略的真实后继满足 IC。重复、平局、零客户和所有离轨历史均保留。

固定任意 `m>=2`、一份完整纯 SPE `sigma`、合法历史 `h`（恰剩两人），过去负载为 `a_x`。对合法强制的倒二主题 `R_e`，令 `Z_e` 为同一 `sigma` 在 `(h,R_e)` 后的真正末位回复。对任意 `e,f`，`Z_f` 只是同目录合法查询；在倒二节点真实 IC 中，偏离 `R_e` 到 `R_f` 的后继也必须由 `sigma` 在该偏离历史上给出。因此

`L_ef = sum_x (z_e(x)-z_f(x))/(a_x+1+r_e(x)) >= 0`。

这里没有冻结在轨后继、没有把静态偏离当真实后继，也没有把跨枝 `Z_f` 当成新的真实回复节点。

## 双边际（四态）可行域

在一块过去负载恒为 `a`、总客户质量为 `H` 的类型块内，只固定每个 `e` 自己的 `(R_e,Z_e)` 四态质量：

- `q_e = |R_e|`，`v_e = |Z_e|`，`t_e = |R_e cap Z_e|`；
- `00,01,10,11` 质量分别是 `H-q_e-v_e+t_e`, `v_e-t_e`, `q_e-t_e`, `t_e`，都必须非负；
- 不固定不同 `e` 之间的 `R_e` 联合，也不固定 `R_e cap Z_f`。

这是一种边缘投影放松，而非完整策略树。质量可以是有理数（清分母后可视为不同单位客户质量），因此公式不依赖把分数客户误当作权重玩家。

逐客户恒等式

`1/(a+1+r) = 1/(a+1) - r/((a+1)(a+2))`

给出

`L_ef,H = (v_e-v_f)/(a+1) + (|R_e cap Z_f|-t_e)/((a+1)(a+2)).`

唯一未固定的量是交叉交叠 `J_ef=|R_e cap Z_f|`，且对任何共同联合都只有 Fréchet 必要界

`0 <= J_ef <= min(q_e,v_f)`。

所以每一非自配对有安全的宽上界

`B_ef,H = (v_e-v_f)/(a+1) + (min(q_e,v_f)-t_e)/((a+1)(a+2))`。

`e=f` 时 `J_ee=t_e`，真实行恒为 0；程序对自配对直接取 0。对非负乘子 `lambda_ef>=0` 和所有负载块求和，真实 IC 给 `0 <= sum lambda L <= sum lambda B`。右端严格负便排除**所有**保持这些 own 四态的共同 `R/Z` 联合扩张。H=0 块全式为 0，不需要条件概率。

稳定子平均只用于从保持组平均四态的候选联合恢复逐字面标签的轨道边缘；它不令同一轨道的会员位相同，也不把 `R_e cap Z_f` 错换成 own 交叠 `t_e`。`min` 也不被声称可由所有对同时达到，因而这只是必要上界而不是精确联合消元。

## `whole`、`contribution`、`context` 与 `refutes` 的准确分级

- **whole（对象本身）**：在其固定六人点、固定全部 own 四态和指定真实末位 IC 量词下，严格负 Fréchet 宽上界排除任意共同 `R/Z` 联合扩张。它是该固定边缘对象的完整结论。
- **contribution**：公式 (2) 的真实末位 IC 恒等式、`J<=min(q,v)` 的任意联合上界、稳定子平均的边缘解释，以及 `0102` 的 1920 项精确负证书。已有单环边只复用这一步。
- **context（本包资产）**：本包只保存 scope-boundary 说明，不新增 context 边；既有 canonical 边的 scope 已明确固定边缘负值仅是局部必要投影。
- **refutes（精确否定对象）**：它 refutes 的唯一陈述是“在所固定旧点和 own 四态下，存在一份共同 `R/Z` 联合同时满足上述真实末位 IC 类”。它不 refute `Q-CAG-HALF`、六人全量题、任意完整 SPE 存在性或任何全模型半覆盖命题。

## 与完整 SPE/half 的障碍

完整 SPE 需要一份同一 `sigma` 在全部有序历史、全部合法偏离上的真实后继 IC，并且最终客户质量来自同一单位客户集合与同一标签联合。这里的证明只看一个已保存点的 16 个负载块和每组 `(R_e,Z_e)` own 四态质量；它允许按质量拆分、没有固定跨组 `R` 联合，也没有物化所有 1306 个 RR 坐标，更没有构造同一 `sigma` 的全历史策略。因此局部边缘不可扩张不能推出“旧必要点是游戏反例”，更不能推出 `2W<OPT_6`。

后来释放 `Z/RZ` 边缘的 3949 阈值修复点不在结论域：它改变关键固定量（据已保存审查，321 质量/42 原子使 60 个 ZZ 类非负，另有 56 个 Z 边缘和 93 joint/164 RR 坐标变化）。若只改 RR/K 或跨组 R 联合而保全部 own 四态，当前负界仍适用；若改 Z/RZ、真实历史或标签组，必须重新定义域并重算。一般人数完整 SPE/half 仍需独立证明，不能用该局部负值替代全量量词。
