## 需要独立核清的数学桥

固定 `n >= 2` 和一个有限标签实例 `L`，覆盖映射为 `C:L -> 2^N`。令 `K=L/~` 为同覆盖商，每个类恰对应一个不同真实集合，投影为 `pi`。固定任一精确标签前缀 `h` 和当前标签 `a`。

价格来源定义

`ell_i^L(h,a) = min { u_i(z) : z 为强制 (h,a) 后任一真正完整纯子 SPE 的物理终局 }`，

`M_i^L(h) = max_a ell_i^L(h,a)`。

拟使用 B10 的前缀版本证明：强制 `(h,a)` 后全部可实现有序覆盖尾路径，与强制 `(pi h, pi a)` 后商子游戏的全部可实现尾路径相同。可直接从固定前缀处开始其逐历史递归；过去玩家的覆盖负载和身份固定，对未来的真实收益只由覆盖决定。规定类代表必须沿被模拟的当前原动作取，不能任意固定代表后宣称模拟原动作表。逆向把商策略按固定代表提升到该原前缀后的全部标签历史。两个方向均保持每个未来节点的全部真实偏离 IC，并保已行动角色 i 的终局收益。

这若成立，则逐行动

`ell_i^L(h,a) = ell_i^K(pi h,pi a)`。

投影对商行动满射，故

`M_i^L(h) = M_i^K(pi h)`。

这里比较的是所有可能真实子 SPE 的集合与极小值。它不要求保留某份固定原 sigma 的每个 alias 菜单列，因此 B10 的“不能保全部固定菜单”异议本身不切断这条门槛桥。

## 任意末位 BR 目标的价格约束

取任意原有序目标 `z=(a_1,...,a_n)`，只要求最后一步是 BR，前面各步可以不可信。令 `bar z=pi z`。所有逐角色终局收益、覆盖 `W`、`OPT_n` 都相等。最后一步的每个原偏离收益等于相应商偏离收益，且投影满射，所以末位 BR 双向保持。由每个精确前缀的 M 等式，有

`g_i^L(z)=M_i^L(z_<i)-u_i^L(z)=g_i^K(bar z)`。

因此对每一个给定的同一非负价向量 lambda，价格约束数值逐目标相等。若同一 lambda 对所有真实集合实例满足 UP_S，它对每个标签实例的商实例都适用，从而满足 UP_L；反向由集合实例作为标签实例的子域直接成立。这是相同 lambda 的性质保持，不是为每个原标签实例重新选择价格。

B10 的完整根 SPE 路径集合双向相等又给 `HALF_S(n) iff HALF_L(n)`。结合原价格等价可得完整标签域的统一实价存在性及同一总价界。一般 HALF 的真值仍开放，这一桥不提供具体 lambda、有理性或新的六人 half 证明。
