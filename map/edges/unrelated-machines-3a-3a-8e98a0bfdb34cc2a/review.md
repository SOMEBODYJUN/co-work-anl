## 同一输入、固定任务和零值处理

考虑有限显式 restricted-assignment 实例，每个原任务 j 有非空资格集 Γ(j)，所有可用端耗时同为 p_j≥0，并额外限制 |Γ(j)|≤2。目标是每个原任务完整选一个资格端，使全部原机器最大总负载最小。机器和任务都保留其身份；不引入复制机、匿名端口或可以忽略的辅助负载。

数学上的配置投影、负载不等式及7/4阈值结论对非负实加工值和每个正实阈值T成立。多项式算法的实现合同则仅限全部加工值、固定基载荷与给定T均以二进制有理数显式编码，按完整展开输入总位长收费；不对任意实数的计算表示作运行时间承诺，也不声称精确求CONFIG最优阈值的多项式算法。

零时间任务先任意放到其某个合法端，最后补回，完全不改变负载。空任务和全零任务直接处理。下面在 T>0 且所有剩余任务 p_j>0 的分支论证。只有一个合法端的原任务、以及写成 loop 的任务，合并为该机器的固定基载荷 q_i；它们仍是完整调度中必须执行的原任务。每个双端任务成为一条有标签的多重边 e={u,v}，共同处理时间 p_e。不同原任务即使端点相同仍是不同平行边。

CONFIG(T) 使用每机配置权重和恰为1、每原任务总覆盖恰为1的形式，配置为在该机器合资格且总加工值≤T的 0/1 原任务子集。JR 的每机权和≤1、每任务覆盖≥1形式与之同阈值等价：先补空配置，每次对过覆盖任务把部分正配置权转到删去该任务的子配置，直至其覆盖为1；向下封闭保持负载合法且其他任务覆盖不变。该等价不替代取得指数列配置 LP 证书的复杂度义务。

在恰等式 CONFIG(T) 中，单端任务只能在固定机器被覆盖；其覆盖1和该机器配置总权1，迫使该任务出现在该机器每一个正权配置中。有限多个固定任务同时满足这一条件，因此每个正权配置都包含该机器全部固定任务，其总耗时正是 q_i。不能将 q_i 忽略，也不能额外给固定任务另一份免费容量。

## 联合推导：CONFIG(T) 到完整 LP3

设合法配置概率为 y_{i,C}，投影为 x_{ei}=Σ_{C含e}y_{i,C}。`M-8dec531708464aaa87be325982ae38fc` 给该投影与逐机合法 0/1 配置凸包的双向充要合同；这里使用其正向结论。逐项核对得到：

1. 非负性及 Edge：x_{eu},x_{ev}≥0，且 x_{eu}+x_{ev}=1，因为双端原任务必须恰覆盖一次。
2. Load：每个正权原配置同时付全部固定任务和在该机执行的边任务，所以 q_i+Σ_{e∋i}p_e x_{ei}≤T。
3. 单件剪枝：若 p_e>T，两端任何合法配置均不能含 e，违反覆盖1；故所有剩余边 p_e≤T。固定基载荷也满足 q_i≤T。
4. Star：定义 E_B(T)={e:p_e>T/2}。任一机器的合法配置至多含一枚这种大边，因为两枚的总处理时间已严格大于T，而 q_i≥0。对这条逐配置有效的基数不等式取期望，得到 Σ_{e∈E_B(T):i∈e}x_{ei}≤1。

将 p_e、q_i 同除 T，上述恰是作者稿 p13 的 LP3：Edge、Load 和全部未加权大边 Star 均齐全。这不是仅得到一般 assignment LP，亦不需要先假定存在负载≤T的整数定向。CONFIG(T) 可行就是 LP3 可行的充分证据。

反向 `LP3⇒CONFIG` 未在这里证明，不能将两者识别为同一多面体。投影对象的“全部单机切割已经有效”与这里补出的 Star 相容：Star 在每个合法单机配置上有效，所以 CONFIG 本来就含有它；这不意味着 LP3 含全部单机凸包切割。

## LP3、LP2 和 ROUND 的承重机制

归一化后 E_B={e:p_e>1/2}。对大边树 S，L(S) 是叶顶点与其唯一树边的配对，LP2 的 Tree 约束是

Σ_{(v,e)∈L(S)}x_{ev}p_e ≥ Σ_{(v,e)∈L(S)}p_e−1。

Theorem 2 的第一部分并非只用 Load。设 S 有 k 个顶点。把其 k−1 条 Edge 等式相加，再减去内部顶点的 Star 上界，得叶端总质量至少 |L(S)|−1，即 Σ_{L(S)}(1−x_{ev})≤1。因 0≤p_e≤1，于是 Σ_{L(S)}(1−x_{ev})p_e≤1，正是上述加权 Tree 约束。因此 LP3⊆LP2⊆LP1，三者整数可行点相同。

第二部分也要保留准确结构。若分数大边图中的一个环 C 另接分数大边 f，则环上 Edge 等式的总质量为 |C|；环顶点 Star 的容量和只有 |C|，但还要付 f 在环端的严格正质量，矛盾。故每个非平凡分数大边连通分量是树或一个没有附枝的纯环，不是任意单环加树枝的伪森林。

LP3 比 LP2 可以严格更强。例：三叶星，每边权3/5，q=0，全部边两端质量均1/2。中心 Load=9/10，叶 Load=3/10。对一边树，Tree 左为3/5而右为1/5；对两边路径，左为3/5而右为1/5；对三边全星，左为9/10而右为4/5，故全部 Tree 成立。但中心 Star 总质量3/2>1。这个短例只澄清多面体关系，不另建立对象身份。

ROUND 的初始点是 LP2 可行点且分数大边图为树或纯环。Theorem 1 维护：所有顶点负载≤7/4；仍关联分数边的顶点负载≤5/4；仍关联分数大边的顶点负载≤1；当前分数大边子树的全部 Tree 约束成立。舍入期间可出现负载>1，因此不继续是原 LP2 的可行点。

叶赋值时，若叶边是小边，叶原负载≤5/4、增载≤1/2；若为大边，叶原负载≤1、且接受条件保证增载≤3/4。超过3/4时该叶边为大边，将其整个分数大边树分量背离叶根定向；由叶到任一接收顶点的路径 Tree 约束，其他顶点各增载严格小于1/4，且该分量不再含分数大边。当分数图没有叶时，FindCycle 优先沿大边前进，再用 ROTATE。旋转保持各顶点加权负载，但未加权 Star 不必保持；扩树 S′ 的论证保持 Tree(S′)，再减去新增叶项的 x_{ev}p_e≤p_e，恢复原 Tree(S)。

每轮至少减少一条分数边，不添加分数边，最终所有边整数化，所有机器负载≤7/4。在上述显式二进制有理编码域，其所有操作和多项式规模 LP3 的求解均为总位多项式；不需要调用 JR 的可能指数 blocker 搜索。恢复尺度并补回全部固定任务和零任务，即得完整实际调度峰≤7T/4。

## 对 JR 目标实际付清的范围

令 T_CONF 为同一实例的最小配置可行阈值。在有限任务的情形，所有可能配置负载阈值只有有限多种，因而正阈值最小值取得；也可用任意趋近阈值取极限得同样不等式。对 T=T_CONF 应用上段论证得

OPT≤(7/4)T_CONF≤(11/6)T_CONF。

因此联合源支付 JR 的一般 restricted-assignment 11/6 结论在 |Γ(j)|≤2 子域上的成立，并额外给出此子域在每个给定可行T上的多项式实际恢复。这是目标全定理的一部分，故使用 contribution。目标仍需其全资格度域的 blocker/repelled-move 论证；本边未把来源的7/4算法扩展到三资格端，也未把 JR 的有限终止升级为其全域多项式输出。

这里给定 T 的恢复算法可直接解 LP3，不需要拿到显式 CONFIG 证书；CONFIG 可行只用于证明 LP3 在该 T 不会 FAIL。本边没有声称可以在多项式时间精确求出一般指数列 CONFIG 的 T_CONF。不同时间合同和不同证明机制保留独立身份。

## 异速双树为何不构成反例

`UM-CONF-GAP-v1` 的每条树任务在父端耗时1/k、子端耗时1，只有根间任务两端都为1。因此它满足两资格端，但不满足 restricted assignment 的同任务两端等时承诺。真实 OPT=2−1/k、CONFIG(1+1/k)可行及比率趋2均与核心兼容。

承重差异可以直接定位：在 normalized CONFIG 阈值1下，某任务可在一端成为大任务、另一端是小任务，不能定义同时适用于两端的共同 p_e。用δ/p_e作两端质量交换就不再保持每个顶点负载；大边子图的 Edge/Star 加和与优先大边旋转也失去共同权重合同。仅把“至多两端”抽出来并不足以应用7/4算法。

不能用核心反驳双树整个 gap 对象，亦不能用双树反驳核心。将双树所有有限端改成相同值会改变真实原矩阵和配置可行性，原有 OPT/CONFIG 证书不自动保留。该比较已解决为清楚的 promise 分离，记入 additional_comparisons，不杜撰 follow-up 或逻辑边。

## 失败阈值与旋转的精确核验

作者稿 p6 定义的 FAIL 只要求所有定向均在某处负载>1；若 OPT∈(1,7/4]，FAIL和实际7/4定向均合法。Algorithm 3 在 LP3 不可行时 FAIL，含义为没有整数负载≤1方向，不是排除≤7/4方向。

两顶点、三条各权3/5的平行边、q=0，是旧强化说法的直接反例：三条 Edge 的总分数质量为3，而两条 Star 的总容量为2，所以 LP3 不可行、算法返回FAIL。实际把两条给一顶点、另一条给另一顶点，峰为6/5；鸽巢原理也给至少6/5。因此 FAIL 时 OPT 可以是6/5≤7/4。

同例每边各端质量1/2是 LP1 可行点，两个顶点分数负载均9/10。在任取两条平行边的二环上旋转δ=3/10后，这两条各整数化到相反端，第三条仍各端1/2。剩余分数图是一条森林边，旋转已无法继续，仍没有全整数。再把森林边给某端才完成实际方向，峰6/5。ROTATE本身仅保持负载并消环；其后完整森林定向是独立步骤。
