# B10 加权背景、容量证书和同族菜单比较

本包核心是 B10 的 AP/BNS 两常数版本、固定支持合同、零误差刚性和七真源菜单聚合/定价。模型固定有限单位客户和有限非空标签共同目录；允许空覆盖、不同标签同覆盖、重复行动、零客户及任意有序历史平局。始终固定一份完整纯 SPE，偏离后沿同一原策略真实后继，不冻结实际叶，也不把被强制动作当作其枝上的优化者。

实际完整读取任务所列 24 个去重文件、10 个 registry 对象，并补读只读容量对象的完整自足正文和 完整 raw 解析证明。没有执行原 LP、CG、SPE 产生器、原 audit 或全域 oracle；历史有限成功保持其原版本身份。本包只新写数学比较与绑定边。没有发现本包原文需要勘误的数学错误。

## 1. 容量证书推出 AP2

固定真实节点 h，余 k≥2，背景整数 b≥0，w_x=1/(b_x+k)。u 是源规定行动的最终收益；任意合法 C,D，s=Σ_Cw，F=Σ_(C∩D)w+Σ_(D\C)1/(b+1)。当前对每个合法 H 的真实偏离最终收益至少 Σ_Hw，所以 u≥K_w=max_HΣ_Hw，尤其 e=u−s≥0。此论证不要求后继最优性或 C 最大。

容量引理 M-966d7f6ae9b243a8a2c6a6571e2f1056 的 B 式对任意全目录共同容量 U 有

F ≤ s+(M−1)(k−1)(u−s)+(k²/2)(U−s).

取 U=u，M=M_C=k+max_(x∈C)b_x 得完整 AP2。C 空时 M_C=k，不需要存在 C 内最大客户：F≤kΣ_Dw≤ku；((k−1)²+k²/2)u≥ku 给同式。零客户亦全零。这里是同一 near-saturation 机制的显式末位 IC/容量证书读出，不增加新颖性或独立外审身份。

## 2. 容量证书推出 BNS2

取 C 为同一背景 w 最大主题，令 K_w=s。容量引理可取 U=K_w（不是其另一读出里的裸目录大小 K/k）；U 是所有合法后继主题的共同上界。A 式容量误差恰零，故

F≤K_w+(k−1)Δ，Δ≤(M_C−1)(u−K_w).

于是得到全部 BNS2：δ=u−K_w≥0，F≤K_w+(k−1)(M_C−1)δ。这里没有保留 AP2 的 k²δ/2 额外误差；不能把 AP2 仅代 s=K_w 就宣称得到 BNS2。若 C 空且最大，正 w 迫全部主题覆盖空，u=F=0。该读出对所有合法背景、每个最大标签和每个查询 D 有效，包括 k=2。

## 3. v2 推出各自 v1

M_C≤M=k+max_Nb_x。AP 中 e≥0，BNS 中 δ≥0，故分别有

s+[(k−1)(M_C−1)+k²/2]e ≤ s+[(k−1)(M−1)+k²/2]e，

K_w+(k−1)(M_C−1)δ ≤ K_w+(k−1)(M−1)δ。

这只证明收紧版到全客户版的完整方向。M 的上界可能由 C 外客户达到，不能反过来仅凭 v1 的数值上界换成 M_C；v2 原证明之所以成立，是其全部有界分母使用点都在 C 内。本包不造 v1↔v2 等价边。

## 4. BNS2 的零误差覆盖刚性

设 δ=u−K_w=0，任取最大标签 C。真实强制 C 枝偏离者 v 满足 K_w≤v≤u=K_w。恒等式

v−K_w=Σ_(x∈C)(k−q_x)/[(b_x+q_x)(b_x+k)]

各项非负、分母正，故每个 C 客户 q_x=k；所有后继都包含 C。每个合法后继主题的 w 大小≤K_w，且权严格正，故其覆盖恰为 C。对另一个最大标签 D，BNS2 的左侧等于

K_w+Σ_(x∈D\C)[1/(b_x+1)−1/(b_x+k)]。

k≥2 使每个非空差集项严格正，F≤K_w 迫 D\C 空；同 w 大小再迫 C\D 空。得到目标的两部分：所有强制 C 后真实后继覆盖恰 C；所有最大标签同覆盖。没有把相同覆盖标签或不同有序历史合并，没有宣称饱和节点存在。

## 5. AP2 到固定支持共同上界

固定标签目录、完整有序历史 h、完整规定策略与有限允许类型支持 P；b_B(h) 是类型固定整数。先取

Mbar_C=k+max{b_B(h):B∈P,C∈B}，空集 max0。

对任何实现该同一完整 SPE 的非负客户重数，实际正支持的 M_C≤Mbar_C，且 e=u−s≥0，故 AP2 安全放宽为 F≤s+[(k−1)(Mbar_C−1)+k²/2](u−s)。现在 u、s、F 对重数线性，Mbar_C 不依赖未知正支持，因此这是固定支持必要线性行。零质量类型留在最大值里只放宽。这里“所有非负重数”指必要性合同：若该策略在这些重数下是完整 SPE，则该行成立，绝非所有任意重数/任意非均衡策略自动满足它。

原单位客户域为非负整数重数；对有理质量可整体放大到整数，同质性保 IC 和行值；固定有限策略的所有 IC 构成有理多面锥，其有理点稠密，故连续延伸到真实质量锥。没有把任意权客户变成另一模型中的权提供者。

共享误差 e 是总收益差，不具备逐客户非负分解，AP2 不许可把每列分别换成 k+b_B 再乘该列收益差。此处保存的是共同上界的充分合同及逐列替换没有被证明的边界，不声称已经给某个逐列版本的完整 SPE 反例。不认证原 64 支持/1867 行实现或有理点。

## 6. AP1 到七真实源 CART 和根7125

五人合法历史有 M≤5，e≥0，故 AP1 可放宽成 M=5 的 AP5。a_k=8(k−1)+k²；加倍得 a_ku−(a_k−2)s−2F≥0。对每客户 C,D 会员位 c_i,d_j，单对系数为

两菜单长度 n_C,n_D 时，全部笛卡尔积求和使用 Σ_(i,j)c_id_j=(Σ_ic_i)(Σ_jd_j)=cd，得到

n_Cn_Da_ku_x−(a_k−2)n_Dc/(p+k)−2n_Cd/(p+1)+2[1/(p+1)−1/(p+k)]cd。

只保证全客户总行≥0，逐客户系数可负。七源恰 actual 的0,1,2,3，AEUVW 的2,3，ABEXY 的3（均零基）；强制 E 槽及末位排除。各节点的 u 是该真实规定动作的最终收益。回复菜单全由同一 σ 生成，重复索引保留，同有序历史不能指定矛盾回复。

## 7. CART 对定价闭包的局部贡献

固定十个原位会员位及共同比较计数 t。每个菜单计数是该族完整直方图的线性函数。CART 新项仅常数、c、d、cd；当 menu_specs 的一端固定/比较、另一端属于一个族，或两端同族时，新增目标仅依该族直方图。因此新增目标可以写 g0+gAB(HAB)+gAE(HAE)+gS(HS)；在共同 t 固定的三个独立完整直方图域上，最大值等于三项分别最大值之和。这是真实新增的数学贡献。

规格计数由 AB/AE 每源 2·10+10·2+2+2+2²=48，Sbranch 每源 3·10+10·3+3+3+3²=75，乘7共1197；固定10²+1每源，共707；连旧717共2621。源码把固定行加 base、ec/hc 加零；menu 新项无旧 ell,h，所以旧仿射角点问题结构不变；新单项式系数全部进缓存，常数缓存外加；crossweights 保 lam[557:717]，wrapper 避旧尾160切片。以上源码已完整比较，但 CART 公式本身并不单独证明旧717行、旧oracle所有系数/缩放和全部实现都正确，边按 contribution 保存，不冒作整个实现正确性的独立证明。

跨族 c(HAB)d(HAE) 一般引入两独立直方图乘积，三族可加式不再自动保持。有限四例回放、固定点 scalar 资格及浮点列生成是各自证据，不将其转为全域 oracle 或完整策略补全。
