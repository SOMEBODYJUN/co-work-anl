# 冻结轻分量 FPT 与站点原图计数 DP 的域、见证及参数区别

本比较的登记端点为 `SC-K-FROZEN-LIGHT-FPT` v3 与
`SC-K-LOCAL-WEIGHT-BOX-DP` v2。结论只比较同一次真实规范贪心、同一批冻结客户、同一完整盒下的在轨选择问题。它不把两个算法、参数复杂度或完整离轨实现说成等价。

## 共同输入与精确见证集合

输入采用共同目录正原子模型：客户逐名显式给出，权重为正二进制有理数，有限目录非空，显式给出 `k≥2` 家带标签设施。固定一次 canonical greedy 的正覆盖运行，得到占用地点集 `O`、重数 `q_s≥1`、末插入分数 `γ>0` 和每名已覆盖客户的原归属。已开站的下一家分数使用首次开设时冻结的原池 `W_s^0/(q_s+1)`；未开站使用尚未覆盖客户的新增总重。这里不把任意预设占用当作该贪心承诺输入。

把只有一个已占选项的客户及 `u_i≥γ` 的客户冻结于其原站。其余已覆盖客户组成 `I*`，每人有全部原已占选项 `A_i⊆O`，满足 `|A_i|≥2` 和 `0<u_i<γ`。设 `N=|I*|`，冻结在站 `s` 的客户总重为 `F_s`。未覆盖客户没有在轨动作，不进入 `I*`。

定义 `S_box` 为所有映射 `a:I*→O` 中满足以下条件者：

1. 每人整原子去一个原允许站，即 `a_i∈A_i`；冻结客户保持原归属。
2. 令 `W_s=F_s+Σ_(a_i=s)u_i`，每站有完整上下盒 `q_sγ≤W_s≤(q_s+1)γ`。
3. 对每名变量客户 `i` 及**每个** `t∈A_i`，都有

   `q_t(W_(a_i)−u_i)≤q_(a_i)W_t`。

在 `a_i=s` 后，让客户在该站的 `q_s` 家标签设施间独立均匀。它选任意本站设施的条件成本为

`u_i+(W_s−u_i)/q_s`，

选另一原可达站 `t` 的某家设施则为 `u_i+W_t/q_t`。因此第3项恰好是所有变量客户在原独立混合意义下的全部纯动作比较，并且也阻止全部混合偏离。盒不作为动作容量；即使某次偏离会出盒，其比较仍在第3项中。

冻结的单选项客户在当前布局没有另一可达物理站；本站设施由独立均匀策略对称。冻结重客户位于 `s` 时，即使有跨轻分量原备选 `t`，也由盒得到

`(W_s−u_i)/q_s≤((q_s+1)γ−γ)/q_s=γ≤W_t/q_t`。

故 `S_box` 精确描述两种方法共同搜索的“指定冻结、站点纯选后站内独立均匀、完整盒、全部原客户精确 NE”见证，不只描述变量子游戏的均衡。它不包含任意跨站混合 NE，也不附加归位保护 `H`。

## 有界轻分量给原图树宽和局部权种界

按 `I*` 的完整菜单连接站点：每个 `A_i` 中的所有站属于同一轻分量。等价地，站点原图 `G` 以 `O` 为顶点，每个 `A_i` 连成团。因为 `|A_i|≥2`，每名变量客户恰属于一个这样的站点连通分量；没有变量邻居的已占站作为单点分量保留。

设整数 `c≥1,d≥0` 满足：每个轻分量至多 `c` 个站，且该分量内变量客户的精确不同有理权值至多 `d` 种。对每个分量 `C` 取一个包含全部 `C` 顶点的袋。把这些袋按任意树连接；不同分量袋交集为空，所有图边均在某袋内，每个顶点只在一个袋出现。所得合法树分解宽至多

`max_C |C|−1≤c−1`。

它能直接按显式输入在多项式时间构造，不需要额外的固定树宽分解定理。每站 `s∈C` 的局部不同轻权集合是分量全部轻权集合的子集，故 `d_s≤d`。因此每个 `(c,d)` 轻分量承诺输入都在站点原图 DP 的 `(τ,d)` 域内，可以取 `τ=c−1`。`N=0` 时图为孤点并，局部权种为0，两法都直接返回冻结原盒状态。

## 支持 IP 与计数 DP 表示相同的全部见证

把变量客户按类型 `a=(u_a,A_a)` 分组，数量为 `n_a`，仍保留逐名原标签。两种方法都以整数 `x_(a,s)` 表示类型 `a` 分到 `s` 的客户数，满足 `x_(a,s)≥0` 和 `Σ_(s∈A_a)x_(a,s)=n_a`。

支持 IP 的二进制 `y_(a,s)` 由 `y≤x≤n_a y` 恰表示 `x>0`。活动位置恰检查

`q_t(W_s−u_a)≤q_sW_t` 对全部 `t∈A_a`。

非活动位置的大常数式仅消活该比较，不另删动作。分量 IP 的 `U_C` 是该分量固定总重加其全部变量客户总重，控制其中每站负载；所有变量菜单完全留在本分量。冻结重客户的跨分量备选已由前节的上下盒不等式支付。

计数 DP 的最终向量 `c_s` 记录站 `s` 每个局部权值的最终人数，部分向量 `p_s` 只记录已处理类型贡献。每个整类型在一个包含其完整菜单团的袋处理一次，枚举同样的 `x_(a,s)`。它在 `x_(a,s)>0` 时用**最终**负载检查同样的扣一名原子自重不等式；忘记站时要求 `p_s=c_s`，连接时只加部分向量而不重复加冻结总重。这里的 `c_s` 是计数向量，不是轻分量站数界 `c`。

每个 `a∈S_box` 诱导上述相同的计数、支持和最终向量，因而给出可行的分量 IP，并沿合法分解通过 DP。反之，任一可行 IP 或任一接受 DP 的回溯计数都可按任意顺序分配该类型的原客户标签，恢复 `S_box` 中的映射；同类型客户有相同权和完整菜单，因此所有这样的标签排列仍满足同一全原 NE 比较。给定 `S_box` 中任一逐名见证，取它自己的计数并恢复其原标签排列即可恢复该见证本身。

所以两种精确表示投影到逐名客户分配后的可行集合都恰是 `S_box`。在共同域上判定结果一致，恢复见证的保证一致；这里没有断言两种具体算法必定选择同一个见证，也没有把参数域外的一方算法作完整性声明。真实规范贪心的一般冻重盒存在性使该共同集合非空，但表示的双向正确性不靠“初始贪心分配已经是 NE”这一错误前提。

## FPT 与现有 XP 型界的准确差别

支持 IP 在每个轻分量使用至多

`2d(c·2^(c−1)−c)`

个整数变量。按源对象明示的标准固定变量整数规划合同，其总时间是 `f(c,d)poly(L)`，其中输入位长 `L` 的多项式指数不依赖 `c,d`。这是参数 `(c,d)` 的 FPT 保证；源对象未声称已经实现 canonical ILP。

站点原图计数 DP 的已证保守时间是

`poly(L,分解长度)(N+1)^[4d(τ+1)+τ+1]`。

代入上节直接构造的 `τ=c−1` 分解，只得到

`poly(L)(N+1)^(4dc+c)`。

每个固定 `c,d` 上它是输入位多项式，但指数随参数改变，因此这个**已证运行界**是 XP 型；它不能替代 `f(c,d)poly(L)` 的参数独立指数。上述域包含和见证集合相同也不证明该 DP 的另一个 FPT 实现不存在，更不证明该盒选择问题在 `(τ,d)` 下不可能 FPT。

此比较只交在轨盒见证。独立的数学 `BOX-TO-2` 接口不要求 `H`，完整位多项式离轨/default 完成仍按其 `MAX` 合同。当前两个数学选择器未实现为 canonical DP/ILP，现有在轨验证软件还额外检 `H`；这些接口层次不由本域包含消除。

## 严格 canonical greedy 的同权无界长链

对每个整数 `n≥2`，取共同目录 `s_1,…,s_n`，显式设施数 `k=n`，并令

`δ=1/(4n)`，`b_j=1+(n−j)/(2n)=1+2δ(n−j)`。

每站 `s_j` 有一名仅能到本站的私有客户，权为 `b_j`。每条相邻边另有一名权 `δ` 的客户 `e_j`，其完整物理菜单恰为 `{s_j,s_(j+1)}`，`1≤j<n`。所有客户逐名、不可拆、正有理；没有其他站、客户或覆盖。客户数为 `2n−1`，分子分母位长 `O(log n)`。

证明该真实规范贪心严格依次开 `s_1,…,s_n`，每站恰一家。假设前 `i−1` 步正如此开设。

- 若 `i<n`，`s_i` 的未覆盖候选为 `b_i+δ`：左边客户已在先前站覆盖，右边客户未覆盖。任意更晚内点 `s_j`（`i<j<n`）的候选至多 `b_j+2δ≤b_i`。更晚末点的候选为 `b_n+δ=1+δ<b_i`。故 `s_i` 严格胜过全部其他未开站，包括 `i=1` 时的情况。
- 若 `i=n`，仅剩 `s_n`，其左边客户已覆盖，候选恰为 `b_n=1`。
- 每个已开站 `s_h` 的冻结原池重为 `b_h+δ`（`h<n`）；它当前只有一家时的第二家候选至多

  `(b_1+δ)/2=3/4−1/(8n)<1`。

  只要尚有未开站，后者最大候选至少1，因此绝不会重复插入。

这完成全部 `n` 步的严格归纳，不依赖任何平局规则；末分数 `γ=1`。全部私有权 `b_j≥1` 冻结，而全部 `e_j` 权 `δ<1` 且有两个最终已占选项，都是可动轻客户。因此站点原图恰是 `n` 顶点路径，树宽恰为1，局部不同轻权数恰为1，但唯一轻分量含 `n` 个站。私有权的多样性不计入局部**变量轻权**参数。

还可直接给一个共同全盒原 NE 见证，避免只诉诸一般存在性：把每个 `e_j` 放到右端 `s_(j+1)`。此时

`W_1=b_1`，`W_j=b_j+δ (2≤j≤n)`。

各站负载均在 `[1,2]` 内。客户 `e_j` 位于 `s_(j+1)` 的外部负载为 `W_(j+1)−δ=b_(j+1)`，而其唯一另一站负载 `W_j≥b_j=b_(j+1)+2δ`，故全部可动客户严格稳定。私有客户只有一个选项，故这确是相同冻结下的原 NE 和完整盒见证。初始贪心原池分配通常不满足客户 NE，本证明未把它当作所求见证。

## 分离的量词与结论边界

对任意事先固定的分量界 `c_0`，取 `n>max(c_0,1)`，上节实例始终在原图 DP 的固定 `(τ,d)=(1,1)` 域，却不在“每轻分量站数≤c_0”的输入域。更强地，没有仅依赖 `(τ,d)` 的有限函数 `g`，能对所有这样的真实贪心输入保证轻分量站数≤`g(τ,d)`：只须取 `n>g(1,1)`。

这是两类**结构参数承诺**的严格单向包含：有界分量给有界原图宽度及局部权种，反向无法以固定 `(τ,d)` 控制分量站数。每个单独有限路径当然仍可取 `c=n` 后运行 FPT 选择器，不能说它处于该算法所有参数取值的适用范围之外。该同权族也未提供任何搜索困难性或时间下界；更不证明两个选择器的输出集合不同。共同域的精确见证集合相同与结构参数域严格分离完全相容。
