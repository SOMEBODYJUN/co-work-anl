## 一、模型、资格和退化输入

输入是有限机器集 M、任务集 J，`m>=1,n>=0`；每个 `p_ij` 为非负二进制整数或不可用 `infinity`。每个任务必须完整放到一个有限端，目标为各机器真实处理时间之和的最大值。不同机器上的同一任务时间可以不同，不使用 restricted assignment 假设，也不改变任何端值或资格。

先扫描输入。`n=0` 时输出空分配和值 0。若某任务没有有限端，报告不可行；这也说明通常“每任务至少一有限端”的合同如何在外部入口检查。无资格任务不因图宽小而被悄悄丢弃。删除没有任何资格任务的机器只去掉永远为 0 的负载，最优值和其余实际分配完全相同。下文对剩余非空可行实例进行。

零时间端仍是真实资格边。选择该边必须把任务标志从 0 改为 1，不能从负载 0 推断任务尚未分配。算法无正 OPT、数值网格或除法前提，因而 OPT=0 也直接得到真实最优分配。

## 二、团大小和团共同袋

令 `J(i)={j:p_ij<infinity}`。任意两个不同的 `j,j' in J(i)` 共享机器 i，故在 primal 图相邻。因此每个 J(i) 是团。

设 `(T,{X_t})` 是 primal 图的宽 k 树分解。每个任务 j 的出现袋组成连通子树 T_j；同一团中的任意两个任务由边覆盖条件得到两个出现子树相交。有限树上的连通子树具有 Helly 性：把树定根，取这些子树中“离根最近的顶点”深度最大的一棵，记该顶点为 z；与它相交的任一另一子树的最近根顶点和交点之间的路径包含 z，故 z 属于全部子树。于是存在袋 X_t 包含整团 J(i)。

所以 `d_i=|J(i)|<=k+1`，`Delta=max_i d_i<=k+1`。这里的减一不能漏：树宽是最大袋大小减一，单任务单机器的 primal 宽为 0。

若只在包含 J(i) 的袋上挂 `J(i) union {i}`，已得到 incidence 宽不超过 k+1 的分解：原任务出现子树仍连通，机器只在所挂袋出现，全部资格边被覆盖。因每台机器的可能负载为其资格任务子集和，`L_i<=2^{d_i}`，含空集和 0；重复和只会减少不同负载值数。仅将 `w<=k+1,L<=2^{k+1}` 代入 M247 黑盒，确实只得到 `2^{O(k^2)} poly(input)`。以下保留分解的特殊形状，付清更强界。

## 三、机器只在叶分支，join 只有任务

先把 primal 分解整理成空根、空叶、引入/遗忘单任务和二叉 join 的形式；复制袋和在相邻袋之间先删除旧袋独有任务、再加入新袋独有任务均不增加袋大小。所有这些袋只含任务。

对每台非空机器 i，找一个原袋 X 包含 J(i)。在 X 处接一个新分支，并用袋 X 的二叉 join 与已有子树合并；多台机器挂在同一 X 时用若干份 X 串接这些 join。每条新分支由下向上严格使用下列模板：

1. 空叶；逐个引入 J(i) 中的任务，标志初始化 0。
2. 引入唯一机器 i，初始化其负载为 0。
3. 对每个 j in J(i)，恰介绍一次资格边 ij。
4. 遗忘机器 i，把其已完整负载计入已关闭机器的最大负载。
5. 引入 X\J(i) 中的其余任务，标志初始化 0，抵达只含任务的袋 X。
6. 在 X 与主树的其余部分 join。

分支中不会提前遗忘任何 J(i) 任务，因此“未选给 i”的任务不会被错误地强迫分配。每条资格边只在唯一机器分支的一个指定 introduce-edge 节点介绍。i 的全部出现组成同一条不分叉路径，而且它在进入任何 join 以前已经遗忘。于是任意袋至多有一台机器，所有 join 袋完全不含机器；最大袋是 `J(i) union {i}`，大小至多 k+2，即 incidence 宽至多 k+1。

对任务 j，原主树上的出现子树连通，新分支仅从一个已含 j 的袋延伸出含 j 的连通路径，故其全部出现仍连通。一个任务可能在不同叶分支多次 introduce；每次只是初始化该子树尚未选择任何边的局部计数。所有选择由唯一资格边承载，而不是由 introduce-vertex 节点承载。join 会相加两个子树的局部计数，最终唯一向根消失的 forget 才检查完整计数。这正是重复 introduce 不复制原任务的原因。

## 四、闭合最大负载的精确 DP

对 nice 节点 t，令 E_t 为其子树已经介绍的资格边集合。每个状态包含：

* 每个袋内任务 j 的一位 `b_j in {0,1}`，等于 E_t 中选中并与 j 关联的边数。
* 若袋内有机器 i，它在 E_t 的已选边负载 `lambda_i`；没有机器时该部分为空。
* 一个表值 c：在满足这些接口信息、且所有已经遗忘的任务都恰选一条资格边的局部选择中，已经遗忘机器的最大负载的最小值；无遗忘机器时最大值取 0。

任何忘出袋的顶点不再出现在子树以外，故其全部关联边已经介绍。这个性质来自分解的连通出现条件和每条介绍边必须同时含两端。状态完全表达未来会接触的任务计数和机器部分负载；对于同一接口，较小的 c 在未来的 max 运算下永远不劣，所以仅保留最小 c 是精确的。

递推如下，所有可达选择都取最小表值。

* 空叶仅有空状态，值 0。
* introduce-job 把新局部标志置为 0；introduce-machine 把新局部负载置为 0。
* introduce-edge ij 可以不选；也可在 `b_j=0` 时选择，把该位改为 1 并令 `lambda_i:=lambda_i+p_ij`。表值 c 暂不改变。
* forget-job 只接受 `b_j=1`，然后去掉此位。
* forget-machine i 去掉负载坐标，并令 `c:=max(c,lambda_i)`。
* join 袋仅含任务。两个子树介绍的边集不交；令 `b_j=b_j^left+b_j^right`，只保留各和不超过 1 的组合，表值候选为 `max(c_left,c_right)`。

这些规则直接保持上述不变量。反向看，任一全局合法分配在每个 E_t 的限制都给一个合法局部选择，从而沿对应状态不会被剪掉；任一空根接受选择使每个任务最终恰选一条真实资格边，每台机器在遗忘时计入完整负载。空根的最小 c 因而恰为 OPT。

这里只计已关闭机器的 c 是明确的状态定义，不把活跃机器的完整 Cmax 偷换成两个子树 Cmax 的最大值。活跃机器负载保存在 lambda，待 forget-machine 才进入目标。算法直接最小化真实目标，不在 `0..OPT` 逐值搜索，也不需要先知道 OPT。

## 五、单指数状态数、算术次数和分解取得

机器 i 的负载总是 `sum_{j in S}p_ij`，其中 `S subset J(i)`，因此至多 `2^{d_i}` 个不同数值。机器活跃时袋内只有其 J(i) 任务，故即使用宽松的“任务位与负载值分别枚举”估计，该袋状态数也至多 `2^{d_i} 2^{d_i}<=4^{k+1}`；实际负载可由选中子集确定，状态往往更少。机器之外的主树袋至多有 `2^{k+1}` 个状态。

join 不含机器，每个袋内任务只有“未在两边选择、仅左边选择、仅右边选择”三种合法组合，故所有状态组合总数至多 `3^{k+1}`。机器分支上的边介绍、机器关闭和状态更新也只需 `2^{O(k)}` 次加法/比较。不能把这个特定分解重新粗化为“每个宽度坐标都可能是一个独立机器负载”，否则会无谓退回平方指数。

若输入分解有 b 个袋，整理和新增机器分支得到 `O((k+1)(b+m))` 个 nice 节点；每个 J(i) 的共同袋可以通过扫描袋寻找，费用 `O(poly(k)bm)`。以论文通常的 `b=O((k+1)n)` 分解规模计，连同显式矩阵读取、每机至多 k+1 个资格任务、局部子集和和回溯，全部 DP 和构造的加法/比较次数为 `2^{O(k)} O(nm)`（非空 n,m；k 的多项式因子被单指数吸收）。

任意人为冗长的显式分解必须先付读取代价，不能给出独立于它长度的运行时。可在根定向后删除满足子袋包含于保留父袋的节点，把其孩子接回该父袋；top-down 只对每个原节点作一次包含检查即可。所得每个非根保留袋含一个不在父袋中的任务；该任务的最高出现袋唯一，所以这些“新任务”可以按袋注入到 J，保留袋数至多 n+1。这个缩减保宽、覆盖和连通性，不是求树分解的算法。可将读取/缩减代价另列为输入分解长度乘 `poly(k)`，然后取得上述 DP 界。

如果只输入资格图而没有分解，使用目标合同允许的 FPT 求分解入口。PDF 页 5 明说宽 k 分解可在 `f(k)|V|^{O(1)}` 时间取得，并写产生 `O(k|V|)` 个袋；为兼容 k=0，这里的统一规模按 `O((k+1)|V|)` 计。本轮不把其外引文献当作独立重证。完整精确 FPT 的时间是该独立取得代价加上本轮 DP。未声称求分解本身也是 `2^{O(k)} O(nm)`，也没有用已有 fixed-k 的 `n^{O(k)}` 搜索冒充 FPT。

## 六、二进制位长与实际回溯

令 B 为有限输入处理时间的最大位长。任何存储负载都是某台机器至多 n 个原整数的子和，非负且至多 `n max p_ij`，故其位长为 `O(B+log(n+1))`；闭合峰值 c 为此类数值的最大值，具有相同位长。每次加法、比较、选中边记录和索引处理均按其真实位长计费。枚举范围只依资格任务子集，不依处理时间数值大小或 OPT 大小，因此大二进制整数不会引入伪多项式循环。

每个最优表项保留实现其最小值的子状态、边是否选中及 join 分拆指针。自空根回溯至叶，每条边只在其唯一介绍节点读取选中决定；每个原任务最终恰出现一条选中边，输出该边的机器标识。输出共有 n 个实际机器选择，并可按原矩阵重算所有负载；输出位数 `O(n log(m+1))`。这得到实际最优分配而不只是目标数值。

因此，在给定常规规模宽 k 分解时，上述算术次数乘各次操作的位成本仍是 `2^{O(k)} poly(input-bitlength)`；连同 FPT 取得分解项仍为参数 k 的精确 FPT。有限端允许零时，计数位依旧保证任务恰一次，位复杂度与回溯论证不变。

## 七、原 primal 递推确实给出目标的论文时间

本轮对原 primal 页 7–9 的承重链作了独立静态检查。以袋内任务为 J_t，离开子树接口的任务为 check J_t，至 parent 才离开的为 tilde J_t；令 `check M_t=M(check J_t)`、`tilde M_t=M(tilde J_t)\check M_t`。若机器承接已失活任务，则它的其他资格任务只能在当前接口或同一子树；否则共享机器产生的 primal 边与任务出现连通性冲突。因此 `J(check M_t union tilde M_t) subset J_t union check J_t`。对刚失活任务的机器，排除 check M_t 后，同样得到 `J(tilde M_t) subset J_t`。

左右子树的失活机器组彼此不交：若同一机器在两组出现，它分别承接左右两个已离开父袋的任务，两任务在 primal 相邻；覆盖此边的袋和连通性会迫使它们经过父袋，矛盾。这正是 primal Lemma 10 中两个子调度目标可用 max 合并的理由，负载不会在同一机器上跨两个孩子相加。

于是对袋内子集 J 的 S(t,J)，左右按不交任务子集枚举，得到 Lemma 10；对 `J' union tilde J_t=A dot-union X`，A 交给 tilde M_t，X 连同既有失活任务交给 check M_t，机器组不交且 `J(tilde M_t) subset J_t`，得到 Lemma 11。第二步子问题只有 A 中至多 k+1 个任务，Section 2 按机器枚举任务子集的精确 DP 需 `2^{O(k)} O(m)`。各袋所有状态、分拆和该子问题仍为 `2^{O(k)} O(m)`；常规 `O((k+1)n)` 个袋给 `2^{O(k)} O(nm)`。

所有取最小/最大和小子问题均保存达到最优的选择即能回溯。这同时核清目标“论文 DP 运行该时间”的事实归属。原 Remark 7 的团下界漏减一及 Lemma 9(6) 中文漏 check 已由当前正文历史修正；本轮未重新提出这两处旧修正。

## 八、本轮发现的额外源递推问题与最小修正

原 PDF 页 4 定义 `OPT(S)=min_{sigma in S} Cmax(sigma)`；页 9 又定义 `S(t)=S(I[check J_t,check M_t union M_t])`，S(t,lambda) 仅限制 M_t 的负载。按这些定义，它计入活跃机器。页 10 Lemma 13 印为父值等于最小的两个子值最大值，缺少合并后父活跃负载这一项。页 11 incidence Lemma 15 的同类 join 也须保留这一目标语义。

明确反例：机器为 a,i,b；任务 x 资格为 {a,i}、y 资格为 {b,i}，`p_ix=p_iy=1,p_ax=p_by=2`，其余端不可用。dual 图是路径 a–i–b。取空袋根 a_root，唯一孩子为空袋 u；u 的孩子为 t={i} 和空叶；t 的两个孩子为 l={i,a}、r={i,b}；l,r 各有两个空叶。每个图边被覆盖，每台机器的出现袋连通，且满足源文空叶和二叉内部节点形式。

按当前正文已修正的 nearly-inactive 机器定义，l 的失活机器为空、刚失活机器为 {a}、刚失活任务为 {x}；r 对称为 {b},{y}。故 tilde S(l) 是把 x 分配到 {a,i} 的调度集合。取 `lambda_l(i)=1,lambda_l(a)=0` 强制 x→i，子 OPT=1；右边同样强制 y→i，子 OPT=1。父 t 的失活机器为 {a,b}，活跃机器为 {i}，失活任务为 {x,y}。给父 `lambda(i)=2`，其 OPT=2。左右投影负载必须相加为 2，而每边在 i 的负载只能是 0 或 1，故 (1,1) 是唯一满足父负载的拆分，min 无法避开。印式右端为 1，左端为 2。

保留原 OPT 定义时，最小修正是在 join 右端同时取 `max_{i in M_t} lambda_i`。另一种等价的完整算法表述是本轮明确给出的 closed-cost 状态：只把已经忘掉机器的峰计入 c，活跃负载单独存储，机器遗忘时才用 max 计入。这后一种语义已逐节点证明，不能只改公式却留下旧 OPT 定义。

## 九、端点比较、方向和后续处置

M247 到 M232 的本次迁移不改实例、资格端或 p_ij，仅将 primal 宽 k 对应到受控 incidence 分解，并细化运行时计数。无开放参数前提、数值猜测或未经证明的后端。所保留的条件都是目标模型及既有分解入口的合同。ALL 模式只有这个精确来源，不把共享定义另立为数学 hub。

反方向的准确范围也作了静态核对。给 incidence 宽 w 的分解，把每个袋中的机器 i 换成整个 J(i)，并保留该袋原有任务。若每机资格度至多 Delta 且实例非空可行，则 Delta>=1，新袋大小至多 `(w+1)Delta`。每条 primal 边的两个任务共享某机器 i，任一原来含 i 的袋替换后就同时含两者。一个任务 j 的新出现集合是原任务出现子树与所有相邻机器出现子树的并；每台相邻机器的子树通过某个覆盖资格边 ij 的原袋与任务子树相交，故其并连通。因此得到 primal 宽至多 `(w+1)Delta-1`。这正是 Remark 8 的另一方向，结合 M232 可支付 M247 的 degree 参数支。

它没有自动支付 M247 的 OPT 参数支。明确例子为 n 件任务各有一台仅处理它的私有机，时间 1，另加一台可处理全部任务的机器，其每端时间也为 1。incidence 图是树、宽 1，全部放私有机给 OPT=1；但共同额外机器使 primal 为 K_n、宽 n-1，目标 OPT=1 的大端剪枝也不会删除任何资格。故不能仅用 `(incidence宽,OPT)` 通过该结构替换去界 primal 宽。这个例子只排除了这条特定参数桥，不反驳 M247 的 OPT 支，也不声称不存在其他证明。
