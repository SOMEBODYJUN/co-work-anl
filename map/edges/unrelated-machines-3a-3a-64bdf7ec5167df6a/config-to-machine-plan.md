# CONFIG 投影到有界资格机器计划的可行性接口

## 1. 对象、实读范围与关系的作用范围

本比较的核心为 `M-665cd08feee04456b5cb538e29d62305` v2，只读对端为 `M-8dec531708464aaa87be325982ae38fc` v1。两者分别是每机至多 2、3、4 项资格的整数流算法，以及 CONFIG(T) 投影恰为各机合法 0/1 配置凸包加逐任务列和一的结构等价。registration pins 与任务现行 input_pins 一致。

实读两端登记陈述和完整正文，重点复核 Page–Solis-Oba–Maack 冻结作者稿第 6 节（PDF 物理及印刷第 9–11 页）的分案 (a)–(f)、Figure 5 和 Theorem 2；Figure 5 另经渲染核对。其余论文正文和参考文献已以 pdftotext 提取阅读，不把引用中的外部算法当作本比较的推导前提。对 CONFIG 端实读“配置松弛、单机凸包与局部切割”完整自足证明；本比较不依赖该资源中其它定理、图平衡趋二例或外引算法。

恢复稿曾参考 `07fa3ec375d2385b` 的机器计划辨识；本轮直接从冻结 PDF 的分案和 Figure 5 独立重建下述网络，不以该任务或其对象作为额外依赖，也没有改写其边。本次比较的是 CONFIG 投影与该网络的精确接口。这里交付的是核心的**满流存在性这一证明步骤**，不把 CONFIG 投影等价单独记成整条算法定理的完整证明。

## 2. 阈值、行计划与全部合法配置的包含

模型是有限机器集 M、任务集 J；有限加工时间为正整数，其余为不可用端。每机原资格数至多给定的 `ell in {2,3,4}`。给正整数阈值 T，删去加工时间大于 T 的端，记余下资格集为 K_i，q=|K_i|。任何 T 可行配置本来就不使用被删端。若任务已无资格机，则 CONFIG(T) 不可行、也不可能有满流；以下允许这种情况自然由最大流检出。

机器计划指定总容量 d_i 和缓冲门集合 B_i；其整数允许集为

`A_i={A subseteq K_i: |A|<=d_i and |A intersect B_i|<=1}`，

行不等式为 `0<=x_ij<=1, sum_j x_ij<=d_i, sum_(j in B_i) x_ij<=1`。缓冲集合以外的资格直接到机器，B_i 中资格先经过共用容量一门，再到机器；机器到汇容量 d_i。机器和缓冲门均为每机专用。

令 `C_i(T)={C subseteq K_i: sum_(j in C)p_ij<=T}`。以下核实原论文按顺序选择的每个计划都满足 `C_i(T) subseteq A_i`。这是单机 0/1 配置包含，不预先假设任何全局整数 T 调度存在。

1. q=0 时取 d_i=0，只有空配置。
2. 若整行总加工时间至多 T，取 d_i=q、B_i 为空；允许全部资格子集，恰与合法配置族相同。特别不能先按“大任务至多一项”误删此分案。
3. 余下总和大于 T 且 q<=3 时取 d_i=q-1，B_i 为所有 `p_ij>T/2` 的资格。合法配置不能含全 q 件，也不能含两件 B_i，故满足两容量。
4. 余下 q=4，降序记加工时间 `p1>=p2>=p3>=p4`。若 `p2+p3+p4>T`，取 d_i=2、B_i 为所有大于 T/2 的资格。三个最小加工值之和已经超 T，所以任意合法配置至多两件；两件大任务仍不可能同现。
5. 若 `p2+p3+p4<=T` 且 `p1+p2>T`，取 d_i=3，并把前两资格加入 B_i。任意合法配置不能含全部四件，也不能同时含前两件。后三项和至多 T 还保证 `p3<=T/2`，故原来大于 T/2 的资格全部已在前两项中；添加前两项后 `B_i={j1,j2}`。因此新缓冲门也不排除合法配置。
6. 若 `p2+p3+p4<=T` 且 `p1+p2<=T`，取 d_i=3、B_i 为所有大于 T/2 的资格。全四件总和仍超 T，因此合法配置至多三件；大任务容量一仍有效。

于是每个配置特征向量都满足该行计划的线性不等式。取凸组合，`conv{1_C:C in C_i(T)}` 中的每个点仍满足全部这些不等式。没有要求或断言反向包含。

## 3. 从 CONFIG 到分数满流，再到整数满流

假定 CONFIG(T) 可行。由对端的投影等价，有 `x_ij=sum_(C contains j)y_iC`，每行 x_i 是合法配置特征向量凸组合，而且每任务 `sum_i x_ij=1`。第 2 节于是给

`sum_j x_ij<=d_i` 和 `sum_(j in B_i)x_ij<=1`。

在 Figure 5 网络中，从源向每个任务送一单位，再按各端 x_ij 分流。非 B_i 端直接送到机器；B_i 端先送到该机缓冲门。每条资格弧容量一，因为 `0<=x_ij<=1`；缓冲门容量一和机器出口容量 d_i 分别由上面两个不等式保证。所有流守恒，源端任务弧全部饱和，所以存在值 |J| 的分数流。

网络容量全为非负整数，最大流整数性给出同值的整数最大流。源到任务容量一并且全部饱和，故每任务恰沿一个有资格端送一单位；这解码为实际完整分配，逐机满足 A_i 的两个基数限制。该论证只使用一个共同的投影 x，没有把机器配置独立采样后假装每任务恰一次。

所得已经成立的关系为：

`CONFIG(T) feasible => Figure-5 full integral flow exists`，

以及其逆否命题 `flow REJECT => CONFIG(T) infeasible`。给定输入和 T，网络及最大流均可在显式输入的位多项式时间内构造和求解；论证不需要实际先求一份 CONFIG 证书。每机至多四项时 CONFIG 本身至多 16 个局部配置也可枚举，但这不是本边的算法依赖。

任意真实 T 调度给 CONFIG(T) 的确定性配置点（每机给其实际所取任务集配置权重一）。因此上式也补足核心声明中的 `OPT<=T => full flow`。原目标完整定理还需要：对网络任意整数输出证明 1、3/2、5/3 三种负载界；用可靠 REJECT 和正整数阈值搜索得到相对真实 OPT 的算法；以及三角形自由交叠图蕴含每机至多两资格。这些已在核心原证明中成立，**本边只登记上述可行性步骤，不以单个结构等价替代其余推导**。

### 3.1 阈值搜索只需要可靠拒绝，不需要满流接受性单调

这里“正整数阈值搜索”不应被解释为用单调判定器精确找出最小满流阈值。冻结 PDF 第 9 页关于找到最小成功 T 的措辞过强，算法定理本身并不需要它。

明确例子有四项任务 a、b、c、d：机器 1 加工时间依次为 10、5、4、3；机器 2 只有 c 的资格且时间为 1；机器 3 只有 d 的资格且时间为 1。a、b 必须在机器 1，故 OPT=15。在 T=10 时，机器 1 的后三项总和为 12>T，属于 (d)，d_1=2、B_1={a}，于是把 a、b 给机器 1、c 和 d 各给其专用机器是满整数流。在 T=12 时，属于 (e)：后三项和为 12，前两项和为 15>T，缓冲门改为 B_1={a,b}，强制 a、b 共用容量一，故不能满流。这只否定接受性单调，不否定可靠 REJECT 或近似保证。

当 J 非空且每项任务至少有一个有限正整数端时，取整数下界 L=0（拒绝）及成功上界 H 为全部有限端加工时间之和；在 H 下每行属于 (b)，所以满流存在。每步取整数中点，若成功则设 H 为中点并保存其调度，若拒绝则设 L 为中点。由已经证明的 `OPT<=T => success`，拒绝必有 `T<OPT`，因而始终保有 `L<OPT`；同时 H 始终成功。区间收缩到 H=L+1 时，整数性给 H<=OPT。于是保存的调度负载至多核心的相应比例乘 H，也至多该比例乘 OPT。这个过程可以错过更小的成功阈值，但不会损害 Theorem 2。空任务集直接输出空调度；没有有限资格端的任务直接判无可行调度。

当前 v2 正文和登记陈述仅说二分阈值及相应近似，没有声称流接受性单调或精确找到最小成功阈值。因此这里给出精确的搜索依据，无须改变核心命题或 registry。

## 4. 何时等价，以及逆向失败的精确实例

ell=2 时，每机计划的整数允许集恰为 C_i(T)：整行总和不超 T 时允许全部子集；否则仅可能是两项资格且总和超 T，此时 d_i=1，仅空集和单件合法。因此满流当且仅当存在真实 T 调度；第 3 节与确定性配置点又给 `CONFIG(T) feasible iff full flow iff integral T schedule`。这与核心精确分支一致。

ell=3 或 4 的域中不能把上述包含升级为等价。一个完全明确的整数实例：T=10，任务 a、b、c；机器 1 的有限加工时间分别为 6、5、1；机器 2 只有任务 c 的资格，加工时间 1；其余端不可用。每机资格数分别为 3 和 1，属于 ell=3，也属于 ell=4 的上界域。

机器 1 总和 12>T，选 d_1=2、B_1={a}；机器 2 选 d_2=1、B_2 为空。将 a、b 给机器 1，将 c 给机器 2，便是满整数流；机器 1 实际负载 11。所有真实分配中 a、b 都必须给机器 1，所以 OPT=11>T。CONFIG(T) 同样不可行：投影必须有 `x_1a=x_1b=1`，但机器 1 的任何 T 合法配置都不可能同时含 a、b，因而凸包有效不等式 `x_1a+x_1b<=1` 被违反。

这同时说明机器计划行多面体含不在 CONFIG 单机凸包中的整数点 `(x_1a,x_1b,x_1c)=(1,1,0)`。其用途仅是排除“流计划精确描述 CONFIG(T)”或“满流说明 OPT<=T”的候选桥；它不反驳两个登记对象，也不构成两者之间的 refutes 边。CONFIG 已含全部单机有效切割的结论仍完全有效，流算法只是使用合法配置凸包的外松弛。
