# 末覆盖重数判据：有限审计、完整 SPE 与 half 的边界

## 核心结论

本包的核心对象是 `M-b24a8511d5c54a3cb4eba5f809a3f24e`（实际末主题重复覆盖重数的平方阈值半覆盖判据），而不是一个固定回复的 LP 对象。模型是空根背景、有限单位客户、有限非空共同标签目录、`m` 个单位提供者依全部有序历史选一次标签、终局客户价值在覆盖者间均分的完整纯 SPE。允许重复动作、同覆盖异标签、空主题、零客户及任意离轨弱平局；`k` 按最终客户覆盖集合恰等于实际末覆盖集合 `B` 的玩家数计，不能用同标签计数替代它。

末位最佳回复必为包含极大客户集；因此真实末节点的“包含 `B`”人数等于同覆盖重数 `k`。令 `S=|B|`、`u` 为末位利润、`W` 为实际总覆盖、`V=W-S`，并令
`R=sum_{x in (union_i S_i)\\B} 1/(c_x+1)`。逐客户税分解和末位 IC 给出

`OPT_m <= W + (m-1)u - R`.

每个实际玩家在其真实前缀改选 `B`，沿同一完整策略的真实改变后历史至少取得 `S/m`；故 `ku <= S <= mu` 且 `W >= k(2m-k)u/m`。丢弃 `R` 后，`(m-k)^2 <= m` 是足以 `OPT_m <= 2W` 的平方判据。保留 `R` 并用 `R >= V/(m-k+1)` 可将真实前缀缺席收益进一步细化，但这一步仍是完整 SPE 的真实偏离下界，不是冻结后继的 LP 行。

## 与前缀缺席判据的关系

通过 `map read-add` 实读了共享端点 `B2-REPEATED-LAST-ABSENCE-v1`。同一正文的逐客户前缀缺席式为

`u_i >= sum_{x in T} 1/(m-n_i(x))`，

对 `T=B` 重排后得到 `A_r = H_m-H_t-(t-k)(m-t)/(mt) >= k(m-t)/(mt) >= 0`，再以 `a=(d+2)/(d+1)`、`d=m-k` 定义 `gamma(m,k)=min_t C_t`，从而 `W+R >= gamma(m,k)u`，`gamma >= m-1` 足以 half。该 γ 判据严格加强平方判据；正文中已经存在由 B2 γ 判据到其它线性残余对象的边，本文不重复反向逻辑边，也不把平方判据宣称为 γ 判据的逆命题。

有限定义检查逐字核对 `m<=12` 的 8178 个覆盖/缺席序列、364 个按 `r` 的最小值、`m<=100` 的 171700 个系数和同数目的多项式下界、724 个旧平方包含、933 个旧残余到 γ 的蕴含、1156 个多项式认证案例，以及 `m<=60` 的 37820 个放松 `(d,h)` 端点恒等式。全部有理断言通过；六行报告 `(m,d)=(6,3),(8,4),(12,5),(20,7),(50,12),(100,17)` 的 γ 和旧阈值与冻结表逐项相同。`m=6,k=3` 的 γ 为 `85/16>5`，故六人末覆盖重数至少三次的子类有 half 认证；`m=5,k=1,2` 的 γ 分别为 `127/50`、`95/24`，在这一接口下不认证，但这不是五人 half 的反例（五人 half 有独立对象）。

## 固定回复/LP、真实完整 SPE 与 half 的边界

声明材料中的原算术脚本和新定义脚本只检查标量 `(m,k,r,t)` 公式，或有限完整 SPE 的固定输入；没有发现 LP、固定回复链或可把 LP 质量直接解释为同一合法共同目录客户重数的证书。因此 `gamma` 未通过、旧有限条件未命中、或多项式筛选失败，都只表示该充分判据没有支付到 `m-1`，不表示存在 half 反例。

两个恢复的五人原审计仅针对六个固定种子（七或八主题、三种扩展）及其 exact solver：共 174 条有序 SPE 路径、14 条满足旧/残余 half 条件；六个实例的最小福利比为 `6/5, 7/5, 40/31, 15/13, 35/27, 1`。这些是有限完整 SPE 检查，不能外推至全部六人 SPE 或全模型。新定义 JSON 另含一个 14 单位客户的两位提供者完整 SPE 点：实际 `(0,1)`、`W=8`、`OPT=10`、half slack `6`、唯一最优有序元组 `(2,3),(3,2)`、`R=9`；它校准税/分区计算，仍然不是 half 反例，也不是 LP 证书。

因此本包只发布一条 self-context `checks` 边：它把公式审计、有限 exact-SPE 样例和停止边界接回核心对象；不声称固定回复/LP 能构造完整 SPE，不把有限负例或判据未命中升级为全模型反例，也不新增跨对象逻辑边。尚欠目标是对未被 γ/平方条件覆盖的真实 `k,d` 类给出新的完整 SPE 证明，或提供同时满足全部历史 IC 的精确反例；需要支付真实偏离后的完整续局，而非冻结响应行。
