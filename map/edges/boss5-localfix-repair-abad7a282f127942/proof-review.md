\[
A_{i,j}^{(\ell)}=(\Gamma_{L,i}\times\{j\})\cup((\Sigma_{L,i}\setminus\Gamma_{L,i})\times\{j+\ell\}),
\]
\[
B_{i,j}^{(\ell)}=(\Gamma_{R,i}\times\{j\})\cup((\Sigma_{R,i}\setminus\Gamma_{R,i})\times\{j-\ell\}).

## 三可着色图的完整目标

实际目标是：对每个固定整数 k≥3，在有限图上区分 3-colorable 与非 k-colorable 为 NP-hard。不能把 k 当作随输入增长且免费的参数。

先由上一节得到任意固定 palette C 的八色 YES 硬度：选 `a<1/C`，有 C 着色必有比例≥1/C 的独立色类，所以 NO 图非 C-colorable。GS20 Lemma 8 的有限 arc-graph 归约再把固定八色 YES 降到三色 YES。其一般步骤是

\[
\operatorname{GraphColoring}(b(t),b(c))\le_p\operatorname{GraphColoring}(t,c),\quad
b(n)=\binom n{\lfloor n/2\rfloor}.
\]

例如 `b(4)=6,b(6)=20≥8`，两次一般步骤足以把八色 YES（也可视为二十色）变成四色 YES。给定最终 k，先取一个固定的中间 NO palette `t4=2^(2^k)`，再取源 C 至少为 `b(b(t4))`。接着应用 GS20 所列的两次 arc 构造，`arc²(K4)` 三可着色，因而四色 YES 保证最终三色 YES；反向若最终图 k 可着色，arc 的标准子集着色界两次给出原四色阶段的图至多 `2^(2^k)` 可着色，与其 NO 保证矛盾。这里仅需该固定常数链，GS20 Lemma 8 已给出其图模型与多项式归约。

所有常数按“最终 k → 中间 palette → 源 palette C → 独立集阈值 a → PCP soundness → 常数字母表”顺序选择。每段都是固定常数参数的确定性多项式归约，正例始终完整合法着色。得到目标整句，并与 FMW Corollary 1.7 一致；未调用其 Remark 1.8 的稍超多项式、缓慢增长色数版本。

## 共同前提中的确定性双正规化

超图目标的源比核心多一项：KS14 Definition 2.4/Conjecture 2.5（印刷 p7，物理 PDF p8）显式要求 biregular，脚注说当时不知是否可 WLOG。不能从核心的模型名或 MZ 的不完美双正规版本免费获得它。本边的第二共同前提是正式登记的独立正规化引理，全文入口保留。

为完整复核，令原未加权二部投影多重图有 E≥1 条带身份约束，去孤点。每个原左点 u 建 d_u 个 clone，每个原右点 v 建 d_v 个 clone，两侧各 E 个。每条原约束 e=(u,v) 在其两云全部 clone 对间放同一原投影，权 `1/(d_u d_v)`，并保 e tag。每 clone 加权度1，总权 E。

固定任何 clone 标签，对每个原点独立均匀抽一个 clone 标签；每原 e 的期望满足指标恰等于它的所有 clone 对的加权满足量。故新加权值不超过原值；原最优标签复制给全部 clones 取得反向界，加权值严格相等。原完美标签满足每条复制约束。

设 `S=Σ_e d_u d_v≤E³`，给定有理 `0<η<1`，取 `D=ceil(S/(ηE))`。对每个带 e 身份的 clone 对引入 `x_eab=D/(d_u d_v)`；每个 clone 的行/列和都是整数 D。先取 floor，每行列剩余需求为非负整数，分数余量给这些需求一个容量1的可行二部流。整数流解把每变量舍成 floor 或 ceil，仍保每行列和 D。平行变量作为不同流弧，不能把投影不同的变量合并。得到两侧各 E 点、全部度数 D、边数 DE 的未加权二部约束多重图。

对任意 clone 标签，满足指标为0或1，舍入前后归一分数差绝对值至多 `S/(DE)≤η`。该逐标签统一界直接可对最大值使用，无需枚举或概率并集。因此新值与原值差≤η。原完美标签满足所有留下的非负重数约束，故新 YES 仍严格为1；逐边标签和投影原样保留，exact4 没有损失。

`S≤E³,D≤E²/η+1,DE=O(E³/η)`；有理数位长、整数流网络和构造规模皆可控。固定 η 或计入1/η时为确定性多项式显式输出；不声称对二进制 η 仅依赖 log(1/η) 的显式输出多项式，也不用指数 lcm。源取 soundness ζ/2、桥取 η=ζ/2，得到 exact4、biregular、完美 YES 与 NO≤ζ 的全部合同。两共同前提均在，不拆为各自单独充分。

## 带身份平行约束的平滑多层化

本节补足旧 proof 仅用自然语言说明的 KS14 Appendix A 扩展。它给一个可直接检查的 typed 有序坐标版本，不需要假定每对端点只有一个投影。设正规化后的源为 `V→U`，共同域 `[m]→[k]`，`m=dk,d=4`。每个 V 点 incident constraints 数相同为 b，每个 U 点相同为 a，按独立 e 身份计；允许同端点多个不同 π_e。记源约束集合为 F。

固定层数 L>1、整数平滑参数 T>1，令 `Q=TL+L−1`。第 l 层点为 `(A,z)`，其中 `A⊆[Q],|A|=l−1`；A 中坐标 z_j 是 U 点，其余坐标是 V 点。每坐标保存位置和类型，同一原变量可在不同位置重复。此点标签是按 Q 个位置分别赋值的 tuple：U 位置用 `[k]`，V 位置用 `[m]`。允许 tuple 内相同原变量的两个位置暂有不同标签，soundness 会逐坐标解码。层大小为

\[
n_l=\binom Q{l-1}|U|^{l-1}|V|^{Q-l+1},\quad
K_l=k^{l-1}m^{Q-l+1}.
\]

对 l<l′，令 `h=l′−l`。从 v=(A,z) 选择 `H⊆[Q]\A,|H|=h`；对每个 j∈H 独立选择一条 incident 源约束 `e_j=(z_j,u_j)`。目标层点 w 的类型集为 `A∪H`，只把 H 上 V 点换为各 u_j，其余坐标原样保留。每个 H 和各 e_j 给一个独立多层约束身份。其映射 π 将 H 坐标的标签经 π_ej 投影，其余坐标标签恒等保留。

因此每个目标标签恰有 `d^h` 个原像。KS14 在印刷 p7、p19、Appendix A 印刷 p28，把 l<l′ 时的指数/替换数印作 `l−l′`；这是本地符号反向。实际域大小 `K_l/K_l′=d^(l′−l)` 和本构造的替换坐标数均为正 h。本稿使用 `d^h≥4`，没有按负指数调用，不需因此改变核心定理身份。

**层间双正规与均匀分布。** 固定源层点的出度恰 `binom(Q−l+1,h)b^h`。固定目标层点的入度恰 `binom(l′−1,h)a^h`：反选 h 个 U 位置，各选一条 incident 源约束恢复相应 V 点。这些数与点无关。均匀源层点、均匀 H、每 j 均匀 incident constraint-ID 所得恰为层间均匀约束，非均匀的“不同邻点”分布。因源 biregular，均匀 V 点加均匀 incident ID 使目标 U 点均匀；独立坐标保证目标层点均匀。

**完备性。** 完美源标签逐位置赋值，满足所有层间约束。不存在近完美损失。

**平滑性。** 固定第 l 层点和两个不同标签 tuple。若某个不同坐标已经为 U，它恒等保留，二者绝不碰撞。否则选一个不同的 V 坐标 j；只有 j∈H 才可能投影后相等。因此在按身份均匀的层间约束下

\[
\Pr[\pi(i)=\pi(i') ]\le h/(Q-l+1)\le (L-1)/(TL)\le1/T.
\]

此界不依赖同端点各投影是否相同，也不要求源每邻点同一映射。

**弱密度。** 从全 V 的第1层均匀点开始，每次均匀选一个剩余 V 位置并均匀抽一条 incident constraint-ID，将其换成 U。每层边缘为该层的均匀顶点分布；给定 l,l′，中间 h 步的每个 H 有 h! 个顺序，每个 tag tuple 有同样概率，所以这对层的联合分布恰为层间均匀约束分布。给定 s≥ceil(2/ρ) 个层及每层至少ρ比例的点集，在同一条链上令 X 为访问这些集合的次数，则 `E X≥sρ≥2`。由二阶矩

\[
E\binom X2\ge\tfrac12((s\rho)^2-s\rho)\ge s^2\rho^2/4.
\]

对至多 `s(s−1)/2` 个层对平均，某层对同时访问的概率至少ρ²/2，尤其≥ρ²/4，正是 KS14 的弱密度合同。这里每层按顶点数的密度已由均匀边缘支付，未把边权密度偷换成顶点密度。

**每对层的 soundness。** 固定任意多层标签，使某层对的均匀约束满足率为 p。按上一均匀约束生成过程，再从 H 均匀选一个 distinguished 坐标 j。多层约束满足时该坐标的源约束必满足，故此坐标满足概率至少 p。固定位置类型 A、H、j、所有其它位置的原变量，以及其它替换坐标的源 constraint-ID。剩下 `(z_j,u_j,e_j)` 的分布仍是均匀源 constraint-ID：z_j 原先均匀于 V，e_j 在其 b 条 incident IDs 中均匀，故每原 ID 概率 `1/(|V|b)=1/|F|`。其它坐标独立抽样，条件化不改变此分布；重复原变量符号也未被排除，不会引入无碰撞条件偏差。

在固定的此上下文中，第 l 层赋值于位置 j 给出了仅依赖 V 端点 z_j 的 `[m]` 标签，第 l′ 层赋值于位置 j 给出了仅依赖 U 端点 u_j 的 `[k]` 标签。e_j 的身份不进入任一层点，只进入被测试的投影。因此二者是一份合法的源标签策略，对均匀源 ID 的满足率≤val(source)。对全部固定上下文平均，得到 `p≤val(source)`。这同时处理同端点不同投影：端点策略不看它们的 ID，而满足判据逐 ID 取相应 π_e。故 source NO≤ζ 推出每层对 NO≤ζ。

由此，KS14 Theorem 2.8 所需的完美性、逐层对低值、弱密度、平滑性和精确常数 fiber 全部按约束重数成立。固定 L,T 和源常数字母表后，Q 为常数，所有层点、标签和约束显式展开均为输入规模多项式；没有要求源最大度为常数。

## 二可着色三一致超图的完整目标

实际目标整句是：对每个固定 δ>0，在有限未加权三一致超图上区分 2-colorable 与不存在比例至少 δ 的独立集为 NP-hard。先固定 `0<α<min(δ,1/2)`，支付更强的 NO 阈值α。

KS14 §5 取 `L=ceil(32α^(−2))`。先固定测试噪声以及各层差对应的 `r=d^h`；r 的最大值只依赖固定 L,d。其 dimension-free 相关空间/不变性引理依次选择 ν、γ、τ、s 和足够大的 T，最后使源 ζ 严格小于其解码成功率常数，例如 §5.3 末的 `α²τ²γ²/(2048r)`。这全在源字母表和输入规模之前固定。然后核心选 soundness ζ/2，正规化引理取η=ζ/2，上一节给出具有全部合同的 layered PCP。

在第 l 层每个点 v 上放码块 `Hv={−1,1}^{K_l}`，每顶点权 `2^(−K_l)/(L n_l)`。每层总重1/L。对每条带身份多层约束 π_e，独立地在每个 fiber 上用 KS14 的 `D_(θ,r)`：先均匀取 X,Y，令 Z=−Y；以概率 θ 选一个 fiber 坐标，把该坐标的 Y,Z 同改为−X。对测试分布支撑中的每个三元组 `(x∈Hu,y,z∈Hv)` 加边。

完美标签σ给码字 x 颜色 `x[σ(v)]`。若关联 fiber 未修改选中标签坐标，则 Y,Z 相反；若两者在该坐标被改成相同值，则它们都为−X。两种情形三点不会单色，因此是完整二着色。

**三点互异。** 因 d=4、h≥1，每个 fiber 至少4坐标，而每 fiber 至多修改1坐标。至少一个未改坐标使 Y,Z 仍相反，故整个 y≠z。x 在不同层的不同码块，故与 y,z 都不同。无需默删退化的二点/单点超边。不同带身份测试若输出同一个三点集合，可以在最终超图去重；是否含完整边只依赖支撑存在性，不能同样去重源投影后还声称保值。

**soundness 的带身份接口。** 若独立集有权质量≥α，按各层的均匀顶点权以及 weak-density 取得两层，其中 heavy blocks 的端点诱导至少α²/64比例的约束。对每条带身份 π_e，独立集意味着测试乘积指标期望为0。§5.3.1 的重随机化逐 π_e 应用；§5.3.2 的 smoothness 坏事件也按 incident ID 分布求概率。Lemma 5.15 的并集界 `Pr[αsubset未被π_e打散]≤s²/T` 因上一节 smoothness 原样成立。每个点的 good incident 比例再经层间双正规和 heavy 约束计数，给至少α²/128比例 heavy-good 约束。Eq.(33) 的公共影响坐标逐 π_e 产生满足概率≥τ²γ²/(16r)，期望总满足率超过源 ζ 即矛盾。所有函数和最终标签只依赖顶点；同端点不同 π_e 可各自有不同好坐标，最终对均匀 ID 线性求期望仍成立。若独立集避开所有测试支撑，所有带身份测试各自期望为0，即使最后支撑边取并或去重也不影响论证。

这里复用 KS14 已证相关空间、不变性和超收缩分析，没有重证这些成熟解析引理；新增完整证明支付的是不同投影平行约束、多层均匀分布、原 source 值和该分析之间的实际接口。

**从有理顶点权到无权有限超图。** 令 `Kmax=max_l K_l`，取

\[
B=L\left(\prod_{l=1}^L n_l\right)2^{K_{\max}}.
\]

把权 w_x 的每原顶点替成 `B w_x=(∏_{j≠l}n_j)2^(Kmax−K_l)` 个不同 clones，正整数；总 clone 数恰 B。每原三点边换成三个不同 clone 云的全部三元组。任意 clone 独立集所占据的原顶点集必须独立，否则任选各占据云一 clone 就有完整边；其 clone 数至多这些原独立点的全部云大小。反向复制某原独立集的所有 clones 达到该大小。因此最大独立集比例严格等于原最大加权独立集质量，非仅近似。完美二着色在每云复制同色保持。

δ、L、T、源常数字母表固定后，K_l 是常数，n_l 为输入规模的固定次幂；B、多层约束、码块和完整三部超边展开均为多项式。得到有限未加权、无退化边的3-uniform输入，NO最大独立集比例<α<δ，YES完整2-colorable，目标整句已付清。FMW Corollary 1.10 给相同应用核对。正规化引理与 perfect exact4 源必须保持共同 ALL 前提。
