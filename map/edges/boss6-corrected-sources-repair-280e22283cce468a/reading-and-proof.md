# 调谐十四资源缩权族的修订比较与精确起点

本批比较 `WCF-R3-SCALED-RETUNED-v1`（登记版本 1）、`WCF-R3-SCALED-RETUNED-v2` 和 `WCF-R3-SCALED-TEMPLATE-v1`（均为登记版本 6）。四玩家两动作，七互补掩码为 `0101,0112,1022,1100,1120,1122,1211`，权重为 \((1,1/(10m),1/(20m),1/(50m))\)，\(m\) 为正整数。固定调谐振幅 \(t_r=(49,110,49,60,2,3,100)/100\)。若第 \(j\) 对的支持总权为 \(T_j\)，其每侧延迟为 \(t_j(x/T_j)^{p_j}\)，前六对 \(p_j=32m^2\)，末对 \(p_7=2\)。玩家费用是所用资源延迟之和。记 \(s^{\oplus i}\) 为仅玩家 \(i\) 翻位的状态，偏离费用从该状态的新负载重算。\(s\) 是 2-PNE 恰当四个差 \(C_i(s)-2C_i(s^{\oplus i})\) 都非正。

## 辅助极限、固定模板与两条统一尾界

前六对在全支持时费用恰等于振幅，缺少支持者时费用至多 \(t_j e^{-64m/117}\)。末对仅在与重玩家同侧时趋于 1，另一侧趋于 0。固定调谐振幅在八个代表态 `0000` 至 `0111` 的四个翻位比的最大值依次为
\[
50,\;35/9,\;149/52,\;107/50,\;100/49,\;100/49,\;15/7,\;149/65.
\]
互补态费用相同，故辅助表的最佳均衡倍率为 \(100/49\)，在 `0100,0101,1010,1011` 处取得弱均衡。全部极限分母正，有限个比值及其有限最大、最小值连续，故 \(B(G_m(t_r))\to100/49\)。对每个固定 \(1\le\alpha<100/49\)，最终 \(B(G_m)>\alpha\)，排除 \(\alpha\)-PNE。有限游戏在 \(100/49\) 处的行为不由收敛决定。辅助表只用来计算极限，真正的反例都是有限 \(m\) 的多项式游戏。

指定见证玩家按八代表的顺序为 \(3,3,4,1,4,3,4,2\)（一基），互补态沿用同一人。其 \(\alpha=2\) 的极限差依次为 \(24/25,51/50,9/20,7/50,1/50,1/50,7/50,19/100\)。一般模板在 \(g=1,h=d+e+f\) 下要求 \(a,c<1/\alpha\) 及 \(\alpha-1-c<h<(a+1)/\alpha\)，推出 \(\alpha^3-\alpha^2-2\alpha-1<0\)。反向由正文先取开区间内的有理 \(a=c\) 与 \(h\)，再取小正有理 \(e,f\) 及足够大的 \(b\)，满足全部八行。故根 \(r>2\) 刻画这组固定见证的严格可行域。其量词为每个固定 \(1\le\alpha<r\) 可先选有理振幅 \(t\)，再选 \(M\)，使所有整数 \(m\ge M\) 全态有严格见证。最优值只属于指定见证锥。

旧绝对误差路线取 \(S=273/100\)、\(\delta=1/50\)。每个当前及偏离费用的绝对误差至多 \(E_m=S e^{-64m/117}+17/(50m)\)。所以指定有限差至少为 \(\delta-3E_m\)。当 \(m\ge52\) 时，\(64m/117>28\) 且 \(e>8/3\)，得到严格正的统一有理下界
\[
\frac1{50}-3\left[\frac{273}{100}(3/8)^{28}+\frac{17}{2600}\right]
=\frac{9671406313347824129679641}{25145657047984286833888460800}.
\]
这用一般模板正文的绝对误差式直接专化，数值 52 来自上述有理比较。

定向路线取 \(L_m=(1-2/(100m+17))^{32m^2}\le e^{-64m/117}\)。前六对的误差是非负的，每名玩家可用振幅总和最多 \(56/25\)。指定的当前成本都含极限末对费 1，有限减少至多 \(17/(50m)\)。指定轻玩家翻位后末对的有限增加至多 \(289/(10000m^2)\)，重玩家翻位后末对的有限费至多其极限费 1。故指定有限差至少为
\[
\frac1{50}-\frac{17}{50m}-\frac{578}{10000m^2}-\frac{112}{25}L_m.
\]
对 \(m\ge20\) 用 \(L_m<(3/8)^{10}\) 得统一下界 \(2735869393/1048576000000>0\)。两种估计各自覆盖无限尾域，定向路线的范围包含旧尾域，旧证明仍可独立使用。

## 有限证书与精确起点三

\(m=3\) 证书给 16 个指定严格二倍出口，精确最佳倍率大于 2，极小态为 `0101,1010`，最高次数为 288。\(4\le m\le19\) 由 [Boss2 的有限缺口证明](../../../research/workspaces/map-v2/Boss2/retuned-gap-4-19.md)及其[整数核验](../../../research/workspaces/map-v2/Boss2/retuned-gap-4-19.py)支付。将各权乘 \(100m\) 后是整数 \((100m,10,5,2)\)，令 \(U_j\) 为整数支持总权，\(L=\operatorname{lcm}_j U_j^{p_j}\)。用 \(100L\) 同比放大所有费用，振幅分子为 \(a_j\) 的资源在整数负载 \(x\) 时收费 \(a_j(L/U_j^{p_j})x^{p_j}\)。因此可以只用整数符号判定严格差。本轮复跑检查了 256 态和 1024 个真实翻位，256 个指定差均严格为正。每个 \(m\) 的最小指定差乘 \(10^6\) 后的下取整依次为
\[
9866,11911,13270,14238,14963,15526,15975,16343,16649,16908,17130,17322,17490,17638,17770,17887.
\]

在 \(m=1,2\) 用有限模型有理重算 `0100` 及补态 `1011` 的全部翻位。各态四个差的最大值乘 \(10^6\) 后的上取整分别为 \(-193221,-23030\)，故两游戏各有 2-PNE。合并 \(m=3\)、\(4\le m\le19\) 及 \(m\ge20\) 三部分，此固定振幅族无 2-PNE 当且仅当 \(m\ge3\)。对每个整数次数上界 \(d\ge288\)，可取 \(m=\lfloor\sqrt{d/32}\rfloor\ge3\)，得到最高次数 \(32m^2\le d\) 的有限反例。288 是该固定族中反例的最小次数。这个比较新增的精确起点来自三段证据和两个早期均衡，旧 v1 与 v2 的登记陈述仍各自按原证明范围理解。
