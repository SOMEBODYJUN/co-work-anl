# 支持笔记：737 终端双证书（SOLVER-TERMINAL-DUAL-FRESH）

## 1. 原题模型与松弛域

共同目录定义给有限单位客户、有限非空标签目录、五名依次观察完整有序历史的提供者；完整纯策略是每个有序前缀上的标签函数，SPE 量词是所有位置、所有前缀、所有合法单步偏离沿给定真实续局均满足弱收益不等式。737 页面只取该模型的必要信息投影，不保留完整策略或同标签异历史的续局选择。

对 737 原子，十位会员掩码为 `ABCDEUVWXY`。AB 与 AE 家族各有 8 个 `(t,r,s)` 桶，Sbranch 有 16 个 `(t,h,i,j)` 桶；每族总质量为 5，三族共享第一位 `t` 的重数 `d`。`actual/second/third` 三菜单的整数参数 `(ℓ,h)` 满足

\[
0\le h\le d,\qquad 0\le \ell-h\le5-d.
\]

令 `w(a)=1_{A∨B∨C∨D∨E}`，`o(a)=1_{d>0}`。737 的行锥为

\[
Gx\ge0,\quad x\ge0, w^Tx=1,  O=o^Tx.
\]

717 行是旧保交叠及常锚点跨族行；737 的新增 20 行按 `(source,target,position,kind)` 分成

\[
(AB,AE,1/2,D/O), (AB,S,1/2/3,D/O), (AE,AB,1/2,D/O), (AE,S,1/2/3,D/O).
\]

目标覆盖 `O` 只是共同 `t` 组非空的五个比较主题并集指示。除非另给真实最优五元组的标签级识别，不能把 `O` 换写成原博弈的 `OPT_5`。

所有整数乘子 `I_r` 与有理权 `I_r/D` 对应，权均非负。原报告和完整重放确认：

\[

## 4. 双 source 条件分解能做什么

给每个 source 在 `t=0,1` 两组记录 `r=1` 槽数的签名 `L_f=(h_{f0},h_{f1})`；固定共同 `d` 后，合法签名空间为

\[
\mathcal L_d=\{0,\ldots,5-d\}\times\{0,\ldots,d\}.
\]

每组 `n` 槽内只出现两种倒数 `a_0=1/(p+t+1)` 与 `a_1=1/(p+t+2)`。对目标计数 `c`，单菜单 D/O 的最小／最大分母和是

\[
\operatorname{Top}(c)=a_0\min(c,n-h)+a_1\max(0,c-n+h),
\]
\[
\operatorname{Bottom}(c)=a_1\min(c,h)+a_0\max(0,c-h).
\]

因此每条 single row 只在这个必要信息域给出逐客户包络。双 source 同时固定 `(L_AB,L_AE)` 后，AB、AE、Sbranch 三个家族可分别取各自完整 hist 的最大分数，再对两个签名求最大；该分解证明了定价程序在**所写 737 直方图域**内的 exact full-type dual 检查，但不构造各客户共同的主题置换，也不恢复全历史。

## 5. 浮点保存路线的硬障碍

`complete-field-check.json` SHA 为 `d9ef1858a1ab545b036265c4f10c5878274fdd06ed08d04c8c816846f6363e46`。它完整校验 1141 保存列的结构（106 bit patterns、10 AB hist、21 AE hist、22 Sbranch hist、48 menu tuples；无结构重复），并逐项比较 20 条新增行的 22820 个系数。但将 binary64 保存质量按其实际二进制有理数代入后，

\[

\]

且 20 条 single 聚合中有两条严格负：

\[

## 6. 迁移／反驳边界

- 737 full dual 可迁移为“任何同一 737 松弛域质量的上界”。要迁移到 717/727/728 或真实 CAG，必须先给完整端点对象、字段同构、行方向和共同／独立相关性证明。
- `β>2` 只切断“用 737 必要行直接证明五人 half”的路线；它不反驳真实 SPE half。因为真实策略锥包含每个离轨历史的后继一致性与真实 IC，严格包含于该信息松弛。
- 76 点的 `O>2` 只反驳“737 行系统自身推出 `O≤2W`”，不能反驳原题 `OPT_5≤2W`。
- 728 的 AB→Sbranch 共同 OO 未在 737；故不存在由行数产生的 728→737 或 737→728 自动包含。已有 canonical 边对其交叉可行集已有独立处置，本包不重发。
