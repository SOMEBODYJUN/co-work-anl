# 数学支持：5251 行显式新回复点与遗漏 floor 的有限审计边界

## 1. 共同模型与对象身份

本包在共同目录模型中工作：客户集 `N` 有限，每个客户单位价值一；标签目录 `S` 有限、非空，标签到客户子集的覆盖映射允许空集、重复覆盖和不同标签同覆盖；六名单位权提供者按固定次序逐一选标签，并观察此前全部有序动作。终局客户价值由全部覆盖者均分，`u_i` 是第 `i` 位覆盖客户的份额和，`W=sum_i u_i`。完整纯策略是每个有序历史上的动作函数；纯 SPE 要求在每个合法历史、每个单步标签偏离之后沿给定真实续局满足真实 IC。空主题、重复选择、同覆盖异标签、零客户和弱平局均保留。

登记对象 `M-94fb0280f8af4175b3ec6801a8843744` 是一个有限必要行系统的有理点，而非已经实现的目录或策略。它固定 `early_reply_exact.json` 的 1905 列（`K=1`、16 个 `hist`、582 个 `joint-reply`、1306 个 `overlap`），`O=1`，171 个正质量，

`W = 57770848877002761745569033003977 / 120785977474956965853696208259979`,

并在旧 4927 行上加入 324 条实际第四/第五位的新回复价格行，得到 5251 行。所有 5251 行 Fraction 回代非负，最小余量为 0；324 条新增价格行在该点全部严格正，新增组的最小余量为

`3068136569007345979888391178557 / 402619924916523219512320694199930`.

这正是登记 statement 的“5251 行精确可行”部分。对象同时把同一固定质量向量放入完整 36 条实际安全 floor 中；这 36 条不是上面的 324 条价格投影。

## 2. 324 条价格行的承重与量词

固定 actual 主题 `A_1,...,A_6`，实际源位置只取 `s=4,5`；强制主题 `T` 是已有 `R_e` 或 `Z_e`。`R_{0,j,l}`、`R_{1,j,l}` 和 `Z_e` 沿原策略取真实后继，三种有序边类的重数分别是 30、30、6。每个新源只使用一个新增会员位，继承 1905 列中的仿射坐标。

对单客户，令 `p` 为源前负载、`ell` 为 actual 前五位负载、`t=1_T`、`q=1_Q`，隐藏后继位为 `f`、末位为 `g`、总负载 `z=p+t+sum f`。固定非负参数 `alpha_j` 和 `mu` 后，逐客户代价为

`H(f)=t/z + sum_j alpha_j f_j/(ell+1) - mu*g/z + mu*q/(p+t+sum_{j<r}f_j+1)`,

零分子份额按零约定；`psi=min_f H(f)`。真实源 IC、actual 末位对每个真实后继的报价和分支末位对 `Q` 的最佳回复给出

`u_s+(sum alpha_j)u_6-sum_x psi_x >= 0`,

其余项可写成 `(u_s-v_T) + sum_j alpha_j(u_6-P_ell(F_j)) + mu(v_{F_r}-U(Q)) + sum_x(H(f_x)-psi_x)`。这里取 `min` 是因为 `H-psi>=0`；偏离后的真实后继没有被冻结。对 `Q=T` 仍按合法自查询的完整分母计算。这一身份只证明这些固定主题/源下的必要行，不能扩展为全部目录、所有早期源或完整 SPE 证明。

实际第四位有两个隐藏后继，参数组合为 `2*3*3*2*3*2=216`；实际第五位只有一个后继，仅保留末位付价，得到 108 条，共 324 条。它们不是 324 个独立方向，也不是新的福利常数。独立审计将源码 AST 中的新增 build 与字面隐藏状态枚举逐系数比较（`324*1905=617220` 个系数），得到完全一致。

## 3. 36 条 floor、精确失败键与审计范围

全实际前缀 floor 的行式为

`n_g u_s - sum_{e in E_g} sum_{x in Q_e} 1/(sum_{a<s}1_{A_a}(x)+7-s) >= 0`,

其中 `s=1,...,6`，`Q_e` 为 `R_e` 或 `Z_e`，并按 `R/Z` member、三种 orbit 和有序边重数展开 36 行。对 5251 点，36 行恰 5 条负、5 条为零；五个负键（`i` 从 0 计）为

`(1,0,1,0), (1,1,1,1), (2,0,0,0), (2,0,1,0), (2,1,1,1)`.

最负键是 `(2,0,1,0)`，余量为

`-37918341723853123058170585072309 / 1073653133110728585366188517866480`.

该负值只说明此固定有理点不满足保留全部 36 floor 的必要行，故不能作为这些坐标的完整 SPE 完成；它没有给出实际目录、全部历史 IC 或偏离后真实终局，因此不是完整 SPE 反例，也不否定六人 half。独立审计进一步按 `K/hist/joint/overlap` 逐字段核验，检查 194 个 joint 上界和 2612 个 overlap 上界；所有 1905 个列描述符相同，`O=1`、`W` 和 strict half gap 与原 JSON 一致。

`audit_added_price_rows.py` 仅审计继承 16-hist 布局的新 324+36 行和四个保存点，不重跑旧 4927/4963 全图、LP、优化或 SPE 树。它枚举了 536 个不同隐藏投影键、1772 个二进制状态（压缩候选数也为 1772），并比较了 `360*1905=685800` 个新增系数；这是精确结构证据，不是对完整游戏的重新求解。
