# 从共同标签到共同集合的安全债务保持

固定本包 q32 完整有序策略 σ，取 Kσ 的任一整数单位客户点。令 L 为原七标签，令 S={cov(a):a∈L} 为互异的覆盖集合目录，记 π:L→S 为覆盖映射。π 逐槽作用于有序历史和终局。以下构造从原 σ 得到一份在目录 S 上的完整有序纯策略，并保留其实际前缀的安全债务。这一构造允许同一客户点上出现 0、1 之外的覆盖相等，也包括零客户时仅有一个覆盖类的情形。

对每个合法商历史 H∈S^d，递归固定一个原标签历史 `lift(H)`，满足 π(lift(H))=H。令 lift(空)=空。在非终局历史 H，令 h=lift(H)，a=σ(h)，定义商策略 τ(H)=π(a)。对 H 的每个合法下一动作 C∈S，取标签 b(h,C)∈π⁻¹(C)，其中 **b(h,π(a))=a**，并定义

```text
lift(H·C) = lift(H)·b(h,C).
```

这样每个商历史的提升都与其所有前缀相容。商路径每次遵循 τ 时，提升恰沿对应原历史的 σ 规定动作延长。从任意商决策历史 H，商策略的规定终局因此是原 σ 从 lift(H) 的真实终局的投影。强制改选任何 C 后，商真实终局的提升恰由原历史 lift(H) 强制 b(h,C) 后沿 σ 真实续行。商终局与其提升逐槽覆盖相等，故两边每个角色的收益相等。原策略在该历史对该代表标签的真实 IC 逐项推出商策略对 C 的真实 IC。每个 H、每个 C 都如此，τ 是完整有序纯 SPE。商历史 τ 可以依有序覆盖历史行动，此构造也无需 σ 在同覆盖的原历史使用同一续局。

从根出发，商实际路径提升回原实际路径 00011。原标记路径和商路径的实际前缀客户负载、终局福利 W 和各位置实际收益 u_i 逐项相同。对任一实际前缀，所有原有序竞争标签元组在 π 下投影到合法有序集合背景，并且覆盖映射满射保证每个合法有序集合背景均可逐槽提升。空背景和重复动作都保留。对任一原查询分布 p，将 p 按 π 推送到集合查询分布，期望支付在对应竞争背景下相同；任一集合查询分布也可通过在每个覆盖类选代表标签提升。于是两个模型的 max_p min_B 静态安全值在每个实际前缀精确相等。原 q32 各 V_i=u_i=W/5，故商策略各 V_i=u_i=W/5，各 D_i=0，支付一般弱总安全债务在严格集合目录读法中的这一实例。

此处商策略只承接实际前缀静态安全与债务比较。自由删槽列和同分布去相关的两条 q32 边均直接量化原标签目录、原 σ、原真叶与原删槽，不用商历史选择器替换这些数据。
