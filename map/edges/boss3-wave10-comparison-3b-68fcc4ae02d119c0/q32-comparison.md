# q32 冻结完整策略的三项安全预算

固定原 `sym_m5p7_q32_Jout.json` 中的五人、七标签完整有序策略 σ。令 Kσ 由全部合法历史和全部合法单步改选的真实收益差非负及客户类型质量 w_T≥0 给出。原动作表覆盖 2801 个历史及 16806 个非自身比较。其余结论量化 Kσ 的全部 w，包括零点，整数类型质量按独立单位客户解释。保留不同标签、重复行动和全部原离轨续局。

## 从两条真实激励差到覆盖相同

实际终局为 00011。根强制 1 的真实终局为 10000。实际末位在历史 0001 规定选 1，强制 0 的真实终局为 00010。令 x、y、z 分别为在标签 0、1 上只喜欢 0、只喜欢 1、同时喜欢两者的客户总质量，其余标签的兴趣位任意。

根真实差 g_R=(x/3+z/5)−(y+z/5)=x/3−y，末位真实差 g_L=(y/2+z/5)−(x/4+z/5)=y/2−x/4。恒等式 6g_R+12g_L=−x，3g_R+4g_L=−y。两条真实差均非负，故 x=y=0。由类型质量非负，每个 0、1 兴趣位不同的类型均为零质量。两个标签覆盖相同，W=z，五位实际收益各为 W/5。

## 各实际前缀的静态安全值

令 h=0001，f_B(a) 为查询 a 对静态四槽 B 的收益，F_p(B)=Σ_a p_a f_B(a)。末位在 h 的全部七项真实最佳回复比较给 f_h(a)≤W/5，故同一个背景 h 对所有查询混合给 F_p(h)≤W/5。

对实际位置 i，过去为实际前缀 z_<i，剩余人数 r=6−i。将余下 r−1 个竞争槽全填 0，合并实际过去后共有四个 0/1，其客户负载逐类型等于 h。此纯背景对任意合法查询分布均封顶 W/5。反向取纯查询 δ0。在任意合法有序额外竞争背景 B∈{0,…,6}^(r−1) 中，允许重复标签，查询所覆盖的每名客户计入真实过去及本次查询后分母至多 i−1+r−1+1=5，故至少取得 W/5。第 5 位的额外背景是空元组。由此五个实际前缀的 V_i=v_(6−i)(b_i)=W/5，v_5=V_1，且全部实际收益 u_i=W/5。

对弱总安全债务，i<5 时 D_i=u_i−V_i+(5−i)(V_(i+1)−V_i)=0，末位 D_5=u_5−V_5=0。于是 Σ_iD_i=W−5v_5=0≥−v_5/2。这里的 D_i 是位置安全债务。原一般义务仍量化所有目录、人数和完整纯 SPE，并包含尚待支付的其他固定策略、其他客户锥及六人范围。

## 实际删槽列与独立推送的不同量词

AFC 的 H_i(p)=min_b F_p(V_i(b)) 允许各位置自由选列。选择该位置的实际动作 b=z_i，得到四槽实际删位列。由于 0、1 等覆盖，该列负载等于 h，故这组固定列为任意 p 给 H_i(p)≤W/5。等价对偶可用 q_i=δ_(z_i)，位置权重各 1/5，并同时控制所有七个纯查询。δ0 面对所有合法背景至少得 W/5，故 H_i(δ0)=W/5 且 max_p Σ_iH_i(p)=W。这个自由列构造只需要每个位置实际动作的列。

独立推送预算要求查询与强制动作独立地按同一个 p 抽样，给 C_i(p)=Σ_b p_b F_p(V_i(b))。对 p=δ0，需从表中使用五个强制 0 真叶，特别第四位的强制 0 真叶 00001 和末位的 00010 各自删自己的槽。其五个竞争列都与 h 等负载，故 C_i(δ0)=W/5，Gσ(δ0)=W−Σ_iC_i(δ0)=0。δ0 的最优性量化根的全部合法背景，由前节保底及封顶给出。

完整 35 列还支付一个同锥加强。每个 V_i(b) 都由四个 0 或 1 组成，对每个在 Kσ 可有质量的类型与 h 同负载。于是对任意 p，H_i(p)=C_i(p)=F_p(h)。公开偏离均值 D_i(p)=Σ_b p_b f_(V_i(b))(b)=F_p(h)，因此逐位去相关项 κ_i(p)=D_i(p)−C_i(p)=0，逐位激励松弛 e_i(p)=W/5−F_p(h)≥0。这里的 D_i(p) 是公开偏离均值。于是 Gσ(p)=5(W/5−F_p(h))≥0。对任一真正静态最优 p，全部合法根背景 B 都满足 F_p(B)≥v_5=W/5，尤其 h 如此，故 Gσ(p)=0。一般存在最优 p 的候选在这个固定锥上得到局部支持。其他完整策略上，真实删槽列可能诱发不同负载，36 客户全查询反例仍适用其原量词。

冻结整数点有 W=20，h 的七个纯查询收益皆为 4。纯查询 δ2 在四个 2 的合法静态背景取得 8/5，且由分母界对所有背景至少保 8/5。因此该点 δ2 满足 Gσ(δ2)=0，同时安全值 v_5=4，展示预算取等允许非最优查询。

## 复验与覆盖比较边界

`verify-menu-columns.py` 直接从冻结动作表走有序真叶，复验 35 个位置动作各自删除正确槽，核 63 个非空、0/1 兴趣位一致类型上的全部 2205 个逐类型负载恒等式，并对五个实际前缀分别遍历 2401、343、49、7、1 个合法额外竞争背景。保存的 `menu-columns-exact.json` 可逐字节重放。冻结 `recheck_q32.py` 的输出也与原 `q32-exact.json` 逐字节一致。

原克隆 33 客户、W=20、OPT_5=33 是一个冻结整数点的事实。原 13 个有理乘子的 33/20 界控制同一锥的指定比较支持 J=(2,3,4,5,6)，而 21 个五标签支持的枚举仅针对该冻结点。静态锐界与 v_5=W/5 则给出本锥单位客户点的全支持 OPT_5≤9W/5。三个安全预算各用前节中的独立付款链。
