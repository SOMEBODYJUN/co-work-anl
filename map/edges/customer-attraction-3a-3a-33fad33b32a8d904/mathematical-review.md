## 恢复的精确对象

固定同一客户、同一保留标签内的有限记录。P 是同一真实末两人分支的倒二行动前负载；Q 是该分支的末位行动前负载。单位提供者使 Q=P+a，a∈{0,1}。记录数可以为零，与总玩家数不同。

设 L(c)=#{P=c}、M(c)=#{Q=c}，两边总数相等、有限支撑，负载非负。任何合法联合只能有 Y_c=J(c,c)、X_c=J(c,c+1)。由 L(c)=X_c+Y_c、M(c)=Y_c+X_(c−1)，X_−1=0，逐 c 唯一得到

\[
X_c=F_L(c)-F_M(c),\qquad Y_c=F_M(c)-F_L(c-1).
\]

所以累计交错 F_L(c−1)≤F_M(c)≤F_L(c) 是非负性的充要条件；相等总数与有限支撑保证尾部 X=0。反向把这些整数放入两格就恢复 L/M，故存在性与唯一性均成立。空组全部计数零，仍唯一。

唯一的是每标签的联合类型计数表 J(P,Q)。即使有多个 indexed lists 产生同一表，也没有恢复每个有序索引的配对或完整策略。最终实际会员和完整源收入不能删去：terminal 的 actual-share A、pair 的 H-source 必须由完整 source 直方图另存。相邻 a=Q−P 虽被联合类型确定，仍没有给出末位实际会员及其他完整源信息。

## 五模式查询项与同一成本矩阵

五等号模式端点对每个固定真实分支 i 给

\[
n_\tau h_i-\frac{L_\tau(b_i,c_i;B,C,K)}{P_i+1}
+\frac{\omega M_\tau(b_i,c_i;B,C,K)}{(P_i+1)(P_i+2)},
\]

其中 τ 是五种索引模式之一，ω=1 或 2；b,c 来自同一个完整 target tuple，B=Σb、C=Σc、K=Σbc 也由该 target 直方图给定。五模式的 n,L,M 采用端点正文完整表格，不将全积总和非负替换任何单模式。源项是 n_τΣh_i；查询部分只依源 P 与同一 target tuple。

例如一个 terminal 菜单位 z，D/O 非负权 α,β，其源项为 [α+(q−1)β]A，查询成本是

\[
C_T(Q,z;Z)=\frac{-\beta Z+(\beta-\alpha)z}{Q+1},\qquad Z=\sum z.
\]

固定 target 完整直方图 h_t 后，所有 B,C,K,Z 为参数。要让这些 terminal 与 pair 行共用一次同标签匹配，先以预定全局非负行权把查询项合成

\[
C((P,Q),t;h_t)=C_T(Q,z;Z)
-\frac{L_\tau(b,c;B,C,K)}{P+1}
+\frac{\omega M_\tau(b,c;B,C,K)}{(P+1)(P+2)}
\]

（多行时在同一个 C 内求和，t 必须含这些菜单的全部联合位）。令 H_ell(t) 为 target 标签组中的 tuple 计数。共同查询上包络准确为

\[
\Phi(J,h_t)=\max_{x\in\mathbb Z_{\ge0}}
\sum_{\ell,p,q,t}x_{\ell,p,q,t}C((p,q),t;h_t),
\quad
\sum_t x_{\ell,p,q,t}=J_\ell(p,q),\quad
\sum_{p,q}x_{\ell,p,q,t}=H_\ell(t).
\]

这是同标签槽的整数运输：每份匹配给一张这样的表；反向依整数格数分配具有相同类型的 source 槽与 target tuple，就得到一份匹配。两方向同值，故无额外损失。这里只优化声明的自由重排包络；未认证全客户共同主题置换或额外历史一致性。

相邻恢复给出的 J 因而足以计算这个**合成后的一次**支持函数。source indexed 顺序不同但 J 相同，只是相同成本行的重排，运输可行表和目标都相同。无需保任意背景的额外未知联合向量；逐标签恢复兼容 L/M 后即可用 J。这是本包交给条件分解对象的局部贡献。

把完整源收入留在 G_s(h_s)，便有 U=G_s(h_s)+Φ(J(L_s,M_s),h_t)。在该目标本来声明的有限乘积域里固定全部 source L/M 后，Φ 仍只依单个 target h_t，故可接入原定理的条件纤维证明。自环中 G 与 Φ 必须同一 h 最大；跨不同 target 族共匹配时，其联合 tuple 不能由各自边缘 h_t 拼出，须另扩大变量。任意非相邻／多步背景仍保联合向量签名。

这一逻辑边只完成目标的“真实相邻 terminal+pair 共匹配签名减维”部分。目标整条条件分解还用其独立有限分割证明、全部允许 H_f、源 G 与外部参数；两源对象单独不推出目标全部陈述。更没有从表示精确推出付款乘子存在、实际根 W 上界、全树可实现性、多项式复杂度或六人 half。

## 为什么不能分别最大化

新有限比较只为核此接口：q=1…3，source 类型 P∈{0,1,2}、a∈{0,1} 的全部多重集与 target 两菜单位的全部多重集，共 1354 对。逐对对五模式、ω=1/2、terminal 权(α,β)=(1,0),(0,1),(1,1)，共 40620 个成本比较，枚举全部不同 tuple 匹配。实际 source 顺序与由边缘恢复的规范 source 顺序给同一共同最大值；这些是通用成本 fixture，不是完整 SPE。

其中 q=2、source (P,Q)=((1,1),(0,0))、target (b,c)=((0,0),(1,0))，取 τ=i=j=k、ω=1，terminal 查询 z=b 且(α,β)=(0,1)。两种排列中 terminal 查询分别为 −1/2、−1，pair 查询分别为 −1、−1/2。因此同一次合成查询最大为 −3/2，而分别最大后相加为 −1，严格差 1/2。源 A/H 是对匹配的常数，加回也不消除此差。此例精确说明不同的 max 量词会产生额外放松，不称真实 SPE 分离点。

若允许 Q−P∈{0,1,2}，相同边缘 P=(0,1)、Q=(1,2) 可有 {(0,1),(1,2)} 与 {(0,2),(1,1)}；Σ1/((P+1)(Q+1)) 分别 2/3 与 7/12。它只否定一般边缘决定混合成本，没有构造两个完整 SPE。
