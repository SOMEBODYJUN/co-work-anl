# 固定五人策略 NET-Q 3A 实读结论

核心对象 `CA-TWO-FIXED-FIVE-PLAYER-NET-Q-MATCH-v1` 的模型是共同七标签目录 `0,…,6` 上的五名顺序单位提供者；固定完整动作表分别为 `σ252`（实际路径 `00011`）和 `σ48`（实际路径 `01010`）。客户按最终覆盖者均分，客户型重数非负；完整 SPE 量词只在应用真实 IC 的上界步骤使用。

对任一冻结策略、任一恰五个不同标签的支持 `J`，把第 `i` 个原实际前缀强制为 `π_i∈J` 后沿同一动作表走到真实叶 `z_i(π_i)`。对每个非空会员型 `B⊆{0,…,6}`，证书检查

```
Σ_{i:π_i∈B} 1/n_B(z_i(π_i))
  - d_B/(1+c_B) + 1[c_B>0 and d_B=0] >= 0.
```

127 个类型同时成立，乘任意非负客户重数并求和得到
`Σ_i M_i(π_i) >= Q(c,J)-E_J`，其中 `Q(c,J)=Σ_x d_x(J)/(1+c_x)`、`E_J=|C\\O_J|`。两份动作表的 21 个支持均有证书排列；保存证书的通过排列总数分别为 432（σ252）和 402（σ48）。若对应冻结策略为完整 SPE，原实际前缀的逐项 IC 给 `Σ_i M_i(π_i)≤W`，故 `Q(c,J)≤W+E_J`。任意最优比较元组的标签支持可补成五个不同标签而保持同一最优覆盖并集，因而存在型最优净 Q/调和预算匹配成立。

`CA-TWO-FIXED-FIVE-PLAYER-OMISSION-PAYMENTS-v1` 只支付未覆盖客户的单位遗漏量并给出 `|V\\U|≤P≤W`、`|V|≤2W` 和 `OPT_5-W` 的未加权匹配。它没有支付已覆盖客户的重叠项 `d_x(J)/(1+c_x)`，所以不能推出 NET-Q；本批将该 overlap 作为已解决的语境区别关闭，保留 context `cites` 边而不冒称逻辑蕴含。
