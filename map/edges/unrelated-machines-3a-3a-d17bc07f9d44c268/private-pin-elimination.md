# 固定 pin 消去与三个原矩阵的精确阈值

## 原矩阵到无预载模型的双向映射

固定一变量、两棵私有满四叉深三树。每轨有 21 台内部机和 64 枚叶任务。selector 在两根的处理时间均为 1，每条内部边在父端用时 1/4、在子端用时 1。每枚叶任务可在父端用时 1/4 或在该叶独有的 host 用时 1。每台 host 恰有一枚只能放在本机的 pin，开放时其用时为 0，关闭时为 1。原矩阵共 170 台机和 297 件任务，其中 selector 1 件、内部边 40 件、叶 128 件、pin 128 件。有限资格之外均不可用。

给定有理阈值 $1\le C<2$，关闭 host 上的 pin 必须执行。若叶也放上去，负载为 2，超过阈值。因此消去所有 pin、关闭的 host 及其叶任务的外端资格。令每枚叶自成一个 clause，开放时容量 $A_c=1$，唯一 unit 即原 host；关闭时容量 $A_c=0$，叶仍保留父端。开放 host 无预载，所有 clause 的 unit 互异。剩下的 169 件树任务及其完整双轨骨架满足 mandatory 森林定理的无预载假设。

原阈值调度限制到保留的任务与机器，就得到变换后矩阵的完整阈值调度。反向保留变换后调度的全部树任务位置，恢复每台关闭 host，并把全部 128 枚 pin 放回各自唯一资格端。开放 host 的 pin 加 0，关闭 host 上仅有 pin，负载 1。所有内部机负载保持，所得完整原调度峰值仍至多 $C$。这两个见证转换逐任务扫描。该映射保留阈值可行性，关闭 host 的负载在恢复时可能增加。

## 三个 profile 的最优值

在变换后的矩阵使用无预载森林定理，令 $r=\lceil4(2-C)\rceil$。原阈值可行当且仅当至少一轨存在深三的根生 $r$ 叉子树，其叶全部开放。由于每个开放叶有自己的 host，这些叶可以同时注入原外部机器。森林回译把未选轨及未选分支的树任务放回各自父端，随后恢复每枚 pin。$C<1$ 对三个原矩阵均不可行，因为 selector 必须耗时 1。

| 原 profile | 开放叶 | 有森林的整数 $r$ | 原矩阵 OPT |
| --- | --- | --- | --- |
| `all_positive_open_T_YES` | 正轨全部 64 叶 | $1,2,3,4$，均在正轨 | $1$ |
| `all_negative_open_T_YES` | 负轨全部 64 叶 | $1,2,3,4$，均在负轨 | $1$ |
| `only_pruned_negative_open_weak` | 负轨三个地址位均在 $\{0,1\}$ 的 8 叶 | $1,2$，均在负轨 | $3/2$ |

前两组在 $C=1$ 可下传所选整轨，达到 selector 下界。第三组正轨全闭，负根只有首位 0、1 的分支含开放叶，故 $r\ge3$ 不可行。取负轨并在每层都选地址位 0、1，得到深三的 $r=2$ 子树。其 7 台活跃内部机的负载为 $1+(4-2)/4=3/2$，其余内部机和全部 host 均负载 1。于是 $1\le C<3/2$ 时不可行，$C=3/2$ 可行。三组的树任务相同，pin 的真实加工时间向量各异，各自构成独立原矩阵。

## 冻结证书核验

全量解析原附件 `unit_readout_two_tree_actual_certificates.json` 的 1,762,176 字节，SHA256 为 `b44ee0f44485f2e1497b87338106d642beaa85b96196a810c569b4d120febefd`。调用同目录上层 `replay.py` 的 `certificates` 对冻结输入做语义核验，覆盖 6 份证书、4,440 个实际任务归属、13,872 个有限资格项、2,544 台机负载、384 枚固定 pin 和两个 NO 矩阵的 256 条源赋值见证。对三个私有 profile 另按实际资格和 pin 时间核对逐叶私有 host、三份原矩阵共同的树任务及各自开放集。逐轨、逐 $r=1,2,3,4$ 从叶向根复核，叶可用恰在 pin 时间为 0，内部点可用恰在至少 $r$ 个孩子可用，得到表中的各轨可行性。冻结见证的峰值与表一致。精确下界由上述映射和树结构给出。
