## P7 的承重条件

在五人共同标签目录中取任意完整纯策略 SPE 的有序前缀 `h_0`，长度为二。背景负载 `p_x` 属于 `{0,1,2}`，当前收益为 `u`。取加权最大合法标签 `H`，权为 `1/(p_x+3)`，并从 `(h_0,H)` 沿同一策略取真后继 `Q,R`。两标签同覆盖时，历史和真后继仍逐标签取值。裸最大大小 `K` 仅用于 `K≥|H|`。

七条非负总行分别来自第三位对 H 的真实偏离 IC、H 对 Q 和 R 的两条最大性、末位 R 对 D 五槽的真实 IC 和、裸大小 cap、末两人税对五个 `(R,D_i)` 的和，以及 H 对 J 五槽的最大性和。令税背景 `b=p+1_H`，并记 `U_b(X,Y)` 为先前负载 b、两尾主题 X/Y 下选择 X 的收益，`g_b(X,Y)=Σ_{x∈X∩Y}1/[(b_x+1)(b_x+2)]`。在真末两人节点令 `L=σ_5(h_0,H,R)`，即第 4 位改 R 后的真末回复。税界对比较对 `(R,D_i)` 的精确余项为

```text
[v_Q − U_b(R,L)] + [U_b(L,R) − U_b(D_i,R)]
+ [v_R − U_b(L,Q)] + [g_b(Q,Q) − g_b(Q,L)] + g_b(R,D_i).
```

前三项分别在第 4 位、改 R 后末位及原 Q 后末位非负，其余两项由交集非负。令 `B=v_Q+v_R+g_b(Q,Q)`，五对税行总和的每客户比较系数为 `(5r+d−2rd)/(b+1)+2rd/(b+2)`，其中 `r=1_R`、`d=#D`。这与末位真实 IC 用到的 `d/(b+1_Q+1)` 分母不同。全部五对保重复和对角。D 和 J 任意合法，H 被强制，Q/R 在对应真节点优化。

七行以 `(17040,9000,10080,600,1085,360,2679)` 合并，提出 `C=17040u+1085K−2679Σ_x j_x/(p_x+3)` 后得 `C+Σ_x G_x≥0`。逐客户在八种隐藏会员位上取最大得到 `G_x≤−F(p_x,d_x)`，故 `C−Σ_x F(p_x,d_x)≥0`。本轮用标准库有理数从七条总行的字面系数重建 G，全部 144 个余项与冻结父审逐值匹配，18 个最大值等于 −F。逐客户取最大只用于这个必要方向。零客户、空覆盖和重复选择保留，收益分子为零时取零。

## 超几何勘误与正文勘误

触发端点改版的勘误位于父审资源 §6。令 `s` 为从原五槽中均匀保留 r 槽时抽中的客户会员数，`E[s]=rd/5`。以固定标签 Q 填余槽，客户新计数是 `s+(5−r)q`，其中 `q=1_Q`。q=0 时取凹函数在 `[0,d]` 的弦，d=0 退化为常数端点。q=1 时 `s+(5−r)∈[d,5]`，取 `[d,5]` 的弦，d=5 退化为常数端点。其它弦长分别为 d 和 5−d，均为正。r=0 或 r=5 也直接取等号。取均值得到

```text
E F(p,s+(5−r)q) ≥ (r/5)F(p,d) + ((5−r)/5)F(p,5q).
```

本轮有理检查全部 216 个系数态，其中 64 态严格。q=0,d=5 与 q=1,d=0 都可严格，例如 p=0,r=1 的两例分别为 960>400、1740>1600。此勘误适用于比较混合菜单与两端凸组合。94/60 在每个真实节点直接调用 P7，不需要抽样、弦界或冻结源点的零分离。原登记对象保留旧证据指纹，本 clone 中实际可读的是当前资源及当前勘误登记。

另有一处正文措辞可澄清。目标程序正文 §5 同一句提到母 payment 中的 `actual:5:sum-opt`、`max:tax:opt-union` 和子类中的 `actual:5:O`、`max:tax:opt-pairs`。上列四份具体冻结报告中四键同时存在，零基索引始终分别为 59、3072、58、3073。可将该句改为“所核四份冻结报告均保留这四个键，且各母表为子表的有序前缀。各 run 读取母报告的列并重新生成现行行名和系数，不能据行名相同推断系数相同。”该勘误只需改措辞，94/60 的必要行证明和已登记数学结论没有依赖这处版本提示。
