# Minzer–Zheng 联合源与严格 MinRep gap

## 结论与实际模型

固定任意 ε′>0。存在 g₀，使每个先固定的整数 g≥g₀ 都有确定性多项式归约，输出有限非空、共同非空字母表 Σ、全投影约束的 D-regular 二部**约束多重图** Π；其两侧同大，记总顶点数 N，并且同一输出源同时具有

- Q=|Σ|=O(g^(2+ε′))；
- YES：val(Π)≥1−1/d；
- NO：val(Π)≤γ₀=2^−11 g^−2；

其中 Γ=5γ₀/4，d=10⁶·2ln(2Q)/√Γ。两项承诺属于同一归约的不同输入，不是对同一输入要求互斥的两项同时发生。中间正则度 D 可以随输入规模变化；本结论不声称这是冻结论文 Theorem7.2 显示的输入规模无关常数度实现。我们使用已登记的整数度舍入桥支付正规性，随后才把最终度降至 O(g ln g)。

可进一步让源的 YES 误差≤1/(2Δ)，其中固定整数 Δ 满足 d≤Δ≤d+2。应用已证的记录版稀疏化后，输出字母表 Q、保留上述正规化后 N、每个随机种子最大记录度≤Δ，并有

- YES：以至少0.9概率，MinRep≤2N；
- NO：以至少0.9概率，**全部**成本≤0.06N/√Γ的列表均不能覆盖所有记录，因而 MinRep>0.06N/√Γ>2gN。

这是单位标签成本、全约束覆盖、允许带身份平行约束的随机多项式 gap 归约。任意固定实数 g 可用整数 ⌈g⌉ 的结果得到同阶界及至少所需的因子。这里不认证要求简单约束图、额外平滑性或其他费用模型的外部连通性应用。

## Lemma7.8的平行端口审核

以下说明源文的实施修法及其精确条件，**不作为上一节主证明的额外前提**。

对任意左正规投影多重图，先删孤立右点并把所有边记录统一复制T次。复制不改任何赋值的满足比例，故严格保值。取T≥D，使每个非孤右点b的端口数n_b=T·deg(b)≥D。将原文A_b改为这些带原约束身份的入射端口集合P_b；端口e携带其原左端a(e)及投影π_e，端口不是能独立选标签的新左顶点。

假定给定每个n_b上的D-regular二部expander H_b=(P_b,B_b)，两侧n_b点且第二奇异值λ_b≤K√D，K为统一常数。每条expander边(e,j)对应一条从**原左点**a(e)到新右点j的约束π_e。原左点仍只赋一个标签。输出左度DT·d_left、右度D；因先作统一复制，不能冒称左度仍是原引理显示的D·d_left。对Theorem7.2“存在某些度数”的目的，此额外固定T不改变可用性。

任意原标签复制给全部右克隆，expander把每端口复制D次，故新值≥旧值。反向固定新标签F′，定义

    X_(b,σ)={e∈P_b：π_e(F′(a(e)))=σ}；
    Y_(b,σ)={j∈B_b：F′(j)=σ}。

全投影确保X_σ划分P_b，Y_σ划分B_b，两者大小和均n_b。随机给原b选一份均匀右克隆标签；其原局部满足率期望为Σσ |X_σ||Y_σ|/n_b²。混合引理与Cauchy–Schwarz给

    Σσ e_H(X_σ,Y_σ)/(Dn_b)
      ≤Σσ |X_σ||Y_σ|/n_b²
        +(K/√D)Σσ√(|X_σ|/n_b·|Y_σ|/n_b)
