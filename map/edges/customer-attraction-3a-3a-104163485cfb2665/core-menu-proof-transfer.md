## 可迁移的全历史核心菜单证明

先固定有限带标签共同目录、m 个单位权玩家，以及全部有序历史上的一份完整纯策略 σ。令非空标签类 B 中的每个标签覆盖同一个 mq 客户块；其余标签 P 按一个 partition 分组，每组覆盖一个 q 客户块，各组与核心及其他组互不交。此处 m≥2、q>0；有限单位客户实例取 q 为正整数。任意有理质量版本须先同倍清分母，不能把任意实质量直接称为有限单位客户。

现在假设 **σ 在每个决策历史均规定 B 中的标签**。这个假设是关于全部表项，而非仅根路径。取任意深度 d 的有序历史 h，令 g 为其中已有 big 行动次数，r=m−d 为含当前玩家在内的剩余人数。

遵从规定动作后，全部 r 人沿该 σ 的真实后继选 big；此前 g 人已选 big，故当前收益恰为

\[
  \frac{mq}{g+r}\ge q,\qquad g+r\le m.
\]

若当前强制另一个 big 标签，之后仍在其各自真实有序历史沿 σ 全选 big，总使用者数仍为 g+r，当前收益相同。不能只凭覆盖相同而冻结后继；这里所用的是每个后继节点都规定 big 这一已核的全树事实。

若当前强制任意 private 标签，其所属块总质量 q，当前收益至多 q。此前已经有人使用该组时收益还会降低；是否与另一个 private 标签同组不影响上界。之后真实后继仍 prescribed big。因此每一个原历史、每一个原标签偏离均不增益。非严格不等式保留所有弱平局；相同计数的不同有序历史可规定不同 big 标签。由逐历史单方最佳回复判据，σ 是完整纯 SPE。

这就是源正文证明的可复用承重部分。它允许把原 big 标签重新命名，并允许 private 标签并组，但不要求目标动作函数等于源的保存函数。对目标每张表，必须重新核它确为完整函数并且全树 prescribed big；下一节已经逐表完成这项输入核对。

## private 分组不变性的完整桥

这里补全上述两对表相同的结构解释，使用同一 B/P 标签身份、同一 m≥2 与 q>0、同一 mq 核心和每组 q 的独立块。结论是改变 private partition 后，作为同一完整函数空间的子集，SPE 集合双向相同；不声称任意非均衡策略的收益或两锥全部线性 IC 行相同。

任意历史 h 若已有 π≥1 次 private 行动（计次数，不计 distinct 标签或组数），当前选任意 big，沿该动作真实后继的 big 总使用者不超过 m−π，所以至少得 mq/(m−π)>q；选 private 至多得 q。故任意 SPE 在这些历史必须 prescribed big。反过来，若一份完整 σ 在每个含 private 历史 prescribed big，那么在这些历史无论当前强制何动作，后继仍全 big：任何 big 给 mq/(m−π)，private 至多 q，逐历史 IC 自动成立。

对全 big 历史 h，若强制 private，则后继已含 private，故全 big，当前是其 private 块的唯一使用者，真实菜单值恰为 q。若强制 big 标签 b，沿同一 σ 后继在第一次 private 后必全 big，后续 private 次数 δσ(h,b) 只可能是 0 或 1，当前菜单值为

\[
 V_\sigma(h,b)=\frac{mq}{m-\delta_\sigma(h,b)}.
\]

δ 可以因 b 的原标签不同而不同，必须按每个 b 的真实后继分别取；但同一 σ 在两个 partition 的标签树上取值完全相同，所以每个 δ 与 partition 无关。于是“含 private 历史 prescribed big；全 big 历史 prescribed 动作最大化上述逐标签菜单”是两游戏共同的 SPE 充要判据，给出全策略集合相等。这项证明保留全部有序历史、任意弱平局和同覆盖异标签。

同一 SPE 的根路径不变，首次 private 后全 big，根 private 次数为 0 或 1；根福利分别为 mq 或 (m+1)q。设 private 组数为 G，则至少一个 big 的静态最优为 `mq+q min(m−1,G)`，不用 big 至多 `q min(m,G)≤mq`，故这就是 OPT。由此在本精确块族内 `OPT/W≤2−1/m`。它不涵盖一般 CAG 或原固定策略锥的任意客户变量。

q=0 必须另支：全部收益零、任意完整策略都是 SPE、W=OPT=0；不能沿用“至多一次 private”或定义 0/0。P 为空时只有空 partition；B 为空不在桥内（两人两个 private 标签分组与并组即可改变末位平局）。private 改为 big 也不在桥内：m=2 时原 private p 后 prescribed p 不理性，若 p 改覆盖 big 则可理性。有限单位客户要求整数 q，或有理质量先同倍克隆。四目标实际 q=1，不涉及这些边界的额外假设。

## 源保存策略的显式共轭与身份差别

源实例 big 为 `{0,1,3,4}`，private 为 `{2,5,6}`，非零 mask 为 `4:1,27:5,32:1,64:1`。交换标签 0 与 2 的置换 τ 把客户输入送到 i=0/2 的 G8 输入；正确策略共轭必须同时改历史和动作：

\[
 \sigma_i^\tau(h)=\tau\bigl(\sigma_i(\tau^{-1}h)\bigr).
\]

对原计数表，先将每个新历史标签逆改名再计数查表，最后改名输出。原根动作 3 在 τ 下仍为 3，原根路径 `(3,3,3,1,1)` 亦不变。目标四表根动作都为 1，所以源保存策略的共轭与四目标均不同。仅改 mask 或仅改输出不等于给定策略的合法共轭。

可把该共轭策略再由 private 分组桥送到 G7，所得确是原给定函数的运输，但所得不是 M-c38 保存的两张目标函数。本边实际采用的是源的完整历史核心菜单证明，应用到已逐表核全 big 的四目标上；它不是 same-σ transport，也不是两个有限对象的 whole-result 等价。
