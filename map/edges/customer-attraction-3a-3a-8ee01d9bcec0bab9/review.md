# 合法背景的安全值平台与固定策略的共同静态对偶

## 所有四人子均衡的负载谱与指定前缀的离轨性

取 \(B\ge3\) 为整数。原例的五名单位客户为 \(x,y,p_1,p_2,p_3\)，六主标签依次覆盖 \(xp_1,xp_2,xp_3,yp_1,yp_2,yp_3\)，另有五个单例标签。令 \(h\) 为五个单例各出现 \(B\) 次、没有主标签的任意有序前缀。总人数为 \(5B+4\)。固定 \(h\) 后，旧负载均为 \(B\)，余四人，完整原树 SPE 限制到 \(h\) 下的策略必在所有后裔有序历史满足该子局的全部真实偏离比较，无论 \(h\) 是否在原树实际发生。

在这个四人子局的任意节点，主动作无论如何续局都至少得 \(2/(B+4)\)，单例至多得 \(1/(B+1)\)。前者对整数 \(B\ge3\) 严格较大。因此任一完整子 SPE 在全部历史都选主标签，其主标签历史的限制是主目录的完整 SPE。正文的集合值逆向归纳给出全部可实现完成。交换两核心及置换三花瓣可把任意首个主标签换为 0，因此只需检查 0 后的八项完成。下表为加上首个 0 后，在 \((x,y,p_1,p_2,p_3)\) 的顺序下由四位余玩家产生的负载。

| 0 后的完成多重集 | 新增负载 |
| --- | --- |
| 245 | \((2,2,1,1,2)\) |
| 244 | \((2,2,1,2,1)\) |
| 234 | \((2,2,2,1,1)\) |
| 155 | \((2,2,1,1,2)\) |
| 145 | \((2,2,1,2,1)\) |
| 135 | \((2,2,2,1,1)\) |
| 123 | \((3,1,2,1,1)\) |
| 045 | \((2,2,2,1,1)\) |

每项都覆盖五名客户，排序后仅有两种负载谱 \((1,1,2,2,2)\) 与 \((1,1,1,2,3)\)。对真整数静态值 \(V=v_4(b)=3/[2(B+2)]+1/[2(B+3)]\)，分别从剩余总利润 \(\sum_x c_x/(B+c_x)\) 减去 \(4V\)，得到
\[
\frac{2}{B+1}-\frac{2}{B+3}=\frac{4}{(B+1)(B+3)}>0,\qquad
\frac{2(B+4)}{(B+1)(B+2)(B+3)}>0.
\]
这些计算闭合 AGG0 在该全参数四人子局、所有完整子 SPE 的限制域。四人的总利润只计四人各自分得的份额。

再假设某份完整原树 SPE 的根实际路径以 \(h\) 开头。令 \(q\) 为 \(h\) 最后一位单例客户，行动前 \(q\) 的负载为 \(B-1\)，其他客户负载为 \(B\)。执行该单例后，真实尾部是前述四人子 SPE，故 \(q\) 至少又被选一次，此人收益至多 \(1/(B+1)\)。若他改选任一覆盖 \(q\) 的主标签，其真实偏离续局的四人无论怎样行动，所选的两客户的终局负载分别至多 \(B+4,B+5\)。因此其偏离利润至少 \(1/(B+4)+1/(B+5)\)，严格超过规定动作上界，差为
\[
\frac{B^2+2B-11}{(B+1)(B+4)(B+5)}>0
\]
（\(B=3\) 分子为 4，此后递增）。这违反最后一位单例的真实 IC。故任意排列 \(h\) 都合法、都可作为完整原树 SPE 的子树所在历史，但都不可能出现在任何完整原树 SPE 的根实际路径上。

## 指定 0123 续局的强链与局部斜率

指定实际余路径 \(0,1,2,3\)。按位置记 \(V_i=v_{5-i}(b_i)\)，其中 \(b_i\) 含固定旧背景及前 \(i-1\) 个实际余动作。原正文以查询前固定的匹配证书给出 \(V_1=V_2=V\)。首位 \(u_1=1/(B+2)+1/(B+3)\)，故
\[
D_1=u_1+3V_2-4V_1=-\frac{1}{2(B+2)(B+3)}.
\]
弱系数 \(\widetilde D_1=D_1-(V_2-V_1)/2\) 同为负。任意有限的 \(\alpha\)，即使按局部状态或整份策略选择，右侧 \(-\alpha(V_2-V_1)\) 都为 0。这精确否定对所有合法背景及每份完整子 SPE 逐节点要求 \(D_i\ge-\alpha(V_{i+1}-V_i)\) 的合同。

后续值可直接求出。动作 0、1 后剩两人，纯查询 5（\(yp_3\)）的两客户此前未被两主动作覆盖，面对任一合法竞争动作均给至少 \(2/(B+2)\)。纯竞争 5 后，五名客户新增负载为 \((2,1,1,1,1)\)，所有查询都至多 \(2/(B+2)\)。故 \(V_3=2/(B+2)\)。动作 0、1、2 后新增负载为 \((3,0,1,1,1)\)，末位 3 是真最优，给 \(V_4=u_4=1/(B+1)+1/(B+2)\)。余第二、三位同得 \(u_2=u_3=1/(B+1)+1/(B+3)\)。代入强链，
\[
\begin{aligned}
D_1+D_2&=\frac{1}{(B+1)(B+2)}>0,\\
D_3&=\frac{B+5}{(B+1)(B+2)(B+3)}>0,\\
\sum_{i=1}^3D_i&=P_4(b)-4V
=\frac{2(B+4)}{(B+1)(B+2)(B+3)}>0.
\end{aligned}
\]
这里 \(P_4(b)\) 是固定背景下四人的实际总利润。望远镜由 \(V_4=u_4\) 精确闭合。所得相邻回补只针对这条余路径，普遍两步及全局付款仍是另外的量词。

113 单位客户的三人见证使用真正空背景的实际根，沿相同的四十三历史分组策略得到真实 \(D_1<0\)、\(\widetilde D_1<0\)，同时 \(V_2-V_1=885147385/10233939282>0\)。以该点的精确鞍点回算，\(D_1\ge-\alpha(V_2-V_1)\) 当且仅当 \(\alpha\ge3426993456/885147385\)。因此实际零根证据否定强、弱逐步非负及这个点的小斜率。合法背景的平台排除即使逐状态选择的有限斜率。现行登记未把该普遍逐节点合同另立独立对象。链恒等式仍成立，AGG0 仍开放。

## 固定分组对偶的核验范围

固定分组资源的浮点发现器搜索小分母共同背景 \(Q\)，保存分母 3、背景 01/02/03 等权、六套各 215 项浮点乘子，其中 14 项为负小量。原输出没有认证分母最小。冻结的独立 Fraction 入口直接以同一完整策略的真实完成与偏离完成构造系数，给六查询各 7、6、9、4、3、4 条明确非负整行 IC 乘子。对六查询及全部 63 种非空兴趣类型逐项确认
\[
W/3-\mathbb E_Q f_B(a)=L_a+\sum_t w_t r_{at},\qquad r_{at}\ge0,
\]
其中 \(w\ge0\)，且 \(L_a\ge0\) 来自该形式策略的所有真实 IC 成立。背景对按负载合并为 21 个二槽多重集。43 个动态决策历史仍按顺序分开。该定理量化同一个指定完整策略的零背景客户锥，给该子域的 \(P_3(0)=W\ge3v_3(0)\)。

113 客户见证恰落在这个完整策略锥中。将其客户重数代入 \(Q\)，按标签 0 到 5 的纯查询上界为 \((541/18,308/9,299/9,557/18,203/6,203/6)\)，最大 \(308/9<35=W/3\)。它同时有严格的零根局部债务，给出在同一固定策略、同一客户点上静态聚合证书和逐步亏空并存的比较。该静态上界不按实际节点递推，四人合法背景族也没有固定策略锥的零背景假设。
