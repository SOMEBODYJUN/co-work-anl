# 数学支持：M-ce128 的固定必要点、PAIR 行和连续分离

## 1. 共同模型与量词

客户集 `N` 有限，标签目录 `𝒮` 有限非空，每个标签给出覆盖子集 `cov(S)⊆N`，可有多个标签同覆盖或空覆盖。六名单位权提供者按 `1,…,6` 依次行动，观察全部有序历史并选目录标签。终局客户收益在覆盖者中均分，`u_i=Σ_{x∈A_i}1/c_x`，`W=Σ_i u_i=|∪A_i|`。纯策略在每个历史定义；完整 SPE 要求每个 `i,h,T` 的真实续局偏离不降低 `u_i`。所有零客户、空题、重复动作、同覆盖异标签和离轨平局都属于量词域。

M-ce128 的点仅是这些 SPE 必要不等式在固定 16 hist 支持上的投影。比较元组 `T₁,…,T₆` 的并集 `O=1` 是归一化截面；只有继承的 `--optimum` 行另加“六题达到 OPT₆”的条件。`K` 只是一条共同容量列，不是客户质量；零权列仍是完整 1905 维输入的一部分。

## 2. 5043 点的精确身份

原 JSON 全字段：`base_rows=702`、`first_raw_rows=37`、`additional_index_class_rows=100`、`verified_rows=5043`、`minimum_slack=0`、`positive_columns=184`、`additional_new_reply_floors=36`。列种类为 `K=1, hist=16, joint-reply=582, overlap=1306`。质量满足 `O=1` 及

`W=348849746216199535907980629211183 / 729080852958937593380920238282304`,

严格小于 `1/2`。这是精确有理可行点的存在性记录；原 runtime `execution.json` 只读复放 `all_reply_actual_floors.py --priced --optimum --old-query-cuts --mixed-pair --verify`，exit 0、assert 开启、optimization_runs 0、38 个冻结输入字节不变。独立 point audit 再读全 1905 列和所有质量/边缘字段，但“原入口全 5043 行验证”和“独立局部审计”是两层证据，不能合并成第二次全图推导。

## 3. 36 floor 和 72 mixed 行

对 actual 源 `i`，客户历史前负载为 `p_i`；强制任一合法 `R_e/Z_e` 后，至多剩余 `6−i` 人覆盖，故源 IC 至少支付 `1/(p_i+6−i)`。边族重数为 `30,30,6`，由此得到 36 条新 floor 行。joint 列的 `state[member]` 只消费指定 R 或 Z 边缘，`K`/overlap 系数为 0，输入列顺序要求每个 hist 后紧跟其 joint 块；这解释了程序为何不能按 `hist_column_old` 任意重排。

在前四背景，最后两人真实 IC 的强 PAIR 恒等式是

`H−F(T)−F(Q)+G(T,Q) = I₁+I₂+I₃+G(C,C)−G(C,J)`,

`G(C,C)−G(C,J)` 是 `C\J` 上非负权和。对 R/Z 三类有序边、12 个查询（六 actual、`T_j/B_j/C_j`、`T_l/B_l/C_l`）聚合成 72 键。旧 8 条 alpha=mu=1 端点恰对应其中 3 个不同向量，只因 all/last 的单后继和对角 `B_j=B_l` 重复而保留 8 条历史记录。

当前点 72 行精确结果为 `0 negative / 4 zero / 68 positive`。这证明新增 mixed 行没有切掉当前点；它们只是完整 SPE 必要条件的一部分。旧 4963 点的 7 负 mixed 键、8 条旧端点和当前点不可混用。

## 4. 64/32 连续投影的结构

对合法 `T,Q`，末位真实续局 `J` 只被 IC 消去，隐藏中间回复的相同价格使二元会员按 `s` 计数；取 `g∈{0,1}` 是末位会员。对任意非负 `(α_m,α_l,μ)`，

`Ψ_i(p,ℓ,t,q)=min_{s,g}[ (t−μg)/(p+t+s+g) +(α_m s+α_l g)/(ℓ+1)+μq/(p+t+s+1) ]`.

边行左侧是 `c[u_{i+1}+((n−1)α_m+α_l)u₆]`，右侧按 hist 质量 `h` 和回复一阶边缘 `t_g` 插值：`(h−t_g)Ψ(0,q_g)+t_gΨ(1,q_g)`。这保留隐含 00 质量，不把三状态相加当作总客户质量，也不需要 overlap 变量。

旧 64 表：180 个结构（5 源×2 member×3 轨道×6 qi），价格盒 `[0,1000]`，64 保存记录，63 个不同完整行向量；在旧 query_4971 点独立精确重算 64 负值，最小余量

`−31656298537448410947614489967609469 / 128318230120773016435041961937685504`.

32 refinement 表：32 个有理八元组，实际源分布为第 3 位 15 条/第 4 位 17 条，R 17/Z 15，全部非对角；与旧 64 仅 21 元组重合。其四阶段 audit 为：4971 点 32 负；5075 点 0 负、3 零、29 正；5108 点 0 负、5 零、27 正；changed-Z pair 点 0 负、3 零、29 正。5075 与 5108 具有相同 W 但 124 个权坐标不同，故同 W 不代表同点。

对同一 M-ce128 5043 原件，按已读 `audit_cuts.py` 的 `read_point/evaluate` Fraction 定义重新代入（不运行发现 LP、不改冻结源）：64 表为 64 负、0 零、0 正；32 表为 32 负、0 零、0 正。两表第 0 条均为 `−31656298537448410947614489967609469 / 128318230120773016435041961937685504`；64 表最大（仍为负）为 `−1660673275144715318271976766147377667 / 135434059245652247346439743463320791040`，32 表最大（仍为负）为 `−3052729112298935014707794753150383 / 38884312157810004980315746041722880`。四阶段 JSON 的 4971/5075/5108/changed-Z 结果仍按其声明的独立范围保留，不能混写成 current-5043 运行事件。

## 5. 共同实现障碍和开放义务

point audit 读出 194 个隐含 00 质量均非负（140 为 0），2612 个 overlap 上界均非负（1905 为 0），但 1306 个字面 Frechet 检查有 198 个下界违例。故当前有理点可作为线性必要图点，不能直接还原同一客户空间中的 R/Z 交叠。连续 cut 只读 hist 和 R/Z 一阶边缘，修改 overlap 不会改变这些 cut 系数；但要把“不能延拓”提升到完整 SPE，仍需完成共同客户实现和全历史策略量词，这些都不是本对象已支付的义务。

本包不声称：LP/浮点发现全域最优、连续价格族闭包、所有 5043/5075/5108/10344 行在 changed-Z 下通过、一般 `2W≥OPT₆`、或一个完整 SPE 反例。未来若建新边，须绑定实际点和具体边缘/价格域，保留这些边界。
