# M-ce128：5043 行混合强 PAIR 必要点与连续旧查询分离

## 核心结论

本包的唯一核心对象是 `M-ce128b15d03b4872990063540cb13d60`（“5043行混合强PAIR系统的有理坏点被连续旧查询行分离”）。其模型是共同目录覆盖博弈：有限单位客户，有限非空共同标签目录，每个提供者按固定次序观察完整有序历史并选一次合法标签，终局每个客户的单位价值在全部覆盖者之间均分。空主题、重复标签、同覆盖异标签、零客户、任意离轨历史和弱平局都保留。完整纯策略在每个有序历史定义；纯 SPE 量词是对所有玩家、所有历史和所有单步偏离沿给定策略真实续局成立。

该对象不是一份游戏策略，也不是 SPE 构造。它是固定 16 个旧直方图支持上的 1905 维有理必要图点：`K` 1 列、`hist` 16 列、`joint-reply` 582 列和 `overlap` 1306 列。原件 SHA `83b469f45e6017c024d1f87c614c5b1e968be94bb171ed27bb913c7119843613`，`verified_rows=5043`、`O=1`、正列 184、原全图最小余量 0，并且

`W = 348849746216199535907980629211183 / 729080852958937593380920238282304 < 1/2`.

其存在性是“固定必要系统有一个精确有理点”，不是该点可由一个共同客户目录或完整历史策略实现。对象注册的 obstruction 结论由后继连续旧查询 64-cut 和 32-cut 表在该点的严格负余量承担；这只排除保留该点指定边缘的完整有序历史纯 SPE 延拓，不给一般 six-half 反例或全域闭包。

## 完整对象和必要行

设实际路径为 `A₁,…,A₆`，收益为 `u₁,…,u₆`；六个合法比较主题为 `T₁,…,T₆`，`O=1` 是其并集归一化。前三个实际行动后强制第四位取 `T_j`，真实尾为 `B_j,C_j`；

`R₀,j,l = σ₆(A₁,A₂,A₃,T_j,B_l)`（`j≠l`），
`R₁,j,l = σ₆(A₁,A₂,A₃,T_j,C_l)`（全部 `j,l`），
`Z_e = σ₆(A₁,A₂,A₃,A₄,R_e)`.

R/Z 是同一完整策略中的真实标签身份；被强制主题不因此成为强制节点的最优行动。每个旧索引词 `(T_j,B_j,C_j)` 由 8 桶直方图记录。对角组仅在同词同索引时出现；非对角边是有序边，不能按无序边除二。

36 条 actual-prefix floor 行来自六个源位置、R/Z 两个成员和 `(family,diag)=(0,0),(1,0),(1,1)` 三类：每个组有 30、30、6 条有序边。对源位置 `i`、客户前缀负载 `p_i(x)`，实际后续至多 `6−i` 人给安全份额 `1/(p_i+6−i)`；真实源 IC 逐边给出

`L_{i,member,g} = n_g u_{i+1} − Σ_{e∈E_g} Σ_{x∈Q_e} 1/(p_i(x)+6−i) ≥ 0`.

原程序的 5043 行分层是固定支持基础图、旧 B/C 跨实际源和共同容量、有限 priced/optimum 投影、36 条新 R/Z floor、8 条旧查询端点和 72 条 mixed strong-PAIR。5043 点通过这些有限行，但不能由通过性反推完整共同目录或 SPE。

## 72 条 mixed strong-PAIR 的准确数学作用

在实际前四背景下令 `C=A₅,D=A₆`，`b_x` 为前四负载，
`F(X)=Σ_{x∈X}1/(b_x+1)`，
`G(X,Y)=Σ_{x∈X∩Y}1/((b_x+1)(b_x+2))`，
`U(X,Y)=F(X)−G(X,Y)`，
`H=U(C,D)+U(D,C)+G(C,C)`。

对任意合法强制主题 `T`、查询主题 `Q`，令 `J` 为强制 `T` 后沿同一策略的真实末回复。三条真实 IC 给出

`H − F(T) − F(Q) + G(T,Q) = I₁+I₂+I₃+G(C,C)−G(C,J) ≥ 0`.

将 `T` 取 R 或 Z、`Q` 取六个 actual 主题和两端旧索引词的六个主题，并对 `(0,0),(1,0),(1,1)` 有序边求和，得到 `2×3×12=72` 行。逐客户系数为

`(a₄+a₅)/c + a₄/((b+1)(b+2)) − (t+q)/(b+1) + tq/((b+1)(b+2))`,

其中 `a` 是 actual 六位会员串、`c=Σa`、`t` 是 R/Z 会员、`q` 是查询会员。`K` 与旧 overlap 在这些行中系数全为 0；joint 列只通过 `01/10/11` 三状态边缘补 t=1 差量，隐含 `00` 仍由 hist 减去三状态。

在当前 M-ce128 点，`point-audit.json` 给出 72 行精确余量：负 0、零 4、正 68、最小 0。四个零键是 `(1,0,0,5)`, `(1,1,0,5)`, `(1,1,0,10)`, `(1,1,1,5)`；它们不是四个独立方向。旧 4963 floor 点上同一 mixed 族曾有 7 个负键，这个旧点与当前 5043 点的权向量不同，负值不能迁移。

## 连续旧查询切面及精确边界

64 表和 32 表每条 cut 都来自共同末位报价/隐藏回复投影：对源位置 `i=0,…,4`、R/Z 成员、三类有序索引轨道、六个合法旧查询位和非负价格 `(α_m,α_l,μ)`，以

`Ψ_i(p,ℓ,t,q) = min_{0≤s<n, g∈{0,1}} [ (t−μg)/(p+t+s+g) + (α_m s+α_l g)/(ℓ+1) + μq/(p+t+s+1) ]`

做所有真实隐藏后继的精确计数下包络，并按同轨道边相加。价格乘子的合法性来自源 IC、实际末位共同报价及强制分支末位对 Q 的 IC；它不依赖 16-hist 支持，也不冻结偏离后的真实后继。

旧 64 表是从 180 个有限结构的 `[0,1000]` 浮点 LP 发现后有理化，再以 Fraction 精确回代；它有 64 条保存记录但只有 63 个不同 1905 维向量（对角重复保历史顺序）。32 refinement 表是另一组 32 个参数，和旧 64 仅 21 个完整元组重合，不能视为旧 64 的前缀，也不能把 64+32 当作 96 个独立方向。对象正文报告两表均严格切当前 5043 点；本轮按已读 `audit_cuts.py` 的同一 Fraction 积分定义对 M-ce128 原件复算，64 表为 64 负、32 表为 32 负，首条共同余量为 `−31656298537448410947614489967609469/128318230120773016435041961937685504`。当前声明的四阶段 audit 另明确记录了 4971 点上 old64/32 全负、5075 与 5108 点上 32 表全非负，以及各自的精确最小值。不得把这些不同点的 slack 互换或由同 W 推断同一向量。

## overlap 诊断和不能升级的结论

1905 点的 overlap 辅助坐标不是同一客户空间中已实现的所有集合交叠。`point-audit.json` 逐项检查 1306 个 Frechet 下界，发现 198 个保存辅助量低于 `max(0,r_g+r_q−h)`（1107 个相等、1 个更大）；最显著例子是 hist 列 250 的两个 R 组各覆盖该块全部质量，而保存 overlap 为 0。该诊断只否定“把每个 overlap 量字面认作真实交叠”的解释，不否定原 5043 行 Fraction 验证，也不意味着更换 overlap 就能修复连续 cut 的负余量。

剩余义务是：共同客户实现、全部联合 R/Z 会员、完整目录尾博弈和所有离轨策略仍未由此有限点给出；64/32 发现过程没有连续价格族闭包或 exact optimum 证书。对 current M-ce128 之外的 floor/query/refinement/master 或 changed-Z 点，必须重新代入，不得借用同 W 或同列布局作结论。
