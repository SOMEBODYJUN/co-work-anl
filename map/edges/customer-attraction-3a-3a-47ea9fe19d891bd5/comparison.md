# 同源三尾的共同价格、两个上限与旧任意锚行

任务 `customer-attraction-3a-3a-47ea9fe19d891bd5`，审读 Boss3。两个核心是 `customer-attraction/shared-maximal-potential-three-tail-prefix-bound`（H3）与 `M-043045ec129b4a5f82a3368b324accf9`（平衡正价）。以下先给两条普遍式在同一真实源上的精确交集，再核原证明与数值资产的边界。

## 同一客户价格与两个上限

固定六人共同标签目录、单位客户、同一完整有序历史纯 SPE σ 和任意合法有序三行动源 h。以 b 记源背景，A=σ₄(h)，u 是源规定者沿 σ 的最终收益。令 `P=b+1_A`，固定一个全目录 `f_P(T)=Σ_T 1/(P+1)` 最大标签 X。离轨 h 仍可比较，只有实际 h 的 u 是实际 u₄。X 固定后，以下 D 遍历全目录。定义

\[
\kappa_X=\sum_{j\in X}\frac1{b_j+3},\qquad
U_X=\sum_{j\notin X}\frac1{b_j+1},\qquad
\delta=u-\kappa_X\ge0.
\]

SAFE 的付款为 `u≥v_h(X)≥κ_X`，其中 `v_h(X)` 取同一 σ 在 `(h,X)` 之后的真实两步续局，客户分母至多 `b+3`。H3 给

\[
L_b(X,D)=\sum_{j\in D\cap X}\frac1{b_j+3}+\sum_{j\in D\setminus X}\frac1{b_j+1}
\le C_H=10u-9\kappa_X.
\]

在平衡正价定理中用同一 h、`p=b,k=3,r=u`，源权 `a=M=1`，静态查询单独取固定 X 且权 1，自查询权与全部中间/末位价格、容量权均为 0，先取 `θ=0`。正价的被定价主题 `F=D`，不同于固定的静态查询 X。对单客户以 x 表示 X 会员，t 表示 D 会员，H 为 `(t−c)/(b+t+s+c)+x/(b+t+s+1)`，其中 `s∈{0,1}`，零分子项取 0。固定 t，分别对 `c,s` 取最小得到

\[
\Psi_0(0)=-\frac{1-x}{b+1},\qquad \Psi_0(1)=\frac{x}{b+3}.
\]

当 `t=0,x=0`，取 `c=1,s=0` 得负最小值。当 `t=0,x=1`，取 `c=1` 得 0，两项恰取消。当 `t=1,x=0`，取 `c=1` 得 0。当 `t=1,x=1`，取 `c=s=1` 达到最小的查询成本，且源项为 0。故价格 `w=Ψ₀(1)−Ψ₀(0)` 逐客户恰为 H3 的 `L_b(X,D)` 中 D 的系数，正价共同预算 `B=u` 给

\[
L_b(X,D)\le C_B=u+U_X,\qquad C_B-C_H=U_X-9\delta.
\]

因此 `U_X≤9δ` 时，平衡正价这一特例给同源、同 X、全部合法 D 的 H3 主式。`U_X≥9δ` 时，H3 给同参数正价不等式。相等时两者给同一行。这两个方向分别是定域的局部贡献。正价特例允许任意先固定的合法 X，H3 一侧要求 X 在规定第四行动 A 后的 `f_P` 上最大。全部两式使用同一源收益 u 和同一 X。可对固定菜单作非负合账，不能从两个帽子取得两个免费的源收益。

## 此固定单查询零外价族的任意折扣

保持上节除折扣外的全部参数。对某客户写 `A₀=1/(b+1)`、`D₀=1/(b+2)`、`C₀=1/(b+3)`。按 `(e00,e01,e10,e11)` 的顺序，直接对中间位 s 取最小得

| 固定 X 会员 x | 四个有向边代价 |
| --- | --- |
| 0 | `(0, −A₀, D₀, 0)` |
| 1 | `(D₀, 0, D₀+C₀, C₀)` |

由二状态三候选公式，当 `x=1` 得 `Ψθ(0)=θC₀, Ψθ(1)=C₀`。核候选时使用 `D₀≥C₀>θC₀`。当 `x=0`，设 `ξ=(θA₀−D₀)_+/(1+θ)`，则

\[
\Psi_\theta(0)=-(1-\theta)A_0-\theta\xi,\qquad
\Psi_\theta(1)=-\xi.
\]

例如状态 0 的二循环候选与转入 1 候选之差为 `θ(D₀−θA₀)/(1+θ)`，状态 1 的二循环候选为 `(D₀−θA₀)/(1+θ)`，其余两候选的最小是 0。于是对任意合法 D，记 `t_j=1_D(j)`，有精确余量分解

\[
S_\theta(D):=u-\sum_j\Psi_{\theta,j}(t_j)
=(1-\theta)\bigl(C_B-L_b(X,D)\bigr)+\theta\delta
 +\sum_{j\notin X}[\theta(1-t_j)+t_j]\xi_j.
\]

最后一项逐客户非负。由零折扣行与同锚 SAFE 即可付清这一具体族的任意 `0≤θ<1` 行。这个代数结论限同源、平衡权 1、固定单查询 X、无自查询、零外价的选参。带正外价、多个查询或动态自查询的 Bellman 行仍用各自的预算和系数核对。该特例中进一步有 `x=1` 的价格 `(1−θ)C₀`，`x=0` 的价格 `(1−θ)(A₀−ξ)`，因 `0≤ξ≤(A₀−D₀)/2` 故仍严格正。所有零分母边界沿原零分子约定；零客户的各和为零。

## 旧 AP 的实际覆盖域

旧任意锚 AP 令 `C=X,k=3,p=b,s_C=κ_X,e=δ` 后，左侧就是 `L_b(X,D)`。AP1 用共同 `M=3+max_j b_j`（无客户取 `max=0`），AP2 用共同 `M_X=3+max_(j∈X)b_j`（X 空取 `max=0`）。令 `N` 依版本为 `M` 或 `M_X`，旧帽为 `κ_X+(2(N−1)+9/2)δ`。当 `N=3,4,5,6` 时，旧系数依次为 `17/2,21/2,25/2,29/2`。旧帽减 H3 帽恰为 `(2N−15/2)δ`。因此 H3 对自己的最大锚 X 分别支付 AP1 的 `M≥4` 源和 AP2 的 `M_X≥4` 锚；六人统一放宽 `N=6` 的差额为 `(9/2)δ`。`N=3` 时旧帽的系数更小，`δ=0` 时二帽都为 `κ_X`。H3 的 b 约束、锚的 `f_P` 最大性、旧 AP 任意锚与任意尾长的独立证明均保留。固定支持 v2 先对整个支持取共同 `Mbar_X`，切勿对每客户换乘子。旧 BNS 锚按 `Σ_X1/(b+3)` 最大化，与本处 `f_P` 最大性分别核验。

## 原证明、数值证据与构图去向

- H3 主式的四份全局预算依次是 h 对 X 的源 IC、`F−f_P(Y)`、`2(F−f_P(Z))` 和 `(h,X,Y)` 的真实末位查询；`Y=σ₅(h,X)`、`Z=σ₆(h,X,Y)`。解析余项在 `b=0,…,3` 与五个布尔位均非负，`x=y=1,z=0,a=0` 的下界含 `(n−1)(4−n)`，显示 b 上限确实入证。Y 的最优性不为主式付款。指定七权锥的三个 TP 使用真实 `J_L=σ₆(h,X,L)`、相应末位查询和逐客户自交叠税。精确两端点每份均有 128 型、39 个零、89 个正，最小正余项 `1/30`。四支持型给 `E_A+3E_H=−η₂` 及 `C−10=14E_A+12E_B+6E_D+6E_H+η₁+11η₃`，固定 C=10 后另两型和两端点的仿射性给完整 α 区间 `[1,6/5]`。这只约束明定的七预算逐型锥。
- 平衡正价由同一源对每个 T 的真实后继和末回复 `C_h(T)` 付款。固定 q 后可在有限共同目录取辅助 Bellman 主题值最大者，合法的 `C_h(T)` 可重查但仍回同一 h。平衡 `a=M` 给同 `(c,s)` 的差 `(a−q)/(p+s+1)+(μ_*+q)/(p+s+2)`，与 c 及价/容量项无关，先取同域 s 的最小值、再在同一固定点两行取 c 的最小值，给精确正价区间。k=2 时两端重合。k>2 的两行可用不同最优 s，价格仍可受参数影响。每个跨枝应用都需要同一个完整 B 和相同基值和，按应用总权付款。
- 现有 H3 有限接口的 17 个旧查询轨道使用 21021 维坐标、1731 个非零项、零新列。真实未知 XQ 交叠的系数为正，原必要放松允许同时将 420 个上界列取各自的 min，未声称这些上界能共同成为真实交叠。绑定 `5b1b…` 的固定点上 17 行均正，只证该点该 X/上包络上的诊断。Bellman 新特例的 `U_X` 包含所有非 X 客户，若要接任一固定主图，须核相同 X 会员、全部客户质量的坐标合同和查询身份，再判断实际分离。此处没有增加冻结有限系统或比较不同输入点的数值。
- 已有 canonical `ca-six-boss1-complete-history-pays-common-X-H3` 支付 H3 的四预算主式。已有 `boss2-six-cross-balanced-discount-to-positive-price` 支付前身 `M-b233ef00a9c34e189817cdfb7a495107` 到平衡正价的全部一般命题，关闭该准确 3B 重叠。此次新增的是两个定域的同价格上限方向及其对 AP1/AP2 的精确旧行作用。六人一般半覆盖仍需统一付款；两条核心各自的全量陈述不由对方这一个特例推出。
