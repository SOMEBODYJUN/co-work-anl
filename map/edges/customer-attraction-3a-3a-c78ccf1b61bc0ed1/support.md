## 1. 精确模型与已证收费

固定任意合法长度一历史，前置主题为 `Z`，随后沿同一完整有序历史纯 SPE 取五个真实主题 `A,B,C,D,E`。有限单位客户和有限非空带标签目录均可含空覆盖、重复动作、同覆盖异标签、任意弱平局和零客户；偏离后继续使用同一策略真实后继。令

- `b_x=1_Z(x)`，`c_x=1_A(x)+...+1_E(x)`；
- `V=sum c_x/(b_x+c_x)` 为五尾真实利润，`r_Z=sum b_x/(b_x+c_x)` 为前置者真实份额，`W=V+r_Z`；
- `E_Z=|Z\(A∪B∪C∪D∪E)|`；
- 任意五个合法比较标签 `T_1,...,T_5`（允许重复）有 `d_x=sum_i1_{T_i}(x)` 和 `R_Z=sum d_x/(b_x+d_x)`。

严格保留原53个外乘子、局部源乘子、共同容量 `K`，把每条源行的物理收益分母统一平移到同一个 `b`，再在完整二元客户系数域做精确最小化。独立字面实现确认

`epsilon = 62212762317811658581 / 1250000000000000000000 < 1/20`,

并对所有上述模型、量词和五比较得到

`R_Z <= 2 V + epsilon E_Z <= 2 V + r_Z/20`.

若 `Z⊆U`，则 `E_Z=0`，收费变成 `R_Z<=2V`。这是利润收费；不能把 `V` 换成五尾新覆盖、不能把 `R_Z` 当作 `OPT_6`。

## 2. 证明域与独立复核

`53-b` 恒等式为

`2V-R_Z = sum_j lambda_j S_j + kappa K + sum_x rho_b(omega_x)`,

其中 `kappa=2264870/10^22>0`，`S_j>=0` 是平移后的合法源行，`omega_x` 是每个客户的完整压缩类型。完整枚举覆盖 `b=0,1`、五位真实尾类型和五比较重数 `d=0,...,5`。利润目标的 6144 个 `b=0` 条件态全非负；6144 个 `b=1` 条件态中仅 32 个未收费负态，全部在真实尾 `ABCDE=00000`，最坏值正好 `-epsilon`，加入 `epsilon E_Z` 后全部非负。覆盖目标另行核验为全非负，不能与利润目标混用。

`verify_literal_and_bridge.py` 不导入主构造器，直接逐字重算三种模式各 192 个保存见证（共 10176 行值/模式），报告 `ALL DIRECT WITNESS AND CHARGING CHECKS PASSED`。它同时核对单个新增末位查询 `Z` 的固定53权区间：

`62212762317811658581/625000000000000000000 <= t <= 89431876338724648291/60000000000000000000000`,

## 3. 六槽接口的准确缺口

六个比较槽删一平均的客户损失是

`delta_0(d)=1/6` 仅在 `d=1`，以及 `delta_1(d)=7/[6(d+1)]` 对 `d>=1`（`delta_1(0)=0`）。在六个真实根偏离上，背景收费可以逐枝写成 `C_j=2V_j-R_j+epsilon E_j>=0`，但实际路径与根枝之间还存在真实尾利润差 `D_W`、根 IC 松弛 `s` 和六槽债务。ROOT-6/mix-C 与 mix-H 的负号项不能删除。

一个 11 客户的完整全历史 SPE（六客户大主题加五个单客户主题，策略始终选大主题）给 `W=6,u_1=1,V=5,OPT_6=11`，六删一平均五尾利润为 `20/3`，删槽债务 `13/3>2u_1=2`。它只否定“删槽损失由两份第一人收益单独支付”的模板；这个游戏仍满足 `2W=12>11`，所以不是 half 反例。

## 4. 方法障碍与有限点诊断

自由53外权锥的独立有理下界约 `0.01882600676`；加入五个真实 `Z` 查询、`K-|Z|` 和七个真实后继 `Z` 查询后的66行锥下界约 `7.93164968486e-5`。这些证书分别要求完整客户域和共同 `K` 非负，只说明指定证明方法不能做到零收费；它们不反驳 BG5，不是完整目录/SPE 反例。

六根 `background_root_bridge` 的71行投影在固定点上有27原子有理非分离证书，独立审计报告严格下界约 `0.01712481417`，且明确标注“conditional hidden tails, not a complete SPE”。19556/19578 类必要点也未被收费证书分离；其根后继联合实现尚未证明。
