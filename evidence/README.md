# Evidence is not a universal proof

- [audits](audits): internal adversarial readings, scope checks and recorded objections.
- [certificates](certificates): specific input/output pairs whose loads and actual deviations can be checked exactly. Shared, heterogeneous and instance-optimal solvers use distinct JSON fields.
- [runs/2026-09-30](runs/2026-09-30): frozen finite test summaries. The current tests write a new report only with an explicit report path.

The [evidence ledger](../EVIDENCE.md) gives counts and their limits. Proof authority stays with [manuscripts](../manuscripts), and every universal claim retains the status in [CLAIMS.md](../CLAIMS.md).
