## 作者标量程序：枚举合同和冻结对账

原程序仅导入标准库Fraction、itertools、json、Path，不调用SPE求解器、LP或发现代码。`check`显式跳过未覆盖客户的倒数，先保证选中客户的负载至少一，再算t、L、A、D、协方差、J，断言精确响应恒等式。另核

$$\operatorname{Cov}(I,c)\le (\max c-\min c)t(1-t),$$

以及跨覆盖稳定条件和振幅至多一条件下的相应非负比较。

主循环范围是：背景b=0,…,3；三个原始概率质量各0,…,3且总和非零，归一化成p；三个会员指示各0/1；三个负载各0,…,4，排除I=1而c=0。它包含零概率分支及t=0/1。不同质量向量可能归一化为同一p，故计数是**枚举条目数**，不是互异分布数，也不是实际可实现SPE数。

必要性循环取b=0,…,3、覆盖负载1,…,7、未覆盖负载0,…,7，只留差d>1，用 $\varepsilon=(d-1)/(2d)$ 精确构造 $D_x<F_x$。原输出的全部字段为：

| 字段 | 值 |
|---|---|
| status | exact_pass |
| local_identities | 183708 |
| diameter_at_most_one_cases | 49140 |
| cross_membership_stable_cases | 123228 |
| exact_necessity_witnesses | 84 |
| scope | Scalar identity and sufficient-condition regression; not a general SPE proof |

本轮将原脚本原字节复制到隔离 [replay/author/](../../tools/evidence/response-debt/replay/author/)，执行一次，exit0。它按原实现旁写的 [response_debt_audit.json](../../tools/evidence/response-debt/replay/author/response_debt_audit.json) 与[原冻结报告](../../tools/evidence/response-debt/original/security/response_debt_audit.json) **逐字节相同**；[stdout](../../tools/evidence/response-debt/replay/author/stdout.txt)也保留。有限标量循环不施加全历史SPE激励，不能从这些计数推出一般SPE满足条件。

## 独审程序：不同标量域和八客户完整策略

原独审代码也只使用标准库，既不导入作者审计，也不导入规范模型或均衡生成器。其3388个标量条目为：b=0,…,3，两负载各0,…,5，两会员指示0/1，查询概率j/8（j=1,…,7），仍排除选中负载零；逐项核恒等式，并在振幅至多一时核 $D\ge F$。

代码另外显式写八客户四主题及回复 `[2,3,3,2]`，直接算四个末位历史的16个收益表项，断言规定回复是**唯一**最佳；根四收益中规定B达到最大，根B/C平局保留。它计算全部主题对的覆盖最大值并核W=OPT=8，再逐客户直接合计 $D=23/8,F=37/24,D-F=4/3$，并单独核客户x的 $D_x=1/8,F_x=1/6$。

本轮实际原字节复制并运行，exit0；[新保存完整输出](../../tools/evidence/response-debt/replay/review/output.json)含3388计数、全部末位表、四根收益、W、OPT、D、F、D−F。六源中没有另一份冻结独审JSON，不将这份新输出说成旧报告。该有限反例的完整数学及“条件非必要”含义见反例对象。

## 本轮新增的固定分支对照

[check_response_witnesses.py](../../tools/evidence/response-debt/check_response_witnesses.py)是本轮新写的标准库Fraction检查，不导入原作者、独审、规范solver或已完成银行控制器实现。它实际运行一次，输出 [response-witnesses.json](../../tools/evidence/response-debt/response-witnesses.json)，分两个范围：

* 34客户既有SPE中一名mask29客户：只核两个已知真实根分支、$J=1/48$ 与 $D_x-F_x=-1/60$；不再次认证34客户完整树。
* 已证明m=4银行控制器：显式重构十二根行动的BASE真实完整分支，从十名不同单位客户算全部负载和根收益。保存十二分支以及每名客户的全部指标，核均匀p下 $F=383/280,u=D=4/3,F-u=29/840$，归一化债务同为29/840，并核已证公式代入 $t_5=\delta_5=19/14$。

后者是**本批新精确计算**，不是原六源已经写出的数值，也不是重跑旧四人全树。其完整SPE及自由分数最优值依赖[已完成一般银行族](../反例/笛卡尔银行目录的逐人分数门槛反族--反例.md)的解析证明；本轮已全文比较该对象和其原独立控制器代码。本脚本中的十二分支不能单独代替离轨模式的证明，反例正文另复述了本参数的全部模式激励。
