# 两剩余人完整终局推送：任意查询分布的精确正面式

2026-10-21，Boss10/induction个人推导；root逐项重构及独立研究员盲审通过，见同actor的`independent_pushforward/two_player_pushforward_review.md`。精确身份：**B10-TWO-PLAYER-INTEGER-PUSH-SHARP-v1**。一般Q-CAG-HALF仍OPEN。这里证明任意合法背景、恰两名剩余玩家的一个局部推送式，不声称一般剩余人数已闭合，也不声称新颖性或外审。

## 定义与量词

采用CAG-MODEL。固定任意有序前缀，客户背景负载为整数`b_x>=0`（证明对实数非负背景也成立）。令`rho(B)`是在该前缀后，首位选合法主题`B`时，给定完整纯SPE规定的末位最佳回复。它可任意依赖完整有序前缀及平局。

任取目录上的概率分布`p`。取`B~p`，令`R=rho(B)`；取`A~p`独立于`(B,R)`。设

    D = E_B sum_(x in B) 1/(b_x+1_B(x)+1_R(x)),
    C = E_(B,A) sum_(x in A) 1/(b_x+1_B(x)+1_R(x)+1).

`D`是首位混合查询后跟随原真实末回复的平均收益。`C`把两个真实末端主题都当作静态竞争槽，再给独立查询`A`加一名提供者。

结论是更强的定量不等式

    D-C >= sum_x p_x^2/((b_x+2)(b_x+3)) >=0,             (1)

其中`p_x=Pr(x in B)`。主题重复、空主题、零客户及全部末位平局均包括在内。

## 证明

令`q_x=Pr(x in R)`、`j_x=Pr(x in B intersect R)`，以及

    w_x = 1/((b_x+1)(b_x+2)).

二元membership直接给

    D_x = p_x/(b_x+1) - w_x j_x,

    C_x = p_x [1/(b_x+1) - w_x(p_x+q_x)
                         + 2w_x j_x/(b_x+3)].

因此

    D-C = sum_x w_x[p_x^2+p_x q_x-j_x
                              -2p_x j_x/(b_x+3)].       (2)

现在另取`R'`，使它与`B`独立，且边际分布恰为`R`的边际分布。对每个真实首行动`B`，末位最佳回复条件允许与分布`law(R')`平均比较：

    U_b(R,B) >= E_(R') U_b(R',B).

再对`B~p`平均。由

    U_b(X,Y) = sum_(x in X)1/(b_x+1)
               - sum_(x in X intersect Y)w_x

可知`R`与`R'`的裸值项完全抵消，从而末位BR平均slack恰为

    L = sum_x w_x(p_x q_x-j_x) >=0.                    (3)

把(3)代入(2)，并用`0<=j_x<=p_x`，得到精确非负分解

    D-C = L + sum_x w_x p_x[p_x-2j_x/(b_x+3)]
        = L + sum_x p_x^2/((b_x+2)(b_x+3))
            + sum_x 2w_x p_x(p_x-j_x)/(b_x+3).

全部项非负，证明(1)。这只用了真实末位最佳回复；没有要求首位当前处于最优行动，也没有冻结任何回复。

## 等价的确定性两分支式

上述平均证明也有一个不含概率的两分支版本。取任意两个首主题`A,T`；令`R=rho(A),S=rho(T)`，两个终局分别为`(A,R),(T,S)`。定义交叉插入值`G_X(Y,Z)=sum_(x in X)1/(b_x+1_Y(x)+1_Z(x)+1)`。则

    U_b(A,R)+U_b(T,S)-G_T(A,R)-G_A(T,S)
      = [U_b(R,A)-U_b(S,A)]
        +[U_b(S,T)-U_b(R,T)]
        +sum_(x in A intersect T) {
          1/[(b_x+1+r_x)(b_x+2+r_x)]
           +1/[(b_x+1+s_x)(b_x+2+s_x)] } >=0.          (4)

这里`r_x=1_R(x),s_x=1_S(x)`。前两个方括号分别是两条真实末位BR比较，均非负。恒等式逐客户只需区分首主题membership`00,10,01,11`：前两项对`10`给`w(s-r)`、对`01`给`w(r-s)`，恰好覆盖交叉差；`11`剩下显示的正曲率项。因此式(4)允许任意两条真实分支上的不同平局选择，且不是把回复跨节点搬成最佳回复。

独立取`A,T~p`并对(4)平均，再除二，正好得到上面的分解。式(4)可作为两剩余人响应图的确定性局部接口。representation已发现三剩余人下相应两分支式失败；不能外推。

## 余量锐性

独立盲审给出逐参数等号族：只有一名客户`x`，共同目录为`{empty,{x}}`，背景为任意`b>=0`，末位在两种首行动之后都选择`{x}`。这是末位最佳回复。令首查询以概率`t`选`{x}`、以概率`1-t`选空主题。于是`p=t,q=1,j=t`，上面的`L`及末项都恰为零，故

    D-C = t^2/((b+2)(b+3)).

因此(1)在每个非负背景与每个`t in[0,1]`均有等号，统一余量不能提高。

## 对当前首位的含义及一般缺口

若当前首位也遵循给定SPE，实际收益`u`满足`u>=D`，因为对每个合法主题的真实偏离收益均不超过`u`。所以完整末端推送背景`(B,rho(B))`给出对同一`p`的静态插入期望至多`u`，甚至有上述显式曲率余量。

若相同推送式对任意`r`名剩余玩家成立，则选择extra-one安全值的最优查询分布会给每位实际玩家`u_i>=v_(m+1)(0)>=OPT_m/(2m)`，从而推出主目标。但`r=3`的强式`D>=C`已有representation研究员构造完整纯SPE反例，并缩为既有34客户六主题实例加一个空主题（`representation/terminal_pushforward_34_D_lt_C_exact.json`，57有序历史342非自身偏离全部精确通过）。取`p(X2)=1/10,p(empty)=9/10`；空首后终局为`(empty,0,1)`，其独立X2插入值`32/3`；X2首后终局`(2,3,4)`，首位收益`29/3`，自身插入值`13/2`。因此

    D=29/30, C=41/40, D-C=-7/120,

而根实际最大收益`u=29/3`，所以`u-C=1037/120>0`。该例仍满足更弱的`C<=u`，并未反驳extra-one或half。原较大不同反例`representation/terminal_pushforward_D_lt_C_exact.json`也保留其独立发现身份。

这也解释一般归纳义务：必须保留根真实激励松弛`u-D`来支付多玩家后继相关债务，不能无条件推广(3)为“后继组合对首主题反相关”，因为后继组合未必共同最大化一个目标。本文只闭合`r=2`；一般`C<=u`仍OPEN。

同目录先前资产已提出一般extra-one与**分数期望负载**的完整终局推送候选（例如`R-51ca8.../security/extra_mass_interface.md`、`R-5c4f.../security/extra_one_response_debt.md`）；其静态查询值是`F=sum_x p_x/(b_x+1+E c_x)`。本文的`C=E sum_x p_x/(b_x+1+c_x)`是更强的真正整数背景分布，Jensen给`C>=F`。本文不把extra-one候选本身计作新对象；旧文的r<=2门槛推论也不包含这里的任意`p`精确余量恒等式。
