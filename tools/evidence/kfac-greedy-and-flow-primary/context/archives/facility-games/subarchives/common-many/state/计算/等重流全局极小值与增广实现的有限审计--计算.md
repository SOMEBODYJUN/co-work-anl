# 等重流全局极小值与增广实现的有限审计

## 运行域和实际结果

本对象对应 [current_original_oracle_run.json](../../tools/evidence/equal-light-flow-audit/current_original_oracle_run.json) 的一次原版运行。程序全文读取后在九文件固定树上运行，seed 为 `20261007`，Python 3.12，结果 `all_passed`。它枚举所有原始合法分配，再在全局最小解中逐个检查盒约束、(H) 约束和原菜单 NE；不是只检查构造器返回的一条路径。

有限结果为：5242 个 instances、14995 个合法 assignments、5720 个全局 minimizers、20066 个 minimizer 上的原选项检查、12280 次整数增广、362 个有多个全局最小解的实例、1 个多次反向 reroute fixture 和32个非法输入拒绝。网格涵盖空客户、(m=1,2,3) 的小容量表及所有非空菜单组合；随机部分120例，另有负 base、ties、duplicates/order、超大二进制 (q)、大分母和多次反向 rerouting 特殊输入。

## 数学责任

审计的核心量词是“每一个全局最小解”：优化域不预先套用 box 或 (H) 过滤，然后对每个最小解检查所有原菜单选项。这支持当前等重接口在列明有限输入上的实现回归，包括负 base、平局和重复/有序菜单的边界。增广流部分使用整数容量和精确整数成本；记录的12280次是该有限运行的执行计数。

它不证明一般不等重权的多项式时间，也不把等重子类的有限通过改写成所有实例的终止或复杂度定理。历史 pro report 只作为来源身份和比较材料；未取得 pasted source ZIP，未声称外部审查或首次发现。第10批 greedy-box 报告字段适配与本对象分开，本审计没有运行适配版。
