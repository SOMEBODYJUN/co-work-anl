# 固定贪心均衡的坏选择与静止超帽边界

## 共同约定及被限制的量词

[原模型](../定义/共同目录任意设施数模型--定义.md)取正整数原子，固定规范贪心占用后，客户站点纯选择并在站内设施间独立均匀。外部成本比较(W_s−w_i)/q_s与W_t/q_t，实际条件成本两侧再加同一w_i。以下相互不同：原当前站点不能逐站装箱、全局受帽纯初态不存在、某选定在轨NE没有因子二续局、某个选择器偏选坏NE。均不否定同一贪心布局存在另一个安全盒NE或原游戏因子二定理。

## 静止站冻结不能装箱

k8，站序A,E,B,C,D，客户(20,A),(8,AB),(24,BE),(20,B),(10,AC),(30,C),(13,BD),(67,D),(20,E)。贪心D80,B52,C40,D40,D80/3,B26,A20,E20，q=(1,1,2,1,3)、γ20、原总重(20,20,52,40,80)。依序8:B→A、10:C→A、13:D→B、8:A→B、24:B→E，实际成本分别30>28、40>38、106/3>35、38>73/2、89/2>44，严格到NE总重(30,44,41,30,67)。共享者的比较为8+33/2≤8+30、24+20≤24+41/2、10+20≤10+30、13+14≤13+67/3。

B一家在轨a=41/2，移到A时B存续。若把E当前客户冻结在那里，20+24=44>2a=41，且两原子都≤41，不能作普通帽箱或孤立巨原子。这只否定“修复在轨后冻结当前站点、逐站用旧装箱”的接口；24仍可重分B。

再加空站G（D之后），把24选项改BEG，加20/G私有，贪心及严格路径不变、G未占。B→G后三个私有20在B,E,G，24必须与其中之一合箱，所以**任何可行纯赋值**都有非巨原子普通负载≥44>41。跨站重分也不能恢复旧全局帽；67可孤立不影响三站下界。全局普通帽最小恰44。然而纯NE可使偏离者G仅20：A30,E44,B28,C30,D(67,13,0),G20。24在E的44与G44平局、优于B52；8在B28优于A38；10在A30优于C40；13与67在D独占分别13和67，换空D只平局。故无需全局普通家都≤2a，也能保护指定偏离者；[冻结超载定理](../定理/冻结静止超载的偏离者受帽补全--定理.md)后来精确补足这种接口，不把旧失败升级成不可稳定。

## 任意严格修复顺序可到无法因子二支撑的NE

k8，站序A,E,B,C,D,G，十客户
\[
(80,A),(32,AB),(96,BEG),(81,B),(40,AC),
(120,C),(52,BD),(268,D),(82,E),(80,G).
\]
贪心D320,B209,C160,D160,D320/3,B209/2,E82,A80（中间C/D分数同为160，依站序C先），q=(1,1,2,1,3,0)、γ80、原总重(80,82,209,160,320,0)。严格修复32:B→A、40:C→A、52:D→B、32:A→B、96:B→E，实际成本241/2>112、160>152、424/3>281/2、152>293/2、357/2>178。终(120,178,165,120,268,0)是NE；32,96,40,52当前与备选成本依次197/2≤152、178<357/2、120<160、217/2<424/3。

B一家a=165/2移G后，B/E/G各一家、私有81/82/80。96在G的成本**恒为**176，B/E分别至少177/178，无论其他客户怎样独立混合都严格选G，且仅96与私有80能去G。故每个mixed NE偏离收益176，比例32/15>2。任何离轨选择无法救这个在轨NE。

同一占用只先移动40:C→A即得好NE(120,82,209,120,320,0)：共享32/96/40/52分别留B/B/A/D，成本241/2≤152、305/2≤178、120≤160、424/3≤313/2，四原预算均成立。故坏顺序不等于所有NE都坏。

固定布局对**所有合法站纯赋值**求升序收益字典序最大，也唯一选坏NE：若96在B，E仅82；要最小收益>82，96必须E；否则B最多81+52或81+32，若32或52不在B，每家≤133/2或113/2；同时40须A否则A80。于是唯一候选就是坏NE，最小坐标165/2>82。此反例不涉及跨布局的全局字典序选择。

## 固定布局全局客户势极小值亦可能坏

另一输入k8同站序，十客户
\[
(200,A),(128,AB),(231,BEG),(240,B),(68,AC),
(330,C),(60,BD),(740,D),(200,E),(199,G).
\]
贪心D800,B599,D400,C398,B599/2,D800/3,A200,E200（最后依A/E站序），γ200、q同前。四共享客户记X128,Y231,Z68,T60。

| NE的X,Y,Z,T站点 | 总重A,E,B,C,D | 精确势P |
| --- | --- | ---: |
| B,B,A,D | 268,200,599,330,800 | 86264 |
| B,E,A,B | 268,431,428,330,740 | 86200 |

这两者穷尽NE：Y=E要求W_B/2≥200，强制X=T=B，Z必须A（否则330>A200）；Y=B且X=B时Z必须A，随后T若B外部599/2>740/3，故T=D；Y=B且X=A时，Z若C会从330改A328，Z=A时X外部268而B负载至多531/2<268，也不稳。两候选的原NE比较逐项为X:471/2≤268及150≤268，Y:184≤200及200≤214，Z:200≤330，T:740/3≤599/2及184≤740/3。

势P=Σ_s(W_s²−Σ_(i在s)w_i²)/(2q_s)，客户移动变化w_i[W_t/q_t−(W_s−w_i)/q_s]。因此全局极小点必为NE，配合穷尽分类和严格势差，坏NE是**唯一全部赋值全局极小者**，不靠“只枚举NE”假设。坏B一家a214移G后，231在G成本430、E≥431、B≥471，所以每个mixed NE偏离收益430，比例215/107>2。好NE各站全盒，G新覆盖199≤γ，唯一非零单源孤儿A→C满足330+68≤2·268，四预算成立。坏态也唯一固定布局字典序最大：Y=B时E200；要最小>200就强制Y=E,X=T=B,Z=A，得214。

这与[精确势最小值强NP困难](../归约/全局均衡选择的精确优化困难与局部搜索上界--归约.md)是不同问题：即使有精确优化oracle，这里其最优点也不安全；困难归约则限制计算最优值。原潜在/任意顺序程序此前批次已完整比较，本批不重跑；仅本批最重规则变体作一次新实跑。完整源路径、原件和层级见[六套证据](../计算/贪心选择器六套原审计的精确复现--计算.md)。
