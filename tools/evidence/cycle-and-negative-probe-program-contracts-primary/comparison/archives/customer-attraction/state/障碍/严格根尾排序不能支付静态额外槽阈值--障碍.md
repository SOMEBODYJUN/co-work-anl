# 严格根尾排序不能支付静态额外槽阈值

5899B阈值原稿和3315B入口完整实读。三槽环首先由mixed_menus给客户定义，本分支未读其文本/发现码先重构；无界奇数槽由root提出、本分支核算。这是原合作与读序，非本次新blind/外审/新颖性。反的是不保尾部真实SPE的形式菜单桥，不能扩为真实extra-one、聚合安全值或half反例。

## 真安全值与被丢掉的条件

共同有限目录S、合法背景b，静态安全值
\[
 v_n(b)=\min_{Q\in\Delta(S^{n-1})}\max_{T\in S}
 E_{q\sim Q}\sum_{x\in T}\frac1{b_x+1+c_q(x)}.
\]
竞争分布Q先定且不观察query，槽允许重复/相关。被攻击的菜单条件只给每根A一份r槽L_A，首槽A、根收益≤u、**每个**尾槽收益>u。没有要求这些叶来自完整SPE或满足末位BR。企图据此推v_(r+1)≤u为假；固定增加任意人数无关槽数，乃至放一个人数无关乘数，也不能修复。

## 环目录的原始/对偶精确式

取整数k≥7，客户e_i各一位、题A_i={e_(i−1),e_i}。r3、背景0，每根i菜单(A_i,A_(i−1),A_(i+1))给根1、两尾3/2，严格排序无需平局。对任意n≥2且k≥2(n−1)，同环有
\[
 \boxed{v_n(0)=2-2(n-1)/k}.\tag{1}
\]
这里仍在环菜单域k≥7内；n指含查询的静态总槽数，不是实际r。

uniform query每客户边际2/k，任意n−1竞争题给Σc_x=2(n−1)。整数c≥0时
\[
 \frac1{1+c}-1+\frac c2=\frac{c(c-1)}{2(c+1)}\ge0,
\]
故query平均≥(2/k)[k−(n−1)]。反向取n−1不交题A₀,A₂,…,A_(2n−4)的均匀环旋转：每客户以2(n−1)/k概率竞争负载1，否则0，每个纯query都同价2−2(n−1)/k。Q不依query，给合法匹配上界，证明(1)而非有限采样。

n4/k7时v4=8/7>u1。任意固定整数s≥0，取n=3+s、k>2(n−1)且k≥7，同一三槽菜单仍严格排序而v_(3+s)>1。固定n而k→∞，v_n/u→2；这个固定三槽族只给趋二损失，不由此单独否定所有常数。

## 无界奇数槽排除统一乘数

对每个h≥1，r=2h+1，同根菜单为根A_i、h次左邻A_(i−1)、h次右邻A_(i+1)。根两客户各负载h+1，尾一客户与h人共享、另一与h人加根共享，因此
\[
 u_h=2/(h+1),\quad u_{tail}=1/h+1/(h+1)
 =u_h+1/[h(h+1)]>u_h.
\]
任意n≥2、k≥max{7,2(n−1)}，由(1)
\[
 v_n/u_h=(h+1)(1-(n-1)/k)\longrightarrow h+1=(r+1)/2.
\]
取n=r+1、k=(h+1)(2h+1)+1，恰有v_n/u_h=h+1/k>h。因此不存在人数无关C使所有这种弱排序菜单都满足v_(r+1)≤C u；不必声称偶数r也有同构族。

这始终是**弱排序**，不是“所有尾≥t=v_(r+1)”的原最小坏例(R)。[准确R域审查](../审查/最小剩余人数的安全值嵌入与环菜单排序边界--审查.md)已说明三槽h1时完整R只7≤k≤12；无界h族未保该强门槛，不能据它推翻真实最小人数归约。

全部菜单均非SPE。末位右邻得1/h+1/(h+1)≤3/2，改A_(i+3)与整个此前根/邻题覆盖不交，得2。h1也同样3/2→2。重复邻题没有补更深真实最优性；形式叶排序/静态对偶无法替代缺失IC。

## 入口的负载候选与两个旧探针

原入口先提OPT_m≤F(c)=Σ_(c>0)(2−1/(c+1))。这是已知[完整终局税候选](../资源/完整终局税候选的策略锥浮点反例搜索合同--资源.md)，W≤F<2W（W0单列），成立则half；无拥挤F=3W/2。旧[存在型碰撞自由族](../反例/三人碰撞自由族福利障碍--反例.md)W=2k+2/OPT=3k+2→3/2只迫f(1)≥3/2，不否定此系数或给充分性。原coordinator只说在实际C⊆O的子情形与signed-harmonic重合，这是其历史，不把终局税F(c)偷换成依最优元组d的调和F(c,d)/query净预算。

1938B `attack_load_candidate.py`也已全文读仅context：seed2026102307，计划(m,k,cases)=(3,4,500),(4,4,500),(5,5,300),(6,6,80),(5,7,80)，共1460。每生成实例用规范Fraction集合值solver检查**全部SPE终局计数**，但每完成一实例后有52秒墙钟提前退出；`tested`在全例检查后加1，命中counter时不含当前失败例。原README称1460无反例，本批无DONE/TIME原stdout，故只保其原声称与计划范围，不能由源码外循环认已完成1460。它不是R105那154个随机固定策略锥，亦不执行新negative。
