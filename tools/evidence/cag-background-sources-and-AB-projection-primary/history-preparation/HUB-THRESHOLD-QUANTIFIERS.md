# hub 原θ₂与完整SPE门槛的精确量词准备

原hub一般参数中，假设指定完整σ的区间 (M−d)/2 ≤ P ≤ U_B=M−3d/2+e/2。记D=P+d/2、L_H=M−d/2。

- 背景H后全部末查询最大值为D：各P_i收益D，H自身M/2≤D。
- 背景任P_i后全部末查询最大值为L_H：原上界U_B保证H不劣别P_j及重复P_i。
- 上界又给P≤M−d，因此D≤L_H。

故通常的纯最坏背景值 θ₂=min_一个阻挡 max_查询 恰D。这使原有限例的D=θ₂=83/2完全准确，不能因误认θ₂是动态最小首收益而报源错误。

若下界严格，即P>(M−d)/2，H后所有末位BR均为某P_i、绝不会是H。无论平局怎样，根强制H的收益都L_H。因此每个完整SPE的实际根收益至少L_H；原明示完整σ达到L_H，所以动态最低首收益M₂=L_H。偶数无限族和n8/a1/P24有限例均在严格域，分别M₂=3M/4、105/2。

在下界等号D=M/2时，H后H本身也BR，可构造根H后H的完整σ，任Pi后H（原区间已保证BR），根各真偏离Pi只D而遵循H也D。故动态M₂=D=M/2，而原选择H后P₁的另一完整σ根收益仍L_H。该边界说明即便同一个输入、同一个θ₂，真实有序平局仍影响具体收益；静态纯值、所有σ最低、给定σ实际收益三个量不能合并。
