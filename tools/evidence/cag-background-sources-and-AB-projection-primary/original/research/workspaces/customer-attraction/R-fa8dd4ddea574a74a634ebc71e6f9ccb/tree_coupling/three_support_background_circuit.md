# 第三主题固定占位时的七收益正项回路

研究备份，2026-10-21。CAG-MODEL、共同目录、单位提供者；以下是逐客户恒等式，不需要SPE。与双支持回路不同，第三主题引入依兴趣类型变化的背景负载，必须有新的补偿项。一般half仍OPEN；本文无外审或全球新颖性声明。

## 1. 任意人数的正项身份

取不同标签a,b,c，正整数s,k，提供者总数m=3s+k，并记D=3s+2k。令

\[
q=2s\,a+s\,b+k\,c,\quad
r=s\,a+2s\,b+k\,c,\quad
t=3s\,b+k\,c.
\]

U_a(q)仍指选择a的**一名**提供者的收益，不是该主题全部提供者总收益。则有

\[
\boxed{\begin{aligned}
2sD\,U_a(q)+2sD\,U_b(r)+k(k+s)\,U_c(q)
={}&sD\,U_a(r)+3sD\,U_b(t)\\
&+ks\,U_c(r)+k^2\,U_c(t).
\end{aligned}}
\tag{1}
\]

两侧所有系数严格正，全部终局总人数相同为m。身份对每个兴趣类型B逐点成立，故对任意有符号共同客户权重也成立。其他未出现在a,b,c中的目录标签不影响身份。

**证明。** 按客户兴趣B与{a,b,c}的交集分类。空交时所有项零。其余七种模式中，式(1)两侧的共同值如下；每格均直接把 U_x(v)=1_(x∈B)/v(B) 代入并通分得到。

| 兴趣交集 | 左右共同值 |
| --- | --- |
| {a} | D |
| {b} | D |
| {c} | k+s |
| {a,b} | 4D/3 |
| {a,c} | 3s+k |
| {b,c} | 3s+k+ks/(2s+k) |
| {a,b,c} | [4sD+k(k+s)]/(3s+k) |

例如{a,c}模式的左边为 [2sD+k(k+s)]/(2s+k)=3s+k，右边为 [sD+ks]/(s+k)+k=3s+k。{b,c}模式左边为 2sD/(2s+k)+k，右边为 [3sD+k²]/(3s+k)+ks/(2s+k)，两者均等于表格值。证毕。

最小四人实例s=k=1：

\[
\begin{aligned}
10U_a(2a+b+c)+10U_b(a+2b+c)+2U_c(2a+b+c)
={}&5U_a(a+2b+c)+15U_b(3b+c)\\
&+U_c(a+2b+c)+U_c(3b+c).
\end{aligned}
\tag{2}
\]

## 2. 一般不等占位r,s,t的推广

本节一般系数由root与本分支独立解七模式得到；下面的三变量形式多项式检查已通过，未作一般福利支付声明。取r≥s≥1、t≥1，m=r+s+t、D=r+s+2t，并令

\[
q=(r,s,t),\quad q'=(s,r,t),\quad q^0=(0,r+s,t)
\]

依次对应主题a,b,c。则

\[
\begin{aligned}
rsD\,U_a(q)+r(r-s)D\,U_b(q')+st(s+t)\,U_c(q)
={}&s^2D\,U_a(q')+(r^2-s^2)D\,U_b(q^0)\\
&+t[s^2+(2s-r)t]\,U_c(q')+(r-s)t^2\,U_c(q^0).
\end{aligned}
\tag{3}
\]

除Uc(q')系数ζ=t[s²+(2s−r)t]外，其余系数非负。ζ≥0恰当且仅当(r−2s)t≤s²；若ζ<0，把该项移到左边即可得到全非负的正项身份。r=s时部分系数为零，q=q'，身份退化；r>s时其余六项系数严格正。

**独立推导。** 先暂不看兴趣含c的客户。无c的三个非空兴趣模式决定前四个a,b收益项的系数之比为rs:r(r−s):−s²:−(r+s)(r−s)。设尚未乘D时三个c收益项在左边的系数为A,B,G。c-only模式要求G=−A−B；ac与bc模式要求

\[
\begin{aligned}
Ar(s+t)+Bs(r+t)&=t^2s(r-s),\\
Ar(r+t)+Bs(s+t)&=ts(r-s)(s+t).
\end{aligned}
\]

当r>s时，相减并除以r−s给Ar−Bs=ts²，由此解得

\[
A=\frac{ts(s+t)}D,\quad
B=\frac{t[(r-2s)t-s^2]}D,\quad
G=-\frac{t^2(r-s)}D.
\]

abc模式因全部分母都为m，其系数和自动为零。乘D即(3)。r=s时直接代入即可验证退化身份。r=2s后除以s，令t=k，得到(1)。

## 3. 为什么二支持回路不能原系数直接提升

在无c占位且s=1时，已有

\[
2U_a(2a+b)+2U_b(a+2b)=U_a(a+2b)+3U_b(3b).
\]

若在四个终局里统一加入k个c提供者，保留原系数，则兴趣类型{a,c}要求

\[
\frac2{2+k}=\frac1{1+k},
\]

对每个k>0均不成立。故不能把二支持身份视作对任意固定背景封闭。式(1)用c的三个真实收益顶点补偿这种变化，代价是系数改变且出现额外支付项。

这不是不能提升的总体障碍：式(1)已经给一个正确提升。它也不是一般背景的恒等式：若背景由多个不同主题构成，每客户看到的背景人数可能取多个值，不能未经证明把它们合并为一个c。
