# 精确实际分数税支付桥也会失败：36客户完整SPE

2026-10-21。个人新反例；三份独立定义级程序审计通过，其中credible先不读发现证明或packet，独立重建集合值BI及完整续局自动机。一般半覆盖、真正强/弱聚合安全值均未被否定。此处只否定下列辅助支付桥，不声称最小性或世界新颖性。

## 1. 被否定的命题

有限单位客户、共同有限非空主题目录，m名单位提供者依次观察完整有序历史选一个主题，重复和任意历史平局均允许。终局客户负载c_x，玩家收益为其主题内1/c_x之和，福利W为覆盖客户数。

定义

\[
\alpha=(m-1)/m,\quad g(T)=\sum_{x\in T}\frac1{1+\alpha c_x},\quad
M=\max_Tg(T),\quad G=\sum_{x:c_x>0}\frac1{1+\alpha c_x}.
\]

已有逐客户代数 `OPT_m≤mM+W−G` 对任意终局成立。此处否定的候选为每个完整纯SPE均满足 `mM≤W+G`，以及更强逐人候选 `u_i≥M−G/m`。

## 2. 输入与在轨终局

13名提供者面对六个共同主题A,B,T,D,E,P。单位客户兴趣类型如下；每个重数代表不同单位客户。

| 兴趣主题 | 单位客户数 |
| --- | ---: |
| A | 2 |
| B | 2 |
| T | 1 |
| T,D | 1 |
| T,E | 1 |
| A,D,E | 3 |
| B,D,E | 1 |
| P | 25 |

总计36客户，所有六覆盖两两不同。前七类型原封不动采用已有 `coverage_opportunity_failure` 的11客户输入；新机制是增加独立的25客户主题P及十名提供者，不能将旧完整策略直接视为新模型策略。

下面给出的完整策略实际路径为

\[
(P,P,P,P,P,P,P,P,P,P,A,A,B).
\]

每个P玩家得25/10=5/2，每个A玩家得5/2，B玩家得3。因此 `W=33`。选择A,B,T,P覆盖全部36客户，重复主题补足13个选择，故 `OPT_13=36`。

## 3. 完整历史策略的有限无环自动机证书

证书 `refined_tax_k10_packet.json.gz` 保存根节点与27243个节点。每个节点记录实际前缀主题计数。决策节点还记录指定行动a及六个观察行动b各自对应的后继节点；终端节点恰位于深度13。

纯策略的定义是：从根出发，对已经观察到的每个历史行动逐一沿相应边转移，在所得节点选其指定行动。这完全定义每个有序历史上的行动。不同等计数历史允许到达不同节点；证书事实上有27243节点而只有27132个不同计数，所以没有把完整历史模型偷换成计数策略模型。

证明其完整性只需两个归纳不变量：根计数为零；每个观察行动b的后继计数恰增加一次b。每个非终端节点有全部六条边，且每边深度增加一，故任意长度≤13的有序历史都有且仅有一个自动机运行，恰在长度13终止。所有节点均可从根达到。

令z(v)为从节点v不断遵从指定行动得到的终局。审计从终端逆序计算全部z(v)，并对每个决策节点v及每个行动b精确验证

\[
u_{a(v)}(z(v))\ge u_b(z(\operatorname{child}(v,b))).
\]

这是该节点实际当前玩家对沿原策略真实续局的全部行动比较；不会冻结后继玩家。任意有序历史到达已核验节点，故上述比较证明全部子博弈最优性，即完整纯SPE。

独立标准库审计 `audit_refined_tax_packet.py` 展开36个不同单位客户，以 `lcm(1,…,13)` 作为收益公分母，用整数精确验证全部112050项比较。它不调用规范BI、证书构造器或外部LP；只读取输入及自动机。最小SPE差为零，所有比较非负。

构造器采用规范集合值BI找到目标终局，然后在 `(前缀计数,当前所欲终局)` 状态分别选择可行行动和离轨惩罚续局，最终导出上述可独立审计自动机。其发现来源不承担最终核验：完整SPE结论直接来自封闭自动机及逐节点不等式。

## 4. 精确税违反

在实际终局，旧A客户5人负载2，旧B客户3人负载1，旧T客户3人负载0，P客户25人负载10。m=13、alpha=12/13，六主题查询值依次为

\[
(g(A),g(B),g(T),g(D),g(E),g(P))
=\left(\frac{65}{37},\frac{39}{25},3,\frac{2381}{925},\frac{2381}{925},\frac{325}{133}\right).
\]

所以M=3，而且

\[
G=\frac{65}{37}+\frac{39}{25}+\frac{325}{133}
=\frac{708669}{123025}.
\]

于是

\[
\boxed{13M-W-G=39-33-\frac{708669}{123025}
=\frac{29481}{123025}>0.}
\]

这个差已经由单一合法主题T给出，即13g(T)>W+G；无需对所有主题取最大后才出现失败。精确实际税桥严格失败。更强逐人候选对十二个5/2收益玩家均失败：

\[
M-\frac G{13}-\frac52=\frac{13999}{246050}>0.
\]

实际OPT/W=12/11，半覆盖有巨大正余额 `2W−OPT=30`。

## 5. 真正安全值仍被支付

真正静态安全值的对手组合不能观察所抽查询。这里固定合法12主题组合

\[
H=(A,B,T,P,P,P,P,P,P,P,P,P)=A,B,T,P^9.
\]

对应六个纯查询收益恰为

\[
\left(\frac52,\frac32,\frac32,\frac52,\frac52,\frac52\right).
\]

因此任意查询分布的该列期望都≤5/2，给 `v_13≤5/2`，从而

\[
W-13v_{13}\ge33-\frac{65}2=\frac12>0.
\]

所以本反例只能排除固定实际缩放背景及其精确税支付方式。另选静态背景、真正安全值聚合或直接真实分支覆盖证明仍保留。
