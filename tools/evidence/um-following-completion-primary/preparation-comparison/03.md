# 1. 完整束 collision floor

每变量组 x 有完整资源束 `B_x`，`|B_x|=K_x≥1`，资源碰撞度 `Δ`；根需求 q、颜色数 `c∈[1,q]`。给加权交图 `w_xy=|B_x∩B_y|`、`d_x=Σ_yw_xy≤(Δ−1)K_x`。同色加权边势每次改色严格下降，终态每点同色度≤`d_x/c`，势初值多项式于显式束规模，不按二进制巨大需求循环。

最大颜色类 A 至少 `ceil(q/c)` 组。对每资源 u 在 A 中的重数 `h_u`，暂给每关联 `(x,u)` 分数 `1/h_u`；Cauchy 得 `Σ_{u∈B_x}1/h_u≥K_x/[1+(Δ−1)/c]`。整数最大流/配额给每组 `floor(K_x c/(c+Δ−1))` 个互不复用资源，因此

`Λ_c = min( ceil(q/c)/q, min_x floor(K_x c/(c+Δ−1))/K_x )`

是完整束合同下的实际根树评分下界；若某配额为0，则 `Λ_c=0`、根单点是合法默认，不能给零配额叶免费终端。c=1、q、Δ=1、异质 K_x 均在公式域内。

平方池锐例 `q=Δ=t²`、全部束同为 t² 池时真实 `b*=1/t`；取 c=t+1 达到 `Λ_c=1/t`。若 `Δ→∞` 且 `K_min/√Δ→∞`，`c≈√Δ` 给 `liminf √Δ b≥1`。更直接地，若真实 `b*≤η<1`，单组树给 `q≥1/η`；`c=ceil(1/η)−1` 后得到 `η²Δ≥1` 的渐近必要式（需 `η→0` 且 `ηK_min→∞`）。这些是必要/存在性边界，不是 hardness 或 decoder。

锐例的容量上界依赖资源集恰为共同 t² 池、每标签完整邻域且无额外边；最终澄清明确这一点。若只写根 `1/c` 而忽略标签配额，平方池最优仅 `1/(t+1)`；带 `Λ_c` 的完整公式才 sharp。

# 2. 列表 agreement 度预算

对象 `UM-LIST-AGREEMENT-DEGREE-BUDGET-v1`：每右点至少两个不同左邻居，局部公共像和关联容量1。独立 Exact-first 先重构 ticket 贪心与整数流：给每左点列表/标签，固定已服务集 S 恰支付 2|S| 张 ticket；每个新 agreement 可使用邻居原像，重复原像先去重，二进制巨大 L 只截容量 d，不按 L 数值循环。分数流 `2/D` 合法条件是 `D≥2` 且 `L≥ceil(2d/D)`，整数流返回不同邻居的实际原像列表。

sharp map 使用左点私有符号；跨邻居只能经 0 相等，每个符号只支付一个右点 agreement，总列表预算至少 `2|B|`，不是某个 toy 图的实验猜阈值。对象域排除 `alpha=0`、低 L 空域、|B|=1、d=1；必要条件不自动给 soundness 充分性或源归约。最终 canonical 只采纳“满足本页对象域（包括两个不同邻居与局部公共像）”的措辞，未扩展为任意图。

# 3. 关系、实现和未解范围

两源都说明局部配额/列表预算可以给出精确组合界：collision floor 约束完整束共享资源的最小碰撞，list budget 约束逐右点 agreement 的总 ticket。它们的共同限制是：真实物理 decoder、跨层一致性和一般 UM source-to-instance 映射尚未提供。大资源平方必要式不能写成“碰撞即 NO”，列表 2|B| 上界不能写成“满足即可近似”。
