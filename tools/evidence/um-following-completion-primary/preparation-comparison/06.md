# 2. 极小超载星收缩与容量差

剪枝后的极小星必须保留全部邻域。对旧调度外放至少一条叶任务，得到 `min` 不超过其实际代价；任意新 `B` 调度取达到 `min` 的真实任务并把其余任务放回中心 `v`，负载界为
\[
load(B')\le \max(B,T).
\]
反向恢复不需要假设 `B\le T`；正向却不能把论证扩大到旧 `C>T`。每一次替换任务代表不交原任务叶集，逆序恢复时 `argmin` 机器已经存在，`children` 只展开一次，因而不重复任务或指数重建；每轮取 `max` 而非累加。`F\ge2`、无零项时至多 `m` 轮，朴素有理操作为 `O(m^2 n)`，位长不增。

这给出的是收缩/容量差对象的条件上界；来源没有由它直接推出一般 unrelated-machines 近似算法或复杂性结论。比值表达式必须显式限定 `OPT>0`，阈值取得及零实例约定是修补后正文的一部分。

# 3. 紧凑共享资源族与 GPC2

紧凑族中，全局容量 `k-1` 迫使一个中心接收 `X`；局部 `k` 个 `Y` 占用 `k` 个 `k+1` 槽，最多撤走一个 `Z`。上下界取自真实覆盖的所有调度，配置边际由实际支持重算，不能直接移用旧 SC 结论。

GPC2 对多 eligible 任务只需 pair 支撑集合不相交，不要求每个 pair 恰覆盖一项。`G-G/R-R` 用循环置换，`V-R/V-G` 用逐行逐列公式核验；其他 pair 的支持任务集合确实不交，乘积分解因此合法。来源没有假设所有 pair 能拼成一个全局分布，亦没有把局部 pair 证书升级为完整调度算法。

组合合同只需对每个接受阈值 `T` 使用 `S_T` 及逆恢复给出至多 `2T`，再取 inf；不需要猜测组合预处理对 `T` 单调。原族 `T<1` 时 `Y` 剪空，`T=1` 的两种规则都无起点，而 GPC2 证书可行。

# 4. q-profile 障碍与有限计算

若 `A` 调度含零任务或有正任务共机，则其正负载机器数至多 `q-1`；原调度在相应 `B` profile 仍可行而产生矛盾。因此删去一台外机后的 `A` 图有完整 matching，单任务邻域至少 2；两个邻域相交还可构造 `B` 可行分配。该证明覆盖非负/无限替代时间，但只针对 `q` 个普通任务和固定外机，不能排除带身份或辅助结构的算法。

规范单步审计用 seed `837210` 对 4,000 个采样矩阵得到 956 个适用星、3,972 个新调度提升（含 776 异长星和 563 个含零矩阵）；新增 5,000 采样/2 强制 nested 输入得到 122 条多步链、123 个 nested 步骤、83 个拒绝证书和 89,712 个最终调度逆序恢复。`k=2` 紧凑星的 82,944 个分配独立整数放大求得 `OPT=3/2`。

独立程序 seed `918273` 产生 1,095 个合法 fixture 并穷举每个 fixture 的全部分配：92 次收缩、369 个真实不可行拒绝、7,486 个最终分配逆提升，其中 7 个 nested 残余 fixture 和 8 个 nested 最终分配；该程序没有导入规范收缩/恢复核心。全 pair 审计 `k=3,…,12` 覆盖 50,179 个机器对、99,363 个显式联合项，另有 45,309 个 pair 以支持集合分离和精确乘积分解验证；q-profile 实际枚举 `q=2,…,8` 的 A/B profiles 与剪枝后原星分配，但不枚举全部替代矩阵。所有算术使用 Fraction/整数、无容差。有限证据不替代一般证明。

# 5. 第 7 节：多拟阵容量外包

第 7 节只审 `UM-KNAPSACK-MATROID-ENVELOPE-v1` 及规范正文第 7 节，没有重新扩大第 1–6 节。对象为 `I_1`：所有 `K` 的子集与单元素 `{h}`；固定 `k,p\ge1`，且先固定拟阵组，再对所有共同独立集取最大，最后对拟阵组取最小。正文没有把“存在一个好共同独立集”偷换成“全部共同独立集都好”。

唯一回路论证如下：任一回路都含 `h` 且不等于 `{h}`。若有不同极小回路 `C_1,C_2`，从 `C_1\setminus C_2` 取 `f`；`C_1-f` 含 `h`，任何包含它的独立集都遗漏 `f`。augmentation 与 `|K|=k`、`E` 依赖共同保证极大独立集大小为 `k`，故只能扩张成 `E-f`，进而包含 `C_2`，矛盾。有限性使唯一回路精确决定全部独立集。

忽略 free 拟阵后，`{h}\cup S` 共同独立等价于 `K\setminus S` 命中每个超边 `A_a`。所以最大含 `h` 权重为
\[
2-\tau/k,
\]
其中 `\tau` 是命中集最小大小，且 `\tau\le k`；不含 `h` 的最大值为 1，故总体为 `max(1,2-p/k)` 的相应下界。`q=min(p,k)` 个不同 parallel pair `{h,s_a}` 与其余 free 拟阵给出锐值 `1+(k-q)/k`；`p\ge k` 时交集正好为 `I_1`，`k=1` 由 `U_{1,2}` 覆盖。构造是 partition 拟阵且可线性表示，所以限制到线性可表示拟阵不改变最小值。

在 `0<\varepsilon<1` 下，`max(1,2-p/k)\le2-\varepsilon` 等价于 `p\ge\varepsilon k`，整数条件为 `p\ge\lceil\varepsilon k\rceil`。这是存在一组合格外包的数量门槛，不是任意拟阵组的充分条件。若要求每个共同独立集都直接恢复为机器 `v` 上的负载界，则 `\alpha\ge\max(1,2-p/k)`；只要求算法最后选一个共同独立集时，不能由该最坏共同集下界推出算法实际失败。原地集、完整保留真实可行集和全部 profile 恢复是接口前提；本节排除辅助元素/投影、基约束、强耦合、选择性保留以及拟阵数随 `k` 增长的外包。它没有升级为一般调度 gap、复杂性困难性或 `UM-TARGET-v1` 的否定。

来源提到标准 p-extendibility 性质；本节自行给出唯一回路和命中集证明，不依赖该文献补足缺口。有限复跑从规范路径枚举包含 `I_1` 的 family truth table，逐项检查空集、遗传与 augmentation，再枚举无序含重复拟阵组；范围 `k=1,…,4`、`p=1,…,k+1`，共 32,906 个 family truth table 与 20,881 个拟阵多重组，权重按 `1/k` 整数单位和 Fraction 计算，全部满足公式并通过反算。该复跑不证明无界参数命题，也未测试一般调度候选算法。
