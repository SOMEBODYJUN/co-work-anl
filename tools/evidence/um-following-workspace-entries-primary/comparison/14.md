# 2. 对象一：仿射互补负载与固定基数边界（ID `8088efef4cfbcec8c315`）

## 2.1 输入域和准确量词

源问题是一般最大最小分配：玩家集合 (P)，(|P|=m)；资源集合 (R)，每件资源至多给一个玩家；效用 (u_{ij}) 是非负有理数。为尝试编码“每位玩家恰取 (q) 件”，构造 (N=qm) 件资源（不足的部分可用对所有玩家可用的零效用 dummy 填齐），给定

[
 p_{ij}=B-\lambda u_{ij},\qquad 0\le u_{ij}\le U,\quad B>0,\quad B\ge\lambda U.
]

这里处理时间非负；(A_i) 表示分给机器/玩家 (i) 的资源集合。所有后续边界都针对这一具体接口的量词：(\rho>1)，且计数反例要求 (q\ge 1/(\rho-1))。源没有声称任何仿射编码、任意槽 gadget 或一般机器数输入都满足同一结论。

## 2.2 在显式等基数下的正确恒等式

若**额外已经保证**每台机器恰收 (q) 件资源，则

[
 L_i=\sum_{j\in A_i}(B-\lambda u_{ij})
     =qB-\lambda\sum_{j\in A_i}u_{ij},
]

所以

[
 C_{\max}=qB-\lambda\min_i\sum_{j\in A_i}u_{ij}.
\tag{A1}
]

因此在此附加等基数假设下，最小化 makespan 与最大化最小效用是精确的仿射反转。关键逻辑不是“仿射变换自动产生等基数”，而是先把等基数作为独立约束交给解码或选择器。若调度允许任意任务数，(L_i=qB-\lambda\sum u) 中的基线项是 (|A_i|B)，(A1) 不再成立。

## 2.3 无条件的计数溢出反例

令所有效用都相同 (u_{ij}=U)，并写 (p_0=B-\lambda U)。总资源数仍为 (N=qm)，故均匀分配的最优 makespan 为 (OPT=qp_0)。当 (m\ge2,q\ge2) 时，把 (q+1) 件资源给机器 1、(q-1) 件给机器 2，其余机器各 (q) 件，得到

[
 C_{\max}=(q+1)p_0.
]

只要 (q\ge1/(\rho-1))，即 (q+1\le\rho q)，便有 (C_{\max}\le\rho OPT)，但计数不平衡。(q=1) 的退化情形可用两台机器分别收 2 件和 0 件资源；仍是同一个 makespan 乘性反例。由此得到完整量词结论：对任意 (\rho>1) 及满足该 (q) 下界的 (q)，单独的乘性 makespan 界不能推出每机恰有 (q) 件。任何有效解码都必须另加过载限制、槽选择器或等价的非仿射结构。

该反例是接口的普遍失效，而不是 R\(\|\)Cmax 的硬度证明；它也不排除带独立非仿射选择器的另一种归约。

## 2.4 近二比率的参数冲突

若平衡 YES/NO 情形的每机最小效用分别为 (V_Y>V_N)，则平衡调度值为

[
 T_Y=qB-\lambda V_Y,qquad T_N=qB-\lambda V_N.
]

令 (a=\lambda V_Y/(qB))、(b=\lambda V_N/(qB))，则

[
 R=\frac{T_N}{T_Y}=\frac{1-b}{1-a}.
]

当 (b) 较小而 (R\) 要接近 2 时，(a) 必须至少接近 (1/2)，使效用项与基线 (qB) 同阶；这正是 (p_0=B-\lambda U) 变小、计数溢出相对代价仅约 (1/q) 的区域，因而第 2.3 节的溢出调度容易满足同一乘性界。反过来把 (B) 取得很大以抑制溢出，会使 (a) 变小，(R) 趋近 1。源的严格结论是接口参数冲突：

* 仅靠“仿射互补 + dummy 填充 + makespan 乘性近似”不能同时保证近二 gap 和自动等基数解码；
* 至少需要非仿射过载/槽选择器或不同的源编码；
* 这不是对所有可能仿射归约的普遍不可能定理，因为允许的 gadget 类尚未形式化。

## 2.5 `rho=1.9` 的裁剪失效见证

源给出两台机器、(q=2)、四件资源、

[
 U=\begin{pmatrix}1&1&1&1\\1&1&0&0\end{pmatrix},qquad B=1,\quad\lambda=0.4.
]

平衡分配（机器 1 取资源 3、4；机器 2 取资源 1、2）有 (OPT=1.2)。把资源 1、2、3 给机器 1，把资源 4 给机器 2，负载为 (1.8,1)，且 (1.8=1.5\,OPT<1.9\,OPT)。若事后按数量截成每机两件，机器 2 只能保留零效用资源（再补 dummy 或丢弃一件），源目标的最小效用降为 0，而原最优最小效用为 2。这个例子精确否定“先跑近二调度、再按数量裁剪”的黑盒恢复；它不声称一般调度近似比或复杂度结果。

## 2.6 后续用途与开放项

可安全复用的是 (A1) 的**条件接口**和第 2.3 节的**无条件计数反例**：今后任何仿射归约草案都必须显式验证等基数如何产生，并检查 (
ho) 与 (q) 的关系。近二 R\(\|\)Cmax 困难性若要成立，仍需真实整数 gap（YES (OPT\le T)，NO (OPT>(2-\varepsilon)T)）、多项式位长和完整解码；LP/configuration gap 不能替代这些义务。源未解决、也没有声称解决一般近二问题。

# 3. 对象二：近单位锚任务的分量缺额与全局联合舍入（ID `78b4b3116ebe9be9ccd3`）

## 3.1 固定身份输入与定理量词

给定显式非负二进制有理/∞ 的不相关机器矩阵 (P=(p_{ij}))、阈值 (T>0)，以及**固定且输入一开始就知道**的任务身份划分 (J=B\mathbin{\dot\cup}S)：(B) 是 anchors，(S) 是 tiny。给定有理 (\alpha\in[0,1/2))、(\beta\ge0)，令 (h=(1-\alpha)T)。要求：每个 anchor 的每条有限边都在 ([h,T])，每个 tiny 的每条有限边都不超过 (\beta T)，∞ 永远表示禁止端，不可用“大有限数”替换。

令 (G_B=(B,M,E_B)) 是 anchor 有限边资格图。对每个含 anchor 的连通分量 (c)，记机器数 (m_c)、anchor 数 (k_c)、缺额 (d_c=m_c-k_c)，并假设统一上界 (0\le d_c\le d_0)；分量数本身可以无界。tiny 的有限边可以跨组件，也可落到 anchor 图之外的机器。该模型的所有结论均以这些固定角色和结构为前提，不能把同一任务在不同机器上的混合角色事后改名来套定理。

## 3.2 全局联合 LP 与可靠失败语义

对每条 anchor 边设 (z_{ib}\ge0)，对每条 tiny 边设 (x_{ij}\ge0)，并定义

[
 y_i=\sum_b z_{ib},\qquad \ell_i=\sum_j p_{ij}x_{ij}.
]

使用一个覆盖全部 tiny、全部 anchor 和全部机器的联合有理 LP：

[
\begin{aligned}
&\sum_i z_{ib}=1 &&(b\in B),\\
&\sum_i x_{ij}=1 &&(j\in S),\\
&y_i\le1 &&(i\in M),\\
&\ell_i+h y_i\le T &&(i\in M),\\
&z,x\ge0.
\end{aligned}
]

若存在真实 (T)-可行调度，由于 (h>T/2)（正是 (\alpha<1/2) 的用途），一台机器不可能容纳两件 anchor；把调度投影为 0/1 的 (z,x) 即得 LP 可行点。于是 LP 不可行时 `FAIL` 必然推出 (OPT(P)>T)。这一步是 soundness，而不是说 LP 可行就已经有完整整数调度；后者要靠下面的匹配与舍入。

边界应保留：(T=0) 不可代入该比例证明，应单独检查零端；(B=\varnothing) 时退化为 tiny 的全局 LP+ST；(S=\varnothing) 时只需 anchor matching；空任务集输出零负载；每任务无有限边时应按相应输入结构/阈值分支判 FAIL 或标记不适用，而不把结构违例冒充定理结论。

源还给出一个有理 dual 失败证书。把覆盖等式改成不超过 1，最大化总覆盖质量 (F)，机器约束保留 (y_i\le1) 和 (ell_i+h y_i\le T)。若最优 (F<|J|)，存在 (a_j,v_i,w_i\ge0) 使

[
 a_b+v_i+h w_i\ge1\quad\text{(anchor edge)},qquad
 a_j+p_{ij}w_i\ge1\quad\text{(tiny edge)},
]

并且 dual 目标 (sum_j a_j+sum_i v_i+Tsum_i w_i<|J|)。逐边核验这样的有理证书即可排除完整 (T)-调度；强对偶依赖显式有界/可行的该 LP，不能把任意外部字段当证书。

## 3.3 严格低占位删机与 Hall 证明

在组件 (c) 中，anchor 流不会跨组件，故

[
\sum_{i\in M_c}y_i=k_c,qquad
\sum_{i\in M_c}(1-y_i)=d_c.
]

取 (t_c=1/(d_c+1))，删去

[
 D_c=\{i\in M_c:y_i<t_c\}.
]

当 (d_c\ge1) 时，每台被删机器的空余 (1-y_i>d_c/(d_c+1))，所以 (|D_c|\le d_c)，且

[
\sum_{i\in D_c}y_i<|D_c|/(d_c+1)\le d_c/(d_c+1)<1.
]

当 (d_c=0) 时 (D_c=\varnothing)，必须直接写成质量和 (0<1)，不可误写成 (0<0)。阈值是严格小于；(y_i=t_c) 的机器要保留。

删去 (D_c) 后若 anchor 无法饱和匹配，Hall 定理给出 (A\subseteq B_c) 使保留邻居数至多 (|A|-1)。原 fractional matching 对 (A) 的质量是 (|A|)，保留邻居每台至多承载 1，删机总质量严格小于 1，于是

[
 |A|\le |N(A)\setminus D_c|+\sum_{i\in D_c}y_i
    <(|A|-1)+1=|A|,
]

矛盾。故每个组件的全部 anchor 都能匹配到保留机器；不同组件机器不重叠，可以一次性联合 matching。匹配只需使用原资格边，不需复现 LP 的正支撑。

## 3.4 冻结 anchor 后的一次全局 ST 舍入

设 matching 选中组件 (c) 的机器 (i)。因 (y_i\ge t_c)，LP 容量给出 tiny 分数负载

[
 \ell_i\le T-h/(d_c+1)
   =\left[1-\frac{1-\alpha}{d_c+1}\right]T.
]

冻结该匹配，不再改变全部 tiny 的 (x)，对所有 tiny 一次执行标准 Shmoys--Tardos 有序槽匹配。舍入误差 (q_i) 取该机器上有正分数支撑的最大 tiny 时间；由身份假设 (q_i\le\beta T)，若无支撑则 (q_i=0)。因此 tiny 整数负载至多 (ell_i+\beta T)。

匹配锚任务在机器 (i) 上的实际时间至多 (T)，所以有 anchor 的机器满足

[
 L_i\le T+\left[T-h/(d_c+1)\right]+\beta T
 =\left[2-\frac{1-\alpha}{d_c+1}+\beta\right]T.
]

无 anchor 的机器只有 tiny，负载至多 ((1+\beta)T)。由于 (d_c\le d_0)，全局界为

[
 C_{\max}\le\left[2-\frac{1-\alpha}{d_0+1}+\beta\right]T.
]

该算法是确定性位多项式：有理 LP、连通分量、二部 matching、全局 ST 和精确阈值比较均为输入总位长多项式；没有按组件缺额位置枚举笛卡尔积，也不需要 tiny 时间有公共分母或正下界。若 \(\beta<(1-\alpha)/(d_0+1))，这是严格次二；等号只给 2，超过等号不产生统一次二余量。

## 3.5 真实边界、matroid 抽象与可复用机制

源的边界检查必须随定理保存：

* ∅ anchor、∅ tiny、零 tiny 边、无 anchor 机器和 (d_c=0) 都有明确退化处理；anchor 零边不可能出现，因为 (h>0)。
* 若输入声称 (d_c<0)（anchor 数超过组件机器数），则任何 (T)-调度都不可能容纳这些 anchor；若 (k_c\le m_c) 但 Hall 障碍仍存在，联合 LP 应不可行。
* tiny 整数 (T)-可行性本身可能困难；算法只支付 (\beta T) 的 ST 加性误差，不声称解决 tiny 的精确最优分配。
* LP 可行后 matching 的成功是证明结论，不是允许实现随意返回 FAIL 的 oracle 行为。

第 9 节把删机论证抽象到 matroid：对秩 (r)、元素数 (r+d) 的 matroid base polytope 中任意 base 点 (y)，删去 (L=\{e:y_e<1/(d+1)\}) 时 (y(L)<1)，从而 (rank(E\setminus L)=r)，仍存在完整 base。均匀秩一 matroid (U_{1,d+1}) 中所有坐标等于 (1/(d+1)) 说明任何更高 cutoff 都会误删全部元素；这只证明 cutoff 机制锐，不证明调度比最优或困难性。anchor 匹配是 transversal matroid 的 base，组件分解给出这里的有效直和特例。

## 3.6 未知 OPT 的承诺版本

承诺身份为 `UM-ANCHOR-DEFICIENCY-PROMISE-APPROX-v1`。仍固定 (B/S)、(\alpha,\beta,d_0)，并承诺存在一份最优调度：每个 anchor 实际边至少 ((1-\alpha)OPT)，每个 tiny 实际边至多 (\beta OPT)。这是存在性条件，算法不能免费识别；若 anchor 资格分量缺额超过 (d_0)，应报告 `OUT-OF-CLASS`，不能写成 `FAIL`。

对候选 (T) 只保留 anchor 边 (p\le T)、tiny 边 (p\le\beta T)，不施加 anchor 下界；联合 LP 的容量右侧为 (T(1-(1-\alpha)y_i))。可行性随 (T) 增大而单调，因为 (1-(1-\alpha)y_i\ge0)。承诺的最优调度在 (T=OPT) 处给出 0/1 LP 见证，故可在精确整数网格上二分最小可行 (T_0\le OPT)：取所有有限处理时间既约分母的乘积 (Q)，令 (U=\sum_j\min_i p_{ij})，搜索整数 (K\in[0,QU]) 的 (T=K/Q)。(Q) 的位长是输入分母总位长，迭代次数 (O(\log(QU+1)))，没有几何网格因子。随后使用同一删机、matching 和一次全局 ST，得到

[
 C_{\max}\le\left[2-\frac{1-\alpha}{d_0+1}+\beta\right]T_0
 \le\left[2-\frac{1-\alpha}{d_0+1}+\beta\right]OPT.
]

该版本仍是承诺域上的算法；一般混合角色、无界缺额或无法验证尺度 promise 的输入不在结论内，源也没有实现通用有理 LP 后端的端到端程序。

# 4. 两对象的关系、独有内容与处置

## 4.1 不能合并前提

源一把“任务数/基线项”视为仿射解码的主要风险：没有独立等基数，近似 makespan 不保留源目标。源二则把任务身份 (B/S)、anchor 近单位区间、tiny 上界和有限缺额作为输入合同，再通过联合 LP 和 Hall/ST 把角色约束真正执行。anchor 的 (B/S) 不是源一的 dummy cardinality；tiny 的 (\beta T) 也不能被当作仿射效用。两者因此保持同一子存档内的两个独立对象：源一是**负面接口边界**，源二是**有明确结构的正面条件算法**。

## 4.2 已保留的独有内容

* ID `8088efef4cfbcec8c315`：显式等基数恒等式 (A1)、全 (\rho>1) 的 (q+1/q-1) 计数反例、近二参数冲突和 (\rho=1.9) 裁剪失败矩阵；这些内容不能被既有有限配置审计的摘要替代。
* ID `78b4b3116ebe9be9ccd3`：单个全局 LP（tiny 不逐组件分开）、严格低占位质量小于 1、Hall 矛盾、一次跨组件 ST、dual FAIL 证书、(d=0)/零边/空集边界、matroid 余秩抽象、承诺未知-OPT 整数网格；这些是条件算法的承重论证和可复用接续接口。

两个源均保留为 `integrated` 正文对象；没有因“不是主线”“尚未给一般近二算法”而退休，也没有把开放缺口伪装成完成。

# 5. 接续义务与第三阶段关系

1. 若尝试利用仿射互补接口，必须先给出独立等基数/过载选择器，并以全量词验证近似调度不会走溢出分支；不能把 (A1) 写成无条件归约。
2. 若尝试利用锚任务算法，必须在输入层固定 (B/S)，逐边检查区间和禁止端，计算每个 anchor 组件的 (d_c)，并保持 tiny 的**全局**联合 LP 与一次全局 ST；逐组件各解一个 tiny LP 会丢掉跨组件资格。
3. 对一般输入，优先寻找如何生成固定角色与有界缺额的真实 reduction；同一任务兼有 near-unit 和 tiny 边、缺额无界或 promise 无法识别时，当前正文只支持 `OUT-OF-CLASS`/开放项，不支持近二保证。
4. 第三阶段建立超边时，源一可作为“方法边界/反驳”节点连向等基数归约和近二目标；源二可作为“条件算法/推广”节点连向 Hall、transversal matroid、ST 舍入。两者不应通过虚构的“仿射等价”边直接合并；共同前提必须写清是 unrelated-machines 的特定任务合同，而不是六人 SPE 的客户均分语义。
5. 需要新程序或复现时，只把实际执行的脚本、LP 后端和见证放到 `tools/evidence`；本审查没有新增 checkpoint、done 或提交，不把源内提到的有限核验链接误写成此批再次运行的结果。
