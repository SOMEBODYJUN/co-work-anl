# 共同容量与未知阈值的有限精确核验

[证据目录](../../tools/evidence/unknown-target/)保全本13来源的原字节、来源定位与哈希。`original/` 为原相对路径，`replay/` 保存四原程序本轮各一次stdout及新探针，`replay-results.json` 保存退出码和输出。均仅用标准库；严格数学判定用整数或 `Fraction`，没有浮点求解器。

## 四原程序的实际功能

| 程序 | 实际检查 | 本轮输出 |
|---|---|---|
| common_size_reopen_capacity_flow.py | 两个两机三任务矩阵各8整分配；分数等号；支撑头部；价格15<18 | JSON与冻结230字节报告逐字节相同 |
| unknown_target_common_size_exact_repair.py | 4例全部候选阈值，递归容量谓词与独立枚举最优值比较 | `ok` |
| unknown_target_common_multiplier_exact_repair.py | seed=2101的400小实例及全部候选；guard与两不交组件 | `{'random_instances': 400, 'frozen_guard': 'ok', 'disconnected_components': 'ok'}` |
| unknown_target_partition_search_obstruction.py | 四个整数数组的同一PARTITION子程序结果 | `ok` |

第一项共同尺寸矩阵 $[[2,2,2],[2,2,2]]$ 和异端矩阵 $[[2,100,2],[100,2,2]]$ 的整数最小峰值均4；半半共同流每机3。支撑头部例给负载加最大件 $(2,4)$，容量 $(3,4)$。价格例三件任务每件时间 $(2,3)$、容量 $(3,3)$、价格 $(3,2)$，容量价15小于最低任务价和18；这个断言在源码中，旧输出JSON未另列它，故不能仅看JSON摘要当全部检查。

共同尺寸四例依次为有冻结负载的两个任务、分数负载与共同尺寸 $1/6$ 的三任务、孤立高核心guard反例、空残余任务。它计算所有候选的真假与枚举峰值比较，没有实现完整候选二分和输出实际分配。

倍率程序生成 $m=1..4,n=0..6$，正有理 $q,a_i$、有理核心和非空资格。oracle直接枚举实际处理矩阵 $p_{ij}=a_iq$ 上全部合法完整分配；被审分支另用计数容量的递归匹配，两者不是同一算法。`candidate_opt` 线性扫描有理候选，尽管数学正文主张可以二分；脚本不含结构检测器，也不保证大实例递归安全。

PARTITION原程序408字节，`feasible_two_machine(w)` 只是返回 `has_balanced_partition(w)`，没有构造anchor矩阵或证明与原路径promise相容。它不是独立调度oracle，不能用“ok”替代[归约](../障碍/给定目标路径的未知整数搜索--障碍.md)的一般证明。

## 本轮新明确补核

新driver [new_guard_and_partition_audit.py](../../tools/evidence/unknown-target/replay/new_guard_and_partition_audit.py)未改原程序，以明确固定fixture做两项验证，并写[新JSON](../../tools/evidence/unknown-target/replay/new_guard_and_partition_audit.json)：

- 原共同尺寸谓词在1200件合法长链上，默认递归限1000，实际抛出 `RecursionError`；完整实际匹配见证由 $\tau=(1,2,\ldots,1199,0)$ 给出，逐任务资格和无重占已核。这与历史审查相同机制，但当前driver是新写，未声称恢复旧scratch字节。
- 对原四数组真实添加两anchor，再枚举不可拆分残余调度、核全部初态实际最大件promise。$w=(1,1),(1,2,3),(1,1,1,3),(2,2,2,2,2)$ 的 $B$ 分别为1、3、3、5，目标 $T=2B$，实际整数最优峰值分别为2、6、6、11；仅末例不可达目标10。这是对原代码未做义务的明确补核。

历史审查声称的33,210实例/225,648阈值scratch harness未在本批取得，本轮未重跑或重新生成那项扩大枚举；保留为[历史审查的有限证据声明](../审查/共同容量修复的判定与实现边界--审查.md)，不冒充实际新实验。

## 复现和可接续性

在仓库根用 `python3 archives/unrelated-machines/tools/evidence/unknown-target/original/tests/audits/unrelated_machines/脚本名.py` 运行表中原程序；新driver用

```bash
python3 archives/unrelated-machines/tools/evidence/unknown-target/replay/new_guard_and_partition_audit.py
```

源代码、输入参数、原报告与新stdout均在同证据目录，版本定位不依赖历史scratch路径。一般有序槽合同、未知阈值位多项式算法和搜索困难分别由各自完整正文承担。tiny审计成功不提供通用后端，递归失败不否定数学算法，有限实例也不决定一般不相关机器次二目标或全球优先权。
