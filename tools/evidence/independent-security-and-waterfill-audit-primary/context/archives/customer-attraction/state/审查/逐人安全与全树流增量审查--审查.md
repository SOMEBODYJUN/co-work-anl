# 逐人安全与全树流增量审查

本页是 2026-10-10 一批来源的增量审查。它们都使用 CAG 的共同有限目录、单位客户和单位提供者；客户由最终覆盖者均分，策略在所有有序历史上完整定义。这里的 `security` 指静态竞争背景下的混合安全值，`aggregate` 指实际福利或全树预算；两者不能用同一符号替换。已有对象[自适应后继与真实菜单安全值障碍](../障碍/自适应后继与真实菜单安全值--障碍.md)、[静态安全值与聚合保底的精确核验](../计算/静态安全值与聚合保底的精确核验--计算.md)、[总安全预算的精确证书](../计算/总安全预算的精确证书与独立审计--计算.md)承载主结论，本页补充本批的独立证书和量词边界。

## 1. 34 与 360 客户：完整 SPE 的逐人安全失败

### 34 客户压缩实例

`70a225d01e7d689d1883` 直接展开 34 个单位客户（13 个类型）、3 位提供者和 6 个主题。完整策略有 43 个有序非终局历史、258 个动作比较、216 个终局；215 个非指定偏离中 144 个严格更差、71 个平局。实际终局是 \((0,3,4)\)，收益
\[
(u_1,u_2,u_3)=\left(\frac{29}{3},\frac{67}{6},\frac{67}{6}\right),
\quad W=32,quad \operatorname{OPT}=34.
\]

静态安全值由精确原始/对偶证书给出
\[
v=\frac{2411}{246},qquad u_1-v=-\frac{11}{82},qquad
W-3v=\frac{213}{82}>0,qquad W-\frac{\operatorname{OPT}}2=15>0.
\]
六个主题覆盖集合两两不同，首位最优安全分布唯一；正对偶支撑矩阵行列式为 \(-12055/48\)。因此这是一个真实完整纯 SPE 的**逐人**安全桥反例，同时明确不是聚合安全或 half 反例。

独立文本审查 `9603788cc9ab53b8d9ac` 和独立单位客户/整数行列复核都重复该结论：所有 21 个无序静态背景、36 个有序背景、126 个纯查询和 1548 个 continuation-background entries 均用 Fraction 逐项检查；六个正支撑约束确定唯一分布
\(p=(10,10,21,10,10,21)/82\)。这批独有内容是两个独立实现与精确行列式，而不是新的反例类型。

### 360 客户实例

`6be47bc0797b53c84494` 审查 360 个不同单位客户（19 个类型）、同样 3 位提供者/6 主题的完整策略。43 个节点、258 个比较、216 个终局全部展开；215 个非指定偏离中 164 个严格更差、51 个平局。实际收益为 \((102,117,117)\)，\(W=336\)、\(\operatorname{OPT}=360\)，安全值
\[
v=\frac{93177}{908},qquad u_1-v=-\frac{561}{908},qquad
W-3v=\frac{25557}{908}>0,qquad W-\frac{\operatorname{OPT}}2=156>0.
\]
真实根的 \(D=102,C=v,e=0,\kappa=-561/908\)，而后两节点的正松弛补偿使总 GB 仍为 \(65339377/3710088>0\)。因此增加客户规模没有把逐人失败提升为福利失败；它反而保留了“局部负 \(\kappa\) 可由后继补偿”的区分。

`a37ba8208186189c11c4` 保存同一 34 客户输入的完整独立结果：43 个节点、216 个终局、258 个比较、1548 个偏离背景查询，安全值上下界均为 \(2411/246\)，实际聚合 margin 为 \(213/82\)，half margin 为 15。`a0b7ba352b8f55edd896` 将 34/360、iid flow、selected cones、四人尾部提升和随机位置交换放在同一来源清单中，并明确没有任意人数 half 证明或完整聚合安全反例。故 70a、6be、a37、960 的处置是集成到既有逐人安全反例/计算对象，不重建相同稳定 ID。

## 2. 自适应去相关与全树流模板

### 自适应去相关的精确差额

`bd875beb7f1944154abb` 对 26,171,145 个客户、1,885 个有序节点和 22,620 个动作比较重放了四人上传策略的去相关矩阵。实际根为 \((8,4,5,0)\)，收益 6,135,345；两个指定去偏主题的真实续局为 \((2,3,11)) 与 \((6,7,3))，矩阵为
\[
\begin{pmatrix}6135342&6135349\\6135349&6135345\end{pmatrix}.
\]
自适应均值为 \(12270687/2\)，独立均值为 \(24541385/4\)，差为 \(-11/4\)，自由菜单 cap 为 6,135,345。该结论只反驳指定 universal decorrelation；审计明确不反驳 half 或混合安全桥。它与已有真实菜单障碍合并，独有内容是本次完整大整数矩阵和 96 个后继 membership 身份复核。

### 全树势恒等式与流分离

`b991ca30daf6314edd54` 和 `379d7599d93910cb6dc4` 逐字段重建完整树流量。36 客户三人实例有
\[
W=34,\quad \Psi=97/3,\quad (G_1,G_2,G_3)=(0,1/2,31/18),
\]
单位流余项为 \(-5/9\)，按删除位置总式的余项为 \(-5\)。完整 258 条激励行非负、静态 Nash 行为零；因此固定 iid 流或把固定流系数乘三都不能给出非负预算证书，但真实 \(W-\Psi=5/3>0\)。

另一个 15 类型分离向量的客户总质量为 1,178,518,685,350,194，43 个节点中平均行最小值 0、9 行为零、34 行为正；六个静态 Nash 行仍全为 0，而
\[
(c-\psi)w=-1085816540911589/12<0,
\]
且有 59 条负的完整 Gamma 行。这个向量不是 SPE 反例，因为根改选主题 5、1 等有正收益；它只分离“节点独立权重+固定 q 平均所有偏离”的 Farkas 模板。`379...` 还在 n=4 非均匀 q 与 252 组四元位置子集上检查了势恒等式，确认实现不依赖 n=3 或均匀分布。

`c7b73d6fbb280dc7583b` 的独立数学审查确认四人尾部提升：若任意合法背景的四人剩余利润满足 \(F_4\le(1499/750)V_4\)，则对 n 人完整 SPE
\[
\operatorname{OPT}_n\le\left(\frac n2-\frac1{750}\right)W.
\]
一般 k 的消元形式为 \(n/2-k/2+\beta_k\)。审查同时确认固定流和任意深度平均流的上述分离障碍成立，并强调它们只排除指定非负线性证书，不排除保留全部逐偏离行的其他支付。该推论已有专门正文，本批将审查稿作为独立范围证据集成，不把它写成六人 half 结论。

## 3. 固定策略锥、根菜单与无知安全值

`d4f5aa611832cf09885d` 在 36 客户三人完整策略上检查 43 个节点、258 个比较。根路径 ((0,3,4))，收益 ((10,12,12))，真实菜单矩阵的全概率 minimax 值为 11，而不受限静态安全值为 10；根 stationary menu cap 为 11，福利 34、最优 36、\(2W-\operatorname{OPT}=32\)。因此“当前根回复菜单支付不了当前收益”的障碍不等于真正安全值桥失败。

`a4dd82aa41fb5665aec0` 在固定完整策略锥、任意非负客户类型权重和全部安全分布上检查 4,914 个精确身份。`aggregate_theta_failure`、`root_tax_failure` 等目标的最小残差均为 0，说明所列 Q/\(\Gamma\) 只满足固定策略锥身份；不能推出跨所有完整策略的普遍支付。`4a9f922216ecd8d44763` 对五个固定游戏在指定精确最优 p 上给出 PASS：原 36 客户的最小 GB budget 为 \(17/6\)，34 客户为 \(60/41\)，360 客户为 \(55088965/3710088\)，root-tax failure 为 \(3/2\)，global decorrelation failure 为 \(70429743611/10570351740\)。每项都明确 “fixed game only; no universal claim”。

`f4e841a776a9a84ea705` 的 oblivious security audit 给出七个固定输入的精确值：\(m=n=1\) 至 \(6\) 的 sharp family 值都为 1；36 客户三人输入的 exact value 为 10，背景分类为 repeat \(37/3\)、same-group 10、cross-group \(97/9\)。这是静态安全值数值和末位 \(\theta\) 的接口核验，不是一般 SPE bridge。

## 4. 研究前沿审查与模型边界

`0d95efeb88adc5463938` 的独立审查确认一后继去相关恒等式、四人矩阵和三人根菜单审计无致命问题，同时明确不判定逐人 \(u_i\ge v_n\)、总桥 \(W\ge nv_n\) 或 half。`3aee25998e06b261a8b5` 复核完整树证书等价定理 (T) 的 minimax/Farkas 推导，同时确认旧 GB 已被 36 客户完整 SPE 否定；它还保留“89 客户的新增特征是后继去相关差额为零，而非首次否定总去相关”的纠错。

`cf8cc31e84852e50ac59` 的前沿审查确认：三极大覆盖证明给出 \(\operatorname{OPT}_n\le U\le2W-c\)（至少两个极大集的条件），五人上界为精确 \(\beta=24236714656727/10967499015623>2.21\) 的完整历史定理；两者都没有证明六人 half。审查中 40,919 个座位三元组、292,824 个阈值模式等有限检查只支持实现；四极大标量 half 证书障碍也只是接口障碍，不是 SPE 福利反例。
