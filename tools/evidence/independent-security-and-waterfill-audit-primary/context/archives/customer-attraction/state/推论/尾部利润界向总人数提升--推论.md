# 尾部背景利润界向任意总人数的合法提升

## 独立来源记录

tail_lift_source.md 是 2026-10-10 的独立推导稿，完整重写本页的索引子集计数、真实最大主题 $K/n$ 保底、整数背景税预算和 $\beta_4=1499/750$ 消元，并给出可复用的固定 $k$ 通式。它与较早的 tail_profit_lift.md 结论相同，但提供了独立的推导路径和“不能把五人根界当任意背景前提”的范围提醒；本页将两条来源并列保留，未把同一结论重复计数为两个定理。

客户集 $N$ 有限，客户价值均为一；共同主题目录 $\varnothing\ne\mathcal S\subseteq2^N$ 有限。单位提供者依次观察全部有序前史，各选一个目录主题；客户价值在所有最终覆盖者之间均分。允许空主题、重复选择、零客户和任意离轨平局。固定一份在**所有合法有序历史**定义的纯SPE，偏离后始终沿这同一份策略在改变后的历史继续；相同负载的不同有序历史不必使用同一续局。完整定义见[共同目录模型](../定义/共同目录完整历史模型--定义.md)。

根游戏人数为整数 $n\ge1$，实际主题为 $(S_1,\ldots,S_n)$，实际收益为 $u_i$，根福利 $W=|\bigcup_iS_i|=\sum_i u_i$；定义 $\operatorname{OPT}_n=\max_{(T_1,\ldots,T_n)\in\mathcal S^n}|\bigcup_jT_j|$。固定整数 $1\le k\le n$；实际前 $n-k$ 位主题形成的背景 $b_x\in\mathbb Z_{\ge0}$ 是真实覆盖次数，截取给定策略的子树仍是完整纯SPE。零分子份额一律定义为零。

## 1. 比较覆盖在真实背景下的接口

固定实际前n−k位玩家的有序历史，客户背景负载b_x，最后k位实际利润和V。
假定一个普遍合法背景定理 `F_k(b)≤β_kV`，其中F_k是同背景下最优k主题剩余利润
`Σ_x c_x/(b_x+c_x)`；零分子项为零。

取取得O=OPT_n的n个比较主题T_1,…,T_n，允许重复。
对每个k元**索引**子集I，比较利润不超过β_kV。
每位最优覆盖客户x任选一个覆盖它的索引j_x。在含j_x的C(n−1,k−1)个I中，c_x≥1，且

\[
\frac{c_x}{b_x+c_x}\ge\frac1{b_x+1},
\quad \frac{c_x}{b_x+c_x}-\frac1{b_x+1}
=\frac{b_x(c_x-1)}{(b_x+c_x)(b_x+1)}\ge0.
\]

全部索引子集求和及C(n,k)/C(n−1,k−1)=n/k给

\[
\sum_{x\in\cup_jT_j}\frac1{b_x+1}\le\frac{\beta_kn}{k}V.
\]

补上每个最优客户的b_x/(b_x+1)，并允许非最优客户贡献非负税项，得到

\[
O\le\frac{\beta_kn}{k}V+\sum_x\frac{b_x}{b_x+1}.
\tag{2}
\]

背景取实际有序前缀，因此尾部恰为该给定SPE的真实子博弈；这一步不冻结任何偏离续局。

## 2. 早期收益与背景负载的合法预算

令K=max_{T∈S}|T|。每位实际玩家在自己的真实节点改选最大主题时，不论后继如何
依原策略改变，每个客户最终最多被n人分享，故偏离收益至少K/n。SPE给u_i≥K/n。
实际收益和为W，因此

\[
K\le W,\qquad V\le W-\frac{n-k}{n}K.
\tag{3}
\]

实际早期主题大小各≤K，故Σ_xb_x≤(n−k)K。整数b≥0满足b/(b+1)≤b/2，得到

\[
\sum_x\frac{b_x}{b_x+1}\le\frac{n-k}{2}K.
\tag{4}
\]

这里没有断言这些税项能被根福利支付，只用真实负载与最大主题大小。

## 3. 一般公式及末四人常数

合并(2)–(4)，若 `0≤β_k≤k/2`，则n≥k使K系数非负，可用K≤W：

\[
\begin{aligned}
O&\le\frac{\beta_kn}{k}W+(n-k)\left(\frac12-\frac{\beta_k}{k}\right)K\\
&\le\left(\frac n2-\frac k2+\beta_k\right)W.
\end{aligned}
\tag{5}
\]

已证的[固定背景四人利润定理](../定理/固定背景四人利润界--定理.md)给k=4、β_4=1499/750<2；代入(5)即得下述无条件结论。
亦可直接重算为 `O≤1499nW/3000+(n−4)K/3000≤(1500n−4)W/3000`。
W=0时(3)给K=0，O=0；n=k、空主题、重复主题及全部平局都被原推导包括。
不将目前五人零背景根界作为任意背景β_5使用。

因此对每个整数 $n\ge4$、每个上述实例及每份完整历史纯SPE，

\[
\boxed{\operatorname{OPT}_n\le\left(\frac n2-\frac1{750}\right)W.}
\tag{Tail4}
\]

## 4. 通式的精确条件及现有结果边界

第3节一般公式是一个条件推论：固定整数 $1\le k\le n$，若**所有相关合法有序前缀和每份完整子局纯SPE**满足 $F_k(b)\le\beta_k V_k$，且 $0\le\beta_k\le k/2$，则

\[
\operatorname{OPT}_n\le(n/2-k/2+\beta_k)W.
\]

$\beta_k\ge0$ 保证将 $V_k$ 替换为(3)上界时不反向；$\beta_k\le k/2$ 保证 $K$ 的系数非负，可用 $K\le W$。若通用前提包含单个非空主题的零背景实例，它本身已经强制 $\beta_k\ge1$；显式写非负条件使消元前提更清楚。三人背景常数 $5/3>3/2$，所以不能将它代入这一特定的最后消元公式，尽管第1节索引接口仍然合法。

第2节 $b/(b+1)\le b/2$ 只对 $b=0$ 或 $b\ge1$ 成立，单位提供者使合法背景为整数，故这里完全适用。不得仅凭背景多项式对实数非负，就把本提升放宽到任意 $(0,1)$ 实负载。最大主题保底 $u_i\ge K/n$ 同时适用于每个实际玩家，因每次比较都沿其原策略真实续行；它不是逐人静态安全值桥。

对 $n=4$，(Tail4)重获 $1499/750$；$n=5$ 给 $1874/750>2$，已被[五人半覆盖](../定理/五人半覆盖--定理.md)及其正余项改进超越；$n=6$ 给 $2249/750>2$，不能解决[恰六人半覆盖](../../subarchives/six-providers/问题--问题.md)。零背景五人根福利定理没有提供本通式所需的任意背景 $\beta_5$。对 $n\ge6$，本系数优于原通用 $n(2n-1)/(4(n-1))$：旧系数比 $n/2$ 大 $n/(4(n-1))>0$，本系数比 $n/2$ 小 $1/750$；这只是界的比较，不认证外部文献版本或新颖性。

本推导没有使用已被反例否定的首步机会成本桥、任意人数背景总税或实际根总税，见[固定背景收益与税](../定义/固定背景剩余收益与税--定义.md)。其全部联合前提是合法背景利润定理、索引包含计数、真实节点 $K/n$ 保底、整数背景税预算与非负消元。无需以有限人数抽样替代上述解析证明。
