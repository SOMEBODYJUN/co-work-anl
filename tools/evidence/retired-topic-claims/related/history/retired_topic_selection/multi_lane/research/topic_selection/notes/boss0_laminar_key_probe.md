# 四代理laminar关键核：精确枚举与顺序贪心障碍

对象沿用 **SEL-LAMINAR4-KEY-v1**，不是新题或新存在定理。来源是 Cookson–Shah [Constrained Fair Allocations via Partition Matroid Reductions, 2608.31121v1](https://arxiv.org/html/2608.31121v1)，§5、Appendix B Definitions 13–14/Lemma 11。原作者将四代理laminar EF1存在性约化到下述两个核的更强输出；本轮读取了相关原始定义和约化陈述，未声称独立审完一般约化证明。

## Exact Statement / Objects / Domain / Quantifiers

四代理，同一laminar独立集系统，完整分配。八物品核的三个分组大小为(3,3,2)，每人每组至多一件、每人总容量二；十二物品核的四分组大小为(3,3,3,3)，每人每组至多一件、总容量三。估值非负且可加；目标对每个估值profile和预先指定代理顺序，找到可行完整分配，同时EF1和ordered no-envy。

EF1为对每个i,j，存在g∈A_j使v_i(A_i)≥v_i(A_j\{g})（空包条件为空）；ordered no-envy为i<j时v_i(A_i)≥v_i(A_j)。这两个条件均需要，单独检验EF1不足以接入原文拼接接口。本次只检测指定顺序1,2,3,4；因为估值profile任意，其他顺序可重标号，但本次有限输入不能代替全部profile。

## 试攻与核验合同

[代码](../probes/boss0_laminar_keys.py)按每一类别向四代理的所有单射枚举，筛掉总容量不符项，直接计算每个候选分配的有序无嫉妒与EF1。另用逐物品4^8归属独立枚举八物品核的全部可行分配；再以逐件移除oracle交叉检查部分完整profile和全部返回见证。算术为有界非负整数，最大允许单件值10^6，本次包大小至多三，int64没有溢出；不接受浮点估值的隐式取整。

八物品可行分配数为4·3·(3!)²·2!=864：两个三物品类别分别遗漏不同代理，二物品类别遗漏其余两代理。十二物品数为4!·(3!)⁴=31104：四类别各遗漏不同代理。代码计算公式并与实际枚举反算相等。

固定seed=20261020；八物品测试84个profile，十二物品测试16个profile，其中包含全零、相同单位估值、稀疏零值、共同非均匀估值及seed随机整数。每个有限profile均找到ordered EF1分配。没有发现反例只属于这些有限输入的Observation，不增加一般命题的证明状态。程序还拒绝维数、负值、浮点、过大数值、不合法类别与容量等边界。

## 可以严格排除的朴素算法

所有代理对八物品有相同估值(1,2,3,1,2,3,1,2)。对全部可行完整分配依次最大化代理1、2、3、4的自身效用，即可行残余上的顺序独裁；公共可行性允许交换两个包，故其输出满足ordered no-envy。

但本例的每个顺序独裁输出效用向量均为(6,4,3,2)。最末代理看最前代理的两件价值3物品，移除任一件仍为3>2，违反EF1。所有并列选择均失败，不是随意tie-breaking造成。

同时存在目标分配：A1={g1,g6}、A2={g2,g8}、A3={g3,g4}、A4={g5,g7}，效用(4,4,4,3)，且每包跨类别。直接逐项核验EF1和ordered条件。含义仅为必须允许早期代理牺牲部分自身最优效用；不否定有序EF1存在，也不声称这个小贪心反例足以独立成稿。

## Status / Dependencies / Evidence / Objections / Next

Status=有限精确Observation与显式朴素算法障碍；问题来源A，非团队新题。依赖为原文核定义、共同可行性、可加估值与直接不等式，未导入数值优化结论。[冻结输出](../probes/results/boss0_laminar_keys_20261020.json)含完整输入、seed、版本、代码SHA-256及反例见证。

最强未决义务：估值连续且无界，当前随机整数不是完备离散化；十二物品核组合复杂性更高。下一判别应设计保留包间比较的估值锥覆盖/可核验证书，或提取允许补偿交换的构造；反复增加随机样本信息价值低。价值在于有原作者明确尝试、固定有限核和可复用拼接接口，但只有证明两个核或产生新的边界机制才接近完整成果。
