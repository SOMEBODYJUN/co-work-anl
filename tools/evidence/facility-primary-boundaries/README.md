# 现行入口、54节失败路线及三设施形式问题

source-manifest.json保三主源完整原字节、两冻结来源、SHA和全读行数，共67654B/586行。reading-log.json保实际分段；section-scope-map.json逐54节保原标题/行/节hash/独有scope/正式对象，恰23节CAG和31节设施，不因原文件名误归档。supporting-source-manifest只保存另全文旁读的Q-CUBIC，不为它提交done。

三篇新正式页分别为CAG真实顺序收费边界、设施量词与后续回收、三设施(s,s,t)形式问题。大部分已知反例/证明链接既有自足对象，不重建重复命题。comparison-manifest将明确本批全文、选区及同worker上一批已完整读过的依赖。

本批不重跑旧成功审计/五人全域/求解器/外部调度器。仅新写标准库Fraction定义核算三设施两站两单位客户全部8标签布局，保存脚本/真实输出/命令。它支持一个手算例，不证明普遍形式。validation只检查字节、54节覆盖、链接、回执目标和语法，不代数学判断。

所有写入先外部staging，Boss串行拷入checkpoint再done；本worker不写Git/claim/done/共享正文或图。原材料内旧链接按冻结树保字节，不强改成当前路径或为了链接完整复制全仓。
