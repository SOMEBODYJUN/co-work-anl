# 固定贪心盒内收益字典序失稳

在[共同目录原子客户模型](../定义/共同目录任意设施数模型--定义.md)中，固定规范贪心已占站、重数q及末分数γ。每客户先完整选一个可达已占站，再在本站独立均匀混合；要求全部完整盒q_sγ≤W_s≤(q_s+1)γ。所选规则把每站收益W_s/q_s重复q_s次，升序排序后取字典序最大向量，候选**不预先要求NE**。

这个规则与[同时搜索全部布局的全局字典序因子二证明](../定理/共同目录任意设施数因子二存在--定理.md)不同：固定占位又加盒，原真实改善可能溢出盒。本页给唯一坏最大者，故不是破平局问题。

## 完整正整数输入

站点顺序H/M/N/L/R，k=11。五私有原子为H:446、M:230、N:189、L:159、R:100；六轻原子为X权46、x权2均选H/M，Y权82、y权81均选M/N，Z权4、z权30均选N/L。

规范贪心严格唯一站/分数依次为H:494、M:393、H:247、N:223、M:393/2、H:494/3、L:159、M:131、H:247/2、N:223/2、R:100。因此q=(4,3,2,1,1)、γ=100、原池W⁰=(494,393,223,159,100)，轻客户开站图为一致有向链H→M→N→L。盒分别[400,500]、[300,400]、[200,300]、[100,200]、[100,200]；所有六轻权均<γ，私有原子冻结。

## 解析证明唯一最大者

分配X:M、x:H、Y:M、y:N、Z:L、z:N给总重(448,358,300,163,100)，收益向量
\[
(100,112,112,112,112,358/3,358/3,358/3,150,150,163).
\]
R强制第一坐标100，此候选其他设施都>223/2。因此任一最大者的其他设施也须全部>223/2；以下情况穷尽六个二选项原子：

1. X留H：若无M/N客户去N，N≤223；若至少一个去N，M≤230+2+82=314，价≤314/3。两种均不能全超过223/2。
2. X和x都去M：H=446，其价恰223/2，也排除。因此X:M、x:H强制。
3. 无M/N客户去N仍有N≤223；两人都去N则即使Z/z全离开也有N≥189+82+81=352>300。故恰一人去N。
4. Y权82去N、y留M：M=357。N上盒迫使权30的z去L，否则即使仅Z离开仍有189+82+30=301>300。Z的两种选择都盒可行，但M价119<358/3，先于N/L坐标便败给展示候选。
5. y权81去N、Y留M：M=358。Z/z至少一人离开N，剩三种为(Z:L,z:N)总重N/L=(300,163)、(Z:N,z:L)为(274,189)、两人去L为(270,193)。它们H/M前缀完全相同，N价分别150/137/135且均先于L价出现，故第一种唯一胜出。

这证明唯一最大者正是展示分配，不靠数值搜索猜唯一性。

## 唯一坏者和同占位好者的全部比较

坏者Z在L，源外部价(163−4)/1=159>N价300/2=150，实际条件成本163→154，严格改善。改后N=304>300，故只被人工盒约束挡住；其他五轻客户均稳定。原游戏没有该盒容量。

同一占位的初始分配却全部稳定：

| 客户及原站 | 源外部价 | 替代站价 |
| --- | ---: | ---: |
| X:H | 112 | 131 |
| x:H | 123 | 131 |
| Y:M | 311/3 | 223/2 |
| y:M | 104 | 223/2 |
| Z:N | 219/2 | 159 |
| z:N | 193/2 | 159 |

私有客户只有本站选项。因此原分配本来就是完整盒精确客户NE，可由原池/受帽合同补成因子二完整续局。坏选择器既不证明无盒NE，也不证明该布局不能支持因子二，更不证明完整模型的常数下界。

原Fraction审计独立逐步核全部竞争贪心分数、枚举64赋值，恰24个入盒，确认唯一坏最大者和初始NE。本轮原字节只执行一次，完整stdout/空stderr/hash保存于[精确核验](../计算/浅层归属几何与盒选择器的精确核验--计算.md)。解析分类给完整有限反例，代码提供实际算术复验；无外审或优先权声明。

与[深度三势极小反例](有向深度三树的盒势最小失稳--反例.md)共同说明“盒内极值”不能不经全偏离证明就转成NE，两者极值目标和图结构不同。后续[截断交错势](../引理/阈值截断与归位计数的严格推进--引理.md)使用阈值截断、归位计数和H守护，不是这里未截断收益最大化；它不抹去本反例，也不受本反例否定。
