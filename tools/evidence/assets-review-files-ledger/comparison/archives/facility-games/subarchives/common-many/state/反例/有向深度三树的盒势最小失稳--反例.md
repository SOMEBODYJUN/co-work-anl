# 有向深度三树的盒势最小失稳

模型为[共同目录正权原子客户](../定义/共同目录任意设施数模型--定义.md)，k=15，站点固定顺序A1/A2/B/C/D/R。每位客户覆盖时必须服务；选定物理站后在该站设施间独立均匀混合，成本包含自身全重。

## 完整原子输入和严格贪心

六私有客户的站/权分别A1:4599、A2:4598、B:3045、C:2000、D:1451、R:1000；另有四客户：X1权400选A1/B，X2权400选A2/B，Y权900选B/C，Z权150选C/D。全部正整数，没有聚合可拆流。

规范贪心每次严格唯一最大，完整站/分数序列为
\[
\begin{gathered}
A1:4999,\ A2:4998,\ B:3945,\ A1:4999/2,\ A2:2499,\ C:2150,\ B:3945/2,\\
A1:4999/3,\ A2:1666,\ D:1451,\ B:1315,\ A1:4999/4,\ A2:2499/2,\ C:1075,\ R:1000.
\end{gathered}
\]
原程序逐步与**所有**竞争站比较，不以分数单调表替代唯一最大检查。故q=(4,4,3,2,1,1)、γ=1000、初池W⁰=(4999,4998,3945,2150,1451,1000)。四轻客户均<γ，初在(A1,A2,B,C)，六私有客户均≥γ且只有一选项，冻结合法。

轻图A1→B←A2，接B→C→D，是树、无向最大度三、最长开站有向路径三，每边恰一名轻客户；R孤立。被反驳的选择器是固定此占位，在全部完整盒q_sγ≤W_s≤(q_s+1)γ内最小化
\[
P=\sum_s\frac{W_s^2-\sum_{i:a_i=s}w_i^2}{2q_s}.
\]

## 全部盒内分配的解析穷尽

按(X1,X2,Y,Z)记录站点，共16种原合法赋值。Y留B时B总重3945+400h≤4000，迫使两个X均留原站，Z两选择均盒可行。Y去C时，若Z留C则C=3050>3000；所以Z必须去D，此时两个X任意四选择均入盒。下表恰全部六种：

| 分配 | 总重(A1,A2,B,C,D,R) | P | NE |
| --- | --- | ---: | --- |
| (B,B,C,D) | (4599,4598,3845,2900,1601,1000) | 5948950/3 | 否 |
| (A1,A2,B,C) | (4999,4998,3945,2150,1451,1000) | 1983200 | 是 |
| (B,A2,C,D) | (4599,4998,3445,2900,1601,1000) | 1983450 | 否 |
| (A1,B,C,D) | (4999,4598,3445,2900,1601,1000) | 1983550 | 否 |
| (A1,A2,C,D) | (4999,4998,3045,2900,1601,1000) | 2037350 | 否 |
| (A1,A2,B,D) | (4999,4998,3945,2000,1601,1000) | 2050850 | 否 |

第一行势严格最小，与第二行差650/3>0。但其Z位于D，源外部价(1601−150)/1=1451，大于C价2900/2=1450。因此Z真实严格想回C；加上共同自身150，实际条件成本1601→1600。移动后C=3050>3000，仅被人为完整盒约束挡住，原游戏没有该容量约束。

初始第二行四外部比较为4599/4≤1315、2299/2≤1315、1015≤1075、1000≤1451，故精确NE。其余五行Z都在D：Y在C时目的C价1450；Y在B时C价1000，均严格小于Z源外部1451。于是第二行是**唯一盒NE**，第一行是**唯一盒势极小者**，并列破平局不能修复该选择器。

## 递归整池交换具体失去的是什么

从坏极小者令Y回B、两X分别回A1/A2，再令Z回C，恢复初始盒NE。这个递归整池交换确实盒可行，却使P增加650/3。由于起点已是全局盒势最小者，任何同时盒内重分配都不能严格降P。因此失败的是所需“交换降势”断言，不是交换可行性或原客户均衡存在。

[深度二定理](../定理/开站有向深度二的整池交换盒均衡--定理.md)用入邻都是源及每池S_h≤γ给降势项；深度三时入邻可再带外来质量，这一具体推导不再有同样保证。不能把条件简单替换成深度三，即使图仍是树且每边只有一客户。本例有分叉，不反驳已另证的一致有向路径算法。

同输入位于有界树宽/局部权种的[结构DP域](../推论/结构参数下完整盒均衡的多项式选择--推论.md)，可选真正盒NE。一般盒存在性也已由后续交错势证明，不能保留旧全类OPEN为当前真值。这里不证明找盒NE困难、全态无NE、因子二下界或该贪心布局无因子二续局。

原Fraction程序本轮真实执行一次，逐原子计算16态、6盒、全部原客户比较、唯一极小/唯一NE及650/3，完整表和严格贪心轨迹已保存于[精确核验](../计算/浅层归属几何与盒选择器的精确核验--计算.md)。本有限例的完整解析穷尽是反例证明；程序PASS是算术/实现证据，内部对称前驱审查不提升为本严格版本的外审或优先权认证。
