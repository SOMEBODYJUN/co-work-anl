# 共同目录三五地点固定倍率的全布局守卫

## 判定对象、结论和复用边界

有限显式正二进制有理原子客户，两家带标签设施共享非空有限目录S，允许同址；被覆盖客户必须选覆盖者，各客户独立混合，条件成本为含自身权重的实际设施负载期望。设施最大化期望收到的客户权。完整规则对每个带标签布局分别指定一个**精确**客户NE。\(\alpha^*(I)\ge1\)在所有纯设施在轨布局及所有完整规则上取最小；\(\mathrm{DEC}_a\)问是否\(\alpha^*(I)\le a\)。源NO必须排除任意在轨NE和任意离轨惩罚，源YES须给一份完整合法续局。

这不是六名单位提供者顺序选择主题、最终客户均分的CAG模型。目录地点数不是设施数；全文设施始终两家。

两个冻结主源的内部结论是：

| 固定有理a | 目录大小 | 结论 |
| --- | --- | --- |
| a=1 | 恰三地点 | DEC₁弱NP完全 |
| 1<a<σ=(1+√3)/2 | 恰三地点 | DECₐ弱NP完全 |
| 1<a<φ=(1+√5)/2 | 恰五地点 | DECₐ弱NP完全，源YES还给精确α*=a，NO给α*>a |

正有理权可统一放大成正整数，结论对显式二进制正整数仍成立。“弱”另有整数总重伪多项式算法支持，不是从数值大小猜出的标签。a事先固定；不声称a输入时的统一多项式预处理界、强NP难、最少地点数或固定常数gap。σ是特定三地点守卫的预算端点，不是模型复杂度相变；恰三地点σ≤a<φ仍未由这些源分类。a=φ时五地点参数的开区间消失，也不能由此自动推出算法；任何黄金比上界须另核其完整证明。

分类已在[实例最优前沿](../审查/实例最优计算的参数与判定前沿--审查.md)登记。本页补全其未展开的**全布局归约证明**，复用已吸收的[局部弱NP源](指定设施均衡负载极小值的弱NP完全性--归约.md)、[全部混合负载谱](../定理/两设施原子客户的完整混合均衡负载谱--定理.md)、[整数DP](../算法/两设施均衡谱的阈值动态规划与权类参数化--算法.md)，不另复制这些独立定理。冻结原字节、ID/SHA与双提交路线见[manifest](../../../../tools/evidence/small-catalog-primary-complexity/source-manifest.json)。状态是完整内部证明；无外部同行评审或全面优先权认证。

## 局部源的精确接口

对正整数SUBSET SUM列表b及\(0\le K\le\sum b\)，已整理局部归约用五进制标记产生正整数\(u_1,\ldots,u_n\)、目标\(R_0<U=\sum u_i\)，二次有界和\(\sum t_iu_i=R_0,t_i\in\{0,1,2\}\)当且仅当源YES。改\(t_i\mapsto2-t_i\)，使用

\[
R=2U-R_0>U,\quad\delta=R-U>0,\quad Q=2U+R+1.
\]

局部共同客户为n个\(Q+u_i\)和n+1个Q锚，总重\(W=(2n+1)Q+U\)，客户数\(k=2n+1\)。有

\[
W>\delta+Q,\qquad0<\delta<Q/3,\qquad Q/W<1/(2n+1).
\]

背景差为+δ的全部NE差额谱\(\mathcal D\)满足

\[
\Delta\ge-Q,\qquad\min\mathcal D=-Q\iff\text{源YES}.\tag{L}
\]

其证明不是假设混合者数量受限：在\(\Delta=-Q\)，变量纯1/混合/纯2分别编码0/1/2，混合概率\(u_i/[2(Q+u_i)]\)；锚客户补足恰n+1名非纯1客户。反向任一NE编码回有界和，\(\Delta<-Q\)则强迫全部锚纯1并使负载差转为正，矛盾。公共平移两私有背景不改变谱；交换标签得到背景差−δ、\(\max\Delta\le Q\)且等号当且仅当YES。

整数源所有闭支持点额外分母至多k−1，单混合连续片端点是整数，所以NO时镜像极值满足\(Q-\max\Delta\ge1/(k-1)\)。这是**数值**间隙，不是按源位长逆多项式的gap。

三地点正倍率构造需要Q/W、δ/W小。可在原SUBSET SUM中补固定多名正数K+1（大于目标，不能进入解），再编码。n超过只依赖固定a及守卫常数的阈值后，两比例任意小。补数数量与源实例无关、单个补数位长O(log(K+1))，仍是多项式归约；显然的源边界可直接处理或保留局部编码。

## 三地点a=1：六类在轨布局的精确守卫

用局部源的W,δ,Q，目录为{A,B,C}。设

\[
x=(W+\delta-Q)/2,\quad c=(W+\delta+Q)/2,
\]
\[
u=(W-\delta+3Q)/2,\quad v=2Q,\quad z=(W-\delta+Q)/2.
\]

两名AB共同客户各重x，一名AC客户重c，BC硬群保原权；A/B/C各有私有客户u/v/z，无客户覆盖三地点。由W>δ+Q全正，乘2即整数。reach为

\[
R_A=R_B=M=2W+\delta+Q,\quad R_C=N=2W+Q<M.
\]

BC私有背景为\(W+\delta+Q,W+Q\)，谱恰为\(\mathcal D\)，总收益\(V=3W+\delta+2Q\)。令

\[
k=M-x=(3W+\delta+3Q)/2,\quad
h=M-c=(3W+\delta+Q)/2=(V-Q)/2=V-k.
\]

AB两共同客户等重且两私有背景相同，全部NE的**收益**都是(k,k)，并不要求策略唯一。AC唯一共同客户严格选较小reach的C，收益为(h,N)。BC收益为\(((V+\Delta)/2,(V-\Delta)/2)\)。三个异址对及反射均已列尽，且

\[
N>k>M/2,\qquad h>N/2.
\]

记\(\mu=\min_{\Delta\in\mathcal D}(V+\Delta)/2\)。极值存在、达到，由(L)知\(\mu\ge h\)且等号当且仅当YES。

| 在轨类 | 排除或允许的全部NE论证 |
| --- | --- |
| AA | 较低收益家≤M/2，去B后在AB每个NE得k>M/2 |
| BB | 较低收益家≤M/2，去A后在AB得k>M/2 |
| CC | 较低收益家≤N/2，去A后在AC得h>N/2 |
| AB | B上设施去C，在AC得N>k |
| AC | A上设施去B最低可惩罚收益μ；其他异址偏离得k<N，同址偏离可对半，N/2<h、M/2<N；故可稳定当且仅当μ≤h |
| BC，源NO | B收益x≥μ>h，故C收益V−x<V−h=k；C上设施去A，在AB必得k |

源YES时AC可稳定，分别指定实际偏离的NE，其余布局补任意客户NE即可；源NO时六个无序类全部严格失败，反射覆盖全部九个带标签布局。没有将局部μ当作全局归约本身，也没有假定同址在轨收益均分。

## 三地点固定1<a<σ：改变reach顺序后的守卫

固定有理\(1<a<\sigma=(1+\sqrt3)/2\)，取有理\(1<\beta<1/[2(a-1)]\)。定义

\[
J=\frac{a(W-Q)}{2(a-1)},\quad R=J+\delta/2,\quad L=J-\delta/2,
\quad V=2J-W,\quad m_0=(V-Q)/2,
\]
\[
k=\beta W,\qquad h=m_0/a.
\]

一名AB客户权R−k，一名AC客户权J−h，BC硬群不变；三私有权为

\[
P_A=k+h-R,\qquad P_B=k-W,\qquad P_C=h-\delta/2-W.
\]

reach恰为\((R_A,R_B,R_C)=(J,R,L)\)，R>J>L。BC私有背景为R−W、L−W，差为δ，原全部谱保留。AB单公共客户选较小reach的A，收益(J,k)；AC单公共客户选C，收益(h,L)。关键恒等式是

\[
J=a(V+Q)/2,\quad V-m_0=J/a,\quad ah=m_0.\tag{T3}
\]

正权与守卫不能只由试算猜测。令q=Q/W、d=δ/W趋0；三个私有权除W的极限依次为

\[
\beta-(a+1)/(2a)>0,\quad\beta-1>0,
\quad1/[2a(a-1)]-1>0.
\]

最后一式等价于a<σ；两个共同客户权的极限也正。所需全部严格条件为

\[
L>ak,\quad L>aJ/2,\quad J>aR/2,\quad m_0>aL/2,
\]
\[
L/2<m_0,\quad J/2<aL,\quad k<aL.\tag{G3}
\]

首式极限余量是\(a(1/[2(a-1)]-\beta)>0\)；第二/三式用a<2；第四式余量\((2-a^2)/[4(a-1)]>0\)，因为σ<√2。第五/六式用a<2和a>1；第七式已由L>ak、a>1推出。有限个有理严格不等式的极限余量全正，故补足固定多名源整数可使它们同时成立。所得常数位长只依赖固定a、β；统一清分母的位长为源位长多项式。

BC中B的最小收益仍记μ，由(L)有\(\mu\le m_0\iff\)YES。源YES在AC的唯一NE(h,L)在轨：A去B选择达到μ的BC续局，A去C同址对半得L/2<m₀；C去B在AB得k<aL，C去A同址对半得J/2<aL。两类有序偏离布局不冲突，可补全规则。

源NO的全部类为：

| 在轨类 | 对任意续局有效的严格偏离 |
| --- | --- |
| AA | 较低家≤J/2，去C后在AC得L>aJ/2 |
| BB | 较低家≤R/2，去A后在AB得J>aR/2 |
| CC | 较低家≤L/2，去B后在BC每个NE得至少μ>m₀>aL/2 |
| AB | B上设施得k，去C后在AC得L>ak |
| AC | A上设施得h，去B后在BC得至少μ>m₀=ah |
| BC | B收益x≥μ>m₀，C收益y<V−m₀=J/a；C上设施去A，在AB必得J>ay |

六类及反射覆盖全部九布局。此证明只给DECₐ的YES/NO，不额外声称三地点YES的精确最优恰为a。

## 三地点两种具体模板为何停止

来源还保留被更强归约取代的第一种正倍率模板。它是理解预算障碍的独有数学，不删除为“旧路线”。设a₀>1满足\(2a_0^3-2a_0-1=0\)。固定1<a<a₀，取有理t满足

\[
\max\{(2-a)/(2a-1),a-1/2\}<t<\frac{2-a^2}{2(a^2-1)}.
\]

置K=tW、R=W+K+δ、L=W+K、V=W+2K+δ、T=(V−Q)/2、k=a(V+Q)/2、h=T/a。两名AB客户各重R−k，一名AC客户重R−h，BC群不变，私有权为

\[
P_A=2k+h-2R,\quad P_B=2k-R-W,\quad P_C=h-\delta-W.
\]

reach为(R,R,L)，AB全部NE收益(k,k)，AC收益(h,L)，BC仍是背景差δ的全部谱。前述固定补数使Q/W、δ/W足够小后，除全正权外还有

\[
L>ak,\ k>aR/2,\ T>aL/2,\ K+\delta>Q,\ R/2<aL.
\]

这些正余量包括\(P_B/W\to a(1+2t)-2-t>0\)、\(P_C/W\to(1+2t)/(2a)-1>0\)、\((L-ak)/W\to1+t-a^2(1+2t)/2>0\)、\((T-aL/2)/W\to[1+2t-a(1+t)]/2>0\)。\(P_A/W\to(a+1/(2a))(1+2t)-2(1+t)>0\)：在a=1它为t−1/2>0，并随a≥1严格增加。R−k>0跟随R>L>ak>k，R−h>0由2aR>V−Q。t区间非空的关键条件为\(2a^3-2a-1<0\)，另一个条件\(3a^2-2a-2<0\)在a<a₀<6/5自动成立。

YES在AC可取μ≤T=ah并用同址对半；NO的AA/BB以k>aR/2守卫，CC以μ>T>aL/2守卫，AB偏C得L>ak，AC偏B得μ>ah，BC的C收益<V−T=k/a而偏A得k。故同样排尽六类。只是此区间已被上一节覆盖。

此模板继续微调必须同时满足P_C>0与L>ak，即

\[
R>\frac{(2a+1)(W+\delta)+Q}{2},\qquad
R<\frac{a^2(W-Q)+(a^2-2)\delta}{2(a^2-1)}.
\]

上界减下界乘正分母后的分子为

\[
-(2a^3-2a-1)(W+\delta)-2\delta-(2a^2-1)Q.
\]

当a≥a₀、δ≥0、Q>0严格为负，所以**这个AB双等重模板**无法延伸。

更强的R>J>L模板中

\[
P_C=\frac{[1-2a(a-1)]W-(2a-1)Q-a(a-1)\delta}{2a(a-1)}.
\]

a≥σ时为负。即使在同一覆盖和阈值编码\(J=a(V+Q)/2\)下移动中间reach，写z=J−L∈(0,δ)，对应分子为

\[
[1-2a(a-1)]W-(2a-1)Q-\delta+2z[1-a(a-1)].
\]

它对z仿射，端点分别为\([1-2a(a-1)]W-\delta-(2a-1)Q\)及\([1-2a(a-1)](W+\delta)-(2a-1)Q\)，均负，故该调整也无效。两个障碍均只限制具体覆盖/角色/阈值守卫，不是一般模型算法、不能证明σ以上易解，也不排除更多地点或新守卫。

## 五地点：固定亚黄金比的有效参数

五地点构造与前三地点路线不同，保留覆盖四地点的中心宏客户，再通过桥宏原子把镜像局部源放进硬边。对固定有理1<a<φ，令e=2⁻ʲ，试

\[
r_2=a+e,\quad r_3=\max(1,ar_2/2)+4e,
\quad r_4=\max(1,r_2/a,ar_3/2)+e.
\]

所需严格条件为

\[
1<r_4<r_3<r_2<r_{10}=1+1/a,\ r_2>a,\ r_2>ar_{10}/2,
\]
\[
r_3>ar_2/2,\ r_4>ar_3/2,\ ar_4>r_2,\ ar_4<2,
\quad r_2+r_3+r_4<4.\tag{G5}
\]

为何试探必停：e→0的极限为a、b=max(1,a²/2)、c=max(1,a³/4)。b<a<1+1/a由a<2及a²<a+1给出。a>√2时c<b；a<√2时充分小e有r₃=1+4e、r₄=1+(1+1/a)e，仍r₃>r₄。有c<2/a：c=1时a<2；c=a³/4时a⁴<φ⁴=3φ+2<8。又

\[
a+b+c<\phi+\phi^2/2+\phi^3/4=2\phi+3/4<4
\]

（φ<13/8）。其余严格下界由各max加正e、a>1得到；因此充分小有理e同时满足全部条件。a是固定常数，搜索与所得位长不依赖源输入。

固定

\[
\eta=\tfrac14\min\{1,(r_{10}-r_2)/(1+1/(2a)),2-ar_4,r_4-1,
(4-r_2-r_3-r_4)/3\}>0.
\]

将局部群权W₀、背景差d₀、阈值Q₀同乘\(\lambda=\eta/(W_0+d_0+Q_0)\)，使用背景差−d的镜像源；W=λW₀、d=λd₀、Q=λQ₀，W+d+Q=η。定义

\[
H=1-W-d,\quad T=(H+1-Q)/2=1-\eta/2,\quad v_1=T/a,
\]
\[
v_2=r_2-H,\quad v_3=r_3-H,\quad z=r_4-1+d,
\quad P=1-v_2-v_3-z-W.
\]

| 客户类型 | 权重 | 覆盖的1起始地点 |
| --- | --- | --- |
| 中心宏客户 | H | 1,2,3,4 |
| 1私有 | v₁ | 1 |
| 第二叶 | v₂ | 2,5 |
| 第三叶 | v₃ | 3,5 |
| 桥宏客户 | z | 4,5 |
| 5私有 | P | 5 |
| 显式缩放局部群 | 总重W，各原重乘λ | 4,5 |

reach为\(R_1=H+v_1,R_2=r_2,R_3=r_3,R_4=r_4,R_5=1\)。这里

\[
H>1-\eta\ge3/4,\quad
P=4-r_2-r_3-r_4-3(W+d)>0,
\]
\[
R_1=r_{10}-(W+d)-\eta/(2a),\quad
R_1-r_2>\tfrac34(r_{10}-r_2)>0.
\]

因此全正权且R₁>r₂>r₃>r₄>1、R₁<2；另有

\[
v_1>v_2>v_3>0,\quad z-d=r_4-1>W,\quad T>ar_4/2,
\quad av_3<av_2<T.
\]

这些由η中相应四分之一余量给出，不能只通过有限参数试验替代。中心宏原子保留，未将全体客户稀释成微客户；故不与已整理的原子粒度必要条件冲突。

## 桥宏原子的双向消元与十种异址NE

一般布局有权z的一个公共宏客户、其他公共客户总重W，独占背景差δ>W。宏客户若纯1，则\(\Delta\ge\delta+z-W>z\)违反NE；若真正混合，其无差异式消去自身贡献，得到\(0=\delta+\sum_{\rm micro}w_i(2p_i-1)>0\)。故全部NE中宏客户纯2。

反向也必需：删宏客户、给第二背景加z，任一缩减NE扩回p_z=0后
\(\Delta=\delta-z+\sum_{\rm micro}w_i(2p_i-1)\ge\delta-z-W>-z\)，宏客户严格愿选2。因此原NE与缩减NE一一对应。δ=W不能使用：A=1,B=0，公共权(3,1)，概率(1/2,0)给负载(5/2,5/2)，宏客户真正混合。

除(4,5)外，所有有公共客户的异址对只有一个公共原子，严格选较小reach一侧；其条件成本就是各地点完整reach，故NE收益唯一。十个异址无序对全部为

\[
(i,j),\ 1\le i<j\le4:\ (v_i,R_j);\quad
(1,5):(R_1,1);\quad (2,5),(3,5):(H,1).
\]

(4,5)的独占背景差为z−d>W，桥z被强制去5；缩减背景为H、1−W，差−d，全部NE恰是镜像局部源。定义地点5真正最小收益

\[
\mu=\frac{H+1-\max\Delta}{2}\ge T,
\quad\mu=T\iff\text{YES},
\quad\text{NO}\Rightarrow\mu-T\ge\lambda/[2(k-1)]>0.
\]

每个硬边NE还都有\(L_4\le H+W=1-d<1\)。μ是分析量，归约算法不求它；全部坐标极值因完整闭谱而达到。

## 五地点YES完整续局与NO全部十五类

源YES在轨取(1,4)，唯一NE收益(v₁,r₄)。第一设施去2、3、4、5时分别指定收益v₂、v₃、r₄/2、T，均≤av₁=T（同址用对半）；第二设施去1、2、3、5时分别得R₁/2、r₂、r₃、1，均<ar₄。两个实际偏离族的有序布局不冲突，其余布局独立补精确NE，得到完整a稳定规则。

补默认NE不用oracle：公共客户按权递减放到当前较低背景负载一侧，给纯NE。任取一侧最后加入的公共客户权w，该侧最终负载减另一侧最终负载≤w；这侧更早客户均更重，故也无改善。不存在公共客户的一侧无客户检查义务。

## 位长、NO间隙、NP成员性与“弱”

源五进制数位O(源客户数+输入位长)，显式微客户数线性。固定a后的守卫数/η是常数，其余有理运算为多项式次且位长多项式；LCM的位长至多所有分母位长之和。统一正缩放保持任一NE、收益比和完整续局量词，得到正二进制整数输入。

五地点源还给可核算的严格gap。设γₐ为下面九个正数的最小值：

\[
r_2-(a+1)/2,\ r_3-ar_2/2,\ r_4-ar_3/2,
\ T-ar_4/2,\ r_2-a/2,\ r_3-T,\ r_4-T,
\tfrac{3a}{4}(r_{10}-r_2),\ r_2-a.
\]

T=1−η/2也只依赖a；这些数控制十四种非门控类的加性margin。任一在轨单方收益<R₁<2，NO的门控margin至少λ/[2(k−1)]，所以

\[
\alpha^*(I)\ge a+\tfrac12\min\{\gamma_a,\lambda/[2(k-1)]\}>a.
\]

λ可随二进制源输入指数小；该式不能推出固定常数或逆源位长gap，也不能据此单独排除FPTAS。[四地点精度间隙](../定理/四共同地点实例最优倍率的无FPTAS间隙--定理.md)使用另一种机制。

对任意固定有理a≥1，DECₐ属于NP。证书是在轨布局/NE，加每个实际单方偏离布局的NE，共O(|S|)个profile；未出现的布局可用上述纯NE独立补齐。固定每个profile的纯/名义混合支持后，条件成本、概率域[0,1]及设施\(L^{dev}\le aL^{on}\)是有理线性约束。实证书给一个非空有界有理多面体，存在多项式位长有理顶点。名义混合允许退化端点仍满足NE，零收益直接用乘法不等式，不丢严格/零概率边界。故有显式多项式长度有理证书及精确验证。

正整数全体客户总重Bₜₒₜ时，[DP-W](../算法/两设施均衡谱的阈值动态规划与权类参数化--算法.md)按重前缀和(m,z)状态在每布局\(O(n^2B_{tot}+n\log n)\)次有理运算求全部谱，状态z是数值整数和。取各真坐标极小值及全目录威胁，按每负载片最小化\(\max\{1,D_1/x,D_2/(V-x)\}\)，只需把\(VD_1/(D_1+D_2)\)夹到区间。也可用已证[同址正规形](../算法/同址平衡正规形与异址交叠参数精确优化--算法.md)省去同址支持枚举。所有中间位长多项式，状态数按Bₜₒₜ而非logBₜₒₜ，得伪多项式精确全局算法；有理输入清分母的数值总重可能指数大。这与两个NP困难归约合成“弱NP完全”。
