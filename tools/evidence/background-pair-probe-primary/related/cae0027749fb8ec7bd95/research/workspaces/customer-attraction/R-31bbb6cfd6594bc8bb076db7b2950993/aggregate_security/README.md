## 首两人安全支付候选（未证明）

固定一个合法沉没前缀背景b，剩r≥2人，v_r(b)是竞争元组不观察随机查询的真正静态混合安全值。候选是续局实际首两人收益和≥2v_r(b)。若对全部这样的子博弈成立，沿实际路径按相邻两人分组，利用背景嵌入v_(r−1)(b+1_A)≥v_r(b)及末位最佳回复，即得W≥m v_m(0)。这个配对推论是条件推论，前提仍OPEN。

`background_pair_probe.py`生成给定非负整数客户重数下的一个完整有序历史SPE：逐节点精确整数公倍数收益逆向归纳，完全相等时随机选。随后保留该形式策略的全部真实节点偏离Γ行，在非负客户质量锥内交替：(a)固定查询p，用LP最大化安全下界，归一化首两人收益和为1；(b)在所得客户质量上重新求真正静态安全零和LP。相同系数行仅去重；有序历史动作并未匿名化。LP部分浮点，因此仅为发现性数值筛查，不认证一般候选、固定策略整个锥或任何全局最优。
