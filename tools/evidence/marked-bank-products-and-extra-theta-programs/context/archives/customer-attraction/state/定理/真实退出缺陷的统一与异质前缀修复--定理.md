# 输入、真实菜单与两条不同精确结论

采用[完整有序历史共同目录模型](../定义/共同目录完整历史模型--定义.md)：有限单位客户、有限非空真实集合目录，m≥2名单位玩家，保空主题/重复行动/零收益和任意历史依赖平局。固定1≤j<m和完整目标z=(A₁,…,A_m)，只要求给出固定前缀(A₁,…,A_j)后的**完整纯SPE** π，实现目标尾；前j位不要求理性。令W为目标覆盖，O=OPT_m，u_i为目标最终利润，h_i=(A₁,…,A_(i−1))。

对每个i≤j和每个旧主题A（包括A=A_i），定义

\[
\ell_i(A)=\min_{\rho\in\operatorname{SPE}(h_i,A)}u_i(h_i,A;\rho),\quad
M_i=\max_A\ell_i(A),\quad \delta_i=(M_i-u_i)_+,\quad
D=\max_{i\le j}\delta_i,\quad R=\sum_{i\le j}\delta_i.
\]

极小范围是**真正完整后继SPE**，不是冻结目标旧尾；有限树使每个极值达到且有理，逐(i,A)固定达到极小的ρ_(i,A)。正常旧行动也要有此退出：产品中仅保险坐标变化时同样不能保留可能不可信的旧计划。

**统一修复。** 任取正有理s≥D，可构造同人数的有限共同目录和完整SPE，使旧坐标实际路径仍为z，且在共同整数缩放前精确有

\[
W'=W+(m+j)s,\qquad O'=O+(2m-1)s,\qquad
O'-2W'=O-2W-(2j+1)s.\tag{U}
\]

**异质修复。** 若D>0，可构造同模型完整SPE，精确有

\[
W'=W+mD+R,\qquad O'=O+(2m-1)D,\qquad
O'-2W'=O-2W-(2R+D).\tag{H}
\]

所有有理规模只是记账；用一个正整数L**同时复制旧客户和全部新客户**清分母，每项收入、W、O和差额整体乘L，客户/玩家仍单位、人数仍m。不能只放大保险而保留原u/δ。下面给全部承重构造；没有声称一般预算本身成立。

# 任意标记位置的银行及低退出全树

取非空标记I⊆{1,…,m−1}，k=|I|，d=m−k≥1，s>0。保险客户块两两不交：每个i∈I有银行B_i大小2s，蓄水主题Y大小ds，另有d−1个叶主题各s，目录恰m个块。正常路径在标记位置i选B_i，其余位置选Y；末位总是Y。正常利润标记2s、其余s，覆盖(m+k)s；m个动作把全部块各选一次，最优(2m−1)s。

**低退出引理。** 在任一正常前缀强制当前任一保险动作T（包括原正常动作），都存在剩余者完整SPE，使当前强制者最后保险利润≤s。以下除以s；设当前第i位，前面用p个不同银行、q次Y，p+q=i−1、q≤d−1。

已用银行再选的份额无论后续如何都≤2/2=1；叶总大小1，也无条件≤1。这些孩子任取完整逆向归纳(BI)续局。

若强制Y，进入Y-clean模式：银行各至多一次、叶未用、Y总数≤d。有空银行时规定选预定空银行，无空银行后规定Y。**改变空银行顺序或提前选仍未超cap的Y仍属clean**，不是退出。剩余人数等于空银行数加尚缺Y数，故clean终局每银行一次、Y恰d次；未来fresh银行收益2、Y收益1。空银行节点规定2，改另一空银行仍2，改clean Y得1。首个重复银行/叶/Y超d才退出，其当前raw利润已经≤1；在整个该孩子永久固定一份真正BI-SPE。无空银行的规定Y也得1，所有替代≤1。对子树深度逆归纳给每个clean节点和所有dirty孩子IC，最初强制Y最终得1。

若强制fresh银行F，进入F-clean模式：F保持一次，其他银行各≤1，叶未用，Y≤d−1；先填其他空银行，再填Y至d−1，最后一位复制F。当前强制后的剩余人数精确为

\[
(k-p-1)+(d-1-q)+1=m-i.
\]

不同fresh银行顺序和提前clean Y同样合法；fresh未来银行最终独占收益2，d>1时clean Y收益d/(d−1)∈[1,2]，最后复制F得1。空银行阶段改clean Y至多2；Y阶段已无空银行，任何dirty动作利润≤1；最后改Y得d/d=1，改任何旧银行/叶≤1。首个非末位重复、叶、Y超d−1的raw cap≤1，永久贴真正BI孩子。d=1时完全没有Y阶段，不写d/(d−1)，最后复制F的证明仍成立。逆归纳覆盖全部clean顺序和全部退出，F最终恰被复制一次，强制者得1。

任何退出后均**永久锁定**其BI模式，不能因后面计数重新满足clean条件而返回。证明用完整有序历史而非静态NE可实现性；每个first-exit可以分别选BI，不限制同负载历史的平局相同。

正常保险路径自身可信：在每个正常节点任何不同动作后贴低退出子SPE，正常银行得2、正常Y得1，偏离≤1；从后往前即得完整SPE。若I⊆[j]，固定正常前j位后银行已全用，规定以后**每个有序尾历史都选Y**也是真SPE：最终Y数至多(j−k)+(m−j)=d，当前规定收益≥1，银行重复或叶≤1；此论证包括此前尾玩家已偏离银行/叶的历史。

# 统一修复的全坐标首次退出与精确最优

统一版取I=[j]，d=m−j，正常保险路径B₁,…,B_j,Y^d。新目录为全部旧A与保险T的Cartesian并集，客户宇宙不交；行动仍是实际集合，不是允许临场改变组件权重的虚拟接口。

正常第i≤j位规定(A_i,B_i)。第一次**任意联合**行动(A,T)不同后，整张未来子树永久取旧ρ_(i,A)与相应保险低退出L_(i,T)的积。A=A_i仅改保险、T=B_i仅改旧主题，以及两者同改都包括。规定收益u_i+2s；偏离真实收益≤ell_i(A)+s≤u_i+D+s≤u_i+2s。若前j位全正常，之后用输入π与全Y尾SPE的积。

进入永久产品模式后每个坐标只读各自投影的后继有序历史；后来联合偏离收益差是各坐标真正IC差的和，分别≤0，且当前偏离擦不掉首次模式。正常节点再逆归纳即覆盖完整产品树。不是只验逐坐标偏离，也不是强留原不可信离轨表。

保险正常覆盖2js+ds=(m+j)s，保险所有m个不交块总客户(2m−1)s。产品任意m元组的各投影≤各自最优；反向取旧最优m元组与保险m个块按槽配对，完整Cartesian目录允许同时实现两个最优。故O恰相加而非只有一个方向，得到(U)。

# 异质分层的单一固定产品

取不同正δ高度0=e₀<e₁<…<e_L=D。第l层厚度s_l=e_l−e_(l−1)>0，标记I_l={i≤j:δ_i≥e_l}。这是**一个固定新实例中的有限组件**，不是随历史修改的客户权重；每层都有刚证的任意位置bank。精确层积分为

\[
\sum_l s_l=D,\quad
\sum_{l:i\in I_l}s_l=\delta_i,\quad
\sum_l|I_l|s_l=R.
\]

旧坐标与各层取完整Cartesian并集目录。正常早期i保险收益D+δ_i，真尾每位D。首个联合异常(A,T₁,…,T_L)后，**所有坐标含未改者**永久进入ρ_(i,A)与各层低退出的积；偏离利润≤ell_i(A)+Σs_l≤M_i+D≤u_i+δ_i+D，正好由正常收益支付。前j位全正常后用π和每层全Y尾。永久模式和后续产品IC同统一版，故仍为完整SPE。

W_ins=Σ(m+|I_l|)s_l=mD+R，O_ins=Σ(2m−1)s_l=(2m−1)D，OPT精确加法由逐槽配对每层最优给出，得到(H)。这保留了标记可穿插、先Y后某个bank的合法性；仅检查前j个连续bank不足以证明异质版。

# 零端点、等价量词与当前五人推论

D=0时不建立零大小银行。由输入真尾开始，从i=j逆推到1，保留正常动作及已经修好的正常孩子；其他旧行动贴ell极小真孩子，偏离≤M_i≤u_i。旧路径z本身成为完整SPE。这也处理零客户，毋须取正尺度极限。

对固定m≥2、固定合法j，HALF(m)与“全部本合同输入满足O−2W≤(2j+1)D”等价；同样与“全部满足O−2W≤2R+D”等价：违反预算经编译出严格half反例；反向对任一实际SPE取其真尾，D=R=0，预算即half。该等价不证明一般一边。跨所有m可以量化所有合法j，或每m指定任意j(m)∈[1,m−1]；固定数值j只涵m≥j+1，不能偷带较小人数。j=m−1只需原末位BR，j=1复得旧root损失3D。

R≤jD，故异质成本≤统一成本；一个孤立正缺陷成本3D，全j个相等时成本(2j+1)D。它不是所有修复器成本最优性：后来[双侧signed修复](双侧有符号缺陷的真实供给修复与有限字典最小性--定理.md)保留负g并给更广合同，有限字典LP最小性亦不能倒填本稿。
