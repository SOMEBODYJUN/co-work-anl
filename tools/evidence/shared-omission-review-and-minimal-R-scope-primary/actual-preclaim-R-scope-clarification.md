# 环菜单的严格排序与最小反例R域

原件 `6a6fc00f223d8a624898` 5544B：§2的(R)要求每个后继最终收益≥t=v₄(0)>u；§3全k≥7环构造先只核后继3/2>u=1。这里不把严格排序自动替换为完整R。

给k≥7，单位客户e_i、题A_i={e_(i−1),e_i}，根i指定终局(A_i,A_(i−1),A_(i+1))。根1，两后继各3/2；均匀查询对任意三竞争题用整数负载总和6和1/(1+c)≥1−c/2得v₄≥2−6/k。三个不交题(A₀,A₂,A₄)的均匀旋转，使每个纯query也恰得2−6/k，故等号。

于是
\[
 3/2\ge t=v_4=2-6/k\quad\Longleftrightarrow\quad k\le12.
\]
在7≤k≤12，u1<t且两后继≥t，所以完整数值(R)成立。Mfull≥真正v₄>u，已经足够否定“任意菜单满足R⇒Mfull≤u”的无SPE松弛，无须把全k都称R实例。k≥13时v₄>3/2，后继不足t，只有较弱的后继>u排序成立。

现有《缺少尾部理性的环边阈值扩展障碍》用n≥13、另取t=3/2≤v₄，正确反驳其更弱的“存在t≤v₄且尾≥t”组合桥；它未声称取t=v₄，所以不改该旧页。两段取t方式必须分开。

同一给定根菜单的列负载有2客户c2、2客户c1、其余c0。均匀query的每列价为(2/k)[k−4+2/3+1]=2−14/(3k)，均匀旋转列对每query同价，因此Mfull也等于该值。此处按同一会员结构解析重构，非新增优化器或枚举运行；原5544B只用Mfull≥v₄已足够。

所有这些菜单都非SPE：历史(A_i,A_(i−1))后规定末位A_(i+1)得3/2，真实改A_(i+3)得2。参数k≥7保证不交。这不能成为原extra-one或half的真实反例。当前银行真SPE已另反一般extra-one/Mfull，原最小r条件归约本身仍正确；原稿未给完整R的全k范围不应被新正文照抄扩大。
