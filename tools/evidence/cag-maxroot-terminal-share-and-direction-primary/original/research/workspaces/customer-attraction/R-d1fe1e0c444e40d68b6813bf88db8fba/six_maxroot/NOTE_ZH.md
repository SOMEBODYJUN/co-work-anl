## 系数证书与核验

每份 JSON 给所有非零乘子 λ≥0，并满足 PAIR/LAST 乘子和为 1。对每种客户成员位 ω，核验器重建上述原始均分系数 `Gj(ω,o)`，其中最优覆盖位 o 取 0、1。它逐项核验

`B·vT(ω)+C·1T(ω)−o = Σj λj Gj(ω,o)+ρ(ω)`，`ρ(ω)≥0`。

在全客户求和后加上 `B(r−vT)≥0`，即得目标不等式。最优覆盖位的消去被另行核验，故没有隐藏最优主题成员位假设。

`verify.py` 仅用 Python 标准库，不导入 `discover.py`、SciPy、NumPy 或浮点恢复器。所有判号使用清分母后的 Python 整数。前四条各覆盖全部 8192 型，后三条各覆盖全部 32768 型；最小整数余项均为零。每个 JSON 还可由 `recover.py` 从发现记录在有理网格上向外修复，但该过程不是核验证明的依赖。
