# R-171 接续工作区主张边界与开放义务

## 稳定身份与来源

- `R-171cd7d518434f36a48cd50df29c9303` 是 `customer-attraction` 存档下的个人研究工作区；本页合并审读的冻结来源为 `b3335acda0d4782bca24`（`CLAIMS.md`）、`5d94d9ce945202efcf2f`（根 `README.md`）、`9022a7d09f082f7bf7de`（接续 `CLAIMS.md`）、`d7b01fbdd33968bc5544`（接续 `README.md`）和 `83e372de07df77beb979`（coupling `README.md`）。原文 SHA/大小见 `R-171-coupling-20261031/original/`。
- 所有来源明确采用原 CAG-MODEL：单位客户、共同有限目录、任意有序历史、历史依赖平局；研究目标是完整纯 SPE 的 `2W >= OPT`（Q-CAG-HALF）。这些来源都把该目标标为 **OPEN**，没有声称共享 canonical、外审或新颖性认证。

## 实读后的数学对象与关系

1. **不是主目标反例的负面桥。** `B5-OPTIMAL-OMISSION-EXISTENCE-NO-v1` 给出二人和一般 `k>=3` 的完整 SPE 族，其中唯一最优无序主题集合的遗漏 `U` 可大于 `W`，因此不能把“选择一个有利最优组合并支付其遗漏”当作普遍桥。它仍有正的原 half 余量，不构成 `2W<OPT`。
2. **早期菜单缺陷。** `B5-EARLY-MENU-LOAD-DEFECT-v1` 精确定义实际中继负载缺陷 `epsilon` 及扣除真实末位激励松弛后的 `delta`。价格上界和 `delta<=epsilon` 有条件地成立；没有全局支付 `delta` 的一般预算，故不能删去该项或把局部零缺陷条件推广为定理。
3. **窗口租金与完整 SPE 稀疏障碍。** `B5-PATH-INTERVAL-RENT-v1`、`B5-SPARSE-RENT-COMPLETE-SPE-NO-v1` 和 `B5-CHRONOLOGICAL-RENT-DECOMPOSITION-v1` 分别给出连续窗口的根预算、两个单例客户的完整 SPE 稀疏族、以及 reset/clock/skip-premium 的精确关系。后者说明即使路径来自完整 SPE，稀疏槽位也不能自动得到根支付；发散可能全部藏在 skip-premium。
4. **固定人口 pair 仅是局部接口。** `B5-FIXED-POPULATION-PAIR-ERROR-v1` 将特定 `r,s` pair-circuit 误差压到三活跃项，并可接到窗口预算；短终局值不是任意真实续局的激励值，因此尚未连接到全树 SPE。
5. **POOL 只给条件恒等式。** `B5-POOLED-RESPONSE-LOAD-INTERFACE-v1` 的 Jensen 余项分解是精确的；`W>=mP` 若另行成立则推出自由分数安全值上界，但这个 POOL 预算本身未证。逐客户条件也不是一般 SPE 自动性质。
6. **有符号查询缺陷的边界。** `B5-SIGNED-DELTA-ALL-QUERIES-NO-v1` 否定“任意查询/任意最优组合都能付清”的加强命题，但保留有利最优组合版本；`B5-QUERY-OVERLAP-RESIDUAL-v1` 把真实 slack、重复查询信用和 `tau` 余项写成可检查的标量不等式，仍没有全局支付。
7. **静态校准不得偷换模型。** 弱 CCE、POOL 及低相关混合只是在具体族上的校准。它们不证明一般弱 CCE 桥、一般 POOL 桥，也不降低 Q-CAG-HALF 的开放状态。

## 证据与可接续方式

- 根 README、两份 CLAIMS 和 coupling README 互相指向同一组对象；没有发现将旧摘要升级为新定理的冲突。主要独有内容是：完整 SPE 稀疏族、clock 与 premium 的区分、以及对“最优遗漏/任意查询”加强桥的反例边界。
- 后续工作应在原策略的真实偏离不等式中构造 clock 费用，或用真实激励松弛、带符号抵销支付 skip-premium；不能仅因根路径来自 SPE 就删除稀疏跳过造成的分母差异。
- 本页是审查/路线页，不把有限脚本、负面桥或静态校准升级为 `2W<OPT`、一般算法、hardness 或完整证明；不迁移到 `unrelated-machines`。
