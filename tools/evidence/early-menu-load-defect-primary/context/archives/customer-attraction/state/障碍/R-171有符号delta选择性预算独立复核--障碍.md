# R-171 有符号 delta 选择性预算独立复核

## 来源与定义

本页合并 `f1b5ba2be30875a41ff3`（独立 exact replay 脚本）、`d484154b4c11051915bb`（冻结输出 JSON）和 `c67d06a4b3d29de8f735`（父方独立复核文档）。原文证据与 comparison notes 位于 `R-171-parent-delta-20261031/`。对象是旧 13 人、36 客户、六主题完整纯 SPE；实际路径为 `P^10 A A B`，`W=33`、末位收益 `w=3`、`OPT=36`。

对每个实际非末位 `i` 使用同一个查询分布 `mu` 的有符号中继缺陷 `delta_i(mu)`。早期价格恒等式与末位回复平均可给出充分预算
\[
 \sum_{i<m}\delta_i(\mu)\le (W+w)/(2m)=18/13,
\]
但该预算不是早期价格引理本身的结论。

## 精确失败机制

父方独立从每条边的真实 count 增量和指定动作重建终局，核对 27,243 个节点和 112,050 个历史收益比较；没有使用 desired/expected 缓存。对纯查询 `mu=delta_T`，前十个非末位的 `delta_i=1/2`，后两个为零，故
\[
 \sum_i\delta_i=5>18/13,
\]
差额为 `47/13`。

这不是“每个位置各自挑最坏查询”的伪失败：对全部 2,002 个达到 `OPT=36` 的允许重复主题多元组用同一个 `mu` 穷举，最大总 delta 为 `1373/507`，仍高出预算 `671/507`；最小值为 `-38375/5577`，全目录均匀分布为 `7/132`。因此“任意最优比较组合均可支付”被否定，而“存在有利最优组合”的选择性版本仍未被否定。

## 依赖、边界与用途

脚本需要外部冻结的 `R-c50fecc37aa44fb4a69a2122bb70e5fe/security/refined_tax_k10_packet.json.gz`；本批没有把该未随源文件提供的依赖冒称为重新执行。冻结 JSON 已保留节点数、比较数、客户数、路径、最优组合两端和整数化总矩阵，足以复核报告算术。

这是一个针对中继缺陷预算加强命题的精确障碍，且主目标余量 `2W-OPT=30` 仍为正；不能升级为六人目标的反例或一般 Q-CAG-HALF 不可能性。后续需要选择性最优组合、保留真实客户余项/激励 slack 或另一种全局支付机制。
