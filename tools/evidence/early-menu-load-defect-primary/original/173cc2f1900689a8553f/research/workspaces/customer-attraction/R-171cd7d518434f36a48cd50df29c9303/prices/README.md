* `early_menu_load_defect.md`：B5-EARLY-MENU-LOAD-DEFECT-v1。任意早期当前玩家与
  实际末位之间可以有任意数量真实适应中继。通过显式有符号二次负载缺陷 ε(μ)，
  精确修复末两人价格消元；统一折算价 v+max ε 继承末位参数包络。
  更强净缺陷 δ(μ)=ε(μ)−真实末位平均slack，支持更低折算价 v+max δ。
  中继客户总负载不变时缺陷为零；仅卸载时有四分之一范围上界。
  仅卸载时又有 ε≤3P_M/8 的实际中继利润支付；一般缺陷支付未解，尚待独立审查。
  根实际节点给 OPT≤W+(m−1/2)u_i+mε_i，因而某最低收益玩家的中继负载
  跨其全部偏离不变时，有全人数半覆盖的结构推论。另有逐客户“所选主题不增拥挤，
  末位会员与中继负载同向排序”的零缺陷充分条件，允许非恒定负载。
