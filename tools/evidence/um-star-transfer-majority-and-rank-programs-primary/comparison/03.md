# 1. 三个对象必须分开

本批包含三个不同层次的数学对象。高阶负相关来源延伸私有汇点最优凸包边际族，研究固定边际随机输出在所有同汇点正事件上的阶数 d 上限；两状态多数来源研究复制束删除后的状态内不交资源；鲁棒环来源研究给定严格实际调度背景下，双端环 core 的 phase 是否能被共享 context 读取。它们都与 unrelated-machines 研究相邻，但变量、量词和输出合同不同，不合并成一个主目标算法或困难性结论。

所有有限审计为 Fraction/整数、无随机 seed、无浮点容差。正文解析证明、独立审查和冻结 JSON 分开登记。`actual_success_probability`、`enumeration`、`passed` 等字段只支持列明有限范围，不能代替全称证明。

# 2. `UM-OPT-HULL-HIGHER-NC-SUCCESS-v1`

## 2.1 精确合同和阶乘矩上界

沿用私有汇点族：k>=2、r>=k，一个大任务 B 在 homes H_i 上时间 1；每组 k 个 small 只能在 H_i/Z_i 上时间 1/k；固定最优凸包点 x 由 r 个 OPT=1 调度均匀平均得到。随机合法完整调度 Sigma 保留 B 的 home 边际 1/r 和每个 small 去自身 sink 的边际 1/r。对每组 i、每个 `2<=|S|<=d` 的固定 small 子集 S，只要求

`Pr[所有 j∈S 都去 Z_i] <= r^{-|S|}`。

不要求补事件负相关、不同组相关、任务数保持或某种 dependent rounding。令目标 q∈[1,k]、`t=min(d,q)`，成功事件为 `C_max<=2-q/k`。由于若 B 在 H_h、D_i 是第 i 组送 sink 的任务数，则每态精确有

`C_max=2-D_h/k`。

对任意 `2<=s<=t`，成功强迫 `sum_i binom(D_i,s)>=binom(q,s)`；对合同求和得到

`E sum_i binom(D_i,s) <= binom(k,s)/r^(s-1)`。

因此成功率至多 `A_s=binom(k,s)/(r^(s-1)binom(q,s))`。相邻比

`A_(s+1)/A_s=(k-s)/(r(q-s))<=1`

用到 r>=k，所以最强阶是 t。与概率≤1 合并得到精确上界

`p*(k,r,d,q)=1`（t=1），否则 `min(1, binom(k,t)/(r^(t-1)binom(q,t)))`。

## 2.2 完整达到 law、边界和采样

取 p=p*，均匀选 B 的 home h。以概率 p 在 h 组送 q 个 small 到 Z_h，并从其它不同组各送一个；以概率 1-p 在 h 组送一个、其它 k−1 个不同组各送一个。其余 small 留 home。每态恰 k 个 small 去 sink，组与组内对称性给全部边际；固定组内 s-subset 的全送概率为 `(p/r)binom(q,s)/binom(k,s)`，由 p≤A_s 同时满足全部要求阶。q=1 或 d=1 的 t=1 分支必须直接取 1，不能误用形式上的一阶比值。

这是固定 x 的随机舍入合同，绝不表示一般随机调度困难。输出可重选 x、改变边际、采后重排或直接构造好调度时不受此界限。尤其本族本来就能直接取一个 S_h 得 OPT=1。

当 r=k²、d=k、q=ceil(epsilon k) 时，`p* = binom(k,q)/k^(2q-2) <= 2^k/k^(2epsilon k-2)`。完整矩阵和 x 的编码长度仅为多项式 k；任意固定输入位长多项式次数 B(L) 的 best-of-B samples 成功概率至多 `B p*`，趋于 0。这个 adaptive 结论需要每一轮给定全部过去历史后仍满足同一 x 和正事件 NC；若只知道每轮无条件合同，保留 union bound，不声称乘积界。d 固定时只得到有限阶概率边界，不能由此排除所有固定多项式次择优。

## 2.3 有限独立证据

# 3. `UM-DUPLICATION-STATE-MAJORITY-FLOOR-v1`

变量 x 各有两状态 a=0,1 的标签束，状态内保留资源束 R_x^a 两两不交。若对保留变量 Y 和 delta 定义 `G_a(delta)={x:|R_x^a|>=delta K_x^a}`，且 `G=G_0∪G_1` 非空，则某状态含至少 |G|/2 个好变量。选该多数状态、保留全部残余束，即得到真实根树

`b(H)>=min{|G|/(2 q_r), delta}`，

当根需求 q_r=|Y| 时为 `min{|G|/(2|Y|),delta}`；若每个变量至少一个状态好，则至少 `min{1/2,delta}`。证明只使用状态内不交和显式束大小，算法为计算大小、选多数和输出边，位复杂度总位多项式。

该地板的量词允许任意删叶/删变量，但不允许跨状态资源重用破坏状态内不交。它否定的是“只保留两份完整复制就能把每个残余比例同时降到零”的方法接口，不是一般 UM 的近二反面。

行列池的旧锐性声明曾错误地说任何合法树不能混合两侧；部分资源可分配给两侧。修复后精确前沿为

`max_{1<=k<=2s} min{k/(2s), h_k/K}`, `h_k=min{s,floor(s²/k)}`。

因此保留主多数下界，撤回过宽的整束冲突锐性。这个修复与本次审计的 `sharp fixture` 分开：冻结 JSON 的 34,389 个完整状态对和非空变量子集支持主地板有限核验，不证明所有 K 的最优性。

# 4. `UM-ROBUST-CYCLE-SHARED-CONTEXT-PHASE-v1`

## 4.1 对象和 Exact A

取 T>0、T<=B<2T。每个 core 有 n>=2 台彼此不交的机器 M_i 和 n 个 core 任务 j_i，j_i 恰在 M_i 上耗时 a_i、在 M_{i+1} 上耗时 b_i，均属于 [0,T]；不同 core 的机器/任务集彼此不交。context 可任意跨 core 机器和额外机器共享，但不能给 core 任务增加第三端。给定整个实例的一份严格 C_max<=T 实际调度 sigma；core phase 是所有任务取 home 或所有任务取 successor。

机器 M_i 的碰撞恰发生在前一任务取 successor、当前任务取 home，负载为 `b_{i-1}+a_i`。因此 core 在 B 下只有两个 coherent phase，当且仅当全部碰撞和严格大于 B。若有某个碰撞和≤B，单独翻前一任务就得到混合且 B-feasible 调度；反向由循环二进制字串必含 1→0 转折。

鲁棒时各端都大于 B−T，所以任意 phase 在该机的 old/new core load 差严格小于 `2T−B`。

## 4.2 Exact B/C 和锐包络

从 sigma 删除 context 后，每个 core 限制仍是 B-feasible，故必是一个 coherent phase。给任意显式 phase 向量 theta，把每个 core 任务改到对应原端，context 每件逐件留在 sigma 的原端。对一台 core 机，原 context load c 与 old/new core load x,y 满足 `c+x<=T`、`y-x<2T-B`，于是

`c+y<3T-B`。

不同 core 机器不交，所以这些逐机不等式可同时成立；额外机器负载不变。故同一完整实际 tau_theta 满足 `C_max<3T-B`，从而 B>=3T/2 时所有 phase 向量都 weak B-feasible。

三半阈值锐：对每个 B<3T/2，取两机两件 core 任务（端时间 T 与 T/2）和一件只在一台机器耗时 T/2 的 context。一个 phase 与 context 的负载为 (T,T)，反相位在该机器为 3T/2>B，无扩展。更精细地，对任意 0<e<2T-B，令 d=B-T+e，core 一任务两端 T、另一任务两端 d，context 唯一端 T-d；指定反相位的最小扩展峰恰 `3T-B-e`，故严格包络的上确界锐但有限实例不达到。

machine-disjoint 是承重域条件。若两 core 复用一台机器，T=1、B=6/5 的域外例可使各 core 单独鲁棒、低态背景 strict 可行，但同时切换的共享机负载 23/10>3T-B；这不是明确 theorem 域内反例。结论只针对给定 strict sigma、固定 context 原端和双端环 core，不给一般 UM phase decoder、近二 hardness 或 approximation algorithm。

## 4.3 有限证据

`a304a2379c86ebfd545d` 的 JSON 记录确定性显式 cases、7 个 local cases、shared-context 11 jobs/6 machines 的全部 32 个 core orientations、四个 targets、三半锐例、包络族、等号和 machine-overlap 域外反例，`all_assertions_passed=true`。代码实际逐任务检查 finite edge、全机 Fraction loads 和 phase 构造；无 core 分支靠正文解析证明，不把有限 audit 说成一般验证。

# 5. 跨仓比较和处置

1. 高阶 NC 延续《长链联合投影与最优凸包边际障碍》中的私有汇点 pair-NC：它只加强同 sink 正事件阶数，不改变固定边际、可重选 x 和直接最优解这些逃生口。高阶 p* 与两两期望界不可混写；补事件 NC 未承诺。
2. 两状态多数与行列池修复承接 duplication two-copy、bounded collision label 等方法；它不是 row-uniform 读出 3/2 正面子类，也不提供一般标签解码。
3. 鲁棒环的 shared-context 允许真实跨 core 共享背景，但要求不同 core machine-disjoint；不能把域外 overlap 例当成定理反例，也不能把三半 phase boundary 当成全局 UM gap。
4. 与 CAG/SPE 目标相比，本批没有客户目录、终局均分或 SPE 历史，保持 unrelated-machines 隔离；与 row-count/row-uniform 批相比，变量是状态束/环 phase/固定随机输出合同，独有内容分别保留。

处置均为 `integrated`：高阶 NC 的有限原子与 adaptive 量词写入第 2 节；两状态多数证明和修复后的行列池前沿写入第 3 节；鲁棒环 Exact A/B/C、sharp envelope、域外 overlap 和有限核验写入第 4 节。未将任何 finite JSON 升级为一般算法、NP-hardness、外部新颖性或 UM-TARGET-v1 完成。
