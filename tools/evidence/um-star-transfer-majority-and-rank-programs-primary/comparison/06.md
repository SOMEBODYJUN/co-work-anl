# 1. 可裁剪两状态行列池的精确前沿

稳定对象为 UM-TWO-STATE-POOL-EXACT-FRONTIER-v1。域为整数 s>=1、K>=s；有 2s 个变量和一个 s x s 的单位资源网格。前 s 个变量各只有一条行残余束，后 s 个各只有一条列残余束；所选标签可保留任意资源子集，所有标签保留的资源全局互异。目标分数同时取根覆盖比例、每标签资源数除以 K 和变量标签选择比例的最小值。

完整前沿为
\[
 b^*=\max_{1\le k\le 2s}
 \min\!\left\{\frac{k}{2s},\frac{\min\{s,\lfloor s^2/k\rfloor\}}{K}\right\}.
\]
上界来自每个标签至多 s 格、总资源至多 s^2 格；构造在 k<=s 时取满行，在 k>s 时取全部行与 k-s 列，并以 t=floor(s^2/k) 的循环分配先占列格、再逐行补齐 t 格。资源资格、父子关系和全局不复用均保留，K 只进入精确有理比较，不把隐式大网格的对数描述误算为显式输入。

s=K=4 的可行树取四行和一列、各标签取三格，得 b=5/8；这撤回了“必须整束所以至多一半”的附属锐性说法，但不撤回独立的多数状态地板。旧式 min(1/2,s/K) 在该域中只有受限正确范围：记录给出的精确刻画为 K>=2s-2；K<2s-2 时 k=s+1 已产生严格更大值。K>=2s 的高 K 数例仍分别给 s/K。

该对象不是一般两状态实例算法、近二硬度或六人 SPE 结论。与既有 duplication_state_majority_floor 审查的关系是：多数地板只用状态内不交和多数选择；本对象允许跨状态混取部分束，修正了“整束冲突”的错误外推。源中三套枚举/匹配/循环核验均以整数或 Fraction 记录，属于有限证据；正文承重是计数上界与循环构造。

# 2. 分块类型配置与真实匹配后端

本簇包含 UM-SC-BLOCK-TYPE-PROFILE-RECONSTRUCTION-v1 与 UM-NORMALIZED-TYPE-MATCHING-RANK-VALUE-IDENTITY-v1，对应现有类型压缩和 rank 编译对象。

## 2.1 分块压缩

输入是显式二进制有理 Santa Claus 估值矩阵，m>=1、n>=0、固定正有理 epsilon，资源可闲置。截断、tiny 删除、按固定几何网格向下舍入和按 type 分块后，每玩家输出有限 integer count-profile 菜单；profile 数量由共同块预算 H=ceil(4t/delta) 的 weak-composition 枚举控制，复杂度是固定 epsilon 下的输入位长多项式。n=0 旁路为空菜单和 OPT=0，不能代入 delta/(t a_k)。

审查确认：等于 cutoff 的值必须保留，grid 必须延伸到最小 a_K<=tau；块计数舍入损失与 tiny 加性损失分别支付，最终值下界为 1-3delta>1/(1+epsilon)。分块算法只生成菜单，不输入未知最优分配、不求跨玩家共同 profile、不判定原阈值。旧 Appendix B 的字面 cutoff 曾有反例，现行修复以 tau=delta/n（或等价安全比例）承担损失；该纠错不等于撤回主压缩合同。

## 2.2 归一化 profile 的真实 UM 恒等式

对非空玩家、非空 indexed profile 菜单和显式非负有理 type counts，定义
\[
 f_{ic}(B)=W(c)^{-1}\sum_v v\min\{c(v),N_{iv}(B)\},\qquad
 F_i(B)=\max_c f_{ic}(B),
\]
并令 V 为不交资源分配上最大化的最小 F_i。固定 profile 的 f_ic 是 weighted partition-matroid rank；max_c 一般不次模，四资源反例必须保留。

真实编译为每 profile 一台 private 机、每资源一点 unit 机、每玩家一枚 selector；所有 indexed profiles 的全部 token jobs 都实际存在，未选 profile 任务不能删除。任意不交 bundle 选达成 profile 并外送对应 tokens 给出峰值 2-F_i(B_i)；任意峰值 <2 的实际调度中，资源机至多接一枚 unit token，从 selector 所在 profile 的外送资源反构造不交 bundles。故
\[
 OPT_{\mathrm{UM}}=2-V
\]
在该完整域内成立，包括 V=0、OPT=2 和重复 indexed profiles；空菜单与 m=0 明确排除或走单独固定 OPT=2 退化分支。该恒等式不提供共享 profile 的全局算法，也不把 max-profile 变成次模 oracle。

## 2.3 接续边界

分块压缩与真实编译可在 Santa YES/另行给定 source gap 的承诺下组合，但不能凭 OPT_SC 传递任意小 NO gap。全局不交 profile 选择、隐式直积菜单规模和一般 normalized-menu 复杂度仍开放；外部文献只作背景，未据此声称一般 UM hardness 或近似比。

# 3. 校准单位读出槽与固定密度合同

源绑定 UM-UNIT-READOUT-CALIBRATED-SLOT-v1 与 UM-UNIT-READOUT-BOUNDED-DENSITY-SUBTWO-v1。结构域含私有 k-叉树、selector 两根质量和为 1、非负有理 edge/leaf 下传 t∈[0,1]；内部约束为
\[
 y+\sum_{\rm out}(1-t)\le L=k-r+1,
\]
clause 的外送总质量受 A 容量限制，外部 unit 机每槽至多接一项时间 1。全局 Hall/matching 必须一次覆盖所有原 jobs；“逐机分别存在”不足以证明完整 sigma。切片支持、位长、空输入和 k=1 均需按正文旁路处理。

两项明确边界反例必须保留：

- k=4,h=1,r=2：弱条件 Σout t>=r y 可成立，但强行实际负载达到 7/4，所以弱 LP 不能推出 3/2；
- k=2,h=1,r=2：强 LP 不可行，而实际完整调度峰值为 1，所以 LP 不可行不是一般目标阈值的必要条件。

在固定有理 D>=2 且 d_c<=D A_c 的密度合同内，大 k 取 r=1+floor((k-1)/(2D))，均匀递推给 C<2-1/(4D)；小 k 用真实容量匹配，失败时全 parent 基线证明 OPT=2。该保证依赖唯一 incoming、统一 small 时间、共同 unit 资格、固定 D 和非空/完整 YES 量词；不能推广到一般 UM，也不把 finite audit 的 passed 当成通用 LP 或软件全覆盖。

源审查还确认：受限 C<=1 的严格 YES 必要性需额外 k>1 与 a d_c<=A_c；去掉该假设会与前述非必要反例冲突。Verschae–Wiese Theorem 7 的 2-gcd/max 只能说明有界处理时间的已有 2-1/k，不能冒称本合同给出一般新颖性。代码回放、完整 sigma 数、巨大分母和两路独立证据均只承载有限范围，不替代结构证明。

# 4. 三源比较、现有对象衔接与处置

两源共同保留；单位读出部分仅为与既有对象的比较背景：显式任务/资源身份、全量 jobs、准确位复杂度和“有限实验不等于全称证明”。其独有内容分别是可裁剪两状态池的精确整数前沿、Santa type-profile 的压缩与 2-V 双向编译、以及单位读出树的共同 Hall 槽证书和固定密度两分支。

本页将两个 Boss8 来源记为 integrated，因为其数学内容已进入现有不相关机存档对象或证据包；Boss2 已处理的单位读出源不在本次 receipt 中。不把同一 legacy/main 冻结副本重复计数。未建立新的全仓主图边，仅留下第三阶段可用的条件关系：

- 两状态精确前沿 -> 多数地板的“可裁剪束”边界；边上注明跨状态混取和 K<2s-2 的锐性失败；
- type compression -> normalized rank matching -> 完整 UM OPT=2-V；边上注明 max-profile 非次模和共同选择开放；
- calibrated slots -> fixed-D bounded-density sub-two；边上注明弱/强 LP 反例、私有 pins/固定 D 量词和一般 UM 缺口。
