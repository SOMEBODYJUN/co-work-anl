# 对象、原件与两种残差

本页在[单位客户共同目录完整历史模型](../定义/共同目录完整历史模型--定义.md)的七极大主题、六人某真实前缀语境中，整理一份准确的来源纠错。全文主源是 2018B 的 source_scope_notes，另全文比较 2591B 的 ASR README。原 audit_asr_dual.py 本地缺 blob；没有读取或运行其源码，也没有收到原作者澄清。以下代数由所列定义直接推出，数值与脚本实际语义仍分别归原文报告，不把来源阅读升级为执行认证。

余人数 r=6-t，1<=r<=6。主题 j=0,...,6 各有 r 个 seat。原定义

\[
q_{j,k}=\frac{w_{\{j\}}}{p_j+k}
 +\sum_{I\ni j,\ |I|\ge2}\frac{w_I}{p_I+r},\qquad
U_{j,k}=\frac{|B_j|}{p_j+k},\quad L=6r+1.
\]

其中非负客户重数与前缀负载取自同一个对象。xi 是 7r 个 seat 的第 r 大值，seat 定理只给真实当前利润 u>=xi。给任意含 r-1 个 seat 索引的 H，README 广告阈值及其非负残差分别是

\[
A_H=\frac{\sum_{all}q-\sum_HU}{L},\qquad R_H=u-A_H.
\]

主源记录脚本实际采用 base=E[u]-sum_all E[q]/L、delta_h=(E[U_h]-E[q_h])/L。按这两式实际得到

\[
\boxed{R'_H=R_H-\frac{\sum_Hq}{L}},\qquad
\mathbb E R'_H=base+\sum_{h\in H}delta_h.
\]

所以若这个脚本合同和所报数值正确，所有 H 的 E[R'_H]>0 确实蕴含所有 H 的 E[R_H]>0，因为 q>=0；表达式错位本身不推翻分离障碍。但两个不同表达式的精确最小值不能混称，README 的六个最小值表不能未经代码复核直接认证成广告 R_H 的精确最小值。对 R'_H 排序取 r-1 个最小 delta 的确枚举了全 H 最小值；若要算 R_H，增量应是 E[U_h]/L，两者通常给不同 H 和不同数值。

原 README 六个正有理数按 t=0,...,5 为 10564271/1468088590、677380141/99631633770、3454574/599612625、495326117/122129099460、74904707/83562015420、19909061/3749577615。本页保它们为原报告，未认证原分布、原脚本所有字段或其精确身份。主源提示应按脚本实际 R' 合同解释，而非把本轮未读代码当作已查明。

# 排序论据与“所有 H”是不同的量词

只由 xi 是第 r 大，能推出至多 r-1 个 seat 严格大于 xi。若 H 包含这些 seat，且每个被移除 seat 有 q_h<=U_h，便有

\[
\sum_{all}q\le\sum_HU+(7r-r+1)xi.
\]

这段论证没有对不包含那些大 seat 的任意 H 自动成立。有限 seat 本身带有客户结构；该结构也许能给更强结论，但需要补一个保全部索引的证明。当前主源记录的未决点正是这个量词缺口。本页既不宣称所有 ASR_H 都合法，也不因短证明有缺口就宣称某个合法 CAG 实例已经违反它。r=1 时 H 只能为空，不存在“选择任意 r-1 个索引”的分叉；原问题在更大 r。

# 行族分离仍可保留的正确条件结论

若一份共同客户列上的非负权 Farkas 见证，使旧 M/L/T 行均非负、目标 W-|O_K|/2 的期望严格负，且所有 H 的广告残差 R_H 也非负，则目标不在这个扩大的非负行锥里。即使有些 H 的行未证合法，所有真正合法行构成的子族仍被同一见证排除。这个逻辑不依赖将超族每行都认证为 SPE 必要条件。

原报告只涉及固定 route (0,0,0,0,1,0) 与六比较集合 K={1,...,6}、即遗漏实际末位最大主题 B0 的目标；旧目标期望为 -12442/3967807。其他遗漏标签目标的期望为正，不在此证据覆盖内。见证是必要行系数域上的分离分布，不是完整策略、不是六人低福利 SPE，也不否定换源、换路由或别的共同付款机制。

主源所记“向原 actor 提问”只是历史动作，不是收到澄清、不是当前对外发送指令。本批没有发消息给原作者。应保留旧 M/L/T 五 route 证据的独立身份；没有因 ASR 的表达式或合法性问题将其一并撤销。
