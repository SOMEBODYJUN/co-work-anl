# 最优动作真实尾的静态菜单罚可联合控制

固定[共同目录模型](../定义/共同目录完整历史模型--定义.md)一个合法有序历史，过去并集P、非负整数客户负载b，尚余r≥2人，原规定动作S。定义总覆盖最优补全F_k(Q)=max_(T₁,…,T_k)|Q∪T₁∪…∪T_k|，F₀(Q)=|Q|，G=F_r(P)。取最优首动作A使F_(r−1)(P∪A)=G。

强制A后取r−1个合法尾主题B₁,…,B_(r−1)，可重复，并集Y；在应用于完整SPE时它们是同一原策略真实后继。令d_A为该枝A提供者最终份额，M=A\(P∪S)、t=A\(P∪S∪Y)，
\[
\eta_A=r d_A-|M|-(r-1)|t|\ge0.
\]
此非负性逐客户成立：M内未被尾覆盖客户各给1，其他M客户各至少1/r，A∩(P∪S)额外份额非负。对任意目录主题B定义**同一原背景P**的静态首动作机会损失λ_B=G−F_(r−1)(P∪B)≥0。则
\[
\boxed{\sum_{\ell=1}^{r-1}\lambda_{B_\ell}\le(r-1)(|t|+\eta_A).}\tag{1}
\]
这不需要当前或后继SPE激励；纯静态覆盖交换与分享公式已足够。没有把“菜单外”主题默认为免费。

# 完整逐客户证明

选一份以A开头实现G的静态r主题补全。把其中A换成任意B，覆盖最多损失|A\(P∪B)|，所以λ_B≤|A\(P∪B)|。若q_x是x在尾B₁,…,B_(r−1)内出现次数，求和有
\[
\sum_\ell\lambda_{B_\ell}\le\sum_{x\in A\setminus P}(r-1-q_x).\tag{2}
\]
以下将右侧每客户付款与(1)的t及η精确对应：

- x∈M且q=0：恰在t，缺失数r−1由(r−1)|t|支付；该客户对η为r−1−(r−1)=0。
- x∈M且1≤q≤r−2：它不在旧P，η贡献r/(q+1)−1=(r−1−q)/(q+1)，乘r−1因q+1≤r−1足付缺失数r−1−q。
- x∈M且q=r−1：缺失数0，η贡献0。
- x∈(A∩S)\P：不计M/t，对η贡献r/(q+1)≥1，乘r−1足付其至多r−1缺失数。
- x∈A∩P：式(2)不收费，它对η的额外原背景分享非负；其他客户不出现。

逐客户相加得到(1)。r2的中间q类别为空，仍正确；r−1个尾主题可以重复，空主题、零客户均在有限和内。非整数背景只作分享核时仍可讨论，但本页原博弈应用保非负整数合法历史，不把任意向量自动当可达SPE前缀。

至少一真实尾主题B满足λ_B≤|t|+η_A；若t=∅且η_A=0，则每个尾主题都在**原P**的最优首动作菜单。它不是说强制B后仍沿A枝的旧尾，更不是说B的真实新孩子损失小。

# 精确的真实重置差尚未付

沿[最优首动作菜单主恒等式](最优首动作菜单与真实孩子损失--引理.md)，A枝实际覆盖C_A=|P∪A∪Y_A|，ρ_A=G−C_A。对A真实尾中任一B，将同一个静态r槽终局的这份B移到首位，剩r−1槽仍覆盖C_A，所以F_(r−1)(P∪B)≥C_A，即λ_B≤ρ_A。若原历史真正改选B并按原σ重新展开，实际覆盖是C_B=|P∪B∪Y_B|；令其子孩子损失R_B=F_(r−1)(P∪B)−C_B，则
\[
\boxed{R_B=\rho_A-\lambda_B+(C_A-C_B).}\tag{3}
\]
两真实子树间C_A−C_B无已证符号。上界λ_B、甚至λ_B=0，都不能控制它。主账本的同尾ξ_A是将A枝尾静态放在规定S后，并不自动等于另一个真实孩子；η_A也已用于主分享预算，不能再免费支付reset或全路径相同亏损。
