# 提前实际末主题仍有零源 regret 的正 reset：七客户完整 SPE

## 精确被否命题

固定任意真源历史 h、背景 b、余 k 人、规定真实终局 z。令 C 为 z 的实际末主题，zC 为在同一源强制 C 后沿**同一完整 sigma**得到的真终局；令

`Gamma = u_source(z)−u_source(zC) >= 0`。

拟用源 IC 支付势 reset 的候选是

`Phi_b(z)−Phi_b(zC) <= (k−1) Gamma`。

下例在 k=3、b=0 给 `Gamma=0`、势下降1。因此不仅该系数失败，**任何有限系数乘同一 Gamma 都失败**。所用客户皆为单位、三名单位提供者、四个共同合法主题，允许全部有序历史的平局；不限制为计数策略。

## 七客户实例与完整策略

四主题记为 A,B,C,D。客户兴趣类型为：

| 喜欢的主题 | 单位客户数 |
| --- | ---: |
| A | 1 |
| C | 2 |
| B,C | 2 |
| A,B,D | 2 |

根选 A。第二人见 A,B,C,D 后分别选 B,C,D,B。第三人的完整回复表是：

| 第一人 / 第二人 | A | B | C | D |
| --- | --- | --- | --- | --- |
| A | C | C | C | C |
| B | C | C | A | C |
| C | B | A | A | C |
| D | C | C | C | C |

这是全部21个有序决策历史的策略。尤其 `(A,C)` 与 `(C,A)` 的计数相同，但末位分别取 C、B，均为合法平局。

最后一人的全历史最佳回复由下附逐单位核验器直接计算。按上表真实后继，第二人的四项偏离收益（按 A,B,C,D）分别为：

| 首主题 | 第二人各真实偏离收益 | 规定动作 |
| --- | --- | --- |
| A | `(3/2,2,2,1)` | B |
| B | `(2,5/3,3,1)` | C |
| C | `(2,2,2,2)` | D |
| D | `(2,2,2,1)` | B |

根四项真实收益为 `(2,2,2,1)`，规定 A。因此所有子博弈的一步偏离均不盈利，上述策略是完整纯 SPE。

实际路径 `z=(A,B,C)`，收益 `(2,2,3)`，W=7。实际末主题 C 提前根后，真路径 `zC=(C,D,C)`，收益 `(2,2,2)`，W=6。源收益不变，Gamma=0。势为

`Phi_0(A,B,C)=9`，`Phi_0(C,D,C)=8`。

所以势 reset=1。OPT_3=7，原实际福利为全覆盖，原 half 未被反驳。

把每类客户同时复制 t 次（t 正整数）给整个解析家族：Gamma=0、势 reset=t、实际 W=OPT_3=7t、提前分支 W=6t。故这不是依赖浮点误差或归一化的小负值。

## 正确 reset 税仍精确取等；哪些 IC 不能付它

固定提前主题 C 的背景。新枝真末两人为 `(D,C)`。已有强 PAIR 比较 A,B 给

`Phi_0(A,B,C)−Phi_0(C,D,C)`
`<= sum_(x in D\C)1/[(1_C(x)+1)(1_C(x)+2)]`。

D\C 恰为2名 A,B,D 型客户，它们不在 C 中，故该税为 `2/(1*2)=1`，与势下降精确相等。这保留既有强 PAIR 的正确作用；缺失的是把这个**新枝**税共同接到原实际路径钱包，而非删掉它。

更进一步，按 [任意 k 的精确回放账](promotion_reset_boundary.md#4-任意-k-的精确真实枝账与下一义务)，从提前叶 `(C,D,C)` 强制第二人回放原 A，真续叶为 `(C,A,B)`。该第二人的规定 D 收益为2、偏离 A 收益也为2，IC 松弛为0；最后一项原本就是 B，松弛仍为0。

删掉第二人后，两枝分别为 `(C,C)` 与 `(C,B)`，其势为6和7。因此整条回放链的正 reset=1，而原源 Gamma 及这条回放链的全部真 IC 松弛均为0。仅给这些特定松弛任意有限乘子不能付掉该 reset；这不否定使用其他真 IC、共同价格、全路径利润或真正跨枝信用。
