## 独立重构

固定源 h 强制 T 后的真叶 `(h,T,F_1,...,F_(k−3),B,C)`。新枝必须从该叶的**完整倒二前缀** `(h,T,F_1,...,F_(k−3))` 强制 C，末位才为 V。此处保留 F、不把强制 C 当最优，是代码 `terminal(actions, first[:-2] + (C,), m)` 的准确语义。

令每客户 `e=p+t+s,z1=e+b+c,z2=e+c+v`。按“费用不超过左侧钱包”的方向，五条 IC 的每客户费用分别为：

1. `t/z1`，由原源 r 支付；
2. `c/z2−b/z1`，其全客户和不正，来自真倒二 B 偏离 C；
3. `q/(e+b+1)−c/z1`，来自原真末 C 查询 Q；
4. `q/(e+c+1)−v/z2`，来自新真末 V 查询 Q；
5. `v/(e+b+1)−c/z1`，来自原真末 C 查询新枝主题 V。

对应非负权 `1,1/50,49/800,1/50,3/160` 正确。第五项必须沿原末节点的前缀 e+b；正文和实现均没有误用新枝前缀。C 在两条分支中为同一个主题，V 同时是新真末行动及原末查询；消元前保持两个身份。

报价费用中，π 使用 C 和 V，合计权 `3/50+1/800=49/800`；ρ 使用 B,C,V，合计 `24/125+24/125+1/250=97/250`。容量仅给 B 权1/500及每个中间 F 权49/1600，故为 `[1/500+(k−3)49/1600]K`。没有隐藏的免费 K 项，也没有把跨节点的 U,V0 直接认作同一个收益。

零分子份额由各原单份额独立按零解释。其余查询分母均至少1。非负组合对全部会员型成立，然后取 H 的有限最小值只放松右侧；不需要局部最小会员型可实现为一个 SPE。

隐藏中间位数 k−3。它们只以总数 s 出现，费用又是同权线性和，因此每个 s=0,...,k−3 都可实现；连同 b,c,v 三个位恰有 `8(k−2)` 个计数候选。该压缩不依赖五人或六人；若增加不同中间位权重/身份相关 IC，则需另证。
