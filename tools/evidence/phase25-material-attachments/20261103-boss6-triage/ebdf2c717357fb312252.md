# 固定rank：全形式策略与被核行域

## 客户、计划重置与真正偏离次数

采用[共同目录单位客户模型](<../../../../archives/customer-attraction/state/定义/共同目录完整历史模型--定义.md>)，但这里给的是**完整形式策略**，不先假设SPE。参数m≥1、cutoff=k≥0，置 $M=2^k$、$L=\operatorname{lcm}(1,\ldots,\lceil m/M\rceil)$。2m个两两不交非空主题：第i个A块大小 $L/\lceil(m-i)/M\rceil$（i从0计），另m个B块各L，整数块展开为不同单位客户。

初始计划是A₀,…,Aₘ₋₁。`parse(history)`从空历史逐行动回放，只在实际动作不同于当时规定动作时令rank加一。新rank≤k时，偏离处余r人、该主题过去用了p次、大小L/d，令 $a=2^{k-\mathrm{rank}}$，并设

\[
q=\max\{p+1,\lfloor(r+p+1)/(ad+1)\rfloor\}.
\tag{1}
\]

计划从当前位置复制该主题至总次数q，再依序补未出现的B直到m槽。超过k后规定复制最近实际行动，后续再偏离仍更新所复制标签。对每个有序history都有确定后续，不按同次数历史合并。`finish`递归补规定动作直到终局，收益为所选不交块大小除该块最终人数。

保留域按真正偏离次数而非“与原根路径不同的位置数”定义；计划重置后遵从新计划不再加rank。每个保留节点比较全部2m行动，**包括使孩子进入rank k+1的行动**，这些比较仍沿完整形式策略真正完成。只是不把该高rank孩子继续作为需满足自身IC的节点；省掉的是高rank节点的激励，而非偏离后续局计算。

全部rank≤k有序节点数为

\[
N_j=\binom m{j+1}(2m-1)^j,\quad
N=\sum_{j=0}^{\min(k,m-1)}N_j.
\tag{2}
\]

因为长度d时选j个偏离位置，每处有2m−1个非规定动作，其余动作唯一；按d求和得(2)。原代码实际遍历再核N，不用闭式代替所有真实行。

# repeated-last：标量域而非完整游戏审计

1111B脚本的全部范围是m1..100、c0..m、b0/1且b≤c、比较负载d0..m。它核

\[
\mathbf1_{c>0}-\frac bc+\frac d{c+1-b}-\mathbf1_{d>0}\ge0,
\tag{3}
\]

c0时b0，b/c定义0，分母c+1−b总正。每个m恰 $(2m+1)(m+1)$ 格，总691950；这不是691950游戏、客户实例或完整策略。

再对每个1≤k≤m≤100核

\[
\frac{k(2m-k)}m=m-\frac{(m-k)^2}m,
\quad \frac{k(2m-k)}m\ge m-1\iff(m-k)^2\le m
\iff k\ge m-\lfloor\sqrt m\rfloor,
\]

以及比率 $1+m(m-1)/(k(2m-k))\le2$ 的同一阈值、k=m时2−1/m。共5050个m/k对，但源码stdout只写player_counts100而未另输出5050；此数是按循环域的明确计数。

[5047B独审原文](<../../../../archives/customer-attraction/tools/evidence/independent-ranks-four-boss3/related/repeated_last_review.md>)有全参数证明：真实末位比较先给OPT≤W+(m−1)u；每个实际角色改选固定末覆盖B至少得|B|/m，k个同覆盖者的u相同，再得 $W\ge k(2m-k)u/m$。此处k按**相同客户覆盖**计，非只按相同标签；非空背景不可把剩余玩家利润当根W套用。

这些证明以及更强残余/前缀缺席判据均已在[末覆盖重数定理](<../../../../archives/customer-attraction/state/定理/末覆盖重数与前缀缺席的半覆盖判据--定理.md>)去重。本文只把其先前未执行的原标量脚本恢复成一个新事件，[stdout](<../../../../archives/customer-attraction/tools/evidence/independent-ranks-four-boss3/replay/check_repeated_last/stdout.txt>)及[事件](<../../../../archives/customer-attraction/tools/evidence/independent-ranks-four-boss3/replay/check_repeated_last/execution-record.json>)明写formula audit。
