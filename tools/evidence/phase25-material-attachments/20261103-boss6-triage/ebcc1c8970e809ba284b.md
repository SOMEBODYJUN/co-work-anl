# 一个小输入的完整读后算术

collision_free游戏两玩家、四主题A/B/C/D。兴趣{A}1客户、{A,B,C}2、{B,D}1、{D}1，共5客户。原q=(1,1,0,0)，actual path=(B,A)，W4；比较T=(A,D)覆盖5。末位在B前缀被强制D的利润是{B,D}交叠客户1/2加D私有1，即L(B,D)=3/2。

首位被强制A后，末位B的利润为2/2+1=2，D的利润为1+1=2，C只有2/2=1，A为3/2。可信末位只能B或D；首位A利润分别2和3，故L(0,A)=2。于是cost=2+3/2=7/2，δ=7/2+4−5=5/2，正是所报行。这只展开显示见证点，不用此点算术替代全部actual/T最小化证明或冒新solver运行。

actual首位B后，末位A利润2为唯一最佳（B/C/D分别3/2、1、3/2），选A得原path；首位B终局利润2。若根强制A选B续局，A利润2；根强制C，末位A/B/D利润同为2，选D时C利润2；根强制D，末位A唯一最佳利润3，D利润2。这样选择A后B、B后A、C后D、D后A即给完整五节点纯SPE实现(B,A)，每个末位是BR、根所有行动利润2。所报comparison第一列是L(0,A)=2，不需改actual；末位D只是强制偏离的受迫行动，无要求D在(B,·)最佳。这里给的是读后显式完整小策略，不是原JSON存了动作表或本次程序IC执行。
