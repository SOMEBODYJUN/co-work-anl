# 两个有限目标与共同客户模型

有限单位客户、有限非空标签目录L及覆盖映射S:L→2ᴺ，允许映射不单射、空覆盖、重复选题、零客户和每个有序离轨历史任意弱平局。每名单位提供者观察全部既有有序行动后选一次主题，终局客户在覆盖者间均分。有理非负类型质量只是齐次表示；统一清分母可化成不同单位客户。

本页完整读取三原程序和两原JSON（含全部12302条动作记录）。保存点来自固定策略的客户质量锥，不能把每次换客户后的点当原证书标签所指同一个游戏。本页不重跑原LP、随机策略发现或原main；一次独立标准库固定核处理全部117个保存点。原件、指纹、全部记录与失败行见[证据入口](<../../../../archives/customer-attraction/tools/evidence/early-opportunity-background-and-strong-primary/README.md>)。

令m为总人数，W包括旧玩家与后续玩家的全部实际覆盖，u为指定当前玩家最终收益。`background_attack.py`攻击

\[
C_J-W-mu\le0,\qquad |J|=\min(m,k). \tag{B}
\]

旧s人的合法主题计数b固定，不要求这s人曾经最优；只有余r=m−s人的完整后缀SPE。这比真实空根m人SPE有更宽的旧前缀域，不能从后缀证书给旧人的激励。旧覆盖也进入W，不是“后缀新增覆盖”或“后缀总利润”。

`canonical_strong_attack.py`在空根完整策略锥上攻击更强系数

\[
C_J-W-(m-1)u_a\le0,\qquad a\in\operatorname{supp}(q_{root}). \tag{S}
\]

这里遍历实际路径出现的不同标签，代表所有实际玩家收益；没有另加a为最低收益的行。穷尽所有a后的数学最大值才会选择最低实际收益。它不是(B)的同一目标；两报告也不是分数价格任意菜单的全局搜索。当前[逐人机会损失候选](<../../../../archives/customer-attraction/state/问题/逐人机会损失与分数价格候选--问题.md>)用m系数；静态银行门槛已失败不自动反驳这个净缺口合同，五人half已证也不自动证明它。

# 计数策略发现器及合法背景接口

`count_policy_attack.py`的states(k,d)枚举全部非负k维计数和为d。给seed客户质量，自底向上在每个计数q枚举k个当前行动，真实遵循已选后继得到终局qᵃ。比较的是当前行动在**自己的真实分支**上的收益，而非同一冻结终局的换题收益。选择距最高值10⁻¹⁰内的随机平局动作，记α(q)及全部非自身行

\[
R_{q,a;T}=\frac{1_{a\in T}}{q^a(T)}-
\frac{1_{\alpha(q)\in T}}{q^{\alpha(q)}(T)},\qquad Rx\le0. \tag{IC}
\]

零分子取零，正分子时当前行动已在终局，分母为正。客户类型为全部非空T⊆[k]，x_T≥0、Σx_T=1。归一化活跃客户总质量，**不是W=1**。固定α后对每个比较支持J和实际根主题a解float LP，最大化C_J−W−coefficient·u_a，默认coefficient=m。若k<m，只用全目录支持但仍罚m倍，不遍历重复槽的查询成本。最优覆盖可补重复标签，不意味着含查询收益的每个预算都可如此补齐。

seed质量三类按trial mod3交替：稀疏离散[0,0,0,1,2,3,8,20]、0.3概率指数分布、近均匀1+0.05U；同一Random同时供质量和破平局使用。main默认k6/m5/trials40/seed20261021；每轮增量覆写output，保质量>10⁻⁹及全部动作，正值>10⁻⁸才早停。没有本批该count原main的独立冻结输出，不能把另两文件当其40轮日志。

background顶层按cwd相对research路径runpy导入count以取states；runpy不执行其main，但仍导入NumPy/SciPy。background随机生成s个旧标签，以b+q为状态，终层总计数m；同样逐真孩子建立(IC)。seed质量从[0,0,0,1,2,5,10,30]抽取。在各|J|=min(m,k)支持上只针对**后缀首位实际行动**解(B)，不是全部旧/新玩家。默认k6/s1/r4/trials100/seed2026102114。每轮覆写JSON，stdout省略weights/actions；所有LP失败可能保−10⁹⁹与不全字段，不能作负界；本报告100条字段均完整。

给有理x≥0，若全部合法计数键完整、每个真孩子遵循同一α且(IC)精确成立，则对任意有序后缀历史h定义σ(h)=α(b+counts(h))。逐计数收益比较代表所有这些有序历史，故是完整后缀纯SPE；这不证明任意SPE都可计数化。旧玩家只固定b，不能据此推根SPE。
