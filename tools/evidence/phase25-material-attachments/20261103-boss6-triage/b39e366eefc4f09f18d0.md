# 数学数据与八个函数的合同

沿用[单位客户完整历史模型](<../../../../archives/customer-attraction/state/定义/共同目录完整历史模型--定义.md>)。原标签为L={0,…,k−1}，k≥1，人数m≥1。非负整数 weights[b]=w_b 表示兴趣标签mask为b的w_b名不同单位客户；整数重数不是提供者权重。这里实际输入mask均非零、均只用前k位，零重数保留或省略等价。空兴趣客户可省去，因为不影响收益与覆盖。空覆盖标签、同覆盖标签、重复行动、零客户和任意离轨弱平局都不删。

对终局 s∈L^m，令 n_b(s)=#{j:b含第s_j位}。pay 返回精确有理向量

\[
u_i(s)=\sum_{b:\,s_i\in b}\frac{w_b}{n_b(s)}.
\]

分母仅在客户有覆盖者时使用；对实际选择者所属类型它自动正。Fraction 从整数重数与覆盖人数直接构造，没有浮点容差。

| 函数 | 源码行 | 输入、返回及承重作用 |
|---|---:|---|
| histories(k,m) | 7–8 | 列出所有长度0,…,m−1的有序标签元组，数为Σₜ₌₀ᵐ⁻¹kᵗ；不是计数状态，也不只在轨。 |
| continuation(policy,h,m) | 10–12 | 按同一给定完整动作字典逐步追加 policy[h]，返回含原前缀的长度m终局。长度m历史直接返回。 |
| pay(profile,weights) | 14–21 | 遍历每个非零重数类型及最终覆盖者，给每人加w_b/n_b；返回Fraction元组。 |
| is_spe(policy,weights,k,m) | 23–30 | 每历史h对全部k个行动a比较真实规定终局与先强制a再沿同一策略完成的终局；首次严格盈利偏离返回(False,已查数)，否则(True,kΣkᵗ)。 |
| opt(weights,k,m) | 32–38 | 枚举大小1,…,min(k,m)的全部不同标签子集，算与至少一个所选标签相交的客户总重数，取最大。 |
| audit(policy,weights,k,m) | 40–51 | 调商编译器，再执行下节六项断言；返回商完整IC比较数。它自身不先检查原策略SPE。 |
| backward_policy(weights,k,m,rng) | 53–60 | 显式建立所有终局，再从深度m−1向根求每个节点所有行动的真实终局收益，在全部最大者中用rng.choice选一项。返回完整动作字典。 |
| main() | 62–95 | 穷举两人域并筛SPE；采样200个三人输入、BI并核原SPE；最后核一份六人策略，累计商IC并打印九字段。 |

每人只在其所在层行动一次，所有有序历史上的真实行动比较正是完整纯SPE条件。is_spe 的右侧调用 continuation(policy,h+(a,),m)，因而保留偏离后的真实后继，未冻结actual后继。等号不构成失败，故不另选强制平局规则。比较包括规定行动自身；无效策略的已查数只到首失败，不可都算作完整树工作量。

opt 枚举子集而非m元组是正确的：任一m元组的不同标签数至多min(k,m)，并集不变；任一非空的至多m标签集合可以重复其中标签补齐m项。非负重数下零个主题不会优于所有非空集合，k,m正保证后者存在。零客户直接返回0，不取0/0比值。

逆向归纳的 terminal[h+(a,)] 已是该子树按已定后继策略到达的真实终局，故选择最大值保证本节点IC；从深层归纳得到完整SPE。main 又调用同一套 pay/is_spe 核对这份策略。该算法论证说明为什么其输出应可信，但BI与核对共用 pay，并非两份完全独立的收益实现。

# 正向编译与六项实际审计

编译器先按正客户支撑求覆盖等价类π：标签a和b被同一批正重数类型包含，当且仅当它们覆盖同样单位客户。零类型不区别主题。对每个有序商历史H，递归给一个原历史lift ℓ(H)。若a=σ(ℓ(H))，商动作取π(a)；规定类的代表用a本身，其他类用该类最小原标签，子提升为追加该代表。商客户类型按π改写mask并相加非零重数。

特别代表条件使从H沿商规定路径的lift恰沿原σ走；在H强制任意类d后，则对应原ℓ(H)强制一个合法原标签，其后仍沿σ。两边的整条覆盖序列及收益相同，原全历史IC因此推出商全历史IC。唯一父历史保证递归不冲突。它不用同覆盖别名具有同一后继，也不保全部别名分支。

原 audit 的断言恰为：

| 断言 | 直接检查内容 | 边界 |
|---|---|---|
| valid | 商策略通过 is_spe 全有序树检查 | 原策略SPE须由调用方保证。 |
| cover_classes(qweights,qk)[0]==tuple(range(qk)) | 商后所有标签各自成类 | 正支撑上的覆盖不同；不要求原标签不同。 |
| project_history(h,projection)==H | 每个返回lift条目的前缀逐项投影正确 | for循环遍历已返回条目，未另外断言lift键集等于全部商历史。 |
| 商 continuation 等于原 continuation 的逐项投影 | 每个返回lift节点含终局的整条规定续局相同 | 原/商策略、原前缀及所有后继均参与；不只是根。 |
| 两根 pay 向量相等 | 根的每位实际收益逐项相同 | 未逐节点另存收益向量比较表。 |
| 两个 opt 相等 | 指定客户输入的真实最优m覆盖相同 | 不验证LP目标或任何固定策略锥最优。 |

实际编译器的递归完整生成商动作表与所有深度≤m的lift，is_spe又遍历全部商决策历史；上述“缺独立lift键集断言”是测试覆盖限制，不表示现存返回表缺行。W没有另写一条比较断言，但单位客户均分给W=Σ_i u_i，根逐人收益等式已推出W保持。一般节点的收益保持由覆盖序列投影与正确客户投影推出，不能写成源代码已在每节点直接比较pay向量。

main 两人块只在原 is_spe 返回真时调用audit；三人块及六人块分别在调用前 assert valid。总共八个断言语句：audit六处，加main两处。开启 Python 优化会移去这些assert，且末尾 all_checks_passed 仍是固定true；因此复现必须保留断言，不把JSON布尔值单独当证书。源码并非恶意输入验证器：未显式检查完整字典键集、动作范围、非负整数重数、有效mask或一般参数合法性；本入口的生成方式满足这些前提。

## 一个域内解析例：为何不能全局固定代表

取两人、三个标签，w₃=2、w₄=1、w₇=0，即0、1同覆盖两客户，2覆盖另一客户。设完整策略σ(∅)=1，σ(0)=0，σ(1)=2，σ(2)=0。前缀0或1后，继续同大类所得1与转小类所得1平局；前缀2后选择大类独得2。根选0、1、2的真实收益分别1、2、1，故该σ是本穷举域内完整SPE，实际类路径为AB，W=3。

正确递归在根规定类A取原标签1，故商根之后提升到(1)，后继类为B，保AB。若错误地把A的代表永远固定为0，则商根之后查σ(0)=0，改成AA，W=2。错误产物甚至仍可为SPE，却丢失被指定原策略的路径与W，说明“只核商SPE”不足。源 audit 的续局投影和根逐人收益断言正好约束这项风险。这里是直接列收益的解析说明，未运行新增完整测试或将该例冒作独立原CLI事件。

# 三段实际输入、输出计数及量词

## 两人指定域：全部策略，但并非全部客户模型

输入k=3、m=2，weights={3:a,4:b,7:c}，a,b,c分别取0,…,3，恰64例。mask3客户只接受0、1；mask4只接受2；mask7接受全部标签。0、1始终同覆盖，2可能与它们再合并。四个决策历史∅、(0)、(1)、(2)，每节点三行动，故每例81份完整策略、总5184份；筛出856份原SPE，逐份商审计。

这保留所有原标签依赖平局，含a=b=c=0的零客户实例和部分空覆盖；不把同覆盖历史先合并。a=b=0的四个c输入里，所有标签同覆盖且全部81份策略为SPE，共324份的一类商；其余532份有效策略有两类商。因此商比较数

\[
324(1+1)+532(2+2^2)=3840.
\]

c客户在每个两人终局均给每人c/2，从IC中抵消。仓内既有16组(a,b)的独立私有收益计数给上述856，详见[现存计数解释](<../../../../archives/customer-attraction/tools/evidence/action-quotient-parent-replay/replay/count-semantics.json>)；本次只解析这些已存数值，没有重跑那份计数程序或5184策略。

## 三人固定种子：一次BI策略选择

输入k=4、m=3；rng=random.Random(566240)。对潜在三个覆盖类的mask b=1,…,7，转换为

\[
\mathrm{label\_b}=(3\ \text{若}b\&1)+(4\ \text{若}b\&2)+(8\ \text{若}b\&4),
\]

实际顺序为3,4,7,8,11,12,15；每类型独立调用rng.randrange(6)，生成0至5整数重数。第一类复制为原标签0、1，其余两类为2、3。每个输入用backward_policy在21个有序决策历史中择最大者，生成一份完整SPE，再精确检查和编译。

权重抽样与各历史随机平局共用同一个RNG；顺序是“该例权重七次抽样—该例全部BI平局选择—下一例”。只先生成所有200组权重再BI会改变后续随机流；修改遍历或平局处理也可能改变数据。固定seed不代表跨任意实现和版本仍有同一消费序列。

代码允许退化后商类数少于3；本条固定流的既有200项诊断均为3类，商IC因此为200(3+9+27)=7800。200表示循环产生的输入/策略对，不保证200个互异游戏，更不穷尽三人SPE或每个输入的所有平局选择。

duplicate_signal_dependent_cases=43的精确谓词为“存在a∈{0,1,2,3}使σ(0,a)≠σ(1,a)”，比较末位原标签。两历史覆盖序列相同，但原标签计数不同，故它不证明43例覆盖也改变，更不证明43例不能写成标签计数策略。既有诊断以同一原BI流补查覆盖类：16例有覆盖类改变，另27例只检测到别名改变。该细分是旧诊断复用，非本轮新采样；未将16+27改写为原程序两个输出字段。

## 六人完整规模：一个全历史恒选策略

固定k=7、m=6，weights={1:6,2:1,4:1,8:1,16:1,96:1}。0覆盖六客户，1至4各一私有客户，5、6同覆盖第五个私有客户；合11名单位客户、商后6个主题。每个长度<6的原历史都规定选0。

任意深度t前缀已选大主题c₀次，当前遵从后大主题最终人数为c₀+6−t≤6，当前收益6/(c₀+6−t)≥1。改选私有主题的收益≤1，之后仍依原策略选大主题，故全部离轨历史满足弱IC。实际六人都取0，各得1，W=6；六个不同覆盖共同覆盖11客户，OPT₆=11，2W−OPT₆=1。因此仅是旧11/6型回归，不是half反例。

原决策节点Σₜ₌₀⁵7ᵗ=19608，含自身IC为137256；商决策节点Σₜ₌₀⁵6ᵗ=9331，含自身IC为55986；商lift含终局共有Σₜ₌₀⁶6ᵗ=55987。三数不可混用。

# 未覆盖接口、成本与接续方式

测试仅调用字典策略，未测试编译器支持的callable；所有原输入都有重复覆盖标签，未单列完全无重复的恒等投影。人数仅2、3、6；没有零玩家扩展、单人、空目录、负重数、非法mask、缺失节点、非法动作或异常输入回归。全零客户与空主题在两人域实际出现，不应因未覆盖其他接口而删去这些已覆盖边界。测试只实现和检查原策略到商策略的方向，未另构造商SPE到原标签SPE的反向提升。
