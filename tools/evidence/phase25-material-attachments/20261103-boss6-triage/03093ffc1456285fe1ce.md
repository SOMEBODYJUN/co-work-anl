# 七主题逐人门槛与六主题扩充的三份浮点记录

## 共同模型和报告真正量化的域

采用有限单位客户、单位提供者、共同有限目录、完整有序历史纯SPE。两程序先在某整数种子上按每个有序节点的精确最佳回复随机破平局，取得一份完整策略，再固定该动作表，优化全部非空兴趣类型的非负重数。故每次LP包含**该策略锥的所有客户重数**，却未覆盖全部完整策略；种子为环也不等于LP只许环兴趣类型。

完整数学与源码合同见[程序页](<../../../../archives/customer-attraction/state/程序/逐人最优覆盖门槛与安全扩充的固定策略锥探针--程序.md>)。这里所有目标都按某实际收益 $u=1$ 归一化：direct比较 $OPT_m/u$ 与 $2m$，safe-padding比较 $[O_r+(m-r)K/m]/u_1$ 与 $2m$。不是福利归一化，也不是将半覆盖余量 $2W-OPT$ 放入这三份报告。

[五主源manifest](<../../../../archives/customer-attraction/tools/evidence/security-direct-and-padding-probes-boss3/source-manifest.json>)保两程序及三JSON全部原字节、ID、双冻结来源commit、SHA256和Git blob，合计20486字节。本轮逐个读取记录及所有子字段，依实际源代码解释缺省字段，而非由文件名补结论。

## 四人七主题：16次采样，只有一个收益触发组合枚举

[四人原报告](<../../../../archives/customer-attraction/tools/evidence/security-direct-and-padding-probes-boss3/original/direct_floor_probe_n4_k7_seed231026.json>)根字段为 `scope="finite floating diagnostics only"`、`seed=231026`、16条 `records`（case0至15）。每条有 `k=7,m=4,policy_rows,path,checks`；每项check对应路径中的一个不同主题，按标签递增排列，不是按玩家位置。重复主题的实际角色共用相同终局收益。

这里 `policy_rows` 为去零去重IC数；实际每份策略都有 $1+7+49+343=400$ 个有序决策历史，原始非规定偏离比较2400个。不同IC数并非遗漏部分历史，也未检查跨case完整动作表去重，所以不据16条称穷尽或恰16个不同锥。

## 三人六主题安全扩充：只根，遍历最大旧题与两种槽数

[第三原报告](<../../../../archives/customer-attraction/tools/evidence/security-direct-and-padding-probes-boss3/original/safe_padding_probe_n3_k6_seed231028.json>)根字段只有 `scope="finite float discovery only"` 与八条记录，**没有根seed字段**；231028来自文件名、原默认值和本轮显式重放参数，不倒写成JSON本身已有的元数据。

每条有 `case,k=6,m=3,root_action,rows,best`；`best` 为 `[浮点目标值,{max_topic,old_slots,portfolio}]`。`rows` 只数旧策略IC，不含每个LP另加的六条最大主题大小约束（其中自身约束为零行）。每份完整策略有43个有序决策历史，215个原始非规定偏离比较。

源码对六个候选最大题 $C$ 和全部 $r=2,3$ 组合都求值，每case $6(\binom62+\binom63)=210$ 个LP，八case共1680个。表中最好点都选 $r=2$，不表示 $r=3$ 没检查。由于严格 `>` 更新保best，所留 $C,J$ 还受浮点微差及遍历顺序影响，不能推唯一最优组合。

全部浮点最好值低于分离阈值6，没有触发有理恢复候选。$r=1$ 不在循环内，但由根 $u_1\ge K/m$ 得其目标不超过 $(2m-1)u_1=5u_1<6u_1$，已解析排除；并非本报告穷尽了所有槽数后才知道它阴性。

三人探针测的是安全扩充后的**根DIRECT**，不是三人任意玩家，也不是half目标。它没有添加新客户块、生成扩充策略或对新动作逐节点核验；这一扩充的合法存在性来自[同人数扩充定理](<../../../../archives/customer-attraction/state/定理/同人数不交目录扩充的完整策略保持--定理.md>)。不能借另一个coupled族十二例的端点表替代本源的六主题锥、最大题约束与210个目标，也不把本源当成安全扩充保持定理的独立全历史审计。

[DIRECT现行量词纠错](<../../../../archives/customer-attraction/state/资源/DIRECT与前缀门槛的历史量词和后来反驳--资源.md>)及[银行完整反族](<../../../../archives/customer-attraction/state/反例/笛卡尔银行目录的逐人分数门槛反族--反例.md>)已核其根全历史控制器及 $m\ge5$ 的严格公式；本批复用，没有再跑银行全树。该反族否定逐人加强，却仍付half和真正整数静态安全聚合。两probe不求混合静态安全值，不求自由分数背景，不检测完整根菜单混列存在性，也不能用其阴性维护这些不同接口。
