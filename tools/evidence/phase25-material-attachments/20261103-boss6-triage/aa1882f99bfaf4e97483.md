# 五人主证书与局部复跑的最终验收身份

## 1. 验收的对象与证明边界

本页保存 `CA-FIVE-HALF-EXACT-v1` 导入后的原主程序两次完整复跑、原父方局部复跑及最终验收记录。七个主来源全篇或全字段实读；两个11981B行清单是相同原字节，完整实读其中一份并核另一份字节相同，不冒两次独立扫描。当前正式结论采用已经整理的[五人半覆盖定理](<../../../../archives/customer-attraction/state/定理/五人半覆盖--定理.md>)。

准确模型是有限单位客户、有限非空共同带标签目录、五名单位提供者、每份完整有序历史纯SPE；保留空主题、重复行动、同覆盖异标签、零客户和任意平局。根上无既有覆盖背景，结论是实际覆盖至少达到五目录主题最优并集的一半。这份验收既没有将提供者数改成六，也没有证明带背景的五人利润结论。

证书字节SHA为 `395e056b218d237abe8b85db894f0b1c37d2e14d55c74b1dca723abeceb6a44e`。`final_acceptance.json` 明示证明来自上传导入，原团队不声称发现；一般 `Q_CAG_HALF` 标为OPEN。其“停止五人搜索”是当时工作安排，不能成为本次不处理其他来源的理由。原记录“六个实际gpt-6.1-sol ultra子代理加父方”也仅描述原团队，本次不能用它替代当前实际并发事实。

## 2. 两次主程序复跑属于同一实现

`original_global_replay.json` 与 `parent_main_replay.json` 各2971B。除 `seconds` 外，全部JSON字段、所有32个实际会员掩码的整数最小值以及六个局部输入身份相同。原时间分别为6.648185831999399秒和7.375878482999724秒。两份原字节均保留，时间字段不被删去或合成第三次运行。

| 两报告共同字段 | 数值与含义 |
|---|---|
| `status` / `mode` | `passed` / `exact supplied dual`；核既定证书，不重新搜索权重 |
| `beta` / 正权数 / 分母 | 精确2 / 53 / \(10^{22}\) |
| 固定会员掩码 / 共同最优重数 | 1024 / 6个值，即 \(d=0,\ldots,5\) |
| 完整外条件数 | \(1024\times6=6144\)，不是6144个随机博弈 |
| 第三位分支族直方图 / 第二位分支族直方图 | 总数5的八格792个 / 十六格15504个 |
| 每菜单角 / 缓存context | 4 / 121；后者是计算缓存统计 |
| 最小清分母整数余项 / 负条件 | 0 / 空列表 |
| 零条件数 | 2个外条件，不是“两份最坏SPE” |
| 全局K信用 | 2264870；再乘120为271784400 |

`minimum_by_actual_mask` 全部32项原样保存，成熟主定理附录已有同一表。实际掩码 `00000` 的最小值为0，其余31个掩码的最小值严格正；这里是放大核验域中的系数余项，不应解释成逐博弈严格优于二分之一的统一比例，也不从两个零条件反推存在达到界的完整策略。

两报告中的 `scope` 写着不导入发现过程或既有行求值程序的独立精确全域核验。这描述便携核验器与发现代码的依赖分离。两个不同人执行同一程序，仍然是同一实现的两次复跑；本批没有第二份独立交付的完整便携主核验器。另一条旧557引擎独立解析路径见[共同K与旧引擎审查](<../../../../archives/customer-attraction/state/审查/五人全域证明的旧引擎交叉核验与共同K信用--审查.md>)，它明确依赖旧引擎。

## 3. 相同行清单固定了哪些客户系数

两份行清单各11981B，SHA均为 `cbc5f0c7b6238a1d0e622621c89851292c4ed94e946e36ed16b41e1bb851c0cf`。它们保留：

- BG9项：前六项为第二位源角色、每项8格信用；后三项为第三位源角色、每项16格信用。
- PC8项：五个PC2和三个PC3，每项五个实际收益系数及完整64格信用。
- DEEP3项：各五个缩放后整数系数。
- 六个原组件输入的路径与SHA：BG2、BG3、PC2、PC3、DEEP、MAXROOT。

所有零、正负整数和原数组顺序均保留。负信用不能按“概率”裁零；PC2源收益补一次与PC3已经包含源收益的差别也不能统一处理。源角色与会员位序的解析见共同K审查及[局部组件独立重构](<../../../../archives/customer-attraction/state/审查/五人局部组件独立重构的真实节点门槛与复现范围--审查.md>)。

清单列出MAXROOT源输入的SHA，但没有另存一个MAXROOT客户系数表字段；不能替它补造已由清单显式记录的数值。MAXROOT具体系数来自该已绑定组件及核验代码。相同行清单只证明两份导出使用同一组这些系数，不能单独证明这些系数都满足真实SPE节点约束；后者由局部数学引理和独立局部实现承担。

## 4. 原父方36组件局部复跑

`parent_local_replay.json` 的算术是标准库 `fractions.Fraction`，共36个组件、47872个系数状态，原耗时4.292秒。七个输入SHA完整保存，六个主输入与主报告及行清单一致；第七个是可选 `max_background_player2.json`。逐项 `verified` 均真，各项状态和零余项数为：

| 行族 | 组件数 | 每组件状态数 | 按原索引的零余项数 |
|---|---:|---:|---|
| DEEP | 3 | 4096 | 60，86，64 |
| BG2 | 14 | 512 | 32，33，35，35，32，34，34，31，33，36，30，29，31，31 |
| BG3 | 8 | 256 | 52，30，36，45，33，31，38，31 |
| PC2 | 5 | 4096 | 69，71，65，71，66 |
| PC3 | 3 | 1024 | 312，296，164 |
| MAXROOT | 2 | 1024 | 56，56；两项均保 `comparison_bit_cancels=true` |
| MAX-BG2 | 1 | 768 | 19；保 `unused_reply_removed=true` |

这些整数状态来自局部系数位型，不能当作搜索了47872个完整博弈。MAXROOT的比较会员位最终抵消，真实余域仍须完整覆盖；MAX-BG2去掉未使用回复后为768状态。这些范围更正与早期失败记录已在局部组件审查保留，不能以最终成功报告擦除旧失败，也不能把当前本页的读取算成又一次成功重跑。

七个输入及36条明细是这一运行的身份。这里不更换输入版本，也不将旧研究目录中同名的更早组件自动认作相同输入。独立局部实现的原源码/输入语义此前已实质整理，本批复用该结果而不再次执行47872项。

## 5. 原团队分工与各层证据的关系

4296B README的六路复核分工及1309B最终记录全部保留。它们记录的是共同接受同一证明的过程，不能累加成六份完整主证明。

| 原复核范围 | 保留下来的责任 | 不能由该范围单独推出的结论 |
|---|---|---|
| 直接/局部组件 | 36组件的独立有理重构、真实节点与外舍入 | 整个53权全域拼接已经通过 |
| 最大根 | 四复制最大主题相关行及必要点诊断 | 必要点可由原游戏完整策略实现 |
| 树语义 | 活跃原行的真实历史与复制前缀含义 | 任意相同计数的历史可交换 |
| 尾部/导入链 | 原ZIP、manifest、K输入和只读副本身份 | 哈希相同本身证明所有数学行正确 |
| 反攻/范围 | 假桥梁、反例的固定人数及旧松弛域边界 | 推翻已经完整核验的五人主结论 |
| 证书/旧引擎 | 全局K重构及35旧行加18新行的另一解析路径 | 第二份完全自足的便携主核验器 |

旧6750/7497必要点与新投影的关系只用于诊断旧约束缺失：一个点可以通过旧行而违反新行。原README提到的13条负新行不是本页新做的点审计，也不是原SPE反例。其具体输入与精确结果应到对应已保存证据寻找，不能用验收摘要替代。

`final_acceptance.json` 汇总53权、6144完整条件、最小余项0、36/47872局部结果、K两种缩放、导入来源与审查边界。这是一份接受结果的账目；其可信内容分别追溯到数学正文、输入、源码和具体报告，字段齐备本身不构成独立证明。它明确不是外部同行评审，也不认证全局新颖性。

## 6. 如何接续

需要使用五人结论时，直接引用成熟定理的模型与完整证明。需要复现时，使用规范 `tools/half5-exact/` 包及绑定输入，先分清主全域核验、局部组件核验、K重构和旧引擎解析器；两份原主报告的时间不同不会要求重复发现证书。输入字节、关系证据及当前实际检查见[证据说明](<../../../../archives/customer-attraction/tools/evidence/half5-import-audit-and-acceptance-primary/README.md>)。

本次只作原文实读、原字节核对、报告结构比较和来源处置；原主程序、局部组件程序、旧引擎交叉核验、K重构均 **0次新运行**。六人半覆盖仍须独立处理五人结论无法直接承担的背景、首位和付款关系；本页不将这些开放问题填成已证。
