# 小目录硬度构造器与五地点样本的精确合同

## 对象与量词

两个构造器、三份实例及其三份metadata共八源、15,082字节，已逐函数、逐字段完整读取；八份原件及两条冻结提交路线见[manifest](../../../../tools/evidence/small-catalog-hardness-assets/source-manifest.json)。源码、实例与报告是不同对象：构造器输出输入，metadata保存原审计的结果；实例本身没有NE概率或完整续局。

这里始终是**两家带标签设施**。五地点和四地点指共同目录大小，不是设施数。每名客户有显式覆盖和严格正的原子权；被覆盖客户必须选择覆盖者，客户独立混合并最小化含自身权重的实际负载期望；设施最大化收到的期望客户权。共同目录允许同址。对每个带标签布局可分别选取一个精确客户NE，目标是**存在一个完整规则**及一个纯设施在轨布局使所有单方偏离倍率受控。\(\alpha^*(I)\)在全部布局、全部精确独立混合NE和全部完整规则上取最小，不是在某有限菜单上优化，也不是要求任意续局都稳定。

固定布局私有背景\(A,B\)、公共权\(w_i\)、第一设施概率\(p_i\)，有

\[
X=A+\sum_iw_ip_i,\quad Y=B+\sum_iw_i(1-p_i),\quad\Delta=X-Y,
\]
\[
p_i=1\Rightarrow\Delta\le w_i,\quad p_i=0\Rightarrow\Delta\ge-w_i,
\quad0<p_i<1\Rightarrow\Delta=w_i(2p_i-1).
\]

指定闭三态支持后，混合人数\(m\)、纯有符号和\(z\)满足
\((1-m)\Delta=A-B+z\)。\(m=1\)时保留整段闭区间；名义混合者可在端点变纯。原审计枚举这些全部支持，并另从条件成本直接验证端点及中点，未以概率网格代替实概率域。三态支持和负载片可能重复，计数都不是不同均衡数。

这些是facility-games原子客户模型，和六名单位提供者顺序选择主题、终局按覆盖者均分客户的CAG完整历史纯SPE不是同一模型；本资源不向Q-CAG-HALF-6建立结论迁移。

## 五地点构造器：输入、编码与实际覆盖

`five_site_hardness.py`的函数与CLI合同为：

| 入口 | 输入与结果 |
| --- | --- |
| `constants(a)` | 转为`Fraction`后精确检查\(a>1,a^2<a+1\)，搜索只依赖固定\(a\)的守卫常数 |
| `reduction(numbers,target,a)` | 非空显式正整数列表；每项须`type(x) is int`，目标也须严格整数且在\([0,\sum numbers]\)；返回有理实例和完整参数字典 |
| `integer_instance(instance)` | 对构造输出取分母LCM、统一放大、再除整数权的GCD；返回正整数实例和从归一化输入到整数输入的总倍率 |
| CLI | 必填`--factor --numbers --target --output`，可选`--metadata`；`--numbers`为逗号分隔整数；文件用`x`独占创建 |

`constants`依次试\(e=2^{-j}\)，取

\[
r_2=a+e,\quad r_3=\max(1,ar_2/2)+4e,
\quad r_4=\max(1,r_2/a,ar_3/2)+e.
\]

通过全部严格条件后才停：

\[
1<r_4<r_3<r_2<r_{10}=1+1/a,\quad r_2>a,
\quad r_2>ar_{10}/2,\quad r_3>ar_2/2,\quad r_4>ar_3/2,
\]
\[
ar_4>r_2,\quad ar_4<2,\quad r_2+r_3+r_4<4.
\]

余量为

\[
\eta=\tfrac14\min\{1,(r_{10}-r_2)/(1+1/(2a)),
2-ar_4,r_4-1,(4-r_2-r_3-r_4)/3\}>0.
\]

这不是源SUBSET SUM求解，也没有声称随输入\(a\)统一的多项式预处理界；五地点弱NP完全性正文把\(a\)事先固定为有理数\(1<a<\phi\)。已整理的[参数与判定前沿](../审查/实例最优计算的参数与判定前沿--审查.md)承担一般数学分类，本页保存程序的实际编码与输入资产，不另立同一个困难性定理。

设源为\(b_0,\ldots,b_{N-1}\)、目标\(K\)，令\(M=2\sum b_j+1\)，每对编码数为\(M5^j+b_j,M5^j\)。记其列表为`bounded`、总和\(U\)，原目标为\(R_0=M\sum5^j+K\)，程序实际使用补目标\(R=2U-R_0\)，并设

\[
d_0=R-U>0,\quad Q_0=2U+R+1.
\]

微群是每个`bounded`元素加\(Q_0\)，再加\(2N+1\)名权\(Q_0\)锚客户，共\(4N+1\)名，总重\(W_0\)。五进制没有进位，重数\(t_i\in\{0,1,2\}\)达到\(R\)等价于原子集和YES。宏原子守卫的作用是把这个局部源真正放进全部布局判定；局部困难性不能自行改名成全局困难性。

程序用\(\lambda=\eta/(W_0+d_0+Q_0)\)缩放，记\(W=\lambda W_0,d=\lambda d_0,Q=\lambda Q_0\)，定义

\[
H=1-W-d,\quad T=(H+1-Q)/2=1-\eta/2,\quad v_1=T/a,
\]
\[
v_2=r_2-H,\quad v_3=r_3-H,\quad z=r_4-1+d,
\quad P=1-v_2-v_3-z-W.
\]

实际JSON客户编号与地点编号都从零起：

| 客户编号 | 权重 | 覆盖地点编号 |
| --- | --- | --- |
| 0 | \(H\) | 0,1,2,3 |
| 1 | \(v_1\) | 0 |
| 2 | \(v_2\) | 1,4 |
| 3 | \(v_3\) | 2,4 |
| 4 | \(z\) | 3,4 |
| 5 | \(P\) | 4 |
| 6起 | 缩放微群，总重\(W\) | 3,4 |

`U1=U2=[0,1,2,3,4]`，总客户数\(4N+7\)，reach依次为\(H+v_1,r_2,r_3,r_4,1\)。源码逐项断言全正权、严格reach排序、\(z-d>W\)、\(T>ar_4/2\)及\(av_3<av_2<T\)。指数数值\(5^j\)的位长仅线性增长；统一清分母并除GCD保持全部NE及设施倍率，但整数数值总重可指数大。

在证明的1起始记号中，硬布局是\((4,5)\)，门控在轨是\((1,4)\)；对应JSON为\((3,4)\)、\((0,3)\)。硬布局reach差\(z-d>W\)迫使桥宏客户4在**所有**NE选地点4；反向任一缩减微群NE也可扩回，严格大于不可改为等号。缩减背景差为\(-d\)。微群最大负载差达到\(Q\)当且仅当源YES；所以地点5的最小收益

\[
\mu=(H+1-\max\Delta)/2\ge T,
\quad\mu=T\iff\text{源YES},
\quad\text{NO时 }\mu-T\ge\lambda/[2(4N)]>0.
\]

门控布局第一设施在轨收益\(v_1\)，偏离至地点5在任意续局至少得到\(\mu\)，而\(av_1=T\)。另十四种无序在轨类（五同址、九其他异址）有严格守卫。完整一般证明、位复杂度和NP成员性见[冻结证明](../../../../tools/evidence/small-catalog-hardness-assets/related/research/current/shared/five_site_exact_hardness.md)§3–11；不是由下面三次成功运行推出的。该证明不依赖全局黄金比上界；NO gap可能指数小，不能当固定常数或逆输入长度的gap。

## 为什么15客户不枚举同址仍可得到全局最优

原审计首段明确大例使用proved diagonal normalization；`optimum(...,full=False)`并未把同址忽略。下面给出补全理由，亦见[已整理同址正规形](../算法/同址平衡正规形与异址交叠参数精确优化--算法.md)。本批所有地点reach严格正，故不需零分母约定。

仅在不同地点上计算真实坐标极小\(m(s,t)\)，令

\[
H(t)=\max_{s\ne t}m(s,t),\qquad G_t=\max(1,2H(t)/R_t).
\]

任意同址\(t\)在轨NE两收益和\(R_t\)，至少一家≤\(R_t/2\)，且双方异址威胁相同为\(H(t)\)，因此其倍率至少\(G_t\)。每名客户独立对半又能达到\(G_t\)，所以同址最优恰为\(G_t\)，无需枚举其全部支持。

异址\((s,t)\)的第一负载闭区间\([l,h]\)、总负载\(V\)上，先忽略移到对方地点的同址偏离，最小化

\[
F(x)=\max\{1,H(t)/x,H(s)/(V-x)\}.
\]

最优点是\(VH(t)/(H(t)+H(s))\)夹到\([l,h]\)中。令全部异址片的最小放松值为\(a_O\)，全部同址最小值为\(a_D=\min_tG_t\)。真实最优至少\(\min(a_D,a_O)\)。若\(a_O\ge a_D\)，用同址候选达到\(a_D\)。若某异址候选\(a<a_D\)，则每个地点\(u\)都有\(H(u)>aR_u/2\)；其在轨约束推出

\[
X\ge H(t)/a>R_t/2,\qquad Y\ge H(s)/a>R_s/2.
\]

因此两家搬到对方地点后采用平衡同址NE，所得\(R_t/2,R_s/2\)都已受原在轨收益控制。其他异址偏离分别取真实坐标极小NE，可独立指定完整规则。故全局最优确为\(\min(a_D,a_O)\)；平局时取同址，不能无条件把放松异址平局候选认成合法达到者。

据此`full_diagonal_enumeration=false`只表示**不用逐同址支持枚举**，不表示全局优化缺了一部分。原`audit_case`还独立检查五同址及九个非门控异址的十四个严格守卫，并为YES实际构造和验证全部25布局。第三份资产的全局\(\alpha^*=809/500\)有该解析正规形、原全部异址支持枚举及完整达到证书共同支撑。

仍要区分表中各行的语义：`full=True`使用含同址的真实坐标威胁；`full=False`的同址项是精确\(G_t\)，**单个异址表项是忽略同址偏离的放松值**。上述论证认证其全表最小值，不能把每个放松异址项无条件称为该固定在轨布局的真实最优。保存完整原表正是为了保留这一差异。

## 四地点构造器：另一种精度间隙的输入资产

`four_site_fptas_hardness.py`没有CLI和NE求解器，仅有`parameters(values)`与`reduction(values)`。要求非空list/tuple，元素须严格正且`type(x) is int`。给源PARTITION列表\(b\)、\(T=\sum b\)，补辅助零至\(n=2\max(|b|,2)\)，实际变量客户数为\(n\)、总客户数\(n+6\)。辅助零不会生成零权客户。

归一化参数为

\[
\alpha_0=13/10,\quad M=5n/2,\quad\tau=1/(2n),\quad q=\alpha_0\tau,
\quad V=11n/2,\quad R=\alpha_0(V+\tau)/2,
\]
\[
w_i=1+(na_i-T)/(16n^2T),\quad d=27n/10,
\quad\text{scale}=80n^2T.
\]

地点顺序固定`0=B,1=C,2=A,3=D`：

| 客户 | 归一化权重 | 可达地点 |
| --- | --- | --- |
| 0，大客户 | \(M\) | B,C,A,D |
| 1至n，变量客户 | \(w_i\) | B,C |
| n+1，交叉客户 | \(q\) | B,A |
| n+2，B私有 | \(n-q\) | B |
| n+3，C私有 | \(n\) | C |
| n+4，A私有 | \(R-M-q\) | A |
| n+5，D私有 | \(n/5\) | D |

`reduction`直接写已乘scale的整数公式；不遍历到\(T\)、不搜索子集、也不计算实例最优。输出reach除scale后为\((9n/2,9n/2,R,d)\)，共同目录都为`[0,1,2,3]`。整数化保持精确NE和倍率；与五地点清分母后再除GCD不同，本程序保留固定scale，不另除GCD。

其被引用的数学合同是旁读[完整四地点内部证明](../../../../tools/evidence/small-catalog-hardness-assets/related/research/current/shared/four_site_no_fptas.md)与[独立内部审查](../../../../tools/evidence/small-catalog-hardness-assets/related/research/reviews/facility/four_site_no_fptas.md)的`SC-FOUR-NO-FPTAS`：源YES给\(\alpha^*=13/10\)，源NO给\(\alpha^*\ge13/10+1/(100n^2)\)。关键机制与五地点固定a弱困难性不同：\(\sum w_i=n\)、\(\sum|w_i-1|\le1/(8n)\)，变量带符号和为零当且仅当源可等分；NO时核心BC没有恰一名真正混合者，其他支持由\((1-m)\Delta=z\)与近整数扰动得\(|\Delta-\tau|\ge3/(8n)\)。两个唯一替代偏离的目标收益\(R,R-q\)满足\(2R-q=\alpha_0V\)，把负载差空隙转为核心倍率至少\(\alpha_0+1/(44n^2)\)。其他全部在轨类有解析守卫>1.31，因此得到所述全局NO界；同址守卫仅用较小收益≤reach/2，覆盖任意同址NE。

这个逆多项式n间隙可用加性精度\(1/(200n^2)\)或乘性精度\(1/(260n^2)\)区分源答案。原证明在P≠NP下排除确定性、位时间\(\operatorname{poly}(L,1/\varepsilon)\)、输出原实例完整精确客户NE规则及近最优设施倍率的FPTAS；随机常数成功率版本需要NP不包含于BPP等相应假设。它不排除固定精度PTAS、近似客户NE、相关随机化或一般盒内任意NE搜索。这里只说明构造器为何长成上述形状，不用程序成功替代该解析归约或重新认证文献优先权。
