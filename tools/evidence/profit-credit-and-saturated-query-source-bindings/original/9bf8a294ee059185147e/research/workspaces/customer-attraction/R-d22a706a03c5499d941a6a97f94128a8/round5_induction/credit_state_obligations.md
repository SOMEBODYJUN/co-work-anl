# 尾部信用状态：共享负载可加模板的解析障碍与剩余义务

## 所求信用的合同及排除循环定义

沿同一完整SPE的真实有序路径，在节点h记背景b、余r人、根行动A、根玩家最终收益u，尾部r人真实总利润P_h。令

    Δ_h=F_r(b)−F_{r−1}(b+1_A).

一个充分的信用合同是

    F_r(b)≤2P_h+C_h,
    Δ_h+C_{hA}−C_h≤2u,
    C_terminal≥0，C_empty≤0.                     (1)

后两项加上尾部归纳即推出第一项，逐层可得根half。允许负C是必要的；[all-big精确族](unbounded_profit_bellman_obstruction.md)在首个子节点强制

    2−h_n ≤ C_A ≤ 3−h_n,
    h_n=min_{1≤j≤n}(j+n/j)≈2sqrt(n).

因此非负信用、固定倍当前收益的信用上限、或仅标记“尾部half已成立”都不够。直接令C_h=F_r(b)−2P_h只将局部式变成等式，根C≤0则重述主目标，本文明确不采用。

## 共同覆盖客户的可加信用也不足

一个自然且可从实际负载直接计算的模板为

    C_r(b,c)=Σ_x f_r(b_x,c_x),
    f_r(0,c)=0，f_r(b,0)=0.                      (2)

这里c是r名真实剩余玩家的客户负载。函数族f_r在不同实例之间通用，只可依赖r和该客户的两个整数负载b_x,c_x；不得依赖实例客户总数、目录、其他客户负载或完整策略。f_r可任意依赖r，不假设连续性、符号、凸凹性或单调性。式(2)只允许“背景玩家与剩余玩家共同覆盖”的客户携带信用；无背景或无真实尾部覆盖的客户贡献零。

**结论。** 不存在一族如此实例无关的函数f_r，使(2)定义的C对任意目录和完整SPE同时满足(1)的尾部界与局部递推。这不是half证明的一般必要形式。这只排除该精确模板；允许未被真实尾部覆盖的背景客户携带信用、显式使用目录交叠结构、全局参数或真实离轨菜单的状态均不在排除范围。

### all-big族强制的下界

用all-big n人族，背景一名A、真实尾部r=n−1名全A。A的n名客户均有(b,c)=(1,n−1)，其他客户b=0。由(2)，

    C_A=n f_{n−1}(1,n−1).

真实尾部利润n−1，精确Ftail=2n−h_n。若尾部第一项(1)成立，必须

    f_{n−1}(1,n−1) ≥ (2−h_n)/n.                 (3)

由h_n≤2sqrt(n)+1，右侧≥1/n−2/sqrt(n)>−1/2，对每个n≥16成立。

### 原交叠族强制的上界

改用[原交叠无限族](profit_bellman_counterfamily.md)，仍是n玩家，实际路径(A,B^{n−1})。首位A之后，普通A/叶组的n−1名客户有(b,c)=(1,0)，其贡献由(2)为零；特殊A/B/叶组的n−1名客户有(b,c)=(1,n−1)；其余客户b=0，也贡献零。

所以

    C_A=(n−1) f_{n−1}(1,n−1).

根背景为空，(2)给C_empty=0。该族精确根台阶与当前收益为

    Δ=(17n−23)/6，u=n−1/n.

由根局部递推式(1)，必须

    f_{n−1}(1,n−1)
      ≤ [(23−5n)/6−2/n]/(n−1).                  (4)

当n≥10时，右侧严格小于−1/2：将分子与−(n−1)/2比较，差为

    (10−n)/3−2/n<0.

因此每个n≥16时，(3)要求同一个f_{n−1}(1,n−1)>−1/2，而(4)要求它<−1/2，矛盾。两份输入均有全历史纯SPE，并非任意非均衡负载向量的分离；两族精确最优利润均已由任意n解析证明。

## 这对新状态意味着什么

尚未发现可承担(1)的非循环状态。当前最小的**新增**承重义务不是再证明某个固定倍数的F台阶，而是：

> 构造一种能够区分上述两族的背景信用，并从真实偏离激励证明信用转移不等式Δ_h+C_{hA}−C_h≤2u_h，同时给独立于未知half差额的终端与根边界。

若坚持负载可加，至少必须允许c=0的背景客户参与，或让客户系数依赖其目录关联/其他全局状态。若选择主题结构或完整真实菜单，必须解释为什么这些额外资料可产生所需负信用，并在未假设F≤2P的情况下支付跨层差额。本文没有断言仅放开c=0就足够，也没有把“加入更多参数”当作完成。

两族对信用的冲突具有信息含义：同样的(1,n−1)共享负载在all-big尾部只允许约−2/sqrt(n)的每客户负信用，却在另一根递推中需要约−5/6。区别来自真实尾部未覆盖的旧客户与主题之间的替代结构；共享负载本身看不到这些资料。

## 为什么已有有限数据不能决定剩余义务

此前34棵完整策略的弱机会缺口优化针对OPT−W≤m u_i，既未覆盖全部策略，也未优化(1)的信用函数。19个实例的背景利润诊断只是给出有限节点F_r−P与当前收益的数值。它们都没有为一般目录提供信用的定义、跨分支递推或根边界。

本页的两个无限族仅排除(2)这一模板。它们不能否定依赖全部真实分支或目录关联的新信用，更不能否定half。现在缺少的确实是一个非循环、能看见不同分支替代结构的信用转移引理，而不是更多同类小实例的阴性结果。
