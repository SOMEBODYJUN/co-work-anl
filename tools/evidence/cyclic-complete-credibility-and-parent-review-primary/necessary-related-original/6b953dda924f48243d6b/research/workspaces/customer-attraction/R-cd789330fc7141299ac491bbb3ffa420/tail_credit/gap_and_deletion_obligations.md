# 低尾删除信用与强聚合gap：精确候选、两个停界及剩余义务

2026-10-23，Boss10/tail_credit。状态：研究备份；下述解析引理与反例边界已自检、定义级有限证书已复核，硬删除停界已获独立审查，孩子gap摘要障碍由root重构，见../parent/review_summary.md。一般 Q-CAG-HALF 仍 OPEN。没有外审或新颖性声明。

本轮不重调固定Bellman局部系数，也不再只读取旧客户的(b,c)直方图。核心候选读取同背景最优目录组合及全部真实尾部利润；两个停界分别说明“一个孩子gap标量”与“低尾亏空总量”丢掉了什么。

## 1. 精确一般候选 GAP-r

采用原CAG-MODEL。给定任意完整有序历史h、其背景客户负载b，余r名提供者，以及该子博弈的任意完整历史纯SPE。令c为真实r名尾部客户负载，

    P_h = Σ_x c_x/(b_x+c_x),
    F_r(b) = max_(q∈S^r) Σ_x c_q(x)/(b_x+c_q(x)),

零分子项均按零计。u_j为这r名玩家在同一真实终局中的收益。

**开放候选 GAP-r：对每个上述对象均有**

    F_r(b)−P_h ≤ r min_j u_j.                         (G)

这等价于对每一名剩余玩家j分别有F_r(b)≤P_h+r u_j。它不是把尾部利润P换成总覆盖，也不把背景玩家收益算进P。全部历史、任意平局、重复主题、空主题及零客户保留。

若(G)成立，r min u≤P，立即有F_r(b)≤2P。空背景F_m(0)=OPT_m，因此它足以推出Q-CAG-HALF。这里尚未证明(G)，也没有找到它的合法完整SPE反例。

### 已成立的小剩余人数基底

r=1时F_1=P。r=2时有更强的

    F_2(b)−P ≤ min(u_1,u_2).                          (G2)

证明：定义theta_2(b)=min_A max_B Σ_(x∈B)1/(b_x+1+1_A(x))。背景末两人逐人保底给两人的收益均≥theta，故P≥2theta。对实现theta的一个竞争主题A，任意两个比较主题q的负载c及A的负载d逐客户满足

    c/(b+c) ≤ (c+d)/(b+d+1).

c=0单列；c≥1时清正分母后的差为c(c−1)+bd≥0。右端是两个比较主题及A在同一静态背景下的查询收益和，每项≤theta，故F_2≤3theta。因此F_2−P≤theta≤min u。

这个基底使用[现行末两人背景定理](../../../../current/customer_attraction/last_two_floor.md)的确切量词，不限制背景为零。

## 2. 所有孩子都交出(G)，仍不足以仅凭根最优性归纳(G)

下述为一个**一般可扩展的伪菜单**。它不是完整SPE，也没有否定(G)或half；它精确排除一种丢失孩子内部可信性的归纳摘要。

固定整数k≥3，令

    r=(k−1)^2+1。

共同目录有r个两两不交的主题，每个主题恰k个单位客户；提供者数为r。对每个被强制的根主题a，规定一个伪终局：k人选a，其余r−k人各选一个不同的非a主题。根a后的尾部终局任取这些不同主题即可。

所有根的强制收益均为k/k=1，故只看这些列时，根选任意主题都满足全部根偏离不等式。在每个孩子背景b=1_a中：

    min_tail u = 1,
    P_tail = (k−1)+k(r−k),
    F_(r−1)(1_a) = k(r−1)。

Ftail的上界是每个被占主题至多贡献k，r−1槽至多占r−1个主题；选全部r−1个非a主题达到上界。因此

    Ftail−P_tail=(k−1)^2=r−1=(r−1)min_tail u。

**每个孩子的(G)总结恰好成立**，并且对孩子中任意一名玩家单独写Ftail≤Ptail+(r−1)u_j同样成立。但是根处

    F_r(0)=kr,
    P_root=k(r−k+1),
    F_r(0)−P_root=k(k−1)>r min_root u=r，

严格差为k−2。最小一例k3、r5：根最优15、真实菜单利润9、根收益1，根gap6>5；每个孩子最优12、尾利润8、最小收益1，孩子gap4=4。

由此得到的逻辑停界是：**“全部孩子的(G)结论 + 全部根偏离最优性”本身不能推出父节点(G)**。这是一个可变人数障碍，不是再调一个局部乘子的有限坏点。

### 为什么伪菜单不可信

在这个等大不交主题实例中，每个完整SPE都逐步选择此前未用的主题。直接按剩余人数归纳：任意非终端历史至少有一个未用主题；最后一人选择它得k，任何已用主题至多得k/2。更早的人若选择未用主题，按归纳假设后继继续选各自未用主题，故当前保留收益k；已用主题仍至多k/2。因此所有节点均选未用主题。

上述伪终局含k重复制，故不是任何完整SPE的终局。这个失败恰说明孩子还保留大量可信信息，而一个真实总利润/最小收益gap标量没有保留它。下一步若证明(G)，必须重新打开孩子内部的真实偏离或带入更丰富且非循环的菜单状态；不能把该伪菜单称作原猜想反例。

这个障碍还允许任意**预先固定深度d的真实末尾子树**。把每个伪终局按“先k次a，再r−k个不同新主题”的次序排列；选k足够大使r−k≥d。末d人开始时至少还有d个未用主题，所以末d人的指定新主题路径可以按上面的归纳扩展为该节点完整的真实SPE。这没有使前面的复制可信，只说明“孩子gap标量+最后固定d人的完整可信性”仍未补上一般归纳缺口；d须事先固定，不能把本段表述为孩子整个r−1人真实SPE。

## 3. 删除低收益尾部对根的精确harmonic信用

任一真实终局中，固定仍保留的根主题A及背景负载b。把其后尾部玩家分成保留H和删除L；令h_x、l_x分别为两组对客户x的负载。这里只做终局代数删除，**不声称删除后是较少人数的SPE**。

根在删除L前后收益分别为

    d_A = Σ_(x∈A)1/(b_x+1+h_x+l_x),
    d_A^−L = Σ_(x∈A)1/(b_x+1+h_x)。

所以精确释放信用是

    Γ_A(L)=d_A^−L−d_A
          =Σ_(x∈A) l_x/[(b_x+1+h_x)(b_x+1+h_x+l_x)]。   (D)

删除组在A上原来获得的总利润为

    P_L(A)=Σ_(x∈A)l_x/(b_x+1+h_x+l_x)。

因此Γ_A(L)是P_L(A)按客户乘1/(b_x+1+h_x)后的精确加权和，特别地0≤Γ_A(L)≤P_L(A)≤P_L。绝对利润是一个有效而可能很大的支付上界。

更一般地，令k_x为所有保留玩家（含根和背景）的负载。对k_x>0的客户，删除L释放给全部保留玩家的总收益恰为l_x/(k_x+l_x)，等于L原来在该客户上的收益；k_x=0的客户则完全消失。根只是其中一部分。该守恒不能把L的**低于某门槛的亏空**误认为其全部稀释能力。

## 4. 即使每个真实根尾部平均过线，低尾deficit仍不能支付根稀释

曾考虑一个明确的额外聚合合同：若全部真实根分支根收益d(a)<t，且每个真实尾部总利润P_tail(a)≥(r−1)t，则删除收益低于t的尾部L(a)后，根释放信用能否由

    Γ_a(L(a)) ≤ K Σ_(j∈L(a))(t−u_j(a))               (E_K)

控制，K为通用有限常数。下述真实完整SPE已否定每个这样的K。这个反例允许信用读取真实tail及根菜单，不是旧的(b,c)直方图碰撞。

复用已有六主题、36客户、13人的完整SPE；来源为[原始自足全文](../../R-c50fecc37aa44fb4a69a2122bb70e5fe/security/refined_tax_counterexample.md)。本轮独立重放其完整自动机，输入与在轨数据如下：

| 兴趣主题 | 单位客户数 |
| --- | ---: |
| A | 2 |
| B | 2 |
| T | 1 |
| T,D | 1 |
| T,E | 1 |
| A,D,E | 3 |
| B,D,E | 1 |
| P | 25 |

实际路径P^10,A,A,B，收益十二人5/2、末位3。全部六个真实强制根分支的根收益均5/2；它们的尾部总利润分别为61/2、63/2、63/2、61/2、61/2、61/2（根顺序A,B,T,D,E,P）。

任选0<epsilon≤1/24，取t=5/2+epsilon。因此全部根d(a)<t，且每个真实tail的总利润至少61/2≥12t。实际根P分支中低尾恰为后九个P玩家和两个A玩家。删除它们后根P从5/2增至25，所以

    Γ_P(L)=45/2,
    Σ_(j∈L)(t−u_j)=11epsilon。

给定任意有限K≥0，选择更小的正epsilon使11K epsilon<45/2，即违反(E_K)。K<0时右端为负而Γ>0，亦立即失败。**一个固定且真实完整SPE已给出无界比率。**

这准确否定任意门槛下的deficit-only稀释支付；它不否定可能把t固定为真正安全值、OPT相关值或其他额外内生值的不同合同。尤其本例根F13−P=36−33=3，而13 min u=65/2，故(G)远未失败。不能拿(E_K)失败冒充一般half反例。

两个抽象桥均已出现明确信息损失，不继续在同一桥上扩样或加固定系数。当前未决义务仍是(G)本身，或者一个直接half机制；若沿归纳，必须保留足以排除第2节伪菜单的真实孩子内部偏离，并且用第3节的绝对稀释信用而非第4节的微小deficit来支付低尾。这里没有给出满足这些要求的一般信用。
