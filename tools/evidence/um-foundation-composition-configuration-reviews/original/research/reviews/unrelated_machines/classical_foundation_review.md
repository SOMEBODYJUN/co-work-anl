## 2. 阅读正文前独立重构的 obligations

1. **目标身份。** 必须先固定一个与实例无关的正常数，再给一个统一确定性算法，最后量化所有有限二进制有理输入；机器数与任务数不固定。算法输出实际合法分配，运行时间按输入位长计。估值、随机期望、固定机器数、准多项式和额外输入承诺均不能关闭该目标。
2. **零与不可用边。** 非负性下，OPT=0 等价于每任务各有一条零边，必须精确分配到这些零边。空任务应输出空分配。不可用边必须从合法分配与配置中排除，不能以有限大数替代而悄悄改变输入。
3. **舍入链。** 给定剪枝后的有理可行分数解，需同时证明槽数及精度为多项式、Hall 条件、匹配保持原支撑，以及每机器的负载界；仅证明全局总负载无用。排序方向和前一个槽是否满是最易出错的两点。
4. **算法复杂度。** 给予可行 x 的舍入复杂度与从原输入求 x、选择 T 的复杂度必须分开。二分次数取对数才可按位长多项式；逐个整数目标扫描不可采用。指数配置 LP 的精确求解不是免费步骤。
5. **间隙链。** 下界族必须为每个参数给有限合法输入、有正确负载的配置证书、对所有整数分配成立的下界，并允许参数趋于无穷。证书阈值只给 T_CONF 的上界；除非另证，不能说它等于 T_CONF。supremum 为 2 不表示某个有限实例比值恰为 2。
6. **结论边界。** 间隙排除的是相对该松弛阈值的统一小于 2 的舍入保证，不是相对 OPT 的所有算法。单机有效切面受局部凸包限制，跨机器关系或其他下界仍可能提供新信息。

## 3. 排序槽、量词与位长的逐项攻击

正文在模型中保留 m≥1、n≥0，时间为非负有理数或明确不可用标记，且每任务至少有一条有限边；零值归一化之前已单独处理。ε∈(0,1) 不损失所问的存在性：若有更强有效常数，也可降低 ε。

对机器 i 的正支撑按处理时间非增序连接成分数区间。由每任务总质量为 1，每个 x_ij≤1；故每个正区间最多跨两个单位槽，支撑边与槽数有多项式上界。任何任务集合的全部单位质量流入其邻槽，槽容量至多 1，因此 Hall 条件直接成立；并不要求最后一个槽满，也不要求分数解为 LP 极点。

若槽 r≥2 有匹配任务，则槽 r−1 必在该机器连续填充区间内部，因而确实为满的单位槽。槽 r 的任意正交长任务，处理时间都不大于槽 r−1 的任意任务处理时间，包含同一任务跨槽的相等情形。因此槽 r 的整数负载可收费给槽 r−1 的分数负载。无匹配槽贡献 0，收费槽互不重叠；首槽再收费至多支撑最大值。该证明覆盖 0、排序平局、分数边界恰为整数及空支撑。

代码的增广路为显式广度搜索，未依赖 Python 递归深度。检查支撑、任务守恒及分数负载在匹配前执行。所有端点、交长和比较使用 Fraction/整数。这里多项式时间是相对 **p、x、T 的合计编码长度**；不把给定 x 的位长忽略，也不把本文有限枚举 oracle 当作多项式求解器。

正文把通用 LP 求解与目标搜索列为需另接的程序，未声称已完成该实现。清全部分母后的整数时间可二分；公共分母积的位长至多分母位数总和，给定一个合法分配即有位长受控的上界。因此不存在需要用伪多项式遍历目标来挽救这里舍入证明的缺口。

## 4. 配置树族的独立代数与整数攻击

以终端平行边所在父端为高度 1。终端每个单任务配置质量 1/k；其父端 k 个含 incoming 与一条 small 的配置各质量 1/[k(k−1)]，其余质量选全部 small。故 incoming 的基例边际为 α₁=1/(k−1)，每条 small 总覆盖为

`1/k + 1−1/(k−1) + 1/[k(k−1)] = 1`。

父端子树 incoming 边际为 α_r 时，设父端含自身 incoming 的总质量为 a。某条 small 在该父端的边际为 `1−a+a/k`，需与子树边际 α_r 合计为 1；唯一解为 a=kα_r/(k−1)。所以 α_h=q^(h−1)/(k−1)，不是 q^h/(k−1)。k≥4 与最小高度共同保证 1/2≤α_h<q/2≤2/3，全部局部权重合法；这不是靠有限运行推得的归纳结论。

两根未经处理时，公共大任务覆盖为 2α_h，可能严格大于 1。正确操作是在每个含大任务的配置中，以质量比例 1/(2α_h) 保留它，否则只删除大任务。归一化和每条 small 的边际均不变，根大任务边际恰为 1/2。根部合并后所有任务总覆盖恰为 1。删除任务不增负载；所有所用配置的负载都至多 1+1/k。代码确实做了此操作，没有误把 entire configuration 丢弃。

图的平行边表示不同任务，两个端点是不同机器；根间任务也仅有两台机器。因而每任务恰有两条有限边，既没有第三台隐藏机器，也没有把两端处理时间错误设为相同。

整数下界可不依赖 LP：从收到根间大任务的根出发，若 makespan<2，每个已有 incoming 大任务的内部点都必须把至少一条 small 下传。最终到达终端平行边父端；若下传两条，终端负载至少 2，否则父端负载至少 1+(k−1)/k。正文另给一条下传路径的可行分配达到 2−1/k，故所构造族的整数最优值精确已知。

配置证书只证明 `T_CONF≤1+1/k`。结合整数最优值，实际比值至少为 `(2k−1)/(k+1)=2−3/(k+1)`；分母方向正确。上界则由配置投影与排序槽舍入给出。任意统一 ε>0，取 k+1>3/ε，即反驳相对该配置阈值的 `(2−ε)T` 保证。该操作没有关闭 `UM-TARGET-v1`。

新增审计可在仓库根目录用下列代码重跑；它调用被审舍入，但独立计算目标与输出负载，不把被审程序自己的 assert 作为唯一判断：

```python
import importlib.util, itertools
from fractions import Fraction as F
spec = importlib.util.spec_from_file_location(
    "baseline", "tests/audits/unrelated_machines/rounding_and_gap.py")
mod = importlib.util.module_from_spec(spec)
spec.loader.exec_module(mod)
matrices = rounds = zero_targets = 0
for flat in itertools.product((None, 0, 1, 2), repeat=6):
    p = [list(flat[:3]), list(flat[3:])]
    if any(p[0][j] is None and p[1][j] is None for j in range(3)):
        continue
    matrices += 1
    choices = [(F(0),) if p[0][j] is None else (F(1),)
               if p[1][j] is None else (F(0), F(1, 2), F(1))
               for j in range(3)]
    for first in itertools.product(*choices):
        x = [list(first), [1-v for v in first]]
        frac = [sum(F(p[i][j] or 0)*x[i][j] for j in range(3))
                for i in range(2)]
        largest = [max([F(p[i][j]) for j in range(3) if x[i][j]]
                       or [F(0)]) for i in range(2)]
        target = max(frac + largest)
        sigma, actual = mod.round_slots(p, x, target)
        independent = [sum(F(p[i][j]) for j in range(3) if sigma[j] == i)
                       for i in range(2)]
        assert actual == independent
        assert all(independent[i] <= frac[i]+largest[i] <= 2*target
                   for i in range(2))
        rounds += 1
        zero_targets += target == 0
fixtures = [([[]], [[]], 0),
            ([[0, 0], [0, 0]],
             [[F(1, 3), F(2, 3)], [F(2, 3), F(1, 3)]], 0),
            ([[2, 1, 0], [1, 2, 0]],
             [[F(1, 3), F(2, 3), F(1, 2)],
              [F(2, 3), F(1, 3), F(1, 2)]], F(4, 3)+1)]
for args in fixtures:
    mod.round_slots(*args)
invalid = [([[1, 0]], [[F(-1), F(2)]], 2),
           ([[0]], [[True]], 0), ([[0.0]], [[1]], 0),
           ([[None]], [[1]], 0), ([], [], 0), ([[0]], [[1]], True)]
for args in invalid:
    try:
        mod.round_slots(*args)
    except ValueError:
        pass
    else:
        raise AssertionError("Invalid accepted")
for k in range(4, 65):
    h, a = mod.height(k)
    q = F(k, k-1)
    assert a == q**(h-1)/(k-1) and F(1, 2) <= a < q/2 <= F(2, 3)
    assert h == 1 or a/q < F(1, 2)
    result = mod.compressed_gap(k)
    assert F(result["optimum"]) == F(2*k-1, k)
    assert F(result["gap_lower_bound"]) == 2-F(3, k+1)
    for level in range(1, h+1):
        alpha = q**(level-1)/(k-1)
        assert 0 <= alpha <= 1 and (1-alpha)+k*(alpha/k) == 1
        if level > 1:
            assert 1-alpha+alpha/k+alpha/q == 1
    assert a*(1/(2*a)) == F(1, 2)
print(matrices, rounds, zero_targets)  # 3375 35937 729
```
