# 二分配置核的双符号坏枢轴：独立陈述先行重构

本记录先按 root 提供的精确陈述独立构造；写成之前未读取该新命题的作者证明。它证明一个指定方向的两个最大符号端点都坏，不声称所有方向坏，也不构成 UM-TARGET-v1 的困难性。

## 精确输入和结论

给一般 UM 矩阵 P，m≥2、n≥1，以及阈值1的显式有理 CONFIG 证书 y。每行配置权和1，每任务总覆盖1。记其边际为 x*，正支撑 E+，d=|E+|，行负载 ell_i=sum_j p_ij x*_ij≤1。假设每任务的正支撑至多两个机器，且这两个机器若都存在便分属一份给定二分染色的两色。允许 P 还有 x*=0 的有限端；它们不进入下述活支撑。

固定有理 epsilon∈(0,1)，beta=(1−epsilon)/4。可在包含显式证书的输入位长多项式时间构造一个普通 UM 扩展、一个有显式多项式支撑真实最优分解的初始点、以及一个零空间方向，使：

1. 扩展的真实 OPT=1；初态不是仅有松弛身份。
2. 两个最大正负步长均为1/2；任务等式和全部保护机器负载均保持，初始计数余量严格正。
3. 整段两个符号路径上都有完整 CONFIG(1) 证书。
4. 在任一最大端点永久删除零端并固定整数任务之后，任何保持此活支撑及固定位置的完整调度，其 makespan 至少为 OPT(P)。

若 OPT(P)>2−epsilon，则两个符号端点都没有所要求的次二补全。该命题没有 full-column-rank 或 D=0 结论。

## 两份扩展与路径

复制 P 两次，记 A、B。每份对每个原任务 j 添加它自己的私人机器 U_j，私人端时间 beta；对每个核机器 i 添加一个 filler G_i，其核端时间 ell_i，私人端在另一台自己的私人机器 V_i 上、时间 beta。所有 U_j、V_i 均互异且不与核机器同一化。再加一台私有机器和一个只在该机时间1的 anchor；它从初态即固定。

对单份复制定义参数 lambda∈[0,1] 的边际：

- 原核端为 lambda x*；原任务私人端为1−lambda；
- filler 核端为1−lambda；filler 私人端为lambda。

两份取 lambda_A=1/2+t，lambda_B=1/2−t，−1/2≤t≤1/2。方向就是对 t 求导。对每个原任务，其核方向和为±sum_i x*_ij=±1，私人方向为∓1；filler 的两个方向相反，故全部任务方向和0。核行方向负载为±ell_i∓ell_i=0。

在开区间内所有这些坐标严格介于0与1；核原端因0<x*≤1也不会先到边界。到 t=±1/2 时，一份 lambda=1，另一份 lambda=0，私人/filler 坐标同时到边界。因此两个最大步长都精确为1/2。

## 初态真实最优分解，而且支撑多项式

先只看一份复制。在两色中均匀选择活颜色。活颜色的每台核机器 i 选择其 CONFIG 配置 C_i；非活颜色机器仅执行自己的 filler；活颜色的 filler 去自己的私人机器。每个没有被某个 C_i 选中的原任务去自己的私人机器。

同一任务不可能被两个活核机器同时选中：其正支撑至多两个，且若有两个则颜色相反。因而每个样本都是完整合法分配。活核配置负载≤1，非活核 filler 时间 ell_i≤1，所有私人行负载≤beta<1；anchor 负载1。故这些样本都是 OPT=1 调度。其原核边际为 x*/2，原私人边际1/2，filler 两端边际也各1/2，正好是上述 t=0 点。

不必独立采样所有配置行。将每行 y 的配置按输入次序排列，收集所有行累计权重的断点以及0、1。至多 2+sum_i |supp(y_i)| 个断点把[0,1]划成多项式个正长区间。给每个区间一个公共 U，所有活行都取各自 inverse-CDF 在该区间的配置。这样每行仍有原分布 y_i；由于“不重复选任务”对任意行配置组合都成立，共用 U 不损可行性。每个颜色与每个区间给一个实际最优调度，权为区间长度的一半。两份复制可以使用完全相同的颜色和区间，因此整体仍只有这多项式个原子。累计和、精确排序、原子权与全部调度的编码位长均为输入多项式。

## 删除规则与严格计数余量

定义 s_i=sum_{j:(i,j)∈E+}p_ij。每个私人行初态只有一个时间 beta、边际1/2的端，故 E=beta/2<1−epsilon，均可先永久删除负载等式。anchor 已固定。核行在开路径上满足

E_i=sum_j p_ij(1−lambda x*_ij)+ell_i lambda=s_i，

所以它们的保护状态不会在路径内部改变；受保护者的分数负载恒为 ell_i≤1。初态最多2m个保护核行，且

N=2(d+n+2m)，J=2(n+m)，P_protected≤2m，

从而 N−J−P_protected≥2d>0。这里 n≥1及任务覆盖保证 d≥1。零时间 filler 核端仍可作为正分数变量计数，并不影响论证。

## 全路径 CONFIG 与两个端点的不可补全

在任意 lambda，核行 i 使用配置分布：对原配置 C 赋权 lambda y_i,C，并以权1−lambda取 singleton {G_i}。每个配置负载≤1，权和1，边际正好符合路径。原私人行用 singleton 概率1−lambda；filler 私人行用 singleton 概率lambda；余权取空集。anchor 用确定 singleton。这给每个 t 的完整 CONFIG(1) 证书。

在任一最大端点，lambda=1的那份中，全部原任务私人端都变成0并被永久删除；filler 全部固定在各自私人行。该份所有原任务只能使用原核正支撑，所以任一完整补全限制到这些原任务后，是 P 的一个合法分配（可能还被限制到更小支撑）。其最大核负载至少为 OPT(P)。lambda=0的另一份以及 anchor 不会降低这个下界。故两个符号均坏。

## 范围与有限审计

反例只攻击“任选一个合法方向，试两个最大符号，然后永久删零/固定”的一般充分保证。它不说明其他方向、回退、重新开放私人端或保持更强全局信息的算法失败。二分性和每任务正支撑至多2在初态真实耦合中承担不重复选择；完整 CONFIG 的全路径可行并不提供这样的全局耦合。

独立最小审计采用4机器7任务的二分核：桥在两根均3/4，每根三任务在根1/4、自己的终端3/4。根配置为三项“桥+一小项”各权1/6及“全部三小项”权1/2，终端三个 singleton 各权1/3。128个原分配给 OPT=5/4；显式上下界也直接成立。脚本核初态全部真实原子、两个最大方向、各中间 CONFIG、计数及两个端点全部128个核补全。此有限核验不替代上述一般证明，也不假称该小核已给趋二族。

## 数学攻击与覆盖

### 紧凑零缺陷历史

逐项核了原矩阵、m 个最优分量、边际和真实 OPT=1 下界。初始 home 负载为1，sink excess 为 `2 beta q < 1−epsilon`；处理后 home 的 excess 为 `q=1−1/m>1−epsilon`。方向 `(1,−1,−(m−1),m−1)` 保持两个任务等式及所有保护行，四个边界比值都为 `1/m`。这是最大步长，不是挑选的短步。

在 a 个未处理组时，实际变量、任务、保护行数分别是 `m+4a,2a+1,m`。外端列先消掉任务行依赖，再由 home 列和锚端消掉保护行依赖，故 a≥1 时秩恰为 `J+P`，零空间维数 `2a−1`。终态 home 行在锚变量上是单位矩阵，秩恰 m=N；D=0，任何固定任务补全都恰为 `2−1/m`。紧凑方向立即违反 `x_B+x_A≤1`，因此它不能被解读为保持 CONFIG 的反例。

### 一次 CONFIG 激活提升

输入中的显式 CONFIG 证书及其成员编码必须计入输入长度。每次只激活一个 core 的真实分布至多含 `sum_i k_i` 个原子，概率 `y_i,C/m`；所有未选原任务去各自独立私人机，inactive filler 留 home。anchor 强制真实 OPT=1。

路径采用 `lambda*x*` 原核端、`1−lambda` 原私人端、`1−lambda` filler home 端和 `lambda` filler 私人端。每 core 负载恒为 ell_i，excess 恒为 S_i，私人行可安全先删除；`N−J−P≥|E+|≥n≥1`。沿途完整 CONFIG 证书是 `lambda*y_i,C` 加权原配置，以及权 `1−lambda` 的 filler singleton，私人行各自 singleton/empty。

首次正向边界精确在 lambda=1。端点中若某原任务已整数固定，则它在 P+ 本来就只有唯一正支撑端；固定不额外缩小 P+ 的实际分配集合。因此最佳固定支撑补全**恰为** `max{1,OPT(P+)}`，不只是下界。旧输入中 x*=0 的有限端不能偷偷重新开放；P+ 的定义处理了这一点。

### 同一方向的两个最大符号

每个任务在一个活颜色至多有一台 core 可选，所以任意活行 CONFIG 组合均不重复选择任务。按每个颜色分别合并 inverse-CDF 累计断点，可把原子数界收紧到 `2+sum_i(k_i−1)≤2+sum_i k_i`；空颜色贡献一个区间。两个相同副本复制同一个原子，故不用取指数独立乘积，原子数也不翻倍。

两个副本的参数 `1/2+theta,1/2−theta` 给出同一方向。开区间所有非 anchor 变量仍严格分数，两个符号的首次边界都精确是 `|theta|=1/2`。一个副本变为 P+，另一个已经是完整整数调度，因此两端最佳补全均为 `max{1,OPT(P+)}`。

精确秩还有一个直接子式证明：选择所有原任务私人端、所有 filler 私人端列对应全部 J 个任务行，再选择每个保护 core 的 filler home 列对应其保护行。子式按块为三角，行列式为全部保护 ell_i 的乘积。`S_i>1−epsilon>0` 与正支撑定义推出 ell_i>0，所以该子式非零；即使其他 core 为全零行也不影响。故秩恰 J+P，零空间维数恰 `2|E+|+2m−P`。4核种子的这个30阶子式由另行 Fraction 消元实际得到 `194481/1048576`，N=58，零空间维数28。
