## 2. 真实完整 SPE

`positive_depth_floor_certificate.json` 的400个有序历史逐一给定行动，
深度0,1,2,3分别为1,7,49,343个。实际终局是

\[
z=(B,0,3,4),\qquad
u=(19,29/3,67/6,67/6),\qquad W=51,\quad OPT_4=53.
\]

审计不导入均衡求解器：对每个完整有序历史 h，沿保存的规定动作得到真实叶；
再对七个动作 A 逐一在 h 强制 A，以**同一保存策略**继续到真实叶，
比较当前者收益。2800项（含自身行动）全部非负，2400项非自身比较中
2219项严格、181项平局。因此这是全部离轨历史的纯 SPE 证书，
没有只验证实际路径或冻结后继。

策略的发现用规范集合值逆推生成目标路径 `(6,0,3,4)`。
发现器和其计数缓存不是该证书正确性的依据；上述逐有序历史直接比较是依据。
父研究员另在研究任意人口的 reservation 解析提升，本页不冒称已证明该一般引理。

## 3. 真正 v_4 的匹配有理证书

查询原始分布是

\[
p=(570,570,1197,570,570,1197,1174)/5848.
\]

静态对偶分布 Q 如下；查询抽样与竞争背景独立。

| 三槽竞争背景 | 概率分子，公共分母14620 |
| --- | ---: |
| (0,1,2) | 370 |
| (0,1,B) | 3941 |
| (0,2,B) | 1481 |
| (1,2,B) | 1481 |
| (3,4,B) | 4089 |
| (3,5,B) | 1629 |
| (4,5,B) | 1629 |

对全部343个有序三槽背景 R，直接按客户类型计算得到

\[
\min_R\sum_Ap_A\sum_{x\in A}\frac1{1+c_x(R)}
 =\frac{28481}{2924}.
\]

对七个纯查询 A，各个对偶期望**均**为 `28481/2924`。
原始下界与对偶上界匹配，故真正静态最大最小值精确为

\[
\boxed{v_4=\frac{28481}{2924}},\qquad
\boxed{v_4-u_2=\frac{647}{8772}>0.}
\]

这不是受限真实菜单值，不是 iid 值，不是非最优查询造成的负预算。
第二位置是实际路径上的严格失败。
