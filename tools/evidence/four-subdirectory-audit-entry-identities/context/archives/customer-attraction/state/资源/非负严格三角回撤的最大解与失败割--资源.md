# 输入与最大可行点

n个有序指标、b_i≥0、有限实a_i=c_i−F_i，非负t_iℓ只允许i<ℓ，其余0。求

\[0\le y_i\le b_i,\qquad
 y_\ell-\sum_{i<\ell}t_{i\ell}y_i\le a_\ell.\]

一般lemma不需Σ_ℓt_iℓ=1。若应用输入t=K/b，b_i0时非负K行和b_i迫整行0，取t行0不除零。

升序计算z_ℓ=a_ℓ+Σ_(i<ℓ)t_iℓ g_i；若z_ℓ<0失败，否则g_ℓ=min(b_ℓ,z_ℓ)。完成则g直接满足盒与全部行，故可行。任意可行y若前坐标y_i≤g_i，由t≥0得y_ℓ≤a_ℓ+Σt_iℓy_i≤z_ℓ及y_ℓ≤b_ℓ，所以y_ℓ≤g_ℓ。首次z_j<0时任何可行y都需0≤y_j≤z_j<0，矛盾。因此完成 iff可行，且完成的g是 **逐坐标最大的** 可行点。b0、z0、负a与z=b平局都包括。

# 任意非负价格的必要割

给λ_i≥0，q_i=Σ_(ℓ>i)λ_ℓt_iℓ。将行乘λ求和并用盒约束，得

\[\sum_i\lambda_i a_i\ge\sum_i(\lambda_i-q_i)y_i
\ge-\sum_i b_i(q_i-\lambda_i)_+,\]

所以所有可行输入满足

\[C(\lambda)=\sum_i\lambda_i a_i+\sum_i b_i(q_i-\lambda_i)_+\ge0.\]

这尚不是游戏IC；λ只是该固定三角系统的价格。

# 首次失败的显式负割与准确符号

若贪心首次在j失败，取λ_j=1、λ_ℓ=0对ℓ>j。向后i=j−1,…,1依次算q_i，并取λ_i=q_i若g_i<b_i，λ_i=0若g_i=b_i。未饱和时g_i=z_i，饱和时g_i=b_i；平局也按饱和处理，b_i0无异常。

仅为代数把g_i=0延伸至i≥j、z_i仍用同一表达式，则

\[
C(\lambda)=\sum_i\lambda_i(z_i-g_i)
+\sum_i[(\lambda_i-q_i)g_i+b_i(q_i-\lambda_i)_+]=z_j<0.
\]

第二和每项0，第一和除j外皆0。不需要定义一个实际g_j贪心值。因此可行 iff所有非负价格cut非负；失败者已由算法给，不借一般Farkas oracle。

割等于负值 **z_j**，不是−z_j。单指标b₁0、a₁−1给z₁=C(1)=−1。原稿的这项sign correction保留；当前来源路由对象也已正确，不重复构造勘误。

# 计算与应用域分开

给定完整t矩阵用O(n²)次加乘比较得到g或λ；有理输入可精确算，strict triangular有界深度的路径乘积和控制位长，多项式二进制实现不需浮点容差。对任意未编码实数只陈述有限数学步骤，不凭空宣称机器bit复杂度。

一般t≥0时λ可超过1；只有游戏路由进一步有正b行Σt=1（零行0），逆向归纳才得价格在[0,1]。不能把应用的这个额外界倒填泛用lemma。

固定来源CAG应用中，若已建立合法付款点A_i≤2u_i、来源future库存b_i、严格未来终端K_iℓ≥0且Σ_(ℓ>i)K_iℓ=b_i，便有F_ℓ=A_ℓ+Σ_(i<ℓ)K_iℓ，撤回y_i按来源全路由同比例缩放、回到原actual角色，费用变

\[F'_\ell=F_\ell+y_\ell-\sum_{i<\ell}(K_{i\ell}/b_i)y_i.\]

此时a_ℓ=2u_ℓ−F_ℓ，三角系统恰判这份固定路由能否修到共同cap。若成功且总库存确为比较覆盖O，ΣF'=O给O≤2W；但lemma没有保证所有SPE都能成功，没有生成合法初始付款、退款身份、非负未来增量或独立来源上限，也不允许遗漏shared capacity。修复还可超原initial u_i上限、只是共用最终2u_i cap，不能说仍在原INIT多面体。
