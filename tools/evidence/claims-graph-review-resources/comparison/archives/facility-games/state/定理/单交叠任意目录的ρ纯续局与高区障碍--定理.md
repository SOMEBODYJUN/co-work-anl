# 单交叠任意目录的ρ纯续局与高区障碍

## 模型、规则及定理

两个带标签设施的目录$U_1,U_2$有限非空，大小任意，可相交；有限正实权原子客户有固定地点覆盖，覆盖后必须服务，客户费用是所选设施包含自身完整重量的实现负载期望，设施收益是服务权期望。客户可独立混合，完整续局逐有序布局独立指定精确客户NE。要求

\[
|C_s\cap C_t|\le1\qquad(s\in U_1,t\in U_2),\tag{H}
\]

含合法同址，所以目录共同地点最多覆盖一客户。同一客户允许覆盖任意多行列；不把它在不同格的出现视为不同原子。

令$\rho=2\cos(\pi/7)$，$q(r)=r^3-r^2-2r+1$；$\phi<\rho<2$且$q$在$[\phi,\infty)$严格增。按带标签行动的$(reach,priority)$升序固定任意全序$\prec$。每格唯一共同客户选较小行动，其他客户强制；无共同客户全强制。唯一共同客户的两条件成本恰为两reach，故这是一套**预先固定的完整纯客户NE规则P**，reach平局由全序解，物理同址的两个设施标签仍不同。

**SPARSE-RHO-ALL。** 对每个满足(H)的输入及任意上述固定全序，P至少有一个纯设施布局，使所有全目录真实偏离收益不超过当前收益ρ倍。结合[六客户2×2族](单交叠短目录的ρ稳定阈值与六客户锐族--定理.md)，最小普遍因子恰ρ，且下界排除全部混合NE乃至CCE续局。上界不声称任意逐格平局选择或任意混合续局都稳定；它使用这一全局优先级规则。它不是多交叠或一般共同目录的锐常数，也不依赖一般异构因子二候选。

## 任意r的高区下降与平衡子类

在P中以**整个原目录**计算

\[
F_1(t)=\max_sP_1(s,t),\quad F_2(s)=\max_tP_2(s,t),
\quad b_1(t)\in\arg\max_sP_1(s,t),\quad b_2(s)\in\arg\max_tP_2(s,t).
\]

回应平局可任意固定破除，行指向$b_2$列、列指向$b_1$行。P是固定规则，其$F_i$不是允许每格优化NE后的真实坐标极小威胁。布局r稳定恰$F_1(t)\le rP_1(s,t),F_2(s)\le rP_2(s,t)$，包含不动项不加限制，因为$r\ge1$。零收益始终用此乘法式。

记$M_1=\max_sR_s,M_2=\max_tR_t$。对任意$r\ge1$，称$R_s\ge M_1/r$的行为高行，$R_t\ge M_2/r$的列为高列；等号算高。若P没有r稳定格，高行$s\to t=b_2(s)$必有唯一共同客户i分给列，满足

\[
t\prec s,\qquad w_i>R_s-M_1/r.\tag{1}
\]

证明：列已得全行最佳，若行得到全reach，其全部偏离至多$M_1\le rR_s$，格已稳定。故它失去共有客户；行必须有真实偏离收益$>r(R_s-w_i)$，又不超过$M_1$，得(1)。高列对称，有$s=b_1(t)\prec t,w_i>R_t-M_2/r$。证明未除当前收益，零到正改善亦覆盖。

因此高行动诱导图无有向环：每边严格下降于带标签全序，而非必须严格下降数值reach。有限出度一回应图每个环都须含低行$R_s<M_1/r$或低列$R_t<M_2/r$，不限制环长和客户身份总数。

**SPARSE-BALANCED-R。** 若两边每个行动均高，P必有r稳定格，否则回应图既有环又无高区环，矛盾。若任一侧最大reach为0，该方收益恒0且无正收益偏离，任取其行动、另一方取全目录最佳回应即精确稳定。故零reach退化也完整覆盖。反之若某输入在全部混合规则下的最优倍率$>r$，任一P当然无r稳定格，每个完整目录回应环必须进低区。这是必要障碍，不是说出现低点就一定坏。

## 首个高→低入口的排除：r≥ρ

反设P无r稳定格，$r\ge\rho$。排除零最大reach后，两方最大reach记$a,d>0$。高区非空，每条仍留高区的出边严格下降；若无高→低边，高区是非空有限出度一闭图而必有环，矛盾。交换设施标签可把一条高→低边记作高列$C\to B=b_1(C)$，不预设$a,d$大小。

记$c=R_C\ge d/r,b=R_B<a/r$，取最大reach行A。令$\beta=F_1(C)=P_1(B,C)\le b<a$。AC中行不能得全a，故必失去唯一共同客户x，权$X>0$，收益$(a-X,c)$。列已获全reach，其任何偏离至多$d\le rc$；AC坏只能由行造成：

\[
\beta>r(a-X),\quad \beta\le b<a/r
\ \Longrightarrow\
X>a-b/r>a(1-1/r^2)>a/r>b.\tag{2}
\]

最后严格号用$r>\phi$。B的总reach小于X，所以B不覆盖**这个客户x**；C覆盖它，故BC的列收益至少X。B已是C列的全目录行最佳回应，BC坏只能由列造成。取$D=b_2(B)$，reach$d'$，则

\[
d'\ge F_2(B)>rP_2(B,C)\ge rX>a.\tag{3}
\]

AD中行reach较小，得全a，任何行偏离均不提高。因此坏只能由列造成。令$E=b_2(A)$、$e=R_E$。A是高行，由(1)得$E\prec A$，所以在AE列得全reach，$F_2(A)=e\le a$（相等reach也由优先级保证此分配）。若AD无共同客户暂取Z=0，否则其共有客户z权Z；AD收益为$(a,d'-Z)$，于是

\[
e>r(d'-Z),\qquad d'-Z<e/r\le a/r.\tag{4}
\]

由$d'>a$知Z不能为0。若z和x不是同一客户，它们均覆盖A，正权可加性给$Z\le a-X$，故

\[
d'-Z\ge d'-a+X>X>a/r,
\]

违(4)。因此z=x、Z=X；相同权重不足以替代此身份结论。

合并(3)(4)，再用(2)，

\[
r(r-1)X<r(d'-X)<e\le a,
\qquad a<\frac{r^2X}{r^2-1}.
\]

$X>0$使$(r-1)(r^2-1)<r$，即$q(r)<0$。而$r\ge\rho$时$q(r)\ge0$，矛盾。两色入口由交换标签全覆盖，所以反设不成立。取$r=\rho$即得定理；严格三次式在ρ端点也排除入口，不需要任何固定短核心或低区返次数界。

## 完整规则、锐性和构造复杂度

P在所有布局已指定纯客户NE，找到的格相对于原全部目录满足两条$F_i$不等式，因而不是只在环内成立的结果。[短目录六客户族](单交叠短目录的ρ稳定阈值与六客户锐族--定理.md)在每个$1\le\alpha<\rho$给正整数2×2输入，四格都存在严格坏偏离，且NE/CCE唯一，属于本任意长类；因此上下界合成普遍锐常数ρ，未要求有限有理输入恰取无理ρ。

显式有理输入可逐地点算reach、逐跨对核(H)、按全序构造P矩阵，求所有$F_i$后扫描全部格。保守$O((n+1)|U_1||U_2|)$有理运算；找稳定格使用$v\le u$直接接受，否则检$v^3-v^2u-2vu^2+u^3\le0$，覆盖$u=0<v$。有限输入和及三次乘法位长多项式。此算法输出普遍达到规则，不优化全部混合NE；后者由[区间精确算法](../算法/全交叉单交叠双目录的区间最优与达到检查--算法.md)求实例最优，二者威胁不能互换。

## 高区结论的真实反例边界

1. **不可删无r稳定格前提。** [普通长环族](../构造/单交叠精确回应核心的长环与亚ρ坏族--构造.md)的$n=3,M=36$有reach行$(42,40,38)$、列$(41,39,37)$。$r=9/5$时两边全高，仍有遍历六行动的唯一回应环；但有r稳定格，如$(A_1,C_1)$需因子$40/39$，故不违反条件性下降。
2. **一方全高不够。** 六客户整数近锐例的reach为行$(144504187,80193772)$、列$(144504186,180193774)$。$r=9/5$时列全高、第二行为低，但全部布局最优$80193772/44504187>9/5$。其全部唯一收益为AC$(44504187,144504186)$、BC$(80193772,100000001)$、AD$(144504187,80193774)$、BD$(80193772,180193774)$；四格所需比依次为$80193772/44504187,180193774/100000001,144504186/80193774,144504187/80193772$，最小第一。全部续局唯一，混合不能救。
3. **无统一正相对低区余量。** 六客户族令$\eta\downarrow0,r\uparrow\rho$，低行/本方最大reach趋$1/\rho$，列仍全高；可选每个r的严格有理化反例，使低行距$1/r$阈值的相对差趋0。不能在所有接近ρ的倍率上给必要低点再加固定正余量；这不宣称在$r=\rho$的无坏实例情形中阈值“最优”。
4. **长坏环不反驳本定理。** 亚ρ族在每个$r<\rho$无r稳定格且精确回应核心任意长，兼容本页只在$r\ge\rho$排入口。原$six\_cycle.json$还存在多交叠，不能拿它冒充(H)域反例。
