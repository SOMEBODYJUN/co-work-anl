## 对象与量词

玩家集合、资源集合和策略集合均有限。玩家 i 的权重 w_i>0，资源 e 的成本为非负多项式 c_e(x)，玩家成本是其策略中资源成本之和；偏离后的资源负载包含偏离者自己的权重。对 alpha>=1，纯状态 s 是 alpha-PNE，当且仅当所有玩家和所有合法单人偏离 t_i 都满足
C_i(s)<=alpha C_i(t_i,s_-i).

本对象证明更强的全状态结论：给定 d>=2^20，存在一个有限游戏，使每个纯状态 s 都有某个玩家和另一条合法策略满足
C_i(s)-(d/10) C_i(t_i,s_-i) >= (2^d-d/10)/8 > 0.
因此该游戏没有 d/10-PNE。构造允许玩家数、权重比和策略中的资源数随 d 增长，不给出多项式输入规模或求解算法。

## 基础构造：循环窗口

先取整数 p>=20，令
alpha=p/10, Q=p^4, m=1+ceil(log_2(p^2)), N=Q^(m-1)/p=p^(4m-5).

有 m 个权重类 a=0,...,m-1，每类 N 个玩家 P_(a,j) (j in Z/NZ)，权重
w_a=Q^(-a), epsilon=w_(m-1), N epsilon=1/p.
给玩家一个全局次序 pos(a,j)=jm+a。每名玩家只有二元动作 0/1。

对测试 tau=(a,b,K,o)，其中 a<b、K<=N、o in {-1,+1}，每个 j 新建一对资源 e_(tau,j,0),e_(tau,j,1)。测试的主用户 h=P_(a,j) 在动作 0/1 分别取侧 0/1；窗口用户是 P_(b,j),...,P_(b,j+K-1)（下标模 N）。窗口用户 u 在主用户动作 0 时取侧
sigma(h,u)=1[pos(u)>pos(h)] xor 1[o=-1],
动作 1 取另一侧。不同测试和不同 j 的资源互不相同，因此每名玩家两条动作策略非空且不相交。

使用相邻测试 tau_a=(a,a+1,Q,-1) (a=0,...,m-2) 和返回测试 tau_R=(0,m-1,N,+1)。定义
X=sum_(r=1)^Q (1+r/Q)^p, Y=sum_(r=1)^Q (r/Q)^p, L=alpha X-Y,
U=sum_(r=1)^N (1+r epsilon)^p, V=sum_(r=1)^N (r epsilon)^p, Z=U-alpha V,
H=2^p-alpha, W=(1+1/p)^p, J=alpha W-1,
A_a=(2L/H)^a (0<=a<=m-2), A_R=H/(2J).

相邻测试两侧资源成本均为 (A_a/w_a^p)x^p，返回测试两侧为 A_R x^p.

### 参数正性和预算

单调性、积分和逐项比较给出
4/Q <= H/L <= 40/Q, L>H, Z/J > 3/(p^2 epsilon), and (A_R Z)/(A_(m-2)L)>3.
例如 Y<=2^(-p)X，X <= (9/4)(Q/p)2^p，H >= (9/10)2^p，从而 L>0 和上式的 H/L 界成立。又
(1+r epsilon)^p-alpha(r epsilon)^p >= 1-alpha p^(-p) >=9/10
给出 Z>=9N/10，而 J>0、J<3alpha，遂得 Z/J>3/(p^2 epsilon)。由 Q/20<=2L/H<=Q/2，有 A_a>=1。

任意状态中相邻测试对任一玩家的贡献不超过 Q A_a 2^p，返回测试贡献不超过 N A_R W。于是所有基础成本有统一上界
B_*=m Q^(m-1) 2^p.
这里按潜在用户总权重 w_a+Qw_(a+1)=2w_a 和 1+N epsilon=1+1/p 计数，不把一条改善环误当作全状态界。

## 前沿状态与全状态补全

每个权重类的前沿（front）是其线性玩家序列中的二进制串至多改变一次。所有类都是前沿的状态称 product-front。把每类前沿参数化为相位 x_a in Z/(2N): 前 x_a 个位置为 1（x_a<N），或前 x_a-N 个位置为 0、其余为 1（x_a>=N）。循环平移所有 clone 并对跨边 clone 翻转动作是基础游戏的扭转对称，可把任一选定类相位归一化为 0，同时保持成本和对应偏离成本。

在相邻测试 a->a+1 中，令相对相位 r=x_(a+1)-x_a mod 2N，并定义
n(r)=Q-min(r,Q) for 0<=r<=N, and n(r)=min(r-N,Q) for N<=r<2N.
重类前沿端点的旧/新成本为 A_a(1+n(r)/Q)^p 和 A_a(2-n(r)/Q)^p。若 r 不在 [0,Q] union [N,N+Q]，某个重类端点精确得到 (A_a 2^p,A_a)。任何轻类端点在该测试的旧、新成本均至多 A_a X。因此中间类的选定重端点有
A_a H-alpha A_(a-1) X = A_(a-1)(alpha X-2Y) >= (1/2)A_(a-1)L > H/2.
类 0 的返回边给出
H-alpha A_R W = H(J-1)/(2J) > H/3.
所以若某个相邻相位差不落入两个长度 Q 的短区间，就有保持该类前沿的改善。

否则 x_(a+1)-x_a=k_a N+t_a mod 2N，k_a in {0,1}, 0<=t_a<=Q，从而
x_(m-1)-x_0=kN+T mod 2N, 0<=T< (m-1)Q < N.
将末类归一化后考察返回测试。若 k 偶，用前向端点；若 k 奇，用后向端点。理想全一或全零指示模式的 margin 是 Z，而 T+1 个缺陷每个至多损失 (alpha+1)W。故末类有端点的返回 margin 至少 A_R[Z-(alpha+1)(T+1)W].
利用 T+1<=pQ=p^5、W<3、Z>=9N/10 和 A_RZ>3A_(m-2)L，并扣除末类输入端最多 A_(m-2)X，得到严格大于 H/2 的总 margin。每一步只翻一个真实玩家，且翻后仍为前沿。因此存在 eta_0=H/4，使每个 product-front 都有保持前沿的单人偏离，margin 至少 eta_0。

### 三元锚定补全

基础游戏的前沿结论还不能自动覆盖非前沿状态。对每个权重类、每个 1<=i<j<N，添加一对新资源，仅由该类的 clone 0,i,j 使用，侧选择加入相位 0,1,0。两侧成本均为
M (x/(3w_a))^p, M=2 alpha B_*.
若三人的动作模式为 010 或 101，三人同侧，触发成本 M；其他模式的任一玩家时，该对资源成本至多 M(2/3)^p。一个非前沿串必含先出现的 b、之后最早相反位 i、再之后回到 b 的 j，故该三元组触发；前沿串没有这种模式。

设 L_c=binom(N-1,2)。若是前沿状态，原有保持前沿的偏离新增时钟成本至多 alpha L_c M (2/3)^p；若是非前沿，翻回最早相反位的玩家旧时钟成本至少 M，新时钟成本至多 L_c M (2/3)^p，基础成本至多 B_*。只要
(2/3)^p <= eta_0/(4 alpha^2 B_* L_c),
前沿的 margin 至少 eta_0/2，非前沿的 margin 也至少 eta_0/2。原始精确整数预算证明在 p>=2^20 时满足更强的
4 alpha^2 B_* L_c/eta_0 < (3/2)^p.
证明可取 2^k<=p<2^(k+1)，令 m-1<=2(k+1)，有
4 alpha^2 B_* L_c/eta_0 <= m p^(12(m-1)) < 2^(24(k+1)^2+k),
而 24(k+1)^2+k<2^(k-1)（从 k=20 归纳），故小于 (3/2)^(2^k)<= (3/2)^p。于是添加三元资源仍可使用原次数 p，每个纯状态均有 margin >= eta_0/2=H/8=(2^p-p/10)/8.

## 结论及适用边界

取 p=d 即得主命题。所有参数是正有理数；每名玩家恰两条非空不交动作；旧资源和新增资源都是正有理数倍 x^d，且每个状态有严格 d/10 改善。故没有 d/10-PNE。

若记所有此类游戏普适纯近似均衡因子下确界为 a_*(d)，该对象给 a_*(d)>=d/10。若另有同模型的 d-近似纯均衡存在定理，则得到 d/10<=a_*(d)<=d，即 Theta(d) 阶。英文稿进一步说明把非负多项式拆成单项式资源、用私有资源承载常数项，可将该外部上界从单项式表示扩展到一般非负多项式；这是对已知上界的归约，不是本文构造的独立上界证明。

严格边界如下：
* 这是全状态严格改善族，区别于只展示一个改善环；全状态性由前沿覆盖 + 三元锚定补全两步承担。
* 构造不声称多项式规模、不声称精确最优常数、不声称外部同行评审或世界首次。
* alpha=p/10 只针对 p>=2^20；较小次数、受限权重谱、受限策略结构和高效算法不是本对象结论。
* 每个状态存在某个改善不等于给出统一的同一玩家或同一策略；不存在均衡的量词是逐状态存在改善者。
