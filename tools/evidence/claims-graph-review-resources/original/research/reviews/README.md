# 独立检查与清洗记录

当前主攻 **Q-CAG-HALF**，存档 **customer-attraction**。实际检查从[客户吸引审查目录](customer_attraction/)沿对应Claim和正文读取；结果状态在[五轴账本](../review_status.json)，范围在[精确账本](../current/claims.md)。

清洗者负责检查对象、量词、推导、反例、复杂度、证据和真实异议，并将可复用内容写成自足资产入库。检查必须注明所读版本、实际覆盖和未覆盖义务；多票赞同不能替代证明。探索、讨论和候选保存不以审核通过为前置条件。

| 保留审查 | 使用时机 |
| --- | --- |
| [客户吸引](customer_attraction/) | 当前已证子题、策略计算和失效桥梁 |
| [设施](facility/) | 共同/异构目录、任意设施数的不同模型 |
| [加权拥塞](weighted_congestion/) | 线性全状态证明及其它工具；外审状态另列 |
| [不相关机](unrelated_machines/) | 暂停主线的结构接口和真实反例范围 |

角色只维护[清洗者](../customer_attraction/CLEANER.md)、[Boss](../customer_attraction/BOSS_START.md)、[整理者](../customer_attraction/EDITOR.md)。旧审查不因换题自动失效，也不自动适用于不同命题。
