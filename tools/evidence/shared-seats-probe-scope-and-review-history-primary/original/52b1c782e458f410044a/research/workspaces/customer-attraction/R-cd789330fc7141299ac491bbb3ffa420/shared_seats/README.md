# 共享遗漏席位：平行块候选与精确停界

2026-10-23，内部探索备份。一般 Q-CAG-HALF **仍 OPEN**。本目录没有一般证明、主目标反例、外审或新颖性结论。

## 当前结论

1. 不可把一般目标加强为 `W >= |O\C|`，即使允许有利重选最优并集；已读 Boss5/旧Boss10 的 71 客户完整二人反例。原目标必须保留 `I=|O∩C|` 与 `G=|C\O|`：`D+I <= 2(I+G)` 等价于 `D <= I+2G`。
2. 私有席位的直接“把实际遗漏指派到最优主题”推广同时断在两处：一个动作可能触及多个指派块，使残余容量降超过一；共享触块不推出后继主题包含于根主题，故不能把后继收益中继给根。
3. 排除第一处后，得到一个准确但未证明的全人数候选：遗漏集合 U 可分为不交块 Q_j，每个合法主题的 U 截面只可能为空或恰为某一个完整 Q_j，并要求每个 Q_j 确为某合法主题的 U 截面。一个块允许由任意多个不同极大主题共享，它们在实际已覆盖集合 C 上任意不同。此类中希望 `W >= sum(top_m{a_j/k})`。这只是候选；它不覆盖一般共享遗漏。
4. v1原备份遗漏块可实现性，root指出后在v2补入(Cov)并保留修正记录；原v1若包含不可覆盖客户则r=1即假。同一v2状态的 r≤2 阈值归纳可闭合，本质上是既有末两人保底恒等式。r≥3 时，根与所选同块后继的收益差取决于其他后继在 C 上的分支负载，不能由固定最大变体中继；详见 `parallel_omission_obligation.md`。未得到绕过这一障碍的一般机制。

## 有限判别，不能作普遍证据

- `probe_groups.py`：固定种子 283674，m=3、三块、每块两变体、两个 outside 主题；3 万次随机输入，用完整集合值 BI 查找 actual outside-only SPE 且 W 小于遗漏三块量。没有找到候选。仅对数值不等式使用整系数/有限整数线性收益；命中时才交规范 Fraction BI 精确复核。
- `probe_groups_cone.py`：固定种子 73667，150 次种子实例；取真实完整 SPE 的策略锥，允许全部 192 种由两个 outside 主题至少一个覆盖的 C 兴趣类型和三个 U 块类型变化，在 W=1 下最大化 D。实际可用锥均返回最优 1（浮点 LP，仅作判别）。种子策略的离轨选择在 equality 附近变化并没有被全部枚举。
- `probe_groups_cone3.py`：同一明确候选，三个 actual outside 主题、全部 448 种 C 兴趣类型，40 次种子实例。实际可用锥也停在 D/W=1。
- `probe_spectrum_cone.py`：同样三 outside，12 次种子；最大化两席取第一块、一席取第二块的谱部分 `(3/2)a_1+a_2`，所得样本锥最优约 5/6。不能从这些固定策略锥推出全谱或一般人数结论。
- `probe_spectrum.py` 是把第一个随机检查改为完整 top-m 谱的脚本，本轮未运行；不要声称已有结果。
