# 三块复制菜单的一个局部可信性阻断：最后低收益行动

2026-10-23，Boss10 / mixed_menu。**局部解析引理，非整个三块不可实现性证明。**
三块的单位客户与主题沿用 `replicated_menu_minimax.md`；每块 16 名客户、四个主题。
本页独立分析一个余三人的合法前缀，只用末两人的直接最佳回复，不调用大集合 BI。
发现范围与独立核查范围不得混淆：credible_family 已对全部 last-low 截面作精确
集合 BI，而本页只解析其中一个最小 floor 见证。

固定有序前缀的主题计数为

```
s = (1,0,1,1) | (2,1,0,0) | (2,1,0,0) = A0 C0 D0 | A1 A1 B1 | A2 A2 B2.
```

前缀有九人，还余三人。任何实现 `qD | q0 | q0` 的续局必须新增 `D0,C1,C2`，
其中新增 D0 的最终收益为 `13/4`。本引理只断言：**若当前三人中的第一位在此时
被要求选 D0，他会严格偏离**。它不排除另一排序先走 C1 或 C2；覆盖全部排序
需要 credible_family 的完整 last-low 截面义务。

## 1. 当前选 D1，可保证至少 37/10

让当前人偏离选 D1 后，余两人面对背景

```
s' = A0 C0 D0 | A1 A1 B1 D1 | A2 A2 B2.
```

此时额外插入每个主题的收益如下。所有分母已包含新提供者。

| 主题 | A | B | C | D |
| --- | ---: | ---: | ---: | ---: |
| 块0 | 13/4 | 9/4 | 13/4 | 13/4 |
| 块1 | 43/15 | 23/15 | 37/10 | 91/30 |
| 块2 | 35/12 | 9/4 | 21/4 | 21/4 |

余两人中的首人选择 C1 时，末位严格只会选择 C2 或 D2，因为后两者的插入收益
为 `21/4`，其他所有主题更小。首人 C1 收益因而保持 `37/10`，即保证值。

首人若选 C1、C2、D2 之外的主题，其即时插入收益至多 `13/4`，而后继行动
只能降低他在自己主题上的收益。因此该行动严格输给上述保证值，不能出现在 SPE。

若首人选 C2，末位的全部最佳回复恰为 C1、D2，值均为 `37/10`；
若首人选 D2，末位的全部最佳回复恰为 C1、C2，值均为 `37/10`。
因此余两人的任意 SPE，新增主题多重集只能为

```
{C1,C2}, {C1,D2}, {C2,D2}.
```

前两种情形下，当前偏离者 D1 的最终收益为

\[
4/2+3/2+1/5=37/10.
\]

第三种情形中，块1不再被后继进入，D1 的最终收益为
`4/2+3/1+1/4=21/4`。故不论原策略在离轨历史如何平局，D1 偏离保证
`37/10>13/4`，指定的当前 D0 行动无法最优。

## 2. 计算核验与精确边界

`verify_last_low_witness.py` 显式展开 48 名不同单位客户，对余两人的每个首动作
枚举 12 个末位动作，保留全部末位最佳回复。它核对上表、保证值、三种可能的
SPE 终局以及 D1 的最坏收益，全程使用有理数；不导入原 solver 或可信性探针。

该局部支付机制说明：复制菜单中把额外查询价格高的 `q0` 留在多块，会给真实
后继创造跨块进入机会。未来不能任意把这些进入都惩罚掉，因为最后两人自身也
有 `37/10` 的外部机会。**它尚不是任意 n 的一般 no-go 引理，也没有证明 Mfull。**
