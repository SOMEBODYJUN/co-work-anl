# 2. 单层配额超图的平方根重数地板

## 2.1 精确合同和结论

取有限变量集 `X`，`|X|=q>=1`，资源集 `R`，每个变量 `x` 的邻域 `A_x` 满足 `|A_x|>=K>=1`，每个资源的关联度 `deg(u)<=Delta`。对 `1<=t<=K`，令 `nu_t` 为最多能选择的变量数，使每个变量选出 `t` 个邻域资源且全部选出资源互不相交。定义

\[
b=\max_{1\le t\le K}\min\{t/K,\nu_t/q\}.
\]

稳定身份为 `UM-SQRT-MULTIPLICITY-FLOOR-v1`。正文证明
\[
b\ge B(K,\Delta):=\max_{1\le t\le K}
\min\left\{\frac{t}{K},\frac{K-t+1}{K-t+1+t\Delta}\right\}.
\]
若 `K>=sqrt(Delta)+1`，取 `t0=floor(K/(sqrt(Delta)+1))`，则
\[
b\ge t_0/K\ge 1/(\sqrt{\Delta}+1)-1/K.
\]
当 `K<sqrt(Delta)+1` 时不应强行写成正的固定平方根地板，必须保留离散的 `B(K,Delta)`；这一步是该源的整数边界。

## 2.2 证明机制

固定 `t`，取最大不交 `t`-束，大小为 `s=nu_t`，其资源并集 `U` 大小为 `st`。对每个未选变量，若 `A_x` 在 `U` 外还有 `t` 个资源即可扩充，故至少 `K-t+1` 个邻域资源落在 `U` 内。两边计数给
\[
(q-s)(K-t+1)\le\sum_{u\in U}\deg(u)\le\Delta st,
\]
从而
\[
\nu_t/q=s/q\ge (K-t+1)/(K-t+1+t\Delta).
\]
与 `t/K` 取最小、再对 `t` 取最大即得结论。令 `alpha=sqrt(Delta)`，`h(t)=(K-t+1)/(K-t+1+tDelta)` 随 `t` 下降；在 `t0` 处结合取整误差得到显示下界。

## 2.3 数量级示例、上界和多标签边界

分组族把 `q=g Delta` 个变量分成 `g` 组，每组 `Delta` 个变量共享一组大小 `K` 的私有资源，组间资源不交。此时
\[
\nu_t=g\lfloor K/t\rfloor,
\qquad b=\max_t\min\{t/K,\lfloor K/t\rfloor/\Delta\}.
\]
当 `K` 增大时，离散极限是
\[
\max_{s\ge1}\min\{1/s,s/\Delta\}
=\max\{\lfloor\sqrt\Delta\rfloor/\Delta,1/\lceil\sqrt\Delta\rceil\},
\]
仅用于说明 `Theta(1/sqrt(Delta))` 数量级，不能把连续平衡点当作有限 `K` 的精确值。

若资源总数为 `N=|R|`，则 `t nu_t<=N`。令 `rho=N/(qK)<=1`，得到
\[
b\le\max_t\min\{t/K,\rho K/t\}\le\sqrt\rho.
\]
资源总量达到 `qK/Delta` 的设计中，容量上界与重数计数下界同为平方根量级。

多标签输入时不能把同一变量全部标签邻域取并集，因为这会制造原需求图中不存在的束。若每个变量先固定一个完整标签且该标签邻域大小至少 `K`，再把这些固定邻域的资源总度控制在 `Delta`，引理可以直接应用；若没有完整标签，只能使用局部比例上界，不能直接套用公式。

## 2.4 困难性含义和有限审计

若单层共享标签合同满足 `b<=delta`、`K>=sqrt(Delta)+1`，则必要条件为
\[
\Delta\ge(1/(\delta+1/K)-1)^2,
\]
渐近为 `(1/delta-1)^2`。这只是一个构造约束：把碰撞重数设为 `O(1/delta)` 不能压低所有中间 `t` 层；它不是 NP-hardness、PCP/Label-Cover 归约或一般 unrelated-machines 近二下界。

审计 `single_layer_quota_sqrt_multiplicity_floor.py` 使用 `Fraction`，穷举 `q=3`、`K=2,3`、资源宇宙至多 5 的全部邻域族，并直接核验 `nu_t`、重数计数下界和分组族公式，冻结输出为 `ok: 23192 exhaustive systems; group formulas checked`。它另检查 `Delta,K=1..8` 的分组公式。有限枚举只承担所列范围，普适结论来自计数证明；零邻域、连续近似和未固定标签均没有被审计结果偷偷补入。

# 3. 单外层 typed 菜单的近似算法与源边界

## 3.1 两个正式身份和物理域

第二源先区分两个正式结果。

`UM-SINGLE-OUTER-PRIMITIVE-SA1-EPS2-4-v1`：给定显式单外层 typed normalized-flat 菜单、`0<epsilon<=1` 和 plain common primitive-SA1 LP 的完整有理可行点，使用同一公共一/二阶数组构造实际不交 allocation，最低质量至少 `epsilon^2/4`，并恢复全部原 jobs 的 schedule，`Cmax<=2-epsilon^2/4`。该结论不要求 PSD 或真实联合分布，也不把分别条件化的点拼成共同 law。

`UM-SINGLE-OUTER-TYPED-13-8-v1`：只给 typed `Q` 本身，结构显式、输入为 binary-rational，运行 11 次 plain primitive-SA1 阈值 LP 的二分搜索，输出全部原 jobs 的完整 assignment，满足 `Cmax <= (13/8) OPT(P(Q))`。这是一个只在该结构域内的确定性总位多项式算法，不负责从任意 ordinary matrix 识别 typed 表示。

物理域只有一个 outer group `M`，每个 indexed state 有相互不同的 private home；每个 home 有自己的 singleton helper，helper 的其他 states 是 fallback 资源向量；所有 fallback 资源可跨 helper 共享但与全部 homes 分离。每个 group/state 的系数和为一，selector 是一个跨状态的单一原 job，每个 incidence 是独立原 job，所有零 incidence、重复索引、未使用资源和未选状态 jobs 都保留。生成矩阵含 `S+U` 台机器、`G+I` 个 jobs、`S+2I` 个有限端点单元；没有 guard 或额外逻辑约束。

## 3.2 allocation 恒等式和 primitive-SA1 LP

若 `V` 是显式 typed 菜单的最大最小 bundle welfare，普通矩阵最优值 `x` 满足
\[
1\le x\le2,\qquad x=2-V.
\]
给定 allocation 的正 incidence 输出到不交资源、其他 incidence 留 private，得到 `C<=2-v`；反向若 `C<2`，每个 unit resource 至多容纳一个 incidence，selector 选定状态的 private load 给出 disjoint bundle，故恢复 allocation。这一恒等式计入全部原 jobs，并不预先固定 selector。

对阈值 `epsilon`，primitive `A_gs` 选状态，`Z_gsu` 选 incidence claim。base rows 包括每组一状态、box、`Z<=A`、每资源 claims 至多一、每状态质量至少 `epsilon A`。公共一/二阶数组把每个非负 row `h` 分别乘 `1,F,1-F`，得到 `O(N^2)` 变量和多项式规模 LP。若实际 allocation 的最低值至少 `epsilon`，其 Dirac moments 给可行点，故 `R_epsilon(Q)` FAIL 声音推出 `V<epsilon`；可行绝不等于真实 allocation。LP 随阈值单调，正阈值才被测试。

singleton helper 的 own state 强制 `mu_A=mu_Z=Y_AZ` 及 `Y_AF=Y_ZF`，让所有 fallback 条件量从一个正 outer marginal 的同一矩行取出。该共同条件化给出一个 joint fractional packing，而不是给每个 helper 各找一份 fallback 再相加。旧后端独立抽取 helper state/empty、按资源均匀赢家，条件期望至少 `1/2`，去随机化后 weighted welfare 至少 `epsilon^2/2`，再以 `tau=epsilon^2/4` 筛 Good helpers，恢复最低值至少 `tau`。

## 3.3 CDF-max、13/8 和全输入算法

新后端对每个资源按 `w_j p_jsu` 最高分配。以 score level `d` 写 `beta_j(d)`、`t(d)<=1`，独立请求给出
\[
\Pr(\max score\ge d)\ge1-e^{-t(d)}\ge(1-1/e)t(d),
\]
从而 weighted welfare `W>5 epsilon^2/8`。有限有理 score levels 上的条件期望公式可逐个 helper 去随机化。

设 `a=13/8`、`b=10/8`、`d=1/256`、`q=a epsilon-b+d`。当 `q>0` 时，`5 epsilon^2/8 > 2q-q^2`。若 Good helpers 的 home 总权重不超过 `q`，则 `W<=2q-q^2` 矛盾，故 Good 权重超过 `q`，完整恢复得到 `C<=2-q`。若在 `epsilon=1` 有可行点，则可取 `q=97/256`，即 `C<=415/256`；这是给定点推论，不是全输入算法本身的假设。

全输入算法从 `l=0,h=1` 开始，恰 11 次正阈值二分；可行保存点并抬高 `l`，FAIL 降低 `h`，最终 `h-l=1/2048`。若 `q<=0` 用 baseline `C<=2`，并由 `V` 与二分误差证明 `C<(13/8)OPT`；若 `q>0` 用保存的可行点并得到同一比例。总位多项式，不以 `1/epsilon`、分母大小或最小正 marginal 作为循环界；零 marginal 不除法。所有 incidence、selector、零 payload 和重复索引均被分配。

## 3.4 困难性源排除与结构边界

固定 `0<delta<3/8`，若一个 NP-hard 语言能总位多项式归约为该 typed 域，且真实 YES 为 `OPT=1`、真实 NO 为 `OPT>=2-delta>13/8`，则运行 13/8 算法并计算实际 schedule makespan 即可区分，因而在 `P!=NP` 下该单外层结构不能承载这种近二困难性源。这个结论针对所有原 jobs 和全局 selector 选择，不是某个给定状态或 relaxation 支撑的 gap。

该排除不适用于多个 outer groups、缺少 own home 的辅助 groups、隐式深度菜单或任意 ordinary matrix；逐个条件化的 fallback 点不必能拼成共同可行点。它也不否定一般 unrelated-machines 的近二困难性。

# 4. 第二源后半段的 raw 局部 law 反例与 S3 桥

源文件还包含两个与前述 13/8 算法量词不同的对象，必须保留为条件障碍。

首先，`UM-RAW-K2-LOCAL-LAW-DIRECT-CANONICAL-PULLBACK-OBSTRUCTION-v1` 对每个有理 `0<c<1`、`T=1+c` 构造固定 18 机、17 job、34 有限端点族。三位 Boolean functional 满足 `M2` PSD、每台物理机对全局 affine q 的 raw-load localizer，以及每机完整 CONFIG law 的全部本地 degree<=4 矩；真实 OPT 仍为 1。但直接把 canonical claim 定为 selector 端乘 resource-export 端，会出现跨行三因子负式
\[
L(Z_{M0u}A_{H_s0})=-1/160<0,
\]
以及激活质量 slack 的负式 `-c/160`。这说明各行完整 local law 与 global M2 仍不能自动推出 canonical primitive-SA1；它不否定重新求一个 LP 点、13/8 typed 算法或一般排程可行性。源还保留旧 14 机/13 job 前身只共享同机 first/pair 的局限，以及要求全部 global triple literal 非负时该证书会被排除的边界。相关有限 Fraction audit 只检查该固定维族的代数和 OPT witness。

其次，`UM-RAW-SA3-CANONICAL-SA1-POINT-PULLBACK-v1` 给出 source-S3 的充分桥：若给定普通矩阵的共同有理 raw degree<=4 moment table 同时满足 boxes、物理 load slack、每个 unit resource 的 cap1 行及长度<=3 literal lifts，则用 `A_s=a_s`、`Z_e=a_sE_e` 的 degree<=2 product substitution 可得到完整 canonical plain-SA1 点；若另有 raw M2，则可选得到 canonical M1。S3 不包含 CONFIG law 或 PSD，不能从各机 local law 自动获得；其 infeasibility 对 threshold-T 真实不可行是 sound，但可行只给 relaxation 点，不给实际 schedule。显式 LP 的 moment 数为 `O(N^4)`，系数和有理解算位长多项式；source 没有软件实现或运行证书。

这两个后半对象只属于第二源的合同边界，不应被并入第一源的超图计数，也不能改写成一般 fixed-level hierarchy lower bound。

# 5. 比较、证据边界与接续关系

两个来源可以共享“资源不交”和“局部条件不足以给全局对象”的主题，但不能合并结论。平方根来源的 `b` 是单层 t-束覆盖比例，完全没有 selector、machine load、LP moment 或真实 schedule；单外层来源的 `V`、`OPT=2-V`、13/8 算法依赖 explicit normalized-flat typed structure、singleton closure 和共同二阶 primitive-SA1。前者的 `Delta` 是资源总关联度，后者的资源冲突通过 unit resource cap 和 helper 请求处理，符号相同不表示同一参数。

可供第三阶段关系图使用的两条条件关系是：

1. `单层邻域大小/资源重数 -> t-束极大性计数 -> 平方根覆盖地板`，其出口是“要制造小 b 必须高重数或改变单层合同”；
2. `单外层 typed normalized-flat -> 共同 primitive-SA1 + singleton closure -> 13/8 实际 schedule`，其出口是“在 P!=NP 下不能作为真实近二 gap 源”，但跨 outer、无 own home 或隐式菜单仍开放。

本批重跑/读过的证据只支持相应层级。平方根审计的 `23192` exhaustive systems 和分组公式是有限核验；13/8 源没有端到端软件/运行认证，已有 32-case 审计只覆盖 CDF 后端，不能认证 LP 生成、11 步搜索和全 job 恢复。raw K2 固定维证书的 Fraction 检查也不构成一般 hardness。相关审查标明作者是旧引理的知情作者，不能宣称外部盲审或全球新颖性。

开放义务包括：多 outer groups 的共同 fallback 拼接、一般 ordinary matrix 的算法或 gap、从 local law 到 canonical SA1 的额外 global literal 条件、单层多标签/异质邻域的可解码算法，以及把单层重数必要条件转为复杂度归约的真实构造。当前六人 SPE 模型与这些 unrelated-machines 对象保持独立。
