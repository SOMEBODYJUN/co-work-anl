# 三坐标零权切片的精确菜单嵌入

对下面完整域中的每个输入P，存在确定性总位多项式构造C(P)，其几何变量全为带独立tag的 \([3]^3\)，state由完整9格坐标切片组成，并满足
\[
OPT(C(P))=OPT(P).
\]
更具体地，任意P完整调度可扩展成峰完全相同的C(P)完整调度；任意C(P)完整调度可投影成峰不增的P完整调度。两方向均没有C<2假设，也不输入最优值或见证。

结论允许零cell权、不同indexed states使用同一个label向量而具有不同成本表。固定几何维数本身没有限制这些成本表，也没有消除原来的全部组交互。本定理是精确表示，不产生困难性源或一致性约束。

## 1. 完整输入与目标域

输入有有限非空组集G，每组g有非空显式菜单A_g，\(K_g=|A_g|\)。每个indexed state s有互异资源组成的集合S_gs，非负二进制有理权p_gsu，满足
\[
W_{gs}=\sum_{u\in S_{gs}}p_{gsu}\le1.
\]
资源宇宙U显式列出，可以含未用资源。空state、零权和重复indexed states均允许。

完整普通UM矩阵由以下对象组成：

- 每state独立private机M_gs，每资源独立机器R_u，两类机器互异。
- 每组恰一件selector J_g，只能在该组全部state机上耗时1。
- 每个(g,s,u)恰一件不同incidence任务，只可在M_gs耗时p_gsu，或在R_u耗时1。
- 没有其它任务、预载、端或附加限制，所有未选state任务也实际存在。

令 \(U_g=\bigcup_s S_{gs}\)、\(q_g=|U_g|\)、\(S=\sum_gK_g\)。要求每资源在全部菜单中至多接触3个组；同组的多个states可以重复使用它。组交互图以 \(U_g\cap U_h\ne\varnothing\) 连边，零权membership也计入，最大度记为M。

目标每个变量x有完整27枚资源 \(\{x\}\times[3]^3\)。变量出现于至多3组，给这些组分配互异index \(j_x(g)\in[3]\)。每state对每变量选一个坐标label \(\ell\in[3]\)，包含完整切片
\[
\{(x,z):z_\ell=j_x(g)\},
\]
恰9格，每格一件独立incidence，private权非负、资源端时间1。各组变量集非空，state总private质量仍至多1。indexed state身份由自己的private机与全部任务保留，不由label向量唯一决定。

## 2. 固定active格与完整构造

对每个原资源u建变量x_u及全部27格，即使u原本未用也保留。对接触u的组按输入顺序赋互异index。固定
\[
z^*=(1,2,3).
\]
每g的每state，对每个 \(u\in U_g\) 都取label \(\ell=j_{x_u}(g)\)。因为 \(z_i^*=i\)，所有这些切片都含同一active格 \((x_u,z^*)\)。

保留所有原private机和selector；把R_u识别为active资源。原incidence I_gsu识别为该state对应x_u的active-cell任务，保留原p，包括p=0，并保留两个原有限端。若u不在该原state中，则该state的active-cell任务是新添的private0任务；其它8格也都是新添的private0、资源端1任务。

任务身份区分依据是原件映射，不能因为private权为0就把某件原任务误判为辅助任务。不同(g,s,u)映到不同state、变量或任务，没有合并原incidence。原selector的全部有限选择也逐一保留；selector可以有K_g个端，“每件任务恰两端”只适用于incidence。

若 \(U_g=\varnothing\)，给g单独加一个全新dummy变量y_g，index和label都取1；每state包含其9格零权任务，完整27资源仍列出。dummy tag与其它变量互异且只属于g。这保证每组变量集非空，也不制造新组交互。

## 3. 任意完整调度的双向转换

**扩展。** 给任意源调度，保留每个原任务的执行端。全部辅助任务都放自己的private机，耗时0；这同时适用于所选state与所有未选states。原private和active资源负载逐项相同，其余新资源空载，故目标峰与源峰完全相同。非空G及unit selector保证原峰至少1，没有零峰的隐藏例外。

**投影。** 给任意目标完整调度，不要求辅助任务已留private，也不要求峰低于2。按构造身份删除辅助任务和非原机器像，再逐原任务逆映。原incidence只有它的原private与原active资源两个有限端，没有得到另外8格的执行资格；原selector也只有原菜单资格。因此所有原任务仍合法且恰一次，耗时不变；删除任务只能减负载。unused R_u的active像仍保留。

两向对全部调度成立，直接给OPT相等及任意严格／非严格makespan阈值的等价性，包括OPT=2。它不声称保留未定义的拒绝数、其它费用等目标。

## 4. 精确保留的结构与unit阈值

每state只多零权任务，故 \(W_{gs}\) 与K_g逐项相同。若原两组共享u，目标两组的切片都含该变量active格；若原两组不共享资源，其变量tag互不相交，dummy也不会相交。因此**完整组交互图精确相同**，M保持，零权membership仍包含在图中。

每格只属于一个变量cube，而该变量至多出现于3组，故目标资源跨组度仍至多3。这与组交互度M是不同参数。

源或目标存在峰≤1的调度，当且仅当能为每组选择一个state，使所选state的**正private权资源support**跨组不交：

- 必要性：selector已占private负载1，所有p>0的已选任务都必须外送；每资源只能接一件unit。
- 充分性：导出这些正任务，已选零任务和全部未选state任务留各自private；所选根负载1、未选根负载≤1、资源负载≤1。

目标正support正是原正incidence在active格的像。完整几何切片可以在零权格相交，这种交集不强迫unit阈值下外送，不能免费解释成一致性约束。

若把所有零格作正扰动，即使总质量仍控制在1内，selector所在state的这些新正任务也会被迫外送，几何交集可能破坏原unit YES。若label向量被要求唯一决定成本或state身份，当前构造也未实现那种较窄域。

## 5. 精确规模与位复杂度

令 \(e=|\{g:q_g=0\}|\)、\(q'_g=\max(1,q_g)\)。目标规模为

| 对象 | 数量 |
|---|---:|
| 资源机器 | \(27(|U|+e)\) |
| private机器 | S |
| selector任务 | \(|G|\) |
| incidence任务 | \(9\sum_gK_gq'_g\) |

这里 \(K_gq_g\) 不能误称为原incidence数：一个state可能缺少组并集内许多资源，构造仍为这些位置添加零任务。但
\[
\sum_gK_gq'_g\le S\max(1,|U|),\qquad e\le |G|\le S,
\]
故规模仍按显式输入多项式。并未生成 \(3^{q_g}\) 个所有可能label states。

若要求dense矩阵，条目总数至多
\[
\left(|G|+9\sum_gK_gq'_g\right)
\left(S+27(|U|+e)\right).
\]
有限时间只是复制原有理数或写0、1，其余为不可用；tag、index和逐任务映射均为多项式位长，没有按处理时间值或分母复制。

## 6. 有限交互正界的衔接范围

本轮全文比较来源0e40cceb6da556656823的有限交互v2定理。它的输入正是上述完整flat域，包含零权membership，使用有效资源度上界Δ和完整组交互度上界M，给真实近似比
\[
2-\frac1{M+2\Delta-1}.
\]
取有效上界Δ=3，目标得到 \(2-1/(M+5)\)。这是相对于实际OPT的算法保证，不是每个输入都具有这一绝对负载：该定理的失败分支另给实际OPT下界并返回全private调度。

由于本嵌入精确保M，固定M确实有规模无关的改善；允许每组变量并集增长时，M可以增长。固定d=Q=3并不单独给固定M。这个衔接只核目标域和参数，有限交互定理本身仍有独立身份，没有被本表示替代。

若已有本flat域中覆盖所有选态及任意部分导出的真实近二YES/NO源，本嵌入精确传递其makespan承诺；它不提供那个源。进一步处理任意资源度和任意归一化菜单，可分别接[真实路径降度](完整菜单的资源度三路径归约--定理.md)和[三态正规形](归一化菜单的三态资源度三正规形--定理.md)，各步骤的域与保留量另行声明。
