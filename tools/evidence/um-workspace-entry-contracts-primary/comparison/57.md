## 一、鲁棒双端环的三半阈值

### 1. 对象与 Exact A/B/C

一个 core 有不交的机器环 (M_1,\dots,M_n) 与任务 (j_i)，每个任务仅可在 (M_i) 用 (a_i\in[0,T]) 或在 (M_{i+1}) 用 (b_i\in[0,T])。两恒定方向 phase 的峰均不超过 (T)。给 (T\le B<2T)，称 core 在 (B) 鲁棒，当其单独所有完整调度只剩两种恒定 phase。

设二进制方向在 (M_i) 发生 (1\to0) 转折时负载为 (a_i+b_{i-1})。核心恒等式是
\[
\text{robust at }B\iff a_i+b_{i-1}>B\quad(\forall i).
\]
若有一处和不超过 (B)，从恒定 phase 改一件任务即得到非恒定完整调度；反向任意非恒定循环字串必有转折。鲁棒时每个端点都大于 (B-T)，所以两 phase 该机负载差小于 (2T-B)。

给一份完整原实例严格 (T)-调度、任意共享 context 和指定 phase 向量，保持所有 context 任务的原目的地，逐 core 切换到指定 phase。若原 core 负载为 (x)、目标 core 负载为 (y)、context 负载为 (c)，则
\[
c+x\le T,qquad y-x<2T-B,qquad c+y<3T-B.
\]
因此任意指定 phase 都有完整调度峰值严格小于 (3T-B)；当 (B\ge3T/2) 时不超过 (B)。这个结论允许 context 跨 core 共享机器，因为 context 逐件不动且逐机总和直接进入上述不等式；不允许 core 机器彼此重用。

阈值锐性：对每个 (T\le B<3T/2)，两机两件 core（时间 (T,T/2)）加一个仅能放在一台机器的 (T/2) context，有严格 (T)-调度但另一 phase 的任何完整扩展超过 (B)。更精确地，对 (0<e<2T-B)，取轻端 (d=B-T+e)，另一 phase 最小峰恰为
\[
3T-B-e,
\]
趋近 (3T-B)。这些是相位扩展界和共同背景障碍，不是 OPT gap 或源 NO。

### 2. 不可静默删除的范围

core 机器互不相交、任务恰两有限端、端时间不超过 (T)、且给定完整 strict 见证，都是证明必需。若 core 共享机器，域外三任务反例可使单 core 各自鲁棒却共同切换失败；新增第三端也破坏“只有恒定 phase”的字符论证。结论不寻找未知严格见证，也不排除增加第三端、共同 core 或改变源解码语义。

位复杂度按显式资格和有理分母总位长计，比较和逐机负载回算不按 (1/(2T-B)) 数值展开。小规模 Fraction 审计覆盖 orientation、碰撞等号、共享 context、三半锐例和包络族，支持边界但不替代一般证明。

## 二、七态原作业的二次局部核

### 1. 原矩对象和主 Claim

令 (d,s) 为偶数，(2\le s\le d/2)，(eta=s/d)、(h=s/2)、(T=1+eta)。机器为 (u,v,z_1,\dots,z_d)，原任务为 (R,j_1,\dots,j_d)：(R) 可在 (u,v) 用1，每个 (j_l) 可在 (v) 用 (1/d) 或 (z_l) 用1。实际 OPT=1。

构造真实完整 assignment law (P) 于 ((C,H)) 七类，(C) 表示 (R) 是否在 (v)，(H) 是在 (v) 的 payload 数；坏类 ((C,H)=(1,d)) 质量 (p=\eta^3/1000)，其余类别用 (u_0=4p(1-eta)) 和 (e=4/5-p-u_0) 配平。所有原 Boolean/one-hot 关系和共同次数六矩来自同一真实 law；坏样本 v 负载为2，但 OPT仍由把R放u、payload留v的完整调度达到1。

主 Claim 是：同一有理度数六矩 (M_3) PSD、所有原 Boolean/one-hot、每台机器全局 degree-two physical-load localizer 以及逐行合法 CONFIG first/pair 都可同时成立，且坏样本质量与维数无关。这是局部二次核反例，不能写成 relaxation integrality gap、全局 near-two 或一般物理接线定理。

### 2. 行配置与全局二次负载证明

在 (v) 行，把坏的 active (H=d) 质量 (p) 改到 active (H=s) 质量 (p/\eta)，并以 active (H=0) 配平；把 inactive (H=d/2) 质量 (u_0) 对称拆到 (0,d)。这些修改保持 (C,H,CH) 一阶/交叉矩，同时令 (H(H-1)) 的减少与增加精确抵消，故 v 的全部 first/pair 矩可由合法 CONFIG(T) 分布匹配。u 与各 z 行为单 Bernoulli，直接有配置 law。

任意全局次数至多二多项式经标签置换对称化可写成
\[
\bar q(C,H)=P(H)+C(a+bH),\quad \deg P\le2.
\]
active/inactive 两条仿射插值关系控制坏点 (q(1,d)^2)；五个正 slack 类的质量至少常数乘 (eta)，Cauchy 和 (p=\eta^3/1000) 给
\[
L[(T-\mathrm{load}_v)q^2]\ge0.
\]
非 v 行每个真实样本负载均不超过1，故同一 law 对所有行的 degree-two localizer 均非负。这里允许 q 使用任意机器/job 原端点，不是只检局部变量。

### 3. 背景接口、稀疏 CONFIG 和边界

若任意外部背景把 v 可见 jobs 写成同一 (C,Y) 仿射表示、没有新增 payload，以上 localizer 和 v 行配置结论可逐背景复用；其它背景行必须另行核验，不能由 v 行推出全局合法性。每个显式 (d,h) 的 uniform h-subset law 可用 Fisher–Yates 交换加消列压成至多 (D=1+d+\binom d2) 个实际 subsets，精确保留 first/pair 矩，分母位长多项式；这只是配置支持压缩，不保更高矩或另一共同 law。

原正支持上的实仿射 Boolean 函数在指定 (\Omega_0\) 上只有 (0,1,C,1-C,Y_i,1-Y_i)。加上 base≤4 矩、共同 M3、原 Boolean/one-hot 和 Gram-null 等式时，任一忠实仿射端点仍逐点落入该清单；同行 pair 零时最多两个正 owners 且两者须同 bit 互补。这个 fiber 结论需要每个背景重新具备全支持和相应矩条件，不能积分后当成总物理入度界。

若改在 base≤5 条件下强行加入忠实非线性端点 (Z=CY_i)，取 (q=Z(H-h)) 得
\[
L[(T-C-H/d)q^2]=-p(1-eta)(d-h)^2<0.
\]
因此该给定 AND 延拓一定破坏全局二次检验。它只否定忠实 Gram-AND 的点延拓，不否定所有非线性接线、改变 base 或重新分配负载的方案。

### 4. 证据与开放边界

有限 Fraction 审计覆盖 12 组参数和部分完整小矩；辅助 sparse CONFIG 过程与原矩证明分别记录。软件没有实现一般 SDP finder、显式跨行接线或 growing-depth 共同 law。核心结果是 dim-free 的局部二次噪声控制和两个点延拓边界；未证明将它接成 shared-head、递归证书、全局低载调度或近二 gap。

## 三、比较、处置和第三阶段用途

双端环源独有的是任意共享背景下的相位不可读界、精确 (3T-B) 包络、(3T/2) sharp threshold 与 disjoint-core 条件；七态源独有的是实际 OPT=1 的共同 M3/二次 localizer、合法逐行 CONFIG、Fisher–Yates 稀疏支持以及仿射/AND 延拓边界。两者共同警告：局部真实见证或低阶矩/配置边际不能直接推出全局 source soundness；每次新接线都必须逐行支付负载、资格和共同 law。

这些结果供第三阶段 mapper 使用：检查双端 gadget 是否确有不交 core、是否给定 strict witness，检查高阶 localizer/Gram 连接是否超出 base 与矩量级；不得把七态坏样本当作一般不可近似性，也不得把双端环相位自由度当作所有共享背景的反例。两源均 `integrated`，六人 SPE 客户目录、完整历史、均分和任意平局语义与本批无关；`UM-TARGET-v1` 与六人SPE覆盖目标仍开放。
