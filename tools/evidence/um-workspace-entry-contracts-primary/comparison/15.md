# 分叉树估值与单状态支持多面体

以下q保留原根、完整深度和每层同一分叉数。多状态最大值f具有精确signed demand及可构造的逐点G(k,h)近似加性支持；单状态的完整minorant域进一步具有O(|V|)非零系数的精确扩展LP。后者严格限于单状态，不能与多状态的demand交换max混用。旧O(k|V|)表示仍成立，并保留其全部阈值分离恒等式；文末给出后续单位色类分解所导出的更强表示。


**证据口径。** 下文关于原作者、原研究者、既有独立重构、读后攻击、内审、代码实现及旧审计数量的叙述，均是所列冻结来源的历史记录。它们不表示本轮重新完成这些活动；本轮实际阅读、核对与新运行单列在文末。外审及新颖性不据这些记录升级。

## 共同对象与编码合同

- 取整数 k,h≥1。T 是有序、根位于深度0、每个内点恰有k个孩子、全部叶位于深度h的显式满树。记根ρ、结点集V(T)、内点集V°(T)、叶集L(T)，N=|L(T)|=k^h。
- 对整数1≤r≤k，深h的r叉根子树必须包含ρ，每个深度小于h的选中结点恰有r个选中孩子，全部选中叶仍在深度h。不收缩边，不允许提前终止。
- 单树估值q_T(S)，S⊆L(T)，定义为存在上述r叉子树且其全部叶属于S的最大r；无正r可行时定义为0。因此q_T(∅)=0、q_T(L(T))=k。
- 所有树必须显式给出完整结点与边，或给出所有完整叶地址。复杂度按该显式表示、资源标识及所有有理数的总编码长度计；不声称仅按log k、log h处理隐式指数规模树。
- h=0不在本合同内；不对它使用下列分母公式。k=1在合同内：满树是显式深h单链，N=1。

## UM-PRIVATE-TREE-Q-VALUATION-v1

### Exact Statement

给有限资源集U和非空显式状态族A={1,…,R}。每个状态a有一棵共同参数k,h的私有满树T_a及单射λ_a:L(T_a)→U。不同状态的资源像可以任意重叠；仅要求每个状态内部的叶资源互异。令

q_a(S)=q_{T_a}(λ_a^{-1}(S)),    f(S)=max_{a∈A}q_a(S)    (S⊆U).

则：

1. 每个q_a及f均为非负、整数值、单调且次可加的集合函数；特别地，f(S∪S′)≤f(S)+f(S′)对所有S,S′⊆U成立。
2. 对每个有理价格向量p∈Q^U，存在确定性总位多项式时间算法，输出具体S*⊆U及其精确目标值，使

   f(S*)−Σ_{u∈S*}p_u = max_{S⊆U}(f(S)−Σ_{u∈S}p_u).

   可以同时输出达到f(S*)的具体状态及该状态中的实际根子树；f(S*)=0时返回空子树即可。
3. 允许负价格。所有负价资源（包括不在最终选中状态叶像内的负价资源）均可先收入S*，并在子树费用计算时把这些资源的有效价格置0；它们的原负价总额另计入目标值。此操作不要求不同状态的资源像互不相交。

### Objects / Domain / Quantifiers

所有满足共同合同的显式满树、所有有限U、所有R≥1、所有逐状态单射λ_a、所有S,S′⊆U及所有有限有理价格向量。价格不取∞。

### Assumptions / Definitions

“次可加”指集合并的上述不等式，不要求次模或XOS。Demand oracle指上式精确最优化与具体集合输出，不是价值估计。

### Scope / Conclusion

单射叶资源的私有树估值及其有限状态最大值有上述性质和精确demand算法。状态内重复资源不在算法合同内。

### Dependencies

仅使用本文件给出的对象与编码定义；证明和算法论证见下文。

### Evidence / Counterevidence or Objections

一般证明见下文，实际实现证据见末节；有限核验不替代证明。显式性与逐状态单射性是承重假设；不能删除。非空状态族与h≥1已明确限定。

## UM-TREE-Q-XOS-ENVELOPE-v1

### Exact Statement

固定一棵满足共同合同的树T，叶全集记L，q=q_T。定义全部非负加性minorant的权重域

A(q)={w∈R^L_{≥0}: Σ_{ℓ∈S}w_ℓ≤q(S) 对每个S⊆L成立}，

并定义其逐点包络

E_q(S)=max_{w∈A(q)}Σ_{ℓ∈S}w_ℓ.

这里“XOS-envelope”专指所有非负加性minorant的逐点最大值；不声称存在一个共同的加性向量同时达到所有集合上的包络值。

则最大值均可达到，且

E_q(L)= k^h/[k^h−(k−1)^h] = 1/[1−(1−1/k)^h]。

全叶相同的权重

w_ℓ=1/[k^h−(k−1)^h]    (ℓ∈L)

属于A(q)并达到上述全叶最大值。若只允许有理权重w，最大值不变。定义全叶乘性损失

G(k,h)=q(L)/E_q(L)=k[1−(1−1/k)^h]。

对所有整数k,h≥1，

(1/2)min(k,h) ≤ G(k,h) ≤ min(k,h)。

其中k=1或h=1时G=1。进一步，对每个整数B≥2，定义

Γ(B)=max{G(k,h): k,h∈Z_{≥1}, k^h≤B}。

则该最大值存在，且Γ(B)=Θ(log B/log log B)当B→∞。精确量词是：存在与B无关的常数c,C>0及整数B0≥16，使每个整数B≥B0都有

c log B/log log B ≤ Γ(B) ≤ C log B/log log B。

这是一种按显式叶数上限取最大值的陈述，不要求每个整数B恰等于某个k^h。

### Objects / Domain / Quantifiers

所有共同合同下的单状态满树；A(q)的约束量化全部叶子集；非负实权重和非负有理权重的最优值均包括。

### Assumptions / Definitions

E_q是上面明确定义的逐点加性下包络。损失只比较单状态全叶值q(L)与该包络，不表示调度近似比、配置LP间隙或计算困难性。

### Scope / Conclusion

精确全叶包络值、一个实际达到的有理权重向量、统一参数界及叶数上限下的渐近最大阶。

### Dependencies

使用共同对象定义；完整证明见下文。

### Evidence / Counterevidence or Objections

一般证明见下文，实际实现证据见末节；有限核验不替代证明。h=0已排除；k=1的分母为1。不能把单状态的对称性结论直接套到任意多状态最大值。

## UM-TREE-Q-MINORANT-LP-v1

### Exact Statement

固定共同合同下的一棵单状态树T与q=q_T。对任意非负叶权w∈R^L_{≥0}，写W=Σ_{ℓ∈L}w_ℓ。对1≤s≤k，令C_s(w)为所有深h的s叉根子树中最小的叶权总和，并令C_0(w)=0。则

max_{S⊆L}[Σ_{ℓ∈S}w_ℓ−q(S)]

= max_{0≤s≤k}[W−C_s(w)−(k−s)]。

因此当w为非负有理数时，可在显式树与权重总编码长的确定性位多项式时间内，检验w∈A(q)，或输出具体违反minorant约束的叶集合。

更具体地，下面有限线性系统在w坐标上的投影恰为A(q)：

- 主变量为每叶w_ℓ，令W=Σ_ℓw_ℓ，约束0≤w_ℓ≤1及W≤k。
- 对每个s∈{1,…,k}和每个结点u∈V(T)，引入0≤c_{u,s}≤k。
- 对每个叶ℓ及每个s，约束c_{ℓ,s}=w_ℓ。
- 对每个内点u和每个s，引入0≤z_{u,s}≤k，以及每个孩子v∈Ch(u)对应的0≤t_{u,s,v}≤k，并约束

  t_{u,s,v} ≥ z_{u,s}−c_{v,s}，

  c_{u,s} ≤ s z_{u,s}−Σ_{v∈Ch(u)}t_{u,s,v}。

- 对每个s，约束c_{ρ,s} ≥ W−k+s。

该扩展系统只有O(k|V(T)|)个变量与约束，所有系数都是编码位长O(log(k+1))的整数。给定任意明确的S0⊆L，在线性系统上最大化Σ_{ℓ∈S0}w_ℓ，所得值恰为E_q(S0)，并存在确定性总位多项式时间算法输出精确有理最优值和一个实际达到的有理支持权重向量。

### Objects / Domain / Quantifiers

所有共同合同下的单状态满树，所有非负叶权w，以及所有指定叶子集S0。强分离部分输入为有理权重；投影恒等本身在实数域成立。

### Assumptions / Definitions

A(q)、E_q沿上一命题定义。C_s要求真正的同深s叉子树，不是任意s^h片叶。上述有限LP的“投影”指存在满足全部辅助变量约束的实向量。

### Scope / Conclusion

单状态minorant域的精确强分离、紧凑扩展表示，以及任意指定集合上的精确有理包络优化。没有把这一单状态LP断言为多状态max估值的minorant表示。

### Dependencies

共同定义、上一命题给出的包络定义与标准有界有理LP的精确位多项式可解性。数学恒等与扩展表示的证明见下文。

### Evidence / Counterevidence or Objections

一般证明见下文，有限实现证据见末节。不能用demand中的状态最大值交换来消除多状态共同blocking约束；不能删除显式树编码合同。k=1有效，h=0未包括。

### Status / Related Files

限定范围证明如下；冻结来源已有陈述先行独立重构与读后攻击记录。强分离及LP约束数据已实现，generic精确LP最优化未实现。外审及新颖性未认证。

## 一般证明

## 1. 深度固定的分叉对偶

对满k叉深h树的任意叶集合S及1≤r≤k，恰有以下两种情况之一：S含深h的r叉根子树，或其补集含深h的(k−r+1)叉根子树。

存在性按深度归纳。对每个根孩子，若其S部分含r叉子树则标红，否则归纳假设给补集中的(k−r+1)叉子树，标蓝。至少r个红孩子时连接它们；否则至少k−r+1个蓝孩子，连接这些蓝子树。归纳底是一个叶是否属于S。这里用高度0作辅助归纳底，不对高度0定义主命题中的q及包络分母。

排他性也按深度归纳：两棵根子树的首层孩子集大小之和为k+1，必相交；在相交孩子下继续，最终有共同叶，不可能分别处于S及其补集。

因此，对0≤t≤k，

q(S)≤t  当且仅当  L\S含深h的(k−t)叉子树，

其中t=k时将0叉子树解释为空集合。由此，q≤t集合的最大叶数恰为

M_t=N−(k−t)^h。

上界因补集至少有(k−t)^h片叶；取任一(k−t)叉子树的补集达到上界。h≥1确保t=k时0^h=0。

## 2. 次可加性

一种自足的递推证明如下。对子树的k个孩子的整数分叉值b_1,…,b_k，父点的分叉值为

H(b)=max({0}∪{r∈{1,…,k}:至少r个b_i≥r})。

可用叶的辅助叶值设为k，不可用叶的辅助叶值为0，自底向上应用H恰计算q。

H对非负整数向量单调且次可加。设p=H(x)、q=H(y)。p+q≥k时结论直接成立。否则，若H(x+y)≥p+q+1，至少p+q+1个坐标有x_i+y_i≥p+q+1。每个这样的整数坐标必满足x_i≥p+1或y_i≥q+1。但前一种坐标至多p个、后一种至多q个，矛盾。

叶可用性对集合并逐坐标次可加，故逐层应用上述单调性及次可加性，得到q_a(S∪S′)≤q_a(S)+q_a(S′)。最后

max_a q_a(S∪S′)≤max_a[q_a(S)+q_a(S′)]≤max_a q_a(S)+max_a q_a(S′)。

单调性、非负性与整数性直接来自定义。

## 3. 带任意有理价格的精确demand

先令Z={u∈U:p_u<0}，credit=−Σ_{u∈Z}p_u。单调性保证最优集合包含Z；这包括所选状态之外的负价资源。

对每个状态a、每个1≤r≤k，给叶ℓ费用max(p_{λ_a(ℓ)},0)。令D_{a,r}为最小费用深h的r叉子树。固定r时，叶的费用如上；每个内点的最优费用是其孩子最优费用中r个最小值之和。因状态内叶资源互异，跨孩子费用可直接相加，无重复占用或重复计价。保存确定性并列规则即可回溯具体子树。另设D_{a,0}=0，对应空子树。

精确最优demand值为

credit + max_{a,r∈{0,…,k}} [r−D_{a,r}]。

上界证明：给任意S⊇Z，取实现f(S)的状态a及r=f(S)，其r叉子树叶资源均在S中。该子树的有效费用至多S\Z的总价格，因此D_{a,r}≤Σ_{u∈S\Z}p_u，给出上式上界。

达到性：取使上式最大的a,r及一棵最小费用子树K，输出S=Z∪λ_a(L(K))。有f(S)≥r，原价格总和恰为−credit+D_{a,r}，故输出达到至少该值。结合上界即为最优。可在输出集合上再计算所有状态的q，回溯一个实际达到f(S)的状态及子树。

固定r的动态规划只排序k个孩子费用。对所有状态与r，组合操作数为O(Rk|V(T)|log(k+1))量级。每项费用是输入价格的有限和，所有中间有理数的位长受输入总位长的多项式控制。完整树或完整叶地址是输入的一部分；k=1的深链也按显式链长度计。没有按仅二进制给出的h展开隐藏指数对象。

## 4. 全叶XOS包络的精确值

记M_1=N−(k−1)^h。对任意整数0≤t≤k，

M_t=Σ_{j=0}^{t−1}[(k−j)^h−(k−j−1)^h]≤t[k^h−(k−1)^h]=tM_1。

这里整数幂差s^h−(s−1)^h随s单调不减。若q(S)=t，第一节给|S|≤M_t，故全叶相同权重w_ℓ=1/M_1满足w(S)=|S|/M_1≤t。它是全域有效的加性minorant，并给w(L)=N/M_1。

反向，取一个达到最大叶数M_1的q≤1集合S0。满树的根保持自同构群在叶上作用传递，且保持q。对任意有效minorant w，将w(gS0)≤1对全部自同构g平均；每片叶进入随机gS0的比例为M_1/N，因此

(M_1/N)w(L)≤1。

从而w(L)≤N/M_1。这个平均仅作证明，不要求算法枚举自同构群。统一有理权重达到上界，也说明实数域与有理数域在该目标上的最大值相同。

损失G=k[1−(1−1/k)^h]。上界G≤k显然；Bernoulli不等式给G≤h。k≥2时，(1−1/k)^(−h)≥1+h/k，故

G≥kh/(k+h)≥(1/2)min(k,h)。

k=1时G=1，h=1时也G=1。

令L_B=log B。若t=min(k,h)，k^h≤B给t log t≤L_B，且G≤t，因此当B充分大时G≤2L_B/log L_B。反向取整数t=floor(L_B/(2log L_B))；当L_B≥16时，t≥L_B/(4log L_B)，且t^t≤B。取k=h=t，得G≥t/2≥L_B/(8log L_B)。由此得到冻结statement中按叶数上限B取最大值的Θ阶；未要求B本身为k^h。

最大值存在：k≥2时只有有限个k^h≤B的整数对；k=1的无限多个h全部给同一个值1。

## 5. 强分离与紧凑LP

对非负叶权w，记W=w(L)。第一节的补集对偶给

max_{S:q(S)≤t}w(S)=W−C_{k−t}(w)。

必要性：补集含一棵(k−t)叉子树，其权重至少C_{k−t}；非负性保证整个补集权重不小于该子树权重。达到性：取最小费用子树的补集。于是

max_S[w(S)−q(S)]=max_{0≤t≤k}[W−C_{k−t}(w)−t]。

一边由给定S取t=q(S)得到；另一边用达到最大费用的q≤t集合，其真实q可能更小，只会增加违反量。此式亦直接给出违反集合。所有C_s都能用上一节同类树形动态规划精确计算。

现在核对statement的紧凑LP。对k个实费用b_v，

sum_s_smallest(b)=max_z [s z−Σ_v max(z−b_v,0)]。

取z为第s小费用即达到；对任意z，上式不超过任意s项费用和，故不超过最小s项之和。

若w∈A(q)，则0≤w_ℓ≤1，W≤k。对每个s，把c_{u,s}设为以u为根、至原深度h的最小费用s叉子树值。令z_{u,s}为孩子c值的第s小值，t=max(z−c_child,0)。全部c、z、t都在[0,k]内，因为费用非负且任何所选子树叶权总和≤W≤k。内点约束取等号；由上面的强分离式，根满足C_s≥W−k+s。故所有minorant权重都有一个可行扩展。

反向，设LP有可行扩展。按树深度归纳，c_{u,s}不超过真实最小费用s叉子树值：叶处相等；内点由t≥max(z−c_child,0)及sum_s_smallest恒等式，得c_u≤sum_s_smallest(c_child)，再用归纳假设及该函数的单调性。于是根的真实C_s≥c_{ρ,s}≥W−k+s。配合W≤k处理s=0，强分离恒等式全部项≤0，故w∈A(q)。投影恒等得证。

LP有O(k|V(T)|)个变量、约束，系数为位长O(log(k+1))的整数且有显式有界区间。对任意给定S0最大化其w坐标和，标准精确有理LP算法给多项式位长的最优有理点及最优值。本文未实现或虚构一个generic精确LP求解器。

注意：多状态f=max_a q_a的demand能交换两个最大值；但其minorant约束w(S)≤max_a q_a(S)不是单状态minorant域的交集。此时q_a(S)≤t必须对所有状态同时成立，对应补集中同时放置各状态的blocking子树，其共享资源并集费用不能拆成各自费用和。本稿没有解决这种联合blocking优化。


## 任意资源集合的锐XOS损失与实际支持构造

**ID/version：UM-PRIVATE-TREE-GLOBAL-XOS-LOSS-v1。** Objects / Domain / Quantifiers / Assumptions：共同合同的任意k,h≥1、全部显式非空state族、逐state单射及每个S⊆U。定义f=max_a q_a，A(f)={w≥0:w(B)≤f(B)对全部B⊆U}、E_f(S)=max_{w∈A(f)}w(S)，以及G(k,h)=k[1−(1−1/k)^h]。

**Exact Statement / Conclusion：** 对任意S，可确定性总位多项式构造一个具体非负有理w，使全部B⊆U都有w(B)≤f(B)，且

    w(S)≥f(S)/G(k,h)，    f(S)/G(k,h)≤E_f(S)≤f(S)。

该统一因子对每个固定(k,h)的完整输入类锐：single-state、S为全叶时，前述精确包络给f(S)/E_f(S)=G(k,h)。算法不求精确E_f、不调用整个minorant域的分离oracle。Scope：源估值的逐点XOS下支持工具，不是分配算法或调度hardness。

**完整证明与构造。** r=f(S)=0时返回全零。否则先用value DP找达到r的state a及其真实满r叉深h子树T′，全部r^h叶资源属于S。记B′为这些叶资源，仅在B′上置

    w_u=1/[r^h−(r−1)^h]，

其它资源权0。逐state单射使B′确有r^h个不同资源。任意B⊆U，将T′看作一棵满r叉树，前述uniform minorant给

    w(B)≤q_{T′}(B∩B′)≤q_a(B)≤f(B)。

中间不等式因T′中的每棵s叉同深树仍是原state的真正s叉同深树；没有压缩路径或删除祖先条件。全部权确为f的全域minorant，而不仅在目标S上有效。又

    w(S)=r^h/[r^h−(r−1)^h]=r/G(r,h)。

利用有限几何和

    G(d,h)=Σ_{j=0}^{h−1}(1−1/d)^j，

它对整数d≥1单调不减，r≤k便给所需下界。single-state全叶的精确反向界给锐性。f(S)=0、r1、k1、h1及state之间共享资源均包括。实际输出至多|U|个有理数，分母r^h−(r−1)^h的位数为O(hlog(r+1))，树和完整叶地址已显式计入输入；运行时间按总位长多项式。

## 单状态单位色类分解与线性规模支持多面体

**ID/version：UM-TREE-Q-ONE-THRESHOLD-MINORANT-v1。**

## Objects / Domain / Quantifiers

任意整数 k,h≥1，一棵显式满 k 叉深 h 的有根树 T。根深度 0；每个内部点恰有 k 个孩子；叶集 L 均在深度 h。输入须列出完整树，或全部完整叶地址；不采用仅二进制 k,h 表示的隐式指数树。这里仅有一个 state，叶标识互异，没有跨 state 的 max 操作。

对 A⊆L，q(A) 是叶都位于 A、根仍为原根、深度仍为 h、每个选中内部点恰有 r 个选中孩子的子树所能达到的最大整数 r∈{1,…,k}；没有正 r 可行时取 0。特别地 q(∅)=0。所有下述集合量词均遍历 L 的全部子集。

令 I={A⊆L:q(A)≤1}。空集属于 I。定义

χ_I(A)=min{r∈Z_{≥0}: A 可划分为 r 个属于 I 的集合}，

其中 r=0 仅允许 A=∅；可用空色类将较少色类补齐。定义非负加性 minorant 域

𝒜(q)={w∈R^L_{≥0}: w(A)≤q(A) 对所有 A⊆L}。

## Exact Statement 1：单位色类分解

对所有 A⊆L，χ_I(A)=q(A)。并且给定显式 A，可确定性总位多项式时间输出 q(A) 个具体、不交且覆盖 A 的色类，各色类 B 都有 q(B)≤1。A=∅ 时输出零个色类。该算法不只输出色数。

## Exact Statement 2：单阈值精确分离

对所有非负实权重 w，有以下等价：

w∈𝒜(q)  ⇔  max_{B⊆L:q(B)≤1}w(B)≤1。                    (1)

若 C_s(w) 表示最小权重同深 s 叉根子树的叶权总和，并规定 C_0(w)=0，则再等价于

C_{k−1}(w)≥w(L)−1。                                    (2)

因此既有按全部 s=0,…,k 分别检验的 minorant 合同，在本 single-state 对象上可精确缩为一个 s=k−1 阈值；(1)、(2) 都没有改变域 𝒜(q)。

当 k≥2，定义 W_v=位于结点 v 以下全部叶的总权重。定义树形数值 F_v：叶处 F_ℓ=0；每个内部点 v 满足

F_v=max_{c∈Ch(v)}[W_c+Σ_{d∈Ch(v),d≠c}F_d]。             (3)

则根值 F_ρ 恰等于 max_{B:q(B)≤1}w(B)。对非负有理 w，此递推及回溯可在显式树和权重的总编码长的确定性位多项式时间内完成；若 F_ρ>1，能够输出一个实际违反 minorant 约束的 B，且 q(B)=1。

k=1 单独处理：L 只有一个叶 ℓ，q(A)=|A|，域为 0≤w_ℓ≤1，分离只需比较 w_ℓ 与 1。式 (2) 依 C_0=0 仍有效。h=1 且 k≥2 时，式 (3) 给 F_ρ=max_ℓ w_ℓ，与 I 为 singleton/empty 集合相符。叶处 F=0 是辅助基例，不宣称高度0的 q 已被定义成主合同的集合函数。

## Exact Statement 3：O(|V(T)|) 非零系数的紧凑扩展表示

当 k≥2，以下有界有理线性系统在 w 坐标上的投影恰为 𝒜(q)。变量为每个叶的 w_ℓ、每个结点的 W_v,F_v，以及每个内部点的 Z_v：

* 0≤w_ℓ≤1；0≤W_v≤k；0≤F_v≤1；0≤Z_v≤k。
* 每个叶 ℓ：W_ℓ=w_ℓ，F_ℓ=0。
* 每个内部点 v：W_v=Σ_{c∈Ch(v)}W_c，Z_v=Σ_{c∈Ch(v)}F_c。
* 每条父子边 v→c：F_v≥W_c+Z_v−F_c。
* 根约束 F_ρ≤1。

系统有 O(|V(T)|) 个变量、约束和非零矩阵系数。这里计入两个 child-sum 等式的全部非零数，而非把长度 k 的和视作单个系数。矩阵系数均为 0、1、−1；显式上界中的 k 编码位长为 O(log(k+1))。k=1 直接用一个 w 变量和 0≤w≤1 即可。

对任意指定 S⊆L，最大化 w(S) 的这个有界 LP 的最优值等于 E_q(S)=max_{w∈𝒜(q)}w(S)。因此标准确定性精确有理 LP 算法可在总位多项式时间输出精确 E_q(S) 和达到它的实际有理权重。此为数学算法合同；没有在本记录中声称已经编写 generic LP 求解器或运行任何新代码。


### 自足完整证明

## 1. 对象和辅助递推

T 为显式满 k 叉深 h 的有序树，k,h≥1。根为 ρ，叶集为 L。对 A⊆L，q(A) 是能够在 A 内实现的最大同深满分叉数；无正分叉可行时取 0。主合同不定义 h=0 的估值。

为计算主估值，可在任意叶 ℓ 定义辅助值 b_ℓ(A)=k·1_{ℓ∈A}，并在内部点定义

b_v(A)=H((b_c(A))_{c∈Ch(v)})，
H(x)=max({0}∪{r∈{1,…,k}:至少 r 个坐标 x_i≥r})。

对高度至少 1 的子树，其 b_v 就是该子树的真实同深分叉值；特别地 b_ρ(A)=q(A)。高度 1 时 H 对叶的 0/k 向量给可用叶数，归纳即可验证该解释。所有这些值都可以一次自底向上的确定性 DP 计算。

下面分开处理 k=1：此时 L 只有一个叶，q(A)=|A|，一切色类和 minorant 结论直接成立，域为 0≤w_ℓ≤1。式 C_{k−1}=C_0=0 给 W≤1。后文的叶辅助 F=0 递推只需在 k≥2 使用，避免把 k=1 的辅助叶值误读成单位色类最优权。

## 2. 所有分叉值都能由单位色类实现

令 I={B⊆L:q(B)≤1}。先证明对任意 A，存在 q(A) 个 I 中的色类，不交且覆盖 A，并给出实际算法。

当 A=∅ 时 q(A)=0，输出零个色类。以下设 r=q(A)>0。

### 高度 1 的实际基例

此时 q(A)=|A|，按固定叶次序将每个叶分成一个 singleton 色类。这产生恰 r 个色类，每类 q=1。不能在这里将辅助叶值 k 当作 singleton 色数。

### 高度大于 1 的递归构造

对根的每个孩子 c，令 A_c 为 A 在其叶子树中的部分，r_c=q_c(A_c)，这里子树高度至少 1，q_c 是真实估值。由 h-index 递推，r 是这些 r_c 的 h-index。

称 r_c>r 的孩子为高孩子。高孩子至多 r 个：r<k 时若有 r+1 个，就会使根支持 r+1 叉子树；r=k 时没有高孩子。

准备颜色 1,…,r。按固定孩子次序，把每个高孩子的全部 A_c 放到一个各不相同的颜色中。高孩子内部不必再分色。

对其余孩子 c，有 r_c≤r。按归纳，将 A_c 实际划分为 r_c 个 q_c≤1 的色类，并将这些颜色依次对应根的颜色 1,…,r_c；未使用的颜色在该孩子下取空集。

由构造，各叶恰在一个色类中。固定任意根颜色 i，它在低孩子下的分叉值均≤1，并且至多有一个高孩子携带该颜色。因而它在根下至多有一个孩子的分叉值≥2，不能含同深 2 叉根子树，所以该整色的 q≤1。于是给出了所需 r 个单位色类。

这也是确定性实际划分算法：先一次计算所有子树 r_c；递归仅在低孩子继续；高孩子的叶直接写入其指定颜色；高度 1 时按叶次序写色。每个树点仅参与有限次扫描，每个叶仅被写入一个输出色类。即便使用朴素列表与排序实现，总操作数仍按显式树大小多项式；不存在按隐式指数对象展开的步骤。

### 色数下界

为自足起见，再核对 q 的次可加性。H 在非负整数向量上单调且次可加：设 p=H(x)、s=H(y)。p+s≥k 时结论直接成立；否则若 H(x+y)≥p+s+1，则至少 p+s+1 个坐标满足 x_i+y_i≥p+s+1，其中每个必有 x_i≥p+1 或 y_i≥s+1；这两类坐标各至多 p、s 个，矛盾。

辅助叶向量对集合并逐坐标次可加，逐层使用 H 的单调性与次可加性便给

q(A∪B)≤q(A)+q(B)。

故任意将 A 划分为 t 个单位色类的方案，都有 q(A)≤t。结合实际 r 色构造，得到

χ_I(A)=q(A)。                                           (4)

色类可用空集补齐的约定不影响最小值，也不影响后续权重不等式。

## 3. 全部 minorant 约束缩为单位阈值

令 w≥0。若 w∈𝒜(q)，则对每个单位色类 B 有 w(B)≤q(B)≤1。

反向，假设每个 q(B)≤1 的集合都满足 w(B)≤1。任意 A 可由第 2 节分成 q(A) 个单位色类 B_i。于是

w(A)=Σ_i w(B_i)≤q(A)。

A=∅ 时不等式为 0≤0。因此

w∈𝒜(q) ⇔ F_ρ(w):=max_{B:q(B)≤1}w(B)≤1。                (5)

这不是只验证目标集合，而是精确刻画全部集合上的非负加性 minorant 域。

### 单个 blocking 阈值

对 k≥2，深度归纳的二色分叉对偶给

q(B)≤1 ⇔ L\B 包含一棵同深满 (k−1) 叉根子树。             (6)

简要重构：如果 B 没有 2 叉根子树，则至多一个根孩子的 B 部分含 2 叉子树；其他至少 k−1 个孩子各由归纳在补集中提供 (k−1) 叉子树，连接即得补集树。两种树不能同时存在，因为第一层孩子数 2+(k−1)=k+1，必相交；在相交孩子下递归，最终必有共同叶。高度 0 只作“该叶属于哪种颜色”的辅助归纳底，不将主估值合同扩为 h=0。

令 C_{k−1}(w) 为最小叶权的同深 (k−1) 叉根子树费用，W=w(L)。由非负性和 (6)，任意 q(B)≤1 都有 w(B)≤W−C_{k−1}(w)。反向取最小费用 blocking 树的叶补集，按 (6) 它是单位色类，并达到此上界。因此

F_ρ(w)=W−C_{k−1}(w)。                                   (7)

结合 (5) 得单阈值条件 C_{k−1}(w)≥W−1。k=1 时依约定 C_0=0，同一条件正是单叶的 W≤1。

## 4. 单位阈值的实际 weighted DP 与分离

以下设 k≥2。对任意结点 v，W_v 是其下全部叶的总权。定义辅助叶 F_ℓ=0。它恰对应辅助叶值 b_ℓ(B)=k·1_{ℓ∈B}≤1 时只能取空集；这解释了为何不能误设 F_ℓ=w_ℓ。

对每个内部点 v，定义

F_v=max_{c∈Ch(v)}[W_c+Σ_{d∈Ch(v),d≠c}F_d]。              (8)

归纳证明：一个 v 以下的单位色类，至多在一个孩子 c 下具有辅助/真实分叉值≥2；其余孩子下必须各为单位色类。允许 c 不真正超阈值，仅把它作为潜在的唯一例外。由于 w≥0，c 下无约束时最优是全部叶，费用 W_c；其他孩子各自取最优受限叶集，费用 F_d。由此所有可行集合的费用不超过式 (8)，并且该式的任一个达到项所构造的集合都可行，所以等号准确。

高度 1 时 F_ρ=max_ℓ w_ℓ，确为 singleton/empty 色类的最大权。更高层递归保存一个达到的孩子 c：回溯时，在该孩子下取全部叶，在其他孩子下递归取其受限最优集合；叶 F=0 对应空集。由此实际输出一个达到 F_ρ 的 B。

若 F_ρ>1，该 B 不为空，因任意非空叶集都包含一个 1 叉同深路径，故 q(B)=1，且 w(B)>q(B) 是实际违反证书。若 F_ρ≤1，(5) 证明 w 属于完整 minorant 域。精确有理数求和、最大值比较和回溯均按显式输入总位长多项式。

## 5. 线性规模扩展 LP 的投影恒等

仍设 k≥2。变量和系统如下：

* 每叶 w_ℓ，每点 W_v,F_v，每内部点 Z_v。
* 0≤w_ℓ≤1；0≤W_v≤k；0≤F_v≤1；0≤Z_v≤k。
* 叶：W_ℓ=w_ℓ，F_ℓ=0。
* 内部点：W_v=Σ_c W_c，Z_v=Σ_c F_c。
* 每条父子边 v→c：F_v≥W_c+Z_v−F_c。
* 根：F_ρ≤1。

### 每个 LP 可行点投影为真实 minorant

W 的叶等式和内部 child-sum 等式强制 W_v 为该点以下的真实叶权总和。代入 Z_v=Σ_c F_c，每条不等式变成

F_v≥W_c+Σ_{d≠c}F_d。

右侧关于所有其他孩子的 F 都是非负系数。叶 F=0 是真实 weighted DP 基例，因此逐层归纳，LP 的 F_v 不小于式 (8) 的真实最优值。特别地真实 F_ρ≤LP 的 F_ρ≤1。由 (5)，w∈𝒜(q)。反向论证不靠 LP 辅助量等于真实 DP，也不错误使用含负系数的 Z 形式直接作单调归纳。

### 每个真实 minorant 都有满足人工界的 LP 扩展

给定 w∈𝒜(q)，令 W 为真实叶权总和，F 为式 (8) 的真实 DP，Z_v=Σ_c F_c。所有结构等式成立，每条父子不等式成立，且 F_ρ≤1。

现在逐项检查所有人工界无损：

1. 每个 singleton 的 q 值为 1，所以 0≤w_ℓ≤1。
2. W_v≥0，且 W_v≤W_ρ≤q(L)=k。
3. F_v≥0。任意 v 以下的局部单位色类，视作全树叶集后仍为全局单位色类：非根祖先路径上每层只使用一个孩子。于是 F_v≤F_ρ≤1；辅助叶 F=0 也符合此界。
4. 0≤Z_v=Σ_c F_c≤k。

所以真实 F、W、Z 满足所有给定界，投影不会因人工界而变小。两向结合证明投影恰为 𝒜(q)。k=1 直接使用单变量 0≤w≤1，不需要本扩展系统。

## 6. 线性非零系数计数与位复杂度

设 n=|V(T)|，i 为内部点数，ℓ 为叶数，e=n−1=ki。变量数为 ℓ+2n+i=O(n)。

叶等式共有 2ℓ 个。每个内部点的两个 child-sum 等式虽各有 k+1 个非零系数，但全部内部点加起来的 child 项各只扫描 e 条边，所以这两类等式共只有 2(i+e) 个非零系数。每条父子不等式有至多 4 个非零系数，共至多 4e 个。叶等式与根约束另有 O(n) 个非零系数；所有单变量界亦为 O(n)。因此变量数、约束数、矩阵非零系数数均为 O(n)，没有把长度 k 的和隐藏成一个常数成本。

矩阵系数为 0、1、−1；右端及人工界只使用 0、1、k，位长 O(log(k+1))。系统显式有界、非空（全零点可行）。对任意指定 S⊆L，以 Σ_{ℓ∈S}w_ℓ 为目标，投影恒等说明其最优值就是 E_q(S)。标准确定性精确有理 LP 定理给出总位多项式的精确最优值及一个实际有理达到点。这里没有声称实现或运行 generic LP 优化器。
