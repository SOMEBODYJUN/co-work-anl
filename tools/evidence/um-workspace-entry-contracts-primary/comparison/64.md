# 1. 全部原机器、原任务及版本域

输入显式有限CNF，每clause c至少k_c≥2个实际文字occurrences；允许重复文字/变量、同clause正负同现。每occurrence是不同物理索引，只属本clause。只保出现变量，各变量occurrences任意排环，少于3补dummy；dummy不属clause、polarity任取。总索引N，真实索引L=Σk_c，clause数h，环后继i⁺、前驱i⁻。正s_i=0、负s_i=1，pin(i)=M_i当s_i=0，或M_i⁺当s_i=1；dummy同样定义。

给输入二进制有理0<a<1。非空时有每索引两台不同原机M_i、C_i，每clause一台原R_c，全部机彼此不同。R_c是本clause专属、供本clause诸q共享的**真实物理机器**，不是virtual label。原任务为每索引q_i/b_i和每clause u_c，恰2N+h件、原机也2N+h台。

| 原job | 恰有的全部有限原端 |
| --- | --- |
| q_i | M_i:a，M_i⁺:1，C_i:1；真实i∈c再有R_c:1，dummy无R端 |
| b_i | C_i:1，pin(i):a |
| u_c | 本clause每个真实i的C_i:1；没有R_c端 |

其它∞，无预载、其它jobs、抽象OR/免费同编号关系或activation复制。每原job整件恰一次。有限资格由q的3N+L、b的2N、u的L合计**5N+2L**；非空dense是(2N+h)²项。

v1原写法对空Φ给N=h=0、零机零job。空二部图有空matching，但不属本项目至少一机的普通UM，所以v1的完整目标合同只能在非空Φ成立。v2另定空式一台idle原I、零jobs、负载0；机器数max{1,2N+h}，任务数2N+h，空矩阵为1×0。非空v1/v2的全部资格、时间和以下证书相同。

可选给B∈[1,2)再选a>B/2以连接nearunit保护环，但本全公式构造不使用这个额外下界，对全部0<a<1成立。即使a很小允许实际机器另有更多共居可能，以下构造仍主动每机只放一job。

# 2. 一份共同分数匹配，不是分数执行

真实i∈c令θ_i=1/k_c≤1/2，dummy令θ_i=0。在原job–machine资格图赋分析质量，未列边全0：

| 原job | 分数匹配质量 |
| --- | --- |
| q_i，s_i=0 | M_i:1/2−θ_i，M_i⁺:1/2；真实时另R_c:θ_i |
| q_i，s_i=1 | M_i:1/2，M_i⁺:1/2−θ_i；真实时另R_c:θ_i |
| b_i | pin(i):θ_i，C_i:1−θ_i |
| u_c | 本clause每个C_i:θ_i=1/k_c |

q_i→C_i的**原资格保留**但质量0，dummy不虚构R端。k_c=2时扣后为0，不要求该边严格正；dummy θ=0是质量，不是原处理时间变0。各环长≥3使本位/后继是不同机器，不把同一原job在同一机重复计作两个资格。

逐job：真实q两内部项合1−θ，加R项θ得1；dummy两half合1。b两项合1；u在k_c个不同物理C各给1/k_c，合1。重复文字/变量不合并这些C_i。

# 3. 两种等价的逐M恒等式及所有列和

作者按每条环edge i合q_i和b_i看：在M_i合计1/2、在M_i⁺合计1/2，因为pin方向被扣的θ恰由同编号b补回。因此每M_i收本edge左端及前edge右端，合1。

独立稿直接把同一M_i所有原邻项列开：
\[
(1/2-[s_i=0]\theta_i)
+(1/2-[s_{i^-}=1]\theta_{i^-})
+[s_i=0]\theta_i+[s_{i^-}=1]\theta_{i^-}=1.
\]
这没有假设变量polarity统一；任意正负排列、同clause正负同现和dummy方向都逐项抵消。

真实C_i收b的1−θ与唯一所属clause u的θ，合1；dummy C只收b的1。每R_c收该clause各q的1/k_c，共k_c项，合1。于是**同一份全局**证书把全部2N+h jobs及2N+h机器同时单位饱和，不是各clause或每台机器分别挑一份可能冲突的见证，也不依赖SAT赋值或a的数值。

# 4. 作者全图整数流：全部原任务真实恢复

作者在原有限资格全图建source→每job容量1、job→每有限原机容量1、每机→sink容量1。前述分数证书给值2N+h可行流，总源容量也只有此值；整数容量最大流有同值整数流。故每原job选一个原有限端，每原机恰接一job。

这些是整件原q/b/u，不是分析份数或新增任务；原有限处理时间仍a或1，均≤1，所以**所有原机同一actual**负载同时≤1。R_c原邻job只本clause真实q，因此每R_c确实由本clause一枚原q以unit端占据。Clause的“有一个实际query身份读出”没有丢；丢的是该q与u占用C_j迫返的b_j同编号关系。

作者用的是原有限全图，允许整数算法选到证书质量0但实际合法的边；不应从分数q→C=0反推原P删了该资格。这样的全图整数输出仍满足全部主结论，不承诺每clause的其它模式被唯一规范化。

# 5. 独立正支撑Hall与逐次BFS

独立稿仅取分析质量>0的支撑边，主动不使用q→C原资格，k_c=2的扣零边也不入此分析图。对任意左任务集S，其发出总质量|S|都进邻机Γ(S)，每机总质量1，所以|S|≤|Γ(S)|，Hall成立。

固定输入job/machine顺序，从空matching开始，对最小未matched原job做交替BFS，到空机即翻转，大小增1。若失败，可达任务与邻机形成|Γ(S)|<|S|的Hall违例，与共同证书矛盾。至多2N+h次成功增广覆盖全部jobs；两侧等大故也覆盖全部原机。投影回原job目的地，原time仍a/1、全机≤1。

作者全图整数流与独立正支撑BFS证明同一原P存在所需actual，但搜索图/确定顺序可不同，不要求输出同一matching。删掉零质量边只为独立算法分析，没有修改物理原矩阵；更没有把实际R_c消去成virtual。两条完整路线和两个M恒等式各自保留，不以“相同”吞掉源的推导形式。

空Φ不调用非空perfect-matching步骤：v2直接输出一idle机、空assignment、负载0，每“非idle机一job”真且没有伪造R或matching。v1的空图数学事实不救其零机对象合法性。

# 7. 显式规模与准确失败边界
