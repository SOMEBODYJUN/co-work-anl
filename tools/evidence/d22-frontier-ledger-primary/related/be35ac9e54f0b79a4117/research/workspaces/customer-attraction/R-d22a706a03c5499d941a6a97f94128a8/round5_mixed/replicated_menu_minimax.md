# n 块条件根菜单：精确混合值与首次失效阈值

2026-10-23，Boss10 / mixed_menu。**条件性解析结论；不是完整 SPE 反例。**
下述 n 块菜单的可实现性是独立承重义务。这里只计算：若该菜单真实实现，其混合
防御值是多少，以及它实际否定哪些接口。没有外审或新颖性声明。

**同轮后续诊断：** credible_family 的精确集合 BI 已发现 n=3 四类指定根子树
全部不可实现，并复现 n=2 四类全部可实现。原始结果在
`../round5_credible/block_menu_n3_probe.json`。本文件的静态矩阵公式不改变这个
可信性失败；没有把 n=4 的阈值当成真实 SPE 反例。一个最小余三人阻断节点的
独立解析见本目录 `three_block_last_low_witness.md`。

## 1. 客户、终局和条件菜单

取 n≥1 个互不相交的十六单位客户块。第 j 块的主题为 A_j,B_j,C_j,D_j，
兴趣类型与单位客户数为 `{A}:2,{B,D}:4,{A,C}:6,{C,D}:3,{A,B,C,D}:1`。
共同目录恰为这 4n 个主题，总玩家数为 4n，背景为零。

单块四主题计数定义为

```
q0=(2,1,1,0), qA=(2,0,1,1), qB=(1,1,1,1),
qC=(1,0,2,1), qD=(1,0,1,2).
```

**条件菜单 R_n：** 强制根选 T_j 后，真实完整终局在第 j 块为 qT，
其余 n−1 块均为 q0。此条件包含根本人，所有列各有恰 4n 槽。
必须另给同一完整历史纯 SPE 同时兑现所有根列；只指定这些终局不够。
已有 n=2 完整证书不自动证明 n>2。

根各分支自身收益为 `(13/4,9/4,13/4,13/4)`，故该菜单若实现，根收益
`u=13/4`，可选择任意 A_j,C_j,D_j 为实际根行动。

## 2. 从单位客户得到完整额外查询矩阵

记 `L[S,T]` 为在本块终局 qT 后**额外插入** S 的收益，
记 `h[S]` 为在本块终局 q0 后额外插入 S 的收益。按 A,B,C,D 排列，

| 查询 / 根本块列 | A | B | C | D | h：根在别块 |
| --- | ---: | ---: | ---: | ---: | ---: |
| A | 71/30 | 16/5 | 27/10 | 16/5 | 71/30 |
| B | 11/5 | 23/15 | 11/5 | 23/15 | 11/5 |
| C | 27/10 | 16/5 | 49/20 | 59/20 | 16/5 |
| D | 16/5 | 38/15 | 59/20 | 137/60 | 37/10 |

于是全矩阵为 `K[S_i,T_j]=L[S,T]`（i=j）或 `h[S]`（i≠j）。
各列都是条件菜单真实 4n 槽，查询与列随机化独立。

## 3. n≥3 的原始/对偶精确匹配

设 `Q(D_j)=1/n`，其他列概率为零。对每个块 i，四种查询的期望收益为

```
A_i: 71/30 + 5/(6n)
B_i: 11/5 − 2/(3n)
C_i: 16/5 − 1/(4n)
D_i: 37/10 − 17/(12n) =: M_n.
```

当 n≥3，D_i 项为四项最大值。与 C、A、B 项的差分别为
`1/2−7/(6n)`、`4/3−9/(4n)`、`3/2−3/(4n)`，均非负。
所以 `min_Q max_t (KQ)_t ≤ M_n`。

反过来，取独立查询分布 `p(D_i)=1/n`。对任意根列 T_j，

```
(p^T K)[T_j] = ((n−1)37/10 + L[D,T])/n ≥ M_n,
```

因为 D 行的四个本块值中最小者为 `L[D,D]=137/60`。
对所有列分布 Q 取平均，再用最大查询≥查询平均，得到
`max_t(KQ)_t ≥ p^T KQ ≥ M_n`。因此

\[
\boxed{M_{\rm full}(R_n)=\frac{37}{10}-\frac{17}{12n}\qquad(n\ge3).}
\]

同一个 `p=Q=uniform(D_1,...,D_n)` 还是对称 meta-Nash：所有支持内 D 行收益
均为 M_n，其他行收益不超过 M_n。这一事实只针对条件矩阵，不替代 SPE 可实现性。

## 4. 首个严格混合障碍为四块

当 n≥3，

\[
M_n-u=\frac9{20}-\frac{17}{12n}
=\frac{27n-85}{60n}.
\]

故 n=3 时值为 `581/180<13/4`，n=4 时值为

\[
\boxed{M_4=\frac{803}{240}>\frac{13}{4},\qquad M_4-u=\frac{23}{240}.}
\]

一、两块不构成更早的混合障碍：n=1 取纯根列 A，列最大值 `16/5<13/4`；
n=2 已认证混合值 `851/280<13/4`。所以在这份菜单族内，n=4 是首个失效整数。
四块仅需 64 名单位客户、16 个主题、16 名玩家；这仍是**条件参数**，不是已给出
完整 SPE 的实例声明。

## 5. 一旦实现，哪些命题被否定

若 R_4 由一个完整纯 SPE 实现，任意列随机化 Q 的最大额外查询均至少 803/240，
严格大于真实根收益 13/4。因此完整根菜单 Mfull 被否定；也否定以任意给定查询
分布推送真实完整根终局的弱不等式 `p^T Kp≤u`，因为上述均匀 D 分布有
`p^T Kp=803/240`，且支持内真实根收益全为 13/4。此时所有 meta-Nash 的收益
都大于 u（它们的列分布也是可行 Q），并非仅展示某个高收益 meta-Nash。

这不否定自由选择 4n 槽竞争背景的 extra-one 安全门槛：在每个块都选静态
`qB=(1,1,1,1)`，所有额外查询不超过 `16/5<13/4`。
这份静态 profile 没被规定为根菜单中的可选列，因此恰好区分“真实菜单内混合”
与“自由背景”。

也不否定半覆盖：菜单中每一列覆盖全部 16n 客户，所以如果实现，则实际
`W=OPT_(4n)=16n`。全局目标 Q-CAG-HALF 仍开放。

## 6. 核验与剩余工作

`verify_replicated_menu_minimax.py` 不读先前矩阵、不导入 CAG solver，直接从
五类客户重数和整数 profile 计算上述全部有理数并核对 n≥3 的匹配。
代码内有限 n 检查仅检查实现公式；一般 n 结论由第 3 节有理解析证明承担。

后续有判别价值的义务是把 n=3 已观察到的 last-low 阻断提升为可扩展的
后继激励机制。n=4 及更大 n 不能由 n=2 直和推出；本文件没有越过此义务。

## 7. 一次真实子树替代诊断：原对偶方向也未穿过

仍固定 n=3 的具体实例、`u=13/4` 与 `p=uniform(D0,D1,D2)`。
允许对每个根行动选择任意真实 SPE 子局终局，同时要求根自身收益不超过 u。
同轮 credible_family 的精确集合 BI 给四类根动作的可选终局数分别为
`60,39,35,35`，其中 p 插入值的最大者依次为

```
A: 101/30 > u; B: 283/90 < u; C: 197/60 > u; D: 551/180 < u.
```

四类最大者都可写为 `qT | qE | q0`，其中 `qE=(1,1,2,0)`，允许交换后两块。
qE 的额外 D 查询值为 `4/2+3/3+1/5=16/5`，比 q0 的 `37/10` 少 `1/2`。
所以对原条件矩阵有效的均匀 D 查询，面对真实子树时在 B、D 类根上已不能保持
高于 u。此诊断没有产生另一份 mixed 反例，也没有证明所有 p 失败。

最大值与 SPE 可实现性由 credible_family 探针承担，本目录没有独立重跑大 BI；
本目录核验器只从单位客户独立核对展示终局的插入值及根自身收益。有限诊断失败
不是一般 Mfull 的证明，亦不支持在固定人数上继续无限调参。
