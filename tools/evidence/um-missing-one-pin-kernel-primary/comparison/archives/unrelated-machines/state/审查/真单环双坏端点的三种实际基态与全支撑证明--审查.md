# 真单环双坏端点的三种实际基态与全支撑证明

## 独立身份、原矩阵与初始目标

41152B/637行主review全部实读，含两份不同声明先行重构及各作者/最终读后记录；624行canonical也已全文读。本页只承担UM-CONFIG-PRESERVING-CIRCUIT-TWO-SIGN-SUPPORT-LOSS-v1，旧三身份不因它升级。尤其旧[双符号直和](完整配置双符号直和提升的真实耦合与审查先验--审查.md)不是circuit。本页保存三种**确实不同**真实基态而非把所有证明压成一个存在断言；先验/软件/版本另见[配套审查](真单环审查的Exact先序与有理参数版本证据--审查.md)。

奇D≥3，L=D+2、N=DL，CRT使t↦(a=t modL,j=t modD)双射，t循环modN。两个复制标签c0/1；机器K_(c,a)共2L，G_(c,t)共2N，Q_a共L，Z_t共N。任务：

- 两selector U_c，在本标签全部K耗时1；
- 每t/c一port F_(c,t)，home K_(c,a(t))耗时1/D、outer G_(c,t)耗时1；
- 每t一H_t，在G_(0,t)、G_(1,t)、Q_(a(t))均耗时1；
- 每t一E_t，在G_(1,t)、G_(0,t+1)、Z_t均耗时1。

其余端∞。机器3N+3L、任务4N+2、有限端10N+2L。置ρ=(L−1)/L、γ=ρ/2。目标边际：U每rail1/L，F home/outer为ρ、1/L，H/E两G端各γ、停车1/L。不能从这些局部数字推出实际调度，下面逐任务构造。

## 作者基态：rails D、D+1

唯一写t=hL+r，0≤h<D、0≤r≤D+1。U0给K_(0,D)，U1给K_(1,D+1)；各选中rail全部D个ports外送，其余ports全home。每K负载1。H/E按表执行全部原jobs：

| offset r | H_t实际端 | E_t实际端 |
|---|---|---|
| r<h | G_(1,t) | G_(0,t+1) |
| r=h | Q_h | G_(1,t) |
| h<r<D | G_(0,t) | G_(1,t) |
| r=D | G_(1,t) | Z_t |
| r=D+1 | G_(0,t) | G_(0,t+1) |

G1在r<h或rD接H，在h≤r<D接E，在rD+1接F；G0在r≤h接前E，r0由前block末E送入（包括t0全环回绕），h<r<D或rD+1接H，rD接F。每G恰一unit。Q_h仅一H、其余Q空，Z各至多自己的E，故真实峰1；unit U任何端1迫真实OPT1。

## Exact先行基态一：同rails 0、D，pivot h+1

common_capacity选择U0在K00、U1在K1D，只外送a0的F0和aD的F1，其余home。记r_h=h+1。H在r<r_h去G1、r=r_h去Q_(r_h)、r>r_h去G0。E在r<r_h去G0next，rD去Z，其余G1；r_h≤D使这三个E条件不冲突。

G1在rD接F，其余r<r_h接H、r≥r_h接E。G0在r0接F，前block rD+1的E去自己的G1，故回绕不撞；1≤r≤D时前E到达当且仅当r≤r_h，与H条件r>r_h互补；rD+1的前E已停车、由H填。Q1..D各一H、Q0/Q_(D+1)空；每block E_D停私有Z。全部原任务一次，真实峰1。

## Exact先行基态二：同rails 0、D，pivot h

literature_mechanism也选rails0/D、ports规则同上，H/E却如下，不能冒充基态一或作者表：

| offset r | H_t实际端 | E_t实际端 |
|---|---|---|
| r<h | G_(1,t) | G_(0,t+1) |
| r=h | Q_h | G_(1,t) |
| h<r<D | G_(0,t) | G_(1,t) |
| r=D | G_(0,t) | G_(0,t+1) |
| r=D+1 | G_(1,t) | Z_t |

G0的r0接F（前E停Z），1≤r≤D时前E与H分别按r≤h/r>h互补；rD+1接E_D。G1的rD接F，r<D由H/E互补，rD+1接H。Q_h各一H、Z各至多自己的E，边界h0/hD−1均合法，真实峰仍1。

## 同步旋转给全部有限端的共同边际

对任一上述基态，同时平移t→t+s及a→a+s modL，旋转F/G/H/E/Z、K/Q，U任务身份不动，是实例自同构；E的G0next同步成t+s+1，不能单独转任务或停车机器。s遍历Z_N取N等权原子。

每rail被U选中D次，U边际1/L；每F outer D次/home余次，得1/L/ρ。三个基态每block H的G0/G1数量都D−h、h+1，E的G0next/G1数量都h+1、D−h，各停车一次。求和均D(D+1)/2，停车D；旋转对每类t传递，故H/E两G边际均D(D+1)/(2N)=γ、停车D/N=1/L。这是**同一个全局分布**实现全部边际，不是各行分别抽样。

N原子互异：U位置先迫若同调度则平移差s≡0 modL；基态每已用Q标签仅一个停车H，标签不变再迫该H编号不变，故s≡0 modN。每原子都完整峰1且U迫OPT1，初态确属真实最优凸包。

## 一个真支撑极小circuit与整段完整CONFIG

方向只在H的G0/G1端取+1/−1，在E的G1/G0next端取+1/−1，余0。物理关联图G0t—H_t—G1t—E_t—G0(t+1)串成单个4N边/4N顶点简单环；所有相关任务/机器系数1。沿行约束核坐标交替传播，仅一自由倍数，rank A_C=4N−1；任一坐标零迫全零，故真子支撑无核，是**support-minimal**，不是另证全矩阵最小基数circuit。

方向坐标γ±θ，2γ=ρ<1使最大箱段恰[−γ,γ]，先碰0而非1。所有机器负载保持，端点全部任务仍有≥2条分数正端；没有任务整数化，损失来自永久删零端。整段CONFIG(1)显式如下：

## 两端点对所有正支撑完整调度的精确最优值

正端点H只余G0/Q、E只余G1/Z；负端点H只余G1/Q、E只余G0next/Z，U/F端全留。B=2−1/D。任正端完整调度若峰<B<2，hard复制0的U在某K0a，该rail保留h枚ports给1+h/D<B，迫h≤D−2，即至少两F外送各自G0。对应H不能与unit F同机，唯一另端都是同一Q_a，迫至少两unit撞Q，矛盾。负端用复制1同理。未固定其它任务或背景原子，故下界覆盖**任意**完整正支撑调度。

三种完整B上界也保留其不同来源：作者在hard复制选rail只外送一F、让对应H停Q，其余H占hard G；easy复制选rail全部D个F外送，冲突E各去自己的不同Z，其余E占easy G，hard rail负载B、easy≤1。common_capacity独立上界则选U0 rail0/U1 railD，仅外送F_(0,0)、F_(1,D)：正端H0停Q0/E_D停Z_D，其余H G0/E G1；负端H_D停Q_D/E_(N−1)停Z_(N−1)，其余H G1/E G0next。literature_mechanism另选两selector都rail0，仅外送两F_(c,0)，正端H0Q0/E0Z0，负端H0Q0/E_(N−1)Z_(N−1)，其余按对应G。后两上界两个selected rails均B，全部G/Q/Z≤1。各方案安排**全部**原任务且只用该端点正端，故两OPT恰B。
