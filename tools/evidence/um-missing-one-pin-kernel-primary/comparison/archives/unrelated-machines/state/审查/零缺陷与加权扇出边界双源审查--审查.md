# 读取范围和共同边界

本审查逐项读取两个冻结 JSON、相关规范/独立程序及当前 `weighted_fanout_profile_boundary.md` 和 review。稳定 ID 为 `5f65c9a3f17aaf1502b5`（weighted-excess 文件 SHA `35dc6adc3c3447ca5138287e46fa0265c109f58817fcd946afff7235cb4f6beb`，库存摘要为 `5f65c9a3f17aaf1502b5`）与 `6e26495b5249fd378264`（weighted-fanout 文件 SHA `afc737d04ddb1943b5e2d5d295fa872faadfad4324330672b9384cea34f38c04`）。两对象均使用 Fraction/确定性整数核验，且 scope 只覆盖给定实际 YES 见证、有限 profile 或有限构造；不能从有限输出推出一般 UM hardness、未知 YES 的寻找算法或全局近二结论。

## 1. weighted excess zero-defect trap

`weighted_excess_zero_defect_trap_audit.json` 报告 `status=all Fraction checks passed`、8 个固定 cases、seedless deterministic Fraction arithmetic、命令 `weighted_excess_zero_defect_trap.py`。每例有 (m,q,\beta,\epsilon)、机器/工作/有限边计数、多个 optimal witnesses、maximal pivots 和 terminal completions。代表行：

- (epsilon=1/2,m=3,q=2/3,\beta=1/8)：7 jobs、15 finite edges、3 maximal pivots、所有 terminal completions makespan (5/3)。
- (epsilon=1/2,m=5,q=4/5)：11 jobs、25 finite edges、5 pivots、terminal makespan (9/5)。
- (epsilon=1/10,m=11,q=10/11,\beta=9/40)：23 jobs、55 finite edges、11 pivots、terminal makespan (21/11)。

每个 state 都记录 (N,J,P,rank,nullity,count\_slack)。在终点 state，`count_slack=-1`，而 `terminal_D=0`、所有 anchor completions 都回到同一零缺陷端点；这说明仅凭剩余 nullity/计数 slack 不能把“零缺陷”当作可继续消除的缺陷。报告 scope 还明确保留 task equalities/protected loads，不包含 CONFIG/big-count inequalities，因此是局部障碍，不是完整算法反例。

该源的用途是约束后续 excess-pivot/selector 证明：若算法把 zero-defect 状态当成必有下一步，终点样例已阻止这一推断；必须另证全局 CONFIG 或容量不等式。它不证明所有 pivot 规则都失败，也不否定已有 upper-column 或 Hall 证明。

## 2. weighted fanout profile boundary

`weighted_fanout_profile_boundary_audit.json` 同时承载两项明确 claim：`UM-WEIGHTED-FANOUT-PROFILE-BOUNDARY-v1` 和 `UM-FANOUT-MISSING-ONE-THREE-HALVES-v1`。实际构造使用三主机/多主机 weighted fanout profile；对给定两份实际 YES 及显式 beta 做二色/多色吸收闭包和 splice，输出 bound 形如 (T(2-\beta))；当 (eta=1/2) 得锐 (3T/2)。在 (T=1,eta=1/3) 的四主机样例，bound 为 (5/3)；(T=7/3,eta=3/10) 的具体输入输出 bound (119/30=(2-3/10)T)，重算 loads 为 `[35/9,7/3,7/3,7/3,7/3,0]`。

规范实际审计的计数包括：22 个 full binary tree shapes、98 个 binary-tree exact missing profiles、177 pair actual witnesses、1 dictionary beta subset boundary、3 fixed positive/huge-rational boundaries、24 invalid inputs、244 random actual instances、1263 exact missing-pair-sum checks、2706 subset-profile-sum checks、8118 weighted actual constructions、12704 test-only assignment states、44 uniform-star profiles、81 weighted-star facet profiles 和 18 weighted-star vectors。独立合并程序另有 192 simplified root-tree instances、140844 full assignments、400 weighted-profile random instances、8376 weighted constructions、6722 local K-budget checks、32975 full assignments、140 weighted-star budget equalities；其函数体来自四个独立 scratch 文件，entry point 只是合并，不应把合并当第五种数学证明。

实际输入与程序均是 Fraction/清分母整数；构造不计算 μ、不调用 test-only oracle，也不解决未知 YES witness。`scope=actual schedules only; no general SC extension audited`，故 Santa/效用对象不可从该 JSON 代签。规范和独立输出都明确 no general UM hardness、no source satisfiability、no novelty certification。
