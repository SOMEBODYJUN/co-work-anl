# 2. heavy区间为何给计数容量

strict时每M至多一q/b，因为各时间≥ρ>1/2。每正C至多一J，因为任两原J时间和>1。任一J与该C的unit b也不能共居，故J占C迫同编号正b去自身M。这里流中C的容量1是**件数约束**，不是把C真实成本统一为1。

False时unit f占满正pool，无正q可按1/k导出。若t枚正b返回，k枚正q加t枚b除了唯一q_k可去Mₖ₊₁外都需k台正M，故k+t−1≤k、t≤1；额外负q/b入流只减余量。独立稿另从两个返回点h<h′出发，q_h不能自身/满pool，只能后继耗1，沿正block传播至q_h′₋₁撞第二b，同样矛盾。两证均不要求输入全环同向，均计所有aux。

于是False branch c≤1、True平凡c≤k，得到

\[
K_u,K_v\le\lceil(k+1)/2\rceil=k/2+1,
\quad K_a\le1\ (a\notin\{u,v\}),
\quad 0\le K_a\le k.
\tag{1}
\]

1/2严格下界确用于“一C至多一J”：若允许等于1/2，两件局部时间和可以恰1，此计数前提不能继续用。它不是整个更广模型无三半全False调度的反例；后来v4另有不依赖该计数的证明，见§7。上端1包括在内，保证选中单J输出C≤1；unused>1只允许在I，不允许在v3正C资格中。

# 3. 独立稿：完整双出现项的一个全局整数流

每J保两个带标号实际出现项(z,u)/(z,v)，同job同h也保两项。这是记账，不复制物理任务。内部h按真实时间降序p₁≥p₂≥⋯，邻项成容量1配对slot，奇尾单列。两actual给Σp≤2、非空最大p₁≤1。

网络源→每原J cap1；J→它实际出现项的slot或正C cap1；slot→汇 cap1；正C→branch gate cap1；gate→汇 capKₐ。重复同job同slot/C边可合并一条cap1。每actual目的地各送half，slot最多两half、C每见证≤一J所以half合≤1、branch平均≤Kₐ，给覆盖全部J的分数满流。

从0按确定性残量增广取得整数满流，最多|J|次：若不足总源容量|J|就无增广，残量可达割容量不足该值，与分数满流矛盾。每job源容量1使同一物理job只选一次，即使两个出现项在不同slot。选slot便输出该原h，真实时间≤slot最大值，因此每I负荷

\[
p_1+p_3+\cdots\le(\sum p+p_1)/2\le3/2.
\tag{2}
\]

排序奇偶差≤p₁，由−p₂+p₃、−p₄+p₅等非正分组得出；偶尾额外负项、奇尾、全零/空表都合法。没有按成本倒数、uniform行或tiny下界假设。每C≤一原J且每branch正C的J数≤Kₐ，真实C时间保(1/2,1]。所有共享内部/跨branch/guards/aux在这同一次流中处理，非每branch另占一份内部资源。

# 4. 作者：先固定同目的地的另一合法编码

作者Proof先固定两actual同目的地的J。在内部h固定总负载Fₕ≤1；固定C在两strict都已有一heavy J，不能再接第二J，故删掉它不会丢其它残余job的实际端。设branch固定C数dₐ，两c均含dₐ，残gate Kₐ−dₐ非负。

\[
\operatorname{load}_h\le F_h+(\sum w+w_1)/2
\le3/2-F_h/2\le3/2.
\tag{3}
\]

Fₕ1时剩项可为0，仍须执行所有原jobs；空表残负荷0，加回F不丢。固定C也扣branch d，没有免费重复安排。

# 5. 两套完整backbone回填

全局J流后，对每变量令S⊆[k]为被J占的正C，c=|S|≤Kₐ。共同先把f→正pool、S中的正b→自身M，其余正b和全部负b→原C。每C恰一J或b，正C实际≤1，负C负荷恰1。S空则全部q→自身M，不导出。

**作者max集合route。** S非空令p=maxS：S去p的正q→正pool；p前其余正q→自身M；p..k正q→后继；负k+1..2k−1的q→后继；负末q₂ₖ→负pool。p前M由返回b或自身q各一，M_p为b_p，M_p₊₁..M₂ₖ为前驱q；负末导出避免环尾撞M₁。所有q列表互斥穷尽，原端合法。

**独立区间route。** 写S={h₁<⋯<h_c}：h₁前q自身；对相邻选中点hⱼ/hⱼ₊₁，q在hⱼ..hⱼ₊₁−2走后继，q_hⱼ₊₁₋₁导正pool；末选点h_c..k走后继；负首q_k₊₁导负pool；负k+2..2k的q走自身。空区间略过，连续选中点也有效。每M选中点为b，点间/最后到Mₖ₊₁为前驱q，其余为自身q，互斥覆盖全部M。q_k的后继是原Mₖ₊₁，导出q_k₊₁是真负block任务。

两套都是每原q一次，全部M恰一原q/b、时间ρ或1；区别是具体原q去向。S非空均恰c−1枚正q及一枚负q导出，故

\[
\operatorname{load}(A_0)=1+\max(0,c-1)/k,
\quad \operatorname{load}(A_1)\le1/k.
\tag{4}
\]

任意非连续/相邻S均覆盖，不要求原guard身份或旧witness出口不动。与同一J分配合并无隐藏冲突：不同变量ring/pool互异，J无M/pool/负C端、backbone无I端，正C按S二选一。全部原q/b/f/J各一次。
