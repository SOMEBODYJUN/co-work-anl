# 两层共享标签收费的全源三半逃逸与强列表 NO 反例

读取目的：在把 partial Min-Rep 的列表费用转成实际负载前，核对一个具体两层交叉尺寸 compiler 的全部原任务。这里给出的真实调度关闭这一 compiler；不证明一般 UM 的近二困难性，也不证明所有共享收费构造不可能。

## 1. 精确身份和对象

**ID/version：`UM-TWO-LEVEL-LABEL-FEE-ESCAPE-v1`。**

- Objects / Domain：显式二部投影约束多重图 \(G=(U,V,E)\)，每顶点 \(v\) 有非空有限标签集 \(\Sigma_v\)，每边 \(e=(u,v)\) 有全定义投影 \(\pi_e:\Sigma_u\to\Sigma_v\)。允许平行边、孤立点、不同字母表和非单射投影。给整数 \(D\ge2\)，所有度数不超过 \(D\)。以下矩阵全部显式展开；不同名称的机器、任务互异，只有表中重用的名称表示真实共享。
- Assumptions：无复杂度假设；不使用源 YES 见证、分数证书或未知 OPT。全部原任务必须安排。
- Exact Statement / Quantifiers：对每个上述构造呈现及每个预给定的边状态 \(a_e\in\Sigma_u\)，可确定性按展开矩阵总位长多项式输出完整实际调度，保持所选根和左右两个查询全部外送，且峰值 \(\le1+\lfloor D/2\rfloor/D\le3/2\)。若 \(U\cup V\ne\varnothing\)，则更精确有 \(\mathrm{OPT}=1+\mu/D\)，其中 \(\mu\) 是边状态选择的“最大逐顶点第二标签次数”的最小值（§2.1）；这是值恒等式，不承诺多项式优化 \(\mu\)。同一矩阵满足 \(\mathrm{OPT}\le1\) 当且仅当源存在满足全部约束的 singleton 赋值；任意完整实际峰值 \(<1+1/D\) 的调度均能解码这种赋值。对下述奇数移位族，实际 \(\mathrm{OPT}=1+1/q\)，而总 cost \(\le2g\) 的源列表只能覆盖 \(\le g^2/q\) 比例。
- Scope / Conclusion：一个明确的真实 compiler 及其全部输出域的逃逸算法、任意低调度 decoder 和反例族；不是一般三半算法或一般不存在 \(\varepsilon\) 的证明。
- Dependencies：UM-MODEL-v1；下面完整自足构造、逐机计数与解码。不调用外部近似定理或 PCP。
- Evidence / Counterevidence：一般证明在本文；实际独立重构、读后和最终文件审查见专门审查。有限代码只核所列输入，不能代替量化证明。
- Status：限范围证明及内部审查分别登记；无外审、全球新颖性或独立论文价值认证。`UM-TARGET-v1` 与其一般反面继续 OPEN。

令 \(\delta=1/D\)、\(\beta=3/4\)。所有未列处理时间为 \(\infty\)。

| 原任务 | 全部有限端与时间 |
| --- | --- |
| 每边一个 \(s_e\) | 该边所有 \(R_{e,a}:1\)，\(a\in\Sigma_u\) |
| 每 \((e,a)\) 一个 \(x^u_{e,a}\) | \(R_{e,a}:1/2\)、\(H_{e,u,a}:1\) |
| 每 \((e,a)\) 一个 \(x^v_{e,a}\) | \(R_{e,a}:1/2\)、\(H_{e,v,\pi_e(a)}:1\) |
| 每 incidence \((e,v)\)、每 \(b\in\Sigma_v\) 一个 \(z_{e,v,b}\) | \(H_{e,v,b}:\beta\)、\(A_{v,b}:\delta\) |
| 每 \((v,b)\) 一个 \(w_{v,b}\) | \(A_{v,b}:1\)、\(B_{v,b}:1\) |
| 每 \((v,b,r)\)、\(r\in[D]\) 一个 \(f_{v,b,r}\) | \(B_{v,b}:\delta\)、\(C_{v,r}:1\) |

特别地，pool 按源顶点分隔：\(f_{v,b,r}\) 只能到自己固定编号的 \(C_{v,r}\)，同顶点不同标签共享这台机器；不同顶点不共享。没有任意重编号、全局 pool 或压缩任务。非单射投影可能使同一边多个未选查询共享一个 \(H\) 资格，但它们在以下构造中都留在各自根。

空顶点图无任务时补一台空机器，满足 \(m\ge1\)，此时 OPT 为零；其余退化输入按上述表逐项生成。

## 2. 任意源、任意边状态的完整三半调度

预给每边状态 \(a_e\)。将 \(s_e\) 放在 \(R_{e,a_e}\)；所选状态的两个 \(x\) 都放自己的 \(H\) 端，所有未选状态的两个 \(x\) 留在各自根。每个根负载恰为 1。每边每侧只有一个选中查询，故一个 \(H\) 至多收到一件 unit 查询。

收到查询的 \(H\) 把自己的 \(z\) 送到对应 \(A\)；其他 \(z\) 留在 \(H\)。于是每个 \(H\) 负载是 1 或 \(3/4\)。记 \(c_{v,b}\) 为 \(A_{v,b}\) 收到的 \(z\) 件数。全部选择同时满足

\[
\sum_b c_{v,b}=\deg(v)\le D.
\]

设 \(s=\lfloor D/2\rfloor\)。一个顶点至多有一个标签满足 \(c_{v,b}\ge s+1\)，因为 \(2(s+1)>D\)。称之为重标签。

对每个非重标签，把 \(w\) 留在 \(A\)，全部 \(D\) 件 \(f\) 留在 \(B\)。其负载分别是 \(1+c_{v,b}/D\le1+s/D\) 与 1。

若顶点有重标签，把其 \(w\) 送到 \(B\)，其全部 \(D\) 件 \(f\) 分别送到原资格 \(C_{v,r}\)。此标签的 \(A\) 负载 \(c_{v,b}/D\le1\)，\(B\) 负载 1。同顶点没有第二个重标签，故每台原 \(C\) 至多一件 unit；不同顶点的 \(C\) 本就互异。

这列出了每类全部原任务，包括未选状态和未选标签的执行端。同一份完整分配同时满足所有机器负载

\[
\boxed{C_{\max}\le1+\frac{\lfloor D/2\rfloor}{D}\le\frac32.}
\]

证明不要求 regularity、投影单射性、源满足性或求一致标签。因此即使源只承诺某个 hard-image 子类，这套 compiler 的全部实际像也在上述绝对上界内。

### 2.1 更精确的最优值恒等式

对边状态向量 \(a=(a_e)\)，仍以 \(c_{v,b}(a)\) 计每顶点的所选端点标签次数。令 \(c_{v,(2)}(a)\) 为这些次数中的第二大值，不足两个标签时补零；设

\[
\mu=\min_a\max_{v\in U\cup V} c_{v,(2)}(a).
\]

空顶点集单列 OPT=0。非空时，每个状态向量都有 \(0\le\max_v c_{v,(2)}\le\lfloor D/2\rfloor\)，而

\[
\boxed{\mathrm{OPT}=1+\mu/D.}
\]

**上界：** 给定任意 \(a\)，在每个顶点打开出现次数最大的一个标签（全零时任取标签），把它的 \(w\) 放 \(B\)、全部 \(f\) 放自己的 \(C_{v,r}\)；其余标签 \(w\) 留 \(A\)、\(f\) 留 \(B\)。根、查询和端口 guards 按第2节安排。所选标签的 \(A\) 至多1，\(B\) 与每台 \(C\) 至多1；其他 \(A\) 的负载不超过 \(1+c_{v,(2)}/D\)。这甚至给定状态后的更细上界，取最优状态得到所需存在性。

**任意调度下界：** 非空顶点集有 unit \(w\)，所以 OPT≥1；\(\mu=0\) 已闭合。设 \(\mu>0\)，反设一个完整实际调度的峰值 \(C<1+\mu/D\le3/2\)。每个 \(s_e\) 的实际根选择定义 \(a_e\)。由于 \(C<3/2\)，其两个半长查询必须外送；端口与 unit 查询共居的 guard 也必须到 \(A\)，因为 \(1+3/4>C\)。故每 \(A_{v,b}\) 至少收到 \(c_{v,b}(a)/D\) 的真实负载。

记 \(k=\lfloor D(C-1)\rfloor\)，则 \(0\le k<\mu\le\lfloor D/2\rfloor\)。由 \(\mu\) 的最小值定义，这个实际状态向量有某顶点的两个标签次数都至少 \(\mu\)，因而至少 \(k+1\)。这两个标签的 \(w\) 都不能留 \(A\)，否则各自负载至少 \(1+(k+1)/D>C\)；它们必须分别在自己的 \(B\)。每台这样的 \(B\) 除 unit \(w\) 外至多能留 \(k\) 件 \(f\)，故两个标签合计至少导出 \(2(D-k)>D\) 件 unit \(f\)。它们只能进入同顶点的 \(D\) 台原 \(C\)，而 \(C<2\) 使每台至多一件，矛盾。未选查询或额外 guards 的非规范移动只增加非负负载，不破坏这个下界。

该恒等式由独立重构者提出，root 与构造作者另行攻击。它不提供求最优边状态的算法；以下三半算法只任取状态，完全不调用 \(\mu\) 优化 oracle。恒等式将困难的 strict 可行性与狭窄的实际负载值域明确分开。

## 3. strict 可行性及任意低实际调度的反解

若源有满足全部边的 singleton 赋值 \(\lambda\)，每边选择 \(a_e=\lambda(u)\)。所选的左右查询真实输出到相应 \(H\)，其 guards 到 \(A_{v,\lambda(v)}\)，其余 guards 留端口。每顶点只把 \(w_{v,\lambda(v)}\) 送 \(B\)，该标签全部 \(f\) 到 \(C_{v,r}\)，其余标签 \(w\) 留 \(A\)、\(f\) 留 \(B\)。所有负载不超过 1，因为 \(\deg(v)/D\le1\)。孤立点也可全部 \(w\) 留 \(A\)。

反过来，给任意完整实际调度，其峰值 \(C<1+\delta\)。不用把它变换成规范形：

1. \(s_e\) 实际所在的 \(R_{e,a_e}\) 已有 unit 负载，若留下任一半长 \(x\)，负载至少 \(3/2\ge1+\delta>C\)。所以该状态左右两个查询实际都在其原 \(H\) 端。
2. 一个这样的 \(H\) 已有 unit 查询；若 \(z\) 留在该端，负载 \(1+3/4>1+\delta\)。因此相应 \(z\) 实际在 \(A_{v,b}\)。
3. \(A\) 有正的 \(\delta\) guard，故其 unit \(w\) 不可能留 \(A\)，只能在 \(B\)。
4. 有 unit \(w\) 的 \(B\) 不能留任一 \(\delta\) 的 \(f\)，所以该标签全部 \(D\) 件 \(f\) 实际进入自己的 \(C_{v,r}\)。由于 \(C<1+\delta\le3/2<2\)，每台 \(C\) 至多一件 unit，同顶点最多一个标签发生这种激活。
5. 每边两端的实际查询标签都被激活，故同顶点全部读出标签一致，并由所选根索引满足 \(\pi_e(a_e)\)。孤立点任取标签。

这给完整的满足赋值。因为 \(1<1+\delta\)，便有 \(\mathrm{OPT}\le1\) 当且仅当源满足。只要顶点集非空，每个 \(w\) 在其两端都长 1，故 OPT 不小于 1，YES 时恰为 1；完全空图则如前为零。这里使用严格 \(C<1+\delta\)，不把等号错误排除。

## 4. 源列表极难覆盖、实际 OPT 却趋于一的族

取奇数 \(q\ge3\)，两个源顶点 \(u,v\)，字母表均为 \(\mathbb Z_q\)。有 \(q\) 条平行边 \(t\in\mathbb Z_q\)，投影

\[
\pi_t(a)=a+t\pmod q.
\]

任何 singleton 标签对只满足一条边，因此不能满足全部边。若两侧列表为 \(L_u,L_v\)，覆盖的边标号包含于差集 \(L_v-L_u\)，于是

\[
|E_{\rm covered}|\le|L_u||L_v|\le (|L_u|+|L_v|)^2/4.
\]

特别，总 cost \(\le2g\) 时覆盖率 \(\le g^2/q\)。对任意先固定 \(g\ge1,\rho\in(0,1)\)，选奇 \(q>g^2/\rho\) 就是 cost \(\le gN\) 仍覆盖严格少于 \(\rho\) 边的强列表 NO，\(N=2\)。这是一个显式反例源族，未声称两顶点族本身 NP-hard 或等于某个指定 PCP 的 hard image。

取 \(D=q\)，每条边选择 \(a_t=t\)，其右标签为 \(2t\)。奇数性保证两边读出的标签各恰遍历一次。按第2节先排所有根、查询和端口 guards，再将**所有** \(w\) 留 \(A\)、**所有** \(f\) 留 \(B\)，不启用任何 \(C\)。每台 \(A\) 恰有一件 \(w\) 和一件 \(z\)，负载 \(1+1/q\)；其余机器负载不超过 1。第3节任意低调度的反解排除了更小峰值，故

\[
\boxed{\mathrm{OPT}(I_q)=1+1/q.}
\]

全部原对象的规模为

\[
m=3q^2+6q,\quad n=6q^2+3q,\quad\#\text{finite entries}=13q^2+4q.
\]

因此任意固定 \(\varepsilon\in(0,1)\) 及 \(g,\rho\)，可同时选奇 \(q>g^2/\rho\) 且 \(1+1/q<2-\varepsilon\)：强列表 NO 并没有给这套矩阵带来所需的真实近二 NO。

## 5. 失效步骤、可回收部分与重试条件

尝试把“任一查询标签”沿 guard 链转成一次近单位 label fee。第一层确实把两个所选查询送出，且所选 \(z\) 也真实到共享 \(A\)，所以失败并非用状态索引伪造查询或漏算未选任务。问题是 \(w\) 留在 \(A\) 时真实负载只有 \(1+c/D\)：一条查询仅加 \(1/D\)，弱阈值不迫使单次查询打开标签。

第2节进一步给出了**全部源**的完整三半逃逸。提高端口 \(\beta\) 到接近 1 不改变这条逃逸，因为被查询的 guards 已全部离开端口。可回收 strict decoder、强列表 NO 计数和完整恢复算法；重试需要改变内部收费结构或与源共同证明另一种全局解码，不能只加强同一列表 soundness。

环共享背景边界限制的是另外一种二端相位读出，本结论不使用它；本矩阵已有多层交叉尺寸和跨边共享，但仅说明这套具体结构仍不足。不得据此宣布所有共享 medium jobs、非环代码或一般算法的边界。

## 6. 构造性、核验与阅读入口

给定展开呈现和边状态，第2节仅扫描原任务、累计整数计数并输出每件任务的有限原端。负载以精确有理数回算，总位长多项式；不按 \(1/\delta\) 的数值做未计入输出的循环。若从源生成矩阵，可选 \(D=\max(\{2\}\cup\{\deg(v):v\in U\cup V\})\)，展开和稠密普通矩阵均为源显式编码长度的多项式。若另给巨大二进制 \(D\)，只承诺按已经展开的原矩阵位长构造，不把输出 \(D\) 件任务称为 \(\operatorname{poly}(\log D)\)。
