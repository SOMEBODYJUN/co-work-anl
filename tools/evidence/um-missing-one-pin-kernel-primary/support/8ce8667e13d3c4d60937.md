# 永久消元的零缺陷死锁与完整配置路径的支撑丢失

本文只攻击如下局部规则：从给定分数点出发，保持活任务列和及尚未删除的机器负载等式；当机器的加权 excess 不超过 `(1-epsilon)T` 时永久删除其负载等式；沿任意合法零空间方向走到某变量的 `0/1` 边界；整数任务随即永久固定。下述反例给出一条明确、确定性的坏枢轴历史。它不证明所有枢轴规则都会失败，也不证明一般 `UM-TARGET-v1` 的负面结论。

## 1. UM-WEIGHTED-EXCESS-ZERO-DEFECT-TRAP-v1：精确陈述与输入

取任意固定有理数 `epsilon in (0,1)`，整数

`m >= 3` 且 `m > 1/epsilon`，

并置

\[
T=1,\qquad q=1-\frac1m,\qquad
\beta=\frac{1-\varepsilon}{4}.
\]

有 `2m` 台机器 `H_1,...,H_m,Z_1,...,Z_m`，以及恰好 `2m+1` 个任务：一个锚任务 `B`，每组两个任务 `A_i,F_i`。全部有限处理时间为

| 任务 | 有限端及处理时间 |
| --- | --- |
| `B` | 每台 `H_i` 上时间 `1` |
| `A_i` | `H_i` 上时间 `q`，`Z_i` 上时间 `beta` |
| `F_i` | `H_i` 上时间 `1/m`，`Z_i` 上时间 `beta` |

其余端不可用。因此全部有限端都已被 `T=1` 剪枝保留，且输入为非负二进制有理数。

存在一个显式的真实最优调度凸包点 `x^(0)`，以及恰好 `m` 次合法的最大零空间枢轴，使终态满足：

1. 每台仍被保护的 `H_i` 的含已固定任务的分数负载始终等于 `1`；
2. 所有 `Z_i` 在初态即合法删除其负载等式；所有 `H_i` 全程不能按 excess 规则删除；
3. 终态仅有 `B` 未固定，且 `x_(H_i,B)=1/m`，每台 `H_i` 已永久固定负载 `q`；
4. 活变量的等式矩阵列满秩，没有非零零空间方向；
5. 保持已固定任务的任何实际补全，其 makespan 都恰为
   \[
   2-\frac1m>2-\varepsilon=(2-\varepsilon)\mathrm{OPT}.
   \]

这里“补全”必须保持已经固定的任务位置；若允许撤销固定或重新开放删去的任务端，则不属于被攻击的合同。

## 真实 `OPT=1` 与初始凸包分解

对每个 `h in [m]`，构造完整调度 `S_h`：

- `B -> H_h`；
- `A_h,F_h -> Z_h`；
- 每个 `i != h` 的 `A_i,F_i` 都放 `H_i`。

此时每台 `H_i` 的负载恰为 `1`；`Z_h` 的负载为 `2beta=(1-epsilon)/2<1`，其余 `Z` 空闲。因 `B` 的每条有限端时间都为 `1`，有 `OPT>=1`；上述调度又给 `OPT<=1`，所以 `OPT=1`，且全部 `S_h` 均最优。

令 `x^(0)` 为这 `m` 个完整最优调度的均匀平均。其全部有限端坐标为

\[
x_{H_i,B}=\frac1m,\quad
x_{H_i,A_i}=x_{H_i,F_i}=q,\quad
x_{Z_i,A_i}=x_{Z_i,F_i}=\frac1m.
\]

每台 core 的分数负载为

\[
\frac1m+q^2+\frac q m=\frac1m+q=1,
\]

每台外机的分数负载为 `2beta/m`。因此初态不仅是剪枝 LST 或 CONFIG 可行点，而且明确属于真实最优调度凸包。

## excess、删除规则与固定约定

令活任务为尚未整数固定的任务；其活端仅含当前严格正的分数端。整数任务的唯一 `1` 端记入固定负载 `f_i` 后从活系统移除；值为 `0` 的端永久删除。定义

\[
E_i=\sum_{j\text{ 活且 }x_{ij}>0}p_{ij}(1-x_{ij}).
\]

若 `E_i <= (1-epsilon)T`，允许永久删除该机器的分数负载等式。其余保护行保持“固定负载加活分数负载”等于删除前的值；本例中所有保护行均为 `1`。

初态外机满足

\[
E_{Z_i}=2\beta q=\frac{(1-\varepsilon)q}{2}<1-\varepsilon,
\]

所以先删除所有 `Z_i` 合法。初态 core 满足

\[
E_{H_i}=q+\frac qm+\frac1{m^2}=1>1-\varepsilon.
\]

每组舍入后，其 core 只有锚任务仍活，故

\[
E_{H_i}=1-\frac1m=q>1-\varepsilon.
\]

未舍入组的 core 仍有 `E=1`。因此任意整数枢轴时刻的所有 `H_i` 都保持受保护；枢轴内部尚未有端消失时，该行 excess 也保持 `1`。

## 明确的最大零空间枢轴历史

按 `i=1,...,m` 顺序处理每组。处理组 `i` 时，保持所有锚变量及其他组变量不动，只取方向

\[
d_{H_i,A_i}=1,\quad d_{Z_i,A_i}=-1,\quad
d_{H_i,F_i}=-(m-1),\quad d_{Z_i,F_i}=m-1.
\]

两个任务列方向和均为零。core 方向负载为

\[
q\cdot1+\frac1m\bigl(-(m-1)\bigr)=0,
\]

所以全部保护行负载均保持；外机行已删除，不是零空间约束。

四个活变量到各自 `0/1` 边界的正向步长都恰为 `1/m`：

\[
\frac{1-q}{1}=\frac{1/m}{1}
=\frac q{m-1}=\frac{1-1/m}{m-1}=\frac1m.
\]

故最大步长正是 `theta=1/m`，走完后四个坐标成为

\[
(x_{H_i,A_i},x_{Z_i,A_i},x_{H_i,F_i},x_{Z_i,F_i})
=(1,0,0,1).
\]

于是永久固定 `A_i -> H_i`、`F_i -> Z_i`，删除它们的另一个端。该方向是局部规则允许的一个明确方向，而非声称任意基选择、任意符号或任意确定性规则都会选它。

## 每一步的精确计数、秩与终态 stall

在已完成 `t` 组后，置 `a=m-t`。每个未处理组仍有四个活变量，`B` 有 `m` 个活变量，所以

\[
N_t=m+4a,\qquad J_t=2a+1,\qquad P_t=m,
\]

其中 `N_t` 为活变量数，`J_t` 为活任务数，`P_t` 为保护机器行数。因此计数余量为

\[
N_t-J_t-P_t=2a-1.
\]

当 `a>=1` 时，任务等式与保护行等式全部线性独立，实际零空间维数恰为 `2a-1>=1`。证明：任何行线性依赖中，未处理组的两个外端列先迫该组两个任务行的系数为零；再由该组 home 列迫对应 core 行系数为零；由于锚任务有该 core 的端，锚任务行系数继而为零，最后全部 core 行系数都为零。其余任务行系数已由外端列迫为零。

当 `a=0` 时，`N=m,J=1,P=m`，计数余量为 `-1`；`m` 个 core 行在锚变量上就是单位矩阵，秩恰为 `m=N`，锚任务列和等式是这 `m` 行之和。因此确实没有非零零空间方向，而不是仅由计数猜测 stall。

终态 `f_(H_i)=q`、`x_(H_i,B)=1/m`，每个 core 仍有分数负载 `q+1/m=1`。若采用问题中的总亏缺量

\[
D=\sum_{\text{活端 }(i,j)}(T-p_{ij})(1-x_{ij}),
\]

则所有活端都是时间 `T=1` 的锚端，故 `D=0`，并且

\[
D=0<\varepsilon T(N-J)=\varepsilon(m-1).
\]

所以该 full-rank core 满足给定的“小亏缺”必要条件，却没有保持已固定任务的次二补全。任何锚分配都使某个 core 负载成为 `q+1=2-1/m`；其余 core 负载为 `q`、外机负载为 `beta`，因此每个补全的 makespan 都精确等于 `2-1/m`。

## 一个确实阻断本历史的逃生条件

在本例中 `m>=3`，所以 `q>1/2`。任一 `T=1` 真实配置在 `H_i` 上至多包含一个大于 `1/2` 的任务，特别给出有效不等式

\[
x_{H_i,B}+x_{H_i,A_i}\le1.
\]

初态在此式取等号；上述方向保持 `x_(H_i,B)=1/m` 并增大 `x_(H_i,A_i)`，所以任意严格正步长都会立即违反它。因此本例没有攻击“全过程保持这些 big-count/CONFIG 不等式”的增强规则，更没有证明这样的增强规则在一般输入上足够。它只说明：真实最优凸包的**初态身份**不会自动沿仅保持任务等式和保护行负载的零空间枢轴传播。

## 位复杂度、审计与范围

实例有 `2m` 台机器、`2m+1` 个任务、`5m` 条有限端；所有有理数字位长为 `O(log m + bitlength(epsilon))`。显式稠密矩阵、`m` 个真实最优见证、每个最大步长及整个 `m` 步历史均可在总位多项式时间构造。`m` 是显式规模，不是二进制隐式展开；本结论没有 NP 困难性或近似不可能性含义。

伴随 Fraction 审计独立构造全部 `S_h` 和平均 `x`，逐步重算 excess、固定负载、活变量/任务/保护行计数、精确矩阵秩、最大步长，以及终态全部 `m` 个锚补全。有限审计只核实现和公式；一般命题由上述显式证明承担。

## 2. UM-CONFIG-PRESERVING-ACTIVATION-SUPPORT-LOSS-v1：保持完整CONFIG的一次提升

本节是另一项精确命题，不改写前面的紧凑反例。前例的具体方向被 big-count 立即截断；本节说明，**即便每个沿途分数点都属于完整 CONFIG(1)**，任意合法负载零空间枢轴也不自动保持原始 YES 实例的低负载支撑补全。它通过一个显式激活提升，把任意给定的 CONFIG 坏支撑嵌入真实最优凸包初态。该结论仍不是一般调度困难性，也不排除选择好枢轴的算法。

## 输入合同与精确结论

给定 `m>=2` 台 core 机器、`n>=1` 个原任务的显式有理实例，以及一个**显式有限有理 CONFIG(1) 证书**

\[
y^*_{i,C}\ge0,\quad \sum_Cy^*_{i,C}=1,\quad
x^*_{ij}=\sum_{C\ni j}y^*_{i,C},\quad \sum_i x^*_{ij}=1.
\]

每个正权配置 `C` 的处理时间和不超过 `1`。证书的全部配置、权重和成员列表都是本命题的输入；其编码长度计入总输入长度。这里不假定可以免费求解一般 CONFIG LP。

记

\[
E^+=\{(i,j):x^*_{ij}>0\},\quad
\ell_i=\sum_jp_{ij}x^*_{ij}\le1,\quad
S_i=\sum_{j:(i,j)\in E^+}p_{ij}.
\]

只保留 `E+` 作为原任务的 core 端，称所得原实例为 `P+`。正权配置不会包含 `E+` 外的端，因此原证书仍适用。允许 `ell_i=0`；零处理时间合法。

取固定有理 `epsilon in (0,1)`，并置 `beta=(1-epsilon)/4`。可在所给显式输入长度的位多项式时间构造一个普通 UM 实例 `P_lift`、一个显式真实最优凸包点 `x^(0)` 和一次最大零空间枢轴，使：

1. `OPT(P_lift)=1`；
2. 所有沿途点都保持全部任务等式、所有 core 的分数负载 `ell_i`，并具有显式完整 CONFIG(1) 证书；
3. 每个非 core 的活行在初态均按加权 excess 规则合法删除；
4. 该一次枢轴达到 `0/1` 边界后，原任务仅剩 `E+` 端，所有 filler 永久固定到各自私有外机；
5. 该状态的保持固定任务的最佳实际补全值精确为
   \[
   \max\{1,\mathrm{OPT}(P^+)\}.
   \]

特别地，若给定支撑满足 `OPT(P+) > 2-epsilon`，则该合法历史从一个真实 `OPT=1` YES 初态出发，在始终保持完整 CONFIG 的情况下失去所有 `(2-epsilon)` 支撑补全。它不声称枢轴后等式矩阵列满秩，也不需要这一点；之后继续删端或固定任务无法恢复已不存在的支撑补全。

## 新实例与显式真实最优分解

对每个原任务 `j` 加一台不同的私有外机 `R_j`，令该任务在此时间为 `beta`。对每个 core `i` 加一个 filler `f_i`，它只可在 core `i` 用时 `ell_i`，或在一台新的私有外机 `Q_i` 用时 `beta`。所有 `R_j,Q_i` 互不相同，也与全部 core 不同。最后加一台孤立机器 `W` 和一个仅可在 `W` 用时 `1` 的任务 `U`。

因此新实例有 `2m+n+1` 台机器、`n+m+1` 个任务以及 `|E+|+n+2m+1` 条有限端。除新增上述端外，不加其他端。

用以下有限分布定义完整实际调度：以概率 `1/m` 选择一个 active core `i`，再按其给定分布 `y^*_(i,C)` 选择一个配置 `C`。

- 把 `C` 中的原任务放到 active core `i`；其他全部原任务放到各自 `R_j`。
- 把 `f_i` 放到 `Q_i`；对每个 `h!=i`，把 `f_h` 留在 core `h`。
- 把 `U` 放到 `W`。

active core 的负载由配置可行性不超过 `1`；inactive core 只有自己的 filler，负载 `ell_h<=1`；每台私有外机只可能有一个时间 `beta<1` 的任务；`W` 的负载为 `1`。所以每个分布原子都是 makespan 恰为 `1` 的完整调度。孤立任务 `U` 又给出 `OPT>=1`，故这些都是实际最优调度。

这个分布最多有 `sum_i |supp(y_i^*)|` 个原子，原子权为 `y^*_(i,C)/m`，是可显式构造的有理凸组合。其边际为

\[
x^{(0)}_{ij}=\frac{x^*_{ij}}m,\quad
x^{(0)}_{R_j,j}=1-\frac1m,\quad
x^{(0)}_{i,f_i}=1-\frac1m,\quad
x^{(0)}_{Q_i,f_i}=\frac1m,\quad x^{(0)}_{W,U}=1.
\]

原任务私有端的公式使用了 `sum_i x^*_(ij)=1`。每个 core 的边际负载恰为 `ell_i`。

## 完整 CONFIG 路径与合法删除

令 `lambda` 从 `lambda_0=1/m` 增至 `1`，定义

\[
x_{ij}(\lambda)=\lambda x^*_{ij},\quad
x_{R_j,j}(\lambda)=1-\lambda,
\]
\[
x_{i,f_i}(\lambda)=1-\lambda,\quad
x_{Q_i,f_i}(\lambda)=\lambda,\quad x_{W,U}=1.
\]

任务列和始终为 `1`，每个 core 的处理负载恒为

\[
\lambda\ell_i+(1-\lambda)\ell_i=\ell_i.
\]

对每个 core，用权重 `lambda*y^*_(i,C)` 选择原配置 `C`，另用权重 `1-lambda` 选择 singleton `{f_i}`。这给出该行的完整 CONFIG(1) 证书，因为 `ell_i<=1`。对 `R_j`，singleton `{j}` 与空配置的权分别为 `1-lambda,lambda`；对 `Q_i`，singleton `{f_i}` 与空配置的权分别为 `lambda,1-lambda`；`W` 恒选 `{U}`。因此整个路径均有一份明确的 CONFIG(1) 证书，不只是 LST 可行。

在初态，每个私有外机只有一个活端，所以 `E<=beta<1-epsilon`，均可立即删除其负载等式。`U` 已整数固定，无活端。对每个 core，在开区间 `lambda in [1/m,1)` 内其正支撑不变；原端总处理时间为 `S_i`，filler 端时间为 `ell_i`，而分数行负载为 `ell_i`。故

\[
E_i=S_i+\ell_i-\ell_i=S_i,
\]

全程常数。若某 core 初态达到删除阈值，就可立即删除；其余全部保护 core 均被下述方向保持。方向实际上保持所有 core，所以无需假设所有 core 都保护，也无需任何关联图连通性。

## 一次最大枢轴与精确端点

取 `lambda` 的导数方向：原 core 端为 `x^*_(ij)`，原私有端为 `-1`，filler home 端为 `-1`，filler 私有端为 `+1`，孤立任务方向为 `0`。上式已证明它保持所有活任务等式与所有保护 core 负载。私有行已经删除，所以这确实是所规定等式系统的非零零空间方向。

初态除 `U` 外所有正端均严格分数：因为 `m>=2`、`0<x^*<=1`。沿该方向首次触碰 `0/1` 边界正是在 `lambda=1`；原私有端、filler home 端都变为 `0`，filler 私有端变为 `1`。若某原 core 端有 `x^*=1`，它也只在这个同一端点变为 `1`。因此最大步长精确为 `1-1/m`。

初始活变量数、活任务数、保护行数满足

\[
N=|E^+|+n+2m,\quad J=n+m,\quad P\le m,
\]
\[
N-J-P=|E^+|+m-P\ge|E^+|\ge n\ge1.
\]

这只给出计数余量和显式方向，不声称全部等式独立；证明不需要这一额外条件。

端点后，所有 filler 已永久固定在不同的 `Q_i`，负载各为 `beta`；`U` 固定在 `W`，负载 `1`。每个原任务仅剩 `E+` 中的 core 端，且其分数值恰为 `x*`。若原任务已在端点整数固定，则其在 `P+` 中本来就只有唯一端，因为 `x*` 的该列和为 `1`。所以端点的所有补全与 `P+` 的所有合法实际调度一一对应，外加独立的固定任务。最佳补全值精确为 `max{1,OPT(P+)}`。

## 应用范围与剩余逃生口

该提升适用于任意显式给定的 CONFIG 支撑反例；若已有一族 `OPT(P+)/T_CONFIG` 趋于 `2` 的显式证书，把其阈值缩放为 `1` 后即可对每个固定正 `epsilon` 得到上述坏历史。这是在**枢轴历史**中的嵌入结论，不是重复声称 CONFIG gap 已否定一般相对 `OPT` 算法。

证明没有免费 CONFIG oracle，没有隐式指数原子，也没有从任何低估阈值推断新实例真实最优值；新实例的 `OPT=1` 由完整调度原子与孤立 unit 下界直接证明。全体构造和路径的编码长度均为显式 `(P*,y*)` 输入长度的多项式。

这个族本身易解：初始显式最优分解的任一原子都是最优输出。因而它只迫使候选算法证明自己选择的分支、跨机器共同分布或端重开机制能保住好补全；它不排除这些机制。保留完整 CONFIG 的边际路径，仍不同于保持真实最优调度凸包的共同分解。

## 小型精确审计种子

伴随审计使用 `4` 台 core、`7` 个原任务的显式 CONFIG(1) 证书：两台 root 各有三枚局部任务，每枚在 root 时间 `1/4`、在该 root 的 terminal 时间 `3/4`；另有一枚任务在两 root 时间均为 `3/4`。每个 root 以各 `1/6` 权选择“共同任务加一枚局部任务”，以 `1/2` 权选择全部三枚局部任务；每个 terminal 以各 `1/3` 权选择一枚局部任务。

## 3. UM-CONFIG-PRESERVING-TWO-SIGN-SUPPORT-LOSS-v1：同一方向双端点均坏

本节的陈述已在 `activation_two_sign_statement_zh.md` 冻结后交独立重构；本节给出完整证明。它针对“方向任意选，随后试两个端点符号”这一更强的充分合同。它没有排除选择另一个方向、保持某个共同可行原子，或重新开放私有端的算法。

## 源域与精确结论

沿用上一节显式 `(P*,y*,x*)`、`E+`、`M=|E+|`、`ell_i`、`S_i`、`P+` 的定义。另要求给定 core 的一个二分 `M_0,M_1`，使每个原任务在 `E+` 中至多有两个端，且每个颜色中至多有一个端。`m>=2,n>=1`，时间非负有理，全部正权配置及成员显式列出。

固定有理 `epsilon in (0,1)`，仍取 `beta=(1-epsilon)/4`。对上一节的提升实例取两个完全互不相交的相同副本，分别称 `A,B`；每副本保留自己的孤立 unit 任务。新实例记为 `P_two`。它有 `4m+2n+2` 台机器、`2n+2m+2` 个任务。

存在一个显式多项式项的真实最优分布，其两副本边际都取上一节参数 `lambda=1/2`。在这个初态，方向

\[
\lambda_A=\frac12+\theta,\qquad
\lambda_B=\frac12-\theta
\]

的两个最大 `0/1` 步长都恰为 `|theta|=1/2`。整条线 `theta in [-1/2,1/2]` 保持完整 CONFIG(1) 与每个 core 的负载 `ell_i`，而两个端点的最佳支撑补全值都精确为

\[
\max\{1,\mathrm{OPT}(P^+)\}.
\]

特别地，如果 `OPT(P+)>2-epsilon`，那么该**同一合法方向**的两个最大符号端点都从真实 `OPT=1` 初态失去次二补全。结论仍不涉及任一端点的列满秩或小亏缺 stall。

## 半激活的真实最优分布

先处理一个副本。以各 `1/2` 概率选择颜色 `c=0,1`，同时激活这个颜色的全部 core。对每个 active core `i`，选择一个服从 `y_i*` 边际的配置 `C_i`；下面会给出显式多项式项的共同选择法。

把每个被选配置中的原任务放到其 active core；其他原任务放到自己的私有 `R_j`。active core 的 filler 放 `Q_i`，inactive core 的 filler 留 home。孤立 unit 任务留 `W`。

这个分配不会把同一个原任务选到两台 active core：每个任务在同一颜色中至多有一个可用端。因此各 `C_i` 两两任务不交，整个分配合法。active core 的配置负载至多 `1`，inactive core 的 singleton filler 负载 `ell_i<=1`，各私有行至多一个时间 `beta<1` 的任务，孤立 unit 行负载 `1`。每个分布原子都是完整的实际最优调度。

任一 core 原端的边际为 `(1/2)x*_(ij)`，filler home/private 各为 `1/2`。每个原任务放到 core 的总概率是 `(1/2)sum_i x*_(ij)=1/2`，故其私有端边际为 `1/2`。因此这是所需的半激活边际。

## 公共区间耦合与多项式原子数

对每个 core 给正权配置任意固定排序，形成 `[0,1]` 上的累积权重区间。固定颜色 `c` 后，取该颜色所有 core 的区间端点的并，再加入 `0,1` 并排序。每个相邻公共区间内，每台 active core 的所选配置都不变；令该联合配置组合的概率等于该公共区间长度。

这样每个 core 的配置边际严格等于输入 `y_i*`，却无需列出独立乘积分布。若 `k_i=|supp(y_i*)|`，颜色 `c` 最多有 `1+sum_(i in M_c)(k_i-1)` 个公共区间；空颜色也只有一个区间。两种颜色合计原子数至多

\[
2+\sum_i(k_i-1)\le2+\sum_i k_i.
\]

每个原子权再乘 `1/2`。全部端点和权均为显式有理加减、排序所得，位长及构造时间按输入配置证书长度多项式有界。

两个相同副本使用**同一个**上述原子，即在各副本复制同一完整调度，便得到两个半激活边际的共同真实最优分布。副本机器和任务互不相交，所以这种相关复制合法，原子数不增长。孤立 unit 下界给 `OPT(P_two)=1`。

## 两个最大方向、保护行与完整 CONFIG

每个副本使用上一节的参数化。副本 `A` 沿该参数正向，副本 `B` 沿其反向；方向显式为上一节导数 `d_lift` 与 `-d_lift` 的直和。

每个原任务等式、每个 filler 等式、所有 core 负载分别保持。所有活私有行在初态均有 `E=beta/2<1-epsilon`，可合法删除；孤立 unit 已整数固定。对开区间 `theta in (-1/2,1/2)`，每副本全部非 unit 正端严格分数，core 的 excess 恒为 `S_i`。所以全部未删除的保护行均由该方向保持，无需关联图连通性。

每个副本任意 `lambda in [0,1]` 的完整 CONFIG 证书正是上一节给出的“`lambda*y_i*` 原配置加 `1-lambda` singleton filler”，再加各私有行的 singleton/空配置。因此整条双副本线都保持完整 CONFIG。

正向到 `theta=1/2` 时，副本 `A` 的参数到 `1`，副本 `B` 的参数到 `0`；负向恰好交换。区间内部没有非 unit 变量达到 `0/1`，而两个端点均有私有端及 filler 端达到边界，所以这两个步长确为各符号的**最大**步长。

## 开区间的精确秩和零空间维数

令 `p0=|{i:S_i>1-epsilon}|`。删除初态所有达到阈值的行后，开区间中始终有

\[
N=2(M+n+2m),\quad J=2(n+m),\quad P=2p_0\le2m.
\]

这些任务行及保护 core 行全部线性独立。任意行依赖中，每个任务的私有端列只出现在其任务等式中，因为私有机器行已经删除；所以全部活任务行的系数为零。对每个保护 core，`S_i>1-epsilon>0` 且 `x*>0`，故 `ell_i>0`。该 core 的 filler home 列随后迫该 core 行的系数为零。

于是等式秩精确为 `J+P`，实际零空间维数为

\[
N-J-P=2M+2m-P\ge2M.
\]

这既是精确计数也是实际秩结论，只用于开区间。它不声称端点没有别的方向；端点已经失去所需支撑补全，与后续矩阵秩无关。

## 两端点的精确补全与应用边界

参数 `lambda=0` 的副本已经整数：全部原任务放各自私有外机、全部 filler 留 home、孤立 unit 固定，实际 makespan 为 `1`。参数 `lambda=1` 的副本与上一节端点相同：所有原任务私有端永久删除，fillers 固定各自外机，剩余原任务恰为 `P+`。其最佳补全为 `max{1,OPT(P+)}`。两个符号只是交换这两个副本，故各自最佳补全值相同。

若已有双树 CONFIG 近二族，其每个任务是二分机器图的一条边：分别沿每棵树交替着色，再令连接两根的任务跨颜色即可；平行末端边不改变二分性。缩放其显式 CONFIG 阈值为 `1` 后，源域与完整证书合同都满足本节要求。因此可令 `OPT(P+)>2-epsilon`，给出任意固定改善量的双端点坏历史。这里仍没有新 NP 困难性、没有否定方向选择，也没有免费 oracle。

正面剩余义务因此进一步收窄：仅证明“对当前任意零空间方向试两个符号”不足以保住补全；候选算法必须控制**方向本身**，维护更多跨机器共同结构，或者允许恢复被删端。初态显式最优原子的任意一个仍直接解出本构造，所以它不是难实例族。

## 4. UM-CONFIG-PRESERVING-CIRCUIT-TWO-SIGN-SUPPORT-LOSS-v1：单环 circuit 的双坏端点

本节给出一个独立于第三节直和方向的新构造。对每个奇整数 `D>=3`，令 `L=D+2`、
`N=DL`。下文显式普通 UM 实例的真实 `OPT=1`，初态有恰 `N` 项等权真实最优调度分解。
存在一个真正支撑极小的 circuit 方向，其物理支撑是单个长度 `4N` 的简单交替环；同一方向的
两个最大箱端点之间整条线保持完整 CONFIG(1) 与全部机器负载等式，而两个端点的完整正支撑
限制实例最优值都精确为 `2-1/D`。

因此对任意固定有理 `epsilon in (0,1)`，选奇数 `D>1/epsilon` 即得真实最优凸包初态和
同一 circuit 的两个坏符号端点。全过程没有任务变为整数；损失来自端点永久删除零端。
全部行始终有 `E_i>1-epsilon`，均应受保护。以下给出全部任务、有限端、基准原子分段表、
旋转分解和两端点的实际上下界；不使用 CONFIG oracle。

本结论只否定“把任意指定方向限制成 circuit，再试两个最大符号端点就必保好补全”的充分
合同。它不声称所有 circuit 都坏，不排除另选方向、保留真实共同原子或恢复删除端，也不
提供新的 NP 困难性；`UM-TARGET-v1` 保持 OPEN。

### 4.1 实例与初始点

取奇整数 \(D\ge3\)，令 \(L=D+2\)、\(N=DL\)。因为 \(\gcd(D,L)=1\)，映射
\(t\mapsto(a(t),j(t))=(t\bmod L,t\bmod D)\) 是 \(\mathbb Z/N\mathbb Z\) 到
\(\mathbb Z/L\mathbb Z\times\mathbb Z/D\mathbb Z\) 的双射。后继 \(t+1\) 同时把两个坐标加1。

有两个复制标签 \(c=0,1\)，各有一个 selector \(U_c\) 和 \(L\) 台 rail \(K_{c,a}\)。
Selector 只可在本复制的全部 rails 上执行，耗时1。每个 rail 有 \(D\) 个 port 任务
\(F_{c,a,j}\)，它在该 rail 用时 \(1/D\)，在自己的外机 \(G_{c,t}\) 用时1。
再加任务 \(H_t\)，可在 \(G_{0,t},G_{1,t},Q_{a(t)}\) 用时1；任务 \(E_t\)，可在
\(G_{1,t},G_{0,t+1},Z_t\) 用时1。所有这些机器互异，其他端不可用。

置 \(\rho=(L-1)/L\)、\(\gamma=(L-1)/(2L)\)。初态在 selector 的每条 rail 端取 \(1/L\)；
port 的 home/outer 端取 \(\rho,1/L\)；每个 \(H_t,E_t\) 的两个 \(G\) 端各取 \(\gamma\)，
其停车端取 \(1/L\)。下面直接构造它的真实最优分解，不从 CONFIG 反推真实可行性。

### 4.2 一份完全实际、makespan 1 的基准原子

唯一地写 \(t=sL+r\)，其中 \(0\le s<D\)、\(0\le r<L=D+2\)。注意此时 \(a(t)=r\)。

基准原子选择复制0的 rail \(a=D\)，复制1的 rail \(a=D+1\)：把各 selector 放所选 rail，
把该 rail 全部 \(D\) 个 ports 外送其 \(G\)，其他 ports 全留 home。故选中 rail 负载1，
未选 rail 的 \(D\) 个小任务总负载也是1。被这些外送 ports 占用的 \(G\) 恰是每个 block 中
offset \(r=D\) 的 \(G_0\)，以及 offset \(r=D+1\) 的 \(G_1\)。

剩余任务按下表安排：

| 每个 block \(s\) 的 offset \(r\) | \(H_t\) 的实际位置 | \(E_t\) 的实际位置 |
| --- | --- | --- |
| \(0\le r<s\) | \(G_{1,t}\) | \(G_{0,t+1}\) |
| \(r=s\) | \(Q_s\) | \(G_{1,t}\) |
| \(s<r<D\) | \(G_{0,t}\) | \(G_{1,t}\) |
| \(r=D\) | \(G_{1,t}\) | \(Z_t\) |
| \(r=D+1\) | \(G_{0,t}\) | \(G_{0,t+1}\) |

表的空区间直接略过。每个 \(Q_s\) 只收到一个 \(H\)，其余 \(Q\) 空；每个 \(Z_t\) 至多收到
自己的一个 \(E_t\)。检查 \(G_{1,t}\)：当 \(r<s\) 或 \(r=D\) 由 \(H_t\) 占用，
当 \(s\le r<D\) 由 \(E_t\) 占用，\(r=D+1\) 由复制1的 port 占用，恰一个任务。

检查 \(G_{0,t}\)：当 \(r\le s\) 时，来自前一个 \(E_{t-1}\)；对 \(r=0\)，前一个 block 的
末尾 \(E\) 也正好按最后一行送入。若 \(s<r<D\) 或 \(r=D+1\)，由 \(H_t\) 占用；
\(r=D\) 则由复制0的 port 占用。仍恰一个任务。

所以全部 \(G\) 负载恰为1，其他每机至多1。该原子是完整实际 makespan 1 调度。
Selector 每条有限端时间为1，又直接证明该实例真实 \(\operatorname{OPT}=1\)。

### 4.3 同时循环旋转与精确边际

对 \(q\in\mathbb Z/N\mathbb Z\)，同时执行旋转：

* \(t\mapsto t+q\)，即 \((a,j)\mapsto(a+q\bmod L,j+q\bmod D)\)；
* port 任务、\(G\)、\(H\)、\(E\)、\(Z\) 按对应下标旋转；
* rails \(K_{c,a}\) 与 \(Q_a\) 的标签变为 \(a+q\bmod L\)；两个 selector 的任务身份不变。

这是实例的自同构。把基准原子旋转得 \(\sigma_q\)，每个仍是实际最优调度。取恰 \(N\) 个
原子的均匀分布。

每个 label 在 \(N/L=D\) 次旋转中被 selector 选中，故 selector 各 rail 边际 \(1/L\)，
port 的 outer/home 边际为 \(1/L,\rho\)。

每个 block \(s\) 中，\(H\) 的停车数为1，位于复制0/1的数量分别是
\(D-s\)、\(s+1\)。因此全部基准原子中
\[
\#(H\to G_0)=\sum_{s=0}^{D-1}(D-s)=\frac{D(D+1)}2,
\quad
\#(H\to G_1)=\sum_{s=0}^{D-1}(s+1)=\frac{D(D+1)}2,
\]
停车总数为 \(D\)。旋转在 \(H_t\) 的 \(N\) 个下标上传递，且保持 \(G_0/G_1/Q\) 类型；
所以每个 \(H_t\) 的两个 \(G\) 边际均为
\(D(D+1)/(2N)=(L-1)/(2L)=\gamma\)，停车边际 \(D/N=1/L\)。

同一表中每个 block 的 \(E\) 送 \(G_{1,t}\) 的数量为 \(D-s\)，送 \(G_{0,t+1}\) 的数量为
\(s+1\)，停车数也为1。因此每个 \(E_t\) 的两个 \(G\) 边际也均为 \(\gamma\)，停车 \(1/L\)。
这正是给定初始点 \(x\)，并且所有有限端严格正且分数。

### 4.4 真 circuit、最大箱段与全程完整 CONFIG

令 \(d\) 在 \(H_t\) 的 \(G_{0,t},G_{1,t}\) 端为 \(+1,-1\)，在 \(E_t\) 的
\(G_{1,t},G_{0,t+1}\) 端为 \(+1,-1\)，其他端为0。每个受影响任务方向和0，每个 \(G\) 的
两个方向负载相消，其他机器行方向全0，故 \(d\in\ker A\)。

物理支持图为
\(G_{0,t}-H_t-G_{1,t}-E_t-G_{0,t+1}\) 循环串接，最后下标 mod \(N\) 回到起点。
全部 \(4N\) 个机器/任务顶点互异，度恰为2，得到**一个**长度 \(4N\) 的简单交替环。
任一支撑于这些列的核向量，由一个非零坐标经任务行与机器行沿环传播，必须在全环非零，
且只剩一个自由倍数。因此 \(\operatorname{rank} A_C=4N-1\)，\(d\) 支撑极小，非直和。

沿 \(\theta\)，正方向 \(G\) 端为 \(\gamma+\theta\)，负方向端为 \(\gamma-\theta\)。
因 \(2\gamma=\rho<1\)，最大箱段恰为 \([-\gamma,\gamma]\)。端点各删去一个符号的
\(2N\) 条 \(G\) 端，另一符号变为 \(\rho\)；全部停车端 \(1/L\) 不动，所以所有任务仍分数。

完整 CONFIG(1) 证书逐行显式给出：

* 每 rail 以 \(1/L\) 选 singleton selector，以 \(\rho\) 选全部 \(D\) 个 home ports。
  两个配置的负载都恰为1。
* 每 \(G\) 的任务全为单位任务。其 port 边际 \(1/L\)，其两个 blocker 边际为
  \(\gamma+\theta,\gamma-\theta\)，权和 \(1/L+2\gamma=1\)。按这三个权选对应 singleton。
* 每 \(Q_a\) 有 \(D\) 个单位 \(H\)，各以权 \(1/L\) 选其 singleton，再以权 \(1-D/L\) 选空集。
* 每 \(Z_t\) 以权 \(1/L\) 选 \(\{E_t\}\)，以权 \(1-1/L\) 选空集。

全部配置可行且逐任务覆盖等于沿途边际，给出整条连续箱段的证书，而非有限采样推断。

### 4.5 两端点完整正支撑的整数最优值

正端点只保留 \(H_t\) 的 \(G_{0,t},Q_{a(t)}\) 两端，以及 \(E_t\) 的 \(G_{1,t},Z_t\)
两端。负端点只保留 \(H_t\) 的 \(G_{1,t},Q_{a(t)}\) 两端，以及 \(E_t\) 的
\(G_{0,t+1},Z_t\) 两端。所有 selector/port 支撑不变。

正端点看复制0，负端点看复制1；把该复制称为 hard 复制。其 selector 必须放某 rail
\(K_{c,a}\)。设该 rail 的 \(D\) 个 ports 中外送了 \(s\) 个，rail 负载为
\[
1+\frac{D-s}{D}=2-\frac sD.
\]
若某全调度的 makespan 严格小于 \(2-1/D<2\)，就必须 \(s\ge2\)。每个外送 port 占自己
的 \(G_{c,t}\) 一个单位任务位置；该端点的 \(H_t\) 也只有该 \(G_{c,t}\) 或 \(Q_a\) 可去。
低于2时它不能与 port 共机，所以这 \(s\ge2\) 个单位 \(H\) 必须全部进入同一 \(Q_a\)，
使该机负载至少2，矛盾。因此两个完整端点实例都满足 \(\mathrm{OPT}\ge2-1/D\)。

上界也是实际完整分配。在 hard 复制任选一个 label，只外送该 rail 的一个 port，把其
对应 \(H\) 放 \(Q_a\)，其余 \(H\) 全留各自唯一 \(G\)，其余 ports 全留 home；hard
选中 rail 负载恰 \(2-1/D\)。在 easy 复制任选一个 label，将该 rail 的全部 ports 外送，
把与它们冲突的 \(E\) 放各自私有 \(Z\)，其他 \(E\) 放唯一剩余 \(G\)，其他 ports 留 home。
easy 复制每机至多1；全部 \(Q,Z\) 至多1。两端都达到上界，故最优值精确相等。

### 4.6 excess 与全部行保护

只计当前正活端，开段与两个端点逐机 excess 为：

| 机器类 | 分数负载 | excess |
| --- | --- | --- |
| \(K_{c,a}\) | 1 | 1 |
| \(G_{c,t}\)，开区间 | 1 | 2 |
| \(G_{c,t}\)，端点 | 1 | 1 |
| \(Q_a\) | \(D/L\) | \(D-D/L\) |
| \(Z_t\) | \(1/L\) | \(1-1/L\) |

固定 \(0<\varepsilon<1\)，取奇 \(D>1/\varepsilon\)。这时 \(1/L<1/D<\varepsilon\)，
所以表中全部 excess 都严格大于 \(1-\varepsilon\)。没有一行可合法删去，方向又保持所有行。
两端点的整数支撑最优值 \(2-1/D>2-\varepsilon\)，故这是真 circuit 版本的双坏指定方向。

### 4.7 编码、证据和范围

实例有 \(3N+3L\) 台机器、\(4N+2\) 个任务、\(10N+2L\) 条有限端；处理时间仅为1和1/D。
原子表有 \(N\) 个原子，每个完整列出 \(4N+2\) 个任务实际位置，需
\(O(N^2\log(N+1))\) 位；权重均为 \(1/N\)，初始边际与两个端点证书权重需 \(O(\log D)\) 位。
任意有理路径参数 \(\theta\) 的证书构造与位长另计其实际输入编码长度；对无有限编码的实参数，
仅陈述上述显式公式给出的配置可行性，不把它当作二进制算法输入。
所有生成、排序、旋转、负载计算都在显式实例规模的多项式位时间内完成；无 CONFIG oracle，
无隐式指数分布。D 是本显式族的参数，不把 \(\operatorname{poly}(D)\) 误称为
\(\operatorname{poly}(\log D)\) 输出时间。

有限精确审计另行检查 D=3,5,7 的全部初态原子与任务、旋转边际、cycle 支持/秩、最大步长、
若干沿途证书、两端实际上界及所选 label 的全部 export 子集和 unit parking matching。
全实参数的结论由上文证明承担，不声称已枚举所有完整调度。

原始实例容易解：任一显式原子都是最优解。该结果仍不提供新的困难性，不排除具体选择另一个
circuit、试初始真实原子、保存跨机器共同分解或恢复删除端。它只关闭“把任意方向限制为
支撑极小 circuit 后，两最大符号端点必有一个保好补全”这一充分合同。
