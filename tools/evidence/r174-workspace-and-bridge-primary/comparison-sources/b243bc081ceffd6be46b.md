# 跨枝福利中继恒等式（含旧玩家返还、未闭合）

日期：2026-10-24。对象是任意有限共同目录、任意人数、完整历史依赖的纯 SPE。本文记录一个可在所有节点使用的精确关系；它不是 Q-CAG-HALF 的证明，也不是反例。

**2026-10-24 勘误。** 初稿在非根节点漏掉了已经行动玩家的最终利润，将仅在根自动成立的 R1 错称通用节点式。下文补入旧玩家项 P，保留根特例；原错误版本不再作为通用引理。两人三客户的完整 SPE 反证与独立重构见[勘误记录](../../R-cef41b80a6e048b5a395b738d3b0b6e7/harmonic/relay_erratum.md)。已有正确来源为[全深度账本 §1](../../R-2e5a6ea95aff4f4c89f75237a74ba472/relay_credit/full_depth_ledger_and_harmonic_obstruction.md)；此次是纠正适用范围，不认领新的支付机制。

## 节点与强制分支

固定任意历史 (h)（长度 (i-1)），令 (A^*=\sigma_i(h)) 为原策略行动。对每个合法主题 (T)，令 (z(T)) 是在 (h) 后强制当前人选 (T)，随后沿同一份完整策略 (\sigma) 的终局。写

\[
V(T)=\sum_{\ell>i}u_\ell(z(T)),\qquad
P(T)=\sum_{j<i}u_j(z(T)),\qquad
W(z(T))=P(T)+u_i(z(T))+V(T).
\]

这里 (V(T)) 使用强制主题改变后的真实后继，不能替换为原路径后缀。过去行动虽固定，过去玩家的最终利润 P(T) 仍可随未来负载改变。

## 精确中继关系

SPE 的一步偏离最优性给出，对任意 (T)：

\[
u_i(z(A^*))\ge u_i(z(T)).
\]

令 Γ(T)=u_i(z(A^*))−u_i(z(T))≥0。相减并使用完整利润守恒，得到

\[
\boxed{W(z(T))-W(z(A^*))
=V(T)-V(A^*)+P(T)-P(A^*)-\Gamma(T)
\le V(T)-V(A^*)+P(T)-P(A^*).}
\tag{R1-v2}
\]

因此，强制分支相对原分支可能产生的福利增量，由后继利润变化及旧玩家份额变化共同支付。根节点 P=0，才自动还原初稿的 ΔW≤ΔV；一般节点若另有 ΔP≤0，也可推出该式。这个符号不能无条件假定。式子不冻结后继、不要求同负载历史采用相同平局，也不使用静态 PNE。

更精确地，对固定的这一项比较，旧 ΔW≤ΔV 成立当且仅当 ΔP≤Γ。如果改研究剩余玩家总利润 R_h(T)=W(z(T))−P(T)，则 ΔR_h=ΔV−Γ≤ΔV 确实普遍成立；但 R_h 是含固定背景时的剩余利润，不是覆盖福利。此次修复已由另一研究员独立重构并核对范围、边界与链接，见[内部审查](../../R-cef41b80a6e048b5a395b738d3b0b6e7/exchange/relay_correction_review.md)；没有外审或新颖性认证。

令 (\Pi(z)=\sum_x H_{c_x(z)}) 为 Rosenthal 调和势，令 (\Pi_{-i}(z(T))) 表示从终局中删去当前玩家 (i) 的行动后、保留该分支真实后继的势。逐分支的精确势分解为

\[
u_i(z(T))=\Pi(z(T))-\Pi_{-i}(z(T)).
\]

故 SPE 不等式等价于

\[
\boxed{\Pi(z(T))-\Pi(z(A^*))
\le \Pi_{-i}(z(T))-\Pi_{-i}(z(A^*)).}
\tag{R2}
\]

R2 把同一缺口转移到删去当前玩家、仍保留旧玩家及真实后继的势差，说明静态势的单步局部最大性不足以直接控制完整树。R2 本身在一般节点仍成立；它不是没有旧玩家项的福利 R1 的无条件等价式。

## 未付义务

R1-v2/R2 还需要对不同强制主题的完整付款项作跨枝控制，才可能给出全局半覆盖。一般目录没有自动的后继闭包；(V(T)) 与 (V(A^*)) 位于互斥有序子树，逐枝把它们相加会重复计费，非根还需结算 P。需要新的共同支付、边平衡或后继主题包含关系，才能把正确关系接到 (2W\ge\operatorname{OPT}_m)。

这条身份与 `route5a/sequential_deviation_share_lemma.md` 的逐客户份额下界互补：L1--L4 控制单个偏离者的客户份额，R1-v2 记录分支福利增量中全部玩家的有符号利润变化；它没有提供跨枝共同容量。
