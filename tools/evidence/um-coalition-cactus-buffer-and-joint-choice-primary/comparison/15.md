# 2. 共同大边选择与条件块切面

`joint_matching_completion_and_block_cuts.md` 先固定目标 `T`、有理松弛量 `δ`，选择任务—机器的大边匹配 `H`，再要求剩余任务有小边分数解 `x` 满足

`Σ_i x_ij=1`，`Σ_{j∉J_H} p_ij x_ij ≤ (1+δ)T-h_i`。

这是明确的充分接口，不是已实现的选择算法。正文的 `UM-JOINT-SMALL-ROUND-v1` 在给定 `(H,x)` 时用有序单位槽匹配保持 `H`，每机负载至多 `(3/2+δ)T`；输入位长包括 H 和 x，槽数、交长、排序与增广匹配均按总二进制位长多项式。该条件舍入和其有限核对已经在 `joint_matching_completion_review.md` 中逐项重构；这里确认它没有把松弛容量的一半误换成原始 `T/2` 分界，也没有把 H 的选择藏进匹配步骤。

同一正文又给出 `UM-JOINT-CHOICE-NP-v1`：对固定有理 `δ∈[0,1/3)`，即使 `T=1`、有限时间只有 `{1/3,1}`、每个任务恰有一个小端，(Aδ) 见证存在性仍由 3DM 归约得到 NP 完全性；唯一小端使这个受限接口等价于容量 1 的整数调度。追加的 `UM-JOINT-HALF-CHOICE-NP-v1` 把窗口扩到固定 `δ∈[0,1/2)`、时间 `{1/2,1}`，并给出 `UM-JOINT-HALF-PROMISE-NO-v1` 的承诺搜索障碍。δ=1/3 或 δ=1/2 的边界反例只说明对应归约不再保真，不能被写成边界处已有算法；3DM 的外部 NP 完全性仍是导入 Paper Fact。

`UM-ESCAPE-BLOCK-CUT-v1` 是另一类条件结论。对明确的长链/末簇逃逸族，`r_B=k-floor(k(B-1))` 和末簇不等式 `Z_g≥(r_B-1)Y_v` 给出随 B 正确重算的多机器块切面；在 `B<θ_k=2-1/k` 时所有这些切面联合不可行，`B=θ_k` 时系数归零并由真实最优调度给出可行 Dirac 配置。这个证明对任意配置分布取边际并逐层求和，不只是切掉一份已知证书；但它只识别该专用逃逸族，没有一般分离 oracle、统一 gap 或近二算法。

因此，本源最稳定的处置是“给定共同见证的完整条件舍入 + 选择见证的限域复杂度 + 专用块强化”。它没有关闭主目标。

# 3. 逐机跨度二的联合槽舍入

`joint_slot_prefix_rounding.md` 定义 `UM-ROW-SPREAD-TWO-ROUND-v1`：删除零成本任务后，若每个非空机器行有正有理 `γ_i`，所有有限处理时间均落在 `[γ_i,2γ_i]`，则确定性位多项式算法直接对全部任务做一次有序槽匹配，输出 `C_max≤(3/2)OPT`。不同机器的 `γ_i` 可以相差任意倍数；没有全局粗格点或先选 H 的要求。

证明在目标 `T` 上加入三类必要的行约束：分数负载 `≤T`，严格大于 `T/2` 的质量 `≤1`，严格大于 `T/3` 的质量 `≤2`；当 `T<4γ_i` 时再加总质量 `≤floor(T/γ_i)`。前缀质量整数化后，对任意全局槽覆盖匹配都保留相同的前缀任务数。令 `t=T/γ_i`，四段边界分别给出最多 1、2、3 件或普通 ST 加性界；`3≤t<4` 时利用最大值 `≤2T/3`、第二项 `≤T/2`、第三项 `≤T/3`，和恰为 `3T/2`；`t≥4` 时最大端不超过 `T/2`。严格前缀确保 `T/2,T/3` 等号任务落在正确一侧。

目标搜索用所有剩余正有限处理时间的有理 gcd 建立格点，以上界 `U=Σ_j min_i p_ij` 二分必要 LP 的最小可行格点；删除零任务、空行、T=0、大分母和 `γ_i` 极小均有明确位复杂度处置。已有 `joint_slot_prefix_review.md` 已实际重构并攻击了这些步骤；本页确认其状态是受限跨度类的完整证明，普通有理 LP 求解是标准工具导入，代码只做局部/半单位审计。

原文追加的 `UM-TWO-SMALL-INCIDENCE-SHARP-APPROXIMATION-v2` 是另一个域，不能并入前一身份的量词：给共同上界 `b`，每行至多两枚 `0<p<b` 的不同 job 资格，允许任意 unit 资格、任意共享和每 job 多个 small/unit 端。正文分别处理 `OPT<b` 的二容量流精确判定、`b≤T<2b` 的显式 CONFIG 枚举与槽匹配、`OPT≥2b` 的普通 load LP，并给 `3/2` 实际调度和由 perfect-3DM 导出的任意 `ρ<3/2` 困难性。正文同时逐项说明 zero job、无 b 端、二进制大需求、单机/单任务边界，以及证明只适用于“两枚非unit资格”结构类。已有 slot 审查把这段标为 `published-framework synthesis`：数学段已读、未见 fatal objection；Page–Solis-Oba–Maack 等外部框架与新颖性均未认证，不能写成一般 UM 近二算法。

这两个正面接口与 joint-choice 障碍彼此相容：跨度二/双 small incidence 的算法直接联合舍入，不需要输出受 NP 难约束的 `(Aδ)` 共同见证；它们也没有把有限 half-unit 反例的 `3/2` 下界误写成一般 `2−ε` 不可能性。

# 4. 有序槽包络与 CONFIG 的精确身份

`slot_envelope_and_configuration_identity.md` 定义单行有序槽包络 `E_p(x)`：按 p 非增排序，将 x 区间装入单位槽，取各槽最大相邻处理时间之和。前缀分层给出

`E_p(x)=Σ_t(p_t-p_{t+1}) ceil(X_t)`，

并且 `E_p(x)-p·x=Σ_t(p_t-p_{t+1})(ceil(X_t)-X_t)≥0`。共同偏移 `y_t(u)=floor(X_t+u)-floor(X_{t-1}+u)` 给每个 `x` 至多 `d+1` 个 0/1 配置原子，所有前缀计数不超过 `ceil(X_t)`，从而 `conv S_p(B)=conv{1_C:p(C)≤B}`。已有 `slot_envelope_identity_review.md` 已独立重构这一双向证明、零值/空行/有理断点和多项式位复杂度；本页确认 legacy/main canonical 正文保持同一数学内容。

将每行包络与全局任务列守恒拼接，标准 ST 匹配给 `L_i≤E_{p_i}(x_i)`；取任意最优整数调度的 0/1 指示又有 `E_i=L_i`，因此

`min_{x∈X(P)} max_i E_{p_i}(x_i)=OPT(P)`。

这是一种精确重参数化，算法方向仍然等价于求解原调度。固定阈值 B 后逐行凸化，恰好得到等式覆盖版 CONFIG 的边际投影（补空配置并利用向下闭合可与“至少覆盖一”形式互换）；仓库已有两树 CONFIG gap 逼近 2，不能把这个身份写成新的小于二松弛。先凸化整个上图只得到 `p·x` 的线性下包络，和固定 B 的 CONFIG 身份必须区分。

# 5. 交叉关系、失败机制与接续

三源形成一条准确但未闭合的链：

* joint matching 源说明“先选共同大边/共同剩余容量，再补小边”的充分路线在选择步骤有 NP 难点，专用逃逸族可以用块切面表达；
* joint slot 源给出不需要该共同见证的受限跨度算法，并在双小端结构类给出 3/2 sharp 的证明/归约；
* slot envelope 源说明一般矩阵的完整槽状态是 OPT 的精确非凸表示，逐行凸化会回到 CONFIG 的已知二倍边界。

因此“给定证书可舍入”“受限行结构可舍入”“完整槽状态精确但难求”必须分开标注。有限审计、局部 3DM 回溯、配置 gap 和 external Paper Fact 都不承担一般 `UM-TARGET-v1` 的正负结论。三份正文也没有建立到当前六人 SPE 客户覆盖目标的归约；保留源对象和所有开放义务，后续若要接续应研究跨尺度共同容量机制、可计算的块分离与保相关舍入。

三源均处置为 `integrated`。本文件新增的独有去向是 source-ID/冻结版本 crosswalk 及三种接口的关系证据；数学证明与已有独立审查保持逐项对应，没有删去前沿、未证明扩展或边界反例。
