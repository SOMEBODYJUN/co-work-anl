# 逐前缀 extra-slot floor 接口：独立盲审

2026-10-24。本审查只收到十客户、十主题和指定三人叶的陈述，未读作者证明；从单位客户定义独立重算。结论：所给数值全部正确，且足以反驳“仅凭根 IC 与全部真实前缀的 extra-slot floors 推出根 extra-slot 安全值”这一一般接口。它不是完整 SPE，也不是一般 Q-CAG-HALF 的反例。

## 精确输入与目标接口

客户 e_0,…,e_9，主题

\[
A_i=\{e_{i-1},e_i,e_{i+1}\}\quad(i\bmod10).
\]

三名玩家，空背景。强制根选 A_i 后指定完整叶

\[
Z(A_i)=(A_i,A_{i-1},A_{i+2}).\tag{1}
\]

此处静态安全值采用

\[
v_s(b)=\max_{p\in\Delta(\mathcal S)}\min_{B\in\mathcal S^{s-1}}
\mathbb E_{T\sim p}\sum_{x\in T}\frac1{b_x+1+c_x(B)}.
\]

被检验的一般接口只保留：根在各指定完整叶间最优；根后第一个玩家的最终收益至少 v_3(1_{A_i})；末位收益至少 v_2(1_{A_i}+1_{A_{i-1}})。这些前缀安全值比统一保底 v_4(0) 强，但仍不足以推出根收益≥v_4(0)。

## 1. 叶收益逐客户重算

旋转对称，只算 i=0。根 A_0={9,0,1}，两个尾主题 A_9={8,9,0}、A_2={1,2,3}。根三个客户各负载2；第一个尾玩家有客户8独享及0、9均分；末位有客户1均分及2、3独享。因此

\[
(d_i,u_{i,2},u_{i,3})=(3/2,2,5/2)\quad\text{对每个 }i.\tag{2}
\]

全部根行动给同一个3/2，故选择任意一个根行动均满足根 IC。

## 2. v_4(0)=33/20 的解析双向证书

取均匀查询分布 p。每个客户属于恰好三个主题，所以对任意三个静态竞争主题的客户负载 c_x，查询均值为

\[
\frac3{10}\sum_{x=0}^9\frac1{1+c_x},\qquad \sum_xc_x=9.
\]

对整数 c≥0，有 1/(1+c)≥1−c/2。因此该均值至少

\[
\frac3{10}(10-9/2)=33/20.\tag{3}
\]

竞争元组 (A_0,A_3,A_6) 三主题两两不交，覆盖九名客户，故达到等号。再把此元组的十个旋转各以概率1/10取作静态竞争者分布；每个客户恰有一次未被覆盖、九次负载1。任意三客户查询主题的期望收益都恰为

\[
3\left(\frac1{10}+\frac9{20}\right)=33/20.\tag{4}
\]

(3) 是 primal 下界，(4) 是对全部查询成立的 dual 上界，严格证明 v_4(0)=33/20。故根收益低于该值3/20。

## 3. 每个逐前缀 floor 都确实成立

根 A_0 后，为 v_3(1_{A_0}) 取两竞争主题 A_3,A_6。三主题 A_0,A_3,A_6 两两不交，背景加竞争覆盖除 e_8 外的九客户，且每个负载1。任意查询为三个相邻客户，至多包含唯一未覆盖客户e_8，所以收益至多1+1/2+1/2=2。故

\[
v_3(1_{A_i})\le2=u_{i,2}.\tag{5}
\]

根 A_0 与第一尾 A_9 后，为 v_2(1_{A_0}+1_{A_9}) 取唯一竞争主题 A_4。十个客户的背景加竞争负载依次为

\[
(2,1,0,1,1,1,0,0,1,2).
\]

查询三邻接客户。零负载客户只有2、6、7，没有三个连续零负载；故查询收益至多1+1+1/2=5/2，A_6及A_7达等。因此

\[
v_2(1_{A_i}+1_{A_{i-1}})\le5/2=u_{i,3}.\tag{6}
\]

旋转给全部根分支。以上仅需上界，所以没有错误宣称两个背景安全值恰等于其给定上界。

## 4. 可以补全为全部历史都满足非根 floors 的完整策略

令根规定A_0；第二位在任意首主题A_i后规定A_{i-1}；末位在特殊前缀(A_i,A_{i-1})后规定A_{i+2}，其他前缀选任意真实最佳回复。

这是每个有序历史都有指定动作的完整纯策略。根全部偏离叶仍为(1)，故根 IC 成立。每个第二位节点由(5)满足对应floor。特殊末位节点由(6)满足floor；其他末位节点为真实最佳回复，其收益为 v_1(b)，且 v_1(b)≥v_2(b)，也满足floor。因此即使接口要求**全部合法非根有序历史**的前缀floor，而非只在某条实际路径上要求，结论仍失败。

该完整策略不是SPE：特殊前缀(A_0,A_9)后，末位规定A_2得5/2，合法改选A_4与两固定旧主题完全不交，得3；旋转同理。故不能把此接口反例称为extra-one首位定理、一般 half、或完整SPE的反例。

## 5. 独立精确审计

`audit_state_floor_blind.py` 不导入原solver或作者文件，使用Fraction逐客户重算全部十个旋转，检查两个静态上界及明确末位偏离；另遍历全部1000个有序三竞争元组核对均匀查询下界，并核对十旋转dual的每一查询上界。全部断言通过，结果保存在 `state_floor_blind_audit.json`。

承重结论限于上述一般接口：逐前缀extra-slot数值保底没有保留足够的真实后继行动比较，不能代替SPE理性。若继续最小反例路线，必须使用未被这些floors包含的真正后继IC。
