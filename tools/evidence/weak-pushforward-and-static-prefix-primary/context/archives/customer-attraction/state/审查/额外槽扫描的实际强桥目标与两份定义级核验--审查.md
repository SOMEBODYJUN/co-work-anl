# 额外槽扫描的实际强桥目标与两份定义级核验

## 完整终局与实际被测命题

固定[共同目录模型](../定义/共同目录完整历史模型--定义.md)的一份完整有序历史纯SPE及实际路径。Z_i(A)为实际前缀、强制位置i选A后沿同σ完成的全部n槽。额外查询T不成为原玩家。定义
\[
D_i(p)=E_{A\sim p}u_i(Z_i(A)),\quad
G_i(p)=E_{A,T\text{ iid }p}\sum_{x\in T}\frac1{1+c_x(Z_i(A))}.
\]
全p强聚合桥ΣG_i≤ΣD_i与弱福利预算ΣG_i≤W不同；SPE只给ΣD_i≤W。

3194B `extra_slot_decorrelation_probe.py` 的docstring称攻击弱福利预算，但**实际LP与SLSQP攻击强桥**。程序对所有非空兴趣mask建立会员M_{a,j}，R_{i,a,j}=1/(1+load_{i,a,j})。零背景下每个实际位置保完整n槽；类型权重x≥0。

`aggregate_coeff`给
\[
\mathrm{coeff}_j=\sum_{i,a}p_aR_{i,a,j}\,(p^\top M)_j,
\quad\mathrm{coeff}\cdot x=\sum_iG_i(p).
\]
`diag`给Σ_{i,a}p_aM_{a,j}/max(load_{i,a,j},1)，乘x正是ΣD_i：有M_{a,j}=1时强制者已覆盖该客户，所以load≥1，clamp不改变有贡献项。类型不含A时分子为零。于是实际最小化`−(coeff−diag)`，而非`−(coeff−W)`。

后续H_{T,A}=Σ_{i,j}R_{i,A,j}M_{T,j}x_j、v_A=Σ_{i,j}M_{A,j}x_j/load_{i,A,j}，SLSQP最大化pᵀHp−pᵀv，即ΣG−ΣD。W·x=1只作归一化，输出
\[
\texttt{ratio}=1+\sum_iG_i(p)-\sum_iD_i(p)
=1+\frac{\sum G_i-\sum D_i}{W}\ \text{在未归一化原单位中}.\tag{R}
\]
它不是ΣG/W；不能用`ratio=1`称弱预算已经饱和，更不能因为75次无正点恢复已被精确反例否定的强桥。

## 策略锥、数值域和真实运行

完整读5375B依赖`background_pair_probe.py`。仅调用其representation和policy_cone，原依赖main未执行。后者对初始非负整数客户权重做完整有序逆向归纳，收益先乘LCM转整数，任意平局由同一Random状态选；每个有序历史保真强制子分支，G行取规定行动减偏离行动系数。去重G并转float后，x满足Gx≥0才仍属于该固定完整策略锥。

本扫描调用背景恒为全零，样本(n,k)来自(3,6)、(4,5)、(5,5)，共75次；seed12261023，密度从.2/.5/1选，初始正重数1至19。每个样本从uniform、k个纯点和两个随机分布开始交替，最多5次；LP失败会break，正差>10⁻⁷可提前停止，所以不能把75·(k+3)·5宣称实际求解次数。SLSQP是局部数值搜索，既不穷尽p也不穷尽策略。新x和p均float，未进行有理恢复/全部精确IC认证；原完整策略生成正确不自动使任意近似LP结果成为合法单位客户反例。

本批真实原入口一次13.116131986003893秒、exit0/stderr空，完成75；其[新17712B JSON](../../tools/evidence/extra-slot-programs-primary/runtime-tree/research/workspaces/customer-attraction/R-12bf6a96d24c48eca828620d6642e203/menu_minimax/extra_slot_decorrelation_probe.json)与[冻结主报告](../../tools/evidence/extra-slot-programs-primary/original/76b6133ddf55ba4b18f3/source)全字节相等。报告只有scope、completed和一个best，未保存75份完整样本/证书。best含n5/k5、ratio1、31类型权重、5项p、actual(4,3,3,1,1)、25强制终局计数及完整781行动；完整字段均解码，历史键域精确覆盖1+5+25+125+625。

best只有mask26={1,3,4}权重1，其余0，所有781指定行动均属于{1,3,4}。原p=(0.4999999999999998,1.249000902703301e−16,0.5,0,0)，浮点和0.9999999999999999，不能把原serialized数直接冒称精确有理概率证书。其精确极限p*=(1/2,0,1/2,0,0)只查询两个空主题，D=G=0、W=1，(R)=1而ΣG/W=0，直接展示两种ratio含义不同。

再以这个单单位客户和原指定表作解析说明：所有规定主题都覆盖唯一客户，故在任意历史，规定行动给正份额，不覆盖的主题给0，覆盖的偏离同份额；原表确可实现完整SPE。对任意**合法归一化**查询分布、ρ=p({1,3,4})，每个真实强制分支有4+1_{A覆盖}个覆盖者，直接给ΣD=ρ、ΣG=ρ−ρ²/6。这个解析解释不是把原float p修成未记录的程序输出，也没有新增数值探针。
