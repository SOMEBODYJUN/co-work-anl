# 新表示分支：一般直接收益保底及真实后继关系

当前对象为任意有限共同目录、任意人数、每份全有序历史纯 SPE 的 Q-CAG-HALF。一般目标仍 OPEN。本分支不扩张固定人数或固定目录结果，不将有限检查当证明。

## 当前材料

- `opt_threshold_cycle.md`：三窗口环精确核验，说明仅保留最小人数归约得到的全菜单根低于 OPT/(2m)、全部尾高于该阈值的排序，尚不足以推出矛盾。它没有完整 SPE，最后一人的真实最佳回应已明确失败。此为父方指定桥的范围核验，非新主线。
- `audit_opt_threshold_cycle.py`、`opt_threshold_cycle_audit.json`：独立 Fraction 回放，直接枚举最优三主题并集及末位动作。

下一步回到全部真实后继最优性，寻找实际支付一般福利缺口的关系。不得从抽象菜单负例推出 direct floor 或 Q-CAG-HALF 失败。

父方候选须区分：`DIRECT-v0` 只要求空背景完整 SPE；`PREFIX-DIRECT-v0` 还要求全部合法背景下的子 SPE，并以原总人数 m 和 OPT_m 定阈值。后者蕴含前者，但未证明等价。最小剩余人数归约只对更强 prefix 版本合法。两项均 OPEN。本分支尚未找到新增真实 IC 到一般福利支付的正面引理；当前保存的唯一新增检查是被父方指定的抽象菜单停界。
