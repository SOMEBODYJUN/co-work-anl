# 精确算法与非线性学习附录：来源和证据

本包只对正式认领的A11–A15五源申报语义完成。原件共104083字节，保存于`original/learning/appendices/`；`source-manifest.json`给源ID、原blob、两条冻结提交定位、长度和实际重算SHA。

`related/`保存全文旁读的现行精确算法综述、四地点主证明、近带主证明、EPTAS候选、立方费用问题和学习主章12；它们的冻结身份由`related-manifest.json`核对，不在本批额外done。`comparison-manifest.json`记录已实读现正文的路径与读取时SHA，相关程序与旧运行仍由既有证据包承载。

正式新增五页完整保留五源的全部数学推导，并加入来源差异、状态边界与独有教学算例的精确去向。尤其A12/A13不能因未登记的旧标签或缺少软件而丢弃其完整解析证明；也不能因它们写得详细而称通用规范软件已经交付。A15局部引理与EPTAS全局候选、A14无FPTAS合同、一般SC-PHI-E/A待审保证分别保留。

本批唯一新数学运行是`teaching_witness_audit.py`的窄精确核算：2份出行费用九布局规则与距离平方、立方九状态全谱、2份四地点16布局见证、10份近带输入。原stdout/stderr与完整精确输出在`replay/`，执行记录在`execution.json`。它不导入旧canonical求解器，没有重跑旧530、435/12、32/19、1322/2004等suite，也不冒充规范非线性算法或全称证明。

逐源阅读、比较、公式自查和模型边界见[semantic-review.md](semantic-review.md)。元数据、SHA和链接静态检查只核文件合同，不自动认证数学真值、外审或优先权。
