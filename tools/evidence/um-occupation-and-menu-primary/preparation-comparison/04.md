# 1. 对象分离与阅读范围

本批两个来源都围绕“宏任务占用 home 后，剩余任务能否共同补全”，但承担的数学身份不同。

第一源 `37cf25f76e20361e1511` 是 `UM-OCCUPATION-MODE-SIDE-CONSTRAINT-v1` 的核心面维数有限审计。它只枚举 transversal base polytope 的暴露面，验证“有 K 个线性侧约束时，非单值 home 数至多 2K”的核心不等式；不测试私有任务 DP、heavy-home 枚举、预算 LP 或实际调度器。

第二源 `bc9a4af396b1b13d8692` 是 `UM-OCCUPATION-INDUCED-EDGE-DEFICIT-v1` 的实际图矩阵与最大流复核。它在固定有理 α、δ 的显式图族上给出 OPT=1 的调度，并验证任意占位集合 I 的 tiny 通过量缺口正好等于诱导边数 `|E(G[I])|`。这是一个表示/障碍恒等式，不是 makespan hardness，因为构造实例本身总有直接最优调度。

为避免把有限字段当证明，我完整回读了 `fixed_sink_occupation_rounding.md`、`fixed_sink_occupation_review.md`、`residual_throughput_and_occupation_projection.md`、`residual_throughput_occupation_review.md` 以及两份审计程序。两个来源的共同边界是 Fraction/整数精确算术、无随机抽样、无通用 LP 软件或外部求解器结论；`UM-TARGET-v1` 仍开放。

# 2. 固定汇点 occupation 模式面：一般引理和算法合同

固定整数 K>=1，宏任务只在 homes H 上运行，且每条有限宏边时间严格大于 T/2。每个私有组 J_h 只在自身 home h 和固定 K 个共享 sink 的子集上运行。给定 T，私有组用多维 DP 生成有限模式：每个模式记录 occupation 标签（home 是否被宏占用）、一个完整的实际私有任务分配和每个 sink 的向上取整负载向量。向上取整尺度 `s=T/(4N)`，总舍入损失按所有私有任务总数 N 计算一次，而不是每个 home 重复收费。

宏任务可匹配的 home 集合构成 transversal matroid。模式多面体 `P(Q)` 由每 home 选一个模式、并要求 occupation 向量落在该 transversal base polytope 中。其扩展表达使用宏到 home 的二分匹配流变量；积分性只用来得到存在实际宏匹配，不把扩展 LP 的任意 basic point 当成投影顶点。

核心引理 `UM-OCCUPATION-MODE-SIDE-CONSTRAINT-v1`：在 P(Q) 上添加任意 K 个线性侧约束，若 y 是交切多面体的顶点，则正支持中具有至少两个正模式变量的 home 数 R≤2K。证明分三步：

1. 对 occupation 向量 x 的暴露最小面 G，混合（既有 occupied 又有 empty 支持）home 集 F 的每个非固定坐标都通过两个最优宏匹配的同一交替路径成对交换。交换两边都保持最优，故边权相等；这些交换方向生成图的森林方向，给出 `dim G≥|F|/2`。
2. y 的最小 face 纤维维数为
   `d_P=d_B+Σ_h(a_h−1)−|F|`，其中 a_h 是 home h 的正模式数，d_B=dim G。于是 `d_P≥R/2`。
3. 交切 K 个侧约束的顶点必须落在原最小 face 维数≤K；否则可在 face 的方向空间内同时消掉活跃侧约束，仍可正负移动而非顶点，矛盾。因此 R≤2K。

此证明仅适用于模式的宏信息只有 occupied/empty、所有 occupied 模式都与该 home 的宏匹配兼容。若模式依赖具体宏身份、大小或一般匹配边，则上述 occupation-base 结构失效，不能套用 2K 界。

给定 T 的 fixed-sink 算法随后枚举至多 `10K²` 个 heavy home/模式，删除其余 heavy 模式；对每个分支精确求有理 LP，再逐坐标 lex 优化得到 y 投影顶点。至多 2K 个非积分 home 需要改变；每个改变模式的 sink 总贡献≤βT（β=1/(8K)），所以 sink 负载≤`(1+1/4+2Kβ)T=3T/2`。empty home 私有负载≤T，occupied home 私有负载≤T/2 加宏≤T，也至多 3T/2。带下界的整数匹配流同时覆盖所有宏任务及正支持强制 occupied home，故实际输出不丢宏、不重复私有任务。

该身份是“对每个固定 K、给定 T、宏边>T/2 的受限构造”。它不是 K 随输入增长的一般多项式算法，也不提供未知 OPT 的免费搜索。正文另立 `UM-FIXED-SINK-MACRO-PROMISE-APPROX-v1`：在所有宏有限边>OPT/2 的额外 promise 下，用共同分母 D 和不要求接受集合单调的二分搜索得到 3OPT/2；这个 promise 不得并回给定 T 的主合同。

# 4. 固定残余通过量格和角色变化警告

相关正文 `residual_throughput_and_occupation_projection.md` 给出固定残余任务集 R、资格边 E、任意非负有理处理时间 p 和容量向量 c 的 LP：

`F(c)=max Σ_(i,j) x_ij`

其中每个任务总分配≤1、每台机器负载≤c_i。对偶是 `min Σ_j a_j+Σ_i c_i u_i`，约束 `a_j+p_ij u_i≥1`。用两个最优对偶 `(u,a),(v,b)` 的 coordinatewise min/max 组合，可得 F 单调且满足

`F(c)+F(d) ≥ F(c∨d)+F(c∧d)`。

因此固定残余身份下，F 是次模格函数；达到 `F(c)=|R|` 当且仅当全部残余任务有共同分数路由。若存在零资格边，必须先把零时间任务从残余中剥离；物理删除机器的模型不能把这些任务免费计入。固定占位集合 I、残余容量 `c_i(I)=C_i-a_i 1_{i∈I}` 时，`g(I)=F(c(I))` 为非增次模，缺口 `D(I)=|R|-g(I)` 为超模。这个性质不能直接给出共同占位选择：超模最小化方向相反，且任务角色随宏边选择变化时 R(H)、h(H) 同时变化。

正文的 2×2 反例 `P=[[1,1/2],[1/2,1]]` 显示固定残余的 F 不能被直接搬到动态角色：四个大边子集 H 的自然完成值 `2,1,1,2`，既非单调也非次模；原实例 OPT=1/2，故它只是范围负控，不是 promise 算法反例。

# 5. 任意图的占位诱导边缺口（bc9a）

`UM-OCCUPATION-INDUCED-EDGE-DEFICIT-v1` 固定有理 α∈[1,2)、δ>0，对任意非空简单图 G=(V,E) 构造：每个顶点有一台图机器和一台辅助机器；|V| 个宏任务在所有机器上时间 1；每个顶点有 r 个只可在自身图机器上的 tiny；每条边有一件只可在两端图机器上的 tiny，所有 tiny 时间相同 h≤δ。取 q 为 α、δ、最大度 Δ 的显式整数倍，使 `h=1/q`、`r=q(α−1)` 为整数且 `Δh≤2−α`。

将宏任务放辅助机、专属 tiny 放图机、边 tiny 任意定向，得到实际 makespan 1；单位宏给 OPT≥1，所以 OPT=1。对任意占位集合 I⊆V，图机在宏占位后的剩余容量为 `α−1`（I 内）或 α（I 外）。固定残余任务为全部 tiny，令 F 为第 4 节通过量，则

`D(I)=|R|−F(c(I))=|E(G[I])|`。

上界：I 内所有专属 tiny 与内部边 tiny 只能使用 I 的图机，共有 `r|I|+|E(G[I])|` 件，I 的总容量为 `r|I|` 个 h 单位，故至少损失 `|E(G[I])|` 的通过量；不允许假定 LP 必须先完整安排专属 tiny。下界：保留全部专属 tiny，丢弃 I 内边 tiny，其余边定向到未占位端；I 外图机负载≤1≤α，I 内负载恰 α−1，故达到该上界。

于是全部占位集合的完整通过/可行集合恰是 G 的独立集族。星图 K_{1,s} 表明叶集可行，加入中心必须移除全部 s 叶，因此不存在固定 p 使这类系统 p-extendible。这个交换缺口是任意图的精确集合系统表示，但不转化成 makespan hardness：实例直接有 OPT=1 的辅助机调度，α、δ 固定时构造规模多项式；当 α、δ 作为二进制输入并逼近边界时，q 可能很大，正文明确不声称 uniform bit-polynomial generator。

# 6. 有限图矩阵/最大流证据（bc9a）

来源 JSON 的 15 个 cases 是 K1、K2、P3、K3、K1,4 与 α∈{1,3/2,199/100}。每例：

- 全部宏/私有/边 tiny 任务按实际矩阵生成，`OPT1_actual_schedule_verified=true`；
- 全部占位子集检查原矩阵的边方向，预测“独立集当且仅当可行”与实际完整 sigma 一致；
- 读取实际 tiny 资格集合和机器剩余容量，用独立整数最大流计算最大通过量，验证 deficiency 恰等于内部边数；
- 无随机性、Fraction/整数、Python 3.12，源 hash `5d2b822bf18e0ea081a2627b755d248f855d2a003b169cb0818e80509bc6f966`。

典型值：K2 具有 deficiency 0/1，P3 最大 deficiency 2，K3 最大 3，K1,4 最大 4；每个 α 版本的 `q,h` 和任务数随固定参数变化。K1,4 还核对加入中心至少移除全部四叶，作为无固定 p-extendibility 的有限实例。程序只核对指定图与固定参数，不覆盖任意图全枚举、任意 α/δ 或一般调度器。

# 7. 全仓比较、处置与后续

1. 与《固定汇点占位模式与三半实际调度》：occupation 面证据是其核心引理的独立 finite replay；不把 20,760 个小面当作完整 fixed-sink 算法测试，也不把 promise-OPT 版本混入给定 T 身份。
2. 与《全局基数与逐行均匀相关读出边界》及紧凑共享逃逸：它们分别研究逐查询计数/共同容量和逐行均匀正面子类；本批的 F 次模与任意图独立集缺口需要固定残余/占位语义，不能互换。
3. 与 heavy matching、joint block cuts、residual throughput：F 的格次模性是固定 R 的精确 LP 性质；动态 H 同时改变 R 与容量，正是一般恢复算法的缺口。不能由通过量接近 |R|、免费拟阵识别或单个占位证书推出实际全局调度。
4. 与当前六人 CAG/SPE：宏/占位/容量模型不同，保持 unrelated-machines 隔离。
