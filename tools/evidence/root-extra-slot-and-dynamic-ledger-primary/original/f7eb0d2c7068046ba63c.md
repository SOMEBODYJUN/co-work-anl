# 一般直接覆盖机制：背景新覆盖预算与障碍

2026-10-23；团队子任务 global_mechanism。当前为探索笔记，不提升任何 Claim。一般 Q-CAG-HALF 仍 OPEN。

## 1. 精确对象

有限共同主题目录、单位客户与单位玩家；每次偏离均保留给定完整历史 SPE 的真实后继。以下不假定同计数历史同动作、不冻结后继、不使用 SPE→静态NE 或最低静态CCE福利桥。

## 2. 一个可变人数加强候选

固定任意合法前缀主题计数 b，余 r 位玩家。令 B 为前缀已覆盖客户集。取该子局任意完整历史纯 SPE 的实际后缀，令 c_x 为后缀覆盖次数，定义

- D_b(c)=|{x∉B:c_x>0}|：实际后缀新覆盖；
- U_b(c)=Σ_x c_x/(b_x+c_x)：后缀玩家总最终收益，c_x=0项取零；
- M_r(b)=max_{T_1,…,T_r}|(∪T_j)\B|：r个共同目录主题能新增的最大覆盖。

**未证候选 BG-NEW：M_r(b)≤D_b(c)+U_b(c)。**

空背景时 D=U=W，候选正好推出主目标。它与已否定的一般背景税式 F_r(b)≤U_b(c)+τ_b(c_<r) 不同：本式左边只计背景外的新客户，右边明确保留新覆盖D，而非机会税。并未证明它，也未将有限搜索称作支持证据。

r=1直接成立：唯一玩家的实际收益不小于任何主题的背景外客户数，故 U≥M_1(b)，D≥0。零客户/空主题仍成立。

## 3. 朴素归纳的致命缺口

若首步选择A，归纳只能控制 M_{r−1}(b+A)，而 M_r(b)比较组合仍有r个主题。删除其中一个比较主题会损失其在其余比较主题与A之外的私有覆盖；当前玩家对该主题的真实偏离收益可能被适应性后继压低。因此不能把缺失私有覆盖直接交给当前收益，也不能在实际路径与该偏离路径之间搬用旧玩家收益。

更具体，r=2实际后缀(A,B)，令a,b为两人实际收益。根偏离B的分母保底仅给 a≥Σ_{x∈B}1/(b_x+2)。末位比较两个新覆盖最优主题的均值给 M_2≤2b+|A\B_base|/2（此处B_base是背景覆盖集）。把这些粗界按目标D+a+b直接相加，在旧客户 x∈B\A、b_x≥1 上留下

    −1/(b_x+1)+1/(b_x+2)<0。

这不是 BG-NEW 的反例；它精确否定了这组固定系数静态保底直接相加的证明。修复必须保留真实根后继或使用旧收益的另一共同预算，不能直接断言非负。

## 4. 当前信息边界

BG-NEW目前未证明，也未反驳。尚无可变r的闭合递推。下一次值得推进的工作应提供跨真实分支的旧收益支付或直接构造合法反例，而非继续固定人数的同类数值探针。

## 5. 真正静态安全值的两条全人数约化（exchange_attack子任务）

定义

    v_m=max_p min_{q:|q|=m−1} E_{T~p}[Σ_{x∈T}1/(1+c_x(q))]。

静态对手不见查询T。以下精确约化不证明W≥m v_m，也不证明一般half。

### 5.1 不交客户、笛卡尔积目录的可加性

两个分量客户集不交，目录取所有A∪B，其中A、B分别为分量合法主题。则对每个m≥1，有 v_m=v_m^(1)+v_m^(2)。

证明：任意联合查询分布p的边际为p1,p2，收益可分相加。对手的m−1个乘积主题恰可按位置分别取任意两个分量的m−1主题组合，所以

    min_q E_p U = min_q1 E_p1 U1 + min_q2 E_p2 U2。

任意两个边际可由乘积分布实现，分别最大化即得结论。

若两个分量分别有完整历史纯SPE，则在每个联合有序历史按各自投影历史逐分量执行，得到完整乘积SPE。任意联合偏离的两个收益差分别非负，故和也非负。此SPE福利相加，所以强缺口 W−m v_m 可加。

**限制：** 没有断言任意乘积实例的任意SPE分离；跨分量历史和平局可以耦合。结论只阻止用已有分量SPE的独立乘积把“逐人负余额、总非负”放大成负总余额。

### 5.2 公共padding严格保持强缺口

给每个主题同时增加K个新公共客户。对任意完整终局、任意玩家，新增收益恰K/m，与所有行动无关。因此每个完整有序历史的全部偏离差保持不变；原完整策略是SPE当且仅当padding后仍是SPE。

静态安全值、实际福利、最优覆盖分别满足

    v'_m=v_m+K/m， W'=W+K， OPT'_m=OPT_m+K。

从而 W'−m v'_m=W−m v_m。若真正强聚合桥有反例，则加公共客户可把OPT'/W'推到1，同时保留强桥负差。这说明只筛福利比很坏的实例可能遗漏强安全值桥反例，不反驳half。

弱缺口不同：

    W'−(m−1/2)v'_m = W−(m−1/2)v_m + K/(2m)。

真正聚合桥 W≥m v_m 仍OPEN；上述两条解析约化均未闭合它。

## 6. 交接
