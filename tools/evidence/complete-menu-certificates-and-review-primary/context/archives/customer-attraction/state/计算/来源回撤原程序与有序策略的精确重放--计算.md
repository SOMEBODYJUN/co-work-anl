# 来源回撤原程序与有序策略的精确重放

## 原件与一次真实运行

本批四源为README1148、审计程序10829、冻结报告9173、一般修复稿11138字节，总32288字节，全部`clean show`实际取回、全文阅读并逐份核冻结SHA。[原件清单](../../tools/evidence/origin-retraction-workspace/source-manifest.json)给两个完整commit/path；[原件目录](../../tools/evidence/origin-retraction-workspace/original/)保原bytes。

原程序不导入规范求解器或第三方库，只用标准库Fraction。它用`HERE.parents[4]`定位原树根，硬编码读取348客户、52客户两旧证书，直接覆写自身目录中的同名报告，没有命令行输出选项。本次按原路径把**未改字节**程序和两个输入复制到仓库外replay树，实际执行一次普通`python3`，exit0，stderr空。所有assert处于启用状态，不使用`-O`。

生成报告、stdout均与9173字节冻结报告逐字节相同，SHA为`6488b65a790c2af4bab4f0019a10f6cd4f784d6318fd12517232ba6cfd077cd9`，没有只比较status字段。[执行记录](../../tools/evidence/origin-retraction-workspace/replay/execution.json)、[stdout](../../tools/evidence/origin-retraction-workspace/replay/original.stdout.txt)、[stderr](../../tools/evidence/origin-retraction-workspace/replay/original.stderr.txt)、[新报告](../../tools/evidence/origin-retraction-workspace/replay/origin_retraction_exact_audit.json)保命令、真实cwd、时间、exit和哈希。[重放输入清单](../../tools/evidence/origin-retraction-workspace/replay-input-manifest.json)绑定未改代码及两输入；已有原件与新报告分开，未覆盖冻结证据。

这不是独立开发的第二实现。解析正确性见[固定路由修复算法](../算法/固定来源路由的最大回撤与价格分离--算法.md)，一般SPE成功不由有限运行认证。

## 原程序实际检查的完整流程

每个fixture将非负整数重数展开为不同单位客户。`finish`始终按输入的**有序历史**调用policy；程序枚举每层全部历史和全部主题，比较原规定真实完成叶与当前强制行动后的真实完成叶，使用包括客户自身的均分收益。旧动作表少一历史会在查询时失败，后继从未冻结成实际后继。含规定动作自身的比较也计数。

比较元组$T$的覆盖通过枚举允许重复的全部$m$主题组合确认等于OPT。之后逐$(i,x)$重建canonical比较份额$p=1/c_T(x)$、实际分母$\delta=c_B(x)+1-\mathbf1_{x\in B_i}$、actual正价$H$、剩余库存$r$及加强future边容量$\min(p,1/\delta)/c_{W_i}(x)$。

默认只送满足$d_i\le u_i$所需的最少future总量，并按每坐标可送量比例拆分；52客户例特意取`max_future=True`，使每坐标送出$\min(r,q)$、激活$R$分支。全部$I$ future质量一次按实际未花份额比例转为$J$，逐角色核$H_i+J_i\le u_i$。

`propagate`保留来源$i$、精确history $g$和客户$x$三标签。每角色层先按$(g,x)$跨来源合计核$c_{\operatorname{finish}(g)}(x)h\le1$，然后按原reset叶的**新增future coverer**传播$h/c_A$，current为剩余质量。这里optional-common边固定取0，不是搜索其全部可行选择。统计`tagged_R_nodes`按非零$(i,g,x)$项计，不是独立历史节点数或访问轨迹总数。

程序核每来源$\sum_\ell K_{i\ell}=b_i$、严格未来零元、总费用等于OPT，再运行前向贪心。随后按$\theta_i=y_i/b_i$重新传播同一次来源，逐矩阵项核$K'_{i\ell}=(1-\theta_i)K_{i\ell}$、费用仿射回撤式、总质量不变及成功时全部$2u_i$ cap。零$b$不作除法。

程序虽实现了首次失败的后向价格和CUT等于负$z_j$的分支，本次六个case全部成功，**没有动态执行该失败分支**。该分支的一般正确性来自算法正文中的解析证明，不能由空的`failure_dual`字段或报告passed声称已经测试。原脚本采用assert，不是面向任意不可信外部证书、在优化模式下仍有效的通用验证API。

平局例以两个不交单客户主题及空主题逆向归纳，平局选择器显式依赖历史的带位置加权和；程序实际核$\sigma(0,0,1,1)\ne\sigma(0,1,0,1)$，这两个历史主题计数相同。实际叶$(0,0,1,1,1)$，$u=(1/2,1/2,1/3,1/3,1/3)$，费用$A=(1/6,23/36,37/72,1/6,37/72)$，总2。回撤没有改变这份策略或压成匿名计数策略。
