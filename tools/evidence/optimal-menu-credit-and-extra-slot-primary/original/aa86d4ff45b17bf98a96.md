# 全局安全付款的排列尝试：原策略下尚未闭合

2026-10-24。对象始终是任意有限单位客户、共同有限非空目录、任意人数和全部有序历史纯SPE。目标是原实际叶的 `W≥m v_m(0)`，或直接 `2W≥OPT_m`。这是个人研究checkpoint，没有新增已闭合的付款定理，不把下面恒等式称为一般half进展。没有扫描、没有再造局部反例。

## 1. 原策略不动的统一行

固定原完整策略σ，实际叶z，实际利润u_i，令t=v_m(0)。原实际位置i强制A后的真实终局为Z_i(A)，删除当期行动所得m−1槽背景为B_i(A)。对任意目录分布p，

    d_i(p)=E_A u_i(Z_i(A))≤u_i,
    C_i(p)=E_{A,A'} f_{B_i(A')}(A)≥min_B E_A f_B(A).

所以若p为安全值最优分布，

    W−m t ≥ Σ_i[u_i−d_i(p)] + Σ_i[d_i(p)−C_i(p)].       (S1)

(S1)的右侧仍可能无法按项定号。这里不回到已失败的全p去相关结论；尚未证明对某个安全值最优p右侧非负，亦没有从任意平局中删除误差。

## 2. 固定叶的交换恒等式及其准确可用性

固定两个指定玩家，行动分别为A,B，其余全部行动记Y，过去背景为b。写

    F_(b,Y)(T)=Σ_(x∈T)1/(b_x+c_x(Y)+1).

逐客户消掉A∩B项可得

    u_A(A,B,Y)−u_B(A,B,Y)
       =F_(b,Y)(A)−F_(b,Y)(B).                         (S2)

(S2)对任意背景、人数、空题、重复主题成立，且两侧全部在同一叶。它是末两人恒等式的直接同叶版本。将A向后逐位交换时，**只在同时保留Y时**可以望远镜。真实σ在两个不同有序历史上通常产生不同Y，因而不允许在(S2)两侧分别放两份真实续局再消项。

更明确地，对相同客户负载的有序前缀h,h'，可把σ在h后的续局“运输”为h'后的一个合法子SPE：所有未来玩家的可行动作和最终收益依赖负载，不依赖过去顺序。这个事实只制造一个新的可选子SPE；它没有断言原σ在h'后选择该子SPE。替换原孩子还可能破坏祖先的IC，故不能用它证明原实际叶总付款。

## 3. 保留全体过去玩家后，选择漂移的守恒

对具有相同负载b的h,h'，分别沿原σ得两续局Y,Y'。令

    P_old(b,Y)=Σ_x b_x/(b_x+c_x(Y)),
    P_new(b,Y)=Σ_x c_x(Y)/(b_x+c_x(Y)),

分母零的项取零；old是全部已行动者最终利润之和，new是全部后继最终利润之和。因为每个被覆盖客户总付款一，准确有

    P_old(b,Y)−P_old(b,Y')
      = W(b,Y)−W(b,Y') − [P_new(b,Y)−P_new(b,Y')].      (S3)

所以对过去玩家身份平均确实消去了“哪个旧玩家”的标签，但保留了真实续局的福利选择差。除非另付(S3)右侧，排列平均不能把它变为零，也不能把某个离轨P_new直接记在实际surplus S内。

## 4. 当前未付的共同量

令D=Σ_i(t−u_i)_+，S=Σ_i(u_i−t)_+，ε=(2m−1)t−OPT_m≥0。half的准确目标仍为

    2D≤2S+t+ε.

本轮没有构造容量为每份实际(u_i−t)_+且只使用一次的跨枝流。以上排列/交换工作没有给出这样的容量约束。下一步若继续用交换，必须让全部(S3)选择漂移在同一共同流中消去或被实际利润支付；逐对重排、独立选择同计数的有利续局、或同一actual surplus在多条交换路径重复付款均不足。若不能完成该共同约束，应换方法而不继续收集局部阴性材料。
