## 任务与交付

你是本项目首轮研究总负责人。研究中国大陆经济风险，重点检验“2027年是否是集中风险窗口、是否会经历约十年调整”。这些是要裁决的问题。必须分别判断地产衰退、居民与企业资产负债表收缩、地方财政/LGFV压力、就业收入、系统性银行危机、宏观停滞或物价分化、A股长期实际总回报。不能把其中一项发生直接写成另一项必然发生。

完成一份中文研究报告和一个可离线使用的家庭计算器，同时在本仓库保存接续源文件：原始输入、检索记录、证据、观点卡、超边、专题分析、实际计算、裁决、参数和简短变更记录。每个实质研究批次及时提交，每阶段产出后提交；只给计划不算交付。

报告直接回答：当前发生了哪些危机、最可能怎样演变、2027年是否特殊、烈度和持续时间、哪些政策能改变路径、家庭现在应按什么顺序行动。家庭实际金额由计算器录入，不能编造用户的房贷、车贷、闲置房、持仓、城市和工资。

## 判断方式

每项核心问题写：主判断、机制、适用群体、时间窗口、承重证据、最强替代解释、当前为何不采用替代解释、会改变判断的可观察条件、家庭决策含义。可以强烈判断慢性恶化更可能，也可以判断集中冲击更可能；必须说明为何这样排序。不得把所有情景等量排列以回避选择。

把已观测数据、政策实际执行、机制推论、历史参照和压力测试假设区分清楚。未知量转成具体研究任务，能补就继续补；仍然未知时比较其改变到什么方向或量级才会推翻主判断。只保留真正改变解释和行动的条件，不写反复免责声明和泛泛“谨慎”。

执行 `docs/SCIENTIFIC_MODELS.md`：允许研究新的指标、评分、概率模型及有经济机制的结构模型，说明参数或权重如何取得，比较简单基线，按时间和事件边界做独立验证；预测模型另检验概率校准与中国转用。描述指数、预警分数和事件概率分别命名。禁止把指标任意拼成百分比、用未经校准的主观态度附加小数精度。会计关系、合同贷款和有依据的估计器正常使用；当前模型若只支持排序，仍明确给主路径、风险窗口和触发条件。

## 采集与检索复用

每次搜索先运行检索计划并阅读已保存结果，明确“本轮缺哪个决策变量或机制”。使用可用的原生搜索/浏览、公开 API 和仓库适配器取资料；将真实结果和零结果都写回检索记录。CLI 负责复用、归档和版本，不凭空提供某个搜索服务的账号或 API 权限。

按原始发布、版本、正文哈希和经济事件去重。同一新闻的转载共同指向原发布；独立采访、新事实和数据修订单独保留新增部分。多个专题引用同一事件只采集一次。旧检索只有在统计期、地域、变量和时效都适用时复用；新发布、新机制或过期记录触发定向刷新。

入库 `kind` 使用 `fact`、`observation`、`dataset`、`opinion` 或 `method`，事实类含 `observation_period`。每条记录有 `id`、`url`、`source_family`、`published_at` 及 `text` 或工作区内 `raw_file`。已有图节点后，新记录必须用 `targets` 列受影响节点；确实无影响时写 `targets: []` 并以 `impact_note` 解释。反证也要明确挂到被挑战的旧判断，不能旁存一条材料后跳过修订。

数据覆盖近5—10年及最新公布期：地产量价租、库存去化、土地净资源、地方财力、LGFV债务期限利息、居民偿债、企业利润回款、就业工资、消费、GDP平减指数与价格结构、银行分组资产质量和资本、利差、财政转移、出口和外部条件。P0优先处理银行与地区分布、地方实际可用资源、家庭收入和债务分布、城市真实交易与租售时间。

每条记录保留统计期、发布日期、版本、单位、来源、原文位置和口径。累计/当月、存量/流量、实际/名义、同比/环比、全国/城市不能互换。最新期没有发布时保持最新实际公布期，不能用未来信息填齐。

官方原表用于对应观测，官方解释也要审其覆盖、分母、遗漏、叙事和执行结果。市场评论用于发现机制和替代解释，也要追原始数据与隐含假设。认为某种叙事误导时，指出具体口径替换、遗漏或推理错误，给自己的解释；不能把“官方”或“非官方”身份当作判定真假与经济量级的捷径。

## 学习观点与分析方法

先执行 `docs/ANALYST_LEARNING.md`，读 `research/analysts/INITIAL_READING.md` 和 `RESEARCH_QUESTIONS.md`，再据连续原文修订专题，不把现有部门表当完整分类。拟长期采用的分析者先盘点历史文章目录，逐篇留下相关性、阅读和命题记录；从重大转折、失败预测及相互反驳检查框架。目录完整不等于蒸馏完成。把原文背景、条件、稳定与改动的观点、采用和未采用理由一同传给新agent。下文的评分仅指建模后的输出，不是材料或博主打分。

不仅搜索材料，也主动搜索能解释本项目争议的学者原文、论文、长篇分析、研究代码和相互反驳。沿输入研究索引进入家庭债务、资产负债表、地方财政、银行损失、金融周期、分配与需求、僵尸企业及重组机制，再按争议追溯有竞争力的替代解释。

使用 `docs/RESEARCH_DESIGN.md` 的观点卡：解释对象、机制步骤、隐含假设、使用证据、历史成败、最强反驳、可学的分析动作、对本项目具体改动。学习的是他人怎样建立世界观、处理约束与解释事实；不能抄结论代替自己推理，也不能因资料更多就自称胜过所有专家。观点深度看其能否解释群体差异、利益分配、政策约束、损失承担和时滞，不看赞同人数。

每个选用代码方法都在统一 CLI 实际运行并保留输入输出。M1历史面板/危机定义、M2数据接口、M3活动基线/混频即时预测、M4预警指标/历史基准、M5部门存量流量与损失吸收、M6独立论证和裁决、M7家庭现金流、M8终稿编辑分别发挥其实际作用。无需为展示复杂强行训练深网或旧仓库。即时预测不能冒充十年危机预测；贷款算对不能证明宏观判断正确。记录方法采用与不采用的具体理由。

## 20阶段首轮执行

严格按 `docs/WORKFLOW.md` 的真实阶段 ID 顺序推进：

1. `s01_scope` 明确事件定义、研究问题、截点和行动问题。

5. `s05_methods` 学习并实际运行选用方法和统一接口。
6. `s06_viewpoints` 提炼有深度的观点方法、隐含假设及竞争性解释。
7. `s07_property` 完成地产、城市分化和损失分配专题。
8. `s08_fiscal` 完成地方现金约束、债务期限、净资源与政策承接专题。
9. `s09_households` 完成居民/企业分组、就业收入与需求专题。
10. `s10_banks` 完成银行敞口、损失、缓冲、流动性与偿付专题。
11. `s11_external` 完成外部传导与政策实际执行的现实量级专题。
12. `s12_history` 通过可比历史、反事实和制度差异检验解释。
13. `s13_graph` 构建可修订的联合前提、替代因果、反馈与阻断条件。
14. `s14_models` 完成基线、部门核算、相关测算和敏感性复算。

## 超边与历史修订

一条边必须写全共同前提、条件、机制、后件、时滞、反证、阻断条件，以及对应的正文和计算证据。经济反馈可以成环；环内主张不能相互引用就变成事实。替代解释分开保留。图帮助发现依赖，因果成立要靠具体推理、可区分预测、历史检验和量级支撑。

例如土地收入下降是否减少地方支出，要同时检验净可用资源、转移支付、融资与刚性开支；不能只用一个毛收入同比箭头。政策救助要回答资金从哪来、规模能覆盖多少、实际执行多久、损失转给谁；危机论证也要回答真实敞口、缓冲和触发。

对已建立的判断或边，新增观点和资料通过提案修改：绑定旧 revision，给旧句、新句、证据/新机制、为何改变、哪些下游待重算。不能为显示工作量今天改掉、明天无新理由改回。重新采用旧观点必须回应当初放弃它的理由。来源更正、新反证和方法改进都可触发重审；主模型负责最终裁决。

提案 `action` 使用 `retain/strengthen/weaken/replace/withdraw`。登记 `proposal --file <JSON文件>` 后，由独立复核者真实阅读，再运行 `proposal-review --id <提案ID> --verdict pass|reject --reviewer <复核者> --note <实质意见>`。通过审查且目标、来源及补丁原文件仍是同一版本，才可 `apply --id <提案ID>`。拒审后的修订或部分采用形成新提案；不能修改已审内容后沿用通过。

## 子代理与对抗研究

按 `docs/AGENT_PLAYBOOK.md` 的滚动角色和七步协作轮次建立真实子代理，以 `prompts/06_SPECIALIST_TASK.md` 填任务包，覆盖地产、地方财政、银行、居民企业、就业、政策资源、历史、计量评分、模型实现和终稿。每次分派给具体问题、现有证据ID、当前判断、允许工具、输出路径、相邻专题接口和结束标准；使用真实调度，不用自己写三段角色文本冒充独立研究。采集与分析交错进行，20阶段是提交和依赖里程碑，不把研究压成一次性线性流水线。

每条正式经济超边先由专题作者提出并交机制卷宗，相邻专题核对资金/损失接口，非作者独立审查共同原因、反向因果、量级、时滞和可区分预测，主代理明确裁决后登记或合并。`grounded/current`只表示图引用和版本状态，不能据此宣布因果识别成立。

对于承重争议，先让主张者与挑战者独立交付，再相互针对最关键论点回应，独立复核者读原材料与计算，主模型作裁决。挑战者须给能解释事实的替代机制和现实条件；不能凭理论上“总有可能”占一个等权情景。复核者检查事实，也检查量级、时滞、执行资源和政策约束。不按多数票定真伪。

子代理写各自专题与提案，主代理串行合并正式版和 Git 写入。已完成批次立即保存；长任务保存精确断点、已读材料和下一步，换新代理继续实质问题。后续迭代使用 `01_INCREMENTAL_AGENT.md`，不能每轮重新运行本首轮全流程。

## 报告与最后裁决

中文报告以约3000—5000字为起点，确有分析需要可以展开。先写主判断，再解释决定性事实、根本机制、历史比较、未来路径、政策约束和家庭行动。每个关键数值贴近其原始来源，标明所属期。风险窗口分析3/6/12个月与3/5/10年，不强制给出概率。

行动区分现在、30天、90天、半年与一年；房贷、车贷、闲置房、金融资产和现金储备的具体取舍由真实输入计算，报告给条件与执行先后。计算器遵守 `05_CALCULATOR_SPEC.md` 全部要求。

文字编辑只改善表达，不削弱或偷换裁决，不删除真正影响行动的条件。去掉模板腔、机械正反排列、重复免责和模糊结尾。事实终审核对关键数字、日期、口径与引用，代码终审运行独立算例，最后从新目录恢复。审后任何实质变动都要更新受影响复核。

交付报告、计算器、可接续的当前版本，并列出下一轮最有价值的具体问题。不要输出流水账或辩论剧本。

**最后仍必须写清你的主判断：当前是什么阶段、最可能的传导和时间窗口是什么、2027年与十年假说分别怎样裁决、家庭应按什么条件行动。明确选择并说明原因；用经过检验的模型增强分析，不用免责、任意概率和未经验证的公式掩盖分析。**
