# 家庭离线计算器交付规范

计算器把研究裁决转换为可编辑的情景和真实家庭现金流。它必须实际运行方案并给出行动次序，不用任意综合得分、伪概率或漂亮静态界面代替计算。

## 页面与输入

交付一个CSS/JS内嵌的中文单文件HTML，无CDN、后台、遥测或网络请求。离线直接打开，支持手机查看、增删资产贷款、参数编辑后真实重算、JSON导入导出、全量策略与逐月结果CSV导出。图表文字默认英文，金额、字段解释和操作说明用中文。图表绑定真实结果。

原始家庭金额为空；演示数据只有用户显式选择时才载入，并持续标为示例。单位元/月，可从万元转换。界面优先显示严重现金风险、可支撑时间、策略动作和执行顺序。未知值允许范围输入，不偷偷补成所谓行业平均。

|---|---|
| 收入 | 多成员税后工资/奖金、经营实际回款、其他已存在收入、稳定性、各来源独立冲击、失业起点、持续期与复工恢复 |
| 支出 | 必要生活、教育、医疗、养老、保险、可削减支出、突发费用、时间变化 |
| 流动资产 | 现金、存款及到期日、可即时变现余额、股票/基金/债券/黄金/其他资产、集中度、杠杆、交易成本与到账时间 |
| 多套房产 | ID、城市/类型、自住出租闲置、估值范围、保守可成交价、挂牌成交月数、租金、空置、维护物业税费、成交成本、锁定出售限制、住房替代安排 |
| 关联房贷 | 关联房产ID、剩余本金、实际利率、固定/浮动、重定价期与合同、剩余期数、还款方式、月供、提前还款费用与限制、能否带押过户 |
| 多辆车 | ID、估值折旧、是否必要通勤生产、车贷本金利率月供、结清费用、保险养车、替代出行成本、锁定限制 |
| 其他债务 | 消费贷、信用卡、经营贷、亲友借款、担保，余额、利率、到期、分期/到期还本、费用、偿付限制与代偿 |

城市资料由研究阶段取得，保存城市、统计期、来源与适用条件；计算器离线导入和编辑。资料提及昆明不代表所有房产在昆明。贷款合同与实际税费以用户输入为准，不承诺普遍可以转贷或零成本提前还款。

## 情景接口

每个参数保存数值、单位、施加时点、持续时间、范围、来源ID、可编辑与假设类型。假设类型区分观测、历史参照、研究估计和人为压力测试。包括房价、租金、空置、工资、失业、复工、股票总回报与集中持仓折价、通胀、存贷款利率、成交折价和出售延迟。

主情景依据研究形成：结构延续、严重下行/信用损失、有效恢复；有具体依据时加入外需、汇率或成本复合压力。不要强行平均权重。没有校准权重就逐情景比较及最坏情景比较，不把“通过几个情景”的比例写成现实安全概率。

区分一次性水平冲击和年率/按月路径，不能把一次跌价每月重复施加。跨资产与收入影响通过明确的联合情景体现。相同策略在各情景使用共同的外生路径；条件触发只读当时可观察信息，不能预知未来价格。

## 120个月引擎

使用标准贷款合同公式和会计恒等关系，以月递推，资产、债务和可用现金分账。用numpy-financial独立核对等额本息与本息分解；零利率按本金除期数。每期利息按期初余额与合同月利率，末期本金封顶，偿清后余额不能负数。等额本金按合同处理；浮动利率仅在重定价期变化。部分提前偿付分别测试降月供与缩期限，并执行合同限制。

每月现金等于期初现金，加实际到账税后收入、净租金、可用资产净处置款和可用现金利息，减必要及其他支出、贷款本息、提前还款、税费与费用。金融资产未实现涨跌不当现金，受限/抵押资产不当可立即使用资金。总回报已含股息时不再另加股息。

房产出售在成交到账月份才入账。卖房结清关联债务，扣成本，移除资产及其后续租金，避免“净卖价已扣贷款”后再次扣还贷。负资产房须先有资金补差和解押，不能因挂牌便凭空取得净收入。车辆和其他资产处置同理。

净资产使用现金、金融资产、房产、车辆和其他可计价资产减剩余债务，名义与通胀折算实际值分列。每月账户能勾稽，处置和债务结清不重复。

现金不足时仅按事先策略执行合法及时变现。资产不能及时卖出则记录首次失败月、未付金额和缺口，不能允许负现金自动变成无息借款。后续违约成本无法可靠估计时截断，并将之后净资产列为空或条件性续算；不得把失败后的十年终值拿去与正常履约策略排名。欠款不因截断而消失。

## 真实策略枚举

永远保留不行动基准。按资产实际数量和合同生成实质不同的动作组合：

- 闲置房持有、出租、降价出租、立即挂牌、6/12月挂牌或现金阈值触发挂牌；多套出售先后。
- 房贷原计划、部分提前还款、全部结清，分别降月供和缩期限；金额档按可用资金和储备约束生成。
- 车保留、提前结清或出售，保留必要交通约束与替代成本。
- 股票保留、分批减仓、清偿杠杆或转现金，成交成本和到账时间计入。
- 储备月数与支出调整；第二收入只用实际存在或用户录入的收入。

目标100—500个可行且有实际差异的候选；组合不足时输出全部。组合很大时按有理由的分层枚举/剪枝处理，标明实际覆盖，不能靠随机小数或微调凑数量。检查资金、合同、负资产补差、住房替代、锁定和重复，保存不可行原因。几十几百种候选必须真的逐情景、逐月运行，可查看、筛选、比较和导出全部结果。

## 输出与排序

先检查执行、最低生活、储备和到期偿付，再比较财富。不把现金流、净资产和债务压力任意加权成一个“最优分数”。允许用户切换明确单项目标，显示Pareto非支配候选；使用标准后悔值比较时说明比较目标和相同可行集，不把不同量纲直接相加。

至少显示12/36/120月最低现金、首次资金缺口、最坏缺口、支撑月数、剩余债务/月供/偿债比、提前还款省息与流动性变化、租售净现金、1/3/5/10年名义和实际净资产、峰谷回撤与复苏机会成本。现金失败的策略正确显示失败和终值不可比。

摘要给基准、跨情景较稳健、现金流最好、后悔较少、长期潜力与债务压力最低的具体策略，以及10—20个非重复优质候选。每项说明动作、时点、资金来源、价格/成交时间、每月变化和条件未满足时的替代动作；区分现在可执行和触发后执行。无可行策略时显示缺口最小方案及仍需补多少资金，不能判为安全。

逆向压力测试逐一或联合求工资下降、失业持续、出售延迟、房价、租金到什么水平会使现金不足；计算净租金与卖房净款的盈亏平衡、可承受提前还款上限、卖股/还贷对现金耗尽的影响。用实际重跑求边界，不从自创风险分数倒推。

## 独立验证与离线验收

使用独立Python算例和numpy-financial对照，实际覆盖零利率、1期、提前还贷、负资产出售、延迟到账、失业、投资亏损、空置、重定价、无法出售、现金不足与无可行策略。验证不重复处置、不重复股息、不重复还贷、本金不负、固定输入复现、无冲击手算一致、失败终值不参与正常排名。

实际离线打开HTML，编辑收入、增删资产贷款、切情景和目标、触发重算、导入导出、看逐月表与图，并检查移动布局。界面按钮的存在不算完成，操作后要产生对应真实结果。

首轮工程包提供的是流程与方法基础，正式家庭计算器由Pro在本阶段按完整规范产出。工程演练采用的合成家庭参数始终标明测试，不能写进正式中国预测或充当用户资产数据。
