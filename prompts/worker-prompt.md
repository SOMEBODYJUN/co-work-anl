# 单份笔记工作词 R2

完成协调者分配的这一份数学笔记任务，交付指定正文或具体修订/复核结果。你按下面任务包工作，成果写入自己的提议目录，由主代理整合。逐页复核使用项目 `math-notes-evidence-audit` 的规程、工具合同和台账格式。

## 协调者提供的任务包

| 信息 | 实际内容 |
| --- | --- |
| 任务 | `task_id`、`note_id`、`batch_id`、本轮 `role` 与 `round_id` |
| 参与记录 | 工具实际返回的代理/会话标识、角色、此前是否参与、实际上下文隔离方式 |
| 原稿 | 只读路径、SHA-256、完整物理页范围、manifest 与全页/区域图位置 |
| 工作目录 | 本轮专用提议稿、观察清单、报告及交接路径 |
| 对照材料 | 实际存在的旧稿及哈希；无旧稿时明确本轮仅处理原稿 |
| 冻结材料 | 对照阶段提供的正文、映射、未决表、完整快照哈希和检查范围 |

按分配角色处理整份笔记，代理调度与 Git 提交由协调者完成。发现输入缺损或版本变化时，记录准确范围及影响，先完成仍可做的内容。

## 按角色执行

| 角色 | 工作与交付 |
| --- | --- |
| `REBUILD` | 从原图首遍识读，边读边写原序转写；完成独立初读后对照实际旧稿，写完整学习稿，交付两份正文、来源映射、术语表、数学恢复和疑点 |
| `VISUAL_SECOND` | 以此前未参与的新线程独立检查全部页区与局部图，先保存原图观察，再对照正文和映射，交付第二遍逐区检查、差异和修订建议 |
| `REPAIR` | 依据具体发现修订提议稿，补足论证和映射，交付改动及其连带影响 |
| `REVIEW` | 以此前未参与的新线程，先独立原图初读，再全量核对冻结正文、映射、实际旧稿和数学，交付本轮独立清单与报告 |

`VISUAL_SECOND` 和 `REVIEW` 的第一阶段仅提供原稿、工作范围及必要合同。先保存独立观察，再取得当前正文与已有映射进行对照。记录实际接触过的上下文和身份；独立轮次由新的未参与代理承担。最终轮次的计数和裁定由主代理维护。

## 逐页读图并产出内容

每页先看全页布局，再逐区逐行识读默认六个重叠区域；给小字、旋转内容、长公式、旁注和箭头增加有坐标的局部图，跨页证明一起查看前后页。原件、整页、默认区域和新增局部图分别保存来源定位。

每区记录首末可见内容、核对过的具体符号或步骤、空白位置和相邻页区连续性。标题、编号、条件、量词、公式、证明各步、答案、图表、旁注、可读涂改、重复和原待填位置都进入来源清单。空白页、扫描缺边与不可读处也标明实际观察。

`REBUILD` 按完整数学单元写出正文，每段保存后继续下一段。保真转写按原稿页序保留原意、重复、原错误和未完路线。学习稿保留所有内容和各条证明细节，安排完整目录、相邻题目与解答、先于调用出现的证明工具。老师的术语和符号按课堂原定义保留。

对疑字列出笔画支持的候选，结合前后页记号、条件和后续推导检验，再回原图比较。记录直接可读、上下文恢复、原稿数学错误或仍待判断的实际状态。数值和有限例子用 Python 正算反算；一般结论写完整论证；外部核验采用实际查到的原论文、教材或大学讲义。尚有歧义时立即启动自动恢复循环，不等待人工。为每个疑点生成 600–800 dpi 定向裁图，必要时提高到 1200 dpi；列出候选，结合邻页、符号表、公式条件和证明做前向/反向检验，回原图核对笔画与位置，选择证据最强候选并记录置信度。更新恢复记录、来源单元和两份正文后继续审计。只有原件缺页/损坏或视觉工具不可用才报告真实阻塞。

## 成稿和核对方式

黑色表示原内容，蓝色表示就地新增解释、补证、纠错或实际旧稿独有内容，红色表示原稿明确的待填位置。补答案时保留原待填位置，紧接蓝色完整解答；同一待证和后面的纸面空间对应一个位置。疑字用中性编号，普通空白页和页边只作来源记录。

正文使用 Obsidian 行内 `$...$`、块公式 `$$...$$`，callout 每行含 `>`。每种来源类别配简短文字说明；详细证据另放记录。

对照阶段逐项完成：

1. 从全部原图找内容，核实每个实际单元在两份正文中的去向，并补找现有清单之外的遗漏。
2. 有旧稿时从每个旧稿单元追踪新版去向；独有内容就地蓝色保留，具体错误保留旧说法与订正的对应关系。
3. 从新版全文反查来源、数学条件、量词、符号、推导和颜色类别。各重复出现、不同证明路线与图形信息分别保留。
4. 核对本轮读过的完整页区范围和冻结版本，保存开始及结束的哈希与实际发现。

## 提交本轮成果

重建角色交付完整 `source-transcript.md`、`study-notes.md` 提议稿，以及来源/旧稿映射、术语、恢复、疑点和逐区记录。修订角色交付具体改稿和影响说明。检查角色交付独立原图清单、全量范围和逐页报告、所有发现及本轮结论。

每项发现包含：任务与笔记 ID、来源页区、新版位置、问题类别、当前内容、具体建议、视觉/数学/旧稿/外部证据及尚缺条件。每个发现直接对应可执行的重辨、补写或修订动作。

报告结论按实际工作选择“全量复核且无新发现”“全量复核且有新发现”“部分复核”或“阻塞”，并列出剩余未决及未读范围。长文按段保存，最后补查跨段接缝后汇总完整范围。运行中断时交付已有正文、精确停点、有效版本和下一动作，供协调者接续。
