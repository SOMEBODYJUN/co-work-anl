## 1. 阅读前独立重建的六项义务

目标不能由改善环直接推出。至少必须证明：

1. **合法实现：** 每个玩家只有一个资源无关权重；两动作真是资源集；在每个新资源的目标负载中加入偏离者自身；系数正、有理、实际次数为 d。
2. **真实前沿端点：** 从窗口关联推出重端点、轻端点和反向偏离；相位平移必须是合法资源置换，不能擅自同时归零不同相位。
3. **所有前沿覆盖：** 任意相位向量要么有局部出口，要么累计短差通过两个 parity 的 return 出口；一条 sweep 不够。
4. **所有非前沿覆盖：** 当前非法状态中要有真实的单玩家修复；不能用多人修复后的状态成本作当前偏离成本。
5. **同次泄漏：** 修复门的总泄漏必须被同一个次数 d 压小；N、g 变大带来的全部因子均须进入预算。
6. **统一尾部：** n 随 d 变化后重新核验实际假设，尤其是二进制 ceil 在 2 的幂右侧跳升、舍入方向和 d=2^20 端点；有限可编码不能偷换为多项式规模。

## 3. 从资源侧重新推出真实费用

对相邻类 a<a+1，若重类相位为零，则 clone 0 的窗口为轻 clone 0,…,K−1。这些轻用户在线性位置中均在重用户之后，故 (J) 的 order 位和负方向位相消；当前同侧轻人数正是窗口中动作位为零的人数，给出 (L) 的 h(r)。新侧由其他用户保持不动并加入 mover 自身，故新成本是 `A_a(1+(K−h(r))/R)^d`。

backward 是重类相位减一处 forward 边的反向。归零该前驱相位后，轻类相对相位增加一，故必须用 **r+1**，不是 r−1。对整数 K<r<N，r+1≤N 且 h(r+1)=0，因此 backward 旧/新恰为 `(A_aT,A_a)`；对 N+K<r<2N，forward 的 h(r)=K 也给同一费用。两个闭短区间外的相位全部覆盖。

把轻类相位归零，其 forward mover 是 clone 0。它参加的 K 个窗口重 anchors 为 −k mod N，0≤k<K。k=0 时，全部 K 名轻用户在其当前侧；k>0 时，窗口绕线性末端，当前侧有 K−k 名轻用户。翻位后目标侧有原先另一侧的 k 名轻用户及 mover 自己，共 k+1 名。重用户是否在当前侧记为 e_k，直接给 (M)。两个轻人数序列均是 1,…,K 的排列，逐项重用户贡献至多 1，故两个端点均 ≤A_aX。backward 反向同样保留此两端上界。

共同扭转平移中，order 谓词变化是 anchor 和 user 两个 wrap 位的 xor。user 动作位的 wrap 翻转消掉 user 项，所有该 pair 用户只共同多出 anchor wrap 位；交换该 pair 的两资源即可保持负载。类内权重固定、pair 两侧延迟相同，所以旧费用与指定一次翻位后的新费用均保持。这只允许归零 mover 类相位，正文没有错误归零其他类。

相邻失配出口的其他测试干扰也已完整计入：根类只另用一个 return pair，新成本≤A_RW；中间类只另作 incoming 测试的轻用户，新成本≤A_(a−1)X。丢掉非负旧干扰费用，正好给 (N) 与根类的 3H/4。没有漏掉一个出边测试或把玩家合并。

## 4. Return 的两种 parity 与全部前沿

无邻接失配时，相位差写为 k_aN+t_a，0≤t_a≤K。求和得到 kN+t mod 2N，其中 k 是 parity，t≤gK<N；因此累计误差未跨越 N，不能仅取模后忽略 t。

末类归零后，return mover clone 0 在 anchor −k mod N 的 pair 中，k=0 时当前侧为 1，k>0 时当前侧为 0。当前同侧轻人数是 N−k，翻位后为 k+1，包括 mover 自身；故 (O) 中的 σ_0=1、其余 σ_k=0 以及两项负载均正确。e 全 1 时旧新是 (U,V)，e 全 0 时是 (V,U)；改变一位使每端费用改变至多 W。

独立逐指标计算缺陷：

| 累计 parity | 选择 | e 向量的精确缺陷 |
| --- | --- | --- |
| 偶，r=−t mod 2N | forward | t=0 时仅 e_0=0；1≤t<N 时恰 e_0,…,e_t 为零，其余为一 |
| 奇，r=N−t mod 2N | backward，读取 r+1 | t=0 时 e 全零；1≤t<N 时恰 t 个 e 为一 |

奇 parity 的 t=1 边界也正确：r+1=N，此时重类全一，只有 e_0=1。两种情况下与合适理想向量至多相差 t+1 位，故旧减 α 乘新至少为 `A_R[Z−(α+1)(t+1)W]≥3A_RZ/4`。扣除真实 incoming 新成本 ≤αA_(g−1)X 后，由 (G)、(E) 至少为 4A_(g−1)J。与失配出口合起来，每个前沿状态有一个保前沿的真实单 clone 出口，余量至少 η=θH/4。此处的分类是穷尽论证。

## 5. 非前沿的真实单人修复与同次预算

任意基体状态中，邻接 pair 潜在总负载为 `(1+θ)w_a`；对任意玩家每测试至多 K 个 pair，故每测试贡献≤KA_aT。全部邻接贡献≤gKS^(g−1)T≤gR^gT。return 每测试最多 N 个 pair，单 pair 负载≤1+1/d，故贡献≤NA_RW≤R^gT。因而 B_* 确实同时上界全部当前基体成本和全部真实偏离后的基体成本，而非只界前沿。

锚定三元 (0,i,j) 的实际资源侧为动作位 xor (0,1,0)，恰在原动作 010 或 101 时三人同侧，成本 M；未触发时最大负载 2w_a，成本≤M(2/3)^d。anchor 0 参加 L_c 对，其他 clone 参加 N−2≤L_c 对；N≥3 由 (H) 保证。

非前沿取首位 b 和最早异位 i，后面有返回 b 的 j，故当前 i 至少支付一项 M。只翻 i 回 b：i 在三元中居中时与 anchor 相同，因中位被 xor 一而不可能触发；i 居末位时，该三元的中位早于 i，按最早性也等于 anchor，仍不能触发。i 不可能是固定 anchor 0。故 i 的所有新时钟均未触发；不需要别人的新时钟也未触发，更不需要同时把全串修成前沿。其真实当前偏离余量就是 (U) 的下界。

前沿出口以新前沿为终点，故所有新时钟也未触发。两类状态的损失都被 `αL_cMζ` 控制。由 M=2αB_*，条件 (T) 确给损失≤η/2。

实际次数预算重算如下：

\[
4\alpha^2B_*L_c/\eta\le256nd^2(g+1)R^{3g}=\Gamma.
\]

`8n≤d` 给 log R≤5log d；`g+1≤14n log d≤14d log d≤d³` 在 d≥16 成立。展开 log Γ，常数项 log256≤2log d、log n≤log d、2log d、log(g+1)≤3log d 相加是 8log d；剩余 `3g log R≤195n(log d)²`。而 `8log d≤5n(log d)²`，故 (W) 的 200 常数正确。由 (A) 的严格修复条件，

\[
\zeta=(2/3)^d<\Gamma^{-1}\le\eta/(4\alpha^2B_*L_c).
\]

取倒数后的不等式方向没有反转错误。时钟系数为 M/(3w_a)^d，实际延迟仍是正有理系数乘 x^d；没有额外提高次数。

## 6. 统一尾部与最小端点

令 L=ceil(log₂d)、n=ceil(d/(1200L²))。

- d=2^20 时，L=20，`1048576>480000`，n=3，目标倍率 `1048576−480000=568576>0`。这里 α=2d/3>目标倍率；不要求二者相等。
- 幂右侧 L 立即增加，不能凭单调性略去。对 L≥21 有 d>2^(L−1)，基点 `2^20>1200·21²=529200`；`2L²≥(L+1)²` 在 L≥3 上成立，所以该整数下界向全部后续 L 传播。因而整个范围都有 x=d/(1200L²)>1。
- 所以 `x≤n≤x+1<2x=d/(600L²)`；特别 n≥2、d≥8n。`n≥x` 给 α=d−d/n≥d−1200L²，舍入方向正确。
- `log(1+1/(8n))≥1/(8n+1)`，于是 `log T≥d/(9n)≥(200/3)L²`；而 `log(16nd)<4+2L`。此估计统一给 T>16nd，完全替代旧 n² 二项式界。
- `200n(log d)²≤(d/3)(log d/L)²≤(d/3)(log2)²<d/3<d log(3/2)`。末个严格号由积分中 1/t>2/3 在 [1,3/2) 上成立得到。修复条件也统一成立。

因此 (A) 对每个整数 d≥2^20 成立。把已证明的严格 α-margin≥η/2 换为较小目标倍率，只增加 `(α−目标)C_new≥0`，严格号保持。这给要求的 ∀d∃G_d∀s∃i,t_i，而非仅子序列或固定 c 的非统一结论。

## 8. 固定 n 原定理的阈值及固定 c 推论

为精确界定同一个全状态接口的另一个已审范围，本轮也独立核验了参数族所给 `d_0(n)=max{2^20,(600n)^2}` 对 (A) 的充分性，而不是只接受其阈值声明。

固定整数 n≥2。若 d≥d_0(n)，则 d≥8n、d≥512n²。d≥4 时 `(d−1)(d−2)≥d²/4`，因而

\[
T\ge {d\choose3}(8n)^{-3}
\ge\frac{d^3}{12288n^3}\ge16nd.
\]

最后一步只需 `d²≥196608n⁴`，由 d≥512n² 保证。对 d≥2^20，`log d≤d^(1/4)`：在起点 `log d=20log2<20<32=d^(1/4)`，其差的导数在 d≥256 上非负。再由 `sqrt d≥600n`，

\[
200n(\log d)^2\le200n\sqrt d\le d/3<d\log(3/2).
\]

所以全部 (A) 成立，前面独立重建的合法实现、所有前沿、所有非前沿及实际同次证明原封适用。给任意固定 c∈(0,1)，先取整数 `n>1/(1−c)`，则 α=(1−1/n)d>cd；若将 `cd`-PNE 限于标准 α≥1 定义，只须再令 d≥ceil(1/c)。全部目标新成本非负，所以严格 α 改善蕴含严格 cd 改善。
