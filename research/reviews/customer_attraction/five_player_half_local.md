# 五人证书局部组件的独立审查

审查日期：2026-10-25。审查对象：`customer_attraction/proofs/half5_exact_v1/LOCAL_LEMMAS_ZH.md`、`MAXROOT_LEMMA_ZH.md`、`components/verify_local_components.py` 及其实际读取的七份 JSON；为核对较强末两人式，另阅读 `PROOF_ZH.md`。未修改原证明包。

## 结论及范围

在上述实际输入和所写数学模型下，未发现局部证明的致命漏洞。独立运行 `python3 components/verify_local_components.py` 正常退出：36 条局部不等式、47,872 个完整系数状态均以 Python `fractions.Fraction` 精确通过；两条 MAXROOT 界各有 56 个零余项类型，最优覆盖位 0/1 的消去亦通过。

本审查确认的是这些五人局部组件的适用条件、符号和可核验性。全局的 53 行组合及其 6,144 个外层条件需要主证书审查；本审查不单独声称已经据此证明任意人数结论。

## 逐项语义核对

1. **原节点与强制节点。** DEEP 的四条路径分别有第一可优化索引 1、3、4、2；BG2、PC2 等对应门槛同样排除了该枝被强制行动者。源行动者只通过原节点收益减去强制分支收益的比较付款。MAXROOT 中 `(T,A,B,C,D)` 的第二位和第三位分别与复制末主题 D 的真实分支比较；不会把已强制的根 T、第二位 D 或第三位 D 视作该枝的最优行动者。

2. **安全分母。** 五人第 i 位、过去负载 b 的合法比较是 `v >= Σ_H 1/(b+6−i)`。代码的局部 0 起始索引已经把固定前缀和剩余人数正确换算。未来全部允许沿原策略改变，没有把原后续行动冻结。

3. **raw 的符号。** DEEP/BG/PC 大部分 `raw` 是 `a−bound`，不是已知非负 slack：CAP 为 `|H|`（bound 为 K），IC 为“安全比较收益减真实节点收益”（bound 为 0），TRUE 为“强制分支当前者收益减源真节点当前者收益”（bound 为 0）。故 `rho = source_value + Σλ raw − gamma` 与文中的 `source + Σλ bound − Σgamma = 源IC + Σλ(bound−a)+Σrho` 一致。不能仅因 raw 的 IC/TRUE 号向下而误判。

4. **实际末位统一价格。** 对任意合法目录主题 H，实际末位的真实最优性确实给 `Σ_H 1/(1+actual_prefix_load) <= u5`。H 可以是任意离轨回复；这里只查询 H 的集合，没有把离轨玩家的实际利润写成 u5。PC2 对外部 u 列逐一检查；PC3 特别已经包含 `a3=1`，代码也只加一次源 u3。

5. **末两人税的合法性。** 固定有序前缀后，令强制 T 的真实末位回复为 R。源首位 IC、该 R 节点对 Q 的 IC、原实际末位对合法主题 R 的 IC，都是同一策略中的真实比较。由其恒等式得到更强的 `H >= f(T)+f(Q)−g(T,Q)`；LOCAL/MAXROOT 使用的两人总利润版本再减去一个非负 g，故合法。

6. **MAXROOT 的 O 行。** 五个最优索引的十个无序对求和时，每个被最优覆盖的客户选一个覆盖它的索引，含此索引的四对各贡献至少 `1/(b+1)`。因此 `(5/2)H+Σb/(b+1)−O >= 0`。原末位的五个目录比较同理给 `5v_last+Σc/(c+1)−O >= 0`。不同分支的利润始终分开保留。共同最大主题 T 满足 `|T|=K`，允许把 T 的逐客户位用于消去 K；B>0 才允许由源根 IC 替换成实际 u1，代码对此有明确检查。

7. **重复、空集及有序历史。** 独立会员位域扩大了实际可能的标签配置；相同历史应有相同回复这一约束被放松，只会使逐列证明更强。重复目录选择和最优索引没有去重。所有零分子份额直接置零，避免 0/0。K=0、空客户集和弱 IC 平局均被覆盖。

8. **向外取整。** 左侧非负收益、K 的系数上取整，右侧 gamma 下取整，方向正确；gamma 本身不需要非负。实际查询主题的标签不能因字母相同就与另一局部段的同名字母相认，文档对此已说明。

## 一个不影响现有证书的核验器加固点

`verify_priced2()` 的 `TAX` 解析分支（当前代码约第 203 行）允许任意 tag，包括 `fourth`。但 `fourth` 路径为 `(A,T,E,Q,J)`，Q 是被强制的第四位，不能对尾 `(Q,J)` 调用要求首位真实优化的末两人税。当前五份 PC2 记录**完全没有 TAX 行**，所以这不影响现有任何组件，也不是当前证明漏洞。未来扩充该 JSON 家族时宜加 `assert tag in ('init','third')`，防止解析器接受语义不合法的新记录。DEEP 的对应分支已经显式排除了强制第四位路径。

## 五人闭合的实质机制

局部层面的关键不是单独的最大根界，而是三种信息互相补足：真实深层偏离给根/前位更多控制；实际末位给所有合法隐藏回复统一定价；同一策略的复制分支把离轨尾部利润接回源真节点。局部乘子组合后对隐藏会员位取精确最小值，形成可在主证书中组合的投影切面。最终对所有外部 ui/K 列共同记账，避免把不同分支的福利各自作为实际 W 付款。

MAXROOT 的两个数值界只是严格的五人必要关系；正如其文档所述，它们单独不推出半覆盖。五人的成功是有限合法信息闭合的结果，不自动形成关于人数的归纳步骤。

## 可以直接推广的数学资产

以下陈述对任意非负整数背景负载 b、任意有限共同目录及真实末两人子局成立，与总人数无关。设尾实际主题为 C,D，定义

`f_b(X)=Σ_X 1/(b+1)`，`g_b(X,Y)=Σ_(X∩Y) 1/((b+1)(b+2))`，

`H=u_C+u_D+g_b(C,C)`。

则对任意合法 T,Q，

`H >= f_b(T)+f_b(Q)−g_b(T,Q)`。

现取任意 m≥2 个合法比较主题，每个客户的比较重数为 d。保留重叠而非先粗化，求全部无序索引对即得

`C(m,2) H >= Σ_x [(m−1)d_x/(b_x+1) − d_x(d_x−1)/(2(b_x+1)(b_x+2))]`。

这比把每对右侧仅写成两人总利润所得的式子逐客户强 `d(d−1)/(2(b+1)(b+2))`。两式对比较索引重复仍成立。进一步丢弃重数细节得到通用包络

`(m/2)H + Σ_x b_x/(b_x+1) >= |∪_{j=1}^m T_j|`。

证明逐客户下界只需 d≥1 时，上述强对和至少 `(m−1)/(b+1)`；其 d 的二次式在区间 [1,m] 为凹函数，最小值在端点，而 d=m 端点也不小于 d=1。m=1 时直接用真实末位比较。

另一个通用资产是实际末位价格：总人数 n 时，`Σ_H 1/(1+actual_prefix_load) <= u_n` 对每个合法 H 仍成立。因而“源IC + CAP + 实际末位价格 + 真后继IC，再消去隐藏会员位”的 PC 构造可对任意尾长参数化；较早前缀只需保留其负载和实际价格负载。它不要求把不同完整有序历史合并。

## 推广边界

原 JSON 的数值表和五人的分母不能直接换一个人数继续使用。可推广的是合法行构造、符号恒等式和隐藏位最小化操作；新的背景域/尾长必须重新给出全域余项或解析公式。

也不能直接把五人无背景半覆盖结论用于任意背景的“新增覆盖”。反例：既有前缀在 100 个客户上负载为 1，目录还有一个与之不交的单客户主题；最后一人选旧 100 客户收益 50，大于新客户收益 1，新增覆盖为 0，而最优新增覆盖为 1。故任意人数归纳需要携带明确的背景信用/税项；这里自然出现的 `Σb/(b+1)` 正是这样的参数。该反例不反驳原五人定理。

适合继续研究的目标是带背景信用的统一尾部不等式族及其可望远镜相加的系数，而不是声称 53 行五人证书已经证明一般 n。
