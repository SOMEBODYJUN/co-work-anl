# 反面路线两项方法边界的独立复核

审查对象：`UM-SINGLE-LAYER-QUOTA-VALUE-v1` 与 `UM-AFFINE-COMPLEMENT-CARDINALITY-BOUNDARY-v1`。本复核只检查两份自足推导的定义、量词、边界和精确审计；不把它们升级为一般近二困难性。

## 1. 单层配额超图

对评分 (b>0) 的根树，根选出的 (x) 数为 (s)，每个 (x) 必须接唯一 (e_x)，每个 (e_x) 至少接 (lceil Kb
ceil) 个资源。单父条件使资源子集互不相交；因此树给出一个 (t)-配额族并满足 (s/qge b,t/Kge b)。反向把任意不交 (t)-配额族接到根，三类正需求点的比值恰为 (
u_t/q,1,t/K)。两向均覆盖 (b=0)、空邻域、(q=1)、(K=1) 和 (|X|>q) 的截断项。

有限程序独立枚举树中的资源子集和配额族，没有调用桥梁或优化器；4788 个宇宙3、(q\le3,K\le4,|X|\le3) 实例及100个固定种子边界实例全部通过 Fraction 比较。仍未声称 (
u_t) 的一般计算复杂度或源问题 gap 存在。

## 2. 仿射互补与基数解码

在每台机器恰取 (q) 件时，(L_i=qB-\lambda u_i) 的恒等式直接成立。计数攻击取所有效用相同、(N=qm)，均匀分配的 OPT 为 (qp_0)，一台取 (q+1) 件、一台取 (q-1) 件的负载比为 ((q+1)/q)。对 (1<\rho<2)，取整数 (q\ge1/(\rho-1)) 且 (m,q\ge2) 即得 (\rho)-可行的不等基数解；(q=1) 为单独退化边界，未被该断言混用。

具体矩阵 (U=((1,1,1,1),(1,1,0,0)))、(B=1,\lambda=2/5) 给平衡 OPT (6/5)，三件溢出分配 makespan (9/5=3/2\,OPT<1.9\,OPT)，截断后原最小效用可以从源最优2降至0。这个证书只否定“近似后按数量裁剪即可解码”的接口；它不排除附加过载惩罚、槽选择器或其它归约。

`tests/audits/unrelated_machines/affine_complement_cardinality_boundary.py` 以 Fraction 复核上述比值和计数不等式。两项均保持 `UM-TARGET-v1` OPEN。
