# 门槛覆盖与 LST 正支撑释放的独立复核

本复核针对 `UM-THRESHOLD-COVER-JOINT-SLOT-v1` 的固定阈值/未知 `OPT` 接口，以及原 `UM-LST-SUPPORT-RELEASE-v0` 反例的数值修正。复核者先按精确量词重构，再读取候选正文；有限计算使用 `Fraction`，不把通过运行升级为一般定理。

## 覆盖候选

重构确认：最小覆盖 FPTAS 的输出 `X_h` 只需满足 `e_h≥d_h` 且 `e_h≤(1+η)e_h*`。它用于制造联合加权 token LP 的可行见证；实际舍入时不能把 `X_h` 当成输出任务集。输出应对流选中的 `(h,z)` 取固定顺序前缀 `Y_h`，使剩余 home 负载不超过 `τT`，于是实际出口 `e'_h≤d_h`。共同资格保证整段 `Y_h` 可送到同一个 sink；有序槽收费用 `d_h≤e_h`，故 sink 界保持有效。

发现并修正了一个原搜索论证错误：FPTAS 选择的 `e_h(t)` 不必随 `t` 单调。修正后的 one-sided 不变量为：在 promise 下，对每个网格 `t≥OPT`，固定一个真实 `OPT` 调度；其使用宏边满足 `p≤OPT≤t`，且 `p>OPT/2` 只用于证明 home 至多一个宏。由于 `τ≥1/2`，该调度的私有出口至少 `W_h−OPT/2≥W_h−τt=d_h(t)`，故当前 FPTAS 见证的加权 sink 总量不超过 `(1+η)OPT≤(1+η)t`，测试必接受。网格点 `t<OPT` 若接受，前缀恢复仍给 `R(τ)t≤R(τ)OPT`。因此以 `high` 为任意合法分配总工作量、`low=-1` 做接受/拒绝二分，不需谓词全局单调；`OPT=K/Q` 在输入分母乘积网格上，且所有 `t≥OPT` 接受，终点为某个不大于 `OPT` 的接受点。

代数复核给

`R(τ)=max{1+τ,(1+η)(2−τ+δ)}`，

`τ=((1+η)(2+δ)−1)/(2+η)`，

`R=((1+η)(3+δ))/(2+η)<2` 当且仅当 `δ+η+δη<1`。这只适用于唯一 home、共同资格、等端时间、宏/私有分组的结构类；不产生一般 `UM-TARGET-v1` 算法。

## 原支撑族修正

原 `lst_support_release_and_threshold_group.py` 的枚举输出实际为

`OPT=51/100 + 49m/(100(m+1)) = 1−49/(100(m+1))<1`，

而不是 `OPT=1`。因此旧族仍可反驳“锁定正支撑后残余小任务必可填入”的合同，但不能作为真实 `OPT=T=1` 的近二族。

独立重构的新 `UM-LST-SUPPORT-RELEASE-OPTIMAL-v1` 采用每块 `m` 核心机、一备用机、`m` 私有任务和一个单位锚任务；私有任务在其核心和备用机耗时 `1−1/m`，锚任务在全部本块机器耗时 `1`。LST 点把私有任务放核心、锚均匀分到核心，核心分数负载为1。真实最优值恰为1（锚任务下界及锚放备用机见证）。无零质量边激活时锚必落核心并与相应私有任务叠加，负载为 `2−1/m`；每块激活一条零边即可达到1。`r` 个独立块因此在至多 `k` 条零边预算下有精确前沿 `2−1/m`（`k<r`）和1（`k≥r`）。这只限制固定支撑加有限释放合同，不是一般算法困难性。

## 后续致命异议（2026-10-17）

复核后发现，前述“固定顺序前缀 `Y_h` 使实际出口 `e'_h≤d_h`”并未由剩余负载条件推出；方向通常相反，只有 `e'_h≥d_h` 是必然的。取 `T=1`、`τ=1/2`、`W_h=1`、`δ=2/5`，私有端时间按固定顺序为 `(2/5,2/5,1/5)`。此时 `d_h=1/2`，为了使 home 剩余负载不超过 `1/2`，该前缀需迁出 `4/5`；而达到 `d_h` 的最小覆盖集合可取 `(2/5,1/5)`，成本为 `3/5`。因此当前 LP 用 `e_h` 计费不能控制该实际输出前缀的 sink 成本，式 (85) 及其后的给定阈值/未知 OPT 结论尚未证明。该异议阻止把此 Claim 标为 complete；需要新的任务级 sink profile、重新选取与流耦合的输出集合，或新的预算不等式。
