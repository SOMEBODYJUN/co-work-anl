# 固定总工作量近二局部极小族的独立审查

审查对象：`UM-FIXED-WORK-CONVEX-LOCAL-MINIMUM-v1` 及其 Fraction 审计。该审查只评价单任务局部势合同，不把局部停滞升级为一般算法困难性。

## 证明重构

对 m≥3，两件 unit 和 m^2−1 件大小 1/m 的 tiny 任务使总工作量恒为 m+2−1/m。初始负载为 (2,1+1/m,...,1+1/m)。分开两件 unit，并给每台 unit 机两件 tiny，可达最大负载 1+2/m。若最大负载严格小于该值，unit 机各至多一件 tiny，其余机器各至多 m+1 件，总 tiny 容量至多 m^2−m<m^2−1，故 OPT 恒等式成立。

三类单任务动作的二次势增量分别为 2/m、2/m、2/m^2，排序负载向量也严格变差。任何负载不超过 2−epsilon 的分配必须把 unit 移出初始机器，并从其目标机至少移走 1+ceil(epsilon m) 件 tiny，所以支持至少 2+ceil(epsilon m) 件任务。取 m>4/epsilon−2 时初始比值已超过 2−epsilon。

审计用 `Fraction` 检查 m=3,4,5,8,12，并对 m=3 枚举全部分配；冻结 JSON 与脚本哈希一致。计算只验证列出的有限实例，普遍性来自计数证明。

## 结论和限制

该族关闭“保持总工作量、每步只换一件任务并严格下降固定二次势或排序势”这一局部路线；它不排无界批量、非单调过渡、输入自适应势、全局重求解或一般近似算法。两机二次势的精确全局最小化还包含 PARTITION 判定，因此全局势不能被当作免费的位多项式 oracle；这只是额外复杂度义务，不是本题新的硬度结论。`OPT=0`、不可用边和空任务不在该族中，零值分支需另行精确处理。状态为限定范围内已证明并精确审计，外部评审与新颖性未认证。
