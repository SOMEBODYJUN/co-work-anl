## 实际审查与冻结版本

函数图研究者首先提出保留纯大边环的构造；另一内部审查者先只收到“每个正阈值源至少一件eligible便有全程路径”的精确陈述，未读前者证明，自行重构出任意选边、保留所有坏环的三阶段证明。主研究者选择这条较直接的重构写正文并实现。实际最大件初态及有序槽推论也经该审查者先陈述重构，再读取全文。构造者只登记为构造者复核，不充作盲审或外部评审。

两位研究者随后实际通读规范正文与实现，主研究者核查所有机器负载、对象和原始锐例。最终微修把 padding 的不可迁移性明确写成“仅原机可用，未列端不可用”；修补后双方再次读取，均无仍成立的致命异议。

## 承重义务与攻击结果

| 义务 | 独立重构与核对 |
| --- | --- |
| 源补集为什么足够 | 对 (h_i>0\)，(h_i=A_i+(f_i+Q_i)-U\le A_i-T\)；源端剪枝 (a_j\le T\) 给 (A_i-a_j\ge h_i\)。零阈值不使用此正分支等式。 |
| 剪枝不可省 | 两机各一件源2、目标1，T1时首步需3但U2.5；它有eligible却不属剪枝输入。这一负控制阻止从旧激活总量恒等式无条件扩域。 |
| 同一坏环接收很多树的共同容量 | 每个坏环点恰有一件暂留的所选环入边 β；只要全部坏环边未迁，所有其他来流总额统一由 (S+Q-\beta<U\) 覆盖，不逐树重复花预算。 |
| 阶段顺序 | 先处理安全环且附树未进入；树再指向永久根或受保护坏环根；非所选任务全部迁完后坏环源的补集才完整移出。条件保护绝不提前写成永久激活。 |
| 实际全机输出 | 每阶段每一步的目的机不是永久安全就是受保护；源负载只减；第三阶段所有机器永久激活。每件恰一次到原给定目标，非只算估值。 |
| 无合格单件时 | 返回失败只是否定本充分条件；两机四小件/方向例仍有峰7/4路径，因此不许导出OPT>T或无路径。 |
| 实际最大件可能是固定任务 | h>0强迫S>T+f；局部promise给M≥S−T>f，而每件不动任务≤f，故最大件必改变且eligible。没有把不动任务自动当不可用迁移。 |
| 槽输出的actual-max性质 | 独立处理槽1匹配/未匹配两种分支；r≥2任务收费到不同前一满槽。由构造直接给S−M≤分数负载，不把旧support-max句子替换定义。 |
| 锐性与绕路 | 两段族均有实际初峰C；低段padding只在原机可用，故首次改变必须是指定环任务。高段同样首次迁移给U。重复、回退不能消掉第一次改变的下界。 |
| 锐性的范围 | 认证整个actual-max局部promise类、允许m=2，不声称每个固定m,n；尤其不声称这两族来自实际ST输出。实际ST输出只取得上界。C=T到另一指定目标的非空路径仍与零步到最优集合不同。 |
| 位复杂度 | 给定实际σ、τ，端点提取、有理求和比较、函数图与输出次数均多项式；没有隐藏目标oracle、数值展开或指数进展。审计枚举不属于构造。 |

## 有限检查与状态

规范 `tests/audits/unrelated_machines/held_cycle_buffer_path.py` 复用前阶段的输入/负载定义，实际检查：纯坏二环、多个树共享受保护接收点、两组优先级族、零/空/固定任务、长有理缩放、无eligible却有好路径的反向语义负控制、两段锐族的五个阈值。独立 `tests/audits/unrelated_machines/held_cycle_buffer_path_independent.py` 不导入规范程序，独立实现三阶段构造，检查两类坏环和退化域。精确参数、路径、实际峰与代码哈希均冻结。

这些有限检查只承担checks；一般结论来自正文证明。内部审查无standing fatal不等于外审认证、全球新颖性或主目标完成。

精确状态：两项给定目标的声明范围证明和实际构造完成；外审、新颖性未认证。任意剪枝初态全程路径、所有源件都小于激活阈值时的共同动作、未知目标及一般统一次二算法仍OPEN。
