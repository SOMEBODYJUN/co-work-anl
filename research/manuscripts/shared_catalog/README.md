# 双设施共同目录黄金比论文

本稿将共同目录双设施的黄金比存在与多项式构造整理成独立英文论文。当前为可编译成文稿，投稿期刊尚未确定；英文已依据Harks–Klimm (MOR 2012)的明确公开段落校准，记录见写作状态。通用排版不代表已完成目标期刊格式。

- [连续英文PDF](main.pdf)：两节主文与三个技术附录，保留完整全分支证明。
- [LaTeX主文](main.tex)、[参考文献](references.bib)：可独立构建，不依赖内部Markdown、外部图片或私有证明附件。
- [写作状态与来源](WRITING_STATE.md)：记录主人结构、命题身份、来源、已做核查及未决事项。

主文第一节介绍前人问题并给出模型；第二节定义P/E/T/C四类菜单、陈述核心覆盖引理，再用简短证明推出主定理。附录分别证明坏回应环不可能存在、局部多混合均衡以及多项式交换界。没有加入实例最优复杂度等旁支。

从本目录运行 `latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex`。本会话的TeX环境修复与实际结果见写作状态；正常安装的TeX Live无需这些临时环境设置。
