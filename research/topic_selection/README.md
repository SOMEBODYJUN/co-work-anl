# 从论文机制到可检验问题的选题地图

## Research Goal

在运筹学与优化理论内，比较原子博弈、Nash均衡、不可分物品公平分配、广义指派近似算法的候选。优先可形成独立数学增量且能在预算内验证的题；不以知名开放题的名气替代可做性，也不承诺算力能解决问题。

## Definition Map

先固定模型与输入编码，再固定均衡/公平/近似概念及量词，再识别现有定理与工具的适用条件；最后形成候选命题。Nash均衡与Nash社会福利分别定义，MaxGAP可拒绝任务与min-cost全指派分别定义，goods与chores的EFX删除方向分别定义。

## Claim Map 与状态

这里保留候选、文献问题与有限审计；没有把选题建议升级为新定理。六条原始调研在lanes/；[SELECTION.md](SELECTION.md)汇总来源、实际净增量、风险和取舍。[CLAIMS.md](CLAIMS.md)固定值得继续核验的精确候选身份；[FAILED_ROUTES.md](FAILED_ROUTES.md)记录过期题目、错误推广和停止条件。

## Dependency Graph

每个候选依次需要：精确模型 → 原始论文机制 → 当前状态核验 → 非直接推论的增量 → 首个可证引理/反例 → 构造及位复杂度 → 独立攻击。有限枚举仅检查例子，不能接成一般证明。

## Research Frontier

先把“确实尚缺”与“我们还没查到”区分；再把“能证明的常规推论”与“值得成文的新结果”区分。优先推进有公开出处且已有首个具体机制的窄题，同时留有足够重要的扩展。当前比较不采用伪精确成功概率或期刊保证。
