# 任意尾长统一正价接入另一实际源的共同投影

状态：组合合同由既有完整真实行与Main任意k正价定理直接推出；新程序已核k2完整嵌入与k3非平衡边例。当前唯一新点实验为5775上的“actual第四源k3价格→actual第三源k4初段”，theta=1/2、R/Z三轨道共六结构；不将5752旧实验负值移用。

## 1. 两个实际源与每主题独立价格

固定同一完整有序历史纯SPE。初段源为actual第i位，尚余k=7-i人；使用共同34+PAIR的两真实枝T→B,C及C→J,V，两个中间人数为s,s'，每族k-3人。其任意非负alpha合同为

    (a_T+a_C)u_i+A_alpha*u6+D_alpha*K >= sum E_alpha。

价格源另取actual第g位，尚余k_g=7-g人，背景为其前actual主题负载；使用Main已证的平衡a=M末回复折扣闭包。给每个l∈{b,c,j,v,s,ss}一套独立非负beta_l，其静态查询菜单先固定，不随被定价F改变；允许闭包每步自查询当前强制主题。由此得到

    P_l(F):=sum_x w_l,x 1_F(x) <= B_l-sum_x b_l,x，
    B_l=a_l*u_g+A_l*u6+D_l*K，
    w_l=Psi_l(1)-Psi_l(0)>=0，b_l=Psi_l(0)。

当a_l>0时w_l逐客户严格正。这里k_g可大于2，必须由真实中间人数消元后的四边和Bellman固定点求Psi_l，不使用k2特有边平衡等式。每个l都可以有不同价格、不同中间/末位费用和不同查询权。

价格静态菜单可包含当前轨道的已知R_e、Z_e、原T/B/C等。对于一个固定e，先固定这些查询标签，再对所有被定价F使用同一b_l,w_l。不同e可有不同的价格函数，但beta参数和预算系数相同；轨道归一平均仍只付一次相应预算。不能把依赖隐藏F的菜单伪装成已经固定的Q。

## 2. 完整付款与联合min

令m=(1,1,1,1,k-3,k-3)，隐藏人数h=(b,c,j,v,s,s')。给四个尾主题各用一次相应价，给每个中间主题用其族的相应价，再与初段相加，得到

    (a_T+a_C)u_i + [sum_l m_l a_l]u_g
     +[A_alpha+sum_l m_l A_l]u6
     +[D_alpha+sum_l m_l D_l]K
      >= sum_x min_hidden {
           E_alpha,x + sum_l [m_l b_l,x+w_l,x h_l] }。       (1)

证明只在每个真实合法隐藏主题上使用一次完整价格行，保持同一隐藏会员后共同取min。中间族用同价时，其全部成本为(k-3)b_l+w_l*s，不能只支付b_l一次。两个actual源收入u_i、u_g分别保留；即使源数值碰巧相同，也不将其费用无权并入一笔源预算。

发现器归一a_T+a_C=1，价格源各a_l不与此前两个源权合计归一，而在u_g账项中完整求和。所有beta_l为零时逐列恢复旧共同34+PAIR锥。

## 3. 464权的有限LP与有理复原

初段使用332个客户共用非负权。每个价格族使用22个参数：alpha_mid、alpha_last、beta_mid、beta_last、17静态查询权及1个self权；源权a_l是这18个查询权之和，直接消去。这给332+6×22=464个非负权。

在每个可见客户状态、每个价格族引入两个势U_l(0),U_l(1)，对t,c及s_price=0,...,k_g-2写

    U_l(t)-theta*U_l(c) <= H_beta_l(t,c,s_price)。

初段共同投影的信用变量z对每个隐藏赋值约束为

    z <= E_alpha +(1-theta)*sum_l[(m_l-h_l)U_l(0)+h_l U_l(1)]。

所有乘数m_l-h_l和h_l非负。给定参数的Bellman最大可行势逐坐标支配任何次解，因此优化不会因上述势写法获得超过真正闭包的信用。最终完全丢弃浮点势：恢复非负有理参数后，逐s_price精确取四条边的最小值，再用四确定平稳策略/三个有理候选求真实Psi_l，重算整个隐藏联合min。

实现 `any_tail_price_projection.py` 在每个重构状态还精确核

    (1-theta)[(a-q)/(p_g+k_g-1)+(mu_self+q)/(p_g+k_g)]
       <= Psi_l(1)-Psi_l(0)
       <= (1-theta)[(a-q)/(p_g+1)+(mu_self+q)/(p_g+2)]。

新行若负，必须重建全部4849列，包括每个hist的00基值、R/Z三非零态相对00的增量、轨道30/6归一、两actual源与末价/K的全部预算，精确点积一致后才报告。
