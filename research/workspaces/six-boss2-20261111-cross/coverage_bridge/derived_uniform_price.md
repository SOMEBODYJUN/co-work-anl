# 折扣闭包导出的统一正价格及早源付款

状态：一般价格及组合合同已证；固定theta=3/4、固定六C查询菜单的数值分离待当前独立alpha/beta扫描结束后执行。这里不会把“seed随被定价主题变化”的行当作统一价格。

## 1. 固定查询菜单与正客户价格

恰六人，固定同一完整有序历史纯SPE。actual第五位源的背景p5是前四actual主题负载，ell是前五actual主题负载。在actual前三前缀后强制六个固定合法比较主题T_i，真实第五/六位为旧B_i、旧C_i；这些旧C_i在本文始终固定。

令

    q_x=[2*1_A6(x)+sum_(i=1)^6 1_oldCi(x)]/8，
    b_x=3/[8(ell_x+1)]+1/64，
    A_x=q_x/(p5_x+1)，
    C_x=b_x+q_x/(p5_x+2)，
    D_x=1/(p5_x+1)-b_x，
    kappa_x=(3/4)(C_x-A_x+D_x)-D_x，
    s_x=A_x+min(0,kappa_x)，
    w_x=(p5_x+2-q_x)/[4(p5_x+1)(p5_x+2)]。

q是A6权1/4及每个旧C_i权1/8的合法纯查询混合，所以0<=q<=1。特别

    1/[4(p5+2)] <= w <= 1/[4(p5+1)]，                    (1)

每个客户的价格严格为正。

既有平衡k2折扣闭包的两初始位值准确为

    Psi(0)=s，Psi(1)=s+w。                              (2)

因为a0=M=1时四边代价满足e00+e11=e01+e10，且

    Psi1-Psi0=(1-theta)(C-A+D)
              =(1-theta)(p5+2-q)/[(p5+1)(p5+2)]。

上述q、s、w都只依赖固定actual与旧C菜单，不依赖以下被定价主题F。

## 2. 一笔共同价格上限，适用于目录全部主题

记

    B5=u5+(3/8)u6+K/64，
    P(F)=sum_x w_x 1_F(x)，
    Pcap=B5-sum_x s_x。

两状态闭包对每个合法初始F成立，结合(2)给

    P(F) <= Pcap，所有F in catalog。                    (3)

因此真实非负加性最大值 `max_F P(F)` 至多Pcap。Pcap由同一实际u5、u6、同一个K和同一固定客户常量组成；它不是给每条分支刷新一次的免费银行。

式(3)对任意从其它真实偏离枝取得的B、C、J、V或中间主题都可使用，因为它们都在原共同目录。即使F在分析中由sigma的某个历史产生，也不改变固定q。若改用含当前F的查询组合，必须重新给出统一性证明，不能直接沿用(3)。

## 3. 接到早期同源34+PAIR投影：每次使用都记全额

选actual早源i<=4，余k=7-i人，两真实分支T→...B,C以及C→...J,V，中间计数s_mid、s'_mid。用旧34+PAIR任意非负alpha合账，两源权和1，得

    u_i+A_alpha*u6+D_alpha*K >= sum_x E_alpha。

给四尾主题的派生价分别权gamma_b,gamma_c,gamma_j,gamma_v>=0；两中间族逐主题同价gamma_s,gamma_ss>=0。总使用次数（含权）为

    L=gamma_b+gamma_c+gamma_j+gamma_v
       +(k-3)(gamma_s+gamma_ss)。

每个合法主题价(3)按权相加，其客户成本恰为

    L*s_x+w_x[gamma_b*b+gamma_c*c+gamma_j*j+gamma_v*v
                         +gamma_s*s_mid+gamma_ss*s'_mid]。

所以严格合法的新共同投影为

    u_i+L*u5+[A_alpha+(3/8)L]u6+[D_alpha+L/64]K
      >= sum_x min_hidden {
           E_alpha + L*s_x
           +w_x[gamma_b*b+gamma_c*c+gamma_j*j+gamma_v*v
                        +gamma_s*s_mid+gamma_ss*s'_mid] }。 (4)

所有隐藏位仍在一个min中共享，尤其第一枝C与第二次源行动同身份。新增价格对s_mid只线性，而其它项仍只依赖中间人数，故16(k-2)^2原计数压缩不变。

注意actual早源u_i与actual第五收益u5是**不同钱包**。式(4)分别保它们的真实系数；不把二者都替成一个源r，也不把不同离轨源收益之和当W。总次数L必须同时乘在u5、3u6/8、K/64以及客户常量s_x上；漏任何一项都会改变价格行。

gamma全零恰退旧34+PAIR共同17查询锥，故此扩充保留旧端点。它把已经证明的目录全体主题正价用于早期隐藏回复，提供跨actual源的明确连接；是否足以支付OPT6−2W仍取决于之后共同主证书。
