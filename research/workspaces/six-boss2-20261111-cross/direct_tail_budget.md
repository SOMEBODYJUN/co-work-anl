## 1. 精确合同（先于计算冻结）

采用有限单位客户、有限非空共同**带标签**目录及完整有序历史纯 SPE。弱平局、空覆盖、同覆盖异标签、重复标签与重复行动、零客户均保留。固定 actual 前四位有序历史

\[
h=(A_1,A_2,A_3,A_4),\qquad P_x=\sum_{r=1}^4\mathbf1_{A_r}(x).

令 `A=A5,B=A6`，actual 收益 `u5,u6`。任取六个合法带索引标签 `T_i`（允许重复），严格定义

\[
S_i=\sigma_6(h,T_i),\quad
t_i=\mathbf1_{T_i},\ s_i=\mathbf1_{S_i},\quad
a=\mathbf1_A,\ b=\mathbf1_B.
\]

若 `T_i=T_j` 是同一字面标签，则 `(h,T_i)=(h,T_j)`，必须 `S_i=S_j`；仅覆盖相同的异标签不作此识别。若 `T_i=A`，则 `S_i=B`。所有 `S_i` 都是同一原目录中的真实主题；它们在另一末位节点中仅作为合法查询，不被冒充为该节点的指定后继。

记 `c=P+1≥1`、`d=P+a+1≥1`、`δ=1/((P+1)(P+2))`，并定义

\[
U(X,Y)=\sum_x\frac{\mathbf1_X(x)}{P_x+1+\mathbf1_Y(x)}.

三族完整客户和的真行是

\[
D_i:=u_5-U(T_i,S_i)\ge0,\qquad
C_i:=u_6-U(S_i,A)\ge0,
\]
\[
L_{ij}:=U(S_i,T_i)-U(S_j,T_i)\ge0.\tag{1}
\]

另有同节点对每个合法已知 `Q` 的真查询

\[
E_{iQ}:=U(S_i,T_i)-U(Q,T_i)\ge0.\tag{2}
\]

这里 `Q` 可取全部 `T_j` 和 actual 标签；式(2)不是式(1)中 `S_j` 的别名。actual `u5,u6` 必须由同一客户空间及实际 `(A,B)` 给出；以逐客户实际份额分配预算时，`a/(P+a+b)` 与 `b/(P+a+b)` 在分子零时定义为零，不计算 `0/0`。式(1)(2)的收益分母始终正。

## 2. 置换式成立，但平均恰是旧双向行之和

令 `n=Σ_i t_i`、`m=Σ_i s_i`、`k=Σ_i t_i s_i`。逐客户有

\[
\frac{s_i-s_j}{c+t_i}=\frac{s_i-s_j}{c}-\delta t_i(s_i-s_j).
\]

对任意**固定于客户之外**的排列 `π∈S6`，裸回复项消去，得到

\[
\sum_iL_{i,\pi(i)}
=\sum_x\delta_x\sum_i t_i(s_{\pi(i)}-s_i)\ge0.\tag{3}
\]

即 Main 提出的方向正确。每个排列分解成互不相交有向循环；固定点贡献零。这里逐客户成立的是等式，非每客户 IC 的非负性。

对全部 `720` 个排列均匀平均，纯计数给

\[
\mathbb E_\pi\sum_iL_{i,\pi(i)}
=\frac16\sum_{i,j}L_{ij}
=\frac16\sum_{i<j}(L_{ij}+L_{ji})
=\sum_x\delta_x\left(\frac{nm}{6}-k\right)\ge0.\tag{4}
\]

因此 `6Σ_x δk≤Σ_x δnm`，并且该**全平均**已经是十五个两节点双向查询的固定非负组合。不能把这句话扩大为“任意三环由两环推出”或“逐对边缘实现可拼成共同六节点实现”；这两种扩大均不由(4)成立。

## 3. 保 n 的精确分段 min 行

设 `D=Σ_iD_i,C=Σ_iC_i,V=Σ_{i,j}L_ij`。对每个共同参数 `η≥0` 取

\[
G_\eta=D+\frac\eta6C+\frac16V\ge0.
\]

展开(1)(4)，同索引交叠 `k` **精确**消去：

\[
G_\eta=6u_5+\eta u_6-
\sum_x\left[\frac n{P+1}+\frac m6\left(
\frac\eta{P+a+1}-\frac n{(P+1)(P+2)}\right)\right].\tag{5}
\]

在仅保 `0≤m≤6` 的放大隐藏域上，方括号关于 `m` 仿射，故其最小值恰为

\[
\Phi_\eta(P,a,n)=
\min\left\{\frac n{P+1},\frac n{P+2}+\frac\eta{P+a+1}\right\}.
\]

于是得到合法必要行

\[
\boxed{6u_5+\eta u_6\ge\sum_x\Phi_\eta(P_x,a_x,n_x),\qquad \eta\ge0.}\tag{6}
\]

这是(5)同一个旧真行组合的精确标量隐藏消元，不认领新覆盖机制。最小值的端点 `m=0,6` 在自由六位域中可取；若已知 `T_i=A` 等标签相等使某些 `s_i=b`，则(6)仍合法，但“对该更小身份域精确”不再自动成立。本稿不删去这些身份要求来声称原模型的达到性。

边界逐项明确：

- `n=0` 时 `Φ=min(0,η/d)=0`，包括 `η=0`；不删除此类客户在 actual 收益中的贡献。
- 重复 `T_i` 使 `n` 保重数而非并集数；公式仍逐索引成立。
- `P=0` 的所有分母仍正；零客户时两侧均为0。
- `η=0` 给 `6u5≥Σ n/(P+2)`，正是六个逐题最坏单后继保底之和。
- `η≥6` 时所有 `0≤n≤6,0≤P≤4` 的右端均饱和为 `Σ n/(P+1)`，而左端随 `η` 不减。因此检验全(6)可限 `η∈[0,6]`，不能直接套只适用于截断覆盖版本的 `[0,1]`。

余量 `6u5+ηu6−ΣΦη` 是凸分段仿射函数，折点为

\[
\eta=\frac{n(P+a+1)}{(P+1)(P+2)}.
\]

六人全域的不同正折点恰为 `{r/q:1≤r,q≤6}`，共23个；加0共24点。它们来自解析端点，不是网格猜测。若所有有比较覆盖的类型均 `n=1`，只剩

\[
0,\ 1/6,\ 1/5,\ 1/4,\ 1/3,\ 1/2,\ 1.
\]

## 4. 与旧覆盖价格的完全重合位置

令 `o=1_{n>0}`，旧包络阈值为

\[
\theta_\eta(P,a)=\min\{1/(P+1),\ 1/(P+2)+\eta/(P+a+1)\}.
\]

因为(6)两个分支均随 `n` 不减，`Φη≥oθη`。所以(6)推出旧覆盖行 `6u5+ηu6≥Σoθη`；二者之差是明确的非负比较重数信用 `Φη−oθη`。当 `n∈{0,1}` 时，这项信用逐客户恒为零，(6)与旧 `τ=6` 覆盖包络逐系数完全相同。

## 5. 精确未用义务：同一 m 同时进入两种真查询成本

式(2)的已知查询尚未用于(5)，也没有保留 `L_ij` 的不均匀整行权。接续必须明确这些行怎样在同一 `s_i` 上合并，不能仅说“更强联合”。本稿接着给一个逐客户可核的候选合同；不另做已由 `joint_requery` 承担的81条跨 family-state 查询，不宣称其在当前矩阵上严格分离。

具体取式(2)中的六个 `Q=T_j`，定义

\[
Y=\sum_{i,j}\bigl[U(S_i,T_i)-U(T_j,T_i)\bigr]\ge0.
\]

它与 `V` 的查询对象不同：`V` 查询真实回复菜单 `S_j`，`Y` 查询原比较菜单 `T_j`。逐客户有

\[
Y_x=\frac{6(m-n)}{P+1}+\delta(n^2-6k).\tag{7}
\]

对共同 `η≥0,0≤γ≤1`，全部真行乘子非负，故

\[
\widehat G_{\eta,\gamma}
=D+\frac\eta6C+\frac{1-\gamma}{6}V+\frac\gamma6Y\ge0.
\]

同一个 `k` 再次消去；在对**同一个** `m` 取端点前，得到

\[
\widehat G_{\eta,\gamma}
=6u_5+\eta u_6-\sum_x\left[
\frac{(1+\gamma)n}{P+1}-\frac{\gamma\delta n^2}{6}
+\frac m6\left(\frac\eta{P+a+1}-(1-\gamma)\delta n-\frac{6\gamma}{P+1}\right)
\right].
\]

因此一个准确可复用的候选必要合同是

\[
\boxed{6u_5+\eta u_6\ge\sum_x\Psi_{\eta,\gamma}(P_x,a_x,n_x),}\tag{8}
\]
\[
\Psi_{\eta,\gamma}
=\frac{(1+\gamma)n}{P+1}-\frac{\gamma\delta n^2}{6}
-\left[(1-\gamma)\delta n+\frac{6\gamma}{P+1}-\frac\eta{P+a+1}\right]_+.
\]

`n=0` 时 `Ψ` 可能负，这是合法且应保留的 actual 付款抵扣；不得沿用(6)的 `n=0→0` 而将它删去。零客户仍全部为0。已知标签相等可进一步限制 `m`，但无此细分信息时(8)只声称对自由六位/重复类的标量放大域精确，不声称全SPE达到。

两个端点都是旧对象：`γ=0` 恰为(6)；`γ=1,η=6` 恰为

\[
6(u_5+u_6)\ge\sum_x\left[\frac{2n}{P+1}-\frac{\delta n^2}{6}-6a\delta\right].\tag{9}
\]

(9)就是旧强PAIR对全部36个有序 `T_i,T_j`（含对角）求和后除6；`H=u5+u6+Σaδ`，没有新增强PAIR定理。因此这里的候选内容是**投影前合用同一回复重数**，不是重新认领两个端点。

这个共同隐藏量的作用可精确计量。固定 `η0≥0`，令 `η=(1−γ)η0+6γ`，则逐客户恒等式为

\[
\Psi_{\eta,\gamma}
=(1-\gamma)\Phi_{\eta_0}+\gamma\Psi_{6,1}+\Delta,
\]
\[
\boxed{\Delta=\min\left\{(1-\gamma)
\left[\frac{\eta_0}{P+a+1}-n\delta\right]_+,\ 6\gamma a\delta\right\}\ge0.}\tag{10}
\]

证明只须将两条仿射 `m` 成本的最小值比较。强PAIR端点的斜率总量为 `−6aδ`；旧包络端点的斜率总量为 `η0/d−nδ`。斜率同号或 `a=0` 时独立取最小不会损失；相反时两个行想取相反的 `m` 端点，共同最小比独立最小高两笔冲突额中的较小者，正是(10)。

例如在 `P=1,a=1,n=1,η0=1,γ=1/7` 上，`δ=1/6,η=12/7`，有

\[
\Phi_1=\frac12,\qquad \Psi_{6,1}=-\frac1{36},\qquad
\Psi_{12/7,1/7}=\frac{143}{252},\qquad \Delta=\frac17.
\]

独立先投影再合权只有 `107/252`，严格少 `1/7`。这是一个**单客户系数层**的共同消元严格性，既非完整实例的旧锥/新锥严格包含，也非当前必要点的负行。候选(8)可能已经由其它已保存组合查询对象覆盖；在与完整旧强PAIR和全部旧价格行公平比较之前，不认领新全局切面。仅改 `η` 的旧 `Gη` 不能产生这里的额外 `Y` 真查询项；但这一事实也不等于证明(8)在所有已知行之上独立。

### 与当前81运输工作的准确分工

本候选的唯一隐藏接口是同一 actual 第五源中六个直接回复的会员重数 `m=Σs_i`。`V`、`Y` 和 actual 报价 `C` 必须用同一批 `s_i`；不引入任何 `family-state` 边缘、既有 `R/Z` 四态边缘或跨 family 运输。81工作则对一个旧 `R/Z` 节点和既有分支状态保存共同边缘；两者不是同一运输域。

真正尚缺的是：证明(8)是否超出当前已支付的完整旧行族；若没有，给出固定非负冗余证书并停止此方向。即使有局部提升，还需将其 actual `u5,u6` 预算与早四位收益合成 `2W−OPT6` 的共同付款。任何逐客户正 `Δ`、单点系数改善或旧点违反已知81行都不能替代这一步。
