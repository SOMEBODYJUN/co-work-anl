# 加权查询标签收费的单侧一致三半逃逸

内部 scratch 候选，2026-10-19；暂 ID `UM-WEIGHTED-TWO-QUERY-LABEL-FEE-ESCAPE-DRAFT-v1`。未做独立完整攻击，未核全球新颖性，不登记、不改 canonical、frozen evidence、maps 或 git。本稿改变 guard 在共享标签机上的处理时间，另立对象；它不继承原 canonical v1 的“所选左右两个查询都外送”的强输出。

## 1. 精确加权变体

显式二部投影约束多重图 \(G=(U,V,E)\)，两侧顶点集不交。每顶点 \(v\) 有非空有限标签集 \(\Sigma_v\)，每边 \(e=(u,v)\) 有全定义投影 \(\pi_e:\Sigma_u\to\Sigma_v\)。允许平行边、孤立点、不同 alphabets 和非单射投影。

给整数 \(D\ge2\)、\(\deg(v)\le D\)；令 \(\delta=1/D\)。再给有理 \(\eta\in(0,1)\)，\(\beta=1-\eta\)。\(\eta\) 可以随待排目标改善量变化，本稿没有把它视作统一常数改善。

对每个 incidence \((e,v)\) 及每标签 \(b\in\Sigma_v\)，给**正有理数** \(a_{v,b,e}>0\)，满足逐标签预算

\[
\sum_{e\ni v}a_{v,b,e}\le1
\qquad(v\in U\cup V,\ b\in\Sigma_v).
\tag{1}
\]

只要求 (1)，不要求跨所有标签的已选查询总质量 \(\sum_b\sum_{e:\text{选 }b}a_{v,b,e}\le1\)。

不同机器名除明确共享者外互异。全部原 jobs 与全部有限端如下，未列端不可用：

| 原 job | 全部有限端与处理时间 |
| --- | --- |
| 每边 \(s_e\) | \(R_{e,a}:1\)，\(a\in\Sigma_u\) |
| 每 \((e,a)\) 的 \(x^u_{e,a}\) | \(R_{e,a}:1/2\)，\(H_{e,u,a}:1\) |
| 每 \((e,a)\) 的 \(x^v_{e,a}\) | \(R_{e,a}:1/2\)，\(H_{e,v,\pi_e(a)}:1\) |
| 每 incidence 与标签的 \(z_{e,v,b}\) | \(H_{e,v,b}:\beta\)，\(A_{v,b}:a_{v,b,e}\) |
| 每 \((v,b)\) 的 \(w_{v,b}\) | \(A_{v,b}:1\)，\(B_{v,b}:1\) |
| 每 \((v,b,r)\)，\(r\in[D]\)，的 \(f_{v,b,r}\) | \(B_{v,b}:1/D\)，\(C_{v,r}:1\) |

pool 资格严格按顶点、编号固定：\(f_{v,b,r}\) 只能去该顶点原 \(C_{v,r}\)，不能跨顶点或改编号。所有未选 state 和未选 port 的 jobs 也实际保留。完全空顶点集没有 jobs，补一台 dummy。

## 2. 待独立攻击的完整结论

对每个上述显式构造呈现，可确定性按展开矩阵总位长多项式输出**同一个完整实际调度**，其

\[
\boxed{C_{\max}\le3/2.}
\]

输出使每个左源顶点选一个统一标签，该顶点全部所选左查询都真实外送。每条边的所选右查询实际留其 root，负载 \(1+1/2\)。这不是对两个查询都必须外送的受限调度问题的上界，也没有给查询增加新的 baseline 或外加义务。

本结论不依赖任何源满足性、源 NO、PCP、未知 OPT、分数证书或所有标签总查询质量上界。尤其 \(\beta=1-\eta\to1\) 不影响这个三半构造。

## 3. 完整单侧一致构造与逐机证明

对每个左顶点 \(u\)，任选一个 \(\lambda(u)\in\Sigma_u\)。对其每条 incident edge \(e=(u,v)\)，都选 state \(a_e=\lambda(u)\)。实际安排：

1. \(s_e\to R_{e,\lambda(u)}\)。这个所选 state 的左查询 \(x^u_{e,\lambda(u)}\to H_{e,u,\lambda(u)}\)，右查询 \(x^v_{e,\lambda(u)}\) 留 \(R_{e,\lambda(u)}\)。所有未选 states 的两个查询均留自身 root。
2. 收到上述左查询的端口，其 \(z\to A_{u,\lambda(u)}\)。所有其他 \(z\) 均留各自 \(H\)。
3. 每个左顶点 \(u\)，将 \(w_{u,\lambda(u)}\to B_{u,\lambda(u)}\)，其全部 \(D\) 件 \(f_{u,\lambda(u),r}\) 分别到各自原 \(C_{u,r}\)。该顶点其余标签的 \(w\) 留 \(A\)，全部 \(f\) 留 \(B\)。
4. 每个右顶点所有标签的 \(w\) 留 \(A\)，全部 \(f\) 留 \(B\)。

这是对同一批完整原 jobs 的一次整体构造，没有把单个 query 的局部证书互相独立叠加。各左顶点整批查询共同使用一个按 (1) 预算的原 \(A\) 和一份原 pool。

| 原机器 | 完整实际负载 |
| --- | --- |
| 所选 \(R\) | selector 1 加保留的右查询 \(1/2\)，恰 \(3/2\) |
| 未选 \(R\) | 两件半长查询，恰 1 |
| 收到左查询的 \(H\) | 一件 unit 查询，恰 1；其 \(z\) 已外送 |
| 其他 \(H\) | 仅 \(z\)，负载 \(\beta<1\) |
| \(A_{u,\lambda(u)}\) | 全部 incident 左查询 guards 的总工作 \(\sum_{e\ni u}a_{u,\lambda(u),e}\le1\) |
| 其他左 \(A\) 及全部右 \(A\) | 一件 unit \(w\)，恰 1 |
| 每台左 \(B\) | 被选标签仅 \(w\)，其他标签为 \(D\) 件 \(1/D\) 的 \(f\)，均恰 1 |
| 每台右 \(B\) | \(D\) 件 \(1/D\) 的 \(f\)，恰 1 |
| 每台左 \(C\) | 来自唯一选中标签的一件 unit \(f\)，恰 1 |
| 每台右 \(C\) | 0 |

孤立左顶点也可照第3步任选一 label 打开，不会超载；亦可全部 \(w\) 留 \(A\)、\(f\) 留 \(B\)。因此完整峰值不超过 \(3/2\)。有边时本构造峰值恰 \(3/2\)，但未声称一般 actual OPT 达到它。非空无边顶点集可直接输出峰值 1；完全空图输出 0。

非单射投影只影响未外送的所选右查询指向哪个潜在 \(H\)，不造成实际冲突。所有所选左 \(H\) 按 edge incidence 区分，同端口至多一个 unit 查询。

所有循环均扫描实际显式 jobs、标签与 incidences，输出原有限端；有理加法与比较按总位长多项式。从源生成矩阵可取

\[
D=\max\bigl(\{2\}\cup\{\deg(v):v\in U\cup V\}\bigr),
\]

展开为源显式位长多项式。若另给巨大二进制 \(D\)，只承诺按已经展开矩阵位长计，不把 \(D\) 个 jobs 当作 \(\operatorname{poly}(\log D)\) 输出。

## 4. 可保留的 strict 接口及其阈值

加权变体仍有真实 \(\mathrm{OPT}\le1\) 当且仅当源 singleton 满足性（完全空图同样按无任务处理）。

YES：给满足赋值，所选 state 左右 queries 都外送，其 port guards 到各自一致标签 \(A\)；按 (1) 每个 \(A\) 接全部 incident work 仍至多 1。每顶点仅打开一致标签，全部 \(f\) 到其 pool，所有未选 jobs 留原私有端。全部机器至多 1。

反向：任意峰值至多 1 的完整实际调度中，所选 root 两查询都必须外送；因为 \(\beta>0\)，所到端口的 guard 必须离开；因为 \(a_{v,b,e}>0\)，被查询标签的 \(w\) 必须到 \(B\)；因为 \(1/D>0\)，其全部 \(f\) 必须到 unit pool。固定 pool 每顶点最多允许一标签，故读出一致满足赋值。未假设其他 jobs 的规范形。

若 \(E\ne\varnothing\)，设所有实际权重的最小值为 \(a_{\min}>0\)，并取

\[
\kappa=\min\{1/2,\beta,1/D,a_{\min}\}>0.
\]

同样对任意完整实际 \(C<1+\kappa\) 调度可作逐步反解。该阈值可能随输入变小；它不能替代统一 near-two decoder。正权假设保留了 strict 反解，但不会阻止第3节只外送一侧查询的完整三半逃逸。
