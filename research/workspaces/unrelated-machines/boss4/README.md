# boss4 的个人研究工作区

研究存档：`unrelated-machines`；身份：`boss4`。唯一主目标`UM-TARGET-v1`保持OPEN。

当前精确问题是：怎样保留不同机器集合之间的多机相关性，并在一般输入上实现统一优于2的位多项式构造？

已采用资产：[长链反例与固定机器联合投影](../../../current/unrelated_machines/long_path_coalition_gap.md)、[独立审查](../../../reviews/unrelated_machines/long_path_coalition_review.md)、[精确账本](../../../unrelated_machines/CLAIMS.md)。本文的CC_r不要求跨集合完整overlap一致性；该限制不可省略。经典两树来源保留原归属，标准耦合不声称原创。

当前卡点：完整三机交叠相容性已能解决这批树宽2反例，但没有一般图舍入/复杂度定理。单边界可解挂件可用真实最小边界负载消去；多边界不能独立取最小值，联合Pareto信息可能指数。没有理由假设一般输入的大任务都在可消去部分。

内部研究员只提供本组推导/独立攻击，由boss汇集；不作为独立Work身份、不自行推送。共享成熟资产只链接，不复制一套。

接续新增：[五机树Markov固定补全反例](../../../current/unrelated_machines/tree_markov_completion.md)。相关的q-star普通任务压缩反驳已发boss2汇入其消元资产，避免复制一套接口；公屏151为一般q证明，不能以送达当作对方已完成入库。
