# 共同前缀的截断攻击暴露：候选充分定理与试验

状态：本人推导，未非作者复核。仅六不交等大最大锚子类；不声称一般六人原题已解。

## 固定模型与已读来源

原题与定义均按本 RUN spec 精确 SHA；恰六名单位权提供者、有限单位客户、有限非空共同标签目录、全部有序历史完整纯 SPE、空覆盖/重复/弱平局全部保留。设六个合法锚覆盖 T_1,...,T_6 两两不交、|T_j|=K=max_B |B|；若 K=0 直接成立。设 B 为锚外互异非空覆盖的集合，不限制 q=|B|。

来源：正式《六不交最大锚与四种额外覆盖》§所有有序历史的归纳中的复制支付和重复攻击排除；该正文已全文实读。这里用同一个归纳但将 qK/2 全局粗界换成逐前缀截断预算。

## 量与条件

给任意有序前缀 h，当前为第 i 位，未来槽数 r=6-i。J(h) 是尚未在 h 选择过其覆盖的锚指标集；s=|J|≥7-i≥1。p_x 是 h 的真实客户负载。令 B_0(h) 是在 h 尚未出现过其覆盖的非空额外覆盖集合。

对 j∈J、F⊆B_0(h)、|F|≤r，记 n_F(x)=#{B∈F:x∈B}，定义

D_j(h,F)=Σ_{x∈T_j} (p_x+n_F(x))/(1+p_x+n_F(x)),
E_j(h)=max_{F⊆B_0(h), |F|≤r} D_j(h,F).

若对每一个合法非终局前缀 h 都有

    min_{j∈J(h)} E_j(h) ≤ K/2,                         (E)

则每份完整纯 SPE 的每个当前玩家收益都至少 K/2，因而 W≥3K=OPT6/2。

条件(E)只依原目录与前缀覆盖多重集，可枚举有限计数前缀验证。它不依某个有利的 SPE/平局选择。需要对全部前缀成立；只在 actual 前缀检查不足。

## 证明

对剩余人数反向归纳。固定任意合法前缀 h，取(E)支付的 j，并将当前行动强制成某个原标签覆盖 T_j；以后严格沿同一完整 σ 的新历史继续。

如果有后手选同覆盖 T_j，他和强制者在同一终局的收益逐客户相同。该后手的归纳收益≥K/2，直接支付强制者。

否则，在真实分枝中，某个 B∈B 若与 T_j 相交且总出现至少两次，并有一次发生在当前强制位之后，则最后一次选 B 的后手在 B 的每客份额≤1/2，在 B∩T_j 非空处份额≤1/3。其总收益严格小于 |B|/2≤K/2，违反该真实后手的归纳。故任何会伤害 T_j 的未来额外覆盖在前缀中从未出现，并在未来至多选一次。其它锚与 T_j 不交；空覆盖也不伤害。将所有这类未来覆盖收成 F，则 F⊆B_0(h)、|F|≤r，强制者准确收益为 K-D_j(h,F)（不相交的行动均不计）。于是≥K-E_j(h)≥K/2。原节点弱最优性将下界转移到规定动作。

末位 r=0 也同理；此时无后手归纳，E_j正是先前折扣。归纳保所有有序历史和任意平局。最后沿同一实际终局只对六位各求和一次。

## 可计算的更简单上界

令 P_j=Σ_{x∈T_j} p_x/(1+p_x)，以及

L_{jB}(h)=Σ_{x∈T_j∩B} 1/[(p_x+1)(p_x+2)].

对 B_0(h) 中的 L_{jB} 从大到小排序，取前 min(r,|B_0|) 个之和 H_j。因为 t/(1+t) 的后续单位增量递减，任何 F 给 D_j(h,F)≤P_j+Σ_{B∈F}L_{jB}≤P_j+H_j。故用 min_j(P_j+H_j)≤K/2 替代(E)仍充分。这个独立 top-r 上界可能松，不把它当必要条件。

也可按客户把所有潜在未来攻击数截断到 r：E_j≤Σ_{x∈T_j}(p_x+min(r,d_0(x)))/(1+p_x+min(r,d_0(x)))，d_0(x)=#{B∈B_0:x∈B}。此客户界与 top-r 界可逐锚取最小。

## 与 q=5 的首个区分试验

这条纯暴露路线故意忽略未来最佳回应，所以要先找其适用边界。最小对称压力目录：六个不交 K=5 锚，在每个锚中标出一个客户，共同组成大小5的额外主题时不能同时取六锚，故改为 q=6 个大小5的主题 B_a，分别取除第a锚以外五锚的标记客户。此类目录每锚只有一人可受额外攻击，暴露≤5/6<K/2，支持任意 q 但强交点集中。若希望 E 超半，可采用两个/多个不同标记层，使每锚潜在受攻击客户增加，同时核 max|B|=K。

更直接的 q=5 试验：K=5，五个额外覆盖分别从六锚中各取一个标记层但漏一个锚；剩余完整层用循环分配保持每个 |B|=5。应枚举其合法前缀并输出 (E)、top-r 最坏余量。若(E)在 q5 早层失败而完整 SPE 算法仍保证≥K/2，说明必须用真实后手 BR/倒三约束，而非继续压全局暴露预算；这将优先支持执行线的动态分枝路线。只构造失败(E)不反驳原题。
