# C类四轻锚共享菜单：从B框架迁移的精确映射（r2）

状态：C思路未付。本文不参与B整体证书的正式非作者审查，不修改B冻结稿或canonical。只对一个配对轨道做本线有理对偶试验，其余轨道交execution。

## 数学前提与选择量词

仍为六不交最大锚T_0,...,T_5，|T_j|=K=max|S|，q≤5种非锚互异非空覆盖，全原标签/完整有序历史纯SPE/任意弱平局。K0全零独立处理，下面K>0后统一除K作必要实质量松弛。

C的任意原有序三人前缀h覆盖多重集为一个旧锚与同一非锚E两次，标签顺序、同覆盖异标签都保留。将旧锚命名T5，其余T0,...,T4都是**新锚**。客户前缀载荷是

    p_x=1_{T5}(x)+2·1_E(x).

在五个新锚上P_j=(2/3)|E∩T_j|，Σ_jP_j≤2K/3；故至多一个j能有P_j>K/3，至少四个新锚满足P_j≤K/3，等价|E∩T_j|≤K/2。选择任意四个这类轻锚后同时重标为T0,...,T3，第五个剩余新锚为T4；**不需要T4真的重，也不把它当旧锚**。

`tail-menu-reduction-r1.md` §6已经解析证明：若C当前规定收益u4<K/2，则这至少四条轻锚强制分枝的真实末两位都为尚未出现extra中的两个不同覆盖。此结论只用正式旧末两位7K/12及同一历史真实比较，不把未付B/C当前floor当归纳前提。

若q≤4，现有正式四额外覆盖定理直接支付C当前K/2，本新计算不必处理。因此本迁移只需q恰5，E已在前缀出现，其余恰四种互异未出现额外覆盖取合法代表F0,...,F3；不添占位标签。必要客户型空间不强制各F覆盖不同，是扩大可行域的安全放松，不漏原q5目录。r1曾记录可用重复合法查询代表补槽的通用写法；r2采用此更小的正式q4归约，避免不必要占位。

## 完整客户型与载荷

类型为(block,bits)，block∈{0,...,5,outside=6}；bits=(e,f0,f1,f2,f3)∈{0,1}^5。六锚互不相交；outside只略去全0位，因为该客户不影响任何菜单收益/覆盖。总数6·32+31=223，另加gamma变量共224列。

- 六锚block各总质量1（恢复K为各K）。
- E及四F各总质量≤1。
- 四轻锚约束Σ_{block=j}e·mass≤1/2，j0..3。
- 其余新锚4不加旧锚载荷；唯一旧锚5加1；E在每块包括旧锚与outside都加2。

第j强制枝j0..3的倒二背景为

    b_x=2e_x+1_{block=5}+1_{block=j}.

固定pattern指定尾部A_j=F_a,Y_j=F_y，a≠y；每个客户对尾玩家的真实份额、当前强制锚份额均在同一客户型计算，不能分枝各有独立质量。

## 行族（与B应改之处）

1. 四强制收益w_j≤gamma，末两位u_j,v_j≥7/12。
2. 真实末位查询六个锚、E、四F全部保留；旧锚查询冗余也无妨。
3. 倒二真实H安全分母查询同一完整菜单。
4. 对每个k∈{0,...,4}\{j}，强制Tk后真末位查询其余三个新锚，给

       u_j≥1−(2/3)|E∩T_k|−(2/9)Σ_{l∈{0,...,4}\{j,k}}|E∩T_l|.

   这里s−2=3，漏掉T4会错。旧B的系数1/2、1/4不能照抄。
5. 每枝四F的16个有序(T,Q)的(TQ)容量行：u_j≥f_b(T)+U_b(Q,T)−1。b是上面的C真实背景，不能改成单E层。

同一组四轻锚可以按S4重新排序，四F可以同时重标号，所以B的1365 pair multisets/69个F置换轨道分类适用于这四个受检枝；但是B的行系数、乘子和其证明结论不能直接复用。T4作为第五新锚是一个不同的固定block，不参与四轻枝的S4，但始终参与查询。
