## 1. M 到 COMMON：需要一个新的、明确的同客户核

固定合法完整叶 F/R 和客户 x，记 `f=c_F(x)`、`b=c_R(x)`，共同 coverer 集 C 的大小为 r，新 R-coverer 集为 D，故 `b=r+|D|`。若 r=0，目标无输入，所有金额为零；否则 f、b 都正。

两叶源给出的逐客户双边项是

\[
M_{j\ell}(x)=\frac{\mathbf1_{j\in E_F(x),\,\ell\in E_R(x)}}{fb}.
\]

其完整逐客户公式使本推导不只是“两个对象都有容量”这样的主题类比。对每个共同输入 j，原 M 将请求 `λ_j(x)/f` 均分给 R 的 b 个 coverer，每人 `λ_j/(fb)`。把原来给 C 中 r 个收款人的这整块金额 `λ_jr/(fb)` 全部重新给回同一个 j，给每个 D 中收款人的 `λ_j/(fb)` 不变。这正是目标 COMMON-PROJ，而不是声称 M 本身已保角色标签。

每个输入的输出和为

\[
\frac{\lambda_j r}{fb}+|D|\frac{\lambda_j}{fb}
=\frac{\lambda_j}{f}.
\]

各项非负；共同收款人 j 只收到它自己的保留块，而新增收款人 ℓ 收到全部共同输入的和。除以 R 份额 `1/b`，精确密度为

\[
\Lambda_{j,x}=\lambda_jr/f,
\qquad
\Lambda_{\ell,x}=\sum_{j\in C}\lambda_j/f\quad(\ell\in D).
\]

若已经合并的每个 `λ_j(x)≤L_x`，两者同时不超过 `L_xr/f≤L_x`。逐客户构造后有限求和即可；若要支配每个完整 R 利润行，另需所有 `L_x≤L`。F-exclusive 角色的 incidence 没有被偷偷纳入输入。单客户限制也保持原标签，允许同覆盖异标签；这里不需要集合目录单射、不需要 SPE、更不需要逐客户改权 IC。

因此该边确实得到目标原句的任意两叶、任意客户密度、所有列同时的结论。原 M 可以更早回流，新的 COMMON 核一般也没有 future 方向；后续方向必须由共同前缀或真实 query 的额外结构证明。

## 2. COMMON 到 PUSH：原显式矩阵及价格界都可导出

取 F=W、R=B，且 `B_j=W_j` 对全部 `j<i`。对共同输入角色 j，在 `x∈B_j` 给常密度 `λ_j`；其它共同角色给零。于是 COMMON 的同角色项总额为

\[
\lambda_j\,\mathrm{base}_j,
\qquad
\mathrm{base}_j=\sum_{x\in B_j}\frac{r_x}{c_Bc_W}
=p_j(B)-N_j\ge0.
\]

新增 R-coverer ℓ 不可能小于 i：若 `ℓ<i`，两叶该标签完全相同，不能在同一客户上一有一无。因此新增总额为

\[
\sum_{j<i}\lambda_jq^+_{j\ell},
\qquad
q^+_{j\ell}=\sum_{x\in B_j\cap(B_\ell\setminus W_\ell)}\frac1{c_Bc_W},
\quad\ell\ge i.
\]

逐 j 守恒即目标原式 `p_j(W)=base_j+Σ_{ℓ≥i}q^+_{jℓ}`。COMMON 的所有列同时密度界给每个输出角色金额不超过 `L p_ℓ(B)`。在零父利润处金额为零、系数置零，其余归一得到目标确切的矩阵

\[
T_{jj}=\mathrm{base}_j/p_j(B),
\qquad T_{j\ell}=q^+_{j\ell}/p_\ell(B)\ (\ell\ge i),
\]

其它项零。令全部输入 `λ_j=1`，同一密度界给每列和 `Σ_jT_{jℓ}≤1`；一般 `κ=λT∈[0,L]^m`，且

\[
\sum_{j<i}\lambda_jp_j(W)=\sum_\ell\kappa_\ell p_\ell(B).
\]

这同时证明整组输入的守恒、原矩阵、全部列界；并非每个输入角色各取一次父钱包。每份金额只从 j 留在 j 或进 `ℓ≥i>j`。故任意非负非减 z 都有

\[
\sum_{j<i}z_j\lambda_jp_j(W)
\le\sum_\ell z_\ell\kappa_\ell p_\ell(B)
\le L\sum_\ell z_\ell p_\ell(B).
\]

取 `λ_j=1`、`z_ℓ=1_{ℓ≥k}` 得目标的完整后缀界。这里保持的是列次随机；没有行和≤1 的结论。i=1 输入为空，L=0、空主题、零客户按零约定都成立。

## 3. 祖先规范化的严格补法：三分支与有限性

固定同一完整纯 SPE σ 和严格递增栈

\[
L^0=Z,
\qquad L^r=\mathrm{finish}_\sigma(L^{r-1}_{<i_r},d_r),
\qquad i_1<\cdots<i_s.
\]

不要把“j≤最后强制位置仍须处理”写成可以一律继续 PUSH：PUSH 的输入是严格 `j<i_r`，不能接等号。对 `θu_j(L^r)` 应逐一分成：

1. **`j>i_r`：** L^r 从 i_r 之后按 σ 完成，故该金额已经是真 prescribed 利润，停止修域。
2. **`j=i_r`：** 在真实有序历史 `h=L^{r−1}_{<i_r}`，L^r 正是强制 d_r 后的原策略真实续局。令 `d=u_j(L^r)`、`v=u_j(L^{r−1})`。因为 `i_r>i_{r−1}`，parent 从该历史起的 natural 完成确实是 L^{r−1}。原 whole-IC 给 `0≤d≤v`，所以 `θd=(θd/v)v`，系数≤θ；v=0 时 d=0，删除零项。这一步没有把 d 拆成客户非负 regret，也没有购买未来强制下的假过去 IC。新的行在 parent 中位于 `j=i_r>i_{r−1}`，已真 prescribed。
3. **`j<i_r`：** 才用当前 B=L^{r−1}、W=L^r 的 PUSH。新增 recipient `ℓ≥i_r>i_{r−1}` 已在 parent 真 prescribed；同角色保留项若仍不合法，只会留一个同 j 的待处理项，并将栈深度 r 减为 r−1。

对每一条尚未终止的请求链，步骤 3 最多发生 s 次；步骤 2 直接在合法 query 处结束，步骤 1 也结束。每次 PUSH 只产生有限多个输出，并且每个输入最多有一个还须修复的同角色后继，故总输出有限。只递归未终止的严格过去请求时，其完整利润系数经过对角保留因子≤1；所以每次再次使用 COMMON 的那束待修请求仍可保原 L 上界。

这完整补足了有限域修复，但合法输出包括各祖先叶上真实 prescribed/context 的利润，而不仅是 Z 的 actual 利润。只有一直未终止的纯过去部分才最终来到 Z。也不能把多个已停止输出的系数合计后继续宣称≤L。

### 一个单栈例精确显示累计密度边界

取三人、X 含三客户、Y 含一个与 X 不交的客户，另有空主题 E。σ 在全部有序历史都选 X，是完整纯 SPE：任何 X 动作最终收益至少 `3/3=1`，Y 至多 1，E 为零。

\[
Z=(X,X,X),\quad L^1=(X,Y,X)\ (i_1=2),
\quad L^2=(X,Y,E)\ (i_2=3).
\]

对 L² 两个 prefix 角色均给 λ=1。首次 PUSH 后，L¹ 的角色 1、2、3 金额分别为 `(3/2,1,3/2)`，各完整利润系数均为 1。角色 3 已真 prescribed，停在 L¹。角色 2 是真实 query；其 `d=v=1`，给 Z 的角色 2 金额 1。角色 1 再 PUSH 到 Z，给 Z 角色 1 金额 1、角色 2 金额 1/2。最终合法表示为

\[
4=1\cdot u_3(L^1)+1\cdot u_1(Z)+\tfrac32\cdot u_2(Z)
=\tfrac32+1+\tfrac32.
\]

Z 的角色 2 合并密度已为 3/2，超过原 L=1。它来自“等号 query 输出”与“更早 prefix 的新 tail 输出”在同一合法行相遇。此例不反单步 PUSH 或有限终止；它排除将其误读成整次祖先修复共同 cap1。也说明全部输出不能在同一个 actual cap1 钱包中免费吸收，因为输入金额 4 大于 W(Z)=3。

## 4. COMMON 到 QUERY：严格后继与逐条界

对任意合法 m 槽 F、任意 j，置

\[
R=\mathrm{finish}_\sigma(F_{\le j}),\quad
V=\mathrm{finish}_\sigma(F_{<j}),\quad
H=u_j(F),\ d=u_j(R),\ v=u_j(V).
\]

F 与 R 在 j 前及 j 自身完全相同。对 `x∈F_j`，只给共同角色 j 密度 1，COMMON 得

\[
a=\sum_{x\in F_j}\frac{r_x}{c_Fc_R},\qquad
q_\ell=\sum_{x\in F_j:\ell\in E_R(x)\setminus E_F(x)}\frac1{c_Fc_R},
\quad H=a+\sum_{\ell>j}q_\ell.
\]

新 R-coverer 不可能 `ℓ≤j`，因为那里的标签在两叶相同；所以严格 `ℓ>j` 是由真实历史前缀推出，不是从一般 COMMON 的任意两叶范围附送的。

每个求和客户都有 `r_x≥1`，因而固定任一 ℓ，其 `q_ℓ` 的每个正项都≤同客户的 a 项。故是**每一条** `q_ℓ≤a`。另有 `r_x≤c_F`，所以 `a≤Σ_{x∈F_j}1/c_R=d`。同一真实历史 `F_{<j}` 的完整行动 IC 给 `d≤v`。合计得到目标确切链

\[
q_\ell\le a\le d\le v\quad\text{对每个 }\ell>j.
\]

于是 current 金额是 `(a/v)v`，系数≤1；v=0 时 a 及每个 q 都为零，系数取零。R 的所有 `ℓ>j` 利润是真规定尾的完整利润，q 为其非负子金额。F_j 为空则整个输入和输出为零。没有分客户调用 IC，也没有要求 F 本身为 SPE。

`Σq≤a` 确实不由结论推出：三人、X 为单客户并有空主题、σ 恒选 X，取 `F=(X,E,E)`、j=1，则 `R=(X,X,X)`，`H=1`、`a=1/3`、`q_2=q_3=1/3`，总未来额 2/3 大于 a。该例满足全部真实历史条件，直接固定了“逐条”的含义。

## 5. ALL 价格转移：完整目标在精确子模型与开放输入下成立

### 价格存在性供给的量词

统一价源的完整正文及同 SHA 作者原稿、独审全文已读。其精确域是有限真实集合目录；不同客户宇宙上的 Cartesian 联合主题能唯一读回坐标。现行 CAG-MODEL v1 更广，允许同覆盖异标签，不能由共享模型名自动扩张该价格等价。

固定 n≥2，`HALF(n)` 的含义是该集合目录域内全部有限实例、全部完整纯 SPE 都满足 `2W≥OPT_n`。源等价给同一实非负向量 `λ∈R_+^{n−1}`，只依 n，统一所有实例的全部末位 BR 目标 z：

\[
F_\lambda(z)=2W(z)-OPT_n+\sum_{j<n}\lambda_jg_j(z)\ge0,
\qquad g_j=M_j(z_{<j})-u_j(z).
\]

`M_j=max_A min_{真实完整子SPE}u_j`，不是原 σ 一次偏离值或删前背景门槛。源的真正承重步骤可独立重构：signed 产品在首次联合偏离时所有坐标永久同时退出到各真实最低孩子；W 和 OPT 可加；严格银行给每个 g_j≤−1；若非闭实生成锥碰开负正交，严格裕量可有理逼近并清分母成单位客户副本，编译坏 SPE；有限维开集分离再由银行排除 β=0。故 HALF(n) 供给统一实价，并可有 `Σλ≤2n−1`。此推理不依赖锥闭、有理价格或产品 M 可加。它也没有证明 HALF(n) 本身。

### 原根钱包与末位同博弈 regret

原 m 人 σ 在每个真实根主题 T 后给叶 `(T,H_T,A_T)`。删去根提供者，保留相同目录、客户及中间行动 H_T，令 `q=(H_T,A_T)`。取该删后固定历史任意末位 BR B_T，令 `q⁺=(H_T,B_T)`。原集合目录覆盖单射在删去一个玩家后保持；没有删客户、加入 T 背景或给 H_T 免费重新优化。

写 `b_x` 为 H_T 负载，

\[
f_0(X)=\sum_{x\in X}\frac1{b_x+1},\quad
f_T(X)=\sum_{x\in X}\frac1{b_x+1+1_T(x)},
\quad r_T=f_0-f_T.
\]

A_T 是 f_T 的 BR，B_T 是 f_0 的 BR，因此正确 regret

\[
0\le\ell_T=f_0(B_T)-f_0(A_T)
\le r_T(B_T)-r_T(A_T)
\le P_T=\sum_{x\in T\setminus A_T}\frac1{(b_x+1)(b_x+2)}.
\]

原根在真实叶的收益 d_T 包含这些客户各自的 `1/(b_x+1)`，而 `2/[(b_x+1)(b_x+2)]≤1/(b_x+1)`，故 `2P_T≤d_T≤u_1`。任意根主题分布 p 给 `2E_pP_T≤u_1`，只使用一次根预算。跨删前后取 `f_0(B_T)−f_T(A_T)` 不是这个 regret。

### 目标身份与不等式逐项核对

令 `n=m−1≥2` 并调用开放 HALF(n)。q 未必是 n 人完整 SPE，甚至未必末位 BR；UP 只在 q⁺ 使用。这足够，因为 UP 本来量化全部末位 BR profile，而非只量化 SPE profile。删后无需从原 σ 先构造一份新的完整均衡策略。

对每个 j<n，q、q⁺ 的精确有序前缀相同，n 人博弈和目录相同，故真正 M_j 完全不变。令 `Δ_j=u_j(q⁺)−u_j(q)`、`Ω_λ=Σ_{j<n}(2−λ_j)Δ_j`。由所有角色利润和等于覆盖，

\[
F_\lambda(q^+)-F_\lambda(q)
=2\ell_T+\sum_{j<n}(2-\lambda_j)\Delta_j
=2\ell_T+\Omega_\lambda.
\]

UP(q⁺)≥0 给 `F_λ(q)≥−2ℓ_T−Ω_λ`，再用钱包源 `ℓ_T≤P_T`，准确得到整个目标原句：

\[
\boxed{OPT_n\le2W(q_T)+\sum_{j<n}\lambda_jg_j(T)+2P_T+\Omega_\lambda(T).}
\]

此 λ 对所有 T 同时相同。一般而言，若另行直接给定满足目标精确 UP 合同的 λ，转移本身不需要 HALF(n)；HALF(n) 在本 ALL 边承担的是价存在性供给。统一价来源和钱包来源分别承担不同必要输入，两者共同列 ALL 是准确的。

没有证据可删正 Ω、把 g 截成正缺陷、设 λ 全 2、把多个根主题不带权相加或支付更早的全树修复。目标仍是条件转移；`PAY?`、六人 half、标签别名模型的无条件价存在性均没有被推出。
