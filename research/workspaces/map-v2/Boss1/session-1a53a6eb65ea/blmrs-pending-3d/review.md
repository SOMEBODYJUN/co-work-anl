## 冻结执行规则为何正好产生被否入口

§4 的调用接口明确要求 B0、I_M、I_P 两两不交。原算法先以 matroid loops 初始化 I_P，并逐个选未覆盖元素作单点 B0。对一调用，快返阈值是 e²|B0|；未快返则构造 A、C。A 的某一层秩检验只从 I_M 中扣掉**当前层** A_l，不扣先前层；小项可加性则用累计所有已建层的 2b 封顶收缩。该区别正是外层“加 a2”时每层恰选一项、但先后共选 L+1 项的依据。

四个操作按“第一个可做的操作”重复执行。因此操作 1 必须把立即可加元素穷尽后，才轮到操作 2 的 |A_I|≥e|A|；只有两者均不做且 |B|≥e|B0| 才进入操作 4。反例所用顺序符合这一规则。

本审查与两个对象一样，先采用明显的 C 印式更正：

`C = A ∪ {i∈I_M\A : f(i | 2b A)<2b} ⊆ I_M`。

未更正的印式还含 B0，会直接与 E′=E\C 冲突；这不是此处依赖的额外错误。所走非快返调用 A 都非空，因此空 A 保护不挡住本族。

冻结递归在每次操作 4 取

`B0′=B0∪B, I_M′=I_M\C, I_P′=I_P\B`，

并使旧 B0 中每项优先于新 B。子成功后更新 `I_M←C∪I_M″`、`I_P←(B\I_M″)∪I_P″`。父仅在 `|B0∩I_M″|≥e²|B0|` 时返回，否则更新 B 并继续原四操作。这些公式没有把已进入 I_M 的旧候选从 B0 删除。Lemma30 的证明只论证第3项的小项可行性，把第1项视为显然；漏掉的正是多次子调用间这种部分覆盖。

## 对 q≥16 外层可达族的解析复核

记 e=1/q、b=1、L=3q+1、Y=q+8。均匀分量的简化秩为 L+1，含 L 个 a、z、L 个 X 代表；X 用 x1 的平行副本补成 q² 项。另有 Y 个秩1的 y/u 配对分量及 {t,w} 分量。小项侧每个 a/u/u 块与每个被 c/c 阻挡的 y 块容量2，大块 X∪{t} 容量q²。所有秩和封顶余边际均可直接由分量、容量核算，无需依赖旧有限运行。

外层预备轨迹按下列事实成立：

1. 未配对 u 与所有 c 恰是初始 loops；每容量2块内初始 I_P 至多两项，因此初始化合法。先 u 后 y 的配对交换把所有 u 送入 I_P，把所有 y 送入 I_M；每次只有对应配对旧 u 满足移除秩条件。
2. L 个 X 代表先快返。每次加入后续 x1 平行副本时，只有旧平行占位者可移；大块中旧副本占用尚不足 q²，故操作1和2可以把旧占位者送入 I_P。最终 X 中 q²−L 项在 I_P，L 个不同类仍在 I_M。
3. a1 快返后均匀分量饱和。加 a2 时，每一层只能移一个旧元素：同层移去两项而只增加一个新候选会掉秩；先前层不从此层检验中删除。故 L 个旧 X 与 a1 全进 A，Y 个 y 因无本分量候选而不进 A。全部 X 的 2b 预留合法，因为 `2L=6q+2≤q²`。
4. 大块恰余 L 个 b 单位，操作1穷尽后恰将 L 个旧 X 放入 A_I；a1 仍被本块两 u 阻挡。`L≥(L+1)/q`，所以操作2先成功，把 X 全送入 I_P。剩余 a、z 和 t 均快返。此前无操作3或外层重启；允许的每次外层调用只看已覆盖元素与单点目标，丢掉未来无关元素也不改变上述秩检验。

于是最后单点目标 w 的 A=C={t}、B=X，第一次递归合法。收缩 t 后 w 成为 loop，封顶收缩 X∪{t} 后 X 的小项容量归零；这恰把该合法子调用变为附证内部反例所需结构。旧内部稿以 q²+1 个 X 类候选描述；新外层稿实际是 q² 个 X 加一个 loop w，同样大小、同样候选秩，且所需交换结果仍然存在。

第一层递归令 D0={w}∪X、s=|D0|=q²+1。先 a 后 z 的顺序给第一层 L 个 a，下一层只有 z 而被舍弃，故 A=C={a_i}、B 为2L个u。第二层候选总数 t=s+2L=q²+6q+3，其第一 addable 层是 z 加所有Y个y。逐项阈值为：

| 步骤 | 所需不等式 | q≥16 的结果 |
| --- | --- | --- |
| 第一递归保留 a 层 | L>s/q | `3q+1>q+1/q` |
| 舍弃 z 单元素后层 | 1<s/q | 成立 |
| 第一递归未在操作3失败 | 2L≥s/q | 成立 |
| 第二递归保留全层 | Y+1>t/q | `q+9>q+6+3/q` |
| z、y1、y2 立即可加后操作2成功 | 3>(Y+1)/q | `3>1+9/q` |
| 第二递归的三项输出满足成功合同 | 3>t/q² | `3>1+6/q+3/q²` |
| 回到第一递归仍不足父成功阈值 | 1<s/q² | `1<1+1/q²` |
| 父只有a1立即可加，仍不能操作2 | 1<L/q | `1<3+1/q` |
| 父仍不能操作3失败 | 2L−2≥s/q | `6q≥q+1/q` |

第二递归把 z、y1、y2 移到小项侧，按旧候选优先规则在拟阵侧放入一个 ξ∈X 及 u11、u12，总数3。父只从旧 D0 得到 ξ 一个，确实低于 `1+1/q²`；并且只 a1 块的两个 u 已释放，故 A_I 恰为{a1}，B恰剩2L−2。下一操作4仍用整个 D0∪B，而 I_M\C 已含 ξ，故交集至少{ξ}；在此构造中恰为单点{ξ}。

这证明的是“每q≥16存在实例和允许确定顺序”，足够反驳声称每个合法执行入口均不交的全称命题；没有说每个选序都会失败。任意固定较小参数上界仍包含某个1/q，因此单纯缩小 e 也不是排除论证。

反例还给阈值1全覆盖：最后外层调用前，从 I_M 移去 t、a1、y1，换入 w、任意 ξ∈X、u11；I_P 反向换回 t、a1、y1。拟阵在三个分量各一换一仍独立；小项侧在大块以t换ξ、a1块以a1换u11，并在原空y1块加y1，均合法。两集合不交且覆盖全体。因此该轨迹不是由阈值1真实不可行造成的提前合法 failure。这个见证不要求两侧都为 polymatroid 基，也不应和原资源最终每项补基混为一谈。

## 反例切断什么，保留什么

精确方向是 **obstruction refutes invariant**。反例否定按冻结公式执行时，每次递归仍满足输入不交性的普遍保证；由此冻结 Lemma30 及依赖该入口合同的完整搜索证明不能继续无条件归纳。它不直接证明不存在满足 Theorem4 比率的算法，也不否定其他修订、选择规则或独立证明的可能。因此 a3 当前 open 的登记与此证据相符，不能改成“近似存在性已 refuted”。

71b 附证中的 combined-rank 证书从一开始就明确假设 `B0,I_M,I_P` 不交，并列出 C⊆I_M、2bA可行、r(B0|C)界等不变量。它给出的证书排强可行解、直接失败证书与失败递归传递，是在这些入口和集合不交条件成立时的论证；本反例不反驳这些条件句，但阻止拿它们为当前冻结整条执行完成证明。

同样，附证递归节点数的计数明确以每子调用合法以及 Lemma32 的阻塞收缩为前提。其 s=|B0|、d=|B| 的兄弟桶比较不能用于证明反例发生后的非法调用已合法，也不能自行补回搜索正确性。

旧附证和旧收据说“该内部反例尚未证明外层可达”，作为对**旧内部构造**能力的历史描述没有错；新 c8c04a 正文已经支付其加强版本，不能把“当前还没有可达见证”继续列为数学未付义务。宜保留旧证据精确字节并用新说明绑定新可达来源，而非静默改写历史。

## 为什么资源舍入局部边仍成立

完整目标 a3 是所有合法实例的一般 `(8+ε)` 和两值 `(4+ε)` 多项式算法。边的 conditions 则明确假设中间见证已经给出，roles / scope / contribution 又明确只给 Lemma22 的最后一步，两者不能混读。

一般值入口：原资源有公共有限非负有理值；H、L为不交原项，H值至少V/(2α)、L值小于V/(2α)，α≥2。给定重项整数独立向量覆盖W；给定轻项分数独立向量在U=E\W上逐人价值至少V/α。重项独立向量补原整数基；轻项限制到U并补分数基，再用737严格舍入，得每个U玩家至少

`V/α − max_{j∈L} v_j ≥ V/(2α)`。

每轻项整数结果再在原玩家底集补原基，非负性使U收益不降；W已获一个重单位，仍至少V/(2α)。原项H、L互斥，资源没有重复使用。U为空直接完成；U非空而L空不能具有所假设正阈值见证。这是完整的给定见证后收尾证明，不需要调用规范递归。

737在这里可复用的承重理由是严格槽证明：按值降序切完整单位槽；左秩 `F(S)=Σ_j f_j(π_j(S))` 和按不同槽计容量的右coverage秩均为整数单调次模；交长分数向量饱和全槽，两polymatroid交整数性得整数饱和。投回原资源先得整数独立向量，补基不降值；非增价值阶梯的有序积分把损失限制在最大单项。混合槽/纯槽组压缩与逐坐标次模最小化补基避免二进制大秩逐单位展开。该证明没有§4的B0、A、C或递归入口合同。

另一个两值入口：已给每人值至少V的整体原资源有理分数基，且最大项w<V/α。直接舍入给

`V−w>V(1−1/α)≥V/α`，

最后一步用α≥2。这只支付该大阈值分支，不支付其他两值分支。取规范后端α=4+ε/2可解释一般2α=8+ε收尾，但构造见证的有效规范后端仍未付。

因此允许保留 accepted、conditional、contribution 与原方向737→a3；不能填成完整whole_result，不能把源737单独当作完整a3已证，也无需因不交反例撤销这项局部贡献。
