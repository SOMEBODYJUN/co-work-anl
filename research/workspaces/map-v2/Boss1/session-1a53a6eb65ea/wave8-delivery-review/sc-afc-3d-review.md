# SC保信用与AFC静态安全两条根half路线的临时3D比较

本稿只作本轮integration的外部定位，不改变已冻结的SC正式包，不新增边、对象或任务。AFC/static两个当前登记对象及正文全文、routing边和其§11证明已实读；SC端点当前版本已核，并重读其菜单定义/三门槛静态部分。实际引用及SHA在同目录`sc-afc-3d-refs.json`。本稿没有执行科学程序、求解器、LP、BI或IC重放。

两路线确实在同一个CAG模型、同一份完整原策略、同一个删当前槽菜单上相接；有精确的“整数菜单分布→平均负载→KEEP-q”映射。但当前材料不能把AFC的自由列付款与SC的自洽共同查询付款互换，也没有给两候选逻辑独立性的CAG分离反例。integration可并列保留两个具体前沿，不写“混合查询相同所以互相推出”。

## 1. 共同模型与逐点菜单身份

固定任意m≥2、有限单位客户、有限非空共同标签目录与一份全部有序历史纯SPE σ。保空覆盖、同覆盖不同标签、重复及任意离轨弱平局。根actual叶z、原根福利W=Σ_i u_i=|∪z_i|。

两源都使用actual位置i的真实前缀h_i：强制合法B，沿同一σ真实完成Z_i(B)，只删当前i槽为V_i(B)。这个V_i(B)恰有m−1个合法共同目录槽，包含不重置的过去以及该改变历史后的真实未来。两条路线的同名V不是仅相似的模型组件，而是可以逐i、B完全对应的同一个元组。

令

\[
f_C(A)=\sum_{x\in A}\frac1{1+c_x(C)},\qquad
F_p(C)=\sum_Ap_A f_C(A).
\]

原actual IC直接只给f_{V_i(A)}(A)≤u_i。查询A和生成菜单列的触发B若独立，便是另一项F_p(V_i(B))；不能用当前IC免费替换二者。

## 2. 两路线的选择器与目标金额

| 内容 | SC保信用+KEEP-q | AFC+真正静态安全值 |
|---|---|---|
| 查询选择 | 每份原σ只需存在一个适当p；p须自洽 | AFC原候选对全部查询p；half归约取静态安全最优p* |
| p如何依赖σ | p可依赖σ及它的响应矩阵K | p*可只按实例/人数选；不需要按σ选，也不要求自洽 |
| 菜单触发列 | 同一p在每个位置都作B的分布，再均匀平均位置 | 先有H_i(p)=min_B F_p(V_i(B))；对偶可给每位置各自自由ρ_i(B) |
| 响应/背景 | q(p)=Kp，μ_x(p)=(m−1)q_x(p) | 对偶得到实际整数元组分布Q_ρ，或其主题边际q_ρ；通常没有q_ρ=Kp* |
| 查询最佳性 | supp(p)⊆argmax_T g_T(μ(p))；G=M | p*对所有合法整数C保证F_{p*}(C)≥v_m；不是对某μ的g最佳性 |
| 共同付款义务 | ∃SC p：mG+(m−1)R≤2W | ∀p：Σ_iH_i(p)≤W，等价∃共同自由ρ_i使max_T E_{Qρ}f_C(T)≤W/m |
| 已得到的条件福利 | OPT≤mG+(m−1)R≤2W | W≥m v_m，OPT≤(2m−1)v_m≤(2−1/m)W |

此处SC的R=Σ_T q_Tg_T是平均负载静态信用，不是剩余玩家总利润、旧玩家份额或Σ_iH_i。SC在单个p上把覆盖成本与2W比较；AFC在全查询包络上把精确整数菜单收益与W比较。数值单位同为客户价值，不代表相同钱包已经付清。

## 3. 可以严格完成的同模型映射

为避免混用两源的q，AFC每位置触发分布记ρ_i。均匀位置质量必须保持1/m。定义实际整数背景分布

\[
 Q_\rho=\frac1m\sum_i\sum_B\rho_i(B)\,\delta_{V_i(B)}.
\]

它是真正合法m−1槽元组的分布；跨位置无须拼成同一终局，因为这里只是在有限背景集合中抽一个元组。ρ_i在查询T抽样前固定。允许任意联合分布不增加能力，因为目标只消费各位置边缘；这正是AFC正文的minimax约化。

主题槽均值与客户负载为

\[
 (q_\rho)_T=\frac1{m(m-1)}\sum_i E_{B\sim\rho_i}\#_T(V_i(B)),\qquad
 \mu_x^\rho=E_{C\sim Q_\rho}c_x(C)=(m-1)(q_\rho)_x.
\]

置h_T(ρ)=E_{Qρ}f_C(T)、g_T(μρ)=Σ_{x∈T}(1+μρ_x)⁻¹。逐客户Jensen准确给

\[
 g_T(\mu^\rho)\le h_T(\rho)\quad\text{对每个T}. \tag{J}
\]

所以若AFC共同对偶已付款，max_T h_T(ρ)≤W/m，则同一个自由平均负载有M_ρ=max_T g_T(μρ)≤W/m。KEEP-q随即还可保留

\[
 \operatorname{OPT}_m\le mM_\rho+(m-1)R_\rho
 \le(2m-1)M_\rho\le(2-1/m)W,
\quad R_\rho=\sum_T(q_\rho)_Tg_T(\mu^\rho)\le M_\rho.
\]

这是已闭合、同模型、同原菜单的代数映射。它说明AFC付款也会支付一个**自由菜单平均负载**的静态保信用式。但其背景不是已经证明具有SC见证的Kp，故不能把此M_ρ重命名成某个正式SC的G。

静态安全定理本身也由同一代数核支撑：对任意整数背景分布Q先作(J)，再对其主题边际用KEEP-q的R≤M，得OPT≤(2m−1)max_T E_Q f_C(T)，最后对Q取min得到OPT≤(2m−1)v_m。AFC路线采用独立已证的这条静态定理；SC路线保留了R并把查询限定到Kp自洽域。共有静态证明，不等于共有动态付款。

## 4. AFC为什么还没有提供正式SC付款见证

SC的自然整数菜单分布是上述自由分布的对角子族：所有ρ_i都取同一个p，记Q_p。它的平均负载正是μ(p)，主题边际正是Kp。因此共享菜单身份之外，存在严格的选择器约束：AFC允许ρ_1,…,ρ_m不同；SC的响应均值由同一个待证查询p确定，还必须有p在g(μ(p))的最大查询上支撑。

用集合表述，所有自由菜单均值组成U_free，所有对角响应均值μ(p)组成U_diag，后者包含在前者之内；SC又要求p和μ(p)同时满足最佳查询互补条件。AFC给出U_free中一个低cap点，没有证明这个低cap域与SC配对选择相交。

要把上一节AFC对偶见证直接送入强SC付款，一个充分的额外桥是找到p满足

\[
 \mu(p)=\mu^\rho,\qquad
 \operatorname{supp}p\subseteq\arg\max_T g_T(\mu^\rho).
\]

这时该p为正式SC，G=M_ρ≤W/m，甚至强付款成立。更强而易读的充分条件是q_ρ=Kp并满足该支撑条件；各ρ_i本身都等于p也足以确保响应一致，但不是最低必要条件，因为g和R只读客户均值。当前AFC来源没有给这个共同响应/自洽选择定理。

另一种容易误用的尝试是直接把AFC的∀p用于某个已存在SC p。它只给Σ_i min_B F_p(V_i(B))≤W。设

\[
 C_i(p)=E_{B\sim p}F_p(V_i(B)).
\]

确有H_i(p)≤C_i(p)，也有G(p)≤m⁻¹Σ_iC_i(p)（Jensen）。两项都位于同一个未付款的C总额之下，不能由ΣH≤W推出mG≤W，更不能直接证明所需保信用门槛。SC存在/紧性和AFC全查询量词各自真实，尚缺把低自由列选择和同p响应约束接在一起的数学。

## 5. SC保信用为什么还没有提供AFC或W≥mv_m

即便先讨论比本轮信用门槛更强的已付款SC mG≤W，已知也只是分数均值cap M=G≤W/m。对它的自然整数分布Q_p，(J)给g_T≤h_T(p)，方向不能倒用为h_T(p)≤W/m。负载方差造成的各查询Jensen缺口

\[
 J_T^{\rm ind}(p)=h_T(p)-g_T(\mu(p))\ge0
\]

没有由SC支撑等值、DIAG或强分数付款自动支付。若要以这份Q_p直接证AFC共同对偶，需要另付所有T的g_T+J_T^{ind}≤W/m；或者重新构造自由ρ_i并证明它们的精确共同cap。当前SC源没有给这一步。

本轮实际使用的保信用条件mG+(m−1)R≤2W比强SC付款还弱，允许背景信用G−R降低覆盖账单。它更没有推出整数静态值v_m≤W/m。源中已证明的是

\[
 \delta_m=\min_q\max_Tg_T(q)\le v_m,
\qquad
 \delta_m\le\min_pM(Kp)\le\min_{p\in SC}G(p).
\]

这是两个分别高于δ_m的限制值，没有提供v_m≤G(p)。故SC半覆盖推导没有经由W≥mv_m；不能从相同福利终点反向补这条强安全桥。强SC路线若成立会给与AFC相同的(2−1/m)福利系数，仍不因此证明两个预算选择器等价。

把两菜单优化值并排更清楚。令

\[
 a_\sigma=\min_{\rho_1,\ldots,\rho_m}\max_T h_T(\rho)
 =\frac1m\max_p\sum_iH_i(p),\qquad
 b_\sigma=\min_\rho\max_Tg_T(\mu^\rho).
\]

严格已得

\[
 v_m\le a_\sigma,\quad b_\sigma\le a_\sigma,\quad
 \delta_m\le b_\sigma\le\min_pM(Kp)\le\min_{SC}G.
\]

AFC是a_σ≤W/m；强SC存在是min_SC G≤W/m；本轮信用候选则是另一个SC上的mG+(m−1)R极小值≤2W。上述不等式不比较a_σ与min_SC G，也不比较a_σ与SC信用目标，不能由其中一条付款机械推出另一条。

## 6. 根、背景与共同预算的范围

两条正式half边都只输出原根命题。菜单V_i(B)中存在过去玩家，仍是原m人零外生背景游戏删一个槽后的m−1槽；这不意味着付款候选已经量化任意外生合法背景b。AFC对任意p、每个位置的自由列选择，以及SC对同p的平均响应，都以同一原根W和同一σ全部actual位置为预算。

若从一个非空h另设剩余r人局，旧负载b必须留在分母中，未来玩家总利润一般不等于覆盖，原静态OPT_m覆盖计数与根W也换了意义。现有两边没有给这种背景化付款。不能以“i的actual前缀本来非空”把它们升为∀b的全子局安全桥；也不能借PB任意背景逐步失败否定这两个根候选。

真正未付的共同预算各自明确：AFC须在位置等权下把自由菜单精确查询包络共同付到W；SC须在同p响应/自洽条件下把静态保R覆盖账单共同付到2W。原actual IC只逐角色付同一动作的真实自适应偏离收益。把互斥叶的收益、分数化产生的信用或不同查询极值同时记入同一个W，都需要额外跨历史IC证明。

m=1时两路线均直接W=OPT_1，SC池分母不使用；m=2时AFC另有单后继模块，但这不建立任意m的选择器转换。W=0全用不等式，AFC可由静态v≥0推OPT=0，SC保信用下各非负项也为0并由KEEP-q推OPT=0，均无需比值。

## 7. 本轮integration应保留的关系与缺口

1. 可以记录一个精确共同入口：两路线同σ、同实际位置、同V_i(B)、同f_C(A)。可用Q_ρ和它的均值把AFC已付对偶送入自由KEEP-q静态式；这是真实同模型映射。
2. 两条已经accepted的whole边分别保ALL：SC信用候选+KEEP-q→Q；AFC候选+真正静态安全定理→Q。它们的未证预算不能互相当作已付前提。
3. AFC到正式SC还缺自由菜单低cap与Kp自洽域的兼容选择定理；SC到AFC还缺精确整数菜单的全查询cap及Jensen缺口付款，或独立的自由列构造。
4. 对AFC→half这一次归约，实际上某个静态安全最优p*上的Σ_iH_i(p*)≤W已经足够；AFC全部p量词更强。该弱化仍没有在本比较中证明，不能从存在SC得到。
5. 当前材料没有原CAG实例把AFC与SC信用候选分离，因此这里只判“尚无互换推导/缺哪一步”，不判两命题已证互不蕴含。635坏p与16无纯SC均不提供所需分离；非CAG势例也不能承担它。
