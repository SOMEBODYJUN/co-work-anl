# 轻分量 FPT 域与站点原图 DP 域：待独立比较的证明草稿

端点为 `SC-K-FROZEN-LIGHT-FPT` 与 `SC-K-LOCAL-WEIGHT-BOX-DP`。使用同次真实规范贪心占位、同一冻结重客户及单已占选项客户、同一完整盒和全部原菜单 NE。本文是 Boss2 本轮3D发现的自足推导草稿，交后续3B实读核验，不把两个算法声明为全域等价。

## 有界轻分量域包含于原图 DP 域

活动站点原图把每名可动轻客户的完整已占菜单连成团。按轻客户连接的每个站分量若至多 c 个站，则图的每个连通分量至多 c 个顶点，取每个分量的全顶点袋即给宽至多 c−1 的树分解；分量之间可任意连接空交袋。若每分量至多 d 种精确轻权，每站的相邻轻权种数也至多 d。因此轻分量 (c,d) 域满足局部权种 DP 的 (τ,d) 域，取 τ≤c−1。

两者恢复的逐名客户归属、站内独立均匀策略、完整上下盒及扣自重不等式相同。可动客户的全部选项在本分量；冻结重客户的跨分量备选仍由完整盒给外部负载≤γ≤目的站平均负载，单选项客户自动稳定。故不会因图分解删去原动作。

支持 IP 的结论是 f(c,d)poly(L)。把 τ=c−1 代入现有计数 DP 界，只得到 poly(L)(N+1)^(4dc+c)，其指数依参数变化。这个界不能代替 FPT 结论，也不证明更快算法不存在。

## 真实规范贪心的无界长链族

对每个整数 n≥2，取 k=n、共同地点 s_1,…,s_n、δ=1/(4n)。地点 s_j 有一名仅达本站的私有客户，权

`b_j = 1 + (n−j)/(2n)`。

对每条相邻边 {s_j,s_(j+1)}，另有一名权 δ 的客户，恰可达这两站。所有客户为逐名不可拆正有理原子，标签设施显式给出。

证明规范贪心依次开 s_1,…,s_n，且每站恰一家。第 i 步前，s_i 的未覆盖候选重在 i<n 时为 b_i+δ；任何更晚的内点 s_j 的候选至多 b_j+2δ≤b_i，因为 b_(i+1)=b_i−2δ；末点候选为 1+δ<b_i（i<n）。所以当前最早未开站严格胜出。任一已开站 h 的冻结原池重是 b_h+δ，其第二家得分至多

`(b_1+δ)/2 = 3/4 − 1/(8n) < 1`，

而未开站候选始终至少 1，故不会重复插入。最后一步得分为 b_n=1，即 γ=1。此归纳也处理 n=2，无需用平局顺序。

私有权全部≥γ，均被冻结；每条边客户权 δ<γ 且有两个已占选项，均为可动轻客户。所有轻客户同权，活动站点原图恰为 n 顶点路径，树宽1、每站局部轻权种数1；但唯一轻分量含 n 个站。因此该族对固定 (τ,d)=(1,1) 始终在 B-DP 域，而轻分量站数没有统一常数上界。私有重客户的不同权值不计入局部“轻权种”参数。

这证明两个参数输入域的反向包含不成立，不是算法输出集合不等价或复杂性下界。一般盒存在性保证该真实贪心族有完整盒 NE；本文没有把初始原池分配直接当作 NE。
