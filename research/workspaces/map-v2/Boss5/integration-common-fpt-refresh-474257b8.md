## 两包的真实共同链

新父边保留

`ALL(SC-K-BOX-NE-FPT-TYPES, SC-K-GREEDY-BOX-EXISTS) ⇒ SC-K-FROZEN-LIGHT-FPT`。

类型按精确有理权和完整已占菜单分组。活动支持条件为 `y≤x≤n y`，故有客户在 s 时才激活 `q_t(W_s−w)≤q_s W_t`；减去的是一名原子的自重，全部原选项 t 均检查。分量总重给不活动行的大常数。盒不是容量，可能导致出盒的原偏离也没有从游戏中删除。

轻客户的完整菜单恰落在单一轻分量。同冻结集合的全局盒见证限制到各分量，保证各 IP 可行；各 IP 的可行解拼合，所有可动客户的比较仍完整。单选客户在本站标签间无差异。任何冻结重客户即使有跨轻分量的原备选 t，仍由

`(W_s−w_i)/q_s ≤ ((q_s+1)γ−γ)/q_s = γ ≤ W_t/q_t`

稳定。未覆盖客户无动作。因此恢复的是全部原客户及全部原允许设施动作的精确 NE，客户在所选物理站的标签设施间独立均匀。只检查可动客户或只检查本分量冻结重客户均不够，新边已经付清这一步。

每分量有 m≤c 站时，整数变量数≤`2d(c2^(c−1)−c)`；显式有理编码、清分母和逐名恢复保多项式位长/输出成本。标准固定变量 ILP 给 `f(c,d)poly(L)`。这不是任意固定占用的普遍成功算法；3-PARTITION 私有/公共原子归约没有保真实贪心承诺。新 receipt 还给出直接区分：m≥2 时首站收到全部公共物品和私有 γ，第二次在首站得分 `(m+1)γ/2>γ`，故归约的全 q=1 预设占用不可能是同输入的规范贪心输出。

三站链 HM 和 ML 菜单均非空，形成一个三站轻分量；其他纯冻结孤点保持原盒。源取 c=3，一般变量上界为 `2d(3·2²−3)=18d`。d 数这一轻分量可动客户的精确不同轻权，既不是人数，也不是冻结背景或全物理目录的权种数。同一边可混用 d 种权，因此覆盖每个固定 d 上界的整个合格三站链域，确实比旧“每条边内部同权”的域宽。

目标要求 `∃统一算法 ∃固定多项式 P ∀任意异权三站输入` 的 `P(L)` 位时间。新边付 `∃参数算法、可计算 f、固定指数 poly` 的 `f(3,d)poly(L)`，所以每个固定 d 上界有位多项式算法；d 随输入增长时不能省略 f。原整池交换证明只给可生成降势邻域和有限正确性，没有控制重复返回与总阶段数。两条近边继续保留其各自结论，不被三站新边替换。
