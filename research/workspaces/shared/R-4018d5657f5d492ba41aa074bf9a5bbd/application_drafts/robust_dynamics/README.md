新增机制是**共享系数的不确定性作为线性分式处理**，不是将已有倍率简单乘一个误差比：
多项式系数盒上每个人数插入的精确极值只需排序后O(d)个阈值顶点，且有单行支撑函数核验。
因此现有实际区间/I3合同获得精确的、位多项式的稳健版本。
任意资源整体幅度不确定性完全抵消，保留已有有限实例的改进。

动态部分利用**删除/新增资源的独占差额**：保留资源无势差，不必验证其版本或承担测量误差。
固定的参考系数势可控制对整个盒都安全的移动，即使实际系数在盒内漂移。
异步实现每玩家一个未决扫描、资源版本验证；若串行安全下降需要T次接受移动，则最多n(T+1)个菜单扫描。
接受相对势余量时可有位多项式扫描数，但输出是明示的系统归一加性遗憾/不确定性表，
不是无条件全员乘性PNE。精确β下降只保留有限终止，不制造多项式步数声明。

严格边界包括：延迟一条提交即可使两玩家精确最佳反应循环；
逐时游戏都有精确势不推出参数漂移下的逐时最佳反应收敛；
对所有参数都成立的安全移动终止，也不等于终点对所有参数均稳定。
