当前承重资产是 [结构专题](../../../current/weighted_congestion/structural_reconstruction/README.md)，不按历史概述认定证明。六名内部研究员分别研究冲突资源干预、结构化核心计算、参数不确定性、门的预算设计、积分边际校准和独立应用攻击。

## 真实前沿

1. 共同尺度失败只否定指定合同，不能推原游戏无均衡。正在研究以常数费用替换少数冲突资源，返回原游戏带明确加性遗憾的状态；需区分普通近似均衡与势局部极小的 changed-resource 合同。
2. 有限终止没有位多项式界。正在研究分离势/核心因子的低树宽计算，以及稳定预算下的社会成本选择；不能混淆类型图与玩家交互图。
3. 不确定系数的共同尺度能否不枚举盒顶点就得到稳健证书；稳定证书应对每个参数实现成立，但不同实现的停止状态不必相同。
4. 修复门的前沿税和容差都会影响决策，应在次数与峰值约束下优化，不以“惩罚足够大”代替预算。

## 已核查的小边界

一玩家，两动作都含共享资源。原共享费用0，私有动作费分别1和0；将共享资源改为常数1后，两动作成本2和1。高成本动作是2-PNE，但原动作成本1和0，故不是任何有限倍率PNE。这由Fraction精确核查。它说明：仅凭修改游戏的普通β-PNE，不能忽略保留资源产生的误差；改用势局部最小的删除/加入合同才可直接丢弃原保留资源的非正残差。不是原游戏无均衡反例。
