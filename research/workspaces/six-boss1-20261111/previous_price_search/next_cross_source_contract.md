# 若直接 OPT6 报价不分离：固定内层价格的跨源末题合同

本页只准确定位下一合同，没有新增优化扫描。直接 OPT6 的 90 案仍待 Actions 返回；本合同不预判其结果，不修改已冻结的四个计算依赖。

## 1. 内层价格必须先完整固定

选定 actual 价格源 `i`、当前初始种子、静态合法查询菜单、折扣以及全部非负内层权。Main 已证明的接口给出逐客户 `b_x,w_x` 和一个共同预算 `B_i`，满足

\[
\sum_x(b_x+w_x\mathbf1_F(x))\le B_i
\qquad\text{对目录中每个合法标签 }F,
\]

其中 `w_x≥0`，且上一主题查询权正时 `w_x>0`。这些 `b,w` 是固定函数，不再随外层未知标签 `F` 改变。特别是静态查询不能先看 `F` 再选。

## 2. 外层用同一个真实末题会员

取一个不同的 actual 源 `r`，尚余 `k_r=7−r≥2` 人；背景负载为 `p_x^(r)`。逐一强制六个比较标签 `T_j`，按原完整历史 SPE 真实续局。记其强制会员为 `y_xj`，中间 `k_r−2` 个主题总会员为 `s_xj`，真实末题为 `F_j`，会员为 `c_xj`。同一 `j` 内价格中的 `c_xj` 与源收益分母中的 `c_xj` 是同一个变量。

再固定全局非负外层权

\[
\eta,\lambda,\alpha'_m,\alpha'_l,\beta'_m,\beta'_l.
\]

置 `ell_x=Σ_{a≤5}1_Aa(x)`，以及

\[
A'_x=\beta'_m+\frac{\alpha'_m}{\ell_x+1},\qquad
B'_x=\beta'_l+\frac{\alpha'_l}{\ell_x+1}.
\]

外层同源 IC、每个真实后继主题的 actual 末价与容量、以及内层对合法末题 `F_j` 的价格界相加，得对每个合法比较索引 `j`

\[
\begin{split}
&\eta u_r+\lambda B_i+
[(k_r-2)\alpha'_m+\alpha'_l]u_6+
[(k_r-2)\beta'_m+\beta'_l]K\\
&\quad\ge
\sum_x\left[
\frac{\eta y_{xj}}{p_x^{(r)}+y_{xj}+s_{xj}+c_{xj}}
+A'_xs_{xj}+(B'_x+\lambda w_x)c_{xj}+\lambda b_x
\right].
\end{split}
\tag{C1}
\]

零分子份额为零，包括 `0/0`。外层 source 的收入是 `u_r`，内层价格 source 的收入仍完整留在 `B_i` 中；不能把两笔收入当成同一个来源。

定义每个客户的二元局部函数

\[
g_x(y)=\min_{\substack{c\in\{0,1\}\\0\le s\le k_r-2}}
\left\{
\frac{\eta y}{p_x^{(r)}+y+s+c}+A'_xs+(B'_x+\lambda w_x)c
\right\}.
\tag{C2}
\]

在 (C1) 中对同一对 `(s,c)` 逐客户取极小，再对六个合法索引平均，得到

\[
\boxed{
\eta u_r+\lambda B_i+
[(k_r-2)\alpha'_m+\alpha'_l]u_6+
[(k_r-2)\beta'_m+\beta'_l]K
\ge
\sum_x\left[
\lambda b_x+(1-d_x/6)g_x(0)+(d_x/6)g_x(1)
\right].}
\tag{C3}
\]

这里 `d_x` 只统计 `y_x1,…,y_x6` 中的 1；没有强制会员 `d_x/6`。每个真实 `F_j` 都支付相同完整预算 `λB_i`，六次求和再除六之后仍是一笔 `λB_i`，没有省略重复使用的费用。`b_x` 无需非负。

## 3. 最小可执行实例与证据范围

可首先固定已经本地精确核过的内层 `actual2 / seed A6 / theta=1/4` 权：按顺序取

\[
(\sigma,\alpha_m,\beta_m,\mu_{mean\_T},\mu_{previous})
=\frac{(928272,6180,439,60300,716)}{995907},
\]

其它内层权为零。其预算是

\[
B_2=\frac{928272u_2+18540u_6+1317K}{995907}.
\]

该价格的完整 448 型 `b,w` 已在 `smoke_actual2_seedA6/actual2_seedA6_theta1_4.json` 内独立核过。外层只取根源 `r=1`，于是 (C2) 中 `p=0`、`s=0,…,4`。只优化六个全局非负外层权并归一化总和为一；固定内层价格后，这个优化仍可用有限线性 Bellman/极小值约束表达。

这一步精确区分“上一主题直接平均报价”与“把同一正价用来约束较早源的未知真实末题”。不需要先增加新的隐藏状态列：在仅使用 actual 与比较均值的本实例里，(C3) 仍有完整 448 客户型行，投影到当前坐标后只有 `K/hist` 列可能非零。它可能弱于保留更多真实后继耦合的版本，但其预算、会员同一性与证据范围都是明确的。

若 90 案直接报价均获得精确无分离证书，这个固定内层、单一外层来源合同是一个可审的小任务；没有据此授权或启动无限权表扫描。若要同时改变内层参数，应重新处理 `w=Psi(1,t)−Psi(0,t)` 的非线性依赖，不能把固定价格的线性优化误说成整个嵌套价格锥的结论。

## 4. 独立消息核对与不能省略的相关性

`cross_root_pricing` 代理已在消息中独立核对 (C1)–(C3) 的来源收费、`k_r−2` 次中间费用、一次末题费用、`lambda*b` 在极小值之外以及同一 `c` 的符号，未发现漏项。其强调的边界是：如果以后让内层 `b,w` 含随外层索引变化的 `T_j` 或另一真实回复会员，就必须保留这些会员与 `y,c` 的联合型，不能只按 `d/6` 边缘平均。本页最小实例的内层仅含固定 actual 种子与比较菜单均值，故 `b,w` 不随 `j` 改变。

这是对合同的独立消息检查，没有新数值结果，也没有对整个跨源价格锥的完备性结论。
