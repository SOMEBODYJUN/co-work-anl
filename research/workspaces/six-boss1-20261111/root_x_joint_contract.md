## 3. 旧词级 X 质量被固定；根尾条件分布不被固定

### 3.1 不依赖独立性假设的词频恒等式

旧词为 `w_i=(t_i,b_i,c_i)`。hist h 固定 actual 六位与六旧词多重集，重数为
`n_h(w)`。现有根 μ 的归一是

\[
\mu_{h,w,s}\ge0,\qquad\sum_{s\in\{0,1\}^5}\mu_{h,w,s}=H_h
\quad(n_h(w)>0). \tag{M}
\]

它不是总量 `n_h(w)H_h/6`；后者才是一个固定有名根碰到旧词 w 的真实质量。

直接从未经平均的客户记录定义

\[
\mu_{h,w,s}=\frac1{n_h(w)}\sum_{c\in h}\sum_{i=1}^6
1_{\{w_i(c)=w,\,s_i(c)=s\}},
\]

并在该式求和中再乘同一个客户位 `z_c=1_X(c)`，定义 η。逐客户都有
`Σ_i1_{w_i=w}=n_h(w)`，故

\[
\sum_s\eta_{h,w,s}=\sum_{c\in h}z_c=x_h
\quad\text{对每一个出现的 w}. \tag{WX}
\]

这条证明没有假设 X 与旧词或根状态独立。同步 S6 只把这些平均解释为固定有名
根的边缘：`|(w_i=w,s_i=s,X=1)|=n_h(w)η_hws/6`。

更完整地，令 U 是六个有名旧词的向量，`O_h` 是其 S6 轨道。对每个原客户
平均全部 720 个排列，每个 U 的原像数都是稳定子大小，且 X 位不变。因此

\[
\rho_h(U,X=1)=x_h/|O_h|,\qquad
\rho_h(U,X=0)=(H_h-x_h)/|O_h|. \tag{U}
\]

(U) 是这个**查询平均表示**中的均匀性结论，不是原 SPE 或原客户具有随机独立性
的断言。特别不允许把 `η_hws` 强制设成 `x_h μ_hws/H_h`。

### 3.2 最小透明的根 X 新变量

对每个 38 组及全部 32 态加入一个 η，合同为

\[
0\le\eta_{h,w,s}\le\mu_{h,w,s},\qquad
\sum_s\eta_{h,w,s}=x_h. \tag{J}
\]

另保留 (M) 和 `0≤x_h≤H_h`。定义

`ν¹_hws=η_hws`、`ν⁰_hws=μ_hws−η_hws`、`H¹_h=x_h`、`H⁰_h=H_h−x_h`。

这样新增 1216 个透明质量坐标、1216 个上界与 38 个等式；非负性作用于全部 η。
每组实际有 31 个自由分配量，但显式保 32 态能避免错误删掉 `00000` 或某个零态。
若从单独的完整 X 系统出发，原根 μ 本来尚未装入，也须另接其已有合同；本页
“新增 1216”是相对于已有 μ 与 x 的接口，不声称完整矩阵已有这些 μ。

H=0 时 μ、x、η 均为零；x=0 时 η=0；x=H 时 η=μ。没有归一分母，也不删除
任一边界纤维。只给加权式 `Σ_w n_w Σ_sη/6=x_h` 会过弱：例如词重数为 1、5，
H=1、x=1/2，组 X 总量取 1、2/5 满足加权式，却违反真正的两条 (WX)。

### 3.3 这一星形边缘的共同实现范围

给定满足 (J) 的有理数，可在每个 `(h,U,z)` 上令六个有名根的状态条件分布为

\[
\Pr(s_1,\ldots,s_6\mid h,U,z)
=\prod_{i=1}^6\frac{\nu^z_{h,w_i,s_i}}{H_h^z}
\quad(H_h^z>0), \tag{GLUE}
\]

再给该纤维质量 `H_h^z/|O_h|`。零纤维直接取零。求和立即恢复 μ、η、x 和

这只是为所列**单根边缘**选择的一种存在性构造。它不声称原策略条件独立，

| 查询类别 | X=1 质量 | X=0 质量 |
| --- | --- | --- |
| actual A_i | `a_i x_h` | `a_i(H_h−x_h)` |
| 旧 T/B/C，给定其旧词 v | 相应位乘 x_h | 相应位乘 `H_h−x_h` |
| own R/Z 或 H1/H2 | 对应真实 y_Q | 原真实边缘 q_Q−y_Q |
| 根 Y_k，给定根旧词 w | `M¹_hwk=Σ_s e_k η_hws` | `M⁰_hwk=Σ_s e_k(μ−η)_hws` |
| X | x_h | 0 |

有名根 i 与一个旧索引 j 的 same/off 权分别是 1/6、1/30。分到旧词后：

\[
\omega^{same}_h(w,v)=\frac{n_h(w)}6\,1_{v=w},\qquad
\omega^{off}_h(w,v)=\frac{n_h(w)(n_h(v)-1_{v=w})}{30}. \tag{FREQ}
\]

两个不同有名根也用后一式，w=v 时仍是不同根，不能合并成 same。
对 R/Z，根索引及节点两个旧索引形成已知八种相等型。可统一定义

`ω(h,w,g;O)=该完整字面轨道 O 中产生 (w,g) 的元组数 / |O|`。

枚举完整有名元组或全部 720 个同步排列，得到同一权重。条件 root 状态、X 位
或 own 状态不改变这些词频：在固定 h、固定一个端点词后，选其它端点的数量
只是相应重数的下降阶乘。它不依赖该客户的 X 或尾态。因此每个块的两个边缘
确实分别是 ν、`q_Q^ε`，没有额外假设 root 与 own 独立。

### 5.2 根 PAIR(X,Q) 的条件排序包络

在一个源根块中，X=ε 条件质量为 `ν_s^ε`，根背景为 p(s)。逐客户恒等式是

\[
\Phi_{p(s)}(X,Q)
=\frac{\epsilon}{p(s)+1}+\frac{1_Q}{p(s)+1+\epsilon}. \tag{CP}
\]

对只知道条件查询质量 q^ε、尚未知其与源态耦合的情况，定义

\[
L_c(q;\nu)=\min_{0\le\theta_s\le\nu_s,\ \sum_s\theta_s=q}\sum_s c_s\theta_s
=\max_{\lambda\in\{c_s\}}
\left[\lambda q-\sum_s\nu_s(\lambda-c_s)_+\right]. \tag{L}
\]

取 `c_s^ε=1/(p(s)+1+ε)`。每个轨道的完整必要上包络为

\[
\mathbb E[W]-\sum_{blocks}\omega\left[
\sum_s\frac{\eta_s}{p(s)+1}
+L_{c^0}(q_Q^0;\nu^0)+L_{c^1}(q_Q^1;\nu^1)
\right]\ge0. \tag{RP-ENV}
\]

这里 `E[W]` 按该轨道完整归一，仍只是一份平均 root 源钱包。
Q 是同根 T/Y 时已有精确逐态位，须使用 RPQ，不把它再松成运输；Q 是同根 X
用 RXX。actual 或固定旧词位也是常量，可直接求值。Q 是不同根尾、R/Z/H
时使用对应条件边缘和完整 ω；每个查询位可在整目录中合法引用。

把 L 引入为辅助时，每个有限片写

`L−λq+Σ_s ν_s(λ−c_s)_+ ≥0`。

L 在主行中只有非正系数，故可统一降到规范值 (L)，保持所有行可行。
这里 c 为正价格，q=0 或零纤维的规范值均为 0；q 等于纤维总量时取全体费用。
只可合并 `(ν的符号坐标,c的完整32态向量,q的符号式)` 完全相同的 L。
该消元是所列包络的精确辅助消元；各块都取最优运输仍只给必要松弛。

### 5.3 actual RC 的条件交叠上包络

对一个 root-Y 与旧隐藏 Q、或两个不同根尾的块，令两个 X=ε 条件单边缘为
`q^ε,r^ε`。真实交叠满足

\[
I^\epsilon\le\min(q^\epsilon,r^\epsilon),\qquad
J_P(Q,R)\le\sum_{blocks}\frac{\omega}{D_P}
\left[\min(q^0,r^0)+\min(q^1,r^1)\right]. \tag{CJ}
\]

因此在 (X) 的 `a+C−B_Q−B_R+J_P(Q,R)` 中用 (CJ) 的右边，得到全域必要行。
它比直接 `min(q^0+q^1,r^0+r^1)` 至少不弱，并且保留同一 X 分层。
每个新虚拟交叠 z 只须 `0≤z≤q^ε,r^ε`；在主行系数为正，所以可统一提高到 min。

**此处 z 是新虚拟上界，不是已经通过 own 层的真实 y。** 后者已受 O1…O6
以及条件查询费用约束，不能再规范到 min。对同根两个角色、重复同标签角色、
或固定旧词位，应使用已知精确交叠；不能把同一态中 `e_l e_m` 换成一个更大 min。

单个条件块的 Fréchet 上界可达；不同块、不同查询同时可达未被证明。
这些模板因此覆盖所有 41 个 root-PAIR(X,Q) 和 360 个有序 actual 新 RC 必要
查询，但不称它们共同实现了一张跨根客户分布。

## 6. 根 η 不可逐行消元；合法的联合消元方向

η 是真实共享条件质量，既受 `Σ_sη=x_h`，又同时在 RX、RPQ、XC 等行中出现。
例如一个两态组满足 `μ0=μ1=1/2,x=1/2`；两行 `η0≥3/8`、`η1≥3/8` 各自有完成，
合起来却不可能。逐行最大化会丢掉正是本层要保存的共同 X 相关性。

若以后需要只留旧质量、μ、x、y 的投影，必须对**整组主行**取固定非负乘子 λ。
把组合中 η 的系数记为 `d_{g,s}`，其中 g=(h,w)，其余项记 A_λ。固定其余质量时

\[
M_d(x;\mu)=\max_{0\le\eta_s\le\mu_s,\ \sum_s\eta_s=x}
\sum_s d_s\eta_s
=\min_{\tau\in\{d_s\}}
\left[\tau x+\sum_s\mu_s(d_s-\tau)_+\right]. \tag{SUP}
\]

所以合法消元得到

\[
A_\lambda+\sum_g M_{d_g}(x_h;\mu_g)\ge0. \tag{PROJ}
\]

对固定 λ，(PROJ) 等价于对每组所有 τ 的组合均要求

`Aλ+Σ_g[τ_g x_h+Σ_s μ_gs(d_gs−τ_g)_+]≥0`。

这是线性必要行族。这里必须用 **max** 消去待实现 η 对正余量的贡献；直接使用
某行费用的 min 或擅自替换 η 会弄反消元方向。保留所有 λ≥0 时，由紧凸集合
与非负正交锥的分离，这一整族也给出 (J) 与所列有限主行的精确投影；只选部分
λ 则仍是必要松弛。未引入客户依赖乘子，未为每行重选 X。

β 的区间消元、虚拟 z 的单调提高、L 的单调降低、η 的联合支持函数消元是四种
不同操作，不能混用。当前冻结 full-X 的 420 个 min 仅适用其旧虚拟 y 语义。

## 7. 如需真正全根共同律，下一层必须声明什么

对固定 h，完整六根在同步 S6 下可由整数计数表 `N_{w,s}` 表示，满足
`Σ_s N_ws=n_h(w)`。若需要保所有跨根交叠，可引入符号质量

\[
\Pi_{h,z,N}\ge0,\quad \sum_{z,N}\Pi_{h,z,N}=H_h,\quad
\sum_N\Pi_{h,1,N}=x_h,
\]

\[
\mu_{h,w,s}=\frac1{n_h(w)}\sum_{z,N}N_{w,s}\Pi_{h,z,N},\qquad
\eta_{h,w,s}=\frac1{n_h(w)}\sum_NN_{w,s}\Pi_{h,1,N}. \tag{FULLROOT}
\]

这是有名 `(旧词,五尾态,X)` 完整向量的 S6 轨道表示，非逐对独立运输。
例如 `T_k(N)=Σ_ws N_ws e_k(s)`、`I_kl(N)=Σ_ws N_ws e_k(s)e_l(s)` 时，不同根的
有向交叠平均为 `(T_k T_l−I_kl)/30`，同根平均为 `I_kl/6`。
全部 cross-root 预算都必须在同一 Π 上评价，不能再分别选择各自排序。

本轮仅给这个可审核的全域定义，没有枚举该巨大状态域。即使完成 FULLROOT，
仍需与旧 R/Z/B4 等完整隐藏律、相同标签/历史的一致性联立，才涉及完整 SPE。
保留全部 32 态或全部 210 个 own 局部核，只证明各自明定层，不能越过这些义务。
