## 2. 原 kernel 字面保留和新 API

本地以下三件是冻结来源的逐字节副本：

- legacy_751_catalogue.json：原始 751 行目录；
- legacy_751_kernel.py.txt：原始 751 符号 kernel；
- legacy_243_kernel.py.txt：其原始 243 kernel。

它们只作可审计来源，本次没有执行或导入旧 kernel。新的 [symbolic_coefficients.py](symbolic_coefficients.py) 独立写出各族 Fraction 公式；它只读取本地 SHA 固定的旧行目录和 Main 的 SHA 固定 C30 表。单状态接口直接接受完整九位 atom 和四位 tail，不接受外层 q 或外层查询均值参数。

审计视图保留 legacy_index、legacy_name、旧均值标签及旧 Q 扩展标记；有效名和真实前缀中的 Q 改为 C。完整视图是 [full751_audit_view.json](full751_audit_view.json)。每条旧行的迁移理由、是否依赖外平均、目的地和可见付款均在 [migration_audit.json](migration_audit.json)；无一条 genuine kernel 因固定 C 而失效。

旧的两条外查询矩及 moment_envelope 接口不属于这 751 条 genuine kernel。删除它们不是丢弃有效预算，而是去掉已不符合新物理变量定义的平均约束。内部 C30 另有自己的六查询矩，仍由原精确表保留。

## 3. 真源和钱包的独立语义核对

各行族均逐项核对了以下范围：

- 实际第二源 IC 比较实际动作 A2 与强制合法 C 后的真实续局。强制 C 不产生新的第二源最优性。
- 生成的 R3…R6 是合法目录标签，能在原实际节点作为查询；这些查询的偏离后继由原完整策略在各自历史决定。
- ACTUAL MAX、MX、RC 始终使用原实际 P、原实际收益和原实际势最大标签 X。固定 C 不产生新 X，不赋予 C 势最大性。
- NEW SAFE 和内部 P25 的源是固定 C 后的真实第三至第六节点；P25 只用于第三、四、第五源。内部强制 T 的真尾不与外层 R 固定。
- NEW PAIR 的共同钱包属于固定 C 后的真实末两人；ACTUAL RC 的共同钱包属于原实际 u5+F_X。
- Omean 来自真实六标签均值；双均值的 30 对是异索引而非异标签。纯 C/C、R/R 等自对保留为纯同标签查询。
- C30 位序是 (a1,c,r3,r4,r5,r6,o)，符号为负 cut；其钱包使用固定 C 分支的 v3、v4、v6。C30 内部查询会员不被固定为 c。
- 完整目录标签、空覆盖、别名、重复动作、弱离轨平局均保留。覆盖相等不用于推断标签相等。

## 4. 前端 17 行没有被错误称为冗余

[visible_prerequisite_routing.json](visible_prerequisite_routing.json) 保存每条公式的全局名字、原始索引、付款乘子、规范化字面行 SHA 和全部 513 列身份检查。参考输入只提供公式，未提供旧数值点。

纯可见的 9 条 ACTUAL_RC(C,T)、1 条 FMAX_C、1 条 MX_C 和 5 条 SAFE_i_C 构成 16 个显式前置。CAP(C) 由全局等式 \(\sum c\,w-K=0\) 的 −1 倍支付。它不授权任何 C 势值最大化。

734 条局部行保留原顺序和全部零/重复 kernel，记录在 [active734_catalogue.json](active734_catalogue.json)。删除 17 个局部位置仅是前端/隐藏变量分工，不是 734 行推出其他 17 行的证明。未来点释放必须再次确认这些 16 个具体预算及 C 等式，不能只凭旧文件中曾存在同名行。

物理实例中，七单点目录提供完整纯 SPE，并同时包含 C 不覆盖 O 内客户、C 覆盖 O 外客户两种情况，所以不能将旧外矩的任一侧用于固定 C。一个客户的别名/空标签实例保留菜单重复和真实标签身份；零客户实例覆盖零边界。它们没有绑定此前任何 LP 点，也没有被用作未来输入。

另以一个 NEW_SAFE_j5(R5) 的单位权，直接得到全零可见型的质量乘子 m=−1/2；在故意不满足质量等式的代数代入上验证完整付款身份，确认自由乘子的符号方向正确。此代数检查不是声称该代入为可行客户分布。

本次没有生成全 751×8192 稠密矩阵，也不声称对此不存在的矩阵做了完整回放。751 行的迁移有效性由实读来源、真实历史量词和显式状态双射证明；直接检查的数量如实列于上表。

## 6. 未绑定边界与后续使用

[symbolic_template.json](symbolic_template.json) 和 [future_point_release_template.json](future_point_release_template.json) 保持所有候选绑定字段为 null。没有数值质量、K/O、支持、固定矩阵、phase I、候选权或求解器授权。旧 1002/1003 候选已经有更廉价整面排除，不具备此模板的待绑定资格。

未来固定点必须先经 Main 指定的新必要族筛选并单独释放。若该点有 s 个正完整类型，物理合同为 16s 非负列、s 个质量等式、734 个隐藏不等式、0 个外矩；16 条全局前置及 C 等式另行确认。任何普遍投影必须完整覆盖全部 512×16 状态并保留自由质量乘子。

当前结果只是符号必要合同，不是固定点可行/不可行证书，不是完整 SPE 实现，也不是新的福利下界。原六人半覆盖命题仍 OPEN。
