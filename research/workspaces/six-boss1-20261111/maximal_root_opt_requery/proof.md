# 根 C 分支的第三源最优菜单重查：精确不可补全与全 128 型切面

Boss1；RUN `six-boss1-20261111`。本轮只写新目录与相邻摘要，已完成的 `maximal_root_tail_wallet/` 保持冻结。仅一次局部 phase-I 发现，之后全部为精确线性代数与 Fraction 检查。

## 1. 结论

`maximal_root_tail_wallet/` 的精确 10 正原子点，**不能补成所指定第三源对六个合法最优标签的平均真实重查层**。输入原证书 SHA 为 `80d9267b6ed9b5e47c4f8ea92523aaf1e73754eb28416e4117f8db754b88d771`，原输入 SHA 为 `3c1a824ed0a17562da812db1d0bb12485f0b1c7f743577af7bc2ecf316d3ab65`，Main 的独立检查已释放此点。

同时得到对全部 128 个原根分支类型有效的普遍必要切面

\[
\boxed{126000v_3+65719v_4+4962v_6
       -\sum_{h\in\{0,1\}^7}m(h)w_h\ge0.}
\tag{CUT}
\]

这里 v3、v4、v6 是同一原真实根 C 分支的收益，w_h 是其原子质量；m 的完整有限公式见第 4 节。K 和 actual 根 u 的系数均为零。

指定释放点上，左端恰为

\[
\boxed{-\frac{26828130879519777790818450922693961}
{16138758469380629653371589538760}}
=-1662.341680769288\ldots<0.
\tag{SEP}
\]

此结论是固定点的精确不可补全和普遍有效的投影切面，不是完整 SPE 反例，不是最锐全局根线，也不证明 half。未从一个点的排除推断整个旧最优面被排除。

## 2. 必须保持的真实角色与矩区间

原根 C 真分支为 `(C,B2,B3,B4,B5,B6)`。对每个客户保留原类型

\[
h=(p,y_2,y_3,y_4,y_5,z,o).
\]

六个合法最优标签记为 Q1,...,Q6，o 是它们覆盖并的会员。分别在**同一个真 source-3 历史 `(C,B2)`**强制 Q_k，沿原完整策略继续为 `(R4_k,R5_k,R6_k)`。新变量

\[
\nu_{h,q,r,y,t}\ge0
\]

是这六个真实分支的 1/6 平均，其中 q 是产生该分支的同一个 Q_k 的会员，r,y,t 是该分支自己的 R4_k,R5_k,R6_k 会员。

记 `r_h^Q=Σ_{r,y,t}ν[h,1,r,y,t]`。每个原型都满足

\[
\sum_{q,r,y,t}\nu_{h,q,r,y,t}=w_h,
\qquad \frac{o_hw_h}{6}\le r_h^Q\le o_hw_h.
\tag{M}
\]

区间来自真实菜单重数 d∈{1,...,6}，没有假设六个最优标签不交叠；o=0 时 q 质量必须为零。ν 已经含外层六分支平均，来源 IC、尾大小帽和旧源 SAFE 不再额外除 6。Omean 的内层六查询仍有自己的 1/6。

点上 10 个正原型给 **160 个 ν 变量、10 条质量式、20 条矩上下界**。121 条真预算全部保留：

| 真预算 | 原始行数 |
|---|---:|
| 旧真 source 3 对六个 Q_k 的平均 IC | 1 |
| 三个新尾的平均 K 大小帽 | 3 |
| 旧根 C 分支 sources 2–6 查询三个新尾平均的 SAFE | 15 |
| 原 actual 根 u 对三个新尾平均的大小/6 地板 | 3 |
| 新分支 sources 4–6 各查询 11 个角色的 SAFE | 33 |
| 新真末两位对同 11 个角色的完整 PAIR | 66 |
| **真预算合计** | **121** |

加矩界共 **141 原始不等式**。11 个查询角色为旧六纯标签 C,B2,...,B6、同一个 Q、同支 R4,R5,R6、Omean。NEW_SAFE6(R6) 的零行与 15 个固定点仿射重复全部保留。

所有行的付款在优化前写入 [derivation.md](derivation.md)。特别是 old B3 始终使用旧会员 y3，Q 始终使用新位 q；新末两位的真前缀是 `(C,B2,Q_k,R4_k)`。PAIR(Q,Omean) 的交叠是 `q*o/6`，没有假设独立。PAIR(Omean,Omean) 在每个外层分支内部平均完整 36 个有序查询对，再弱化为 `o/36`，随后平均外层六分支。

\[
A_R\nu\le b_R(w,K,u),\qquad R=b_R-A_R\nu\ge0.
\]

以下九个整数权均非负；其余真预算的权为零。

| 真预算 | 整数权 |
|---|---:|

| 旧 source4 SAFE(R4) | 43 |
| 旧 source4 SAFE(R5) | 31218 |

| 旧 source6 SAFE(R4) | 1654 |

| 新真末两位 PAIR(Omean,Omean)，完整 36 配对 | 7740 |

B(w)=126000v_3+65719v_4+4962v_6.
\]

这里的新尾既是各 Q_k 真偏离产生的后继，也是旧 source4、旧 source6 可以合法重查的共同目录动作。它们在新终端钱包和旧源查询中不能分别改成不相干的角色。这正是此前只保留单个根 C 分支时遗漏的跨分支共同合法性信息。

## 4. 全 128 型的显式局部式与正确消元方向

对一个旧型 h 及新状态 `(q,r,y,t)`，记

\[
b=p+y_2,\quad D_4=b+y_3+3,\quad
D_6=b+y_3+y_4+y_5+1,\quad
D=b+q+r+1,\quad \theta=o/6.
\]

D4 是旧 source4 的 SAFE 分母，D6 是旧真末节点分母；D 是新分支末两位的真前缀分母。九预算在这个状态上的加权 A 系数为

\[
\begin{aligned}
\Phi_h(q,r,y,t)={}&
\frac{126000q}{b+1+r+y+t}
 +\frac{43r+31218y+34458t}{D_4}
 +\frac{1654(r+y+t)}{D_6}\\
&+5400\frac{\theta-t}{D+y}\\
&+7740\left[
\frac{o}{3D}-\frac{o}{36D(D+1)}
-\frac{y}{D+t}-\frac{t}{D+y}-\frac{y}{D(D+1)}
\right].
\end{aligned}
\tag{PHI}
\]

定义两组八态最小值

\[
a_q(h)=\min_{r,y,t\in\{0,1\}}\Phi_h(q,r,y,t),\quad q=0,1.
\]

若该型单位质量中的平均 q 取值为 s，则 s∈[o/6,o]。准确消元是

\[
\begin{aligned}
m(h)&=\min_{s\in[o/6,o]}[(1-s)a_0(h)+sa_1(h)]\\
&=\begin{cases}
a_0(h),&o=0,\\
\min\{(5a_0(h)+a_1(h))/6,\ a_1(h)\},&o=1.
\end{cases}
\end{aligned}
\tag{ENV}
\]

这是**加权 A 系数的下界**，即真 slack 的 ν 系数的负号；不是直接最小化非负预算的 ν 系数。它给

\[
\sum_hm(h)w_h\le \sum_R\lambda_RA_R\nu
\le\sum_R\lambda_Rb_R=B(w),
\]

从而 (CUT) 普遍成立。

为逐项给出 Farkas 付款，令

\[
\delta_h=\max(a_1-a_0,0),\qquad
\gamma_h=\max(a_0-a_1,0),
\]

分别乘在 lower slack `L_h=r_h^Q−o_hw_h/6` 与 upper slack `U_h=o_hw_h−r_h^Q` 上。定义

\[
\rho_h(q,r,y,t)
=\Phi_h(q,r,y,t)+(\gamma_h-\delta_h)q-a_0(h)
=\Phi_h(q,r,y,t)-a_q(h)\ge0.
\]

令质量式 `E_h=Σν_h−w_h=0`。则完整恒等式是

\[
\boxed{
B-\sum_hm(h)w_h
=\sum_R\lambda_RR
 +\sum_h\delta_hL_h+\sum_h\gamma_hU_h
 +\sum_{h,q,r,y,t}\rho_h(q,r,y,t)\nu_{h,q,r,y,t}
 +\sum_ha_0(h)E_h.
}
\tag{ID}
\]

质量式乘子 a0 允许为负，例如原型 0010001 的 a0=−326。其余所有付款及余项非负。

对本证书，完整 128 型检查进一步给

\[
\min_h(a_1(h)-a_0(h))=113681/4>0.
\]

因此全部 upper 权为零，全部 lower 权为正，(ENV) 可简写为 `m=a0+o(a1−a0)/6`。这是在完整允许区间上求到下端点的结论；**没有假定实际最优菜单重数为 1**。若真实菜单重叠，s 更大，只会增加该加权列下界。上界仍原样保存在固定 LP 中。

所有 128 旧型、两种 q、每种八个尾态共 **2048 个状态**均保留。ρ 有 **290 个零、1758 个正值**。全部最小值和极小态见 [universal_moment_envelope.json](universal_moment_envelope.json)，全部状态余项见 [all_2048_state_residuals.tsv](all_2048_state_residuals.tsv)。切面的 128 原子系数为 `126000*l3/c+65719*l4/c+4962*l6/c−m(h)`，保存在 [universal_cut_128.tsv](universal_cut_128.tsv)。K/u 两参数列准确为零。

## 5. 固定点矛盾与 tight SAFE3 的作用

释放点上原 SAFE3(Omean) 精确取等，v3 为

\[
\frac{44921881310133211653}{1143130391321139871688}.
\]

若补全存在，则 source3 平均 IC、尾部最大负载及矩下界给

\[
v_3\ge\sum\nu\frac q{p+y_2+1+r+y+t}
\ge\sum_h\frac{r_h^Q}{p+y_2+4}
\ge\sum_h\frac{o_hw_h}{6(p+y_2+4)}=v_3.
\]

所以这个固定点的任何补全本来就必须有 `r_h^Q=o_hw_h/6`，且 q=1 的正质量只落在 `(r,y,t)=(1,1,1)`。本轮没有将它们作为额外假设或约束输入；它们只是对为什么完整重查很苛刻的解释。全域投影仍在每个 q 上遍历全部八态，并使用完整矩区间。
