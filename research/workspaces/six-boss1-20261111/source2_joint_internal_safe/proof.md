# 同一第二源最大 C 分支的三内部 SAFE 联合付款与源 IC 重配

Boss1；RUN `six-boss1-20261111`。本包全部使用精确有理运算，优化器调用为 **0**。

**归属：** 三内部 SAFE 的联合方向及三帽饱和猜测由 Main 提出，本席从真实份额独立确定其完整有限域。第 6 节的 \(\alpha=25+\Theta-s\) 重配、\(s\in[0,9]\) 乘积域及 985 行由 **Main 提出并先行枚举**，本席在本包独立重建来源、验证全部状态和完整系数；不将该扩张记为本席独立发现。

## 1. 两个普遍结论

采用[原共同目录完整历史模型](../../../../archives/customer-attraction/state/定义/共同目录完整历史模型--定义.md)：有限单位客户、有限非空共同合法标签目录、恰六人、任意完整有序历史纯 SPE。原实际首标签为 A1，原实际第二源收益为 \(u_2\)。取合法 C 真正达到全目录最大裸大小 \(K=|C|\)。任取六个合法查询标签及其覆盖并 O，允许重复、空覆盖和同覆盖异标签。

逐客户记 \(p=\mathbf1_{A_1},c=\mathbf1_C,o=\mathbf1_O\)，定义

\[
B=\sum_x\frac{c_x}{p_x+5},\qquad M=\sum_x\frac{o_x}{6(p_x+4c_x+1)},\qquad N_j=\sum_x\frac{o_x}{6[p_x+(j-2)c_x+7-j]},\quad j=3,4,5.
\]

令 \(\Theta=\theta_3+\theta_4+\theta_5\)，三权域为

\[
\mathcal P=\left\{\theta\ge0:
\theta_5\le\frac5{12},\quad
\theta_4+\frac{\theta_5}{36}\le\frac5{12},\quad
\theta_3+\frac{\theta_4}{72}+\frac{\theta_5}{36}\le\frac5{12}
\right\}.
\tag{P}
\]

首先，对全部 \(\theta\in\mathcal P\)，有

\[
\boxed{25u_2+\frac{\Theta}{5}K\ge24B+M+\theta_3N_3+\theta_4N_4+\theta_5N_5.}
\tag{J25}
\]

其次，Main 的源 IC 重配给出更大的普遍族：对全部 \(\theta\in\mathcal P\)、\(s\in[0,9]\)，

\[
\boxed{(25+\Theta-s)u_2+\frac{s}{5}K\ge24B+M+\theta_3N_3+\theta_4N_4+\theta_5N_5.}
\tag{RW}
\]

\(25+\Theta-s\ge16\)，所以全部真实预算权非负。(J25) 是 (RW) 的 \(s=\Theta\) 截面。本包证明 \(\mathcal P\) 以及 \(\mathcal P\times[0,9]\) 分别是下述**指定仿射最小值公式**在非负内部 SAFE 权下的完整可行域；没有声称它们穷尽任意可能的 SPE 钱包。

O 始终表示六个真实合法标签的覆盖并，不作为合法行动使用。本族不需要菜单最优性或 X 的任何最大化性质。

## 2. 必须使用的同一真实分支

在实际第二源的真实历史 \((A_1)\) 强制合法 C，随后沿给定同一完整策略取 \(R_3,R_4,R_5,R_6\)。记这条分支的真实终局收益为 \(v_2,\ldots,v_6\)，客户尾会员为 \(r_3,r_4,r_5,r_6\)，总负载

\[
L=p+c+r_3+r_4+r_5+r_6.
\]

令六个查询在该客户上的会员重数为 d，\(o=\mathbf1_{d>0}\)。真实末 BR 的均值查询成本为

\[
\frac{d}{6(p+c+r_3+r_4+r_5+1)}.
\]

内部真实源 \(j=3,4,5\) 的前缀是 \((A_1,C,R_3,\ldots,R_{j-1})\)。在该节点真改任一查询后，沿其自己的真实续局，最多再有 \(6-j\) 位覆盖该客户。因此该源有 SAFE 均值预算

\[
v_j\ge\sum_x\frac{d_x}{6[p_x+c_x+\sum_{k=3}^{j-1}r_{k,x}+7-j]}.
\tag{SAFE-j}
\]

此处的收益是同一强制 C 分支的 \(v_j\)。没有把它改成原实际 \(u_j\) 或 \(u_2\)，也没有预设 \(R_j\) 覆盖等于 C。偏离后真实续局可以随标签和有序历史变化，SAFE 只用剩余人数给出普遍收益下界。

在 (J25) 中支付以下九项真实预算：原第二源 IC 权 25；三个中间尾大小帽各权 \(1/2\)；末尾大小帽权 1；同一末节点的六查询 BR 均值权 1；三个内部 SAFE 均值权分别为 \(\theta_3,\theta_4,\theta_5\)。C 真达到全目录最大裸大小，保证四个真实后继的大小帽均合法。

逐客户完整成本，在把各个正查询成本的 d 弱化为 o 后为

\[
\begin{aligned}
\Psi_{25,\theta}(p,c,o;r)={}&
\frac{25c-r_6-\theta_3r_3-\theta_4r_4-\theta_5r_5}{L}
+\frac{r_3+r_4+r_5}{2}+r_6\\
&+\frac{o}{6(p+c+r_3+r_4+r_5+1)}
+\sum_{j=3}^{5}\frac{\theta_jo}{6[p+c+\sum_{k=3}^{j-1}r_k+7-j]}.
\end{aligned}
\tag{COST25}
\]

零负载时首分子也为零，首项取零。把 d 换为 o 产生的准确非负差为

\[
\frac{d-o}{6}\left[
\frac1{p+c+r_3+r_4+r_5+1}
+\sum_{j=3}^{5}\frac{\theta_j}{p+c+\sum_{k=3}^{j-1}r_k+7-j}
\right].
\tag{MENU}
\]

四个均值使用同一六标签菜单；它们的前缀可以不同，但未使用独立客户边际。`derive_exact.py` 对 4096 个实际菜单位/尾态情况逐项检查此仿射差的四个系数。

## 3. 三权仿射最小值和三条必要帽

令

\[
m_{25}(p,c,o)=\frac52c+\frac{24c}{p+5}+\frac{o}{6(p+4c+1)}.
\]

欲证的准确最小值为

\[
\min_{r\in\{0,1\}^4}\Psi_{25,\theta}
=m_{25}(p,c,o)+\sum_{j=3}^{5}\theta_j\left(\frac{o}{6[p+(j-2)c+7-j]}-\frac c5\right).
\tag{MIN25}
\]

固定 \((p,c,o,r)\) 后，成本减右端为 \(a+b_3\theta_3+b_4\theta_4+b_5\theta_5\)。128 个准确仿射形式保存在 `state_halfspaces.json`。以下三个状态给出必要的三条帽，均为 \((p,c,o)=(0,0,1)\)：

| 唯一中间覆盖 | 准确余项 |
|---|---|
| 尾 0010 | \(5/12-\theta_5\) |
| 尾 0100 | \(5/12-\theta_4-\theta_5/36\) |
| 尾 1000 | \(5/12-\theta_3-\theta_4/72-\theta_5/36\) |

例如尾 1000 的源 3 实际收益为 1，使该 SAFE 权的成本减少 \(\theta_3\)；它还把后续源 4、5 的查询分母各增加一，从而产生 \(-\theta_4/72\)、\(-\theta_5/36\)。这些交叉项来自真实的行动顺序，不能换成同一前缀。

加上权本身非负，恰得到 (P)。其全部八个顶点如下。

| 顶点 | \(\theta_3\) | \(\theta_4\) | \(\theta_5\) |
|---|---:|---:|---:|
| V000 | 0 | 0 | 0 |
| V001 | 0 | 0 | 5/12 |
| V010 | 0 | 5/12 | 0 |
| V011 | 0 | 175/432 | 5/12 |
| V100 | 5/12 | 0 | 0 |
| V101 | 175/432 | 0 | 5/12 |
| V110 | 355/864 | 5/12 | 0 |
| V111 | 12425/31104 | 175/432 | 5/12 |

程序用六边界的 20 个三元组合做有理 3×3 消元，得到的所有可行顶点正好是表中八点。这个有界多面体也可逐坐标看成区间：先选 \(0\le\theta_5\le5/12\)，再选 \(0\le\theta_4\le5/12-\theta_5/36\)，最后选 \(0\le\theta_3\le5/12-\theta_4/72-\theta_5/36\)。依次在每个区间两端取凸组合，即给出八顶点的凸组合表示。

全部八顶点的 128 个余项均非负，共 **1024** 项。余项对权仿射，所以整个 (P) 内都非负。对每个 \((p,c,o)\)，还有一个在全部顶点同时达到零的尾态：c=0 时 0000；p=0,c=1 时 1111；p=1,c=1 时 1110。因此 (MIN25) 在整个域上是**准确最小值**。结合必要帽，(P) 就是这一仿射包络的完整非负权域。

## 4. 全正选择、完整八型表及普遍行

取三个帽同时饱和的

\[
\theta^*=\left(\frac{12425}{31104},\frac{175}{432},\frac5{12}\right),\qquad \Theta^*=\frac{37985}{31104}.
\]

该点唯一最大化本域的 \(\Theta\)：分别给第 5、第 4、第 3 帽权 \(2449/2592,71/72,1\)，三个左端相加恰为 \(\Theta\)，右端为 \(37985/31104\)。三个付款权都严格正，取等必须使三个帽都饱和，唯一解就是 V111。这只是本明确权域内的总权最大性。

令 T 为第 2 节九预算的非负和，\(\Delta\) 为菜单弱化余项，\(\rho\) 为隐藏成本减 (MIN25) 的余项总和。精确付款为

\[
25u_2+\frac{\Theta}{5}K-24B-M-\sum_j\theta_jN_j
=T+\Delta+\rho+\left(\frac52-\frac{\Theta}{5}\right)(|C|-K).
\tag{PAY25}
\]

最后是自由质量等式，真实 C 满足 \(|C|=K\)。V111 时其乘子为 \(70163/31104\)。乘以 31104，得到较小的整数钱包尺度

\[
\boxed{777600u_2+7597K\ge746496B+31104M+12425N_3+12600N_4+12960N_5.}
\tag{JINT}
\]

对应整数真实权为：源 IC 777600；三中间帽各 15552；末帽 31104；末 BR 均值 31104；三个内部 SAFE 为 12425、12600、12960；C 大小自由乘子 70163。K 付款准确为 \(77760-70163=7597\)。该“整数尺度”指上述钱包量的权，客户份额列仍按准确有理数保存。

## 5. 与已有单 NS5 的关系

V000 是原 `P25(C,Omean)` 在 \(|C|=K\) 等式下的同一行；V001 正是单 NS5 行除以 12。其完整 513 列关系已核验，包括 C 大小等式的符号。

\[
R_{\mathrm{joint}}-R_{\mathrm{NS5}}
=\theta_3^*(K/5-N_3)+\theta_4^*(K/5-N_4).
\tag{DIFF}
\]

所以不能逐实例宣称全正联合行总是比单 NS5 强；应保留两条或完整顶点族。在刚冻结的 1003 行必要锥精确点上，单 NS5 为零，而 V111 的值是

{381465753715801281779447014549073142227295922176}
\approx-0.007315407987815423.
\tag{J1003}
\]

这给出可核的“新增信息”：该点满足全部原 1003 行、两等式和非负性，却违反新联合行，所以这条行不被冻结 1003 系统蕴含。V011、V101 也违反同一点。该比较不将此必要锥点解释为真实 SPE。

## 6. Main 的四参数源 IC 重配

本节扩张由 Main 提出。本席从真份额独立核验。

保持所有尾大小帽、末 BR 和内部 SAFE 的权，唯独把原第二源 IC 权改为

\[
\alpha=25+\Theta-s.
\]

真实成本只把 (COST25) 第一分子中的 \(25c\) 改成 \(\alpha c\)。准确仿射最小值为

\[
\boxed{m_{\theta,s}(p,c,o)=m_{25}(p,c,o)-\frac{sc}{5}+\sum_{j=3}^{5}\frac{\theta_jo}{6[p+(j-2)c+7-j]}.}
\tag{MIN-RW}
\]

其完整可行域恰为 \(\mathcal P\times[0,9]\)。三条 \(\theta\) 帽仍由 c=0 的三个单中间覆盖态给出。另两个独立边界由以下状态给出：

| 状态 | 成本减 (MIN-RW) 的准确余项 |
|---|---|
| p=1,c=1,o=0，尾 1111 | \(s/30\) |
| p=0,c=1,o=0，尾 1110 | \((9-s)/20\) |

因此 \(s\ge0\)、\(s\le9\) 必要，且这些余项不依赖三权。该乘积域有 16 个顶点：上表八个 \(\theta\) 顶点分别配 s=0、9。对每个顶点和全部 128 隐藏态，本席直接按九个真预算重建成本，**2048 项全部非负**；8 个 \((p,c,o)\) 在每个顶点均有上述公共达到态。仿射性遂证明整个乘积域上的准确最小值。所有 \(\alpha\ge16\)，没有负源 IC 权。

此处公共达到态 p=1,c=1 的 1110 保留末位可以不覆盖 C 的情况；源 IC 重配未把弱平局删成四尾全覆盖。

一般付款为

\[
\alpha u_2+\frac{s}{5}K-24B-M-\sum_j\theta_jN_j
=T_{\alpha,\theta}+\Delta+\rho+\left(\frac52-\frac{s}{5}\right)(|C|-K).
\tag{PAY-RW}
\]

它证明 (RW)，无须取等或固定任何低福利点。16 条完整 513 列行保存在 `sixteen_reweighted_vertex_family.json`，共 8208 个准确系数。程序还在所有 16 顶点检查实际六索引平均，共 65536 个菜单/尾态情况。

对固定 \(\theta\)，\(R(\theta,s)\) 关于 s 仿射，且 \(\Theta\le37985/31104<9\)，所以

\[
R(\theta,\Theta)=\left(1-\frac{\Theta}{9}\right)R(\theta,0)+\frac{\Theta}{9}R(\theta,9).
\]

因此 16 个重配端点的有效性已经包含原八个源 IC 权 25 的钱包。单 NS5 是 \(\theta=(0,0,5/12),s=5/12\) 的内点，权为 \(103/108\) 与 \(5/108\) 的两个 s 端点凸组合。这些完整列关系均逐项核验。

## 8. 等号与别名的精确边界

局部零态允许某中间尾在 C 外覆盖客户，不表示真实取等时这种额外覆盖一定能保留。以单 NS5 为例，其所有 c=1 最小态都包含 r3=r4=r5=1；若整条真实预算取等，三个正权大小帽也取等，所以每个中间尾已包含大小为 K 的 C，最终只能覆盖恰 C。局部零态 0010 的 C 外 R5 会员因此被总大小等号排除。

单 NS5 在真实 SPE 中取等还迫 p=1,c=1 为尾 1110、p=0,c=1 为尾 1111。每个 C 客户对强制第二人的份额都是 1/5，源 IC 取等即给 \(u_2=K/5\)。这与当前 1003 面上的正差相矛盾；985 行把这项障碍转成不依赖取等前提的普遍付款。

上述“覆盖恰 C”从不表示标签相同。各个真实历史继续保留原标签和给定策略的不同续局；本证明使用的仅是当前实际客户份额、真实 IC 和对合法查询的最坏剩余负载下界。

所有零型、o=0 型、空覆盖、同覆盖异标签、重复查询与弱平局都在状态域和原模型量词内。任意有限单位客户可按状态聚合；O=0 时不需归一化。所有源码及数据均未修改旧输入，且没有把必要锥点当成完整 SPE。
