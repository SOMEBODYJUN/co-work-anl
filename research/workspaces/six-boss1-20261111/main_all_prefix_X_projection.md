# Main：同一最大主题的四个早期源与末两位联合投影

Boss1；RUN six-boss1-20261111。此处为解析推导，不依赖固定16hist或任何数值点。

## 1. 量词和共同身份

在原六人完整有序历史纯SPE模型中，固定从空历史出发、沿同一策略σ的实际完整六人路径。对其actual前缀，令`b_i`为玩家i之前的逐客户负载，`r_i=7−i`。本文四个早期源用`i=1,2,3,4`，前三个由旧AP支付，第四个由已核H3-X支付。若另从离轨前三历史开始，H3-X仍可单独使用；较早三个源须使用它们各自真实续局的收益，不能将给定离轨后缀冒充其实际终局。以下九参数合账只使用同一根实际路径。

令`P=b_5`，actual末两位主题为A、B，收益为u5、u6。一次选定整个共同目录中使

`f_P(X)=Σ_X 1/(P+1)`

最大的合法标签X。所有早期源、所有末两位预算共用这一标签与同一逐客户会员x。有限非空目录保证选择存在；弱平局任取其一。设K是整个共同目录裸大小的上界。

沿用正式MP的两份等长合法配对菜单Q_j、R_j及五个非负全局参数`λ,β,γ,δ,ε`。对四个较早源再各取任意非空合法查询菜单S_{i,j}和固定非负数η_i；菜单项可以重复，平均仅是合法不等式的线性组合，不是新的可行动标签。所有参数在一次应用内对全部客户共同固定。

## 2. 原预算在消去X之前的形式

正式MP证明的五预算之和为

`T + Σ k_t x_t ≥ 0`，

其中

`T=(λ+β+ε)u5+γu6+δK−λf_P(B)−ε平均f_P(Q)−(β+ε)平均f_P(R)+ε平均g_P(Q,R)`，

`k_t=(λ b_t+β平均r_t)/[(P_t+1)(P_t+2)]+ε/(P_t+1)−γ/(P_t+a_t+1)−δ`。

这里a、b分别是actual第五、第六主题会员，不与早期负载b_i混同。

对i=1,2,3，旧任意锚AP在M≤6下给C_i为43、65/2、23。对i=4，同一个X的H3-X给C_4=10、r_4=3。将其菜单平均后，都可统一写成

`C_i u_i − 平均 f_{b_i}(S_i) + Σ d_{i,t} x_t ≥ 0`，

`d_{i,t}=−(C_i−1)/(b_{i,t}+r_i)+(r_i−1)平均s_{i,t}/[(b_{i,t}+1)(b_{i,t}+r_i)]`。

前三个AP使用X的合法性；第四个H3-X额外使用同一X在P下的最大性。不同源的u_i分别是各自actual继续收益，不能用离轨分支中的其他收入替换。

## 3. 九参数全类型必要式

定义

`ell_t=k_t+Σ_{i=1}^4 η_i d_{i,t}`。

先将四个早期预算乘η_i与末两位五预算相加，再逐客户加上

`(ell_t)_+−ell_t x_t ≥ 0`，

得到

**`T+Σ_{i=1}^4 η_i[C_i u_i−平均 f_{b_i}(S_i)]+Σ_t(ell_t)_+ ≥ 0`。**

这是五个MP参数加四个η的共同投影族。所有原始客户类型均适用，不要求d=1，不要求16hist，不删除零客户或空主题。每个分母至少为1；没有除以任何收益、质量或缺额。

η全部为零即MP；仅η4非零即此前Main的HMP；仅η3非零可把实际第三位的同X AP查询与末两位cap/RC/末价/容量直接合账。此式来自同一X的预算相加，不能仅把各自已经消X后的正部界相加并宣称等价。

## 4. 信息接口及不能越过的边界

若S_i和Q/R均是actual主题或逐hist已知的菜单会员，则ell的正部可按这些共同会员类型精确计算；每个固定参数实例是一条原客户质量上的必要行。

若多个查询含隐藏R/Z/H等标签，必须知道足以计算ell的共同会员分布。不能把同一hist内的边缘平均代入非线性的正部，也不能将每个交叠的独立最大值假装来自同一个X。可以采用明确上包络放松，但需单独证明方向。
