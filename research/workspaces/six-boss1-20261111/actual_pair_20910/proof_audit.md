# actual 单一末两位源强 PAIR 的独立数学审查

本页亲读并复核正式引理《共同末位报价与隐藏回复投影》及《跨族末两人菜单的共同锚点与运输界》的三条真 IC 与倒二自税证明。它使用既有一般必要行；本任务的新工作只是新 20910 行精确点上明确有限标签族的完整审计。

## 1. 一份真实源、三条真实 IC、自税一次

固定同一完整历史纯 SPE，在真实源 `h=(A1,A2,A3,A4)` 剩两位，规定主题为 `A=A5`、`B=A6`。客户背景为 `P`。记

\[
f(Q)=\sum_x\frac{q_x}{P_x+1},\quad
g(Q,R)=\sum_x\frac{q_xr_x}{(P_x+1)(P_x+2)},\quad
U(Q,R)=f(Q)-g(Q,R).
\]

`U(Q,R)` 是第五位选择 Q、第六位选择 R 时第五位的真实收益。其逐客户恒等式为 `q/(P+q+r)=q/(P+1)-qr/((P+1)(P+2))`；q=0 时份额取0。

对任意合法比较标签 Q,R，令 V 为同一策略在真实历史 `(h,Q)` 规定的最后回复。下面三条都是全客户和非负的真实 IC：

\[
\delta_1=u_5-U(Q,V),\quad
\delta_2=U(V,Q)-U(R,Q),\quad
\delta_3=u_6-U(V,A).
\]

第一条只用源第五位 IC；第二条用强制 Q 后真实最后节点；第三条在 actual 最后节点以合法 V 作查询。没有把强制 Q 本身当成最佳回复，也没有把别的源收益代付到本源。

令 `H=u5+u6+g(A,A)`，直接展开得

\[
H-f(Q)-f(R)+g(Q,R)
=\delta_1+\delta_2+\delta_3+g(A,A)-g(A,V)\ge0.
\]

最后差为 A\V 上的正权和。这是所用必要行的完整理由。H 中的自税明确是 **A5 自税**，不是 `g(A5,A6)`，也不是某个 R/Z 源收益。`verify.py` 独立对本任务所有可能的背景 P=0,…,4 及 A,B,Q,R,V 五个位的全部32组合检查该恒等式，共160个 Boolean 情形；普遍非负性由上面的全行 IC 分解证明，未假设逐客户 IC 非负。

## 2. 原描述符到底固定什么

每个 hist 固定 actual 六个位和六个旧词 `(t_i,b_i,c_i)` 的八桶直方图。R/Z 描述符保留每个 `(family, 1[i=j], w_i, w_j)` 组的 own 四态平均；00 态为 hist 质量减去01、10、11三列。B4 的八态保留同一个分支 `(A1,A2,A3,A6,H1,H2)` 的 `(H1,H2,ell/6)` 联合分布。

因而以下交叠必须精确保留：

| 情形 | 交叠 |
|---|---|
| 同一字面标签 Q=R | Q 自身边缘 |
| 两个 static 位 | 两位乘积 × hist 质量 |
| static 位与随机主题 | static 位 × 该随机边缘 |
| 同一个字面节点 e 的 R_e、Z_e | own11 质量 |
| 同一 B4 的 H1、H2 | 八态中 H1=H2=1 的质量和 |

不同 R/Z 标签即使落到同一旧词组，也不据此相等。1306 个 `overlap` 列只有上包络语义，不作已固定真实 RR 交叠；本族的这些列系数为0。B4 的 `ell/6` 是目录均值坐标，不是合法纯标签，因此不添作第159个行动。新点没有 D 完成，D 也不在本族。

准确的历史别名 `R_(0,i,i)=C_i` 已在目录定义中处理：只保留30个非对角 R0，未再给该别名一个随机 own 坐标。其余同词或同覆盖异标签不合并。

## 3. 为什么组平均可以出现在完整 S6 行中

不能把某一组的平均边缘误当每个字面标签的独立固定边缘。本实现先保留完整字面 pair orbit，再按 hist、双方描述符 token 与已固定交叠关系分组。

固定这样一个组 G，其标签对数为 n。若左侧随机描述符组包含 m 个字面标签，完整索引等号型及固定旧词直方图保证每个左标签具有同一伙伴数 d，满足 n=md。因此对任意共同客户会员实现，严格有

\[
\sum_{(Q,R)\in G}\operatorname{mass}(Q)
=d\sum_{Q\text{ in descriptor group}}\operatorname{mass}(Q)
=n\,\overline q.
\]

右侧同理。对于 static 查询，已固定的0/1会员只乘对应已知随机边缘。这里是字面求和次数的恒等式，不是客户条件独立假设。

`verify.py` 用全部720个置换独立重建每个代表的像，验证每个字面对恰出现 `720/orbit_size` 次；之后逐组逐标签检查以上均匀度恒等式，完整完成336448个符号会员系数核对。旧描述符的 `hist_column_old` 是旧编号；现行 hist 归属使用列序中实际 hist 分块，并独立核旧号到现行16个分块的一一对应，不把旧编号当现行索引。

## 4. 未知交叠的固定线性上界

若 G 的交叠没有被上节固定，则对每个真实 Boolean 组合 `q*r≤q`、`q*r≤r`。完整组和满足

\[
\sum_{(Q,R)\in G}\operatorname{mass}(Q\cap R)
\le n\min(\overline q,\overline r).
\]

在本精确点比较两个已知边缘值，选择较小者；相等时按符号表达式字典序作可复现的固定选择。保存后，此选择不再随待评价点改变。在任何其它合法边缘点，选中的边缘仍然是交叠上界，故得到一条完整线性必要行。当前点上的取值恰为这一组的 Fréchet 最大交叠上界。

真实强 PAIR 余量中交叠的系数为正 `1/((P+1)(P+2))`，以该上界代入得到真实非负余量的上界，故替换后的完整行仍必须非负。若替换后的行负即可分离；若非负，不能反过来断言真实交叠可达到该上界。

独立 Boolean 审计保留真实父源：两个不同 own 节点枚举4×4态；own 与 B4 枚举4×8态；同 own 或同 B4 只枚举其同一联合态。250种语义真值表含3310个不同组合，在所有 hist/轨道分组展开共454584次。未知交叠的线性上界减去真实乘积逐项非负；精确已知情形逐项相等。

## 5. 归一、支持与结论范围

每条输出使用完整有序 pair orbit 的均匀平均，因此外部钱包 H 恰付一次。所有 S6 频数、包括零质量 hist 的固定选择均保留。原4849列上的全部符号系数由独立核验器重建；后续15736辅助列均补0。不存在把当前点质量替成常数 rhs 的操作。

全部490条线性必要行在指定新点严格为正，说明此点不能由这个完整的单源、158个已具名标签、逐组单行 Fréchet 上包络家族分离。它不证明未知交叠可以共同实现，不证明该客户律有末两位 SPE，不证明全有序历史 SPE，更不证明或反驳六人 half。这个准确有限家族已闭合，可释放任务。
