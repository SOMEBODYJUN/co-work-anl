# 全局威慑反例攻击：单层放大的承重义务

身份：Q-CAG-HALF 的独立对抗尝试。2026-10-23。状态：没有主反例，没有一般half证明。

已读当前模型、FAILED_ROUTES、RESEARCH_STATE、精确全集BI和已有无拥挤3/2族。这里不重复把小目录随机阴性当作一般信息；`discarded_pre_context_search.py`仅保留读取规范前的可复现草稿，不是规范solver，不承担数学结论。

## 目标机制

试图放大已知Q/B无拥挤族：每个fresh组有root core C_i=X_i，另有最优主题A_i=X_i∪Y_i；偏离A_i后，不止一个而是t个后继攻击该组，并从全局储备D领取激励。若单个攻击者把core平分，已有构造只容许|Y_i|≤|X_i|/2，给3/2。多攻击者表面上可容许|Y_i|接近t|X_i|，因此看似可越2。

这种计算遗漏了两个真正的SPE约束。

## 确切末位约束

假设候选root路径先选择k个互不相交的C_i=X_i，每组大小x，最后t人均选择与各X_i、Y_i不相交的同一储备主题D，|D|=R，Y_i在root未覆盖。

最后一人root收益为R/t。偏离到A_i的真实后继为空，且X_i已被一人覆盖，所以偏离收益恰x/2+|Y_i|。因此任何完整SPE必须有

    R/t ≥ x/2 + |Y_i|.

这个约束不依赖离轨平局或候选攻击策略。把t个攻击者追加到旧构造，不能在保持储备每人收益约x时把|Y_i|提升到tx；事实上仍有|Y_i|≤x/2。

## 早期储备偏离约束

仍在以上模板，取一个root早期玩家，root收益为x，假设其选择D后用完整SPE续局威慑。若所有能覆盖D的主题都是D本身，最终该偏离玩家的收益是R/q，其中q为该分支最终D的选择人数。因此必须有

    q ≥ R/x.

如果允许攻击主题部分覆盖D，精确的必要条件变成

    Σ_{z∈D} 1/(1+load_suffix(z)) ≤ x.

Cauchy给出另一必要条件：后继对D的总membership至少R²/x−R。

于是用大的R支付末位激励，会同时迫使早期D偏离分支投入大量攻击容量。这不是免费的一次性末位奖金。

## 被遗漏的fresh-A分支

在任何威慑子树，如果仍有某个Y_j未被前缀覆盖，最后攻击者可选择A_j。若X_j已被一次覆盖，其末位偏离收益为x/2+|Y_j|；若X_j尚未被覆盖，偏离收益为x+|Y_j|。所以把其余fresh组用C填完，不能替代核对fresh-A。

因此一个真正可能放大的递归构造至少要同时解决：

1. 末位root能支付每个大隐藏块；
2. 早期储备主题偏离后，把储备充分拥挤；
3. 在该拥挤分支中，把所有仍fresh的高隐藏主题也压低；
4. 新增能同时覆盖多块隐藏客户的攻击主题，在root本身的偏离也要受到同类可信威慑。

第3—4项强迫共享遗漏与跨组攻击；它们是新构造应保留的递归状态，不能由任取BI填充代替。单个坏菜单、root收益计算或固定攻击者数量都不够。

## 复用边界和下一次判别

这些只否定上述“独立fresh core + 一个不交储备 + 追加t个攻击者”的直接放大理由，不否定共享遗漏、交叠储备或一般Q-CAG-HALF。

下一次有信息的判别应先给出闭合的变人数状态域，明确记录：fresh高隐藏主题集合、每个储备客户的已有负载、以及可用于攻击的剩余人数；然后同时验证A、储备、fresh攻击主题的偏离。没有闭合这些状态前，继续调core/bonus大小没有判别价值。

## 一般威慑容量不等式（直接代数，未查全球新颖性）

固定任意真实root路径的第i个玩家，其实际最终收益为u_i，当前前缀客户负载为b。令T为任意合法偏离主题，Q⊆T为任意非空客户子集，q=|Q|。沿原完整策略的真实偏离后继，记L_z为后继玩家覆盖z的次数。SPE和Cauchy给

    u_i ≥ Σ_{z∈Q} 1/(b_z+1+L_z)
        ≥ q² / (q + Σ_Q b_z + Σ_Q L_z),

因此

    Σ_{z∈Q} L_z ≥ q²/u_i − q − Σ_{z∈Q} b_z.

若Q是实际遗漏客户，则它在任意root前缀均有b_z=0，故真实偏离分支必须支付

    suffix-memberships(Q) ≥ q²/u_i − q.

特别地，u_i<q/2会迫使后继对Q的总membership严格大于q；一次完整覆盖Q还不够，必须重复覆盖或集中多重交叠。这不把membership误作福利，不把某分支后继收益误记到root预算，也不声称不同偏离分支共享一份容量。

该必要条件可用于拒绝一个具体递归威慑状态。一般half仍缺的是不同分支的共同容量预算；单独相加这些分支下界是无效步骤。
