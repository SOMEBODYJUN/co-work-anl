# 本轮路线判别与诚实回收

Q-CAG-HALF 仍 OPEN。下面没有主命题反例。

| 尝试 | 失败或停止的准确原因 | 可复用信息与重试条件 |
| --- | --- | --- |
| 末位收益不高于平均、遗漏客户可由 W 全额支付 | 已有完整 SPE 分别否定早晚单调和遗漏≤W，后者甚至唯一最优组合遗漏36>W35 | 保留 O内已覆盖客户单预算、O外已覆盖客户双预算；不改变 half 身份 |
| 全k静态最优槽交换、仅实际前缀谐和坏树 | 查重确认分别被旧 optimal_exchange_moments、rank-one/fixed-rank 障碍覆盖 | 不重复证明；静态OPT行不是新的早期SPE约束；非SPE坏树不能反驳真实SPE的细量词候选 |
| 逐客户首覆盖/owner运输后直接使用 SPE | 各客户会选择不同的偏离行乘子；SPE只限制每条行的总收益，不能逐客户截取 | 需要客户共同的自适应行选择；一玩家两不交singleton已能显示截取不合法 |
| 前向吸收加整主题包络信用 | 净包络可直接退回，不必指数传播；但得到的总收费右端恰为 OPT+ΣλΓ，尚无非循环≤2W几何控制 | [准确表示](transport/customer_absorption_and_envelope_credit.md)仍可复用；不能因流终止或净信用非负而宣布完成支付 |
| 自由完整路径菜单的旧证书阴性扩样 | 指定16份规范证书在对应m下没有给通用时机冲突；有限实现结果不能支持全称真值 | 停止扩同种子；新 [产品等价](parent/product_menu_time_obligation.md) 提供跨实例严格分离的判别，不证明桥真 |
| 用主收益绝对范围定奖金的银行编译 | [探索稿](counterexample/coupled_bank_note.md) 的银行成本(3m−1)g超过主部分最多mg的福利改善，不能生成坏half | 更低真实regret奖金必须核查全部可信退出分支；该稿仅探索机制，不作为已审正式编译定理 |
| 跨节点银行重复消费 | [容量谱](global_induction/bank_joint_deviation_budget.md) 已控制同一实际路径：每客户容量≤1−c/m；嵌套为零 | 互斥离轨子树的容量仍未由根福利支付。可以研究该新缺口，不能把单路径预算扩成全树免费预算 |

未找到新承重界的随机诊断代码和重复输出已清理；有实质对象/参数的诊断保留准确范围与实际证据。个人备份不是 canonical 升级。
