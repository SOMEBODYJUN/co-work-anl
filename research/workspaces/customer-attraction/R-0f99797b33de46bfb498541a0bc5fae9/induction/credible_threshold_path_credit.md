# 真实可信阈值的任意路径价格：新信用候选与准确停界

2026-10-23。分支工作稿；未证明一般半覆盖，也没有找到目标反例。
本稿没有提交、推送或外发。`Q-CAG-HALF` 仍 OPEN。

## 1. 为什么改变状态

背景最优剩余利润 `F_r(b)` 的固定倍当前收益 Bellman 台阶、统一鲁棒
`h_r` 的 max 储备、仅背景/真实尾部共同覆盖客户的可加信用均已被完整
SPE 否定。下述候选真正加入后继最优性：每个价格由**全部可信子 SPE**
约束，而不是仅用最终分母界。没有把旧台阶换一个符号后继续使用。

目录和客户均采用现行 CAG-MODEL。`b` 必须来自同一目录的合法有序前缀；
计数缓存仅用于可实现终局集合，不要求不同有序历史使用同一续局。
`r` 是该前缀后的剩余人数。

## 2. 价格与可分路径下界

令 `R_{r-1}(b+1_A)` 为玩家当前选择 A 后，全部完整历史纯子 SPE
可实现的后继终局集合。对其中终局 q 评估当前 A 玩家的最终均分收益
`U_A(b+1_A+q)`。定义

```
v_r(b) = max_A min_(q in R_(r-1)(b+1_A)) U_A(b+1_A+q).
L_0(b) = 0,
L_r(b) = v_r(b) + min_A L_(r-1)(b+1_A).                 (CP)
```

q 在此编码 r−1 个后继行动；没有给背景玩家额外决策机会。有限性保证所有
极值达到，零客户和空主题无须特殊除法。

**已证的直接事实。** 每个完整纯 SPE 的当前收益至少 v，而且 v 恰等于
该状态所有纯 SPE 中当前玩家收益的最小值。下界来自每个动作的真实子局
属于相应 R。达到性则选择实现外层 max 的 A 及其最小收益孩子，并对其余
动作选择各自最小收益孩子；各有序孩子子树不交，故可合法拼合。

**已证的剩余利润下界。** 同状态每个完整纯 SPE 的 r 名剩余玩家总利润
`P_r(b,σ)` 满足

```
P_r(b,σ) >= L_r(b).                                    (LB)
```

证明对 r 归纳：当前收益≥v，实际孩子的剩余总利润≥其 L，而该 L≥所有孩子
L 的最小值。这个证明没有假设 half，也未使用背景总税。

等价地，L 是从 b 出发的**所有任意合法 r 步行动路径**上，逐前缀 v 之和的
最小值。路径本身不必是 SPE，各层实现 v 的惩罚子 SPE 也不必彼此相容。
因此 L 不等于最小 SPE 总利润；它可能严格较小。现有 61 客户根税输入上
精确得到 L=36，而最小 SPE 福利=38，已经给出严格区分。

## 3. 真正未证的支付义务

同背景最优剩余利润仍定义为

```
F_r(b) = max_(r个目录主题) sum_x c_x/(b_x+c_x),
```

分子为零时贡献零。新的具体候选为

```
F_r(b) <= 2 L_r(b)       对所有合法背景及剩余人数。      (PRICE-HALF)
```

若成立，结合 (LB) 并在根用 F_m(0)=OPT_m，立即推出原目标。
直接把 L 替换为最小 SPE 总利润只会重述原问题，这里没有这么做。

PRICE-HALF 是比“每个真实 SPE 的总利润支付最优一半”更强的可分价格
断言。首要风险是：父节点可用惩罚续局压低 v，下一步的 L 最小路径却可能
借助不相容的奖励/另一个孩子状态压低未来价格。要关闭候选，必须控制这种
跨层独立取最小值造成的缺口，或给出严格完整 SPE 菜单森林使 F>2L。
没有证据允许把此缺口略过。

## 4. 两个解析边界

### 任意合法背景恰两人

记 `U_b(A;B)=sum_(x in A)1/(b_x+1+1_(x in B))`，
`theta=min_A max_B U_b(B;A)`。已证末两人保证给 `v_2(b)>=theta`，而
`min_A L_1(b+1_A)=theta`，所以 `L_2(b)>=2theta`。

对实现 theta 的 A 和任意两主题比较组合 T,S，逐客户有

```
c/(b+c) <= c/(b+1+a) + a/(b+2),
```

其中 c=1_T+1_S、a=1_A；c=0 时左端按零计。c=1,a=1 的唯一需清分母
情形为 `1/(b+1)<=2/(b+2)`，其余直接成立。因此

```
F_2(b) <= U_b(T;A)+U_b(S;A)+U_b(A;A) <= 3theta
        <= (3/2)L_2(b).
```

这仅校准新价格定义与现有两人机制兼容，未新增一般人数定理。

### all-big 任意人数校准

取 n 名客户的大主题 A、n−1 个互不相交的单例主题，共 n 位玩家。
任何合法前缀后，选择 A 的最大可能最终 A 负载不超过 n，所以每个
`v_r(b)>=1`。沿全 A 路径，每个前缀有全 A 的完整子 SPE，当前收益恰 1，
故该路径各 v=1。于是

```
L_n(0)=n,   OPT_n=2n−1.
```

因此 PRICE-HALF 若成立，其人数无关常数 2 已渐近锐；这个价格状态同时
保留了旧 F 台阶所丢失的无界尾部信用。

## 5. 本轮诊断及其限制

`credible_floor_path.py` 用规范集合值 BI 精确计算 v、L、全部合法背景 F；
对 examples 中 19 个最多七主题、最多六人的输入和 100 个四主题随机输入
做了单次边界攻击。没有严格违反 PRICE-HALF。结果在
`credible_floor_path_results.json`；随机无违反不承担普遍量词。

原 69 客户 floor 储备反例在新状态中，精确算得根 L=40、OPT=69、最小
SPE 福利=48。最小价格路径可取 A,A,E,A；四个价格均为 10。全部 84 个
非终局计数状态的 v 均≥10。这说明旧反例没有直接杀死新候选，不是一般
PRICE-HALF 的支持证据。

`credible_path_menu_cone.py` 用下述专门松弛攻击跨层不相容性：固定任意
行动路径，在其每个前缀、对每个动作分别选择一个真实可信孩子 SPE。
只加入这些孩子**全部**决策节点的 SPE 线性比较，完全不强迫任意路径自身
成为 SPE。价格变量 t_i 满足 `t_i>=U_A(q_iA)`，故在这些森林保持合法的
任何重数点上，真实 `v_i<=t_i`。归一化 `sum_i t_i=1` 后最大化比较覆盖；
若精确恢复出比较覆盖>2，便有 `L<=sum_i v_i<=sum_i t_i=1`，得到候选反例。
这一接口专门允许各层惩罚孩子彼此不相容。

本轮只对上述 19 个输入和 69 客户反例各取一个 L 最小路径的菜单森林，
检查其所有至多 m 主题比较支持。未产生 >2；最高浮点/精确恢复端点为四人
7/4，许多端点退化为 all-big。一个浮点点未恢复为精确可行，结果明确标为
`exact:false`，没有据此声称上界。完整输出在
`credible_path_menu_cone_results.json`。

这些 LP 仅是有限固定菜单的候选生成器，不是覆盖全部策略锥的定理或对偶
认证。停止扩大同类扫描；下一承重行动是证明任意路径真实阈值的全局价格
预算，或解析构造可复核的奖励/惩罚拼接反例。
