# outside等号边界任意人数族的独立完整历史审查

2026-10-22，recursion2。root指定审查 `../independent2/weak_outsider_boundary.md`
的任意人数族。下面从其客户实例重建完整策略存在性，未调用发现者的审计代码或
SPE构造器。结论：该辅助边界反例在其所述量词下成立；未发现致命异议。
不是 Q-CAG-HALF 反例，没有外审或新颖性认证。

## 1. 实例与被否定的桥

任意整数m≥2，取m个两两不交的guard客户块A_i，每块2m人。U从每块取两人，
故|U|=2m。另有m−1个两两不交且与所有guard不交的主题V_j，每个2m−1人。
共同目录为这些A_i、U、V_j。λ=2m，G={A_i}，cap各1。

各A_i相对G私有核心都是完整A_i，所以核心信用2m=λ，总容量m，大小2m<2λ。
每个outside大小≤λ。故该族满足旧small_outsider条件把严格<λ改为≤λ后的全部
假设。m≥2保证U与各A_i不同；m=1不属于本族声明。

## 2. 不预设其他分支的完整策略补全

定义两组有序模板历史：

- H1：长度至少1、且全部由不同guard主题组成的前缀；
- H2：首行动为U，其后仅有不同V主题的前缀。

只在长度小于m的决策节点规定行动。H1指定任意尚未使用的guard，H2指定任意
尚未使用的V。H1和H2不相交，各自沿其指定行动保持在同一类中，且选项总存在：
H1长度<m时至少一个guard未用；H2长度t<m时只用t−1个V，而共有m−1个V。

现在在整棵有限有序树上底向上填充：若节点在H1或H2中，用上述指定行动；
所有其余非根节点，用已经完成的孩子真实续局计算当前玩家最终收益，任选最大者。
根指定U。下面核对每个指定节点均为真正最优，因此此构造没有循环补全假设。

H1节点的fresh guard与此前、此后全部所选guard不交，最终收益恰2m。全目录
最大主题大小为2m，所以在任何已填充的偏离孩子中收益都不可能超过2m。
故全部H1节点最优，无论其他孩子采取什么完整续局。

H2节点的fresh V不被前缀U、已选V或之后不同V覆盖，最终收益恰2m−1。
而给定该前缀，任意行动的最终收益不超过其即时收益；各行动即时收益满足：

| 当前行动 | 即时收益上界 |
| --- | ---: |
| 任一guard | (2m−2)+2/2=2m−1 |
| fresh V | 2m−1 |
| 重复U | 2m/2=m |
| 重复V | (2m−1)/2 |

因此全部H2节点也最优；其中偏离到guard、重复U或其他非模板历史之后的任意
SPE填充只会进一步降低当前偏离者的收益，不会破坏此比较。

根U后整条指定路径使用所有不同V，U的2m客户始终独占，根收益2m，亦达到
全目录最大主题大小。故根最优。其他节点按真实孩子最大化构造，因此全部有序
历史均满足SPE，包括所有重复、乱序、outside较晚进入的非模板历史。

## 3. 福利、最优与严格边界

实际路径为U及所有V，收益为2m、2m−1,...,2m−1，所以

    W=2m+(m−1)(2m−1)=2m²−m+1 < 2m²=mλ。

m个guard覆盖2m²人。任意m个比较主题可先删掉重复；不含U时，由每个guard
大小2m、每个V大小2m−1，覆盖至多2m²。含U时，若另取r个guard、t个V，
r+t≤m−1，则覆盖恰为

    2m+r(2m−2)+t(2m−1) ≤ 2m²−m+1 < 2m²。

所以OPT_m=2m²，且2W−OPT_m=2m²−2m+2>0。被否定的是旧条件外推后的
“每位玩家收益≥λ”及“W≥mλ”；half在该族仍有严格余量。
