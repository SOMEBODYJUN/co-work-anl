# 删除接续的正确方向、最优边际与原根全树义务

2026-10-24。Boss16/deletion；适用任意有限单位客户、任意共同有限非空目录、任意人数及每个完整有序历史纯SPE。空主题、重复及任意历史平局均保留。**一般half仍OPEN。** 本稿给可直接接续的归纳账和一般静态比较组件；没有获得新的福利界或可信修复定理。作者证明、作者自检、独立内审和外审分开记录在本目录README。

## 1. 固定原SPE，先写归纳真正需要的方向

固定m>=2人的完整SPE sigma，实际终局z，福利W，实际玩家i的主题S_i及利润u_i。记

    e_i = |S_i \ union_(j!=i) S_j|,
    O = OPT_m, O_- = OPT_(m-1), Delta_m = O-O_- >=0.

因果删除i后的完整计划记tau_i；它的实际叶就是z删i，因此

    W(tau_i)=W-e_i.

这只是一个完整计划，不能直接代入人数归纳。任取真正同目录(m-1)人完整SPE eta，写

    W(eta)=W-e_i+d_i.                                      (1)

d_i可以为正、零或负；不能预设它非负。若已经证明人数m-1上任意目录、每份完整SPE均有O_-<=alpha W(eta)，则

    O-2W <= Delta_m-alpha e_i+alpha d_i-(2-alpha)W.         (2)

所以使用这条归纳的直接充分付款是

    Delta_m+alpha d_i <= alpha e_i+(2-alpha)W.              (PAY)

特别仅用alpha=2时，需要Delta_m+2d_i<=2e_i。若只知存在eta满足W(eta)>=W(tau_i)-E，不能把它用于(2)给原W下界。直接有用的方向是找到**某一份**eta满足W(eta)<=W(tau_i)+E，并支付Delta_m+alpha E。

更准确的精确slack账是

    2W-O = [2W(eta)-O_-] +2e_i-2d_i-Delta_m.               (3)

因此较小人数已有的正half slack可以支付一部分修复，但“较小人数half”这个单一标量只给方括号非负，不能免费支付正Delta_m或向上修复。

e_i按客户恰为实际覆盖负载1且唯一覆盖者为i的客户数；这些集合互不相交，故sum_i e_i=|{x:c_x(z)=1}|<=W。它与u_i不同，u_i还含共享客户份额。删除原实际根时同样必须保留e_1，不能把投影福利误写成W-u_1。

## 2. 最优人数边际：全范围界与边界

对任意一个实现O的m元比较组(T_1,...,T_m)，定义其独占块

    E_j = T_j \ union_(k!=j) T_k.

移除T_j所得合法(m-1)元组覆盖O-|E_j|。E_j两两不交，sum_j|E_j|<=O，故

    O_- >= O-min_j|E_j| >= (m-1)O/m,
    0<=Delta_m<=O/m.                                     (4)

比较主题可重复；重复位置的E_j为空，仍成立。若目录全空则O=O_-=0，所有式子直接为零。m=1时原问题直接由单人最佳回应给W=OPT_1；无需制造空目录或调用人数0的SPE。若为了统一算术定义OPT_0=0，(4)在m=1也成立，但(2)的策略归纳仅用于m>=2。

只将(4)和子人数half结合得到

    O <= 2m/(m-1) W(eta),

还需修复福利上界或额外slack；不能把(m-1)/m的方向反用成O<=(m-1)O_-/m。

## 3. 可供根删位选比较组的锚定静态加强

固定上述最优m元组及任意合法主题A；此处可取原实际根S_1，但证明不使用根激励。对a>=1定义

    n_a(A) = |{x in (union_j T_j)\A : # {j:x in T_j}=a}|,
    g(A) = |A\union_j T_j|.

随机从m个比较位置无放回均匀删去两个，再补入A，得到一个合法(m-1)元组。对O\A内比较重数a的客户，丢失概率为binom(2,a)/binom(m,a)，a>2时取零；O内属于A的客户不会丢，O外A客户全部增加。因此存在一个这样的确定性元组，给

    O_- >= O+g(A)-2 n_1(A)/m-2 n_2(A)/[m(m-1)],
    Delta_m <= 2 n_1(A)/m+2 n_2(A)/[m(m-1)]-g(A).         (5)

m=2时删两个再补A就是单主题A，式(5)精确退化成OPT_1>=|A|；n_2项的系数为1。m>=3时重数>=3的比较客户被该操作自动保留。结合(4)可取两个上界的最小值。

这是旧最优子列表交换机制的显式“带一个实际锚主题、少一个槽”应用，不认领新的最优交换原理。它是无条件的一般静态关系，尚未支付(2)中的d_i，也没有利用原根全部孩子IC。它可降低需付的Delta_m，不能被当成可信修复。

## 4. 必须保留的删除来源信息

删原实际根A时，剩余策略在固定A背景下的全部有序历史均为SPE。对任意新历史h、规定叶z及强制T后的原真实叶z_T，原IC松弛Gamma_h(T)>=0。对保留角色定义该叶删除退款

    r_h(z)=sum_(x in its action cap A) 1/[c_x(z)(c_x(z)-1)].

被计客户由根和当前两人覆盖，故分母严格为正。删除后保留同一策略的精确比较是

    U_h(T)-U_h(prescribed)
       =r_h(z_T)-r_h(z)-Gamma_h(T).                       (6)

(6)适用于全部新有序历史，但只是原计划的比较。如果后来为了可信性换掉某个孩子，z_T会改变，Gamma_h(T)也不再是那条原IC的松弛。实际叶退款总额u_1-e_1只付同一个原实际叶，不能每个新叶重发。

此外空背景原根本身有全部真实孩子行

    u_1 >= d_T := u_root(Z_(empty,T))  for every T in S.    (ROOT)

这不是“任意固定背景child”的附属性质。潜在正面修复应联合使用(6)与(ROOT)，并在换孩子后证明新的共同付款；只把(ROOT)写在边上而未用于任何不等式，不算已利用原根来源。

本次尝试尚未找到这样的跨孩子关系。原因不是(6)缺少有符号退款，而是物理修复需改动真实后继，旧原IC对改后的叶不再直接适用。沿原策略的全历史因子二与实际退款预算均不能补这个域变化。

## 5. 同一推导代入m=5

(2)原样给

    OPT_5-2W <= Delta_5-alpha e_i+alpha d_i-(2-alpha)W,
    Delta_5<=OPT_5/5,

并可用(5)进一步降低Delta_5。取现有一般四人因子alpha=1499/750，所需付款为

    Delta_5+(1499/750)d_i <= (1499/750)e_i+W/750.          (7)

这是条件接口，不是任意目录五人已证界。旧真实根删第二位族在m=5时W=10、e_i=0、d_i=1、Delta_5=0，代入(2)右端为1489/750>0，故该一般归纳本身不能推出half；游戏实际OPT_5=12仍远低于2W=20。

全局最坏SPE福利的候选

    W_min(m)-W_min(m-1) >= Delta_m/2                       (FALSE)

已由旧人口悖论反驳：同一个12客户3主题目录，全部3人SPE福利12、全部4人SPE福利11，而OPT_3=OPT_4=12，左右分别为-1与0。更早13客户2至3人数例及严格40至39版本同样排除它。这里使用的是原游戏人数变化的全SPE分类，不是向下修复例，也没有新作扫描。

## 6. 准确接续点

可继续的一般义务是：构造一份真正删后SPE eta及删位选择，使(3)右端非负；或不作物理修复，直接从全树(6)+(ROOT)证明等价净赤字的共同支付。只研究向下修复损失不承担(2)；只精化actual regret也不控制改孩子后的新叶。本次未证明(PAY)，没有新half范围。
