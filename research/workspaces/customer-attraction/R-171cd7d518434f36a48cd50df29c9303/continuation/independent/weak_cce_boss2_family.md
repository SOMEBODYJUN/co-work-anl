# Boss2弱iid反例族与弱CCE桥：一个直接的静态PNE核对

状态：解析补充。旧`../../independent/weak_cce_occupancy.md`的精确计数LP和充分性
保持原范围；一般弱CCE桥尚未证明或反驳。本页不重新发现Boss2的完整SPE族。

## 对象

取m>=2、K>=2，A为两个单位客户的核心，B为2(m-1)个与A不交的单位客户，
c_1,...,c_K为不同的额外单位客户。共同目录为

    C=A， B， P_j=A∪{c_j} (1<=j<=K)。

Boss2已经给出全部有序历史的完整纯SPE，实际路径C B^(m-1)，W=2m；
在m=K>=53时它否定弱iid桥。该政策和弱iid证书见
`R-c4732bee2f7b4e50a70568170e3334ae/round4_security/weak_iid_counterexample.md`。
此处只研究同实例静态CCE是否仍可提供较低福利的比较。

## 一个合法静态PNE

考虑静态终局P_1 B^(m-1)。选择P_1的玩家独享A和c_1，收益3。
他改为C收益2，改为另一P_j收益3，改B收益2(m-1)/m<2。

任意一个B玩家的收益为2。改C会与P_1分享A，收益1；改P_1收益
2/2+1/2=3/2；改为j!=1的P_j收益2/2+1=2。故所有玩家均无严格盈利偏离，
终局是一个允许可信平局的静态纯Nash，也是静态CCE。
其福利恰为

    2(m-1)+2+1=2m+1。

因此若C_m为同实例静态CCE的最低期望福利，则

    C_m <= 2m+1，
    (1-1/(2m)) C_m <= 2m-1/(2m) < 2m=W。

所以**Boss2整个m>=2,K>=2族都满足旧稿的弱CCE桥**。这不是仅凭
`C_m<=Z_m`所得的逻辑推论，而是提供一个明确可行的静态CCE上界。
本页没有声称2m+1是C_m的最小值，也不将该族的阳性核对推广为一般结论。

## 可接续观察：只用三个占用状态还可降低此上界

将终局P_0=C B^(m-1)、P_1=P_1 B^(m-1)、P_2=C C B^(m-2)
分别在玩家位置和K个花瓣标签下均匀对称化；m=2时P_2就是CC。
各状态的福利为2m、2m+1、2m。用旧稿b_m公式，聚合的
`W-H_B`、`W-H_P`分别为

| 状态 | W-H_B | W-H_P（任意固定花瓣标签，经过标签对称化） |
| --- | ---: | ---: |
| P_0 | 2/m | -1 |
| P_1 | 1+2/m | (m-1)/(2K) |
| P_2 | -2（m>=3） | (m-2)/3（m>=3） |

对m>=3取

    p_1 = 4/[m+6+3(m-1)/K]，
    p_2 = (2+m p_1)/(2m+2)， p_0=1-p_1-p_2。

当这些概率非负时，B和每个P查询约束都恰取等，C查询更弱，
于是得到一个CCE，福利为2m+p_1。对m>=3，分母至少m+6，
所以0<p_1<=4/(m+6)<=4/9；直接整理

    p_0=[2m-(3m+2)p_1]/(2m+2)>=0

等价于`p_1<=2m/(3m+2)`，由`4/(m+6)<=2m/(3m+2)`在m>=3成立。
这个可行构造表明该族的CCE差额甚至可为O(1/m)，不需要把PNE上界误认成精确最优值。

表格的P_2行要求m>=3，是因为此时B确已覆盖；m=2时不使用三状态加强。
一般弱CCE桥的真正缺口仍是旧稿对偶中所有非负主题权方向的跨树控制。

`audit_weak_cce_boss2.py`不调用旧b_m公式，而是对各支持终局逐个替换每位玩家，
直接重算均分收益，再对玩家位置及花瓣标签作有限平均。57组参数
（m=2,...,12、K=2,...,6，另加m=K=53及100）全部通过PNE比较、
概率非负、CCE约束及福利式的Fraction核验，报告为`weak_cce_boss2_audit.json`。
此有限复核不替代上面任意m,K的解析推导，也没有求解最优CCE。
