# 真实偏离背景先聚合负载：Jensen信用与全局分数支付接口

2026-10-21，Boss5 security个人研究备份。原Q-CAG-HALF、真正强/弱聚合安全值及下面的全局候选均仍OPEN。这里只证明一个精确恒等式、条件性归约和旧36客户见证上的严格区别；没有一般SPE新定理或新反例。未作独立审查或新颖性认证。

## 1. 固定对象与同旧接口的关系

固定CAG-MODEL任意m人共同目录游戏及一份完整有序历史纯SPE。实际路径为z=(S_1,…,S_m)，实际最终收益u_i，总福利W=Σu_i。对实际第i位前缀，当前人改选b后沿**同一原策略**的真实后继得到完整终局z_i(b)。删去偏离者自己的第i槽，得到m−1主题背景B_i(b)，负载h_{i,x}(b)。全部固定过去保留在B_i中。任何同计数历史仍可有不同后继。

给任意目录分布p，写t_x=Pr_(a~p)(x∈a)。先独立均匀抽i∈[m]、再抽b~p，定义

    H_x(p) = (1/m) Σ_i E_b h_(i,x)(b),
    P(p)   = Σ_x t_x / [1+H_x(p)].                       (P)

H(p)是一个合法**确定分数主题背景**：它属于m−1个目录主题负载的凸包。它不依赖独立查询a的抽样实现。这里没有声称任何顺序玩家能隐藏偏离，也没有把P叫作真正整数安全值v_m。

同旧去相关定义，令

    D_i=E_b f_(B_i(b))(b),
    C_i=E_(a,b iid p) f_(B_i(b))(a),
    e_i=u_i−D_i≥0, κ_i=D_i−C_i.

旧全p预算W≥Σ_i C_i已经失败。这里先跨i,b平均负载、然后才取倒数。Jensen给

    m P(p) ≤ Σ_i C_i(p).                                (1)

因此W≥mP(p)是更弱的要求；旧失败不自动否定它。它也弱于先为每名玩家各自构造分数背景cap的FF-LEADER充分机制。本页不把自由分数静态值或minimax归约本身算作新对象；关注的是这个跨玩家真实背景的确定线性推送与可精确提取的Jensen信用。

## 2. 精确信用恒等式

令随机h_x=h_(i,x)(b)，期望H_x=E h_x，其中i均匀、b~p。定义

    J(p)=Σ_x t_x E[ (h_x−H_x)^2 /
                         ((1+H_x)^2(1+h_x)) ] ≥0.

逐项使用正数y=1+h_x、A=1+H_x上的恒等式

    1/y = 1/A − (y−A)/A² + (y−A)²/(A² y)

并对i,b取期望，中间线性项为零，得

    (1/m)Σ_i C_i(p) − P(p) = J(p).

因此准确的全局余额为

    W − mP(p) = Σ_i e_i(p) + Σ_i κ_i(p) + mJ(p).        (2)

J同时包含单个真实节点回复随机性的信用和不同实际节点之间的信用。这里保留旧去相关总和的负值，允许由这两种方差信用及真实激励松弛跨节点偿还。J≥0本身当然不能证明右侧非负。

## 3. 尚开放的充分桥

候选义务为：对每个原模型完整SPE及每个p，

    W≥mP(p).                                          (POOL)

**POOL若成立，则一般half成立，甚至得到OPT_m≤(2−1/m)W。** 证明如下。

令K_(m−1)为全部质量m−1的自由分数主题背景负载，令

    t_m = min_(L∈K_(m−1)) max_A Σ_(x∈A) 1/(1+L_x).

查询分布上是线性函数，L上是连续凸函数，两域均为紧凸集；凸minimax给

    t_m=max_p min_(L∈K_(m−1)) Σ_x t_x/(1+L_x).

对每个p，取明确背景L=H(p)，故POOL给t_m≤W/m。另固定任意L∈K_(m−1)，写L=(m−1)Σ_Aq_A1_A，M=max_AΣ_(x∈A)1/(1+L_x)。对于任意m个最优比较主题的重数d_x，逐客户

    1_(d_x>0) ≤ (d_x+L_x)/(1+L_x).

求和得OPT_m≤mM+(m−1)Σ_Aq_Ag(A)≤(2m−1)M。对L取最小并代入t_m≤W/m即得结论。这是已有自由分数安全值静态代数在本构造中的合法应用；没有从POOL推断W≥mv_m，因为t_m≤v_m的方向不能倒用。

m=1时K_0只含零背景，P(p)=E|A|≤W，归约仍成立。全零目录、空主题、重复主题和从未覆盖的客户都由原和式处理，无需0/0或效率比。

还可以只要求对t_m的一个最优查询p成立；全p版本是便于攻击的加强，并非原half必要条件。
