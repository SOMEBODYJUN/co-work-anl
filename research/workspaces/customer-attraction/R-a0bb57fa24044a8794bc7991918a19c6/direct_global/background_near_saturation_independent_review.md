# 有背景近饱和交换候选：独立数学审查

日期：2026-10-21。研究员 direct_global。审查对象：同一工作区
`credible_counterexample/background_near_saturation.md`，本次读到的 BNS、AP 版本。
本审查先从模型重建所需逐客户不等式，再逐条核对正文；没有调用作者程序。

**结论：未发现 fatal objection。BNS、AP 和饱和刚性结论在陈述量词内成立。**
这只审查该必要条件，不证明 Q-CAG-HALF，也不认证它足够闭合任何五人模板。
下文同时记录一个直接的系数改进：两式中的 M 可以仅依赖比较主题 C 上的背景最大值。

## 1. 自行重建：保留真实分支

固定任意有序历史 h，背景 b，剩余 k>=2 名玩家。记
w_x=1/(b_x+k)。取合法主题 C，让当前玩家在 h 偏离 C 后完全遵循原策略，
得到实际后继 A_2,...,A_k=L。对这个分支令 q_x 是 k 名未行动者最后覆盖 x 的总数。
当前偏离者收益为 v=Σ_{x∈C}1/(b_x+q_x)。其中 x∈C 保证 1<=q_x<=k。
原节点 SPE 给 v<=u；每个合法主题 T 的最坏负载保底给 Σ_T w<=u。

记 s=Σ_C w、e=u-s>=0，并令

    d=Σ_{x∈C}(k-q_x)w_x,
    d_L=Σ_{x∈C\L}w_x.

定义更小的常数

    M_C=k+max({b_x:x∈C}∪{0}).

若 C 非空，缺额为正的项满足 b_x+q_x<=M_C-1；因此

    0<=v-s=Σ_{x∈C}(k-q_x)/[(b_x+q_x)(b_x+k)],
    d<=(M_C-1)(v-s)<=(M_C-1)e.                 (R1)

C 空时左端全零，同式仍真。原文使用 M=k+max_N b_x，故是 (R1) 的较弱版本。

## 2. 最后一个真实节点的两个比较

设 t 是 L 在这个分支中的收益。C∩L 上 v 与 t 的项完全相同；C\L 上

    1/(b_x+q_x)>=1/(b_x+k-1)
      >=[M_C/(M_C-1)]w_x.

最后一步的方向正确，因为 z/(z-1) 对 z>1 递减，且 b_x+k<=M_C。
L\C 上则 1/(b_x+q_x)<=1/(b_x+1)<=k w_x。

若 C 达到全目录 w 最大值 K，所有 A_j 的 w 大小都<=s=K，所以
Σ_{A_j\C}w<=Σ_{C\A_j}w。于是

    t-v <=[k-M_C/(M_C-1)]d_L.                 (R2a)

对任意 C，所有 A_j 的 w 大小都<=u=s+e，故右侧多出 k e：

    t-v <=[k-M_C/(M_C-1)]d_L+k e.             (R2b)

现让末位在同一真实历史偏离任意 D。D∩C 每个客户的偏离收益至少 w_x。
若 x∈D\C，而 z_x 是 k-2 个中间主题 A_2,...,A_{k-1} 的覆盖数，偏离收益为
1/(b_x+z_x+1)。对任意 b,z>=0 的整数，直接望远镜给

    1/(b+z+1)>=1/(b+1)-z/[(b+1)(b+2)]
      >=1/(b+1)-(k/2)z/(b+k).                (R3)

第二步等价于 b[kb+3k-2]>=0，因此包括 b=0,z=0 所有边界。
记 F=Σ_{D∩C}w+Σ_{D\C}1/(b_x+1)。最大主题情形有
Σ_{x∉C}z_xw_x<=d-d_L，任意 C 情形则<=d-d_L+(k-2)e。
末位 SPE 的真正偏离不等式与 (R2) 遂给

    F<=v+(k/2)d+[k/2-M_C/(M_C-1)]d_L          (R4a)

以及任意 C 情形在该右侧增加 k²e/2 的 (R4b)。这里没有将离轨后继冻结。

## 3. 闭合系数、两人边界与结论

k>=3 时 M_C>=k，故 M_C/(M_C-1)<=k/(k-1)<=k/2。
(R4) 中 d_L 的系数非负，允许 d_L<=d。再用 v<=s+e 与 (R1)，得到

    F<=s+[(k-1)(M_C-1)+k²/2]e.               (AP-C)

若 C 加权最大，(R4a) 没有额外 k²e/2 项，故

    F<=K+(k-1)(M_C-1)(u-K).                 (BNS-C)

k=2 时不存在中间主题，并且 d=d_L；应直接合并 (R4) 两个系数，
无需使用非负系数论证。所得同为 (AP-C)、(BNS-C)。M_C>=2 保障分母不为零。

由于 M_C<=原文 M<=原总玩家数，原文 BNS 和 AP 都成立。
五人节点取 M=5 的 AP 系数 57/2、20、25/2、6 计算也正确。
客户集空时所有效用、K、s、F 都为零，结论无须定义效率比；空主题 C 的情况
也已被上述约定覆盖。

## 4. 刚性结论和范围

BNS 的 δ=0 强制 d=0，因此所有 A_j 包含 C。它们加权大小不超过 K，而每个
客户的 w 严格为正，所以覆盖必须等于 C。在同一末位历史，用任意另一最大主题
D 偏离，F=K+Σ_{D\C}[1/(b_x+1)-1/(b_x+k)]。每个差集项在 k>=2 时严格为正，
末位最优性给 D\C 空，再由等加权大小得到 D=C。因此原文饱和刚性正确。

没有把合法有序历史商成计数策略，没有限制平局选择，也没有假定 C、D 或各后继
主题互异。所有主题使用同一共同目录，正是外部关联预算能调用全目录大小上界的理由。

本引理的全局承重缺口仍为：现有推导没有说明任何某个在轨节点必须 δ 小，也没有给
出跨节点加权 slack 的总支付。把 BNS/AP 相加后直接把 Σe 认作 W 将是不成立的新步骤。
