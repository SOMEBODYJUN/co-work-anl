# Chain reply requery: an m-independent shared-source projection

## Status

`CA-CHAIN-REQUERY-OPEN-v1` is a proved local necessary inequality (new in this
workspace), with an exact finite binary projection. It is not a proof of
Q-CAG-HALF and has not been externally reviewed. Its purpose is to preserve a
single source history and the identities of replies reused as later source
actions across a chain of branches.

## Setup

Fix any finite CAG instance, any `m >= 3`, a complete-history pure SPE `sigma`,
and a true history `h` with `k >= 3` players still to move. Let `p_x` be the
number of earlier covers of customer `x`, and let `r` be the source player's
payoff at `h` under `sigma`. For a chain length `L >= 2`, construct branches
`q=0,...,L-1` recursively at the *same* source history:

* Force the source to choose a legal theme `T_q` and then follow `sigma`.
* Write the `k-1` later themes as `A_{q,1},...,A_{q,k-1}`.
* Let `R_q=A_{q,k-1}` and `B_q=A_{q,k-2}`.
* For `q<L-1`, force the source in the next branch to choose the actual
  theme `T_{q+1}=R_q` generated by branch `q`.

All these themes belong to the common directory. The source payoff in branch
`q` is `v_q`; the final player's payoff in branch `q` is `e_q`. Since `h` is
on the complete strategy tree, source IC gives `r-v_q >= 0`. Since the final
player in branch `q+1` is at a terminal decision, it may query `B_q`, giving
`e_{q+1}-q_q >= 0`, where `q_q` is the payoff from that query at branch
`q+1`'s terminal history.

Let `ell_x` be the actual load before the global last player and `u_m` that
player's actual payoff. Let `K=max_{S in D}|S|`. Choose nonnegative rational
weights `lambda_q, eta_q, alpha_q, beta_q`, with `eta_q` only for
`q=0,...,L-2`.

## Exact row

For each customer write

```
t_q = 1[x in T_q],     a_qj = 1[x in A_{q,j}],
D_q   = p + t_q + sum_j a_qj,
```

and put `b_q=a_{q,k-2}`, `y_q=a_{q,k-1}`. The terminal query of `B_q` in
branch `q+1` has customer share

```
Q_q = b_q / (p + t_{q+1} + sum_{j=1}^{k-2} a_{q+1,j} + b_q),
```
with a zero value when `b_q=0` (the same zero-numerator convention handles all
fractions). The source and terminal shares in branch `q` are `t_q/D_q` and
`y_q/D_q`; an actual global-terminal query of `R_q` has share `y_q/(ell+1)`.
Define

```
F_chain = sum_q lambda_q * t_q/D_q
          + sum_{q=0}^{L-2} eta_q * (Q_q - y_{q+1}/D_{q+1})
          + sum_q alpha_q * y_q/(ell+1)
          + sum_q beta_q * y_q.
```

The identity constraints are `t_{q+1}=y_q` for `q<L-1`; no other equality is
needed. Define `psi_chain(p,ell)` to be the minimum of `F_chain` over all
binary variables in all branches satisfying these identities. This is a finite
minimum. Relaxing the identities gives a weaker but still valid row.

Then the following inequality holds for every legal choice of the chain and
weights:

```
(sum_q lambda_q) r + (sum_q alpha_q) u_m + (sum_q beta_q) K
    >= sum_x psi_chain(p_x, ell_x).
```

## Proof by exact decomposition

Summing the nonnegative SPE rows

```
Σ_q lambda_q (r-v_q)
+Σ_{q=0}^{L-2} eta_q (e_{q+1}-q_q)
+Σ_q alpha_q (u_m-P_ell(R_q))
+Σ_q beta_q (K-|R_q|)
```

leaves the left side above minus `Σ_x F_chain(x)`. Here
`P_ell(R_q)=Σ_{x in R_q}1/(ell_x+1)`, and the source contribution of branch
`q` is `v_q=Σ_x t_q/D_q`; the terminal contribution is
`e_q=Σ_x y_q/D_q`; the cross-query payoff is `q_q=Σ_x Q_q`. Every row is
nonnegative: the first family is the source's true-node IC, the second family
is terminal best response after the forced branch, the third family is the
actual last player's best-response price bound, and the fourth family is the
common-directory size bound. Therefore

```
A >= Σ_x F_chain(x) >= Σ_x psi_chain(p_x,ell_x).
```

The last step uses that each actual customer membership pattern is one of the
binary patterns in the minimum. The proof uses no finite sampling, no tie
breaking, and no assumption that the branch minima can be jointly realized by
one strategy. Empty and repeated themes and zero customers are included.

## Why this is new relative to the two-branch row

For `L=2`, this is one source requery row: the first branch's actual terminal
reply is reused as the second source action, and the second terminal player
queries the first branch's penultimate theme. For `L>=3`, the same source
payoff `r` funds a chain `T_0 -> R_0=T_1 -> R_1=T_2 -> ...`; all cross rows
retain the identities before minimizing. Pairwise use of the existing
same-source lemma would separately minimize the middle branch variables and
would lose the shared equality `T_{q+1}=R_q`. Thus this row is a concrete
higher-order query-closure interface, although it still needs a global choice
of weights and a common budget to imply half coverage.

## Six-player specialization

For `m=6`, the useful earliest source has `k=6`; the chain minimum has
`L*2^(5*L)` literal assignments before using any count compression. A direct
implementation should enumerate the two identity-linked source/terminal bits
and sort the `k-3` hidden middle bits only when the selected weights make them
symmetric. The row is already valid at the fourth position with `k=3`, where
it retains two hidden branch replies and gives a genuinely three-branch
comparison. It therefore avoids the invalid five-player two-hidden-reply
substitution at the third position of a six-player tree.

The remaining global obligation is explicit: choose finitely many chains and
nonnegative weights so that the resulting customer-type coefficients dominate
`OPT_6-2W` while the total `K` coefficient is nonnegative. No such certificate
is claimed here.
