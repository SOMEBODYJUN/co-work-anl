## 一般桥的精确候选及当前有限范围

给定完整SPE实际路径z，对每个实际节点i、每个合法偏离a，沿原策略执行真实后继，
删除偏离者行动得到竞争元组B_i(a)。令M_sigma为这些元组的并集。
研究较强候选：

`min_(Q in Delta(M_sigma)) max_t E_Q f_B(t) <= W/m`。

它保留所有实际节点的全部偏离菜单、允许任意共同静态Q。
它不同于已经失败的根菜单、节点内平均、经验iid或各分布自身推送核；
若成立则推出真正安全桥。当前无一般证明或合法反例，不能仅从minimax存在推出支付。
纯查询p不可能分离：每个实际i中包含B_i(pure query)，其查询值<=u_i；
故任何分离p必须真正混合。

有限浮点探索保存在：

- `menu_union_probe.py`及`menu_m3k6.json`、`menu_m4k6.json`、`menu_m3k6_integer.json`：
  分别150、100、1000棵完整BI形式策略的全重数Γ锥；使用若干查询p交替LP。
  没发现严格正gap；不是穷举策略或查询，不能证明候选。
- `group_menu_probe.py`、`group_menu_probe.json`：既有两组三标签政策的实际菜单
  `{01,02,03,04,34}`，若干p及交替全重数LP；没有正gap。
- `fresh_menu_probe.py`、`fresh_menu_probe.json`：1000棵三人六标签的辅助fresh形式策略，
  限制两查询标签不在实际节点竞争菜单中，优化任意有符号子集势。未出正gap。
  这些不是合法客户实例；其作用是隔离大正偏置编译会自动填平的重复查询信用。

上述无例计算已停止扩样；不把更多相同采样当一般推进。
