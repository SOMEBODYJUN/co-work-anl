## 当前结论和停止点

1. 研究从无拥挤Q/B模块的可拼接限制出发。若遗漏块只被其风险主题和若干完整复制者共享，r重惩罚把遗漏/实际基块比最多推至(r−1)/r；独立组复制仍只趋2。必须引入中间关联，并使惩罚者本身最佳回复。
2. `risk_cycle_module.md`记录了风险图、fresh最大收益屏蔽、重复惩罚的精确机制，以及一个闭合的K_(q,q)根惩罚子博弈。该子博弈具有真正完整SPE扩张（补根后实际风险全覆盖，比率仅1+1/(2q)），不能称为原目标反例。
3. `homogeneous_anchor_barrier.md`给出一个直接解析的模板排除：q个互不交安全锚点、t名末尾清理者、统一遗漏/锚点比例、遗漏在风险主题中最小关联数d，必有OPT≤(1+t/d)W。尤其单清理者的均匀图边模板至多3/2。这是既有robust分母保底的模板推论；父方已核对无实质异议，无外审/新颖性认证。
4. 对rank≤2逐人theta候选做了有限诊断。父方及时指出该候选已被七环四人完整SPE否定，故立即停止扫描。随机负结果仅作为失败记录；不再据此扩大样本或主张候选开放。
5. `rank_two_probe.py`和`rank_two_background_probe.py`是上述已停止诊断的可重现源，不承担任何一般结论。前者所有组完成；后者在(5,4,4)组中被中断。两者的stdout未冻结，不把未冻结计数当证据资产。
