# 同质锚点模块的末尾预算障碍

2026-10-23，既有robust偏离分母保底的模板推论；父方已逐式核对，无实质异议。无外审/新颖性认证，不作为新承重定理提升。仅约束下述构造模板，不解决一般Q-CAG-HALF。

来源机制：`research/current/customer_attraction/continuation_lemmas.md`“可回收的直接保证与仍开放的义务”已给出任意历史、任意后继的 `sum_(x∈T)1/(b_x+r)` 保底。本页只是将其中背景为零的锚点和实际遗漏部分取出，再双计其关联次数。

## 1. 为什么看这个模板

常见低福利构造取一批互不交的实际安全块 C_i，再取风险主题 A_i⊇C_i。风险主题额外覆盖实际遗漏 Y；偏离 A_i 后让真实后继去共享 C_i 和 Y∩A_i，以压低偏离者。若让每个遗漏属于几个风险主题，中间关联很容易出现，但这种共享本身不自动改善效率损失：末尾安全块仍必须有真实可行的偏离预算。

以下给出一个不依赖具体后继菜单、允许全部历史平局的障碍。它可在写整个策略树以前排除一类均匀参数构造。

## 2. 精确引理

固定任意原CAG-MODEL实例、任意m人完整纯SPE及其实际路径。设路径最初q≥1个行动依次为 C_1,...,C_q，剩下t=m−q≥1个行动任意。假设：

* C_1,...,C_q作为客户集两两不交，写 X_i=|C_i|。
* U是整条实际路径覆盖的客户集，Y是一个实际遗漏比较集，Y∩U=∅。
* 有q个合法目录主题 A_i⊇C_i，使每个Y客户至少属于d≥1个A_i。
* 有统一λ≥0，满足 |Y∩A_i|=λX_i 对每个i成立。

若 X_q>0，则

    λ ≤ t,
    |Y| ≤ (t/d) Σ_i X_i ≤ (t/d) W.

特别地，当t≤d且某个最优并集 O满足 O\U⊆Y时，OPT_m≤2W。更精确地，在该条件下 OPT_m≤(1+t/d)W。

零锚点边界：若X_q=0而λ由0/0未被约束，则不能用第q锚点推出λ≤t；应取最后一个正锚点p，结论改为λ≤m−p。若所有X_i=0，上述比例假设和覆盖次数迫使Y=∅。

## 3. 证明

考察实际第q位玩家的真实历史。此前恰有C_1,...,C_(q−1)，故C_q中的每个客户此前未被覆盖；Y中的每个客户也未被覆盖。若该玩家改选合法A_q，则沿原完整策略走完真实后继，剩下包含自己在内恰t+1人。A_q中的 C_q∪(Y∩A_q) 每个客户终局至多被这t+1人覆盖，因此偏离者的真实收益至少

    [X_q+|Y∩A_q|]/(t+1) = (1+λ)X_q/(t+1).

实际玩家选择C_q，终局收益至多X_q。完整SPE在该实际历史的最优性给

    X_q ≥ (1+λ)X_q/(t+1).

X_q>0时即λ≤t。这里没有冻结后继、没有指定平局，也没有假定偏离后风险动作被重复若干次。

每个Y客户在A_1,...,A_q中的出现次数至少d，故

    d|Y| ≤ Σ_i |Y∩A_i| = λΣ_iX_i ≤ tΣ_iX_i.

两两不交的C_i均被实际覆盖，所以Σ_iX_i≤W。最后，O\U⊆Y给|O|≤|U|+|Y|。

## 4. 对具体风险图模板的结论

若有q=m−1个相同大小X>0的安全块、一个末尾清理行动，每个风险A_i包含C_i和相同数量M的遗漏客户，则λ=M/X≤1。

* 私有遗漏：d=1，遗漏总量至多qX，因而不能违反half。
* 风险图顶点主题、边为遗漏客户：每条遗漏边属于两个风险主题，d=2，得到OPT≤3W/2（前提是这些q个风险主题已覆盖比较遗漏）。
* 每个遗漏属于至少d个风险主题：得到OPT≤(1+1/d)W。

这严格说明为什么“把独立遗漏改成均匀共享图边，再沿用相同安全块和单个末尾清理者”不是通向大于2的机制。重试必须改变承重假设：例如非统一 M_i/X_i、风险主题数远大于实际安全块数、风险主题不含对应完整安全块、更多清理玩家t>d，或不再使用两两不交的前缀安全块。这里只列出模板逃逸口，不声称任何逃逸口已经构成真正反例。
