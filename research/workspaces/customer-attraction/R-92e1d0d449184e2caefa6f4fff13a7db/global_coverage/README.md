## 精确的净预算

固定一个最优比较并集 O 和实际根覆盖 C，写

    I = O intersect C,
    D = O minus C,
    G = C minus O.

正确目标是 `|D| <= |I|+2|G|`，即 `OPT-W <= W`。所有比较主题 T_j 都包含于 O，因此在实际前缀改选 T_j 的当前玩家完全不覆盖 G。G 的收益只能由原先前缀或该真实分支的后继取得；这为「原路径G信用一次 + 离轨尾部G信用一次」的候选支付提供了准确来源，但没有自动给跨枝容量。

## 一个可复用、但不承担一般证明的精确份额恒等式

固定实际位置 i。令 b_x 为 i 之前的实际客户负载，c_x 为实际完整终局负载。当前改选任意 T subset O 后沿原完整策略真实续局；令 k_x 为该分支未来玩家在 x 上的总负载。因为 T 不覆盖 G，分支在 G 上的最终负载为 b_x+k_x。

对每个 x in G（故 c_x>0），定义

    a_i(x) = (c_x-b_x)/c_x,
    r_i,T(x) = b_x/c_x - b_x/(b_x+k_x),
    z_i,T(x) = 1_(b_x+k_x=0).

在 b_x+k_x=0 时将第二项 `b_x/(b_x+k_x)` 定义为0；此时 b_x=k_x=0，含义为分支旧前缀对 x 的总利润为0，而非除以零。则有逐客户精确恒等式

    [分支所有未来玩家在x上的总利润]
      = k_x/(b_x+k_x)
      = a_i(x) + r_i,T(x) - z_i,T(x).                 (B)

左侧同样在 b_x+k_x=0 时按0。证明只需用

    k/(b+k) + b/(b+k) = 1_(b+k>0),
    (c-b)/c+b/c=1.

`a_i(x)` 是原实际当前及全部后继在 x 上的利润；`r_i,T(x)` 是旧前缀在真实偏离后损失的利润，允许负值；`z_i,T(x)` 是该分支完全遗漏这位原已覆盖客户的信用。对 G 求和得到

    L_i,T(G) = A_i(G) + R_i,T(G) - Z_i,T(G).           (B-sum)

这没有冻结后继，也不把真实分支旧玩家利润误认成根路径旧玩家利润。它不使用SPE，故不能单独推出half。其用途是明确一条分支的外部奖励从哪里来：相对实际后缀的额外银行利润，恰为旧前缀损失减去新遗漏信用。把 `R` 丢掉或逐枝用整份G支付，都会掩盖真正跨互斥子树义务。

对任意非负分支权重 lambda，(B-sum) 可直接线性相加。若想将所有尾部G奖励共同压到一次 `|G|`，必须额外构造与实际玩家G份额兼容的路由/容量；单枝 `L_i,T(G)<=|G|` 不能逐枝相加后仍只付一次G。本轮未构造这一路由。

## 最优替换能做什么、不能做什么

已有联合替换稿可控制每条真实尾部在 O 外取得的客户并集（零背景时这正好是尾部O外总利润）。但当 O 已是全目录并集时，所有外部逃逸预算均为零，已有中间关联的驻留负flux模板仍可逐客户发生。因此外部G预算不能单独支付一般中间关联的 inside covariance；还需要真实更早节点比较或跨客户信用。这个观察只是机制定位，不是合法 SPE 反例。
