## 可复用的乘法驻留界

以下自足推导已交relay_transport合并，以便和其sharp加法债务使用同一实现。
令r>=2、n=r-1。对于某个客户，根主题membership为I_i∈{0,1}，尾部实际负载为K_i∈{0,...,n}。
尾部主题分别归属某包含它的极大主题，路由矩阵列和n，π为驻留概率。于是

    E_π K <= n E_π I.

固定整数背景b>=0，定义根份额d_i=I_i/(b+I_i+K_i)，剩余全部玩家份额
R_i=(I_i+K_i)/(b+I_i+K_i)，零分子按零。对于I=1侧记L=n-K。
平衡不等式给 `E_(I=0)K <= E_(I=1)L`。I=0侧若K>=1，有
`K/(b+K)<=K/(b+1)`，所以

    E R <= E_(I=1) [(1+K)/(b+1+K)+L/(b+1)]
        = E_(I=1) [d*(r+LK/(b+1))]
        <= [r+floor(n^2/4)/(b+1)] E d.                 (M)

因此平均尾部收益与平均根收益之间只能得到

    E[tail total]/n <= [1+floor(n^2/4)/(n(b+1))] E d.

这个界甚至不需要无self路由假设。它是所有此类单客户菜单的sharp乘法界：
四标签I0,I1,O0,O1，客户只属I0,I1；取整数1<=l<=n，根I_j的尾部为
`(n-l)`份I_(1-j)及l份O_j，根O_j尾部为一份I_j及n-1份O_(1-j)。
驻留质量为π(I_j)=1/[2(l+1)]、π(O_j)=l/[2(l+1)]；I侧K=n-l，O侧K=1。
选l使l(n-l)=floor(n²/4)，式(M)取等。可给每主题加私有anchor保持互不包含；
本处只声称该客户的标量取等，不声称整个合法客户实例或完整SPE取等。

b=0时，平均尾/根的sharp比值为 `1+floor(n²/4)/n`，随r线性增大。
故已知r3的-1/8问题不能靠常数因子的逐客户根尾比较统一修复。
这里没有提供half所需的新正面预算，只准确识别了应由真实中继补偿的二阶量LK。
