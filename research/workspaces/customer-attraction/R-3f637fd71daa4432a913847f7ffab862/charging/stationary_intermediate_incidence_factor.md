# 任意关联的逐客户平稳乘法修补：精确常数与退化障碍

2026-10-23，charging 内部分支。状态：自足代数推导，未独立内审。
这是对一个菜单模板的定量停界，不是完整 SPE 反例；Q-CAG-HALF 仍 OPEN。

## 1. 菜单对象

有 k 个强制极大根分支，每分支 n>=1 名真实后继。把各后继行动路由到包含它的极大主题，得到整数 n_{ji}>=0，满足 n_{ii}=0、sum_j n_{ji}=n。
取列随机矩阵 n_{ji}/n 的任意平稳分布 pi。

固定一个客户 x、其背景负载 b>=0、极大归属 I。记 a_i=1_{i in I}，K_i 为根 i 分支中真实覆盖 x 的后继人数。
唯一使用的覆盖信息为

    0<=K_i<=sum_{j in I}n_{ji},
    sum_i pi_i K_i <= n sum_{i in I}pi_i.                 (S)

根收益与后继平均收益在该客户上的平稳平均分别为

    R=sum_i pi_i a_i/(b+a_i+K_i),
    F=sum_i pi_i K_i/[n(b+a_i+K_i)].

分母为零时相应零分子项按零计。

## 2. 精确通用乘法因子

令

    M=floor(n^2/4),
    beta=n(b+1)/[n(b+1)+M],
    c=beta/[n(b+1)].

**引理。** 对上述所有菜单，R>=beta F。

证明逐分支扣除 c(na_i-K_i)。当 a_i=1、K_i=q 时，剩余为

    1/(b+1+q)-beta q/[n(b+1+q)]-c(n-q)
      = beta[M-q(n-q)]/[n(b+1)(b+1+q)] >=0,

因为整数 0<=q<=n 满足 q(n-q)<=floor(n^2/4)。
当 a_i=0、q>=1 时，剩余为

    -beta q/[n(b+q)]+cq
      = beta q/n [1/(b+1)-1/(b+q)] >=0.

q=0 的外侧项准确为零。以 pi 求和，(S) 给出被扣除总额非负，故 R-beta F>=0。证毕。

该证明甚至没有使用无自环条件；无自环不会改善以下四根的锐性构造。

## 3. 四根、2of4 关联已达到等号

任取整数 q in [0,n]。固定 I={1,2}，有四个根，非零路由计数如下：

| 根 i | 后继目的 j 及人数 |
| --- | --- |
| 1 | j=2: q；j=3: n-q |
| 2 | j=1: q；j=4: n-q |
| 3 | j=1: 1；j=4: n-1 |
| 4 | j=2: 1；j=3: n-1 |

零数项省略，全部无自环。设 p=1/(n-q+1)，取

    pi_1=pi_2=p/2,
    pi_3=pi_4=(1-p)/2.

直接核算 n pi_j=sum_i pi_i n_{ji}。可令后继选择整个目的极大主题，于是两个内侧根的 K=q、两个外侧根的 K=1。相应

    R=p/(b+1+q),
    F=[p q/(b+1+q)+(1-p)/(b+1)]/n,
    R/F=n(b+1)/[n(b+1)+q(n-q)].

取 q=floor(n/2)，便得到 beta，故 §2 的通用因子精确最优。
可给四个极大主题各添私有标记客户以保证它们互不包含；这里的等号仅讨论固定 2of4 客户的贡献。

完全具体的共同目录可取五名客户 x,p_1,p_2,p_3,p_4，四主题

    B_1={x,p_1}, B_2={x,p_2}, B_3={p_3}, B_4={p_4}.

它们恰是四个不同包含极大元。根 i 后的 n 个后继按表逐一选择合法全主题 B_j；因此 K 上界在四个分支同时取等，并非只写出无法由共同目录实现的数字。
四个根后的有序历史互异，可将这四条物理可行路径同时扩展为一份完整纯策略（在余下节点任意填行动）。该扩展的最优性未验证，不能称为 SPE；尤其私有标记可能给真实末位盈利偏离。
所比较的 R/F 仅是客户 x 的逐类型系数；加标记后不声称总根收益/总后继平均仍等于 beta。

## 4. 一般主线的致命缺口

空背景 beta=n/[n+floor(n^2/4)]，趋于 4/n。因此对任意固定 alpha>0，当后继人数足够大时，断言逐客户 R>=alpha F 已被上述无自环、平稳四根菜单否定。

这量化了已有极端关联证明无法直接推广至中间关联的原因。它不排除依客户、依实例选择不同分布，不排除跨客户正余项共同支付，也不排除调用每名后继的真实更深 SPE 行。
上述菜单只满足路由与平稳性，**没有认证为 SPE**。因此不能据此否定 theta、聚合安全值或 half 目标。

继续沿平稳路线时，真正新增的信息必须超出无自环、平稳性与逐客户容量：例如分支内末位的跨根最佳回复，或不同客户类型之间受同一真实后继行动约束的共同信用。

## 5. 加入所有后继高于所有根，仍不能令逐客户亏损消失

以下补充仅说明模板停界，并不把 §3 的任意 n 菜单认证为 SPE。
在 n=2,q=1 时，四个单位客户的关联取

    {1,2}, {1,3}, {2,4}, {3,4}.

每个主题含两个客户；这正是四环的顶点—边关联。相对顶点指唯一与本顶点不共享客户的主题。三个玩家采用以下完整策略：

1. 根任选主题 a；第二位在 a 后选一个固定邻点 b。
2. 任意前缀 (a,b)：若 b=a，末位选 a 的相对顶点；若 b 邻接 a，末位选 a 的另一个邻点；若 b 是 a 的相对顶点，末位复制 b。

末位收益依这三种前缀类型为 2、3/2、1，逐一枚举四个合法偏离便知都是最佳回复。
第二位选邻点终局得 3/2；复制根或改选相对点都得 1，故各历史最优。
第一位任意主题都被两个邻点回复，收益恒为 1。于是这确为全部有序历史上的纯 SPE，根收益 1、两后继均 3/2。

四个强制根的真实菜单恰为 §3 的 n=2,q=1 表。平稳分布均匀，每个上述客户都达到 beta=2/3；全部客户合计也达到 R/F=2/3。
所以即使加入“存在共同 t，全部后继收益至少 t、全部强制根收益严格低于 t”以及真实末位 BR，原始平稳非负式仍不成立：取 t=3/2 即可。

然而每个根分支的福利均为 4，等于 OPT_3。静态 theta_3=1（在相对主题前缀下取得），没有违背首位 theta 保底。
这一例强调：平稳根—后继比较的负项可以纯粹来自角色间再分配，与实际遗漏没有直接对应。下一机制须量化未覆盖客户，不能把强制根低于全部后继本身当成福利缺口。
