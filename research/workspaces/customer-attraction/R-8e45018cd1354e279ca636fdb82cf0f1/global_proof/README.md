# 一般证明分支：对称 iid 局部递推障碍

主目标 Q-CAG-HALF 仍 OPEN。本分支未获得一般证明或目标反例。

尝试的候选：令 Z_r(b) 为背景 b 下 r 人静态对称混合 Nash 的期望剩余利润。希望沿真实 SPE 首步 A 有 u_1+Z_{r-1}(b+1_A)≥Z_r(b)，从而递推全局福利桥。该候选已经被最小的两不交 singleton、三玩家游戏直接否定，无须数值优化。

取 A={a}, B={b}。完整 SPE 为根 A；第二人在 A 后选 B、在 B 后选 A；末位在 AA、AB、BA、BB 后分别选 B、A、B、A。每个节点为最佳反应，实际 ABA，收益(1/2,1,1/2)，W=OPT_3=2。根静态三人对称混合 Nash 唯一为 q_A=q_B=1/2，故 Z_3(0)=2[1−(1/2)^3]=7/4。固定首步 A 后，两剩余人静态对称混合 Nash 唯一 q_B=1（两纯收益比较为 A:1/2−q_A/6，B:1/2+q_A/2），故 Z_2(1_A)=1。因此局部差 u_1+Z_2−Z_3=−1/4。

这只排除上述逐步 Z 递推；本例全局 W>Z_3。其他团队已独立攻击更强全局 W≥Z 桥，本分支不把这里的局部失败升级为全局结论。

代码 `iid_drift_probe.py` 是先前发现此障碍的可重放数值探索（seed 8913；SLSQP ftol=1e−10、maxiter=300；规范精确 SPE oracle）。其六主题候选已被上面两主题手算反例替代；`iid_drift_candidate.json` 仅保留发现来源。数值值不是数学证明。

下一步应改换主目标级别的全局控制，而非继续修补同一个逐步 iid 不变量。一般半覆盖仍缺跨实际偏离分支的联合补偿。
