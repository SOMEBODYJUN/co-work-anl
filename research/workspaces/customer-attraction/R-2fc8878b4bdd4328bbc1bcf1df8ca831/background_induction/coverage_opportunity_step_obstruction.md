# 新增覆盖候选的首步归纳障碍：23 个单位客户

2026-10-21。个人研究结果。下述反例已经由独立于 LP、游戏求解器的
`Fraction` 脚本逐有序历史重放；父代理尚未独立复核此 23 客户版本。
它只否定一个更强的首步充分条件，不否定背景整体候选或 Q-CAG-HALF。

## 1. 整体候选与首步充分条件

固定任意合法有序背景历史，客户负载为 b，尚有 r 位玩家。令

* P 为给定完整纯 SPE 中未来 r 人的总利润；
* Δ 为未来行动新覆盖的、满足 b_x=0 的客户数；
* O_r(b) 为至多 r 个共同目录主题能够覆盖的 b_x=0 客户最大数。

当前正在探索、尚无一般证明或真正反例的候选是

    P + Δ >= O_r(b).                                      (GLOBAL)

空背景时 P=Δ=W，所以 (GLOBAL) 恰好成为主半覆盖命题。这里的背景版本
不把未来利润 P 冒充总覆盖，也不把原背景遗漏集合替换为最终遗漏集合。

若首位实际主题为 A，首位未来收益为 u，令

    a = |A ∩ {x:b_x=0}|,
    L = u + a + O_(r-1)(b+1_A) - O_r(b).

一个足以直接归纳 (GLOBAL) 的局部加强是 L>=0。它与已否定的
F_r 利润机会成本税是不同公式；本例证明这个新的局部加强同样不成立。

## 2. 单位客户、合法背景与完整续局策略

共同目录有六个主题，标签 0,...,5。每行表示该数量的不同单位客户。

| 感兴趣的主题 | 客户数 |
| --- | ---: |
| {0} | 3 |
| {0,1} | 1 |
| {2} | 6 |
| {3} | 1 |
| {1,3} | 5 |
| {4} | 3 |
| {1,4} | 1 |
| {0,2,4} | 1 |
| {1,2,5} | 2 |

共 23 名单位客户。固定过去有序历史为 (2,5)，尚有三人。以下规定未来
每个有序历史上的行动，故不遗漏任何离轨历史：

1. 第一位选 2。
2. 第二位在第一位选 1 后选 2；在其他第一位行动后都选 1。
3. 最后一位在未来前两动作均为 1 时选 2；在无序动作对为
   {1,3}、{1,5} 或 {3,3} 时选 0；其余情况均选 1。

最后规则只是一份合法的特殊计数策略，没有把允许的全部纯策略限制为计数策略。
独立脚本遍历深度 0、1、2 的全部 1+6+36=43 个有序节点，逐一重算六个
偏离在指定真实续局中的收益，共 258 项比较，全部满足 SPE 最优性。
将这份子博弈 SPE 向前用有限逆向归纳补全，即得到原五人博弈的完整 SPE；
固定历史 (2,5) 不必是补全后根路径上的历史。

## 3. 精确严格违反与整体候选的正余额

实际未来路径是 (2,1,1)。原背景未覆盖的客户恰有 14 名。主题 0、3、4
覆盖全部这 14 名，因此 O_3(b)=14；任意两个主题最多覆盖其中 10 名，
例如主题 3、4 达到该值。首位重复主题 2，故 a=0，且 O_2(b+1_2)=10。

首位收益为

    u = 6/2 + 1/2 + 2/5 = 39/10.

另外两位各有 7/2+2/5=39/10。因此

    L = 39/10 + 0 + 10 - 14 = -1/10 < 0.

但整条路径 P=117/10，新增覆盖 Δ=7，故

    P + Δ - O_3(b) = 117/10 + 7 - 14 = 47/10 > 0.

所以这是首步加强的严格反例，不能称为 (GLOBAL) 或半覆盖的反例。

## 4. 正确的剩余归纳义务

定义给定续局的整体余额 G_r(b)=P+Δ-O_r(b)。对真实首动作 A，总有精确恒等式

    G_r(b) = G_(r-1)(b+1_A) + L.                         (TEL)

本例尾部两人的余额是

    G_2(b+1_2) = 78/10 + 7 - 10 = 48/10,

恰与首步 -1/10 相加得到整体 47/10。因而仅归纳得到 G_tail>=0 不足以
闭合证明；若 (GLOBAL) 为真，必须使用足够强的状态量来量化尾部正余额，
或给整条路径的全局支付。不能把 (TEL) 中每一步都认作非负。

## 5. 文件与发现证据等级

* `audit_coverage_step_v2.py --check-only`：23 客户 v2 不写文件的定义级精确重放；不导入
  LP、原规范求解器或发现程序。
* `coverage_step_exact_audit_v2.json`：冻结的 23 客户 v2 全部比较记录，勿原位覆盖。
  不带 v2 的脚本和 JSON 是开发期间的过渡文件，不再用作引用入口。
* `coverage_step_lp_candidate.json`：488 客户发现源的归一化浮点解；不是正式证书。
* `coverage_step_compressed.json`：23 客户压缩来源；其正确性由上述精确重放确认。
* `probe_coverage_step.py`、`probe_coverage_step_lp.py`：有限发现工具。
  q6,r4 的 2000 个随机背景实例未发现局部式失败，而完整策略锥 LP 的
  q6,r3 第 47 棵策略已找到上述来源，说明有限无反例并非一般证据。

488 客户发现源和 23 客户 v2 是同一首步桥失败命题的两个不同见证。
488 版局部差额 -5、整体差额 104；23 版局部差额 -1/10、整体差额 47/10。
两套重数、证据身份与数值不得相互替换。

不存在人数、客户数或主题数最小性的结论；也没有外部同行评审或新颖性认证。
