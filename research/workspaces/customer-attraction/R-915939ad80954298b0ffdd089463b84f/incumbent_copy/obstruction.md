# 最坏可信后继也不能规范为对先入主题静态复制稳定

本文件记录本轮从任意人数机制出发检验的一条归约及其**精确反例**。它不是六人半覆盖的反例：本例 `W=OPT_6=45`。不声称最小规模或新颖性；数学核验等级为作者解析核对、独立实现回放，尚未由另一研究员审查。

## 被否定的准确全称命题

采用 CAG-MODEL，任意人数 m≥2，固定一个合法首主题 T。对首位已固定 T 后的全部完整历史纯 SPE 后继，令

`a(T)=min u_T`。

候选要求：存在一个达到 a(T) 的后继终局 z，使每名后继玩家对以下**静态**变动均不盈利：把自己的主题换成 T，并冻结所有其他终局行动。

这是试图将最坏可信稀释转换为静态 copy 条件的辅助归约；它并非 SPE 定义，也并非 half 的等价表述。根已选 T 者不再被要求在该孩子重新最优。被否定的量词包含“在全部最坏续局中存在一个”，不是只否定某个任意平局选择器。

## 单位客户及终局

六人，共同目录五主题0,…,4。下表每行表示该数量的不同单位客户；无带权玩家。

| 感兴趣主题 | 客户数 |
| --- | ---: |
| {0} | 6 |
| {1} | 6 |
| {2} | 4 |
| {3} | 3 |
| {0,3} | 6 |
| {1,3} | 1 |
| {0,4} | 4 |
| {2,4} | 1 |
| {0,2,4} | 1 |
| {3,4} | 7 |
| {2,3,4} | 6 |

固定 T=0。全部后继 SPE 的终局计数都等于

`q=(1,1,1,2,1)`。

全部根 SPE 的计数同样只有 q；可实现有序根路径恰为

`(0,3,3,4,1,2)`、`(0,3,3,4,2,1)`。

主题收益依次为

`(31/3,19/3,19/3,23/3,20/3)`，

所以 a(0)=31/3。第四位选择主题4，收益20/3；若冻结其他行动，把它改成0，则新计数为(2,1,1,2,0)，收益变为41/6。因此静态增益为1/6>0。唯一可信终局计数已排除通过另选最坏后继修复这项复制条件。

原SPE中的**真实**第四位偏离有后继重置。下面固定可重建的一份完整策略：实际路径(0,3,3,4,1,2)，历史(0,3,3)后强制选0，再沿同一策略，得到

`(0,3,3,0,4,1)`。

偏离者收益37/6，相对20/3的真实增益为−1/2。故静态盈利复制与真实不盈利完全相容，不能将两者识别。

## 全量有限证明的合同与复现

[verify.py](verify.py)包含固定输入及两条独立实现路径，不需要重跑发现扫描。

1. 独立有序树逆向归纳，直接展开45个不同单位客户，以 Fraction 计算。递归在每个**有序**历史保存所有可实现的有序终局，不按计数锁定任何平局。若动作a的孩子终局集合为R_a，当前位置为i，则最低可强制阈值为`M=max_a min_{z∈R_a}u_i(z)`；返回各孩子中`u_i(z)≥M`的全部终局。这来自各不相交孩子可独立选后继SPE。该有限集合递归精确穷尽本实例的所有纯SPE终局；并非用“无反例搜索”证明一般命题。
2. 仓库规范全集求解器单独重算根及固定T孩子，生成具有上述实际路径的完整策略；规范定义级核验器检查全部3906个决策历史、15624项非自身偏离。独立单位客户实现再对这份完整策略检查3906个历史、19530项含自身行动比较，全部非负。

独立根树递归包括19531个有序节点（含终局）；固定T子树包括3906个节点（含终局）。独立枚举最优覆盖等于45，实际覆盖同为45。完整输出在[exact.json](exact.json)。

## 改变的认识及接续边界

这条归约原本希望：先在全部可信后继中极小化先入者收益，再以静态复制稳定性控制其稀释。失败机制是中间玩家改行动会重置更晚真实回复；即使可信终局计数唯一，这个差异仍存在。计数唯一不等于所有偏离都冻结后继，也不等于同计数历史采用相同策略。

下一步必须保留中间真实偏离后继，或者证明其损失可由共同银行支付。仅选更狠威胁、对最坏续局再破平局、或要求最低叶后继各有先入者收益保底，均不能免费补此归约（本例各后继收益都低于31/3）。原半覆盖目标、本例的全部真实SPE，以及保留完整后继的查询工具均未被反驳。此处没有新的正面福利界。
