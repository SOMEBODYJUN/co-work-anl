# 末主题提前：末两人势单调不能无损迭代，且新枝 reset 系数尖锐

状态：下列恒等式有自足证明；一个参数家族否定明确的势单调加强。**不是一般 half 或六人 half 的反例。** 家族是原单位客户、共同有限目录、完整有序历史纯 SPE 模型，保留任意历史平局。本页不声称基础三主题实例本身新颖，也不把既有强 PAIR 改名为新付款。

## 1. 原拟推广机制及准确断点

固定任意背景负载 b，定义调和势增量

`Phi_b(Z)=sum_x [H_(b_x+c_x(Z))−H_(b_x)]`，`H_0=0`。

真末两人节点的规定终局为 `(B,C)`。在同一源强制选 C，真末位回复 V。记

`U_b(X,Y)=sum_(x in X)1/(b_x+1+1_Y(x))`，
`f_b(X)=sum_(x in X)1/(b_x+1)`。

直接由精确势和新末位查询 B 得

`Phi_b(C,V)−Phi_b(B,C)=U_b(V,C)−U_b(B,C) >= 0`。

另外

`f_b(V)−f_b(C)`
`= [U_b(B,C)−U_b(C,V)] + [U_b(V,C)−U_b(B,C)] >= 0`。

右边两项分别为原倒二对 C 的真 IC、新末位 V 对 B 的真 IC。这解释了先前 `promoted_last_reply.py` 的叉；完整末位回复轨道的静态运输已在共享 `stationary_pair_transport.md` 中处理，以上不构成新增共同福利预算。

一个真正跨人数的候选是：任意余 k 人的真节点，把原末主题提前到源，再走同一 sigma 的真实后继，调和势仍不降。**该候选已经在 k=3 失败。** 失败不仅来自冻结后继，而来自同一份合法历史依赖策略中互斥分支的真实重置。

## 2. 三人完整 SPE 的解析家族

任取正整数 t。三个互不相交单位客户组为 P,Q,O，大小分别为 `2t,2t,3t`。共同目录恰为

`A=P union O`，`B=Q union O`，`C=P`。

根选 A。第二人的动作在第一人选 A、B、C 后分别为 B、C、B。第三人的完整动作表为：

| 第一人 / 第二人 | A | B | C |
| --- | --- | --- | --- |
| A | B | B | B |
| B | A | A | B |
| C | B | A | B |

注意 `(A,B)` 与 `(B,A)` 的计数相同，但末位动作分别为 B、A，均是合法平局。限制为同计数同回复会漏掉这份策略。

末位每个历史上的三项查询收益，以及第二人每个历史上的真实偏离收益，均由脚本精确逐单位核验。也可直接核对第二人的三个收益向量（按 A,B,C，所有数字乘 t）：

* 首主题 A：`(2,2,1)`，规定 B；
* 首主题 B：`(2,2,2)`，规定 C；
* 首主题 C：`(5/2,7/2,1)`，规定 B。

根三项真实收益为 `(3,5/2,1)t`，规定 A 因而最优。末位有限表和这四项比较覆盖全部十三个有序决策历史，故这是完整纯 SPE，而非一条仅在轨路径。

实际终局为 `z=(A,B,B)`，收益 `(3,2,2)t`。其原末主题 B 提前根后，真终局为 `z'=(B,C,B)`，收益 `(5/2,2,5/2)t`。有

`Phi_0(z)=21t/2`，`Phi_0(z')=19t/2`，

所以 **势严格下降 t**。同时 `W(z)=OPT_3=7t`，half 有充足余量。

## 3. 正确的三人 reset 界及系数不可减

这一节使用既有强 PAIR，不认领新的金额。一般真三人节点实际为 `(A,B,C)`；强制原末 C 到源后，真续局为 `(C,D,E)`。在固定背景 `b'=b+1_C` 的真末两人节点 `(D,E)`，强 PAIR 比较合法主题 A,B 给

`Phi_b(A,B,C)−Phi_b(C,D,E)`
`<= g_(b')(D,D)−g_(b')(D,E)`
`= sum_(x in D\E) 1/[(b'_x+1)(b'_x+2)]`，

其中 `g_b(X,Y)=sum_(x in X intersect Y)1/[(b_x+1)(b_x+2)]`。证明只需强 PAIR 的

`U_(b')(D,E)+U_(b')(E,D)+g_(b')(D,D) >= Phi_(b')(A,B)`

和 `U_(b')(D,E)+U_(b')(E,D)=Phi_(b')(D,E)−g_(b')(D,E)`。

在上节家族中，推广记号的 C 是家族主题 B，D 是家族主题 C，E 是家族主题 B。新枝倒二独有集恰为 P，且 P 没有旧背景或提前主题负载。因此 reset 税为

`|P|/(1*2)=t`，

**恰等于势下降 t**。因此这个无条件三人 reset 界里，保持其余项不变时不能把该税乘一个全称常数 alpha<1；更不能免费删掉它。此结论不是说一切别的共同预算都不可能。

## 4. 任意 k 的精确真实枝账与下一义务

下列只是把需支付的对象固定清楚，不把恒等式算作付款。原真叶为 `(A_1,...,A_k)`，令 C=A_k。对 j=1,...,k，令 Z_j 是强制有序前缀 `(C,A_1,...,A_(j−1))` 后沿同一 sigma 的完整后继；因此 Z_1 是提前分支，Z_k 是原叶的循环排列，势与原叶相同。

对 j<k，在该长度 j 的前缀后的真节点，令规定当前行动者为 a_j，强制比较行动为 A_j。令 Gamma_j 为这条真 IC 的非负松弛。Z_j^- 和 Z_(j+1)^- 分别删掉两枝中的该位玩家，保留所有真正其他行动。精确势差给

`Phi_b(original)−Phi_b(Z_1)`
`= sum_(j=1)^(k−1) [Phi_b(Z_(j+1)^-)−Phi_b(Z_j^-)−Gamma_j]`。

最后一项的删位势差为零；其余项是互斥真枝的**有符号 reset**，不能识别为同一个删位游戏的 SPE，也不能无损望远镜。k=3 时强 PAIR 可把它们的净额付成上节新枝独有税；家族证明该付款可能恰好用尽。

真正下一义务是为不同源、不同提前主题产生的新枝 reset 找到同一份实际福利预算，或更强的跨枝抵消恒等式。重复沿末位回复图闭包、逐枝分别用强 PAIR、或把每个新枝税视作已有实际税，都没有完成这项义务。全 n half 与六人 half 仍 OPEN。
