# 同一共同目录中增加提供者使全部完整 SPE 福利下降

## 精确身份与状态

候选身份 `B1-POPULATION-WELFARE-NO-v1`。对象为原 `CAG-MODEL`：有限单位客户、
有限非空共同主题目录、单位权提供者、固定次序、完整有序历史纯 SPE，保留全部平局。
本文件是自足辅助反例，不是 Q-CAG-HALF 反例。尚未经外部审查，新颖性未认证；
独立内部审查由 Boss 另行组织。这里的全称只涉及下述固定目录的人数三和四，
不能扩大成一般人口变化公式。

**Exact statement.** 存在同一个十二单位客户、三个两两不同且包含极大的共同主题目录，
使三名提供者的每一个完整纯 SPE 福利都等于十二，而四名提供者的每一个完整纯 SPE
福利都等于十一。三人全部可实现有序路径恰为 `ABC, BAC`；四人全部可实现有序路径
恰为 `AABB, ABAB, ABBA, BAAB, BABA, BBAA`。

因此，无论以最差或最佳完整 SPE 福利衡量，增加提供者都未必使福利非减。
把每一类客户复制任意正整数 q 次，保留全部 SPE 最优性及路径集合，福利由 12q
下降至 11q，绝对损失无界。这种同次缩放不是一个新的策略机制。

## 客户与收益

| 客户兴趣集合 | 不同单位客户数 |
| --- | ---: |
| 仅 A | 3 |
| 仅 B | 3 |
| 仅 C | 1 |
| A、B | 1 |
| A、C | 2 |
| B、C | 2 |

没有 ABC 共同客户。三主题大小分别为 6、6、5，且各有私有客户，故三者两两不同、
互不包含，严格符合集合目录而非重复标签。

终局计数 (a,b,c) 中，若对应坐标为正，

\[
U_A=3/a+1/(a+b)+2/(a+c),\quad
U_B=3/b+1/(a+b)+2/(b+c),\quad
U_C=1/c+2/(a+c)+2/(b+c).
\]

求值时仅在所选主题坐标正时使用该式。W(1,1,1)=12，W(2,2,0)=11。
三人、四人最优福利都为 12，因此反例满足半覆盖，且离违反半覆盖很远。

## 三人完整子博弈分类

最后一个玩家的精确收益如下。只把历史中 A/B/C 的顺序压缩用于显示收益；
同计数的各有序历史仍可独立选择任意最优行动。

| 已选两主题 multiset | 选 A | 选 B | 选 C | 全部最优行动 |
| --- | ---: | ---: | ---: | --- |
| AA | 2 | 16/3 | 11/3 | B |
| AB | 17/6 | 17/6 | 3 | C |
| AC | 8/3 | 9/2 | 13/6 | B |
| BB | 16/3 | 2 | 11/3 | A |
| BC | 9/2 | 8/3 | 13/6 | A |
| CC | 14/3 | 14/3 | 5/3 | A 或 B |

首主题为 A 时，第二人选 A、B、C 后的实际自身收益分别为 17/6、9/2、3，
因此唯一选 B，末位随后唯一选 C。首主题为 B 时由对称性得到 BAC。
首主题为 C 时，第二人选 A 或 B 后各得 9/2，选 C 后无论末位在 A/B 如何平局
均只得 13/6，因此后继路径为 CAB 或 CBA，首位 C 的最终收益均为 3。

根选 A、B、C 所得首位收益分别为 9/2、9/2、3。故完整 SPE 根路径恰为 ABC、BAC。
每个孩子子博弈都已包含全部离轨回复与其平局，既没有遗漏惩罚，也没有强加共同平局。

## 四人完整子博弈分类

最后一个玩家的收益表：

| 已选三主题 multiset | 选 A | 选 B | 选 C | 全部最优行动 |
| --- | ---: | ---: | ---: | --- |
| AAA | 3/2 | 21/4 | 7/2 | B |
| AAB | 23/12 | 11/4 | 8/3 | B |
| AAC | 11/6 | 13/3 | 2 | B |
| ABB | 11/4 | 23/12 | 8/3 | A |
| ABC | 5/2 | 5/2 | 11/6 | A 或 B |
| ACC | 5/2 | 25/6 | 3/2 | B |
| BBB | 21/4 | 3/2 | 7/2 | A |
| BBC | 13/3 | 11/6 | 2 | A |
| BCC | 25/6 | 5/2 | 3/2 | A |
| CCC | 9/2 | 9/2 | 5/4 | A 或 B |

代入第三人的比较，全部两人续局路径菜单为：

| 前两主题 multiset | 全部 SPE 续局后缀 |
| --- | --- |
| AA | BB |
| AB | AB 或 BA |
| AC | AB、BA 或 BB |
| BB | AA |
| BC | AA、AB 或 BA |
| CC | AB 或 BA |

例如在 AC 背景，第三人选 A 后末位唯一选 B，当前人得 5/2；选 B 后末位可在
A/B 间平局，当前人得 13/3 或 5/2；选 C 后末位唯一选 B，当前人得 11/6。
因此选 B 总能最优；若其指定离轨续局取使 B 得 5/2 的末位平局，选 A 也最优。
这恰产生 AB、BA、BB 三个后缀，不得把同计数的平局绑定在一起。
其他五行由上表直接比较得到。

首主题为 A 时，第二人选 A 或 B 后各得 11/4；选 C 后，无论后续菜单如何选，
终局计数均为 (2,1,1) 或 (1,2,1)，第二人 C 都得 8/3。
由于 11/4>8/3，第二人只可能选 A 或 B，之后必补齐两 A 两 B。
首主题为 B 时同理。

首主题为 C 时，第二人选 A 或 B 后自身收益可以因离轨平局而异，但其支持的
全部终局计数均为 (2,1,1) 或 (1,2,1)。若第二人选 C，后两人必须分别选 A、B，
第二个 C 的收益为 11/6；第二人改选 A 的任何可信续局收益至少 5/2，故 C 不可能
最优。因此首位 C 的全部可信后继终局都是 (2,1,1) 或 (1,2,1)，首位收益均为 8/3。

根选 A、B 始终各得 11/4；根选 C 始终得 8/3。因此根只选 A 或 B。
上述子菜单同时表明所有两 A 两 B 的六种有序排列都可完整补全。
故所有完整 SPE 福利严格为 11，结论包括全部离轨历史及任意合法历史平局。

## 独立可复现证据

`population_paradox_audit.py` 不导入规范包、不调用 max-min 门槛递推。
它逐个有序历史枚举全部孩子 SPE 终局路径的 Cartesian 组合，再保留当前收益最大
的所有行动。不同孩子的策略域不交，可独立拼合；每个终局路径保留一个完整子策略
证人足以对父节点进行全部收益比较，所以递推恢复全部可实现路径。

收益直接由十二个独立客户逐客户求 Fraction。它为每个返回路径单独回放完整策略，
对全部有序历史及每个非自行动检查最优性。三人证书每棵含十三个节点、二十六项
非自比较；四人证书每棵含四十个节点、八十项非自比较。

同目录人数一至五的运行结果也保留在 `population_paradox_audit.json`，但本命题只需
三人和四人。零客户、单个全主题客户、三个全主题客户的两人边界回归确认全部九条
有序路径可实现，不借助固定平局删去策略。

复现命令（从仓库根）：

```sh
python research/workspaces/customer-attraction/R-44b24f3962bd4f68a4b6913610c0d417/continuation_order/population_paradox_audit.py
```

## 为什么该路线失败，留下什么

失败路线是：先证明较少提供者的 SPE 福利下界，再以“增加一人只能改善覆盖”
直接向上归纳。这里三人每个 SPE 都覆盖所有客户，四人每个 SPE 都漏掉 C 的私有客户，
因此比较最佳或最差 SPE 都无法修复该单调步骤。

机制是均分拥挤改变末端的吸引力排序：三人遇到 AB 背景时末位唯一选 C；
四人实际末端为 AAB 或 ABB 时末位唯一补选 B 或 A，C 的 8/3 收益严格低于 11/4。
这并不阻止带精确补偿项的递归、全局半覆盖或其他跨分支机制。
下一步可测试该替代机制与接近半覆盖的 all-big 家族能否合法复合；添加主题会改变
全部离轨菜单，不能仅拼接在轨动作就声称复合有效。
