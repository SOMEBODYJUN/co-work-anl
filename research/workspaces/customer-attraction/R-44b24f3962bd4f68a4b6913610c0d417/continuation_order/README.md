# 完整续局菜单：人口变化障碍与新的聚合候选

一般 Q-CAG-HALF 仍 OPEN，本目录不含一般证明或主目标反例。

- `population_paradox.md`：自足十二单位客户、三个包含极大主题的辅助反例。
  三人每个完整 SPE 福利十二，四人每个完整 SPE 福利十一；全部子博弈分类和
  任意合法平局均明确。堵住以人数福利非减作直接归纳的路线，等待独立审查。
- `population_paradox_audit.py` / `.json`：不导入规范包、逐有序历史 Cartesian
  拼合全部 SPE 子局路径，并独立单位客户 Fraction 回放全部离轨证书。
- `terminal_weight_budget.md`：真实末节点权重预算及开放的 m u_m≤2W 候选。
  本轮尚未证明该 cap，非原半覆盖等价；记录所缺全局预算及有限攻击范围。
- `terminal_cap_probe.py` / `.json`：随机完整可信策略锥，seed431903；一千二百棵
  的最大精确恢复 cap=8/5，样本范围不扩大为全称证据。
- `terminal_cap_iteration.py` / `.json`：针对最高末位占比的策略/锥迭代，seed431904，
  m=5,6,7、p=5 共二百三十二轮，最大 7/4，均未产生新边界。
- `terminal_cap_joint.py` / `.json`：三个指定路径的完整树 MILP 改目标攻击；
  全部二十秒超时且只得平凡端点，不能作数值上界证书。
- `markov_cap_joint.py` / `.json`：已知受限计数 Markov 搜索思想的 cap 改目标，
  四个固定路径，全部端点可完整有序展开；不作全称约化，也不宣称新工具。

人口反例的四人终局 AABB 本身也是静态 PNE，因而简单与不交 all-big 家族相加
没有显示突破半覆盖的机制；true_counterexample 分支在测试共享客户/主题变体。
下一步最有信息价值的是证明或反驳末位权重预算 (B) 能否全局推出 cap，或找到
人口替代机制与真实跨分支静态后悔的合法组合；不要重复已失败的单人克隆保底。

本轮已遇到该 cap 随机/迭代搜索的信息价值边界，重复同类有限锥不构成继续忙碌的理由。
