# 同目录增加一人可使所有 SPE 的福利同时下降：独立审查

状态：从单位客户定义独立重构并核验通过。发现者在审查前只提供实例与待查结论；本审查未读取发现代码或证明，不调用规范 `customer_attraction` 包，不使用 max-min 筛选递推。
这是否定人口福利单调归纳的辅助反例，不反驳 Q-CAG-HALF。外审、新颖性和最小性未认证。

## 对象与精确陈述

三个共同主题标签 A、B、C；不同单位客户依兴趣分组：

| 兴趣 | 客户数 |
|---|---:|
| A | 3 |
| B | 3 |
| C | 1 |
| AB | 1 |
| AC | 2 |
| BC | 2 |

共有十二名客户。三个主题都有私有客户，故覆盖两两不同，互不包含；目录是真正的有限集合。每位提供者仍单位权，完整有序历史、重复主题和所有合法平局均保留。

对同一目录：三人时，全部完整纯 SPE 的有序在轨路径恰为 ABC、BAC，福利恒为十二；四人时，全部完整纯 SPE 的在轨路径恰为 AABB 的六种排列，福利恒为十一。两种人数的最优覆盖都是十二。
因此不只是最差 SPE 福利，连最佳 SPE 福利也随人数增加而下降。

任取正整数 k，将每一分组复制 k 倍得到不同单位客户；所有终局个人收益乘 k，所有 SPE 比较保持，故福利从 12k 降到 11k。下降量无上界。该缩放是一般代数事实，有限运行仅检查其实现。

## 自足逆向归纳核对

终局计数 q=(a,b,c) 中，选择了相应主题的提供者收益为

\[
U_A(q)=3/a+1/(a+b)+2/(a+c),\qquad
U_B(q)=3/b+1/(a+b)+2/(b+c),
\]
\[
U_C(q)=1/c+2/(a+c)+2/(b+c).
\]

只对已选择主题使用相应式，故没有零分母。令 E_m(h) 为有序前缀 h 后全部可由完整 SPE 实现的有序终局。叶子 E_m(h)={h}。内部节点为每个行动的子局独立选择一个可实现终局，即

\[
(t_A,t_B,t_C)\in E_m(hA)\times E_m(hB)\times E_m(hC).
\]

在这个实际菜单中，当前人可选且仅可选其最终个人收益最大的行动。枚举全部菜单与全部最大者，取其选中终局的并集，恰得 E_m(h)。必要性来自每个子树自身为 SPE；充分性来自三个子树互不相交、可独立拼接并在根选最佳行动。没有要求同计数历史采用同一策略；下表的集合相同只是该实例的计算事实。

三人时末位节点的完整计数表如下。右列是可实现终局计数集合。

| 前缀计数 | 终局计数 |
|---|---|
| 200 | 210 |
| 110 | 111 |
| 101 | 111 |
| 020 | 120 |
| 011 | 111 |
| 002 | 102 或 012 |

三种一人前缀 100、010、001 均只能延伸至 111。根选 A 或 B 最终得 9/2；根选 C 最终得 3，因此根恰选 A、B。继续归纳得到路径恰 ABC、BAC。

四人时末位表：

| 前缀计数 | 终局计数 |
|---|---|
| 300 | 310 |
| 210 | 220 |
| 201 | 211 |
| 120 | 220 |
| 111 | 211 或 121 |
| 102 | 112 |
| 030 | 130 |
| 021 | 121 |
| 012 | 112 |
| 003 | 103 或 013 |

再向前归纳：

| 两人前缀计数 | 终局计数 |
|---|---|
| 200、110、020 | 220 |
| 101、011 | 211 或 121 |
| 002 | 112 |

一人前缀 100、010 只能延伸至 220；001 可延伸至 211 或 121。在根，选 A、B 均得 11/4，选 C 无论后继平局如何均得 8/3，且 11/4>8/3。故根不选 C，并最终得到全部六个 AABB 排列。

## 实际证据与范围

同目录 [population_audit.py](population_audit.py) 直接展开单位客户，通过有序子局的 Cartesian 菜单重构每个可实现根路径的一份完整证书，再遍历每个有序历史及每个行动计算真实偏离。三人有十三个决策历史，每份证书三十九次含自身比较；两条根路径共七十八次比较。四人每份证书四十个历史、一百二十次含自身比较，六条根路径共七百二十次比较。任一根路径的证书均覆盖全部离轨节点。

程序同时检查一人、两人、二倍客户缩放及零客户边界。冻结输出在 `population_audit.json`。重新运行默认只打印，`--output` 仅写一个尚不存在的路径，不覆盖冻结证据。

该反例排除“加入同质玩家时最差 SPE 福利不会下降”以及更强的逐均衡福利单调主张。它不排除适当配对不同人数均衡、允许福利损失的归纳，也不证明任何无限人数的下降模式。半覆盖主目标在两个实例中均成立，状态不变。
