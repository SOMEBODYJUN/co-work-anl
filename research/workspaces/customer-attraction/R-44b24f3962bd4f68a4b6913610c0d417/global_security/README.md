# Boss1：真正安全值与笛卡尔积可信耦合

原目标 Q-CAG-HALF 仍 OPEN，原模型全历史纯SPE及任意平局不变。本目录没有一般证明或目标反例。

## 新解析候选：福利非可加

先读 `cartesian_efficiency_failure.md`。两个各自每个SPE都最优的分量，完整笛卡尔积目录仍能出现低效SPE。三行a客户×两色q客户、三人、q≥a，联合完整策略有W=2a+2q<3a+2q=分量最差福利之和。a=q=1只需五客户六不同主题。全部43有序历史显式定义，末位合法平局可跨分量惩罚第二名的行偏离。

- `audit_cartesian_efficiency_failure.py`：不导入规范求解器、发现器或证书，按单位客户Fraction复算全树全部比较；独立写出的有序历史集合递推检查两分量所有SPE福利，另匹配安全值原始/对偶。
- `cartesian_efficiency_verified.json`：七组参数（含q=a边界），每组43节点258项含自比较，全部通过。
- `simple_cartesian_q1.json`：规范solver另行发现的五客户实例/全树策略；本正文使用更简洁的不同显式全树策略，二者不要混淆。

正文末段另给任意人数的一般正面分解边界：若每个分量在每个有序子博弈的全部SPE对全体玩家给同一支付向量，则每个联合SPE可逐分量实现，最差福利可加；逆向归纳解析证明，未声称必要性。该限定包括前缀玩家，不能只要求后继自身支付唯一。`audit_payoff_unique_product.py`及`payoff_unique_product_verified.json`是小规模有序终局全集的独立精确回归，检验符合假设的47组输入；一般证明来自正文逆向归纳。

状态：解析候选、定义级精确审计通过；仍待主代理或其他研究员独立攻击。外审、新颖性和全局最小规模均未认证。安全值强桥在本族成立，3v=2a+3q/2<W。

## 有限发现实验（不升为一般结论）

- `cartesian_probe.py`：两个三标签分量，联合九标签，计数缓存完整可实现终局集合；不限制计数Markov策略。用静态零和LP求分量安全值，其乘积可加性由既有资产证明。
- `cartesian_probe.log`：n=3、seed5101、1000输入，未发现真正安全强聚合或首对候选反例；发现福利非可加，后被上面精确解析族替代。
- `cartesian_n5_probe.log`：n=5、seed6154、500输入，同样无安全强桥或首对桥候选；不能据此增加一般命题真值。对应best JSON只是数值发现检查点。
- `shrink_cartesian.py`、`shrink_cartesian.log`、`shrunk_cartesian.json`：seed6113、150轮质量删减发现更简单族；发现中的重复标签已在最终六主题输入中去除并重新精确核验。
- `exact_cartesian.py`：最初51客户非可加候选的规范Fraction复现脚本；其大证书未保留，最终简单解析族已覆盖同一机制，避免冗余资产。

所有浮点实验发现与完整SPE精确认证分开。未发现反例不是证明。

## 尚缺的承重步骤与后续

真正强安全桥W≥m v_m、弱桥W≥(m−1/2)v_m仍未闭合。旧Boss7候选“任意背景首两人收益和≥2v_r(b)”若成立则可按在轨相邻配对与背景嵌入闭合强桥，但本轮未证明该首对命题；不因过去/本轮有限无反例而提升。

乘积机制进一步显示，不可把一般证明化约为对每个分量独立求SPE，再相加其最差福利。可尝试对跨分量可信惩罚收费，或者利用多层可信耦合搜索真正坏点。单个三人非可加族既不反驳半覆盖，也不保证可以无成本放大；必须计算惩罚分量自身福利。

后续放大探针：`singleton_product_probe.py` 在m=5、五行×四色目录上检查q=1,2,3,4，保存 `partition_product_m5.json`/`.log`。q=2的浮点候选W10、OPT13，前四人同行不同色、末位换行；未展开独立精确全树，不提升数学状态。这类单个末位的色惩罚需要支付约q/2以补同行损失，颜色分量自身福利不可忽略；现阶段没有越过半覆盖或安全值界的机制。这里停止该低信息参数枚举，下一次应尝试更深可信耦合或解析惩罚预算。
