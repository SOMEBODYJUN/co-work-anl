# 次模/联盟支付路线：静态有效性与动态报复损失

状态：一般路线工作稿；不是 Q-CAG-HALF 证明。研究对象仍是任意有限共同目录、任意人数、全部有序历史依赖纯 SPE。

## 1. 终局的 Shapley/次模事实

对终局 `a=(A_1,...,A_m)`，客户 `x` 的覆盖者集合记为 `C_x(a)`，`c_x=|C_x|`。对玩家联盟 `K⊆[m]` 记

```
U_K(a) = sum_{i in K} u_i(a)
       = sum_x |C_x(a)∩K| / c_x(a),
W_K(a) = |union_{i in K} A_i|.
```

逐客户立即得到

```
W(a)-W_{-K}(a) <= U_K(a) <= W_K(a) <= W(a).
```

左端是社会福利在删除联盟 K 后的边际损失；右端是联盟自己覆盖的客户数。等式 `sum_i u_i=W` 是 K=[m] 的特例。客户覆盖福利是动作集合上的单调次模函数，`u_i` 正是覆盖合作博弈的 Shapley 分配（随机玩家排列中 i 成为该客户首个覆盖者的概率为 1/c_x）。

若 K 由独立 Bernoulli(p) 选取，则还有可复用的负载谱恒等式

```
E U_K = p W,
E [W(a)-W_{-K}(a)] = sum_x p^{c_x},
E W_K = sum_x [1-(1-p)^{c_x}].
```

因此 `sum_x p^{c_x} <= pW <= sum_x(1-(1-p)^{c_x})`。这是一条对任意终局的次模/联盟预算，不使用均衡。

## 2. 静态有效效用支付的精确缺口

固定任意比较元组 `T_1,...,T_m`，令 `O=|union T_i|`，实际终局为 `a`，`C=union A_i`。若玩家 i 在**静态** profile 中改成 `T_i` 而其他玩家动作冻结，记

```
v_i = u_i(T_i, A_{-i}),
```

则只为 `O\\C` 中每个客户选取一个包含它的比较槽，即得

```
O-W <= sum_i v_i.                              (S)
```

这是 Vetta valid-utility 的覆盖专用一步：每个实际未覆盖比较客户在其指定槽中有完整单位份额。若终局是静态 PNE，则 `u_i>=v_i`，求和给 `O<=2W`。

对真实 SPE，强制 i 在其实际历史选 `T_i` 并让原策略按该新历史继续，记动态偏离收益 `g_i`，并定义报复损失

```
rho_i = v_i-g_i.
```

SPE 只给 `u_i>=g_i`，所以精确地

```
O <= 2W + R,   R := sum_i rho_i.                 (D)
```

证明：`O-W <= sum v_i = sum g_i + R <= W+R`。因此次模/Shapley 路线若要闭合 Q-CAG-HALF，必须证明所有比较元组均有 `R<=0`，或用更弱的全局 bound `R<=2W-O`。四客户和十四客户完整 SPE 证书表明单个 `rho_i` 可以严格为正，所以静态有效效用定理不能直接升级到 SPE。

## 3. 报复损失的客户级上界（仍不能聚合）

设在 i 的实际前缀上，静态冻结后的后继计数为 `k_x`，真实动态偏离 `T_i` 后的后继计数为 `\hat k_x`，并令 `q_x=b_x+1`（既有前缀覆盖加上偏离者）。则

```
rho_i = sum_{x in T_i} [1/(q_x+k_x)-1/(q_x+hat k_x)].
```

只对 `hat k_x>k_x` 的项，

```
1/(q+k)-1/(q+hat k)
 = (hat k-k)/((q+k)(q+hat k))
 <= (hat k-k)/(q+hat k).
```

右端可由偏离续局中新增覆盖者在 x 上的总份额支付。因此 `rho_i` 不超过偏离续局对 `T_i` 的新增后继覆盖份额；这是一个真实客户级可复核上界。问题在于对不同 i，新增后继续局不同且客户集合重叠，直接求和会重复使用同一福利。现有安全值/水位账本正是在这里遇到“跨互斥子树共同支付”缺口。

## 4. 明确的正报复损失证书

在 `research/current/customer_attraction/continuation_lemmas.md` 的十四客户、两人完整 SPE 中，实际路径为 `(A,B)`，`W=9`，而比较最优并集可取 `(B,T)`，`O=10`。玩家 1 静态改为 T、冻结玩家 2 为 B 时有 `v_1=5`；真实 SPE 偏离 T 触发玩家 2 改选 D，给 `g_1=4`，故 `rho_1=1>0`。玩家 2 为末位，`rho_2=0`。证书仍满足 `2W=18>O`，所以它只说明 `R<=0` 不能作为一般引理。

该例的正损失机制是：偏离者想拿到未覆盖 T 客户，但后继转向 D/E 重新占用部分 T 类客户，静态单位份额被稀释；后继动作仍为其真实最佳回复。任何把 SPE 改写为冻结后继的静态 PNE 证明都会在此处错误。

## 5. 研究结论与下一判别

- 已建立任意终局的 Shapley/次模联盟预算，以及把原目标精确化为“静态有效支付减去总报复损失”的式 (D)。
- 该路线尚未得到 `R<=0` 或可由 `W` 支付的全范围 bound；不能把静态 valid-utility 文献定理当作一般 SPE 证明。
- 最有信息量的后续是：寻找一个利用真实后继 IC 的跨 i 望远镜，使正 `rho_i` 由后继新增客户的福利或后继自身 SPE surplus 支付；若不能，需给出 `R` 可随 m 累积的完整主目标反例，而不是只扩展固定证书。

## 6. 不能把完整策略形式直接当作次模博弈

静态动作福利 `|union|` 次模，并不意味着把每位玩家的完整历史策略当成一个正常形博弈动作后仍次模。两人共同目录取

```
X={a,b}, Y={c,d}, Z={b,c,d}.
```

以 player 1 的基准策略 `Y` 为无元素，元素 `e1` 表示改为 `X`；以 player 2 的基准完整计划 `r_X=X, r_Y=X` 为无元素，元素 `e2` 表示只把 `r_X` 改为 `Z`（`r_Y` 保持 X）。诱导终局福利为

```
F(∅)=W(Y,X)=4,
F({e2})=W(Y,X)=4,
F({e1})=W(X,X)=2,
F({e1,e2})=W(X,Z)=4.
```

于是 `F({e1})+F({e2})=6 < 8=F(∅)+F({e1,e2})`，违反二元素次模不等式。故不能把完整策略博弈直接套静态 valid-utility/Vetta 结论；必须利用有序历史的真实 IC，而不是只把策略计划视为一个新的固定目录动作。
