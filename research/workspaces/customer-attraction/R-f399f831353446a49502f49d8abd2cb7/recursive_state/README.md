# 一般递归状态：最优遗漏客户的真实响应税

状态：候选全范围引理，尚未闭合 Q-CAG-HALF；已逐式检查其依赖只用完整历史 SPE。目标是记录一个可复用的递归接口，并明确税项为何仍是主障碍。

## 设置

固定任意完整历史依赖纯 SPE `sigma`，实际终局为 `z=(S_1,...,S_m)`，固定任意最优比较元组 `T_1,...,T_m`，并集 `C`，`O=|C|`。令

`U = C \\ union_i S_i`

为比较并集中实际未覆盖的客户。对每个 `x in U` 选一个 owner `iota(x)`，满足 `x in T_iota(x)`；可改成任意分数 owner `lambda_{i,x}>=0`，对所有出现 x 的 i 有 `sum_i lambda_{i,x}=1`。

在实际前缀 `(S_1,...,S_{i-1})` 强制玩家 i 选 `T_i`，以后按同一原策略继续，记完整离轨终局为 `z^(i)`。因为 `x in U`，实际前缀和实际原后缀都没有 x，所以在 `z^(i)` 中 x 的覆盖者为当前玩家加上未来响应者；记

`k_i(x)=#{j>i: x in S_j^(i)}`.

## 真实 SPE 给出的精确式

玩家 i 的离轨收益包含其 owner 客户的份额。因此真实偏离最优性给

`u_i(z) >= u_i(z^(i)) >= sum_{x in U_i} 1/(1+k_i(x))`,

其中 `U_i={x in U: iota(x)=i}`。求和并用 `W=sum_i u_i(z)` 得

`|U| <= W + R_iota`,

`R_iota = sum_{x in U} k_iota(x)(x)/(1+k_iota(x))`.

由于 `O = |C\\(actual union)| + |U| <= W + |U|`，得到全范围但带税的递归界

`O <= 2 W + R_iota`.  (RS-1)

更强的 fractional-owner 形式为

`O <= 2W + R(lambda)`,

`R(lambda)=sum_{x in U} sum_{i:x in T_i} lambda_{i,x} k_i(x)/(1+k_i(x))`. 逐客户最优 owner 选择给最小可证税

`R_min = sum_{x in U} min_{i:x in T_i} k_i(x)/(1+k_i(x))`.

这里没有使用静态背景、固定后继或任何特殊目录条件；`z^(i)` 始终允许所有后继在离轨历史下按原完整策略改变。

## 为什么这是递归接口而非证明

`k_i(x)/(1+k_i(x))` 恰等于离轨分支中未来响应者在 x 上的总福利份额：若有 k 个未来响应者，皆分 `1/(1+k)`。因此 `R` 是“把一个未覆盖最优客户从当前 owner 偏离支付转移给未来响应”的真实分支税。它不能由根路径的 `W` 直接扣除：未来响应者可能只在该离轨分支覆盖 x，且完整 SPE 只约束其在该分支偏离不增，并不把该分支收益与原路径收益逐项比较。

沿 `z^(i)` 从后向前把每个未来动作替换为原路径动作，SPE 不等式方向是“规定离轨动作收益 >= 强制原动作收益”；所以它给出的是离轨未来总收益至少静态混合的方向，无法把 `R` 上界为根福利。任何声称 `R<=W` 或直接删除该项的递归证明都必须提供额外的跨分支信用，不能用单节点最优性替代。

## 可检验的更强接续义务

若能证明任意实例、任意完整 SPE 与任意最优 tuple 存在 fractional owner `lambda` 使

`R(lambda) <= 0`（等价于所有被选 owner 分支没有未来新增覆盖，通常过强），则 RS-1 直接闭合 Q。更现实的全局支付版本是构造跨分支流 `X`，把每个响应税份额 `1/(1+k_i(x))` 映到原路径玩家容量 `u_j(z)`，满足

`sum_{i,x,j} X_{i,x,j} <= W` 以及每个税额的需求约束；目前没有一般构造。

若只得到 `R<=W`，仅推出 `O<=3W`，不能证明 half。故该接口的价值在于把“真实后继响应造成的不可支付部分”精确隔离为 `R`，并给出继续研究所需的跨树流/递归信用对象。

## 依赖与范围

只依赖模型中完整历史 SPE 的单次偏离不等式；不依赖 iid、安全值、静态 PNE、特殊人数、极大主题或无拥挤条件。它不能被解释为一般 half 证明，也不是目标反例。下一步应直接研究 `R(lambda)` 是否可由多层 owner 交换或全树流支付，或构造真正完整 SPE 使该税持续放大。
