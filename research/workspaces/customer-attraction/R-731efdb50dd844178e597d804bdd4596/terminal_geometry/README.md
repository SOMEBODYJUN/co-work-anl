# 末端真实菜单与重复前缀研究

任务为 Q-CAG-HALF 的实际路径末端几何。一般目标仍 OPEN。
本目录的 LP 输出均为必要条件松弛；坏点从未声称是完整 SPE。

- `joint_menu_lp.py/.json`：共同优化末两人 S、Z、V，加最末回复对全部比较主题和实际主题的真实比较，及全部实际节点的有序前缀偏离保底。m5 数值松弛上界约 2.15383，说明固定 G 以外联合选这些行仍不够。
- `repeated_prefix_branch_lp.py/.json`：路径 C^(m−2)AB，加入倒三 C→B 的真实后继 Q,R 及该分支自己的最优性。m5 仍约 2.02066。
- `repeated_prefix_two_branches_lp.py/.json`：再同时加入倒三 C→A 的另一真实分支。m5 数值上界约 1.9927595，可转精确半覆盖证书；m6 仍超过二，不能外推任意人数。
- `repeated_prefix_optimal_menu_lp.py/.json`：倒三 C 对 m 个比较主题 T_i 的真实三人菜单 T_i,Q_i,R_i。用八格三重会员计数保留同一分支交集，并加入该分支末两人税比较。独立模板仍未达二；尚未与前一模板完全联合。
