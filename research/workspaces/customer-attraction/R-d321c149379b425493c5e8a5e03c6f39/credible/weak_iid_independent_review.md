# 固定一百个扩展主题的弱 iid 福利桥：盲独立审查

## 1. 实例、完整策略及最优覆盖

m≥2，J=100（策略证明只需 J≥2）。客户为 core 集 A 的两名客户、与它不交的 B 的 2(m−1) 名客户，以及互不相同且不属 A∪B 的 e_1,...,e_J。共同主题为 A、B、Q_j=A∪{e_j}。都是不同单位客户、单位提供者，没有改变输入类。

完整策略如下。根选 A。每个非根、非末位的有序历史都选 B。末位仅按此前非 B 行动数 n 指定：

| 前缀类别 | 末位动作 |
|---|---|
| n=0 | 任意 Q_j |
| n=1，唯一非 B 动作为 A | B |
| n=1，唯一非 B 动作为 Q_j | 任一 Q_l，l≠j |
| n≥2 | B |

“任意”可固定成最小索引，“不同”可固定成循环下一个索引；同计数历史不必共享回复，但这里恰可共享。策略在全部有序历史都有明确值。

实际路径 A,B,...,B；每人收益 2，W=2m。选 B 加 min(J,m−1) 个不同 Q，必要时重复补足 m 个行动，达到 2m+min(J,m−1)。含 B 的任何 m 主题至多达到这个数；不含 B 时覆盖至多 2+min(J,m)，更小。因此

OPT_m=2m+min(100,m−1)。

## 2. 全部历史上的最优性

**末位。** n=0 时，Q 收益 3，A 为 2，B 为 2(m−1)/m<2。n=1 唯一 A 时，B 与每个 Q 都得 2，A 得 1。n=1 唯一 Q_j 时，不同 Q_l 与 B 都得 2，同 Q_j 得 3/2，A 得 1。n≥2 时，B 得 2(m−1)/(m−n)>2，任何非 B 行动收益至多 1+2/(n+1)≤5/3。因此所指定的末位动作在每个历史均为 BR。

**中间玩家。** 设当前历史已有 n 个非 B 行动，且当前不是末位。跟随指定 B 的最终收益为：

- n=0，或 n=1 且唯一非 B 是 A：恰 2。
- n=1 且唯一非 B 是 Q：2(m−1)/(m−2)>2；这种中间节点只在 m≥3 出现。
- n≥2：2(m−1)/(m−n)≥2。

若 n=0 而当前改选 A，则末位改 B，当前 core 收益仍为 2；若当前改 Q_j，则末位选不同 Q，当前 core 得 1、私有得 1，共 2。

若 n=1，当前改非 B 后末位选 B；其 core 至多得 1，Q 私有至多得 1，故偏离收益至多 2。若 n≥2，当前改非 B 后末位仍 B，偏离收益至多 1+2/(n+1)≤5/3。这穷尽所有合法偏离，各指定 B 均最优。

**根。** 根改 B 后，直到末位都是 B，末位选 Q，根 B 收益 2。根改 Q_j 后，中间都 B，末位不同 Q，根收益 1+1=2。根选 A 也得 2。因所有孩子子策略已逐历史核验，根最优；整棵完整策略为纯 SPE，而非仅实际路径。

## 3. 对称 iid Nash 的全部支持与唯一性

定义

f_m(p)=E[1/(1+Bin(m−1,p))]=[1−(1−p)^m]/(mp)， f_m(0)=1。

m≥2 时 f_m 严格递减。A 在任何对手分布下都严格被任意 Q_j 支配，因为它们有完全相同的 core 份额，Q_j 还有严格正的私有份额。因此对称 iid Nash 中 A 概率为零。

记 b=P(B)，q_j=P(Q_j)。所有 Q_j 的共同 core 收益为 2f_m(1−b)，其私有收益为 f_m(q_j)。如果某 Q_j 未使用而另一个被使用，前者私有收益 1 严格超过后者，故未用 Q_j 会严格盈利。因此一旦 Q 的总概率为正，全部 J 个 Q 都正概率；严格递减性还强制 q_j=(1−b)/J。

全 B 不是 Nash：Q 得 3 而 B 得 2(m−1)/m<2。全 Q 也不是 Nash：B 得 2(m−1)，而 Q≤2/m+1，且 m=2 时私有项严格小于 1。故 b∈(0,1)，由无差异方程唯一确定：

2(m−1)f_m(b)=2f_m(1−b)+f_m((1−b)/J)。                 (N)

左边严格递减、右边严格递增；b=0 时左大于右，b=1 时左小于右，所以恰一个根。这里的唯一性仅针对对称 iid Nash 分布；没有声称全部非对称/相关静态均衡唯一。

其期望覆盖为

Z_m=2(m−1)[1−(1−b)^m]+2(1−b^m)+J[1−(1−(1−b)/J)^m]。 (Z)

## 4. 全部 m≥41 的严格弱桥反例

取 J=100，bbar=1−3/(2m)。Taylor 截断给

e^(3/2)>Σ_(j=0)^5 (3/2)^j/j!=5711/1280>40/9，

故 e^(−3/2)<9/40。Bernoulli 求和给 f_m(p)≥1−(m−1)p/2。

在 bbar 处，方程 (N) 的左边严格小于

2(m−1)/(m−3/2)=2+2/(2m−3)≤2+2/79。

右边严格大于

(4/3)(1−9/40)+1−3/400=2+31/1200。

31/1200>2/79，所以 (N) 的根 b<bbar。另一方面，对于 m≥3，在 b=1/2 时左边减右边大于零：

2(m−2)f_m(1/2)−f_m(1/(2J))
≥4(m−2)(1−2^(−m))/m−1>0。

因此 b>1/2。令 r=1−b，则 3/(2m)<r<1/2。

把 (Z) 写作 2m 减去漏掉的 core/B 客户、再加私有客户：

- core 漏损 2b^m<2e^(−3/2)<9/20；
- B 漏损 2(m−1)r^m<2(m−1)/2^m≤80/2^41<1/100；
- 私有覆盖 J[1−(1−r/J)^m]>3/2−9/(8J)=1191/800，由二阶 Bonferroni 下界。

所以对全部 m≥41，

Z_m>2m+823/800>2m+82/81≥2m+2m/(2m−1)。

这等价于

(1−1/(2m)) Z_m > 2m = W。

每一步均为统一解析估计，未用有限数值外推。指数尾界与极小 B 漏损的严格性不会在 m→∞ 时消失。

## 5. m=20 的简短有理证书

令 D_m(b) 为 (N) 左减右。以下都是直接整数幂构成的有理数不等式：

D_20(92579/100000)>1/20000，
D_20(4629/5000)<−1/25000。

故唯一 b 位于这两个有理端点之间。分别用下端点估计 B 覆盖、上端点估计 core 和私有覆盖，得

Z_20≥38[1−(1−92579/100000)^20]
      +2[1−(4629/5000)^20]
      +100[1−(1−(1−4629/5000)/100)^20]

## 6. 真正静态安全值与主目标没有被否定

取 m−1 名静态竞争者的固定主题为一个 A 和 m−2 个 B。查询 A 得 1，查询 B 得 2，查询任意 Q_j 得 2。因此任意不被竞争者观察的查询混合分布收益都至多 2，真正安全值 v_m≤2。

所以该 SPE 的 W=2m≥m v_m；连强聚合安全支付都没有在本族失效。失效的仅是把这个真正 minmax 值换成对称 iid Nash 的 Z_m/m。主 half 也明显成立，因为 OPT/W≤(3m−1)/(2m)<3/2。
