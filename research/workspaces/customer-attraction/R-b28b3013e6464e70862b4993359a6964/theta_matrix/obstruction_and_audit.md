# Theta 同序矩阵候选：独立审计与逐客户下界的精确边界

状态：候选审计/障碍；不是 Q-CAG-HALF 证明，也不是反例。

## 对象

沿实际完整纯 SPE 有序路径 `z=(z_1,...,z_m)`，令 `h_i=z_{<i}`。对强制主题 `A` 定义
`L_i(A)=min{u_i(y): y` 是从 `(h_i,A)` 开始的任意完整纯 SPE 续局终局`。候选同序矩阵不等式为：对任意达到 `OPT_m=O` 的有序元组 `T=(T_1,...,T_m)`，

```
Σ_i L_i(T_i) >= O-W(z).
```

## 精确有限核验

独立用 `customer_attraction.ExactSPESolver` 的完整历史递推，以 `Fraction` 计算 `L_i`（不把同计数节点强制共用续局）。穷举所有七种非空客户类型的 `0/1` 子集：`p=3,m=3` 的 127 个非空输入、全部可达有序纯 SPE 路径、全部最优有序元组，均无严格违例；同法 `p=3,m=4` 也无违例。随机压缩客户实例（`p<=5,m<=5`）的多批精确筛查亦无违例。以上只记录有限阴性。

既有 36 客户 `aggregate_theta_failure` 的 SPE 反例只否定 `W>=m*theta_m` 的逐人/总 floor；在其实际路径上各 `L_i(T_i)` 仍有明显正余量，因此不否定同序矩阵候选。

## 一般逐节点引理（可复用，但不足以闭合）

若 `X subseteq A\C(h_i)`，其中 `C(h_i)` 是实际前缀覆盖客户集，剩余人数 `r=m-i+1`，则在当前玩家强制 `A` 后，任何后继续局中 `x in X` 至多被这 `r` 位玩家覆盖。因此该偏离给当前玩家至少 `|X|/r`，SPE 最优性给

```
u_i(z) >= |A\C(h_i)|/r,
L_i(A) >= |A\C(h_i)|/r.
```

但仅按此界，对缺失集合 `M=O\C(z)` 记 `a_i=|M∩T_i|`，只能得到
`Σ_i L_i(T_i) >= Σ_i a_i/(m-i+1)`；而实际福利的同样粗界只有
`W >= Σ_i max_j a_j/(m-i+1)`。例如 `m=10` 且 `a_i=1`（十个互斥缺失单位）时，两项总和均为 `H_10≈2.93`，合计约 `5.86<10=|M|`。因此必须利用真实后继 IC/跨树支付来证明候选，不能把逐客户 fresh 下界直接求和。

## 结构性卡点

`L_i` 取不同 SPE 续局分支的最小值；各 `i` 的最小分支通常来自不同离轨树，不能把其未来覆盖信用相加。已有 `dual_lp_route` 的 tie-face 例说明 `L_i(A)` 随客户权重穿越 SPE 平局面跳变，不能在固定 `Gamma_sigma` 锥中直接线性化。故当前结论仍为 OPEN：需要一条不重复使用离轨客户信用的共同支付，或完整一般反例。
