# 可信坏构造方向：2026-10-24 检查点

本轮只研究任意人数、任意共同目录、每个完整有序历史纯 SPE 的 Q-CAG-HALF。
没有发现真正 half 反例，没有新增已证的一般福利不等式，也没有用有限阴性提升候选。

已读根四入口、模型与一般证明工作稿；特别核对了现有常数三根修复、无拥挤 3/2
族、多惩罚者推广失败、复制遗漏池失败、共享加载保险失败及最后低收益截断。
下述是探索去向及停止点，不是一项新障碍定理。

## 探索的真正反例机制

试图把无拥挤 3/2 族的单个围堵行动换成多个围堵行动，并提高尾部补偿主题的收益，
以使末位在其他组的静态残余主题之外仍愿意围堵已偏离的玩家。这里最先核对的并非
一条辅助安全值桥，而是是否可能得到 `OPT_m > 2W` 的真实完整 SPE。

发现必须立刻改变原族的遗漏结构：若实际组行动 `C_i=X_i`，遗漏块 `Y_i` 仅被
`A_i=X_i union Y_i` 覆盖，围堵主题只增加 `X_i` 的竞争，则根改选 `A_i` 后始终独享
`Y_i`。因此实际该玩家收益为 `|X_i|` 时，其真实 IC 已强迫 `|Y_i| <= |X_i|`。
单纯增加围堵人数只能把这一模板的形式比率推近二，不能使它越过二。
这不是新结果：它属于现行“实际遗漏全局私有”一般定理所覆盖的机制。因此没有为
这套模板做更大有限搜索，也不把其局限登记成主线新成果。

真正尚可攻击的变化应当令遗漏 `Y_i` 自身也被离轨行动共享。此时这些用于共享遗漏的
主题同样是根可以选择的合法主题，必须一并给出真实的可信围堵。若围堵者的收益来自
额外支付池，根改选带该支付池的主题也必须被同一张完整策略控制。

## 尚未支付的义务

若继续构造，所需不是分别写出几张低根收益的终局，而是同时给出：

1. 每个合法根行动之后的一份完整后继 SPE，而不只验证目标路径；
2. 共享遗漏的每个围堵主题自身作为根行动时的可信后继；
3. 所有这些分支的最后低收益行动，仍能压过其他尚未触及的最优遗漏主题；
4. 在同一个输入上严格得到 `OPT_m > 2W`，并验证实际最优比较元组。

目前尝试的支付池互换并未满足第 2、3 项。把若干同根低收益分支独立列出、给付款者
增加新客户，或者只说明固定实际终局的比率大，都没有完成这项义务。
本轮没有输出一个未经全历史验证的“候选反例”。

常数三 root-only 编译器仍给出严格的攻击接口：若有在全部正深度均为 SPE 的计划，
其实际福利为 W、根最大 regret 为 Delta，且 `OPT_m - 2W > 3 Delta`，即可编译成真正
half 反例。当前未找到满足该严格门槛的输入。此接口及 FREE-ROOT 候选已有来源，
本轮不重复既有有限策略锥扫描，也不将它们称为新发现。
