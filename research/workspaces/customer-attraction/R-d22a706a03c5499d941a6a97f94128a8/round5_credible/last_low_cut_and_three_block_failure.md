# 最后低收益行动截断与三块真实菜单失败

2026-10-23。解析通用引理加精确有限结果；一般半覆盖仍 OPEN。

## 1. 为什么值得检验这套复制菜单

每块四主题 A,B,C,D，五类客户为 `{A}:2`、`{B,D}:4`、`{A,C}:6`、`{C,D}:3`、`{A,B,C,D}:1`。
各块客户不交。块数为 n，人数为 4n；共同目录有 4n 个主题。

定义局部目标（坐标次序 A,B,C,D）

\[
q_0=(2,1,1,0),\quad q_A=(2,0,1,1),\quad q_B=(1,1,1,1),\quad
q_C=(1,0,2,1),\quad q_D=(1,0,1,2).
\]

曾经希望根选 `T_j` 后，本块取 `q_T`，其余每块取 `q_0`，并使根实际收益 `u=13/4`。
两块时这四类根子树确实可实现，并已有完整 DAG。若一般 n 也可实现，均匀查询各块 D 会产生强混合菜单诊断；相关零和矩阵由 `round5_mixed` 独立处理。
这里专门检查承重的真实策略可实现性，不从不交客户推出直和定理。

## 2. 通用的最后低收益行动引理

任意有限共同目录游戏、任意目标终局计数 `z`，记其行动收益为 `U_a(z)`。
固定阈值 `u`，令

\[
L=\{a:z_a>0,\ U_a(z)\le u\}.
\]

令 `R(p)` 为固定前缀计数 `p` 后所有完整历史依赖纯 SPE 可实现终局；定义精确门槛

\[
F(p)=\max_b\min_{q\in R(p+e_b)}U_b(q).
\]

**引理。** 若对每个 `p≤z`、`Σ_{a∈L}(z_a-p_a)=1` 的非终局前缀都有 `F(p)>u`，则目标 `z` 不能沿任何纯 SPE 路径实现。若只研究一个指定有序根前缀，则仅需检查与该前缀相容的截面。

证明：假设有实现 z 的真实 SPE 路径，取路径上最后一个属于 L 的行动 a。其行动前计数 p 在所述截面，实际该玩家最终收益 `U_a(z)≤u`。对每个偏离 b，真实后继是 `R(p+e_b)` 中的一员，所以当前玩家最佳偏离收益至少 F(p)>u，矛盾。此论证不修改过去行动，不冻结后继，也不把插入收益当原玩家收益。

这是一条一般引理；它本身没有证明本例任意 n 的截面门槛下界。

## 3. 三块的所有截面被严格阻断

`block_menu_probe.cpp 3` 不导入规范代码而实现集合值 BI：

\[
R(p)=\bigcup_a\{q\in R(p+e_a):U_a(q)\ge F(p)\}.
\]

证明其覆盖任意有序历史纯策略的标准归纳是：每个动作后的有序子博弈可以独立选取最不利于当前行动者的 SPE；计数相同只说明子博弈同构，不要求两个有序历史共享后继选择器。因此缓存所有可选 outcomes 不丢失历史依赖策略。

所有收益乘 `lcm(1,...,12)=27720` 后为整数。全部分母至多12，无浮点、无数值容差。单块收益直接按五类原始客户计算，不导入规范模型或 SPE solver。

三块总计：2,704,156 个计数状态、1,352,078 个终局、3,207,136 个保留 outcomes。根门槛仍为13/4，根终局200个。

| 根行动 T_0 | 指定目标 q_T⊕q_0⊕q_0 在首步子博弈中可实现？ | 最后低收益截面大小 | 全截面最小 F(p) |
|---|---:|---:|---:|
| A_0 | 否 | 192 | 37/10 |
| B_0 | 否 | 384 | 37/10 |
| C_0 | 否 | 192 | 37/10 |
| D_0 | 否 | 192 | 37/10 |

所有上述截面节点的 F(p) 都严格大于13/4，不是只有最小门槛代表通过。B 的截面包含与已选根 B 不相容的额外节点；检查更大的截面仍全部严格阻断，故不影响排除。
精确输出保存各门槛的出现次数、最小门槛代表、代表中每个偏离动作的真实子博弈最差收益及一个达到最差值的终局。**当前全部截面的数值仅由本目录这一份 C++ 实现产生，尚未经第二个实现或独立逐截面重构。**两块回归用于排查实现错误，不替代三块的独立审核。

由第2节引理，三块指定菜单失败于最后低收益行动；不存在给定四根终局的完整策略嫁接。
这是对明确 n=3 架构的完整有限排除，不是任意 n 定理，更不表示一般 half 成立。

最小门槛的共同代表为

\[
p=(A,C,D)\mid(A,A,B)\mid(A,A,B),
\]

即 `(1,0,1,1)|(2,1,0,0)|(2,1,0,0)`，还剩3人。
选择第二块 C 或 D 均能保证37/10；选择第一块任何行动最多保证13/4。这个三人子博弈另由 `round5_mixed` 从48单位客户独立解析检查。**独立审查范围仅此局部代表，不是全部截面或全部三块 BI 的独立审核。**一个代表的解析检查不被用来替代全部截面检查。

## 4. 替代菜单的指定诊断也未通过

root 指定只检验一个明确候选：`p=uniform(D_0,D_1,D_2)`、`u=13/4`。
对每个代表根行动 a，在其真实首步子博弈的所有终局 q 中筛 `U_a(q)≤u`，再最大化独立额外插入值

\[
\frac13\sum_{j=0}^2\sum_{x\in D_j}\frac1{1+c_x(q)}.
\]

插入分母确实有 `+1`。计算使用 `lcm(1,...,13)=360360` 的整数收益；未用原玩家收益替代插入收益。

| 根行动 | 通过原根收益上限的终局数 | 最大平均 D 插入值 | 是否严格超过13/4 |
|---|---:|---:|---:|
| A_0 | 60 | 101/30 | 是 |
| B_0 | 39 | 283/90 | 否 |
| C_0 | 35 | 197/60 | 是 |
| D_0 | 35 | 551/180 | 否 |

四个最大化目标均为本块 q_T、另一块 `(1,1,2,0)`、最后一块 q_0（两后块可交换）。B、D 列不足，所以这套指定查询诊断不能产出新的真实混合菜单反例。未据此否定其他查询分布或一般机制；没有继续刷参数。

## 5. 新的一般候选与确切未证部分

单块从零开始的6个纯 SPE 根终局为

\[
\mathcal Q=\{(1,0,1,2),(1,0,2,1),(1,1,2,0),
(2,0,0,2),(2,0,1,1),(2,1,1,0)\}.
\]

对 n=1,2,3，精确根终局集合恰是 `Q^n` 中至多一个块取 q_0 的组合；其基数分别为6、35、200，即 `5^n+n5^(n-1)`。
验证方式是：枚举的每个根终局逐块属于 Q、没有两个 q_0，且总基数等于上述合法组合数，故有限集合两边相等。

**仅为猜想：** 相同刻画对任意 n 成立。它会给本例真正可扩展的模块障碍：不交客户并不允许多个低收益、不饱和 q_0 块同时嫁接。
尚缺任意 n 的真实子博弈容量不变量或一般截面下界证明。不能从 n≤3 的吻合外推该量词。

本次没有得到 half 反例，也没有得到一般半覆盖证明。所得进展是把“多块可能突破混合菜单”的条件代数与“多块真实策略不能直接嫁接”的承重义务严格分开，并为失败给出可复算的最后低收益截断机制。
