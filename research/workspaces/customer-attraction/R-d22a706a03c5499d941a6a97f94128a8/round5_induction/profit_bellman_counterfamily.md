## 一般候选与足够性

固定任意合法有序背景h，客户负载b，余r名玩家。定义

    F_r(b)=max_{q为r个目录主题} Σ_x c_q(x)/(b_x+c_q(x)),

每个分子为零的项取零。它是同背景下r位剩余玩家的最优总利润；F_0(b)=0。若完整纯SPE在当前根选A、真实根终局收益u、其余r−1人总利润V，则真实剩余总利润P=u+V，尾部仍是背景b+1_A下的完整SPE。

尝试的可变人数归纳式是

    F_r(b) <= 2u + F_{r−1}(b+1_A).                (Bellman-2)

若它对全部合法背景与r成立，结合归纳假设F_{r−1}(b+1_A)≤2V，即得F_r(b)≤2P。零背景F_m(0)=OPT_m，因此足以闭合一般half。但下文证明Bellman-2对每个r=n≥5已在**空背景、原族实际首行动**失败。

## 原始客户与完整策略

固定n≥4，x=n−2，目录A,B,L_1,…,L_n。各组是不同单位客户。

| 客户全部喜欢的主题 | 重数 |
|---|---:|
| {L_j}，j<n | x（每j） |
| {A,L_j}，j<n | 1（每j） |
| {B,L_j}，j<n | x（每j） |
| {L_n} | x |
| {B,L_n} | x |
| {A,B,L_n} | n−1 |

完整策略：空历史选A；非空历史长度至多n−2时，若此前全是B则选A，否则选B；末位在每个历史选精确最佳回复，平局顺序B,A,L_1,…,L_n。所引现行正文已按所有有序历史给出完整SPE证明，并非只检查下面的实际路径。

实际路径及数值为

    (A,B,…,B),
    u_A=n−1/n,
    u_B=n−1/n−1/(n−1),
    W=n²−2,
    OPT_n=2n²−2n−2.

全部叶覆盖所有客户且每叶有其余主题覆盖不到的x名私有客户，最优n主题支持因此唯一为全部叶。

## 新的精确F_{n−1}(1_A)最优化

固定一名A作为背景，余n−1槽。设剩余主题计数为a,b,ℓ_1,…,ℓ_n，和为n−1。令d=|{j:ℓ_j>0}|。剩余利润准确写为

    P(a,b,ℓ)= x d + x Σ_j 1_{b+ℓ_j>0}
              + Σ_{j<n}(a+ℓ_j)/(1+a+ℓ_j)
              + (n−1)(a+b+ℓ_n)/(1+a+b+ℓ_n).

首项为叶私有组，第二项为B/叶共享但不在A中的组，后两项是背景A已覆盖的客户。对f(c)=c/(1+c)，移除一位覆盖者的边际损失为1/[c(c+1)]，c≥1。

**情形b=0。** 若a>0或某叶重复，移除一名A或一个重复叶，再把该槽换为此前未用的普通叶。这样的普通叶存在：原来至多n−2个不同叶，至少两叶未用。移除A对全部A客户的总利润损失至多(2n−2)/2=n−1；移除重复叶的损失更小，且不丢失任何A外已覆盖客户。新普通叶增加2x名A外客户，A内贡献非负。因2x=2n−4>n−1（n≥4），该替换严格改善。

所以此情形的最优解没有A和重复叶，恰选n−1个不同叶。特殊叶的A内贡献(n−1)/2≥普通叶的1/2，故可选特殊叶及n−2个普通叶，得到

    P_0=2(n−1)x+(2n−3)/2.                         (1)

**情形b≥1。** 保留一名B。若还有A、额外B或重复叶，移除一名这样的多余玩家并换成未用普通叶；未用普通叶同样存在。该替换不减少A外旧覆盖，并增加至少x名新私有客户。A内可能损失分别有以下上界：

- 移除A：普通A组总损失≤(n−1)/2；特殊组当前至少被A、B两位剩余玩家覆盖，损失≤(n−1)/6；合计≤2(n−1)/3≤x（n≥4）。
- 移除额外B：特殊组当前至少被两名B覆盖，损失≤(n−1)/6≤x。
- 移除重复普通叶：其一名A客户损失≤1/6≤x。
- 移除重复特殊叶：保留B且特殊叶至少两位，损失≤(n−1)/12≤x。

添加新普通叶的A内贡献又非负，因此每次替换均不减利润。反复替换可达：a=0,b=1，余n−2槽为不同叶。

如果从全普通叶选择中，以特殊叶替换一个普通叶，A内利润变化为

    (n−1)(2/3−1/2)−1/2=(n−4)/6≥0.

所以可取B、特殊叶和n−3个普通叶。全部B/叶非A客户贡献nx，私有叶客户贡献(n−2)x；A内普通组贡献(n−3)/2，特殊组贡献2(n−1)/3。因此

    P_1=2(n−1)x+(7n−13)/6.                       (2)

由P_1−P_0=(n−4)/6≥0，所有计数情形均已覆盖，精确得到

    F_{n−1}(1_A)=2(n−1)(n−2)+(7n−13)/6.           (3)

这是任意n≥4的解析最优性证明，不依赖有限n外推。

## Bellman亏空与系数障碍

由于F_n(0)=OPT_n，式(3)给

    F_n(0)−F_{n−1}(1_A)=(17n−23)/6,

而真实首位收益为u_A=n−1/n。因此

    2u_A+F_{n−1}(1_A)−F_n(0)
      =(23−5n)/6−2/n.                            (4)

n=4恰为零；每个n≥5为负，n=5恰为−11/15。该族使任何通用局部常数α至少满足

    α >= n(17n−23)/[6(n²−1)] -> 17/6.

故每个固定实数α<17/6最终都被该族否定。精确量词可取ε=17/6−α>0，再选整数n≥5且n>4/ε：

    17/6 − n(17n−23)/[6(n²−1)]
      =(23n−17)/[6(n²−1)] < 4/n < ε.

其中首个严格不等式清正分母后为n²+17n−24>0，对n≥2成立。因此所选n的必要系数严格大于α。它比旧总覆盖补全的首步必要系数趋2更强，但针对的函数不同，不能互相替代。

实际尾部利润

    V=(n−1)u_B=n²−n−2+1/n

还有精确剩余half裕量

    2V−F_{n−1}(1_A)=(17n−35)/6+2/n.

该裕量大于根Bellman亏空；二者相减仍为全局正裕量2W−OPT=2(n−1)。因此本反例并未否定F_r(b)≤2P本身，更未否定Q-CAG-HALF；它说明如果归纳只携带一个系数二的尾部下界，会丢失必须跨节点搬运的尾部信用。
