# 五环五客户：区间收益下界不能支付额外一单位分数门槛

2026-10-22。个人数学资产 `B7-INTERVAL-EXTRA-ONE-FLOOR-NO-v1`。
发现者标准库Fraction逐状态复算；root另行独立重建集合递归，已核对本页主数值。
外审及新颖性未认证。

**结论。** `background/interval_ceiling_relaxation.md` 的区间下界不普遍满足
`L_I(b)>=t_(r+1)(b)`。反例为空前缀、五共同主题、五名单位客户、六名单位玩家：

```
L_I(0)=1/2 < 10/17=t_7(0) < 2/3=真正SPE根收益下界。
```

它只否定区间松弛的这个充分接口；没有否定真正EXTRA-ONE-LEADER、真正聚合安全值或一般半覆盖。
本例全部真正SPE均覆盖五人，且区间总预算仍有`G_I(0)=23/6>5/2=OPT_6/2`。

## 1. 单位客户与两个递归

主题标签为Z/5Z。五名不同客户C_i各喜欢主题i及i+1，共同目录恰有这五个主题。
因此主题a覆盖C_(a-1)、C_a，各有两名客户，目录主题两两不同。
兴趣mask为`3,6,12,24,17`，每种重数一。总人数m=6，允许重复主题。

对终局主题计数z，使用主题a的玩家收益为

```
U_a(z)=1/(z_(a-1)+z_a)+1/(z_a+z_(a+1))  若z_a>0；
U_a(z)=0                               若z_a=0。
```

给定计数前缀b，记孩子集合H_a=H_I(b+e_a)。区间递归精确定义为

```
H_I(b)={b}                                      在终局；
L_I(b)=max_a min_(z in H_a) U_a(z),
E_I(b)={a:max_(z in H_a) U_a(z)>=L_I(b)},
H_I(b)=union_(a in E_I(b)) H_a                    在非终局。
```

它保留一个eligible行动孩子中的**全部**终局。相反，真正全历史纯SPE全集递归，
令孩子集合为K_a，阈值`l=max_a min_(z in K_a)U_a(z)`，只保留
`union_a {z in K_a:U_a(z)>=l}`。这个逐终局筛选就是两者的承重区别。

## 2. 静态额外一单位门槛的解析确值

对主题分布q=(q_0,...,q_4)，静态背景允许六个分数主题质量。客户C_i的分数负载为
`6(q_i+q_(i+1))`。因此

```
t_7(0)=min_q max_a [1/(1+6(q_(a-1)+q_a))
                            +1/(1+6(q_a+q_(a+1)))].
```

取均匀q，每客户负载12/5，每个纯查询恰得`2/(17/5)=10/17`，给上界。
对任意q，五个纯查询的均值为

```
(2/5) sum_i 1/[1+6(q_i+q_(i+1))] >= 10/17。
```

因为五个`q_i+q_(i+1)`之和为2，且`x↦1/(1+6x)`凸，Jensen给上述下界。
最大查询不小于均值，故` t_7(0)=10/17`。这是连续背景域的精确证明，不靠浮点优化。

## 3. 精确区间值与假终局机制

根五个孩子的当前主题最小值均为1/2，最大值均为1；故根`L_I=1/2`且所有行动eligible。
以孩子b=e_0为例，显式集合有23个终局，其主题0收益分布如下。

| U_0 | 1/2 | 7/12 | 2/3 | 5/6 | 1 |
|---|---:|---:|---:|---:|---:|
| 终局个数 | 2 | 4 | 7 | 8 | 2 |

一个低见证为`z^-=(3,1,0,1,1)`，U_0=1/4+1/4=1/2；
一个高见证为`z^+=(1,1,1,2,1)`，U_0=1/2+1/2=1。
其余根行动由循环旋转给同样上下界。根总集合有60个终局。

低见证有一条区间允许路径`(0,0,0,1,4,3)`。最早的严格泄漏已经出现在前缀e_0：

| 前缀b | L_I(b) | 当前行动 | 证明该行动eligible的高终局 | 高终局收益 | 同时保留的低终局收益 |
|---|---:|---:|---|---:|---:|
| (1,0,0,0,0) | 2/3 | 0 | (2,0,1,2,1) | 5/6 | 1/2 |

因为高终局收益5/6>=2/3，行动0被保留；它孩子中的低终局z^-也随集合并被保留，
尽管该行动在z^-中的最终收益1/2严格低于节点阈值2/3。
这正是区间剪枝放松允许的现象，不是某一份SPE可以采用的理性续局。
该路径还在前缀2e_0以及(3,1,0,0,0)处有类似严格泄漏，详见冻结审计。

## 4. 真正SPE与总预算均不失败

独立按真正SPE集合递归，根阈值为2/3。对每个根主题，所有可实现的当前玩家收益恰为
`{2/3,5/6,1}`。真正SPE根终局共20个，每个均覆盖五名客户；所以

```
min_SPE W=OPT_6=5,
min_SPE u_first=2/3>10/17。
```

同一精确区间递归的根总支付为23/6，仍大于OPT_6/2。
因此本例既不反驳`G_I(0)>=OPT/2`，也不反驳真正当前收益的额外一单位静态门槛。
它明确排除一条证明捷径：不能先用本区间超集计算L_I，再逐点声称L_I已支付该静态门槛。
