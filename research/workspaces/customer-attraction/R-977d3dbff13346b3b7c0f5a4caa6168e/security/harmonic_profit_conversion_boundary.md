# 调和菜单的利润转换边界：两主题完整SPE迫使系数趋于一

2026-10-21。内部独立攻击 `B7-HARMONIC-PROFIT-CONVERSION-BOUNDARY-v1`。
模型为有限单位客户、共同有限非空目录、单位提供者、全部有序历史纯SPE，允许任意平局。
本页审查同一工作区 `../early_price/harmonic_tail_menu_debt.md` 的一个**可能的加强目标**；
原稿没有声称这个加强已经成立。本页不否定原稿恒等式，不否定一般半覆盖或真正安全值聚合。
不声称新颖性或外审。该两主题输入不是作为新的福利低效例提出，而是提取精确菜单预算边界。

## 1. 必须同时保留的点态松弛

沿用原稿的一个真实节点：过去客户负载p，剩r人，实际当前主题A，实际当前收益u，
实际后继总利润W_tail，后继调和势Psi。对比较向量z，令tau=sum z>=1、pi=z/tau，
d_x=sum_(T contains x) z_T。真实根分支T之后的后继负载为k_T。
定义原稿的真实激励松弛S_z、循环遗憾R_pi和实际菜单比较Z_pi，并令

```
C_eta = sum_x (q_x-t_eta(x))_+,
rho_x = E_(T~pi)[q_x min(1,d_x)-d_x/(p_x+1+k_T(x))
                                      -eta V_(p_x)(1_A(x),k_T(x))],
e_x = (q_x-t_eta(x))_+ - rho_x >=0.
```

原稿式(8)精确重排为

```
eta W_tail+C_eta-[coverage_q(z)-tau u]
 = S_z+tau R_pi+eta Z_pi+sum_x e_x-eta(Psi-W_tail).      (A)
```

所以若希望把原稿的eta Psi信用改成eta W_tail，不能只检查R、Z；必须保留e。
但即使保留**全部**e，右边也不普遍非负。下面给完整SPE的解析反例，且S、R、Z全为零。
因此它不是某个循环债符号错误造成的假象。

## 2. 任意r>=2的完整策略

目录只有两个不交主题：A含一名客户，B含r名不同客户，共r+1名单位客户。
有r名玩家。完整策略为：根选A；每个非根有序历史均选B。

对任意非根历史，设已经有a个A，当前及未来共有s名玩家。若当前按策略选B，
其最终B人数为r-a，收益

```
r/(r-a) >=1.
```

若改A，后继仍全B，其收益为1/(a+1)<=1。因此每个非根节点指定B最优，
包括离轨和末位节点。根选A收益1；根改B后所有人选B，收益r/r=1。
故指定策略在全部有序历史都是纯SPE。没有选择有利离轨平局或隐藏随机化。

实际终局、收益与最优覆盖为

```
A,B^(r-1),
u=1,  W_tail=r,  W=OPT_r=r+1,
Psi=r H_(r-1).
```

取D=B，即过去与当前A均未覆盖的保护客户；比较权q=1_D。
完整连续价格可直接分离两个主题的变量：

```
B_D(1) = max_(z_A,z_B>=0) [r min(1,z_B)-z_A-z_B] = r-1. (B)
```

最优点为z_A=0、z_B=1。因此任何普遍局部利润界

```
B_D(u) <= c_r W_tail
```

都必须有c_r>=1-1/r。特别地，r>=3时B_D(u)>W_tail/2；
而任意固定c<1都在足够长后继上失败。r=2给等号B_D(1)=1=W_tail/2，
与真实末两人价格界的系数一致。这里没有断言系数1-1/r在一般目录中足够。

## 3. 原稿全部债与点态松弛的精确数值

在(B)的最优点，tau=1、pi=delta_B。根A和根B之后的真实后继元组均为B^(r-1)，
所以整个根后继菜单是常数，且

```
S_z=R_pi=Z_pi=0.
```

对每个B客户，p=0、1_A=0、d=1、k_T=r-1。
在eta=1/2时，原稿的全整数阈值确为t_eta=1；故C_eta=0，

```
e_x = H_(r-1)/2 - (r-1)/r,
sum_x e_x = r H_(r-1)/2-r+1,
(Psi-W_tail)/2 = r H_(r-1)/2-r/2.
```

代入(A)，总净余额精确为

```
sum_x e_x-(Psi-W_tail)/2 = 1-r/2.                     (C)
```

r>=3时严格负，正好是W_tail/2-B_D(1)。r=3的最小例只有四名客户：
Psi=9/2、W_tail=3、sum e=1/4，势过量的一半为3/4，余额-1/2。

更一般地，对eta>=1/2，同一客户的阈值仍为1，因为
`[1/(k+2)+eta H_(k+1)]-[1/(k+1)+eta H_k]
 =[eta(k+2)-1]/[(k+1)(k+2)]>=0`。
因此C_eta=0、sum e=eta rH_(r-1)-r+1，(A)右边为

```
1-r(1-eta).
```

这再次给出eta>=1-1/r的必要条件。势过量不能被看作可免费花费的信用；
在这个常数菜单中，既没有协方差债，也没有激励松弛可额外调用。

## 4. 精确限制与接续

本例只否定将全层数的半倍调和势信用统一转换成半倍实际后继利润，
包括保留全部点态包络松弛后的加强。它不否定原稿的带债上界，
不否定仍开放的系数1候选B_D(u)<=W_tail，也不否定较广的强价格桥
`B_1(u)<=W-u`：本例B_1(1)=r-1<r=W-u。
它也不是旧PROTECTED客户总量预算的重复声明；这里计算的是连续价格B_D。

一般半覆盖、真正W>=m v_m及额外一单位安全接口均未在本页解决。
接续应使用允许系数随剩余人数增长的利润预算，或给出跨多个真实节点的共同支付；
不能要求每个早期节点继承末两人的1/2系数。

并精确复算(B)、(C)及原稿点态阈值。有限核验支持算术；任意r的证明是第2—3节。
