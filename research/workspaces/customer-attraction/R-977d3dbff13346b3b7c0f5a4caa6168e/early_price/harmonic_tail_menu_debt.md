# 任意层数真实菜单：调和后继势的精确价格债务表示

临时身份 `B7-HARMONIC-TAIL-MENU-DEBT-v1`。状态：作者自足解析推导，待独立数学重构。
一般 Q-CAG-HALF 仍 OPEN。本页给任意层数的**恒等式与带显式债项上界**，没有证明这些债项在多后继时非负，也没有证明一般半覆盖。

## 1. 对象、量词与实际收益

采用 CAG-MODEL。固定任意有限共同非空目录、有限单位客户、任意完整历史纯 SPE，
固定该策略任意一个真实有序前缀。前缀留下客户负载 `p_x>=0`，还有 `r>=1` 位玩家。
当前玩家实际选 `A`；写 `a_x=1_A(x)`，实际后继元组的客户负载为 `k_A(x)`。
每个目录主题 `T` 的真实后继元组由同一给定完整策略在 `(prefix,T)` 后产生，
记其客户负载为 `k_T(x) in {0,...,r-1}`。不同历史的平局回复不识别、不重选。

实际当前收益、后继收益总和与前缀玩家最终收益总和分别为

```
u = sum_x a_x/(p_x+1+k_A(x)),
W_tail = sum_x k_A(x)/(p_x+a_x+k_A(x)),
P = sum_x p_x/(p_x+a_x+k_A(x)).
```

第二、三行零分子分母同时为零时取零。整个实际终局福利为 `W=P+u+W_tail`。
定义 `H_0=0, H_n=sum_{j=1}^n 1/j` 和实际后继的调和势增量

```
Psi = sum_x [H_(p_x+a_x+k_A(x)) - H_(p_x+a_x)].
```

`Psi` 一般不是 `W_tail`。逐客户有 `W_tail<=Psi<=H_(r-1) W_tail`（`r=1` 时二者均零）。
后一粗界用每个分式 `(p+a+k)/(p+a+j)<=k/j` 证明；本页主恒等式不使用此界。

对实权 `q_x in [0,1]` 和价格 `v>=0`，定义

```
B_q(v)=max_(z_T>=0) [sum_x q_x min(1,sum_(T contains x) z_T) - v sum_T z_T].
```

实权仅用于比较，不改变博弈收益。每个 `z_T>1` 可截断为1而不降低目标，
故价格最大值可限于紧立方体 `[0,1]^S`。

## 2. 任意后继数量的精确交叉对称

对单客户的整数 `p,k>=0`、`a in {0,1}`，置

```
F_p(k) = H_(p+k)-H_p,
kappa_p(k) = 1/(p+1)-1/(p+k+1),
V_p(a,k) = H_(p+a+k)-H_(p+a).
```

直接望远镜给

```
V_p(a,k)=F_p(k)-a kappa_p(k).                         (1)
```

`a=0` 直接成立；`a=1` 时两段调和和的差是 `1/(p+1)-1/(p+k+1)`。
当前查询主题 `T` 面对任意后继负载 `k` 的收益是

```
U_p(T,k)=sum_x 1_T(x)/(p_x+1+k(x))
        =sum_x [1_T(x)/(p_x+1)-1_T(x) kappa_(p_x)(k(x))].  (2)
```

所以当前查询收益与**整组后继的调和势**具有完全相同的交叉项。
定义 `V_p(T,k)=sum_x V_(p_x)(1_T(x),k(x))`。
对目录任意概率分布 `pi`，`T,Q` 独立服从 `pi`，令

```
R_pi = E_T V_p(T,k_T) - E_(T,Q) V_p(T,k_Q),
Z_pi = Psi - E_T V_p(A,k_T).                              (3)
```

`R_pi` 是真实菜单整组调和势的循环遗憾；`Z_pi` 是实际后继元组对同一菜单的势比较。
二者都是原始真实菜单的明确定义数值；它们在 `r>=3` 时**不是自动合法的单玩家最优性 slack**。
由 (1)—(2) 的相同交叉项，得到精确恒等式

```
E_T U_p(T,k_T) - E_(T,Q) U_p(T,k_Q) = R_pi.               (4)
```

此式对任意后继映射成立，无须后继最优性；因此不能仅由其名称断言 `R_pi>=0`。

## 3. 点态参数价格与两笔债务

取任意 `z>=0`，`tau=sum_T z_T>=1`，`pi_T=z_T/tau`。
当前玩家的真实 SPE 比较给

```
S_z = tau u - sum_T z_T U_p(T,k_T) >=0.                  (5)
```

对 `eta>=0` 定义逐客户阈值

```
t_eta(x)=min_(0<=k<=r-1) [1/(p_x+1+k)+eta V_(p_x)(a_x,k)]. (6)
```

则对同一 `z` 有一般层数、任意整数背景的精确来源上界

```
sum_x q_x min(1,sum_(T contains x)z_T) - tau u
 <= eta Psi + sum_x(q_x-t_eta(x))_+ - tau R_pi - eta Z_pi. (7)
```

两笔原始债是 `-tau R_pi` 与 `-eta Z_pi`。没有将正部逐项加入，故它们可以互相补偿。

证明：固定客户，写 `d=sum_T z_T 1_T(x)`、
`e=E_T kappa_p(k_T)`、`f=E_T F_p(k_T)`、`h=sum_T z_T 1_T(x)kappa_p(k_T)`。
以 `alpha=a/(p+1+k_A)`、`psi=V_p(a,k_A)` 记实际贡献，有

```
(S_z)_x=tau alpha-d/(p+1)+h,
(tau R_pi)_x=-h+d e,
(Z_pi)_x=psi-f+a e.
```

所以令 `G=S_z+tau R_pi+eta Z_pi`，则有**精确恒等式**

```
coverage_q(z)-tau u = eta Psi + sum_x rho_x - G,
rho_x = E_T [q_x min(1,d)-d/(p_x+1+k_T(x))
                               -eta V_(p_x)(a_x,k_T(x))]. (8)
```

对固定 `k`，括号中的函数在 `d in [0,1]` 和 `[1,tau]` 分别线性。
端点 `d=0` 的值非正；`d=tau` 比 `d=1` 小 `(tau-1)/(p+1+k)`。
因此其值至多 `max{0,q-1/(p+1+k)-eta V_p(a,k)}`，再对 `k` 取最大即
`rho_x<=(q_x-t_eta(x))_+`。在 (8) 仅丢去合法非负量 `S_z`，得到 (7)。

价格本身由 (7) 得

```
D_eta=max{0, max_(0<=z_T<=1, 1<=tau<=|S|)
                      [-tau R_(z/tau)-eta Z_(z/tau)]},
B_q(u) <= eta Psi + sum_x(q_x-t_eta(x))_+ + D_eta.         (9)
```

`D_eta` 的最大值存在，因为相应集合紧且 `tau>=1`。价格正最优点可取 `tau>=1`：
若 `0<tau<1`，所有客户覆盖均在线性段，把 `z` 除以 `tau` 后目标除以 `tau`，
保持每个坐标至多1；若原目标正则严格变大。零目标由 (9) 右端非负处理。
这说明没有遗漏 `tau<1` 或空主题边界。

## 4. 所有 eta 的明确整数极小点

`eta=0` 时 (6) 的极小点可取 `k=r-1`。`eta>0` 时，一个明确极小点是

```
k_star=min{r-1, max{0, ceil(1/eta-p-2+a)}}.              (10a)
```

这里每个客户代入自己的 `p,a`。证明：对所有 `k>=0`，

```
f_eta(k+1)-f_eta(k)
 = [eta(p+k+2)-1]/[(p+k+1)(p+k+2)]  if a=0,
 = [eta(p+k+1)-1]/[(p+k+1)(p+k+2)]  if a=1.             (10b)
```

分子随 `k` 严格递增，所以先下降再上升；(10a) 正是第一个非负增量的位置，
再截断到允许区间。若该增量恰为零且还有下一点，则 `k_star+1` 同时极小。
因此 `t_eta` 是已知有限个仿射函数的下包络，breakpoint 恰在可能进入区间的
`eta=1/(p+j+2-a)`，`0<=j<=r-2`。无需优化整个真实菜单来求阈值。

## 5. eta=1/2 时全层数阈值只需 k=0 或1

只要 `r>=2`，(6) 在 `eta=1/2` 的精确值为

```
t_(1/2)(x) = 1/(p_x+1),   p_x>=1;
             3/4,         p_x=0, x in A;
             1,           p_x=0, x notin A.              (10)
```

证明不是只检查有限 `k`。令 `f(k)=1/(p+1+k)+(1/2)V_p(a,k)`，则任意 `k>=0` 有

```
f(k+1)-f(k)
 = (p+k)   /[2(p+k+1)(p+k+2)]  if a=0,
 = (p+k-1) /[2(p+k+1)(p+k+2)]  if a=1.                 (11)
```

`p>=1` 时全部非负，最小值在 `k=0`；`p=0,a=0` 时仍全部非负，最小值为1。
`p=0,a=1` 时仅 `k=0` 到1严格下降、1到2持平、之后上升；最小值在 `k=1`，值3/4。
若 `r>=3`，该最后情形的 `k=2` 也取同一最小值，但不需要它来决定阈值。
因此更长后继仅改变势信用 `Psi` 和两笔债，不降低末两人时的参数阈值。

例如 `q=1` 时，(9) 变为

```
B_1(u) <= Psi/2 + sum_(p_x>=1) p_x/(p_x+1)
                         + |A intersect {p=0}|/4 + D_(1/2). (12)
```

对任意 `D subset {p=0} minus A`，有

```
B_(1_D)(u) <= Psi/2 + D_(1/2).                            (13)
```

这里的 `D` 是比较客户集，`D_eta` 是显式债额，二者不可混同。

## 6. 恰一名后继为何闭合；多名后继缺什么

`r=2` 时每个真实后继是一个合法主题 `R_T`。有 `Psi=u_last`，

```
R_pi=E_(T,Q) [U_p(R_T,T)-U_p(R_Q,T)] >=0,
Z_pi=u_last-E_T U_p(R_T,A) >=0.
```

每个括号都是同一完整策略下真实末位节点的合法单主题最优性；故 `D_eta=0`。
这恢复 Boss4 的全参数真实末两人价格包络，而不是另加假设后的不同模型。
`r=1` 时后继为空，`Psi=R=Z=0`，阈值为 `1/(p+1)`，直接退化为末位最佳回复。

`r>=3` 时，换成 `k_Q` 是同时替换整组后继，不能作为某一个玩家的合法行动。
即使 `k_Q` 在另一真实分支可实现，也不能断言 `R_pi` 或 `Z_pi` 非负。
已有完整四人去相关证书给根查询分布 `pi_4=pi_9=1/2` 的 (4) 左侧为 `-11/4`，
故此处恰有 `R_pi=-11/4`。来源是
`research/current/customer_attraction/continuation_security_barriers.md` §3，
所引完整策略在全部有序历史验证 SPE；它不是 half 反例。

新精确读数进一步显示，不能仅把两笔债与当前 slack 合起来就断言非负。
此证书根实际主题 `A=8`、实际后继 `(4,5,0)`；查询4与9的真实后继为
`(2,3,11)` 与 `(6,7,3)`。定义直接重算给

```
R_pi=-11/4,  Z_pi=3,  Psi=70761167/3.
```

取 `z_4=z_9=1`（故 `tau=2`）、`eta=1/2`，有

```
tau R_pi+eta Z_pi=-4,   S_z=3,   G=S_z+tau R_pi+eta Z_pi=-1.
```

这只否定将 (8) 的 `G` 无条件当成非负证书；原价格上界保留显式债便完全成立。
