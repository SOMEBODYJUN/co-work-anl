## 本轮改变了什么认识

1. **真实早期激励不能被收益排序或末位最佳回复替代。** 环形菜单可使所有后继严格高于根，并高于所需额外槽安全值；即使末位真正最佳也仍可失败。但同一两参数圆环的全部完整SPE均通过extra-one，恰由第二人的真实可选偏离排除全部危险参数。
2. **孩子的单个gap总结不自闭合。** 一个无界人数伪菜单满足所有孩子gap、全部根比较乃至任意预先固定深度的真实末尾，仍违反父gap。它不是SPE，不反驳gap或half。
3. **低尾缺口不是绝对稀释信用。** 一个已有真实完整SPE固定不变，只让任意阈值逼近低尾收益，亏空趋零而硬删除返还保持正数。安全值内生阈值及分数删除未被排除。
4. **全共享遗漏也能趋近二。** 显式完整常值SPE族中全部遗漏恰属两个不同极大主题，无实际独有浪费。经典常值判据及其福利机制明确复用旧根饱和资产；这里不声称新的半覆盖子类。
