# 第二轮：完整可信策略的势增量候选

2026-10-23。一般 Q-CAG-HALF、EI 与WP仍OPEN。只写本目录，未改共享文件、旧冻结、git或身份。

## 当前精确候选

任意合法客户背景 `b`、任意余人数 `r≥1`、任意完整有序历史纯SPE，首位收益 `u` 是否满足

\[
u\ge\Delta_{r+1}(b):=P_{r+1}(b)-P_r(b),\qquad
P_k(b)=\max_{q\in\mathcal S^k}\sum_x\sum_{j=1}^{c_q(x)}\frac1{b_x+j}?
\tag{PI}
\]

这是比EI更强、未证明的新一般候选；以下静态代数说明它足以给EI，后者给half。未将有限诊断计为支持证据，不再扩同类样本或固定锥。

## 已证明的代数与真正缺口

1. 任取一个全局最优r槽势profile `q_r`，有

   `Δ_(r+1) ≥ max_T entrant(T;q_r) ≥ θ_(r+1) ≥ v_(r+1)`。

   因在 `q_r` 上再加一个主题是合法的r+1槽势候选。
2. 对任意全局最优r+1槽势profile `q_(r+1)`，删任一占用者都给一个r槽候选，因此 `Δ_(r+1)≤min_j u_j(q_(r+1))`。
3. 定义 `L_b(A)=Σ_(x∈A)1/(b_x+1)` 和非负机会损失

   `E_k(b,A)=P_k(b)−L_b(A)−P_(k−1)(b+1_A)`。

   则对全部k≥1和合法动作A有精确恒等式

   `Δ_(k+1)(b)−Δ_k(b+1_A)=E_(k+1)(b,A)−E_k(b,A)`。

   若A是P_(k+1)的最优首动作，则E_(k+1)=0，孩子势边际至少为父边际。实际SPE动作未必是该势最优动作；一般边际嵌入为假，不能把后继当成势的共同最大者。

最危险的未证义务正是如何使用完整孩子自身的偏离，将那些非势最优动作造成的边际下降与原根返还共同支付。若只传递一个势边际或尾部平均，已知伪菜单仍有信息损失。水位共同客户池可以支付删除返还，但不会自动保存原IC，须保留补偿项。

### 不需要Δ沿路径单调的直接half归约

有一个对全部人数成立、无需SPE的静态下界。若b由k个合法过去主题产生，剩r槽，令 `m=k+r`，则

\[
\boxed{\Delta_{r+1}(b)\ge\frac{\operatorname{OPT}_m}{2m}.}
\tag{S}
\]

证明：选P_r的最优profile q_r，令其与b合并的负载为L。令 `g(T)=Σ_(x∈T)1/(1+L_x)`、`M=max_T g(T)`，上面的插入式给Δ≥M。
对一个m主题最优覆盖的负载d，逐客户有 `1_(d_x>0)≤(d_x+L_x)/(1+L_x)`，于是

`OPT_m≤Σ_(j=1)^m g(T_j)+Σ_x L_x/(1+L_x)≤mM+(k+r)M=2mM≤2mΔ`。

后一个和恰为k个过去主题与r个q_r主题的g值之和；没有把背景当客户权重，没有期望背景或Jensen步骤。全零客户时乘法式成立。
所以只要证明各合法背景的局部PI，即使Δ在实际路径上下降，仍可对同一个原m实例逐人使用(S)，得到 `u_i≥OPT_m/(2m)`，直接推出half。Δ的非单调性只阻断朴素最小r中继，不阻断这个充分性归约。

## 平衡势缺陷：不能只计尾部绝对效率

对属于某个P_r全局最优profile的根主题A，令z_A为该根分支真实r−1人tail，定义

\[
\ell_A=P_{r-1}(b+1_A)-\Phi_{b+1_A}(z_A),\qquad
k_A=P_{r-1}(b)-\Phi_b(z_A).
\]

二者均非负，第二项仅把相同tail当作删除根后的合法profile，不声称其为较小SPE。
因A出现在某个P_r最优profile，`L_b(A)+P_(r−1)(b+A)=P_r(b)`，故精确有

\[
d_A=\Delta_r(b)-\ell_A+k_A.
\tag{BD}
\]

因此一条足够证明PI、但尚未证明的承重义务是：某个P_r最优支持动作A满足
`ℓ_A−k_A≤Δ_r−Δ_(r+1)`。这里不另立更强候选；它只是PI路线应保留的抵销对象。
只控绝对缺陷ℓ_A会丢掉整块与根无关的尾部损失：旧13人36客户真SPE的P根分支满足
`ℓ_P=k_P=1/2`，而 `Δ13=Δ14=5/2`。因此“绝对尾势损失≤边际减速”在这个已核真的例子就失败；正确的平衡式恰抵销为零。
这个精确分解也说明不能把未来玩家共同最大化势作为隐含前提。

### 对一般人数恒主题策略的解析一致性检查

在任意合法背景b的子博弈中，若给定完整策略在所有剩余历史均选同一主题A，那么PI成立，且实际 `A^r` 还是P_r的一个全局最优profile。这是PI候选的结构一致性检查，不是一般全深度exchange证明。

实际首位 `u=Σ_A1/(b+r)`。根偏离T的真实后继仍为 `A^(r−1)`，所以根IC给

`g(T):=Σ_(T∩A)1/(b+r)+Σ_(T\A)1/(b+1)≤u`。

对内客户取H在负载r处的后向支撑斜率 `1/(b+r)`，外客户取零负载处斜率 `1/(b+1)`。对任意n槽profile z，离散调和凹性逐客户给

`Φ_b(z)≤Φ_b(A^r)+Σ_(j=1)^n g(T_j)−r u≤Φ_b(A^r)+(n−r)u`。

取n=r即P_r=Φ_b(A^r)，取n=r+1即Δ_(r+1)≤u。
一般真实leaf q若仿用“删除根”的斜率 `w_x=1/(b_x+c_x+1−1_A(x))`，完整SPE没有给静态全查询cap；而且即便给cap≤u，尚须共同支持 `Σ_x w_x c_x≥r u` 才能以上述方式关掉势增量。恒主题类恰好取等，一般共享历史不能默认这个等式。
