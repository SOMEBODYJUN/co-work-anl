# 静态最优覆盖选择、真实分支损失与单角色覆盖信用

2026-10-24，independent7。范围始终为原 CAG-MODEL：任意有限单位客户、任意有限非空共同目录、任意人数、每个完整有序历史纯 SPE，允许全部平局、空主题、重复及零覆盖。本稿没有完成一般 half；没有外审或新颖性声明。

## 1. 独立尝试的静态候选及精确失败

固定实际终局 z，玩家数 m、覆盖 W。对合法主题 T 定义

    D_T(z) = sum_i u_i(T,z_{-i}).

最初尝试：存在一个达到 OPT_m 的 m 元组 `(T_1,...,T_m)`，使

    (1/m) sum_j D_{T_j}(z) <= W.                 (UNIFORM-OPT?)

这个候选若成立，即可用标准逐客户静态覆盖预算闭合 half，甚至锐 `2-1/m`。它与“存在最优元组及一个角色匹配，使 sum_i u_i(T_pi(i),z_-i)<=W”不同：这里是对全部匹配的均匀平均，不可据其失败否定最优匹配。

**UNIFORM-OPT 已反驳。** 直接复用 `examples/customer_attraction/eight_cce_welfare_gap.json` 及同名完整策略，不构造新特例正面结果。三人实际路径 `(0,1,1)`，三收益均 2，W=6。最优覆盖 8 仅可由元组 `(1,2,3)` 获得（忽略排列）。其三个静态累计查询值为

    D_1=16/3, D_2=D_3=7。

因此

    sum_j D_{T_j}=58/3 > 18=mW,
    (1/m) sum_j D_{T_j}=58/9 > 6。

但最优匹配可将主题1给原角色0、主题2/3给两位原角色1，得到 `4/3+2+2=16/3<6`，所以不能用这个反例攻击匹配路线。

这条失败桥是在此前600个固定 seed、三人五主题有界整数样本未找到反例后，转而读取现有精确证书即被否定的。前者不作为正面证据、没有一般证明含义，不继续扩样。

## 2. 每个角色的精确静态覆盖 gap 恒等式

本节不需 SPE。固定任意 m 个比较主题 T_j，联合 C*、覆盖 O；记

    d_x = #{j:x in T_j},  o_x=1_{d_x>0},
    c_x = actual final load,  w_x=1_{c_x>0}。

固定实际角色 i 的实际主题 A，令 `a_x=1_{x in A}`、`b_x=c_x-a_x`。`b` 是删去实际角色后的静态负载，非顺序历史。当前实际收益为

    u_i = sum_x a_x/(1+b_x)。

定义静态查询总价及逐客户余项

    S_i = sum_j u_i(T_j,z_-i) = sum_x d_x/(1+b_x),
    E_i(x) = (d_x-a_x)/(1+b_x) - o_x + w_x。

则对全部客户精确地有

    O-W = S_i-u_i-E_i,       E_i=sum_x E_i(x)>=0。       (ID)

非负性不需任何均衡：

- 若 `c=0,d>0`，则 `a=b=0`，`E=d-1>=0`。
- 若 `c>0,d>0`，则 `E=(d-a)/(1+b)>=0`。
- 若 `c>0,d=0`，则 `E=1-a/(1+b)>=0`。
- 全零客户贡献零。

一个直接条件推论：若角色 i 对全部主题是**静态**最佳回复，则 `S_i<=m u_i`，从而

    O-W <= (m-1)u_i。

因此最后角色始终有这个单角色 gap 上界。不能把早期 SPE 最优性替换成静态最佳回复。若能对某个最小实际收益角色证明同一个上界，就会有锐福利界；这仍是未付的动态义务。

## 3. 接入真实分支：一份明确但未支付的取消合同

现在恢复固定完整 SPE。对角色 i 的真实实际历史 h_i、每个 T_j，沿原同一策略的真实后继取得叶 z_i(T_j)。定义

    Q_i = sum_j u_i(z_i(T_j)),
    L_i = S_i-Q_i。

每个真实 IC 给 `u_i>=u_i(z_i(T_j))`，所以 `Q_i<=m u_i`。ID 精确成为

    O-W = Q_i-u_i + (L_i-E_i)
         <= (m-1)u_i + (L_i-E_i)。                   (DYN)

若另证 `L_i<=E_i`，就得到这一角色的 sharp-gap。该合同充分而未证；其与 root gap 并不等价，因为 DYN 还丢掉非负的真实 IC slack `m u_i-Q_i`。不能把它当已成立的消元规则。

已存 root_tax_failure 不直接否定此合同：实际 AAAF，u=(9,9,9,11)，O-W=23；唯一最优元组 ABCD。前三位的真实查询总价 Q_i=36，故 `Q_i-u_i-(O-W)=4`；末位 Q=77/2，余量9/2。这是同一完整策略上的精确计算，非一般证明。

general_tax_failure 是七人恒 A、到达前缀 AAA 后余四人的**背景总税**反例。它未否定空背景的 DYN 或本合同：根 W=7、OPT_7=9，所有实际角色 u=1，每个最优七元组真实查询总价均7，因而 `Q_i-u_i-(O-W)=4`。其子博弈要用剩余利润最优 F_4(b)，不能将背景税失败偷换成本合同失败。

## 4. 真正可用的逐客户支付：其他实际角色的覆盖不产生未付损失

记 P 为角色 i 的真实过去负载，F^j 为强制 T_j 后**真实**未来负载，定义

    q_i(x) = sum_{j:x in T_j} 1/(P_x+1+F^j_x)。

`sum_x q_i(x)=Q_i`；这是合法分支收益逐客户和。静态损失逐客户为

    ell_i(x)=d_x/(1+b_x)-q_i(x)。

**全范围点态关系。** 对任何 `x in C_actual\A`，有

    ell_i(x) <= E_i(x)。                            (OTHER)

证明不需均衡或固定未来：若 d>0，则 a=0,c=b>0，所以 `E=d/(1+c)`、`ell=E-q<=E`；若 d=0，则 ell=0、E=1。

因此所有实际覆盖、但不在当前实际主题上的客户，其静态→动态损失均已由同客户信用支付一次。它不要求不同分支共享一个查询背景，不调换真实未来。

更精细地，全体客户的**精确**净信用分解为

    E_i-L_i
      = sum_{x in C*\C_actual} (q_i(x)-1)
      + sum_{x in A cap C*} (q_i(x)-1/c_x)
      + sum_{x in (C_actual\A) cap C*} q_i(x)
      + sum_{x in C_actual\C*} (1-a_x/c_x)。          (NET)

只在 `c_x>0` 的组使用 `a_x/c_x`。最后两项非负，第一项是比较遗漏客户的全额覆盖债务，第二项是当前实际主题客户原来份额的保留债务。OTHER 是一条真正的一般点态不等式；NET 本身只是精确分解，不提供第一、二项的非负性。它不能消除与原问题同样困难的跨真实子树支付。

这把一个可能的单角色继续问题缩为：用真实后继 IC，使遗漏覆盖债务与当前主题份额债务，被另外两项及真实根 IC slack 共同支付。本文没有证明这一点。已有“一个孩子 GAP 标量+根 IC”伪菜单障碍仍说明，必须打开后继内部可信性，不能重新用一个孩子 gap 数值替代整组真实比较。

`audit_static_cover_and_credit.py` 从现有八客户/root-tax输入及完整有序策略出发，单位客户展开，逐历史全部合法行动比较，精确核验 UNIFORM-OPT 的反例、ID/DYN/NET 及 OTHER。另对 general_tax_failure 的恒 A 策略做全树定义级检查。

## 6. 最深低阈值节点：真实威胁必须携带查询外客户

这是一条全输入的真实后继结构关系，不是一个新的福利下界。固定 t>0，取一个完整 SPE 的合法历史 h，假设该节点当前收益 u<t，而 h 的全部 proper 有序后继历史中规定行动者的最终收益均至少 t。当前节点任意强制主题 A 后的真实根收益记 d_A；SPE 给 `d_A<=u<t`。

在该真实分支的任一未来玩家主题 B 下，同一完整叶的客户总负载为 k。未来玩家的真实收益至少 t，因此

    sum_(x in B\A) 1/k_x
      >= t-d_A + sum_(x in A\B) 1/k_x
      >= t-u + sum_(x in A\B) 1/k_x。              (EXCLUSIVE)

这只是同叶两个主题利润共同交集精确消去，再用每个真实后继节点的阈值，不把离轨玩家利润替换成原路径利润。特别地，B 不可能包含于 A；每位真正威胁当前查询的后继都必须带来严格正的查询外利润。它保留的是**逐后继**关系，比只记一个孩子平均利润过线保留更多成员信息。

本关系可用于最深违反逐人 FLOOR 的节点；存在性与正深度阈值来自该选取，不能假设一般节点全部后继自动过线。EXCLUSIVE 的逐后继优势仍可能反复使用相同查询外客户，本文未证明这些优势在多个强制主题之间有共同容量。因而它尚未支付 NET 第一、二项，也不绕过已有 GAP 孩子摘要障碍。
