# 一般半覆盖工作稿：真实捕获流与最优主题交换核

2026-10-23，Boss10/root。**Q-CAG-HALF仍OPEN。** 本轮只研究任意人数、任意有限共同目录、全部有序历史纯SPE的一般问题。本文区分已证终局关系、真实激励来源与尚未支付的全树项；不把一般等价改写当成证明进展，不独立扩张特殊正面范围。

## 1. 固定模型与真正终点

固定原单位客户/单位玩家完整SPE σ，人数m，实际终局Z、覆盖C及W=|C|。取一个最优m槽主题元组T=(T_1,...,T_m)，O为其并集。令I=C∩O，G=C\O，R=O\C；集合与其大小依上下文区分。目标为

    |R| <= |I|+2|G|，即 |O|<=2W。

m=1、零客户、全部主题空的边界已有直接证明；以下所有有限求和与概率公式也覆盖空集合、重复主题和零负载。最优元组不必唯一，下面对每个最优元组成立。

在实际位置i强制选T_j、后继沿同一完整σ，所得真实终局记Y_ij，当前玩家真实收益为d_ij。完整SPE给所有d_ij<=u_i，且全部离轨后继仍需保留。不能把Y_ij的后继替成实际后继，也不能删除固定祖先后声称同一子SPE存在。

## 2. 一个准确但尚未闭合的自由匹配终点

对每个i,j，令k_ij(x)为Y_ij中当前玩家之外覆盖x的后继人数。对x∈R，所有实际前缀都不覆盖x，所以T_j∩R上的被捕获价值恰为

    H_ij = Σ_(x∈T_j∩R) k_ij(x)/(1+k_ij(x))。

这确实是该真实分支后继在这些客户上获得的总利润，不是任意模板权。令

    Q_ij = Σ_(x∈T_j∩I) 1/c_x(Y_ij)，
    A_ij = H_ij-Q_ij。

因为T_j⊆O，当前查询不会获得G或O外客户，故逐客户精确有

    d_ij = |T_j∩R| - A_ij。                         (CAP)

任意排列π的Σ_i|T_π(i)∩R|均等于Σ_(x∈R)a_x，其中a_x为最优元组覆盖次数。因此

    max_π Σ_i d_i,π(i) >= |O|-W

等价于

    min_π Σ_i A_i,π(i) <= Σ_(x∈R)(a_x-1)+|G|。      (FLOW?)

若(FLOW?)成立，左侧对应的真实偏离总收益不超过Σu_i=W，立即闭合half。原先已失败的遗漏匹配要求右侧没有|G|；那份反例不自动否定(FLOW?)。本稿没有证明(FLOW?)，也不把更强的uniform平均作为前提。

对仅根有最大regret Δ、其余全部正深度子局已为完整SPE的计划，所有排列偏离收益之和<=W+Δ；若(FLOW?)右端允许再加2Δ，则得到|O|<=2W+3Δ。这与同行已证的保险等价攻击接口相容，尚不是其一般证明。

**尚未支付的项。** H_ij来自互斥真实子树；把其中一名后继转交给某个实际位置时，前缀、余下主题槽和该后继的原可选行动均可能改变。原完整IC不提供删除祖先后的新SPE。需要一次全树收费，使H只流过一次，并以Q、重复比较信用及实际G共同支付。

## 3. 对全部输入有效的最优元组交换核

本节机制由shared分支提出独立Bernoulli替槽及调和积分，root重构并补随机匹配与参数核。其作用是约束真实或虚拟终局在O外的覆盖/势；不使用SPE，也没有消去上一节的跨树债务。

令B=(B_1,...,B_m)为任意m个合法主题，可为任意真实离轨终局。写a_x=Σ1_(x∈T_i)、c_x=Σ1_(x∈B_i)。将T_i与B_i逐槽配对，定义

    J={x∈O:不存在i使x∈T_i∩B_i}。

独立以概率p将每一槽T_i替换为B_i。每个实现仍是合法m槽组合，最优性给期望覆盖<=|O|。对O外客户，新增覆盖概率为1-(1-p)^c；对O内客户，若存在同槽双覆盖则不可能丢失，否则丢失概率恰为p^a(1-p)^c。因此对全部0<=p<=1，

    Σ_(x∉O)[1-(1-p)^c_x]
        <= Σ_(x∈J) p^a_x (1-p)^c_x。               (BER)

这只用最优元组覆盖数，不假定元组主题不交、客户兴趣有界或历史匿名。

### 调和积分

对p∈(0,1)乘dp/p。左项在零端连续延拓且积分为H_c；右端a>=1，所以积分有限。得到

    Σ_(x∉O) H_c_x <= Σ_(x∈J) Beta(a_x,c_x+1)，      (HARM)

其中Beta(a,c+1)=(a-1)!c!/(a+c)!。这是同一笔全客户预算，不能给每个客户另乘任意权后声称最优性仍成立。

### 去除配对选择

均匀随机排列B的槽再配对。固定x∈O，其a个T槽与c个B槽不相交的概率为

    P_m(a,c)=C(m-a,c)/C(m,c)，若a+c<=m；否则为0。

对(HARM)按配对平均，左端不变，故有纯负载型的双元组通用关系

    Σ_(x∉O) H_c_x
        <= Σ_(x∈O) P_m(a_x,c_x) Beta(a_x,c_x+1)。   (MATCH)

这里只压缩两个固定主题元组的客户负载；没有压缩或匿名化原策略。

### 参数核

对任意α>0，改乘p^(α-1)dp，得到

    Σ_(x∉O)[1/α-Beta(α,c_x+1)]
        <= Σ_(x∈J) Beta(a_x+α,c_x+1)。              (KERNEL)

同样可以对配对平均。α↓0时退化为(HARM)；这里Beta按其有限积分定义。α=1左端为Σ_(x∉O)c_x/(c_x+1)，与插入价格/拥挤税使用相同倒数口径。以上是通用交换代数，不是SPE支付结论。

### 锚定真实查询槽

relay分支补充如下可直接作用于Y_ij的版本，root另作重构。若B有一个槽等于T_j，将该槽与T_j固定配对并保持不替换，其余m−1槽独立替换/随机配对。T_j内所有客户全程覆盖；对x∉T_j，a_x、c_x均不受删除这个固定槽影响。因此

    Σ_(x∉O) H_c_x
        <= Σ_(x∈O\T_j) P_(m−1)(a_x,c_x) Beta(a_x,c_x+1)。 (ANCHOR)

参数核亦同。真实Y_ij确有一个当前查询T_j，所以(ANCHOR)无需删除任何原SPE祖先，即可约束该分支后继在O外的新覆盖/势。只有静态替槽概率中固定了一个槽，绝不声称固定槽后余下真实策略是删槽游戏的SPE。m=1时两侧为零；重复槽按位置计算。

## 4. 怎样接一般论证，哪里还不能接

每条原IC可写成

    ∫_0^1 Σ_x [1_(x∈规定主题)t^(c_x(规定真叶)-1)
                   -1_(x∈偏离主题)t^(c_x(偏离真叶)-1)] dt >=0。

故真实收益比较和(BER)/(KERNEL)都有明确的客户级积分表示。可能的接法是在不改变完整原树的前提下，选择每条真实IC与每次最优元组替槽的非负权，使O外新利润及基线项只收费一次，留下(FLOW?)所需的Q与重复信用。

**积分权不能偷换。** 原IC仅给整个积分非负，不给被积式逐点非负；不能随意再乘t依赖的Beta核后声称仍是原IC。合法的最终组合必须使用整条原IC的非负常数系数，或者另行证明核差由(BER)等真实关系支付。同样的积分表示只是一项可选择的表达，尚不是这份支付证明。

但不同Y_ij的N\O支持可不同；不能把所有离轨O外客户都叫作实际G并对各枝使用同一G预算。尤其当G为空时，(HARM)在实际叶的左端为零，并不自行控制共享遗漏R。因此本节虽是全输入有效关系，还未接通half的最后动态步骤。

本轮继续以(FLOW?)或更弱的直接half支付为终点，不将终局核、signed恒等式、无法闭合或有限阴性升级为一般定理。
