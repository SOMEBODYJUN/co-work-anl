# 实际相邻下降钱包：两个旧完整策略检验与无拥挤族的锐诊断

2026-10-24；security10。root 提供新的**一般候选**后作定向攻击。任意人数、任意共同有限目录、任意完整有序历史纯 SPE 的原 Q-CAG-HALF 仍 OPEN。本页两份旧packet的诊断均未分离候选；随后 exchange10 的[十单位客户完整 SPE](../exchange/compact_adjacent_wallet_counterexample.md)已严格否定强式 A、逐一最优指派版及逐一共同查询版。存在最优指派的弱式 A-opt 仍 OPEN。冻结旧负值保留，不能当作一般正证。无外审或新颖性主张。

## 1. 候选和精确价格

实际叶为 Z=(Z_1,…,Z_m)，实际客户负载 c_x，W=|union Z|。冻结其他实际行动，定义

    f_i(T)=u_i(T,Z_-i),     M_i=max_T f_i(T),
    C_j=Σ_(x∈Z_j\Z_(j+1)) 1/[c_x(c_x+1)],
    Ctot=Σ_(j<m) C_j.

被攻击且现已由上述独立新证据否定的强式 A 是

    Σ_i M_i−W≤Ctot.                                      (A)

较弱的存在式是能选一个最优比较元组及到角色的排列，使

    Q−W≤Ctot,       Q=Σ_i f_i(T_i).                      (A-opt)

本页没有把冻结查询当作原真实偏离。

root 的静态 cashout 可独立逐客户重构。令 r_x 为实际0/1覆盖序列的1→0次数，则 r_x≤c_x。比较覆盖客户时 Q_x≥1/(c_x+1)，所以 Ctot,x≤Q_x；实际覆盖但比较不覆盖时 Ctot,x≤1；实际未覆盖时钱包为零。故对任意比较元组，

    Ctot≤Q+W−|union T|.

这就是 root 的 Ctot≤S+W/m，其中 S=Q+(1−1/m)W−|unionT|。如果 (A-opt) 为真，两个界相夹立即给 OPT≤2W；但未证的是 (A-opt) 或强式 (A)，不是此静态消项。

一个用于检查符号的等价静态表示：令

    g_x=1/(c_x+1),
    h_x=1/[c_x(c_x+1)] 当c_x>0，h_x=0 当c_x=0。

以 g(T)、h(T) 表示相应客户和，则

    f_i(T)=g(T)+h(T∩Z_i),
    M_i−u_i=max_T[g(T)−g(Z_i)−h(Z_i\T)],
    C_j=h(Z_j\Z_(j+1)).

这是同一冻结价格下的总 regret 与有向主题切换量，**不是新付款证明**。静态相邻行关系

    f_j(T)−f_(j+1)(T)
      =h(T∩(Z_j\Z_(j+1)))−h(T∩(Z_(j+1)\Z_j))

只给 M_j≤M_(j+1)+C_j。逐行往回套会重复后方钱包，不能推出 (A)。

## 4. 已有任意人数无拥挤族正好压紧强式

这里不是继续证明一个结构子类；只是将**同一个一般候选**代入已成立的任意人数完整 SPE 族，检查钱包是否被真实损失用满。来源为现行 `collision_free_three_halves_family.md`，完整全历史归纳及独审由原资产承担。

其主题为 A_i=X_i∪{a_i}、B_i=X_i∪{b}、C_i=X_i（|X_i|=2），以及 D={b,d}；m=k+1，实际叶 C_1,…,C_k,D，W=2k+2，OPT=3k+2。实际覆盖全部客户的负载都是1，其他 a_i 未覆盖。

每个早期 C_i 行选择 A_i 的冻结值为3，且所有主题大小≤3，所以 M_i=3；末位 D 行所有主题冻结值≤2，故 M_m=2。每个相邻实际主题不交、前主题恰有2名负载1客户，所以每个 C_j=1。于是对每个 k≥1同时有

    Σ_i M_i−W=k=Ctot。

该已有族上统一系数不能从1降低，而且每一份早期下降钱包都可以承重；但 exchange10 的十客户完整 SPE 已使一般强式为假，族上等号不能挽救它。这里没有扩大无拥挤族原结论。

最优支持恰为{A_1,…,A_k,D}。将 A_i 分给其自己的 C_i 位置、D留末位，Q=3k+2=W+Ctot，仍达强式上沿。**允许最优匹配重排则完全不同**：将 D 分给 C_1，A_1分给C_2，…，A_(k−1)分给C_k，A_k分给末位D，得到

    min_opt Q=2k+1=W−1。

下界也直接成立：D分给某个早期位置时其值1，各A值至少2；D留末位时其值2，各A仍至少2。因此本族只压紧 row-max 强式，不压紧存在最优匹配的弱式。
