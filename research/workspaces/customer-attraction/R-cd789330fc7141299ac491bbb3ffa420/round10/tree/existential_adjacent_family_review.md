被攻击的精确桥是：每个完整历史纯 SPE 都存在一个最优 m 槽比较元组及其角色指派，使

    Q-W<=Csum,
    Q=sum_i u_i(T_i,Z_(-i)),
    Csum=sum_(j<m)sum_(x in Z_j\Z_(j+1))1/[c_x(c_x+1)].

## 1. 实例、政策及最优组合

取任意整数 k>=1，人数 m=k+1，令 t=k+1。全部客户组互不相交：核心 K 有 k(k+1) 个单位客户；a_1,...,a_k 各一个；b 一个；E 有 k 个。共同目录为

    C=K,
    A_i=K union {a_i}  (1<=i<=k),
    B=K union {b},
    D={b} union E.

总客户数 k^2+3k+1。每个 a_i 只能由 A_i 覆盖，E 只能由 D 覆盖；取全部 k 个 A_i 和一个 D 已覆盖全部客户。因此最优值恰为 k^2+3k+1，且每个最优 m 槽元组的多重集必须恰为 `{A_1,...,A_k,D}`。这是比较指派穷尽的关键，不只是找到一个最优下界。

政策定义在全部有序历史。若过去全部为 C，则当前不是末位时选 C，末位选 D。若过去至少有一个非 C，则选过去未选过的 A_i 中最小编号者；若所有 A_i 都已选过，则选 B。

## 2. 全历史政策确实是 SPE

先说明政策没有未定义或遗漏的历史。任一决策历史长度至多 k。若所有 k 个 A_i 都已出现，则历史长度恰 k，且它们每个出现一次，历史中没有 C、B 或 D。因此只会在末位进入“无 fresh A_i，选 B”情况。反之选择 fresh A_i 后，其私有客户 a_i 在过去没有覆盖者，后继政策也绝不重复该 A_i。

考虑已经出现非 C 的任意历史，令过去 D 的数量为 d。

- 若 fresh A_i 存在，规定当前选它。全部未来政策动作都属于 C,A_i,B 这些覆盖 K 的主题，实际政策从不再选 D；于是选择当前规定动作后的最终核心负载为 m-d。该当前玩家收益恰为 `k(k+1)/(m-d)+1>=t`。
- 在同一历史强制改选任何覆盖核心的主题，后继依同一真实政策行动，全部后继仍覆盖核心，最终核心负载仍 m-d。当前的额外私有/共享客户利润至多1。因此每个核心主题偏离收益都不超过规定收益。这个比较没有冻结任何后继。
- 强制改选 D 后，D 的最终覆盖者至少为过去 d 人加当前一人；政策后继不选 D。其 E 利润为 k/(d+1)，b 的利润至多1/(d+1)，故总偏离利润至多 `t/(d+1)<=t`，仍不超过规定收益。
- 若没有 fresh A_i，上面的历史长度事实强制当前为末位，过去恰为全部不同 A_i，d=0。规定 B 得 `k(k+1)/m+1=t`。改任何核心主题的额外利润至多1，改 D 至多 t，所以同样最优。

再考虑全部为 C 的前缀 `C^l`。

- 若 l<k，规定 C，其真实后继是若干 C 后接末位 D。核心最终负载 k，当前收益 `k(k+1)/k=t`。
- 当前改选任意 A_i 或 B，立即触发政策，后继全为覆盖核心的 fresh A 或必要时 B；最终核心负载 m。当前额外客户至多1，因此收益至多 `k(k+1)/m+1=t`。实际上在这种前缀下选 A_i 或 B 均可取到1的额外客户。
- 当前改 D，后继全为 fresh A_i：剩余人数为 k-l，fresh A_i 足够，因此没有未来 D 或 B。当前独占 b 和 E，收益 t。
- 若 l=k，当前已末位。选 D 得 t；选 A_i 或 B 得 `k(k+1)/m+1=t`；选 C 只得 k。

这覆盖全部合法有序历史、全部行动、全部可能平局。政策本身按完整历史定义；证明只使用计数来计算某个既定历史的真实收益，没有把历史匿名化。

## 3. 实际叶和相邻税

实际叶为 `C^k,D`。每个 C 玩家核心利润 t，末位 D 也得 t，所以

    W=(k+1)^2=m^2.

内部相邻 C 到 C 没有退出客户。唯一 C 到 D 转移退出全部 K，每个核心客户实际负载为 k，故

    Csum=k(k+1)/[k(k+1)]=1.

## 4. 对每个最优指派的冻结成本穷尽

固定任何实际 C 角色，删除它后静态竞争组合为 `C^(k-1),D`。对于每个 A_i，其冻结查询核心份额为 `k(k+1)/k=t`，私有 a_i 又给1；对于 D 查询，b 和 E 都与原末位 D 均分。故该类行的相关冻结成本为

    frozen_C(A_i)=k+2,
    frozen_C(D)=(k+1)/2.

实际末位 D 角色删除后，竞争组合为 `C^k`，因此

    frozen_last(A_i)=k(k+1)/(k+1)+1=k+1,
    frozen_last(D)=k+1.

最优比较多重集已被 §1 唯一确定，指派只分两类：

1. D 分给实际末位，则全部 A_i 给 k 个 C 行，`Q=k(k+2)+(k+1)=OPT`。
2. D 分给某个 C 行，则一个 A_i 分给实际末位，其余 k-1 个分给 C 行，

       Q=(k-1)(k+2)+(k+1)+(k+1)/2.

第二类比第一类便宜 `(k+3)/2>0`，所以精确最小值满足

    min_optimal_assignment Q-W=(k-3)/2,
    min_optimal_assignment(Q-W-Csum)=(k-5)/2.

当 k>=6，即 m>=7，这个严格正差穷尽所有最优元组和全部角色指派，故真正否定了存在性弱桥；不是由某个坏指派推断存在性失败。

因为 Csum 恒为1而最小 Q-W=(k-3)/2 无界，对任何预先固定有限系数 alpha，取 k>2alpha+3 就否定 `min_opt Q-W<=alpha*Csum`。这只限制该精确相邻税付款接口，不能扩大为一般目标或所有证明路线的不可能性。

## 5. 没有被否定的结论

    OPT/W=1+(m-1)/m^2<2.

故原 HALF 在此族完全没有失败。已开放的较宽弱冻结预算 `min_opt Q<=(1+1/m)W` 也未被反驳，因为其允许差额 W/m=m，而这里差额为 `(m-4)/2<m`。

同一实际叶的全部静态覆盖余量 `J=sum_(x covered)1/(c_x+1)` 等于 `k+(k+1)/2`，并未与恒为1的 Csum 同量级。本族不能否定使用真实全部余量 J 的付款；这里没有据该观察另立新候选或声称一般付款已证。
