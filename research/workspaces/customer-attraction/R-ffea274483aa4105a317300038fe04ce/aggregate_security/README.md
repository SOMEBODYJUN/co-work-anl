# 聚合安全值：非局部配对攻击与待证义务

本目录只记录本轮个人研究；主目标Q-CAG-HALF、强/弱聚合安全值及首两人配对桥均未解决。已读模型、失败机制、安全值锥、动态iid债务、末两人驻稳及末回复运输正文。未更改共享正文，未操作git或对外通信。

## 当前一般候选

复核既有R-31bbb6cfd6594bc8bb076db7b2950993/aggregate_security中首两人候选：对任意合法沉没前缀负载b、剩余r≥2人及该子博弈完整纯SPE，实际首两人收益和≥2v_r(b)。若成立，则沿任意实际路径按相邻两人分组，逐次用v_(r−1)(b+1_A)≥v_r(b)，奇数尾人用末位最佳回复，严格推出W≥m v_m(0)以及半覆盖。候选未证明；不能把末两人驻稳循环直接移给首两人。

## 新攻击模板：连续两名辅助牺牲者

n=5，九标签分为三个各三标签组。在只能选未用标签的辅助边际势游戏中，令全部五元子集F=0；四元子集若最大组计数为2则F=−1，其余F=0。每一五元终局的所有收益均为0或1。首两人无论怎样选不同标签，后面三人都可选首两人尚未使用的一整组，从而实际收益为(0,0,1,1,1)。每个后三人收益达到全域上限1，因此相应子树可以补全SPE；首两人所有偏离均得到0。Möbius编译及足够大统一偏置得到完整CAG策略。

这说明“在任何匿名边际势SPE中前段最多一名辅助低收益者”并非可用证明。它没有否定真正配对安全值：统一偏置会降低静态安全值，而合法客户的非负性可能是配对支付的关键。

## 发现性数值范围

`group_pair_probe.py`：精确整数公倍数收益逆向归纳建立上述合法编译实例的完整策略，包含所有7381有序决策历史。分别让实际首两人来自不同组或同组。然后在19个标签/组置换轨道客户重数的整个固定策略锥上，以首两人收益和归一为1，LP最大化真正安全下界2v。由于该轨道模型在九行动上传递，对称均匀查询是安全最优。两策略浮点LP最优均为1，且最优点可以只给全兴趣类型质量；这只是数值发现报告，没有保存对偶有理证明。

`group_pair_full_types.py`：在同两棵完整策略的全部511非空客户类型上保留全部激励，分别得到9481/9478个去重行。对均匀查询加三个固定种子Dirichlet查询，各最多五轮“固定查询安全下界锥LP—该质量下真正安全LP”交替。共16个已完成锥LP全部观察比为1（浮点误差以内）。这些记录均不是普遍证明，也不认证固定策略整个非线性安全值目标。

生成报告：`group_pair_numerical.json`、`group_pair_full_types_numerical.json`。下一步应推导任意r的共同静态竞争分布与首两人预算的运输恒等式，或者放宽此候选并攻击新的完整策略；不能把这两棵策略的成功提升为一般配对定理。

## 接口与后续边界

`interfaces_and_sacrifice.md`包含首两人iid安全最优分布接口P、其静态下界P≥2v、安全最优面极点最小化观察、“任意安全最优p”两人反例，以及任意k≥1,n≥2k+1的连续k名辅助牺牲者一般证明。后者没有声称合法客户安全值失败。

`first_pair_iid_attack.py`/`first_pair_iid_numerical.json`：固定34客户策略及原安全鞍点p,Q，全63类型锥LP未找到P超过首两人支付。`two_player_safe_iid_probe.py`/对应报告：1800生成输入中跳过零客户样本，对静态安全极点及四随机方向安全面极点测试，未见采样最小P超过最差完整SPE福利。不能把未穷尽安全面极点的采样当作实例级存在性证明。

`optimal_p_budget_attack.py`及`optimal_p_budget_walk.py`/对应报告：在同一两组三标签完整策略锥，固定原34鞍点以及120个随机线性方向锥点所给出的安全鞍点(p,Q)，测试实际路径去相关查询总额ΣC_i(p)≤W。浮点最优最大违反量均为0以内。固定鞍点线性截面成功不证明全锥、所有安全p或一般聚合桥。

本轮没有证明一般支付构造。已经将P的精确对象与两人量词边界交给tree_transport独立攻击；对方另行攻击首两人2v桥，其结果以对方记录为准，不计入本目录完成范围。
