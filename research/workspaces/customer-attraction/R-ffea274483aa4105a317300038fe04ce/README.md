- **纯续局菜单不能无损凸化。** 合法前缀后的两人子博弈，先凸化后截断可信收益门槛严格降低最坏剩余利润。见 `continuation_geometry/README.md`、干净输入与自含手证；`tree_transport/projected_hull_independent_review.md` 为盲算独审，root也从原始输入独立Fraction核对。可以保留非凸承诺截面递推，不能把混合续局悄悄当纯SPE。

- **低阶矩不等于有界标签正性块。** `tree_transport/global_positivity_arity.md` 给二次Boolean非负函数不能分解成真子目录非负块的任意p族。`direct_global/`有独立证明审查。它只限制统一正性替代方法，未排除为half特殊选择乘子。
