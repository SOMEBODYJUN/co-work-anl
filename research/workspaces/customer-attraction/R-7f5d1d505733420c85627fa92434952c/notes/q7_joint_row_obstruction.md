# 七个极大主题的联合行族停界（精确障碍）

## 身份与范围

这是一个**证明模板障碍**，不是 Q-CAG-HALF-6 的原模型反例，也不说明六人命题为假。它只说明：把现有“至多六个极大覆盖集”的联合预算直接改写为七个极大覆盖集，并只使用同一组行族时，无法在一个合法路由域上得到逐客户的 `W-U/2` 非负证书。

固定六名提供者，取七个极大覆盖标签 `0,…,6`。真实行动的极大容器路由固定为

```text
a = (0, 0, 0, 0, 1, 0).
```

客户列由两个位掩码 `(I,J)` 表示：`I` 是七个极大主题中包含该客户的集合，`J` 是实际六个行动对该客户的覆盖位置。只允许 `J` 在路由中标签属于 `I` 的位置上非零；最后一位是极大行动，因此 `J_5=1_{0∈I}`。为便于检验，列域还保留了所有满足这些条件的真成员关系；共有 1631 列。

## 行族

每列使用 41 个合法非负 SPE slack 的逐客户系数：

1. 六条混合下界 `M_t`。核心列的 floor 是 `1/6`，单例列的 floor 是 `1/12`；其余在 `t<5` 时使用

   `1 / max(t + 7(6-t)/2, 12)`，

   最后一位使用七极大版本的 `7/72=(6+1)/(6(6+7-1))`。
2. 七条真实末位对每个极大主题的最佳回复行

   `L_j = pay_5 - 1_{j∈I}/(p+1)`，其中 `p` 是真实前五位覆盖数。
3. 28 条允许重复索引的真实末两位税行

   `T_{jk}=pay_4+pay_5+d/((p+1)(p+2))-(1_{j∈I}+1_{k∈I})/(p+1_{j∈I}+1_{k∈I})`，

   零分子项按定义取 0。

这些行分别是六极大联合预算证明中的 mixed、lastBR 和 twoTax 行的七极大版本；这里不加入更深的真实查询、同源再查询或索引耦合行。

## 有理 Farkas 证书

令 `b(I,J)=1_{J≠∅}-1/2`。若存在非负行乘子 `λ_r` 使每个列的残差

```text
r(I,J) = b(I,J) - Σ_r λ_r row_r(I,J)
```

均非负，就得到该模板的半覆盖证书。

下面 17 个列及其非负有理权重给出一个相反的精确组合。列按 `(I-mask,J-mask)` 书写：

权重总和恰为 1。对 41 条行分别取加权平均，得到的每个行平均均非负；而目标右端的加权平均为

```text
Σ weight · b(I,J) = -148577/8996100 < 0.
```

因此对任意非负 `λ`，加权残差平均满足

```text
Σ weight · r(I,J)
  = -148577/8996100 - Σ_r λ_r · (加权行平均_r)
  ≤ -148577/8996100 < 0.
```

至少一个列的残差必为负。该论证完全是有理数逐列核验，不依赖浮点优化器。
