# 完整SPE福利低于每个静态CCE福利：十三客户反例

Claim `B6-WORST-CCE-WELFARE-NO-v1`。采用原CAG-MODEL，存在三名单位玩家、五个共同主题、十三名单位客户与全部有序历史上的纯SPE，使W=9，而同实例每个静态粗相关均衡CCE的期望福利至少137/15>9。精确最低CCE福利为2785/297。作者Fraction原始/对偶核验和另一路不导入作者模型的独立逐客户核验已通过；外审、新颖性和最小性未认证。原Q-CAG-HALF仍OPEN，此例OPT3=12且2W=18。

## 精确对象

主题0到4。不同单位客户按兴趣类型分组：{1}:2，{2}:1，{3}:1，{0,1,2,3}:2，{4}:4，{0,2,3,4}:3。压缩重数不是带权提供者。

根选0；第二位在首主题0、1、2、3后选4，在首主题4后选0。末位规则：若前两动均不为4，选4；若有一动为0另一动为4，选4；在(1,4)、(3,4)、(4,1)、(4,3)、(4,4)选2；在(2,4)、(4,2)选3。以上穷尽25个末位历史。各根偏离真实续局均给根收益3；第二位、末位完整比较见证书及独立报告。因此实际(0,4,4)收益(3,3,3)，W9。

## 为什么每个静态CCE都更好

静态CCE指任意有序终局分布μ，对每个玩家i和固定合法主题T，都满足Eμ[u_i(a)]≥Eμ[u_i(T,a_-i)]。允许任意玩家间相关，无需分布对称。

取固定混合偏离p=(0,1/5,1/5,1/5,2/5)。对任意有序终局a，记客户x总负载c_x。求和全部三名玩家偏离到同一主题T的收益，该主题内一名客户的系数为3（c=0），或4/(c+1)（c>0）：在c个原覆盖者移除时分母是c，其余3−c次分母是c+1，故c/c+(3−c)/(c+1)=4/(c+1)。

因此对每个终局计数q，

H_p(q)=Σ_T p_T Σ_{x∈T}[3·1_{c_x=0}+4/(c_x+1)·1_{c_x>0}]

恰等于全部三位玩家的混合偏离收益和。枚举全部35个三人五主题计数（不是游戏抽样），Fraction精确最小值137/15，在(0,0,0,1,2)及(0,0,1,0,2)取等。对每个CCE将其15个固定偏离约束按p加权再求玩家和，得到EμW≥EμH_p≥137/15>9。没有使用SPE→NE、匿名平局或冻结后继。

精确最低值的更强对偶λ=(0,38/99,1/11,1/11,28/99)及达到的五计数分布见`cce_failure_small_benchmark.json`。独立审查验证125个有序终局对偶列与全部15个CCE约束，证明最低值确为2785/297。

## 与真正安全值的边界

固定不观察查询的两对手主题(0,4)，各查询收益为(2,3,3,3,3)，故真正静态安全值v3≤3，W≥3v3在此例仍成立。把对手背景强制为某三人随机终局删除随机一人的边际，会施加额外一致性；这个更强静态比较不能从原聚合安全值桥推出。

失败机制：即使允许改换为任意静态CCE，福利也无法被本SPE支付。任何更弱静态比较或真正安全值桥仍需独立研究。此例不反驳一般半覆盖、原聚合安全值桥，也不声称目录、客户数最小。

## 文件与复现

- `probe.py`：随机标签计数压缩的最低CCE LP，全部输出做Fraction原始/对偶等值核验；含零客户、单玩家、重复/空主题边界。
- `cone_attack.py`：固定完整策略与固定CCE对偶乘子的客户重数LP；不是任意策略枚举。
- `alternating_cone_result.json`：首次完整策略锥发现，保留实际有理结果。
- `cce_failure_candidate.json`：七十客户中间证书。
- `cce_failure_small.json`：最终十三客户、完整31节点策略和简单有限列约束证书。
- `cce_failure_small_benchmark.json`：精确最低CCE值、原始分布、对偶与同实例模型。
- `../continuation_transport/cce_independent_small.py`及对应报告：完全独立按十三名单位客户和全部有序终局验证，未导入上述实现。

后续优先方向：一般覆盖仍可完全绕开静态比较；真正v_m比较未被本例击穿。不要重复把最低PNE换成最低CCE以导入静态PoA。
