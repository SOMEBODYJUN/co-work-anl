# 根饱和的不可补全障碍与任意主题对根行

研究员：counterexample_search；主目标 Q-CAG-HALF 仍 OPEN。本文是个人工作稿，没有外部审查。新增一般必要行有解析证明；有限点检查不代替一般证明。

## 1. 437 行坏点不能补全成任何共同目录 SPE

令 m≥2，r 是一个完整纯 SPE 的根收益，K 是整个共同目录的最大主题大小。根偏离任意主题的收益至少为该主题大小除以 m，因此 K≤mr。

若 r=K/m，偏离到任意大小 K 的主题 C 时，根收益必须恰为 K/m。每个 C 客户的终局负载必须都是 m；于是该真实分支的每个后继主题都包含 C。它们的大小至多 K，所以每个后继主题的覆盖都等于 C。若存在另一个大小 K 的主题 D 且 D≠C，末位改到 D 的收益为 |D∩C|/m+|D\C|>K/m，而其指定行动同 C 的收益仅为 K/m，矛盾。

故根饱和 r=K/m 强制全部最大主题同覆盖。

`root_saturation_exact.py` / `.json` 精确核验已发表 437 行 primal 的下列数值：

- r=7107130833817292681086323177446462215 / 70560308704423797361284609157664425493。
- |C|=|D|=5r。
- |D\C|=|C\D|=29804534291965508075715774863499600009 / 141120617408847594722569218315328850986>0。

因此这个指定坏点不能补全为任何真实共同目录完整 SPE。若添加主题大小>K，根最低收益已超过 r；若所有新增主题大小≤K，上述等号刚性矛盾仍成立。任意细分客户或重新分配旧菜单索引不改变这一论证。这里只排除已冻结的一个点；不证明整个 437 行可行域的真实可补全部分满足半覆盖。

Boss 独立得到更强的最大主题近饱和界，本文不将下述较弱任意主题行表述为最佳最大主题界。

## 2. 无须知道最大主题的线性根必要行

对任意两个合法主题 A,R（未假设它们极大或最大），m≥2，令

q_m=3m²−4m+2。

则任意完整纯 SPE 的根收益 r 满足

q_m(mr−|A|) ≥ 2(|R|−|A|)+2(m−1)|R\A|.  (P)

这是一条关于客户重数的线性必要行。它使用任意主题 A,R，因此可以直接加入已有有限必要条件模板，无须额外证明谁是整个目录最大主题。

### 解析证明，m≥3

令 δ=mr−|A|≥0。沿根偏离到 A 后的原策略真实分支，后继主题依次为 B₂,…,B_m。设根在这个分支的收益为 v≤r，令 d_j=|A\B_j|，d=Σ_{j=2}^m d_j。每个缺少的 A 覆盖席位对 v−|A|/m 至少贡献 1/[m(m−1)]，所以

d≤m(m−1)(v−|A|/m)≤(m−1)δ.  (1)

根保证全部合法主题大小≤mr。因此每个 B_j 都有 |B_j\A|≤d_j+δ。设末位指定行动 L=B_m、d_L=d_m。比较同一终局的 L 与 A 收益，A\L 客户负载至多 m−1，得到

u_L−v≤|L\A|−d_L/(m−1)≤δ+(m−2)d_L/(m−1).  (2)

末位在其真实前缀改到 R，R∩A 客户所得至少 1/m。令 e=|R\A|，h_x 是客户 x 被中间 m−2 个主题覆盖的次数。对整数 h≥0，1/(h+1)≥1−h/2。中间主题在 A 外的总覆盖席位至多

Σ_{j=2}^{m−1}|B_j\A|≤d−d_L+(m−2)δ≤(2m−3)δ−d_L.

故末位偏离 R 的收益至少

|R|/m+(m−1)e/m−(2m−3)δ/2+d_L/2.  (3)

末位最佳回复、(2)、v≤r 给出

r+(2m−1)δ/2+(m−3)d_L/[2(m−1)] ≥ |R|/m+(m−1)e/m.

m≥3 时用 d_L≤(m−1)δ 得 r+(3m−4)δ/2≥右端。代入 mr=|A|+δ 并整理即为 (P)。

### m=2

此时没有中间主题，(2) 给 u_L≤r+δ。末位改到 R 至少得到 |R|/2+e/2，所以 3δ≥|R|−|A|+e，恰为 q₂=6 的 (P)。

### 逐客户证书（另一种可接续表示）

对上述真实 A 分支，令一个客户的 A,L,R membership 为 a,b,t∈{0,1}，中间负载 h∈{0,…,m−2}。以正分子才作除法，定义

u_A=a/(h+a+b), u_L=b/(h+a+b), u_R=t/(h+a+t)。

将四条合法总量行

mΣu_A−|A|≤δ；|L|−|A|≤δ；Σh−(m−2)|A|≤(m−2)δ；Σ(u_R−u_L)≤0

分别乘 2(m−1)²,2m,m,2m。它们的 δ 系数之和是 q_m。减去 (P) 的右端后，每个客户的余项为

T=2(m−1)²(mu_A−a)+2m(b−a)+m(h−(m−2)a)+2m(u_R−u_L)−2(t−a)−2(m−1)t(1−a).

八种 membership 情形可直接验证 T≥0。a=0 时，(b,t)=(0,0),(0,1),(1,0),(1,1) 的 T 分别为 mh，mh(h−1)/(h+1)，mh(h+3)/(h+1)，mh；它们对整数 h≥0 非负。a=1 时，将 t 从 0 改成 1 增加 2(m−h−2)/(h+2)≥0。t=0,b=0 的 T=m(m−h−2)(2m−h−3)/(h+1)；t=0,b=1 的 T=m(m−h−2)(2m−h−6)/(h+2)。后者对 m≥4 非负，m=2,3 的全部合法整数 h 直接给零。这也独立证明了 (P)。

## 3. 新行仍不能单独闭合旧支持松弛

`augment_fixed_support.py` 给旧 64 原子支持上的 437 行加入全部十个固定主题的 90 条有序异主题对 (P)，求得并精确恢复一个有理可行点：

O=2564220213160830955158014979762925756724212153 / 1252636381574830042037876564751687330728253864≈2.04705870824>2，W=1。

全部 527 行与非负性用 Fraction 核验，完整 64 维新点保存在 `augment_fixed_support.json`。这个点只否定“旧437行加全部固定主题对(P)可直接推出半覆盖”的模板蕴含；它没有真实策略，也不是 SPE 反例。未保存精确最优 dual，故不声称 2.04705870824 是新松弛的精确最优值。

## 4. 其他探针及下一步

- `projected_point_probe.py/json` 仅将原坏点投影到十个固定主题后做规范全集 SPE；实际 ABCDE 路径在 ABC 已不可实现。加新主题能改变末位最佳回复，故这个有限探针单独不证明任意补全失败；真正不可补全依据是第 1 节。
- `one_new_last_reply.py/json` 允许一个新末位主题任意细分旧客户，浮点 LP 表明该自由度足以将原 V/W 偏离收益压低到实际 D 以下；未做精确认证，不作为定理。
- `quantitative_root_lp.py/json` 只探索四条总量行的有限 relaxation。m=2,…,20 的浮点发现与 (P) 一致；一般 (P) 的证明完全独立于该有限运行。

下一步需要把根真实分支的主题预算与后续所有分支的 SPE 最优性同时耦合；仅靠本节的四条总量行和旧必要条件仍不足。可将 (P) 应用于符号背景的后续节点，但背景负载破坏共同常数 m 的简单大小比较，需要重新推导，不能直接套用。
