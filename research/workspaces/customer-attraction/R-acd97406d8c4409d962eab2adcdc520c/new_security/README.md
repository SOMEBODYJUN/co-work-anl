## 1. 有限单位客户输入与完整策略

取整数 n≥2、K≥2。共同有限主题目录为 A,B,C₁,…,C_K：

- 核心由两个不同单位客户构成，A恰覆盖该核心；
- B覆盖2(n−1)个另行私有单位客户，与核心及下列客户互不相交；
- C_j覆盖同一个两客户核心，再加自己的一个私有单位客户，该K名客户互不相同。

每位提供者单位权，按固定顺序观察全部有序历史后各选一次，允许重复主题。总客户数2n+K。定义完整纯策略σ：

1. 根选A；所有其他非末位节点均选B。
2. 在末位节点，若已有前缀全为B，选C₁；若前缀恰有一个非B主题，且它是C_j，选编号最小的另一个C_l；其余前缀均选B。

该定义依赖完整合法历史、包括离轨历史；没有冻结偏离后的后继。K≥2保证“另一个C_l”存在。实际终局为(A,B,…,B)，每位收益均为2，福利W=2n；最优覆盖为

## 2. 全部有序历史的SPE证明

固定任意非末位决策节点，令ℓ为已经出现的非B主题次数。除根的指定行动外，之后所有非末位都按σ选择B，只有末位可能按上述分类改选。以下逐类比较当前玩家的所有可能行动，故覆盖任意历史依赖平局和所有离轨分支。

- ℓ=0：当前选B，最终出现n−1个B与末位C₁，当前收益2；当前改A，末位选B，当前收益2；当前改C_j，末位选另一C_l，当前从核心得1、从私有得1，合计2。故三类行动都给2。根也因此可以选A。
- ℓ=1，唯一非B为A：当前选B后末位选B，总共n−1个B，当前收益2。改A的收益1；改任意C_j的收益2（末位现见两次非B而选B）。所以B最优。
- ℓ=1，唯一非B为C_j：当前选B后，末位选另一C_l，总B数n−2，当前收益2(n−1)/(n−2)>2。该类非末位节点只能在n≥3出现。改任意不同C_l得2，改相同C_j得3/2，改A得1；故B最优。
- ℓ≥2：当前选B后，末位必选B，当前收益2(n−1)/(n−ℓ)>2。当前改非B后从核心最多得2/(ℓ+1)，并从私有客户最多得1，合计至多1+2/(ℓ+1)≤5/3。因此B严格最优。

在末位节点直接比较：

- 前缀全B时，任意C_j给3，A给2，B给2(n−1)/n<2，故C₁最优。
- 恰一个非B为A时，B给2，C_j给2，A给1，故B最优。
- 恰一个非B为C_j时，B给2，不同C_l给2，相同C_j给3/2，A给1，故选不同C_l最优。
- ℓ≥2时，B给2(n−1)/(n−ℓ)>2，所有非B行动至多5/3，故B最优。

因此σ是**每个有序历史**上最优的完整纯SPE。证明用实际偏离主题后的真实σ续局，没有将静态对手观察到查询的情况误写为安全游戏。
