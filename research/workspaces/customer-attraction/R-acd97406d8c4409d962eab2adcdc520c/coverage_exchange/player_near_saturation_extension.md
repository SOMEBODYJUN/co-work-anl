# 任意实际玩家的近饱和最大主题交换

状态：候选解析引理，2026-10-21；由 Boss6 根近饱和证明的独立审查中识别。未独立审查，尚非共享已可靠结论。主目标 Q-CAG-HALF 仍 OPEN。

## 精确陈述

采用 CAG-MODEL。令 m≥3，K=max_{D∈S}|D|，固定任意完整历史纯 SPE 的实际路径和**任意实际玩家** i。令 E_i=m u_i−K。则对任意大小为 K 的最大主题 C 及任意合法主题 D，

m|D\C|+|D∩C|≤K+(m−1)^2E_i，且 E_i≥0。

因而

OPT_m≤(2−1/m)K+(m−1)^2E_i。

m=2 时，对首位玩家同式成立；对末位玩家，系数 (m−1)^2=1 需要换为 2。m=1 不属于该交换陈述，直接 W=K=OPT_1。

## 证明：i<m

在第 i 位实际前缀处真实改选 C，之后跟随同一完整策略。记枝内当前玩家收益 v、最后动作 L。除“当前偏离者未必在第一位”外，这条完整 m 动作路径与根近饱和证明所用路径完全相同。

- 偏离者覆盖 C，故每个 x∈C 有正负载；K/m≤v≤u_i。
- d=Σ_{x∈C}(m−c_x)=Σ_{j≠i}|C\A_j|≤m(m−1)(u_i−K/m)=(m−1)E_i。
- 每个真正动作大小≤K，故 |A_j\C|≤|C\A_j|；这对已固定的过去动作和未来动作都成立。
- i<m 保证偏离者与末位不同。末位 L 仍是原策略在该真实有序历史上的最佳回复。

因此 root_saturation.md 的 (4)、(5) 逐字适用，得到上述任意 D 交换式。过去动作未被改写，也没有使用过去玩家在这个离轨分支上的最优性。

## 证明：i=m

令实际过去负载为 b_x，末位真实收益为 u_m。末位若改选 C 的收益为 v=Σ_{x∈C}1/(b_x+1)，故 K/m≤v≤u_m。对虚拟终局“原过去＋C”定义

d=Σ_{x∈C}(m−1−b_x)≤(m−1)E_m。

这次没有把 C 误称为原策略真正末位回复；只用当前末位真实最优性比较合法 D。过去在 C 外的总关联数不超过 d。于是真正改选 D 的收益至少

|D∩C|/m+|D\C|−d/2。

所以

m|D\C|+|D∩C|≤m u_m+md/2≤K+[1+m(m−1)/2]E_m。

对 m≥3，有

(m−1)^2−[1+m(m−1)/2]=m(m−3)/2≥0，

故得到统一的 (m−1)^2 系数。

## OPT 和条件半覆盖

按根引理的 I/R 非重计求和，任何 m 比较主题并集均至多 (2−1/m)K+(m−1)^2E_i。每个实际玩家各有 K/m 的直接偏离保底，故 W≥K。因此只要**存在一个**实际玩家 i 满足

E_i≤K/[m(m−1)^2]，

即可得 OPT_m≤2K≤2W。这比只检查根玩家条件弱；不声称任意实例必有这样的 i。

## m=2 末位的明确边界

C={a,b}，实际过去 B={b,c}，D={c,d}，共同目录可为 {C,B,D}。末位选择 C 或 D 都得 3/2，K=2，E_2=1。但相对 C，2|D\C|+|D∩C|=4>3=K+E_2。因此不能把根的系数1直接扩到二人末位。

检查其能否在完整两人 SPE 上到达：若根选 B、其后回复 C，根改选 C 后末位回复 D（二者不交，末位收益2，根收益2），这会使根不选 B，故这个最简目录**不支持指定根路径**；它仅反驳“所有合法末位节点”扩展。欲在完整根实际路径上反驳同系数还需另证。本引理对 m≥3 的证明没有依赖此反例。为避免夸大，这里只将其记录为末位局部证明边界。

## 取实际最小收益后的无条件边界

令 i 达到 min_j u_j。因 m u_i≤W，有 E_i=m u_i−K≤W−K。故 m≥3 时

OPT_m≤(2−1/m)K+(m−1)^2(W−K)。

这是本近饱和机制的无条件但常常很弱的推论；W≈K 时较有信息，W−K 大时不足以半覆盖。它未被声称优于既有一般弱福利界。

## 一段式统一推导供接续

任取实际 i、最大 C，设 E_i=m u_i−K。当前真实改选 C 后所有 C 客户负载 c_x≥1，v=Σ_C1/c_x≤u_i，故 d=Σ_C(m−c_x)≤(m−1)E_i；各其他动作 A 的外部量 |A\C|≤|C\A|。若 i<m，用真实末动作 L，d_L=|C\L|：其收益 t≤v+(m−2)d_L/(m−1)，其任意 D 偏离收益≥|D∩C|/m+|D\C|−(d−d_L)/2。m≥3 合并 d_L≤d 得 Q/m≤K/m+(m−1)^2E_i/m。若 i=m，不声称假想末动作 C 最优；直接用实际 u_m≥D 偏离收益及过去外部关联≤d 得 Q≤K+[1+m(m−1)/2]E_m≤K+(m−1)^2E_m。这里 Q=m|D\C|+|D∩C|。求 m 比较主题并集用 I/R 求和即得 OPT 版本。

## m=3 时统一逐 D 系数确实锐

取两个互不交单客户主题 A={a}、B={b}，三名玩家。完整策略：根选 A；第二位在 A 后选 B、在 B 后选 A；末位在 AA、AB、BA、BB 后分别选 B、A、B、A。末位各节点均为最佳回复；第二位选相反主题后收益为1，重复首主题仅1/2；根两种行动最终均得1/2。因此这是完整历史纯 SPE，实际 A,B,A。

对根（末位同样）取最大 C=A、D=B：K=1、u_i=1/2、E_i=1/2，而 Q=3。因此若统一交换式写成 Q≤K+cE_i，必须 c≥4；本文 m=3 系数 (m−1)^2=4 达等。其 OPT_3=2、W=2，主半覆盖当然成立。这个锐性仅针对逐 D 交换接口，不针对 OPT 目标；它说明不能靠把逐 D 系数压到2直接证明弱逐人半覆盖阈值。
