# 完整 SPE 福利低于所有静态 PNE：一个失败桥

状态：显式有限反例，作者定义级有理交叉审计完成；独立审查由 Boss 另行实施。不是 Q-CAG-HALF 反例。

被否定候选为：对任意共同目录单位客户游戏及任意完整纯 SPE 终局 s，存在一个同实例静态纯 Nash 终局 p 满足 W(p)≤W(s)。若成立，它本可用静态半覆盖导出顺序半覆盖；下面否定它。

四人共同目录 A,B,C,D。下列客户兴趣及重数表示50名不同单位客户：

| 兴趣 | 重数 |
|---|---:|
| AB | 1 |
| AC | 2 |
| BC | 1 |
| ABC | 5 |
| BD | 2 |
| ABD | 16 |
| CD | 8 |
| ACD | 6 |
| BCD | 9 |

定义完整策略：

1. 根选A。
2. 第二人在历史D后选A，其余首动作后选D。
3. 第三人在历史DD后选A，其余长度二历史后选D。
4. 第四人通常选D；若前三个行动恰为B,D,D的任意排序，则选C；若恰为C,D,D的任意排序，则选B；若为D,D,D，则选B。

这些规则覆盖全部85个有序历史。真实路径为(A,D,D,D)，三位D玩家各得71/6，A玩家得27/2。因此W=49，唯一未覆盖客户为BC型。根四种行动的原策略真实续局收益分别为

`A:27/2, B:49/4, C:143/12, D:71/6`，

所以根A严格最优。全部离轨子局的最优性通过不导入规范求解器的 Fraction 审计逐项验证；任何比较都使用规则4的真实回复。

穷举35个四维非负整数终局计数（总数四），唯一静态PNE计数为 `(A,B,C,D)=(0,1,1,2)`。该计数覆盖全部50客户，B收益49/4，C收益143/12，两位D收益各155/12。其他34个计数各有一个严格静态盈利偏离。

因此

`W(SPE)=49 < min{W(PNE)}=50`。

机制：在路径(A,D,D,D)中，A玩家的静态改选B会使其收益由27/2增至55/4（后继固定为DDD）；真实顺序偏离至B后，末位从D改选C，使根的偏离收益下降到49/4。该可信回复把静态收益改善阻止，但又留下实际未覆盖的BC客户。由静态最佳回复迭代得到PNE时，福利必须从49上升到50；不能通过“找一个不增福利PNE”的方式转移静态定理。
