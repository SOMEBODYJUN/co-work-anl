# 一般直接证明尝试：全局覆盖、静态均衡桥与真实边界

对象固定 CAG-MODEL、目标 Q-CAG-HALF（一般全称半覆盖仍 OPEN）。这是 Boss6 的子研究员草稿，不修改共享数学状态。允许任意历史平局，客户类型重数表示不同单位客户。

## 已取得的实质边界

- [静态最差 PNE 支配桥反例](pne_welfare_bridge_failure.md)：四人四主题50单位客户，完整纯 SPE 福利49，而本实例所有静态 PNE 福利50。这里不是已知的“终局不是PNE”反例，而是否定更弱的“存在一个PNE其福利不高于任意给定SPE”桥。
- [已冻结缩减实例与完整策略](pne_bridge_reduced.json)。不声称最小，不再覆盖。
- [不导入规范求解器的定义级 Fraction 作者审计](audit_pne_bridge.py)，枚举85有序历史、340行动比较和35终局计数。作者交叉实现不是独立外审。
- [桥扫描脚本](scan_bridges.py)、[缩例脚本](shrink_pne.py)保留发现经过；缩例脚本默认输出路径仅为发现用途，冻结实例应另存新版本。

## 在攻候选与精确缺口

固定真实根覆盖 C 和任意比较主题 T_1,...,T_m，尝试直接证明

`|(T_1 union ... union T_m) minus C| <= W`。

这比半覆盖强，但不同于已失败的逐人或 m 倍最大残余主题保证。解释为：离轨分支可用 C 客户作为可信惩罚的银行，完全避开实际路径的比较客户是否能超过银行总预算。当前没有一般证明，不能据有限固定策略锥成功上升状态。

未来若用归纳，必须保留真实离轨玩家覆盖 R 后从 C 获取的份额转移。简单要求每步或所有前缀非负已有别处反例。另一个可选方向是对比非均匀的分支覆盖收益，而不逐人给独立查询保底。
