## 真正安全值中的独立性限制

`../round3_security/quantifiers/`（按其实际 README 读取）研究互不交单客户主题的静态安全值。
Boss 自行重构的定量结论候选：n≥3 个单客户主题、n 名提供者时，真正静态安全值为
v=(n+1)/(2n)，而任何 n−1 名独立但允许非同分布的静态竞争者，其最大查询收益至少

    v + (n−1)(n−2)/(2n²[n²+2(n−1)²]).

此结果限制安全对偶的 product 构造，并不否定聚合安全值桥；该实例全部 SPE 覆盖所有 n 名客户。
普遍证明与研究员独立重构以该目录最终正文为准；未完成前仍按候选记。

- `audit_product_security.py`：Boss 零导入独立 Fraction 审计，逐整数余项、真实静态原始/对偶、product 概率卷积、碰撞恒等式、行平方和界及阈值分支。
- `product_security_audit.json`：上述有限审计冻结输出。不是一般证明。

## 抽象承重假设的低成本判别

`abstract_clone_probe.py` 固定完整形式策略，以任意匿名精确势
u(a,H)=F(H+a)−G(H) 为变量，加入全部真实有序历史 SPE 行、全部终局效用非负和
全部 clone 最坏性 u(a,H+a)≤u(a,H+b)。归一实际总收益 W=1，固定查询分布，
优化面对全部静态背景的查询保证。所有根行保留，不把非客户吸引的势点视作真实客户。

- `abstract_clone_n3p3.json`：200 个随机逆推形式策略、每个 8 个固定查询的有限发现运行。
- `abstract_clone_n4p3.json`、`abstract_clone_n3p4.json`：各 80 个策略、8 个查询。

这些运行没有分离强聚合界；没有普遍真值含义，也没有恢复一般对偶证书。
已停止延长同类无反例样本，把“精确势 + clone 最坏性是否足以产生全树支付”交给结构分支解析攻击。
源随机种子、约束、边界和求解方法全部在脚本中，浮点最优值不称为精确上界。
