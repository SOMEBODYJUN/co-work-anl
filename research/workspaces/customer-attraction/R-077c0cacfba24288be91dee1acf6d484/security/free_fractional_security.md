# 自由分数静态背景：新的较弱安全门槛与开放逐人桥

日期：2026-10-21。模型严格为 CAG-MODEL：任意有限共同目录、单位客户、单位提供者、全部有序历史上的纯 SPE，允许空主题、重复主题及任意历史依赖平局。

**状态。** 以下静态性质、嵌入与凸切线证书由本文直接证明；尚未经独立数学审查。核心逐人桥 **FF-LEADER 是 OPEN 候选**，不是已证明定理。一般 Q-CAG-HALF 及真正聚合安全值桥仍 OPEN。这里没有把静态分数对手解释成可执行的隐藏随机承诺。

## 1. 自由分数背景的定义

固定合法过去背景客户负载 b，恰剩 r≥1 人。对主题分布 q，记

    α_x(q) = Σ_{A∋x} q_A,
    g_{r,b,q}(A) = Σ_{x∈A} 1/[b_x+1+(r−1)α_x(q)],
    t_r(b) = min_{q∈Δ(S)} max_{A∈S} g_{r,b,q}(A).

不同于真正安全值，分母采用一个自由选择的**确定分数负载**，并不对整数主题组合取期望。不同于已被否定的实际均匀缩放背景，q 可依实例与完整策略重新选择，也允许选择实际路径以外的目录主题。有限目录和紧单纯形保证最小值达到。r=1 时 q 不影响值，t_1(b)=max_A Σ_{x∈A}1/(b_x+1)。

记真正不观察查询抽样的静态安全值为 v_r(b)。Jensen 给

    t_r(b) ≤ v_r(b).

准确证明：对任意整数竞争组合的分布 Q，令其期望主题计数除以 r−1 为 q；逐查询有 E_Q f_B(A) ≥ g_{r,b,q}(A)。因此 max_A E_Q f_B(A) ≥ t_r(b)，再对 Q 取最小。r=1 两者相等。

## 2. 根下界与合法前缀嵌入

空背景、m 人时，已有静态代数直接给

    OPT_m ≤ (2m−1)t_m(0).

证明：对每个 q，令 L_x=(m−1)α_x(q)，M=max_A g_{m,0,q}(A)。最优 m 主题在客户 x 的重数为 d_x。逐客户 1_{d_x>0} ≤ (d_x+L_x)/(1+L_x)，故

    OPT_m ≤ Σ_{j=1}^m g(T_j) + (m−1)Σ_A q_A g(A)
          ≤ (2m−1)M.

再对 q 取最小。该证明也适用于最大覆盖标准 LP：将 1_{d>0} 换为 min(1,d)，d 为任意非负分数重数，逐客户不等式仍真。因此若逐人桥成立，它实际上支付标准最大覆盖 LP 的一半；本文不据此提升桥的状态。

对每个合法主题 A、r≥2，有

    t_{r−1}(b+1_A) ≥ t_r(b).

原因：左侧背景中，除 b 之外的总分数主题负载为 1_A+(r−2)q。它属于右侧允许的全部总重 r−1 分数主题负载；左侧优化域只是右侧的子集。r=2 时左侧总分数负载只有 A，同样成立。这一嵌入不调用理性续局。

## 3. 新的开放承重桥 FF-LEADER

精确候选如下。

> 对任意合法过去背景 b、任意剩余人数 r≥1、任意完整有序历史纯 SPE，当前行动者的最终收益 u 满足 u ≥ t_r(b)。

它严格弱于已失败的逐人真正安全值桥 u≥v_r(b)，不能因为后者失败而否定。它也不是仅在某份实际缩放背景上要求 cap。

若 FF-LEADER 成立，沿原真实路径的背景嵌入给每位玩家 u_i≥t_{m−i+1}(b_i)≥t_m(0)，从而

    W ≥ m t_m(0),
    OPT_m ≤ (2−1/m) W < 2W  （m>1）.

实际上只需更弱的根聚合桥 W≥(m−1/2)t_m(0) 即推出半覆盖。FF-LEADER 是充分条件，并非原猜想的等价重述。

目前没有从全部真实根分支的 leader payoff cap 推出存在一份自由分数背景 cap 的一般构造。普通 log 势极大背景也不能未经证明代替 t 的 minimax 最优背景。

## 4. 凸极小极大与精确反例证书

对查询分布 p、背景分布 q，定义

    F(p,q) = Σ_x α_x(p)/[b_x+1+(r−1)α_x(q)].

F 对 p 线性，对 q 凸且连续。紧凸单纯形上的凸极小极大定理给

    t_r(b) = max_p min_q F(p,q).

固定 p 后令

    H_A(p,q) = Σ_{x∈A} α_x(p)/[b_x+1+(r−1)α_x(q)]².

当 r>1，∂F/∂q_A=−(r−1)H_A。某 q* 全局极小化 F(p,·) 当且仅当

    H_A(p,q*) ≤ κ 对全部 A，
    q*_A>0 ⇒ H_A(p,q*)=κ.

这是凸最小化的 KKT 条件。p 作为 epigraph 对偶时还应支持在 g_q(A)=t 的活跃查询上。它与最大化 Σ_x log[b_x+1+(r−1)α_x(q)] 的 KKT 不同，后者只给 g_q(A) 的支持等值，不能自动认证本 minmax。

更方便的是不要求 q0 精确极小。任意有理 p,q0 均给一个**全背景精确下界**：

    t_r(b) ≥ F(p,q0)
             +(r−1)[Σ_A q0_A H_A(p,q0)−max_A H_A(p,q0)].      (LB)

证明：凸切线 F(p,q)≥F(p,q0)+∇F(p,q0)·(q−q0)，右侧在单纯形上的最小值正为 (LB)。再用 max_p min_q 定义。所有客户重数与背景为整数、p/q0 有理时，右端可用 Fraction 精确检查。若数值发现 t_r(b)>u，把 p/q0 有理化并得到 (LB)>u，就能严格否定 FF-LEADER；无须声称浮点最小值或无理驻点精确。

## 5. 目前精确边界：不可把自由背景限制在实际上轨支持

这个边界是已有 `tests/audits/customer_attraction_full_tree_flow.py` 五客户例的新推论，**不是新输入或一般桥反例**。

三个主题标签 0,1,2，非空客户兴趣 mask 的重数为 {2:1,5:2,6:2}。即一名只喜欢1，两名喜欢0/2，两名喜欢1/2。两名玩家；完整策略根0，末位在首0后选1，在首1或2后选2。

末位在首0后各行动收益为 (1,3,3)，在首1后为 (2,3/2,3)，在首2后为 (1,2,2)。指定行动逐行最优。根三个行动的真实收益分别为 (2,2,2)，因此全历史为纯 SPE。实际路径 (0,1)，收益 (2,3)，W=5。

若强制 q 只支持实际主题0,1，写 q=(s,1−s,0)，遗漏主题2的查询值为

    g_q(2)=2/(1+s)+2/(2−s) ≥ 8/3 > W/2.

不等式由凸性/对称性于 s=1/2 取等。因此不存在实际支持上的分数背景把全部查询 cap 到 W/2。该加强的强聚合 cap 要求已失败。

但允许 q=(0,0,1)，三个查询值为 (1,2,2)，故 t_2≤2；真正静态安全值也恰为2（查询2面对任意单竞争主题收益≥2，对手固定2使全部查询≤2）。FF-LEADER、真正聚合桥和原半覆盖均未被反驳。这里也没有反驳较弱的实际支持 cap W/(m−1/2)。

## 6. 有限发现记录，不作普遍证据

`fractional_leader_probe.py` 使用每一条完整有序历史 SPE 比较 Γw≥0。固定 p 时，以连续 q 的凸 oracle 为半无限 LP 添加切平面；交替重选 p 时，用 t 的 epigraph 凸规划及其 KKT 对偶乘子。所有数值仅供发现。

- 既有34、36、113客户所用三棵六主题完整σ：各10次 p/w 交替，最大 t/u1 浮点比值为1；没有发现反例。这里保留全兴趣类型，等号ray可能使局部搜索停滞。
- 既有86客户五人十主题完整σ，仅保留其29种原正兴趣类型并允许任意非负重数：10次交替，最大 t/u1≈0.9969369455。原实例约0.996383975。没有发现反例；不是全类型锥认证。
- 独立子研究员另对六主题反组完整σ去掉全兴趣类型、100个固定 p 做切平面攻击，最高约0.9786565434；其 checkpoint 在 `aggregate_attack/`，不是全 p 证明。
