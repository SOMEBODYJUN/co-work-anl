## 解析尝试与承重障碍

1. 根真实最优性给所有根行动A的真实续局leaderpay L(A)<=u_root；这是真正跨分支共同cap。还没有从它构造一个查询不观察的共同分数对手q。选A后后继适应A的量词障碍保留。
2. 自由t最优(q,p)的凸KKT条件是q支持最大化 sum_{x in A} alpha_p(x)/[b_x+1+(r-1)alpha_q(x)]^2 的主题。普通log势最大者使用不同权重，不能直接把log KKT当成minmax KKT或断言两最优对象相同。
3. 固定p的凸oracle可以精确化为有理一阶下界；但所有已完成p只有负gap，没有需要精确恢复的反例。只增加有限p不能替代一般证明。
4. 若 b=B 很大，真安全值与分数t的Jensen差通常从O(B^-3)开始，而leader亏损若能在O(B^-2)的等主题大小pairwise-overlap极限里成立，就可能升成扩大背景接口的反例；要成为原模型反例还需合法主题多重前缀，且保留全部前缀主题可继续选择。去掉等大小主题共同的自项后，极限效用为 |A|/B - sum_j |A cap B_j|/B^2；0/1结构还给 |A|+|B cap D|-|A cap B|-|A cap D|>=0（等大小时是Hamming三角约束）。尚未找到满足该结构的极限亏损；此为可继续的解析攻击方向，不是反例。

下一步优先是证明／反驳根全部真实分支共同cap到自由q存在性的引理；若走凸证书，需为任意完整策略构造q或按p使用真实激励行，而非固定q、固定节点平均或全兴趣等号面。
