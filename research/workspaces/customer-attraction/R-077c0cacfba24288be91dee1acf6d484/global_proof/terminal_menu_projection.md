# 真实末两人菜单的无条件机会损失投影

状态：完整解析推导，尚未独立审查。是`common_penultimate_theme_half.md`中同一G的一个无条件推论；不声称一般half或新颖性。

## 对象及精确结论

采用CAG-MODEL。任意有限单位客户、共同非空有限主题目录、m>=2名单位玩家，以及每个全部有序历史纯SPE，允许空/重复主题和任意平局。真实倒二主题A、末位主题B，前m−2主题并集P，F=|A\P|，末两人真实收益u_A,u_B，实际总覆盖W。

对任意m个比较主题并集大小O，有

    O <= m u_A + u_B/2 + tau_(m−2) + F/4,            (1)
    tau_(m−2) = sum_(x:p_x>=1) p_x/(p_x+1),

其中p_x是前m−2实际负载。因此

    O−W <= m u_A−u_B/2−F/4.                          (2)

特别取O=OPT_m。没有倒二主题包含于早期主题的假设。

## 同一真实菜单

比较主题为T_1,...,T_m，固定前m−2实际有序历史后，原SPE在T_j之后的末位真实回复为R_j。
使用现行正文的非负真实SPE组合

    G=S+Z/(2m)+V/m >=0,
    S=sum_j[u_A−U_p(T_j,R_j)],
    Z=sum_j[u_B−U_p(R_j,A)],
    V=sum_(j!=k)[U_p(R_j,T_j)−U_p(R_k,T_j)].

每个客户记a=1_A、d=sum1_Tj、ell=sum1_Rj、o=1_(d>0)。交集会员h消去后

    G_x=m alpha+beta/2−d/(p+1)
        −ell/[2m(p+a+1)]+d ell/[m(p+1)(p+2)].

所以

    O <= m u_A+u_B/2+sum_x r(p,a;d,ell),
    r=o−d/(p+1)−ell/[2m(p+a+1)]
          +d ell/[m(p+1)(p+2)].                      (3)

## 逐客户上界

若d=0，r<=0。若d>=1，r关于(d,ell)双线性，在[1,m]×[0,m]的最大值在四角。

若p=0,a=0，四角值为0、0、1−m、(1−m)/2，最大0。
若p=0,a=1，四角值为0、1/4、1−m、3/4−m/2，最大1/4（m>=2）。

若p>=1，四角(d=1,ell=0)为p/(p+1)。
(d=1,ell=m)相较该值的增量为

    1/[(p+1)(p+2)]−1/[2(p+a+1)],

当a=0时等于−p/[2(p+1)(p+2)]<=0；当a=1时等于(1−p)/[2(p+1)(p+2)]<=0。
(d=m,ell=0)显然不大于该值。(d=m,ell=m)相较该值的差为

    1/(p+1)−m/(p+2)−1/[2(p+a+1)] <=0,

因为实际前缀负载p<=m−2，所以m/(p+2)>=1>=1/(p+1)。因此

    r <= p/(p+1) (p>=1),
    r <= a/4      (p=0).

代入(3)得到(1)。

## 将税压入实际覆盖

逐客户有

    W−tau_(m−2)−u_B >= F/2.                          (4)

对p>=1客户，左端贡献1/(p+1)−b/(p+a+b)>=0；对p=0,a=1客户贡献1−b/(1+b)>=1/2；
对p=a=0,b=1客户贡献0；完全未覆盖贡献0。故(4)成立。
把tau_(m−2)+F/4 <= W−u_B−F/4代入(1)，得到(2)。

## 用途及边界

任何真正违反half的SPE必须有

    m u_(m−1) > W+u_m/2+F/4,

且末位原税诊断给m u_m>W。所以最后两位都严格高于实际平均收益。
这些是必要条件，不能排除较早玩家的真实分支支付缺口。

(2)特别证明`OPT_m−W<=m u_i`在i=m−1处成立；末位由已有真实最佳回应税界成立。
不能将i=m−1任意替换为更早位置：此G使用了后继为一个真实末位最佳回应的性质。
