# 任意 Beta-clone 终局的复用债：完整一般关系与可信缺口

2026-10-24。个人研究稿；对象为任意有限共同目录、任意剩余人数和任意合法整数背景。父方与本研究员独立得到下述单次玩家比较和总债等式；§4 的复用次数上尾强化由本研究员逐式推导，尚未独立审查。没有新颖性或外审声明。**Q-CAG-HALF 仍 OPEN；本文没有新的 SPE lift。**

本文承接 [Beta 静态表示](../full_tree/beta_clone_background_representation.md)。已经失败的接口是“固定原完整策略，在每个 fresh 历史保留规定选择，再补全重复孩子”，见[自足失败见证](../full_tree/beta_clone_fixed_strategy_lift_failure.md)。下文不再检验同类见证，只把全部含重复终局上仍成立的比较写清。

## 1. 对象和统一口径

原单位客户为 x，兴趣主题集合为 A_x，固定背景负载为 b_x≥0。每个原主题有 q≥r 个 clone。对于 b_x≥1，令 P_x 的密度为 b_x(1-p)^(b_x-1)；给定 P_x=p，每个相关 clone 独立以概率 p 包含这个客户。b_x=0 时令 P_x=1。此概率记号表示有限兴趣类型的非负有理质量分解，清共同分母后是不同单位客户组成的确定标准 CAG；以下所有量均除去该共同倍数。

固定任意 r 槽 clone 终局 z，允许任意重复。原主题投影记为 πz。对玩家 i 定义

\[
 U_i^c=u_i^{\rm clone}(z),\qquad
 U_i^b=\sum_{x\in \pi(z_i)}\frac1{b_x+K_x},
 \tag{1}
\]

其中 K_x 是 πz 中覆盖 x 的玩家总数，含复用次数；A_x 是客户兴趣标签集合。

对每个 x，把 z 中相关的不同 clone 列为 j=1,...,d_x，使用次数为 n_{x,j}≥1；故

\[
 K_x=\sum_{j=1}^{d_x}n_{x,j}.
\]

同一个全局 clone 的使用次数不依赖 x；下标 x 仅表示当前客户的相关 clone 列表。令 S 为 clone 在全终局恰出现一次的玩家集合，R 为其余玩家。S、R 是按完整 clone 标签划分，不能按原主题是否重复划分。

若 K_x=0，则该客户所有项均为零。凡遇 b_x=K_x=d_x=0 的覆盖比例均按零定义。

若某些 clone 覆盖集合相同，可先在带标签副本中记账，再商为合法集合目录；对商目录终局任取标签提升即可应用本文。S、R、H_t 依该提升定义，不能当作商目录的内在量；各终局实际收益与相应比较不受同集合副本影响。

## 2. 每个单次 clone 玩家逐客户获得非负增益

**命题 1。** 对每个 i∈S，有 U_i^c≥U_i^b；此不等式逐原客户成立。

证明。只需固定 i 覆盖的某个 x。给定 P_x=p，并条件于 i 的相关标签被包含。其余一个使用 n≥2 次的相关标签，其拥挤贡献为 nI，I~Ber(p)。把这一个相关标签拆为 n 个互异 fresh 标签后，拥挤贡献成为 Y~Bin(n,p)，其它负载 Z 保持冻结。

函数 g(s)=1/(1+Z+s) 在 [0,n] 上凸。对于每个 y∈[0,n]，

\[
 g(y)\le(1-y/n)g(0)+(y/n)g(n).
\]

对 Y 取期望，利用 EY=np，得到

\[
 \mathbb E g(Y)\le(1-p)g(0)+pg(n)=\mathbb E g(nI).
 \tag{2}
\]

把式(2)乘以 i 的标签被包含的条件概率 p，再对 Z 和 P_x 取平均，说明拆开别人的复用标签不能提高 i 的份额。依次拆开全部其它重复标签。i 自己是单次标签，拆完后所有 K_x 个相关标签互异，Beta 静态身份给其份额恰为 1/(b_x+K_x)。因此原含重复终局中的份额至少为此值。b_x=0 时 P_x=1，全部比较取等。逐客户相加即得结论。证毕。

这个方向要特别注意：**单次玩家因别人复用而得益**。不能把静态 fresh 优势误读为所有玩家的 clone 收益都不超过或都不小于原背景收益。

## 3. 全部复用玩家的精确总债等式

clone 终局覆盖一个原客户的质量，只取决于不同相关 clone 数 d_x：

\[
 W_c=\sum_x\frac{d_x}{b_x+d_x}.
 \tag{3}
\]

原主题投影的原背景剩余总利润为

\[
 P_b=\sum_iU_i^b=\sum_x\frac{K_x}{b_x+K_x}.
 \tag{4}
\]

定义

\[
 D=P_b-W_c
 =\sum_{x:b_x>0}\frac{b_x(K_x-d_x)}{(b_x+K_x)(b_x+d_x)}\ge0,
\qquad
 G=\sum_{i\in S}(U_i^c-U_i^b)\ge0.
 \tag{5}
\]

P_b 是原背景中剩余玩家的总利润，并非原客户的通常覆盖福利。

**命题 2（精确复用债）。** 对任意 z，

\[
 \boxed{\quad
 \sum_{i\in R}(U_i^b-U_i^c)=D+G\ge0.
 \quad}
 \tag{6}
\]

证明。clone 游戏收益守恒给 Σ_iU_i^c=W_c。用式(4)减去该式，再把 S 项移到右边，便是式(6)。D、G 的非负性分别来自式(5)和命题1。此等式也逐客户成立。证毕。

若全终局只有一个被复用的 clone，且其出现 n≥2 次，则 R 中这 n 位玩家选择完全相同的 clone，收益相同；其原主题投影收益也相同。因此每位复用者均满足

\[
 U_i^c\le U_i^b,\qquad i\in R.
 \tag{7}
\]

有多个复用标签时，式(6)只控制其总和，不能直接逐标签分摊同一份债。

## 4. 按复用次数的所有上尾均有折扣

这是式(6)之外的一个静态强化，仍然没有跨树含义。令 n_i 为玩家 i 所用完整 clone 标签在 z 中的总出现次数；对整数 t≥1，定义 H_t={i:n_i≥t}。

**命题 3。** 任意 t≥1 均有

\[
 \sum_{i\in H_t}U_i^c\le\sum_{i\in H_t}U_i^b.
 \tag{8}
\]

证明。固定客户 x 和 P_x=p。相关的两个不同 clone j、l 的使用次数为 n_j、n_l，除这两组外的负载为 Z。每个使用者从 x 获得的条件期望分别为 v_j(p)、v_l(p)。只在两标签恰一个被包含时有差别，故

\[
 v_j(p)-v_l(p)
 =p(1-p)\mathbb E\left[
 \frac1{n_j+Z}-\frac1{n_l+Z}\right].
 \tag{9}
\]

因此 n_j≥n_l 蕴含 v_j(p)≤v_l(p)；对 P_x 积分后仍成立。写 v_j 为积分后的每用户份额，则对任意相关复用次数上尾 J_t={j:n_j≥t}，它以 n_j 为权的平均份额不超过全体相关组的加权平均份额。令 C_t=Σ_{j∈J_t}n_j，若 C_t>0，则

\[
 \sum_{j\in J_t}n_jv_j
 \le \frac{C_t}{K_x}\sum_jn_jv_j
 =\frac{C_t}{K_x}\frac{d_x}{b_x+d_x}
 \le\frac{C_t}{b_x+K_x}.
 \tag{10}
\]

最后一步等价于 b_xd_x≤b_xK_x。C_t=0 时两边均零。右端恰为 H_t 中玩家在原背景投影下从 x 获得的总份额。对 x 求和得式(8)。证毕。

由有限层蛋糕分解，任意定义在 {1,...,r} 上的非负非降函数 f 还满足

\[
 \sum_i f(n_i)U_i^c\le\sum_i f(n_i)U_i^b.
 \tag{11}
\]

例如，使用最大复用次数 clone 的玩家，各自亦满足 U_i^c≤U_i^b：逐客户式(9)使其单人份额不超过全体加权平均，随后使用式(10)的最后一步。这不是对任意复用组的逐人结论。

## 5. 为什么这些关系还不能补完真正偏离树

固定原背景完整 SPE σ，当前玩家的规定利润为 u，改选原主题 T 后沿原策略得到叶 t_σ(T)。原 SPE 只给

\[
 u\ge u_i^b(t_\sigma(T)).
 \tag{12}
\]

在 clone 树中复用某个旧 clone 后，可信后继可能产生另一个 clone 叶 z；其投影 πz 未必是 t_σ(T)，甚至未必是原背景该子博弈的某个 SPE 叶。即使适用最有利的单组折扣式(7)，它也只给

\[
 u_i^c(z)\le u_i^b(\pi z),
 \tag{13}
\]

而没有给所需的 u_i^b(πz)≤u_i^b(t_σ(T))。式(6)把同一叶上的债转给该叶的其它玩家，不能把他们位于互斥真实子树的收益移到规定叶，亦不能证明原规定后继在重复孩子仍然最优。

已有固定策略失败见证精确展示此差别：重复孩子给当前玩家25，原主题投影 AAC 给其27；这完全符合式(13)。被要求保留的 fresh 叶 AAB 只给24；原 SPE 对该规定分支的比较不能把投影 AAC 的27压到24。这里只复述已证缺口，不把该局部合同称作实际根路径或 Q-CAG-HALF 反例。

## 6. 尚开放的较弱可信接口

对给定原背景 SPE σ，令其实际剩余总利润为 P_σ，Beta clone 游戏的最优值由既有静态身份精确等于 F_r(b)。下列两个比固定完整策略 lift 更弱的候选仍未证明，也未被本稿反驳：

1. 存在某份 unrestricted clone 完整 SPE，其实际叶全部 fresh，并投影为 σ 的实际叶；允许重选其它所有 fresh 历史的规定行为。
2. 存在某份 unrestricted clone 完整 SPE τ，使 W_c(τ)≤P_σ；不要求保持叶或原主题计数。

第1项蕴含第2项；若第2项对全部合法输入成立，则原根 half 会推出背景半剩余利润：F_r(b)≤2W_c(τ)≤2P_σ。这个条件推论不是背景 half 的证明。

式(6)、(8)仅是任意固定终局的真实一般关系。它们没有选出 τ，没有保持任何真实子树的最优性，亦没有证明其福利方向。当前需要的仍是使所有应付偏离同时可信的全树比较，而不是把同叶复用债再次当作跨叶信用。
