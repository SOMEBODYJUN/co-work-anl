# Beta-clone 固定完整策略提升不可补全：一个自足见证

2026-10-24。个人解析结果；作者从定义核对，父代理和内部子代理已独立手算核心表，另一路独立审查进行中。无外审、新颖性或最小性声明。**原 Q-CAG-HALF 仍 OPEN。**

本稿只击穿 [Beta 背景静态表示](beta_clone_background_representation.md) 的一种可信接入：把给定原完整 SPE 在所有 fresh-clone 历史的原主题选择逐项保留，再希望任取重复 clone 孩子的完整 SPE 填满。静态表示和最优值身份仍正确；这里不否定允许重选所有 fresh 历史的更弱终局实现，也不提供半覆盖反例。

## 1. 合法原背景及原局部完整 SPE

有三个 regular 主题 A、B、C，下列每行均由不同单位客户组成：

| 原兴趣 | 客户数 | 固定背景负载 |
|---|---:|---:|
| A、B | 36 | 0 |
| C | 3 | 0 |
| A、C | 36 | 1 |
| B、C | 10 | 0 |

对每个 A、C 客户 x 另加只含 x 的主题 P_x。固定合法前缀 h 依次选择这36个 singleton 主题各一次，恰好实现表中背景 b；随后尚有3位玩家。全目录因此有限共同，全部原客户、玩家均为单位。

在 h 后任何剩余有序历史，任一 singleton 行动利润至多1；选择 C 不论真实未来如何，单从背景为零的13名 C 或 B、C 客户就保证至少13/3。因此每个 singleton 严格劣于某个 regular 行动，且这种比较保留真实未来响应。首次 singleton 历史之后可以各自任取完整 SPE 填满，regular 历史上只需比较 A、B、C。

现规定剩余第一人曾选择 A。其后第二人的每个行动 a 对应末位真实选择如下：

| 第二人 a | 末位规定选择 | 第二人最终利润 |
|---|---|---:|
| A | B | 24 |
| B | A | 22 |
| C | A | 22 |

这些末位选择确为完整最佳回复，因为末位的全部 regular 行动利润为：

| 第二人 a / 末位候选 | A | B | C |
|---|---:|---:|---:|
| A | 21 | 22 | 22 |
| B | 24 | 17 | 20 |
| C | 27 | 23 | 31/2 |

例如 AA 后末位选 B 时，第二人收益为 `36/3+36/(1+2)=24`；末位 B 得 `36/3+10=22`，与 C 的 `3+36/4+10=22` 并列。第二人改 B 后末位 A 给其 `36/3+10=22`；改 C 后末位 A 给其 `3+36/4+10=22`。故在合法历史 hA，规定第二人 A、末位按表执行，是完整的两人子 SPE。

对 h 后另外两个首行动孩子各任取完整 SPE，再在 h 选最佳行动；对 h 的其他祖先及旁枝同样逆向填满。这得到原39人博弈的一份完整历史纯 SPE，包含上述 hA 子策略。**不声称 h 或 hA 是它的实际根路径。** 反驳完整策略提升只需要这些合法历史也必须满足 SPE。

## 2. 精确非负单位客户 clone 游戏

每个原主题建3个 clone。对背景零客户，令它喜欢其全部相关 clone。对某个背景一的 A、C 客户 x，其相关 clone 恰为

\[
 A_0,A_1,A_2,C_0,C_1,C_2,(P_x)_0,(P_x)_1,(P_x)_2.
\]

对这9个标签的每个非空子集 R，放置

\[
\frac{2520}{10\binom9{|R|}}
\tag{1}
\]

名不同单位客户。按 |R|=0,...,9，式(1)的整数值分别为
`252,28,7,3,2,2,3,7,28,252`；空 R 无法被覆盖，删去。其余背景零客户一律复制2520次。由此构造完全由有限单位客户组成的标准空背景 CAG，尚有3位玩家。

除去统一因子2520，(1)就是 P~Uniform[0,1] 后，各相关 clone 条件独立 Bernoulli(P) 的有限兴趣型质量。所选 regular 标签的边际联合律不依赖是否同时存在 singleton clone。

每个 singleton clone 的总质量（未乘2520口径）为1/2；任一 C clone 单从13个背景零客户仍保证至少13/3。因此 singleton clone 在全部历史上也严格不可能是末位最佳回复，且不会影响下面的真实偏离比较。

三个 B clone 覆盖恰相同，可合并为同一合法主题。A、C 及 singleton clone 的相关兴趣型确保所用 A_0、A_1 和各 C clone 覆盖不同；下文局部合同和利润在合并 B 副本后完全不变。计数口径仍把合并的 B 主题写作 B_0，避免把标签副本当额外合法集合。

## 3. 必须保留的 fresh 合同

考虑合法 clone 历史 `(A_0)`。保留上面原完整 SPE 的 fresh 原主题选择，要求当前选任一未用 A clone（由对称性写 A_1），其后真实末位选择 B_0。这条 fresh 叶的当前利润恰为24（以下所有表都除去2520公共因子）。

这两步本身在末位合法：在 `(A_0,A_1)`，末位 fresh B 或 C 都得22，fresh A 得21；复用 A_0 或 A_1 各得19。故可以按原策略选 B_0。

## 4. 重复孩子的所有完整 SPE 均给出严格盈利偏离

现在当前玩家在 `(A_0)` 处改为重复 A_0。末位观察到 `(A_0,A_0)` 后，其全部 regular 选择利润以及当前重复者的最终利润如下：

| 末位行动 | 末位利润 | 当前重复者利润 |
|---|---:|---:|
| fresh A clone | 22 | 19 |
| fresh B clone | 22 | 21 |
| fresh C clone | 23 | 25 |
| 重复 A_0 | 18 | 18 |

所有 singleton clone 利润至多1/2。所以末位的每个最佳回复都必为某个 fresh C clone；不需要假定特定平局规则，重复孩子没有可用于威慑当前人的另一个 SPE。

关键的背景一客户积分只有两项。令 I、J 条件于 P=p 独立 Bernoulli(p)，则一个 A_0 重复者对 A、C 型客户的份额为

\[
\mathbb E\frac{I}{2I+J}
=\int_0^1\left[\frac{p(1-p)}2+\frac{p^2}3\right]dp
=\frac7{36},
\]

fresh C 对该客户的份额为

\[
\mathbb E\frac{J}{2I+J}
=\int_0^1\left[p(1-p)+\frac{p^2}3\right]dp
=\frac5{18}.
\]

故末位 C 得 `36*(5/18)+3+10=23`，当前重复者得 `36/2+36*(7/36)=25`。fresh A 末位得 `36/3+36*(5/18)=22`；fresh B 得 `36/3+10=22`；重复 A_0 末位得 `36/3+36*(1/6)=18`。表中其余当前值按同样份额直接得到。

因此任意试图补全重复孩子的完整策略都会使当前获得25，严格超过所要求 fresh 叶的24。统一乘2520后仍严格。**不存在原 clone 游戏的完整纯 SPE 同时满足这个 fresh 局部合同。** 给定原完整 SPE 在所有 fresh 历史逐项提升当然包含此合同，所以那种固定策略提升不成立。

## 5. 精确后果与停止点

该见证支付了“末位复用 clone 静态不优”无法跨越的真实缺口：复用早期 clone 改变末位对 fresh A/B/C 的利润，其中 fresh C 从22升为23，原来可用的 B 平局威胁消失，重复者反而从所规定的24升至25。

这不排除在 clone 游戏内重选原 fresh 子策略，也不排除只要求原实际终局的某个 fresh 实现；本稿未证明原 hA 在根实际路径。更没有从这个辅助接口失败推出背景半利润或原 Q-CAG-HALF 失败。对此固定策略提升候选已得到严格分离，停止扩大同类扫描。

发现脚本 `attack_beta_clone_local_lift.py` 仅用于提出精确类型，本文证明由上述全比较表和确定单位客户构造承担。先前 `probe_beta_clone_lift.py` 及几个有限输出只属于探索，不作为普遍正面证据。
