# 保留精确税的实际分数负载候选：本轮有限攻击

主目标Q-CAG-HALF仍OPEN。沿用旧Boss9的候选：令实际终局负载为c，α=(m−1)/m，g(T)=Σ_(x∈T)1/(1+αc_x)，M=max_Tg(T)，G_C=Σ_(c_x>0)1/(1+αc_x)，尝试证明 mM≤W+G_C。与一般逐客户代数 OPT_m≤mM+W−G_C 合用即足以half；两个式子的地位不同，前者仍未证。

本轮复用旧完整策略锥探针，参数m=5、p=7、rounds=8、seed=91527。每轮从合法整数客户实例的精确全集逆向归纳中抽一个完整SPE，随后在它的全部真实有序历史约束及非负客户类型锥内，对每个查询主题作浮点LP攻击。结果文件[m5p7_probe.json](m5p7_probe.json)保存参数、原程序路径和SHA-256；56个查询未发现正浮点目标。此结果既不是一般证明，也不是这些锥上的精确对偶上界。

复现命令从仓库根调用所记录的旧程序，使用 --players 5 --topics 7 --rounds 8 --seed 91527 --output <尚不存在的输出路径>。程序拒绝覆盖输出；只接受完整有序策略，正候选须另做Fraction恢复和定义级核验。没有发现正候选，所以本轮没有发布新的合法实例。

停止延长同样随机样本：这些有限运行的信息收益不足以承担一般结论。下一步优先解析跨主题客户耦合或构造可审查的真实续局。旧粗桥W≥(m−1/2)M的反例不能直接否定此精确税候选。
