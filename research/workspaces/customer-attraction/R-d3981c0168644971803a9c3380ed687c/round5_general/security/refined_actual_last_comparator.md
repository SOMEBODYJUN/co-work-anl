# 实际末菜单的精确税比较与较弱付款义务

2026-10-24，round5/security。**一般推导；root与capacity已独立按逐客户代数核对，尚无外审或新颖性认证。** 对全部任意人数、有限共同目录、每份完整有序历史纯SPE成立。它没有证明新福利下界；新增接点是把旧静态覆盖/税代数接到末节点一槽混合菜单，使所需付款弱于`mL≤W`。

## 1. 对象与来源去重

实际完整SPE终局为`z=(S_1,…,S_m)`，福利`W`，末位利润`u=u_m`。只计实际前m−1人的客户负载`b_x`；令`a_x=1_(x∈S_m)`。定义

    f_b(T)=Σ_(x∈T)1/(b_x+1),
    h_x=1/[(b_x+1)(b_x+2)],
    H_b(T,A)=Σ_(x∈T∩A)h_x,
    K_b(T,A)=f_b(T)−H_b(T,A)
            =Σ_(x∈T)1/[b_x+1+1_(x∈A)],
    L=min_(Q∈ΔS) max_T E_Q K_b(T,A)=v_2(b).

b是真实实际末节点前缀，不能换成任意背景后仍把剩余利润称作根覆盖W。

目录有限，最优列分布Q存在。末位真实BR只给`f_b(T)≤u`，并没有给`u≤W/m`或`mL≤W`。

静态覆盖的逐客户不等式来自 [oblivious security](../../../../../current/customer_attraction/oblivious_security.md) §2；实际前缀税及只用末位BR的旧界`OPT_m≤m u+τ(b)`见 [two_remaining_tax](../../../../../current/customer_attraction/two_remaining_tax.md) §6。当前LAST对象及强付款候选见 [seq245主稿](../../../R-ab2c6df20538474c948f5f24e59437ee/GENERAL_PROOF_WORKING.md)。旧实际均匀缩放分数背景的精确税式`OPT≤mM+W−G_C`使用另一背景；本页没有重试其已失败的付款。

本页不把上述静态代数、LAST定义或有限minimax认领为新机制。实际读取的三个来源中未见下述`−u/2`末位信用及相应弱化LAST付款的明确组合；它是旧代数的一个可直接复核推论，不是独立的half证明。

## 2. 任意列分布的精确税接口

固定任意分布Q，令

    M_Q=max_T E_Q K_b(T,A),
    t_b(A)=Σ_(x∈A)h_x,
    τ(b)=Σ_x b_x/(b_x+1).

取任意m个比较主题`T_1,…,T_m`，其覆盖次数为d_x。对每个固定A，令`n_x=b_x+1_(x∈A)`。逐客户有

    1_(d_x>0) ≤ (d_x+n_x)/(1+n_x).

对客户及A∼Q求和得到

    |∪T_j| ≤ Σ_j E_Q K_b(T_j,A)
              +E_Q Σ_x n_x/(1+n_x)
            ≤m M_Q+τ(b)+E_Q t_b(A).            (1)

最后等号用精确增量

    (b+1)/(b+2)−b/(b+1)=1/[(b+1)(b+2)].

查询T_j与Q独立。每个列背景b+A是m个共同目录主题的合法整数负载，未使用Jensen替换，未冻结任何早期玩家偏离后的真实后继；这里只是在实际末节点作静态比较。

## 3. 末位BR与实际覆盖共同支付部分税

由于`1/(b+2)≤1/2`，逐客户有

    t_b(A)≤f_b(A)/2≤u/2.                       (2)

第二步只用实际末节点的真实BR。

记末位新覆盖客户数`n_new=|S_m\∪_(i<m)S_i|`，则

    W−τ(b)=n_new+Σ_(x:b_x>0)1/(b_x+1)≥u.      (3)

因为u恰为n_new加上S_m覆盖的旧客户那部分。于是(2)—(3)给

    τ(b)+E_Q t_b(A)≤W−u/2.                    (4)

对达到L的Q使用(1)，得到全部原输入有效的比较关系

    OPT_m≤mL+τ(b)+E_Q t_b(A)
         ≤mL+W−u_m/2.                         (RLC)

零客户、空主题、重复行动和m=1均无需除以W，所有分母严格正；论证完全保留这些边界。

可保留更多非负余量。设

    D_old=Σ_(x:b_x>0,x∉S_m)1/(b_x+1),
    e_Q=u−E_Q f_b(A)≥0,
    B_Q=E_Q Σ_(x∈A) b_x/[(b_x+1)(b_x+2)]≥0.

则直接有精确式

    τ(b)+E_Qt_b(A)
      =W−u/2−D_old−e_Q/2−B_Q/2.              (5)

这只细化(4)中的已识别信用，不产生早期玩家的新付款。

## 4. 已被后续反例否定的弱付款及m=5压力测试

原LAST候选`mL≤W`比half所需更强。由(RLC)，新的充分义务可以放宽为

若证明(WLAST?)对全部原根SPE成立，即有`OPT_m≤2W`。后续 [P填充23客户核](last_menu_retained_tax_failure.md) 已在完整原根SPE上严格反驳(WLAST?)，并反驳对全部Q保留精确税信用的充分助手。(RLC)的静态比较保持正确，不能将助手反例扩大成half反例。

    OPT_5≤5L+W−u_5/2;
    若5L≤W+u_5/2，则OPT_5≤2W.

若原较强LAST成立，则进一步有`OPT_5≤2W−u_5/2`。以上关于W的闭合均是**条件**结论，不能称为无条件五人half结果；没有进行五人专项扫描或调系数。

## 5. 直接证明曾停在哪里，及为什么停止

有限minimax给

    L=max_p[f_b(p)−max_A H_b(p,A)].

因此此前尝试对一个真正最优p证明

    m f_b(p)≤W+u_m/2+m max_A H_b(p,A).          (6?)

完整SPE的早期合法偏离使用真实后继；第i位强制T后的竞争主题可以是`B_i(T)`，依赖T。任何把

    E_(T∼p) H_b(T,A(T))

换成`max_A H_b(p,A)`的步骤都存在量词错误。最后两个实际玩家各获得至少L可以从已有末两人保底及背景单调性推出，但它尚未支付前m−2位的总缺口。后续完整SPE反例已说明这条一般付款本身为假，不能继续把它当待证引理。

针对强LAST和根逐人LAST，在一份已有完整六主题形式策略上各做一次有明确查询来源的定点锥LP，均未发现反例。这些是阴性诊断，既无精确全锥对偶，也不支持一般真值；随后另一已有真实核的解析P填充反驳了目标助手。不会继续扩大固定策略、人数或p网格。
