## 1. 固定同一份完整策略，强制者不能冒充优化者

把所有局部路径补成完整五角色顺序，使用全局零起始角色索引。下面“首个真正优化索引”之前的指定行动只通过源节点的真实偏离比较付款。

| 局部族 | 完整路径及首个真正优化索引 |
|---|---|
| DEEP | `TABCD`:1；`TQHIJ`:2；`TAQEF`:3；`TABQG`:4 |
| BG2 | `ATBCD`:2；`ATQEF`:3；`ATBQG`:4 |
| BG3 | `ABTCD`:3；`ABTQE`:4；`ABTDF`:4 |
| PC2 | `ATEFG`:2；`ATQHI`:3；`ATEQJ`:4 |
| PC3 | `ABTEF`:3；`ABTQG`:4；`ABTFH`:4 |
| MAXROOT | `TABCD`:1；`TDQRS`:2；`TADXY`:3 |
| 可选 MAX-BG2 | `ATBCD`:2；`ATDEF`:3 |

逐个读取当前正乘子键后，所有实际使用的 IC 都在相应门槛之后。TRUE 行是在原源节点比较强制子枝相同角色的最终收益；它不要求子枝强制者自己最优。ROOT/FORCED 行只比较原实际根或第二位与其真实强制分支。

特别是 MAXROOT 第一条复制分支的第二位 D、第二条复制分支的第三位 D，以及 DEEP/BG/PC 的强制 Q/F，都未被当成其强制节点上的优化者。当前 PC2 输入没有 TAX 键，见第7节。

每条路径由同一原 sigma 在所写有序历史给出。如果不同字母实际相同，导致有序历史相同，原 sigma 自然给一致回复。把局部会员位当成独立二进制位是扩大系数域，不是假设策略可独立指定不一致回复。没有把同计数、不同顺序的历史合并，也没有要求匿名或有利平局。

## 2. IC 分母和 raw/bound 符号

全局零起始角色 i 在某条路径上的过去负载为 b 时，其合法安全查询是

    sum_H 1/(b+5-i) <= 该节点规定终局中的该角色收益。

原因是强制 H 后最多还有 5-i 个包括当前角色的行动者；全部未来仍沿原 sigma 改变。末位 i=4 是精确目录最佳回复。原核验器使用的局部索引在各族均正确补入固定前缀和剩余人数。

DEEP/BG/PC 多数 raw 不是非负 slack，而是 `a-bound`：

- CAP 的 raw 为主题会员位，外部 bound 为共同 K；
- IC 的 raw 为安全查询减当前真节点收益，bound 为0；
- TRUE 的 raw 为强制子枝当前角色收益减源真节点该角色收益，bound 为0；
- ACTUAL 的 raw 为在原实际节点对合法主题的安全查询，bound 为对应实际 ui。

因此 BG/PC 的局部证书正是

    source_ui + beta K + sum alpha_i ui - sum gamma
      =(source_ui-v_T)+sum lambda(bound-raw)+sum rho,
    rho=v_T+sum lambda raw-gamma >=0.

DEEP 则将 ROOT raw=v_T 的非负乘子 alpha 直接对应为 alpha(u1-v_T)。各族 CAP 乘子和、ROOT/FORCED 源列和 ACTUAL 的五个外部 ui 列均逐一重新核对。没有把负向 raw 当成非负 slack，也没有多发一次源收益。

## 3. 实际末位价格和投影源列

PC 的隐藏回复 H 只作为一个合法原目录主题进入原实际末位的查询：

    sum_H 1/(1+1_A+1_B+1_C+1_D) <= u5。

这与离轨末位的实际收益无关；该收益没有被替换成 u5。当前非零 ACTUAL 价格确为第五位价格。PC2 的 `u_coefs` 仅存附加价格系数，仍需一次源 u2；PC3 的 `u_coefficients` 已含源 u3=1，不能再加一次源 u3。独立程序按完整路径收益与外部价格分开重建，逐列匹配。

BG2 的可见位顺序是 ATQ；BG3 是 ABTQ；PC2/PC3 是实际 ABCD 加 TQ。隐藏回复逐客户消元给对所有隐藏位均成立的 rho>=0，故可以按真实客户重数求和；不需要每个客户能独立选择一份真实策略。这也解释了将局部主题对替换为固定主题、最优索引或同索引真实菜单主题时，左侧仍是同一组原实际 ui 与同一个 K。五次代入只把这些共同外部预算乘五，没有改称五个互斥枝利润为实际福利。

## 4. 末两人关系及 MAXROOT

对真实末两人 C,D、固定过去负载 b，令 f(X)=sum_X1/(b+1)，g(X,Y)=sum_(X cap Y)1/[(b+1)(b+2)]。首位强制 T 后同一 sigma 的真实末回为 Q。三条真 IC 的和为

    u_C+u_D-f(T)-f(S)+g(T,S)+g(C,Q) >=0。

再用 g(C,C)>=g(C,Q)，得到强式

    H=u_C+u_D+g(C,C) >= f(T)+f(S)-g(T,S)。

LOCAL/MAXROOT 的两人总利润版本再减去一个非负 g(T,S)，因此合法。当前局部 TAX 行只用于首位也是真优化者的末两人子局。

MAXROOT 的三条路径上，各自末两人和末位利润分别保留。五个比较索引的十个对中，每个被并集覆盖的客户固定一个覆盖索引，含它的四对各贡献至少 1/(b+1)；故 `(5/2)H+sum b/(b+1)-O>=0`。末位五次查询给 `5u_last+sum c/(c+1)-O>=0`。重复比较索引不被去重，空主题不破坏该论证。

同一裸大小最大主题 T 满足 |T|=K。两条 MAXROOT 界均 B>0，才能用原根 IC 将 B v_T 替换为 B u1。22个非负乘子中，六个含 O 行的乘子和精确为1。独立程序重新核对1024个十位主题状态及 O 位0/1的消去；两条界各重建56个零余项类型。没有把强制根当成该枝优化者，也没有用它的其他子枝旧角色利润套原根收益上界。

可选 MAX-BG2 同样重新核对；它在实际第一主题 A 后强制裸最大 T，第三位复制该枝末主题 D。B 等于 FORCED 乘子，K 列等于 gammaT 加 CAP 总乘子，|A|列等于 gammaA。删除未活跃回复位不影响系数，768态覆盖实际使用的全部状态。该族是否为最终主恒等式依赖仍由主证书的活跃行决定。

## 5. 向外取整和冻结索引

使用 M=10^6 时，ui、K 和类型客户数都非负。左侧收益/K系数 ceil，右侧每个 gamma floor，使左减右增加，故合法。gamma 为负时同样成立。DEEP 的 gamma|T| 和 zeta|T cap Q| 在右侧预算，必须 ceil，即使两者为负也不改变方向。MAXROOT 负的 K 系数同样 ceil，变得较不负，所以行左侧增大。

我独立重建并与冻结 manifest 完全比对：BG 九项、PC 八项、DEEP 三项，以及 MAXROOT 的 `(46313177,-7412362)`。BG2 索引严格为 `[0,1,3,5,11,12]`，后接 BG3 `[0,1,2]`；PC 为五个 PC2 后接三个 PC3。PC2 源 u2 只加一次，PC3 不再增源系数。全部六个 manifest 来源哈希匹配。没有用浮点比较或依元数据重新排序。

## 6. 本轮独立实现和结果

`audit_imported_half5_local_independent.py` 只读证明包 JSON，未导入包内 Python 或其他仓库模块。它以完整五角色路径重写局部份额、合法节点门槛、TRUE 切换、税、CAP、ACTUAL 价格和 MAXROOT 行，精确使用 Python Fraction，并另重建冻结取整表。全部36组件、47,872系数态通过，报告为 `audit_imported_half5_local_independent.json`，输入哈希一并记录。输出都保留在本席工作区，没有更改冻结证明包。

这是一份新的独立局部实现；它不是第二份全主域整数恒等式验证器。53条主行的组合、共享 K 列和全主域闭合由其他审查席分别验证，本报告不冒称完成该部分。
