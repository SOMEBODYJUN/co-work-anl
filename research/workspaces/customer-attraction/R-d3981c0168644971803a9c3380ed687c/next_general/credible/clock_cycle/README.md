# 共享遗漏与 clock 银行：未闭合构造记录

2026-10-24。Q-CAG-HALF 一般研究的构造分支备份；没有新定理、完整反例或有限计算结论。未调用优化器、枚举器或参数扫描。只讨论原模型的共同目录、单位客户及完整有序历史纯 SPE。

## 当前机制与必须闭合的义务

目标是实际先后使用多个银行主题 A_i，再使用大银行 B；希望早期实际收益低于末段 B 玩家收益，从而让最优主题同时覆盖实际银行和大量共享遗漏。旧常数三 root-only 编译器与全局私有遗漏预算均已复用为限制，没有重算或声称超越它们。

单个“复制未来较大 A_j 并附新奖励”的处罚动作不能自行闭合：原玩家可以直接选择那个扩张动作；复制它又要覆盖更多客户并获得新的补偿。有限闭合必须明确给全部目录动作和全部离轨历史可信续局，不能把无限奖励梯子或任意背景局部 SPE 当作根构造。

## 银行覆盖与处罚的量纲

设实际 B 尾部 n 人分银行大小 K，基准收益 R=K/n。一处罚主题原路径覆盖 rho 比例 B，末位查询得到约 rho R，因而可附的原遗漏总量至多约 (1-rho)R。若处罚者全都只覆盖同一 rho B，剩余 (1-rho)B 是整主题 B 的额外吸引力；复制目标遗漏造成的收益损失无法免费由该同一份遗漏奖励支付。

若每个处罚者还取其他实际银行客户来补偿，原末位查询价格也会增加。实际负载高的银行客户价格较低，故唯一尚未排除的机制是：利用前缀内生形成的高负载银行承担少量目标复制，处罚者从其他银行客户或共享遗漏取得补偿。这与合法背景 PB 中的 flat 机制有关，但背景若覆盖全部宇宙则根福利已最优，不能直接移植。

## 可接续但尚未实现的接口

一种具体、未证的候选构造方向是：

1. 用 balanced regular 行动的根路径内生填充银行背景；必须逐完整历史证明每个填充玩家最优，不能只指定原路径。
2. 给未用的 regular 超主题附大量近私有的新 petals，再用少量共享 petals 承担处罚切换所需的微小亏损；实际 prescribed 子主题不包含这些 petals。
3. 精确计算所有新增 petals 对全部原 IC 的影响，尤其直接偏离处罚超主题和后段末位查询。原私有遗漏定理保证仅私有 petals 不会越二，故共享部分必须承重。
4. 最后直接验证 OPT-2W>0；若仅得到正深度 SPE 的 root-only 计划，则必须另算真实根 regret Delta，并满足 OPT-2W>3Delta 才能用既有编译器。

目前上述任何一步都未完成；它只是下一次构造应检验的明确机制。没有把 PB 的合法全覆盖背景、有限策略片段或渐近近似称为根反例。若继续，优先写出一个有限目录和完整策略，再做标量精算；不要扩大无机制扫描。
