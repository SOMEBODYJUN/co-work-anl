# 严格低于 theta 的静态拥挤缺口：二元关联真实菜单的必要条件

2026-10-23。后续个人推导，解析命题，已获 ../parent/static_crowding_review.md root独立内部重构；无外审或新颖性认证。Q-CAG-HALF 仍 OPEN。这里没有证明一般 degree≤2 theta 定理，也不宣称对任意非均匀扰动完整策略保持不变。

## 1. 任意背景与真实根菜单

共同目录的不同极大主题为 A_1,...,A_k，客户关联不受限制，内部子主题任意。第3节先给一般关联的静态槽覆盖接口，再写出度≤2的顶点多重覆盖形式。固定一个合法有序背景，客户旧负载 b_x，尚余 r=q+1 人。固定一份完整历史纯 SPE，当前实际收益 u。

对于根强制选 A_i 后沿原策略产生的真实分支，记 q 个真实后继对客户 x 的负载为 K_i(x)，根收益为

`d_i=sum_(x in A_i) 1/(b_x+1+K_i(x)) <= u`。

这里所有分支来自同一完整策略。令 theta_r(b) 为 q 个静态竞争主题后最佳查询的最小值（原定义）。固定静态主题计数 p，sum p_i=q，令客户静态负载 c_p(x)=sum_(i:x in A_i)p_i，则

`F_i(p)=sum_(x in A_i)1/(b_x+1+c_p(x))`。

固定背景与竞争前缀时，任何子主题查询被包含它的极大主题查询支配，所以静态查询最大值确为 max_i F_i(p)。

## 2. 一般精确静态缺口行

对每个 i 有定义级恒等式

`F_i(p)-d_i = sum_(x in A_i) [K_i(x)-c_p(x)]/[(b_x+1+c_p(x))(b_x+1+K_i(x))] =: Gamma_i(p)`。

因此

`theta_r(b) <= max_i F_i(p) <= u+max_i Gamma_i(p)`。             (1)

也可把每个 Gamma_i 用只保留正部的 E_i 上界：

`theta_r(b)-u <= max_i E_i(p)`，

`E_i(p)=sum_(x in A_i) (K_i(x)-c_p(x))_+/[(b_x+1+c_p(x))(b_x+1+K_i(x))]`。 (2)

式(1)只是静态查询、根真实偏离及负载恒等式的合法组合，不认领这项直接恒等式的新颖性。它的用途是保留**根严格低于 theta**的信息，而不是像根—尾驻留支付那样只保留根低于后继。

若 u<theta，则对每个 q 动作静态前缀 p 必有某个根 i 满足 Gamma_i(p)>0。特别地，如果存在 p 使每个 A_i 上的逐客户静态负载 c_p(x)≥K_i(x)，则 theta≤u，严格低阈值不可能。

## 3. 一般关联的整数槽覆盖，以及 degree≤2 的顶点形式

令 I_x={i:x in A_i}，对可覆盖客户定义

`h_x=max_(i in I_x) K_i(x)`。

如果存在非负整数静态主题槽数 p_i 满足

`sum p_i <= q, sum_(i in I_x) p_i >= h_x` 对每个客户 x，      (3-general)

则不足 q 的动作可以任意补齐。其静态负载同时支配每个根分支在自身主题上的真实尾负载，因此

`theta_r(b) <= max_i F_i(p) <= max_i d_i <= u`。

**一般静态槽覆盖排除引理：** (3-general) 是任意客户关联、任意非均匀客户重数、任意合法背景以及任意内部子主题下的充分条件。它不要求尾收益高于根，也不声称所有真实菜单必满足该整数覆盖条件。严格 u<theta 的最小反例必须使这个整数槽覆盖成本大于 q。不可覆盖客户 I_x 为空，可删除或将 h_x=0，不影响任何式子。

以下才专门假设每个客户的 |I_x|≤2。对私有块 P_i=A_i\union_(j!=i)A_j，定义

`h_i=max({0} union {K_i(x):x in P_i})`。

对二元客户块 P_ij（恰属 i,j），定义

`h_ij=max({0} union {K_i(x),K_j(x):x in P_ij})`。

若存在非负整数主题数 p_i 满足

`sum p_i <= q, p_i>=h_i, p_i+p_j>=h_ij`，                    (3)

把不足 q 的动作任意补齐即可逐客户满足 c_p≥K_i。故

**度二静态多重覆盖排除引理：** 条件(3)是一般条件(3-general)在度≤2客户上的等价写法。条件(3)成立时，任何具有这些真实根分支的完整 SPE 当前根收益 u≥theta_r(b)。这个结论允许任意非均匀单位客户重数、合法背景、内部子主题及历史平局。

等价地，严格 u<theta 的最小反例必须有整数顶点多重覆盖成本大于 q。这只是必要条件，不是已经证明的普遍菜单性质。

在最小 r 的 theta 反例中，所有真实后继收益≥theta>u≥d_i，因此任何后继动作不能包含于 A_i。此时私有客户 K_i=0，故 h_i=0；若给每个后继任选一个包含它的极大主题作归属，均不能归属 i。对于完整极大主题后继，h_ij=max(n_(ji),n_(ij))；对于内部子主题，实际 h_ij 可以更小。该归约不把非真实菜单当 SPE。

## 4. 负通量族的非均匀稳健排除

将 k=2q 个极大主题分为 X,Y 各 q 个。假设每个根 i 的 q 个真实后继能够一一归属给相反组的 q 个极大主题，每个后继覆盖包含于其归属极大主题。**无需后继恰选完整极大主题，也无需客户重数对称。**

则私有块 h_i=0；同组边 h_ij=0；跨组边 h_ij≤1。取静态前缀为 X 的全部 q 个极大主题各一次，条件(3)成立。因此 u≥theta_r(b)。

这直接回答负通量族的非均匀扰动问题中可证明的部分：只要真实根菜单保留“相反组的一一归属”形态，任意大小的非均匀边权扰动及背景都不能造成根严格低于 theta；并非只证明小扰动或更多对称参数。

完整主题后继时，还可以明确写出静态 slack。记 D_i 为根 i、相反组各一次的根收益。若 i∈X，定义

`s_i= sum_(私有x in A_i)[1/(b_x+1)-1/(b_x+2)]`

`    +sum_(同组二元x in A_i)[1/(b_x+1)-1/(b_x+3)] >=0`。

静态前缀 X 下，查询 i∈X 得 D_i−s_i，查询 i∈Y 恰得 D_i。因此

`theta <= min{ max(max_(i in X)(D_i-s_i),max_(i in Y)D_i),`

`              max(max_(i in Y)(D_i-s_i),max_(i in X)D_i) } <= max_i D_i <=u`。 (4)

对于内部子主题后继，实际 d_i≥D_i，同一结论仍成立。式(4)保留了对称负通量族驻留支付丢掉的静态信用。

零背景、没有私有客户时 D_i=跨组加权度_i/2+同组加权度_i，s_i=2同组加权度_i/3。若某根 i 独占最大 D_i，领先其余根至少 gamma>0，且同组加权度 w_i>0，则选择其所在组作静态前缀得到

`u-theta >= min(gamma,2 w_i/3)`。

在原对称族，两个组都有最大根，因此这个严格 slack 可以恰为零；根恰 theta 与负真实通量完全相容。

这里没有证明扰动后的原完整策略仍是 SPE：原族有大量真实平局，改变一条边就可能移除部分原菜单。菜单形态的稳定性与上述条件性根保底必须分开。

## 5. 为什么整数覆盖条件本身还不能闭合一般情况

**有完整 SPE 的反例，不能普遍要求(3)。** 取五主题完全图 K_5，每条边一个单位客户，r=3、q=2。根选 0；首动作 i 后第二人选 i+1（模5）。在真实前缀 (i,i+1) 后末位选 i−1；其余两项不同时末位任意选尚未出现的主题；两项相同时末位任意选其他主题。

每个三不同终局的每名玩家收益为 3。两不同末位前缀的 fresh 回复收益 3，重复回复 11/6；重复前缀的 fresh 回复收益 10/3，重复回复 4/3。因此末位规定最优；第二人 fresh 得3，重复得11/6；根所有动作得3。这是全部有序历史纯 SPE。

每根分支的两名后继正是其循环邻居，故需求 h_ij=1 的图是五边形 C_5。用两个整数顶点动作不能覆盖五条边，整数覆盖成本为3>q。但 theta_3=3=u：两个不同静态竞争主题的最大查询为3，两个重复静态主题的最大查询为10/3。

所以“所有真实菜单的拥挤覆盖成本≤q”已经被这个真正完整 SPE 否定。该条件只能作为**严格低阈值反例的必要门槛**。一般突破还须利用跨客户带符号的 Gamma 行（完整图中正负项相消），或者真正的较早/较晚响应关系，不能把多重覆盖排除引理冒充一般证明。

另一个有区别的障碍是纯 C_5 客户图上的同一循环菜单：它的静态成本同样3>2，形式上给根1、两尾各3/2且 theta=3/2，但末位在根i、第二人i+1后可以选距离二且不接触二者的主题，得2>3/2，因此这个菜单不是 SPE。前者说明覆盖成本条件太强，后者说明真实最优性仍有额外限制；二者不能混为同一个反例。

## 6. 当前准确结论与下一缺口

新增可用陈述是(1)—(4)、一般关联条件(3-general)，以及其任意非均匀背景版。它排除了真实负flux族及保留相反组一一归属的所有扰动菜单作为 theta 最小反例；无需正驻留余项。一般 degree≤2 的全员 theta 猜想仍未证明，本轮不继续扩样。

一般严格低阈值菜单必须同时满足：

1. 每份 q 动作静态前缀都在某个根上留下正 Gamma；
2. 整数拥挤多重覆盖成本>q；
3. 所有真实后继最优性，而不只是尾收益高于根。

现在没有证明这些条件互不相容，也没有合法实例同时实现 u<theta。缺失的是能够跨客户支付这些正 Gamma 的一般关系；仅修复逐客户覆盖或只要求菜单真实都已不够。
