# 共同后继价格的有限字典种子 LP：精确线性化与真实实现

2026-10-25。父方一般推导；convex 已据包含公式/提示的精确合同独立重构、再全文对照通过，不称无提示盲审。见 [独立审查](../convex/pooled_dictionary_lp_independent_review.md)。原 Q-CAG-HALF 仍 OPEN。本文不提供严格负种子或一般福利界；给的是把本轮真实共同后继帽用于有限组件字典的精确优化方法。它不把不可实现的 LP 点当作原游戏。基础产品拼合、signed 银行编译和 LP 理论均为既有工具，不认领其首次发现。

## 1. 输入必须先是真实组件

固定任意 m≥2 与非空有限组件字典 t=1,...,T。每个组件符合原单位客户共同目录模型，给一条末位 BR 的目标路径、收益 u_i^t、福利 W_t 和最优覆盖 O_t；记 B_t=2W_t−O_t。不同组件的客户宇宙可取不交副本。

在每个正常位置 i<m，输入 [共同后继帽](../signed/pooled_successor_transfer.md) 的真实菜单：强制 A 后，下一角色的门槛 theta_t(A)，以及下一动作 B 与真正完整 grandchild SPE 的叶对 (d,v)。这些输入不能用任意数表或仅有限必要条件点代替。定义

    H_it(tau)=max_A min_z [d_z−tau(v_z−theta_t(A))]，tau≥0。

对任意非负有理组件权重 w，定义

    Psi_i(w)=sup_(tau≥0) Σ_t w_t H_it(tau)。

权重暂为复制比例，不是非单位客户。清分母后都是整数个单位客户组件。作者已构造真实全历史退出，使整数复制数 n 下每个强制 joint 动作的当前利润≤Psi_i(n)+D_i；D_i 是最大单组件当前利润范围，与复制数不成比例。

## 2. 价格无限区间可以精确变成有限约束

每个 H_it 是有限有理仿射函数先取 min、再取 max 得到的连续分段线性函数；每段属于某一原菜单直线。取这些直线所有非负有理交点及0，形成有限价格集合 P_i。可去掉冗余点，但不需要最小化它。

每个 H_it 有有限上界：它不大于逐组件凸化后的真实有限帽。故其最后一段斜率≤0。非负权重下 Σw_t H_it 的最后斜率也≤0，其他区间均为直线，最大值必在 P_i 达到（常值尾取其起点即可）。于是同时对**全部**w≥0精确有

    Psi_i(w)=max_(tau∈P_i) Σ_t w_t H_it(tau)。        (GRID)

价格集合只依赖菜单，不依赖随后求出的 w；因此没有把连续搜索误当有限阴性。

## 3. signed 费用的精确 epigraph

令 d=m−1，任取 g∈R^d，P=Σg_i+、N=Σ(−g_i)+、p=max_i g_i+、v=max_i(−g_i)+。既有双侧修复成本满足

    C(g)=2P−N+p+v
        =Σ_i g_i+Σ_i(g_i)+ +max_i(g_i)+ +max_i(−g_i)+。  (C)

后一式因为 P−N=Σg_i。C 是凸、正齐次、逐坐标非减的函数；逐坐标单调也可由其非负价格支撑函数证明。直接地，某坐标增加δ≥0时，Σg增加δ，正部项不减，而max(−g)+至多减少δ，故净变化非负。

约束 h_i≥g_i、h_i≥0，p≥g_i、p≥0，v≥−g_i、v≥0 后，固定 g 的最小 Σ(g_i+h_i)+p+v 恰为 C(g)，没有带负系数的伪正部松弛。

## 4. 有限字典的精确 LP

用 Σ_t w_t=1、w_t≥0 归一。变量为 w_t、psi_i、g_i、h_i、p、v：

    psi_i ≥ Σ_t w_t H_it(tau)   对每个 tau∈P_i；
    g_i = psi_i−Σ_t w_t u_i^t；
    h_i≥g_i，h_i≥0； p≥g_i，p≥0； v≥−g_i，v≥0。

目标最小化

    Σ_t w_t B_t +Σ_i(g_i+h_i)+p+v。                 (LP)

由(GRID)、(C)与 C 的逐坐标单调性，LP 值**精确等于**

    min_(w≥0,Σw=1) [B(w)+C(Psi(w)−u(w))]。          (VALUE)

特别，不能通过人为抬高 psi 制造更负的 C；最优时总可令 psi=Psi(w)。右侧是紧单纯形上的连续分段线性函数，最小值达到；有限有理 LP 可取有理最优解。

## 5. 负点何时才是真正反例，非负值能说明什么

若 LP 有严格负的真实有理可行点，即可取其 w，按精确网格重算预算（不会更高），不必额外证明全局最优；反之非负排除须有精确最优认证。取对应有理 w，清分母得整数 k。正齐次给

    epsilon=−B(k)−C(Psi(k)−u(k))>0。

把这些组件再复制 q 次。共同后继帽提供每个 i、每个合法 joint 强制（含 own）的真正完整退出表，上界 U_i=q Psi_i(k)+D_i。由 C 的次可加与齐次，真实缺陷上界的预算满足

    q B(k)+C(q[Psi(k)−u(k)]+D)
       ≤−q epsilon+C(D)。

取正整数 q>C(D)/epsilon，右侧严格负。再用既有 signed marked/LOW 层修复及清分母，便得到原模型的有限单位客户、共同有限目录和**全部历史纯 SPE**的真 half 反例。产品 OPT 与 W 的可加、全部退出可信性及银行编译都是必要依赖，不能漏掉。

当前**没有**这种负点。即使某份有限字典的 LP 由精确对偶认证为非负，也仅排除该字典、所用真实菜单及这一共同一层后继帽的充分攻击；实际产品 M 还可能更低，别的组件不在字典，原 half 更没有因此被证明。浮点 solver 输出也需有理重建和真实菜单/全历史证据。

## 6. 一个真实字典上的严格优化改善，仍无负种子

取 m=3 的两种组件：E为三个不交单客户资源，J为两个不交、各两客户资源；目标都取前两人相同资源、末位另一资源。末位均为真实 BR。该不交组件机制已有 R44 来源，不认领新游戏。

令 w_E=x、w_J=1−x，0≤x≤1。真实菜单由 signed 及 counter 独立分类给出：

    Psi_1=max[x,(x+2(1−x))/2]，Psi_2=x+(1−x)；
    u_1=u_2=[x+2(1−x)]/2，B=x+4(1−x)。

所以共同帽的 VALUE 恰为

    F(x)=3+(3/2)|x−2/3|，min F=3。

旧逐组件帽给

    F_old(x)=4−x/2，min F_old=7/2。

这是整个字典优化值的严格改善，不只是某个非最大 L 的下降。清分母 x=2/3 对应两份 E、一份 J：真实根 M_1=2，M_2=3，目标收益(2,2,4)，B=6、C=3、B+C=9>0。因此它仍不是 half 负种子。

该例的任意整数复制数 E_count=s、J_count=t 亦可逐个 joint 根重标签，末位 BR 分类给

    M_1=(s+2t)/2+(1/2)max(0,s−2t)，M_2=s+t。

在 s=2,t=1 处没有舍入余数，达到连续池帽。父方 [原始单位展开审计](audit_joint_threshold_example.py)另从所有 joint 根/下一/末动作重建，不导入作者程序；有限 QA不代任意输入证明。
