# 实际分数负载弱桥的独立定义级审查

审查对象为 `CA-FRACTIONAL-ACTUAL-LOAD-WEAK-v1`，不改变
`Q-CAG-HALF` 的对象或状态。只审查发现者目录中的四人实例与完整策略；
无限族可实现性不在本次通过范围。外部审查和新颖性均未认证。

## 精确结论

四共同主题记为 A、B、Q、D，四名单位提供者。不同单位客户分为四类：
3 人只喜欢 A，1 人只喜欢 Q，1 人喜欢 A、D，12 人喜欢 B、Q、D。
四个覆盖不同，其中 B 是 Q、D 的真子集，允许这一目录条件。

所给策略定义了全部 85 个有序决策历史。在每个历史先执行每个备选动作、
再执行所给原策略的真实后继，逐个单位客户重算最终均分收益，
所有 255 个非自身动作比较均非负；最小 slack 为零。
因此这是一份完整历史依赖纯 SPE，保留全部离轨历史与任意平局。

实际路径是 `(B,B,B,A)`，各人收益均为 4，福利 W=16。A 与 Q 的并集已经覆盖
全部 17 人，因此 OPT₄=17。设 α=3/4，按实际终局负载计算的查询值为

| 查询主题 | Σₓ∈T 1/(1+αcₓ) |
| --- | ---: |
| A | 16/7 |
| B | 48/13 |
| Q | 61/13 |
| D | 388/91 |

故 M=61/13，且 `(4−1/2)M−W=11/26>0`。
弱分数实际负载桥被否定；本例 `2W−OPT₄=15>0`，不是半覆盖反例。

## 对充分性代数的独立重构

对任意实际终局负载 c 与任意 m 个比较主题的负载 d，令 L=αc。
逐客户 `1[d>0]≤(d+L)/(1+L)`。求和后，

`O≤Σⱼg(Tⱼ)+ΣₓLₓ/(1+Lₓ)=Σⱼg(Tⱼ)+αΣᵢg(Aᵢ)≤(2m−1)M`。

这一步没有使用 SPE，仍成立；失败的是将实际福利支付给 M 的充分桥。
本脚本另对四人实例的全部 256 个有序比较元组核对该代数，而不是反向推断
此桥的失败会使目标失败。真正静态混合安全值的最小背景可离开实际分数负载，
本反例也不否定其聚合桥。

## 可复核证据与审查方式

- `audit_fractional_weak.py`：仅导入 Python 标准库，将重数展开为 17 名不同单位客户。
  不导入发现者 MILP、规范 SPE 求解器或规范 verifier。
- `fractional_weak_m4_audit.json`：记录每个有序历史的四个真实分支收益及上述精确结果。
- 策略键集合先与所有合法历史逐项比较，缺失一个节点会被拒绝；另核对声明终局与
  实际路径计数完全一致。零客户输入在同一完整策略下给 W=OPT=M=0。

发现者的有限搜索、MILP状态或“m=2,...,9 可实现”的报告不作为本审查结论依据。
通过范围是这一个完整合法反例及其所否定的全称辅助桥。
