# 末节点、多主题与前缀缺席研究

目标始终为一般 Q-CAG-HALF；没有改变任意目录、任意人数、所有完整历史纯SPE量词。

- `prefix_absence_repeated_last.md`：精确个人ID `B2-REPEATED-LAST-ABSENCE-v1`。复核上一轮残余判据，给逐客户真实前缀缺席保底、严格更强的末主题重复判据、无需调和数的多项式充分条件，以及解析渐近常数 `sqrt(2+sqrt(3))`。作者证明+根代理独立重构主不等式、多项式条件和一致渐近展开；仍个人候选、未正式提升共享Claim或外审。一般目标仍开放。
- `prefix_absence_audit.py`：独立 Fraction 公式审计；输出另存 JSON，不修改历史证据。
- `prefix_absence_audit.json`：已通过8178个完整覆盖顺序pattern、171700个精确系数案例、933个旧判据蕴含和1156个多项式充分条件蕴含。有限算术只审计公式，普遍证明在正文。
- `envelope_cone_probe.py`：一般包络桥的浮点发现程序。给一个规范求解器重构的完整纯SPE策略，保留全部真实有序历史偏离行；再要求每个末前缀的税敏感包络值 `E(h)` 都超过 `2W+epsilon`，在线性策略锥中最大化epsilon。正值必须另做有理重构和定义级全历史核验；不是一般半覆盖反例。
- 尚待研究：税敏感全部末历史包络 `E*=min_h[m BR(h)+tau(h)]` 能否由实际SPE福利支付；需要真实离轨后继最优性，不能只叠加在轨最坏负载保底。

包络实验已完成：`envelope_cone_probe.json` 保存m=5、p=7的12棵随机完整策略锥的结果。每锥全部16806个有序偏离行加210个末节点包络行，浮点最优epsilon均约−0.2，没有找到包络反例。这个有限无反例计算不证明包络桥；当前只登记浮点探索状态，与上方解析候选分开。

关键下一步：选结构性较差SPE而非仅稠密随机输入；若epsilon仍等于−1/m，检查LP对偶是否出现可推广的跨末节点支付。若发现epsilon>0，先有理清分母，并从客户表直接核验全部历史；如果仅对偶模板失败，准确记为包络桥障碍。成熟重复主题子类已经独立成文，不能把其完成视为主目标完成。
