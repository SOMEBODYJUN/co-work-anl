## 真正 CAG 曲率探索的停点

逐资源份额满足两项更强结构：

1. `1/(1+k)=∫_0^1 t^k dt`，且同一客户在所有分支都使用这一个核；不能给每层独立选一个一般 DR 曲率。
2. 同一客户在最终负载 c>0 时总共恰支付 `c·(1/c)=1`。在实际入场过程中，新覆盖者把负载从 k−1 加到 k：新人的旧客户收入为 `1/k`，每名旧覆盖者损失 `1/[k(k−1)]`，全部旧人的总损失也恰为 `1/k`（k≥2）。新覆盖客户则新增一单位总支付。这是份额税转移与覆盖守恒；不仅是匿名势恒等式。

这些结构本身没有给当前 AFC 需要的跨分支金额。一个早期查询被真实尾部追随时，当前玩家的份额损失能在**该偏离分支**中找到尾部所得，但不能直接把该所得替换为原实际路径尾部利润。回到原路径仍需当前策略在相应有序历史的真实 return IC，以及其后继重置。固定后继、把调和势当作尾部联合最大化目标、或把多分支税池各花一遍都不合法。

本分支尝试用随机优先级/积分表示、入场税流与共同 saddle 的资源价格耦合；截至本页没有补上这一步，因此不另把上述税账或 Bregman 重排包装成新付款定理。也未做有限阴性扩样或另开固定人数项目。

下一次值得继续的具体对象是：构造一份在每个真实 return 比较后保留税池、且同一客户总共只付一单位的全树运输。若只有匿名 DR 或只剩原余额等式，则仍未越过已证方法边界。
