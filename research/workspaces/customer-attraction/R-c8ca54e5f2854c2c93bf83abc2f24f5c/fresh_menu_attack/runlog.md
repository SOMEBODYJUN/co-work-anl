## 独立定义级 oracle 对比

父方要求后执行：

```
PYTHONPATH=. python research/workspaces/customer-attraction/R-c8ca54e5f2854c2c93bf83abc2f24f5c/fresh_menu_attack/verify_oracle.py
```

精确输出冻结于 `oracle_audit.jsonl`。各例对完整策略按定义穷举，逐历史检查原真实偏离；菜单包络的有理 p exact 模式与枚举最大 gap 完全一致：

| 实现检查 | 完整策略数 | 纯 SPE 数 | 两法的最大 gap |
| --- | ---: | ---: | ---: |
| generic | 128 | 1 | −3/2 |
| disjoint_ties | 128 | 14 | −1 |
| empty_theme | 128 | 1 | −8/3 |
| identical_coverages | 128 | 128 | 0 |
| zero_customers | 128 | 128 | 0 |
| one_empty_theme | 1 | 1 | 0 |
| one_player_zero | 2 | 2 | 0 |

这些只验证 oracle 的实现，覆盖全历史/平局/空零边界；不作为 AFC 的正面数学证据。

本轮解析没有找到共同付款的新不等式。现交接精确菜单包络及公共客户删除，不继续阴性扩样。
