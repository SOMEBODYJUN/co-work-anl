# 同一真实末两人菜单的新增与保护客户分数价格

2026-10-21。个人解析结果；父代理正在独立复核，未认证外审或新颖性。一般 Q-CAG-HALF 仍 OPEN。

## 对象与结论

使用 `research/current/customer_attraction/model.md` 的共同目录、单位客户与提供者。固定任意合法有序前缀，负载为 `p_x >= 0`，之后恰剩两名玩家。固定该子局任意完整历史依赖纯 SPE，实际行动为 `A,B`，实际收益为 `u_A,u_B`。允许空主题、重复主题与全部平局。

对任意客户子集 `D` 与 `v >= 0`，定义

```
B_D(v) = sup_(z_T >= 0) [sum_(x in D) min(1,d_x) - v tau],
d_x = sum_(T contains x) z_T,  tau = sum_T z_T.
```

有限客户和目录保证该上确界有限；例如目标始终不超过 `|D|`。以下证明逐个有限 `z` 给界，无需预先主张最优解存在。

记原前缀未覆盖客户集 `F={x:p_x=0}`，`a_F=|A intersect F|`。则

```
B_F(u_A) <= u_B/2 + a_F/4.                              (F)
```

更一般，对每个 `D subset F` 且 `D intersect A = empty`，有

```
B_D(u_A) <= u_B/2.                                     (D)
```

特别，原完整终局遗漏集的任意子集均满足 (D)，无须约束其与所有真实离轨回复的交叠。

这两式与加入克隆行所得的另一预算不同：后者给
`B_F(u_A) <= u_B - (1/2) sum_(x in A,p_x>=1) 1/(p_x+2)`。
二者可以取最小值，但不能声称逐实例互相支配。

## 三类真实比较及联合会员消去

令 `R_T` 为给定原策略在当前首位改选 `T` 后的真实末位回复。置

```
U_p(X,Y) = sum_(x in X) 1/(p_x+1+1_Y(x)).
```

对任意 `tau >= 1`，以下均为原 SPE 同一完整策略所支持的非负量：

```
S = tau u_A - sum_T z_T U_p(T,R_T),
Z = tau u_B - sum_T z_T U_p(R_T,A),
V = sum_(T,Q) z_T z_Q [U_p(R_T,T)-U_p(R_Q,T)].
```

`S` 使用首位真实偏离；`Z` 使用实际末位节点相对所有合法 `R_T`；`V` 使用真实节点 `(prefix,T)` 相对其他节点回复 `R_Q`。共同目录使这些交叉主题合法。每个有序历史的回复始终是其原指定回复；未把同计数历史的策略识别。

取 `G=S+Z/(2tau)+V/tau >= 0`。对一名客户记

```
p=p_x, a=1_A(x), b=1_B(x),
alpha=a/(p+a+b), beta=b/(p+a+b),
d=sum_T z_T 1_T(x), ell=sum_T z_T 1_(R_T)(x).
```

零分子份额取零。直接展开后联合会员 `h=sum_T z_T 1_T(x)1_(R_T)(x)` 抵消，得到

```
G_x = tau alpha + beta/2 - d/(p+1)
      - ell/[2tau(p+a+1)] + d ell/[tau(p+1)(p+2)].       (1)
```

定义

```
r_q = q min(1,d) - d/(p+1)
      - ell/[2tau(p+a+1)] + d ell/[tau(p+1)(p+2)].       (2)
```

于是对 `q_x=1_D(x)` 有精确总恒等式

```
sum_(x in D) min(1,d_x)-tau u_A
    = u_B/2 + sum_x r_(q_x) - G.                       (3)
```

## 全参数逐客户界

始终有 `0<=d,ell<=tau`。若 `q=0`，由 `ell<=tau`，

```
r_0 <= -d/(p+1) + d/[(p+1)(p+2)]
     = -d/(p+2) <= 0.                                  (4)
```

省略的 `-ell/[2tau(p+a+1)]` 也非正。此界对全部 `p>=0,a in {0,1}` 成立。

若 `q=1,p=0,a=0`，则

```
r_1 = min(1,d)-d + (ell/tau)(d-1)/2 <= 0.              (5)
```

证明：`d<=1` 时两项非正；`d>=1` 时使用 `ell/tau<=1` 得 `r_1 <= (1-d)/2 <=0`。所以 `D subset F\A` 时每个客户的余项非正，(3) 给 (D)。

若 `q=1,p=0,a=1`，则

```
r_1 = min(1,d)-d + (ell/tau)(d/2-1/4) <= 1/4.          (6)
```

当 `d<=1`，首项零、最后一项至多 `1/4`；当 `d>=1`，使用 `ell/tau<=1` 得 `r_1 <= 3/4-d/2 <=1/4`。对新增集 `F`，只有实际首位新增客户可能付此 `1/4`，所以 (3) 给 (F)。

以上为无限参数解析不等式；未用有限 `p,tau` 枚举作归纳外推。

## 总权不足一、零与比较组合

若 `0<tau<1`，所有 `d_x<=tau<1`。将 `z` 除以 `tau` 后总权一，前后覆盖截断均在线性段，故原价格利润是正规化价格利润的 `tau` 倍。两式右端都非负，得到相同界。`tau=0` 时价格利润零。因此对全部非负权成立，取上确界即得结论。

若 `k` 个合法主题覆盖 `D`，将这 `k` 个主题各赋权一（重复主题累加权重）得到

```
|D| <= k u_A + u_B/2.                                 (7)
```

在实际末位节点，因为 `D` 与原前缀、`A` 均不交，真实末位相对任意主题 `T` 的最优性还给 `u_B >= |T intersect D|`，故

```
|D| <= k u_B.                                         (8)
```

这两条只来自真实尾部，不包含早期节点最优性。它们尚不闭合一般 half，甚至仅以它们推出 `|D|<=u_A+u_B` 时，`u_B/2<u_A<u_B` 存在代数缺口。
