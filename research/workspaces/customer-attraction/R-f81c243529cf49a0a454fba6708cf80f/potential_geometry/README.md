## 实际终局插入候选：未证明

固定一份完整 SPE 实际终局 z，客户最终负载 c_x，定义

\[
J_T(z)=\sum_{x\in T}\frac1{1+c_x},\qquad
B(z)=\sum_x\frac{c_x}{1+c_x}.
\]

任何 m 个比较主题 T_j 的覆盖 O 都满足

\[
O\le\sum_{j=1}^m J_{T_j}(z)+B(z).
\]

这是已有共同目录静态逐客户预算的直接写法：对比较覆盖重数 d_x，用 `1_(d_x>0) <= (d_x+c_x)/(1+c_x)`。它没有使用真实后继，不算新承重关系。

本轮私人候选为

\[
m\max_TJ_T(z)+B(z)\stackrel?\le2W(z).
\tag{A}
\]

若 (A) 对全部输入成立即直接推出一般 half；但本轮**没有证明 (A)**，也没有证明它与原 half 等价。它要求实际终局的一列满足一个放宽插入预算，与允许离轨根菜单混合的 Mfull 不同。未付项就是从全历史 IC 控制实际终局静态额外插入查询；任何仅用上述静态预算的推导都没有推进这个步骤。

`attack_actual_insertion.py` 只在已经冻结的70份 m=4,p=5 完整策略锥中，对每个查询 T 最大化 (A) 左边减右边，归一 W=1。350个浮点LP的精确非负客户候选及完整有序历史 IC 经 Fraction 重验，没有找到正差；已保存最高**精确可行候选**差为 −1/5。没有恢复每个LP的精确上界对偶，因此不可把这个值写成所有这些锥的已证最大值，更不能称一般 (A) 成立。源策略和每个候选可复现，输出见 `attack_actual_insertion.json`。另一代理另在34客户旧策略锥做6次同类攻击，也未得反例；那份证据由其自己目录保存，本目录不重复计数。

## P0：允许最优元组重选的遗漏私有化

parent 后续指定的精确一般候选是：对每份原完整 SPE 实际有序终局 z，存在一个真正最优 m 元组 C；将每个实际遗漏且在 C 内覆盖的客户兴趣缩为 C 中某个原覆盖主题单例，删除 C 外实际遗漏，覆盖客户不改；希望修改后 z 仍由某份完整 SPE 实现，离轨策略允许重选。若成立可接已有私有遗漏定理。此处全称固定 C 的加强已由旧36客户反例否定，不能代替 existential C。

本轮独立攻击机制：把两份36客户旧实例做**同标签对角和**，试图制造彼此冲突的可选最优主题组。第一份组为 `{0,1,2}|{3,4,5}`，第二份为 `{0,1,5}|{2,3,4}`；每份有每个跨组二元兴趣1客户、每个两X两Y兴趣3客户。总72名单位客户、6共同主题、3人。希望坏路径 `(0,3,4)` 两份都保留而没有共同可用最优组。

精确集合值逆推结果：原路径 `(0,3,4)` **已经不是原游戏 SPE 可实现终局**，全部原 SPE 福利70，OPT也70。可实现计数恰为四组三主题 `{0,1,2}`, `{0,1,5}`, `{2,3,4}`, `{3,4,5}`。所以这个具体冲突机制失败在原动态 IC，不是 P0 反例，也不是 P0 的一般正面证据。

潜在一般承重义务：若一次遗漏私有化使 z 不再可实现，能否由新增的可信偏离树构造另一个等覆盖最优元组 C′，并改选 owner 避免冲突？36客户的失败不是一个单主题交换就能修复，不能免费调用普通覆盖局部交换。此义务完全未证。
