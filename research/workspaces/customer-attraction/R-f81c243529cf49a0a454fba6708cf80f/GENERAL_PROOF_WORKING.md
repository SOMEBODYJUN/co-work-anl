# 一般半覆盖：父方推导与未闭合义务

本轮主目标仍为原 Q-CAG-HALF，状态 OPEN。本文件是研究工作稿，不提升共享账本。恢复依据是仓库实际文件及 Git，不以历史聊天的身份或状态替代本 clone 的程序绑定。

## 1. 精确目标与已知承重点

固定任意有限单位客户、有限非空共同目录和任意 m≥1；固定任意完整有序历史纯 SPE σ，实际终局 z，福利 W。对任意最优 m 元组 C，其覆盖并集也记 C，欲证明 |C|≤2W。所有离轨续局读取真实策略；不把早期偏离后的后继冻结。

设 I 为实际覆盖，R=C\I，G=I\C，则目标精确等价于

`|R| <= |I∩C|+2|G| = W+|G|`。

因此简单加强 |R|≤W 不是原目标，不能丢掉 G 的信用。已有 SOURCE-NET 的首次 source 付款、捕获前沿和终局水位均没有支付捕获之后重置实际前缀的 incoming 费用；本轮没有把单枝信用跨树重复使用。

## 2. 可信门槛的跨多步候选

对任意前缀 h 和合法行动 A，R(h,A) 是强制 A 后所有完整纯 SPE 可实现终局的集合，定义

`L(h,A)=min_{y∈R(h,A)}u_current(y)`, `Θ(h)=max_A L(h,A)`。

有限树拼合保证 Θ(h) 既是每份该子博弈 SPE 的当前收益下界，又可由某份完整 SPE 达到。旁枝必须从不受祖先终局承诺限制的 R 中选取。

既有同序比较候选要求最优元组 (T_i) 有 Σ_i L(h_i,T_i)≥OPT−W。本组另检验更强但结构不同的 **TB-ANY**：任意合法路径 z（即使不是 SPE）均有

`OPT_m <= W(z)+Σ_i Θ(h_i)`。

若此式成立，则对真实 SPE 逐位置 u_i≥Θ(h_i)，求和便直接给 half。它目前没有一般证明。精确有限 DP 是 J(leaf)=W(leaf)、J(h)=Θ(h)+min_A J(h,A)，只把候选写成一个可攻击的最小值，不算证明。

局部尝试 Θ_r(b)≥F_r(b)−F_(r−1)(b) 已被既有 root_tax 实例否定：零背景四人 Θ=9、OPT4=61、OPT3=51。数字已用 Python 精确有理求解及覆盖枚举核对；该局部加强不是继续研究的前提。总预算未因局部加强失败而被否定。

## 3. 遗漏私有化作为竞争归约

保持所有已覆盖客户不变，把实际遗漏且在某个最优元组 C 中的客户只保留一个原兴趣 owner∈C，其余遗漏可删除。C 仍达到旧 OPT，删兴趣不会提高 OPT，因此最优值保持。若还能选 C/owner 并重建一份福利不增的完整 SPE，则可尝试对共享遗漏的 incidence 作有限下降，归约到已有私有遗漏定理。

这里最危险的是可信性：在实际路径没有被覆盖的客户，对其删兴趣不会改变该叶收益，却可让离轨惩罚者不再愿意执行旧威胁。单叶收益不变不意味着原叶仍可由某份 SPE 实现。

本轮新检验复用旧36客户输入：固定 C 为全部 Y 主题时，两个遗漏客户的 owner 被迫 Y2；改后全部可信 SPE 只剩全 Y 终局。允许重选最优 C 则可用全部 X 并保留原叶。因此 **固定任意 C** 的加强失败，**存在一个有利 C** 的版本未被该证据否定。准确证明与独审由 credible_attack/、branch_transport/ 保存。

父方曾尝试以旧36客户加 X0 私有3、各 Y 私有2强迫唯一最优 Y。Python 精确 BI 表明原候选路径根本不再是 SPE，不能作为任何归约反例：根偏离到 Y 后，新的末位激励使惩罚者失去最优性。这个失败诊断只否定该 padding 尝试，不给原目标真值信息。

弱私有化归约如果对全部实例成立，并能反复保持 OPT 与不增福利，将推出现有私有遗漏定理的更强 `(2−1/m)` 上界。因此该归约比只证 half 更有野心；不能把它当必要条件。

## 4. 查重与停止无信息重复

自由连续分数背景 Λ_s(b) 完全等于已有 t_(s+1)(b)。其凸 minimax、平方价格 KKT 和几何均值对偶均已有正文；本轮不新增工具身份，不重新跑阴性扫描。盲重构提醒：裸比较 OPT≤(m+s)Λ 限空背景，非空背景须留背景信用；s=0 不能强加 q 的支持 KKT。

当前真正未付义务仍是跨真实理性续局的共同预算。TB-ANY、存在型私有化和实际插入价格只是竞争的充分候选，均未闭合。没有新承重关系时应准确停止本轮推导，而不是用增加样本、改名或等价重述维持忙碌。
