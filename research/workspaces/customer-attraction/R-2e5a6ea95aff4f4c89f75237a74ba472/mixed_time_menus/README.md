# 完整菜单的有限重入、同步时刻与静态极限

2026-10-23，`mixed_time_menus` 子研究员。Q-CAG-HALF 仍 **OPEN**。
本目录保存任意人数的菜单归约及一个两人单位客户的精确同步边界；没有发现新的
完整 SPE 福利反例，也没有证明任何一般支付桥。未独立审查、未外审。

- [有限重入与同步时刻](finite_reentry_and_synchronized_schedules.md)：把现有
  PRODUCT-MENU-TIME 扩到至多 d 次真正跨树重入；固定 d 时只需恰 d 个强制时刻，
  全称菜单桥等价于跨实例通用的时刻集合分布。允许全部 m 次重入时，菜单恰为
  全部静态 m 槽背景，承重精确降为 `W >= m v_(m+1)`。
- [精确审计](audit_reentry.py)、[实际输出](audit_reentry.json)：不导入模型或 SPE
  solver，直接按七名单位客户检查两个组件和产品的全部有序历史；验证查询时间
  向量 `(2/3,1)`、`(1,2/3)`，以及同步单重入 `5/3 > 4/3`、双重入 `4/3`。

新增可接续义务是给出 d=d(m)<m 的统一干预成本或通用时刻集合支付；不能只对每个
实例各选有利时刻，再把不同实例的时刻选择相加。无限制重入本身不会产生支付证明。
