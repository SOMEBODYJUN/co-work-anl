# 删除实际遗漏客户会破坏终局可实现性，且可信根阈值可有无界单客户敏感性

目标背景为原 Q-CAG-HALF，完整历史、任意平局、单位客户和共同目录均不变。
**一般半覆盖仍 OPEN。** 本文否定一个删除归纳接口，不是其反例。

状态：精确参数证明及完整策略核验；另一研究员从定义独立重建删除端点，并审查
参数分区和整数族。无外审或新颖性认证。独立审计见本工作区
`../full_tree_duality/audit_omitted_deletion.py` 及相应证据文件。

## 1. 精确对象与欲排除的桥

对固定实例 I 和目标终局计数 c，令 C 为 c 实际覆盖的客户，U=N\C。
删除归纳桥 DEL-OMIT 声称：若 c 能由 I 的某个完整纯 SPE 实现，删除 U 后，
c 仍能由**重新选择全部离轨续局**的某个完整纯 SPE 实现。
这里绝不把“同一策略失去最优性”当成不可实现性。

根可信阈值为

\[
M(I)=\max_{a\in\mathcal S}\min_{q\in R_I(e_a)}U_a(q),
\]

R_I(b) 是背景计数 b 后完整纯 SPE 可实现终局的全集。它是现行全集逆向归纳
的精确对象，不是静态保底或实际根收益。研究一个客户删除时 M 是否只变化常数，
必须同时允许所有合法续局改变。

## 2. 五主题单位客户表

人数固定为五。主题按 A,C,D,E,F 编号 0,1,2,3,4。下表每行重数代表不同单位客户；
唯一参数行仅属 E。先用有理 t 表示参数，所有实际实例随后整体放大为整数。

| 客户兴趣主题 | 重数 |
| --- | ---: |
| A | 3 |
| A,C | 7 |
| A,D | 1 |
| C,D | 1 |
| E | t |
| A,C,E | 1 |
| A,C,D,E | 2 |
| C,D,E | 1 |
| A,C,F | 5 |
| D,F | 2 |
| C,E,F | 2 |
| D,E,F | 10 |

固定目标 c=(2,1,0,0,2)，实现路径可取 F,F,C,A,A。
它覆盖表中全部非参数客户，福利 W(c)=35；按路径的收益为

\[
(23/3,23/3,7,19/3,19/3),
\]

与 t 完全无关。目录主题彼此不同；t=0 时保留合法主题 E。

## 3. 全参数精确结论与证明合同

对所有实数 0≤t≤1，该有限收益游戏的集合值逆向归纳给出

\[
c\in R_t(0)\quad\Longleftrightarrow\quad t\ge3/4,
\qquad
M(t)=\begin{cases}33/4,&0\le t<3/4,\\7,&3/4\le t\le1.\end{cases}
\tag{1}
\]

其中有理 t 通过整体清分母成为完全合法的单位客户实例；实数参数只用于证明
这些整数实例共同的阈值公式，不扩大原目标模型。

**全参数证书而非有限抽样推论。** 证明实现为 `verify.py`，证据为
`verification.json`。固定每个终局计数 q、占用动作 a，收益是
\(\alpha_{q,a}+t\beta_{q,a}\)，其中仅 a=E 时
\(\beta=1/q_E\)，否则 β=0。枚举所有终局得到 211 条不同仿射线；取其在 [0,1]
中全部交点及两个端点，共 65 个分点。分点和所有相邻开区间中点共 129 个代表。
在任一开区间中，**全部可能收益比较的弱序固定**。从终局向上归纳，所有孩子
集合、min/max 达到关系及 R_t(b) 全部固定。因此每个开区间只需一个有理代表，
端点另行精确计算。这是覆盖整个参数区间的有限解析分区证明，不是从有限 k
回归猜测一般 k。

程序没有只列当前被选中的比较；它列全部终局的占用动作收益两两交点，故涵盖
每个可能历史中全部当前/备选续局的比较。恒等相等的线在整个开区间一直相等，
任意平局没有被删除。另一个实现逐个展开全部有序历史、逐名单位客户计算收益，
在 t=0,1/2,3/4,1 独立核对全集；正例完整证书各检查 781 个决策历史、3124 个
严格备选动作比较。完整阈值端点证书在 `threshold_certificate.json`。

## 4. 单客户删除的直接反例及局部开关

t=1 是 36 客户的原模型实例。其根全集恰为

    (2,0,1,1,1), (2,1,0,0,2).

删除唯一未覆盖的 E 私有客户，t=0，根全集恰为

    (2,1,1,0,1).

故 DEL-OMIT 为假。W(c)=35、OPT=36，显然不违反 half。

下面定位真正机制，而非把递推当作黑箱：历史计数 (2,0,1,0,1)，即已有 A,A,D,F，
最后一人的五个动作收益为

\[
(17/3,\;77/12,\;23/4,\;17/3+t,\;25/4).
\]

于是 t=3/4 恰是 C/E 的切换；更大 t 时 E 严格更好，更小 t 时 C 严格更好。
选择 E 给先前的 D 玩家 20/3；选择 C 则给该 D 玩家 47/6。
目标中第二次选择 F 的玩家收益是 23/3=46/6，处于两者之间。
因此遗漏客户能通过末位回复改变更早 D 偏离的可信收益，尽管在轨无人接触它。

独立删除端点审计还有一个短排除切口：任意目标顺序都有第二次 F，其前缀必为
(a,c,0,0,1)，0≤a≤2、0≤c≤1，共六态。t=0 时，在每个该态改 D 的完整 SPE
终局都唯一为 (2,1,1,0,1)，收益 47/6，严格超过第二次 F 的 46/6。
因此允许任意重选离轨续局也无法恢复目标，而不只是原路径 F,F,C,A,A 失败。

## 5. 无界单客户敏感性：一般整数族

对任意整数 k≥1，令 q=4k+1，把全部非参数行重数乘 q，E 私有客户原为 3k+1 人。
删去其中一人后为 3k 人。归一化参数分别是

\[
t_+=\frac{3k+1}{4k+1}>3/4,
\qquad t_-=\frac{3k}{4k+1}<3/4.
\]

由 (1) 和收益齐次性，删除前目标可由完整纯 SPE 实现，删除后不可实现，而且

\[
M_+=7q,\qquad M_-=(33/4)q,\qquad M_--M_+=(5/4)q\longrightarrow\infty.
\tag{2}
\]

只删一名单位客户；所有目标路径上的玩家收益与覆盖均保持原数值。
关键末位 C/E 比较在删除前差 +1/4、删除后差 −3/4，均严格。
**没有声称全部有序历史上的所有激励比较都严格。** 因而 (2) 不依赖把关键参数
恰设在平局端点，但仍完整尊重原目标允许任意平局的量词。

该族删除前客户总数 143k+36，目标福利 140k+35，OPT 等于客户总数；五个主题
全选即可覆盖全体。它是无界客户规模、固定五人五主题的删除接口反族，不是
无界人数反族，也不构成 half 反例。`verify.py` 的若干整数 k 回归只是验证公式
和整数化实现；任意 k 的依据是已经覆盖整个区间的 (1)。

## 6. Honest salvage 与下一义务

固定完整策略的参数可行域是闭区间；目标终局可实现参数集是有限个此类闭区间
的并。它可随遗漏客户变化而发生续局切换。本例精确排除以下桥：

1. 删除所有实际遗漏客户后可保持原终局可实现。
2. 单名遗漏客户对根可信阈值只有统一常数的绝对影响。
3. 只依据目标在轨收益不变，就认为完整 SPE 的可信威胁不变。

它没有排除带完整续局切换信用的参数归纳、总福利桥或真正安全值聚合。
若继续参数路线，必须支付可跳变的子博弈可实现性，不能以遗漏质量乘固定常数
作为普遍连续误差。root 在此停止优化此固定例，回到一般跨分支支付。
