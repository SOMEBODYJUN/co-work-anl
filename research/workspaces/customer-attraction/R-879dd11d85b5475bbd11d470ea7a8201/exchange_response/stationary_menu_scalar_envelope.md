# 一般真实菜单的驻留标量包络：精确二次损失及无自环锐性

2026-10-23。个人探索资产；Q-CAG-HALF **仍 OPEN**。本页是一般解析引理及辅助模板的精确边界，不是完整 SPE 反例，也没有证明一般半覆盖。母代理独立提出并核算了第 3 节四标签锐构造；其余解析部分尚未独立审查。

来源边界：旧稿 `R-0f99797b33de46bfb498541a0bc5fae9/parent/stationary_middle_incidence_boundary.md`
已给任意 r 的四标签负通量。本页新增任意背景的普遍最优比值 M_r(b)、点态证明和实现这个最优比值的参数选择，
不把已有“负余项存在”重新算作新发现。

## 1. 对象与结论

固定合法背景客户负载 b、剩余人数 r>=2、包含极大主题 A_1,...,A_k。
根依次强制选 A_i，并执行原完整策略的真实后继，得分支 z^i。把每名后继
主题归属到一个包含它的极大主题。记 n_(ji) 为根 i 分支中归属 j 的后继数，
故 sum_j n_(ji)=r-1。这里不假设后继选择仅依计数，也不冻结任何真实后继。

取列随机矩阵 R_(ji)=n_(ji)/(r-1) 的任意驻留概率 pi。
对客户 x，令 I_i=1_(x in A_i)、K_i=根 i 分支真实后继对 x 的负载、b=b_x，并记

    D_x = E_pi I_i/(b+I_i+K_i),
    P_x = E_pi (I_i+K_i)/(b+I_i+K_i),
    S_x = (r-1) E_pi I_i - E_pi K_i >= 0.

零负载项按零计。D_x 是驻留根收益；P_x 是这 r 名剩余玩家的驻留总收益。
S_x>=0 来自后继主题包含于其归属主题及驻留等式，不需要无自环。

**一般包络引理。** 令 q_r=floor((r-1)^2/4)，则

    P_x <= [r+q_r/(b_x+1)] D_x - S_x/(b_x+1).       (1)

特别地，M_r=floor((r+1)^2/4)=r+q_r 给

    sum_x P_x <= M_r sum_x D_x.                    (2)

所以若这些根分支的每个根收益均 <=u，且每名后继收益均 >=t，则

    u >= [(r-1)/(M_r-1)] t.                        (3)

r=2、3、4、5 的系数依次为 1、2/3、3/5、1/2；大 r 时约 4/r。
这没有达到一般 theta-floor 所需的系数 1。

## 2. 点态证明

对 I in {0,1}、K in {0,...,r-1}，定义 D=I/(b+I+K)、P=(I+K)/(b+I+K)。
逐项有

    P <= [r+q_r/(b+1)] D + [K-(r-1)I]/(b+1).      (4)

I=0、K=0 时等式；I=0、K>=1 时只是
K/(b+K)<=K/(b+1)。I=1 时，清正分母把 (4) 化为

    q_r >= K(r-1-K),

对整数 K in [0,r-1] 成立。对真实分支依 pi 求均值，最后项均值为
-S_x/(b+1)，即得 (1)。再求客户和、用 S_x>=0、b_x>=0 得 (2)。

令 D=sum_xD_x、P=sum_xP_x。尾部收益下界给 P-D>=(r-1)t，而 (2) 给
P-D<=(M_r-1)D<=(M_r-1)u，证明 (3)。

等价的根减尾均值负通量界为

    D_x - (P_x-D_x)/(r-1)
      >= [-q_r D_x + S_x]/[(r-1)(b_x+1)].         (5)

因此原样驻留模板的中间关联负余项，可以由根收益定量控制，但系数随 r 增长。

## 3. 无自环仍不能改善这个普遍标量常数

以下是纯菜单/逐客户锐性，不声称菜单可由完整 SPE 实现。
令 n=r-1，选 j=floor(n/2)，取四个标签 U_0,U_1,V_0,V_1。
某客户 x 仅属于 U_0,U_1。给每个根指定 n 个后继归属：

- 根 U_e：j 个 U_(1-e)，以及 n-j 个 V_e；
- 根 V_e：一个 U_e，以及 n-1 个 V_(1-e)。

每列和为 n，对角为零。令 p=1/(n-j+1)=1/(r-j)，则

    pi_(U_0)=pi_(U_1)=p/2,
    pi_(V_0)=pi_(V_1)=(1-p)/2.

它的四个分量均严格为正。以 U_0 为例，其入流为 j*p/2+(1-p)/2=n*p/2；
以 V_0 为例，其入流为 (n-j)*p/2+(n-1)*(1-p)/2=n*(1-p)/2，证明驻留。
r>=3 时 j>=1、n-j>=1、n-1>=1，该链不可约，所以 pi 唯一。
因此不能以“另挑驻留分布”避开这个最坏客户系数。
r=2 时图为两个不交二环，各驻留分布仍达到比值 2。

所有后继采用它被归属的完整主题时，内部根的 K=j，外部根的 K=1。
于是 S_x=0，且

    P_x/D_x
      = r+j(r-1-j)/(b_x+1)
      = r+q_r/(b_x+1).                            (6)

这在任意非负背景 b_x 下精确取等。空背景时 P_x=1，D_x=1/M_r。
r=3、j=1 正是已有四标签 2of4 的 -1/8 例。
这给其任意人数推广与精确最坏常数。

只覆盖客户 x 的四个标签并非两两不同覆盖或极大目录，故上述首先只是单客户标量构造。
可以给每个标签加一个仅属自己的私有客户，使全部覆盖两两不同且包含极大；
再令 x 代表 Q 个不同单位客户，Q趋于无穷，整体菜单的 P/D 趋于 M_r。
这只保证非负单位客户的合法主题菜单，不保证后继节点最优，更不是 SPE 证书。

## 4. 精确缺口与路线判断

这个引理可用于把真实菜单的驻留负通量显式写成“根收益倍数减内部子主题遗漏返还”。
但其最坏倍数随人数二次增长；无自环、整数后继数与任意合法背景都不单独修复它。
若想一般保常数，必须使用本页没有用到的真实后继最优性、跨客户结构或更早中继比较。
不能继续只改驻留 pi 或以无自环为理由断言所有中间归属逐客户非负。

本页也没有把 S_x 当成可另花的信用：它已在 (1) 中扣除，重复用于低 tail 删除返还会双计。
root 删除后的后继收益和根收益会同时增加，本页不声称已控制这种重耦合。

验证脚本 `audit_stationary_menu_scalar_envelope.py` 以 Fraction 检查点态 (4)、
无自环构造的行列和、驻留、所有背景上的 (6)。一般结论由第 2 节及第 3 节公式证明，
有限运行只检查实现。
