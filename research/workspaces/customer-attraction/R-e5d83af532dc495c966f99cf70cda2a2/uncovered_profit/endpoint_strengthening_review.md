# 末两位分数价格预算的独立重构与人数系数

状态：个人解析审查资产。2026-10-21父代理提出倒二误差E加强后，本分支不导入父的计算脚本，独立重建聚合恒等式和逐客户表。一般早期位置仍OPEN；本页不是一般half证明。

## 对象

采用CAG-MODEL，有限共同主题目录、单位客户、单位提供者，任意全部有序历史纯SPE和任意平局。固定实际倒二之前的完整有序前缀，客户负载记p_x，实际末两主题A、B。W包括全部前缀的最终覆盖，u_A、u_B为最后两人的实际收益。定义

    B(v)=max_{z_T≥0}[Σ_x min(1,Σ_{T∋x}z_T)−vΣ_Tz_T].

对任意固定前缀都成立

    B(u_B) ≤ W−u_B,                                             (1)
    B(u_A) ≤ W−u_A+E,                                          (2)
    E=Σ_{x∈A∩B,p_x≥2}(p_x−1)/[2(p_x+1)(p_x+2)].

若总玩家m≥3，则p_x≤m−2，因而

    B(u_A) ≤ W−κ_m u_A,    κ_m=(m+1)/[2(m−1)].                 (3)

m=2时E=0且B(u_A)≤u_B=W−u_A。m=3时也E=0。对任意m≥2还有B(u_A)≤W−u_A/2，但(3)在每个固定m更强。

## 末位：独立的折扣证书

令p'_x为实际末位之前的负载，y_x=p'_x/(p'_x+1)。末位真实最佳回复给每个主题T

    Σ_{x∈T}(1−y_x)=Σ_{x∈T}1/(p'_x+1) ≤ u_B.

由有限覆盖LP对偶，B(u_B)≤Σ_xy_x。若x被实际末位覆盖，y_x恰等于该客户给所有前缀玩家的最终利润总和；若末位不覆盖，y_x≤1，而前缀玩家最终利润总和为1。未覆盖客户两者均零。因此Σy_x≤W−u_B，得(1)。

## 倒二：从真实菜单重新计算

固定非负主题权z，总重τ≥1。R_T是原完整策略在固定前缀后实际观察到T时的真实末位回复。定义真实比较的非负组合

    S=τu_A−Σ_T z_T U_p(T,R_T),
    Z=τu_B−Σ_T z_T U_p(R_T,A),
    V=Σ_{T,Q}z_Tz_Q[U_p(R_T,T)−U_p(R_Q,T)],
    H=u_B−Σ_{x∈A}1/(p_x+2),
    G=S+Z/(2τ)+V/τ+H/2 ≥0.                                  (4)

H是实际末位改A的真实合法比较；不冻结后继。S是倒二的全部真实偏离，Z是实际末位对每个合法R_T的比较，V中每条行是观察到T后的真实末位相对R_Q的比较。故任意历史依赖平局均允许。

固定客户，设a=1_A，b=1_B，d=Σ_Tz_T1_T，ell=Σ_Tz_T1_(R_T)，h=Σ_Tz_T1_T1_(R_T)，D=(p+1)(p+2)。实际末两份额为α=a/(p+a+b)、β=b/(p+a+b)，零分子时份额定义为零。直接展开后h消去：

    G_x=τα+β−d/(p+1)−ell/[2τ(p+a+1)]+d ell/(τD)−a/[2(p+2)].

令s=min(1,d)，

    r=s−d/(p+1)−ell/[2τ(p+a+1)]+d ell/(τD).

由G≥0得到

    Σ_x s_x−τu_A ≤ u_B+Σ_x[r_x−a_x/(2(p_x+2))].                (5)

d∈[0,τ]，ell∈[0,τ]。在d的两个区间[0,1]、[1,τ]上r双线性，最大值在d∈{0,1,τ}、ell∈{0,τ}。逐角可得

    r≤p/(p+1)  (p≥1),    r≤a/4  (p=0).                       (6)

例如p≥1，角d=1、ell=τ相对d=1、ell=0的差为−p/(2D)（a=0）或(1−p)/(2D)（a=1），均非正；d=τ的角相对d=1相应角均随τ减小，最大取τ=1。p=0的六角分别直接给a/4。此处不需要q或m有界。

## 最终利润的逐客户支付表

该客户给全部前缀玩家的最终利润和为f=p/(p+a+b)，约定p=0时f=0。由(6)，r−a/[2(p+2)]−f的统一上界为：

| 条件 | 上界 |
| --- | --- |
| p=0，任意a,b | 0 |
| p≥1，a=b=0 | −1/(p+1) |
| p≥1，a=0,b=1 | 0 |
| p≥1，a=1,b=0 | −1/[2(p+2)] |
| p≥1，a=b=1 | (p−1)/[2(p+1)(p+2)] |

唯一正项是a=b=1且p≥2，恰为E。把表代入(5)，前缀利润和为W−u_A−u_B，得到(2)。

对0<τ<1，将z放大到z/τ；全部客户d≤τ<1，目标利润恰按τ缩放。右侧常数W−u_A+E非负，所以τ≥1所得界也涵盖τ<1；τ=0显然。取所有z的最大值得B界。

## 人数系数与真实边界

E中客户的实际A份额为1/(p+2)，故该客户的E/α=(p−1)/[2(p+1)]。当m≥3、2≤p≤m−2时，此比率至多(m−3)/[2(m−1)]；把E外A份额也计入只增右边。于是(3)成立。m=3不存在E客户，直接κ_3=1。

这些端点推出任意k个比较主题并集O_k满足

    O_k≤W+(k−1)u_B,
    O_k≤W+(k−κ_m)u_A  (m≥3).

它们只支付真实末位和倒二；不能将κ_m分配给一般早期玩家。一般候选OPT_m−W≤m u_i与更强B(u_i)≤W−u_i仍需独立证明或完整SPE反例。
