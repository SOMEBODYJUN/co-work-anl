# 自由起点、自由查询的逐客户捕获价格

2026-10-24。个人一般组件，待独立审查。**Q-CAG-HALF 仍 OPEN。**
本文没有证明新的普遍福利下界。新增接口是：信用侧可按客户选择接纳、路由和起点，而每条原 IC 仍只乘一个共同标量；固定实际前缀菜单后，最小总收费有非循环的反向 Bellman 公式。末节给一个严格充分、尚未证明的净缺口价格桥。它比固定 owner、预付 source 和逐行钱包更灵活，但不因灵活而自动成立。

## 1. 原真实菜单；信用流程不修改策略

固定任意一般 CAG-MODEL 实例、任意完整历史纯 SPE σ。实际路径为 S=(S_1,...,S_m)，实际覆盖 C，实际收益 u_i，W=Σ_i u_i。对实际第 i 位前缀强制合法主题 a，然后继续同一 σ，记真实叶 Z_i(a)、当前收益 D_i(a)。原 IC 为

    D_i(a) ≤ u_i。

全部历史依赖和任意平局均保留。固定一个实际未覆盖且目录可覆盖的单位客户 x。只对 a∋x 使用查询状态 (i,a,x)。实际前缀在 x 上零负载，故

    F_(i,a)(x)={j>i:x∈Z_i(a)_j},
    c_(i,a)(x)=1+|F_(i,a)(x)|,
    r_(i,a)(x)=1/c_(i,a)(x)。

进入质量 f 在当前吸收 rf，并向 F 中每个角色各送 rf。每个后继 j 可以任选一个含 x 的合法主题 b，进入新状态 (j,b,x)。该查询重新读取其原实际前缀 Z_j(b)。这一自由度不要求 b 等于旧叶 Z_i(a) 中角色 j 的行动；后者只是一个始终合法的特例。角色严格递增，故有限停止；每单位源质量全部且仅吸收一次。

这里的路由是证明对象，不是玩家修改策略，也没有把真实旧叶的后继冻结成新叶。

## 2. 客户侧自由切分仍只有整行 IC 标量

允许不同客户、不同到达来源对同一个 query 使用不同的接纳比例或不同后继选择。令 f_(i,a)(x) 是该 query 最后实际接纳的总质量，并令

    A_(i,a)=Σ_(x∉C,x∈a) r_(i,a)(x) f_(i,a)(x),
    w_(i,a)=A_(i,a)/D_i(a)。

A>0 时必有 D>0；A=0 时取 w=0。然后对**完整原行**乘一个非负常数 w，得到

    A_(i,a)=w_(i,a)D_i(a) ≤ w_(i,a)u_i。          (SCALAR)

没有给 x 单独使用不同的原收益差系数。客户级选择只决定非负信用流及其总吸收 A；(SCALAR) 不声称 w 逐客户支配 f，也不声称原 IC 逐客户非负。

因此旧首次满行构造中“同一个 query 的全部 incoming 一律乘同一 θ”是一个可选约束，不是整行 IC 合法性的必要条件。若保留逐行钱包，可直接要求

    Σ_a (u_i/D_i(a)) A_(i,a) ≤ η_i。

任意客户级接纳都保持这个整行财务合同。全流程费用记 K；无停止时，源总质量 M 满足

    M=Σ_(i,a)A_(i,a) ≤ K
      :=Σ_(i,a)u_i A_(i,a)/D_i(a)。                (PAY)

这一 scalarization 复用旧 `increasing_role_capture_flow.md` §3 的总量代数；本稿没有把它重新称为发现。新自由度是不同信用客户可以选择不同 query/接纳，而不把 IC 本身逐客户重加权。

## 3. 自由路由最小费用的精确 Bellman 公式

对每个实际未覆盖可覆盖客户 x，按 i=m,...,1 定义

    V_i(x)= min_(a∋x) V_(i,a)(x),

    V_(i,a)(x)= [u_i/D_i(a)
                    +Σ_(j∈F_(i,a)(x))V_j(x)]
                  /[1+|F_(i,a)(x)|]。            (BELL)

V_(i,a)(x) 正好是在固定当前 query (i,a) 注入一单位 x 质量，以后任意选择合法含 x 查询时的最小总整行费用。证明从最后角色反向归纳：当前吸收 r 的费用是 r u_i/D_i(a)，每个后继接到 r，可独立选最低成本 V_j；全部相加即 BELL。有限目录保证每个 min 达到。随机化或拆分不能低于最小值；选择达到 min 的查询则同时达到。

不同客户可以独立选自己的最优路由，最后把其 A 汇总。虽然这些选择不同，(SCALAR) 最后仍为每个 (i,a) 一个共同 w，所以各客户最小值相加确实可实现。

定义自由起点价格

    κ_x = min_(1≤i≤m) V_i(x)。                   (FREE)

则每客户一单位质量在任意实际位置、任意含 x 查询起步的最小总费恰为 κ_x。源质量可任意非负实数，线性缩放成立。对任何给定源质量 q_x≥0，最小总费恰为 Σ_x q_x κ_x。

SPE 给 u_i/D_i(a)≥1，所以反向归纳得

    V_i(x)≥1，κ_x≥1。

令 H_i=V_i−1，则有明确的累计原 IC 税式

    H_i(x)=min_(a∋x)
       [(u_i/D_i(a)−1)+Σ_(j∈F)H_j(x)]/(1+|F|)。 (TAX)

终点 H_m(x)=min_(a∋x)[u_m/D_m(a)−1]。TAX 的每项非负，保留真实偏离 slack 一次，没有把捕获后重置当作免费。它不借助较少人数 SPE 或删掉任何原玩家。

## 4. 只用总钱包时，可自由取消 G 并选自由起点

固定任意达到 OPT_m 的合法 m 元组，覆盖 O。令 R=O\C，g=|C\O|。因为 OPT≥W，|R|≥g，净缺口

    δ=OPT−W=|R|−g≥0。

如果只证明总费用 K≤W，不再坚持每角色 K_i≤某个特定 η_i，则可以在 R 上任意取 q_x∈[0,1]、Σ_R q_x=δ。这里 q 只是要付款的净缺口质量；恒等式已经扣了全部实际独有客户 g。无需再给每条子树领一份 g，也无需假设这些取消量与旧 owner-source 钱包相容，因为此处没有使用旧逐行钱包。

用自由起点/自由路由支付 q 后，PAY 及 BELL 给

    δ ≤ K_min(q)=Σ_(x∈R)q_x κ_x。

因此以下是真正充分的一般候选：

    min_{0≤q_x≤1, Σ_R q_x=OPT−W}
            Σ_(x∈R)q_x κ_x ≤ W。                (KAPPA?)

若某个最优 O 满足它，立即有 OPT−W≤W。左端是明确可计算的非循环量：按 κ 从低到高取 δ 质量，等价取消 R 中 κ 最大的 g 质量，末个并列类型可分数取消。单位客户仍是原客户；分数仅用于证明信用，不修改游戏。

**未闭合。** 本文未证明每个一般实例与每个完整 SPE 都有满足 KAPPA? 的最优 O。它可能比 half 强；不能因为左端最小费用有精确递推就宣称费用已由 W 支付。特别地，只知道 κ≥1 的方向完全不足。也不能把每客户的自由最优起点，另当成每个实际角色容量一的 matching。

与旧 NET? 的关系：任何固定 owner/source、固定捕获者 query 路由的完整付款，都是这里可选流程的特例。放弃逐行 η、允许任意 g 取消和自由起点，只使可选总费用更低。反之本稿不保证其最优流程兼容旧 γ/f/η；无需冒称兼容。这不是把同一初始 source-net 钱包重复使用。

## 5. 实际核验与来源边界

`kappa_prices.py` 对现成九类实例，使用规范集合值 BI 生成一个或两个最差叶的完整历史证书，再读取其真实实际前缀菜单。它用 Fraction 算 BELL，并对每个被测试缺失客户、每个起点 query 穷举后续按角色选择的全部 query policy，直接发送单位流，核总吸收 1 及最低费用与 BELL 相同。结果在 `kappa_existing_audit.json`；这些有限实例未否定 KAPPA?，没有一般真值意义，也没有新增单位客户反例。

代码亦保留一次已停止的 `probe_flow_matching.py`。它只检查旧弱匹配一般候选，发现已有 `R-12bf.../direct_cover/` 的等价最小后继压缩与诊断后停止；没有把重复密集样本算作研究进展。
