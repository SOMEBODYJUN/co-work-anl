# 根方向有限探针（非证明）

这些脚本只用于检查明确的一般候选，不是 Q-CAG-HALF 的证明证据，也没有把有限无反例升级为一般结论。

- `tmp_exhaust_theta.py`：小主题/小人数的完整 ordered-outcome Theta 负松弛搜索。
- `tmp_search_theta.py`：随机完整 SPE 路径的 `W + ΣTheta - OPT` 筛查。
- `tmp_local.py`、`tmp_local_all.py`：针对“最优剩余福利单步下降由动态阈值支付”的局部候选探针。

本轮没有将这些脚本作为共享数学资产引用；它们只为后续选择反例或证明义务保留可重放入口。
