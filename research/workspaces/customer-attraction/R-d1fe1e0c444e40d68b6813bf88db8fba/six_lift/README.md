## 完整域投影与精确性

给实际六位会员位 `eta∈{0,1}^6`、比较重数 `d=sum_i t_i∈{0,...,6}`。保留六个四位索引类型的完整 16 格直方图，固定 t 重数等于 d。定义

`gamma(eta,d) = max_hist sum_j L_j * (60 * 第j行逐客户系数)`。

于是对每个真实实例和完整 SPE，有新必要行

`sum_x gamma(eta_x,d_x) + 37823040 K >= 0`。

理由：任一真实客户直方图属于最大化域；十条合法行的非负组合逐客户至多为 gamma，故扩大右端得到必要不等式。各客户的直方图可独立最大化只是扩大域，不要求这些最大值可由同一策略同时实现。

十条权中，固定主题只出现实际 `A,...,F`。因此若先写成 13 固定位 `(A,...,M)` 的图，gamma 与另外七位无关；对七位取最小不会再丢失信息。隐藏最大值只依赖 `(p=A+B, p4=A+B+C+D,d)`，共有 63 个条件态。

每个背景 p 完整检查 `binom(21,15)=54264` 个六元素 16 格直方图；三个 p 共 **162792** 个直方图态。直方图 t=0、t=1 两组分别枚举 compositions(6−d,8) 与 compositions(d,8)，是完整域的双射，不是抽样。所有判号和极值为 Python 整数；新表覆盖全部 448 个 `(eta,d)`。
