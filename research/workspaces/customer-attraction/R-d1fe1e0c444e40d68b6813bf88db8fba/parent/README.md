# 六人联合付款系统与真实末对投影

**六人half仍未闭合。** 本目录保存对一个明确必要条件锥的直接攻击，不把其精确可行点当作原模型SPE反例。

## 真实末对联合投影

固定任意真实源，余 k≥3人，强制合法T后，k−3个中间后继的总会员数为s，最后两名真实后继主题为B,C。源规定者原收益r；实际整局末位收益u_m；共同容量K；源背景p，实际末位背景ℓ。对每客户，当前强制者收益为v=t/(p+t+s+b+c)，零分子取零。

保留三类共同实际末位报价/容量：中间主题合计分别≤(k−3)u_m、(k−3)K，B及C各自≤u_m、K。保留真实C对每个合法Q的末位IC，及该分支B,C的强末对比较

`H≥f_(p+t+s)(Q)+f_(p+t+s)(R)−g_(p+t+s)(Q,R)`。

将全部上界写为 `Σ_x c_j(x,hidden)≤B_j`，对任意非负α_j，令

`ψ(x)=min_hidden[v(x,hidden)+Σ_jα_j c_j(x,hidden)]`。

则一般有效

`r+Σ_jα_j B_j≥Σ_xψ(x)`。

左减右恰为源真IC、Σα_j乘各真非负预算行，以及逐客户最小化余项三者之和。source强制者不被当作强制枝的优化者；B,C才使用自身真实末位/末对条件。中间隐藏仅通过总数s出现，所以完整隐藏最小化有4(k−2)个候选；若新增身份相关中间IC则须重做压缩。

六人实现 `strong_pair_projection.py` 使用全部实际查询、平均比较查询、同索引及异索引强末对。后两种平均分别保留d/m与d(d−1)/(m(m−1))，没有把比较会员位独立化。十四条保存的新行及原始/对偶证书见同名JSON；独立语义审查、字面隐藏词核验和完整有序历史SPE回放见 `../six_difficulty/`。这是明确的一般局部生成器，不是新的全m福利定理，也不认证全球新颖性。

## 联合实验的准确对象

`joint_system.py` 读取旧587行，并把以下信息共用同一组客户变量和K：

- 真实末对联合投影；
- 自由同源再查询，包括在当前联合点上重新分离的十四条切面；
