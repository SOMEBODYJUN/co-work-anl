# 自由联合同源再查询：一般局部证书族与六人分离

本工作没有证明六人或一般 half，也没有构造 SPE 反例。新增内容是把此前固定七权的同源树扩成 34 个任意非负参数的真实行锥，保留同样的两个回复分支及同样的 `16(k−2)^2` 计数消元规模。在既有六人 587 行精确点上，找到并精确重放了 35 条新负余量行。主组合由父方汇总。

## 一般陈述与付款

固定同一份完整历史纯 SPE、任意余 `k≥3` 人的真实源历史 h、源规定者原最终收益 r。实际整局末位收益为 u，实际末位之前负载为 ℓ，共同最大主题大小为 K。任意合法 T,Q，定义同一策略的两条路径

`(h,T,H₁,…,H_(k−3),B,C)` 与 `(h,C,G₁,…,G_(k−3),J,V)`。

第二条再次从**同一个完整 h**出发；源强制者不被假定在强制分支最优。给一名客户写会员位 `t,q,b,c,j,v`，背景 p、中间会员总数 s,s′，记

`z₁=p+t+s+b+c`，`z₂=p+c+s′+j+v`。

生成器 `NAMES` 中每个坐标对应一条真的非负行。将其写为“外部预算减逐客户特征”的形式：

| 坐标 | 外部预算 | 逐客户特征 |
| --- | --- | --- |
| sourceT | r | t/z₁ |
| sourceC | r | c/z₂ |
| price:e，e∈{b,c,j,v} | u | e/(ℓ+1) |
| cap:e，e∈{b,c,j,v} | K | e |
| last1:e，e∈{t,q,b,j,v} | 0 | e/(p+t+s+b+1)−c/z₁ |
| last2:e，e∈{t,q,b,c,j} | 0 | e/(p+c+s′+j+1)−v/z₂ |
| safeB:e，e∈{t,q,c,j,v} | 0 | e/(p+t+s+2)−b/z₁ |
| safeJ:e，e∈{t,q,b,c,v} | 0 | e/(p+c+s′+2)−j/z₂ |
| price:s / price:ss | (k−3)u | s/(ℓ+1) / s′/(ℓ+1) |
| cap:s / cap:ss | (k−3)K | s / s′ |

所有份额零分子按零解释。末位两菜单是精确最佳回复；B、J 的安全查询只使用真实倒二节点以及偏离后至多再有一名后继。价格来自原实际末位对目录主题的精确查询；容量来自同一个 K。`price:s` 为同一系数加权的 k−3 个真实中间主题报价之和，`cap:s` 同理。

对任意非负有理参数向量 θ，令 `Eθ` 是上表特征的加权和，`Bθ` 是预算的加权和，则

`Bθ − Σ_x Eθ(x)`

恰好是上表各真实非负行以 θ 加权的和，因此非负。定义

`Γθ(p,ℓ,t,q)=min_{b,c,j,v∈{0,1}; 0≤s,s′≤k−3} Eθ`，

得到一般合法行

`Bθ ≥ Σ_x Γθ(p_x,ℓ_x,t_x,q_x)`。

加上 `Σ(Eθ−Γθ)` 就是完整非负恒等式。这个论证对任意非负背景及任意合法主题成立，不把不同历史的源收益免费认同。全部中间位仅经 s,s′ 及同价线性成本出现，故完整二元域的消元**精确**等于 `16(k−2)^2` 个候选。扩大域可能不由真实 SPE 实现，只减弱必要行。

原同源七权由 `sourceT=2, sourceC=3/2, last1:q=1, last2:b=1/2, price:j=1/4, price:v=5/12, cap:v=1/12` 精确恢复。本族真正新增自由权、更多跨枝末位查询、倒二安全行及对更多真实主题的共同报价/容量，不声称整棵树首次出现。

## 一个无需大参数表的新切面

在 k=3 时取上述七权改为

`sourceT=24, sourceC=16, price:b=1, cap:j=2, cap:v=4, last1:q=10, last2:b=4`，

其余为零，得到

`40r+u+6K ≥ Σ_x min F`，

其中对 b,c,j,v 取最小，

`F=(24t−10c)/z₁+(16c−4v)/z₂+b/(ℓ+1)+2j+4v+10q/(p+t+b+1)+4b/(p+c+j+1)`。

仍需把有符号分子拆回原单份额，以免在零分母写出无定义表达式。将这条行除以61，在旧587行精确点上取源为实际第4位、T为实际末主题、Q均匀遍历六比较索引，余量恰为 `−5438010682/4635795904065<0`。因此旧587行系统没有蕴含此合法新行；该旧点本身不是 SPE。

## 六人证据及接口

- `compact_cuts.json`：35 条精确合法切面；最大参数分母10000，记录旧587点、每条精确负余量。用于父方共同主LP，避免发现权的巨大分母。
- `free_joint.json`：原35条发现权及首轮诊断。该文件没有 `final`：独立主LP浮点值约0.4149339693，精确原点恢复通过而对偶退化恢复未完成，因此不声称它是精确最优值。
- `free_joint.py`：`make_row(types,m,cut)` 返回完整外部类型系数及 K 列；`rawcut(cut)` 去掉元数据。全部收益在同一实际终局读出，共同 K 不被复制成免费预算。
- `verify_free_joint.py`：不调用优化器，独立从字面双后继数组重建所有34特征，与计数域逐态相等；精确恢复原七权投影，并重新计算35条在全部448个六人外部类型上的系数和旧点负余量。

接口示例：

```python
data = json.loads((payment_dir / 'compact_cuts.json').read_text())
for cut in data['cuts']:
    rows.append(free_joint.make_row(types, 6, free_joint.rawcut(cut)))
```

六人只用来检验一个一般参数族能否提供此前欠缺的信息；目前这35切面不等于共同 half 付款。没有证明本34参数整锥到闭包仍不足，也没有给任意m的主乘子公式。下一义务仍是同其他合法行统一选择非负权，把所有客户余项与共同K列一次支付。
