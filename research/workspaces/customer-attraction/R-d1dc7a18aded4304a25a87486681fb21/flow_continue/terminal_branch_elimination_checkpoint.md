# 末异题分解的跨分支接续检查点

2026-10-24，flow_continue。**没有新的一般容量付款，没有 Q-CAG-HALF 反例。** 以下只精确记录对已有末异题 δ 组件的接续检查，不宣称新颖性、独立外审或一般福利推进。根方收到精确诊断后已重构确认其范围。

## 1. 同一条真实续局内可以合法使用的关系

复用 `menu/review_last_nonB_rigidity.md`。固定任意有序 context 的背景 b、剩余人数 n、其原规定续局及任意合法主题 B。若续局不全为 B，取最后非 B 行动 T，之前尾负载 p、之后 r 个 B。原 IC 及逐客户最坏后继界给

    u_T >= d_B >= G_B，
    G_B = sum_(x in B) 1/(b_x+p_x+r+1)。

因 T 后全部为 B，原叶内有精确差集关系

    sum_(x in T\B) 1/(b_x+p_x+1)
      - sum_(x in B\T) 1/(b_x+p_x+r+1)
    = gamma_T+zeta_T >= 0。

这恰是该原叶中 T 对比较主题 B 的静态偏离不盈利；合法性来自原真实偏离收益 d_B 不低于这个静态值。它不推出 T 对任意其他主题的静态最优性。

原 α−β 分解再加入两份非负分母误差 A、E，得到

    alpha_T-beta_T=A_T+E_T+gamma_T+zeta_T。

若 B 不等于此续局的末题，最后非 B 已经是末位，gamma 是该末位原 BR 的 slack，zeta=0。只有 B 等于末题时，才可能选到更早的 IC；若末两题不同，选到的仍总是倒二。

## 2. 为什么全部这些组件仍不能替代早期 IC

给一个仅用于界定组件信息的显式政策。**该政策不是 SPE，也不作为原目标反例。**

取五名玩家，共同目录由小主题 C 及六个大主题 A_1,…,A_6 构成；七个主题两两不交，|C|=1、|A_j|=3。完整政策在每个有序历史规定：前三位均选 C；第四、第五位各选此前未用过的最小编号大主题。历史最多已有四个行动，故这条规则在全部历史都有定义。

最后两位在每个历史上都是真实最佳回复：指定的大主题未被过去覆盖，也不被后继覆盖，收益为 3；任意其他行动的收益至多其主题大小，因而不超过 3。两位指定大主题总不相同。

现在考察任意 context 的任意比较主题 B。若 B 不等于该自然续局的末题，最后非 B 是末位；若 B 等于末题且还剩至少两位，最后非 B 恰为倒二。因此每份 δ 分解使用的 gamma 都来自上述已经成立的末两位真实 IC，其余三项由原逐客户证明非负。若只剩一位且全选 B，分解不定义，与原引理一致。

还可直接核对有承重意义的后一情形：对 n>=2，T 和 B 是新选的两个不交大主题，b、p 在它们上都为零，r=1，故

    alpha_T=3， beta_T=3/n， A_T=0，
    E_T=3/2-3/n>=0， gamma_T=0， zeta_T=3/2。

但实际政策的叶为 (C,C,C,A_1,A_2)，W=7；五个不同大主题给 OPT_5=15>2W。前三位的实际收益为 1/3，合法改选一个未用大主题后收益为 3，因而其真实 IC 严格失败。

准确结论仅为：**所有有序 contexts、所有 B 的末异题四项非负组件，可同时成立而不控制前三位的真实 IC。** 这里把代数等式及其所选 gamma 非负作为组件约束；没有声称该政策满足原引理的完整 suffix-SPE 前提。这没有否定将该组件与其余完整原 IC 一起使用的证明。尤其不能把此政策叫作 SPE、客户模型反例或 half 反例。

## 3. 跨分支消元没有完成的付款

曾考虑把 B\T 侧的需求转送到 T\B 客户，构造跨末题的有向消元。上面的同枝关系确实允许利润单位的差集比较，但两侧分母分别为 b+p+r+1 与 b+p+1；转成客户数量时没有统一不增质量的规则。更重要的是，不同强制主题所到叶的 b、p、末题及真实换枝收益均可改变。它们的 recipient 不是一个共同后继历史，不能交换，更不能把多份原 gamma 的当前利润各自看成同一份 actual u_i 的独立库存。

尚需的新关系必须实质调用早期、可能互斥的真实 IC，并把多来源的净负载同时压到同一批 actual 钱包。对既有合法净券图，可选择证明某个共同 owner/路由具有全 O 的同角色 cap2；对净遗漏方案，则需共同支付 |R|-|G|=OPT-W，不能只对每个 B 分别给一份 actual 钱包。末异题 δ 本身、已知角色命中界和任意 chi 的归一化代数，目前都没有给出这条跨来源预算。

因此本轮在该精确缺口处停止；不继续制造同一组件的更多示例或阴性扫描。SAFE/CLIP 的非负化和 KAPPA? 的最小费用接口全部保留原来未支付的身份。
