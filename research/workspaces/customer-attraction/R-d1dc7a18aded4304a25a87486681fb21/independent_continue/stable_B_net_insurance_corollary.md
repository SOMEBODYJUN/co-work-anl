# 稳定全 B 实现接口的一条净利润推论

2026-10-24。接续同目录 `stable_B_trigger_blind_review.md` 的独立重构。以下是一条适用于任意人数、任意共同目录与背景的**条件性实现工具推论**，不以扩张结构类为研究目标，不证明一般 Q-CAG-HALF，也不声称新颖性。root收到精确空背景陈述后，独立核出末位复制、总利润和静态最优三步推导，确认该净价式；背景版为本文同一逐客户计算。

## 1. 精确对象

固定任意有限单位客户、有限非空共同目录、任意非负整数背景 b、n>=1 名尾玩家。假设存在 B 满足

    sum_(T\B)1/(b+1) <= sum_(B\T)1/(b+n)  for every T. (H)

令

    M = sum_(x in B)1/(b_x+n).

前文已解析证明：M 恰为全部完整历史纯 suffix-SPE 中的最小首人收益。固定任意一份这样的 SPE，记其首人收益为 h，尾部总利润为 P。定义同背景的最优尾利润

    F_n(b) = max_(T_1,...,T_n)
             sum_(x:c_x>0) c_x/(b_x+c_x),

其中 c_x 为比较 n 元组的负载。F_n(b) 不是含旧背景玩家的覆盖福利；b=0 时才是 OPT_n，并且 P=W。

则

    2P - F_n(b) >= 3(h-M).                            (N)

## 2. 同一静态背景的最优利润预算

令 d_x=(n-1)1_(x in B)。由(H)，在静态背景 b+d 下，每个合法查询 T 的收益都不超过 B 的收益 M：

    sum_(x in T)1/(b_x+d_x+1) <= M.                  (4)

对于任意比较负载 c_x>=1，直接清正分母得

    c_x/(b_x+c_x)
      <= (c_x+d_x)/(b_x+d_x+1),                     (5)

因为右减左的分子为 c_x(c_x-1)+b_x d_x>=0。c_x=0 时左端按0计，右端非负，故(5)仍有效。

右端求和正好是 n 个比较主题及 n-1 个 B 在同一静态背景 b+d 下的查询收益和。由(4)，

    F_n(b) <= (2n-1)M.                               (6)

这里没有把额外查询当成同一终局的实际玩家，也没有跨不同真实分支求和。

## 3. 末位复制首人提供一份共享下界

对任意完整 SPE，每名尾玩家在其实际前缀改 B 的真实保底，至少为 M：此前最多 i-1 人，每个 B 客户的最终负载最多 b_x+n。因此每人实际收益都至少 M。

当 n>=2 时，设实际首主题为 A，实际尾负载为 c_x。末位在自己的真实节点可合法改 A。对 x in A：

- 若实际末位覆盖 x，该客户的偏离后分母仍是 b_x+c_x；
- 若实际末位不覆盖 x，偏离后分母是 b_x+c_x+1。

因为首人覆盖 x，b_x+c_x>=1，故两种情况下的末位查询份额都至少是首人份额的一半：

    1/(b_x+c_x+1) >= 1/[2(b_x+c_x)].

末位最佳回复遂给 u_n>=h/2。这里末位没有后继，所以没有冻结真实未来的问题。其余 n-2 人至少 M，于是

    P >= h+h/2+(n-2)M.                              (7)

合并(6)—(7)，

    2P-F_n(b)
      >= 3h+(2n-4)M-(2n-1)M
       = 3(h-M),

即(N)。n=1 时(H)表示 B 为加权单人最佳主题，故 h=M=F_1(b)，(N)同样成立。零收益及空 B 情况无需除以 M。

## 4. 与一般目标的准确关系

空背景时得到

    2W-OPT_n >= 3(h-M).

因此此前一般保险候选在“全 B 触发实现器满足明确(H)”这个接口下可由三步通用代数直接支付。它不假设任意输入存在这样的 B；一般目录上(H)可能根本没有解。它也不把任意背景的尾利润替换为包含背景玩家的福利。

真正一般保险候选、跨真实枝共同容量及原 half 仍未闭合。若已有文献或旧稿包含这条推论，本页应定位为独立重构而非新结论。

旧 `homogeneous_screen.md` 已经排除零背景满足(H)目录的真正 half 反例；本页没有扩大 half 已证范围。当前推论只准确控制通用稳定全 B 实现器的净保险价，不据此另开结构类或常数优化项目。
