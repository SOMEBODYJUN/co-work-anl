## 可直接用的代数与精确停点

对查询分布 p 令 p_x=P_(T~p)(x in T)，φ_p(b)=Σ_x p_x/(b_x+1)。有限 minimax 精确给

    M_b = max_p min_A φ_p(b+1_A).

同一 b 下，K_b(T,A)=F_b(T)−H_b(T,A)，其中

    F_b(T)=Σ_(x in T)1/(b_x+1),
    H_b(T,A)=Σ_(x in T∩A)1/[(b_x+1)(b_x+2)].

H 是 PSD Gram 核。这不把凹二次势最大元的自响应值变成真正 minimax；已有 R-ab2c6df.../global_proof/quadratic_meta_nash_gap.md 的严格分离继续适用。

实际倒二之前背景为 b'，倒二主题为 B，所以 b=b'+1_B。既有末两人定理及安全值关于背景的单调性给

    u_(m−1),u_m >= theta_2(b') >= v_2(b') >= v_2(b)=M_b.

因此准确剩余义务为

    Σ_(i<m−1)(M_b−u_i)
      <= (u_(m−1)−M_b)+(u_m−M_b).

这只是既有通用工具的直接推论，不是新的 half 承重关系。相同实际主题的玩家利润相等，故重复倒二或末主题的更早玩家也自动过 M_b；任何 LAST 坏点的亏损必须来自其它实际主题。这不控制这些亏损总和。

固定列分布 q，客户边际 q_x=P_(A~q)(x in A)。背景增加一个主题 B 的精确核变化为

    K_b(T,q)−K_(b+1_B)(T,q)
      =Σ_(x in T∩B)[(1−q_x)/((b_x+1)(b_x+2))
                    +q_x/((b_x+2)(b_x+3))].

它只在同一冻结背景比较；真实早期偏离会改变后继末前背景，不能把该式直接沿互斥子树相消。
