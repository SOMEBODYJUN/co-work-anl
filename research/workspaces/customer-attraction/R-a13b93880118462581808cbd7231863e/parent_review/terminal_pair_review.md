# 真实末两主题负载继承：主代理独立审查

审查对象为 `../security/terminal_pair_load_security.md` 的
`CA-TERMINAL-PAIR-LOAD-SECURITY-v1`，2026-10-21。
审查者与发现者是不同内部代理；未做外部同行审查或新颖性认证。

## 关键义务的独立重建

固定实际有序前缀，早期人数 `t=m-2`、逐客户负载 `p_x`，
末两主题 `A,B`，总负载 `c_x=p_x+1_A(x)+1_B(x)`。
在同一实际终局中，早期所有玩家收入从每个客户合计恰为 `p_x/c_x`。
这是一个根路径恒等式，没有借用离轨旧玩家收入。

若 `p_x>=alpha*1_A(x)+beta*1_B(x)` 且 `alpha,beta>=0`、
`alpha+beta=t`，对所有正分母直接相除求和得

`P_early >= alpha*u_A + beta*u_B`。

同一真实末两人子博弈的 `CA-LAST-TWO-FLOOR` 给
`u_A,u_B>=theta(h)`。其证明对每个真实末位最佳回复成立，
故全部离轨历史和任意平局均保留。相加得

`W >= (alpha+1)*u_A+(beta+1)*u_B >= m*theta(h)`。

`theta(h)>=theta_m>=OPT_m/(2m-1)` 是既有全局末位下界，
因此 `m*OPT_m <= (2m-1)*W`，即正文的 `(2-1/m)` 界。
另外 `theta_m>=v_m` 来自有限 minimax 的弱不等式，
所以条件聚合安全值 `W>=m*v_m` 也成立；不调用开放的一般聚合安全桥。

量词与边界核对：`m=2` 给 `t=0,alpha=beta=0`，还原已有两人界；
`c_x=0` 时两端分子全零；重复主题、空主题、零客户均无新增除法。
若一个实际末两主题为空，末两人正保底除非全部主题为空，
因此非零实例中不会产生空行动例外。

## 条件的等价形式与严格扩大

交集 `A∩B` 上要求 `p_x=t`。差集最小负载分别记 `L_A,L_B`，
空差集最小值定义为 `t`；可行 `alpha` 恰在
`[max(0,t-L_B), min(t,L_A)]`，区间非空等价于 `L_A+L_B>=t`。
此检查没有把“主题遗漏A某客户”错误升级为“遗漏全部A客户”。

共同倒二包含条件取 `alpha=t,beta=0`，因此旧同一假设得到更强结论。
四客户例取 `A={0,1},B={2,3},C={0,2},D={1,3}`、实际路径
`(C,D,A,B)`，早期无主题包含任一末两主题，但 `p_x=1`、
`alpha=beta=1`。完整SPE证书见 `../credible_attack/load_dominance_witness.json`。
主代理的 `terminal_pair_review.py` 不导入发现代码或规范求解器，
从85个有序决策历史独立重放255个真偏离，重算四人收益均为1，
`W=OPT_4=4`、局部 `theta(h)=1`。有限见证只证实新条件类确有
超出旧包含条件的可实现路径；一般条件定理来自上面的解析证明。

## 审查发现的限制

正文第4节余项恒等式正确。但其保守充分判据重写为

`P_early >= (m-5/2)*theta(h) + alpha*(u_A-theta(h)) + beta*(u_B-theta(h))`，

由于两个收益差非负，这个**需计算真实P的判据**在 `alpha=beta=0`
最宽，不应称作经参数优化获得的新一般支付机制。
真正新增的机制是负载条件(H)无需另证真实P的安全值预算即能保证它。

不能断言只受负载约束的 `max(alpha+beta)<=t`：
两个末主题不交且早期全覆盖它们时可达 `2t`，空主题还可能使该优化无界。
原定理固定总重 `t`，不受这个问题影响。

**结论：** 对上述精确条件性陈述未发现致命异议；可作为内部独立审查通过的
条件定理保存。一般 `Q-CAG-HALF` 与一般聚合安全桥仍 OPEN，
不由该局部条件提升。下一步需要控制一般真实前缀的支配缺口。
