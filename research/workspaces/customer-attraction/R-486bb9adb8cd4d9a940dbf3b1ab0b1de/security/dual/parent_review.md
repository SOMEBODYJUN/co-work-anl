# 父 security 对全锥 full-push 证书的检查

2026-10-21。检查范围：`verify_group_full_push.py` 与 `group_crosscap_certificate.json`；没有认证一般 FTA。父检查并非外部同行评审。

已重新运行标准库审计并通读实现：43 个有序决策历史，215 个非自身偏离，63 个非空客户兴趣类型。指定策略根0；第二位选首主题相反组最小标签；第三位在第二主题所属组三标签选最小未用标签。重复历史也有确定动作，未强制原模型其他策略匿名。

`own` 用实际完整终局的负载，不给额外查询槽；`insert` 用 1+完整终局负载，恰是本轮质量m背景。`M(a,b,t)` 确实沿实际路径三个不同首次偏离节点分别重放同一策略，不是改换平局。JSON 所有 λ 均引用真实完整有序历史上的合法 Γ 行，均非负；逐 63 类型精确核验

    2c−M_ab−M_ba = Γ^T λ_ab+r_ab,  r_ab>=0.

15 个不同查询对全部覆盖，没有把同组置换当成未验证的策略对称性。6 个对角恒等式以在轨当前偏离 Γ 行之和加自身查询额外负载信用认证；即便该行动等于原行动，零 Γ 行也可直接计算。

故对每个 w>=0, Γw>=0，这一策略的全部交叉 cap 和对角 cap 同时成立。乘以 p_a p_b 并求和才推出全部 p 的 FTA；不是从有限 p 搜索提升。客户有理/整数重数均包括在范围内，实锥推导不改变单位客户博弈的正式输入。

该结论精确范围仍是这一固定完整形式策略及其整个可实现重数锥。它没有排除其他 σ 的 FTA 反例，也没有证明任意 m 的聚合安全值或一般 half。旧该策略全锥已有 W>=3v_3 证书，本次的独立价值是加回偏离者后对全部 p 的统一去相关预算及真实激励分解，不应宣传为新的更强效率常数。
