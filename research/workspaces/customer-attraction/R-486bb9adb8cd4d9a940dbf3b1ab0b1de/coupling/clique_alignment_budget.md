# 共同客户的完全图对齐债：精确 χ 与超出全部环的 K5 障碍

2026-10-21；研究备份。模型严格为 CAG-MODEL：有限单位客户、共同非空有限目录、任意 m、任意全部有序历史纯 SPE 与历史平局。一般 Q-CAG-HALF 仍 OPEN。以下给必要支付不等式及组合表示，不是完整 SPE 可行性刻画，不是根福利定理；尚待 root 独立审查，无外审或新颖性声明。

## 1. 真实行及独立边包络

固定 m≥2、q≥1、L≥2。对族 r∈[L] 固定原同一 SPE 中一个长度 m−2 的有序历史 H_r，及 q 个合法目录主题 Z_i^r。令 F_i^r 是**原策略**在真实历史 H_r+Z_i^r 上的末位回复。历史、主题、菜单项可以重复；不同同计数历史无需同回复。

对每个单位客户 x 记

    b_r = H_r 中覆盖 x 的行动数； z_i^r=1{x∈Z_i^r}；f_i^r=1{x∈F_i^r}；
    a_r=1/(b_r+1)；g_r=1/((b_r+1)(b_r+2))；
    A_r=Σ_i f_i^r/(b_r+z_i^r+1)；K_r=Σ_i z_i^r；C_rs=Σ_i z_i^r z_i^s；
    ℓ_rs=max(0,K_r+K_s−q).

以下下标 x 通常省略。给无向完全图的每条边选一个方向 r→s，该方向仅确定比较行的来源与正系数。对该边，把 q 个真实末节点 H_r+Z_i^r 上查询 Z_j^s、j≠i 的全部 q(q−1) 条 BR 行相加。逐客户系数恰为

    O_rs = (q−1)A_r − (q−1)a_r K_s + g_r(K_r K_s−C_rs).               (1)

故 Σ_x O_rs,x≥0。证明只是把查询项写为

    Σ_i Σ_{j≠i} z_j^s/(b_r+z_i^r+1)
      = (q−1)a_r K_s − g_r(K_r K_s−C_rs)，

其中 1/(b+z+1)=a−gz。其他历史出现的主题只作为当前节点的合法单次查询，不执行那里的续局。

若只保留各族本地状态直方图，则单边 C_rs 最小为 ℓ_rs。独立边上包络为

    E_rs^O = (q−1)A_r − (q−1)a_r K_s + g_r(K_r K_s−ℓ_rs)，            (2)
    E_rs^O−O_rs = g_r δ_rs， δ_rs=C_rs−ℓ_rs≥0。                    (3)

## 2. 完全图的精确联合对齐损失

置 K=Σ_r K_r=tq+s，其中 t=floor(K/q)、0≤s<q。定义

    χ_q(K_1,…,K_L)
      = q·binom(t,2)+s t − Σ_{r<s}max(0,K_r+K_s−q).                 (4)

**CC-CLIQUE-1（精确组合定理）。** 对任何 S_r⊆[q]、|S_r|=K_r，

    Σ_{r<s} (|S_r∩S_s|−ℓ_rs) ≥ χ_q(K_1,…,K_L) ≥0。               (5)

而且对每个整数向量 0≤K_r≤q，上述下界都可达到。因此它是保留本地行数 K_r、允许各族重新排列索引时的精确完全图最小对齐损失。

**证明。** 令 d_i=Σ_r 1{i∈S_r}，则

    Σ_{r<s}|S_r∩S_s| = Σ_i binom(d_i,2)，Σ_i d_i=K。

若 d_i≥d_j+2，把一单位从 d_i 移到 d_j，使 binom 之和减少 d_i−d_j−1>0。因此在所有整数列次数、总和 K 下，最小值是 q·binom(t,2)+s t，恰在列次数为 t 或 t+1 时达到。暂时忽略行数只会减小最小值，故先得到式(5)的第一个不等式。

现在给具有全部规定行数的取等矩阵。令 P_0=0、P_r=Σ_{v≤r}K_v，取

    S_r={ j mod q : P_(r−1)≤j<P_r }。

此处索引可用 0,…,q−1。因 K_r≤q，单行这段中无重复余数，所以确有 K_r 个1。整张矩阵是连续整数 0,…,K−1 的余数分配，故每列恰出现 t 或 t+1 次。式(5)取等。最后每个合法对齐逐对均有 C_rs≥ℓ_rs，取等矩阵的损失之和非负，故 χ≥0。证毕。

取等构造不要求 K_r 相同，不要求源方向相同，也不要求 b_r 相同。若本地固定的是完整有限状态 (z_i^r,f_i^r,其他本地标签) 的直方图，可先给 z=1 指定 S_r，然后把各自该组本地状态任意贴上这 K_r 个位置，其余贴在补集。这样保留 A_r 及全部本地直方图。因此组合精确性仍成立。若额外固定跨族共同索引标签，则该构造未必合法，(5)仍有效但精确性须逐标签组处理。

## 3. 任意真实菜单、任意方向和权重的必要不等式

每条定向完全图边赋预先固定的 λ_rs≥0。对客户 x 令

    w_rs,x=λ_rs g_src(rs),x，ω_x=min_{r<s} w_rs,x。

**CC-CLIQUE-2（真实 SPE 支付）。** 上述任意菜单与非负 λ 均满足

    Σ_x [ Σ_{r<s} λ_rs E_rs,x^O − ω_x χ_q(K_1,x,…,K_L,x) ] ≥0。   (6)

逐客户，式(3)(5)给

    Σ_edges λE − Σ_edges λO
      =Σ_edges wδ ≥ωΣ_edges δ ≥ωχ。

所以方括号逐客户至少为其真实 BR 行加权和。对客户求和，真实行总和非负，推出(6)。这里 λ 不可按客户选择；ω_x 与 χ_x 是对固定 λ 逐客户做合法上包络时出现的系数。零边权自动给 ω=0，q=1 自动 χ=0，重复历史和主题亦不影响真实行。

**精确性范围。** 若对某一客户所有有效权 w_rs,x 都等于 w_x≥0，则其逐客户联合上包络精确等于 Σ λE−w_xχ，取等来自§2。一般不等权仅声称 min-weight 的安全下界，未声称它精确。不同客户各自达到组合最大值，不保证它们能由同一全局目录/完整策略同时实现；必要性不依赖这种同时实现。

## 4. K5 严格超出全部环预算

取 q=2、L=5、每个 K_r=1、b_r=0、λ_e=1，所有十条边都是 O 比较，方向任意。于是 g=1/2、ℓ=0、K=5=2·2+1，式(4)给

    χ_2(1,1,1,1,1)=2·binom(2,2)+1·2=4。                           (7)

每个 S_r 是两个索引中的一个，O 边的缺额就是两端选择相同索引。任意五点二分至少有 binom(2,2)+binom(3,2)=4 条同侧边，2/3二分达到。故精确损失为4g=2。

旧环定理对全 O 简单环在长度奇数时给无权缺额1，偶数时给0。考虑使用任意非负权环预算、且每条 K5 边的总消耗不超过1。若某个奇环上的最小有效归一化权为 y_C，它占用每条环边至少 y_C，所以

    3Σ_C y_C ≤ Σ_C |C|y_C ≤10，因而 Σ_C y_C≤10/3。                 (8)

每条边恰在三角形中出现三次；给每个三角形 y_C=1/3 达到10/3。因此所有这类环预算的最佳总缺额只是10/3，严格小于共同图精确值4。这一论证允许一个环内任意不等权；超过最小权的部分只多消耗边容量，不增加该环的扣除。

还有不依赖“预算打包”表述的严格分离。以非负有理质量混合两种本地状态，每个族都使用相同直方图：

- 质量2/3的类型 X：两个 (z,f) 状态为 (1,1),(0,0)，A=1/2。
- 质量1/3的类型 Y：两个 (z,f) 状态为 (1,0),(0,1)，A=1。

每边独立包络的总数值 E=(2/3)·0+(1/3)·(1/2)=1/6，g总质量=1/2。任何偶环约束非负；任何长度 h≥3 的奇环及任意非负边权 λ 满足

    Σ_e λ_e E−(min_e λ_e)(1/2)
      ≥(h/6−1/2) min_e λ_e ≥0。                                  (9)

因此全部加权环必要式同时通过；而完全图新式的数值为

    10/6−(1/2)·4=−1/3<0。                                        (10)

这些是局部直方图/包络资料的严格分离。它们不是 SPE 实例，当然也不是 Q-CAG-HALF 反例；其意义恰是所有环一致性仍遗漏共同客户的五族容量关系。不能用(10)声称完整策略可行性或福利反例。

## 5. 无法由任何真子图看见的 q+1 族容量债

root 在未读本文时独立审查并指出更直接的全参数分离。取任意 q≥2、L=q+1、全部 K_r=1、全 O 完全图。此时 ℓ_rs=0、ΣK=q+1，式(4)立即给 χ=1。各族选择的 singleton 菜单索引可看作 q 种颜色；q+1 个族必有一对同色，且仅有一对同色可达到。故完整图有正的精确缺额1。

然而该完整图的**任何真边子图**都可同时使全部保留边缺额为零：任选一条被删边 r–s，让其两个端点使用相同索引，其他 q−1 个顶点各用不同的剩余索引。唯一同色点对恰为已删边，所有保留边均为异色。这证明完整图容量债不能由任何真边子图各自的精确包络看到；不是某个选取的环公式太弱。

当 q≥3 时，全部简单环都是 K_(q+1) 的真边子图，因此每个简单环的精确联合缺额都是0，完整图仍为1。也可直接给任意环用至多3种索引相邻异色。旧任意 K 环公式此时同样给0：每条 O 边的 |q−K_r−K_s|=q−2，长度 h≥3 的奇 O 环有 [q−h(q−2)]_+/2=0；偶 O 环本来就无扣除。

若需要像§4那样给出全部局部包络通过而完整图失败的非负有理数据，可固定 b_r=0 并在每族混合两种本地状态：质量1/(q−1)的类型 X 只有命中 z=1 的那一项 f=1，故 A_X=1/2；质量(q−2)/(q−1)的类型 Y 只有某个 z=0 项 f=1，故 A_Y=1。两者都 K_r=1，平均 A=1−1/[2(q−1)]，于是每条边的独立包络

    E_O=(q−1)A−(q−1)+1/2=0。

全部真边子图的精确扣除0，故其必要包络式数值均为0；完整图式为 −(1/2)·1<0。q≥3 给严格超出全部单环的例族；q=2退化为三角奇环。仍须强调这只是辅助局部资料，不是SPE实例。

## 6. 一般带符号图的精确高阶表示

对于任意族交互图 G，D 边表示同索引比较，O 边表示异索引比较。仍记 δ_D=min(K_r,K_s)−C_rs，δ_O=C_rs−ℓ_rs。每个客户的 q 个共同索引可压缩为整数 t_B≥0，B⊆[L] 表示该索引恰被哪些菜单族命中。它们满足

    Σ_B t_B=q，Σ_{B∋r}t_B=K_r，C_rs=Σ_{B⊇{r,s}}t_B。               (11)

反向任意满足(11)的整数 t_B 都可展开成 q 个索引，因此共同对齐的精确加权损失是

    Ψ_G(K;w)=min_{整数t≥0, (11)} [
       Σ_D w_rs (min(K_r,K_s)−Σ_{B⊇{r,s}}t_B)
      +Σ_O w_rs (Σ_{B⊇{r,s}}t_B−ℓ_rs) ]。                          (12)

相应 Σ_x[Σ_edges λE−Ψ_G(K_x;w_x)]≥0 是精确的逐客户重排包络必要式。这里 D 边的独立包络为 E_D=A_r−a_r K_s+g_r min(K_r,K_s)。式(12)是有限整数表示与组合等价，不声称快速求解或全局 SPE 充分性。仅令 t_B 为实数会丢失固定 q 的整数索引一致性；q=2,K_r=1 的全 O 图恰为“把各顶点放到两个索引，最少同侧边权”的问题。

§2用全部图列次数闭合了全 O 完全图的(12)等权情形。对同一族整体取补 S_r→[q]\S_r，会把其每条邻边的 D/O互换且保持缺额；因此可同样处理经一组顶点取补后变为全 O 的完全图，使用变换后的 K_r 或 q−K_r。未声称任意符号完全图都能如此变换。

## 7. 来源、意义和缺口

直接来源是 R-e5d83af532dc495c966f99cf70cda2a2/customer_coupling/cycle_alignment_budget.md 及其 parent_tail/cycle_alignment_independent_review.md 的真实行/独立边包络与任意 K 的精确环损失。新点是：共同客户产生一个**全图索引容量**，环的 Hamming一致性不足；全 O 完全图可用平衡列次数得到任意 q、任意行数的闭式精确损失，不必枚举二元配对。

未闭合的承重桥仍是把这些真实离轨菜单的 ΣA_r 费用与早期真实 SPE 比较共同支付到同一个根实际福利 W。本文没有这种无重复根预算，不改善一般五人福利常数，也没有解决一般半覆盖。其用途是排除把独立菜单或仅环一致性的坏点当成可补全 SPE，以及为更强全树共同类型定价提供闭式列约束。
