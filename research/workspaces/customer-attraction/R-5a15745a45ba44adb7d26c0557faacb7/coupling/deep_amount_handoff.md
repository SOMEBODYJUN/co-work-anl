# 深层跨枝金额耦合：准确停止点

2026-10-24。Q-CAG-HALF 仍 OPEN。本页是可接续义务及已付金额的核对，不把辅助合同视为一般福利进展。

## 1. DEEP-AMOUNT-CAP2 的精确输入

任意 m、有限共同目录与完整有序历史纯 SPE σ。P 为实际根叶。每个分枝 α=(iα,Tα) 的完成叶为 Wα=finishσ(P_<iα,Tα)，同一 cut 允许任意多个合法 forced 主题。对 j<iα≤l 定义

    qα,jl=Σ_{x∈P_j∩(P_l\Wα,l)}1/[cP(x)cWα(x)]。

输入系数 λα,j≥0 满足每个 sender j 的共同金额预算

    Σα:j<iα λα,j p_j(Wα)≤p_j(P)。                 (AMOUNT)

待证的 DEEP-AMOUNT-CAP2 是每个 l 都有

    Σα:iα≤l Σj<iα λα,j qα,jl≤2p_l(P)。           (DEEP?)

本分支没有证明或反驳 DEEP?。末层 cap2 及其 sharpness 的精确来源分别是[父证明](../parent/terminal_amount_cap.md)和[全n完整 SPE 族](amount_cap1_family.md)。已通过的内部审查也只在该范围内。

## 2. 固定策略的最坏请求已可闭式表达，但不证明真值

固定 P、σ、l 后，各 sender 的 AMOUNT 彼此独立。若 p_j(P)>0，则固定该 j 对目标 l 最坏正价为

    p_j(P) max_{α:j<iα≤l} qα,jl/p_j(Wα)。

无合法 α 时取零；p_j(Wα)=0 时该主题 P_j 没有客户，qα,jl=0，不作除零。对 j 求和给该固定完整策略的精确最大金额。父方对既有证书所做有限核验不支持一般真值，本分支不重复或扩大扫描。

末层的 p_j(P)≤2p_j(Wα) 在深层只能免费换成随剩余人数增长的负载比。又因不同 α 的 cWα 不同，不能在同一客户上把每个孩子的 common-prefix 计数各花一次。要恢复常数二，必须新增使用真实后继全部历史 IC 的关系。

## 3. AMOUNT 已支付什么，尚未支付什么

对一份孩子的标准非负 prefix 回推，安全 retained 项加上全部正价恰等于输入 p_j(Wα)。因此 AMOUNT 已经给

    Σα,j λα,j Σl≥iα qα,jl
       ≤ Σα,j λα,j p_j(Wα)
       ≤ Σj p_j(P) ≤ W(P)。

这是全部正价的**总金额**界。DEEP? 若成立，其额外价值是单个角色的钱包系数、以及后续整条 IC 可购买性；它不是新的同 parent 总资金。不能从“单列二”推断原覆盖来源已经进入 AMOUNT。

一般证明仍须共同完成至少两件事：将 OPT 或净遗漏的真实来源在不预付结论的情况下组织成 AMOUNT 输入；以及让 direct、既有 suffix claim、静态拥挤和跨孩子回推使用同一利润库存。多 parent 的 W(P) 也不能各自取一份后再称实际 W。

## 4. 一次解析修复尝试及停止

曾尝试把 sharp 末层族的不同孩子提前，让很多尾玩家复制 T_j，从而让 sender 的 Y_j 收益下降约尾长倍数。若 T_j 只含 Y_j，未占用的 D 会吸引真实末位，所拟复制续局不是子 SPE。若加入 D\X_j 阻挡 D，则 parent 末位的真实偏离 IC 同时限制 Y_j 的大小，原拟大比率消失。

这只是对该明确 DEEP 候选的一次机制检查，不是一般 DEEP? 证明，不是新的结构正面结论，也没有证明某方法不可能。未找到能同时支付“拥挤 sender 客户”与“阻挡替代主题”两部分收入的一般关系，故在此停止。无需再扩固定规模或有限无反例样本。
