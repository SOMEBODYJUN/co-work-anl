2026-10-24。草稿／失败机制记录。Q-CAG-HALF 保持 OPEN；本文没有新的一般正面预算，没有 half 反例，没有保险器。

## 1. 只读到的可靠输入

原模型为有限单位客户、任意有限共同目录、任意单位玩家数 m、全部有序历史纯 SPE，允许空主题、重复及任意历史平局。

`R-d398.../compiler/padded_insurer_repair.md` 的 root-only 编译器是一个真正全树构造：若旧计划只在根有最大 regret Delta，则清分母后新实例的 half 坏差额为 L(OPT_old-2W_old-3Delta)。因而反例候选必须先给出所有正深度孩子均可信的旧计划，并严格满足 OPT_old-2W_old>3Delta；不能只写一条坏终局。

## 2. 直接删去 real 背景的明确失败

这一检查针对精确尝试：保留 PB 的 real/dummy regular 目录及 Fill/Copy/Punish/Greedy 策略，删去 real 块的背景负载，仍要求使用原来的两个充分 IC 条件 (G)、(F)。设一个 real 块有 q 个客户，则真实收益改为

    f(c)=q/c.

dummy 的收益函数仍记 g(c)，只需其随 c 非增，q>0、r>=1、k>=2、t>0。原 Greedy 充分条件 (G) 变为

    g(r)>2f(1)-f(2)=3q/2.

所以 g(1)>=g(r)>3q/2。而原 Fill/Copy 充分条件 (F) 变为

    q=k f(k)>f(t)+(k-1)g(1).

右边严格大于 (k-1)3q/2>=3q/2，矛盾。因此这次直接背景删除不能沿用原证明。结论仅否定这一明确移植；(G)、(F) 是原策略的充分估计，不宣称每个可能修订后的全树策略都必须满足它们。尤其没有证明所有空背景 Fill/Copy 机制不可能。

PB 的背景不是无害的记账：其 q/M 级 real 与 dummy 基础利润近似相同，而拥塞损失只是 q/M^2 级，才可能令 (G) 与 (F) 同时成立。删去 real 背景破坏的正是这组兼容性。加入大量预载玩家则会实际覆盖原客户，不能把这一成本从 W 扣除。

## 3. 一个可用但未完成的跨坐标联动位置

常数三停界已经排除：不交极大花瓣保险，以及根以下策略按多个不交坐标独立执行时的任意多坐标叠加。它没有排除真实 Cartesian 目录中根以下策略依赖联合有序历史。

这种联动唯一具体可见的信用是：末位在多个坐标上各有最佳回复平局时，可由某一坐标的偏离触发另一坐标的最佳回复平局切换。末位自己的每坐标利润不变，但倒二位可在未改动的坐标上失去利润。因而不能用“联合偏离收益等于固定各坐标偏离收益之和”来排除这种策略；模式切换使两个比较使用不同的末位平局。

例如一坐标为两个不交等大 d 的主题 C,D，已固定根 C，倒二选 D。末位选 C 或 D 都获 d/2：前者使倒二获得 d，后者使倒二获得 d/2。另一个坐标的倒二偏离可触发后一回复，给出 d/2 的惩罚幅度。这是对给定末位历史的真实平局计算，不是完整保险。要完成构造，仍须验证倒二位同时改两个坐标、选 C 的分支，以及所有其他联合根分支；尤其有效根幅度必须用 h-M，其中 M=max_B min_suffix U_B，不能用任选两条根收益差。

最直接将这一信用用于支持一个本来不可信的“低根惩罚”不交银行分支，尚未降低真正 half 成本。给出计算以固定停止点，而非报告已实现候选：

- 第一坐标银行 A 大小 a，B 大小 b，b>a，拟取根 A、倒二 A、末位 B；末位 B 真实最优。倒二规定收益 a/2，改 B 后末位可选 B（两银行各先有一位时，b/2>a/2），从而得到 b/2，regret 为 (b-a)/2。
- 第二坐标 C,D 大小同为 d，拟取根 C、倒二 D、末位 C；用末位 D 平局惩罚第一坐标偏离，最多可付 d/2，因此至少要 d>=b-a。
- 这只支付一个倒二比较。根 floor 和其他联合比较没有闭合，不能称整个孩子为 SPE。即使只按此叶记账，第二坐标增加实际覆盖 2d；把“惩罚幅度 d/2”视为免费信用会漏掉实际利润池。

下一份值得检验的候选必须把上述平局切换放进一个完整递归状态域，而非只列实际叶及几个 pair 比较。本轮未找到这样的状态域，因此没有运行参数扫描、没有尝试通过扩大旧锥来替代可信性证明。

## 4. 身份与下一步

这里没有新增适用于全部输入的福利关系；第2节仅是明确移植失败，第3节仅定位一种未被独立坐标停界覆盖的真实响应自由度。一般 half、root-only robust 不等式，以及自由 Mpath 的共同支付仍未解决。

若继续攻击根修复，需要完整正深度计划满足旧 gap>3Delta；若继续改保险，需要完整 H 和各根最低续局的有效幅度 h-M，并证明 D=2W_H-OPT<3(h-M)。只算同一根高低终局、把 PB 子树称为根反例、或依靠末位局部表，均不足以满足这两个合同。
