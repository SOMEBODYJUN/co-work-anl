# 早期逐人机会缺口：探索备份

研究对象仍为一般 Q-CAG-HALF。此目录不含已证明的新一般定理；2026-10-21 正在攻击候选 `OPT_m-W<=m u_i`。它若逐人成立，求和给 half；不能把候选当已有引理。

还测试更强的合法背景版本：固定任意 s 名旧玩家留下的实际主题负载，不要求这些旧动作曾最优，剩余 r 名构成完整 SPE，m=s+r，欲有 `OPT_m<=W(all)+m u_first`。W 为所有旧/新玩家的覆盖，而非剩余利润。

- `count_policy_attack.py`：每个计数历史选择真实逆向归纳最优动作，构成可展开为全部有序历史的合法纯 SPE；固定完整策略后，对全部非空兴趣类型重新赋非负质量，保留全部后继激励行，最大化逐人缺口。数值 LP 发现不得直接作定理或精确反例。
- `count_m5k6.json`：100 个五人六主题计数策略锥，全比较五主题集、全部实际使用主题目标；未见正浮点缺口。有限指定锥范围不代表任意策略。
- `count_m7k7.json`：七人七主题同类搜索，运行中/完成状态由文件记录数恢复。
- `full_history_attack.py`、`full_m5k7.json`：每个完整有序历史独立随机选一个尚未出现标签，在全类型等质量基点合法；继而固定这棵策略的完整激励锥再赋权。不是匿名平局限制；仍只覆盖抽到的策略。
- `background_attack.py`、`bg_m5r4k6.json`：一位固定旧提供者、四位未来玩家，只有未来的完整激励约束，用于攻击合法背景强化。
- `path_budget_lp.py`、`path_budget_m5.json`：仅保留同一真实路径的逐位置最大负载保底的松弛；不是完整 SPE 计算。五人时位置1--5的 `(OPT-W)/u_i` 浮点上界分别约14.935、12.362、9.674、6.825、4，说明这些下界单独不能支付早期候选；松弛点不是合法策略反例。

下一步：从数值优点恢复有理反例，或寻找一般真实分支的解析支付。根/背景候选都保持 OPEN，不以有限零反例提升。
