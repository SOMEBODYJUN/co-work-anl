# 合法大前缀的二阶归约与整数安全值的方差误差

2026-10-21，Boss2内部security个人推导。原Q-CAG-HALF、真正强/弱聚合安全桥、FF-LEADER和EXTRA-ONE-LEADER均仍OPEN。以下是静态误差界及完整策略的渐近归约；没有将数值阴性提升为一般证明。尚待独立检查。

## 1. 真正整数安全值与自由分数背景：一个显式误差界

固定任意合法客户背景b，余r>=2人，l=r-1。记

    t_r(b)=min_q max_A Σ_(x∈A)1/[b_x+1+l q_x],
    v_r(b)=max_p min_(C∈S^l) E_(A~p) Σ_(x∈A)1/[b_x+1+load_C(x)].

q_x=Pr_(T~q)(x∈T)。v的整数对手组合不观察查询抽样。Jensen已给t<=v。
取达到t的任意q*，将l个整数竞争主题独立抽q*，这是一份合法静态对偶。令lambda_x=b_x+1、mu_x=l q*_x。则

    0 <= v_r(b)-t_r(b)
       <= max_A Σ_(x∈A) l q*_x(1-q*_x)/[lambda_x(lambda_x+mu_x)^2]
       <= (l/4) max_A Σ_(x∈A)1/lambda_x^3.                 (1)

证明完全来自精确恒等式

    1/(lambda+y)=1/(lambda+mu) -(y-mu)/(lambda+mu)^2
                +(y-mu)^2/[(lambda+mu)^2(lambda+y)].

对Y~Bin(l,q*_x)取期望，线性项为零；最后一项不超过Var(Y)/[lambda(lambda+mu)^2]。每个纯查询的iid收益因此至多其分数收益加(1)中相应误差。再用静态minimax对偶v<=max_A E_iid f_C(A)。没有用适应性对手代替整数安全值，也没有声称iid对手最优。

特别地，全部客户背景至少B时，若K=max_A|A|，则

    0 <= v_r(b)-t_r(b) <= (r-1)K/[4(B+1)^3].             (2)

这说明大背景下两个静态值的差是三次小量；它本身不支付任何真实SPE收益。

## 2. 合法背景缩放与二元交叠矩阵

主题标签共K个。兴趣类型T的正整数重数w_T代表不同单位客户。选一个每坐标均正整数的主题计数P，令d_T=Σ_(a∈T)P_a>=1。对整数B>=1，过去历史按P的计数重复B次，故每个类型的背景为B d_T。这是原共同目录的合法前缀；过去行动任意排列，完整续局仍分别按有序历史定义。

强制所有合法主题具有相同的一阶分数大小

    s_a=Σ_(T∋a)w_T/d_T =s.                              (3)

定义非负对称矩阵

    C_ab=Σ_(T∋a,b)w_T/d_T^2.                            (4)

它还满足C_ab<=min(C_aa,C_bb)，且为非负incidence向量的Gram和，因而PSD。不得把任意对称矩阵当成这样的合法C。

对剩r人的任意有序终局z及其中选a的玩家，定义二元成本

    L_i(z)=C_aa+Σ_(j!=i)C_(a,z_j).

逐客户的精确展开给

    u_i^B(z)=s/B-L_i(z)/B^2+R_i^B(z),
    0<=R_i^B(z)<=r^2 U/(B^3 d_min^3),                  (5)

其中U=Σ_Tw_T，d_min=min_(w_T>0)d_T。因为

    1/(Bd+c)=1/(Bd)-c/(B^2d^2)+c^2/[B^2d^2(Bd+c)]

且0<=c<=r。没有将R的符号在比较两条分支时擅自保留；两条R之差可以为负。

所以一份有限完整形式策略sigma若在二元成本游戏中每个非平凡真实偏离都有成本差>=delta>0，则当

    B > 2r^2 U/(delta d_min^3)

时，同一sigma在具有合法过去前缀BP的原CAG子博弈中仍为完整纯SPE。这个充分界偏保守。若某些比较二阶恰平，需要逐一检查更高阶或精确零恒等式；不能直接用非严格二元SPE声称有限B可提升。任意合法过去前缀后的SPE都可逆向补全到根SPE，尽管这个前缀不必位于其实际根路径。

## 3. 真v与分数t的共同二阶值

对整数l>=0，定义一个有限对称矩阵零和值

    tau_l(C)=max_(q∈Delta) min_a [C_aa+l(Cq)_a]
            =min_(p∈Delta) [Σ_ap_a C_aa+l max_b Σ_ap_a C_ab].      (6)

在(3)下，(5)的均匀误差同时给

    t_(l+1)(BP)=s/B-tau_l(C)/B^2+O(B^-3),
    v_(l+1)(BP)=s/B-tau_l(C)/B^2+O(B^-3).              (7)

对t，先对每个q、a作均匀展开，再min_q max_a，符号反转给max_q min_a。对真v，每个查询p的二阶最坏整数背景是最大化其成本；l个竞争主题的成本可分离为l次同一最大列，因此其值正是(6)。也可由(1)及分数展开推出共同二阶式。O常数在固定实例、固定l下有限且不依赖p/q。

这隔离了三个准确的较小义务：

* 原FF-LEADER的一项必要极限条件：每份可严格提升的完整二元成本SPE都应有L_1<=tau_(r-1)。
* 原EXTRA-ONE-TRUE-LEADER的一项必要极限条件：L_1<=tau_r。
* 原首两人真安全桥的一项必要极限条件：L_1+L_2<=2tau_(r-1)。

若在合法(3)-(4)内找到严格相反不等式，并且完整二元策略的全部关键比较具有严格余量，就由(5)-(7)在有限大合法B得到相应真正CAG辅助桥反例。若只找到任意对称矩阵反例，或二元策略存在未处理平局，则仍不是合法CAG反例。这些局部桥即使失败也不自动否定根半覆盖。

## 4. 本轮发现记录及当前承重缺口

`high_background_probe.py`：固定兴趣阶数k、循环轨道初始质量及等大主题，r3..5、K6/7，480完整策略锥；LP最大化L_1-(r-1)sk/K，最高0（浮点误差内）。代码使用未缩放的原始交叠D、实际主题大小S=1，并从实际成本去掉自身S；其目标为cross_raw-(r-1)Sk/K。对应合法P=(1,...,1)的背景有d_T=k，故本文C=D/k^2、s=S/k，且tau_(r-1)(C)=[S+(r-1)Sk/K]/k^2。uniform q给所有行同值，而uniform查询对每列同值，精确认证此tau。因此程序目标只是本文L_1-tau的正数k^2倍。

`nonuniform_background_probe.py`：任意每坐标正的合法P，全部非空类型，约束s_a=1；r3..5、K5/6，共2000固定p/策略锥LP，最大观察L_1-tau_(r-1)=0。交替固定p不是全局优化；生成的二元policy平局未被假定可提升。

`general_pairwise_cone_probe.py`把C扩大为任意非负对称矩阵，尝试定位incidence/PSD限制是否承重。该扩大模型结果只按程序最终输出保存，不是CAG证据。`pairwise_matrix_probe.py`是较慢的集合值穷举前身，手动中断，未宣称完整计数或结论。

下一步不是继续累计阴性样本：直接构造(6)与全部真实二元偏离之间的非负循环支付，或在合法incidence锥内给严格成本反例，并处理所有二阶平局。若二元普遍leader成立，则需要识别CAG三阶及以上兴趣交互如何产生已有逐人v失败；不能从共同二阶式推回原一般leader。
