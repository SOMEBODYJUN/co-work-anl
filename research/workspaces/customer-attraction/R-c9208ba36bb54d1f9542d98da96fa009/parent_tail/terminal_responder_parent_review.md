# 单末位响应交换的父分支定义级审查

审查对象：`../credible/terminal_responder_exchange.md`，2026-10-21版本。
状态：父分支独立推导与发现者精确恒等式一致；另有global分支在只见定理陈述、未见证明时的独立重构。未认证外审或新颖性。此处只提升准确条件下的结果，不提升一般Q-CAG-HALF。

## 审查的精确对象

单位客户、单位提供者、共同有限非空目录、全部有序历史上的原纯SPE，m=k+1>=2。实际主题C_1,...,C_k,D两两不交。对一个指定i和一个指定合法T，偏离Ci到T后，其余早期玩家确实仍各选原主题；只有末位按给定策略改为R。此条件是原策略的真实分支事实，不是把玩家行动强行冻结的新博弈。

令A=Ci，H为其他早期主题并集，U=A∪H∪D。全部出现的实际/离轨历史分别保留，即使两个历史主题计数相同也不识别它们。记真实偏离者收益v_T，真实离轨末位收益v_R；实际末位节点改R收益e_R，离轨末位节点改D收益e_D。三个非负slack为

    S=|A|−v_T， O=|D|−e_R， V=v_R−e_D。

父分支从逐客户定义直接重建：

    3|A|/2−[|T\U|+|T∩A|+|T∩(U\A)|/2]
       = S+O+V+|A\R|/2。

核心抵消是T∩H∩R客户的1/6，分别来自偏离者收益与末位新旧收益差，符号相反；遗漏这一项会使证明错误。H包含早于和晚于i的固定玩家，但所有这些玩家在两个被比较的末位节点均已行动，且在偏离者最终收益中均已计入，因此没有时序偷换。交点和所有收益只在各自真实有序历史评估。

## 全人数条件推论的重构

存在一个最优m元组T_1,...,T_m，对全部i<=k及全部j<=m上述真实分支条件成立。记P=Σ_i|Ci|、L=|D|、W=P+L、O=OPT_m。

对上述恒等式不等式按i,j求和。最优并集在早期覆盖客户上的权为(k+1)/2，在D客户上的权为k/2，在实际未覆盖客户上的权为k。把最优并集与实际覆盖的交集大小分别以P、L上界，得到

    O <= (2+1/k)P+L/2 = F。

实际末位对每个T_j的真实BR比较给查询和≤mL；早期实际覆盖客户查询权1/2，其他客户查询权1。因此

    O <= P/2+(k+1)L = G。

取λ=k(2k+1)/(2(k+1)^2)，两数均非负且λ<1，精确展开

    λF+(1−λ)G = β_k W，
    β_k=(8k²+11k+4)/(4(k+1)^2)，
    2−β_k=(5k+4)/(4(k+1)^2)>0。

故β_k W>=OPT_m，进而2W>=OPT_m。证明对任意k成立；有限k检查只核对实现。

## 量词和范围攻击

- W=0时上述两预算仍合法，直接强制OPT=0；不定义效率比。
- 空主题、重复选择、最优元组中的重复主题均不改变索引求和；不同索引被逐次计入。
- 最优元组只要求存在一个，不能改称每个最优元组均满足响应条件。
- 指定偏离之外的全部子历史仍须由原SPE覆盖，但无需满足响应条件。原SPE在每个历史最优的前提没有放松。
- 不能删除响应条件。早期回复改变时，H在离轨节点变为另一负载，关键1/6抵消不再直接发生；父分支已给有符号响应缺口表示，由发现者在单独稿继续推导。
- 不自动把原无拥挤3/2无限族列为此全交叉假设的例子；只部分局部偏离满足条件。
- 不声称常数锐或一般无拥挤SPE半覆盖。它是有无界人数和目录的明确条件定理。
