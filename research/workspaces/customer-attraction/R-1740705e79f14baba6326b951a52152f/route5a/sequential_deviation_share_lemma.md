# 顺序偏离份额账本（route5a，未闭合一般半覆盖）

日期：2026-10-23；2026-10-24修正遗漏付款接口及相应诊断，L1–L4不变。对象仍为 CAG-MODEL 的任意有限共同目录、任意人数、全部有序历史纯 SPE。本文只保存一个全范围可证关系、一个精确的动态增强形式和该接口的严格缺口；不声称 Q-CAG-HALF 已证。

## 1. 沿实际路径的未覆盖偏离份额

固定一份完整纯 SPE `sigma`，其根终局为 `z=(S_1,...,S_m)`，`U=union_i S_i`，`W=|U|`。在实际长度 `i-1` 前缀 `h_i=(S_1,...,S_{i-1})`，对任意合法主题 `T`，记强制当前人改选 `T`、其余后继仍按同一份 `sigma` 的真实终局为 `z_i(T)`。完整 SPE 的一步最优性给出

```
u_i(z) >= u_i(z_i(T)).
```

若 `x in T\U`，则 `x` 不在任何实际主题 `S_j` 中，因而也不在 `h_i` 中；在偏离枝 `z_i(T)` 中，`x` 至多被当前人和 `m-i` 名后继覆盖。因此当前人的该客户份额至少为 `1/(m-i+1)`。所有客户收益非负，故得到全范围关系

```
(L1)  u_i(z) >= |T\U|/(m-i+1)       (每个 i、每个合法 T)。
```

这保留完整历史依赖后继；没有冻结后继，也没有把离轨收益换成原路径收益。它是一般稿式(3)在最终未覆盖客户上的直接专门化。

任取一个比较元组 `T_1,...,T_m`，逐位置使用各自的偏离，得到

```
(L2)  W >= sum_i |T_i\U|/(m-i+1).
```

比较主题可以按任意排列 `pi` 重新分配给玩家位置，所以更强的可用形式是

```
(L2*) W >= max_pi sum_i |T_{pi(i)}\U|/(m-i+1),
```

最大化由重排不等式实现：把 `|T_j\U|` 较大的主题放在较晚位置。若令 `a_j=|T_j\U|`、`k_x=# {j:x in T_j}`，则未加权缺口为 `L=|C\U|`，而 `sum_j a_j=sum_{x in C\U} k_x >= L`。

## 2. 该关系为什么不能单独推出半覆盖

把 `T_j` 取为最优 `m` 元组时，(L2*) 的通用下界不足以保证足以闭合半覆盖的 `W>=L`。例如形式上有 `m` 个两两不交的未覆盖主题且每个 `|T_j\U|=1` 时，(L2*) 的值仅为

```
1/m + 1/(m-1) + ... + 1 = H_m,
```

而 `L=m`。因此 `H_m<m`（每个 `m>=2`）时，单纯把每个未覆盖客户按最坏分母 `m-i+1` 支付，不能闭合 `2W>=OPT_m`。这只是支付模板的障碍，不是同一目录中的 Q-CAG-HALF 反例；两两不交主题的 SPE 后继理性通常会提供额外信息。

## 3. 可复用的精确动态增强

对每个 `i,T` 和每个 `x in T\U`，令 `q_i(T,x)` 为偏离枝 `z_i(T)` 中在当前人之后仍覆盖 `x` 的后继人数。则没有最坏化的精确行

```
(L3)  u_i(z) >= sum_{x in T\U} 1/(1+q_i(T,x)).
```

(L3) 仍只使用当前节点的真实 SPE 比较，且 `0 <= q_i(T,x) <= m-i`。如果某个后继行动 `R` 满足 `R subseteq T`，则在该同一偏离终局中，当前偏离者在 `T` 上的份额逐客户等于该后继在 `R` 上的份额；因而

```
(L4)  u_i(z) >= u_j(z_i(T))
```

（允许当前主题还有 `T\R` 上的额外客户）。这就是极大主题动态路由证明中“后继归属于同一最大主题时，偏离者继承后继利润”的核心机制。对任意目录，若能在每个偏离枝找到满足 `R subseteq T` 的后继，并且已有递归下界可支付 `u_j(z_i(T))`，则可把 (L3) 的分母从剩余人数预算改成后继的真实利润；若所有后继都不落入 `T`，(L3) 给出直接尾部份额。

任意主题目录没有自动提供这样的闭包分类：后继可与 `T` 部分交叠并带有 `T` 外客户，SPE 只约束其总收益，不能逐客户拆分。正是这一点阻止了把 (L4) 机制直接推广为任意目录的 `2W>=OPT`。

## 4. 条件性接入接口（不提升主命题）

**2026-10-24 勘误。** 原稿把遗漏半额付款误当成 half 的充分支付，且将
`W >= (OPT_m-W)/2` 误写成 `2W>=OPT_m`。后一个不等式实际等价于
`3W>=OPT_m`。L1--L4 不受影响；这里撤回这条推导，不声称原条件在完整
SPE 类中已有反例。发现与独立算术重构见
[`route5a_half_credit_gap.md`](../../R-65d0f88edf3849b39ca5eb79760e970b/full_tree/route5a_half_credit_gap.md)
及该工作区的父方审查。 同期另一组从原式独立重遇同一算术缺口，见 [独立纠错记录](../../R-105f776c3e6d4a22bb7c380c5df8edc7/global_payment/route5a_arithmetic_correction.md)。合并保留两组来源；原证明接口 v1 撤回，下面的净需求条件单列为修正接口 v2，不声称旧条件已有完整 SPE 反例。

准确记 `I=|C intersect U|`、`L=|C\\U|`、`E=|U\\C|`，则
`W=I+E`、`OPT_m=I+L`、`OPT_m-W=L-E`。令排列付款为

```
A_pi=sum_i |T_{pi(i)}\U|/(m-i+1).
```

若仅有旧条件 `A_pi>=L/2`，(L2*) 只能推出
`OPT_m=I+L<=W+2A_pi<=3W`。若某个最优比较元组允许排列满足

```
A_pi >= OPT_m-W = L-E,
```

才可由 `OPT_m-W<=A_pi<=W` 直接得到 `2W>=OPT_m`。这是修正后的
条件性充分接口，未声称它对一般目录恒成立。更强的 `A_pi>=L` 也足够，
但已有完整 SPE 的遗漏量可以超过 W，不能把遗漏全额付款普遍化。

更动态地，若对最优元组的每个位置偏离都能用同一完整策略树上的递归信用
构成付款 P，同时另证 `OPT_m-W<=P<=W`，则同样闭合。只有信用总和至多 W
而没有前一个需求下界，并不足够。目前没有任意目录的全局信用不变量。
此前已记录的最大主题、层级和少最大主题证明使用了额外的 `subseteq` 闭包；
不能由这些范围免费取得一般目录的需求下界。

## 5. 状态和下一步

- (L1)--(L3) 是一般人数、一般目录、全部历史依赖纯 SPE 的全范围可证关系；不依赖有限枚举。
- (L2*) 是对已知前缀利润关系的未覆盖专门化；它精确揭示了“最坏未来分母”支付在多 disjoint optimal topics 上的不足。
- 真正未解的动态义务是：利用偏离枝后继的最优性，把不同主题的 `q_i(T,x)` 份额跨枝聚合，而不冻结后继、不假设静态 PNE、也不要求同负载历史同一平局。
- 两两不交单例的形式 H_m 缺口不能被写成 Q-CAG-HALF 反例；后继改选未占用主题是需要保留的额外机制。
