真正卡点：SPE给每个历史下本人的真实偏离收益比较；它不把离轨后继固定成实际后继，也不把离轨玩家收益与实际玩家收益一一对齐。根总税、逐步非负、静态CCE及纯终局负载校正已有真正反例。三四人证书没有构成可变人数归纳；五人必要条件松弛的2以上最优点没有完整策略，不能作为SPE反例。全树固定策略锥是正确表示，但跨所有m与所有策略的统一非负支付仍未给出；线性span不是非负锥。

本轮比“又试若干小实例”新增的认识是：连把关注对象压到实际与最优这至多2m个主题的比较交换也不是免费步骤；被删的未用主题可对所有人数制造真实威胁，且剪枝能保留OPT同时完全消除低福利。后续如仍用目录缩减，必须保留真实续局闭包或显式支付其激励增益；不能继续假定未用主题无关。
