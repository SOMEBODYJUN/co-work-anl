# 真实反例构造的私有核守卫障碍

范围：Q-CAG-HALF，完整有序历史纯 SPE，全体单位玩家、单位客户、共同目录。这里没有找到主猜想反例。

新增可复用机制见 [private_guard.md](private_guard.md)：若至少 m 个目录主题各有 a 个全目录私有客户、每个主题总大小严格小于 2a，则任一完整 SPE 的任何后续玩家都不会重复一个已经出现的这类主题。证明保留全部离轨历史及任意平局，不是仅检查在轨。

该机制击穿一个显式的二以上伪坏点族：m=7 时九主题、679 客户，拟定路径 B^5 C^2 福利336而最优679；末位比较和实际节点分母保底都可以成立，但任一B玩家有保证至少49的真实偏离，胜过42。参数族越过因子2恰好触发守卫条件。`private_guard_audit.py` 精确重建这些数值和必要行；`private_guard_audit.json` 保存结果。

另存 `two_support_obstruction.py` / `.json`：只从逐实际节点保底与真实末两人税界出发，给五人、六人每种二标签在轨词生成精确有理对偶。五人统一上界15/8、六人137/70；这是限制在轨支持至多二主题的候选过滤结论，仍待独立核查，不改变一般OPEN。七人以后这套必要行不再闭合2，因此不能外推。

下一步：异质目标主题或含三个跨块诱饵，使私有核大小不再统一，并保留真正完整策略；若仍只用同大小不交目标、私有客户只由自身主题覆盖，那么增加诱饵数量本身无法绕过守卫。
