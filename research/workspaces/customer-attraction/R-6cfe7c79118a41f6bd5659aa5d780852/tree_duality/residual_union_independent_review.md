# 27 客户残余并集桥反例的独立审查

2026-10-21；审查者 tree_duality。审查 global_proof/residual_union_bridge_counterexample.md 及其 JSON 输入。**结论：所述反例与全部列明数值正确，可以按明确辅助桥范围提升为内部核验结果。** 这不是主猜想反例。

独立脚本 `independent_residual_review.py` 不导入原审计逻辑、规范模型或求解器。它只读取输入 JSON，将各重数展开成 27 个不同单位客户，直接按主题客户集合与均分定义计算每次终局收益。

1. 六主题覆盖两两不同；七个决策节点全部定义。逐客户核对全部 42 项含自行动比较，各项非负；六个根偏离的真实续局收益全部恰为 6。原稿的 6×6 末位收益表逐项一致。
2. 指定实际路径 A,B，两主题不交，W=13；T,S 与实际覆盖完全不交且彼此不交，故残余并集为14。全21个无序主题对（含重复）枚举确认OPT₂=14，最优对恰为 B,T；B,S；T,S。全部主题对的最大残余为14。
3. 因此 `W≥max_(两主题比较组)|比较并集\C|` 确被否定；“对每个最优比较组要求其残余≤W”也被最优对 T,S 否定。
4. 精确枚举全部5120个末位最佳回复规则，再对每个规则允许全部根最优动作，共得到15584个完整SPE根选择；最小福利为12，并有Q,R路径见证。因此原稿关于最差SPE福利的附带陈述也正确。
5. 私有客户块A、B、T、S分别只接受其对应主题，所以覆盖全部27客户至少需这四主题；四主题又确实足够。不能把实际覆盖与残余最优对的27客户并集误当成合法两主题最优覆盖。

**必须保留的量词边界：** 此例不否定“存在某个最优比较组，其残余≤W”；另外两个最优对 B,T 和 B,S 的残余各只有7。被否定的是最大残余版本或对所有最优组的版本。它也不否定一般半覆盖，因2W=26>14。
