# 自由终局、逐人归一的完整树候选生成器

主目标 Q-CAG-HALF 仍 OPEN。本目录保存工具、实际计算边界与一个辅助桥反例，未获得一般福利定理或主目标反例。

**新阶段认识：** [三人七客户末位克隆反例](terminal_clone_counterexample.md)精确否定逐人候选2u_i≥u_m：实际收益(3/2,2,7/2)，W=OPT=7。`terminal_exact_audit.json`保存完整单位客户实例、全部有序策略及固定锥精确原始/对偶。另一研究员已从单位客户独立重构全部节点，见 `../next_counterexample/terminal_clone_refutation_review.md`；更弱聚合候选尚未反驳。

## Exact interface

固定正整数 m,p，选一个实际玩家 j，归一其收益 u_j=1。若有正客户，则任意实际玩家真实偏离一个主题 T 均至少得到 |T|/m，故 SPE 给 |T|≤m。所有终局的每人收益因而落在 [0,m]；任意非空客户类型的重数也≤m。

每个有序节点 h 和每个玩家 i 设最终收益变量 v_(h,i)，每个行动设一热二元变量 x_(h,a)。每个叶节点的 v 是该完整有序终局上客户重数的线性均分表达式。对每条边使用

    |v_(h,i)−v_(ha,i)| ≤ m(1−x_(h,a))

并对当前玩家 i=|h|（从零计）强制

    v_(h,i) ≥ v_(ha,i)  对所有 a。

选中边的向量递推与全部真实一步偏离恰好编码完整纯 SPE；没有固定计数选择器或截断离轨深度。根动作设0仅使用共同标签置换。比较组合 J 在包含0与不包含0的两类中各取代表；不假定真实最优组合必须包含实际根动作。目标分别为比较覆盖减 W、比较覆盖、末位收益；均归一同一实际 u_j。

这是已有 `tests/audits/cone_attack_joint_milp.py` 完整策略/重数联合方法的目标与归一变体，不声称全新 MILP 方法。变体不固定实际终局路径，保存所有玩家的最终收益，便于攻击 GAP：m u_j≥OPT_m−W，以及末位克隆候选2u_j≥u_m。归一排除了全零实例；全零实例直接满足两条乘法不等式。

## 文件与证据范围

- `full_tree_milp.py`：数值候选生成器。叶、所有离轨节点和任意历史平局均保留。浮点求解器的“最优”和数值上界均不作为证明。
- `milp_m*p*i*.json`：本次固定参数运行，含完整动作映射、数值终止原因和时间。m=4,p=5两类运行很快触及单次40秒上限，不能据此推断数学命题。
- `audit_milp_candidates.py`：从每个完整动作映射重建规范 StrategyCone，重新解固定锥 LP，有理恢复、清分母为单位客户，并分别用独立逐历史比较和规范验证器核验。固定锥有理对偶只认证该锥，不认证联合MILP全局上界。
- `exact_candidate_audit.json`：实际有理实例与完整策略。边界m=1、两主题m=2以及m=3样本通过；未违反 GAP。m=4候选主要退化到共同客户，说明该数值模型的当前搜索信息价值低。
