# 全局证明：静态总偏离宽限接口（Boss8子研究员）

对象始终为CAG-MODEL：任意有限共同目录、单位客户均分、任意m及每份完整有序历史纯SPE。Q-CAG-HALF仍OPEN。本目录仅为个人探索，不提升共享结论。

当前新候选是每个合法主题T的静态总偏离满足`D_T(q)≤(1+1/m)W(q)`。它不是把SPE视为静态均衡；它容许总静态偏离收益超过实际福利。若成立，直接推出一般半覆盖。详见[精确数学笔记](static_allowance_notes.md)。

- [有限样本脚本](scan_static_portfolio.py)：950个指定种子随机实例共5619组终局主题比较未否定候选；最大D/W为1613/1584。有限成功不证明候选。
- [完整策略锥攻击](cone_static_allowance.py)：以规范求解器生成合法完整策略，再在其全部非负重数锥内优化D_T/W；精确整数收益行，数值LP探索，任何失败必须有理重构并逐历史核验。

最低静态CCE福利桥已有另一个Boss团队在攻；本目录不将数值minCCE算例作为新结果。下一步优先攻击静态总偏离宽限，并探索真实克隆前缀树可否支付这个较弱界。
