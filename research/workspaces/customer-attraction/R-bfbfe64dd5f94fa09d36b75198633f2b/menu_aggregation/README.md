## 真正未付的点

对同一 p，实际位置 i 的整尾响应写为 `Y_i(A)`，则 m-1 槽去相关项可写成平均调和势循环单调误差。整尾并非单人行动；合法逐位移植后出现删除当前动作的尾势返还。额外一槽只再提供已知非负插入折扣 `L_i`。本轮没有证明这些互斥离轨叶的返还总额由 `sum_i L_i` 或实际 W 唯一付款。

特别地，移植后的后继历史一般不是后续实际前缀；不能将其直接接到下一行 `R_(i+1)(p)` 做望远镜。SUMmin 的 min 允许另选 A，但本轮也没有构造能利用该自由度支付返还的共同选择器。

同一机制代 m=5，只给条件链 `SUMmin => M_unif<=W/5 => Mpath<=W/5 => OPT_5<=2W`；第一步所需付款尚未证明，所以没有无条件五人结论。按父任务不扩阴性实验；若没有新真实全树付款，可从这里停止。
