# 当前只攻五人 HALF(5)

用户最新明确要求只攻五人，暂停清理与其他数学目标；本对话按此执行，覆盖根AGENTS较早general-only范围约束，但不改变其他会话任务。

精确目标 Q-CAG-HALF-5：有限单位客户N、有限非空共同目录S⊆2^N，恰五名单位提供者按固定顺序观察全部有序历史各选一主题，允许重复、空主题、零客户和任意历史依赖平局。对每个完整纯SPE，证明2W>=OPT_5。这是原Q-CAG-HALF的五人限制；五人仍OPEN。

## 当前主线

旧437行索引系统精确最优仍大于二，不能只调其乘子。最新根最优主题四人真实回复的二值背景信用已有独立系数审计；其尾利润和来自互斥分支，未可替成实际W。

本轮将已有加权近饱和(AP)关系接到这些实际根回复节点：保留全部真正节点、原策略后继，尝试共同约束低根收益导致的饱和和跨枝外流。没有采用逐人安全值加强。

- `ap_binary_pricing.py`：在原根32型联合直方图与二值尾证书上，加入实际/已有离轨节点的AP行，以及每条根最优分支三个真正尾节点的AP行。读取上游代码和冻结输入但不改它们。
- `ap_binary_discovery.json`：运行时生成的浮点全类型列生成状态，含源hash；不是全称福利界、不是游戏或完整SPE反例。若出现二以内候选仍须有理恢复、全类型exact定价及独立审查。

## 继续义务

只接受覆盖全部客户状态的非负证书，或真实单位客户目录与全部历史SPE反例。发现LP的中间目标或有限阴性不能称HALF(5)解决。并行分支本轮已有额度报错，不虚报六路仍在运行；父方直接推导与实现。

## 本轮已发生的核验与转向

GAP5的独立单位客户支付实现回放覆盖全部有序历史，含零客户、空主题、不交私有例与交叠；输出audit_global_cap.json。它只检验实现，解析陈述仍待独立审查。

AP+根二值菜单的列生成已得到二以上的受限原始可行点，未恢复全类型上界证书；加入GAP5后当前浮点对偶也没有使用这些新增行。停止为该系统单纯逼近数值最优，转而补真实根复制中间主题的后继。ap_binary_discovery/global_cap_discovery只作准确恢复记录，不报新上界。

尝试给合法背景主题增加查询及其真实copy分支（legal_background_tail/background_copy_tail）后，当前局部证书的对偶仍用旧行，未产生新的有理证书或五人结论；不扩同一局部系数扫描。
