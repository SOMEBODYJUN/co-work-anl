# 五人：把同一实际利润给出的全目录大小上界接入真实离轨交换

当前目标仅为 HALF(5)，保持原共同目录、单位客户和全部有序历史纯SPE。目标仍OPEN。
本页是一项待独立审查的解析关系及其五人接入；不宣称独立新颖性或福利界。

## 精确关系

固定同一份完整五人SPE sigma，实际路径利润为 u_1,...,u_5。
取任意源角色 j∈{1,...,5}。对任意原策略的合法历史 h，当前尚有 k∈{2,3,4,5}
人行动；旧客户负载为 b_x，当前在此历史的规定续局利润为 u。
对任意两个合法主题 C,D 定义

s_C=Σ_(x∈C)1/(b_x+k)，
F_h(C,D)=Σ_(x∈C∩D)1/(b_x+k)+Σ_(x∈D\C)1/(b_x+1)，
A_k=4(k−1)，a_k=2A_k+k²。

则候选解析结论为

    2F_h(C,D) <= 2A_k u + 5k u_j − (a_k−2)s_C.       (GAP5)

它是一条关于原单位客户重数的线性必要关系：u_j来自同一实际叶，u来自该精确
离轨历史，所有比较保留原sigma后继；没有声称二者属于同一终局。

## 全目录大小上界只支付一次

设 L=max_(T∈S)|T|。任一实际角色 j 在自己的原真实前缀改选最大主题，最终每个
客户负载至多5，故该偏离收益至少L/5；实际SPE比较给 L<=5u_j。
这不是逐人安全值v的加强，只是原分母保底。

在任一上述h，对全部合法T的加权大小有

    Σ_(x∈T)1/(b_x+k) <= |T|/k <= 5u_j/k = U.

因而 U≥s_C。该大小上界可以输入该历史的交换证明；多个行仍需由非负证书统一
组合，不能各次再独立花一份u_j。

## 从真实C分支推导，而非冻结后继

强制当前C，沿原sigma得到余下k−1个真实主题，末主题为P；当前利润v<=u。
令 w_x=1/(b_x+k)，δ=u−s_C>=0，

    d=Σ_(x∈C)(k−c_x)w_x，d_P=Σ_(x∈C\P)w_x。

这里c_x是该真实分支的k位剩余者覆盖数，过去仍为b_x。对有缺席的C客户，
b_x+c_x<=4，所以 d<=4δ。
所有合法后继主题B的加权大小<=U，故

    Σ_(x∈B\C)w_x <= Σ_(x∈C\B)w_x + (U−s_C)。

与旧AP交换证明相同，真实末位收益与当前收益相消C∩P；其C外收益最多k倍加权
大小，C\P项至少5/4倍加权大小。末位真实改D又给

    F_h(C,D) <= v + (k/2)d +(k/2−5/4)d_P +(k²/2)(U−s_C)。

k>=3时，d_P系数非负，用d_P<=d、v<=u、d<=4δ，得到

    F <= s_C + A_k(u−s_C) +(k²/2)(U−s_C)。

k=2时中间后继为空，d=d_P，同一结论成立。代入U=5u_j/k并乘2，即(GAP5)。
零客户、C或D为空、重复行动均不破坏分母正性。源角色可处于实际任何位置，
h可以离轨；完整SPE分别提供两处合法比较，未识别不同有序历史。

## 与旧AP、根32型菜单的关系

旧AP取同一历史的目录大小上界U=u，得到

    2F <= a_k u − (a_k−2)s_C。

(GAP5)以同一实际u_j控制目录上界，右侧的当前利润系数从a_k降为2A_k，
另付5k u_j；两式均保留，不能无条件互称支配。

程序在实际/原已列离轨真实节点加入(GAP5)，并对五条根最优主题回复的真实
尾节点求和。该求和的实际源项为25k u_j，不能误写5k u_j；它在逐客户状态中
是同一实际叶利润的系数，不是假定所有根尾利润相同。
