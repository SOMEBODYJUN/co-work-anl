# extra-slot iid首位候选：本轮独立攻击

对象：任意合法固定背景负载b，r名剩余单位提供者的完整历史纯SPE；候选要求首位真实收益u≥λ_{r+1}(b)，λ_n为同背景静态n人对称iid Nash共同收益。一般候选仍未证、未找到真实反例。保持任意完整历史与任意平局。

## 已有逐人反例不能直接复用

旧34客户三人逐人v3反例的根收益29/3，而λ4=Z4/4≤34/4=17/2<29/3。旧36客户菜单例根收益10，而λ4≤36/4=9。两点只用静态总收益不超过客户总数，不必求iid Nash。因此extra-slot松弛确实避开这两条旧反例。

## 一般r=1与两人等单独收益子类

r=1时首位选择最大f_b(A)=Σ_{x∈A}1/(b_x+1)，而任意2人iid单人期望不超过同分布单独收益，故u≥λ2(b)。

若r=2且全部主题的f_b(A)共同等于K，定义

 h_b(A,B)=Σ_{x∈A∩B}1/[(b_x+1)(b_x+2)]。

逐客户恒等式U_b(A,B)=f_b(A)−h_b(A,B)。令h_min为所有合法主题对的最小值，取实现h_min的主题对的第一端A*。末位所有真实最佳回复都最小化h_b(A*,B)，因此首位偏离A*后恰获K−h_min，任意SPE首位收益至少此数。

对任意分布q与任意n≥2，删除其余n−2个iid玩家逐客户只会提高当前玩家收益，所以n人iid的单人平均收益≤两人iid平均收益=K−E_{A,B iid q}h_b(A,B)≤K−h_min。因此上述两人首位甚至支配每个n≥2的iid平均收益；特别u≥λ3(b)。不使用λ_n随n单调，也不假设某个Nash分布唯一。

独立Fraction检查为`check_equal_standalone.py`；一般依据是上述解析证明，有限回归不替代证明。

## 支持内iid平均真实偏离路线已失败

详见[整数hub族](child/hub_family.md)。最小本轮展示为9主题262客户：hub及8个peripheral；70核心客户分别对应[8]全部4子集，喜欢hub及对应4个peripheral；每个peripheral另24私有客户。

q均匀8个peripheral是静态3人iid Nash，共同λ3=997/24。真实两人游戏中，强制首位选择任意peripheral后，末位唯一最佳回复hub，首位收益83/2=996/24<λ3。因此单用同一iid Nash支持平均root真实偏离不能证明候选。

但首位选支持外hub可得105/2，末位选择任意peripheral。所以这不是extra-slot反例：真实SPE根会选hub。child中给出偶k≥8的完整整数无限族和全部历史策略；其一般证明独立于有限检查。

## 当前承重义务与下一次判别

一般情况必须利用支持外主题。两人候选可进一步降为一个新静态义务：任意固定背景二人PNE至少一侧收益≥同背景λ3。原因是任意真实末位最佳回复映射R的二人势P(A,B)=f_b(A)+f_b(B)−h_b(A,B)沿(A,R(A))→(R(A),R²(A))非减；有限有向周期上的势全相等，周期边反向也最佳回复，故都是二人PNE。如果所有真实首位强制收益均小于λ3，周期中两端也均小于λ3。静态义务尚未证明。

更强可判别候选：任意单向最佳回复B∈BR_b(A)都满足λ3≤max{U_b(A,B),U_b(B,A)}；若成立，直接取最大f_b的A即可。此候选也未证明。仅平均q下的BR关系和KKT(A)不足以直接给所需债务方向，需保留支持外响应或其他真实比较。

一个正确但尚不闭合的静态局部性质：二人PNE(A,B)的经验边际p=(δ_A+δ_B)/2满足，3人iid分布p下各纯行动C收益α_C(p)≤[U_b(C,A)+U_b(C,B)]/2≤(u_A+u_B)/2。不能未经证明把这个特定p下的cap变成全局iid Nash共同值λ3的cap；对称Nash共同值不是一般安全值的替代。

`diagnose_fixed_cone.py`保留旧6主题策略全部43有序历史，63类型与固定均匀4人iid KKT；在记录的9个合法背景中未得到λ4>u1。`diagnose_maximum_standalone.py`仅检查最大单独收益行动配一个真实末位BR是否可能低于λ3，固定少数q切片未得到反例。两者是数值LP诊断，不是一般结论，现已停止扩大扫描。
