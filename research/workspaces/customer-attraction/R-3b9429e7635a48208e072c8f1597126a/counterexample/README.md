# 共享遗漏回复循环：直接反例攻击与停界

## 精确目标与候选机制

攻击原目标自身：在一份覆盖所有有序历史的完整纯策略中，寻找合法非负整数客户重数使`OPT_m>2W`。不把辅助桥失效当目标反例，也不把有限阴性结果当一般证明。

候选机制是既有五主题A/B/T/D/E残余回复循环的共享遗漏块，辅以新鲜不交主题。以任意m的方向设想为：放大BDE和TDE共享客户，令偏离触发拥挤回复，而实际路径保留至少两种主题；若一份完整策略锥内能把共享遗漏变为超过实际覆盖的最优增量，才有真正目标反例。

本次仅作一个具体直接目标攻击：m=5，七标签，初始类型重数`{B:3,T:3,AD:2,AE:2,BDE:8,TDE:8,F:3,G:3}`。规范全集solver给两个最差终局计数`(0,1,1,1,2,0,0)`及D/E交换，种子W=26、OPT=32。

## 实际运行与准确范围

`shared_cycle_cone_attack.py`复用规范`ExactSPESolver`及既有`tests/audits/customer_attraction_strategy_lp.py`，不另造BI或锥核验器。对上述两个终局各重构一份完整策略，分别优化两个预定比较组合。每份策略含全部2801个有序决策历史，1506条不同非零IC行。四个整数端点均由既有独立逐历史逐偏离函数以Fraction核验。

四个端点的OPT/W依次为8/5、7/5、8/5、7/5；原目标均有余量。两项8/5只恢复精确可行原始点，没有恢复精确最优对偶，故不称固定锥上界；另两项7/5对所选比较组合有精确对偶。没有穷尽其他策略、其他比较组合或其他输入，没有任何固定规模或全范围阴性结论。

完整输出、完整策略及原始点无损压缩在`shared_cycle_cone_attack.json.gz`（只作可复现诊断，不提升数学身份）。复现脚本拒绝覆盖已存在输出；重新运行前另选输出名。

## 停止的后续想法

曾考虑把旧437行大于二原始点投影为actual五主题与五个OPT主题，再做BI。读取证书发现64个原子全为`j=1`：若仅保留actual+OPT，原实际遗漏就变成全局私有，直接落入既有全人数私有遗漏定理，因此不能产生目标反例。这个投影未执行；增加旧菜单再计算也没有具体新可信结构，按主会话意见停止，不重启五人模板项目。

## 可接续处

本轮没有新增通用承重关系。潜在真正坏结构仍须同时处理：实际至少两种非等价主题、共享的中间关联遗漏、以及同一完整策略的全部离轨理性。不能继续用全重复单主题路径或仅全局私有遗漏来期望越二。

盲审child-only ROW时核对了一个弱事实：只要最后玩家是真实BR，最终`W≥max_T|T|`，不要求父节点或其他早期玩家最优。若末位实际主题为A而有`|T|>W`，改T保留A∩T上的原份额，失去A\T的旧收益至多`|C\T|`，新增T\C贡献`|T\C|>|C\T|`，从而严格盈利。这里C为实际最终并集。该事实本身不接通half，不另立Claim。

分支至此停止。未继续437行投影或扩大有限规模搜索；给主会话的实质结论是仍无主目标反例及新一般付款关系。
