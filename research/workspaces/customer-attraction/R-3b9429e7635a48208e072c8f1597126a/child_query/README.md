# 真实查询行：精确量词、去重与本轮停界

2026-10-25。本分支只检验一般共同有限目录、任意人数和全部有序历史纯 SPE 的查询行候选。**没有证明新的一般福利界，没有得到候选反例，Q-CAG-HALF 仍 OPEN。** 有限非分离不构成正面证据；本轮已停止继续扩大该类扫描。没有执行 git 或对外消息操作。

## 1. 本轮精确对象

固定原 m 玩家实例的一个有序历史 h，当前位置 i，旧客户负载 b。对每个合法主题 T，在 h 强制当前选 T，以后使用同一份完整历史策略，所得叶为 Z_T；定义

\[
q(T)=u_i(Z_T)=\sum_{x\in T}\frac1{b_x+1+c_x^T},
\]

其中 c_x^T 是该查询分支中当前之后的真实覆盖人数。所有未来行动可随 T 一起改变，不能冻结后继。实际动作 A 对应 Z=Z_A，实际完整终局并集 U、福利 W=|U|；W 包括固定旧覆盖。

任取 m 个合法比较主题 T_1,...,T_m，重复主题对应同一个有序孩子和同一后续策略。令 C=∪_j T_j、O=|C|。原候选 ROW 为

\[
\sum_{j=1}^m q(T_j)\ge O-W.
\tag{ROW?}
\]

在原完整 SPE 的最小实际收益位置，ROW? 与 Σ_jq(T_j)≤m u_i≤W 合用即得 O≤2W。因此证明全部早期实际位置的 ROW? 足以完成原 half；这里只重述条件蕴含，没有证明前提。

父无 IC 强式 RF-ROW? 只要求每个严格孩子 σ|(h,T) 是完整 SPE；父当前规定 A 可以任意，祖先也不要求最优。其查询、实际 Z 和 m 槽比较的其余定义不变。还可以问任意比较长度 q≥1 的加强版，但本轮没有证明它。

已存 [倒二真实查询行](../../R-e05f01e191354b028004b433016ae1c9/penultimate_true_query_row.md) 实际证明 RF-ROW 在倒二位置成立，且任意比较长度均可；末位也成立。不能将单末位去相关直接推广到多个后继。[三人尾部删除返还恒等式](../../R-e05f01e191354b028004b433016ae1c9/three_remaining_decorrelation_residual.md) 的无符号返还已有合法反例；它没有反驳 ROW?、RF-ROW? 或原 half。

## 2. 端点消元与既有来源完全重合

令 R_T 是 h,T 后全部完整孩子 SPE 可实现的终叶集合，

\[
\ell_T=\min_{z\in R_T}u_i(z).
\]

固定实际 A、z∈R_A，记 t=u_i(z)，比较主题次数 d_T（Σ_Td_T=m）。各即时孩子的有序历史子树不交，故最低查询行精确为

\[
\sum_Td_T\ell_T+d_A(t-\ell_A)
=d_A t+\sum_{T\ne A}d_T\ell_T.
\tag{ENV}
\]

实际 A 孩子已经固定为 z，不能删去对角修正 d_A(t−ℓ_A)。RF-ROW? 等价于对全部这些端点证明

\[
W(z)+d_A t+\sum_{T\ne A}d_T\ell_T\ge O.
\tag{RF-END?}
\]

若同时要求父节点是 SPE，只限制到 t≥max_Tℓ_T 的端点；最低旁枝分别拼合即证明该限制充分。非空 h 的这种局部节点表述不自动说明端点可被某份根 SPE 实际到达。

**去重：** 独立审查分支找到这些式子与 [round11/direct/direct_general_working.md §3](../../R-cd789330fc7141299ac491bbb3ffa420/round11/direct/direct_general_working.md) 的 ENV、RF-END? 及父 IC 限制逐项相同。本轮没有新增量词约化成果，也不把它计为一般论证推进。

## 3. 真正尚未付清的金额：一份精确账务表达

下面仅把 ROW? 的缺口写明，是恒等记账，不声称新支付引理。令 M=C\U 是实际遗漏比较客户，B=U\C 是实际比较外覆盖。对每个 x∈M 任取一个覆盖它的比较槽 j(x)。由于旧前缀已经属于 U，这些 x 的 b_x=0。定义

\[
L=\sum_{x\in M}\frac{c_x^{T_{j(x)}}}{1+c_x^{T_{j(x)}}},
\]

以及非负余额

\[
E=\sum_{x\in M}\sum_{\substack{j\ne j(x)\\x\in T_j}}
\frac1{1+c_x^{T_j}}
+\sum_{x\in C\cap U}\sum_{j:x\in T_j}
\frac1{b_x+1+c_x^{T_j}}.
\]

L 是所选 owner 查询分支中，未来玩家在该遗漏客户上所得的总份额；不同客户可能选不同真实分支。由 1/(1+c)=1−c/(1+c) 和 O−W=|M|−|B|，逐客户精确得到

\[
\boxed{\sum_jq(T_j)-(O-W)=|B|+E-L.}
\tag{BAL}
\]

因此真正未付的是 **L≤|B|+E**：要用一份实际比较外覆盖 |B| 和已经在查询行中的 E，支付来自互斥孩子历史的遗漏客户份额总和 L。孩子各自的利润、末位银行或税界不能直接相加后由同一个 W 支付。本轮没有建立该共同支付；BAL 只把 ROW? 改写成准确金额义务。

## 4. 实施过的反例攻击及其限制

[attack_row.py](attack_row.py) 是浮点发现工具：用客户类型线性核计算集合值 BI，给每个即时孩子独立选最低当前收益续局，并保留实际 A 孩子；又把所得完整严格后继策略的所有 IC 保留为 LP 锥、删去父 IC，最小化 RF-END 的行目标。它没有声称只依赖计数的策略能够代表全部有序策略；计数用于保存终叶全集，策略展开仍逐有序历史。

输出 [row_discovery.json](row_discovery.json)、[cone_discovery.json](cone_discovery.json)、[cone_discovery_m5.json](cone_discovery_m5.json)、[empty_cone_discovery.json](empty_cone_discovery.json) 都只是有限浮点非分离记录，没有负命中，无独立精确 LP 证书；不得把这些文件当作定理或无反例保证。重复扫描与旧 round11 的攻击高度相近，故停止扩展。若未来找到负数候选，必须先有理化、展开全部有序历史并精确检查所有孩子 IC，才能认作 RF-ROW 的合法反例。
