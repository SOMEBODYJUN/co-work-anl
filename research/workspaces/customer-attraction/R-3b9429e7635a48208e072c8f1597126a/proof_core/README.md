# proof_core：一般菜单与直接ROW的缺失共享付款

2026-10-25。本个人区只研究一般 Q-CAG-HALF；主目标仍 OPEN。
没有证明一般 half，没有新反例，没有新已证福利常数。

已读根 AGENTS、研究短地图、一般证明稿、模型及失败路线表。
本轮独立考虑了完整根菜单的总利润付款，并与同轮 child_query 的直接 ROW 核对。

## 精确候选及范围

固定原模型、任意完整历史纯 SPE σ、实际终局 z 与实际福利 W。
强制根行动 A 后沿同一 σ 到达 Z(A)，定义含根的 m 槽矩阵

\[
K(T,A)=\sum_{x\in T}\frac1{1+c_x(Z(A))},\qquad
M_{\rm root}=\min_Q\max_T\mathbb E_QK(T,A).
\]

研究过的候选为

\[
M_{\rm root}\le W/m.\tag{RAVG?}
\]

它是一般稿全路径菜单候选 M_path≤W/m 的加强；并非新机制。
已否定的逐人 M_root≤u_1 不推出本候选为假。
同轮 independent_audit 定向查源未找到 RAVG? 的既有直接反例；这不是对其真值的证据。

每一列都是合法 m 槽静态竞争背景，所以已知静态共同目录比较给

\[
\operatorname{OPT}_m\le2mM_{\rm root}.
\]

故 RAVG? 一旦证明即闭合 half；目前没有它的证明。
m=5 代入只得到条件式 OPT_5≤10M_root≤2W，第二个不等式尚未证明。

## 与直接 child-min ROW 的关系

同轮 child_query 使用每个固定孩子的完整 SPE 可实现集合 R_T，
并记当前玩家在该孩子的最小最终利润 ℓ_T。
对实际 A 孩子终叶 z 与比较次数 d（总次数 m），其精确最坏拼合金额为

\[
\sum_T d_T\ell_T+d_A[u_i(z)-\ell_A].
\]

欲以它支付比较覆盖与实际覆盖的净差，这是一个使用真实孩子集合的
直接 ROW 义务，不等同于静态安全值；本区没有证明该义务。

二者不能通过静态比较免费互推。对单一列 y，逐客户恒有

\[
O\le\sum_{j=1}^m\sum_{x\in T_j}\frac1{1+c_x(y)}
+\sum_x\frac{c_x(y)}{1+c_x(y)}.
\]

最后一项属于该同一列 y，其上界是 W(y)。
若 y 是离轨孩子叶，W(y) 没有被实际 W(z) 支付。
同样，“ℓ_T 很低迫使 T 在自己孩子里被多位尾部竞争”
没有给出一份可将不同 T 的孩子尾利润共同搬到实际 W(z) 的预算。
该跨孩子付款才是两种表达都保留的真实义务。

## 有限诊断

临时诊断仅尝试反驳精确候选 RAVG?。
固定随机种子7709，在200个小稠密输入、m∈{3,4,5,6}、4–6标签上，
以规范全集 SPE 求解器构造最差福利终局的完整证书，随后数值求菜单LP。
没有找到反例。它不是一般证明，也不是半覆盖证明；没有将此阴性扩样作为后续主线。
数值LP未作有理证书，因为没有反例需要认证；重复源实现的诊断脚本不作为长期资产保存。

## 当前停界

没有构造出新的跨枝共同信用。单末位去相关、逐人安全保底、
固定实际负载税或仅以同枝匿名性替换跨枝利润均不能填补上述缺口。
若继续，应从新的真实全树关系入手；不应再扩大同式阴性扫描。
