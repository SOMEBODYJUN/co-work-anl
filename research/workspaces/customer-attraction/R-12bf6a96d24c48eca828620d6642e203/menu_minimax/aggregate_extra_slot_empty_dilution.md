# 完整单偏离菜单的额外一槽：强聚合去相关仍被空主题稀释击穿

2026-10-23。Boss9 / menu_minimax 的候选诊断。**一般 Q-CAG-HALF、完整根菜单 Mfull、弱聚合预算仍 OPEN。** 本文不是新 SPE 实例；它复用 Boss10 已保存的 34 客户加空主题完整 SPE，新增的是对「聚合后额外一槽自动消除去相关负债」的精确否定及一般空主题方向公式。父研究者已另做单位客户定义级独立审计，见 `../parent/audit_extra_slot_independent.py` 与其输出（以实际路径为准）。无外审或新颖性声明。

## 1. 原本尝试的更弱一般充分接口

固定任意完整纯 SPE 的实际路径 `z=(a_1,...,a_m)`。对每个实际位置 i 和行动 a，记 `Z_i(a)` 为固定实际前缀、强制第 i 位选 a、其后跟随同一原策略所得的**完整 m 槽终局**；所有旧玩家也包含在内。对主题分布 p 定义

```
D_i(p) = E_(a~p) u_i(Z_i(a)),
G_i^+(p) = E_(a,t iid p) sum_(x in t) 1/[1+c_x(Z_i(a))].
```

真实 SPE 给 `D_i(p)<=u_i`，故 `sum_i D_i(p)<=W`。下面三条必须区分：

1. 强聚合去相关 `sum_i G_i^+(p)<=sum_i D_i(p)` 对每个 p；**本文否定**。
2. 弱聚合预算 `sum_i G_i^+(p)<=W` 对每个 p；**本文未否定，仍是开放候选**。
3. 允许对全部 `(i,a)` 完整菜单列自由混合，取得所有纯查询的 cap 至多 `W/m`；**本文未否定，且比第 2 条弱**。

第 2 条若成立，选择 extra-one 安全值的最优查询 p，每个 `Z_i(a)` 都是合法 m 槽静态背景，所以 `G_i^+(p)>=v_(m+1)(0)`，因而 `W>=m v_(m+1)(0)>=OPT_m/2`。第 3 条也直接给同一充分结论。第 1 条原想提供第 2 条的简单证明，但失败。

## 2. 任意策略菜单的空主题方向公式

目录含空主题 E。任取分布 q，令 `p_e=(1-e)delta_E+e q`，`0<=e<=1`。记

```
D(q)=sum_i D_i(q),
G(q)=sum_i G_i^+(q),
H_E(q)=sum_i E_(t~q) sum_(x in t) 1/[1+c_x(Z_i(E))].
```

空主题作为查询和偏离者都收益为零，但强制空主题后原策略仍会真实续局。直接展开两个独立抽样的四项得

```
D(p_e) = e D(q),
G(p_e) = e(1-e) H_E(q) + e^2 G(q),
D(p_e)-G(p_e)
  = e[D(q)-H_E(q)] + e^2[H_E(q)-G(q)].          (ED)
```

这是任意完整形式策略的代数恒等式，不要求 SPE。若 `H_E(q)>D(q)`，则所有充分小的正 e 都击穿强聚合去相关。`+1` 额外槽仅给二阶补偿，不能自动支付这一阶空主题回复负债。该式不否定弱预算，因为真实激励松弛 `W-D(p_e)` 通常很大。

## 4. 沿实际路径的精确三位置计算

令 `q=delta_2`。各位置强制 2 或 E 后的完整终局及三类值如下。

| 位置 i | Z_i(2) | Z_i(E) | D_i(q) | E 后插入 2 | G_i^+(q) |
| --- | --- | --- | ---: | ---: | ---: |
| 1 | `(2,3,4)` | `(E,0,1)` | 29/3 | 32/3 | 13/2 |
| 2 | `(0,2,1)` | `(0,E,1)` | 32/3 | 32/3 | 7 |
| 3 | `(0,3,2)` | `(0,3,E)` | 67/6 | 67/6 | 7 |
| 总和 | | | 63/2 | 65/2 | 41/2 |

由 (ED)，

```
sum_i [D_i(p_e)-G_i^+(p_e)] = -e+12e^2.
```

取 `e=1/24`，精确得到

```
sum_i D_i(p_e)=21/16 < 4/3=sum_i G_i^+(p_e),
sum_i(D_i-G_i^+)=-1/48.
```

逐位置余量分别为

```
D_1-G_1^+ = -e+(25/6)e^2,
D_2-G_2^+ = (11/3)e^2,
D_3-G_3^+ = (25/6)e^2.
```

因此尾两人的真实正曲率确实存在，但在小 e 下不能消去更早的一阶负债。弱预算在本例有巨大松弛：`W-sum_i G_i^+=32-4/3=92/3>0`。本文不把一个强辅助桥失败称为 half 或 Mfull 反例。

## 5. 父研究者提出的全主题非空加强及独立重构

这一强桥不能靠排除空主题挽救。把上面每种旧客户重数乘正整数 K，再给主题 E 加入一名只喜欢 E 的新单位客户，主题 0,...,5 不吸引该客户，原完整策略不变。所有七个主题现在均非空，单位客户总数为 `34K+1`。

**完整 SPE 保持。** 原策略在全部 57 个决策历史从不选择 E。逐定义核对所选旧行动的旧收益最小为 `29/3`。非 E 偏离的全部比较只是原比较乘 K，新私有客户对此没有贡献。对 E 的偏离收益至多 1，而所选旧行动收益至少 `29K/3`。因此每个整数 `K>=1` 均保留完整 SPE。此证明只使用有限明确策略的精确最小值，不把“微小扰动”当作未经检查的平局稳定性。

对 `p_e=(1-e)delta_E+e delta_2`，新私有客户在每个位置的偏离收益均值为 `1-e`。其完整终局额外查询值是

```
(1-e)[(1-e)/2+e]=(1-e^2)/2.
```

所以三位置合计给正贡献 `(3/2)(1-e)^2`。总余量精确为

```
F_K(e)=K(-e+12e^2)+(3/2)(1-e)^2
      =(12K+3/2)e^2-(K+3)e+3/2.                 (NE)
```

其判别式为 `K(K-66)`；顶点与最小值为

```
e*=(K+3)/(24K+3),
F_K(e*)=-K(K-66)/(48K+6).
```

顶点在 `(0,1)`。因此存在某个 `e in[0,1]` 使强桥严格失败，当且仅当 `K>66`。整数缩放最小值是 `K=67`。固定上文的 `e=1/24` 已经得到

```
sum D_i = 1453/16,
sum G_i^+ = 34879/384,
sum(D_i-G_i^+) = -7/384 < 0.
```

这是 2279 个不同单位客户、七个非空主题、三名单位玩家的完整纯 SPE。实际福利为 `32K=2144`；新增 E 私有客户未被实际路径覆盖。它仍远未反驳弱 `sum G_i^+<=W`。

这一加强由父研究者提出；本侧从完整类型表和动作表独立重构并展开逐单位客户核验，见 `audit_nonempty_extra_slot.py/.json`。父方原始独审不作为本侧代码输入。
