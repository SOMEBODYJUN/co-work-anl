# 任意背景的末位利润证书：精确非负余项与剩余信用义务

2026-10-23。个人探索资产；一般 Q-CAG-HALF 仍 OPEN。本页没有证明一般半覆盖，也没有反驳它。以下是可直接由定义检查的代数分解。

## 对象、来源与身份

固定非负整数客户负载 `b_x`，有 `r>=1` 名剩余玩家面对同一个有限非空主题目录。`b` 可为合法前缀的负载；以下证明甚至不需要其可实现性。客户与玩家仍为单位。实际剩余主题依次为 `A_1,...,A_r`；令

    e_x = sum_{i<r} 1_{x in A_i},
    l_x = 1_{x in A_r},
    P   = sum_x (e_x+l_x)/(b_x+e_x+l_x),
    v   = sum_{x in A_r} 1/(b_x+e_x+1).

利润中零分子项一律定义为零。假设仅为：末位 `A_r` 对实际前缀是最佳回应。所有完整纯 SPE 都满足这一点，早期玩家是否最优暂不使用。

对任意 `r` 个比较主题 `T_1,...,T_r`，令 `d_x=sum_j 1_{x in T_j}`，其同背景剩余利润为

    R_b(T)=sum_x d_x/(b_x+d_x).

令 `F_r(b)=max_T R_b(T)`。现行 `research/current/customer_attraction/two_remaining_tax.md` §6 已有空背景的 `OPT_r <= r v + tau`。以下结论是该末位证书的全背景推广与精确余项重写，不作为新的主目标进展或文献新颖性声明。`rg` 检查现行正文与 Boss10 round5_induction，未找到已经单列的全背景三项余量形式。

## 精确分解

定义三个余项：

    L(T) = sum_{j=1}^r [v - sum_{x in T_j}1/(b_x+e_x+1)],
    K    = sum_x [e_x/(b_x+e_x+l_x) - e_x/(b_x+e_x+1)],
    J(T) = sum_x [(d_x+e_x)/(b_x+e_x+1) - d_x/(b_x+d_x)].

所有涉及零分子的商仍取零。则

    P + (r-1)v - R_b(T) = L(T) + K + J(T).       (1)

`L(T)>=0` 正是同一实际末位节点上分别偏离至 `T_j` 的最优性之和。`K>=0`，因为 `l_x<=1`，且逐客户

    K_x = 0                                      if l_x=1 or e_x=0,
    K_x = e_x/[(b_x+e_x)(b_x+e_x+1)]             if l_x=0 and e_x>0.

`J(T)>=0`，且逐客户的完整边界式为

    J_x = [b_x e_x + d_x(d_x-1)]
          /[(b_x+e_x+1)(b_x+d_x)]                if b_x+d_x>0,
    J_x = e_x/(e_x+1)                            if b_x=d_x=0.    (2)

式 (2) 用到 `d_x` 是非负整数，故 `d_x(d_x-1)>=0`。当 `b_x=d_x=0`，原利润零分子项定义为零，不能直接使用含零分母的第一行。

证明 (1)：把 `L` 的定义展开，用 `sum_j 1_{x in T_j}=d_x` 消去比较主题之和。随后 `K` 把 `sum e/(b+e+1)` 换成实际早期玩家总利润；末位实际利润为 `v`。因此右端恰为 `P+(r-1)v-R_b(T)`。式 (2) 是通分恒等式，以上符号也覆盖空主题、重复主题、零客户与 `r=1`。

特别地，空背景下

    J_x = (d_x-1)/(e_x+1)     if d_x>=1,
    J_x = e_x/(e_x+1)         if d_x=0.           (3)

因此 `J` 同时记录比较组合的重复覆盖，以及实际旧覆盖落在比较组合之外的客户；`K` 记录实际末位没有覆盖的早期客户上的差额。这个分解保留了这些资料，没有把它们丢进一个统一人数系数。

取任一最优比较组合 `T*`，得到一般末位界

    F_r(b)-P <= (r-1)v.                          (4)

若实际最小收益恰为末位，则直接有

    F_r(b)-P <= (r-1) min_i u_i <= P*(r-1)/r.

故此条件下 `F_r(b) <= (2-1/r)P`。没有假设完整 SPE 中末位收益普遍最小。

## 真实末位过高时还缺什么

对一个给定最优组合写 `R*=L(T*)+K+J(T*)`。一般背景 half 的精确剩余支付是

    R* >= (r-1)v-P.                             (5)

如果想证明更强的最小收益候选，则足够证明

    R* >= (r-1)v-r min_i u_i;                   (6)

更强的 `(r-1)min_i u_i` 版本则需

    R* >= (r-1)(v-min_i u_i).                   (7)

本页不把 (5)--(7) 当成已证不等式。这些式子只是明确指出早期真实激励必须支付哪个方向；直接重新排列 (1) 不能给出付款机制。

恰两人的任意背景有一个更强的合法特例：现行两人税定理给 `F_2(b)-P<=g_b(A_1,A_1)`。而

    u_1 >= sum_{x in A_1}1/(b_x+2) >= g_b(A_1,A_1),
    u_2 >= U_b(A_1,A_1) = sum_{x in A_1}1/(b_x+2)
                              >= g_b(A_1,A_1).

第一行是因为另一位每个客户至多新增一单位负载，第二行是实际末位偏离至 `A_1` 的真实最佳回应。因此 `F_2(b)-P <= min(u_1,u_2)`。这只是现行两人税界的推论，不是一般人数的归纳链。

## 69 客户既有完整 SPE 的分解

使用 `R-b6d636d360e14c11aeb4b76415ed422b/parent_review.md` §4 的四人六主题输入。实际路径 `(0,0,0,5)`，收益 `(10,10,10,18)`，`P=48`，`F_4(0)=69`。比较组合可取 `(0,1,2,3)`，覆盖所有69名客户且 `d_x=1`。于是

    v=18,       L=51/2,       K=15/2,       J=0,
    R*=33,      P+3v-F=48+54-69=33.

这里实际前3位的主题0有30名私有客户，均不被末位5覆盖，故 `K=30/4=15/2`。比较四主题在末位前缀的收益分别为 `15/2,13,13,13`，所以 `L=72-93/2=51/2`。强候选 (7) 所需信用为 `3(18-10)=24`，本例的 `R*=33` 足够；这个计算不认证一般候选。完整 SPE 合法性沿用已存在独立审查，本轮脚本只重算本段的单位客户标量。

## 为什么单靠终端证书还不够

现行 `R-b6d.../parent_review.md` §3 的非 SPE 模板取 `r` 个两两不交、大小均为 `K=lcm(1,...,r)` 的大主题，实际前 `r-1` 位按位置选互不交的私有主题，大小 `K/(r-j+1)`，最后一位选大主题。所有真实末层都可最佳回应，早期粗分母保底也满足，但真实早期偏离严格获利。对比较组合取全部大主题，有

    P=K H_r,    F_r(0)=rK,    v=K,
    L=0,        K_term=J=K(H_r-1)/2,
    R*=K(H_r-1).

大 `r` 时它违反 (5)，故 (5) 必须调用早期真实最优性；仅靠末层最优性和各人的粗分母保底不能给出所需支付。这是把既有障碍翻译到本页余项，并非新的完整 SPE 反例。

下一步的实质义务是从同一完整策略的早期真实偏离菜单证明 (5) 的一个非循环充分下界，或改用另一个信用目标。有限样本没有改变这个义务的 OPEN 状态。
