# 最优覆盖的随机等槽交换矩：可变人数、只依(c,d)的合法行

个人一般引理草稿，2026-10-23。它只使用静态 OPT_m 的定义，不是 SPE 福利定理；未记录外审或新颖性。

固定任意真实/比较的 m 槽主题元组 a 和达到 OPT_m 的元组 o（两者都可重复）。客户负载分别记 c_x,d_x∈{0,…,m}。记 A=∪a，O=∪o。

## 1. 全 r 交换不等式

对 r∈{0,…,m}，独立且均匀地选 o 的 r 个槽删除、选 a 的 r 个槽插入。得到一个仍恰有 m 槽的合法比较元组。此操作完全不执行原策略，也不假设任意真实续局可交换。

定义

    Q_r(c)=C(m−c,r)/C(m,r)=C(m−r,c)/C(m,c),
    P_r(d)=C(r,d)/C(m,d),

越界二项式系数按零。Q 是插入槽未覆盖客户的概率；P 是删除槽包含全部 opt 覆盖者的概率。独立性给原 O 客户丢失概率 P_r(d)Q_r(c)，原 O 外客户新增概率 1−Q_r(c)。由 OPT 最优性，取期望得

    Σ_{x:d_x=0,c_x>0} [1−Q_r(c_x)]
       ≤ Σ_{x:d_x>0} P_r(d_x) Q_r(c_x).              (R_r)

右端同时含遗漏客户(c=0)和交集客户(c>0)。若 c+d>m，交集客户右端贡献恒为零，因为任意 r 下无法同时删光 d 个 opt 覆盖者并避开 c 个 actual 覆盖者。

r=m 恢复 E=|A\O|≤|O\A|；r=1 则是平均单槽交换，只由 d=1 的 opt 私人客户支付实际 O 外覆盖的重数。

## 2. 1/r 加权的精确调和行

对 (R_r) 以 1/r 加权，r=1,…,m。两个纯侧系数恰为

    Σ_{r=1}^m [1−Q_r(c)]/r = H_c                 (c≥1),
    Σ_{r=1}^m P_r(d)/r = 1/d                    (d≥1).

交集系数有闭式

    K_m(c,d)=Σ_{r=1}^m P_r(d)Q_r(c)/r
            = C(m,c+d)/(d C(m,c) C(m,d))         (c≥0,d≥1).

因此得到一般合法行

    Σ_{x∈A\O} H_(c_x)
      ≤ Σ_{x∈O\A} 1/d_x + Σ_{x∈A∩O} K_m(c_x,d_x).     (H)

证明 K 闭式：C(r,d)/r=C(r−1,d−1)/d，随后 Vandermonde 求和
Σ_r C(r−1,d−1)C(m−r,c)=C(m,c+d)。当 c=0，K=1/d；当 c+d>m，K=0。

左侧调和恒等式可对 c 归纳：Q_r(c−1)−Q_r(c) 加权求和为1/c；基点 c=0 为零。也可用同一 hockey-stick 恒等式直接求和。

## 3. 逆向 1/(m−r) 行

对 r=0,…,m−1 以1/(m−r)加权，同样得

    Σ_{x∈A\O} [H_m−1/c_x]
       ≤ Σ_{x∈O\A} [H_m−H_(d_x)]
         +Σ_{x∈A∩O} K_m(d_x,c_x).                    (Hrev)

纯侧恒等式为 Σ_{s=1}^m C(s,c)/(s C(m,c))=1/c 和
Σ_{s=1}^m C(m−s,d)/(s C(m,d))=H_m−H_d。

## 4. 实际用途和严格缺口

这些行给最优性在终局 (c,d) 矩上的可变人数表示，可以直接并入 signed ghost 预算的类型比较；它们比只保留 W≤OPT 多出客户负载和 opt 重数的相互限制。

但它们完全是静态覆盖最优性，不使用 SPE 约束，不能独立证明 F(c,d)≤W+E 或 J_c(d)≤2W。一个无SPE的反例是：actual 元组只覆盖一个很小主题，opt 的 m 个必要主题共享巨大实际遗漏块，F 的调和重复信用可任意大。下一步必须把这些交换行和真实早期偏离/后继最优性共同支付，不能只把等式换名成证明。

## 5. 已有全树尾深障碍具体证明这些新静态行仍接不住债

来源：[全树最后若干层的真正可信性仍不能替代早期真实续局](../../R-b6d636d360e14c11aeb4b76415ed422b/common_catalog/global_terminal_depth_obstruction.md)，本文不另称一个新障碍族。

该来源给 m≥2、1≤k<m、K=lcm(1,…,m)，所有主题互不相交。实际早期选择大小 K/r 的私人 E，最后 k 人选不同的 K 客户大主题 T；最优取全部 m 个 T。写 h=H_m−H_k，则类型质量恰为

- A\O：c=1,d=0，总量 Kh；
- O\A：c=0,d=1，总量 K(m−k)；
- A∩O：c=1,d=1，总量 Kk。

来源已经保留原完整树每个最后 k 层有序历史的全部真实最佳回复，以及全部早期实际节点的每主题鲁棒 floor。它不是完整 SPE，真正早期偏离收益被丢失。

把这些类型代入新增 (R_r)，r>0 时 RHS−LHS 恰为

    K(r/m)[m−kr/m−h] ≥0，

因为 h≤m−k。故所有新最优性交换矩都成立；它们是原最优性行的非负平均，无法排除该来源实例。

同时

    F=L=K(m−k/2),
    W+E=K(k+2h),
    F−W−E=K(m−3k/2−2h).

一旦来源的 half 松弛反例条件 m>2(k+h) 成立，这个 signed 预算差更严格地大于 Kk/2。
例如来源冻结参数 m=8,k=2,K=840：W=2703、OPT=6720、E=1023，F=L=5880，故 signed 预算差为2154，而全部新静态行及完整最后两层真实最优性仍成立。

结论十分具体：**把本文的全部静态最优性交换行加到“所有实际早期鲁棒 floor + 全树最后 k 层真实最优性”仍不能支付欠覆盖债。** 这不是对完整 SPE 的反例；缺口正是更早真实偏离收益及其后继为何不能实现最坏拥挤的跨分支中继。本文的矩行可作为额外输入，不能替代这项机制。
