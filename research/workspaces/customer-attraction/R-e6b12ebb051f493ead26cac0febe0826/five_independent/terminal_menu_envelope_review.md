# 末两人菜单消元参数族：独立定义级审查

**状态。** 内部独立代数与量词审查通过。该参数族是任意五人完整历史纯 SPE 的必要条件；本审查没有得到 `OPT_5 <= 2W` 的证书，也没有认证任何 LP 点为完整 SPE。没有运行实验扫描。

**审查对象。** 父方提出的 `S + alpha Z + V/5` 消元接口。输入完全采用 CAG-MODEL：有限单位客户、任意有限非空共同目录、全部有序历史和任意历史依赖平局，允许空题与重复题。审查不假设统计独立、计数匿名策略或有利回复。

## 固定同一个原策略的合法行

固定任意长度三的合法有序前缀 `P`。令其客户负载为 `p_x`，原完整 SPE `sigma` 在此后的真实两题为 `(D,E)`，收益为 `u4,u5`。对任意五个合法比较题 `T_1,...,T_5`（不要求最优，也不要求两两不同），令

`R_j = sigma_5(P,T_j)`。

定义 `U_P(A,B) = sum_{x in A} 1/(p_x+1+1_B(x))`。以下每项分别由第四位或第五位在指定合法有序节点的 SPE 条件给出：

* `S = sum_j [u4 - U_P(T_j,R_j)] >= 0`：第四位在 `P` 查询 `T_j`，跟随原策略的真实 `R_j`。
* `Z = sum_j [u5 - U_P(R_j,D)] >= 0`：第五位在实际节点 `(P,D)` 查询合法目录题 `R_j`。
* `V = sum_{j,k} [U_P(R_j,T_j) - U_P(R_k,T_j)] >= 0`：第五位在节点 `(P,T_j)` 查询合法目录题 `R_k`。`j=k` 项恰为零。

共同目录保证所有跨节点查询合法。重复 `T_j` 的对应原策略回复必须相同，但证明不需要放松这一一致性；和式仍按五个比较索引计数。

## 不依赖菜单的外包络

固定客户，令 `q=p+1`，`d=sum_j 1_Tj`，`ell=sum_j 1_Rj`，`h=sum_j 1_Tj 1_Rj`，`D=1_D`。令 `v4,v5` 表示该客户对实际两位收益的贡献。直接展开得

`S_x = 5v4 - d/q + h/[q(q+1)]`，

`Z_x = 5v5 - ell/(q+D)`，

`V_x = (d ell - 5h)/[q(q+1)]`。

因此对每个**整条和式共同使用**的 `alpha >= 0`，

`Q = S + alpha Z + V/5 >= 0`，

且其逐客户贡献恰为

`Q_x = 5v4 + 5alpha v5 - d/q + ell [d/(5q(q+1)) - alpha/(q+D)]`。

因为 `0 <= ell <= 5`，逐客户有 `Q_x <= g_alpha(x)`，其中

`g_alpha(x) = 5v4 + 5alpha v5 - d/q + max(0, d/[q(q+1)] - 5alpha/(q+D))`。

故 `sum_x g_alpha(x) >= sum_x Q_x >= 0`。方向正确：这是全客户求和后的必要外包络，不声称 `g_alpha(x) >= 0`，也不能在每名客户处各自选择不同的 `alpha` 后宣称仍来自同一个非负 slack 组合。

## 有限断点与全参数族等价

五人长度三前缀给 `p in {0,1,2,3}`，比较题数给 `d in {0,...,5}`，并且 `D in {0,1}`。每个客户的唯一可能折点是

`alpha* = d(p+D+1)/[5(p+1)(p+2)]`。

它处于 `[0,1]`：`d <= 5` 且 `p+D+1 <= (p+1)(p+2)`；最大值一仅可能在 `p=0,D=1,d=5` 取得。

令 `B` 为 `{0,1}` 与上述所有有限参数折点的并集。对固定实际实例，`G(alpha)=sum_x g_alpha(x)` 在相邻 `B` 点之间是线性的。因此全 `B` 上非负即推出 `[0,1]` 上非负。`alpha >= 1` 后全部 hinge 已归零，`G` 的斜率为 `5u5 >= 0`，检查 `alpha=1` 足够。反向包含立即成立。所以

`[for every alpha in B, G(alpha)>=0]` 与 `[for every real alpha>=0, G(alpha)>=0]`

确实等价。这一有限化是参数族本身的精确有限化，不能据此声称所得必要条件已足以证明 half。

## 退化与范围

所有分母至少一；零客户、空题、重复比较题、重复实际题和历史依赖任意平局均无例外。若未来将该接口用于更多前缀长度或不同数量的比较索引，必须相应修改 `p,d` 域、系数五及断点集合。
