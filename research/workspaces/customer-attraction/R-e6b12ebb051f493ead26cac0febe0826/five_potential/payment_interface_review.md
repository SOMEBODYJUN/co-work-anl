# 五人一次末二势缺陷弱付款接口：独立常数复核

2026-10-25。输入为 [CAG-MODEL](../../../../current/customer_attraction/model.md)：恰五名单位玩家、有限单位客户、任意有限非空共同目录、所有有序历史上的纯 SPE，允许重复/空主题及任意历史依赖平局。本页只独立复核既有真实行的组合常数；不是新福利界，也没有证明下述充分付款条件或旧 ONE-GAP。

固定一份完整纯 SPE 的实际叶 `(A,B,C,D,E)`，令

    p=u1+u2+u3,  d=u4,  e=u5,  W=p+d+e,  O=OPT5.
    q=1_A+1_B+1_C.
    Gamma=max_(T,S) Phi(q+T+S)-Phi(q+D+E)>=0.

其中 `Phi(z)=sum_x H_(load_z(x))`。零客户实例不需要作任何比值，以下仍成立。

## 只使用的三条已证输入

1. [真实倒二查询行](../../R-e05f01e191354b028004b433016ae1c9/penultimate_true_query_row.md)式(3)，取五个最优比较主题并用第四人的真实 IC，给

       5d >= O-W+t_q(D) >= O-W+Gamma.

   后一不等式使用下一项的 `Gamma<=t_q(D\E)<=t_q(D)`。这里 `t_q(T)=sum_(x in T) 1/[(q_x+1)(q_x+2)]`。

2. [末二势缺陷](../../R-cd789330fc7141299ac491bbb3ffa420/round13/security/two_tail_envelope_prefix_payment.md)的 TAIL2-GAP：

       0 <= Gamma <= t_q(D\E) <= d/2.

3. [真实前缀利润预算](../../../../current/customer_attraction/fractional_cover_path_budget.md)式(2)，在 `i=5,r=1,tau=5` 给

       O <= (u1+u2+u3+u4)+5e = W+4e.

三条均来自同一实际叶和同一原完整策略，没有冻结回复、改选离轨平局或对多条互斥历史重复收费。

## 独立消元

令 `R=O-W>=0`；非负性因为 `O=OPT5`，而实际叶本身是一个五主题组合。三条输入给

    e >= R/4,
    Gamma <= min(d/2, 5d-R).

因而

    p+Gamma = W-e-d+Gamma
            <= W-R/4 + min(-d/2, 4d-R).

当 `R>=0` 时，右侧两条仿射函数的最小值在 `d=2R/9` 处取得最大值 `-R/9`。故

    p+Gamma <= W-13R/36 = (49W-13O)/36.       (A)

因此 (A) 在本页的全部输入域中成立；它没有假定已知 half。

因此，若能对所有五人完整 SPE 另行证明

    u1+u2+u3+Gamma >= 23 O/72,                (PAY?, OPEN)

则与 (A) 合并给 `49W>=49O/2`，从而 `2W>=O`。`PAY?` 只是一个充分接口；本页没有证明它，也不声称它由原 half 等价推出。旧 ONE-GAP 使用真正静态安全值 `v5(0)`：`p+Gamma>=3v5(0)`。由于既有 `9v5(0)>=O`，旧候选足以推出 `PAY?`，但本页没有反向蕴含。

## 边界同时紧时的必要条件

在 `W=O/2` 且 (A) 取等时，三条数值输入必须同时紧：

    d=O/9,  e=O/8,  Gamma=O/18,  p=19O/72.

进一步，`Gamma=d/2` 要求 TAIL2-GAP 的逐客户两次上界均取等。因此在 `d>0` 时，第四人所有正收益客户都必须属于 `D\E` 且满足 `q_x=0`：主题 D 与前三主题的并集、以及与 E 均不相交。于是 `d=|D|`。这只是这些既有不等式在该边界同时紧的必要负载条件，没有证明完整 SPE 无法实现或无法逼近它。

## 停界

本页的新增信息仅是独立确认常数 `23/72`、更一般的上界 (A)、以及它们的等号要求。真实前三收益与实际一次 Gamma 的下界仍未获得；这些消元式不能充当其付款。
