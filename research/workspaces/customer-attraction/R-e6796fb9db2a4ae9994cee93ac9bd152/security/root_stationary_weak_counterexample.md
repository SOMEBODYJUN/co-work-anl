# 根回复成员stationary核连弱安全阈值也不能保证

日期2026-10-21。个人研究身份：Boss8团队security研究员，主代理
`R-e6796fb9db2a4ae9994cee93ac9bd152`。本页是**旧完整SPE的新辅助桥反例**，
不是新SPE输入，不是否定一般Q-CAG-HALF，也不否定真正强/弱聚合安全值。
发现计算、自足数学推导和定义级精确审计分别说明；无世界新颖性或外审认证。

## 1. 被否定的精确候选

模型为本仓库CAG-MODEL：有限单位客户、有限非空共同目录、m名单位玩家、观察全部
有序历史、重复行动和任意历史依赖平局均允许。给定完整纯SPE策略sigma，根偏离到
主题a后按原策略执行，删除根行动所得真实m−1人尾计数为B(a)。定义根成员核

\[
K(a,b)=\frac{B(a)_b}{m-1}.
\]

取stationary分布pi，即pi K=pi，并将其推到根回复背景上：Q(B(a))累加pi_a。
查询t独立于该分布，收益为

\[
f_B(t)=\sum_{x\in t}\frac1{1+\operatorname{load}_B(x)}.
\]

本页否定“每个完整纯SPE都能通过这个根stationary核获得
max_t E_Q f_B(t)≤W/(m−1/2)”；实例中stationary分布**唯一**，故无法通过
在该核内重选stationary分布修复。不否定允许任意根菜单混合Q的版本。

自足原文为同目录`refined_tax_counterexample.md`。共同主题按(A,B,T,D,E,P)排序，
m=13，客户兴趣类型为：

| --- | ---: |

| T | 1 |

共36客户，实际路径P^10,A,A,B，计数(2,1,0,0,0,10)，十二人收益5/2、末位3，W=33。
合法组合A,B,T,P覆盖全部客户，故OPT13=36，2W−OPT=30。

## 3. 根核、唯一stationary分布及弱失败

从原packet实际后继重新构造的六个真实根尾为：

| 根行动a | B(a)，顺序(A,B,T,D,E,P) |
| --- | --- |
| A | (1,0,1,0,0,10) |
| B | (1,0,0,0,1,10) |
| T | (1,0,0,0,1,10) |
| D | (1,0,0,0,1,10) |
| E | (1,0,0,1,0,10) |
| P | (2,1,0,0,0,9) |

因此K为此六行矩阵除以12。stationary方程可直接解出。写坐标为
(a,b,t,d,e,p)，先由p=(10/12)(1−p)+(9/12)p得p=10/13；再依次有

\[
b=p/12=5/78,\quad a=(1+p)/12=23/156,
\]
\[
t=a/12=23/1872,\quad d=e/12,\quad e=(b+t+d)/12=1/156,
\]

故

\[
\boxed{\pi=(23/156,5/78,23/1872,1/1872,1/156,10/13).}
\]

上述先后唯一确定全部六坐标，且代回总和为1和piK=pi；也可用精确高斯消元，
stationary方程加归一化的秩为6。此K无零列；审计显式检查零列集合为空，
未删除任何状态、未假设正坐标，也未任意选一个非唯一stationary解。

六查询收益按(A,B,T,D,E,P)为

\[
\left(\frac{189}{104},\frac{563}{312},\frac{427}{156},
\frac{401}{156},\frac{791}{312},\frac{350}{143}\right).
\]

唯一最大是查询T，因此指定核cap与弱阈值满足

\[
\boxed{\operatorname{cap}(Q)=\frac{427}{156}
>\frac{33}{13-1/2}=\frac{66}{25},
\qquad\text{差}=\frac{379}{3900}>0.}
\]

这个差是静态不观察查询的指定分布下的精确数值；不把它误解成真实玩家可以隐藏查询。

## 4. 反例准确止步处：任意根菜单混合已能修复

允许在六个根回复背景上选任意概率时，取根标签权重

\[
q=(1/6,1/3,0,0,1/3,1/6).
\]

其六查询值恰为

\[
(73/36,29/12,29/12,29/12,29/12,305/132).
\]

cap=29/12<33/13，甚至满足强支付。反向查询分布
p=(0,5/18,7/18,1/6,1/6,0)对六个根尾的期望都恰为29/12，故根菜单
受限minimax值精确为29/12。这里给出匹配原始/对偶只是刻画本有限实例。

真正v13更不被否定：合法静态背景(A,B,T,P^9)对全部六查询的值为
(5/2,3/2,3/2,5/2,5/2,5/2)，故v13≤5/2，W−13v13≥1/2。
根stationary核失败不推出任意根菜单混合失败，不推出全部实际节点菜单混合失败，
也不推出不限制背景的真正聚合桥失败。

## 5. 审计和继续方向

本目录`audit_root_stationary_weak.py`不导入规范solver、原作者构造器或本目录探索LP；
仅读取旧packet，逐单位客户精确重建全部上述数值，冻结结果为
`root_stationary_weak_audit.json`。root另以不读取此计算代码的标准库程序独立重建
完整SPE与stationary系统，结果在主工作区`root_review/audit_root_stationary.py`
及其冻结输出，已确认相同pi、cap、弱差及唯一性。

新义务是允许依完整策略和客户数值共同选择任意根菜单或全部真实菜单分布，或者
完全放开静态背景。本反例排除固定根stationarity作为通用弱支付的充分机制；
它没有证明新通用核，也没有完成一般半覆盖。
