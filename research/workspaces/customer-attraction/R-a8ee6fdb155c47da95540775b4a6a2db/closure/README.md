## 节点与域

沿用原模型及同一完整策略。令实际前三主题历史为 g，实际前四主题历史为 h。
六个任意比较主题为 T_i，真实比较分支为 `(g,T_i,B_i,C_i)`。

* `R_(0,i,j)=sigma6(g,T_i,B_j)`，限制 i 不等于 j；
* `R_(1,i,j)=sigma6(g,T_i,C_j)`，全部 i,j；
* `Z_e=sigma6(h,R_e)`。

每个旧客户型记录实际六位 `a`、比较覆盖重数 `d` 和六个旧词
`(t_i,b_i,c_i)` 的8格直方图。与旧点相同，所有候选旧型的 `d=1`。
这是点的支撑性质，不是定理假设。比较词按字典序展开得到六个有标签的词。
轨道键为 `(family, i_equals_j, word_i, word_j)`；C族对角与异索引始终分开。

对每对有标签回复 e,f，新的真实末位比较为

\[
 \sum_x\frac{z_e(x)-z_f(x)}{a_1(x)+a_2(x)+a_3(x)+a_4(x)+r_e(x)+1}\ge0.
\]

按两族和四索引等号型合成60个原始族。本次逐原子直接计算这条式子，
没有对交叠作独立最大化。空主题、重复、零客户及任意历史平局没有从合法行的域中删除。

## 文件 schema

`joint_atoms_exact.json`：

* `histograms[k]`：旧型元数据；`actual_bits` 为六位0/1串，`d`为比较重数，
  `hist`为八个非负计数、总和为6。
* `groups[k][j]`：第k旧型的第j回复轨道，格式
  `[family, i_equals_j, word_i, word_j]`，每个word是三个0/1位。
* `atoms`：每项有 `hist_index`、等长的确定0/1数组 `R` 与 `Z`、正有理 `weight`。
  数组次序严格对应 `groups[hist_index]`。
* `K`：全图共同最大主题容量；有理字符串。
* `O`、`W`、`strict_half_gap`、`minimum_slack`：精确有理字符串。

所有有理数用 Python `Fraction` 可直接解析的十进制整数或 `numerator/denominator` 串。
未列出的旧型和原子质量为0。发现阶段的浮点状态不作为持久证据保留。
