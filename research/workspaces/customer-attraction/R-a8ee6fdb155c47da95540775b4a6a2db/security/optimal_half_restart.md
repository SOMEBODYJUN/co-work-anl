# 容量二重启的最优有效价格：一个较宽的核付款条件

2026-10-26。**状态：一般有限核代数工具，未闭合六人付款。** 本页不证明六人
`2W >= OPT_6`，不证明安全值聚合，也不声称给出了实际源 reduced-cost 银行。
它严格放宽已有
`R-291a34e2dbf4451aa0115fed89a7729b/candidates/half_restart_absorption.md`
的“满价 `argmax(P/2-g)` 重启点”充分条件：给定同一核和价格后，直接选出容量二
域中的最优重启。二人例使用真实完整 SPE 的回复核，但其价格仅来自可行背景，
不是同一 joint saddle 的价格。尚无独立审查或新颖性认证。

## 1. 精确条件及选择法

令有限非空状态集为 `S`，`T` 为其上的 Markov 核；函数按列向量约定，分布按
行向量约定。给实函数 `P,g,b` 和常数 `gamma`。付款解释时要求 `g <= gamma`，
且 `b >= 0` 是**另外已经筹得、尚未使用**的逐源银行；纯代数不需要这两项假设。
定义随机矩阵

`R = (1/2)(I-T/2)^(-1) = sum_(k>=0) 2^(-k-1) T^k`

以及有效价格

`h = P/2 + R(g+b-P/2)`.

则有精确的最优化结论

`min_{p probability, pT <= 2p}`

`  { (1/2) E_(p,T)[P(B)-P(A)] + gamma-E_p g-E_p b }`

`= gamma-max_A h(A)`.                                      **(OPT)**

取任意 `r` 支撑在 `argmax h`，令 `p=rR` 即达到该最小值。因而

`max h >= gamma`

是容量二域中**存在一份查询分布令边界与查询债可由 b 付款**的充分必要条件。
它不要求 `h` 最大点、`P/2-g` 最大点或重启点满价。

计算时只需求唯一 Bellman 解

`v = (g+b-P/2)/2 + Tv/2,     h=P/2+v`.

无需搜索概率单纯形，也无需固定重启支撑后再尝试配平。

### 证明

对任意可行 `p`，定义 `r=2p-pT`。`r` 逐坐标非负，且总质量为一；反过来每个
概率 `r` 唯一产生 `p=rR`，满足 `p=(r+pT)/2`。因此这是一一对应，并且保留
`pT <= 2p`。

由 `pT=2p-r`，目标准确等于

`gamma-E_p(g+b)+(E_pP-E_rP)/2`

`= gamma-E_r [P/2+R(g+b-P/2)] = gamma-E_r h`.

在全部概率 `r` 上最小化即得 **(OPT)**；取其最大点实现等号。有限状态保证最大点
存在，几何级数保证逆矩阵存在。空主题、自环、重复主题标签和所有平局均不改变论证。

## 2. 多角色的实际银行合同

若有 `m` 个角色，各自拥有 `T_i,P_i,b_i`，共用 `g <= gamma`，则可以各自选择
`p_i=r_iR_i`，得到

`sum_i [E Delta P_i/2 + gamma-E_(p_i)g-E_(p_i)b_i]`

`= m gamma-sum_i max h_i`.                               **(JOINT)**

这是直接可用的**条件性**付款门槛。比如 deleted-slot 的共同静态价格已经合法给出
`OPT_m <= (2m-1)gamma`，并且另有来自同一原策略、同一批真实源的银行合同

`W-m gamma >= -sum_i [E Delta P_i/2 + gamma-E_(p_i)g-E_(p_i)b_i]`, **(BANK)**

那么 `sum_i max h_i >= (m-1/2)gamma` 即推出 half。六人对应 `sum_i max h_i >= 11gamma/2`。
若价格来自 full-slot 质量 `m` 的背景，已知静态界是 `OPT_m <= 2m gamma`，
同一合同需要 `sum_i max h_i >= m gamma`；不能沿用 deleted-slot 的半份放松。

**(BANK) 仍未证明。** 在共享负载记号中，需把 `Cov` 表成同批有符号 swap 源，
并使其 reduced-cost 银行只用一次；`I,G,D` 或额外 `b` 已用过的部分不得再放进去。
本页只把给定银行合同之后的查询选择做到了最优，没有新增这份银行。

同样，`p_iT_i <= 2p_i` 只在选定状态空间中成立。若状态仅记录主题，它只控制主题
边际，**不控制**合并后完整 raw 源原子的容量。要用于 atomwise `theta <= 2 inventory`，
状态必须保存真实源原子身份，或者另证主题投影能合法提升；交换后携带的旧 suffix
不能自动当成该新主题的真实规定 suffix。

## 3. 真回复核中严格放宽旧条件的二人例

共同目录为两个不交主题 `A,B`，分别有两名、一名单位客户。完整二人 SPE 为：
根选 `A`；末位在 `A` 后选 `B`，在 `B` 后选 `A`。前者末位收益一，与复制 `A`
平局；后者选 `A` 收益二，严格最佳。根两种真实收益分别为二、一，故根也严格最优。
全部有序历史只有根及两个末节点，已全部覆盖。

因此真实第一后继核为交换核 `T(A)=B,T(B)=A`。真末位阈值为

`K(A)=1, K(B)=2`.

取 `P=2K`，故 `P(A)=2,P(B)=4`。这检查了 full-slot raw SWAP 的 `P=mu K` 形式，
其中 `mu=2`；**没有**声称该 `mu` 已来自一份已筹资的六人合法 dual。
取可行 full-slot 背景 `(A,B)`。每名客户负载一，故 `t_x=1/2`，

`g(A)=1, g(B)=1/2, gamma=1, b=0`.

这是可行背景价格；没有把它说成最优 joint saddle。此时

`J=P/2-g=(0,3/2)`.

唯一 `J` 最大点为低价 `B`，不存在满价的 `J` 最大点，所以旧充分条件不适用。
但本页有效价格为 `h=(1/2,1)`；选 `r=delta_B` 得

`p(A)=1/3, p(B)=2/3, pT=(2/3,1/3) <= 2p`,

`E Delta P/2=-1/3,      gamma-E_p g=1/3`.

两项准确抵消，且 `max h=gamma`。因此新条件在一个真实 SPE 核上严格宽于旧条件。
这只证明核选择工具的严格性，不把该背景提升成 saddle，也不产生新的六人福利结论。

## 4. 唯一未付义务

六人接入仍必须证明：shared-load 的 `Cov` 能用同一原策略的真实 swap 源及合法
原子库存获得 **(BANK)**，同时保持所选 `g,P_i,b_i` 的共同来源。即使数值上
`sum max h_i >= 11gamma/2`，缺少这个映射也不能报告六人付款。

最优分布、严格放宽及若干有自环的三状态基分布恒等式。它核对公式，不代替以上一般证明。
