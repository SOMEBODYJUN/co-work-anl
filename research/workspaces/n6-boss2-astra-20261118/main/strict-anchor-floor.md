# 三种额外覆盖的严格后手门槛

设六个大小 \(K>0\) 的不交最大锚。锚外不同非空覆盖至多 \(q\) 种。仍保留所有原标签、空覆盖、重复选择、历史依赖和平局。对每份完整纯 SPE 的每个合法有序历史，有以下统一保底：\(q\le3\) 时当前收益至少 \(5K/8\)；\(q\le2\) 时至少 \(2K/3\)。于是分别得到 \(W\ge15K/4\)、\(W\ge4K\)。本工作笔记待非作者核验。

沿 `informed-b/four-extra-maximal-anchors.md` 的证明设 \(J\) 为未在前缀选过的锚集，\(s=|J|\)。对每个前缀向后反推保底 \(g\)，分别取 \(g=5K/8\) 或 \(2K/3\)。强制某新锚后若有复制锚的后手，其同叶收益由归纳直接给强制者至少 \(g\)。在没有复制的分枝，若某个与新锚相交的额外覆盖曾出现两次且最后一次是后手，最后的选择者总收益至多 \(K/2<g\)，矛盾。因此前缀重数 \(m_B\) 给出该交叉覆盖的末叶重数上界 \(\max(1,m_B)\)。

末位时设 \(M=\sum_B m_B\le s-1\)，\(d=\#\{B:m_B>0\}\le\min(q,M)\)。所有新锚的先前折扣之和至多 \(K[d/2+(M-d)/6]\)，逐客户按首层 \(1/2\) 和重复层 \(1/6\) 付费。末位可任选新锚，故保底 \(K(1-[d/2+(M-d)/6]/s)\)。在 \(1\le s\le6\) 存入 \(M=s-1\)、\(d=\min(q,s-1)\) 得其最小值，分别为 \(5K/8\) 与 \(2K/3\)。

非末位时 \(s\ge2\)。若 \(s=2\)，只能是四不同锚后的倒二，新锚的前缀折扣为零，倒二可得 \(K\)。若 \(s=3\)，倒二由原倒二比较得 \(2K/3\)；倒三的过去必为三个不同锚，因此由 `third-from-last-anchor-deficit.md` 的 (1) 得 \(3K/4\)。若 \(s=4\) 且前缀有重复额外覆盖，前缀恰含两个不同旧锚及同一额外覆盖两次，因此只能是倒二。此时新锚的公共折扣总和 \(P\le2K/3\)，因为同一额外主题在其客户上增加两层、每客折扣 \(2/3\)。原倒二均值式 \(K-2P/s\) 给 \(2K/3\)。

其余非末位历史中，若没有重复额外覆盖，则全 \(J\) 的无复制分枝损失上界之和至多 \(qK/2\)，而 \(s\ge4\)。若有重复，则 \(s\ge5\)、\(M\le s-2\)、\(d\ge1\)。沿已证首层和重复层的计费，总和至多 \(K[q/2+(M-d)/6]\le K[q/2+(s-3)/6]\)。相应的平均强制收益下界为 \(K[1-q/(2s)-(s-3)/(6s)]\)。对 \(5\le s\le6\) 代入 \(q=3\) 或 \(2\) 均达到各自 \(g\)。在共同前缀选定符合下界的任一新锚，真实偏离有复制时由归纳付账，没有复制时由该上界付账。原节点最优性完成反推。

作为推论，在这两个目录子类中，在任一合法前缀之后被策略规定的行动不能重复任何已经选过的覆盖，也不会选择空覆盖，因为两者将分别使该行动者至多赚 \(K/2\) 或零。离轨前缀本身依然可以任意包含重复和空选择。此推论可用来约束其它真实偏离的菜单。多个额外覆盖足以破坏完全效率，见 `informed-b/two-extras-efficiency-boundary.md`，它仍满足本界。
