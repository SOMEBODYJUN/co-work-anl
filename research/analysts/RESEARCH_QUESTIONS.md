# 从原文争议派生的专题与模型任务

这些问题来自 `INITIAL_READING.md` 的具体观点分歧，补充原部门分类。分类仍可在进一步历史阅读后改变。下列均为待检验任务，未自动登记为有效因果超边。

| 新的问题分解 | 学习入口 | 应取的观测、核算与模型任务 |
|---|---|---|
| 信用需求不足、风险厌恶供给收缩和旧债续借分别占什么作用？ | Wright2023、张斌2024 | 分借款人/银行/期限取实际融资、报价、申请拒绝和现金流；区分新增生产融资与再融资；比较机制对应的预测 |
| 中央可融资空间、地方可用现金、支出执行和政策乘数分别怎样变化？ | Setser2024、Wright2025、张斌2024 | 建中央地方资产负债及或有损失表，核转移与到账；估计支出的现实去向和时滞；不能把地方收入下降等同中央无融资能力 |
| 为什么政策工具偏向某些受益者，改变路线需要谁作决定？ | Batson2020/2023、Setser2024 | 从政策约束、预算安排和实际受益分组核验；推测的动机单列，政策愿望不能替代实际支出 |
| 预售融资、监管放款、交付与家庭损失如何相互影响？ | Batson2022及其原始引文 | 按项目核资金账户、施工和交付，分别算已付购房款、继续月供、交付缺口和银行暴露；价格与违约率另计 |
| 宏观下行如何经欠款、征收和就业反过来损害私人部门？ | 张斌2026、Wright2025 | 企业应收、政府付款、税费和非税分组；识别一次性征收与经常收入，建立企业现金与就业传导任务 |
| 全国非税下降来自中央一次性收益基数还是地方征收变化？收入与支出是否同向？ | Wright2026与财政部2025原发布及发布会 | 拆中央/地方、税收/非税/土地、经常/一次性与本级/转移；用实际支出、融资及拖欠核接口，不能用全国总量替代地方机制 |
| 政府投资和居民转移在不同阶段哪种更能阻断负反馈？ | 张斌2024/2026、Wright2026、Batson2020 | 给定同额净资源，比较到账速度、闲置资源、进口泄漏、债务承担和实际需求反应；政策量级与机制一起检验 |
| 一个作者的制度解释与短期预测何时分离？ | Batson2022/2023、统计局2023全年结果 | 冻结事前命题与条件后逐项对结果；分别保留机制、时点和指标上的采用范围，不能整体贴“准/不准”标签 |
| 制造业名义占比下降来自实际结构、相对价格还是竞争力变化？ | Batson2025 | 分解名义与实际增加值、价格和就业；比较规划措辞与实际补贴、支出、信贷安排，分别检验声明和执行 |
| 实际汇率变化有多少来自名义汇率，有多少来自相对物价？ | Batson2026 | 对齐BIS名义/实际有效汇率、权重、基期和物价口径；再研究政策、出口与就业联系，分解关系和因果效果分别登记 |

这些任务分别进入房地产、财政、企业、居民、银行、政策和计量专题，并指明相邻接口。模型输出按具体目标登记：现金缺口、损失/缓冲、事件排序、严重程度或经过验证的概率。作者文章、目录数和阅读者赞同数都不作训练标签或评分输入。
