返回边的轻/重比为 `ε=q^(m−1)`，故 `Nε=1/p`。写

\[
U=\sum_{r=1}^N(1+r\varepsilon)^p,\quad
V=\sum_{r=1}^N(r\varepsilon)^p,\quad
J=\alpha(1+1/p)^p-1,\quad Z=U-\alpha V.
\]

定义邻接幅度和返回幅度

\[
A_a=(2L/H)^a\quad(0\le a\le m-2),\qquad A_R=H/(2J).
\]

下文证明 `H,L,J,Z>0`，故全部幅度为正有理数。`m≥3`；`N=p^(4m−5)` 是正整数，且 `N≥Q`，所以所有下述窗口合法。类与 clone 的数目都允许随 `p` 增长；没有多项式输入大小主张。

### 2.2 全部资源与两个动作

玩家为 `P_(a,j)`，其中 `a=0,...,m−1`，`j∈Z/NZ`，权重为 `w_a`。线性更新顺序为

`pos(a,j)=jm+a`。

测试共有 `m` 个：

- 对每个 `0≤a≤m−2`，邻接测试 `τ_a=(a,a+1,Q,−1)`，每个资源费用为 `(A_a/w_a^p)x^p`；
- 返回测试 `τ_R=(0,m−1,N,+1)`，每个资源费用为 `A_R x^p`。

对任一测试 `τ=(a,b,K,o)` 和每个 `j∈Z/NZ`，引入两个全新资源 `e_(τ,j,0),e_(τ,j,1)`。测试内两侧同费，各测试之间及各 `j` 之间资源互不相同。

区分用户 `h=P_(a,j)` 的动作0使用资源0，动作1使用资源1。窗口为

`P_(b,(j+k) mod N), k=0,...,K−1`。

因为全部测试均有 `a<b`，这是沿全局圆周顺序在 `h` 之后最先遇到的 `K` 名 `b` 类玩家。窗口用户 `u` 的动作0使用侧

`σ(h,u)=1[pos(u)>pos(h)] xor 1[o=−1]`，

动作1使用另一侧。不在该测试窗口中的玩家不使用该资源对。每名玩家的两个动作分别合并它在全部测试中指定的资源。每个玩家至少参与一项测试，故两个动作均非空；在每对参与资源中始终恰用一侧，故两动作互不相交。

每项测试有 `2N` 个资源，共 `2mN` 个。所有玩家权重在其全部资源上相同，没有资源特定需求或玩家特定费用。

### 2.3 两轮逐人真实偏离成本

每个玩家依 `pos` 顺序由0翻至1，再依同序由1翻回0。一次翻位切换该玩家全部参与资源对的侧，偏离后始终包括其自身权重。

对一般窗口正方向测试，区分玩家 sweep 前后负载为 `w_a` 与 `w_a+Kw_b`；每个 `b` 类 clone 在恰 `K` 个窗口中出现，圆周秩分别恰为 `1,...,K`，其前后负载分别枚举 `w_a+rw_b` 与 `rw_b`。这包括窗口跨越线性末端的情形：已更新用户与未更新用户在两侧交换，而圆周秩计数不变。`o=−1` 交换以上前后成本。第二轮所有用户集合相对第一轮逐资源侧互补，两侧同费使每名玩家前后成本重复第一轮。

因此邻接测试 `τ_a` 对其重类的旧/新成本为

`(A_a 2^p, A_a)`，

对其轻类的旧/新成本为

`(A_a Y, A_a X)`。

返回测试对类0的旧/新成本为

`(A_R, A_R(1+1/p)^p)`，

对末类的旧/新成本为

`(A_R U,A_R V)`。

故所有同类玩家在其各自环边上的总旧/新成本恰为：

| 类 | 旧成本 | 真实偏离后成本 |
|---|---|---|
| `0` | `2^p+A_R` | `1+A_R(1+1/p)^p` |
| `1≤a≤m−2` | `A_a 2^p+A_(a−1)Y` | `A_a+A_(a−1)X` |
| `m−1` | `A_(m−2)Y+A_R U` | `A_(m−2)X+A_R V` |

从而两轮的逐类 `α` margin 精确为

\[
\gamma_0=H/2,\quad
\gamma_a=A_{a-1}L\ (1\le a\le m-2),\quad
\gamma_{m-1}=A_R Z-A_{m-2}L.\tag{1}
\]

## 3. 系数闭环与健康余量的完整界

先证

\[
\frac4Q\le\frac HL\le\frac{40}Q,\qquad
\frac ZJ>\frac{3}{p^2\varepsilon}.\tag{2}
\]

右端 `H/L≤40/Q` 等价 `L/H≥Q/40`；下面分别证明。

对 `f(t)=(1+t)^p`，单调性及逐区间上下 Riemann 和给

\[
Q\frac{2^{p+1}-1}{p+1}\le X
\le Q\frac{2^{p+1}-1}{p+1}+2^p-1
\le2^p\left(\frac{2Q}{p+1}+1\right).
\]

因 `p≥2`、`Q=p^4`，

`2p/(p+1)+p/Q≤2+1/8≤9/4`，

故 `X≤(9/4)(Q/p)2^p`。又 `p≤2^p` 给 `H≥(9/10)2^p`。所以

`L<αX≤(9/40)Q2^p`，从而 `H/L≥4/Q`。

另一方面，`r/Q≤1` 使 `Y≤2^(−p)X`。因此

\[
L\ge(\alpha-2^{-p})X\ge(\alpha/2)X
\ge\frac{\alpha Q2^p}{2(p+1)},
\]

结合 `H≤2^p`、`α=p/10` 与 `p/(p+1)≥1/2`，得到 `L/H≥Q/40`。这也同时证明 `L>0`，并给

\[
Q/20\le2L/H\le Q/2.\tag{3}
\]

每个返回求和项满足

`(1+rε)^p−α(rε)^p≥1−α p^(−p)≥9/10`，

故 `Z≥(9/10)N>0`。又 `J>0`，以及 `(1+1/p)^p<3` 给 `J<3α`，从而

`Z/J>(3/10)N/α=3/(p²ε)`。

由幅度公式，

\[
\frac{A_R Z}{A_{m-2}L}
=\frac{(H/L)^{m-1}(Z/J)}{2^{m-1}}
>\frac{3\,2^{m-1}}{p^2}\ge3.\tag{4}
\]

所以末类 margin 严格为正。更精确地，

\[
\gamma_{m-1}>\frac23 A_R Z
=\frac{HZ}{3J}>\frac H{p^2\varepsilon}>H/2.
\]

最后一步用 `ε≤p^(−4)` 与 `p≥20`。由 (3)，`A_a≥1` 且 `L≥(Q/40)H>H`，所以全部中间类 `γ_a≥L>H/2`。结合 (1)，环上最小真实余量恰为

`η=γ_0=H/2`。

所有环边均严格 `α` 改善；这未检查环外状态，也不声称无 `α-PNE`。

### 3.1 全部基体状态成本上界

考虑任意纯状态，不限于环或前沿。在邻接测试 `τ_a` 的任一资源上，全部潜在用户总重为

`w_a+Qw_(a+1)=2w_a`。

重类 clone 仅参加该测试的一对资源，费用至多 `A_a2^p`；轻类 clone 参加恰 `Q` 个窗口，费用至多 `Q A_a2^p`。因此统一可用 `Q A_a2^p` 控制该测试对任一玩家的贡献。

由 (3)，`A_a≤(Q/2)^a≤Q^(m−2)`，所以全部邻接测试贡献不超过

`(m−1)Q^(m−1)2^p`。

返回测试的全部潜在用户总重为 `1+Nε=1+1/p`。区分玩家只使用一对，末类每个 clone 参加恰 `N` 对，故它对任一玩家的贡献不超过

\[
NA_R(1+1/p)^p
<\frac{3N2^p}{2(\alpha-1)}
=\frac{3}{2p(\alpha-1)}Q^{m-1}2^p
\le Q^{m-1}2^p.
\]

这里使用 `J≥α−1`、`H≤2^p`、`α≥2`、`p≥20`。两类测试相加给全部状态的

`C_i(s)≤B_*=mQ^(m−1)2^p`。

再用 `η=H/2≥(9/20)2^p`，得到

`B_actual/η≤B_*/η≤(20/9)mQ^(m−1)`。

由于 `m−1=ceil(log_2(p²))≤2log_2 p+1`，上述对数平方结论均立即成立。这里只用明确的成本上界；没有把参与资源数、循环费用或期望费用误作全部状态最大费用。


## 4. 前沿相位与端点的真实费用

每类相位 `x_a∈Z/(2N)` 的位串为 `B_x(j)=1[j<x]`（`0≤x<N`），或 `1[j≥x−N]`（`N≤x<2N`）。forward mover为clone `x_a modN`，backward mover为 `(x_a−1) modN`。共同扭转平移将所有相位同增1且保持真实当前及翻位后成本，故可把某mover类相位归零；不可把其他类固定为全0。

共同扭转平移的验证如下。在全部类同时将clone j映到j+1 modN，跨越N−1到0者同时翻位。令玩家的wrap标志为ε_i。窗口圆周用户集合不变，线性先后指示满足

    1[pos(u′)>pos(h′)] = 1[pos(u)>pos(h)] xor ε_h xor ε_u.

资源对随其区分clone平移，并在ε_h=1时交换两侧。轻用户的实际侧由其动作位xor关联相位给出；动作翻位ε_u与关联中的ε_u抵消，恰只剩与区分资源一致的ε_h侧交换。对应权重和两侧费用相同，所以全部成本与一次指定真实偏离的前后成本均保持。逐位代入B_x得此变换把每类相位加1。故对任意mover归零和backward反边都合法。

邻接测试a→a+1的heavy forward mover取相对相位 `r=x_(a+1)−x_a mod2N`。归零后h=(a,0)，窗口index0,...,Q−1全在其后，orientation−使其动作0侧全为0。因此令n(r)为该窗口中动作0人数，准确有

```
n(r)=Q−min(r,Q),                  0≤r≤N;
n(r)=min(r−N,Q),                  N≤r<2N.
```

heavy forward旧/新成本是 `A_a(1+n/Q)^p`、`A_a(2−n/Q)^p`。backward mover是相位x_a−1处forward边的反向，故其旧/新为上述表在r+1（模2N）处的新/旧；r+1不是r−1。

若 `r∉[0,Q]∪[N,N+Q]`：

- `Q<r<N` 时n(r+1)=0，backward旧/新恰为 `A_a2^p,A_a`；
- `N+Q<r<2N` 时n(r)=Q，forward旧/新恰为 `A_a2^p,A_a`。

故选定方向的该测试α-margin恰为 `A_a H`。闭区间放宽允许若干事实上已有出口的端点，方向不受影响。

### 4.1 任意前沿的light端点界

考虑任意邻接测试a→b=a+1，归零light类相位，使forward mover为(b,0)。它参加恰Q个窗口。对窗口编号 `k=0,...,Q−1`，区分index `h=−k modN`。在mover当前资源侧的light用户数恰为Q−k，翻位后目标侧包括自身的light数恰为k+1；heavy是否共享分别由 `e_k∈{0,1}` 和1−e_k确定。因此旧/新成本分别为

```
A_a Σ_(k=0)^(Q−1) ((Q−k)/Q+e_k)^p,
A_a Σ_(k=0)^(Q−1) ((k+1)/Q+1−e_k)^p.
```

此处e_k由另一类真实相位决定，但逐项用e_k≤1及1−e_k≤1，两式都≤`A_a X`。这是N≥Q时wrap窗口的真实用户数；并非把任意状态的Q个资源粗上界Q2^p混入。backward旧/新是forward某相对相位的交换，所以两式仍均≤`A_a X`。共同扭转平移返回任意front的两endpoint，故该界对任意front、两个方向成立。

若mover是内类a∈{1,...,m−2}，前节选定heavy出口的总margin至少

`A_a H−α A_(a−1)X = A_(a−1)(αX−2Y)`。

由 `Y≤2^(−p)X`、`α≥2`、`L≤αX` 得 `αX−2Y≥αX/2≥L/2`；原输入界 `A_(a−1)≥1,L≥QH/40>H` 给该margin>H/2。

类0另参与返回测试但只是一个区分resource pair，因此其新成本≤`A_R W`。其选定heavy出口总margin至少

`H−αA_R W=H(J−1)/(2J)>H/3`，

因为 `W>2`（二项式前两项为2，其余正），α≥2使J>3。由此：若未已有margin≥H/4的出口，所有邻接相位差均在上述两个短区间中。

## 5. 全部相位的覆盖：短区间累计与返回端点

逐一写 `x_(a+1)−x_a=k_aN+t_a mod2N`，`k_a∈{0,1}`、`0≤t_a≤Q`。于是

`x_(m−1)−x_0=kN+T mod2N, 0≤T≤(m−1)Q`，

其中k只需取Σk_a的奇偶。取整代表时两个区间不重叠，因为N>Q；T<N由后面粗界保证。

返回测试的light类是末类。把该类相位归零，其heavy类相对相位为r=x_0−x_(m−1)。按真实窗口枚举k=0,...,N−1，区分index `h_k=−k modN`，动作0的相位 `σ_0=1, σ_k=0(k>0)`，令 `e_k(r)=1[B_r(h_k)=σ_k]`。真实forward旧/新为

```
O(r)=Σ_(k=0)^(N−1) ((N−k)ε+e_k(r))^p,
Q(r)=Σ_(k=0)^(N−1) ((k+1)ε+1−e_k(r))^p.
```

未乘返回幅度A_R。假想e全1时O=U,Q=V；假想e全0时O=V,Q=U。每改变一个e位，两式的变化绝对值均≤W，因为所有负载≤1+Nε=1+1/p。

- k为偶数，r=−T mod2N。选forward。T=0时e0=0且其余全1，至多1个缺陷；1≤T<N时e0,...,e_T=0且其余全1，恰T+1个缺陷。因此 `O−αQ≥Z−(α+1)(T+1)W`。
- k为奇数，r=N−T mod2N。选backward，旧/新为 `Q(r+1),O(r+1)`。T=0时r+1=N+1，e全0，恰无缺陷；1≤T<N时r+1=N−T+1，恰有T个e位为1，其余0。因此同样 `Q(r+1)−αO(r+1)≥Z−(α+1)(T+1)W`。

这是逐resource集合比较，包含自身重量；未把前沿块当一个玩家移动。

### 5.1 统一前沿余量

第3节已证明或由其参数直接得到的一般界：`m≤p`、`m≥3`、`N≥p^7`、`W<3`、`Z≥(9/10)N`、`A_R Z>3 A_(m−2)L`、`L≥QH/40`、`A_a≥1`。`m≤p`可由 `2^(p−1)≥p²`（p≥7后比值递增）直接得到。它们另保证 `T≤(m−1)Q<N`。

写defect `D_0=(α+1)(T+1)W`。由于α+1≤p/5、T+1≤pQ=p^5，得

`D_0≤(3/5)p^6≤Z/30`，

最后用p≥20及Z≥(9/10)p^7。末类incoming light新成本≤`A_(m−2)X`，故选定return出口总margin严格大于

```
(29/30) A_R Z−α A_(m−2)X
> (29/10−2) A_(m−2)L
= (9/10) A_(m−2)L > H/2.
```

这里用αX≤2L（由Y≤αX/2）。因此每个front均有margin≥H/4的保front出口。第一、二种情况或末类情况穷尽所有phase向量，不依赖有限抽样。


## 6. 同类时钟与全部纯状态的严格出口

本节自足重建已知条件编译机制，明确使用B_*作为上界、η_0=H/4作为下界；不把它们冒充真实max或min-max的精确值。令

    L_c=binom(N−1,2)≥1, M=2αB_*.

对每类a和1≤i<j<N，新建一对仅由(a,0),(a,i),(a,j)使用的资源。三人的关联相位为(0,1,0)：玩家的动作位xor该相位决定使用哪侧，两侧同费

    c_a(x)=M[x/(3w_a)]^p.

它们与全部旧资源、其他三元资源互异，不改变玩家或两个动作，只在原动作中加入所规定的新资源。每名玩家参与的新增资源对数至多L_c。若局部动作是010或101，三人同侧，各付M；其他模式任意用户付费至多Mδ，其中δ=(2/3)^p。

一个类的全部这些时钟不触发，当且仅当位串至多一次相邻变化。正向显然；若不是这种前沿，令b为首位，最早异位i后必有某j>i仍为b，因此三元(0,i,j)为b,1−b,b并触发。

先假定满足预算

    δ ≤ η_0/(4α²B_*L_c).                    (CLOCK)

若s是product-front，第5节给一个保前沿的mover，其基体margin≥η_0。翻前翻后所有参与时钟都不触发，其新时钟总成本≤L_c Mδ；舍去旧时钟非负成本，得到完整游戏margin

    ≥ η_0−αL_c Mδ ≥ η_0/2 >0.

若s不是product-front，在任一非法类取最早异位i并翻回首位b。它旧时钟成本至少M。对它参与的每个三元：若i居中，翻后中位与锚点相同；若i居末，中位更早、按最早性与锚点相同。因此翻后全部不触发，新时钟成本≤L_c Mδ。i不使用其他类时钟，基体新成本≤B_*。所以完整真实margin

    ≥ M−αB_*−αL_c Mδ
    ≥ αB_*−η_0/2 ≥ η_0/2 >0.

最后用α≥1、B_*≥η_0。两种情形覆盖全部状态，始终只翻一名玩家，没有同时修复其他玩家。全过程只用成本不等式，零成本无除法。若相应偏离成本为零，严格正margin仍直接给所需结论。

## 7. 在原次数内满足预算的明确起点

基体成本界与前沿余量给B_*/η_0≤(40/9)mQ^(m−1)。L_c≤N²=Q^(2m−2)/p²和α=p/10给

    4α²B_*L_c/η_0 ≤ (8/45)m p^(12m−12) ≤ m p^(12m−12).

m−1≤2lnp/ln2+1≤5lnp、lnm≤lnp及ln(3/2)≥1/3，于是充分预算所需的最小整数次数不超过

    D_*=ceil[ln(4α²B_*L_c/η_0)/ln(3/2)]
       ≤ 180(lnp)²+3lnp+1.

当p≥2^20时，lnp≤p^(1/4)：起点20ln2<20<32；函数p^(1/4)−lnp的导数在p≥256非负。因此

    D_* ≤ 184sqrt(p) ≤ p.

固定实际新增费用次数就是p。由于(2/3)^D随D非增，D_*≤p保证(CLOCK)。这避免使用任何实数对数取整作为构造算法；所有实际资源费用始终是正有理系数乘x^p。原次数与新增次数一致，整个输出次数恰p，不能把基体次数误当输出次数。

## 8. 原题严格否定的全部量词

给任意实C≥1与整数d0≥2。选整数

    k≥max{20, ceil(20C), ceil(log_2 d0)},  d=p=2^k.

则p≥2^20、p≥d0；ln2>1/2给lnp=kln2>k/2≥10C，因此p/10>Cp/lnp。第6—7节对G_p每个纯状态s给合法单人偏离，满足

    C_i(s) > (p/10)C_i(t_i,s_{−i})
           ≥ (Cp/lnp)C_i(t_i,s_{−i}).
