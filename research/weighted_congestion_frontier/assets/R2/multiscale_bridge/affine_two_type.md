# 两个精确权组的线性费用：共享乘子边际的 sharp 平方根跨度界

作者：R2 内部研究成员 dense_scales；2026-10-14。此文件接续 `path_obstruction.md`，给出该障碍在两个精确权组、线性费用中的定量上界。

## Claim 身份

- **ID/version：** `WC-R2-AFFINE-TWO-TYPE v1`。
- **Exact Statement：** 一个资源有两种正权 `a,b`，每种权组任意有限人数；同组玩家使用共同正乘子 `h_a,h_b`。令 `q_a=h_a/a`、`q_b=h_b/b`，并令 `D=max(q_a,q_b)/min(q_a,q_b)`。对费用 `c(x)=x` 存在显式集合函数 `F`，对每个玩家和每个包含它的集合满足

  `h_i W(S) <= F(S)-F(S\{i}) <= sqrt(D) h_i W(S)`。

  固定 `a,b,h_a,h_b` 后，`sqrt(D)` 是对所有有限人数统一有效的最小因子：任意较小因子被某个有限人数实例的两条单调路径否定。
- **Objects / Domain：** 两个精确权组、线性资源费用、任意集合势；允许一个组暂为空。
- **Quantifiers：** 固定正权和组乘子；上界对每个有限人数以及每个子集同时有效；sharpness 允许人数趋于无穷但每个反例仍有限。
- **Assumptions：** 同组使用共同乘子；最大最小比例 `D` 是乘子密度 `h/w` 的比，不是权重本身的比。
- **Scope：** 资源局部边际证书；不宣称一般次数费用同样成立。对 `c(x)=u x+v`、`u,v>=0`，把本势乘 `u` 再加 `v sum_i h_i` 立即有效。
- **Conclusion：** 对 `h_i=w_i^p` 和 `0<=p<1`，两个权组的 worst-multiplicity sharp 因子为 `(max(a,b)/min(a,b))^((1-p)/2)`。因此 dense 组计数本身可被消去，但权跨度不能被消去。
- **Dependencies：** 分片二次函数的一阶导数、单变量积分、有限和渐近。
- **Evidence：** 下列完整一般证明；`verify_affine_two_type.py` 使用 Fraction 核验分片边际和子集路径比。
- **Counterevidence / Objections：** 单一二次型会错误要求因子至少 `D`；这里使用两个二次分支，不能用单一 Hessian 的交叉项检查替代一般集合势检验。有限人数的最优因子可以严格小于 `sqrt(D)`。
- **Status：** 一般证明完成，两成员独立构造及主对话Fraction核验通过；规范身份在 research/current/weighted_congestion_frontier_power_bridge.md。新颖性未认证。
- **Related Files：** `path_obstruction.md`, `verify_affine_two_type.py`。

## 1. 显式分片势

交换组标签后可假设 `q_a<=q_b`。令

`q=q_a`, `D=q_b/q_a`, `k=sqrt(D)>=1`。

令集合中两组总负载分别为 `A`、`B`。定义连续函数

```text
P(A,B) = A²/2 + D A B + D B²/2,             A >= k B;
P(A,B) = k A²/2 + k A B + k³ B²/2,          A <= k B.
```

两个二次表达式之差恰为

`-(k-1)(A-kB)²/2`。

它们在分界直线上的函数值及梯度均相同，所以 `P` 是第一象限上的 `C^1` 函数。`D=1` 时两式均为 `(A+B)²/2`。

离散集合势定义为

`F(S)=q P(A(S),B(S)) + (1/2) sum_{i in S} h_i w_i`。

第二项是必要的离散自作用校正；不能省略它后仍声称下界使用加入后的总负载。

## 2. 连续梯度夹逼

在区域 `A>=kB`，

`P_A=A+D B`, `P_B=D(A+B)`。

因为 `D=k²` 和 `A>=kB`，

`A+B <= A+D B <= k(A+B)`。

最后一个不等式等价于 `(k-1)(A-kB)>=0`。故在此区域

`A+B <= P_A <= k(A+B)`,

`D(A+B) <= P_B <= kD(A+B)`。

在区域 `A<=kB`，

`P_A=k(A+B)`, `P_B=kA+k³B`。

此时

`P_B-D(A+B)=k(k-1)(kB-A)>=0`,

`kD(A+B)-P_B=k(k²-1)A>=0`。

所以相同梯度夹逼在整个第一象限成立。乘回 `q` 后，其统一形式为

`q_j(A+B) <= partial_j(qP) <= k q_j(A+B)`, `j in {a,b}`。

## 3. 从连续梯度到离散边际

加入一个组 `j`、权为 `w_i` 的玩家。设加入前总负载为 `W_0`，加入后为 `W=W_0+w_i`。沿该组坐标积分，即使穿过分界直线，也有

`h_i(W-w_i/2) <= Delta(qP) <= k h_i(W-w_i/2)`。

离散校正项增量是 `h_i w_i/2`。相加得

`Delta F >= h_i W`,

`Delta F <= k h_i W - (k-1)h_i w_i/2 <= k h_i W`。

这完成上界。所有负载与权均非负，加入玩家的权严格为正；空集、单组集合和分界线没有例外。

删除玩家就是反向读取同一边际，不需另建势或改变乘子。两组标签根据 `q` 而非权重大小排序；若输入标签次序相反，交换 `a,b` 及相应负载、乘子后应用同一构造。

对仿射费用 `c(x)=u x+v`、`u,v>=0`，定义

`F_c(S)=u F(S)+v sum_{i in S} h_i`。

其边际满足

`h_i(uW+v) <= Delta F_c <= k h_i(uW+v)`，

因为常数部分精确产生 `v h_i`。`u=v=0` 时所有边际均为零；`u=0` 时该势事实上是精确的。sharpness 陈述针对包含 `c(x)=x` 的整个非负仿射族，不声称纯常数费用也需要因子 `k`。

若 `h_i=w_i`（power 接口的 `p=1`），则两组 `q` 相同、`D=k=1`，所得势为标准线性加权势 `(W²+sum_i w_i²)/2`，完全精确。

## 4. 对所有人数统一的最优性

取 `M` 个权 `a` 的玩家和 `N` 个权 `b` 的玩家，并写 `A=Ma`、`B=Nb`。先 `a` 组后 `b` 组的路径和，除以共同 `q`，为

`T_ab/q = A²/2 + D B²/2 + DAB + (aA+DbB)/2`。

反序路径和为

`T_ba/q = A²/2 + D B²/2 + AB + (aA+DbB)/2`。

选整数序列 `M,N -> infinity`，使 `A/B -> k`。例如令 `M=ell`、`N` 为最接近 `ell a/(kb)` 的正整数。则线性修正项相对二次主项趋于零，故

`T_ab/T_ba -> (D+Dk)/(D+k)=k`。

任何边际夹逼因子必须至少为任意两条路径和的比，所以任何 `alpha<k` 均被某个有限 `M,N` 否定。此处证明的是人数统一最优性，不是每个有限矩形的最优性。

## 5. 已出现 LP 数值的精确解释

主对话报告 `a=1,b=1/16,h_a=1,h_b=1/4`，即 `D=4,k=2`，矩形计数上限分别为 `(1,16),(2,32),(4,64),(8,128)` 的 LP 最优值。它们无需额外非单调循环：在较小终集上比较两个单调组序，已经得到以下精确下界。

| 计数上限 `(M,N)` | 使用的终集 `(m,n)` | 精确路径比 | 小数 |
|---|---|---|---|
| `(1,16)` | `(1,11)` | `51/29` | `1.758620689655...` |
| `(2,32)` | `(2,20)` | `521/281` | `1.854092526690...` |
| `(4,64)` | `(4,36)` | `1805/941` | `1.918172157279...` |
| `(8,128)` | `(8,68)` | `6677/3413` | `1.956343392909...` |

这些有理路径比是精确下界。它们与主对话 LP 数值相符只是有限观察；在没有相应有理可行解证书时，不把浮点 LP 相符升级为有限矩形的精确最优性定理。
