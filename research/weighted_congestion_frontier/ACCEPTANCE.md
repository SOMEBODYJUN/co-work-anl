# 数学与交付验收

## 主目标的数学门槛

WC-TARGET v1 使用 MODEL.md 的全类。完成增长阶目标须对同一全类、同一精确阈值给出同阶上下界的一般证明，闭合边界和外部定理条件，经关键独立攻击并消除尚成立的致命 objection，完成文献比较和规范入库，确认成果已推送 main。外部同行评审与全球新颖性单独记录，不由内部证明或推送自动取得。

当前团队已保存 T_d∼d/ln d 无限下界，普遍上界仍为已核实文献 d。全类 O(d/ln d) 上界将完成与当前下界的增长阶匹配；若发现其他阶，也须给出相应匹配证明。下一项阶段突破须在明确的无限次数范围严格改善 main 中当前核实的全类上界或非存在下界，写清新旧比较；优先全类 o(d) 上界或越过当前 T_d 的更强下界。最初相对文献的下界突破已保存，不应被重复计算成新进展。

重要 claim 的审查覆盖：精确 ID/version 和全部量词；所有 proof obligations；零成本、退化策略、极端权重和次数端点；外部定理适用条件；审查者先依据精确问题自主重构关键瓶颈，再阅读冻结证明攻击；fatal objection 的处理；后续文献与优先权；计算代码、参数、seed、精度、误差控制和实际结果；远端 commit 与文件 hash。

Truth、Value、Novelty、Mechanism、Ambition 分别记录。Paper Fact、Interpretation、Conjecture、Observation、Evidence、Canonical Record 保持各自层级。一般证明决定普遍命题，有限计算提供其实际范围内的证据；尚成立的致命 objection 阻止状态提升。

## 阶段成果与交接

精确 lemma、bridge、反例、obstruction、严格失败机制和可复用实验都是阶段资产。子类界、有限实例和方法限制按其真实范围保存，不据此宣布主目标解决。可接续的候选按候选保存；完成材料所需核验后立即 checkpoint 到 main 并按需分享冻结入口，不创建研究分支。重要 claim 的状态提升再执行相应完整证明与独立攻击要求。主目标仍开放时继续追关键义务。

失败记录给出依赖、具体失败步骤、否定范围、回收结果和重试条件。改变表示或机制后，选择下一项能判别竞争解释的动作。

用户停止、实际运行限制或确无可判别下一动作时交接：写清已知、最关键未解义务、证据范围、停止原因和下一项行动，保存并推送实质成果。主目标解决、阶段突破、局部资产和会话交接分别判断。

## 协作程序验收

每个 Work 对话用提示词指定的角色号统一发言和提交；本地 `work.py` 加 txt 凭据能从空目录恢复，也能接续已有项目。配置一次后 `read`、`send`、`sync`、`checkpoint` 直接复用。子 agent 在内部按研究需要并行协作。

公屏是异步消息流，同级 boss 可自由研讨有启发的未完成 idea，不要求先成稿、独立审查或提交文件；同题独立工作与多路线可并行。读屏保留研究工作树，发言可恢复，并发消息均可读取；成果消息核对已推送文件的 hash。同步保留未提交成果，具体冲突可诊断，checkpoint 的远端确认可复查。纯本地测试与实际 GitHub 收发分别记录；技术核验和消息赞同不决定数学真值。

## 论文者的交付门槛

按 prompts/PAPER_WRITER.md 和 SOURCES.md 中的原文执行。正文有明确数学主语与作者主张，贡献逐一接到冻结证明和精确旧结果；条件、论证、引用完整可连续阅读。首次、最优、锐等表述有对应优先权核查。

完整成稿通读，实际导出逐页检查，保存编译命令和覆盖范围。尚无可成文贡献时交付真实贡献缺口；已有独立成果可以先行成文。写作交付与主目标成功各自验收。

## 提取者的交付门槛

按 prompts/EXTRACTOR.md 重建数学内容。工具或结构有精确接口、量词、承重条件、原作者与不可变来源、实际证明或候选义务、具体复用或检验、反例边界和实际文献检索范围。

独立工具可以在 WC-TARGET 之外有价值。其一般化与当前主目标之间的桥梁按实际证明记录。提取后的文件应让下一位研究者直接使用；有真实增量才进入 toolbox 和研究地图。
