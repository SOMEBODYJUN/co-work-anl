# 验收与结束条件

## 数学成功

WC-TARGET 保持 MODEL 的全类。阶段突破须给完整一般证明的 o(d) 上界，或有准确新旧比较的严格新无限非存在下界；最终刻画增长阶还需匹配或足够精确的上下界。不存在“同伴多数通过就算证明”。

验收逐项：精确 claim/version 与全量词；全部 proof obligations 已闭合；零成本、退化策略、权重极端、次数端点核查；所有 theorem import 条件；独立成员先自主重建关键瓶颈，再读冻结证明攻击；任何未解决 fatal objection 阻止升级；文献后续与优先权复查；实际代码/参数/seed/精度/结果复现；远端 commit 与文件 hash 核对。计算、模型信心、时间花费均不能替代证明。

研究真值、价值、新颖性、机制解释、目标野心分别评估。目标不是保证发表，也不是把更多小例包装成解题。

## 阶段资产与继续研究

可以保存精确 lemma、bridge、反例、明确 obstruction、严格失败机制或可复用实验。它们是有价值的阶段交付，主目标仍开放时继续探索，不因第一个小引理就结束整队。

若一个 idea 失败，保存依赖、失败步骤、否定范围、可回收结果、重试条件，释放认领后自主选择不同机制。没有真实增量时不制造数学文件，不把“计划写完”作为研究完成。

本次会话仅在完整目标达到、真实工具/上下文限制、用户停止或本轮约定预算结束时交接。没有有限预算时，按可用运行范围持续有效探索；没有可判别下一动作时诚实交接，不空转。预算结束不是命题被反驳；工具失败不是数学证据。退出前保存资产、push、发布含最关键未解义务的 handoff，并 release；突然中断由租约回收。

## 协作与基础设施验收

所有对话相同入口，均能自主提出和认领；协调者缺席不阻塞；同一具体推进单元并发只成功一个，冲突后重算；不同推进单元可并发；公开补充、联合工作、反证、冻结版本审查不被认领禁止；过期可接替、旧 token 不能改新 owner；读公屏不会改变脏工作区；发送失败可恢复、不虚报推送；结果消息校验实际已推送资产的 hash。纯本地并发测试和实际 GitHub 收发分别记录，不能混称。

## 默认持续工作预算与准确结项

每支研究天团默认约三千六百秒有效工作。以实际时间记录起止，运行条件允许且未达主目标验收时持续推进；局部结果/路线失败后接续新义务或更换机制。无可判别下一动作、真实预算/上下文/工具边界、用户停止可以交接；禁止以睡眠、无增量轮询或反复无关核验凑时长。主目标解决、阶段突破、局部资产和本轮交接是四种不同结论，不能因时间用完自动选择“完成”。

若宣称 WC-TARGET 的增长阶已经确定，必须提供同一全类、同一精确阈值的匹配增长阶上下界，含所有域和量词、端点处理、全部依赖与证明。一条新的 o(d) 上界或严格新无限下界只有阶段突破资格。任何成员可提出验收；冻结 claim/version/commit/hash 的证明及独立重构/攻击记录必须可读，未消除 fatal objection 阻止通过。公屏 finish 仅结束当前具体单元，不是目标完成按钮。脚本验收只检查可执行操作和记录一致性，不能自动判定一般数学证明正确。

## 论文者的交付门槛

论文者按 prompts/PAPER_WRITER.md 和 SOURCES 的实际原文执行。具有明确数学主语与作者主张，贡献逐一接到冻结的证明/证据和确切旧结果；完整理论条件、论证和引用能顺读，不以账本字段或标题代替实际内容。核实优先权才使用首次/最优/锐；必要 scope 只在其限定结论处写清，避免免责声明取代正文。正文内容通读与实际导出逐页检查分别记录；工具不可用不能说已编译/逐页通过。无足够成果时只交真实贡献缺口，不造占位论文。成稿就绪与主数学目标完成独立判定。

## 提取者的交付门槛

提取者按 prompts/EXTRACTOR.md 实际重建数学内容。工具或结构有精确接口/量词/承重条件、源作者及不可变版本、实际证明或候选义务、至少一个具体复用或检验、反例边界与按实际检索标注的新颖性。可以独立于 WC-TARGET 有价值；不能为使主目标看似有进步而强连不存在的桥。仅改名字、分类或聊天摘要不算工具成果。没有新工具时不强行创建，保存真实缺口或准确交接已查范围即可。

## 身份与多队实测要求

已启动成员登记真实 team/member、parent 和 runtime/config；身份碰撞在并发时只接受一个，新会话自动生成互异根署名。模型未知仍保持 unknown。不同团队可以同时登记、提出不同单元、直接回复/请求帮助；同一单元只能一个有效 owner，补充与独立攻击仍开放；原有脏工作区保持。身份是自报署名，不宣称密码学认证或在线检测。每队七槽位的计划数包括根成员，未实际启动的成员不得计入实际数量。
