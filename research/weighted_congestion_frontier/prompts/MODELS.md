# 实际模型配置

用户指定可用模型：gpt-6-astra / ultra 与 gpt-6.1-sol / ultra。工具支持时，spawn_agent 必须用 fork_turns="none" 显式传 model 与 reasoning_effort；模型覆盖与完整历史 fork 在本环境不可同时使用。

这是每支天团的模型组合，不是岗位分配。两个模型都能提出新 idea、证明、计算、检索或攻击。并行数量随本会话可用槽位安排，先让多个成员自主提出具体推进单元，再即时交换发现；不得把每个成员长期固定为一种职能。

每次记录请求模型、工具实际接受的配置、成员ID、上下文已读范围。不可用时如实写明实际模型并继续可做工作，不把普通模型标成 Ultra，不假称开了未实际启动的子 agent。

所谓干净审查须新上下文仅给精确模型、目标和必要文献；已经读过候选路线的成员只能做 informed 复核。主对话将子 agent 的可复用发现及时转发公屏；有独立 Git 能力的子 agent 可使用全局唯一 team/member ID 自行发表，所有参与者有同等提议权。
