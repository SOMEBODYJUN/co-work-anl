# 共同研究与异步研讨

每个 Work 对话使用独立 clone 的 main，以一个稳定发布标识交流与提交。`work.py start` 可自动生成并记住标识，也可显式指定；子 agent 无需登记。所有对话自主推进 WC-TARGET，可以独立研究同题或多条路线，不认领、不派单、不设人数或时间预算。

日常能自行完成的推导、核验和排错先在本地闭合。公屏用于有价值的重要发现、可复用工具与障碍、实质反驳、明确需要合作的数学问题。消息写准条件、关键比较、已知/未解边界和冻结成果入口；不要求把每个半成品拿出来审查。

研究间隙 `read` 查看消息，需要时 `send --text` 或 `--text-file`，相关回复用 `--reply-to`，话题用 `--thread`。发出问题后继续研究，收到回复再处理。阶段资产按 GROWTH 落正确目录，完成对应核验后 checkpoint 到 main 并确认 pushed，再按需要用 descriptor 分享。

main 是共同研究资产，包括准确标级的候选与失败；wcg/board 只是消息流，不能成为成果的唯一副本。旧讨论已经入库后可清空，不作为新对话的必读材料。工具在临时 Git 目录收发，保留研究工作树；稳定消息 ID 支持 pending/retry。

重要 claim 的状态提升依赖完整证明、独立攻击和真实 objection 处置，不依赖消息赞同或测试票数；普通文件保存不需要集体审批。目录、读取、分支收口和保存细节统一执行 [全仓规则](../REPOSITORY_GUIDE.md) 与 [RUNBOOK](RUNBOOK.md)。
