# 连续静态安全值与对数势：精确分离

状态：自足候选推导，2026-10-21；尚未独立审查，未认证文献新颖性。
本页只排除一个表示等价，不反驳 Q-CAG-HALF 或任何 SPE 安全值支付桥。

## 对象与仍开放的桥

在 CAG-MODEL 的有限共同目录、单位客户和 m 名单位提供者中，令 k=m−1，
对目录概率 q 写 q_x=Σ_{A∋x}q_A，并定义

    g_A(q)=Σ_{x∈A}1/(1+k q_x),
    v_cont=min_{q∈Δ(S)} max_A g_A(q).

这是紧单纯形上的凸优化：各 g_A 为凸连续函数，其逐点最大亦凸。
OPT_m≤(2m−1) max_A g_A(q) 对任意 q 成立：逐客户使用
1_{d_x>0}≤(d_x+kq_x)/(1+kq_x)，其中 d_x 是 m 个最优主题的覆盖重数；
再利用 Σ_x kq_x/(1+kq_x)=k Σ_A q_A g_A(q)。故

    v_cont ≥ OPT_m/(2m−1).

任何静态竞争元组分布的均值负载都等于 kq_x。Jensen 给每个查询的真实
期望收益至少 g_A(q)，因此 v_cont≤真正的静态混合安全值 v_m。
这里没有交换适应性续局和不观察查询的静态竞争者。

若能对每个完整历史纯 SPE 证明 W≥(m−1/2)v_cont，则半覆盖成立；
本页没有证明该支付桥。下面说明不能直接把 v_cont 等同于对数势的 KKT 值。

## 一个每个 m≥2 都成立的分离族

令 k=m−1≥1，a=k+3，d=2k+3，四个主题标签为 0,1,2,3。
客户兴趣类型及整数重数为

| 兴趣主题 | 重数 |
| --- | ---: |
| {1} | a |
| {2} | a |
| {3} | a |
| {0,2,3} | d |
| {0,1} | a |

这编码 4a+d=6m+9 个不同单位客户，四主题覆盖两两不同。
令 L(q)=Σ_x log(1+kq_x)。由于 log 凹，L 为凹函数。
其偏导为 k g_A(q)。在

    q*=(0,1/3,1/3,1/3)

处，令 D=1+k/3=a/3、F=1+2k/3=d/3，直接计算得到

    g_0(q*)=a/D+d/F=6,
    g_1(q*)=2a/D=6,
    g_2(q*)=g_3(q*)=a/D+d/F=6.

所有偏导相等，所以凹函数的一阶支撑不等式证明 q* 是 L 的全局最大者。
同一 KKT 值等于 6。

但令

    s=(3d+2a)/(4(d+2a)),  ε=1/(4k),
    q'=(ε, 1/3−sε, 1/3−(1−s)ε/2, 1/3−(1−s)ε/2).

因为 0<s<1/2，k≥1，q' 各项非负且和为一。
q' 上各查询值为

    g_0=a/[D+k(1−s)ε]+d/[F+ksε],
    g_1=a/[D−ksε]+a/[D+k(1−s)ε],
    g_2=g_3=a/[D−k(1−s)ε/2]+d/[F+ksε].

第一式的两个分母均严格增大，因此 g_0<6。
对 g_1 通分，g_1<6 等价于

    ε < D(1−2s)/[2ks(1−s)]
      = a/[4k(d+2a)s(1−s)].

因 s(1−s)≤1/4，右端至少 a/[k(d+2a)]，严格大于 1/(4k)，
最后一步用 4a>d+2a，即 2a>d。
对 g_2 通分，g_2<6 等价于

    ε < [sD−(1−s)F/2]/[ks(1−s)]
      = 1/[8ks(1−s)].

这里 sD−(1−s)F/2=(2a−d)/24=1/8。
右端至少 1/(2k)，亦严格大于 ε=1/(4k)。所以

    v_cont ≤ max_A g_A(q') < 6 = max_A g_A(q*).

这证明每个 m≥2 都有合法单位客户目录，使对数势最大者不是连续 minimax 的
最优负载。没有在本族指定或认证任何完整 SPE；本族不是福利反例。

## 使用边界

对数势最大者仍可作为一个显式合法 q，故给 v_cont 的上界；其 KKT 值的普遍
SPE 支付若成立，也会给更强的充分桥。被否定的是“最大对数势恰求解 v_cont”。
真正 v_cont 应使用其凸 epigraph 问题或另证的正确最优性条件。

`audit_continuous_log_boundary.py` 用 Fraction 构造本族、逐客户重算全部查询，
并核验通分恒等式和若干退化边界。解析全称证明在上文；有限审计不替代证明。
