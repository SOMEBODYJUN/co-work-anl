# 有界配置任务数的整数类型多面体与严格次二槽舍入

本文给一个结构性正面定理，不是一般 `UM-TARGET-v1` 的解。
“每个配置至多K个正任务”允许一台机器有任意多可选任务，也允许任意正处理时间跨度；
但K必须固定，余量与算法次数均依赖K。标准槽匹配是既有工具，
本页自足证明配置任务数对其完整槽包络给出的统一余量；全球新颖性未认证。

## 1. 精确身份与输入

**`UM-BOUNDED-CONFIG-CARDINALITY-SLOT-v1`。** 对每个整数K≥1、每个合法UM输入、
每个有理T≥0及显式有理等式覆盖CONFIG(T)点y，先将具有某条零边的任务分到该零边并删除，
并从y的各配置中删去它们。设余下每个正权配置至多含K个任务。
令x为其任务边际，建立标准非增处理时间单位槽，只在区间正交长时连边。
则对每台机器，完整槽包络E_i以及**任意**覆盖任务的槽匹配输出同时满足

\[
 L_i\le E_i\le (2-K^{-(K-1)})T\quad(K\ge2),\qquad
 L_i\le E_i\le T\quad(K=1).                    \tag{1}
\]

K=2、3时还分别有锐包络界3T/2、11T/6。
显式输入包括P,T,y的全部编码；给定点后的实际匹配构造为确定性位多项式。
并不把一般指数配置LP当免费oracle。空配置允许；只要求正权配置的任务数有界，
不要求所有本地合法配置、所有可选任务或所有最优调度满足该界。

**Dependencies / Definitions。** UM-MODEL-v1、UM-ST-ROUND-v1；
本地槽包络定义与[已有精确表示](slot_envelope_and_configuration_identity.md)相同。
下面的整数类型压缩仅用于证明，不合并实际任务，也不改变共同匹配图。

## 2. 严格前缀与整数类型压缩

T=0时非负性使所有有正边际的任务都只有零负载，预处理后为空；不作除零。
以下T>0，缩放为1。固定一行，正边际质量总和为u≤K，槽数q=ceil(u)≤K。
空行包络0；q=1时包络至多1。其余设q≥2，按槽顺序的最大相邻时间为
\(a_1\ge\cdots\ge a_q>0\)，且a1≤1。

对s=2,…,q，排序及严格正交长给

\[
 \sum_{j:p_j\ge a_s}x_j>s-1.                    \tag{2}
\]

取首个与槽s相交的任务，其右端严格越过s−1；此前任务全不小于a_s，即证。
等值任务平局及恰整数边界都由同一正交长约定处理。

令d=q−1、b_t=a_{t+1}。对每个正权配置C，将其中p_j<b_d的任务忽略；
其余任务归入满足p_j≥b_t的**最小**下标t，得到计数向量c∈Z^d_{≥0}。
于是Σc_t≤K、c·b≤1；前t类任务数恰为配置中p_j≥b_t的任务数。
由原配置分布诱导的有限计数分布，其前缀均值为

\[
 H_t=\mathbb E\sum_{v\le t}c_v>t\qquad(1\le t\le d).       \tag{3}
\]

重合阈值归入最早类别，故(3)仍精确。原配置中被忽略的任务大小非负，
所以c·b≤原配置负载≤1。

## 3. 整数多面体把严格不等式变成统一余量

固定这些计数类型的支持集S及其分布，考虑

\[
 Q_S=\{z_1\ge\cdots\ge z_d\ge0:\ c\cdot z\le1\ (c\in S)\}.
\]

实际b属于Q_S。由H1>1，某个整数类型c有c1≥2，故z1≤1/2，全部坐标有界。
Q_S闭且非空，线性目标Σz在一个顶点达到最大值。
对任意非零z，Abel求和及(3)给

\[
 \mathbb E(c\cdot z)
 =\sum_{t<d}(z_t-z_{t+1})H_t+z_dH_d
 >\sum_{t<d}(z_t-z_{t+1})t+z_dd=\sum_tz_t.
\]

至少一个非负系数严格为正，故不等号严格。另一方面每个类型c·z≤1，
所以Σz<1；z=0也有目标严格小于1。

顶点取d条独立活约束。其系数与右端均为整数，右端只有0、1。
类型行的Euclidean范数≤Σc≤K，排序行范数√2≤K，非负行范数1。
Hadamard给活约束矩阵的整数行列式绝对值D满足1≤D≤K^d。
Cramer法则使该顶点目标为某个整数N除以D；既然严格小于1，就有

\[
 \sum_tb_t\le \max_{Q_S}\sum_tz_t
 \le1-1/D\le1-K^{-d}\le1-K^{-(K-1)}.
\]

加a1≤1即得(1)。所有机器分别成立，并由**同一个**全局覆盖匹配同时兑现。
匹配存在性来自给定x的任务质量守恒和每槽容量1，不依赖类型多面体的数值求解。

## 4. 小K锐界与实际全局匹配下界

由(2)，某个配置至少含s个大小≥a_s的任务，故a_s≤1/s。
q≤2、3时分别得包络≤3/2、11/6。下表给完整普通UM实例中的实际覆盖匹配达到值：

| 配置任务数上限K | 中心行时间层 | 实际坏匹配负载 / OPT |
| --- | --- | --- |
| 2 | 1,1/2 | 3/2 |
| 3 | 1,1/2,1/3 | 11/6 |
| 4 | 1,3/8,1/3,1/4 | 47/24 |

构造每例中心行：unit任务B的singleton配置质量取η=1/100，其余配置权乘1−η。
K2用两枚1/2的配置；K3用两枚1/2配置权2/3及三枚1/3配置权1/3；
K4用计数(2,0,1)、(0,3,0)、(0,0,4)的负载1配置，原权分别5/9、1/3、1/9。
计数的三个时间层为3/8、1/3、1/4；D0在首、第三配置中为同一原任务。
每个任务另有独占私有机器，处理时间1，以singleton质量1−x_j补足覆盖。
全部任务送各自私有机给实际负载1，而B在其所有可用端都用时1，所以OPT=1。
中心每槽最大件可选成不同任务；其余任务匹配各自私有槽，得到表中完整匹配。

K2和K3因此为锐界。K4这里只断言47/24是已构造下界，**不**断言它是全域最坏值。
有限搜索未提升为一般锐性。此处坏匹配存在不排除选择另一个更好匹配或直接选择最优调度。

逐项核配置、覆盖、实际正交槽边与负载，冻结输出另存。

## 5. 未知OPT的结构承诺算法：另立身份

**`UM-BOUNDED-CARDINALITY-PROMISE-APPROX-v1`。** 对每个固定K≥1，在另有承诺
“至少一个普通OPT调度每机至多含K个无零边任务”的输入类上，存在确定性位多项式算法，
输出真实完整分配，比例为(1)（K2、K3可用上述更强值）。算法次数可依赖固定K；
不是K作为输入时的统一多项式声明，也不是一般主目标。

零边任务先独立安排，剩余n=0时输出零调度。枚举每行大小≤K的全部任务子集，
有O(m n^K)个；将其有理负载和组成排序候选阈值集（含0）。
在这些阈值上用等式覆盖有理LP判断可行性，取第一个可行阈值T*并执行实际ST匹配。
配置LP只在这些子集和断点改变，可行性随T单调；若存在上述OPT调度，T=OPT时一定可行，
所以T*≤OPT。无需知道普通OPT，也不需假设舍入输出的接受集合单调。

固定K时列数、候选数和输入有理和的位长均多项式；显式有理LP有确定性位多项式算法，
解和匹配总编码长度受控。本文未集成通用LP软件，代码只核给定证书及舍入边界。
若所有阈值均不可行，只能可靠断言“没有满足本K上限的调度”，
不能在无结构承诺的输入上声称OPT>T或拒绝安排全部任务。
零OPT、空任务、单可用机器、不可用边及大分母由预处理、显式子集和与精确有理运算处理。

## 6. 失败接口、文献范围及状态

若K随输入增长，余量K^{-(K−1)}趋零，枚举指数也增长；两者都不能替代UM-TARGET-v1。
只限制“大任务”数量而另收费tiny任务，也不能直接套本证明：每配置剩余容量变成
T减其各自tiny工作量，右端不再是本证明统一的整数1；跨配置的共同负载尚待证明。
固定K正面定理不提供从任意P恢复该承诺的算法。

与已归档Page–Solis-Oba–Maack论文的“每行总可选任务数≤ℓ”不同：该论文PDF第2页定义
\(J_i=\{j:p_{ij}<\infty\}\)并限制|J_i|，这里仅限制所给正权配置的基数。
本文不据此认证全球新颖性。ST匹配和标准整数线性代数属已有工具；
一般证明、独立重构、实际审查和有限审计分别登记，外审未记录。
