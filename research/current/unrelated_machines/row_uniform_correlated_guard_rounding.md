# 逐行均匀相关读出的半数保留与平层原调度三二界

读取目的：检验把源变量的一个标签同时传给多处单位读出，是否足以支持近二困难性。这里允许任意跨测试相关性，直接构造共同标签和共同资源匹配；结论只覆盖下述简单、逐行均匀、平层结构。它不用 CONFIG 下界，也不把一般 UM 的主目标或反面标为完成。

## 1. 精确对象与版本

有限二部简单图 `G=(U,V,E)`，每对 `(u,v)` 至多一条边。每个左点有显式非空有限标签集 `A_u`。每个右点有 `q_v=deg(v)` 个不同单位资源 `R_v`；不同右点的资源互异，孤立右点没有资源。每条边 `e=(u,v)` 有显式全定义映射

\[
f_e:A_u\longrightarrow R_v,
\qquad |f_e^{-1}(r)|=|A_u|/q_v\quad(r\in R_v).
\]

这叫**逐行均匀**。一个左标签 `a_u` 决定该左点的全部边请求，不允许各边另选标签。记 `d_u=deg(u)`。读出集合 `F⊆E` 合法，是指其请求资源全局互异；输出须列出真实 `f_e(a_u)`。

`UM-ROW-UNIFORM-CORRELATED-GUARD-HALF-RETENTION-v2`：对每个上述显式输入，确定性总位多项式算法输出共同标签和合法 `F`，同时满足

\[
|F\cap\delta(u)|\ge\lceil d_u/2\rceil\qquad(u\in U).
\]

`d_u=0` 的配额为零，`d_u=1` 的唯一请求全保留。待审 scratch 的 v1 仅主张 `floor(d_u/2)`（单边另全保）；审查者只读该陈述后独立重构出本 v2 的更强结论。v1 未作为 canonical Claim 登记，不混用两结论。

- Objects / Domain：上列图、标签表与请求表；允许空图和孤立点。
- Quantifiers：对全部有限显式输入，同时对全部左点。
- Assumptions：简单关联、资源分区、`q_v=deg(v)`、每条复合请求行均匀；不是只假设某个标签列完美匹配。
- Conclusion：实际共同标签、实际整数保留集合与资源分配，逐点 ceil-half 配额；不声称该界最优。
- Dependencies：整数碰撞势、二部匹配的整数性；证明在下文自足给出，无外部近似定理。
- Evidence：陈述先行独立重构、随后攻击及精确实现，见审查与审计。
- Counterevidence / Objections：第 5 节给出删除承重假设的反例；没有一般 UM 结论。
- Status：完整限定范围证明；独立内部攻击通过；构造器已实现；外审、新颖性与可独立成文性未认证。

## 2. 整数势同时选择真实标签

给定一个全左标签赋值。资源 `r` 的请求数记为 `c_r`，定义

\[
\Phi=\sum_r\binom{c_r}{2},\qquad
C_u=\sum_{e\in\delta(u)}(c_{f_e(a_u)}-1).
\]

固定其它左标签，移走 `u` 的请求。其余请求数记 `c^{-u}`。若改为标签 `a`，新碰撞成本为

\[
C_u(a\mid a_{-u})=\sum_{e\in\delta(u)}c^{-u}_{f_e(a)}.
\]

简单关联与右资源互异保证同一个 `u` 的两条请求永远不落在同一资源。因此同时更换该左点的全部请求时，势差**精确**等于新旧 `C_u` 之差，没有遗漏该左点内部的二次项。

在 `A_u` 上均匀平均，逐行均匀给出

\[
\frac1{|A_u|}\sum_a C_u(a\mid a_{-u})
=\sum_{v\in N(u)}\frac{q_v-1}{q_v}<d_u
\quad(d_u>0).
\]

每个测试中其它请求恰为 `q_v−1`；其它左点的当前标签可以任意相关，无需它们随机或独立。逐次扫描左点及其显式标签，只要 `C_u` 严格减小便更换。每次势至少下降 1，初势至多

\[
\sum_v\binom{q_v}{2}\le\binom{|E|}{2}.
\]

停止时每个左点的当前成本不大于上述标签平均值。因为成本是整数，所有非孤立左点同时满足

\[
C_u\le d_u-1.\tag{1}
\]

这是对同一个最终全左标签赋值的结论。

## 3. 一次全局匹配实现 ceil-half

对每条请求给分数 `1/c_r`。资源上的分数和为 1。对整数 `c≥1` 有

\[
\frac1c\ge 1-\frac{c-1}{2}.
\]

`c=1,2` 等号；`c≥3` 时右边非正。由 (1)，每个非孤立左点的分数和至少

\[
\sum_{e\in\delta(u)}\frac1{c_{f_e(a_u)}}
\ge d_u-\frac{C_u}{2}
\ge\frac{d_u+1}{2}
\ge\lceil d_u/2\rceil.\tag{2}
\]

把每个左点复制成 `ceil(d_u/2)` 个配额节点，均连接其当前真实请求资源。(2) 是覆盖这些配额的分数匹配；或将每行分数缩到精确配额，得到标准二部流。整数性给覆盖全部配额的整数匹配。不同测试的资源互异且每左每测试仅一边，匹配的资源唯一确定一条原请求边，故得到所需 `F`。

另一个不经过分数的 Hall 检查是：先删去配额为零的孤立左点，对其余任意左点集 `S`，令 `k_r` 为 `S` 对资源 `r` 的请求数，`D_S=Σ_{u∈S}d_u`。则

\[
\sum_r k_r(k_r-1)\le\sum_{u\in S} C_u\le D_S-|S|.
\]

利用 `k(k−1)≥2(k−1)`（`k≥1`）得到

\[
|N(S)|\ge(D_S+|S|)/2\ge\sum_{u\in S}\lceil d_u/2\rceil.
\]

这给出全部共同配额的 Hall 条件，避免把单个左点可支付误当成全局可支付。

## 4. 完整平层 UM 的实际三二输出

`UM-ROW-UNIFORM-FLAT-STATE-THREE-HALVES-v1` 的 Objects 是给定上述分组数据并按下面规则显式编译的原处理时间矩阵；不包含从未知矩阵识别该结构的附加问题。

每个 `(u,a)` 建一台 parent `M_{u,a}`，每个资源建一台外机。每左点有一枚单位 selector，可在其任一 parent 上处理。`d_u>0` 时，每个状态 `a` 和每条 incident edge `e` 有一枚不同 port：在 `M_{u,a}` 上时间 `1/d_u`，在外机 `f_e(a)` 上时间 1。未列资格为 `∞`。没有预载、隐含任务或免费组容量。`d_u=0` 时没有 ports；若无机器，添一台空 dummy，使 `m≥1`。

取第 1—3 节的同一个标签赋值和匹配：selector 放选中 parent；选中状态的 `F` ports 放其真实外机；其它**所有状态、所有原 ports** 留各自 parent。于是

- `d_u>0` 时，未选 parent 有全部 `d_u` 枚 ports，负载 1；
- `d_u>0` 时，选中 parent 负载为 `1+(d_u−|F∩δ(u)|)/d_u≤1+floor(d_u/2)/d_u≤3/2`；
- 外机负载至多 1；孤立左点的选中 parent 负载 1，其余 parent 负载 0。

因此算法输出完整合法 `σ`，`C_max≤3/2`。`U≠∅` 时单位 selector 给 `OPT≥1`，故 `C_max≤(3/2)OPT`；`U=∅` 时无任务，输出空 `σ`，`OPT=C_max=0`。这里处理时间均为正有理；一般零时间矩阵未被额外宣称落在此编译类。

- Quantifiers / Assumptions：全部上述显式结构输入，标签数、两侧度数均可无界；沿用 retention v2 的全部条件。
- Scope / Conclusion：这一完整平层原调度子类的确定性位多项式 `3/2` 近似和绝对 `3/2` 负载；不是一般 UM 的 `3/2` 算法，也不声称近似比锐利。
- Dependencies：`UM-ROW-UNIFORM-CORRELATED-GUARD-HALF-RETENTION-v2` 与 `UM-MODEL-v1`。
- Evidence / Status：完整构造证明，陈述先行独立内部攻击通过，实际全任务输出与 Fraction 回算已实现；外审、新颖性未认证。
- Counterevidence：删除简单性或逐行均匀性后，下面的反例否定统一绝对 `3/2` 输出；其 `OPT` 也上升，故不能据此否定更大类的另一种 `3/2` 近似算法。

## 5. 承重假设与否定范围

**多重自查询。** 一左点、四条平行边到同一右测试，四标签和四资源，每条请求都是同一个 identity 映射。各行均匀，但任何标签都将四请求压到同一资源，只能保一条。平层编译的精确 `OPT=7/4`：选中 parent 的四 ports 最多一枚外送，另三枚各 `1/4`；按此分配即可达到。简单性不可删除。

**纯列完美不推出逐行均匀。** 取两个左点 `u,w`、一个度 2 右测试、资源 `0,1`，各左仅一个标签，右标签集 `{0,1}`。令 `φ_{uv}(b)=b`、`φ_{wv}(b)=1−b`，故每个纯 `b` 的两请求是完美匹配；但令左投影分别常为 `0,1`，复合请求都为资源 0。不能同时各保留唯一读出。平层编译的精确 `OPT=2`：若每台负载小于 2，两个选中 parent 的单位 port 都须外送，却同机碰撞；将一枚留 parent 即达到 2。这个例子未声称有共同 projection 边际。

因此若一个困难性编译的全部弱调度阻碍恰为本简单逐行均匀单位读出及其平层 parent，上述算法直接给共同可行解。跨测试共享同一源标签本身不足以使读出比例趋零。重试须实质改变承重对象，例如非均匀复合行、同一左点的多重自查询、跨资源组耦合、非平层祖先约束或非单位/非均匀处理时间，并重新检查全部原任务负载。此结论不替这些方向证明 soundness。

## 6. 构造性、验证及文献对照

记显式输入总编码长为 `L`。势为不超过 `|E|²` 的整数，严格改标次数多项式；一次扫描只访问显式映射表。配额节点总数不超过 `|E|`，资源数为 `|E|`，增广匹配及完整 port 编译均为多项式。处理时间 `1/d_u` 仅需 `O(log(d_u+1))` 位；没有以处理时间数值代替输入位长。实现额外用 Fraction 检查 (2)，其分母可用 `|E|!` 公倍数界定为多项式位长。

[实现](../../../tests/audits/unrelated_machines/row_uniform_correlated_guard.py)用整数势与增广匹配构造实际 `σ`。[冻结证据](../../../evidence/runs/unrelated_machines/row_uniform_correlated_guard_audit.json)逐项保存 361 个输入和输出；1646 个标签 profile 中 943 个稳定点通过全部左点子集 Hall 核验；6068 枚原任务回算、12 个非法输入拒绝。挫折三角的 32768 个完整合法调度独立枚举给精确 `OPT=3/2`，构造器也输出 `3/2`；这不是三二近似比的锐例。有限核验不替代第 2—4 节证明。

最接近的背景是 Combinatorial Santa Claus 的 relaxed matching：Bamas–Garg–Rohwedder [arXiv:2007.09116v2](https://arxiv.org/abs/2007.09116v2) 摘要回顾 uniform regular hypergraph 的常数 relaxed matching，并研究非均匀情形；该稿明确被 [arXiv:2011.06939](https://arxiv.org/abs/2011.06939) 取代。这里的资源束大小可随 `d_u` 变化；换取的额外条件是每条请求行均匀及每左每测试一次。本文的具体增量是该子类的显式整数势、逐点 ceil-half 共同匹配和完整原 `3/2` 调度，不把已有 relaxed matching 的常数存在性当成本项新结果。尚未认证这个简单局部势论证在相关文献中的新颖性，更未认证独立论文价值。
