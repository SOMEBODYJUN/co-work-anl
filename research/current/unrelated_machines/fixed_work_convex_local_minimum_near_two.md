# 固定总工作量下凸势与排序势的近二局部极小族

本页登记精确身份 `UM-FIXED-WORK-CONVEX-LOCAL-MINIMUM-v1`。它审计一条可能的全局交换路线：即使总处理量对所有分配都固定，并且机器完全相同，二次负载势和按负载排序的词典序势也可以在一个接近二倍的严格单任务局部极小点停止。该族不证明一般调度困难性，也不否定允许无界同步批量、全局重求解或改变势函数的算法。

## 1. 精确命题

对每个整数 `m≥3`，构造 `m` 台完全相同的机器和 `m²+1` 件任务。两件任务 `u_1,u_2` 的处理时间在每台机器上均为 `1`；其余 `m²−1` 件 tiny 任务的处理时间在每台机器上均为 `1/m`。因此所有边有限、所有时间为正，并且任意完整分配的总工作量相同。

初始分配 `σ⁰` 把 `u_1,u_2` 放在机器 `0`，把 tiny 任务均分为 `m+1` 件放在每台机器 `1,…,m−1`。记

\[
 d=1+1/m,
 \qquad L(σ⁰)=(2,d,d,\ldots,d).
\]

则：

1. `OPT=1+2/m`，而 `C_max(σ⁰)=2`，所以
   \[
   \frac{C_{\max}(σ⁰)}{OPT}=\frac{2m}{m+2}\xrightarrow[m\to\infty]{}2.
   \]
2. 二次势 `Φ(σ)=Σ_i L_i(σ)^2` 在 `σ⁰` 处对每一个单任务换机都严格增加。
3. 将负载按非增序排列得到的向量在每一个单任务换机后都严格词典序变差；故 `σ⁰` 也是排序势的严格单任务局部极小点。
4. 对任意 `0<ε<1`，若一个分配满足 `C_max≤2−ε`，则相对于 `σ⁰` 至少改变
   \[
   2+\lceil εm\rceil
   \]
   件任务（一个 unit 任务和至少 `1+\lceil εm\rceil` 件 tiny 任务）。因此固定批量大小不能给出统一的次二修复。

这里“局部”只允许一次把一件任务改到另一台机器；不限制机器之间的处理时间，因为本族所有机器相同。结论的有限计算审计只核验构造和公式，不承担全称命题之外的复杂度或困难性结论。

## 2. 目标值与精确 OPT 证明

初始 tiny 数为 `(m−1)(m+1)=m²−1`，故初始负载如上，总工作量恒为
\[
W=2+(m²−1)/m=m+2−1/m.
\]

先给出达到上界的分配：把两个 unit 任务分别放到机器 `0,1`；机器 `0,1` 各接两件 tiny；其余 `m−2` 台机器中一台接 `m+1` 件 tiny，其余各接 `m+2` 件 tiny。tiny 总数为
\[
2+2+(m+1)+(m−3)(m+2)=m²−1,
\]
且最大负载为 `1+2/m`。

反过来，假设某分配的最大负载严格小于 `1+2/m`。两个 unit 任务不能在同一台机器上，因为那会产生负载 `2>1+2/m`（`m≥3`）。在两个分别承载 unit 的机器上，剩余容量严格小于 `2/m`，所以每台至多放一件 tiny；其余 `m−2` 台机器的 tiny 数严格小于 `m+2`，至多放 `m+1` 件。这样全部 tiny 至多可放
\[
2+(m−2)(m+1)=m²−m<m²−1,
\]
矛盾。因此 `OPT=1+2/m`。

## 3. 二次势和排序势的严格局部极小

初始势为
\[
Φ(σ⁰)=4+(m−1)(1+1/m)^2.
\]
只有三种单任务换机：

* 把机器 `0` 上的一件 unit 移到某台 `i≥1`：相关负载由 `(2,d)` 变成 `(1,d+1)`，故
  \[
  ΔΦ=1^2+(d+1)^2-2^2-d^2=2/m>0.
  \]
* 把某台 `i≥1` 上的一件 tiny 移到机器 `0`：相关负载由 `(d,2)` 变成 `(d−1/m,2+1/m)=(1,2+1/m)`，同样 `ΔΦ=2/m>0`。
* 把 tiny 从一台 `i≥1` 移到另一台 `k≥1`：相关负载由 `(d,d)` 变成 `(d−1/m,d+1/m)=(1,1+2/m)`，故 `ΔΦ=2/m²>0`。

相应排序负载向量也严格变差：前两种动作把最大值从 `2` 提高到 `2+1/m`；第三种保持首项 `2` 不变，却把第二大负载从 `d=1+1/m` 提高到 `1+2/m`。所以词典序排序势同样没有单任务下降步。注意总工作量 `W` 在所有分配间都相同；该障碍不是由势函数偏好较小总工作量造成的。

## 4. 近二比值与批量支持下界

给定 `0<ε<1`，考虑任意 `C_max≤2−ε` 的分配。由于 `2−ε<2`，两个 unit 任务必须分开，至少有一个 unit 从初始机器 `0` 移到某台 `k≥1`。机器 `k` 初始有 `m+1` 件 tiny；最终在其上已有一个 unit，故最多可保留
\[
\left\lfloor m(C_{\max}-1)\right\rfloor
\le \lfloor m(1−ε)\rfloor
=m-\lceil εm\rceil
\]
件 tiny。因此至少有
\[
(m+1)-(m-\lceil εm\rceil)=1+\lceil εm\rceil
\]
件 tiny 离开 `k`。连同离开机器0的 unit，支持大小至少 `2+\lceil εm\rceil`。

另一方面，取 `m>4/ε−2` 时，初始比值 `2m/(m+2)>2−ε`。于是任何只允许固定数量任务同步迁移的修复合同，都在这族上失效；这只是对该局部合同的反例，不是对所有算法的困难性证明。

## 5. 复杂度、边界和范围

显式矩阵有 `m(m²+1)=O(m³)` 个条目，每个条目的编码长度为 `O(log m)`；构造、初始分配、上界分配和局部动作检查均按显式输入位长多项式时间完成。tiny 的分母是 `m`，没有按处理时间数值展开槽。比例趋二只使用 `m` 无界，未把 `m` 当固定参数。

“全局最小化凸势”本身也不能作为免费的位多项式子程序。即使在两台完全相同的机器上，给定整数任务大小 `a_1,…,a_n`、总和 `W`，分配到两机的二次势为
\[
S^2+(W-S)^2=W^2/2+2(S-W/2)^2,
\]
其中 `S` 是第一台机器的总量。若 `W` 为偶数，判定是否存在势值 `≤W²/2` 正好判定 `PARTITION`。因此要求精确全局凸势最小点至少包含一个 NP-hard（弱意义）子问题；任何次二算法若调用该目标，必须另给近似势的位多项式求法及其与 `C_max` 的严格桥梁。本段是潜势搜索的复杂度义务，不是 `R||C_max` 的新困难性声明。

本族所有处理时间正且有限，`OPT>0`。它不覆盖 `OPT=0` 的边界：若一般输入的每件任务都有零处理时间可用边，则可逐件选零边，得到 `C_max=OPT=0`；任何算法的近似不等式在该分支是 `0≤(2−ε)·0`。因此该零值预处理必须与本正值局部障碍分开。

`m=2` 不纳入命题，因为上述计数族的最优值与初始值不产生趋二比；空任务、不可用边和零任务也不是本族对象。这里没有复杂度假设、随机性、估值或外部文献调用。该族只排除“从任意状态出发、每一步只换一件任务、保持二次势或排序势严格下降”的统一次二合同；允许无界批量、非单调过渡、接收机增载或直接全局优化的路线仍未判定。

**Truth / Value / Novelty / Ambition。** 负载公式、`OPT` 计数和局部势差是自足精确结论；价值在于把固定工作量也纳入局部修复审计。它不是 `R||C_max` 的 NP-hardness 归约，也不声称新颖性或论文级独立性。后续若研究全局势，必须说明如何在位多项式时间找到全局势极小点，以及该极小点如何与 `C_max` 关联；本族的固定工作量并不能替代这两个义务。
