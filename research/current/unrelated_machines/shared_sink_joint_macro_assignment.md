# 单共享汇点的宏任务共同匹配与私有任务整组撤离

## 1. 精确身份与主目标的关系

`UM-SHARED-SINK-JOINT-MACRO-v1` 是一个正面的限域可构造接口。它允许同时重选全部宏任务，而不是固定宏任务后再优化微任务。它不解决一般 `UM-TARGET-v1`：任意实例的任务未必有唯一 home，多个共享接收机器也未必能化成同一个真实成本标量。

**Objects / Domain / Definitions。** 机器为不交并 `H ∪ {z}`，`H` 是显式给定的 homes。任务分成宏任务集 `B` 和两两不交的私有组 `S_h (h∈H)`。宏任务仅在 homes 可用；私有任务 `j∈S_h` 的有限端点是 `{h,z}` 的非空子集。有限时间是二进制非负有理数，其余为不可用。给定二进制有理 `T≥0`、`0<η≤1`，要求每个有限宏任务时间严格大于 `T/2`。私有任务不要求小于某个阈值，因而“私有”不等于通常按尺寸定义的 tiny。

**Exact Statement / Quantifiers。** 对所有上述输入，有一个统一确定性算法，时间为 `poly(输入总位长,1/η)`，返回 FAIL 或实际合法分配。每个返回分配均满足

`L_h≤T (∀h∈H),  L_z≤(1+η)T`。

若 `OPT≤T`，算法必返回分配；所以 FAIL 蕴含 `OPT>T`。成功不表示原 `T` 精确可行。宏任务数、home 数、私有任务数均不固定，不给调度分布或好匹配 oracle。

**Dependencies。** `UM-MODEL-v1`；下文自足的非负成本覆盖背包缩放及最小成本二分图匹配。不依赖配置 LP、真实最优凸分解或整数见证 oracle。

**Status。** 完整限域证明，已经先行独立重构、冻结攻击与双路精确核验；未发现声明范围内仍成立的致命异议，未外审，未认证新颖性。最小覆盖背包的近似方案、二分图最小成本匹配均为标准工具；本文新增记录的是两者在共同迁移中的精确输入/输出合同，不主张通用新算法或独立论文价值。

## 2. 每个占位模式的真实撤离成本

先分离每个 `S_h`：仅在 home 可用者必须留在 `h`，其时间和记 `F_h`；仅在 `z` 可用者必须去 `z`，全部组的这种成本和记 `c_forced`；两端均可用者形成 `U_h`，写 `a_j=p_hj, c_j=p_zj`。强制任务可有零时间。若 `c_forced>T` 可安全 FAIL。

模式 `t` 是一个在 `h` 可用且时间 `β_ht≤T` 的宏任务，或空模式 `0`，其 `β_h0=0`。如果 `F_h+β_ht>T`，该模式不存在。否则从 `U_h` 选择实际子集 `X` 送去 `z`，余者留在 `h`，需满足

`Σ_(j∈X) a_j ≥ D_ht := max(0,F_h+β_ht+Σ_(j∈U_h)a_j−T)`。

令 `c*_ht` 为该覆盖条件下 `Σ_(j∈X)c_j` 的最小值。因为全部 `U_h` 都可送 `z`，模式存在时此覆盖问题必可行；其成本可为零。重要的是 `c*_ht` 与一个实现它的任务子集同时存在，不能只取互不相容的坐标下包络。

## 3. 保覆盖、保零成本的自足缩放

以下给任意非负有理覆盖实例 `(a_j,c_j,D)`、`q` 件物品的确定性子程序，返回可行集合 `X`，成本 `ĉ≤(1+η)c*`。可行性在真实 `a` 上精确检查；从不对覆盖值作向下近似。

先取所有 `c_j=0` 的物品。若已覆盖 `D`，返回成本零；否则减去其覆盖值，剩余最优成本严格正。若全部剩余物品仍不能覆盖，返回不可行。令剩余物品数为 `q≥1`。

对每个不同的正成本 `C` 作一次猜测：只准使用 `c_j≤C` 的物品，设 `s=ηC/q`，整数成本 `w_j=floor(c_j/s)`。每项 `w_j≤q/η`，总整数成本不超过 `q floor(q/η)`。按整数成本动态规划，保存每个精确整数成本的最大真实覆盖量及实际集合；使用逐层表/不可变回溯，保证同件物品不复用。选覆盖成功的最小整数成本状态。最后在所有猜测的候选中选真实成本最小者。

若 `X*` 是正最优成本的最优集合，取猜测 `C=max_(j∈X*)c_j`。该猜测保留 `X*`，且 `C≤c*`。DP 返回 `X` 时，`Σ_X w_j≤Σ_X* w_j`，因此

`Σ_X c_j < sΣ_X(w_j+1) ≤ sΣ_X* w_j+qs ≤ c*+ηC ≤ (1+η)c*`。

严格号只用于有物品的正成本分支；最终使用非严格保证即可。被预先加入的零成本物品不会改变这个界。若 `D=0`、空组或零最优值，零成本分支精确返回，不把乘性误差变成正加性误差。

每次猜测至多 `O(q³/η)` 状态更新，至多 `q` 次猜测，共 `O(q⁴/η)`；回溯集合可用多项式存储。`a` 的和与所有整数比较/有理运算均有输入位长的多项式上界，极小正成本和大分母不增加状态数。

## 4. 一次全局匹配共同重选全部宏任务

设 `b=|B|, h=|H|`。若 `b>h`，因每个 `T` 可行 home 至多接一个宏任务，可安全 FAIL。对每个存在的 `(h,t)` 模式运行第 3 节，得到实现子集 `X_ht` 及真实成本 `ĉ_ht≤(1+η)c*_ht`。

建二分图，右侧为全部 homes，左侧为 `b` 个真实宏任务和 `h−b` 个互异 dummy。真实宏任务 `t` 到 `h` 的边表示存在的模式 `(h,t)`，成本为 `ĉ_ht`；每个 dummy 到 `h` 的边成本为 `ĉ_h0`，表示空模式。找最小成本完美匹配；无完美匹配则 FAIL。

每个 home 恰选一个模式，所有宏任务恰使用一次。按匹配恢复各 `X_ht`、全部强制任务及宏任务；私有组不交，所以没有重复分配。每个 home 的负载精确不超过 `T`，真实汇点负载是

`c_forced + Σ_(匹配边(h,t)) ĉ_ht`。

如果该负载大于 `(1+η)T` 则 FAIL，否则返回实际分配。所有成功输出的界可独立直接核算。

**不漏掉 `T` 可行实例。** 任取一个实际 `T` 调度。由于每条有限宏任务边大于 `T/2`，每个 home 至多有一个宏任务；用 dummies 补成一个完美匹配 `M*`。其私有任务撤离集合给每个匹配模式的可行解，故

`c_forced + Σ_(M*) c*_ht ≤ T`。

最小成本匹配 `M` 的成本不大于 `M*`，于是

`c_forced+Σ_(M)ĉ_ht ≤ c_forced+(1+η)Σ_(M*)c*_ht ≤ (1+η)T`。

没有按 home 数累加误差：各局部误差乘在同一个真实汇点成本上，再一起求和。宏任务和整组撤离是同一个匹配决策，未预先冻结宏任务。

## 5. 总位复杂度与退化输入

至多 `h(b+1)` 个模式，每个至多执行 `O(q_h⁴/η)` 覆盖 DP。匹配图至多 `2h` 个顶点和 `h²` 条边；可用单位容量最小成本流：从零流开始，每次沿残余最短增广路增加一单位，至多 `h` 次。以精确有理 Bellman–Ford 求最短路，反向边成本取负；最小成本流的逐流量最优性保证不存在负残余环，故所得完美匹配为最小成本。固定顶点/边顺序及平局规则使算法确定。规范代码采用等价的整数 Hungarian：将实际有理模式成本的全部分母乘积清掉，用严格大于任何全有限完美匹配成本的大罚表示禁边，并在结束后检查是否用了禁边；其状态和迭代为 O(h³)。

所有成本是原 `p_zj` 的实际子集和，覆盖值是原 `p_hj` 的实际子集和；有理最短路和总成本的分母位长受输入分母位长总和及多项式运算次数控制。这里证明的是整个构造的总多项式界，不是只说每步多项式；审计中的指数枚举不属于算法。

空任务返回空分配。`H=∅` 时宏任务与全部私有任务均为空，唯一机器 `z` 的负载为零。`T=0` 且有宏任务时，所有宏任务有限时间均正，剪枝后无可用边，安全 FAIL；无宏任务时，以上零成本分支精确检查是否可把每件任务分给零边。仅一个有限端点、空私有组、零 home 时间、零 sink 时间、完全相同成本、极大有理分母均由同一构造覆盖。

## 6. 可复用内容、边界与下一义务

此接口覆盖第 10 节[冻结宏任务反例](optimal_hull_marginal_rounding_barrier.md#10-冻结宏任务后的微任务全局重开间隙与尖锐迁移前沿)的整个共同汇点结构，允许一次改变线性数量的宏任务；无需在原槽图内修复，也不保持给定分数点的逐行计数。宏任务 eligibility 图可以任意有环，所以它不只是森林消元。

然而一般实例中一个任务可在多个 home 间改变自身尺寸身份，且有多个共同接收容量。单汇点成本相加只控制一个实际预算，不能把最小加权和误当同时满足全部预算。多个 sinks 的局部相关菜单也不自动给全局可构造选择，完美匹配添加多预算约束后不再自动积分。接下来必须明确新增的可交换结构、真正共同的容量信息或新的舍入余量；不把这个限域接口升级成 `UM-TARGET-v1` 的统一算法。

最接近的已知工具是最小覆盖背包 FPTAS 与最小成本二分图匹配。文献背景可核 Bentz–Le Bodic, arXiv:1607.07950；本文未调用其更快复杂度，也未认证上述拓扑合同的全球优先权。Truth、Value、Novelty、Mechanism、Ambition 分开：当前价值是实际共同选择、整组迁移及误差不按机器数累积；一般模型的统一常数仍缺失。

## 7. 实现、独立审查与有限证据

规范实现：[shared_sink_joint_assignment.py](../../../tests/audits/unrelated_machines/shared_sink_joint_assignment.py)，API `solve_shared_sink(H, macros, tinies, T, eta)`，输出宏任务在前、私有任务在后的实际机器列表与 Fraction 负载，或可靠的 `REJECT_TARGET`。Python 输入拒绝浮点和布尔量；二进制有理数或其精确字符串表示可用。

规范审计包含独立子集枚举、排列匹配与原任务逐件分配 oracle，种子、源码哈希、边界和实际枚举数写入冻结运行记录。独立实现使用不同的全局绝对预算 floor DP，作为第二条构造及独立实际分配核对。一般证明与这些有限检查分开。

[冻结独立审查](../../reviews/unrelated_machines/shared_sink_joint_review.md)记录先行重构与最终版本。规范[冻结结果](../../../evidence/runs/unrelated_machines/shared_sink_joint_assignment_audit.json)为500个覆盖子集、200个匹配排列、600个原分配随机用例和14个边界，实际枚举155915个调度；10个非法合同检查。独立[第二实现](../../../tests/audits/unrelated_machines/shared_sink_joint_independent.py)及其[冻结结果](../../../evidence/runs/unrelated_machines/shared_sink_joint_independent_audit.json)检查41207个合法用例、593913个实际分配，23280个OPT≤T实例两构造均成功。不同算法在OPT>T时可作不同选择，可靠FAIL与资源增广成功不矛盾。

独立实现的不同机制为全局尺度 `s=ηT/N`（N为全部私有任务数，N0/T0另分支），对各sink时间floor，整数预算 `Q=floor(N/η)`；每home按整数sink成本保存最小真实home负载，所有home的总舍入损失小于Ns。它保证本命题的one-sided接口，不声称对一般home可行最小sink成本有乘性近似；第3节的乘性证明仅用于规范构造。
