# 真实最优调度凸包与固定有序槽图的近2损失

本页攻击一个直接联合舍入接口，不攻击主目标 `UM-TARGET-v1`。分数点甚至有显式真实最优调度凸分解，但把它压成一个标准有序单位槽图后，**所有**覆盖任务的槽匹配都可接近2倍真实OPT。缺失的并非单机容量有效性，而是该槽图强加的逐机任务基数。可以直接输出给出的最优分量，故没有算法困难性结论。

## 1. Exact Claim：UM-OPTIMAL-CONVEX-ST-SLOT-GAP-v1

对每个整数m≥2，存在m台完全相同机器、n=m²个任务的UM-MODEL-v1正有理实例P_m，及m个显式最优调度σ⁰,…,σ^(m−1)，满足：

1. OPT(P_m)=1，且每个σᵃ的每台机器负载都为1。
2. 它们的均匀凸组合边际为x_ij=1/m；因此x在**真实全局最优调度的凸包**内，而不只是配置LP投影。
3. 对每台机器按处理时间非增排列正x区间，平局采用任意次序，以单位槽切分并只连接正交长（UM-ST-ROUND-v1的标准构造）。对由此得到的**每一个**覆盖全部任务的槽匹配，其对应调度的makespan精确为

   2m/(m+1)=2−2/(m+1)。

**关联派生命题 UM-OPTIMAL-CONVEX-SLOT-REPAIR-v1。** 对任意这样的覆盖匹配，允许离开固定槽图后，可将大任务机上的m−1个小任务分别迁到其他m−1台机器，在线性组合时间内恢复OPT=1；恰需改变m−1个任务的机器。原反例身份只包含上列1–3，修复的独立结论另立身份，证明见第4节。

机器数m可变。输入矩阵、凸分解、x和一份覆盖匹配均有关于m的多项式编码长度，并可确定性多项式构造。所有边均有限、所有时间均正，分数负载恰1。任意同值任务排序均保留第3项。

故不存在统一ε>0，使对所有这样的(P,T,x)，这个固定槽图总含makespan≤(2−ε)T的覆盖匹配：取T=OPT=1和m+1>2/ε即可。此结论只限制固定槽图的输出空间；不限制另选x、改变槽构造、直接用凸分解、重新迁移任务或其他算法。

## 2. 输入与真实最优凸分解

任务为一个大任务b和小任务s₁,…,s_(m²−1)。在每台机器上均有

p_ib=1，　p_is=1/(m+1)。

把全部小任务固定分成m−1个组G₁,…,G_(m−1)，每组m+1个任务。机器编号暂取0,…,m−1。σᵃ把b分给a，将G_r分给(a+r) mod m。大任务独占一机，每个其他机器恰有m+1个小任务，故所有机器负载都为1。

大任务本身强制OPT≥1；上述调度给OPT≤1，因此OPT=1。每个任务在a从0到m−1遍历时恰访问每台机器一次。均匀平均这些0/1分配即给x_ij=1/m。每机器分数负载还可独立反算：

Σ_j p_ij x_ij = [1+(m²−1)/(m+1)]/m = [1+(m−1)]/m = 1。

这一步提供真实全局凸包证书，不能与此前配置LP间隙族混淆。

## 3. 固定槽匹配的精确整数值

每机总分数任务质量为Σ_jx_ij=m²/m=m。因此每机**恰有m个槽**，全部m²个槽与任务数相同。任意覆盖全部m²任务的匹配必须用尽所有槽，故每机器最终恰有m个任务。

唯一大任务所在机器于是还有m−1个小任务，负载为

1+(m−1)/(m+1)=2m/(m+1)。

其他机器只有m个小任务，负载为m/(m+1)。所以每个覆盖匹配的makespan都精确等于所声明的值。这个计数与机器之间的小任务平局次序无关，也不依赖任何浮点或渐近猜测。

覆盖匹配确实存在：区间交长给每任务总质量1、每槽总质量1，Hall条件保证覆盖。若各机采用共同任务索引处理平局，还可直接构造：把排序后的m²任务每m个分成一块，第r块恰占各机器的第r槽；该块内第i个任务匹配到机器i的该槽。任意平局也可由标准增广匹配构造，位复杂度沿经典接口。

这说明失败甚至不是“选择了坏匹配”：固定图里不存在更好的匹配。分数点所来自的最优调度都被这个图排除，因为那些调度的非大任务机器各有m+1个任务，超过槽图逐机上限m。

## 4. 跨槽修复、复杂度、边界与精确范围

**本族的一轮最优修复。** 任意槽匹配中，大任务机还有m−1个小任务，其余每机有m个小任务。把这m−1个任务一一迁到其他m−1台机器后，大任务机负载1，其余每机有m+1个小任务、负载也为1。扫描调度后只需O(n+m)组合操作，所有负载精确可算；总位复杂度多项式。若大任务不换机，达到1必须移走同机全部m−1个正时间小任务；若大任务换机，其目标原有m个小任务均须移走，连同大任务至少改变m+1项。因此该m−1项Hamming修改数最优。这个修复主动突破原槽容量，不能表示为同图内另选匹配。

稠密P和x各有m³项；每个数的编码为O(log(m+1))位。显式列m个长度m²的调度也只需O(m³ log(m+1))位。构造遍历上述列表、排序及增广匹配均在实际输入/证书位长上多项式。这里不是声称任意原输入的最优凸分解可多项式求出；本族分解是显式证书。

m=1也可按同一公式定义为只有b的单任务实例，匹配值和OPT均为1；趋2结论使用m≥2且m无界。空任务、零时间和∞不出现在反例族中，因此它属于主模型的一个严格合法子类，足以反驳全称舍入合同。本文没有把这些正值例子的归一化推广为零OPT算法。

标准ST一般2T上界保持成立。此处处理时间按行跨度m+1增长，故也不反驳UM-ROW-SPREAD-TWO-ROUND-v1的两倍跨度正面结果。已给的σᵃ可直接取任一个作为最优输出；即使算法接收整个凸分解，只有在强制它最终输出这个固定槽图的匹配时才受本页限制。
