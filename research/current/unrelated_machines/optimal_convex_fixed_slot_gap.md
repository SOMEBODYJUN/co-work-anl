# 真实最优调度凸包与固定有序槽图的近2损失

本页攻击一个直接联合舍入接口，不攻击主目标 `UM-TARGET-v1`。分数点甚至有显式真实最优调度凸分解，但把它压成一个标准有序单位槽图后，**所有**覆盖任务的槽匹配都可接近2倍真实OPT。缺失的并非单机容量有效性，而是该槽图强加的逐机任务基数。可以直接输出给出的最优分量，故没有算法困难性结论。

## 1. Exact Claim：UM-OPTIMAL-CONVEX-ST-SLOT-GAP-v1

对每个整数m≥2，存在m台完全相同机器、n=m²个任务的UM-MODEL-v1正有理实例P_m，及m个显式最优调度σ⁰,…,σ^(m−1)，满足：

1. OPT(P_m)=1，且每个σᵃ的每台机器负载都为1。
2. 它们的均匀凸组合边际为x_ij=1/m；因此x在**真实全局最优调度的凸包**内，而不只是配置LP投影。
3. 对每台机器按处理时间非增排列正x区间，平局采用任意次序，以单位槽切分并只连接正交长（UM-ST-ROUND-v1的标准构造）。对由此得到的**每一个**覆盖全部任务的槽匹配，其对应调度的makespan精确为

   2m/(m+1)=2−2/(m+1)。

**关联派生命题 UM-OPTIMAL-CONVEX-SLOT-REPAIR-v1。** 对任意这样的覆盖匹配，允许离开固定槽图后，可将大任务机上的m−1个小任务分别迁到其他m−1台机器，在线性组合时间内恢复OPT=1；恰需改变m−1个任务的机器。原反例身份只包含上列1–3，修复的独立结论另立身份，证明见第4节。

机器数m可变。输入矩阵、凸分解、x和一份覆盖匹配均有关于m的多项式编码长度，并可确定性多项式构造。所有边均有限、所有时间均正，分数负载恰1。任意同值任务排序均保留第3项。

故不存在统一ε>0，使对所有这样的(P,T,x)，这个固定槽图总含makespan≤(2−ε)T的覆盖匹配：取T=OPT=1和m+1>2/ε即可。此结论只限制固定槽图的输出空间；不限制另选x、改变槽构造、直接用凸分解、重新迁移任务或其他算法。

## 2. 输入与真实最优凸分解

任务为一个大任务b和小任务s₁,…,s_(m²−1)。在每台机器上均有

p_ib=1，　p_is=1/(m+1)。

把全部小任务固定分成m−1个组G₁,…,G_(m−1)，每组m+1个任务。机器编号暂取0,…,m−1。σᵃ把b分给a，将G_r分给(a+r) mod m。大任务独占一机，每个其他机器恰有m+1个小任务，故所有机器负载都为1。

大任务本身强制OPT≥1；上述调度给OPT≤1，因此OPT=1。每个任务在a从0到m−1遍历时恰访问每台机器一次。均匀平均这些0/1分配即给x_ij=1/m。每机器分数负载还可独立反算：

Σ_j p_ij x_ij = [1+(m²−1)/(m+1)]/m = [1+(m−1)]/m = 1。

这一步提供真实全局凸包证书，不能与此前配置LP间隙族混淆。

## 3. 固定槽匹配的精确整数值

每机总分数任务质量为Σ_jx_ij=m²/m=m。因此每机**恰有m个槽**，全部m²个槽与任务数相同。任意覆盖全部m²任务的匹配必须用尽所有槽，故每机器最终恰有m个任务。

唯一大任务所在机器于是还有m−1个小任务，负载为

1+(m−1)/(m+1)=2m/(m+1)。

其他机器只有m个小任务，负载为m/(m+1)。所以每个覆盖匹配的makespan都精确等于所声明的值。这个计数与机器之间的小任务平局次序无关，也不依赖任何浮点或渐近猜测。

覆盖匹配确实存在：区间交长给每任务总质量1、每槽总质量1，Hall条件保证覆盖。若各机采用共同任务索引处理平局，还可直接构造：把排序后的m²任务每m个分成一块，第r块恰占各机器的第r槽；该块内第i个任务匹配到机器i的该槽。任意平局也可由标准增广匹配构造，位复杂度沿经典接口。

这说明失败甚至不是“选择了坏匹配”：固定图里不存在更好的匹配。分数点所来自的最优调度都被这个图排除，因为那些调度的非大任务机器各有m+1个任务，超过槽图逐机上限m。

## 4. 跨槽修复、复杂度、边界与精确范围

**本族的一轮最优修复。** 任意槽匹配中，大任务机还有m−1个小任务，其余每机有m个小任务。把这m−1个任务一一迁到其他m−1台机器后，大任务机负载1，其余每机有m+1个小任务、负载也为1。扫描调度后只需O(n+m)组合操作，所有负载精确可算；总位复杂度多项式。若大任务不换机，达到1必须移走同机全部m−1个正时间小任务；若大任务换机，其目标原有m个小任务均须移走，连同大任务至少改变m+1项。因此该m−1项Hamming修改数最优。这个修复主动突破原槽容量，不能表示为同图内另选匹配。

稠密P和x各有m³项；每个数的编码为O(log(m+1))位。显式列m个长度m²的调度也只需O(m³ log(m+1))位。构造遍历上述列表、排序及增广匹配均在实际输入/证书位长上多项式。这里不是声称任意原输入的最优凸分解可多项式求出；本族分解是显式证书。

m=1也可按同一公式定义为只有b的单任务实例，匹配值和OPT均为1；趋2结论使用m≥2且m无界。空任务、零时间和∞不出现在反例族中，因此它属于主模型的一个严格合法子类，足以反驳全称舍入合同。本文没有把这些正值例子的归一化推广为零OPT算法。

标准ST一般2T上界保持成立。此处处理时间按行跨度m+1增长，故也不反驳UM-ROW-SPREAD-TWO-ROUND-v1的两倍跨度正面结果。已给的σᵃ可直接取任一个作为最优输出；即使算法接收整个凸分解，只有在强制它最终输出这个固定槽图的匹配时才受本页限制。

## 4a. 每源一个目的地也可修复：同步阈值与逐批严格下降

**精确身份 `UM-ONE-DESTINATION-SLOT-REPAIR-v1`。** 对每个m≥2及本页的任意槽匹配输出σ，一次同步修复要求：对每个机器i，所有在σ中属于i、最终搬离i的**原任务**至多去一个外部目的地。达到makespan≤1的最小Hamming距离精确为m(m−1)/2；若强制大任务搬离原机，最小距离为m(m+1)/2。此处Hamming按原始σ与最终分配比较；接收后再转发同一个任务不能冒充一次迁移。原先不限制目的地的m−1最优修改数属于UM-OPTIMAL-CONVEX-SLOT-REPAIR-v1，保持不变。

**大任务不动的实际构造。** 设其原机为A，任选其他机器次序B₁,…,B_(m−1)。A从自己原有的m−1条small中全部送到B₁；B₁从自己在σ中原有的m条small中送m−2条到B₂；继续，每个源都只送自己的原初任务，末前源送1条到末机。最终A仅大任务，其他每机恰有m+1条small，负载均1。各源原始库存足够，移动数恰(m−1)+…+1=m(m−1)/2。

这个构造还可按路径顺序逐批执行。令v₀=A、v_t=B_t；第t批把v_(t−1)的m−t条**原σ** small送给v_t，t=1,…,m−1。该批后A负载1，先前B₁,…,B_(t−1)各有m+1条small，当前B_t有2m−t条small，其后机器仍各m条。故每个整批之后的真实makespan恰为

`C_t=(2m−t)/(m+1)`，`C_0=2m/(m+1)`。

每批严格下降1/(m+1)，最后为1；每源在整个序列中仍只用一个外部目的地。接收机器会增载，所以它不满足逐机器坐标非增合同。这不声称把批次拆成单任务后每一步仍严格下降。

**大任务不动的下界。** 只画small从原机到最终机的正流边，边权为迁移条数，每源外度≤1。A净供给m−1、不收small；其他每点净需求1。若有从A不可达的非空集合U，则其没有来自可达补集的流入，却有严格正总净需求，矛盾。于是A的功能图轨道在首次重复/停止前依序访问全部机器v₀=A,v₁,…,v_(m−1)。对首次访问前缀S_k={v₀,…,v_k}，k=0,…,m−2，其唯一外向边为v_k→v_(k+1)，而补集总净需求m−1−k。因此该边流减反向入流为m−1−k，边流至少此值。不同k用不同边，求和得到Hamming≥m(m−1)/2。最后允许回接形成循环；不能把“最小值”错误加强成每个修复都恰为三角数。例如m3的small流A2→B、B3→C、C2→B合法，Hamming7而最小3。

**大任务搬走的分支。** 设大任务从A到B。A唯一的外迁目的地已是B，而B最终不能收small，所以A所有m−1原small必须留A；A是small净需求2、无外迁的汇。B必须送走全部m条原small且不收small，是净供给m的源；其他机器各净需求1。相同不可达集合守恒迫使所有点从B可达，又因A无外迁，small功能图必为经过所有机器后在A结束的路径。边流依次m,m−1,…,2，再加大任务1次迁移，距离恰m(m+1)/2。按路径各源原初库存选任务即可达到；连同大任务A→B，完整迁移图可成有向圈。两个分支相差m，整体最小值取big不动分支。

**范围与证据。** 建立每源原任务列表后，两个路径构造只扫描任务及机器，可在O(n+m)组合操作及输入位多项式内输出实际分配。只对本页这个显式同机族成立；没有证明一般配置/真实最优凸包初始化总有一次严格下降修复。该正面机制可作任意拟议一般修复算法的测试，不是新近似比。proof、命题范围和独立攻击见本页既有审查的追加节；规范/独立代码为 `tests/audits/unrelated_machines/one_destination_slot_repair.py` 与 `one_destination_slot_repair_independent.py`，冻结范围见 `evidence/runs/unrelated_machines/one_destination_slot_repair_audit.json`。

## 6. 最小总处理量的整个最优面也可能丢掉修复边

另立`UM-MIN-WORK-FACE-SUPPORT-GAP-v1`。它不属于第1节真最优凸包合同；
它检验的是basic或最小总处理量初始化能否自动修复支撑损失。两项身份不相互冒充推广。

对每整数m≥2，构造m台机器：大任务B在任机耗时m；每台home h有m−1个不同小任务，
在h耗时1，在其余机器耗时1+d，其中d=1/m。共有m(m−1)+1个任务，全部时间正且有限。
令T=m+d，考虑目标T的剪枝assignment LP及真实总处理量目标

\[
 W(x)=\sum_{i,j}p_{ij}x_{ij}.
\]

**精确结论。** OPT=m+d，最小LST阈值恰m。在T=OPT最小化W的整个面F_m上，
每一个点都将全部small积分固定home且让B在每台机器有正质量。
因此，对任意x∈F_m，任何只用其正支撑的合法整数分配，包括任意标准槽覆盖matching，
其makespan都恰为2m−1。该面含下列明确的原assignment-LP basic点。
更强地，任何使用全部原边、但要求W(σ)≤min_xW(x)=m²的调度也必有同一坏值。
比值为

\[
 \frac{2m-1}{m+1/m}=2-\frac{m+2}{m^2+1}\longrightarrow2,
 \qquad\frac{OPT}{T_{LST}}=1+\frac1{m^2}\longrightarrow1.
\]

这是整个最小总处理量面的**支撑**障碍，甚至不必限制到槽图；不是LP值接近两倍的例子。
未声称F_m满足配置LP、属于真实最优调度凸包，或排除使用其他目标、重新打开零质量边、
允许总处理量上升的修复及UM-TARGET-v1。

**整数最优值。** 把B给h，其m−1个home小任务各送一台不同的其他机器，其余small不动。
B机负载m，其他机负载m+d。反向，若B机还接任何small，负载至少m+1>m+d；
否则全部m(m−1)个small在其他m−1台上，且至少m−1个必须离home，
总处理量至少m(m−1)+d(m−1)，平均为m+d。故OPT恰为T。
目标小于m时B无剪枝可用边；目标m时small留home、B均分给每台机器，负载恰m，
故T_LST=m。全部原边在目标m已存活，不是剪枝人为删除修复边。

**全部最优面的精确身份。** 令S(x)为small离home的分数质量，则
W(x)=m²+dS(x)。上述均分B的点可行且成本m²；d>0迫使任何最小成本点都令S(x)=0。
写B的份额为b_i，则该面正好是

\[
 \{	ext{small全部留home},\quad \sum_i b_i=1,\quad
 0\le b_i\le(m+1)/m^2\}.
\]

每个b_i≥1−(m−1)(m+1)/m²=1/m²>0。因此所有最优点的支撑完全相同，
连取整个面的支撑并集都无法加入一条small跨机边。支撑内调度只可选择B的机器，
其负载必为m+(m−1)。相同成本恒等式对整数分配给出W(σ)≤m²时的结论。
给定x生成的槽覆盖存在，由UM-ST-ROUND-v1的Hall证明保证。

**basic见证及复杂度。** 取b_i=(m+1)/m²（i<m）、b_m=1/m²。
前m−1行load=T，最后一行load=m−1+1/m<T。正变量共m²个。
在正支撑上考虑满足全部任务等式及前m−1行tight load的齐次方向：
每个small仅有一个正坐标，故其方向为0；前m−1个B方向由tight行变成0；
B的任务等式令最后一个也为0。因而这些active等式在正变量上满列秩，
再配零变量的active非负约束，确为原LP顶点，不仅是成本面顶点。
P有m[m(m−1)+1]个条目，分数、basic点及显式调度都可按实际位长多项式构造。

**允许工作量上升时的锐修复阶梯。** 对整数q≥0，在全部原边上、至多q个small离home
（等价于W(σ)≤m²+dq）的最优makespan精确为

\[
 \max\{2m-1-\min(q,m-1),\ m+d\}. \tag{4}
\]

B机本来的m−1个home任务至多有q个离开，给第一项下界，真实OPT给第二项。
取q'=min(q,m−1)，把B-home的q'个small分别送到其他q'台机器，其余不动，达到该界。
恢复OPT需且只需m−1个small离home；工作量只增加(m−1)/m，
相对m²的增加为(m−1)/m³→0。故不能把精确成本保持的反例扩成任何固定乘法成本松弛的反例。

**来源、边界和证据。** ST1993印页464图1、465末段已有相同机器上的经典tight例：
大任务m、小任务m(m−1)个、各home积分固定，保积分舍入值2m−1。
本节的1/m跨机扰动将这一经典机制变成“所有最小总处理量点支撑均坏”，
basic性质是直接线性代数；新颖性、独立论文价值与外审未认证。
本节由boss7内部adaptive_rounding提出并由主研究者独立计数重构，
不将简单经典扩展称作新的近似下界。
