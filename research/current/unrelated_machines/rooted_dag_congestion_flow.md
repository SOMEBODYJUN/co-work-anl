# 共同拥塞证书的需求根树提取、固定支撑搜索与尖锐比例

本页接续[需求树到真实调度的精确桥梁](rooted_dag_degree_token_bridge.md)。它给出一个明确的正面联合容量接口：一次整数流同时选择分叉、汇流与任意长低需求走廊；固定支撑的证书也能用流求出。一般输入上的支撑选择及统一常数拥塞仍未解决。UM-TARGET-v1保持OPEN。整数流机制是标准工具的自足应用，未认证全球新颖性或独立论文价值。

## 1. 对象、完整合同和精确身份

D=(V,E)为显式非空有限简单DAG，根r的输入入度为0。k_v为二进制非负整数，k_v=0的点必须是原图终端；允许正需求死端、不可达点和任意根编号。根树及截断评分b(H)沿用桥梁正文§1：所有选中的原正需求点均收费，包括输出叶，且b(H)=min({1}∪{deg_H⁺(v)/k_v:k_v>0且v∈H})。

**共同K证书。** 给整数K≥1及含根的支撑W⊆V，只在E[W]上给非负有理f；未列边流量为0。令I_v=Σ_u f_uv、O_v=Σ_w f_vw，并按原需求划分

B={v∈W:k_v≥K}，L={v∈W:0<k_v<K}，Z={v∈W:k_v=0}。

同时要求：

- 每个非根v∈W满足I_v≤K；根因原入度0有I_r=0。
- 每个v∈B满足O_v≥k_v。高点的接收与输出供给在本点分别处理，不要求守恒。
- 每个v∈L\{r}满足O_v=I_v；若r∈L，另要求O_r≥K。
- Z无输出边，输入仍受同一个K上界约束。W外只受原图合法性约束，不要求它们另有证书。

这是同一份全支撑共同流，不是每个点各自存在的延伸，也不是激活边际LP。W不要求每点均从r可达；提取后只保留真实根可达部分。输出可使用E[W]中的零f边，不承诺保持f的正支撑。

**UM-DAG-CONGESTION-FLOW-v1。** 对所有上述输入：

1. 给定有效共同K证书，可确定性在图、需求、K、W、f合计二进制位长的多项式时间内输出真实根树H，使b(H)≥1/(2K−1)。提取只求一次整数最大流，不按深度逐轮付损失。
2. 仅给合法D,k,K,W，也可确定性位多项式判定此固定W,K上是否存在共同证书；存在则输出整数f。固定W时，可行性对整数K单调，因而还能以位多项式时间求最小可行K及整数证书，或报告此W没有任何K证书。固定K的失败不表示b*=0，也不表示一般调度不可行。
3. 对每个整数K≥2，有显式合法分层族及有效共同K证书，而其真实b*恰为1/(2K−1)。因此该保证对本证书类精确尖锐。K=1给b(H)=1。
4. 令κ*为所有含根支撑W的最小可行整数拥塞；无证书时为∞。若b*>0，则(1+1/b*)/2≤κ*≤ceil(1/b*)；给定评分β>0的实际根树及整数K≥1/β，可位多项式构造其顶点支撑上的证书。这是存在性/已给树转换，不是求最优W的算法。

根为原终端时，提取直接返回根单点树，评分1；固定W证书搜索仍按完整合同检查W内其余点。K必须为整数，不能默扩到任意实数阈值。以上没有从一般D寻找有用W及统一常数K的算法。

## 2. 一次整数流协调全部分支与走廊

根非终端。构造一个源s、汇t的网络。每v∈W用输入副本v⁻与输出副本v⁺表示。

| 原点类型 | 网络弧与整数容量 |
| --- | --- |
| 高点v∈B | s→v⁺容量q_v=floor(k_v/K)；v⁻→t容量1 |
| 非根低点v∈L | v⁻→v⁺容量1 |
| 低根r∈L | s→r⁺容量1，不设从r输入到输出的通路 |
| 终端v∈Z | v⁻→t容量1 |
| 原边u→v∈E[W] | u⁺→v⁻容量1 |

设所有源弧容量之和为Q。证书保证存在饱和全部源弧的分数流。证明不能只把各高点出流各自截成q而让下游不动；正确做法如下。

先把每条原边流设成f_uv/K。每个非根点的总入流≤1，故原边也≤1。低点转接同量流；高点输入与终端输入流到t。每个高点由s供给O_v/K≥k_v/K≥q_v；低根供给O_r/K≥1。这构成一个源弧容量暂时放宽的分数s-t流，其余弧容量均不超过表中界。原图无环，拆点后也无环，故可按源弧分解成非负有理s-t路径流。对每条源弧，单独删去其过剩路径质量，恰保留表中的供给；所有转接及接收量只会减少。因此得到满足原网络全部容量、总值Q的分数流。

从零流作整数增广，整数容量保证每次增广与最终最大流均为整数。若停在值<Q，残量网络中s的可达集给出容量<Q的割，与已存在的Q分数流矛盾。因此算法得到值Q，且每条源弧均饱和。

将使用的原网络弧还原到D中。每个非根至多一条入边；每个被访问低点恰一条出边；每个高点恰有q_v条出边；终端没有出边。取从r可达的边和点。因D无环且非根入度≤1，它是真实arborescence；所选点发出的全部已选边都保留，故其度数界不因取可达部分降低。不可达高点虽曾同时参与流计算，最后可整体丢弃。

## 3. 统一比例、总位复杂度和固定支撑搜索

低点有1≤k_v≤K−1，其比例1/k_v≥1/(2K−1)。对高点写k_v=q_vK+s_v，q_v≥1、0≤s_v≤K−1，则

k_v≤q_vK+K−1≤q_v(2K−1)，

故q_v/k_v≥1/(2K−1)。所有选中正需求点同时满足此界，截断项1也满足。K=1时低点不存在且q_v=k_v。

每个证书边f_uv≤K，因为其孩子非根且总入流≤K。因此O_v≤K deg⁺_{E[W]}(v)，q_v≤deg⁺_{E[W]}(v)，且Q≤|E[W]|（低根项也≤其出度）。提取网络有O(|V|)点、O(|V|+|E|)弧；每次正整数增广至少增加1，所以至多|E|次，图操作为多项式。没有按巨大k或K展开容量副本。证书验证用精确有理数求和比较；分母积的位长至多输入分母位长总和。网络容量q及最终边集均有受控位长，输出最多|V|−1条原边。

固定W搜索用同一拆点网络，把原边、低点转接及高点/终端的接收容量全部改成K；高点源弧容量改成k_v，低根源弧容量改成K。求最大流并检查所有源弧是否饱和。有证书时，用上一节未缩放的路径分解，按每个源删到这些精确供给，得到网络可行流；反向，任何饱和整数流在原边的用量就是有效f。这证明双向等价，并使成功搜索返回整数证书。

搜索流量可能随K数值很大，不能用“每轮至少增1”证明搜索位多项式。规范程序用最短增广路BFS，即Edmonds–Karp：残量最短距离不下降；同一弧再次成为最短路的饱和瓶颈前，其尾点距离至少增2，因此每弧作瓶颈O(|V|)次，总O(|V||E|)次增广、O(|V||E|²)图操作。容量位长为O(log(K+1)+Σ_v log(k_v+1)+log(|E|+1))的多项式界，整数加减比较及构图总位复杂度多项式。失败只否定给定W,K的共同证书。任意选W的组合问题没有被这个流解掉。

**固定W的最小拥塞也可求。** 设K₁≤K₂，已有K₁证书并令g=f/K₁。按D的拓扑序，在每条原边的上界g_e内重建归一化g'。新高点选总出流k_v/K₂≤原g出流；新非根低点选总出流等于已收到的新入流。后者不超过原g入流，且原g出流至少原g入流：原低点守恒，原高点则g出流≥k_v/K₁≥1≥g入流。新低根选总出流1，原高根或低根的归一化出流均至少1。各点贪心分配到尚有上界余量的出边即可；新入流总不超过原入流，每步都有足够出边容量。终端不输出。乘K₂得到新证书，所以固定W的可行整数K构成上闭集。

令U=1+max_{v∈W}k_v。在U下所有正点都是低点。若r为终端，零流就是证书；若E[W]有r到Z的路径，沿该路径送U、其他边送0就是证书。反向，任意有效证书中，正根有正出流；沿正流前进，每个到达的正点（高点或守恒低点）均有正出流。DAG保证最终到达原终端。因此无此路径且根为正需求时，任何K都不可行。先查路径，再在[1,U]用固定K流判定二分，至多O(log(U+1))次，即可输出最小K及其整数证书。运行次数取决于二进制位长，不遍历1,…,U。根为终端时也不能未经检查就把最小K报成1，因为W内其他高点仍须共同满足合同。

## 4. 对每个整数拥塞K的精确尖锐族

取K≥2，k=2K−1，h=ceil(log₂K)，d=h+1。用整数位长h=(K−1).bit_length()构造，避免浮点对数。层宽a₀=1，逐层

a_(ℓ+1)=ceil(k a_ℓ/K)=2a_ℓ−floor(a_ℓ/K)。

层0的唯一点为根；层0至d−1的每个点需求均为k，层d每个点为0需求终端；相邻层连全部由前向后的边。对每条ℓ到ℓ+1边取f=k/a_(ℓ+1)，W=V。每个正需求点总出流恰k，每个非根点总入流k a_ℓ/a_(ℓ+1)≤K，所以证书有效，且没有低点。

对ℓ≤h有a_ℓ=2^ℓ：在产生这些层之前a_ℓ<K，递推没有减项。又K≤2^h<2K，所以末层

a_d=2^(h+1)−floor(2^h/K)=2^d−1。

若根树有b>1/k，则每个选中正需求点至少有2个孩子；所有孩子都在下一层，且不能复用顶点，故末层至少需2^d个不同终端，与其只有2^d−1个矛盾。任取一条贯穿各层的路径则b=1/k。于是b*=1/(2K−1)。例如K=2为层宽(1,2,3)、全部非终端需求3，真实b*=1/3。

该参数族有O(K)个顶点、O(K²)条边。这里是逐K的显式反例族；没有声称在logK时间内输出其所有顶点。它限制共同证书本身所能保证的比例，不是一般根树或调度近似的困难性，更不能把K相关常数当作主目标的统一ε。

## 5. 证书搜索还缺什么：激活边际不够

**UM-DAG-ACTIVATION-CORRIDOR-GAP-v1。** 对每整数q≥2，有显式DAG使下列加强激活LP可行，但真实b*=1/q：a_r=1；非根a_v=Σ_u x_uv≤1；每正需求点Σ_w x_vw≥k_va_v；0≤x_vw≤a_v。这是含父激活上界的准确合同，不等同本文共同拥塞证书。

构造q个分支r→v_i，k_r=1、k_vi=q。每v_i连q个私有w_ij；所有w_ij再连同一个私有x_i，最后x_i→t_i。k_w=k_x=1，k_t=0。边际取a_vi=a_wij=1/q，a_xi=a_ti=1；边值依次为1/q、1/q、1/q、1。逐点入流、出流和父激活上界均精确满足；点数1+q(q+3)，边数2q²+2q。

任意正比例树选中v_i后，每个所选w_ij都必须继续到x_i。因x_i不能有两个父点，v_i最多选一个w孩子，故b≤1/q；一条r-v_i-w_ij-x_i-t_i路径达到1/q。LP质量在低需求汇流走廊中合并，不能被当作不同真实子资源。此反例只排除该LP可行性直接保证统一正常数根树比例；不导入任何SA下界或调度困难性。

本文强合同在高点要求无条件O_v≥k_v，并在低点要求共同守恒，而不是k_va_v的独立分数激活。两种合同不能互换。

**支撑选择与真实树的定量关系。** 给定实际根树H，β=b(H)>0，取W=V(H)及任意整数K≥1/β。每个高点的树孩子数d_v≥βk_v≥k_v/K，故可沿这些孩子以每边容量K贪心分配总量k_v；不按k_v展开副本。每个非根低点把其收到的量（至多K）沿一个树孩子续送，低根沿一个孩子送K；β>0保证每个正需求点都有树孩子。按树拓扑序处理，高点接收与新供给分开，终端吸收。树中每点仅一个父点，故没有额外汇流，所有输入≤K；未用树边取0。这构造一个整数共同K证书，位长与循环数均由给定树、需求和K的编码长控制。根原为终端则W={r}，零流即证书。

定义κ*=min{K≥1:存在含根W及其共同K证书}，空最小值约定∞。当b*>0，取最优树和K=ceil(1/b*)，得到κ*≤ceil(1/b*)；反向提取保证b*≥1/(2κ*−1)，反算得κ*≥(1+1/b*)/2。b*=0时不存在任何共同证书，否则提取会给正评分。此界表明搜索有用支撑保留了真实根树问题的内容；固定W上的K优化已经可求，却没有给从一般D找到好W的算法。不能先假设已知好树再宣称这一步搜索已解决。
