这是本轮重新组织论证而写的研究说明，不是历史记录的改名或搬运。符号、证明义务与实现分开登记。**状态：内部审读后的研究候选；仍待外部独立重构。** 下列推导便于重算，不以历史审计的“通过”措辞替代证明。

## 1. 模型与量词

有限客户集 I，每人正权 wᵢ；地点 s 有固定可达集 Sₛ。两个设施分别从非空有限目录 U₁、U₂ 选择地点，目录可不同、相交或不交。同一物理地点在两目录中是两个带设施标签的行动。被覆盖客户必须选择一个可达设施，无外部选项；未覆盖客户不参与。客户成本是所选设施的实现总负载，含自身权重；混合策略若出现，采用独立随机化。设施收益是期望负载。

α-SPE 在此指：第一阶段设施位置纯；每个合法有标签布局都有一个精确客户 NE；固定整套后续后，每个设施单方偏离收益不超过 α 倍在途收益。用乘法不等式而非直接除法处理零收益。存在的是**一套可选后续**，不是所有后续均稳定。

| 当前命题 | 必要范围 | 结论与证据边界 |
|---|---|---|
| HC-2-UP | 任意上述有限目录、可达关系；算法用二进制正有理权重 | 四种子纯菜单构造 factor 2；所有后续可纯；内部候选 |
| HC-2-LOW | 六顶点无向图、每方两个位置、每对恰两名共有客户 | 实例最优因子 (2M+10)/(M+14)→2；直接代数与严格占优论证 |
| HC-2-SHARP | 同时接受上界证明和下界证明 | 通用最优常数恰为 2；不能只由下界或程序运行推出 |
| HC-RHO | **同时**满足 min(|U₁|,|U₂|)≤2 与每跨对共有客户数≤1 | 通用 sharp ρ=2cos(π/7)；纯上界与严格唯一后续下界 |
| 单共有客户实例精确求解 | 仅每跨对共有客户数≤1；两目录可任意大 | 算出该有限输入的最优因子；不是任意目录的统一 ρ 证明 |

存在论的上界论证可用正实数；多项式位复杂度只在显式可达关系与二进制有理权重输入下陈述。四种子上界不依赖共享目录 φ 定理。
