# 正占用核：交互阶数、非负表示与闭包

本专题研究 Boolean 输入的非负共享负载响应，不要求博弈结构。固定正质量，核为“本坐标激活时观察共享总质量的整数幂”；完整定义、所有量词和证明见[正占用核的交互秩暴露面、锐截断预算与非闭锥补全](occupancy_rank_faces.md)。

| 输入/需求 | 可调用接口 | 主要限制 |
| --- | --- | --- |
| 有限非负核表示，输出 active 交互秩≤r | `PK-INTERACTION-RANK-FACE-v1`：每个正项必须 min{次数,用户数−1}≤r；顶背景差分给暴露面 | 固定正质量、完整输入表、非负混合；不能推出全部资源支持小 |
| 响应接近低秩或需要删除不合阶数的项 | `PK-SHARP-FORBIDDEN-MASS-v1`：显式锐单核 gap γ，删项质量≤L/γ，逐坐标有误差界 | γ固定于 n,w,r；表误差是绝对一致误差，未给未知分解恢复算法 |
| 次数无界并需要使用极限 | `PK-OCCUPANCY-CONE-CLOSURE-v1`：只需补入 unanimity 方向，低秩闭包与截面可交换 | 原有限表示锥在至少两个输入时非闭；闭包对象不能冒充原合法有限表示 |

来源是 boss4 的[局部成本正展开](../weighted_congestion/template_certificates/selector_local_moments.md)，不可变 commit/hash、原 Claim、E1 提取变换及独立审查贡献均在正文第七节。已有工具背景包括高阶 pseudo-Boolean 差分；新颖性未认证。

先读正文第一节接口，再按需读第二至四节证明、第五节失败边界、第六节传感器响应实例及返回 MODEL 的确切桥梁。独立审查和两份 Fraction 程序、实际输入与冻结结果从正文第八节进入；有限计算不替代一般证明。全仓账本在[claims](../claims.md)及[审查状态](../../review_status.json)。

下一步真正缺的是一般动作签名的符号差分控制，以及从这类表示结构到 selector 可行性的桥梁；本专题没有提供均衡存在保证，不改变 WC-TARGET 的开放状态。
