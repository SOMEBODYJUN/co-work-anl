# CA-PORTFOLIO-MATCHING-NO：最优组合匹配收费也会失败

## 输入、量词及结论

本页仅讨论顺序客户吸引模型：两名单位玩家依次从同一个有限主题目录选一个主题；
每名单位客户在最终吸引自己的玩家之间均分价值。完整纯策略可依赖全部有序历史。
客户类型的整数重数表示多名不同单位客户，不表示不可分战略原子权。

设某个纯 SPE 的实际有序路径为 \((S_1,S_2)\)，实际覆盖为 \(C\)。
对一组达到 \(\mathrm{OPT}_2\) 的主题 \((T_1,T_2)\)，令 \(V_{i,T}\) 为玩家 \(i\)
在自己的实际历史选择 \(T\) 后，余下玩家遵循同一完整策略时获得的实际收益。
候选收费要求：存在某个最优主题组合及其排列 \(\pi\)，使

\[
V_{1,T_{\pi(1)}}+V_{2,T_{\pi(2)}}\ge |(T_1\cup T_2)\setminus C|.
\]

**该候选为假。** 下述共同目录实例有唯一的最优两主题集合，而且两种排列的偏离收益和
都严格小于最优组合遗漏的客户数。因此它也反驳“对每个固定最优组合成立”的版本。
它不反驳 \(\mathrm{OPT}_m\le2W\)，也不排除采用其他收费对象或多步偏离的证明。

## 一个可直接核验的实例

目录按 \(A,B,T,D,E\) 排列。以下客户块互不相交；第一列列出喜欢该块的全部主题。

| 客户类型 | 单位客户数 |
| --- | ---: |
| \(A\) | 15 |
| \(B\) | 15 |
| \(A,T\) | 6 |
| \(B,T\) | 5 |
| \(A,B,T\) | 1 |
| \(D\) | 16 |
| \(D,T\) | 6 |
| \(E\) | 14 |
| \(E,T\) | 6 |
| \(B,T,E\) | 2 |

共有 86 名单位客户。主题大小分别为 \((22,23,26,22,22)\)。
第一玩家选 \(E\)，第二玩家的完整响应规定为

\[
A\mapsto B,\quad B\mapsto T,\quad T\mapsto B,
\quad D\mapsto T,\quad E\mapsto A.
\]

每个首动作后，第二玩家五个可能动作的收益如下。

| 首动作 | 第二玩家收益，按 \(A,B,T,D,E\) | 指定响应 | 第一玩家最终收益 |
| --- | --- | --- | ---: |
| \(A\) | \(11,45/2,45/2,22,22\) | \(B\) | \(43/2\) |
| \(B\) | \(43/2,23/2,22,22,21\) | \(T\) | 19 |
| \(T\) | \(37/2,19,13,19,18\) | \(B\) | 22 |
| \(D\) | \(22,23,23,11,22\) | \(T\) | 19 |
| \(E\) | \(22,22,22,22,11\) | \(A\) | 22 |

指定响应逐行达到最大值。第一玩家遵循各行的指定响应后得到
\((43/2,19,22,19,22)\)，故选 \(E\) 也是最优动作。
这完整检查了全部六个决策历史和 24 个非平凡单步偏离，因此上述完整纯策略是 SPE。

## 唯一最优组合与匹配失败

实际终局为 \((E,A)\)。二者覆盖不相交，故 \(u_1=u_2=22\)、\(W=44\)。
全部不同主题对的覆盖如下；重复主题覆盖至多 26，无法达到最大值。

| 主题对 | 覆盖 |
| --- | ---: |
| \(A,B\) | 44 |
| \(A,T\) | 41 |
| \(A,D\) | 44 |
| \(A,E\) | 44 |
| \(B,T\) | 41 |
| \(B,D\) | **45** |
| \(B,E\) | 43 |
| \(T,D\) | 42 |
| \(T,E\) | 40 |
| \(D,E\) | 44 |

因此唯一最优集合为 \(\{B,D\}\)。最优覆盖与实际覆盖仅共享
一名 \(A,B,T\) 客户和两名 \(B,T,E\) 客户，故遗漏数为 \(45-3=42\)。
真实偏离收益矩阵为

| 玩家及实际历史 | 偏离至 \(B\) | 偏离至 \(D\) |
| --- | ---: | ---: |
| 第一玩家，空历史 | 19 | 19 |
| 第二玩家，首人已选 \(E\) | 22 | 22 |

第一行已经包括完整离轨响应：\(B\) 后选择 \(T\)，\(D\) 后也选择 \(T\)。
第二行是在实际前缀 \(E\) 上直接选择该主题。两种排列都只给 \(19+22=41<42\)，
而唯一最优集合排除了通过改选其他最优组合修复匹配的可能。
