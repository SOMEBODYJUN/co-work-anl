# CA-TAX-BRIDGE-NO：空背景、三人已否定首步机会成本桥

- **状态与版本：** 2026-10-09，十五名单位客户的显式精确反例，含全部有序历史的纯 SPE；内部直接重构，外部同行评审未记录。
- **输入类：** [CAG-MODEL](model.md) 的共同有限目录、单位客户及单位提供者；背景为空，恰三名玩家依次观察完整历史。
- **被否定的量词：** [两名剩余玩家税界](two_remaining_tax.md) 式 (9) 声称对每个合法背景、每个剩余人数及每个完整纯 SPE 都有
  $F_k(b)\le u_{\rm first}+\tau_b(\mathbf1_A)+F_{k-1}(b+\mathbf1_A)$。
  下面在合法空前缀、$k=3$ 直接得到严格反例。
- **边界：** 该反例只否定这个首步桥。该实例的整条根税界恰为等号，且满足半覆盖目标；不能据此否定整条税界或主目标。

## 1. 对称星形客户目录及完整策略

共同目录为 $A,B,C,D$。每个表格单元是该数量的不同单位客户：

| 感兴趣主题 | 单位客户数 |
| --- | ---: |
| $A$ | 2 |
| $A,B$ | 3 |
| $C$ | 2 |
| $B,C$ | 3 |
| $D$ | 2 |
| $B,D$ | 3 |

共十五名客户。$B$ 覆盖九名客户；三个叶主题 $A,C,D$ 各覆盖五名客户，
各有两名私有客户及三名与 $B$ 共有的客户，叶主题之间完全不交。

完整策略在每个有序决策历史都选择 $B$，包括所有離轨历史。
因此三个层次分别有 $1,4,16$ 个决策节点，共二十一个；没有删去任何平局。
实际路径是 $(B,B,B)$，每名玩家收益为 $9/3=3$，福利为 $W=9$。

## 2. 三层 SPE 检查的直接证明

更强地，三玩家游戏中，$B$ 相对每个叶主题都是弱占优行动。
固定当前玩家之外另外两名玩家的任意行动；这覆盖第一层之后的两个 $B$、
第二层之后的一名先行玩家与一个 $B$，以及第三层的任意两名先行玩家。

任取叶主题 $L\in\{A,C,D\}$，比较当前玩家选 $B$ 和改选 $L$。
两种终局中，$B,L$ 共有的三名客户的覆盖人数完全相同，因而其收益项抵消。
选择 $B$ 还得到其他两个叶组的共有客户：每组有三名客户，每名客户的
终局覆盖人数至多为三，故每组贡献至少一，总计至少二。
选择 $L$ 还得到它的两名私有客户，贡献至多二。因此

$$u(B,s_{-i})-u(L,s_{-i})\ge 2-2=0.$$

这个比较对两名其他玩家的所有实际行动均成立。
每个历史中，玩家偏离后其后继按完整策略继续选择 $B$，其后继行动在两个
比较枝中相同，正属于上述比较。故第一、第二、第三层的全部偏离不等式成立，
全历史始终选 $B$ 是完整纯 SPE。该证明没有把一般 SPE 自动当作静态 PNE；
本例另外具有弱占优结构，所以可以直接作固定行动比较。

## 3. 精确最优值及首步桥失败

无背景时 $F_k(0)$ 就是至多 $k$ 个主题的最优覆盖。因此

$$F_1(0)=9,\qquad F_2(0)=11,\qquad F_3(0)=15.$$

$F_1$ 由 $B$ 达到；两个主题选 $B$ 和任意叶主题覆盖 $9+2=11$，
两个不同叶只覆盖十名；三个叶 $A,C,D$ 覆盖全部十五名。

实际首动作是 $B$。以该动作形成的背景 $b=\mathbf1_B$ 固定后，
每个共有组已有一名覆盖者，而六名叶私有客户仍无覆盖者。
两名剩余玩家的所有比较主题类型只有以下四类：

| 两个比较主题 | 两名剩余玩家的总收益 $R_{\mathbf1_B}$ |
| --- | ---: |
| 两个 $B$ | $9\cdot2/3=6$ |
| $B$ 与一个叶 $L$ | $3\cdot2/3+6\cdot1/2+2=7$ |
| 两个相同叶 $L,L$ | $3\cdot2/3+2=4$ |
| 两个不同叶 $L,M$ | $2(3\cdot1/2+2)=7$ |

故 $F_2(\mathbf1_B)=7$。背景为两个 $B$ 时，最后一名玩家选 $B$ 得三，
选任意叶也得 $2+3/3=3$，所以 $F_1(2\mathbf1_B)=3$。

首步税只涉及 $B$ 覆盖的九名客户，精确为

$$\tau_0(\mathbf1_B)=9\left(1-\frac12\right)=\frac92.$$

因而式 (9) 的两端是

$$F_3(0)=15>3+\frac92+7=\frac{29}{2},$$

严格违背量为 $1/2$。失败已经发生于空背景，不能通过仅修补非零背景分母
排除此反例；同时，恰两名剩余玩家的已证明税界没有受到反驳。

## 4. 整条税界仍恰等号

本例前三人实际总收益为九，实际前两动作均为 $B$。拼接税为

$$\tau_0(2\mathbf1_B)=9\left(1-\frac13\right)=6.$$

故整条根税式在本例恰给

$$F_3(0)=15=W+\tau_0(2\mathbf1_B)=9+6.$$

第二步已证明的两人税界也恰等号：

$$F_2(\mathbf1_B)=7
=3+3+9\left(\frac12-\frac13\right).$$

首步桥使用的是子局的**最优**值 $F_2(\mathbf1_B)=7$；该值与实际后两人
总收益六的差只是一，而剩余实际税为 $3/2$。
所以把整条预算逐层用式 (9) 分配，首步会少掉 $1/2$。
正确的拼接恒等式不能消除这个机会成本缺口。

本例效率比为 $15/9=5/3$，并且 $2W=18\ge15$；
[任意纯 SPE 半覆盖目标](../../questions/customer_attraction_half_coverage.md)
没有被本例反驳。这里没有声称十五客户是所有可能反例的最小规模。
