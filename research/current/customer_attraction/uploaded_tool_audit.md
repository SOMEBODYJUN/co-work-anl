# 上传工具、完整策略与最后一步收益下界的独立审计

本页使用 [CAG-MODEL](model.md)：有限共同目录、单位提供者、单位客户均分，
完整有序历史依赖的纯 SPE。上传包原始字节保留在
[uploaded_2026-10-10](../../../history/source/notes/customer_attraction/uploaded_2026-10-10/)。
原包是来源材料；本分支的规范求解器仍为 `customer_attraction/`。
本页核验的是一个有限反例证书及实现之间的有限对照，不证明或否定一般半覆盖猜想。

## 1. 可登记的精确反例

**CA-LAST-FLOOR-ALL-PLAYERS-NO。** 对共同目录和 $n$ 位提供者，定义

$$
b_a(h)=\sum_{x\in S_a}\frac1{h_x+1},\qquad
\theta=\min_{h\in\mathcal S^{n-1}}\max_a b_a(h),
$$

其中 $h_x$ 是前缀中覆盖客户 $x$ 的提供者数，重复主题按次数计入。
候选断言“任意纯 SPE 中每位提供者都获得至少 $\theta$”为假。
存在 $n=4$、12 个共同主题的完整纯 SPE，使第一位提供者恰有
$u_1=\theta-1$。客户均为单位价值；4095 个非空兴趣类型的正整数重数只是
26,171,145 名不同单位客户的压缩，不是改变提供者权重或客户收益规则。

保存的策略实际路径为零基标签 $(8,4,5,0)$，完整数据如下。

| 量 | 定义级精确结果 |
| --- | ---: |
| 客户总数 | 26,171,145 |
| 非空兴趣类型数 | 4095 |
| 最小、最大类型重数 | 1、15,091 |
| 最大主题大小 $K$ | 13,088,768 |
| $\theta$ | 6,135,346 |
| 在轨 $u_1,u_2,u_3,u_4$ | 6,135,345；6,135,380；6,135,380；6,135,371 |
| 在轨福利 $W$ | 24,541,476 |
| 实际 $\operatorname{OPT}_4$ | 24,541,532 |
| $2W-\operatorname{OPT}_4$ | 24,541,420 |

因此 $W/\operatorname{OPT}_4=6135369/6135383>1/2$。
这个反例只否定逐人 $\theta$ 保证；它与既有逐人 residual 保证、收益随行动次序
单调、首步税桥等不同，不能替换这些断言的定义。它也不否定“最后两位至少
$\theta$”的断言：本证书最后两人分别高于 $\theta$ 34 和 25。
对这一辅助命题的反例是仓库新增资产，不作世界新颖性、发表优先权或外审认证。

## 2. 证书为何是合法的完整 SPE

[保存的原始证书](../../../history/source/notes/customer_attraction/uploaded_2026-10-10/auxiliary_counterexample.json)
为每个长度 $0,1,2,3$ 的有序历史单独指定行动，恰有
$1+12+12^2+12^3=1885$ 个决策节点。审计首先检查键集合恰等于这些历史，
拒绝缺项、额外历史、重复历史或非法行动，随后逐一重放保存的策略。
这里没有把重新生成的策略替代保存策略，也没有要求同计数历史共享行动。

固定历史 $h$，设保存行动为 $a$，从该节点执行保存策略的终局为 $s(h)$；
先改选 $b$ 再执行原策略的真实终局为 $s(h,b)$。独立脚本由单位客户定义计算

$$
u_a(s(h))=\sum_{M\ni a}\frac{r_M}{\sum_{c\in M}q_c(s(h))},\qquad
u_b(s(h,b))=\sum_{M\ni b}\frac{r_M}{\sum_{c\in M}q_c(s(h,b))}.
$$

每个计算中被评价的主题都实际有人选择，分母因而严格正。对于全部历史与全部
12 个行动，精确检查 $u_a(s(h))\ge u_b(s(h,b))$。
共通过 22,620 个比较，其中 20,735 个是不同于保存行动的真实备选行动；
最小严格收益差为 1。每人各移动一次，逐历史最佳回应与子树归纳便证明这份完整
策略为纯 SPE。该核验不使用上传工具或规范求解器的终局集合递推。

根节点保存策略的实际偏离收益尤其说明为何第一人不获得 $\theta$：

| 第一人行动标签 | 该行动后保存策略给第一人的收益 |
| --- | ---: |
| 0、1、2、3 | 6,135,344 |
| 4、5、6、7 | 6,135,342 |
| 8、9、10、11 | 6,135,345 |

根节点选择 8 是最佳回应。$\theta$ 量化的是给定三人前缀后最后一人的最佳
行动，不能把这种量直接当作早期提供者面对重新响应续局的偏离保证。

$\theta$ 的独立计算枚举所有 $\binom{14}{3}=364$ 个三人前缀计数，
对每个前缀比较全部 12 个最后行动。恰有四个前缀计数达到最小值：
在标签 $\{8,9,10,11\}$ 中选择三个不同标签的四种组合。
$\operatorname{OPT}_4$ 枚举全部 $\binom{15}{4}=1365$ 个终局计数；
唯一最优计数是标签 $0,1,2,3$ 各一次。
这些有限穷举给出该实例的精确 $\theta$ 和最优性证书，不是一般人数的最优效率定理。

## 3. 构造的实质内容

上传脚本把 12 个标签分为三组，每组四个。先定义只在大小三和四的不同标签集合
上非零的对称势函数扰动 $F$；其值由原脚本 `SMALL`、`BIG` 两张精确整数表给定，
仅取决于各组出现几个标签。对子集作 Möbius 变换得到多线性系数

$$
c_T=\sum_{U\subseteq T}(-1)^{|T\setminus U|}F(U),\qquad
d_T=(-1)^{|T|+1}|T|c_T\quad(T\ne\varnothing).
$$

再作超集 Möbius 反演，得到中间有符号重数

$$
\widetilde r_M=\sum_{T\supseteq M}(-1)^{|T\setminus M|}d_T.
$$

恒等式 $H_k=\sum_{j=1}^k(-1)^{j+1}\binom{k}{j}/j$ 说明相应
harmonic potential $\sum_M\widetilde r_M H_{|M\cap S|}$ 重构 $F(S)$。
负数只出现在构造中间量；最终对全部非空兴趣类型加同一偏置
$6391=1-\min_{M\ne\varnothing}\widetilde r_M$，使所有 $r_M$ 都为正整数。
对相同数量的不同标签，这个对称偏置贡献与标签的身份无关，所以保存所需的
扰动比较。重复主题与完整离轨最优性不能仅凭这一势函数观察获得；完整策略核验
仍覆盖它们。

通用反演、足够大正偏置下全部历史的无重复嵌入，以及福利不保持的边界，现已另由
[Möbius编译定理](mobius_compiler.md)完整证明。该定理使用安全大偏置条件，不能
回填成上传偏置6391的未证明一般保证；上传实例的合法性仍由以上保存策略审计认证。

独立审计将保存的4095个重数与上传脚本重新执行构造所得重数逐项比较，全部相同；
随后对1365个终局的覆盖及每个实际占用主题的收益，逐项比较独立 `Fraction`
定义级计算与上传 NumPy 表，全部相同。以上机制提供合法完整反例，但没有证明
12主题或客户数最小，也没有据此声称别的客户规模不存在同类反例。

## 4. 全 SPE 枚举与已有实现的关系

三份实现使用同一个集合值逆向归纳，而非不同的均衡概念。记 $E(k)$ 为计数前缀
$k$ 的全部可实现纯 SPE 终局计数，均使用

$$
L(k)=\max_a\min_{q\in E(k+e_a)}U_a(q),\qquad
E(k)=\bigcup_a\{q\in E(k+e_a):U_a(q)\ge L(k)\}.
$$

选中分支支持指定终局，其他行动分支各自选取当前玩家收益最小的可信子 SPE；
有序子树彼此不交，故可独立拼接。计数缓存的是可能集合，完整策略仍逐有序历史
展开。这正是既有 [CA-EXACT-PURE-SPE-ALL](exact_solver.md) 的必要、充分归纳。
上传工具没有新增全 SPE 枚举的数学递推，也没有改变为 Markov 或固定平局 SPE。

| 项目 | 规范 `customer_attraction/exact.py` | 既有独立 `customer_attraction_search.py` | 上传 `exact_spe.py` |
| --- | --- | --- | --- |
| 精确算术 | Python 任意精度整数与 `Fraction`，按需缓存收益 | 以 $\operatorname{lcm}(1,\ldots,n)$ 缩放的 Python 整数 | 相同 LCM 缩放，NumPy dense `int64` 矩阵 |
| 状态与终局 | 计数向量；递归缓存终局集合 | 分层计数向量；整数终局编号，逆层处理 | 计数向量；递归缓存终局集合 |
| 平局量词 | 全部历史依赖纯 SPE | 相同 | 相同 |
| 完整证书 | 全有序历史，支持指定在轨次序及 selector | 搜索摘要，规范 solver 可作复核 | 全有序历史；固定规则选一个支持目标的证书 |
| 主要接口 | 实例验证、全集、有序路径、福利和完整 verifier | 固定参数有限攻击、轨道缩减、冻结输出 | compact mask 输入、`last_floor()`、势函数反例构造 |
| 规模限制 | 有限枚举，不声称位多项式 | 有限枚举，不声称位多项式 | 另有 `int64` 范围与 dense table 大小限制，依赖 NumPy |

上传 `verify()` 以 `assert` 检查最优性，须保持断言启用；独立审计采用显式异常，
其关键检查不会因 `python -O` 被关闭。上传原 `main()` 会写回其脚本目录，复现时
应使用隔离副本；本页的 audit 只导入来源模块，重放保存策略，并将输出写到新路径。
规范求解器的允许输入范围和接口也更完整，故保留上传来源代码不建立第二套规范包。

## 5. 精确运行范围及成果边界

[独立审计脚本](../../../tests/audits/customer_attraction_uploaded.py)另外直接枚举完整
有序策略，并在小输入上同时比较上传工具、规范 `Fraction` 求解器及既有 LCM 搜索：

- 两主题三个非空兴趣类型的重数各取0、1、2，共27个客户输入，每个输入测试
  $n=1,2,3$；
- 三主题七个非空兴趣类型各取0或1，共128个客户输入，测试 $n=2$。

合计209个实例、14,094个完整有序策略映射；所得根终局集合四路全部一致。
上传与规范 solver 的全部1793个前缀终局集合也一致。
原包自测的27个三人实例包含在此范围内；原包100个随机 bound 检验不作为本页
全称证明依据。大反例上传工具返回97个根终局计数，本页不以该数值单独认证一般
算法正确性或任何最差福利界。

上传的三人 $W\ge8\operatorname{OPT}_3/15$ 弱于仓库已有锐界
$W\ge3\operatorname{OPT}_3/5$；其一般人数公式
$W\ge4(n-1)\operatorname{OPT}_n/[n(2n-1)]$ 与全SPE枚举及本辅助反例是不同成果，
需要独立全称证明审读，不能由本页的有限成功认证，也不解决 $n\ge5$ 半覆盖目标。
本页新内容是保存完整策略的定义级审计、$\theta$ 辅助断言的精确反例及来源实现
与已有规范机制的明确对应；世界新颖性和外部同行审查均未认证。
