# CA-PREFIX-BALANCE-NO：所有在轨前缀余额非负为假

**版本与状态：** 2026-10-10，显式二十二单位客户反例、完整有序历史纯策略和直接精确核验。
独立交叉审查与两份互不导入的逐客户精确审计通过；外部同行评审未记录。本页否定一个辅助不变量，
**不否定一般半覆盖猜想或空背景根总税**。

## 1. 精确输入类及被否定命题

采用 [CAG-MODEL](model.md)：有限共同主题目录、单位客户、单位权提供者，
各人依次观察完整有序历史并选择主题；终局中每个客户在其全部吸引者之间均分。
纯 SPE 在每个合法有序历史指定行动，允许重复主题以及历史依赖的平局选择。

为避免与固定背景的剩余利润混淆，本页定义的是**包含原覆盖的总覆盖补全**：

\[
F_r(C)=\max_{T_1,\ldots,T_r\in\mathcal S}
|C\cup T_1\cup\cdots\cup T_r|,\qquad F_0(C)=|C|.
\tag{1}
\]

固定一个完整纯 SPE 的实际路径 \((S_1,\ldots,S_n)\)，令
\(C_t=\bigcup_{i\le t}S_i\)，且 \(u_i\) 始终是**原完整终局**中的收益。
[逐期覆盖机会反例](coverage_opportunity_counterexample.md)之后保留的加强候选为

\[
\forall t\in\{0,\ldots,n\}\qquad
B_t:=\sum_{i\le t}u_i+F_{n-t}(C_t)-\operatorname{OPT}_n\ge0.
\tag{2}
\]

**命题 CA-PREFIX-BALANCE-NO。** 式 (2) 在共同目录、单位客户和全部历史纯 SPE
的精确输入类中为假。以下四人、六主题、二十二客户实例的实际首动作即有
\(B_1=-1/4\)。因此只要求根 SPE 的实际前缀也不能挽救式 (2)。

更一般的[完整解析反例族](prefix_balance_family.md)对每个整数 \(n\ge4\)
给 \(B_1=4-n-1/n<0\)，并证明每个固定实数 \(\alpha<2\) 都不能普遍修复
\(\alpha u_1+F_{n-1}(C_1)\ge\operatorname{OPT}_n\)。该推广已通过两路独立代数审查，
其任意人数结论来自全部有序历史的解析证明，而非有限样本外推。

## 2. 二十二客户与完整策略

目录标签按顺序为 \((L_0,A,B,L_1,L_2,L_3)\)。下列每行是该数量的
不同单位客户，表中列的是这些客户喜欢的**全部**主题；所有客户组互不相同。

| 喜欢的全部主题 | 客户数 |
| --- | ---: |
| \(L_0\) | 2 |
| \(A,L_0\) | 1 |
| \(B,L_0\) | 2 |
| \(L_1\) | 2 |
| \(A,L_1\) | 1 |
| \(B,L_1\) | 2 |
| \(L_2\) | 2 |
| \(A,L_2\) | 1 |
| \(B,L_2\) | 2 |
| \(L_3\) | 2 |
| \(B,L_3\) | 2 |
| \(A,B,L_3\) | 3 |

四个叶主题两两不交，大小为 \(5,5,5,7\)，覆盖全部二十二客户。
主题 \(A\) 有六客户，\(B\) 有十一客户，\(|A\cap B|=3\)。

下面给出每个有序历史上的完整纯策略：

1. 第一位选择 \(A\)。
2. 第二位在首动作是 \(B\) 时选择 \(A\)，否则选择 \(B\)。
3. 第三位在前两个动作恰为 \((B,B)\) 时选择 \(A\)，否则选择 \(B\)。
4. 第四位在每个三动作历史后选择自己的收益最大主题；有平局时依次优先
   \(B,A,L_0,L_1,L_2,L_3\)。

第四条是一个精确确定的规则：对每个候选主题，把该主题追加到真实历史，
逐客户计算最终均分收益，再按所列优先序选最大者。它定义全部 \(6^3\) 个末位节点，
没有冻结偏离后的续局。前两条后继规则也应用于全部离轨历史。

## 4. 真实路径及所有前缀余额

真实路径为 \((A,B,B,B)\)。\(A\setminus B\) 的三客户全归首位，
\(A\cap B\) 的三客户由四人均分，所以

\[
u_1=3+3/4=15/4.
\]

每位 \(B\) 玩家分得 \(B\setminus A\) 的八客户的三分之一及交叠客户的四分之一，故

\[
(u_1,u_2,u_3,u_4)=(15/4,41/12,41/12,41/12),\qquad W=14.
\tag{4}
\]

四个叶主题覆盖全部客户，所以 \(\operatorname{OPT}_4=22\)。
这些叶各有两名其他主题无法覆盖的私有客户，故它们也是唯一的最优四主题支持。

首动作 \(A\) 已覆盖六客户。在 \(A\) 外，每个叶恰有四客户，而 \(B\) 覆盖八客户。
三个补全主题若不用 \(B\)，至多用三个叶，新增至多十二客户；若用 \(B\)，
至多还用两个叶，各新增两名私有客户，新增仍至多十二。
重复 \(A\) 或其他主题不能增加这个上界；选三个叶，或选 \(B\) 与两个叶，均达到。
因此 \(F_3(A)=18\)。已有 \(A\cup B\) 后，只剩四个叶各两名私有客户未覆盖，
一次叶选择恰新增两客户。因此其余补全值如下。

| 前缀长度 \(t\) | 实际前缀 | \(\sum_{i\le t}u_i\) | \(F_{4-t}(C_t)\) | \(B_t\) |
| --- | --- | ---: | ---: | ---: |
| 0 | 空 | 0 | 22 | 0 |
| 1 | \(A\) | \(15/4\) | 18 | **\(-1/4\)** |
| 2 | \(A,B\) | \(43/6\) | 18 | \(19/6\) |
| 3 | \(A,B,B\) | \(127/12\) | 16 | \(55/12\) |
| 4 | \(A,B,B,B\) | 14 | 14 | 6 |

故式 (2) 在实际根首步就失败。相应机会损失为
\((\delta_1,\delta_2,\delta_3,\delta_4)=(4,0,2,2)\)，
特别 \(\delta_1=4>15/4=u_1\)。这也强化了旧局部反例：局部收费甚至会在空背景根节点失败。
然而望远镜恒等式仍成立：\(\sum_i\delta_i=8=\operatorname{OPT}_4-W\)。

## 5. 主目标与根税仍未被否定

本例满足

\[
\frac W{\operatorname{OPT}_4}=\frac7{11}>\frac12,
\qquad 2W-\operatorname{OPT}_4=6.
\tag{5}
\]

只计实际末位行动前的前缀 \((A,B,B)\)，三名 \(A\setminus B\) 客户负载为一，
八名 \(B\setminus A\) 客户负载为二，三名交叠客户负载为三。于是空背景根税为

\[
\tau_0(c_{<4})=
3\cdot\frac12+8\cdot\frac23+3\cdot\frac34=\frac{109}{12},
\qquad W+\tau_0(c_{<4})-\operatorname{OPT}_4=\frac{13}{12}>0.
\tag{6}
\]

所以它只否定“每个前缀都已经积累非负余额”。终局总余额仍恰是半覆盖目标，
可以允许早期出现负余额再由后期支付。一般人数半覆盖继续开放；空背景根总税现已由[61客户实例](root_tax_counterexample.md)否定；
不能把本例的首步失败改写成这两个全局目标的反例。
