## 1. 对象与局部前沿

采用 MODEL 的成本，不乘玩家权。类 a=0,...,m−1 的 N 名玩家为 p_(a,j)，j∈Z/NZ，权重 w_a>0；全局线性顺序先 j 后 a，记 pos(j,a)=jm+a。每个测试 τ=(a,b,K,o) 满足 a≠b，1≤K≤N，方向 o∈{+1,−1}。它对每名 distinguished 玩家 h=p_(a,j) 建立一对同费资源，轻用户窗口为

    p_(b,j+δ+k mod N),   k=0,...,K−1,   δ=1[a>b].

h 在动作0使用资源0；窗口玩家 u 在动作0使用资源 σ(h,u)=1[pos(u)>pos(h)] xor 1[o=−1]。动作1总选对侧资源。每个测试的所有 N 对资源费用相同，这里写 z_τ x^p。允许有限测试非负叠加，并要求每个类至少参与一个测试；零系数测试的资源仍保留。这样每名clone的两个资源子集动作均非空且互异，前沿计数是MODEL真实策略状态计数。单个测试的贡献表允许未参与类存在，但它只是代数子项，不把缺席类的空/空重复标签当两个合法策略。类名/“轻”只是角色名，不假设 w_a>w_b。

定义类前沿位模式，x∈Z/(2N)Z：

    B_x(j)=1[j<x],                  0≤x<N;
    B_x(j)=1[j≥x−N],                N≤x<2N.

它依次为全0、增长的1前缀、全1、增长的0前缀。类前沿空间为 x=(x_0,...,x_(m−1))∈(Z/(2N)Z)^m。沿 x_a→x_a+1 的 forward 单步由 clone j=x_a mod N 翻位；沿 x_a→x_a−1 的 backward 单步由 j=(x_a−1) mod N 翻位。仅N=1时这两个邻居重合；以下成本仍正确。N≥2时两者不同，且它们是该类前沿状态中仅有的、翻位后仍在前沿的玩家。

## 2. 共同扭转平移与严格商表示

在所有类上同时定义 T：

    (Ts)_(a,j)=s_(a,j−1),          j≥1;
    (Ts)_(a,0)=1−s_(a,N−1).

即把 clone j 移到 j+1 mod N，跨越末端的玩家额外翻位。T^N 是全局位互补，T^(2N) 为恒等。

**命题 A。** T 保持每名对应玩家的真实当前和偏离后成本。它把前沿相位 x_a 同时变为 x_a+1。因此每个测试对某类 forward 端点的成本只依赖两个相关类的相对相位；整体前沿空间可规范化 x_0=0，恰有 (2N)^(m−1) 个相对状态。

**证明。** 玩家 p_(a,j) 的 wrap 指示为 ε_h=1[j=N−1]。把该玩家为 distinguished 的资源对映到 index j+1 的资源对；若 ε_h=1，同时互换两侧资源。窗口的循环索引使用户关联保持。对窗口轻用户 u，写其 wrap 指示 ε_u。线性顺序的比较满足

    1[pos(u')>pos(h')] = 1[pos(u)>pos(h)] xor ε_h xor ε_u.

两者同一 clone index 时 wrap 相同且类顺序不变；只有一方 wrap 时比较恰反转；这覆盖所有情形。方向 o 额外的异或不影响该等式。故变换后轻用户实际资源侧为

    (s_u xor ε_u) xor (σ(h,u) xor ε_h xor ε_u)
    = (s_u xor σ(h,u)) xor ε_h,

与 distinguished 玩家所需的资源侧交换相同。每个资源的用户集只是相同权重的 clone 重标，费用系数也相同，所以每个负载及对应玩家成本保持。相同关系在一次指定玩家翻位后仍成立，故偏离后真实成本也保持。最后逐位代入 B_x 得 TB_x=B_(x+1)。对角相位平移若固定一个相位向量，平移量必为0模2N，因此作用自由，每轨道恰有2N个状态。证毕。

商状态记 r_a=x_a−x_0（a≥1）。规范化 x_0=0 不删除类0的动作：类0 forward 使所有 r_a 同时减1，backward 使所有 r_a 同时加1；类 c≥1 的动作只使 r_c 加/减1。端点 mover 标签须按同一 T 的重标对应，不能把商坐标固定误读为冻结类0玩家。

这个表示没有把不同类 front 的错位当作原全局 sweep。原 sweep 只是上述前沿空间内的一条对角走法。

## 3. 单测试的精确 forward 端点表

固定 τ=(a,b,K,o)。将 mover 类 c 的相位通过命题 A 归零，另一相关类相位为 r∈Z/(2N)Z。记费用系数暂为1，以下 old/new 为实际当前和偏离后成本；乘 z_τ 后再对测试相加即可。

**distinguished 类 c=a。** mover 为 p_(a,0)。令 v_k=(δ+k) mod N，

    σ_k=1[pos(v_k,b)>pos(0,a)] xor 1[o=−1],
    n_0(r)=#{k: σ_k xor B_r(v_k)=0}.

则

    O_(τ,a)(r)=(w_a+n_0(r)w_b)^p,
    Q_(τ,a)(r)=(w_a+(K−n_0(r))w_b)^p.

这是 mover 只有自己的资源对、另外 K 名用户按真实动作分到两侧的直接计数。

**窗口类 c=b。** mover 为 p_(b,0)，它恰参加 K 个窗口，令

    h_k=(−δ−k) mod N,              k=0,...,K−1,
    σ_k=1[pos(0,b)>pos(h_k,a)] xor 1[o=−1],
    e_k(r)=1[B_r(h_k)=σ_k].

则

    O_(τ,b)(r)=Σ_(k=0)^(K−1) [ (K−k)w_b+w_a e_k(r) ]^p,
    Q_(τ,b)(r)=Σ_(k=0)^(K−1) [ (k+1)w_b+w_a(1−e_k(r)) ]^p.

证明：在 mover 相位0时该类玩家全部动作为0。对所列第 k 个窗口，mover 当前一侧共有 K−k 名窗口玩家；翻位后目标一侧含 mover 共 k+1 名窗口玩家。distinguished 玩家与其当前同侧恰当 e_k=1，故公式计入自己的权重且在偏离后重新计算负载。跨越线性端点及 K=N 由同一计数覆盖。

对一般相位 x，forward mover 的贡献取 r=x_other−x_c。backward mover 则是相位 x_c−1 处 forward 边的反向：它的 old/new 精确为

    Q_(τ,c)(r+1), O_(τ,c)(r+1).

因此 α-margin 表为 O(r)−αQ(r) 与 Q(r+1)−αO(r+1)，不能把反向 margin 简写为负 forward margin。

以上给有限精确表示，可把全前沿端点检测从字面资源遍历转为每测试长度2N的费用表；没有证明某个倍率必有/必无稳定前沿。

## 4. 同权类内时钟不能新增合法前沿出口

考虑同一权 w 的三个玩家局部010/101触发资源对，两侧同费 c。一般局部结论明确假定翻位前后均非完整触发；用于类前沿时，只对按原index递增排列的锚定三元(0,i,j)、1≤i<j<N逐项应用，不把任意乱序或循环wrap三元包含进来。若一条翻位边的前后局部模式都不完整触发，则 mover 当前和偏离后负载都恰为2w。原因是非完整模式把三人分为2+1：单人组玩家翻位将完整触发，只有二人组成员的翻位能保持非完整，而它恰从二人组换到另一二人组。

所以在一个类的合法前沿边上，任意非负类内锚定时钟的总 α-margin 恰为

    −(α−1) Σ_(参与该玩家的时钟三元) c_T(2w) ≤0.

不需要单项式、次数或单调性，只需 c_T(2w)≥0。每个完整类前沿边的两端均不含010/101触发，因此本式可逐三元相加。结论：若某个类前沿状态在基体中对所有端点边稳定，那么任意此类内时钟也不能为它增加一个仍留在前沿空间内的 α-改善出口。这限制“先锁各类，再仅靠前沿出口覆盖合法状态”的证明；它不排除保留某个离开前沿的改善，也不排除其他同步机制。

## 5. 一个12玩家的精确不同步稳定前沿

取 m=3，N=4，p=8，α=21/20，类权 (1,1/4,1/16)。只用三个测试，全部 o=−1：

| 测试 (a,b,K) | max-normalized 系数 z | 每个资源的实际 x^8 系数 |
| --- | --- | --- |
| (0,1,1) | 19/100 | 311296/9765625 |
| (1,2,1) | 1/3 | 4294967296/1171875 |
| (2,0,4) | 143/300 | 38386270208/6624208646923275 |

这里 normalization 精确定义为：该测试的 sweep 类成本向量为 P,Q，令 scale=max_c{P_c,Q_c}，实际系数=z/scale。P,Q 直接由循环窗口正文公式得到（o=−时交换）；最后一个 scale=Σ_(r=1)^4(r+1/16)^8。资源总数3×4×2=24；每人仍仅两个动作。

**严格原环。** 全0开始，依原 j 后 a 顺序翻全体，再同序翻回，24条边每类精确 margin 为

| 类 | margin γ_a |
| --- | --- |
| 0 | 5196536771452589269747 / 69002173405450781250000 |
| 1 | 35209483 / 468750000 |
| 2 | 529420641444850677653 / 6624208646923275000000 |

每项严格大于3/40。配对对称性使两轮相同，字面审计仍重算全部24条边，不以该对称性替代核验。

**不同步稳定前沿。** 取 x=(0,4,0)，即每个 clone index j 的三类动作均为(0,1,0)。每类前后两个端点的 α-margin：

| 类 | forward | backward |
| --- | --- | --- |
| 0 | −429267676445185263491 / 1725054335136269531250 | −3337036005889500128279 / 18400579574786875000000 |
| 1 | −231363497 / 468750000 | −231363497 / 468750000 |
| 2 | −2021513519923027322347 / 6624208646923275000000 | −5308749789735550922347 / 6624208646923275000000 |

六项都严格小于−9/50。故任意类内010/101同费时钟仍不能令任何前沿端点成为 α-改善。直接枚举512个前沿状态，恰8个对端点稳定，正是 x+(t,t,t) mod8，t=0,...,7。

**必须保留的边界。** x不是基体的 α-PNE。类0的内部 clone j=1,2 的真实 margin 均大于1/5，翻位后离开类前沿空间。新增时钟可能压制或保留这些出口；本文没有排除全部选择。这个实例仅推翻“严格原 sweep 环自动提供全前沿出口”的一般命题，也证明稳定前沿不能由任意非负类内时钟新增合法前沿出口。
