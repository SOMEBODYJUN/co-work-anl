# 五地点固定倍率困难性：数学范围与研究价值审查

**审查对象：** `SC-FIVE-DECa-HARD`，以 `research/current/shared/five_site_exact_hardness.md` 的精确陈述和证明为准。审查日期 2026-10-02。此文是内部审查记录，不是外部同行评议、新颖性证书或投稿决定。

## 1. 是否回答原定问题

仓库的 `Q-INSTANCE-COMPLEXITY` 询问：两家带标签设施、同一有限目录、显式正有理原子权、实际线性负载成本、各带标签布局可独立指定精确独立混合客户 NE 的模型中，对**每个事先固定的有理** `a` 满足 `σ=(1+√3)/2≤a<φ=(1+√5)/2`，判定实例最优倍率 `α*(I)≤a` 的复杂度。新的定理在该模型中证明即使**恰五个共同地点**、正二进制整数权也弱 NP 完全，因此覆盖整个原定区间。结合既有三地点 `a=1` 命题和新定理的 `1<a<φ`，固定有理 `1≤a<φ` 的本类判定得到内部证明层的完整分类；`SC-PHI-A` 给 `a≥φ` 的普遍 YES 与多项式构造。

这**没有**把旧三地点定理的上限从 `σ` 提升到 `φ`：三、四地点的高倍率细分类仍未解决；没有证明五地点最少、`a` 作为输入时的统一复杂度、强 NP 困难、固定常数 YES/NO 间隙或精确求 `α*` 的多项式时间。`NO` 间隙可随源输入缩小。它给实例判定的困难性，不是新的普遍存在性上界。

## 2. 逆向数学审查及可复现证据

两条与原交付作者不同的内部审查路线分别从规范模型和证明义务重构，再逐式检查 §3 的五进制有界子集和与 `1/(k−1)` 间隙，§4 的 `δ>W` 宏原子双向 NE 对应，§5–6 在每个固定有理 `1<a<φ` 的严格正参数，§7–9 的全部十种异址、五种同址及两个标签顺序，§8 的八个互不冲突的离轨续局，§10 的显式正整数位长，§11 的 NP 有理证书及整数总重伪多项式 DP。未发现仍成立的致命反驳。特别是规范模型只要求显式覆盖，未要求地点本身必须是客户；本构造的五地点 incidence 合法。

独立交付的 `SHA256SUMS` 均匹配；在当前工作区重跑其 `verify_delivery.py`，冻结的两个有限审查批次、两个完整续局证书、四份故意损坏证书的拒绝均通过。23 个有限实例、1103 次参数及 96 次宏原子谱比较仅用于攻击算术和实现，不构成全称证明。原交付包关于无法取得 Git checkout 的记录是**当时的工具状态**，并非数学反证；实际仓库集成须以随后真实 Git 提交和仓库检查为准。

## 3. 与此前成果的价值比较

| 结果 / 问题 | 本次评价的边界 |
| --- | --- |
| 共同目录的尖锐 `φ` 多项式构造 `SC-PHI-E/A` | 现有最强的 A 篇主线：原论文给 `φ` 下界，并明确称紧确性开放；新上界在两设施共同目录这一精确子类中闭合存在性缺口。它仍不宣称解决任意设施数与异构目录的广义猜想。见 [IJCAI 2024 Theorem 5、Observation 4](https://www.ijcai.org/proceedings/2024/0315.pdf)。 |
| 新 `SC-FIVE-DECa-HARD` | 使 A 的**同一子类**有“`φ` 可构造、每个固定有理 `a<φ` 的实例达标判定弱 NP 完全”的配套分类。比旧三地点只覆盖 `a<σ` 的部分结果有实质推进；新宏原子强制与五地点全布局守卫是证明机制。单独论文价值取决于其相对先前广义困难性结果的新意表述及优先权。 |
| 任意长单交叠的尖锐 `ρ`，`SPARSE-RHO-ALL` | 与新复杂度定理同属高价值内部结果，但数学贡献不同：它给任意长目录的普遍尖锐存在性、构造及首个低区入口机制；新困难性固定两个设施和五个地点，给实例判定边界。两者没有自然的绝对大小次序，且作用类不能简单套入同一参数链。 |

**优先权的精确分界。** [IJCAI 2024 Theorem 6 的全文证明](https://arxiv.org/pdf/2403.03114)已经给较广模型在固定 `a<φ` 的 NP 完全性，但归约有随输入增长的 `m+2` 家设施，且 `U(g)≠U(h)`；它不能推出本次的两设施、相同五地点目录结果。故不能称本定理“首次证明低于 `φ` 的判定 NP 完全”。它是**严格受限类的强化及 A 同类判定边界的闭合**。全文文献排查尚未完成，尤其不能因定向检索未找到相同结论便认证新颖性。

**组稿含义。** 原出版评估认为局部困难性不足以形成独立第三篇；本次全局固定倍率分类跨过了当时的数学门槛，须重评。与 A 合并，可形成尖锐可构造上界与同一输入类阈值以下判定困难性的完整叙事；独立成篇则必须突出相对 2024 年广义结果的严格受限模型和新守卫方法。任何 SIAM 或其他期刊定位仍以外部审稿、优先权和实际英文论文质量为条件。
