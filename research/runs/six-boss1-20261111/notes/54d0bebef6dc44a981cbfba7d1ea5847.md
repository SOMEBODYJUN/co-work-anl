# 四源同一 X 隐藏尾层：独立字面付款审查

Boss1，RUN `six-boss1-20261111`。本审查只读取通用模型、原代码定义与无权重描述符；没有读取游戏点或调用优化器。

## 1. 固定对象和精确历史

固定共同有限非空标签目录及一份六人完整有序历史纯 SPE。设 actual 行动为
`A1,…,A6`，原 source i 的有序前缀为 `A1,…,A(i−1)`。对每名客户，令
`b_i=sum(a1,…,a(i−1))`，`P=sum(a1,…,a4)`，并只选一次

`X in argmax_Q f_P(Q)`，其中 `f_P(Q)=sum q/(P+1)`。

在 source i 强制 X，后续均由这同一份策略在强制历史下真实产生。写
`r=7−i`、`m=r−2=5−i`，其后继依次是 `Y(i,1),…,Y(i,m),T(i)`。
μ 的索引完整保留 `x,y1,…,ym,t`；其中 `Y(i,m)` 是第五位，`T(i)` 是第六位。

每个 source 和 hist 的两条质量等式是

`sum_(ys,t) μ(i,h,1,ys,t)=x_h`，

`sum_(ys,t) μ(i,h,0,ys,t)=H_h−x_h`。

四个 source 的尾位数分别为 6、5、4、3，故每 hist 的状态数分别为
64、32、16、8。16 个 hist 共给 1920 个非负 μ 与 128 条质量等式。

对真实 SPE 按客户状态分组得到这些 μ，直接满足等式。反向只有共同
`(hist,X)` 边缘的耦合可完成：对其质量 `M>0`，四个尾状态的条件乘积
可取 `product_i μ_i / M^3`；`M=0` 时所有对应 μ 为零。这个构造仅证明四份尾
边缘的测度兼容，不认证原 R/Z 的全联合律、跨分支标签别名、全部真实历史或完整 SPE。

原 21021 列采用固定 16 个 hist 支持。因此有限矩阵的必要性范围是旧投影位于该
支持的 SPE；通用公式对任意客户类型成立。固定支持本身不容纳所有任意类型实例。

## 2. 原 source IC、全部 actual SAFE、同一 MAX 和容量

source i 的 actual 收益始终为 `u_i=sum a_i/sum_j a_j`，零分子项为零。
强制 X 后该 source 的真实收益为

`v_i=sum μ x/(b_i+1+sum(ys)+t)`。

于是原 source 的完整历史 IC 给 `u_i−v_i>=0`。此处把分母中的 x 替成 1
只发生在分子含 x 的表达式中，因此 x=0 时系数恰为零，x=1 时是原分母。

对四源共 14 个真实新尾标签中的每个 L，以及每个 actual source j=1,…,6，
在 source j 改选 L 后，必须沿 L 自己的真实后继继续。记该偏离收益为 v(j,L)。
因为至多还有 `6−j` 位未来覆盖者，逐客户有

`v(j,L)>=sum_L 1/(b_j+7−j)`。

因此

`u_j−sum_L 1/(b_j+7−j) = [u_j−v(j,L)] + [v(j,L)−sum_L 1/(b_j+7−j)] >=0`。

这里的第一项是一条真实原 source IC，第二项逐客户非负；没有冻结另一条 X
分支的后继。j=6 时没有未来动作，第二项恒零，正好是 actual 第六位查询 L 的 IC。
共有 84 条 SAFE。

每个 L 的 14 条 MAX 是同一 `F_X=f_P(X)` 与 `f_P(L)` 的比较，P 始终是
actual 前四负载。14 条容量是 `K−|L|>=0`，其中 K 是同一共同目录的容量上界。
这些都在客户求和后非负；MAX 不能逐客户假设非负。

## 3. 真实末位 BR 和索引均值

source i 的真实末节点在 `A1,…,A(i−1),X,Y(i,1),…,Y(i,m)` 之后。
其 terminal 收益与对任一合法 Q 的查询差为

`sum μ (t−q)/(b_i+x+sum(ys)+1)`。

Q 可取 X、六个 actual 标签、该 source 的每个新 Y，或原六 T/B/C 标签的一组
固定均匀查询。原 literal 定义为：

- `T_k` 是原六元最优菜单中的第 k 个合法标签；
- `B_k=σ5(A1,A2,A3,T_k)`；
- `C_k=σ6(A1,A2,A3,T_k,B_k)`。

原 `PATTERNS=product((0,1),repeat=3)`，每词的三位严格是 `(T_k,B_k,C_k)`。
对于同一 hist 内每客户，三组会员数 `d_T,d_B,d_C` 已知。由于上述 BR 分母不依赖
k，对六条真 IC 取平均后恰可用 `q=d_Q/6`，没有任何独立性假设，也没有把均值加作纯行动。

## 4. 最后两位 PAIR 的三 IC 加非负付款

固定 source i 分支真实前四历史，包含原 source 之前的 actual 动作、强制 X，
以及前 `m−1` 个中间动作。逐客户背景是

`p=b_i+x+sum(ys[:-1])`，`d=p+1`，`z=ys[-1]`。

总历史长度确为四，所以 `0<=p<=4`，`1<=d<=5`。定义

`f(L)=sum l/d`，`g(L,R)=sum lr/[d(d+1)]`，

`U(L,R)=f(L)−g(L,R)=sum l/(d+r)`。

令真实第五、第六位的分支收益为 `s=U(Z,T)`、`w=U(T,Z)`；它们全部从 μ 求出，
不是 actual u5 或 actual u6。对合法 L,R 及第五位改 L 后的真实末回复 J_L，有

`TP(L,R)=s+w+g(Z,Z)−f(L)−f(R)+g(L,R)`

`= [s−U(L,J_L)] + [U(J_L,L)−U(R,L)] + [w−U(J_L,Z)] + [g(Z,Z)−g(Z,J_L)]`。

前三项依次是：真实第五 source IC；真实偏离历史 `(h,L)` 的末位 IC；原真实
末节点 `(h,Z)` 对合法 J_L 的 IC。末项为

`sum z(1−j_L)/[d(d+1)]>=0`。

这证明 TP 必要非负；单个客户的前三项不要求非负。把

`H=z/(d+t)+t/(d+z)+z/[d(d+1)]`

作为局部钱包，三份系数是

`TP(Q,X): H−(q+x)/d+qx/[d(d+1)]`，

`TP(Q,Q): H−2q/d+q/[d(d+1)]`，

`TP(X,X): H−2x/d+x/[d(d+1)]`。

对六个 indexed Q_k，第二式必须平均同索引对角 `(Q_k,Q_k)`。于是
`average(q_k^2)=average(q_k)=q`，不是 `q^2`。第一式的交叠则为
`average(x q_k)=xq`，因为同一个无索引 X 被固定。这里没有遗漏同源已知中间标签；
当 Q 等于 Z、X 或其他别名时，恒等式原样成立。

## 5. actual cap 和 RC：两 IC 加全局 MAX

现在回到 actual 前四历史 h，背景为 P，actual 第五位收益为 u5。
写 `F=f_P(X)`、`U_P(L,R)=f_P(L)−g_P(L,R)`。

对任一新尾标签 Q，令 `V=σ6(h,X)`，则

`u5−U_P(Q,X)`

`= [u5−U_P(X,V)] + [U_P(V,X)−U_P(Q,X)] + [F−f_P(V)] >=0`。

第一项是 actual 第五 source 改 X 的真实 IC，第二项是偏离历史 `(h,X)` 的
末位对 Q 的 IC，最后是同一个 X 的全目录最大性。因此 14 条 cap 的 μ 项确为
`−q/(P+1+x)`。

对任意合法 Q,R，令 `V=σ6(h,Q)`，旧 RC 恒等式为

`u5+F−f_P(Q)−f_P(R)+g_P(Q,R)`

`= [u5−U_P(Q,V)] + [U_P(V,Q)−U_P(R,Q)] + [F−f_P(V)] >=0`。

这也是两条 IC 加一条 MAX，不是三 IC。本层只在同一 μ 分支内取两个新尾标签，
或取一个新尾标签配一个 actual 已知位/六索引均值。前者 `qr` 在 μ 中精确可见；
后者平均交叠是新尾会员位乘已知均值。跨两个不同 μ 分支的真正交叠没有保存，
所以没有据条件乘积人为增添跨分支 RC 行。

## 6. 边界和独立算术范围

全程保留非严格不等式。零客户、空标签、同覆盖异标签、重复行动、X 与旧标签
相同以及任意历史依赖弱平局都不导致除零；所有非零份额的分母至少为 1。
本文没有声称这些有限行充分描述 SPE。

独立标准库核验器从原终局份额重建收益，而不导入生成器。其通用检查覆盖：

- 四源全部 64 个 actual 六位型与全部尾位型，共 7680 个客户型；
- 六个 original source 的全部240个 SAFE 偏离后继状态；
- 真实四步背景 p=0,…,4 与五个 PAIR 会员位的全部160个三 IC 恒等式；
- actual P=0,…,4 的320个 MX与320个RC局部付款恒等式；
- p=0,…,4、z/t/x及六个索引位的全部2560种字面平均；
- 逐分支系数与当前矩阵的核验结果另存 `independent_verification.json`。

通用恒等式的证明由上文承担，枚举用于检查实现的分母、符号和索引；不把枚举
次数作为 SPE 可实现性或全局福利结论。
