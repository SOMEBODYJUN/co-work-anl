## 2. 任意尾长的同源重查轨道

固定任意完整有序历史纯SPE sigma，以及一个固定真实有序源h，余k>=2人。背景为p_x，源规定行动者的真实最终收益为r。固定全局actual末位收益u_m、末前负载ell_x和共同目录最大主题大小K。

对每个合法主题T，从**同一h**强制T后沿原sigma完成，记中间k-2主题为F_1(T),...,F_(k-2)(T)，真实最后主题为C(T)。这是有限标签集上的确定映射C；同覆盖异标签仍不合并。选择任意初始合法主题T_0，递归

    T_(n+1) = C(T_n).

每次回到h；不是在旧叶后添加玩家。轨道最终周期，但证明不要求初始比较主题位于周期上。

固定一组合法查询Q_j及客户无关乘子mu_j>=0。查询可以包含初始T_0、actual各主题、六比较索引的均匀组合；也可另外以非负权mu_self在每个轨道分支末位查询该分支当前T_n。最后一种查询虽随n变化，但各次仍是合法真实末位IC。

给所有中间主题相同actual末价alpha_mid>=0、容量beta_mid>=0；末主题用alpha_last,beta_last>=0。设

    M = sum_j mu_j + mu_self,
    q_x = sum_j mu_j 1_{Q_j}(x),
    a_x = beta_mid + alpha_mid/(ell_x+1),
    b_x = beta_last + alpha_last/(ell_x+1).

对客户的当前/下一主题会员t,c和中间会员数s=0,...,k-2定义

    H_x(t,c,s) = (t-Mc)/(p_x+t+s+c)
                 + a_x s + b_x c
                 + (q_x+mu_self*t)/(p_x+t+s+1).

零分子份额按0。分子非零时对应t或c非零，首分母必正。每一轨道步骤的真实IC、actual末价和容量行非负相加给

    B := r + [(k-2)alpha_mid+alpha_last]u_m
           + [(k-2)beta_mid+beta_last]K
       >= sum_x H_x(t_n(x),t_(n+1)(x),s_n(x)).                 (1)

源r和全局u_m、K的预算完全相同；没有把不同离轨源收入合并。

## 3. 有限二状态Bellman证书支付整条无限轨道

取有理0<=theta<1。若每个客户有两个有限实数V_x(0),V_x(1)，满足全部

    V_x(t) - theta V_x(c) <= H_x(t,c,s)
    (t,c in {0,1}, s=0,...,k-2),                            (2)

则

    B >= (1-theta) sum_x V_x(t_0(x)).                     (3)

证明：将(1)按(1-theta)theta^n加权求和，左端权和为1。代入(2)后，对每客户的V项望远镜为

    (1-theta)[V_x(t_0)-theta^(L+1)V_x(t_(L+1))].

L趋无穷时尾项趋0；客户有限，各V有限，故可求和。全部行的乘子非负。theta=0即只用第一条单步portfolio。无限表达仅用于给出解析来源；(2)是有限条可精确核验的证书。

最强逐客户值是收缩Bellman方程的唯一解

    V_x(t) = min_(c,s) [H_x(t,c,s)+theta V_x(c)].           (4)

允许逐客户的扩大域路径任意取(c,s)，不声称这些局部路径能同时实现为一份目录或策略。这只使下界减弱，保持原SPE全部量词。

## 4. 三个有理候选的显式闭式

令e_tc=min_s H_x(t,c,s)。每条边的中间人数可独立消去，因为未来状态仅是c。记Psi_t=(1-theta)V_x(t)。精确为

    Psi_0 = min{ e_00,
                 (1-theta)e_01 + theta e_11,
                 (e_01+theta e_10)/(1+theta) },
    Psi_1 = min{ e_11,
                 (1-theta)e_10 + theta e_00,
                 (e_10+theta e_01)/(1+theta) }.            (5)

四个确定平稳策略分别是两个自环、全部去0、全部去1和二循环；对指定起点有两个策略同值，故只剩三个候选。Bellman收缩保证最优确定平稳策略存在，亦可由这四个2x2线性方程直接核(4)。所以(3)完全变成有限有理行生成器，最多检查4(k-1)个边代价和6个闭式候选；无需设置重查深度。

theta趋1时两起点共同趋

    min{ e_00, e_11, (e_01+e_10)/2 },                     (6)

即二状态的最小平均环。此时丢失初始最优主题的会员信息；因此不能只因有限映射有循环而把最优比较主题放进循环。theta<1明确保留初始信用，避免该既有失败。
