# 六人独立障碍线

## 0. 题面、隔离与首个鉴别实验

数学输入仅为本 RUN 的 packet-obstacle.json 所载目标与两个定义节，无已给障碍。六个玩家、共同非空有限标签目录、所有有序历史、任意纯 SPE 及任意平局。客户单位价值，允许零客户、空覆盖、覆盖相同的标签。

记给定终局的覆盖为 A，令 M(A)=max_T |T∖A|。每个至多六标签最优见证各自向 A 外贡献至多 M(A)，故 6M(A)≤|A| 将足以推出半覆盖。首个实验将精确枚举小目录的所有可实现 SPE 终局，区分两种可能：找出 6M(A)>|A| 的完整历史 SPE（仅反驳该充分条件），或者给出写明范围的阴性结果。另记 6u_6>|A| 可否发生，以免用未证的末位收益平均界。计数压缩只合并相同可实现结果集合，不固定相同负载历史的平局策略。

证据会用独立的有序历史小树复核；所有终局收益以 60 为公分母。反例必须有实际可扩展至全树的终局；有限无反例不构成普适定理。断点：正建立首轮计算与可读证据。

## 1. 首实验及一个可手验的末位反例

first_experiment.py 对每个行动从其后继可实现的 (最终各标签计数，末位标签) 集合取当期参与者最低可实现收益，再取各行动最低值之最大值。沿候选行动的特定终局超过或等于该门槛，当且仅当可在其他互不相交的行动子树中分别选取足够低的真实续局。子树在不同有序历史可独立选择；仅用共享集合节约计算。ordered_support 用显式客户集、全有序终局、逐兄弟存在量词交叉实现。

first_three.json 给出三标签七个非零隶属型计数分别取 0,1,2 的全部 2187 个目录；4806 个根 (计数，末位标签) 类型。0 个目录违反 6M≤W，261 个目录违反 6u6≤W，0 个目录违反半覆盖。first_four.json 给出 seed=20261119 的 2500 个四标签抽样目录，2982 个根类型，强充分条件未发现违反，末位平均界有 76 个违反。first_check_two.json 是两标签型计数 0..2 的 27 个目录双实现核对，first_check_three.json 是 10 个三标签抽样的双实现核对。二者包括异标签同覆盖和空目录覆盖型（标签集始终非空）；孤立客户不影响任何量。扫描范围外未作推论。

目录标签数最少的末位平均界反例可取两个不交标签 P,Q，|P|=1，|Q|=6。给出全树策略：首位选 P，其后每位在每个有序历史一律选 Q。若过去用了任意个 P，当前选 Q 终值至少 6/6=1，改 P 终值至多 1；根部跟随 P 收益 1，改选 Q 也为 1。故为全树纯 SPE，终局 PQQQQQ 福利 7、末位收益 6/5，所以 6u6=36/5>7。单标签全员同得，无法严格违反。双实现穷尽此例所有 (最终 P 数,最终 Q 数,末位标签)：(0,6,Q),(1,5,P),(1,5,Q)。另一名首轮范围内客户数最小的三标签反例在 first_three.json；单独用完整历史程序复核所有根类型。此例仅排除末人收益≤均值，原题及充分条件 6M≤W 仍开。

## 2. 尾二人的共同阻挡标签（一般必要条件）

在任何四步有序前缀 p，写 p_x 为历史负载、v(T)=Σ_{x∈T}1/(p_x+1)、I(T,C)=Σ_{x∈T∩C}1/((p_x+1)(p_x+2))。当末二人选 T,C 时，各自收益 v(T)-I(T,C)、v(C)-I(T,C)。取 v 最大的一个目录标签 L。在第五人改选 L 的真实子局，末位真实选 C 后，L 的收益至少为 C 的收益，因为 v(L)≥v(C)。末位 C 的收益又大于等于其每一个备选标签 T 对 L 的收益。因此该前缀的在轨第五人收益 u5 满足
u5≥max_T [v(T)-I(T,L)]，对每一个 v 最大标签 L 同时成立。
不需要 C 唯一，L 可任意打破并列，不冻结在轨末位。若 X_j⊂T_j∖A 是任意两两不交的未覆盖最优块，总量 B，A 是给定原终局的并集，块上 p_x=0，则 B≤q u5+|L∩(∪X_j)|/2≤q u5+M/2，其中 q 为所用块数。此式独立于对每个 T_j 分别取不同的惩罚标签。下一步将同一共同标签的思路推进至更长尾部，或找出推进失效的明确机制。
