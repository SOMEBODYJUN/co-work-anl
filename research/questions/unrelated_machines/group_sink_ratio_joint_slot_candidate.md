# 组—汇点比例处理时间下的联合槽舍入（候选正面接口）

本稿记录一个可复用的结构扩展：共同资格私有组的任务在 home 与每个可用 sink 上可以有不同处理时间，但同一组—sink 对内保持一个精确比例。它把“所有有限端时间相同”放宽为“按 sink 的组级比例缩放”，同时保留真实联合选择与位多项式输出。它不是 `UM-TARGET-v1` 的一般算法；唯一 home、共同资格和宏任务大边仍是结构假设。证明状态为候选，外审和全球新颖性均未认证。

## 1. 结构与精确命题

机器分成不交的 home 集 `H` 与 sink 集 `Z`。任务分成宏任务 `B` 与私有组 `J_h`（`h∈H`）。宏任务只允许分配到 `H`。对每个组给出共同资格 `E_h⊆Z`；每个 `j∈J_h` 只允许在 `h` 或 `E_h` 中运行。设 home 处理时间为 `w_j≥0`。对每个 `z∈E_h`，存在显式有理比例 `ρ_hz≥0`，使得

```
p_{h,j}=w_j,       p_{z,j}=ρ_hz w_j       (j∈J_h).
```

若 `w_j=0`，结构要求 `p_{z,j}=0`。宏端时间 `p_{h,b}` 是一般非负有理数。定义 `W_h=Σ_{j∈J_h}w_j`，并令 `ρ_max=max_{h,z}ρ_hz`（空的 `E_h` 不参与最大值）。比例条件可由输入在位多项式时间内交叉相乘核验；若组中没有正 `w_j`，所有 sink 端必须为零，比例可取零。

固定阈值命题 `UM-RATIO-GROUP-JOINT-SLOT-v1`：给定有理 `T≥0`、`0≤δ<1/2`，若

```
W_h≤T,
 w_j≤δT,
 p_{h,b}>T/2  对每个有限宏端，
ρ_max<2,
```

则存在确定性总位多项式算法，返回 `FAIL` 或实际完整分配；若成功，它满足

```
L_h≤(3/2+δ)T,
L_z≤(1+ρ_max/2)T.
```

若 `OPT≤T`，算法必不返回 `FAIL`。因此当固定结构常数 `δ≤δ̄<1/2`、`ρ_max≤ρ̄<2` 时，成功调度满足

```
C_max≤αT,   α=max{3/2+δ̄, 1+ρ̄/2}<2,
ε=2−α=min{1/2−δ̄, 1−ρ̄/2}>0.
```

未知最优值命题 `UM-RATIO-GROUP-PROMISE-APPROX-v1`：在同一结构类中，不给 `OPT`，承诺在真实 `OPT` 处上述三项阈值条件成立（`W_h≤OPT`, `w_j≤δOPT`, 所有有限宏端 `>OPT/2`），并给定 `δ̄,ρ̄` 的固定上界。则有确定性位多项式算法输出实际调度，`C_max≤αOPT`。若 `OPT=0`，逐任务选择零端；空任务直接输出空分配。若比例常数随输入任意逼近边界，则这里只得到逐实例 `max{3/2+δ,1+ρ_max/2}`，不声称统一 `ε`。

## 2. 虚拟出口与必要 LP

设 `d_h=(W_h−T/2)_+`。给每个 `d_h=0` 的 home 一个零成本 dummy 旁路。LP 变量为宏位置 `a_{b h}≥0`、组到 sink 的 token `y_{h z}≥0` 以及零需求旁路 `y_{h⊥}`。约束为

```
Σ_h a_{b h}=1,                         (每个宏任务)
 x_h:=Σ_b a_{b h}≤1,                    (每个 home 至多一个宏)
 Σ_{z∈E_h}y_{h z}+y_{h⊥}=x_h,
 Σ_h ρ_hz d_h y_{h z}≤T                 (每个 sink).
```

禁止 `y_{h⊥}` 于 `d_h>0`。所有系数是显式有理数，LP 规模为输入的多项式。

若存在 makespan `T` 的真实调度，宏端大于 `T/2` 使每个 home 至多一个宏。对占用 home `h`，记 `e_h` 为被送离 `h` 的私有任务的 home 总时间。因为 home 负载≤`T`，有

```
e_h ≥ W_h−(T−p_{h,b}) > W_h−T/2=d_h.
```

令 `e_{h z}` 是送到 sink `z` 的部分，若 `e_h>0` 取 `y_{h z}=e_{h z}/e_h`；若 `d_h=0` 走 dummy。由比例结构，真实 sink `z` 的负载是 `Σ_h ρ_hz e_{h z}≤T`，故

```
Σ_h ρ_hz d_h y_{h z}≤Σ_h ρ_hz e_{h z}≤T.
```

因此真实 `T` 调度给出 LP 可行见证。注意等比例是必要性成立的关键；只给上界 `p_{zj}≤ρ w_j` 时，真实 sink 负载不能反推出 `Σρ e_{h z}≤T`，本 LP 可能错误拒绝。

## 3. 按 sink 成本排序的联合整数流

对每个 sink `z`，把所有正 `y_{h z}` 按成本

```
c_{h z}=ρ_{h z}d_h
```

非增排序，并在一维质量轴上放置长度 `y_{h z}` 的连续区间。用单位槽切开。组 `h` 连接它在每个 sink 的相交槽，交长为边权。宏—home 部分与槽部分放在同一网络：源→宏容量1，宏→允许 home 容量1，`h_in→h_out` 容量1，`h_out`→该组在各 sink 相交的槽容量1；`d_h=0` 时另有到 dummy 汇的旁路；每个槽→汇容量1。

LP 解给该网络值 `|B|` 的分数流。网络容量全为整数，确定性增广路得到值 `|B|` 的整数流，因而同时选择宏的 home 与每个占用组的 sink；不先分别舍入两个匹配。

对任意 sink `z`，若整数流选中了其第 `r≥2` 个槽中的组 `h`，排序保证该槽成本 `c_{h z}` 不超过前一完整槽的每单位成本。故所有非首槽的选中成本可由互不重叠的前槽分数成本支付；首槽至多增加

```
max_h c_{h z}≤ρ_max·T/2.
```

于是同时有

```
Σ_{h→z} c_{h z}≤Σ_h c_{h z}y_{h z}+max_h c_{h z}
                    ≤T+ρ_max T/2.
```

这是加权有序槽收费；成本排序而不是按 token 数排序是本扩展的新增步骤。

## 4. 前缀恢复与真实负载

令 `τ=1/2+δ`。选中宏的 home `h` 若 `W_h≤τT`，不撤离私有任务；否则按固定编号扫描任务，形成一个前缀，直到剩余 home 负载不超过 `τT`。在撤离最后一件之前，已撤离 home 总量严格小于 `W_h−τT`，最后一件至多 `δT`，所以实际撤离量

```
e'_h < W_h−τT+δT=W_h−T/2=d_h.
```

若 `W_h≤τT`，则 `e'_h=0≤d_h`。所有私有任务具有同一组的 sink 资格；将该前缀送到整数流选中的 sink `z` 合法，且其 sink 处理量为 `ρ_hz e'_h≤ρ_hz d_h=c_{h z}`。因此

```
L_h≤T+τT=(3/2+δ)T,
L_z≤Σ_{h→z}c_{h z}≤(1+ρ_max/2)T.
```

未占用 home 保留全部私有任务，负载 `W_h≤T`；`d_h=0` 的占用 home 也有 `W_h≤T/2`，故同一 home 界成立。每个宏和每个私有任务都恰分配一次。

## 5. 未知 OPT、边界和复杂度

先处理空任务与 `OPT=0`：非负时间下 `OPT=0` 当且仅当每个任务有零端，逐任务选零端即可。对 `OPT>0`，令 `Q` 为所有有限处理时间分母的乘积；其位长是输入分母位长之和，且 `OPT` 与可行调度负载在网格 `k/Q` 上。用初始合法分配给出整数上界 `QU`，在 `[0,QU]` 上二分最小通过值。测试 `t` 包含 `W_h≤t`, `w_j≤δt`、有限宏边 `p≤t` 与上述 LP，其中 `d_h(t)=(W_h−t/2)_+`。

测试单调：随着 `t` 增大，资格宏边只增加，`d_h(t)` 不增，sink 约束只放松，零需求旁路只增加。故二分次数 `O(log(QU+1))`，不是按数值 `Q` 扫描。承诺在 `t=OPT` 通过，得到最小接受 `t≤OPT`，再按第3–4节舍入。每个 LP、槽网络、排序、增广和前缀扫描均为输入位长多项式；有理交长和成本比较用整数交叉相乘。比例条件也只需逐边交叉相乘验证。

`T=0` 时只需零端检查；若存在正宏端而某私有任务无零端，则不可能有 `OPT≤0`。空 `E_h` 对正 `d_h` 的 home 使 LP 不可行，语义正确。分母乘积位长而非其数值控制搜索复杂度。

## 6. 准确范围、限制与待审义务

这是 `UM-WEIGHTED-GROUP-JOINT-SLOT-v1` 的组—汇点比例扩展，不改变原稿的唯一 home、共同资格或宏大边假设；原等端接口是 `ρ_hz=1` 的特例。新 LP 使用每条组—汇点边的成本 `ρ_hz d_h`，因此允许不同 sink 对同一组有不同缩放。

尚待独立审查的重点是：

1. 网络槽的交长与带 home 容量的联合整数流确实保留每个组恰选一个 sink；
2. 必要性不误用 `e_h=0` 或零时间任务；
3. 未知 OPT 的单调测试在 `d_h=0` 与宏边阈值断点保持；
4. `ρ_hz` 的比例核验、零任务、空 sink、巨大分母的总位复杂度；
5. 该结构与既有加权组正文的差异是否足以成为独立可复用资产；不把结构类结果升级为一般 `UM-TARGET-v1`。

## 7. 研究价值判断

**Truth：** 证明链是条件性候选；需独立审查后才能进入内部可用。
**Value：** 明确指出等端时间假设的可放宽形式，并把槽收费从 token 数改为真实组—汇点成本。
**Novelty：** 尚未查到同一合同的先例，不能据此宣称新颖。
**Mechanism：** 比例结构使“home 需要释放的时间”能线性换算为任一 sink 的真实成本；成本排序的有序槽将多 sink 选择一次性整数化。
**Ambition：** 仅推进一类结构接口；不接近一般输入的统一常数突破，因分组生成和共同资格提取仍未解决。
