# 去掉共同出口资格后的唯一 home／等量子逐件资格流候选

以下是对 `weighted_group_joint_slot_rounding.md` 的一个**独立限域变体**。不改仓库文件；这里只保存候选合同、证明及边界，供上游判断是否值得冻结。

## 合同：全占用、全局等端 tiny 量子、任意资格

显式机器是不交并 `H\cup Z`，其中 `H` 是 home、`Z` 是接收机。私有任务 `J_h` 唯一可在其 home `h` 上完成；任务 `j\in J_h` 还可在任意显式集合 `E_j\subseteq Z` 的接收机上完成。其所有有限端处理时间都是同一个全局量子 `u>0`：

```
p_hj = p_zj = u       (z\in E_j),
```

且 `E_j` 可完全不同（不要求共同资格、laminar、交叠或非空）。可有 `E_j=\varnothing`，此时任务只能留在自己的 home。记 `n_h=|J_h|`，故 `W_h=n_hu`。

有恰 `|B|=|H|` 个宏任务。每个宏任务在**所有** homes 上可用，并且处理时间同为 `p`，满足给定阈值

```
T/2 < p <= T .
```

宏任务和私有任务均显式列出；任务数、机器数、资格图、`T,p,u` 都是二进制有理输入。可另加 tiny 条件 `u<=delta T`（`delta<1/2`），但下面的精确算法实际上不消耗 `delta`。

### 给定阈值的精确合同（EXACT-EQUAL-QUANTUM-ELIGIBILITY）

存在一个确定性总位多项式算法，输出 FAIL 或完整分配，并且：

* 若 `OPT<=T`，必输出 `C_max<=T`（因此给定 `T` 上是精确判定/构造）；
* 任意成功输出都逐机满足 `L_h<=T`、`L_z<=T`；
* FAIL 在该结构类中等价于没有 makespan `T` 的分配，而非仅仅是一个近似器的拒绝。

该合同保留唯一 home 和等端 tiny 体积，但完全去掉组共同出口资格。比率为 1；若只想接入现有 `3/2+delta` 接口，也可无损地把 `T` 换成给定目标并报告 `<= (3/2+delta)T`，但那会丢掉本变体真正的精确性。

## 算法（只用整数下界流，不用配置/整数调度 oracle）

### 1. 宏任务位置

建立任意固定双射 `B\leftrightarrow H`（宏端点是 complete，时间同为 `p`）。因为 `2p>T`，任何 `T` 可行调度都不可能把两个宏放在同一 home；而宏数恰为 homes 数，所以每个 home 必须恰放一个宏。宏分配与私有任务流完全解耦。

### 2. 每个 home 必须外送多少个私有任务

home 放一个宏后剩余容量为 `R=T-p`。最多能在该 home 保留

```
r_h = floor(R/u)
```

件私有任务。令必需外送的件数

```
k_h = max(0, n_h-r_h).
```

这等于 `max(0, ceil((W_h-R)/u))`；不需要对 `W_h` 加上任何正下界。零量子私有任务可先全部留在 home，单独处理 `u=0` 的退化分支。

### 3. 一个带下界的整数网络流

网络节点为 `s`、每个 home `h`、每件私有任务 `j`、每个接收机 `z` 和 `t`：

* `s -> h` 容量区间 `[k_h,n_h]`；
* `h -> j` 容量 `1`，只对 `j\in J_h`；
* `j -> z` 容量 `1`，只对 `z\in E_j`；
* `z -> t` 容量 `q=floor(T/u)`。

求带上下界的可行流（标准 super-source/super-sink 转换，再用整数增广最大流）。所有容量都是整数，故得到整数流。流过 `h->j->z` 的任务送到 `z`；未送出的任务留在其唯一 home。每件任务最多走一次，资格边按输入逐件读取，因此完全允许非共同、非 laminar 的 `E_j`。

### 4. 正确性

**完备性。** 设存在真实 `T` 调度。宏数等于 homes 数且 `p>T/2`，故该调度每个 home 恰有一个宏。对 home `h`，留在 home 的私有任务数至多 `floor((T-p)/u)=r_h`，故外送数至少 `k_h`。接收机 `z` 的真实负载为某个整数倍 `m_zu<=T`，于是 `m_z<=floor(T/u)=q`。把真实外送任务沿其实际资格边送入上述网络，得到一个可行整数流。

**可靠性。** 网络可行流把 `m_h` 件任务从 `h` 外送，其中 `m_h>=k_h`。home 负载

```
L_h = p+(n_h-m_h)u <= p+r_hu <= T.
```

接收机负载是 `m_zu<=q` 件量子，故 `L_z<=qu<=T`。宏双射、私有任务的 home 留存和流外送合起来恰覆盖每个原任务一次。因而流存在当且仅当该类上存在 `T` 调度；`FAIL` 不是一个未经证明的整数 oracle 语义。

带下界流可由一次标准可行循环流（加入 `t->s` 无限边、平衡点到超级源/汇）在总位长多项式内求出；至多 `|J|` 单位增广。分数处理时间只出现在一次 `floor` 和输出负载计算中，不导致按数值大小的循环。

## 未知最优值（可选的 promise 端）

若希望不给 `T` 而承诺真实 `OPT<2p`（等价于 `p>OPT/2`），同一类可直接求精确最优值。任意可行上界取

```
U = max_h (p+n_hu),
```

即全部私有任务留在 home。对 `t\in[p,2p)`，定义

```
r_h(t)=floor((t-p)/u),   q(t)=floor(t/u),
 k_h(t)=max(0,n_h-r_h(t)).
```

流可行性随 `t` 单调（`r_h,q` 只增，`k_h` 只减）。最小临界值必在有限集合

```
{p+ku : 0<=k<=max_h n_h}  union  {ku : 0<=k<=sum_h n_h},
```

与 `[p,2p)` 的交集里；该集合大小 `O(|J|+|H|)`，排序后逐个或二分测试带下界流即得位多项式精确 `OPT`。在 promise 下 `OPT` 落在搜索区间，且宏位置确实一-home；若区间内没有可行候选则报告 promise 域外。若 `u<=delta OPT` 亦可作为 tiny 承诺，但算法不使用它。

## 为什么这是真正去掉共同资格，而不是把资格悄悄变回交集

例如 `T=1,p=3/5,u=2/5`，一枚 home `h` 有两个私有任务 `j_1,j_2`，分别 `E_{j_1}={z_1}`、`E_{j_2}={z_2}`，且 `h` 也都是可用端。将宏放在 `h` 后，两个私有任务分别送到两个 sinks，三台实际机器负载均不超过 `1`。它们的资格交集为空；任何把整组强行放到一个共同 sink 的 token 证明都会错误地拒绝该实例。本流逐件使用 `j->z` 边，保留了这类分裂出口。

## 边界和可复用扣除

1. **全局同量子是承重的。** 若每件任务有不同 `w_j`，`z->t` 的 `T` 容量不再能转成整数件数；同一网络会变成带加权容量的 generalized assignment。即使只有一个 home、一个 sink，决定哪些可选任务留 home/送 sink 就包含 subset-sum 型二箱分配。故本接口不能把“端点等时”误写成“只需每件 tiny”而继续声称普通整数流精确。
2. **全占用且同宏时长是承重的。** `|B|=|H|`、宏 complete、共同 `p` 使占用模式固定，私有流不必与宏匹配联合舍入。若宏时长或宏-home资格任意，则每条宏边改变相应的 `k_h`，需要把匹配选择与带下界资格流耦合；这正是原 `weighted_group` 的联合选择义务，不能免费拆成“先匹配、再流”。
3. **若只需 `3/2+delta`，可放宽宏同质化。** 在保留完全占用而允许各宏 `p_b>T/2` 时，取 `k_h=max(0,ceil((W_h-(1/2+delta)T)/u))`，再做同一流，可给出 `L_h<= (3/2+delta)T`、`L_z<=T`；真实 `T` 调度仍保证这些下界。此推广不再精确，且要求 `W_h=n_hu`，但允许宏时长异质（宏匹配仍与流独立，因为只使用 `T/2` 下界而非实际 `p_b`）。
4. `u=0` 时全部私有任务逐件留 home，宏双射直接给 `L_h=p<=T`；`Z=\varnothing` 时流只有在所有 `k_h=0` 时可行；空任务、空 home 以及 `E_j=\varnothing` 均由同一网络边界处理。

## 与现有结论的扣除

* `weighted_group_joint_slot_rounding.md` 允许宏任务在任意 home 边上选择、每组 `w_j` 可不同，但要求一个共同 `E_h`；通过虚拟 `d_h`、home-token 和有序槽给 `3/2+delta`。本接口删掉共同 `E_h`，改为全局等量子和固定一-home占位；改用逐件资格流，获得给定 `T` 的精确 `1`。两者没有量词包含关系：本接口的全占用/全宏同质化不在旧稿，而旧稿的异质 `w_j` 和宏联合选择不在本接口。
* `hall_group_joint_flow.md` 还要求共同资格、组总量下界和 `q`-槽，给 `q(2+delta)/(q+1)`；本接口不要求正组总量下界、也不固定 sink 数或资格层次，但放弃了可变宏占位与异质任务尺寸，网络是普通下界流而非 Hall token。
* `shared_sink_joint_macro_assignment.md` 处理一个共同 sink，并可用 cover-FPTAS 及最小成本匹配联合选择异质宏；本接口允许多个 sink、逐件任意资格，却以宏全占用/同质时长换取整数流。它没有把多 sink 的加权容量免费压成标量预算。
* `joint_matching_completion_and_block_cuts.md` 的半单位选择归约说明，一般“先共同选宏，再补小任务”接口存在 NP 难的 `H` 选择；本变体明确冻结该占位（所有 home 都有且只有一个同质宏），因此没有调用那个被禁用的整数选择 oracle。

## 结论

这是一个可审计的、非共同资格的正面接口：唯一 home + 全局等端 tiny 量子 + 全占用同质宏，允许完全任意的逐件 `E_j`，且给定 `T` 时由一次整数下界流精确构造。它不能被外推为 `weighted_group` 的一般资格版本；首先会失效的边界是不同 tiny 量子（加权容量）或宏占位/时长异质（联合选择）。
