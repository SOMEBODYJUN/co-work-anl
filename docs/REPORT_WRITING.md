# 用实质认识写深度报道

写作者先读本批thinking_context.txt、承重机制及其最强对手，再读真实观察。
开头交代本轮最重要的发现，随后解释主体的选择、约束、传导与代价。

外部写作依据：BBC Academy《Features for the News website》2019版，第2—3、6—10页：
围绕清楚的中心认识组织文章；解释发生了什么以及为何发生；辨认受益者与承受者；
让背景服务于理解；把重要发现放前面，繁琐细节可链接原始材料。
原件：https://downloads.bbc.co.uk/academy/academyfiles/Features_for_the_News_website_guide_v1-0.pdf

Reuters《Standards and Values》的Sourcing、Freedom from bias及Opinion and Analysis：
考虑来源的动机，主动寻找能推翻主解释的材料；公平并非给每方平均篇幅。
署名观点应有充分根据。本项目是研究分析，保留作者的经济裁决；不照搬新闻稿禁写
个人意见的编辑制度，也不把措辞激烈当作认识深入。
原件：https://reutersagency.com/about/standards-values/

以下是对本项目的具体适配：正文每一节回答一个读者确实需要理解的问题，形成从
事实到行为、从行为到机制、从机制到后果的连贯推理。来源冲突须解释分歧发生的
环节，并说明主判断胜出的证据。真实人物与企业材料能显示行为时使用，未取到的
采访、场景和对话不能编造。经济推断的归属应清楚。

后台另存验收、模型限制和完整论证。正文保留会改变判断的条件，以相应事实解释，
不在每一段重复方法声明。结尾给读者一个清楚认识及其后果，不复述整个工程过程。
