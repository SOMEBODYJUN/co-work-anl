# 由过往实际失误建立的回归检查

这些是以后每份相关笔记都应重点检查的风险，不表示当前所有原稿已经被再次核验。

| 风险 | 必做检查 |
| --- | --- |
| A定理保留，B证明或旁注消失 | 新审阅者原图盲读建立独立来源清单，与现有清单求并；不能只看标题或行数 |
| 简单函数分格数与截断范围不相容 | 写明指标范围、格点、端点与无穷值，正反算分格；检查“格点相等”是否仍在截断区 |
| 老师负部约定被改成标准教材约定 | 保留老师定义；若取 min(f,0)，核对相应分解式的加减号 |
| 逐点、依测度、几乎处处、一致收敛混淆 | 明确量词、定义域、测度有限条件及整列/子列；每条蕴含各写证明或反例 |
| 打字机序列把[0,1]改成(0,1] | 原定义域、每层区间的并、x=0和其余端点分别检查；不默改集合 |
| 用抽出子列的坏集控制原整列 | 对整列另构造尾上确界或明确合适论证；不能把子列估计搬给整列 |
| 从上连续性缺少有限性条件 | 检查递减列是否有某一项测度有限，明确从该项开始；避免无穷大相减 |
| 硬币模型漏掉最小σ-代数 | 保留“使坐标函数可测的最小σ-代数”等原旁注，核对生成族 |
| 第三页乘积拓扑、末页拓扑反证被当成边角略去 | 分别给来源ID与正文位置；核实两处的论证关联及其实际假设 |
| 留题只剩提示、指定证明方法没做 | 完整保留题目和指定方法，在原位给蓝色完整答案，原待填位继续红色 |
| 公式可编译就被称数学无误 | 数学条件与推导独立审阅；数值/枚举是辅助，不能证明一般结论 |
| 子代理失败被算成已经审核 | 核对实际返回、文件落盘、任务ID、版本和全量范围；失败不增加计数 |
| “正在保存”后没有文件 | 交付前实际检查文件存在、包可解压，列出真实下载件 |
| 正文修了但沿用修改前的三轮结论 | 完整内容版本哈希变化，计数归零，锁定新版本重新全查 |
| 反复重复同一个错读仍被称收敛 | 每轮新线程先读原图再看稿，不让后续审阅者获知“已通过”结论 |
