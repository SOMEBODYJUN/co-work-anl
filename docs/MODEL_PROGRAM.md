## 真实历史基线

`research/models/jst_example`包含JST R6原数据、许可说明、转换脚本对应面板、明确实验和结果。原始文件是18国1870—2020年、2718行、88次危机起点；使用了年初/年末约定、至少一年的特征滞后、三年预测窗口、战争及危机后排除等事先写明的规则。程序生成1741条可用预测行。它使用修订后的历史数据，属于回顾验证，不冒充当时原始发布版本的伪实时研究。

特征为私人信用/GDP、五年信用/GDP变化、期限利差、短期利率、五年实际房价变化和公共债务/GDP；国内六变量基线，不是BoE WP848的原代码/完整变量复现。[BoE研究](https://www.bankofengland.co.uk/working-paper/2020/credit-growth-the-yield-curve-and-financial-crisis-prediction-evidence-from-a-machine-learning)提供信用、利差、非线性与历史验证的依据；本例另行设定并保存所有变换和划分。

训练信息期最多到1981年，标签在1984年底成熟；校准信息期1985—1999年，标签到2002年底成熟；测试信息期2003—2016年，标签最多到2019年底成熟。每个预警行不是一次独立危机，程序按事件ID去重，并检查同一事件不跨拟合边界。国家仍可能共同受到全球冲击，不能把事件数当完全独立样本数。

实际测试包含187行、39条正标签、13个有合格预测行的国别危机事件。在校准段10%非危机期警报预算下，当前logit检出3个、漏掉10个，Brier约0.1705；训练基准率的Brier约0.1766。当前HGB未检出这13个事件，Brier约0.1832，差于基准率。这个实验没有证成复杂模型更好。**当前HGB不采用为主预警器；logit仅保留为比较基线，两者均未获得中国事件概率用途。**不能通过在已看过的测试段上反复调参，把成绩改好后再称独立验证。

下一步比较全球变量、不同制度时期、事件定义与国家迁移等具体假设；每次先登记实验与选择规则。此测试段已经公开查看，后续在它上的开发属于探索性比较；新的确认性检验需要预先锁定的独立数据或评估安排。主判断继续由真实中国观测、部门核算和机制完成。

## 统一运行

```sh
python bootstrap.py --research
.venv-methods/bin/python work.py methods run --name early-warning \
  --input research/models/jst_example/experiment.json \
  --output work/history-model.json
.venv-methods/bin/python work.py methods run --name bank-stress \
  --input tests/fixtures/models/bank.json --output work/bank-check.json
```

early-warning输入列为country/as_of/horizon_end/event/event_id及明确features；正标签可附event_date以检查确在未来窗口。verified_release_vintages还须提供逐行available_at，不能晚于信息日。预处理只在训练段拟合，校准器只在校准段拟合，阈值只在校准段选择，测试段不参与这三步。输出逐行分数、基准、概率损失、可靠性分箱、国别及事件结果。警报预算是有理由的决策偏好，不是材料权重。

bank-stress要求期初资产负债勾稽；信用组合互不重复，每组的准备仅吸收对应损失。损失率、存款流出、折价、RWA变化和外部承接均为有来源的条件参数。信用损失不再从现金重复扣除；流动性借款不能自动增加权益；未能支付的流出显示资金缺口。它是一个期限上的条件测算，尚非完整动态银行网络。Main将这些数值与财政、企业及居民接口对账，再裁决现实路径。

压力研究的外部依据是[巴塞尔委员会压力测试原则](https://www.bis.org/committees/bcbs/basel-consolidated-guidelines/module/rma/30)：明确资本/流动性用途、与对象相符的数据粒度和模型、场景与参数依据，以及独立质询和敏感性复核。本地会计引擎是依这些问题构建的简化研究工具，不宣称复现某家监管机构的完整模型或满足监管验收。
