# 作者复刻：本轮要求逐项对照

当前目标：以已有的人物复刻项目为实现基础，忠实重建“窥市寻真”的认识、判断方式与表达，供 GPT 使用，并保留可回查的原文。先完成作者学习，再开展经济危机分析。

这份对照说明用户各句话要求实际做什么；不把它当作克隆方法或已完成的证明。

| 用户要求 | 对应的执行含义 | 此前需要纠正的做法 |
|---|---|---|
| “不能猜”“当然是用别人项目” | 方法依据来自项目原始方法和实际源码。基于它改接口、接数据，不能重新发明提炼方法。 | 读介绍后自行拼接，又把拼接整体归到上游名下。 |
| “别人克隆人的项目” | 项目本身须有个人模拟的实现；先核清目标、输入、完整处理和输出。 | 把记忆组件、评测项目和训练项目笼统称为一套现成克隆方案。 |
| “重新做”“按照每一个要求做” | 按本表重做实际实现和交接；旧包、旧完成声明不能继续视为已满足要求。 | 仅增加提醒 Pro 的提示词，没有纠正实现。 |
| “全都用这个” | 正式分批学习为 6.0 Astra Max；按随后明确补充，流程测试为 6.0 Sol。实际模型身份留存。 | 把测试与正式模型、计划与执行混为一谈。 |
| “一篇……一批吧” | 最后明确的是每批一个 fresh 子代理，按完整文章和实际长度安排，不机械逐篇换。 | 一篇生成极长笔记，或同一个代理无限累积。 |
| “上下文够……浪费 subagent” | 批次充分使用真实可用上下文，计算原文及原生调用展开后的长度，不编造模型容量。 | 把任意字符数当作已验证的上下文容量。 |
| “一批一批弄好” | 本批实际走完并保存，再由新代理处理下一批；各批产物须可继续使用。 | 只派任务、只读、只生成初稿就报完成。 |
| “每一个 subagent……必须完成这样走完” | 交给代理的是可执行上游链，不能让每个代理自行另拟拆解方法。 | 每批只给“读完总结”的提示词。 |
| “为什么要检查可能” | 没有依据把某个词设为专门检查任务；取消这种学习重点。 | 让“可能、不一定、例外”占据提炼任务。 |
| “什么叫反驳和回应……不是通过这些词连接” | 按文章本身的认识发展和推导理解，不强塞预定标签。 | 给所有文章套同一套我自定的论证格子。 |
| “最重要的是怎么提炼观点” | 学作者如何选问题、抓关键因素、解释主体行为、联系事实、形成判断和取舍，并学其表达。 | 只列结论、抽象标签或语气词。 |
| “去学”“搬过来用才是学习” | 方法学习落实为真实源码的运行；代码产物进入后续处理。 | 搜过、看过、下载过被称为已经采用。 |
| “放到仓库”“放了用了没有” | 固定源码版本、实现和真实结果保存进项目；后续调用真实使用这些结果。 | 文件存在与核心方法参与混淆。 |
| “流程完美吗”“粗制滥造” | 用真实原文完整运行，说明实际缺口；不以测试数量或成功退出保证人物复刻成功。 | 报告接口跑通和测试数量，替代复刻效果。 |
| “完整弄过来，一步步” | 保留所采用项目的正常阶段和阶段连接；可选分支与必经阶段区分清楚。 | 摘模板或单个函数，跳掉训练等阶段却沿用完整方法名称。 |
| “不要改正常流程”“正常流程干嘛少” | 不删算法步骤；必要的数据/模型接口适配、源码故障修复逐项标明。 | 把另造方法包装为适配。 |
| “不是提示词决定的” | 保留资料、状态、记忆、检索、处理代码、中间产物传递、回答和存取；原项目中的提示词仍是其一部分。 | 用一份长提示词替代系统。 |
| “一年前的模型都可以” | 优先依靠成熟流程的实际实现；更强模型不代替方法。 | 拿 Pro 或 Astra 更强作为可靠性根据。 |
| “1.08万字……1500篇吃得下吗” | 输入、产物、使用时上下文分别计量；原文留在存储中，依项目机制调用；不按篇无限扩写。 | 把产物越长视为学得越深，并准备全部塞入上下文。 |
| “未证明、未验证……除非作者自己说” | 作者学习阶段不引入模型自己的外部真假裁判，不主动外查作者是否正确。 | 在提炼正文插入无来源的怀疑和免责声明。 |
| “全都相信……不管对错就吸取” | 以作者自己的认识为重建输入，忠实学其立场、偏好、判断与经验。 | 按模型价值取向过滤、纠正和稀释作者。 |
| “克隆一个人”“不是世间真理” | 目标是这个人的认识体系和局限，不把作者改造成模型认定更客观的人。 | 把人格学习变成普遍真理审查。 |
| “思维、逻辑、说话方式、评判体系、价值观、世界观、方法论” | 这些共同构成目标；面对新问题能按作者的认识分析并表达，不能只模仿措辞。 | 用声音相似或记忆命中代替全部目标。 |
| “百分百明确判断弱化” | 作者怎样肯定、否定、强调，按原意吸收，不擅自加“几乎”等缓和。 | “都”改“几乎”，或把强判断变成保守说法。 |
| “从源头上相信” | 忠实重建要求贯穿输入、每个原生生成调用、综合和回答。 | 到最后才逐句补丁返修。 |
| “每一个字每一句”“不是看第一句和最后一句” | 按全部实际要求执行；反复追问说明反复未落实，不能略过。 | 把重复批评当作无关文字，仅回应首尾。 |
| “你克隆了什么”“现在完全不能做到” | 现有证据不足以宣布完成了作者复刻；本次小批运行也不自动改变该状态。 | 再把流程演练报成作者已经学会。 |

作者在原文中讲的回测、证伪、稳健性检验或改变认识的方法，属于他的认识，照样完整吸收。这与模型在学习过程中自行审判作者是否正确是两件不同的事。

历史中的“先学作者，再研究危机”“原文笔记本可回查”“跨年认识变化保留出处和时间”“以同一公众号整体学习，不按署名拆成人”继续有效。
