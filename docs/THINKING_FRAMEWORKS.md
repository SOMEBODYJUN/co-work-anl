# 学习长期分析方式，更新当期判断

本项目学习公开文章中可观察的论证策略：先问什么、看谁的约束、怎样追资金和成本、如何处理政策及制度。不能声称还原作者的内部心理，也不把某一年观点固定成所有agent必须维护的答案。

## 四层研究记忆

| 层 | 保存什么 | 如何使用与修订 |
|---|---|---|
| 会计约束 | 资产负债对应、存量流量、资金来源用途、损失承担、不可重复计数 | 按明确核算边界始终勾稽；边界和统计定义变化时重做对应表 |
| 慢变制度与行为前提 | 决策权、预算责任、激励、担保、政策偏好、执行惯例及历史证据 | 作为有依据的先验前提进入机制；制度、执行或群体行为改变时修订 |
| 可迁移分析动作 | 分析者怎样找矛盾、分解问题、列竞争机制、追查损失转移与现实资源 | 新专题优先采用这些问题与检查动作；用新的具体对象实践，保留成功及失败 |
| 当期状态与估计 | 发布版本、收入现金、暴露、参数、政策进展、预测及当前裁决 | 按信息时点更新；与慢变框架冲突时同时审查观测、模型和旧前提 |

所谓长期“定调”，在本项目体现为稳定的问题意识和受证据约束的行为前提。规范性的价值目标、对现实行为的预测、会计恒等式是三种东西。例如希望资源到达低收入家庭，并不能证明政策实际以此为优先；反过来，历史偏向生产者也不意味着转向居民永不发生。

## 从已读材料归纳的策略卡

以下为本项目对公开论证的归纳，原文与阅读边界见 `research/analysts/INITIAL_READING.md`、`docs/VIEWPOINT_PROGRAM.md`，不是模仿作者身份。

| 路线 | 持续使用的问题与动作 | 需要防止的盲点或改判条件 |
|---|---|---|
| Pettis资产负债表与分配 | 逐部门找损失和补贴的承担者，追查展期后成本怎样转为收入、回报及需求变化 | 不能由会计上的资源转移，直接决定行为弹性和兑现时点；真实收入转移或有效重组会改变路径 |
| Batson制度与执行 | 比较规则、实际执行、利益关系和政策文本变化；将融资安排与家庭风险对应 | 对动机的推测要与事实分开；制度解释成立不保证短期销售预测正确 |
| Wright信用与政策工具 | 分解信用需求、供给、续债、银行利润及财政执行，查工具的边际效果 | 总量下降的方向不证明每个原因；中央一次性收益、地方税源和土地必须分开核算 |
| 张斌需求负反馈 | 分析支出—收入—信用的反馈及快慢变量，寻找可以阻断循环的净新增支出 | 政策资源、对象和传导时滞仍需实测；不能由会计分解单独识别因果方向 |
| Setser公共资产与或有损失 | 将融资能力、资产、直接债务与承接损失分开列账，再检查政策是否使用空间 | 当前仅核读一篇，不宣称已提炼长期作者框架；账面股权不等于当期可用现金 |

不同框架在同一机制上组合。例如财政问题同时使用资产负债表、执行能力与需求反馈：中央能否融资、谁决定转移、地方实际到账多少、谁获得收入、银行承担什么损失、需求何时改变。保留它们的分歧，不能把几个结论平均成一个结论。

## 现实约束进入基准判断

每条重要政策或恢复机制，写清行动者、权限、资金来源、规模、受益对象、执行步骤和时滞，再以预算、合同、实际拨付及历史行为检查。宣布的政策可以通过可信预期影响行为；直接现金效应与预期效应分别建模并找观测。基准路径采用有现实支持的行为与资源假设，政策的愿望目标不自动成为预测。

专题任务同时交代：采用的策略问题、慢变前提及依据、当前观测、最强竞争解释、会改变前提或当前判断的条件。Main负责比较解释与量级，并作明确裁决。

## 明确判断的交付方式

每个核心问题以“我的主判断是……”开头，给对象、方向、时间窗口和承重机制；说明它为何优于最强竞争解释。随后给出需要什么现实变化才改判，以及当下行动条件。模型误差以实际样本、误报漏报、敏感参数和适用范围表达，不能用无排序情景清单代替选择。

某个模型未通过检验时，明确拒绝其当前用途，继续用已核验观测、部门核算和可检验机制完成主判断。保留真实的不确定性与可修订条件，同时完成裁决。科学检验和明确判断共同约束研究。
