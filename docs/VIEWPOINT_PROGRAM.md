# 观点学习与竞争机制研究任务

观点学习要产出可以改变判断的分析。每个专题从作者怎样解释约束、损失分配、行为和时间出发，再用本题资料选择更有解释力的机制。每个核心问题最终形成主判断；观点数量不决定权重，也不按作者名望投票。

## 目前已有的基础

原有 `VIEWPOINT_SEEDS.md` 三张种子卡已经保存了 Pettis、Sufi、Drehmann/Borio/Tsatsaronis 的问题和方法。阅读范围分别是作者原文、Sufi作者摘要及芝大简报、BIS作者摘要。本轮进一步打开下列原作者/研究机构页面，补出了竞争机制与实际任务。表中的“已读范围”是当前阅读记录；“下一步”是首轮研究者必须完成的实质工作。

这些方法卡不预填中国当前经济结论。下列 `H-*` 是建议使用的机制命题名，尚未登记为正式图中的有效超边。

## 每张卡怎样交付

专题agent完成一张卡时，在 `research/viewpoints/<卡ID>.md` 写出：

1. 作者实际解释的变量、时间尺度、制度背景和原文定位。
2. 核心机制的中间步骤，哪些属于会计约束，哪些属于行为假设，哪些已有识别证据。
3. 与本项目最强替代解释的可区分预测；至少指出一项当前数据能检验的差别。
4. 对中国的分组检验：城市、收入、负债、企业类型、银行或地方财力的差异。
5. 适用条件、反向因果、共同原因和作者历史预测的结果；同一标准检查支持与反对作者。
6. 对当前图、正文或参数的具体改动：加强、削弱、替代、撤回，或有依据地保留。

下一步先读研究正文中承重机制、数据、识别设计和稳健性段落；相关复现材料只有实际运行后才登记为复现完成。观点摘要可以用于派工和选择框架，正式因果结论要回到能承重的原文段落与本题检验。

## 怎样形成竞争而不是堆积观点

围绕同一观测分别写出竞争机制。比如“利率下降但私人信用仍弱”，至少区分：主动修复资产负债表、未来收入/利润预期弱、有效抵押品不足、银行供给约束。专题作者列各解释预测，数据研究者寻找能区分它们的分组和时序，挑战者攻击最关键桥梁，主代理按解释力与现实量级作裁决。允许多种机制共同成立，但要明确各自覆盖对象和相互关系。

对“政策支持”继续追踪宣布、执行、净新增资源、到账对象和持续时间；对“政策无效”也追踪同样的链条。认为官方或市场叙事存在误导时，指出具体分母、覆盖、修订或因果跳步，再给替代解释。这个程序用于选择当前最有解释力的主判断，不能成为把所有观点并列后拒绝裁决的结尾。

## 传给增量研究者的记忆

保留每次作者框架被采用、局部采用或驳回的具体理由，以及哪项新材料或新推理改变了它。后续agent先读这些历史，再通过 `proposal` 提交机制和正文修改，独立 `proposal-review` 后由主代理 `apply`。把新作者姓名加入参考文献不算深化；新增一条真正能够解释地区差异、损失分配或政策时滞的机制，才算研究增益。
