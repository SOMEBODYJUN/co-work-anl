# 工具、搜索与研究资产的实际状态

这份清单以代码、固定版本和运行收据为准。工程演练用于检查研究记忆、提案、合并和恢复；首轮Pro负责用真实资料完成各专题、经济裁决和完整家庭计算器。

## 搜索与采集

| 能力 | 实际接入/演练 | 判断职责 |
|---|---|---|
| GitHub公开仓库搜索 | 公共API；真实查询 `repo:statsmodels/statsmodels`，保存命中 | 定向测试了发现接口，后续按具体研究问题做仓库筛选、读代码与选择 |

| 原文采集 | BIS金融周期原文实际取回；保存URL、时点、原字节/文本指纹 | 研究者实读、分类、定位；取回页面不自动完成其所有论据核对 |
| Pro内置网络/PDF工具 | 通过JSON bridge和search-log保存真实工具结果 | 搜索服务由Pro实际运行环境提供；CLI管理记忆与来源，不冒称独立拥有全部通用搜索能力 |
| 新闻与事件去重 | URL/hash/统计期/版本/来源家族/event_id/TTL，精确查询及同范围旧搜索呈现 | 语义是否同一事件、哪些采访/反证属于新增信息由研究者判断并记录 |

输入访问演练覆盖18个来源项，其中17个网页、1个本地快照；15网页取回，北大小微摘要503和financeun超时形成定向补采任务。原访问状态、原始数值复核和经济解释分别记录；不能以访问成功代替字段口径审查。

## 已有研究与下一项实质产物

当前已有47条输入观测、18个来源项、三张观点种子卡、财政传导的入库样例，以及工具与更新演练。三张卡实际范围是Sufi作者摘要/芝大简报、Pettis资产负债表原文、BIS金融周期作者摘要；扩展的八组竞争机制与阅读任务见 `docs/VIEWPOINT_PROGRAM.md`。

端到端测试以合成家庭收入8000→9000、现金缺口第7→13月检验真实CLI、Git、两次clone、修订和复算。20份阶段文件是工程用例的阶段说明。首轮研究另须交出真实地产、财政、银行、居民企业专题、观点全文比较、历史对照、真实模型卡与检验、经济报告和多资产120月计算器；不把测试文件更名成这些研究结果。

专题分工、首批已有证据对应的具体任务、超边的提出/相邻核对/独立经济复核/Main裁决，见 `docs/AGENT_PLAYBOOK.md` 和 `prompts/06_SPECIALIST_TASK.md`。研究验收检查这些实质产物，文件版本验收用于保护它们的准确提交。
