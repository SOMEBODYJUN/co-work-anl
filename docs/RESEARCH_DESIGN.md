# 研究判断、观点学习与因果超边

研究系统要积累的是可复用的解释和修订理由。它既保留“发生了什么”，也保留“为什么这样解释、哪一步曾经被反驳、学到什么后改变了看法”。程序管理来源和版本；经济判断由主模型及专题研究者完成。

## 判断的最小内容

每个核心问题都有独立判断 ID，至少回答：主判断是什么、解释机制是什么、适用于哪个群体和时间窗口、由哪些证据承重、最强替代解释为何目前排在后面、什么可观察变化会使判断改写、对家庭行动有什么影响。

“地产仍处于调整”“地方财政拖累需求”“2027年集中爆发银行危机”“经济停滞十年”“A股十年实际总回报为负”分别裁决。前一项成立，不自动支付后一项的举证责任。判断可以很明确，同时保留具体的反转条件；条件写成可监测变量和机制变化，不写“未来很复杂”。

## 资料与观点同时进入研究

| 材料类型 | 保存什么 | 允许支撑什么 |
|---|---|---|
| 原始统计、财报、政策执行记录 | 原文、日期、统计期、单位、覆盖群体、版本、表格位置 | 对应口径的观测事实及可复算量级 |
| 专家文章、工作论文、研究长文 | 原文链接、作者、论题、机制、方法、证据、假设、利益和适用范围 | 分析框架、待检验机制、替代解释；不能仅凭作者声望当作事实成立 |
| GitHub 研究实现 | 固定版本、具体源码/API、许可、输入、输出、真实运行 | 对应方法的计算与可复现结果；仓库名和星数不证明经济结论 |
| 本项目推理 | 所用事实、机制桥梁、反事实、现实约束、量级和反证回应 | 明确主判断及可修订因果关系 |
| 人为压力情景 | 明确的测试用途、参数、单位、施加时点 | 检查策略在给定冲击下的表现；不写成真实预测概率 |

官方发布和市场评论都按具体内容阅读。对官方材料检查统计覆盖、统计期、分母、名义实际、修订、遗漏和政策宣布与执行的区别；对民间材料检查选样、信息来源、论证跨度、动机与历史记录。不能因其官方身份自动接受解释，也不能因其身份自动判为掩饰。若认为发布叙事误导，指出具体遗漏、口径替换或无法成立的推论，并给出替代解释和对应证据。

## 学习观点的方法

围绕实际争议搜索观点，而不只搜数字。可以从输入研究索引中已列出的家庭债务、资产负债表、僵尸企业、地方债和金融周期论文起步，再追原作者的相关原文、反驳与后续检验。每个专题至少覆盖其最有解释力的主要框架和一个真正有竞争力的替代解释；不按固定学派数量凑齐。

每张观点卡回答以下问题：

1. 作者真正解释的变量是什么？它与本项目正在判断的变量是否相同？
2. 核心机制包含哪些中间步骤？谁付钱、谁亏损、谁有权改变规则？
3. 有哪些隐含的制度、分布、时间或行为假设？
4. 哪些是观测结果、哪些是模型推论、哪些是作者对未来的判断？
5. 什么事实能区分它与最强替代解释？作者是否回应过这些事实？
6. 我们能学到哪种分析动作：部门核算、分组比较、反事实、融资约束、利益分配、期限分析，还是历史机制比较？
7. 应当改写本项目哪条传导、哪段正文、哪个参数？若暂时不改，保留理由是什么？

观点有深度，表现为它能解释群体分化、政策约束、损失转移和时间变化，并经得起反事实与量级检验。篇幅、语气、悲观程度和赞同人数都不代替这些内容。资料更多也不自动带来更好的解释；新 agent 要说明新增材料具体改善了哪一步推理。

## 超边如何保存传导

一条超边表示一组共同前提在给定条件下支持一个后件。正文仍要交代机制、量级和可观察检验，图不能把相关性自动升级为因果。

建议为每条边保存：

| 字段 | 内容 |
|---|---|
| 联合前提 | 必须共同使用的事实、资源约束、行为或制度条件；明确 ALL |
| 后件 | 本条机制实际支持的结论，限定群体、方向和时间 |
| 机制 | 中间步骤、资金或损失如何流动、为什么是这个方向 |
| 条件 | 政策执行、再融资、需求行为、合同和其他边界 |
| 时滞 | 冲击从何时开始、经过哪些期限、影响持续多久 |
| 量级 | 观测、会计核算、历史估计或研究判断的依据 |
| 反证 | 当前最强反对证据与已给出的回应 |
| 阻断条件 | 哪种可观察变化能切断或明显削弱传导 |
| 正文与计算 | 原文证据位置、专题分析、脚本、输入和输出 |
| 历史 | 上版机制、修改理由、提案、接受或驳回记录 |

例如“土地收入下降→地方支出下降”缺少土地净收入、转移支付、债券融资和刚性支出条件。更完整的联合机制是：净土地可用资金减少，且转移/融资未抵消，且地方支出有可调整部分，才支持特定支出受压的结论。若中央转移已经弥补，要更新对应条件；不能把原来的单箭头继续用于所有地区。

独立替代解释各保留一条边；不能把 A 或 B 的替代关系误写为 A 和 B 都必须存在。反馈在经济机制中可以存在，但循环内的节点不能互相引用就全部变成已证事实。图必须有循环外的观测、已验证机制或实际测算作为支撑。

同一原始新闻可以被多个专题和多条边引用，其来源 ID 仍只有一个。对同一经济事件的转载进入同一事件簇，保留有新增采访或不同原始观测的部分。来源家族用来辨认同一发布的传播，不等同“某机构所有研究都算一份”。

## 检索记忆与重复搜索

每次搜索前先读取检索计划：主题、变量、地区、统计期、发布期、已搜词、来源、结果 ID、零结果和失效条件。复用适用范围内的旧结果；新月份发布、修订、失效链接、事件进展、新机制所需变量可以触发刷新。一个月前搜不到的资料不能永远标为搜不到。

精确 URL 归一、正文哈希、原发布及版本、事件 ID 提供程序去重。语义上是否同一事件或同一主张，仍由研究者读后判断；新增访谈、修订与反驳不能被“看起来相似”吞掉。检索复用节省重复采集，把时间用于新解释和更深入的比较。

## 修订为何发生

接受修改必须产生具体研究增益：新增观测、关键口径纠正、更强识别、被遗漏的机制、政策实际执行变化、时间结构变化、独立复算纠错或重要反证。增益可以来自深入推理，不要求每次都有新新闻；但必须写清旧推理错在哪里或漏了什么。

修改提案绑定旧 revision，写旧判断、新判断、证据/方法、受影响超边、正文替换、参数变化、需要重算的输出。动作字段为 `retain`、`strengthen`、`weaken`、`replace` 或 `withdraw`。回到曾经放弃的观点时，先回应当时放弃它的具体理由，并在 `responds_to` 引用相关已接受提案。换个 agent、换种语气或重复引用旧材料不构成反转理由。

反证会让依赖节点待复核，而不是自动判另一边胜利。已有节点后，入库新证据用 `targets` 明确受影响节点；没有影响时提交空 `targets` 和具体 `impact_note`。这项路由使新反证进入旧判断的修订链，而不是在旁边新增一份文件就算完成研究。

主代理阅读提案与独立复核后裁决，可以只接受其中一部分。真实复核先通过 `proposal-review` 绑定提案、当前目标和来源版本，`apply` 再检查这些版本及补丁原文件。部分采用时，把接受内容形成新的完整提案并重新复核，不修改已审提案后直接应用。拒绝的提案保留其理由，供下一轮避免重走旧路。

## 定量边界

可以使用已知会计恒等关系、合同贷款公式、公开估计器，也可以建立具有机制依据、明确估计方式和独立验证的新评分或概率模型；每个参数有单位、时点和依据。执行 `docs/SCIENTIFIC_MODELS.md`，分别标示描述指数、预警分数与事件概率。禁止任意赋权、随意归一后称为概率、给未经校准的专家态度附加伪精度。当前验证只支持排序时，仍明确给主路径、次序、时间窗口和行动条件。

家庭策略先比较能否执行、能否维持生活与偿付、现金缺口与储备，再展示财富和机会成本。可以展示每个给定情景下的实际计算，不把情景的数量占比写成现实事件概率。只采用标准且有明确决策含义的比较，不用任意综合评分替用户隐含分配偏好。
