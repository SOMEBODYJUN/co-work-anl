## 已有能力及其实际层级

| 能力 | 上游已有内容 | 本次可复用程度 |
| --- | --- | --- |
| 原稿优先 | 要求保留讲授顺序、例子、动机、证明策略与有意重复 | 可作为基础规程；仍需内容级证据保障 |
| 不清内容处理 | 高、中、低置信处理；中等用 `% CHECK:`，低等保留醒目标记并登记 | 可借鉴分类；本次应让未决内容在交付稿中也可见 |
| 数学恢复 | 要求补写证明、证明提纲如实标明，不冒称出自原稿 | 与本次目标一致；须把原稿读法与恢复建议分别保存 |
| 数学纠错 | 区分排印错误、缺假设、实质矛盾、约定差异；记录依据 | 是人工/模型执行的流程要求，没有自动证明或等价性检查器 |
| 联网核验 | 优先实际打开原始论文、作者/大学/期刊等权威来源，记录精确支持点 | 可沿用；搜索命中本身不能消除字形歧义 |
| 连续性 | 检查点、记号/术语/标签/图形/决定/疑点登记与交接 | 有说明和若干条目样例，没有已实现的状态库、锁或调度 |
| 图形来源 | 原图裁剪、矢量重绘、来源登记、方向与约定检查 | 可复用来源检查；本次不能按“无用”判断删去原稿内容 |
| 编译验收 | 要求完整项目编译和代表页检查 | 是操作要求；脚本不调用 TeX，不检查实际输出 |
| 静态结构 | 页码注释、重复标签、入口直接 include、逐文件环境配对、逐文件页码倒序、部分疑点标记 | 已实现，但边界很窄；实测见下表 |

上游如“faithful”“verified”“publication-ready”等措辞表达目标，README 也明确说结构脚本不能代替编译、目视检查和数学审阅。应把这一边界保留下来，而不是把规程名称当作已经通过质量验证。

## 与本批任务的缺口及必须覆盖的默认行为

| 本次要求 | 现有缺口或冲突 | 需要补充的约束/实现 |
| --- | --- | --- |
| 中文手写 PDF 与旧 Markdown 全部重新识别复核 | 脚本仅扫描 `.tex`；没有 PDF/Markdown 读取、重识别与差异比对 | 固定每份输入身份与哈希；PDF 重新读图，旧 Markdown 作为独立对照，不循环自证 |
| 逐页放大、逐区、逐行 | 仅要求适当分辨率查看和页级注释，没有可验证的区域/行级检查记录 | 全页侦察、带重叠裁剪、坐标/缩放/页号记录；每个来源条目都有转录去向或明确未决状态 |
| 保留全部内容 | 图形模块允许省略装饰性/冗余图；转录模块允许将黑板简写语义整理 | 用户本次要求优先：原始层保留正文、边注、涂改、重复、图与图内文字；整理层可重排，但不能让原始信息消失 |
| 数学恢复不能冒充原稿 | 规程原则支持，但中等置信可按上下文重建并只留 TeX 注释 | 分开记录可见原稿、候选读法、编辑补写、数学核验和决定；未解决读法不被单一整洁公式覆盖 |
| 多份笔记来源分离 | 页码模式只有整数，没有 `note_id`；不同笔记可混成一个页码集合 | 使用输入文件身份、PDF 物理页、区域、条目共同定位；逐笔记验收 |
| 最多三份笔记同时处理 | 无任务队列、信号量、工作目录隔离或写入归属 | 调度层限制活跃笔记数；每份有唯一集成写入者；代理数量不能偷换笔记并发上限 |
| 跨轮使用新子代理 | 没有轮次身份、上下文独立性或复核职责约束 | 新轮记录新代理身份、范围与完成证据；复核者重新看原始图，不能只读前轮结论 |
| 防止只检查标题、定理而丢小字 | 页标记不能说明内容齐全 | 条目级覆盖必须包含普通文字、例题过程、草算、注释、重复、图中标记与删除线信息 |
| 可恢复与真实进度 | 交接是文字要求，无机器状态与原子保存 | 检查点记录已看页面/区域、未看范围、疑点和输出版本；禁止用估计百分比代替证据 |
| 完整交付 | LaTeX 导向，无本批最终 Markdown 及旧稿变更记录实现 | 明确需要的读者稿、忠实转录、来源账本、差异/疑点/恢复记录和真实验收报告 |

“逐行检查”是来源核对的粒度，不要求整理稿机械保留所有扫描换行。但每一行的内容必须能追踪到输出或原始层保留记录。跨页定理或证明应保留连续关系，裁剪和并发边界不能截断内容。

## 不能据此作出的承诺

以下承诺均缺少本次可复现证据，不能对用户宣称：

1. “安装后即可自动完成全部中文手写数学笔记。”仓库没有识别引擎和本批资料基准。
2. “页码覆盖通过，所以全部内容无遗漏。”页标空壳和不可达文件反例已经否定该推断。
3. “退出码为零，所以数学正确、可编译、没有未决问题。”脚本未做这些验收，且未决标记不阻断。
4. “能可靠恢复所有潦草符号。”上下文、外部定理或模型意见只能形成候选，不能证明原稿字形。
5. “已逐页逐区逐行看过”或“已独立复核”。这些必须有实际图像查看与复核执行记录；阅读规程不构成执行。
6. “并行会自动更可靠”或“换代理就保证独立”。仍需并发上限、来源隔离、重新读图、写入职责和综合裁决。
7. “可直接正式发布”。原稿权利、外部图形许可、未决内容和排版质量需要另外核验。

不应把这些缺口归咎为作者违约：上游明示它是技能流程，并明确给出结构脚本的用途限制。本次需要补足的是用户更严格的具体工作协议及执行证据。
