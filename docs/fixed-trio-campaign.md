# 本次固定三人战役复核口径

本次用户明确指定一个 RUN，依次处理 RA12、CA07、CA09、CA10、CA11、CA12。
每篇只使用三名新的 `gpt-6.2-sol`、`max` subagent，三人跨阶段工作至该篇完成；
该篇完成后才换三名新人。因此本次的独立性指三个实际独立代理之间的复核，
不声称三人到终审时从未参与当前篇。

原技能 `audit.py` 的“此前未参与”模式保持不变。`tools/campaign_audit.py`
只用于显式声明 `review_policy.mode: user_requested_fixed_trio` 的本次台账。
该字段以及授权/参与表的真实文件哈希进入完整内容快照；报告显式记录
`review_protocol` 与 `fresh_final_reviewers_claimed: false`。

固定三人模式仍要求两遍不同身份的全页/全区检查，第二遍与恢复复核为非作者；
三名实际代理各自完成一轮全量终审、独立原图记录与对照报告。
Boss 不能替代三人中的任何一个。终审覆盖、图像与原 PDF 像素、双向映射、
正文逐行覆盖、候选与正反验证、未决项、完整快照与三轮哈希链均按原门槛检查。
改动内容后旧轮次归档，从新快照重新检查，不能给旧报告更换哈希。

高分辨率裁图可在 `source_crop` 中记录 `dpi`（72 至 1200），`bbox_px`
始终以 manifest 原始全页像素为坐标。审计重新从原 PDF 指定页、指定矩形、
指定 dpi 渲染并逐像素比较，不把插值放大图当作新的原图证据。

原 PDF 若仍存有被页面裁框遮住的矢量笔迹，可声明 `pdf_viewport` 补证。
该记录仅允许在内存中向外扩大 MediaBox；如仍受 Form 限制，可同时扩大
已存在 Form 的 BBox 及其唯一矩形裁剪指令。审计核验原 Form 流的 SHA-256、
矩形只向外扩大及逐字节可逆替换，再从原 PDF 重渲染并逐像素比较。
不得添加或修改绘画路径，不保存改写后的 PDF，不把上下文推测画成墨迹。
若原矢量中没有后续笔画，正文只保留可见残句，另标注数学解释的范围。

合成测试位于 `validation/test_campaign_audit.py`，不作为真实手稿复核证据。
