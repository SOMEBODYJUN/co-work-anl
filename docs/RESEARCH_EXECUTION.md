# 把可计算数据、思考框架与经济裁决接在一起

本项目的主任务是调查、理解并裁决中国经济风险，计算为承重问题服务。LLM负责原文阅读、语境和命题提取、竞争机制、调查及成稿；有数值和可识别目标的问题交给合适的计量、机器学习或会计模型，保留实际输入和验证。无法可靠量化的观点仍可通过机制、反证和历史核验参加裁决，不强行给每句话造分数。

## 用什么分析什么

| 研究对象 | 适合的方法 | 当前接入和下一步 |
|---|---|---|
| 经济活动、更新的月季观测 | 桥接回归、混频动态因子、发布信息归因；比较滞后/简单基线 | 统一适配器已运行；首轮建设中国面板、发布时点及逐次更新实验 |
| 信用与银行危机窗口 | 先验明确定义事件；正则logit与非线性表格模型比较，成熟标签、时间/国家留出、独立校准 | 真实JST历史样本已训练；当前HGB未获采用，logit仅比较基线；继续检验变量、迁移和误报漏报 |
| 地产—地方财政—银行的损失与现金 | 部门会计、合同期限、银行资本/流动性压力、情景与敏感性 | 部门会计与银行承损适配器可运行；真实分组暴露和资金接口仍由首轮建立，不能把单银行引擎称完整网络模型 |
| 居民实际行动 | 120月合同现金流、多资产约束、策略枚举和独立对照 | 贷款接口已验；完整家庭引擎、界面和策略按计算器规范由首轮交付 |
| 连续文章里的思考方式 | 原文定位、命题/条件/推理步骤、预测兑现、竞争解释和慢变前提卡 | 已有原文阅读与策略卡；按专题继续扩大阅读，形成可修改的框架记忆 |
| 新闻、政策和事件 | 提取行动者、执行状态、金额、期限、受益群体；来源家族和事件去重 | 已有采集、检索与入库接口；提取结果追原文，不把情绪词或提及次数当主经济模型 |
| 联合前提、反馈及阻断条件 | 可审查的机制超边、版本提案、事实核验与下游复算 | 当前为离散机制研究记忆；训练型超图模型是另一个需要定义和验证的研究任务 |

已有模型能放进Codespaces使用，前提是输入、依赖、许可、资源和输出用途适配。CPU表格模型优先运行；需要MATLAB、专有数据库、GPU或额外授权的上游，明确缺什么，再选适配器或替代实现，不把“有GitHub链接”写成已复现。当前采用的源码/许可证/固定版本见`vendor/manifest.json`与`docs/METHODS.md`。

## 一项新模型怎样成为可用分析

先冻结实际问题、信息截点、可观测目标、基线、切分和采用规则，再估计。训练、模型选择、概率校准和最终评估各自使用适当的分离样本；时间序列与事件重叠不做普通随机拆分。已经看过的测试段不能继续充当未见过的最终验证。无论模型好坏，记录成绩、适用对象、失败处和用途裁决。

复杂模型获得更好结果要通过实际比较证明。[BoE WP848](https://www.bankofengland.co.uk/working-paper/2020/credit-growth-the-yield-curve-and-financial-crisis-prediction-evidence-from-a-machine-learning)证明其特定跨国历史设计中机器学习可改善预警，不能保证本地六变量模型复现同样结果。[scikit-learn的验证说明](https://scikit-learn.org/stable/modules/cross_validation.html)解释同样本训练评估的问题和时间/分组划分；实现仍以仓库锁定版本为准。

允许进一步采用混合模型：例如用活动模型估当前状态，用部门现金流算承压量级，用验证过的预警模型辅助风险排序，最后以政策执行和制度机制裁决。这些输出回答不同问题，不能简单平均成一个“中国危机概率”。组合本身若要提供预测数值，也要定义组合规则并另做样本外检验。

## “定调”怎样落地

长期保留的是会计约束、分析动作以及经历史支持的制度/行为前提，分别写清来源、适用边界、反例和修订条件。临时信息和当期观点附时间，不覆盖成长久规则。作者结论转向时追查其信息、假设或推理哪一步改变；在新问题上学会这一步，而非要求模型永远模仿某个人的态度。

每条恢复或政策机制都追问：谁决定、能否执行、谁出钱、净新增多少、谁实际拿到、何时改变行为、损失最终落谁。政策目标不能直接当实际行为，制度偏好也不能当永不变化的自然定律。不同框架在同一问题上组合，保留能区分它们的观测，最终选出解释力最强的主路径。

## 超边和训练型网络的边界

目前代码中的ALL超边登记“这些前提共同通过什么机制、在什么条件和时滞下影响后件”，并传播待复核状态。它能承载离散推理与可修订研究记忆，但尚没有学习参数、损失函数和独立预测检验。因此当前不能宣称已训练出一种离散神经网络，也不能把连通性当成科学因果证明。

如果后续要训练这类模型，先选可核验目标（例如有原文金标的联合前提抽取、预先定义的机制触发事件），明确参数、输入输出、损失、训练/验证/测试边界和简单对照。人工金标的来源与分歧保留；按来源、作者、时期及事件防止泄漏。对预测任务验证迁移；对抽取任务验命题及关系正确性，不能把抽取准确率当因果预测能力。没有这些条件时继续使用可审查的机制图，照样完成经济研究。

## 第一轮先贯通，再有依据地深化

Pro先用现有工具完整走一遍20阶段，把中国真实输入、作者框架、机制、实算、裁决、报告和计算器接起来。模型效果差，裁决拒绝用途并补合适的证据或计算；研究争议能解决，继续调查；界面或计算错误，修后复测。未过验收继续修复，检查点保留同一身份和同一周期。

第一次实质验收通过后，下一轮按新证据和最有价值的问题走8阶段增量，深化数据覆盖、机制或模型，不能每次重建整个架子。具体恢复和停止条件见`docs/PRO_RUNTIME.md`。算力预算可以全部用于有明确输入、研究价值和验收对象的任务；不以消耗多少核小时或模型数量证明研究质量。
