# 独立运行审查

本次审查实际执行统一 CLI、Git 提交、独立 clone 和离线复算，覆盖首轮到增量轮的完整接续。工程演练使用明确标注的合成家庭：起始现金 12000 元，月生活及债务支出 10000 元，初始月收入 8000 元；增量轮将收入修订为 9000 元。它验证研究工程的行为，正式经济判断按研究流程另行形成。

## 实际完整运行

执行 `python tests/run_end_to_end.py`，共调用 63 次 CLI。首轮完成 20 个阶段，登记来源、保存查询、建立 ALL 联合前提边、生成实算结果、报告和可重算的离线测试页面，随后进行版本审查及发布。拒审立即撤销旧通过；审后改正文不能沿用旧审查发布。

首轮提交后，从独立 Git clone 使用克隆内的程序和已保存原始输入恢复，离线复算结果相同。增量轮沿用该工作区和历史，更新一项输入后，旧机制和判断都进入待复核；传导边与结论分别提出提案、独立审查、串行合并，再完成 8 个增量阶段。月度复算从第 7 月首次缺口变为第 13 月首次缺口，并在现金失败处停止。第二次独立 clone 再次恢复当前发布，重放结果相同。

演练保存被驳回提案的具体理由；未经提案审查直接 apply 被拒绝；试图回到旧结论而未回应上次改判依据也被拒绝。脚本中的作者、审查者名称是测试身份，未调用或伪造外部模型分析。该独立审查由单独的实际审查 agent 执行。

## 找到并修复的缺陷

| 复现问题 | 修复后的实际行为 |
|---|---|
| 不同统计期出现相同正文/数值，被仅按正文哈希合并 | 去重同时核对材料类型、统计期、原发布时间、修订版本及事件；不同月份保留独立记录 |
| 同一转载 ID 再次入库触发冲突 | 重复入库幂等；保留原始来源与转载映射 |
| 纯空白文件可以完成阶段 | 空字节和纯空白产物被拒绝 |
| 提案只有合并路径，缺少独立通过或驳回 | `proposal-review` 绑定提案、目标版本、证据与文件哈希，保存通过或驳回；apply 核对当前审查 |
| 改写一个判断就恢复全部入边 | 入边保持待复核，须另行审查对应机制；单改结论不能替入边放行 |
| 只核当前原文，历史版本原文被篡改仍能发版 | 当前与历史版本原始 blob 全部核验并纳入快照；历史字节改变同样阻止发版 |
| 方法子命令与总入口都输出 JSON | 总入口单次输出一个 JSON 对象，便于后续程序接入 |

## 独立回归与方法复算

`python -m unittest discover -s tests -p test_audit.py -v` 的 12 项独立 CLI 回归全部通过，覆盖上述历史原文问题，以及 ALL 前提不齐、开放循环自证、观点提升为事实、搜索范围与过期、拒审、审后变化和未登记正式文件。

在不继承系统 site-packages 的干净虚拟环境中，额外实际运行贷款、桥接回归、DynamicFactorMQ、存量流量以及 AKShare 缓存重放。贷款月供与 vendored numpy-financial 对照误差约 `9.1e-13` 元；混频模型的 news 影响与预测修订勾稽误差约 `1.7e-16`，拟合收敛；AKShare 的 83 行真实宏观表能离线重放。合成面板结果始终以合成工程测试标识，不进入中国经济预测。
