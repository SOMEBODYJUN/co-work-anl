# 从分析者的历史观点学习，再修订研究问题

本项目需要真正的经济解释：作者如何理解制度、利益、资产负债表、政策行为和传导。方法论文与代码不能代替连续的观点阅读。专题分类先作为工作假设，经过下面的原文学习后再拆分、合并和增加；不以一张预制部门表决定研究边界。

评分指模型估计与验证后的输出，包括压力指数、事件排序、严重程度和有校准依据的概率。观点学习不建立材料分数、博主总分或情绪指数来替代经济模型。

## 先盘点，再逐篇形成可追续的判断

1. 确认作者、原发站点、其他发表渠道、付费/公开边界和转载关系。候选池同时包括独立博客、中文分析者、机构研究者及其最强批评者。名气、语气、政治立场和支持人数不作为入选依据。
2. 对拟长期学习的作者，尽可能盘点当前公开历史目录，按时间建立队列。全文无法取得的项目保留精确缺口；没有原发日期的转载不用于事前预测核验。公开目录完整只意味着该站点当前公开文章的目录完整。
3. 初筛也要留理由。音乐、书单等文章可以在读到足以判断内容后注明范围外；标题和分类只用于排队。跨年、跨周期选读，主动找重大转折、作者改口、失败预测和他人回应，避免只采集当前看起来正确的文章。
4. 逐篇读正文及承重引文。记录作者在当时真正提出什么，分开机制解释、条件预测、无条件预测和政策主张。二手转述回到被引用者；无法回到原文时保留引用层级。读摘要、读正文段落、读全文、复算图表是不同状态。
5. 形成文章卡后，再整理同一作者的观点时间线：稳定框架、发生变化的命题、变化依据、失误和未兑现条件。重复文章合并解释，但保留日期、原句位置和版本。
6. 用当时可得信息核验预测。固定对象、指标、方向、窗口、条件和措辞，届期后接实际结果。含糊判断不强行变成数值预测；不能把预测期延后到终于正确，也不能把政策建议误当实际预测。无法归责的条件变化单独解释。
7. 另一位真实研究者回读承重原文和反证，作采用、局部采用、收窄或不采用的书面裁决。作者在一个领域判断失误，不自动否定其全部机制；有一次成功也不能授权其所有观点。

## 每篇保留的实质内容

文章卡包括：作者/标题/原发时间/URL/版本；阅读范围；当时的对象与背景；完整的机制链和必要条件；直接数据与转引出处；作者最强论据；最强替代解释；可以区分两种解释的观测；预测的事后核验；对本项目的问题、专题、超边或模型变量的具体修改。

主张拆成最小可质询命题。机制与预测不能混为一句；例如“风险转移给购房者”与“今年销售恢复”分别登记。观点不是新的独立观测，不作为危机训练标签。因果识别没有完成时保留经验或机制推断的范围。

## 怎样传给下一名 agent

交接包同时提供：作者时间线、选用与未选用理由、文章索引、原文精确位置、竞争解释、已核验和待核验命题、旧裁决以及需要继续读的断点。承重主张必须能沿索引回到完整原文及其前后条件；不能只把几个警句放入系统提示词。

Main按当前争议选择下一名阅读者，阅读者根据文章发现修订问题表，再由相邻专题核对资金/行为接口。独立挑战者优先读原文和相反案例，再读作者的蒸馏。通过审查的机制才按既有提案程序进入正式图。完整著作和文章的阅读访问按实际权限进行；公开仓库保存索引、自写研究笔记和可分发输入，不自动上传第三方全文。

具体派工包括四种可滚动职责：原文与作者脉络研究者负责目录、原发定位和观点变化；历史命题核验者独立固定预测对象与结果；竞争解释研究者读取真正相互冲突的原文并提出区分观测；专题编排者将已学机制转成问题、接口、模型目标和超边候选。一个空位可以在不同轮次承担不同职责，作者与其独立核验者仍使用不同真实身份。

甄别时逐项检查：危机定义是否随时间偷换、旧文是否经过事后改写、预测窗口是否不断后移、统计分母和量纲是否混用、多个说法是否来自同一个匿名源、政策建议是否被包装成已发生预测、作者是否解释失败和改判。付费研究、持仓或商业宣传作为利益背景记录。最终给具体机制的采用与不采用理由，不给作者整体制造一个数值总分。

## 已运行的目录接口

```sh
python work.py analysts inventory-wordpress \
  --site andrewbatson.com \
  --output research/analysts/batson-public-inventory.json
```

此接口实际连接公开WordPress API，逐页取得目录，核对唯一文章数与站点报告数；不调用大模型，不生成观点、不打分。重新盘点保留已登记的阅读记录；文章元数据变化后标为需重读。达到页数限制或出现缺项时不登记目录完整。其他发布系统需要其自己的索引接口或经核对的人工目录，不能伪装成已经覆盖。

当前实读笔记见 `research/analysts/INITIAL_READING.md`，从原文派生的跨专题问题见 `research/analysts/RESEARCH_QUESTIONS.md`。这些是首批阅读成果；各作者的全渠道历史蒸馏尚未完成。
