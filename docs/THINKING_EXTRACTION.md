# 真实文章到经济思维的执行合同

先取得原文，再归纳作者如何认识经济。公开署名、机构等级、措辞激烈都不替代实读。
选用文章须说明它提供了什么：主体行为模型、制度约束、反常线索、解释竞争、认识变化，
或能推翻旧认识的反证。宏观统计发布通常是观测输入，不能因来自官方就充当思维教材。

以上是可借用的方法；没有一个上游原样提供完整的中国经济思维蒸馏器。下面是本项目
对这些方法的明确适配，由实际研究代理完成语义工作，程序提供真实输入、定位和接口。

## 读者收到什么

任务包固定给出研究问题、真实正文段落、作者/日期/URL/哈希、本合同、输出结构与可运行命令。
段落来自实际文章正文；项目几十字的摘要不能代替原文。遇到只有摘要、菜单或登录页，
给该文留补采任务，继续有正文的文章。

## 提炼什么

1. **世界认识**：作者认为经济中哪些关系持续重要，例如政策选择、部门收入、承损和信用如何相互作用。
2. **主体模型**：谁有权选择，追求什么，受什么约束，能把哪些成本转给谁。
3. **问题优先级**：作者为什么先问这个问题；这种先后次序能揭示什么、会漏掉什么。
4. **推断动作**：看到什么反常线索，提出了什么隐藏机制，怎样区分它与真正的对手。
5. **跨文变化**：同一作者跨时期是否改变假设或结论；不同作者分歧究竟发生在哪一环。

经济思维输出要有连贯的认识，不写成“注意A、不能B”的禁令清单。每项有分量的认识
附文章和段落定位；跨文支持不足就准确标为暂定，不自造作者从未表达的心理活动。
作者公开论证、项目重构和当前经济裁决分别标明。

## 怎样接进研究图

从原文产生精确命题，标为作者主张、观测或项目推断。机制记录全部共同前提、后件、
行动者的实际选择、条件和时滞。两种解释要面对同组事实，提出一个能改变排序的观察。
图查询必须返回整条机制、全部前提及原文定位；随后据此写出具体下一项调查。

来源定位和结构检查不自动决定经济真假。普通线索先进入候选研究记忆；正式报告的
承重判断再由实际读者核论证、数据与量级。缺口要转成补采、比较、计算或修订任务。

关系区分analytical_inference（根据论证推出认识/调查）、causal_hypothesis（现实因果
假说）与feedback_transition（跨期状态变化）。作者争论可以启发调查，不能只因
把双方文字放进同一个ALL前提就算现实机制成立。一个后件只表达该边实际能推出的
内容；不同机制共同解释复合现象时先拆子命题。反馈需要时间下标，不能以原结论作
同一时点的前提。编译器保留完整推理示范和后续调查，供报告作者直接学习与使用。

## 成稿与继续

写作先给本题主判断，再给决定性事实、主体行为和机制，回应最强对手。后台状态和
程序检查不进入正文。任务只回答包中的问题，不能把局部演练扩大为整场中国危机已研究完成。
暂时取不到某文只影响该文，不影响其他阅读与报告推进；计算器不在研究任务中。
