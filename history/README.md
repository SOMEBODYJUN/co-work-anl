# Historically superseded routes

The files under [proofs](proofs), [handoffs](handoffs) and [searches](searches) preserve development history, unique derivations and failed search evidence. Their old frontier statements do **not** override [CLAIMS.md](../CLAIMS.md). In particular, the older true-minimum route is not the bit-polynomial phi constructor, and the earlier heterogeneous sparse-lower interval is superseded by the overlap-two strict factor-2 family.

Original paths and new destinations are recorded individually in [path_migration.json](../research/path_migration.json). For current mathematics start with [ASSETS.md](../ASSETS.md) and [the hypergraph](../research/index.html).
