# 完整策略锥攻击：逐人反例、聚合锥障碍与最优 p 支付界

本目录是独立研究工作区，没有修改仓库或登记。所有结果使用共同有限目录、单位客户克隆、相同的 equal-share 效用、完整有序历史纯 SPE。没有产生原半覆盖猜想反例，也没有产生真正聚合安全桥 `W<n v_n` 反例。

## 1. 真正逐人安全桥已被完整 SPE 否定

`individual_security_failure_360.json` 自含 360 个单位客户的 19 个兴趣类型、六个两两不同覆盖标签、全部 43 个有序决策历史的策略，以及静态安全值原始/对偶。策略是仓库既有 36 客户策略，客户重数改变：根 X0，第二人选相反组三主题中的最小标签，末位选第二行动所属组中最小未用标签。

其实现路径为 `(X0,Y0,Y1)`，收益 `(102,117,117)`，`W=336`，`OPT_3=360`。真正静态安全值为

\[
v_3=\frac{93177}{908}>102,
\quad u_1-v_3=-\frac{561}{908}.
\]

匹配原始分布是

\[
p^*=\left(\frac{79}{681},\frac{115}{454},\frac{115}{454},
\frac{347}{2724},0,\frac14\right).
\]

静态对偶竞争背景及概率为 `01:67/227`、`02:67/227`、`12:27/227`、`34:1731/7264`、`35:381/7264`。对偶查询上界除 Y1 为 `90699/908` 外，其他五主题均为 `93177/908`。因为 Y1 的对偶查询严格低于值，任何最优原始分布均有 `p(Y1)=0`；五个正概率竞争背景必须全部绑定，剩余五列绑定方程的 Fraction 秩为五，所以 `p*` 唯一。

独立脚本 `verify_individual.py` 没有导入优化器、仓库 solver 或任何上传核验器。它直接沿每个有序历史重放策略，检查全部 258 个行动比较，枚举全部 36 个有序静态背景，核对原始下界和六查询的对偶上界，检查六标签覆盖两两不同，以及唯一最优 p 的秩论证。冻结输出为 `individual_security_failure_360_verification.json`。

聚合仍有

\[
W-3v_3=\frac{25557}{908}>0,
\qquad 2W-\operatorname{OPT}=312>0.
\]

在这个唯一安全最优分布下，`W-Σ_i C_i=65339377/3710088>0`。根的激励松弛恰零，`D_1=102`、`C_1=v_3`，故负根去相关与真实 `u_1<v_3` 相符；后两人支付足够补偿。根团队已另找到更简洁的 34 客户压缩，主文可采用该压缩；这里保留唯一 p 的 360 客户证书。

## 2. 完整锥上的、对所有 p 同时成立的精确障碍

固定完整策略 σ，所有非空客户兴趣 mask 的非负重数为 w；完整有序历史的真实偏离行组成 Γ，故 `w>=0, Γw>=0` 恰为完整 SPE 重数锥。令终局 z 的玩家 i 收益行为 `d_i`，福利行为 `c`。

对目标 `d=d_i`，若存在一个合法静态竞争分布 Q，并且对每个查询主题 a 分别存在非负有理 `λ_a,r_a`，使逐 mask 恒等式

\[
d-\sum_B Q_B f_B(a)=\Gamma^T\lambda_a+r_a,
\]

则对任意该锥内 w，所有查询都有 `E_Q f_B(a) <= u_i`，因此静态 minimax 给 `v_n(w)<=u_i(w)`。这一证书的 Q 不依赖 w 或 p；λ 可以使用任何真实离轨历史。对 `d=c/n` 同理得到整个锥的聚合安全桥 `W>=n v_n`。

`complete_cone_security_barriers.json` 自含三棵完整策略和全部证书；`verify_cone_barriers.py` 独立从完整有序策略重新生成 Γ，要求每个保存行真的是某个真实偏离行，核对 Q 合法概率、λ 非负及所有 mask 的残差非负。它没有导入候选生成器。共 13 个证书、4914 个客户系数恒等式全部精确通过。

| 固定策略来源 | 覆盖的整个重数锥结论 | 单人证书的纯静态背景 |
| --- | --- | --- |
| 61 客户根税策略 | 每人 `u_i>=v_4`，且聚合 | 前三位 005，末位 000 |
| 89 客户总去相关策略 | 每人 `u_i>=v_4`，且聚合 | 四位依次 005、002、025、025 |
| 36 客户原策略 | 后两位 `u_i>=v_3`，且整个锥 `W>=3v_3` | 后两位 04、03 |

61 与 89 的四个单人 B 正是各自实现终局删除该玩家所得的竞争背景。因此这些完整 Γ 证书更具体地说明：任意重数只要保留该策略的完整 SPE 性质，原实现终局就仍为静态纯 Nash 终局。静态 PNE 显然逐人安全，所以继续调整这两棵策略的重数不能攻击真正安全桥。

36 的聚合 Q 可取如下七个背景：`01:1982/6471`、`02:1442/6471`、`03:1/3`、`04:565/6471`、`05:5/719`、`34:55/2157`、`35:115/6471`。所有六查询的 `W/3−E_Q f_B(a)` 都有保存的非负 Γ 分解。因而 **在保留这棵原策略时，任何非负客户重数、任何 p 都不可能得到聚合安全桥反例**。根的共同 Q 接口没有证书，已经由 §1 的真正逐人反例说明为何。

这些都是三个指定完整策略锥的量词，不能提升为任意策略、任意人数或任意目录定理。

## 3. 五个固定游戏中所有完整 SPE 的最优 p 预算攻击

为了不继续做低信息随机权重搜索，另对固定 36/34/360/61/89 客户游戏、各给定精确安全最优 p，计算该游戏全部纯 SPE 的最大 `Σ_i C_i(p)−W`。

菜单递归的合法性如下。在历史 h 的各行动 b 后，令 `M(hb)` 为全部可以由完整纯 SPE 续局实现的终局。当前玩家可以给每个未选分支独立指定一个续局；因此当前实现 q 是可行 SPE 终局，当且仅当 q 属于某个选行动 a 的菜单，且

\[
f_a(q)\ge \max_b\min_{q'\in M(hb)}f_b(q').
\]

对于固定实现有序路径 z，在轨玩家 i 的偏离 b 可以取任何 `M(h_i b)` 中满足 `f_b(q')<=u_i(z)` 的终局。来自不同在轨节点的首次偏离分支互不相交，所以可以分别选使独立查询 `Σ_a p_a f_{B_i(b)}(a)` 最大的续局，然后装配完整有序策略。这样精确取得给定 z 的最大 C 总和，再遍历全部可实现 z，取得游戏上的全 SPE 最大值。

生成器 `menu_gb.py` 仅利用计数来压缩这个指定对称游戏的状态，输出的策略仍指定全部有序历史。独立审计 `verify_all_spe_gb.py` 完全不使用计数压缩：它直接为每个有序历史递归所有有序终局，独立计算最大预算违反值，并重放保存的达到策略和静态 p/Q。二者结果精确匹配。

| 固定游戏 / 指定安全最优 p | 全部可实现有序 SPE 路径数 | 全 SPE 中最小 `W−Σ_i C_i(p)` |
| --- | ---: | ---: |
| 原 36，六主题均匀 p | 48 | `17/6` |
| 根团队压缩 34，其保存 p | 40 | `60/41` |
| 360，唯一最优 p* | 23 | `55088965/3710088` |
| 61，其保存 p | 102 | `3/2` |
| 89，其保存 p | 6 | `70429743611/10570351740` |

所有值严格正，故改变这些固定游戏的完整 SPE 平局续局仍不能破坏给定最优 p 的 GB。360 的 p 唯一，故该游戏上所有完整 SPE 的最优 p 补偿预算都为正。其余行只涉及指定的一个最优 p；没有把它们的最优分布全空间覆盖进去。

冻结输出为 `all_SPE_GB_verification.json`，每例保存完整达到策略为 `all_SPE_GB_*.json`。这些有限游戏的完整枚举仍不是任意游戏的支付定理。

## 4. 复验及剩余边界

```sh
python verify_individual.py
python verify_cone_barriers.py
python verify_all_spe_gb.py
```

本轮主实质结果是真正逐人桥被否定。原一般半覆盖和聚合安全桥没有被否定。指定三棵完整策略的聚合锥攻击已精确耗尽；五个固定游戏的完整续局预算攻击也已精确闭合。下一次针对聚合桥或安全最优 p 的 GB，必须改变完整策略锥与客户游戏，不能继续在这些已证障碍内调权重或平局。
