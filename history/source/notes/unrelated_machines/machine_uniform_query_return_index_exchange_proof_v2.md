## 1. 真实内部负载精确化为截断整数容量

令 N=|A|+2k。固定机器 h，若 s_h>0，其全部有限端时间都是同一 s_h，安排 z 个原 jobs 的负载恰为 z s_h。因此峰≤T 的充要条件为 z≤floor(T/s_h)。由于整个系统至多 N 件原任务，截断 c_h=min(N,floor(T/s_h)) 不改变任意模式的可行性。s_h=0 时，任何至多 N 件任务负载都是0，取 c_h=N 精确；s_h>T 时 c_h=0。

于是每个模式恰对应原资格二部图的一个容量匹配：每件指定内部原任务匹配一次，每台 h 接至多 c_h 件。反向任意这样的匹配直接就是原真实时间上的 strict T 调度；并非分数执行或虚拟任务替代。

容量可用容量网络实现，不必展开 slots。为组合论证也可把 h 替成 c_h 个有相同资格的 slots：总数至多 |H|N，是真正显式多项式上界，而不是未截断的 T/s_h。匹配解码时把该机的所有 slots 归回同一原 h，实际负载仍≤T。

## 2. 一次增广给二选一算法

固定 i≠j，设 aligned_i、aligned_j 的实际调度均已核合法且峰≤T。记

    L = |A|+k。

先在容量匹配图中取 aligned_i 的匹配，删去原 job q_i 的匹配边。得到 M，它完整覆盖

    A ∪ (R\{b_i})

的 L−1 件 jobs，未遗漏任何 A。现只考察左侧 jobs

    U = A ∪ R ∪ {q_j}。

其中当前恰有 b_i、q_j 两件未被覆盖。aligned_j 的匹配完整覆盖 A∪(R\{b_j})∪{q_j}，也全部属于 U，大小 L。因此 U 对 H 的最大容量匹配至少为 L，比当前 M 大一。

标准容量匹配增广性保证存在一条增广路；也可先作有限 slots 展开后应用普通二部图的增广路事实。该路从一个未匹配的左侧原 job 出发，只可能是 b_i 或 q_j，终止于有空余容量的机器。翻转此路保持所有原本已匹配左侧 jobs 仍恰匹配一次，仅新增起点那一件。

- 若起点为 b_i，输出覆盖 A∪R 的匹配，恰是 inactive。
- 若起点为 q_j，输出覆盖 A∪(R\{b_i})∪{q_j} 的匹配，恰是 mismatch(j,i)。

每个输出只用原有限端，所有原机器同时满足容量，故实际峰≤T。这证明不作 inactive 前提时的二选一构造，并不需要枚举所有内部子集。

如果 inactive 在 T 不可行，第一种增广结果不可能存在；因此结果必为 mismatch(j,i)。交换 i,j 后另运行一次，得到 mismatch(i,j)。对任意不同索引均如此，故全部 aligned 可行且 inactive 不可行时，所有 k(k−1) 错配都在 T 可行。

这等价于把固定 A 收缩、再截断到边界 k 阶的 transversal matroid basis-exchange，但上述完整增广证明不要求 reviewer 免费接受该归属。固定 A 不能被增广路删掉；其覆盖性在翻转前后逐件保持，正是这里的强制辅助合同。

## 3. 全部原任务、outside 与 weak 阈值

局部输出覆盖当前内部模式 A∪X。完整私有测试封装中，对每枚边界 j∉X 放自身 O_j；这些机器互不相同且处理时间都是 T，因此 outside 全机峰≤T。每枚原任务要么在内部输出中恰一次、要么在其 O_j 恰一次，两类互斥并覆盖全部 N 件 jobs。

真实 compiler 若把 outside 资格接到共享变量环，改变某个边界任务的内外状态可能破坏那些机器的锁定负载。本构造不保证这样的全局扩展；Claim 只证明局部接口存在这些具体身份模式。它也没有称错配会让任意给定公式 strict 可行。

若 B≥T 且接口禁止峰≤B 的 inactive，则尤其禁止 T inactive，所以前节的结论适用。输出的 mismatch 本来已经 strict≤T，因此也在 weak≤B。这里完全不需要 B<2T、也不把 B 当某个待猜的 OPT。

## 4. v1 特例的准确含义

旧单容量 v1 中，所有内部 finite 时间属于 (B/2,T] 且 T≤B<2T。两件任意内部 jobs 若落同机，负载严格大于 B，因此也大于 T。每个 strict 或 weak 内部可行模式都只可能每机至多一件；反向任何资格匹配的每条真实端时间≤T，故给 strict 调度。

所以 v1 的 strict 可行模式等价于把所有 finite 时间先统一成 T 的逐机统一系统，其容量均1。对这个模式等价系统用本证明，输出相同原资格的匹配后再恢复真实时间≤T，就得到 v1 的同索引交换结论。没有声称 v1 的每机原时间本身都相同，也不回改 v1 原输入域。

## 5. 有理位复杂度、端点与技术扣除

所有 s_h、T 的二进制有理比较、正数除法后取整与 min(N,·) 均按输入位长多项式；s_h=0 先单列。即使未截断 floor(T/s_h) 数值极大，其整数位长仍由输入数值位长控制，且不用按其数值生成网络节点。实际机器容量始终≤N，流/匹配图仅依显式任务、机器、资格及这些整数容量。

检查给定两调度、删除 q_i 一边、寻找一次增广路及解码全部原机器目的地都确定性多项式。若见证未给，先分别求两个 aligned 的容量满匹配，失败时可靠报告对应模式不可行即可；这不声称求一般 weighted UM 或隐藏源最优解。空 H、零容量行或辅助 A 本身不可匹配只会使 aligned 前件失败；s_h=0 不产生除零，T>0 是本域前提。N≥4 由 k≥2 保证，容量截断无需单列 N=0。

全部原任务实际负载可按各机接到的整数件数乘 s_h 回算，输出大小按显式原输入多项式。没有使用有限枚举作为一般证明，也没有实现新软件。

容量匹配、增广、transversal matroid 收缩/截断/交换均为标准技术。本合同只把它们应用到所有原 query / return 身份的精确局部接口，并说明为何增加逐机统一 tiny slots 仍不能修复索引同步；不认证全球新颖性或独立成文价值。没有 NP-hard source、near-2 gap、全局 decoder 或一般 UM 算法结论。主目标保持 OPEN。
