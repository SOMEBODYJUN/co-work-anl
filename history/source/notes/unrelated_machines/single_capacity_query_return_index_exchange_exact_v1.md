## 1. 明示局部实际矩阵与模式

给显式有限内部机器集 H、显式辅助原任务集 A，以及两组相互不同的原边界任务 Q={q_1,...,q_k}、R={b_1,...,b_k}，k≥2。三类任务互不相交。给正二进制有理数 T、B，满足 T≤B<2T。

输入为这些 jobs 在 H 上的显式资格与真实处理时间；所有有限内部端均满足

    B/2 < p_hj ≤ T.

未列端为∞；辅助任务任意资格数，无树/环/无预载/状态独立等额外结构要求。内部机器没有外加预载。所有 A 必须在 H 实际执行。

对任意边界子集 X⊆Q∪R，称 X 为可行内部模式，当且仅当 A∪X 的每枚原任务可整件、恰一次地合法分到 H、峰≤T；其它边界任务不在 H 执行、须由接口外部执行。由于所有有限内部时间 >B/2，若一个模式有峰≤B 的内部实际分配，每台 H 也只能一件 job，因此同一模式已能在峰≤T 实现。此句不对外部机器或它们的负载作推断。

该局部模式可以无遗漏地嵌入一个完整普通 UM 的测试封装：给每枚边界任务 j 一个与 H 及其它封装机器均不同的 outside 机 O_j，j 在 O_j 处理时间 T；A 无 outside 端。模式 X 的完整调度另要求恰 X 在 H、其余边界 jobs 在各自 O_j，故所有原 jobs 都实际执行一次、outside 峰≤T。若真实 compiler 的边界外端接到共享变量机器而非这些私有测试机，本结论只承诺内部重新分配，不自动承诺外部全局负载可行。

定义：

- 对齐索引 i 的内部模式 X_i={q_i}∪(R\{b_i})：局部网络读入恰 q_i，返回（不在内部执行）恰 b_i；其它 q_j 在外部、其它 b_j 在内部。
- 无查询 inactive 模式 X_∅=R：所有 q 在外部，所有 b 在内部。
- 错配 (j,i) 模式 X_{j,i}={q_j}∪(R\{b_i})：读入 q_j，却返回 b_i。

这三个定义读的是具体原任务身份与原机器实际目的地，非 unit-presence；没有把边界任务复制或拆分执行。

## 2. 精确结论

对每个上述显式输入，假设 inactive 模式 X_∅ 不可行。则对任意不同 i,j：

    若 X_i 与 X_j 都可行，则 X_{j,i} 与 X_{i,j} 也都可行。

因此，如果全部 k 个对齐模式均可行，而 inactive 不可行，那么全部 k(k−1) 个错配模式也都已经在严格阈值 T 可行。任何这样的单容量辅助网络，都不能实现“所有索引可选择、必须至少查询一次、查询原任务身份必须与返回原任务身份同索引”的纯接口合同。

更强的无承诺算法表述：给任意两份实际可行 X_i、X_j 内部调度，可确定性总位多项式输出以下至少一项：

1. inactive 的实际完整内部调度；
2. 错配 X_{j,i} 的实际完整内部调度。

输出峰≤T，覆盖所述模式内全部 A 与指定边界 jobs。交换 i,j 得另一方向。若测试封装也作为输入，按模式将其它边界 jobs 放各自 O_j 后得到所有原 jobs 的完整实际峰≤T 调度。

算法不需要输入原两份见证：可先用显式内部资格图的匹配判定并构造它们，或报告某个对齐模式本身不可行。有限端的 B/2 下界只用来把峰≤B 的弱内部模式化为单容量；构造输出仅用真实原端且实际时间≤T。
